## 下一批真实环境验收

1. 选择一个 HCU Megatron 模型与明确资源，核对运行方式和命令。
2. 全设备健康/性能验收，冻结官方/HCU/依赖/数据/基线。
3. 跑通缩层或完整最小模型，采实际并行域 profile。
4. 热点建模和一个系统/融合候选，局部回归及阶段 loss。
5. 最小 DP 域稳定后接入现有容错，故障注入和本机离线/恢复测试。
6. 根据遇到的真实接口完善适配器、Wiki 和 Skill，并发布后续版本。

首版的“完成”指本表已实现工具和可复现本地验证完成，不表示所有站点、所有引擎和规划中的全部机制已经生产验证。

后续 Wiki 深度扩展还包括官方 release/roadmap 与特性 PR 的持续策展、cuDNN frontend / AI 编译依赖调用链，以及各 SFT/RL 引擎的实际模型与底层实现专题；当前注册和入口说明不等于这些工作已全部完成。
