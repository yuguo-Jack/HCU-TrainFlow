The NVIDIA CUDA Deep Neural Network library (cuDNN) provides optimized operations for training and inference on NVIDIA GPUs. Use attention, matrix multiplication, convolution, and multi-operation fusion through your framework or the cuDNN Python and C++ APIs.

Integrations

Use cuDNN through the tools in your AI stack, or build directly on its graph APIs. These paths show how selected frameworks and libraries reach cuDNN. Support depends on the operation, selected backend, library versions, and GPU.

Get started

Set up a compatible NVIDIA GPU, CUDA, and cuDNN backend before using the frontend. Check the supported products and installation guide for your environment.

Python
C++

Install the Python frontend:

pip install nvidia-cudnn-frontend

Check that Python can load the cuDNN backend:

import cudnn
print(cudnn.backend_version())

Follow the Python installation guide, then build and execute your first graph.

For most applications, start with the frontend APIs. Use the cuDNN backend API if you need a C-only interface or legacy fixed-function routines that the frontend does not expose.

Operations

cuDNN supports individual operations and flexible fusion patterns. Describe a computation as an operation graph so cuDNN can select an execution plan for your GPU.

Attention

Scaled dot-product attention for transformer training and inference.

Matrix multiplication

Matrix products and supported fusion patterns.

Convolution

Convolution and cross-correlation for vision and other workloads.

Normalization

Batch, layer, instance, and RMS normalization.

Mixture of experts

Grouped matrix multiplication for expert workloads.

Pointwise and reduction

Arithmetic, activations, comparisons, and reductions.

cuDNN also supports softmax and pooling.
