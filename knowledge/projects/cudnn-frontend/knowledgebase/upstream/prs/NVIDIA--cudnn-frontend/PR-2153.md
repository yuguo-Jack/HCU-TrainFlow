# Honor D192 half LPT scheduling and preserve runtime initial waves

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2153) · state: closed · merged: True

## Original PR description

D192 half-precision attention declines native SM107 LPT, while the shared THD decoder leaves the accepted SM100 D192 scheduler policies in natural order. Honor the existing LPT/LPT-L2 work order in the compact THD decoders and expose the qualified native SM107 LPT domain, including dense, compact ragged and paged execution.

The native D192 body already uses a persistent THD scheduler. Declare that contract to the adapter and retain up to two initial waves for small workloads. The existing binder reevaluates the wave choice from each call's current storage capacity, including broad shape-override declarations. No device-length read, staging copy, new public knob or heuristic/placement change is introduced. Native SM107 LPT-L2 remains outside its qualified domain.

Validation:

- 29 focused host checks pass, including execution of the actual THD work decoder against independently enumerated expected task orders. The parent fails the new scheduling/admission regressions.
- 30 native SM107 and 20 native SM100 cases pass. Coverage includes FP16/BF16, Natural/LPT (and SM100 LPT-L2), optional Stats, logical dense widths, split identities, bottom-right masks, windows/sinks, changed-length and all-empty retained replay, fresh bindings, poisoned workspace/output tails, paged physical origins, and runtime initial-wave rebinding. Outputs are checked against CPU FP64 and scheduler variants are bitwise compared where applicable.
- Compute Sanitizer memcheck, racecheck and synccheck pass on both architectures; the final two-wave declaration also has targeted THD/rebinding checks under all three tools.
- Regression helpers are collected by the existing architecture CI entrypoints, with guards preventing duplicate architecture execution. Scoped repository hooks and diff checks pass.

This changes a scheduler knob domain only, so the support-matrix exemption in SDPA Rule S2 applies. Nonpaged D192 independent physical offsets remain a separate existing coverage gap and are not claimed by this change.
