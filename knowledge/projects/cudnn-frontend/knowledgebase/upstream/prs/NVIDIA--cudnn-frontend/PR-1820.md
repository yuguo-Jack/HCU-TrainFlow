## Affected area

Build, packaging, or installation; documentation and container recipes.

## Summary

Require `nvidia-cutlass-dsl[cu13]>=4.8.0`, preserving the Windows ARM64 exclusion. Update the three Docker recipes that explicitly install older DSL releases, and align package-floor documentation and agent guidance.

## Why

The latest stable downstream releases, verified on 2026-10-23, already pin CuTe DSL 4.8.0:

- [vLLM v0.32.0](https://github.com/vllm-project/vllm/releases/tag/v0.32.0): [requirements/cuda.txt, line 22](https://github.com/vllm-project/vllm/blob/v0.32.0/requirements/cuda.txt#L22).
- [SGLang v0.5.22](https://github.com/sgl-project/sglang/releases/tag/v0.5.22): [python/pyproject.toml, line 53](https://github.com/sgl-project/sglang/blob/v0.5.22/python/pyproject.toml#L53).

Both release tags declare:

> `nvidia-cutlass-dsl[cu13]==4.8.0`

Use `>=4.8.0` here to align the minimum with those released consumers while allowing later patch releases.

The previous 4.6.2 floor and its downstream-compatibility explanation are outdated for these releases.

## Related issues

Related to #1819, which proposes a 4.7.1 floor and a separate JAX minimum update. This PR targets the 4.8.0 baseline already used by the released downstream consumers; it does not change JAX requirements.

## API and compatibility impact

Installations pinned below CuTe DSL 4.8.0 must upgrade. The CUDA extra and platform marker are preserved. Kernel-specific runtime version/architecture checks remain intact, including guards for environments that bypass dependency resolution. Python/C++ APIs and the optional JAX dependency group are unchanged.

## Testing

- `setuptools.build_meta.prepare_metadata_for_build_wheel(...)` — generated package metadata successfully. Verified the DSL requirement accepts 4.8.0/4.8.1, excludes 4.7.1/4.8.0.dev0, and retains the Windows ARM64 exclusion.
- Resolved generated required dependencies with `nvidia-cutlass-dsl==4.8.0`, using `uv pip compile --python-version 3.12 --python-platform x86_64-unknown-linux-gnu --no-build` — 10 packages resolved; all DSL companion libraries are 4.8.0.
- Resolved the DSL dependency chain at Python 3.10 on Linux ARM64 and Windows x64 — passed.
- `pre-commit run --files <all changed files>` — passed.
- `git diff --check` — passed.

GPU regression suites and Docker image builds were not run locally: this host has no usable NVIDIA GPU. Downstream dependency pins establish the shared installation baseline, not a claim of GPU regression coverage for this PR.
