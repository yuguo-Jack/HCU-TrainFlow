# fix(bsa): compute blk64 backward O*dO products in FP32

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1713) · state: closed · merged: True

## Original PR description

SM100 blk64 backward currently multiplies BF16 `O` and `dO` before converting the product to FP32. The conversion cannot recover the rounded product bits, so `sum(O*dO)` introduces avoidable error into the softmax derivative. This change promotes both operands before multiplication, matching the precision used by blk128 preprocessing.

## Affected area

FE OSS kernels / CuTeDSL: SM100 blk64 block-sparse attention backward preprocessing.

## Summary

- Compute the elementwise `O*dO` products and row reduction in FP32, retaining BF16 input storage.
- Add four L0 regression cases covering BHSD/BSHD storage, multiple batches/heads, and full/tail preprocessing tiles.
- Exercise the real preprocessing kernel against an FP64 dot-product reference. Include a deterministic BF16-representable input (`1.0625`) whose square is not BF16-representable, and verify scaled LSE as well.

## Why

For a 128-element row filled with `O=dO=1.0625`, the previous implementation produces `-144` for the signed delta instead of `-144.5`. Promoting before multiplication removes that intermediate BF16 rounding.

Additional isolated measurements of the same native blk64 kernel used B=1, Nq=Nkv=131072, D=128, BF16, topK=205/2048 (approximately 10% KV retained), and three seeds on NVIDIA B20Z / SM100. The full delta relative L2 error against an FP64 dot product of the supplied BF16 O/dO falls from approximately **1.65e-3 to 4.8e-8**.

For three real-model QKV captures with four heads and random dO, the sampled gradient relative L2 errors against mathematical FP64 sparse attention are:

| Capture | dQ before | dQ after | dK before | dK after |
|---|---:|---:|---:|---:|
| A | 0.42445% | 0.30795% | 0.24679% | 0.25638% |
| B | 1.25787% | 0.95807% | 0.32584% | 0.28136% |
| C | 1.81116% | 1.33109% | 0.38514% | 0.31473% |

These are medians across three seeds. Each seed samples 64 Q tokens and 64 K/V tokens per head; each reference gradient includes the complete attention/reduction domain, with FP64 normalization and delta computed for all Q rows. These are sampled gradient norms, not whole-tensor norms. dQ error improves by about 24–27%; dK improves in two captures and increases slightly in A. dV does not depend on delta. Other BF16 rounding remains, so this does not guarantee a decrease in every gradient error.
