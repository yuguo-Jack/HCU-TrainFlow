# fix(sdpa): bind SM80 THD Stats by graph-declared strides

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2126) · state: closed · merged: True

## Original PR description

SM80 THD graph execution rejects valid flat or rank-4 Stats buffers because it treats the buffer's carrier shape as the packed layout. This breaks graphs whose Stats descriptor correctly declares token-major or head-major packing while the variant pack supplies a capacity allocation.

Bind Stats using the graph-declared strides after checking the exposed storage span, dtype and device. Preserve standalone layout validation. Execution adds no allocation, copy, device-to-host read or kernel launch. Engine capabilities are unchanged, so no support-matrix eligibility changes are needed.

Validation: the regression failed before the fix (7 failed / 5 passed), then all 12 host cases passed. On A100, the complete THD forward suite plus the host regressions passes 113 tests, including 16 new FP16/BF16 D128/D256 carrier cases, FP64 O/Stats comparisons, rebind/capture/replay, capacity guards and existing no-allocation/no-sync checks. Scoped pre-commit passes.
