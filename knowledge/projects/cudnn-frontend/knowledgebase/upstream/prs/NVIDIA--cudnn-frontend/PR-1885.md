## Summary

`test_sm120_fp8_blk128_dsl_gate_precedes_quantizer_import` called `bsa_fp8_blk128_fwd(object(), object(), object(), object(), 1)` to prove that the SM120 CuTe DSL version gate raises before any operand is read or the quantizer is imported. Since `bsa_fp8_blk128_fwd` became the shared SM90 / SM100/SM103 / SM120 entry, its first statement is `_get_device_arch_for_device(q.device.index)`, so on SM120 the test fails with `AttributeError: 'object' object has no attribute 'device'` before reaching the gate.

Q is now a one-element CUDA tensor; K, V and the block index stay `object()`. The architecture dispatch can read Q's device, and the test still proves what it was written for: on SM120 the gate (`_require_sage_fp8_cutedsl`) raises before K, V or the index is touched and before `_fp8_quant` is imported. Test-only change.

## Why

The test only runs on SM120 (`_require_sm120()`), so the regression shows up only on an SM120 job.
