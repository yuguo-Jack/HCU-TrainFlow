# ops: add JAX ops for NSA

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1777) · state: open · merged: False

## Original PR description

Adds JAX ops for NSA, following `docs/fe-oss-apis/api_conventions.md`. Each one wraps the existing CuTeDSL kernel through the JAX bridge, and under `jax.jit` its output matches the PyTorch API bit for bit. The HSTU JAX ops are in #1769.

| New name | Wraps |
| --- | --- |
| `cudnn.ops.nsa.selection_attention_forward_jax` | NSA selection attention |
| `cudnn.ops.nsa.compression_attention_forward_jax` | NSA compression attention (with LSE) |
| `cudnn.ops.nsa.top_k_reduction_forward_jax` | NSA top-k reduction |

`nsa` is an op family, so it is a subpackage of `cudnn.ops`, resolved lazily. `import cudnn.ops` still imports neither PyTorch nor JAX.

Not covered:
- Sliding window. It runs on the cuDNN graph API, not a CuTeDSL kernel, so it can't go through the JAX bridge. The docs point to JAX's cuDNN attention with a local window instead.
- Backward. The PyTorch NSA APIs are forward-only too.

Changes to existing code:
- The `native_sparse_attention` package `__init__` files (and those of its `compression`, `selection` and `top_k` subpackages) load their PyTorch APIs lazily, so the JAX ops never import PyTorch. The public names are unchanged.

Kernel quirks the wrappers handle:
- The kernels change their own state when traced, and the bridge traces more than once, so each trace builds a fresh kernel object.
- The bridge's static tensors give size-1 dimensions stride 0, but the compression kernel reads the batch stride. That op uses dynamic tensors; selection and top-k use static ones.

Docs: `nsa.md` gains a JAX section. API index: 4 names and 1 module added.

Testing on an SM100 GPU with CUDA JAX 0.12.0:
- New: parity with the PyTorch APIs under `jax.jit`, unsupported-input errors, and a subprocess check that the ops import without PyTorch.
- Existing: the PyTorch NSA suites (for the lazy-import changes), `test/python/core/test_import_boundaries.py` and `test/python/api_index`.
- 69 passed, 2 skipped (the existing selection tests for the unimplemented BSHD layout). pre-commit passes.
