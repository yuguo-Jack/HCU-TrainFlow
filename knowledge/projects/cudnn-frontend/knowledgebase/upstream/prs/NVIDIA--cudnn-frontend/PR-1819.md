# build: require CuTeDSL 4.7.1 and JAX 0.6.0

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1819) · state: open · merged: False

## Original PR description

Raise the package minimum to CuTeDSL 4.7.1 and the optional JAX dependency group to JAX 0.6.0. This makes installation enforce the supported baseline without adding version-dependent test logic.

## Affected area

Build, packaging, and installation.

## Summary

- Require `nvidia-cutlass-dsl[cu13]>=4.7.1`, preserving the Windows ARM64 exclusion.
- Require `jax>=0.6.0` in the JAX dependency group and align the JAX diagnostic and documentation.
- Update the three Docker recipes that explicitly install an older CuTeDSL, and align package-floor guidance.

## Why

[CuTeDSL 4.7.1 declares its minimum supported JAX version as 0.6.0](https://github.com/NVIDIA/cutlass/blob/v4.7.1/python/CuTeDSL/cutlass/jax/__init__.py). Enforce these minimums through dependency metadata.

## Related issues

None.

## API and compatibility impact

Installations pinned below CuTeDSL 4.7.1 must upgrade, including downstream environments that still pin 4.6.2. JAX remains opt-in. Kernel-specific runtime gates and BSA's stronger JAX requirement are unchanged. No test code or version-dependent skips are added.
