# Consider split prefix attention for SM100 page128 graphs

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1710) · state: closed · merged: True

## Original PR description

The SM100 BF16 D128 paged-prefix selector currently excludes 128-token pages even though the same split kernels support them. Admit page sizes 16 and 128 to the existing occupancy-based split/packing choice. This lets eligible underfilled page128 graphs consider the same default split route as page16 graphs; the existing shape, mask, layout, batch and workspace constraints still apply.

This is a one-line selector change. Kernel implementations, prepared execution, workspace layout and the SM107 page16-only selection domain are unchanged. It is independent of #1709 and does not expand FlashInfer auto admission.

Validation:
- Existing heuristic/geometry suites: 1,155 passed, 2 deselected.
- Existing BF16 page128 dynamic-length, pointer-rebinding, O/LSE and CUDA Graph tests: 42 passed.
- Ten-shape baseline/candidate/candidate/baseline component matrix passed O/LSE, sampled fp64 and poisoned-output replay checks; an additional six-shape output-only FA2/FA4/TRTLLM comparison passed correctness.
- Scoped pre-commit checks passed. No timing or winning-knob golden tests added.

Ready for review. Full-power B200 performance qualification and remote CI remain prerequisites for merging; local component measurements do not establish a serving-wide default-dispatch win.
