# Reduce SM80 wide-head attention shared storage

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2138) · state: closed · merged: True

## Original PR description

The SM80 wide-head body keeps two K and V stages plus a separate QK-partial exchange, limiting shared-memory residency. Keep one K slot and one V slot, and reuse consumed K storage for the partial exchange. Shared storage falls from 100 to 64 KiB for D512/V512 and from 108 to 70 KiB for D576/V512.

CTA barriers fence K readers before alias stores, publish partial scores, and release their readers before next K overwrites the slot. K prefetch overlaps softmax and SV; the loop-end barrier protects V reuse. QK/softmax arithmetic ordering is unchanged. The narrow D256 specialization retains its existing pipeline. No API, capability, geometry, knob or placement change.

Validation: all 76 existing A100 wide-head GPU cases pass, including FP16/BF16, padded logical widths, masks/sinks, dense/paged/THD, rebinding and changed-length CUDA Graph replay. Ten Compute Sanitizer memcheck cases and ten racecheck cases report zero errors or warnings. Scoped hooks pass. The inherited device-family fixture correction has two passing focused CPU cases.

A bounded paired A100 PCIe 40 GB experiment isolates the K-stage change using six BF16 unmasked wide geometries and one D256 control, both execution orders, full FP64 O/Stats references and canaries. All 28 observations pass and all 14 baseline/candidate pairs are bitwise identical. All six wide cases improve in both orders; the D256 control is unchanged. This is warm CUDA-event kernel replay against the same body with two K stages, not backend or serving performance. The measured variant and final committed source have identical executable ASTs; repository and sanitizer qualification use the final committed source.

Exact emitted wide binaries have no spills. The driver occupancy API reports increased D576 CTA residency capacity, with D512 retaining its existing capacity; this is not a measurement of achieved occupancy.

Depends on #2137; land that PR and its dependencies first.
