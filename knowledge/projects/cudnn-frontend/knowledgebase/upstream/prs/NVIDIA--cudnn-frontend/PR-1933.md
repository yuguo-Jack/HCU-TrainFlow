## Affected area

FE OSS kernels or CuTeDSL

## Summary

On the SM100 half row, single-token **D576x512 absorbed-MLA decode** fell through `_place_sm100_f16`'s s_q == 1 branch to the final `TRAIL`, the d64 / d128 / d192 decode rule. As a result the backend's decode engine was the default for every MLA decode step. Multi-token decode (s_q 2–4) already leads.

This PR adds one arm. Paged bf16 D576x512 at s_q == 1 now LEADs when `h_q * b * S_kv >= SQ1_D576_MIN_WORK` (2**20) and otherwise keeps the backend. Dense K/V and f16 were not measured and keep the backend.

## Why

The measurements used a full-power B200 (1000 W, 148 SMs), cuDNN 9.28.0.38 and the inference harness's serving form: paged K/V, page 64, `--kind mla_absorbed`, 20 timed iterations. The legs were backend, FROST and default dispatch, with the opt-in flag unset.

- **Training grid, frozen before timing:** h_q 16 / 32 / 64 / 128 × b 1 / 8 / 32 / 128 × S_kv 2k / 8k / 32k / 128k × s_q 1 / 4.
  - s_q 4: FROST is faster on all 64 cells.
  - s_q 1: FROST is faster on every cell with `h_q * b * S_kv >= 2**20`, at 0.08–0.74 of the backend's time. At or below 2**19 the backend is faster on every cell but one: FROST takes 1.11–3.08× as long, and the exception is 0.72.
  - The floor sits on the conservative side of that mixed 2**19 level.
  - Training regret (default ÷ faster leg, geo / max): 1.923 / 12.18 before, 1.003 / 1.383 with the rule.
- **Holdout:** 40 seeded random cases, frozen before the rule, with h_q 8–128, b 1–192, S_kv 1k–160k and s_q 1–4. It was run once at the frozen head `44656ab34`.
  - Every default route matches the rule.
  - Regret is 1.000 geo / 1.015 max, with none above 1.05. The parent default scored 1.259 / 11.16.
  - The 4 cases whose route changed run at 0.09–0.13 of the parent default's time.
  - The s_q == 1 cases below the floor keep the backend, within 1.015 of the faster leg.
