# Fix packed MXFP8 THD test operand shapes

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1718) · state: closed · merged: False

## Original PR description

## Summary
The MXFP8 THD test helper passes flat capacity buffers to a binder that requires `(T, H, D)` or `(B, H, S, D)` operand geometry, causing rejection before kernel execution.

## Fix
Bind zero-copy `(capacity_tokens, heads, head_dim)` views for Q, K, V, and O. This preserves each allocation and its NaN-poisoned capacity tail, while keeping the existing numerical references and auxiliary tensors unchanged.

## Validation
- Python syntax and whitespace checks pass.
- Real CPU PyTorch 2.14.1 checks pass in 60 scenarios (240 operand views): FP8 inputs, multiple output dtypes, empty capacities, grouped heads, differing V dimensions, preserved storage aliases, output-write propagation, and NaN capacity tails. The original flat representation is rejected by the current Python geometry predicate.
