# ops: add JAX ops for HSTU attention and HSTU LMSD

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1769) · state: open · merged: False

## Original PR description

Adds JAX ops for HSTU attention and HSTU LMSD, following `docs/fe-oss-apis/api_conventions.md`. Each one wraps the existing CuTeDSL kernel through the JAX bridge, and under `jax.jit` its output matches the PyTorch API bit for bit. The NSA JAX ops are in #1777.

| New name | Wraps |
| --- | --- |
| `cudnn.ops.hstu_attention_forward_jax` / `_backward_jax` | HSTU attention (SM100 path) |
| `cudnn.ops.hstu_lmsd_forward_jax` / `_backward_jax` | HSTU LMSD |

HSTU is not an op family, so its ops are top-level names in `cudnn.ops`.

Covered:
- HSTU attention: head dimensions 32, 64 and 128; causal, full and local windows; BF16 and FP16.
- HSTU LMSD: hidden sizes 64–960 and every combination of the segment options.

Not covered:
- LMSD dropout. The kernel takes its seed as a compile-time launch value, so in JAX every new seed would recompile. The JAX op rejects a nonzero dropout ratio. Supporting dropout needs a kernel change so the seed is read from device memory.
- Head dimension 256 (its backward is a separate two-kernel path), arbitrary masks, paged KV and the single-token decode path.
- Differentiable (`custom_vjp`) entries. Their naming is still open, as in #1727.

Changes to existing code:
- The `hstu_attention` and `hstu_lmsd` package `__init__` files load their PyTorch APIs lazily, so the JAX ops never import PyTorch. The public names are unchanged.
- `hstu_attention/_kernels/block_sparsity.py` imports torch only under `TYPE_CHECKING`; it was used only in annotations.

The kernels change their own state when traced, and the bridge traces more than once, so each trace builds a fresh kernel object.

Docs: `hstu_attention.md` and `hstu_lmsd.md` gain JAX sections. API index: 4 names added.

Testing on an SM100 GPU with CUDA JAX 0.12.0:
- New: parity with the PyTorch APIs under `jax.jit`, unsupported-input errors, and a subprocess check that the ops import without PyTorch.
- Existing: the PyTorch HSTU suites (for the lazy-import changes), `test/python/core/test_import_boundaries.py` and `test/python/api_index`.
- 246 passed. pre-commit passes.
