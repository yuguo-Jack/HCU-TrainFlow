# perf: overlap native SM100 D192 backward MMA stages

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1952) · state: closed · merged: True

## Original PR description

Native SM100 D192x128 backward currently inherits the D256 MMA order and one-deep operands. This change uses the existing lookahead order for D192 and adds a second Q/dO/dO-for-dV operand slot for dense layouts. Packed THD keeps its compact operand rings. This overlaps the next score MMA with current dP/P work while fitting the SM100 shared-memory budget.

## Affected area

FE OSS SDPA backward kernels / CuTeDSL.

## Summary and compatibility

Native D192x128 uses MMA lookahead. Dense D192 uses two-deep Q, dO and dO-for-dV rings (208896 bytes including scaffold, within the 232448-byte cap); THD uses one-deep operands. The existing kernel body handles both configurations. D256 and profile 2 retain their prior settings. Public APIs, numerical tolerances, workspace size, eligibility and selection policies do not change.

## Why

Lookahead permits the next score MMA to overlap current dP/P work. Dense D192 has shared-memory capacity for the additional operands; packed THD retains its compact descriptor-patched operand pipeline. The factory selects these existing pipeline combinations using the head geometry and layout.
