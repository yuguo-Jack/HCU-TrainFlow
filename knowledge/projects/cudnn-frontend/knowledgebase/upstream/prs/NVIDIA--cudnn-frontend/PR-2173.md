# Add explicit single-Q native D128 THD topology

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2173) · state: closed · merged: True

## Original PR description

Add an explicit one-Q warp-specialized topology for native D128 half-precision THD prefill. The existing two-Q topology processes two full Q subtiles per CTA; the new option processes one full Q tile and retains the two-slot score/P pipeline. It reuses the native one-Q kernel with D128 configuration.

Select it with the existing public `WARP_SPEC_CFG=1` and `TILE_CGA_M=1` knobs (M128/N128). Graph and standalone admission share the geometry boundary: exact D128, fp16/bf16, nonpaged THD, no packing or KV split, bias, per-key mask, gate, or mixed KV storage. Public knob roundtrip and template identity preserve the selected topology. Omission or zero retains existing behavior; candidate enumeration and heuristic defaults are unchanged.

Validation: nine native tests pass, including explicit admission/declines, public identity, four independent-origin lifecycle cases, and four mask forms with forced softmax rescaling. Three cases each pass Compute Sanitizer memcheck, synccheck, and racecheck with no errors or hazards. Changed-file formatting passes. The parent rejects the newly requested public identity.

Depends on #2172 for native physical-origin support. This branch contains that prerequisite; the topology change is commit `164ddbf310264bb3642566001d604fe454909054`. The capability edit adds only a knob domain, exempt from the support-matrix update under SDPA Rule S2.
