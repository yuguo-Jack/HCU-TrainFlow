# Optimize SM100 paged causal prefill interior exponentials

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1798) · state: closed · merged: True

## Original PR description

Paged causal THD attention sends every softmax exponential through MUFU, even on interior tiles that need no causal masking. Reuse the existing mixed-exp2 implementation for 16 of each 128 columns on eligible interior tiles, distributing some exponent work to the FMA pipeline. Diagonal and other masked tiles retain their existing implementation.

The extension is limited to SM100 BF16 D128-flavor, unsplit, causal paged attention without a sliding window, bias, or an explicit KV mask. It changes no public API, knob, workspace, launch count, plan cache, or per-run host preparation. Nonpaged and split-KV paths, FP16, SM103, and SM107 retain their existing behavior. This complements the nonpaged work in #1702; the shared source block needs reconciliation when either PR lands.

Validation:

- The three changed files are byte-identical to the locally qualified candidate: 44 focused pytest cases passed, covering dtype/page/layout/shape combinations and the existing architecture gates.
- Eight prepared capture/rebind contracts with 16 compiled owners passed on both DSL 4.8 and the 4.7 floor; those case sets overlap. Memcheck, racecheck, and synccheck reported zero errors for the B33 dynamic-length case across all three schedulers.
- Integrated onto current develop `f05b536c`; changed-file formatting/license checks pass. Current-head upstream CI is requested separately.

Tests extend existing suites and check numerics, dynamic metadata, pointer rebinding, and capture behavior. There are no timing thresholds or heuristic-winner golden tests. This PR makes no serving-throughput claim.
