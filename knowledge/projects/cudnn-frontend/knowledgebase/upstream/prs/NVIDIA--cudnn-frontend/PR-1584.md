## Affected area

Python API or bindings (`tools/cudnn_repro` dev tool)

## Summary

- `log_parser._parse_tensor_dump`: return `None` (skip the line) when the `Data: [...]` payload is not a JSON list of integers, instead of raising.
- `__main__.main`: exit with `error: Log file '<path>' not found` instead of a raw `FileNotFoundError` traceback.
- Add 3 tests covering both.

## Why

The tensor-dump regex is greedy (`\[.*\]`), so a log line with extra bracketed text or a mangled payload makes `json.loads` raise `JSONDecodeError`, which aborts `cudnn-repro` for the whole log even though the dump is optional data. Missing input files should produce a clear one-line error rather than a traceback.
