# csa(compressor): decline the ratio=128 backward where its CTA exceeds the device's shared memory

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2238) · state: open · merged: False

## Original PR description

## Problem

`_bwd_schedule_r128` bounds the ratio=128 backward CTA's shared memory only by SM100's 227 KiB per-CTA ceiling. A device with less shared memory per CTA passes `check_support()` and then rejects the launch.

On an RTX 5060 Ti (cc 12.0, 101,376 B per CTA opt-in), `head_dim=512, coff=2` needs 105,024 B:

```
error[CUDA_LAUNCH_INVALID_CONFIG]: CUDA launch failed: cudaErrorInvalidValue (1)
CUDA rejected the launch configuration before running the kernel.
```

develop `a0f7b9f4`, `-m L0 test/python/compressed_sparse_attention`: 3 failed.
- `test_numerics_vs_references[b1x8192-d512-r128c2]`
- `test_backward_fills_uninitialized_buffers[ragged2-d512-r128c2-padded-tokpad]`
- `test_backward_deterministic_dape[r128-d512-c2]`

The other 194 CSA cases pass on cc 12.0.

## Change

- `compressor_sm100_r128.py`:
  - The size formula moves into `_bwd_smem_bytes`. The schedule's existing 227 KiB check uses it unchanged.
  - New `bwd_smem_bytes_r128(ratio, d, coff, nb_total)` returns the size for the schedule a plan selects.
- `CSACompressorBackward.check_support()` compares that size with the device's `shared_memory_per_block_optin` (`cudnn._device.device_info`). If the CTA does not fit, it declines with a `NotImplementedError` that states both numbers.
- Tests:
  - The three cases above skip where the backward does not fit.
  - `test_check_support_accepts_envelope_r128` asserts the decline on such a device instead of expecting acceptance, so the case still runs there.

On SM100 the limit is 227 KiB, so no decision changes there.

## Testing

RTX 5060 Ti (cc 12.0), cuDNN 9.27, CuTe DSL 4.8.1, `-m L0 test/python/compressed_sparse_attention`:
- develop: 3 failed, 194 passed.
- this PR: 0 failed, 194 passed, 4 skipped. Three skips are the cases above; the fourth also skips on develop.

I compared the outcomes test by test: no test that passes on develop is skipped or fails with this PR. The skip reads `ratio=128 backward needs 105024 B of shared memory per CTA; this device allows 101376 B`.

`black 26.3.1 --line-length 160 --fast` is clean.
