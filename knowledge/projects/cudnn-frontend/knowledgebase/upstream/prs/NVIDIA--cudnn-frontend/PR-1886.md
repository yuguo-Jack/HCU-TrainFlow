# sdpa: parallelize THD tensor map construction across ports

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1886) · state: closed · merged: True

## Original PR description

Physical-origin THD setup assigns sequences to descriptor-writer warps. Each writer then builds Q, K, V and O maps serially, leaving most writer warps idle for small batches.

Distribute writer warps across both ports and sequences: four port groups for nonpaged attention, two for paged Q/O. Every descriptor still has one elected writer and is published by the existing tensor-map release fence. The descriptor format, physical-origin addressing and launch sequence stay the same.

Validation: 31 existing physical-origin tests pass, including nonpaged/paged inputs, both dtypes and Stats layouts, stride rebinding, retained captures and live/empty transitions. Eight compact parent/candidate controls check complete O/Stats results, untouched capacity tails and changed-input replay. Scoped hooks pass. Four D128/D256 nonpaged/paged cases pass memcheck and synccheck with zero errors.

One initial qualification process and cold sanitizer invocations crashed. The cold sanitizer crash also reproduces on the unchanged parent after compilation and execute return; its cause remains unassigned. The passing sanitizer runs load normally compiled artifacts, with four verified compiled-cache hits per tool, and instrument the full target execution/replay tests.
