# perf: acquire THD backward tensor maps once per lifetime

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1963) · state: closed · merged: True

## Original PR description

THD backward loaders explicitly acquired runtime tensor maps but then repeated the tile helper's default acquire for every load. Reuse the existing compact-map acquisition at launch and physical-origin acquisition per work item for D192 and D256. The fused D192 Qdk path acquires its map in the consuming store warp before the q loop, on both CTAs and with the initialized dead-work fallback.

Pipeline synchronization, descriptor publication, workspace size and launch counts are unchanged. Record the acquire-lifetime trap in SDPA Rule S8.
