# Optimize causal THD forward attention for context parallel workloads

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1702) · state: closed · merged: True

## Original PR description

Causal THD forward attention leaves all softmax exponent work on MUFU, including interior tiles with no causal-mask work. This change reuses the existing mixed-exp2 implementation for 32 of each 128 columns on eligible SM100 BF16 D128-flavor interior tiles. Masked and diagonal tiles keep the existing MUFU path.

The optimization is limited to nonpaged, unsplit causal THD without a sliding window, bias, or KV mask, under the existing architecture gate. It adds no API, knob, allocation, helper kernel, or host execution path. Dense causal, FP16 causal THD, D64, paged and split-KV behavior retain their existing paths.

### Independent change

This PR now contains only three files: the existing forward kernel, numerical/replay tests, and architecture-gate tests. The THD work-lookup implementation and tests from #1696 have been removed from this PR's diff. It can be reviewed and landed independently of #1696 and the TE integration PRs. Current develop `f05b536c` was merged without rewriting the branch history.
