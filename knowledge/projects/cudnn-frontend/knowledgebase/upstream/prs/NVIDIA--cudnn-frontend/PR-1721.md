## Summary

Add GitHub security scanning configuration for cuDNN Frontend.

This PR adds a dedicated `Security scan` workflow that runs on pull requests, pushes to `develop`/`main`, a weekly schedule, and manual dispatch. The workflow includes:

- CodeQL analysis for C/C++ with `build-mode: none`
- CodeQL analysis for Python
- Dependency Review for non-draft pull requests

It also adds supporting configuration:

- `.github/codeql/codeql-config.yml` enables `security-extended` and `security-and-quality` CodeQL query suites, while ignoring vendored/generated code paths.
- `.github/dependency-review-config.yml` fails on moderate-or-higher dependency findings and restricts allowed licenses to approved open-source licenses.
- `.github/dependabot.yml` enables weekly dependency update checks for GitHub Actions and Python package manifests.
