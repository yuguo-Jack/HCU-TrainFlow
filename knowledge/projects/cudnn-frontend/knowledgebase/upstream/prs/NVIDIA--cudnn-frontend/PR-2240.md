# test(gemm/frost): skip the sm100-tree host checks in a process that runs the sm120 tree

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2240) · state: open · merged: False

## Original PR description

## Problem

`cudnn.gemm.frost.compiler` and the active tile catalog serve the sm100 tree in every process except one on a cc 12.x GPU, where they serve the sm120 tree (`arch_family.family_for_arch`). Every other process means CPU-only machines, SM80 and SM90 as well as SM100.

Fourteen host-level tests check sm100-tree internals through that facade, so they pass everywhere except cc 12.x. The internals they check:
- `_tma_store_sequence`, `_use_tma_store_epi` and `_store_modes`
- `_use_bulk_combine` and `_host_tma_c_descs`
- `cta_group` and the sm100 planner

On an RTX 5060 Ti (cc 12.0), develop `a0f7b9f4`, `CUDNN_FRONTEND_ENABLE_FROST_ENGINES=1 -m L0 test/python/gemm/frost` gives 45 failed. 42 of them are these 14 tests:

| test | cells | error |
|---|---|---|
| `test_matmul::test_tma_store_serves_every_drain_height` | 8 | `('stg',) == ('tma',)` |
| `test_matmul::test_m_major_tma_store_serves_a_narrow_drain` | 6 | |
| `test_matmul::test_epi_smem_row_bytes_is_the_real_staging_alignment` | 5 | `cannot import name '_tma_store_sequence' from 'cudnn.gemm.frost.sm120.compiler'` |
| `test_tile_select_analytic::test_joint_planner_runs_real_support_gates` | 6 | sm120 configs from the active catalog |
| `test_tile_select_analytic::test_planner_bounds_terminal_quant_one_cta_to_measured_total_rows` | 4 | `'ConfigSm120' object has no attribute 'cta_group'` |
| `test_moe_combine_bulk::test_normal_two_cta_combine_uses_atomics` | 3 | `no attribute '_use_bulk_combine'` |
| 8 more | 1–2 each | same pattern |

## Change

- `gemm_test_utils.requires_sm100_tree` skips only when the active family is not sm100.
- Unlike `requires_sm100`, which needs an SM100-family GPU, it keeps these tests running on CPU-only, SM80, SM90 and SM100 machines.
- It is applied to the 14 tests. Porting them to `plan_as_sm100` would be the other option, but several also JIT sm100 configs, which cannot run on cc 12.x.

## Testing

RTX 5060 Ti (cc 12.0), cuDNN 9.27, FROST engines on, `-m L0 test/python/gemm/frost`:
- develop: 45 failed, 2639 passed.
- this PR: 3 failed, 2639 passed.

I compared the outcomes test by test, and no test that passes on develop is skipped.

`black 26.3.1 --line-length 160 --fast` is clean.

## Not in this PR

The other 3 failures, `test_block_scale_matmul::test_block_scale_resident_sf_tmem_budget[dual-128-256-*]`, have a different cause:

```
NotImplementedError: ... no AB stage fits in SMEM including buffer alignment padding
```

The test pins the arch to 100/107, but the planner reads the device's per-CTA shared memory, which is about 99 KB here. Its other 37 cells pass on cc 12.x, so marking the whole test would have hidden them. I left it as is.
