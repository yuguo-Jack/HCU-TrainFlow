# Add pooled DSA training backward for SM100

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2243) · state: closed · merged: True

## Original PR description

## Summary

Adds the training-side composition for the pooled DSA indexer on SM100. It complements the pooled forward APIs of #1847 and is independent of that PR.

- New package `cudnn.deepseek_sparse_attention.pooled` with `pooled_keys_forward`, `unpool_backward`, `pooled_indexer_select`, `pooled_expand_compact`, `pooled_sparse_attention_backward`, `pooled_sparse_attention_backward_with_teacher`, `pooled_teacher_recompute`, `pooled_indexer_target` and `pooled_indexer_backward`, lazily exported from `cudnn.deepseek_sparse_attention`.
- Pool and expand kernels for the softmax-weighted pooled keys and the compact token expansion of the selected pools plus the causal tail.
- `sparse_attn_score_recompute_wrapper` takes `pool_size` and emits per-pool probability sums; the SM100 `SparseAttentionBackward` takes `pool_target`/`pool_size` and emits them from its own probabilities.
- SM100 generic backward: per-role register budget for the shared-K/V path; the pool mass is read from the probability tile in 16-byte chunks along the swizzle atom.
- Docs section in `docs/operations/sparse_attention/dsa.md`, `api_index.txt` entries, tests with a torch reference, and `benchmark/dsa/benchmark_pooled_backward.py`.
