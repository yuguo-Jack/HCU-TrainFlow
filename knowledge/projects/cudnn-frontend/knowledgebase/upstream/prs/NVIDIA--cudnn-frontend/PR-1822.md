# sdpa fwd placement (sm100): FROST leads nonpaged d256 THD prefill at GQA8; packed paged D128 full prefill also on cc 10.3 and page 64

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1822) · state: closed · merged: True

## Original PR description

## What

Two placement changes in `_place_sm100_f16` (`python/cudnn/sdpa/fwd/placement.py`):

1. **Nonpaged THD d256 prefill leads.** BF16, exact d256, bottom-right causal, integral GQA or MHA, at least 256 query tokens per request, KV above 512, no window / sink / right band / epilogue gate. The nonpaged THD path previously had only the packed d128 clause, so every d256 ragged graph fell through to TRAIL.
2. **The packed paged D128 full-prefill clause (#1809) also covers cc 10.3 and page 64** (`PAGED_D128_FULL_PREFILL_CCS`, `PAGED_D128_FULL_PREFILL_PAGE_SIZES`); the rest of its domain is unchanged.

## Tests

`test/python/sdpa/frost/test_heuristic_geometry.py`: two tests cover both domains and their edges (short KV and short query classes, non-integral group, FP16, window, sink, top-left, shape-override graphs, other page sizes, long prefixes).
