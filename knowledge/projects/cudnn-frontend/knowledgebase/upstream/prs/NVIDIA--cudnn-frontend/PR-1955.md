# perf: use native-width stage3 GEMMs for SM100 D192 backward

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1955) · state: closed · merged: True

## Original PR description

D192x128 half backward currently computes dQ/dK with a 256-column stage3 tile. Use the native 128x192 single-CTA GEMM row, with its generated operand/epilogue constants, for dense and packed FP16/BF16 paths on the SM100 line. The tile remains inside the existing workspace write granularity; D256 and quantized rows retain their existing selections.

The change reuses the prepared backward chain and preserves graph eligibility and placement policy.

Validation: 179 focused tests pass, covering full gradient references, GQA/MQA, masks/tails, workspace chunks, independent packed origins, changed-input/length replay, rebinding, deterministic operation and unchanged-row controls. The new path assertions were verified failing on the parent implementation. Two targeted memcheck cases and two synccheck cases pass with zero errors. Scoped pre-commit and diff checks pass.
