# perf(sdpa): split SM80 wide-head QK reduction between paired warps

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2137) · state: closed · merged: True

## Original PR description

The SM80 wide-head body assigns two warps to each query slab, but both previously computed the entire QK reduction. Split that reduction between the paired warps and exchange FP32 partial scores before softmax. The existing V partition, masks, paged/THD addressing and output path stay intact.

The exchange adds 4 KiB of shared memory and one CTA barrier per KV tile. Shared storage becomes 100 KiB for D512/V512 and 108 KiB for D576/V512. The narrow D256 specialization retains its existing reduction. No API, capability, knob or placement change.

Validation: all 76 existing A100 wide-head cases pass, including FP16/BF16, padded logical widths, masks/sinks, dense/paged/THD, rebinding and changed-length CUDA Graph replay. Ten representative Compute Sanitizer memcheck cases report 0 errors; two racecheck cases report 0 errors and 0 warnings. Scoped hooks pass.

A bounded A100 PCIe 40 GB paired experiment checks six BF16 unmasked wide-head geometries and one unchanged D256 control, in both execution orders with full FP64 O/Stats and canary checks. All six wide cases improve; the D256 control is effectively unchanged and remains bitwise identical. This is warm CUDA-event kernel replay against the parent native body, not a backend or serving comparison. Wide-head FP32 reduction ordering changes.

Depends on #2136; land that PR and its dependencies first.
