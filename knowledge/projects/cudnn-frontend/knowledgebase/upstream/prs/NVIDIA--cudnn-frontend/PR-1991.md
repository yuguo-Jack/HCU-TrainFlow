# Avoid sorting identity axis overrides in native variant packs

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1991) · state: closed · merged: True

## Original PR description

Shape overrides currently allocate five temporary vectors and sort both stride vectors even when the resulting axis permutation is identity. Detect that case from the current strides for ranks up to eight, so common already-aligned bindings return directly. Other cases retain the existing stable-sort path.

## Affected area

Python native bindings.

## Summary / why

The bounded pairwise comparison preserves stable index order at stride ties. It handles equal axis order even when the stride values or tie groups differ, without caching mutable caller geometry. Added cases extend the existing Python-versus-native differential test across stable ties, a non-self-inverse permutation, and ranks eight/nine.
