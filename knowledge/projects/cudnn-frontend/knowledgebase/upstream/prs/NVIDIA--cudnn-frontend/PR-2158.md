# Support nonpaged D64 THD split attention

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2158) · state: closed · merged: True

## Original PR description

Nonpaged D64 THD attention previously rejected explicit split-KV plans. This change enables FP16/BF16 split execution on SM100/SM103/SM107 with CGA1 and TILE_N128, using the shared physical-D64 single-Q body, FP32 partials and the existing combine. Packed and unpacked heads preserve independent Q/K/V/O/Stats origins without staging copies; older native extensions decline with a rebuild message.

The graph and standalone paths share admission and native binding. Regression coverage includes compact and gapped origins, current strides/pointers, NH/HN Stats, changed lengths under retained capture, empty/keyless rows, supported schedulers and SM107 proper-divisor PackGQA. Existing sink, gate, padded-Stats and paged restrictions are retained. No heuristics or placement changes.

Stacked on #2157 (and its #2155/#2153 dependencies). Current develop is merged; the independent parent test classes are retained.

Validation: 386 host checks pass. SM100 passes 28 GPU cases and SM107 passes 29, plus six host controls through each architecture entry. Targeted memcheck/racecheck/synccheck pass on four cases per tool on SM100 and five per tool on SM107. The standalone reference uses CPU FP64 to avoid a cuBLAS initialization warning observed in an earlier SM100 sanitizer run; tolerances and kernel math are unchanged. Both architecture CI entries collect the new tests. Formatting and license checks pass.
