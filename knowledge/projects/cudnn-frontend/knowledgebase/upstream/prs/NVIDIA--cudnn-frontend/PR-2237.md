# test(nsa): skip the compression attention and top-k reduction tests on cc 12.x

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2237) · state: open · merged: False

## Original PR description

Follow-up to #2169.

## Problem

#2169 made `CompressionAttention` and `TopKReduction` decline cc 12.x in `check_support()`:

```
RuntimeError: CompressionAttention requires SM100+ compute capability with tcgen05 (not cc 12.x), but found SM120 on device 0
```

Their tests get there through `nsa_init`, whose shared `compute_capability < 100` skip lets cc 12.x through. On an RTX 5060 Ti (cc 12.0), develop `a0f7b9f4`, `-m L0 test/python/native_sparse_attention` had 8 failures: the compile/execute and wrapper cases of `test_NSA_compression_attention.py` and `test_NSA_topk_reduction.py`.

## Change

Only these two modules skip on a device without tcgen05 (`has_tcgen05`), before they build the plan.

`nsa_init` stays as it is on purpose. Selection attention and SWA serve cc 12.x, and their 19 tests pass there. I first tightened `nsa_init` itself, and that skipped 18 of them.

## Testing

RTX 5060 Ti (cc 12.0), cuDNN 9.27, `-m L0 test/python/native_sparse_attention`:
- develop: 8 failed, 19 passed, 8 skipped.
- this PR: 0 failed, 19 passed, 16 skipped. The same 19 tests pass.

`black 26.3.1 --line-length 160 --fast` is clean. On cc 10.x, `has_tcgen05` is true, so nothing changes there.
