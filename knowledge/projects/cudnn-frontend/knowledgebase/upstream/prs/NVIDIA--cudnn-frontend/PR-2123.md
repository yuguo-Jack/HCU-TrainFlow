# sdpa: keep SM107 half dense split attention at physical D64

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2123) · state: closed · merged: True

## Original PR description

Half-precision SM107 dense split plans with head dimensions up to 64 currently use the D128 envelope. This change keeps physical D64 operands and FP32 partials, including correct workspace sizing and partial binding. CGA1/N128 uses the shared single-Q D64 pipeline compiled for the target architecture; CGA2 and N64 use native SM107 prefill.

Packed and unpacked plans support attention sinks, proper-divisor GQA groups, and optional natural/log2 final Stats. The combine adds the sink once. Graph and standalone admission agree; the support matrix documents the routes and existing THD/paged boundaries. No heuristic or placement changes.

Validation:
- 22 target-GPU replay/rebinding tests: FP16/BF16, both APIs, partial groups, narrow KV tiles, empty partitions and keyless rows.
- 33 CPU metadata checks and 89 existing small-tile knob contracts.
- Four existing DEV cases, both comparison orders, full FP64 O/Stats checks before and after warmed replay, and workspace guards. Scoped Compute Sanitizer memcheck passed.
- Scoped pre-commit hooks and `git diff --check`.

The architecture CI entrypoint collects the new regression cases.
