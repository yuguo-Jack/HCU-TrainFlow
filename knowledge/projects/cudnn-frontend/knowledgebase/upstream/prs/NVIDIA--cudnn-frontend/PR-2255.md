## Affected area

FE OSS CuTeDSL kernels: the SM100-family block-scaled unified indexer scorer, shared by MXFP8 and MXFP4.

## Summary

The load warp writes the per-head weight tile into two rotating shared-memory slots, but neither the Q/K tensor-memory pipeline nor tile parity publishes all 32 lanes of these stores to both epilogue warpgroups. The next tile can also overwrite a slot before both groups have finished reading it. A numerical reference can pass despite these unordered accesses.

Add a two-stage `PipelineAsync` with all 32 load lanes as producers and all 256 epilogue lanes as consumers. The producer acquires before writing a slot and commits the weights; both consumer warpgroups wait before the epilogue and release after it finishes. The existing output interface, score computation and Q/K pipelines are unchanged.

Related to #2244, which fixes the separately implemented BF16 dense score mainloop; that PR explicitly excludes MXFP8/MXFP4.

## Validation

On a B300 (SM103), cuDNN 9.27.0.42, PyTorch 2.14.1+cu130, CuTeDSL 4.8.1/cu13 and Compute Sanitizer 2026.2.1:

- Six new sanitizer regression cases passed: racecheck and synccheck for MXFP8 H4, MXFP4 H4 with empty/partial rows, and MXFP4 H64 persistent multi-block reuse. On develop the same selection produced 3 racecheck failures and 3 synccheck passes; on this change all six passed.
- Existing indexer selection: 36 passed, 43 deselected, covering MXFP8/MXFP4, small heads, variable-length tails and persistent work.
- Cold-compiled reference cases for MXFP8 H4 and MXFP4 H4/H64 passed with each of CuTeDSL 4.8.0/cu12, 4.8.0/cu13, 4.8.1/cu12 and 4.8.1/cu13. The CUDA 13 framework/backend and driver were retained; the compiler flavors report CUDA 12.9 and 13.4. An initial 4.8.0/cu12 environment failed to discover its runtime; the separately installed retry loaded CUDA 12.9 and passed.
- Changed-weight CUDA Graph replay matched eager scores. A short replay-only ABBA experiment gave base medians 8.22/8.22 us and fix medians 14.08/8.23 us, with one noisy fix run; these samples do not establish a performance conclusion.
- Changed-file pre-commit hooks and `git diff --check` passed.
