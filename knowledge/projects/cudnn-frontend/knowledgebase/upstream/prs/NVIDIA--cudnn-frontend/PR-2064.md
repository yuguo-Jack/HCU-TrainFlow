# sdpa: overlap D256 P1 math with previous PV

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2064) · state: closed · merged: True

## Original PR description

Native SM100/SM103 BF16 D256 causal prefill computes P1's register math after waiting for the preceding PV. Move that arithmetic before the wait so it can overlap PV, keeping the TMEM stores, barriers, fences and accumulation order unchanged.

On a 76-SM SM100 P2021, warm CUDA-event graph replay in both process orders improves the existing Qwen 4K cell from 134.45–134.50 to 133.63–133.66 us (0.59–0.65%) and 2K from 85.12–85.13 to 84.29–84.31 us (0.96–0.97%). Across six existing cases at their previously fastest native plans, geomean latency improves 0.38–0.40%; small MHA and natural partial-GQA cases are effectively flat.

Validation: all 12 existing fused-correction tests passed, including forced rescaling, tails, sinks, rebinding, retained replay, and SM100/SM103 natural/LPT register codegen. Pre-commit passed. Whole O/Stats are bitwise equal to the original in all 72 paired phases.

The 288-phase FP64 diagnostic retains an existing single-element changed-input GQA4 O-bound failure, identical in original, candidate, unchanged control and backend; all Stats pass. Original tolerances and the diagnostic's nonzero exit were preserved. This change introduces no new numerical difference.

Independent review found no correctness or synchronization issue and passed the same 12 tests. On its separate shared SM100 setup, two larger GQA cases were effectively flat, while a small S=769, Hq/Hkv=6/1 forced-rescale case was 1.3–1.5% slower (about 0.2 us). The measured benefit is workload-dependent; this is not a universal speedup claim.

The existing cross-target cubin test now records the two intentionally changed dense BF16 causal binaries. Fresh-process compilation with public CuTe DSL 4.8.0/CUDA 13.4 reproduces both historical and new records; the existing ten-rendering test passes, with the other eight THD/paged/gated records unchanged. The follow-up commit changes only those two test records and their comment.
