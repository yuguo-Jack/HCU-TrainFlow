# test: align forced two-CTA admission with the supported devices

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1985) · state: closed · merged: True

## Original PR description

Forced two-CTA D128 backward tests admit SM103 even though `cta_pair="on"` supports only devices in `CTA_PAIR_CCS`, currently SM100. The tests reach `check_support()` and fail with `NotImplementedError`.

Use the production device set in the shared test gate and apply it to the pair branch of the dK/dV accumulation tests. Keep the broader accumulation gate for the mixed one-/two-CTA heuristic tests so SM103 retains its one-CTA coverage. Add a regression for SM100 admission and SM103 skips through both pair-test entry points.

Validation:
- Both new gate regression cases pass with CuTe DSL 4.8.0.
- All 66 previously failing cases skip with simulated SM103 capability metadata. This checks admission on an SM100 host, not execution on SM103.
- Changed-file pre-commit and `git diff --check` pass.
