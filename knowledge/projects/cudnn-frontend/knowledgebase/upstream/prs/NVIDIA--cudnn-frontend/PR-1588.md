## Summary

<!-- What changed? Keep the scope concise. -->
Adds cudnn.gnn.mha_simple, a PyTorch API backed by cuDNN’s GNN MHA Simple forward and backward operations. It supports separate source keys and values and destination queries, optional edge features and score parameters, caller-provided dropout masks, returned attention coefficients, deterministic backward, and FP32 feature gradients for half-precision inputs.

## Why

<!-- What problem does this solve, and why is this approach appropriate? -->
This exposes the new cuDNN MHA Simple backend operation to PyTorch users working with CSC graphs. The wrapper handles tensor validation, backend dispatch, and gradient propagation while following the existing GNN frontend pattern.

## API and compatibility impact

<!-- Note public API, supported GPU/cuDNN/CUDA/Python versions, performance, or backward-compatibility changes. Write "None" if not applicable. -->
- New public API: cudnn.gnn.mha_simple.
- A loaded cuDNN 9.29 or newer backend and an SM 8.0 or newer GPU are required. The operation is unavailable on Windows.
- The bindings can be built with older supported cuDNN headers through dynamic loading; cuDNN 9.29 headers are not required at build time.
- Returned attention coefficients are FP32 and pre-dropout. Deterministic backward requires reverse-CSC metadata and must be requested explicitly.
