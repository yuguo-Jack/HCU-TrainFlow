## Affected area

FE OSS kernels or CuTeDSL.

## Summary

- `sm100/prefill_d128_f16.py`: the dense band's exp2 split interleave is `(8, 2)` when the installed public CuTe DSL is at least 4.8.1 and `(16, 4)` below it or when the version cannot be read; the paged causal interior keeps `(16, 2)`.
- `cudnn/frost/buffers.py`: `cutedsl_release(version)` returns the public wheel's release tuple (None for an absent, foreign or unparsable version); `cutedsl_at_least(floor)` compares the installed release against a floor; `cutedsl_too_old` reads the release through the same parser.
- `test_sdpa_fwd_dsl_sm100.py`: loads the kernel module with the DSL version mocked and checks the pattern per version, the unreadable-version fallback, the paged interior and the causal fold-out, through a test-local template cache.
