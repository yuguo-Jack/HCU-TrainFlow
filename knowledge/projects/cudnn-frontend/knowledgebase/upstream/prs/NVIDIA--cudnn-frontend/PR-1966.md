# perf: align backward Q loads with MMA lookahead

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1966) · state: closed · merged: True

## Original PR description

The backward loader waited for dO_dV(i)'s buffer before issuing Q(i+1), delaying the next score even when the MMA used lookahead. Preload the first Q tile, then issue dO(i), Q(i+1), and dO_dV(i) in the consumer's order.

Share the Q load helper with the natural-order path, preserve the empty/final-tile guards and whole-ring drains, and document the dependency in the SDPA guide. Buffer sizes, TMA counts and launch counts are unchanged.
