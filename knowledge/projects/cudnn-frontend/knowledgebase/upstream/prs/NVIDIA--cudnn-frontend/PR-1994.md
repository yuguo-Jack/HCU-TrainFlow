# Serve aligned SM80 SDPA layouts natively and decline staging

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1994) · state: closed · merged: True

## Original PR description

SM80 attention now serves eight-aligned padded head widths through native loads and caller-strided stores, removing the padding gather/scatter path for supported layouts.

Graph eligibility and standalone preparation share a native addressing contract. Supported dense permutations, gapped layouts, strided Stats and packed THD remain available; THD ignores its unused batch stride. Copy-dependent declarations, including standalone RoPE and unsupported backward auxiliary contracts, decline before compilation.

The change also preserves standalone Stats backing-storage validation, rejects overlapping gradient elements before writes, and avoids a long host alias walk for legal interleaved outputs. Tests cover declaration rejection, numerical correctness, changed-input CUDA Graph replay, launch counts and artifact reload.

Related to #1986. Keep the issue open pending its separately owned default-route numerical verification. Heuristics and placement are unchanged.
