# Honor independent physical origins in native D256 THD prefill

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2172) · state: closed · merged: True

## Original PR description

Native unsplit D256 half-precision THD plans dropped physical-origin metadata during graph lowering, while the kernel addressed Q/K/V and Stats from logical prefix sums. With independently padded tensor ports, those are different addresses.

Forward the existing Q/K/V/O/Stats origin specifications to this branch, build sequence-local tensor maps, and consume the independent Stats origin. Mark the existing device-counter scheduler as persistent so its launch is bounded by resident workers. The public API, capability rows, and heuristic defaults are unchanged.

Validation: the regression test fails on the parent at the missing-origin contract assertion; all four native lifecycle cases pass after the fix. Coverage includes fp16/bf16, token/head-major Stats, natural/LPT scheduling, padded strides, offset rebinding, empty/keyless sequences, retained capture/replay, and execution under sync-debug error mode. Two cases each pass Compute Sanitizer memcheck, synccheck, and racecheck with zero errors or hazards. Changed-file formatting hooks pass.
