## Affected area

FE OSS kernels or CuTeDSL

## Summary

Persistent THD forward launches size their grid from a safety envelope. For one geometry on cc 10.0, `SdpaFwdDslSm100._thd_plan` instead launches exactly the packed token tiles: paged, bf16 d128, causal, b = 1, GQA 4 / 8, the cga2 LPT plan, with the tile count between one and two resident waves. cc 10.3 runs the same kernel but keeps the looser resident-wave count.

On a B300 the exact count helps GQA4 and does nothing for GQA8. This PR admits cc 10.3 for GQA4 only (`cfg.PACK_G == 4`). cc 10.0 and cc 10.7 are unchanged.

`test_packed_thd_grid_capture_changes_lengths` checks O / Stats under captures replayed with new lengths. It skipped off cc 10.0 ("initially admitted only on SM100") and now also runs on cc 10.3.

## Why

GQA4 paged b = 1 prefill on cc 10.3 runs 3-20 % faster in this window.

## Measurements

B300 SXM6 (1100 W), cuDNN 9.28.0.38. The harness was `benchmark/attention_inference/benchmark_single_attention.py --phase context --kv_layout paged --page_size 16 --causal --backend cudnn_oss` (FROST pinned), b = 1, 50 iterations after 10 warmup. Arm A is develop; arm B is the same tree with the gate widened. The arms ran A/B/A/B in separate processes with separate caches, and both ran the same plan (`PACK_GQA=1, SCHED_POLICY=1, SPLIT_KV=1, TILE_CGA_M=2`).

The first A/B widened cc 10.3 for GQA 4 and 8 (B/A per pair):

| case (q / kv, h_q / h_kv) | group | B/A |
|---|---|---|
| 2049 / 2049, 32 / 8 | 4 | 0.942, 0.939 |
| 1500 / 6000, 32 / 8 | 4 | 0.975, 0.972 |
| 4000 / 4000, 16 / 4 | 4 | 0.803, 0.805 |
| 3000 / 3000, 32 / 4 | 8 | 0.996, 1.002 |
| 4096 / 8192, 32 / 4 | 8 | 1.001, 0.999 |
| 1025 / 1025, 64 / 8 | 8 | 1.031, 1.025 |
| 900 / 4000, 64 / 8 | 8 | 0.997, 0.996 |
| 512 / 512 and 8192 / 8192, 32 / 8 (outside the window) | 4 | 0.998-1.009 |

GQA8 shows no gain and one 2.8 % loss, so cc 10.3 admits GQA4 only. That restriction was chosen after this run, so a second frozen set (seed 20261109) re-tested the restricted gate:

| cases | B/A |
|---|---|
| 8 GQA4 cases inside the window (h_q / h_kv 32 / 8, 16 / 4, 48 / 12, 24 / 6; q 866-4298, kv up to 4x q) | 0.83-0.97 on 7, 0.995-1.003 on 1 |
| 2 GQA8 cases inside the window (unchanged by the gate) | 0.993-1.002 |
| 2 GQA4 cases outside it (q 240, q 8371) | 0.998-1.009 |
