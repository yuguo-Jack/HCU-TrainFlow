## Affected area

CI or test infrastructure.

## Summary

Add 60 deterministic convolution cases covering forward, data-gradient, and weight-gradient operations, including ReLU and residual-add fusions. Preserve the existing 16 fixed cases and the convolution fuzzer's default behavior.

- Cover FP16, BF16, and FP32 inputs with FP32 computation across nine convolution configurations, including rectangular inputs, singleton spatial axes, and different filter sizes.
- Represent the convolution intermediate's dtype explicitly so the reference rounds at the same graph edge.
- Exercise both virtual and materialized weight-gradient intermediates, checking every exposed output independently.
- Add 21 small reference checks covering intermediate rounding, residual addition, activation, and default behavior.
- Mark the new GPU matrix L1, with a separate test entrypoint for focused selection. This change does not modify CI configuration; existing jobs selecting L1 will include these cases.

- `test/python/conv/graph/test_conv_fixed.py` defines the fixed parameter matrix, executes the cases, and checks final and materialized intermediate outputs.
- `test/python/conv/graph/test_conv_fuzzer.py` provides the shared graph and reference helpers. Optional intermediate settings preserve existing defaults; backward ReLU is available for the new fixed cases.

## Why

Add reproducible coverage for convolution fusion and intermediate rounding combinations that should run consistently rather than depend on random selection. Reuse the existing graph and reference helpers so fixed cases and the fuzzer share the same execution path, while checking materialized convolution results independently of the final fused output.
