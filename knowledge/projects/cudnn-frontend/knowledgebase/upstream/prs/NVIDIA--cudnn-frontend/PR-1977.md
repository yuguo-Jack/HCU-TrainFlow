# test: align SDPA contracts with appended fields and D192

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1977) · state: closed · merged: True

## Original PR description

Legal field additions and the native D192 backward row left older SDPA contract tests failing. Preserve each historical field segment while allowing later appends, construct the legacy positional capability prefix correctly, include the qualified D192 zero-scale row, and give the prepared-chain mock its configuration.

The FP8 THD fold check now distinguishes the final positional `live_kv` operand from the appended `D_b` keyword and checks both. The independent-width FP8 output test requires SM89+, where its native FP8 conversion is supported. The test guide records the append-only and keyword-argument traps.

Validation:
- Reproduced all 12 contract failures on develop `cd969f288`.
- After correction: 28 passed on SM100, including 16 FP8 fold cases with changed lengths, retained replay and fresh bindings.
- Simulated SM80 metadata: all 16 FP8 cases correctly skipped. This is a gate check, not an SM80 execution result.
- Changed-file pre-commit and `git diff --check` pass.
