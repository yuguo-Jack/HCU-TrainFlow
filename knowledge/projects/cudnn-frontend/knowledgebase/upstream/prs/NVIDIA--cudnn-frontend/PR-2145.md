# sdpa fwd heuristics (sm107): propose the sink split on the half row unless a window bounds the walk

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2145) · state: closed · merged: True

## Original PR description

## What

On the SM107 (Rubin) half row, `mismatch()` already admits split-KV with an attention sink, but `heuristics._split_points` left cc 10.7 out of its sink gate. So sink decode never split on Rubin: one CTA per packed head walked the whole KV cache. This PR proposes the split there, except under a sliding window, where the window already bounds the walk and the split's combine measured slower.

The native D64 one-wave rule (#2118, #2140) now checks whether the packed set splits instead of checking for a sink. A packed set that splits leads. One that cannot (single-Q off the 128-key tile) keeps the unpacked one-wave plan first, as before.

## Evidence

- **Study (train):** 327 dense bf16 sink cells covering d 64/128, b 1/3/16/64, KV 3000/4096/100000/131072 (on and off the tile), and S_q 1-4, with and without a window. Each cell was timed under develop and two sink-split variants. This policy matches the best measured arm in every cell. A split everywhere, including under windows and one-wave D64 off the tile, loses in the cells this policy excludes.
- **Holdout:** 28 cells, frozen before timing and sampled off the training lattice (non-power-of-two groups, odd KV, b 2/5/12/24/48). It covers every cell where this policy's first plan differs from develop's. No cell is slower than develop.
- **Numerics:** `test_sdpa_fp8_sm107.py` and `test_sdpa_fwd_split_kv_sm100.py -k sink` (L0+L1) pass on Rubin.

## Tests

- `test_rubin_native_d64_packs_past_one_unpacked_wave` gains an off-tile KV axis and now states the rule by whether the packed set splits.
- `test_rubin_decode_packing_uses_selected_flavor` expects the split with a sink and no window, and no split with a sink under a window.
- `test_sm107_shared_d128_scheduler_follows_the_measured_tables`: the long-cache LPT cell moves from b=1 to b=128. At b=1 the split now leads, sink or not; at b=128 no split is proposed, so the unsplit decode tile's LPT lead is still what the cell checks.
- Host heuristics/placement suites: 1826 passed.
