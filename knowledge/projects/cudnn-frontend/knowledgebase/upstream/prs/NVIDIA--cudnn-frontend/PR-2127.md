# perf(sdpa): use single-Q D64 for SM107 unsplit decode

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2127) · state: closed · merged: True

## Original PR description

Depends on #2123.

SM107 half D64 dense unsplit plans currently run a two-slab prefill body even when every live query row fits in one slab. Select the existing physical-D64 single-Q body for N128/CGA1 plans when Q length times the packed group fits 128 rows. The module is compiled for the actual SM107 target.

Keep longer queries, N64, CGA2, THD, paged, additive bias, KV masks and prefolded-scale handling on their existing paths. No public capability, knob domain or heuristic policy changes. Both graph and standalone execution retain the same bindings, output precision and workspace contract.

Validation: host route regressions fail before the change (4 failed / 7 passed) and pass afterward (11 passed), including boundary and feature controls. On SM107, 62 graph/standalone replay-and-rebind tests pass: 20 new unsplit cases plus the existing split and packing controls. Two scoped memcheck cases pass with zero errors. Coverage includes FP16/BF16, partial GQA, asymmetric widths, masks/sinks, both Stats log bases, the 128-row boundary and a 129-row prefill control. Scoped pre-commit passes.
