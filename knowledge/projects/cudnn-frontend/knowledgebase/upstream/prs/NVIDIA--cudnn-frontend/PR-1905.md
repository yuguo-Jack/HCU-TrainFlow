# sdpa: enable fused row max for shared SM107 paged D128

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1905) · state: closed · merged: True

## Original PR description

Paged half-precision D128 on SM107 uses the shared SM100 kernel, but the adapter enabled its fused row-max only on SM103 because the native SM107 siblings use that instruction unconditionally. Enable the existing fused load/max specialization for this shared route; masked tiles keep their current path and plan ordering is unchanged.

Adds public graph regression coverage for BF16/FP16 with and without PackGQA, checking the selected kernel and architecture flag, full O/Stats against FP64, poisoned workspace replay, and changed page maps/data/lengths. Existing SM100 and SM103 row-max selection stays unchanged.

Validation on commit `060c35708`: all four public graph tests pass on SM107; the packed BF16 case also passes Compute Sanitizer memcheck and synccheck with zero errors. A separate-process compile/run verifies four fused LDTM row-max instructions and retained register allocation in SASS. Formatting and SPDX hooks pass.
