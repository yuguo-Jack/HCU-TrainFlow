## Affected area

Tests only: `test/python/gated_attention_block/cutedsl/test_block_backward_{fp8,mxfp8}.py`.

## Summary

#1522 added `test_{fp8,mxfp8}_dense_tail_backward_is_finite_and_quantizes_bitwise` for the dense `S % 128 != 0` record that #1520 serves. That test checks finite gradients and the bitwise quantizer / scalar / delta layer. It does not compare gradient values with an oracle (CodeRabbit's nitpick on #1522).

This PR adds the same `s992_dense_b1` cell to the parametrization of `test_{fp8,mxfp8}_stage_localised_bounds`. That test checks every stage and the end gradients against the row reference and the seeded oracle, under the bounds the matrix cells use. The cell stays out of `_CELLS`, so the other matrix tests and `test_the_matrix_declares_what_the_module_says` are unchanged.

## Related issues

Follow-up to #1522 / #1520.

## API and compatibility impact

None (tests only).

## Testing

- Collection on B200: the new ids `test_{fp8,mxfp8}_stage_localised_bounds[s992_dense_b1-norm]` collect, and `test_the_matrix_declares_what_the_module_says` passes in both files.
- The new cells need SM107. CI's `python/*/cutedsl:cutlass-4.8:sm107` lane is their first run. If a stage misses its bound on the dense tail, that is a finding about the #1520 backward path.
