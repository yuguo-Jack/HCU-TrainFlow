## Summary

Replace pybind11 with nanobind and add opt-in Python stable ABI builds through `CUDNN_FRONTEND_PYTHON_STABLE_ABI=ON`.

Preserve explicit `int(enum)` conversion for all 15 exposed enum types and add regression coverage for integer persistence and enum reconstruction.

## Why

<!-- What problem does this solve, and why is this approach appropriate? -->
[nanobind](https://github.com/wjakob/nanobind) is a C++/Python binding library created by the original author of pybind11. Its [stable ABI support](https://nanobind.readthedocs.io/en/latest/api_cmake.html) allows a single wheel per platform to support multiple Python versions, reducing wheel build and release maintenance.

This PR migrates the bindings to nanobind and adds opt-in stable ABI builds. The relevant requirements are:

- **CPython 3.12+ for stable ABI builds:** nanobind's linked build mode relies on limited API functionality introduced in Python 3.12. See the [nanobind FAQ](https://nanobind.readthedocs.io/en/latest/faq.html#can-i-make-stable-abi-extensions-for-pre-3-12-python).
- **CMake 3.26+ for stable ABI integration:** CMake 3.26 introduced the `Development.SABIModule` component and `Python::SABIModule` target used by this build. See the [CMake documentation](https://cmake.org/cmake/help/v3.26/module/FindPython.html).
- **Python 3.10+ for the selected nanobind dependency:** this PR uses nanobind 3.0.1 or newer within the 3.x series, which requires Python 3.10+. See the [nanobind changelog](https://nanobind.readthedocs.io/en/latest/changelog.html).
- **Free-threaded builds are excluded from this stable ABI path:** they continue to use version-specific builds. See [nanobind's free-threading documentation](https://nanobind.readthedocs.io/en/latest/free_threaded.html).

Similar migrations have been discussed and adopted in other projects:

- [ONNX: migrate to nanobind for stable ABI support](https://github.com/onnx/onnx/issues/7275)
- [MLIR: migrate Python bindings to nanobind](https://github.com/llvm/llvm-project/pull/118583)
- [MLIR: add optional stable ABI support](https://github.com/llvm/llvm-project/pull/183856)
