## Affected area

## Summary

The 2026-10-13 develop schedule failed 9 cases on the `python/*/cutedsl:cutlass-4.8:sm107` lane. In each case the API correctly rejects Rubin (SM107), and the test did not gate on that:

- 8 cases, from #1553: the `qcluster-h16` / `qcluster-h32` parameters of `nondefault_stream_zero_init_ordering`, `sm100_execute_allocates_nothing_and_never_synchronizes` and `execute_requires_preallocated_outputs`. `q_cluster_mode="adaptive_pair"` requires compute capability 10.0 or 10.3 (`_BLACKWELL_CAPABILITIES`), so `_require_sm100()` (major == 10) is not enough. The new skip uses the file's `_TWO_CTA_CAPABILITIES`, which is the same set.
- 1 case, from #1422: `test_dglu_canonical_deterministic_dprob`. The dGLU API raises `NotImplementedError` for deterministic dprob on the Rubin kernel. `require_sm100()` accepts any major 10.

The skips mirror the API's own eligibility checks; neither path is supposed to run on SM107.

## Testing

B200 (SM100), cuDNN 9.27.0.42, from this branch: the 8 q-cluster cases and the dprob case all pass (9 passed), so nothing is newly skipped on SM100. Not run on SM107 locally (no Rubin GPU here); the CI sm107 lane will show the skips.
