# [1.29.0-megatron] Cherry-pick dGLU deterministic dprob (#1319, #1325, #1414)

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1589) · state: closed · merged: True

## Original PR description

Cherry-pick three merged `develop` PRs to `feat/1.29.0-megatron`, in merge order:

| Commit | PR | Change |
|---|---|---|
| `52563c6e` | #1319 | dGLU deterministic `dprob` (`deterministic=True`, opt-in) |
| `d4b515b8` | #1325 | dGLU: initialize dbias/amax on the launch stream; key the dbias cache on `n` |
| `8d418066` | #1414 | allow deterministic `dprob` with discrete weights |

Kernel, docs and tests are as merged. The 1.29 Python wrapper predates develop's `dglu_block_scaled_run` / `_kernel_instance` refactor, so the API layer is adapted (each commit message has a "Backport" note):

- **#1319**: slot allocation + fixed-order reduction at 1.29's two `execute` call sites; `deterministic=True` passed in `compile()`, which also keeps `_kernel_obj` for the test.
- **#1325**: 1.29 allocates outputs inline, so that block runs under `_torch_stream_context(current_stream, ...)`. The cache-key fix applied cleanly.
- **#1414**: dropped its edit to an SM107 test branch that only exists on develop.
