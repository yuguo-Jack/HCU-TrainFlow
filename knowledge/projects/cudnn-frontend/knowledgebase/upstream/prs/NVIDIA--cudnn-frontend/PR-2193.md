## Affected area

FE OSS kernels or CuTeDSL (SM120 SDPA forward).

## Summary

Enable FP16/BF16 dense exact-D128 additive attention bias on SM120. Load FP32 or matching-dtype bias directly into registers, broadcasting batch/head dimensions and applying `scale * QK + bias` before masking and softmax. Bind current caller storage through the shared prepared dense validator.

## Why

SM120 plans currently decline additive bias. A bias-only prepared host and natural-unit score scale provide the native lowering without execute-time copies or extra kernels. Stable max subtraction avoids inverse-scale and log2-intermediate overflow; the bias-present sink epilogue handles zero-mass `-inf` rows and `+inf` sinks. Rule S15 records these traps and detectors.

## Related issues

Related to #381.

## API and compatibility impact

Scope is unsplit, unpacked M64/M128 prefill with exact D_QK=D_V=128. Existing top-left causal, sliding-window, right-band and padding masks compose. Other heads, decode tiles, THD, paging, splits, PackGQA and execute-time shape/stride overrides retain declines. The graph contract already forbids bottom-right causal with bias; standalone preserves that restriction.

The optional standalone execute operand is appended. No graph API, heuristic or tolerance change. The bias-free host ABI, specialization and arithmetic remain intact. Execution adds no allocation, host read, layout conversion or runtime compilation. No performance claim. Native qualification is cc12.0 only.
