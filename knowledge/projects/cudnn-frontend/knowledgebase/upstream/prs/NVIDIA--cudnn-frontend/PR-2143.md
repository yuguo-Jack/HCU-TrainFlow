# Fuse SM107 D256 split decode reduction within a cluster

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2143) · state: closed · merged: True

## Original PR description

Dense BF16 D256 decode with one query, GQA ratio 16 and an already-selected eight-way KV split currently launches attention followed by a separate reduction. This change reduces the partials inside the same thread-block cluster, using an ordered cluster barrier and fixed split traversal. Each thread writes disjoint final elements; final Stats are optional.

The internal specialization retains the existing engine, split/pack knobs, caller workspace and public graph/standalone APIs. Final O and Stats use their own validated strides and pointers. Both Python and native C++ binding support the new frame; an older extension keeps the separate reduction. Other dtypes, geometries, masks, lengths, paged KV, sinks, gates and PDL retain their existing implementation.

Validation:

- Fresh C++ extension builds successfully; 590 focused dense/split host tests pass, with 44 skips and two GPU-only cases excluded from that host run.
- Native integration run: 67 tests pass, covering O-only/O+Stats, Python/native binding, ordered/mapping graph calls, independent pitches, element-aligned final O, fresh pointers, changed-input retained capture, bytewise repeatability, workspace canaries and separate-reduction/template controls.
- The existing decode suite's host checks pass: 30 passed, 133 GPU-only skips. This includes 17 new internal specialization/admission checks.
- Scoped repository hooks and `git diff --check` pass. The integrated graph path passes four cases each under Compute Sanitizer memcheck, racecheck and synccheck, with zero errors, hazards or warnings.

No capability-row, support-matrix, public-knob, placement or heuristic change.

The 20 native cluster-split regressions are collected through `test_sdpa_fp8_sm107.py::TestNativeClusterSplit`, an existing CI entry. The shared helper has no `test_` prefix, avoiding duplicate collection in directory sweeps.
