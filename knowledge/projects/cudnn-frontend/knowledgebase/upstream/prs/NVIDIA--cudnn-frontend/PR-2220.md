# sdpa 8-bit (sm107): P-slot TMEM forward layout, MXFP8 d128 split-KV, fp8 D192x128 dK/dV + dQ kernel pair

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2220) · state: open · merged: False

## Original PR description

## What

Forward (`sdpa_fwd_prefill_sm107_fp8`, `sdpa_fwd_prefill_sm107_mxfp8`):

- Split-KV for the MXFP8 d128 prefill on dense graphs with half outputs (`SM107_MXFP8_SPLIT_SHAPES`).
- Per-tensor FP8 kernels: a per-chunk abs-max tree with one Amax_O atomic per warp, two O chunks per TMEM wait and a dead-row select in the fp8-output epilogue, dedicated TMEM P columns with SMEM row stats and a register row-sum, early BMM1, and the TMA warp publishing the decoded next tile for the softmax warp groups.
- MXFP8 kernels: P in a dedicated TMEM slot shared by the softmax warp groups (aliased in the S tails on single-CTA builds), row stats in SMEM, an fp32 register row-sum in place of the ones-tile MMA, the softmax / correction register split 184 / 104, and the O slab declared after the scale-factor slabs.
- d192x128 (both families): the correction releases each sub-tile's first BMM2 of the next tile once that sub-tile's O is read; the softmax warp groups start a tile after sub-tile 0's O store.
- Heuristics: single-CTA builds are listed for quantized d128 on the dense unsplit legs and for d192x128 dense MHA causal graphs (an fp8 O for the per-tensor kernel) under a K/V byte bound; quantized d128 GQA causal proposes plain LPT first; the no-GQA causal LPT wave bound follows.

Backward: the `sdpa_bwd_sm100_d192_fp8` dK/dV + dQ kernel pair serves dense MHA (192, 128) without windows on the sm107 line, with the K64 fp8 MMA form, the line's scheduler budget, the dQ kernel launched as the dependent grid of the dK/dV kernel, a wide delta pre-pass, the dK/dV epilogue register budget, and dP computed in two halves (the first into the spare TMEM columns). The stage-3 GEMM template renders a (256, 192) fp8 row and takes the MMA instruction N from the cluster tile.

Benchmark: `benchmark_single_sdpa.py --graph_replay N` (opt-in) times N executes captured in one CUDA graph.

`SUPPORT_MATRIX_TRACKER.md` records the MXFP8 split-KV shape and the pair row's cc 10.7 admission.
