# docs: put the framework token after the direction in op API names

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1596) · state: closed · merged: True

## Original PR description

Changes the naming convention from #1461 so the framework token is a suffix:

| Variant | Before | After |
| --- | --- | --- |
| PyTorch | `cudnn.<op_name>_<direction>` | unchanged |
| JAX | `cudnn.<op_name>_jax_<direction>` | `cudnn.<op_name>_<direction>_jax` |
| No framework | `cudnn.<op_name>_standalone_<direction>` | `cudnn.<op_name>_<direction>_standalone` |

For example, `cudnn.grouped_gemm_glu_forward` and `cudnn.grouped_gemm_glu_forward_jax`. The PyTorch name is now a prefix of its JAX and standalone variants.

Updates `docs/fe-oss-apis/api_conventions.md` (pattern and examples), `python/cudnn/AGENTS.md`, and the cutedsl integration skill. Docs only: no API has been renamed under either order yet.
