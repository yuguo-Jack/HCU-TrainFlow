# docs: JAX op functions return a plain tuple or dict, not TupleDict

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1593) · state: closed · merged: True

## Original PR description

Follow-up to the review note on #1461.

The contributor guides said every public op function returns a `TupleDict`, including the `<op>_jax_<direction>` ones. `TupleDict` is an unregistered dict subclass, so `jax.jit` rejects it as a return value. This scopes `TupleDict` to PyTorch functions and tells JAX functions to return a plain tuple or dict, in `python/cudnn/AGENTS.md` and the cutedsl integration skill.

Check, with the `TupleDict` class from `python/cudnn/api_base.py` on JAX 0.11.2 (CPU):

- `jax.jit(lambda x: TupleDict(output=x + 1))(1)` raises `TypeError`.
- The same function returning a plain dict or a tuple works.

Docs only; no runtime change.
