# Use bounded packed ragged grids on SM107

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1799) · state: closed · merged: True

## Original PR description

## Problem and change

The SM107 nonpaged D128 PackGQA path added in #1793 uses one persistent wave even when all declared packed work fits within two waves. Extend the existing bounded B1 launch rule to this path: assign each declared work unit an initial cluster when the total is above one resident wave and at most two; otherwise retain the existing persistent grid.

This reuses the same plan-time work count for setup and the compiled launch. It is restricted to BF16 D128, GQA4/8, causal LPT, CGA2, unsplit, without sink/gate/sliding window. The SM100 paged rule is preserved. No new knob, API, workspace, runtime device read or per-run preparation. Candidate enumeration and default placement are unchanged.

## Validation

- Extended the existing Rubin rebind/capture test with a larger B1 declaration. **16 passed** on SM107: FP16/BF16, NH/HN and ln/log2 Stats, fresh storage, changed device prefixes, poisoned outputs, untouched tails and retained old captures.
- A separate 22-case paired probe and 14-case fresh-process repeat check full FP64 O/LSE, single/20-operation replay, actual launch/binder agreement, coarse declared capacity and excluded-path controls. Comparative warm/cold and host validation is recorded privately; no Rubin timings are published here.
- Only `_thd_plan` changes among the implementation methods; execution methods are structurally identical. Scoped pre-commit passes.

The tests verify the execution contract, without pinning a particular launch count, heuristic winner or timing threshold.
