[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1860) · state: closed · merged: True

## Original PR description

## What

#1855 restored the packed PackGQA proposal for Rubin d64 decode. One existing test still pinned the #1607 behavior: `test_sm107_shared_d128_scheduler_follows_the_measured_tables[swa_decode_natural]` asserts that the first proposal is unpacked. On #1855's GPU CI pipeline (76646497), that case failed in the four SDPA lanes; I merged #1855 without catching it.

The d64 branch of that test now asserts the intended routing:
- a packed lead on the shared d128 decode tile, at NATURAL;
- the unpacked native 64-wide tile still proposed as a runner-up;
- every proposal admissible under `mismatch()`.

Test-only change; no production code is touched.

## Tests

- The previously failing case fails on develop 42e37c650 and passes with this change.
- All FROST SDPA heuristics files, `-m "L0 or L1"`: 1632 passed. That covers `test_sdpa_fwd_heuristics.py`, `test_sdpa_fwd_placement.py`, `test_heuristic_geometry.py`, `test_sdpa_heuristics_small_tile_sm107.py`, `test_split_kv_heuristic.py`, `test_sdpa_bwd_heuristics.py` and `test_knob_vocabulary_frost.py`.
