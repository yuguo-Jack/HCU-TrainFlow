# Remove the cudnn.torch block-sparse attention aliases

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1728) · state: closed · merged: False

## Original PR description

Removes three namespace aliases:

| Removed | Use instead (the same function) |
| --- | --- |
| `cudnn.torch.block_sparse_attention_forward` | `cudnn.block_sparse_attention_forward` or `cudnn.BSA.block_sparse_attention_forward` |
| `cudnn.torch.block_sparse_attention_backward` | `cudnn.block_sparse_attention_backward` or `cudnn.BSA.block_sparse_attention_backward` |
| `cudnn.torch.block_sparse_attention_fp8_forward` | `cudnn.block_sparse_attention_fp8_forward` or `cudnn.BSA.block_sparse_attention_fp8_forward` |

They were added in #1111 and shipped in 1.30.0 and 1.31.0. No caller was found: TransformerEngine, FlashInfer, Megatron-LM and JAX (heads of 2026-10-12/13) do not reference them, and GitHub code search finds no other user. This follows #1597, which removed the `cudnn.jax`/`cudnn.torch` grouped SwiGLU aliases.

`cudnn.torch` keeps the SDPA provider (`calls`, `install`, `served_plan_names`).

Changes:
- `cudnn.torch`: drop the names from `__all__` and `__getattr__`.
- `test_BSA_jax_parity.py::test_torch_runtime_without_jax` calls the top-level functions and asserts the `cudnn.torch` names are gone.
- `bsa.md`: the example imports from `cudnn`.
- API index: the three names are removed.

Testing, on an SM100 GPU with CUDA JAX 0.11.2:
- `test/python/block_sparse_attention/cutedsl/test_BSA_jax_parity.py`, `test/python/block_sparse_attention/jax/test_bsa_jax.py` and `test/python/api_index`, all markers: 44 passed, 2 skipped. One skip needs two visible GPUs; the other needs `CUDNN_API_INDEX_PACKAGE_ROOT`.
- The API index scanner matches the edited baseline, apart from the environment artifact below.
- pre-commit passes.

Environment note: `develop`'s C++ does not build against the shared backend build on this machine, so the package under test was this branch's Python with a compiled module from an earlier build. That module lacks the optional `gnn_agg_*` symbols (9 names in the index scan). This PR changes no C++.
