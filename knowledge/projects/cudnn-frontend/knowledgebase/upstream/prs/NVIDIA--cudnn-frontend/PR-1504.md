## Original PR description

## Summary

#1488 made the Rubin MXFP8 row claim THD at d256 only (`thd_d_shapes`), so a THD graph at d128 is now declined by the generic THD-shape clause (`THD (ragged) rides the packed native-tile leg on this engine (shapes [(256, 256)]); the head-dim envelope is dense-only`), which sits ahead of the row's own cc 10.7 clause in `engines.mismatch`. The P1 decline cell `test_sdpa_mxfp8_cc107_unsupported_requests_decline_L0[thd]` (#1478, merged two hours before #1488) still pinned the row's old sentence, so develop's cc 10.7 lane is red on that one cell. This PR makes the cell expect the THD-shape clause (test-only, one constant + one table entry). The row's own sentence, which still says THD is not wired on cc 10.7, is rewritten by #1481 together with its paged half.

## Testing
