## Affected area

FE OSS kernels or CuTeDSL

## Summary

- Preserve runtime Int64 strides in prepared SM100 DSA backward plans when a contiguous tensor or generic workspace can exceed signed Int32 element offsets.
- Retain the original compact plan specialization for address-safe shapes, so common shapes keep their existing code generation and performance.
- Include the address-width specialization in the compile cache key and cover data, Top-K index, and workspace boundaries.

## Why

Prepared plans previously compiled all symbolic tensors with compact layouts. For BF16 H96/D576, `S_q=38,837` is the first query extent where `S_q * H * D` exceeds `2^31` elements. The compact descriptor can narrow the leading offset and cause an illegal memory access during backward, while `S_q=38,836` still passes.

Making every plan fully dynamic with Int64 strides fixes the overflow but regresses common short shapes. This change selects the wide descriptor only when the plan's maximum compact offset requires it. The selection happens during support checking and compilation; `execute()` gains no branch, synchronization, or allocation.

## Related issues

None.

## API and compatibility impact

No public API or supported-shape change. Prepared SM100 DSA backward plans now compile one of two internal address-width specializations. The specialization is part of the cache key, and existing positional compiler call sites remain compatible through appended default arguments.

On an NVIDIA L20D (SM103), CUDA 13.0, PyTorch 2.12.1, and cuDNN Backend 9.20.0:

| Deterministic H96/D576 case | Baseline median | This PR median | Workspace |
| --- | ---: | ---: | ---: |
| `S_q=256, S_kv=4096, topk=2048` | 1.05725 / 1.06324 ms | 1.05860 ms | 906,166,272 bytes |
| `S_q=38837, S_kv=2048, topk=2048, valid_topk=1` | 10.16221 / 10.16444 ms | 10.22313 ms | 482,813,952 bytes |

The short shape keeps the original compact plan. The boundary result includes the reviewed Int64 Top-K row stride and is 0.58% above the prior always-wide medians. The post-#1766 ordinary H96 two-CTA path measured 0.66315 ms and produced finite gradients.
