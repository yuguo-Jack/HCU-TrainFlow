# test(gemm): gate the sm120-only wide-K and quant-scale padding tests on requires_sm120

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2168) · state: closed · merged: True

## Original PR description

## Problem

Several sm120-only tests run on every GPU and fail on any part that is not cc 12.x. They plan an sm120 config and execute it, but are not gated on `requires_sm120`.

- **`test_sm120_moe_block_scale_wide_k_major_tile_declines_before_compile`** (8 cases). #2024 added it under `@requires_sm120`; #2015 (7439066f) dropped the decorator, apparently while resolving the neighbouring hunk. Off cc 12.x, the graph reaches the sm120 dtype check before the TMA box check that the test asserts:
  ```
  E     Expected regex: 'exceeds the TMA box_dim ceiling of 256'
  E     Actual message: 'the sm120 fp8_e4m3xfp8_e8m0 MMA instruction exists only on 120 <= SM < 130, but the active GPU is sm_90'
  ```
- **The F8_128x4 quant-scale padding tests from #2011** (14 cases): `test_sm120_quant_scale_k_padding_is_zeroed` and `test_sm120_quant_scale_blob_admits_runtime_m_in_its_padding` in `test_matmul.py`, plus their MoE twins `test_moe_quant_scale_k_padding_is_zeroed_sm120` and `test_moe_quant_scale_blob_admits_runtime_s_in_its_padding_sm120`. They `_resolve` / `by_name` an sm120 config and execute it, but carry no sm120 gate; the MoE twins have only `requires_matmul_gpu`. On a B300 they fail with:
  ```
  E   NotImplementedError: block_scale_quantize requires block_size to divide the epilogue chunk width (...); got block_size=32, vsize=8
  ```

## Change

- Restore `@requires_sm120` on the wide K-major test, as #2024 had it.
- Add `@requires_sm120` to the two `test_matmul.py` tests.
- Replace `requires_matmul_gpu` with `requires_sm120` on the two MoE twins.

## Tests

- **Develop:** the 8 wide-K cases fail on a GH200 (sm90) and on a B300 (cc 10.3). The 14 quant-scale cases fail on the B300 (they are part of the 23 failures of `test/python/gemm` there).
- **With this change, on the B300:**
  - `test_moe_grouped_block_scale_matmul_fwd.py`: 618 passed, 157 skipped, 0 failed.
  - `-k sm120` over `test_matmul.py`, `test_moe_grouped_matmul_fwd.py` and `test_moe_grouped_block_scale_matmul_fwd.py`: 109 passed, 512 skipped, 0 failed.
