# Fix grouped GLU compiled-object cache reuse across devices

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1808) · state: closed · merged: True

## Original PR description

Calling a block-scaled SwiGLU or GLU wrapper on one GPU and then another with the same geometry can reuse the first GPU's compiled object. That object retains a CUDA launchable and workspace. The second call fails with `CUDA_LAUNCH_INVALID_CONFIG` / `cudaErrorInvalidValue`; clearing the cache makes it pass.

Include the input device in both compiled-object cache keys. GLU already has a device-aware outer memo, but its inner compiled-object cache also needs the device. This is two lines of production code; kernels, signatures and same-device reuse are unchanged.

The review follow-up in `1e767dc73` resets every created CUDA Graph in `finally`, under its creation device, including partial capture/assertion failures. Both cross-device tests pass again; the baseline still reproduces both expected failures. Production files are byte-identical to the earlier 38-pass qualification.

Validation:

- On two SM107 GPUs, the existing baseline and #1807 both reproduce the device-switch failure. Same-device calls and clearing the cache before switching pass.
- The new two-case regression fails on the baseline and passes with this fix. It alternates devices without clearing the caches, replays each device's capture after changing inputs, and compares against same-device eager outputs.
- The complete canonical GLU suite plus the two original GEMM/JAX cases from #1807: **38 passed**. No tests skipped. Each capture uses an explicit stream on its own device.
- Scoped formatting and license checks pass. Python Rule 4 now records the inner-cache detector and capture-stream requirement.

This was found while investigating #1807's remaining SM107 CI failure. The independently reproduced cache defect matches its error class, but the exact preceding CI sequence is not established; this is not a claim that the entire failed CI lane has been reproduced or fixed. The single-GPU original JAX cases also pass on the baseline. #1795's AOT wrapper work is separate and does not change these two cache keys.
