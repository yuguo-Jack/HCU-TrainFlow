# Use task-prefix lookup for unpacked paged split attention

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1712) · state: closed · merged: True

## Original PR description

Unpacked GQA and MHA paged D128 split attention still scan the batch to map each persistent task to its request. Reuse the work-prefix lookup introduced in #1711 for these configurations as well. The existing decoder already maps unpacked query heads, and the workspace contract already reserves the prefix tail.

This is a small follow-up to the now-merged #1711: remove the packing eligibility restriction and extend the existing numerical capture matrix at batch sizes 33 and 65. The setup producer and decoder share the same predicate. There is no new tuning knob, default-dispatch rule, host preparation, kernel launch, or synchronization protocol.

Validation on the proposed source:

- SM100: 88 existing unpacked capture cases plus 16 new B33/B65 cases passed.
- SM107: the same 88 existing and 16 new cases passed independently.
- Coverage includes FP16/BF16, MHA and unpacked GQA, page sizes 16/128, K/V layouts, O/LSE, changing and empty lengths, and retained graph/standalone capture. The new SM100 cases cover natural, LPT and LPT_L2 task order.
- Full-attention B33 GQA and B65 MHA capture probes passed memcheck with zero errors. Scoped format/license hooks passed.

Ready for review. Merge prerequisites remain current-head review/internal CI and controlled target-GPU performance qualification. The additional racecheck and target qualification are in progress; no serving-throughput claim is made here.

The PR is now based on `develop` after #1711 merged. Reparented head `fa6ea8d2a275` preserves all seven qualified implementation/test files byte-for-byte; the only inherited source difference is the previously merged page128 selection update (#1710). The original isolated validation checkout remains frozen. The earlier CI request was declined solely because its base was the parent branch; a fresh request targets this `develop`-based head.
