# perf(sdpa): mix exp2 in native D64 causal prefill

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1877) · state: closed · merged: True

## Original PR description

Native BF16 D64 causal prefill currently puts every softmax exponential on the MUFU pipe. Reuse the existing mixed-exp2 helper for unmasked interior tiles on SM100, assigning one quarter of the columns to FMA. Diagonal/masked tiles keep their existing math; FP16, noncausal, sliding-window, paged, THD, split-KV and other architecture paths retain their prior behavior. Public APIs and tuning knobs are unchanged.

Coverage checks full O and Stats against FP64 across packed/unpacked plans, both CTA widths, rectangular causal alignment, sinks, storage rebinding, and changed-input CUDA Graph replay. Architecture-gate tests cover the enabled and unchanged paths.

Validation: the 12 new numerical/replay cases, 73 architecture-gate checks, and 27 existing D64 cases passed. The unchanged SM103 path compiles; the focused packed two-CTA case passes memcheck and synccheck with zero reported errors. Scoped pre-commit checks pass.
