## Summary

- Replace the eight SUSE network and local `zypper` install commands in `docs/installation/linux.mdx` with `sudo zypper --non-interactive install`.

## Why

NVBugs bug 6929079. The SUSE network and local install sections passed DNF's `--allowerasing` to Zypper. The [openSUSE Leap 15.6 Zypper manual](https://manpages.opensuse.org/Leap-15.6/zypper/zypper.8.en.html) does not define that option, so those commands cannot be followed as written. `--non-interactive` is the global option the manual recommends, and it must come before `install`. The old `-y` flag is a valid install alias for `--no-confirm`, but the manual recommends the global option instead. The `dnf` and `tdnf` commands still use `--allowerasing`. `--force-resolution` was not added because the manual advises against it for unattended installs, and a conflict-resolution workflow should be documented only after it is validated.
