## Affected area

FE OSS kernels / CuTeDSL: GDP summary normalization.

## Summary

Repeated GDP summary calls with token-major K and in-kernel L2 normalization fail because the cached normalization launch binds rank-4 K to a dummy Q argument compiled as rank 3. Pass the normalized-K workspace as that unused argument, matching the initial `skip_q=True` compilation.

Extend the existing token-major summary test to execute twice, preserving bitwise comparisons with expanded inputs for forward state, transition and backward summary.

## API and compatibility impact

None. The actual K input, normalization math, workspace and stream are unchanged.

## Testing

- `pre-commit run --files python/cudnn/linear_attention/frost/gdn_engine.py test/python/linear_attention/test_la.py`: passed.
- On NVIDIA GB300, from `test/python`: `python -m pytest -q linear_attention/test_la.py::test_gdp_summary_token_major_bitwise`: **3 passed** (Householder counts 1, 2, 3).
- With the original engine line restored, the same regression fails at the cached L2-normalization launch with `Mismatched Tensor on argument #0 ... expected ndim=3`.
