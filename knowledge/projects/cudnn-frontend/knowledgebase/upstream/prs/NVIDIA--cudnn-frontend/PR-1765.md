## Affected area

FE OSS kernels, Python API, tests and benchmarks.

## Summary

Add `cudnn.ops.qsa_forward` and `cudnn.ops.qsa_backward` for packed QSA training. They replace the Miles `qsa_fprop` and `qsa_bprop` calls with the same argument order and `block_size=4`. Forward returns `out, out_fp32, lse`; backward returns `dq, dk, dv` through ordered TupleDict results. See the [API and tensor contract](https://github.com/NVIDIA/cudnn-frontend/blob/1e0af98e806e71e0e07fb1291809ee4d9d50efa6/docs/fe-oss-apis/qsa.md).

The implementation supports Blackwell SM100/SM103 and native Rubin SM107. Forward selects dense or gathered tiles using current device data and exact masks. Blackwell 12:1 backward pairs adjacent queries to share K/V loads while preserving separate masks. Int64 address products support large bitmaps. Backward uses FP32 accumulation and a three-component dS representation for dQ cancellation accuracy, then casts gradients to BF16.

## API and compatibility

Contiguous CUDA BF16 THD inputs, D256, 12Q/1KV or 24Q/2KV, and four-token blocks. FP32 output and natural-log LSE are saved for explicit backward; no autograd wrapper is installed. Unsupported configurations fail before launch. Requires CuTeDSL >=4.7; Rubin also requires a native SM107-capable build. Imports remain lazy, metadata is rebuilt per call, and launches use the current stream.

At 128K, forward compact indices use 16 GiB. Paired 12:1 Blackwell backward reduces that buffer to 8 GiB. Other backward paths retain the full-size indices.

## Results

Commit `1e0af98` contains the measured kernel files from source archive `84f4b2e66b6658e968e8a9649993457f6a197bd6add66b331d568228a6fd768d`. All 13 QSA source files match that archive.

On B200 and B300 SXM6 AC, forward and backward beat unchanged Miles in all nine regular cases. The close packed 4096-token, 24-query-head case also wins with timing order reversed. At 32768 tokens and 12Q/1KV, forward/backward speedups are 3.798x/4.999x on B200 and 3.746x/4.928x on B300 SXM6 AC. Full calls include allocation, metadata, preparation and casts. See [Blackwell results and methodology](https://github.com/NVIDIA/cudnn-frontend/blob/1e0af98e806e71e0e07fb1291809ee4d9d50efa6/benchmark/qsa/results.md).

Original Miles forward fails at 128K due to Int32 bitmap row offsets. The separately labeled 128K comparison uses only an Int64 offset fix; it is not an unchanged-Miles comparison.

The pinned Relax standalone benchmark also passes all 24 Blackwell cases and wins all 72 attention comparisons (forward, backward and combined), with adapter costs included. Long cases pass reversed-order checks. The [adapter and run guide](https://github.com/Anerudhan/relax/tree/fb5adf456ff826a84ca0dee605d5ada8abb85ef3/examples/models/qwen3.8-flash-next/cudnn_qsa) preserve the upstream baseline and selector.
