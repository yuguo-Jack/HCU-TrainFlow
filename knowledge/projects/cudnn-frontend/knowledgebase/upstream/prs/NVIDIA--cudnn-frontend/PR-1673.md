## Affected area

CI or test infrastructure: Python graph BatchNorm tests.

## Summary

Add 163 deterministic FP8 cases to `test/python/norm/graph/batchnorm_fusion_cases.py`, all marked L1. Cover BN, BN+ReLU, BN+Add+ReLU, and their backward patterns across 11 shapes with batch size 400.

- Forward: E4M3 and E5M2 inputs/outputs.
- Backward: E4M3/E4M3, E5M2/E5M2, and E4M3/E5M2 activation/gradient types.
- Preserve the original eight cases, including IDs and seeds; exclude the two already-covered FP8 combinations.
- Generate stable IDs and seeds so inserting or reordering cases does not change existing inputs.

## Why

The existing FP8 coverage has one forward and one backward case. Expand the shape and dtype matrix using the existing graph builders and independent references, without adding another test harness. Reuse checks for outputs, statistics, gradients, masks, and AMAX.

## Related issues

None.

## API and compatibility impact

No production API, graph-builder, reference, or CI scheduling changes. Existing cases and capability checks are unchanged. Unsupported configurations skip; numerical failures remain failures.
