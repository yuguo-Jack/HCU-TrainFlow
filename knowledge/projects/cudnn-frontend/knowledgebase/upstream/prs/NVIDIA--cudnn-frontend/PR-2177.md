# Allow unsplit D192 THD overrides without split workspace bounds

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2177) · state: closed · merged: True

## Original PR description

An explicit single-CTA D192/V128 THD plan was rejected when shape overrides were enabled without `max_total_seq_len_q`, even with `SPLIT_KV=1`. Its admission reused a bound needed for split partial workspace, which the unsplit plan does not allocate.

Allow that existing unsplit implementation to accept the graph while preserving the split-workspace bound and the other feature restrictions. Automatic candidate generation is unchanged. Extend the existing physical-origin tests to cover single-CTA Natural/LPT without a total-Q hint, including FP16/BF16, both Stats layouts, pointer/stride rebinding and retained CUDA Graph replay.

Validation: the focused capability regression fails on the parent and passes after the fix (4 cases). The parent GPU admission check also fails as expected; 16 native lifecycle cases pass, plus 2 cases each under memcheck, synccheck and racecheck with zero errors/hazards/skips. Twenty original FI-graph observations pass complete-row O/natural-LSE checks and poisoned replay in both execution orders (40 reference phases). Changed-file pre-commit hooks pass.
