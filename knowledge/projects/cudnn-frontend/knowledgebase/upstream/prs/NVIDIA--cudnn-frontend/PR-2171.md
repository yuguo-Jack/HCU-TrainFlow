# Skip softmax math for fully masked native causal tails

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2171) · state: closed · merged: True

## Original PR description

A two-CTA native D128 THD work item shares its KV range across four query subtiles. Earlier subtiles therefore continue computing softmax for a suffix that is masked for every live row. Publish alpha=1 and explicit zero probabilities for that suffix, preserving the producer range, every data barrier, and the score-slot phase sequence. The specialization applies to unpacked, unsplit half-precision causal attention; other specializations retain their existing arithmetic.

The native CI entry adds six lifecycle cases covering N64/N128, FP16/BF16, both causal alignments, right-band widening, forced rescaling, independent physical origins, stride/buffer rebinding, changed-input retained replay, and empty work. Reference-side checks require the rescale stress to cross the existing threshold. The shared test helper retains its original defaults and tolerances.

Validation on this head: six native cases passed; two cases each passed unfiltered Compute Sanitizer memcheck, synccheck and racecheck with zero errors/hazards. The four changed files passed all pre-commit hooks. Two high-growth numerical boundary probes were also compared against the parent: inputs, FP64 references, and failing output tensors were byte-identical; those pre-existing boundaries are not fixed by this change.
