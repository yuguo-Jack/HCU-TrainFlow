# Support paged KV for native D128 single-Q prefill

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2175) · state: closed · merged: True

## Original PR description

Extend the explicit `WARP_SPEC_CFG=1` native D128 half-precision THD topology to paged K/V. The loader fills the existing K/V stages through page-sized TMA boxes, with independent K/V pool layouts and block-table strides. Q, O and Stats keep their declared physical origins; the attention arithmetic and consumer pipeline are unchanged.

The option supports HND/NHD and mixed pool layouts, legal page sizes, optional Stats, diagonal bands, sinks and natural/LPT scheduling under the existing graph contract. It remains unsplit and unpacked. Omission or zero retains the existing topology; heuristic enumeration and defaults are unchanged. This extends only the explicit knob domain and changes no Capabilities eligibility row.

Validation: 18 native tests pass, including five paged lifecycle cases plus the existing one-Q and D256-origin controls. Coverage includes independently padded table strides, fresh bindings, changed lengths, keyless/empty inputs, poisoned gaps and retained CUDA Graph replay. Three paged cases each pass Compute Sanitizer memcheck, synccheck and racecheck with no errors or hazards. Original numerical tolerances are unchanged. The parent rejects this paged knob combination. Changed-file formatting passes.

Depends on #2173 for the explicit one-Q topology and its #2172 prerequisite. This branch includes those prerequisites; the paged extension is commit `0d6ce27b996b38bbd9b2dc9882851b5f93b8ccec`.
