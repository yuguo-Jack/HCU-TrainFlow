# Support narrow KV tiles for native SM107 FP8 D64

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1972) · state: closed · merged: True

## Original PR description

## Summary

Native SM107 per-tensor FP8 D64 previously rejected an explicit 64-column KV tile even though the existing kernel body can render it. This change admits `cudnn.knob_type.TILE_N: 64` through the graph API and `tile_n=64` through the standalone adapter for E4M3/E5M2, including head dimensions already served by the D64 envelope. It reuses the native body and its existing packed, split, sink and output paths.

The graph A/FALLBACK proposals and standalone default remain 128. The explicit domain is kept separate from the half-precision resident-arm selector, so padded FP8 tails do not silently inherit that selector. Wider per-tensor and block-scaled domains are unchanged.

## Affected area

FE OSS kernels / CuTeDSL SDPA.

## API and compatibility impact

Expands an existing performance knob; no new parameter or enum value, no new graph eligibility, and no heuristic or placement edits. The support matrix does not track knob domains (SDPA Rule S2).

## Testing

On SM107, public CuTeDSL4.8 and cuDNN9.28, from `test/python`:

```bash
pytest -q -o addopts= -m L0 \
  sdpa/frost/test_sdpa_fp8_sm107.py::TestNativeD64Fp8Narrow \
  sdpa/frost/test_sdpa_sm107_native_d64_fp8.py::test_standalone_d64_padded_default_tile_n \
  sdpa/frost/test_sdpa_fwd_config_sm107.py::test_fp8_d64_narrow_tile_keeps_graph_defaults \
  sdpa/frost/test_sdpa_fwd_config_sm107.py::test_fp8_narrow_tile_stays_within_per_tensor_d64
```

**52 passed, no skips.** Covers both FP8 input types, CGA1/2, half/FP8 outputs, packed/unpacked, split with sinks, tail lengths, O/Stats/Amax, rebinding and retained CUDA Graph replay. Eight checks pin A/FALLBACK defaults and six native controls pin standalone defaults.

For each of `memcheck` and `synccheck`:

```bash
compute-sanitizer --tool <tool> --error-exitcode 91 python -m pytest \
  -q -o addopts= -m L0 -k 'swa or padded or split_sink or (standalone and 129)' \
  sdpa/frost/test_sdpa_fp8_sm107.py::TestNativeD64Fp8Narrow
```

**10 passed per tool, zero errors.** Four E4M3/E5M2 x CGA1/2 offline target compiles also pass. Scoped formatting and license checks pass.
