# sdpa fwd (sm100): single-CTA prefill body for nonpaged d128 MHA THD; FROST leads nonpaged d128 MHA and d64 causal THD from 512 declared tokens

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1903) · state: closed · merged: True

## Original PR description

## Summary

**Kernel routing (first commit).** Nonpaged D128 half-precision THD graphs with one query head per KV head, unsplit and under a plain mask (none, causal or padding), now run the single-CTA two-slab prefill body on cc 10.0 and cc 10.3: a config predicate (`config_sm100.supports_sm100_nonpaged_d128_thd_single_cta`) shared by the engine capability domain, the mismatch check and the adapter gate, and the width chooser puts that body first with the pair tile kept as a runner. Grouped heads, windows, bands, sinks, biases, kv_masks and pre-folded scales keep the pair tile. The kernel body itself is unchanged (the paged THD and Rubin nonpaged routes already run it).

**Placement.** Two placement rules for the SM100 / SM103 f16 row in `_place_sm100_f16` (`python/cudnn/sdpa/fwd/placement.py`):

- **Nonpaged BF16 d128 causal THD with one Q head per KV head**: the unpacked FROST plan leads the backend when each sequence declares at least `NONPAGED_D128_MHA_THD_MIN_TOKENS` (512) tokens of Q and KV and the cache declares at least `NONPAGED_D128_MHA_THD_MIN_KV_TOKENS` (4096) tokens, on cc 10.0 and cc 10.3.
- **Nonpaged BF16 d64 causal THD with any whole-number Q/KV head ratio**: the unpacked FROST plan leads under the same declaration bounds with a 512-token cache floor, on cc 10.0 and cc 10.3.

Both rules require bottom-right alignment or `s_q == s_kv`, equal declared Q and KV extents and totals, no sliding window, sink, right-band widening or epilogue gate. Graphs outside these bounds keep the existing order. The module docstring records both rules next to the other SM100 THD rows.

## Tests

- `test/python/sdpa/frost/test_sdpa_fwd_thd_d128_single_cta_sm100.py`: the single-CTA body leads and matches an fp32 reference for short, mixed and full-length live sequences under the three masks, with and without Stats, for BF16 and FP16; grouped heads keep the pair tile.
- `test/python/sdpa/frost/test_heuristic_geometry.py`: the new leg's capability domain, first plan, runner and mismatch admission across dtypes, masks and both architectures, the graphs that stay off it, and parametrized cases for both placement rules on cc 10.0 and cc 10.3 with cache-shape and bounded declarations.
