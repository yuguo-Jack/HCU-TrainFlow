# dsa: JAX ops for the DSv4 indexer, top-k, sparse attention and compressor in cudnn.ops.dsa

## Original PR description

@coderabbitai ignore

Fixes #2065. This takes the JAX bindings from #1947 (@dinodeep) the rest of the way. The ops follow [`docs/operations/api_conventions.md`](https://github.com/NVIDIA/cudnn-frontend/blob/develop/docs/operations/api_conventions.md) and live in `cudnn.ops.dsa`, a layout that matches #1847.

| `cudnn.ops.dsa.` | #1947 name |
|---|---|
| `indexer_forward_jax` | `indexer_forward_jax_sm100` |
| `indexer_top_k_forward_jax` | `indexer_top_k_jax_sm100` |
| `indexer_backward_jax` | `sparse_indexer_backward_jax_sm100` |
| `dense_indexer_backward_jax` | `dense_indexer_backward_jax_sm100` |
| `sparse_attention_forward_jax` | `sparse_attention_forward_jax_sm100` |
| `sparse_attention_backward_jax` | `sparse_attention_backward_jax_sm100` |
| `compressor_forward_jax` | `compressor_forward_jax_sm100` |
| `compressor_backward_jax` | `compressor_backward_jax_sm100` |

The `compressor_*` ops cover the ratio-4 CSA and ratio-128 HCA compressor.

## Changes from #1947
- Removed the exports from top-level `cudnn` and from `cudnn.csa` / `cudnn.deepseek_sparse_attention`. The ops are exported only from `cudnn.ops.dsa`.
- Each op raises a clear error on a GPU outside the SM100 family.
- `sparse_attention_backward_jax` checks the rank of `topk_indices`.
- `compressor_backward_jax` zero-fills only `grad_ape`, since the kernels write every `grad_kv` and `grad_score` element.
- Kept the lazy torch imports in the kernel modules, so the JAX ops run without PyTorch installed.
- Fixed the sparse-attention test: it called the op with the default `softmax_scale` (1/√512) but compared against an unscaled reference.
- Added tests:
  - top-k on rows whose length is not a multiple of the vector width (fp32 and bf16, under `jit`);
  - both indexer backwards against JAX autodiff;
  - a check that the caller's `attn_score` is unchanged after `indexer_backward_jax`, which updates an aliased copy in place.
- Tests skip when CuTeDSL is missing or the GPU is not SM100-family.
- Documented the JAX ops in `dsa.md` and `csa.md`.
