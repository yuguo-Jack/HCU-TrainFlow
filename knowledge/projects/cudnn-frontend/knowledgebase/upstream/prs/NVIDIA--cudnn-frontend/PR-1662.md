## Affected area

CI or test infrastructure.

## Summary

Make the SM107 backward SASS probe select the main kernel by its `.text` section symbol instead of assuming that it appears before the setup kernel. Count setup-section lines independently and report a clear error when the main section is missing.

## Why

Disassembly section order should not affect the test result. Selecting the intended section keeps setup instructions, unrelated kernels, and non-code sections out of the main-kernel instruction counts while preserving the existing register, spill, and drain assertions.
