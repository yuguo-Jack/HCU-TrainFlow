## Affected area

Python API or bindings

## Summary

Accept a contiguous flattened `[HO * K]` `dt_bias` in the public KDA safe-gate APIs, in addition to the native `[HO, K]` shape.

The public forward, forward-summary, and backward-summary entry points convert the flattened form to a metadata-only `[HO, K]` view before dispatch. Invalid lengths and non-contiguous flattened inputs are rejected before backend allocation or launch.

## Why

Megatron stores KDA `dt_bias` as a flat `[H * K]` parameter. Its non-safe gate path already reshapes that parameter, but direct cuDNN safe-gate and Kimi context-parallel summary calls previously exposed the backend-specific `[H, K]` requirement. Some backends happened to accept the flat pointer when `numel` matched, while shape-strict dispatch rejected it, so the behavior was not a stable API contract.

Normalizing once at the public cuDNN boundary keeps downstream integrations backend-independent, preserves the original parameter storage and gradient shape, and avoids a copy.

## Related issues

None.

## API and compatibility impact

Backward-compatible Python API extension:

- `kimi_delta_attention`
- `kimi_delta_attention_summary`
- `kimi_delta_attention_summary_bwd`

Each now accepts `dt_bias` as `[HO, K]` or contiguous `[HO * K]` when `safe_gate=True`. The flattened form is viewed without allocation; autograd still returns `[HO * K]` gradients to the caller. Kernel ABI, graph tensor shape, supported hardware, and existing matrix-form callers are unchanged.
