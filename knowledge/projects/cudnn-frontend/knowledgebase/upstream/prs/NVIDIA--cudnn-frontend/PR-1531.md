# sdpa: allow explicit D128 split-KV with scalar KV tails

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1531) · state: closed · merged: True

## Original PR description

A dense D128 graph with a mask-free KV extent off the 128-token tile currently rejects explicit split-KV, even though the native scalar-tail mask and split loop already compose. This admits that combination for SM100/SM103/SM107 FP16/BF16 and per-tensor FP8.

The shared predicate keeps engine admission and standalone validation aligned. Kernels, native execution, workspace binding and default selection are unchanged; no lengths tensor, staging, new knob or runtime host work is added. Existing CGA restrictions remain. Other dimensions, MXFP8, dense padding and sink combinations retain their current limits. This completes an explicit-support gap left after #1425 and #1520; automatic tuning is separate.

The existing native-launch regression now checks six bounded KV extents spanning tile boundaries, poisoned backing padding, changed-input capture/replay, O/LSE, half and quantized O, and FP8 Amax with nonunit scales. New metadata checks exercise admission boundaries rather than heuristic winners. The support matrix documents the domain.

Validation with cuDNN 9.27 and CuTe DSL 4.8:
- B300: 163 focused and adjacent split/metadata checks passed.
- SM107: all 16 scalar-tail GPU cases passed; the same 16 passed Compute Sanitizer memcheck with 0 errors.
- Baseline negative control: the public explicit split regression fails at the expected unsupported KV-tail combination on unmodified develop.
- B300 memcheck completed all 16 tests, but CUDA Python's 13.4.1 API probes against a 13.4.0 driver produced 14 API diagnostics. No device-memory diagnostic was reported; that run is not counted as a clean sanitizer pass.
- Changed-file formatting/license checks and `git diff --check` passed.

Default scalar-tail plans remain unsplit pending independent tuning. The existing Rubin per-tensor FP8 engine remains opt-in; this PR does not change that policy.
