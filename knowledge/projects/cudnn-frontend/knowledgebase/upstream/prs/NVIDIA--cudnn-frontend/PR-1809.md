# Prefer packed FROST for paged D128 full prefill

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1809) · state: closed · merged: True

## Original PR description

Paged D128 full and near-full prefill currently leaves the backend ahead of the existing packed, unsplit FROST candidate. This change lets that candidate lead in a bounded BF16 SM100 domain: THD paged KV with page size 16, batches 1–4, 16–64 query heads, GQA 4/8, Q lengths 512–8192, and Q ≤ KV ≤ 2Q under bottom-right causal masking. Windowed attention, sinks, widened right bands, and configurations rejected by the existing packing recommendation retain their current placement.

The change reuses the existing packing recommendation and candidates. It adds no engine, tuning knob, kernel, execution-path work, or caller API. Cheap geometry checks precede the packing helper to limit planning overhead outside the selected domain. FlashInfer auto admission is a separate follow-up.

Validation: the existing placement suite passes (284 tests), scoped pre-commit hooks pass, and dynamic length/page-table/pointer changes plus retained CUDA Graph captures were checked with output and LSE references. This is a placement change; it does not claim universal parity with other attention implementations or end-to-end serving gains.
