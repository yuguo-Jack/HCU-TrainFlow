# test(gemm): pin the SM100-only FROST GEMM tests to the SM100 tree

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2196) · state: open · merged: False

## Original PR description

## Problem

`cudnn.gemm.frost.compiler` re-exports the compiler of the active GPU's family. Fifteen GEMM tests check SM100 behavior through it, render SM100 configs, or size SM100 plans from the device's SMEM. On an SM12x GPU they meet the sm120 tree and fail. On an RTX 5090 at develop d760fefe that is 45 cases:

- `ImportError`: `_tma_store_sequence`, `_host_tma_c_descs` and `_TMA_STORE_EPI_PIPELINES` exist only in `sm100/compiler.py`.
- `AttributeError`: `_use_bulk_combine`, and `ConfigSm120` has no `cta_group` (the planner tests).
- SM100 assertions answered by the sm120 gates, for example `_use_tma_store_epi(sm100 config)` returning False, and `test_sm120_epi_vec_clamp_and_stg_only` checking its SM100 half through the active tree.
- SMEM sizing: `test_block_scale_resident_sf_tmem_budget` sizes SM100 block-scale plans against the 5090's SMEM ("no AB stage fits").

Without a GPU the active family is sm100, so these pass on a GPU-less host and on SM100 parts; they fail anywhere the sm120 tree is active.

## Change

Host-only checks now name the SM100 tree (`cudnn.gemm.frost.sm100.compiler`) instead of the active one:
- `test_narrow_n_under_two_cta_mma_still_takes_the_tma_store`
- `test_epi_smem_row_bytes_is_the_real_staging_alignment`
- `test_no_template_hardcodes_the_staging_alignment`
- `test_moe_tma_store_uses_rank2_output_descriptor` and `test_moe_block_scale_tma_store_uses_rank2_output_descriptor`
- `test_normal_two_cta_combine_uses_atomics`
- `test_sm120_epi_vec_clamp_and_stg_only` now asks each tree about its own configs (`C120` for the SM120 half, `C100` for the SM100 half).

Tests that launch SM100 kernels or size SM100 plans from the device get `@requires_sm100`:
- `test_tma_store_serves_every_drain_height` and `test_m_major_tma_store_serves_a_narrow_drain` (end-to-end SM100 launches).
- `test_block_scale_resident_sf_tmem_budget`.
- Five planner tests in `test_tile_select_analytic.py`.

## Tests

- RTX 5090 (cc 12.0), the fifteen tests: develop 45 failed / 45 passed; this change 23 passed, 67 skipped, 0 failed.
- B300 (cc 10.3), the same tests with this change under the default family: 90 passed.
- `pre-commit` on the touched files passes.
