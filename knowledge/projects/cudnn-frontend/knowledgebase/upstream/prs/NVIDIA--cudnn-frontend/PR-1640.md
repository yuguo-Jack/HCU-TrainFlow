## Summary

follow up https://github.com/NVIDIA/cudnn-frontend/pull/1523

nanobind's default optimization level `-Os` override `-O3` since cudnn_frontend is header only

https://nanobind.readthedocs.io/en/latest/api_cmake.html

> In non-debug modes, it compiles with size optimizations (i.e., -Os). This is generally the mode that you will want to use for C++/Python bindings. Switching to -O3 would enable further optimizations like vectorization, loop unrolling, etc., but these all increase compilation time and binary size with no real benefit for bindings.

## Why

<!-- What problem does this solve, and why is this approach appropriate? -->
Environment: Ubuntu 24.04 / WSL2, RTX 5070 Ti, CPython 3.12.14, GCC 13.3, CUDA 13.1, cuDNN 9.24. Binding versions: pybind11 2.13.6 and nanobind 3.0.1.

Compared pybind11 2.13.6 before migration with nanobind 3.0.1 after migration. The pybind11 Release build uses `-O3`; nanobind defaults to `-Os`. Adding `NOMINSIZE` preserves `-O3`. 
All timings are µs/call; lower is better. Both regular and Stable ABI extensions were benchmarked on the same CPython 3.12 runtime.

| Benchmark | pybind11 `-O3` | nanobind `-Os` | nanobind Stable ABI `-Os` | nanobind `NOMINSIZE` / `-O3` |
|---|---:|---:|---:|---:|
| Tensor repr | 1.7585 | 1.9326 | 1.9432 | 1.5181 |
| Graph repr / JSON export (8 ReLUs) | 90.7264 | 109.6786 | 112.5338 | 81.0789 |
| Graph JSON deserialization (8 ReLUs) | 88.1383 | 120.8963 | 116.9726 | 81.3099 |
| Native graph construction (8 tensors) | 10.3836 | 4.2678 | 4.8435 | 3.6014 |
| Graph construction + validation (8 ReLUs) | 61.4352 | 52.9148 | 53.3001 | 49.2164 |
| Graph construction + lowering (8 ReLUs) | 446.1304 | 411.7371 | 410.3211 | 400.7558 |
| Dense binding, cached pack | 0.6852 | 0.5384 | 0.6338 | 0.3300 |
| Dense binding, new pack | 4.8023 | 3.3342 | 3.8875 | 2.8897 |
| CUDA Graph replay, GPU time | 1.0550 | 1.0543 | 1.0590 | 1.0526 |

Note the wheel size is larger with `-O3`
| Artifact | pybind11 `-O3` | nanobind `-Os` | nanobind `NOMINSIZE` / `-O3` |
|---|---:|---:|---:|
| Compiled extension | 7.04 MiB | 2.92 MiB | 4.00 MiB |
| Compressed wheel | Not recorded | 8.99 MiB | 9.36 MiB |
