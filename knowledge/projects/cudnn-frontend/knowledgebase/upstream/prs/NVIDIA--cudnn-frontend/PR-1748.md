# Preserve head-major GDP K/V gradients for channel views

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1748) · state: open · merged: False

## Original PR description

Head-major GDP inputs already work, but backward returns update-major gradients that require copies to restore flattened projection channels. Return compact head-major dK/dV for these inputs so channel restoration is a view.

## Affected area

FE OSS kernels / CuTeDSL and the GDP Torch wrapper.

## Summary

- Select K and V destination layouts independently; real/fake allocation and graph-cache identity agree.
- Extend the existing TMA descriptor-family machinery to dK/dV stores in the V64/V128, checkpoint/warmup and chain paths, preserving commit/wait ordering.
- Write grouped-head reductions directly into the selected destination.
- Add `test_gdp_head_major_grads` to the existing test module and document the policy.

Nine runtime files: +350/−89; one existing test file: +124; one existing documentation file: +16. [File responsibilities and validation evidence](https://github.com/bmac3/cudnn-frontend/blob/c6e0e8c25a63fc5353a7de69f9bf01d98b25a4c9/validation.md).

## Why

Logical `[L,U,H,D]` inputs with head-major inner strides `(D,U*D,1)` now receive compact gradient strides `(H*U*D,D,U*D,1)`. Then `grad.transpose(1,2).view(L,H*U*D)` shares storage. Regular token padding is compacted.

## Related issues

Closes #1747.

## API and compatibility impact

Automatic layout selection; no argument changes. Expanded-row and update-major gradient behavior is preserved, including U1 and mixed K/V inputs. Q/decay/output/sequence timelines and beta packing are unchanged. This does not widen the existing FROST hardware support; new execution evidence is GB300 SM10.3/BF16 only.

The direct-store tradeoff is measurable: 2.73% longer head-major backward alone and 28.37% less time for backward plus channel restoration (geometric means of paired case ratios). Existing update-major backward changed by +0.05% and head-major forward by +0.01% (geometric means). The largest head-major backward median was +4.06% for normalized H28, with paired rounds ranging from +2.94% to +6.51%. This does not establish end-to-end training speedup. [Per-case timings and paired-round ranges](https://github.com/bmac3/cudnn-frontend/blob/c6e0e8c25a63fc5353a7de69f9bf01d98b25a4c9/summary.md).
