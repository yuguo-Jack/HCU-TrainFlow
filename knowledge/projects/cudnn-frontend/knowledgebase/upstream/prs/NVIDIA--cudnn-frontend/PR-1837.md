# docs: clarify the Windows ARM64 CuTeDSL dependency exception

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1837) · state: closed · merged: True

## Original PR description

The installation documentation says the base package includes the CuTeDSL runtime on every platform, but the existing platform markers in `pyproject.toml` exclude both `nvidia-cutlass-dsl` and `apache-tvm-ffi` on Windows ARM64.

Clarify this exception in the OSS overview, BSA, NSA, SM120 SDPA backward, linear-attention, and MoE EP documentation. The base install does not enable these CuTeDSL APIs on Windows ARM64. This addresses the remaining [documentation review comment on #1820](https://github.com/NVIDIA/cudnn-frontend/pull/1820#discussion_r4364649778), which merged while this follow-up was being prepared.

Validation: evaluated both existing dependency markers with `packaging` for Windows ARM64, Windows AMD64, Linux x86_64, and Linux aarch64; both are excluded only for Windows ARM64 in this matrix. `git diff --check` passed. Scoped pre-commit completed with all hooks skipped because the changes are Markdown only. No runtime or dependency metadata changes; GPU tests were not run for this documentation correction.
