## Affected area

FE OSS kernels / CuTeDSL: SM100 packed D128 split-KV SDPA.

## Summary

Packed split attention writes FP32 partials directly to its workspace, so its output no longer shares the Q staging slab. Enable the existing early-Q handoff for SM100 D128 FP16/BF16 ragged and paged split attention. Release Q after the last QK multiply and overlap the next Q load with the current output tail.

Enable the existing exp2/FMA softmax implementation for that same D128 packed-partial form. Both choices are fixed when the plan compiles.

## Why

The previous THD gate retained the staged-output handshake even though split attention bypasses the staging slab. The existing MMA-owned Q-empty handoff already protects Q reuse; the correction role releases O only after its TMEM reads complete. Scheduler credits and the empty-work protocol are preserved.

The exp2/FMA implementation moves part of softmax exponentiation off the MUFU pipe. Its existing sliding-window and quadrant-softmax exclusions remain. D192 was evaluated separately and is not enabled: its benefit was inconsistent and its extra compilation work was less attractive.

This is a warm kernel optimization. The polynomial softmax form can add cold compilation work; this PR does not claim a cold-plan or serving-throughput improvement.

## Related issues

Follow-up to the existing packed split-KV pipeline. Independent of #1715's combine prefetch; neither PR depends on the other.

## API and compatibility impact

No public API, tuning knob, capability, dependency floor, workspace size, native-binder work or per-run preparation is added. Unsplit THD keeps its staged output store. Dense paths and other architectures retain their existing choices. FP32 partial Stats and final O/LSE contracts are unchanged.
