[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2160) · state: closed · merged: True

## Original PR description

The SM80 `check_support` rejection test still expected D512 to fail after #2136 added the native 512/512 and 576/512 envelopes, making the CuTeDSL CI lane fail. Probe QK=640/V=512 and QK=576/V=576 to check the two unsupported boundaries independently; retain the dtype rejection check.

Validation: reproduced the stale D512 assertion; both updated boundary and dtype checks pass in a host metadata harness with CPU storage and mocked SM80 device queries. Repository pre-commit hooks pass. Native SM80 validation will run through `python/sdpa/misc` (which includes the CuTeDSL SM80 job).
