## Affected area

FE OSS kernels or CuTeDSL (FROST SDPA forward heuristics and placement).

## Summary

#1452 kept SM107 (Rubin) on the old nonpaged D128 THD split rule (unpacked CTAs, one wave, Q64) because Rubin had not been measured. This PR gives Rubin the SM100 rule: count packed / ragged CTAs, allow a two-wave budget, and use a Q8 floor. `blackwell_d128` is renamed `counted_d128` and covers cc 10.0-10.6 and 10.7.

## Why

Setup: gr100 board (cc 10.7, 216 SMs), cuDNN 9.27.0.42, CuTeDSL 4.8.0. I re-ran #1452's THD sets (`w`, `s`, `hold2`: 120 cases, BF16/FP16, fixed and bounded, Stats none/NH/HN). Each case timed the backend, unsplit FROST, and explicit splits 2-16 packed and unpacked. I scored each rule offline against the measured arms.

| Rule on Rubin | Leads | Mean regret | Leads slower than the backend |
|---|---|---|---|
| backend only | 0 | 294% | 0 |
| current (unpacked, one wave, Q64) | 36 | 199.5% | 0 |
| packed count, one wave, Q8 | 81 | 30.2% | 0 |
| **this PR: packed count, two waves, Q8 (SM100 rule)** | 99 | **10.6%** | 0 |

Measurement caveats:
- Another user's job shared the GPU for part of the session. The three other THD sets measured during those minutes were discarded; the 120 cases above are from minutes with no other process on the GPU.
- On this board the first-measured arm can read 40-85% slow, which biases these ratios against FROST.
- Not run: the final default pick on the device. The offline replay uses the same `(splits, pack)` the rule returns, and the explicit packed split arms passed the harness's FP64 O/LSE checks on Rubin.

## API and compatibility impact

The default plan order and `(SPLIT_KV, PACK_GQA)` change for SM107 nonpaged d128 half THD graphs inside the split domain. Explicit records behave as before.

## Testing

- `test_nonpaged_d128_rubin_split_fills_two_waves` replaces the Rubin one-wave test. It asserts Rubin's two-wave packed-CTA budget and the legality of the proposed knobs; it pins no winning split.
- Heuristics / placement / split-KV / analyzer host tests: 1633 passed, 2 skipped.
