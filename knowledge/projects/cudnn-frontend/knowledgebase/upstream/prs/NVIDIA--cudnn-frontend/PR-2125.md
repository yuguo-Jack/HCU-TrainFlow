# sdpa: add native SM107 half paged D192/V128 attention

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2125) · state: closed · merged: True

## Original PR description

SM107 half attention previously declined paged KV for D192/V128, including graphs with packed THD queries. Add a native paged D192/V128 specialization of the existing SM107 prefill body, with a separate factory that retains the nonpaged D192 boundary.

The new path supports dense and THD Q, independent HND/NHD K/V pools and physical origins, partial GQA packing, masks, sinks and optional Stats. It requires two CTAs and no split; unsupported combinations decline before compilation. Dense logical widths may use the D192/V128 envelope; THD retains exact native widths. Eligibility and the support matrix are updated together. Placement and candidate ranking are unchanged.

Validation:

- Four direct FP16/BF16 dense/THD kernel compilations.
- 12 admission and descriptor checks, including RED-to-GREEN coverage for preserving the nonpaged packing decline.
- 24 target-GPU FP16/BF16 graph tests pass: dense exact/envelope widths, THD independent origins, HND/NHD pools, partial packing, masks/sinks, optional natural/log2 Stats, empty rows, changed bindings/lengths and CUDA Graph replay.
- Two scoped Compute Sanitizer memcheck cases pass with zero errors (packed BF16 THD, mixed/HND pools and token/head Stats).
- Changed-file formatting, SPDX and whitespace checks pass.
