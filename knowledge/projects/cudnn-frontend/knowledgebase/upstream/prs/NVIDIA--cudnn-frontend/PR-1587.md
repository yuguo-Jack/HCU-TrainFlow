## Affected area

## Summary

Replace the text-only cuDNN overview with a landing page in the existing NVIDIA docs theme. Add Python/C++ setup tabs, operation links, and an interactive integration map. Place the Quick start, Samples, and Open-source kernels cards after Operations.

The map retains the prototype's All paths, Training, Inference, and Direct API filters. Selecting a framework or library highlights its route and shows a short explanation with a documentation link. Selecting it again resets the map. It covers PyTorch, JAX/XLA, Megatron Core, Transformer Engine, vLLM, SGLang, FlashInfer, TensorRT for RTX, and Tokamax.

Use the NVIDIA theme's colors and font in both light and dark mode. Scope the map's styles and events to a page-local MDX component; add no packages or shared theme changes. Keep keyboard controls, visible focus, live route descriptions, and a layout that fits mobile screens.

Reorder the sidebar to Overview, Samples, Release Notes, API Reference, Developer Guide, Installation, and Reference. List operations directly under API Reference, followed by For Agents (formerly Utilities) and the Experimental APIs dropdown (formerly Frontend OSS APIs). Keep Quick Start available from its page card and preserve every page URL.

## Why

Help readers choose an entry point and see how their framework connects to cuDNN while keeping the overview consistent with the rest of the documentation.

## API and compatibility impact

None. Changes are limited to `docs/index.mdx` and `docs/fern/versions/latest.yml`. Preserve the existing overview route and backend API guidance.
