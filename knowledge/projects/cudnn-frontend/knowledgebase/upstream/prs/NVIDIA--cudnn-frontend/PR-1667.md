## Affected area

CI or test infrastructure

## Summary

`test_block_fp4.py::test_workspace_layout_is_byte_identical_without_fp4` compares `dataclasses.asdict(layout)` against a frozen snapshot. ce0710d78 ("the e4m3 KV cache") appended five fields to the workspace layout: `kc8`, `vc8`, `kv_inv`, `kv_gathered` and `kv_len_t`. Each is `-1` unless `kv_cache_dtype` is e4m3. The snapshot was not updated, so the dicts differ only by those keys. This PR adds the five keys as `-1` to `_COMMON`. Every snapshotted offset stays the same, which is the invariant the test exists to freeze.

## Why

All 12 parametrizations fail on every `python/*/cutedsl` lane of develop schedule pipeline 74082381 (FE commit 149f1150d), e.g. job 489328317 (cutlass-4.7:sm80):

```
Left contains 5 more items:
{'kc8': -1, 'kv_gathered': -1, 'kv_inv': -1, 'kv_len_t': -1, 'vc8': -1}
```

The previous schedule (73793365, ae1c4d52a) did not have ce0710d78 and did not show this failure.
