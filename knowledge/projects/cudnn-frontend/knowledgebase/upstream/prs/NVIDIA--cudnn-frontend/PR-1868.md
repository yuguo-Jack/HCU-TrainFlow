# test(sdpa): align native fixtures with physical-origin host contracts

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1868) · state: closed · merged: True

## Original PR description

After #1866, several SDPA tests still assume the older host argument list or call a graph-lowered adapter as a standalone plan. Those tests fail before exercising their intended assertions.

This updates the shared frame fixture to accept unannotated runtime arguments, supplies every runtime slot to the packed combine entry, and constructs an independent public standalone API and workspace in the paged capture test. Existing numerical, workspace rejection, replay, and artifact reload assertions remain in place. The test guide records the ABI checks.

Only tests and their guide change. The original fixture failure was reproduced; the focused host checks and changed-file pre-commit checks pass.
