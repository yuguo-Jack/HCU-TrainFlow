# [SDPA] Add native SM80 wide-head forward coverage

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2136) · state: closed · merged: True

## Original PR description

SM80 forward attention currently declines head dimensions above 256. Add native 512/512 and 576/512 envelopes, including independently eight-aligned logical Q/K and V widths, through the existing FE graph contract.

The bounded 32-query, 16-key, four-warp body partitions V columns between two warps per query slab and retains Q in shared memory. Dense, THD and paged inputs use their declared strides and independent physical origins directly. Unsupported explicit tile geometry declines before compilation; backward coverage remains capped at 256/256.

Validation: 193 host admission/geometry/band checks and 76 A100 graph/native tests pass, covering both half types, logical widths, masks, sink/bias, empty lengths, O-only/Stats, independent pool/table layouts, rebinding and changed-length CUDA Graph replay. An earlier native prototype also passed 64 full-reference observations including legacy-width controls. Ten representative Compute Sanitizer memcheck cases pass with 0 errors; final source matches the checked snapshot. Scoped hooks pass. This change establishes functional coverage; no performance improvement is claimed.

Depends on #2133 and #2134 for paged/origin and single-query graph coverage, and #2135 for unread runtime-padding protection. Land those dependencies first. No heuristics or placement change.
