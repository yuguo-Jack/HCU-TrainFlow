# perf(sdpa): join masked maxima for packed paged D128

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2061) · state: closed · merged: True

## Original PR description

Packed paged BF16 D128 on SM100 currently reduces masked score chunks separately. Join them into one row-maximum tree for the existing M128/N128/CGA2, packed GQA>=4 schedule. On four paged variable-length cases, warm CUDA-graph replay improves 2.16% and 2.27% geometrically across two process orders; every measured case improves. The unmasked tree, sums, synchronization, workspace and public plan selection stay unchanged.

Validation of this head on a dedicated 76-SM SM100 GPU with CuTe DSL 4.8.0:

- 11 existing paged row-max and physical-origin tests pass; the row-max test now asserts the architecture/dtype/packing gate.
- The candidate, original and independently compiled unchanged control produce bitwise-identical complete O and Stats across 144 arm/phase observations, including fresh binding, capture, poisoned retained replay and changed inputs.
- Four BF16 D128 cases use B=2, sequence lengths [257,1535], page size 16 and Hq:Hkv of 16:4, 32:8, 64:8, 64:4. Baseline→candidate medians in the first order are 53.92→52.40, 76.85→74.77, 134.19→131.53, 132.52→131.05 microseconds. The candidate also beats the other measured original CGA1/CGA2 packed/unpacked plans; this is a bounded plan comparison, not a default-dispatch or serving claim.
- Original FP64 tolerances are preserved. One existing baseline O element exceeds the bound in the 64:4 case and is reproduced identically by all six old/new arms in both orders; the diagnostic keeps a nonzero exit. Its value is reproduced by the existing BF16 intermediate-probability rounding. The change introduces no parent/head discrepancy; Stats and changed-input checks pass.
- Disabled whole-module AST matches the parent; the enabled AST matches the measured prototype. Scoped pre-commit passes for both changed files.

No backend timing claim: the backend declines this exact overprovisioned page-table declaration. This PR does not change heuristics or the support matrix.

The patch is based on landed #2059. Current-develop composition checks are complete: all 288 plan/phase O and Stats results also match the prior qualification bitwise. The normal GPU CI pipeline is running.
