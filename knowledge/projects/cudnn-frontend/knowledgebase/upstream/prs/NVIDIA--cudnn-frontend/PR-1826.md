## Affected area

FE OSS kernels / CuTeDSL: GDN-2 steep-decay correctness and backward correction performance on `1.31.0-rc`.

## Summary

Backport #1816 at source head `17fd57b39cfd45681637c5802ea5fe3f9c284194` to `1.31.0-rc`.
The source PR is still open. This backport can receive review and validation in parallel.
I will update this PR if #1816 changes before merging. Please coordinate final integration with #1816.

The release branch does not contain the steep-decay correction from merged PR #1644.
The first commit therefore includes the existing v1.31 adaptation of that prerequisite fix.
Its source is `d313ebe67335c31e31c241822003c6ee3d5c1c28` in `alfred-pm/cudnn-frontend`.
The following six commits backport #1816 with original author attribution and cherry-pick references.

The correctness fix preserves steep per-channel gates through bounded exact replay, with caller-owned scratch and state snapshots.
The optimization reuses overlapping gate intervals during backward correction, rather than rebuilding each interval from zero.
It retains direct token-log accumulation, nonpositive exponents, and conditional dispatch.
Lower-triangle summation order changes, so bitwise equivalence to the previous algorithm is not claimed.
