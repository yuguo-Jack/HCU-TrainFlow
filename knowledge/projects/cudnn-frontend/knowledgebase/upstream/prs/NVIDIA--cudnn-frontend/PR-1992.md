# sdpa: balance the D64 CGA1 softmax tail sum

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1992) · state: closed · merged: True

## Original PR description

The SM100 BF16 D64 causal kernel sums the second softmax chunk through a long FP32 dependency chain. Use a balanced pairwise sum for that tail in the CGA1 schedule, after P publication. The first chunk retains its existing overlap with conversion/publication, and the helper's default preserves other callers.

On a local SM100 device with 68 SMs, three existing GPT-OSS-style 2k/8k cases reduce complete-attention CUDA-Graph replay time by 1.0–1.8% in both build orders (CGA1 geometric mean 1.3–1.4%). CGA2 controls remain within 0.1%. This is local kernel evidence, not a production B200 or serving result. The candidate retains a small 8-byte spill; the net gain is measured, not inferred from instruction count. No heuristics or placement changes.

Validation on the final two-file patch: 24 existing FP64 O/Stats/rebinding/replay tests; 36 full-attention arm/case/order combinations; 12 memcheck and 12 synccheck cases with zero errors; changed-file pre-commit and diff checks pass. The timed arms include a buildable cuDNN backend plan. An interrupted sanitizer attempt is excluded and the separate successful run is retained.
