## Affected area

FE OSS kernels or CuTeDSL

## Summary

SM90 sparse score recomputation executes producer and consumer warp groups in different control-flow branches, but their named rendezvous lower to aligned `bar.sync`. Synccheck reports divergent threads at the first rendezvous and terminates the instrumented launch. In the consumer, warps also reuse the first entries of the shared Top-K score array as cross-warp scratch before all warps have finished reading them; racecheck reports a write-after-read hazard and can observe incorrect output.

Use non-aligned CTA named barriers for warp-role rendezvous, and synchronize the consumer warp group before reusing the score array as scratch. Add synccheck regression coverage for both sparse attention and sparse indexer scores.

## Related work

Related to #2248: that PR removes a separate pre-existing `sWeights` initialization race. On develop, racecheck still reports that separate issue; the clean racecheck results below are measured with this change applied on top of #2248 head `768d4462`.

## API and compatibility impact

No public API changes. The change targets SM90. Both CUDA 12 and CUDA 13 CuTe DSL compiler flavors were tested; the CUDA 12 compiler runs used the existing CUDA 13 PyTorch/cuDNN runtime, not an end-to-end CUDA 12 deployment.

## Testing

- GH200 (SM90), cuDNN 9.27.0.42, PyTorch 2.14.0+cu130, CuTe DSL 4.8.1/cu13: `test_DSA_sparse_score_sync_sm90.py` on develop: 2 passed, 2 failed under synccheck; with this change: 4 passed.
- GH200 existing sparse-score boundary selection: 10 passed, 40 deselected.
- Cold-compile BF16 reference checks on SM90: 4 cases each on DSL 4.8.0/cu12, 4.8.0/cu13 and 4.8.1/cu12; 12 passed. DSL 4.8.1/cu13 is covered by the regression and existing tests.
- On #2248 head `768d4462` with this change, attention memcheck and synccheck report 0 errors; attention and indexer racecheck report 0 errors and warnings.
- Generated PTX: role-specific rendezvous change from `bar.sync` to `barrier.sync`; the unconditional CTA initialization barrier remains `bar.sync`.
- CUDA Graph replay outputs for both score paths matched the reference after 1,010 replays per shape.
- Changed-file pre-commit hooks and `git diff --check` passed.
