## Affected area

## Summary

Two test-only fixes. Each one turns every `python:dev` / `python:rel` lane on develop red on its own.

**1. Hopper KDA marshal: per-thread stream handle.** `test/python/linear_attention/hopper/test_hopper_marshal_stream.py` still expected the per-thread stream handle `2` to resolve to torch's default stream. Since #1182, `cudnn._torch_stream` rejects that handle on purpose. This PR drops `2` from the default-stream parametrization and adds `test_per_thread_stream_handle_is_rejected`, which asserts the `ValueError`. The test now matches `test/python/core/cutedsl/test_torch_stream_sentinels.py`. Only the test changes.

**2. Tier lists: #1502's `packed` parametrization.** #1502 added a `packed` axis to `gated_attention_block/cutedsl/test_quantize_mxfp8.py::test_compact_source_is_bit_exact_vs_oracle`, so its ids gained a `-dense` / `-packed` suffix. As a result, 18 cells in `tiers/nightly_only.txt` and 2 in `tiers/smoke_cc107.txt` no longer collected, and `test_tiers.py::test_every_listed_cell_collects[nightly_only.txt, smoke_cc107.txt]` failed. Each listed cell now uses its `-dense` id, which is the cell it named before. `nightly_only_reasons.tsv` and `smoke_cc107_code_paths.tsv` are updated to match. The new `-packed` cells stay in the default tier; whether any of them belong in `nightly_only` is up to the test owner.

## Why

**(1)** After #1182 merged (2026-10-09 17:29 UTC), `test_default_stream_handles_run_on_torch_default_stream[per_thread]` fails on every `python:dev` and `python:rel` lane with this error:

```
ValueError: cudaStreamPerThread (CUstream(2)) cannot be represented safely by torch stream interop; pass a concrete torch.cuda.Stream or its cuda_stream handle instead
```

It was the only failure in all six lanes of pipeline 72781706 (#1542, based on 8cab74c78, which includes #1182). For example, sm100 dev: 1 failed, 5800 passed. #1182's final CI did not run those lanes. The rejection is intended: handle 2 names a different stream in each host thread, so it is not the legacy default stream.

**(2)** Once (1) was fixed, pipeline 72799059 for this PR (head ea1e5814a, based on develop d75cd1741) showed the next red underneath it on all 6 lanes: `test_tiers` with 18 + 2 stale ids. That failure entered develop with #1502 (cf9558a9e).

## Related issues

Follow-up to #1182 and #1502. #1181 also edits the marshal test but does not touch the per-thread case.
