## Affected area

FE OSS kernels / CuTeDSL SDPA.

## Summary

Use lane zero as the stable K/V producer in the SM120 half-precision and MXFP8 prefill load helpers.

## Why

Repeated leader elections across successive K/V loads can expose optimization-sensitive divergent control flow on older PTX assemblers. These helpers are called by a complete producer warp, so a fixed live lane provides one issuer for both loads. Existing CTA barriers continue to gate pipeline reuse.

## Related issues

None.

## API and compatibility impact

No public API, dependency, architecture-admission, launch-geometry, or optimization-level changes. Transaction counts, TMA coordinates, scale copies, and barrier initialization are unchanged. The shared election primitive retains its existing semantics.
