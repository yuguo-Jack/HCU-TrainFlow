## Problem

`gemm/cutedsl/test_grouped_gemm_dglu_workspace.py::test_dglu_workspace_device_rejected_before_consumer[wrong_device]` fails on any host with one visible GPU:

```
Expected regex: 'workspace must be'
Actual message: 'cudnn: cuda:1 does not exist (1 device(s) visible)'
```

The test declares the workspace on ordinal `device + 1`, and its comment says this works "even on a single-GPU CI worker". On a single GPU that ordinal does not exist, and `python/cudnn/_device.py` rejects it before the workspace-device check. The call is still rejected before any launch; `seen` stays empty. Only the expected message is stale. CI is unaffected, because its workers see 4 GPUs.

## Change

Test-only. The test accepts either rejection (`workspace must be|does not exist`) and the comment now says why. The "no launch" assertion is unchanged.
