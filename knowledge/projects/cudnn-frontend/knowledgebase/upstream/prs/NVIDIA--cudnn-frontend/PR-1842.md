## Affected area

FE OSS kernels / CuTeDSL: shared SDPA backward dot helper.

## Summary

Group the pitched BF16 vector-load predicate into four short clauses. Preserve
all eleven checks, their order, and short-circuit behavior. Add the diagnosis
and validation procedure to the SDPA agent guide.

## Why

The predicate introduced in #1629 is a flat eleven-operand `and`. CuTeDSL 4.8's
Boolean rewrite reuses the preceding expression several times for each operand.
Recursive AST visitors consequently traverse the resulting graph exponentially:
the complete predicate requires 33,181,689 visits despite having only 348 unique
nodes. The grouped form requires 36,639 visits.

Cold backward artifact tests have been timing out inside
`ast.fix_missing_locations`, reached from this helper's preprocessing before
GPU execution. Short clauses remove this expansion without dropping the safety
checks that enable vector loads. Tests retain their existing deadlines.

## Related issues

Follow-up to #1629. The child-stack diagnostics added in #1840 identified the
preprocessing stage. Two separate CI child exits with `-11` remain unexplained;
this PR does not claim they are fixed before changed-source CI verifies them.

## API and compatibility impact

None. No eligibility, public API, launch geometry, arithmetic, or execute-time
binding changes. This addresses cold compilation; no GPU or serving speedup is
claimed.

## Testing

- Whole-file AST equivalence after flattening associative Boolean clauses;
  operand order is preserved. Actual public DSL 4.8 preprocessing reproduces
  the expansion and its reduction.
- B200, Torch 2.14 / CUDA 13.0, cuDNN 9.27, public CuTeDSL 4.8.0: all 16 original
  artifact-child executions passed (one unchanged baseline cold/reload pair
  and seven candidate pairs: D256 FP16/BF16, SM100 dense FP16/BF16, 2x2 BF16,
  staged FP16/BF16). The original child programs retain their 300-second
  limits, gradient references, fresh-pointer checks and poisoned capture replay.
  Fresh matching native bindings and the actual loaded sources were verified.
- `python -m pytest -m 'L0 or L1' sdpa/frost/test_sdpa_bwd_dot_strides.py`: **37 passed, zero skips**. This covers physical alignment/stride variants, full CPU FP64 references, canaries, pointer rebinding, changed-input capture and aligned/misaligned lowerings for SM100/103/107/110/120.
- `pre-commit run --files python/cudnn/sdpa/bwd/kernels/bprop_chain_common.py python/cudnn/sdpa/AGENTS.md`: passed.

Local x86 B200 qualification is distinct from the ARM64/debug-cuDNN CI lanes.

Local harness issues were kept separate: one unsupported pytest launcher option
failed before collection; the successful run later hit a temporary-symlink
artifact-copy error. Its complete XML/log and source receipts were verified,
and the container/allocation cleanup was confirmed. No numerical failure was
retried or waived.
