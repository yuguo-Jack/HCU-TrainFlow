# Honor independent physical origins in nonpaged D192 split attention

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2157) · state: closed · merged: True

## Original PR description

Nonpaged D192/V128 THD split plans did not bind independent physical offsets, and the native binder rejected that contract. This change wires the existing per-sequence input maps and physical-output combine into the FP16/BF16 single-CTA split route on SM100/SM103/SM107. FP32 partials remain compact; older native extensions decline with a rebuild message.

Depends on #2155 and its parent #2153. Existing split capacity, mask, packing, sink and padded-Stats restrictions remain. Candidate ranking and placement are unchanged.

Validation: 342 native-binder checks and three extension-version controls pass. SM100 and SM107 each pass 20 origin/replay cases, covering split2/split9, both input precisions, both packed Stats layouts, independent offsets/strides, poisoned gaps, changed inputs, keyless rows and empty retained-capture replay. Two cases per architecture pass each of memcheck, racecheck and synccheck with zero errors. The old binder rejects the six new D192 frames, and the parent graph probe reproduces missing origin binding before execution. Both selected CI entrypoints collect the new coverage. Formatting and diff checks pass.
