# Fix CUDA graph topology sample on Windows and H100

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1741) · state: closed · merged: True

## Original PR description

## Summary

Fix two CI failures in the CUDA graph topology sample:

- Use `fe::get_environment` for `CUDNN186_LOG`, avoiding MSVC C4996 under `/WX`.
- Count only top-level frontend nodes in the SDPA alibi eligibility check and its log. Recursive counts include backend child-graph memsets and can fail `memsets == 0` even when the frontend adds no memset. Keep the checks for one frontend copy, no frontend memset, and one backend child graph.
