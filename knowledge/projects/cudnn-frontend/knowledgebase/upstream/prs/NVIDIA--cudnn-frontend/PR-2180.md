# gemm(frost sm100): decline a block-scale K that ends inside a scale block

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/2180) · state: closed · merged: True

## Original PR description

## Problem

#2008 (B01) declined this on SM120. The SM100 block-scale templates size the F8_128x4 scale-factor view the same way, from `floor(K / block_size)` scales per row. The SM100 prechecks never compare K with the block size; only the 16-byte TMA rule gates it.

So an MXFP8 graph whose K ends inside a 32-element scale block still plans on SM100. On a B300 (cc 10.3), with all scales set to 1:
- M = N = 256, K = 144: 51870 of 65536 outputs are wrong.
- K = 130, with M-major A and N-major B: 23341 of 65536 outputs are wrong.
- K = 160, whole blocks: correct.

The partial last block's scales read as zero, and rows past the first 128-row block read another block's scales.

## Change

- `sm100/compiler.py`:
  - New `_check_whole_scale_blocks(chain)` reuses the shared `_partial_scale_block_reject`, the same helper the SM120 tree uses.
  - It runs in `_precheck_block_scale`. It also runs in `_precheck_moe_block_scale` ahead of `mma_arch_reject`, whose GATHER token-SF check would otherwise name a `floor(K / block_size)` shape.
  - `_validate_whole_scale_blocks = True` on `CompiledFusedGemm` and `CompiledMoeBlockScaleGemm`. A plan built at a whole-block K then refuses a call whose K ends inside a block, before it writes anything.
- The four SM120 tests become helpers that SM120 and SM100 both run, each with its own config. The tests are the dense graph-declined and call-refused tests, and their MoE counterparts. SM100 uses `CONFIG_sm100_128x128x128_128x128x32_cluster1x1_1ctamma`.

## Tests

On a B300 (cc 10.3):
- The new SM100 tests on develop: 9 failed. The graphs plan, and the K = 144 call writes its output.
- With this change: 9 passed (SM100), 9 skipped (SM120).
- `test_block_scale_matmul.py` and `test_moe_grouped_block_scale_matmul_fwd.py`, `-m "L0 or L1"`: 1074 passed, 350 skipped, 0 failed.
- `pre-commit` on the touched files passes.
