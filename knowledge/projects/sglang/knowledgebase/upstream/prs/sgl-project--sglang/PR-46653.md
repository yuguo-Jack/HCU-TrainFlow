# [Perf] [AMD] Kimi-K3: static FP8 dense layers and tuned decode GEMMs

[Upstream PR](https://github.com/sgl-project/sglang/pull/46653) · state: open · merged: False

## Original PR description

## Motivation

K3's dense layers run bf16, or dynamic-FP8 with per-step activation scaling.

## Modifications

- `SGLANG_K3_TARGET_DENSE_FP8` (default `off`) loads static-input-scale FP8 dense weights.
- `SGLANG_DRAFT_FP8_ACTIVATION_SCHEME` does the same for the DFlash draft.
- Decode GEMMs dispatch to the K3 tables added in ROCm/aiter#6959.

## Accuracy Tests

`test_fp8_online_static_input.py` passes.

Full K3 stack on MI355X TP8 (DFlash, prod config) vs B300, McNemar:
- GPQA-D 89.4 vs 87.9 (p=0.55)
- AIME25 96.7 vs 93.3 (p=1.0)
- MATH500 92.2 vs 92.2 (p=1.0)
- MMLU-Pro 89.6 vs 90.0 (p=0.77)
- GSM8K 97.2%

## Speed Tests and Profiling

Not measured on its own. It is included in the full-stack K3 MI355X numbers in the other K3 PRs.

## Dependencies

- Stacked on #46652 (shared `kimi_k3.py` edits). Only the last commit is new here.
- ROCm/aiter#6959.
