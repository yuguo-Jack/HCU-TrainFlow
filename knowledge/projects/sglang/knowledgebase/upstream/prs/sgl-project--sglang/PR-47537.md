# [Fix] rust-server: Give the mixed-logprob frame test's payload flat output ids with row offsets

[Upstream PR](https://github.com/sgl-project/sglang/pull/47537) · state: closed · merged: True

## Original PR description

## Motivation

`test_mixed_logprob_batch_frame` has failed `base-a-test-cpu` on main since #47106 merged ([report](https://github.com/sgl-project/sglang/pull/47106#issuecomment-6534080230), e.g. [this job](https://github.com/sgl-project/sglang/actions/runs/41126892409/job/124315366100)):

```
File "python/sglang/srt/rust_server/server.py", line 580, in push_generation
    offsets = payload.output_ids_offsets
AttributeError: 'types.SimpleNamespace' object has no attribute 'output_ids_offsets'
```

#47415 made `RustServer.push_generation` read each step's output ids as `output_ids_flat` plus `output_ids_offsets`. #47106 added this test on an older base, with the per-row `output_ids` list. Each PR passed CI on its own base; the conflict only shows on main.

## Modifications

Build the test's payload with `output_ids_flat` / `output_ids_offsets` for the same rows (`[7, 8]`, `[9]`, `[5]`, `[]`), in the literal form #47415 used for the other payloads in this file. The test's assertions are unchanged.
