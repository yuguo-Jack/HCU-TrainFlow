# [Feat][CPU] Add prefill torch compile graph and dynamic graph support

[Upstream PR](https://github.com/sgl-project/sglang/pull/44394) · state: open · merged: False

## Original PR description

## Motivation

Ported from the internal implementation.

Add CPU torch.compile graph support for both prefill and decode on Intel AMX systems, including static bucket graphs and optional dynamic-shape fallback graphs.

The implementation supports:

- Static prefill graphs using total-token buckets.
- Optional dynamic fallback graphs through `SGLANG_TORCH_DYNAMIC_SHAPE=true`.
- Exact buckets first, padded buckets second, and dynamic fallback last.

CPU prefill graphs are experimental and remain disabled by default; they must be explicitly enabled with the `full` backend.

## Modifications

- Extend `CPUGraphRunner` with CPU prefill graph capture and replay.
- Add static and dynamic graph support for both decode and prefill.
- Add prefill padding and hidden-state trimming.
- Define CPU decode configuration precedence:
  `decode.bs` > `decode.max_bs` > `--torch-compile-max-bs`.
- Generate prefill buckets from `prefill.max_bs` when needed.
- Reject unsupported CPU graph backends such as `breakable` and `tc_piecewise`.
- Add a stable prefill forward dispatcher to avoid unnecessary recompilation.
- Make layer-boundary objects compatible with TorchDynamo during CPU graph capture and replay.
- Fix graph breaks, runtime recompiles, and `InternalTorchDynamoError` failures related to `msgspec.Struct` objects and
  Python-side CPU capability checks.
- Update required CPU custom-op schemas, fake registrations, rotary embedding handling, and related kernels.
- Update CPU graph documentation and tests.

## Tests

- Restore and adapt the CPU graph unit tests to the current `arg_groups` configuration API.
- Cover backend gating, bucket generation, option precedence, padding, dispatcher stability, dynamic fallback, and encoder-decoder decode graph reuse.
- Reuse the existing real-model benchmark and MMLU test while enabling explicit CPU prefill graphs and dynamic-shape fallback.
- Verify graph and eager accuracy and graph execution without graph breaks or runtime recompiles.
