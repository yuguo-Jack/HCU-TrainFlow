# [elastic ep] live serving during scale

[Upstream PR](https://github.com/sgl-project/sglang/pull/45560) · state: open · merged: False

## Original PR description

# Support live serving and decode graph reuse during elastic EP scale-up


# This pr is based on scale down pr and will be open when it merged.

## Summary

Elastic EP scale-up pauses serving while connecting joining ranks and preparing the expanded topology. This PR allows existing ranks to serve during preparation and adds decode CUDA graph reuse for scale-up. Final admission and topology activation remain synchronous.

## Changes

- Prepare NIXL connections in a background worker, keeping joining peers inactive until admission.
- Coordinate readiness across scheduler ranks before admitting the complete joining cohort into Mooncake.
- With graph reuse enabled, capture locally on joiners while existing ranks retain their decode graphs. Preserve graph-referenced routing buffers, counters, and model storage across growth.
- Without graph reuse, interleave eager serving with individual graph captures.
- Preserve synchronous recovery and coordinate preparation failures and timeouts across ranks.

## Preliminary performance: DeepSeek-V3 FP8, EP32 → EP40

Five H100 80GB nodes: four original nodes plus one joining node. Mooncake PG, NIXL EP.

### Interruption during scale

Continuity workload: 128 long streams pinned to the original ranks, plus 8 short requests/s.

| Metric | Synchronous | Live + graph reuse |
|---|---:|---:|
| POST scale → reported ready | 51.08 s | 24.37 s |
| Down time (Longest global token-output gap during scale) | 36.21 s | **1.37 s** |
| Pre-scale output throughput | 920 tokens/s | 907 tokens/s |
| Output throughput during during scale | 9.5 tokens/s | 806 tokens/s |

The longest scale-window output gap fell by approximately **96%**. 

### Post-scale capacity

| Concurrent streams | Synchronous | Live + graph reuse | Fresh static EP40 |
|---|---:|---:|---:|
| 128 | 2,994 | 3,061 | 3,000 |
| 512 | 14,058 | 15,399 | 13,928 |


## Configuration and scope

Enable uniformly across original ranks and joiners, including recovery joiners:

```bash
export SGLANG_ELASTIC_LIVE_SCALE=split
```

For scale-up graph reuse, also pass:

```bash
--elastic-ep-reuse-cuda-graph
--max-ep-size <maximum-supported-size>
```
