# [AMD] DeepSeek-V4.1: TP4 A8W4 MoE rows in AITER (pointer)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42501) · state: closed · merged: False

## Original PR description

A draft AITER PR, ROCm/aiter#6363, proposes the E385/top-7 A8W4 MoE rows used by DeepSeek-V4.1-Flash at TP4 with the fused shared expert. It is not ready: the rows at M 64, 256 and 512 require the stage-1 race fix in ROCm/aiter#6170, and the 16k serving result remains unexplained. In our serving tests the rows gave no TTFT gain at 8k, 60k and 128k prompts. No SGLang code change is needed: after the AITER rows are merged and included in an image, SGLang selects them through its existing lookup. This SGLang draft is a pointer only.
