# Reuse Hugging Face LFM2-MoE configuration

[Upstream PR](https://github.com/sgl-project/sglang/pull/43939) · state: closed · merged: True

## Original PR description

Use Hugging Face's `Lfm2MoeConfig`, retaining SGLang's hybrid-cache properties, as already done for dense LFM2. This removes the duplicated constructor.

Current main pins Transformers 5.19.0, which already removed the `conv` remapping. This migration also fixes config loading with Transformers 5.17.0.

Before this change, unpatched SGLang `488869c2d0` with Transformers 5.17.0 fails on B300:
```bash
python -m sglang.launch_server --model-path LiquidAI/LFM2-24B-A2B --max-mamba-cache-size 16
```
```text
    all_mamba_layers = config.mamba2_cache_params.layers
AttributeError: 'NoneType' object has no attribute 'layers'
```

Tested on `LiquidAI/LFM2-24B-A2B` with CUDA graph capture. Outputs matched the layer-override baseline.
