# [Fix] sgl-router: Keep the kv-indexer connection through bursts of cancelled prefix queries

[Upstream PR](https://github.com/sgl-project/sglang/pull/45100) · state: closed · merged: True

## Original PR description

## Motivation

A router cancels every prefix query it stops waiting for. Under load, a burst of such cancellations against a busy kv-indexer exceeds h2's default limit of 20 pending-accept reset streams. h2 then tears down the connection, and every query in flight on it fails with `UNKNOWN`. The client reported `UNKNOWN` as a contract rejection, so the router failed those requests instead of falling back to load-based routing.

## Modifications

- Indexer server: raise the pending-accept reset-stream limit to 4096.
- Client: classify `UNKNOWN` (a torn-down connection) as `Unreachable`.
