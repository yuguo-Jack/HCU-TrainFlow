# [Test] pd: Cover Mooncake cancellation through KV page reuse

[Upstream PR](https://github.com/sgl-project/sglang/pull/45210) · state: closed · merged: False

## Original PR description

## Motivation

Closes #45209. Related to #43699. Connect the existing deferred-release checks to actual byte writes and destination-page reuse in CPU CI.

## Modifications

Add five tests using the production Mooncake worker, descriptor builder, ABORT/ACK handlers and decode release queue. CPU buffers, queued control messages and event-gated SDK calls cover completed/in-flight cancellation, two-rank drain, duplicate/stale ACKs and the device timeout fallback. Check transferred bytes, untouched guards, single release and subsequent page reuse. Registered in `base-a-test-cpu`; no production changes.

## Accuracy Tests

- Seven related suites: **171 passed, 129 subtests passed**.
- New suite repeated **100 times in one process: 500 passes**, no surviving worker threads or CUDA initialization.
- Three temporary production-method mutations—early ACK, accepting one rank, ignoring generation—each fail the intended test with an assertion, not an incidental exception.
- Direct CI entrypoint (`python test_file.py -f`), registry validation and scoped formatting/lint checks pass.

## Speed Tests and Profiling

No inference performance claim. The five tests take about 0.02s after imports locally; no GPU, RDMA or model download is needed. Real transport completion semantics remain outside this CPU test.
