# [Fix] [NPU] scope: fix dtype error in sampling backend ascend

[Upstream PR](https://github.com/sgl-project/sglang/pull/39609) · state: open · merged: False

## Original PR description

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

`torch_npu.npu_top_k_top_p` requires same `dtype` for `logits` and `top_p`. Currently for models like CosyVoice3 from SGLang-Omni it produced error as `logits` come in `blfloat16` while `top_p` in `float32`.

## Modifications

`top_p` casted to `logits.dtype`. Make calculation in original dtype

## Speed Tests and Profiling

Enabling `--tts_engine.engine.sampling-backend ascend` gives `5%` speed up for CosyVoice3
