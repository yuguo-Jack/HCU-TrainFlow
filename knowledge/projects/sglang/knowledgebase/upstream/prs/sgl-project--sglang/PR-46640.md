# [Fix] utils: Fix CPU engine detection under torch.compile fullgraph

[Upstream PR](https://github.com/sgl-project/sglang/pull/46640) · state: closed · merged: True

## Original PR description

## Motivation

`is_cpu()` calls `is_host_cpu_x86()` / `is_host_cpu_arm64()` before it reads
`SGLANG_USE_CPU_ENGINE`. Those probe `torch.cpu.is_available()`. When `is_cpu()`
is called from a `torch.compile(fullgraph=True)` region, Dynamo unwraps the
`lru_cache` wrapper and tries to trace the probe, which fails with
`torch.* op returned non-Tensor` even when the CPU engine is not requested.

Same class of issue as #41065 (`is_musa()`).

## Modifications

- Return `False` from `is_cpu()` before the host-CPU probes when
`SGLANG_USE_CPU_ENGINE` is not `1`.
- The result is unchanged in every case; the probes now run only when the CPU
engine is requested.
