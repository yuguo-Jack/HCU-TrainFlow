# [CI][Ascend] Fix plog persistence and add debug-only nightly perf suite for DeepSeek-V4-Flash

[Upstream PR](https://github.com/sgl-project/sglang/pull/37386) · state: closed · merged: False

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

On Ascend NPU CI runners, Ascend SDK logs (plog) are redirected via `ASCEND_WORK_PATH`, but the per-case plog backup logic hardcoded `/root/ascend/log/debug/plog`, so plog files were not persisted — making post-failure diagnosis of nightly perf cases impossible. Additionally, debugging a single nightly perf case currently requires the whole nightly suite to run. This PR closes the plog persistence loop (backup inside the test -> artifact upload) and enables isolated single-case debug execution in the nightly pipeline, following the same pattern as the qwen3_235b debug case in PR #37241.

## Modifications

<!-- Detail the changes made in this pull request. -->

1. `python/sglang/test/ascend/e2e/test_npu_performance_utils.py` (`_backup_plog`):
   - Resolve the plog source path dynamically: prefer `$ASCEND_WORK_PATH/debug/plog`, fall back to `/root/ascend/log/debug/plog`; warn with the full candidate list when neither exists.
   - Support recursive copy: `shutil.copytree(..., dirs_exist_ok=True)` for directories in addition to the existing per-file `copy2`, so plog subdirectories are no longer silently skipped.

2. `.github/workflows/_npu-single-node-test-stage.yml`:
   - Export `PLOG_UPLOAD_DIR=/root/.cache/tests/logs/plog/{branch_label}-{create_time}-{run_id}-{run_attempt}` in the `Run test` step (nightly-only block), mirroring the `_backup_plog` `plog_base` layout.
   - Add an `Upload plog artifacts` step guarded by `always() && inputs.is_nightly_pipeline_job && env.PLOG_UPLOAD_DIR != ''` with 7-day retention, so plog is available as a GitHub artifact even when tests fail.

3. `.github/workflows/nightly-test-npu.yml`:
   - Temporarily disable all existing nightly jobs with `if: ${{ false }}` (job definitions kept intact for easy restore).
   - Convert `nightly-perf-16-npu-a3` into `debug-nightly-perf-16-npu-a3` (same runner/config), and update `needs` and the `check-all-jobs` summary references accordingly.

4. `test/registered/npu/performance/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_in8k_out1k_50ms.py` and `test_npu_deepseek_v4_flash_w8a8_8p_in32k_out1k_50ms.py`:
   - Register the additional `debug-nightly-perf-16-npu-a3` suite (the AST-parsed `register_npu_ci` marker supports multiple registrations per file), so `run_suite.py --suite debug-nightly-perf-16-npu-a3` selects exactly these two cases.
   - Lower `--mem-fraction-static` from 0.7 to 0.65 to leave headroom against NPU OOM during debugging.
