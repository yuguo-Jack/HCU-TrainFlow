## Motivation

Unified allocation and sliding-window retirement repeatedly queried stable geometry and launched avoidable copies, mapping lookups, and tombstone writes in the scheduler path.

## Modifications

The bind kernels reuse compiled code when consuming an odd number of int64 free-list entries changes pointer alignment. A GPU test verifies both mappings and JIT-cache reuse; the prefix-view comment states its lifetime contract.

- Snapshot allocator geometry once for each capacity query.
- Retain consumed free-list views instead of copying lists that are rebound rather than modified in place.
- Fuse FLOAT-sub-pool unbinding and skip signal-only invariant tensor work when invariant detection is disabled.
- Keep enabled invariant checks and add coverage for capacity, ownership, deferred frees, and absence of host synchronization.
