# [Refactor] memory-pool: Build DSA indexer host pools from buffer info

[Upstream PR](https://github.com/sgl-project/sglang/pull/45019) · state: open · merged: False

## Original PR description

## Motivation

Followup of #40917. The DSA indexer host pool was described through `HostPoolDecl` and a builder that re-read the device pool to recover the index layers, page layout and packed draft depth. The DSA pool now exports an `IndexKeyBufferInfo` through `get_device_pool_infos()`, and the assembler builds the indexer host pool and its sidecar entries from that info. `HostPoolDecl`, `host_pool_decls()` and the DSA builder are removed. The completeness check now compares the assembled host pools with the device pool infos instead of the declarations.

Index page format, host capacity and layer mapping are unchanged.

## Accuracy

HiCache multi-turn KL with forced host hits against #40917, same commands on both sides. Assembled host pools and the H2D transfer sequence are identical to the parent on every rank.

- GLM-5.2, tp 4, EAGLE: DSA KV and indexer host pools with the packed draft, host hit counts equal, KL within 1.5x of the parent's.
- Qwen3.8-Flash-Next, tp 4, NEXTN: hybrid Mamba with the QSA indexer, 3 runs per side, decode-hit KL identical, prefill-hit KL within the parent's range.
- Qwen3.8-27B NEXTN and Qwen3 with a STANDALONE draft: equal to the parent.
