# [Fix] Render LLAMA2 message roles and separators from stored roles

[Upstream PR](https://github.com/sgl-project/sglang/pull/43266) · state: open · merged: False

## Original PR description

## Motivation

LLAMA2-style templates derive message tags and separators from index parity. Two consecutive user messages therefore label the second one as an assistant and end the generation prompt with `[INST]` instead of `[/INST]`.

Fixes #43155.

## Modifications

Use each message's stored role for its tag and turn separator. Preserve the existing first-user prefix handling, and render a leading assistant message with its assistant tag. Add regressions for consecutive users across the `llama-2`, `mistral`, and `devstral` templates, consecutive assistants, and an assistant-first history. Pin the complete alternating-history prompt to preserve its existing output.
