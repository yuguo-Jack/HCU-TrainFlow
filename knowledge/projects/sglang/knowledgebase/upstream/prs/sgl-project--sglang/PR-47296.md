# [Fix] [AMD] diffusion: detect ROCm through torch when amdsmi is unavailable

[Upstream PR](https://github.com/sgl-project/sglang/pull/47296) · state: open · merged: False

## Original PR description

## Motivation

`rocm_platform_plugin()` in `multimodal_gen` decides ROCm vs. CPU only through amdsmi's Python bindings. Those bindings are optional, and the `rocm/pytorch` images ship without them. In that setup the exception is logged at debug level and platform resolution falls through to `CpuPlatform` on a machine with a working ROCm GPU. Nothing warns about it; the first CPU-only op then fails, for example:

```
'_OpNamespace' 'sgl_kernel' object has no attribute 'fused_norm_scale_shift_cpu'
```

The SRT side does not have this problem because it detects ROCm through `torch.version.hip`. The same silent fallback was reported in #35317, which also covered gfx1250 plumbing; that PR was closed as a stale draft. This PR is only the detection fix.

## Modifications

- `multimodal_gen/runtime/platforms/__init__.py`: when amdsmi is missing or fails, fall back to `torch.version.hip is not None and torch.cuda.is_available()`. If amdsmi works, it is still used first, so environments that have it behave as before.
- `test_platform_detection.py`: add a CPU unit test with amdsmi made unimportable. The test covers HIP with a GPU (ROCm), HIP without a GPU (None) and a non-HIP torch (None).

## Accuracy / validation

All runs used the `rocm/pytorch` ROCm 7.2.3 image, which has no amdsmi, with `Wan-AI/Wan2.1-T2V-1.3B-Diffusers`, 17 frames at 832x480 and 10 steps. Hardware: RDNA4 (gfx1201). The base is main plus #43679 (sgl-kernel build on gfx1201), #47254 (RDNA attention default) and a local guard that makes the quark aiter imports optional (same change as #40863).

| | Result |
|---|---|
| base | The platform resolves to CPU; generation fails with the `fused_norm_scale_shift_cpu` error above |
| + this PR | The platform resolves to ROCm. Generation then fails in the default attention backend selection because aiter is not installed, which is what #45937 addresses for RDNA |
| + this PR + #45937 | The video is generated. `torch_sdpa` attention; denoise 1.22 s/step |

New unit test: `python/sglang/multimodal_gen/test/unit/test_platform_detection.py` fails without the fix (the HIP-with-GPU case returns `None`) and passes with it (14 passed, 21 subtests).

With amdsmi missing, CDNA images now get ROCm instead of CPU. Nothing changes when amdsmi is present.
