# [Test] [AMD] deterministic: Add a TP4 deterministic inference test on MI35x

[Upstream PR](https://github.com/sgl-project/sglang/pull/43999) · state: open · merged: False

## Original PR description

## Motivation

This PR adds a multi-GPU deterministic inference test to AMD CI on MI35x. Today the deterministic test runs only at TP1, so nothing in CI covers the deterministic all-reduce, and multi-GPU regressions in deterministic mode go unnoticed. It follows up the review of #43788, which asked for multi-GPU coverage.

The test runs at TP4, where the all-reduce matters most: at two ranks every all-reduce implementation is batch-invariant, while at four or more the RCCL, two-stage and AITER all-reduces are not. The existing test is not enough when simply run on more GPUs: with its 10 trials it can pass without #34543, the fix for all-reduce inputs larger than the custom all-reduce buffer. With 50 trials the prefix log-probability check catches that bug.


## Modifications

- `test/registered/attention/test_deterministic_tp4.py`: Qwen3-8B, TP4, Triton attention, `--enable-deterministic-inference`. One check: `prefix` mode with `--return-logprob` and 50 trials.
- Registered on `stage-c-test-large-8-gpu-amd-mi35x`. There is no 4-GPU MI35x suite. About 3-4 minutes on 4 GPUs.
- The TP1 test (`test_deterministic.py`) is kept: it is shared with CUDA and XPU, runs per PR on MI300, and also covers `single` mode.
- No code change.
