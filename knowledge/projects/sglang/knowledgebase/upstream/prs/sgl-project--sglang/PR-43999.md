# [Test] [AMD] deterministic: Add a TP2 deterministic inference test on MI35x

[Upstream PR](https://github.com/sgl-project/sglang/pull/43999) · state: open · merged: False

## Original PR description

## Motivation

This PR adds a TP2 deterministic inference test to AMD CI on MI35x. Today the deterministic test runs only at TP1, so nothing in CI covers the deterministic all-reduce, and multi-GPU regressions in deterministic mode go unnoticed. It follows up the review of #43788, which asked for multi-GPU coverage.

The existing test is not enough when simply run at TP2. With its 10 trials it passes on MI350X even without #34543, the fix for all-reduce inputs larger than the custom all-reduce buffer. With 50 trials the prefix log-probability check fails without that fix and passes with it.

## Modifications

- `test/registered/attention/test_deterministic_tp2.py`: Qwen3-8B, TP2, Triton attention, `--enable-deterministic-inference`. One check: `prefix` mode with `--return-logprob` and 50 trials.
- Registered on `stage-c-test-large-8-gpu-amd-mi35x`. There is no 2-GPU MI35x suite. About 5 minutes on 2 GPUs.
- No code change.

## Accuracy Tests

MI350X, `rocm/sgl-dev:v0.5.21-rocm724-mi35x-20261012`, AMD CI environment (`SGLANG_USE_AITER=1`, `SGLANG_IS_IN_CI_AMD=1`), with #43788 applied in every run:

| | Result | Time |
| --- | --- | --- |
| With #34543 | OK in 10 of 10 runs | 242-314 s |
| Without #34543 | fails in 2 of 2 runs (server out of memory / log-probabilities differ) | 419-518 s |
| Existing 10-trial test at TP2, without #34543 | passes (does not catch it) | 180 s |
