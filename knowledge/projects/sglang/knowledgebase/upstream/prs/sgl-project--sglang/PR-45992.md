## Motivation

KDA’s chunked prefill path currently materializes contiguous Q/K/V tensors and normalizes Q and K through separate operations. For strided QKV inputs, this introduces redundant intermediate memory traffic and multiple kernel launches.
This PR combines QKV materialization and Q/K L2 normalization into one Triton kernel, reducing preparation overhead while preserving the existing numerical behavior.
## Modifications

- Add a fused Triton kernel that reads strided Q/K/V directly, applies Q/K L2 normalization, and produces contiguous Q/K/V outputs.
- Preserve the reference FP32 reduction, normalization, and BF16 output conversion.
- Add an opt-in path controlled by SGLANG_KDA_FUSED_QKV_PACK=1, disabled by default.
- Restrict the fused path to supported CUDA BF16 layouts with batch dimension 1 and head dimension 128. Unsupported configurations retain the existing implementation.
- Keep the optimization independent of CP and MoE optimizations.
- Add regression tests for output equivalence, CUDA Graph replay, KDA state updates, and fallback behavior.

## Accuracy Tests

9 GPU regression tests passed on NVIDIA H200
Coverage includes:
- Bitwise equivalence against the separate preparation operations for sequence lengths 1, 65, 4237, and 32768.
- CUDA Graph replay correctness after updating inputs.
- Full KDA output, SSM state, and tracked-state equivalence for single- and multi-sequence inputs.
- Fallback behavior for unsupported layouts, including head dimension 64.
```bash
python -m pytest -q \
  test/registered/kernels/ops/attention/test_kda_qkv_pack.py
```
This validation covers operator and KDA integration correctness; no model-level accuracy evaluation was performed for this PR.
