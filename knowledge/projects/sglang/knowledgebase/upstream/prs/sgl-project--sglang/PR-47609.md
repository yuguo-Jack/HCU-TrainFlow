# [Test] dsv41: Check the balanced paged decode indexer against the per-row kernel on randomized inputs

[Upstream PR](https://github.com/sgl-project/sglang/pull/47609) · state: closed · merged: False

## Original PR description

## Motivation

Follow-up to #47387: broaden the numerical parity inputs of the balanced paged decode indexer test, as suggested in its review.

## Modifications

Add `test_fp4_paged_logits_balanced_matches_per_row_random`. Inputs: Gaussian queries and head weights, random FP4 payload bytes covering every e2m1 code, e8m0 exponents mostly in the typical range plus ~1% at the extremes (0, 1, 126-128, 200, 254), shuffled pages, and ragged lengths including 0, 1, tile edges and past `max_len`. It runs 3 seeds × 32 / 64 heads × (ratio 1, ratio 2 with a candidate mask), and the balanced kernel must match the per-row kernel bit for bit.

## Accuracy Tests

Test-only change. All 12 cases pass on H200. Each case compares ~340K visible scores, with thousands of distinct finite values and some infinities from the extreme scales.
