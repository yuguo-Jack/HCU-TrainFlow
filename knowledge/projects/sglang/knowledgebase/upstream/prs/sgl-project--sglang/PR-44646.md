# [Doc] diffusion: Align PR title conventions

[Upstream PR](https://github.com/sgl-project/sglang/pull/44646) · state: closed · merged: True

## Original PR description

## Motivation

The Diffusion contribution guide still requires the legacy `[diffusion] <scope>: <subject>` format, which conflicts with the repository-wide PR-title check.

## Changes

- Document the existing `[Type] [Hardware] scope: title` convention in the general contribution guide, with the hardware tag optional.
- Replace the Diffusion-specific convention with `diffusion` and `diffusion/<submodule-or-model>` scope examples, including `[Perf] diffusion/scheduler: Reduce scheduling overhead`.
- Distinguish PR titles from development commit messages and preserve the old `#commit-message-convention` anchor.

Documentation only; no runtime or CI behavior changes.
