# [CI] Fix TestQwenImageModulationCache after Qwen-Image modulation sharding

[Upstream PR](https://github.com/sgl-project/sglang/pull/43747) · state: closed · merged: True

## Original PR description

[by Claude Code]

## Motivation

Fixes #43746.

#43691 added `self._shard_modulation` to `QwenImageTransformerBlock.__init__`, and made `_get_modulation_params()` read it unconditionally. `TestQwenImageModulationCache._block()` in `test/registered/kernels/ops/diffusion/test_model_fast_paths.py` builds the block with `__new__` and skips `__init__`. So all four tests in the class fail with `AttributeError: 'QwenImageTransformerBlock' object has no attribute '_shard_modulation'`. That fails `jit-kernel-unit-test-1-gpu-large` in `PR Test Base`, for example in [this job](https://github.com/sgl-project/sglang/actions/runs/38193715150/job/114634289012) on #43104.

## Modifications

- In the test helper `_block()`, set `block._shard_modulation = False`. This is the replicated, non-TP layout that the single-GPU `_CountingProjection` stubs model, and it matches the behavior from before #43691. This is a one-line, test-only change.
