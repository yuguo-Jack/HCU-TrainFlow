# [Refactor] memory-pool: Rename index key format to layout

[Upstream PR](https://github.com/sgl-project/sglang/pull/47705) · state: closed · merged: True

## Original PR description

## Motivation

`IndexKeyFormat.DSA_FP8` names the index key buffer after the model instead of its memory arrangement. This PR renames the enum to `IndexKeyLayout` to match `KVBufferLayout` and `KVScaleLayout`, renames `IndexKeyBufferInfo.key_format` to `key_layout`, and renames `DSA_FP8` to `PAGED_FP8_KEYS_WITH_SCALES`, which says that each buffer row is one page of fp8 keys followed by their fp32 scales. #40916 adds the `KEY_ROWS` layout next to it.

No behavior change.
