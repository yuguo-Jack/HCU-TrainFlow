# [diffusion] Deduplicate UniPC solvers and Gemma3 shard loading

[Upstream PR](https://github.com/sgl-project/sglang/pull/42899) · state: closed · merged: True

## Original PR description

## Summary

- Share UniPC state and sample transforms between the flow and regular schedulers.
- Share the bh coefficient recurrence and predictor history/order updates across regular UniPC, flow UniPC, and Helios.
- Keep correction, step indexing, tensor assembly, and return wrapping in each scheduler. Preserve the original model output for external solver-p calls.
- Reuse Gemma3 shard-ID normalization without changing checkpoint mappings or loader retry order.

Production code is reduced by 318 lines; including focused regression tests, the total diff removes 196 lines. No new configuration or user-facing API is introduced.

## Coverage

- CPU/CUDA, FP32/FP64/FP16/BF16, bh1/bh2, solver orders, prediction types, state reset, and repeated requests.
- Complete scheduler trajectories against the original implementations, including matching existing nonfinite and rejected configurations.
- Native small-model Helios flat, pyramid, and DMD denoising with original versus refactored schedulers, CFG, history inputs, and repeated requests.
- Distinct missing-timestep behavior, external solver-p argument identity, lower-order warmup, and dynamic thresholding.
- Gemma3 string/integer shard-ID fallback and error propagation.

This is code deduplication, not an algorithm change or performance claim. Small-model coverage is not a full-checkpoint image/video E2E benchmark. Main has been merged to include the existing Kandinsky BCG test fix.
