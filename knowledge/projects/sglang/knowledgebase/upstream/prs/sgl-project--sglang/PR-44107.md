# [Fix] glm47: Bound tool argument pairs

[Upstream PR](https://github.com/sgl-project/sglang/pull/44107) · state: open · merged: False

## Original PR description

## Motivation

For complete tool schemas, the non-strict GLM47 grammar allows known argument keys to repeat without a bound. If the model emits an unknown key, it can keep generating repeated known keys until the output limit.

## Modifications

Limit argument pairs in each call to the number of keys in a complete schema. Keys remain optional and can appear in any order; duplicates are still allowed within the limit. Incomplete or free-form schemas retain the existing rule. The parser keeps the last value for a repeated key.

## Accuracy Tests

Focused grammar regressions and scoped formatting pass on the updated branch, including bounded, open and empty schemas. Earlier direct XGrammar and llguidance checks accepted optional and reordered keys and rejected excess pairs. The limit applies within one call, so the model can still start another call. The looping requests have not been replayed with a live model.

Run the unit suites with `python -m pytest` and formatting with `pre-commit run --files <changed-files>`.

## Speed Tests and Profiling

CPU measurements with the GLM-4.7-Flash tokenizer showed similar grammar compilation and per-token mask times across both runs. The interquartile ranges overlap, and the measurements cover grammar work only.

**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Cap arguments for complete zero-key schemas**

When a no-argument tool declares `{"properties": {}, "additionalProperties": false}`, `_glm_has_complete_properties()` regards it as complete but `all_props` is empty, so this new bounded rule is skipped and the fallback `(...)*` still accepts arbitrary repeated argument pairs. Such GLM47 calls can therefore still run to `max_tokens`, precisely the production loop this change is meant to prevent; distinguish a complete empty schema from an unresolved/free-form schema and emit zero argument pairs.
