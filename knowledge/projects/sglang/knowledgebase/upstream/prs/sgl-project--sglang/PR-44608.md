# [Feat] rust-server: add direct scheduler ingress (PoC)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44608) · state: open · merged: False

## Original PR description

## Motivation

[Proof of concept]

External frontends can own templating and tokenization and only need to inject pre-tokenized requests into the scheduler and get output tokens back. The current embedded Rust server routes these requests through the full frontend. The gRPC handler converts the request and pushes it straight onto the scheduler ring. The scheduler is unchanged.

```
GenerateTokens → from_generate_tokens → DirectIngress::submit
  (vocab check → normalize → register with detok shard → encode → push to ring) → scheduler
responses: existing detok shard → stream; cancel: abort on drop
```

## Accuracy Tests

None yet. It has not been run against a live server. The next step is to compare `GenerateTokens` and `Generate` token ids for the same prompt with `SGLANG_RUST_SERVER=1`.
