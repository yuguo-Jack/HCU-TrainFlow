## Motivation

Fix two incompatibilities between unified cache and DeepSeek V4:
1. Current runs have revealed the need to check unaligned truncation boundaries, so as to prevent the end of the previous interval from overlapping the start of the following interval.
2. For the DeepSeek V4 NPU platform, independent C128 cache management is used. When performing alignment truncation, the C128 alignment length (128*14=2048) must be taken into account. The floor_cache_len in the component is invoked in the unified cache.

## Modifications

1. Add a new floor_cache_len interface to the component and invoke it in the unified cache.
2. boundary checks; if the boundaries overlap, merge them into a single interval.
