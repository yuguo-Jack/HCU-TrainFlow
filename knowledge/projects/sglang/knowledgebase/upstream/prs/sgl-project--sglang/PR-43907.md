# [PD] Decode a copy of the running rows and drop finished rows at commit

[Upstream PR](https://github.com/sgl-project/sglang/pull/43907) · state: open · merged: False

## Original PR description

Stacks on #43906

- The PD decode normal and overlap loops launch a copy of the running rows and join a copy of the prebuilt batch.
- Finished rows leave at the commit that finishes them; the loop-top leave before preallocation is gone.

Behavior change (PD decode): `/v1/loads` running count, the running and LoRA gauges, and internal state drop finished rows at commit. Preallocation, the LoRA gate, budgets, idle, abort, and pause are unchanged.
