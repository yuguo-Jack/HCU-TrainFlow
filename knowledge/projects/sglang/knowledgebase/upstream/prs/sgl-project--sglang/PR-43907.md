# [Refactor] scheduler: Share one interface across request lists and abort through each list

[Upstream PR](https://github.com/sgl-project/sglang/pull/43907) · state: closed · merged: True

## Original PR description

Every list that holds live requests now shares one interface, `RequestList`, and each list's abort lives on the list.

- `scheduler_components/request_list.py`: `RequestList` is an abstract class (iteration, `join`, `leave`, `take`, `clear`, `abort`), and `ListKind` names each list. `_RequestList` is the shared implementation: requests in join order, held by identity. `move(reqs, src, dst)` hands requests from one list to another and raises if one is not in `src`.
- `running_reqs`, `prefill_launched_reqs`, the grammar queue, the PD prefill bootstrap and transfer queues, the PD decode retracted and held lists, and the dLLM waiting queue are `_RequestList`s, changed only through `join`, `leave`, `take`, `clear` and `move`. The PD prefill transfer queue always exists, empty outside PD prefill, instead of being `None`.
- `request_lists()` is keyed by `ListKind`; `is_fully_idle` and the request-list invariant check read kinds.
- `abort_request` calls each list's `abort`. The waiting queue, the chunked request, the PD decode prealloc and transfer queues, and requests in flight keep their own abort code.
- List owners build and release aborts through shared entry points: `_make_abort_req` moves to `managers/utils.py` as `make_abort_req`, `Scheduler._release_aborted_request` becomes `release_aborted_request`, and `AbortReq.matches(rid)` replaces the `abort_all or rid.startswith(...)` test repeated at each abort site.
- A unit test checks that every field of a list owner annotated as holding requests is a `RequestList`, apart from an allowlist of the fields not migrated yet.

Behavior changes:
- One abort handles the lists in `request_lists()` order, so the outputs of different requests can be sent in a different order.
- Requeueing an optimistic PD prefill request raises if the request is not in the list it leaves; before, that was ignored.
