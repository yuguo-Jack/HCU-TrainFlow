# [CI] nightly: Disable the MiniMax-M3.1-Flash H200 test while it times out

[Upstream PR](https://github.com/sgl-project/sglang/pull/47789) · state: closed · merged: True

## Original PR description

## Motivation

`test/registered/e2e/models_large/test_minimax_m31_flash_h200.py`, added in #46627, has timed out on every nightly run since:

- [Oct 31](https://github.com/sgl-project/sglang/actions/runs/41208487121/job/124558454967): `✗ TIMEOUT … after 2760.0 seconds`
- [Nov 1](https://github.com/sgl-project/sglang/actions/runs/41314397568/job/124871376759): `✗ TIMEOUT … after 2760.0 seconds`

In both runs most of the time went to fetching `MiniMaxAI/MiniMax-M3.1-Flash` weights before the server started, and the test was killed shortly after shard loading finished. Each timeout also fails `nightly-test-8-gpu-h200`, which hides the results of the other files in that job.

## Modifications

Set `disabled=` on the file's `register_cuda_ci` call. `run_suite.py` skips disabled registrations, so the test stays in the tree and can still be run directly. Remove the `disabled=` argument to re-enable it once the timeout is understood.
