# [Fix] hunyuan: Escape control characters in tool-call streams

[Upstream PR](https://github.com/sgl-project/sglang/pull/42206) · state: open · merged: False

## Original PR description

## Motivation

Fixes #42139. Hunyuan streaming tool calls containing control characters such as `\^_` emit invalid JSON and can corrupt subsequent argument deltas.

## Modifications

Use the same JSON string escaping for partial values as for completed arguments. Add regression coverage for all 32 control characters, quotes, backslashes and Unicode across single-character, seven-character and whole-response chunks.

## Accuracy Tests

Rebased onto `9fa9308e95`, which contains the required base `ff8d964cf5`. On this source, 45 Hunyuan tests and 105 subtests pass on CPU; the control-character streaming subcases fail with the unmodified main production code.

`pre-commit run --all-files` passes, including the Rust formatting and Clippy checks.

These are feature-specific CPU serialization tests; model-forward and kernel code are unchanged.
