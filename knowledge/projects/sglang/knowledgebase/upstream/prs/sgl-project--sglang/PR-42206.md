# [Fix] Escape control characters in Hunyuan tool-call streams

[Upstream PR](https://github.com/sgl-project/sglang/pull/42206) · state: open · merged: False

## Original PR description

## Motivation

Fixes #42139. Hunyuan streaming tool calls containing control characters such as `\^_` emit invalid JSON and can corrupt subsequent argument deltas.

## Modifications

Use the same JSON string escaping for partial values as for completed arguments. Add regression coverage for all 32 control characters, quotes, backslashes and Unicode across single-character, seven-character and whole-response chunks.

## Accuracy Tests

Rebased onto `933668131`, including the current required base `60878c3f`. On the unmodified base, the regression fails in 60 control-character/chunking subcases. With the fix, all 627 function-call unit tests pass, including 1731 subtests, and all 45 Hunyuan tests pass through the registered test entry point. These are CPU parser tests using Python 3.12.13, PyTorch 2.13.0, Transformers 5.15.0, and xgrammar 0.2.7.

## Speed Tests and Profiling

No model execution or kernel changes.
