# [Fix] DSv4.1: Fix BCG image handling and add multimodal bounded replay coverage

[Upstream PR](https://github.com/sgl-project/sglang/pull/44131) · state: closed · merged: True

## Original PR description

[codex/claude generated]

## Motivation

DeepSeek-V4.1 multimodal prefill can produce incorrect results with breakable CUDA graphs (BCG). The eager model wrapper remaps image hash placeholders to model token IDs, but the captured transformer body kept reading the original IDs. Its Engram image-row mask was also omitted when capture used a dummy batch without multimodal inputs.

On four GB300 GPUs, the same 200 MMMU-Pro questions scored 76.5% with TP4+EP4 and 68.0% with BCG before this fix. BCG scored 78.0% after the fix; BCG with decoder bounded replay scored 78.5%.

## Modifications

- Refresh the captured body's static input IDs from the eager wrapper's prepared IDs, preserving the scheduler's original cache-key IDs.
- Capture the DeepSeek-V4.1 Engram image-token mask independently of dummy-batch multimodal metadata.
- Add CPU regressions for prepared image IDs and image-row Engram masking; both reproduce failures before the fix.
- Replace MMLU with MMMU-Pro in the existing GB300 TP4+EP4 and DP4+EP4 DSPARK tests, and add TP4+EP4 with decoder SWA bounded replay inside BCG. Keep GSM8K and speculative acceptance checks in all three configurations.
- Use sgl-eval 0.1.3 with the V4.1 preset. MMMU-Pro uses 200 examples, a 32768-token output cap, and a 0.75 threshold; GSM8K retains its 0.95 threshold.

## Accuracy Tests

Local validation on four GB300 GPUs, using the same 200 MMMU-Pro questions, DSPARK block size 5, 64 client threads, 32 maximum running requests, memory fraction 0.7, and 8192-token prefill chunks:

| Configuration | MMMU-Pro accuracy | Truncation rate |
| --- | --- | --- |
| TP4+EP4, BCG disabled | 76.5% (153/200) | 4.0% |
| TP4+EP4 + BCG, before fix | 68.0% (136/200) | 6.0% |
| TP4+EP4 + BCG, after fix | 78.0% (156/200) | 4.5% |
| TP4+EP4 + BCG + decoder bounded replay, after fix | 78.5% (157/200) | 3.5% |

All four evaluations completed with zero request errors. Each is one run at temperature 1.0, top-p 0.95, without a fixed sampling seed; these measurements are not a deterministic equivalence proof. Encoder bounded replay was disabled throughout. The first three configurations also disabled decoder bounded replay.
