# [CP] Support GLM-5.3-Flash colocated prefill CP and decode attention TP with DFlash2/MTP

[Upstream PR](https://github.com/sgl-project/sglang/pull/43972) · state: open · merged: False

## Original PR description

## Motivation

Stacked on #43182 (base branch `codex/glm53-cp-prefill-bcg`). This PR adds colocated **GLM-5.3-Flash prefill attention CP + decode/target-verify attention TP**, with native MTP and DFlash2 support.

Publishing as a draft for review: full accuracy acceptance and the performance matrix are not complete. The targeted accuracy results below are not a claim of equivalence or a fix for a historical accuracy regression.

## Modifications

- Enable the shared decode-attention-TP context for GLM5Next and its native MTP architecture. Apply cached attention-head shards to DSA decode/target verification only; KDA and MoE retain their existing TP placement.
- Keep shared-group DFlash draft construction, execution, and KV-pool allocation in a TP-only attention context, without inheriting the target's prefill CP or decode weight-slicing policy. Most placement logic remains in `cp_decode_attn_tp.py`.
- Preserve the MN-major, TMA-aligned layout of packed UE8M0 FP8 scale shards and cache the slices for stable graph pointers.
- Gather draft auxiliary hidden states into global sequence order and remove CP/capture padding on the prefill graph path.
- Preserve KDA host checkpoint metadata in the static forward batch during prefill graph replay.
- Extend the existing CP4 + native-MTP test with decode attention TP; add unit coverage for placement/restoration, scale layouts, DSA/KDA dispatch, draft features, and graph checkpoint metadata.
- Document usage in the GLM-5.3-Flash cookbook. No manual benchmark scripts, tensor dumps, or diagnostic runtime patches are included.

### Usage

For four GPUs, add these options to the existing GLM-5.3-Flash launch command:

```bash
--tp-size 4 \
--attn-cp-size 4 \
--enable-prefill-cp \
--cp-strategy interleave \
--enable-cp-decode-attn-tp
```

For DFlash2:

```bash
--speculative-algorithm DFLASH \
--speculative-draft-model-path incoai/GLM-5.3-Flash-DFlash2 \
--speculative-draft-attention-backend fa4
```

The target's DSA prefill uses CP, while its decode/target verification and the DFlash draft use attention TP over the colocated group. This change does not add a language-only restriction. All new experiments reported here use four GPUs; TP8 is not used as the accuracy baseline.

## Accuracy Tests

### Targeted AIME26 question 14 replication

Candidate: `ccaebb79069c213e30187d4700471b78686eaff8`. Hardware: 4×B200. Both configurations enable DFlash2/fa4, thinking, `temperature=1`, `top_p=1`, and `max_tokens=300000`. Each configuration runs seeds 0–31 in two waves of 16 requests, with no diagnostic patches or score-based early stopping.

| Configuration | Correct | Accuracy | Normal stops | Truncated |
|---|---:|---:|---:|---:|
| Prefill CP4 + Decode TP4 + DFlash2 | 21/32 | 65.625% | 32 | 0 |
| TP4 + DFlash2 | 19/32 | 59.375% | 32 | 0 |

This experiment did not reproduce a lower CP score. It is **one question sampled 32 times per configuration**, not 32 full AIME runs. The sample is too small to establish equivalence; matching API seeds do not strictly pair DFlash's internal random trajectories. All 64 raw responses were retained and their downloaded SHA256 hashes verified.

### Diagnostic checks (isolated instrumentation, not production changes)

- In the measured short, long, and mixed-request cases, DFlash draft tokens, selector probabilities, target outputs, and acceptance outputs agreed across ranks.
- For 281/288-token prefixes, holding CP prefill fixed while switching decode attention to TP preserved prefill logits, all 33 saved KDA prefill states on all four ranks, and the first draft tokens exactly. Graph on/off also produced identical first-verify logits within each configuration.
- First-DSA-layer logical-order MLA cache bytes and causal token selections matched; decode weight/scale slices and layouts matched native TP4. The measured projection difference was largely reproduced by rounding each TP partial to BF16 before summation.
- Separately, repeated long-prefill experiments isolated shared kpool top-k order/cutoff-tie nondeterminism in both TP4 and CP4. The stable-sort reference used for diagnosis is **not** part of this PR.

These checks bound observed numerical differences; they do not prove the cause of a historical AIME score gap or correctness for every input.
