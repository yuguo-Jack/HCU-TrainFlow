# [Feat] kernels: Add out-of-tree dispatch for causal Conv1D

[Upstream PR](https://github.com/sgl-project/sglang/pull/38751) · state: open · merged: False

## Original PR description

## Motivation

Out-of-tree platforms need a supported causal Conv1D extension point without replacing module globals at runtime.

## Modifications

- Wrap the existing variable-length Triton implementation in `BaseFusedOp`.
- Preserve the public `causal_conv1d_fn` signature and existing `mamba.causal_conv1d_fn` registry key.
- Keep Triton as the only built-in implementation while allowing out-of-tree platforms to register their own forward method.
- Add focused coverage for out-of-tree dispatch.

This PR does not add a Torch reference backend: `forward_native` intentionally raises `NotImplementedError`, and the new test covers only out-of-tree dispatch.

## Accuracy Tests

The existing numerical tests are unchanged. The added test verifies that an out-of-tree implementation is selected through `BaseFusedOp`.

## Speed Tests and Profiling

The Triton kernel is unchanged. Dispatch is resolved once and cached by `BaseFusedOp`.
