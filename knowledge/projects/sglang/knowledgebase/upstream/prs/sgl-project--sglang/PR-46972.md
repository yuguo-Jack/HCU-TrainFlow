## Motivation

Combining int8 Mamba checkpoints with unified memory accepted a flag that had no effect because unified pools do not allocate an int8 checkpoint pool.

## Changes

Reject the unsupported flag combination during argument validation with an actionable error. Add coverage for the rejected combination and for unified memory alone.

## Validation

At `ec405b2dac`, the two flag-compatibility cases changed from **1 failed / 1 passed** to **2 passed**; the complete server-argument suite passed **320 tests**. Later CPU review checked all four flag combinations and rejected only the unsupported combination.

Server startup and checkpoint loading were not tested for this fix.
