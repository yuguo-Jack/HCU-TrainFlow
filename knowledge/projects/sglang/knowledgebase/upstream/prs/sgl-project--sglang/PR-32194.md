# [Spec][DSV4] perf: Skip unused draft metadata

[Upstream PR](https://github.com/sgl-project/sglang/pull/32194) · state: closed · merged: False

## Original PR description

## Motivation

DSV4 NextN/DSpark draft attention is SWA-only (`compress_ratio=0`), but draft decode still built unused C4/C128 compression metadata. CUDA graph capture also prepared metadata for the terminal speculative step even though only `num_steps - 1` draft forwards execute.

## Modifications

- Build only SWA/C1 metadata for DSV4 draft decode in eager and CUDA graph paths, while preserving the target C4/C128 path.
- Prepare multi-step draft metadata only for executed forwards.
- Add focused metadata-contract and production EAGLE CUDA graph regression coverage.
