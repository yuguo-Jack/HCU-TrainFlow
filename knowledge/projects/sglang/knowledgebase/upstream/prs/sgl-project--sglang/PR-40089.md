# [sgl-router] Policy reorg 6/N: per-bucket policy in config and --selection-engine

[Upstream PR](https://github.com/sgl-project/sglang/pull/40089) · state: closed · merged: False

## Original PR description

Stacked on the 5/N cache PR. Additive config surface; no runtime change.

## Modifications

- `BucketSpec.policy: Option<PolicyKind>` (serde default): the policy attached to a bucket; the model policy when omitted. `PolicyKind` gains `Deserialize` with the same snake_case spellings as `--policy`. Buckets cannot attach `fused_score` / `score_policy`.
- `--selection-engine legacy|reorg` (default `legacy`) on `RoutingArgs`. It is read by `main.rs` only, not stored in `Config`, so no config literal changes; it is removed with the legacy path.
- The two resolver options the design sketches (`affinity_first`, disabling advance-on-rejection) are deferred: their defaults reproduce today's behavior and nothing sets them yet.
