## AITER prerequisites

- [ROCm/aiter#6266](https://github.com/ROCm/aiter/pull/6266) — per-tensor FP8 descales on FlyDSL varlen FMHA, the route that uses FlyDSL only where it beats CK, and the single-split MLA fill skip.

`flydsl_flash_attn_varlen_func` on AITER main already accepts `q_descale` (merged as ROCm/aiter#5326). #6266 is the draft the measured prefill build adds on top of that.

## Motivation

Kimi-K3 MLA prefill at TP8 has 12 heads, QK dim 192 and V dim 128. On gfx950 it runs the BF16 varlen kernel. AITER's FlyDSL FP8 FMHA supports this shape. The prefix-prefill path also writes BF16 K and V and then scans them again to quantize.

## Modifications

- Run MLA prefill on the FlyDSL FP8 FMHA when the head shape is supported. Q, K and V are quantized per tensor.
- Keep upstream's PS metadata and its asm/Gluon selection for MLA decode and target verify.
- Add `SGLANG_ENABLE_AITER_MLA_FLYDSL_FP8_PREFILL_REQUIRED` to fail instead of falling back, for benchmark runs.
- For an MXFP4 `kv_b_proj` on prefix prefill, fuse the projection, K/V split, RoPE concat and FP8 cast (opt-in).
- Keep the ROCm fused prefix KV projection in `forward_mha_rocm.py`; `forward_mha.py` calls it only under `_is_hip`, and its CUDA path is unchanged.

| New env flag | Default |
|---|---|
| `SGLANG_ENABLE_AITER_MLA_FLYDSL_FP8_PREFILL` | **on** |
| `SGLANG_ENABLE_AITER_MLA_FLYDSL_FP8_PREFILL_REQUIRED` | off |
| `SGLANG_ENABLE_AITER_MLA_FLYDSL_FUSED_KV_PROJ` | off |
| `SGLANG_ENABLE_AITER_MLA_ZERO_PAD_FP8_PREFILL` | off |

`SGLANG_ENABLE_AITER_MLA_FLYDSL_FP8_PREFILL` is on by default. It changes MLA prefill on gfx950 for any model whose head shape the FlyDSL kernel supports, not only Kimi-K3. Set it to 0 to keep the BF16 kernel.

The previous `SGLANG_AITER_MLA_*` names remain deprecated aliases.

Shared (non-K3) files: `aiter_backend.py`, `forward_mha.py`, `forward_mha_rocm.py`.
