## Motivation

Strix Halo/gfx1151 uses different wave-size and kernel assumptions from AMD CDNA GPUs. Qwen3.5 AWQ MoE can run through ROCm Triton, but previously used the heuristic MoE config because no Radeon 8060S profile was available.

This follows the community Strix Halo recipe in [`docs/RUNNING_AWQ_MOE.md`](https://github.com/JeremiahM37/strix-halo-sglang/blob/main/docs/RUNNING_AWQ_MOE.md) and upstreams the reproducible config/tuning pieces into SGLang.

## Modifications

- Fix packed W4A16 `N` config filename generation.
- Add Radeon 8060S/gfx1151 up/down Triton MoE configs.
- Add sequential single-GPU tuning with `--no-ray`.
- Fix the W4A16 `BLOCK_SIZE_K` compatibility filter.
- Document the Strix Halo tuning recipe.

## Accuracy Tests

The Qwen3.5 AWQ checkpoint loaded successfully on Radeon 8060S/gfx1151, both tuned configs were selected, `/health` returned HTTP 200, and a minimal chat request returned `TUNED_OK`. No model weights or forward math were changed; a full accuracy suite was not run.

## Speed Tests and Profiling

This is a fused-MoE kernel microbenchmark, not an end-to-end serving benchmark. Default versus tuned results on the same container/model/Triton version:

| Tokens | Default (us) | Tuned (us) | Improvement |
| ---: | ---: | ---: | ---: |
| 1 | 305.13 | 180.30 | 40.91% |
| 2 | 530.36 | 397.90 | 24.98% |
| 4 | 987.78 | 749.89 | 24.08% |
| 8 | 1732.48 | 1332.19 | 23.11% |
| 16 | 2927.57 | 2240.29 | 23.48% |
| 32 | 4591.12 | 3515.53 | 23.43% |
| 64 | 6176.29 | 4473.50 | 27.57% |
| 128 | 6998.44 | 4962.49 | 29.09% |

Geometric-mean fused-MoE kernel improvement: **27.32%** on the validation Radeon 8060S. No end-to-end TTFT/TPOT or serving-throughput claim is made.

Reproduction:

```bash
SGLANG_AWQ_MOE_TRITON_ROCM=1 \
python benchmark/kernels/fused_moe_triton/tuning_fused_moe_triton.py \
  --no-ray --model /models/Qwen3.5-35B-A3B-AWQ-4bit \
  --tp-size 1 --dtype int4_w4a16 \
  --batch-sizes 1 2 4 8 16 32 64 128 --tune
```

## Limitations

- The down config reuses the tuned map and does not enable TMA yet.
- Configs are specific to Radeon 8060S/gfx1151, ROCm, and the active Triton version.
- End-to-end serving and full accuracy benchmarks are follow-ups, not claims of this PR.
