## Motivation

A unified pool named its longest target window `swa` and every other window `swa_<len>`, so a window's name depended on the other windows a model declares; and the prefix tree, its match/evict API and admission carried at most two windows (`SWA` and `AUXILIARY_SWA`) with dedicated fields. This PR names every window sub-pool by its own lifetime and gives the prefix tree one slot per window sub-pool.

## Modifications

- Names (`mem_cache/kv/plan.py`, `kv/decl.py`, `kv/build.py`, `kv_cache_configurator.py`): every window sub-pool is `window_<len>`, or `window` when the length is not stated. Backends ask for sliding-window layers by role (`KVLayerRouter.plays`) instead of comparing sub-pool names (`kv/router.py`, `routed_cache.py`, `layers/attention/{triton,trtllm_mha,intel_amx}_backend.py`). External names (prefix tree component, host pool, PD state type) are unchanged in this PR.
- Tree slots (`mem_cache/unified_cache/*`, `unified_radix_cache.py`, `base_prefix_cache.py`, `managers/schedule_batch.py`, `prefill_budget.py`): `ComponentType` is an int id with fixed FULL, SWA, MAMBA and C128 ids; a further window registers its own id. `EvictParams.window_num_tokens`, `EvictResult.window_num_tokens_evicted`, `MatchResult.window_host_hit_lengths` and `Req.window_host_hit_lengths` are keyed by tree slot and replace the second-window fields. Host pools and PD keep one further window; a third is refused where the host stack is built and where PD lists its state entries. Static storage maps tree components to sub-pools strictly.
- The Rust tree core keeps one window slot; a tree with several window slots falls back to the Python tree core, logging the reason (`unified_cache/tree_core_registry.py`).
- Buffer-mode pipeline and storage attachment take any number of further window components.
- Tests: `test/registered/unit/layers/attention/test_trtllm_mha_unified_window.py`, plus updates to the tree-core registry, prefill adder, multiwindow placement, layout golden (`unified_layout_golden.json`), HiCache and session tests.

**API change:** the `AUXILIARY_SWA` fields of the prefix-cache match/evict API are replaced by per-slot maps. No serving behavior change for current single-window models.
