# [Doc] qwen: Use TRT-LLM MHA for the B300 Qwen3-VL-4B recipe

[Upstream PR](https://github.com/sgl-project/sglang/pull/48051) · state: closed · merged: True

## Original PR description

## Motivation

The B300 cookbook command generator explicitly selects `flashinfer` for Qwen3-VL-4B-Instruct, overriding SGLang's automatic `trtllm_mha` selection.

Update the tested recipe and clarify the existing B300 backend defaults.

## Modifications

- Select `trtllm_mha` for Qwen3-VL-4B-Instruct with BF16 on B300.
- Document the default attention backend for Qwen3-8B and Qwen3-VL-4B-Instruct without speculative decoding.
- Leave page size unset and preserve the other recipe combinations.

## Accuracy Tests

The existing B300 TP1 runs completed the 1024-token text workloads. Qwen3-VL-4B-Instruct with TRT/page 64 also passed two synthetic-image smoke requests.

## Speed Tests and Profiling

Measured on B300 with TP1, BF16 weights and KV cache, approximately 8K input tokens and 1K output tokens, and no speculative decoding. The runs used SGLang `fb9846d3e2`, PyTorch `2.14.1+cu130`, and FlashInfer `0.7.2`.

The random ShareGPT workload used seed 42, 40 measured requests at C4 and 640 at C128. Each concurrency received a full-length workload rehearsal before the measured phase and a KV-cache flush before timing. No compilation was logged during the accepted measurement windows.

Output throughput, tokens/s:

| Backend / page size | Qwen3-8B C4 | Qwen3-8B C128 | Qwen3-VL-4B C4 | Qwen3-VL-4B C128 |
| --- | ---: | ---: | ---: | ---: |
| FlashInfer / 1 | 712.5 | 2599.5 | 880.1 | 2642.4 |
| FA4 / 128 | 707.3 | 2485.5 | 899.6 | 2890.4 |
| Triton / 1 | 570.5 | 2169.1 | 739.6 | 2574.7 |
| TRT / 16 | 784.5 | 2913.1 | 1070.5 | 3281.1 |
| TRT / 32 | 786.5 | 2756.5 | 1062.1 | 3396.1 |
| **TRT / 64 (current default)** | **795.2** | **2773.0** | **1029.2** | **3353.2** |
| TRT / 128 | 795.2 | 2768.3 | 1036.9 | 3347.3 |

FlashInfer/page 1 and TRT/page 16 reuse the preceding warmed reference runs; the remaining configurations come from the same-node backend/page-size sweep. Qwen3-VL throughput measurements use text-only requests.

TRT leads the tested backend groups. The cookbook recipe uses TRT with the current default page size of 64; the other page sizes are included for comparison.
