## Motivation

Diffusion layerwise offload can enqueue a full layer's pinned-memory H2D copy while Ulysses `all_to_all_single` is using the same PCIe fabric. On PCIe-only multi-GPU systems, this overlap slows both the collective and the denoise step.

This PR adds an opt-in, communication-aware prefetch path that bounds H2D submission and creates a hard no-H2D window around standard NCCL Ulysses collectives.

## Modifications

- Add a rank-local prefetch traffic coordinator.
  - Prefetch producers reserve and publish bounded chunk completion events.
  - A collective closes admission and drains only the already admitted chunks.
  - The collective completion event is transferred back to the copy stream without a device-wide synchronization.
- Add a pure-DMA layerwise prefetch producer with configurable chunk size and in-flight depth.
- Guard standard and varlen NCCL Ulysses `all_to_all_single` calls.
- Keep the path disabled by default and fail closed unless CUDA, pinned host weights, contiguous consolidated buffers, and non-IPC Ulysses are in use.
- Document the opt-in environment variables and topology-specific tuning requirements.
- Add coordinator concurrency/error tests and layerwise lifecycle/configuration regression tests.

The defaults are:

```bash
SGLANG_DIT_COMM_AWARE_PREFETCH=0
SGLANG_DIT_PREFETCH_CHUNK_MIB=2
SGLANG_DIT_PREFETCH_INFLIGHT=2
```
