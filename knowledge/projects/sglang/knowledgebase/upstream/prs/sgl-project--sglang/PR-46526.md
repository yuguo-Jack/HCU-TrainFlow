# [Refactor] dsv4: Pass tail metadata to enter_late_layer_tail

[Upstream PR](https://github.com/sgl-project/sglang/pull/46526) · state: closed · merged: False

## Original PR description

- `enter_late_layer_tail` on the CUDA and HIP DeepSeek V4 backends takes an optional `metadata` argument; without it the backend uses `tail_forward_metadata` as before.
- The prefill-graph break passes the exact-row tail metadata it builds to `enter_late_layer_tail`, instead of swapping it into `backend.tail_forward_metadata` and restoring the held value in a `finally`. The break no longer writes that backend field.
- No behavior change, on the normal and the exception path: the backend state after the call and the value returned are the same. The model's own tail path does not pass `metadata` and is unchanged.
- First step toward giving the late-layer tail a single owner. The earlier content of this PR (shared row selection, graph gate and DP rows) is dropped here and comes back in later PRs.
