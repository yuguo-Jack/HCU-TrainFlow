# [NPU][GLM5.2] support dsa pcp with interleave & zigzag

[Upstream PR](https://github.com/sgl-project/sglang/pull/40165) · state: open · merged: False

## Original PR description

## Summary

Adapt GLM-5.2 (GlmMoeDsa) DSA prefill context parallelism to the CP V2 strategy flow, mirroring the DSV4 CP V2 support merged in #39427. After CP V1 was deprecated upstream, the NPU DSA path still referenced removed V1 metadata fields and could no longer run with --enable-prefill-cp.

## Changes

- **ascend_backend.py**: add prepare_dsa_cp_metadata which builds per-token local metadata for the Ascend sparse kernels (q/kv lengths from sharded local positions, per-token block-table rows selected by local batch ids); rewrite do_cp_balance_attn to a single npu_sparse_flash_attention call on the strategy-sharded local Q (no V1 prev/next balance split).
- **dsa_npu_indexer.py**: read V2 local metadata instead of the removed V1 attn_cp_metadata fields (actual_seq_q_prev_tensor / kv_len_prev_tensor / ...); rewrite do_npu_cp_balance_indexer as a single npu_lightning_indexer call.
- **deepseek_v2.py**: prepare DSA CP metadata at the inner-model entry (the eager CP runner invokes DeepseekV2Model directly); restore rebuild_cp_kv_cache, gathering the rank-local latent KV into full sequence order via cp_gather_full_sequence_states.
- **forward_mha.py**: on NPU with CP active, gather kv_a/k_pe to full sequence order before writing, since out_cache_loc spans the full sequence under CP V2.
- **unit tests**: add `test/registered/unit/layers/cp/test_dsa_cp_metadata.py` covering the zigzag/interleave block layout, local row selection, padding alignment, the `is_cp_active` gate, and the GLM DSA layer-split helpers.

The first commit fixes the attn_cp_tp_broadcast_pyobj broadcast order for attn-CP > 1 (broadcast along the attn-TP 0 line first, then TP).

## Testing

Full-model verification on a 4-node Ascend 910B3 cluster (32 NPUs/node) with GLM-5.2-w8a8 (GlmMoeDsa) in PD disaggregation:

- **Prefill** (2 nodes, 209/212): `--tp-size 8 --pp-size 4 --attn-cp-size 8 --enable-prefill-cp --cp-strategy interleave --chunked-prefill-size 8192 --max-prefill-tokens 65536 --mem-fraction-static 0.88`, NEXTN spec (num-steps 1, draft 2)
- **Decode** (2 nodes, 216/217): `--tp-size 32 --dp-size 32 --ep-size 32`, NEXTN spec (num-steps 3, draft 4)
- Key envs: `DEEPEP_HCCL_BUFFSIZE=2048`, `SGLANG_PP_LAYER_PARTITION=18,20,24,16`, `SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1`, `SGLANG_ENABLE_SPEC_V2=1`, `MALLOC_CHECK_=3`
- Client: vllm bench serve through the sglang PD router (16 prompts, concurrency 4, input 65536 / output 2500)

### Throughput / latency results

| config | result | TTFT mean / median / P99 | TPOT | throughput |
| --- | --- | --- | --- | --- |
| zigzag + chunk 4096 | :white_check_mark: 16/16 | 9.45s / 5.85s / 26.05s | 26.89 ms | 3370 tok/s |
| interleave + chunk 8192 (fixed len) | :white_check_mark: 16/16 | 9.12s / 6.08s / 20.05s | 25.70 ms | 3570 tok/s |
| interleave + chunk 8192 (variable input 40960–90112) | :white_check_mark: 16/16 | 7.82s / 6.94s / 15.53s | 25.85 ms | 3550 tok/s |

The zigzag + chunk 8192 crash is a deep_ep CAM dispatch buffer overflow (`HCCL_BUFFSIZE is too SMALL`, 3304MB needed > 2048MB) triggered when a pass dispatches the whole 8076-token batch per rank; chunk 4096 caps the per-rank dispatch at ~1.78GB. Interleave keeps CP active on every pass (1024 tokens/rank, ~604MB), so it is safe with chunk 8192.

#!/bin/bash
# GLM-5.2-w8a8 2p2d (prefill-decode disaggregation) launcher.
# Same script on all 4 nodes; the role is picked from the local IP.
#   prefill (2p): 192.168.25.209, 192.168.25.212   tp8 x pp4 = 32 cards
#   decode  (2d): 192.168.25.216, 192.168.25.217   tp32 = 32 cards
# KV pool capacity: --mem-fraction-static 0.88 gives the decode pool ~82k
# tokens (>= 68036 needed for 64k in + 2.5k out).

echo performance | tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor >/dev/null 2>&1
sysctl -w vm.swappiness=0 >/dev/null 2>&1
sysctl -w kernel.numa_balancing=0 >/dev/null 2>&1
sysctl -w kernel.sched_migration_cost_ns=50000 >/dev/null 2>&1

export SGLANG_SET_CPU_AFFINITY=1
unset https_proxy http_proxy HTTPS_PROXY HTTP_PROXY ASCEND_LAUNCH_BLOCKING
source /usr/local/Ascend/ascend-toolkit/set_env.sh
source /usr/local/Ascend/nnal/atb/set_env.sh

# ---- common env ----
export TRANSFORMERS_VERBOSITY=error
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export STREAMS_PER_DEVICE=32
export SGLANG_DISAGGREGATION_BOOTSTRAP_TIMEOUT=1200
export SGLANG_DISAGGREGATION_WAITING_TIMEOUT=1200
# P has CP but D has none: KV transfer must involve all CP ranks (both sides)
export SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1

P_IP=('192.168.25.209' '192.168.25.212')
D_IP=('192.168.25.216' '192.168.25.217')
MODEL_PATH=/home/weights/GLM-5.2-w8a8

LOCAL_HOST1=$(hostname -I | awk '{print $1}')
LOCAL_HOST2=$(hostname -I | awk '{print $2}')
mkdir -p /home/gjs/glm/logs

# =============================================================================
# prefill (2p)
# =============================================================================
for i in "${!P_IP[@]}"; do
    if [[ "$LOCAL_HOST1" == "${P_IP[$i]}" || "$LOCAL_HOST2" == "${P_IP[$i]}" ]]; then
        echo "role=prefill node=${P_IP[$i]} node_rank=$i"

        export ASCEND_MF_STORE_URL="tcp://${P_IP[0]}:24666"
        export DEEP_NORMAL_MODE_USE_INT8_QUANT=1
        export TASK_QUEUE_ENABLE=2
        export ENABLE_PROFILING=0
        export DEEPEP_HCCL_BUFFSIZE=2048
        export SGLANG_PP_LAYER_PARTITION=18,20,24,16
        export MALLOC_CHECK_=3
        export HCCL_SOCKET_IFNAME=enp196s0f0
        export GLOO_SOCKET_IFNAME=enp196s0f0
        # Note: DEEPEP_NORMAL_LONG_SEQ_* is NOT used (native long-seq path
        # double-frees on this deep_ep build); small chunks instead keep the
        # per-rank dispatch <= the default capacity.
        export SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=128
        export SGLANG_ENABLE_SPEC_V2=1
        export SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1
        export SGLANG_ENABLE_TP_MEMORY_INBALANCE_CHECK=0
        export SGLANG_DISAGG_PREFILL_EARLY_SEND_CACHED_PREFIX=1

        nohup python3 -m sglang.launch_server \
          --model-path "$MODEL_PATH" \
          --disaggregation-mode prefill \
          --tp-size 8 --attn-cp-size 8 --enable-prefill-cp --cp-strategy interleave \
          --nnodes 2 --node-rank "$i" --dist-init-addr "${P_IP[0]}:5000" \
          --mem-fraction-static 0.88 \
          --attention-backend ascend --device npu --quantization modelslim \
          --disaggregation-transfer-backend ascend \
          --max-running-requests 64 \
          --served-model-name glm-5 \
          --chunked-prefill-size 8192 --max-prefill-tokens 65536 \
          --moe-a2a-backend deepep --deepep-mode normal \
          --load-balance-method round_robin \
          --disable-shared-experts-fusion --disable-cuda-graph --dtype bfloat16 \
          --speculative-draft-model-quantization unquant \
          --pp-size 4 \
          --speculative-algorithm NEXTN --speculative-num-steps 1 --speculative-eagle-topk 1 --speculative-num-draft-tokens 2 \
          --reasoning-parser glm45 --tool-call-parser glm47 \
          --trust-remote-code \
          --disaggregation-bootstrap-port 8995 \
          --host "${P_IP[$i]}" --port 8000 \
          > /home/gjs/glm/logs/prefill_$i.log 2>&1 &
        break
    fi
done

# =============================================================================
# decode (2d)
# =============================================================================
for i in "${!D_IP[@]}"; do
    if [[ "$LOCAL_HOST1" == "${D_IP[$i]}" || "$LOCAL_HOST2" == "${D_IP[$i]}" ]]; then
        echo "role=decode node=${D_IP[$i]} node_rank=$i"

        export ASCEND_MF_STORE_URL="tcp://${P_IP[0]}:24666"
        export SGLANG_SPEC_ENABLE_OVERLAP_REFLOW=1
        export SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1
        export SGLANG_ENABLE_SPEC_V2=1
        export HCCL_BUFFSIZE=320
        export SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=48
        export TASK_QUEUE_ENABLE=0
        export SGLANG_NPU_USE_MULTI_STREAM=1
        export HCCL_SOCKET_IFNAME=enp196s0f0
        export GLOO_SOCKET_IFNAME=enp196s0f0

        nohup python3 -m sglang.launch_server \
          --model-path "$MODEL_PATH" \
          --disaggregation-mode decode \
          --tp-size 32 --nnodes 2 --node-rank "$i" --dist-init-addr "${D_IP[0]}:5000" \
          --dp-size 32 --enable-dp-attention --ep-size 32 \
          --mem-fraction-static 0.88 \
          --max-running-requests 384 \
          --attention-backend ascend --device npu --quantization modelslim \
          --served-model-name glm-5 \
          --moe-a2a-backend deepep --deepep-mode low_latency \
          --cuda-graph-max-bs-decode 12 \
          --disaggregation-transfer-backend ascend \
          --watchdog-timeout 9000 --context-length 180000 \
          --tokenizer-worker-num 16 \
          --disable-shared-experts-fusion --dtype bfloat16 --load-balance-method round_robin \
          --speculative-draft-model-quantization unquant \
          --speculative-algorithm NEXTN --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4 \
          --reasoning-parser glm45 --tool-call-parser glm47 \
          --trust-remote-code \
          --host "${D_IP[$i]}" --port 8000 \
          > /home/gjs/glm/logs/decode_$i.log 2>&1 &
        break
    fi
done

#!/bin/bash
# sglang PD router (single entry for prefill/decode disaggregation).
# Run on the decode head node, e.g.:
#   docker exec -d sglang-gjs-0915 bash -c "cd /home/gjs/glm && bash start_router.sh"
# Clients (vllm bench / evalscope) hit http://192.168.25.216:30000

PREFILL_IP="${PREFILL_IP:-192.168.25.209}"
DECODE_IP="${DECODE_IP:-192.168.25.216}"
SVC_PORT="${SVC_PORT:-8000}"
BOOTSTRAP_PORT="${BOOTSTRAP_PORT:-8995}"
LOG_DIR="${LOG_DIR:-/home/gjs/glm/logs}"
mkdir -p "$LOG_DIR"

exec python3 -m sglang_router.launch_router \
  --host 0.0.0.0 \
  --port "$ROUTER_PORT" \
  --pd-disaggregation \
  --policy round_robin \
  --prefill "http://${PREFILL_IP}:${SVC_PORT}" "$BOOTSTRAP_PORT" \
  --decode "http://${DECODE_IP}:${SVC_PORT}" \
  > "$LOG_DIR/router.log" 2>&1

## Performance: single-call vs two-call DSA attention (zigzag)

Measured on the 4-node 2p2d GLM-5.2-w8a8 stack (b072 image; 2 prefill nodes tp8 x cp8 x pp4 zigzag + 2 decode nodes tp32 x dp32, NEXTN 1x2/3x4), fixed-length 64k-input x 8-concurrent requests:

| variant | success | wall | TTFT mean (min/max) | e2e mean (min/max) | decode tok/s |
| --- | --- | --- | --- | --- | --- |
| single fused call (shipped) | 8/8 | 38.13s | 21.70s (8.72 / 33.32) | 26.05s (12.96 / 38.12) | 53.7 |
| two calls, per-sequence metadata (experiment) | 8/8 | 38.21s | 21.79s (8.81 / 33.43) | 26.10s (12.95 / 38.20) | 53.6 |

The two-call variant splits the local Q into prev/next halves and issues two `npu_sparse_flash_attention` calls with per-sequence metadata. It was built as an experiment during development; after fixing a batch-local `actual_seq_lengths_query` restart for the second call (plus empty-shard / block-table-row / contiguous-view guards), its output matches the single-call path exactly (max element diff 0.0, verified with an in-model probe at 64k). End-to-end performance is identical (<0.5% difference), so this PR ships the single-call implementation for simplicity.

Accuracy spot-check on the two-call variant (full 68-layer model): "What is 6 times 7?" -> "42", "What is 7 times 8?" -> "56".
