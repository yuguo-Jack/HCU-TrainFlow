# [CI] [NPU] tests: Add GSM8K PR gate for DSV4-Flash W8A8 8P GPQA

[Upstream PR](https://github.com/sgl-project/sglang/pull/45293) · state: closed · merged: True

## Original PR description

## Motivation

Split the DeepSeek-V4-Flash W8A8 8P accuracy test case changes out of #43063 so they can be tracked and iterated on separately. #43063 now only carries the DeepSeek-V2-Lite-W8A8 cleanup.

## Modifications

- `test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_gpqa.py`:
  - Register the case to `base-c-test-acc-16-npu-a3` so it runs in the PR pipeline (`est_time=3600`).
  - Identify the invoking pipeline by requiring `GITHUB_EVENT_NAME == pull_request` and excluding the nightly workflow via `GITHUB_WORKFLOW_REF`, so local runs and other workflows keep the full nightly profile instead of silently downgrading to the PR smoke profile.
  - On the PR pipeline run a 300-question GSM8K subset with a 0.93 threshold (relaxed from 0.95: the official report lists 91.1 on BF16 8-shot, while our 0-shot CoT evalscope runs measured 0.98, and 0.95 left too little headroom for sampling noise on the 300-question subset); the nightly pipeline keeps the full GPQA run (0.874).
  - Drop the obsolete `nightly-acc-16-npu-a3-cann910` registration.
