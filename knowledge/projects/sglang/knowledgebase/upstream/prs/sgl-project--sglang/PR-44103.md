# [Perf] [AMD] Qwen3.8-flash-next: Opt-in AITER GDN chunked prefill (opt_vk stages and fused FlyDSL)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44103) · state: open · merged: False

## Original PR description

## Motivation

On ROCm, GDN chunked prefill runs the five-kernel Triton FLA path. AITER has faster gfx950 implementations. This PR wires them in behind an opt-in flag; defaults and non-HIP platforms are unchanged.

## Modifications

- `SGLANG_AITER_GDN_PREFILL=1` (with `SGLANG_USE_AITER=1`) routes `TritonGDNKernel.extend` on HIP through AITER. `SGLANG_AITER_GDN_PREFILL_H` selects the implementation:
  - `triton` (default) / `hip` / `flydsl`: AITER's opt_vk stages, called one by one so the per-chunk states `h` stay available for radix state tracking.
  - `fused`: one FlyDSL kernel for the whole chunk loop, which also writes the track snapshot. Needs ROCm/aiter#6496 and a bf16 SSM state (`SGLANG_MAMBA_SSM_DTYPE=bfloat16`).
- New `gdn_aiter_prefill.py`. Prefill metadata is built once per forward from `extend_seq_lens_cpu`, so there is no device-to-host sync.
- Batches AITER can't handle, or an AITER build without the kernel, fall back to Triton.

## Accuracy Tests

GSM8K (1319, chat, thinking off), Qwen3.8-Flash-Next MXFP4, MI355X TP1 + NEXTN: Triton 96.1%, opt_vk 96.6%, fused 96.7%.

Kernel output vs an fp32 recurrence (relative L2 error): fused 3.31e-3 (output) / 2.87e-3 (final state), Triton 4.11e-3 / 3.54e-3.

## Speed Tests and Profiling

One GDN layer, 32K tokens: Triton 3.37 ms, opt_vk 2.52 ms, fused **1.54 ms**.

End-to-end: Qwen3.8-Flash-Next MXFP4, MI355X TP1 + NEXTN, ISL 32K / OSL 1K, random prompts, mean of 2 runs (run-to-run spread ≤ 0.3%):

| Conc | Prefill | Output tok/s | Mean TTFT (ms) | TPOT (ms) |
|---|---|---|---|---|
| 12 | Triton | 575.7 | 6234 | 14.6 |
| 12 | opt_vk | 586.1 (+1.8%) | 6014 (−3.5%) | 14.5 |
| 12 | fused | **599.2 (+4.1%)** | **5775 (−7.4%)** | 14.3 |
| 16 | Triton | 626.7 | 8125 | 17.4 |
| 16 | opt_vk | 640.1 (+2.1%) | 7841 (−3.5%) | 17.2 |
| 16 | fused | **654.8 (+4.5%)** | **7445 (−8.4%)** | 17.0 |

Usage:
```bash
export SGLANG_USE_AITER=1
export SGLANG_AITER_GDN_PREFILL=1
export SGLANG_AITER_GDN_PREFILL_H=fused   # needs ROCm/aiter#6496; otherwise triton
export SGLANG_MAMBA_SSM_DTYPE=bfloat16    # fused only takes a bf16 SSM state
```
