# [DeepSeek V2/V3，GLM5.2] PD Disaggregation Layerwise KV Transfer & PP Early Release KV

[Upstream PR](https://github.com/sgl-project/sglang/pull/38309) · state: open · merged: False

## Original PR description

### **Feature 1: Layerwise KV Transfer**

**Background**: PD Disaggregation
In Prefill-Decode (PD) disaggregation, the prefill worker computes the KV cache for a prompt, then transfers it to a separate decode worker before the decode worker can begin generating tokens. The transfer happens after the entire model forward completes — a serial bottleneck:
[Prefill: layer0 → layer1 → ... → layerN] → [transfer ALL layers] → [Decode starts]

**Goal**:
Overlap KV transfer with compute by sending each layer's KV the moment its attention op finishes, rather than waiting for the full forward.

**Mechanism**:
1. Dedicated NPU transfer stream (AscendKVManager.init_layerwise): A separate stream transfers KV independently from the compute stream.
2. Per-layer dispatch (save_kv_layer): After layer N's attention completes:
Record a compute-stream event (marks KV data as ready)
Transfer KV on the transfer stream with a wait_event dependency — non-blocking for the CPU; the NPU hardware handles the overlap
Compute:   [layer0 attn] [layer1 attn] [layer2 attn] ... [layerN attn]
Transfer KV:             ↓ transfer0      ↓ transfer1      ↓ transfer2  (overlapped)

**Env var**: `SGLANG_DISAGG_LAYERWISE=1`
**accuracy test**:
glm5.2 model (gsm8k)
