# [Feat] tool-call: --tool-call-constraint none samples auto tool choice without a grammar

[Upstream PR](https://github.com/sgl-project/sglang/pull/47203) · state: open · merged: False

## Original PR description

**Problem.** With `--tool-call-parser glm47`, every chat request that has tools is decoded under a grammar built from the request's tools. The model can only name declared tools, and can make one call per turn when `parallel_tool_calls` is false. RL rollouts sample freely and parse afterwards, and some clients declare a few tools and look the rest up at run time. Both need unconstrained sampling.

```text
# illustrative tool names
request tools: [get_tool_schemas, search_files]   tool_choice: "auto"
model wants:   <tool_call>read_file ...  (schema fetched one turn earlier)

before (auto): the grammar allows only get_tool_schemas or search_files
               -> the call is rewritten to a declared name
after (none):  the model samples read_file; the parser returns it as a tool call
```

**Fix.** A server option `--tool-call-constraint {auto,none}`. `auto` (default) keeps today's behavior. `none` installs no grammar and no structural tag for `tool_choice="auto"`, for every parser, and parses the text afterwards. `required` and named tool choices still constrain under both values.

**Tests.** `test/registered/unit/entrypoints/openai/test_serving_chat.py`:

- `test_tool_call_constraint_auto_installs_the_glm47_grammar`
- `test_tool_call_constraint_none_samples_auto_requests_unconstrained`
- `test_tool_call_constraint_none_keeps_required_tool_choice_constrained`

Rebased on main `a4a19332ab` (one conflict next to main's new `muse` tool branch). On CPU the 3 tests pass and the file has 0 new failures. The branch merges into current main without conflicts.

**Proven in a run.** A Qwen3.8-27B-VL training run (2026-10-17): all 8 engines started with `--tool-call-constraint none` and logged 0 grammar lines. Rollout 6 (partial, 32,936 turns) had 0 tool-schema errors.

Draft until it is checked again in a run on current main.
