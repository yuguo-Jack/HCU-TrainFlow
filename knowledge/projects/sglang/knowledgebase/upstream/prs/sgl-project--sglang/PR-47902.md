## Motivation

- DeepSeek-V4-Pro-0813 W4A8: add a two-node 16p PD-mix performance case (in 128k / out 1k, 90% shared prefix) and a new 1P1D 32p GPQA-Diamond accuracy case.
- DeepSeek-V4-Flash-0731 W8A8: add a new 1P1D 16p GPQA-Diamond accuracy case.
- DeepSeek-V4-Flash FP8 4P: re-enable the previously commented-out GPQA-Diamond accuracy case on A5.
- Re-enable the `nightly-acc-4-npu-a5` job now that the A5 machines are back online, and wire the new multi-node cases into the nightly NPU pipeline.
- Add the shared `DEEPSEEK_V4_PRO_0813_W4A8_MODEL_PATH` constant used by the new DeepSeek-V4-Pro test cases.
