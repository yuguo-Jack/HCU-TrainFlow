## Motivation

Attention and transfer consumers currently navigate composite pools themselves. A shared layer router makes the storage owner, local layer index and load-back wait explicit for each model layer.

## Changes

- Add layer routes and subpool views for static and unified KV pools.
- Migrate attention backends and host consumers to routed layer access and stage-relative load waits.
- Pass MLA layer overrides explicitly and remove the allocator-specific full-to-window translation entry point.

## Validation

Historical validation at `46a9ed59d0`:
- Router tests: **3 tests / 9 subtests passed**; the incorrect-local-ID mutation failed.
- TP1 H200, unified FA3, GSM8K-200: gpt-oss-120b **97.0% → 96.5%**, Qwen3.8-27B **98.0% → 96.0%**; zero request errors. Environment: PyTorch 2.14.1, FlashInfer 0.7.2, sglang-kernel 0.4.10.
- Later four-chain replay: **0 divergences**; CPU route/wait-offset checks passed.

Exact-output parity was not established by that sampled A/B. GPU serving was not rerun on the rebased head.
