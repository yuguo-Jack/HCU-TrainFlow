# [Fix] hunyuan: Parse tool arguments with JSON Schema type arrays

[Upstream PR](https://github.com/sgl-project/sglang/pull/38940) · state: open · merged: False

## Original PR description

## Motivation

A Hunyuan tool parameter with a valid JSON Schema type array, such as `{"type": ["integer", "null"]}`, raises `TypeError: unhashable type: 'list'`. Non-streaming parsing then drops the call; streaming cannot finish its arguments.

## Modifications

Expand scalar and array-valued schema types before applying the existing normalization. Preserve type precedence, aliases, coercion, and null handling. The production fix is unchanged from the original PR; the branch now incorporates upstream `0d6b283d7e6ac79edc10b2ca788f309e972f527b`.

Exercise nullable primitives, arrays/objects, string unions, and type arrays inside `anyOf`/`oneOf` across bare Hy3 tokens, suffixed Hy3 tokens, and suffixed Hy4 tokens without a tool separator. Repeated calls check streaming-state reset.
