# [diffusion] comfyui: run LTX-2.5 / LTX-2.3 in SGLD integrated mode

[Upstream PR](https://github.com/sgl-project/sglang/pull/43583) · state: open · merged: False

## Original PR description

## Motivation

Run Lightricks LTX-2.5 / LTX-2.3 audio-video DiTs (ComfyUI `ltxav`) in ComfyUI SGLD integrated mode, using the official templates with `SGLDUNETLoader`:
- LTX-2.5 INT8 ConvRot / BF16 single files
- the LTX-2.3 all-in-one dev FP8 checkpoint, with the distilled LoRA

The DiT and its text connectors run on the worker with SGLang's native LTX numerics. Gemma, the VAEs, the latent upsampler and the samplers / guiders stay in ComfyUI.

The checkpoint-spec hooks (`quant_markers` / `checkpoint_key_filter` in `comfyui_checkpoints/spec.py`) are the same change as in #43581; whichever PR lands first, the other picks them up from `main`.

## Modifications

- **Checkpoint spec** (`comfyui_checkpoints/ltx_2.py`): reads the DiT config from the file and rejects video-only files. Keeps only DiT and text-connector keys, and maps `comfy_quant` markers to SGLang module paths. Connector quant markers come from `inspect_comfy_quant_markers`.
- **LTX-2 DiT module paths** (`runtime/models/dits/ltx_2.py`): linears now pass their checkpoint-relative module path to the quant config, so per-layer markers resolve. **This also affects native runs**: with a prefix-aware quant config, `--quantization-ignored-layers` (and ModelOpt exclude lists) now match LTX-2 layers, where before they silently matched nothing. Without a quant config nothing changes. Covered by `test_ltx2_linear_quant_prefixes.py`.
- **Worker** (`LTX2ComfyUIStepStage`): handles one ComfyUI `apply_model` call per request. It patchifies the video / audio latents, runs the connectors on the worker, and returns ComfyUI-layout velocities. Under SP, each rank takes equal whole-frame blocks of the video.
- **Plugin**: ltxav adapter / executor, registered in the generator and the `model_type` list.
  - STG (`stg_self_attn_blocks`) and modality guidance (a2v / v2a cross-attention off, `run_vx` / `run_ax`) raise: the worker does not apply them, so the extra pass would silently equal the cond prediction.
  - Keyframe guides (`LTXVAddGuide`) and reference audio raise.
  - LoRA follows the server merge mode (`auto`). With the LTX-2.3 FP8 checkpoint the whole transformer gets a dynamic low-rank delta, since SGLang cannot merge into static FP8 weights; a requantizing merge will be proposed separately.
- README notes. No example workflows: the official LTX templates work after swapping the model loader for `SGLDUNETLoader`.

## Accuracy Tests

- Unit: `test_comfyui_*.py`, `test_ltx2_linear_quant_prefixes.py`, `test_conditioning_cache.py`: 159 passed. pre-commit clean.
- End-to-end on H200, official-template graphs reduced to one stage: 640x360, 49 frames, 8 steps euler, fixed seed. Final latents compared with stock ComfyUI (`UNETLoader`, or the checkpoint model with `LoraLoaderModelOnly`):

| Workflow | Result | vs stock ComfyUI |
|---|---|---|
| LTX-2.5 INT8 ConvRot t2v | completes | video latent cos 0.952, audio 0.9996; decoded video PSNR 24.4 dB, same frames |
| LTX-2.5 t2v, `LTXVDualCFGGuider` cfg 3 (cond / uncond batched on the worker) | completes | video cos 0.810, audio 0.996; same composition |
| LTX-2.3 dev FP8 + distilled LoRA 0.5 | completes | video cos 0.870, audio 0.998; same composition and text |

The differences come from SGLang's INT8 / FP8 kernels versus ComfyUI's and accumulate over the steps; the trimmed branch is bit-identical (sha256) to the previous head of this PR on all three workflows.
