> LGTM. Could you share an example showing a successful inference after launching the server? Thanks!

Sure.
Launch the server:
`export CUDA_VISIBLE_DEVICES=6
python  -m sglang.launch_server   --model-path mispeech/midashenglm-7b-0804-fp32  --port 12312   --mem-fraction-static 0.85  --trust-remote-code  --tp-size 1 `
Send request:
`curl http://localhost:12312/generate  -H "Content-Type: application/json"  -d '{
    "text": "Please describe this audio.",
    "audio_data": "/audio_data/example.wav",
    "sampling_params": {
      "temperature": 0.1,
      "max_new_tokens": 512
    }
  }'`
