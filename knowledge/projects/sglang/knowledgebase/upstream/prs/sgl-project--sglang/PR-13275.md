# [Fix] Fix detokenizer streaming chunk detection logic

[Upstream PR](https://github.com/sgl-project/sglang/pull/13275) · state: closed · merged: False

## Original PR description

## Motivation

This PR fixes issue #8031, which causes severe performance degradation in the detokenizer when handling tokens that decode to empty strings.

### Root Cause

The detokenizer uses `len(new_text) > 0` to check if decode status should be updated. When a token decodes to an empty string (e.g., token 163586 in Kimi-K2-Instruct), this check fails and `surr_offset` never advances. However, `decode_ids` continues to grow, causing each iteration to decode an ever-growing token list `s.decode_ids[s.surr_offset:]`, leading to exponential performance degradation.


## Modifications

Replace text-length check with offset comparison to correctly handle tokens that decode to empty strings:

```python
# Before
if len(new_text) > 0 and not new_text.endswith("�"):

# After
if s.read_offset > s.surr_offset and not new_text.endswith("�"):
```

### Highlights
