# [Chore] [NPU] deps: Bump kernel and hybrid memory packages

[Upstream PR](https://github.com/sgl-project/sglang/pull/48352) · state: closed · merged: True

## Original PR description

## Motivation

Align NPU Docker builds and CI dependency installation with the newer SGLang NPU kernel and hybrid memory package versions.

## Modifications

- Bump `SGLANG_KERNEL_NPU_TAG` from `2026.9.0.post12` to `2026.11.0.post1` in the NPU Dockerfile, CI dependency installer, release workflow, and nightly workflow.
- Bump `memfabric-hybrid` and `memcache-hybrid` from `1.2.1` to `1.3.0`, and update the corresponding `MF_VERSION` in the Dockerfile.

Not applicable — this PR only updates pinned dependency versions and does not modify model- or kernel-source code.
