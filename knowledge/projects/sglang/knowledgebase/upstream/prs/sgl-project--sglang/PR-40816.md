# feat(dsv4): route A5 compressor to explicit SWA-mapped state table

[Upstream PR](https://github.com/sgl-project/sglang/pull/40816) · state: open · merged: False

## Original PR description

Forward_compress now builds the A3 explicit state_block_table (_build_explicit_state_block_table, with the c4 SWA full->swa mapping) for A5 too, and calls torch.ops.npu.compressor on both archs. Drops the A5 CYCLE request-bank path (_build_cycle_state_block_table + custom.compressor).
