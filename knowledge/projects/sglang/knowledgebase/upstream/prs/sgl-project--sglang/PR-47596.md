# [Test] model_loader: Add CPU unit coverage for MTP weight filtering

[Upstream PR](https://github.com/sgl-project/sglang/pull/47596) · state: closed · merged: False

## Original PR description

## Motivation
Add regression coverage for the existing MTP checkpoint filtering path when `draft_model_idx` is set.

Closes #47594

## Modifications
- Preserve non-MTP checkpoint weights.
- Keep only the requested MTP layer and remap it to layer `0`.
- Verify filtering remains lazy and does not eagerly consume later checkpoint weights.

Validation: `python -m py_compile test/registered/unit/model_loader/test_default_model_loader.py` passed; `git diff --check` passed. The focused pytest could not collect because `torch` is not installed in this environment.
