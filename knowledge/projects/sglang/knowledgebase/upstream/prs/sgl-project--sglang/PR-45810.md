# [Fix] moe: scale the KT routed output once when the top-k already folds the factor

[Upstream PR](https://github.com/sgl-project/sglang/pull/45810) · state: open · merged: False

## Original PR description

## Motivation

Since #44993, `TopK` folds `routed_scaling_factor` into the top-k weights whenever the layer's quant method reports `fuse_routed_scaling_factor_in_topk`. `KTEPWrapperMethod` forwards unknown attributes to its GPU method through `__getattr__`, and the MXFP4 methods (`mxfp4_flashinfer_cutlass_moe`, `mxfp4_marlin_moe`, `mxfp4_flashinfer_trtllm_moe`) report `True`. So under KTransformers the top-k weights already carry the factor.

`DeepseekV2MoE.forward_normal` and `forward_normal_dual_stream` still multiply the routed output by `routed_scaling_factor` unconditionally whenever the quant method is `KTEPWrapperMethod`. The routed experts were therefore scaled twice. On DeepSeek-V4.1 (`routed_scaling_factor` 1.5) they came out at 2.25x instead of 1.5x, on every layer.

## Modifications

The KT branch of that condition now scales only when the top-k has not already folded the factor (`not self.routed_scaling_factor_fused_in_topk`). Both sites are changed. GPU methods that do not fuse the factor keep the single multiply they had before.

## Accuracy Tests

DeepSeek-V4.1-Flash (1017 checkpoint), KTransformers hybrid MoE on 2x RTX 5070 Ti (TP2) with AVX2 MXFP4 CPU experts.

- **Reference.** Teacher-forced log-probs on 24 x 480-token pieces (11,496 scored tokens) from the checkpoint's own `inference/model.py`, streamed one layer at a time.
- **Layer 0.** I dumped piece 0's MoE pieces on both sides from the same input.
  - The routing and the top-k weights are identical, and the weights already sum to 1.5 per token.
  - The shared expert matches within 0.2%.
  - The KT routed output is 1.50x the reference.
  - With one scale, the residual stream after layer 0 matches the reference within 1.9%; before this fix it was 13%.

| | mean NLL | vs reference (paired, per token) |
|---|---|---|
| reference (`inference/model.py`) | 2.5940 | |
| before | 2.8780 | +0.2839 (SE 0.0116) |
| after | 2.5960 | +0.0020 (SE 0.0046) |
