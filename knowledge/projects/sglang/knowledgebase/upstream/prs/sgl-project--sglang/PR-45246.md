# [Doc] tpu: Introduce SGLang-TorchTPU in README and TPU guide

[Upstream PR](https://github.com/sgl-project/sglang/pull/45246) · state: closed · merged: True

## Original PR description

## Motivation

SGLang-TorchTPU is now public, but the upstream README points to a blog and the TPU guide describes only SGL-JAX. Readers need a direct repository link and a clear choice between the PyTorch and JAX backends.

## Modifications

- Link SGLang-TorchTPU before SGL-JAX in the README hardware table and add a short introduction.
- Add a TorchTPU tab to the TPU guide with hardware scope, model coverage, and links to the repository's getting-started instructions, serving recipes, support guide, and issues.
- Keep the existing JAX instructions in a separate tab.

Only README.md and docs/docs/hardware-platforms/tpu.mdx change. Cookbook pages and command generators are unchanged.

## Validation

- Checked both backend tabs and repository destinations.
- `git diff --check` passed.
- Preview-only correction of a pre-existing popular-models.jsx syntax error was made in a separate copy and is not included in this PR.
- No TPU hardware tests; documentation-only changes.
