# [AMD] DeepSeek-V4.1: faster prefill MXFP8 dense GEMM at large M on gfx950

[Upstream PR](https://github.com/sgl-project/sglang/pull/42500) · state: closed · merged: False

## Original PR description

In DeepSeek-V4.1-Flash prefill, the dense MXFP8 GEMMs at large M (16k-token chunks) reach only about a third of the MXFP8 peak on MI355X. A faster kernel for these shapes needs aiter work; this draft tracks the SGLang side: selecting the new kernel for the DeepSeek-V4.1 prefill shapes once it is available.

- Predicted from the prefill traces (MI355X, tensor parallel on 4 GPUs): up to about 2.5% less prefill GPU time.
- Conservative expectation: about 1% lower time to first token and up to 0.5% higher output throughput at 32 concurrent requests.
- Status: draft without code; needs a new aiter kernel.
