## Motivation

Opt-in FlyDSL for the GDN **prefill state-matrix** step (`chunk_gated_delta_rule_fwd_h`) on ROCm. Decode, `kkt`/`w,u`, and `chunk_fwd_o` stay on Triton.

**Depends on https://github.com/ROCm/aiter/pull/5543** (`[FlyDSL] Add token-major layout option to GDN prefill h kernel`, branch `jograner/gdn-token-major`). That PR adds `wu_head_major=False` / `g_head_major=False` so SGLang’s native `[B,T,H,…]` tensors hit the kernel with **no transpose**. Do not merge this until that aiter PR is in the ROCm image (or pin `jograner/gdn-token-major`).

Enable with `SGLANG_GDN_PREFILL_FLYDSL=1` (HIP only). Default remains Triton.

SGLang’s GDN prefill keeps tensors token-major, which is what Triton fwd_h and chunk_fwd_o already consume:

w, u: [B, T, H, D]

g: [B, T, H]

aiter’s FlyDSL fwd_h wants head-major (and a gathered VK state):

w, u: [B, H, T, D]

g: [T, H] (or equivalent head-major)

state: [N, H, V, K]

[PR #31191](https://github.com/sgl-project/sglang/pull/31191) did that conversion in _chunk_gated_delta_rule_fwd_h_flydsl() in chunk.py:

```
w_c = w.permute(0, 2, 1, 3).contiguous()   # [B,T,H,K] -> [B,H,T,K]
u_c = u.permute(0, 2, 1, 3).contiguous()
h0  = initial_state[initial_state_indices].contiguous()
...
v_new = v_new_hm.permute(0, 2, 1, 3).contiguous()  # back to token-major
```
permute by itself is only a view. .contiguous() copies the tensor so memory order matches the new shape. Those copies show up as extra GPU kernels.

On MI355X they measured, per GDN call:

FlyDSL core kernel: −114 µs (the 1.5× win)

layout copies: +230 µs

net: +117 µs, so e2e tok/s went down ~0.2–4%

That is why they called it scaffolding: the kernel was faster, the SGLang-side layout tax ate the gain. A real win needs a FlyDSL kernel that reads SGLang’s native layout.

## Modifications

- `python/sglang/kernels/ops/attention/fla/chunk.py`: if `SGLANG_GDN_PREFILL_FLYDSL=1` and HIP, try `aiter.ops.flydsl.linear_attention_prefill_kernels.chunk_gated_delta_rule_fwd_h_flydsl_opt`. Call it with token-major `w`/`u`/`g`, indexed state pool, `inplace_final_state=True`, `use_exp2=False`, `bf16_convert_trunc=False` (RNE, match Triton). Host eligibility check (`K=V=128`, `chunk_size=64`, bf16 contiguous `k/w/u`, fp32 `[B,T,H]` `g`, live indexed pool, `inplace_update=True`). Mismatch or missing aiter → Triton; log the decision once per process. **No `-1` padded-slot guard** on the FlyDSL indexed path — only live slots.
- `test/registered/kernels/test_gdn_prefill_flydsl.py`: FlyDSL vs Triton on `o` / `h` / pool (aligned, unaligned tail, GQA, bf16 pool, single sequence). AMD CI `stage-b-test-1-gpu-small-amd`.

Decode / packed decode / `chunk_fwd_o` / intra `w,u` are unchanged.
