# [Fix] attention: Honor selected FlashAttention implementation

[Upstream PR](https://github.com/sgl-project/sglang/pull/33007) · state: closed · merged: True

## Original PR description

## Motivation

`FlashAttentionBackend` selects the requested FlashAttention implementation
during initialization and stores its varlen entry point in
`self.flash_attn_varlen_func`.

The KV-cache-skipping prefill path bypasses that selected callable and invokes
the module-level generic wrapper instead. Because the call does not pass
`ver`, the wrapper uses its default `ver=3`. A backend configured for FA4 can
therefore silently execute FA3 when `fa_skip_kv_cache` is enabled.

## Modifications

- Route KV-cache-skipping prefill through the varlen callable selected by the
  backend.
- Leave the generic module-level wrapper available to the existing MLA paths
  that explicitly pass `ver`.

## Accuracy Tests

Run this minimal reproduction against upstream and this PR:

```python
from types import SimpleNamespace
from unittest.mock import patch

import torch

from sglang.test.test_utils import maybe_stub_sgl_kernel

maybe_stub_sgl_kernel()

from sglang.srt.layers.attention import flashattention_backend
from sglang.srt.layers.radix_attention import AttentionType

q = torch.randn(2, 1, 4)
k = torch.randn(2, 1, 4)
v = torch.randn(2, 1, 4)
calls = []


def generic_flash_attn(**kwargs):
    calls.append("generic")
    return torch.zeros_like(kwargs["q"])


def selected_flash_attn(**kwargs):
    calls.append("selected")
    return torch.ones_like(kwargs["q"])


metadata = SimpleNamespace(
    cache_seqlens_int32=torch.tensor([2], dtype=torch.int32),
    cu_seqlens_k=torch.tensor([0, 2], dtype=torch.int32),
    cu_seqlens_q=torch.tensor([0, 2], dtype=torch.int32),
    fa_skip_cu_seqlens_q=None,
    fa_skip_max_seqlen_q=None,
    local_attn_metadata=None,
    max_seq_len_q=2,
    page_table=torch.tensor([[0, 1]], dtype=torch.int32),
)
backend = object.__new__(flashattention_backend.FlashAttentionBackend)
backend.__dict__.update(
    attention_chunk_size=None,
    attn_cp_size=1,
    fa_impl_ver=4,
    fa_skip_kv_cache=True,
    flash_attn_varlen_func=selected_flash_attn,
    forward_metadata=metadata,
    has_local_attention=False,
    kv_cache_dtype_str="auto",
    kv_cache_is_mxfp8=False,
    num_splits=1,
    page_size=1,
    token_to_kv_pool=SimpleNamespace(get_kv_buffer=lambda _: (k, v)),
    topk=1,
    use_mla=False,
)
layer = SimpleNamespace(
    attn_type=AttentionType.DECODER,
    head_dim=4,
    is_cross_attention=False,
    k_scale=None,
    layer_id=0,
    logit_cap=0.0,
    scaling=0.5,
    sliding_window_size=-1,
    tp_k_head_num=1,
    tp_q_head_num=1,
    tp_v_head_num=1,
    v_head_dim=4,
    v_scale=None,
)
forward_batch = SimpleNamespace(
    _attn_output=None,
    attn_cp_metadata=None,
    extend_num_tokens=2,
    forward_mode=SimpleNamespace(
        is_context_parallel_extend=lambda: False,
        is_target_verify=lambda: False,
    ),
)

with patch.object(
    flashattention_backend,
    "flash_attn_varlen_func",
    generic_flash_attn,
):
    output = backend.forward_extend(q, k, v, layer, forward_batch)

print({"calls": calls, "output": output.unique().tolist()})
assert calls == ["selected"]
assert torch.all(output == 1)
```

Observed results:

| Implementation | Called entry point | Result |
| --- | --- | --- |
| Upstream | Generic wrapper (`ver=3` default) | Assertion fails |
| This PR | Backend-selected FA4 callable | Passes |

## Speed Tests and Profiling

No attention kernel, launch configuration, or tensor transformation is
changed. The patch replaces the generic Python dispatcher with the callable
already selected and stored by `FlashAttentionBackend`; no additional host or
device work is introduced.
