# [Fix] server_args: Expose DP scheduler rank count

[Upstream PR](https://github.com/sgl-project/sglang/pull/42563) · state: open · merged: False

## Original PR description

## Motivation

After #41818, the deprecated `--dp-size N --enable-dp-attention` spelling resolves to `dp_size=1` and `attn_dp_size=N`. In-process integrations that derive the scheduler count from `ServerArgs.dp_size` therefore register only one rank even though the configured attention-DP width is N.

This change exposes that count as `ServerArgs.num_dp_ranks` and names the accessor in the deprecated flag's warning so integrations can migrate. The NVIDIA Dynamo routing issue reported in #42560 was later resolved in [ai-dynamo/dynamo#16005](https://github.com/ai-dynamo/dynamo/pull/16005); this accessor remains useful for other in-process consumers.

Related to #42560.

## Modifications

- Add `ServerArgs.num_dp_ranks`, computed from the resolved replica and attention-DP widths.
- Include the accessor in the deprecated flag's migration warning for in-process integrations.
- Extend the registered regression tests for the legacy spelling, the explicit attention-DP flag, and ordinary data parallelism.
