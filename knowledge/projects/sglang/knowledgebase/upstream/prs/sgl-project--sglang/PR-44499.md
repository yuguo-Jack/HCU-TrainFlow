# [Perf] request-logger: Skip logged fields before watermark redaction

[Upstream PR](https://github.com/sgl-project/sglang/pull/44499) · state: open · merged: False

## Original PR description

## Motivation

With `--log-requests`, both request-log formatters call `redact_watermark_secrets` on every field of the request, and only drop the skipped fields afterwards. Redaction makes a recursive copy of each value, so every logged request copies its whole `input_ids` list. Levels 0 and 1 never print `input_ids`, so that copy is wasted, and the cost grows with prompt length.

## Modifications

The skipped fields are now dropped before redaction, in both `_transform_data_for_logging` and `_dataclass_to_string_truncated`.

The log output stays the same. Redaction treats each field on its own, and the fields that are no longer redacted are the ones that were being dropped anyway.

## Accuracy Tests

N/A. This PR only changes the logging path. The benchmark below also checks that the log lines from main and from this PR are identical (same md5, timestamp excluded), and that the watermark key still shows up as `<redacted>`.

## Speed Tests and Profiling

The benchmark uses `--log-requests-level 1` and logs one received request plus one finished request. The input is a `GenerateReqInput` with a watermark key. CPU only.

| format | `input_ids` length | main (ms) | PR (ms) | speedup |
|---|---:|---:|---:|---:|
| json | 1024 | 2.018 | 0.516 | 3.9x |
| json | 8192 | 12.377 | 0.520 | 23.8x |
| json | 32768 | 47.798 | 0.513 | 93.2x |
| text | 1024 | 1.936 | 0.479 | 4.0x |
| text | 8192 | 12.008 | 0.480 | 25.0x |
| text | 32768 | 46.569 | 0.479 | 97.2x |

Absolute times depend on the machine. The trend does not: on main the cost grows linearly with `input_ids` length, and on this PR it is constant. Levels 2 and 3 skip no fields, so this change does not affect them.

<summary>Benchmark script</summary>

```python
# RequestLogger cost vs. input length. Run on main and on this branch.
import hashlib
import json
import logging
import timeit

from sglang.srt.managers.io_struct import GenerateReqInput
from sglang.srt.utils.request_logger import RequestLogger


class Capture(logging.Handler):
    def emit(self, record):
        self.line = record.getMessage()


for fmt in ("json", "text"):
    request_logger = RequestLogger(True, 1, fmt, None)
    capture = Capture()
    for target in request_logger.targets:
        target.handlers, target.propagate = [capture], False
    for n in (1024, 8192, 32768):
        req = GenerateReqInput(
            input_ids=list(range(n)),
            sampling_params={"max_new_tokens": 16, "watermark": {"key": "secret"}},
            rid="rid-0",
        )
        out = {
            "text": "x" * 64,
            "output_ids": list(range(256)),
            "meta_info": {"id": "rid-0"},
        }

        def log():
            request_logger.log_received_request(req)
            request_logger.log_finished_request(req, out)

        ms = min(timeit.repeat(log, number=50, repeat=5)) / 50 * 1e3
        line = capture.line
        if fmt == "json":
            line = json.dumps(
                {k: v for k, v in json.loads(line).items() if k != "timestamp"}
            )
        assert "secret" not in line and "<redacted>" in line
        print(
            f"{fmt} input_len={n} ms={ms:.3f} md5={hashlib.md5(line.encode()).hexdigest()[:12]}"
        )
```
