# [Fix] sgl-kernel: bump sgl-attn to pick up FP8 two-level accumulation

[Upstream PR](https://github.com/sgl-project/sglang/pull/46770) · state: closed · merged: True

## Original PR description

## Motivation

Pick up sgl-project/sgl-flash-attn#51 (two-level accumulation for SM90 FP8 forward) in sgl-kernel's FA3 build. Without it, the FP8 KV path on Hopper accumulates P@V in the tensor core's reduced-precision FP8 accumulator and long-context outputs degrade; see that PR for details.

## Modifications

Bump the `repo-flash-attention` FetchContent pin in `python/sglang/kernels/aot/CMakeLists.txt` from f89bc230 to 141fa063, the current head of sgl-flash-attn's `sgl-kernel` branch, and update the archive SHA-256. 141fa063 is f89bc230 plus that one commit, which only changes `hopper/utils.h`.

## Checklist

- The new archive differs from the old one only in `hopper/utils.h`.
- The patched FA3 was validated in sgl-flash-attn#51: sgl-kernel's `tests/test_flash_attention.py` with FP8 cases enabled passes 2017/2017 on H100, and BF16/FP16 instantiations compile to identical SASS.
