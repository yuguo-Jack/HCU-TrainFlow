# [Test] [XPU] kv_canary: Make kernel tests device-agnostic and run them on XPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/46775) · state: open · merged: False

## Original PR description

## Motivation
The kv_canary kernel tests hard-code `torch.device("cuda")` and `torch.cuda.synchronize()`, so they fail on XPU with `Torch not compiled with CUDA enabled`.

## Modifications
- `test/registered/kernels/ops/kv_canary/*` and the `_fixtures` / `_differential` helpers now get the device from `get_device()` and synchronize through `get_device_module()`.
- Registered the kv_canary kernel tests on the XPU suite `stage-b-test-1-gpu-xpu`.
- `test_disabled_assert_inputs_passes_none_to_cuda` now skips on devices other than CUDA, since it only covers the CUDA JIT launch path.

On XPU the kernels run their byte-equal torch reference (`kv_canary._dispatch`), so these tests cover the XPU launch path. CUDA behavior is unchanged.
