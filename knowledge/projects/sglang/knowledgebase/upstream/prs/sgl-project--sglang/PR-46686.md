# [CI] [AMD] diffusion: Skip the CUDA-only Nomas fused-kernel and FlexAttention unit tests on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/46686) · state: closed · merged: True

## Original PR description

## What

Three tests in `test_nomas.py` are skipped only when `torch.cuda.is_available()` is False, and that is also True on ROCm. They now also require `current_platform.is_cuda()`, so they skip on ROCm and still run on NVIDIA:

- `test_fused_qk_norm_rope_and_modulate_cast_are_bitwise_exact` and `test_pixelumm_fused_norm_and_swiglu_are_bitwise_exact` assert that the `torch.compile(..., emulate_precision_casts=True)` helpers match eager output bit for bit. On ROCm, the Inductor kernels round differently, and `torch.equal` returns False.
- `test_growing_history_across_twelve_segments` uses the FlexAttention backend. On ROCm, compiling `create_block_mask` with dynamic shapes in `nomas_kv_cache.py` fails with `InductorError: AssertionError: failed to set ranges [s55, s55]`.

The other `test_nomas.py` tests, including the CPU/SDPA reference cases, still run on ROCm.

## Why

The file was added in #46124. On the AMD `multimodal-gen-test-1-gpu-amd` stage, it has failed on every run since then, with the same three tests failing on both pytest attempts:

- rocm10: https://github.com/sgl-project/sglang/actions/runs/40250572724/job/121341392522
- rocm10: https://github.com/sgl-project/sglang/actions/runs/40192619249/job/121166713508
- rocm724: https://github.com/sgl-project/sglang/actions/runs/40217267267/job/121241063976

## Test plan

- [x] `python -m py_compile` on the changed file.
- [x] Passed on MI300 (rocm10) in a dispatched `multimodal-gen-test-1-gpu-amd` run on this commit: https://github.com/sgl-project/sglang/actions/runs/40426111669/job/121932306506 (partition 1: `test_nomas.py` 31 passed, 4 skipped including the three gated tests, 0 failed). Partition 0's two failures are in `test_vae_tiled_decode_groups.py` and unrelated to this change.
- No behavior change on CUDA: when `current_platform.is_cuda()` is True, the skip condition is unchanged.
