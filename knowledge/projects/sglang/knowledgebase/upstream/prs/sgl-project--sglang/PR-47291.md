# [Feat] diffusion: add Physis H3 causal pipelines

[Upstream PR](https://github.com/sgl-project/sglang/pull/47291) · state: open · merged: False

## Original PR description

## Motivation

Add support for `Physis-AI/physisserve-minimaxh3_33b-same_step-ls-dev` in SGLang, including offline generation and HTTP serving with Ulysses, timestep pipelining, and block pipelining.

## Modifications

- Add a Physis H3 pipeline using SGLang's native H3 DiT and Qwen3-VL text encoder, with the Diffusers H3 VAE.
- Implement the checkpoint's four-step sampling schedule, same-step noisy KV history, near-clean attention sink, and configurable joint bootstrap.
- Add two causal pipeline modes:
  - `timestep`: assign complete denoising steps to GPUs.
  - `block`: partition the ordered sequence of denoising steps and transformer blocks across GPUs.
- Integrate causal pipeline configuration, request dispatch, and worker failure handling with the existing runtime.
- Add an offline generation example, usage documentation, and regression tests.

Pipeline modes use static, single-request placement, with one dedicated GPU for text encoding and VAE decoding. DiT weights are replicated across denoising GPUs. The complete latent sequence is decoded into a video after denoising.

The default bootstrap jointly denoises five opening latents. Setting `--bootstrap-chunks 1` may cause flicker in the opening frames.

- Resolution: 1344 × 768
- Frames: 158
- Frame rate: 24 FPS

The visual comparison includes the official PhysisServe implementation and SGLang's Ulysses, timestep, and block modes.

## Speed Tests and Profiling

Hardware: NVIDIA H200.

Generation latency was measured after two warmup runs, using the same prompt, seed, resolution, and frame count.

| Implementation | GPUs | Latency |
| --- | ---: | ---: |
| Official PhysisServe | 8 | 45.08 s |
| SGLang Ulysses | 8 | 24.36 s |
| SGLang TPP | 5 | 26.74 s |
| SGLang block (Physis) | 8 | 21.08 s |

TPP uses four denoising GPUs and one text-encoder/VAE GPU. Block mode uses seven denoising GPUs and one text-encoder/VAE GPU.
