# docs: add Clef accuracy results to the deployment wizard

[Upstream PR](https://github.com/sgl-project/sglang/pull/43349) · state: closed · merged: True

## Original PR description

## Motivation

Show measured Clef and Clef Flash accuracy in the deployment wizard and replace the long validation note with a concise results table.

## Modifications

Remove the note above the model introduction. Add H200, B200, and B300 results to the wizard’s existing Benchmark / Accuracy card, matched to the selected model variant and GPU. Keep the cross-GPU table alongside Cloudflare’s reported scores. Each card identifies Decision Index 0.2.1 and the request count.

## Accuracy Tests

Decision Index 0.2.1, all 1,319 GSM8K test problems in both four-choice and ten-choice formats: 2,638 requests per model/GPU configuration. All 15,828 evaluation requests succeeded. Scores were independently recounted from saved predictions.

| Model | Reported | H200 | B200 | B300 |
|---|---:|---:|---:|---:|
| Clef | 80.8% | 80.71% | 80.59% | 80.59% |
| Clef Flash | 67.3% | 67.32% | 67.36% | 67.36% |

All runs used BF16, TP=1, and the three-flag serving commands. These are Decision Index’s multiple-choice GSM8K scores.

All six wizard selections were checked in the browser, including selection persistence after reload. Every displayed score matches the saved evaluation results. Cookbook config validation, scoped pre-commit, Mintlify build validation, and Mintlify link checks passed.

## Speed Tests and Profiling

No performance measurements; documentation only.
