# [Perf] DeepSeek chat templates: concatenate tool text once instead of per-tool

[Upstream PR](https://github.com/sgl-project/sglang/pull/47007) · state: open · merged: False

## Original PR description

## Motivation

The DeepSeek example chat templates append each rendered tool to a growing namespace string:

```jinja
{% set tool_ns.text = tool_ns.text + '...' + (tool | tojson) + '...' %}
```

Each iteration copies the accumulated text, so rendering T tools costs O(T × prompt_bytes) in string copies. Measured with 177 medium tool schemas (~500 KB tool JSON, median of 7 batches, Xeon 8124M):

| Template | before | after | saved |
|---|---:|---:|---:|
| tool_chat_template_deepseekv3 | 46.7 ms | 7.2 ms | 39.5 ms |
| tool_chat_template_deepseekr1 | 49.9 ms | 7.0 ms | 42.9 ms |
| tool_chat_template_deepseekv31 | 23.2 ms | 7.8 ms | 15.4 ms |
| tool_chat_template_deepseekv32 | 22.6 ms | 7.7 ms | 14.8 ms |

Remaining cost is the 177 `tojson` calls (~5 ms) plus Jinja overhead; T=1 shows no regression.

## Fix

Collect the per-tool text in a block `{% set %}` and concatenate once. The per-tool expression is unchanged and evaluated in the same order, and Jinja emits the captured characters as-is, so the rendered prompt is byte-identical — including error behavior (`TypeError`/`UndefinedError` from the same expression either way, feeding the same client-error path).

## Verification

- Byte-identity harness compiling original and rewritten templates with transformers' own `_compile_jinja_template`: **1,664 template×case outcomes identical** (607 renders + 1,057 matching error pairs) plus **1,600 fuzz renders** byte-identical. Cases: tools None/[]/undefined, unicode/CJK/emoji/lone surrogates/NUL, shuffled key order, 60-level nested `$defs`/`$ref` schemas, description None/missing, non-string names, multi-turn with message-embedded tools, assistant tool_calls, 400 malformed tool lists. Negative control (removing one whitespace-control `-`) is detected as a 2-byte diff.
- `test/manual/test_deepseek_chat_templates.py`: 4 passed, 12 subtests.
- `pre-commit run --files`: all hooks pass.

No committed unit test: the change is behavior-preserving by construction, so a regression test would have to time renders (flaky) or mirror template output (pins nothing). The byte-identity evidence is in this PR body.
