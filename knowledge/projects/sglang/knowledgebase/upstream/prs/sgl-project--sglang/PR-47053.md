# [Doc] kimi-k3: Convert the cookbook page's pipe tables to JSX tables

[Upstream PR](https://github.com/sgl-project/sglang/pull/47053) · state: closed · merged: True

## Original PR description

## Motivation

The Kimi-K3 cookbook page uses 8 markdown pipe tables. The cookbook review checklist (`cookbook-review-pr`, section 9b) forbids markdown pipe tables, and the Mintlify authoring reference asks for JSX `<table>`, as on the DeepSeek-V4 page.

## Modifications

- Convert all 8 pipe tables on `docs/cookbook/autoregressive/Moonshotai/Kimi-K3.mdx` to the JSX table style of the DeepSeek-V4 page: column widths, alternating column shading, left alignment as before, and code spans, bold text and links turned into `<code>`, `<strong>` and `<a>`.
- No wording changes. All 116 cells have the same text as before (checked by comparing each cell after stripping formatting).

Note: #41794 edits two rows of the AMD ROCm/AITER environment table on this page. Whichever PR merges second needs a small rebase.
