# [Fix] attention: Restore block pointers on Triton 3.9 for FLA kernels (cherry-pick #45470)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47939) · state: open · merged: False

## Original PR description

Cherry-pick of #45470 to `amd_march`. Triton 3.9 removed `tl.make_block_ptr` / `tl.advance`, so the FLA kernels (Qwen3.5, Qwen3-Next, Kimi linear attention) fail to compile; this adds the compatibility shim from `main`, which does nothing on Triton 3.8 and older.
