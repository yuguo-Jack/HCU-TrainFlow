# fix(kimi-k3): validate native output and propagate terminal failures

[Upstream PR](https://github.com/sgl-project/sglang/pull/45757) · state: open · merged: False

## Original PR description

Malformed Kimi K3 native headers can be consumed by reasoning parsing or fall through as ordinary text while a valid call is also extracted. Missing channel closures, duplicate arguments and invalid typed values can likewise lead to a successful terminal.

Use a shared incremental native validator and a raw-header guard. Validate declared tool names before their deltas, preserve early string-argument delivery and literal markers inside raw strings/quoted JSON, and release typed JSON only after validation. Restore a trimmed tools-close suffix only when finish metadata proves it was generated. Propagate failures through Chat and Responses without a successful terminal; preserve known length-limit semantics. The Responses adaptation retains main's token-output adapter.

Validation: 529 targeted CPU tests and 158 subtests pass against main ce66b3ab5935feea3a92935700669a9b8baba131; repository commit hooks pass. The raw header guard also tracks response/message boundaries that reasoning cleanup strips before the tool parser runs: an unclosed response before a valid tools section or at stop now fails with the native output error in Chat and Responses instead of reporting a successful call. Length-cut calls now keep an empty-string expected-arguments sentinel until native call-close validation, preventing terminal flush from fabricating `{}`. Actual Chat streaming tests cover 72 cases across auto/required/named, first/second-call truncation, incremental/cumulative output and reasoning on/off. Tests also cover all character splits, malformed headers, partial second calls, typed JSON, duplicates, early streaming, stop restoration, actual serving terminals and token-adapter forwarding.

A previous v0.5.22 candidate passed a small isolated B300 replay (10 baseline + 10 candidate). This head adds early-delivery compatibility and current-main adaptation and has NOT had a new GPU run. Historical malformed generation/no-call was not reproduced; this change validates output integrity and does not claim to repair model generation. Private requests/native captures are excluded.
