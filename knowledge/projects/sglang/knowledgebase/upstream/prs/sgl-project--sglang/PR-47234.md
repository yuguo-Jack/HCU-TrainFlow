# [Feat] attention: Add OOT linear-attention backend registration

[Upstream PR](https://github.com/sgl-project/sglang/pull/47234) · state: closed · merged: True

## Original PR description

## Motivation

The attention registry constructs GDN and KDA backends directly, leaving out-of-tree (OOT) providers without an explicit way to supply alternative implementations. This PR adds backend-factory registration so providers can extend backend selection without patching constructors or kernel methods.

## Changes

- Add platform-keyed OOT backend registration to the attention registry. Registered factories are selected before backend construction.
- Support GDN, KDA, and backends selected through `LinearAttnModelSpec`. Registrations match exact fully qualified class names; unregistered custom subclasses retain their original implementation.
- Add overridable dispatcher builders to GDN and KDA. Provider subclasses can supply their kernels while reusing upstream initialization, cache management, and forward-metadata handling.

In-tree platforms and unregistered backends retain the existing selection policy. This PR does not change kernel implementations or arithmetic.

## Testing

- 50 registry, GDN/KDA, and configuration-policy tests passed. Registry coverage exercises the public hybrid-backend wrapper, registered model backends, and fallback behavior.
- End-to-end OOT integration passed Qwen offline inference, Kimi Linear smoke testing, and the full 1,319-question GSM8K evaluation.
- Repository-selected Ruff checks, formatting, isort, and codespell passed.

GPU numerical suites were not independently rerun.
