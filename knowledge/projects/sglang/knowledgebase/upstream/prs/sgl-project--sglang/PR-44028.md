# [DSV41] Engram precompute on GPU

## Motivation

Issue #42170 and #39700. Currently, all the hash token ids input to engram are computed at the beginning. But engram table lookup, wkv projection, collective communication are all computed in each engram layer in an ad-hoc manner, which can be performed in advance and be overlapped with mhc/attention because none of them depends on the hidden states of previous layer.

## Modifications

1. Do the prefetch (including engram gather, collectives and wkv proj) of layer N in advance and overlap the prefetch with mhc and attention.
2. Add EngramPrefetcher to produce and consume the engram kv.
3. Add moe_fence to sync megamoe with the prefetch results. Only after prefetch megamoe can be started because megamoe has num_sm requirements and cannot be overlapped with prefetch. (Currently only megamoe backend is tested. TPMoE and EPMoE should be ok but hasn't been tested. Will test them later and post the results).
4. The engram prefetch on device is only enabled for decode and target verify.
