# [AMD] Run the MiniMax indexer CP test on MI35X, not MI300

[Upstream PR](https://github.com/sgl-project/sglang/pull/43259) · state: closed · merged: True

## Original PR description

## Motivation

`test/registered/amd/test_minimax_indexer_cp.py` (added in #41488) has failed on every `stage-b-test-1-gpu-small-amd` MI300 run since it landed, as @bingxche reported on #41488 ([first failure](https://github.com/sgl-project/sglang/actions/runs/36951042978/job/110670268955), [still failing 2026-10-08](https://github.com/sgl-project/sglang/actions/runs/37709475489/job/113091796233)):

```
triton.runtime.errors.OutOfResources: out of resource: shared memory, Required: 131072, Hardware limit: 65536.
```

The error comes from the reference side of the test: `flash_decode_with_topk_idx`'s score kernel needs 128 KB of LDS, and MI300 (gfx942) has 64 KB. Indexer CP itself is gfx950-only (`unsupported_reason` returns `"requires AMD gfx950"`), so the test belongs on MI35X anyway.

## Modifications

Register the test in `stage-b-test-1-gpu-small-amd-mi35x` instead of `stage-b-test-1-gpu-small-amd`. No code change.

## Accuracy Tests

On MI350X (gfx950):

```
python test/registered/amd/test_minimax_indexer_cp.py -f
Ran 1 test in 8.174s
OK
```

Suite collection: the file is now in `stage-b-test-1-gpu-small-amd-mi35x` and no longer in `stage-b-test-1-gpu-small-amd`; `validate_all_suites` passes.
