# feat(speculative): add EAGLE3 and DFlash support for Qwen3-Omni

[Upstream PR](https://github.com/sgl-project/sglang/pull/33051) · state: closed · merged: False

## Original PR description

## Summary

Adds EAGLE3 and DFlash speculative decoding support to two multimodal models by delegating the required hooks to their nested text backbone:

- **Qwen2-Audio** (`qwen2_audio.py`): delegate `get_embed_and_head` / `set_eagle3_layers_to_capture` (EAGLE3) and `get_input_embeddings` / `set_dflash_layers_to_capture` / `lm_head` (DFlash) to `self.language_model`
- **Qwen3-Omni** (`qwen3_omni_moe.py`): same delegation pattern, targeting `self.thinker`
- **Qwen2** (`qwen2.py`): add missing `set_dflash_layers_to_capture` method that `Qwen2Audio` and `Qwen3Omni` now delegate to

No changes to forward logic — the text backbone already threads captured aux-hidden states through its `LogitsProcessor`, so the multimodal wrappers need only expose the hook entry points.

## Performance

Measured on 1×H100, tp=1, greedy, concurrency=1. All results are lossless (no accuracy regression).

| Model | Method | Dataset | Accept len | Speedup |
|---|---|---|---|---|
| Qwen2-Audio-7B | EAGLE3 (steps=3, draft=4) | AISHELL test | 3.37 | **1.65×** |
| Qwen2-Audio-7B | DFlash block-4 (draft=4) | AISHELL test | 3.29 | **1.58×** |
| Qwen3-Omni-30B-A3B | EAGLE3 multi-domain (steps=3, draft=4) | LibriSpeech test-clean | 3.12 | **1.49×** |
| Qwen3-Omni-30B-A3B | DFlash multi-domain block-6 (draft=6) | LibriSpeech test-clean | 4.15 | **1.60×** |
