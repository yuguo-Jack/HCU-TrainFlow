# [Refactor] kernels: Register agent-generated kernels under their KDA / Cake backend

[Upstream PR](https://github.com/sgl-project/sglang/pull/45277) · state: closed · merged: True

## Original PR description

## Motivation

#45112 documented `kda_kernels/` and `cake_kernels/` as the agent-generated kernel backends. But 5 specs whose implementation lives in those directories were registered under their language or library backend, so filtering the registry by backend missed them:

| op | backend before | implementation |
|---|---|---|
| `attention.kda_qwen38_qsa_sm121` | `TRITON` | `kda_kernels/qwen38_qsa_sm121` |
| `diffusion.layernorm_modulate` | `TRITON` | `kda_kernels/layernorm_modulate_triton` |
| `diffusion.qk_head_layernorm` | `TRITON` | `kda_kernels/layernorm_modulate_triton` |
| `diffusion.scale_residual_norm_scale_shift_nvfp4` | `JIT` | `kda_kernels/norm_scale_shift_jit` |
| `sampling.softmax` | `FLASHINFER` | `cake_kernels/sampling` (there was no Cake backend value) |

## Modifications

- **New backend:** add `KernelBackend.CAKE`, with its `forward_cake` stub, method mapping and default-priority slot. No op implements `forward_cake`, so auto-selection is unchanged.
- **Re-register the 5 specs** under `KDA` / `CAKE`. The two facade calls that pin a backend for an exact lookup now use the new value: `qwen38_qsa_sm121_varlen` → `KDA`, `cake_softmax` → `CAKE`.
- **README:** list the agent kernels by backend, which replaces the target-prefix workaround.
- **Guard test:** `test_agent_kernels_register_their_backend` checks that a spec targets `kda_kernels/` or `cake_kernels/` exactly when it is registered as `KDA` or `CAKE`.

Only registry metadata changes; dispatch is unchanged.

## Validation

- `test_kernels_namespace.py` and `test_fused_op.py`:
  - main: 106 passed.
  - this PR: 108 passed. The two new cases are the guard test and the `CAKE` case in the forced-backend stub test.
- The two pinned lookups resolve to the same callables as before (`cake_kernels.sampling.softmax`, `kda_kernels.qwen38_qsa_sm121`).
- Filtering by backend now lists all 15 agent kernels: 14 KDA and 1 Cake.
