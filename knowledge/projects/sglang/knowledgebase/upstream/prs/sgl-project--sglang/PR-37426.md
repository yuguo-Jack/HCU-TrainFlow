# [CI][Diffusion] Add caching for npu GT images in CI

[Upstream PR](https://github.com/sgl-project/sglang/pull/37426) · state: open · merged: False

## Original PR description

## Motivation

The NPU diffusion consistency tests download ground-truth images one file at a
time from `raw.githubusercontent.com` while the suite runs, and nothing is
cached between jobs, partitions, or retries.

This fetches the pinned ascend GT directory once per runner, caches it per
revision, and points the existing `SGLANG_CONSISTENCY_GT_DIR` hook at it, so the
tests read ground truth from disk.

## Modifications

**`scripts/ci/utils/diffusion/prefetch_consistency_gt.py`** 

- Resolves the repository, pinned revision and subdirectory from the same
  constants the tests read (`SGL_TEST_FILES_CI_DATA_REPO`,
  `SGL_TEST_FILES_CI_DATA_REVISION`, `SGL_TEST_FILES_CONSISTENCY_GT_BASE`), so
  the pinned SHA is never duplicated into the workflow.
- Fetches only `diffusion-ci/consistency_gt/sglang_generated/ascend`.
  Falls back to the repository tarball with a filtered extract when
  `git ls-remote` fails.
- Caches per revision at `~/.cache/sglang/consistency-gt/<sha>/`. The
  `.complete` marker is written last and installed by an atomic rename.
- Verifies, before any model loads, that every consistency-checked NPU case can
  find its ground truth — using the tests' own `gt_exists`, so the lookup rules
  are not reimplemented.
- Prunes revisions unused for 14 days.
- Exports `SGLANG_CONSISTENCY_GT_DIR` through `$GITHUB_ENV`.

**`.github/workflows/pr-test-npu.yml`** — adds a "Prefetch consistency GT" step
to `multimodal-gen-test-1-npu-a3` and `multimodal-gen-test-2-npu-a3`, between
dependency install and the test run. The test step itself is unchanged.

**`python/sglang/multimodal_gen/test/server/ascend/testcase_configs_npu.py`** —
comments recording that consistency-checked cases are mirrored in
`CONSISTENCY_CASES` in the prefetch script, and must be kept in step.

- OrangeRedeng · comment · 2026-10-08T21:34:40Z · [source](https://github.com/sgl-project/sglang/pull/37426#discussion_r4224369759)

File: `scripts/ci/utils/diffusion/prefetch_consistency_gt.py` · line 271

**Avoid deleting downloads that are still in progress**
A directory without _.complete_ may still be downloading - the marker is only added at the end. If one partition finishes while another is still fetching GT, this loop deletes the other partition’s temporary directory, even with the 14-day retention setting. That can fail its prefetch step.
Could we skip active temporary directories here and clean up abandoned downloads separately?

- Allor-maker · comment · 2026-10-09T12:35:04Z · [source](https://github.com/sgl-project/sglang/pull/37426#discussion_r4230138753)

File: `scripts/ci/utils/diffusion/prefetch_consistency_gt.py` · line 271

Fixed that. `.tmp.` directories are now handled separately and judged by
age instead of the marker, it's written last, so it can't tell an in-flight
fetch from an abandoned one: younger than an hour is skipped, older is removed
as abandoned (the script's own timeouts cap a fetch at ~15 min). Installed
revision dirs keep the marker and `--keep-days` rule.
