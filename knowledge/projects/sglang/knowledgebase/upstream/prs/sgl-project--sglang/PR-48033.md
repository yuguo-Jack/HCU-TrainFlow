# [Feat] embedding: Add Cohere-compatible /v2/embed API

[Upstream PR](https://github.com/sgl-project/sglang/pull/48033) · state: open · merged: False

## Original PR description

## Motivation

Clients using the Cohere-style embedding API cannot currently call `POST /v2/embed` on SGLang. Add the embedding contract used by vLLM v0.32.0 and route requests through SGLang's existing embedding inference and pooling pipeline.

## Modifications

- Add Cohere-compatible `POST /v2/embed`, reusing SGLang's existing embedding inference and pooling pipeline.
- Adapt text, image, and mixed requests, including task prompts, input truncation, output dimensions, and embedding formats.
- Add unit tests and GPU end-to-end checks with existing embedding models.

### Draft scope and remaining validation

This PR adds the API adapter; it does not add Nemotron model implementations. Real image-model inference and Nemotron 3.5 1B/8B HF-reference validation remain pending model integration. Live vLLM differential testing and performance benchmarking have not been run.

Embedding requests do not yet support encoder/language disaggregation (EPD). Multimodal truncation supports safe text-tail trimming and rejects removal of media tokens, actual START trimming, or unsupported positional metadata. LoRA and priority tests cover parameter forwarding, not adapter loading or scheduling order.

## Accuracy Tests

Tested implementation commit: `33571ee3aa5121eecc7c1cd0239fa9a7e100a1cc`. The subsequent commit changes documentation only.

- 88 unit tests and 118 subtests passed, covering request validation, adaptation, output encoding, truncation, processor tokenization, and HTTP behavior.
- 9 GPU integration tests and 10 subtests passed on NVIDIA GB200 with `Alibaba-NLP/gte-Qwen2-1.5B-instruct` and `Qwen/Qwen3-Embedding-0.6B`.

GPU checks compare `/v2/embed` with `/v1/embeddings` using `atol=rtol=1e-5`; these verify API consistency, not independent HF reference accuracy. The Qwen3 128-dimensional test explicitly enables Matryoshka in the test configuration.

GPU reproduction on a supported inference host:

```bash
python -m pytest -q test/registered/prefill_only/test_cohere_embedding.py
```

Documentation validation: `mint validate`, `mint broken-links`, and applicable pre-commit checks passed. The site build reports six warnings in other existing pages; none concern the new page.

## Speed Tests and Profiling

Not benchmarked. This change reuses the existing model forward and pooler; it adds API preprocessing, truncation, and response conversion.
