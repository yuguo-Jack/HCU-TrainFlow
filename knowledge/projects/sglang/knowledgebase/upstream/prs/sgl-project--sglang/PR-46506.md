## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111, #45311, #45513, #45749, #46005) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Adds the section to the MiniMax-M3.1 page** (`MiniMax/MiniMax-M3.1`, which deploys `MiniMaxAI/MiniMax-M3.1-Flash`). It covers the NVIDIA SGLang AgentX lanes on GB300, GB200, B300 and B200. The Deployment panel gets the `agenticLink` footer, as on the other pages; its content and the Playground are untouched.
2. **Syncs to InferenceX `main`** (`1c3e892a`).
3. **Overlays nine open InferenceX PRs** (table below).

**Linker config flag (#46388).** #46388 renamed `--hicache-storage-backend-extra-config` to `--unified-cache-external-linker-config` in the generated data. This sync shows the flag as SemiAnalysis launched it: the submission recipes use `--hicache-storage-backend-extra-config`, and every submission image predates `--unified-cache-external-linker-config` (added to `main` on 2026-10-25), so the renamed commands would not parse in the images shown. Current SGLang still accepts the old flag (deprecated for external linkers). `_agentx.jsx` keeps #46388's spelling in `LINKER_FLAGS` and adds the old one, so the KV-tier switch strips either.

**Flag rules added**
- Keep (serving): `--enable-nvidia-megakernel`, `SGLANG_NVIDIA_MEGAKERNEL_SLOTS`, `SGLANG_SPEC_TP_SYNC`, `--startup-weight-load-mode` ([InferenceX #4434](https://github.com/SemiAnalysisAI/InferenceX/pull/4434)); `--monokernel-backend`, `FMHA_SM100_ALLOW_JIT`, `ALLOW_JIT`, `SGLANG_FORCE_COARSE_WAR_BARRIER` (MiniMax-M3.1-Flash).
- Remove: `--enable-metrics-for-all-schedulers` (metrics only, like `--enable-metrics`); `SGLANG_SIMULATE_ACC_GREEDY` (part of synthetic acceptance, read only with `SGLANG_SIMULATE_ACC_LEN`; disclosed with it).
