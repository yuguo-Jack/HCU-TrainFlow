## Modifications

- Bounded delivery windows and configurable read/metadata-query batching.
- Opt-in native descriptor coalescing and UCX split sizing, requiring compatible KVCR support.
- Process-owned anonymous DRAM, optional huge-page advice and audited NUMA placement.
- Explicitly opt-in Python thread-switch tuning; preserve default behavior.
- Preserve source claims, sparse fallback, per-pool validation and terminal native lifetime.
- Preserve the pinned upstream positional argument ordering; append the new option separately.

The optional KVCR SDK tuning is a separate companion draft; basic HiCache enablement does not depend on it.
