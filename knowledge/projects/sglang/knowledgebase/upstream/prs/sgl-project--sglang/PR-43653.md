# [diffusion] Add the LLaDA-Image cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/43653) · state: open · merged: False

## Original PR description

## Motivation

LLaDA-Image serving has no cookbook page yet. The Supported Models catalog lists neither registered checkpoint, and the server's startup log already points users to the model's cookbook page for memory guidance.

## Changes

- Add `docs/cookbook/diffusion/inclusionAI/LLaDA-Image.mdx` with its command builder config `docs/src/snippets/configs/inclusionAI/llada-image.jsx`, following the diffusion page layout, including the ComfyUI section.
- The builder serves Base and Turbo on one GPU and pins the validated checkpoint revisions beside `--trust-remote-code`, because both checkpoints load remote configuration code.
- The builder shows the Python command, as the Ming-Image page does, and Quick start points to a nightly Docker image or a source install. Editing uploads the source image, so a Docker run needs no extra mount.
- Add a LLaDA-Image navigation group next to Ming-Image, an overview card, and a Supported Models row for `inclusionAI/LLaDA-Image` and `inclusionAI/LLaDA-Image-Turbo`, and move the NEW tag from Ming-Image to this page.
- The page builds on @Anmuliar's original cookbook draft, whose commit keeps its authorship.

## Validation

```bash Command
node docs/scripts/check_cookbook_configs.mjs
node --test docs/scripts/tests/*.test.mjs
cd docs && mint validate && mint broken-links --check-anchors --check-redirects
```

All of them pass. The builder's Serve command started both checkpoints, and its generation and edit requests and the page's Python examples returned valid 1024 by 1024 images. Sizes off the 16 or 32 pixel grid, text encoder offload, FP8 quantization, and Cache-DiT are refused with an explicit error.

## Performance

Measured on one H200 with BF16 weights at 1024 by 1024, using the builder's commands. Each cell is the median client wall time of 40 sequential requests, ten in each of four fresh server processes after two warmups.

| Task | Turbo, 4 steps, CFG 1 | Base, 50 steps, CFG 5 |
| --- | --- | --- |
| Text to image | 0.5783 s | 13.0801 s |
| Image editing | 1.4240 s | 31.3271 s |

## Accuracy Tests

Scored with BF16 weights at 1024 by 1024 using the builder's commands. GenEval uses 553 prompts with seeds 42 to 45 and its Mask2Former detector. LongText-Bench uses 160 English and 160 Chinese prompts with seeds 42 to 45 and Qwen2.5-VL-7B OCR. CVTG-2K uses 2000 prompts with seed 42 and reports OCR word accuracy. Base uses 50 steps for LongText-Bench and 20 steps for GenEval and CVTG-2K. LongText-Bench scores move by about 0.001 between evaluator runs because its OCR model samples.

| Benchmark | Turbo, 4 steps, CFG 1 | Base, CFG 5 |
| --- | --- | --- |
| GenEval | 0.8250 | 0.8361 |
| LongText English | 0.8974 | 0.9189 |
| LongText Chinese | 0.9228 | 0.9103 |
| CVTG-2K word accuracy | 0.8236 | 0.7805 |
