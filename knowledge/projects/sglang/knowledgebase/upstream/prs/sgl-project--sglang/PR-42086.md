## Motivation

Fixes #42068. A failed `/hicache/storage-backend/clear` request returns HTTP 400 but currently says the storage backend was cleared.

## Modifications

- Return a failure message when `ret.success` is false; preserve the successful response and status codes.
- Add a regression to the existing endpoint suite, whose server has hierarchical cache disabled.

`ClearHiCacheReqOutput` only exposes `success`, so this does not assume a `message` field or change the response format.
