# [diffusion] Remove unused helpers and write-only state

[Upstream PR](https://github.com/sgl-project/sglang/pull/43064) · state: closed · merged: True

## Original PR description

## Summary

Remove unused helpers, write-only state and duplicated implementations:

- USP's obsolete collective wait wrapper and its unused import, NVFP4's unused tensor-shape wrapper, and SVG2's unused kwargs checker.
- Qwen edit's unused condition-image sizing method and Qwen VAE's unused constructor-time convolution counts.
- Old Cache-DiT step-count/warmup fields; mounting still uses the complete active cache key.
- LTX's old LoRA phase field; switching still uses the active phase/strength signature.
- Unused disaggregation configuration copies and RIFE's unused resolved-path field.
- Encoder's unused mapping copy and the unused stage logging setter.
- Empty HF config registry and unreachable config reloading; standard AutoConfig registration remains supported.
- Obsolete disagg_args compatibility shim and its alias-only test; actual role/CLI definitions stay in server_args/disagg.py.
- Share spatial VAE tile geometry across tiled encode/decode and parallel tiled/patch decode, retaining independent traversal, blending and communication.
- Share SLA/SageSLA projection initialization, feature-map setup and reference linear-attention math within the existing backend module; keep sparse kernels separate.
- Share identical TP query/KV head partition rules across Llama, Qwen3, Gemma2 and Gemma3; retain model-specific projections, RoPE, QK norm and sliding attention.
- Reuse the existing linear weight allocator for ConvRot INT8 JIT and comfy backends; keep their validation, scale storage and postprocessing independent.
- Share MOVA audio/video text and time embeddings, time projection and block initialization, preserving registration order and distinct heads/patch convolutions.
- Reuse common sampling request extras for action policies without changing their fields, inheritance or action-specific request merge.
- Share Qwen-Image/JoyImage/Krea2 channelwise VAE decode normalization without changing tensor construction or reciprocal/cast order.
- Share LTX2/SANA-WM video latent normalization in the existing VAE config module.
- Inherit identical CUDA/MUSA unsupported-device methods and the default XPU communicator.
- Reuse identical ModelOpt FP8 inference dispatch while retaining separate postprocessing.
- Reuse the existing unquantized linear weight allocator for embeddings, without changing the embedding method's base class or its apply/embedding implementations.
- Unused diffusion CPU-architecture probe (the SRT implementation remains used and unchanged), plus eight obsolete test-only HTTP/port/memory/video/GT helper functions and their typing-only import.
- Uncalled post-training SP reduce, temporary logger suppression and error-formatting helpers.
- Inline the single-caller AutoConfig wrapper and remove redundant NVFP4 list forwarding.
- Share Wan/LingBot 3D sequence-shard RoPE coordinate construction in the existing NDRotaryEmbedding class, keeping their independent model-level LRU caches.
- Share identical generic/H3 latent input verification in the existing latent-preparation module, preserving H3's inheritance and noise-generation path.
- Unwired function-level Python tracing and its unused env entry. Setting the removed env emits a retirement warning; --enable-trace request tracing is unchanged.
- Superseded CLI cleanup, safetensors shard filtering, single-file NVFP4 wrapper, and unused HF helpers/context-length constant. Active file-selection and quantization paths are unchanged; SRT's same-named utilities are untouched.

- Share H3 positive-finite float validation between sampling configuration and canonical requests through the existing configuration utility module, preserving accepted inputs and error messages.

- Share 2x2 latent packing across Qwen-Image, FLUX.1 and LongCat through the existing pipeline configuration base, removing FLUX's dependency on a private Qwen helper. FLUX.2's distinct layout is unchanged.

- Share Cosmos3's QKV/output projection initialization within its existing model module; causal and cross-attention retain separate head checks, norms and execution paths.

- Reuse the existing prequantized NVFP4 GEMM implementation for the ordinary linear path's duplicated tail, preserving activation quantization, tuple opt-in rejection and output reshape.

- Share SANA-WM AdaLN modulation preparation between dense and streaming block entry points, without merging their attention, cache or FFN control flow.

- Remove thirteen unused parallel-state/communication and WebUI argument helpers. Keep process-group initialization/destruction, active DP accessors and the declared distributed exports unchanged.

- Remove unused LTX2 latent denormalization helpers, Z-Image padding inspection and the obsolete sequence-rank alias. Active decoder normalization and canonical SP accessors remain unchanged.

- Remove superseded capacity-blind disaggregation selection, its unused maximum-slot setting and kwargs plumbing, and the empty completion hook. Capacity-aware selection is now the abstract policy contract; production algorithms, counters, locks and pool routing are unchanged.

- Store disaggregation request start timestamps directly instead of allocating a private dataclass with an unused stage timestamp; preserve exported statistics, locking and formulas. Remove LTX2's unused generic coordinate wrapper while retaining the directly used video/audio methods.

- Remove forward-context batch-size timing that was permanently disabled with no configuration or caller, together with its unused globals/imports and unwritten attention-backend field/setter. Preserve active timestep, metadata, batch and nested-context restoration; request/stage observability is unchanged.

- Remove the unused pipeline JSON-export method and its exclusive imports, plus empty stage hook/offload methods with no callers or overrides. Keep CLI JSON loading and active stage load_model fallback intact.

- Remove MOVA scheduler's uncalled training target/weight and reverse-recovery methods, unused training branch/argument and write-only training state. Retain train_timesteps/train_sigmas because inference step_from_to uses their lookup tables.

- Share the validation and construction logic of MOVA's directional sequential and single-modality pair modes within their existing scheduler method, retaining each direction's tensor operation order and errors.

143 existing production files: net 1,820 lines removed, including the obsolete disaggregation shim. 109 net lines removed from existing test files, including obsolete helper definitions; one stale source reference corrected. No test cases or assertions were removed. No new files, configuration, tests, or numerical-path changes.

- Reuse offload component-name normalization for load ordering; remove its duplicate implementation without changing suffix handling or risk ranking.

- Share identical model unwrapping between Ideogram and Z-Image BCG prompt padders in their existing prompt-padding utility; preserve wrapper lookup order and the separate model-identification semantics.

- Remove six obsolete `channels_last_3d` API-existence checks in VAE loading/layout and parallel convolution. Keep device-policy gates, tensor-layout checks, conversion exceptions, and environment overrides unchanged.

- Use the public PyTorch schema-inference API directly for custom-op registration; remove the obsolete PyTorch 2.4 private fallback and a catch-and-rethrow-only AttributeError handler. Preserve duplicate-registration protection and fake implementation registration.

- Remove catch-and-rethrow-only wrappers from default weight loading and Qwen2.5-VL parameter lookup. Keep scalar filling, shape validation, extra-bias skipping, and missing-parameter errors unchanged; do not remove exclusion handlers ahead of broader recovery catches.
