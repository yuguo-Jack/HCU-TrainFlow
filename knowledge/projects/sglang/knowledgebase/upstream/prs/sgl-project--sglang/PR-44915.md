# [Refactor] linker: Share the MLA load broadcast and hit policy across direct linkers

[Upstream PR](https://github.com/sgl-project/sglang/pull/44915) · state: open · merged: False

## Original PR description

## Motivation

The Mooncake direct linker owns the MLA dedup load broadcast (plan check, per-batch prepare, ordered per-layer broadcast), and the UMBP linker owns the per-pool hit policy. A follow-up local DRAM linker needs both. This PR moves them to shared places with no behavior change.

## Modifications

- `linker_mla_dedup.py`: new `LinkerLoadBroadcast` with the logic previously inlined in `MooncakeDirectLinker` (`plans_agree`, `begin`, `broadcast_until`, `reset`, `destroy`). `MooncakeDirectLinker` now delegates to it.
- `unified_cache_linker.py`: `apply_hit_policy`, moved from `UMBPDirectLinker._apply_hit_policy`. UMBP calls the shared function.

## Accuracy Tests

No numeric change. DeepSeek-V4-Flash-FP8 TP4 linker KL test (`test_unified_cache_linker_kl_dsv4.py`) with Mooncake over TCP and `--enable-linker-mla-dedup` on 4x B300 (threshold 0.01):

| case | avg KL | loaded tokens |
|---|---|---|
| decode_cache_hit_branching | 0.0015 | 37376 |
| logprobs_match | 0.0040 | 26624 |
| prefill_cache_hit_branching | 0.0026 | 44032 |

## Tests

`test_unified_cache_linker.py`, `test_registry.py`, `test_linker_pool_assembler.py`, `test_umbp_direct_linker_rank_keys.py`, `test_server_args.py -k linker`: all pass.
