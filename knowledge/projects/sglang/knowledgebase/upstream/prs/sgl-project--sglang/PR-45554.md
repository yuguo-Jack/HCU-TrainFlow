## Original PR description

## Motivation

The Ascend DeepSeek-V4-Flash tutorial currently lists EAGLE as the speculative decoding example and does not explain DSpark Compact deployment. Update the tutorial to document DSpark and provide a Compact configuration for Ascend A3 single-node PD mixed deployment.

## Modifications

- Introduce DSpark speculative decoding and confidence-guided Compact verification.
- Replace the EAGLE feature-table example with DSpark and update the model weights to `DeepSeek-V4-Flash-0731-w8a8`.
- Update the single-node launch example for an Ascend A3 node with 16 NPU dies and TP/DP=16, using one shared script for Static and Compact modes.
- Add SPS cost-table profiling, Compact configuration, and scheduling verification instructions.
- Add accuracy, stability, and performance-comparison guidance while preserving the existing tutorial structure and reusing its verification and evaluation sections.
