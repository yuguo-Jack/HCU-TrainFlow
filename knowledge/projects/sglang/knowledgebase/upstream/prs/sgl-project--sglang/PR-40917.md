# [Refactor] memory-pool: Build KV host pools from buffer info

[Upstream PR](https://github.com/sgl-project/sglang/pull/40917) · state: closed · merged: True

## Original PR description

## Motivation

The MHA and MLA HiCache host pools took the device pool object and read its private fields (`k_buffer`, `v_buffer`, `kv_buffer`, `data_ptrs`, layer bounds, draft pools) to rebuild the buffer list, layer mapping and packed draft offsets that the device side already knows. Every new pool layout had to be taught to each host consumer separately.

Each KV device pool now exports a typed `MHABufferInfo` or `MLABufferInfo` through `get_device_pool_infos()`, and the host pools are built from that info plus explicit capacity and layer bounds. GPU host pools no longer hold a device pool reference. Packed MTP drafts are passed as their own buffer infos and checked against the target row geometry at construction. Physical layout, host capacity, transfer kernels and the L3 page format are unchanged.

This replaces the earlier declaration based approach of this PR.

Three behavior changes come with it:

- An MHA host now rejects KV scale layouts other than MXFP8 at construction. On main an FP4 KV pool gets a host that saves the packed payload without its scales, so a load back restores wrong values silently.
- Aibrix storage takes the dtype from the host pool instead of the device pool. With FP8 KV on main, an L1 write and read back through the Aibrix SDK corrupted 416 of 6656 bytes per block, while this PR returns every byte unchanged.
- Packed MTP draft layers under prefill CP layer split now map to the host row after this rank's target layers. On main the first write-through on a GLM-5.2 PD prefill worker with `--enable-dsa-cache-layer-split` and EAGLE fails with `index 78 is out of bounds for dimension 0 with size 40`.

## Modifications

- `device_pool_info.py`: `MHABufferInfo`, `MLABufferInfo`, `MLAHostAllocation`, and providers on the MHA, MLA, SWA, unified and hybrid pools.
- `pool_host/mha.py`, `mha_mxfp8.py`, `mla.py`: construct from buffer info, drop device pool reads, validate packed drafts.
- `hybrid_pool_assembler.py`, `hisparse_coordinator.py`: pass buffer info and capacity instead of the pool.
- Aibrix and TensorCast storage read the host dtype instead of the device pool.
- `test_hicache_staged_write_back_dispatch.py`: set the host fields the new constructors own on the `__new__` built MLA host.
