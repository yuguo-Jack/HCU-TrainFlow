# [Fix] dsv41: Bound MoE routing to live SWA graph-tail rows

[Upstream PR](https://github.com/sgl-project/sglang/pull/44347) · state: closed · merged: True

## Original PR description

## Motivation

During DeepSeek V4.1 bounded decoder SWA replay inside a breakable prefill graph, attention switches to the live tail while MoE can retain the full-prefill GPU row bound. A 128-row tail can therefore expose a routing bound of 16,384 rows.

## Modifications

Bind the global and local GPU routing counts to a persistent tail scalar while the late layers run. Clamp the existing count so an idle DP peer stays at zero, then restore the original CPU count and GPU tensor references on exit. Reuse the scalar across replays so captured MoE kernels retain a stable address.

This is an independent fix against main, separated from the MegaAttention integration in #43922.

## Accuracy Tests

- The same routing method implementations previously passed eight CUDA graph checks across two GB300s, covering counts 128, 7, idle 0, and 256. Those checks ran on the optimization branch; AST comparison confirms both extracted routing methods are identical here.

## Speed Tests and Profiling

A separate end-to-end throughput benefit has not been measured for this fix alone. The earlier AgentX comparison combined it with the Mega query-layout optimization. Eager tails already use compact tensors; this fix addresses the padded graph-tail path.
