# [Test] parallel_state: Run every test in the file under CI

[Upstream PR](https://github.com/sgl-project/sglang/pull/45471) · state: open · merged: False

## Original PR description

## Motivation

CI runs each registered test file as `python file.py`. `test/registered/unit/distributed/test_parallel_state.py` defines 8 tests, but its hand-written `__main__` calls only the 4 the file was written with (6 cases). Four pytest-style tests added later have never run in CI:

- `test_deterministic_reduce_scatter_preserves_input_and_selects_rank_shard` (#38160)
- `test_deterministic_reduce_scatterv_selects_rank_shard` (#38160)
- `test_nondeterministic_reduce_scatter_keeps_native_path` (#38160)
- `test_custom_allreduce_precedes_symmetric_memory_pynccl` (#35061)

They also rely on `@pytest.mark.parametrize` and the `monkeypatch` fixture, which the hand-written runner can't supply.

## Modifications

- Replace the hand-written `__main__` with `sys.exit(pytest.main([__file__]))`, the same entry point 89 other registered files use, so pytest collects every test, parametrization and fixture.
