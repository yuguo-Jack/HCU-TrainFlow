## Motivation

With top-k 1 and every draft step retained, frozen-KV MTP has a single chain. Probability ranking cannot change which nodes reach target verification, but the current path still computes full-vocabulary softmax, cumulative scores, frontier gathers, and tree ranking.

## Modifications

Select draft logits directly and construct the chain metadata without ranking. Keep the generic path for branching or pruned trees. Return contiguous metadata for the CUDA tree builder's layout contract.

Depends on #44852. Target weights and verification are unchanged; finite-precision softmax ties can resolve differently in assistant proposals.

## Accuracy Tests

Two CPU-tensor unit tests cover six configurations, including the one-step empty-parent boundary and generic-path fallbacks. A deliberate parent-index mutation makes the topology test fail. XPU serving tests and six greedy parity prompts pass.

GSM8K smoke: 82%/200, zero errors, two truncations. No quality-equivalence claim.

## Speed Tests and Profiling

Same physical Intel Arc Pro B70, TP1 BF16, context 8,192, KV capacity 32,768, max running requests 8; captured MTP with three steps/four verification tokens. Fixed 256-token OpenAI chat requests, two repeats per variant/concurrency. Controls bracket the initial candidate runs; the final contiguous-layout candidate was also measured separately.
