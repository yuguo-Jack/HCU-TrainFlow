# [Feat] [AMD] moe: Run AITER MegaMoEGfx1250 with the mori dispatch

[Upstream PR](https://github.com/sgl-project/sglang/pull/48097) · state: open · merged: False

## Original PR description

Opt-in MegaMoE on gfx1250: AITER `MegaMoEGfx1250` with the mori dispatch (bf16 wire, GEMM2 scatter fused into combine). Enable with `--moe-a2a-backend megamoe` and `SGLANG_AMD_USE_FLYDSL_MEGA_MOE=1`.

<!-- results -->
### Accuracy
GSM8K (200 questions, greedy), DeepSeek-V4-Pro: EP4 with MegaMoE 0.975.

### Performance
Setup:
- Model: DeepSeek-V4-Pro, BF16 KV cache, DSPARK speculative decoding (block 6, 1 step)
- Parallelism: EP4 (`--tp 4 --dp 4 --ep 4 --enable-dp-attention`, mori a2a)
- Step time: torch profiler on rank 0, GPU time per step; decode = 8 steps at 4 running requests (VERIFY = target verify, DRAFT = DSPARK draft), prefill = one EXTEND step of an ~8k-token prompt (TP4) / 4k (EP4)
- Comparison: with vs without this PR, same image and node, all earlier PRs of the series applied

Profiler step time (mori dispatch -> MegaMoE, `SGLANG_AMD_USE_FLYDSL_MEGA_MOE=1 --moe-a2a-backend megamoe`):

| step | without | with | change |
|---|---|---|---|
| decode VERIFY | 45.52 ms | 34.39 ms | -24.5% |
| decode DRAFT | 3.23 ms | 2.60 ms | -19.7% |
| prefill EXTEND | 323.5 ms | 311.7 ms | -3.7% |
