# [Perf] dsv41: Run the decoder tail only over the prompt's last window

[Upstream PR](https://github.com/sgl-project/sglang/pull/46152) · state: open · merged: False

## Original PR description

## Motivation

With encoder SWA bounded replay, DeepSeek-V4.1 runs the late (decoder SWA) layers only over the last 128 rows of each prefill extend. Every chunk of a long prompt pays that tail, although only the prompt's final window is ever read later. A non-final chunk's tail is mostly MegaMoE weight traffic for rows nobody reads.

## Modifications

Behind `SGLANG_OPT_DSV41_PROMPT_WINDOW_TAIL` (default off), a prefill chunk runs the tail layers only over its rows in the prompt's last window, and over its last row otherwise.
- `ForwardBatch` carries each request's remaining prompt length (`extend_prompt_rest_lens_cpu`).
- `late_layer_tail_lens` / `late_layer_tail_layout` derive tail rows and window floors from the prompt's end instead of the extend's end. Whole-extend tails (hidden-state capture, logprobs) are unchanged.
- DP late-layer row counts use the same lengths, so every reader sees one layout.
- Not applied with prefill context parallelism.

Rows inside the prompt's final window get exactly the tail of the unchunked prompt. A prompt whose last chunk is shorter than 128 tokens now computes the same tail rows as the unchunked prompt; previously its result depended on where the chunk boundaries fell.

## Benchmark

GB300, DeepSeek-V4.1-Flash, DP2 TP2 EP2 prefill, `benchmark/engine_steps/bench_engine_steps.py`. ABBA, 4 runs per arm.

| workload | off (ms/step) | on (ms/step) | change |
|---|---|---|---|
| 131K-token uncached prompts, 32K tokens/step (mostly non-final chunks) | 1249.04 | 1233.71 | -1.23% |
| 131K context, 4K uncached suffix, 32K tokens/step | 331.42 | 330.70 | -0.22% |

Accuracy with the flag on: `test_deepseek_v41_flash_gb300_dp2ep2` passes (GSM8K 0.985, MMMU-Pro 0.76). Greedy outputs are identical to flag off.

Prefill curve, GB300 DP4 TP4 EP4, 131K-token uncached prompts, B new tokens per rank per step, 3 runs per point:

| B | off (ms/step) | on (ms/step) | change |
|---|---|---|---|
| 4K | 52.85 | 51.85 | -1.90% |
| 8K | 86.42 | 82.36 | -4.70% |
| 16K | 154.83 | 151.32 | -2.27% |
| 32K | 295.20 | 293.10 | -0.71% |
| 64K | 579.63 | 578.50 | -0.20% |

With 131K contexts and a 4K uncached suffix per request, every B from 8K to 64K is within 0.1%.

## Tests

- New `test/registered/unit/layers/test_dsv41_prompt_window_tail.py` checks that any chunking of a prompt computes the unchunked prompt's tail rows and floors in its last window, plus one placeholder row per other chunk.
- Existing tail / encoder-replay unit tests pass with the flag on and off.
