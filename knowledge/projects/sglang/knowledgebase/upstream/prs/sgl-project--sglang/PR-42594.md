# [Fix] minimax-m2: Fix quadratic regex scans in the streaming tool-call parser

[Upstream PR](https://github.com/sgl-project/sglang/pull/42594) · state: open · merged: False

## Original PR description

## Motivation

`MinimaxM2Detector.parse_streaming_increment` (`minimax-m2`) re-runs two patterns over the **whole buffer on every chunk**, and both go quadratic on unclosed tags:

1. `<invoke name="([^>]+)">`: with no `>` after the name, every `<invoke name="` start scans to the end of the buffer.
2. `<parameter name="([^>]+)">(.*?)</parameter>` (`finditer`): the same for the name, and the lazy body rescans to the end from every parameter start when `</parameter>` never arrives.

| Input | Before | After |
|---|---|---|
| 126 – 128 KB, one streaming call | 8.1 – 9.3 s | ~0 |
| 31 KB stream in 64-char (multi-token) chunks | 0.58 s worst chunk, **93 s total** | ~0 |

Tool-call parsing runs synchronously on the tokenizer manager's event loop, so one such response stalls every in-flight request. (`detect_and_parse` uses alternations that always match at the first start, so it is already linear.) Found with an Atheris fuzzing harness that records per-input parse time.

## Modifications

- `_search_quoted_tag(text, prefix, close_tag=None, pos=0)`: a linear replacement for both patterns that returns the same `(name, body, match end)`. `[^>]+` cannot cross a `>`, so a start matches only if the first `>` after the name is directly preceded by `"` with a non-empty name. The next `>` is cached across consecutive starts. When the `>` or the close tag is missing after one start, it is missing after every later start too, so the scan stops there.
- New `TestMinimaxM2Detector` with a regression test (fails on `main`, passes here).

## Accuracy Tests

- Helper vs the original `search` / `finditer` on 300k random strings: identical.
- Differential test of `main` vs patched detector (20k random + 20k mutated well-formed inputs, streaming under random re-chunking and non-streaming): **0 mismatches** (8.9k produced parsed calls).
- `test/registered/unit/function_call/`: 630 passed.
