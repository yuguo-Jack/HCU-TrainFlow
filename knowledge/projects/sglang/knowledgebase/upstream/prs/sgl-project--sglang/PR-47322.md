# [CI] debug_utils: Set test_dumper nightly est_time from measured runs

[Upstream PR](https://github.com/sgl-project/sglang/pull/47322) · state: open · merged: False

## Original PR description

## Motivation

`test/registered/debug_utils/test_dumper.py` is registered for the CUDA nightly with `est_time=30`, but it takes about 6 minutes. The value was hand-set in #34186 and never refreshed: the weekly est_time update (`scripts/ci/update_est_time.py`) reads `sglang-ci-stats/model.json`, which has no nightly suites.

## Modifications

`est_time=30` → `est_time=368` in the `stage="nightly", runner_config="2-gpu-large"` registration. AMD and XPU registrations are unchanged.

## Rationale

`test_dumper.py` elapsed time from the 30 most recent Nightly Test (Nvidia) runs (Sep 1 – Oct 29, 2026), job `nightly-test-2-gpu-large (0)`, read from each job's `filename=..., elapsed=..., estimated_time=30.0` line:

| Mean (28 runs that completed the file) | **367.6** → 368 |
| Median | 367.5 |
| Min / max | 315 / 403 |
