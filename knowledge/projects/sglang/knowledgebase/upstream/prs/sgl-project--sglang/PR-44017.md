# [Feat] [XPU] GDN: support speculative decoding

[Upstream PR](https://github.com/sgl-project/sglang/pull/44017) · state: open · merged: False

## Original PR description

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

Support speculative decoding for GDN on XPU.

## Modifications

It replaces the Qwen3.5-specific fused XPU GDN route with SGLang’s shared GDN backend, using standalone SYCL kernels for conv1d and supported prefill, decode, and speculative verification phases.

It also adds XPU dispatch tests and a Qwen3.5-9B nightly NEXTN end-to-end test, and updates the existing nightly test’s descriptions.

## Accuracy Tests

Verified with Qwen3.5-9B. The outputs are the same with and without speculative decoding, configs:
- NEXTN/top-k=1
- NEXTN/top-k=2, with triton backend for full attention
- NGRAM/breadth=1

## Speed Tests and Profiling

<!-- If this pull request impacts inference speed, provide benchmarking and profiling results. -->

Qwen3.5-9B, single Intel Arc B60 GPU, input length 1024 (real natural text), output length 512, batch size 1.

| Mode            | Mean TTFT |      Mean TPOT | Mean E2E |
|-|-|-|-|
| No speculation  |   0.267 s | 40.97 ms/token |  21.20 s |
| NEXTN/top-k=1   |   0.281 s | 33.09 ms/token |  17.19 s |
| NGRAM/breadth=1 |   0.268 s | 37.95 ms/token |  19.66 s |

If larger inputs won't fit a single B60 GPU with NEXTN speculative decoding (due to draft weights).
