# [Fix] diffusion: Respect ancestor cgroup memory headroom

[Upstream PR](https://github.com/sgl-project/sglang/pull/44860) · state: open · merged: False

## Original PR description

## Motivation

Diffusion host-memory planning can overcommit pinned memory when a parent cgroup has a larger limit but less remaining headroom than the child. For example, a child using 10GiB of 32GiB under a parent using 60GiB of 64GiB has 4GiB remaining, not 22GiB. Sibling usage counts against the parent.

## Modifications

Select the ancestor with the least `max(0, limit - usage)` rather than the least numeric limit. Apply the existing file-cache exclusion before comparison. Extend the existing budget tests with four v1/v2 cases, including cache-adjusted headroom.
