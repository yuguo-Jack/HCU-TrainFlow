# [CI] [AMD] pr-test: Run stage-c-test-large-8-gpu-amd as one job

[Upstream PR](https://github.com/sgl-project/sglang/pull/47151) · state: closed · merged: True

## Original PR description

## What

`stage-c-test-large-8-gpu-amd` runs as 1 job instead of 2.

## Why

#46708 moved the large-model tests (DeepSeek-V3 basic/MTP, MoRI-EP) out of this suite to nightly. What's left is two 8-GPU collective tests, `test_aiter_allreduce_fusion_amd` and `test_aiter_allgather_amd`, about 7 min together. With two shards, every PR run paid for two 8-GPU MI300 container setups and RCCL checks to run 3–4 min of tests each. This saves one 8-GPU MI300 job per PR run, about 8 min × 8 GPUs.

`test_aiter_allreduce_fusion_amd` needs 8 GPUs, so the job stays on the 8-GPU pool.
