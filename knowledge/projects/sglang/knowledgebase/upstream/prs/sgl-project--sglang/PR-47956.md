**[P1] Extract the draft text config before reading attention dimensions**

`get_config()` returns the full Hugging Face config, but composite draft configs such as `Qwen3_5Config` store `head_dim`, `hidden_size`, and `num_attention_heads` under `text_config`. With XPU, inherited `intel_xpu` attention, and no explicit draft attention backend, this new check raises before draft initialization—even when the actual text head dimension is supported.

I reproduced this using a locally saved `Qwen3_5Config` and the real `get_config()` loader: the text head dimension is 256, but this expression raises `AttributeError: 'Qwen3_5Config' object has no attribute 'hidden_size'`.

Please extract the text config with `get_hf_text_config()` before calculating the head dimension, and add a composite-config regression test. The current tests only cover flat configs.
