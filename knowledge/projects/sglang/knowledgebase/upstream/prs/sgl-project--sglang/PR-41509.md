# fix(hicache): reject buffer-only write-back at runtime

[Upstream PR](https://github.com/sgl-project/sglang/pull/41509) · state: closed · merged: False

## Original PR description

## Summary

Startup validation already rejects HiCache `buffer_only` host memory with the `write_back` policy, because buffer-only host memory is transient and cannot retain deferred writes. Runtime storage attachment accepted the same incompatible combination.

Reject `buffer_only + write_back` at the beginning of runtime attachment, before policy mutation or storage-controller calls. The regression test covers both a fresh attach and a same-backend policy update and verifies that neither path has side effects.
