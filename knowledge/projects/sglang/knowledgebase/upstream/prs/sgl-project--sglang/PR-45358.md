# [Fix] srt: Replace bare except: with except Exception:

[Upstream PR](https://github.com/sgl-project/sglang/pull/45358) · state: open · merged: False

## Original PR description

Bare `except:` swallows `KeyboardInterrupt` and `SystemExit`, making it impossible to interrupt with Ctrl+C. PEP 8 explicitly recommends against bare `except:` for this reason.

Changed `except:` to `except Exception:` in 11 parsing/serialization fallback paths (5 files):
- `function_call/step3_detector.py` (2 sites)
- `function_call/llama32_detector.py` (3 sites)
- `observability/trace.py` (1 site)
- `entrypoints/openai/encoding_dsv32.py` (1 site)
- `utils/rpd_utils.py` (4 sites: skip-on-missing fallbacks for optional rocpd tables)

The `encoding_dsv4.py` / `encoding_dsv41.py` hunks from the original revision were dropped on rebase — #45315 removed those modules upstream.

Import-fallback and feature-probe bare `except:` sites (`protocol.py`, `minicpmo.py`, `common.py`, kernel import probes) are intentionally left alone — they need to catch any exception from a broken install or a capability probe.

After this, no unintentional bare `except:` remains in `python/sglang/srt`. No behavior change on existing inputs. `KeyboardInterrupt` and `SystemExit` now propagate instead of being swallowed.
