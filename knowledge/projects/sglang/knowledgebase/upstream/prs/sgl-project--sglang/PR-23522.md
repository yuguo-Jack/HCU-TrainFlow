## Motivation

When I was testing Qwen3.5 model using bench_one_batch_server, I saw the log print like this
<img width="2656" height="532" alt="image" src="https://github.com/user-attachments/assets/6970e550-21ad-4559-920a-ee27df8ce6c9" /> 
<img width="2144" height="674" alt="image" src="https://github.com/user-attachments/assets/0aecb2e5-cc84-4adf-b851-251aa6c09791" />

This root reason to this problem is that in [bench_one_batch_server_internal.py], launch_server_process() use "fork" to launch subprocess and try to re-reinitialized CUDA while the parent process has already initailized. This will lead to subsequent problem that ModelRegistry.get_supported_archs() can not get correct supported archs. 

## Modifications

Explicitly change the multiprocessing start method as "spawn" can solve this problem.
