# [Fix] Initialize BF16 GEMM dispatch in the one-batch benchmark

[Upstream PR](https://github.com/sgl-project/sglang/pull/43702) · state: closed · merged: True

## Original PR description

## Motivation

The one-batch benchmark bypasses scheduler initialization and initializes the MoE, FP8 and FP4 configurations without initializing BF16 GEMM dispatch. BF16 measurements can therefore use a different backend from serving.

## Modifications

Import `initialize_bf16_gemm_config` at module scope and call it from `_init_process_global_configs`, alongside the existing initializers, before loading the model. This is a two-line benchmark correctness fix, independently based on main `97bfa5cc53`.

## Validation

Repository pre-commit checks pass. Static inspection confirms the same initializer is used by the scheduler and that both benchmark modes use the shared initialization helper. No new GPU benchmark or serving validation was run. This change does not modify serving behavior or claim a throughput gain.
