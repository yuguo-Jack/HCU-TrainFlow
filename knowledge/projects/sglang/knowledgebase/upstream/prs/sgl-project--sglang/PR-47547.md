# [Perf] RL: Skip routed-expert capture on ranks that send no rows

[Upstream PR](https://github.com/sgl-project/sglang/pull/47547) · state: closed · merged: False

## Original PR description

Stacked on #47523. Only the last commit is new here.

## Why?

Without DeepEP, every TP rank computes the same top-k ids, but only the output rank (pp0 · attn-tp0 · attn-cp0) sends them. The other ranks still copied every MoE layer's ids into a device buffer that nothing reads.

```text
Before (TP8, no DeepEP)                            After
rank 0:   capture → device buffer → host → out     rank 0:   capture → device buffer → host → out
rank 1-7: capture → device buffer  (never read)    rank 1-7: skip
```

## What?

- Only the output rank allocates the routed-experts device buffer.
- Without DeepEP the other ranks skip capture. With DeepEP they still join each layer's all-gather, so the output rank doesn't hang, but they keep nothing. #47548 removes that per-layer all-gather.

## Verification?

H200, DeepSeek-V2-Lite-Chat, TP2, `--enable-return-routed-experts`, 6 prompts sent one at a time (**observed**):

```text
                        main     #47523     this PR
DeviceCache allocs        2         2          1
HostCache allocs          2         1          1
routing vs main           -     identical  identical   (bitwise, all 6 prompts)
decode, ms/token        2.93      2.93       2.91
```

## Test?

- `test_routed_experts_scattered_a2a.py::TestOutputRankHostCache`: `test_only_output_rank_keeps_rows` and `test_scattered_other_rank_only_joins_the_all_gather`. Both **observed** passing on H200 (`lmsysorg/sglang:dev`), and both fail on #47523.
- `pre-commit`: **observed** passing.
