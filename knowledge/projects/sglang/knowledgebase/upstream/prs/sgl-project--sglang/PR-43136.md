# [Perf] [AMD] DCP: Slice gathered MHA prefixes with host offsets to drop GPU syncs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43136) · state: open · merged: False

## Original PR description

## Motivation

- DCP MHA one-shot prefill gathers each request's cached prefix KV and interleaves it with that request's new-token KV.
- The old path built slice bounds from GPU `torch.cumsum` tensors; using GPU scalars as Python slice bounds forces a device-to-host sync: 4 syncs per request per MLA layer.
- On long cached prefixes (AgentX-style multi-turn) this stalls the host on every layer, although the same lengths are already on the host.

## Modifications

- `layers/dcp/comm.py`: build prefix and extend offsets on the host with `itertools.accumulate`; no GPU sync in the interleave.
- `all_gather_kv_cache_for_mha_extend` now takes `extend_seq_lens_cpu`; the unused device `seq_lens`, `extend_prefix_lens` and `extend_seq_lens` arguments are removed.
- Both callers updated: `forward_mha.py` (CUDA) and `forward_mha_rocm.py` (ROCm).
- New CPU test in `test_dcp_layout_unit.py`: request ordering, zero-length prefixes, padded extend rows.
- `test_dsv31_dcp8_gsm8k.py`: coverage note corrected; neither MHA extend path (one-shot, chunked-KV) is asserted to run.
- Outputs are unchanged: only where the offsets are computed moves.

#!/usr/bin/env python3
# Time all_gather_kv_cache_for_mha_extend alone (24 MLA layers, Kimi-K3 shapes), DCP collective excluded.
# Works on both revisions: detects the old 9-argument signature.
# Usage: PYTHONPATH=<sglang tree>/python python bench_helper.py --device 0 --revision head
import argparse
import json
import statistics
import time
from types import SimpleNamespace

import torch

from sglang.srt import runtime_context as rc
from sglang.srt.layers.dcp import all_gather_kv_cache_for_mha_extend


SCENARIOS = (
    ("agentx_avg", 4, 125_000, 512),
    ("agentx_p90", 5, 229_000, 512),
    ("shared_16k", 16, 16_384, 1_024),
    ("shared_64k", 48, 65_536, 1_024),
)
MLA_LAYERS = 24


def measure(device: int, batch: int, prefix_len: int, extend_len: int):
    torch.cuda.set_device(device)
    total_prefix = batch * prefix_len
    total_extend = batch * extend_len
    prefix_kv = torch.empty(
        (total_prefix, 1, 512), dtype=torch.bfloat16, device="cuda"
    )
