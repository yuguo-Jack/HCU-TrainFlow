# [Fix] anthropic: Preserve reasoning history for Jinja templates

[Upstream PR](https://github.com/sgl-project/sglang/pull/40965) · state: open · merged: False

## Original PR description

## Motivation

Anthropic Messages API requests can replay assistant thinking blocks into the next turn. Templates that read `message.reasoning_content` currently receive an empty reasoning channel because the adapter wraps that history into assistant content instead.

## Modifications

- Pass prior thinking as `reasoning_content` when the tokenizer chat template references that field.
- Keep custom chat encoders on the native path and preserve marker wrapping for templates that do not reference `reasoning_content`.

Fixes #40959
