# [AMD][CI] Run test_tracing.py in the extra tier, matching CUDA

[Upstream PR](https://github.com/sgl-project/sglang/pull/43928) · state: closed · merged: True

## Original PR description

## What

Move the AMD registration of `observability/test_tracing.py` from `stage-b-test-1-gpu-small-amd` to `extra-a-test-1-gpu-small-amd`. CUDA already runs this file in `extra-a` / `1-gpu-small`, so both backends now gate it in the same tier. The `backend-specific:` rationale is unchanged.

## Why

#38581 restored the AMD registration after #37436 dropped it, but put it back in the per-PR `stage-b` lane while CUDA kept it in extra. That mismatch meant the FastAPI 0.142 tracing break (fixed in #42769) failed every AMD PR, while NVIDIA PR CI stayed green because it only runs this file when `run-ci-extra` is set. This removes 113s (est_time) from `stage-b-test-1-gpu-small-amd`.
