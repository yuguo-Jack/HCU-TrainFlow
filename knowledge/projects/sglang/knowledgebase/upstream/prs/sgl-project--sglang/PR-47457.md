# [Fix] deepseek_v41: track image work after cancellation

[Upstream PR](https://github.com/sgl-project/sglang/pull/47457) · state: open · merged: False

## Original PR description

## Motivation

Stacked follow-up to #38036, preserving its admission commits and original authors. The DeepSeek supplement remains two files (+433/-2); the full PR includes the unmerged parent feature.

DeepSeek image preparation calls `asyncio.to_thread` directly, bypassing the parent's native-future tracking. If a request is cancelled while preparation is running, its reservation can be released before that work finishes.

## Changes

Track CPU and GPU preparation with the existing admission lease while keeping the default executor, ContextVars, return values, exceptions and image order. Cancellation before work starts skips the native function; cancellation after it starts retains the reservation until the function exits.

The latest main sync adopts the canonical multimodal type and modality imports while preserving admission tracking, request identity cleanup and the parent's commit history. It adds no executor pool, parallel-image feature or inference kernel. Cancelled wrappers may briefly retain argument references; this does not guarantee immediate removal from the executor queue.

## Validation

Focused CPU checks pass through the real DeepSeek processor, output types and lease. They cover queued and running cancellation, ContextVars, exceptions, submission failure and completion order. The real-image regression constructs the processor, decodes a local PNG data URL and runs PIL/Torch patchification; cancellation keeps the lease held until native work finishes, and the same processor then accepts another request.

The affected Dots, GLM, media-artifact and Llava cancellation checks also pass after the import migration. Manager checks cover admission cleanup, reused request IDs, abort-before-dispatch and main's early audio rejection. Targeted CLI/positional-field checks pass. The admission implementation and DeepSeek regression source are unchanged.

These checks use normal package imports on macOS arm64, Python 3.12 and Torch 2.15, with local tokenizer and vision fixtures. Scoped project-pinned Ruff, formatting and PR diff checks pass. Earlier broad integration and counterfactual results were reused where the code is unchanged.

There is no new HTTP serving, GPU, Rust/CUDA image-processing, checkpoint accuracy or speed result. The PR still needs #38036 to land, and official test CI requires the `run-ci` label.
