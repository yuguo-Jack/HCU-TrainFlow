## Motivation
Pipeline Parallel output communication may deadlock on NPU/HCCL backends when multiple stages post sends before their corresponding receives. This is especially problematic for PP configurations with more than two stages.

## Modifications
Add an optional SGLANG_PP_OUTPUT_VIA_CPU path that moves PP output tensors to CPU and relays them through the Gloo communication group. Intermediate stages forward the host tensors, while the receiving stage copies them back to the device for local processing. CPU-relayed outputs bypass the existing TP send/all-gather scheme and send the full replicated tensor directly.
