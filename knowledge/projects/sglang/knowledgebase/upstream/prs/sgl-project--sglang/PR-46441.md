# [Fix] mlx: Accept draft_parallel_layout in the stub's alloc_memory_pool

[Upstream PR](https://github.com/sgl-project/sglang/pull/46441) · state: closed · merged: True

## Original PR description

## Motivation

https://github.com/sgl-project/sglang/pull/46290 added `draft_parallel_layout` to `TpModelWorker.alloc_memory_pool` and forwards it to the model runner, but `MlxModelRunnerStub.alloc_memory_pool` kept the old signature, so MLX worker startup raises `TypeError: alloc_memory_pool() got an unexpected keyword argument 'draft_parallel_layout'` and `test_mlx_runner_pool_contract.py` fails on every PR. The stub now accepts the keyword, matching `ModelRunner.alloc_memory_pool`.
