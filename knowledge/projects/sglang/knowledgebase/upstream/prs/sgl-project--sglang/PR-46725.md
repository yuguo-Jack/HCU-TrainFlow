# [Fix] [MUSA] fa3: Preserve draft-extend prefix KV attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/46725) · state: open · merged: False

## Original PR description

## Motivation

The MUSA FA3 extend path currently selects paged KV-cache attention only when `extend_prefix_lens_cpu` reports a prefix or the batch is in target-verify mode.

`DRAFT_EXTEND_V2` also consumes an existing KV prefix, but that prefix is not represented by the regular extend-prefix condition. Falling through to varlen attention means the draft query can no longer attend to the cached prefix.

This is a focused upstream port of the fix proven in the MUSA `musa/0.5.16` branch. The original internal change was authored by ning.qiao, who is credited in the commit trailer.

## Modification

- Route MUSA FA3 `DRAFT_EXTEND_V2` batches through `flash_attn_with_kvcache`.
- Keep the decision in a private MUSA-only helper; no common attention, scheduler, or `ForwardMode` component is changed.
- Add CPU unit coverage for regular extend, cached-prefix extend, target verify, and draft extend.
