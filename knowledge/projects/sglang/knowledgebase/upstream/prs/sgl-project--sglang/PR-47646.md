# [Fix] kernels/jit: Correct the PDLTriggerSecondary comment on what griddepcontrol.wait covers

[Upstream PR](https://github.com/sgl-project/sglang/pull/47646) · state: closed · merged: True

## Original PR description

> (auto generated by Claude)

The comment inside `PDLTriggerSecondary` said the dependent grid's `griddepcontrol.wait` only covers writes issued before `launch_dependents`. Per the PTX ISA, `griddepcontrol.wait` waits until the prerequisite grids have completed and all their memory operations are visible, which `PDLWaitPrimary`'s comment in the same file already states. The trigger only lets the dependent be scheduled earlier; stores after it are covered too. Comment-only change; the `"memory"` clobber stays.
