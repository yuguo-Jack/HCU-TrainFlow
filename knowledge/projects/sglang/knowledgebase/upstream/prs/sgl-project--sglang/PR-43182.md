# [Feat] cp: Enable GLM-5.3 Flash interleave BCG with batched prefill and DFlash2

[Upstream PR](https://github.com/sgl-project/sglang/pull/43182) · state: closed · merged: True

## Original PR description

## Motivation

Enable breakable prefill CUDA graphs by default for GLM-5.3 Flash interleave CP, and replay captured token shapes across multiple prefix-free requests. This builds on #44022's shared CP/BCG policy.

## Changes

- Organize CP BCG helpers under `layers/cp/bcg/`: shared capture/replay code in `bcg.py`, interleave-specific support/metadata/positions/token IDs in `interleave_bcg.py`, and zigzag shard geometry in `zigzag_bcg.py`. Deduplicate common support checks, token alignment, and the capture-support wrapper.
- Register `(interleave, dsa)` for GLM-5.3 Flash with CP = TP > 1 and DP/PP/EP = 1. Keep graph defaults in the shared CUDA graph policy and honor explicit disabling.
- Keep fixed-address CP-local embeddings/positions and rank-major token IDs. KPool retains global positions; KPool and KDA graph breaks consume the live request layout.
- Admit multi-request replay based on the concatenated token count and aligned local shard capacity. Prefix-cache-hit, multimodal, and non-bucket batches still use eager CP. Draft prefill remains eager.
- Switch the registered GLM CP test to `DFLASH`, `incoai/GLM-5.3-Flash-DFlash2`, and draft attention `fa4`; inherit the default prefill capture ceiling (the 2048-limit change is handled separately in #45473), with `--mem-fraction-static 0.85`.
- Run the DFLASH draft under ordinary TP for CP targets, keeping its model, attention backend, KV pool, and KV memory budget consistent with the target's borrowed TP-sharded LM head. Preserve attention-DP isolation.
- Cover uneven multi-request token boundaries and draft DP isolation. Restore the fused draft placement test to its base version and remove the requested CP draft topology test.
