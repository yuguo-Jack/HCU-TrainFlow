# [Chore] [XPU] gguf: strip import-time warn into GGUFConfig

[Upstream PR](https://github.com/sgl-project/sglang/pull/45826) · state: closed · merged: False

## Original PR description

## Motivation

Every XPU launch printed a wall of warnings that only apply to GGUF users, making real problems easy to miss.

## Modifications

- `gguf.py`: emit the "Only CUDA, MUSA and NPU support GGUF" warning when a
  `GGUFConfig` is actually constructed instead of at import time.

## Accuracy Tests

Verified that in the following launch, GGUF warns disappears:
```bash
sglang serve \
  --trust-remote-code \
  --device xpu \
  --model-path Qwen/Qwen3.8-27B \
  --mem-fraction-static 0.85 \
  --attention-backend intel_xpu \
  --chunked-prefill-size 32768 \
  --max-prefill-tokens 32768 \
  --reasoning-parser qwen3 \
  --tool-call-parser qwen3_coder \
  --host 0.0.0.0 \
  --port 31455 \
  --disable-radix-cache \
  --linear-attn-backend intel_xpu
```
