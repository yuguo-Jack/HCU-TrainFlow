## Code Review

This pull request introduces a fused Triton kernel `fused_gate_sigmoid_mul_add` to optimize MoE shared expert gating in Qwen2, along with corresponding benchmarks and unit tests. It also updates the TRT-LLM MHA backend to support draft extend v2 with fixed shapes and registers TRTLLMHAAttnBackend in the Eagle speculative worker. The review feedback suggests several performance and safety improvements: avoiding temporary GPU allocations in the hot path of `trtllm_mha_backend.py` by using the `out` parameter in `torch.cumsum` and `torch.arange`, adding a zero-token guard and contiguity assertions to the new Triton kernel, and moving an inline import in `qwen2_moe.py` to the top of the file to reduce overhead.

Using `torch.cumsum` with `.copy_` allocates a temporary tensor on the GPU, which can be slow and trigger caching allocator overhead in the hot path. We can completely avoid this allocation by using the `out` parameter of `torch.cumsum` to write directly into the pre-allocated slice of `metadata.cu_seqlens_k`.

```python
            torch.cumsum(
                metadata.cache_seqlens_int32,
                dim=0,
                dtype=torch.int32,
                out=metadata.cu_seqlens_k[1:],
            )
```
