## Motivation

This PR enhances the SGLang Cookbook by adding the Ascend NPU (**Atlas 800I A3**) deployment scenario for **Qwen3.8-Max** (`Qwen3.8-2.4T-A95B`).

- Adds the 4-node Atlas 800I A3 PD co-located deployment recipe.
- Provides interactive command generation with required NPU environment variables, HCCL interconnect flags, and DeepEP/modelslim parameters.
- Updates the installation documentation with official Ascend Docker image guides.

Fixes / Relates to: https://github.com/Ascend/sglang/issues/1220
CC: @amote-i @Estrella-xx

**Draft: On-hardware validation is pending. This PR currently verifies local cookbook configs, selector behavior, and frontend rendering.**

## Modifications

1. `docs/src/snippets/configs/Qwen/qwen3.8.jsx`:
   - Added `"a3"` to `supportedHardware`.
   - Added `Modelslim (W4A8)` to `quantizations`.
   - Added Ascend official Docker image (`quay.io/ascend/sglang:main-cann9.0.0-a3`) to `dockerImages`.
   - Added multi-node HCCL/GLOO network interface binding hints to `multiNodeHints.a3`.
   - Added the 4-node unified PD co-located recipe under `cells[]` with best-practice configurations (W4A8 quantization via modelslim, TP64 + DP4 attention, DeepEP auto mode, overlap stream).

2. `docs/cookbook/autoregressive/Qwen/Qwen3.8.mdx`:
   - Added `<Tab title="NPU">` under the installation section with Docker pull commands and hardware prerequisites.
   - Added notes on Ascend NPU 4-node topology and referenced the detailed deployment tutorial.
