# [Perf] deep_select: use the 3-CTA tier for non-paged bf16 top-512 too

[Upstream PR](https://github.com/sgl-project/sglang/pull/48246) · state: closed · merged: True

## Original PR description

## Motivation

#47328 added a 3-CTA-per-SM config for bf16 top-512 and switches to it when it needs fewer rounds than the 2-CTA config. It is built only for the page-transform path. The non-paged ragged calls, such as the DeepSeek-V4.1 prefill indexer top-k (thousands of rows, 64K-131K columns, per-row ends and offsets), never get it.

## Modifications

- `deep_select.py`: build the 3-CTA config for every bf16 top-512 module except `sorted_index`, instead of only for `page_transform`. The C++ rounds-based switch from #47328 then picks it whenever it needs fewer rounds.
- `test_deep_select.py`: `test_denser_tier_with_end_and_offset` runs the 3-CTA config without a page table, with ragged ends and per-row output offsets.

## Accuracy Tests

- `test/registered/kernels/ops/attention/test_deep_select.py` on sm_107 (CC 10.7) with the module-level skip forced off (`is_deep_select_supported()` does not list CC 10.7): 17 passed, including the new test.
- Benchmark inputs below: the selected index sets are identical to the parent's.

## Benchmarking and Profiling

sm_107 (CC 10.7), one GPU, bf16 logits, k = 512, ragged ends, 2 calls per CUDA graph, kineto median, time relative to the parent:
