## Motivation

The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Syncs to InferenceX `main`** (`57116fff`). These merged lanes now come from their dashboard runs:
   - MiniMax-M3.1-Flash B300 SGLang (TP2 / TP4 points): [InferenceX #4726](https://github.com/SemiAnalysisAI/InferenceX/pull/4726), [run 41488743791](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41488743791), 2026-11-03. It was in progress in #47929 and is now verified.

The sync regenerates the file from InferenceX `main` and the dashboard, with the same points.
   - Overlaid in #47929 and since merged, on the same runs: Muse Spark Open B300 ([InferenceX #4725](https://github.com/SemiAnalysisAI/InferenceX/pull/4725)) and GB300 SGLang ([InferenceX #4724](https://github.com/SemiAnalysisAI/InferenceX/pull/4724)), Qwen3.8-Flash-Next B300 ([InferenceX #4683](https://github.com/SemiAnalysisAI/InferenceX/pull/4683)) and DeepSeek-V4.1-Flash GB300 SGLang ([InferenceX #4603](https://github.com/SemiAnalysisAI/InferenceX/pull/4603)).
   - PowerX re-runs, with provenance changes only (same commands): GLM-5.2 B200 Dynamo+SGLang agg / disagg ([InferenceX #4656](https://github.com/SemiAnalysisAI/InferenceX/pull/4656)), GLM-5.2 FP8 B300 SGLang ([InferenceX #4702](https://github.com/SemiAnalysisAI/InferenceX/pull/4702)) and Qwen3.8-Flash-Next GB300 ([InferenceX #4552](https://github.com/SemiAnalysisAI/InferenceX/pull/4552)), all 2026-11-03.
2. **Overlays five open InferenceX PRs:**
   - Muse Spark Open GB300 Dynamo+SGLang: retuned aggregated points and new TP8 disaggregated points.
   - Muse Spark Open B200 and GB200 SGLang, retuned per concurrency.
   - DeepSeek-V4.1-Flash GB300 Dynamo+SGLang HiCache disagg points on the `20261030` nightly.
   - MiniMax-M3.1-Flash GB200 Dynamo+SGLang config.

- **Eight new mirrored settings**, all on the Muse Spark Open GB300 Dynamo+SGLang lanes ([InferenceX #4757](https://github.com/SemiAnalysisAI/InferenceX/pull/4757)), kept as submitted:
  - `SGLANG_TRTLLM_MHA_FULL_ATTN_KV_SPLITS` and `SGLANG_TRTLLM_MHA_FULL_ATTN_KV_SPLITS_MIN_BS`: TRT-LLM MHA full-attention decode / verify kernel tuning (minimum KV splits per request and KV head, and the batch size from which it applies).
  - `SGLANG_DISAGGREGATION_QUEUE_SIZE` and `SGLANG_DISAGGREGATION_THREAD_POOL_SIZE`: PD KV-transfer queues and thread pool.
  - `SGLANG_DISAGG_PREFILL_EARLY_SEND_CACHED_PREFIX=0`: the prefill worker does not send the KV of a cached prefix ahead of the forward pass.
  - `--optimistic-prefill-attempts`: prefill forward passes that may start before the bootstrap handshake completes.
  - `DYN_ROUTER_USE_KV_EVENTS=false` and `DYN_ROUTER_TTL_SECS` (Dynamo frontend): the KV router predicts cache state from its own routing decisions instead of worker KV events, and keeps predicted blocks for that long.
- The GLM-5.3 and Qwen3.5 data change only in their shared source block (the InferenceX `main` SHA and the overlay list).
