## Accuracy Tests

<!-- If this pull request affects model outputs (e.g., changes to the kernel or model forward code), provide accuracy test results. -->

The gsm8k acc results is: 0.835. (the reference value of grok-1 is around 0.85, see: https://huggingface.co/lmzheng/grok-1, no reference value of grok-2)
```bash
# server
python -m sglang.launch_server \
  --model-path xai-org/grok-2 \
  --tokenizer-path <your_local_grok-2_path>/tokenizer.tok.json \
  --device cpu \
  --tp-size 6  \
  --trust-remote-code

# client
python -m sglang.test.run_eval \
  --eval-name gsm8k \
  --num-examples 200 \
  --num-shots 5 \
  --num-threads 1
```
