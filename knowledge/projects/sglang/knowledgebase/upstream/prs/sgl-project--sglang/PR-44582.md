# [Fix] models: Warn on unknown .bias parameter for non-GPTQ models (#44504)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44582) · state: open · merged: False

## Original PR description

### What does this PR do?

In `Qwen3_5ForCausalLM.load_weights` and `Qwen3_5ForConditionalGeneration.load_weights`, checkpoint parameters ending in `.bias` that were not in `params_dict` were unconditionally skipped via `continue` without logging any warning.

While this silent skip is intentional for extra bias tensors frequently left in GPTQ quantized checkpoints, it causes unknown or mismatched bias parameters in unquantized checkpoints or vision components (such as renamed or converted vision weights during RL training) to be silently dropped without user notification or logs.

### Changes

- Restricts the silent skip of unknown `.bias` parameters strictly to GPTQ models (and non-visual weights).
- For non-GPTQ models or visual weights, emits `logger.warning(f"Parameter {name} not found in params_dict")`, consistent with other unknown checkpoint parameters.
- Adds regression unit tests in `test/registered/unit/models/test_qwen3_5_unknown_bias_warning.py` verifying that unquantized unknown biases and visual biases trigger warnings while GPTQ extra text biases remain silent.

Fixes #44504.
