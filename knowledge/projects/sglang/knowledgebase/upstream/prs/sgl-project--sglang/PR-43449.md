# [Feature] Capture aux hidden states on the target without a speculative draft

[Upstream PR](https://github.com/sgl-project/sglang/pull/43449) · state: open · merged: False

## Original PR description

## Motivation

Auxiliary hidden-state capture is the per-layer concatenation that EAGLE3, DFLASH and DSPARK drafts consume. Today it is only reachable by loading a speculative draft; `ModelRunner` carries a `TODO: expose this to server args?` for it.

Data-generation and draft-training pipelines need these hidden states from a plain target server. Without this change they either patch SGLang or re-run the target in a separate process.

## Modifications

- **New server arguments** (`exec.features`, both off by default):
  - `--aux-hidden-state-capture {eagle3,dflash,dspark}` wires the target model's existing capture hook without a draft: `set_eagle3_layers_to_capture`, `set_dflash_layers_to_capture`, or the native `set_dspark_layers_to_capture` when the model has one.
  - `--aux-hidden-state-layer-ids` selects the layers, using the same convention as a draft config's target layer ids. It is required for dflash and dspark; eagle3 falls back to the model's default EAGLE3 layers.
- **Resolver.** `resolve_spec_aux_hidden_state_config` handles the capture-only case. It resolves no draft layer counts, so the KV pool reserves nothing for a draft.
- **DSPARK hook routing.** It moves from `spec_algorithm.is_dspark()` to the resolved config (`SpecAuxHiddenStateConfig.is_dspark`), so capture-only DSPARK picks the native hook. Behavior is unchanged for speculative runs.
- **Hidden-state capture output.** Capture then returns the aux concatenation through the existing paths (`return_hidden_states`, `--return-hidden-states-mode`). Aux capture replaces `hidden_states`, so under full capture the post-norm last-layer hidden states are kept next to it in a new `LogitsProcessorOutput.last_hidden_states`. The decode and prefill CUDA-graph runners trim it like `hidden_states`.
- **Validation.** `validate_aux_hidden_state_capture` rejects layer ids without a method, dflash/dspark without layer ids, and either option combined with `--speculative-algorithm`.
- **Docs.** Rows added to `server_arguments.mdx`.

Example (no draft loaded):

```bash
python -m sglang.launch_server --model-path Qwen/Qwen3-8B \
  --aux-hidden-state-capture dflash --aux-hidden-state-layer-ids 1 9 17 25 33 \
  --return-hidden-states-mode full
```

A request with `"return_hidden_states": true` then receives the concatenated hidden states of the five layers.

## Accuracy Tests

One GB300 (CUDA 13), image `lmsysorg/sglang:nightly-dev-cu13-20261006-f3fe7534` with SGLang main `8c273d6813` + #43448, this PR and #43450 (maocheng23/sglang `spec-capture/integration`) overlaid. The SpecForge capture plugin (sgl-project/SpecForge#945) is the consumer.

- **Against an independent forward.** Tiny Llama target (8 layers, hidden 64), `--aux-hidden-state-capture eagle3 --aux-hidden-state-layer-ids 1 3 4 --return-hidden-states-mode full`:
  - across the three gate tests (EAGLE3 and DFlash feature layouts), the aux states match a separate HF forward of the same layers within bf16 tolerance (2e-2);
  - `lm_head(last_hidden_states)` reproduces HF's logits within that tolerance;
  - one EAGLE3 training step on the captured features gives a finite loss.
- **Real model.** Qwen3.8-27B (hybrid GDN, 64 layers), TP1, `--aux-hidden-state-capture dflash --aux-hidden-state-layer-ids 5 19 33 47 61 --return-hidden-states-mode full`:
  - shapes are `[L, 25600]` (aux) and `[L, 5120]` (last hidden) for L = 7 to 4096;
  - the captured aux rows equal what this PR returns through `return_hidden_states` (max abs diff 0.0);
  - `lm_head` of the last kept hidden state picks the token the server samples greedily.
- On the GPU image, this PR's tests pass together with the #43448 and #43450 suites and `test_auxiliary_output.py` (75 passed).

## Speed Tests and Profiling

With both options off, the only change on the serving path is one attribute check per eager logits-processor call. CUDA-graph replays don't execute that Python. Nothing changes in kernels, memory or IPC.

Measured together with #43450 (see the `bench_serving` A/B there): parity with main on Qwen3.8-27B for both decode and prefill.

## Tests

`test/registered/unit/model_executor/model_runner_components/test_aux_hidden_state_capture.py` (CPU, 19 cases):
- CLI parsing and every validation rule;
- the resolved config for eagle3/dflash/dspark, including that no draft KV is reserved and draft runners never capture;
- DSPARK→DFLASH hook routing;
- a real `LogitsProcessor.forward`: full capture with the flag returns aux in `hidden_states` and the input states in `last_hidden_states`; without the flag (stock EAGLE3/DFLASH serving) and under LAST/NULL capture, `last_hidden_states` stays `None`.

Server-args registry, namespace and CLI-metadata suites pass unchanged.
