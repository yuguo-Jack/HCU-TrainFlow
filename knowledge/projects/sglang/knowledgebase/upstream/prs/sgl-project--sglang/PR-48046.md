## Motivation

The NVIDIA megakernel commit pin is duplicated in the two CUDA Dockerfiles. Move it to a dedicated file so version updates have one source of truth and future CI can detect pin changes using a file path filter.

## Modifications

- Add `docker/sgl-nvidia-mega.commit`, preserving the existing pinned revision `54b428921749fef89fcbd043000f839ac9cc4638`.
- Read the shared file through a BuildKit bind mount in both Dockerfiles.
- Preserve `--build-arg SGL_NVIDIA_MEGA_COMMIT=...` overrides and the existing installation skip conditions.
