## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. This PR:

3. **Syncs to InferenceX `main`** (`12dbddac`). All seven InferenceX PRs of #44654 have merged, and so has [InferenceX #4155](https://github.com/SemiAnalysisAI/InferenceX/pull/4155), which retunes Muse Spark Open B200.

## How the commands are produced

The pipeline is the same as in #44654, with these changes:

- **Retired configs.** A config key that an overlaid InferenceX PR deletes now leaves the page with the overlay, as it will when the PR merges. Before, the pipeline ignored deletions, so these four keys would have stayed next to their replacements. Their measured `main` versions are kept only as KV-offload donors, like a key that an overlay overrides.
- **Run attribution.** When two InferenceX PRs name the same key on one dashboard date (#4147, then #4155, on 2026-10-16), the lane is credited to the PR whose run produced the dashboard rows. No other lane's attribution changed.
- **Rules.** These are kept as serving configuration:
  - worker flags `--flashinfer-allreduce-fusion-backend`, `--speculative-use-block-verification` and `--enable-http2` (Granian HTTP server with HTTP/2);
  - env `SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN` and `SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND`;
  - the `SGLANG_Q35MF_*` switches of the #4162 image.

  `TORCH_NCCL_HEARTBEAT_TIMEOUT_SEC` is kept as a timeout.

Each lane is still rendered at the exact commit of the run that produced its dashboard data, or at the PR head while in progress. SA-only settings are removed: the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment). Placeholders replace IPs, ports and NICs. Router and KV-offload variants that were not run are derived and labeled "Derived — not run". `NCCL_CUMEM_ENABLE=1` from the SemiAnalysis cluster environment (#44228) applies to the new lanes as well: their GB300 and B200 clusters export it.

The data files are generated, so there is no hand-written code to review here.
