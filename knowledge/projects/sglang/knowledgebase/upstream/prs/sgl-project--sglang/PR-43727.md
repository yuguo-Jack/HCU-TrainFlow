# [Feat] hicache: Export host Mamba pool occupancy next to host KV

[Upstream PR](https://github.com/sgl-project/sglang/pull/43727) · state: closed · merged: True

## Original PR description

Hybrid Mamba/GDN/KDA models keep a host Mamba state pool next to host KV, sized from the device Mamba pool. In cases, it fills long before host KV and its LRU drops the oldest states, after which a prefix whose KV is still on host can no longer be matched. Only the KV pool was exported, so this looked like a radix-tree pruning bug in #33713.

Add sglang:hicache_host_mamba_used_states / _total_states gauges fed from UnifiedRadixCache.host_pool_group, exported only for models that have the pool, print the slot count in the allocation log line, and document the second host pool in the HiCache best-practices page.

Refs #33713, #36935.
