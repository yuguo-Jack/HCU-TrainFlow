## Original PR description

## Summary

This implements Phase 1 of #29709 for HiCache L3 KV cache events.

- Emit engine-side `BlockStored` events with `medium=EXTERNAL` when L3 backup acknowledgements are drained.
- Cover both `HiRadixCache` and `UnifiedRadixCache` ack paths.
- Add L3 event coverage for the file backend and a mocked Mooncake backend.
- Document `medium=EXTERNAL` in `docs_new` HiCache docs and `--kv-events-config` server argument docs.

This intentionally keeps the scope to engine-side events only: no storage metadata plumbing, no Mooncake-native publisher, and no KV event wire-format changes.
