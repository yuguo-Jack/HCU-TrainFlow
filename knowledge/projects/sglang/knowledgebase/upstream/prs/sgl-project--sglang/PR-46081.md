# [Fix] diffusion/mesh: Guard asynchronous job publication and defaults

[Upstream PR](https://github.com/sgl-project/sglang/pull/46081) · state: closed · merged: True

## Original PR description

## Motivation

Mesh jobs currently expose their expected output path while still queued. If an exporter creates the file before finishing, `/content` can serve a partial export, including after the job fails. A worker-returned path that does not exist can also be marked completed. Request preparation failures leave a queued record with no background task.

HTTP replay additionally exposed that omitting the optional seed passes `None` into sampling validation and returns 500.

## Modifications

- Preserve sampling defaults for absent/null optional fields while retaining explicit values, including seed 0.
- Prepare the request before recording an accepted job.
- Require an existing output before marking completion, clear artifact references on failure, and serve content only for completed jobs.
- Document the mesh endpoint and its process-local metadata / deletion semantics.

All production changes stay in the existing mesh API (+27/-15). No new manager, configuration option, or model-compute change. Background-task retention and shutdown ownership remain separate from this PR; #34480 already addresses that work.

## Validation

On an isolated development machine:

- The publication/preparation regressions fail on the parent implementation: 5 failures, 2 passing controls.
- 91 related API, security, storage, and video-lifecycle tests pass after the fixes.
- Real TCP/HTTP replay with 64 concurrent mesh jobs: JSON/base64 and multipart, GLB and OBJ, successful export, partial-write failure, missing file, and empty worker result. All 64 premature downloads return 404; 16 completed outputs are byte-exact and 48 injected failures stay unavailable. Metadata deletion/listing also checked.

The HTTP replay uses native sampling/preparation, dispatch, stores, and file responses, with model generation/export replaced for fault injection. It is not GPU mesh inference or a model-quality benchmark. Existing unbounded queueing, durable recovery, and file retention are outside this patch.

Pre-commit passes. No model accuracy or inference-speed claim.
