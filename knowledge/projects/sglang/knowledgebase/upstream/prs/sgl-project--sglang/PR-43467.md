# [Fix] qwen3-coder: Close streamed arguments at the tool boundary

[Upstream PR](https://github.com/sgl-project/sglang/pull/43467) · state: open · merged: False

## Original PR description

## Motivation

Fixes #43150. When Qwen3 Coder output closes `</tool_call>` without `</function>`, streaming leaves the argument object unterminated or drops the last parameter, even though non-streaming recovers it.

## Modifications

Use `</tool_call>` as a parameter terminator and route an unfinished function through the existing argument-closing path. Keep normal function endings, subsequent tool calls, and trailing assistant text intact.

## Accuracy Tests

Rebased onto `9fa9308e95`, which contains the required base `ff8d964cf5`. On this source, 252 function-call parser tests and 62 subtests pass on CPU; the missing-function-end streaming subcases fail with the unmodified main production code.

`pre-commit run --all-files` passes, including the Rust formatting and Clippy checks.
