# [Perf] diffusion: Cache the fused linear-GELU verdict per linear

[Upstream PR](https://github.com/sgl-project/sglang/pull/44643) · state: closed · merged: True

## Original PR description

## Motivation

`can_use_linear_gelu` runs at every quality-gated GELU up-projection: FLUX, Qwen-Image, LongCat, LTX-2, HunyuanVideo, GLM-Image and Wan. On every call it re-ran the input-independent guards:
- the SM120 architecture check;
- the quantization, `skip_bias_add` and `gather_output` checks;
- the bias, weight rank and dtype checks.

That is 2.67 µs per call on an x86 host, mostly `getattr` misses on `nn.Module`. In a py-spy profile of FLUX.1 TP2 it was 1.3% of the denoise host time.

## Modifications

In `fused_linear_gelu_site.py`:
- The input-independent verdict is kept per linear in a `WeakKeyDictionary`.
- `mount_fused_linear_gelu` and `unmount_fused_linear_gelu` clear it, so a re-mount re-reads the linear.
- The per-input checks still run on every call: device, half dtype and `x.dtype == weight.dtype`.

No model call site changes. No memory is involved.

## Accuracy Tests

On H200:
- `test_sites.py`: 25 passed, including the new `test_linear_gelu_verdict_is_reused_until_remount`. It checks that three calls read the linear once and that a re-mount reads it again.
- `test_wan_gelu_mlp.py`: passed.
- `test_model_fast_paths.py`: 114 passed.
