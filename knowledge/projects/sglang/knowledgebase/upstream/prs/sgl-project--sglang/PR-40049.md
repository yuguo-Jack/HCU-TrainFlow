## Original PR description

Stacked on the 1/N state-move PR (itself on #39867).

## Modifications

Pure relocation: `FreshLoadLookup`, the prefill/decode pressure comparators and `has_kv_capacity` move from `policies/admission.rs` to `policies/state/engine_load/view.rs`. This is the design's `LoadView`: shared load comparison that both the current selection code and the upcoming bucket policies read.

- Callers repoint imports (`power_of_two`, `session_aware`, `load_based`, `cache_aware`, `decode`).
- Methods the remaining admission code still calls become `pub(crate)`; nothing else changes.
