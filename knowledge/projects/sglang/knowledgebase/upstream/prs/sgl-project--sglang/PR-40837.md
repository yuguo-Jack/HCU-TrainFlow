# [Bug][LoRA] Honor PEFT use_rslora when computing adapter scaling

[Upstream PR](https://github.com/sgl-project/sglang/pull/40837) · state: closed · merged: False

## Original PR description

## Motivation

PEFT adapters saved with `use_rslora=True` store that flag in `adapter_config.json` and scale updates by `lora_alpha / sqrt(r)`. SGLang's `LoRAAdapter` always used `lora_alpha / r`, so rsLoRA adapters load silently but apply updates that are `sqrt(r)` times too weak (e.g. 8× at `r=64`).

Fixes #40835

## Modifications

- Read `use_rslora` from the PEFT adapter config (default `False`).
- Compute scaling as `alpha / sqrt(r)` when rsLoRA is enabled, matching PEFT/vLLM.
- Add a CPU unit test covering standard LoRA, rsLoRA, and the default-off path.
