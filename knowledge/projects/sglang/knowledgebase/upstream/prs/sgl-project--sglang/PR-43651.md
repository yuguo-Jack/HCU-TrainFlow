# Handle optional usage in OpenAI frontend streams

[Upstream PR](https://github.com/sgl-project/sglang/pull/43651) · state: open · merged: False

## Original PR description

## Motivation

OpenAI frontend streaming currently assumes the final SSE event contains usage. An otherwise valid stream without usage raises `AttributeError` after yielding its text; an empty stream raises `UnboundLocalError`. Usage emitted before a later text/non-usage event is also lost.

## Modifications

Track the last non-null usage summary separately from text events and add it once after the stream completes. Leave existing counters unchanged when no summary was provided. Handle both chat and legacy completions; retry behavior is unchanged.

Add registered CPU tests using the actual OpenAI SDK's SSE parsing with `httpx.MockTransport`: missing usage, empty streams, usage before a later event, and cumulative summaries counted once. Each case covers both chat and legacy completion streams and checks emitted text plus existing token counters. No core function is mocked.
