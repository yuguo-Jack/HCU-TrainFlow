# [Feat] lora: MoE execution plans (10/21)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42877) · state: closed · merged: False

## Original PR description

Part 10 of 21 of the LoRA runtime stack (branch `lora-stack-09-moe-plans`, base `lora-stack-08-inkling-sink`). The stack is cut from the development branch of #42284.

## What this part adds

Add the MoE plan model (MoePlan, A/B families and specs, act and finalize
families, the ActivationFn enum), the plan loader with load-time validation,
the default table, and the SGLANG_LORA_MOE_CONFIG_DIR override. A device
without a tuned table serves the default plans.

Tests: spec and pipeline validation, fusion ownership, route-requirement
union, token-dense bridge ownership.
