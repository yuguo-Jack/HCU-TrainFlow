# [CI] pr-title: Validate pull request title format

[Upstream PR](https://github.com/sgl-project/sglang/pull/44165) · state: closed · merged: True

## Original PR description

## Motivation

Standardize PR titles so reviewers can quickly identify the change type, affected scope, and optional hardware target.

## Modifications

Add a lightweight PR title check accepting:

```text
[Type] scope: title
[Type] [Hardware] scope: title
```

- Type must be `Feat`, `Fix`, `Refactor`, `Perf`, `Doc`, `Test`, `CI`, or `Chore`.
- Scope is required and has no allowlist or letter-case restriction. Both broad modules and specific model/backend names are accepted.
- Hardware is optional and must be a single tag without spaces. Hardware tags use uppercase (e.g. `AMD`, `NVIDIA`, `NPU`, `MI300X`), except for exactly four canonical spellings: `Intel`, `Apple`, `Huawei`, and `Ascend`. Hardware names have no allowlist.
- The title description has no letter-case restriction.
- Reverts use GitHub's default `Revert "original title"` format, including when the original title predates these rules. `[Revert]` is not accepted.

Examples:

```text
[Fix] attention: Fix KV cache indexing
[Feat] qwen3: Add model support
[Perf] [AMD] flash-attn: Optimize decode performance
Revert "[Fix] attention: Fix KV cache indexing"
```

The check runs on PR creation, edits, pushes, reopening, and readiness for review without requiring `run-ci`. It reads current PR metadata on reruns and uses read-only permissions without checking out PR code. Invalid titles fail with format guidance and examples.

Update the PR template and cookbook authoring guide with compliant title examples, and run regression tests in the lint workflow. Test script extraction is bounded to the validation block and supports YAML chomping indicators and indentation changes.

Migrate automated PR title templates for version bumps, kernel dependency syncs, cherry-picks, LMSYS blog syncs, and weekly CI test timing updates. Version bumps use the fixed `release` scope, including the `docs install` caller.
