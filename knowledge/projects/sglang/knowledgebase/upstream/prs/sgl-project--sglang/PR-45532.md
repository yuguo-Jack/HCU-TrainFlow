# [Feat] step3-vl: Add Rust image preprocessing

[Upstream PR](https://github.com/sgl-project/sglang/pull/45532) · state: open · merged: False

## Original PR description

## Motivation

Add Rust image preprocessing for the Step3/Step5 vision family through the existing `sglang-mm` processor interface. This can be reviewed independently of model execution and attention kernels.

## Modifications

- Add image tiling, normalization, image-token expansion and PyO3 bindings.
- Add bilinear resampling and tile geometry; retain existing processors' default resampling behavior.
- Preserve Pillow <=12 rounding as `pil`, with explicit `pil_v13` for Pillow 13's adaptive pass order. The Python adapter must select the appropriate semantics when integrating this processor.
- Reject invalid normalization parameters and overflowing RGB dimensions; cover pixels, tile order, token spans and malformed inputs.

This registers the Rust processor but does not enable it in the Python Engine.

## Accuracy Tests

Rust library tests passed with and without `parallel` (42 each). Ten Python tests passed on both Pillow 12 and 13. Additional comparisons against the Python image patcher covered ten image sizes in PIL and tensor modes; outputs matched elementwise when selecting the corresponding semantics.

Validation ran on macOS ARM64 with torch 2.14.1 and torchvision 0.29.1. Clippy, Rust formatting and Ruff passed. The existing `/proc` thread-count integration test still needs Linux CI.

## Speed Tests and Profiling

No Engine performance claim; this PR adds the preprocessing implementation and bindings only.
