# [Fix] disaggregation: Keep a requeued optimistic prefill request's multimodal inputs

[Upstream PR](https://github.com/sgl-project/sglang/pull/45440) · state: closed · merged: True

## Original PR description

## Motivation

A PD prefill server serving image requests with optimistic prefill enabled (`--optimistic-prefill-attempts >= 1`, or `--disaggregation-decode-allocation-policy prefill_complete`) can crash with a device-side out-of-bounds assertion in the embedding lookup once a request is yielded and requeued.

`optimistic_release_and_requeue` released the request through `Scheduler._release_aborted_request`. Since #43475 that helper also calls `req.release_mm_inputs_on_abort()` and aborts a streaming session, which is right for a request that is going away but not for one that is about to be prefilled again. The retry then runs with `multimodal_inputs=None` while its input ids still hold the image placeholder values, which are outside the vocabulary by design, and the text-embedding gather asserts. #43442 made this path fire whenever the request slots are exhausted, so an overloaded prefill server hits it regularly; the log line `Req ... exhausted optimistic prefill attempts falling back to bootstrap queue` (or `... optimistic prefill yielded ...`) shows up right before the assert.

## Modifications

- `optimistic_release_and_requeue` now finishes the cache attempt directly (`tree_cache.finish(handle, CacheRequestOutcome.ABORT)`), which is the part of the abort release a requeue still needs. The multimodal inputs and the streaming session stay with the request, as before #43475. Real aborts still go through `_release_aborted_request`.
- `test/registered/unit/disaggregation/test_prefill_complete_integration.py`: the existing requeue test's fake request gains the `cache_request_handle` the requeue now reads, and a new `test_requeued_optimistic_request_keeps_multimodal_inputs` pins the regression with the real `Scheduler._release_aborted_request` and `Req.release_mm_inputs_on_abort` bound to fakes. It fails on the unfixed code (`multimodal_inputs` is `None` after the requeue) and passes with this change.
