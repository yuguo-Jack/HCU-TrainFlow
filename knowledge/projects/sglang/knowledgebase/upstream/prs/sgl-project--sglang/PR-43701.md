# [Perf] Tune small-batch BF16 projection tactics on Blackwell

[Upstream PR](https://github.com/sgl-project/sglang/pull/43701) · state: closed · merged: False

## Original PR description

## Motivation

The existing BF16 split-K dispatcher lacks measured Qwen3-VL-4B TP1 projection tactics for small decode batches. Add the selected tactics to its existing table.

## Modifications

Add 13 entries: QKV (N6144/K2560), output (N2560/K4096), and down (N2560/K9728) at M1/2/4/8, plus down at M16. Existing backend/feature gating, warmup and fallback behavior are reused. No new kernel, runtime flag, precision change, test or benchmark file is added.

This PR is independently based on main `97bfa5cc53`; it does not require GEMM autotuning or the other optimization PRs.

## Accuracy Tests

Prior numerical validation of the first 12 shapes covered 36 shape/seed cases: normalized RMSE approximately 0.00165 and cosine similarity at least 0.99999994. These are BF16 numerical checks, not bitwise equivalence to the previous GEMM path.

The M16 production dispatch matched its measured standalone winner bitwise, including changed-input graphs. A real-text probe confirmed all 36 down-projection weights during graph capture. A matched-startup full GSM8K diagnostic scored 1220/1314 versus 1221/1314 (12 control-only and 11 candidate-only correct); the startup-only tactic override was restored before evaluation. This is limited empirical evidence, not accuracy equivalence.

Current branch: all 13 entries exactly match the previously selected tactics, all existing entries are unchanged, and repository pre-commit checks pass. No fresh GPU or serving validation was run on this main-based branch.

## Speed Tests and Profiling

Prior B300 measurements of selected small-batch GEMMs with cold weights and CUDA graph replay improved kernel throughput by 1.26–1.30×. Short model decode times:

| Batch | Previous ms | Tuned ms |
| ---: | ---: | ---: |
| 1 | 3.126 | 2.987 |
| 4 | 3.333 | 3.201 |
| 8 | 3.694 | 3.588 |

The M16 entry was measured separately in two same-GPU C16/N80 serving pairs, nominal 8192-input/1024-output, after 64 warmups and flush:

| Pair | Previous output tokens/s | Tuned output tokens/s | Change |
| --- | ---: | ---: | ---: |
| 1 | 2562.44 | 2575.85 | +0.523% |
| 2 | 2555.87 | 2565.17 | +0.364% |

Geometric paired gain: +0.443%. Median TTFT increased 599.14→601.58 ms and 601.04→607.43 ms; median TPOT decreased 5.65738→5.62964 ms and 5.70315→5.64546 ms. Those serving arms contained common earlier optimizations; these results are not a clean-main comparison or an isolated serving estimate for all 13 entries. Kernel/model/serving gains must not be combined.
