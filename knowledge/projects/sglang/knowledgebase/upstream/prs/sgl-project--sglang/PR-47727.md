# [Fix] disaggregation: Call finalize_bootstrap outside the assert statement

[Upstream PR](https://github.com/sgl-project/sglang/pull/47727) · state: closed · merged: True

## Original PR description

## Motivation

`handle_pending_bootstrap` calls `finalize_bootstrap(req)` inside an `assert`. The call initializes the sender, sets `start_send_idx` and clears `pending_bootstrap`, so under `python -O` the whole statement is stripped and the request moves on with an uninitialized sender. The other two call sites already call it as a statement.

## Modifications

Call it as a statement and assert the result.
