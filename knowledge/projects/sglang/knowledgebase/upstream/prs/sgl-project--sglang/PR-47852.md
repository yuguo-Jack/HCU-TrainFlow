# [Perf] diffusion: Fuse MiniMax-H3 encoder SiLU and padding

[Upstream PR](https://github.com/sgl-project/sglang/pull/47852) · state: closed · merged: True

## Original PR description

Fuse SiLU, BTCHW→BCTHW layout conversion, spatial reflection and causal zero padding before MiniMax-H3 encoder convolutions. Skip empty spatial padding in downsampling convolutions.

For uncached reference-video conditioning on one B200, native Pika H3 Ref2VA improves **61.728 → 58.761 s (4.81%)** mean end-to-end latency. Six warmed saved requests per variant in A–B–B–A order against the same main base: 864×480, 5 s, six evaluations, seed 42, lossless, resident weights and eager execution. Visual encoding improves **10.935 → 7.971 s**; denoising time is unchanged.

Validation: three dtype kernel cases and pre-commit pass; all twelve timed MP4s are byte-identical. Full-pipeline profiles reduce visual-encoding GPU launches from 95,679 to 73,279.
