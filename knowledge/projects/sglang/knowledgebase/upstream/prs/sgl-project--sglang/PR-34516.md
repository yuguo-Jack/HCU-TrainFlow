## Motivation

Rename NPU test files to reflect actual parallelism and rename MMMU test classes

## Modifications

This PR makes the following changes to the Ascend NPU test infrastructure:

1. **Rename test files to reflect actual parallelism**:
   - `test_npu_qwen3_32b_w8a8_2p_in3k5_out1k5_50ms_a2.py` -> `test_npu_qwen3_32b_w8a8_4p_in3k5_out1k5_50ms_a2.py` (2p -> 4p)
   - `test_npu_qwen3_32b_w8a8_2p_in3k5_out1k5_50ms_gpqa_a2.py` -> `test_npu_qwen3_32b_w8a8_4p_in3k5_out1k5_50ms_gpqa_a2.py` (2p -> 4p)
   - `test_npu_qwen3_6_27b_2p_in64k_out1k_prefix90_50ms.py` -> `test_npu_qwen3_6_27b_1p_in64k_out1k_prefix90_50ms.py` (2p -> 1p, including the test method name)

2. **Rename MMMU test classes** to specific model names to avoid class name collisions and clarify the model under test:
   - `TestQwen3_VL_30B_A3B_Thinking_MMMU`
   - `TestQwen3_VL_8B_Thinking_MMMU`

3. **Add `--max-total-tokens 32256`** to the `kimi_k2_6_w4a8_8p` performance test case.
