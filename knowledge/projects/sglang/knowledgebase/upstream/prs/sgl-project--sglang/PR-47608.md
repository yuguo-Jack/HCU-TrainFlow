[Upstream PR](https://github.com/sgl-project/sglang/pull/47608) · state: open · merged: False

## Original PR description

## Motivation
Add CPU coverage for `DefaultModelLoader`'s loader-specific extra-config validation so typos and format-incompatible options fail instead of being silently accepted.

Closes #47607

## Modifications
- Verify unknown keys such as `num_thread` are rejected.
- Verify `enable_gds` is rejected for `SAFETENSORS` and accepted for `FASTSAFETENSORS`.
- The invalid `enable_gds` type case is already covered by `test_fastsafetensors_enable_gds_requires_boolean` in `test_prefetch_checkpoints.py`.
