## Motivation

Extend NPU nightly coverage for the DeepSeek-V4 family:

- DeepSeek-V4-Pro-0813 W4A8: add a two-node 16p PD-mix performance case (in 128k / out 1k, 90% shared prefix) and a new 1P1D 32p GPQA-Diamond accuracy case.
- DeepSeek-V4-Flash-0731 W8A8: add a new 1P1D 16p GPQA-Diamond accuracy case.
- DeepSeek-V4-Flash FP8 4P: re-enable the previously commented-out GPQA-Diamond accuracy case on A5.
- Add the shared `DEEPSEEK_V4_PRO_0813_W4A8_MODEL_PATH` constant used by the new DeepSeek-V4-Pro test cases.

## Modifications

- `python/sglang/test/ascend/e2e/test_npu_performance_utils.py`
  - Add the `DEEPSEEK_V4_PRO_0813_W4A8_MODEL_PATH` constant pointing to `/root/.cache/modelscope/hub/models/Eco-Tech/DeepSeek-V4-Pro-0813-w4a8`, next to the existing DeepSeek-V4-Flash-0731 path constant.
- `test/registered/npu/performance/deepseek_v4_pro/test_npu_deepseek_v4_pro_w4a8_16p_in128k_out1k_prefix90_20ms.py` (new file, 157 lines)

  - `DEEPSEEK_V4_PRO_W4A8_16P_ENVS`: HCCL/GLOO NIC binding via `NIC_NAME` with 300 s connect/execute timeouts, DeepEP settings (`SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=128`, `DEEPEP_HYBRID_DEPLOYMENT=1`, `DEEP_NORMAL_MODE_USE_INT8_QUANT=1`), DSPARK spec-decode switches (spec v2, `static` ragged verify, quant audit, fast kernel/sampling off), NPU multi-stream, and `SGLANG_DSV4_FP4_EXPERTS=False`.
  - `DEEPSEEK_V4_PRO_W4A8_16P_OTHER_ARGS`: `--nnodes 2`, `--tp-size 32`, `--dp-size 8` with `--enable-dp-attention` / `--enable-dp-lm-head`, `--quantization modelslim`, DeepEP A2A (`--moe-a2a-backend deepep`, `--deepep-mode auto`), DSPARK speculative decoding against the same W4A8 model (`--speculative-num-draft-tokens 6`, `--speculative-dspark-block-size 5`), `--chunked-prefill-size 16384`, `--prefill-decode-interval 2`, `--enable-prefill-delayer`, `--mem-fraction-static 0.8`, `--max-running-requests 32`, `--kv-cache-dtype auto`, `--moe-dense-tp-size 1`, decode CUDA-graph batch sizes 1, 2, 4, 6, 8, 10, 12, 14, 16, and `--load-balance-method round_robin`.
  - Test class `TestNPUDeepSeekV4ProW4A816PIn128kOut1kPrefix90RadixCache` extends `TestNpuPerfMultiNodePdMixTestCaseBase` (launches the master/worker nodes and runs the benchmark on the master) with workload `generated-shared-prefix`, `repeat_rate=0.9`, `input_len=131072`, `output_len=1024`, `num_prompts=32`, `max_concurrency=8`, `warmup_requests=16`, `request_rate=inf`, `seed=42`.

- `test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_0731_w8a8_1p1d_16p_gpqa.py` (new file, 238 lines)
  - Register the case for nightly NPU CI: `register_npu_ci(est_time=3800, suite="", nightly=True)`.
  - Common/prefill/decode environment dicts: `PYTORCH_NPU_ALLOC_CONF=expandable_segments:True`, `STREAMS_PER_DEVICE=32`, `HCCL_OP_EXPANSION_MODE=AIV`, GPU-branch opt-outs (`SGLANG_OPT_FP8_WO_A_GEMM=0`, `SGLANG_OPT_USE_OVERLAP_STORE_CACHE=False`, `SGLANG_OPT_FUSE_WQA_WKV=0`, ...), DSPARK switches (`SGLANG_ENABLE_SPEC_V2=1`, `SGLANG_RAGGED_VERIFY_MODE=static`, `SGLANG_DSPARK_QUANT_AUDIT=1`), disaggregation timeouts of 1800 s, plus prefill-only DeepEP long-sequence knobs and decode-only `SGLANG_NPU_USE_MULTI_STREAM=1`.
  - Prefill args: `--tp-size 8`, `--pp-size 2`, `--dp-size 8` with `--enable-dp-attention` / `--enable-dp-lm-head`, `--page-size 128`, `--attention-backend dsv4`, `--quantization modelslim`, `--disaggregation-mode prefill` over the Ascend transfer backend, DeepEP `normal` mode, `--mem-fraction-static 0.62`, `--max-prefill-tokens 70000`, `--chunked-prefill-size 131072`, `--max-total-tokens 140000`, prefill context parallel (`--enable-prefill-cp`, `--cp-strategy interleave`), and hierarchical cache (`--hicache-io-backend kernel_ascend`, `--hicache-ratio 1.5`, `--hicache-write-policy write_through`).
  - Decode args: `--tp-size 16`, `--dp-size 16` with DP attention / DP LM head, `--deepep-mode low_latency`, `--kv-cache-dtype bfloat16`, `--mem-fraction-static 0.71`, `--max-running-requests 256`, decode CUDA-graph batch sizes 1-6, and DSPARK speculative decoding against the same W8A8 checkpoint (`--speculative-num-draft-tokens 6`).
  - Test class `TestNPUDeepSeekV4Flash0731W8A8PDSEPGPQAHigh` extends `TestNpuAccuracyMultiNodePdSepTestCaseBase` with GPQA-Diamond, `accuracy = 0.874`, thinking-high generation config (`max_tokens=125000`, `temperature=1`, `top_p=1`), `eval_batch_size=128`, and the cache-aware router policy.
- `test/registered/npu/accuracy/deepseek_v4_pro/test_npu_deepseek_v4_pro_0813_w4a8_1p1d_32p_gpqa.py` (new file, 210 lines)
  - Register the case for the nightly NPU suite but keep it disabled until it is validated: `register_npu_ci(est_time=4800, suite="", nightly=True, disabled="accuracy testcase")`.
  - Common environment dict: `SGLANG_DSV4_FP4_EXPERTS=True`, multi-node HCCL/GLOO binding via `NIC_NAME` with `HCCL_HOST_SOCKET_PORT_RANGE=auto`, `SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=128`, DSPARK fast kernel/sampling off, and disaggregation timeouts of 1800 s; prefill adds `DEEPEP_HCCL_BUFFSIZE=2048`, decode adds `DEEPEP_HCCL_BUFFSIZE=1600` plus `SGLANG_ENABLE_SPEC_V2=1` and `SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1`.
  - Prefill args: `--nnodes 2`, `--tp-size 16`, `--pp-size 2`, `--dp-size 8` with DP attention / DP LM head, `--attention-backend ascend`, `--quantization modelslim`, `--disaggregation-mode prefill` over the Ascend transfer backend, `--load-balance-method total_tokens`, `--max-running-requests 64`, `--mem-fraction-static 0.82`, `--max-prefill-tokens 70000`, `--chunked-prefill-size 65536`, DeepEP `auto` mode, `--disable-cuda-graph`, prefill context parallel (`--enable-prefill-cp`, `--cp-strategy interleave`), hierarchical cache (`--hicache-io-backend kernel_ascend`, `--hicache-ratio 1.5`, `--hicache-write-policy write_through`), and `--max-total-tokens 140000`.
  - Decode args: `--nnodes 2`, `--tp-size 32`, `--dp-size 4` with DP attention / DP LM head, `--load-balance-method round_robin`, `--max-running-requests 8`, `--mem-fraction-static 0.78`, DeepEP `auto` mode, decode CUDA-graph batch sizes 1, 2, 8, and DSPARK speculative decoding against the same W4A8 model (`--speculative-num-draft-tokens 6`).

- `test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_fp8_4p_gpqa_a5.py`
  - Restore the commented-out `test_npu_deepseek_v4_flash_fp8_4p_gpqa` method so the existing FP8 4P DSPARK GPQA-Diamond case (`accuracy = 0.874`) runs on A5. No other change.

## Accuracy Tests

The PR only adds or re-enables accuracy test definitions; no model forward or kernel code is modified, so no accuracy run output is attached. The expected baselines encoded in the new cases are 0.874 for DeepSeek-V4-Flash 0731 W8A8 1P1D 16p, 0.874 for the re-enabled DeepSeek-V4-Flash FP8 4P case, and 0.85 for DeepSeek-V4-Pro 0813 W4A8 1P1D 32p. The DeepSeek-V4-Pro case is registered with `disabled="accuracy testcase"`, so it is not executed by CI yet.
