# [Refactor] environ: Rename the SGLANG_Q35MF_* runtime switches to SGLANG_OPT_* names

[Upstream PR](https://github.com/sgl-project/sglang/pull/47804) · state: closed · merged: True

## Original PR description

## Motivation

Nine runtime switches that came in with #45474 still carry an internal code name (`SGLANG_Q35MF_*`, with `EDGE`, `MKH_N3B` and similar fragments). The names do not say what the switch controls and do not follow the `SGLANG_OPT_*` convention used by the other children of `SGLANG_ENABLE_NV_MEGA_RUNTIME_OPTIMIZATION`. This PR gives them descriptive names.

## Modifications

| Old name (deprecated alias) | New name | What it controls |
|---|---|---|
| `SGLANG_Q35MF_BK_VEC_COPY` | `SGLANG_OPT_SMALL_FIELD_COPY_VECTORIZED` | Vectorized small-field copy kernel |
| `SGLANG_Q35MF_MKH_N3B` | `SGLANG_OPT_SPEC_VERIFY_REUSE_STAGED_INPUTS` | Verify reuses inputs already staged on device |
| `SGLANG_Q35MF_MKH_N3C` | `SGLANG_OPT_SPEC_POST_VERIFY_ONE_LAUNCH_LOAD` | Post-verify loads its inputs in one launch |
| `SGLANG_Q35MF_EDGE_CHAIN_TREE` | `SGLANG_OPT_TRTLLM_MHA_CHAIN_VERIFY` | TRT-LLM MHA chain-shaped verify path |
| `SGLANG_Q35MF_EDGE_SPARSE_VERIFY_SAMPLING` | `SGLANG_OPT_SPEC_COMPACT_VERIFY_SAMPLING` | Compact verify sampling |
| `SGLANG_Q35MF_EDGE_PACKED_VERIFY_BCAST` | `SGLANG_OPT_SPEC_PACKED_VERIFY_BCAST` | Packed verify broadcast |
| `SGLANG_Q35MF_EDGE_SHM_SYNC` | `SGLANG_OPT_SCHEDULER_SHM_SYNC` | Scheduler shared-memory sync |
| `SGLANG_Q35MF_EDGE_SHM_SYNC_MULTIHOST` | `SGLANG_OPT_SCHEDULER_SHM_SYNC_MULTIHOST` | Scheduler shared-memory sync across hosts |
| `SGLANG_Q35MF_EDGE_MULTIHOST_TCP` | `SGLANG_OPT_SCHEDULER_SHM_SYNC_LEADER_TCP` | Leader TCP exchange for the multi-host sync |

- `environ.py`: each switch is now declared under its new name with `EnvBoolWithAlias`, keeping the old name as `deprecated_name`. Setting the old name still works and logs a `DeprecationWarning`. Defaults are unchanged and still follow `SGLANG_ENABLE_NV_MEGA_RUNTIME_OPTIMIZATION`.
- Call sites read the new names. The shared-memory exchange log and error messages drop the internal `EDGE` prefix.
- `docs/src/snippets/agentx/Qwen/*.jsx` still use the old names. They are generated from the SemiAnalysis InferenceX launch commands and are marked "do not edit by hand". They keep working through the aliases and will pick up the new names on the next sync.
- No behavior change.
