# [CI] base-b: Move kernel and unit tests that pass on the 5090 to 1-gpu-small

[Upstream PR](https://github.com/sgl-project/sglang/pull/44880) · state: open · merged: False

## Original PR description

## Summary

Second of the series that splits #41231 into reviewable PRs, one CI lane each (first: #44876). This one moves 27 light base-b test files (kernels/ops, moe, unit, layers, mem_cache, model_loading, prefill_only) from 1-gpu-large (H100) to 1-gpu-small (RTX 5090). Every change is the `runner_config` of one `register_cuda_ci` line, with `est_time` set to the measured 5090 duration where the estimate was more than 1.5x low. `test_nvfp4_marlin` was already registered on 1-gpu-small (est_time 12, 11s measured); its 1-gpu-large duplicate is dropped.

Rule for a file to move: it passes on the 5090 (SM120, 32 GB) with the CI install and env, every test it skips on the 5090 also skips on H100, and where it launches a server, any architecture-dependent default it picks up (e.g. FA3 on H100 vs FlashInfer on SM120) is not what the test is about. No coverage is lost.

| base-b per-commit est_time | main | this PR |
|---|---|---|
| 1-gpu-large | 129 files / 175.4 min | 101 / 168.1 min |
| 1-gpu-small | 150 files / 191.9 min | 177 / 205.8 min |

Partitions are sized from est_time by `compute_partitions.py`, so no workflow change is needed. Independent of #44876 (no shared files).

## Validation

All 30 candidate files passed on the 1-gpu-5090 runners at `8d58a33e16` with `/rerun-test -c` ([run 39021620314](https://github.com/sgl-project/sglang/actions/runs/39021620314)), then compared with the same files on H100 in main's scheduled run:

- `test_mhc_kernels` stays on 1-gpu-large: 33 passed, 16 skipped on the 5090 vs 49 passed on H100. The skipped cases are its `test_hopper_*` functions, which exercise the SM90-only mHC dispatch.
- Same skips on both: `test_topk_padded_region` (3), `test_fp8_utils` (1). `test_flash_mla_backends` skips all 15 cases on H100 and runs 14 on the 5090.
- `test_post_capture_kv_sizing` is the only file that starts a server; it gets FlashInfer on the 5090 instead of FA3. Post-capture KV sizing has no attention-backend-specific path, and the run confirms the sizing path ran.

Merged main `5e630fa571` into the branch: main deleted `kernels/ops/gemm/test_fp8_kernel.py` (#44690), so it is no longer part of this PR. Main changed 9 of the other files since the run above, so all 28 are being rerun on the 5090 with `/rerun-test -c`.
