## Motivation

The full/window/state unified allocator forwarded HiCache completion events only to token sub-pools. Its recurrent-state allocator could move pages without waiting for the transfer that still accessed them.

## Changes

Send each HiCache completion event to every member covered by the move gate. Extend event propagation coverage while preserving the state allocator's distinct handling of in-flight token ids.

## Validation

The member-event regression **failed before the fix and passed afterward** at `3c85e134ec`. Later CPU review confirmed the event reaches every member in both two-member and three-member pools.

This validates event propagation; GPU stream ordering was not rerun for the published head.
