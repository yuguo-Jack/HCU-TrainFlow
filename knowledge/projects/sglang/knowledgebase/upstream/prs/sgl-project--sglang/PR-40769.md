# [ROCm] Optimize GLM-5.2 target QKV-A, Q-B, and O projections

[Upstream PR](https://github.com/sgl-project/sglang/pull/40769) · state: closed · merged: False

## Original PR description

## Summary

- add an opt-in gfx950 path for the GLM-5.2 target model under TP4
- fuse QKV-A projection with Q/K latent RMSNorm and use tuned BF16 Q-B/O kernels
- specialize only the validated M=4 decode/target-verify shape; other shapes and unsupported configurations use the existing native path
- keep the draft/NextN model, DCP, scattered inputs, and LoRA on the native path

Enable with `SGLANG_ROCM_FUSED_TARGET_ATTN_PROJECTIONS=1`.

## Validation

- Ruff format/check and `git diff --check`
- CPU dispatch/fallback tests
- MI355X numerical correctness for QKV-A + Q-B + O (SNR > 20 dB)
- MI355X CUDA graph capture/replay
- Result: 4 tests passed

## Preliminary performance

AgentX-style TP4/EP4, MTP 4/3/1, 100K input / 100 output, 95% cache hit:

- C1: E2E +1.50%, decode +2.73%
- C10: aggregate +0.08%, decode +0.38% (within noise)

This is a draft while the upstream-native end-to-end run is finalized.
