# [Fix] anthropic: Accept thinking enabled without budget_tokens

[Upstream PR](https://github.com/sgl-project/sglang/pull/47093) · state: open · merged: False

## Original PR description

## Motivation

`/v1/messages` rejects `thinking: {"type": "enabled"}` without `budget_tokens` with a 400. Some Anthropic-compatible clients send exactly that, for example deepseek-harness, which enables thinking this way on every request, so it cannot run against SGLang with thinking on. SGLang does not enforce the budget anyway.

## Modifications

- `budget_tokens` is optional on `thinking.type == "enabled"`; when present it must still be >= 1024.
- The unit test that asserted the 400 now asserts the request is accepted with reasoning enabled.
