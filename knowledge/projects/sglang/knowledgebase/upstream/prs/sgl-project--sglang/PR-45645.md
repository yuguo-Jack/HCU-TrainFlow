# [gRPC] Return 400 for invalid Generate input instead of INTERNAL

[Upstream PR](https://github.com/sgl-project/sglang/pull/45645) · state: closed · merged: False

## Original PR description

## Motivation

Native `Generate` now carries `image_data` (#42833). When the tokenizer manager cannot fetch or decode an image, it raises `ValueError`, and `RuntimeHandle._run_generate` turns every exception into `_send_native_error`, so the client gets gRPC `INTERNAL` (HTTP 500 at a gateway) for what is a bad request. HTTP `/generate` returns 400 for the same input.

## Modifications

- `_run_generate` catches `ValueError` and finishes the stream with the tokenizer manager's abort shape: `finish_reason = {"type": "abort", "status_code": 400, "err_type": "BadRequestError", "message": ...}`.
- Any other exception still goes through `_send_native_error` (INTERNAL).

## Tests

- `test/registered/unit/entrypoints/test_grpc_bridge.py`: 7 passed, 2 new (`TestNativeGrpcErrors`: a `ValueError` yields one terminal 400 abort chunk, streaming and not; a `RuntimeError` stays an error).
