# Cherry pick sglang 20114 22940 23427

[Upstream PR](https://github.com/sgl-project/sglang/pull/25201) · state: open · merged: False

## Original PR description

## Motivation

Cherry-pick upstream fixes into `sglang-miles` so the Miles async agent / disaggregated setup no longer needs the corresponding temporary local patches from radixark/miles#1062.

This PR brings in fixes for:

- Missing TBO support for `HybridLinearAttnBackend`, fixed upstream by sgl-project/sglang#20114.
- HiCache / hybrid-cache index handling for Mamba-related pools, fixed upstream by sgl-project/sglang#22940.
- A race / lifetime bug where transfer index tensors could be normalized for load/write streams by mutating radix-tree-owned state, fixed upstream by sgl-project/sglang#23427.

The related pause-generation fix from sgl-project/sglang#24462 is already present on `sglang-miles`, so it is not included here.

## Modifications

Cherry-picked the following upstream SGLang PRs onto `sglang-miles`:

- sgl-project/sglang#20114
- sgl-project/sglang#22940
- sgl-project/sglang#23427

These touch TBO forward batch preparation / attention backend forwarding and HiCache hybrid-cache index movement / stream lifetime handling.

## Accuracy Tests

Ran the random agent in radixark/miles#1062. This PR is a direct cherry-pick of upstream merged fixes onto the `sglang-miles` branch.

## Speed Tests and Profiling

Speed remains the same in the random agent. No intentional performance change; this is intended to restore correctness for the affected TBO and HiCache/disaggregated paths.
