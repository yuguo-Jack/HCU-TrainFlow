# [Refactor] muse-spark: Consolidate layer modules into one package

[Upstream PR](https://github.com/sgl-project/sglang/pull/44717) · state: closed · merged: True

## Original PR description

This PR targets #44666 (`codex/muse-spark-stack-03-srt-tests`). It consolidates the eight new Muse Spark layer modules under `sglang.srt.layers.muse_spark`, including the MegaMoE and NVFP4 helpers, and updates runtime, kernel, and Docker imports.

The relocation commit preserves runtime behavior and contains only file moves, import rewrites, package initialization, and formatter changes. A separate fix removes two stale calls to the deleted CUDA IPC cache-hit acknowledgement helper inherited from the base branch, preventing a `NameError` on image cache hits while preserving raw inputs for re-prefill. Existing multimodal tests now use real `MultimodalDataItem` fixtures.

```python
from pathlib import Path
import subprocess
import sys

FILES = (
    'muse_spark_audio.py',
    'muse_spark_bf16_moe.py',
    'muse_spark_fp4_moe.py',
    'muse_spark_int4_moe.py',
    'muse_spark_layers.py',
    'muse_spark_navit.py',
    'moe/muse_spark_megamoe.py',
    'quantization/muse_spark_nvfp4_moe.py',
)

def transform(root):
    root = Path(root)
    layers = root / 'python/sglang/srt/layers'
    target = layers / 'muse_spark'
    target.mkdir()
    replacements = {
        'sglang.srt.layers.' + path[:-3].replace('/', '.'):
        'sglang.srt.layers.muse_spark.' + Path(path).stem
        for path in FILES
    }
    tracked = subprocess.check_output(['git', 'ls-files', '-z'], cwd=root).split(b'\0')
    for entry in tracked:
        if not entry:
            continue
        path = root / entry.decode()
        if not path.is_file() or path.is_symlink():
            continue
        data = path.read_bytes()
        updated = data
        for old, new in replacements.items():
            updated = updated.replace(old.encode(), new.encode())
        if data != updated:
            path.write_bytes(updated)
    for path in FILES:
        (layers / path).rename(target / Path(path).name)
    (target / '__init__.py').touch()

if __name__ == '__main__':

    )
```
