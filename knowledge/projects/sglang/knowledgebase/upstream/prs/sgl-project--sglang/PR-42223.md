# [Diffusion][NPU] Refactoring of sparse attention backends and support for A5

[Upstream PR](https://github.com/sgl-project/sglang/pull/42223) · state: open · merged: False

## Motivation

Update NPU attention backends following the migration of the standalone attentions kernels into ```sgl-kernel-npu```. Extend sparse attentions support on Ascend 950 and enable packed variable-length inputs for ```rain_fusion_attn``` for MiniMax-H3.

Related PR:
https://github.com/sgl-project/sgl-kernel-npu/pull/836/

<!-- Describe the purpose and goals of this pull request. -->

## Modifications

* Replace legacy attentions imports and operator calls with the migrated ```sgl-kernel-npu``` operators.

* Add A5 support for ```block_sparse_attn``` through ```torch_npu.npu_block_sparse_attention```, while retaining ```ada_block_sparse_attn``` on A2/A3.

* Replace ```attentions.rainfusionattention``` operator with ```torch_npu.npu_block_sparse_attention```, including A5 support.

* Add packed TND variable-length self-attention for ```rain_fusion_attn```, with per-sequence sparse masks and sequence-length validation.

* Use Ascend FA for initial dense steps on A5 and retain ```Laser Attention``` on A2/A3. Keep non-DiT layers, such as MiniMax H3's token refiner, on the dense varlen path.

* Removed the ```attentions.layernorm``` call, this kernel is already performed inside ```F.layer_norm```. 

* Update backend documentation and dependency error messages.
