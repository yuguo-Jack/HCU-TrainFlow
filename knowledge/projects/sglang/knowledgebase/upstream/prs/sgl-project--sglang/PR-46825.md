# [Doc] [AMD] cookbook: Add GLM-5.3 MI355X AgentX recipe

[Upstream PR](https://github.com/sgl-project/sglang/pull/46825) · state: closed · merged: True

## Original PR description

## Motivation

SemiAnalysis InferenceX benchmarks GLM-5.3 AgentX on MI355X with `lmsysorg/sglang-rocm:v0.5.22-rocm10-mi35x-20261025` ([InferenceX #4593](https://github.com/SemiAnalysisAI/InferenceX/pull/4593)). The cookbook has no MI355X agentic command for GLM-5.3, and its AMD note says to serve without MTP.

## Modifications

- `docs/cookbook/autoregressive/GLM/GLM-5.3.mdx`: under Agentic Long-Context Deployment, add an MI355X subsection with the TP4/EP4 HiCache and TP8/EP1 launch commands for `amd/GLM-5.3-Quark-MXFP4-AttnFP8` with EAGLE MTP.
- Scope the AMD MTP note in Configuration Tips to the Deploy panel's FP8 and BF16 commands, and point it to the new subsection.

`node docs/scripts/check_cookbook_configs.mjs`, `mint validate` and `mint broken-links` pass; `mint validate` reports no warnings for this page.

## Accuracy Tests

GSM8K (lm-eval, chat template, real draft verification) with these commands: 0.9719 ± 0.0045 at TP4/EP4 and 0.9757 ± 0.0042 at TP8/EP1.

## Speed Tests and Profiling
