# [Test] [AMD] deepseek-v4.1: Give the encoder-replay test's request window a zero_row

[Upstream PR](https://github.com/sgl-project/sglang/pull/45728) · state: closed · merged: True

## Original PR description

## What
Give the stub request window in `TestEncoderReplayRequestWindowHip` (`test_dsv4_hip_bcg_metadata.py`) a `zero_row`.

## Why
#45579 makes `DeepseekV4HipRadixBackend.make_core_attn_metadata` pass `request_window.zero_row` to `window_layout`. The test stubs the window as `SimpleNamespace(capacity=256)`, so both tests in the class fail before they reach the mocked `window_layout`:

```
File ".../deepseek_v4_backend_hip_radix.py", line 3559, in make_core_attn_metadata
    zero_row=window.zero_row,
AttributeError: 'types.SimpleNamespace' object has no attribute 'zero_row'
```

Seen in `stage-b-test-1-gpu-small-amd-mi35x` partition 1 on a branch cut from current `main`: https://github.com/sgl-project/sglang/actions/runs/39687298904/job/119524656578

The mock only records the `floor` kwarg, so the value of `zero_row` doesn't matter. Test-only change. #45507 fixes the other failures in this file; this one landed after it was opened.
