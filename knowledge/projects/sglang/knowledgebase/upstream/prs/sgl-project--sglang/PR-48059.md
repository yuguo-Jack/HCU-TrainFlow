# [Feat] [Intel] diffusion: SageAttention V3 for XPU self-attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/48059) · state: open · merged: False

## Original PR description

## Motivation

On Intel XPU (CRI), diffusion self-attention runs BF16 flash attention and dominates video DiT steps. deepklox's SageAttention V3 kernels for CRI are 2-2.6x faster at these shapes but are not usable from sglang.

## Modifications

Opt-in `SGLANG_DIFFUSION_XPU_SAGE_ATTN_V3=pure|hybrid` in the XPU attention backend: eligible self-attention layers run deepklox SageAttention V3; everything else, plus blocks listed in `SGLANG_DIFFUSION_XPU_SAGE_ATTN_V3_BF16_BLOCKS`, keeps BF16 flash attention. The kernel is a torch custom op, so `torch.compile` has no graph break.

## Accuracy Tests

Wan2.2-T2V-A14B 1280x720x81, 40 steps, BF16 blocks 0,33,34,38: valid video with the same scene and motion as BF16 (PSNR 16.7 dB). Kernel vs fp32 at Wan shape: cosine 0.962 (`pure`), 0.985 (`hybrid`).

## Speed Tests and Profiling

1 Intel CRI card. Self-attention S=75600, H=40, D=128: flash 555.3 ms, `pure` 215.1 ms (2.58x), `hybrid` 268.8 ms (2.07x). Wan2.2-T2V-A14B 1280x720x81, 40 steps, end to end: 2398.8 s -> 1411.9 s (1.70x).
