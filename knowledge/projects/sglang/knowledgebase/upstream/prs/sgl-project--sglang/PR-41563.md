## Motivation

<!-- Describe the purpose and goals of this pull request. -->

The configuration of Hy3-FP8 uses `lm_head==fp32`, which results in the use of a standard `torch.matmul(hidden_states.float(), weight.Float().T)` operation on the CPU. However, the `weight` matrix has already been packed, leading to incorrect logits and subsequent errors during sampling.

## Modifications

<!-- Detail the changes made in this pull request. -->
* enable Hy3-fp8 model on Xeon
  * skip AMX weight packing when `lm_head==fp32`
  * add `fused_experts_fp8_pertensor_kernel` for Hy3-fp8 model on Xeon
