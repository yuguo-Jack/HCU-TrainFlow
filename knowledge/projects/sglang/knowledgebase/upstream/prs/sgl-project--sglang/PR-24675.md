## Motivation

Implements get_cpu_copy / load_cpu_copy across the full DSv4 KV-pool hierarchy so that retract->resume under SWA pressure no longer kills the decode scheduler with NotImplementedError.

Thanks @yunkchen! The decode crash this targets is fixed on main by #43936: a retracted DeepSeek-V4 PD decode request is now sent back to prefill for recompute instead of raising `NotImplementedError`, and a request that cannot be recomputed (multimodal input, or the `none` backup backend) is aborted on its own while the scheduler keeps running. Keeping the KV on the host across retraction is still a valid optimization; that path is open in #37239. Closing as superseded; please reopen if I've missed a case.
