# [Feat] afd: add Attention-FFN disaggregation for MoE inference

[Upstream PR](https://github.com/sgl-project/sglang/pull/45562) · state: open · merged: False

## Original PR description


## Motivation

MoE inference normally places attention and routed experts on the same GPU group. This PR adds Attention-FFN disaggregation (AFD), allowing them to run on separate groups. Multiple attention instances can share one FFN instance and its routed-expert weights, so attention capacity can grow without replicating those weights for every instance.

Requests continue to use SGLang's serving APIs on the attention instances. AFD is opt-in through `--afd-role`.

![SGLang AFD: tokens from multiple attention instances form shared expert batches, and Megamoe M2N overlaps attention with remote expert execution across microbatches and layers](https://github.com/user-attachments/assets/dd4e8f84-4272-4fee-a4a4-3b7e7df6d54c)

F batches routed tokens across A instances. In the Megamoe M2N decode path, per-microbatch communication lanes overlap with attention computation, while one persistent kernel per F rank processes successive layers and microbatches. Timing in the diagram is schematic.

## Modifications

- Add attention (A) and FFN (F) roles, startup handshakes, role-specific weight loading, and remote expert execution. A owns requests, KV cache, attention, routing, shared experts, and sampling; F owns routed experts.
- Support asymmetric A/F parallelism, CUDA graphs, decode microbatch overlap, and batching across attention instances sharing F. F graph and dispatch capacities are derived from the attention handshakes.
- Provide staged NCCL and NVSHMEM transports, Direct DeepEP, and Megamoe M2N. NCCL uses standard SGLang dependencies; other backends load their optional components only when selected.
- Integrate Qwen3 MoE, Qwen3.5 MoE, DeepSeek V3/V3.2/V4, and the GLM-5 MoE DSA family, including EAGLE/MTP and DSpark with draft execution on A.
- Add coverage to the registered CPU test suites, an AFD deployment guide, and a DeepSeek-V4-Pro Megamoe M2N recipe.

### Usage and scope

Start attention workers with `--afd-role attn --afd-ffn-addr <ffn-host>:<port>` and FFN workers with `--afd-role ffn`. For a shared F, set `--afd-attn-instances` to the number of attention instances. Send generation requests to A.

Complete deployment examples and the backend/precision support matrix are in `docs/docs/advanced_features/afd_disaggregation.mdx`. The multi-host Pro recipe is in `docs/cookbook/autoregressive/DeepSeek/DeepSeek-V4.mdx`.

The initial implementation uses fixed membership established at startup and homogeneous attention instances, with TP size one within each attention DP group. Direct backends require pure expert parallelism on F. Direct MegaMoE requires SM100/SM103 GPUs with peer-accessible memory; cross-host execution requires a shared NVLink fabric with CUDA FABRIC access. The deployment guide lists the remaining feature combinations and restrictions.

```python
#!/usr/bin/env python3
r"""Measure fixed-batch decode throughput with SGLang's streaming API.

Requires Python 3.11+. Dependencies:
    pip install aiohttp transformers huggingface_hub orjson
    pip install datasets  # Only needed to download GSM8K.

Example:
    python bench_decode.py --model /path/to/model --concurrency 256 \
        --base-url 127.0.0.1:30000 --input-len 8192 --prefix-len 7373

The default dataset is ShareGPT. --dataset gsm8k uses openai/gsm8k, configuration
main, split train. Both download through the Hugging Face cache unless a local
JSON/JSONL --dataset-path is given. Prompts use ShareGPT's first conversation turn
or GSM8K's question field, without a chat template. Explicit input lengths
repeat/truncate token IDs; the shared prefix is part of that length.

All requests must fit concurrently, and all prefill must finish before decode
starts. All URLs must share one coordinated decode schedule.

Record the total received token count when every request has returned tokens,
then again when the first request finishes. Throughput is the count difference
divided by the elapsed client time. Counts come directly from streaming metadata,
without interpolation. HTTP delivery order can shift the boundaries relative to
GPU steps; this is client-observed throughput, not exact GPU timing.
TPOT is concurrency / throughput, expressed in milliseconds for this window.
Streaming updates are buffered every 8 tokens by default to avoid output-path
backlog at high concurrency. Counts still come from cumulative metadata; no
interpolation is used. --stream-interval 1 requests per-token updates.
"""

import argparse
import asyncio
import json
import random
import time
from dataclasses import dataclass, field

import aiohttp
import orjson

SHAREGPT_REPO = "anon8231489123/ShareGPT_Vicuna_unfiltered"
SHAREGPT_FILE = "ShareGPT_V3_unfiltered_cleaned_split.json"


def resize_tokens(tokens: list[int], length: int) -> list[int]:
    return (tokens * ((length + len(tokens) - 1) // len(tokens)))[:length]


def load_dataset_rows(args: argparse.Namespace) -> list[dict]:
    if args.dataset == "gsm8k" and not args.dataset_path:
        from datasets import load_dataset

        return list(load_dataset("openai/gsm8k", "main", split="train"))

    from huggingface_hub import hf_hub_download

    dataset_path = args.dataset_path or hf_hub_download(
        repo_id=SHAREGPT_REPO, filename=SHAREGPT_FILE, repo_type="dataset"
    )
    with open(dataset_path) as f:
        if dataset_path.endswith(".jsonl"):
            return [json.loads(line) for line in f if line.strip()]
        return json.load(f)


def load_prompts(args: argparse.Namespace) -> list[list[int]]:
    from transformers import AutoTokenizer

    dataset = load_dataset_rows(args)
    tokenizer = AutoTokenizer.from_pretrained(args.model)
    random.Random(args.seed).shuffle(dataset)

    prompts = []
    prefix = []
    for row in dataset:
        if args.dataset == "gsm8k":
            text = row["question"]
        else:
            conversation = row.get("conversations", row.get("conversation", []))
            if len(conversation) < 2:
                continue
            text = conversation[0]["value"]
        tokens = tokenizer.encode(text)
        if len(tokens) < 2:
            continue
        if args.prefix_len and not prefix:
            prefix = resize_tokens(tokens, args.prefix_len)
            continue
        if args.input_len is not None:
            tokens = resize_tokens(tokens, args.input_len - args.prefix_len)
        prompts.append(prefix + tokens)
        if len(prompts) == args.concurrency:
            return prompts
    raise ValueError(f"Dataset has only {len(prompts)} usable prompts")


@dataclass
class DecodeCounter:
    counts: list[int]
    output_len: int
    finished: set[int] = field(default_factory=set)
    num_started: int = 0
    total_tokens: int = 0
    all_started: asyncio.Event = field(default_factory=asyncio.Event)
    start: tuple[float, int] | None = None
    end: tuple[float, int] | None = None

    def record(self, index: int, meta: dict, now: float) -> None:
        count = meta["completion_tokens"]
        previous = self.counts[index]
        if index in self.finished or not previous <= count <= self.output_len:
            raise RuntimeError(f"Invalid token progress: {previous} -> {count}")
        self.total_tokens += count - previous
        self.counts[index] = count
        if previous == 0 and count > 0:
            self.num_started += 1
            if self.num_started == len(self.counts):
                self.start = (now, self.total_tokens)
                self.all_started.set()
        reason = meta["finish_reason"]
        if reason is not None:
            if reason["type"] != "length" or count != self.output_len:
                raise RuntimeError(f"Incomplete generation: {count} tokens, {reason}")
            self.finished.add(index)
            if self.end is None:
                self.end = (now, self.total_tokens)

    def result(self) -> dict:
        if (
            len(self.finished) != len(self.counts)
            or self.start is None
            or self.end is None
        ):
            raise ValueError(
                "Every request must produce tokens and finish successfully"
            )
        start_time, start_tokens = self.start
        end_time, end_tokens = self.end
        if end_time <= start_time or end_tokens <= start_tokens:
            raise ValueError(
                "No common decode window: a request finished before all started"
            )
        duration = end_time - start_time
        measured_tokens = end_tokens - start_tokens
        return {
            "decode_throughput_tokens_per_s": measured_tokens / duration,
            "tpot_ms": duration * len(self.counts) / measured_tokens * 1000,
            "window_duration_s": duration,
            "measured_tokens": measured_tokens,
        }


async def stream_batch(
    session: aiohttp.ClientSession,
    base_url: str,
    prompts: list[list[int]],
    indices: list[int],
    counter: DecodeCounter,
    args: argparse.Namespace,
) -> None:
    payload = {
        "input_ids": prompts,
        "sampling_params": {
            "temperature": 0,
            "max_new_tokens": args.output_len,
            "ignore_eos": True,
            "stream_interval": args.stream_interval,
        },
        "stream": True,
    }
    async with session.post(
        base_url.rstrip("/") + "/generate", json=payload
    ) as response:
        if response.status != 200:
            raise RuntimeError(
                f"{base_url}: HTTP {response.status}: {await response.text()}"
            )
        # SGLang sends one JSON object per SSE data line. Iterating lines handles
        # arbitrary TCP fragmentation without treating network chunks as events.
        async for raw_line in response.content:
            if not raw_line.startswith(b"data:"):
                continue
            now = time.perf_counter()
            data = raw_line[5:].strip()
            if data == b"[DONE]":
                break
            event = orjson.loads(data)
            if "error" in event:
                raise RuntimeError(f"{base_url}: {event['error']}")
            index = event["index"]
            if not 0 <= index < len(indices):
                raise RuntimeError(f"{base_url}: Invalid request index {index}")
            counter.record(indices[index], event["meta_info"], now)
        else:
            raise RuntimeError(f"{base_url}: Stream ended without [DONE]")
    if any(index not in counter.finished for index in indices):
        raise RuntimeError(f"{base_url}: Stream ended before all requests finished")


async def report_prefill_progress(counter: DecodeCounter) -> None:
    started = time.perf_counter()
    total = len(counter.counts)
    while not counter.all_started.is_set():
        print(
            f"Prefill: {counter.num_started}/{total} requests returned first token "
            f"({counter.num_started / total:.1%}); "
            f"elapsed {time.perf_counter() - started:.1f}s",
            flush=True,
        )
        try:
            await asyncio.wait_for(counter.all_started.wait(), timeout=1)
        except TimeoutError:
            continue
    print(
        f"Prefill: {total}/{total} requests returned first token (100.0%); "
        f"elapsed {time.perf_counter() - started:.1f}s. Collecting decode results.",
        flush=True,
    )


async def benchmark(args: argparse.Namespace, prompts: list[list[int]]) -> dict:
    counter = DecodeCounter(counts=[0] * len(prompts), output_len=args.output_len)
    async with aiohttp.ClientSession(
        timeout=aiohttp.ClientTimeout(total=6 * 60 * 60), read_bufsize=1024 * 1024
    ) as session:
        async with asyncio.TaskGroup() as group:
            group.create_task(report_prefill_progress(counter))
            for index, base_url in enumerate(args.base_url):
                group.create_task(
                    stream_batch(
                        session,
                        base_url,
                        prompts[index :: len(args.base_url)],
                        list(range(index, len(prompts), len(args.base_url))),
                        counter,
                        args,
                    )
                )
    return counter.result()


def parse_args() -> argparse.Namespace:
    parser = argparse.ArgumentParser(
        description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter
    )
    parser.add_argument(
        "--model",
        required=True,
        help="Tokenizer model ID or local path; must match the servers",
    )
    parser.add_argument(
        "--base-url",
        nargs="+",
        default=["http://127.0.0.1:30000"],
        help="Server root URLs sharing one decode schedule; defaults to http://",
    )
    parser.add_argument(
        "--concurrency",
        type=int,
        default=256,
        help="Total requests across all URLs (default: 256)",
    )
    parser.add_argument(
        "--dataset",
        choices=("sharegpt", "gsm8k"),
        default="sharegpt",
        help="Prompt source (default: sharegpt); GSM8K uses main/train",
    )
    parser.add_argument(
        "--dataset-path",
        help="Local JSON/JSONL for the selected dataset; otherwise download/cache from Hugging Face",
    )
    parser.add_argument(
        "--input-len",
        type=int,
        help="Exact input tokens, including shared prefix; default: original prompt length",
    )
    parser.add_argument(
        "--prefix-len",
        type=int,
        default=0,
        help="Shared prefix tokens; requires --input-len (default: 0)",
    )
    parser.add_argument(
        "--output-len",
        type=int,
        default=512,
        help="Generated tokens per request, ignoring EOS (default: 512)",
    )
    parser.add_argument(
        "--stream-interval",
        type=int,
        default=8,
        help="Tokens between streaming updates; 1 increases output overhead (default: 8)",
    )

        "--seed", type=int, default=42, help="Dataset shuffle seed (default: 42)"
    )
    args = parser.parse_args()
    if args.concurrency <= 0:
        parser.error("Concurrency must be positive")
    if args.stream_interval <= 0:
        parser.error("--stream-interval must be positive")
    if args.output_len < 2:

    args.base_url = [
        url if url.startswith(("http://", "https://")) else f"http://{url}"
        for url in args.base_url
    ]
    return args
```

### End-to-end serving with PD disaggregation

On **Qwen3-235B-A22B-FP8 with 32 SM100 GPUs**, PD + AFD delivers **22.5% higher output throughput at comparable TPOT** (~15 ms), using the same 16-GPU prefill pool and the existing PD serving path.

Thanks for the suggestion. I just ran an additional EP16 experiment on SM100 with Qwen3-235B.

Scaling colocate to EP16 improves per-GPU throughput and brings it on par with AFD at the same GPU budget. The larger aggregate batch gives each expert more tokens to process, which can improve GEMM efficiency—the same batching effect that AFD aims to exploit by pooling tokens from multiple attention instances.

We also scaled AFD’s FFN group to EP16. This further improved per-GPU throughput. A key motivation for homogeneous AFD is to feed experts with larger batches while keeping attention-side concurrency manageable. Its potential advantage lies in independently tuning attention and FFN capacity to match their different computational characteristics.

These AFD results keep the A:F GPU ratio fixed. As expert execution becomes more efficient while attention-side remains unchanged, the bottleneck can shift toward attention. The optimal A:F ratio may therefore change with deployment scale.
