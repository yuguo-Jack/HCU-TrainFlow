# [Scheduler] Run the pipeline micro-batch ring on the in-flight step queue

[Upstream PR](https://github.com/sgl-project/sglang/pull/43898) · state: open · merged: False

## Original PR description

Stacks on #43897

- `InflightQueue` can hold a ring of per-slot records; the three PP loops keep their micro-batches there instead of `mbs` / `last_mbs` lists.
- Under `SGLANG_DEBUG_INFLIGHT_STEPS`, each push checks the slot index; a PP loop asserts overlap is off when it installs the ring.
- The sampling-mask query and scripted runtime tests read the slots through `get_pp_batches`.
- The unreachable `PREBUILT` checks in the PP output relay are dropped.

No behavior change.
