# [Perf] R3: Skip routed-expert capture on ranks that send no rows (2/3)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47553) · state: closed · merged: True

## Original PR description

Stacked on #47552.

## Why?

Without DeepEP, every TP rank computes the same top-k ids, but only the output rank (pp0 · attn-tp0 · attn-cp0) sends them. The other ranks still copied every MoE layer's ids into a device buffer that nothing reads.

```text
Before (TP8, no DeepEP)                            After
rank 0:   capture → device buffer → host → out     rank 0:   capture → device buffer → host → out
rank 1-7: capture → device buffer  (never read)    rank 1-7: skip
```

## What?

- Only the output rank allocates the routed-experts device buffer.
- Without DeepEP the other ranks skip capture. With DeepEP they still join each layer's all-gather, so the output rank doesn't hang, but they keep nothing. #47554 removes that per-layer all-gather.

## Verification?

Same 8×H200 benchmark as #47552 (Qwen3-30B-A3B-Instruct-2507; A = `--tp 8`, B = `--tp 8 --dp 2 --enable-dp-attention --moe-a2a-backend deepep --deepep-mode auto`), median of 3 runs, each setup on one node with no profiler (**observed**):

```text
                                         #47552                 this PR
A  --tp 8                   device buf   8 × 12 MB              1 × 12 MB
                            ITL c1       3.621 ms               3.571 ms   (−1.4%)
                            ITL c32      5.357 ms               5.289 ms   (−1.3%)
                            ITL c128     8.227 ms               8.178 ms   (−0.6%)
B  DP attention + DeepEP    device buf   8 × 12 MB              2 × 12 MB
                            GPU memory   -                      −32 MiB on each of 6 other ranks
                            ITL c1       5.421 ms               5.393 ms   (−0.5%)
                            ITL c8       5.668 ms               5.632 ms   (−0.6%)
                            ITL c128     7.462 ms               7.391 ms   (−1.0%)
TTFT c1                                  unchanged (A 24.4 → 24.2 ms, B 60.9 → 61.0 ms)
routed experts, 4 greedy prompts                                bitwise identical to main
```

- A gains more: its 7 other ranks now skip capture entirely. In B they still join each layer's all-gather, which #47554 removes.
- Also DeepSeek-V2-Lite-Chat TP2: device buffers 2 → 1, routing bitwise identical (**observed**).

## Test?

- `test_routed_experts_scattered_a2a.py::TestOutputRankHostCache`: `test_only_output_rank_keeps_rows` and `test_scattered_other_rank_only_joins_the_all_gather`. Both **observed** passing on H200 (`lmsysorg/sglang:dev`), and both fail on #47552.
- `pre-commit`: **observed** passing.
