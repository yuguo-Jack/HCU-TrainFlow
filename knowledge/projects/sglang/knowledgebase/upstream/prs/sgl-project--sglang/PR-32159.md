# [Activation] Use FlashInfer silu_and_mul on SM120+ for 1.49x speedup

[Upstream PR](https://github.com/sgl-project/sglang/pull/32159) · state: closed · merged: False

## Original PR description


## Motivation
Prerequisite: Flashinfer 0.6.15 

Flashinfer 0.6.15 add new API called silu_and_mul() outperforms sgl_kernel's implementation by 1.49x on SM120
   (Blackwell Desktop) GPUs.

   Microbenchmark (SM120, B=32, H=8192):
   - sgl_kernel: 5.63 μs/call
   - FlashInfer: 3.79 μs/call (1.49x faster)

   E2E benchmark (DSv4-Flash, TP4+DP2, CC=32, in=4096/out=150):
   - Throughput: 297 → 312 tok/s (+5.1%)
   - TPOT: 74.09 → 70.31 ms (-5.1%)


## Modifications

 In python/sglang/srt/layers/activation.py, after importing silu_and_mul from
   sglang.jit_kernel.activation, add a runtime override for SM120+ (compute capability >= 12)
   that replaces it with FlashInfer's implementation.
