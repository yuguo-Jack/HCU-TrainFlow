# [Fix] rust-server: Skip server endpoint collective on elastic-EP joiners

[Upstream PR](https://github.com/sgl-project/sglang/pull/47506) · state: open · merged: False

## Original PR description

addresses #47505

elastic-ep joiners cannot enter the startup `world_group` endpoint all-gather because serving ranks already completed it during cluster startup and never re-enter it. this skips the collective and returns an empty list when `is_ep_joiner` is set, avoiding hangs on scale/recover joiners.

added unit test verifying `world_group.all_gather_object` is skipped when `is_ep_joiner=True`.
