# [Fix] distributed: Keep deprecated parallel_state getters traceable under torch.compile

[Upstream PR](https://github.com/sgl-project/sglang/pull/47346) · state: open · merged: False

## Original PR description

## Motivation

The deprecated `parallel_state` getters (`get_tp_group()`, `get_attn_tp_group()`, `get_moe_ep_group()`, `get_tensor_model_parallel_world_size()`, ...) are wrapped by `_warn_if_called_from_outside`, which calls `sys._getframe(1)` to find the caller. Callers under `sglang.srt.distributed.` are exempt and are never added to `_ALREADY_WARNED`, so the frame lookup runs on every call from `communication_op` (for example `tensor_model_parallel_all_reduce()` -> `get_tp_group()`).

TorchDynamo cannot trace `sys._getframe`, so every collective inside a compiled region graph-breaks, and `torch.compile(..., fullgraph=True)` fails.

## Modifications

Skip the caller check while `torch.compiler.is_compiling()`. Eager behavior, including the `DeprecationWarning` for external callers, is unchanged.

Migrating the remaining in-package callers to `get_parallel()` would also fix this; this is the smallest change that covers every caller until the getters are removed.

## Accuracy Tests

No numerical change: the getters return the same objects. With full-graph `torch.compile` decode (`fullgraph=True`) on an out-of-tree platform, the collectives trace without graph breaks and DeepSeek-R1-0528 (TP8) GSM8K (5-shot, flexible-extract) is 0.9583 (reference 0.9651 +/- 0.0107).

## Checklist

- [x] Formatting: black-stable (ruff-format compatible), imports in isort order.
- [x] Unit test: a new case in `TestTheAccessorsHaveNoCallersOutsideTheirPackage` (`test/registered/unit/test_runtime_context.py`) compiles `tensor_model_parallel_all_reduce` with `fullgraph=True` against a stub TP group. Before this change it fails with `Unsupported: ... sys._getframe`; after it, it passes.
