# [AMD] Use SHUFFLE KV and AITER sparse attention for MiniMax-M3

[Upstream PR](https://github.com/sgl-project/sglang/pull/41998) · state: open · merged: False

## Original PR description

## Motivation

MiniMax-M3 stores sparse K/V in NHD and gathers selected blocks for AITER prefill. This PR stores sparse-layer K/V in the layout AITER paged attention reads directly, removing that gather and using the same consumer for prefill, decode and verification.

## Modifications

- Store sparse K/V in separate page16 SHUFFLE planes within the existing allocation, while keeping allocator pages at 128 tokens.
- Feed the AITER indexer's page tables into `pa_decode_gluon` and reuse selections across the existing layer groups.
- Enable the writer and consumer together for supported gfx950 FP8 HD128 configurations without PD disaggregation. Dense layers and index-K retain NHD storage.
- With HiCache, keep the SHUFFLE layout when pages move through `--hicache-io-backend kernel` with `--hicache-mem-layout layer_first`, which copies whole 128-token pages. Other HiCache transfers keep NHD.
- Add backend, cache-layout, scaling, long-context, graph-replay and HiCache host-pool regressions.

Depends on #41708. Set `SGLANG_M3_USE_AITER_SPARSE_PA=0` to disable this path.

## Accuracy Tests

`amd/MiniMax-M3-MXFP4`, MI355X, TP4/EP1, full 5-shot GSM8K (1,319 questions), chat-completions, 16384-token output budget, temperature 0, real EAGLE3 verification, 8 concurrent requests.

| Configuration | Strict-match | Flexible-extract |
|---|---:|---:|
| `SGLANG_M3_USE_AITER_SPARSE_PA=0` | 96.74% | 96.66% |
| This PR | 96.36% | 96.36% |
| This PR, HiCache (`kernel`, `layer_first`) | 97.04% | 96.97% |

Repeated runs of the same server vary by up to 7 answers.

25 GPU regression tests passed on MI355X with the enable flags unset: 10 sparse-PA, 9 indexer and 6 HiCache host-pool tests. Tested with AITER `e7d2453f25`.

## Benchmarking and Profiling

AgentX on MI355X, TP4/EP1, C32, no KV offload, 3600 seconds per run, and 10 warmup requests per lane. Both sides use EAGLE3 with simulated acceptance length 2.78, HD128 ASM prefill and AITER FP8 index selection; the candidate adds only SHUFFLE KV and sparse PA.
