# [Feat] lora: Shared token routes and the LoRA workspace (02/21)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42869) · state: open · merged: False

## Original PR description

Part 02 of 21 of the LoRA runtime stack (branch `lora-stack-01-route-primitives`, base `lora-stack-00-shared-hooks`). The stack is cut from the development branch of #42284.

## What this part adds

Add the route primitives both LoRA engines run on: RouteView, the sorted token
route builder (one route per forward and block size, capacity independent of
the request count), and LoraWorkspace, which keys routes, side streams and
events by the caller's stream. Register the route builder in the lora kernel
inventory; kernels/README.md describes the lora kernel group's layout.

Tests: route construction and replay, workspace reuse across streams, route
scratch sizing, and the host-level route-view, bucket-id and dispatch
contracts.
