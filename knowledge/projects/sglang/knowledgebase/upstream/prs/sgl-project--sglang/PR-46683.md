# [Perf] Support prompt-only hybrid cache tracking

[Upstream PR](https://github.com/sgl-project/sglang/pull/46683) · state: open · merged: False

## Original PR description

## Motivation

Hybrid prefix-cache users that publish only prompt checkpoints still prepare decode tracking masks and indices, capture checkpoint-save work, and update checkpoint-boundary bookkeeping. These operations are unnecessary when generated tails are never inserted into the cache.

## Modification

Add an internal request-pool policy, fixed before graph capture, that skips decode checkpoint preparation and saving while continuing live KV/recurrent-state updates. The caller must suppress generated-tail cache insertion. The default remains false. Also expose an independent unified-prefill switch so callers can select that prefill kernel without changing decode splitting.

```text
prefill -> track reusable prompt checkpoint
 decode -> update live state, skip reusable-checkpoint tracking
 finish -> caller publishes prompt only
```

This is the SGLang runtime counterpart of [sglang-omni#3235](https://github.com/sgl-project/sglang-omni/pull/3235). It is separate from the GDN graph implementation in #46619.

## Benchmarking Result

Integration measurement on one H200, Drama3 streaming c16. Both arms used the GDN graph runtime from #46619 and the same request-seed foundation. A disabled prefix caching; B enabled Omni prompt-only prefix caching with these runtime policies. This measures the combined cache integration, not the isolated cost of these six runtime changes.

Executed A → B → B → A → A → B, with fresh servers, 128 substantial/256 prime/256 shape warmup requests, then 256 timed requests per visit.

| Visit | Arm | Requests/s | Mean TTFA (ms) |
| --- | --- | ---: | ---: |
| 1 | A | 10.445 | 225.1 |
| 2 | B | 11.031 | 206.3 |
| 3 | B | 10.807 | 205.9 |
| 4 | A | 10.557 | 218.3 |
| 5 | A | 10.446 | 219.5 |
| 6 | B | 10.957 | 205.5 |

Mean throughput improved 4.28%; mean TTFA decreased 6.82%. B reused 81.95% of prompt tokens. This is a modest single-workload result without independent A/A calibration. The standalone branch is based on 9f6678aa; the measured stack applied the original policy on GDN head 31913fac. Subsequent control-flow cleanup preserves that policy, but the current head has not received a fresh GPU qualification.

## Accuracy Test

The integration passed early 32-pair and retained middle 256-pair WER/SIM gates. Main corpus WER was A 1.5659% / B 1.1653%; mean speaker similarity was A 63.488 / B 63.226, within the predeclared 1-point regression gate. All 1,536 timed requests succeeded with zero max-token hits. The GPU lifecycle regression passed 18 synthetic requests covering cache reuse, changed residual input, one-token suffix replay and abort/reuse.
