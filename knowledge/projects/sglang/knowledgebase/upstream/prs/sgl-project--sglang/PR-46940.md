# [Feat] PD: Decode KV offload for Mamba and SWA hybrid models

[Upstream PR](https://github.com/sgl-project/sglang/pull/46940) · state: open · merged: False

## Original PR description

## Motivation

`--disaggregation-decode-enable-offload-kvcache` writes each decode request's new KV to L3 so the next turn's prefill restores it instead of recomputing it. The decode manager built its own host pool per pool type and supported only MHA/MLA and unified-SWA pools, so hybrid models with sliding-window and Mamba layers (e.g. Inkling) fail at startup with `Unsupported KV cache type for decode offload`.

Inkling test checkpoint (`thinkingmachines/Inkling`, revision `test`: window 512, page 128, Mamba track interval 128), PD on one node (TP1 prefill with `write_back` HiCache and a file L3 store, TP1 decode, NIXL), 2 sessions × 3 turns of 384 new tokens:

| turn | prompt | decode-written tokens (per session) | prefill reuse of them, offload off | offload on | tokens and logprobs vs a no-cache reference |
|---|---|---|---|---|---|
| 1 | 992 | 256 | 0 (`cached_tokens` 512) | **256** (`cached_tokens` 768) | identical (drift 0) |
| 2 | 1472 | 384 | 0 (896) | **384** (1280) | identical (drift 0) |

Run on a fork carrying this change with #46934 and #46935, which these hits need (shorter than the window; `write_back` prefill).

## Modifications

- The decode's prefix-less tree cache attaches the same HiCache stack a prefill builds, and the manager writes through it, so every object it stores (KV, SWA window, Mamba state, draft sidecars) is one a prefill reads.
- Mamba: an offloading decode keeps boundary tracking (`auto` picks the extra buffer). A chunk ends on the track grid and takes the tracked state by donation once its host write is queued, so a failed write keeps the state for the retry. Finished requests release through `release_kv_cache` (the old path leaked Mamba slots).
- Refused at startup: a prefill of another attention TP size or with attention CP (L3 keys carry the attention-TP rank; MLA exempt); a decode radix cache together with offload (both would write through the tree's controller); pure-SWA models (their prefill has no L3 path). The HiCache DCP checks now apply to offload.

For reviewers: the attention-TP check also refuses heterogeneous-TP `page_head` reuse via `tp_lcm_size` (SWA and Mamba objects are not head-split); and a fused draft placement is declined under offload, as under host-pool retraction.
