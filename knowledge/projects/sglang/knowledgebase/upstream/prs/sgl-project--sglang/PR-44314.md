# [Fix] weight-export: handle missing send groups without KeyError

[Upstream PR](https://github.com/sgl-project/sglang/pull/44314) · state: open · merged: False

## Original PR description

## Motivation

`send_weights_to_remote_instance()` indexes `_weights_send_group` before its missing-group branch. Sending before initialization, or sending again after the first call consumes the group, therefore raises `KeyError` instead of returning the existing initialization guidance.

## Modifications

Use `dict.get()` for the guard. Existing `None` handling, broadcasts and process-group cleanup are unchanged. Add three registered CPU regression tests covering unknown groups, `None` groups, and a successful send followed by a repeated call (including TP rank/port selection).

## Validation

- Real module imports and single-rank CPU Gloo A/B, Python 3.12 / Torch 2.11.0+cu130: all four candidate checks passed (missing, None, successful broadcast, repeat-after-send). The unchanged baseline raised `KeyError` in the missing/repeated cases. No GPU, server or model download was used.
- Applicable pre-commit formatting/lint checks passed. Three local hooks required invoking their unchanged scripts with `python` because Windows has no working `python3` launcher; all three then passed.
- The unchanged registered `test/registered/unit/model_executor/model_runner_components/test_weight_exporter.py` now runs against complete package source with no import stubs: candidate `aa2a943` passes 3/3; the unchanged production control errors in the missing/repeated cases and passes the `None` control. Linux / Python 3.12 / Torch 2.11.0+cu130, CPU engine, no install or model download.
- CUDA remained uninitialized. The framework parses the first character of `CUDA_VISIBLE_DEVICES`, so the local CPU run used absent ordinal `9` after verifying physical indices 0–7. Both arms emitted the same optional CUDA-backend probe warnings under the process memory bound. This is a local registered-test result, not official CI; `base-a-test-cpu` still requires maintainer authorization.

Model-output accuracy and speed benchmarks are not applicable to this error-path fix.

AI-assisted implementation and investigation.
