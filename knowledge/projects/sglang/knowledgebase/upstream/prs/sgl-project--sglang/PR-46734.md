# [Feat] sgl-model-gateway: Accept bucket policy in the standalone CLI

[Upstream PR](https://github.com/sgl-project/sglang/pull/46734) · state: open · merged: False

## Original PR description

## Motivation

The `bucket` policy (prefill chosen by prompt length, boundaries rebalanced by character load) is implemented and wired
for PD prefill, and the Python launcher accepts it, but the standalone Rust binary's `--policy`, `--prefill-policy` and
`--decode-policy` reject it.

## Modifications

- Add `bucket` to the three value parsers and map it in `parse_policy`.
- Add `--bucket-adjust-interval-secs` (default 5, as in the Python launcher); `bucket` also takes
  `--balance-abs-threshold` / `--balance-rel-threshold`, as in the Python launcher.

## Accuracy Tests

Routing-only change. End to end: 2P1D (DeepSeek-V4-Flash, 8x MI308X) behind
`--pd-disaggregation --prefill-policy bucket --decode-policy round_robin`: requests spread over both prefill servers,
gsm8k 200 0.93, 0 router errors.

Unit test in `src/main.rs`: `--prefill-policy bucket --bucket-adjust-interval-secs 7` yields `PolicyConfig::Bucket`
with interval 7. `cargo +nightly fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings` and
`cargo test` pass.
