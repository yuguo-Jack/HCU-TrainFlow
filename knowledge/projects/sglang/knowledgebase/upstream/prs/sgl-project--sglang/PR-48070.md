## Motivation

Sync the MiniMax-M3.1 AgentX explorer's GB300 Dynamo + SGLang launches with https://github.com/SemiAnalysisAI/InferenceX/pull/4750 (verified in https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41528865560):

- 6P1D (prefill DEP2, decode DEP16): add c220, c240 and c260.
- New Dynamo aggregated TP4 cell at c1 with the MSA MonoKernel (`--enable-nvidia-megakernel`, `--page-size 128`, `--speculative-num-steps 1`, `--speculative-num-draft-tokens 8`).
- The MonoKernel row sits after TP4 c1 in the InferenceX config, so the later aggregated points and cell ids shift by one row.

The new MonoKernel point decodes to the command that ran in that workflow run (excluding host, port and reporting flags); all other launch commands are unchanged. `check_cookbook_configs.mjs`, `mint validate` and `mint broken-links` pass.
