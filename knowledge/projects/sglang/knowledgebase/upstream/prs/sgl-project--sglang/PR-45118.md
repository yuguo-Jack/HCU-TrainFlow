# [Fix] diffusion: Prevent int32 overflow in Qwen-Image-2.1-Turbo VAE RMSNorm

[Upstream PR](https://github.com/sgl-project/sglang/pull/45118) · state: closed · merged: True

## Original PR description

## Motivation

The channel-first RMSNorm pointwise kernel in the Qwen-Image 2.1 VAE computes flattened offsets in int32. When `CHANNELS * SPATIAL` exceeds `INT32_MAX`, compilation can fail. A larger total element count across batches can also overflow the flattened index.

With SGLang's default `quality="lossless"` setting, Qwen-Image-2.1-Turbo can fail when generating 4K images, reporting an error at `norm_index`:

`CompilationError: Scalar 2371092480 is out of range for type int32`.

Fixing the channel RMSNorm indexing allows generation to complete.

## Modifications

- Cast `program_id` to int64 **before** multiplying by `BLOCK` in `channel_rmsnorm_preserve_reduction.py`:
   ```python
   index = tl.program_id(0).to(tl.int64) * BLOCK + tl.arange(0, BLOCK)
   ```

## Accuracy Tests

### Fix verification

`quality` uses the default `lossless` setting. The environment uses PyTorch 2.13.0 and Triton 3.7.1, with text-encoder CPU offload enabled and VAE tiling disabled. Both arms use the same model, inputs, seeds and eight-step configuration; only the indexing expression changes. All four cases below use an actual size of **3840×2144**. Before the fix, each fails to compile due to the int32 error and produces no image. After the fix, each completes one warmup and three measured requests; all four outputs within each case are byte-identical. Times are the means of the three measured requests. Raw request times and configurations are in `default-lossless-validation.json` in the bundle.

### Output equivalence

**Environment:** 1×H20 (SM90), Python 3.12.15, PyTorch 2.14.1+cu130, CUDA 13.0, Triton 3.8.0.

- **30 CUDA regression tests passed**, including full nonuniform BF16/FP16 tensors crossing `2**31`. All four full-tensor outputs match the Torch reference byte for byte.
- 4K text-to-image test with `quality` set to `exact`: **generation fails before the fix, with no image; after the fix, generation succeeds, and the warmup image and all three measured images exactly match the Torch norm reference images.**
- The 4K generation was confirmed to call the fixed channel RMSNorm function.
