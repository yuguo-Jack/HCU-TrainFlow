# [Fix] deps: Pin python-dateutil<3 to keep botocore resolvable

[Upstream PR](https://github.com/sgl-project/sglang/pull/45857) · state: closed · merged: True

## Original PR description

## Motivation

python-dateutil 3.0.0 (released 2026-10-21) is getting installed by the docker deps step and frozen into constraints.txt. botocore, pulled in later by runai-model-streamer[s3], requires python-dateutil<3.0.0, so the framework dev-tools install can no longer resolve (pip backtracks through every boto3 release and fails with resolution-too-deep). This causes docker/Dockerfile and docker/Dockerfile.cu134 to fail to build (maybe others too).
