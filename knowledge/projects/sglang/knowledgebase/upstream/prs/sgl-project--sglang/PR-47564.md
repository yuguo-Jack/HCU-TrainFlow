# [Test] server_args: Align Muse Spark platform mocks

[Upstream PR](https://github.com/sgl-project/sglang/pull/47564) · state: open · merged: False

## Original PR description

## Motivation

The Muse Spark launch test simulates NVIDIA GPUs, but ModelConfig still reads the host's real HIP status. On ROCm, this rejects the simulated FP4 configuration before the launch assertions run.

## Modifications

Mock `ModelConfig.is_hip` alongside the existing NVIDIA platform override. Keep all assertions and production code unchanged.

## Validation

On MI355X / ROCm 10, upstream a8106545 failed all four Blackwell/Hopper quantization subtests. With this change, all four passed. Formatting and lint passed. Hosted CI is pending.
