# [Feat] [NPU] attention: support mixed-chunk on the ascend attention backend

[Upstream PR](https://github.com/sgl-project/sglang/pull/47367) · state: closed · merged: True

## Original PR description

## Motivation

`--enable-mixed-chunk` crashed with `NotImplementedError` on Ascend NPUs for anything beyond plain MHA: `AscendAttnBackend.forward_mixed` rejected batches carrying indexer `topk_indices` (DSA models, e.g. GLM-5.2), and its own FIA call for the plain-MHA case misread the paged-KV geometry (FIA pools expose per-layer views shaped `[P*ps, 1, H, D]`, so `block_size` derived from `k_cache.shape` is 1), and did not handle attention-sink layers or DP token padding.

A mixed batch is just a varlen extend batch whose rows have heterogeneous extend lengths (decode rows are 1-token extends), so no new kernel capability is required — the extend routing already covers all of the above (per-row query/KV lengths, `sparse_mode=3`, SWA block tables, `learnable_sink`, DP padding trim).

The `ASCEND_USE_FIA=0 and qk_head_dim > 128` guard is likewise obsolete: it dates back to the `torch_npu._npu_paged_attention_splitfuse` implementation (#12491, head_dim limit 128), but `forward_mixed` now always calls `npu_fused_infer_attention_score` (#15518), which supports `qk_head_dim` up to 256 — the flag no longer selects the operator on this path.

## Modifications

- `AscendAttnBackend.forward_mixed` (`ascend_backend.py`): rewritten as a single guard plus full delegation to `forward_extend`, so mixed batches traverse exactly the same routing as prefill batches — DSA sparse path (GLM-5.2), FIA v2 + `learnable_sink` + SWA block tables (MiMo-V2.5), plain TND FIA (MHA). Also picks up the DP token padding trim the old path lacked.
- Drop the stale `ASCEND_USE_FIA=0 and qk_head_dim > 128` rejection; `forward_mixed` now raises only for the pure MLA backend (without DSA).
- `modelslim.py`: fall back to the fused prefix when the scheme lookup misses after `packed_modules_mapping` rewrites it; fused-layout checkpoints (e.g. MiMo-V2.5 `fused_qkv`) otherwise silently degrade to bf16.
