# [Closed] Kandinsky6 fused QK-norm+RoPE and norms: no default-path speedup

[Upstream PR](https://github.com/sgl-project/sglang/pull/47755) · state: closed · merged: False

## Original PR description

## Status: closed, not worth merging

After addressing review feedback (gating the non-exact paths by quality), the end-to-end speedup on the default path is zero. Closing. The numbers below replace the ones originally posted here, some of which were wrong.

## What was tried

- Fused QK-norm + matrix RoPE into one Triton kernel (`qknorm_matrix_rope`).
- Fed bf16 activations straight into the fused LayerNorm + scale/shift instead of an fp32 copy.
- Used `residual_gate_fp32` for the gated residuals.

## Findings

Operator-level check against fp64 (`quality_tier_admission`, DiT-like inputs with outlier channels, dim 4096, head dim 128, seq 4096 and 32760):

| op | result |
|---|---|
| QK-norm + RoPE | error identical to eager, qualifies as lossless |
| gated residual (`residual_gate_fp32`) | bit-exact |
| bf16-input norm + scale/shift | about 1.4x eager RMS error, up to 1.67x max error at seq 32760, fails lossless, `high` tier only |

End to end on 1x H100, Kandinsky-6.0-Lite-distill-5s, 121 frames 512x768, seed 42, 10 timed runs per arm in balanced order:

| arm | mean | vs main |
|---|---|---|
| main | 23.26 s | |
| this PR, default quality (`lossless`: QK-norm+RoPE only) | 23.26 s | 0.0% (95% CI -0.1% to +0.1%, p=0.82) |
| this PR, `quality="high"` (adds bf16-input norms) | 22.51 s | 3.2% (95% CI 3.1% to 3.3%) |

So all of the gain came from the bf16-input norm, which is not lossless. The fused QK-norm+RoPE showed no measurable end-to-end gain despite its microbenchmark.

Corrections to the earlier description:
- The earlier 43.2 dB parity figure does not reproduce. Ungated, this PR vs main on H100 is 26.0 dB over the full clip (28.0 dB on frame 0). For scale, main on H100 vs main on H200 is 24.95 dB, so that drift is within the spread across legal environments, but the earlier number was wrong.
- The earlier 4.4% end-to-end figure was measured before gating. With the review fixes applied, the default path is unchanged.
