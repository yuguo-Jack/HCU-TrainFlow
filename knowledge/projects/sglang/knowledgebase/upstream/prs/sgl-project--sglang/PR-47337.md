# [Fix] model_loader: Neutral UE8M0 block scales for dummy weights

[Upstream PR](https://github.com/sgl-project/sglang/pull/47337) · state: closed · merged: True

## Original PR description

## Motivation

`initialize_dummy_weights` only initializes floating-point tensors. MXFP8 layers allocate their UE8M0 block scales (`weight_scale_inv`) as `torch.uint8` zeros (`fp8.py`, MoE and linear `create_weights`), so with `--load-format dummy` those scales stay 0. In UE8M0, 0 means 2^-127, so every MXFP8 weight dequantizes to roughly zero. The MXFP8 layers then produce near-zero outputs, which can propagate to NaN downstream.

## Modifications

- `initialize_dummy_weights`: fill uint8 `*weight_scale_inv` tensors with 127 (2^0), the UE8M0 counterpart of the existing neutral FP4 global scales (filled with 1.0).
- Unit test `test_ue8m0_dummy_block_scales_are_neutral` next to `test_nvfp4_dummy_scales_are_neutral`.

## Accuracy Tests

Affects only `--load-format dummy`; real checkpoints load their own scales.
