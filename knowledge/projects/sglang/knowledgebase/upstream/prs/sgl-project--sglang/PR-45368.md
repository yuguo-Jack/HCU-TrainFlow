## Motivation

`test_per_token_group_quant.py::test_masked_post_quant_writes_exactly_the_real_rows` fails on `main` with `ImportError: cannot import name 'silu_and_mul_contig_post_quant' from 'sglang.kernels.ops.moe.dsv4'`, which breaks `jit-kernel-unit-test-4-gpu-b200` (e.g. https://github.com/sgl-project/sglang/actions/runs/39393626348/job/118531172346).

#44618 added the test with an import from `moe.dsv4`, and #45112 then moved `silu_and_mul_contig_post_quant` to `activation.silu_and_mul_clamp`, updating only the sibling test's import.

## Modifications

Import `silu_and_mul_contig_post_quant` from `sglang.kernels.ops.activation.silu_and_mul_clamp` in that test, matching the sibling test at line 326. `silu_and_mul_masked_post_quant` is still imported from `sglang.kernels.ops.moe.dsv4`. Test-only change.
