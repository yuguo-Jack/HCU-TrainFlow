# [Doc] [AMD] cookbook: Refresh DeepSeek V4 AgentX PD recipe optimizations

[Upstream PR](https://github.com/sgl-project/sglang/pull/44454) · state: closed · merged: True

## Original PR description

## Motivation

The DeepSeek-V4 cookbook's MI355X Pro Official (0813) PD recipes still use the earlier AgentX kernel and router settings. Sync the optimized DSpark configuration into the Deployment and Playground commands and document the remaining concurrency points.

## Modifications

- Enable FP8 unified KV on both PD roles at the TP-only presets, and dense mxscale on both TP roles / DP decode only. Keep the decode dispatch budget aligned with the DSpark block size.
- Use DP-aware `power_of_two` decode routing with `least_requests` and one-second load polling for Pro Official High-Throughput. TP-only routing remains round-robin.
- Keep the panel's c16 / c48 / c256 presets; document c1 (replacing c4), c32, c192, c384 and c512 overrides, including admission limits, graph sizes and c512-only prefill EPLB.
- Keep the original Pro EAGLE/MTP presets unchanged.
