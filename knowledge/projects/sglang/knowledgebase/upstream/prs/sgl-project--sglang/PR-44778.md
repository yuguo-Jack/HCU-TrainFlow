# [Fix] kda: Use raw beta in prefill CUDA graphs

[Upstream PR](https://github.com/sgl-project/sglang/pull/44778) · state: closed · merged: True

## Original PR description

KDA eager and graph extend both receive raw beta, but the graph helper infers beta activation from gate rank. Kimi-K3 supplies a 4D gate, causing graph replay to skip the required beta sigmoid. Set `beta_is_raw=True` to match eager extend while retaining the existing gate-shape normalization.

Validation: A semantically equivalent version of this fix passed GPU serving smoke tests with prefill/decode CUDA graphs enabled, including prefix-cache reuse; sampled activations and logits were finite. This one-line patch passed 16 isolated CPU adapter checks, including 3D/4D raw-beta inputs and padding; the unpatched helper fails the eight 4D cases. Python compilation, Black, and `git diff --check` passed. The existing CUDA graph/kernel test suite was not rerun for this commit.
