# [Test] constrained: Cover JSON whitespace limits

[Upstream PR](https://github.com/sgl-project/sglang/pull/43981) · state: open · merged: False

## Original PR description

## Motivation

Add focused regression coverage for --constrained-json-max-whitespace-cnt, ensuring that CLI configuration reaches XGrammar and that JSON Schema matching and token masks enforce the configured limit.

## Modifications

- Add test/registered/unit/constrained/test_xgrammar_whitespace.py with 10 CPU unit tests using a small synthetic vocabulary.
- Cover the unbounded default and limits of 1 and 2, including spaces, tabs, LF newlines, mixed whitespace, and boundary conditions.
- Verify that each whitespace run has its own budget and that spaces inside string values remain unrestricted.
- Test token masks for tokens containing multiple whitespace characters, accumulated whitespace across tokens, and budget resets.
- Register the tests in base-a-test-cpu.
