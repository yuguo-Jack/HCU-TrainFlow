# [Perf] model_executor: Return the input from ForwardBatch._pad_tensor_to_size when no padding is needed

[Upstream PR](https://github.com/sgl-project/sglang/pull/47349) · state: open · merged: False

## Original PR description

## Motivation

`ForwardBatch._pad_inputs_to_size` passes every batch tensor (input ids, positions, sequence lengths, cache locations, ...) through `_pad_tensor_to_size`, which always `torch.cat`s a pad. When the tensor already has the target size the pad has zero rows, and the `cat` is a pure allocation plus copy for each tensor on each forward.

That is the common case in `prepare_mlp_sync_batch`. Under sum-length DP padding the target is the rank's own token count (rounded up to a multiple of the attention-TP size). Under max-length padding, every rank whose batch already matches the largest one takes the same no-op path.

## Modifications

Return the tensor unchanged when `tensor.shape[0] == size`. Every caller (`_pad_inputs_to_size` and the spec inputs' `pad_batch`) reassigns the result to the attribute it came from. When no padding runs at all, these attributes already alias the scheduler-side tensors, so returning the input matches that case.

## Accuracy Tests

Values are unchanged. On an out-of-tree platform, with TP8 MoE models using expert parallelism: outputs match the golden tokens, and GSM8K is 0.9719 (baseline 0.9742 +/- 0.0107).
