# [Fix] spec: Keep softmax batch-independent under deterministic inference

[Upstream PR](https://github.com/sgl-project/sglang/pull/47773) · state: open · merged: False

## Original PR description

## Motivation

With `--enable-deterministic-inference`, which promises batch-invariant ops, sampled speculative requests on B200 can get different tokens when the batch size changes.

On `openbmb/MiniCPM5-2B` with DSpark and `--random-seed 42`, row 0 gets token 19929 at batch 1 and 19930 at batch 8 and 32. Over 16 seed and prompt pairs, one differs between batch 1 and 8 on main and none with this change.

This keeps a contract and has no expected accuracy effect, because only rounding changes. EAGLE and NEXTN show token flips only on synthetic logits, so DSpark is the only server-visible symptom seen.

Under the flag, the sampler uses `torch.softmax`, but DSpark's `SoftmaxTemp` calls FlashInfer and four draft and verify calls use `sampling.softmax`. On B200, both select a launch configuration from the row count.

No open PR fixes this. #46657, #45894, #46211 and #47317 edit the same softmax code, so the later merge must keep the flag check.

## Modifications

Under the flag, `spec_softmax` uses `torch.softmax` for the four calls, and `SoftmaxTemp` uses its existing Triton branch. Other runs do not change.

DSpark avoids `torch.softmax` because its bits can change with row position at some vocabulary sizes, as measured on MiniCPM-V-4.7-1B at 248094, which is not a multiple of 4. Draft and verify keep it to match the sampler, so they share this limit.

Their only failure also occurs on main in that environment, and GPU-only cases skipped.

No accuracy eval ran with the flag on. On B200 (torch 2.14.1, FlashInfer 0.7.2), softmax rows compare a row in a batch with that row alone.

Not fixed: sampled DSpark ignores `sampling_seed`, the sampler keeps that limit, and top-k or top-p target probabilities keep `torch.softmax`, untested for position dependence.

Not checked: SM103, ROCm, other Blackwell parts, Hopper, NPU, Sail, verify-side flips, a draft or verify flip reaching server output, `test_multi_layer_eagle_reject_sampling_deterministic`, DeepSeek-V4 (the flag refuses `dsv4`), and full CI.
