## Motivation

Part 3/5 of the DeepSeek-V4.1 CP>1 support series, split from the original combined PR [#45954](https://github.com/sgl-project/sglang/pull/45954). This PR extends upstream CP1 folded encoder replay to interleaved Prefill CP, with GPU prefix-cache and HiCache L2 recovery.

Compacting a replay tail changes its row numbers, but must preserve its original CP owners and request positions. The request window is maintained in global sequence order, while attention queries and indexer request counts are rank-local. Hidden states, auxiliary states, and logits must use the same compact-row mapping.

For example, retained logical rows `[5, 6, 12, 20, 31]` under CP8 belong to ranks `[5, 6, 4, 4, 7]`. Redistributing them by compact indices `0..4` would assign the wrong owners. Ranks with no retained rows must still participate using valid padding. This is an illustrative layout, also covered by the CPU ownership regression.

## Modifications

- Reuse upstream folded replay and preserve original owners when packing compact tails and gathering outputs.
- Keep window writes global, queries local, and padding outside valid history. Apply the compact mapping consistently to input IDs, indexer request rows, hidden/auxiliary capture, and logits.
- Restore full CP metadata after compact-output gathers, including failure paths.
- Preserve replay-owned KV when cache insertion would otherwise rebind it to a stored snapshot the request never adopted.
- Admit the supported CP>1 configuration after resolving effective parallelism; retain upstream CP1 and encoder-off dispatch.

Scope: text-only SM90 CUDA, interleave Prefill CP with attention TP=1, PP/DP/DCP/attention-DP=1, native MoE dispatch, disabled Prefill CUDA graphs, and optional HiCache host mode `cache`. Vision checkpoints require `--language-model-only`. P/D and L3 require their separate extensions.

## Accuracy Tests

Archived CPU validation for this split head: **43 passed, 0 skipped** across the replay/cache suites. Coverage includes ownership, empty ranks, padding, output capture, cache ownership, and CP1/encoder-off isolation. Lint passed during split preparation.

These checks do not validate CUDA execution or real H2D transfers. Historical combined H20 results are not standalone acceptance for this head. Hardware acceptance compares L1/L2 at the same CP size, adopted prefix, and replay floor; cold-versus-replay and cross-CP bitwise equality are not requirements.
