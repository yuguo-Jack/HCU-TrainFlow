# Fix LoRA loading for ungated MoE up_proj exports

[Upstream PR](https://github.com/sgl-project/sglang/pull/43916) · state: open · merged: False

## Original PR description

## Motivation

Ungated MoE adapters, such as Nemotron adapters exported with an expert `up_proj` and `down_proj`, leave the input projection under `up_proj` during loading. SGLang's fused MoE buffers expect `gate_up_proj` even when the expert has only one input projection, so the adapter input projection does not reach the expected buffer.

## Modifications

- Rename orphan routed-expert `up_proj` tensors to `gate_up_proj` when the base layer is ungated, preserving the original tensor and single-projection shape for both per-expert and packed layouts.
- Preserve existing `gate_proj` exports, including empty `up_proj` placeholders in either checkpoint key order, and leave gated expert stacking unchanged.
- Retain `up_proj` as an eligible target when the base model also has standalone dense/shared-expert modules. Those weights keep their standalone names.
