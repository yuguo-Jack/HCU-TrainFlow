# [Fix] SenseNova-U1: let think_mode image tokens attend to the reasoning

[Upstream PR](https://github.com/sgl-project/sglang/pull/45163) · state: open · merged: False

## Original PR description

Tracking issue: #37742. Related: #40702 (exposes `think_mode` through the image API).

## Motivation

With `think_mode=True`, `t2i_generate` decodes the reasoning, `</think>` and `<img>` into the
condition KV cache, and starts the image RoPE t-index after them. But it still passes the
pre-think prompt length as `prefix_lengths` to `prepare_flash_kv_cache`. That sets
`actual_seq_lengths_kv = prompt_len + image_len`, and `_flash_or_sdpa` compacts K/V to
`k[:, :prompt_len] ++ k[:, prefix_width:]` in every layer at every denoising step. So the image
tokens never see the reasoning, `</think>` or `<img>`, while their positions assume they follow
them, and every think-mode image is noise. This affects the CUDA, CPU and NPU-FIA paths; it came
in with the batched-generation change (#39382), which introduced `prefix_lengths`.

## Modification

After the think decode, `condition_prefix_lengths` becomes the cache length (`t_index + 1`,
the same value the image t-index starts at). Think mode only accepts one prompt, so there is
no padding to account for.

## Tests

- `test_sensenova_u1_think_mode_image_attends_to_reasoning`: a tiny random NEO-Unify model on
  CPU, 4 think tokens; the think-mode image must match the one computed with the whole prefix
  visible (`prefix_lengths=None`, valid for one unpadded prompt). Fails on main
  (3043 / 3072 elements differ), passes with the fix.
- GPU, 1x H200, SenseNova-U1.5-8B-MoT, CFG 4, seed 42, `think_mode=True`. On the real model,
  the cache length after the think decode equals `t_index + 1` in every run, and the
  reasoning text is byte-identical before and after the fix; only the denoise attention changes.
  - 2048x2048, 50 steps, default think budget (1024): two prompts (a bakery price poster; a
    clock at a quarter past three next to a calendar on the winter-solstice month). On main
    both images are structureless noise. With the fix both are coherent: a "SUNRISE BAKERY"
    poster with three priced items, and a wall clock beside a "DECEMBER 21ST" desk calendar
    (the reasoning resolved the solstice date; the clock hands and the item names are not
    accurate). Wall time is unchanged (32.3 / 27.9 s on main vs 33.2 / 28.1 s, mostly the
    think decode).

- Non-think requests never reach the changed branch.

## Notes

- Output changes for every `think_mode=True` request; non-think requests are untouched.
- #40702 exposes `think_mode` through the API; without this fix those requests return noise.
- Conflicts textually with the SenseNova CFG-parallel change, which moves this code into
  `_t2i_think_prefill`; whichever lands second carries the one-line change over.
- Not fixed here: on Ascend without FIA, a think request with `batch_size > 1` builds its
  dense mask from the pre-think `key_valid_mask`, which is shorter than the cache. Not run on NPU.
