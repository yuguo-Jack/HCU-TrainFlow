# [Fix] speculative: Preserve NaN argmax semantics in DSpark kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/46433) · state: closed · merged: False

## Original PR description

## Motivation

The small-row speculative argmax and DSpark fused Markov greedy step select indices using equality with a reduced maximum. NaN scores can leave an invalid or incorrect index: on H100, an all-NaN row of width 131072 returns 131072, and the Markov kernel at width 152064 returns INT_MAX. Passing such a token to the next embedding lookup can cause a device-side failure.

## Modifications

Give NaNs priority and select the first index, matching `torch.argmax`. Exclude padded lanes from candidate indices. The row kernel keeps separate value/index reductions with NaN propagation; the final reduction and Markov kernels reuse the existing NaN-aware `_argmax_pair` helper. This does not repair the source of NaNs or make an affected request's output valid.

Only two kernel files change; no new test files.

## Accuracy Tests

Local H100 PCIe, PyTorch 2.14.1+cu130, baseline `a99c7d050f`:

- 333 direct GPU comparisons against PyTorch: finite values, all/partial NaNs, positive/negative infinities, ties, strided rows, vocabulary/tile boundaries, and NaNs originating in the Markov matvec. Baseline failed 96 cases; patched kernels pass all 333. Markov matvec cases include FP32/BF16/FP16; finite winners are separated to exclude the kernel's documented near-tie rounding differences.
- 16 CUDA graph replays with changed NaN locations, followed by embedding lookups, pass. Includes the all-NaN width-131072 case.
- Ruff lint/format and `git diff --check` pass.

These are kernel-level checks with constructed exceptional inputs, not a reproduction of spontaneous NaNs in a running model.

## Speed Tests and Profiling

Normal-input CUDA graph microbenchmark, vocabulary 152064, median of five samples (16 calls per graph, 100 replays per sample). This correctness fix has a measurable cost in the small-row argmax; these numbers do not establish an end-to-end serving impact.

| Kernel | Before (µs) | After (µs) |
| --- | ---: | ---: |
| row_argmax, 1 row | 3.46 | 3.66 |
| row_argmax, 16 rows | 7.06 | 8.84 |
| row_argmax, 64 rows | 20.69 | 26.26 |
| Markov, 1 row, rank 32 | 9.59 | 9.51 |
| Markov, 1 row, rank 128 | 62.45 | 62.34 |
