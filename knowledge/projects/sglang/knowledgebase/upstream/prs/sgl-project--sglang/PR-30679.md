# [Diffusion] Add DreamZero action generation support

[Upstream PR](https://github.com/sgl-project/sglang/pull/30679) · state: open · merged: False

## Original PR description

## Motivation

This PR adds DreamZero action generation support to the multimodal generation runtime.

DreamZero is a world-action model that predicts robot action chunks from observation windows. It cannot use the standard image/video denoising pipeline directly because it needs:

- causal DiT rollout over observation/action token blocks
- session-level KV and cross-attention cache reuse across evaluation steps
- DreamZero-specific observation preparation, text/image encoding, denoising, and action output stages
- CFG, TP, and SP execution paths
- RLinf evaluation through the SGLang runtime/server boundary

For serving, DreamZero reuses the existing `/v1/actions/*` action API. The shared API changes are intentionally narrow: WAM models are routed through the existing action endpoint, while OpenPI realtime
websocket support remains VLA-only.
