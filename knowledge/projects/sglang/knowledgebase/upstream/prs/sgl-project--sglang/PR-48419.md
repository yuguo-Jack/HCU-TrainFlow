# [Fix] Keep prefill batches homogeneous by input form

[Upstream PR](https://github.com/sgl-project/sglang/pull/48419) · state: open · merged: False

## Original PR description

## Motivation

With radix caching disabled, ordinary token requests and `input_embeds` requests are individually supported. Concurrent requests can share a normal causal prefill batch. The batch gathers all token IDs but only supplied embedding rows, then gives that shorter embedding tensor to the whole forward.

A two-token ordinary request plus three supplied embedding rows creates five KV locations for only three input vectors. A native CPU KV write fails on that mismatch; a single supplied row can instead broadcast incorrect values into another request's slots.

## Modifications

Extend the existing scheduler pooling-mode compatibility guard to preserve one input form per forward. Incompatible requests remain queued before their preemption/cache/initialization path, while later compatible requests can still batch together. This also preserves a resumed chunk's input form.

Nearby diffs #20376 (chunk slicing/prefill-decode mixing), #45041 (decode cleanup), #47493 (DP padding), #40745 (sessions) and #43681 (width validation) cover separate cases.

## Accuracy Tests

Tested base: `fd19cfb660f42bd3ceb6df7598bd343572e30d2c`. At publication, main has advanced by one documentation-only commit; the runtime, policy and test files are unchanged.

- Four new native scheduler subcases fail on the base. The candidate passes 68 tests and 66 subtests across the scheduler admission/running-request and PrefillAdder suites.
- A separate 120-case CPU queue/KV replay has 88 base failures and zero candidate failures. It uses actual Scheduler selection, PrefillAdder, batch construction, ModelRunner embedding kwargs and MHATokenToKVPool writes/readback. It verifies per-request vectors and recovery of request/token slots, including both input orders, interleaved queues, one-row broadcasting and ignore_eos.
- Independent review passes 34/34 selected cases (base fails 24), including 24 physical KV scenarios and eight chunk-continuation cases. Scheduler canaries cover both pooling/input-form compatibility axes and early preemption/prefetch/init exclusion.
- Torch 2.14.1+cpu. Source/import/native-library bindings were checked before and after the component proofs. A local embedding table and identity K/V projection isolate the row/value contract; full-model and GPU execution were not run.

## Speed Tests and Profiling

Mixed input forms require separate prefill batches. Later compatible requests still join the current batch. No throughput improvement is claimed.
