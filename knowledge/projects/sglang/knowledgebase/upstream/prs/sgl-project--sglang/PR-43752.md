## Original PR description

## Summary

**Use DiffusionGemma token scores to answer choice, yes/no and ordinal questions.**

- **Stack 2/3.** Depends on #41232. Merge order: #41232 → this PR → #43767.
- **Follow-up:** #43767 tracks the TweetEval prefix failures and is marked **[WIP]**.
- **[Review this layer only](https://github.com/Hangzhi/sglang/compare/16b1b8de683447385badc5c5989923fec31bd852...6d92bcc6b0d198025fa2884dfc1a35647da3b6f9).** GitHub's default diff also includes PR1.

## Changes

- Use the same scores for `/v1/decisions`, `/v1/systemone` and pointwise `/v1/score`.
- Check the four-token prefix. Read the answer at canvas position 4.
- Normalize candidate scores at the requested temperature.
- Return prompt and label IDs for replay. Keep decision completion-token usage at zero.
- Reject unsupported score layouts.

Candidate probabilities compare the supplied options. They do not measure the chance that the answer is correct.

## Validation

- **129 tests and 152 subtests passed.** Repository pre-commit hooks passed.
- **Replay passed in eager and CUDA graph modes.** Decision scores match raw `/generate` scores within **0.0002** at temperature **1.7**.
- **Text, images, batches and streaming passed.**
- **Hardware:** one RTX PRO 6000 Blackwell 96GB. BF16, TP1, Triton. Full 256-token canvas; sampler seed 42.
