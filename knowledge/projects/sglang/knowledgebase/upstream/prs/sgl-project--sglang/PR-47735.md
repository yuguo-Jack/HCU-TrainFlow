# [Refactor] unlimited-ocr: Reduce scheduler coupling

[Upstream PR](https://github.com/sgl-project/sglang/pull/47735) · state: closed · merged: True

## Original PR description

Unlimited-OCR v2 currently wires its document admission policy, asynchronous SHM receiver, crop-transfer lifecycle, overlap cleanup, and off-tree KV accounting directly through the common scheduler.

This change gives the model one runtime owner, moves asynchronous ingress into `UocrRequestReceiver`, and uses a model-specific `PrefillAdder` for retained-window admission. Pool statistics query retained-window ownership through the cache. Forward input resolution is selected at construction; the graph-input flag describes the worker contract rather than a model name.

The document queue, abort/flush ordering, graph relay and recapture behavior, CLI options, and document output metadata retain their existing semantics. Tests cover admission retry after reclamation, retained/source-window accounting, idle ownership, graph recapture, and the ordinary-model path.
