# [Metrics] Populate num_paused_reqs gauge during pause_generation

[Upstream PR](https://github.com/sgl-project/sglang/pull/41559) · state: open · merged: False

## Original PR description

## What

`sglang:num_paused_reqs` ("The number of paused requests by async weight sync.") was fully plumbed — defined in `SchedulerMetricsCollector`, mirrored through `SchedulerMetricsReporter.num_paused_reqs` -> `SchedulerStats.num_paused_reqs` -> exported in both decode and prefill stats paths — but **nothing ever assigned it**, so the gauge was always exported as `0`, including while the engine is paused via `/pause_generation` (used by async weight update / RL rollout flows).

## Root cause

- The only writes to the reporter field were the two `self.num_retracted_reqs = self.num_paused_reqs = 0` resets after stats publish; there was no producer.
- The normal stats reports never run while `_engine_paused` is True (the event loop short-circuits), and the forced one-shot idle publish in `pause_generation` did not include the paused count either.

## Changes (one thing only)

- `pause_generation` (both `in_place` and `retract`) sets the gauge to the number of requests whose generation is suspended. The request set is factored into `_gather_pause_retract_reqs` so both modes (and the gauge) use one accounting identical to the existing retraction set.
- Treat it as a **level gauge**: held non-zero across the pause window, cleared on `continue_generation`. The forced idle publish while paused mirrors it into `SchedulerStats`; only the edge-triggered `num_retracted_reqs` keeps being reset after publish.
- CPU unit tests (no GPU): retract-mode pause, in-place pause, and resume clearing.

## Verification

- New tests fail on unmodified code (`0 != 2`), pass after the fix; the existing 21 tests in the file and the reporter-adjacent observability unit tests (`test_forward_pass_metrics.py`, `test_scheduler_stage_metrics.py`) all pass (CPU torch in a Linux env).
- No new metric, no label change; dashboard semantics change from "always 0" to the documented meaning.
