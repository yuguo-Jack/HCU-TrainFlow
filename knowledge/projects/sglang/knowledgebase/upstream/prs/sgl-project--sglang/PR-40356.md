# [Fix] [Ascend] bench_serving: Correct Kimi K2.5 image token counts

[Upstream PR](https://github.com/sgl-project/sglang/pull/40356) · state: open · merged: False

## Original PR description

## Motivation

Kimi K2.5 image benchmarks undercount input tokens because its Hugging Face processor leaves one unexpanded placeholder per image. The text-only fallback also omits chat-template tokens. Consequently, input-token totals and throughput metrics are incorrect.

For `Describe the image.` with one 224×224 image, the old count is **18**; the corrected count is **81 = 12 text + 69 vision**, matching both serving APIs.

Related: https://github.com/Ascend/sglang/issues/1095

## Modifications

- Calculate image expansion using Kimi K2.5's `media_tokens_calculator` and encode formatted text directly with its tokenizer. Preserve the placeholders sent to serving.
- Add regression coverage for both APIs, text-only inputs, multiple images, non-square resolutions, and media boundary markers.
- Document the image benchmark command and token-accounting convention. Vision counts include media boundary markers.

The existing tokenizer loading path already supports Kimi K2.5. This change affects benchmark accounting only.

## Accuracy Tests

- **46 dataset tests pass**, including **14 new Kimi regression subcases**:
  `python3 test/registered/bench_fn/test_benchmark_datasets_api.py`.
- **16/16 client/server token comparisons match** using full original INT4 weights on two A2 nodes. Coverage includes text-only, single/multiple images, mixed resolutions, portrait/landscape images, and a real photograph; text + vision equals the server total throughout.
- Text, real-image, and two-image requests return complete answers (`finish_reason=stop`). Functional checks use temperature 0, max_tokens 128, and `chat_template_kwargs={"thinking": false}`.
- isort, Ruff lint/format, codespell, repository custom lint, whitespace checks, and Mintlify build/link validation pass.

## Speed Tests and Profiling

**256/256 requests completed** across eight cases, with 32 requests and two warmups each. Random PNG images, seed 1095, text-length parameter 128, output length 16, and range ratio 1 were used. Token comparisons and benchmarks retain the default thinking template; benchmarks use the default `ignore_eos=True` (no `--disable-ignore-eos`) for fixed short outputs.

<summary>Environment and reproduction</summary>

Validated on 2026-09-19 using source base `832ec39cc0324cb0e7823dc8385e27a30c356bdd`, two A2 nodes with 8×910B3 64 GiB each, CANN 9.0.0, torch/torch_npu 2.10.0, and Transformers 5.12.1. Model: ModelScope `moonshotai/Kimi-K2.5`, full original INT4 weights (64 shards). Downloaded from `master`, which is not an immutable revision.

Image: `quay.io/ascend/sglang@sha256:db4f9fa26f09bd7d44cb83967ce23ce9cdf00fa41b35579bf112baef3e6955c6`.

Both nodes need the complete model and working NPU/HCCL access; containers used host networking and IPC. Inside each Ascend container, set `MODEL_PATH`, `PRIMARY_IP`, `NODE_RANK` (0/1), and the communication interface:

```bash
export HCCL_SOCKET_IFNAME='<communication-interface>'
export GLOO_SOCKET_IFNAME="$HCCL_SOCKET_IFNAME"
export HCCL_CONNECT_TIMEOUT=600
export SGLANG_FORCE_CPU_IMAGE_PREPROCESSING=1
python3 -m sglang.launch_server \
  --model-path "$MODEL_PATH" --trust-remote-code \
  --device npu --tp-size 16 --nnodes 2 --node-rank "$NODE_RANK" \
  --dist-init-addr "$PRIMARY_IP:29795" \
  --attention-backend ascend --mm-attention-backend ascend_attn \
  --sampling-backend ascend --dtype bfloat16 \
  --context-length 2048 --chunked-prefill-size 512 \
  --max-running-requests 2 --mem-fraction-static 0.85 \
  --cuda-graph-backend-decode disabled --cuda-graph-backend-prefill disabled \
  --host 127.0.0.1 --port 31095
```

After startup, benchmark from a separate container shell on rank 0:

```bash
python3 -m sglang.benchmark.serving \
  --backend sglang-oai-chat --host 127.0.0.1 --port 31095 \
  --model "$MODEL_PATH" --tokenizer "$MODEL_PATH" \
  --dataset-name image --image-count 2 --image-resolution 448x448 \
  --image-format png --image-content random \
  --random-input-len 128 --random-output-len 16 --random-range-ratio 1 \
  --num-prompts 32 --max-concurrency 2 --warmup-requests 2 --seed 1095 \
  --output-file kimi-k25-multi448-c2.jsonl
```

For the full matrix, combine backend `sglang`/`sglang-oai-chat`, images `1×224×224`/`2×448×448`, and concurrency `1`/`2`.
