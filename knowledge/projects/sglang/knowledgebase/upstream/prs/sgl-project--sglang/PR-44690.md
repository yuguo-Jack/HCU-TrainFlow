# [Refactor] kernels/diffusion/tests: Prune dead code and fix tests that never ran

[Upstream PR](https://github.com/sgl-project/sglang/pull/44690) · state: closed · merged: True

## Original PR description

## Motivation

Six months of fast kernel and diffusion work left a lot behind in `python/sglang/kernels`, `python/sglang/multimodal_gen` and the kernel/diffusion test trees: kernels nothing calls, registry metadata nothing reads, per-model copies of the same fused-op glue, env knobs that do nothing, and tests that pass without testing anything. This PR removes that, and fixes the real bugs the audit turned up along the way (several were silently shipping).

**408 files, +3,629 / -26,346.** About 1.3K of the additions are test oracles and helpers moved out of production modules into `python/sglang/test/kernels/`.

## Bugs fixed (please review these first)

| Area | Problem | Fix |
|---|---|---|
| SANA (diffusion) | Since #37816 the VAE loader calls `vae.state_dict()` before `load_state_dict`; `AutoencoderDC` builds its inner diffusers model lazily, so that call built it with random init and the later load returned early. **All 375 VAE tensors were random; every SANA T2I image on main is noise.** | `load_state_dict` loads into an already-built inner model. Regression test in `test_vae_loader.py` (fails on main). |
| GLM-Image (diffusion) | #33555 added an unconditional `query[:, t:] = q_img` write-back after an in-place RoPE; torch 2.14 rejects the self-copy, so **every GLM-Image request fails** in the first DiT block. | Copy back only when the rotation returned new memory. Regression test `test_glm_image_attention.py`; `test_ar_models` re-enabled (fails on main, passes here in 175 s on 2xH200). |
| MiniMax-H3 VAE | The default-on `h3_vae_qk_rmsnorm_rope` path ran in `quality=exact` but was not bit-exact (~25% of rotated channels differ). A second, faster, quality-gated fused path for the same op already existed. | Removed the non-bit-exact path. **Behavior change:** the exact tier now runs the native chain (bit-identical to native); lossless is unchanged. |
| Diffusion CI | `STANDALONE_FILES` moved to `server/gpu_cases.py` in #24630 but the CUDA partition planner kept reading the runner, so **no CUDA standalone file has run since June** (12 2-GPU files + the 1-GPU ones). | Planner reads the case config. All 15 newly scheduled files were run on H200 through the CI code path; one rotted test fixed. |
| Env vars | Code read the legacy `SGL_*` names while docs/`environ.py` define `SGLANG_*`, and the rewrite is one-directional, so the documented names did nothing: `SGLANG_USE_DEEPGEMM_BMM` (5 models), `SGLANG_DG_USE_NVRTC`, `SGLANG_CPU_QUANTIZATION`, `SGLANG_DSA_TOPK_ROW_SPLIT`. | Read via `envs`; legacy names still work. |
| `BaseFusedOp` | `KernelBackend.FLYDSL` mapped to a missing `forward_flydsl`, so `SGLANG_FORCE_FUSED_OP_BACKEND=flydsl` raised `AttributeError`. | Stub added + test. |
| Tests that never ran | `test_fp8_kernel` returned early on every CUDA GPU with sm>=90; `test_swapab_attention` was registered on H100 but gated to sm_10x (production SM100 kernel had no CUDA coverage); sm_100 / sm_120 / 2-GPU / 4-GPU diffusion unit tests sat on a 1-GPU H100 lane; `test_qwen_image21` cache tests exercised a test-local re-implementation of the fix. | Each now runs on hardware that satisfies its gate (or was deleted with its dead kernel); the qwen_image21 tests drive the real block and fail when the fix is reverted. |
| SenseNova-U1 | `FlowMatchingHead` called `SimpleMLPAdaLN` with a signature the class doesn't have (crash for `fm_head_layers > 2`). | Restored the timestep-conditioned head; test fails on main. |

## Modifications

### Kernels (`python/sglang/kernels`, -13.8K)
- **Dead / test-only kernels removed** (each re-verified with whole-repo grep incl. string lookups): seg_la kernel, dsv4 `fused_ape_pool_norm_rope`, tilelang `fp8_index`, KDA prefill timing scaffolding, nvlink push/pull all-reduce wrappers, inkling two-shot all-reduce, `cutedsl_gdn_mtp_ring` T=1 entry, non-`f_b` FlyDSL KDA decode, dsa `GetK/GetS`, adler32 whole-tensor entry points, ReplaySSM circular commit, cvt helpers, mxfp8 v-cache update, fp8 ue8m0/hopper/transpose helpers, `w8a8_block_fp8_matmul`, `awq_gemm_triton`, rocm `tkw1`, `moe_fused_gate_jit`, inkling gate v1, `post_reorder_triton_kernel`, `fused_inplace_qknorm_across_heads`, elementwise `silu_and_mul_triton`/autotune path, `rms_normalize_triton`, stale `top_p_renorm_triton` copy, and others.
- **Legacy DSV4 compressor path removed** (`compress_old.py`, `fused_compress_triton.py`, srt `dsv4/compress_hip.py`, the old `CompressorBackendMixin`): every CUDA/HIP backend uses `compressor_v2`; `fused_norm_rope_inplace` (live) moved to `dsv4/elementwise.py`. AOT dsv4 q/k norm+RoPE ops (duplicates of the JIT ones) removed.
- **Registry (option A):** the KernelSpec inventory stays; write-only metadata goes (`FormatSignature`, `KernelSpec.format_signature/description/group/name`, `BaseFusedOp.format_signature/descriptions/dispatch_forward`, unused selector/platform helpers). `spec.CUDA_ONLY` replaces ~44 inline frozensets. Unused `BaseFusedOp`s (4 RMSNorm, Gelu/GeluTanh/ReLU2/QuickGELU) removed; facade wrappers nobody imports removed (this also fixes facade functions shadowed by same-named submodules). `Fp8ScaledMMOp` no longer declares an SM90 heuristic as a capability.
- **#42184 criteria applied** to the four remaining gate sites (route-quant, engram, vision_rope, minimax_m3): gates check eligibility, launchers enforce contracts.
- **Duplicates:** sparse-MLA decode reuses the shared kernels (bit-exact, 720 cases x 2 archs incl. fully masked rows); mxfp8 gfx95 reuses `mxfp8_quant`. Forks that are *not* bit-exact stay, each with a one-line comment (grok RMSNorm, gfx1250 qk-RMSNorm, int8 group quant on ROCm, marlin SiTU, minimax Gemma RMSNorm).
- **Test oracles shipped in op modules moved to `sglang.test.kernels`** (LPLB, dsa transform index, DCP LSE combine, dsv4 K-cache quant refs, extend attention, dspark window, multigpu launcher, mhc, per-token-group quant dispatch).

### Diffusion (`python/sglang/multimodal_gen`, -9.4K)
- **Dead code:** SenseNova-U1 unreachable chat/interleave/it2i paths (~2.6K; T2I output byte-identical), auto-residency estimators and the warmup stage-iteration calibration chain nothing read, SANA-WM parity debug harness (`SANAWM_*` env hooks incl. `torch.load` input injection), `MINIMAX_H3_USE_FUSED_NORM` path, unresolved MiniMax-H3 euler scheduler, registry subprocess-inspect path (pointed at a nonexistent module), delta-gzip realtime encoding (server + web UI), bundled-overlay lookup, `EncodingStage`, bitsandbytes 4-bit swap, `generate_with_lora` (could never run), `convert_hf_to_fp8.py`, unused platform hooks, unread `ServerArgs` fields, etc.
- **Env:** 12 `envs.py` entries nothing read removed (+ the docs rows presenting 5 of them as working knobs); raw reads of `SGLANG_ENABLE_FUSED_QKNORM_ROPE` / `MINIMAX_H3_VAE_*` declared in `envs.py` with identical parsing; unprefixed GDN dev knobs dropped.
- **Refactors (bit-exact):** `BitExactFusionGate.run()` replaces 24 hand-written verify-once/fallback blocks and the `mismatch_msg` boilerplate; one LayerNorm+modulate helper for FLUX.3/GLM/LongCat; `sites/` exports one `QualityGatedFusion` per family instead of four wrappers each (~50 facade entries, 28 imports gone). Sites that are hand-tuned for launch overhead, re-raise, verify inside the try, or differ in reference were left as they are (listed in the commit messages).

### Tests and CI
- Deleted always-skipped tests (env var set nowhere, `skipif(True)`, hard-coded dev paths), tautologies (default/literal echoes, `inspect.getsource` shape tests, log-format echoes, torch-behavior tests), duplicate cases and duplicate helpers; trimmed grids with no extra coverage (`fused_fp8_qkv_kv_cache` 1,344 -> 288 cases, AOT `moe_align` 4,368 -> 144, AOT per-token-group quant 3,632 -> 320). CI-tooling meta-tests are intentionally kept.
- New lane wiring: swapab on B200; Blackwell, SM120 and 4-GPU diffusion unit steps; 2-GPU diffusion unit files as 2-gpu standalone files; `quant-videogen` installed for its tests; comm benches no longer register no-op AMD runs; HPC-Ops tests (always skipped: the package isn't in the CI venv) disabled explicitly.
- **CI cost:** the standalone-file fix adds runners (1-GPU H100: 5 -> 6 partitions; 2-GPU: 3 -> 5 by current estimates). The estimates are 2-15x above the measured H200 times; I'll copy this PR's CI-measured values into `STANDALONE_FILE_EST_TIMES` before merge.

## Speed Tests and Profiling

No perf-path changes intended. `BitExactFusionGate.run` was not applied to the launch-overhead-tuned sites (the closures add ~160-180 ns per call on the host).
