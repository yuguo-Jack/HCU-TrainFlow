# [Fix] nemotron_vl: Pad visual spans using processor offsets

[Upstream PR](https://github.com/sgl-project/sglang/pull/44581) · state: open · merged: False

## Original PR description

## Motivation

Literal `<img>` / `</img>` tokens in prompt text are incorrectly treated as visual boundaries by Nemotron VL's marker-pair padding. Unmatched markers can leave visual rows unpadded; balanced literal pairs can pad text instead, causing an embedding-row mismatch and potentially a CUDA assertion.

## Modifications

Pad image/video spans using the processor's recorded offsets rather than searching the prompt for marker pairs. Preserve literal text, visual data offsets, and existing audio padding.

## Accuracy Tests

All **6 CPU tests** in the existing `test_nano_nemotron_vl_processor.py` pass. The added regression covers stray start/end markers, balanced literal pairs, and audio-padding preservation. The complete stack is tree-identical to the previous combined version of #44581. Project isort/ruff checks pass.

GPU/serving validation has not been rerun for this split.

## Speed Tests and Profiling

Not benchmarked; no performance claim or kernel changes.
