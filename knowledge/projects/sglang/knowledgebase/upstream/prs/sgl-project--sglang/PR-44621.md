## Motivation

`--monokernel-backend amd` (the monokernel framework from #44353) needs the [sgl-amd-mono](https://github.com/sgl-project/sgl-amd-mono) plugin, which the ROCm image does not ship, so the option cannot be used with the published images.

## Modifications

- `docker/rocm.Dockerfile`: after the SGLang install, clone sgl-amd-mono at a pinned commit (`SGL_AMD_MONO_REPO`, `SGL_AMD_MONO_COMMIT`), `pip install --no-deps -e .`, and fail the build if its `sglang.srt.plugins` entry point is not registered.
- Installed on gfx950 images only (its kernels target gfx950); `--build-arg ENABLE_SGL_AMD_MONO=0` skips it. The plugin registers its specs lazily, so nothing changes unless a server passes `--monokernel-backend amd`.
