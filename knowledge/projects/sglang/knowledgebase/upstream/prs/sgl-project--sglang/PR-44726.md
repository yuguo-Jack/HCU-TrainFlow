## Motivation

Add HiCache storage management endpoints to the Rust server so clients can attach,
detach, clear, and inspect the configured storage backend.

## Modifications

- Add PUT, DELETE, and GET /hicache/storage-backend, and POST /hicache/storage-backend/clear.
- Forward attach options to the scheduler and preserve operation results and messages.
- Initialize the configuration view from Python launch configuration and update it only after successful attach/detach operations.
- Keep mutable HiCache configuration in CoreConfig/CoreInner; move the initial state into the mutex without retaining a second copy.
- Add inline Rust endpoint tests and Python configuration-forwarding coverage.

No changes to model computation or numerical output. No numerical-accuracy benchmark was run.

## Local HiCache E2E validation

Validated the Rust frontend with a real model and the file storage backend.

### Environment

- Tested commit: `009f851d9b0863600d2f0b87a404f218712afee2`
- GPU / driver: `NVIDIA GeForce RTX 5080 (16 GB), driver 617.42`
- Python / PyTorch: Python 3.12.3, PyTorch 2.14.1+cu130 (CUDA 13.0)
- Model: Qwen/Qwen2.5-0.5B-Instruct
- Single GPU; Rust frontend enabled.
- HiCache: direct I/O, layer_first layout, page size 64.
- FlashInfer attention, PyTorch sampling; CUDA graphs and overlap scheduling disabled.

### Server launch

In terminal A:

```bash
cd /workspace/sglang
source /opt/sglang-venv/bin/activate

export SGLANG_RUST_SERVER=1
unset CUDA_LAUNCH_BLOCKING SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND

export SGLANG_HICACHE_FILE_BACKEND_STORAGE_DIR=$(mktemp -d /tmp/hicache-manual.XXXXXX)
echo "Storage directory: $SGLANG_HICACHE_FILE_BACKEND_STORAGE_DIR"
```

output: `/tmp/hicache-rerun.dIWrAI`

```bash
sglang serve \
  --model-path /workspace/models/Qwen2.5-0.5B-Instruct \
  --host 127.0.0.1 \
  --port 30173 \
  --enable-hierarchical-cache \

  --hicache-size 1 \
```

### 2. Attach and inspect configuration

```bash
curl -sS -w '\nHTTP %{http_code}\n' \
  -X PUT "$BASE/hicache/storage-backend" \
  -H 'Content-Type: application/json' \
  --data '{
    "hicache_storage_backend":"file",
    "hicache_storage_backend_extra_config_json":"{}",
    "hicache_storage_prefetch_policy":"timeout",
    "hicache_write_policy":"write_through"
  }'

curl -sS -w '\nHTTP %{http_code}\n' "$BASE/hicache/storage-backend"
```

Expected: HTTP 200; GET reports `file`, `"{}"`, `timeout`, and `write_through`.

Actual:

```text

HTTP 200
```
