# [Fix] [AMD] Qwen3.8: prefill tokens alignment

[Upstream PR](https://github.com/sgl-project/sglang/pull/42767) · state: open · merged: False

## Original PR description

Qwen3.8 Flash Next could crash during chunked prefill with `SGLANG_EXACT_CHUNK_FILL=1`. At concurrency 12, requests with 32,769 input tokens reproduced a GPU abort at QSA's prefix-alignment assertion: exact fill could split a compression group and leave the next chunk with an invalid prefix length.

This PR fixes the crash by preserving QSA's required alignment for unfinished prefill chunks while retaining exact token accounting. The original reproducer completes successfully with exact fill enabled after the fix, with no material performance degradation or answer-accuracy regression observed in validation.

Validation compared the fix with the working configuration using exact fill disabled:

- **Crash reproduction:** all 12 previously failing requests completed successfully.
- **Performance:** median output throughput changed by −0.05% at concurrency 8 and −0.25% at concurrency 12; mean request latency changed by +0.05% and +0.25%, respectively. Each comparison used five timed rounds after warmup.
- **Accuracy:** targeted arithmetic and 16K–64K retrieval tests scored 36/36 in both versions, with identical generated tokens. Cached-prefix replay scored 12/12 in both. A fixed 48-question GSM8K sample scored 46/48 in both, with the same two questions marked incorrect.
- **Regression tests on this PR branch:** 58 tests passed, including 37 subtests.

Serving, performance, and accuracy results were collected on the original implementation in `qwen_3_8_improvement`; this PR backports that fix to the older Qwen integration base. Those end-to-end runs have not been repeated on this PR base. Accuracy testing used real speculative verification; GSM8K and cached-replay checks disabled CUDA graphs in both arms to avoid a separately reproduced existing lifecycle fault. These measurements show no material regression in the tested workloads, rather than guaranteeing identical performance or generation for every workload.
