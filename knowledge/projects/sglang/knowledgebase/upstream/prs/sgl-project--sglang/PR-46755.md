## Motivation

<!-- Describe the purpose and goals of this pull request. -->

FlashInfer multi-item scoring (MIS) resets `forward_batch.positions` so each item follows the shared query independently. Qwen3.5 text models with MRoPE instead consume `forward_batch.mrope_positions`, which retains packed-sequence positions. Preceding items therefore introduce an incorrect positional gap even though the MIS attention mask hides them.

```text
Packed input:       Q0 Q1 D A0 A1 D B0 B1 D
B rotary positions:
  packed / before:  6  7
  item-local / fix: 2  3
```

Synchronize the text MRoPE tensor that the model actually consumes, without changing the existing logical MIS positions or multimodal spatial coordinates.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Mirror each MIS suffix's existing item-local positions across the three MRoPE axes only when the request has no multimodal inputs.
- Preserve logical scalar delimiter position `-1` for empty queries; clamp only the consumed MRoPE rotary-cache indices to zero.
- Preserve query-prefix positions, cached-prefix offsets, genuine multimodal coordinates, and non-MIS/decode behavior. Keep the existing on-device metadata calculation, attention-mask parameters, and GDN implementation unchanged.
- Add four synthetic CPU regression tests under `test/registered/unit/layers/attention/`, using `CustomTestCase` and `base-a-test-cpu`. Cover text position resets, empty-query index safety and delimiter exclusion, mixed requests with cached prefixes, and non-MIS no-op branches.

Compatibility: text MIS outputs on MRoPE models intentionally change. No API, flag, dependency, or persisted-data change is introduced. This is a two-way door: rollback is a revert; the blast radius is text scoring.
