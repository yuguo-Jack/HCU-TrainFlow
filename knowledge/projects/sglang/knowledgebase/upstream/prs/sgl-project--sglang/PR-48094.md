# [Perf] [AMD] dsv4: Fuse the next RMSNorm into mhc_post_pre

[Upstream PR](https://github.com/sgl-project/sglang/pull/48094) · state: open · merged: False

## Original PR description

On gfx1250, fuse the next RMSNorm into the Gluon `mhc_post_pre` and drop the separate `rms_norm` launch at each hyper-connection boundary.

Depends on https://github.com/sgl-project/sglang/pull/48065
<!-- results -->
### Accuracy
GSM8K (1319 questions, greedy), DeepSeek-V4-Pro, TP4: 0.943 (without this PR 0.945)
### Performance
Setup:
- Model: DeepSeek-V4-Pro, BF16 KV cache, DSPARK speculative decoding (block 6, 1 step)
- Parallelism: TP4 (`--tp 4`, CP prefill + CP decode attention)
- Step time: torch profiler on rank 0, GPU time per step; decode = 8 steps at 4 running requests (VERIFY = target verify, DRAFT = DSPARK draft), prefill = one EXTEND step of an ~8k-token prompt (TP4) / 4k (EP4)
- Comparison: with vs without this PR, same image and node, all earlier PRs of the series applied

Profiler step time (without -> with):

| step | without | with | change |
|---|---|---|---|
| decode VERIFY | 15.71 ms | 14.81 ms | -5.7% |
| decode DRAFT | 1.83 ms | 1.83 ms | +0.2% |
| prefill EXTEND | 160.7 ms | 159.7 ms | -0.6% |

Serving (`python -m sglang.bench_serving --backend sglang --dataset-name random --random-range-ratio 1`, fresh random prompts):

| input/output, concurrency, prompts | output tok/s | mean TTFT (ms) | mean TPOT (ms) |
|---|---|---|---|
| 32k/1k, C4, 32 | 653.5 -> 681.4 (+4.3%) | 2293 -> 2193 (-4.4%) | 3.74 -> 3.59 (-4.0%) |
| 1k/1k, C1, 32 | 420.1 -> 442.4 (+5.3%) | 163.0 -> 157.1 (-3.6%) | 2.22 -> 2.11 (-5.0%) |
| 1k/1k, C4, 96 | 1227.8 -> 1292.7 (+5.3%) | 303.2 -> 290.5 (-4.2%) | 2.93 -> 2.78 (-5.1%) |

Without and with were run on different days; the same build repeated across that gap moved by up to 3% (32k/1k C4: 664.3 -> 681.4 tok/s).
