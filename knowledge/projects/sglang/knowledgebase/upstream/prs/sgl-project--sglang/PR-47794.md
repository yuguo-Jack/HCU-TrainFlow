# [Fix] quantization: Pad gated NVFP4 CUTLASS MoE projections

[Upstream PR](https://github.com/sgl-project/sglang/pull/47794) · state: open · merged: False

## Original PR description

## Motivation

Continues #30888 after automatic inactivity closure; reopening the original was rejected by GitHub. Current main still asserts when a gated ModelOpt NVFP4 MoE uses 352 intermediate channels per TP rank and the CUTLASS block-scale swizzle requires padding.

## Modifications

Pad each gate/up half independently to 384 channels before swizzling, along with matching w2 packed columns and block scales. Limit the new path to `FLASHINFER_CUTLASS`; retain other backends unchanged. Adapt the CPU post-load regression to the current MoE configuration and local-expert fields.

## Accuracy Tests

Two CPU regressions pass. Current head `fd40c16362db37357edd537495fcd495ff1060eb` was also validated on Runpod NVIDIA L40S (SM89), PyTorch 2.14.1+cu130 / CUDA 13.0: **2 passed, 0 skipped**, in 0.291s, adapting the PR tests to allocate tensors on CUDA and replacing the CPU swizzle double with the real `swizzle_blockscale`. Marker assertions check gate/up boundaries and zero padding through the real post-load path.

A negative control that bypassed per-half padding reproduced the gated-padding assertion and the `(1, 2816, 22)` w2 blockscale warning.

Additional validation on the same head: **real CUTLASS NVFP4 MoE forward passed on NVIDIA B300 (SM103)**, PyTorch 2.14.1+cu130 / CUDA 13.0 / FlashInfer 0.7.2. Synthetic weights use the failing per-rank dimensions (hidden 2816, intermediate 352), 4 experts, top-k 2 and BF16 activations. The probe calls the production post-load path with real swizzling, then `flashinfer.fused_moe.cutlass_fused_moe`.

| Batch | Max error vs independently padded baseline | Max difference vs deliberately incorrect tail padding |
| --- | --- | --- |
| 1 | 0.0 | 0.1015625 |
| 8 | 0.0 | 0.12109375 |
| 32 | 0.0 | 0.1171875 |

All three cases produced finite, nonzero outputs; the process exited 0. The manually padded baseline places gate/up halves independently, while the negative control pads the fused tensor tail and is correctly distinguished.

This is a single-GPU synthetic kernel test at TP=2 per-rank dimensions, **not distributed TP=2 model inference or a full-model quality/performance benchmark**. Those checks remain pending, so the PR remains a draft. Historical GPU results on #30888 are not validation of this head.

```python
"""Actual CUTLASS forward against independent manually padded weights.

Single GPU, synthetic quantized weights at the per-TP-rank failing dimensions.
No distributed execution or full model quality/performance claim.
"""
import copy
import importlib.util
from contextlib import ExitStack
from pathlib import Path
from types import SimpleNamespace
from unittest.mock import patch

import torch
from flashinfer.fused_moe import cutlass_fused_moe

assert torch.cuda.is_available()
assert torch.cuda.get_device_capability()[0] >= 10
torch.manual_seed(47794)
path = Path("test/registered/unit/layers/quantization/test_modelopt_nvfp4_moe_padding.py")
spec = importlib.util.spec_from_file_location("padding_fixture", path)
fixture = importlib.util.module_from_spec(spec)
spec.loader.exec_module(fixture)
fixture.NUM_TEST_EXPERTS = 4
q = fixture.modelopt_quant
backend = q.MoeRunnerBackend.FLASHINFER_CUTLASS


def postload(layer):
    method = q.ModelOptNvFp4FusedMoEMethod.__new__(q.ModelOptNvFp4FusedMoEMethod)
    method.quant_config = SimpleNamespace(group_size=16, use_per_token_activation=False)
    method.enable_flashinfer_trtllm_moe = False
    with ExitStack() as stack:
        stack.enter_context(patch.object(q, "get_moe_runner_backend", return_value=backend))
        stack.enter_context(patch("sglang.srt.layers.moe.get_moe_runner_backend", return_value=backend))
        stack.enter_context(patch.object(q, "MOE_NVFP4_DISPATCH", False))
        stack.enter_context(patch.object(q, "should_use_flashinfer_cutlass_moe_fp4_allgather", return_value=False))
        method.process_weights_after_loading(layer)


def manual_pad(layer, *, naive=False):
    # Explicit index placement, independent of the production split/pad helper.
    for name in ("w13_weight", "w13_weight_scale"):
        src = getattr(layer, name)
        dst = torch.zeros((4, 768, src.shape[-1]), dtype=src.dtype, device=src.device)
        if naive:
            dst[:, :704] = src
        else:
            dst[:, :352] = src[:, :352]
            dst[:, 384:736] = src[:, 352:]
        setattr(layer, name, torch.nn.Parameter(dst, requires_grad=False))
    for name, width in (("w2_weight", 192), ("w2_weight_scale", 24)):
        src = getattr(layer, name)
        dst = torch.zeros((4, 2816, width), dtype=src.dtype, device=src.device)
        dst[..., :src.shape[-1]] = src
        setattr(layer, name, torch.nn.Parameter(dst, requires_grad=False))


def forward(layer, x, ids, scores):
    return cutlass_fused_moe(
        x, ids, scores,
        layer.w13_weight.view(torch.long), layer.w2_weight.view(torch.long), x.dtype,
        quant_scales=[
            layer.w13_input_scale_quant,
            layer.w13_blockscale_swizzled.view(torch.int32), layer.g1_alphas,
            layer.w2_input_scale_quant,
            layer.w2_blockscale_swizzled.view(torch.int32), layer.g2_alphas,
        ],
        tune_max_num_tokens=32,
    )[0]


print("GPU", torch.cuda.get_device_name(), torch.cuda.get_device_capability(), flush=True)
print("Torch", torch.__version__, "CUDA", torch.version.cuda, flush=True)
with torch.inference_mode(), torch.device("cuda"):
    original, _ = fixture._make_gemma4_tp2_layer()
    for name in ("w13_weight", "w2_weight"):
        tensor = getattr(original, name)
        tensor.copy_(torch.randint(0, 256, tensor.shape, dtype=torch.uint8, device="cuda"))
    for name in ("w13_weight_scale", "w2_weight_scale"):
        getattr(original, name).fill_(1 / 64)
    for name in ("w13_input_scale", "w2_input_scale", "w13_weight_scale_2", "w2_weight_scale_2"):
        getattr(original, name).fill_(1)
    candidate, reference, wrong = [copy.deepcopy(original) for _ in range(3)]
    manual_pad(reference)
    manual_pad(wrong, naive=True)
    for layer in (candidate, reference, wrong):
        postload(layer)
    print("postload shapes", candidate.w13_weight.shape, candidate.w2_weight.shape, flush=True)
    for batch in (1, 8, 32):
        x = torch.randn(batch, 2816, dtype=torch.bfloat16) * 0.1
        ids = torch.stack((torch.arange(batch) % 4, (torch.arange(batch) + 1) % 4), dim=1).int()
        scores = torch.tensor([0.625, 0.375], dtype=torch.float32).repeat(batch, 1)
        actual = forward(candidate, x, ids, scores)
        expected = forward(reference, x, ids, scores)
        incorrect = forward(wrong, x, ids, scores)
        torch.cuda.synchronize()
        assert actual.shape == (batch, 2816)
        assert torch.isfinite(actual).all() and actual.abs().max() > 0
        torch.testing.assert_close(actual, expected, atol=1e-3, rtol=1e-3)
        assert not torch.allclose(actual, incorrect, atol=1e-3, rtol=1e-3)
        print("PASS batch", batch, "manual-pad max error", (actual - expected).abs().max().item(),
              "naive-tail-pad max error", (actual - incorrect).abs().max().item(), flush=True)
print("PASS: real CUTLASS forward, 3 batches, correct padding baseline, wrong-boundary negative control", flush=True)
```
