# [Fix] startup: remove TorchScript deprecations at their sources

[Upstream PR](https://github.com/sgl-project/sglang/pull/46620) · state: closed · merged: True

## Original PR description

## Motivation

Model discovery invokes deprecated TorchScript APIs even when serving Qwen or GPT-OSS: `deepseek_ocr.quick_gelu`, `phi3_small.quick_gelu`/`gegelu`, and timm's `hrnet.ModuleInterface` (imported through Transformers' Gemma3n config). An unrelated GigaChat registration message also appears at INFO.

## Modifications

- Replace the SGLang TorchScript decorators with `torch.compile(dynamic=True, backend=get_compiler_backend())`. Phi-3's inner `quick_gelu` is a plain function compiled as part of `gegelu`.
- Flatten GeGLU's interleaved pairs before computing the activation and restore the output shape afterward. This avoids the dynamic row indexing overhead observed when compiling the original slices.
- Upgrade all five timm dependency pins from 1.0.16 to 1.0.25, the first release containing [the upstream TorchScript removal](https://github.com/huggingface/pytorch-image-models/commit/bdab30b0eb1055cceb2f288c55084bb7f5dec693).
- Move linear-attention registration bookkeeping to DEBUG.

There are no changes to `models/registry.py` in the final diff and no new warning filters.

| Qwen3-8B TP2 | 1 → 0 | 6 → 0 | Passed |
| GPT-OSS-20B TP1 | 1 → 0 | 3 → 0 | Passed |

- All 16 existing tests passed: `python -m unittest test.registered.unit.models.test_model_registry test.registered.unit.configs.test_linear_attn_model_registry test.registered.unit.multimodal.test_deepseek_ocr_geometry`.
- The final model registry imports with zero TorchScript deprecations. Both activations pass FP32/FP16/BF16 comparisons against the original TorchScript functions and float64 references, including optional clamping, infinities/NaNs, strided and batched inputs, empty GeGLU inputs, CUDA graph replay and the OCR feed-forward caller. Fusion changes low-precision intermediate rounding; FP16/BF16 outputs match float64 references within one dtype epsilon plus underflow tolerance.
- timm 1.0.25 strictly loads the state dictionary produced by 1.0.16 for SGLang's `vit_so400m_patch14_siglip_384.webli` configuration and gives bit-identical BF16 outputs for 384px and 400px images.
- Pre-commit passed for all changed files.

The NCCL port-speed-query warning and GPT-OSS Harmony vocabulary-load failure remain visible. The latter disables `/v1/responses` on this machine, while `/generate` succeeds. Full Phi-3/OCR checkpoint accuracy and other hardware backends were not evaluated.

## Speed Tests and Profiling

Warmed CUDA graph microbenchmarks, median of three runs, with each dtype in a fresh process. GeGLU input shape `(128, 28672)`:

| Dtype | TorchScript | Compiled |
|---|---:|---:|
| FP32 | 4.685 µs | 3.610 µs |
| FP16 | 4.727 µs | 3.199 µs |
| BF16 | 4.717 µs | 3.181 µs |

At 1 and 16 tokens, GeGLU changes by less than 0.07 µs. QuickGELU changes by less than 0.11 µs across the tested 1/16/128-token shapes. These are operator measurements, not end-to-end throughput results.
