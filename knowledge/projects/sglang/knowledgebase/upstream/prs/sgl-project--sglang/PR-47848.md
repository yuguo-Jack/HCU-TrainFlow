# [Fix] [Apple] mlx: Initialize Mamba checkpoint grid for auxiliary radix cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/47848) · state: open · merged: False

## Original PR description

## Motivation

On the Apple Silicon MLX backend, hybrid-SSM models can fail when using the Mamba radix cache because `MlxAuxiliaryStateComponent` does not initialize all fields required by its inherited `MambaComponent` methods.

Unlike `MambaComponent`, the MLX implementation directly invokes `TreeComponent.__init__`, leaving the following fields uninitialized:

- `mamba_cache_chunk_size`
- `mamba_checkpoint_grid`
- `mamba_max_states_per_path`

When serving `mlx-community/Qwen3.6-35B-A3B-4bit` with the `no_buffer` Mamba radix cache strategy, this results in:

```text
AttributeError: 'MlxAuxiliaryStateComponent' object
has no attribute 'mamba_checkpoint_grid'
```

The error originates from `finalize_match_result_in_tree_core`, where the inherited Mamba cache logic accesses the missing attribute.

This PR fixes the missing initialization to restore compatibility with the inherited Mamba cache logic.

Related to #32449 and #32450.

PR #32450 addresses broader MLX hybrid-SSM radix cache issues, including allocator compatibility and copy-on-write handling. This PR specifically addresses the missing initialization of `mamba_checkpoint_grid` and related inherited fields.

## Modifications

**1. Initialize inherited Mamba cache fields**

Updated `MlxAuxiliaryStateComponent.__init__` to initialize:

- `mamba_cache_chunk_size` from `slot.checkpoint_interval`
- `mamba_checkpoint_grid` using `math.lcm(slot.checkpoint_interval, params.page_size)`
- `mamba_max_states_per_path` from the runtime execution context

These values follow the initialization logic used by the base `MambaComponent`.

**2. Update existing MLX unit tests**

Updated the existing tests in:

- `test_attention_patching.py`
- `test_max_running_requests.py`

The tests now provide the required `page_size` and runtime configuration when constructing `MlxAuxiliaryStateComponent`.

**3. Add a regression test**

Added `test_auxiliary_state_initializes_mamba_cache_fields` to verify that all three inherited fields are initialized correctly.

The regression test was verified against both the original and patched implementations.
