# [Fix] [XPU] baichuan: Apply ALiBi slopes on intel_xpu

[Upstream PR](https://github.com/sgl-project/sglang/pull/45999) · state: open · merged: False

## Original PR description

## Motivation

Baichuan2-13B / Baichuan-13B use ALiBi and skip RoPE. `baichuan.py` passes the ALiBi slopes to attention only on NPU, so on XPU the model runs with no position information and degenerates (`0 0 0 ...`). Baichuan2-13B-Chat gsm8k is **0.00** on B60 (vLLM RTX 6000 Blackwell: 53.5).

## Modifications

- **`models/baichuan.py`**: pass `slopes` on XPU too, as fp32.
- **`layers/attention/xpu_backend.py`**: `forward_extend` / `forward_decode` accept `slopes` and forward it as `alibi_slopes` to `flash_attn_with_kvcache`, next to the existing `sinks` kwarg.

Other models and backends are unchanged. On XPU with `--attention-backend triton`, Baichuan-13B now raises at the first forward (triton takes no `slopes`) instead of running without position information.

Depends on sgl-project/sgl-kernel-xpu#573 (`alibi_slopes` in the FMHA kernels) and the sgl-kernel-xpu pin bump that follows it.
