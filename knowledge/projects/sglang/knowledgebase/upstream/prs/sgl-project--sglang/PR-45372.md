## Motivation

Qwen3-VL vision modules could not correctly use ModelOpt NVFP4 weights.

There were three related issues:

1. Qwen3-VL always disabled `quant_config` for the vision model, so vision linear layers were built as BF16 layers even when the checkpoint provided ModelOpt FP4 metadata and packed weights.
2. The ModelOpt W4A4 FP4 linear path only accepted 2D inputs, while Qwen3-VL vision attention can pass tensors with leading dimensions such as `[B, S, K]`.
3. ModelOpt mixed-precision dispatch and exclusion checks did not consistently resolve `model.visual.*` and `visual.*` aliases, so vision metadata, skip rules, and packed module mappings could disagree after weight-name mapping.

This PR enables the supported ModelOpt quantization paths for Qwen3-VL vision while keeping other quantization backends disabled for vision.

## Modifications

1. Forward ModelOpt vision quant configs in `qwen3_vl.py`
   - Pass `quant_config` into `Qwen3VLMoeVisionModel` only for `modelopt_fp4` and `modelopt_mixed`.
   - Keep the previous `None` behavior for other quantization backends.
   - Fix Qwen3-VL weight-name mapping from `model.visual` to `visual`, including root, glob, and nested layer names.

2. Support Qwen3-VL vision prefixes in ModelOpt quantization
   - Add shared prefix candidates for `model.visual.*` and `visual.*`.
   - Apply the alias handling to uniform ModelOpt FP4 exclusions, mixed-precision metadata dispatch, packed-module skip checks, and vision position embedding handling.

3. Preserve leading dimensions in W4A4 FP4 linear apply
   - Flatten `[..., K]` inputs to `[M, K]` before FP4 quantization and GEMM.
   - Restore the output to `[..., N]`.
   - Preserve the existing flattened contract for pre-quantized tuple inputs.
   - Keep W4A16 and Marlin behavior unchanged.

4. Add regression tests
   - Add CPU unit coverage for W4A4 leading-dimension inputs, non-contiguous inputs, bias handling, AWQ pre-quant scaling, and pre-quantized tuple inputs.
   - Add Qwen3-VL tests for ModelOpt vision config forwarding, visual weight-name mapping, uniform exclusions, fused QKV split exclusions, mixed precision dispatch, and vision position embedding dispatch.
   - Add CUDA backend regression coverage for leading-dimension NVFP4 linear inputs against a dequantized reference.
