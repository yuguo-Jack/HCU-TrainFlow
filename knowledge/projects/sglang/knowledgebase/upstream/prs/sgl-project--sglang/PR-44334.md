# [Fix] io-struct: validate batch bootstrap routing columns

[Upstream PR](https://github.com/sgl-project/sglang/pull/44334) · state: open · merged: False

## Original PR description

## Motivation

`GenerateReqInput` repeats bootstrap lists without checking their length. For two prompts and `n=3`, a one-element `bootstrap_host` normalizes successfully but `req[3]` raises `IndexError`. A three-element list also succeeds and attaches its third host to the first prompt's second sample.

Reject malformed routing columns before requests are split. Preserve both supported forms: one value per original prompt, or one value per expanded request. The latter matters for PD routers; #43863 documents the same convention on the Rust worker.

## Modifications

- Normalize `bootstrap_host`, `bootstrap_port`, `bootstrap_room`, `bootstrap_pair_key`, and `decode_tp_size` together. Repeat per-prompt lists; retain full per-choice lists; reject other lengths with a field-specific `ValueError`.
- Keep scalar broadcast, distinct scalar room numbering, and `None` defaults unchanged.
- Extend the existing `test_io_struct.py` with regression coverage and the documented `maybe_stub_sgl_kernel()` CPU helper. Working kernel installations are unaffected.

This changes only Python request normalization, not the Rust implementation in #43863.

## Accuracy Tests

Complete-package Linux CPU check, Python 3.12 / Torch 2.11.0+cu130:

```sh
CUDA_VISIBLE_DEVICES=9 SGLANG_USE_CPU_ENGINE=1 \
  python test/registered/unit/managers/test_io_struct.py -v
```

Device index 9 was verified absent. Both arms used the same full Python package and candidate test file; only `io_struct.py` was restored to the base version for the control.

- Fix: 68 tests run, 66 passed, 2 existing CUDA-dependent tests skipped.
- Control: 32 failing subcases across the two new malformed/per-choice tests; other tests retained their outcomes.
- Direct calls to normalization and `req[i]` reproduced the short-list `IndexError` and intermediate-list host misalignment. The fix rejects both; legal per-choice child mappings match the control.
- Actual imported paths/hashes checked; CUDA remained uninitialized. Existing dependency/backend warnings were present in both arms.

The documented optional-kernel helper is used. This is not accelerator, server, RDMA, or official CI qualification. Official CI remains to run.
