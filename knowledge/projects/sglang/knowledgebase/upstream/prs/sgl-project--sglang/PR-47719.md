# [Fix] [AMD] kernels: Fix ROCm 7.0 mHC compilation and FP32 GEMM

[Upstream PR](https://github.com/sgl-project/sglang/pull/47719) · state: open · merged: False

## Original PR description

## Problem and change

The ROCm 7.0 base image referenced by `docker/rocm.Dockerfile` cannot compile the gfx950 mHC boundary header or execute the BF16-input/FP32-output GEMM used by current DeepSeek V4.1 code:

- Its HIP host compilation pass rejects the two 16-byte `__builtin_amdgcn_global_load_lds` calls (`invalid size value`, `size must be 1, 2, or 4`). The gfx950 device pass accepts them. Guard the device-only prefetch bodies with `__HIP_DEVICE_COMPILE__`.
- Its Torch accepts `out_dtype=torch.float32` but rejects the ROCm BF16-to-FP32 GEMM backend. Use the existing FP32-input fallback on HIP Torch versions older than 2.9.1. Supported HIP versions and CUDA retain the native path. The capability check uses only version strings, so it performs no probing during graph capture.

This PR changes only these two runtime files. No Dockerfile, CI job or recurring test is added. It is independent of the Docker multistage refactor in #22037.

## Direct verification

Verified on **MI355X** using `rocm/sgl-dev:rocm7-vllm-20250904`, the ROCm 7.0 base image referenced by `docker/rocm.Dockerfile`. Tests used its bundled HIP compiler and PyTorch without upgrading either.

- Digest: `sha256:b781af2c7c37229e15eb3007e6117328c7138c232cdb22d0c12d7309062ac2d0`
- HIP `7.0.51831-a3e329ad8`, AMD clang `20.0.0git`, Torch `2.9.0a0+git7bcbafe`.
- Unpatched source: `07efafb546`; both affected files are byte-identical to the pre-refactor baseline `5eb7018347`.

No compiler, Torch, Triton or other package was upgraded in this image. The HIP harness only unpacks the TVM-FFI 0.1.10 wheel for headers; it does not install it. The GEMM harness compiles the actual function AST unchanged from each source file to avoid unrelated SGLang/AITER imports; all Torch calls and GPU arithmetic are real, with no mocks.

| Check | Unpatched | Patched |
|---|---|---|
| Full mHC header, HIP host + gfx950 device compilation | Two host-pass errors at the LDS calls | Pass |
| Native `torch.mm(BF16, BF16, out_dtype=float32)` | `gemm input type at::BFloat16 and output type float is not supported for ROCm` | Framework intentionally unchanged |
| SGLang GEMM function | Same framework error | Eager and graph replay exactly equal FP32 reference |
| mHC GPU computation | Cannot build | All 16 cases exactly equal CPU reference |

mHC cases cover both stats-only and post-combine forms, `M={1,17,129,257}` and `H={128,192}`, including tail rows and the next-block prefetch path. The GEMM operands produce results not representable in BF16, so casting a rounded BF16 result to FP32 would fail the check.

Control validation with the ROCm 7.2 image (`lmsysorg/sglang-rocm:v0.5.21-rocm724-mi35x-20261013`, Torch `2.11.0+rocm7.2`, HIP `7.2.26015`): native mixed-output GEMM, unpatched SGLang function and patched function all pass eager/graph FP32 comparisons. Pre-commit checks pass.

These failures reproduce with the base image's bundled toolchain and upstream kernel code, independently of the Docker refactor. Verification is operator-level; it does not include rebuilding the full SGLang Dockerfile or running a full model.

## Reproduce the one-off checks

From this PR checkout, prepare a directory mounted as `/probe` with `before/` and `after/` copies of the two changed files (before from `git show 07efafb546:<path>`, after from this checkout), and copy `python/sglang/kernels/jit/include` to `/probe/include`. Save the three harnesses below there. Run the CPU compile check and then the GPU checks:

```bash
docker run --rm -v "$PWD/probe:/probe" \
  rocm/sgl-dev:rocm7-vllm-20250904 bash /probe/cpu_probe.sh

docker run --rm --device=/dev/kfd --device=/dev/dri --ipc=host \
  --group-add video -e HIP_VISIBLE_DEVICES=0 -v "$PWD/probe:/probe" \
  rocm/sgl-dev:rocm7-vllm-20250904 \
  bash -lc 'python /probe/gemm_probe.py && /probe/after_probe'
```

<summary>gemm_probe.py</summary>

```python
import ast
import functools
from pathlib import Path
from typing import Optional
import torch
from packaging.version import Version

print('torch', torch.__version__, 'HIP', torch.version.hip, 'device', torch.cuda.get_device_name(0), flush=True)
torch.manual_seed(0)
x=torch.randint(-32,33,(17,128),device='cuda').bfloat16()/8
w=torch.randint(-32,33,(64,128),device='cuda').bfloat16()/8
reference=torch.mm(x.float(),w.float().t())
assert (reference != reference.bfloat16().float()).any()
try:
    native=torch.mm(x,w.t(),out_dtype=torch.float32)
    torch.testing.assert_close(native,reference,rtol=0,atol=0)
    print('native mixed-output: PASS',flush=True)
    native_supported=True
except RuntimeError as exc:
    assert 'not supported for ROCm' in str(exc),str(exc)
    print('native mixed-output:',str(exc),flush=True)
    native_supported=False

# Compile the actual checked-in function AST unchanged; isolate its framework
# boundary so unrelated SGLang/AITER imports do not alter the base environment.
for mode in ('before','after'):
    source=Path('/probe',mode,'bf16_fp32.py').read_text()
    tree=ast.parse(source)
    selected=[node for node in tree.body if isinstance(node,ast.FunctionDef) and node.name in ('_linear_bf16_fp32_cublas','_supports_bf16_fp32_output')]
    ns={'torch':torch,'Version':Version,'functools':functools,'Optional':Optional}
    exec(compile(ast.Module(body=selected,type_ignores=[]),str(Path(mode,'bf16_fp32.py')),'exec'),ns)
    fn=ns['_linear_bf16_fp32_cublas']
    try:
        value=fn(x,w)
    except RuntimeError as exc:
        assert mode=='before' and not native_supported and 'not supported for ROCm' in str(exc),str(exc)
        print(mode+': EXPECTED FAILURE: '+str(exc),flush=True)
        continue
    assert mode=='after' or native_supported
    assert value.dtype==torch.float32
    torch.testing.assert_close(value,reference,rtol=0,atol=0)
    stream=torch.cuda.Stream(); stream.wait_stream(torch.cuda.current_stream())
    with torch.cuda.stream(stream):
        for _ in range(3):fn(x,w)
    torch.cuda.current_stream().wait_stream(stream)
    graph=torch.cuda.CUDAGraph()
    with torch.cuda.graph(graph): captured=fn(x,w)
    graph.replay()
    torch.testing.assert_close(captured,reference,rtol=0,atol=0)
    print(mode+': PASS, eager and graph replay exactly equal FP32 reference',flush=True)
```

#include <cstdio>
#include <cstring>
#include <vector>
#include <stdexcept>
using namespace sglang::mhc_boundary_hip;
void check(hipError_t e){if(e!=hipSuccess)throw std::runtime_error(hipGetErrorString(e));}
uint16_t bf(float f){uint32_t u;std::memcpy(&u,&f,4);return (u+0x7fff+((u>>16)&1))>>16;}
float fp(uint16_t b){uint32_t u=uint32_t(b)<<16;float f;std::memcpy(&f,&u,4);return f;}
template<class T>T* upload(const std::vector<T>& a){T* p;check(hipMalloc(&p,a.size()*sizeof(T)));check(hipMemcpy(p,a.data(),a.size()*sizeof(T),hipMemcpyHostToDevice));return p;}
template<class T>void compare(T* p,const std::vector<T>& want,const char* name){std::vector<T> got(want.size());check(hipMemcpy(got.data(),p,got.size()*sizeof(T),hipMemcpyDeviceToHost));for(size_t i=0;i<got.size();++i)if(got[i]!=want[i]){std::fprintf(stderr,"%s mismatch at %zu: %g != %g\n",name,i,double(got[i]),double(want[i]));throw std::runtime_error("mismatch");}}
template<bool post>void run(int m,int h){
  int slices=h/64;
  std::vector<uint16_t>x(m*h),res(m*4*h),want_res(m*4*h),want_y(m*h);
  std::vector<float>p(m*4),c(m*16),pre(m*4),w(24*4*h),mix(slices*m*24),sq(slices*m);
  for(int r=0;r<m;++r){for(int j=0;j<h;++j){x[r*h+j]=bf(float((r+j)%7-3)/8);for(int k=0;k<4;++k)res[(r*4+k)*h+j]=bf(float((r+j+k)%7-3)/8);}for(int k=0;k<4;++k){p[r*4+k]=float(k+1)/8;pre[r*4+k]=0.25f;for(int q=0;q<4;++q)c[r*16+q*4+k]=q==k?1.f:0.125f;}}
  for(int n=0;n<24;++n)for(int k=0;k<4;++k)for(int j=0;j<h;++j)w[n*4*h+k*h+j]=float((n+k+j)%5-2)/16;
  for(int r=0;r<m;++r)for(int j=0;j<h;++j){float yy=0;for(int k=0;k<4;++k){float v=fp(res[(r*4+k)*h+j]);if(post){v=fp(x[r*h+j])*p[r*4+k];for(int q=0;q<4;++q)v=v+fp(res[(r*4+q)*h+j])*c[r*16+q*4+k];v=fp(bf(v));}want_res[(r*4+k)*h+j]=bf(v);yy=yy+pre[r*4+k]*v;sq[(j/64)*m+r]+=v*v;for(int n=0;n<24;++n)mix[((j/64)*m+r)*24+n]+=v*w[n*4*h+k*h+j];}want_y[r*h+j]=bf(yy);}
  auto dx=upload(x),dr=upload(res),dout=upload(std::vector<uint16_t>(res.size())),dy=upload(std::vector<uint16_t>(x.size()));
  auto dp=upload(p),dc=upload(c),dpre=upload(pre),dw=upload(w),dm=upload(std::vector<float>(mix.size())),ds=upload(std::vector<float>(sq.size()));
  Params args{dx,dr,dp,dc,dpre,dw,dout,dy,dm,ds,h,4*h,m,h,(m+15)/16};
  hipLaunchKernelGGL((hc_boundary_prefill_kernel<post>),dim3(slices,1),dim3(kThreads),0,0,args);
  check(hipGetLastError());check(hipDeviceSynchronize());
  compare(dm,mix,"part_mix");compare(ds,sq,"part_sq");if(post){compare(dout,want_res,"res_out");compare(dy,want_y,"y");}
  for(void* ptr:{(void*)dx,(void*)dr,(void*)dout,(void*)dy,(void*)dp,(void*)dc,(void*)dpre,(void*)dw,(void*)dm,(void*)ds})check(hipFree(ptr));
  std::printf("mHC post=%d M=%d H=%d: PASS exact CPU reference\n",int(post),m,h);
}
int main(){for(int m:{1,17,129,257})for(int h:{128,192}){run<false>(m,h);run<true>(m,h);}return 0;}
