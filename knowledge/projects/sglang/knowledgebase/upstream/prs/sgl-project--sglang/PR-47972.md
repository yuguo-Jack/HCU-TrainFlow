# [CI] [AMD] amd-ci: Pass optional HF proxy env into the CI container

[Upstream PR](https://github.com/sgl-project/sglang/pull/47972) · state: open · merged: False

## Original PR description

## Motivation

Let the AMD CI runner route the container's Hugging Face downloads through an optional caching proxy.

## Modifications

In `amd_ci_start_container.sh` and `amd_ci_start_container_disagg.sh`:

- If the runner sets `HF_ENDPOINT` and `$HF_ENDPOINT/healthz` answers, pass `HF_ENDPOINT` (and `HF_HUB_DISABLE_XET` if set) into the container.
- If the proxy doesn't answer, warn and download from huggingface.co as before.
- If `HF_ENDPOINT` isn't set, nothing changes.

## Tests

Ran the new block under `set -euo pipefail` with `HF_ENDPOINT` unset, proxy up, and proxy down. `bash -n` and shellcheck are clean.
