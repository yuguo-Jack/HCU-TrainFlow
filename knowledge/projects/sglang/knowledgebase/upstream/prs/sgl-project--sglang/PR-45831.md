# [CI] multimodal_gen: Calibrate single-GPU shard scheduling from CI

[Upstream PR](https://github.com/sgl-project/sglang/pull/45831) · state: closed · merged: True

## Original PR description

## Motivation

The single-GPU diffusion shards in #45761 finished in approximately 16–21 minutes, below the intended roughly 30-minute shard budget. Their scheduling estimates no longer reflect the recorded testcase durations.

## Modifications

Update 50 H100 single-GPU `estimated_full_test_time_s` values using the existing successful [CI run 39736544560](https://github.com/sgl-project/sglang/actions/runs/39736544560). Use the largest observed individual attempt per testcase, rounded up to 10 seconds. These estimates cause the current planner to select three shards instead of five, with an estimated 30-minute budget per shard.

Keep the testcase inventory, standalone-file estimates, two-GPU/B200 scheduling, and all performance, memory, and consistency thresholds unchanged. Leave the newly added Wan Animate distilled testcase's estimate unchanged because it was absent from the sampled run.

## Accuracy Tests

Scheduling metadata only; generation settings and accuracy thresholds are unchanged.

## Speed Tests and Profiling

The source CI run contains 50 unique measured testcases with 72.2 minutes of summed maximum per-case wall time. The new three-shard layout has not been executed; the 30-minute figures are scheduling estimates, not measured new job durations. No additional GPU runs were requested for this calibration.
