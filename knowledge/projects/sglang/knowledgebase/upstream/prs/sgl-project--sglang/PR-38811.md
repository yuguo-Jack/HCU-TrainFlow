# Fix draft KV memory sizing with DP attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/38811) · state: closed · merged: False

## Original PR description

## Motivation

DFLASH-family draft KV memory sizing currently shards the draft model's KV heads by the global tensor-parallel size. With DP attention, the attention tensor-parallel width can be smaller than the global TP width, so this underestimates the draft KV pool and can over-allocate the shared token capacity until startup runs out of memory.

For example, with TP 32, attention TP 1, and 16 draft KV heads, the estimator accounts for one KV head while the draft pool stores all 16 heads on each attention rank: a 16x underestimate of the draft KV term. This is a memory-sizing issue, not an inference-output accuracy bug.

## Modifications

Use `attn_tp_size` instead of the global `tp_size` when resolving the DFLASH-family draft KV bytes per token. This matches the parallel width used by the actual attention KV pool.
