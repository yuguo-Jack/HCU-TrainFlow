Fixes #40083

This Pull Request addresses issue #40083 by adding regression tests for the recently fixed JSON Schema prevalidation. Specifically, it ensures that uniqueItems and multipleOf keywords trigger an UnsupportedJSONSchemaFeature exception when used with the default xgrammar backend, enforcing standard rejection of these constraints as expected instead of generating nonconforming JSON.
