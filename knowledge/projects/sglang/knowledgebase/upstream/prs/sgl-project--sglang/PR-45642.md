# [Doc] [NPU] cookbook: add A3 deployment scenarios to GLM-5.2

[Upstream PR](https://github.com/sgl-project/sglang/pull/45642) · state: closed · merged: True

## Original PR description

The A3 deployment scenarios themselves landed in #45597. I had a draft for the same task (Ascend/sglang#1211) in #39321 that crossed with it by accident — that work is retired and the merged recipes stand as they are. What this PR keeps is the two pieces of it that still apply on top of the merged version, both measured on an A3 card. Nothing here changes a recipe #45597 added.

**1. The pinned A3 image cannot start the PD recipes.** They pass `--attn-dp-size` (#41818, 2026-09-30), while `cann9.0.0-a3-v0.5.16` carries an sglang built 2026-07-30. Feeding the merged `npuPdRecipes` entries to `prepare_server_args()` inside each image:

| image | result |
|---|---|
| `cann9.0.0-a3-v0.5.16` (pinned today) | `error: unrecognized arguments: --attn-dp-size`, both roles |
| `v0.5.22-cann9.1.0-a3` | both roles resolve — `quantization=modelslim`, `attention_backend=ascend`, `disaggregation_mode=prefill` / `decode` |

The first commit moves the image reference in all four places. The single-node and multi-node A3 cells are unaffected — they use `--dp-size` with `--enable-dp-attention`, which the newer image still accepts. If you would rather keep the 9.0.0 image, the alternative is to spell the two PD recipes `--dp-size N --enable-dp-attention` like the other A3 cells; happy to switch.

**2. Configuration Tips has no Ascend entry.** The second commit adds four bullets: the 16-device topology behind `--tp-size 16` and how the PD roles span two nodes behind the router, the W8A8 footprint and why the recipes pass `--speculative-draft-model-quantization unquant`, the host CPU/NUMA settings as runnable commands, and the cross-node wiring rules.

Checks: `check_cookbook_configs.mjs` and its test suite, `mint broken-links --check-anchors --check-redirects`, and the applicable pre-commit hooks pass. The A3 Docker command emits the new tag with its 16 `davinci` devices, and both PD roles still render. On-hardware verification still needs full A3 nodes, so the cells keep `verificationStatus: "in-progress"`.

cc @amote-i @stellaxcpeng. Could someone with write access add the `run-ci` label? `pr-gate` gates the test workflows on it.
