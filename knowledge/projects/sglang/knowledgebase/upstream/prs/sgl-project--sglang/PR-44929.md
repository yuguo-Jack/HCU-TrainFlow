# [Fix] cache: Accept packed draft layer mappings in the UMBP linker

[Upstream PR](https://github.com/sgl-project/sglang/pull/44929) · state: open · merged: False

## Original PR description

## Motivation

The direct-linker pool groups pack draft depth N onto the transfer layer of target layer N (DSA with MTP/EAGLE/DSpark draft pools, DeepSeek-V4 paged SWA with a draft), so one logical layer maps to several device buffers. UMBP's layer ordering treated the tuple as a broken bijection and refused to start.

Split out of #44623 per review.

## Modifications

- Walk every buffer index of a mapped layer when ordering UMBP pool layers, rejecting a buffer mapped twice.
- Emit every buffer of a packed layer in one UMBP range group.
- Unit test for the packed target/draft ranges.

## Validation

- Unit test passes.
