# [Test] linker: Cover sub-window SWA continuation restores

[Upstream PR](https://github.com/sgl-project/sglang/pull/47747) · state: closed · merged: False

## Original PR description

## Disposition

Closed after correctness validation against main `cb0a7a953fa6b8409b67959d445c95c802e50c14`, which includes #46395. No corresponding direct-linker sub-window restore defect was found, so this test-only PR is not needed as a port of the HiCache fix in #46934. No runtime fix is proposed.

## Validation

- **SWA short-tail serving test:** two standalone Inkling (`thinkingmachines/Inkling`, test revision `85b071f87d9bf5ff16a213a2d825faeed3af2cbf`) servers shared Mooncake TCP storage. With a 512-token SWA window and 128-token pages, the reader retained a 512-token device prefix and restored a 256-token remote continuation. Both independent prompts reported device=512, host=256; the control reported device=512, host=0. All 257 generated tokens per prompt and their logprobs matched the recomputation control exactly (maximum difference 0).
- **Actual PD decode publication:** `yujiepan/kimi-linear-tiny-random`, NIXL PD transfer, Mooncake TCP linker, 64-token pages and 128-token Mamba checkpoints. Across two sessions with two turns each, enabling decode publication raised second-turn **prefill** cache hits from 512 to 768. Prefill logs confirmed external loads; decode-local cache counters were not used as proof of a remote hit.
- **Independent numerical control:** for both sessions, PD linker restore produced exactly the same 257 output tokens and logprobs as a standalone server reusing its local decode-generated cache, with no linker enabled (maximum difference 0). Reusing decode-generated state versus recomputing it can produce different greedy continuations on this tiny KDA model even without a linker; that difference was reproduced in the local control.
- **Diagnostic payload check:** temporary read-only instrumentation compared SHA-256 hashes before offload and after layer-wise load. All 22 loaded page/layer records matched their written payloads: 16 KV and 6 Mamba, zero mismatches. The instrumentation is not part of this PR.
- A targeted fixed-continuation comparison against recomputation scored 256 tokens per session: mean k3 estimates were 8.87e-8 and 5.31e-8, maximum absolute logprob differences 0.001461 and 0.000975. These are limited diagnostic samples, not a general model-accuracy threshold or a claim of bit-identical recomputation.

## Scope

The SWA short-tail serving test and the PD decode-publication test are separate validations. Inkling SWA-compress plus decode radix cache is currently rejected at startup; ordinary gpt-oss SWA does not yet have a direct-linker pool strategy. No combined SWA+PD validation on those unsupported configurations is claimed. The test-only additions cover the Python/Rust tree-core continuation contract; no production runtime code is changed.

No performance claims.
