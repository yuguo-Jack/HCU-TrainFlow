# [AMD][CI] Drop removed tp_rank/tp_size kwargs from small-M FP8 proj test

[Upstream PR](https://github.com/sgl-project/sglang/pull/43318) · state: closed · merged: True

## Original PR description

## Motivation

`test_smallm_fp8_proj_gfx950.py` fails on main in the [scheduled AMD run](https://github.com/sgl-project/sglang/actions/runs/37776737975/job/113309486224):

```
TypeError: RowParallelLinear.__init__() got an unexpected keyword argument 'tp_rank'
```

#42588 removed the `tp_rank` / `tp_size` kwargs from `RowParallelLinear`. #41134 merged a few hours later with a test that still passed them, and its CI had run against a main from before #42588, so the conflict only showed up after both landed.

## Modifications

Drop `tp_rank=0` and `tp_size=1` from the `RowParallelLinear` call in `test_quark_row_linear_takes_producer_tuple`. The test already runs under `init_single_process_dist()` and `get_parallel().override(tp_size=1, tp_rank=0)`, so the layer's default TP group gives the same rank and size.

## Accuracy Tests

Test-only change; no effect on model outputs.

`python3 registered/amd/test_smallm_fp8_proj_gfx950.py` in the CI image `rocm/sgl-dev:v0.5.21-rocm10-mi35x-20261008` on MI355X: 7/7 pass.
