# [diffusion] comfyui: grouped SGLDOptions, native model loader and model-aware preflight

[Upstream PR](https://github.com/sgl-project/sglang/pull/44058) · state: closed · merged: True

## Original PR description

## Motivation

`SGLDOptions` was a flat list of ServerArgs fields. Several did nothing in ComfyUI integrated mode (`dp_size` > 1 is rejected, `enable_cfg_parallel` only recomputes since ComfyUI already splits cond/uncond, `sp_degree` duplicated Ulysses x Ring), FastH3 / VDN-H3 needed `runtime_model_path` plus a base H3 file as a placeholder, and some settings were silently ignored (online `quantization` on ComfyUI files). Breakable CUDA graph did not start at all in ComfyUI mode, and Spectrum never skipped a step.

## Modifications

1. **Runtime fixes (H3 / ComfyUI mode)**
   - BCG: ServerArgs forced `warmup_mode=server` plus a default warmup resolution, overriding `comfyui_mode`'s `warmup_mode=off`; the synthetic request has no sampler tensors, so every `cuda_graph` worker failed at startup. Skip both in `comfyui_mode` (the H3 step stage captures on its first real step).
   - Spectrum: each ComfyUI step is a one-step request, so its counters reset every step. The H3 step stage now gives it the run's step count.
2. **`SGLDOptions`** (same node id, new inputs; saved workflows need the node re-set). `model_type` and `num_gpus` stay on top; the rest fold into groups whose headers show the current value (`Parallel · auto`, `Cache · Cache-DiT`):

   | Group | Fields |
   |---|---|
   | Parallel | `parallel_mode` auto / manual; manual: `tp_size`, `ulysses_degree`, `ring_degree` |
   | Attention | `attention_backend`: auto, flash_attention, torch_sdpa, sage_attention2, sage_attention3, sol_attention, H3 sparse backends; `attention_backend_config` (picking sol_attention fills its defaults) |
   | Quantization | `quantization` (online, native directories only); `int8_gemm` auto / sglang_jit / comfy_kitchen (GEMM kernel for INT8 ConvRot weights) |
   | Cache | `cache_mode` off / cache_dit / teacache / spectrum; for cache_dit, `cache_dit_tuning` auto / manual (warmup steps, residual threshold, max consecutive cached steps, Fn blocks). Per request, never restarts the worker |
   | Execution | `execution_mode` eager / torch_compile / cuda_graph; `regional_compile` |
   | Memory | `memory_mode` resident / layerwise_offload; resident and prefetch layers |

   Removed: `sp_degree`, `dp_size`, `dp_degree`, `enable_cfg_parallel`, `runtime_model_path`, `transformer_weights_path` (which weights to load belongs to the loader; `SGLDUNETLoader` already lists local GGUF files).
3. **`SGLDNativeModelLoader`**: loads FastH3 / VDN-H3 native directories (type from `model_index.json`); the ComfyUI model skeleton is built from `transformer/config.json`, so no companion file is needed.
4. **`core/preflight.py`**: checks the options against the resolved model at the loader, before the running worker is touched, and raises instead of ignoring a setting:
   - cuda_graph: MiniMax H3 only, with cache off and no layerwise offload.
   - FastH3 / VDN-H3: eager only, ring 1; VDN attention fixed; H3 ring > 1 needs flash_attention; per-model attention allowlist.
   - cache_dit / spectrum: MiniMax H3 family (spectrum at SP 1). Other models send each sampler step as its own request and need per-run state first (#43696 adds it for Cache-DiT; the allowlist widens when it lands). TeaCache: no integrated model yet.
   - Online quantization only for native directories; `int8_gemm` only for H3.
5. README and bundled workflows updated.

## Accuracy / Benchmark (2x H200, warm, end-to-end seconds)

MiniMax-H3 INT8 ConvRot, 864x480, 107 frames, 20 steps:

| config | s | PSNR vs flash_attention |
|---|---|---|
| flash_attention | 23.5 | ~40 dB (same-seed rerun) |
| sage_attention2 / torch_compile / layerwise offload | 23.5 / 23.9 / 23.1 | offload ~40 dB |
| cuda_graph (failed at startup before) | 23.0 | ~40 dB |
| cache_dit (auto) / cache_dit (manual, threshold 0.3) | 12.7 / 12.3 | 18.9 dB (auto) |
| spectrum (11 of 20 steps skipped) | 23.2 | no net speedup; same in native `DiffGenerator` (20.19 vs 20.24 s) |
| Ulysses 2 (2 GPUs) | 15.1 | |
| FastH3 VSA / VDN-H3 via native loader | 13.5 / 16.2 | |

Rejected at the loader (1-6 s, before the worker starts): cuda_graph + cache, compile on FastH3, cache_dit on Z-Image, online quantization on a ComfyUI file.
