# [Perf] dsv4: Write the MegaAttention output straight into the prefill graph buffer

[Upstream PR](https://github.com/sgl-project/sglang/pull/45901) · state: closed · merged: True

## Original PR description

- The breakable prefill graph's MegaAttention break computed `_mega_core` into a fresh tensor and then copied it into the graph's output buffer, one device-to-device copy of the attention output per layer per step.
- `_mega_core` takes an optional `out` and passes it to the wo_a einsum, and the break passes `output[:real_num_tokens]`, so the einsum writes the graph buffer directly.

No behavior change: the output is bit-identical; the copy is gone. Other callers of `_mega_core` pass no `out` and are unchanged.

Verification: outputs are identical with and without the change; the device-to-device copy disappears from the prefill-graph profile; prefill with the breakable graph is slightly faster at small batches.
