[Upstream PR](https://github.com/sgl-project/sglang/pull/47900) · state: closed · merged: True

## Original PR description

## Summary

- Group SANA-Video, SANA-WM and LongLive with Cosmos under NVIDIA.
- Move HY-Nomas into Tencent; combine MOVA/MOSS-Image under OpenMOSS and LingBot Video/World under Robbyant.
- Use publisher/team labels for FLUX (Black Forest Labs), LTX (Lightricks), JoyAI-Echo (JD.com), LongCat-Image (Meituan), Ming-Image (InclusionAI), ERNIE-Image (Baidu), Qwen-Image (Qwen), and Z-Image (Tongyi-MAI).
- Apply Black Forest Labs consistently to the existing VLA FLUX group and merge autoregressive ERNIE into the existing Baidu group.
- Preserve all page paths, URLs, content, and deployment configurations.

Only `docs/docs.json` changes.

Group by the publishing organization/team, not a model's base architecture or an ultimate corporate parent. Existing team groups such as Qwen and Wan remain separate; the model cards and modality-based cookbook landing pages are unchanged. Existing NEW tags are preserved.
