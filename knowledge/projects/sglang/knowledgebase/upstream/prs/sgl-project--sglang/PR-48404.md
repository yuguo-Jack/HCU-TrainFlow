# [Fix] eplb: reject incompatible recorder modes

[Upstream PR](https://github.com/sgl-project/sglang/pull/48404) · state: open · merged: False

## Original PR description

## Motivation

Combining `--enable-eplb` with `per_pass` or `per_token` is accepted at startup but crashes the scheduler on the first rebalance. EPLB requires object dumps, while these recorder modes only support file output.

Reject the combination early with an actionable error. Fixes #48403.

## Changes

- Validate the incompatible modes in `handle_eplb_and_dispatch`.
- Add regression coverage for rejected (`per_pass`, `per_token`) and allowed (`None`, `stat`, `stat_approx`) modes.
