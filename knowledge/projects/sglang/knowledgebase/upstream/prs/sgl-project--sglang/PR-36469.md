# [Test] mooncake: DO NOT MERGE, validate mooncake-transfer-engine 0.3.14rc4 from test.pypi

[Upstream PR](https://github.com/sgl-project/sglang/pull/36469) · state: open · merged: False

## Original PR description

## Motivation

Validate the **Mooncake 0.3.14 release candidate** in sglang **CI** before it ships to prod PyPI. This points the CI dependency install at the `0.3.14rc4` pre-release on **test.pypi**.

- Package under test: https://test.pypi.org/project/mooncake-transfer-engine-cuda13/0.3.14rc4/ (`mooncake-transfer-engine` 0.3.14rc4 is published too)
- Pinned version: `0.3.14rc4`
- Release branch: [kvcache-ai/Mooncake `release/v0.3.14`](https://github.com/kvcache-ai/Mooncake/tree/release/v0.3.14)

## Modifications

`scripts/ci/cuda/ci_install_dependency.sh` (`install_extra_deps`):
- Bump `MOONCAKE_VERSION` from `0.3.13.post1` to `0.3.14rc4`
- Add `--extra-index-url https://test.pypi.org/simple/` to the mooncake installs
- Split the mooncake install off from the other bundled deps (`nvidia-cuda-nvrtc py-spy scipy huggingface_hub[hf_xet] pytest`) so `uv`'s `--index-strategy unsafe-best-match` can't pull those from test.pypi

Rebased onto current main. Follows the same bump pattern as #32302.

> [!NOTE]
> **Test/validation PR, do not merge as-is.** Before merge, remove the `--extra-index-url https://test.pypi.org/simple/` and pin the final `0.3.14` release once it is on prod PyPI.
