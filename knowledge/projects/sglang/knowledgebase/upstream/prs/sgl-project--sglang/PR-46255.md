# [Fix] diffusion: LoRA alpha reload, auto-mode skip, critic coverage

[Upstream PR](https://github.com/sgl-project/sglang/pull/46255) · state: closed · merged: True

## Original PR description

Stacked on #45837.

## Changes

- An alpha override reloads the adapter. Fused GQA groups bake the alpha into lora_B at load time, so updating the alpha dict alone left them on the old scale.
- merge_mode auto: an unchanged set_lora that auto already kept unmerged is skipped instead of re-entering the weight-update context. The skip check only reads the cached rounding result (`measure=False`).
- The critic is covered by the `use_module_names_only` "all" offload path and by `_reject_lora_on_packed_weights`.

## Tests

No new files. 3 tests in `test_lora_pipeline.py` and `test_fused_lora_compose.py` fail on #45837 and pass here. The existing alpha-override test stubs the loader, since it now reloads.

Modal CPU, LoRA unit files (pipeline, fused compose, auto-merge rounding, merge cache, peft): 66 passed. ruff format clean. No GPU run.
