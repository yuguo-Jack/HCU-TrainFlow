# [Feat] [AMD] diffusion: Add MXFP6 and A6W4 online GEMM quantization

[Upstream PR](https://github.com/sgl-project/sglang/pull/48173) · state: open · merged: False

## Original PR description

## Motivation

Currently on gfx950 the two quantization options for ROCm are MXFP4 and FP8. This PR adds the middleground - MXFP6 and A6W4. They are the compromise between the two, both in speed and accuracy.


## Modifications

- `runtime/layers/quantization/aiter_packed_mx.py`: shared base for both formats.
- `runtime/layers/quantization/mxfp6.py`: `Mxfp6Config` / `Mxfp6LinearMethod`, weights and activations via `quant_mxfp6_gemm`, product via `gemm_a6w6`.
- `runtime/layers/quantization/a6w4.py`: `A6W4Config` / `A6W4LinearMethod`, weights via `quant_mxfp4_gemm`, activations via `quant_mxfp6_gemm`, product via `gemm_a6w4`.
- Each format wraps its activation quant plus GEMM in one functional custom op (`direct_register_custom_op`) so the layer stays `torch.compile` compatible.
- Registered `mxfp6` and `a6w4` in the quantization registry and in the four online-quant sites (`transformer_load_utils`, `comfyui_checkpoints/spec`, `text_encoder_loader`, `--quantization` help). Both honour `--quantization-ignored-layers`.

## Accuracy Tests

Relative error against an fp32 reference, measured on gfx950 at Wan2.2-A14B layer shapes (hidden 5120, ffn 13824, M=9450). Error is flat across shapes, as expected for block-wise quantization of this data.

| format | rel err | vs MXFP4 |
| --- | --- | --- |
| bf16 | 0.0017 | - |
| mxfp4 (existing) | 0.1580 | - |
| **mxfp6** | **0.0399** | 4.0x better |
| **a6w4** | **0.1217** | 1.3x better |


## Speed Tests and Profiling

GEMM only, gfx950, Wan2.2 layer shapes at M=9450, summed over one block's five linears (ms):

| | bf16 | mxfp4 | a6w4 | mxfp6 |
| --- | --- | --- | --- | --- |
| GEMM per block | 3.993 | 1.550 | 1.701 | 1.844 |
| weight bytes (qkv) | 157.3 MB | 41.8 MB | 43.9 MB | 64.5 MB |

A6W4 is 8% faster than MXFP6 at the kernel level and keeps MXFP4's weight footprint to within 5%.

Wan2.2-I2V-A14B, 720x1280, 81 frames, 40 steps, 8x MI350 ulysses-8, warmup excluded:

| | bf16 | mxfp4 | a6w4 | mxfp6 |
| --- | --- | --- | --- | --- |
| total | 71.51s | 65.23s | 65.27s | 65.61s |
| denoise | 64.72s | 59.62s | 59.63s | 59.98s |
| per step | 1.6179s | 1.4905s | 1.4908s | 1.4994s |
| peak memory | 67634 MB | 28778 MB | 30832 MB | 37958 MB |
