## Original PR description

## Summary

Add `--dataset-name embedding` for UTF-8 JSONL containing string or string-array `input` values. The loader counts batched input tokens, preserves per-record embedding parameters, skips malformed/unsupported records, and generates zero output tokens. Embedding arrays stay single requests through benchmark warmup and measured traffic.

```text
embedding JSONL → dataset rows → existing /v1/embeddings request path
```

Related to #9674 (dataset usage only).

**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Exclude embedding batches from multi-turn detection**

When the first valid JSONL record uses the advertised string-array input, storing the `list[str]` directly in `DatasetRow.prompt` makes `benchmark()` classify it as multi-turn: `_normalize_round_messages(first_prompt[0])` accepts the first string, after which `wrap_multi_turn_request_func()` rejects both embedding backends because they are not chat backends. Consequently, an all-batched embedding dataset aborts before warmup instead of reaching `/v1/embeddings`; the embedding path needs to be distinguished from multi-turn chat prompts.
