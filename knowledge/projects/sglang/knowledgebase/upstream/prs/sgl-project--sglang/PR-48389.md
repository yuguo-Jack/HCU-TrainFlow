## Motivation

<!-- Describe the purpose and goals of this pull request. -->

GLM DSA models on NPU run prefill with CP interleave, where per-rank KV memory is the hard capacity bottleneck on the prefill node. The GPU side already supports DSA cache layer-split(`sglang/srt/mem_cache/dsa_cache_layer_split.py`), which shards the KV/indexer cache layers across CP ranks so that each rank only materializes the layers it owns; non-owned layers are borrowed via owner-broadcast reads into a remote scratch buffer.

This PR brings the same feature to Ascend NPU with minimal, mirrored changes. On the prefill node this halves the per-token KV memory (~108.8 KB -> ~51.6 KB per token in our GLM-5.2 measurements) and grows the usable KV token capacity accordingly, and it composes with hierarchical cache: L1 (device) holds owned layers only while L2 (host) keeps the full-layer copy for prefix reuse.

## Modifications

<!-- Detail the changes made in this pull request. -->

- **`hardware_backend/npu/dsa_cache_layer_split.py` (new)**:  It keeps an owned-only stacked KV/indexer buffer plus an independent remote scratch tensor for borrowed layers, retains the asynchronous prefetch state machine, and reports the KV-transfer layer span so PD transfer sees a contiguous logical layer range.

- **`hardware_backend/npu/memory_pool_npu.py`**: add a `_kv_local_offset()` hook and split buffer construction into `_create_buffers()`, so subclasses can reorganize the per-layer buffer indexing without duplicating every access site.

- **`mem_cache/kv_cache_configurator.py`**: when the CP layer shard is active on a DSA model (non-draft), swap in the sharded pool class via `pool_cls` / `pool_kwargs`.

- **`disaggregation/prefill.py`**: compute `prefill_end_layer` from the per-layer buffer-group span (NPU MLA pools report one entry per layer per buffer group: latent k/v, indexer k, fp8 index scale), keeping the non-split path unchanged.

- **`disaggregation/ascend/conn.py`**: when a layer-split prefill reports owned-only entries while a non-split decode peer registers every layer, route the entry-count mismatch into the existing group-aware destination remap (same slicing as the PP path).

- **`arg_groups/model_hook.py`**: allow the `ascend` transfer backend for layer-split on NPU.

- **`mem_cache/pool_host/mla.py`**: support `kernel_ascend` one-shot D2H backup for the layer-sharded host pool (triggered once on the first target layer, draft pools skipped), so layer-split + hierarchical cache (L1 -> L2 write-back) works on NPU.
