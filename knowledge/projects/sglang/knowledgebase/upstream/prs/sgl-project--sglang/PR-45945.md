## Motivation

A background bulk transfer that overlaps the forward (a KV-cache gather over NVLink, host <-> device copies over PCIe) slows any latency-critical op that shares its link, and nothing preempts work already on the GPU. This adds an interface to gate such transfers, independent of what moves the bytes.

A background transfer (low priority) runs as chunks on its own streams. A latency-critical op (high priority) inside paused_background_transfers(link) stops every background transfer on that link at its next chunk boundary; the transfers resume on their own once the op is done. Nothing on the GPU is preempted, so the chunk size bounds how long the op waits.

The transfer's owner hides the chunks and the chain; its callers only start it and wait for it. The bracket belongs to the foreground op, never to the transfer, and can be hidden the same way, for example inside the all-reduce, so model code writes neither:

```python
import torch

from sglang.srt.distributed.device_communicators.gated_transfer import (
    Link,
    TransferChain,
    copy_chunks,
    paused_background_transfers,
)


class Prefetcher:
    """Low-priority host-to-device copies that yield to PCIe-critical ops."""

    def __init__(self, chunk_bytes=16 << 20):
        self.chain = TransferChain(Link.PCIE_H2D)  # once, on the current device
        self.chunk_bytes = chunk_bytes

    def start(self, dst, src, done=None):
        # Returns at once; the copy starts after the current stream's queued work.
        self.chain.run(copy_chunks(dst, src, self.chunk_bytes), done=done)

    def wait(self, done=None):
        # The current stream waits for the copy (default: the last one started).
        self.chain.wait(done)


# Allocate first: nothing inside a bracket may allocate.
weights_host = torch.randn(64 << 20).pin_memory()  # 256 MiB
weights = torch.empty_like(weights_host, device="cuda")
batch_host = torch.randn(1 << 20).pin_memory()
batch = torch.empty_like(batch_host, device="cuda")

prefetch = Prefetcher()
prefetch.start(weights, weights_host)  # background: low priority

with paused_background_transfers(Link.PCIE_H2D):  # foreground: high priority
    batch.copy_(batch_host, non_blocking=True)

prefetch.wait()  # before reading weights
```

- A chunk is any callable chunk(stream), run with that stream current, so a chain runs copy-engine copies (copy_chunks, CopyChunk), NCCL calls on a communicator no foreground op uses, or kernels. An all-gather or all-to-all over NVLink wraps a chain the same way: one CopyChunk per span and peer, plus its cross-rank barrier as setup / finish ops.

- Links: Link.NVLINK, Link.PCIE_H2D and Link.PCIE_D2H (PCIe is full duplex). A bracket may name several, e.g. Link.NVLINK | Link.PCIE.
- With several transfers in flight, pass each a torch.cuda.Event as done and wait for the one you read: wait(done).
- Inside a bracket, enqueue only the communication call. Allocate its outputs first, and never wait on a paused transfer there.
- A watchdog (SGLANG_GATED_TRANSFER_WATCHDOG_MS, default 1000) forces open a pause held that long and logs an error: a pause that cannot resume costs speed, not a hang.

## Speed Tests and Profiling
Measured on 8x H200 (driver 595.58.03, CUDA 13.0, NCCL 2.30.7): a gate wait adds 2.0 us of GPU time per chunk whether the word is in device or host memory; a pause+resume pair 4.7 us (device word) vs 5.7 us (host word).

Tests (test_gated_transfer.py): CPU bracket bookkeeping (nesting, links, owner thread, failing pause / resume, drained skip, capture, compile, the pending hint) and watchdog sampling; 1 GPU chains of D2D / pinned H2D / D2H copies, current-stream callables, setup / finish ordering, a raising chunk, dedicated streams, a held first chunk, the one-chunk drain bound within and across runs and with the pause landing mid-copy, the wait guard, close, the capture refusal and the watchdog opening a stuck gate; 2-4 GPUs plain PyNcclCommunicator broadcast / allgather calls as chunks, a paused rank holding every rank, and a foreground all-reduce on another communicator pausing and resuming in-flight NCCL chunks (watchdog off, so a missing resume fails). Pause words are flipped from the host in the tests: GPU work queued while a gate is parked can share its hardware queue.
