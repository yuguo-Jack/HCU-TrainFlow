# fix(openai): preserve zero cached tokens when reporting is enabled

[Upstream PR](https://github.com/sgl-project/sglang/pull/44010) · state: open · merged: False

## Original PR description

With `--enable-cache-report`, an uncached request currently returns `prompt_tokens_details: null`. This preserves `{"cached_tokens": 0}` so clients can distinguish a zero cache hit from disabled reporting.

Applies the reporting flag consistently to buffered responses, final streaming usage, and Chat continuous usage. Adds regression coverage for zero, positive, and disabled-reporting cases. Existing multiple-choice aggregation and multimodal details are preserved.

Split from my original fix in #28801, which now covers the separate legacy Completions continuous-usage change. Related: #43005. Thanks to @ai-jz for helping narrow the scope.

Validation: pre-commit and `git diff --check` passed. Isolated usage and serialization checks passed; the zero-value regression cases fail on unchanged `main`. Full registered handler tests were not run locally because PyTorch/FastAPI are unavailable.
