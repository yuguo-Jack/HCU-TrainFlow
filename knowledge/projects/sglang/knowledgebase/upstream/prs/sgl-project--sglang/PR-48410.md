# Publish ARM CPU Docker images for SGLang releases 

[Upstream PR](https://github.com/sgl-project/sglang/pull/48410) · state: open · merged: False

## Original PR description

## Motivation

SGLang already [builds and tests an Arm64 CPU Docker image in PR CI](https://github.com/sgl-project/sglang/blob/main/.github/workflows/pr-test-arm64.yml), but it does not publish a versioned image that users can pull This PR adds a release workflow to publish Arm64 CPU images.

## Modifications

- Add a workflow that builds `docker/arm64.Dockerfile` for a release tag or manually supplied SGLang version.
- Check that the built image runs on Arm64 and loads the CPU attention kernel before pushing it to Docker Hub as `lmsysorg/sglang:v<version>-arm64-cpu`.
- Include the new workflow file in the Arm64 PR CI change filter.

## Accuracy Tests

No model or kernel code is changed. Locally, I built the image for `v0.5.22`, started `Qwen/Qwen2.5-0.5B-Instruct` on CPU, and received a successful chat-completion response.

Arm64 PR CI: pending
