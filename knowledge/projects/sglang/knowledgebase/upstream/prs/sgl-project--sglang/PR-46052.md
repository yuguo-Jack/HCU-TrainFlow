# [Doc] cookbook: Fix the dead MiniMax-H3 "Learn more" anchors

[Upstream PR](https://github.com/sgl-project/sglang/pull/46052) · state: open · merged: False

## Original PR description

The deploy widget on the MiniMax-H3 cookbook page renders a "Learn more" link per serve dimension. Five of the six dimensions point it at a section anchor that does not exist on the page:

```
learnMore: "#7-feature-contracts-and-advanced-recipes",
```

On `docs/cookbook/diffusion/MiniMax/MiniMax-H3.mdx`, section 7 is **VDN-H3: hybrid attention, 8-step distill**; "Feature contracts and advanced recipes" is section **9**. So the link lands nowhere.

This changes all five occurrences in `docs/src/snippets/configs/MiniMaxAI/minimax-h3.jsx` to `#9-feature-contracts-and-advanced-recipes`. The sixth entry in the same file already uses a valid anchor (`#choose-the-quality-level`) and is untouched.

Docs-only.
