# [CI] pr-check-comment: Comment on PRs when lint or title check fails

[Upstream PR](https://github.com/sgl-project/sglang/pull/44708) · state: closed · merged: True

## Original PR description

- Add `pr-check-comment.yml`: on `workflow_run` of `Lint` and `PR Title`, post one PR comment listing the failed checks once both have finished for the PR head. It runs main's code and reads only API metadata, so fork PRs get comments without running PR code.
- A new comment is posted only when a failed run has not been reported yet; older comments are minimized as outdated, and all of them once every check passes. Draft PRs are skipped.
- The PR title error is quoted from its `pull_request_target` run; lint gets a run link and a fixed `pre-commit` hint, since a PR controls its own lint output.
