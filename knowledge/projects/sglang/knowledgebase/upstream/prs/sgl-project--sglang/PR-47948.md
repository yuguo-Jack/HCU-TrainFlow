# [Perf] diffusion: Fuse LTX-2.3 vocoder resampling and SnakeBeta

[Upstream PR](https://github.com/sgl-project/sglang/pull/47948) · state: open · merged: False

## Original PR description

LTX-2.3's bandwidth-extension vocoder runs separate padding, resampling and SnakeBeta operations for each alias-free activation. Fuse that chain in one Triton kernel under the existing request-scoped `lossless` gate, retaining the native path for exact quality and unsupported inputs.

Measured on one B200: the FP32 vocoder improves **69.15 → 25.26 ms (2.74×)**. Full native 768×512, 121-frame requests with 30+3 steps improve only **6.659 → 6.610 s (0.74%)** across six warmed saved requests per variant, including reverse-order repeats. This is a focused decoder improvement below the general 1.5% full-request performance target. Measurements used baseline `d2d3632ae0`; the branch is rebased onto current main.

Video frames are identical. Audio passes the existing quality thresholds (spectral similarity 0.9975, waveform correlation 0.9984, RMS difference 0.019 dB). Validation: three cases in one existing kernel test cover cropped edges, stored parameter dtypes and CUDA device handling; 105 kernel-namespace checks and pre-commit pass.

Inspired by WanGP's alias-free activation fusion; the kernel is independently implemented from SGLang's existing resampling math. No new model options or dependencies.

```bash

```
