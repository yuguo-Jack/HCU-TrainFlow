# [Intel][XPU] GDN fork stride fixes and device-agnostic tests

[Upstream PR](https://github.com/sgl-project/sglang/pull/48369) · state: open · merged: False

## Original PR description

## Motivation
Intel XPU fixes split out of #37698. Part of #24922.

## Modifications
- XPU GDN recurrent fork: use the token stride for 4-D KDA `a`, and take the intermediate-state pitch from the buffer's allocated stride so adaptive speculative decoding keeps the right layout.
- `test_fused_verify_triton_gdn.py`: import through the platform dispatcher and register on the XPU nightly kernel suite.
- Shared test CLI: `--device` choices come from `SUPPORTED_DEVICES`, so `xpu` is accepted and `rocm`, which `DeviceConfig` refuses, is rejected.
- Mamba scatter: one `TRITON_DEVICE_TYPES` list shared by the kernels and their tests.
- Remote-instance weight loading and ComfyUI Flux tests use `current_platform` in place of hardcoded CUDA calls.
