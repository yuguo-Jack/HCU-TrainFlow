# [Feat] [NPU] cp-decode-attn-tp: Support dynamic ModelSlim W8A8 weights

[Upstream PR](https://github.com/sgl-project/sglang/pull/44259) · state: open · merged: False

## Original PR description

## Motivation

CP decode attention TP slices replicated attention weights during decode. For dynamic ModelSlim W8A8 on NPU, the post-load weight uses a transposed FRACTAL_NZ layout. Slicing it through the generic tensor path can produce an invalid local weight and fail during decode graph capture.

## Modifications

- Use the ModelSlim scheme to select the correct post-load slicing axes for weights, scales, and offsets.
- Convert each W8A8 weight to ND, extract an independent local shard, and repack it as FRACTAL_NZ for NPU matmul.
- Limit scheme-specific dispatch to NPU, preserving the existing non-NPU behavior.
- Add a DeepSeek-V4-Flash W8A8 GSM8K regression test with CP decode attention TP enabled.

## Accuracy Tests

The new test is configured for 200 GSM8K questions, 8-shot prompting, and a 0.93 accuracy threshold. A complete accuracy result for this staged change is not yet available: the recent server runs failed before evaluation, first in an older checkout's generic weight-slicing path and then in MoE grouped matmul.
