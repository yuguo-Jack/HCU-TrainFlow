# [PD] Reclaim parked optimistic prefills when request slots are exhausted

[Upstream PR](https://github.com/sgl-project/sglang/pull/43442) · state: closed · merged: True

## Original PR description

## Motivation

With early decode allocation, completed optimistic prefills can occupy every request slot while waiting for bootstrap. If decode admits different requests, those requests cannot start prefill, leaving both sides waiting.

## Modifications

Keep completed prefills parked normally. Reclaim a parked request when the request pool is full and queued work needs admission, including bootstrap requests blocked by metadata exhaustion. Release metadata when an exhausted optimistic attempt returns to bootstrap. Preserve parking for `prefill_complete` allocation.

The reclaim regression uses a CPU request pool to check parking without contention and reclaiming only one slot under pressure. The existing retry test checks metadata cleanup on bootstrap fallback.
