# [Fix] disaggregation: Match the whole bootstrap address when evicting a dead prefill's connections

[Upstream PR](https://github.com/sgl-project/sglang/pull/47704) · state: closed · merged: True

## Original PR description

## Motivation

`CommonKVManager._handle_node_failure` drops connection-pool entries with `k.startswith(failed_bootstrap_addr)`. Keys are `{bootstrap_addr}_{dp}_{cp}_{tp}`, so when prefill `host:3000` misses its heartbeats, the entries for `host:30001`, `host:30002`, ... are evicted too, and decodes re-bootstrap against prefills that are healthy.

## Modifications

Match `f"{failed_bootstrap_addr}_"` instead. The existing node-failure unit test gains a sibling-port entry that must survive the eviction.
