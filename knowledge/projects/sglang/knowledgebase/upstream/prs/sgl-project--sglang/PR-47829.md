# [Fix] test: Stub _confidence_budget_prepare in the scheduler running-reqs test

[Upstream PR](https://github.com/sgl-project/sglang/pull/47829) · state: closed · merged: True

## Original PR description

## Motivation

`test/registered/unit/managers/test_scheduler_running_reqs.py` fails on `main`, which turns `base-a-test-cpu` red on every PR:

```
AttributeError: 'Scheduler' object has no attribute '_confidence_budget_prepare'
```

#44405 added `Scheduler._confidence_budget_prepare`, set in `__init__` and read on every `run_batch`. #47716 added `test_ngram_grammar_step_launches_no_finished_row`, which builds a `Scheduler` with `__new__`, sets its attributes by hand, and never set this one. Each PR passed alone; together they break.

## Modifications

Set `s._confidence_budget_prepare = None` in the test's stub, next to the other scheduler fields it sets.
