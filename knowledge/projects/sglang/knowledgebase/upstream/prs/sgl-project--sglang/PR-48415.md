# [Feat] model: Add basic Kimi-K3.1 support (NV, AMD)

[Upstream PR](https://github.com/sgl-project/sglang/pull/48415) · state: open · merged: False

## Original PR description

Adds Kimi-K3.1 (`KimiK31ForConditionalGeneration`): Kimi-K3 with DeepSeek-style sparse attention (DSA) in its full-attention layers, an fp8_ds_mla KV cache whose tile scales are rounded up to powers of two as the reference writer does, and `flashmla_kv` on CUDA or the Triton sparse MLA backend on ROCm.

No behavior change for other models; the exact packed top-k kernel now also builds on CUDA, where only this model selects it.

Performance and further features (DCP, PD, speculative decoding) follow in #48414.

Model: https://huggingface.co/moonshotai/Kimi-K3.1-Pro
