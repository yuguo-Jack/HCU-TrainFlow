## Motivation

The decode metadata kernel reached into pool objects to choose static SWA mappings and duplicated the fused kernel body. Make the boundary explicit: runtime resolves a mapping tensor, and the kernel consumes tensors and strides.

## Modifications

The launch-size comment states the current 256/128-column policy.

- Pass `full_to_swa_index_mapping` explicitly from FlashAttention/XPU runtime callers.
- Share one fused kernel body while retaining the existing launch sizes, lengths-only mode, and live-prefix write contract.
- Write through the caller's original strided output storage; add static FULL/SWA, prefix/tail, and strided-buffer coverage.
