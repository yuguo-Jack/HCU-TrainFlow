# [Benchmark] Add rerank benchmark script

[Upstream PR](https://github.com/sgl-project/sglang/pull/47854) · state: open · merged: False

## Original PR description

This PR adds a standalone, closed-loop benchmark client for the cross-encoder /v1/rerank API. Unlike generation benchmarks, it sends query–document pairs and validates relevance scores rather than requesting generated tokens.

### Key features:

Configurable concurrency, request count, warmup count, query length, total pair length, and documents per request.
Uses SGLang’s tokenizer-loading utility to match server-side tokenization. Pair length includes the query, document, and special tokens.
Validates response counts, document indices, finite scores, and server-reported input token counts.
Reports successful requests/s, query–document pairs/s, input tokens/s, and mean/P50/P90/P95/P99 end-to-end latency.
Excludes input preparation and warmup from measurement, supports JSON result export, and returns a nonzero exit code on request failures.
The benchmark uses repeated synthetic text and measures serving performance, not ranking accuracy. Server-side prefix caching should be disabled. With multiple documents per request, pairs/s provides a more meaningful throughput metric than requests/s.

### Usage Examples
Start a CPU server for a reranker model:
`
sglang serve --model-path /path/to/reranker-model --is-embedding --disable-radix-cache --host 127.0.0.1 --port 30000
`
Single-document benchmark
`
python benchmark/prefill_only/bench_rerank.py --model /path/to/reranker-model --base-url http://127.0.0.1:30000 --input-len 256 --query-len 32 --documents 1 --concurrency 24 --num-requests 20000 --output-file rerank-c24.json
`
