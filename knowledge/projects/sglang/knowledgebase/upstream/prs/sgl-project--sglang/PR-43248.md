# [AMD][DI][CI] mi355x spur: choose RDMA devices per node, by rail

[Upstream PR](https://github.com/sgl-project/sglang/pull/43248) · state: open · merged: False

## Original PR description

## What
On pit2, choose each node's RDMA devices separately, by rail instead of by name.

A port that was down at boot is named `rocepNNsM` on that node and `rdmaN` on the others. #41405 needs the same names on every node, so a port that has since come back up is still skipped.

`drive.sh` now reads each node's ports, matches them by rail (the number at the end of the interface name, `tw-eth3` is rail 3), and writes one list per node. Each server reads its node's list when it starts. The device count stays what the recipe asks for. The slurm path is unchanged.

## Validation
- Device choice checked on the live nodes and on the 2026-10-04 failure state.
- Generated scripts for the slurm path are byte-identical to main.
- `ib_write_bw` over `rocep*` names: 352-373 Gb/s.
- Pending: a full run with a `rocep*` device inside the container (g02 + g11).
