[Upstream PR](https://github.com/sgl-project/sglang/pull/42876) · state: open · merged: False

## Original PR description

Part 09 of 21 of the LoRA runtime stack (branch `lora-stack-08-inkling-sink`, base `lora-stack-07-mla-correction`). The stack is cut from the development branch of #42284.

## What this part adds

Add InklingBatchDenseMLPWithLoRAV2, which runs the shared sink on the pool
buffers through the dense runner, and keep the legacy wrapper for the other
backends. LoRAManager picks the class by backend.

Tests: sink numerics, linearized-LoRA units, routed/sink overlap gate.
