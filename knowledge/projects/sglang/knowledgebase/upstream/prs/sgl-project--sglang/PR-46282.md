## Motivation

Ascend MoE currently lacks a unified communication backend for expert-parallel prefill and decode. The existing routing paths make it difficult to support different communication domains, quantized dispatch formats, and model-specific expert layouts consistently.

This PR introduces the `ascend_ops` backend for Ascend NPU MoE execution. It provides TP-group AllGather and AllToAllV paths for prefill, EP-group MC2 dispatch/combine for decode, and shared routing interfaces for expert
permutation and unpermutation. The backend also adds explicit configuration and validation for supported layouts and dispatch quantization modes.

This enables a consistent Ascend MoE execution model across prefill, decode, expert-parallel, and no-A2A paths while reducing duplicated routing logic and making future Ascend operator interface changes easier to maintain.
