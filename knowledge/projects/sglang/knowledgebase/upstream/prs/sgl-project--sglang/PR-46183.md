# [Perf] dsv41: Pass bf16 head weights to the full-scan paged MQA logits

[Upstream PR](https://github.com/sgl-project/sglang/pull/46183) · state: closed · merged: False

## Original PR description

The full-scan paged MQA logits get the indexer head weights in fp32, so DeepGEMM runs its fp32 reduce; the sparse-set and prefill-table scorers in the same file already pass them as bf16. Cast them to bf16 at the two full-scan calls as well.

Decode step on GB300 at fixed batch: numbers to follow.

Closing: this is a no-op. `deep_gemm_fp4_paged_mqa_logits` already casts the head weights with `weights.to(index_weights_dtype())` and requests `index_logits_dtype()` logits, which since #45880 resolve to bf16 on SM100 (GB300 included), so the full-scan calls already run DeepGEMM's bf16 path. A fixed-batch A/B on GB300 (DP attention 4, EP 4) measured 0.02 to 0.4% between the arms, within noise.
