# [Fix] HiCache: Include indexer pools in hybrid host memory budgets

[Upstream PR](https://github.com/sgl-project/sglang/pull/44462) · state: open · merged: False

## Original PR description

## Motivation

Two hybrid HiCache paths leave indexer host buffers outside their memory budget:

- Auto-sizing unwraps `QSATokenToKVPool` as a `HybridLinearKVPool`, counting full KV but omitting the compressed index keys that `QSAIndexerPoolHost` also mirrors. The resolved ratio can therefore exceed the available host budget.
- For hybrid Mamba + DSA with an explicit `--hicache-size`, the KV/Mamba split already includes DSA index bytes. The assembler gives that entire KV-group share to the MLA host pool, then allocates the declared indexer beside it. A 100 GB regression case produces about 110.31 GB before this fix.

## Modifications

- Count QSA compressed keys for target and draft host mirrors. Exclude the request-local key/RoPE state, which has no host mirror.
- Reserve declared indexer bytes within the MLA group's explicit budget before choosing its token capacity. Account for skipped index layers, layer sharding, packed draft layers, and index page geometry.
- Keep the existing allocation page rounding and ratio-mode behavior.
