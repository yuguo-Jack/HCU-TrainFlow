# [Feat] anthropic: forward inline MP4 user content to Chat

[Upstream PR](https://github.com/sgl-project/sglang/pull/46119) · state: open · merged: False

## Original PR description

## Motivation

Forward inline MP4 blocks from Messages user content into the existing Chat `video_url` path. Preserve their position around text and tool results for both streaming and non-streaming requests.

This is a SGLang extension, not an Anthropic API type. Accept only base64 MP4 in top-level user content; reject unsupported sources/locations and video token counting, whose text-only result would undercount. The served model still needs a video-capable processor. K3's model-side video support remains in #35325; this adapter does not duplicate or provide that foundation.

## Test Plan

The new conversion regression fails on the base protocol and passes with the fix. Focused existing Messages tests also pass, covering both response modes, ordering, source validation, forbidden locations, token-count rejection and tool-result/reference compatibility. These are actual protocol/adapter tests with synthetic encoded payloads; MP4 decoding and full video-model generation are not exercised. Focused lint/formatting pass.

Prepared with Codex assistance.
