# [Feat] attention: Add the MSA-v1 sparse backend and NVFP4 KV pool

[Upstream PR](https://github.com/sgl-project/sglang/pull/46141) · state: closed · merged: True

## Original PR description

## Summary
The MSA-v1 sparse attention backend on the NVFP4 KV pool for MiniMax-M3.1: main KV and index K stored as NVFP4 page rows, Q8KV4 decode indexer with an FP8 fallback, MSA-v1 prefill, and pool sizing. It also adds an FP8 Q epilogue to the grouped QK-norm/RoPE kernel.

## Changes to existing code
- The attention registry selects this backend for the `minimax_m3_nvfp4` KV stack.
- The KV cache and pool configurators build the NVFP4 pool and size it by its per-token bytes for `minimax_m3_nvfp4`.
- `allocate_attention_outputs` sizes the sparse output by the V dtype (bf16 when V is FP8) instead of the Q dtype, so an FP8 Q from the QK-norm epilogue does not make the output FP8. Only MiniMax-M3 reaches the sparse branch.
- New `PageRowBufferInfo` in the device pool info union.
