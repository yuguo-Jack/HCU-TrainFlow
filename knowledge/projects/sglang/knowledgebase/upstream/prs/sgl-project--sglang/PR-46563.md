# [Feat] sglang-processor: GLM-5.3-Flash image preprocessing

[Upstream PR](https://github.com/sgl-project/sglang/pull/46563) · state: open · merged: False

## Original PR description

Stacked on #46562. Co-authored with @ScarletGuo. Rebased with the stack onto `main` `911693e3f8`, which includes #45449. The two GLM commits applied unchanged.

Add GLM-5.3-Flash image preprocessing. Dynamo's `glm5_next` family plans tokens but does not process pixels. (A followup upstream PR is feasible).

## Modifications

- **`mm/models/glm5_next.rs`.** Ports SGLang's `Glm4vImageProcessor` and transformers' `Glm5NextImageProcessor` onto Dynamo's planner:
  - resize to the content size (no upscale above the token minimum), zero-pad to the canvas;
  - normalize and patchify in Qwen-VL's order;
  - glm4v image-only M-RoPE.

  Images decode as SGLang's `smart_to_rgb` does: EXIF transpose, then alpha (PNG, WebP, GIF, and BMP with an alpha bitmask) composited onto an edge-contrasting background with PIL's `paste` rounding.
- **`MmPipelineSpec`.** Dynamo's `ProcessorSpec`, or a family spec carrying the knobs Dynamo's spec lacks: GLM's mean, std and resample. Decoding is chosen per family when the processor is built.
- **`RUST_MM_FAMILIES`.** Adds `glm5_next` through `Glm4vImageProcessor`, honoring `min_image_tokens` / `max_image_tokens` overrides.
- **`generate_mm_parity.py`.** Picks the processor class through SGLang's registry, and takes each family's image delimiters and overrides from a small table.

## Tests

- New fixture `mm_parity/glm-5.3-flash.json` (26 cases): every corpus format, the PIL backend, two images, and token overrides. All are bit-exact with Python's CPU path under Pillow 12.3, except the existing 16-bit `known_gap`. Disabling alpha compositing fails 7 of them.
- The corpus gains `rgba_bitfields_56x56.bmp`, a BITMAPV4 BMP with an alpha bitmask. Pillow opens it as RGBA, so `smart_to_rgb` composites it. Pillow can't write one (it saves RGBA as BI_RGB, which reads back as RGB), so the generator writes the header by hand.
- The Qwen fixtures' existing cases regenerate byte-identical. The Qwen2.5-VL format sweep gains this PR's three new corpus images.
- `test_rust_mm_gate` gains the GLM entry.
- At this head (`96a7f52353`): `cargo test -p sglang-processor --all-features`, including the GLM fixture, and `cargo test -p sglang-server` (388) pass. The Python `test/registered/unit/multimodal/rust/` tests pass, and clippy `-D warnings`, rustfmt and pre-commit are clean.
- Not run yet: an end-to-end GLM-5.3-Flash run (bit-exact `/generate`, MMMU / MMMU-Pro).
