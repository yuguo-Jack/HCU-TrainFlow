## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. This PR:

1. **Adds the section to the new Muse Spark Open page** (#44527), right after the Playground as on the other pages. It covers the four Muse Spark Open SGLang AgentX lanes that SemiAnalysis is adding for B200, B300, GB200 and GB300.
2. **Refreshes DeepSeek-V4.1-Flash** to three open InferenceX PRs that retune its B200, B300 and GB200 SGLang curves.
3. **Syncs to InferenceX `main`** (`c08eb51d`), which has merged [InferenceX #2978](https://github.com/SemiAnalysisAI/InferenceX/pull/2978) (a new Qwen3.5 lane), [InferenceX #3953](https://github.com/SemiAnalysisAI/InferenceX/pull/3953), and the first two Muse Spark Open lanes ([InferenceX #4147](https://github.com/SemiAnalysisAI/InferenceX/pull/4147), [InferenceX #4140](https://github.com/SemiAnalysisAI/InferenceX/pull/4140)).

## How the commands are produced

The pipeline and rules are the same as in #44228, with these changes:

- **DFlash.** Deployment chips label DFlash as "DFlash N", where N is `--speculative-num-draft-tokens`.
- **Synthetic acceptance at the pinned commit.** InferenceX forces a golden acceptance length on speculative-decoding workers (`SGLANG_SIMULATE_ACC_LEN`). The pipeline removes it from the commands and discloses it per deployment.
  - The value is now computed with InferenceX's own code and curves at each lane's pinned commit, for lanes that use InferenceX's composed recipes. Before, it came from an older local InferenceX checkout, which did not know DFlash.
  - Muse Spark Open gets 4.05. That matches `SGLANG_SIMULATE_ACC_LEN=4.05` in the B200 c1 worker of [run 38825822770](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/38825822770), a sweep on the #4147 head.
  - Every other lane's value is unchanged.
- **Rules.** Kept as serving configuration: worker flags `--dsv4-attn-backend`, `--tokenizer-backend`, `--enable-layernorm-sp`, `--enable-megamoe-for-layernorm-sp`, `--mm-feature-transport`, `--speculative-draft-model-path` (a Hugging Face id in the measured run) and `--speculative-draft-attention-backend`, and env `SGLANG_DP_USE_GATHERV`.

Each lane is still rendered at the exact commit of the run that produced its dashboard data, or at the PR head while in progress. SA-only settings are removed: the benchmark harness, cluster paths and caches, telemetry, and the synthetic acceptance above. Placeholders replace IPs, ports and NICs. Router and KV-offload variants that were not run are derived and labeled "Derived — not run". `NCCL_CUMEM_ENABLE=1` from the SemiAnalysis cluster environment (#44228) also applies to the new lanes: their B200, B300, GB200 and GB300 clusters export it, and the B200 c1 worker fingerprint of run 38825822770 shows it.

The data files are generated. The hand-written change is the Muse Spark Open page section.
