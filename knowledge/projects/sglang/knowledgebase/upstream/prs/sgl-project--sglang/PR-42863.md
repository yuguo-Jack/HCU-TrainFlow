# [Perf] [SM120] all-gather: Speed up TP4 logits and DSpark vocab all-gathers on PCIe-only hosts

[Upstream PR](https://github.com/sgl-project/sglang/pull/42863) · state: open · merged: False

## Original PR description

## Motivation

On hosts without NVLink, `make_vocab_gather` and `MultimemAllGatherer` fall back to NCCL because there is no multicast. Decode-sized gathers are latency-bound on that path. Per decode step, the logits processor gathers the target's vocab-sharded logits, and on the sharded sampling path the DSpark Markov head gathers one FP32 `[bs, vocab/tp]` row block per draft position. (Sharded greedy gathers compact candidate pairs.) On 4x RTX PRO 6000 Blackwell (PCIe) at TP4, one NCCL gather of `[1, 32320]` takes 38 us in BF16 and 53 us in FP32 (tables below).

#34528 added FlashInfer's PCIe-IPC all-reduce for these hosts. FlashInfer also provides a PCIe-IPC all-gather (`PcieIpcAllGatherWorkspace`, flashinfer-ai/flashinfer#5023). It copies opaque 16-byte packs, so its output is bit-identical to NCCL's.

Requires the PCIe-IPC all-gather API, available since FlashInfer 0.7.1rc1. The version SGLang pins in `python/pyproject.toml`, 0.7.0.post1, has the PCIe-IPC all-reduce but not the all-gather, so with that version the gathers stay on NCCL. There is no version check. Before the build, each rank imports the API it uses (`PcieIpcAllGatherWorkspace`, `PcieIpcAllGatherLaunchConfig`, `PcieIpcAllGatherVariant`); if that fails, it logs a warning, reports itself not ready to the other ranks, and every rank keeps NCCL. The multi-GPU test skips on such a FlashInfer, so in SGLang's CI it skips until the FlashInfer pin includes the all-gather API (0.7.1rc1 or later).

## Modifications

- `vocab_gather.py`: add `PcieIpcVocabGather` behind the existing `VocabGather` interface. It covers both the side-by-side (`__call__`) and rank-major (`gather_stacked`) layouts. Slices the workspace cannot take go to the NCCL fallback: more rows than it was sized for (`max_rows`, checked by the adapter because FlashInfer bounds only the element count), more than `max_rows * width` elements, or another dtype. Non-contiguous or misaligned inputs are copied rather than sent to NCCL, so the path depends only on dtype and shape, which every rank shares. The workspace is rebound when the caller's stream changes, as the PCIe-IPC all-reduce adapter does.
- `make_pcie_ipc_gather` builds it only when the PCIe-IPC all-reduce is configured for the group (`SGLANG_ENABLE_PCIE_IPC_ALLREDUCE`, off by default) and enabled on every rank, the group is TP4, and its ranks share one host.
- Collective safety: whether a group takes part is decided only from settings every rank shares, so either every rank enters the agreements below or none does. These are the new `GroupCoordinator.pcie_ipc_eligible` (the existing `eligible_group` result, recorded because a rank-local setup failure leaves `pcie_ipc_comm` as None on that rank only), the world size and the row capacity. FlashInfer allocates and maps the IPC buffer without coordinating a failure on one rank, which would leave the others waiting. So before the build, the ranks agree over the group's CPU group (one-int `all_reduce(SUM)`) that the group is on one host (`in_the_same_node_as`, as the custom all-reduce checks it; FlashInfer's TP4 all-gather does not reject a group spanning hosts, and its failed IPC handle exchange there leaves the buffers allocated) and that each rank has its PCIe-IPC communicator set up and enabled, the all-gather API, and enough free GPU memory. Any exception in that local check counts as not ready, and if any rank is not ready, no rank starts the build. After the build, they count the ranks that built a workspace, which is the last thing the adapter constructs. If all did, the gather is used. If none did, every rank keeps NCCL; FlashInfer validates and binds the workspace jointly, so its own construction errors are raised on every rank. If only some did, every rank raises and startup fails: releasing a FlashInfer workspace is collective over the whole group (a group barrier before the IPC buffers are freed), so the ranks that built one cannot release it alone, and serving on would leave its IPC buffers mapped. A failure inside FlashInfer's buffer exchange itself (for example `cudaIpcOpenMemHandle` on one rank) can still hang; that is inside FlashInfer, and I plan to report it there separately.
- The workspace is handed to the group's `PcieIpcCommunicator`, which releases it in `GroupCoordinator.destroy` before the process groups (new `adopt()`).
- Opt-in per call site: `make_vocab_gather(prefer_pcie_ipc=...)`, default off, set by the DSpark Markov head for DeepSeek-V4.1, and `MultimemAllGatherer(pcie_ipc=...)`, default off, set by the logits processor (all models). Servers without `SGLANG_ENABLE_PCIE_IPC_ALLREDUCE`, or not at TP4, are unchanged. Order in `make_vocab_gather`: NVLink multicast, then PCIe-IPC, then NCCL.
- `MultimemAllGatherer` with `pcie_ipc=True` still tries multimem first on its first eager call, never under capture; when multimem is unavailable (no multicast), it calls `make_pcie_ipc_gather`. The workspace is sized for decode (`recommended_max_tokens(include_prefill=False)`), as the PCIe-IPC all-reduce is, and larger inputs stay on NCCL.
- Launch config: one fixed config, 24 blocks x 512 threads, recursive doubling, for every shape. FlashInfer's default runs its seed policy for any shape it has not tuned exactly. On this host the seed policy was 1.5-1.9x slower than NCCL at 16-96 BF16 rows (table below); decode row counts vary. At the three BF16 shapes tuned exactly (1, 2, 4 rows), the fixed config is within 0.4 us of the tuned one, and for FP32 the tuner picked it at 4 and 16 rows. It is the same on every rank and needs no tuning collectives. It was measured only at TP4, so TP2/TP8 stay on NCCL.
- Docs: the `SGLANG_ENABLE_PCIE_IPC_ALLREDUCE` entry mentions the gathers.

Workspace memory per gather is about `2 * world_size * max_rows * width * itemsize` per rank. For example, logits BF16 `[128, 32320]` at TP4 is 66 MB. With both gathers enabled on DeepSeek-V4.1-Flash at TP4, the KV cache pool was 3.6% smaller (2,219,008 vs 2,301,952 tokens).

## Accuracy Tests

The change is a copy and is bit-identical to NCCL `all_gather_into_tensor`. I checked the FlashInfer primitive on the target hardware for every microbenchmark shape below (`torch.equal` against NCCL; BF16 with the fixed config, FP32 with the tuned configs). The wrapper benchmark below also checked every one of its shapes bitwise (`torch.equal`) against SGLang's NCCL gather before timing.

New tests. With this branch head, the multi-GPU test passed on 4x RTX PRO 6000 with `torchrun --nproc-per-node 4 -m pytest` (27 passed on each rank). I did not run it at world size 2. The CPU test `test/registered/unit/distributed/test_pcie_ipc_gather_selection.py` passed without a GPU (30 passed).
- `test/registered/kernels/ops/communication/test_pcie_ipc_vocab_gather.py` (multi-GPU, world sizes 2 and 4). It needs a FlashInfer with the PCIe-IPC all-gather and skips otherwise, so it skips in SGLang's CI with the current pin (0.7.0.post1). It compares bitwise against NCCL in both layouts for FP32/BF16, 1-16 rows, with NaN/inf/-0.0 in the inputs. It also checks CUDA-graph capture on a side stream, replay with new inputs, and eager calls between replays, the copy path for strided and misaligned inputs, and the NCCL fallback for wrong-dtype slices and for slices past the row bound, including a narrow one that fits by element count.
- `test/registered/unit/distributed/test_pcie_ipc_gather_selection.py` (CPU). It replaces the FlashInfer workspace with a fake, so it covers selection, the cross-rank agreements and the output layout, not the kernel. It covers selection and fallback: opt-in only, TP4 only, PCIe-IPC all-reduce on/off/disabled or missing on this rank, NVLink first, a group spanning hosts, too little free memory, a missing all-gather API symbol or an exception in the local check, a workspace failure falling back to NCCL, and release order on destroy. Six cases run four real gloo ranks. When one rank lacks memory, lacks its communicator, or raises in its local check, or when ranks 2 and 3 are on another host, every rank ends on NCCL and no rank starts the build. When the build fails on every rank, every rank ends on NCCL. When it fails on one rank, every rank raises and no workspace is destroyed. It also checks the output layout, the single launch config, the row bound for a narrow slice that fits by element count, the copy of strided and misaligned inputs, stream rebinding only on stream change, and that `MultimemAllGatherer` switches only when opted in on a PCIe-IPC group (other users keep multimem/NCCL, and a group without PCIe-IPC makes no agreement), defers under capture, and sizes the workspace for decode.

```python
"""TP4 vocab all-gather through SGLang's wrappers: PCIe-IPC (fixed launch config)
vs the NCCL path it replaces, BF16 and FP32 [rows, 32320], side-by-side layout.

  torchrun --nproc-per-node 4 pcie_gather_wrapper_bench.py [--max-rows 128]

Both sides go through the code the server runs. The PCIe-IPC side is built by
make_pcie_ipc_gather (both cross-rank agreements, the fixed 24x512 recursive-
doubling config) and timed through PcieIpcVocabGather.__call__, including the
rank-major to side-by-side copy. The NCCL side is NcclVocabGather.__call__, i.e.
GroupCoordinator.all_gather(dim=-1) on a "tp" group, captured inside
group.graph_capture() so pynccl serves it as it does in decode graphs.
Each case: 50 calls captured in one CUDA graph, 20 replays, us per call on
rank 0; the median of --trials such measurements is printed. Every case is
checked bitwise against NCCL before timing. Prints a markdown table on rank 0.
"""

import argparse
import logging
import os
import statistics

# Before any SGLang import: the "tp" group must get its PCIe-IPC communicator.
os.environ["SGLANG_ENABLE_PCIE_IPC_ALLREDUCE"] = "1"

import torch
import torch.distributed as dist

import sglang.srt.distributed.parallel_state as ps
from sglang.srt.distributed.device_communicators import vocab_gather
from sglang.srt.distributed.device_communicators.vocab_gather import (
    NcclVocabGather,
    PcieIpcVocabGather,
    make_pcie_ipc_gather,
)
from sglang.srt.runtime_context import get_parallel

WIDTH = 32320  # DeepSeek-V4 vocab shard per rank at TP4
CASES = {
    torch.bfloat16: (1, 2, 4, 6, 16, 24, 48, 96),  # logits gather
    torch.float32: (1, 2, 4, 8, 16),  # DSpark vocab gather
}


def setup():
    local_rank = int(os.environ["LOCAL_RANK"])
    world_size = int(os.environ["WORLD_SIZE"])
    assert world_size == 4, "the PCIe-IPC gather is taken at TP4 only"
    torch.cuda.set_device(local_rank)
    dist.init_process_group(backend="gloo")
    ranks = list(range(world_size))
    ps._WORLD = ps.init_world_group(ranks=ranks, local_rank=local_rank, backend="nccl")
    get_parallel().override_permanently(world_group=ps._WORLD)
    group = ps.init_model_parallel_group(
        group_ranks=[ranks],
        local_rank=local_rank,
        backend="nccl",
        use_custom_allreduce=False,
        group_name="tp",
    )
    assert group.pcie_ipc_eligible and group.pcie_ipc_comm is not None
    return group


def time_call(group, fn, x, calls, reps):
    stream = torch.cuda.Stream()
    with group.graph_capture(stream=stream):
        for _ in range(3):
            fn(x)  # warm up on the capture stream
        graph = torch.cuda.CUDAGraph()
        with torch.cuda.graph(graph, stream=stream):
            for _ in range(calls):
                fn(x)
    torch.cuda.current_stream().wait_stream(stream)
    dist.barrier()
    graph.replay()
    torch.cuda.synchronize()
    dist.barrier()
    start, end = torch.cuda.Event(True), torch.cuda.Event(True)
    start.record()
    for _ in range(reps):
        graph.replay()
    end.record()
    torch.cuda.synchronize()
    dist.barrier()
    return start.elapsed_time(end) * 1e3 / (calls * reps)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--max-rows", type=int, default=128)
    parser.add_argument("--calls", type=int, default=50)
    parser.add_argument("--reps", type=int, default=20)
    parser.add_argument("--trials", type=int, default=3)
    args = parser.parse_args()

    logging.disable(logging.INFO)
    group = setup()
    rank = dist.get_rank()
    if rank == 0:
        print(f"sglang vocab_gather: {vocab_gather.__file__}", flush=True)
        print(f"torch {torch.__version__}, {torch.cuda.get_device_name()}", flush=True)
    nccl = NcclVocabGather(group)
    lines = [
        "| dtype | rows | SGLang PCIe-IPC, fixed config (us) | SGLang NCCL (us) | NCCL / PCIe-IPC |",
        "|---|---|---|---|---|",
    ]
    for dtype, row_counts in CASES.items():
        gather = make_pcie_ipc_gather(
            group,
            local_width=WIDTH,
            dtype=dtype,
            max_rows=args.max_rows,
            fallback=nccl,
        )
        assert isinstance(gather, PcieIpcVocabGather), "PCIe-IPC gather not built"
        for rows in row_counts:
            assert rows <= args.max_rows
            x = (torch.randn(rows, WIDTH, device="cuda") * (rank + 1)).to(dtype)
            same = torch.equal(
                gather(x).view(torch.uint8), nccl(x).contiguous().view(torch.uint8)
            )
            flags = torch.tensor([int(same)], dtype=torch.int32)
            dist.all_reduce(flags, op=dist.ReduceOp.MIN)
            assert flags.item() == 1, f"{dtype} rows={rows}: not bit-identical"
            pcie, ref = [], []
            for _ in range(args.trials):
                pcie.append(time_call(group, gather, x, args.calls, args.reps))
                ref.append(time_call(group, nccl, x, args.calls, args.reps))
            p, n = statistics.median(pcie), statistics.median(ref)
            name = str(dtype).removeprefix("torch.")
            lines.append(f"| {name} | {rows} | {p:.1f} | {n:.1f} | {n / p:.2f}x |")
            if rank == 0:
                print(lines[-1], flush=True)
    if rank == 0:
        print(
            f"\nTP4, [rows, {WIDTH}], side-by-side layout, workspace max_rows="
            f"{args.max_rows}; {args.calls} calls per CUDA graph, {args.reps} "
            f"replays, median of {args.trials} trials, rank 0.\n"
        )
        print("\n".join(lines), flush=True)
    group.destroy()
    ps._WORLD.destroy()
    dist.destroy_process_group()


if __name__ == "__main__":
    main()
```
