# [NPU] Support Qwen3.8-Flash-Next with graph replay, MTP, and Triton kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/37570) · state: open · merged: False

## Original PR description

## Motivation

Enable Qwen3.8-Flash-Next inference on NPU with Qwen Sparse Attention (QSA), graph replay, and NEXTN/MTP speculative decoding, building on the mainline model support from [#37500](https://github.com/sgl-project/sglang/pull/37500).

Dependency: [sgl-project/sgl-kernel-npu#807](https://github.com/sgl-project/sgl-kernel-npu/pull/807) provides the production kernels. Before merging, an installable kernel package containing these modules and the corresponding SGLang dependency must be verified together; local source-tree validation does not establish release-package availability.

## Modifications

- Reuse shared QSA indexer orchestration on NPU, preserving per-query bounds, padding, MTP index reuse, and logical-to-physical KV mapping.
- Integrate six operator groups from `sgl_kernel_npu.qwen3_8_flash_next`: PLE short convolution, packed/paged MQA scoring, Top-K, block expansion, sparse attention, and hyperconnection norm/mix/combine. Wrappers own their model input contracts and internal Triton/native paths; unsupported NPU metadata is not silently redirected to a general reference.
- Adapt rank-4 NPU KV pools through zero-copy views, so incompatible layouts fail rather than silently copying cache storage.
- Keep NPU dispatch beside GPU entrypoints and preserve other platforms' behavior. Support sigmoid-gated normalization and retain the NPU hyperconnection compilation workaround for cached restarts.
- Use graph-capturable PLE convolution for decode/target verify, preserving state updates, tracking, MTP, and ordinary prefill. Guard the newly merged CUDA verify-fusion path on NPU.
- Maintain live graph metadata and draft-extend bounds; bypass CPU attention-input updates for Qwen QSA paths that consume device metadata. Avoid the CPU-fallback assertion in NPU QSA write planning.
- Add and update regression tests for dispatch, indexing, cache layout, normalization, PLE, operator chains, and graph replay. Adapt tests to upstream runtime-context and graph-worker changes, including direct execution through registered CI entrypoints.

RUN_TIME="$(date +%Y%m%d_%H%M%S)"

    --max-running-requests 8 \

    --mm-attention-backend ascend_attn \
    --dtype bfloat16 \
    --mamba-ssm-dtype bfloat16 \
    --mm-enable-dp-encoder \
    --reasoning-parser qwen3 \
    --tool-call-parser qwen3_coder \
    --speculative-algorithm NEXTN \
    --speculative-num-steps 3 \
    --speculative-eagle-topk 1 \
