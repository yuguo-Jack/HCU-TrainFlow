## Original PR description

## Motivation

Re-enable the Inkling unified cache linker KL test now that #44220 has merged and full prefill graphs wait for layer-wise loads. The direct linker also needs RDMA access: the initial single-GPU H100 run aborted while starting Mooncake, and the selected runner container had no `/dev/infiniband` devices.

## Modifications

Remove the temporary `disabled` marker and use `4-gpu-h100`, matching the DSV4 linker test's runner configuration. Inkling remains TP=1. Add a comment explaining why this single-GPU test requires the larger runner pool.

The DSV4 linker has passed on this pool: https://github.com/sgl-project/sglang/actions/runs/38514536851. RDMA device visibility was also verified on `h100-novita5-gpu-0123`, which previously passed the DSV4 linker test.
