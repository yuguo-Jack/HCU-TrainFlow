## Original PR description

## Motivation

`docs/docs/references/environment_variables.mdx` documents two variables that `python/sglang/srt/environ.py` no longer defines:

- `SGLANG_SWA_EVICTION_INTERVAL_MULTIPLIER` was replaced by `SGLANG_SWA_EVICTION_INTERVAL` in #28755, so setting the documented variable has no effect.
- `SGLANG_GRANIAN_PARENT_PID` was removed in #28573.

## Modifications

- Replace the `SGLANG_SWA_EVICTION_INTERVAL_MULTIPLIER` row with `SGLANG_SWA_EVICTION_INTERVAL`: decode batches between sliding-window-attention out-of-window evictions, default `128` (matches `environ.py`).
- Remove the `SGLANG_GRANIAN_PARENT_PID` row.
