# feat(bench): add --gsp-input-ids to skip server tokenization

[Upstream PR](https://github.com/sgl-project/sglang/pull/40900) · state: open · merged: False

## Original PR description

## Summary

- add `--gsp-input-ids` for the generated-shared-prefix dataset
- send raw random token IDs directly so the server skips tokenization before prefill
- keep input-ID cache entries separate from text-mode cache entries

This ports the change from HYGON-AI/sglang-das#315.

## Benchmarking note

When measuring the speedup, 用 `/generate` 或 `/v1/completions` 发；不要用 chat 接口，否则 chat template 等额外开销会让结果看起来“没快多少”。
