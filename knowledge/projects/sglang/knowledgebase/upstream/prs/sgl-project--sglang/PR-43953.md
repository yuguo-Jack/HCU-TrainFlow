# [Fix] [AMD] dit: Apply model-default prefetch to explicit layerwise offload

[Upstream PR](https://github.com/sgl-project/sglang/pull/43953) · state: open · merged: False

## Original PR description

## Motivation

**What goes wrong**
On gfx1250, Wan 2.2 A14B with --dit-layerwise-offload waits on each DiT layer's copy from host memory, and that copy cannot overlap compute. Prefetch stays at 0. An explicit layerwise request returns before the model prefetch size is applied. Wan 2.2 already publishes a prefetch size of 2 on the automatic path, and that value never reaches an explicit request.

**Where it shows up**
The early return is shared placement logic, so any device that requests layerwise offload explicitly can hit it. gfx1250, and any machine where both DiTs still fit, keeps the weights resident. This prefetch default is never consulted, so there is no missing overlap. It shows up on the low-memory Wan 2.2 A14B path, including the gfx1250 multi-GPU run: visible memory is not enough for both DiTs, so --dit-layerwise-offload is required, and the explicit path leaves prefetch at 0 while performance_mode=auto and --dit-offload-prefetch-size is unset.

**How to fix**
Apply the model prefetch size before that return, so an explicit layerwise request uses it unless the user set one.

## Modifications

- When `dit_layerwise_offload` is true or `is_dit_layerwise_offload_selected` is true, `_default_layerwise_components_for_unset_placement` still calls `_set_default_dit_offload_prefetch_size()` before returning.
- `_set_default_dit_offload_prefetch_size` is unchanged: it applies only in `performance_mode=auto`, only when the model publishes a prefetch size, and only when the user did not set `--dit-offload-prefetch-size`.
- Unit tests check that the model default (2) is applied, and that an explicit prefetch size is left alone.

## Accuracy Tests

N/A - this change does not affect model outputs. It only changes how many layers are prefetched during layerwise offload.

## Benchmarking and Profiling

No before/after latency number for this prefetch change is included. With prefetch left at 0 the runtime streams one layer at a time. After this change, an explicit layerwise request in auto mode uses the model default (2 for Wan 2.2).
