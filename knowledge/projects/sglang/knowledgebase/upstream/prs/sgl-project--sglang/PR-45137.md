# [Feat] [diffusion] [NPU] Add support for HiDream-O1-Image (Dev-2604, Dev, Full)

## Motivation

HiDream-O1-Image is a unified VLM diffusion model. SGLang had no support for it. This PR adds the model with its three official checkpoints (Dev-2604, Dev, Full).

<!-- Describe the purpose and goals of this pull request. -->

## Modifications

- `ascend_backend.py`: align the forward_decode_graph sinks/SWA branch with the eager decode path — hybrid-SWA models without attention sinks crashed under graph mode when a sink-less SWA layer reached `attention_sinks_triton(..., sinks=None, ...)`.
```
- if sinks is not None or self.is_hybrid_swa:
+ if sinks is not None or (self._is_swa_layer(layer) and self.use_fia):
```

- **Model implementation (`runtime/models/dits/hidream.py`):** Implemented the vision encoder with DeepStack, a tensor-parallel (TP) 36-layer text decoder, diffusion heads, and TP-sharded weight loading. Added two-pass Flash Attention (causal for autoregressive tokens and bidirectional for image-generation tokens) and interleaved 3D MRoPE.

- **Generation pipeline (`stages/model_specific_stages/hidream/`):** Added T2I and TI2I sample builders with reference-image conditioning and cached vision embeddings. Implemented patch encoding/decoding, layout conditioning, `keep_original_aspect`, and a `tqdm` progress bar for denoising. Added variant-specific schedulers:
  - **DEV:** Flash noise-injecting Euler scheduler, fixed 28-step `DEFAULT_TIMESTEPS`, and `s_noise=8.0`.
  - **FULL:** UniPC scheduler with 50 inference steps and CFG scale of 5.0.

- **Prompt enhancement (`prompt_enhance.py`):** Added a client for the existing `--pe-server-url` service to rewrite prompts using the official prompt enhancer, with JSON fallback handling and prompt caching.

- **Configuration and registration:** Added per-variant recipe defaults resolved from the served model path. Registered T2I and TI2I as supported task types. Added `--num-inference-steps` support to `sglang serve`; for DEV, values other than 28 trigger a warning and are ignored.
