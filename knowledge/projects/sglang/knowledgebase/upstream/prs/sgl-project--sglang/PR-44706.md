[Upstream PR](https://github.com/sgl-project/sglang/pull/44706) · state: closed · merged: True

## Original PR description

## Motivation

The B200 DeepGEMM release test job [exceeded its 60-minute limit](https://github.com/sgl-project/sglang/actions/runs/38864289997/job/116854382412) while still progressing through `test_fp8_fp4.py`, before reaching the MegaMoE and sanitizer tests.
