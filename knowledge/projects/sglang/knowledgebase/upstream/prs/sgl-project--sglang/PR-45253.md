## Motivation

Split #44747 into reviewable parts. This is the Beam CUDA Docker image part, position 1 of 8 in the merge order below. Its branch starts from #44747's merge base with main. No other part depends on it or includes it.

## Modifications

Adds `docker/beam/beam.Dockerfile`, a Beam serving image on top of `lmsysorg/sglang:v0.5.22`, following `docker/muse_spark/muse-spark.Dockerfile`. It clones the upstream `beam` branch (pin a commit with `BEAM_REF`) and installs it without dependencies. It then adds the two pins that branch needs on top of the release: OpenAI 2.8.0 for the Responses shell types and `nvidia-cuda-tileiras` 13.4.92 for the cuTile router GEMM. The Dynamo and `grpcio-tools` pins moved to #45292.

`docker/Dockerfile` is not changed by any part. This image is a stopgap: delete it once Beam runs from the main image.

This part changes **1 file (+31 / -0)** beyond the parts its branch carries.
