# docs: add MiniCPM-V 4.7 cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/43829) · state: closed · merged: True

## Original PR description

## Motivation

Adds the MiniCPM-V 4.7 cookbook page for the model support in #41993.

The `openbmb/MiniCPM-V-4.7-*` checkpoints are public on Hugging Face. This page is ready to merge ahead of #41993: the initial support path is the patch image `lmsysorg/sglang:dev-minicpm-v-4.7` (built from the #41993 head), and the image/install references move to `dev` / main once #41993 lands.

Known issue in the public FP8 and int4 repos: their `tokenizer_config.json` declares `auto_map.AutoProcessor = processing_minicpmv4_7.MiniCPMV4_7Processor`, but the repos do not ship that file, so SGLang cannot load their processor. The FP8 and INT4 cells add `--tokenizer-path openbmb/MiniCPM-V-4.7-35B-A3B` to load the tokenizer and processor from the base repo, which has the same `tokenizer.json` and chat template. This is verified on GB300: `openbmb/MiniCPM-V-4.7-35B-A3B-FP8` with that flag, and without `--trust-remote-code`, serves and passes all five image probes. The flag stays until OpenBMB updates the FP8 and int4 repos to ship the file or drop the `auto_map` entry; the issue has been reported to the model team. The BF16 base repos and both DSpark drafts load without it.

## Modifications

- `docs/cookbook/autoregressive/OpenBMB/MiniCPM-V-4_7.mdx`: new page. Deploy panel and Playground, model introduction, license, and checkpoint table, configuration tips, reasoning and tool-calling examples, and per-request `mm_processor_kwargs` (`downsample_mode`, `max_slice_nums`) with measured prompt-token counts.
- `docs/src/snippets/configs/openbmb/minicpm-v-4.7.jsx` and `-benchmarks.jsx`: single-GPU cells for 1B BF16 and 35B-A3B BF16 / FP8 / INT4 on GB300 and H200 (verified) and H100 (1B / FP8 / INT4, unverified; 35B-A3B BF16 does not fit an 80 GB card at the default memory fraction). Every cell carries `--reasoning-parser auto --tool-call-parser auto` (resolved to `qwen3` / `qwen3_coder` from the chat template); the FP8 and INT4 cells also carry `--tokenizer-path openbmb/MiniCPM-V-4.7-35B-A3B`. A DSPARK overlay picks the variant's draft checkpoint. The image is `lmsysorg/sglang:dev-minicpm-v-4.7` (built from the #41993 head). Benchmarks carry GSM8K and speed for every GB300 and H200 cell, with and without DSPARK.
- `docs/docs.json`: page added at the top of the OpenBMB group. The `NEW` tag moves from MiniCPM5-2B to this page, and the OpenBMB vendor card now links here.

## Validation

All recipes ran on one GPU (GB300 or H200) with the #41993 head. Every recipe passed the image probes (16x / 4x / 16x-again / multi-image / `max_slice_nums=1`: 355 / 1291 / 355 / 556 / 93 prompt tokens, all `finish_reason=stop`). With the `auto` parsers, the thinking trace returns in `reasoning_content` and the final answer in `content`, and a `get_weather` request returns a structured `tool_calls` entry; the page shows the verbatim outputs.
