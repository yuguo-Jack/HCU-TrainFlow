## Original PR description

## Motivation

#45700 moved the fused draft's KV dtype check onto the region it binds and reworded the refusal. The draft-gate test still matched the old wording (`speculative-draft-kv-cache-dtype`), so it fails on main although the behavior it checks still holds: the draft still refuses to bind a bf16 region under an fp8 draft, and an e4m3 region under an e5m2 draft.

## Modifications

- `test/registered/unit/mem_cache/test_kv_cache_configurator_draft_gate.py`: the two `assertRaisesRegex` calls match the refusal by its rule, `draft KV dtype must match`. Test only; no production change.
