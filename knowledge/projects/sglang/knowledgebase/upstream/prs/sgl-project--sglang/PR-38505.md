## Modifications
### 1、Fix timeout issues caused by network instability in multimodal test cases.
Injects `GITHUB_PROXY_URL=https://gh-proxy.test.osinfra.cn/` into the "Run test" step of the two multimodal tasks (1‑npu and 4‑npu) in `pr‑test‑npu.yml`, so that the test process can pick up the proxy. Meanwhile, in the NPU‑specific `server/ascend/conftest.py`, `requests.get` / `requests.head` are wrapped at module‑load time. The proxy prefix is prepended only for GitHub URLs such as `raw.githubusercontent.com` ([[localhost](https://localhost/)](https://localhost) / HF / modelscope remain unaffected). This reduces the download latency for consistency‑check assets including GT images and case maps from direct‑connection delays of tens of minutes to normal levels via the proxy channel, preventing the 60‑minute timeout in the Run test step.
