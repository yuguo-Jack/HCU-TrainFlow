# Fix cgroup in namespace on hicache init

[Upstream PR](https://github.com/sgl-project/sglang/pull/43388) · state: open · merged: False

## Original PR description

Hicache init tries to resolve max memory from cgroup and fails when it starts with `/../` which is valid linux behaviour when it lives in namespace and cannot read outside of it: (grep `..` in https://man7.org/linux/man-pages/man7/cgroup_namespaces.7.html)

And even if I specify `--hicache-size` it does not skip this init

## Motivation

To make it run under such conditions

## Modifications

Throw handled RuntimeError in such case.
Also keep old check for ".." in path and throw ValueError if it is there by intent
