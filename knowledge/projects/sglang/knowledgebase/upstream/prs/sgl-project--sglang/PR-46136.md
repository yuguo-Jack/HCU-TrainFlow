# [Chore] docker: Select released wheels and the torch index in the cu134 image

[Upstream PR](https://github.com/sgl-project/sglang/pull/46136) · state: closed · merged: True

## Original PR description

## Summary
cu134 image build options:
- `SGL_WHEELS_SOURCE=pypi` downloads the released sglang-kernel / sgl-deep-gemm / sgl-deep-ep wheels instead of building them; `source` (default) keeps the current builds.
- `TORCH_INDEX_URL` / `TORCH_VERSION` / `TORCHVISION_VERSION` / `TORCHAUDIO_VERSION` select the torch wheels; they default to the nightly arguments, so existing invocations are unchanged.
- `INSTALL_AI_DYNAMO=0` skips ai-dynamo.
- `SGL_KERNEL_VERSION` follows pyproject (0.4.10).
- The nsight-systems apt key goes through a signed-by keyring instead of `apt-key`.
- ffmpeg is added to the runtime image.
