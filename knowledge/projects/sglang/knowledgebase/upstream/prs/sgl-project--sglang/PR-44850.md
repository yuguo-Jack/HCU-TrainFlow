# [Fix] deepseek-v4.1: Serve prompt-logprob requests under decoder SWA bounded replay

[Upstream PR](https://github.com/sgl-project/sglang/pull/44850) · state: closed · merged: True

## Original PR description

- `late_layer_whole_extend` picks the requests that read prompt rows: prompt logprobs, or every hidden state outside DSpark. Their late-layer tail is their whole extend, so these requests are served instead of raising in the forward and taking every scheduler down.
- `late_layer_tail_layout(whole_extend=...)` gives every row of a whole extend its plain sliding window, so no row of these requests is truncated; other requests keep the window tail and its floor. Both the CUDA and the HIP backend use it.
- A step whose tail outgrows the prefill CUDA graph's tail block runs eagerly. The backend answers the same question from the schedule batch (`vote_prefill_cuda_graph`), which the DP prefill-graph vote calls, so no DP rank replays the graph while another runs the step eagerly.
- DSpark's exemption comes from the server's speculative algorithm, since prefill-graph capture batches carry DSpark's `FULL` capture mode without it.
- `_check_late_layer_tail_readers` now raises only when the tail misses rows a reader needs; the DSpark logits path moves prompt-logprob starts into the tail.
- `--enable-return-hidden-states` makes every tail a whole extend, so decoder SWA bounded replay now resolves off with it; passing both flags still runs correctly.
- The DeepSeek-V4.1 cookbook and the flag's help now say that prompt-logprob requests are served, and that RL rollouts whose logprobs must match the trainer should pass `--no-enable-decoder-swa-bounded-replay`.
- Unit tests in `test/registered/unit/layers/test_dsv41_late_layer_tail_readers.py`.

Supersedes #41448 and #42719.

No behavior change for requests that read no prompt rows: their tail layout, prefill-graph decision, and logits path are unchanged.
