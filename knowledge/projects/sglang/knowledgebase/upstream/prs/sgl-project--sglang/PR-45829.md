# [Model] MiniCPM-OCR-jev

[Upstream PR](https://github.com/sgl-project/sglang/pull/45829) · state: open · merged: False

## Original PR description

## Motivation

Serve Qwen3.5-VL checkpoints fine-tuned as sequence classifiers (MiniCPM-OCR Jev)
with `--is-embedding`: the `lm_head` is replaced by a bias-free `score` head, and
the prediction is pooled at the last token.

## Modifications

- New `models/qwen3_5_classification.py`: `Qwen3_5VLForSequenceClassification`
  subclasses `Qwen3_5ForConditionalGeneration`, swaps `lm_head` for `score`,
  pools with `PoolingType.LAST` (no normalize) and returns raw logits.
- Register the arch next to `Qwen3_5ForConditionalGeneration` in the model
  overrides, `is_qwen3_5` / `is_generation_model`, `mm_schedule`,
  encoder disaggregation allowlist and `QwenVLImageProcessor.models`.

## Accuracy Tests

Logits match the HF reference on the same inputs.
