# [CI] [AMD] miles: drop the ROCm 7.2.4 MI35X nightly image build

[Upstream PR](https://github.com/sgl-project/sglang/pull/47194) · state: closed · merged: True

## Original PR description

## Motivation

`release-docker-amd-miles-rocm724-nightly.yml` builds and pushes `rocm/sgl-dev:miles-rocm724-mi35x` every day, but no nightly in this repo runs against it. #37495 moved the Miles nightly to ROCm 10 and deleted the 7.2 test workflow. Since #40387 (2026-09-24), this job has been publishing an image that nothing here tests.

## Modifications

Delete `release-docker-amd-miles-rocm724-nightly.yml`. The ROCm 10 build (`release-docker-amd-miles-rocm10-nightly.yml`, MI35X + MI30X) and both ROCm 10 Miles nightlies are unchanged. No other file in the repo references the removed workflow.

## Miles CI

Miles' own ROCm CI used the undated `miles-rocm724-mi35x` tag that this job overwrites. radixark/miles#4514 (merged) moved it to `miles-rocm10-mi35x`, so nothing reads the 7.2.4 tag now and this can merge.
