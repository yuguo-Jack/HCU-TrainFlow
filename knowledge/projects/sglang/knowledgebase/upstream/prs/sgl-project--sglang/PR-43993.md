# [DSV4.1] Skip Mega mHC fusion on 0-row (DP-idle) batches

[Upstream PR](https://github.com/sgl-project/sglang/pull/43993) · state: closed · merged: True

## Original PR description

## Motivation

Fixes #43992.

With `SGLANG_OPT_DSV41_MEGA_MHC_PREFILL=1` (#42808), DeepSeek-V4.1 with MegaMoE (`--moe-a2a-backend megamoe`) and DP attention (`--attn-dp-size > 1`) crashes as soon as one DP rank runs an idle (0-row) batch, e.g. on the server's startup warmup request:

```
RuntimeError: Tensor match failed for Tensor<0, 5120>[strides=<20480, 1>, dtype=bfloat16, device=cuda:1]
  at python/sglang/kernels/jit/csrc/deepseek_v4/mega_moe_pre_dispatch.cuh:189
- Root cause: Tensor is not contiguous as expected
```

On the idle rank, `_post_fusion()` takes the Mega mHC branch with a `[0, 5120]` view whose stride is `(20480, 1)`. `mhc_mega_boundary()` allocates its output with `torch.empty_like(x)`, which keeps that stride for a 0-element tensor; the result becomes the next sublayer's cached input and is handed to MegaMoE, whose pre-dispatch rejects it. The non-Mega path is fine because `post()` already returns a fresh `(0, mult, hidden)` tensor for 0 rows.

## Modifications

- `python/sglang/srt/models/deepseek_v4_mhc.py`: in `_post_fusion()`, take the Mega mHC branch only when `y.shape[0] > 0`; 0-row inputs fall back to `post()`. Non-empty batches are unchanged, and the idle rank still runs the MoE dispatch / all-to-all.

## Accuracy Tests

GSM8K (`python -m sglang.test.few_shot_gsm8k --num-questions 1319`), DeepSeek-V4.1-Flash FP4, B300, `--tp 2 --attn-dp-size 2 --ep 2 --moe-a2a-backend megamoe`, DSpark (block size 5, real acceptance):

| | `SGLANG_OPT_DSV41_MEGA_MHC_PREFILL` | accuracy |
|---|---|---|
| main (`c2dfd5d3d6`) | 0 | 0.907 |
| this PR | 1 | 0.906 |

(main with `SGLANG_OPT_DSV41_MEGA_MHC_PREFILL=1` cannot be measured: it crashes at startup.)

## Speed Tests and Profiling

No throughput claim. This is a correctness fix; the added check reads tensor metadata only, and non-empty batches take the same path as before.
