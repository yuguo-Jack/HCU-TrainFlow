# [Doc] diffusion: Fix documented snippets that cannot load a model

[Upstream PR](https://github.com/sgl-project/sglang/pull/46050) · state: open · merged: False

## Original PR description

Three copy-pasteable snippets that build a generator fail before producing any video: two import a name that does not exist, and one calls `from_pretrained` in a way that cannot set the model path.

### 1. `docs/cookbook/diffusion/LongLive/LongLive-2.0.mdx` (Multi-shot section)

```python
from sglang import DiffGenerator
```

`DiffGenerator` is not exported by the top-level `sglang` package: it is absent from `__all__` in `python/sglang/__init__.py`, and that module defines no `__getattr__`, so the import raises `ImportError`.

It is exported by `sglang.multimodal_gen` (`__all__ = ["DiffGenerator", "PipelineConfig", "SamplingParams"]`), which is how every other diffusion page imports it (`Kandinsky6.mdx`, `Kandinsky6-SR.mdx`, `progressive_resolution.mdx`, `plugin.mdx`).

### 2. `docs/docs/sglang-diffusion/support_new_models.mdx` (Implement the Pieces, step 1)

```python
from sglang.multimodal_gen.configs.sample.sampling_params import ImageSamplingParams
```

There is no `ImageSamplingParams` class. That module defines `SamplingParams`, `SkipSoftmaxParams` and `CacheParams`, and every image pipeline in the tree subclasses `SamplingParams` (`zimage.py`, `qwenimage.py`, `ernie_image.py`, `longcat_image.py`, `ming_image.py`, ...). The same page refers to `SamplingParams` elsewhere.

### 3. `docs/cookbook/diffusion/LongLive/LongLive-2.0.mdx` (same snippet, next line)

```python
gen = DiffGenerator.from_pretrained("Rabinovich/LongLive-2.0-5B-Diffusers")
```

The signature is `from_pretrained(cls, local_mode: bool = True, **kwargs)` (`multimodal_gen/runtime/entrypoints/diffusion_generator.py`). The positional string binds to `local_mode`, so `model_path` is never set and `ServerArgs.from_kwargs()` gets no model. Every other page passes it by keyword (`model_path=...` in `progressive_resolution.mdx`, `Kandinsky6.mdx`, `HY-Nomas.mdx`, `multimodal_gen/README.md`).

The same two mistakes appear in `python/sglang/multimodal_gen/.claude/CLAUDE.md` (lines 31-32); corrected there too.

### Change

Snippets now import symbols that exist and pass `model_path=` by keyword. Docs and comments only; no code or test change.
