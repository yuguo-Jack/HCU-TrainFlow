## Motivation

RFC #43949 part 4 of 4: run the DSpark draft stages on monokernels too. Depends on #44405 and #44407; please review the last commit.

## Modifications

- `DRAFT_SPEC` for the DSpark draft model: its stages run as whole layers, attached by the draft's own loader.
- `deepseek_v4_dspark.py` calls the same `mono` hooks as the target model.

## Accuracy Tests

DeepSeek-V4.1-Flash TP4 DSpark: GSM8K 1319 0.904, accept length 3.398 (3.362 without).

## Speed Tests and Profiling

TPOT c1 -5.0%, c4 -5.6% vs the draft on the normal path.
