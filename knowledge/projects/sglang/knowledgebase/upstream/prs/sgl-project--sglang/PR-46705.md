# [Perf] diffusion/ming: Reuse ordered RMSNorm in the DiT

[Upstream PR](https://github.com/sgl-project/sglang/pull/46705) · state: closed · merged: True

## Original PR description

## Motivation

Ming's DiT computes RMSNorm statistics in FP32 and rounds normalized values to BF16 before multiplying by the learned weight. Its native implementation launches separate square, mean, reciprocal-square-root, cast, and multiply operations throughout the denoising loop. This reuses the existing ordered RMSNorm implementation to reduce those launches while preserving the native result.

## Modifications

- Add `eps=1e-5` to the shared cast-before-weight operator, keeping its existing `1e-6` default and epilogues unchanged.
- Extend its ordered reduction to width 3840. Widths 128/3840 use the ordered path for eligible row counts; other shapes, including width 2560, retain ATen mean with fused pointwise operations.
- Dispatch `MingRMSNorm.forward_native` through the existing per-signature bit-exact gate. Residual, compile, unsupported dtype/epsilon, and noncontiguous input/weight cases retain native behavior.
- Add focused reduction-boundary, mixed-magnitude, model-dispatch, CUDA graph replay, and native compile fallback coverage. No new flags or model weights are introduced.
