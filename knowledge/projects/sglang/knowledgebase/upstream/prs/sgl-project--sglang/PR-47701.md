# [Feat] activevln: Add differentiable actor and SRT weight export

[Upstream PR](https://github.com/sgl-project/sglang/pull/47701) · state: open · merged: False

## Original PR description

## Motivation

Enable RLinf to train an ActiveVLN Qwen2.5-VL policy and synchronize its updated weights to native SRT rollout. This adds the differentiable actor interface and weight export needed by the training framework.

## Modifications

- Add `ActiveVLNModel` using the Transformers Qwen2.5-VL forward, with frozen vision, configurable language-layer training, gradient checkpointing, response-token logprobs and optional entropy.
- Export full or trainable-only weights under checkpoint names accepted by SRT's existing weight loader.
- Keep `vlas/__init__.py` empty and import Pi0.5 explicitly in its pipeline. This removes the package-level `Pi05PolicyModel` re-export; callers use `vlas.pi05_policy`.
- Add six CPU unit tests covering forward/gradient parity, image embeddings and multi-axis positions, checkpointing, response/EOS scoring, weight export and invalid inputs.

## Accuracy Tests

- Six SGLang tests and two checkpointing subtests passed. The combined SGLang/RLinf suite passed 30 tests and two subtests.
- Verified that importing ActiveVLN does not load Pi0.5, and that the Pi0.5 pipeline imports the same concrete policy class.
- Real-checkpoint validation on A800 passed backward, native weight updates, cache flush and suspend/resume. Frozen vision received no gradients. Actor/SRT BF16 token-logprob absolute differences were 0.003746 mean and 0.060549 maximum; the RLinf actor recomputes old logprobs.
- The companion RLinf integration completed two GRPO iterations: actor and SRT shared GPU 0 through offload, and Habitat-Sim rendered on GPU 1. Updated actor weights were used by the next rollout, and frozen tensors stayed unchanged. This is a training smoke test, not a convergence or navigation-success-rate evaluation.

GPU checks preceded the final import cleanup. Model computation is unchanged; import checks and focused tests were rerun afterward.

## Speed Tests and Profiling

Standalone ActiveVLN inference through native SRT on **one NVIDIA A800-SXM4-80GB**, BF16, TP1, using `Arvil/Qwen2.5-VL-3B_rl_r2r_4000`. The main tables do not invoke the RLinf policy wrapper or trajectory packing.

The first 16 R2R records were replayed for eight turns, with 256 measured observations per batch size after warmup. Generation was greedy and returned token logprobs, with 21 output tokens per response, context length 4096 and maximum image pixels 76800.

Timing starts with decoded CPU RGB and ends at parsed actions, including preprocessing and SRT IPC. Disk, simulator time, startup and warmup are excluded. KV, multimodal and NGRAM caches are cleared between replays and retained within each trajectory. Amortized latency is the batch response time divided by batch size, not individual response latency.

FlashInfer, NGRAM with 12 draft tokens, torch.compile, target-verify/ViT CUDA graphs and memory saver were enabled. **Prefill graphs were disabled in the following five-batch matrix.**

| Batch | Mean batch latency (ms) | Amortized ms/observation | Throughput (obs/s) |
|---|---:|---:|---:|
| 1 | 122.54 | 122.54 | 8.16 |
| 2 | 161.28 | 80.64 | 12.40 |
| 4 | 216.57 | 54.14 | 18.47 |
| 8 | 317.67 | 39.71 | 25.18 |
| 16 | 505.13 | 31.57 | 31.68 |

**Full prefill CUDA graphs enabled:** a separate native SRT ablation kept the remaining options unchanged and measured B=1 and B=16:

| Batch | Mean batch latency (ms) | Amortized ms/observation | Throughput (obs/s) |
|---|---:|---:|---:|
| 1 | 116.31 | 116.31 | 8.60 |
| 16 | 473.71 | 29.61 | 33.78 |

All native responses were format-valid. These results characterize ActiveVLN generation with existing SRT features; this PR adds no inference-kernel optimization.

Known runtime limitation: with memory saver disabled, native SRT can encounter an illegal memory access after cache flush with NGRAM, torch.compile and CUDA graphs. This also reproduces independently of the RLinf adapter. The reported runs used memory saver and passed.
