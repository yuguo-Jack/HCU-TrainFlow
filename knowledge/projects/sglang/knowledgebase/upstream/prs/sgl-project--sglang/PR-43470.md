# [CI] Remove the GLM-5.3-Flash PTX KDA prefill nightly test

[Upstream PR](https://github.com/sgl-project/sglang/pull/43470) · state: closed · merged: True

## Original PR description

## Summary

`test_glm53_flash_kda_ptx_prefill_blackwell.py` (added in #41445) runs in the 4-gpu-b200 and 4-gpu-gb300 nightly suites to compare the `ptx_kda` linear-attention prefill backend against Triton on GLM-5.3-Flash. It is currently failing on both runners: its baseline server asserts `extend=TritonKDAKernel` in the server log, but #43246 made FlashInfer the default safe-gate KDA prefill backend on Blackwell, so that server now runs `extend=FlashInferKDAPrefillKernel`.

Rather than updating the log check, this removes the test. GLM-5.3-Flash is already covered per PR on B200 (`test_glm53_flash_b200.py`) and H200 (`test_glm53_flash_h200.py`), and `ptx_kda` is an opt-in backend that isn't used enough to justify its own nightly job.
