# [NPU] Fix host-pool tensor-bool ambiguity and torch.compile crash on layer-boundary records

[Upstream PR](https://github.com/sgl-project/sglang/pull/43042) · state: closed · merged: False

## Original PR description

## Motivation

Two independent scheduler-startup crashes:

1. When the device KV pool stores its buffers as stacked tensors (e.g. the NPU unified pool), scheduler startup crashes with `RuntimeError: Boolean value of Tensor with more than one value is ambiguous` while building the HiCache host pool.

2. Since #42307 built the Qwen2 decoders from stage boundaries, every layer forward constructs layer-boundary records (`Contribution` and friends) as mutable `msgspec.Struct` objects. With `--enable-torch-compile`, the NPU fullgraph compile path (`test_npu_compile_graph_tp1_bf16`) crashes during graph capture with `InternalTorchDynamoError: TypeError: object.__new__(Contribution) is not safe`.

## Modifications

1. In `MHATokenToKVPoolHost` and `MLATokenToKVPoolHost`, `_init_device_row_stride` collected device buffers via `getattr(pool, side, None) or ()`. The `or` falls back only after evaluating the truthiness of the attribute, which raises on multi-element tensors. Replace it with an explicit `is not None` filter before iterating. Iterating a stacked tensor still yields per-layer slices, so row-stride detection is unchanged.

2. Dynamo traces user-class construction by building an example value via `object.__new__`, which msgspec's C-level `tp_new` rejects. Records created inside the traced forward region are therefore converted to plain dataclasses, which dynamo supports natively: `Contribution`, `DeclaredSum`, `OwedOutput` (`residual/stream.py`), `UnreducedOutput`, `DeferredFinalize` (`output.py`), `ExitDecision` (`exit.py`) and `MoeDeferredFinalize` (`fusions/cutedsl.py`, whose base class converted). `msgspec.structs.replace` becomes `dataclasses.replace`. Structs built only at model init (`OutputTransform`, contracts, plans) keep msgspec. Field layout, defaults, methods and frozen semantics are unchanged.
