# [KVCR] Hint salted lookups with the published event hash (stacked on #45650)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47681) · state: open · merged: False

## Original PR description

Stacked on #45650 (fork branch, so this targets main). Review only the top commit, 0aa0808fec. Independent of #47514.

For `cache_salt`/`extra_key` requests, the KVCR storage key differs from the event hash that the router indexes. The linker now registers each lookup's tail event hashes in a bounded FIFO map, and the KVCR runtime decodes a storage hash back to the registered event hash, so KVCR hints match what the router publishes. Unsalted requests are unchanged.
