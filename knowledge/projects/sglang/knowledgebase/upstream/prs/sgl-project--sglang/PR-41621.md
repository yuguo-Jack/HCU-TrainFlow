# Support page_first_kv_split in MLA HiCache L3 flat page I/O

[Upstream PR](https://github.com/sgl-project/sglang/pull/41621) · state: open · merged: False

## Original PR description

## Purpose

On Ascend NPU, MLA HiCache is forced onto `kernel_ascend` + `page_first_kv_split` (separate host `k_buffer` / `v_buffer` / indexer buffers). L1↔L2 transfer already works on that layout, but the generic L3 path (`file`, and any backend that goes through `_generic_page_set` / `_generic_page_get`) calls `get_data_page` / `set_from_flat_data_page`, which only handle `layer_first` / `page_first` / `page_first_direct`. Enabling `--hicache-storage-backend file` therefore crashes on the first L3 write with:

```text
ValueError: Unsupported layout: page_first_kv_split
```

This PR teaches `MLATokenToKVPoolHost` how to flatten one kv_split logical page into a contiguous uint8 blob (and restore it), so generic L3 backends can round-trip NPU MLA pages without depending on Ascend MemCache zero-copy.

Related but not duplicate: Ascend MemCache L3 work ([#26043](https://github.com/sgl-project/sglang/pull/26043), [#36188](https://github.com/sgl-project/sglang/pull/36188), [RFC #35620](https://github.com/sgl-project/sglang/issues/35620)) targets a different I/O path. This change unblocks `file` / copy-based L3 on the same layout.

## Changes

In `python/sglang/srt/mem_cache/pool_host/mla.py` (`MLATokenToKVPoolHost`):

- Add `_kv_split_page_tensors` / `_kv_split_page_nbytes` — page components in the same order as `get_page_buffer_meta` (K, V unless FP8 DSA packed, indexer K, optional FP32 scale)
- Extend `get_data_page` / `set_from_flat_data_page` / `get_dummy_flat_data_page` for `page_first_kv_split`
- No change to L1↔L2 `kernel_ascend` transfer; other layouts unchanged

## Test Plan

HTTP 200 alone does **not** prove L3. Required evidence: (1) pages appear under `FILE_DIR` after fill, (2) Prefill restart clears L1/L2 while files remain, (3) replay Prefill logs show non-zero load / `#cached-token`.

Tested on Atlas 800I A3, GLM-5.3-w4a8, 1P1D (Prefill TP16 + Decode), `file` L3. Numbers below are from a tokenizer-exact ~80k prompt (same procedure as the script: fill → restart → replay).

## Repro script (`l3_file_roundtrip.py`)

```python
#!/usr/bin/env python3
"""Minimal L3 file-backend fill/replay without rampbench.

Builds a deterministic long prompt by repeating a fixed chunk, posts it to
OpenAI-compatible /v1/chat/completions. Same --phase fill then --phase replay
(after Prefill restart) must use identical args so radix / L3 keys match.

Exact token count is approximate (no tokenizer). Default length is large enough
to exercise multi-page L3 (~hundreds of pages at page_size=128).
"""
from __future__ import annotations

import argparse
import time

import requests

# Unique stage tag so this workload does not collide with other caches.
STAGE = "<wr:hicache-l3-file:standalone> "
# Multi-word chunk tokenizes more stably than a single repeated character.
CHUNK = "The quick brown fox jumps over the lazy dog. "


def build_prompt(approx_tokens: int, chars_per_token: float) -> str:
    target_chars = max(0, int(approx_tokens * chars_per_token) - len(STAGE))
    n = (target_chars + len(CHUNK) - 1) // len(CHUNK)
    body = (CHUNK * n)[:target_chars]
    return STAGE + body


def main() -> None:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--phase", choices=("fill", "replay"), required=True)
    ap.add_argument(
        "--endpoint",
        default="http://127.0.0.1:6688/v1/chat/completions",
        help="Router or Prefill chat completions URL",
    )
    ap.add_argument("--model", default="glm-5")
    ap.add_argument(
        "--approx-tokens",
        type=int,
        default=80000,
        help="Approximate prompt size; not tokenizer-exact",
    )
    ap.add_argument(
        "--chars-per-token",
        type=float,
        default=4.4,
        help="Rough chars/token for English CHUNK (measured ~4.4 on GLM-5 chat template)",
    )
    ap.add_argument("--timeout", type=float, default=420.0)
    args = ap.parse_args()

    prompt = build_prompt(args.approx_tokens, args.chars_per_token)
    payload = {
        "model": args.model,
        "messages": [{"role": "user", "content": prompt}],
        "max_tokens": 1,
        "temperature": 0,
        "stream": False,
        "chat_template_kwargs": {"enable_thinking": False},
    }
    print(
        f"l3 {args.phase} prompt_chars={len(prompt)} approx_tokens~{args.approx_tokens}",
        flush=True,
    )
    t0 = time.time()
    resp = requests.post(args.endpoint, json=payload, timeout=args.timeout)
    dt = time.time() - t0
    print(f"l3 {args.phase} HTTP {resp.status_code} {dt:.1f}s", flush=True)
    if resp.status_code != 200:
        print(resp.text[:500], flush=True)
        raise SystemExit(1)
    usage = (resp.json() or {}).get("usage") or {}
    if usage:
        print(
            f"l3 {args.phase} usage prompt_tokens={usage.get('prompt_tokens')} "
            f"completion_tokens={usage.get('completion_tokens')}",
            flush=True,
        )


if __name__ == "__main__":
    main()
```
