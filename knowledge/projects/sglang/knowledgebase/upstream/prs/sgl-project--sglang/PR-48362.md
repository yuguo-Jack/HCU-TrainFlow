# [Test] runners: Fix the HF embedding reference for sentence-transformers 6

[Upstream PR](https://github.com/sgl-project/sglang/pull/48362) · state: closed · merged: False

## Original PR description

## Motivation
With sentence-transformers 6, `test_embedding_models` compares against a wrong HF reference:
- ST 6 renders plain text through the backbone's chat template, while SGLang embeds the raw text.
- The non-ST branch builds `models.Transformer` without `is_causal=True`, so gte-Qwen2 runs bidirectionally. The kwarg was renamed (`config_args` to `config_kwargs`) in v6.

## Modifications
- `test/runners.py`: drop the chat-template ("message") modality for ST >= 6; pass `is_causal=True` with the version's kwarg name. No-op for ST < 6.
- `test_embedding_models.py`: `mem_fraction_static=0.85` on XPU only, so the 8B model has enough KV for the ~6.4k-token prompt on a 24 GB card.

Test-only change.

## Accuracy Tests
`test_embedding_models::test_prefill_logits` (gte-Qwen2-1.5B, Qwen3-Embedding-8B, e5-mistral-7b) and `test_embedding_encoding_format` pass on Arc Pro B60 with sentence-transformers 6.0.1.
