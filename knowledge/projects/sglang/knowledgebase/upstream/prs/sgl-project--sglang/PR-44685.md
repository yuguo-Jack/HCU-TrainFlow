# [Fix] Support namespace tools and defer_loading for Muse Spark

[Upstream PR](https://github.com/sgl-project/sglang/pull/44685) · state: open · merged: False

## Original PR description

## Motivation

`/v1/responses` drops `defer_loading` on function tools and does not pass namespace tools to the chat template. Calls to namespace members also return a flattened name instead of separate `namespace` and `name` fields.

Port of [radixark/sglang-muse-spark#229](https://github.com/radixark/sglang-muse-spark/pull/229), based on **`muse-spark`**. Original author: [sid-rp](https://github.com/sid-rp) (`sid-rp <sidrp@meta.com>`). The original commit author, author timestamp, and commit message are preserved from `dda2e791970dfe8815b61ee407edc5e0ae88da8d`.

## Modifications

- Forward function-tool `defer_loading` and render namespace tools as nested template inputs while registering qualified names for tool-call parsing.
- Return separate namespace/function names in full and streaming Responses outputs, and rejoin them when replaying function calls.
- Include the original seven namespace-tool unit tests.

The port contains exactly the original five changed files (+309 / -5), with an identical stable patch ID (`82d241528a9066ecebbf7e91bc8c34d184c321e9`). No conflict resolution or additional code changes were needed.
