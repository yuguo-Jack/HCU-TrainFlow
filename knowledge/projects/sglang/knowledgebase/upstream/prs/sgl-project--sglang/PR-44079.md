# [HiCache] Fix and document HF3FS benchmarks

[Upstream PR](https://github.com/sgl-project/sglang/pull/44079) · state: open · merged: False

## Original PR description

## Motivation

The HF3FS benchmarks use outdated APIs and hardcoded file paths. Update
the three benchmarks so they can run against an existing 3FS deployment,
and document their prerequisites and usage.

## Modifications

- Add `--file-path` to all three benchmarks and delete the data file after
  successful completion.
- Use separate read/write buffers in the client benchmark.
- Update the storage benchmark to current internal APIs and account for
  cache eviction in its correctness test.
- Update the zero-copy benchmark to use `batch_set_v1` and `batch_get_v1`
  with a registered host KV-cache pool.
- Use simple tensor equality checks where applicable and correct
  throughput labels to GiB/s.
- Add a README covering setup, workloads, memory requirements, and usage.
- Remove the outdated, environment-specific `bench.sh`.

Not applicable; benchmark scripts and documentation only.
