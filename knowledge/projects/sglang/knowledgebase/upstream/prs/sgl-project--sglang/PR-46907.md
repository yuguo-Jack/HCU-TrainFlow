# [Fix] minimax-h3: Swap the fc1 halves of the Acc LoRA in build_minimax_h3_pdd_weights

[Upstream PR](https://github.com/sgl-project/sglang/pull/46907) · state: closed · merged: True

## Original PR description

## Motivation

`python -m sglang.multimodal_gen.tools.build_minimax_h3_pdd_weights` merges an Acc-8Step (PDD) LoRA from `alibaba-pai/MiniMax-H3-Acc-LoRAs` into the native MiniMax-H3 transformer. The LoRA is trained on the Diffusers SwiGLU projection (`ff.net.0.proj`), whose rows are `[value, gate]`. The native fused `mlp.fc1` is `[gate, value]`: the Diffusers checkpoint loader in `models/dits/minimax_h3.py` swaps the same halves when it loads `ff.net.0.proj`, and the tool already re-lays out `to_q` / `to_k` / `to_v` for `qkv_proj`. For fc1 it adds the delta unswapped, so in every block the gate rows receive the value delta and the value rows the gate delta. The merged Acc8 model then generates soft, blurry video.

## Modifications

- `tools/build_minimax_h3_pdd_weights.py`: `_diffusers_to_native_fc1` swaps the two halves of the fc1 delta before the merge. Every other target is unchanged.
- `test/unit/test_minimax_h3_pdd_offline.py`: `test_fc1_delta_is_merged_into_native_gate_value_rows` merges a one-block fc1 LoRA into a zero base and checks that the gate half lands on the native gate rows. It fails on the current `main` and passes with the fix; the other cases in the file pass either way.

Acc8 weights built with the current tool need to be rebuilt.

## Accuracy Tests

Weights: the FL2VA transformer merged with `MiniMax-H3-FL2VA-Acc-8Step.safetensors`, once with the current tool and once with this fix. Against the base weights plus the LoRA delta in the native layout (computed in FP32, rounded to BF16), the fixed merge matches all 258 merged tensors bit for bit. The current tool's output differs only in the 52 `mlp.fc1` tensors (5.2e9 elements, worst tensor error 12.7x the BF16 rounding of the reference). The 277 non-target tensors are identical in both.

Video: MiniMax-H3 FL2VA Acc8, t2va 768p 16:9, 15 s (362 frames), 9 sigma points, flow shift 12 / 3, seed 42, transformer attention `torch_cudnn_sdpa`, SGLang v0.5.21 (this tool is identical in v0.5.21 and `main`). The two runs of each prompt differ only in the transformer weights and their fused PDD heads. With the current tool, outlines of faces, eyes and hair are soft and smeared and flat areas look washed out; with the fix the same frames have sharp line art and detail.

| Prompt | Laplacian variance, current tool | Laplacian variance, with the fix |
| --- | ---: | ---: |
| 2D-animated character close-up | 190.6 | 427.1 |
| Live-action scene with a 2D-animated character | 399.1 | 631.2 |

Mean over 61 evenly spaced frames of the decoded RGB; higher is sharper.
