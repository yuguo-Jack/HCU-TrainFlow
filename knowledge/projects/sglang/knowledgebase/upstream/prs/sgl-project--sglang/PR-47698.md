# [Perf] eplb: Replace per-item tensor ops with list packing in deepseek_vec.pack_groups

[Upstream PR](https://github.com/sgl-project/sglang/pull/47698) · state: open · merged: False

## Original PR description

## Motivation

In `python/sglang/srt/eplb/eplb_algorithms/deepseek_vec.py`, `pack_groups()` previously executed per-item 0-D PyTorch tensor operations (`full.masked_fill_`, `argmin()`, tensor indexing, and in-place scalar writes) inside the nested `num_layers * num_groups` greedy packing loop:

```python
for i in range(num_layers):
    pack_weights = torch.zeros(num_nodes, device=device, dtype=torch.int64)
    pack_items = torch.zeros(num_nodes, device=device, dtype=torch.int64)
    full = torch.zeros(num_nodes, device=device, dtype=torch.bool)
    for group in indices[i]:
        full.masked_fill_(pack_items >= groups_per_node, True)
        pack = pack_weights.masked_fill(full, float("inf")).argmin()
        ...
```

While `deepseek.py`'s `balanced_packing` was optimized in #21232 to convert tensors to Python lists before running the greedy loop, `deepseek_vec.py`'s `pack_groups` still ran 8–10 PyTorch dispatcher launches per `(layer, group)` iteration. For a DeepSeek-V3-scale configuration (`num_layers=60`, `num_groups=256`, `num_nodes=8` = 15,360 iterations), `pack_groups` spent ~2.0 seconds in Python/ATen dispatch overhead per rebalance call.

## Modifications

- Convert sorted `indices` (`indices.tolist()`) and `tokens_per_group` (`tokens_per_group.tolist()`) to Python lists once before the loop in `deepseek_vec.pack_groups`.
- Perform the greedy bin-packing loop (`min(range(num_nodes), key=...)` and weight/count updates) in pure Python lists and construct `pack_index` and `rank_in_pack` in a single `torch.tensor(..., dtype=torch.int64, device=device)` transfer at the end.
- Add `TestPackGroups` unit test in `test/registered/unit/eplb/test_balanced_packing.py` verifying slot uniqueness, bounds, and exact match with `deepseek.balanced_packing`.

## Benchmark

Measured on CPU across 20 runs (`torch.manual_seed(42)`):

| Shape `(num_layers, num_groups, num_nodes)` | Before (`ms`) | After (`ms`) | Speedup |
|---|---|---|---|
| `(58, 8, 2)` | 59.8 ms | 0.9 ms | **66.9x** |
| `(60, 64, 8)` | 495.3 ms | 6.5 ms | **76.2x** |
| `(60, 256, 8)` | 2,003.8 ms | 25.8 ms | **77.7x** |

Outputs (`pack_index`, `rank_in_pack`) are bit-for-bit identical before and after.
