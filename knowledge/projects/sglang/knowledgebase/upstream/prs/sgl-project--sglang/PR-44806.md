# [Fix] minimax-h3: fix AdaLN cache slot leak on preparation failure

[Upstream PR](https://github.com/sgl-project/sglang/pull/44806) · state: open · merged: False

## Original PR description

## Motivation

`MiniMaxH3AdalnCache.build` reserves one slab slot per missing plan, then embeds the timesteps, writes them and queries the tensor-parallel layout. Only the checkpoint projection that follows sat inside the rollback guard, so a failure in any earlier step left the reserved slots in neither the free list nor the resident map. Each failed request shrank the cache until a later build died with `IndexError: pop from empty list`, which then failed every request.

## Modifications

- `runtime/models/dits/minimax_h3_adaln_cache.py`: move the embedding, timestep writes and tensor-parallel queries into the existing rollback guard, so every failure returns the reserved slots.
- `test/unit/test_minimax_h3_adaln_cache.py`: CPU regressions for repeated failures at each stage, with and without resident plans (eviction included). They check the free list, resident map, slot lengths and counters after every failure, and a successful retry at the end.

## Accuracy Tests

Unit: `test_minimax_h3_adaln_cache.py` 30 passed. Two host-tier tests depend on available host memory and need the override named in the commit message on small hosts; without it they fail (28 passed, 2 failed). Without the fix the new tests fail.

Real MiniMax-H3 FL2VA checkpoint, TP2 on 2 x B200, t2va, 4 s, 50 steps, seed 42. Server runs on this branch head, on a merge of the three H3 fixes (this PR, the VAE tile validation and the sigma preflight), and on unpatched `main` (`2948662026`).

## Speed Tests and Profiling

Not a performance change. The fix only touches the failure path / load-time validation; the regression run below produced bit-identical output, but latency was not measured.

Limitations: the only injected fault is the embedding callable raising; everything the cache reads and computes comes from the real checkpoint. Only the FL2VA partition, t2va, TP2 and one prompt/seed were run.
