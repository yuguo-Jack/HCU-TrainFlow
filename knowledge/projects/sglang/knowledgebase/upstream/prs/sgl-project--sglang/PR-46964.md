## Motivation

Add support for the official [Hy-Nomas](https://huggingface.co/tencent/Hy-Nomas) distilled INT8 DiT and PixelUMM FP8 VAE checkpoints to the existing Nomas pipeline introduced in #46124.

The INT8 DiT stores quantized weights and retains BF16 linear computation. The FP8 VAE uses block-scaled Triton FP8 GEMM.

## Modifications

- Validate official checkpoint metadata, layer manifests, tensor shapes and dtypes before loading.
- Load groupwise INT8 DiT weights through the parallel linear loaders, dequantize in FP32 for BF16 computation, and preserve FP32 scales across component moves.
- Load the FP8 VAE on meta, replace its 180 selected decoder projections, and stream weights through the existing VAE loader.
- Match the official SM89 activation quantization using 128×128 blocks and reuse the existing Triton block FP8 GEMM.
- Let the VAE model declare quantized projections and unused encoder weights while retaining strict decoder validation.
- Extend Nomas tests to cover checkpoint validation, serialization, parallel loading, quantized computation and dtype preservation

| Comparison | Result |
|---|---|
| SGLang DiT replay vs. captured pipeline | All 8 predictions bitwise identical; all 775 scales remain FP32 |
| Official DiT vs. SGLang with shared text and main attention implementations | All 8 predictions and final latent bitwise identical |
| Video pixels using each implementation's attention and FP8 GEMM paths | PSNR 26.37 dB; mean SSIM 0.8277 |
| Video pixels with shared DiT attention, Triton vs. official CUTLASS VAE | PSNR 42.64 dB; mean SSIM 0.9920 |
| Video pixels with shared DiT attention and test-only official CUTLASS VAE linears | Bitwise identical |
| Standalone SGLang VAE replay vs. captured pipeline | Bitwise identical |

Pixel metrics are computed before MP4 encoding. PSNR uses raw outputs with data range 2; SSIM uses outputs normalized and clipped to [0, 1]. Shared-backend substitutions are for validation only.
