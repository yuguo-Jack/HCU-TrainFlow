## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111, #45311, #45513, #45749, #46005, #46506, #46547, #46807, #46948) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Removes launches whose results SemiAnalysis purged.** The merged Klaud-Cold image bumps [InferenceX #4203](https://github.com/SemiAnalysisAI/InferenceX/pull/4203), [#4529](https://github.com/SemiAnalysisAI/InferenceX/pull/4529), [#4515](https://github.com/SemiAnalysisAI/InferenceX/pull/4515), [#4324](https://github.com/SemiAnalysisAI/InferenceX/pull/4324) and [#4449](https://github.com/SemiAnalysisAI/InferenceX/pull/4449) had issues, so their results were purged from the InferenceX dashboard. #46807 and #46948 mistook the missing rows for a dashboard problem and pinned these lanes to the PRs' `/use` runs. Each lane now shows the run the dashboard shows again (table below).
2. **Adds the in-progress InferenceX PRs** in the Source table: MiniMax-M3.1-Flash FP8 draft KV on B200 / GB200 / GB300, the DeepSeek-V4.1 GB300 DEP16 disagg HiCache lane, and DeepSeek-V4 B200 disagg DSpark6 HiCache.
3. **Syncs to InferenceX `main`** (`253c38bf`). Muse Spark Open B300 ([InferenceX #4417](https://github.com/SemiAnalysisAI/InferenceX/pull/4417)) is now on the dashboard and comes from `main`.
