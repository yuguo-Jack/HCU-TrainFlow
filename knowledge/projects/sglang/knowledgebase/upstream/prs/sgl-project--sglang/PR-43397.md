# [diffusion] comfyui: fix QwenImageEditAdapter dropping extra reference images

[Upstream PR](https://github.com/sgl-project/sglang/pull/43397) · state: closed · merged: False

## Original PR description

Fixes #43116

`QwenImageEditAdapter.pack` only packed `ref_latents[0]`. Extra reference images from ComfyUI's multi-image edit workflow were silently dropped.

Fix: pack every entry in `ref_latents`, concatenate along the token dimension, build `vae_image_sizes` as one entry per image. Matches the native pipeline's existing multi-ref handling in `configs/pipeline_configs/qwen_image.py`.

## Testing

- Added unit test `test_qwen_image_edit_pack_keeps_all_ref_latents` (CPU) in `test/unit/test_comfyui_adapters.py`, with 3 ref latents of different sizes.
- Pre-fix: only 1 of 3 images kept (1024 tokens).
- Post-fix: all 3 images kept (2368 tokens).
- GPU: loaded real Qwen-Image-Edit-2511 on an A100, ran one forward pass with 3 ref latents through the patched adapter:
  - `vae_image_sizes: [(64, 64), (96, 32), (48, 48)]`
  - `image_latent` tokens: 2368
  - `noise_pred` shape: `[1, 3600, 64]`, bf16
  - No crash, no shape mismatch, all 3 images used.
