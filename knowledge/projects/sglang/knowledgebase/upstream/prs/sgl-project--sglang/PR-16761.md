## Original PR description

- Clear aiter JIT lock files before tests to prevent deadlocks when multiple TP workers try to compile simultaneously
- Add flash attention kernel warmup (flash_attn_varlen_func)

The deadlock occurs when 8 TP workers all wait on aiter file_baton locks that are never released from interrupted compilations:
