## Motivation

While following the official Ascend NPU docs to deploy and benchmark **Qwen3.6-35B-A3B**, we hit two documentation gaps that block a clean “copy from docs and run” path:

### 1. Recommended stable image is too old for NEXTN

Current docs recommend:

```text
quay.io/ascend/sglang:v0.5.13.post1-cann9.0.0-a3
```

But Qwen3.6 Ascend best-practice configs enable **NEXTN** speculative decoding. On `v0.5.13(.post1)`, server startup fails with:

```text
AttributeError: 'NPUMHATokenToKVPool' object has no attribute 'data_strides'
```

Root cause:

- Enabling NEXTN sets `enable_kv_cache_copy=True`
- Parent KV pool warmup expects `data_strides` / `data_ptrs`
- Ascend `NPUMHATokenToKVPool` uses a different paged layout and did not set them
- Fix landed on `main` in [#27202](https://github.com/sgl-project/sglang/pull/27202) (2026-06-09), but was **not cherry-picked** into `release/v0.5.13`
- First release tag containing the fix: **`v0.5.14`**
- Official Ascend image with the fix: `quay.io/ascend/sglang:v0.5.14-cann9.0.0-a3` (and `...-910b`)

So the docs currently recommend a stable image that cannot run the documented NEXTN best-practice commands.

## Modifications

### 1. [`ascend_npu_quick_start.mdx`](docs/hardware-platforms/ascend-npus/ascend_npu_quick_start.mdx)

- Update stable release example tag:
  - A3: `v0.5.13.post1-cann9.0.0-a3` → `v0.5.14-cann9.0.0-a3`
  - A2: `v0.5.13.post1-cann9.0.0-910b` → `v0.5.14-cann9.0.0-910b`
- Update Tip example tag to `v0.5.14-cann9.0.0-a3`
- Add a short note: for Qwen3.6 + NEXTN, use **SGLang `>= v0.5.14`**; `v0.5.13(.post1)` may fail during KV-cache init on Ascend

### 2. [`model-tutorials/qwen3_6_35b_a3b.mdx`](docs/hardware-platforms/ascend-npus/model-tutorials/qwen3_6_35b_a3b.mdx)

- Validation baseline: **v0.5.13** → **v0.5.14**
- Recommend **v0.5.14 or later** for NEXTN / multimodal
- Document known issue on `v0.5.13(.post1)`:
  - `NPUMHATokenToKVPool` missing `data_strides` when NEXTN is enabled
- Update Installation docker pull / run image tags for A3 and A2 to `v0.5.14-...`

### 3. [`best_practice/qwen3_6_35b_a3b.mdx`](docs/hardware-platforms/ascend-npus/best_practice/qwen3_6_35b_a3b.mdx)

- Top note: use image **`>= v0.5.14`** for these NEXTN configs
- Top note: without `--dataset-path`, random bench downloads ShareGPT from HF; offline users should pass a local dataset path
- Add to all `random` benchmark commands:

```bash
--dataset-path /path/to/dataset \
```
