# [Test] [NPU] parameter: Add sampling mask max tokens e2e test

[Upstream PR](https://github.com/sgl-project/sglang/pull/39934) · state: open · merged: False

## Original PR description

## Motivation
Add NPU end-to-end regression tests for the --sampling-mask-max-tokens parameter. This parameter controls the maximum number of token IDs in a returned sampling mask and aborts the request when the realized sampling support exceeds this limit. Before this PR, the parameter lacked NPU/Ascend coverage and behavior parity with CUDA was not verified.

## Modifications
- Add test_npu_sampling_mask_max_tokens.py with two test classes:
  - TestNpuSamplingMaskMaxTokens : single-node scenario. Verifies normal sampling-mask return and request abortion when top_k exceeds --sampling-mask-max-tokens .
  - TestNpuSamplingMaskMaxTokensPD : PD-disaggregation (1P1D) scenario, using --mini-lb , --disaggregation-bootstrap-port , --prefill <url> <bootstrap_port> , and SGLANG_ENABLE_DISAGG_SAMPLING_MASK=1 , to verify sampling-mask return and over-limit abortion in prefill/decode separated serving.
