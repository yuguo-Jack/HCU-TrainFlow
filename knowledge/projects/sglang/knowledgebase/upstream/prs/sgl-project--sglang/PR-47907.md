## Motivation

A motivating MiniMax-H3 Ref2VA workload was substantially slower in SGLang than vLLM-Omni. Investigation found that SGLang defaults to `reference_resize_mode="diffusers"`, which upscales small reference images to a 2048-pixel short edge and increases reference-token work throughout denoising.

Switching to the existing `max` policy reduced median latency by **37.7%** and achieved **5.3% lower latency than vLLM-Omni** in that comparison. Informal visual review found no clear quality regression; the broader proxy-score results are below.

## Modifications

- Default native H3 Ref2VA image references to `max`: only downscale when the short edge exceeds 2048 pixels, with dimensions rounded to multiples of 32.
- Share the default across sampling parameters, prequeue planning, and reference encoding.
- Preserve explicit `diffusers`/`match` overrides and FastH3 Omni's existing `diffusers` default.
- Update documentation and resize/admission regression tests.

Reference conditioning can change generated content. Requested output resolution, frame count, denoising steps, and precision are unchanged.

## Accuracy Tests

Evaluated **26 public VBench small-reference cases**, producing **148 videos** across both policies: 24 cases at seeds 42/43/44, plus reused seed-42 outputs for cases 16 and 64. Settings: native H3 Ref2VA, BF16, 50 steps, 1344×768, 124 frames at 24 fps, concurrency 1, conditioning cache disabled.

| Metric | SGLang `max` | SGLang `diffusers` | Change |
| --- | ---: | ---: | ---: |
| Imaging quality (MUSIQ) ↑ | 71.74 | 72.05 | −0.43% |
| Subject consistency ↑ | 92.16 | 92.41 | −0.28% |
| Background consistency ↑ | 94.82 | 94.97 | −0.16% |
| Aesthetic quality ↑ | 61.88 | 62.06 | −0.29% |
| Motion smoothness ↑ | 99.07 | 99.08 | −0.01% |
| Dynamic degree | 79.49 | 85.90 | −7.46% |
| Reference-subject similarity ↑ — 15 cases | 91.02 | 91.16 | −0.15% |
| Reference-background similarity ↑ — 11 cases | 89.61 | 89.57 | +0.04% |

Scores average seeds within each case, then weight applicable cases equally; quality values use a 0–100 scale and relative changes use unrounded values. Dynamic degree's apparent quality regression reflects a binary motion-threshold pass rate, which does not establish worse perceptual quality.

These are H3-adapted VBench diagnostics, not official leaderboard scores or a formal quality-equivalence study. The expanded quality evaluation predates the latest rebase.

## Speed Tests and Profiling

**Public VBench performance:** the 26-case affected-input subset averaged **192.91 s with `max` versus 223.44 s with `diffusers`**, a **13.67% reduction**. Timings use the same seed-then-case weighting as above; the two reused cases retain their earlier-device timings.

An earlier five-input public VBench run used the unmodified official vLLM-Omni serving benchmark client, one B200, the same output shape, 50 steps, and one timed request per input:

| Configuration | Mean latency | Median latency |
| --- | ---: | ---: |
| SGLang `max` | **187.18 s** | **200.41 s** |
| SGLang `diffusers` | 210.83 s | 212.37 s |
| vLLM-Omni | 279.32 s | 308.58 s |

The five-input aggregate includes different reference sizes because SGLang caps large references while vLLM-Omni retains native geometry. On the two cases with matching resolved reference sizes, SGLang averaged **161.29 s versus 169.28 s**, or **4.73% lower latency**; encoder defaults and runtime versions still differ.
