# [Fix] scheduler: throttle polling loop when scheduler is paused

[Upstream PR](https://github.com/sgl-project/sglang/pull/46307) · state: open · merged: False

## Original PR description

## Motivation
When the scheduler is paused (self._engine_paused = True), the event loops repeatedly poll non-blocking sockets and record metrics in a tight loop without waiting, which can spin CPU cores during pause states.

## Modifications
- In _record_scheduler_state_for_paused_engine, call maybe_sleep_on_idle() if an idle sleeper is configured.
- Fall back to sleeping 5ms when an idle sleeper is not available.
- Added 	est_paused_engine_waits_or_throttles to 	est/registered/unit/managers/test_scheduler_pause_generation.py.
