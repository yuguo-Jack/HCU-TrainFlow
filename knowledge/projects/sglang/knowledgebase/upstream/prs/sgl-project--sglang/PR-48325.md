# [Feat] docker: Install AWS EFA in the main image; drop the EFA image variant

[Upstream PR](https://github.com/sgl-project/sglang/pull/48325) · state: open · merged: False

## Original PR description


- Add docker/install_efa.sh and run it in the framework and runtime stages of docker/Dockerfile: EFA installer 1.51.0 in minimal mode (libfabric, aws-ofi-nccl, hwloc), with LD_LIBRARY_PATH set so the AWS libfabric wins over the distro copy.
- Remove docker/efa.Dockerfile and release-docker-efa.yml. The standard mooncake-transfer-engine-cuda13 0.3.14 wheel includes the EFA transport, so no EFA wheel swap or separate -efa image is needed.
- Docs: all CUDA 13 images include EFA. Enable it at runtime with MOONCAKE_PROTOCOL=efa, SGLANG_DISAGGREGATION_NIXL_BACKEND=LIBFABRIC, NCCL_NET_PLUGIN=ofi and NCCL_TUNER_PLUGIN=ofi. Update the manual install steps for Mooncake 0.3.14.
