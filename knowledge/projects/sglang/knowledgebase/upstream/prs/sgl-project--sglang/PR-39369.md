# [Fix] [NPU] npu: Preserve Ascend TP routing weight precision

[Upstream PR](https://github.com/sgl-project/sglang/pull/39369) · state: open · merged: False

## Original PR description

## Motivation

Preserve the FP32 routing weights returned by the NPU TopK path until `npu_moe_finalize_routing` so BF16 hidden states do not reduce routing precision. Fixes #39351.

## Modifications

- Removed the hidden-state dtype conversion from `AscendTPDispatcher.dispatch`.
- Added a registered unit test covering FP32 weight preservation and int32 expert IDs.

## Accuracy Tests

- `python3 test/registered/unit/layers/moe/test_ascend_tp_dispatcher.py -v` could not run locally because the environment does not provide `torch`.
- Ascend NPU accuracy validation was not run because no Ascend NPU hardware is available in this environment.

## Speed Tests and Profiling

Not run. This change removes a dtype conversion and adds no new runtime operation.
