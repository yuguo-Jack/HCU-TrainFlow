# [Fix] diffusion/ci: Keep final failure reasons at the end of shard logs

[Upstream PR](https://github.com/sgl-project/sglang/pull/46916) · state: closed · merged: True

## Original PR description

## Motivation

Diffusion shards continue running standalone tests after parametrized failures, burying the failed cases and reasons under later output. Buffered parent progress messages can also appear after their child pytest output. See [the affected job](https://github.com/sgl-project/sglang/actions/runs/40494205576/job/122155684284).

## Modifications

Print a final failed-cases-and-reasons footer after all shard tests and the execution report. Read complete failure messages from the existing JUnit report, falling back to pytest output when no report is available, and omit failures recovered by retries. Flush parent stdout before starting each pytest process. Execution order, retry policy, and failure exit codes are preserved.

## Validation

Four targeted CPU runner regression tests passed with real child pytest processes; three reproduce the bug before the fix. Coverage includes later standalone output, recovered retries, complete multiline failure reasons, and buffered output ordering. Pre-commit passed.
