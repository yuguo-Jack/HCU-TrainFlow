# refactor(sglang): TRTLLMHAAttnBackend → inherit from AttentionBackend directly (#28808)

## Original PR description

## Summary
Fix sgl-project/sglang#28808.

`TRTLLMHAAttnBackend(FlashInferAttnBackend)` overrode every attention-specific
method (init_forward_metadata, forward_decode, forward_extend, get_cuda_graph_seq_len_fill_value, ...).
The only real reuse from the FlashInfer parent was ~10 lines of init plumbing:
token/KV pool construction, kv_indptr/kv_last_page_len buffer allocation,
skip_prefill flag, and SWA resolution.

Inheriting from FlashInferAttnBackend additionally allocated:
- `prefill_wrapper_ragged`, `prefill_wrappers_paged`, `prefill_wrappers_verify`
- `decode_wrappers`
- `FlashInferIndicesUpdater*` objects
- shared `global_workspace_buffer`

None of these are used on the TRTLLM path. Several fields were also set twice:
`_swa_kv_pool` and `max_context_len`.

**Change:** TRTLLMHAAttnBackend now inherits directly from `AttentionBackend`.
The small amount of genuinely-shared setup is inlined. No behavioral change
intended — all public API is preserved.

Diff: 1 file, +40 / -9.
