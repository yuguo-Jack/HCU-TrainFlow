# [Fix] scheduler: Publish KV events while the engine is paused

[Upstream PR](https://github.com/sgl-project/sglang/pull/46334) · state: closed · merged: True

## Original PR description

## Motivation

An RL weight sync runs `pause_generation` in retract mode, then `update_weights_*` with `flush_cache=True`, then `continue_generation`. The flush queues AllBlocksCleared, but a paused scheduler never publishes KV events, so a KV-event router (sgl-router, or Dynamo) keeps that worker's whole pre-flush cache view for the entire sync and scores requests against blocks that no longer exist. The clear reaches the router only after resume.

#24003 added a publish at pause entry. It covers what was queued up to the pause, not what happens during it, such as the weight update's flush.

Found while following #24003's pause-time flush through a weight update.

## Modifications

Every pausable event loop (normal, overlap, PD prefill, PD decode, MLX) calls `_record_scheduler_state_for_paused_engine()` on each paused iteration and skips `on_idle`. This adds one `publish_kv_events()` call to that helper, which covers the flush and anything else recorded while paused. The call does nothing on ranks without a publisher, and on an idle paused loop it only drains an empty queue.
