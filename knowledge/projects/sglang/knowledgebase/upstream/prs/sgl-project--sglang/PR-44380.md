## Motivation

`base-a-test-cpu` fails on main in two unit tests whose hand-built fakes no longer match the code they exercise, after #44326, #42817 and #39730 added new attributes that these fakes never set.

## Modifications

- `test_cp_strategy_unit.py`: set `runner.max_seq_len = None` on the fake `PrefillCudaGraphRunner` (read by `can_run_graph` since #44326).
- `test_request_class_override_points.py`: give the fake scheduler a `kv_events_publisher` with events disabled (#42817), and the fake tokenizer manager a no-op `positional_embeds_transport` (#39730).
- Test-only change; no runtime code touched.
