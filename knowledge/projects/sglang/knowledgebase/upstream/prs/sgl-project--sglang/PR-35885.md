# fix(parser): match model-specific rules before the mimo fallback

[Upstream PR](https://github.com/sgl-project/sglang/pull/35885) · state: closed · merged: False

## Original PR description

## Motivation

Parser auto-detection returns the first rule that matches, so broad rules have to come last. The `mimo` rule matches on nothing more than a template setting `enable_thinking | default(false)`, which many chat templates do. It was ordered ahead of rules that key on model specific markers, so those templates resolve to `mimo`.

On current main, a template that contains the marker and also sets that default resolves as:

| Template contains | Expected | Detected on main |
| --- | --- | --- |
| `<mm:think>` | `minimax-m3` | `mimo` |
| `<minimax:tool_call>` | `minimax` | `mimo` |
| `Step-3.5` | `step3p5` | `mimo` |
| `<steptml:invoke` | `step3` | `mimo` |
| `<｜DSML｜tool_calls>` | `deepseek-v4` | `mimo` |
| `<function=` and `<parameter=` | `qwen3_coder` (tool call) | `mimo` |

The last row is the one that breaks output parsing, since the tool call parser itself is wrong.

`test_specific_rules_precede_broad_fallbacks` already states that specific rules must run before broad ones, and already guards `poolside_v1` and `minicpm5` against `mimo`. This applies the same ordering to the remaining rules.

## Modifications

- Move `mimo` after the marker based rules in `REASONING_PARSER_RULES` and `TOOL_CALL_PARSER_RULES`. Its position relative to `qwen`, `deepseek_v3` and `deepseek_r1` is unchanged, since those predicates cannot match at the same time as `mimo`.
- Extend `test_specific_rules_precede_broad_fallbacks` with the missing ordering checks.
- Add two tests that run detection on templates carrying both a marker and the `enable_thinking` default.

Templates with no marker still resolve to `mimo`, so detection for MiMo itself is unchanged.

Reproduction used minimal templates built from the marker plus the `enable_thinking` default, not a full vendor template.

Tests:

```

43 passed, 65 subtests passed
```

Reverting only the source change, with the new tests in place, fails 12 of them.
