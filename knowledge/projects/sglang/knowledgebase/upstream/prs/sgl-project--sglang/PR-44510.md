# [Doc] cookbook: Add Nemotron 3.5 Super VL

[Upstream PR](https://github.com/sgl-project/sglang/pull/44510) · state: closed · merged: True

## Original PR description

## Motivation

Add an interactive Nemotron 3.5 Super VL cookbook at `/cookbook/autoregressive/NVIDIA/Nemotron3.5-Super`. The SGLang model source is on the [`nemotron3-super-dev-20261015` branch](https://github.com/sgl-project/sglang/tree/nemotron3-super-dev-20261015).

## Modifications

- Add single-node B200, H200, RTX PRO 6000, and DGX Spark recipes. B200 offers NVFP4 and BF16, H200 offers BF16, and RTX PRO 6000 and DGX Spark offer NVFP4.
- Add a Mamba SSM DType selector with `bfloat16` and `float32`. High Throughput omits MTP; Low Latency enables EAGLE MTP.
- Keep `--moe-runner-backend triton` on H200. Omit the explicit attention backend, maximum running requests, and static memory fraction from B200 recipes; omit the last two limits from H200 recipes.
- Show GSM8K accuracy only in the selected recipe's Benchmark card. All non-Spark float32 selections are verified; Spark float32 remains unverified.
- Add the page to navigation and the NVIDIA homepage card; move the NEW tag from the prior NVIDIA page.

## Accuracy Tests

The bfloat16 Mamba-state source runs cover all ten supported hardware/quantization/strategy cells. All eight non-Spark float32 selections completed 300-question text-only GSM8K runs with zero request errors. Spark float32 testing was stopped before completing the cohort.

The completed results used the early-access NGC weights and source at `2c7511f6f7cf1cdf9ae568ad0fb25f291edb10da`. The command panel uses the public `lmsysorg/sglang:nemotron3-5-super` tag and the requested public Hugging Face checkpoint IDs. Those public artifacts have not been verified by the accuracy runs.

Not applicable to this documentation change. The strategy labels do not assert measured throughput or latency gains.
