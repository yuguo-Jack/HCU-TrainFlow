# [Feat] mistral3: Support Nemotron 3.5 Rerank multimodal reranking

[Upstream PR](https://github.com/sgl-project/sglang/pull/47340) · state: open · merged: False

## Original PR description

## Motivation

Add support for [`nvidia/Nemotron-3.5-Rerank-8B-BF16`](https://huggingface.co/nvidia/Nemotron-3.5-Rerank-8B-BF16) for text, image, and combined-document relevance scoring. The published checkpoint currently fails model resolution.

## Modifications

- Reuse native Mistral3, Ministral3, and Pixtral components with bidirectional attention, mean pooling, and the published scoring head.
- Select query/document chat formatting through model capabilities and preserve images through `/v1/rerank`, including returned image documents.
- Apply serving defaults only to the supported bidirectional, mean-pooled classifier layout; add regression/serving tests and a documented launch example.

## Accuracy Tests

A100/FlashInfer, H100/FA3, and B200/TRTLLM default paths each passed 13 reference cases plus eight batch/concurrency/API checks. Text, image, combined documents, multilingual queries and a long input passed.

TP2 on two B200s also passed all 21 checks, including all 13 reference cases. PP2 failed during warmup in the existing embedding/reward pipeline scheduler, which treats intermediate pipeline tensors as final embeddings. PP support would need a separate shared pipeline scheduler fix.

Reproduce the checks from the published model-card (starts its own server):

```bash
python3 test/registered/e2e/models/test_nemotron35_rerank.py
```

Server used for reference/speed checks:

```bash
python3 -m sglang.launch_server \
  --model-path nvidia/Nemotron-3.5-Rerank-8B-BF16 \
  --revision f88f8d9104726747791283ab156d2fcdb29e90a7 \
  --served-model-name nemotron-rerank \
  --host 127.0.0.1 --port 30001 --context-length 32768 \
  --max-running-requests 4 --max-total-tokens 32768 --mem-fraction-static 0.7
```

For the TP2 check, add `--tp-size 2` to the server command above.

Scores matched Transformers-based path (used as reference) with the same model checkpoint within atol=0.05, rtol=0.02.

Small repeated-input baseline; no image speed test or profiling. Run against the active server:

```python
import time
from concurrent.futures import ThreadPoolExecutor
from statistics import mean

import requests

url = "http://127.0.0.1:30001"
payload = {
    "query": "What is NVIDIA NeMo Framework?",
    "documents": [
        "NeMo Framework offers comprehensive functionalities for developing both LLMs and Multimodal Models.",
        "A biological foundation model designed to analyze and generate DNA, RNA, and protein sequences.",
    ],
    "return_documents": False,
}


def rerank_request():
    start = time.perf_counter()
    response = requests.post(url + "/v1/rerank", json=payload, timeout=120)
    response.raise_for_status()
    assert response.json()[0]["index"] == 0
    return time.perf_counter() - start


for repetition in range(3):
    for concurrency, count in [(1, 200), (4, 400)]:
        for _ in range(4):
            rerank_request()

        requests.post(url + "/flush_cache", timeout=120).raise_for_status()

        start = time.perf_counter()
        with ThreadPoolExecutor(concurrency) as pool:
            futures = [pool.submit(rerank_request) for _ in range(count)]
            latencies = [future.result() for future in futures]
        elapsed = time.perf_counter() - start

        print(
            repetition,
            concurrency,
            "requests/s", count / elapsed,
            "documents/s", 2 * count / elapsed,
            "mean ms", 1000 * mean(latencies),
        )
```

[by Claude Code] **Severity: functional | Confidence: High**

**Issue**

Image documents are sent as `input_ids`, so `BaseMultimodalProcessor.load_mm_data` decodes them to text and the HF processor tokenizes it again. The checkpoint template escapes control strings with a zero-width non-joiner, which the tokenizer drops, so the decoded text loses the escape. Control strings in user text then become real special tokens.

**Example**

With the checkpoint tokenizer and `PixtralProcessor`, the document `[{"type": "text", "text": "see <s>old</s> price"}, image]` is scored with the BOS and EOS token ids. With the text `"[IMG] figure"`, the request fails: "Prompt has 2 image placeholders but 1 image inputs were provided".

**Fix**

Render with `tokenize=False` and send `EmbeddingReqInput(text=prompts, image_data=...)`, so the template output is tokenized once. Add a CPU test with `<s>` in an image document.

[by Claude Code] **Severity: functional | Confidence: High**

**Issue**

`BaseMultimodalProcessor._call_processor` always calls the HF processor with `padding=True`. This checkpoint's `tokenizer_config.json` sets `pad_to_multiple_of: 8`, so each image document gets up to 7 trailing `<pad>` tokens. SGLang keeps them in `input_ids` and ignores the processor's `attention_mask`, so the bidirectional layers attend to the pads and `PoolingType.MEAN` averages them in. The Transformers reference and text-only documents have no pads.

**Example**

A 300x200 image with the text "plain text" gives 105 tokens in Transformers, but 112 tokens (7 `<pad>`) in SGLang. Small images shift the score the most.

**Fix**

For this model, drop positions where `attention_mask` is 0, or call the processor without padding for a single prompt. Add a CPU test that an image document has no `<pad>` tokens.

[by Claude Code] **Severity: functional | Confidence: High**

**Issue**

The checkpoint template uses `raise_exception` to reject an image in the query and more than one image in a document. That raises `jinja2.TemplateError`, not `ValueError`, so `OpenAIServingBase.handle_request` returns HTTP 500 and logs a stack trace for a bad client request. Only videos get the 400 check here.

**Example**

A query with an `image_url` part returns 500 "Internal server error: Queries must be text". A document with two images returns 500 "Internal server error: At most one image per document is supported".

**Fix**

Raise `ValueError` for both cases next to the video check, or catch `jinja2.TemplateError` around `apply_chat_template` and re-raise it as `ValueError`. Also list both limits in `rerank_models.mdx`.
