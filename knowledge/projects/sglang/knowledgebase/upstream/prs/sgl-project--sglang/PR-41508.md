# feat(router): add opt-in deterministic response cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/41508) · state: closed · merged: False

## Original PR description

## Summary

- add an opt-in deterministic exact-response cache to `sgl-model-gateway`
- restrict eligibility to authenticated, explicitly scoped, non-streaming greedy requests on supported HTTP endpoints
- isolate entries by namespace, authorization, caller scope, routing selectors, method, path, and byte-exact body
- bound entries with TTL, response-size, ready/in-flight limits, cancellation-safe singleflight, and LRU eviction
- clear cached responses through `/flush_cache` and reject unsupported IGW, PD, and gRPC configurations
- document that cache hits replay the original response body exactly, including IDs, timestamps, and usage metadata
