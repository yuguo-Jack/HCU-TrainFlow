# [Fix] diffusion: LoRA format alpha and rank scaling

[Upstream PR](https://github.com/sgl-project/sglang/pull/45833) · state: closed · merged: True

## Original PR description

## Motivation

Split from #44309 (adapter-state fixes stay there). Format and scaling bugs in `pipelines_core/lora`.

## Changes

- Fused-section `.alpha` keys are deferred with A/B, so per-section alpha is folded into the fused group instead of being stacked and crashing or losing scale.
- Fractional alpha is no longer truncated by `int()`.
- RSLoRA and `alpha_pattern` accept `lora_A`/`lora_B` keys without `.weight`.
- AI-toolkit Flux `.alpha` keys follow the renamed modules instead of being orphaned.
- `name.replace(".weight", "")` becomes `removesuffix`.
- AI-toolkit Flux keys the converter does not handle itself (double-block `img_mlp`/`txt_mlp`) keep their `double_blocks.` names, so `FluxArchConfig.param_names_mapping` maps them to `ff`/`ff_context`. They were renamed to `transformer_blocks.N.img_mlp.*`, which matches no layer, so MLP updates and their alpha were dropped.

## Tests

No new files. Extended `test_lora_peft.py`, `test_fused_lora_compose.py` (one parameterized test with distinct per-section alphas, checked against independent section deltas) and `test_lora_pipeline.py`. The 4 new tests fail on `main` and pass here. `test_ai_toolkit_flux_alpha_follows_renamed_modules` also checks an `img_mlp.0` module through the real `FluxArchConfig` mapping (fails without the converter change).

Modal CPU, LoRA unit files: 112 passed, 3 skipped (main: 107 passed). ruff, isort, codespell clean. No GPU run.
