## Modifications

<!-- Detail the changes made in this pull request. -->

**Installation guide (installation.mdx)**
- Added a selection table for Docker image vs. source install, explicitly recommending the Docker image for most users
- Added a torch_npu verification step: a deterministic command checking `torch.npu.is_available()` and computing a small tensor on device
- Added explanations: the DeepEP-compatible library is only needed for MoE with `--moe-a2a-backend deepep`; why NUMA balancing is disabled (to avoid memory-bandwidth overhead and latency jitter from page migration)
- Added a PD mixed vs. PD disaggregation comparison table, plus prerequisites for PD disaggregation (network reachability among the three components, accessible store address)
- Noted that the router command requires the `sglang-router` package (pre-installed in the Docker image; `pip install` needed for source installs)
- Added a "How do I provide model weights?" FAQ (HF_TOKEN auto-download or a local path), with per-command hints
- Points users to the supported models list and per-model deployment guides

**Quickstart (quick_start.mdx)**
- When `npu-smi` is not found, hints that the Ascend HDK driver needs to be installed first
- Added a "Next Steps" section at the end, linking to the installation guide, model tutorials, best practices, parameter tuning, and supported models
