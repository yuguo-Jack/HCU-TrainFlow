## Motivation

HCCL buffer sizes need manual tuning for each model and prefill workload. Size unset buffers automatically during NPU startup, before workers create communication groups, while preserving existing environment overrides.

## Modifications

- Estimate `HCCL_BUFFSIZE` from representative prefill rows, hidden size and dtype, with 1.25× headroom, 32 MiB rounding and a 64–1024 MiB range.
- Estimate `DEEPEP_HCCL_BUFFSIZE` using the normal-mode dispatch/combine formula only for MoE models using the `deepep` backend, EP > 1 and `normal` or `auto` mode. Preserve existing round and streaming settings and validate their bounds.
- Round the DeepEP requirement up to 32 MiB and raise an actionable startup error above the 4096 MiB automatic limit. Never silently clamp below the calculated requirement.
- Preserve explicit buffer values and the existing DeepEP-to-HCCL fallback precedence. Explicit overrides bypass unnecessary calculations; validate all proposed sizes before changing the environment.
- Enable sizing by default without adding environment controls. Log sizing decisions and document legacy overrides, MiB units and communication-group memory implications.
