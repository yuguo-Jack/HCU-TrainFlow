## Original PR description

kill_process_tree temporarily sets SIGCHLD to SIG_DFL to suppress teardown logs, but previously left that process-wide setting in place, including when the target PID no longer existed. Restore the caller handler in finally. Added POSIX tests for missing-parent and normal child cleanup; both failed before the fix and pass afterward. Validation: 2 focused tests on Linux, repository-pinned Ruff check and format, git diff --check.
