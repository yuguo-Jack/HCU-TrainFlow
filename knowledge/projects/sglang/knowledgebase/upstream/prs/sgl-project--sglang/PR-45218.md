# [Fix] test: Add logical_forward_mode to the KDA prefill-graph stand-in batch

[Upstream PR](https://github.com/sgl-project/sglang/pull/45218) · state: closed · merged: True

## Original PR description

## Summary

`test_kda_prefill_graph.py` fails on main with `AttributeError: 'types.SimpleNamespace' object has no attribute 'logical_forward_mode'`. sgl-project/sglang#34535 made `MambaAttnBackendBase._forward_metadata` read the new `ForwardBatch.logical_forward_mode` property. The test's `SimpleNamespace` stand-in copies `ForwardBatch` fields by hand and was missing it. This PR adds `logical_forward_mode=ForwardMode.EXTEND`, which is what the real property returns for a plain extend batch.

Bisected on an H200: the test passes at `33dd8f6a2e~1` and fails at `33dd8f6a2e`. With this fix it passes on `8e7601ae4a` (2 passed, 5 subtests), and the related mamba, GDN and KDA backend unit tests pass too.
