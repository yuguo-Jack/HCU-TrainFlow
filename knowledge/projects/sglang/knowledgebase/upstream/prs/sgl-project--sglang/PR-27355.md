File: `scripts/ci/amd/run_benchmark.sh` · line None

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Using `pkill -f "sglang.launch_server"` will unconditionally kill all `sglang.launch_server` processes running on the host machine. If the CI runner is shared or configured with multiple executors/workers running concurrent jobs, this will abort other active benchmark runs.

Since we export the unique `RESULT_FILENAME` environment variable for each run, we can precisely target and kill only the server process launched by this specific job by checking `/proc/<pid>/environ`.

```suggestion
    for pid in $(pgrep -f "sglang.launch_server" 2>/dev/null); do
        if grep -z -q "^RESULT_FILENAME=${RESULT_FILENAME}$" "/proc/${pid}/environ" 2>/dev/null; then
            kill -15 "$pid" 2>/dev/null || kill -9 "$pid" 2>/dev/null || true
        fi
    done
```

File: `scripts/ci/amd/generate_benchmark_matrix.py` · line 140

![medium](https://www.gstatic.com/codereviewagent/medium-priority.svg)

If any required key (such as `name`, `model-prefix`, `precision`, `runner`, `framework`, `model`, or `runs-on`) is missing in `benchmark-configs.yaml`, this script will raise a cryptic `KeyError` traceback, making CI failures harder to debug.

We can improve robustness by validating the configuration structure and catching `KeyError` to print a clean, descriptive error message.

```python
    for cfg in configs:
        if not isinstance(cfg, dict):
            print("ERROR: config entry is not a dictionary", file=sys.stderr)
            return 1
        name = cfg.get("name")
        if not name:
            print("ERROR: config entry is missing 'name'", file=sys.stderr)
            return 1
        if name_filter and name not in name_filter:
            continue
        for variant in cfg.get("variants", ["base"]):
            if variant_filter and variant not in variant_filter:
                continue
            try:
                rows.append(
                    {
                        "name": name,
                        "model_prefix": cfg["model-prefix"],
                        "precision": cfg["precision"],
                        "runner": cfg["runner"],
                        "framework": cfg["framework"],
                        "model": ov_model or cfg["model"],
                        "runs_on": cfg["runs-on"],
                        "variant": variant,
                        "tp": str(cfg.get("tp", 8)),
                        "ep": str(cfg.get("ep", 1)),
                        "isl": ov_isl or str(cfg.get("isl", 1024)),
                        "osl": ov_osl or str(cfg.get("osl", 1024)),
                        "dp_attn": (ov_dp or str(cfg.get("dp-attn", False))).lower(),
                        "conc_list": ov_conc or str(cfg.get("conc-list", "32")),
                    }
                )
            except KeyError as e:
                print(f"ERROR: config '{name}' is missing required field: {e}", file=sys.stderr)
                return 1
```
