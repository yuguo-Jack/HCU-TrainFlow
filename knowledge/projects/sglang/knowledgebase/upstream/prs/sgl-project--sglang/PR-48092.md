[Upstream PR](https://github.com/sgl-project/sglang/pull/48092) · state: closed · merged: True

## Original PR description

## Motivation

#44489 added a test in `test/registered/unit/test_model_overrides.py` that imports `ResolvedView` through `sglang.srt.arg_groups.overrides`, which only re-imports it. The `check-indirect-imports` pre-commit hook (added to main shortly before the merge) rejects that, so the Lint job fails on main and on every PR that runs `pre-commit run --all-files`:

```
test/registered/unit/test_model_overrides.py:2010: `ResolvedView` is imported from `sglang.srt.arg_groups.overrides`, which only re-imports it; import it from `sglang.srt.arg_groups.model_override_base`
```

## Modifications

- `test/registered/unit/test_model_overrides.py`: import `ResolvedView` from `sglang.srt.arg_groups.model_override_base` in `test_deterministic_aiter_decode_only_on_gfx950_without_mla`. No behaviour change.

## Checks

`python3 scripts/lint/check_indirect_imports.py test/registered/unit/test_model_overrides.py` passes (fails on main); isort / ruff / ruff format pass.
