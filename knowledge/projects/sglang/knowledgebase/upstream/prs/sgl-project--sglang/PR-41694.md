# [DCP] [HiCache] Restore complete hybrid checkpoints across DCP ranks

[Upstream PR](https://github.com/sgl-project/sglang/pull/41694) · state: open · merged: False

## Original PR description

**Stack 3/4.** Depends on #41693. Targets `main`, so the full diff is cumulative. [Incremental diff](https://github.com/Venkat2811/sglang/compare/70a39075a379ef6d9bee277b5737f9767ce6c48e...39e4d07b341dd50551e77214122e899b895a021a). Refreshed onto `4cca7fcd3e` on 16 October; remains draft. The reviewed recurrent-file dependency was replayed locally; #41692 itself was not changed.

## Motivation

A hybrid cache hit needs KV and a recurrent checkpoint at the same boundary on every required rank. A shared KV hit alone cannot establish a safe restore point.

This work grew out of experiments with Kimi-K3 serving configurations.

## Modifications

- Intersect sparse checkpoint endpoints across required ranks while preserving main's per-pool prefix bounds and deferred query beliefs.
- Identify recurrent DCP objects by owner and schema; require materialized host state pools.
- Preserve buffer-mode sidecar boundaries and the current PP query protocol. Missing state shortens reuse to a complete checkpoint.

The earlier chunked write-through insertion override is removed because main now handles it. DCP1 Mooncake object names remain unchanged. The cumulative recurrent-file changes from #41692 still intentionally invalidate incompatible old files. Live P/D is gated until the next stage; this PR does not add cross-layout conversion.

## Accuracy Tests

Before = MLA stage `70a39075a3`, which rejects hybrid DCP storage. Final stage = `39e4d07b34`. GPU campaigns used identical runtime code; final changes after the campaign exports only adapt/format test fixtures. No historical Kimi-K3 result is credited to this refresh.

Both SSD runs compare against cache-off references and test missing-state fallback. IDs match and measured logprob delta is zero. Cold disk reads are intentionally forced; these are correctness checks, not a claim of L2-equivalent latency.

20 CPU files, native four-rank hybrid failure contracts, Python/Rust GPU restore tests, docs validation and pre-commit passed. B200, hosted CI and Kimi-K3 were not rerun. The registered B200 lane still requires its own hosted run.
