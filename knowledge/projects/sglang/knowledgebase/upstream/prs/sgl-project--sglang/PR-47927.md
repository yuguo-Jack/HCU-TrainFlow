# [Fix] [AMD] mhc: Fix the mHC weight orientation across DSV4 layer boundaries on gfx1250

[Upstream PR](https://github.com/sgl-project/sglang/pull/47927) · state: closed · merged: False

## Original PR description



On gfx1250 the fused mHC read at the cross-layer boundary and in the non-CUDA decoder stage both get the projection weight in the transposed layout, but they passed fn_transpose depending on the call site, so one path read it in the wrong orientation. Pass fn_transpose=True on gfx1250 in both places.
