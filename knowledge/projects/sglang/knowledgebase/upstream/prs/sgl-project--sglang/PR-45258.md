# [Perf] function_call: Optimize Gemma4, Hunyuan, GigaChat3, and GigaChat35 streaming tool detectors to O(N)

[Upstream PR](https://github.com/sgl-project/sglang/pull/45258) · state: open · merged: False

## Original PR description

## Motivation

During token-by-token streaming of tool calls, `Gemma4Detector`, `HunyuanDetector`, `GigaChat3Detector`, and `GigaChat35Detector` repeatedly rescan the accumulated streaming buffer from index `0` on every token delta, resulting in quadratic $O(N^2)$ CPU overhead in the streaming detokenizer/parser path:

1. **`Gemma4Detector` (`python/sglang/srt/function_call/gemma4_detector.py`)**:
   - While streaming tool call arguments inside `<|tool_call>call:name{...}<tool_call|>`, `parse_streaming_increment` calls `_find_matching_brace(current_slice)` from `i = 0, depth = 1` on every chunk, and `_find_matching_brace` / `_parse_gemma4_args` / `_parse_gemma4_array` allocate `text[i : i + len(STRING_DELIM)]` at every character offset.
   - **Optimization**: Track incremental brace-scan state (`_brace_scan_pos`, `_brace_depth`, `_in_string_delim`, `_string_content_start`) across chunks so `_find_matching_brace` resumes from the previous scan cursor, and use `str.startswith(STRING_DELIM, i)` instead of per-character substring slicing.

2. **`HunyuanDetector` (`python/sglang/srt/function_call/hunyuan_detector.py`)**:
   - `_stream_args` re-runs `self.func_args_regex.finditer(args_text)` from position `0` on every chunk (even while an `<arg_value>` block is still open), slices `tail = args_text[last_closed_end:]` and `partial_value = tail[...]`, re-serializes `self._completed_args` via `json.dumps` on every chunk, and runs 5 full-string `.replace(...)` passes over the entire growing `safe_value`.
   - **Optimization**: Gate `func_args_regex.finditer` on `args_text.find(self.arg_value_end_token, av_search_from) != -1` starting from `self._last_closed_end`, cache serialized `self._completed_args_prefix`, cache the open `<arg_value>` offset (`_open_av_val_start`), and incrementally escape only the newly safe slice `args_text[safe_start:safe_end]` in $O(|\text{delta}|)$ time.

3. **`GigaChat3Detector` & `GigaChat35Detector` (`gigachat3_detector.py`, `gigachat35_detector.py`)**:
   - `GigaChat3Detector.parse_streaming_increment` re-runs `REGEX_FUNCTION_CALL.search`, `NAME_REGEX.search`, `ARGS_REGEX.search`, `cur_args.startswith(prev_args)`, and `json.loads(cur_args)` on incomplete JSON across every chunk.
   - `GigaChat35Detector.parse_streaming_increment` re-partitions `current_text` and re-runs `_GCML_INVOKE_RE.finditer` over the entire `invokes_body` on every chunk even when no closing `</｜GCML｜invoke>` tag has arrived.
   - **Optimization**: Cache header/argument offsets and incremental brace/string scan state in `GigaChat3Detector`, and advance an incremental `_scan_pos` cursor in `GigaChat35Detector` gated on `</｜GCML｜invoke>` presence in the unparsed tail.

## Modifications

- `python/sglang/srt/function_call/gemma4_detector.py`: Incremental `_find_matching_brace` cursor and `startswith(STRING_DELIM, i)` checks.
- `python/sglang/srt/function_call/hunyuan_detector.py`: Incremental `_stream_args` regex/tag cursor, cached `_completed_args_prefix`, and $O(|\text{delta}|)$ open-string escaping.
- `python/sglang/srt/function_call/gigachat3_detector.py`: Cached header/name/arguments offsets and incremental brace-depth scanner (`_advance_args_scan`).
- `python/sglang/srt/function_call/gigachat35_detector.py`: Incremental `_scan_pos` and `_eot_pos` tracking for `<｜GCML｜invoke>` blocks.
- `test/registered/unit/function_call/test_hunyuan_detector.py` & `test/registered/unit/function_call/test_function_call_parser.py`: Added unit tests covering incremental streaming with escaped characters, braces inside string literals, and split delimiter tags.
