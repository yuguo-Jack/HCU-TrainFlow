# [CI] radix-cache: Shrink unified radix cache unit tests and their config matrix

[Upstream PR](https://github.com/sgl-project/sglang/pull/45259) · state: closed · merged: False

## Original PR description

- Run config-independent tests on a few representative configs instead of all 19: `requires_representative_full` (Full, page size 1 and 4) and `requires_representative_aux` (Full, Full+SWA, Full+Mamba at page size 1 and 4, plus Full+SWA+Mamba). Tests whose bodies branch on page size, Mamba extra buffers, or the host transfer layout keep every config.
- Turn runtime `skipTest` config checks into `requires_*` decorators, so unsupported configs are not generated.
- Fold near-duplicate tests into `subTest` tables with the same assertions: lock-receipt misuse and unanchored-release failures, segment-lock fuzz seeds, LRU bounded refresh, Mamba checkpoint grid, and aborted Mamba load-back slots.
- Rerun under the Rust tree core only the classes that build a tree core through the backend switch.
- Share repeated setup through kit helpers (`_prefetch_until_staged`, `_hicache_chain`, `_evict_to_host`, `_init_load_back`, `_swa_l3_abort_fixture`, `_buffer_chain_leaf`, `CacheConfig.sw_pages`, `extra_key` / `cache_salt` on `match_prefix`, and others), and split five multi-scenario buffer-only tests into one test per scenario.
- Drop assertions that repeat another test on the same path or restate config; replace expected write intents computed by the pipeline under test with literal pools; run the bigram L3 prefetch test against the real cache controller.
- Drop six weak tests: `test_shared_prefix_split`, `test_swa_evict_internal_tombstone`, the cache-salt and LoRA event parentage split tests (their field checks move to the remaining salt and LoRA tests), `test_scheduler_hicache_load_back_rolls_back_mamba_on_capacity_failure`, and `test_write_through_eviction_counts_unbacked_tokens`.
- Test cases go from 2734 to 1709 across the six topic modules and the Rust rerun; every remaining case keeps its outcome.
