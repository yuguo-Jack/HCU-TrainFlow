# feat(hicache): support separate L2 pool ratios

[Upstream PR](https://github.com/sgl-project/sglang/pull/30199) · state: closed · merged: False

## Original PR description

Add --kv-hicache-ratio and --mamba-hicache-ratio so KV and Mamba L2
  pools can be sized independently.

  ## Motivation

  Hybrid KV/Mamba workloads may need different L2 host pool sizing for KV
  cache and Mamba state cache. A single `--hicache-ratio` forces both
  pools to use the same ratio, which makes it harder to tune host memory
  usage for mixed cache layouts.

  ## Modifications

  - Add `--kv-hicache-ratio` and `--mamba-hicache-ratio`.
  - Default both new ratios to `--hicache-ratio` when unset, preserving
  existing behavior.
  - Route KV host pool sizing through the resolved KV ratio.
  - Route Mamba host pool sizing through the resolved Mamba ratio.
  - Apply the KV ratio to decode-side offload host pool sizing.
  - Add server args unit coverage for defaulting, override, validation,
  and `--hicache-size` warning behavior.
  - Update HiCache and server argument documentation.
