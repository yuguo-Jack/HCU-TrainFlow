# [Feat] [NPU] disaggregation: Support PD KV checksum

[Upstream PR](https://github.com/sgl-project/sglang/pull/41056) · state: open · merged: False

## Original PR description

## Motivation

Enable the existing `--disaggregation-enable-kv-checksum` diagnostic on Ascend NPU for prefill/decode disaggregation.

## Modifications

- Select the checksum backend from the actual index tensor's device. NPU calls `sgl_kernel_npu.mem_cache.checksum.adler32_strided_checksum`; the existing CUDA kernel path is preserved.
- Move the Triton-Ascend implementation and its six direct kernel tests to [sgl-kernel-npu `f933a46`](https://github.com/sherdavincl9/sgl-kernel-npu/commit/f933a46887d6a3254b5aa19d714f4f15a2926ffd). The kernel follows the same ordered raw-byte Adler-32 semantics.
- Keep framework integration and PD service tests in SGLang. No additional device-wide synchronization or independent early-send fix is included.

The installed `sgl_kernel_npu` package must include the new checksum module.

## Validation

Tested on **Ascend A3, Qwen3-32B, prefill TP2 + decode TP2**, using SGLang `05dfe4c85d` with kernel `f933a46`:

- **6 kernel tests passed:** independent `zlib.adler32` reference, byte tails, descriptor ordering and duplicates, empty components, multiple dtypes, modular overflow, corruption, and invalid descriptors.
- **2 framework integration tests passed:** page/FIA layout mapping, nested state descriptors, and NPU backend dispatch.
- **3 PD service tests passed:** varied input lengths through the 10000-token case, chunked prefill, cached-prefix reuse, and intentional checksum corruption followed by successful recovery.

Service validation includes upstream early-send fix #41395. These tests validate checksum and transfer integrity for this configuration; no model-task accuracy benchmark or A5 validation is claimed.
