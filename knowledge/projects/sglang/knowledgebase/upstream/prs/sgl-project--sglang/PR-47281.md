# [Feat] sensenova_loop: Add multimodal Loop and mHC inference

[Upstream PR](https://github.com/sgl-project/sglang/pull/47281) · state: open · merged: False

## Original PR description

## Motivation

Add text, image, and video support for SenseNova Loop (`sensenova_loop`), based on Qwen3.5 with shared layers and multi-stream hyper-connections (mHC).

## Modifications

- Reuse the Qwen3.5 decoder, vision encoder, and multimodal processor.
- Execute repeated layers with shared weights and separate KV/GDN states for each visit.
- Add the mHC router with log-space Sinkhorn, checkpoint loading, model registration, tests, and launch documentation.

## Accuracy Tests

Tested on one H800 80GB with BF16, TP=1, PP=1, and fixed ungated loops.

- 20 tests and 12 subtests passed at `bfd17017`; pre-commit passed.
- Text, image, and video API smoke tests passed.

Earlier comparison against the HF reference using the upstream FA3 path:

| Input | Vision cosine | Final-prefill logits cosine |
| --- | ---: | ---: |
| OCR | 0.989706 | 0.994451 |
| Wide image | 0.991788 | 0.998371 |
| Two images | 0.990714 | 0.984661 |
| Video | 0.999495 | 0.999324 |
| 7 text prompts | — | 0.998292–0.999888 |

These compare complete output tensors. The HF comparison has not been rerun after the cleanup commits; task-level accuracy evaluation is pending. The checkpoint and HF reference are not public yet.
