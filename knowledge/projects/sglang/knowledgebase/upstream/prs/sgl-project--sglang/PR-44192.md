# [CI] glm5.2: Temporarily disable PD HiSparse+MTP B300 test

[Upstream PR](https://github.com/sgl-project/sglang/pull/44192) · state: closed · merged: True

## Original PR description

## Summary

`test/registered/e2e/models/test_dsa_glm52_hisparse.py` was rewritten in #37771 into a 1P1D GLM-5.2-NVFP4 test with EAGLE MTP and HiSparse, and it has failed both times it has run on 8×B300. On the first GSM8K batch the decode server hits `NaN detected! verify: target model logits` in EAGLE verify and aborts, and the test is killed with exit code 137. It failed this way on #37771's own CI run before merge ([job](https://github.com/sgl-project/sglang/actions/runs/38354570978/job/115154648003)), and it now breaks `extra-b-test-8-gpu-b300` for unrelated PRs on top of main.

This PR disables the test until the NaN is fixed, the same way `test_deepseek_v41_pd_cp_dspark.py` is disabled: `disabled=` in `register_cuda_ci(...)`, plus `@unittest.skip` so selective reruns skip it too. Test-only change; revert to re-enable.
