# [Perf] overlap: Stash the speculative relay in one launch

[Upstream PR](https://github.com/sgl-project/sglang/pull/48224) · state: open · merged: False

## Original PR description

Stacked on #47324; only the last commit is new here.

## Motivation

With the overlap scheduler, every speculative decode step ends with `FutureMap.stash`, which hands the step's outputs to the next step's resolve. It wrote each relayed buffer with its own `index_put`: bonus tokens with a dtype copy, top-k values and indices, hidden states, draft probabilities and the DSA seed. At one request each of those launches sits on the critical path between two steps.

## Modifications

- `scatter_spec_extras` (`gather_spec_extras.py`), the mirror of `gather_spec_extras`, writes every relayed buffer in one launch, casting each to its buffer's dtype. It shares the gather's row kernel. Off the GPU it keeps the `index_put`s.
- `FutureMap.stash` (`overlap_utils.py`) calls it once. Buffers the step does not relay are skipped, as before. A source with fewer rows than indices raises, as the `index_put` did.
- The resolve's gather also takes the DSA seed, one indexing launch fewer.

Six fewer launches per speculative step. On by default; no new flag.

`stash` is also the relay of every non-speculative overlap decode step, which hands over only the next tokens. There it now writes them with the same kernel, one launch for one.

Tests:
- `test_gather_spec_extras.py`:
  - the scatter against the `index_put`s it replaces: mixed dtypes, a float downcast, the seed, non-contiguous rows, bonus tokens alone (the non-speculative relay);
  - empty rows, a width mismatch, and fewer rows than indices;
  - the gather with the seed, with and without hidden states;
  - the CPU fallback, without a GPU.
- CPU `test_dspark_step_inputs_once.py`: the CPU stash path.

Related:
- #41170 (open) also fuses the relay stores, adding single-request views.
- #31329 (closed) proposed a separate CUDA-only scatter kernel with a fallback inside `stash`. This PR reuses the gather's row kernel and keeps `stash` a single call on every device.
- #47200 (open, draft) keeps unchanged relay rows in place behind a CUDA master switch.
