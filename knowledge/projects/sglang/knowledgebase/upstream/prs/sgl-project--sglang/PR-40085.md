# [sgl-router] Policy reorg 3/N: bucket-engine core (Policy::pick, admission, load-only policies)

[Upstream PR](https://github.com/sgl-project/sglang/pull/40085) · state: closed · merged: False

## Original PR description

Stacked on the 2/N load-view PR. Adds `POLICY_DESIGN.md` and the first slice of its implementation, built beside the current selection path in `src/policy_reorg/`. Nothing calls it yet; the directory moves to `src/policies/` once the old path is deleted.

## Modifications

- `policy_reorg/mod.rs`: `Policy::pick(engines, &PickRequest) -> BoxFuture<PickResult>`, `PickRequest`, `PickError`, `build_policy` / `build_decode_policy`. Migrated configs get the acceptance checks the current path runs implicitly (capacity, per-bucket pending budget, `--filter overloaded`).
- `policy_reorg/admission.rs`: `EngineAdmission` with `AllowAll`, `CapacityAdmission`, `PendingPrefillAdmission`, `InFlightLimitAdmission`, `QueueLimitAdmission`, `AllOfAdmission`; `Admission::select` runs a policy's selection at the configured placement.
- `policy_reorg/{power_of_two,least_load,random,round_robin}.rs`: the load-only policies. One `PowerOfTwoPolicy` serves prefill and decode by comparing on the request's stage; `LeastLoadPolicy` keeps the `load_based` scoring and tie-break with a per-instance rotor.
- `state/engine_load/view.rs`: `LoadView`, one lazily captured snapshot per selection pass.
