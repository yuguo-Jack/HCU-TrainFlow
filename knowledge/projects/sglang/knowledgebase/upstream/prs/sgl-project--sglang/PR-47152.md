# [CI] [AMD] pr-test: Move the Kimi-K2.5 MXFP4 BCG test to nightly

[Upstream PR](https://github.com/sgl-project/sglang/pull/47152) · state: closed · merged: True

## Original PR description

## What

Moves `test_kimi_k25_mxfp4_bcg_mi35x` from `stage-c-test-large-8-gpu-amd-mi35x` to the `nightly-amd-8-gpu-mi35x` suite. `test_kimi_k25_mxfp4` stays in PR CI.

## Why

The MI35x 8-GPU stage-c job brings up two Kimi-K2.5 MXFP4 servers on every PR: the base test (~12 min) and its BCG variant (~7 min). CUDA keeps one Kimi model (K3, on B300) in base-c. Keeping the base test covers Kimi-K2.5 MXFP4 per PR, and the BCG variant runs once a day. This saves about 7 min of 8-GPU MI35x time per PR run.

## Notes for the reviewer

- `nightly-amd-8-gpu-mi35x` is the suite that the nightly `nightly-accuracy-8-gpu-mi35x` job already runs. Its accuracy step takes about 20 min against a 180 min timeout, with 2 h per file.
- The stage-c MI35x suite is already a single shard, so there is no matrix change.
