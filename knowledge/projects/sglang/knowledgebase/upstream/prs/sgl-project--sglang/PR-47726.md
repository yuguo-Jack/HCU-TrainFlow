# [Chore] rust: Pin the sgl-model-gateway toolchain to 1.92

## Original PR description

The rust workspace and sgl-router already pin 1.92; the gateway still asked for 1.90 in both its rust-toolchain.toml and its e2e Dockerfile.

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

 The repo has three Rust projects with their own toolchain pins. rust/ and sgl-router/ already pin 1.92, but sgl-model-gateway/ still asked for 1.90 — so a developer or CI job building the gateway could end up on a different rustc than everything else, and the e2e Dockerfile baked in yet another pin. Unify all of them on 1.92.
