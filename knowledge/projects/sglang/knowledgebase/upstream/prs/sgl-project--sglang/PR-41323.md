# [Fix] Serialize UnreducedOutput payloads in the non-intrusive dumper

[Upstream PR](https://github.com/sgl-project/sglang/pull/41323) · state: closed · merged: False

## Original PR description

## Problem

Since #41196, decoder layers hand `hidden_states` across the layer boundary wrapped in `UnreducedOutput` while its all-reduce is deferred to the next layer's `prepare_attn`. The non-intrusive dumper's value converter does not recognize the wrapper, so `non_intrusive__model.layers.N.inputs.1` dumps silently vanish for every layer > 0 (layer 0 survives because its input comes from `embed_tokens` as a plain tensor).

This fails `test_nightly_precision_regression` with:

```
zai-org/GLM-5.2-FP8: ERROR - no non-initial transformer layer input dumps found
```

Repro: nightly run [36145732791](https://github.com/sgl-project/sglang/actions/runs/36145732791/job/108106450702) (sha `2f5c9ac4`); the previous nightly at `77983865` passed and #41196 is inside that window.

## Fix

- `_SGLangPlugin.convert_value`: serialize `UnreducedOutput` as `{"": value.partial}`. The anonymous key keeps the caller's sub-name (`layers.N.inputs.1`), so the dump names the nightly test filters on are unchanged. The payload is dumped **as-is** — running the owed collective from inside a hook would alter the execution being measured.
- `_NonIntrusiveDumper._convert_value`: route tuple/list elements through the same converter so `(UnreducedOutput, residual)` outputs keep their positional `.output.0` / `.output.1` names instead of collapsing/dropping.
- Nightly test: `_assert_fused_tp_layout` → `_assert_deferred_tp_layout`, diagnostics reworded ("post-fusion" → "post-reduction"). Assertion strength unchanged — these checks prove a TP-partial→replicated layout transition across the deferred-allreduce boundary, not which kernel executed.

No baseline/schema impact: the comparator only compares `self_attn.inputs.hidden_states` (post-reduction, unchanged semantics), and layout validation runs before any baseline upload.

## Tests

- New `test_unreduced_output_wrapper_dumped_as_payload` in `test_dumper.py`: wrapped positional input dumped under its own name, wrapped tensor in tuple output keeps positional numbering, pre-hook snapshot survives in-place payload mutation, and the wrapper still reaches the consumer untouched.
- `TestNonIntrusiveDumper`: 12 passed locally (CPU). Remaining `test_dumper.py` failures locally are environmental only (no accelerator / zmq / distributed fixtures on a CPU relay host).
