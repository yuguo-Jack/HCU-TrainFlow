# [CI] [NPU] precise-test: run only the recommended multimodal_gen cases

[Upstream PR](https://github.com/sgl-project/sglang/pull/46014) · state: closed · merged: True

## Original PR description

## Motivation

Follow-up to #45955, which added the recommendation side for `multimodal_gen` (per-suite `should_run_*` / `only_tests_*` outputs, case-level buckets and the baseline safety gate) but deliberately left the two multimodal jobs consuming nothing, so they still ran their full suite on every PR.

This PR closes the loop: the jobs now honor the bucket, so a PR only runs the multimodal cases its diff affects.

## Changes

`.github/workflows/pr-test-npu.yml`, both `multimodal-gen-test-1-npu-a3` and `multimodal-gen-test-4-npu-a3`:

- add `recommend-tests-from-coverage` to `needs` and gate the job on `should_run_* != 'false'` (same pattern as the `base-b`/`base-c` jobs);
- in `Run test`, join the `only_tests_*` lines into a pytest `-k` expression and pass it to `run_suite.py`: `[case_id]` for parametrized cases, file stem for standalone files;
- fail the step if an entry looks like a path (contains `/` or ends in `.py`): the bucket contract is per-case `-k` tokens, and a path would select zero tests while pytest exit 5 is treated as success;
- log whether a filter was applied or the shard runs its full assignment.

No shared `multimodal_gen` runner change: `run_suite.py` already accepts `-k`, ANDs it with the shard's own case filter, and treats a standalone file that collects nothing (exit 5) as success.

## Fallback semantics

The filter is left empty (full suite, previous behavior) when the recommendation cannot be trusted:

- recommend job skipped (coverage mode, non-PR event) or any of its steps failed, so the outputs are missing;
- precision mode disabled, or nothing recommended for the suite;
- the safety gate forces a full suite (baseline missing/unreadable/has no `multimodal_gen` keys, or a case/standalone file is absent from the baseline).

Note this only takes effect once the rebuilt coverage baseline contains multimodal case-level keys; until then the safety gate keeps both suites on the full-suite path.

## Verification

- YAML parses, no editor diagnostics;
- reproduced the bucket -> `-k` contract with the real `testcase_configs_npu.py` (7 cases for `1-npu`; 6 cases + 1 standalone for `2-npu`);
- pytest 9.1.1: `-k "[case_id]"` selects exactly one case and does not match `[case_id_v2]`; case ids containing `.` work; empty `"${FILTER_ARGS[@]}"` expands to no argument;
- shell paths exercised under `bash -eo pipefail`: filtered, empty (full suite), and path-token (guard fails the step).
