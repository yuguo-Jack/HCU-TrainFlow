# [CI] tests: Fork the gloo exchange test's ranks from a preloaded forkserver

[Upstream PR](https://github.com/sgl-project/sglang/pull/44679) · state: closed · merged: True

## Original PR description

Stacked on #44622 (which adds `TestSyncRowExchangeGloo`); this PR's diff is the one commit on top of it, and it retargets to `main` when #44622 merges.

## Motivation

`TestSyncRowExchangeGloo` starts each gloo rank from a `spawn` context, so every rank is a fresh interpreter that re-imports the whole package before it exchanges a single row. On a small CPU runner that import dominates the test.

## Modifications

The ranks start from a `forkserver` context that preloads the test module, so the import happens once in the server and each rank forks from it. The forkserver process is single-threaded, so ranks fork from a clean interpreter rather than from the multi-threaded test process. Worlds, rounds and assertions are unchanged; the comment about the runner's memory cap is reworded since it no longer depends on spawning.

## Test plan

- `TestSyncRowExchangeGloo` on top of #44622: passes under `pytest` (1 passed) and as `python3 test_dp_attn.py TestSyncRowExchangeGloo` (OK), the way the CPU test runner invokes it.
- Cost, on four pinned cores at the 8-rank world: about 84 CPU-seconds with `spawn`, about 8 with `forkserver`; peak resident memory about 7.8 GB either way, so the world cap is kept.
- `black`, `isort`, `ruff check --select=F401,F821,F823,UP037` clean on the changed file.
