# [rust-processor] Share the reasoning splitter and tool constraint across hosts

[Upstream PR](https://github.com/sgl-project/sglang/pull/42996) · state: closed · merged: True

## Original PR description

First of a stack that serves the router's `/v1/completions` and `/v1/chat/completions` through the engine's `/generate`, behaving exactly like the Python engine's own routes. Stacked on #42666. This PR is a refactor with no behavior change.

## Modifications

- `parser/mod.rs` is split by concern: `reasoning.rs` holds the reasoning splitter, the one-shot split and the reasoning-parser names, and `tools.rs` builds the `tool_choice` constraint and maps tool-parser names. `aliases.rs` is folded into these two.
- sglang-server and sglang-renderer drop their identical copies of these and call the processor.

## Checks

- `cargo test --workspace` in `rust/` passes. The parser tests move with their code, and overlapping ones are merged.
- clippy and fmt are clean.
