# Build Mamba host pools from device buffer infos

[Upstream PR](https://github.com/sgl-project/sglang/pull/43596) · state: closed · merged: True

## Original PR description

## Motivation

Capture committed Mamba buffers during host assembly. Transfers then use the temporal, convolution and extra checkpoint tensors directly, removing reads of the device pool and its private sibling list. Keep the existing kernels, capacity rules and empty PP stages.

This is independent of the DSA declaration migration and introduces only fields consumed by the Mamba host.

Validation: cache and transfer regression passed 3275 tests and 4051 subtests. Kimi ordinary/direct/unified and Qwen GDN ordinary/unified match main exactly in all six corresponding input/output score and token phases, including two real host-only restores per run. Kimi TP1/PP2 and TP2/PP2 also match main across all six phases and two host-only restores. Qwen GDN MTP also matches main in all six phases and two host-only restores. Final test import ordering was checked separately with the staged-write-back module.
