# [Feat] cohere-asr: Support CohereLabs/cohere-transcribe-03-2026

[Upstream PR](https://github.com/sgl-project/sglang/pull/47049) · state: open · merged: False

## Original PR description

## Motivation

[`CohereLabs/cohere-transcribe-03-2026`](https://huggingface.co/CohereLabs/cohere-transcribe-03-2026) is a 14-language ASR model: a 48-layer Fast Conformer encoder and an 8-layer Transformer decoder that cross-attends to it. SGLang has no implementation of it. Today the server dies while parsing the config:

```
AttributeError: 'CohereAsrConfig' object has no attribute 'hidden_size'
```

The checkpoint nests every shape inside `encoder` / `transf_decoder` / `head` dicts, so the generic shape derivation finds nothing. Past that, there is no model, multimodal processor, or transcription adapter, and the transformers fallback only covers decoder-only `ForCausalLM` architectures.

## Modifications

The model follows the `models/whisper.py` encoder-decoder layout. `pad_input_ids` prepends one placeholder token per encoder frame, so `prepare_encoder_info_extend` reserves that many cross-attention KV slots. The decoder's self- and cross-attention use `RadixAttention` (layer ids `i` and `decoder_layers + i`). The Conformer's self-attention adds a relative-position term (`matrix_bd`) that `RadixAttention` cannot express. The encoder therefore runs as plain batched matmuls outside the KV cache and claims no layer ids, so `num_attention_layers = 2 * decoder_layers`.

**New files**
- `configs/cohere_asr.py`: flattens the decoder shapes onto the top-level config. It sets the served context to the combined encoder + decoder row length; the checkpoint's own `max_seq_len` (1024) counts decoder positions only and would otherwise shadow it. It defaults dtype to bf16, because the checkpoint declares none and `auto` would end at fp16. `cohere_asr_encoder_seq_len()` is the integer mirror of the 8x conv subsampling and sizes the placeholder span.
- `models/cohere_asr.py`: Conformer encoder, cross-attending decoder, head tied to the token embedding (with bias). `load_weights` also walks `named_buffers()`, because the BatchNorm running stats and the decoder position table are buffers.
- `multimodal/processors/cohere_asr.py`: mel features from the checkpoint's own feature extractor, trimmed to the valid frame count. The extractor emits one extra zero-filled stft frame; trimming it lets the single-clip encoder run unmasked with output identical to the reference's masked path. The processor also builds the language-specific decoder prompt.
- `transcription_adapters/cohere_asr.py`: 35 s chunking (the model's `max_audio_clip_s`). Language is explicit: the model does no detection, and the request defaults to `en`.

**Shared-code changes**
- `mem_cache/allocation.py`: **the same hunk as #39040, byte-for-byte.** An encoder-decoder KV row is `[encoder_len][decoder tokens]`, while `batch.seq_lens` counts only the decoder side. Paged decode allocation must work in row positions. Without this hunk, on XPU (`page_size` 128) the scheduler dies on the first cohere request whose decode crosses a KV page. Because the hunks are identical, whichever PR merges second rebases cleanly. `page_size == 1` (CUDA's default) never reaches this code.
- `utils/hf_transformers/tokenizer.py`: `_fix_added_tokens_encoding` probes every public tokenizer attribute but caught only three exception types. `CohereAsrTokenizer.max_len_sentences_pair` raises `AssertionError`, because the tokenizer rejects pair sequences, and that aborted server startup. A getter that raises now just means "not a special-token string", and discovery continues.
- `transcription_adapters/base.py`, `serving_transcription.py`: new `chunk_separator()` adapter hook used when long audio is split. It defaults to `""`, so Whisper (which emits a leading space per chunk) and every other adapter are byte-identical. cohere returns stripped chunk text and needs `" "` (`""` for zh/ja), or the words at each seam fuse.
- `arg_groups/attention_hook.py`, `arg_groups/model_override_base.py`: the Whisper-only radix-cache-disable and flashinfer-default guards now also cover cohere-transcribe, which pads its prompt with placeholder encoder tokens in the same way.
- `configs/model_config.py`: registers the arch as audio, encoder-decoder and multimodal, and adds the layer-id count above.
- Docs: added to both tables in `supported-models/multimodal_language_models.mdx`. The checkpoint's remote-code processor imports **`librosa`**, which SGLang does not depend on, so the docs say to install it.

**Serving**
```bash
pip install librosa
python -m sglang.launch_server --model-path CohereLabs/cohere-transcribe-03-2026 \
  --trust-remote-code --enable-multimodal
curl http://localhost:30000/v1/audio/transcriptions \
  -F file=@audio.wav -F model=cohere-transcribe -F language=en
```

## Accuracy Tests

Intel Arc Pro B70, TP 1, `--attention-backend intel_xpu`, `docker.io/intel/sglang-dev:latest` (2026-10-27, `main@7fe5b127e4`, torch 2.14.0+xpu, transformers 5.19.0) with this branch overlaid, plus `librosa`. `lmms_eval --model sglang_asr` (the `/v1/audio/transcriptions` path), `openslr_librispeech_other`, `num_concurrent=1`, seed 42, greedy.

| Run | WER ↓ | Requests |
|---|---|---|
| 50 samples | 1.9759 | 50 × HTTP 200 |
| full set (2939) | 2.3486 | 2939 × HTTP 200, 0 non-2xx, 0 empty transcripts |

For reference, on the same harness: Qwen3-ASR-1.7B 3.35, GLM-ASR-Nano 4.34, granite-speech-3.3-8b 15.07.

Numerics: with the checkpoint weights loaded directly, the encoder matches the HF remote-code `ConformerEncoder` at 4e-7 relative error in fp32, and bit-identically at odd mel-frame counts. (Observed on transformers 5.12: the remote model's own `from_pretrained` left most parameters at random init, so its `generate()` was not usable as a reference.)

Functional (same stack, `SGLANG_DEBUG_MEMORY_POOL=1`, so the paged allocator asserts its page invariants on every alloc/free):
- 11 s and 4 s clips are correct; a 55 s clip is chunked into two requests and stitched.
- 8 concurrent 55 s clips give 8 identical transcripts. `verbose_json` and `text` formats work, `language=fr` is honored, a missing language defaults to `en`, and `language=xx` returns HTTP 400 with the server staying up.
- After 30 s idle the pool-leak invariant reports clean, with no negative token usage.
- A/B with `main`'s `allocation.py`: the 55 s clip kills the scheduler in `free_segment`'s page-consistency assertion (`paged.py`).
- Whisper-large-v3 regression on the same stack (it shares the allocator, guards and chunk join): correct transcripts, `""`-joined chunks, 4 concurrent identical, no errors.

## Speed Tests and Profiling

Not a speed change. For scale: the full 2939-utterance set took 34 min 55 s end to end on one B70 at `num_concurrent=1`.

## Unit tests

- `test/registered/unit/models/test_cohere_asr_subsampling.py` (new): `cohere_asr_encoder_seq_len()` equals the real conv-stack output length for odd and even frame counts up to the 35 s maximum. Dropping one stride-2 stage from the formula fails 11 of 13 lengths.
- `test_serving_transcription.py`: cohere chunk transcripts are space-joined, but not for zh. Fails on `main`'s `serving_transcription.py`.
- `test_hf_transformers.py`: a tokenizer property that raises is skipped, and discovery continues past it. Fails on `main`'s `tokenizer.py`.
- The allocator hunk is #39040's, and so is its test. #39040's `test_encdec_paged_kv_page_accounting.py`, run against this branch, passes 18/18 (129 subtests); with `main`'s `allocation.py`, 119 cases fail. That run needed the fixture refresh noted on #39040: today's `main` reads `batch.device` and `tree_cache.supports_prefix_sharing()`.
