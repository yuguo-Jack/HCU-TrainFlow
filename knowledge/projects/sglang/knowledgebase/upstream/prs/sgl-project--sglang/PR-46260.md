# [Fix] sgl-router: Bump tokio for RUSTSEC-2026-0386

[Upstream PR](https://github.com/sgl-project/sglang/pull/46260) · state: closed · merged: True

## Original PR description

`cargo deny` (tier-1 lint) now fails on every PR touching sgl-router: tokio 1.48.0 in `sgl-router/Cargo.lock` has the AsyncFd I/O-safety advisory [RUSTSEC-2026-0386](https://rustsec.org/advisories/RUSTSEC-2026-0386).

## Modifications
- Lockfile-only bump: tokio 1.48.0 → 1.54.1 and tokio-macros 2.6.1 → 2.7.2 (`cargo update -p tokio`). The advisory lists >=1.53.3 as fixed.

## Tests
- `sgl-router`: `cargo build --all-targets` and `cargo test` pass (1467/1467).
