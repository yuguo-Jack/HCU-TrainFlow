## Motivation

Add an opt-in AITER FlyDSL dual-wave FP8 MLA prefill dispatch while preserving
the existing ASM path when FlyDSL is disabled.

## Modifications

- Add the `SGLANG_AITER_FLYDSL_FP8_PREFILL_ATTN` feature flag, disabled by
  default.
- Build only the metadata required by the selected path.
- Quantize BF16 Q/K/V per tensor and dispatch
  `flydsl_flash_attn_fp8_func` for supported shapes.
- Fall back to the existing dispatch for unsupported FlyDSL shapes.
- Preserve the existing ASM path when FlyDSL is disabled.

Enable the FlyDSL FP8 prefill path with:

```bash
SGLANG_AITER_FLYDSL_FP8_PREFILL_ATTN=1
```

`SGLANG_AITER_FP8_PREFILL_ATTN` is enabled by default.

## Accuracy Tests

GSM8K (1,319 questions, 5-shot), Kimi-K3 TP8/DCP8 on 8× MI355X:

| Configuration | Accuracy | Invalid |
| --- | ---: | ---: |
| BF16 MLA prefill | 0.951 | 0.001 |
| FlyDSL FP8 prefill | 0.960 | 0.001 |
