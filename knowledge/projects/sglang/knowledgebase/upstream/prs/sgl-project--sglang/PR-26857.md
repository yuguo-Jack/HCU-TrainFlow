## Code Review

This pull request introduces two new fused Triton kernels (`fused_sigmoid_mul` and `fused_gate_sigmoid_mul_add`) to optimize gating operations in Qwen3.5 and Qwen2 MoE models, along with corresponding benchmarks and unit tests. It also updates the TRT-LLM MHA backend to support draft extend v2 in speculative decoding. The reviewer feedback focuses on improving robustness, specifically by adding CPU fallbacks for the new Triton kernels to prevent crashes on CPU environments, ensuring `use_fused_gate` is disabled on CPU, and replacing `.squeeze()` with `.flatten()` on the gate weight tensor to avoid unexpected dimension reduction.

The `fused_sigmoid_mul` Triton kernel is not supported on CPU. When running Qwen3.5 on CPU, calling this function directly will result in a crash. Adding a CPU fallback ensures robust CPU execution support.

```python
def fused_sigmoid_mul(
    attn_output: torch.Tensor,
    gate: torch.Tensor,
) -> torch.Tensor:
    """
    Fused sigmoid-mul for attention output gating.

    Equivalent to: attn_output * sigmoid(gate)
    """
    if attn_output.device.type == "cpu":
        return attn_output * torch.sigmoid(gate)

    out = torch.empty_like(attn_output)
```

The `fused_gate_sigmoid_mul_add` Triton kernel is not supported on CPU. Adding a CPU fallback using eager PyTorch operations ensures that the function can be safely called on CPU tensors without crashing.

```python
def fused_gate_sigmoid_mul_add(
    hidden_states: torch.Tensor,
    gate_weight: torch.Tensor,
    shared_output: torch.Tensor,
    final_hidden_states: torch.Tensor,
) -> None:
    """
    Fused gate-sigmoid-mul-add for MoE shared expert gating.

    Equivalent to:
        gate = hidden_states @ gate_weight
        final_hidden_states += sigmoid(gate).unsqueeze(1) * shared_output
    """
    if hidden_states.device.type == "cpu":
        gate = hidden_states @ gate_weight
        final_hidden_states += torch.sigmoid(gate).unsqueeze(1) * shared_output
        return

    num_tokens, hidden_dim = hidden_states.shape
```

File: `python/sglang/srt/models/qwen2_moe.py` · line 516

![medium](https://www.gstatic.com/codereviewagent/medium-priority.svg)

Using `.squeeze()` on the weight parameter can be risky if any dimension is unexpectedly 1 (e.g., in test/toy cases with a hidden dimension of 1, it would squeeze both dimensions to a 0D scalar). Using `.flatten()` is a safer and more robust way to convert the 2D weight of shape `[1, hidden_dim]` to a 1D tensor of shape `[hidden_dim]`.

```suggestion
                fused_gate_sigmoid_mul_add(
                    hidden_states,
                    self.shared_expert_gate.weight.flatten(),
                    shared_output,
                    final_hidden_states,
                )
```
