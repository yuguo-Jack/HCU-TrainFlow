# [Doc] cookbook: Add LFM3 cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/46859) · state: closed · merged: True

## Original PR description

## Summary

Adds the LFM3 cookbook page (companion to #46858), covering the text-only and vision-language variants:

- `docs/src/snippets/configs/LiquidAI/lfm3.jsx` — config for the shared Deploy/Playground engines: 22 cells (11 hardware families × text/VL), BF16, single-node TP1, `--trust-remote-code` and default parser flags (`--reasoning-parser auto` / `--tool-call-parser auto`, which resolve `qwen3` / `qwen3_coder` from the LFM3 chat template)
- `docs/src/snippets/configs/LiquidAI/lfm3-benchmarks.jsx` — GSM8K on H200: 93.63% (sgl-eval full 1319, temp 1.0 / top_p 0.95, 100% stop rate)
- `docs/cookbook/autoregressive/LiquidAI/LFM3.mdx` — page: Deploy, Playground (TP override / PD disagg / HiCache), model introduction, configuration tips, advanced usage (reasoning, tool calling, vision/video)
- `docs.json` nav, `intro.mdx` card href, NEW tag moved from LFM2.5

## Validation

- Only the two **H200** cells are `verified: true` (end-to-end run on H200, BF16, TP1, flashinfer: GSM8K above, plus state/protocol/VL probes and a Transformers reference comparison). All other cells are `verified: false` inferred recipes with the platform adjustments noted in §2 (aiter + `SGLANG_USE_AITER=1` on AMD, CUDA 13 image for DGX Spark).
- `node docs/scripts/check_cookbook_configs.mjs` OK; `mint validate` and `mint broken-links` pass.

Draft pending the model's public release: HF repo ids and the `dev` image tag are provisional placeholders and will be finalized once the release artifacts are live.
