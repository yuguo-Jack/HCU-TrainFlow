# [Fix] diffusion: SenseNova-U1: keep think tokens in attention, fix 4.x import and vision_model init

[Upstream PR](https://github.com/sgl-project/sglang/pull/47746) · state: open · merged: False

## Original PR description

## Summary

Three small fixes in `multimodal_gen/runtime/models/sensenova_u1/neo_unify`:

1. **Think mode dropped reasoning from attention.** `condition_prefix_lengths` was computed from the original prompt, before `_generate_think` appended the think tokens and `</think>\n\n<img>` to the KV cache. `prepare_flash_kv_cache` then used the short length, so `_flash_or_sdpa` took the per-sample compact path and kept only `k[:orig_len]` plus image tokens (same loss on NPU-FIA via `_copy_right_aligned_prefix_bnsd`). The length is now recomputed from the cache after `_generate_think`.
2. **Transformers 4.x import break.** `model_input_compat` was only defined in the `try`, so the `except ImportError` path left it undefined. It now falls back to a no-op decorator.
3. **NameError when `vision_model` is passed.** `vision_model_mot_gen` was only created in the `else` branch; it is now built unconditionally.

## Tests

- New regression test for (1): stubs the model and asserts the `prefix_lengths` given to `prepare_flash_kv_cache` equal the full cache length in think mode. Fails on base, passes with the fix.
- `test_sensenova_u1.py` and `test_sensenova_u1_backbone.py` on CPU (Modal): 78 passed, 1 skipped.
- No import test for (2): CI pins transformers 5.19.0, so the 4.x path is not exercised.

## Not included

`_apply_time_schedule` forces `"standard"`; fixing it changes outputs, so it is left for a separate issue.
