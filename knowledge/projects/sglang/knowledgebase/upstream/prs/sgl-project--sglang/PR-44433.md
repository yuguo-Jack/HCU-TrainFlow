# [Test] [NPU] speculative: Cover target-only acceptance thresholds

[Upstream PR](https://github.com/sgl-project/sglang/pull/44433) · state: open · merged: False

## Original PR description

## Motivation

Cover the two target-only speculative acceptance thresholds on the NPU path at both the sampler integration boundary and the HTTP service boundary.

## Modifications

- Add three `CustomTestCase` cases that parse real EAGLE3 CLI arguments, publish the runtime configuration, and execute `eagle_sample` with the real NPU sampler.
- Hold the candidate chain, logits, acceptance coins, and final sampling coin fixed. Changing either threshold alone must change the accepted draft count from 0 to 1 and the returned length from 1 to 2. Assert exact output tokens and indices as well as the forwarded sampler arguments.
- Add a Qwen3.5-9B NEXTN/MTP service smoke using the shared `QWEN3_5_9B_MODEL_PATH`, `popen_launch_server`, and process cleanup helpers. Check the reported non-default thresholds, issue a real `/generate` request, and check speculative-statistic consistency.
- Register both files only in `full-1-npu-a3` with `nightly=True`. No base-suite or A5 registration is added.

The fixed-input tests supply the behavioral oracle. The service smoke does not require a particular acceptance rate or assume that an arbitrary real prompt must produce different lengths for different thresholds.

Companion kernel tests: https://github.com/sgl-project/sgl-kernel-npu/pull/860. This SGLang PR uses the existing kernel implementation and does not depend on merging that test-only PR.

## Accuracy Tests

This PR changes tests only; it does not change model or sampler implementation.

Tested against SGLang base `f2b73d4f9b4e64415b8d775b0f811c7801f1728b` on a real Ascend910_9362 NPU:

```bash
python -u test/registered/npu/basic_function/speculative_inference/test_npu_eagle_target_only_thresholds.py
python -u test/registered/npu/basic_function/speculative_inference/test_npu_nextn_target_only_thresholds.py
```

- Fixed-input integration: 3 tests passed in 9.668 seconds, exit 0.
- Real service: 1 test passed in 52.685 seconds, exit 0. Health, server-info, and generation requests returned HTTP 200. The request generated 16 tokens and accepted 7/8 proposed drafts (acceptance rate 0.875, reported mean acceptance length 2.0).

The smoke checks the resolved algorithm name `EAGLE` and the original `NEXTN` CLI argument separately, matching the existing NEXTN alias normalization. Its service process and port were released after the test.

For local validation only, the standard model cache path was temporarily symlinked to an existing checkpoint. The submitted test uses the shared model-path constant without a local override.

Local checks passed: isort 7.0.0, Ruff 0.15.1 check/format, codespell, `check_registered_tests.py`, `check_no_bare_pytest_main.py`, and `git diff --check`.

A5 has not been tested.
