# [Feat] sgl-router: Add opt-in decode cache affinity

[Upstream PR](https://github.com/sgl-project/sglang/pull/44516) · state: open · merged: False

## Original PR description

## Motivation

Decode workers can reuse cached prefixes, but bucket-first routing currently rejects `cache_aware` on decode groups. A repeated request can therefore go to a cold decode worker even when an eligible worker already holds the prefix.

This implements the decode-selection part of the decode-aware pairing item in #43699, related to #43098 and #25760.

## Modifications

- Allow decode groups to opt into `cache_aware` with `prefer` or `balanced` affinity. The default remains power-of-two.
- Rank admitted workers by their longest confirmed GPU-or-host prefix, then GPU-resident depth and decode load. Disk/external copies and pending placements do not count.
- Keep bucket and version-group boundaries, admission limits, and load-based fallback. Balanced mode uses running-request load.
- Limit cache affinity to single-DP-rank workers using the local radix tree. Multi-rank workers can still be selected by the load fallback; remote-index affinity needs a tier-aware API first.

The README includes the bucket configuration. Prefill selection and engine transfer behavior are unchanged.

## Accuracy Tests

Added policy regressions for tier changes, eviction, admission, stale load, partial-page thresholds, cache-salt/LoRA isolation, and missing cache signals. An HTTP PD test checks selection within the prefill's version group and preserves the shared bootstrap room.

The tokenizer parity tests require external fixtures and were excluded. No model accuracy or GPU serving run was performed.

## Speed Tests and Profiling

Added a paired CPU lookup benchmark on the same tree, with half the owners on GPU and half on host memory. Apple M4 Pro, Rust 1.92.0 release build, 20 samples, 1s warmup, 2s measurement:

| Shared prefix | Existing any-tier lookup | New resident lookup |
| --- | ---: | ---: |
| 8 workers, 64 blocks | 8.11 us | 13.83 us |
| 32 workers, 512 blocks | 232.26 us | 360.90 us |

```sh
cargo +1.92.0 bench --locked --bench tree_lookup -- resident_prefix --sample-size 20 --warm-up-time 1 --measurement-time 2
```

These measure tree lookup cost, excluding token hashing and dispatch. The additional walk distinguishes GPU residency from host-backed prefixes. Reduced KV transfer and TTFT still need a real PD serving benchmark; this PR makes no claim about those gains.
