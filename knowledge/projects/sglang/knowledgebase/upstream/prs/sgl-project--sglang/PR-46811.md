# [Feat] [AMD] HiCache: page-striped host tier for DSv4

[Upstream PR](https://github.com/sgl-project/sglang/pull/46811) · state: open · merged: False

## Original PR description

## Motivation

A page-striped HiCache host tier for aggregated DeepSeek-V4 (`--hicache-host-shard stripe`). DSv4 decodes with head-TP, so every rank must keep the full device KV, and device-side KV sharding (`--enable-kv-cache-sharding`, #30501) does not apply. Striping only the host copy gives each TP rank 1/N of the host pages, so the same pinned memory holds N times the tokens. DSv4-Pro AgentX c96: +20.6% tok/s/GPU, -33.7% TTFT vs Replicated 1.5x at equal host memory; +10.5% tok/s/GPU, -17.5% TTFT vs Replicated 2.5x with 40% less pinned host memory (S1).

## Modifications

- Striped host tier (default off): each TP rank stores 1/N of host pages; backup copies owned pages after a MIN-agreed admission; load = owned H2D + pynccl all-gather before the next extend. Fail-closed gate (TP > 1, unified KV, `write_through`); `hicache_stripe_*` metrics.
- Unlike the sharded host pool used with `--enable-kv-cache-sharding`, which follows a sharded device pool, this tier stripes only the host copy while device KV stays replicated; the two are mutually exclusive.
- Cost: no collective on decode; one small CPU all-reduce per extend and per backup (S5).
- Scope: aggregated DSv4 only (no DP-attn, PP, PD or storage backends).

## Accuracy Tests

GPU runs: 8x MI355X; A1 on `lmsysorg/sglang-rocm:v0.5.22-rocm724-mi35x-20261016`, A2 on `lmsysorg/sglang-rocm:v0.5.22-rocm724-mi35x-20261019` and `lmsysorg/sglang-rocm:v0.5.22-rocm724-mi35x-20261025`.

**Notation (all tables).**
- **Replicated / Striped Nx**: HiCache host tier with `--hicache-host-shard off` (stock behaviour: every TP rank keeps a full copy of the host KV) or `--hicache-host-shard stripe` (this PR: each of the 8 TP ranks keeps 1/8 of the host pages, so the same memory holds 8x the tokens). N = `--hicache-ratio`, host pool size per rank as a multiple of the device KV pool. Device KV is replicated in both.
- **Stock image**: the same image without this PR (no `--hicache-host-shard` flag).
- **FULL / FAST**: InferenceX AgentX with a 3,600 s / 1,200 s measurement window.
- **Device / host hit**: share of prompt tokens served from the GPU radix cache / loaded back from the HiCache host tier; **theoretical** is the trace's reuse upper bound.
- **tok/s/GPU total / output**: input + output tokens per second per GPU / output tokens only.
- **AL**: mean speculative accept length.
