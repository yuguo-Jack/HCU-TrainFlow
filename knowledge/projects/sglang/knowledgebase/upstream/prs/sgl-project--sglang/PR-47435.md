# [fix] prefill CUDA graph fallback returning a runner instead of GraphCapture

[Upstream PR](https://github.com/sgl-project/sglang/pull/47435) · state: open · merged: False

## Original PR description


When no configured capture size fits the backend's token budget, capture_prefill_graph returned the bare EagerRunner instead of wrapping it in a GraphCapture like every other early-return in the function. Callers read capture.runner and capture.memory_usage (model_runner.py), neither of which exists on EagerRunner, so this branch raised AttributeError at startup instead of falling back to eager prefill.
