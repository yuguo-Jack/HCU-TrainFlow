# [Fix] scheduler: Retire the beam group of an aborted chunked leader

[Upstream PR](https://github.com/sgl-project/sglang/pull/47381) · state: closed · merged: True

## Original PR description

- `Scheduler.process_pending_chunked_abort` now retires the aborted request's beam group through `BeamCoordinator.retire_group`, as the waiting-queue abort already does. A beam-search leader aborted mid chunked prefill left its group counted as live, so the coordinator's per-step scans, gated on the live-group count, kept running for the rest of the server's life.
- The leader has no member rows before its prefill ends, so retiring the group is all the release it needs. `retire_group` does nothing for a request without a beam group, so other chunked aborts are unchanged.
- Add `test_aborted_chunked_beam_leader_retires_its_group` to `test_scheduler_chunked_abort_race.py`; it fails without the fix.
