# fix: substitute image placeholder for glm5 next multimodal reminder

[Upstream PR](https://github.com/sgl-project/sglang/pull/40061) · state: closed · merged: False

## Original PR description

Fixes #39850

This PR fixes a bug where GLM 5.3 Flash image requests render a no multimodal reminder instead of the image placeholder, preventing the model from seeing the image.

The fix substitutes the no multimodal reminder with the proper IMAGE_TOKEN when image data is present. It also adds a multimodal OCR check in the existing 8 GPU CI tests for h200 and b200 runners by appending the enable-multimodal argument and running a basic OCR test.
