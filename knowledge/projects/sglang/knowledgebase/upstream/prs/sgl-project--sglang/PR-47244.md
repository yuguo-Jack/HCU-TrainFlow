# [CI] [AMD] workflows: Run scheduled Extra tests, stop skipping nightly tests, merge MI35x 1-GPU jobs- #47238

[Upstream PR](https://github.com/sgl-project/sglang/pull/47244) · state: closed · merged: True

## Original PR description

## Motivation

1. `pr-test-amd.yml`: run the MI35x 1-GPU suite as 1 job instead of 2. Raise its time limit from 45 to 75 minutes, because the whole suite takes about 46 minutes.
2. `pr-test-amd.yml`: fix the condition so scheduled runs call the Extra tests.
3. `nightly-test-amd.yml`: in those 14 jobs, run the later test step even if an earlier test step failed. If setup fails, the job still stops.

With these changes, a failure in a scheduled run no longer stops other tests from running.

## Expected impact

- **Item 1:** each PR uses about 50 minutes of MI35x 1-GPU runner time instead of 54, and takes 1 runner slot instead of 2. This helps a little, but it does not fix the waiting time. That needs more runners or fewer tests. With no wait, this job takes about 23 minutes longer.
- **Item 2:** adds 3 Extra runs a day on MI300 runners, which have free capacity right now. The Extra tests have not run on `main` for over 5 weeks, so the first scheduled runs will probably show some failures.
- **Item 3:** nightly runs report results for every test, not only the tests before the first failure.
