# [Scheduler] Reset the adopted prefill's per-step fields when preparing for decode

[Upstream PR](https://github.com/sgl-project/sglang/pull/43903) · state: open · merged: False

## Original PR description

Stacks on #43902

- `prepare_for_decode` resets the per-step prefill fields a running batch keeps after adopting a prefill (positional overrides, extend token counts, HiCache consumer index, logprob token ids).
- The scripted trace records a mixed step's decode rows as running and the running count at plan start (trace format 4).

Behavior change: decode CUDA graphs are used again after a prefill with positional overrides; DP-converted steps drop stale overrides; the HRRN policy stops counting the prefill's tokens on decode steps, with and without speculative decoding.
