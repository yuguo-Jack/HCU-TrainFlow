# [Fix] context-parallel: Preserve list and tuple sharding in interleave CP

[Upstream PR](https://github.com/sgl-project/sglang/pull/40462) · state: open · merged: False

## Original PR description

## Motivation

`InterleaveCPStrategy._interleave_shard` explicitly handles Python lists and tuples, but indexes them with a `range`. Both types raise `TypeError`, including for empty sequences. This is a fix for the supported sequence branch; the Tensor path is unchanged.

## Modifications

Use strided slicing to preserve the input sequence type. Add regression coverage through `shard_local_tokens` for list/tuple, empty/short/uneven/divisible lengths, CP sizes 1/2/4, and every rank. Check values, type, and input immutability.
