# [Refactor] scheduler: Write every request finish state through Req methods

[Upstream PR](https://github.com/sgl-project/sglang/pull/43896) · state: closed · merged: True

## Original PR description

- Add `Req.request_finish`, `Req.request_discard`, `Req.clear_requested_finish` and `Req.finish_outside_step`; each body is exactly the assignment it replaces.
- Route every writer of `to_finish`, `finished_reason` and `discard_output_reason` under `python/sglang/srt` outside the step commit's finish checks through them (27 sites): abort, session close, retract, grammar reject, sampling mask, discarded output, beam group result, dLLM context limit, PD prefill handoff and transfer failure, `prepare_abort`, and the external KV load failure. The conditions around the PD and queued-abort writes stay at their call sites.
- Move the AST scan of `test_req_kv_lengths.py` into `python/sglang/test/field_writes.py`, shared by both guards.
- Add `test/registered/unit/managers/test_req_finish_state.py`: a guard that fails on any write of these fields outside the finish methods and the commit's finish checks (`update_finish_state` and its helpers), plus unit tests pinning each method.
- Unit fakes that reach a routed writer borrow the `Req` method.

No behavior change.
