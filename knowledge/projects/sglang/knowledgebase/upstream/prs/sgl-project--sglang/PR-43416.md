# [diffusion]  comfyui: fix-implement VideoInput.as_trimmed and resolve cloud-uploaded video urls in ComfyUI nodes

[Upstream PR](https://github.com/sgl-project/sglang/pull/43416) · state: closed · merged: False

## Original PR description

## Summary

Fixes #43190. `SGLDVideoInput` never implemented `as_trimmed`, which ComfyUI made abstract in ComfyUI#12107, so `SGLDiffusionGenerateVideo`/`SGLDiffusionGenerateH3` fail to instantiate their output on any ComfyUI since that change:

```
RuntimeError: Failed to generate video: Can't instantiate abstract class SGLDVideoInput without an implementation for abstract method 'as_trimmed'
```

Separately, both nodes only ever read `file_path` from the server response. `file_path` is `None` once a cloud upload succeeds (the local file is removed after upload), and is a server-side path when the server runs on another host. Both cases either crashed with a confusing `TypeError` or silently wrote nothing.

- `SGLDVideoInput.as_trimmed` now does a real ffmpeg stream-copy trim (fast, no re-encode), returning `None` for a negative resulting duration per the `VideoInput` contract.
- `SGLDVideoInput.save_to` now raises `FileNotFoundError` with a clear message when `video_path` isn't actually readable here, instead of silently writing nothing.
- A new `resolve_video_path()` helper fetches the video from the response's `url` (streamed to disk, not buffered) when `file_path` is empty.
