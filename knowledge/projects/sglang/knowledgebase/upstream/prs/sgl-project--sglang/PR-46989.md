## Motivation

Admission, memory accounting and transfers currently inspect concrete KV pools to discover their resources. Expose those resources through storage so these consumers can handle static and unified layouts consistently.

## Changes

- Read per-subpool capacity and usage through KV storage for admission, statistics and leak checks.
- Route beam-search row allocation and release through storage.
- Register static KV and state transfer descriptors through the same storage interface, preserving transfer ordering and layout metadata.

Clarify storage comments and use `CustomTestCase` for the NPU transfer tests.
