# [feat] Add Qwen3 MoE true-on-policy parity

[Upstream PR](https://github.com/sgl-project/sglang/pull/24408) · state: open · merged: False

## Original PR description

## Motivation

Add the SGLang side of the Qwen3-30B-A3B MoE true-on-policy stack on top of `sgl-project/sglang:sglang-miles`.

This PR is one of three coupled PRs that must land together because they share the `qwen3_moe_true_on_policy_v1` contract and were validated as one end-to-end stack.

**Companion PRs:**
- Miles: https://github.com/radixark/miles/pull/1059
- Megatron-LM: https://github.com/radixark/Megatron-LM/pull/30

Supersedes the fork-side review PR: https://github.com/maocheng23/sglang/pull/3

## Modifications

- Adds the `qwen3_moe_true_on_policy_v1` contract to `python/sglang/srt/true_on_policy/`.
- Enables deterministic Qwen3-MoE routing/top-k behavior under the true-on-policy contract.
- Keeps the deterministic decode path needed for current correctness; the prefill-only fast-decode path and custom CUDA tree allreduce work were cleaned out.
- Keeps minimal EP communication support needed by the MoE contract while preserving upstream dense communication behavior.
- Disables custom allreduce/NVLS under deterministic TP decode so TP allreduce order stays stable.
