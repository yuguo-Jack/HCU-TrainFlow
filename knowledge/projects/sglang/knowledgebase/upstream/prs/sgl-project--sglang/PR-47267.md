# [Fix] dflash: Gather candidate top-k over the lm_head's group under DP attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/47267) · state: open · merged: False

## Original PR description

With DP attention, DFLASH requires `--enable-dp-lm-head`, which shards the target lm_head over the attention-TP group. `candidate_topk` still all-gathered the per-shard candidates over the full TP group, so each DP rank's candidates mixed in other DP ranks' rows.

Gather over the group the head is sharded on: `attn_tp_group` when `lm_head.use_attn_tp_group`, else `tp_group`.

The vocab-shard gather test now runs for both head layouts and fails if the candidates are gathered over the wrong group.
