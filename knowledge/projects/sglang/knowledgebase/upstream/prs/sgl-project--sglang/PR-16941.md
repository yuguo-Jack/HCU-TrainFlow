# [AMD] Add AMD CI registration (1-gpu unit test) to nightly CI.

## Original PR description

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

1. Adds **19 new AMD test files** (14 accuracy + 5 perf) for MI30x and MI35x
2. Adds AMD CI registration to **12 existing unit tests** (LoRA, debug utils, scheduler, bench, core)
3. Restructures **15 CI jobs** (9 MI30x + 6 MI35x) with clear accuracy/performance separation
4. Combines accuracy + perf tests for same model into single jobs, saving ~5-10 min Docker setup time per model
5. Adds new accuracy tests for DeepSeek-V3.1, Grok1-FP8, Grok1-INT4, Grok2 that previously only had perf benchmarks

Nightly CI passed: https://github.com/sgl-project/sglang/actions/runs/20944046091. Please help to review! @yctseng0211 @bingxche @HaiShaw
