# [Refactor] diffusion: Write DiT attention break outputs into caller-allocated buffers

[Upstream PR](https://github.com/sgl-project/sglang/pull/46659) · state: closed · merged: True

## Original PR description

- The DiT attention break, the eager region that the `UlyssesAttention`, `UlyssesAttention_VSA`, `LocalAttention`, and `USPAttention` forwards run in under the diffusion breakable CUDA graph, copies the forward's result into an output the caller allocates right before the break and returns nothing; the captured segment after the break reads that output. Before, the break returned a fresh output on every replay and the graph wrapper copied it into the one it had captured, with `UlyssesAttention`'s `(output, replicated_output)` tuple boxed in `_BCGBoxedTupleOutput`, which is removed.
- Each module sizes its output with `_new_bcg_output`, which takes the forward's arguments: q's batch, rows, and heads with v's head dim. `USPAttention` also covers a pre-exchanged qkv (`qkv_pre_all_to_all`, where the output all-to-all shards the rows and gathers the heads) and the segmented prefix of the masked local path (`q_prefix` with `attn_mask`, where the output includes the prefix rows). `UlyssesAttention` returns `None` in the replicated slot when no replicated q is given, as its forward does.
- The break asserts that each result has its output's shape and dtype, so a misprediction fails the capture, and that signature then runs eagerly, instead of being broadcast or cast silently.
- No behavior change intended. The outputs are now allocated in the capture's memory pool instead of being held outside it for each break. The change runs only while a diffusion breakable CUDA graph is captured; eager runs and the opt-in dense capture (`capture_dense_attention`) are unchanged.
- A unit test captures and replays `LocalAttention` and both forms of `UlyssesAttention`, and checks that each replay leaves the new result in the captured output.
