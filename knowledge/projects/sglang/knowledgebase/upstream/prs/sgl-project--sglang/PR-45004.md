# [CI] radix-cache: Register the Inkling cache linker KL test to extra-b

[Upstream PR](https://github.com/sgl-project/sglang/pull/45004) · state: closed · merged: True

## Original PR description

## Motivation

#44938 registered `test_unified_cache_linker_kl_inkling.py` with `stage="extra-a"` and `runner_config="4-gpu-h100"`, which computes the nonexistent suite `extra-a-test-4-gpu-h100`. `validate_all_suites` raises on it, turning base-a red on every PR (e.g. any pr-test wave's base-a-test-cpu lanes fail at the suite check — [failing job](https://github.com/sgl-project/sglang/actions/runs/39132531238/job/117690613219)).

## Modifications

`stage="extra-a"` → `stage="extra-b"`. `extra-b-test-4-gpu-h100` is the valid 4-GPU H100 extra suite; extra-a only has 1-gpu-small / 1-gpu-large / 2-gpu-large on CUDA.

## Tests

Verified the computed suite name against `PER_COMMIT_SUITES` + `NIGHTLY_SUITES` + `OTHER_SUITES`: `extra-b-test-4-gpu-h100` is in the CUDA set; `extra-a-test-4-gpu-h100` is not.
