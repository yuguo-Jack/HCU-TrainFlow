# [Fix] [AMD] MiniMax-M3: default SGLANG_MINIMAX_M3_INDEX_TOPK_FREQ to 1

[Upstream PR](https://github.com/sgl-project/sglang/pull/46340) · state: closed · merged: True

## Original PR description

## Motivation

#36527 added sparse index top-k sharing for MiniMax-M3 on gfx95 and enabled it by default (`SGLANG_MINIMAX_M3_INDEX_TOPK_FREQ=2`). With sharing on, every other sparse layer attends the KV blocks selected for the previous layer rather than its own, so ROCm serves a numerically different model from every other platform (where the backend pins 1) unless users know to opt out.

## Modifications

Change the default to 1 (sharing disabled), keeping the sharing path available as an explicit opt-in via `SGLANG_MINIMAX_M3_INDEX_TOPK_FREQ=2` or higher. Comment updated accordingly. No other behaviour changes.

## Validation

MiniMax-M3.1-Flash (NVFP4, DSpark) on MI355X TP4 with `SGLANG_MINIMAX_M3_INDEX_TOPK_FREQ=1` completed InferenceX's AgentX sweep at concurrency 1-64 plus the accuracy eval: https://github.com/SemiAnalysisAI/InferenceX/pull/4469
