# [Perf] hisparse: Use deque for HiSparseCoordinator.ack_staging_queue FIFO drain

[Upstream PR](https://github.com/sgl-project/sglang/pull/46621) · state: open · merged: False

## Original PR description

## Motivation

In `python/sglang/srt/managers/hisparse_coordinator.py`, `HiSparseCoordinator.ack_staging_queue` stores in-flight `HiSparseAct(start_event, finish_event, req)` entries in FIFO order and drains ready requests from the front of the queue on every scheduler step inside `collect_ready_reqs()`:

```python
while finish_count > 0:
    _, _, req = self.ack_staging_queue.pop(0)
```

Because `self.ack_staging_queue` was initialized as a Python `list`, each `pop(0)` shifts all remaining elements left in $O(N)$ time, resulting in $O(K \cdot N)$ list-shift overhead when draining $K$ ready requests from a staging queue of length $N$.

## Modifications

- Replace `self.ack_staging_queue: List[HiSparseAct] = []` with `collections.deque[HiSparseAct] = deque()`.
- Use `self.ack_staging_queue.popleft()` in `HiSparseCoordinator.collect_ready_reqs()` for $O(1)$ FIFO dequeue per completed request.
- Preserve `deque` in `HiSparseCoordinator.abort_staging_request()` when filtering out an aborted request (`deque(act for act in self.ack_staging_queue if act.req is not req)`).
- Add a unit test (`TestHiSparseStagingQueueUnit.test_collect_ready_reqs_and_abort_preserve_fifo_deque`) in `test/registered/unit/managers/test_hisparse_unit.py` covering FIFO drain order, partial readiness, and request abort.

## Accuracy & Performance Verification

- Verified unit tests in `test/registered/unit/managers/test_hisparse_unit.py` pass via `pytest`.
- Microbenchmark draining 512 staged requests via `popleft()` vs `list.pop(0)`: **~7.4x faster** queue drain with $O(1)$ per-request dequeue complexity.
