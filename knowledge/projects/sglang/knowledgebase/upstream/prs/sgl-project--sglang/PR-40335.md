## Summary

<img width="2410" height="786" alt="image" src="https://github.com/user-attachments/assets/538a0d8c-ff06-4f82-9f27-935158d7bf41" />
The DeepSeek V4.1 CP prefill indexer introduces host synchronization when uploading CPU metadata and indexing the request-to-token table with a CUDA scalar. These waits prevent the CPU from submitting subsequent work asynchronously.

- Upload query lengths and key offsets through the existing pinned-memory, non-blocking transfer helper.
- Keep request indices as one-dimensional CUDA tensors to avoid implicit device-to-host scalar reads.
- Add a regression test that rejects CUDA scalar reads during mixed-length prefill, including requests with zero query tokens.
