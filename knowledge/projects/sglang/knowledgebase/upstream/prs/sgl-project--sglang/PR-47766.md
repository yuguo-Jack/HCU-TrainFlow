# [Fix] router: Forward disagg_prefill_dp_rank on DP-aware prefill PD requests

[Upstream PR](https://github.com/sgl-project/sglang/pull/47766) · state: open · merged: False

## Original PR description

## Motivation

Follow-up to #27546.

When a disaggregated prefill/decode router (`sgl-model-gateway`, `sgl-router`, or `MiniLoadBalancer`) dispatches a DP-aware PD request (`prefill_worker.dp_rank() == Some(rank)`), it injects `"disagg_prefill_dp_rank": rank` into the **decode** request body so decode can connect directly to the selected prefill DP rank without querying `/query_dp_rank`, while omitting `"disagg_prefill_dp_rank"` from the **prefill** request body (sending only `data_parallel_rank` / `routed_dp_rank`).

On the prefill engine (`load_balance_method="follow_bootstrap_room"` by default):
1. `DataParallelController.follow_bootstrap_room_scheduler` honors `req.routed_dp_rank` and dispatches the request to the router-selected `dp_rank`.
2. `PrefillBootstrapQueue.create_sender` constructs `CommonKVSender` with `req_has_disagg_prefill_dp_rank = req.disagg_prefill_dp_rank is not None` (`False`).
3. Unless `bootstrap_room % num_dp_ranks` happens to match the selected rank or `SGLANG_DISAGGREGATION_FORCE_QUERY_PREFILL_DP_RANK=1` is set (which still triggers a redundant blocking `/register_dp_rank` HTTP POST per request even though decode already received `disagg_prefill_dp_rank`), `CommonKVSender.__init__` aborts `(num_dp_ranks - 1) / num_dp_ranks` of requests with `KVPoll.Failed` (`follow_bootstrap_room conflict`).

## Modifications

- **`sgl-model-gateway/src/routers/http/pd_router.rs` & `sgl-model-gateway/tests/routing/pd_routing_test.rs`**: Generalize `inject_prefill_dp_rank_for_decode` to `inject_prefill_dp_rank` and inject `"disagg_prefill_dp_rank"` on both prefill and decode PD worker requests when `prefill.dp_rank()` is `Some(rank)` (leaving non-DP workers zero-copy `Cow::Borrowed` without `disagg_prefill_dp_rank`).
- **`sgl-router/src/server/routes/chat/forward.rs`, `sgl-router/tests/proxy/dp_rank_routing.rs`, & `sgl-router/REFERENCE.md`**: Pass `prefill_rank` into `Leg::new` on the PD prefill leg (`pd.is_some()`) as well as decode, while keeping plain non-PD requests and fan-out PD requests (`prefill_rank == None`) unchanged.
- **`sgl-model-gateway/bindings/python/src/sglang_router/mini_lb.py`**: Set `prefill_req["disagg_prefill_dp_rank"] = p_rank` alongside `decode_req["disagg_prefill_dp_rank"] = p_rank` in `_fork_dp_requests`.
- **`python/sglang/srt/disaggregation/{base/conn.py,fake/conn.py,common/conn.py,prefill.py}` & `test/registered/unit/disaggregation/test_register_to_bootstrap.py`**: Forward `req_disagg_prefill_dp_rank=req.disagg_prefill_dp_rank` to `KVSender` (preserving the `req_has_disagg_prefill_dp_rank` keyword argument), resolve the dispatched DP rank across both `--enable-dp-attention` (`attn_dp_rank`) and replica DP (`system_dp_rank`), skip both `follow_bootstrap_room conflict` and `/register_dp_rank` when `req_disagg_prefill_dp_rank` matches, and fail fast with `disagg_prefill_dp_rank mismatch` if an explicit `disagg_prefill_dp_rank` ever disagrees with the dispatched rank.
