# fix: prevent scheduler crash when top_logprobs exceeds vocab size

[Upstream PR](https://github.com/sgl-project/sglang/pull/40099) · state: closed · merged: False

## Original PR description

Fixes #40076

This PR fixes an issue where requesting a `top_logprobs` value greater than the vocabulary size causes the server scheduler to crash with a `RuntimeError: selected index k out of range` during `topk` computation.

The fix safely bounds the requested `max_k` to the vocabulary size in both `get_top_logprobs_raw` and `get_top_logprobs_chunk` within `logprob_processor.py`.
