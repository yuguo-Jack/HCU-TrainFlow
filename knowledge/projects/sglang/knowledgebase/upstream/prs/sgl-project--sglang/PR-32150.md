# [Feature][NPU][Quantization] Adapt Qwen3.5 Dense Model with MXFP8/MXFP4 (W8A8/W4A8/W4A4) Quantization Schemes on A5 NPU.

[Upstream PR](https://github.com/sgl-project/sglang/pull/32150) · state: closed · merged: False

## Original PR description

## Motivation

This PR follows https://github.com/sgl-project/sglang/issues/21584 and quantization roadmap https://github.com/sgl-project/sglang/issues/31783.
This PR aims to verify and adapt MXFP8/MXFP4 quantization (W8A8/W4A8/W4A4) for the Qwen3.5 dense model.

**Note: Please merge after https://github.com/sgl-project/sglang/pull/32745**.

## Modifications
### 1、Handle accuracy drop of dual-scale MXFP4 (W4A4) online quantization by random orthogonal matrix.
I benchmark online MXFP4 (W4A4) quantization on the Qwen3.5‑27B dense model on the A5 NPU. The results (see below) show ~3% accuracy degradation compared to the BF16 baseline.

| Accuracy | Run 1 | Run 2 | Run 3 | Avg | vs BF16 |
|--------|-------|-------|-------|-----|---------|
| **BF16 (baseline)** | 91.89% | 91.96% | 91.36% | 91.73% | — |
| **Online W4A4** | 88.55% | 89.08% | 88.48% | 88.70% | -3.03% |

To improve the accuracy of online MXFP4 (W4A4) quantization for the Qwen3.5 dense model, I adopt two standard techniques.
(1) Block‑diagonal Random Orthogonal Matrix
During online MXFP4 (W4A4) quantization, we apply a block-diagonal random orthogonal matrix $\( R \)$ to both weights and activations to improve numerical stability. The matrix is defined as:

$$
R = \begin{bmatrix}
R_1 & 0 & \cdots & 0 \\
0 & R_2 & \cdots & 0 \\
\vdots & \vdots & \ddots & \vdots \\
0 & 0 & \cdots & R_B
\end{bmatrix}, \quad 
R_i \in \mathbb{R}^{g \times g}, R_i^\top R_i = I
$$

where $\( g = 32 \)$ aligns with the MXFP4 block size. Each block $\( R_i \)$ is a random orthogonal matrix generated via Householder reflections. The transformation is applied as:

$$
W' = W R, \quad x' = x R
$$

(2) Layer‑wise Selective Rotation
Block-diagonal random orthogonal rotation incurs extra computational overhead. Based on empirical evaluations, I limit its application to quantization-prone layers—namely MergedColumnParallelLinear and QKVParallelLinear. This setup retains the full accuracy benefits of the rotation while keeping incremental inference costs minimal.

**The rotation optimization is disabled by default and does not alter the existing online MXFP4 (W4A4) quantization path. Users may opt in by setting the corresponding environment variables to improve accuracy at the cost of moderate inference throughput.**

### 2、Add documentation.
Updated documentation to provide instructions for enabling the block-diagonal random rotation optimization.

### GSM8K

Three runs per configuration, where each run has 1319 prompts on A5 NPU. Both online and offline modes stay around 1% accuracy drop compared to the BF16 baseline.

| Accuracy | Run 1 | Run 2 | Run 3 | Avg | vs BF16 |
|--------|-------|-------|-------|-----|---------|
| **BF16 (baseline)** | 91.89% | 91.96% | 91.36% | 91.73% | — |
| **Online W8A8** | 91.81% | 91.05% | 91.21% | 91.35% | -0.38% |
| **Online W4A8** | 91.28% | 90.22% | 91.21% | 90.90% | -0.83% |
| **Online W4A4** | 91.21% | 91.51% | 90.98% | 91.23% | -0.5% |
| **Offline W8A8** | 91.43% | 91.74% | 91.21% | 91.46% | -0.27% |
| **Offline W4A8** | 91.28% | 91.51% | 91.13% | 91.30% | -0.43% |
| **Offline W4A4** | 91.51% | 91.74% | 91.36% | 91.53% | -0.2% |
