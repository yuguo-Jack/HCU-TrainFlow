# [Scheduler] Split next-batch planning into named stages

[Upstream PR](https://github.com/sgl-project/sglang/pull/43899) · state: open · merged: False

## Original PR description

Stacks on #43898

- `get_next_batch_to_run` is split into admit, gather, decode selection, and finalize stages.
- `select_decode_rows` selects decode rows for both decode and mixed steps.
- DP attention uses one eligibility predicate for the extend-view vote and the decode-to-extend conversion; the coordination term that no valid config reaches is dropped.

No behavior change.
