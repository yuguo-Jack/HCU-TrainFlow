# [Fix] rust_server: Give each plain-DP replica its own listener port

[Upstream PR](https://github.com/sgl-project/sglang/pull/45996) · state: closed · merged: True

## Original PR description

## Motivation

With `SGLANG_RUST_SERVER=1`, every DP-group leader embeds a Rust listener on `--port + offset` and `--grpc-port + offset`. The offset counts DP-group leaders inside one TP group's node-local range. Plain DP (`--dp N` without attention DP) runs N separate TP groups, each led by its own TP rank 0, so every replica computes offset 0 and binds the same HTTP and gRPC ports. Plain DP cannot start in Rust mode.

## Modifications

- `RustServer.launch`: under plain DP the listener offset is the replica index (`dp_rank`). Plain DP is single-node (`check_server_args` already rejects multi-node replicas), so every replica's leader is on this node. Attention DP and no-DP keep the existing formula.
- `check_server_args`: Rust-mode PD prefill with plain DP is rejected, since every replica registers its KV bootstrap rows with the `--port` listener.
- Test: the Rust server extension test gets the DP fields `launch` now reads.

## Dependencies

Independent of the other PRs split out of this one (sidecar, attention-DP idle, `node_listeners`). The `node_listeners` PR has a plain-DP test case that needs this PR.
