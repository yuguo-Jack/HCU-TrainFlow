# [Fix] [NPU] batch-invariant: Enable PyTorch deterministic algorithms

[Upstream PR](https://github.com/sgl-project/sglang/pull/45063) · state: open · merged: False

## Original PR description

## Motivation

On Ascend NPU, `--enable-deterministic-inference` registers batch-invariant operators but does not enable PyTorch's deterministic-algorithm mode. Operators outside those registrations therefore do not receive this setting from the deterministic-inference initialization path.

## Modifications

Call `torch.use_deterministic_algorithms(True, warn_only=True)` in the NPU branch of `enable_batch_invariant_mode()`.

This requests deterministic implementations from operators/backends that honor the PyTorch setting. `warn_only=True` allows detected nondeterministic operations without a deterministic implementation to warn instead of raising through PyTorch's determinism checks. The setting is process-wide and remains enabled after initialization.

This setting alone does not guarantee bitwise equality across different batch shapes. Existing FIA bindings, workspace queries, and graph handlers are unchanged.
