# Refactor HiCache host pool assembly with declarations

[Upstream PR](https://github.com/sgl-project/sglang/pull/40608) · state: closed · merged: False

## Original PR description

## Motivation

Overview PR for the declarative HiCache host pool assembly for sparse attention. It carries the whole path so the design can be reviewed and CI can run on the full stack. It is not meant to merge: the work will land as stacked PRs (declarations and DSA target, draft transform, hybrid Mamba and DSA, QSA, cleanup) and this PR is closed afterwards.

Each sparse attention variant wires its indexer host pool by hand in hybrid_pool_assembler.py and every new combination has missed one. On main, hybrid Mamba plus DSA and QSA both restore KV from host with a stale indexer, host restore KL against warm is 0.06 to 0.87 and drops to 1e-3 on this branch. See https://github.com/sgl-project/sglang/issues/39830, https://github.com/sgl-project/sglang/pull/39156, https://github.com/sgl-project/sglang/pull/39893 and the earlier draft incident https://github.com/sgl-project/sglang/pull/32176.

A device pool now declares the host pools its buffers need through host_pool_decls(), and one assembler builds the KV host pool plus every declared dependent pool for target, packed and separate drafts and the hybrid Mamba stack. A pool that is declared but not assembled fails at startup instead of restoring stale buffers.

## Modifications

- pool_host/host_pool_decl.py: HostPoolDecl, HostPoolStorageInfo, HostPoolBuilder, make_kv_pool_decl, make_draft_sidecar_decls.
- hybrid_pool_assembler.py: prepare_host_pool_configs, validate_packed_draft_pools, assemble_host_pools_from_decls. _PlainKvStrategy, _DsaStrategy, _MambaStrategy and the separate draft builder assemble from declarations. build_kv_only_stack, build_kv_only_group and the DSA isinstance branches are removed. _check_declared_pools_present runs after every strategy.
- pool_host/dsa.py: DSAIndexerPoolHost is built from its declaration and its host layers cover only device layers that own index buffers. Shared topk layers are 0-row placeholders that crashed the transfer kernels.
- pool_host/qsa.py: compressed key host pool for QSATokenToKVPool as page rows on DeepSeekV4PagedHostPool, plus the layer fence in get_qsa_compressed_k_buffer.
- build_kv_host_pool takes the MLA row width from the device pool (fp8 DSA store) and rejects packed drafts whose KV row differs. A draft that cannot be packed is an error instead of a silent skip.

## Accuracy

GLM-5.2-FP8 tp8 with HiCache, gsm8k: main 0.945, this branch 0.946.
Qwen3.8-Flash-Next tp8 gsm8k in chat format: HiCache 96.97, no HiCache 96.89.
Host restore with fixed continuation, KL against warm: DSA target 1e-4, hybrid Mamba and DSA 4e-4 to 2.6e-3 (main 0.06 to 0.7), QSA 9e-4 to 4.7e-3 (main 0.39 to 0.87), QSA packed MTP acceptance warm 3.37 and host 3.32. L3 file backend restart restores from storage with matching argmax. Separate draft paths are CPU tested only, there is no DSA or QSA family standalone draft model.
