# [Refactor] disaggregation: Share the flag all-reduce and host-destination predicate in the decode transfer queue

[Upstream PR](https://github.com/sgl-project/sglang/pull/45641) · state: closed · merged: True

## Original PR description

## Motivation

Follow-up cleanup to #45453, which added a second copy of the CPU flag all-reduce (next to `_all_reduce_polls`) and two more copies of the `enable_host_receive and host_staged` predicate inside `DecodeTransferQueue`. This PR removes the duplication without changing behavior.

## Modifications

- `disaggregation/utils.py`: new `all_reduce_flags(flags, group, op)`; `_all_reduce_polls` becomes a MIN call into it. The shared helper short-circuits on an empty list and on a single-rank group (the poll path only reaches it with a non-empty queue, so this is a no-op there) and reduces as `int32`.
- `DecodeTransferQueue`: `_is_host_destination(decode_req)` replaces the five inline `enable_host_receive and host_staged` checks; `_all_reduce_release_flags` is dropped in favor of `all_reduce_flags`; `resolve_deferred_releases` computes `drained` and `ready` in one loop instead of two comprehensions.
- Tests: the four `setUp` copies that patch `get_world_size` to 1 collapse into one `_run_as_single_rank(test)` helper per file.

No behavior change.
