# [AMD] Qwen3.5: pack GDN in_proj_qkvz+ba into one AITER ASM MXFP4 GEMM

[Upstream PR](https://github.com/sgl-project/sglang/pull/43785) · state: open · merged: False

## Original PR description

## Motivation
With `SGLANG_ROCM_USE_AITER_FP4_ASM_GEMM=1` on gfx950 (#39598), Quark W4A4 MXFP4 GDN layers
run `in_proj_qkvz` on the AITER ASM FP4 GEMM while `in_proj_ba` (N=96) stays on Triton
(N <= 128 guard). At decode that is two quantizations of the same input and two GEMMs per
GDN layer.

## Modifications
- `pack_asm_fp4_weight_tail()` (Quark MXFP4 scheme): appends a row-major MXFP4 projection
  to one already in ASM layout, padded to whole 256-row tiles and shuffled/swizzled like
  `process_weights_after_loading`. Shuffle and swizzle are local to 16/32 rows, so the
  leading rows are unchanged; whole tiles avoid the partial-tile issue behind the guard.
- `Qwen3_5GatedDeltaNet`: extends the ROCm packed in_proj path (BF16/FP8) to MXFP4. Decode
  batches (M <= 64) run one `per_1x32_f4_quant` + `gemm_a4w4`; `in_proj_qkvz` aliases the
  packed rows, `in_proj_ba` keeps its Triton layout for prefill. Gated by the existing
  `SGLANG_QWEN35_PACKED_IN_PROJ`; online weight updates are refused as for FP8.
- `Qwen3_5ForConditionalGeneration` forwards `prepare_before_cuda_graph_capture` to the
  backbone so dense VL entry checkpoints pack too.

Depends on #39598 (stacked on its head; the diff includes its commits until it merges). Tuned a4w4 configs for the packed N: ROCm/aiter#6419 (without them `gemm_a4w4` uses its default heuristic: correct, possibly slower).

## Accuracy / tests
- CPU: packing layout and fallbacks, weight loader.
- gfx950 (added, not yet run on this branch): `test_quark_mxfp4_asm_packed_gpu.py`, packed vs separate projections, M in {1,2,7,16,33,64}.
- Not yet run: GSM8K with `SGLANG_QWEN35_PACKED_IN_PROJ=0/1` on this branch.

## Benchmark
MI355X, amd/Qwen3.8-27B-Quark-AWQ-MXFP4, 5 serving rows, output throughput geomean vs the
same image without this change: TP1 +3.4% (TPOT -3.4%), TP2 +3.8% (TPOT -4.2%);
best row +7.7% / +9.7%. Measured as an overlay on a downstream image built on #39598, not on bare #39598.
