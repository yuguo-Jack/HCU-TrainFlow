# [Fix] compressed-tensors: Format capability errors correctly

[Upstream PR](https://github.com/sgl-project/sglang/pull/40589) · state: open · merged: False

## Original PR description

## Motivation

When a compressed-tensors scheme requires a newer GPU, `RuntimeError` receives three positional string fragments. Python renders those arguments as a tuple, so users get a noisy message instead of one sentence.

## Modifications

- join the capability error into one string
- add a CPU-only regression test that checks the exception arguments and capability values
