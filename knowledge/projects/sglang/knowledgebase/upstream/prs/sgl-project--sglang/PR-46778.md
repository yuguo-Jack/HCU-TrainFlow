# [Doc] diffusion: add Strix Halo (Radeon 8060S) recipe for Qwen-Image 2.1

[Upstream PR](https://github.com/sgl-project/sglang/pull/46778) · state: open · merged: False

## Original PR description

### Summary

Adds a measured recipe for the AMD Radeon 8060S (Strix Halo, gfx1151) to the Qwen-Image 2.1 cookbook: one row in the hardware table and a `### Strix Halo (Radeon 8060S)` subsection next to the existing DGX Spark one.

The subsection records two platform prerequisites that are not obvious from the existing AMD guidance:

- `TORCH_ROCM_AOTRITON_ENABLE_EXPERIMENTAL=1` — a **PyTorch** SDPA switch, not an SGLang flag. Without it PyTorch falls back from the Flash-efficient attention kernel and 1024x1024/40-step latency goes from ~155 s to more than 9 minutes on this GPU (measured).
- `--attention-backend torch_sdpa` — the runtime resolves the backend to AITER by default, which is not verified on gfx1151.

### Measurement

Same methodology as the existing table: original checkpoint, 1024x1024, 40 steps, CFG 1, one RGBA PNG per request, median HTTP latency of three warm requests after a discarded warmup, excluding startup. Peak memory is the request-phase sample reported by the server.

| Config | Median | Notes |
| --- | --- | --- |
| `torch_sdpa` + AOTriton env (row value) | 154.98 s | 3 runs: 154.93 / 154.98 / 155.11 |
| `SGLANG_CACHE_DIT_ENABLED=true` (default MC=3) | 56.96 s | documented as an optional speed/fidelity trade |

Platform: Ubuntu 24.04.2, kernel 7.0.0-38-generic, PyTorch 2.9.1+rocm7.2.4 (HIP 7.2.53211), Radeon 8060S with 128 GB unified memory (the kernel reports a 512 MiB VRAM carve-out, GTT cap ~108 GiB). FP8 is unavailable on this GPU.

### Scope and limits

- Only numbers reproducible on **upstream main with merged features** are used. Custom Triton kernels from open PRs (#44037 / #46065 / #46515) are intentionally excluded, so the row is slower than our best local result.
- **Edit** is left as `—`: `POST /v1/images/edits` returns 500 with `prompt_embeds ... NaN` on this base checkpoint, and `Qwen-Image-Edit-2511` weights are not available on the test machine. Transparent output is likewise unverified.
- Cache-DiT quality: PSNR 28.4 dB at default settings vs 27.5 dB with `SGLANG_CACHE_DIT_MC=6`, measured with the CLI on the same prompt and seed.
