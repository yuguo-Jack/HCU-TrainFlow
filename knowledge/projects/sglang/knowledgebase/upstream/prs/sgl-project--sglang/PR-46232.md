# [Perf] dsv41: Run MegaGate routing in prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/46232) · state: closed · merged: True

## Original PR description

MegaGate (`bf16_mega_gate` routing, with Mega-mHC writing the MegaMoE input) ran only for decode and target verify, up to 2048 rows. Prefill kept the regular routing chain: gate GEMM, router, top-k masks, padding fill, and a separate MegaMoE pre-dispatch per layer.

- `should_use_mega_gate` now also takes extend batches (draft extend keeps the regular router), up to MegaMoE's per-rank token cap `SGLANG_OPT_DEEPGEMM_MEGA_MOE_NUM_MAX_TOKENS_PER_RANK`, the size of the buffer the routing and the Mega-mHC input go to.
- Still behind `SGLANG_OPT_DEEPGEMM_MEGA_GATE=1`; without it nothing changes.

## Verification

- `test_mega_moe_deepgemm_api.py` covers extend, target verify and draft extend, and the row cap.
