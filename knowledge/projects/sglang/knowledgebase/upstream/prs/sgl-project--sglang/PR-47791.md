## Original PR description

## Motivation

Sync the MiniMax-M3.1 AgentX explorer's GB300 Dynamo + SGLang launches with https://github.com/SemiAnalysisAI/InferenceX/pull/4698 (verified in https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41271829525):

- 6P1D (prefill DEP2, decode DEP8 / DEP16): prefill `--chunked-prefill-size` 8192 → 16384; DEP8 adds c340, DEP16 adds c360 and c400.
- New 4P1D shape: 4 DEP2 prefill workers and one DEP8 decode at c224 / c256.
- New Dynamo aggregated cells: TP4 c1–c16; TP4 c24 and TP2 c40 with HiCache, `--schedule-policy shortest-prefill-first` and `--prefill-decode-interval 32`; TP2 c40 / c44 with HiCache.

Every new point decodes to the command that ran in that workflow run (excluding host, port and reporting flags); the cells added from https://github.com/SemiAnalysisAI/InferenceX/pull/4686 are re-encoded in the generator's format, and all other cells are unchanged. `check_cookbook_configs.mjs`, `mint validate` and `mint broken-links` pass.
