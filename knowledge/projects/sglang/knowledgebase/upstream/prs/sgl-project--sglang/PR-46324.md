# [Perf] diffusion: skip unread text encoder layers in FLUX.2 (~22% faster encode)

[Upstream PR](https://github.com/sgl-project/sglang/pull/46324) · state: closed · merged: False

## Original PR description

## Summary

FLUX.2-dev reads `hidden_states[10, 20, 30]` of its 40 layer Mistral3 encoder, and FLUX.2-klein reads `[9, 18, 27]` of its 36 layer Qwen3 encoder. Both still ran every layer. This drops the layers after the last one read, right after weight loading, in `TextEncoderLoader`.

`hidden_states[k]` is the input of layer `k`, so layers up to `max(k)` are enough. I keep layer `max(k)` itself so the final norm path in both encoders is untouched (marked with a `shortcut:` comment). Dropping that layer too would need a change inside each model, which I left out.

The read layers now live in `flux.py` as one constant per model, used by the postprocess functions and by a new `text_encoder_output_layers` field on the pipeline config.

## Results

A100-SXM4-80GB, torch 2.14.1, real `TextEncoderLoader.load`, GPU resident, one 512 token prompt, batch 1. Runs alternate pre, post, post, pre. 3 warmups, then 20 timed runs each. "Pre" is the same code with the truncation call turned off.

| Encoder | Layers | Median ms pre | Median ms post | Prompt embeddings |
|---|---|---|---|---|
| FLUX.2-dev (Mistral3 24B) | 40 -> 31 | 106.2, 105.5 | 82.0, 82.0 | bit-identical (max diff 0.0) |
| FLUX.2-klein-4B (Qwen3) | 36 -> 28 | 33.4, 32.6 | 25.6, 25.5 | bit-identical (max diff 0.0) |

Weights resident after load: dev 42.66 -> 33.34 GiB, klein 7.56 -> 6.03 GiB (measured after `gc.collect()`, the freed layers are not released until the cycle collector runs).

The klein latency was noisier on a second host (52 ms pre, 40 to 45 ms post), but the ratio was the same.

## Tests

CPU only, added to existing files:
- `test_qwen3_encoder.py`: `hidden_states` at the read indices are equal between the full and the truncated model, and the layer count is `max(k) + 1`.
- `test_text_encoder_loader.py`: the Mistral3 wrapper resolves to its language model and is truncated to `max(k) + 1`. A real Mistral3 forward needs a tensor parallel group, so output equality for it is covered by the GPU run above.

4 existing cases in `test_text_encoder_loader.py` (`test_native_encoder_restoration_checks_checkpoint_before_fallback`) fail with "world group is not initialized" when that file is run on its own. They fail the same way on unmodified main.

## Notes

Only `Flux2PipelineConfig` and its subclasses are affected. Other pipelines that use the same encoders are unchanged.
