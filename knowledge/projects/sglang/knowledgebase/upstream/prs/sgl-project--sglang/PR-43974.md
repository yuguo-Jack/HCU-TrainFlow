## Original PR description

## Motivation

Closes #43971. Measured cache misses (zero), positive reuse and unreported counts are different states. Current reporting drops explicit zero but substitutes missing counts while summing prompts, and multimodal details can invent a cache count.

## Modifications

- Preserve explicit nonnegative cached-token counts, including zero; omit unknown/invalid counts.
- Publish aggregate cache totals only when every contributing prompt is known; preserve choice de-duplication and use the actual prompt-index map for streaming.
- Align normal, continuous and final-stream reporting and omit unknown cache fields without dropping measured multimodal counts.
- Add generic CPU regressions in `test_cache_usage_reporting.py`.

This is usage projection only: no signing/proof protocol, authority service, registry, model parameters, dependency/lock changes or cache-storage implementation. Generic cached tokens do not establish paid write/TTL retention.
