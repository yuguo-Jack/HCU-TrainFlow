# [Perf] diffusion/pi05: Optimize prefix encoding and action denoising

[Upstream PR](https://github.com/sgl-project/sglang/pull/47697) · state: open · merged: False

## Original PR description

## Motivation

Reduce Pi0.5 inference latency while keeping the existing attention backend as the default.

## Modifications

Five commits separate checkpoint compatibility from inference optimizations:
- Fix duplicate empty-camera slots and exclude processor-state files from weight loading.
- Reuse prefix computations and preserve K/V ownership across graph replays and cached requests.
- Add opt-in full-loop CUDA graphs and timestep conditioning caching.
- Add opt-in fused normalization using generic preserve-reduction RMSNorm, with bitwise verification and Torch fallback.
- Add opt-in `action_attention_backend="triton_split_kv"`; `auto` remains the default.

## Accuracy Tests

40 recorded **LIBERO-10** observations (10 tasks × 4), fixed noise, identical checkpoint and native BF16/FP32 parameters:
- Prefix reuse + loop graphs + time cache + fused norm: **64,000 action values bitwise equal** to both the graph-enabled baseline and eager execution.
- Enabling split-KV is **not bitwise equivalent**: max absolute error **0.008609**, RMSE **0.000603** on normalized actions.

These results cover the tested inputs/configuration; closed-loop task success was not evaluated here.

**87 tests passed** on RTX 4090 (runtime helpers, prefix cache/graphs, RMSNorm, split-KV). Changed-file pre-commit and documentation link checks passed. Repository-wide Rust hooks could not run locally because `cargo`/`rustup` are unavailable.

## Speed Tests and Profiling

RTX 4090 24 GiB; PyTorch 2.13.0+cu129 / Triton 3.7.1; 4 CPU threads, batch 1, action chunk 50×32, 10 denoising steps. Each configuration uses a fresh process, 80 warmup requests and 200 measured requests.

| Configuration | Mean | P95 | Latency reduction |
|---|---:|---:|---:|
| Baseline, existing CUDA Graphs enabled | 71.94 ms | 72.29 ms | — |
| Prefix reuse + loop graphs + time cache + fused norm | **58.88 ms** | 59.18 ms | **18.2%** |
| Above + optional split-KV | **52.14 ms** | 52.68 ms | **27.5%** |

Baseline: `103041ad` (main `464187fa` plus the same checkpoint fixes); optimized: `3df2656e`. Prefix/action graph capacities are 16 in both arms, covering all 12 observed lengths; measured graph hit rate is 100%. Global prefix caching is disabled. A final baseline rerun measured **72.03 ms** (0.12% drift).

The optimized row enables `enable_action_loop_cuda_graph`, `enable_action_time_cache`, and `enable_fused_norm`, retaining `action_attention_backend="auto"`. Baseline profiling already shows Flash Attention for vision and efficient SDPA for masked Gemma attention; CPU thread, prompt-bucket and SDPA-priority sweeps did not improve it.

Timing covers prepared CPU observations → normalized CPU actions, including transfers; excludes preprocessing, network, model loading and graph capture. Checkpoint SHA256: `877b3ec1130548b69af7f8aeef3ec9d3fc7738040f0b9beb490857ec970997ae`.
