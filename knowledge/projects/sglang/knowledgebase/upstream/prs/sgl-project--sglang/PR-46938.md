# [CI] test: Defer serving benchmark imports

[Upstream PR](https://github.com/sgl-project/sglang/pull/46938) · state: closed · merged: False

## Original PR description

## Motivation

CPU tests that only need `CustomTestCase` also initialize the serving benchmark, model configuration, and FlashInfer when they import `sglang.test.test_utils`. This adds startup work even when the test never runs a benchmark. Deferring that work reduced mean helper import time from 13.23 seconds to 5.92 seconds in the local samples below.

## Modifications

Load `run_benchmark` when a benchmark helper or its existing named import first needs it. Cache the original function object and keep both helpers compatible with patches to `sglang.test.test_utils.run_benchmark`.

## Accuracy Tests

Passed the existing benchmark endpoint and steady-state benchmark tests:

```sh
PYTHONPATH=python CUDA_VISIBLE_DEVICES=0 python -m pytest -q test/registered/unit/bench/test_benchmark_endpoint.py test/registered/bench_fn/test_steady_state_benchmark.py
pre-commit run --files python/sglang/test/test_utils.py
```

A separate mocked smoke check verified the legacy import's function identity, both helper paths, warmup calls, returned results, and process teardown. An import check confirmed that importing `CustomTestCase` leaves benchmark serving unloaded.

## Speed Tests and Profiling

Measured on local Linux with Python 3.12 and `CUDA_VISIBLE_DEVICES=0`, after preloading the CPU worker's NumPy, pytest, SciPy, Torch, and Triton modules. The fresh-process order was `base → change → change → base`, with two samples per version. The table measures the additional `test_utils` import, excluding preload time.

| Measurement | Before | After |
| --- | --- | --- |
| Mean helper import time | 13.23 s | 5.92 s |
| Observed range | 10.96–15.49 s | 4.81–7.02 s |
| Serving benchmark loaded by the helper import | Yes | No |

The observed mean decreased by 7.31 seconds (55%) in this small sample. This measures import startup only; full CI duration and inference performance were not measured. Tests that later need the model stack will still pay its initialization cost.
