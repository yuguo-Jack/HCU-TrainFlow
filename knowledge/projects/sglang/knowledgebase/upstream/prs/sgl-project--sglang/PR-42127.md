# fix(multimodal): convert grayscale tensors to RGB in PIL backend

[Upstream PR](https://github.com/sgl-project/sglang/pull/42127) · state: closed · merged: True

## Original PR description

## Motivation

With `--image-processor-backend pil`, a grayscale JPEG decoded as a single-channel tensor can fail during RGB normalization with `mean must have 1 elements if it is an iterable, got 3`. The PIL backend converts PIL images to RGB but leaves grayscale tensors single-channel.

## Modifications

- Preserve the existing CUDA tensor-to-CPU handling.
- After PIL backend processing resolves the channel layout, expand a single-channel tensor to three channels when `do_convert_rgb` is enabled.
- Add regression tests comparing a grayscale JPEG tensor with its PIL RGB equivalent, and covering the conversion flag and channel layout.

## Accuracy Tests

- Reproduced the original channel-count failure before the fix.
- The relevant tests passed on a GPU machine with Transformers 5.17.0.

## Speed Tests and Profiling

Not run; this is a correctness fix for grayscale tensor inputs.
