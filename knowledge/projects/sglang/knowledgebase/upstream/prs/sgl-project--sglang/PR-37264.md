## Summary

- extend the parser coverage added by #43669 with default, preset, composition, current numeric-selector, and unknown-token contracts
- cover enabled/disabled and single-rank `SpecTpSync.sync` behavior
- cover distributed-min versus local available-memory calls

## Overlap and remaining scope

Upstream #43669 now owns the retired DSpark draft-handle compatibility tests and the merged `dspark-draft` selector. This PR was rebased onto that change and preserves those upstream tests. Its remaining diff is test-only and covers the non-overlapping helper behavior: environment default and preset semantics, parser composition/error handling, collective gating, identity return, rank-zero source selection, and memory-reduction arguments.

No production code is changed.

## Why

`SpecTpSync` protects DSpark and DFlash decisions that must stay identical across TP ranks. The upstream parser tests cover the recent selector migration, but the helper execution boundary and memory-reduction behavior still had no direct unit coverage.
