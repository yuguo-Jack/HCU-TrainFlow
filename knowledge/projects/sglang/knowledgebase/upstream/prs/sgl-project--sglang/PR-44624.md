# [Feat] [CPU] model: Support Muse models on CPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/44624) · state: closed · merged: True

## Original PR description

## Motivation

The meta-models/Muse-Glimmer-30B model can not be configured with TP=6 and launched successfully in a CPU environment.

The following three dimensions are not divisible by 6: 
- Number of visual attention heads: 16
- Visual MLP intermediate dimension: 8960
- Vision adapter intermediate layer: 4096


## Modifications

Zero-padding logic applied for Muse-Glimmer-30B model:
- Visual heads padded from 16 to 18; visual MLP intermediate dimension padded from 8960 to 9024.
- `VisionAttention `and visual RoPE switched to use `config.head_dim`; `projection_size` updated to `heads * head_dim` (18 × 96 = 1728).
- To satisfy AMX GEMM alignment requirements for input dimensions per shard (IC % 32), the adapter's fc1 output/fc2 input dimension is rounded up to the nearest multiple of `tp * 32` (4096 → 4224).
 


## Accuracy Tests

The meta-models/Muse-Glimmer-30B model starts up correctly, and the accuracy of responses for both text and image inputs is normal. The Acc of GSM8K benchmark is 96.79%.
