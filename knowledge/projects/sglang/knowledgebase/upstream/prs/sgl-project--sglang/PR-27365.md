The following two test cases in the nightly pipeline failed.

Changing the default test model to "Qwen/Qwen3.5-9B" introduces two major concerns:

1. **Model Existence & Accessibility**: There is no public "Qwen/Qwen3.5-9B" model on the Hugging Face Hub. If this is a typo for a public model (such as "Qwen/Qwen2.5-7B-Instruct"), it should be corrected. If it is a private or internal model, setting it as the global `DEFAULT_MODEL_NAME_FOR_TEST` will prevent external contributors from running the test suite locally.
2. **Test Suite Compatibility**: Many tests in the repository import `DEFAULT_MODEL_NAME_FOR_TEST` and may implicitly rely on Llama-specific tokenizer properties, vocabulary sizes, or chat templates. Changing the default model from Llama to Qwen without updating those dependent tests is highly likely to cause widespread test failures.

Consider using a widely available, public model that does not require gated permissions (e.g., "Qwen/Qwen2.5-7B-Instruct") and ensure all dependent tests are updated or verified for compatibility.

```suggestion
DEFAULT_MODEL_NAME_FOR_TEST = "Qwen/Qwen2.5-7B-Instruct"
```
