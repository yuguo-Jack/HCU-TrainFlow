# [Doc] docs: Fix stale links to moved and removed repo files

[Upstream PR](https://github.com/sgl-project/sglang/pull/47314) · state: open · merged: False

## Original PR description

## Motivation

Several docs pages link to repo files that were moved or deleted, so the links return 404 on GitHub.

## Modifications

- `docs/docs/supported-models/support_new_models.mdx`: `test_generation_models.py` moved from `test/registered/models/` to `test/registered/e2e/models/`, so the link now points there. That file no longer has an `ALL_OTHER_MODELS` list (its own docstring says to add new models to `ALL_MODELS`), so I updated the list name too.
- `docs/cookbook/autoregressive/GLM/GLM-5.3-Flash.mdx`: the `compute-mamba-ratio` skill is at `.agents/skills/compute-mamba-ratio/SKILL.md`. Nothing exists under `.claude/skills/`.
- `docs/docs/references/multi_node_deployment/lws_pd/lws_pd_deploy.mdx`: the `lws-examples/*.yaml` files were deleted in the Mintlify cutover (#28964). Each manifest is already shown inline right below its heading, so I removed the five dead links and kept the filenames as plain text. The prefill and decode files were called `prefill.yaml` / `decode.yaml` while the deploy step runs `kubectl apply -f p.yaml` / `d.yaml`, so they're now named `p.yaml` / `d.yaml` to match.

These are docs-only changes. Every new link target was checked against current `main`, and a scan of the repo's `.md`/`.mdx` files finds no other `github.com/sgl-project/sglang/blob/main/...` links that point to missing files.

AI assistance was used to find and make these edits. I reviewed the diff.
