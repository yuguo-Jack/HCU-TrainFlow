# [Feat] tbo: Add opt-in threshold-based admission policy

[Upstream PR](https://github.com/sgl-project/sglang/pull/47290) · state: closed · merged: False

## Original PR description

## Summary

Implements the admission part of RFC #47289:

- add opt-in `--tbo-admission-policy {always,threshold}` (default `always` keeps current behavior);
- under `threshold`, reject TBO locally when the batch is below `--tbo-prefill-token-threshold` / `--tbo-decode-token-threshold`, or when either child has fewer than `--tbo-min-child-tokens` real tokens or is empty;
- the rejection reuses the existing `local_can_run_tbo` vote, so all DP ranks reach the same decision without a new collective field;
- reject reasons are logged under `SGLANG_TBO_DEBUG`; fallback metrics are left as follow-up;
- validate the new integer args are non-negative;
- add CPU unit coverage for decode, prefill, child minimum, empty child, and `always`.

## Validation

- `python -m py_compile` and `git diff --check` pass.
- Unit tests and a TBO-off vs `threshold` performance / token-equality comparison are pending; results will be added here before marking ready.

Refs #47289
