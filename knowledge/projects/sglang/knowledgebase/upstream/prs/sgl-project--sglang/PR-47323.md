# [Perf] diffusion/attention: Fuse VSA tile packing and layout conversion

[Upstream PR](https://github.com/sgl-project/sglang/pull/47323) · state: open · merged: False

## Original PR description

## Motivation

VSA packs Q/K/V/gate into a tiled BSHD buffer, then copies each tensor into contiguous BHSD storage before attention. This PR replaces that gather/scatter/copy chain with one Triton kernel that writes tiled BHSD output directly.

## Modifications

- Fuse tile packing, zero padding and layout conversion; reuse the output buffer.
- Return a BSHD view to keep the attention interface. The existing transpose/contiguous calls then need no copy.
- Keep the old path for sequence-parallel execution and inputs outside the kernel's CUDA, dtype and head-dimension limits.

## Accuracy Tests

- 14 kernel/backend tests pass on RTX 5090, covering partial tiles, strided inputs (including offsets beyond int32), padding reuse, dtype/shape changes and fallback. The backend test checks for host synchronization after warmup.
- All 12 benchmark videos and both profile videos are byte-identical to the baseline. The decoded 61 frames are pixel-exact: mean/worst-frame SSIM 1, PSNR infinity.

## Speed Tests and Profiling

RTX 5090, native SGLang FastWan2.1-T2V-1.3B, 832x480, 61 frames, 3 steps, seed 42, sparsity 0.8. BF16 DiT/VSA, FP32 T5; T5 layerwise offload, resident DiT/VAE, conditioning cache disabled.

Same configuration for both variants. Three ABBA rounds, six samples each; every process runs a matching request warmup. Timings exclude startup, model loading and warmup. Profiler runs are separate.

| Metric, median | Baseline | This PR | Reduction |
|---|---:|---:|---:|
| Generation request | 4185.33 ms | 4082.38 ms | 2.46% |
| Denoising | 1870.79 ms | 1766.25 ms | 5.59% |

Request ranges: 4180.25–4191.90 ms baseline, 4080.46–4084.35 ms patched. The three ABBA rounds improve request latency by 2.44%, 2.45%, 2.52%.

The full-video profile replaces 90 gathers, 90 scatters and 360 layout copies with 90 fused launches. Layout GPU time falls from 144.35 to 37.68 ms. Peak reserved memory falls by 300 MiB; peak allocated memory is effectively unchanged.

Measured with Torch 2.11.0+cu128 and Triton 3.6.0 in a CUDA 12 compatibility environment, not main's pinned dependency set. Multi-GPU inference, torch.compile and CUDA Graphs were not tested.
