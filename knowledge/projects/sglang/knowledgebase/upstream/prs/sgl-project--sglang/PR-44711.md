# [CI] diffusion: restrict 5090 performance checks to qualified runners

[Upstream PR](https://github.com/sgl-project/sglang/pull/44711) · state: closed · merged: False

## Original PR description

The diffusion 5090 job compares measurements against fixed performance baselines while accepting every runner with the generic `1-gpu-5090` label. Recent executions of the same code show substantial differences across runners, including persistent failures on main.

Require the additional `diffusion-perf-qualified` label for this job. Existing generic 5090 jobs keep their current runner selection, and the performance baselines and tolerances stay unchanged.

**Rollout prerequisite:** keep this PR in draft until a runner has passed qualification against the existing main-branch suite, its available capacity has been checked, and a runner administrator has added both required labels. Merging before qualifying and labeling capacity would leave this job queued.
