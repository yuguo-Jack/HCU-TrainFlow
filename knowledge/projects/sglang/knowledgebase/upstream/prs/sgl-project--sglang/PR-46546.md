# [Doc] cookbook: MiniMax-M3.1 GB200 recipes and B200 Low-Latency (MonoKernel)

[Upstream PR](https://github.com/sgl-project/sglang/pull/46546) · state: closed · merged: True

## Original PR description

## Motivation

The MiniMax-M3.1 Deployment panel has no GB200 entry and no B200 Low-Latency recipe. SemiAnalysis InferenceX runs MiniMax-M3.1-Flash on both:

- [SemiAnalysisAI/InferenceX#4509](https://github.com/SemiAnalysisAI/InferenceX/pull/4509) runs the MSA-V1 MonoKernel at batch size 1 on B200 and GB200 (run [40194550246](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/40194550246)).
- [SemiAnalysisAI/InferenceX#4491](https://github.com/SemiAnalysisAI/InferenceX/pull/4491) runs TP4 and TP4 + EP4 on GB200.

This PR adds those recipes to the cookbook.

## Modifications

`docs/src/snippets/configs/MiniMaxAI/minimax-m3.1.jsx`:

- **B200 Low-Latency (new cell).** The B300 MonoKernel command, unchanged. The plugin supports sm_100 at `--tp 4`, and InferenceX#4509 runs this exact flag set on B200.
- **GB200 (new hardware, three cells).**
  - Balanced: the B200 Balanced command, unchanged.
  - High-Throughput: B200's recipe (`--tp 8 --attn-dp-size 2 --ep 8`) needs 8 GPUs, and a GB200 node has 4. GB200 therefore uses the GB300 TP4 + EP4 (MegaMoE) recipe, plus B200's `--cuda-graph-max-bs-prefill 16384`, because GB200 has 186 GB per GPU. InferenceX#4491 runs TP4 + EP4 on GB200 at `--mem-fraction-static 0.8`.
  - Low-Latency: the MonoKernel command, unchanged.
- `gb200` is added to `supportedHardware`, `dockerImages` (`lmsysorg/sglang:dev-minimax-m31-flash`, the same image as GB300) and `BLACKWELL_HW`. Without the last one, DFlash2 on GB200 would show a "requires Blackwell" reason instead of the MonoKernel one. The DFlash2 hint now lists GB200 High-Throughput next to GB300.
- Every new cell has `verificationStatus: "in-progress"`, so the panel shows **Final Verification In Progress**.

`docs/cookbook/autoregressive/MiniMax/MiniMax-M3.1.mdx`: the strategy list, the MonoKernel section and the memory tuning notes now mention B200 / GB200.

The AgentX section is not changed. Its data file is generated by the sa-infx-cookbook sync, which can mirror InferenceX#4509 once that PR merges.
