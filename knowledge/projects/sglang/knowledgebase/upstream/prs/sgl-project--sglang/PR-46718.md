# [Refactor] dsv4: Set the tail source KV layer id in a capture stub

[Upstream PR](https://github.com/sgl-project/sglang/pull/46718) · state: closed · merged: True

## Original PR description

- The DeepSeek V4 `write_tail_source_kv` break writes the compressed KV of the tail's source layer and sets `tail_source_kv_layer_id`, by which that layer skips its own compressor inside the tail. A capture stub now sets only the layer id while the breakable prefill graph captures.
- Replay and eager runs are unchanged. At capture, the stub runs in place of the body, as `capture_stub` already works: the capture pass no longer writes KV computed from inputs the graph has not produced yet, and the backend holds the same layer id afterwards.
- This is needed before the capture pass stops running break bodies. Without the stub, the id would stay `None` at capture: on CUDA the source layer's compressor would run during capture on the tail rows, and on HIP `enter_late_layer_tail` would fail its assert.
- Tests: `test_dsv41_late_layer_tail_readers.py`, `test_num_token_non_padded_localization.py`, `test_encoder_swa_replay.py`, `test_eager_on_graph.py` pass on CPU.
