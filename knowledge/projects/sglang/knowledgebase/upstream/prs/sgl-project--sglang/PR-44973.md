## Motivation

DSPARK with FA4 and unified memory needs physical FULL/SWA page tables refreshed from live allocator mappings on graph replay. Building translated verify metadata outside capture adds scheduler work and launches.

## Modifications

Replayed onto the corrected prerequisites; the launch-size comment reflects the translated gather path.

- Build translated verify tables and sequence metadata in captured work using explicit FULL/SWA virtual-to-physical tensors.
- Make tail clearing an explicit metadata contract and keep lengths-only callers separate.
- Add graph-replay, mapping, strided-storage, and fused-placement tests.
- Admit FA4 for DSPARK with unified memory while preserving the existing EAGLE/DFLASH restrictions.
