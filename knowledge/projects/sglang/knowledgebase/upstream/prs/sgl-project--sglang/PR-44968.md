# [Refactor] hicache: Route Mamba host transfers from pool info

[Upstream PR](https://github.com/sgl-project/sglang/pull/44968) · state: closed · merged: True

## Original PR description

## Motivation

Followup of #43596. The hybrid Mamba stacks built the controller routing from `req_to_token_pool.mamba_map` while the Mamba host pool was built from the pool's `DevicePoolInfo`, so routing and host layout came from two separate sources. The assembler now captures the info once and derives both from its `layer_ids`. The packed draft offset uses the same axis instead of `num_mamba_layers`.

The direct linker still reads `mamba_map` and will move with the linker migration.

## Accuracy
