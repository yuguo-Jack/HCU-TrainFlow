# [PDMux] Reserve Mamba and HiCache state across prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/42412) · state: closed · merged: False

## Original PR description

## Motivation

An admitted prefill can run out of Mamba slots when tracking, checkpointing or HiCache load-back allocates state later. Reserve those slots at admission so memory pressure defers the request before model execution. Large HiCache host buffers also need recoverable CUDA registration.

## Changes

- Reserve live, ping-pong and checkpoint slots transactionally, including requests continuing across chunks; consume reservations in request allocation and HiCache load-back.
- Release unused reservations on checkpoint bypass, completion and abort. Roll back partially prepared load-back state on failure.
- Retry requests through scheduler admission when slots are unavailable, preserving HiCache dependencies across prefill/decode overlap.
- Register large host buffers in aligned chunks and unwind completed registrations if a later chunk fails.
