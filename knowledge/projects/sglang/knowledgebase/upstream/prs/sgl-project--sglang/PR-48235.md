# [Test] [NVIDIA] flash-attn: batch-invariance test for FA4 absorbed MLA

[Upstream PR](https://github.com/sgl-project/sglang/pull/48235) · state: open · merged: False

## Original PR description

## Motivation

Deterministic inference on SM100/SM110 runs absorbed MLA through the in-tree FA4 (`flash_attn.cute`) `qv` kernel with `num_splits=1`. True on-policy RL and batch-invariant serving require a request's output bits to remain identical across batch compositions and execution phases. While `test_flash_attn_varlen_qv_deepseek_absorbed` validates numerical accuracy, there was no bitwise regression test covering batch invariance and prefill-vs-decode equivalence.

## Modifications

- Add `test_flash_attn_qv_deepseek_absorbed_batch_invariant` (`nheads in {16, 128}`, `page_size in {1, 128}`) in `test/registered/kernels/ops/attention/test_flash_attention_4.py`, verifying `int16` bitwise equality across:
  - solo request vs. mixed variable-length prefill/decode batch;
  - one-shot prefill vs. non-tile-aligned prefix cache hit + extend;
  - teacher-forced prefill rows vs. step-by-step autoregressive decode.
