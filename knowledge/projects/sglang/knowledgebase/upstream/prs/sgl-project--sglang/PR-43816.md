# [Fix] hicache: Key MLA Mamba state per TP rank in the SeaweedFS backend

[Upstream PR](https://github.com/sgl-project/sglang/pull/43816) · state: closed · merged: True

## Original PR description

## Motivation

MLA shares KV storage keys across TP ranks, but Mamba checkpoints are sharded. Give SeaweedFS Mamba keys a TP rank/size suffix so one rank cannot overwrite another rank's checkpoint. Keep existing keys for other pools. Same fix as #43594 for NIXL.

Old unranked Mamba objects are not reused because their owning rank is ambiguous.

Validation: the new two-rank Mamba round-trip test fails before and passes after; the SeaweedFS test module passes.
