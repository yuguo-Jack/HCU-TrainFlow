# [Perf] [AMD] glm5: Tune sampling, shared-expert fusion, and DSA kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/46880) · state: open · merged: False

## Original PR description

## Motivation

- HIP shared-expert fusion for Glm5Next is admitted only at TP4 and TP8. TP1 is unsharded, so the shared expert already has the same shape as one routed expert, and the gate still refuses it.
- The DSA fp8 partial decode kernel hardcodes a 16-head tile. That tile is not always the one that fills the grid. A RoPE tail cannot take a wider tile: TileLang infers two layouts for `acc_s` and refuses to build a 32- or 64-head tile.

Sampling is unchanged. The 2048-wide top-p prefix is not in this PR.

## Modifications

- Admit HIP shared-expert fusion at TP1 for Glm5Next, beside TP4 and TP8. Any other TP size is still rejected.
- Size the DSA fp8 partial decode head tile to the grid, on gfx950 only. Other targets keep the fixed 16-head tile.
  - The pick is the largest tile in `(64, 32, 16)` that still fills the grid. A tile wider than `num_heads` pads rows without shrinking the grid, so candidates stop at `num_heads`, and every candidate including the fallback satisfies `num_heads <= h or num_heads % h == 0`.
  - A RoPE tail (`d_tail != 0`) pins the tile to 16. GLM-5.3-Flash has `qk_rope_head_dim=0` and keeps the wide tiles.

## Accuracy Tests

Unit tests on one MI355X. No model-level accuracy run is included.

| test | result |
|---|---|
| `test/registered/unit/models/test_shared_experts_fusion_gates.py` (Glm5Next TP1/TP4/TP8 contract) | 48 passed, 1 failed |
| `test/registered/kernels/ops/attention/test_pick_h_per_block.py` | 7 passed |

The one failure is `TestDeepseekV2Gate::test_expert_parallelism_blocks_fusion_off_rocm`, and it fails the same way on `main` on this host. That case asserts the non-ROCm branch of the DeepseekV2 gate, which an MI355X does not take. This PR touches only the Glm5Next gate.

The head-tile helper never returns a tile the kernel assert would reject, never pads past `num_heads`, and returns 16 for every tail.
