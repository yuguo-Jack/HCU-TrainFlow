# [PDMux] Support layerwise MTP and DSpark for DeepSeek-V4.1-Flash

[Upstream PR](https://github.com/sgl-project/sglang/pull/42514) · state: closed · merged: False

## Original PR description

## Motivation

Single-NextN/EAGLE and DSpark need complete target prefill state before draft extension or KV injection. This layer connects both paths to split PDMux and performs final-only post-processing while preserving batch-owned captures.

## Changes

- Capture full pre-mHC NextN states shaped `[tokens, hc_mult * hidden_size]`. Hand the final target result to an independent draft batch view and publish draft inputs/sequence lengths once.
- Retain DSpark auxiliary captures and tail row indices across slices; inject draft KV after target completion. Final DSpark IDLE results without logits return directly without injection; EAGLE IDLE ranks retain the empty-seed draft-extend path.
- Match the [pdmux-standard layer_split reference](https://github.com/Li-brua/sglang/tree/17761860ccbc6cea53b0c3625fa0c89880b48f9e) final-slice flow without an additional bidirectional handoff fence. The optional planner stream follows `SGLANG_ENABLE_OVERLAP_PLAN_STREAM`.
- Retain DeepSeek decode/verify backend isolation so metadata updates cannot invalidate an unfinished split prefill. Switch target/DSpark decode backends through the shared PDMux hook; preserve EAGLE's per-step draft context.
- Keep per-slice prepare/pad/unpad, eager EAGLE draft execution, target/DSpark per-stream graph paths and ordinary heterogeneous-DP speculative coordination.

Support is scoped to single-layer NextN/EAGLE and explicitly adapted DSpark targets. Existing algorithm, tail and DP restrictions remain enforced.
