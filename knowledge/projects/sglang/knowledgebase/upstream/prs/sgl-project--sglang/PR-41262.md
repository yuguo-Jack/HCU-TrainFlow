# [DO NOT MERGE][XPU] Install sglang-kernel-xpu from sgl-kernel-xpu main branch

[Upstream PR](https://github.com/sgl-project/sglang/pull/41262) · state: open · merged: False

## Original PR description

## Motivation

`python/pyproject_xpu.toml` pins `sglang-kernel-xpu` to the `v0.2.0+xpu` release wheel in `sgl-project/whl`. Kernel changes merged to `sgl-kernel-xpu` main are not picked up until a new release wheel is built and published via `release-whl-kernel-xpu.yml` and this URL is bumped.

## Modifications

Point the dependency at the `sgl-kernel-xpu` main branch instead of the release wheel:

```diff
-  "sglang-kernel-xpu @ https://github.com/sgl-project/whl/releases/download/v0.2.0+xpu/sglang_kernel_xpu-0.2.0-cp310-abi3-manylinux_2_38_x86_64.whl",
+  "sglang-kernel-xpu @ git+https://github.com/sgl-project/sgl-kernel-xpu.git@main",
```

## Notes

- With a git reference, `pip install .` builds `sglang-kernel-xpu` from source (scikit-build-core + CMake). The install environment needs the oneAPI/SYCL toolchain (`source /opt/intel/oneapi/setvars.sh`), and install time increases.
- Installs are no longer reproducible across time since `main` moves.
