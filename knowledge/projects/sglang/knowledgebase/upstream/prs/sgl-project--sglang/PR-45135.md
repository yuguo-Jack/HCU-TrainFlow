# [CI] workflows: Skip optional test workflows without opt-in labels

[Upstream PR](https://github.com/sgl-project/sglang/pull/45135) · state: open · merged: False

## Original PR description

## Motivation

PRs without CI opt-in labels currently get red Base, AMD, AMD Extra, and Extra checks: the shared gate fails on the missing label, and the finish jobs fail in turn even though no tests ran.

## Modifications

- Add a metadata-only opt-in workflow that reads current PR labels. Missing labels skip optional tests successfully; adding labels and rerunning picks up the new label set.
- Keep the existing draft, label, and cooldown gate for opted-in runs. Require successful opt-in before starting builds or extra tests, skip AMD change detection when not opted in, and gate every Base build, test, and wait job so later `always()` jobs cannot launch tests.
- Preserve scheduled and parallel-dispatch Base runs and scheduled extra runs when their PR gate is skipped.
- Add hosted regression CI for label changes, API failures, downstream job gating, and scheduled execution. Use checkout/setup-node v6 and Node.js 24.

## Validation

- [Fork CI passed on 8f3ab69c63](https://github.com/zydo/sglang/actions/runs/39222125471): all six jobs, including 23 regression tests and reusable-workflow integration checks.
- Confirmed four regression checks fail against the original workflows.
- Pre-commit passed for changed files; actionlint passed for the new workflows.
- Full GPU suites were not run because the fork has no self-hosted GPU runners.
