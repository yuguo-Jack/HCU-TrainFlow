# [Perf] multimodal_cache: reuse precomputed combined_hash in MultiModalStaticCache.get

[Upstream PR](https://github.com/sgl-project/sglang/pull/46552) · state: open · merged: False

## Original PR description

## Motivation

`MultiModalStaticCache.get(self, mm_hashes: List[int], combined_hash: Optional[int] = None)` accepts an optional precomputed `combined_hash` (matching the base `MultimodalCache.get` interface), but previously overwrote it unconditionally on the first line:
```python
combined_hash = self.combine_hashes(mm_hashes)
```
As a result:
1. Any caller passing a precomputed `combined_hash` had its value ignored and `hash(tuple(mm_hashes))` recomputed.
2. Both multimodal embedding cache callers (`_get_chunked_embedding_full` in `python/sglang/srt/managers/mm_schedule.py` and the disaggregated encoder cache lookup in `python/sglang/srt/disaggregation/encoder/server.py`) already compute `MultiModalStaticCache.combine_hashes(...)` immediately before calling `.get(...)`, causing `combine_hashes` to be computed twice on every multimodal request lookup.

## Modifications

- In `MultiModalStaticCache.get` (`python/sglang/srt/mem_cache/multimodal_cache.py`), only compute `self.combine_hashes(mm_hashes)` when `combined_hash is None`.
- Pass the already-computed `combined_hash` in `_get_chunked_embedding_full` (`python/sglang/srt/managers/mm_schedule.py`) and in the disaggregated encoder server (`python/sglang/srt/disaggregation/encoder/server.py`).
- Add a unit test (`test_multimodal_static_cache_reuses_precomputed_combined_hash`) in `test/registered/chunked_prefill/test_mm_chunked_embedding_unit.py`.

Full credit to the SGLang multimodal caching and chunked prefill authors who designed `MultimodalCache` / `MultiModalStaticCache` and `mm_schedule.py`.
