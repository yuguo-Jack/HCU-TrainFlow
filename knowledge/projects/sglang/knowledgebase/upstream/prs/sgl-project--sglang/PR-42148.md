# [AMD][CI] setup: Skip redundant pip-cache chown walk and MORI rebuild

[Upstream PR](https://github.com/sgl-project/sglang/pull/42148) · state: closed · merged: True

## Original PR description

## Motivation

Two operations I've identified in the AMD CI script that could be omitted include recursively changing owner permissions on all files in `pip-cache` and rebuilding MORI when it has the correct version already. These steps add approximately 4 minutes and 2.5 minutes respectively. Aggregated across an entire week, this adds up to about 2000 hours of GPU runtime. This is approximately 17% of the time CI takes. By reducing the time these steps take, we should see reduced demand for AMD CI nodes.

## Modifications

- Changed the ownership of the `pip-cache` folder only to `root` to avoid long-running recursive modification.
- Triggers MORI build only when necessary
