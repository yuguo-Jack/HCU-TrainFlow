# [Perf] tokenizer: Avoid redundant initialization during startup

[Upstream PR](https://github.com/sgl-project/sglang/pull/45095) · state: closed · merged: False

## Original PR description

## Motivation

Make startup a little faster by avoiding redundant tokenizer initialization. Fixes #45094.

## Modifications

- Reuse the scheduler's tokenizer in the same-process TP worker for the standard text HuggingFace path.
- Load only the pre-tokenizer and decoder when applying the v5 compatibility fix, without rebuilding the vocabulary.

## Validation

- 152 unit tests and pre-commit passed.
- Local Qwen3-32B-FP8 on one H100: the component repair step dropped from about 240 ms to 18 ms. Startup followed by 32 concurrent generation requests passed.
