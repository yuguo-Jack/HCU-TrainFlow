# fix(openai): include cache details in continuous Completions usage

[Upstream PR](https://github.com/sgl-project/sglang/pull/28801) · state: open · merged: False

## Original PR description

The `/v1/completions` streaming handler tracks cached tokens but omits them from `continuous_usage_stats` chunks. This adds `prompt_tokens_details` with the per-choice cached count when `--enable-cache-report` is enabled, including zero. Disabled reporting stays unchanged.

Adds a handler regression test for zero, positive, and disabled-reporting cases. The response/final-stream and Chat zero-value fix is split into #44010; these PRs can merge independently.

Thanks to @rlrs for the earlier investigation and implementation in #20203.

Validation: pre-commit and `git diff --check` passed. Isolated streaming checks passed for cache counts, reporting flags, repeated chunks, and multiple choices; the same checks reproduce the bug on `main`. Full registered handler tests were not run locally because PyTorch/FastAPI are unavailable.
