# [Fix] spec: Remove `--speculative-skip-dp-mlp-sync`

[Upstream PR](https://github.com/sgl-project/sglang/pull/45043) · state: closed · merged: True

## Original PR description

- Remove `--speculative-skip-dp-mlp-sync`: its field, its startup check, its conditions in `Scheduler.get_next_batch_to_run` and in the DSpark planner, and its rows in the server arguments docs
- The speculative pre-sync under DP attention now runs whenever `SGLANG_ENABLE_DP_SPEC_PREFILL_COORDINATION` is off

Launch commands that pass the flag now fail with an unrecognized-argument error. With attention DP outside PD disaggregation, the flag let one DP rank prefill while another decoded, which sent the decoding rank's batch into the prefill path, raised `AttributeError` and took the server down (reproduced with GLM-4.7-Flash and its MTP draft, DP 2); `SGLANG_ENABLE_DP_SPEC_PREFILL_COORDINATION=1` skips the same sync safely. In every other configuration the flag changed nothing that runs.
