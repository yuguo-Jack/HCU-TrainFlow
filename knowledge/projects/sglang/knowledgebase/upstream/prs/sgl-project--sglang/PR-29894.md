# Fix /server_info 500 error when load_format is set to a custom loader class

[Upstream PR](https://github.com/sgl-project/sglang/pull/29894) · state: closed · merged: False

## Original PR description

## Summary

http_server `GET /server_info` raises a `ValueError` and returns HTTP 500 whenever `server_args.load_format` is a **class** rather than a string. This happens for any custom model loader passed as a class — which `get_model_loader` explicitly supports (`isinstance(load_config.load_format, type)`) — and is hit in practice by out-of-tree platforms that register a custom loader (e.g. an LPU/accelerator platform that sets `load_format = MyCustomLoader`).

The `/server_info` payload is normalized through the shared `msgspec_to_builtins` helper in `python/sglang/srt/utils/msgspec_utils.py`, but that helper passes through any object it doesn't explicitly handle, so a class object reaches FastAPI's `jsonable_encoder` and crashes it.

## Symptom

A PD-disaggregation router (or any client) calling `/server_info` on such a worker gets a 500, with the server logging:

```
File ".../fastapi/encoders.py", line 345, in jsonable_encoder
    data = dict(obj)
TypeError: '_abc._abc_data' object is not iterable
...
File ".../fastapi/encoders.py", line 350, in jsonable_encoder
    data = vars(obj)
TypeError: vars() argument must have __dict__ attribute
...
ValueError: [TypeError("'_abc._abc_data' object is not iterable"),
             TypeError('vars() argument must have __dict__ attribute')]
```

## Root cause

`server_info()` builds its response from:

```python
msgspec_to_builtins({
    **dataclasses.asdict(server_args),          # includes load_format
    **_global_state.scheduler_info,
    "internal_states": internal_states,         # each entry is vars(server_args)
    "version": __version__,
    "kv_events": server_args.describe_kv_events_publisher(),
})
```

When `load_format` is a class, the class object appears twice in this payload:

1. top-level, via `dataclasses.asdict(server_args)`; and
2. inside every `internal_states[i]`, because `Scheduler.get_internal_state()` does `dict(vars(get_global_server_args()))` and only pops `model_config`.

`msgspec_to_builtins` (in `python/sglang/srt/utils/msgspec_utils.py`) handles `msgspec.Struct`, `dict`, `list`, `tuple`, and `set`, then falls through to `return obj` for everything else — so the class object passes through unchanged.

FastAPI's `jsonable_encoder` then has no rule for a bare class and falls back to `vars(cls)`. Because model-loader base classes are ABCs (`BaseModelLoader(ABC)`), the class `__dict__` contains the ABC bookkeeping attribute `_abc_impl` (an `_abc._abc_data` object), which is itself not serializable — producing the two chained `TypeError`s above.

## Fix

Add a branch to the shared `msgspec_to_builtins` helper that renders a class object as its dotted name. Because the helper already recurses through `dict` and `list`, this single branch covers both occurrences (top-level and `internal_states`) and fixes every caller, not just `/server_info`.

**File:** `python/sglang/srt/utils/msgspec_utils.py` (the `msgspec_to_builtins` function used by `server_info()` and other serialization paths).

```diff
 def msgspec_to_builtins(obj: Any) -> Any:
    """Recursively convert msgspec structs to dict/list Python builtins."""
    if isinstance(obj, msgspec.Struct):
        return {
            field.name: msgspec_to_builtins(getattr(obj, field.name))
            for field in msgspec.structs.fields(type(obj))
        }

    if isinstance(obj, dict):
        return {key: msgspec_to_builtins(value) for key, value in obj.items()}

    if isinstance(obj, list):
        return [msgspec_to_builtins(item) for item in obj]

    if isinstance(obj, tuple):
        return tuple(msgspec_to_builtins(item) for item in obj)

    if isinstance(obj, set):
        return [msgspec_to_builtins(item) for item in obj]

+  if isinstance(obj, type):
+      return f"{obj.__module__}.{obj.__qualname__}"

     return obj
```

## Reproduction / test

1. Launch a server whose `load_format` is a class (any custom loader passed as a class; out-of-tree platforms that set `load_format = SomeLoaderClass`).
2. `curl http://<host>:<port>/server_info`
   - **Before:** HTTP 500 with the traceback above.
   - **After:** HTTP 200 with `"load_format": "<module>.<ClassName>"`.
