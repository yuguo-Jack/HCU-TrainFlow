# [Fix] [NPU] tests: Prefetch the sgl_eval MMLU archive and pin the Mamba SSM dtype

[Upstream PR](https://github.com/sgl-project/sglang/pull/45589) · state: open · merged: False

## Motivation

The `nightly-1-npu-a3` MMLU case never finishes on the NPU CI runners. `sgl_eval` downloads the `cais/mmlu` archive with its own `httpx` client: it ignores `HF_ENDPOINT`, prints nothing while downloading and never retries, so the run sits silent after `sgl-eval mmlu generation: ...` until the per-file timeout. The runners can only reach Hugging Face through the mirror, so the archive must be staged before the test starts.

Separately, `test_npu_hicache_mamba` left the Mamba SSM path at the model config's dtype and failed on A3.

## Modifications

- `_npu-pr-test-stage.yml`: prefetch `data.tar` with `hf download cais/mmlu --include data.tar --local-dir` (goes through `HF_ENDPOINT`, has progress and retries), then export `SGL_EVAL_ARCHIVE_DIR`. A failed prefetch only emits a warning, so the job degrades to the previous behaviour.
- `npu_eval_accuracy_kit.py`: add `honor_local_sgl_eval_archive()`. It matches a prefetched archive by URL basename, re-checks the sha256 that `sgl_eval` pins (a stale mirror copy falls back to the original download), and hands `sgl_eval` a private copy because it unlinks the returned path. The shim is applied on import, so every NPU accuracy case benefits without per-test changes.
- `test_mmlu.py`: call the shim explicitly for the DeepEP MMLU cases, which do not import the kit.
- `test_npu_hicache_mamba.py`: pass `--mamba-ssm-dtype bfloat16` in `common_args`.
- `nightly-test-npu.yml`: PR-triggered runs only exercise `nightly-1-npu-a3`, which hosts both cases under test; every other job stays gated on non-PR events. Scheduled and manual runs are unchanged.

## Accuracy Tests

- `test_npu_sampling_backend.test_mmlu` (Qwen2.5-7B-Instruct, 64 questions, threshold 0.65): previously stalled in `nightly-1-npu-a3`; with the archive prefetched the dataset load is local and the score is reported as before.
- `test_npu_hicache_mamba`: no accuracy expectation change; the SSM path now runs bfloat16 explicitly instead of the config default.
