# [Fix] grpc: support native API and admin key authentication

[Upstream PR](https://github.com/sgl-project/sglang/pull/45215) · state: open · merged: False

## Original PR description

## Motivation

Native gRPC rejects SGLang's API and admin keys, preventing authenticated engines from using the native transport.

## Modifications

Forward both keys to leader and metadata-only follower listeners. Match HTTP permissions: generation and discovery use `api_key`; cancellation, pause/resume, cache flush, profiling and weight updates use `admin_api_key`, falling back to `api_key` when no admin key is configured. With only an admin key, ordinary requests remain open. Health checks remain public. The admin key does not substitute for a separately configured user key.

Check bearer metadata before dispatch using constant-time comparison; reject missing, malformed or incorrect required credentials with `UNAUTHENTICATED`. The standalone `SGLANG_RUST_SERVER` mode remains explicitly unsupported with either key.

The `main` counterpart of #45208, without unrelated `sglang-miles` commits.

## Validation

Local validation on 2026-10-20:

- 20 Rust tests passed (`cargo test -p sglang-grpc --no-default-features --locked`), including the native RPC permission matrix.
- 23 Python tests and 6 subtests passed for gRPC/sidecar server arguments and leader/follower credential forwarding.
- Clippy with warnings denied and `cargo fmt --all --check` passed.
- Additional wire smoke tests against the compiled PyO3 native leader/follower listeners passed for no key, user key, admin key, and both keys. The leader test uses a CPU mock runtime: generation and pause/resume work with authorized credentials, and rejected calls do not invoke runtime operations.

These checks do not constitute GPU rollout validation. Dynamo/Miles clients still require separate admin-credential forwarding before enabling distinct keys end to end.

Synced with upstream main in `d28e93eb33`; the CI ancestry checks now pass. GPU CI still requires the repository's normal maintainer approval (`run-ci`).
