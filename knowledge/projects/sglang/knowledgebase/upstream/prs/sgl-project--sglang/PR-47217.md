# [Fix] [NPU] docker: Bump SGLANG_KERNEL_NPU_TAG to 2026.9.0.post12

[Upstream PR](https://github.com/sgl-project/sglang/pull/47217) · state: closed · merged: True

## Original PR description

## Motivation

The Docker image, CI dependency installer, and release workflows still pin
`SGLANG_KERNEL_NPU_TAG` to `2026.9.0.post10`. Update them to
`2026.9.0.post12` so all NPU build paths use the same kernel package version.

## Modifications

- Update the default `SGLANG_KERNEL_NPU_TAG` in `docker/npu.Dockerfile`.
- Update the CI dependency installer default in
  `scripts/ci/npu/npu_ci_install_dependency.sh`.
- Pass `2026.9.0.post12` to the regular and nightly NPU Docker workflows.
