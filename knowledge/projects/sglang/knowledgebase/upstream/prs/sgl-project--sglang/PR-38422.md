# [NPU] Phase A calibration: full GSM8K eval for dp_attention mixed-chunk

[Upstream PR](https://github.com/sgl-project/sglang/pull/38422) · state: closed · merged: True

## Original PR description

## Motivation

The GSM8K accuracy check in `TestDPAttentionMixedChunk` (`test_npu_dp_attention.py`) evaluates a random 200-example subset. The subset introduces sampling variance (sigma ~= 0.013 per run) and has caused flaky CI failures: a subset scored 0.305 against the 0.34 threshold, while the full test set measures mu = 0.3592.

In addition, PR NPU tests failed because `sgl-eval` was missing in the NPU image (it is declared in the `test` extra, which the image does not install).

## Modifications

- `test/registered/npu/basic_function/dp_attn/test_npu_dp_attention.py`: evaluate the full GSM8K test set (1319 examples) instead of the random 200-example subset (`gsm8k_num_examples = 1319`), which removes the sampling variance that caused flaky failures. Keep the threshold at the upstream value 0.34. Raise `est_time` for the nightly suite to 2400s to match the measured runtime (1995s).
- `.github/workflows/_npu-pr-test-stage.yml`: install `sgl-eval==0.1.0` when it is missing from the environment.

## Accuracy Tests

Calibration run on a3-4 (full 1319-example GSM8K, DeepSeek-V2-Lite-W8A8, DP2TP2 + mixed chunk): `gsm8k_score = 0.3592`, threshold 0.34 keeps ~1.5 sigma headroom with up to 3 retries in the accuracy kit.

## Speed Tests and Profiling

No impact on inference speed; CI-only changes.
