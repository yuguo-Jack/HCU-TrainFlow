## Motivation

`test_shared_expert_routing_extra.py::TestSelectExpertsPerRankSharedSlots.test_routes_like_no_fusion` fails before routing because its EP=8 override leaves TP=1, violating `tp_size == moe_ep_size * moe_dp_size * moe_tp_size`.

Observed in [PR Test Extra on #44977](https://github.com/sgl-project/sglang/actions/runs/39394810488/job/118535400304). The failing test comes from main, introduced by #44913.

## Modifications

Apply a minimal version of the test-topology fix in #44994 so it can land independently of the broader MoE refactor. Model rank 3 of TP=EP=8 by setting TP, attention-TP, and EP sizes/ranks together. This test initializes no communication groups; the existing default DP/CP/MoE-TP widths remain 1.

Only `test/registered/moe/test_shared_expert_routing_extra.py` changes.
