# [Fix] disaggregation: Select the staging device in DCP packing threads

[Upstream PR](https://github.com/sgl-project/sglang/pull/44724) · state: open · merged: False

## Original PR description

## Motivation

A DCP transfer thread starts on CUDA device 0. When it packs rows for a P/D transfer, `torch.cuda.stream(...)` first records the current stream of device 0, which creates an unused CUDA context there. Every rank whose staging buffer lives on another GPU does this, so on an 8-GPU prefill sending to a decode with a larger DCP size, GPU 0 holds seven extra contexts and less usable memory than the other ranks. Packed bytes are not affected.

Found while running P/D with DCP relayout for Kimi-K3 serving.

## Modifications

- `try_pack_dcp_src` selects the staging buffer's device before the gather stream is used. The empty and over-capacity fallbacks still return first.
- Add `test_pd_dcp_pack_device.py`, a GPU test that packs from a fresh thread in a fresh process on device 0 and on device 1, checking the packed bytes and guard bytes against a CPU reference and which GPUs hold a context. The existing CPU test `test_dcp_pack.py` now mocks the device selection.

Verified [2ae31e9a73](https://github.com/Venkat2811/sglang/commit/2ae31e9a73186a3421c7fcbf0d16b1f9e2608e43) against parent [44be30d216](https://github.com/sgl-project/sglang/commit/44be30d2165318011fa1e9002cf58d6061907ed4) on one node with eight B300 GPUs:

| Check | Before | After |
| --- | --- | --- |
| GPU test, `test_pd_dcp_pack_device.py` | Device 0 passes; device 1 fails: contexts on GPUs 0 and 1 | Both pass: context on the owning GPU only |
| CPU test, `test_dcp_pack.py` (11 tests) | 1 error (no device selection) | 11 pass |
| Seven fresh workers on GPUs 1 to 7 | 7 contexts on GPU 0, 4,312 MiB | None on GPU 0 |
| Packed bytes (all workers) | Identical | Identical |
| Pack call from a transfer thread, 54 MiB, three fresh runs | Median 196.2 to 201.8 µs | Median 191.3 to 195.1 µs |

## Accuracy Tests

The gather kernel is unchanged. In both arms the packed bytes and guard bytes match a CPU reference, and every worker produces the same SHA-256. No model output can change.

## Speed Tests and Profiling

The pack call is not slower: medians of 191.3 to 195.1 µs after against 196.2 to 201.8 µs before, 200 calls per run after 20 warm-up calls, 24 layers × 576 bytes × 4,096 tokens per call. The fix runs once per pack call and adds no synchronization.

Environment: driver 580.178.04, PyTorch 2.13.0+cu130. The CPU and GPU tests ran through SGLang's CI runner and unittest; pre-commit passes on all three changed files. Hosted CI has not run yet.

`measure_contexts.py`

```python
"""Start one fresh process per GPU 1..N that packs from a transfer thread; report the GPUs each process holds."""
import json, pathlib, subprocess, sys, tempfile, time

test, n = sys.argv[1], int(sys.argv[2]) if len(sys.argv) > 2 else 7
tmp = pathlib.Path(tempfile.mkdtemp())
procs = []
for d in range(1, n + 1):
    code = (
        f"import json, pathlib, runpy, time; "
        f"r = runpy.run_path({test!r})['_pack_in_fresh_thread']({d}); "
        f"pathlib.Path({str(tmp / f'{d}.json')!r}).write_text(json.dumps(r)); "
        f"[time.sleep(0.1) for _ in iter(pathlib.Path({str(tmp / 'release')!r}).exists, True)]"
    )
    procs.append(subprocess.Popen([sys.executable, "-c", code]))
while not all((tmp / f"{d}.json").exists() for d in range(1, n + 1)):
    assert all(p.poll() is None for p in procs), "a worker exited early"
    time.sleep(0.2)
smi = lambda *a: subprocess.check_output(["nvidia-smi", *a], text=True)
gpu0 = smi("-i", "0", "--query-gpu=uuid", "--format=csv,noheader").strip()
pids = {p.pid for p in procs}
rows = [r.split(", ") for r in smi("--query-compute-apps=pid,gpu_uuid,used_memory", "--format=csv,noheader,nounits").splitlines()]
mine = [r for r in rows if int(r[0]) in pids]
on0 = [r for r in mine if r[1] == gpu0]
hashes = {json.loads((tmp / f"{d}.json").read_text())["buffer_sha256"] for d in range(1, n + 1)}
print(json.dumps({"workers": n, "worker_contexts": len(mine), "gpu0_contexts": len(on0),
                  "gpu0_MiB": sum(int(r[2]) for r in on0), "identical_packed_bytes": len(hashes) == 1}))
(tmp / "release").touch()
for p in procs:
    p.wait()
```

`bench_pack.py`

```python
"""Median time of one DCP pack call from a transfer thread on GPU 1 (24 MLA layers x 576 B x 4,096 tokens)."""
import statistics, threading, time
import numpy as np, torch
from sglang.srt.disaggregation.common.dcp_pack import try_pack_dcp_src
from sglang.srt.disaggregation.common.staging_buffer import StagingBuffer

dev, layers, width, pool, tokens = 1, 24, 576, 8192, 4096
torch.cuda.set_device(dev)
sources = [torch.randint(0, 256, (pool, width), dtype=torch.uint8, device=f"cuda:{dev}") for _ in range(layers)]
buffer = StagingBuffer(layers * width * tokens, f"cuda:{dev}", dev)
indices = np.random.default_rng(0).choice(pool, tokens, replace=False).astype(np.int64)
kwargs = dict(pack_buffer=buffer, kv_data_ptrs=[s.data_ptr() for s in sources], token_item_lens=[width] * layers,
              src_token_item_lens=[width] * layers, pack_offset_bytes=0, src_token_indices=indices)
times = []

def worker():
    for i in range(220):
        t = time.perf_counter()
        assert try_pack_dcp_src(**kwargs) is not None
        if i >= 20:
            times.append((time.perf_counter() - t) * 1e6)

thread = threading.Thread(target=worker)
thread.start()
thread.join()
print(f"pack median {statistics.median(times):.1f} us, p90 {sorted(times)[int(0.9 * len(times))]:.1f} us over {len(times)} calls, {layers * width * tokens / 2**20:.1f} MiB per call")
```
