# [Feat] simulator: Add optional InferCast latency and KV budgets

[Upstream PR](https://github.com/sgl-project/sglang/pull/36069) · state: open · merged: False

## Original PR description

## Motivation

Let SGLang Simulator obtain optional model-forward costs and independent KV budgets from InferCast while native SGLang retains scheduling, chunk admission and prefix-cache behavior. Source-bound DSPark results can then participate in the existing external closed-loop AgentX coordination protocol.

## Modifications

- Carry immutable prepared-forward work with each result, preserving ordered EXTEND/MIXED work, DECODE histories, sampling, topology, units and explicit unsupported errors. InferCast UMD and the existing resource-budget interfaces remain the model/capacity owners; optional imports stay lazy.
- Bind native DSPark progress and regional costs to exact source/runtime profiles. Validate costs before publishing progress, preserve native output and cancellation accounting, and charge discarded launched tails without exposing their tokens. Acceptance ratios do not become latency multipliers.
- Use the existing UMD operation path for explicit HYBRID costs. Measured exact/supported interpolation takes priority; only a typed numeric miss can use an explicitly selected profile-bound analytic asset. Source bindings are verified independently of numerical coverage, and query ledgers retain measured/theoretical contributions.
- Add explicit TP2/attention-DP2 library transactions: join both actual ordered partitions, keep allocation/CPU vectors/FIFO retirement local, evaluate one joint whole-worker cost/progress result, build both native results before publication, and replicate history only after both publication callbacks succeed. Partial publication failures remain sticky. These entry points leave public ADP2 activation guards closed.
- Project prospective joint work from both prepared reference views and actual independent planner/buffer facts through the existing SDK query contracts. Validate the full materialized capture ladder and role variants before selecting a bucket; completed-frame witnesses are a separate observation path.
- Preserve native overlap, countdown and drained profile semantics in coordinated OFFLINE execution. Consume native result accounting before any post-result terminal/timer Grant, while retaining earlier in-flight timer Grants. Prepare the native controller's spawned callable through the existing early CPU bootstrap.
- Keep native-size packed KV payload storage on meta only in the opt-in CPU bootstrap, preserving logical capacity and real allocator/request ownership. Document source contracts and unsupported configurations.
- Add an internal native attention-DP common-clock bridge. One DPC owns external ingress, paired native budget/dispatch, both result/accounting acknowledgements and a single profile writer; scheduler peers consume the same read-only clock. Preserve waiting/chunked cancellation obligations through both native abort callbacks and paired release acknowledgements.
- Wire typed native selection and worker-forward entry routes through the existing predictor owner, retaining local buffers, capture ladders, counters, first-empty behavior and reset ownership. An explicit joint source binding now validates original startup/capture/proposal/allocated-runtime assets through the existing SDK and constructor. Its narrow TP2/attention-DP2 CPU entry reuses the native DPC, typed worker route and paired clock; all other entry defaults remain unchanged.
