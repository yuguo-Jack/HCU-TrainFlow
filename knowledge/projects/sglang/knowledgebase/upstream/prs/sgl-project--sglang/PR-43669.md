# [DSpark] Merge the draft TP sync sites into `dspark-draft`

[Upstream PR](https://github.com/sgl-project/sglang/pull/43669) · state: closed · merged: True

## Original PR description

Stacks on #43668.

- With one draft path, the five per-path draft sync sites (`dspark-draft-greedy`, `dspark-draft-sample`, `dspark-draft-multinomial`, `dspark-graph-sample`, `dspark-graph-greedy`, numbers 2-6) become one site, `DSPARK_DRAFT` (`dspark-draft`, number 17). It takes a fresh number so an old number cannot silently mean it.
- The retired names and numbers 2-6 still resolve, to `dspark-draft`, with a warning.
- `dspark-draft` is not in the `rng` preset: the draft noise is a deterministic function of its inputs, so ranks with identical logits draft identical tokens.
- Tests: the parser maps retired handles, negates them (`all,-6`), and keeps the draft site out of `rng`.

Behavior change: a retired handle now selects every draft step, and `SGLANG_SPEC_TP_SYNC=rng` no longer syncs draft tokens.

## Verification

- `test/registered/unit/spec/test_spec_tp_sync.py` passes.
- DeepSeek-V4.1-Flash, TP4 on GB300, `SGLANG_SPEC_TP_SYNC=init`: the server starts and serves without a hang, with the default draft and the greedy draft. TPOT at temperature 1, concurrency 16 stays within run-to-run noise of the default sync.
