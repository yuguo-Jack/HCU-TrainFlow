[Upstream PR](https://github.com/sgl-project/sglang/pull/43841) · state: open · merged: False

## Original PR description

## What
Fix a broken cross-page link in the Jina reranker cookbook page:
`../DeepSeek/DeepSeek-V3_2.md` → `../DeepSeek/DeepSeek-V3_2`.

## Why
The target page is `DeepSeek-V3_2.mdx`, and Mintlify resolves internal links without the file extension. Every other reference to this page (the GLM-5 / 5.1 / 5.2 / 5.3 cookbook pages and `docs.json`) already uses the extensionless form, so this `.md` link was the lone outlier and 404s on the docs site.

## How verified
- Confirmed the only valid target is `cookbook/autoregressive/DeepSeek/DeepSeek-V3_2.mdx`, and every other in-repo reference uses the extensionless path.
- `mint broken-links` is the same check SGLang CI runs; this PR's CI exercises it.
