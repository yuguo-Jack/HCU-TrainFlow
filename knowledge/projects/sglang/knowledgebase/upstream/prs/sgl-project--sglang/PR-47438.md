## Motivation

Historically, DSV4 used some operators that were not officially released in CANN 9.1 (under op-transformer/experimental), and CANN no longer maintains these operators. Operators officially released in CANN 9.2 can be used directly, without separately pulling the op-transformer/recipe repository for compilation and installation. Use the officially released operators in CANN 9.2 to absorb the experimental-state operators and some recipe operators currently used by DSV4.

## Modifications

### Current DSV4 Operator Sources

1. op-transformer official release (target state)
2. op-transfomer/experiment
3. cann-recipe-infer
4. sgl-kernel-npu (in-house repository)
