# K3 PD disaggregation

[Upstream PR](https://github.com/sgl-project/sglang/pull/37175) · state: closed · merged: False

## Original PR description

## Motivation

Fix Kimi-K3 PD disaggregation on Ascend with PP Prefill and DSPARK Decode. This requires correct layer mapping during KV transfer, matching persistent state layouts, and preserving the shared-expert communication path used by the Prefill configuration.

- **PP-local Hybrid MLA KV buffers:** a Prefill PP stage registers only its own layers, while a PP=1 Decode peer registers all layers. Positional pairing can copy a Prefill buffer into the wrong Decode layer.
- **DSPARK state layout:** Prefill does not run target verification, but its persistent KDA/Mamba convolution window and temporal-state layout must match DSPARK Decode.
- **Explicit DP-attention with DP=1:** K3's DeepEP shared-expert attention-TP communication path requires DP-attention to remain enabled. Previously, argument normalization silently disabled it at DP=1, changing the shared-expert communication path even when explicitly requested. Preserving the flag also requires removing the DP>1 assertion in `require_mlp_tp_gather()`: with one attention DP group, that gather is unnecessary. At DP=1, enabling this flag does not itself change the effective attention TP size.

## Modifications

- Route Ascend Hybrid MLA KV transfers with Prefill PP>1 through global-layer-ID pairing; retain the existing path for other Ascend layouts.
- Repeat NPU MLA layer IDs for the latent-KV and RoPE-key buffer groups.
- Infer Prefill's persistent NPU state-layout width from the shared `--speculative-dspark-block-size` and align both the convolution window and temporal-state transpose. Prefill still skips speculative verification and its per-draft-token state snapshots.
- Reuse the Mamba TP-slicing decision, pass destination slot sizes to direct state transfer, and reject incompatible slot sizes before copying.
- Honor explicitly enabled DP-attention at DP=1, return false for the unnecessary MLP TP gather in that case, and tolerate configuration views without `enable_dp_attention`.
- Add unit coverage for Hybrid MLA layer-ID metadata across NPU and non-NPU buffer layouts.

For DSPARK Decode, set the same `--speculative-dspark-block-size` on Prefill and Decode without enabling speculative execution on Prefill. The PP layer-mapping change addresses PD transfer; it does not claim to fix same-instance PP/chunked-prefill generation quality.
