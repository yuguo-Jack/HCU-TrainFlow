# [Fix] chat_parsing: Preserve integer tool argument precision

[Upstream PR](https://github.com/sgl-project/sglang/pull/45734) · state: open · merged: False

## Original PR description

## Motivation

Follow-up to #43941. With integer-schema string arguments, both public `parse_response` and streamed `ResponseParser` round `9007199254740993.0` to `9007199254740992` and incorrectly accept `3.0000000000000001` as integer `3`.

## Modifications

Check integrality and convert using the exact decimal text. Retain the existing float range guard and leave the `number` branch unchanged.

Add CPU regression coverage through both public parser entry points, including precision, underflow, range limits, and union fallback.

AI tools assisted the investigation, implementation, tests, and this description.
