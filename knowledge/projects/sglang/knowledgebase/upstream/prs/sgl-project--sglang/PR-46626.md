## Motivation

Profile V2 (`SGLANG_PROFILE_V2=1`) is missing the `PREBUILT` case that the V1 by-stage predicate got in #40098. `_get_stage_from_forward_mode` (`python/sglang/srt/utils/profile_utils.py:175`) maps prefill, decode and `IDLE`, and raises for any other mode:

```
RuntimeError: unsupported profile stage: forward_mode=<ForwardMode.PREBUILT: 7>
```

`Scheduler.run_batch` calls `SchedulerProfilerManager._profile_batch_predicate` on every batch, before its `PREBUILT` early return (`_run_batch_prebuilt`). Under V2 the predicate calls `ProfileManager.step`, which maps the mode before it looks at any profiling state. So a `PREBUILT` batch reaching `run_batch` would kill the scheduler, even with no profile requested. `PREBUILT` is the PD-decode placeholder for requests whose KV just arrived; it never enters a model forward. V1 ignores it.

Reachability: I did not find an in-tree event loop on current main that passes a `PREBUILT` batch to `run_batch`. Since #19568, `get_next_disagg_decode_batch_to_run` makes a new `PREBUILT` batch the running batch, or merges it into it, and `update_running_batch` switches it to `DECODE` before `run_batch` (checked on CPU by calling that function). This was already the case when #40098 fixed V1. `run_batch`, the DP-attention sync and FPM still handle `PREBUILT` explicitly, and so does V1. This change makes V2 handle it the same way.

This carries forward #40383 (@bojiang-li), which was closed by the stale bot without a review.

## Modifications

- `python/sglang/srt/utils/profile_utils.py`: `_get_stage_from_forward_mode` returns `None` (no stage) for `PREBUILT`, as it does for `IDLE`. The V2 mapping now classifies every forward mode the same way as the V1 by-stage predicate.
- `test/registered/unit/utils/test_profile_utils.py` (new, `base-a-test-cpu`): starts a decode-stage capture on a real `ProfileManager`, steps it with `ForwardMode.PREBUILT`, and checks that the capture was neither ended nor advanced. `activities=[]`, so no profiler backend runs. On main the test fails with the `RuntimeError` above. It also fails if `PREBUILT` is mapped to a profile stage instead of `None` (checked locally by mapping it to `"prefill"`). No existing test covers `ProfileManager`, so the new file mirrors the source path.
