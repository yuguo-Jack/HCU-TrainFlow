## Motivation

After aiter's head-padded asm MLA decode/verify kernel, Kimi-K3 TP8 runs the split combine (#44983's
`mla_split_reduce`), the absorbed W_vc bmm and the output gate per MLA layer and step. On gfx950 each is a separate
launch.

## Modifications

All new paths are gated on `is_gfx95_supported()`.

- On #44983's split path the aiter backend can hand the split partials to the model (`mla_epilogue_handoff`) instead
  of combining them itself.
- Kimi-K3's absorbed-V epilogue runs the W_vc bmm and the output gate as one kernel (`mla_v_up_gate`) or, with the
  deferred partials, the split combine, W_vc and the gate as one (`mla_decode_epilogue`, 1-64 rows,
  `SGLANG_ROCM_K3_FUSED_MLA_EPILOGUE`).

`DeepseekV2AttentionMLA` gains `fused_absorb_v_epilogue()` (returns None), so other DeepSeek-family models keep their
decode path.

| New env var | Default |
|---|---|
| `SGLANG_ROCM_K3_FUSED_MLA_EPILOGUE` | on |

## Accuracy Tests

**Setup for every number below:** 8x MI350X (gfx950, 1000 W), Kimi-K3 (MXFP4 MoE, bf16 attention) at TP8 with EAGLE3
(topk 1, 3 steps, 4 draft tokens), FP8 KV cache, `SGLANG_USE_AITER=1`, aiter's K3 FlyDSL kernels
(`AITER_SITUV2_A8W4=1 AITER_FLYDSL_FORCE=1 SGLANG_AITER_K3_OPT=1`), CUDA graphs for bs 1/2/4/8/16, and an aiter bf16 GEMM table with K3 rows re-tuned on this pod with HBM-resident weights
(`AITER_CONFIG_GEMM_BF16`; not part of this PR, it belongs in aiter's model configs). EAGLE3 on K3 needs the
aux-capture commit of #43599, applied locally for these runs. Microbenchmarks rotate their weights through HBM.
Per-feature numbers were measured on the integration branch of this series as each piece landed (Oct 13-14,
earlier `main`). All branches of the series are on `main` 4eb606b2ae (2026-10-17); the kernel tests below ran on this
branch, and the end-to-end checkpoints on that `main` plus the queue up to each slot.

- GSM8K 400 with the fused epilogue: 0.985 / accept 3.625. End to end: see below.
- `test_mla_decode_gfx950.py` (extended): W_vc + gate keeps the bmm's and the gate's bf16 rounding; the epilogue
  matches split combine + W_vc + gate. On MI350X, with #44983's cases: 4 passed (19 subtests).
