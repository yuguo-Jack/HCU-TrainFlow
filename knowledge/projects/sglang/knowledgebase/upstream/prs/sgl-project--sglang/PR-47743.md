# [Perf] mla: Use masked K concatenation for padded head counts

[Upstream PR](https://github.com/sgl-project/sglang/pull/47743) · state: closed · merged: True

## Original PR description

## Motivation

Kimi-K3 has 12 local MLA heads at TP8. `_concat_and_cast_mha_k` currently requires a power-of-two head count before calling the Triton helper, even though that helper already handles padded head counts. These shapes fall back to two separate tensor copies.

## Modifications

Remove the redundant head-count restriction at the shared model dispatch point. Reuse the existing masked concat kernel and keep the feature-dimension guards and the 128-head specialized path.

For FA3 with FP8 KV storage, these head counts now follow the same output-dtype rule as the existing power-of-two Triton path. Other covered backends retain the input dtype.
