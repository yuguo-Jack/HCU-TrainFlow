# [Fix] [NPU] tests: Restore evalscope GSM8K baseline via NPUGSM8KMixin backend

[Upstream PR](https://github.com/sgl-project/sglang/pull/45732) · state: closed · merged: True

## Original PR description

## Motivation

The NPU nightly pipeline switched the Moonlight GSM8K accuracy cases from evalscope to sgl_eval, which dropped measured scores from ~0.83 to ~0.73-0.82 because sgl_eval probes 0-shot with greedy decoding while the historical 0.83 baseline was calibrated with evalscope (4-shot chat, temperature 1.0). Forcing thresholds onto the sgl_eval scale loses the legacy calibration.

This PR adds a native `evalscope` backend to `NPUGSM8KMixin` so NPU accuracy cases can declare `gsm8k_backend = "evalscope"` and keep their historically calibrated thresholds.

## Modifications

* `NPUGSM8KMixin`: add `gsm8k_backend = "evalscope"` support via a new `_test_gsm8k_evalscope` method (delegates to the existing `run_evalscope` harness), expose the request concurrency as the overridable class attribute `gsm8k_eval_batch_size = 64`.
* Make the 1% accuracy tolerance idempotent: guard the threshold relaxation with a flag so outer retries (`run_suite --enable-retry`) cannot compound the 0.99 factor (0.83 -> 0.8217 -> 0.8134).
* Resolve the `run_evalscope.sh` install script relative to `__file__` instead of the stale `/root/sglang` hardcode (the CI image WORKDIR moved to `/sgl-workspace`).
* Require both the `pull_request` event and a non-nightly workflow ref for the PR smoke short-circuit, so PR-triggered nightly runs still execute the full accuracy cases.
* Point the two Moonlight cases (`TestDPAttentionMixedChunk`, `TestAscendMlaFiaHicacheBf16`) back to `gsm8k_accuracy_thres = 0.83` with `gsm8k_backend = "evalscope"`.

## Accuracy Tests

Validated on Ascend A3 (910B) in the nightly pipeline (run [39711641496](https://github.com/sgl-project/sglang/actions/runs/39711641496)):

| Case | Measured | Relaxed threshold (0.83 x 0.99) | Result |
|---|---|---|---|
| TestAscendMlaFiaHicacheBf16 (tp2, FIA+HiCache) | 0.8230 | 0.8217 | pass, first attempt |
| TestDPAttentionMixedChunk (tp2, dp2, mixed chunk) | 0.8260 | 0.8217 | pass, first attempt |

Both scores land within the historical evalscope fluctuation band of the 0.837 baseline; the previous sgl_eval runs measured only ~0.73-0.82.
