# [Perf] router: Parse MCP response stream events once

[Upstream PR](https://github.com/sgl-project/sglang/pull/39451) · state: open · merged: False

## Original PR description

## Motivation

The Responses API streaming path reparses each JSON event several times when MCP is active: once for response accumulation, once for tool interception, and once for event transformation/forwarding. This cost grows with long streamed responses.

## Modifications

- Parse each upstream SSE JSON payload once in the MCP streaming loop.
- Share the parsed value with the response accumulator and tool handler.
- Transfer the same value into the existing forwarding transformation.
- Preserve malformed-JSON raw forwarding, event ordering, response/tool ID masking, output-index allocation, and persistence behavior.

The public protocol and non-MCP path are unchanged.

## Accuracy Tests

- `cargo test --locked --test api_tests test_streaming_with_mcp_tool_calls --no-fail-fast`: 1 passed.
- Focused compiled-binary replay of `test_streaming_`: 4 passed, covering single-round and multi-turn MCP streaming, upstream errors, and timeouts.
- Full CPU gateway A/B: 90/90 measured runs returned HTTP 200, the configured delta-event count, no error event, a `[DONE]` marker, and identical output byte length between arms.

## Speed Tests and Profiling

Measured on an Intel Core i9-14900HX, release profile (`opt-level=z`, fat LTO, one codegen unit), pinned to one logical CPU. Each cell used 15 fresh-process control/candidate pairs with alternating order and one warmup request per process.

The full `/v1/responses` route used the real router plus local HTTP mock worker and MCP server:

| Stream | Median speedup | Paired-bootstrap 95% CI |
| --- | ---: | ---: |
| 8,192 deltas | 1.591x | [1.461x, 1.692x] |
| 512 deltas | 1.059x | [1.039x, 1.082x] |
| 32 deltas | 1.000x | [0.999x, 1.003x] |

Weighted geometric speedup: **1.284x**, 95% CI **[1.236x, 1.321x]**.

A separate production-inner-path probe measured a weighted 2.173x speedup, 95% CI [2.044x, 2.263x]. The full-route numbers above are the primary claim; they include HTTP and MCP fixed costs but exclude model execution, remote network, GPU, and production concurrency.
