# [Fix] [AMD] diffusion: Install websockets with the ROCm diffusion extras

[Upstream PR](https://github.com/sgl-project/sglang/pull/44529) · state: open · merged: False

## Original PR description

## Motivation

The CUDA `diffusion` extra in `python/pyproject.toml` lists `websockets`. `diffusion_common` in `python/pyproject_other.toml` does not. That block is the base for `diffusion_hip` (installed by the ROCm Docker image and, through `all_hip`, by the AMD CI), and for `diffusion_musa` and `diffusion_mps`.

Without `websockets` or `wsproto`, uvicorn cannot accept a WebSocket upgrade, so the realtime video API is unreachable on ROCm installs:

- **The shipped image.** `lmsysorg/sglang-rocm:v0.5.21-rocm10-mi35x-20261014` (SGLang `bab9c81`) has neither package. On it, a `robbyant/lingbot-world-fast-diffusers` server with `--pipeline-class-name LingBotWorldCausalDMDPipeline` reports healthy on 1× MI355X, but an upgrade request to `/v1/realtime_video/generate` gets `404 Not Found`, and uvicorn logs `No supported WebSocket library detected. Please use "pip install 'uvicorn[standard]'", or install 'websockets' or 'wsproto' manually.`
- **The AMD CI.** It hits the same gap from the client side. `lingbot_world_realtime_plastic_beach` is skipped on every `multimodal-gen-test-1-gpu-amd` run (for example scheduled run 38661136204, partition 3) at the `websockets` import guard in `test/server/realtime_consistency.py`, so the realtime path never runs on AMD.

## Modifications

Add `websockets` to `diffusion_common`, unpinned as in the CUDA extra.

## Accuracy Tests

Same image and server on 1× MI355X (gfx950), with `websockets` 17.2 installed:

- The upgrade request returns `101 Switching Protocols`.
- `pytest sglang/multimodal_gen/test/server/test_server_1_gpu.py -k lingbot_world_realtime_plastic_beach` gives 1 passed in 95.7 s.

## Speed Tests and Profiling

No kernel or model change. Chunk timings from that run (832×480, warmup off):

- The first chunk takes 27.4 s, which includes the first-call compile.
- The next three take 1.75–1.89 s per 12-frame chunk.

cc @HaiShaw @michaelzhang-ai, since this also lets the AMD lane run the realtime LingBot-World case instead of skipping it.
