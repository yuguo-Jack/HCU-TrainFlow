# Fix Trinity parser stripping think tags from tool arguments

[Upstream PR](https://github.com/sgl-project/sglang/pull/42236) · state: closed · merged: False

## Original PR description

## Motivation

Fixes #42140. Trinity currently strips `<think>` and `</think>` from the raw response before parsing tool calls. For example, a `write_file` argument containing `Qwen emits <think> and </think> tags` becomes `Qwen emits  and  tags`.

## Modifications

Parse the original text and strip think markers only from the returned `normal_text`, preserving tool argument strings in both streaming and non-streaming parsing. Keep the existing whitespace behavior for the non-streaming text prefix.

Add regressions to the existing CPU-registered function-call parser suite. Streaming coverage uses a complete JSON payload, seven-character chunks, and single-character chunks, followed by the tool's closing marker.

Related #30990 addresses think markers split across streaming deltas; its patch still removes tags from raw JSON arguments. This change addresses argument preservation reported in #42140.
