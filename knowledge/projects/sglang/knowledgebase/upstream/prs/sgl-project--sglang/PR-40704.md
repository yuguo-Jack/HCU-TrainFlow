# [Feat] hicache: Add radixshmem storage backend

[Upstream PR](https://github.com/sgl-project/sglang/pull/40704) · state: open · merged: False

## Original PR description

## Motivation

[Radixshmem](https://github.com/ai-dynamo/radixshmem) keeps KV pages in a node-local shared-memory slot pool and indexes them in a radix tree that is shared across the nodes of a cluster. A page written by one instance can be found by prefix match from any instance, and a page held on another node is pulled over RDMA (NIXL or radixshmem's own transport).

This PR adds it as a HiCache L3 storage backend, so that instances on one or more nodes share one prefix cache through the existing `--hicache-storage-backend` path. It supports the hybrid layouts HiCache already handles: MHA and MLA KV, DeepSeek-V4/V4.1 (compressed KV, indexer and SWA sidecars), and SWA and Mamba side state.

## Modifications

1. **radixshmem backend** (`mem_cache/storage/radixshmem/`, built-in name `radixshmem`).
   - Each page is stored in up to three slots, KV, SWA and Mamba; every pool goes into the slot of its `indices_from_pool`.
   - One slot is shared by the attention TP/CP group, with a TP-independent layout.
   - Reads and writes are collective over the group, so `backup_skip` is `False` for a `shard_collective` backend.
   - Requires `hicache_storage_pass_prefix_keys`.
2. **Read barrier:** a `shard_collective` backend all-reduces each batch's read result, so all ranks take the same branch.
3. **Startup hooks:** `build_kv_cache` calls the backend's `connect()`, and `register_sidecar_pool` passes each `SidecarPoolSpec` to `describe_sidecar()`. Both apply only to backends that define these methods.
4. **`prefix_keys` fix:** prefetches now include the anchor node's own pages, so `prefix_keys + keys` is one contiguous chain.
5. **FULL-head trim fix:** pages dropped from the head of a buffer-mode prefetch are appended to `prefix_keys`.

## Usage

Start one radix-server per node (see the [radixshmem README](https://github.com/ai-dynamo/radixshmem#readme) for build and server options), then:

```bash
python -m sglang.launch_server ... \
  --enable-hierarchical-cache --hicache-host-memory-mode buffer_only \
  --hicache-storage-backend radixshmem \
  --hicache-storage-prefetch-policy wait_complete \
  --hicache-storage-backend-extra-config '{"radixshmem_name": "/radixshmem", "hicache_storage_pass_prefix_keys": true}'
```
