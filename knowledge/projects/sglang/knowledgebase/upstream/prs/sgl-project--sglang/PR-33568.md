# [Fix] deepseek: Stop adding omitted tool-schema fields to prompts

[Upstream PR](https://github.com/sgl-project/sglang/pull/33568) · state: open · merged: False

## Original PR description

## Motivation

The DSV4/DSV32 tool serializer adds `strict: false` when the request omits `strict`. The checkpoint reference encoder preserves that omission, so the injected tool payload differs from the request.

## Modifications

Serialize injected DSV4/DSV32 tools with `exclude_unset=True` and `by_alias=True`, matching the Kimi K3 injection sites. Preserve the separate DeepSeek-V4.1 serializer. Add a regression comparing the injected tool dictionary with the request.

## Accuracy Tests

147 CPU tests and 90 subtests passed in the OpenAI serving-chat suite, including the DSV4 tool-payload regression. Live DeepSeek prompt comparisons have not been rerun.

## Speed Tests and Profiling
