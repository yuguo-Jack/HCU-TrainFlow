# [NPU] Use npu.compressor for DeepSeek-V4 arch35

[Upstream PR](https://github.com/sgl-project/sglang/pull/39507) · state: open · merged: False

## Original PR description

`torch.ops.npu.compressor` now supports Atlas A5, so remove the `is_npu_arch35()` dispatch to `torch.ops.custom.compressor` and the stale TODO.


<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

`torch.ops.npu.compressor` (from `sgl-kernel-npu`) now supports Atlas A5 (`arch35`)
via its dual-arch build, so the A5-only workaround that dispatched to the internal
`torch.ops.custom.compressor` is no longer needed.

This lets sglang use a single compressor op on all Ascend generations, drops the
dependency on the internal `custom` package for the DSV4 compressor path, and
removes a stale TODO that no longer reflects reality.

Depends on the `sgl-kernel-npu` change that adds the A5 (`arch35`) compressor
implementation.

## Modifications

<!-- Detail the changes made in this pull request. -->


- `sglang/srt/hardware_backend/npu/attention/ascend_dsv4_backend.py`
  - Remove the `# TODO: torch.ops.npu.compressor does not support Atlas A5 yet.`
    comment and the `torch.ops.custom.compressor if is_npu_arch35() else ...`
    ternary; call `torch.ops.npu.compressor` directly on all architectures.
- `sglang/srt/hardware_backend/npu/dsv4/dsv4_memory_pool.py`
  - Update the `get_state_cache` docstring to reference `torch.ops.npu.compressor`
    only (drop the "`torch.ops.custom.compressor` on A5" wording).
- `test/registered/unit/npu/attention/test_npu_ascend_dsv4_backend.py`
  - Update the compressor-dispatch unit test: on `arch35`, assert
    `torch.ops.npu.compressor` is called (previously asserted
    `torch.ops.custom.compressor`), and that `custom.compressor` is not used.
