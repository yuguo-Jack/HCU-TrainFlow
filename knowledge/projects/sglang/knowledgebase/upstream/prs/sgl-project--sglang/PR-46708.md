# [CI] models: Move less-used model tests to extra and nightly suites

[Upstream PR](https://github.com/sgl-project/sglang/pull/46708) · state: closed · merged: True

## Original PR description

## Motivation

Reduce the model-loading and execution cost of base PR CI while retaining coverage for less-used models in extra or nightly suites.

## Modifications

- Move DeepSeek V3/V4 (excluding V4.1), GPT-OSS, GLM, MiMo-V2-Flash, and MiniMax-M2.5 CUDA integration tests to extra. Move 24 whole files and split four model-specific test classes from three mixed files so the remaining cases stay in base CI.
- Move three AMD tests to the existing 8-GPU nightly suite and increase its step timeout. Remove three NPU base registrations while retaining their existing nightly registrations.
- Retain the empty `base-c-test-acc-16-npu-a3` suite, including its job, precision-selection outputs, and dependencies.
- Remove the AMD base stage that directly invoked the DeepSeek V4 Flash nightly suite; retain its existing nightly accuracy and performance coverage.
- Move H100 DeepSeek V3 server/DeepGEMM warmup and H200 DeepSeek/MiMo warmup into the corresponding extra matrix rows. Remove the stale GLM-5-FP8 warmup, which has no CUDA test consumer.
- Add H20 extra dispatch and move two Intel CPU GPT-OSS tests to a new extra suite. Reuse Xeon SPR socket partitioning, with separate base/extra concurrency groups and the existing extra-label gate.
- Replace `nvidia/Qwen3.5-397B-A17B-NVFP4` with `nvidia/Qwen3.5-122B-A10B-NVFP4`, preserving TP4, ModelOpt NVFP4, MTP, and ReplaySSM coverage.

- Preserve the migrated H200 tests' 1800-second per-file timeout in extra and clarify the EP baseline's extra-CI comment.
- Preserve H20 failure isolation for both base and extra stage names using exact comparisons, without exempting H200 jobs.

## Accuracy Tests

- All changed files pass pre-commit checks, including CI registration validation.
- All 34 model-inventory extractor tests and 15 health-check action tests pass.
- Verified the H200 extra timeout matches base at 1800 seconds and that base retains enabled TP, PP, DP, DP-attention, and EP integration coverage, including Llama TP2/PP2, Qwen DP-attention, V4.1 TP2/EP2 and DP2/EP2, and Kimi K3 TP8/EP8/DCP8.
- Verified the four relocated classes are byte-identical and all 74 affected test/helper definitions have unchanged ASTs.
- Verified the H20 extra suite is discovered by the partition dispatcher, all changed registrations select known suites, and the Xeon base matrix is unchanged.
- Verified base CI has no remaining explicit model warmups, extra forwards the warmup settings and timeouts, AMD job dependencies resolve after removing the V4 base stage, and V4 nightly dispatch is unchanged.
- Verified the replacement Qwen checkpoint's official configuration and weight index contain NVFP4 MoE and MTP weights.
- **GPU end-to-end validation is pending. The existing GSM8K threshold (>= 0.95) and MTP acceptance-length threshold (> 3.3) are retained but have not been calibrated on the 122B model.**

## Speed Tests and Profiling

No runtime performance measurements. This changes CI scheduling and the Qwen test checkpoint; inference implementation is unchanged.
