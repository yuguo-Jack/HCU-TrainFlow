# [Refactor] memory-pool: Move the NVFP4 host budget into its host module

[Upstream PR](https://github.com/sgl-project/sglang/pull/48138) · state: open · merged: False

## Original PR description

## Motivation

Followup of #48137. The MiniMax NVFP4 host budget split `--hicache-size` across main KV, index rows and draft sidecars inside host assembly. It is a property of the NVFP4 host layout, so this PR moves it next to `MiniMaxM3Nvfp4MainKVPoolHost` unchanged and passes the HiCache memory settings explicitly.

## Accuracy

MiniMax NVFP4 with DSpark KL and the host probe are identical to #48137.
