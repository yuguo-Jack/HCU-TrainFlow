# docs: add Wan-Animate-2 cookbook command picker

[Upstream PR](https://github.com/sgl-project/sglang/pull/43380) · state: closed · merged: True

## Original PR description

Add the NEW badge and shared command picker to Wan-Animate-2, with measured recipes for RTX 4090, H200, and B300.

Recommend memory mode plus an expandable allocator on 24 GB RTX 4090, auto/memory on H200, and the two-B300 CFG parity preset. Scope Verified badges to the seven HTTP-tested recipes; document short-video and host-RAM limits, output consistency, and comparable latency/memory measurements. Preserve the older GB200 benchmark separately.

Validation: 44 offline generations across 11 configurations, 14 HTTP generations across seven recipes, repeated-output/hash checks, 233 picker combinations, pre-commit, Mintlify validation and broken-link checks, and desktop/mobile preview checks.
