## Original PR description

# [Feat] bailing: add TP-only FP8 and native Ling3 serving support

## Summary

- Keep shared experts standalone when routed and shared SwiGLU clamp limits differ, and resolve NextN limits at the checkpoint layer index. Keep each layer's MoE and TopK shared-slot layout consistent.
- Requantize serialized block-FP8 routed, shared, and NextN weights onto rank-local TP grids, with unsupported topologies rejected at load.
- Route standalone shared-expert partial-K shards through Triton block-FP8 when DeepGEMM cannot serve the layout.
- Add native Ling3 structural-tag constraints and streaming parsing, including implicit end-of-thinking activation and fail-closed constraint errors.
- Default BailingMoeV3 architectures to the Ling3 tool/reasoning parsers and keep reasoning-only output in `reasoning_content`.

Split out from the Ling-3.1-flash day-0 support effort.

## Validation

- `pre-commit run --files $(git diff --name-only upstream/main...HEAD)` — passed.
- Targeted CPU suite — 661 passed and 1145 subtests passed; 10 deselected tests reproduce on the same upstream/main baseline.
- GB300, full 1319 GSM8K, 32 threads, temperature 1.0 / top_p 0.95:
  - TP4-only: **97.27% accuracy / 99.62% stop**
  - EP4: **97.19% accuracy / 99.55% stop**
  - No `length` finishes; only client-side 300 s timeouts.
- TP-only startup, requant, shared-expert, native parser and generation smoke tests passed.
