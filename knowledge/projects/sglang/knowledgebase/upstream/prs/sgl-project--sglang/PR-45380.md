# [AMD] Build ROCm AOT kernels with -std=c++20

[Upstream PR](https://github.com/sgl-project/sglang/pull/45380) · state: closed · merged: True

## Original PR description

torch 2.14 headers require C++20 (c10 uses std::strong_ordering, string_view::starts_with and requires-clauses), so hipcc with -std=c++17 fails on every .hip unit in setup_rocm.py.
