# [Perf] [NPU] Bound DeepSeek-V4 RoPE tables by serving context

[Upstream PR](https://github.com/sgl-project/sglang/pull/47721) · state: open · merged: False

## Original PR description

## Motivation

DeepSeek-V4 builds its NPU RoPE tables using `max_position_embeddings`, even when the server has a shorter `context_len`. For a model with a 1M position limit served at 136K, the complex frequency buffer and its FP32/BF16 tables still cover all 1M positions.

## Changes

Size the NPU frequency buffer from the serving context plus speculative reserve and alignment, capped at the original table length. Use the maximum adaptive draft capacity when reserving space. Keep the model's YaRN original length, scaling factor and base unchanged.

Use the resulting length in the shared rotary-owner cache key as well, so different table lengths cannot overwrite each other's NPU buffers. CUDA/HIP retain their existing allocation length. No new option or forward-path operation.

## Validation

Isolated Ascend 910C test, torch 2.10.0+cpu / torch_npu 2.10.0.post6, CANN 9.1.0. Two frequency families, rotary dimension 64. Measurements are incremental `memory_allocated` for these tables, not total model HBM.

| Configuration | Rows | Allocated bytes |
| --- | ---: | ---: |
| Main, 1M model limit | 1,048,576 | 2,684,361,728 |
| This change, context 139264, draft 6 | 139,648 | 365,497,344 |
| This change, context 32768, no speculation | 33,024 | 84,548,608 |

The 136K case saves **2.160 GiB per logical NPU** against main. After excluding the retained real/imag copies addressed by #47718, the additional saving is **1.730 GiB**. That comparison releases the copies after initialization to separate the two changes; it is not a full-model run with both PRs. Generic rotary-embedding tables are excluded.

- 8 length-selection cases, including adaptive draft capacity and the model limit.
- 12 full FP32/BF16 table pairs and 24 forward/inverse gather cases: exact equality.
- 4 changed-position NPU graph replays, including positions in the reserved region: exact equality.
- 6 cases executing the extracted RoPE initialization section for NPU/non-NPU and SWA/C4/C128.
- Production frequency generation under the NPU default device: short table equals the full table's prefix.
- Formatting, lint, compilation and diff checks passed. Two Windows `python3` hook launchers failed; the same scripts passed when invoked with `python`.

[Reproduction scripts and recorded results](https://github.com/AkiYangDev/sglang/tree/2bfc02dc812a7277cf8bee8aa961b384759f7321) are kept outside this production diff.
