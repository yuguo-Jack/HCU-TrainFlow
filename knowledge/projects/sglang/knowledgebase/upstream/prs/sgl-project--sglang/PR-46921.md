# [Feat] [NPU] attention: Support modelslim MLA FP8 KVCache

[Upstream PR](https://github.com/sgl-project/sglang/pull/46921) · state: closed · merged: True

## Original PR description

## Motivation

Support ModelSlim static FP8 KV cache for MLA models(deepseekV3 and KimiK3) on 950 NPU, reducing cache memory usage and accelerating attention computation. Alse enabling MLAProlog support for FP8 KV-cache path.

## Modifications

- Introduce reusable ModelSlim static KV-cache quantization infrastructure with a common quantization method and scheme interface for parameter creation, loading, and post-processing.
- Implement the Q_FP8_DYNAMIC_KV_FP8 scheme, storing latent KV in FP8 while retaining BF16 side components.
- Integrate with the NPU memory pool and FIA v2 in attention backend.
- Add MLAProlog support for FP8 KV-cache path.
- Enabled through --quantization modelslim --kv-cache-dtype fp8_e4m3; (Requires ModelSlim-format quantized weights with the attention quantization type set to Q_FP8_DYNAMIC_KV_FP8.)
