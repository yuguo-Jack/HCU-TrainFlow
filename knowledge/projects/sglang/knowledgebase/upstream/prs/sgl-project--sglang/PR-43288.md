# [Perf] wan2.2-s2v: Fuse segmented block modulation and minimize Ulysses exchange copies

[Upstream PR](https://github.com/sgl-project/sglang/pull/43288) · state: open · merged: False

## Original PR description

**Retitled and reduced.** This PR previously carried four commits (the wav2vec2 lip-sync fix and three DiT speedups). It has been split so the correctness fix (#44755) and the self-contained RoPE change (#44756) can be reviewed separately; what remains here is the part that touches **shared layer code** and therefore needs the most review.

## Changes
- **`GatedResidual2Seg` and `LayerNormScaleShift2Seg`** (`runtime/layers/elementwise.py`, `runtime/layers/layernorm.py`): two-segment variants of the existing fused ops. S2V's sequence is visual tokens followed by a replicated reference suffix, and the two segments take different modulation, so the single-segment ops could not express it without splitting and re-concatenating in fp32. Device specialisation is via `CustomOp.forward_xpu`, the framework's own dispatch — there is no `if is_xpu` in a model file.
- **Minimal-copy Ulysses exchange for the replicated suffix** (`dits/wan_s2v.py`): the suffix is identical on every rank, so it does not need to travel through the all-to-all. This commit depends on the modulation refactor above and cannot be separated from it.

3 files, +180/−86 over the port.

## Measured
2 × B60, SP=2 Ulysses, 576×768: the three DiT changes together (this PR plus #44756, which it stacks on) are **−24.5 % per step**, and **−24.0 %** over a 40-step request.

## What a reviewer should push on
The two new classes live in **shared** modules but today have one consumer. If upstream would rather they stayed local to `wan_s2v.py` until a second model needs them, that is a reasonable call and I will move them. The XPU `forward_xpu` paths carry the measured gain; the generic fallback is correctness-only and unmeasured on CUDA.

## Base
⚠️ **Stacked on #43279** (the S2V port) **and on #44756** (fp32 RoPE), split out of this one — its first commit is that RoPE change, which the modulation fusion builds on. Merge order: port → RoPE → this.
