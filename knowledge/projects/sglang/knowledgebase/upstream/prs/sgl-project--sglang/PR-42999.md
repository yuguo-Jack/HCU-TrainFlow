# [sgl-router] Parse tool calls when serving chat through /generate

[Upstream PR](https://github.com/sgl-project/sglang/pull/42999) · state: closed · merged: True

## Original PR description

Chat requests with tools are served through `/generate`, with tool calls parsed in the router. Stacked on #42998.

## Modifications

- **Scope:** tools go through `/generate` when SGLang adds no constraint: `tool_choice` `auto` or `none`, no strict tools, and standard JSON-schema types. `required`, named and strict choices take their constraint from the engine's xgrammar version, so they still go to the engine's own route.
- **Parsing goes through `sglang-processor/parser`:**
  - `deepseekv4` maps to `parser/models/deepseek_v4.rs`, a port of SGLang's DeepSeek DSML detector and `FunctionCallParser`'s wrapping, behind a `ToolDetector` trait (Python's `BaseFormatDetector`).
  - It covers streaming and one-shot responses, with `stop` rewritten to `tool_calls`.
  - Python's JSON and string helpers move to `parser/py.rs`.
- **Behavior change for sglang-server and sglang-renderer:** `tool_call_stream` and `parse_tool_calls` pick the port or Dynamo's jail by name. As a result, sglang-server and `ChatResponseProcessor` (sglang-renderer) now parse DeepSeek-V4 tool calls as Python does too.

## Checks

- `tests/fixtures/tool_parity/deepseekv4.json` replays SGLang's `FunctionCallParser` on chunked outputs, through the `parser/models` registry. A `ChatResponseProcessor` test covers V4 reasoning plus a tool call on the server and renderer path.
- The DeepSeek-V4-Flash-0731 OpenAI fixture gains single, parallel, streamed, `n=2` and history tool cases recorded from a live engine, and all of them match Python.
- **Live check:** every tool case reaches the engine with an identical `GenerateReqInput`.
- **Known limits:** tool arguments with integers beyond 64 bits, `-0`, non-finite numbers, lone surrogates or nesting deeper than 128 parse differently from Python. `SGLANG_TOOL_STRICT_LEVEL` and `SGLANG_FORWARD_UNKNOWN_TOOLS` are assumed unset on the engine.
