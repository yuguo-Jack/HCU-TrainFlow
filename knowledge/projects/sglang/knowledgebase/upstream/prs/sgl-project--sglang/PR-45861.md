# [CI] [AMD] diffusion: Skip the LTX-2.5 diffusion decoder case on the 2-GPU lane

[Upstream PR](https://github.com/sgl-project/sglang/pull/45861) · state: closed · merged: True

## Original PR description

## What

Skip `ltx_2_5_diffusion_decoder_2gpus` in `multimodal-gen-test-2-gpu-amd`. The 2-GPU `run_suite.py` call gets `-k "not ltx_2_5_diffusion_decoder"`, the same way the 1-GPU AMD job already skips `flux_2`.

## Why

This case has not passed once on mi300 in the scheduled `pr-test-amd.yml` runs from 2026-09-24 to 2026-10-22, on rocm10, rocm724 or rocm720. Whenever partition 1 reached it, its server failed to come up within the 1200 s startup deadline. It is the only failure in partition 1: [job 118624622125](https://github.com/sgl-project/sglang/actions/runs/39421857090/job/118624622125) ends the initial pass at `14 passed, 1 skipped, 1 error` after 82 minutes.

The cost comes from the retry policy. `pytest_runner._is_retryable_failure` treats `TimeoutError` as a flake, and the AMD job does not set `SGLANG_DIFFUSION_RETRY_DEADLINE`, so the case is retried up to six more times at 20 minutes each. Since 2026-10-04, partition 1 has hit the 180 min step timeout on nearly every run.

Because the job's matrix is `max-parallel: 1` over image × partition, the time is serialized. On the 7.2.4 / 7.2.0 schedule the four jobs ran back to back from 17:40 to 02:44 UTC on 2026-10-20 ([run 39467849653](https://github.com/sgl-project/sglang/actions/runs/39467849653)). Two of those nine hours were partition 1 timing out, once per image.

## Notes for the reviewer

- The startup failure itself is not diagnosed here. During warmup the server autotunes `flex_attention` for the tiled diffusion decoder (about 90 s per shape on mi300), then logs nothing for the remaining ~13 minutes until the deadline. On H100 the same case decodes in about 3.4 s. That needs a separate look on ROCm; this PR only stops it from costing every AMD run two hours.
- `run_suite.py` ANDs `-k` with its own partition filter. The partition assignment is unchanged, and no other case id contains the substring.

## Test plan

- Dispatched the 2-GPU multimodal stage on rocm10 from this commit: [run 39830758814](https://github.com/sgl-project/sglang/actions/runs/39830758814). Both partitions passed with no retries: [partition 0](https://github.com/sgl-project/sglang/actions/runs/39830758814/job/120006157657) in 60 min (`11 passed, 1 skipped`), [partition 1](https://github.com/sgl-project/sglang/actions/runs/39830758814/job/120006157729) in 64 min (`16 passed, 1 skipped`), against 180 min and a failure before. The filter expression ends in `and (not ltx_2_5_diffusion_decoder)` and the case is never started.
