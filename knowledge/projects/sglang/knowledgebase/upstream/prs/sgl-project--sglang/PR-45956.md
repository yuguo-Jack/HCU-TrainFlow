# [Spec] Support adaptive speculative decoding with TBO

[Upstream PR](https://github.com/sgl-project/sglang/pull/45956) · state: open · merged: False

## Original PR description

## Motivation

Adaptive speculative decoding currently falls back to static parameters when two-batch overlap is enabled because rebuilding an adaptive target runtime state bypasses the `TboAttnBackend` wrapper.

Refs #23705.

## Modifications

- Build adaptive target attention backends with the configured TBO wrapper.
- Share the same TBO-aware backend factory between normal startup and adaptive runtime-state construction.
- Remove the adaptive-spec TBO compatibility guard.

## Scope

This initial PR targets EP TBO without attention DP. Attention-DP plus TBO is intentionally left out because adaptive DP requires cross-rank tier consensus and is tracked as a separate roadmap item.

Not run yet. Opening as a draft for scope and design feedback.
