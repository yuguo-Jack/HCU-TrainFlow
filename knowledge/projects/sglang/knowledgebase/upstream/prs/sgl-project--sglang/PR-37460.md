## Motivation

The LoRA linear classes repeatedly implemented the same logic as the base linear classes. To avoid conflicts and simplify future maintenance, the linear class logic needs to be refactored.

## Modifications

- A base linear class `ParallelLinear` was created, which implements common behaviour for all linear classes.

- Other linear classes inherit from `ParallelLinear` and only re‑implement parts that differ from the base implementation.

- The LoRA base linear class `BaseLayerWithLoRA` implements a generic `forward` method. Each inheriting class specifies the behaviour of its respective base linear layer while leveraging the base LoRA implementation.
