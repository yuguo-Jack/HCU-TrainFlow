Checking only `len(waiting_req_bytes) < 4` is insufficient to prevent `IndexError` when parsing the message.

- If `room_str == "None"`, `KVArgsRegisterInfo.from_zmq` is called, which unconditionally accesses indices up to `msg[11]`, requiring at least 12 frames.
- If `room_str != "None"`, `TransferInfo.from_zmq` is called, which unconditionally accesses indices up to `msg[6]`, requiring at least 7 frames.

Additionally, if `room_str` is not a valid integer, `int(room_str)` will raise a `ValueError`.

We should validate these lengths and catch potential `ValueError`s to gracefully ignore malformed messages without raising exceptions or logging tracebacks.

```python
        waiting_req_bytes = waiting_req_bytes[1:]
        if len(waiting_req_bytes) < 4:
            logger.warning(
                "Ignoring malformed NIXL bootstrap message with %d frame(s) "
                "after guard",
                len(waiting_req_bytes),
            )
            return

        try:
            room_str = waiting_req_bytes[0].decode("ascii")
            agent_name = waiting_req_bytes[3].decode("ascii")
        except UnicodeDecodeError:
            logger.warning("Ignoring NIXL bootstrap message with non-ASCII metadata")
            return

        if room_str == "None":
            if len(waiting_req_bytes) < 12:
                logger.warning(
                    "Ignoring malformed NIXL bootstrap registration message with %d frame(s)",
                    len(waiting_req_bytes),
                )
                return
            # Register new peer and save KV base pointers.
            self._add_remote_peer(KVArgsRegisterInfo.from_zmq(waiting_req_bytes))
            logger.debug(f"Register KVArgs from {agent_name} successfully")
            return

        if len(waiting_req_bytes) < 7:
            logger.warning(
                "Ignoring malformed NIXL bootstrap transfer message with %d frame(s)",
                len(waiting_req_bytes),
            )
            return

        try:
            room = int(room_str)
        except ValueError:
            logger.warning(
                "Ignoring NIXL bootstrap message with invalid room ID %r",
                room_str,
            )
            return
```
