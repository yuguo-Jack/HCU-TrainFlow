# [CI] Make /rerun-test honor disabled= registrations

[Upstream PR](https://github.com/sgl-project/sglang/pull/39812) · state: closed · merged: False

## Original PR description

## Summary

`/rerun-test` never read `disabled=`, so it dispatched tests `run_suite.py` skips. The file's module-level `pytest.skip` then exits non-zero and fails the job.

The handler had its own regex parser for `register_cuda_ci(...)`. It now uses `ci_register.ut_parse_one_file`, the parser `run_suite.py` already uses, and skips any registration with `disabled` set. Per registration, so a file on two pools with only one disabled still dispatches the other.

`detect_suite` over all 1968 registered files:

| Change | Files |
|---|---|
| `disabled=` now blocked | 20 |
| Error message gains a suite name the regex could not resolve | 12 |
| False-positive dispatch removed | 1 |
| Regressions | 0 |

The false positive: the old regex matched `register_cuda_ci(` inside string literals, so any file merely quoting the call was treated as a CUDA registration.

Regression test added; it fails on the pre-fix code.
