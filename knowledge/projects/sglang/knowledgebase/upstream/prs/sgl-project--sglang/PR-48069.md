# [Perf] [AMD] dsv4: Unified-KV attention kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/48069) · state: open · merged: False

## Original PR description

DeepSeek V4 unified-KV attention on gfx1250:
- bf16 sparse prefill uses `pa_sparse_prefill_opus`
- sparse decode passes `kv_splits` sized for the gfx1250 decode tile
- C4 / C4 fp8 indexer / C128 compressors fuse compress with norm/rope/store (`compress_norm_rope.cuh`)
- V4 Pro defaults to unified KV with AITER decode and allows the fp8 two-pool KV

Depends on sgl-project/sglang#48064.

<!-- results -->
### Accuracy
GSM8K (200 questions, greedy), DeepSeek-V4-Pro: TP4 0.975.

### Performance
Setup:
- Model: DeepSeek-V4-Pro, BF16 KV cache, DSPARK speculative decoding (block 6, 1 step)
- Parallelism: TP4 (`--tp 4`, CP prefill + CP decode attention)
- Step time: torch profiler on rank 0, GPU time per step; decode = 8 steps at 4 running requests (VERIFY = target verify, DRAFT = DSPARK draft), prefill = one EXTEND step of an ~8k-token prompt (TP4) / 4k (EP4)
- Comparison: with vs without this PR, same image and node, all earlier PRs of the series applied

Profiler step time (without -> with):
