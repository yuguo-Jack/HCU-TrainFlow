# [Feat] hicache: Register draft Mamba state pool

[Upstream PR](https://github.com/sgl-project/sglang/pull/48167) · state: open · merged: False

## Original PR description

## Motivation

Stateful speculative drafts need a separate HiCache pool identifier for convolution/recurrent state, distinct from the target's `mamba` pool and draft KV pools.

## Modifications

Register `draft_mamba` in Python's `PoolName`, the Rust enum, and Rust's string conversion/parser: four added lines. This only enables pool registration; draft-state lifecycle and storage-backend support are separate work.

## Accuracy Tests

Reused the existing CPU test `test_every_pool_name_crosses_the_prefetch_commit_boundary`, which exercises every Python pool name through the compiled Rust interface. Adding only the Python enum reproduces `ValueError: unknown pool name: draft_mamba`; the complete change passes.

Four CPU tests passed, including HiCache backup/restore and Mamba/SWA prefetch commits:

```bash
PYTHONPATH=python CUDA_VISIBLE_DEVICES='' python -m pytest -q \
  test/registered/unit/mem_cache/test_rust_tree_core_integration.py \
  -k 'every_pool_name or hicache_write_through or mamba_prefetch_commit or swa_prefetch_commit'
```
