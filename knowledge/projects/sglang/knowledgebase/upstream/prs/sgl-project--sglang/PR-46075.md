# [Fix] utils: Preserve quoted subprocess arguments

[Upstream PR](https://github.com/sgl-project/sglang/pull/46075) · state: open · merged: False

## Original PR description

## Motivation

`execute_shell_command()` splits on whitespace and replaces every backslash. Notebook/server-launch commands therefore fail for quoted model paths, JSON flags, escaped spaces, or quoted environment values. Even the quotes around a Python executable remain in its filename.

## Modifications

Use `shlex.split()` after removing backslash-newline continuations. Keep the existing leading environment assignment handling, copied parent environment, and `shell=False` subprocess execution; shell expansions are not enabled.

Add a CPU-registered `CustomTestCase` that runs real child processes and checks their arguments/environment. Only stdout capture is adapted at the Popen boundary.
