# [NPU][CI] Add CANN 9.1.0 nightly suites and mirror 6 tests onto the 9.1.0 image

[Upstream PR](https://github.com/sgl-project/sglang/pull/38332) · state: closed · merged: False

## Original PR description

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

The NPU nightly pipeline currently only runs against the CANN 9.0.0 image (`main-cann9.0.0-a3`). We need to validate the DeepSeek-V4-Flash, GLM-5.2 and Kimi-K3 nightly tests against the new CANN 9.1.0 stack as well, to ensure compatibility and catch regressions on the newer CANN release.

## Modifications

<!-- Detail the changes made in this pull request. -->

- `.github/workflows/nightly-test-npu.yml`
  - Add a new `image_a3_cann910` workflow input (default: `swr.cn-southwest-2.myhuaweicloud.com/base_image/dockerhub/lmsysorg/sglang:main-cann9.1.0-a3`) and expose it via `set-image-config`.
  - Add two single-node nightly jobs running on the CANN 9.1.0 image: `nightly-perf-16-npu-a3-cann910` and `nightly-acc-16-npu-a3-cann910`.
  - Add multi-node POC copies running on the CANN 9.1.0 image: `nightly-poc-multi-node-tests-cann910` (DeepSeek-V4-Flash 1p1d 16P perf) and `nightly-poc-multi-node-mix-tests-cann910` (GLM-5.2 16P GPQA + Kimi-K3 32P GPQA accuracy).
  - Include all new jobs in `check-all-jobs` needs, status aggregation and the results summary table.
- `test/run_suite.py`: register the two new nightly suites `nightly-perf-16-npu-a3-cann910` and `nightly-acc-16-npu-a3-cann910`.
- Three DeepSeek-V4-Flash single-node tests get a duplicate `register_npu_ci` registration into the corresponding `-cann910` suite (the original CANN 9.0.0 registration is kept, so the 6 tests now run on both images):
  - `test/registered/npu/performance/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_in32k_out1k_50ms.py`
  - `test/registered/npu/performance/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_in8k_out1k_50ms.py`
  - `test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_gpqa.py`

In total 6 test instances (3 single-node + 3 multi-node) are newly mirrored onto the CANN 9.1.0 image, while all original CANN 9.0.0 executions are preserved.
