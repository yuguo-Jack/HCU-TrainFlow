# [diffusion][model] Add native SANA-Video 2.0 support

[Upstream PR](https://github.com/sgl-project/sglang/pull/41492) · state: closed · merged: True

## Original PR description

## Motivation

Add native support for `Efficient-Large-Model/SANA-Video_2.0_5B_720p`, covering text-to-video and image-conditioned video generation.

Closes #41490.

## Modifications

- Add the SANA-Video 2.0 transformer and load the official checkpoint directly.
- Match the official text conditioning and T2V/TI2V sampling, reusing SGLang's Gemma encoder, LTX 2.3 VAE and video output stages.
- Add model registration, focused regression tests, T2V/TI2V GPU CI smoke cases and [usage examples](https://github.com/cr-gao/sglang/blob/feat/sana-video2-native/docs/cookbook/diffusion/SANA-Video/SANA-Video.mdx#6-sana-video-20).

The reference is [NVIDIA's official implementation](https://github.com/NVlabs/Sana/tree/f9178744c096dcf2a2ea773da183e341bcbeb044); [vLLM-Omni #8006](https://github.com/vllm-project/vllm-omni/pull/8006) is an additional reference.

## Generated videos

Prompt: “A red tram moves slowly through a sunlit city square.”

Generated on one A800 with the default configuration: 1280×736, 193 frames, 24 FPS and 50 steps, using seed 42. The TI2V example uses the first frame of an earlier T2V sample as its input image.

## Validation

- 30 focused tests passed, including request-level flow shift and existing SANA-Video regressions. Repository pre-commit checks passed.
- The native DiT matched the official implementation exactly for the tested T2V and TI2V component inputs. Gemma and VAE comparisons passed the repository's existing accuracy thresholds. These are component checks, not full-pipeline equivalence claims.
- Real-weight CLI generation passed for both modes. The public `/v1/videos` API passed T2V, uploaded-image conditioning, two-output and repeated-request checks. Both requested outputs were returned, and repeating the same seed reproduced the same video.
- T2V and TI2V passed the default 1280×736, 193-frame, 50-step configuration on one A800. Both new GPU smoke cases also passed on that GPU.
- Both default-profile videos passed full decoding and metadata checks.

This PR covers single-GPU inference with the 5B checkpoint. The 4-step preview and distributed execution are outside its scope.
