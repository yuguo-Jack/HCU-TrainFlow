# [Perf] diffusion: Enable image-prefix sequence parallelism for ERNIE-Image

[Upstream PR](https://github.com/sgl-project/sglang/pull/48218) · state: open · merged: False

## Original PR description

## Motivation

On the baseline, ERNIE-Image passes a 4D spatial latent into generic sequence sharding, so a native Ulysses2 request fails before model execution. Its DiT also keeps the joint image/text stream replicated and disables sequence-parallel attention. This enables image-prefix sharding inside the DiT and makes the existing two-GPU path useful for high-resolution requests.

## Modifications

- Keep spatial latents intact at the pipeline boundary; shard image tokens after embedding and retain the replicated text suffix.
- Reuse `build_shard_plan`, `shard_seq_prefix`, and existing USP suffix attention. Preserve global RoPE positions and gather only the narrow final image patches.
- Retain dense execution for masked text, uneven image-token counts, and Ring; add focused two-rank model/pipeline tests and update the ERNIE cookbook.
