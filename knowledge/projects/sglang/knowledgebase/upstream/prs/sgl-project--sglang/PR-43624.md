# [Model] Keep gpt-oss router logits batch-invariant under deterministic inference

[Upstream PR](https://github.com/sgl-project/sglang/pull/43624) · state: closed · merged: True

## Original PR description

- `TinyGemmLinear` (the gpt-oss router) switches to FlashInfer `tinygemm_bf16` for batches of up to 128 tokens and to the regular GEMM above that, so a token's router logits, and the experts and weights it gets, depend on how many tokens share its batch. With `--enable-deterministic-inference`, a prefill whose last chunk is short, or a prompt batched with others, gave different outputs
- Skip the tinygemm path under deterministic inference, so the router always runs the regular GEMM

Fixes the triton-attention part of #43055: its prefix-mode determinism test returns one output per prompt with the triton attention backend (triton_kernel and triton MoE runners); fa3 still differs. No behavior change without deterministic inference.
