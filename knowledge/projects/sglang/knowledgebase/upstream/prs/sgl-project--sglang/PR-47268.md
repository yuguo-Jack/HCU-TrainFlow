# [Fix] cuda-graph: Wait for host-cache loads before replaying a captured linear-attention extend

[Upstream PR](https://github.com/sgl-project/sglang/pull/47268) · state: open · merged: False

## Original PR description

Breakable prefill CUDA graphs can capture the linear-attention extend. Its state-pool accessor, which waits for HiCache's layer-wise host loads, runs only at capture, and `_wait_for_layer_loads` returns early for breakable replay, so a replay can read recurrent state that a host load is still writing.

Wait for the whole layer-wise load before replaying a graph that captured the linear extend, as full replay already does. Breakable replay without it keeps its per-layer overlap.

The new CPU test checks that such a replay blocks until the last layer is loaded; it fails on main.
