# [Test] diffusion/loader: Make restoration tests independent of execution order

[Upstream PR](https://github.com/sgl-project/sglang/pull/46254) · state: closed · merged: True

## Original PR description

## Motivation

The MOVA bridge restoration and native text-encoder restoration tests use TP/world-group state without requesting its fixture. They pass when another test happens to initialize model parallelism first, but fail when collected alone or in a different order.

## Modifications

Use the existing `single_process_model_parallel` fixture on the two affected parametrized tests. Two lines; no production changes, new fixtures, or relaxed assertions.

## Validation

Remote H200, comparing against main `463af5ac80dc`:
- Before: 8 failures (`tensor model parallel group is not initialized` / `world group is not initialized`).
- After, fresh interpreter for each file: plain state-dict loaders 30 passed; text-encoder loaders 50 passed, 3 skipped.
- Reverse file order: 80 passed, 3 skipped.
- Skips are the existing Blackwell-only NVFP4 tests and unavailable optional `comfy_kitchen` dependency.
- Pre-commit passed.

No inference behavior or documentation changes.
