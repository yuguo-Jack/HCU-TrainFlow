# [Feat] unified-memory: Keep a fused draft through HiCache

[Upstream PR](https://github.com/sgl-project/sglang/pull/46383) · state: open · merged: False

## Original PR description

Stacked on #46381 ([Feat] unified-memory: Fuse MLA drafts into MLA hosts); only the last commit is new here.

## Motivation

With `--enable-unified-memory`, a fused draft's KV lives in the target's entries, so HiCache has to keep those rows together with the target's. #45700 does this for a fused DFLASH draft on a hybrid sliding-window target: the target's L2 page envelopes copy whole pages, draft parts included, so the draft needs no host pool of its own. That holds for every dense draft fused into the target's pages, but EAGLE and NEXTN drafts were still refused with HiCache (`--enable-hierarchical-cache`), and so was a Mamba-hybrid host's fused NEXTN head.

## Modifications

- The FUSED plan from #45700 and its check (`validate_fused_hicache_draft`, `mem_cache/hybrid_cache/hybrid_pool_assembler.py`) now cover every dense draft fused into the target's pages: EAGLE and NEXTN drafts too, including drafts with sliding-window layers and one pool per draft runner. The check verifies, at registration, that every draft pool shares the target's unified buffer and that both host envelopes are page envelopes. A DFLASH draft keeps its full-attention-only rule.
- On a Mamba host the host pool copies rows layer by layer. A NEXTN head's rows now pack into it as layers after the target's, the way a private MTP pool's do. The copies go through the draft pool's pointer tables, at the host's physical ids (`mem_cache/unified_draft_pool.py`, `speculative/base_spec_worker.py`).
- The fusion gate (`mem_cache/kv_cache_configurator.py`) admits HiCache in those two cases and declines it otherwise: a hybrid sliding-window host with a storage backend past L2 or an MLA target (the page-envelope route), the three-sub-pool host, or a draft that does not pack. An MLA host with Mamba or KDA state takes the packed route when the draft's latent rows match the host's. Those cases keep today's private pool or boot refusal. The argument-time refusal of EAGLE with HiCache (`arg_groups/kv_cache_hook.py`) is removed; a decline still refuses the boot and states its reason.

Tests:
- CPU, `test/registered/unit/mem_cache/test_hicache_mtp_state.py`: the plan picks FUSED for page envelopes and packs a fused NEXTN head on a Mamba host; the check takes every dense fused draft (full-attention and window, one pool per runner) and refuses latent pools, non-envelope host pools and a draft outside the target's buffer.
- CPU, `test_fused_draft_placement.py`: the gate's admit and decline cases, including L2-only storage and the DFLASH full-attention-only rule.
- CPU, `test_dense_fused_draft_geometry.py`: a host backup and reload round trip keeps the draft rows with the target's, for dense and latent packed layouts.
- CUDA, `test/registered/kernels/ops/kvcache/test_fused_draft_hicache_transfer.py`: the same round trip through the real cache controller and transfer engine, for MHA and MLA, layer-first and page-first host layouts.

## Accuracy Tests

SM90, `--attention-backend triton`, CUDA graphs on, `--enable-hierarchical-cache` (`--hicache-ratio 2`, no storage backend), `--enable-deterministic-inference`, NEXTN (3 steps, 4 draft tokens), radix cache, overlap scheduler:
- `Qwen/Qwen3.5-9B`, TP 1: a Mamba host, where the fused NEXTN head packs as extra layers.
- `XiaomiMiMo/MiMo-V2-Flash`, TP 4: a hybrid sliding-window host, where the page envelopes carry the draft rows.

Each of 32 prompts is decoded once with its prefix on the GPU, and again after the prefix was evicted to host memory and loaded back. Prompts run one at a time and as a concurrent burst; the unified-memory servers ran with `SGLANG_DEBUG_POISON_POOL=1`. The controlled comparison is the prompts that reloaded from host memory **and** kept the same cached length on both passes: their text and their verify-step count must match.

| model | pool | one at a time: controlled prompts, text / verify-count differences | burst: controlled prompts, differences | all prompts with any text difference (one at a time / burst) |
|---|---|---|---|---|
| Qwen3.5-9B | default | 6, 0 / 0 | 8, 0 / 0 | 6 / 10 |
| Qwen3.5-9B | `--enable-unified-memory` | 18, 0 / 0 | 26, 0 / 0 | 5 / 0 |
| MiMo-V2-Flash | default | 22, 0 / 0 | 22, 0 / 0 | 0 / 0 |
| MiMo-V2-Flash | `--enable-unified-memory` | 22, 0 / 0 | 6, 0 / 0 | 0 / 0 |

All observed text differences occur outside the controlled set, where cached lengths differ between the passes, on both pools. No text or verify-count difference was observed on a matched reload.
