# Cut repeated setup from DeepSeek-VL2 multi-image requests

[Upstream PR](https://github.com/sgl-project/sglang/pull/24624) · state: closed · merged: False

## Original PR description

## Motivation

A DeepSeek-VL2 request with several images repeats request-wide setup for every image. A two-image request reads the same vision dtype twice and allocates a combined crop tensor that it never uses. The caller gets identical image features after paying this extra preprocessing cost.

After this change, each request reads the dtype once and validates crop shapes without building the temporary tensor. Image-token ordering stays the same. If `timm` is missing, the caller sees the same install hint without a misleading empty exception cause.

This PR is stacked on https://github.com/sgl-project/sglang/pull/24622.
