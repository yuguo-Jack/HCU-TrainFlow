# [Fix] disaggregation: Preserve sampler customized_info across PD

[Upstream PR](https://github.com/sgl-project/sglang/pull/40107) · state: closed · merged: True

## Original PR description

## Why is this change needed?

Prefill samples the first output token, but its sampler-provided `customized_info` does not reach decode. For a sampler that copies each generated token into metadata, output tokens `[101, 102, 103]` currently produce:

```diff
- "sampled_token_ids_copy": [102, 103]
+ "sampled_token_ids_copy": [101, 102, 103]
```

Transfer this metadata through the existing P/D buffers using MessagePack and the existing NumPy/tensor codecs. Tensors are restored on CPU.

Transfer is disabled by default (`SGLANG_DISAGG_CUSTOMIZED_INFO_MAX_BYTES=0`), preserving the legacy buffer layout and registration messages. To enable it, upgrade both peers and set the same positive capacity, such as `4096`, on each. Invalid or oversized payloads fail only the affected request and are cleared before its abort response.

With transfer enabled, NIXL and Mooncake validate buffer sizes before writing and use the receiver's row strides. Decode-only speculative decoding can use wider hidden-state rows, and the optional trailing checksum buffer need not be enabled on both peers. Resumed requests keep their existing metadata rather than appending the prefill token again.

## Test Plan

- Reuse the existing customized sampler and three unified-memory P/D parity variants to check scalar and array metadata for every output token. Fixed the assertion hook to match the current parity fixture.
- CPU fixture check: the old hook silently accepted missing first-token metadata; the repaired hook rejects it and accepts complete metadata across all three variants. This verifies assertion dispatch, not GPU transport.
- Cover opt-in/legacy layouts, optional checksums, capacity and row strides, serialization failures, request-local abort/recovery, and metadata preservation during rebootstrap in existing unit suites.
- CPU regression suites: 510 tests and 412 subtests passed; 17 skipped.
- Changed-file pre-commit checks passed. GPU end-to-end validation is pending CI.
