# [sgl-router] Policy reorg 9/N: remove the legacy selection ladder and move the bucket engine into place

[Upstream PR](https://github.com/sgl-project/sglang/pull/40097) · state: closed · merged: False

## Original PR description

Stacked on the 8/N switch PR. Two commits, reviewed separately:

1. **Removal.** Deletes the old `Policy` trait, `selection.rs`, `decode.rs`, `factory.rs`, `scoring/`, the legacy policy files and `RadixTreePrefixProvider`. `AppContext` builds the `BucketResolver` at construction (`AppContext::new` / `with_engine_state`); the chat handler picks one engine per stage and forwards as before. Ingress tokenization moves to `tokenizer/request.rs`; PD pool resolution stays as `policies/pools.rs`. `--selection-engine` is gone.
2. **Move.** `policy_reorg/*.rs` -> `policies/*.rs`, `policy_reorg/buckets.rs` -> `src/buckets.rs`; import repoints only. Review with `git show -M --color-moved=dimmed-zebra`.

## Dropped options (rejected at startup)

`--policy fused_score` / `score_policy`, `--fuse`, `--filter prefix_cache`, `--prefix-cache-min-share`, `--decode-policy legacy_host_affinity`, `--stable-pair`, `--affinity-mode soft` (only `strict` remains). Pressure-guard tuning now requires `--policy cache_aware`. README documents the list.

## Behavior boundaries (deliberate, per POLICY_DESIGN.md)

- No capacity-relaxation pass and no primary/backup substitution: when every compatible bucket rejects, the request gets 503 `prefill_admission_exhausted` instead of an overcommitted engine.
- A session binding rejected by admission is kept; the request falls back within the bucket (`session_admission_fallback`).
- `cache_candidates_exhausted` is no longer emitted; a rejected global cache winner falls back through its size bucket as before.

`tests/proxy/shared_prefill_admission.rs` now holds two tests for those boundaries; the five tests built on fake proposal-trait policies are gone with the trait. The full proxy suite (`bucket_routing`, `chat_routing`, `pd_*`, `sticky_*`, cache tests) passes unchanged otherwise.
