# [Perf][Apple]: Fuse MoE combine multiply-reduce into one Metal kernel

[Upstream PR](https://github.com/sgl-project/sglang/pull/29804) · state: open · merged: False

## Original PR description

## Motivation

The reference MoE combine, `(y * scores[..., None]).sum(axis=-2)`, runs a broadcast multiply and a reduction with a transient between them. One Metal kernel saves a full read of `y`, the transient round trip, and one dispatch per MoE layer.

## Modifications

- `fused_combine.py`: the kernel and its eligibility guard. Contract is `scores.shape == y.shape[:-1]` with rank at least 3, so the rank 4 production call sites (prefill `[1, L, 4, 2048]`, decode `[R, 1, 4, 2048]`) take the fused path. bf16 scores accepted. Ineligible inputs fall back inline, so patching never changes results.
- Default off: `SGLANG_MLX_FUSE_MOE_COMBINE=0` in `environ.py`; `patch_moe_combine_with_fused` swaps the Qwen2 and Qwen3 MoE blocks at load, beside the existing SwiGLU patch. Merging changes nothing for any user.
- `metal_jit.py`: a `MetalJitOp` base with a `can_fuse`, `dispatch_fused`, `dispatch_fallback` template and typed `NotFusable` routing. `can_fuse` is abstract; each op declares its own predicate. Compile failures are memoized and fall back instead of raising into the forward pass. Both MoE kernels migrate onto it; kernel names stay byte identical.

## Accuracy Tests

`test_fused_combine.py` (10), `test_metal_jit.py` (20), `test_fused_swiglu.py` (15). fp16 and bf16 scores are bit exact against the fp32 reference; fp32 scores are bounded by `allclose` plus an integer ULP ceiling of 3 on elements above a 1e-3 magnitude floor, verified at 0 to 1 ULP across 100 seeds per shape including the production prefill shape. Forced compile failure on an eligible input: no raise, bit exact output, no cache corruption. Full `stage-a-unit-test-mlx` through `run_suite.py` at 2a8ac82: 294 tests, 23 files, all pass.

## Speed Tests and Profiling

End to end, `Qwen1.5-MoE-A2.7B-Chat-4bit`, M4 Pro 24 GB, interleaved launches, medians: decode bs=1 131.0 to 131.8 tok/s (+0.6%), bs=4 201.2 to 203.6 (+1.2%), prefill L=268 758 to 818 (+1.5%).

Isolated op, bootstrap 95% CI excluding zero: decode bs=1 +9.6%, bs=4 +7.4%, prefill L=268 +82%.

## Known Limitations

- `warmup_specs` has no consumer yet; `aot.py` picks it up in a follow up PR.
- SwiGLU's `dispatch_fallback` raises rather than computes; its real fallback needs wrapper context the op does not receive.
- Fallback occurrences aren't counted on either op.
