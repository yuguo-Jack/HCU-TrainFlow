# [AMD] Add experimental gfx1201 inference support

[Upstream PR](https://github.com/sgl-project/sglang/pull/32092) · state: closed · merged: False

## Original PR description

## Motivation

SGLang's ROCm path primarily targets AMD Instinct GPUs. RDNA4 `gfx1201`
devices such as the Radeon AI PRO R9700 need architecture-specific build
settings and backend selection to run supported dense and MoE workloads.

This PR adds experimental single-GPU `gfx1201` inference support for BF16/FP16,
online FP8 quantization, Triton BF16/FP8 MoE, and native MXFP4 GPT-OSS models.

## Modifications

- Add `gfx1201` detection and ROCm kernel build configuration with wave32 and
  OCP E4M3 FP8 support.
- Default MHA and MLA attention to Triton on `gfx1201` and keep unsupported
  AITER paths disabled.
- Enable online FP8 dense inference and BF16/FP8 Triton fused MoE kernels.
- Enable native GPT-OSS MXFP4 inference through `triton_kernels`, including
  compatibility with both the legacy `routing_data` and current
  `x_ragged_metadata` matmul APIs.
- Add wave32-compatible MoE TopK handling, architecture guards, focused CPU and
  AMD GPU regression tests, and `gfx1201` documentation.

The `gfx1201` path is intentionally limited to one GPU. Custom all-reduce,
tensor/expert parallelism, AITER, Quark MXFP4, and other untested quantization
formats remain unsupported.

## Accuracy Tests

Validated on an AMD Radeon AI PRO R9700 (`gfx1201`) with ROCm 7.2:

- PR-scope pre-commit hooks: passed.
- Focused CPU/configuration regressions: 7 passed, including 2 subtests.
- The complete gfx1201 and Quark configuration test files passed all 12 tests,
  including 2 subtests.
- Registered `gfx1201` AMD tests: 5 passed using the current pinned
  `triton_kernels` API. These cover TopK softmax/sigmoid, BF16 and FP8 fused
  MoE, FP8 scaled matmul, MXFP4 matmul, and MXFP4 MoE routing against a
  dequantized BF16 reference.
- The same 5 registered tests passed with the legacy `matmul_ogs` API.
- Compiled `sgl-kernel` AOT probes passed for TopK softmax/sigmoid,
  `silu_and_mul`, and MoE block alignment.
- A clean `sgl-kernel` snapshot from the final PR HEAD built and packaged as a
  gfx1201-only wheel with zero unsupported CUDA calls; the isolated wheel
  install passed the same AOT probes.
- The complete compiled `sgl-kernel` MoE TopK softmax/sigmoid parameter matrix
  passed all 1518 cases on `gfx1201`.
- 270 routing compatibility cases passed.
- Real `sglang.Engine` smoke tests passed for Qwen3-0.6B BF16, Qwen3-0.6B
  online FP8, and GPT-OSS-20B native MXFP4. Each generated 16 tokens; GPT-OSS
  loaded 13.09 GB of weights and selected `moe_runner_backend=triton_kernel`.
  BF16 and online FP8 were repeated from the final PR HEAD with the isolated
  wheel and no explicit attention override; both automatically selected
  `attention_backend=triton` and completed successfully.

## Speed Tests and Profiling

No performance improvement is claimed. The Engine runs above are functional
validation, not benchmarks.
