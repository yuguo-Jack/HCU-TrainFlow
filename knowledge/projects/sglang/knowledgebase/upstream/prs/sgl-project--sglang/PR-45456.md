## Motivation

https://github.com/sgl-project/sglang/pull/45252 updated the CUDA 13.4 to a newer version of the torch 2.15 nightly. Torch has switched to a new "nccl2" backend by default, which led to "ValueError: Tensors must be contiguous" during EPLB rebalance. 

## Modifications

Set `TORCH_DIST_USE_NCCL2=0` to go back to the same torch nccl backend we were using before.
