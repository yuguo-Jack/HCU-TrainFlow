## Original PR description

`test_megamoe_sum_deferral.py` has no `__main__` block, so CI runs it as `python3 file.py` without executing its 3 tests, and `check-registered-tests` rejects every commit on this branch that touches `test/registered/`. This adds `unittest.main()`; the file now runs 3 tests and passes.
