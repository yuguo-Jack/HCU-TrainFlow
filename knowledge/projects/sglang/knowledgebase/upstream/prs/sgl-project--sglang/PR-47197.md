# [Fix] hicache: Isolate NIXL storage tests from background eviction

[Upstream PR](https://github.com/sgl-project/sglang/pull/47197) · state: closed · merged: True

## Original PR description

## Motivation

NIXL storage round-trip tests assume written files remain available until readback, but `TestNixlUnified` leaves the default L3 cleaner enabled. At >=80% filesystem usage, its background thread can legitimately evict those files, causing `test_mla_mamba_round_trip_keeps_each_tp_rank` to fail at readback with `NIXL_ERR_BACKEND` and `[False] != [True]`.

The same signature appears on [main](https://github.com/sgl-project/sglang/actions/runs/40785158774/job/123156630934) and in [#46395's CI](https://github.com/sgl-project/sglang/actions/runs/40805636899/job/123234019350). With NIXL 1.3.0, simulating 99% disk usage reproduces the Mamba failure using the real background cleaner, without forcing a cleaner tick. The original jobs did not record disk usage, so their historical pressure condition is not directly verified.

## Modifications

- Disable L3 eviction in the round-trip fixture; cleaner semantics remain covered by `test_hicache_nixl_cleaner.py`.
- Allocate a unique temporary directory per test instead of sharing a fixed path.
- Register cache cleanup (including the optional OBJ cache), and remove the directory last via LIFO `addCleanup`. Previously the primary cache was not explicitly closed and `tearDown` removed the directory before additional caches were closed.

Production storage behavior and the existing round-trip assertions are unchanged.

## Accuracy Tests

Validated on Linux with NIXL 1.3.0, using CPU buffers and the real POSIX backend:
- Existing storage suite with `HiCacheL3Cleaner._disk_usage_pct` patched to return `99.0`: before the change, both Mamba round-trip subcases fail; after the change, **23 passed, 1 skipped** (MinIO unavailable).
- Deterministically scheduling a real cleaner tick after writes under the same simulated pressure: old fixture fails; fixed fixture passes both copy modes.
- `PYTHONPATH=python python3 test/registered/unit/mem_cache/test_hicache_nixl_cleaner.py -v`: **9 passed**.
- `pre-commit run --files test/registered/unit/mem_cache/test_hicache_nixl_storage.py`: passed.

The pressure test loads the existing test module with `runpy.run_path`, patches only the disk-usage query, and runs its three test classes with `unittest.TestLoader`. No actual disk filling is needed.
