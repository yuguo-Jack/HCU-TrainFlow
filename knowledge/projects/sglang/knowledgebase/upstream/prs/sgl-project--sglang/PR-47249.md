# [Refactor] scheduler: Drop the dead Req.decoded_text and BatchTokenIDOutput.decoded_texts

[Upstream PR](https://github.com/sgl-project/sglang/pull/47249) · state: closed · merged: True

## Original PR description

`Req.decoded_text` is set to `""` at construction and never assigned again, so every batch the scheduler sends to the detokenizer carries a column of empty strings.

- Remove `Req.decoded_text`, the `decoded_texts` field of `BatchTokenIDOutput`, and the code that fills, copies, and reads it. The detokenizer starts each request's text at `""` directly.
- In `_check_str_based_finish`, `stop_str in self.decoded_text` was always False, so drop it together with the inner condition that was then always True.

No behavior change: the removed values were constant, and the rewritten stop-string loop was checked against the old one on every stop list of up to two strings and every tail drawn from a small alphabet (including empty stop strings). Tests that built or read the field are updated; the test that set `decoded_text` by hand to reach the unreachable branch is removed.

## Verification

- CPU unit tests under `test/registered/unit/managers/` plus `beam_search/test_output_decode.py` and `sampling/test_sampling_params.py`, one process per file: 1050 passed before, 1049 after (the removed test); the one failure is the same on both heads and unrelated.
