# [Perf] diffusion: Cut LTX-2.3 per-block elementwise work (contiguous AdaLN values, gate-folded masks, vectorized head gate)

[Upstream PR](https://github.com/sgl-project/sglang/pull/46110) · state: closed · merged: True

## Original PR description

Branch: mick/ltx23-block-elementwise (on main 02b983603d), commits 08f4c834c3, 84eaed7e83

## Motivation

LTX-2.3 runs its guidance passes two per CFG rank, so the DiT batch is 2. Three elementwise costs in every block are small at batch 1 and add up at batch 2:

1. `get_ada_values` unbinds a `[B, T, k, D]` sum. With B > 1 every value is strided, so `_ltx2_modulate` copies each scale and shift row to contiguous memory. That is 12 copy launches per block.
2. The modality pass masks the a2v / v2a outputs with a 0/1 per-sample mask, which is a full-size multiply before the gated residual.
3. Gated attention computes `out * (2 * sigmoid(gate_logits))`. The `[B, T, H, 1]` gate is broadcast over the head dim, which PyTorch runs as a non-vectorized strided kernel (26 us at 2x1536x32x128), plus a separate doubling pass. There are six of these per block.

## Modifications

- `get_ada_values` sums value-major (`[k, B, T, D]` via `torch.add(..., out=)`), so every value is contiguous. The audio-video cross-attention tables reuse it instead of an inline copy of the same sum.
- The 0/1 mask commutes with the gate, so it now scales the `[B, T, D]` gate.
- `kernels/ops/diffusion/modulate/head_gate_triton.py`: `head_gate_mul` takes the eager `sigmoid(gate_logits)` and applies the doubling and the product in fp32 with one bf16 rounding, which is what eager does. `LTX2Attention` uses it when the attention output is contiguous and keeps the eager expression otherwise.

All three keep the same operations on the same values, so outputs are bitwise identical.

## Tests

- `test_ltx2_ada_values_layout.py`: the value-major values are contiguous and bitwise equal to the old formula (fp32 and bf16 tables, T = 1 and T > 1). A 0/1 mask on the gate equals the mask on the output, bitwise.
- `test/registered/kernels/ops/diffusion/test_head_gate.py`: `head_gate_mul` is bitwise equal to eager for 4-D and flattened inputs over 4 shapes. Strided, mismatched and fp32 inputs are rejected.

## Accuracy Tests

4xB300 (2 GPUs), LTX-2.3 two-stage 768x512x121, 30 steps, and LTX-2 two-stage: MP4s of 4 requests each are byte-identical (md5) with and without these commits (measured together with the Q/K norm-RoPE vectorization PR).

## Speed Tests and Profiling

`head_gate_mul` on B300: 2x1536x32x128 26.2 to 7.8 us, 2x126x32x64 7.4 to 4.5 us, 2x1536x32x64 16.5 to 6.2 us. With the Q/K norm-RoPE PR, LTX-2.3 stage-1 steps go from 97.2 ms to 91.8 ms, and stage 1 from 2.918 s to 2.754 s (synced stage timing).
