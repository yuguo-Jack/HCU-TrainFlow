# [Fix] sampling: reject out-of-vocab stop_token_ids

[Upstream PR](https://github.com/sgl-project/sglang/pull/44559) · state: open · merged: False

## Original PR description

## Motivation

Fixes #44535 where a `stop_token_ids` entry outside `[0, vocab_size)` crashes the server with a device-side assert in the min_new_tokens penalizer instead of returning a 400.

## Modifications

- Validate `stop_token_ids` in `SamplingParams.verify()`, the same way `logit_bias` is already validated. Bad ids now return a 400 instead of crashing the server.
- Add unit tests for out-of-range, negative, and boundary ids.
