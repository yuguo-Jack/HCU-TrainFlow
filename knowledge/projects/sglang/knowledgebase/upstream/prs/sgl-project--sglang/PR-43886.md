# [Fix] multimodal: Preserve empty media in parallel sampling

[Upstream PR](https://github.com/sgl-project/sglang/pull/43886) · state: open · merged: False

## Original PR description

## Motivation

The nonempty multimodal `n > 1` fix has already landed in #41768. This PR now covers only the remaining empty-list boundary cases:

- Promoting a single request with empty media/hash lists to a parallel-sampling batch must preserve the request dimension.
- Empty video/audio lists in an existing batch must behave as absent inputs rather than causing `IndexError` when extracting a request.

## Changes

- Normalize single-request media and hash lists through a small shared helper, with explicit field access.
- Expand absent video/audio inputs consistently with absent images.
- Test empty media with text, input IDs, and input embeddings; batched inputs; and rejection of empty hashes when images are nonempty.

The earlier gRPC caller-hash override is removed: #47120 makes cache identity content-derived. This PR has no net protobuf or Rust changes and does not allow a caller-supplied hash to substitute for content identity. Previously reported nonempty `n > 1` serving results are historical, not validation of this narrowed diff.

## Validation

- Head `ac8f08fc29ef174c4926d0a1c8ebafebb539743a`, compared with pinned main `7c8ada7ec6890b045245adac4787b410be5ac909`.
- Isolated Linux CPU environment, Python 3.12 / PyTorch 2.14.1+cu130 with no visible CUDA device: the full `test_io_struct.py` and `test_mm_hashes.py` files passed **79 tests plus 40 subtests**; two CUDA-only tests were skipped.
- Negative controls on main reproduce six hash-alignment errors for single-request parallel sampling and two `IndexError` cases when splitting batches with empty audio/video. All corresponding candidate cases pass. Nonempty-image/empty-hash mismatches remain rejected.
- Targeted pre-commit and diff checks passed. Logs, exit codes, scripts and source provenance are retained.
- GPU development capacity is blocked by platform storage provisioning. No new model-serving, gRPC E2E, or performance result is claimed; scoped CI is requested separately.
