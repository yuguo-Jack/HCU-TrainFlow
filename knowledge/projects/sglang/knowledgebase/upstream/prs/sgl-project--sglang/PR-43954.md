## Motivation

`SGLANG_NGRAM_FORCE_GREEDY_VERIFY` is documented but never reaches the verifier.
This change makes the option select greedy NGRAM verification for sampled requests.

Fixes #43931

## Modifications

NGRAM reads the option once at startup and passes the configured boolean as
`force_greedy` to `eagle_sample`. The new trailing argument defaults to `False`
for other callers. The sampler passes `is_all_greedy or force_greedy` to the
unchanged routing predicate. Default routing and existing positional arguments
are preserved; prefill remains sampled.

One registered CUDA integration regression enables the flag through the existing NGRAM
fixture, disables acceptance simulation, and warms the corpus. It compares tokens
after sampled prefill with temperature-zero generation from that exact root.
The tested request must accept drafts beyond its prefill/bonus tokens, using its
own `completion_tokens` and `spec_verify_ct`. Existing CPU truth-table unit tests are
unchanged.
