# [Fix] [Intel] engine: Disable the inductor static Triton launcher on XPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/48360) · state: closed · merged: False

## Original PR description

## Motivation
On XPU, PyTorch inductor's static Triton launcher segfaults loading some compiled kernels (seen with the compiled repetition penalty), killing the scheduler. `test_vision_openai_server_a` (LLaVA) fails on XPU because of it.

## Modifications
`engine.py`: on XPU only, `os.environ.setdefault("TORCHINDUCTOR_USE_STATIC_CUDA_LAUNCHER", "0")` before workers spawn. A user-set value is respected. No change on other devices.

## Accuracy Tests
No model-output change. `test_vision_openai_server_a::TestLlavaServer` video_images and multi_images pass on Arc Pro B60 (together with #48359).

## Speed Tests and Profiling
N/A. Only the kernel launch path changes, and only on XPU.
