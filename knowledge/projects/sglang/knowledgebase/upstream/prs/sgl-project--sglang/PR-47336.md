# [Perf] [AMD] GLM5.3: Allow AITER MXFP4 scatter intermediate only for GLM-5.3-Flash on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/47336) · state: open · merged: False

## Original PR description

## Motivation

AITER can write the MXFP4 MoE stage-2 `scatter` partials as FP4 instead of BF16 (`AITER_MXFP4_INTERMEDIATE=1`). GLM-5.3-Flash uses `scatter` for its 16384-token bucket, so long-prompt prefill benefits. The switch is lossy and process-wide in AITER, so this keeps it opt-in and honors it only for GLM-5.3-Flash on ROCm.

## Modifications

- Register `AITER_MXFP4_INTERMEDIATE` in `Envs`, default off.
- During model-specific resolution, clear it with a warning unless the launch is `Glm5NextForConditionalGeneration` on ROCm.

Enable with:

```bash
AITER_MXFP4_INTERMEDIATE=1
```

Depends on #47139, which moves the AITER pin to include [ROCm/aiter#6435](https://github.com/ROCm/aiter/pull/6435).
