# [AMD] Add Kimi-K3 Gluon whole-layer KDA and attention kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/42839) · state: closed · merged: False

## Original PR description

## Motivation

Add an opt-in ROCm/Gluon path for Kimi-K3 attention, including the whole-layer KDA decode specialization and the supporting MLA/KDA kernels needed to evaluate the complete path in SGLang.

This is opened as a draft because GPU accuracy, end-to-end AgentX, and performance validation still need to be consolidated.

## Modifications

- Add Kimi-K3 whole-layer KDA decode and KDA prefill Gluon kernels.
- Add MLA paged decode and paged prefill specializations.
- Add MLA KC-cache, VC/output-gate, causal-gate, and attention-residual specializations.
- Integrate the kernels through Kimi-K3 and the ROCm MLA attention path with model, backend, dtype, shape, and runtime qualification checks.
- Keep the existing native path for configurations outside the specialized coverage.
- Add focused adapter/coverage unit tests and standalone microbenchmark entry points for each component and the whole-layer KDA path.

The series contains 8 commits based on `50be533d09bde329bface6f1ac0631af93b528bf`.
