# [Fix] constrained: Fix Outlines jump-forward byte parsing and empty jump helper

[Upstream PR](https://github.com/sgl-project/sglang/pull/47228) · state: open · merged: False

## Original PR description

## Motivation

While auditing `python/sglang/srt/constrained/outlines_backend.py` and `python/sglang/srt/constrained/outlines_jump_forward.py`, we identified three self-contained issues in the Outlines jump-forward implementation:

1. **Wrong symbol index when parsing hex byte transitions (`outlines_jump_forward.py`):**
   Inside `for c in symbols:` in `init_state_to_jump_forward()`, multi-character hex byte transitions (`elif len(c) > 1:`) parsed `int(symbols[0][1:], 16)` instead of `int(c[1:], 16)`. When a transition ID maps to both a single-character ASCII symbol (`symbols[0]`, where `symbols[0][1:] == ""`) and a byte transition `c`, `int(symbols[0][1:], 16)` raises `ValueError: invalid literal for int() with base 16: ''` before `outgoings_ct[state] += 1` can exclude the multi-edge state.
2. **Repeated `list.pop(0)` in `OutlinesGrammar.try_jump_forward` (`outlines_backend.py`):**
   `try_jump_forward()` consumed leading UTF-8 continuation bytes (`0x80..0xBF`) using `while len(jump_forward_bytes) and jump_forward_bytes[0][0] in continuation_range: byte_edge = jump_forward_bytes.pop(0)`, shifting the list on each step even though `jump_forward_bytes` is unused afterward.
3. **No-op jump-forward helper returned when no continuation bytes or symbol jump exist (`outlines_backend.py`):**
   When `jump_forward_bytes` has length $> 1$ starting with a non-continuation lead byte (e.g. two multi-byte UTF-8 branches sharing a lead byte before diverging) so `suffix_bytes` is empty and `cur_state` is not a symbol jump-forward state (`not is_jump_forward_symbol_state(cur_state)`), `try_jump_forward()` previously returned `([], self.state)` instead of `None`, causing `jump_forward_str_state()` to return an empty `("", self.state)` jump.

## Modifications

- Parse `int(c[1:], 16)` in `init_state_to_jump_forward()` (`python/sglang/srt/constrained/outlines_jump_forward.py`).
- Iterate directly over `jump_forward_bytes` in `OutlinesGrammar.try_jump_forward()` without `list.pop(0)` and return `None` when `not suffix_bytes and not self.jump_forward_map.is_jump_forward_symbol_state(cur_state)` (`python/sglang/srt/constrained/outlines_backend.py`).
- Add unit tests in `test/registered/unit/constrained/test_base_grammar_backend.py` (`TestOutlinesJumpForward`).
