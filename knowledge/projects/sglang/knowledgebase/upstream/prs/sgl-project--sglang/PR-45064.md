# [Kernel] Add an H20-3e block-32 FP8 GEMM

[Upstream PR](https://github.com/sgl-project/sglang/pull/45064) · state: closed · merged: False

## Original PR description

SM90 WGMMA scales after every K=32 atom so block-[32, 32] FP8 matches the Triton fallback. Decode stays on an 8-token split-K tile; prefill uses a 64x128 tile once the grid covers about half the SMs. Serving enables this kernel only on NVIDIA H20-3e.
