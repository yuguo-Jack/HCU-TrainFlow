# [Fix] DSv4.1: Size the encoder-replay SWA pool by the DSpark draft's stages, and keep more prefix tails

[Upstream PR](https://github.com/sgl-project/sglang/pull/43502) · state: closed · merged: True

## Original PR description

## Motivation

```bash
python3 -m sglang.launch_server --model-path deepseek-ai/DeepSeek-V4.1-Flash --trust-remote-code \
  --tp 4 --ep-size 4 --mem-fraction-static 0.8 --max-running-requests 64 --chunked-prefill-size 8192 \
  --speculative-algorithm DSPARK --speculative-dspark-block-size 5 \
  --enable-encoder-swa-bounded-replay --enable-decoder-swa-bounded-replay
# startup, TP0: DSV4 SWA sizing: ... prefix_tails=256 / DSV4 memory calculation: ... swa_fixed=4.55 GB ... full_token=60815360
```

**The pool is priced at the wrong layer count.**
- Under encoder SWA bounded replay the target keeps its window per request, so the paged SWA pool holds only the DSpark draft's KV.
- `DSV4PoolConfigurator` prices that pool at `paged_draft_layers` = `dflash_draft_num_layers`, the draft config's `num_hidden_layers`. The DSpark head bundled with DeepSeek-V4.1 inherits the target's 40.
- `DeepseekV4ForCausalLMDSpark` builds `len(dspark_target_layer_ids)` = 3 stages. The configurator therefore reserves about 13× the bytes the draft allocates and takes them out of the full KV pool: 3.8 GB per GPU at the default, 33.5 GB at `--swa-prefix-tails 4096`. That memory stays free after graph capture.

**256 prefix tails are too few for multi-turn agentic traffic.**
- A cached prefix is reusable only while its last window still has paged SWA slots (the radix match stops at a tombstoned window).
- On a one-hour agentic-coding replay at 16 concurrent sessions, conversations idle for 3–5 minutes lose their tail while their full KV is still on the GPU. They re-prefill 130K–755K tokens, which blocks everything queued behind them for 2–13 s.
- 3.5% of requests wait more than 1 s. One request with a 104,704-token cached prefix and 311 new tokens waited 11.6 s.

## Modifications

- Record the DeepSeek-V4 DSpark draft's stage count (`SpecAuxHiddenStateConfig.dspark_num_stages`; the dense DSpark draft builds `num_hidden_layers` stages, so it is left unset there) and price the encoder-replay paged SWA by it, falling back to `dflash_draft_num_layers`.
- Under encoder replay with DSpark, default `--swa-prefix-tails` to `4 × max_running_requests × (num_layers_total // paged_draft_layers)`.
  - This keeps the byte budget of the non-replay default, which prices all target layers, and spends it on cheaper tails: 3,328 tails, ≈2.3 GB per GPU, at 64 running requests.
  - An explicit flag still wins.
- Tests:
  - `test_spec_aux_hidden_state_resolver.py`: a 40-layer draft config with three `dspark_target_layer_ids` resolves to 3 stages for the DeepSeek-V4 draft and leaves the field unset for a dense DSpark draft;
  - `test_pool_configurator.py`: the DSpark budget test now uses a 40-layer draft config with 3 stages; the default tails rule and its override.

<details><summary>GSM8K requests (our client)</summary>

- Data: `test.jsonl` (first 50) and `train.jsonl` from openai/grade-school-math.
- Prompt: the first 5 train examples as `Question: …\nAnswer: …\n\n`, then `Question: <question>\nSolve the problem. End your answer with #### followed by the numeric answer.`, sent as one user message rendered by `encoding_dsv41.encode_messages(messages, thinking_mode="chat")` and tokenized without special tokens.
- One request per question, 50 in flight:

  ```
  POST /generate {"input_ids": <prompt ids>, "cache_salt": "L1-v1-gsm8k-<index>", "sampling_params": {"temperature": 0, "max_new_tokens": 1024}, "stream": false, "return_logprob": false}
  ```
- `POST /flush_cache`, then the cold pass, then the same 50 requests again as the hit pass. Every cold response reported `meta_info.cached_tokens == 0`, and every hit response `cached_tokens >= (len(input_ids) - 1) // 256 * 256` (50/50 in both arms).
- Score: the last number in the output (commas removed) equals the last number in the reference answer.

</details>

Static prefix reuse: N distinct 16K-token prefixes at concurrency 16, one output token. Pass 1 caches them; pass 2 revisits them in reverse order with 256 new prompt tokens. All prefixes fit in the full KV pool in both arms.

```bash
python3 static_client.py --url http://127.0.0.1:<port> --out <dir>   # same command for main and this PR
```

It flushes the cache before each population, then runs N=100, N=200 and N=1000 (this PR's job reached its time limit in N=1000 pass 2, so N=1000 is not reported). Prefix hits are pass-2 requests with `cached_tokens >= 16384`; uncached prompt tokens are prompt minus cached tokens; TTFT is request start to the first streamed choice, p50 linearly interpolated.

<details><summary>static_client.py</summary>

```python
import argparse, concurrent.futures, json, math, random, statistics, time, urllib.request
from pathlib import Path

p=argparse.ArgumentParser(); p.add_argument('--url',required=True); p.add_argument('--out',required=True); a=p.parse_args()
out=Path(a.out); out.mkdir(parents=True,exist_ok=True)

def api(path, body=None):
    req=urllib.request.Request(a.url+path,data=None if body is None else json.dumps(body).encode(),headers={'Content-Type':'application/json'})
    with urllib.request.urlopen(req,timeout=300) as r:
        raw=r.read()
        if path.startswith('/flush_cache'):
            assert raw.startswith(b'Cache flushed.'),raw
            return raw.decode()
        return json.loads(raw)

def request(i, n, stage):
    rng=random.Random(42+i)
    ids=[100+i]+[rng.randrange(2000,10000) for _ in range(16383)]
    if stage==2: ids += [rng.randrange(2000,10000) for _ in range(256)]
    body=json.dumps({'model':'deepseek-ai/DeepSeek-V4.1-Flash','prompt':ids,'max_tokens':1,'temperature':0,'ignore_eos':True,'stream':True,'stream_options':{'include_usage':True},'return_token_ids':True},separators=(',',':')).encode()
    req=urllib.request.Request(a.url+'/v1/completions',data=body,headers={'Content-Type':'application/json'})
    start=time.perf_counter(); first=None; usage=None; token_events=0
    with urllib.request.urlopen(req,timeout=300) as r:
        for raw in r:
            if not raw.startswith(b'data:'): continue
            payload=raw[5:].strip()
            if payload==b'[DONE]': break
            d=json.loads(payload)
            if d.get('error'): raise RuntimeError(d['error'])
            if d.get('choices'):
                if first is None: first=time.perf_counter()
                token_events+=1
            if d.get('usage'): usage=d['usage']
    assert first is not None and usage is not None,(i,usage)
    assert usage['prompt_tokens']==len(ids),(i,usage,len(ids))
    assert usage['completion_tokens']==1,(i,usage)
    # Upstream UsageProcessor deliberately omits prompt_tokens_details when cached_tokens==0.
    details=usage.get('prompt_tokens_details')
    cached=0 if details is None else details['cached_tokens']
    assert 0<=cached<=len(ids),(i,cached,len(ids))
    return {'population':n,'pass':stage,'prefix_id':i,'ttft_ms':1000*(first-start),'elapsed_ms':1000*(time.perf_counter()-start),'prompt_tokens':len(ids),'cached_tokens':cached,'uncached_tokens':len(ids)-cached,'usage':usage,'stream_events_with_choices':token_events}

def percentile(values, p):
    v=sorted(values); x=(len(v)-1)*p; i=int(x); return v[i]+(v[min(i+1,len(v)-1)]-v[i])*(x-i)

def run(n):
    api('/flush_cache?timeout=30',{})
    result={'N':n,'prefix_tokens':16384,'extension_tokens':256,'concurrency':16,'generation_tokens':1,'seed':42,'pass1_order':'ascending prefix ID','pass2_order':'descending prefix ID, newest first','timing':'HTTP request start after client prompt construction to first streamed choices event; server emits this on first generated token','passes':{}}
    for stage in (1,2):
        order=list(range(n)) if stage==1 else list(reversed(range(n)))
        started=time.time(); rows=[]
        with concurrent.futures.ThreadPoolExecutor(max_workers=16) as pool:
            futures=[pool.submit(request,i,n,stage) for i in order]
            with (out/f'n{n}-pass{stage}.jsonl').open('w') as f:
                for j,future in enumerate(concurrent.futures.as_completed(futures),1):
                    row=future.result(); rows.append(row); f.write(json.dumps(row)+'\n')
                    if j%100==0: print(f'STATIC_PROGRESS N={n} pass={stage} completed={j}/{n}',flush=True)
        elapsed=time.time()-started; t=[r['ttft_ms'] for r in rows]; prompt=sum(r['prompt_tokens'] for r in rows); cached=sum(r['cached_tokens'] for r in rows)
        result['passes'][str(stage)]={'requests':len(rows),'errors':0,'elapsed_seconds':elapsed,'prompt_tokens':prompt,'cached_tokens':cached,'uncached_tokens':prompt-cached,'usage_cache_hit_rate':cached/prompt,'requests_with_cached_prefix':sum(r['cached_tokens']>0 for r in rows),'requests_with_full_16384_prefix':sum(r['cached_tokens']>=16384 for r in rows),'ttft_ms':{'mean':statistics.mean(t),'p50':percentile(t,.5),'p90':percentile(t,.9),'max':max(t)}}
        print('STATIC_PASS_DONE '+json.dumps(result['passes'][str(stage)]),flush=True)
        (out/f'n{n}-summary.json').write_text(json.dumps(result,indent=2)+'\n')
    return result

summary={'protocol':'independent deterministic raw token-ID prefixes via OpenAI streaming completions, one output token, max_workers16; identical order per arm; flush between populations','populations':{}}
summary['populations']['100']=run(100)
summary['populations']['200']=run(200)
summary['populations']['1000']=run(1000)
(out/'static-summary.json').write_text(json.dumps(summary,indent=2)+'\n')
print('STATIC_DONE',flush=True)
```
