# [Perf] dsv41: Use tuned MXFP8 tactics at decode sizes

[Upstream PR](https://github.com/sgl-project/sglang/pull/45630) · state: closed · merged: True

## Original PR description

## Motivation

Block-fp8 MXFP8 linears autotune every M bucket at startup but only use the tuned tactic from 4096 rows, so decode runs the pinned default tile.

## Modifications

- Lower the threshold to 1; deterministic and batch-invariant execution keep the pinned tactic.
- DEP8 decode at 128K context: step 2% faster at 16-64 requests per rank, 3% at 256.
