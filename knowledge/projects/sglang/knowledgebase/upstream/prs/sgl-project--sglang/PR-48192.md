# [Chore] mooncake: bump mooncake version to 0.3.14

[Upstream PR](https://github.com/sgl-project/sglang/pull/48192) · state: closed · merged: True

## Original PR description

## Motivation

Bump `mooncake-transfer-engine-cuda13` from `0.3.13.post1` to `0.3.14` in the docker image and the CUDA CI dependency install, and re-enable the Mooncake EP test that was disabled until a Mooncake release shipped the PyTorch 2.13 collective forwarding fix (included in 0.3.14).

The 0.3.14 `http_metadata_server` behavior change (refusing `0.0.0.0` without `MC_METADATA_HTTP_TOKEN`) is already handled on main by #48121. 0.3.14rc4 was validated green in #36469 (disaggregation group, mooncake hicache tests, and `ep/test_mooncake_ep_small.py`).

## Modifications

- `docker/Dockerfile`: `ARG MOONCAKE_VERSION=0.3.14`
- `scripts/ci/cuda/ci_install_dependency.sh`: `MOONCAKE_VERSION="0.3.14"`
- `test/registered/ep/test_mooncake_ep_small.py`: drop the `disabled=` flag from `register_cuda_ci`
