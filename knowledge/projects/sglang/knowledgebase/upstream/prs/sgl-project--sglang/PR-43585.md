# [Fix] diffusion: OpenAI API hardening

[Upstream PR](https://github.com/sgl-project/sglang/pull/43585) · state: closed · merged: True

## Original PR description

Part of #43875 (items 1-7). This PR used to also carry items 8-33. Those are now split into two follow-up PRs so each one can be reviewed on its own:
- runtime/utils fixes (items 8-24): #44887
- pipeline and model-helper fixes (items 25-33): #44888

The three PRs touch disjoint files and can merge in any order.

## Summary
Hardens the diffusion HTTP API. Item numbers match #43875.

1. Invalid `output_quality` returned 500; it now returns 400 (`adjust_output_quality` raised outside the try block).
2. `response_format="url"` with no cloud storage and no `output_path` ran the whole generation before returning 400. It is now rejected up front. Unsupported `response_format` values are also rejected before generation.
3. A cloud-upload failure (storage enabled but upload failed) returned a misleading 400 "requires cloud storage". It now returns 502. When `output_path` is not set, the generated file is still removed with the request's temp directory. Behavior change: clients that matched on the old 400 will see 502.
4. URL image inputs were read fully into memory. Downloads now stream into a temp file with a 50 MiB cap, enforced on Content-Length and on bytes received (chunked bodies). The file is moved into place only on success and removed on any error.
5. `upscaling_model_path` / `frame_interpolation_model_path` accepted any URL and the server fetched it. Network entry points (OpenAI, realtime, Vertex, rollout) now reject URLs with 400 in `build_sampling_params`, which they all share. Local paths and HF repo ids still work, and the CLI and Python API still accept URLs (the check is not in `SamplingParams`).
6. The upscaler and RIFE model caches (and the resolved-path cache) grew without bound with client-chosen paths. They are now small LRU caches, guarded by one lock.
7. `frame_interpolation_scale` (0.25-4.0) and `upscaling_scale` (1-8) are range-checked in `SamplingParams._validate` (finite, non-bool). The bounds are chosen, not derived; they match the shipped RIFE scale values and Real-ESRGAN x2/x4/x8 weights. `frame_interpolation_exp` is bounded separately by #43014 (merged).

## Tests
- New cases are added to existing files: `test_openai_security.py` (download cap, response_format, output_quality, LRU caches and lock), `test_multiple_task_types.py` (URL model paths rejected over HTTP, 502 and temp-dir cleanup through the real endpoint), `test_sampling_params.py` (scale ranges, CLI still accepts URL model paths).
- Those three files plus `test_openai_image_api.py`: 149 passed on CPU.
- No GPU run: these are request-handling and validation changes.

## Notes
- 50 MiB download cap and LRU sizes (4 models, 256 paths) are arbitrary constants.
- Local file paths for model weights are still accepted over HTTP (loaded with weights_only=True).
