# [BugFix] Fix Janus-Pro CLIPVisionTower Normalize shadowing and mean/std normalize

[Upstream PR](https://github.com/sgl-project/sglang/pull/39734) · state: closed · merged: False

## Original PR description

## Motivation

Janus-Pro `CLIPVisionTower` image-norm has been broken since the model landed. The torchvision-style transform is shadowed by the VAE GroupNorm factory of the same name, and `forward` calls `torch.nn.functional.normalize` (Lp) instead of per-channel mean/std.

Fixes #39708.

## Modifications

- Rename the image transform to `ImageNormalize` so it no longer collides with the VAE `Normalize` factory.
- Apply `(x - mean) / std` per channel in `forward`.
- Add a small CPU unit test for the math, construction with `pixel_mean`/`pixel_std`, and the factory still returning GroupNorm.

## Accuracy Tests

Unit test covers the normalization math. I do not have a Janus-Pro checkpoint here for an e2e accuracy run.

## Speed Tests and Profiling

Not affected.
