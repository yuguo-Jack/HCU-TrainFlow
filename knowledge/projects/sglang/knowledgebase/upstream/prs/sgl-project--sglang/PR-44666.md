# [Feat] srt: Add muse spark runtime, multimodal support and tests (3/5)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44666) · state: closed · merged: True

## Original PR description

## Motivation

Split [#44530](https://github.com/sgl-project/sglang/pull/44530) into five review layers. This is layer 3/5, now based on `main` after [#44665](https://github.com/sgl-project/sglang/pull/44665) merged.

## Modifications

Adds Muse Spark text and Omni runtime support, multimodal processing, MoE and quantization integration, runtime defaults, shared runtime updates, and registered tests. AMD-specific hunks and the #224 megakernel integration/tests are deferred to their respective layers.

This layer changes **82 files (+9,175 / -224)** relative to its immediate base. Every split commit preserves all 32 `Co-authored-by` trailers from the original commit.

## Validation

- Temporarily disabled the CI registration for `test_muse_spark_12_b300_pd.py` until **2026-11-01**. [B300 job 117611788593](https://github.com/sgl-project/sglang/actions/runs/39099912264/job/117611788593) failed during server startup and ran zero tests: the log shows whole-model Hugging Face cache cleanup immediately before tokenizer loading failed, consistent with a concurrent cache cleanup race. [#44975](https://github.com/sgl-project/sglang/pull/44975) is a one-file follow-up based on this PR that restores the registration; the cache issue still needs validation or a fix before merging that follow-up. CI registry parsing and pre-commit passed for both changes.
- Fixed the earlier failures in [Base run 39006509622](https://github.com/sgl-project/sglang/actions/runs/39006509622) and [Extra run 39006509690](https://github.com/sgl-project/sglang/actions/runs/39006509690): CUDA-decoded video tensors no longer go through CPU pinning; CuTeDSL/CUTLASS preserve Standard combine output for all-gather prefill; runtime group accessors, test fixtures, the model-default whitelist and the custom multimodal executor declaration are aligned.
- Set Muse Spark B300 speculative decoding speed to **500 token/s**; kept the **4.7** acceptance thresholds. The benchmark now flushes both PD workers directly with checked POST requests instead of ignoring mini-LB 405 responses.
- Five complete targeted unit-test files passed: **594 tests**, covering runtime context, server arguments, FlashInfer dispatch/runners, multimodal async call sites and model overrides. Added prefill/idle/decode format and workspace regression cases. Pre-commit and Python compilation passed; these local results do not imply that every GitHub CI suite has passed.
- On a 4x B200 devbox with the same Torch 2.14.1, Transformers 5.19.0 and FlashInfer 0.7.2 versions as CI, reproduced the original CuTeDSL and CUDA pin-memory errors before applying the patch. After the patch, real CPU/CUDA video preprocessing and the original Qwen2.5-VL and Qwen3-Omni video-chat tests passed.
- The original Qwen3.5-397B-A17B-NVFP4 TP4/EP4/DP4 CuTeDSL + FlashInfer server configuration booted successfully and passed six checked serial/concurrent generation requests. This is a smoke test; the full 1,319-question GSM8K suite remains for CI.
- Localized the Qwen3-Omni prefix-cache wording mismatch to Blackwell BF16 split-K numerics: six fixed-seed cold/cache comparisons failed on the default path, while six passed with only split-K disabled; the original base passed on two B200 GPUs. Moved the exact-equality case to a dedicated deterministic + Triton-attention fixture with radix caching explicitly enabled; kept the other nine modality tests on production defaults. The complete updated Qwen3-Omni file passed **10/10 tests** in 167 seconds. No output assertions were relaxed or test cases removed.
- The 8x B300 Muse Spark performance/accuracy suite was not rerun locally: no whole-node B300 capacity was available. Its latest CI attempt failed before reaching accuracy or throughput assertions. The temporary skip changes scheduling only; all test cases and thresholds remain intact.
- Preserved all user follow-up commits and all 32 original coauthor trailers. AMD and Helion changes remain in layers 4/5 and 5/5.
