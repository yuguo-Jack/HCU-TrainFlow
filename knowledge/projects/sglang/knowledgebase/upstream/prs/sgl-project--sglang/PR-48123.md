# [Feat] RL: Store output store replay fields as layer blocks at layer splits

[Upstream PR](https://github.com/sgl-project/sglang/pull/48123) · state: closed · merged: True

## Original PR description

## Summary
Store replay fields as one field per layer block, so a trainer pipeline stage reads only its layers.

## Motivation
Every pipeline stage reads whole `[rows, layers, topk]` replay rows from the output store and keeps its own layers, so a PP rank reads pp times the bytes it uses. Reading a stage's layers row by row was measured 1.7x slower than whole rows, so SGLang must split them when it writes.

With `--pp-size > 1` each SGLang stage captures only its own layers into a zeroed buffer and only the first stage's capture reaches the response, so other stages' layers come back as zeros.

## Usage
```json
{"input_ids": [1, 2, 3], "return_routed_experts": true, "return_outputs_via_store": true, "replay_layer_splits": [12, 24, 36]}
```
On a 48-layer model, `output_store_ref` lists `routed_experts.0-12` through `.36-48`, each `[tokens, 12, topk]`; without splits, one block `routed_experts.0-48`.

## Design Notes
- **Mental model:** Miles sends the layers where its PP / VPP model chunks meet as `replay_layer_splits` (radixark/miles#4643; sgl-router must forward it) → `_validate_one_request` checks them → `_store_token_outputs` hands the writer those splits, mapped to capturer slots for the indexer → `to_stash` cuts views there → `to_fields` copies each block once into field `{name}.{start}-{end}`, one Mooncake key. The scheduler, `FieldSpec`, `StoreRef`, both reads and the mask fields are unchanged.
- **Indexer slots:** DeepSeek-V4 captures a C4 layer at the KV pool's `compress_layer_id`, the count of C4 layers before it, so `indexer_slots_at` maps splits to that count (DSA: the layer id) and refuses other models.
- **Always blocks:** an unsplit field is one whole block and a bare `routed_experts` field is rejected, so this ships with the Miles side.
- **PP gate:** `check_pipeline_parallel_compat` refuses `--enable-return-routed-experts` and `--enable-return-indexer-topk`.
