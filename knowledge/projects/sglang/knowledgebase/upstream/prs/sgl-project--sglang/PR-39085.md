# [Perf] [AMD] dsa: Reuse AITER prefill metadata across layers

[Upstream PR](https://github.com/sgl-project/sglang/pull/39085) · state: open · merged: False

## Original PR description

# [AMD] Reuse AITER DSA prefill metadata across layers

**Depends on:** #39083

## Motivation

During an EXTEND forward pass, every DSA layer builds the same AITER work and
reduction metadata. The metadata depends on the sequences in the current
forward pass, not on the transformer layer. Building it again in every layer
adds unnecessary CPU and GPU work.

## Modifications

- Use the current `DSAMetadata` object to identify the forward pass.
- Build AITER metadata when the first DSA layer runs.
- Reuse that metadata in later layers of the same forward pass.
- Build new metadata when the `DSAMetadata` object changes.
- Keep the existing buffer size, dtype, and device checks.

Decode metadata is unchanged. The reused metadata belongs only to the current
forward pass.

## Accuracy Tests

Hardware: AMD MI355X.

The registered unit test checks that:

- one forward pass builds metadata once;
- a new forward pass builds new metadata.

The reused tensors also completed graph capture and two graph replays on
MI355X. The existing AITER BF16 and FP8 DSA prefill tests pass.

## Speed Tests and Profiling

  Hardware: AMD MI355X, TP4. Matched 8,192-input/600-output benchmark at concurrency 4, comparing the base PR (#39083) with this PR.
  - Mean TTFT: 2,423.85 → 1,656.93 ms (**−31.6%**)
  - Median TTFT: 2,830.50 → 2,011.13 ms (**−28.9%**)
  - Mean ITL: 12.25 → 11.99 ms (**−2.2%**)
  - Median ITL: 11.53 → 11.51 ms (**−0.2%**)
  - Output throughput: 245.66 → 271.39 tok/s (**+10.5%**)
  - Mean end-to-end latency: 9,764.49 → 8,838.01 ms (**−9.5%**)
  Both runs used the same prompts, seed, warmup, FP8 KV cache, 32,768-token prefill size, AITER prefill, and TileLang decode. The result shows that metadata reuse primarily reduces prefill latency while steady-state decode
  latency remains unchanged.

## Reproduction:
  export SGLANG_USE_AITER=1
  python3 -m sglang.launch_server \
    --model amd/GLM-5.2-MXFP4 \
    --tp 4 \
    --trust-remote-code \
    --attention-backend dsa \
    --dsa-prefill-backend aiter \
    --dsa-decode-backend tilelang \
    --kv-cache-dtype fp8_e4m3 \
    --page-size 64 \
    --chunked-prefill-size 32768 \
    --max-prefill-tokens 32768 \
    --disable-radix-cache \
    --mem-fraction-static 0.9
