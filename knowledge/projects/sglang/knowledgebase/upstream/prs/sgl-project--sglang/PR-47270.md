# [Fix] diffusion: recover LTX eager performance without disabling fusion

[Upstream PR](https://github.com/sgl-project/sglang/pull/47270) · state: closed · merged: True

## Original PR description

## Motivation

Fix LTX-2.3 eager regressions without globally removing the fused head-gate or RMSNorm/modulation kernels.

Image-conditioned stage 1 splits guidance into batch-1 forwards. Video retains per-token timesteps, but audio uses per-sample AdaLN and enters RMSNorm modulation fusion. GPU-only timings do not characterize this host-bound path.

The initial version of this PR addressed launch overhead but did not establish recovery against the original good revision. Further same-machine interleaved comparisons identified redundant AdaLN layout work and a separate Blackwell stage-2 sharding regression. Companion #47301 handles shared Blackwell attention routing; this PR alone is not the complete Blackwell fix.

## Changes

- Reuse `replay_launches` for head-gate and RMSNorm modulation, caching launch metadata rather than tensors or outputs. Keep both fused kernels.
- Move head-gate eligibility/fallback inside the cached operator instead of repeating it in the model.
- Avoid the value-major allocation for singleton AdaLN rows, which are already contiguous. Preserve per-token layout where the broadcast-only fused consumers cannot apply; retain contiguous batched broadcast rows.
- Use automatic stage-2 CFG-rank Ulysses on Hopper and on Blackwell with BCG enabled. Blackwell eager does not amortize the extra dispatch; disabling it for graph mode as well would lose an existing benefit. Preserve explicit sequence parallelism and the existing token threshold.
- Extend launch-cache, fallback, fresh-input, graph, compile, AdaLN-layout and CFG/SP topology tests. Document existing image-conditioned BCG warmup and automatic stage-2 platform selection.

No new knobs, kernel arithmetic changes, quality-tier changes, GT updates, or performance-baseline changes. Existing production-file churn: +35/-12 across four files; no new production files. Tests/docs: +174/-14.
