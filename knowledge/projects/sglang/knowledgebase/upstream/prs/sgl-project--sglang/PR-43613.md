# Add --speculative-dcp-size (default 1, > 1 rejected)

[Upstream PR](https://github.com/sgl-project/sglang/pull/43613) · state: open · merged: False

## Original PR description

## Motivation

Introduce a dedicated flag for the DCP width of the speculative draft KV cache, separate from the target's `--dcp-size`. Values other than 1 are rejected for now, but the value is threaded through the three places that currently hardcode "the draft is replicated across the target's DCP ranks", so enabling it later is a validation change rather than a plumbing one.

## Modifications

One commit per area, in dependency order:

1. **Flag**: `speculative_dcp_size` is a leaf of the `parallel` namespace next to `dcp_size` (CLI `--speculative-dcp-size`, default 1); `handle_speculative_decoding` rejects any other value. Docs row + unit test.
2. **Parallel state**: `speculative_dcp_rank` on the parallel bag (`tp_rank % speculative_dcp_size`, pinned to 0 at width 1). A draft consumer reads `get_parallel().speculative_dcp_size` / `speculative_dcp_rank` directly where it builds; the target keeps `attn_dcp_*`. No copies on the runner or the pools. The triton backend and Qwen3.5 NextN read it instead of hardcoding 1 behind `is_draft_worker` guards; this also retires the HIP-DSpark-only special case in the triton backend.
3. **Memory pool sizing**: the draft pool's loc-space scale becomes `attn_dcp_size // speculative_dcp_size` (`get_draft_loc_space_scale`); the target-side draft budgets (DFLASH cell size, NPU DSA draft) and the NPU draft page padding follow it; `get_num_kv_heads` callers pass their worker's KV DCP width and the hidden `is_draft_model` override is removed.
4. **PD disaggregation**: decode sends its draft DCP width/rank as trailing handshake frames (Mooncake `msg[20:22]`, NIXL `msg[23:25]`); prefill threads them into `prepare_dcp_token_item_lens`, `build_dcp_token_transfer_plan` and the Mooncake/Ascend draft destination widths.

Behavior is unchanged at the default. Unit tests cover the new leaves, the draft budget at `speculative_dcp_size=2`, the sharded-draft transfer plan, and the handshake frames.
