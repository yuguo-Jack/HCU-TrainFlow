# [Doc] env-vars: Correct the sliding-window attention eviction setting

[Upstream PR](https://github.com/sgl-project/sglang/pull/45976) · state: closed · merged: False

## Original PR description

`docs/docs/references/environment_variables.mdx` lists `SGLANG_SWA_EVICTION_INTERVAL_MULTIPLIER` as a float with default `1.0`:

> Multiplier applied to the sliding-window-attention eviction interval.

That variable does not exist anywhere in the repository. The setting the code actually reads is `SGLANG_SWA_EVICTION_INTERVAL`:

- `python/sglang/srt/environ.py`: `SGLANG_SWA_EVICTION_INTERVAL = EnvInt(128)`, with the comment *"Decode batches between SWA out-of-window evictions."*
- `python/sglang/srt/managers/schedule_batch.py`: `maybe_evict_swa()` reads it and passes it to `_swa_eviction_trigger()`, which gates eviction on how many tokens have slid out of the window.
- `python/sglang/srt/model_executor/pool_configurator.py` reads it twice and even names it in its error hints.

So it is a token/interval count with default `128`, not a `1.0` multiplier. This change corrects the name, the description and the default. Anyone following the page today sets a variable that has no effect.

Docs-only.
