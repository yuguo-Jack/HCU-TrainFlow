## Motivation

`Qwen3Attention `did not pass `quant_config` to `RadixAttention`, causing attention quantization configuration to be ignored for Qwen3 models.

## Modifications

Pass `quant_config `when constructing `RadixAttention `in `Qwen3Attention`.
