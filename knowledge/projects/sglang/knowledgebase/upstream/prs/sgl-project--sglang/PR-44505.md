# [Fix] function-call: preserve quoted brackets in Pythonic streaming

[Upstream PR](https://github.com/sgl-project/sglang/pull/44505) · state: open · merged: False

## Original PR description

## Motivation

Pythonic streaming drops valid calls such as `[search(query="]")]`. Non-streaming parsing handles them correctly.

## Modifications

Ignore brackets inside Python strings and comments when locating the call boundary. Add regressions for escapes, triple quotes, chunk boundaries and nested arguments.

## Accuracy Tests

21 Pythonic CPU tests pass. All 5,310 chunk-partition checks match the expected arguments and non-streaming output.

<summary>Broader checks and environment</summary>

Python 3.12.3, OpenAI 2.6.1, xgrammar 0.2.7; existing CPU test environment uses Torch 2.13.0 rather than the project's 2.14.1.
