# [Fix] sampling: Reject out-of-vocab stop_token_ids in verify()

[Upstream PR](https://github.com/sgl-project/sglang/pull/44546) · state: closed · merged: False

## Original PR description

A stop_token_ids entry outside [0, vocab_size) passed request validation and then hit a device-side assert in the min_new_tokens penalizer's scatter, crashing the server and every in-flight request. Validate it in SamplingParams.verify() alongside logit_bias so the request gets a 400.

Fixes #44535
