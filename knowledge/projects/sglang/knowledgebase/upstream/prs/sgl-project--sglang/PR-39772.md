# [Test] [NPU] return-input-ids: Add e2e test for --return-input-ids parameter

[Upstream PR](https://github.com/sgl-project/sglang/pull/39772) · state: closed · merged: True

## Original PR description

## Summary

Add an NPU end-to-end test for the `--return-input-ids` server parameter,
verifying that each `/v1/chat/completions` response returns the prompt
(input) token ids via the response-level `sglext` extension.

## Changes

- Add `test/registered/npu/basic_function/parameter/test_npu_return_input_ids.py`.
- Launch a single-NPU server with:
  `--attention-backend ascend --disable-cuda-graph --return-input-ids`
  on `LLAMA-3.2-1B-Instruct`.
- Send one chat completion request and assert:
  - `data["sglext"]["input_ids"]` exists;
  - it is a non-empty list of `int`;
  - decoding the ids round-trips back to the original user message.

## Test

- Registered via `register_npu_ci(est_time=400, suite="full-1-npu-a3", nightly=True)`.
- Ran on NPU: passed.
