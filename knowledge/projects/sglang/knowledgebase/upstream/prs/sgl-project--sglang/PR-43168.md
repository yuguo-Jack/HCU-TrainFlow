## Motivation

When an SWA window is not page-aligned, decode eviction can leave less than a full window below the page where a prefix-cache insertion ends. For a 127-token window at page size 64, the residue `pre_len = 63 mod 64` retains only 64 tokens there, so the inserted prefix cannot be reused.

## Modifications

Round `max(window, page)` up to whole pages before deriving the eviction frontier. Page-aligned windows and page size 1 keep the same frontier; an unaligned window retains at most one more SWA page per request.

The regression uses a 7-token window at page size 4. After eviction at `pre_len=23`, it directly checks that the insertion boundary at 20 still has at least 7 live SWA tokens below it, then verifies release accounting. Restoring the old rounding makes the new frontier assertion fail (4 < 7).
