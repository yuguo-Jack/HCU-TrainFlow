# [Doc] cookbook: add Ling-3.1-flash

[Upstream PR](https://github.com/sgl-project/sglang/pull/44301) · state: closed · merged: True

## Original PR description

## Summary

Adds the **Ling-3.1-flash** cookbook page (`docs/cookbook/autoregressive/InclusionAI/Ling-3.1-flash.mdx` + config/benchmark snippets + navigation), modeled on the Ling-3.0-flash page and written with the `cookbook-add-model` skill.

## What's in the page

- **Deployment cells** (verified badges): H200 TP8+EP8 + NEXTN and GB300 TP4+EP4 + NEXTN, both on `lmsysorg/sglang:dev-ling-3.1-flash`
- **Playground**: speculative options (NEXTN enabled; DSpark disabled — no compatible draft), HiCache/Mooncake L3 preset, MoE/attention/PD axes with model-specific disabled reasons
- **Advanced usage**: reasoning on/off, tool-calling round trip, HiCache with Mooncake — all with verbatim request/response captures from the current checkpoint
- **Benchmark widget**: measured speed entries (H200 bs=1 251.2 tok/s, TPOT 3.63 ms; conc 32 1640.8 tok/s/GPU) and matched accuracy controls (NEXTN 96.89% vs standard 96.97% GSM8K, stop 99.85% vs 99.77%); GB300 bs=1 180.0 tok/s
- **Acceptance-length table** in the 3.0 page's style (2.61 random / 2.43 full GSM8K / 2.13 real text)

## Verification

- `node docs/scripts/check_cookbook_configs.mjs`, pre-commit, `mint validate`, `mint broken-links`, Playwright browser smoke — all pass
- Two review rounds against `cookbook-review-pr` and `cookbook-add-model` skills; all findings addressed
- Every number on the page was measured on the current checkpoint and the `dev-ling-3.1-flash` image (day-0 code PR: branch `bailing-v3-day0`)

## Notes

- The image tag is an alias of the cu13 variant; both resolve to the same multi-arch manifest.
- Mooncake service commands and the flush_cache idle caveat come from a real L3 run (prefetch verified on all 8 TP ranks).
