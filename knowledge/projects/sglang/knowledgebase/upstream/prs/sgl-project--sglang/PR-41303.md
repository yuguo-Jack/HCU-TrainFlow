# [Fix] deepseek-v4.1: Keep the full SWA window for short bounded-replay extends

[Upstream PR](https://github.com/sgl-project/sglang/pull/41303) · state: closed · merged: True

## Original PR description

## Motivation

With DeepSeek-V4.1's `--enable-decoder-swa-bounded-replay`, the layers after the last kv_source layer attend over only the last `min(window, extend_len)` rows of each prefill extend. An extend shorter than the window therefore gives the prompt's first sampled token a truncated window.

This happens on a prefix-cache hit that leaves fewer than `window` uncached rows, and on a chunked prefill whose final chunk is shorter than `window`.

## Modifications

- A prefix-cache hit now stops at least one sliding window short of the prompt when decoder bounded replay is on. Only a hit that would have left less than a window is shortened, by at most one page. `swa_reprefill_tail_tokens()` returns `sliding_window_size` when the new `CacheInitParams.decoder_swa_bounded_replay` is set.
- The late-layer window of a final prefill chunk shorter than the window is now floored at `seq_len - window` instead of at the chunk start, so the chunk reads the previous chunk's tail rows, which already hold their late-layer KV. This is a two line change in `late_layer_tail_layout`.
- A streaming session turn that borrows its slot's record skips the hold-back: the record is the request's own KV, whose last window is already written. `swa_reprefill_tail_tokens(req)` takes the request for this.
- A prefix hit now runs the same rows with the same window floors as a cold prefill. A short final chunk does not: its tail reads the previous chunk's tail rows, which were computed under that chunk's floor. The short-chunk table below measures the difference.

## Accuracy Tests

## Speed Tests and Profiling

The prefix-match limit only applies when a hit would leave fewer than `window` uncached rows, and then recomputes at most one page. The floor change costs each token of a short final chunk at most a full window of 128 keys to score.
