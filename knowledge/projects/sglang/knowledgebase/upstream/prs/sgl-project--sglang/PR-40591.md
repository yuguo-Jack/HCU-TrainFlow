# Implemented MXFP8 quant lightning indexer for DSA

[Upstream PR](https://github.com/sgl-project/sglang/pull/40591) · state: open · merged: False

## Original PR description

Replaced torch_npu.npu_quant_lightning_indexer() kernel with torch.ops.cann_ops_transformer.quant_lightning_indexer (version 2 kernel) preceded by torch.ops.cann_ops_transformer.quant_lightning_indexer_metadata()

## Motivation

Using of quantized lightning indexer achieves lower inference time. Before the modifications, the existing code was designed for token-wise quantization. Microscaling (MX) format achieves lower metric drop. The new pipeline consists of calling two kernels: torch.ops.cann_ops_transformer.quant_lightning_indexer_metadata(), which takes the generic information about the kernel inputs to compute the optimal load balance, and then torch.ops.cann_ops_transformer.quant_lightning_indexer() for the actual computation of LI. The first part is shared by all hidden layers and should be called once per step.

## Modifications

ascend_backend.py - computed and stored metadata
memory_pool_npu.py - changed the format of scales to comply with MX format
dsa_npu_indexer.py - contains the core business logic of the new functionality
mla.py - reusing new scales format in the attention block
