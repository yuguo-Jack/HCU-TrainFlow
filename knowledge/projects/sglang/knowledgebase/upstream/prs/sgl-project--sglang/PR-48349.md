# Enable Hy3-FP8 on xpu

[Upstream PR](https://github.com/sgl-project/sglang/pull/48349) · state: open · merged: False

## Original PR description

The bf16 x bf16 -> fp32 torch.mm path was gated on is_cuda, so on XPU the fp32 lm_head cast the whole weight to fp32 on every step. torch-xpu supports mm with out_dtype, so allow XPU too.

Hy3-FP8 (vocab 120832, hidden 4096) on 1x B60: lm_head 14.7 -> 2.2 ms per decode step; greedy output unchanged.
