# [Refactor] bcg: Record graph breaks at capture without running them

[Upstream PR](https://github.com/sgl-project/sglang/pull/46719) · state: closed · merged: True

## Original PR description

Needs #46718, now merged.

- While a breakable CUDA graph captures, `eager_on_graph` now ends the segment, runs the barrier and the break's `capture_stub` if it has one, records the call, and starts the next segment. The break body no longer runs at capture: its inputs come from segments that have not run yet, so running it there only wrote values nothing reads, and ran collectives and host syncs on them.
- Every break already writes into buffers or holders its caller prepares and returns `None`. The wrapper now asserts `None` at replay and in eager runs, and `_copy_output`, which copied each replay's fresh return value into the output captured at capture time, is removed.
- `capture_stub` stays for host setup that a later captured segment reads: the DeepSeek V4 late-layer tail enter and exit, the tail source KV layer id (#46718), and the Nemotron-H shared-expert side graph. Stubs that only fill outputs no longer do anything useful and are left for a follow-up cleanup.
- The diffusion BCG warmup now runs with the BCG flag on, so it takes the branches the capture records and allocates what the capture expects instead of relying on the capture pass to run each break once.
- The DeepSeek V4 tail enter and exit breaks no longer take a sentinel tensor: they returned it only to keep the break in the replay sequence, and a break now returns `None`.
- Tests: the break tests use caller buffers, and `test_eager_on_graph.py` checks that the capture pass records breaks without running them and that a break returning a value fails (the XPU and multimodal break tests follow the same shape).
- GPU runs at this head on B300 and GB300 pass: `test_breakable_cuda_graph.py`, `test_bcg_with_lora.py`, `test_bcg_with_speculative_decoding.py`, `test_dp_attention_bcg_kl.py`, `test_lora_moe_prefill_cuda_graph.py`, `test_mamba_cache_kl.py`, `test_decoder_tail_moe_bound.py`, `test_deepseek_dual_stream_outputs.py`, the dense, MLA, GDN, SWA and DeepSeek V4 attention unit tests, the DeepSeek V4 Flash FP4 tests, the DeepSeek V4.1 Flash bounded-tail and encoder BCG tests, the Z-Image Turbo BCG tests (single GPU and TP 2), and the multimodal unit tests. `test_paged_experts.py` (GPTQ class), `test_glm53_cp_bcg_dflash.py` (KV transfer) and two `test_nomas.py` cases fail the same way on main.
