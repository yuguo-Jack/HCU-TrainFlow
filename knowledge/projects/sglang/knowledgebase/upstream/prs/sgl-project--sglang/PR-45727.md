## Motivation

Split PR of https://github.com/sgl-project/sglang/pull/32314

HiSparse’s MLA swap kernels assume request-private Host storage and a hot buffer. Supporting shared HiCache storage requires direct access to resident Device KV and Host rows with a different memory layout. This PR adds the kernel support needed by HiSparse V2.

## Modifications

- Add optional device_locs to read resident KV directly without copying it into the hot buffer.
- Add optional host_binding with a runtime Host address and row stride, supporting HiCache layouts and binding after CUDA graph capture.
- Extend speculative MLA swap to reuse hot/scratch state across single-step and multi-step calls, with a fixed workspace layout and preserved miss deduplication.
- Preserve existing callers through optional arguments and add tests for resident reads, mixed sources, Host binding, byte-exact copies, deduplication, overflow, and CUDA graph replay.
