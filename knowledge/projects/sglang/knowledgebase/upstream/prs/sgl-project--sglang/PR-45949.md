# [Perf] [NPU] AscendAttnBackend: D2H-free block-table gather for mirrorless DSA graph replay

[Upstream PR](https://github.com/sgl-project/sglang/pull/45949) · state: closed · merged: True

## Original PR description

## Motivation

Enable mirrorless speculative decoding for GLM-5.x/DSA on Ascend with `SGLANG_NPU_ATTN_BACKEND_NEEDS_CPU_SEQ_LENS=0`, building on #38461.

Graph metadata preparation currently relies on the CPU sequence-length mirror or gathers the full captured block-table width. Carrying a host-side upper bound derived from KV allocation lengths allows replay to limit the gather range without reading sequence lengths back from the device.

## Modifications

- Publish `max_seq_len_host` from the maximum page-aligned KV allocation length when the CPU sequence-length mirror is absent.
- Propagate this bound through `ForwardBatch`, decode graph replay, draft-extend replay, and multi-step draft views.
- Use the host bound to size block-table gathers, including speculative offsets, and clear unused table columns. Preserve the full-width fallback when neither a CPU mirror nor a host bound is available.
- Guard eager CPU length updates against an absent mirror and pass device lengths to `_npu_paged_attention` for mirrorless eager decode.
- Keep the CPU mirror enabled with a warning for hybrid SWA and `ASCEND_USE_FIA`, whose attention paths require host-side lengths.
