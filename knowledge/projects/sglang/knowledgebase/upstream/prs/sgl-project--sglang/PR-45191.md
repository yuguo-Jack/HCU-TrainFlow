# [Fix] rust-server: Support slash-containing model IDs in model retrieval

[Upstream PR](https://github.com/sgl-project/sglang/pull/45191) · state: open · merged: False

## Original PR description

## Motivation

The Rust frontend's model retrieval route matches only a single path segment. Requests such as `/v1/models/Qwen/Qwen3-0.6B` therefore return 404 even when the served model ID exactly matches `Qwen/Qwen3-0.6B`.

The Python frontend already supports model IDs containing slashes through its [`/v1/models/{model:path}` ](https://github.com/sgl-project/sglang/blob/ed0b8f433f/python/sglang/srt/entrypoints/http_server.py#L1961) route.

## Modifications

Change the Axum route from `/v1/models/{model}` to `/v1/models/{*model}` to capture the full model ID.

## Accuracy Tests

Not applicable: this change only affects HTTP routing.

## Speed Tests and Profiling

Not applicable.

## Validation

Started the Rust frontend with `--served-model-name Qwen/Qwen3-0.6B`. The model ID was confirmed through `/v1/models`.
```
SGLANG_RUST_SERVER=1 \
python -m sglang.launch_server \
  --model-path /workplace/model/Qwen3-0.6B \
  --served-model-name Qwen/Qwen3-0.6B \
  --host 127.0.0.1 \
  --port 30002 
```


### Before

The model is listed by `/v1/models`:

```bash
curl -s http://127.0.0.1:30002/v1/models
```

```json
{"object":"list","data":[{"id":"Qwen/Qwen3-0.6B","object":"model","created":1792410590,"owned_by":"sglang","root":"Qwen/Qwen3-0.6B","parent":null,"max_model_len":4096}]}
```

Retrieving that same model returns an empty 404 response:

```bash
curl -i http://127.0.0.1:30002/v1/models/Qwen/Qwen3-0.6B
```

```http
HTTP/1.1 404 Not Found
content-length: 0
```

### After

Retrieving the model succeeds:

```bash
curl -i http://127.0.0.1:30002/v1/models/Qwen/Qwen3-0.6B
```

```http
HTTP/1.1 200 OK
content-type: application/json
content-length: 142

{"id":"Qwen/Qwen3-0.6B","object":"model","created":1792411600,"owned_by":"sglang","root":"Qwen/Qwen3-0.6B","parent":null,"max_model_len":4096}
```

An unknown model ID containing a slash reaches the model lookup handler and returns a JSON error:

```bash
curl -s http://127.0.0.1:30002/v1/models/Qwen/missing
```

```json
{"error":{"object":"error","message":"The model `Qwen/missing` does not exist","type":"BadRequestError","param":null,"code":404}}
```
