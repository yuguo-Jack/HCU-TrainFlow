# [CI] [MLU] slash-command: Register MLU with shared opt-in CI tiers

[Upstream PR](https://github.com/sgl-project/sglang/pull/45385) · state: closed · merged: True

## Original PR description

## Motivation

MLU CI is not registered with the shared slash-command interface introduced in #45735. Register it so contributors can label and rerun MLU CI through the existing commands and permissions.

## Modifications

- Add `mlu` to the opt-in tier registry, mapping `run-ci-mlu` to `pr-test-mlu.yml`.
- Enable `/tag-run-ci-label mlu` to add both required labels, `/tag-and-rerun-ci mlu` to label and retry unsuccessful workflows through the existing broad retry path, and `/run-ci mlu` or `/run-mlu-ci` to rerun MLU only, including successful runs.
- Scope `pull_request_target` rerun selection to the PR source repository and branch in addition to its head SHA.
- Use the shared live-label gate for MLU, removing the separate opt-in precheck and `labeled` trigger. Runs blocked by missing labels can be retried after labeling.
- Update the contribution guide, workflow README, and CI workflow skill with the MLU registration and rerun behavior.

## Validation

- Pre-commit and opt-in tier/workflow consistency checks passed.
- Mintlify broken-link check passed.
