# [VLM][MM refactor 3/6] Extract a shared media processor mixin

[Upstream PR](https://github.com/sgl-project/sglang/pull/43422) · state: open · merged: False

## Original PR description

## Motivation

Media loading and its executors live in `BaseMultimodalProcessor` next to serving-only state (preprocess cache, hash executor, feature transport), so a trainer cannot reuse them.

## Modifications

- Add `MultimodalProcessorMixin` (`multimodal/media_processor.py`) with media loading, the executors and their shutdown, initialized from a `MultimodalProcessorConfig`.
- `BaseMultimodalProcessor` inherits it and keeps only its serving state.
- Extract `_bind_and_finalize_mm_items` and `_move_processor_output_to_cpu` for reuse in later PRs.

No behavior change; most of the diff is moved code. `refactor(move)` commits have reproducible proofs. `move decorated loader helpers` is a hand cut/paste (the proof tool drops decorators); only the owner of two helpers changes.

## Tests

- Existing tests pass on every commit, except two image-decode tests in the move commit that still patch `load_image` at its old path; the next commit fixes them.
