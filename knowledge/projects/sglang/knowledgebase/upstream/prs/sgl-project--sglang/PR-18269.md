## Motivation

<!-- Describe the purpose and goals of this pull request. -->

**1. Fix Janus-Pro crash (regression from #18503)**, [2/9 nightly](https://github.com/sgl-project/sglang/actions/runs/21846207833/job/63042557081#step:5:3020): ERROR: test_mmmu_vlm_models (__main__.TestNightlyVLMMmmuEvalAMD) (model='deepseek-ai/Janus-Pro-7B')

- `LogitsProcessor(config)` → `LogitsProcessor(language_config)` in `deepseek_janus_pro.py`
- `MultiModalityConfig` lacks `vocab_size`; the nested `language_config` (LlamaConfig) has it
- Broke after #18503 added `self.vocab_size = config.vocab_size` at init time

**2. Add Kimi K2.5 nightly tests for MI30x and MI35x**
- New test files: `test_kimi_k25_eval_amd.py` (MI30x) and `test_kimi_k25_eval_mi35x.py` (MI35x)
- Total add 2 tests in [coverage summary](https://github.com/sgl-project/sglang/actions/runs/21742147499?pr=18269).
- K2.5 model covers K2 (same arch) and 2x speed up CI run compared to K2 ([K2.5 16min in mi35x](https://github.com/sgl-project/sglang/actions/runs/21694063561/job/62560377721)).

Nightly pass: https://github.com/sgl-project/sglang/actions/runs/21694063561
