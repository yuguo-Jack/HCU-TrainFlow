# [Feat] minimax-m3.1: Support DSpark on Hopper

[Upstream PR](https://github.com/sgl-project/sglang/pull/46868) · state: closed · merged: True

## Original PR description

## Motivation

MiniMax-M3.1-Flash rejects `--speculative-algorithm DSPARK` off Blackwell. This enables it on Hopper: **2.3x** output throughput at concurrency 1 on 8x H200 with unchanged GSM8K accuracy. DFLASH still requires Blackwell.

## Modifications

- Off Blackwell, the draft model loads its MXFP8 projections as block-FP8 (`minimax_m3_nvfp4`), the same way the target does, and uses `fa3` for draft attention.
- `speculative_draft_model_quantization` becomes model-overridable.
- The sparse attention backend runs TARGET_VERIFY as per-draft-row decode queries whenever the MSA decode plan is not in use. This path was previously HIP-only.

## Benchmark

8x H200, GSM8K via sgl-eval (`--temperature 1.0 --top-p 0.95 --max-tokens 8192`).

```bash
python -m sglang.launch_server --model-path MiniMaxAI/MiniMax-M3.1-Flash --trust-remote-code \
  --reasoning-parser minimax-m3 --tool-call-parser minimax-m3 --tp 8 --context-length 140000 \
  --cuda-graph-backend-prefill breakable --mem-fraction-static 0.85 --cuda-graph-max-bs-decode 64 \
  --speculative-algorithm DSPARK [--speculative-use-block-verification]
```

| | concurrency 1 (50 examples) output tok/s | accept length | concurrency 64 (1319 examples) output tok/s | accept length |
|---|---|---|---|---|
| no speculative | 200.4 | - | - | - |
| DSPARK | **459.4** | 4.37 | 3688.5 | 3.57 |
| DSPARK + block verification | 389.0 | 4.25 | **4035.5** | 3.87 |

## Accuracy

GSM8K, 1319 examples, concurrency 64:

```
no speculative:               0.959
DSPARK:                       0.9575
DSPARK + block verification:  0.9575
```
