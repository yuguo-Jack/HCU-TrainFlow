# [Perf] diffusion/helios: Keep timestep conditioning compact

[Upstream PR](https://github.com/sgl-project/sglang/pull/48281) · state: open · merged: False

## Original PR description

## Motivation

Helios repeats one history timestep and one current timestep across thousands of tokens before every block adds its conditioning table. Keeping those rows compact removes the large repeated addition while preserving the existing norm, residual-gate and exact fallback arithmetic.

Related work: [vLLM-Omni #7736](https://github.com/vllm-project/vllm-omni/pull/7736) also proposes compact conditioning, using indexed modulation kernels. This change reuses SGLang's existing norm and residual kernels with separate history/current spans. That open Omni PR is source context, not the measured native Omni baseline.

## Modifications

- Keep one conditioning row per timestep and pass the history/current token-span lengths into the block.
- Apply the existing `LayerNormScaleShift` and quality-gated residual operator to each span, then concatenate their results.
- Preserve direct 3D/full-token 4D block calls, empty-history behavior and the original FFN FP32 fallback cast. No new kernel, precision policy or flag.
