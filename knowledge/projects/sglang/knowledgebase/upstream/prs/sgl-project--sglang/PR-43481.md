- kevin-mii · comment · 2026-10-16T08:37:16Z · [source](https://github.com/sgl-project/sglang/pull/43481#issuecomment-6211541965)

Thanks! The monokernel framework has landed in SGLang (#44353): `--monokernel-backend amd` loads per-model specs from sgl-project/sgl-amd-mono, so the Kimi K3 monokernel should move there rather than into `kernels/ops/moe` and `srt/models/kimi_k3.py`. sgl-project/sgl-amd-mono#6 (GLM-5.3-Flash) is the template: kernels under `sgl_amd_mono/kimi_k3/gfx950/`, a `spec.py` with the forward and its requirements, registration in `sgl_amd_mono/__init__.py`, and unit, kernel and e2e tests with on/off accuracy and speed.

- #43516 and #43558 (Qwen3.8) are stacked on this PR's kernels, so the shared FlyDSL kernels should land once in the plugin, in a module all three specs import.
- The description is still the empty template. A short summary with accuracy and speed results would help review on the plugin side.
