# [Feat] [NPU] quantization: Add MXFP capability preflight

[Upstream PR](https://github.com/sgl-project/sglang/pull/44366) · state: open · merged: False

## Original PR description

## Motivation

Ascend MXFP support and checkpoint restrictions are spread across selectors, loaders, and execution methods. Invalid configurations can fail during reshape or operator execution. Add one local inventory that documents existing paths and validates known contracts before those operations.

**Depends on #44365.** This draft targets main and includes that prerequisite commit. The capability-only increment is [available here](https://github.com/TallMessiWu/sglang/compare/junlin/pr-diffusion-mxfp8-shared-execution...junlin/pr-ascend-mxfp-capabilities). Merge #44365 first, then synchronize this PR with main.

## Modifications

- Describe 17 existing SRT/Diffusion Dense/MoE online/ModelSlim combinations, reusing `KernelSpec` metadata without adding a global registry, provider selection, or SoC branches.
- Validate known local-K, checkpoint dtype/shape, scale count, operator/enum, MoE runner, activation, and clamp contracts at selection, allocation, post-load, or runner creation.
- Preserve existing full-precision fallback decisions and explicitly reject the already-broken Diffusion dual-scale constructor path.
- Align Diffusion offline MXFP8 validation with #44365: accept partial scale blocks that its adapter pads, while retaining K=64 restrictions in other single-level ModelSlim loaders.
- Generate the support table from the same inventory, add documentation navigation, and cover the selectors and preparation paths with CPU regressions.

## Accuracy Tests

- 15 capability tests and 3 Diffusion adapter tests passed in an isolated CPU harness using production target modules with serving/hardware dependencies isolated and NPU operations mocked. The additional regression exercises Diffusion selection, allocation, raw-scale validation, and shared post-load for K=32/64/96/4304.
- Ruff, isort, codespell, syntax/JSON, CI registration, and diff checks passed. Full serving-package collection was not completed locally because dependencies are incomplete. Mintlify validation was not run because `mint` is unavailable.
- Earlier testing on the original capability branch (`junlin/ascend-mxfp-capabilities`, recorded implementation `d6a46f90d9`) was reported to generate a normal Wan2.2 I2V-A14B offline ModelSlim MXFP8 video. The deployed SHA and complete logs were not independently verified. This new combined PR head has not been rerun on NPU; that report does not validate all 17 combinations, numerical equivalence, or TP/EP/backend coverage.

Not run; no performance claim.
