# [CI] dco: Require sign-off on pull request commits

[Upstream PR](https://github.com/sgl-project/sglang/pull/48199) · state: closed · merged: False

## Original PR description

## Motivation

Add a DCO check so PRs report missing or malformed `Signed-off-by` trailers on every non-merge commit. The workflow follows [CubeSandbox's DCO workflow](https://github.com/TencentCloud/CubeSandbox/blob/master/.github/workflows/dco-check.yml).

## Modifications

- Run the check on PR open, synchronization, reopening, and edits, with read-only repository permissions and cancellation of superseded runs.
- Check only commits introduced by the PR, skip merge commits, and parse Git trailers. Fail if the commit range cannot be resolved, and print sign-off repair instructions when needed.
- Add a PR checklist reminder and document sign-off commands and maintainer setup. Bot-authored non-merge commits follow the same rule; the check validates trailer format, not signer identity.

Maintainers must add `Developer Certificate of Origin` as a required status check after the workflow has run to make it a merge requirement.

## Validation

- Passed `actionlint .github/workflows/dco-check.yml` and `git diff --check origin/main...HEAD` after rebasing onto current `main`.
- Passed 17 local real-Git fixture scenarios covering valid, missing, malformed, and body-only sign-offs; unsigned earlier commits; merge histories; and missing base/head objects.
- Ran the workflow's check script against this PR's signed commit successfully.
