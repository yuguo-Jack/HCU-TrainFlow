## Motivation

Unified pool construction and byte-layout definitions share one large module, making the layout contracts harder to inspect and reuse.

## Changes

Move common layout helpers and the MHA, MLA and recurrent-state specifications into the KV layout package. Update production and test imports while preserving the layout implementations.

## Validation

All **four relocation proofs passed**. At `1c5acd1f3a`, the selected 20-file check had **19 baseline-equivalent results plus the new golden passing**. Later CPU checks matched **418 layout values across 28 configurations**.

Baseline-equivalent results include existing failures; this was not an all-green GPU suite.
