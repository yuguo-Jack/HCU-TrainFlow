# [Fix] Require admin API key for flush_cache and LoRA endpoints

[Upstream PR](https://github.com/sgl-project/sglang/pull/44295) · state: open · merged: False

## Original PR description

## Summary

Following #44242 and #44270, add the `admin_api_key` check to 4 more state-mutating endpoints:

- `/flush_cache` — clears the radix KV cache
- `/load_lora_adapter` — loads a LoRA adapter without server restart
- `/load_lora_adapter_from_tensors` — loads LoRA from tensors
- `/unload_lora_adapter` — unloads a LoRA adapter

When the server is started without `--admin-api-key`, these return 400 instead of allowing access with just `--api-key`.

Signed-off-by: bantianyue <bantianyue@gmail.com>
