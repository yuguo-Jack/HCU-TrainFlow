# [rust-processor] share model file resolution logic

[Upstream PR](https://github.com/sgl-project/sglang/pull/41960) · state: open · merged: False

## Original PR description

Use `sglang-processor` for the Rust server's model file lookup and for Hugging Face cache selection in both processor lookups and renderer downloads. Remove the server's duplicate resolver and direct `hf-hub` dependency, and the renderer's duplicate cache helper.

The shared resolver also lets the server find cached files at a pinned commit SHA without a matching `refs` entry. Cache selection preserves `HF_HUB_CACHE` over `HUGGINGFACE_HUB_CACHE`, then `Cache::from_env()`.

## Validation

- `cargo test -p sglang-renderer launcher --locked --offline` passes all 5 tests.
- `cargo fmt --all -- --check` and `git diff --check` pass.
- A temporary differential harness matches both previous cache selectors across 7 configurations, including override precedence, fallback, empty values, and a non-Unicode override.
