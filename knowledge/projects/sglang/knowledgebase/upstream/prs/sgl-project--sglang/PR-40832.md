# [Test] [CPU] UT: Fix the mapping between the TP and the given NUMA nodes.

[Upstream PR](https://github.com/sgl-project/sglang/pull/40832) · state: open · merged: False

## Original PR description


## Motivation

The TP cases in SGLang UT needs to remove the hard-coded code to accommodate SPR.

## Modifications

- Added adaptive allocation logic for TPs (Tensor Parallelism) to specific NUMA node CPUs; regardless of TP settings, execution is confined to the CPUs of the given NUMA nodes.
- Bypassed automatic threshold setting to prevent small models from crashing due to memory exhaustion on a single physical node.

## Accuracy Tests

- When started as a single process, the workload runs on the given NUMA nodes if TP > 1.
