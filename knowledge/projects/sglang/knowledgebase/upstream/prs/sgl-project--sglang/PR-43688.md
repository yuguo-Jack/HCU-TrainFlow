# [Fix] Adapt to transformers 5.18 / 5.19 changes

[Upstream PR](https://github.com/sgl-project/sglang/pull/43688) · state: closed · merged: True

## Original PR description

## Summary

Keep up with transformers: adapt to the 5.18 / 5.19 changes on top of the 5.19 pin.

- DeepSeek GGUF tokenizer: build the BPE with `tokenizers` directly. The converter it used moved, and the new one shifts special-token ids.
- Drop the nested `rope_parameters` validation backport, now upstream.
- Accept `indexed_attention` (the renamed DSA layer type) in HY-V4 / Qwen4-Exp.
- Drop the removed `_commit_hash` read and the NPU MiniMax-M3 `do_convert_rgb` arg.
- Correct stale comments: the Dinov2 layout change in Hunyuan3D landed in 5.18, not 5.19, and Granite's layer types are rewritten during config init.
- Fix a stale GLM-5.3-Flash cookbook note.

## Verification

B300 with cookbook flags, 5.18/5.19 vs 5.17. GSM8K (chat, 1319q):

| Model | New | 5.17 |
|---|---|---|
| Qwen3.8-Flash-Next | 97.95 | 97.95 |
| Hy4-preview-FP8 | 96.58 | 96.73 |
| MiniMax-M2 | 95.89 | 96.04 |
| GLM-5.3-Flash (image/video also OK) | 97.34 | 97.11 |

DeepSeek-V4-Flash MXFP4 GGUF via `expert_pack`: tokenizer files byte-identical to before, outputs identical. 5.19 vs 5.18: config, tokenizer and image/video processor outputs identical across 51 checkpoints; Gemma 4 single/multi-video and Qwen-Image outputs identical; Transformers backend GSM8K unchanged.
