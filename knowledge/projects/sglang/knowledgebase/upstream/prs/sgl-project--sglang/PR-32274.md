## Motivation

<!-- Describe the purpose and goals of this pull request. -->

1. Inbound HTTP trace context was not attached as the parent of the gateway request span.
2. `/health` requests were adding low-value noise to OpenTelemetry traces.

## Modifications

<!-- Detail the changes made in this pull request. -->

1. Extract W3C trace context from incoming request headers and set it as the request span parent
2. Skip span creation for `/health` by returning Span::none().
