# [Fix] dsv41: Revert MegaGate routing in prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/46242) · state: closed · merged: True

## Original PR description

Reverts #46232.

With `SGLANG_OPT_DEEPGEMM_MEGA_GATE=1`, #46232 let MegaGate run on extend batches again, including inside breakable prefill CUDA graphs. That brings back the prefill capture failure #45969 fixed: on GB300 (DeepSeek-V4.1-Flash, DP attention 4 with MegaMoE, prefill graphs at 4096 and 8192 rows), the second shape's capture fails with `CUDA error: unspecified launch failure` on the non-zero DP ranks, so the server does not start. It reproduces with `sgl-deep-gemm` 0.2.3.post2.

This restores the decode / target-verify gate and its 2048-row cap exactly as before #46232. Prefill MegaGate can return once the capture failure is understood.

## Verification

- `mega_gate.py` and `test_mega_moe_deepgemm_api.py` are byte-identical to the parent of #46232; the MegaGate admission tests pass.
