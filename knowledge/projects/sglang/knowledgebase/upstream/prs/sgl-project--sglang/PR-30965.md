## Motivation

<!-- Describe the purpose and goals of this pull request. -->
there is acc issue in qwen3.5 shared expert dual stream, due to apply same shared expert stream for mtp and target model, which could lead to  data corruption.
## Modifications

<!-- Detail the changes made in this pull request. -->
following deepseek model, use different stream for mtp and target model when enable dual stream.
