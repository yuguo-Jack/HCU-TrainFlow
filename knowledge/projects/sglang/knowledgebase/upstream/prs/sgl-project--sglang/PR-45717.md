# [Feat] [Intel] CPU-core-binding: Support Compute Building Block for next Gen Xeon

[Upstream PR](https://github.com/sgl-project/sglang/pull/45717) · state: open · merged: False

## Original PR description

## Motivation

To support CPU core management in CBB mode for next Gen Xeon. This is a re-submit of #36850 , accommodates the recent changes in #40066 .

## Modifications

Expand core topology query function parse_lscpu_topology to query both NUMA and CBB (via L3 cache affinity). Then auto detect the core management mode base on the parsing results. Other utilization methods are updated accordingly.

## Tests

Core binding functionality is validated on a next (7th) Gen Xeon.
