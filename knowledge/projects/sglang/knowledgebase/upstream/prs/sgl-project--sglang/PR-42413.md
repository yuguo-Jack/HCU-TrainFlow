# [PDMux] Align GLM DP and EP execution across PDMux streams

[Upstream PR](https://github.com/sgl-project/sglang/pull/42413) · state: closed · merged: False

## Original PR description

## Motivation

Uneven attention-DP ranks must use the same prefill intervals, stream selection and communication geometry. Interleaved decode replaces the global DP context needed when prefill resumes. This PR aligns active and IDLE participants so each layer slice uses the correct DP/EP layout.

## Changes

- Keep raw scheduler token counts separate from speculative scaling and gather padding; make split decisions and stream selection consistent across ranks.
- Use matching prefill TP groups and restore the active batch's DP-buffer metadata for MoE dispatch.
- Skip attention planning on IDLE ranks and retain real token counts; use SUM_LEN for GLM PDMux when supported by the communication backend.
- Prepare inputs and restore padded structures on each split-prefill slice, including intermediate slices that return no logits.
