…k_softmax

Add aiter_fused_softmax_topk_with_shared_gate, which folds the shared-expert sigmoid gate GEMV and shared-id append into aiter's routed softmax top-k kernel, and route Qwen2/3.5 MoE through it (replacing routed-topk + the separate fused-append pass) when shared-expert fusion + aiter are enabled. Adds a CPU unit test pinning the wrapper's buffer/argument contract with the kernel.
