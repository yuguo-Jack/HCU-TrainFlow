# [Feat] model-loader: make the unbalanced load barrier timeout configurable

[Upstream PR](https://github.com/sgl-project/sglang/pull/45184) · state: open · merged: False

## Original PR description

## Motivation

At the end of the weight load, the ranks wait for each other in a barrier with a fixed 480 s timeout (`UNBALANCED_MODEL_LOADING_TIMEOUT_S`). With KTransformers the ranks load very different amounts: rank 0 also builds the CPU experts. For DeepSeek-V4.1-Flash-1017 on 2x RTX 5070 Ti, rank 0's extra work takes well over 480 s when the checkpoint is read from disk. The other rank's barrier then times out and a TP2 launch fails. Our launches set 1800 s.

## Modifications

- `python/sglang/srt/environ.py`: `SGLANG_UNBALANCED_LOAD_TIMEOUT_S = EnvInt(480)`.
- `load_model_utils.py`: the barrier timeout reads it. The default is 480 s, as before.
