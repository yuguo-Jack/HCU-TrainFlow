## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111, #45311) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Adds the section to the GLM-5.3 page**, with the GLM-5.3 NVFP4 B300 SGLang MTP lane of [InferenceX #3930](https://github.com/SemiAnalysisAI/InferenceX/pull/3930) (verified by its `/use` run). Like the other pages, its Deployment panel gets the opt-in footer link to the section. The panel's content and the Playground are unchanged.
2. **Overlays eight open InferenceX PRs** (table below): per-concurrency retunes of all four Muse Spark Open SGLang lanes, a new Muse Spark Open GB300 Dynamo+SGLang lane, DeepSeek-V4 B300 Dynamo+SGLang with Mooncake EFA KV transfer, GLM-5.3 B300, and the Qwen3.5 NVFP4 GB300 Dynamo+SGLang refresh.
3. **Syncs to InferenceX `main`** (`6046414d`). No mirrored lane on `main` changed since #45311.

**DeepSeek-V4**
- **NVFP4 B300 Dynamo+SGLang ([InferenceX #4346](https://github.com/SemiAnalysisAI/InferenceX/pull/4346), in progress).** Same deployment shapes as before (agg TP8/TP4/DEP8, disagg 1P1D/1P2D DEP8). The image moves from `nightly-dev-20260916-c9a8fba9` to `nightly-dev-efa-20261019-3c560089`. KV transfer moves from NIXL (LIBFABRIC) to Mooncake over EFA (`--disaggregation-transfer-backend mooncake`, `MOONCAKE_PROTOCOL=efa`). DP attention is spelled `--attn-dp-size 8`, and MTP is not used.
- **Derived HiCache rows of the B300 single-node lanes.** Lanes still in progress never donate KV settings, so the derived HiCache tier of `dsv4-fp4-b300-sglang-agentic-hicache-eagle` / `-hicache-mtp` points measured without offload now takes its flags from the measured B300 HiCache-MTP worker (`--hicache-ratio 3`, `--hicache-write-policy write_back`), not from #3817's Dynamo worker.

**`SGLANG_ENABLE_UNIFIED_RADIX_TREE` is mirrored again.** #45090 removed this variable from SGLang and also deleted it from the generated DeepSeek-V4 and GLM-5.2 AgentX data. These files mirror the launches as submitted, and the variable is part of the submitted launches. It is not a no-op in every image that ran:
- In `v0.5.17-cu130` / `v0.5.18-cu130` (GLM-5.2 GB200 Dynamo+SGLang agg and disagg) it is a live switch (`EnvBool(False)`) that selects the unified radix cache, so dropping it would not run what SemiAnalysis measured.
- In the 2026-09 nightlies and `v0.5.19-cu130` it is deprecated, and in `dev-cu13-nightly-09242` it has no effect.

The regenerated data therefore has it again, on the same lanes as before #45090. #45090's edits outside the AgentX data (`environ.py` and the hand-written DeepSeek-V4 AMD commands) are untouched.

**Not mirrored:**
- `musespark-fp4-h100-sglang-agentic-dflash` and `qwen3.5-fp8-h100-sglang-agentic`: no dashboard changelog names a run for them (as in #45311).
- `qwen3.5-fp4-gb300-dynamo-sglang-agentic-agg-pareto` and `-pp-pareto` are deleted by [InferenceX #4333](https://github.com/SemiAnalysisAI/InferenceX/pull/4333) (as in #45311).

## How the commands are produced

The pipeline is the same as in #45311, with these changes:

- **`--attn-dp-size`.** It is the non-deprecated spelling of `--dp-size N --enable-dp-attention` (#41818), first used by [InferenceX #4346](https://github.com/SemiAnalysisAI/InferenceX/pull/4346). Deployment labels (`DEP8`), GPU counts and KV-donor matching now read it as DP attention.
- **Rules.** Kept as submitted: worker flags `--attn-dp-size`, `--enable-torch-symm-mem` and `--preferred-sampling-params`, and the Dynamo-only worker flags `--dyn-reasoning-parser` and `--dyn-tool-call-parser` (dropped from the derived SGLang-router variant, which keeps `--reasoning-parser`).

Each lane is still rendered at the exact commit of the run that produced its data, or at the PR head while in progress.
- **Removed (SA-only settings):** the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment).
- **Replaced with placeholders:** IPs, ports and NICs.
- **Derived variants:** router and KV-offload variants that were not run are derived and labeled "Derived — not run".

The data files are generated, so there is no hand-written code to review here.
