# [Perf] Cache DeepSeek expert-name matching across weight updates

[Upstream PR](https://github.com/sgl-project/sglang/pull/39383) · state: closed · merged: False

## Original PR description

## Motivation

@humansand

Repeated policy-weight updates scan the same ordered expert mapping for every incoming tensor name. Cache the first matching index on each model so later updates skip repeated substring checks. This draft contains the **receiver name cache only**.

- **Target:** `main`; independent of the earlier scale/transport fixes. Matching Miles draft: [upstream PR](https://github.com/sgl-project/sglang/pull/39384).
- **CPU result:** a synthetic 172,800-name replay changed from **1.988943 s baseline to 0.180377 s warm (11.03×)**. Initial cache population took **2.407988 s (21.1% slower than baseline)**. These measure mapping-stage CPU time, not full-model loading or weight publication.

## Modifications

- **Lookup:** retain the first matching mapping index for each incoming name, then run the existing ordered suffix loop. Preserve overlapping-name priority, name mutation, missing-target fallthrough and ordinary-parameter fallback. `islice` still traverses skipped references; this is not an O(1) complexity claim.
- **Lifetime:** keep the cache per model, invalidate when ordered mapping contents change, and resolve the current parameter dictionary on every load. Cache entries retain indices, not Parameters or device pointers.
- **Bound:** admit at most 262,144 names. Existing hits remain usable after saturation; new names use the original lookup. Memory and cold-cache costs are reported below.
- **Branch adaptation:** Pass the fully constructed per-call mapping into the helper, and invalidate after optional activation-scale mappings are appended. Preserve the existing fused-expert fast path.
- **Scope:** no quantization math, tensor layout, weight-copy, collective, protocol, sender-scale or public configuration change.

## Speed Tests and Profiling

CPU-only mapping replay on Apple M4 Max, CPython 3.14.6, macOS arm64. Synthetic deterministic input: 75 layers × 256 experts × 3 projections × 3 components = 172,800 names; 768 ordered mappings from each checkout's actual `FusedMoE.make_expert_params_mapping`. No model, GPU, network, or external Python package is used.

| Checkout | Original loop median (s) | Candidate cold median (s) | Candidate warm median (s) | Cold overhead (s) |
|---|---:|---:|---:|---:|
| main | 1.988943 | 2.407988 | 0.180377 | +0.419046 |
| miles | 2.025959 | 2.421775 | 0.187798 | +0.395816 |

Cold means a new empty cache for every timed replay; warm means a previously populated cache in the same interpreter. Five trials rotate the order baseline/cold/warm. Exact dispatch tuples for every name are compared outside timing on all 15 replays per checkout. Nine paired edge comparisons cover ordered missing-target fallthrough, negative matches, and mapping-content invalidation. The replay AST-copies the original expert filter loop, cache helper and per-call snapshot/reset; **real `itertools.islice` remains in use**, including consumption of its skipped prefix. The original filter/body AST and literal mapping-factory AST are verified unchanged against the parent.

The cold path is slower here: scanning to discover and insert each first-match index costs more than the original scan alone. The warm path avoids repeated Python substring scans. The cache stores incoming-name → first-index only; it resolves parameter targets anew and preserves ordered fallthrough. This measurement does not establish an integrated-loader or full-weight-sync speedup, and it does not attribute any multi-change end-to-end percentage to this cache.

Cache at 172,800 names (production cap 262,144): dictionary 3,844,864 bytes; distinct retained integer objects 3,226,496 bytes; total dictionary + integer estimate 7,071,360 bytes (6.744 MiB). Including the shared input-name strings gives 23,051,382 bytes (21.984 MiB); mapping snapshot tuple is another 6,192 bytes. These are `sys.getsizeof` estimates, not measured RSS. Shared strings already exist in this fixture, while a production cache can extend their lifetime; shared small integers can overstate incremental ownership.

Timing includes mapping cache snapshot/reset, parameter dictionary lookup and a recording CPU dispatch stub. Factory construction, fixture construction, cache priming, output equality and memory accounting are excluded. Main rebuilds its mapping per actual loader call; Miles constructs it during loader initialization. Neither factory cost is timed. Preprocessing, non-expert fallback loading, tensor operations and downstream stores are outside this mapping-only scope.

#!/usr/bin/env python3
"""Public, standard-library-only replay of the actual expert-name mapping loop.

Run from any directory: python3 bench_mapping.py --repo /path/to/sglang
    --baseline-ref <pre-patch-commit> --output result.json
No model import, tensors, accelerator, network, or private fixture is used.
"""
import argparse
import ast
import copy
import hashlib
import itertools
import json
import pathlib
import platform
import statistics
import subprocess
import sys
import time
import types

LOADER = "python/sglang/srt/models/deepseek_common/deepseek_weight_loader.py"
LAYER = "python/sglang/srt/layers/moe/fused_moe_triton/layer.py"


def sha(data):
    return hashlib.sha256(data).hexdigest()


def git(repo, *args):
    return subprocess.check_output(["git", "-C", str(repo), *args])


def statements(text):
    return ast.parse(text).body


def ast_sha(node):
    return sha(ast.dump(node, include_attributes=False).encode())


def compile_replay(loader_bytes, layer_bytes, candidate):
    tree = ast.parse(loader_bytes)
    cls = next(n for n in tree.body if isinstance(n, ast.ClassDef)
               and n.name == "DeepseekV2WeightLoaderMixin")
    load = next(n for n in cls.body if isinstance(n, ast.FunctionDef) and n.name == "do_load_weights")
    loops = [n for n in ast.walk(load) if isinstance(n, ast.For)
             and isinstance(n.target, ast.Name) and n.target.id == "mapping"]
    assert len(loops) == 1
    source_loop = loops[0]
    assert "expert_params_mapping" in ast.unparse(source_loop.iter) or "_iter_expert_mappings" in ast.unparse(source_loop.iter)
    assert ("_iter_expert_mappings" in ast.unparse(source_loop.iter)) == candidate
    loop = copy.deepcopy(source_loop)
    # Only the non-expert fallback is out of scope. Preserve the whole filter,
    # name mutation, target lookup, submit call, break and ordered continuation.
    loop.orelse = statements("records.append(('unmatched', loaded_weight, name))")
    factory_tree = ast.parse(layer_bytes)
    factories = [n for n in ast.walk(factory_tree) if isinstance(n, ast.FunctionDef)
                 and n.name == "make_expert_params_mapping"]
    assert len(factories) == 1
    factory = copy.deepcopy(factories[0])
    factory.decorator_list = []
    helper = [n for n in cls.body if isinstance(n, ast.FunctionDef) and n.name == "_iter_expert_mappings"]
    snapshot = [n for n in load.body if isinstance(n, ast.Assign)
                and any(isinstance(t, ast.Name) and t.id == "mapping_snapshot" for t in n.targets)]
    reset = [n for n in load.body if isinstance(n, ast.If)
             and "_expert_mapping_snapshot" in ast.unparse(n.test)]
    if candidate:
        assert len(helper) == len(snapshot) == len(reset) == 1
        assert "islice(mapping, start, None)" in ast.unparse(helper[0])
        constants = [n for n in tree.body if isinstance(n, ast.Assign)
                     and any(isinstance(t, ast.Name) and t.id == "_EXPERT_MAPPING_CACHE_MAX_ENTRIES" for t in n.targets)]
        assert len(constants) == 1
    else:
        assert not helper and not snapshot and not reset
        constants = []
    body = statements("records = []\nexpert_params_mapping = self.expert_params_mapping\nexecutor = None\nfutures = records\nuse_async_loading = False")
    body += copy.deepcopy(snapshot + reset)
    outer = ast.For(target=ast.Name(id="name", ctx=ast.Store()), iter=ast.Name(id="names", ctx=ast.Load()),
                    body=statements("loaded_weight = name") + [loop], orelse=[])
    body += [outer] + statements("return records")
    fn = ast.FunctionDef(name="replay", args=ast.arguments(posonlyargs=[], args=[ast.arg(arg=x) for x in ("self", "names", "params_dict")],
        kwonlyargs=[], kw_defaults=[], defaults=[]), body=body, decorator_list=[])
    module = ast.Module(body=statements("from __future__ import annotations") + copy.deepcopy(constants + helper) + [factory, fn], type_ignores=[])
    ast.fix_missing_locations(module)

    def record_submit(*, executor, futures, use_async, func, func_args, func_kwargs):
        param, original_name, mapped_name = func_args
        assert func == param.weight_loader
        futures.append((original_name, param.target, mapped_name, func_kwargs["expert_id"], func_kwargs["shard_id"]))

    env = {"islice": itertools.islice, "_is_npu": False, "maybe_executor_submit": record_submit}
    exec(compile(module, "<public-source-bound-mapping-replay>", "exec"), env)
    replay_cls = type("Replay", (), {"replay": env["replay"], **({"_iter_expert_mappings": env["_iter_expert_mappings"]} if candidate else {})})
    return replay_cls, env["make_expert_params_mapping"], {
        "loader_sha256": sha(loader_bytes), "factory_source_sha256": sha(layer_bytes),
        "expert_loop_ast_sha256": ast_sha(source_loop), "factory_ast_sha256": ast_sha(factories[0]),
        "expert_loop_body_ast_sha256": ast_sha(ast.Module(body=source_loop.body, type_ignores=[])),
        "helper_ast_sha256": ast_sha(helper[0]) if helper else None,
        "cache_limit": env.get("_EXPERT_MAPPING_CACHE_MAX_ENTRIES"),
        "generated_replay_ast_sha256": ast_sha(module),
    }


def params_for(mapping, layers, components):
    return {f"model.layers.{layer}.mlp.{row[0]}{component}":
            types.SimpleNamespace(target=f"model.layers.{layer}.mlp.{row[0]}{component}", weight_loader=None)
            for layer in layers for row in mapping for component in components}


def instance(cls, mapping):
    obj = cls()
    obj.expert_params_mapping = mapping
    return obj


def edge_checks(base_cls, candidate_cls):
    mapping = [("X", "late", 1, "w1"), ("Y", "early", 2, "w2"), ("Z", "X", 3, "w3")]
    base, candidate = instance(base_cls, mapping), instance(candidate_cls, mapping)
    checks = 0
    for target in ("early-X", "Y-X", "Y-Z", "absent"):
        params = {target: types.SimpleNamespace(target=target, weight_loader=None)}
        for _ in range(2):
            assert base.replay(["early-late", "no-match"], params) == candidate.replay(["early-late", "no-match"], params)
            checks += 1
    # This miss caches len(mapping), so failing to reset would skip the new hit.
    assert candidate._expert_mapping_start_cache["no-match"] == len(mapping)
    mapping[:] = [("T", "no-match", 4, "w2")]
    params = {"T": types.SimpleNamespace(target="T", weight_loader=None)}
    expected = [("no-match", "T", "T", 4, "w2")]
    assert base.replay(["no-match"], params) == expected
    assert candidate.replay(["no-match"], params) == expected
    assert candidate._expert_mapping_start_cache == {"no-match": 0}
    return checks + 1


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--repo", required=True, type=pathlib.Path)
    parser.add_argument("--baseline-ref", default="HEAD")
    parser.add_argument("--output", required=True, type=pathlib.Path)
    args = parser.parse_args()
    assert not args.output.exists(), "Refuse to replace an existing result"
    baseline_commit = git(args.repo, "rev-parse", args.baseline_ref).decode().strip()
    candidate_bytes = [(args.repo / p).read_bytes() for p in (LOADER, LAYER)]
    base_bytes = [git(args.repo, "show", f"{baseline_commit}:{p}") for p in (LOADER, LAYER)]
    base_cls, base_factory, base_proof = compile_replay(*base_bytes, False)
    candidate_cls, candidate_factory, candidate_proof = compile_replay(*candidate_bytes, True)
    assert base_proof["expert_loop_body_ast_sha256"] == candidate_proof["expert_loop_body_ast_sha256"]
    assert base_proof["factory_ast_sha256"] == candidate_proof["factory_ast_sha256"]
