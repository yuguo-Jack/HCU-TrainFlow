## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Fix issue https://github.com/sgl-project/sglang/issues/43765.
- PR#41020 added `compact_attention_hip`, the DeepSeek-V4.1 sparse decode attention kernel for gfx950. Its inner attention step (QK matmul, softmax, PV matmul) is a helper called `_qkpv_fp8`, which it imported from aiter's private `_gluon_kernels` module.
- That helper is internal to aiter, not a public API, so aiter can change or remove it at any time. It was removed in aiter PR#4919 (09/18). After PR#42023 moved sglang to an aiter version that includes that change, the import fails with `ModuleNotFoundError`. This breaks `test_compact_attention_hip` in AMD CI.

## Modifications

<!-- Detail the changes made in this pull request. -->

Copy `_qkpv_fp8` into `compact_attention_hip.py` unchanged
