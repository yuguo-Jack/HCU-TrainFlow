## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Multi-item scoring should process each item as an independent continuation of the shared query. This is the behavior requested in [#31969](https://github.com/sgl-project/sglang/issues/31969) and enabled for Qwen3.5 GDN layers by [#33922](https://github.com/sgl-project/sglang/pull/33922).

The GDN item segments still include their synthetic starting delimiters. Full attention masks those delimiters out, but GDN convolution and recurrent updates consume them before the real item:

```text
Packed input: Q | D0 | I1 | D1 | I2 | D2
Current:      query-ending state -> D_i -> I_i
Expected:     query-ending state -> I_i
```

Changing a packing-only delimiter can therefore change an item's score. This follow-up excludes that delimiter from real-item GDN state updates without changing the Score API or packed input layout.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Process only tokens between adjacent delimiters for nonempty items. Preserve the existing one-token delimiter readout for empty items and omit the unobserved final delimiter.
- Keep query-once execution, independent item states, packed output shape, original-index scatter, and zero-initialized unprocessed slots.
- Update the independent convolution/recurrent references and metadata/pooling expectations.
- Add mixed real/empty-item GPU coverage and preserve actual 63/64/65-token item lengths in the chunk-boundary fixture.
