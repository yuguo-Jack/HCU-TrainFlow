# [Fix] hicache: Budget declared DSA index host pools and keep mismatched MTP draft rows separate

[Upstream PR](https://github.com/sgl-project/sglang/pull/42918) · state: open · merged: False

## Original PR description

## Motivation

Replaces #38212, which made HiCache restore DSA index buffers and recurrent checkpoints for GLM-5.3-Flash (#38031). Main now covers most of that:

- #40913 and #40915 declare the DSA indexer host pool for standalone DSA and hybrid Mamba stacks, including packed and separate MTP drafts, and skip shared-topk layers that own no index rows.
- #42178 gives compressed DSA a 256-token logical page, so one index page belongs to exactly one radix page. A widened ownership grid, its L2-only storage guard and the per-page index sidecar (with its transfer-byte accounting) are no longer needed.
- With the radix page equal to the scheduler page, chunk ends and matched prefixes are page aligned (exact chunk fill is disabled for Mamba), DCP already checkpoints on the absolute grid, #39273 falls back to the previous ping-pong state when the latest one overshoots the key, and SWA leaves the insertion length to Mamba. The recurrent checkpoint ordering changes are therefore dropped. Replaying this PR's 320-token chunk, finished-request and SWA-branch scenarios on main publishes every recurrent state under the key it was computed for.
- `build_kv_host_pool` takes the MLA host row width from the device pool (656 elements for FP8 DSA), and `check_packed_kv_rows` rejects packed drafts with a different row. This replaces the packed-row check adapted from #37534.
- #43100 unregisters the DSA indexer host buffer in `DSAIndexerPoolHost.destroy()`.

On current main, two gaps remain, which this PR fixes:

- With an explicit `--hicache-size`, the hybrid Mamba stack gives the whole KV share to the KV host pool and then allocates the declared DSA indexer host pool on top of it, exceeding the budget by the index-to-KV byte ratio. QSA index bytes are already accounted for at this point.
- An MTP draft whose MLA KV rows differ from the target's (for example `--speculative-draft-kv-cache-dtype` different from `--kv-cache-dtype`) is always planned as packed and then fails the packed-row check at startup, although the separate draft sidecar can hold it.

## Modifications

- Scale the hybrid Mamba KV host budget so the KV host pool and every declared dependent pool built on it (the DSA indexer) together fit in the KV share of `--hicache-size`. The dependent bytes come from each declaration's storage info and host layers, including packed draft tails. Ratio mode is unchanged.
- In the HiCache draft plan, pack MTP drafts only when their MLA KV rows match the target's, using the same row signature as `check_packed_kv_rows`. A single mismatched draft uses the separate draft sidecar. Several mismatched draft runners are rejected because the sidecar keeps only the first runner. A mismatched draft with its own recurrent state is also rejected at startup: only packed MTP (#40223) backs that state up, and the sidecar has no host copy of it.

## Accuracy Tests

CPU tests on main 7ff3a11284 with this branch (torch 2.14.1, CPU only, macOS):

- New regressions: the hybrid Mamba host budget with and without a packed draft, and eight draft-plan cases (22 subtests). The budget, mismatched-row, retraction-backup, later-depth and draft recurrent-state cases fail on main; the remaining draft-plan cases pin the unchanged packed and legacy sidecar plans.
- `test_hybrid_pool_assembler.py`, `test_mem_pool_host.py`, `test_hicache_draft_plan.py`, `test_linker_pool_assembler.py`, `test_dsa_pool_host_unit.py`, `test_mla_host_dedup_primitives.py`, `test_hicache_host_register.py`, `test_hicache_staged_write_back_dispatch.py` and `test_decode_retraction_backup.py`: 127 passed. The failures are identical on main: `test_decode_retraction_backup.py` cases that require CUDA, two unified page-envelope tests and host-pool tests whose shared-memory allocation fails on this host.
- `test_unified_radix_cache_unittest.py`, `test_unified_hicache_regressions.py`, `test_unified_radix_hicache_dispatch.py` and `test_dsv4_hicache_l2.py` give identical per-test results on main and this branch.

No GPU or Ascend test was rerun for the rebuilt change.
