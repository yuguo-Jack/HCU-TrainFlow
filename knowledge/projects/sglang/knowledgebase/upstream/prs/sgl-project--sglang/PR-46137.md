# [Feat] layer-boundary: Fuse TP all-reduce, residual add and RMSNorm on the push plane

[Upstream PR](https://github.com/sgl-project/sglang/pull/46137) · state: closed · merged: True

## Original PR description

## Summary
A layer-boundary fusion provider, `CustomAllReduceFusion`, that runs TP all-reduce + residual add + RMSNorm as one kernel on the CustomAllReduceV2 push plane, with the MoE finalize and the shared-expert add folded in when the runner hands back a deferred finalize. A model enables it per stage.

## Changes to existing code
- `MoeDeferredFinalize` moves from `fusions/cutedsl.py` to `fusions/moe_finalize.py`; the DeepSeek-V2 and Qwen2-MoE imports follow.
- `register_fused_all_reduce_comm` can register a dedicated push-only plane (`max_push_size`, `max_push_blocks`); called without arguments it registers the TP group's plane as before, which is what DeepSeek-V4 does.
- `residual_batch.final_norm(..., finalize_norm=..., capture=...)` now hands the updated residual to `capture` after a fused finalize instead of raising.
- Shared `fused_norm_gamma` for GemmaRMSNorm and RMSNorm.

## Verification
- test_all_reduce_residual_norm (multi-GPU), test_custom_all_reduce_fusion, test_cutedsl_ar_fusion

Cut byte-for-byte from #45925 (MiniMax-M3.1-Flash support) at 10e655aa98.
