# [Feat] rust_server: Run --sidecar once per node

[Upstream PR](https://github.com/sgl-project/sglang/pull/46635) · state: closed · merged: True

## Original PR description

## Motivation

`--sidecar` is rejected with `SGLANG_RUST_SERVER=1`. The Python server starts and stops its sidecar from the FastAPI lifespan, but the Rust-mode launcher has no FastAPI app, so nothing starts the sidecar.

## Modifications

- Rust mode accepts `--sidecar` (it still requires `--grpc-port`).
- Every node that hosts a Rust listener runs one sidecar against the node's first listener while the launcher waits on its schedulers. SIGTERM stops the sidecar, then reaches the handler it replaced.

## Dependencies

Independent of the other PRs split out of #45996. For a per-node client to reach every DP rank it also needs `DeploymentInfo.node_listeners` (separate PR), but there is no code dependency.
