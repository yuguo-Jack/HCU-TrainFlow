# [Fix] quantization: Preserve CT MoE zero-point channel order

[Upstream PR](https://github.com/sgl-project/sglang/pull/47251) · state: open · merged: False

## Original PR description

## Motivation

Asymmetric `pack-quantized` MoE zero points are stored in natural output-channel order. The Marlin postload path currently sends those words through `moe_awq_to_marlin_zero_points`, which undoes AWQ's extra input interleave. This changes which zero point belongs to each CT output channel and produces incorrect expert outputs when the zero points vary across channels.

## Modifications

Convert each expert's CT zero points with `unpack_cols` followed directly by `marlin_zero_points`, matching the existing dense CT path. Apply the conversion to both gate/up and down projections.

Add CPU regressions using the installed compressed-tensors packer for W4/W8, multiple groups, output sizes and experts. Include positive controls for correctly interleaved AWQ words.

## Accuracy Tests

The unchanged acceptance limits were relative RMS < 0.03 and atol=0.001/rtol=0.05. Maximum observed relative RMS was 0.00028469.
