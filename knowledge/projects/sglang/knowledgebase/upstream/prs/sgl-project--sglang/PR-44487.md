# [Fix] nemotron: Preserve nested Puzzle configs

[Upstream PR](https://github.com/sgl-project/sglang/pull/44487) · state: open · merged: False

## Original PR description

## Motivation

Nemotron wrappers read nested Puzzle models as regular Nemotron configs, losing per-layer expert settings and causing weight-loading failures.

## Modifications

Use the existing Puzzle config class and prevent serialization from constructing an empty Puzzle config. Add regression tests while preserving ordinary Nemotron behavior.

## Accuracy Tests

- All five config tests pass; the new regression fails before the fix and passes after.
- Live smoke test on this branch with `nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB-BF16` in Docker on 2×H100 (TP=2): model loaded successfully and three chat requests passed with expected output.
