# Add NIXL as a backend for weight transfer

[Upstream PR](https://github.com/sgl-project/sglang/pull/35712) · state: open · merged: False

## Original PR description

Lets a rollout engine publish its weights for peer writes over NIXL, next to Mooncake. A peer such as a miles p2p trainer (radixark/miles#2721) loads each runner's agent and writes the weights in place; sglang stays passive.

Original NIXL work by @amitw-nv, rewritten onto the per-role publication now on `sglang-miles`.

## Changes

- `--remote-instance-weight-loader-start-seed-via-nixl` gives each runner its own NIXL agent: the target, and a speculative draft under its own role. The agent uses the plugin `SGLANG_REMOTE_INSTANCE_NIXL_BACKEND` names (default `UCX`). It registers the runner's weights as VRAM, then publishes:
  - the agent name;
  - its metadata, taken after registration so it carries the registered memory's remote keys;
  - its GPU id;
  - the weight table.
  Registration reuses the merged weight blocks of Mooncake's `register_memory_region_v2` (`_collect_weight_blocks`).
- The flag is rejected in three cases:
  - together with `--remote-instance-weight-loader-start-seed-via-transfer-engine`;
  - without the `nixl` package;
  - with `--enable-memory-saver`, which releases the memory NIXL registered.
- The transfer engine info a runner publishes becomes a transport-tagged dict, which the bootstrap server stores and returns as-is. It was a `[session_id, weights_info_dict]` list.
  - Mooncake: `{"transport": "mooncake", "session_id", "weights_info_dict"}`
  - NIXL: `{"transport": "nixl", "agent_name", "agent_metadata", "gpu_id", "weights_info_dict"}`

  The remote-instance seed loader reads it by key. Loading from a NIXL seed raises `NotImplementedError`.

## Compatibility

`/remote_instance_transfer_engine_info` returns the dict for Mooncake too. radixark/miles#2721 reads it, so this PR merges first.

## Tests

- `test_remote_instance_weight_roles.py`: target and draft publish the Mooncake dict under their roles. `test_a_nixl_runner_publishes_its_agent_after_registering_its_weights` checks that the metadata is taken after registration and checks the published NIXL dict.
- `test_remote_instance_loader.py`, `test_runtime_context.py` and `test_parallelism_context_integration.py` follow the new shape.
- 11 tests and 52 subtests pass on H200. Through radixark/miles#2721, a Qwen3-30B-A3B p2p e2e with one TP2/EP2 engine passes `--check-weight-update-equal` over NIXL.
