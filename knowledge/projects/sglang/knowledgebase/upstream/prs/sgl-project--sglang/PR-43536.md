# [Fix] comfyui: Fix GGUF detection, import guard and VRAM accounting in SGLDiffusion plugin

[Upstream PR](https://github.com/sgl-project/sglang/pull/43536) · state: closed · merged: True

## Original PR description

Fixes #43874

## Summary

Integrated-mode fixes for `python/sglang/multimodal_gen/apps/ComfyUI_SGLDiffusion/`, narrowed per review. Bug numbers match the issue.

- **Bug 1: GGUF unets could not be detected or loaded.** Detection now reads names and logical shapes from the GGUF header with `read_gguf_tensor_meta()` and runs ComfyUI's detection on them, like safetensors, so no BF16 companion file is needed. A GGUF picked in `SGLDUNETLoader` is loaded as the DiT. The GGUF loader maps tensor names through the spec's param mapping for both quant lookup and weight loading: Z-Image `qkv` -> `to_qkv`, `w1`/`w3` packed shards are concatenated into the fused `w13`, and packed tensors whose layer builds without GGUF (adaLN `ReplicatedLinear`) are dequantized on load.
- **Bug 2: `.gguf` leaked into ComfyUI's global `diffusion_models` registry.** `SGLDUNETLoader` now builds its own list with ComfyUI's `recursive_search` / `filter_files_extensions`, so the stock loader no longer offers GGUF files.
- **Bug 3: detection failure returned a bare `None`** ("cannot unpack non-iterable NoneType"). It now raises `ValueError` with the model path.
- **Bug 4: a missing runtime made every node vanish silently.** `executors/minimax_h3.py` guards its runtime imports like `base.py`, and `__init__.py` logs why registration failed.

Dropped from this PR: Cache-DiT (#43696), worker sleep/wake (#44086), server-mode items (#44082), and VRAM accounting (moved to #44086).

## Tests

Regression tests live in the existing unit files and reuse their fixtures (`test_comfyui_checkpoint_spec.py`, `test_comfyui_generator.py`, `test_comfyui_lora_node.py`); no new test file. Targeted CPU run: 52 passed.

ComfyUI v0.39.2 headless, 1x L40S, Z-Image Turbo, 1024x1024, 8 steps, seed 42:

| Path | Time | GPU mem used | vs native BF16 |
|---|---|---|---|
| Native ComfyUI BF16 | 2.87 s | - | - |
| SGLD BF16 | 2.79 s | 23.7 GB | 24.2 dB PSNR / 0.879 SSIM |
| SGLD `z-image-turbo-Q4_K_M.gguf` | 3.09 s | 14.7 GB | 14.2 dB PSNR / 0.431 SSIM |

The GGUF image keeps the same composition; the lower PSNR is Q4 drift in fine detail against a BF16 reference.

H3 GGUF: checked the real `minimax_h3_fl2va_pruned-Q4_K.gguf` header against the new name mapping; 0 of 532 tensor names change, so the H3 path loads as before.

- [ ] TODO: H3 GGUF end-to-end ComfyUI run still pending.

Known gap: Flux ComfyUI GGUF likely still needs its `_convert_weights` reshapes on the GGUF path; left as a follow-up.
