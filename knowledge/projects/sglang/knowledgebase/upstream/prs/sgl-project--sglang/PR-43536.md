# [Fix] comfyui: Fix GGUF detection, import guard and VRAM accounting in SGLDiffusion plugin

[Upstream PR](https://github.com/sgl-project/sglang/pull/43536) · state: open · merged: False

## Original PR description

Fixes #43874

## Summary

Integrated-mode fixes for `python/sglang/multimodal_gen/apps/ComfyUI_SGLDiffusion/`, narrowed per review. One commit per fix. Bug numbers below match the list in the issue.

- **Bug 1: any `.gguf` was detected as MiniMax-H3.** A Flux/Qwen/Z-Image GGUF either failed with an H3-specific error or got built as H3. The architecture is now inferred from the `SGLDOptions.model_type` hint or the filename, with a clear error when it can't be determined.
- **Bug 2: `.gguf` leaked into ComfyUI's global `diffusion_models` registry.** `SGLDUNETLoader` mutated `folder_paths.folder_names_and_paths` at import time, so the stock "Load Diffusion Model" node offered GGUF files it can't load. The node now builds its own file list.
- **Bug 3: detection failure returned a bare `None`.** Callers unpack the result, so users saw "cannot unpack non-iterable NoneType object". It now raises `ValueError` with the model path and detected type.
- **Bug 4: a missing runtime made every node vanish silently.** `executors/minimax_h3.py` imported `sglang.multimodal_gen` unguarded, which took Flux/Z-Image down too, and `__init__.py` swallowed the `ImportError` without logging. The import is now guarded like `base.py` and the failure is logged.
- **Bug 5: inconsistent VRAM accounting.** `SGLDModelPatcher.model_size()` returned a hardcoded guess for `flux`/`lumina2` and 0 for everything else. It now uses the real byte size from the checkpoint header (old table only as fallback), and GGUF loads are sized from the GGUF file rather than the BF16 companion.

Dropped from this PR: the Cache-DiT change (handled by #43696), worker sleep/wake (now #44086, issue #44084), and all server-mode items (now #44082, issue #44083).

## Tests

`test/test_sgld_bugfixes.py` (new): 12 tests covering the fixes above, using stubbed `comfy`/`folder_paths` modules so no ComfyUI install or GPU is needed. Each fails on the pre-fix code. `test/test_h3_request.py` is unchanged and still passes (23/23 total, CPU).
