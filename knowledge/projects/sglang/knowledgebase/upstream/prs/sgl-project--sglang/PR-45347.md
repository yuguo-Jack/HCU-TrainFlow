# [Fix] dsv4: Use type identity in maybe_copy_inplace assert

[Upstream PR](https://github.com/sgl-project/sglang/pull/45347) · state: open · merged: False

## Original PR description

E721: use `is` and `is not` for type comparisons, not `==`. Types are singletons so `==` and `is` are equivalent here, but `is` is the correct semantic for type checks.

Changed `type(src) == type(dst)` to `type(src) is type(dst)` in `maybe_copy_inplace` in `dsv4/metadata.py`. Zero behavior change.

No test needed for this one: a single type-identity operator swap with zero behavior change.
