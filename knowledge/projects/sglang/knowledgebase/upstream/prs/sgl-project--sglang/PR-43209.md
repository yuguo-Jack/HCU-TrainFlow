# Fix benchmark handling of streamed OpenAI server errors

[Upstream PR](https://github.com/sgl-project/sglang/pull/43209) · state: closed · merged: False

## Original PR description

## What changes

When a server sends an SSE error after HTTP 200 headers, the benchmark's OpenAI completions client reports `KeyError: 'choices'` and loses the server's error. The chat completions client skips the error frame and can count the request as successful.

Both clients now mark these requests as failed and retain the server's error payload, including its status code and message. This also applies when the error follows partial output. Successful streams keep their existing behavior.

A shared check runs before each client's token parser. Regression coverage includes errors before the first token, errors after partial output, successful streams, and progress-counter completion. This changes benchmark error reporting, not model execution. No performance improvement is claimed.
