# fix(frontend): reject input embeddings with mismatched hidden size

[Upstream PR](https://github.com/sgl-project/sglang/pull/43681) · state: open · merged: False

## Original PR description

## Motivation

With `--disable-radix-cache`, `/generate` accepts `input_embeds` whose row width does not match the model hidden size. The request reaches the model, fails in RMSNorm, and terminates the scheduler. Subsequent valid requests lose their connection.

## Modifications

Check every embedding row against `model_config.hidden_size` in the tokenizer manager, before dispatching the request. Invalid widths return HTTP 400 through the existing error handling. Add a regression that sends a mismatched row, then verifies that a valid embedding request still succeeds.

import json
import sys
from pathlib import Path
import requests

records = []
url = "http://127.0.0.1:31231/generate"
for payload in (
    {"text": "Hello"},
    {"input_embeds": [[0.0] * 896]},
    {"input_embeds": [[[0.0] * 896], [[0.1] * 896]]},
    {"input_embeds": [[1.0, 2.0, 3.0]]},
    {"text": "Hello"},
):
    try:
        response = requests.post(url, json={
            **payload,
            "sampling_params": {"temperature": 0, "max_new_tokens": 4},
        }, timeout=30)
        records.append({"status": response.status_code, "body": response.text})
        print(response.status_code, response.text)

        records.append({"error": str(error)})
        print(type(error).__name__)
Path(sys.argv[1]).write_text(json.dumps(records, indent=2))
