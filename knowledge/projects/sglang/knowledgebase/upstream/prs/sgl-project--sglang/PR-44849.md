# [Feat] server-args: Add --enable-hicache alias for --enable-hierarchical-cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/44849) · state: closed · merged: True

## Original PR description

## Summary

Adds `--enable-hicache` as an alias for `--enable-hierarchical-cache`, matching the `--hicache-*` naming of the other HiCache options.

I also added a fix for an issue where a YAML `--config` file that sets an on/off flag through its alias fails at startup, for example:

```yaml
enable-hicache: true
```

```
sglang serve: error: unrecognized arguments: true
```
