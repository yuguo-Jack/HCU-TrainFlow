# [NPU][DSV4] A5 explicit-state backend bring-up

[Upstream PR](https://github.com/sgl-project/sglang/pull/44637) · state: open · merged: False

## Original PR description

Migrate the DSV4 request-state ABI from the request-bank CYCLE layout to the explicit per-token EXPLICIT layout so the A5 (Ascend 950) port runs on the explicit state table.

- drop _build_cycle_state_block_table / dsv4_cycle_state_block_table; always use _build_explicit_state_block_table
- compressor_op = torch.ops.npu.compressor unconditionally
- state pool de-bloat; get_state_buf_infos folds the C4 state rows into the SWA payload on every arch; drop get_c4_state_buf_infos
- dsv4_state_payloads emits only DSV4_C128 (C4 state travels in the SWA payload); remove the DSV4_C4_STATE component / registration
- adapt the ABI-dependent unit tests (test_disaggregation_wire.py / test_npu_ascend_dsv4_backend.py) to the new layout
