## Original PR description

## Motivation
QSA chunk prefill reconstructs sequence-length metadata and synchronizes the device to infer a query-length bound already available to the caller.

## Modifications
- Reuse the batch sequence-length tensor.
- Accept an optional known maximum query length, retaining the inferred-bound fallback for existing callers.
- Add CUDA graph replay coverage with changed query inputs.
