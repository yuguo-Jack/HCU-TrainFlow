# fix: preserve streamed Harmony answer prefixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/43243) · state: open · merged: False

## Original PR description

## Summary

Buffer unresolved text after a tool call until it is clear whether it is the `commentary` filler. Flush ordinary text at structural boundaries and at stream end through the Harmony, function-call, and reasoning parser paths.

Fixes #43156

## Related work

- #41017 holds incomplete structural Harmony markers split across chunks. This change preserves ordinary text prefixes while deciding whether a post-tool-call `commentary` string is filler.
- #41045 fixes replayed text and lost tool calls in detector streaming state. This change addresses text held by the Harmony parser after a tool call.

## Testing

- Ran 48 tests from `test_harmony_parser.py` using a lightweight harness because importing the SGLang test package requires local `torch`.
- Targeted Ruff, Ruff format, isort, codespell, `py_compile`, registered-test validation, and diff checks passed.
- The added function-call and reasoning parser tests were not run locally because `torch` is unavailable.
