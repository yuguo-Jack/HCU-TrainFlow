## Overall work

**This stack exposes DiffusionGemma token scores, adds decision APIs and a TweetEval prefix reproducer, and documents the shared dLLM runtime.**

Merge in this order.

## This PR

**Help contributors follow a request through the dLLM runtime and find the right place to change code.**

The runtime spans configuration, denoising algorithms, request state, scheduling, and attention. The README connects these parts with a file map and a request-flow diagram.

- Depends on #43767.

## Changes

- Map the files and their responsibilities.
- Follow request preparation, model forwards, token updates, and output handling.
- Explain synchronous and FDFO scheduling, carried state, and KV cache ownership.
- Cover all four algorithms and their shared hooks.
- Link extension points, tests, and model guides.
