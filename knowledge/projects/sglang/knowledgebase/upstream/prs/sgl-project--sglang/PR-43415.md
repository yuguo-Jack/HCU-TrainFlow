# [diffusion] Pass model-declared image fields through /v1/images/edits

[Upstream PR](https://github.com/sgl-project/sglang/pull/43415) · state: open · merged: False

## Original PR description

## Motivation

`/v1/images/generations` forwards the fields the active `SamplingParams` declares in `image_request_extra_fields()`: Ideogram `preset`, ERNIE `use_pe`, Cosmos3 `guidance_interval` / `use_guardrails`, LongCat `cfg_renorm_*`, and so on. Multipart `/v1/videos` does the same for video. `/v1/images/edits` never reads them, so an edit request with, for example, `-F preset=V4_TURBO_12` returns 200 and silently runs with the default.

## Modifications

- `image_api.py`: `edits` now reads the model-declared image fields from multipart form fields, `extra_body`, or `extra_params`, with form fields taking precedence. It keeps only the fields the model declares and passes them to `build_sampling_params`, the same way `/generations` uses `request_model_kwargs`.
- Malformed `extra_body` / `extra_params` JSON returns 400, matching `/v1/videos`.
- `openai/utils.py`: the form-value decoder and the `extra_body` / `extra_params` parsing move here from `video_api.py` (`parse_form_extra_value`, `parse_multipart_extra_containers`), so `/v1/images/edits` and `/v1/videos` share one implementation. No behavior change for `/v1/videos`.
- No change for models that declare no image extras.

## Tests

New cases in `test/unit/test_multiple_task_types.py`, using the existing FastAPI `http_client` fixture and a test-only `SamplingParams` subclass that declares one field:
- the field arrives through a form field, `extra_body`, and `extra_params`; a form field wins over `extra_body`
- undeclared fields are ignored
- malformed JSON returns 400 and nothing is admitted

Ran on ubuntu with CPU torch: `test_multiple_task_types.py` and `test_openai_image_api.py` give 64 passed. On main, the new cases fail: the value stays at the default, and malformed JSON returns 200.

After the shared-helper refactor, on Windows with CPU torch: `test_multiple_task_types.py`, `test_openai_image_api.py`, `test_cosmos3.py` and `test_kandinsky6_sr_http_request.py` (the last two cover `/v1/videos` multipart extras) give 212 passed.
