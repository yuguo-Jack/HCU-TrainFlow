# fix(npu): fix hybrid KV transfer with PP prefill in PD disaggregation

[Upstream PR](https://github.com/sgl-project/sglang/pull/38402) · state: closed · merged: True

## Original PR description

## Summary

- route Ascend hybrid-linear PP KV transfer through global layer-id pairing
- publish one global layer id per NPU KV buffer group
- validate Mamba state slot sizes after pairing PP-local source layers with decode layers

Ascend already supports PP + PD for dense MLA/MHA layouts. Kimi-K3 uses a HybridLinearKVPool: only sparse full-attention layers own KV buffers, and Ascend exposes multiple buffer groups for each of those layers. The existing positional PP slicing therefore selects the wrong decode entries for later PP stages. This change keeps the existing transfer path for other backends and uses the existing generic layer-id pairing only for hybrid MLA with PP.

This PR intentionally excludes DSpark prompt context collection, draft-KV construction/transfer, and partial draft-weight loading.
