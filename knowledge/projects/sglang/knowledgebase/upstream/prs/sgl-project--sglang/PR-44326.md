# [DSv4.1] Support TRT-LLM decoder bounded replay with BCG

[Upstream PR](https://github.com/sgl-project/sglang/pull/44326) · state: closed · merged: True

## Original PR description

[codex/claude generated]

## Motivation

Enable DeepSeek-V4.1 TRT-LLM attention with decoder SWA bounded replay and breakable prefill CUDA graphs. Also fix a DP hang when a long request exceeds the graph sequence limit: active and idle ranks previously chose different execution paths.

## Modifications

- Allow decoder bounded replay and breakable prefill with TRT-LLM; retain encoder replay and full prefill graph restrictions.
- Use bounded-tail query offsets and tail-relative SWA lengths while retaining full-context compressed KV indices.
- Allocate the attention output bridge with the activation dtype, including when queries are FP8.
- Include the graph sequence limit in the scheduler's shared DP replay vote.
- Keep full-model GB300 E2E coverage and add a regression for active/idle DP fallback agreement. Remove the standalone config and numerical test additions as requested in review.

## Accuracy Tests

Local full-model DeepSeek-V4.1-Flash on 4×GB300, TRT-LLM, decoder bounded replay, DSPARK block size 5, EP4, maximum 64 running requests, memory fraction 0.8, seed 0, and `SGLANG_OPT_ENGRAM_EXTEND_HASH=1`. BCG uses a 16384 sequence bound and a 4096 total prefill token budget (1024 per DP rank). DP4 uses the supported gather/reduce MoE path (`none`) with DP LM head, not DeepEP.

| Configuration | GSM8K200 (≥95%) | MMLU500 (≥90%) |
| --- | ---: | ---: |
| TP4 attention, eager control | 97.5% | 91.2% |
| TP4 attention, BCG | 98.0% | 92.0% |
| DP4 attention, BCG + fallback fix | 98.5% | 92.0% |

The registered accuracy test methods ran against separately launched servers with verified settings and unchanged scoring thresholds. Each configuration passed both tests with no errors or skips. TP4 results precede the upstream update and DP fallback fix; DP4 results include both.

DP4 also passed 23 request checks covering cached prefixes, mixed lengths, repeated replay, chunking, and 17K graph-to-eager fallback. The 17K case stalled before the fix and completes afterward. The corresponding unit regression fails before the fix; all 55 affected unit tests and 52 subtests pass after it. Pre-commit passes. GitHub targeted CI is pending.

TP4 eager/BCG outputs matched all 32 generated tokens for 22/23 replay checks; one short mixed-batch prompt differed in two tokens. No bitwise-equivalence claim. PD/CP was not validated.

## Speed Tests and Profiling

TP4 warmed, cache-flushed 4096-token prompt, 32 generated tokens, temperature 0: median streaming TTFT across three runs was 186.6 ms eager versus 87.9 ms BCG. This is a small local smoke benchmark, not a production throughput claim. No profiling was performed.
