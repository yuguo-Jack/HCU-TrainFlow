# [Fix] custom-all-reduce: Keep integer all-reduces off the custom all-reduce kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/46994) · state: closed · merged: True

## Original PR description

- Custom all-reduce v1 and v2 now return False from `should_custom_ar` for dtypes other than bf16, fp16 and fp32, the only ones their kernels reduce. v2 reads the list from `SUPPORTED_DTYPES` next to its JIT loader (`FloatTrait` in `communicator.cuh`); v1 keeps it beside `_SUPPORTED_WORLD_SIZES`. Other dtypes fall back to NCCL.
- `_dp_gather_via_all_reduce` sends integer rows to the in-place NCCL all-reduce at every TP size. It did so only up to TP 8, a stand-in for "the group fits on one node" that no longer holds on multi-node NVLink.

Since #46853, a multi-node NVLink group of 2-16 GPUs uses custom all-reduce v2 without a VMM-backed allocator. With DP attention and a TP size above 8, `_dp_gather_via_all_reduce` sends integer tensors to `tensor_model_parallel_all_reduce`, which picked v2; v2 then failed to JIT-compile its kernel for the integer dtype:

```
RuntimeError: Failed to build JIT module sgl_kernel_jit_custom_all_reduce_int64_t_16_true ...
communicator.cuh(128): error: class "sglang::device::distributed::FloatTrait<int64_t>" has no member "kNegZero"
```

One case: DeepSeek-V4.1 Engram lookups at DEP16 across four GB300 nodes gather int64 hash ids this way on prefill batches.

No behavior change for floating-point all-reduces. Integer DP gathers above TP 8 take the in-place NCCL path instead of `tensor_model_parallel_all_reduce`; before #46853 both ended in NCCL.

## Verification

- With the v2 dtype check alone (`107bbf81bc`), on four GB300 nodes (TP 16, DP attention 16, one NVLink domain), an Engram DP lookup benchmark that failed with the error above on main now runs to completion with custom all-reduce enabled, prefill and CUDA-graph decode, outputs bitwise equal across `all_reduce`, `reduce_scatter` and `auto`.
- Unit tests in `test/registered/unit/distributed/`, `test/registered/unit/layers/test_dp_attention.py` and `test_dp_attention_cp_replicas.py`: all pass.
