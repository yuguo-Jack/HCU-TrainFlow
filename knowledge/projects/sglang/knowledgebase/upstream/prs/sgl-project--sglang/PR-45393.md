# [CI] tests: Skip Muse Spark B300 PD test when HF_MUSE_SPARK_TOKEN is unset

[Upstream PR](https://github.com/sgl-project/sglang/pull/45393) · state: closed · merged: False

## Original PR description

[by Claude Code]

## Motivation

Fixes #45392.

Since #44975 re-enabled `test/registered/e2e/models/test_muse_spark_12_b300_pd.py`, `base-c-test-8-gpu-b300` fails on every `pull_request` run from a fork.

- GitHub does not pass repository secrets to fork PRs, so `HF_MUSE_SPARK_TOKEN`, which comes from `secrets.HF_MUSE_SPARK_TOKEN` in `_pr-test-stage.yml`, is empty there.
- Without it, server startup dies with `GatedRepoError: 403` on `meta-models/Muse-Spark-Open-816B-A42B-NVFP4`. An example is [this job from #42760](https://github.com/sgl-project/sglang/actions/runs/39348980625/job/118556303062).
- The failure is deterministic, so reruns cannot pass it. Fail-fast then blocks the rest of stage C.

Scheduled `main` runs and same-repo PRs still pass, because they get the secret.

## Modifications

In `TestMuseSpark12B300PD.setUpClass`, raise `unittest.SkipTest` before any setup when running in CI (`is_in_ci()`) without `HF_MUSE_SPARK_TOKEN`.

- Runs that have the secret (scheduled `main` and same-repo PRs) are unchanged and keep the full coverage.
- Local runs outside CI are unchanged.
