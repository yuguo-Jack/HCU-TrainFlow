## Original PR description

## Motivation

DeepSeek-V2-Lite-W8A8 is no longer a tracked model, so its PR-level coverage is no longer needed. Keep the nightly coverage but drop it from the per-commit PR pipeline to avoid spending NPU PR runner time on an untracked model.

## Modifications

- `test/registered/npu/basic_function/runtime_opts/test_npu_mla_w8a8int8.py`: disable the `base-b-test-4-npu-a3` registration with `disabled="model is no longer tracked"`.
- `test/registered/npu/basic_function/runtime_opts/test_npu_mla_fia_w8a8int8.py`: disable the `base-b-test-2-npu-a3` registration with the same reason.
- `test/registered/npu/basic_function/HiCache/test_npu_hicache_mla.py`: disable the `base-b-test-4-npu-a3` registration with the same reason.

The `nightly-*-npu-a3` registrations in all three files are unchanged. This reuses the `disabled=` pattern already used by `test/registered/npu/basic_function/dp_attn/test_npu_dp_attention.py`.
