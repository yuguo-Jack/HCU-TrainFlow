# [CI] [NPU] tests: Replace DeepSeek-V2-Lite-W8A8 cases with Moonlight

[Upstream PR](https://github.com/sgl-project/sglang/pull/43063) · state: closed · merged: True

## Original PR description

## Motivation

DeepSeek-V2-Lite-W8A8 is no longer a tracked model, so its dedicated MLA W8A8 and MLA HiCache test cases are removed. Their FIA (fused inference attention) and HiCache dimensions are now covered by a single Moonlight-16B-A3B bf16 case on 2 NPUs. The DP attention cases that shared the same removed weights move to Moonlight as well, which lets them be re-enabled.

## Modifications

- Remove `test/registered/npu/basic_function/runtime_opts/test_npu_mla_w8a8int8.py`, `test/registered/npu/basic_function/runtime_opts/test_npu_mla_fia_w8a8int8.py` and `test/registered/npu/basic_function/HiCache/test_npu_hicache_mla.py`.
- Add `test/registered/npu/basic_function/runtime_opts/test_npu_mla_fia_hicache_bf16.py`: covers the FIA (`ASCEND_USE_FIA`) and HiCache (hierarchical cache) paths with the bf16 Moonlight-16B-A3B model on 2 NPUs, replacing the removed W8A8 coverage.
  - Registers to `base-b-test-2-npu-a3` (PR) and `nightly-2-npu-a3` (nightly, est_time 1400).
  - Drives GSM8K through `NPUGSM8KMixin`: the PR pipeline only sends the smoke request, the nightly pipeline runs the full 1319-question set with a 0.83 threshold.
  - Keeps expandable pinned host segments (`PYTORCH_NPU_ALLOC_CONF`) because HiCache reserves several GB of host memory per rank.
  - Detects the invoking pipeline via `GITHUB_WORKFLOW_REF`, because the nightly workflow is also path-triggered by pull requests, so the nightly path still runs the full GSM8K evaluation.
- `test/registered/npu/basic_function/dp_attn/test_npu_dp_attention.py`: use `MOONLIGHT_16B_A3B_MODEL_PATH` instead of the removed W8A8 weights in `TestDPAttentionMixedChunk` and `TestDPRetract`, re-enable the former, and set the GSM8K threshold to 0.83 (Moonlight bf16 baseline is ~0.837).
