## Motivation

<!-- Describe the purpose and goals of this pull request. -->

After #27563, disagg speculative decoding will fail with
```
ValueError: NIXL prepared dlist geometry length mismatch: ptrs=79, item_lens=79, data_lens=79, xfer_lens=78
```
due to decode having extra kv-cache for draft model, compared to prefill.
This PR restores previous behavior, which is to ignore them.

## Modifications

<!-- Detail the changes made in this pull request. -->
Slice list of kv-cache on decode side to match prefill.
Block Hisparse + decode only speculative decoding, which is completely untested.
