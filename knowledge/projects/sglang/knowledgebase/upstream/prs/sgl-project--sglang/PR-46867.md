# [Attention] Add cuDNN attention backend (prefill only)

[Upstream PR](https://github.com/sgl-project/sglang/pull/46867) · state: open · merged: False

## Original PR description

Adds a cuDNN attention backend for prefill/extend, using flashinfer's `cudnn_batch_prefill_with_kv_cache`.

## What's included

- `cudnn_backend.py` — `CuDNAttnBackend` implementing prefill/extend via flashinfer's cuDNN batched prefill op.
- Registered as `--attention-backend cudnn` (registry + `ATTENTION_BACKEND_CHOICES`).
- CUDA graph is disabled for this backend (both prefill and decode phases) because decode is not yet implemented — flashinfer does not expose a cuDNN decode function. Speculative decoding is rejected with a clear error.

## Scope / limitations

- **Prefill only.** Decode falls back to no-CUDA-graph execution; this is asserted and warned about at startup rather than silently mis-dispatched.
- Requires cuDNN 9.15+ and a flashinfer build with cuDNN support; the backend is opt-in and does not change any default path.

## Validation

- Rebased onto current `main` (de26bb16a9), adapted to upstream's move of `ATTENTION_BACKEND_CHOICES` into `arg_groups/choices.py`.
- All changed files parse clean; no existing backend or default selection is modified (only additive).
- Full functional validation on GPU is pending CI / reviewer guidance on which model shape to exercise — I have not run a server end-to-end with this backend, and I'd rather state that than imply otherwise.
