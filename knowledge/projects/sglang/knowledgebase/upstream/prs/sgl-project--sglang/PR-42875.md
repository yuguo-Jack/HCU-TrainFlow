# [Feat] lora: Absorbed-MLA kv_b corrections on the dense runner (08/21)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42875) · state: closed · merged: False

## Original PR description

Part 08 of 21 of the LoRA runtime stack (branch `lora-stack-07-mla-correction`, base `lora-stack-06-dense-graphs`). The stack is cut from the development branch of #42284.

## What this part adds

Apply a kv_b_proj adapter as two corrections around the absorbed attention
BMMs (Q += Q @ B_k @ A, V += attention @ A.T @ B_v.T), routed by (slot, head)
with per-head B slices, built once per forward on the caller stream. The MLA
forward selects the correction through kv_b_lora_correction(): "v2" for
triton_v2 with an active adapter, "legacy" for the other backends, None
otherwise.
Tests: correction numerics against a reference at both phases, the
v2/legacy/none selection under capture, the MLA forward's dense-import
contract, and the correction chain and pair routes under replayed graphs.

Files outside the LoRA owners' paths: `srt/models/deepseek_common` (forward_mla.py).
