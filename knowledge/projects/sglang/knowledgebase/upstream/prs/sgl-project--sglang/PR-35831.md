# [FIX] use DP attention group for MoonViT reductions

[Upstream PR](https://github.com/sgl-project/sglang/pull/35831) · state: open · merged: False

## Original PR description

## Motivation

Kimi-VL can deadlock on the first image request when DP attention is enabled with more than one DP group and `attn_tp_size > 1`, such as TP4/DP2.

MoonViT shards its attention output projection and MLP output projection across the attention TP group, but these layers reduce through the global TP group. Only the DP group handling the image executes these collectives, so ranks enqueue different collective sequences.

Fixes #34442.

## Modifications

- Use the DP-attention TP group for the MoonViT attention output projection.
- Use the DP-attention TP group for the MoonViT MLP output projection.
- Add a unit test covering both reduction paths.

## Accuracy Tests

The change only selects the communicator for existing reductions.
The added unit test checks both projections.

## Speed Tests and Profiling

Not run. The change does not add collectives or alter tensor shapes; it routes two existing reductions to the attention TP group.
