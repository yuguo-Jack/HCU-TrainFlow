# [Fix] connector: Fix directory mutation and pattern filtering in `pull_files_from_db`

[Upstream PR](https://github.com/sgl-project/sglang/pull/47733) · state: open · merged: False

## Original PR description

## Motivation

While inspecting `python/sglang/srt/connector/utils.py` and `python/sglang/srt/connector/base_connector.py`, we found three bugs in the connector utilities:

1. **Root directory variable overwritten inside `pull_files_from_db` loop (`utils.py:29-31`)**:
   ```python
   local_dir = connector.get_local_dir()
   ...
   for file in files:
       destination_file = os.path.join(local_dir, file.removeprefix(prefix))
       local_dir = Path(destination_file).parent
   ```
   Reassigning `local_dir = Path(destination_file).parent` inside the `for file in files:` loop overwrites `local_dir` after the first file. Whenever a model in Redis/KV storage has files in subdirectories (e.g. `sub1/a.json` followed by `sub2/b.json` or `config.json`), every subsequent file is written relative to the previous file's subdirectory (`<root>/sub1/sub2/b.json`, `<root>/sub1/sub2/config.json`) instead of `<root>`.
2. **`allow_pattern` and `ignore_pattern` ignored in `pull_files_from_db` (`utils.py:18-22`)**:
   `pull_files_from_db` accepts `allow_pattern` and `ignore_pattern` (forwarded from `RedisConnector.pull_files`), but never filters `files` with them.
3. **Non-callable signal handlers in `BaseConnector._close_by_signal` (`base_connector.py:61-69`)**:
   `_close_by_signal` checks `if existing_handler:` before calling `existing_handler(signum, frame)`. When a signal's previous disposition is `signal.SIG_IGN` (`1`, which is truthy in Python but not callable), receiving the signal raises `TypeError: 'int' object is not callable`. Additionally, if a subclass raises before `super().__init__(url)` sets `self.closed`, `BaseConnector.__del__` calling `self.close()` raises `AttributeError`.

## Modifications

- Keep `local_dir = connector.get_local_dir()` immutable across iterations in `pull_files_from_db` and create `Path(destination_file).parent` without clobbering `local_dir`.
- Apply `fnmatch`-based `allow_pattern` and `ignore_pattern` filtering in `pull_files_from_db` (consistent with `FilesystemConnector.pull_files`) and strip any leading `/` from `rel_path`.
- Import `BaseConnector` from `sglang.srt.connector.base_connector` in `utils.py` to avoid circular imports through `sglang.srt.connector.__init__`.
- Guard `existing_handler` with `callable(existing_handler)` in `BaseConnector._close_by_signal` and use `getattr(self, "closed", True)` in `BaseConnector.close()`.
- Add unit tests in `test/registered/unit/test_connector_utils.py`.
