# Fix unsigned 32-bit rotation in Murmur sampling hash

[Upstream PR](https://github.com/sgl-project/sglang/pull/43825) · state: open · merged: False

## Original PR description

# [NPU] Mask rotate-left input to 32 bits before widening shifts

The 32-bit Murmur rotation can receive a value whose high bits survive conversion to uint64 on the evaluated NPU Triton path. Those bits enter the right-shift term before the final output mask, producing incorrect hash values and therefore different deterministic sampling inputs. Mask the converted value with 0xFFFFFFFF before performing either shift. The hash constants, seed/position/column inputs and sampling configuration remain unchanged.

This is a shared sampling helper correction, not a model-specific answer patch. It applies to callers of rotl32; the runtime implementation is not guarded to NPU even though the recorded device regression is NPU. No other sampler or model code is included.
