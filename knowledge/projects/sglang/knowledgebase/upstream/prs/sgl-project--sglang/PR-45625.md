## Original PR description

## Summary

Adds the cookbook page for [Recursive Flint](https://huggingface.co/RecursiveSI/flint), a 40B MoE open-weight model for fast, local agentic coding (Apache 2.0).

- `docs/cookbook/autoregressive/Recursive/Flint.mdx`: new page with deploy widget, model introduction, and reasoning / tool-calling examples.
- `docs/src/snippets/configs/RecursiveSI/flint.jsx`: deploy config. The widget shows only the hardware row. H200 / B200 / B300 / GB300 run the single-GPU recipe on `lmsysorg/sglang:dev-flint`. The Playground is not included.
- `docs/docs.json` + `docs/cookbook/autoregressive/intro.mdx`: new **Recursive** nav group and landing card.
- `docs/cards/logos/recursive.png`: icon-only 940×525 transparent card logo, rasterized from the official mark on recursive.com.

## Notes for reviewers

- The engine renders nothing when `matchDims` is empty. The config therefore keeps one hidden `variant` dim (`showWhen: () => false`) instead of changing `_deployment.jsx`.
- The bind host defaults to `0.0.0.0` so the Docker `-p 30000:30000` mapping reaches the server.
