# [CI] [AMD] ci: Register two never-run tests on suites a job runs

[Upstream PR](https://github.com/sgl-project/sglang/pull/48135) · state: closed · merged: False

## Original PR description

## Motivation

Two test registrations name suites that no workflow dispatches, so these tests never run in any CI.

## Modifications

- `hicache/test_hicache_storage_3fs_backend.py`: `register_amd_ci` used the CUDA suite name `base-b-test-2-gpu-large`. Register it on `extra-a-test-2-gpu-large-amd`, the AMD counterpart of the `extra-a` / `2-gpu-large` tier its CUDA registration moved to in #47619.
- `unit/layers/attention/test_fp8_fused_writer_hip.py`: registered on `stage-a-test-cpu-amd`, which has no job. Its five checks are CPU-only wrapper checks, so register it with `register_cpu_ci` in `base-a-test-cpu`.

Both fixes are taken from #47179, which will be narrowed to its AMD Extra status reporting.

## Verification

- `test_fp8_fused_writer_hip.py` passes on the CPU runner: 5 tests OK in [this rerun-test-cpu job](https://github.com/sgl-project/sglang/actions/runs/40812228366/job/123245099055). The file and the module it tests have not changed since.
- The 3FS test passed on an AMD 2-GPU runner in [this run](https://github.com/sgl-project/sglang/actions/runs/40812219513) from #47179.
