# [Feat] Spark2.5: Support Spark2.5 Dspark

[Upstream PR](https://github.com/sgl-project/sglang/pull/47183) · state: open · merged: False

## Original PR description

[## Motivation

This PR adds dSpark speculative decoding support for Spark2.5 with bundled target and draft checkpoints.

## Modifications

| File | Purpose |
| --- | --- |
| `python/sglang/srt/configs/model_config.py` | Recognizes `DSparkSpark25DraftModel` and transforms a bundled Spark2.5 configuration into an all-SWA dSpark draft configuration. |
| `python/sglang/srt/configs/spark2_5.py` | Adds `num_draft_layers` and the Spark2.5 bundled-draft configuration transformation, including dSpark metadata. |
| `python/sglang/srt/models/spark2_5.py` | Captures residual-aware auxiliary hidden states for dSpark, enforces PP=1 for capture, uses exact GELU, and skips `draft_model.*` weights when loading the target. |
| `python/sglang/srt/models/spark2_5_dspark.py` | Adds `DSparkSpark25DraftModel` with Spark2.5 attention, context projection, bundled draft-weight loading, shared embedding/head handling, and FULL/SWA context KV writes. |
| `python/sglang/srt/models/dspark.py` | Adds the context-KV writer binding hook and allows dSpark draft variants to select their attention output projection. |
| `python/sglang/srt/speculative/dspark_components/dspark_kv_inject.py` | Binds the context writer once and resolves SWA locations for prefill and verify injections. |
| `python/sglang/srt/mem_cache/allocator/base.py` | Defines the allocator interface for translating physical FULL ids to SWA ids. |
| `python/sglang/srt/mem_cache/kv/alloc/chain.py` | Implements physical FULL-to-SWA translation for chained FULL/SWA allocators. |
| `python/sglang/srt/mem_cache/kv/alloc/runner_ids.py` | Builds paired FULL/SWA context-KV write locations for the current runner. |
| `python/sglang/srt/mem_cache/kv/router.py` | Adds prefix-valid KV storage for committing only accepted rows. |
| `python/sglang/srt/model_executor/pool_configurator.py` | Prices private draft SWA capacity from the draft geometry and prices unified fused SWA entries by their allocated entry size. |
| `test/registered/unit/models/test_spark2_5_dspark.py` | Adds CPU coverage for bundled configuration, construction, shared modules, hidden-state capture/projection, draft computation, FULL/SWA writes, prefix-valid commits, and prefill/ragged verify injection. |
| `test/registered/unit/model_executor/test_pool_configurator.py` | Updates fixtures and adds coverage for the unified fused-SWA pricing path. |](https://github.com/sgl-project/sglang/pull/47183)
