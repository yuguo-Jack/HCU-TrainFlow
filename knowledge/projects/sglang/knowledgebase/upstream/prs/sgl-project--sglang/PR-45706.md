# [Refactor] diffusion: Remove the deprecated kitchen_int8 alias

[Upstream PR](https://github.com/sgl-project/sglang/pull/45706) · state: closed · merged: True

## Original PR description

## Motivation

`kitchen_int8` was explicitly deprecated in favor of `convrot_int8` by #38040 on October 2. The deprecation is included in v0.5.22, released October 19, so it has crossed a release boundary.

## Changes

- Remove the deprecated quantization method name and the now-unused alias-normalization module.
- Keep `convrot_int8`, the `comfy_kitchen` backend, quantization kernels, and component residency/offload options unchanged.
- Update current examples and loader fixtures to use `convrot_int8`.
- Replace the alias-compatibility test with rejection coverage and check the FLUX.3 configuration-loading entry point as well.

Existing configurations using `kitchen_int8` must change that value to `convrot_int8`. This does not remove any `--*-cpu-offload` option or change numerical kernels.
