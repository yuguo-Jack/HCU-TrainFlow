# [Fix] hisparse: Release HiSparse rows on the KV checksum mismatch and chunked abort exits

[Upstream PR](https://github.com/sgl-project/sglang/pull/43911) · state: closed · merged: True

## Original PR description

Two exits free a request's KV with `release_kv_cache` without releasing its HiSparse state first, so the rows leak. Both now call `hisparse_coordinator.request_finished` before the KV free, under the same `enable_hisparse` guard as the other exits.

- PD decode KV checksum mismatch (`_handle_kv_checksum_mismatch`): the transfer has already admitted the request into HiSparse, so its host pages and device buffer were never returned.
- Chunked prefill abort (`process_pending_chunked_abort`): a request aborted between chunks holds only the spec scratch row its extend allocated; `request_finished` frees exactly that (its no-device-buffer branch), and the prefill KV is still freed by `release_kv_cache`.

No change without `--enable-hisparse`. No stream wait is added or moved; `request_finished` keeps its own wait on the forward stream, as at the other exits.

## Test plan
