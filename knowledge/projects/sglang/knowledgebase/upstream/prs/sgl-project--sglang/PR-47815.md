# [Perf] attention: Use live KV lengths for SM12x FA4 graph replay

[Upstream PR](https://github.com/sgl-project/sglang/pull/47815) · state: open · merged: False

## Original PR description

## Motivation

A large KV capacity bound at CUDA graph capture can produce a fixed SplitKV grain that leaves most splits idle when replay uses shorter contexts.

## Modifications

Use live KV lengths to partition SM12x FA4 paged decode during graph replay while preserving the eager split policy. Add one regression that checks the captured plan and attention results across changing replay lengths.

## Accuracy Tests

Pre-commit and `git diff --check` passed. The new GPU regression has not been run on SM12x hardware.

## Speed Tests and Profiling
