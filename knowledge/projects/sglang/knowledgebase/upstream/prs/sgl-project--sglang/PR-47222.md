# [Test] [NPU] glm5_3: Add 2P2D 32P and 1P1D 16P PD-sep performance cases

[Upstream PR](https://github.com/sgl-project/sglang/pull/47222) · state: open · merged: False

## Original PR description

## Motivation

Add Ascend NPU nightly performance regression coverage for the GLM-5.3 family under prefill/decode (PD) separation, so 128K-long-prompt serving regressions are caught by the multi-node nightly pipeline instead of ad-hoc wiki scripts:

- GLM-5.3-w8a8: 2P2D across 4 nodes (32 cards)
- GLM-5.3-Flash-w8a8: 1P1D across 2 nodes (16 cards)

## Modifications

### New performance cases

`test/registered/npu/performance/glm5_3/test_npu_glm_5_3_w8a8_2p2d_32p_in128k_out1k_prefix90_20ms.py`

- 4-node PD separation: 2 prefill nodes (`tp8 / pp4 / attn-cp8` interleave, deepep normal, `--disable-cuda-graph`) + 2 decode nodes (`tp32 / dp32 / ep32`, deepep low_latency) + 1 router node.
- NEXTN enabled on both sides; workload is `generated-shared-prefix` with 256 prompts, `max_concurrency=64`, `input_len=131072`, `output_len=1024`, `repeat_rate=0.9` (system prompt 117964 / question 13107).
- Thresholds: TPOT <= 20 ms, output throughput >= 620 tok/s.

`test/registered/npu/performance/glm5_3/test_npu_glm_5_3_flash_w8a8_1p1d_16p_in128k_out1k_prefix90_20ms.py`

- 2-node PD separation: 1 prefill node (`tp16 / dp1`, deepep normal, chunked prefill 8192) + 1 decode node (`tp16 / dp16`, deepep low_latency, NEXTN 3/1/4) + 1 router node.
- Same dataset shape with 128 prompts and `max_concurrency=16`.
- `--page-size 64`: the NPU DSA path requires 64-token physical pages.
- `--speculative-draft-model-quantization unquant`: the GLM-5.3-Flash checkpoint has no ModelSlim description for the MTP block, so the draft model must stay unquantized instead of inheriting the target's `modelslim` quantization.
- TPOT / output-throughput thresholds are intentionally left ungated (`None`) until the first calibrated nightly run.

### Model path constants

- `python/sglang/test/ascend/e2e/test_npu_performance_utils.py`: `GLM_5_3_W8A8_MODEL_PATH`, `GLM_5_3_FLASH_W8A8_MODEL_PATH`.
- `python/sglang/test/ascend/test_ascend_utils.py`: `GLM_5_3_W8A8_MODEL_WEIGHTS_PATH`.

### Nightly pipeline registration

- `.github/workflows/nightly-test-npu.yml`: both cases are registered in the `multi-node-poc` matrix. While the multi-node port is being validated, the single-node nightly jobs and the A5 job stay temporarily disabled; they will be re-enabled once validation finishes.

N/A - test-only change; no model forward path or kernel code is modified.
