# [Perf] [AMD] kimi-k3: TP8 low-latency collectives on gfx950: column-parallel latent tail and fused attention all-reduce, each fused with the next AttnRes read

[Upstream PR](https://github.com/sgl-project/sglang/pull/44985) · state: open · merged: False

## Original PR description

> Kimi-K3 on gfx950, grouped into larger drafts: prefill #44981 (with #44980) · TP8 LL collectives #44985 (now includes #44986) · decode routing #44987 (with #44978's argmax) · KDA verify #44982 · then #44988. Closed as superseded on main: #44979, #44983, #44984, #44989.

## Motivation

At Kimi-K3 decode sizes, two kinds of work are separate small launches per layer:
- the latent-MoE tail after the MoE all-reduce (norm, 3584 -> 7168 up-projection, shared + residual add) and the next layer's attention-side attention-residual (AttnRes) read; each rank also computes the whole replicated tail GEMM;
- the attention output's TP8 all-reduce, the residual add and the FFN-side AttnRes read.

This PR now also carries #44986, so the TP8 low-latency collectives land together.

## Modifications

Gated on gfx950 TP8 (`layers/communication/k3_ll_comm_hip.get_comm()`).

- **LL protocol (`comm/ll_hip.cuh`):** a low-latency push protocol over a dedicated aiter CustomAllreduce's IPC meta buffer. Senders write 16-byte lines of 8 payload bytes plus an epoch flag into the receiver's scratch, and receivers poll their own; there is no barrier, because a line is rewritten two epochs later.
- **Column-parallel latent tail fused with the next attention read** (`attn_res/read_hip.cuh`, `k3_attn_res_read_hip.py`; `SGLANG_ROCM_K3_COLUMN_TAIL`, up to 64 tokens): each rank runs the tail GEMM on 1/8 of the replicated up_proj rows as split-K fp32 partials (`k3_latent_tail_partials`). The all-gather kernel finishes its slice (/rms, + shared [+ residual]), gathers the stream and runs the next layer's attention read on it, staged in `AttnResidual`.
- **Fused latent tail** (`k3_latent_tail`; `SGLANG_ROCM_K3_FUSED_LATENT_TAIL`, up to 32 tokens): batches the column tail does not take run norm + up-projection + shared + residual add as one kernel.
- **Fused attention all-reduce read (was #44986):** the attention output's one-shot all-reduce, the residual add and the FFN-side read run in one LL kernel for 4-row batches, the EAGLE C1 verify (`SGLANG_ROCM_K3_FUSED_ATTN_AR_READ`). Its scratch region follows the gather read's. The sums run in rank order, so every rank gets the same bits. #44551's two-shot variant for 5-64 rows measured slower than aiter's all-reduce + the Triton read, so it is not included.

|---|---|

| `SGLANG_ROCM_K3_COLUMN_TAIL` | on |

## Accuracy Tests

Setup: 8x MI350X, Kimi-K3 TP8 with EAGLE3 (`lightseekorg/kimi-k3-eagle3.1-mla`; topk 1, 3 steps, 4 draft tokens), FP8 KV, `SGLANG_USE_AITER=1 AITER_SITUV2_A8W4=1 AITER_FLYDSL_FORCE=1 SGLANG_AITER_K3_OPT=1`, with #43599's aux capture applied locally.

- GSM8K: 0.99 / accept 3.62 with the column tail (GSM8K 400), and 0.985 / accept 3.613 with every verify on the fused attention read (GSM8K 200), both from the original PRs. GSM8K 200 on `main` 3a01d4cc8c (2026-10-29): see the next section.
- Kernel tests on MI355X, on this branch merged with current `main`: `test_kimi_k3_latent_tail_hip.py` and the 8-GPU `test_k3_ll_collectives.py` (gather read at 1 / 4 / 64 rows, and the all-reduce read giving the rank-order bf16 sum exactly on every rank): 3 passed, 9 subtests.
- `test/registered/unit/layer_boundary/test_attn_bank_residual_ops.py` fails the same 7 tests on unmodified `main` (`'_Norm' object has no attribute 'weight'`), unchanged by this PR.

## Speed Tests and Profiling

Re-measured on `main` 3a01d4cc8c (2026-10-29), same setup, decode verify cycle on a 50K-token cached prefix, PRs added one at a time:
- the column tail + fused next read: C1 and C4 verify cycle -3.7%;
- the fused attention all-reduce read on top: C1 -1.6%, C4 -4.6%;
- GSM8K 200 stays at 97.5-98.5 across these runs (temperature 1.0).

Microbenchmarks from the original PRs: tail partials ~4 us vs 11.5-13 us replicated; fused latent tail 13.5 vs 19.5 us (-21..-36% over 2-32 rows); the fused attention read at 4 rows took the C1 cycle from 16.02-16.25 to 15.82-15.92 ms, and was slower at 16 rows, hence the 4-row limit.
