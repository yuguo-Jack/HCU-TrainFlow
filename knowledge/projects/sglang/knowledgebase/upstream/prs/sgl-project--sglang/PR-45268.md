# [Doc] [AMD] cookbook: Align DeepSeek-V4 MI355X AgentX recipe with InferenceX #4315

[Upstream PR](https://github.com/sgl-project/sglang/pull/45268) · state: open · merged: False

## Original PR description

## Motivation

[InferenceX #4315](https://github.com/SemiAnalysisAI/InferenceX/pull/4315) needs its MI355X AgentX serving configuration documented in the SGLang cookbook. #45070 aligned §3.6 with [InferenceX #4245](https://github.com/SemiAnalysisAI/InferenceX/pull/4245), whose recipe is byte-identical to #4315's; #4315 only moves the image from `-20261016` to `-20261019`. Comparing every effective arm of the #4315 recipe with §3.6 still found server settings that §3.6 has never carried.

## Summary

- Aligns the DeepSeek-V4-Pro-0813 MI355X AgentX cookbook (§3.6) with SemiAnalysisAI/InferenceX#4315.
- Names the image #4315 pins, `lmsysorg/sglang-rocm:v0.5.22-rocm720-mi35x-20261019`, and links the submitted recipe at `fd09dd949a18`.
- Adds `SGLANG_DEFAULT_THINKING=1`, `SGLANG_DSV4_REASONING_EFFORT=high` and `HSA_NO_SCRATCH_RECLAIM=0` to all three commands, `GPU_MAX_HW_QUEUES=2` to the TP8 command and `GPU_MAX_HW_QUEUES=5` to the DP8 command. The MegaMoE command already set `GPU_MAX_HW_QUEUES=5`.
- Adds the sizing rule: `--max-running-requests` at twice the concurrency, `--cuda-graph-max-bs-decode` at the same value capped at 128.
- Adds `--dp-aware` to the `cache_aware` router guidance. Without it the router registers one worker per server, so it cannot place a session on the DP rank that holds its prefix.

`main` already matched the rest, including every #4315 delta from #45070: `SGLANG_HIP_DSV4_C4_INDEXER_ROWGROUP=1`, DP chunked prefill 131072, FlyDSL MTPR 16384, decode MTPR 512 / fixed-slot cap 1023 (1024 / 2047 at c384), `SGLANG_EPLB_P2P_BATCH_CHUNK_SIZE=7`, and the MegaMoE interval of 40 (20 at c384).

Recipe fields with no cookbook flag because SGLang `main` resolves them identically:

- `--speculative-num-steps 1 --speculative-eagle-topk 1 --speculative-num-draft-tokens 7`: `_handle_dspark` sets steps 1, top-k 1 and draft tokens to `--speculative-dspark-block-size` + 1.
- `--data-parallel-size 8 --enable-dp-attention`: `_handle_deprecated_dp_attention` resolves it to `--attn-dp-size 8`.
- `--served-model-name`: equals the `--model-path` default.

Benchmark-only controls such as synthetic acceptance and AIPerf orchestration were intentionally excluded:

- Benchmark env: `AIPERF_*`, `CONC`, `KV_OFFLOADING`, `AGENTIC_WARMUP_GRACE_PERIOD`. `AIPERF_HTTP_X_SMG_ROUTING_KEY_FROM_CORRELATION_ID` sets `X-SMG-Routing-Key`, which only the `consistent_hashing` and `manual` router policies read, not `cache_aware`.
- `SGLANG_TIMEOUT_KEEP_ALIVE=900`: Uvicorn's idle keep-alive; the recipe sets it to outlast AIPerf's pooled connections.
- `PYTHONNOUSERSITE=1`: container hygiene.
- `--enable-metrics`: server metrics that AIPerf scrapes (`AIPERF_REQUIRED_SERVER_METRIC_PREFIX`).
- Router: `--request-id-headers x-correlation-id` (AIPerf's tracing header), `--connect-timeout-secs 900` and `--request-timeout-secs 14400` (sized for the warmup drain), `--disable-health-check` and `--disable-retries` (measurement integrity).
- Synthetic acceptance and golden-AL injection come from the harness, not the recipe.

Image: `lmsysorg/sglang-rocm:v0.5.22-rocm720-mi35x-20261019` is active in the public `lmsysorg/sglang-rocm` repository (amd64 digest `sha256:8cb29fc407c2e46bdb1866c5edb91f109ac1acbbcb6905089beaa6c79b0813a2`, pushed 2026-10-19). Its image config shows a build from SGLang `main` with AITER `2bb549102ba2` and MORI `f39fa765e897`. It sets `HSA_NO_SCRATCH_RECLAIM=1`, which the recipe overrides, and does not set `GPU_MAX_HW_QUEUES`.

Left unchanged: the Install example and `dockerImages.mi355x` / `mi300x` stay on `-20261016`, because they serve Deploy-panel cells that #4315 did not rerun; §3.6 names `-20261019` itself. #45090 removes the retired `SGLANG_ENABLE_UNIFIED_RADIX_TREE=1` lines from these commands, and the new variables sit at the end of each block so the two PRs touch separate lines.
