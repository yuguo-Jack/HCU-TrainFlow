## Summary

In PD disaggregation, decode workers can now replicate decode-generated KV cache back to prefill workers, so future multi-turn requests can hit the prefill-side radix cache on the full previous conversation instead of only the original prompt.

This adds Mooncake-based Decode-to-Prefill (D2P) KV replication. The first version is gated behind:

```bash
--disaggregation-enable-d2p-kv-replication
```

For now, this path is supported only with `--disaggregation-transfer-backend mooncake`.

* D2P Mooncake KV manager
  * Add `D2PKVManager`, a reverse-direction Mooncake KV manager for D2P replication.
  * On the decode side, capture generated-token KV indices after decode completion and enqueue a D2P transfer request.
  * On the prefill side, receive decode-generated KV pages and insert them into the prefill radix cache.

* D2P bootstrap / protocol
  * Add a D2P bootstrap path using `disaggregation_bootstrap_port + 1`.
  * Add `D2P_REQ` handling in the Mooncake bootstrap thread.
  * Allow Mooncake transfer metadata to omit aux data for D2P, since this path transfers KV cache only.

* Scheduler integration
  * Initialize a reverse D2P manager on decode workers as the sender.
  * Initialize a reverse D2P manager on prefill workers as the receiver.
  * Connect the D2P receiver to the existing prefill Mooncake manager so incoming D2P requests can be dispatched from the bootstrap thread.
  * Poll pending D2P receiver work from the prefill scheduler event loop.

* Small response metadata plumbing
  * Expose `disagg_prefill_prefix_len` in generation responses so tests and users can observe prefill-side cache hits.
  * This field is threaded through several request/output files, but the change is intentionally small: it only carries the existing prefill prefix length through the response path.
  * The unit test depends on this field.

* Correctness / cleanup
  * Lock decode-side radix cache nodes while their KV pages are being replicated.
  * Release radix cache locks when D2P transfer succeeds or fails.
  * Skip D2P replication when no decode-generated tokens are available or when the peer connection is unavailable.
  * Free prefill-side allocations on receive failure.

## Interface

Enable D2P KV replication on both prefill and decode workers with:

```bash
--disaggregation-transfer-backend mooncake \
--disaggregation-enable-d2p-kv-replication
```

Decode workers should also enable decode-side radix cache:

```bash
--disaggregation-mode decode \
--disaggregation-transfer-backend mooncake \
--disaggregation-decode-enable-radix-cache \
--disaggregation-enable-d2p-kv-replication
```

Prefill workers run with:

```bash
--disaggregation-mode prefill \
--disaggregation-transfer-backend mooncake \
--disaggregation-enable-d2p-kv-replication
```
