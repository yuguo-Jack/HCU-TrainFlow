# [Fix] deepseek-v31: Parse standalone tool calls

[Upstream PR](https://github.com/sgl-project/sglang/pull/42298) · state: open · merged: False

## Original PR description

## Motivation

Fixes #42131. A tool call emitted in the format returned by `DeepSeekV31Detector.structure_info()` is currently returned as plain text in non-streaming mode because it lacks the outer section marker.

## Modifications

Accept both the section marker and individual call marker, as streaming already does. Preserve text before the first marker and leave the structural-tag format unchanged.

Add six regression tests covering the structural-tag round trip, both markers, wrapped and unwrapped parallel calls, plain text, malformed JSON, and streaming consistency.

## Validation

All six CPU detector tests pass. On the original detector, five test methods fail (six failing assertions/subtests). The test class was loaded in isolation with the real detector, protocol, and helpers; package startup imports were bypassed because xgrammar is unavailable. The full test module, grammar integration, and a live model/server were not run.
