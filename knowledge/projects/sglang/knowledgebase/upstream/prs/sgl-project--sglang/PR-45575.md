# [Fix] moe: Keep the DeepSeek V4.1 vision router off the packed-ids path under routing simulation

[Upstream PR](https://github.com/sgl-project/sglang/pull/45575) · state: closed · merged: True

## Original PR description

- `vision_topk` no longer takes the Flashinfer MXFP4 packed-ids branch while `SGLANG_SIMULATE_UNIFORM_EXPERTS` or `SGLANG_SIMULATE_ROUND_ROBIN_EXPERTS` is set. That branch returns the fused gate's `packed_topk`, written from the router's own choice, while #45628's override in `_finish_vision_topk` rewrites only `indices` and `weights`, so the packed consumer kept the unbalanced routing. `select_experts` already excludes this case (`_fused_gate_emits_packed_ids` checks `routing_overridden`).
- The rest of this PR (applying the override in `_finish_vision_topk`) landed in #45628; this PR is now that one-line follow-up.

No behavior change unless one of the two switches is set with the Flashinfer MXFP4 runner and no MegaMoE.
