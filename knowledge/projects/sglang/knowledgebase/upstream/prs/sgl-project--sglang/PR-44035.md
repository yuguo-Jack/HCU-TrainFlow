## Motivation
#44016, #44006 and #44007 need aiter features that are in aiter main but not in the current pin: the v4 nm latency model and persistent decode (ROCm/aiter#6126), the row-group FP4 MQA logits kernel (#6145) and the e8m0 mxscale bpreshuffle GEMM.

ROCm/aiter#6042 is merged into aiter main (57e2c6b42e). Needed by #44016, #44006, #44007.

## Modifications
- `AITER_COMMIT_DEFAULT` of the gfx950-rocm720 / gfx950-rocm724 stages -> 57e2c6b42e; other stages unchanged.
- The new pin already includes ROCm/aiter#6042, #5967 and #6007, so these two stages apply no aiter patches.

## Accuracy Tests
GSM8K: main 0.945 (current pin) -> 0.953 (02575f1c3a).
