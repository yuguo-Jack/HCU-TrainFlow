# [Session] Skip the KV free when page alignment empties a streaming-session rewind

[Upstream PR](https://github.com/sgl-project/sglang/pull/43183) · state: closed · merged: True

## Original PR description

## Motivation

`StreamingSession._free_kv_aligned` rounds the rewind target up to a page boundary before freeing `[start, end)`, but its early return still checks the unaligned target. When `ceil_align(target, page_size) >= end`, the aligned range is empty and the session hands `free_kv_row` nothing to free, yet the cache still coalesces the range, slices the token row and walks the segment-free path.

## Modifications

- Move the early return after the alignment and check `end <= start`, so an empty aligned range never reaches the cache. The set of freed slots is unchanged; only calls that already freed nothing are skipped.
- Add a parametrized unit test in `test_streaming_session_unit.py` that drives `_free_kv_aligned` with `page_size=16`: `(17, 20)` and `(17, 32)` make no call, `(17, 40)` frees `[32, 40)` and `(32, 48)` frees `[32, 48)`. The two empty cases fail on the previous ordering, which called the cache with `(32, 20)` and `(32, 32)`.
