# [CI] [NPU] precise-test: gate precision on PR judgeability, not bucket count

[Upstream PR](https://github.com/sgl-project/sglang/pull/46042) · state: closed · merged: True

## Original PR description

## Motivation

The NPU precise-test pipeline recommends tests from the coverage baseline, but its precision gate was keyed off "is any bucket non-empty" (`precision_mode = PRECISION_MODE and total_count > 0`). A PR that only touches a test file therefore fell back to the full a3 matrix whenever the recommendation landed outside the bucketed suites — e.g. editing a `base-a-test-npu` unit test, a nightly-only test, or deleting a test file.

In those cases no scheduled suite can ever run the recommended test, and a full run would not run it either, so the fallback was pure cost. This PR makes precision mode depend on whether the PR is *judgeable* instead of on the bucket count.

## Modifications

`scripts/ci/npu/precise-test/bucket_recommended_tests.py`

- Classify every changed path from `pr_changed_files.txt` into `product` / `test_case` / `test_infra` / `ci_infra` / `ignored`, then decide once: `full`, `skip_all`, or `precision`.
- Precision mode stays on for judgeable PRs even when every bucket is empty. A recommendation that no suite here contains is reported, not escalated.
- A full run is now reserved for signals that genuinely defeat the baseline: test/CI infrastructure changes (`conftest.py`, helpers, case configs, workflows, CI scripts, dependency manifests), a missing changed-file list (`test_selector.py` failed), and the existing multimodal baseline safety gate.
- An empty recommendation for judgeable changes now skips all suites (previously the skip-all rule also required every changed path to be under `python/sglang/`, so docs/examples noise defeated it).
- The step summary reports the decision, the paths that forced a full run, and the recommendations no suite in this workflow runs.

`.github/workflows/pr-test-npu.yml`

- Comment update only; no job wiring or CLI change.

Behavior matrix (a3 suites):

| PR change | before | after |
|---|---|---|
| registered base-b / base-c test file | run that file, skip others | unchanged |
| base-a / CPU unit test, nightly-only test, deleted test file | full matrix | all suites skipped, reported |
| conftest / helper / case config / workflow / CI script / dependency manifest | full | unchanged |
| recommend job failed / no diff available | full | unchanged |
