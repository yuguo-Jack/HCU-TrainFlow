## Motivation

## Modifications

The three commits of #43420, cherry-picked unchanged (`git range-diff` against #43420: 3/3 identical, no conflicts):

- `fix(multimodal)`: allow the shared enums in the safe unpickler.
- `refactor(move)`: move `Modality` and `MultimodalInputFormat` to `sglang.srt.multimodal.modality`; `schedule_batch` keeps exporting them, so existing imports work.
- `test(multimodal)`: `Modality` unpickles from both module paths.
