# [AMD] Update ROCm AITER pin to 2bb549102

[Upstream PR](https://github.com/sgl-project/sglang/pull/44379) · state: closed · merged: True

## Original PR description

## Motivation

Update the ROCm images from AITER e7d2453f2 to [ROCm/aiter@2bb549102](https://github.com/ROCm/aiter/commit/2bb549102ba2d9e51da8ef21107361827075d8b6). The new pin is 197 upstream commits ahead of the current default and is the candidate validated by AITER Scout #170 ([run 38083187535](https://github.com/sgl-project/sglang/actions/runs/38083187535)).


## Modifications

1. Update AITER_COMMIT_DEFAULT for all eight gfx942/gfx950 ROCm image flavors: e7d2453f2 → 2bb549102.

2. Update the gfx1250-rocm1000 stage from its separate pin a6d2b564 to the same 2bb549102, and update the stale comment that described it as a separate pin.

## Accuracy Tests

Not run locally; this Docker dependency update requires AMD GPU image/accuracy CI. Docker is not available in the local environment.

## Speed Tests and Profiling

Not run as a gate.
