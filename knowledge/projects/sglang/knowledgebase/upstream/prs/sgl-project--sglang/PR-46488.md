## Motivation

`preprocess_video` picks frame indices with `np.linspace(..., dtype=np.int64)`, which truncates, while qwen-vl-utils rounds to the nearest frame. The rounding was dropped in #12240 to avoid duplicates, but since `nframes <= total_frames`, rounding can't produce duplicates.

Example, 8 frames from a 200-frame video:
- before: `0, 28, 56, 85, 113, 142, 170, 199`
- after (= qwen-vl-utils): `0, 28, 57, 85, 114, 142, 171, 199`

**You may already be aware of this; if the truncation is intentional, please feel free to close this PR.**

## Modifications

Round with `np.rint` before casting to int64, and keep `np.unique`. Frame count and token count are unchanged. 

## Speed Tests and Profiling

No impact: only the index computation changes
