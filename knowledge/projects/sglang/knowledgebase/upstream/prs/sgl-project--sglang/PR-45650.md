# [Feat] cache: Add KVCR direct-device linker

[Upstream PR](https://github.com/sgl-project/sglang/pull/45650) · state: open · merged: False

## Original PR description

## Motivation

Add [KV Cache Runner (KVCR)](https://github.com/ai-dynamo/kvcr) as an optional direct-device linker for SGLang's unified cache. This enables router-guided KV reuse between workers without staging restores through HiCache. The direct linker and HiCacheStorage are independent integration paths.

## Modifications

- Add a KVCR direct-device linker with device-layout registration, local backup and peer restore.
- Forward request-scoped source hints and publish KVCR-owned inventory separately from framework cache events, so Dynamo can identify valid peer sources.
- Coordinate transfer ownership, completion and bounded deposits, with regression coverage for linker operations and inventory publication.
- Add linker documentation and configuration. This builds on work by Lin Hu and Moein Khazraee.

Build and usage guide: [KVCR #129](https://github.com/ai-dynamo/kvcr/pull/129). Dynamo integration: [Dynamo #17655](https://github.com/ai-dynamo/dynamo/pull/17655).

**Known limitation:** Externally restored prefixes are currently backed up into the destination KVCR again. Preserving no-retain behavior remains a merge gate.

**Review dependency:** The diff against `main` includes the shared linker contracts from [#45648](https://github.com/sgl-project/sglang/pull/45648), which is closed without merging. The stack needs to be reconciled with upstream before this PR can merge; the current PR also has merge conflicts.

## Accuracy Tests

- Linker unit tests: **42 passed**, plus **43 subtests**.
- Qwen3-32B BF16, two TP1 workers on two B200 nodes: a genuine router-generated peer hint restored **1,984/2,048 tokens**, with **8 matching output token IDs** and a successful **520,093,696-byte** peer transfer over RDMA. The destination was explicitly selected by the test.
- Verified KVCR source eviction and owner clearing; a subsequent request had no active peer hint and no reuse.
- The E2E used verified source overlays, including the two compatibility files in the current PR head; it did not run the rebased quick-start image or guide verbatim. Validation is limited to the tested dense model and TP1 topology.
