# [Perf] pd: Copy prebuilt decode batch inputs to the GPU without host syncs

[Upstream PR](https://github.com/sgl-project/sglang/pull/44598) · state: closed · merged: True

## Original PR description

- Add `async_h2d_stack(tensors, *, device)` next to `async_h2d`: stacks per-request host tensors straight into pinned memory and moves them with one non-blocking copy; tensors already on a device are stacked there
- `build_eagle_disagg_draft_input`: `topk_p`, `topk_index`, `hidden_states` and the DSA seed rows go through `async_h2d_stack` instead of a per-request `torch.as_tensor(..., device=...)` / pageable `.to(device)` from the unpinned CPU metadata buffers
- `prepare_for_prebuilt`: `req_pool_indices`, `seq_lens` and `orig_seq_lens` go through `async_h2d` instead of `torch.tensor(list, device=...)`; `process_prebuilt` builds `last_tokens_tensor` with `async_h2d` instead of the same pattern written inline

Each replaced copy ran `cudaStreamSynchronize` on the schedule stream, which under overlap blocks the host until the in-flight forward clears the schedule stream's wait.

No behavior change: the copied values, dtypes and devices are identical.

Verification: on DeepSeek-V4-Flash, PD decode, EAGLE (3 steps, topk 1), TP4, 128 concurrent requests, step time is unchanged on its own (32.2 ms before and after), since an earlier blocking copy in decode preallocation absorbs the same wait; the host-side syncs in these functions are gone. `test_disaggregation_wire.py` and `test_pd_eagle_draft_proposal.py` pass.
