# Fix DSA kpool EXTEND autotune dummy run outside forward context

[Upstream PR](https://github.com/sgl-project/sglang/pull/42636) · state: closed · merged: False

## Original PR description

## Summary

`SGLANG_FLASHINFER_AUTOTUNE_EXTEND=1` crashed at startup on DSA kpool models (e.g. GLM-5.3-Flash) with `no forward context active`. `_dummy_run` initialized attention metadata outside `forward_context`, and the kpool extend planner reads the request pool from it. It now runs inside the context, matching the real forward paths.
