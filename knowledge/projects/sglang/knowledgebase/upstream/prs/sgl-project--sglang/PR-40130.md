# fix: disable prefill cuda graph on low memory with quantized kv

[Upstream PR](https://github.com/sgl-project/sglang/pull/40130) · state: closed · merged: False

## Original PR description

Fixes #40094

This adds a budget check to automatically disable the prefill CUDA graph when the available memory is lower than the estimated transient memory required for dequantizing the KV cache. This prevents stalls and out of memory issues on memory constrained GPUs.
