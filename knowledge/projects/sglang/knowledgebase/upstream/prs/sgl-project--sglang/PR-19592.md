# [AMD] Fix tilelang NSA crash caused by unpinned tvm-ffi in CI install script

[Upstream PR](https://github.com/sgl-project/sglang/pull/19592) · state: closed · merged: False

## Original PR description

The CI install script (amd_ci_install_dependency.sh) installed apache-tvm-ffi from latest main without a version pin. On Feb 27, tvm-ffi PR #480 merged a breaking metaclass change (_ObjectSlotsMeta) that corrupted isinstance checks for TVM objects, causing tilelang's is_var() to crash with:
  AttributeError: 'Var' object has no attribute 'scope'

This broke all NSA-tilelang models (GLM-5, DeepSeek-V3.2, etc.) on AMD CI starting from the Feb 28 nightly.

Fix:
1. Pin tvm-ffi to commit 37d0485b (matching docker/rocm.Dockerfile) in the CI install script.
2. Add a defense-in-depth hasattr guard on tilelang's is_var() to prevent future tvm-ffi breaking changes from crashing the server.

Catching a broad `Exception` and silently passing can hide unexpected errors and make debugging more difficult. It's better to catch more specific exceptions that you expect to handle, such as `ImportError` if the module path changes or `AttributeError` if the `is_var` function is removed or renamed in a future `tilelang` version.

```suggestion
except (ImportError, AttributeError):
    pass
```
