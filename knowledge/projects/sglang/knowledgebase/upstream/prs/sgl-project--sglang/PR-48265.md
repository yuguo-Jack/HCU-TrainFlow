# [CI] [AMD] miles: Split the MI30x 4-GPU nightly into two jobs

[Upstream PR](https://github.com/sgl-project/sglang/pull/48265) · state: closed · merged: True

## Original PR description

## Motivation

The `nightly-stage-c-4-gpu-mi350` job in the MI30X Miles nightly is the last unsplit 4- or 8-GPU Miles suite, and it has not finished on any night since at least 10-24. On ten of the eleven runs that weren't cancelled, it ended with "The self-hosted runner lost communication with the server". Each loss was on a different runner, always after 13-16 tests and 2h46-4h00 into the job. On 11-01 it hit the 300-minute step timeout instead, because a server crash fixed by #47926 made several tests time out.

| Night | Test running when the runner was lost |
|---|---|
| [10-24](https://github.com/sgl-project/sglang/actions/runs/40132792002) | 14/29 `test_qwen3_4B_variable_gbs.py` |
| [10-29](https://github.com/sgl-project/sglang/actions/runs/40964068276) | 16/30 `test_nospec_nor3_bf16_sgl_dpattn2x2_meg_tp2pp2.py` |
| [10-31](https://github.com/sgl-project/sglang/actions/runs/41246924943) | 15/30 `test_qwen3_4B_variable_gbs.py` |
| [11-02, attempts 1 and 3](https://github.com/sgl-project/sglang/actions/runs/41542033993) | 13/32 `test_qwen3_4B_muon_offload_disk.py` |

The runner is lost at whichever test is running after that many tests, and those tests pass on other nights, so this looks like a resource that builds up across the job rather than one bad test. I have not confirmed which resource; the job logs show no disk or OOM errors. Separately, the suite's estimates in miles `main` add up to about 423 min, so as one job it cannot finish within its 300-minute timeout either way.

## Modifications

Split the MI30X 4-GPU suite into two jobs with `--auto-partition-id/--auto-partition-size`, the same way the MI30X 8-GPU suite and the MI35X 4-GPU suite are already split. With the current estimates the halves are 16 and 17 tests at about 212 min each. The MI30X runtimes measured so far cover 16 of the 33 tests and add up to 108 and 115 min.

## Test plan

- [ ] Next MI30X Miles nightly: both 4-GPU parts finish without losing their runner.
