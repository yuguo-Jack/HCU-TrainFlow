# [Fix] multimodal_gen: Fix dynamic-batching bugs - non-output-rank split, OOM memory climb

[Upstream PR](https://github.com/sgl-project/sglang/pull/43750) · state: open · merged: False

## Original PR description

Two bugs in diffusion dynamic batching (`multimodal_gen`), reproduced on CUDA (2x A100) and XPU (Arc Pro B60):

1. **False split failure on non-output ranks.** `_split_batched_output()` expects `output` or `output_file_paths`, but only the output rank sets them. Every successful dynamic batch on a multi-GPU replica therefore logs `Failed to split dynamic batched output cleanly` on each non-output rank, even though all requests succeed.
2. **Device cache not released after a failed forward.** `empty_cache()` runs inside the `except` clause, while the traceback still holds the failed forward's tensors. Their memory stays reserved (2 GiB in the repro below) after the error.

## Modifications

- `scheduler.py`: run the "no outputs" check in `_split_batched_output()` only on the output rank.
- `gpu_worker.py`: move `gc.collect()` + `empty_cache()` after the `try/except/finally`, once the exception is out of scope.
- Tests: add a `worker` stub to the existing `Scheduler` test stubs, and add `test_dynamic_batch_split_succeeds_on_non_output_rank`.
