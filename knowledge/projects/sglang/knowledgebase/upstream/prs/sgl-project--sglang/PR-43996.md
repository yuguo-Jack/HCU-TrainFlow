# [Feat] [NPU] speculative: support NGRAM decoding for MHA and MLA

[Upstream PR](https://github.com/sgl-project/sglang/pull/43996) · state: open · merged: False

## Original PR description

## Motivation

NGRAM produces dynamic verification trees without a draft model. Ascend currently rejects its corpus options, and simply opening the device guard leaves tree attention, verification, and accepted KV relocation incomplete. This PR enables the complete path for full-attention MHA/GQA and dense MLA target models.

Kernel dependency: https://github.com/sgl-project/sgl-kernel-npu/pull/854, tested at `674b503190c98c4114fa6c26806d36824cb736aa`. The reconstruction proposed in kernel PR #484 alone does not provide this serving path.

## Modifications

- Reuse the existing shared CPU trie/SAM and CUDA/CPU configuration checks for all eight corpus options. NPU uses eager execution and synchronous scheduling.
- Import `build_ngram_attention_mask` from `sgl_kernel_npu.attention.ngram_attention` only inside the NGRAM target-verification metadata branch. Both the builder and its Triton kernel live in the kernel repository; the Ascend backend retains no mask implementation or forwarding wrapper.
- Verify MHA/GQA with paged BSH full-mask FIA. Verify dense MLA with latent+RoPE TND FIA, including query-head padding and ND/NZ cache layouts.
- Relocate accepted KV rows with source snapshots before overlapping writes. MLA relocates both compressed latent and independent RoPE storage, using physical NZ tile indices when required.
- Remove the blanket MLA rejection and consolidate the four NGRAM-specific backend error sites into two capability checks. Retain checks for unsupported attention/cache semantics and parallelism, including DCP, which requires local/global KV slot translation.
- Document the supported scope and add kernel-mask, MLA attention/cache, configuration, and real-model regressions.

Supported KV types are FP16/BF16; W8A8 target weights are independent of KV dtype. Sliding-window/linear attention, sparse indexed MLA, sinks, ALiBi, logit capping, PP/CP/DCP, and chain rejection sampling remain unsupported. The existing NGRAM DP-attention restriction remains in place.

## Accuracy Tests

Machine 151, Linux, Ascend910_9362, CANN 9.1 B083, TP=1. Framework commit `4ec6cbf704a02e654f67c9e0131c2884f4a402b2` and companion kernel commit `674b503190c98c4114fa6c26806d36824cb736aa` were tested together.

- **78 regressions passed:** 44 shared CPU corpus tests, 6 NPU framework tests, and 28 kernel tests.
- **Qwen3-0.6B BF16:** all eight corpus-option variants matched the non-speculative baseline for **2,304 greedy tokens**.
- **DeepSeek-V2-Lite-W8A8, BF16 KV:** all eight variants matched the FIA non-speculative baseline for **2,304 greedy tokens**.
- Both matrices also completed eight stochastic cases each, with temperature 0.7, top-k 10, top-p 0.9, and 24 tokens.
- MLA default and root-only generation each matched the corresponding baseline for 288 tokens in **both ND and NZ layouts** (1,152 additional compared tokens).
- Independent FP32 CPU attention oracles cover FP16/BF16, padded query heads (12→16), branching masks, ragged prefixes, nonconsecutive pages, and a page-crossing draft block. Cache tests cover two layers and overlapping source/destination cycles in ND/NZ.
- A fresh backend import with the older kernel package succeeds without loading the new mask module, checking that the dependency is lazy.
- Ruff/isort, kernel Black checks, `git diff --check`, Mintlify build validation, and broken-link checks passed.

For MLA baseline comparisons, use `ASCEND_USE_FIA=true` on both sides: the legacy paged MLA decoder and FIA round BF16 results differently. Exact greedy text also varies on near-tied free-form continuations across verification shapes. In a diagnostic prompt requesting ten integers, token 33 after the requested list ranked token 1679 over 9081 by 0.0625 log-prob in the baseline; depth=8 reversed the ordering. The second batch agreed again. The registered MLA matrix uses a continuing sequence for this prompt so the full 48-token comparison stays inside the specified task. Prompts and log-prob deltas are recorded in the validation artifacts. CPU-oracle numerical checks independently validate attention semantics.

2. 在同一目录生成完整的 `manual_gsm8k.py`。其中 `--mode prepare` 是数据集下载入口：下载官方 GSM8K 训练集/测试集到本地，校验数量，并生成训练集外部语料和哈希清单；评测模式只读取本地文件。

```bash
cat > manual_gsm8k.py <<'NGRAM_GSM8K_PY_EOF'
"""Offline, paired GSM8K regression evaluation for the NPU NGRAM PRs.

Protocol: five train examples, raw completion, greedy, no calculator, strict
numeric answer after ####. This is a paired regression protocol, not a claim
to reproduce a model vendor's chat/thinking benchmark score.
"""

import argparse
import hashlib
import json
import os
import random
import re
import ssl
import subprocess
import sys
import time
import urllib.error
import urllib.request
from decimal import Decimal, InvalidOperation
from fractions import Fraction
from pathlib import Path


ROOT = Path(__file__).resolve().parent
BASE_URL = "https://raw.githubusercontent.com/openai/grade-school-math/master/grade_school_math/data"
DATA_SPLITS = {
    "train": (7473, "17f347dc51477c50d4efb83959dbb7c56297aba886e5544ee2aaed3024813465"),
    "test": (1319, "3730d312f6e3440559ace48831e51066acaca737f6eabec99bccb9e4b3c39d14"),
}
FIELDS = {
    "min_bfs_breadth": int,
    "max_bfs_breadth": int,
    "match_type": str,
    "max_trie_depth": int,
    "capacity": int,
    "external_corpus_path": str,
    "external_sam_budget": int,
    "external_corpus_max_tokens": int,
}
CASE_NAMES = ["default"] + list(FIELDS)
NUMBER = r"[-+]?(?:\d[\d,]*(?:\.\d+)?|\.\d+)"


def write_json(path, value):
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(value, ensure_ascii=False, indent=2), encoding="utf-8")


def read_jsonl(path):
    with path.open(encoding="utf-8") as handle:
        return [json.loads(line) for line in handle if line.strip()]


def sha256(path):
    return hashlib.sha256(path.read_bytes()).hexdigest()


def clean_answer(text):
    return re.sub(r"<<.*?>>", "", text)


def extract_answer(text, strict=True):
    if strict:
        matches = re.findall(r"####\s*(" + NUMBER + r")(?:\s*/\s*(" + NUMBER + r"))?(?![\w/])", text)
    else:
        matches = re.findall(NUMBER, text)
    if not matches:
        return None
    try:
        numerator, denominator = matches[-1] if strict else (matches[-1], "")
        number = Fraction(Decimal(numerator.replace(",", "")))
        if denominator:
            number /= Fraction(Decimal(denominator.replace(",", "")))
        return str(number)
    except (InvalidOperation, ZeroDivisionError, ValueError, OverflowError):
        return None


def prepare(data_dir, ca_file=None, insecure_download=False):
    if ca_file is not None and insecure_download:
        raise ValueError("Choose either --ca-file or --insecure-download")
    data_dir.mkdir(parents=True, exist_ok=True)
    context = None
    for split, (count, expected_sha256) in DATA_SPLITS.items():
        path = data_dir / (split + ".jsonl")
        if not path.exists():
            if context is None:
                context = ssl.create_default_context()
                if ca_file is not None:
                    context.load_verify_locations(cafile=str(ca_file))
                if insecure_download:
                    context.check_hostname = False
                    context.verify_mode = ssl.CERT_NONE
                    print("TLS verification disabled for this dataset download only; "
                          "pinned SHA256 verification is mandatory.", flush=True)
            print("Downloading " + split, flush=True)
            request = urllib.request.Request(
                BASE_URL + "/" + split + ".jsonl",
                headers={"User-Agent": "ngram-gsm8k-validation"},
            )
            try:
                with urllib.request.urlopen(request, timeout=45, context=context) as response:
                    payload = response.read()
            except urllib.error.URLError as error:
                if isinstance(error.reason, ssl.SSLCertVerificationError):
                    raise RuntimeError(
                        "Dataset TLS certificate verification failed. Supply your trusted "
                        "proxy/root CA with --ca-file /path/to/ca.pem (or SSL_CERT_FILE), "
                        "or explicitly use --insecure-download for this public dataset; "
                        "the pinned SHA256 check remains mandatory."
                    ) from error
                raise
            if hashlib.sha256(payload).hexdigest() != expected_sha256:
                raise RuntimeError("GSM8K SHA256 mismatch; refusing to save " + split)
            staging = path.with_suffix(".download")
            staging.write_bytes(payload)
            if len(read_jsonl(staging)) != count:
                raise RuntimeError("Unexpected GSM8K split size: " + split)
            staging.replace(path)
        if sha256(path) != expected_sha256:
            raise RuntimeError("GSM8K SHA256 mismatch for local file: " + str(path)
                               + ". Use the unmodified official JSONL file.")
        rows = read_jsonl(path)
        if len(rows) != count or any(extract_answer(row["answer"]) is None for row in rows):
            raise RuntimeError("Invalid GSM8K data: " + str(path))
    # External retrieval uses training data only; never preload test answers.
    corpus = data_dir / "train-corpus.jsonl"
    with corpus.open("w", encoding="utf-8", newline="\n") as handle:
        for row in read_jsonl(data_dir / "train.jsonl")[:256]:
            document = "Question: " + row["question"] + "\nAnswer: " + clean_answer(row["answer"])
            handle.write(json.dumps(document, ensure_ascii=False) + "\n")
    manifest = {
        split: {"rows": len(read_jsonl(data_dir / (split + ".jsonl"))),
                "sha256": sha256(data_dir / (split + ".jsonl"))}
        for split in ("train", "test")
    }
    manifest["external_corpus"] = {"train_examples": 256, "sha256": sha256(corpus)}
    write_json(data_dir / "manifest.json", manifest)
    print(json.dumps(manifest, indent=2), flush=True)


def aggregate(records, seconds):
    total = len(records)
    counts = {
        name: sum(row["meta_info"].get(name, 0) or 0 for row in records)
        for name in ("completion_tokens", "spec_verify_ct", "spec_num_correct_drafts",
                     "spec_num_proposed_drafts")
    }
    proposed = counts["spec_num_proposed_drafts"]
    verifies = counts["spec_verify_ct"]
    return {
        "questions": total,
        "correct": sum(row["correct"] for row in records),
        "accuracy": sum(row["correct"] for row in records) / total,
        "invalid_answers": sum(row["prediction"] is None for row in records),
        "last_number_fallback_accuracy": sum(row["fallback_correct"] for row in records) / total,
        "truncated": sum(row["meta_info"].get("finish_reason", {}).get("type") == "length"
                         for row in records),
        **counts,
        "spec_accept_rate": counts["spec_num_correct_drafts"] / proposed if proposed else None,
        "spec_accept_length": counts["completion_tokens"] / verifies if verifies else None,
        "generation_seconds": seconds,
        "generation_tokens_per_second": counts["completion_tokens"] / seconds if seconds else None,
    }


def worker(args):
    # Set this before importing sglang/torch or spawning scheduler processes.
    os.environ["ASCEND_USE_FIA"] = "true"
    import sglang as sgl
    from transformers import AutoTokenizer

    train = read_jsonl(args.data_dir / "train.jsonl")
    test = read_jsonl(args.data_dir / "test.jsonl")
    if not 1 <= args.num_questions <= len(test):
        raise ValueError("num-questions must be between 1 and " + str(len(test)))
    rng = random.Random(args.seed)
    indices = list(range(len(test)))
    rng.shuffle(indices)
    indices = indices[:args.num_questions]
    prefix = "Solve each problem step by step. End each answer with #### followed by the final number.\n\n"
    for row in train[:args.num_shots]:
        prefix += "Question: " + row["question"] + "\nAnswer: " + clean_answer(row["answer"]) + "\n\n"
    prompts = [prefix + "Question: " + test[i]["question"] + "\nAnswer:" for i in indices]
    tokenizer = AutoTokenizer.from_pretrained(args.model, trust_remote_code=True)
    input_ids = tokenizer(prompts, add_special_tokens=True)["input_ids"]
    longest = max(map(len, input_ids))
    if longest + args.max_new_tokens > args.context_length:
        raise ValueError("Increase --context-length: prompt max=%d, output cap=%d" %
                         (longest, args.max_new_tokens))
    if args.max_total_tokens < args.batch_size * (longest + args.max_new_tokens):
        raise ValueError("Increase --max-total-tokens or lower --batch-size")
    options = dict(model_path=args.model, device="npu", attention_backend="ascend",
                   trust_remote_code=True, dtype="bfloat16", random_seed=args.seed,

def compare(args, cases):
    baseline_rows = read_jsonl(args.output_dir / "baseline.jsonl")
    baseline = {row["index"]: row for row in baseline_rows}
    base_summary = json.loads((args.output_dir / "baseline.summary.json").read_text())
    report = {"baseline": base_summary, "cases": {}, "allowed_accuracy_drop_pp": args.allowed_accuracy_drop_pp}
    passed = True
    for case in cases:
        rows = read_jsonl(args.output_dir / (case + ".jsonl"))
        summary = json.loads((args.output_dir / (case + ".summary.json")).read_text())
        for field in ("protocol", "test_sha256", "train_sha256", "prompt_ids_sha256", "seed", "num_shots",
                      "max_new_tokens", "batch_size"):
            if summary[field] != base_summary[field]:
                raise RuntimeError("Unmatched comparison config: " + field)
        if len(rows) != len(baseline) or {row["index"] for row in rows} != set(baseline):
            raise RuntimeError("Unmatched question sets")
        lost = [row["index"] for row in rows if baseline[row["index"]]["correct"] and not row["correct"]]
        gained = [row["index"] for row in rows if not baseline[row["index"]]["correct"] and row["correct"]]
        differences = [dict(index=row["index"], baseline=baseline[row["index"]], ngram=row)
                       for row in rows if row["output_ids"] != baseline[row["index"]]["output_ids"]]
        delta_pp = 100 * (summary["accuracy"] - base_summary["accuracy"])
        ok = delta_pp >= -args.allowed_accuracy_drop_pp - 1e-10
        passed &= ok
        report["cases"][case] = {
            **summary, "accuracy_delta_pp": delta_pp, "baseline_correct_ngram_wrong": lost,
            "baseline_wrong_ngram_correct": gained, "different_output_ids": len(differences),
            "throughput_ratio": summary["generation_tokens_per_second"] / base_summary["generation_tokens_per_second"],
            "accuracy_gate_pass": ok,
        }
        write_json(args.output_dir / (case + ".differences.json"), differences)
    report["accuracy_gate_pass"] = passed
    write_json(args.output_dir / "comparison.json", report)
    print(json.dumps(report, ensure_ascii=False, indent=2), flush=True)
    return 0 if passed else 2
```
