# Fuse temperature scaling and softmax in the flashinfer sampler path

[Upstream PR](https://github.com/sgl-project/sglang/pull/41050) · state: closed · merged: False

## Original PR description

https://github.com/sgl-project/sglang/pull/20501#issuecomment-4173745103

## Motivation
When using the FlashInfer backend, replace the separate temperature division, softmax, and copy-back with FlashInfer’s fused temperature-aware softmax. This should reduce kernel launches and intermediate memory traffic while preserving the existing behavior of all other branches, including the deterministic path.


## Modifications

```
            is_cuda()
            and get_exec().kernel.sampling_backend == "flashinfer"
            and not self.enable_deterministic
```
in this case, enable flashinfer softmax.
