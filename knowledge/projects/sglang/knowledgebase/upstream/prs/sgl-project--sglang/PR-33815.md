## Motivation

This PR adds a CPU kernel of rotary embedding for SGLang Diffusion.

The new kernel replaces the native PyTorch fallback on CPU.

## Modifications

Add a CPU rotary embedding kernel for diffusion workloads.
Add unit tests covering 3D and 4D inputs and multiple dtype combinations.
