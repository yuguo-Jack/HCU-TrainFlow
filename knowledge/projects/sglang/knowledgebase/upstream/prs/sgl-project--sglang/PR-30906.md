# Add deterministic sampling kernel tests

[Upstream PR](https://github.com/sgl-project/sglang/pull/30906) · state: closed · merged: False

## Original PR description

## Motivation

`murmur_hash32` and `multinomial_with_seed` are core to seeded deterministic sampling, but they do not have direct model-free kernel regression coverage. Existing server tests can detect output divergence, but they do not isolate hash parity or per-request batch invariance.

## Changes

- Add an independent Python MurmurHash3 reference implementation matching the four-block `(seed_low, seed_high, position, token_id)` layout.
- Compare the Triton kernel bit-for-bit against the reference at widths `1023`, `1024`, and `1025` around its block boundary.
- Preserve the known `seed=7847, position=12345, token_id=1208 -> UINT32_MAX` vector from issue #25106.
- Verify deterministic sampling across replay, split batches, single-row execution, and row permutation.
- Cover negative seed wrapping and position truncation beyond 32 bits.

The tests do not launch a server or load model weights.

## Scope

This PR does not change production sampling or the Gumbel normalization. It is independent of the fix proposed in #25133.

## Testing
