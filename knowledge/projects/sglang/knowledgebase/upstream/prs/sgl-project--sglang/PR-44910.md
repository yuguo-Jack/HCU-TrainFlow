# [Perf] [XPU] gemma4: Use native GEMM for wide BF16 prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/44910) · state: open · merged: False

## Original PR description

## Motivation

Use the optimized native gate/up GEMM for Gemma4's wide BF16 prefill at M=4096 when the installed binary confirms that specialization is available. Older binaries expose the generic tensor API with a slower large-M implementation, so API presence alone cannot select this route safely.

Stacked on [#44908](https://github.com/sgl-project/sglang/pull/44908), with native specialization/query dependency [sgl-kernel-xpu #558](https://github.com/sgl-project/sgl-kernel-xpu/pull/558). Parent is `ebc9d547`; tested child is `8b1ce6ce`.

## Modifications

- Resolve the binary-backed shape query during construction, outside compiled/captured forward. Select only BF16 B70, TP1, unquantized M4096/K1536/concatenated-N24576 wide MLPs under the parent's existing backend, hook, delegated-method, device and gradient guards.
- Reuse the parent's single 128 KiB table across all 35 MLPs. The 20 wide MLPs can use fused projection/lookup; the 15 narrow MLPs keep Torch projection plus lookup. Missing/false queries retain the parent route; M128 keeps its existing route.
- Add the public GEMM namespace entry and actual-wheel tests for native/fullgraph/capture execution, changed inputs/weights, aligned and offset views, shared ownership and legacy-wheel fallback.

Weights and the BF16 projection/activation rounding boundaries are preserved. The kernel implementation and M-fast scheduling live in native #558.

## Accuracy Tests

- Precommit passes; 72 namespace checks and 11 XPU model/public-activation tests pass against the actual isolated native wheel. Native compilation retains the actual operator across input/weight offsets 0/1/32; captured misalignment copies consume changed operands on poisoned replay. Constructor-time missing/false-query cases keep the standalone lookup.
- In the serving ABBA, all 480 timed prefill completions match output IDs/text across the four arms. All 16 compatibility prompts per arm return complete nonempty 16-token responses; IDs/text and every returned selected/top-five logprob field match across all four arms.
- Native #558 separately validates all 20 trained wide layers at M4096 across three activation scales against its previous implementation and the FP32/Torch references.

This draft inherits #44908's unresolved broader quality/determinism review. The serving checks above are bounded compatibility evidence, not a new model-quality evaluation; no additional 200-question evaluation was run for this child.

## Speed Tests and Profiling

One same-GPU ABBA on Intel B70, pinned Gemma4-E2B BF16 target/assistant, TP1/NEXTN (3 steps, 4 draft tokens), server `--random-seed 42`, direct-request `sampling_seed=42`, and benchmark `--seed 42`. Each arm uses four uncached warmups per workload and 24 interleaved samples per workload; each prompt has 4096 input tokens and one output token. Both candidate blocks beat both controls.

| Uncached request wall time | Control A1 | Candidate B1 | Candidate B2 | Control A2 | Reduction vs mean controls |
|---|---:|---:|---:|---:|---:|
| 1×4096, ms | 191.462 | 187.689 | 187.221 | 191.749 | 2.17% |
| 4 queued×4096, ms | 753.209 | 738.054 | 738.103 | 753.104 | 2.00% |

Control drift is +0.15% / −0.014%. A separate CPU+XPU preflight proves 20 actual wide 128×128×32 native kernels, 20 matching CPU operation shapes, and 15 lookup kernels; startup records show 35 lookup slots, 20 wide-native slots, 15 narrow-none slots and one shared table. The preflight retires before timing; no forward hooks or timing observers are installed.

Canonical c8 warm/measured blocks each complete 64 requests×128 tokens with zero errors and explicit per-request cache fields. Reported TPOT is 0.54% lower within 1.06% control drift; the 56 common-text cases across all four arms show 0.31% lower saved streaming-ITL metric within 0.96% drift. **No decode speedup claim.**

Serving uses the exact #558 BMG kernel, registration and AST-extracted public API/query/Fake on the original featureful wheel, identically in both arms. All 87 original and two sidecar binary hashes/mappings and source immutability checks are retained. This is an exact-source sidecar result, not a full released-wheel serving result. The default path remains the parent fallback when the fast binary capability is unavailable.

Independent analysis reproduced every prefill/compatibility output, cache/length/error vectors, common-text/drift calculation and recorded binary provenance. All five servers retired; independent scans confirm no experiment owners, orphans or listener. Scope is this pinned workload/hardware and one paired ABBA.
