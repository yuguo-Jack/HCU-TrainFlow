# [Test] [AMD] diffusion: Expect CUDA-only fast paths to be off on ROCm in kernel tests

[Upstream PR](https://github.com/sgl-project/sglang/pull/44311) · state: closed · merged: True

## Original PR description

## What

Follow-up to #40660. Update the remaining ROCm failures in `test_modulate.py` and `test_model_fast_paths.py` so they expect the CUDA-only fast paths to be off on ROCm. With this change the `nightly-test-1-gpu-kernel` job passes on ROCm.

## Why

Both files are in `nightly-amd-kernel-1-gpu`. After #40660, `test_modulate.py` still had 104 failing cases on ROCm and `test_model_fast_paths.py` had 5. Each one asserts a fast path that is off on ROCm, and in each case the output still matches eager:

- `can_use_modulate_scale_shift_cuda` and `can_use_residual_gate_add_cuda` return False under HIP, and `try_fused_scaled_residual_add_exact` returns None off CUDA.
- `Timesteps.forward` only uses the JIT `timestep_embedding` on CUDA and uses diffusers' implementation otherwise. On HIP the JIT kernel doesn't build.
- The Qwen VAE fused cat+pad and the Qwen-Image 2.1 fused Q/K norm and LayerNorm modulation are gated on `is_cuda()`. The Hunyuan QK norm needs FlashInfer CuTe. On HIP, the ERNIE fused QKNorm+RoPE JIT kernel fails to build, so its gate disables itself and the call falls back to eager.

Changes on ROCm:
- `test_modulate.py`: `test_modulate_scale_shift_matches_eager`, `test_modulate_scale_shift_accepts_adaln_chunk_views` and `test_residual_gate_add_batched_rows` assert that the fast path is rejected and that the public wrapper still matches eager. `test_residual_gate_add_batched_rows_cuda_graph`, `test_scaled_residual_add_is_bit_exact` and `test_timestep_embedding_matches_diffusers` call the CUDA kernel directly and are skipped.
- `test_model_fast_paths.py`: the five cases that assert the fused path engaged are skipped. This follows the file's existing convention (`requires_inline_ptx`): the eager fallback stays covered by the neighboring tests, such as `test_ernie_qknorm_rope_first_attempt_exception_uses_pristine_inputs` and `test_hunyuan_quality_qknorm_stays_unmounted_without_cute_kernel`.

NVIDIA behavior is unchanged. The two modulate tests now also check the public `modulate_scale_shift` wrapper on NVIDIA.

## Test plan

ROCm, MI300, rocm10, at `ceeda9922a`: [nightly-test-1-gpu-kernel](https://github.com/sgl-project/sglang/actions/runs/38597193680/job/115966863434) passes, 19/19 files.
- `test_modulate.py`: 84 passed, 97 skipped (104 failing on main).
- `test_model_fast_paths.py`: 37 passed, 53 skipped (5 failing on main).

Not run on NVIDIA.
