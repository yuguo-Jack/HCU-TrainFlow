## Original PR description

## Motivation

Restore Muse Spark NVFP4 + DFlash2 B300 PD coverage in a small follow-up to #44666. The merged PR temporarily disabled this file after [job 117611788593](https://github.com/sgl-project/sglang/actions/runs/39099912264/job/117611788593) failed during server startup: the log shows whole-model Hugging Face cache cleanup immediately before tokenizer loading failed, consistent with a concurrent cache cleanup race.

This PR is now based directly on `main` after #44666 merged, and changes only the test's CI registration. The cache cleanup race still needs validation or a fix before merging this re-enable.

## Modifications

Remove the temporary `disabled` registration from `test_muse_spark_12_b300_pd.py`, restoring its `base-c` / `8-gpu-b300` scheduling. The file is byte-for-byte identical to the version before the temporary skip; all test cases and server settings are preserved.

## Accuracy Tests

- CI registry parsing confirms that this PR enables the test and the merged baseline skips it.
- After rebasing onto `main`, Python syntax validation, pre-commit and `git diff --check` pass; stable patch ID and range diff confirm that the one-file patch is unchanged.
- Full 8x B300 accuracy/performance results remain pending CI; the prior startup failure ran zero tests.

## Speed Tests and Profiling
