# [CI] tests: Re-enable muse spark B300 PD coverage

[Upstream PR](https://github.com/sgl-project/sglang/pull/44975) · state: closed · merged: True

## Original PR description

## Motivation

Restore Muse Spark NVFP4 + DFlash2 B300 PD coverage in a small follow-up to #44666. The merged PR temporarily disabled this file after [job 117611788593](https://github.com/sgl-project/sglang/actions/runs/39099912264/job/117611788593) failed during server startup: the log shows whole-model Hugging Face cache cleanup immediately before tokenizer loading failed, consistent with a concurrent cache cleanup race.

This PR is now based directly on `main` after #44666 merged, and changes only the test's CI registration. The targeted B300 rerun passed; this PR does not change the cache cleanup implementation.

## Modifications

Remove the temporary `disabled` registration from `test_muse_spark_12_b300_pd.py`, restoring its `base-c` / `8-gpu-b300` scheduling. Set `est_time` from **900 to 800 seconds**, rounding up the CI runner's measured **769-second** file runtime. All test cases, server settings and thresholds are preserved.

## Accuracy Tests

- CI registry parsing confirms that this PR enables the test and the merged baseline skips it.
- Python syntax validation, pre-commit (including CI registry validation) and `git diff --check` pass after the estimate update.
- [B300 rerun job 117911539097](https://github.com/sgl-project/sglang/actions/runs/39206849872/job/117911539097) passed all **3 tests** in **746.859 seconds**, with **769 seconds** total file runtime reported by the CI runner. The rerun tested commit `25ecb5556c1ae908f1de7eaa1c0575511569a629`; the only subsequent code change is the `est_time` estimate.

## Speed Tests and Profiling

The speculative decoding speed gate remains **500 token/s** and both acceptance-length gates remain **4.7**. This PR changes scheduling only.
