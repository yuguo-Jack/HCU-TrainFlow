# [NPU][CI] Constrain evalscope dependency versions

[Upstream PR](https://github.com/sgl-project/sglang/pull/40133) · state: closed · merged: True

## Original PR description

## Motivation

NPU accuracy tests install evalscope in an isolated virtualenv via run_evalscope.sh. Without version bounds on key transitive dependencies, the pip resolver can backtrack to ancient, incompatible versions (e.g. aiohttp 1.0.5) when dependency metadata fluctuates, causing extremely long install times (85+ minutes) or import/runtime failures.

## Modifications

Add explicit version bounds for aiohttp (>=3.11,<4) and httpx (>=0.28,<1) when installing evalscope in python/sglang/test/ascend/e2e/run_evalscope.sh, for both the online and local-source install paths. These constraints prevent the pip resolver from degrading to incompatible legacy versions. Also wrap the pip install step with a 20-minute timeout so that resolver backtracking from any other component fails fast instead of hanging the job.
