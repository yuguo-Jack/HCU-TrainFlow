# [Fix] [AMD] attention: Default deterministic inference to Triton on HIP

[Upstream PR](https://github.com/sgl-project/sglang/pull/48083) · state: open · merged: False

## Original PR description

## Motivation

On ROCm, `--enable-deterministic-inference` without `--attention-backend` picks FA3, which is not available on ROCm, so the server fails to start (for example in `test_return_routed_experts.py`).

## Modifications

On HIP, pick Triton instead.

## Accuracy Tests

On MI350X, a server started with only `--enable-deterministic-inference` now starts with Triton and generates normally.
