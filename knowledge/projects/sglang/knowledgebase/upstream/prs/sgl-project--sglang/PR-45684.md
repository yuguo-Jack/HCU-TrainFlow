# [Refactor] attention: centralize linear and draft TP group selection

[Upstream PR](https://github.com/sgl-project/sglang/pull/45684) · state: closed · merged: True

## Original PR description

## Motivation

Hybrid context parallelism uses full TP for linear-attention head sharding and for an attention-owning draft under CP without attention DP. The group-selection conditions were repeated across model boundaries, draft execution, KV budgeting, and fused-draft placement, allowing their geometry to drift apart.

## Modifications

- Make the GLM KDA boundary use `linear_attn_parallel_group()`, matching its projection and recurrent-state sharding.
- Add `draft_attn_parallel_group()` and `draft_attn_tp_size()` beside the existing linear-attention selectors in `runtime_context.py`.
- Reuse the draft selector in `draft_tp_context()`, DFLASH KV budgeting, and fused-draft placement. Selection depends on the published topology instead of CP strategy initialization.
- Preserve scoped topology restoration, attention-DP isolation, and the existing algorithm-specific gates for EAGLE and DSPARK.
- Extend CPU tests for CP+DP isolation, restoration after exceptions, execution/budget geometry agreement, and fused-draft head counts. Exercise the real linear-attention selector in the boundary tests.
