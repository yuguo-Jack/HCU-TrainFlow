# Fix GLM47 streaming parser dropping buffered tool calls

[Upstream PR](https://github.com/sgl-project/sglang/pull/41493) · state: closed · merged: False

## Original PR description

## Motivation

With `tool_call_parser=glm47`, one text delta can contain multiple complete `<tool_call>` blocks. The streaming detector returns after the first block and leaves the remaining calls buffered. If this is the final delta, `parse_stream_end()` does not recover those calls, so streaming and non-streaming results disagree.

## Modifications

Drain the buffered suffix while parsing makes progress. Stop when the buffer is empty or another fragment is needed, preserving partial-call state and existing argument parsing. Complete calls are available immediately, without requiring an extra empty delta or terminal flush.

Add CPU-registered tests through the actual `FunctionCallParser` covering multiple calls in one chunk, every two-chunk split, seeded multipart splits, text between calls, Unicode/escaping, no-argument tools, partial continuation, empty chunks and finish. Reconstructed arguments reject duplicate JSON keys.

## Accuracy Tests

The new regression fails on the unmodified parser by returning only the first of two complete calls. With the fix, the new chunk tests, GLM47 schema tests and existing function-call parser suite pass: **265 tests, 1,227 subtests**.


Ruff checks/formatting, registered-test validation and `git diff --check` pass. The CPU environment emits an existing unknown `asyncio_mode` pytest-option warning. Model forward computation is unchanged. Additional real-weight ROCm PDD serving checks on GLM-5.3 pass with speculation OFF and with native MTP3: each arm passes 100 protocol cases, eight chat oracles and two real-tool tasks. All eight MTP live turns exercise target verification. The reviewed source and loaded parser method identities were verified in both prefill and decode roles. These are bounded serving regressions, not model-quality equivalence or throughput benchmarks.

## Speed Tests and Profiling

No inference throughput claim. The change drains complete buffered calls that otherwise require another parser invocation.
