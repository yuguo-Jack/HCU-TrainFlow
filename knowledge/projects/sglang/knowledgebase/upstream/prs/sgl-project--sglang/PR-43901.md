# [Scheduler] Attempt admission on every step

[Upstream PR](https://github.com/sgl-project/sglang/pull/43901) · state: open · merged: False

## Original PR description

Stacks on #43900

- Admission no longer skips steps after the running batch was marked full; `batch_is_full` is removed.
- The admission early exits get names; the scripted trace records the skip reason of each step.

Behavior change: a step admits waiting requests as soon as KV memory or request slots free up, the new-token ratio decays, a prefix grows, or a better candidate arrives, instead of after the latch reopens. Steps that would have been skipped now run one admission pass (waiting sort, prefix match). PD prefill, priority preemption, hybrid SWA, HiSparse, and dLLM with priority are unchanged. Throughput on a single H200 (offline, Qwen3-0.6B / Qwen3-8B): fcfs and priority within noise; lpm -1.27% (0.6B) and +7.55% (8B).
