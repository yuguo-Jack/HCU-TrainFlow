# [Perf] diffusion: Fuse LTX video VAE normalization and padding

[Upstream PR](https://github.com/sgl-project/sglang/pull/47869) · state: open · merged: False

## Original PR description

Fuse pixel normalization/SiLU and temporal/spatial padding in the LTX video VAE, producing channels-last tensors for the existing cuDNN convolutions. Normalization uses the request-scoped `lossless` gate.

On one B200, native `Lightricks/LTX-2` two-stage serving improves **4.572 → 4.433 s (3.03%)** mean end-to-end latency; audio/video decoding improves **450 → 308 ms (31.6%)**. Six warmed saved requests per variant in A–B–B–A order against the same main base: 768×512, 121 frames, 40 base steps, seed 42, resident weights, eager, conditioning cache disabled. The two-GPU sharded path showed no meaningful gain.

Validation: 6 focused CUDA cases, including input-device selection, 202 existing registry/dispatch tests, and pre-commit pass. All 121 frames pass existing LTX quality thresholds: minimum CLIP 0.9897, SSIM 0.9606, PSNR 37.6 dB; maximum mean pixel difference 1.92. Audio is identical. Final videos match the previously validated A/B files byte for byte. Full-pipeline profiles reduce audio/video decode GPU launches from 3,191 to 2,023.
