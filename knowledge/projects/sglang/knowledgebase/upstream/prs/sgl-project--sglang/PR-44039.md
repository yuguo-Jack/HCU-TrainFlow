# [Agents] Add a rule to prefer sgl-eval for accuracy evals

[Upstream PR](https://github.com/sgl-project/sglang/pull/44039) · state: closed · merged: False

## Original PR description

## Summary

Add an agent rule (`.claude/rules/prefer-sgl-eval.md`) so accuracy checks use sgl-eval: the CLI from its own virtualenv, `run_sgl_eval` in tests, and the model's recommended sampling settings unless told otherwise. Also point the `generate-profile` and `write-sglang-test` skills and the `few_shot_gsm8k` deprecation message at sgl-eval instead of the deprecated `run_eval`.
