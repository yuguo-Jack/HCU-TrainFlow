# [Fix] cuda-graph: Keep deepstack media prefills eager

[Upstream PR](https://github.com/sgl-project/sglang/pull/44607) · state: open · merged: False

## Original PR description

## Motivation

A breakable or full prefill CUDA graph captures the language model body and binds its `input_embeds`, but not `input_deepstack_embeds`. Models whose vision encoder feeds deepstack features into the first decoder layers, such as the Qwen3-VL family, therefore replay an image or video prefill that fits a captured size without those features. The replay runs, and the answer silently changes. Text batches are unaffected, since they carry no deepstack features.

## Modifications

- At capture time the runner notes whether the captured body takes `input_deepstack_embeds` while the model produces deepstack features (`num_deepstack_embeddings` above zero).
- The shared replay check, which both the forward time gate and the DP vote use, keeps batches carrying image, video or audio inputs eager for such a model, next to the existing media fallbacks. Text batches keep replaying.
- Models without deepstack features, and every configuration without prefill CUDA graphs, behave as before.

## Accuracy Tests

With breakable prefill graphs enabled for Cosmos3 Nano, whose decoder is Qwen3-VL, on the SGLang release that SGLang-Omni pins and the same runner code, the following held.

- Of 16 image and video cases at temperature 0, 8 answers differed from eager before this change, the prompts short enough to replay a captured size, and all 16 matched eager after it. This change does not touch text batches.
- On the MMMU validation multiple choice items (847), 832 answers matched eager before this change and 845 after it, and accuracy matched eager (493 correct in both).

The extended unit case fails on main in its image, audio and video subtests and passes with this change, and the related prefill graph, padding, DP vote and model config unit tests give the same outcomes on both.

## Speed Tests and Profiling

No performance claim. In the affected configuration, media prefills now run eager instead of replaying a graph that drops their deepstack features.
