# [Test] diffusion: Cover CUDA and HIP latency guard policies

[Upstream PR](https://github.com/sgl-project/sglang/pull/42250) · state: open · merged: False

## Original PR description

## Motivation

Diffusion latency guards deliberately reject over-budget CUDA runs but only warn on HIP. Tests must cover both policies without depending on the host GPU.

Upstream #42391 already merged the fixture platform isolation originally proposed here. This PR is now limited to four additional regression cases: E2E/load latency crossed with CUDA/HIP policy. It checks that an in-budget request emits no warning, an over-budget CUDA request raises, and an over-budget HIP request emits exactly one AMD performance warning. Production validators and thresholds are unchanged.
