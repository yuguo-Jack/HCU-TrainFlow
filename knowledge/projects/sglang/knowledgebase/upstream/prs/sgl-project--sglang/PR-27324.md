# [Fix] Guard None mamba_next_track_idx in set_mamba_track_indices_from_reqs

[Upstream PR](https://github.com/sgl-project/sglang/pull/27324) · state: closed · merged: False

## Original PR description

## Problem

Spec v2 + NEXTN + `--mamba-scheduler-strategy extra_buffer` crashes on first request:

```
  File "sglang/srt/speculative/eagle_info_v2.py", line 295, in prepare_for_v2_verify
    set_mamba_track_indices_from_reqs(batch)
  File "sglang/srt/managers/schedule_batch.py", line 1466, in set_mamba_track_indices_from_reqs
    torch.tensor(
TypeError: 'NoneType' object cannot be interpreted as an integer
```

## Root Cause

`set_mamba_track_indices_from_reqs()` assumes all requests have valid `mamba_next_track_idx` (0 or 1), but some requests on the Spec v2 verify path haven't gone through `_alloc_ping_pong_buffer()` yet, so the field is still `None`.

Call chain:
1. `eagle_worker_v2.forward_batch_generation()` → `self.verify(batch)`
2. `verify()` → `verify_input.prepare_for_v2_verify()`  
3. `prepare_for_v2_verify()` detects `enable_mamba_extra_buffer()` → calls `set_mamba_track_indices_from_reqs(batch)`
4. `torch.tensor([req.mamba_next_track_idx for req in batch.reqs])` ← **None causes TypeError**

Normal decode flow initializes `mamba_next_track_idx` to 0 in `HybridReqToTokenPool.alloc()` → `_alloc_ping_pong_buffer()`, but Spec v2 verify path bypasses this for some requests.

## Fix

Guard `None` in the list comprehension, defaulting to index 0 (first ping-pong slot):

```python
# Before (crashes on None):
[req.mamba_next_track_idx for req in batch.reqs]

# After (None-safe):
[req.mamba_next_track_idx if req.mamba_next_track_idx is not None else 0 for req in batch.reqs]
```

Defaulting to 0 is safe because:
- `_alloc_ping_pong_buffer()` initializes `mamba_next_track_idx = 0`, so 0 is always a valid default
- The gather operation reads the first allocated slot which is always valid

## Reproduction

Model: Qwen3.6-27B-FP8 (hybrid GDN architecture)

```bash
export SGLANG_ENABLE_SPEC_V2=1
python -m sglang.launch_server \
  --model-path /path/to/Qwen3.6-27B-FP8 \
  --quantization fp8 \
  --speculative-algorithm NEXTN \
  --speculative-num-steps 5 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 6 \
  --mamba-scheduler-strategy extra_buffer \
  --mamba-backend flashinfer
# Send any chat completion request → immediate crash
```
