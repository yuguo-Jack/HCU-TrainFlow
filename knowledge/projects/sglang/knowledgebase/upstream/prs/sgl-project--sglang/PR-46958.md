# [diffusion] Add encode-only disagg serving with POST /encode

[Upstream PR](https://github.com/sgl-project/sglang/pull/46958) · state: open · merged: False

## Original PR description

## Motivation

Training jobs (for example diffusion SFT in miles-diffusion) need the text-encoder outputs and VAE latents that serving computes, without running the DiT or the decoder. Disaggregated serving already runs the encoders as independent pools; this lets those pools back an encode-only deployment.

## Modifications

- `--disagg-encode-only` (head and encoder roles): the last encoder role on a request's path returns what a denoiser would receive, the Req tensors (e.g. `prompt_embeds`) and extras, through the head, which then needs no `--denoiser-urls` or `--decoder-urls`. Workers report the flag when registering; the head drops a worker whose setting differs.
- `POST /encode` (encode-only servers only): `prompt`, optional `image_path` (conditions, as in generation), `target` (training targets by latent stream, e.g. `{"visual": path or data URI}`), `width`, `height`, `extra_sampling_params`. Returns msgpack `{request_id, encoded}` with the `/rollout/generate` tensor serialization.
- A target routes a request through the image encoder like an image does. `TargetEncodingStage` (pipelines_core) encodes it into `encode_target[stream]`, at least `latents` in the denoiser's layout; a pipeline opts in on its image encoder role, and a target request on a pipeline without one fails.
- FLUX.3 Image: a target stage alongside the condition stage fits the target to `width` x `height` (resize, center crop), VAE-encodes it (posterior mean), and returns `latents` with `latent_ids`, the ids the denoiser gives generated image tokens. Its prompt encoder returns only the prompt branch of `flux3_text`.
- Docs: `disaggregation.mdx`, `cli.mdx`.

Only FLUX.3 Image implements a target stage so far; a default built on the pipeline config's VAE hooks will follow with the next model and its consistency test.

## Tests

- `test_disagg_orchestration.py`: encode-only for combined and split encoders, a target-only request routed through the image encoder, a mismatched worker refused, the worker returning Req tensors and extras but not request scalars, and a target on a pipeline without a target stage failing.
- `test_flux3_image_stages.py`: the target fit and ids, pass-through without a target, other streams rejected.
- `test_server_args.py`: `--disagg-encode-only` accepted only on the head and encoder roles.
- multimodal_gen unit suite: the failures that remain also fail on the base commit in the same environment.
- E2E with FLUX.3 Image and a miles-diffusion SFT run: in progress.
