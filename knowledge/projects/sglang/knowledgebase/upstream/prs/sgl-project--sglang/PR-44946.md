# [CI] deepseek-v4: Set the KV pool in the BCG replay contract test

[Upstream PR](https://github.com/sgl-project/sglang/pull/44946) · state: closed · merged: True

## Original PR description

- `test_backend_replay_keeps_captured_metadata_active` builds its backend with `object.__new__`. Since #44920 the breakable-graph replay reads `token_to_kv_pool.request_window` and `low_ratios`, so the test fails with `AttributeError: 'DeepseekV4AttnBackend' object has no attribute 'token_to_kv_pool'`, on main's scheduled CI too.
- The test now gives the backend a pool without a request window and no low ratios, so it keeps checking the replay contract without the prefill graph's context limit.

Test-only change.
