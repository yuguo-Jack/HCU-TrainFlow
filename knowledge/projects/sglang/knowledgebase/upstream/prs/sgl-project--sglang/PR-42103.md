# feat(sglang-miles): add ModelExpress S3 weight refit

[Upstream PR](https://github.com/sgl-project/sglang/pull/42103) · state: open · merged: False

## Original PR description

## Motivation

Enable SGLang to install published ModelExpress S3 delta and full-checkpoint versions through `POST /update_weights_from_modelexpress`. This provides the serving-side endpoint for Miles' ModelExpress weight-transfer mode and targets the `sglang-miles` branch used by Miles.

## Modifications

```text
version request → tokenizer write lock → scheduler / TP workers
                → MX stage → apply → release
                → TP success agreement → cache/version bookkeeping
```

- Delegate receiver configuration, seed resolution and client reuse to the public [get_modelexpress_generator()](https://github.com/ai-dynamo/modelexpress/blob/0af7e9e4438394588710b8b213cafec5e78db8de/modelexpress_client/python/modelexpress_rl/inference/engines/sglang/__init__.py#L19). The optional MX client is loaded when refit is requested and closed at scheduler shutdown.
- Collect every TP rank's result inline before reporting success; record the installed version after the requested cache flush succeeds.
- Support repeated BF16 MoE reloads by restoring checkpoint-shaped weight views. Reject speculative draft models and incompatible weight-cache modes before mutation.

Receiver configuration uses `object_storage_endpoint_url` and `object_storage_region_name`, matching vLLM. Companion implementation and trainer integration: [ModelExpress #826](https://github.com/ai-dynamo/modelexpress/pull/826) and [Miles #3886](https://github.com/radixark/miles/pull/3886).

Setup and receiver configuration are documented in the companion [ModelExpress SGLang guide](https://github.com/ai-dynamo/modelexpress/blob/0af7e9e4438394588710b8b213cafec5e78db8de/docs/S3_DELTA_WEIGHT_REFIT.md#sglang-backend).

Those results apply to the source snapshots listed there and predate the latest rebase.
- The final evaluation is a small smoke test drawn from the training dataset. An accuracy evaluation on held-out prompts, comparing native loading and MX refit of the same target weights, remains pending.

## Speed Tests and Profiling

See [Miles #3886 — Test and Validation](https://github.com/radixark/miles/pull/3886) for delta/full-checkpoint update timings and observed rollout/decode throughput extracted from the validation logs.

The update timings include trainer staging, S3 publication, and receiver refit. Rollout throughput uses total generated tokens divided by total recorded rollout time; the SGLang decode samples are reported separately. The measurements describe the Qwen3-30B-A3B RL workload on four B200 rollout GPUs with TP4.
