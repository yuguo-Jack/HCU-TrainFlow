# [MoE] Keep up-only TMA opt-in out of down config fallback

[Upstream PR](https://github.com/sgl-project/sglang/pull/42783) · state: closed · merged: False

## Original PR description

## Motivation

When only an up-projection config is available, `get_moe_configs(..., down_moe=True)` reuses its tile parameters. An up config with `USE_TMA=true` currently also enables down TMA through this fallback, despite the documented `without TMA` behavior. This changes the intermediate buffers to expert-sorted order and changes the up GEMM's `c_sorted` setting without a separate down-projection opt-in.

## Modifications

Copy the fallback configurations while omitting the projection-specific `USE_TMA` key. Preserve the cached up configurations and their TMA setting. Explicit down configuration files continue to retain their own `USE_TMA` value.

Regression tests cover exact-version and cross-version fallback, preservation of the cached up config, the prepared runtime up/down flags, and explicit down TMA on/off settings. The fallback test fails on the original code.

## Accuracy Tests

- `python3 -m pytest test/registered/unit/layers/moe/test_fused_moe_triton_config.py -q`: **5 passed**.
- **31 H100 cases passed** using checkpoint-identical layer-zero weights/scales from `Qwen/Qwen3-30B-A3B-FP8@d206ba732169f29bb77fbf80fc2c4b81d4d30782`. Checked the actual file resolver for an up-only TMA config and an explicitly enabled down TMA config. Coverage: M=1,4,16,128,512,1024,4096; random, balanced and hot routes; one captured M=128 fixture; four weight-address copies.
- All cases passed finite-output checks, BF16 output agreement against the default FP8 expert path (`rtol=atol=0.05`), and the FP32 reference guard (`candidate relative-L2 <= default relative-L2 * 1.10 + 0.0001`; dequantized checkpoint weights, TF32 disabled).
- CUDA Graph replay matched eager execution exactly after changes to hidden states, expert IDs and routing weights.

GPU checks used Torch 2.14.1+cu130, Triton 3.8.0, and `lmsysorg/sglang@sha256:ee3db420aca91ad0c7a745471b61264f76cffeb027df1d96117d95fbcb7a70a4`. The measurements cover the expert path; they do not establish full-model quality equivalence.
