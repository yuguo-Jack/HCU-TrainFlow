## Motivation

Query each PP rank’s local storage and allocate prefetch buffers before synchronizing the usable prefix. Combine storage hits and allocation success in the existing MIN reduction, enabling file and other storage backends to use the same PP prefetch flow.
Remove Mooncake’s cross-rank query path and trim surplus buffers after synchronization, preserving the existing prefetch admission and completion interfaces.
