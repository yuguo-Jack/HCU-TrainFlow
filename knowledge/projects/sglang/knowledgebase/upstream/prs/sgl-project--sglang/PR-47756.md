# [Fix] [AMD] diffusion: Enable AITER for FLUX.3 on gfx1151

[Upstream PR](https://github.com/sgl-project/sglang/pull/47756) · state: open · merged: False

## Original PR description

## Motivation

The gfx1151 image lacks the AMD SMI Python package. Diffusion platform detection therefore falls back to CPU even when PyTorch sees the HIP device.

This change restores automatic ROCm detection and enables the AITER configuration validated with FLUX.3.

## Modifications

- Install the ROCm-bundled package from /opt/rocm/share/amd_smi and verify import amdsmi during the build.
- Change the image default to ENV SGLANG_USE_AITER=1.
- Update the LLM Triton example to explicitly set SGLANG_USE_AITER=0 alongside --attention-backend triton.

## Accuracy Tests

Validation used Radeon 8060S Graphics, gfx1151, with PyTorch 2.9.1 and ROCm 7.2.4.

The built image selects ROCm without a platform override. A controlled check that blocks the amdsmi import reproduces the CPU fallback.

The FLUX.3 smoke used these settings:

| Setting | Value |
|---|---|
| Model | black-forest-labs/flux-3-image-klein |
| Attention backend | aiter |
| Resolution | 1024×1024 |
| Inference steps | 16 |
| Concurrency | 1 |
| Warmup requests | 1 |
| Measured requests | 5 |

All six images decoded successfully. Logs record the AITER BF16 varlen attention kernel build and import.

The full inference smoke used `-e SGLANG_USE_AITER=1`. A separate image derived from the tested build with only the ENV change confirms that AITER is enabled without a runtime override.

CI and model accuracy evaluation were not run.

## Speed Tests and Profiling

The measurements exclude the warmup request.

Run on
```python
python3 -m sglang.multimodal_gen.benchmarks.bench_serving \
  --port 30000 \
  --task text-to-image \
  --dataset vbench \
  --width 1024 --height 1024 \
  --num-inference-steps 16 \
  --warmup-requests 1 \
  --warmup-inference-steps 16 \
  --num-prompts 5 \
  --max-concurrency 1 \
  --output-file /tmp/flux3_amdsmi_fix_bench.json

```
| Metric | Result |
|---|---:|
| Completed requests | 5 |
| Failed requests | 0 |
| Mean client latency | 82.25 s |
| Median client latency | 32.25 s |
| Peak GPU memory | 21,064 MB |

The first measured request was slow, which raised the mean latency. No matched SDPA comparison was run, so these smoke results do not establish a speedup.

> [!NOTE]
> `SGLANG_USE_AITER=1` changes the default for the entire image. Validation covers FLUX.3 only. The LLM Triton example explicitly sets `SGLANG_USE_AITER=0`. Wan 2.2 enablement with AITER on gfx1151 will be tested and measured separately in a follow-up.
