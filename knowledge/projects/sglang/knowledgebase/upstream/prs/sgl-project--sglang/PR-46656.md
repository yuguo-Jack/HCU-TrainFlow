# [Perf] [AMD] Kimi-K3: fuse attention-residual aggregation with TP collectives

[Upstream PR](https://github.com/sgl-project/sglang/pull/46656) · state: open · merged: False

## Original PR description

## Motivation

K3's attention-residual aggregation ran as a separate all-reduce plus aggregation kernels per layer.

## Modifications

- HIP kernels `attn_res_smallm`, `ar_agg_hip` and `ag_one_barrier_hip` fuse the aggregation into the TP all-reduce / all-gather with one barrier.
- The logits and up-projection gathers use `all_gather_lastdim_add` from ROCm/aiter#6960.

## Accuracy Tests

- The existing `test_attn_res.py` and `test_attn_res_mix_large_tokens.py` pass on MI355. This PR adds no new test.

Full K3 stack on MI355X TP8 (DFlash, prod config) vs B300, McNemar:
- GPQA-D 89.4 vs 87.9 (p=0.55)
- AIME25 96.7 vs 93.3 (p=1.0)
- MATH500 92.2 vs 92.2 (p=1.0)
- MMLU-Pro 89.6 vs 90.0 (p=0.77)
- GSM8K 97.2%

## Speed Tests and Profiling

Throughput change from turning this feature off on the full stack: -2.7/-1.1/-3.4% on the agentic replay at C=1/8/32, and -6.3/-2.2% at 90k prefix at C=1/8 (mean -3.1%).

## Dependencies

- Stacked on #46653 (it writes the FP8 copy that the static FP8 dense layers read). Only the last commit is new here.
- ROCm/aiter#6960.
