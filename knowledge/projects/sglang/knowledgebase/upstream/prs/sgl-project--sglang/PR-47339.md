# [Fix] hicache: Evict pass-through Mamba host checkpoints before path tails

[Upstream PR](https://github.com/sgl-project/sglang/pull/47339) · state: open · merged: False

## Original PR description

## Motivation

Fixes #45400.

On a hybrid GDN model with `--enable-hierarchical-cache`, host-tier hits drop to zero once the evicted working set is a few long prefixes larger than the device pool. The KV pages are still on host, but identical requests get `cached_tokens: 0` and a full recompute.

A host prefix hit ends at the deepest node on the matched path that still has a Mamba state (device or host). Host Mamba eviction (`drive_host_eviction`) is plain LRU, and a long prefill backs up many chunk checkpoints along one path. With few host Mamba slots, newer intermediate checkpoints evict the tail states of earlier documents, so their host KV is left with no usable Mamba state. `--mamba-max-states-per-path` doesn't help, because it only trims device states after they've been backed up.

## Modifications

- `unified_cache/components/mamba.py` and `rust/sglang-radix-tree/src/components/mamba.rs`: host Mamba eviction now runs in two LRU passes. The first pass evicts only pass-through checkpoints (a node with one child that holds its own Mamba state, on device or host). The second pass, which runs only if the first one didn't free enough, is the existing LRU order. Path tails, forks, and states whose child has no state are kept until no pass-through checkpoint is left, so each path keeps the state its host hit ends at. This matches what `_evict_excess_path_states` already preserves on device.
- The Python and Rust cores get the same change.
- `components/README.md`: describes the new order under `drive_host_eviction()`.
- Tests, in both cores:
  - a pass-through checkpoint is evicted before an older tail
  - a fork is kept until the fallback pass
  - a state whose child has no state is kept
  - eviction falls back to LRU order once no pass-through is left

  Python: `test/registered/unit/mem_cache/test_mamba_host_eviction_order.py` (CPU). Rust: `rust/sglang-radix-tree/src/tests/components/mamba.rs`.

## Accuracy Tests

Answers are unchanged: all 24 responses across the three runs below return the correct passphrase. This change only affects which host Mamba states are evicted, not model outputs.

### Follow-up

Once no pass-through checkpoint is left, eviction falls back to plain LRU, so tails can still be evicted under heavy pressure, for example branch-heavy sub-agent workloads. A minimum-token-distance rule for keeping pass-through checkpoints is being discussed in the issue. This PR keeps to the reproduced case.
