# [DSV4.1] DeepSeek-V4.1 support prefill CP

## Motivation

Baseline: https://github.com/sgl-project/sglang/pull/38798

DeepSeek-V4.1 DSpark PD disaggregation currently requires Prefill and Decode to use the same attention TP layout, which prevents Prefill from using context parallelism for long prompts.

This PR enables the following topology:

- Prefill: TP8 world, attention TP1 x CP8
- Decode: attention TP8 x CP1
- Mooncake PD transfer
- DSpark static verification

## Modifications

- Allow canonical interleave Prefill CP for DeepSeek-V4.1 DSpark PD.
- Validate equal total attention parallel width instead of requiring identical `attn_tp_size`.
- Connect each Decode rank to all Prefill CP ranks.
- Partition globally materialized compressed KV and Indexer pages across CP senders.
- Transfer CP-replicated state only from CP rank 0, including target SWA, draft SWA, and the C2 request ring.
- Preserve the existing odd-boundary whole-request C2 ring handoff.
- Fix CP-v2 decoder bounded replay:
  - use tail-specific CP metadata for hidden-state gathering;
  - preserve global token indices for DSpark hidden injection;
  - use tail-specific input IDs and logits metadata.
- Allow text requests from DeepSeek-V4.1 multimodal checkpoints to use Prefill CP while continuing to reject multimodal requests under CP.
- Align Engram image-token masking with CP-local input IDs.
- Rebuild global routing IDs when entering the bounded-replay tail.
- Fall back to the existing Torch indexer on Hopper/SM90, since DeepGEMM FP8-FP4 MQA logits only supports SM100/SM120.

## Supported Configuration

- `--enable-prefill-cp`
- `--cp-strategy interleave`
- Prefill CP only; Decode must use CP1
- DP1, DCP1, PP1
- Mooncake transfer backend
- `SGLANG_RAGGED_VERIFY_MODE=static`
- DSpark enabled on both Prefill and Decode
- Matching DSpark block size and KV layout on both sides
- Text-only requests under CP

The following remain unsupported:

- Decode CP/DCP
- Multimodal requests with CP
- Encoder SWA bounded replay with CP or PD
- NIXL for this topology
