# [Fix] [Intel] moe: Route dropped slots at weight 0

[Upstream PR](https://github.com/sgl-project/sglang/pull/47664) · state: open · merged: False

## Original PR description


## Motivation
moe: Route EP-dropped expert slots to a local expert at weight 0, EP and padded rows put -1 in topk_ids; sgl-kernel-xpu fused_experts has no drop sentinel, so the device is lost on the first prefill with --ep-size > 1.

## Modifications
- moe/utils: route_dropped_experts_to_local and fold_router_weight_into_input.
- Use them at the four XPU fused_experts call sites (fused_moe, unquant, fp8, mxfp4). Other backends are unchanged.
- Tests: unit/layers/moe/test_moe_utils.py (CPU), xpu/test_moe_ep_drop_sentinel.py.

## Accuracy Tests
gpt-oss-20b on Arc Pro B60, TP2/4 + EP2/4: greedy first tokens match TP 16/16.

## Speed Tests and Profiling
EP prefill 0.70-0.77x TP on 2 cards, 0.56-0.61x on 4 (previously crashed).
