# [PDMux] Align DeepSeek prefill and decode across attention DP ranks

[Upstream PR](https://github.com/sgl-project/sglang/pull/42513) · state: closed · merged: False

## Original PR description

## Motivation

Attention-DP ranks with no local work must participate in peer prefill/decode and advance through the same prefill layer boundaries. This layer enables non-speculative attention DP using the common [pdmux-standard layer_split reference](https://github.com/Li-brua/sglang/tree/17761860ccbc6cea53b0c3625fa0c89880b48f9e) scheduling policy.

## Changes

- Preserve the scheduler's global token vector independently of model-local MLP counts. Size split intervals from its maximum and detect peer decode from gathered metadata; honor the ordinary scheduler skip-gather setting.
- Select streams from the local running batch before decode metadata gather. Prefill overrides only the full-TP handle; attention/MoE groups and sampler request-replica groups retain their ordinary handles.
- Dispatch explicit layer intervals on IDLE ranks. Prepare/pad on each slice and unpad before returning, with no separate unpadded-count snapshot or preparation reuse.
- Reset TBO child markers, clear stale DeepSeek IDLE metadata and clone persistent token IDs before in-place gathering.
- Cover TP8/DP8 and TP8/DP2 group context and lifetime. Speculative support is added by the following adapter; this validation matrix does not establish EP, CP or DCP support.
