# [Perf] kda: Extend fused verify windows

[Upstream PR](https://github.com/sgl-project/sglang/pull/47225) · state: closed · merged: False

## Original PR description

Allow fixed-window DSpARK KDA verification with 9–16 tokens to use the existing CuTe fused kernel instead of falling back. Existing eligibility checks remain unchanged. Extend the output-normalization test to cover windows 8, 9, 12, and 16.

With public Kimi-K3 on B300 TP8, a 9-token verify window, 8192 input tokens, 1024 output tokens, and simulated acceptance length 4, three-run median steady decode throughput increased from 234.11 to 243.04 tok/s at batch 1 (+3.81%) and from 924.42 to 976.24 tok/s at batch 8 (+5.61%). These are performance measurements, not accuracy validation, and were collected before the final rebase onto current main.

The added long-window GPU test cases have not yet been run. Python syntax and diff checks pass.
