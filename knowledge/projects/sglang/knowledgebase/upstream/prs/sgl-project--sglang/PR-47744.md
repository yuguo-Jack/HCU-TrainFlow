# [Fix] linear: Keep replicated outputs out of TP symmetric memory

[Upstream PR](https://github.com/sgl-project/sglang/pull/47744) · state: closed · merged: True

## Original PR description

## Motivation

`RowParallelLinear` resolves `parallel_group="replicated"` to no TP group, but its output allocation still enters the global TP symmetric-memory context whenever allocation symmetry is enabled. Kimi-K3's replicated shared experts produce complete local outputs and do not need that collective memory window.

## Modifications

Disable the TP symmetric-memory allocation context when the linear has no TP group. Keep the existing attention-TP allocation path and the policy for sharded linears. Apply the fix in `RowParallelLinear.forward` so callers do not need model-specific allocation overrides.

Replicated batch sizes vary by rank; sharded outputs complete the real TP AllReduce and match the reference exactly. This is a deterministic linear/allocation smoke test, not a full-model accuracy benchmark.

## Speed Tests and Profiling

No standalone speedup is claimed. Earlier tuning combined local allocation with metadata and scheduling changes, so that aggregate improvement cannot be attributed to this patch. This PR corrects allocation scope without changing linear arithmetic. A full-model run with symmetric memory enabled has not been repeated on this branch.

```python
"""Manual distributed validation of PR #47744 on its exact source tree."""

import json
import os

import torch
import torch.distributed as dist
import torch.nn.functional as F

from sglang.srt.distributed import parallel_state as ps
from sglang.srt.distributed.device_communicators.pynccl_allocator import (
    is_symmetric_memory_enabled,
    is_tensor_in_symmetric_mempool,
)
from sglang.srt.layers.linear import RowParallelLinear
from sglang.test.test_utils import publish_build_topology


@torch.inference_mode()
def main():
    rank = int(os.environ["RANK"])
    size = int(os.environ["WORLD_SIZE"])
    torch.cuda.set_device(int(os.environ["LOCAL_RANK"]))
    ps.set_custom_all_reduce(False)
    ps.init_distributed_environment(
        world_size=size, rank=rank, local_rank=rank, timeout=120
    )
    publish_build_topology(
        tp_size=size,
        world_rank=rank,
        enable_symm_mem=True,
        enable_nccl_nvls=True,
        disable_custom_all_reduce=True,
        device="cuda",
    )
    ps.initialize_model_parallel(enable_symm_mem=True)
    assert is_symmetric_memory_enabled()
    cases = []
    try:
        for layout in ("replicated", "tp", "attn_tp"):
            sharded = layout != "replicated"
            layer = RowParallelLinear(
                256,
                512,
                bias=False,
                input_is_parallel=False,
                params_dtype=torch.bfloat16,
                reduce_results=False,
                parallel_group=layout,
                use_dp_attention_reduce=layout == "attn_tp",
            ).cuda()
            layer.weight.fill_(1.0 / 256)
            for nominal_tokens in (1, 17, 257, 8192):
                # Replicated modules may see different local batch sizes.
                tokens = nominal_tokens if sharded else nominal_tokens + rank
                x = torch.ones(tokens, 256, device="cuda", dtype=torch.bfloat16)
                output, _ = layer(x)
                symmetric = is_tensor_in_symmetric_mempool(output)
                assert symmetric == sharded, (rank, layout, tokens, symmetric)
                expected_local = F.linear(x, torch.full_like(layer.weight, 1 / 256)) if not sharded else torch.full_like(output, 1 / size)
                torch.testing.assert_close(output, expected_local, rtol=0, atol=0)
                if sharded:
                    reduced = ps.get_tp_group().all_reduce(output)
                    torch.testing.assert_close(
                        reduced, torch.ones_like(reduced), rtol=0, atol=0
                    )
                cases.append({"layout": layout, "tokens": tokens, "symmetric": symmetric})
                dist.barrier()
        torch.cuda.synchronize()
        gathered = [None] * size
        dist.all_gather_object(gathered, cases)
        if rank == 0:
            print(json.dumps({"status": "PASS", "world_size": size, "cases_per_rank": len(cases), "rank_cases": gathered}), flush=True)
    finally:
        ps.destroy_model_parallel()
        ps.destroy_distributed_environment()


if __name__ == "__main__":
    main()
```

After [#47744](https://github.com/sgl-project/sglang/pull/47744), an existing unit-test expectation is inconsistent with the updated symmetric-memory policy.

allocator.assert_called_once_with(tp, disabled=False)

Could you update the expectation to account for replicated layers, while preserving the numerical checks? For example:
allocator.assert_called_once_with(
