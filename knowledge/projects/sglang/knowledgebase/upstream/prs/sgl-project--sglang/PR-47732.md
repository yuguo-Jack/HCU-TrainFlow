# [Fix] kv_events: Offset ipc endpoints per DP rank and finish shutdown when the queue is full

[Upstream PR](https://github.com/sgl-project/sglang/pull/47732) · state: closed · merged: True

## Original PR description

## Motivation

Two small fixes in `ZmqEventPublisher`:

- `offset_endpoint_port` only handles `inproc` and `tcp`. With an `ipc://` kv-events endpoint and `dp_size > 1`, every DP rank above zero raises `ValueError` while constructing its publisher, although the socket setup already supports `ipc://`.
- `shutdown()` enqueues the stop sentinel with `put_nowait` on a bounded queue. When the queue is full, `queue.Full` escapes and the socket cleanup after it never runs.

## Modifications

- Suffix `ipc://` endpoints with `_dp{rank}`, the same scheme `inproc` uses.
- Ignore `queue.Full` when enqueuing the sentinel; the thread exits anyway because `_running` is already false and the loop drains the queue first.
- One unit test per fix.
