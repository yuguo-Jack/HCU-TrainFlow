# [Fix] custom-all-reduce: Remove multi-node VMM allocator gate

[Upstream PR](https://github.com/sgl-project/sglang/pull/46853) · state: closed · merged: True

## Original PR description

Remove the VMM-backed caching allocator requirement for multi-node CustomAllReduceV2 groups. These groups already use a torch symmetric-memory workspace during CUDA graph capture and replay; NVLink clique and supported world-size checks remain unchanged.

Update the existing topology capability tests and clarify graph-input registration comments. Python syntax and diff checks passed; unit tests and multi-node GPU validation have not been run.
