## Motivation

Update the SGLang XPU graph fake implementation to match the new sgl_kernel::fwd interface introduced by [sgl-kernel-xpu #540](https://github.com/sgl-project/sgl-kernel-xpu/pull/540). The operator now allocates outputs internally when needed and returns (out, optional_lse), whereas the previous fake assumed an in-place, no-return interface.

## Modifications

Replace the softmax_lse buffer argument with the return_softmax_lse flag.
Create a shape-only output tensor when out is not supplied; otherwise return the provided buffer.
Return an FP32 LSE tensor with shape (num_heads, total_q) when requested, or None otherwise.
Return (out, lse) to match the native operator.

## Speed Tests and Profiling

This change updates tracing metadata only and does not modify device kernels or eager execution, so no standalone latency improvement is claimed.
