# [DSv4] Sparse prefill: build compressed lengths without a host sync

## Motivation

`SparsePrefillChunkCache.ensure_compressed` built the per-request compressed lengths with `torch.tensor(lengths_cpu, dtype=torch.int32, device=device)`. Creating a CUDA tensor from a Python list copies from pageable host memory, so each prefill step paid a pageable H2D copy followed by a stream synchronize when the compressed gather was constructed. This drains the GPU queue and defeats the `output_size` already passed to `repeat_interleave` to avoid a sync.

## Modifications

Build `lengths` with `async_h2d`, which stages the list in pinned memory and enqueues a non-blocking copy on the current stream, as the other DSv4 code paths already do. Values, dtype and device are unchanged.
