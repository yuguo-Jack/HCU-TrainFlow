# [Doc] runtime: Add RFC for active incremental prompt ingestion

[Upstream PR](https://github.com/sgl-project/sglang/pull/46353) · state: open · merged: False

## Original PR description

## Motivation

This documentation-only PR proposes an SGLang serving primitive for active incremental prompt ingestion: append prompt chunks to one in-flight request, prefill each committed chunk, and delay decoding until an explicit finalize operation.

This is intended for producer-consumer workloads where prompt tokens arrive from another model, tool, parser, retriever, or streaming service.

## What this RFC covers

- Distinction from response streaming, chunked prefill, session-aware radix cache, and incremental chat tokenization.
- A conservative request state machine: append -> prefill -> append -> finalize -> decode.
- KV ownership and committed/pending/allocated length semantics.
- Ordering, backpressure, cancellation, rollback, and client-disconnect behavior.
- Correctness and performance tests using synthetic chunks and a small deterministic model.
- A staged implementation plan and open questions for SGLang maintainers.

## Important scope note

The RFC does not claim that SGLang lacks related primitives. SGLang already has session KV reuse and retraction machinery, but the current session contract still requires each request to provide its intended prompt and does not expose an in-flight append/finalize lifecycle. The proposal asks whether that missing primitive fits the existing scheduler and KV abstractions.
