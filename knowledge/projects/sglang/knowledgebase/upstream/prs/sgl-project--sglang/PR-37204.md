## Motivation

Fixes #37186.

The Qwen3.5 dense and MoE weight loaders apply a decoder pipeline-parallel layer interval to any parameter name containing layers.N. Encoder parameters such as model.visual.layers.5.norm.weight can therefore be skipped even when the local visual module needs them. Apply the interval filter only to normalized model.layers.* decoder names.

## Modifications

- Scope PP filtering to decoder-layer names in both conditional-generation loaders.
- Refresh the CPU loader fixtures for the current model structure and cover both visual.layers.* and visual.blocks.* namespaces, while still skipping non-local decoder weights.
- Preserve the current-main MTP embedding regressions and CI registration when resolving the test-file merge.

Synced with current `main` at `f2b73d4f9b4e64415b8d775b0f811c7801f1728b` on October 15, 2026.
