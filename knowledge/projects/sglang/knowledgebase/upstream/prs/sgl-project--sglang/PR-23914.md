# Split error logs to stderr in SRT logger configuration

[Upstream PR](https://github.com/sgl-project/sglang/pull/23914) · state: closed · merged: False

## Original PR description

## Motivation

This PR fixes logging stream behavior in the SRT logger configuration so error logs are emitted to `stderr` instead of being mixed into `stdout`.

Previously, the SRT logger configuration used a single stream handler pointing to `stdout`. That made `ERROR` and exception logs harder to distinguish in shell redirection, process supervision, and log collection setups.

## Modifications

- Added a `_MaxLevelFilter` helper in `python/sglang/srt/utils/common.py` to keep log records below `ERROR` on `stdout`
- Updated `python/sglang/srt/utils/common.py` `configure_logger()` to install separate `stdout` and `stderr` handlers
- Ensured existing root handlers are removed and closed before applying the new configuration
