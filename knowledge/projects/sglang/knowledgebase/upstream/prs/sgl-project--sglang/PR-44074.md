# [model-gateway] Send worker API key during initial HTTP health check

[Upstream PR](https://github.com/sgl-project/sglang/pull/44074) · state: open · merged: False

## Original PR description

## Motivation

Registering an HTTP worker whose `/health` endpoint requires authentication fails even when the registration request includes the correct `api_key`. The initial connection detection probe omits the key, while periodic HTTP health checks already send it.

This affects workers behind authentication proxies or middleware. Stock SGLang health endpoints do not require authentication.

## Modifications

- Pass the configured worker API key to the initial HTTP `/health` probe as a Bearer token.
- Preserve unauthenticated requests when no worker key is configured.
- Add regression coverage for valid, missing, and incorrect worker credentials, plus registration-time probing without a worker key.
- Document authentication for initial and periodic HTTP health checks.

Inference authentication, BYOK behavior, and circuit-breaker policies are outside this change.
