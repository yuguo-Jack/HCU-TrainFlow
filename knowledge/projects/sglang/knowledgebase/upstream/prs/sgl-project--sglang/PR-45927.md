## Motivation

<!-- Describe the purpose and goals of this pull request. -->

- Enable torch.nn.functional.scaled_mm with ScalingType.BlockWise1x32 on XPU.
- Support float8_e8m0fnu scales with zero-copy uint8 view matching PyTorch 2.14 OCP microscaling format.
- Add unit tests in test_xpu_fp8_linear.py covering dispatch, prequantized, dynamic quantization, and end-to-end Fp8LinearMethod execution.
