# [NPU] Support chunked prefill for DeepSeek-V4

## Motivation

Enable chunked prefill for DSV4 (DeepSeek-V4) on Ascend NPU, so long prompts are prefilled in fixed-size chunks instead of one extend — bounding peak memory and compressor-state growth for long context.

## Modifications

Route chunked prefill (batches with `extend_prefix_lens > 0`) through the fused compressor op (`cache_mode=1`), which handles c4 cross-chunk overlap in-kernel; non-chunked prefill and decode are unchanged. Add the matching fused prefill metadata (`start_pos`, block-aligned `positions_cmp`, cumulative state page tables) and make the c4/c128 compress-state pool chunked-aware with per-chunk incremental allocation + eviction to preserve cross-chunk tails and avoid state-pool OOM.
