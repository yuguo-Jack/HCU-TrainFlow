## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Enable MTP speculative decoding for hybrid DSA/linear-attention models in PD + HiSparse serving. This extends the non-speculative support in #43533, keeping target DSA KV backed by CPU memory while draft KV and KDA state remain on GPU.

On GLM-5.3-Flash with 8 × H200, enabling MTP516 delivers **2.50× output throughput** and **63.0% lower mean TPOT** at concurrency 16, with similar median TTFT.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Support mixed target CPU KV and draft GPU KV transfers through NIXL, with separate destination page indices for the two pools. The same-node shared-memory path copies only target KV to CPU memory; draft KV remains GPU-resident and uses NIXL.
- Aggregate completion across transfer components and retain outstanding handles on failure, preventing buffer reuse while writes are still in flight.
- Extend speculative swap to 2–8 candidate tokens, including the wider working sets required by MTP516/718. Apply consistent KPool tail validity checks during gather and commit, and align scratch reservations with physical page allocation.
- Add regression coverage for draft pool isolation and capacity budgeting, mixed-transfer completion, accepted-prefix writeback and CUDA Graph replay with changing inputs and slots.

End-to-end validation covers MTP516 with same-node NIXL, matching TP and PP1/DCP1. The 4/8-token verification paths are additionally covered by kernel and coordinator tests.

## Accuracy Tests

<!-- If this pull request affects model outputs (e.g., changes to the kernel or model forward code), provide accuracy test results. -->

GLM-5.3-Flash achieves **95.81% mean accuracy on full GSM8K** with PD + HiSparse + MTP516, comparable to **95.8%** in the preceding non-MTP HiSparse validation (5-shot, temperature 0, `reasoning_effort=low`).

BF16/FP8 mixed-transfer checks and **12 GPU + 6 coordinator tests** passed, covering transfer correctness, partial acceptance, tail tokens, slot reuse and CUDA Graph replay. Pre-commit checks passed.

## Speed Tests and Profiling

<!-- If this pull request impacts inference speed, provide benchmarking and profiling results. -->

GLM-5.3-Flash on **8 × H200**, same-node PD (**P: GPUs 0–3; D: GPUs 4–7**), TP4/EP4 per endpoint, HiSparse ratio 2 and FP8 TileLang KV. **Only MTP is toggled; ReplaySSM is disabled in both configurations.** MTP516 uses EAGLE with 5 steps, top-k 1 and 6 draft tokens.

Native SGLang serving benchmark: **4K input / 1K output, concurrency 16, 512 requests**. Results are medians of three runs after warmup; all requests succeeded.

| Metric | MTP disabled | MTP516 | Change |
| --- | ---: | ---: | ---: |
| Output throughput (tok/s) | 1169.41 | **2924.80** | **2.50×** |
| Mean TPOT (ms) | 13.10 | **4.84** | **−63.0%** |
| TTFT P50 (ms) | 532.70 | 513.33 | −3.6% |

## Launch Commands

Same-node configuration used for the MTP516 benchmark. For the non-MTP baseline, omit the four `--speculative-*` arguments from both commands.

### Prefill

```bash
CUDA_VISIBLE_DEVICES=0,1,2,3 \
SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=1 \
SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python \
SGLANG_DISAGGREGATION_ENGINE_INIT_TIMEOUT=300 \
SGLANG_DISAGGREGATION_NIXL_BACKEND=UCX \
SGLANG_DISAGGREGATION_NIXL_BACKEND_PARAMS='{}' \
SGLANG_DISAGGREGATION_NIXL_LOCAL_SHM=1 \
UCX_TLS=tcp,cuda_copy,cuda_ipc,self,sm \
UCX_NET_DEVICES=lo \
sglang serve \
  --model-path /path/to/GLM-5.3-Flash \
  --served-model-name llm \
  --trust-remote-code \
  --tokenizer-worker-num 4 \
  --reasoning-parser glm45 \
  --tool-call-parser glm47 \
  --host 127.0.0.1 \
  --port 31000 \
  --nccl-port 29500 \
  --disaggregation-mode prefill \
  --disaggregation-transfer-backend nixl \
  --disaggregation-bootstrap-port 8998 \
  --tp-size 4 \
  --ep-size 4 \
  --mem-fraction-static 0.75 \
  --max-running-requests 48 \
  --cuda-graph-max-bs-decode 48 \
  --chunked-prefill-size 8192 \
  --cuda-graph-backend-prefill breakable \
  --kv-cache-dtype fp8_e4m3 \
  --mamba-ssm-dtype float32 \
  --dsa-prefill-backend tilelang \
  --dsa-decode-backend tilelang \
  --linear-attn-prefill-backend triton \
  --linear-attn-decode-backend triton \
  --linear-attn-verify-backend triton \
  --moe-runner-backend triton \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 5 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 6 \
  --enable-request-time-stats-logging
```

  --model-path /path/to/GLM-5.3-Flash \
  --served-model-name llm \
  --trust-remote-code \
  --tokenizer-worker-num 4 \

  --linear-attn-verify-backend triton \
