# [Fix] openai: Accept replayed assistant reasoning

[Upstream PR](https://github.com/sgl-project/sglang/pull/44109) · state: open · merged: False

## Original PR description

## Motivation

Some clients replay assistant reasoning as `reasoning`. SGLang currently reads `reasoning_content`, so the template can render an empty reasoning block for that history.

## Modifications

Copy a string `reasoning` value into `reasoning_content` only when the native field is missing or null. An explicit `reasoning_content` keeps precedence, and non-string aliases retain current handling.

## Accuracy Tests

The reasoning-replay regression and scoped formatting pass on the updated branch, including native-field precedence. Earlier checks with the real GLM-5.3-Flash tokenizer restored reasoning in rendered prompts. GPU serving and model evaluation remain unverified.

Run the unit suites with `python -m pytest` and formatting with `pre-commit run --files <changed-files>`.
