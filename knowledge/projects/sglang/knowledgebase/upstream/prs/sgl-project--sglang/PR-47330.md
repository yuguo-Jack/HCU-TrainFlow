# [Doc] cookbook: Add model-specific agentic recipes and evidence

[Upstream PR](https://github.com/sgl-project/sglang/pull/47330) · state: open · merged: False

## Original PR description

## Motivation

Add long-context agentic launch recipes and their recorded performance evidence to the existing GLM, Inkling, and DeepSeek cookbook pages.

## Modifications

- Extend the existing GLM-5.2, GLM-5.3, and DeepSeek-V4 agentic sections; add model-local agentic sections and deployment-panel links for GLM-5.3-Flash and Inkling. The diff touches **five existing model pages**, with no new pages or navigation entries.
- Add **12 model/GPU/TP recipes**, labeled collapsible commands, hardware/runtime prerequisites, and qualification notes. Preserve the explicit 1,048,576-token context limit for the six Inkling/DeepSeek recipes.
- Keep each model's evidence beside its recipes: **128 full-precision records**, 35 historical comparison groups, 42 SGLang 0.5.21 concurrency points, and four recorded GPQA comparisons. Collapsible catalogs retain configuration, runtime, workload, source-checksum, and qualification identities.
- Include the measured GLM-5.3 public-image command with its exact image digest and checkpoint revision, distinguishing its parser-off measurement from the parser-on recipe.

The placement follows the model-local agentic subsection in merged [#46825](https://github.com/sgl-project/sglang/pull/46825). These workload-specific recipes have different runtime, checkpoint, or launch conditions from the generic Deploy cells. Existing configuration/benchmark JSX and generated InferenceX data retain their established workload and verification status; historical custom-runtime measurements are not promoted into public-runtime benchmark cards.

## Accuracy Tests

The SGLang 0.5.20 campaign summaries report paired GPQA-Diamond evaluations, **five runs of 198 items per arm**:

| Selected recipe in its measured runtime | Speculation on | Speculation off |
| --- | ---: | ---: |
| DeepSeek-V4-Flash-0731 / B200 TP4 | 0.738 | 0.757 |
| DeepSeek-V4-Flash-0731 / H200 TP4 | 0.741 | 0.760 |
| DeepSeek-V4-Pro-0813 / B200 TP8 | 0.7434 | 0.7202 |
| DeepSeek-V4-Pro-0813 / H200 TP8 | 0.7495 | 0.7384 |

These are recorded historical summaries, with decision-receipt checksums included; raw per-item GPQA outputs are not retained in the CSVs. They do not qualify the changed SGLang 0.5.21 settings, larger context windows, tool calling, or multimodal behavior. No new GPU accuracy tests were executed for this documentation change.

## Speed Tests and Profiling

The model-local evidence preserves output tokens/s/GPU, mean ITL/TTFT, concurrency, replicate counts, errors, exact image identities, and client/workload settings. Historical averages include every retained repeat. The SGLang 0.5.21 tables retain all seven concurrency points per measured configuration, including the Flash B200 outlier and recorded request errors.

- SGLang 0.5.18/0.5.20 measurements use actual speculative verification where enabled, on synthesized hash-trace prompts with `ignore_eos`.
- All 42 recorded SGLang 0.5.21 points use simulated acceptance; these numbers do not qualify the natural-acceptance public launch commands.
- GLM-5.2 shortened-output results, GLM-5.3 parser differences, Pro's heterogeneous client settings, and the unmeasured GLM-5.3-Flash variant remain explicit.
- Custom-runtime digests and trace hashes identify measured artifacts without making them publicly downloadable. Public stock-image results remain separate controls.
