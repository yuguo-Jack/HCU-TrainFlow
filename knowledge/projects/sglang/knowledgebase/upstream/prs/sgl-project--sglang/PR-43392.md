# fix: preserve Qwen3-VL sub-config objects

[Upstream PR](https://github.com/sgl-project/sglang/pull/43392) · state: open · merged: False

## Original PR description

## Motivation

`Qwen3VLConfig` and `Qwen3VLMoeConfig` document support for config objects as well as dictionaries, but their constructors only assign `text_config`/`vision_config` for dictionaries or `None`. Passing an existing sub-config leaves the corresponding attribute unset:

```python
from sglang.srt.configs.qwen3_vl import Qwen3VLConfig

text = Qwen3VLConfig.sub_configs["text_config"](hidden_size=128)
config = Qwen3VLConfig(text_config=text)
config.text_config  # AttributeError before this fix
```

## Modifications

Preserve supplied sub-config objects in both constructors. Dictionary conversion and defaults are unchanged. Add a registered CPU regression covering object/dictionary combinations, object identity, serialization and round trips for both families.

## Accuracy Tests

On Linux/Python 3.12 with the pinned Transformers 5.19.0, using normal SGLang package imports:

```bash
python -m pytest test/registered/unit/configs/test_qwen3_vl_config.py -q
```

Before: all six object-input subcases fail with `AttributeError`. After: one test and all six subcases pass. Other dependencies are inherited from the test environment; this is not a full official CI or model-inference result.
