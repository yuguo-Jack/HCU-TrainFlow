# [diffusion] comfyui: consolidate FluxAdapter correctness fixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/43490) · state: closed · merged: True

## Original PR description

## Summary

Consolidates four separate FluxAdapter correctness fixes in the ComfyUI SGLDiffusion plugin, all touching `executors/flux.py` (plus one checkpoint-loader fix), into one PR with one commit per fix:

1. **Pad odd-sized latents to patch size.** `_pack_latents` viewed latents straight into 2x2 patches without padding; a ComfyUI latent whose height/width isn't a multiple of 2 raised a `RuntimeError`. Pads before packing and crops back in `unpack`, matching `QwenImageAdapter`.
2. **Zero-fill missing pooled vector + reject Kontext/ControlNet.** `pack()` previously sent `y=None` straight through (crashing the DiT embedding layer) and silently dropped `ref_latents`/`control`, running Kontext/ControlNet workflows as plain text-to-image with no error. Now zero-fills a missing `y` like native ComfyUI Flux, and raises a clear `ValueError` for Kontext/ControlNet instead of silently producing a wrong result (full support is out of scope; the backend `FluxPipeline` has nothing to route these into).
3. **Resolve `guidance_embeds` from checkpoint keys.** The checkpoint loader always assumed `guidance_embeds=True`; FLUX.1-schnell checkpoints don't have `guidance_in.*` weights, so loading schnell checkpoints failed with a misleading `ValueError`. Now resolves from the checkpoint's safetensors header, matching how ComfyUI itself decides.

Fixes #43487 (tracking issue covering all four: #43115, #43488, #43489, #43395).

## Test plan

- Added/kept regression tests in `test_comfyui_adapters.py` for the odd-latent-size roundtrip, pooled zero-fill, and Kontext/ControlNet rejection.
- Added regression tests in `test_comfyui_profile.py` for `guidance_embeds` resolution (dev-shaped vs schnell-shaped checkpoints).
- `py_compile` clean on all touched files; full suite needs CI (no local `sglang` install in this environment).
