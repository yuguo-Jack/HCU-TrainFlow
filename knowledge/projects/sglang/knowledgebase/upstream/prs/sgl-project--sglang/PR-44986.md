# [Perf] [AMD] kimi-k3: Fuse the attention output's TP8 all-reduce with the FFN-side read on gfx950

## Motivation

At Kimi-K3 decode sizes the attention output's TP8 all-reduce, the residual add and the FFN-side attention-residual
(AttnRes) bank read are separate small launches per layer.

## Modifications

Gated on gfx950 TP8 (`layers/communication/k3_ll_comm_hip.get_comm()`).

- `attn_res/read_hip.cuh` + `k3_attn_res_read_hip.py`: the attention output's one-shot all-reduce + residual add +
  FFN-side read (softmax over the bank rows and the stream, RMSNorm) in one LL kernel for 4-row batches (EAGLE C1
  verify; `SGLANG_ROCM_K3_FUSED_ATTN_AR_READ`), over #44985's LL communicator; its scratch region follows the gather
  read's.

The sums run in rank order, so every rank gets the same bits.

#44551 also had an opt-in two-shot variant for 5-64 rows (`SGLANG_ROCM_K3_FUSED_ATTN_AR_READ_MAX_ROWS`,
off by default); it measured slower than aiter's all-reduce + the Triton read, so it is not part of this PR.

| New env var | Default |
|---|---|
| `SGLANG_ROCM_K3_FUSED_ATTN_AR_READ` | on |

## Accuracy Tests

**Setup for every number below:** 8x MI350X (gfx950, 1000 W), Kimi-K3 (MXFP4 MoE, bf16 attention) at TP8 with EAGLE3
(topk 1, 3 steps, 4 draft tokens), FP8 KV cache, `SGLANG_USE_AITER=1`, aiter's K3 FlyDSL kernels
(`AITER_SITUV2_A8W4=1 AITER_FLYDSL_FORCE=1 SGLANG_AITER_K3_OPT=1`), CUDA graphs for bs 1/2/4/8/16, and an aiter bf16 GEMM table with K3 rows re-tuned on this pod with HBM-resident weights
(`AITER_CONFIG_GEMM_BF16`; not part of this PR, it belongs in aiter's model configs). EAGLE3 on K3 needs the
aux-capture commit of #43599, applied locally for these runs. Microbenchmarks rotate their weights through HBM.
Per-feature numbers were measured on the integration branch of this series as each piece landed (Oct 13-14,
earlier `main`). All branches of the series are on `main` 4eb606b2ae (2026-10-17); the kernel tests below ran on this
branch, and the end-to-end checkpoints on that `main` plus the queue up to each slot.

- GSM8K 200, every verify on the fused attention read: 0.985 / accept 3.613. End to end: see below.
- `test_k3_ll_collectives.py` (extended, 8 GPUs): the all-reduce read (one-shot, 4 rows, with and without the
  residual) gives the rank-order bf16 sum exactly and the read within rounding, the same on every rank. On MI350X,
  with #44985's gather checks: 1 passed.
- On MI350X, the existing layer-boundary tests `test_kimi_k3_stage_kernels.py` and `test_attn_bank_residual_ops.py`
  (this PR changes `attn_bank.py`): 9 passed, 7 failed (14 subtests passed). All 7 failures are in
  `test/registered/unit/layer_boundary/test_attn_bank_residual_ops.py`, which fails the same 7 tests on unmodified
  `main` on this pod (`'_Norm' object has no attribute 'weight'`), unchanged by this PR.
