# [Perf] [NVIDIA] fp8_fa_sm120: Run cross-attention when K/V length differs from Q

[Upstream PR](https://github.com/sgl-project/sglang/pull/48320) · state: open · merged: False

## Original PR description

## Motivation

The SM120 FP8 attention backend (`fp8_fa_sm120`) only ran when Q, K and V had the same shape. Every cross-attention call went to cuDNN BF16 instead. In LTX-2 that includes video-to-text cross-attention (8160 queries over 1024 text tokens at 960x544, 121 frames) in every transformer block.

The kernel already masks keys past the end of the sequence. The only thing missing was a key length separate from the query length.

## Modifications

- `kernel.py`: new compile-time `key_sequence`. Key masking is generated when the padded K buffer is longer than `key_sequence`, and it compares against `key_sequence` instead of the query length.
- `plan.py`:
  - `validate_inputs` accepts Q `[Sq, H, 128]` with K/V `[Skv, H, 128]`.
  - K and V must still share strides; Q may have its own.
  - The workspace pads Q to the query tile and K/V to the key tile separately.
  - The compiled-kernel cache key is `(Sq, Skv, H, device)`.
- `fused_prep.py`: the amax and pack passes take separate Q and K/V lengths and strides. The grid covers the longer of the two.
- Backend `fp8_fa_sm120_attn.py`:
  - The dense path accepts different Q and K/V lengths when heads and head_dim match.
  - The varlen path still falls back when the lengths differ.
- Masked cross-attention is unaffected: with a mask, `LocalAttention` calls PyTorch SDPA directly and never reaches this backend.

Self-attention (Sq == Skv) compiles and runs exactly the same kernel as before.

## Accuracy Tests

- **Self-attention:** output and LSE are bit-identical to `main`.
- **New unit tests** in `test_fp8_fa_sm120_attn.py`:
  - Cross-attention against cuDNN at (8160, 1024), (1000, 77) and (300, 2050). Together these cover key padding, a partial query tile, and K/V longer than Q. Relative RMS is below 8% and cosine similarity is above 0.995, the same bounds as the self-attention tests.
  - A cache-key test that checks cross-attention does not reuse a self-attention kernel.
- **Full file:** all 14 tests pass on an RTX 5090.
- **End to end (LTX-2.5 T2V, 3 prompts):** frames differ from the BF16 cross-attention baseline (PSNR 19–26 dB, which is typical for a change in FP8 rounding in a diffusion loop). Side-by-side frames look equivalent.

## Speed Tests and Profiling

Setup: one RTX 5090. LTX-2.5 T2V, 960x544, 121 frames, 15 steps, convrot INT8 GEMMs, `fp8_fa_sm120` for self-attention. Numbers are from the 2nd and 3rd request.

| | time per step | time per video |
|---|---|---|
| main | 0.597 / 0.603 s | 8.60 / 8.48 s |
| this PR | 0.587 / 0.592 s | 8.50 / 8.40 s |

The first call for each new (Sq, Skv) pair compiles once, about 10 s, like self-attention today.
