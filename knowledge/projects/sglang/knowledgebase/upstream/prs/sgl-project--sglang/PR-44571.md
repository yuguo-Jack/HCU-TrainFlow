# [Fix] qwen3_5: Warn on unknown visual bias in load_weights (#44504)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44571) · state: open · merged: False

## Original PR description

fixes #44504

`load_weights()` silently swallowed unknown `.bias` weights on all checkpoints via `if name.endswith(".bias") and name not in params_dict: continue`, causing unrecognized vision bias weights to be dropped without warning while unknown weights logged a warning.

this checks `is_gptq = quant_config is not None and getattr(quant_config, "quant_method", None) == "gptq"` and only silently skips extra biases when `is_gptq and "visual" not in name`. all other unknown parameters (including unknown vision bias weights) now emit a warning. added unit tests using `_RecordingParam` and mock named_parameters in `test/registered/unit/models/test_qwen3_5_pipeline_parallel.py`.
