# [Fix] dsv41: Use `--attn-dp-size` in the Engram docs and restore env overrides on exceptions

[Upstream PR](https://github.com/sgl-project/sglang/pull/46896) · state: closed · merged: True

## Original PR description

- Engram tables docs: the `peer_read` example sets attention DP with `--attn-dp-size 8` instead of the deprecated `--dp-size 8 --enable-dp-attention`.
- `EnvField.override` restores the variable in a `finally`, so an exception inside the `with` block no longer leaves the override set for later code and tests.

No behavior change, except that an env override is now undone when its block raises.
