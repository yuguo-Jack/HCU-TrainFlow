# [AMD] DeepSeek-V4.1: emit MXFP8 from the remaining prefill producers on gfx950

[Upstream PR](https://github.com/sgl-project/sglang/pull/42503) · state: closed · merged: False

## Original PR description

#42055 lets several producer kernels write MXFP8 for their consumers, which removed about 7 ms of standalone quant kernels per 100k prefill tokens in our traces. DeepSeek-V4.1-Flash prefill still runs about 16.5 ms of standalone quant kernels per 100k tokens, mostly the stage-1 and stage-2 input quants of the mixture-of-experts (MoE) layers inside aiter's fused MoE. This draft tracks moving those quants into their producers, which needs an aiter change first.

- Predicted from the prefill traces (MI355X, tensor parallel on 4 GPUs): about 0.8% less prefill GPU time.
- Conservative expectation: about 0.5% lower time to first token.
- Status: draft without code; needs an aiter fused-MoE change.
