# [Doc] cookbook: add Muse Spark unified memory control

[Upstream PR](https://github.com/sgl-project/sglang/pull/45360) · state: closed · merged: True

## Original PR description

## Motivation

Expose unified KV memory in the Muse Spark Open cookbook and select its default by deployment strategy. Depends on #45356 for Muse Spark runtime support; merge after that PR.


Blocked until next stable release

## Modifications

- Add **Unified Memory: Enable / Disable** using the existing generic Playground control. The initial selection inherits the Deployment command, and changing Deployment resets overrides.
- Enable `--enable-unified-memory` for every NVIDIA High Throughput recipe (B200, B300, GB300, H200). Low Latency recipes leave it disabled.
- Keep MI355X and Xeon disabled and grey out Enable with an explanation: their `aiter` / `intel_amx` backends are outside the unified-layout allowlist.

## Accuracy Tests

- Cookbook config validator and pre-commit passed.
- Checked all 24 deployment cells with the actual Playground handler: inherited values, enable/disable commands, repeated application, and hardware gating.
- Browser smoke passed: strategy defaults, explicit overrides, reset on Deployment changes, and disabled AMD Enable.
- Isolated Muse Spark page passed `mint validate --disable-openapi`; `mint broken-links` found no broken links.
- Full-site validation is blocked by the existing syntax error at `docs/src/snippets/configs/popular-models.jsx:100`, unchanged by this PR.
