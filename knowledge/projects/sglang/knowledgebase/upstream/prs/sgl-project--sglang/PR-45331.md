## Motivation

Repeated `release_memory_occupation` with the same tag re-entered the
memory-saver pause path. Combined with a missing device sync, the CPU
backup could be overwritten with data read from already-unmapped memory
or with tensors whose producing kernels were still in flight.

## Modifications

- Skip tags that are already in `self.offload_tags` and log a warning.
- `torch.get_device_module().synchronize()` before calling `pause()`.
