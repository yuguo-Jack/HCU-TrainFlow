## Motivation

NPU diffusion startup emits warnings from CUDA-only features, legacy tensor serialization, and unsupported internal-format settings. CLI generation also leaves generator cleanup to process exit.

This PR reduces unnecessary console output and ensures the CLI closes the generator after successful or failed generation.

## Modifications

- Skip CUDA-only GELU fusion registration and numerics settings on NPU.
- Defer the MiniMax sparse-attention import until its backend is used.
- Use zip serialization for CPU tensors in worker configuration payloads.
- Guard global internal-format settings on Ascend 950.
- Avoid logging the same static fusion rejection repeatedly.
- Use the generator context manager for CLI cleanup.
- Add regression coverage for serialization, numerics settings, and shutdown.

## Accuracy Tests

14 CPU local unit tests passed across worker bootstrap, numerics policy, and generator shutdown.

Lint, formatting, and whitespace checks passed. Model accuracy and target-NPU warning checks were not run.
