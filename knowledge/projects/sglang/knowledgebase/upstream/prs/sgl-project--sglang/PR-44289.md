# fix(speculative): add missing pp_proxy_tensors param to frozen_kv_mtp and uno spec-v2 workers

[Upstream PR](https://github.com/sgl-project/sglang/pull/44289) · state: closed · merged: False

## Original PR description

## Background

Issue #40155 reports that the scheduler's non-overlap speculative path always passes `pp_proxy_tensors` to `model_worker.forward_batch_generation(...)`, but some spec-v2 workers had diverged signatures and would crash on the first scheduler step with:

```
TypeError: <Worker>.forward_batch_generation() got an unexpected keyword argument 'pp_proxy_tensors'
```

Three of the seven spec workers were already fixed (`eagle_worker_v2`, `dflash_worker_v2`, `ngram_worker`, `multi_layer_eagle_worker_v2` in PR #29189, and `dspark_worker_v2` in #39262). Two were still missing the parameter on the upstream main branch: `frozen_kv_mtp_worker_v2` and `uno_worker_v2`.

## Problem

The original `forward_batch_generation` signatures:

- `FrozenKVMTPWorkerV2`: `(self, batch, on_publish=None, grammar_barrier=None)`
- `UnoWorkerV2`: `(self, batch, on_publish=None, grammar_barrier=None)`

Both rejected the keyword argument the scheduler always provides.

## Solution

Mirror the same one-line signature fix applied to the other workers:

### `frozen_kv_mtp_worker_v2.py`
- Add `pp_proxy_tensors=None` to the `forward_batch_generation` signature.
- Propagate it to the `self.target_worker.forward_batch_generation(...) ` call on the prefill path.
- Propagate it to `self.verify(...) ` (inherited from `EAGLEWorkerV2`, which already accepts it).

### `uno_worker_v2.py`
- Add `pp_proxy_tensors=None` to the `forward_batch_generation` signature.
- Thread it through to `_forward_prefill`, `_forward_decode`, and `_forward_decode_tree`.
- Forward it to `self.target_worker.forward_batch_generation(batch, pp_proxy_tensors=...)` on the prefill path.
- The decode path uses `ForwardBatch` internally (not a `ScheduleBatch`) so the parameter is accepted for signature consistency but not forwarded further.

## Verification

- Syntax check: `ast.parse` passes for both modified files.
- All 7 spec-v2 workers now expose a `forward_batch_generation` with `pp_proxy_tensors` in its signature.
- `FrozenKVMTPWorkerV2` inherits from `EAGLEWorkerV2`, whose `verify` method already supports `pp_proxy_tensors=None`.

## Testing

No GPU required for this Python-level signature fix. Run:

```bash
PYTHONPATH=python python -c "
import ast
ast.parse(open('python/sglang/srt/speculative/frozen_kv_mtp_worker_v2.py').read())

print('Both files parse OK')
"
```
