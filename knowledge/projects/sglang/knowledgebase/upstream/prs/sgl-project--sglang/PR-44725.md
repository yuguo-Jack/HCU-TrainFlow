# [Fix] minimax_h3: Support out-of-tree platforms

[Upstream PR](https://github.com/sgl-project/sglang/pull/44725) · state: closed · merged: True

## Original PR description

## Motivation

MiniMax H3's full-loop denoising stage rejects out-of-tree platforms because its platform allowlist only includes CUDA, HIP, CPU, MPS, NPU, and XPU.

This prevents out-of-tree backends from reaching the denoising loop, even when they provide the required device APIs and operators.

## Modifications

- Accept `current_platform.is_out_of_tree()` in the full-loop denoising platform check.
- Update the error message to include out-of-tree platforms.

This change removes the platform gate for out-of-tree backends. Each backend remains responsible for implementing the required operations.
