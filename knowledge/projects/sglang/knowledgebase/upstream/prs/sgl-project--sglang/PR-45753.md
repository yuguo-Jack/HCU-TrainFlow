## Motivation

Qwen3.8 context-parallel prefill now reads selected K/V tokens directly from the cache instead of gathering and concatenating each request’s full cached prefix. A small index-to-slot mapping pass eliminates redundant prefix copies and synchronization, reducing memory traffic and attention latency.
