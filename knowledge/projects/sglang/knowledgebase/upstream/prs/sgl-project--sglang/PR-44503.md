# [Refactor] sparse-mla: Expose arithmetic and DSA metadata hooks

[Upstream PR](https://github.com/sgl-project/sglang/pull/44503) · state: closed · merged: True

## Original PR description

Add four extension points for custom MLA arithmetic and DSA metadata while retaining the SRT forward lifecycle: `run_mla_indexer`, `prepare_mla_qkv`, `project_mla_values`, and `init_kernel_metadata`.

Defaults preserve existing operations and fast paths. Query-transforming overrides set `needs_unfused_mla_qkv = True` to receive materialized queries. Custom indexers run during CP prefill; custom metadata refreshes on replay and opts out of glue capture. LoRA correction, output gating/projection, shared-index reuse, and seed handoff remain in the existing lifecycle.

**Scope:** ROCm dense MHA preparation dispatches the indexer hook. The separate `MLA_ROCM` absorbed path bypasses the arithmetic hooks and requires its own overrides.
