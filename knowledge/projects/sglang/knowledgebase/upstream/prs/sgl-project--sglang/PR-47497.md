# [Fix] profile: Allow profile_by_stage without num_steps

[Upstream PR](https://github.com/sgl-project/sglang/pull/47497) · state: open · merged: False

## Original PR description

## Motivation

`POST /start_profile` with `profile_by_stage: true` and no `num_steps` left the stage counters as `None`. The next prefill did `None += 1` and killed every scheduler. Fixes #47294.

## Modifications

Stage counters start at 0 whenever `profile_by_stage` is set. A missing `num_steps` no longer auto-stops the profile; `/stop_profile` still ends it.
