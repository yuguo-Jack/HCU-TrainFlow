# [Perf] MiniMax-H3: fused indexed modulation for FP32 AdaLN tables

[Upstream PR](https://github.com/sgl-project/sglang/pull/44180) · state: closed · merged: True

## Original PR description

## Motivation

Serialized INT8 MiniMax-H3 checkpoints keep their AdaLN shift/scale/gate tables in FP32. `_modulate_scale_shift` and `_modulate_gate` only had BF16 kernels, so these checkpoints fell back to eager `index_select` + multiply + add + cast. That is about 100 gate calls and 1 scale/shift call per forward, each making several full-size passes.

## Modifications

- Add `indexed_scale_shift_fp32_`, `indexed_gate_fp32` and `indexed_gate_fp32_` next to the BF16 kernels in `kernels/ops/diffusion/modulate/indexed_modulation_triton.py`, export them from the diffusion facade, and document them in the kernels README.
- They keep eager torch's rounding: the product goes through `mul_rn_f32` so the following add cannot contract into an FMA, and the result rounds to BF16 once at the store.
- `minimax_h3.py` dispatches to the FP32 kernels by table dtype. It also requires unit column stride on the tables before taking any kernel path, because the kernels index columns contiguously. The eager fallback is unchanged.

## Accuracy Tests

- New tests in `test/registered/kernels/ops/diffusion/test_indexed_modulation.py` require `torch.equal` with eager. They use strided slices of a `[rows, 6*hidden]` table and include cancellation cases. 48 passed on H200.
- H3 unit tests pass.
- H3 whole-model outputs are bit-identical with and without the change (4090, 5090 and H200).

## Speed Tests and Profiling

Kernel at [32700, 5376] on H200: gate 1720 µs → 256 µs, scale/shift 2121 µs → 180 µs.

H3 pruned INT8, SGLD ComfyUI workflow, 4 steps × 3 seeds, comfy_kitchen backend. Steady model-time gain:

| GPU | 480p | 768p | Ref2VA / 4 refs |
|---|---:|---:|---:|
| RTX 4090 | +5.51% | +3.10% | +2.79% |
| RTX 5090 | +4.55% | +2.69% | +2.18% |
| H200 | +4.75% | +3.10% | +2.99% |

H200 with the default JIT backend: +3.44% on 480p. Whether the change applies depends on the checkpoint having FP32 AdaLN tables, not on the GPU or INT8 backend. The full BF16 H3 checkpoint does not hit these kernels.
