# [Fix] openai: expose reasoning tokens in completion_tokens_details

[Upstream PR](https://github.com/sgl-project/sglang/pull/46094) · state: closed · merged: False

## Original PR description

## Motivation

OpenAI clients look for `usage.completion_tokens_details.reasoning_tokens`, but SGLang only emits the legacy top-level counter. SDK users miss the reasoning usage even when it was measured.

## Changes

Derive the standard nested field from the existing cumulative counter, so normal and streaming serialization stay in sync. Keep the legacy field for existing clients.

## Validation

The new regression fails on main with the nested field missing. The fixed protocol module passes the existing CPU protocol suite, including dict/JSON serialization, missing/zero counts and cumulative updates. No model execution changes.
