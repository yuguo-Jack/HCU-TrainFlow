# [rust] Update Dynamo frontend crates to latest compatible releases

[Upstream PR](https://github.com/sgl-project/sglang/pull/42666) · state: closed · merged: True

## Original PR description

Upgrade the Dynamo frontend crates together across the Rust workspace and sgl-router, which path-depends on `sglang-processor`. Use the latest stable releases checked on October 7, 2026:

| Crate | Version |
| --- | --- |
| `dynamo-renderer` | 7.0.1 |
| `dynamo-tokenizers` | 3.1.0 |
| `dynamo-protocols` | 7.0.0 |
| `dynamo-parsers` | 9.2.8 |

Stacked on #42665.

## Changes

- Update both lockfiles, including the required `async-openai` 0.42.1 upgrade. Renderer 7.0.1 and parsers 9.2.8 both use protocols 7, resolving the earlier version constraint.
- Flush `DecodeStream::finish()` at the final chunk in the server and renderer; run the renderer's flushed tail through its stop matcher.
- Preserve tools declared in system messages when building tool constraints and parsing server responses.
- Adapt test literals to the protocol's system-message tools and optional `prompt_cache_breakpoint` fields.
- Keep unsupported V4.1 media and Kimi K3 system turns containing both content and tools on the router's engine fallback path.
- Renderer 7.0.1 fixes DeepSeek float formatting. Remove the two obsolete V4 parity `known_gap` markers without changing the expected prompts or token hashes.

## Validation

- At this PR: processor, renderer, and server tests pass (492); router library, component, and proxy tests pass (1,378).
- DeepSeek-V4-Flash-0731 prompt and token parity pass against its pinned checkpoint, including both formerly marked float cases.
- The five downstream PRs were rebased and tested together: 484 Rust tests and 1,386 router tests pass. V4/V4.1 prompt, token, and OpenAI parity fixtures run with cached pinned checkpoint files; the two pre-existing V4.1 developer-message gaps remain marked.
- Clippy and formatting pass in both workspaces; the processor also builds with only `render,tokenizer` enabled.
