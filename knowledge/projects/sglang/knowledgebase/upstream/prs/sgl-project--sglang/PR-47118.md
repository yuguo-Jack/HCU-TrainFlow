# [CI] [AMD] diffusion/ming: Skip the CUDA-only fused RMSNorm test on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/47118) · state: closed · merged: True

## Original PR description

## What

Skip `test_ming_norm_fusion_replay_and_native_fallback` in `test_ming_image.py` on ROCm. The skip condition was `not torch.cuda.is_available()`, which is false on ROCm, so the test ran there. CUDA behavior is unchanged.

## Why

The test was added in #46705 and asserts that the mocked `rmsnorm_cast_before_weight_bitexact` kernel is called once. On ROCm, `can_use_rmsnorm_cast_before_weight` returns False because it requires `is_cuda()`, so `MingRMSNorm` correctly takes the native path and the kernel is never called. Both parametrizations fail with `assert (0 == 1)` on the first scheduled PR Test (AMD) rocm10 run that contains the test, on the first attempt and the retry: [multimodal-gen-test-1-gpu-amd (rocm10, 3)](https://github.com/sgl-project/sglang/actions/runs/40686510947/job/122810254546).

The native path is still checked by the CPU test in the same file, which compares `MingRMSNorm` bit-exactly against an fp32-variance reference.
