# [Fix] cache: Roll back host slots when allocation raises

[Upstream PR](https://github.com/sgl-project/sglang/pull/46606) · state: closed · merged: True

## Original PR description

## Motivation

HiCache can reserve primary KV and one auxiliary pool before another pool's allocation or reclaim callback raises. Only the `None` result is currently rolled back, so that exception leaves host slots reserved even though no backup was queued.

## Modifications

Roll back the auxiliary allocations made by the current resolution call, then release the primary KV reservation at the controller boundary. Caller-provided allocations stay owned by the caller, and successfully queued operations keep their slots.

If a release callback also raises, drain the other reservations without retrying the failed release. Re-raise the original allocation error with the cleanup error as its cause.
