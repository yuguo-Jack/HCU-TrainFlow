# [Perf] diffusion: keep GQA and MOSS-Image attention on cuDNN SDPA on Blackwell

[Upstream PR](https://github.com/sgl-project/sglang/pull/47586) · state: closed · merged: True

## Original PR description

## Motivation

On B200 (sm_100), #33655 made dense diffusion attention default to `DYNAMIC_CUDNN_SDPA`, which uses cuDNN SDPA and falls back to FA4. Two models still did not get cuDNN.

**Cosmos3 (grouped-query attention, 32 query / 8 KV heads).** `DynamicCudnnSDPAImpl._use_cudnn_sdpa` returns False whenever query and key head counts differ, so every Cosmos3 DiT layer ran FA4. `CudnnSDPAImpl` already handles GQA: `SDPAImpl.forward` passes `enable_gqa=True`. Forcing `--attention-backend torch_cudnn_sdpa` was 14% faster in denoise.

**MOSS-Image.** The main DiT blocks pin `default_attention_backend=FA`, so the Blackwell default never applies to them.

This was found while benchmarking the cookbook commands on B200: forcing `--attention-backend torch_cudnn_sdpa` made Cosmos3-Nano T2V 720p 13% faster end to end than the default.

## Modifications

- **`DynamicCudnnSDPAImpl._use_cudnn_sdpa`.** On sm_10x, grouped-query attention stays on cuDNN when the query heads are a multiple of the KV heads. The existing tile-size rule for short sides still applies. Pre-Blackwell GPUs and uneven head groupings keep the FA path.
- **MOSS-Image `_Block`.** The `default_attention_backend=FA` pin is removed, so the platform default applies:
  - Hopper: FA, as before.
  - sm_10x: `DYNAMIC_CUDNN_SDPA`.

  The two text-refinement blocks keep FA. The supported-backend set is unchanged, since `DYNAMIC_CUDNN_SDPA` is accepted wherever FA and Torch SDPA are.
- **`test_dynamic_cudnn_sdpa_routing.py`.**
  - GQA, both self- and cross-attention shapes, stays on cuDNN on sm_100.
  - Uneven head grouping, and GQA before Blackwell, stay on FA.

## Accuracy Tests

The kernels are the ones Blackwell already uses for multi-head attention: cuDNN SDPA through `CudnnSDPAImpl`, with FA4 as the fallback. Only the routing changes, for the two cases above. As with #33655, cuDNN and FA4 round differently, so outputs are not bit-identical to the FA4 path.

`test_dynamic_cudnn_sdpa_routing.py` and `test_dynamic_cudnn_sdpa_selection.py`: 8 passed on B200.
