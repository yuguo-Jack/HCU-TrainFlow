# [WIP][Refactor] PD+PD: Remove ring-consensus for release at prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/45085) · state: open · merged: False

## Original PR description

## Motivation

This is a follow-up work to #38959.  In #38959, we have replaced ring-consensus for bootstrap.  In this PR, we do the same thing for request releasing consensus.

## Modifications

1. Remove ring-consensus code in `event_loop_pp_disagg_prefill`.
2. In `process_disagg_prefill_inflight_queue`, retrieve consensus state (i.e. `poller.poll_pp_consensus`) and propagate decision to other PP ranks.
3. Add dedicated P2PTag and work list as well for bootstrap and release consensus communication respectively

## Speed Tests and Profiling

This benchmark tests input=4096 and output=1 with various concurrency. Supprisely, this PR shows **better TTFT** against the baseline **under medium concurrency**.    **However, when set output=16, this PR is slower than the baseline.  I'm investigating into this problem.**
