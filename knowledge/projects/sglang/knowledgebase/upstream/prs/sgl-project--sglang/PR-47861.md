# [Doc] cookbook: add Unlimited-OCR-2 NVIDIA platform recipes

[Upstream PR](https://github.com/sgl-project/sglang/pull/47861) · state: open · merged: False

## Original PR description

The Unlimited-OCR-2 command picker currently exposes only L20. Add single-node BF16 TP1 starting recipes for H100, H200, B200, B300, GB200 and GB300, including explicit Docker image mappings. The shared Deployment and Playground widgets continue to generate Python/Docker commands and TP overrides.

Mark all six additional recipes **Not Verified**. H200/B200 service smoke tests used smaller page budgets and bounded concurrency/graph sizes; they do not verify the exact 8,000-token/page cookbook recipes. Preserve the existing L20 recipe and its badge.

Document Linux/CUDA 13 prerequisites, same-node TP2, and memory tuning that preserves weight/KV precision. Keep the required model-selected DASH backend on Blackwell as well.

Validation: cookbook config checks, seven-cell invariant checks, Mintlify build validation, broken-link checks, and applicable pre-commit hooks passed. Documentation only; no new GPU validation or benchmark claims.
