# [Doc] examples: Demonstrate CPU prefix reuse with full-response metrics

[Upstream PR](https://github.com/sgl-project/sglang/pull/44066) · state: open · merged: False

## Original PR description

## Motivation

Maintenance requests can share a fixed manual while only the sensor observation
changes. Add a small client showing how to place that manual first, preserve its
exact token prefix, and inspect SGLang's existing cache reuse through complete
OpenAI-compatible streaming responses.

## Modifications

```text
fixed manual + changing observation -> /v1/completions -> text + cache usage
```

The example reports first-text and full-response latency, completion-token counts,
cache hits and output checks. It distinguishes unknown cache usage from zero,
rejects incomplete streams, and keeps incorrect model outputs. Request failures
are written to JSONL and return a nonzero exit code. Outer Markdown fences can be
normalized for schema checks; raw text and raw JSON validity remain separate.

Scope: four files (client, short guide, runtime README link, registered CPU unit
tests). No serving, scheduler or kernel changes. This demonstrates existing cache
behavior; it does not introduce a new cache algorithm or claim a speedup from
this patch. `bench_serving` remains the tool for throughput benchmarks.
