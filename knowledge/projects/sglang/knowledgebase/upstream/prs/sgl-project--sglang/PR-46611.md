# [Fix] forward-hooks: Warn when CUDA graphs skip Python hooks

[Upstream PR](https://github.com/sgl-project/sglang/pull/46611) · state: open · merged: False

## Original PR description

## Summary
- Code follow-up to docs PR #45318 for issue #45317.
- CUDA graph replay never runs PyTorch forward hooks, so configured `forward_hooks` can silently never fire.
- Log a startup warning when `forward_hooks` are set and CUDA graphs are enabled, and point users at `--disable-decode-cuda-graph` / `--disable-prefill-cuda-graph` (or the matching Engine kwargs) if they need hooks on every forward pass.

## Test plan
- [x] `PYTHONPATH=python:test python3 test/registered/unit/model_executor/test_hook_manager.py`
- [ ] Confirm the warning appears at server startup when `forward_hooks` are configured and CUDA graphs are enabled
- [ ] Confirm no warning when CUDA graphs are disabled or no hooks are configured

Fixes #45317
