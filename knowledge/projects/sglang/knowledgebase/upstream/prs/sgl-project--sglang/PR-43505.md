# [CI] Fix Python 3.10 failure in prefill complete integration test

[Upstream PR](https://github.com/sgl-project/sglang/pull/43505) · state: closed · merged: True

## Original PR description

## Motivation

#43442 added two `self.enterContext(...)` calls to `TestAllocationIntegration.inflight_scheduler` in `test/registered/unit/disaggregation/test_prefill_complete_integration.py`. `unittest.TestCase.enterContext` only exists on Python 3.11 and later, and the `base-a-test-cpu` runner uses Python 3.10, so the test fails with `AttributeError: 'TestAllocationIntegration' object has no attribute 'enterContext'`. The same shard failed on #43442 itself, and every PR that merges current `main` now hits it.

## Modifications

Replace both calls with the existing `enter_scope` helper from `sglang.test.test_utils`, which enters a context manager for the length of one test and is safe on Python 3.10. Other unit tests already use it for the same reason. No behavior change.

## Test plan

`python3 test/registered/unit/disaggregation/test_prefill_complete_integration.py`

- Before, with `TestCase.enterContext` removed to match Python 3.10: 41 tests, 2 errors with the `AttributeError` above.
- After, with `TestCase.enterContext` removed: 41 tests pass.
- After, on Python 3.12 as is: 41 tests pass.
- `ruff format`, `ruff check` with the pre-commit rule set, and `isort` pass.
