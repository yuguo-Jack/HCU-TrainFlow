[Upstream PR](https://github.com/sgl-project/sglang/pull/42888) · state: open · merged: False

## Original PR description

Part 21 of 21 of the LoRA runtime stack (branch `lora-stack-20-nvfp4`, base `lora-stack-19-fp8-tables`). The stack is cut from the development branch of #42284.

## What this part adds

Add the Marlin NVFP4 provider over prepared Marlin weights, the NVFP4 quant
info, the legacy hook's Marlin weight lookup, and the server-arg rule that
NVFP4 MoE LoRA requires lora_marlin.

Tests: NVFP4 provider numerics and the server-arg guard.
