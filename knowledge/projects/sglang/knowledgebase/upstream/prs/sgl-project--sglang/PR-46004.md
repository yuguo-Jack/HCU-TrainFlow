# [Fix] server-args: Preserve dash-prefixed scalar values in YAML configs

[Upstream PR](https://github.com/sgl-project/sglang/pull/46004) · state: closed · merged: False

## Original PR description

## Motivation

YAML scalar values are converted to separate command-line tokens. A value such as `api-key: "--host"` is then interpreted as another option, so startup fails with `argument --api-key: expected one argument`.

## Modifications

Use `--option=value` when a scalar value starts with a dash. Add a regression using the server argument parser for dash-prefixed API keys and model names, including CLI overrides before and after `--config`.

## Accuracy Tests

Model accuracy is unaffected. The registered server-arguments CPU test file passes: 317 tests and 151 subtests. The new regression fails on the base revision with the expected argument-parsing error.

## Speed Tests and Profiling

Not applicable; this change affects startup argument conversion.
