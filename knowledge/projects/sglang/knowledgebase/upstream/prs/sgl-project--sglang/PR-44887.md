# [Fix] diffusion: runtime utils bug fixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/44887) · state: closed · merged: True

## Original PR description

Part of #43875 (items 8-24). Split out of #43585 so it can be reviewed on its own. It touches only `runtime/utils` and its tests, and does not depend on the other two PRs (#43585, #44888).

## Summary
Bug fixes in `multimodal_gen/runtime/utils`, one commit per item. Item numbers match #43875.

Downloads and inputs
8. `load_video` never deleted the video it downloaded from a URL, so `/tmp` filled up over time. It now cleans up (also on failure) and the download has a timeout.
9. Line-wrapped base64 images were silently cut at the first line. The data URL regex now matches across newlines.

Hub, cache and config loading
10. An unreachable Hub was treated as "this repo has no model_index.json", so the cache fallback never ran. It now falls back to the cached copy.
11. The same condition sent `maybe_download_model_index` down the single-model path with a misleading "-Diffusers" error. It now reports the download failure.
12. A local cache dir of `ltx-2.3-distilled` matched the `ltx-2.3` overlay by substring. Cache dirs are now matched by path component.
13. An overlay repo resolved by Hub id downloaded only its manifest, so `model_index.json` was missing on a fresh cache. It now downloads the full overlay metadata.
14. `scheduler` anywhere in a component's path made every component read `scheduler_config.json`. Only the component dir name counts now.
15. Normalizing a ModelOpt `config.json` wrote through the HF cache symlink and changed the shared blob. The file is now replaced instead.
16. The ModelScope LoRA path raised a `TypeError` when no weights were found. It now raises a `FileNotFoundError` that says so.
17. Corrected a comment claiming CI validation failures after download are retried (they are not).

Precision, logging and misc
18. `temporary_module_dtype` restored the whole module to the first parameter's dtype, undoing mixed precision (bf16 weights with fp32 norms). Each tensor keeps its own dtype now.
19. All `RequestMetrics` instances compared equal. They compare by identity now.
20. `log_request_summary` ignored its `tag` argument. It is honored now, with the previously written value as the default, so existing callers see no change.
21. `get_git_commit_hash` ran `git rev-parse` in the current directory. It now runs in the sglang install dir.
22. The "log on every rank at DEBUG" rule read the log level when the logger was created, before `configure_logger`. It reads it at log time now.
23. Enabling the NVTX hooks between a module's pre- and post-hook popped a range that was never pushed. Push and pop stay balanced across toggles.
24. `get_bool_env_var` warned once per bad value instead of once per variable. It is keyed by name now.

## Tests
- New unit tests for each item except 16, 17 and 21 (error message, comment, and cwd-only changes). They extend the existing test files and fixtures. `test_runtime_utils_regressions.py` is new because `vision`, `image_io` and `common` have no unit test file yet.
- PR, the 7 touched test files: 136 pass. 101 ran on a CPU Modal container; `test_performance_metrics.py` (35) ran on an A10G because it imports `vsa`, which needs a GPU at import time.
- main with these tests: 16 of the 18 new cases fail. The two that pass guard behavior main already has: the cached single-model path (`test_unreachable_hub_model_index[True]`) and rejecting a newline in the media type.
- Not run: the full unit suite and a GPU end-to-end run.

File: `python/sglang/multimodal_gen/runtime/utils/precision.py` · line None

[P2] Please also pass `remove_duplicate=False` to this `named_buffers` call. A single module can register the same tensor as both `first` and `second`; the default iterator records only `first`, while `module.to()` converts both registrations into separate tensors. I reproduced FP32 buffers returning as `first=float32, second=float16` after an FP16 context. The shared-buffer test currently covers different owners, which misses this case. As a small cleanup, the parameter snapshot can exclude buffers now that buffer restoration has its own owner/name records.

- BBuf · comment · 2026-10-21T07:02:12Z · [source](https://github.com/sgl-project/sglang/pull/44887#discussion_r4333929554)

File: `python/sglang/multimodal_gen/runtime/utils/hf_diffusers_utils.py` · line None

Non-blocking cleanup: could we create this sibling file with `tempfile.NamedTemporaryFile`/`mkstemp` rather than a PID-only suffix? Two calls for the same component in one process share the current temporary name, so one can truncate or replace the other's file. A unique temporary filename preserves the symlink-safe `os.replace` approach and avoids that collision; keep it in the destination directory so replacement stays atomic.

- BBuf · comment · 2026-10-21T07:02:12Z · [source](https://github.com/sgl-project/sglang/pull/44887#discussion_r4333929559)

File: `python/sglang/multimodal_gen/runtime/utils/vision.py` · line None

Non-blocking cleanup: this now has separate cleanup paths for download and decode errors, plus `was_tempfile_created`, manual `close()`, and two `os.remove()` calls. Could we put the downloaded file inside a `TemporaryDirectory` context spanning download and decode, and use a closing context for the response? The local-file path can stay unchanged. That preserves cleanup on every exit with less state and nested exception handling.
