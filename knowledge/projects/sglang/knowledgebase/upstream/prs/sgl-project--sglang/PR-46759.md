# [CI] [NPU] nightly: add rerun suites for three 2-NPU cases

[Upstream PR](https://github.com/sgl-project/sglang/pull/46759) · state: closed · merged: True

## Original PR description

## Motivation

The 2026-10-26 Nightly Test (NPU) run had three 2-NPU cases fail on host-side pinned-memory allocation (`aclrtMallocHostWithCfg, error code 207001`), not on test logic: `test_npu_qwen3_6_35b_a3b_1p_aime26.py`, `test_npu_mla_fia_hicache_bf16.py`, `test_npu_moe_dense_tp_size.py`. This PR adds dedicated suites and jobs so the three cases can be re-run in isolation.

## Modifications

- Register the three cases into two new nightly suites: `nightly-rerun-2-npu-a3` (runner label `linux-aarch64-a3-2-`) and `nightly-rerun-alt-2-npu-a3` (`linux-aarch64-a3-2`). A distinct suite name is required because `_npu-single-node-test-stage.yml` keys its concurrency group by `test_suite`.
- Declare both suites in `test/run_suite.py` (`NIGHTLY_SUITES[NPU]`).
- Add the `nightly-rerun-2-npu-a3` and `nightly-rerun-alt-2-npu-a3` jobs to `nightly-test-npu.yml`.
- Temporarily set `if: false` on all other nightly jobs, so a nightly run triggered by this PR executes only the two rerun jobs. This will be reverted before merge.
