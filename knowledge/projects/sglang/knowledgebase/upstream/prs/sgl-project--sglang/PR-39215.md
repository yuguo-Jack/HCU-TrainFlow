# [Feat] attention: Enable DSA DCP on SM120 with MTP support

[Upstream PR](https://github.com/sgl-project/sglang/pull/39215) · state: open · merged: False

## Original PR description

## Summary

- Enable the upstream DCP path with `flashinfer_sparse_mla` on SM120: local KV-page indexing, attention output/LSE, and neutral outputs for empty local shards.
- Preserve upstream communication and scheduling.
- Fix cuBLAS workspace lifetime around CUDA graph capture.

## Accuracy

GLM-5.2 NVFP4, TP8/PP1, natural MTP5; GSM8K, 1,319 questions, 5-shot, temperature 0, maximum 4,096 output tokens.

| Configuration | Correct | Accuracy |
|---|---:|---:|
| No DCP | 1,282 / 1,319 | 97.19% |
| DCP4 | 1,286 / 1,319 | 97.50% |

No request errors. Backend numerical/CUDA-graph tests and PP smoke tests also passed.

## Performance

8× RTX PRO 6000, GLM-5.2 NVFP4, TP8/PP1, AgentX fast, MTP5 gold (controlled acceptance length 3.61), 3,600-second target profiling window, no offloading. Each on/off pair uses the same production code, runtime and memory/graph settings: C4 graph8 / memory fraction 0.90; C8 graph16 / 0.86.

| C | Configuration | Throughput (total tokens/s/GPU) ↑ | P90 TTFT (ms) ↓ | P90 TPOT (ms) ↓ | KV usage | Prefix hit (trace/server) |
|---|---|---:|---:|---:|---:|---|
| 4 | TP8 + MTP5 | 462.65 | 262,653.06 | 172.53 | 99% | 98.00% / 26.80% |
| 4 | TP8 + MTP5 + DCP4 | 1,981.70 | 6,565.19 | 28.93 | 73% | 97.46% / 97.32% |
| 8 | TP8 + MTP5 (capacity-limited†) | — | — | — | — | — |
| 8 | TP8 + MTP5 + DCP8 | 2,555.40 | 9,123.28 | 63.87 | 74% | 97.52% / 97.26% |

At C4, DCP4 improved throughput/GPU by **4.28×** and reduced P90 TPOT by **83.2%**; at C8, DCP8 supported the workload within the tested memory budget.

Metrics use completed requests; throughput includes input + output tokens. Tail cancellations: C4 no DCP 4, C4 DCP4 0, C8 DCP8 1. KV usage is the sampled peak excluding evictable cache; server prefix hit uses profiling counter deltas including drain.

† C8 without DCP exceeded the KV capacity under the tested memory budget.

- Yuening-wa · comment · 2026-11-04T16:13:32Z · [source](https://github.com/sgl-project/sglang/pull/39215#issuecomment-6635685314)

Rebased onto main. With `--dcp-size > 1`, SM120 now uses the #39165 default `a2a` backend, which auto-enables `--dcp-replicate-q-proj`. The results in the description used `ag_rs`.

ITL P50, TP8+DCP8, 256K-token context, `ag_rs` → `a2a`:

| Config | `ag_rs` | `a2a` | Change |
|---|---|---|---|
| C16 | 57.3 ms | 51.0 ms | −11% |
| C128 | 180 ms | 158 ms | −12% |
| C16, MTP5 (per verify step) | 143.6 ms | 126.3 ms | −12% |

GSM8K accuracy is unchanged (97.27% vs 97.65% for TP8). Replicated Q costs ~6.5 GiB/GPU, so use `--mem-fraction-static 0.86` (0.90 OOMs on long prefill).
