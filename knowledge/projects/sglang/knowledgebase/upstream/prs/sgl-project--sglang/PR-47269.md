# [Perf] linear-attn: Build the verify valid-row mask only when PP stable rows are on

[Upstream PR](https://github.com/sgl-project/sglang/pull/47269) · state: open · merged: False

## Original PR description

KDA and GDN target verify compute `cache_indices[:bs] >= 0` on every linear layer and pass it to `select_verify_intermediate_state_indices`, which discards it unless PP stable rows are on (`SGLANG_ENABLE_PP_SPEC`). Pass the mask as a callable and evaluate it only when it is used. By default this saves one comparison kernel per linear layer per verify step. Tensor masks are still accepted.

The new CPU test checks that the callable is not called with stable rows off and is used with them on; it fails on main.
