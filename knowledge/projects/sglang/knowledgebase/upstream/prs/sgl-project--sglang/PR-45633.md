# [Perf] dsv41: Fuse the q_norm MXFP8 quantize for wq_b at every row count

[Upstream PR](https://github.com/sgl-project/sglang/pull/45633) · state: closed · merged: True

## Original PR description

## Motivation

The fused `rmsnorm_mxfp8` that feeds wq_b only ran up to 8 rows because its scale swizzle addressed a single 128-row tile; larger batches ran RMSNorm plus a separate `mxfp8_quantize`.

## Modifications

- `mxfp8_epilogue` addresses any number of 128-row scale tiles (unchanged below 128 rows).
- `rmsnorm_mxfp8` accepts any row count; FP8 values and swizzled scales are bit-identical to `mxfp8_quantize(..., is_sf_swizzled_layout=True)` from 1 to 1280 rows.
- Drop the 8-row cap at the q_norm call site.
