# [diffusion] comfyui: run Qwen-Image 2.1 in SGLD integrated mode

[Upstream PR](https://github.com/sgl-project/sglang/pull/43581) · state: closed · merged: True

## Original PR description

## Motivation

Run Comfy-Org's single-file Qwen-Image 2.1 DiT (`qwen_image_2.1_bf16.safetensors`, serialized INT8 ConvRot `qwen_image_2.1_int8_convrot.safetensors`) in ComfyUI SGLD integrated mode, for text-to-image and reference-image edit with the official templates (swap `UNETLoader` for `SGLDUNETLoader`).

The checkpoint-spec hooks (`quant_markers` / `checkpoint_key_filter` in `comfyui_checkpoints/spec.py`) are the same change as in #43583; whichever PR lands first, the other picks them up from `main`.

## Modifications

- **Checkpoint spec** (`comfyui_checkpoints/qwen_image21.py`): native parameter names. ComfyUI's row-fused `img_mlp.gate_up` (weight and per-row `weight_scale`) is split into `gate_layer` / `proj`, and its `comfy_quant` marker applies to both halves.
- **Worker** (`QwenImage21ComfyUIConditionStage` in `stages/model_specific_stages/qwen_image21.py`): per ComfyUI call, inserts a placeholder token at each `image_slots` position, builds the native layout and passes reference latents as `condition_latents`.
  - Reference rows get ComfyUI's half-token shift (`0.5 * (h % 2 - target_h % 2)` per axis). Native sizes are multiples of 32 px, but ComfyUI latent nodes allow odd target grids.
  - The prefix K/V is cached per cond for the sampler run when free memory allows, and dropped at the run's final sigma so it is freed before ComfyUI decodes. TP / SP ranks agree on the cache decision, so an uncached prefix cannot desync collectives.
- **Pipeline**: `QwenImage21Pipeline` declares its config and sampling params, since a single file has no `model_index.json`. It builds the ComfyUI stages. `enable_cfg_parallel` is rejected because ComfyUI runs CFG.
- **Plugin**: `QwenImage21Adapter` / `QwenImage21Executor` (`model_type=qwen_image21`, auto-detected). Reference latents and image slots are part of the cond-cache key.
- Unit tests, one minimal text-to-image workflow (`qwen_image21_t2i_sgld.json`) and README notes.

## Accuracy Tests

- Unit: `test_comfyui_*.py`, `test_conditioning_cache.py`: 268 passed. pre-commit clean.
- End-to-end on H200: 1024x1024, 20 steps euler, fixed seed. Final latents compared with stock ComfyUI (`UNETLoader`):

| Workflow | Result | vs stock ComfyUI |
|---|---|---|
| t2i, bf16 | completes | latent cos 0.997 (relative RMSE 7.5%) |
| t2i, INT8 ConvRot | completes | cos 0.998 (5.8%) |
| t2i, cfg 4 with a negative prompt (cond / uncond as separate rows) | completes | cos 0.996 (8.7%) |
| reference edit, 1040x1024 target (odd latent width) | completes | cos 0.99997 (0.74%); without the half-token shift 8.2% |
