# [Fix] [NPU] tests: Apply MMLU thresholds in the DeepEP accuracy tests

## Motivation

Fixes #36776.

Five NPU DeepEP accuracy tests set `accuracy_mmlu_threshold`. The shared `TestMMLU` mixin (`python/sglang/test/ascend/test_mmlu.py`) reads `getattr(self, "accuracy_mmlu", 0.00)` instead, and nothing reads `accuracy_mmlu_threshold`. So their MMLU check has been `score > 0.0`, and the step summary shows `N/A` as the threshold. This came in with #24689, which moved the tests onto `TestMMLU`. Before that, each test asserted `score > expect_score` with the same values (0.61, 0.56, 0.85).

#36801 made the same five renames, but it was a draft and the stale bot closed it without a review. This PR also removes the `0.00` default that hid the typo.

## Modifications

- In `test/registered/npu/basic_function/parallel_strategy/expert_parallelism/`, rename `accuracy_mmlu_threshold` to `accuracy_mmlu`. Values and comments are unchanged:
  - `test_npu_deepep_auto_qwen3_480b.py` (0.61)
  - `test_npu_deepep_auto_qwen3_next.py` (0.56)
  - `test_npu_deepep_low_latency_deepseek_v3_2_w8a8.py` (0.85)
  - `test_npu_deepep_low_latency_qwen3_480b.py` (0.61)
  - `test_npu_deepep_low_latency_qwen3_next.py` (0.56)

  The only other `TestMMLU` user, `test_npu_deepep_auto_deepseek_v3_2_w8a8.py`, already sets `accuracy_mmlu = 0.85`.
- In `python/sglang/test/ascend/test_mmlu.py`, read `self.accuracy_mmlu` directly in the assertion and in the summary's `accuracy_threshold`. They were `getattr(..., 0.00)` and `getattr(..., "N/A")`. The mixin now declares `accuracy_mmlu: float`. A subclass that omits or misspells the threshold fails with `AttributeError` before the eval runs. This follows `.claude/rules/no-getattr-defensive.md`.
- `GSM8KAscendMixin` uses the same `getattr(self, "accuracy", 0.00)` pattern. I left it alone because a scan of its 38 users found no misnamed threshold attribute.

**Validation (CPU).** I used a local script, in the collapsed block below and not part of this PR. It instantiates each of the six real test classes with `cls("test_mmlu")` and skips `setUpClass`, so no server starts. It mocks `run_sgl_eval` to return a fixed score and stubs the step-summary writer. Then it runs `test_mmlu` and prints the threshold passed to `assertGreater`. `OldNameOnly` is a throwaway subclass that sets only `accuracy_mmlu_threshold = 0.5`. Output, run from the repo root:

On main, a score of 0.99 also passes all six, with a threshold of 0.0 for the five misnamed ones.

I did not run this on NPU. These tests are in the `full-16-npu-a3` and `full-8-npu-a3` (Qwen3-Next) suites of the manually dispatched Full Test (NPU) workflow, and I don't have current scores for them. The only score I found is in the CI run linked from #36776, on an Ascend fork branch: `TestQwen3Next.test_mmlu` logged `mmlu_score=0.625`. That is 5/8, the lowest score that clears 0.56. The four tests with `mmlu_num_examples = 8` all need at least 5/8.

There's no new unit test. The change is in NPU test infrastructure, and a missing or misspelled threshold now makes `test_mmlu` itself error out.

```python
"""Run TestMMLU.test_mmlu of the six NPU DeepEP test classes on CPU, eval mocked.

Usage, from the repo root: python check_mmlu_gate.py <mocked MMLU score>
"""

import contextlib
import importlib
import io
import os
import sys
import unittest
from unittest import mock

os.environ["SGLANG_TEST_MAX_RETRY"] = "0"
sys.path.insert(
    0, "test/registered/npu/basic_function/parallel_strategy/expert_parallelism"
)

import sglang.test.ascend.test_mmlu as test_mmlu  # noqa: E402
from sglang.test.test_utils import CustomTestCase  # noqa: E402

CLASSES = [
    ("test_npu_deepep_auto_qwen3_480b", "TestDeepEpQwen"),
    ("test_npu_deepep_auto_qwen3_next", "TestQwen3Next"),
    ("test_npu_deepep_low_latency_deepseek_v3_2_w8a8", "TestDeepEpDeepseekV32"),
    ("test_npu_deepep_low_latency_qwen3_480b", "TestDeepEpQwen"),
    ("test_npu_deepep_low_latency_qwen3_next", "TestQwen3Next"),
    ("test_npu_deepep_auto_deepseek_v3_2_w8a8", "TestDeepEpDeepseekV32"),
]


class OldNameOnly(test_mmlu.TestMMLU, CustomTestCase):
    model = "dummy"
    other_args = []
    accuracy_mmlu_threshold = 0.5


class Result(unittest.TestResult):
    exc = None

    def addError(self, test, err):
        super().addError(test, err)
        self.exc = err[1]

    def addFailure(self, test, err):
        super().addFailure(test, err)
        self.exc = err[1]


def run(name, cls, score):
    case = cls("test_mmlu")
    case.base_url = "http://127.0.0.1:1"  # setUpClass (server launch) is not run
    applied = []

    def assert_greater(first, second, msg=None):
        applied.append(second)
        unittest.TestCase.assertGreater(case, first, second, msg)

    case.assertGreater = assert_greater
    result = Result()
    with (
        mock.patch.object(test_mmlu, "run_sgl_eval", return_value={"score": score}),
        mock.patch.object(test_mmlu, "write_results_to_github_step_summary"),
        contextlib.redirect_stdout(io.StringIO()),
        contextlib.redirect_stderr(io.StringIO()),
    ):
        case.run(result)
    exc = result.exc
    # CustomTestCase re-raises through retry(); report the first exception raised.
    while exc is not None and exc.__context__ is not None:
        exc = exc.__context__
    if exc is None:
        verdict = "PASS"
    else:
        kind = "FAIL" if isinstance(exc, AssertionError) else "ERROR"
        verdict = f"{kind} ({type(exc).__name__}: {exc})"
    threshold = applied[0] if applied else "-"
    print(f"score={score}  {name:<46}  threshold={threshold!s:<4}  {verdict}")


score = float(sys.argv[1])
for module, cls_name in CLASSES:
    run(module, getattr(importlib.import_module(module), cls_name), score)
run("OldNameOnly (sets accuracy_mmlu_threshold)", OldNameOnly, score)
```
