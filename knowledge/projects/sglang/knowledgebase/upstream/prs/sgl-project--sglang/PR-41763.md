# [Fix] sampling: Abort parallel sampling requests by caller RID

[Upstream PR](https://github.com/sgl-project/sglang/pull/41763) · state: open · merged: False

## Original PR description

## Motivation

Parallel sampling replaces the caller request ID with regenerated scheduler IDs. As a result, `/abort_request` cannot reach the sampled children, and an abort received during prefix caching does not stop child dispatch.

## Modifications

- Preserve the caller request ID as runtime-only bookkeeping for parallel sampling.
- Track regenerated scheduler IDs and fan targeted aborts out to active children.
- Stop parallel child dispatch when the prefix request is aborted or `abort_all` is requested.
- Add regression coverage for targeted aborts, `abort_all`, phase-one cancellation, and request-ID normalization.

Fixes #41755
