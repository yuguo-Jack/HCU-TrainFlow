# [AMD][CI] Disable HIP dma-buf in the Mooncake disaggregation test (OOM since the Mooncake bump)

[Upstream PR](https://github.com/sgl-project/sglang/pull/45644) · state: closed · merged: False

## Original PR description

## What
Set `MOONCAKE_DISABLE_HIP_DMABUF=1` for the disaggregation test in `pr-test-amd.yml`.

## Why
Since #44404 (Mooncake v0.3.14-rc1) registers GPU memory through HIP dma-buf, which the old pin never did. With the large KV cache of `test_disaggregation_basic` (Qwen3-8B, 82 buffers of about 2.7 GB), the prefill server fails right after registration with `hipErrorOutOfMemory`, although 63 GB of GPU memory is still free. The test passed on images before 20261018 and has failed in every run since. The variable makes Mooncake register memory the way it did before the bump.

## Validation
On one MI355X node, started the prefill server with the test's exact arguments:
- image 20261019: fails with `hipErrorOutOfMemory`
- same image with the variable set: starts
- image 20261013 (old Mooncake): starts

`test_disaggregation_pp` also fails in these runs, since before #44404; not addressed here. The cause of the dma-buf out-of-memory itself is not yet known.
