# [Feat] metrics: Add --enable-prefix-cache-hit-rate-window for a sliding-window prefix cache hit rate

[Upstream PR](https://github.com/sgl-project/sglang/pull/45719) · state: open · merged: False

## Original PR description

Report the token-weighted prefix cache hit rate over the most recent 1000
admitted requests in the scheduler log lines, using vLLM's CachingMetrics
semantics so the two can be compared on equal footing. Log-only: no new metric
is exported and sglang:cache_hit_rate keeps its per-report semantics.

- New flag --enable-prefix-cache-hit-rate-window, off by default. With the flag
  off nothing is sampled, no log field is printed, and the diff is inert.
- One sample per admission, recorded from _account_prefill_cache_admission:
  queries = full prompt length, hits = device-tier radix cache match. A chunked
  continuation or a dllm staging re-add never reaches it, so a prompt split
  across batches counts once instead of once per chunk.
- Retracted (preempted) requests are excluded and host/storage tier hits are
  excluded, because vLLM tracks both in separate counters rather than folding
  them into the window.
- The line is omitted while the window is empty -- before the first admission,
  right after a prefix cache flush, and on a PD decode node, which never admits
  -- so a printed 0.0% always means a real measurement.

Updated after review:

1. Sampling moved into `_account_prefill_cache_admission`, after the retracted early return, with hits taken from `device_hit`. Retracted (preempted) requests are now excluded, and host/storage tier hits are excluded -- both match vLLM, which tracks them in separate counters.

3. Renamed the flag to `--enable-prefix-cache-hit-rate-window`, and the help text now says it does not affect the existing `sglang:cache_hit_rate` gauge.
4. The log line is omitted while the window is empty -- before the first admission, right after a prefix cache flush, and on a PD decode node, which never admits.
5. Reverted the per-report `cache_hit_rate` move back inside the metrics block, and fixed the stale comment that claimed the gauge used the window.
