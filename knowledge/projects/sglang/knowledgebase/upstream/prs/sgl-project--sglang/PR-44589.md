# refactor(sglang-miles): rebase patches onto v0.5.22

[Upstream PR](https://github.com/sgl-project/sglang/pull/44589) · state: closed · merged: False

## Original PR description

## Summary

Rebase the existing Miles patch stack onto `release/v0.5.22`.

## Motivation

Miles needs the v0.5.22 upstream changes while retaining its RL serving and weight-update behavior. Replaying the old stack unchanged would duplicate upstream fixes and use obsolete process-group, loader and scheduler interfaces. The migration preserves the existing Miles feature scope.

The reviewed source is [`7b6993a310d0dbb67929b51582d1729a6295e417`](https://github.com/sgl-project/sglang/commit/7b6993a310d0dbb67929b51582d1729a6295e417); the release baseline is [`baa9befa381511cd4d56f83980951e5a45fffc6d`](https://github.com/sgl-project/sglang/commit/baa9befa381511cd4d56f83980951e5a45fffc6d). No `v0.5.22` tag exists. This PR uses the release baseline to expose the retained Miles diff for review; replacing canonical `sglang-miles` history remains a separate operation.

## Before / After

- **Before:** 48 source commits above their old merge-base, including upstream-covered changes and a mapper introduction/reversal pair.
- **After:** 35 kept, 8 partially retained and 5 dropped, producing 43 individually traceable commits on the release baseline. Native replay preserves original author/committer metadata.
- **What moved where:** Removed duplicate lease/mapper ownership; adapted retained callers to upstream-owned groups, layer-boundary stages and loader APIs.

## Modifications

- Preserve on-policy TP reduction, R3 graph layouts, streamed LoRA publication and target/draft replica loading against current upstream interfaces.
- Adapt Marlin padded reload views, MiMo QKV groups, MegaMoE hooks, fused LoRA member slots and prompt KV weight-version metadata.
- Drop only evidence-backed upstream coverage or canceled effects. Repair migrated test fixtures at their owning commits.

## Behavior Preservation

- Existing JSON/flat-top-logprob tests pass on the frozen replay, covering two fully dropped upstream-equivalent commits.
- Combined LoRA pool/stream/publication checks match the frozen source baseline; the final TP dispatch probe preserves group identity and non-policy dispatch.

## Verification

- Final static checks: 228 changed Python files parse, Ruff F821 passes and `git diff --check` passes.
- Replay accounting: all 48 source dispositions and 43 result mappings reconcile. Review covered all 231 changed paths.
- Final `test_batch_result_processor_hidden_states.py`: 10 tests and 2 subtests pass.
- Final release-order and TP-dispatch AST probes pass with isolated imports, stubbed computation/collectives.
- Earlier immutable replay checkpoints: Anthropic 96 tests + 59 subtests; combined LoRA 94 + 22; MiMo/MegaMoE 20; tail core 141 + 4. These are checkpoint results, not a final full-suite run.
- On-policy standard tests: 29 pass, 9 reproduce source-baseline failures.
- Other stale fixtures, macOS socket assumptions and missing platform dependencies remain.
- CPU environment: macOS ARM64, PyTorch 2.14.1 versus repository pin 2.14.0.
- Mint documentation validation was unavailable.
