# [Fix] logprob: preserve the maximum valid input token ID

[Upstream PR](https://github.com/sgl-project/sglang/pull/44331) · state: open · merged: False

## Original PR description

## Motivation

Input logprob assembly currently replaces token ID `vocab_size - 1` with `0`, even though valid IDs are in `[0, vocab_size)`. This can attach an input logprob to the wrong token in the response.

## Modifications

- Preserve all IDs below `vocab_size`; continue replacing multimodal placeholder IDs at or above that boundary with `0`.
- Extend the existing registered CPU test with the maximum valid ID and exact/above-vocabulary placeholders, covering nested/flat output and one-shot/chunked prefill. Also check that logprob values and original request IDs are preserved.
