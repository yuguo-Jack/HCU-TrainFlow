# [Fix] diffusion/disaggregation: Keep decoded images in tensor transport

[Upstream PR](https://github.com/sgl-project/sglang/pull/46104) · state: closed · merged: True

## Original PR description

## Motivation

#45987 lets the output rank encode image bytes even with `save_output=False`. The GLM-Image distributed denoiser only disabled file saving, so it now clears the decoded tensor before sending a tensor-only result to the head. Generation succeeds, but the API returns 500 with `Model generation returned no output`.

This surfaced in [the NPU job on #45919](https://github.com/sgl-project/sglang/actions/runs/39970902229/job/120473996801). It also reproduces on main without the progress-reporting changes.

## Modifications

- Keep decoded pixels as tensors on the GLM worker-to-head hop, matching the existing generic decoder path. The head still handles image encoding and persistence.
- Add regression coverage using real output materialization, ZMQ transport, and head-side encoding. Only model computation is stubbed. Cover one/two outputs, batched/sequential execution, and persistent/in-memory responses.

Production change: two added lines, including the ownership comment. No change to the ordinary image-bytes optimization, model computation, GT, or thresholds.

## Validation

- 8 regression cases fail on main with the missing output payload and pass with the fix.
- 162 related tests and 6 subtests pass; pre-commit passes.
- Real GLM-Image on 2 H200s: external SRT AR server, separate DiT/VAE worker, and HTTP head; 1024x1024, 30 denoising steps. Main reproduces the 500. With the fix, 12 requests return all 16 images across persistent and memory-only modes, including four concurrent requests mixing `n=1/2`.
- Invalid requests return 422; subsequent generation and health checks succeed. Workers create no image files. In persistent mode, all 8 saved images match the returned encoded bytes.

No kernel or model-forward changes, and no speedup claim. Ascend execution is left to CI; the real-model validation above is CUDA, not an NPU benchmark.
