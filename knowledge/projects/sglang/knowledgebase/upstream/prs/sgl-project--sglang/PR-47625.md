# [CI] diffusion: Fix image preprocessing test dependency environment

[Upstream PR](https://github.com/sgl-project/sglang/pull/47625) · state: closed · merged: True

## Original PR description

## Motivation

`test_image_preprocessing.py` imports `diffusers` at module load, but its `base-b-test-1-gpu-small` registration runs in the ordinary inference test environment without diffusion dependencies. This causes `ModuleNotFoundError: No module named 'diffusers'` before any assertions execute, as seen in [this CI job](https://github.com/sgl-project/sglang/actions/runs/41176324728/job/124469727017).

## Modifications

Register the existing test in `base-b-test-diffusion-unit-1-gpu-h100`. Its workflow installs dependencies with `ci_install_dependency.sh diffusion`, so the test gets its required packages while retaining GPU coverage. Test logic is unchanged.

## Validation

- All applicable pre-commit hooks passed, including registered-test validation, Python AST, isort, Ruff, formatting, and spelling.
- Verified with the repository CI collector that the test selects the diffusion unit suite, and checked that the workflow invokes that suite after installing diffusion dependencies.
- `git diff --check` passed.
- GPU test execution was not performed locally; runtime validation remains for CI.

No runtime code or inference performance changes.
