# [Docs] Update GLM-5.3-Flash playground: B300 default, CP8, EP and PD

[Upstream PR](https://github.com/sgl-project/sglang/pull/43802) · state: closed · merged: True

## Original PR description

## Summary

- Default the GLM-5.3-Flash cookbook to the B300 FP8 low-latency recipe. All 32 existing deployment recipes are preserved; only the initial recipe order changes.
- Add CP8 to the Attention selector on B200/B300. It emits `--attn-cp-size 8 --enable-prefill-cp --cp-strategy interleave` when TP8 is selected.
- With CP enabled, limit EP to 1 or the effective CP size and normalize incompatible inherited/stale EP picks to 1. CP+EP also emits `--moe-dense-tp-size` equal to CP size.
- Expose `flashinfer_trtllm` in the MoE selector so the existing Blackwell recipe defaults are selected correctly. Hopper retains DeepGemm and MI355X retains AITER.
- Add PD Disagg with Off/Prefill/Decode (default Off) and Mooncake as the sole transfer backend. Role selections emit the requested disaggregation flags and reuse the existing shared role-port handling.

### Scope and compatibility

The shared Playground change adds opt-in `moe.ep.matchCp` and `moe.ep.denseTpMatchesCp` policies, enabled only by this cookbook. Other cookbooks retain their existing EP behavior. The selector and command generator use the same EP normalization policy.

The runtime currently rejects GLM CP/TP group sharing together with PD (`resolve_cp_tp_group_sharing`). Selecting a PD role therefore disables CP and explains this limitation. The existing PD preview/accuracy caveat remains intact. No runtime code or benchmark results are changed.
