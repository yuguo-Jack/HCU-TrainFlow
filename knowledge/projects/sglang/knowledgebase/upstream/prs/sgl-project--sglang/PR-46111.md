# [Perf] diffusion: Vectorize the LTX-2 Q/K RMSNorm + split-RoPE kernel

[Upstream PR](https://github.com/sgl-project/sglang/pull/46111) · state: closed · merged: True

## Original PR description

Branch: mick/ltx2-qknorm-rope-vectorize (on main 02b983603d), commit 5dbb8589c1

## Motivation

`ltx2_qknorm_split_rope` (sm_100 path) runs 8 times per LTX-2 block. Its output pass reads x, the norm weight, cos and sin, and writes the output one bf16 element at a time. It is the largest non-GEMM kernel in the LTX-2 profile: 4.3 ms per stage-1 step for LTX-2, and 6.7 ms per forward for LTX-2.3 at batch 2.

## Modifications

`kda_kernels/csrc/diffusion/ltx2_qknorm_split_rope.cuh`: the output pass handles 8 consecutive RoPE pairs per thread with 16-byte loads and stores. It does so when the half head dim, the cos/sin strides and every base pointer allow; otherwise the scalar loop runs. The rstd reduction, the per-element math and the rounding are unchanged.

## Tests

`test_rope_ltx2.py::test_ltx2_qknorm_split_rope_vectorized_matches_scalar`: the same inputs with cos/sin moved off a 16-byte boundary run the scalar loop, and both paths agree bitwise (d128 and d64, batch 1 and 2, odd sequence lengths). The existing exactness and alignment tests pass.

## Accuracy Tests

The new kernel is bitwise equal to the old one on 6 production shapes (B300). LTX-2 and LTX-2.3 MP4s of 4 requests each are byte-identical (measured together with the LTX-2.3 elementwise PR).

## Speed Tests and Profiling

B300, one q/k pair:

| shape (tokens q/k x heads x dim) | before | after |
|---|---|---|
| 1536/1536 x 32 x 128 | 30.9 us | 16.6 us |
| 2x1536/1536 x 32 x 128 | 68.8 us | 36.5 us |
| 1536/126 x 32 x 64 | 14.0 us | 8.7 us |
| 2x126/126 x 32 x 64 | 10.1 us | 6.3 us |
| 6144/6144 x 16 x 128 | 69.8 us | 37.4 us |

LTX-2 stage-1 steps go from 48.3 ms to 47.2 ms (synced stage timing).
