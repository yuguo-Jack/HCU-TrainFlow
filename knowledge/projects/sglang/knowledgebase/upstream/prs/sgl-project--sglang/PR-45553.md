# [CI] [NPU] precise-test: collect multimodal_gen coverage per test case

[Upstream PR](https://github.com/sgl-project/sglang/pull/45553) · state: closed · merged: True

## Original PR description

## Motivation

The NPU precision-test pipeline (`coverage-collection-npu.yml` → `pr-test-npu.yml` with `coverage_mode=true`) selects PR tests from a coverage baseline, but it skipped the multimodal-generation jobs entirely. The selector therefore had no coverage data for the diffusion suites, and every PR ran all of them.

This is **PR 1/3** of the multimodal precision-test work: it only adds coverage collection. PR behavior is unchanged (the jobs still run in full on PRs); the recommendation gating and runtime filtering follow in PRs 2 and 3.

## What changed

- **`scripts/ci/npu/precise-test/list_multimodal_tests.py` (new, NPU-only)**: lists one shard's pytest targets (case-level node ids plus standalone files) by reusing the shared diffusion runner read-only (`build_local_partition_assignment`, `PARAMETRIZED_CASE_GROUPS`) and `pytest_runner.collect_test_items`. It emits absolute paths so `run_tests_with_coverage.sh` can encode the workspace layout and `test_selector.py` can recover the repo-relative test path.
- **`pr-test-npu.yml`**: the two `multimodal-gen-*` jobs now also run when `coverage_mode=true`; in that mode they enumerate the shard and execute each target in its own `coverage run -m pytest` invocation, giving per-case attribution. The normal PR path is untouched. `setup-covstub` now depends on both jobs and merges their coverage into the published baseline and the HTML report.
- **`precise_test_coverage_plugin.py`**: patch the diffusion runtime's SIGKILL-only `kill_process_tree` lazily (only when the module is already loaded) so server subprocess coverage is flushed on SIGTERM instead of being lost.
- **`test/server/ascend/test_glm_image_distributed.py`**: SIGTERM-first stop when `COVERAGE_PROCESS_START` is set (NPU-only directory; normal runs unchanged).
- **`coverage-collection-npu.yml`**: comment update.

`python/sglang/multimodal_gen/test/runner/**` is platform-shared and is **not modified**.

## Validation

- `ruff check --select=F401,F821,F823,UP037` and `ruff format --check`: pass
- `py_compile` and workflow YAML parse: pass
- Verified with pytest 8.3 that `-k "[case_id]"` selects a single parametrized case, and that `--collect-only` reports node ids relative to its rootdir (hence the absolute-path rebuild)
- Verified the coverage-directory encode → `normalize_test_name()` round-trip for both a case-level node id and the standalone file

## Follow-ups

- The coverage baseline must be rebuilt with this change before recommendations are enabled: PR 2 adds the bucket + safety interlock, PR 3 enables the `-k` filtering.
- Watch `test_case_map.json` size after the first coverage run; gzip it if it grows too much.
