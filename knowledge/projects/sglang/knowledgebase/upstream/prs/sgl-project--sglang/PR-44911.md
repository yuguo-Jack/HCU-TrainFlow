# [Perf] topk: Restore faster overflow-safe selector

[Upstream PR](https://github.com/sgl-project/sglang/pull/44911) · state: open · merged: False

## Original PR description

## Summary

Restore the overflow-safe radix selector from #37893 for the AOT `fast_topk_v2` path. The current `legacy_radix_topk` replacement is correct, but this implementation was faster in every locally measured CUDA scenario while preserving the shared-memory-only fast path.

This change is intentionally scoped to the AOT selector. Page-table and ragged transforms continue to call the same selection core and their wrappers are unchanged.

## Validation

Hardware: RTX 4090 (SM89), CUDA 11.8, PyTorch 2.1.2+cu118. Built both candidates from source as isolated PyTorch CUDA extensions with `-O3` and `sm_89`; timings are CUDA-event median over 9 rounds after warmup. Every row was checked against `torch.topk` by exact selected-value multiset.

| Scenario | Candidate | main before change | Throughput gain |
| --- | ---: | ---: | ---: |
| B1 x 2049 random | 5.19 us | 5.57 us | 1.07x |
| B1 x 4096 random | 6.45 us | 6.88 us | 1.07x |
| B32 x 8192 random | 8.29 us | 8.79 us | 1.06x |
| B64 x 65536 random | 28.00 us | 29.01 us | 1.04x |
| B64 x 262144 random / overflow | 88.48 us | 255.47 us | 2.89x |
| B16 x 16384 repeated overflow | 20.90 us | 23.07 us | 1.10x |
| B16 x 65536 overflow with row_start=257 | 69.74 us | 91.21 us | 1.31x |
| B16 x 16384 exact ties | 5.06 us | 5.33 us | 1.05x |
| B64 x 65536 concentrated realistic range | 60.32 us | 91.51 us | 1.52x |

Rebuilding this branch and rerunning the same matrix yielded timings within measurement noise of the #37893 implementation, with all exact checks passing.
