# [sglang-miles] Add sparse per-position requested-token scoring

[Upstream PR](https://github.com/sgl-project/sglang/pull/38119) · state: open · merged: False

## Original PR description

## Motivation

A scoring request needs a different candidate-token set at each input position for OPD and multi-teacher distillation. Sending the sequence-wide union through `token_ids_logprob` returns many unused scores. This adds `token_ids_logprob_positions`, returning only each position's requested scores with full-vocabulary normalization.

Replaces #27421, ported onto current `sglang-miles` (`a3591427c204`). The old PR's obsolete integration ancestry is removed. Companion Miles PR: https://github.com/radixark/miles/pull/3116. Follow-up #38098 contains the mixed scoring/generation compatibility fix and should land immediately afterward.

## Changes

- Validate the new field in `GenerateReqInput` / `TokenizerManager._validate_token_ids_logprob`; preserve the flat requested-ID interface.
- Carry absolute positions through `PerPositionTokenIds` and `ScheduleBatch.prepare_for_extend`, including the next-token offset.
- Gather sparse rows in `get_token_ids_logprobs_raw` and `get_token_ids_logprobs_chunk`, using one bulk host transfer per request chunk and the existing response field `meta_info.input_token_ids_logprobs`.
- Cover numerical equivalence, chunk stitching, cross-prefill position alignment, and request validation in CPU CI.

Scope: **7 files, +348/-2**, comprising 134 added production lines and 214 test lines.

## Supported interface

One `input_ids` sequence per HTTP request, `return_logprob=true`, `max_new_tokens=0`, nonnegative `logprob_start_len`, and no streaming. Candidate rows must match input length; empty rows are allowed. Batched HTTP inputs, parallel sampling, multi-item scoring, and simultaneous flat/per-position IDs are rejected. Rust/gRPC transport is not implemented.

## Validation

- Parent alone: **76 passed, 7 GPU-only tests skipped, 6 subtests passed** across sparse scoring, request validation, fast input logprobs, chunk stitching, and io_struct suites.
- All applicable pre-commit hooks passed.
- The full-model GPU experiment was not rerun for this port. Earlier Qwen3.6-35B-A3B dense/sparse and mixed-traffic results apply to the combined stack and are documented in #38098.
