## Motivation

Add DSpine speculative decoding support to SGLang through the existing DFlash runtime.

- Support DSpine checkpoint loading, feature bridges, and candidate transition scoring.
- Add fused Triton bridge kernels and reuse existing draft sampling and verification.
- Add configuration validation, documentation, and CPU/GPU tests.

Reference implementation:
[tencent/dspine](https://github.com/tencent/dspine) (Apache-2.0);
paper: [arXiv 2609.36173](https://arxiv.org/abs/2609.36173); checkpoint:
[tencent/Qwen3-8B-DSpine-b16](https://huggingface.co/tencent/Qwen3-8B-DSpine-b16).
