# refactor(trtllm): remove redundant parent attribute assignments in TRTLLMHAAttnBackend

[Upstream PR](https://github.com/sgl-project/sglang/pull/44102) · state: closed · merged: False

## Original PR description

## Summary

Fixes part of #28808. `TRTLLMHAAttnBackend` inherits from `FlashInferAttnBackend`
but reuses very little from the parent. This PR removes two redundant attribute
assignments that the parent already sets to identical values.

## Changes

Removed these lines from `TRTLLMHAAttnBackend.__init__()`:
```python
self.max_context_len = model_runner.model_config.context_len
self.page_size = model_runner.page_size
```

Both are already set by `FlashInferAttnBackend.__init__()` with the same source
expressions after `super().__init__()` returns. This was purely redundant.

## Validation

- [x] Syntax check passes
- [ ] Full test suite (CI will handle)

## Next steps

This is a small, safe cleanup. The broader refactor suggested in #28808
(making TRTLLM inherit directly from `AttentionBackend` instead of
`FlashInferAttnBackend`) is a larger change that would require skipping
FlashInfer wrapper and indices-updater allocations that TRTLLM never uses.
