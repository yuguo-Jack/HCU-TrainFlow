# [Fix] HiCache: report storage clear failure accurately

[Upstream PR](https://github.com/sgl-project/sglang/pull/44700) · state: closed · merged: False

## Original PR description

## Motivation

`POST /hicache/storage-backend/clear` returns HTTP 400 when the scheduler reports failure, but its response body still says the storage backend was cleared. For example, this happens when neither hierarchical cache nor LMCache is enabled.

## Modifications

Return `Failed to clear hierarchical cache storage backend.\n` when `ret.success` is false. Preserve the successful response and existing HTTP status codes.

## Accuracy Tests

Executed the actual handler body in isolation with scheduler success and failure responses; verified both status codes and exact response text. The scheduler and Response constructor were stubbed to avoid loading the GPU serving stack. `git diff --check` passed. No GPU end-to-end test was run; inference behavior is unchanged.
