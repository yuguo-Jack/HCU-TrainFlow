# [Perf] [AMD] kimi-k3: Add the FP8 MoE pre-route adapter

[Upstream PR](https://github.com/sgl-project/sglang/pull/44821) · state: open · merged: False

## Original PR description

> Based on the latent-tail kernel slice. Review `71bd1cc730` (1006 lines, including the numerical test and benchmark). Compare: https://github.com/yuychang/sglang/compare/up/b5d-latent-tail-kernel...up/b5e-preroute-adapter


## AITER prerequisites

None. This kernel is compiled from the SGLang tree. It only imports AITER FlyDSL helpers that are already on AITER main. [ROCm/aiter#6026](https://github.com/ROCm/aiter/pull/6026) is not used: the measured recipe compiles the vendored kernel (`SGLANG_OPT_HIP_K3_FLYDSL_SOURCE=sglang`).

## Modifications

- Add the pre-route wrapper, the AITER adapter, its registry entries, and the numerical test.
- Gate it with `SGLANG_OPT_HIP_K3_MOE_PREROUTE_FP8` and `SGLANG_OPT_HIP_K3_PREROUTE_PREACTIVATED_SHARED`, both off by default.
