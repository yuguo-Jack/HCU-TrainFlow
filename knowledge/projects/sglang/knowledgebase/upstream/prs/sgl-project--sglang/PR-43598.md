# [CI] Fix Kimi-Linear DCP PD test startup

[Upstream PR](https://github.com/sgl-project/sglang/pull/43598) · state: closed · merged: True

## Original PR description

## Summary

The DCP arm of `test_disaggregation_kimi_linear.py` fails at startup on main:

```
ValueError: Chunked prefill is aligned to 4096 tokens, but each rank's chunked prefill size is 64; ...
```

#43444 added `check_truncation_align_fits_chunk`. Deterministic flashinfer aligns prefill chunks to `SGLANG_FLASHINFER_PREFILL_SPLIT_TILE_SIZE`, which must be `<=` the chunk size:

| | Split tile | `--chunked-prefill-size` | Result |
|---|---|---|---|
| Before | `4096` (default) | `64` | every chunk truncates to 0, so startup is rejected |
| After | `64` | `64` | chunks keep all 64 tokens |

The fix sets the tile through `DCP_ENV` on the prefill and decode servers. The reference server reads the same env, so parity is unchanged. The TP arm doesn't use flashinfer and is untouched.

Verified on 4x H100, full file:

```

OK
```
