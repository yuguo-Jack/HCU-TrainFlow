# [Fix] [AMD] mimo-v2.6: Refresh AITER decode graph metadata

## Motivation

AITER unified attention is correct in eager mode for MiMo-V2.6 after adding asymmetric Q/K=192 and V=128 support, but decode graph replay has two metadata problems:

1. For page size 1 without the hybrid SWA pool, SGLang computes the live page table but does not copy it into the persistent CUDA-graph page-table buffer. Graph replay therefore reads stale entries.
2. Graph-capture buffers can contain padded sequence-length rows beyond the active batch. Building `kv_indptr` from the full buffer instead of `seq_lens[:bs]` can include inactive rows or fail when replaying a smaller batch.

This PR is intentionally separate from [#41573](https://github.com/sgl-project/sglang/pull/41573). It does not touch MiMo processing, MXFP4 loading, or gate-mode propagation.

## Modifications

- Build AITER decode `kv_indptr` from active sequence-length rows only.
- Refresh the persistent unified-attention page table for page-size-1 graph replay.
- Preserve the existing page-size-greater-than-1 transformation and hybrid-SWA paths.
- Add CPU regressions for padded graph rows and page-size-1 page-table refresh.

## Accuracy Tests

Validated on 8× MI355X with `XiaomiMiMo/MiMo-V2.6-Pro-RL`, TP8/EP8, AITER attention/MoE, full KV memory, and decode graphs through batch size 256.

Before this fix, eager requests were coherent but graph replay used stale page-table metadata. After this fix, decode reports `cuda graph: True` and returns:

- `What is 15% of 240? Give only the number.` → `36`
- Average-speed reasoning problem → `80 km/h` with the correct derivation
- GSM8K, 5-shot, 10 samples: strict and flexible exact match `1.0`

### Reproduction

This requires the asymmetric unified-attention support from [ROCm/aiter#6051](https://github.com/ROCm/aiter/pull/6051).

```bash
SGLANG_USE_AITER=1 \
SGLANG_USE_AITER_UNIFIED_ATTN=1 \
AITER_BF16_FP8_MOE_BOUND=0 \
python3 -m sglang.launch_server \
  --model-path XiaomiMiMo/MiMo-V2.6-Pro-RL \
  --served-model-name XiaomiMiMo/MiMo-V2.6-Pro-RL \
  --tp 8 \
  --ep 8 \
  --moe-runner-backend aiter \
  --moe-dense-tp-size 1 \
  --attention-backend aiter \
  --mm-attention-backend triton_attn \
  --disable-hybrid-swa-memory \
  --chunked-prefill-size 32768 \
  --max-prefill-tokens 65536 \
  --max-running-requests 256 \
  --page-size 1 \
  --cuda-graph-max-bs-decode 256 \
  --cuda-graph-backend-prefill disabled \
  --reasoning-parser mimo \
  --tool-call-parser mimo \
  --trust-remote-code \
  --host 0.0.0.0 \
  --port 30000
```

Then:

```bash
curl http://localhost:30000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "XiaomiMiMo/MiMo-V2.6-Pro-RL",
    "messages": [{"role": "user", "content": "What is 15% of 240? Give only the number."}],
    "chat_template_kwargs": {"enable_thinking": false},
    "temperature": 0,
    "max_tokens": 64
  }'
```
