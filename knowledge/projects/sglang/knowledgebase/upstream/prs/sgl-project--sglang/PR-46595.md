# [Fix] openai: match tokenize reasoning effort to chat

[Upstream PR](https://github.com/sgl-project/sglang/pull/46595) · state: open · merged: False

## Original PR description

## Motivation

`/tokenize` and chat don't encode the same request when `reasoning_effort` is in `chat_template_kwargs`. Chat moves it onto the request before rendering; tokenize skips that step. On DeepSeek-V4.1, `thinking=true` with `reasoning_effort=low` renders budget 50 through chat and 75 through tokenize.

## Modifications

Move the existing effort handling into `_prepare_reasoning_effort` and call it from both paths. Hunyuan still uses its own handling.

## Testing

- The new regression compares the full input token IDs for `low`, `max`, a numeric budget, and kwargs overriding the top-level effort. All four cases fail on main and pass with this change.
- DeepSeek serving and renderer, protocol, and chat unit tests: 220 passed, plus 220 subtests.
