# [Feat] lora: Shipped CuTeDSL FP8 base-GEMM tile tables (20/21)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42887) · state: closed · merged: False

## Original PR description

Part 20 of 21 of the LoRA runtime stack (branch `lora-stack-19-fp8-tables`, base `lora-stack-18-cutedsl-fp8`). The stack is cut from the development branch of #42284.

## What this part adds

Add the tuned CuTeDSL FP8 tile tables for B200, GB300 and H200 (masked and
contiguous row domains). A geometry without a table keeps the heuristic
tiles.

Tests: every shipped table loads under another package version.

## Verification

- GB300 run r45: the tree of upstream main `c1c287a429` plus parts 01–20 imports every module this part changes and passes this part's tests together with every earlier part's unit tests: **393 passed, 20 warnings, 154 subtests passed in 30.06s** (excluding the tests that fail identically on the untouched base tree in that environment).
- `pre-commit` passed on the changed files of every part; `pre-commit run --all-files` passed on the complete stack tree.

The complete 21-part tree equals the development branch of #42284 at `e7b7179a86` (the `6588053ef2` tree with four test-only follow-ups squashed into its dense commit: the admission/snapshot trim, the restored FP8 block-shape admission pin, a second trim that keeps only the tests guarding silent failures and adds pins for four coverage gaps, and restored numerical and packing coverage; production code is unchanged) minus the benchmark tools and the Triton MoE tuning tables, which follow in separate PRs.
