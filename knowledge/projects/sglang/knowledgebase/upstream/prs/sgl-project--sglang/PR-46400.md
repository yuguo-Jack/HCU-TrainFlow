# [Doc] cookbook: Label non-GPU benchmark throughput per chip

[Upstream PR](https://github.com/sgl-project/sglang/pull/46400) · state: open · merged: False

## Original PR description

## Motivation

Cookbook benchmark cards for non-GPU hardware call the accelerator a GPU. For example, [GLM-5.3-Flash on TPU7x](https://lmsysorg.mintlify.app/cookbook/autoregressive/GLM/GLM-5.3-Flash#hw=tpu7x&strategy=low-latency&quant=fp8&pdMode=unified&kvDsaPair=fp8-pallas&bcg=off&mmTransport=auto&hicache=off&parsers=auto) shows "throughput per gpu". The label is hardcoded in the shared engine, so every TPU, Ascend NPU, CPU, and Apple Silicon card has the same problem.

## Modifications

`docs/src/snippets/_deployment.jsx`:

- Move `vendorOf` from inside the docker-command builder up to component scope, next to `HARDWARE_CATALOG`, so the benchmark card can use it. The function body is unchanged.
- Add `deviceUnitOf(hwId)`. It returns `"chip"` for the `tpu`, `npu`, `cpu`, and `apple` vendors and `"gpu"` for everything else.
- Build the Speed table's throughput row label and its legend from that unit. GPU hardware still shows `throughput per gpu ... /elapsed/GPU`. TPU and other non-GPU hardware now show `throughput per chip ... /elapsed/chip`.

The `tokens_per_sec_per_gpu` data key is unchanged, so no benchmark files need edits.
