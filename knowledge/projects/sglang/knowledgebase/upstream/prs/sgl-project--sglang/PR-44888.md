# [Fix] diffusion: pipeline and model-helper bug fixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/44888) · state: open · merged: False

## Original PR description

Part of #43875 (items 25-33). Split out of #43585 so it can be reviewed on its own. It does not depend on the other two PRs (#43585, #44887).

**Note: behavior change in item 25. LingBot-World camera poses and intrinsics are now built in float32, and the Plucker rays are computed in float32 before the final cast. Plucker values will differ slightly from before. The effect on generated video was not checked, so a maintainer with a GPU may want to compare LingBot-World output.**

CPU check (16 frames at 832x480, synthetic forward-walk with yaw sweep, float64 as ground truth): the old bf16 path differs from truth in 74% of the conditioning values (mean error 0.0045, max 0.032); the new path matches the float64 result exactly after the final bf16 cast.

## Summary
Fixes in pipelines and the model helpers they use, one commit per item. Item numbers match #43875.

25. Plucker rays were built in bf16 when poses were bf16, so pixel columns above 256 shared a ray. They are computed in float32 now (LingBot-World poses too).
26. The blank default texture and the bake buffers used `(width, height)` where `(height, width)` is needed, which breaks non-square textures.
27. `ImageProcessorV2.load_image` raised `UnboundLocalError` for an ndarray or tensor. ndarrays work and other types raise a `TypeError`.
28. `DiffusersPipeline` output layout: NumPy videos were permuted twice, PIL lists were read as a batch, and several images from an image pipeline were stacked as video frames.
29. `DiffusersPipeline.add_stage` took its arguments in the reverse order of the base class.
30. SANA-Video always encoded the negative prompt at 300 tokens. It uses `max_sequence_length` now.
31. ErnieImage treated a `[null, null]` `pe` entry as a real prompt-enhancement model. It is treated as absent.
32. HunyuanImage3 ignored `--revision` when downloading weights.
33. Hunyuan3D picked an arbitrary checkpoint when several matched the fallback glob. It picks the first by name now.

## Tests
- New `test_pipeline_regressions.py` (CPU): 11 pass.
- With the source changes reverted, 9 fail. The 2 that still pass are the ErnieImage cases for a real `pe` entry and a missing one, which guard that the fix does not over-reject.
- No tests for 29, 32 and 33 (signature order, a passed-through kwarg, and a sort).
- No GPU run, see the note on item 25.
