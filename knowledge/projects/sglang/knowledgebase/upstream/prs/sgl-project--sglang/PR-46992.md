# [Fix] piecewise: make layer-boundary runtime paths dynamo-traceable

[Upstream PR](https://github.com/sgl-project/sglang/pull/46992) · state: open · merged: False

## Original PR description

## Motivation

`tc_piecewise` compiles the language-model forward with `torch.compile(fullgraph=True)`. Any graph break in this region aborts prefill CUDA graph capture.

The layer-boundary runtime path currently contains three Dynamo-incompatible operations:

1. Runtime carriers are constructed as `msgspec.Struct` instances inside the compiled region. Dynamo cannot trace their C-level `__new__`, and its `object.__new__(cls)` safety check rejects the construction.
2. Deprecated module-level group getters inspect `sys._getframe(1)` through a deprecation wrapper, which Dynamo cannot trace.
3. `is_musa()` imports `torchada` lazily. Calling it from a fullgraph-compiled region exposes an import operation to Dynamo and causes another graph break.

These issues were observed during MiniMax-M3 TP16 prefill CUDA graph capture, where boundary carriers are constructed and completed inside the compiled region.

## Modifications

- Convert runtime boundary carriers from `msgspec.Struct` to dataclasses so Dynamo can trace their construction:
  - Use frozen dataclasses for immutable carriers.
  - Keep `Contribution` mutable because `complete()` updates its state.
  - Keep plan-time-only containers on `msgspec.Struct`.
- Document why carriers constructed inside the compiled region must retain a standard Python `__new__`.
- Bypass the deprecation wrapper's `sys._getframe` caller inspection when `torch.compiler.is_compiling()` is true. Eager callers retain the existing one-time `DeprecationWarning`.
- Resolve MUSA availability at module load time so `is_musa()` no longer performs an import inside a compiled region.
- Add focused Dynamo regression tests covering:
  - Construction and completion of layer-boundary carriers under `torch.compile(fullgraph=True)`.
  - The dataclass construction contract required by Dynamo.
  - Deprecation-wrapper behavior in compiled and eager execution.
