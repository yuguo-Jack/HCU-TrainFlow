# [Refactor] [NPU] communicator: remove redundant npu communicator

[Upstream PR](https://github.com/sgl-project/sglang/pull/45950) · state: closed · merged: True

## Original PR description

## Motivation

1. The all_gather and all_reduce defined in the current NPU Communicator do not actually use a custom communication implementation; they directly call the torch interface. This is consistent with the fallback implementation in parallel state, meaning that the code here is actually redundant.
2. quant_all_reduce in NPU Communicator is actually called only on NPU; here we simplify the invocation approach.
3. Optimization of the is_Npu branches in all_gather, all_reduce, and reduce_scatter.

## Modifications

1. Remove the redundant NPU Communicator.
2. Optimize the is_npu branches in all_gather, all_reduce, and reduce_scatter.
3. Make quant_all_reduce default directly to the NPU implementation, since it is currently called only in NPU scenarios.
