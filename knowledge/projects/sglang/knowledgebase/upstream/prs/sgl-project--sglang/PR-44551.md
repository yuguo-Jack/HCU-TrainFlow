## Motivation

At Kimi-K3 decode sizes the TP8 collectives and the attention-residual (AttnRes) reads that consume their output
are separate small launches per layer: the attention output's all-reduce, the residual add and the FFN-side bank
read; the MoE all-reduce, the replicated latent tail (norm + 3584 -> 7168 up-projection + shared + residual add) and
the next layer's attention-side read. Each rank also computes the whole replicated tail GEMM.

## Modifications

Gated on gfx950 TP8 (`layers/communication/k3_ll_comm_hip.get_comm()`).

- `comm/ll_hip.cuh`: a low-latency push protocol over a dedicated aiter CustomAllreduce's IPC meta buffer: senders
  write 16-byte lines of 8 payload bytes + an epoch flag into the receiver's scratch, receivers poll their own;
  no barrier (a line is rewritten two epochs later).
- `attn_res/read_hip.cuh` + `k3_attn_res_read_hip.py`, fused with the AttnRes read (softmax over the bank rows and
  the stream, RMSNorm):
  - the attention output's one-shot all-reduce + residual add + FFN-side read, for 4-row batches (EAGLE C1 verify;
    `SGLANG_ROCM_K3_FUSED_ATTN_AR_READ`), and an opt-in two-shot variant for 5-64 rows
    (`SGLANG_ROCM_K3_FUSED_ATTN_AR_READ_MAX_ROWS`, off by default: slower than aiter's all-reduce + the Triton read);
  - the column-parallel latent tail: each rank runs the tail GEMM on 1/8 of the replicated up_proj rows as split-K
    fp32 partials (`k3_latent_tail_partials`), and the all-gather kernel finishes its slice (/rms, + shared
    [+ residual]), gathers the stream and runs the next layer's attention read on it (optionally writing the bank
    row), staged in `AttnResidual` for that read (`SGLANG_ROCM_K3_COLUMN_TAIL`, <= 64 tokens).
- Batches the column tail does not take run norm + up-projection + shared + residual add as one kernel
  (`k3_latent_tail`, <= 32 tokens, `SGLANG_ROCM_K3_FUSED_LATENT_TAIL`).
- Prefill-sized AttnRes reads (>= 64 rows, bank tile of 8 rows) stream the bank two rows at a time with an online
  softmax (`attn_res_hip._agg_stream_kernel`) instead of holding it in registers.

The sums run in rank order, so every rank gets the same bits.

| New env var | Default |
|---|---|
| `SGLANG_ROCM_K3_FUSED_ATTN_AR_READ` | on |
| `SGLANG_ROCM_K3_FUSED_ATTN_AR_READ_MAX_ROWS` | 4 (two-shot off) |
| `SGLANG_ROCM_K3_FUSED_LATENT_TAIL` | on |
| `SGLANG_ROCM_K3_COLUMN_TAIL` | on |

## Accuracy Tests

**Setup for every number below:** 8x MI350X (gfx950, 1000 W), Kimi-K3 (MXFP4 MoE, bf16 attention) at TP8 with EAGLE3
(topk 1, 3 steps, 4 draft tokens), FP8 KV cache, `SGLANG_USE_AITER=1`, aiter's K3 FlyDSL kernels
(`AITER_SITUV2_A8W4=1 AITER_FLYDSL_FORCE=1 SGLANG_AITER_K3_OPT=1`), CUDA graphs for bs 1/2/4/8/16, and an aiter bf16 GEMM table with K3 rows re-tuned on this pod with HBM-resident weights
(`AITER_CONFIG_GEMM_BF16`; not part of this PR, it belongs in aiter's model configs). EAGLE3 on K3 needs the
aux-capture commit of #43599, applied locally for these runs. Microbenchmarks rotate their weights through HBM.
Per-feature numbers were measured on the integration branch of this series as each piece landed (Oct 13-14,
earlier `main`); the end-to-end numbers are from the integration of all seven PRs rebased on `main` b67785153a,
together with #43599's aux capture, #41867 and #41848.

- GSM8K 400: column tail 0.99 / accept 3.62; fused attention read 0.985 / 3.613 (200, every verify on the fused
  path); AttnRes streaming 0.985 / 3.62. End-to-end integration: see below.
- `test_k3_ll_collectives.py` (new, 8 GPUs): the all-reduce read (one-shot 4 rows, two-shot 8 and 64 rows, with and
  without the residual) gives the rank-order bf16 sum exactly and the read within rounding, the same on every rank;
  the gather read (1 / 4 / 64 rows, with and without the prefix and the bank write) against torch.distributed.
- `test_kimi_k3_latent_tail_hip.py` (new): the fused tail against norm + GEMM + add; the partials finish to the same
  projection. `test_attn_res_hip.py` (new): the streaming read against the register-tile kernel.

## Speed Tests and Profiling

- Column tail + fused next read: C1 decode cycle 17.95 -> 17.25 ms; tail partials ~4 us vs 11.5-13 us replicated.
- Fused attention all-reduce read at 4 rows: C1 cycle 16.02-16.25 -> 15.82-15.92 ms (C4 slower at 16 rows, hence 4).
- Fused latent tail: 13.5 vs 19.5 us (norm + up + add3); -21..-36% over 2-32 rows.
- AttnRes streaming, 8 bank rows: 8192 rows 434 -> 320 us, 2048 rows 114 -> 74 us; uncached 50K prefill
  3.347 -> 3.304 s.
