## Original PR description


## Motivation

On Ascend NPU, the existing HiCache L2 (host DRAM) IO path uses `transfer_kv_dim_exchange` with default host memory allocation. This works functionally but has two issues:

1. **Host memory not AIV-de-referencable**: The default `torch.pin_memory` host buffers are only reachable by the SDMA engine; the fused AIV sparse-copy kernel (`offload.kv_exchange_copy`) from the Memfabric `acc_offload` library can only de-reference host VAs that were mapped into the device VA space via the Memfabric offload entity.
2. **Stream synchronization on H2D upload**: A pageable `.to(device)` on NPU completes with `aclrtStreamSynchronize` that drains everything queued on the current stream, serializing the layer-group pipeline and stalling compute.

This PR adds the Memfabric-mapped host DRAM allocation and the AscendC sparse-copy IO path, gated behind a single environment variable `SGLANG_HICACHE_HOST_MEM_BACKEND=memfabric`.

**Depends on #L3PR** (Ascend MemCache L3 storage backend).

## Modifications

- **`pool_host/common.py`** (+154): Add Memfabric host memory allocator (`alloc_with_memfabric`), lazy initialization (`ensure_memfabric_capacity`), single-switch detection (`memfabric_host_memory_enabled`, `ascendc_io_enabled`), and sync-free H2D upload helpers (`to_device_no_sync`, `track_pinned_staging`) using pinned memory + `torch.npu.Event`.
- **`pool_host/mla.py`** (+266): In `MLATokenToKVPoolHost`, add Memfabric host pool allocation path (sizes the GB-aligned reserve from `--hicache-size`/`--hicache-ratio`), add `_transfer_ascendc_sparse_copy` method that launches the fused `offload.kv_exchange_copy` kernel (builds compact per-component metadata array, converts host pointers to DVAs, uploads indices without stream sync), and wire it into H2D/D2H paths when `ascendc_io_enabled()`.
- **`pool_host/mha.py`** (+17): Extract `k_buffer_5d`/`v_buffer_5d` into local variables before `transfer_kv_dim_exchange` calls (FIA mode compatibility).
- **`managers/cache_controller.py`** (+17): In `submit_device_to_host`, when `ascendc_io_enabled()`, keep token indices on device and upload via `to_device_no_sync` instead of `.cpu()` sync.
- **`hardware_backend/npu/utils.py`** (+7): Extend `set_default_server_args` to also handle `disaggregation_decode_enable_offload_kvcache` config resolution.

Single switch: `SGLANG_HICACHE_HOST_MEM_BACKEND=memfabric` enables both the Memfabric host pool allocation and the AIV sparse-copy IO path simultaneously.

## Accuracy Tests

No impact on model outputs — this PR only affects the HiCache L2 IO transfer path (D2H backup and H2D load). The KV data content is identical; only the transfer mechanism changes.

## Speed Tests and Profiling

- The fused AIV kernel (`kv_exchange_copy`) eliminates host-side entry table construction and avoids per-entry `(src, dst, len)` tuple building, reducing CPU overhead on the D2H backup path.
- Sync-free H2D upload via pinned memory + `torch.npu.Event` avoids `aclrtStreamSynchronize`, allowing layer-group DMA to overlap with compute.
