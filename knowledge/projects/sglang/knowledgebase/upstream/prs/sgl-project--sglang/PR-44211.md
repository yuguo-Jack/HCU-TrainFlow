# fix(spec-v2): unify forward_batch_generation signature across workers and add pp_proxy_tensors to FrozenKVMTP + UNO

[Upstream PR](https://github.com/sgl-project/sglang/pull/44211) · state: closed · merged: False

## Original PR description

## Background

The scheduler non-overlap speculative dispatch path always calls `forward_batch_generation` with `pp_proxy_tensors` (see `srt/managers/scheduler.py`). Across the seven spec-v2 workers, two had drifted out of sync and were missing this parameter: `FrozenKVMTPWorkerV2` and `UnoWorkerV2`. Any model routed through these workers hits a `TypeError` on the first speculative step.

`BaseSpecWorker` is an `ABC` but never declared `forward_batch_generation`, so there was nothing to prevent this drift — the failure only surfaced at runtime.

## Problem

1. **Runtime crash**: `FrozenKVMTPWorkerV2.forward_batch_generation` and `UnoWorkerV2.forward_batch_generation` accept no `pp_proxy_tensors` keyword argument. The scheduler dispatch blows up with `TypeError: got an unexpected keyword argument 'pp_proxy_tensors'`.
2. **No interface guard**: `BaseSpecWorker` does not declare `forward_batch_generation`, so future signature drift will go unnoticed until production.

`dspark_worker_v2` already carried `pp_proxy_tensors` on `main`. `eagle`, `dflash`, `ngram`, and `multi_layer_eagle` were already aligned — same one-line shape as the `multi_layer` fix in #29189.

## Solution

Three focused changes:

1. **`FrozenKVMTPWorkerV2`** — add `pp_proxy_tensors=None` to the signature and forward it to `target_worker.forward_batch_generation` on the prefill path.
2. **`UnoWorkerV2`** — add `pp_proxy_tensors=None` to the signature, propagate through `_forward_prefill`, and forward to `target_worker`.
3. **`BaseSpecWorker`** — declare `forward_batch_generation` as `@abstractmethod` with the canonical signature. This turns the next divergence into a class-definition-time error.

## Testing

- Syntax-checked all three edited files.
- Verified the complete set of seven spec-v2 workers now all carry `pp_proxy_tensors=None` (or keyword-only equivalent) in `forward_batch_generation`.
- Diff scope: 3 files, +33 / −4, all within `python/sglang/srt/speculative/`.

Full build / e2e not run in this environment — happy to add results once CI lands.

Refs: #40155, DSpark instance #39262, `multi_layer_eagle` fix #29189
