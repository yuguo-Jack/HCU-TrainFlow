# [Feat] [CPU] cpu-graph: Support TorchInductor cpp_wrapper with direct custom op C shims

[Upstream PR](https://github.com/sgl-project/sglang/pull/46405) · state: open · merged: False

## Original PR description

## Motivation

When enabling TORCHINDUCTOR_CPP_WRAPPER=1, TorchInductor generates a C++ wrapper for the compiled graph. However, custom operators with non-scalar arguments (such as list or string in multimodal_rotary_embedding_cpu, fused_experts_cpu, qkv_proj_with_rope, etc.) cannot be represented by StableIValue and fallback to Python runtime callbacks (custom_op_wrapper with GIL acquisition, PyTuple packing, and Python function dispatch). This severely degrades CPU decode latency.

This PR introduces direct C ABI shims via Inductor's native custom_ops_to_c_shims interface, allowing custom ops to be called directly as native C functions:

Eliminate Python Fallback: Custom ops with list/str arguments are exposed via extern "C" functions (aoti_torch_cpu_*), completely preventing fallback to Python callbacks.
Zero Dispatcher Overhead: High-frequency kernels bypass c10::Dispatcher and IValue conversion, directly executing the underlying C++ kernel.
Seamless Fallback Loading: Supports loading precompiled symbols from sgl_kernel or dynamically compiling aoti_c_shims.cpp via torch.utils.cpp_extension.load_inline if running against an older wheel.

## Modifications

- Implemented standard C ABI trampolines (extern "C" int aoti_torch_cpu_*) for 6 complex-signature ops (multimodal_rotary_embedding_cpu, fp8_scaled_mm_cpu, fused_experts_cpu, shared_expert_cpu, qkv_proj_with_rope, qkv_proj_with_rope_fused_weight) and core compute ops (rmsnorm_cpu, fused_add_rmsnorm_cpu, silu_and_mul_cpu).

- Added runtime manager to load C shims into the global symbol table (RTLD_GLOBAL) and register them into torch._inductor.config.aot_inductor.custom_ops_to_c_shims.

- Trigger enable_cpu_cpp_wrapper() inside set_torch_compile_config() when SGLANG_CPU_CPP_WRAPPER=1 or TORCHINDUCTOR_CPP_WRAPPER=1 is set.

- Added SGLANG_CPU_CPP_WRAPPER = EnvBool(False).
test/registered/cpu/test_cpu_graph.py:
- Added unit tests for cpp wrapper config registration, custom op accuracy against eager mode, and end-to-end transformer block compilation.
