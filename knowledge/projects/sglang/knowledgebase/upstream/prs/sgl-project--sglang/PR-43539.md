## Modifications

This patch adds two environment variables:

1. `SGLANG_TEST_HICACHE_BACKEND_RANDOM_DELAY`. When set, each backend call will delay `uniform(0, n)` seconds.

2. `SGLANG_TEST_HICACHE_BACKEND_RANDOM_FAILURE`. When set, each backend call randomly fails at specified probability.
