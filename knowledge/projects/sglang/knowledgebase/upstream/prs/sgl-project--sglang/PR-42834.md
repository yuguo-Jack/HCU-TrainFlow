## Original PR description

## Summary

Port #42889 to the `sglang-miles` branch: a cherry-pick of `3e13f1b2c` with no changes.

The OpenAI chat, completion and SageMaker `/invocations` endpoints returned the response model to FastAPI, whose `jsonable_encoder` walks the whole payload in Python; with top-k logprobs that dominated non-streaming latency. These routes now render with `model_dump_json(by_alias=True)` in one pass, with the same JSON values. Measurements and review are on #42889.

## Tests

On `sglang-miles` (`f31278164`), CPU only: `test_json_response.py`, `test_flat_raw_top_logprobs.py`, `test_serving_chat.py` and `test_serving_completions.py` give 205 passed vs 200 on the base branch.
