# [Fix] multimodal: Share typed identities for Kimi prepared inputs

[Upstream PR](https://github.com/sgl-project/sglang/pull/47235) · state: open · merged: False

## Original PR description

## Motivation

#47120 has merged. This PR now targets main with only the three-file Kimi follow-up (+125/-13): the shared Kimi helper, its regression tests, and one valid-fingerprint test fixture.

Kimi's raw-image source/config/grid identity is still needed: a strong tensor hash does not identify preprocessing configuration or permit an early source-cache lookup. This PR preserves that fast path and uses the shared typed identity for prepared inputs instead of a second model-specific implementation.

The previous fallback snapshots a feature or embedding to CPU and combines it with the processor fingerprint and grid. Equal tensors can therefore alias across input formats or different deferred preprocessing metadata. The new regressions reproduce false embedding-cache hits on the parent implementation.

## Changes

- Use the common full identity for prepared/no-source inputs, including feature versus embedding role, input format, shape/dtype, encoder metadata and processor fingerprint.
- Keep raw-image source/config/grid hashing unchanged. Do not remove K3 preprocessing-cache protections or weaken digests.
- Preserve payload/grid validation and ignore stale scalar hints when recomputing a prepared item's identity.
- Add real embedding-cache hit/miss tests, including K3 deferred normalization/backend metadata, and common-identity parity coverage.

No new flags, decoder/resize changes, or radix-cache policy changes. Safe common-prefix reuse is a separate follow-up; the parent's whole-request media namespace remains intact here.
