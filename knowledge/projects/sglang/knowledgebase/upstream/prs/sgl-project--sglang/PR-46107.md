# [Perf] diffusion: Route dense attention with a sub-tile side to FA4 on Blackwell

[Upstream PR](https://github.com/sgl-project/sglang/pull/46107) · state: closed · merged: True

## Original PR description

Branch: mick/blackwell-sub-tile-attention-fa4 (on main 02b983603d), commit cfecddc185

## Motivation

`DYNAMIC_CUDNN_SDPA` sends every dense non-causal attention on sm_10x to cuDNN. When one side is shorter than one 128-row tile and the other is not, cuDNN falls back to `cudnn_generated_fort_native_sdpa_sm80_flash_fprop_wmma`. FA4 is 2-3x faster on those shapes. LTX-2's audio stream has 126 tokens, so audio-prompt, audio-to-video and video-to-audio attention hit this in every block (4 of the 6 attention calls per block in the LTX-2 stage-1 profile).

B300, bf16, no mask, B=1 (B=2 behaves the same):

| q x kv (heads x dim) | cuDNN | FA4 |
|---|---|---|
| 126 x 1024 (32x64) | 17.6 us | 9.5 us |
| 1536 x 126 (32x64) | 13.2 us | 7.5 us |
| 126 x 1536 (32x64) | 24.4 us | 11.6 us |
| 6144 x 126 (16x128) | 35.6 us | 11.7 us |
| 126 x 6144 (16x128) | 84.9 us | 35.3 us |
| 192 x 6144 (32x64) | 32.0 us | 55.6 us |
| 1536 x 1536 (32x128) | 34.7 us | 35.5 us |
| 126 x 126 (32x64) | 6.0 us | 5.6 us |

At 192 tokens and above cuDNN is already on its sm_100 kernels and equal or faster, and with both sides short the two tie.

## Modifications

`layers/attention/backends/sdpa.py`: on sm_10x, `DynamicCudnnSDPAImpl` keeps cuDNN unless exactly one side is shorter than 128 tokens. Those calls go to the FA4 path the backend already holds as its fallback.

Both kernels compute exact softmax attention; only the rounding order changes.

## Tests

`test_dynamic_cudnn_sdpa_routing.py`: both sides at or above a tile, including 192 x 6144, keep cuDNN; one side under a tile routes to FA4; both short keeps cuDNN.

## Accuracy Tests

4xB300 (2 GPUs), LTX-2 two-stage 768x512x121, CFG parallel + BCG, 4 prompts: PSNR against the cuDNN run 16.0 / 19.5 / 23.1 / 14.9 dB.

Reference band for a rounding-only change on this workload: the same server with `quality="exact"` against the default `lossless` (which already mounts other rounding-moving fusions) gives LTX-2 PSNR 17.0 / 20.6 / 23.1 / 20.8 dB and LTX-2.3 18.1 / 19.3 / 17.6 / 20.4 dB over the same four prompts. The 40-step CFG trajectory amplifies any rounding difference to that level, so the e2e number shows only that the change stays inside the band every rounding change lands in.

## Speed Tests and Profiling

LTX-2 stage-1 attention per block drops from 180 us to about 100 us together with the prompt-mask PR. Stage-1 steps go from 51.5 ms to 48.5 ms for the two PRs together (synced stage timing). LTX-2.3 uses the same audio attention shapes at batch 2.
