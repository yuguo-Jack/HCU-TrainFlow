## Scope

Integrate the NPU CPU-offload allocation adaptation from #43824 and the shared Murmur uint32 correction from #43825 on the measured `release/v0.5.20` baseline, `94602c9c2b7cbdb8efd5c52802dac6a1c180089e`.

| #43825 | `ebcec6e4a5416066688e6a5eb71af7476cf21ed7` | One-line shared sampling integer-semantics correction; the implementation is not NPU-only |

Both original heads remain ancestors of this integration branch. The final diff contains exactly their seven files, including the existing tests and preserved evidence. Each component's files are byte-identical to its source PR. No withdrawn compilation, attention-wrapper or kernel changes are reintroduced. The original PRs remain open drafts for component review; this PR neither closes them nor any outstanding issue.

## Validation

Fresh local checks on the integrated source: four CPU-offload allocation-policy tests passed; Python syntax checks passed for all four changed Python files; Ruff F401/F821/UP037 and `git diff --check` passed. Policy tests use recording substitutes and do not establish real device execution.

No new NPU inference or sampling-kernel run has been performed on this combined commit. Existing model scores and vector evidence remain historical results tied to their original source/configuration. Unified model accuracy and cross-repository validation are pending a fixed Omni companion and an allocated NPU test environment. Keep this PR as a draft.

## Conditions and remaining work

CPU-offload delivery retains the documented prefill/decode graphs with compilation explicitly disabled; the transfer overhead remains. Independent compilation/graph compatibility is tracked by #43958 and is not fixed here. The sampling correction does not resolve all speech/audio-text discrepancies tracked by sgl-project/sglang-omni#2738.

The original realtime companion is sgl-project/sglang-omni#2426. A consolidated Omni companion is being prepared separately. Current Omni main pins a newer SGLang/PyTorch stack, so this release-based branch must not be presented as an already-validated match for current Omni main. Upstream review, full CI and the final merge method remain pending.
