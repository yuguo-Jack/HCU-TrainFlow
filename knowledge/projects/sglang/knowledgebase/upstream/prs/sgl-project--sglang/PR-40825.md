# [NPU] Support Kimi-K3 DCP with shared compact communication

[Upstream PR](https://github.com/sgl-project/sglang/pull/40825) · state: open · merged: False

## Original PR description

## Motivation

Enable decode context parallelism (DCP) for Kimi-K3 on Ascend NPU, including DSPARK speculative decoding. Shard target-model MLA KV cache across DCP ranks to reduce per-rank KV storage for a given logical context capacity.

## Modifications

- Add sharded MLA KV allocation, reads, and writes while preserving the scheduler's logical token address space. Reuse the shared DCP-aware Triton KV writer, prefix-index builder, and page-table kernel.
- Adapt Ascend FIA to rank-local KV pages, sequence lengths, and causal masks for decode and DSPARK target verification. Gather sharded prefix KV when needed for prefill/extend.
- Reuse Q AllGather and compact DCP AllToAll with BF16/FP16 partial outputs and FP32 LSE, followed by the shared Triton LSE merge. Handle empty KV shards safely.
- Integrate local metadata and sequence-length updates with NPUGraph capture/replay, and add unit and NPU kernel tests.

Supported scope: Kimi-K3 MLA with FP16/BF16 KV cache and non-NZ FIA V1. Speculative decoding supports DSPARK with static verification; mixed-chunk execution and replicated Q projection are not supported.

  不同主要因为下游读取 KV 的接口不同：

 NPU DSA：由 Ascend backend 准备本地页表、长度和稀疏索引，给稀疏 Attention 使用；跳过整个公共 planner。
