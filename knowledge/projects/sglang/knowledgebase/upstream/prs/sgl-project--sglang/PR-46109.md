# [Perf] diffusion: Build one LTX-2.3 AdaLN row per sample when every token shares the sigma

[Upstream PR](https://github.com/sgl-project/sglang/pull/46109) · state: closed · merged: True

## Original PR description

Branch: mick/ltx23-per-sample-adaln (on main 02b983603d), commit 89d01fddaf

## Motivation

LTX-2.3 two-stage passes per-token timesteps (`[B, T]`) even when there is no denoise mask, so every token carries the same sigma. The DiT then runs its AdaLN MLPs on B*T rows. For the two batched guidance passes per CFG rank that builds a `[2, 1536, 9 * 4096]` table, 226 MB per forward. `ltx2_ada_values9` re-reads it in every block (37 us per block per modality), and every modulation and gate becomes a per-token tensor.

## Modifications

`ltx_2/denoising.py`: `_ltx23_token_timesteps` returns one row per sample (`[B, 1]`) under `quality="lossless"`, and the per-token `[B, T]` expansion under `exact`. A denoise mask keeps its per-token path. The DiT already broadcasts `[B, 1]` rows, as it does for LTX-2.

The values are identical. The AdaLN GEMMs run at M = B instead of M = B*T, and the broadcast modulations take the fused kernels, so only rounding moves.

## Tests

`test_ltx23_per_sample_adaln.py`: the lossless rows are `[B, 1]` and expand to the exact rows. A 2-block LTX-2.3-shaped model (prompt AdaLN, gated attention) gives the same outputs within bf16 rounding for per-sample and per-token rows.

## Accuracy Tests

4xB300 (2 GPUs), LTX-2.3 two-stage 768x512x121, 30 steps, official guider: PSNR against main 18.0 / 19.8 / 19.7 / 18.5 dB.

Reference band for a rounding-only change on this workload: the same server with `quality="exact"` against the default `lossless` (which already mounts other rounding-moving fusions) gives LTX-2 PSNR 17.0 / 20.6 / 23.1 / 20.8 dB and LTX-2.3 18.1 / 19.3 / 17.6 / 20.4 dB over the same four prompts. The 40-step CFG trajectory amplifies any rounding difference to that level, so the e2e number shows only that the change stays inside the band every rounding change lands in.

CI: only `ltx_2.3_two_stage_t2v_2gpus` takes this path (threshold PSNR 16 dB, SSIM 0.45). The HQ pipeline (raw-sigma timesteps), the one-stage legacy path and TI2V (denoise mask) keep per-token rows.

## Speed Tests and Profiling

Same setup. `ltx2_ada_values9` drops from 36.8 us to 4.2 us per call. Client median: 4.27 s before, 4.07 s with this PR alone. With the FA4 routing PR, stage 1 goes from 3.149 s to 2.918 s (105.0 to 97.2 ms per step).
