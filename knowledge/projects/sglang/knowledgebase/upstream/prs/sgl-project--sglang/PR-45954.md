# [Feat] dsv4.1: Support CP>1 encoder replay with P/D and HiCache

[Upstream PR](https://github.com/sgl-project/sglang/pull/45954) · state: open · merged: False

## Original PR description

## Motivation

Extend upstream DeepSeek-V4.1 CP1 encoder SWA bounded replay to CP > 1, including P/D with static DSpark and HiCache L2 / Mooncake L3 recovery.

## Modifications

- Preserve CP token ownership and global window indices through compact replay tails.
- Align DSpark hidden/aux capture and P/D fan-in with the Prefill CP layout.
- Preserve request-owned KV during cache recovery; isolate CP producer identities and intersect restorable endpoints.
- Reuse CP1 replay/compute dispatch; include shared mHC/TopK fixes and regression tests.

Initial scope: SM90 interleave Prefill CP, attention TP=1, PP/DP/DCP/attention-DP=1, Prefill graphs disabled; CP1 Decode with static DSpark and Mooncake P/D; Host cache mode with optional Mooncake L3.

## Accuracy Tests

- CP1 versus matched Commonfix CP1, and CP8 repeatability: cold/L1 checks passed at 257/4097/8193 input tokens with 256 outputs.
- Forced L2 and L3 recovery: **4/4 passed per tier**, matching L1 token IDs, logprobs, and top-2 exactly at the same CP size, adopted prefix, and replay floor. Cross-CP equality is not required.

Quality comparison; CP1 includes the same mHC/TopK fixes:

| Dataset | CP1 replay | CP8 replay | Difference, pp [95% CI] |
|---|---:|---:|---|
| GSM8K, full 1319 | 97.498% | 97.422% | −0.076 [−0.531, +0.379] |

## Speed Tests and Profiling

Historical 128K-input / 1-output observations, RR=0.8, MC=4, N=10:

| Configuration | Input tokens/s | Mean TTFT |
|---|---:|---:|
| Community CP1 | 9,736 | 43.426s |
| Pre-rebase candidate CP8 | 18,160 | 22.869s |

Different seeds and incomplete historical deployment provenance prevent causal attribution. These are descriptive results; no current-head GPU performance, CP1 zero-regression, or Decode-throughput claim is made.
