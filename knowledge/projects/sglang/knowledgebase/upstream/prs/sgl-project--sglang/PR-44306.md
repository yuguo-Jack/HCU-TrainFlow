# [Fix] Z-Image: Synchronize device after warmup request

[Upstream PR](https://github.com/sgl-project/sglang/pull/44306) · state: closed · merged: True

## Original PR description

## Motivation

Since #44069 removed the per-forward host sync in the Z-Image DiT, the request-mode warmup finishes on the host while its DiT step and decode are still queued on the device. The warmup saves no output, so nothing waits for that work. The next request's first blocking op, the text-encoder offload in TextEncodingStage, waits for it instead. This fails the NPU CI perf check for z_image_t2i_1npu:

TextEncodingStage: ~350 ms → ~600 ms on A3; limit 442 ms.
With SGLANG_DIFFUSION_SYNC_STAGE_PROFILING=1 the regression disappears

## Modifications

`gpu_worker.py`: synchronize the device at the end of a warmup request in _finalize_output_batch. The warmup's device work then completes inside the warmup instead of being billed to the next request. Regular requests are unaffected
