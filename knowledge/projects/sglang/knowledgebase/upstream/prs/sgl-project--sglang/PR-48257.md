# [CI] diffusion: Skip the FLUX.3 disagg test when the gated model is unreachable

[Upstream PR](https://github.com/sgl-project/sglang/pull/48257) · state: open · merged: False

## Original PR description

## Motivation

`TestDisaggFlux3Image` (added in #45309) uses `black-forest-labs/flux-3-image-klein`, which is a gated model. Workflows for fork PRs get no secrets (the job log shows `HF_TOKEN:` empty), so the test errors at setup unless the runner already has the model cached:

```
RuntimeError: prompt_encoder failed to start for flux3_split.
Flux3ImagePackageError: could not fetch ['config.json', 'manifest.json', 'hf_quant_config.json'] from Hugging Face repo 'black-forest-labs/flux-3-image-klein': 401 Client Error.
```

That fails `multimodal-gen-test-2-gpu (0)` for reasons unrelated to the PR. In PR runs on 11-03, the job failed this way on all three `h100-novita8` runs and passed on both `h100-novita6` runs:

| PR branch | Runner | Result |
| --- | --- | --- |
| `perf/lingbot-moe-per-sample-mod` | `h100-novita8-gpu-45` | 401 at setup ([job](https://github.com/sgl-project/sglang/actions/runs/41656653186/job/125989316501)) |
| `amx_sgl-diffusion_opt` | `h100-novita8-gpu-45` | 401 at setup ([job](https://github.com/sgl-project/sglang/actions/runs/41666216385/job/126025636170)) |
| #46926 | `h100-novita8-gpu-67` | 401 at setup ([job](https://github.com/sgl-project/sglang/actions/runs/41712145442/job/126183454485)) |
| two other PRs | `h100-novita6-gpu-45`, `-23` | passed |

Main's scheduled runs have the token and pass on every runner.

## Modifications

In `test_disagg_server.py`:
- Add `_require_gated_model(repo_id)`. It returns when an HF token is available, or when a snapshot of the repo is in the local HF cache. Otherwise it raises `unittest.SkipTest("<repo> is gated: needs HF_TOKEN or a cached copy")`.
- Add a `gated_model` class flag to `_DisaggTestBase`, checked in `setUpClass` after the GPU-count check. Only `TestDisaggFlux3Image` sets it. The Z-Image tests use an ungated model and are unchanged.

Runs that have a token, or a cached copy, are unchanged. A fork PR on a runner without the model now skips this one test, with a reason in the log, instead of failing the job. Main's scheduled runs still cover it. The other option is to pre-cache the model on every H100 diffusion runner, but that's an infra change, not a code change.

## Testing

I ran `_require_gated_model` locally against a temporary `HF_HOME`, on `huggingface_hub` 0.36.2 and 2.4.0:
- no token, empty cache: skips with the message above;
- token set, empty cache: runs;
- no token, model cached: runs.

pre-commit passes.
