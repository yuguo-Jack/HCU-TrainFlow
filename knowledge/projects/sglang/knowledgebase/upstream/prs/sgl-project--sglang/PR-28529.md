# Feature/disagg layer pipeline pr

[Upstream PR](https://github.com/sgl-project/sglang/pull/28529) · state: closed · merged: False

## Original PR description

## Motivation

This PR introduces layer-pipelined KV transfer for PD disaggregation on the Mooncake backend.

In the existing PD disaggregation path, the prefill server finishes the full forward pass before transferring KV cache to decode. For long-prefill workloads, KV transfer can become a visible part of end-to-end latency. Layer-pipelined KV transfer streams KV cache by layer groups as soon as those layers are produced, allowing Mooncake transfer to overlap with the remaining prefill compute.

This is intended to improve long-context PD serving latency while keeping the existing transfer path as the default behavior.

## Modifications

- Add layer-pipelined KV transfer support for Mooncake PD disaggregation.
  - Add `--enable-disagg-layer-pipeline`.
  - Add `--disagg-layer-group-size`.
  - Add `--disagg-layer-pipeline-min-prefill-len`.
  - Add request-level fallback to the legacy transfer path for short requests.

- Add CP transfer shard mode support for the NSA-CP all-rank transfer path.
  - Add `--disaggregation-cp-transfer-shard-mode`.
  - This flag is only valid when NSA CP is used together with `SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1`.
  - Under that condition, it must be set to `layer`; `page` should not be used for this path.
  - Keep the default non-NSA / non-all-CP transfer behavior unchanged.
  - Keep the existing env override `SGLANG_DISAGGREGATION_CP_TRANSFER_SHARD_MODE` as a deprecated compatibility path.

- Add Mooncake sender/receiver support for layer-group KV chunks.
  - Transfer main KV by layer groups.
  - Send aux data through a trailing finalizer chunk.
  - Handle draft KV separately after draft forward.
  - Support NSA state transfer with layer-pipelined chunks.
  - Add watermark/progress tracking for multi-chunk LP transfer.

- Add compatibility and safety handling.
  - LP only engages when both prefill and decode support compatible LP settings.
  - Add handshake warnings for LP setting mismatches, including group size and KV dtype mismatch.
  - Preserve the legacy single/fan-out transfer path when LP is disabled or not eligible.
  - Keep default CP behavior unchanged unless the NSA-CP all-rank layer-shard path is explicitly selected.

- Add observability.
  - Add LP chunk count metric.
  - Add per-layer-group transfer latency metric.
  - Add actual transfer duration accounting.
  - Add debug-only LP environment variable warnings.

- Add documentation.
  - Add `docs/advanced_features/disagg_layer_pipeline.md`.
  - Add the new page to `docs/index.rst`.

- Add unit tests for:
  - LP min-prefill-length fallback.
  - Layer-group chunking and watermark behavior.
  - Draft KV transfer behavior.
  - NSA state transfer behavior.
  - Default CP transfer behavior and NSA-CP all-rank layer-shard behavior.
  - MHA/MLA KV pointer layout handling.
  - Metrics and cleanup behavior.

Standard Python `logging.Logger` does not have a `warning_once` method. Calling `logger.warning_once` will raise an `AttributeError` at runtime if a PD layer pipeline setting mismatch occurs between prefill and decode servers. Use `logger.warning` instead to ensure the warning is logged safely without crashing the server.

```suggestion
            logger.warning(
                "PD layer pipeline setting mismatch between prefill and decode "
                f"(prefill={info.layer_pipeline_enabled}, decode={self.layer_pipeline_enabled}); "
                "falling back to non-layer-pipeline transfer for this connection."
            )
```

If `component_indices` is a 0-dimensional PyTorch tensor (which is common for scalar indices), calling `len(component_indices)` will raise a `TypeError: len() of a 0-d tensor` even though `hasattr(component_indices, '__len__')` returns `True`. To prevent potential runtime crashes, check for the `numel` attribute first (which safely returns the total number of elements for PyTorch tensors) before falling back to `len()`.

```suggestion
                    if hasattr(component_indices, "numel"):
                        self._transfer_num_state_indices += component_indices.numel()
                    elif hasattr(component_indices, "__len__"):
                        self._transfer_num_state_indices += len(component_indices)
                    else:
                        self._transfer_num_state_indices += 1
```
