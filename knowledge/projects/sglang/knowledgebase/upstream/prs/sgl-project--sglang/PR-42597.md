# [cookbook] docs: add Intel Arc Pro B-Series (BMG) support to cookbook models

[Upstream PR](https://github.com/sgl-project/sglang/pull/42597) · state: open · merged: False

## Original PR description

## Motivation

Extend the Qwen3.6 and Gemma 4 cookbook pages and their interactive deployment selectors to document Intel Arc Pro B-Series GPUs (codename: BMG (Battlemage)) as a first-class deployment target, so the generated commands and selector capabilities match what BMG supports today:

- **Qwen3.6**: both the **35B-A3B (MoE)** and **27B (Dense)** variants, BF16.
- **Gemma 4**: adds the **E2B**, **E4B** and **12B** variants to the existing BMG coverage (31B, 26B-A4B).

Follows the pattern established in #33649 (which added BMG coverage to Qwen3, Qwen3.5, Llama 3.1/3.3, Gemma 4, DeepSeek-OCR-2, Nemotron3-Nano, FLUX, and Z-Image-Turbo).

## Modifications

### Qwen3.6

`docs/cookbook/autoregressive/Qwen/Qwen3.6.mdx`

- Rewrote the "Model Deployment" lead sentence to enumerate NVIDIA GPUs, Intel Arc Pro B-Series GPUs (BMG), and Intel Xeon CPUs.
- Added an XPU installation pointer ([XPU version installation guide](https://docs.sglang.io/docs/hardware-platforms/xpu#installation)) next to the existing CPU one, which stays unchanged.
- Hardware requirements: added a BMG note (24GB per GPU, BF16 only, TP=4 for both variants), and scoped "fits on a single supported GPU" to NVIDIA GPUs.

`docs/src/snippets/autoregressive/qwen36-deployment.jsx`

- Added `arc_b` (label `BMG`) as a hardware option.
- Added `arc_b: { bf16: { tp: 4, mem: 0.8 } }` under both the `35B-A3B` and `27B` model entries.
- Quantization: BF16 default on BMG; FP8 disabled with a reason tooltip ("FP8 is not supported on BMG for Qwen3.6"); NVFP4 still Blackwell-only.
- Speculative Decoding (MTP): disabled on BMG with a per-reason tooltip.
- Mamba Radix Cache: hidden on BMG (same treatment as Xeon).
- Command generator for BMG emits `--device xpu` and `--linear-attn-backend intel_xpu`.

### Gemma 4

`docs/src/snippets/autoregressive/gemma4-deployment.jsx`

- Added `arc_b` configs for `e2b`, `e4b` and `12b` (`tp: 4, mem: 0.80`).
- Allowed these variants in the BMG model-size lock, the hardware-switch fallback, and the disabled-item check.

### Commands rendered by the selector on BMG (BF16, defaults)

```shell
# Qwen3.6-35B-A3B
sglang serve --model-path Qwen/Qwen3.6-35B-A3B \
  --device xpu \
  --linear-attn-backend intel_xpu \
  --tp 4 \
  --reasoning-parser qwen3 \
  --tool-call-parser qwen3_coder \
  --mem-fraction-static 0.8

# Qwen3.6-27B
sglang serve --model-path Qwen/Qwen3.6-27B \
  --device xpu \
  --linear-attn-backend intel_xpu \
  --tp 4 \
  --reasoning-parser qwen3 \
  --tool-call-parser qwen3_coder \
  --mem-fraction-static 0.8
```

### Validation on BMG

Validated on 4x Intel Arc Pro B60 (24GB) with `lmsysorg/sglang:v0.5.21-xpu`, using the commands above and this chat request:

```shell
curl http://localhost:30000/v1/chat/completions -H "Content-Type: application/json" -d '{"model":"Qwen/Qwen3.6-27B","messages":[{"role":"system","content":"You are a helpful assistant."},{"role":"user","content":"Who won the world series in 2020?"}]}'
```
