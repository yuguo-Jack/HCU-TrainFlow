# [Perf] [NPU] sensenova: Fuse rotary position embeddings

[Upstream PR](https://github.com/sgl-project/sglang/pull/40856) · state: open · merged: False

## Original PR description

## Motivation

SenseNova-U1.5-8B-MoT applies RoPE to query and key tensors in every attention layer. Using an NPU fused operator reduces this work and improves end-to-end generation latency. RoPE table precomputation also needs to handle decoder layers wrapped by Cache-DiT; directly accessing `layers[0].self_attn` causes warmup to fail.

## Modifications

- Add a SenseNova RoPE path that calls `torch_npu.npu_rotary_mul` for query and key tensors using `rotary_mode="half"`.
- Enable it with `SGLANG_SENSENOVA_NPU_FUSED_ROPE=rotary_mul`. The default remains the original implementation, which is also used when the fused path’s conditions are not met.
- Resolve the attention module inside a Cache-DiT wrapper before precomputing shared RoPE tables, and add a unit test for this case.
- Merge the existing `sensenova-release` history into a branch based on the updated `upstream/main`. The resulting PR diff includes earlier SenseNova changes from that branch.

## Accuracy Tests

- Python syntax checks and `pre-commit` passed.
- A unit test was added for the Cache-DiT wrapper case. Local pytest stopped during test collection because `orjson` is missing from the environment.
- **Pending:** Compare generated outputs and numerical error between the original and fused RoPE paths on the target NPU.
