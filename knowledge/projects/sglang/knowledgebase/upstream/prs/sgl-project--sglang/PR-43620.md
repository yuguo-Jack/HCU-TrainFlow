# [DSpark] Run every markov head through one step interface

[Upstream PR](https://github.com/sgl-project/sglang/pull/43620) · state: closed · merged: True

## Original PR description

- `BaseDSparkMarkovHead` gives every DSpark markov head (vanilla, Nemotron 3.5 quantized, gated, RNN, DeepSeek-V4) the same two methods: `init_state(hidden_states)` and `step_bias(prev_tokens, *, hidden_states, state) -> (bias, state)`.
- The per-head step loops become one loop over this interface; a head only says how it computes one step's bias.

No behavior change.

## Verification

- `test_dspark_draft_path_default.py` (CPU) passes; the GPU tests run on the layers above, which build on this interface.
