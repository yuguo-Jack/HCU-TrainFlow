# [Doc] deployment: Fix the LWS manifest document separator

[Upstream PR](https://github.com/sgl-project/sglang/pull/45352) · state: closed · merged: False

## Original PR description

## Motivation

The RDMA RoCE deployment guide uses `***` between its LeaderWorkerSet and Service resources. Copying the complete example into `lws.yaml` produces invalid YAML: the parser treats the asterisks as an invalid alias and rejects the manifest before deployment.

## Modifications

Use the YAML document separator `---` so the two resources are separate documents.
