# Optimize Kimi K3 NVFP4 prefill and decode

[Upstream PR](https://github.com/sgl-project/sglang/pull/46202) · state: open · merged: False

## Original PR description

Add guarded Kimi K3 NVFP4 prefill and decode paths: routing/activation quantization, Cake MoE, CuTe MLA and MHA prefill, KV projection dispatch, FP8 dense dispatch, shared-expert overlap, DFlash preparation graphs, and deferred KDA replay.

Preserve fallbacks for unsupported configurations. Routing/quant fusion, eligible KV projection dispatch, FP8 dense dispatch, early shared-expert fork, split-front TGV, DFlash preparation graphs, and pending KDA replay default to on within their supported configurations. Pending KDA replay supports batch sizes 1–64. Cake MoE, the additional TP shared-expert overlap path, and the CuTe/MHA prefill paths remain opt-in. Include regression tests for quantization, graph replay, and recurrent-state handling.
