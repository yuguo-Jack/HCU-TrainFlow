# [Perf] logits: Write lm_head logits straight into the fp32 logits buffer

[Upstream PR](https://github.com/sgl-project/sglang/pull/45631) · state: closed · merged: True

## Original PR description

Write CUDA fp16/bf16 lm_head GEMM output directly into the existing fp32 logits buffer, skipping the intermediate tensor and copy. Intermediate logits keep their existing dtype when no matching output buffer is available.

## Validation

- GB300: `test/registered/rl/test_fp32_lm_head.py` — 8 tests, including 28 buffer/transform subcases and CUDA graph replay.
- Tiny-model serving comparisons against Hugging Face: Llama TP1/TP2, Qwen3 TP2 with DP2, and Gemma2 TP2 with softcapping. Maximum absolute generated-token log-probability difference: 0.006.
- Isolated logits benchmark, 1024 rows × 129280 vocab × 4096 hidden: 0.890 → 0.589 ms locally; TP2 gather path remains 1.215 ms.

## Results

DeepSeek-V4.1-Flash, DEP8 decode on 2x GB300, MTP 3: step time 22.11 → 21.94 ms at 128 req/rank (−0.8%), 31.88 → 31.61 ms at 256 req/rank (−0.9%); unchanged at ≤64. GSM8K 0.9734.
