# [Perf] sampling: Draw final samples in vocabulary blocks

[Upstream PR](https://github.com/sgl-project/sglang/pull/44116) · state: closed · merged: False

## Original PR description

## Motivation

For rejection sampling, EAGLE, NEXTN, UNO and DFLASH call this sampler eagerly. DSpark does too, unless `SGLANG_OPT_DSV41_SAMPLING_ACCEPT_GRAPH` (off by default) captures the accept step in a CUDA graph. With `SGLANG_ENABLE_NV_MEGA_RUNTIME_OPTIMIZATION=1`, that graph uses blockwise rejection unless block verification is on.

On `main`, one GPU program per request walks the vocabulary for the final token. For a final coin within about 16 FP32 steps of 1 (about 1e-6 of draws), `main` can return a zero-weight or out-of-vocabulary token.

## Modifications

Above 32,768 tokens, the final draw sums weights in parallel over 4,096-token blocks, then scans one block. Up to 32,768 tokens, the draw stays in the acceptance kernel, with 8 warps above a 4,096-lane tile. The draw returns a positive-weight token when the residual has one. Existing configs need no change.

## Accuracy Tests

The empty-residual fallback matches `main` ([concrete inputs](https://github.com/sgl-project/sglang/pull/44116#issuecomment-6548458208)). The cutoff test fails on `main`. The sparse test passes there and fails here without either residual filter.

```python
"""Usage from the repository root: python speed.py BASELINE_FILE VOCABS BATCHES (comma lists)."""
import importlib.util, statistics, sys, time
import torch


def load(name, path):
    spec = importlib.util.spec_from_file_location(name, path)
    module = importlib.util.module_from_spec(spec)
    sys.modules[name] = module
    spec.loader.exec_module(module)
    return module.chain_speculative_sampling_triton


def eager_us(fn, n=60):
    times = []
    for _ in range(n):
        start = time.perf_counter_ns()
        fn()
        torch.cuda.synchronize()
        times.append((time.perf_counter_ns() - start) / 1000)
    return statistics.median(times)


def replay_us(replay, n=60):
    torch.cuda.synchronize()
    start = time.perf_counter_ns()
    for _ in range(n):
        replay()
    torch.cuda.synchronize()
    return (time.perf_counter_ns() - start) / n / 1000


samplers = {
    "main": load("rs_main", sys.argv[1]),
    "pr": load("rs_pr", "python/sglang/kernels/ops/speculative/reject_sampling.py"),
}
slots, steps = 6, 5
for vocab in map(int, sys.argv[2].split(",")):
    for batch in map(int, sys.argv[3].split(",")):
        torch.manual_seed(2026)
        p = (torch.randn(batch, slots, vocab, device="cuda") * 3).softmax(-1)
        noise = (torch.randn(batch, steps, vocab, device="cuda") * 3).softmax(-1)
        q = (0.7 * p[:, :steps] + 0.3 * noise).contiguous()
        cand = torch.zeros(batch, slots, dtype=torch.long, device="cuda")
        cand[:, 1:] = torch.multinomial(q.flatten(0, 1), 1).view(batch, steps)
        idx = torch.arange(batch * slots, device="cuda").view(batch, slots)
        pred = torch.empty(batch * slots, dtype=torch.int32, device="cuda")
        acc = torch.empty_like(idx, dtype=torch.int32)
        num = torch.empty(batch, dtype=torch.int32, device="cuda")
        coins, final = torch.rand(batch, slots, device="cuda"), torch.rand(batch, device="cuda")
        for block in (False, True):
            eager, graph = {k: [] for k in samplers}, {k: [] for k in samplers}
            calls, graphs = {}, {}
            for name, sampler in samplers.items():
                calls[name] = lambda s=sampler: s(
                    pred, acc, num, cand, idx, None, None, coins, final, p, q, 1.0, 1.0, True,
                    block_verification=block,
                )
                calls[name]()
                graphs[name] = torch.cuda.CUDAGraph()
                with torch.cuda.graph(graphs[name]):
                    calls[name]()
            for round_id in range(9):
                for name in samplers if round_id % 2 == 0 else reversed(list(samplers)):
                    eager_us(calls[name], 10)
                    eager[name].append(eager_us(calls[name]))
                    replay_us(graphs[name].replay, 10)
                    graph[name].append(replay_us(graphs[name].replay))
            med = lambda x: round(statistics.median(x), 2)
            print(vocab, batch, "block" if block else "token",
                  "eager", med(eager["main"]), med(eager["pr"]),
                  "graph", med(graph["main"]), med(graph["pr"]), flush=True)
```

I validated `18a42c8f56` on B200 with the sampler, DSpark and EAGLE tests and NEXTN serving. I did not verify ROCm, MUSA, UNO serving, multi-layer EAGLE, or GLM-5.3-Flash at this head.

Deliberate limits:

- Eager time exceeds `main` at some sizes from 32,001 to 65,536.
- From 16,385 to 32,767, sizes not divisible by 16 compile in 8 to 10 s, against about 2 s. Up to batch 48, graph time reaches 1.33x of `main` at 32,001.
- Above the default of 48 requests, token-wise time at 32,001 reaches 3.23x of `main` in eager mode and 3.73x in graph mode.

These limits are deliberate. Do not add code for them without a real input that reaches the case.
