# [Test] [AMD] diffusion: Skip MOSS-Image mismatched-operand test on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/44596) · state: open · merged: False

## Original PR description

## What

Skip `test_moss_image_selected_kernel_rejects_mismatched_operands` on ROCm, the same way the other MOSS-Image fused-kernel tests in `test_model_fast_paths.py` are already skipped.

## Why

#44325 added this test, and it fails on ROCm in `nightly-test-1-gpu-kernel` on all three MI300 lanes (rocm10, rocm720, rocm724): [run 38779021639](https://github.com/sgl-project/sglang/actions/runs/38779021639/job/116574070249), both params, 2 failed / 46 passed.

The test passes mismatched operands and expects a `ValueError` from the input checks in `fused_situ_softcap_mul_bitexact` and `rmsnorm_cast_before_weight_bitexact`. Both kernels are gated on `is_cuda()` (`can_use_fused_situ_softcap_mul`, `can_use_rmsnorm_cast_before_weight`), so on ROCm `_fused_or_native` goes straight to eager. Eager then fails on the shape mismatch with `RuntimeError: The size of tensor a (16) must match the size of tensor b (17)`, which `pytest.raises(ValueError)` doesn't catch.

The test is about the selected fused kernel's behaviour, so skipping it where that kernel can't be selected matches the neighbouring `test_moss_image_situ_fusion_is_bit_exact_and_verified` and `test_moss_image_rmsnorm_fusion_is_bit_exact_and_verified`. NVIDIA is unchanged.

## Test plan

ROCm, MI300, `nightly-test-1-gpu-kernel` at `aa87e6c59d` with `continue_on_error=false`, 19/19 files pass on both lanes:
- rocm10: [run 39264799995](https://github.com/sgl-project/sglang/actions/runs/39264799995/job/118101481520)
- rocm724: [run 39264805984](https://github.com/sgl-project/sglang/actions/runs/39264805984/job/118101508812)

`test_model_fast_paths.py`: 46 passed, 69 skipped (2 failing on main, e.g. [nightly 39150288819](https://github.com/sgl-project/sglang/actions/runs/39150288819)). Not run on rocm720, where `test_modulate.py::test_ltx2_ada_values9[True-...]` fails for an unrelated reason. Not run on NVIDIA; the change only adds a ROCm skip.
