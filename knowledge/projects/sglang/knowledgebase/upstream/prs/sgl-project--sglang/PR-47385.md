# [Doc] ascend: add NPU graph mode optimization guide

[Upstream PR](https://github.com/sgl-project/sglang/pull/47385) · state: open · merged: False

## Original PR description

## Motivation

The Ascend NPU documentation covers installation, deployment and model support, but there is no dedicated page describing graph mode (`ACLGraph` / `GE` graph) usage for serving. Users have to piece this together from scattered notes.

## Changes

- Add `docs/docs/hardware-platforms/ascend-npus/optimization/npu_graph_mode.mdx`, covering:
  - what ACLGraph and GE graph modes are and when to use them
  - configuration knobs / environment variables
  - capture-size and memory considerations
  - troubleshooting notes
- Register the page in `docs/docs.json` under the Ascend NPU optimization group (`parameter_tuning`, `profiling`, **`npu_graph_mode`**, `quantization`, `ring_sp_performance`).
