# [CI] moe: Give the NVFP4 non-gated Marlin MoE test bf16-sized headroom

[Upstream PR](https://github.com/sgl-project/sglang/pull/47687) · state: closed · merged: True

## Original PR description

## Motivation

`test_fused_marlin_moe_nvfp4_non_gated_matches_dequant_reference` in `test/registered/kernels/ops/moe/test_moe_wna16_marlin.py` is flaky on `1-gpu-h100` (tracked as **T8** in #42752):

```
AssertionError: Tensor-likes are not close!
Mismatched elements: 1 / 4352 (0.0%)
Greatest absolute difference: 0.2578125 at index (7, 195) (up to 0.25 allowed)
```

The test is seeded, so the inputs don't change. Two things make it flaky:

- **The kernel output isn't deterministic on SM90.** `fused_marlin_moe` sets `use_atomic_add` for bf16 on SM >= 9, so the partial-sum order varies run to run.
- **The tolerance is one bf16 ulp.** Outputs reach |32-64|, where bf16 values are 0.25 apart, the same as `atol`. A single rounding step of variation fails the assert.

## Modifications

Raise `atol` from 0.25 to 0.5 (two ulps at the output's magnitude), with a comment explaining why. `rtol` is unchanged. Test-only, one line plus a comment.

## Test plan

On an H100 NVL (SM90), with `upstream/main` at `bd1f5596` in `lmsysorg/sglang@sha256:c1f4d9fc…`:

**1. Replicated setup, 200 kernel runs per seed, seeds 0-49:**
- All 50 seeds gave outputs that weren't bit-identical across runs.
- Failures against the test's tolerance: 2119/10000 with the test's bf16 reference.
- An fp32 reference is not a fix. It fails 1204/10000, and on seed 0 it leaves *less* headroom than the bf16 reference (-0.0022 vs -0.0059).
- Worst violation with `atol=0.25` over all seeds was +0.225 (seed 44). With `atol=0.5` that becomes -0.025 headroom on seed 44, and -0.244 on seed 0.

**2. The real test function from the test file, called repeatedly:**

| | seed 0 (as written), 200 runs | `torch.manual_seed` shifted to seeds 0-49, 20 runs each |
|---|---|---|
| main, `atol=0.25` | 0/200 | **179/1000** fail |
| this PR, `atol=0.5` | 0/200 | **0/1000** |

Seed 0 itself sits right at the edge (-0.006 headroom), which fits a rare CI failure.
