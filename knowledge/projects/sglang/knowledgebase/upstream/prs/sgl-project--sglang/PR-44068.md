# fix(environ): align SGLANG_JIT_CACHE_DIR default with SGLANG_CACHE_DIR

[Upstream PR](https://github.com/sgl-project/sglang/pull/44068) · state: closed · merged: False

## Original PR description

## Summary

Partial fix for #19612: Align `SGLANG_JIT_CACHE_DIR` with the unified `SGLANG_CACHE_DIR` root.

### Problem

SGLang already directs third-party JIT caches (Triton, Inductor, CUDA, TileLang, FlashInfer) under `SGLANG_CACHE_DIR` via `redirect_third_party_caches()`, and other internal caches (`SGLANG_DG_CACHE_DIR`, `SGLANG_CUTE_AOT_CACHE_DIR`) resolve relative to it using `_default_cache_subdir()`. However, `SGLANG_JIT_CACHE_DIR` was inconsistent:

- **`environ.py`**: declared as `EnvStr(None)` (no default)
- **`cache.py`**: hardcoded fallback `"~/.cache/sglang/jit"`

This split meant setting `SGLANG_CACHE_DIR=/mnt/cache` did **not** redirect the JIT kernel build cache — operators needed a separate `SGLANG_JIT_CACHE_DIR=/mnt/cache/jit` override.

### Fix

1. **`environ.py`** — Changed `SGLANG_JIT_CACHE_DIR` from `EnvStr(None)` to `EnvStr(lambda: _default_cache_subdir("jit"))`, matching the pattern used by `SGLANG_DG_CACHE_DIR` and `SGLANG_CUTE_AOT_CACHE_DIR`.

2. **`cache.py`** — Updated `cache_root()` fallback from a hardcoded `"~/.cache/sglang/jit"` to `os.path.join(os.path.expanduser(envs.SGLANG_CACHE_DIR.get()), "jit")`, eliminating the second source of truth.

### Result

All JIT/precompilation caches now resolve under a single configurable root:

| Cache | Default path | Override env |
|-------|-------------|--------------|
| Triton | `$SGLANG_CACHE_DIR/triton` | `TRITON_CACHE_DIR` |
| Inductor | `$SGLANG_CACHE_DIR/inductor` | `TORCHINDUCTOR_CACHE_DIR` |
| CUDA | `$SGLANG_CACHE_DIR/nv` | `CUDA_CACHE_PATH` |
| TileLang | `$SGLANG_CACHE_DIR/tilelang` | `TILELANG_CACHE_DIR` |
| FlashInfer | `$SGLANG_CACHE_DIR` base | `FLASHINFER_WORKSPACE_BASE` |
| DeepGEMM | `$SGLANG_CACHE_DIR/deep_gemm` | `SGLANG_DG_CACHE_DIR` |
| CuTe AOT | `$SGLANG_CACHE_DIR/cute_aot` | `SGLANG_CUTE_AOT_CACHE_DIR` |
| **JIT kernel builds** | `$SGLANG_CACHE_DIR/jit` | `SGLANG_JIT_CACHE_DIR` |

Setting `SGLANG_CACHE_DIR=/mnt/cache/sglang` now redirects every cache at once.

### Backward Compatibility

- If `SGLANG_JIT_CACHE_DIR` is explicitly set, it still takes precedence
- Default path changes from `None` → `~/.cache/sglang/jit` (same as `cache.py`'s previous hardcoded fallback)
- External callers that read `SGLANG_JIT_CACHE_DIR` will now see a concrete path when unset instead of `None`
