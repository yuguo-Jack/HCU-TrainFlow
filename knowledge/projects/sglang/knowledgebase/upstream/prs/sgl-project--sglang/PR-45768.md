## Motivation

<!-- Describe the purpose and goals of this pull request. -->
Enable runtime P↔D switching with Mooncake staging buffers under PP=1. 

## Modifications

<!-- Detail the changes made in this pull request. -->
- Add scheduler-owned backing storage shared by prefill chunk views and a persistent decode ring allocator. Retain the Mooncake engine/session, registration, and allocator progress across switches; rebuild role-specific state and refresh peer connections when endpoints change.
- Require deferred KV release, reject busy or unsafe handoffs, synchronize staging work before ownership transfer, and coordinate failures across TP ranks. Ignore orphan writer bookkeeping in readiness checks.
- Join workers before executor shutdown with `wait=False`. Preserve ordinary KV/aux/state deregistration error handling and keep shared backing checks separate. Extend existing unit tests without adding test files.
