## Motivation

<!-- Describe the purpose and goals of this pull request. -->
- Enable the fused all-reduce + norm boundary with 1-shot and 2-shot push (commit `2abf911e9f`).
- Refactor the all-gather + norm kernel onto the same norm rows (commit `e41c694aa2`).

## Modifications

<!-- Detail the changes made in this pull request. -->
- `norm_residual.cuh`: the kernel bodies move into `norm_residual_row` / `norm_residual_cluster_row`, which take the branch through a callback; the kernels become thin entry points.
- `all_reduce_norm_residual.cuh` (new): 1-shot / 2-shot push exchange on the `CustomAllReduceV2` push plane (multicast at TP8), then the norm rows on the reduced row in registers.
- `muse_spark_all_reduce_norm_residual.py` (new): the op, its eligibility check and the boundary wrapper. 1-shot while `num_tokens * world_size <= 128`, 2-shot above; the norm's own launch config otherwise. `_LAUNCH_OVERRIDES` replaces the launch per (compute capability, world size) where serving benchmarks measured a faster one: GB300 TP4 M 48-64, SM107 TP4 M 48.
- `muse_spark.py`: the decoder layer uses the fused boundary when it applies, and `o_proj` skips its all-reduce.

[by Claude Code] **Severity: style | Confidence: High**

**Issue**

`all_reduce_norm_residual` picks the kernel entry point with `getattr(module, ...)` on a built string name. New `getattr` / `hasattr` calls are not allowed in SGLang. A typo in the name fails only at runtime, and static checks cannot see which of the four wrappers runs.

**Fix**

Select the entry point explicitly:

```python
if post_norm_is_input_scale:
    fn = module.run_scale_router if want_router else module.run_scale
else:
    fn = module.run_std_router if want_router else module.run_std
```
