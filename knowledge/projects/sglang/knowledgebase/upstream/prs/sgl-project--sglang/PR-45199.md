# [Fix] sidecar: launch managed sidecars on KV-publishing followers

[Upstream PR](https://github.com/sgl-project/sglang/pull/45199) · state: open · merged: False

## Original PR description

## Motivation

With `--sidecar` on a multi-node attention-DP engine, followers expose metadata gRPC and wait for their schedulers to exit, but never launch the sidecar. Followers that own KV-event publishers therefore need a separately managed sidecar to relay their local events.

## Modifications

- Launch the configured sidecar after follower metadata gRPC starts, only when the node reports local KV-event sources.
- Retain the sidecar handle and PID, stop it before metadata gRPC on shutdown, and clean up services and scheduler processes if startup raises. Cover both blocking server startup and the nonblocking Python Engine lifecycle.
- Clarify in `--sidecar` help that follower modules must support a metadata-only gRPC endpoint. The sidecar provider remains responsible for selecting its telemetry-only role.

### Setup

- 2 NVIDIA A100-SXM4-80GB nodes, one GPU per engine Pod.
- Operator-managed `nvidia.com/v1beta1` DynamoGraphDeployments using **LeaderWorkerSet**, with one two-node replica and a KV-aware Dynamo frontend.
- Model: `Qwen/Qwen3-0.6B` + agg.
- SGLang nightly `nightly-dev-cu13-20261019-3c560089`, base `3c560089e1818a5217a73f2168273485a5350341`, plus this PR's commit `a8abfac201a1dd8d905f0731f4d1321f3d3e83dc` (clean cherry-pick `868fee6497fc28750c2944e05ceccd8d7a962afa`).
- Dynamo operator nightly `20261018-3763cee`, source `3763cee6080ce6a8ab4156f055d8ce72d984458c`. 

Each engine Pod had one `main` container. SGLang itself launched the Dynamo subprocess with:

```sh
python3 -m sglang.launch_server \
  --model-path Qwen/Qwen3-0.6B \
  --host 0.0.0.0 --port 30000 --grpc-port 30001 \
  --mem-fraction-static 0.2 --context-length 4096 \
  --tp-size 2 --incremental-streaming-output --page-size 16 \
  --kv-events-config '{"publisher":"zmq","endpoint":"tcp://*:5557","topic":""}' \
  --sidecar dynamo.sglang.sidecar \
  --sidecar-args '["--grpc-endpoint", "127.0.0.1:30001"]' \
  --log-requests
```
