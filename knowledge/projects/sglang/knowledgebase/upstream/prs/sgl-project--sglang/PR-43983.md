## How the commands are produced

The pipeline and rules are the same as in #42726, #43083 and #43799, and no keep/remove/rewrite rule was added. Each lane is rendered at the exact commit of the run that produced its dashboard data. For an open PR, that is the run named by its authorized `/use` comment, or the PR head when there is none. SA-only settings are removed: the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment). Placeholders replace IPs, ports and NICs. Router and KV-offload variants that were not run are derived and labeled "Derived — not run".

- **Not mirrored.** `qwen3.5-fp8-h100-sglang-agentic` (H100 without MTP) has never produced dashboard data, so there is no run to pin it to.
- **DeepSeek-V4.1 HiCache donor.** Unchanged from #43799: the measured `main` version of `dsv41flash-fp4-gb300-dynamo-sglang-agentic-disagg` keeps donating the derived HiCache flags while [InferenceX #3860](https://github.com/SemiAnalysisAI/InferenceX/pull/3860)'s revision is unmeasured.

The data files are generated, so there is no hand-written code to review here.
