# [Feat] comfyui: video-to-video input and prompt enhancement for server-mode nodes

[Upstream PR](https://github.com/sgl-project/sglang/pull/43673) · state: closed · merged: True

## Original PR description

Fixes #43877 (video-to-video and prompt enhancement parts)

Stacked on #44082, which this branch merges; the diff below #44082 is small.

## Summary

Two additions to the existing server-mode nodes. Both use request fields the server already accepts; no new nodes and no server changes.

1. **Video-to-video**: `SGLDiffusion Generate Video` gets an optional `VIDEO` input. It is saved as an MP4 to the ComfyUI temp dir and sent as `video_path`, which the client from #44082 already uploads.
2. **Prompt enhancement**: an `enhance_prompt` toggle on the image and video nodes, plus a trailing `revised_prompt` `STRING` output. Without enhancement it is the original prompt. The video node passes it through the client's existing `extra_fields`.

New inputs are optional and appended last, and the new output comes after the existing ones, so saved graphs keep working.

## Dropped after review

- Checkpoint sweep, LoRA list / stack nodes, and the merge_mode option: server-mode tooling is out of scope here.
- Audio-video node: ComfyUI's built-in `Get Video Components` already returns `AUDIO` from the `VIDEO` this plugin outputs.
- The separate test files and harness: the tests are now in the existing `test_sgld_server_mode.py`.

## Testing

CPU only, run in a clean Modal container. Two tests were added to `test_sgld_server_mode.py`:

- the image node with `enhance_prompt` on and off (parameterized): the HTTP payload, the decoded image and `revised_prompt`
- the video node with a `VIDEO` source and `enhance_prompt`: the bytes of the saved source clip, `extra_fields` and `revised_prompt`

`test_sgld_server_mode.py`, `test_h3_request.py` and `test_comfyui_lora_node.py` pass, except `test_chained_lora_nodes_keep_every_lora`, which fails the same way on the #44082 head without this change.

`ruff` (the pre-commit selection), `ruff format`, `isort` and `codespell` are clean.
