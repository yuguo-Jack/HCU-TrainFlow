## Motivation
GLM-5.3-Flash already supports interleave prefill context parallelism,
but its prefill CUDA Graphs are automatically disabled. This leaves
CP prefill running eagerly and prevents it from benefiting from
breakable CUDA Graph replay.

Enable BCG for the supported GLM CP configuration while preserving
correct CP-local DSA indexing, global-sequence KDA recurrence, and
KDA state transfer in NIXL-based PD deployments.

## Modifications

- Extend CP+BCG eligibility to GLM-5.3-Flash with interleave CP and
  TileLang or `flashmla_sparse_q8` DSA prefill.
- Preserve the requested prefill graph backend for eligible configurations
  instead of unconditionally disabling it.
- Restrict support to full-width CP with DP1/PP1, no speculative decoding,
  and no DSA cache-layer splitting.
- Require exact capture-bucket matches for GLM replay; unmatched token
  counts fall back to eager execution to preserve KDA recurrence geometry.
- Use CP-local token counts for KPool indexer graph outputs, while keeping
  global token counts for KDA graph metadata.
- Restore global causal positions for KPool compression when BCG uses
  CP-local position buffers, and normalize interleave splitter lengths
  to `int32`.
- Enable NIXL PD prefill with CP/TP group sharing, route KDA state shards
  to matching decode TP ranks, and validate state-layout compatibility.
- Avoid advancing receiver-visible chunk IDs for empty, non-final KV
  transfers while preserving final state notifications.

## Accuracy Tests

Validated GLM-5.3-Flash on 4 × H200 with cp and BCG

```bash
sglang serve \
  --model-path /path/to/GLM-5.3-Flash \
  --served-model-name llm \
  --tp-size 4 \
  --ep-size 4 \
  --mem-fraction-static 0.75 \
  --dsa-prefill-backend tilelang \
  --dsa-decode-backend tilelang \
  --kv-cache-dtype bfloat16 \
  --moe-runner-backend deep_gemm \
  --enable-prefill-cp \
  --cp-strategy interleave \
  --attn-cp-size 4 \
  --chunked-prefill-size 8192 \
  --cuda-graph-backend-prefill breakable \
  --host 0.0.0.0 \
  --port 8009 \
  --reasoning-parser auto \
  --tool-call-parser auto \
```
