# [Fix] scheduler: Park chunked prefill continuation when decode headroom exhausts the budget

[Upstream PR](https://github.com/sgl-project/sglang/pull/44823) · state: open · merged: False

## Original PR description

## Motivation

With many decode requests running, their reserved decode headroom can drive `PrefillBudget.remaining_total` negative. `available_chunk_tokens` then falls back to the full `chunk_limit` so an in-progress chunked request can make progress, but it never checks that those tokens are free. The scheduler then crashes in `alloc_paged_token_slots_extend`:

```
RuntimeError: Prefill out of memory. Try to lower your batch size.
Try to allocate 16384 tokens.
Available full tokens: 3200 (full_available_size=3200 + full_evictable_size_=0)
```

## Modifications

- `PrefillBudget.available_chunk_tokens` returns `None` when the budget is exhausted, so the continuation parks until running decodes free their headroom. This matches `SWAPrefillBudget`.
- The fallback dates from #12333, when an unadmitted chunked request leaked memory. The scheduler now handles a parked chunk: it skips the stash when the chunk computed no new KV, which hybrid-SWA already relies on. A parked chunk cannot starve, since new requests are not admitted while the budget is negative, and decodes finish or are retracted.
- Added a regression test to `test_prefill_adder.py`. It fails on `main` (the chunk is admitted) and passes with this change.

    def test_shortest_prefill_continuation_waits_for_free_kv(self):
        """A prefill engine with no running batch can have every KV slot held by
        admitted requests. A capped continuation must then wait instead of
        taking a chunk the allocator cannot serve."""
        adder = self.create_shortest_prefill_adder(chunk_tokens=16384)
        policy = SchedulePolicy(
            policy="shortest-prefill-first",
            tree_cache=RadixCache.create_simulated(),
            enable_hierarchical_cache=True,
            enable_priority_scheduling=False,
            schedule_low_priority_values_first=False,
        )
        continuation = self.create_shared_req("continuation")
        continuation.full_untruncated_fill_ids = list(range(200_000))
        continuation.prefix_len = 64 * 1024
        short = self.create_shared_req("short-with-host-hit")
        short.origin_input_ids = list(range(150_000))
        short.full_untruncated_fill_ids = short.origin_input_ids
        short.num_matched_prefix_tokens = 148_000
        short.host_hit_length = 148_000
        short.best_match_node = short.last_node
        short.needs_host_load_back.return_value = True
        # No free and no evictable KV: the pool holds admitted requests only.
        self.mock_token_allocator.available_size.return_value = 0
        adder.chunked_req_limit = policy.shortest_prefill_chunk_limit(
            continuation, [short], adder.rem_chunk_tokens, adder.page_size
        )
        self.assertEqual(adder.chunked_req_limit, 14336)

        self.assertIs(adder.add_chunked_req(continuation), continuation)
        self.assertEqual(adder.can_run_list, [])
        self.assertIsNone(continuation.extend_end)
        self.assertEqual(

```python
import random, sys, time, concurrent.futures as cf
import requests

URL = sys.argv[1] if len(sys.argv) > 1 else "http://127.0.0.1:30000"
SEED = int(sys.argv[2]) if len(sys.argv) > 2 else 0
rng = random.Random(SEED)
ids = lambda n: [rng.randrange(100, 30000) for _ in range(n)]


def gen(input_ids, max_new):
    r = requests.post(f"{URL}/generate", timeout=600, json={
        "input_ids": input_ids,
        "sampling_params": {"max_new_tokens": max_new, "temperature": 0, "ignore_eos": True}})
    r.raise_for_status()


docs = [ids(6000) for _ in range(24)]  # 144K tokens: most end up only in the host tier
for d in docs:
    gen(d, 1)

for rnd in range(5):
    with cf.ThreadPoolExecutor(17) as ex:
        futs = [ex.submit(gen, ids(38000), 8)]  # long prompt, chunked
        time.sleep(0.02)
        # short requests: a host-cached 6K prefix + 128 new tokens each
        futs += [ex.submit(gen, docs[i] + ids(128), 64) for i in range(16)]
        errors = sum(f.exception() is not None for f in futs)
    alive = requests.get(f"{URL}/health", timeout=5).ok if errors == 0 else False
    print(f"round {rnd}: {17 - errors}/17 ok, server healthy: {alive}", flush=True)
    if not alive:
        sys.exit(1)
```
