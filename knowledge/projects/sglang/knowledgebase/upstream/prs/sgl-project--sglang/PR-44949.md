# [Feat] logging: add SGLANG_LOG_REQUEST_SKIP_FIELDS to elide large request fields

[Upstream PR](https://github.com/sgl-project/sglang/pull/44949) · state: open · merged: False

## Original PR description

﻿## Motivation

At `--log-requests-level 1` (the level deployments use when they must not log request/response content), `sampling_params.ebnf` is logged in full. When a client sends a grammar constraint (e.g. an agent harness with tool-calling), that field is a multi-kilobyte grammar string that bloats every request log line while carrying no request or response content. The existing `skip_names` are hardcoded per `--log-requests-level`, so there is no way to elide just `ebnf` without dropping the entire `sampling_params` object (level 0) and losing useful fields like `temperature` / `max_new_tokens`.

This is also distinct from `redact_watermark_secrets`, which masks secret *values* (watermark keys). `ebnf` is not sensitive, just very long and noisy.

## Modifications

- Add `SGLANG_LOG_REQUEST_SKIP_FIELDS` (`EnvTuple`, comma-separated) to `python/sglang/srt/environ.py`.
- In `python/sglang/srt/utils/request_logger.py`, `_compute_metadata` reads it and threads a `skip_value_fields` set through `_dataclass_to_string_truncated` / `_transform_data_for_logging` (and all `log_*_request` call sites). A field whose name is in this set has its value replaced with `"<skipped>"` (JSON: `"<skipped>"`), while `None` is preserved as `None` so "request did not carry the field" stays distinguishable from "request carried it". The match is recursive, so `ebnf` nested inside `sampling_params` is covered.
- This mirrors the `redact_watermark_secrets` pattern (keep the field name, replace the value), but is user-configurable and targeted at large-but-non-sensitive fields rather than secrets.

Usage:

```bash
export SGLANG_LOG_REQUEST_SKIP_FIELDS=ebnf,ebnf_full_assistant
```

Level 1 log line then becomes:

```
sampling_params={'temperature': 0.9, ..., 'ebnf': '<skipped>', 'ebnf_full_assistant': '<skipped>'}
```

When the env var is unset, behavior is unchanged (no field is elided).
