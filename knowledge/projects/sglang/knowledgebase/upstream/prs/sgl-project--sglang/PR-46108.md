# [Perf] diffusion: Run LTX-2 stage 2 on a premerged resident DiT

[Upstream PR](https://github.com/sgl-project/sglang/pull/46108) · state: closed · merged: True

## Original PR description

Branch: mick/ltx2-premerged-stage2 (on main 02b983603d), commit c2002dafe5

## Motivation

LTX-2.3's resident two-stage mode keeps a second DiT with the distilled LoRA merged in. Stage 2 then runs plain weights and needs no LoRA switch. LTX-2 got neither. Its device mode was never resolved, and resident mode did not premerge. So stage 2 ran the rank-384 distilled LoRA dynamically on 1370 layers, which adds about 19% to the stage-2 GEMM FLOPs plus two extra GEMMs per layer. It also paid the LoRA switch (~32 ms) on every request. TensorRT-LLM keeps merged stage-2 weights resident for the same reason.

## Modifications

- `server_args.py`: `_adjust_ltx2_two_stage_device_mode` resolves the mode for every two-stage pipeline that refines with a distilled LoRA (`_is_ltx2_distilled_lora_two_stage_pipeline`: LTX-2 and LTX-2.3, not LTX-2.5, which ships a distilled DiT). LTX-2 now takes the same auto default as LTX-2.3: resident on H200 and on GPUs with at least 130 GiB, original otherwise.
- `ltx_2_pipeline.py`: `should_use_premerged` requires resident mode, a distilled LoRA and no user stage-1 LoRA. It no longer requires LTX-2.3.
- CLI help and the LTX cookbook note now say that resident applies to LTX-2 as well.

The merged weights match the official two-stage pipelines, which fuse the LoRA. Compared with the dynamic delta, only the bf16 rounding of the sum moves.

## Tests

- `test_ltx2_premerged_stage2.py`: resident premerges with a distilled LoRA. Original mode, no distilled LoRA (LTX-2.5) and a user stage-1 LoRA each keep one DiT.
- `test_server_args.py`: an LTX-2 two-stage server resolves resident on a 140 GiB device and original on an 80 GiB one.

## Accuracy Tests

4xB300 (2 GPUs), LTX-2 two-stage 768x512x121: PSNR against the dynamic-LoRA stage 2 is 30.6 / 32.1 / 32.8 / 33.0 dB, audio SNR 11.5-15.2 dB. Only the last 3 steps change.

## Speed Tests and Profiling

Synced stage timing, median of 3 requests:

| | LoRA switch | stage 2 (3 steps) | client |
|---|---|---|---|
| before | 0.032 s | 0.439 s | 3.05 s |
| after | 0 | 0.341 s | 2.90 s |

Memory: the second 19B DiT adds about 38 GB per GPU. That is why the default only applies at 130 GiB and above.
