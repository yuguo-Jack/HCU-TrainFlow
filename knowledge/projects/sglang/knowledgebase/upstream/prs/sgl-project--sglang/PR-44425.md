# [Fix] parser: Handle whitespace in force-nonempty fallback

[Upstream PR](https://github.com/sgl-project/sglang/pull/44425) · state: open · merged: False

## Original PR description

Continues #37719. GitHub currently rejects reopening the original closed PR; this uses the same updated branch and retains the original discussion as context.

## Motivation

Fixes #37652.

With force_nonempty_content enabled, a whitespace-only tail after a reasoning block prevents reasoning from being promoted into content. Clients that display content receive a visually empty answer. Treat whitespace-only content as empty, but only swap it when reasoning text is actually available.

## Modifications

- Handle whitespace-only content in the shared fallback and preserve whitespace-only text when there is no reasoning to promote.
- Cover Qwen3, DeepSeek-R1, and GLM-4.5, real nonempty answers, the disabled option, and text without reasoning.

Synced with current `main` at `f2b73d4f9b4e64415b8d775b0f811c7801f1728b` on October 15, 2026.
