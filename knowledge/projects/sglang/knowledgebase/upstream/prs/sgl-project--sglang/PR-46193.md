# [Fix] diffusion/disaggregation: Preserve GLM pixels for the head

[Upstream PR](https://github.com/sgl-project/sglang/pull/46193) · state: closed · merged: True

## Original PR description

## Summary

Keep GLM-Image distributed denoiser outputs as pixels until they reach the head, matching the existing decoder path.

After #45987, image requests ask the output rank for encoded bytes even when `save_output=False`. The GLM denoiser retained `return_file_paths_only=True`, so finalization encoded the image and cleared `output`. Its tensor-only result transport then dropped the encoded bytes. The head returned HTTP 500 despite successful denoising and decoding.

This resets `return_file_paths_only` before execution, including sequential multi-output expansion. No new transport, configuration knob, model computation, or GT changes.

Observed in the [GLM distributed NPU CI case](https://github.com/sgl-project/sglang/actions/runs/40025732670/job/120662166969) on #45919; reproduced separately on main `f05ad5ec013`.

## Validation

- Regression test uses real worker output finalization and ZMQ tensor serialization; only model forward is stubbed. Covers single output, batched outputs, sequential outputs, and the existing decoder path.
- Before fix: all three GLM variants fail with missing output; decoder control passes.
- After fix: 58 image-response, GLM multi-output, disaggregation, and trace tests pass in an isolated Linux/H200 environment.
- Pre-commit passes. Full GLM model/NPU E2E validation remains for CI; the above is not a model-performance benchmark.
