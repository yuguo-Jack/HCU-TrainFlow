# [Fix] linker: Wait for every layer before retiring failed load batches

[Upstream PR](https://github.com/sgl-project/sglang/pull/45468) · state: open · merged: False

## Original PR description

## Motivation

`LayerWiseLoadCounter.finish()` can return `False` and remove its batch as soon as the first failed Future is observed, even when a later layer is unresolved. Its documented wait-for-every-layer barrier should also hold on the failure path.

Fixes https://github.com/sgl-project/sglang/issues/45467.

## Modifications

Resolve each Future before aggregating success, preserving failure reporting after the forward and retaining the batch until all layer completions are observed. Extend the existing waiting test with success/failed-first-layer cases; always resolve its pending Future in `finally` so a failed assertion cannot strand the worker.

This is completion-counter semantics hardening. The regression constructs a failed-first/pending-later Future state directly; it does not reproduce active GPU/RDMA writes or prove physical transfer termination. No engine, transport or page-allocation lifecycle is added.
