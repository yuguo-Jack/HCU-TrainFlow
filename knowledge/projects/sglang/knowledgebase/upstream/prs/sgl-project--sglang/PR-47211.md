## Motivation

Reduce duplicated NPU quantization logic and clarify shared module responsibilities.

## Modifications

- Extract shared dtype, Linear, and MoE helpers.
- Reuse MXFP4 expert weight processing and DSpark weight-name mapping.
- Use W13 for fusion decisions and W2 for standalone activation selection.
- Adapt existing tests without adding test cases.

## Accuracy Tests
