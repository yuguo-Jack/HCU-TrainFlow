# [Perf] [NVIDIA] deepseek_v4: Route 4- and 8-group wo_a prefill and single-token decode to the strided bmm

[Upstream PR](https://github.com/sgl-project/sglang/pull/46023) · state: open · merged: False

## Original PR description

[by Claude Code]

## Motivation

In DeepSeek-V4.1 attention, `wo_a` is a grouped GEMM: `o [T, G, 4096] x wo_a [G, 1024, 4096] -> [T, G, 1024]`, for T tokens and the G output groups on this rank. `wo_b` reads the result flattened to `[T, G * 1024]`, so it needs it token-major. `_apply_wo_a_bf16_matmul` has a fast path that runs one `torch.bmm` into a strided output, which writes token-major directly, but for prefill and single-token decode it accepted only G = 2, the shape under 4-way attention tensor parallelism (TP). The 8 groups are split over the attention TP ranks, so a rank holds 4 groups at attention TP 2 (for example TP 2 without DP attention) and all 8 at attention TP 1: DP attention with one DP rank per GPU, for example DEP4 (4-way DP attention plus 4-way expert parallelism). There, prefill calls fell back to `torch.einsum`, whose result is group-major in memory, so `wo_b`'s `flatten(1)` copied the whole output in every layer that takes this path. This PR lets G = 4 and G = 8 take the strided `bmm` for prefill with 1-65536 rows per rank (Blackwell) and for single-token decode (Blackwell and SM90). On B200 and B300 the prefill GEMM is the same cuBLAS kernel the einsum runs, and the output is bitwise identical at every tested shape; only the copy goes away. Target-verify calls already take this `bmm` at any group count since #46176.

- **Accuracy:** bitwise equal to the einsum at every tested shape, G = 4 and 8 (B200 and B300, eager and under CUDA-graph replay; H100 for single-token decode). DeepSeek-V4.1-Flash DEP4 (G = 8) on 4x B200 (trtllm attention, DSpark), main vs this PR on one node: RULER2 16K 95.56 vs 95.17%, GSM8K 97.19 vs 96.97% (run before 8-group prefill below 4096 rows took the `bmm`, which is bitwise equal there too). No end-to-end eval ran at G = 4.
- **Performance, kernel, G = 8 (B200):** the einsum path's copy takes 98 / 208 / 355 us per call at 4096 / 8192 / 16384 prefill rows, and this PR removes it. The GEMM is the same kernel in both paths, with equal minimum durations. Earlier 8192-row wall-time runs: B300 576 -> 444 us, VR200 (Rubin) 409 -> 207 us per call.
- **Performance, kernel, G = 8 below 4096 rows (B200 / B300):** one call plus `wo_b`'s `flatten(1)`, under CUDA-graph replay, is 1.36x / 1.33x faster at 16 rows, 1.48x / 1.44x at 2048 and 1.54x / 1.66x at 4095 (B200 157.0 -> 106.1 us at 2048 rows; median of 3 runs), and unchanged at 1 row, where the einsum's output is already token-major.
- **Performance, kernel, G = 4 below 4096 rows (B200 / B300):** the same measurement is 1.51x / 1.46x faster at 16 rows, 1.49x / 1.45x at 2048 and 1.50x / 1.46x at 4095 (B200 79.9 -> 53.6 us at 2048 rows), and unchanged at 1 row.
- **Performance, kernel, G = 4 (B200 / B300):** one call, einsum + copy -> strided `bmm`, is 1.49x / 1.46x faster at 4096 prefill rows, 1.59x / 1.68x at 8192, 1.83x / 1.40x at 16384 and 1.28x / 1.24x at 65536 (B200 152.9 -> 102.9 us at 4096 rows, 2192 -> 1710 us at 65536; median of 3 runs). Single-token decode time does not change (1.00x on B200, B300 and H100).
- **Performance, in-server (B200, DEP4):** over three ~16K-token prefills, the copy after the prefill `wo_a` GEMM runs in 60 of 60 calls on main and 0 of 60 with this PR. GPU kernel time on the rank that ran the prefills drops by 16.2 ms (641.5 -> 625.3 ms, -2.5%), 5.4 ms per prefill.
- **Performance, in-server (B300, DEP2, G = 8):** the prefill forward on one rank takes 6.3 ms (2.4%) less at 16000 new tokens after an 80K-token cached prefix (2.0-2.4% across 0, 80K and 210K cached tokens), and 1.25 ms less at 2048 new tokens (77.0 -> 75.7 ms).
- **End to end (estimate, not measured):** about 2-2.5% of the GPU time of a 16K-token prefill on a G = 8 rank (DEP2, DEP4) and about 1.6% of a 2048-token prefill chunk (B300 DEP2), from the in-server times above. At G = 4, about 4 ms per 16K-token prefill per rank: the 20 prefill `wo_a` calls per prefill counted in the DEP4 profile x the 198-219 us copy per 16384-row call (B200, B300), and about 0.5 ms per 2048-token chunk (20 calls x the 24-26 us saved at 2048 rows, B200 and B300); not profiled in a server at attention TP 2. TTFT was not A/B-tested. Target-verify is unchanged; single-token decode only changes which call runs the GEMM (bitwise-equal output; at G = 4 timed equal).

Where this applies: the target model's attention reaches this function only on the `trtllm` (or `flashmla`) attention backend. Among the DeepSeek-V4.1 cookbook's Agentic Long-Context recipes, that is the B200 and GB200 DEP4 and the B300 DEP2/DEP4 aggregated commands (G = 8), and the B300 TP2 aggregated command at concurrency 48 (G = 4). Under MegaAttention (`flashmla_mega`, the `auto` default on Blackwell, and what the GB300 recipes use), the target model's `wo_a` is DeepGEMM `fp8_einsum` and does not reach this function, and the DSpark draft model's `wo_a` runs as target verify, which #46176 already routes; so there this PR changes nothing.

## Modifications

**+15 / −7 runtime code (1 file), +74 / −1 tests (1 file).** No kernel changes, no new flag.

All runtime changes are in `_apply_wo_a_bf16_matmul` (`python/sglang/srt/models/deepseek_v4.py`):
- The fast path's shape check also accepts G = 4 and G = 8 (`o [T, G, 4096]`, `wo_a [G, 1024, 4096]`), on CUDA only. HIP keeps sending G = 4 and 8 to its own GEMMs.
- The stride check `o.stride(0) >= 8192` becomes `>= G * 4096`, the same value for G = 2.
- The 1-row GEMV and the 2-8-row Triton kernels stay G = 2 only, so G = 4 and 8 always take the strided `torch.bmm`.
- G = 4 and G = 8 prefill take the fast path at 1-65536 rows (Blackwell), not only from 4096 rows: short prompts and the last chunk of a chunked prefill pay the same output copy (at G = 8, 0.84 ms of a 77 ms 2048-token prefill forward on B300 DEP2). A per-call microbenchmark found the strided `bmm` no slower at each measured row count (1, 16, 128, 512, 1024, 2048 and 4095), at G = 4 and at G = 8, on B200 and B300, against a threshold fixed before timing (at most 1.02x the old path). G = 2 keeps 4096-65536 rows (not measured below 4096), and HIP prefill is unchanged.
- The other modes and row counts are unchanged: single-token decode (Blackwell and SM90) and target-verify with 1-384 rows (Blackwell; on main, #46176's branch already sends every Blackwell target-verify call to the same `bmm`).
- Single-token decode at G = 4 and 8 removes no copy (with T = 1 the einsum output is already token-major); it only changes which call runs the GEMM, with bitwise-equal output (at G = 4 also equal time on B200, B300 and H100; G = 8 not timed). It serves non-speculative decode at attention TP 1 or 2; with DSpark the target runs verify, not decode. A 1-row prefill call at G = 4 or 8 likewise removes no copy: equal time under graph replay, 15-16% less eagerly (host work).
- Scope: G = 8 measured on SM100 (B200), SM103 (B300) and SM107 (VR200), below 4096 prefill rows on SM100 and SM103 only; G = 4 on SM100 and SM103 (prefill at 1-65536 rows), and on SM90 (H100) for single-token decode. `is_blackwell` covers compute-capability majors 10, 11 and 12, so SM120 / SM121 also take the 4- and 8-group paths, as they already take the 2-group one; not measured.
- Memory: one fewer transient `[T, G, 1024]` bf16 buffer per call (the einsum's output before the copy). No persistent buffers change.

Tests, in `test/registered/kernels/ops/gemm/test_dsv4_wo_a.py` (CI `base-b-kernel-unit`, 4-gpu-b200; `est_time` 20 -> 40 s). The first two check token-major output and `torch.equal` against `torch.einsum`:
- `test_wo_a_strided_bmm_matches_einsum[2|4|8]`: prefill 4096, 8192, 16384 and 65536 rows (the gate's bounds); target-verify 9, 64, 100, 128 and 384 rows; at G = 4 and 8 also target-verify 1-8 rows, single-token decode and prefill 1, 128, 2048 and 4095 rows; each on a contiguous input and on a head slice of a padded 128-head buffer. Against main's `deepseek_v4.py` the G = 8 case fails on the layout assertion at the first prefill shape, and against a gate without G = 4 the G = 4 case fails the same way. Against a gate with the 4096-row floor at G = 8 (or at G = 4), each new 8-group (or 4-group) prefill case at 128, 2048 and 4095 rows fails the layout assertion on its own; the 1-row case cannot, since the einsum's 1-row output is already token-major.
- `test_wo_a_strided_bmm_graph_replay_matches_einsum[2|4|8]`: the same shapes captured in a CUDA graph and replayed three times on refreshed inputs and weights. Catches a host sync or a stale layout under capture (a mutant that reads a value back to the host in the `bmm` helper fails only these cases).
- `test_wo_a_strided_bmm_gate_rejects_unmeasured_prefill`: 4095 prefill rows at G = 2 keep the einsum's group-major output. Gate mutants that drop the floor at every G, or move the G = 2 floor to 4095 rows, fail it; one that keeps the floor at G = 4 instead of G = 2 fails it and the [4] eager and graph-replay cases; one that drops the floor at G = 4 only fails the [8] cases; one that drops 65536 rows (`< 65536`) fails the eager and graph-replay cases at every G.
- Mutants of the G = 4/8 routing, each run against the whole file: sending 4- and 8-group decode to the 2-group GEMV, or 2-8-row 4- and 8-group calls to the 2-group Triton kernel, fails the [4] and [8] cases; writing the `bmm` result group-major into the token-major buffer fails every [2|4|8] case. Not caught: a 4- and 8-group floor of 2 rows instead of 1, since at 1 row the einsum and the `bmm` give the same values in the same layout.

The file skips non-Blackwell GPUs (its MXFP8 reference is Blackwell-only), so SM90's decode route has no CI test; it was checked separately on H100 (below).

Related: #45193 makes the prefill `wo_a` write token-major on AMD gfx950; this PR leaves the HIP routes as they are. #45190 inserts a line between the two `if` lines this PR edits, so whichever PR lands second needs a trivial rebase.

## Accuracy Tests

The output values do not change; only the layout does. `torch.einsum` already runs this contraction as a `bmm` on the same input views, and this PR gives that `bmm` a strided output (`ldc = G * 1024` instead of 1024). Bitwise equality also needs cuBLAS to pick a kernel with the same reduction order for both leading dimensions. On B200 (torch 2.14.1+cu130, cuBLAS 13.1.1.3) the profiler shows the same `nvjet_sm100_tst_*` kernel in both paths at all 13 benchmarked row counts, and on B200 and B300 at the 8 benchmarked prefill row counts from 1 to 4096, at G = 4 and at G = 8. The tests check equality directly.

## Speed Tests and Profiling

Why this point: the change touches 4- and 8-group prefill calls at any row count, so it matters for prefill at attention TP 1 or 2 (DEP2, DEP4, TP2), most for long prefills, independent of concurrency. Kernel-level measurements isolate it; the in-server profiles check that the copy disappears in the real model and what that is worth per prefill forward.

**Microbenchmark, G = 8.** One `wo_a` call at G = 8 (64 heads): the old path (einsum, then the copy `flatten(1)` makes) against the strided `bmm`, in one process on the same inputs. Each arm walks 8 layers of distinct weights (512 MiB, larger than L2). Kernel durations come from `torch.profiler` over CUDA-graph replays: 5 rounds with the arms interleaved, 4 replays of 16 calls per arm per round.

| rows | GEMM, einsum | GEMM, strided `bmm` | copy (old path only) |
|---|---|---|---|
| 4096 | 187.8 / 179.1 | 188.3 / 179.1 | 98.4 / 88.7 |
| 8192 | 387.8 / 350.4 | 364.4 / 350.5 | 208.3 / 193.1 |
| 16384 | 721.6 / 692.3 | 733.3 / 691.9 | 355.2 / 328.8 |

- Both paths launch the same GEMM kernel (`nvjet_sm100_tst_128x256_64x6_2x1_2cta_v_bz_TNT`) and the minima are equal. - Earlier runs at 8192 rows measured wall time only (CUDA-graph replay, median us per call, old -> new): B300 576 -> 444, VR200 409 -> 207. In those runs the strided GEMM alone measured slower than the einsum's GEMM alone (B300 444 vs 385 us, VR200 207 vs 187 us); they were not re-measured with kernel durations.

```python
"""DeepSeek-V4.1 wo_a with 8 groups (DP attention, attention TP 1): the einsum path (einsum, then the
layout copy wo_b's flatten(1) makes) vs the strided-output bmm in _apply_wo_a_bf16_matmul.

Row counts: target-verify rows 6-384 (1-64 requests per rank with DSpark's 6-row window) and prefill
rows 4096-16384. Per-kernel GPU durations come from torch.profiler (GEMM and copy separately), so the
GEMM-vs-GEMM comparison does not rest on graph wall time.

Both arms run in one process on the same inputs. Outputs are compared bitwise (torch.equal), eagerly
and under CUDA-graph replay with refreshed inputs, before any timing counts; the run fails if they
differ or if the patched function did not take the strided path (its output must be token-major
contiguous). Timing replays CUDA graphs, interleaving the arms round by round. Each graph walks LAYERS
distinct weights (8 x 64 MiB of bf16, larger than L2) and distinct inputs, so wo_a streams from HBM as
in the model.

Usage: python3 bench_woa_v2.py [--rows 6 12 ... 16384] [--rounds 20] [--replays 10] [--prof-rounds 5]
Requires PYTHONPATH pointing at the sglang tree under test.
"""
import argparse
import collections
import statistics
import sys

import torch
from torch.autograd import DeviceType
from torch.profiler import ProfilerActivity, profile

from sglang.srt.models.deepseek_v4 import _apply_wo_a_bf16_matmul

G, R, D = 8, 1024, 4096
HEADS, HEAD_DIM = 64, 512  # DEP4: all 64 heads are local; 8 heads x 512 = D per group
LAYERS = 8  # 8 x 64 MiB of bf16 weight, larger than L2
REPS = 2  # passes over LAYERS per graph
CALLS = REPS * LAYERS  # wo_a calls per graph replay
ROWS = [6, 12, 24, 48, 64, 96, 128, 192, 256, 384, 4096, 8192, 16384]
PERF_TOL = 1.01  # strided median must be <= 1.01 x einsum+copy median


def mode_flags(rows):
    # the CUDA gate admits target-verify rows 1..384 and prefill rows 4096..65536
    flags = dict(is_decode=False, is_target_verify=False, is_prefill=False)
    flags["is_target_verify" if rows <= 384 else "is_prefill"] = True
    return flags


def arms(xs, ws, flags):
    return {
        "einsum+copy": lambda: [
            torch.einsum("tgd,grd->tgr", x, w).flatten(1) for x, w in zip(xs, ws)
        ],
        "einsum_only": lambda: [
            torch.einsum("tgd,grd->tgr", x, w) for x, w in zip(xs, ws)
        ],
        "strided_bmm": lambda: [
            _apply_wo_a_bf16_matmul(x, w, fast_path=True, **flags).flatten(1)
            for x, w in zip(xs, ws)
        ],
    }


def capture(fn):
    side = torch.cuda.Stream()
    side.wait_stream(torch.cuda.current_stream())
    with torch.cuda.stream(side):
        for _ in range(3):
            fn()
    torch.cuda.current_stream().wait_stream(side)
    graph = torch.cuda.CUDAGraph()
    with torch.cuda.graph(graph):
        for _ in range(REPS):
            fn()
    return graph


def check(xs, ws, flags):
    """Eager bitwise and layout check; returns True only if every layer matches."""
    ok = True
    for i, (x, w) in enumerate(zip(xs, ws)):
        ref = torch.einsum("tgd,grd->tgr", x, w)
        out = _apply_wo_a_bf16_matmul(x, w, fast_path=True, **flags)
        flat = out.flatten(1)
        if not out.is_contiguous() or flat.data_ptr() != out.data_ptr():
            print(f"  layer {i}: output not token-major; the strided path did not run")
            ok = False
        if ref.is_contiguous():
            print(f"  layer {i}: einsum output unexpectedly token-major")
        if not torch.equal(out, ref):
            diff = (out.float() - ref.float()).abs()
            print(
                f"  layer {i}: MISMATCH max|diff| {diff.max().item():.3e}, "
                f"{(diff != 0).sum().item()} of {diff.numel()} elements differ"
            )
            ok = False
    return ok


def check_graph(x, w, flags, replays=3):
    """One captured strided call, replayed on refreshed inputs, must equal the einsum bitwise."""
    xs, ws = x.clone(), w.clone()
    _apply_wo_a_bf16_matmul(xs, ws, fast_path=True, **flags)
    graph = torch.cuda.CUDAGraph()
    with torch.cuda.graph(graph):
        out = _apply_wo_a_bf16_matmul(xs, ws, fast_path=True, **flags)
    ok = True
    for i in range(replays):
        xs.normal_()
        ws.normal_(std=0.02)
        graph.replay()
        if not out.is_contiguous():
            print(f"  graph replay {i}: output not token-major")
            ok = False
        if not torch.equal(out, torch.einsum("tgd,grd->tgr", xs, ws)):
            print(f"  graph replay {i}: MISMATCH vs einsum")
            ok = False
    del graph
    return ok


def kernel_kind(name):
    low = name.lower()
    if "copy" in low or "elementwise" in low:
        return "copy"
    if "memset" in low or "memcpy" in low:
        return "other"
    return "gemm"


def profile_kernels(run, sessions):
    """GPU kernel durations (us) over `sessions` profiled calls of run(); returns name -> [us]."""
    durations = collections.defaultdict(list)
    run()
    torch.cuda.synchronize()
    with profile(activities=[ProfilerActivity.CUDA]) as prof:
        for _ in range(sessions):
            run()
        torch.cuda.synchronize()
    for evt in prof.events():
        if evt.device_type == DeviceType.CUDA:
            durations[evt.name].append(evt.time_range.elapsed_us())
    return durations


def kernel_report(graphs, fns, prof_rounds, prof_replays):
    """Per arm: per-instance GEMM and copy kernel durations and instances per wo_a call."""
    per = {name: collections.defaultdict(list) for name in graphs}
    source = "graph replay"
    for _ in range(prof_rounds):
        for name, graph in graphs.items():
            d = profile_kernels(graph.replay, prof_replays)
            calls = prof_replays * CALLS
            if not d:
                # the profiler saw no kernels inside graph replays; time eager calls instead
                source = "eager (no kernels seen in graph replay)"
                d = profile_kernels(fns[name], prof_replays * REPS)
            for kname, us in d.items():
                per[name][kname].extend(us)
            per[name]["__calls__"].append(calls)
    out = {}
    for name, d in per.items():
        calls = sum(d.pop("__calls__"))
        kinds = collections.defaultdict(list)
        names = {}
        for kname, us in d.items():
            kinds[kernel_kind(kname)].extend(us)
            names[kname] = (len(us) / calls, statistics.median(us))
        out[name] = (kinds, names)
    return out, source


def fmt_stats(us):
    if not us:
        return "none"
    us = sorted(us)
    p90 = us[min(len(us) - 1, int(0.9 * len(us)))]
    return (
        f"median {statistics.median(us):8.2f} min {us[0]:8.2f} p90 {p90:8.2f} "
        f"(n={len(us)})"
    )


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--rows", type=int, nargs="+", default=ROWS)
    p.add_argument("--rounds", type=int, default=20)
    p.add_argument("--replays", type=int, default=10)
    p.add_argument("--prof-rounds", type=int, default=5)
    p.add_argument("--prof-replays", type=int, default=4)
    args = p.parse_args()

    torch.manual_seed(0)
    dev = torch.device("cuda")
    props = torch.cuda.get_device_properties(dev)
    print(
        f"gpu {props.name} sm{props.major}{props.minor}, torch {torch.__version__}, "
        f"cuda {torch.version.cuda}, blas {torch.backends.cuda.preferred_blas_library()}, "
        f"rounds {args.rounds} x {args.replays} replays, {CALLS} calls per replay"
    )
    ws = [
        torch.randn(G, R, D, device=dev, dtype=torch.bfloat16) * 0.02
        for _ in range(LAYERS)
    ]
    all_ok = True
    perf_ok = True
    summary = []
    for rows in args.rows:
        flags = mode_flags(rows)
        mode = [k for k, v in flags.items() if v][0]
        xs = [
            torch.randn(rows, HEADS, HEAD_DIM, device=dev, dtype=torch.bfloat16).view(
                rows, G, D
            )
            for _ in range(LAYERS)
        ]
        ok = check(xs, ws, flags)
        gok = check_graph(xs[0], ws[0], flags)
        all_ok &= ok and gok
        print(f"rows {rows} {mode}: exact={ok} graph_exact={gok}")
        if not (ok and gok):
            summary.append(f"rows={rows} exact={ok} graph_exact={gok} (not timed)")
            continue
        fns = arms(xs, ws, flags)
        graphs = {name: capture(fn) for name, fn in fns.items()}
        start, end = torch.cuda.Event(True), torch.cuda.Event(True)
        times = {name: [] for name in graphs}
        for _ in range(args.rounds):
            for name, graph in graphs.items():
                graph.replay()  # warm
                for _ in range(args.replays):
                    start.record()
                    graph.replay()
                    end.record()
                    end.synchronize()
                    times[name].append(start.elapsed_time(end) * 1e3 / CALLS)
        med = {name: statistics.median(t) for name, t in times.items()}
        for name in graphs:
            t = sorted(times[name])
            print(
                f"  wall {name:12s} median {med[name]:8.2f} us/call "
                f"(min {t[0]:.2f}, p10 {t[len(t) // 10]:.2f}, "
                f"p90 {t[(9 * len(t)) // 10]:.2f}, max {t[-1]:.2f})"
            )
        report, source = kernel_report(graphs, fns, args.prof_rounds, args.prof_replays)
        print(f"  kernels from {source}:")
        for name, (kinds, names) in report.items():
            for kind in ("gemm", "copy", "other"):
                if kinds.get(kind):
                    print(f"    {name:12s} {kind:5s} us/instance {fmt_stats(kinds[kind])}")
            for kname, (per_call, kmed) in sorted(names.items()):
                print(f"      {per_call:5.2f}/call median {kmed:8.2f} us  {kname}")
        saved = med["einsum+copy"] - med["strided_bmm"]
        within = med["strided_bmm"] <= PERF_TOL * med["einsum+copy"]
        perf_ok &= within
        gemm_e = statistics.median(report["einsum_only"][0]["gemm"])
        gemm_s = statistics.median(report["strided_bmm"][0]["gemm"])
        copy_c = report["einsum+copy"][0].get("copy") or [0.0]
        line = (
            f"rows={rows} mode={mode} einsum+copy={med['einsum+copy']:.2f}us "
            f"strided_bmm={med['strided_bmm']:.2f}us saved={saved:.2f}us/call "
            f"({100 * saved / med['einsum+copy']:.1f}%) einsum_only={med['einsum_only']:.2f}us "
            f"gemm_kernel_einsum={gemm_e:.2f}us gemm_kernel_strided={gemm_s:.2f}us "
            f"({100 * (gemm_s - gemm_e) / gemm_e:+.1f}%) "
            f"copy_kernel={statistics.median(copy_c):.2f}us "
            f"exact=True graph_exact=True perf_within_1pct={within}"
        )
        summary.append(line)
        del graphs, fns, xs
        torch.cuda.empty_cache()
    for line in summary:
        print(f"SUMMARY lever=dsv4-dep4-woa-strided gpu={props.name.replace(' ', '_')} G=8 {line}")
    print(f"SUMMARY lever=dsv4-dep4-woa-strided all_exact={all_ok} perf_all_within_1pct={perf_ok}")
    return 0 if all_ok else 1


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Per-call time of DeepSeek-V4.1's wo_a at 8 groups per rank (64 heads x 512) in prefill, the previous commit's
`_apply_wo_a_bf16_matmul` (OLD: einsum, group-major output) vs this branch's (NEW: strided bmm, token-major output),
each followed by the `flatten(1)` that wo_b applies (a copy for OLD when T > 1).

Both arms call the full function (gate included). NEW is sglang.srt.models.deepseek_v4 from PYTHONPATH; OLD is the
previous commit's deepseek_v4.py (git show <prev>:python/sglang/srt/models/deepseek_v4.py > old.py) loaded under
another module name.

Modes: graph (each arm captured as one CUDA graph of 16 calls over 8 layers of distinct weights, 512 MiB) and eager
(the same 16 calls run eagerly). Per round and arm: 1 warm-up, then REPLAYS timed samples bracketed by CUDA events;
arms interleaved round by round; per-call time = sample / 16; metric = median over ROUNDS x REPLAYS samples.
Before a row count is timed, NEW must be token-major and torch.equal to the einsum on every layer (eager) and under
graph replay with refreshed inputs.

--aa: both arms run OLD (noise floor). --old-einsum: OLD is torch.einsum + flatten(1) directly.

Usage: PYTHONPATH=<this tree>/python python3 bench_woa_g8_floor.py --old-file old.py [--rows ...]
       [--modes graph eager] [--rounds 20] [--replays 10] [--aa] [--old-einsum] [--tag NAME]
"""

import argparse
import collections
import importlib.util
import statistics
import sys
import time

import torch
from torch.autograd import DeviceType
from torch.profiler import ProfilerActivity, profile

from sglang.srt.models import deepseek_v4 as dsv4_new

G, R, D, HEAD_DIM = 8, 1024, 4096, 512
HEADS = 8 * G
LAYERS = 8
REPS = 2
CALLS = REPS * LAYERS
FLAGS = dict(is_decode=False, is_target_verify=False, is_prefill=True)


def load_old(path):
    spec = importlib.util.spec_from_file_location("dsv4_old", path)
    mod = importlib.util.module_from_spec(spec)
    sys.modules[spec.name] = mod
    spec.loader.exec_module(mod)
    return mod


def check(xs, ws):
    ok = True
    for i, (x, w) in enumerate(zip(xs, ws)):
        out = dsv4_new._apply_wo_a_bf16_matmul(x, w, fast_path=True, **FLAGS)
        ref = torch.einsum("tgd,grd->tgr", x, w)
        if not out.is_contiguous():
            print(f"  layer {i}: NEW output not token-major")
            ok = False
        if not torch.equal(out, ref):
            print(f"  layer {i}: NEW not equal to einsum")
            ok = False
    return ok


def check_graph(x, w, replays=3):
    xs, ws = x.clone(), w.clone()
    dsv4_new._apply_wo_a_bf16_matmul(xs, ws, fast_path=True, **FLAGS)
    graph = torch.cuda.CUDAGraph()
    with torch.cuda.graph(graph):
        out = dsv4_new._apply_wo_a_bf16_matmul(xs, ws, fast_path=True, **FLAGS)
    ok = True
    for i in range(replays):
        xs.normal_()
        ws.normal_(std=0.02)
        graph.replay()
        if not out.is_contiguous() or not torch.equal(out, torch.einsum("tgd,grd->tgr", xs, ws)):
            print(f"  graph replay {i}: NEW not token-major or not equal to einsum")
            ok = False
    del graph
    return ok


def capture(fn):
    side = torch.cuda.Stream()
    side.wait_stream(torch.cuda.current_stream())
    with torch.cuda.stream(side):
        for _ in range(3):
            fn()
    torch.cuda.current_stream().wait_stream(side)
    graph = torch.cuda.CUDAGraph()
    with torch.cuda.graph(graph):
        fn()
    return graph


def kernel_kind(name):
    low = name.lower()
    if "copy" in low or "elementwise" in low:
        return "copy"
    if "memset" in low or "memcpy" in low:
        return "other"
    return "gemm"


def kernel_report(runners, prof_rounds=3, prof_replays=4):
    per = {name: collections.defaultdict(list) for name in runners}
    for _ in range(prof_rounds):
        for name, run in runners.items():
            run()
            torch.cuda.synchronize()
            with profile(activities=[ProfilerActivity.CUDA]) as prof:
                for _ in range(prof_replays):
                    run()
                torch.cuda.synchronize()
            for evt in prof.events():
                if evt.device_type == DeviceType.CUDA:
                    per[name][evt.name].append(evt.time_range.elapsed_us())
    calls = prof_rounds * prof_replays * CALLS
    out = {}
    for name, d in per.items():
        kinds = collections.defaultdict(list)
        names = {}
        for kname, us in d.items():
            kinds[kernel_kind(kname)].extend(us)
            names[kname] = (len(us) / calls, statistics.median(us))
        out[name] = (kinds, names)
    return out


def time_arms(runners, rounds, replays):
    start, end = torch.cuda.Event(True), torch.cuda.Event(True)
    times = {name: [] for name in runners}
    cpu = {name: [] for name in runners}
    for _ in range(rounds):
        for name, run in runners.items():
            run()
            torch.cuda.synchronize()
            for _ in range(replays):
                start.record()
                t0 = time.perf_counter()
                run()
                t1 = time.perf_counter()
                end.record()
                end.synchronize()
                times[name].append(start.elapsed_time(end) * 1e3 / CALLS)
                cpu[name].append((t1 - t0) * 1e6 / CALLS)
    return times, cpu


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--old-file", required=True)
    p.add_argument("--rows", type=int, nargs="+", default=[1, 16, 128, 512, 1024, 2048, 4095, 4096])
    p.add_argument("--modes", nargs="+", default=["graph", "eager"])
    p.add_argument("--rounds", type=int, default=20)
    p.add_argument("--replays", type=int, default=10)
    p.add_argument("--aa", action="store_true")
    p.add_argument("--old-einsum", action="store_true")
    p.add_argument("--tag", default="run")
    args = p.parse_args()
    dsv4_old = load_old(args.old_file)

    torch.manual_seed(0)
    dev = torch.device("cuda")
    props = torch.cuda.get_device_properties(dev)
    gpu = props.name.replace(" ", "_")
    print(
        f"gpu {props.name} sm{props.major}{props.minor} torch {torch.__version__} cuda {torch.version.cuda} "
        f"G={G} heads/rank={HEADS} rounds={args.rounds} replays={args.replays} calls/sample={CALLS} "
        f"aa={args.aa} old_einsum={args.old_einsum} new={dsv4_new.__file__} old={dsv4_old.__file__}"
    )
    if args.old_einsum:
        old = lambda x, w: torch.einsum("tgd,grd->tgr", x, w).flatten(1)
    else:
        old = lambda x, w: dsv4_old._apply_wo_a_bf16_matmul(x, w, fast_path=True, **FLAGS).flatten(1)
    new = lambda x, w: dsv4_new._apply_wo_a_bf16_matmul(x, w, fast_path=True, **FLAGS).flatten(1)
    if args.aa:
        new = old

    ws = [torch.randn(G, R, D, device=dev, dtype=torch.bfloat16) * 0.02 for _ in range(LAYERS)]
    summary = []
    all_ok = True
    for rows in args.rows:
        xs = [
            torch.randn(rows, HEADS, HEAD_DIM, device=dev, dtype=torch.bfloat16).view(rows, G, D)
            for _ in range(LAYERS)
        ]
        ok = check(xs, ws) and check_graph(xs[0], ws[0])
        all_ok &= ok
        if not ok:
            summary.append(f"rows={rows} mode=all exact=False (not timed)")
            continue
        fns = {
            "old": lambda: [old(x, w) for _ in range(REPS) for x, w in zip(xs, ws)],
            "new": lambda: [new(x, w) for _ in range(REPS) for x, w in zip(xs, ws)],
        }
        for mode in args.modes:
            if mode == "graph":
                graphs = {name: capture(fn) for name, fn in fns.items()}
                runners = {name: g.replay for name, g in graphs.items()}
            else:
                graphs = None
                runners = fns
            times, cpu = time_arms(runners, args.rounds, args.replays)
            med = {name: statistics.median(t) for name, t in times.items()}
            cmed = {name: statistics.median(t) for name, t in cpu.items()}
            for name, t in times.items():
                t = sorted(t)
                print(
                    f"  rows {rows} {mode} {name}: median {med[name]:9.2f} us/call (n={len(t)}, min {t[0]:.2f}, "
                    f"p10 {t[len(t) // 10]:.2f}, p90 {t[(9 * len(t)) // 10]:.2f}, max {t[-1]:.2f}) "
                    f"cpu-enqueue median {cmed[name]:.2f} us/call"
                )
            kinfo = ""
            if mode == "graph":
                report = kernel_report(runners)
                for name, (kinds, names) in report.items():
                    for kind in ("gemm", "copy", "other"):
                        if kinds.get(kind):
                            k = sorted(kinds[kind])
                            print(
                                f"    kernels {name} {kind}: median {statistics.median(k):9.2f} us/instance "
                                f"min {k[0]:.2f} (n={len(k)})"
                            )
                    for kname, (per_call, kmed) in sorted(names.items()):
                        print(f"      {name} {per_call:5.2f}/call median {kmed:9.2f} us  {kname}")

                def kmed(arm, kind):
                    us = report[arm][0].get(kind)
                    return statistics.median(us) if us else float("nan")

                def kcount(arm, kind):
                    return len(report[arm][0].get(kind, [])) / (3 * 4 * CALLS)

                kinfo = (
                    f" gemm_kernel_old={kmed('old', 'gemm'):.2f}us gemm_kernel_new={kmed('new', 'gemm'):.2f}us "
                    f"copy_per_call_old={kcount('old', 'copy'):.2f} copy_kernel_old={kmed('old', 'copy'):.2f}us "
                    f"copy_per_call_new={kcount('new', 'copy'):.2f}"
                )
            ratio = med["new"] / med["old"]
            summary.append(
                f"rows={rows} mode={mode} old={med['old']:.2f}us new={med['new']:.2f}us "
                f"ratio_new_over_old={ratio:.4f} cpu_old={cmed['old']:.2f}us cpu_new={cmed['new']:.2f}us"
                f"{kinfo} exact=True"
            )
            del graphs, runners
            torch.cuda.synchronize()
        del fns, xs
        torch.cuda.empty_cache()
    for line in summary:
        print(f"SUMMARY tag={args.tag} gpu={gpu} G={G} aa={args.aa} old_einsum={args.old_einsum} {line}")
    print(f"SUMMARY tag={args.tag} gpu={gpu} G={G} all_exact={all_ok}")
    return 0 if all_ok else 1


if __name__ == "__main__":
    sys.exit(main())
```
