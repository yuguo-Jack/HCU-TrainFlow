# [Fix] diffusion/moss: Preserve full latents for sequence parallelism

[Upstream PR](https://github.com/sgl-project/sglang/pull/46664) · state: closed · merged: True

## Original PR description

## Motivation

MOSS-Image sequence parallelism currently shards image latents twice. The pipeline slices the latent height before the DiT builds full-image RoPE and independently shards the joint image/text tokens. On the tested 2048×2048 checkpoint, main SP2/SP8 produce repeated horizontal strips.

Keep the original latent at the pipeline boundary and let the DiT own sequence sharding/gathering. This restores correct multi-GPU scaling with four production lines and an extension to the existing distributed regression. No new flag, tensor copy, dependency or attention arithmetic is introduced.

## Changes and revisions

`MOSSImagePipelineConfig.shard_latents_for_sp` returns `(latents, False)`, preventing the early spatial slice and redundant stage gather. The existing two-rank test now calls the real stage pre/post methods around the model; it fails on main at the full-latent identity assertion.

Cleanup reused the test stage across skip-layer cases and removed a redundant assertion. The review followed BBuf cleanup source/review examples [#39293](https://github.com/sgl-project/sglang/pull/39293), [#40265](https://github.com/sgl-project/sglang/pull/40265) and [#42391](https://github.com/sgl-project/sglang/pull/42391). The production file is byte-identical before/after cleanup. The diff changes only the pipeline config and its existing numerical test. ## Performance

Hardware: eight NVIDIA B300 SXM6 AC,275040MiB each, all-pair NV18, driver595.91.07. The fixed budget is physical GPUs 0–7. **Valid main uses CFG2 on GPUs 0–1; final and Omni use all 8. This measures correct scaling within the same budget, not an equal-topology kernel speedup.** Main SP timings are excluded because its images are incorrect; MOSS main explicitly rejects TP.

The selected comparator is based on the following B300 checks, all with the same checkpoint and image-quality gate. New compile checks retain native prompt caching and enable `TORCHINDUCTOR_EMULATE_PRECISION_CASTS=1`; the failed configurations are preserved with their generated images or startup errors.
