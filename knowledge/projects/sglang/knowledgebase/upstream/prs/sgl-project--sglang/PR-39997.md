## Original PR description

## Motivation

Appending media mutates a shared `token_modalities` list, changing the saved parent and sibling requests even when the append is discarded.

## Modifications

Create a new list during merge. Add parent/sibling isolation regressions and `test/manual/session/repro_session_media_metadata.py`.

## Accuracy Tests

All 6 CPU cases pass; the two isolation cases fail on upstream. Existing Qwen2.5-VL image-append/branch parity passes on H200 for both baseline and fix. The CPU cases reproduce the alias; the GPU test checks integration.

Validated against public upstream `b02e16a895` (September 16, 2026).
