# [Test] [AMD] deepseek-v4.1: Give the BCG metadata test pool no SWA ring

[Upstream PR](https://github.com/sgl-project/sglang/pull/45506) · state: closed · merged: False

## Original PR description

## What
Test-only fix for the two unit tests that keep `stage-b-test-1-gpu-small-amd-mi35x` red on main.

## Why
Both partitions fail on every scheduled run since Oct 19, e.g. [partition 0](https://github.com/sgl-project/sglang/actions/runs/39421857090/job/118624623384) and [partition 1](https://github.com/sgl-project/sglang/actions/runs/39421857090/job/118624623363).

- `test_dsv41_bcg_hip.py`: `AssertionError: 2 != 1` on the captured page-table width. Since #43733 the HIP backend captures and replays the DeepSeek-V4.1 prefill graph at `prefill_cuda_graph_default_max_seq_len` (16K) when no `max_seq_len` is configured, instead of the bucket's own length. The page table is that limit clamped to the `req_to_token` width (512 in the fixture), so 2 pages, not 1.
- `test_dsv4_hip_bcg_metadata.py`: `AttributeError: 'types.SimpleNamespace' object has no attribute 'swa_req_ring_size'`. Since #44673, `get_dspark_swa_page_indices` reads `swa_req_ring_size` and `swa_valid_from` from the KV pool, and the test's mock pool doesn't have them.

## Fix
- `test_dsv41_bcg_hip.py`: take the limit from `backend._graph_metadata_max_seq_len(capture_batch)`, which is what capture and replay actually use. Build the eager reference at that limit and expect `ceil(min(limit, req_to_token width) / page_size)` columns. This also turns on the existing limit branch (eager rebuild at the limit, overflow raises), which had no caller before.
- `test_dsv4_hip_bcg_metadata.py`: add `swa_req_ring_size=None` and `swa_valid_from=None` to the mock pool. These match the real pool's paged-SWA defaults.

No library code changes.

## Test plan
- [x] `stage-b-test-1-gpu-small-amd-mi35x` on rocm10 via dispatch: https://github.com/sgl-project/sglang/actions/runs/39541960302. Both partitions passed (31/31 and 32/32). `test_dsv41_bcg_hip.py` ran 1 test and `test_dsv4_hip_bcg_metadata.py` ran 19 tests, all OK.
