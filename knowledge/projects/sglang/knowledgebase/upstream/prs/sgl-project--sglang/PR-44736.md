[Upstream PR](https://github.com/sgl-project/sglang/pull/44736) · state: open · merged: False

## Original PR description

## Motivation

NPU CI can fail on a diffusion latency check without producing an image-consistency artifact. If coverage recommendations are also missing, the failure can go unreported.

This PR collects test results and logs into a single report, so contributors can see what failed and whether diagnostics are missing, even without coverage recommendations.

## Modifications

- Save diffusion test outcomes, error details, available performance metrics, and source links; capture partition logs without hiding test failures.
- Report final retry outcomes, avoid duplicate consistency failures, and flag failed jobs with missing diagnostics.
- Show recommendations in a collapsible table with observed failures; unconfirmed execution is never treated as a pass.
- Summarize failures, recommendation matches, and next steps without repeating test lists. Mark missing recommendations explicitly and fail the upload if the report is missing.
