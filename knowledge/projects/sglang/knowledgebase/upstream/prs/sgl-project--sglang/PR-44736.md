## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Performance-only diffusion failures, such as Z-Image stage latency regressions, can produce no consistency artifact. Without coverage recommendations, the analyzer then skips execution and succeeds without creating `failure_report.md`.

Ensure these failures produce a report and make missing diagnostics explicit.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Save per-test outcomes, phases, error types/messages, available actual/baseline/threshold values, and source run metadata in `diffusion-test-summary.json`.
- Capture partition logs for the 1-NPU and 2-NPU suites while preserving the test command's exit status.
- Run analysis without requiring recommendations or consistency artifacts. Read structured results and logs alongside existing consistency summaries.
- Include upstream diffusion job outcomes, flag failed jobs without test diagnostics, and keep skipped/cancelled jobs separate from failures.
- Surface analysis errors and fail the report upload when `failure_report.md` is missing.

## Accuracy Tests

<!-- If this pull request affects model outputs (e.g., changes to the kernel or model forward code), provide accuracy test results. -->

Five local regression tests passed, covering performance-only failures, HTTP/setup failures, collection-log fallback, missing artifacts, skipped/cancelled jobs, and legacy consistency artifacts. The temporary test file was removed after validation.

Ruff lint and formatting checks, YAML parsing, shell syntax checks, and `git diff --check` passed. Live NPU CI validation remains pending.
