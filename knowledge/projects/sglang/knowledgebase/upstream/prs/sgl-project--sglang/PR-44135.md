# docs: deduplicate model-specific guides into the cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/44135) · state: closed · merged: False

## Original PR description

## Summary

Resolves the remaining docs/cookbook overlap from #18427.

## Changes

### Case 1 — cookbook already had the content (EmbeddingGemma)

- ****: removed the condensed `EmbeddingGemma` subsection. The cookbook page at `/cookbook/autoregressive/Google/EmbeddingGemma` is authoritative and covers prerequisites, Hopper performance defaults, and deployment behavior. Replaced with a `<Note>` pointer. The model name in the supported-models table now links to the cookbook.

### Case 2 — cookbook did not have the content (Qwen3-Reranker, Qwen3-VL-Reranker)

- Moved the detailed sections from `rerank_models.mdx` (~240 lines: launch commands, request/response formats, multimodal examples, common pitfalls) into two new cookbook pages:
  - `docs/cookbook/autoregressive/Qwen/Qwen3-Reranker.mdx`
  - `docs/cookbook/autoregressive/Qwen/Qwen3-VL-Reranker.mdx`
- `rerank_models.mdx` now keeps only the category-level cross-encoder guide, the supported-models table (model names link to cookbook), and a short summary of decoder-only deployment rules.

### Navigation

- Added both new cookbook pages to `docs/docs.json` under the Qwen group so they appear in the sidebar.

### What was deliberately kept

The category-level quickstarts (client request examples, Matryoshka embedding, multimodal embedding example, cross-encoder rerank endpoint docs) are endpoint documentation rather than per-model duplication.

### Already resolved during docs migration

The `popular_model_usage.html -> /cookbook/autoregressive/intro` redirect is already in `docs.json`, along with per-model redirects.

Refs #18427
