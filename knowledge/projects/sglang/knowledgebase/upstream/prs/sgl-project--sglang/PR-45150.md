# [Fix] model_loader: Fix state-dict post-processing, KV scale sync, and LoRA wrapper handling across non-default loaders

[Upstream PR](https://github.com/sgl-project/sglang/pull/45150) · state: open · merged: False

## Original PR description

## Motivation

While auditing SGLang's non-default model loaders (`ShardedStateLoader`, `PreshardedModelLoader`, `RemoteModelLoader`, `RemoteInstanceModelLoader`, `QuantizedRLModelLoader`, `DummyModelLoader`, `GGUFModelLoader`, and `load_model_with_cpu_quantization`) against `DefaultModelLoader` (and vLLM's `process_weights_after_loading` pipeline), we identified three post-load discrepancies:

1. **Stale derived buffers and FP8 KV-cache scalar scale caches on state-dict / direct-buffer loaders (`ShardedStateLoader`, `PreshardedModelLoader`, `RemoteModelLoader._load_model_from_remote_kv`, `RemoteInstanceModelLoader`)**:
   - `ShardedStateLoader`, `PreshardedModelLoader`, and `RemoteModelLoader._load_model_from_remote_kv` run `quant_method.process_weights_after_loading(module)` *before* copying the saved tensors into `model.state_dict()` so that quantized linear/MoE parameters have their post-processed shapes, while `RemoteInstanceModelLoader` overwrites parameter buffers in-place via NCCL/RDMA without running parameter `weight_loader` hooks.
   - Because `process_weights_after_loading` runs while `module.k_scale` and `module.v_scale` are still at their initial sentinel `-1.0`, `BaseKVCacheMethod.process_weights_after_loading` sets `module.k_scale_float = 1.0` and `module.v_scale_float = 1.0`. When the state-dict copy subsequently populates `module.k_scale` and `module.v_scale` with calibrated scales, `module.k_scale_float` and `module.v_scale_float` are never refreshed—silently using `1.0` instead of the calibrated KV scales in every attention forward pass that reads `layer.k_scale_float` / `layer.v_scale_float`.
   - Furthermore, `ShardedStateLoader`, `RemoteModelLoader._load_model_from_remote_kv`, and `RemoteInstanceModelLoader` did not call `_rebind_parameter_aliases(model)` or rebind linear-attention `qkv_conv1d` views on `module.attn`, leaving `GemmaRMSNorm.gemma_weight` (a non-persistent buffer normally populated by `GemmaRMSNorm._weight_loader`) stuck at `1.0` instead of `weight.data + 1.0` and `attn.conv_weights` / `attn.bias` pointing at pre-load tensors.

2. **`BaseLayerWithLoRA` (`FusedMoEWithLoRA`) `AttributeError` in 8 non-default loaders**:
   - `DefaultModelLoader._process_weights_after_loading` uses `_modules_with_quant_method(model)` to skip `BaseLayerWithLoRA` wrappers (since `model.named_modules()` already visits `module.base_layer`, and `FusedMoEWithLoRA` does not wrap `process_weights_after_loading`).
   - Eight non-default loaders (`QuantizedRLModelLoader`, `DummyModelLoader`, `ShardedStateLoader`, `PreshardedModelLoader._load_from_presharded`, `GGUFModelLoader`, `RemoteModelLoader._load_model_from_remote_kv`, `RemoteModelLoader._load_model_from_remote_fs`, and `load_model_with_cpu_quantization`) iterated `model.named_modules()` directly and called `quant_method.process_weights_after_loading(module)` on the LoRA wrapper itself.

3. **`GGUFModelLoader.load_model` missing `.eval()`**:
   - Every other loader in `loader.py` returns `model.eval()`, whereas `GGUFModelLoader.load_model` returned `model` without calling `.eval()`.

## Modifications

- Add `_finalize_state_dict_load(model)` in `python/sglang/srt/model_loader/loader.py` to centralize:
  1. `PreshardedModelLoader._rebind_parameter_aliases(model)` (refreshing `GemmaRMSNorm.gemma_weight` and `conv1d.conv_weights`);
  2. `qkv_conv1d` weight/bias view rebinding on `module.attn`; and
  3. `BaseKVCacheMethod` scalar cache synchronization (`module.k_scale_float` and `module.v_scale_float`) from the loaded `module.k_scale` and `module.v_scale` tensors.
- Invoke `_finalize_state_dict_load(model)` in `ShardedStateLoader.load_model`, `PreshardedModelLoader._load_from_presharded`, `RemoteModelLoader._load_model_from_remote_kv`, and `RemoteInstanceModelLoader` (`load_model_from_remote_instance_by_nccl` and `load_model_from_remote_instance_by_transfer_engine`).
- Use `_modules_with_quant_method(model)` across all 8 non-default model loaders.
- Return `model.eval()` from `GGUFModelLoader.load_model`.
- Add `TestFinalizeStateDictLoad` unit tests in `test/registered/unit/model_loader/test_presharded_loader.py`.
