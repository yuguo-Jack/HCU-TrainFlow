## Original PR description

## Motivation

Several recently merged diffusion controls are missing from, or incompletely described in, the existing public documentation.

## Modifications

- Document MiniMax-H3 Ref2VA reference resizing policies, their scope and rounding behavior, and the ModelTC Turbo adapter's recommended policy (#35839).
- Clarify when automatic LoRA merging keeps an adapter dynamic because of estimated rounding loss (#43385).
- Add per-request profiling examples for image generation and multipart image editing, including server-side trace placement and measurement caveats (#43573).

The changes stay in the existing cookbook, CLI reference, and profiling guide. No README model section, navigation restructuring, or deprecated documentation is added.
