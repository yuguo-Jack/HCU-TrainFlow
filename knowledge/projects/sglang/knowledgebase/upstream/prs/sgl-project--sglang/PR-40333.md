# [Feat] [NVIDIA] deepseek-v4.1: Support prefill CP with BCG in PD serving (2/N)

[Upstream PR](https://github.com/sgl-project/sglang/pull/40333) · state: open · merged: False

issue：https://github.com/sgl-project/sglang/issues/39700
base pr：https://github.com/sgl-project/sglang/pull/40323

## Motivation
Enable DeepSeek V4.1 prefill nodes to use interleave context parallelism (CP) together with breakable CUDA graphs (BCG), including prefill/decode disaggregated serving.
This allows prefill computation to run across CP ranks while preserving graph replay correctness for batches with different prompt lengths and request layouts.

## Modifications
- Integrate interleave CP with BCG capture and replay. Keep CP-local embeddings, positions, token IDs, and live-token metadata consistent with the captured buffers. Align token IDs with the layouts used by TP-MoE and MegaMoE.
- Handle variable-length batches and capture padding correctly. Select replay buckets using per-rank capacity, preserve captured metadata addresses, and process only live tokens when updating low-ratio compressed state.
- Preserve global context and output ordering. Compute Engram hashes from global prompt context, gather CP outputs in token order, and trim padding before the logits tail, including DSPARK auxiliary hidden states.
- Support prefill CP for vision-enabled V4.1 models. Prepare multimodal embeddings before CP sharding. Text requests can use BCG; requests containing image inputs fall back to eager CP.
