# [Session] Ignore unused Mamba slots during cleanup

[Upstream PR](https://github.com/sgl-project/sglang/pull/40044) · state: closed · merged: False

## Original PR description

## Motivation

Lazy Mamba buffers contain unused entries marked `-1`. Closing or aborting a streaming session returned these entries to the pool, so 8 slots could become 9 free slots, including an invalid one.

Related #39838. The report's private 8-GPU workload has not been reproduced.

## Modifications

Skip unused entries when counting and releasing session buffers. Rebased on current main and updated the regression tests to use the current request release path.

## Accuracy Tests

22 related CPU tests and 8 subtests pass. On current main without the fix, all 4 lazy-buffer regression cases fail with `9 != 8`; regular buffers pass.

## Speed Tests and Profiling

Not applicable to this buffer cleanup change; model calculations are unchanged.
