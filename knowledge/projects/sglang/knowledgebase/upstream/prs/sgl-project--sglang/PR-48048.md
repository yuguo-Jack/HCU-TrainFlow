# [Fix] model_loader: Bound CPU checkpoint retention in multithreaded PT loading

[Upstream PR](https://github.com/sgl-project/sglang/pull/48048) · state: open · merged: False

## Original PR description

## Motivation

The default multithreaded `.pt` / `.bin` loading path submits every shard and keeps all Futures in a list until the iterator finishes. Completed Futures own their state dictionaries, so previously copied checkpoint tensors remain alive even when the model consumer no longer needs them. Limiting `num_threads` does not limit this retained checkpoint storage.

## Modifications

- Keep a bounded set of pending shard reads and consume ready Futures with `FIRST_COMPLETED`, without blocking on the first file in input order.
- Release each Future and state dictionary after yielding its weights, then replenish the window.
- Extend the existing CPU weight-utils tests with real `torch.save`/`torch.load` checkpoints, the default `DefaultModelLoader` dispatch and `default_weight_loader` copy consumer. Also cover a slow first shard, early close, errors, empty input and consumers retaining multiple tensors with shared storage.

This bounds loader-owned checkpoint state, not memory retained by downstream consumers or total process RSS. The existing `weights_only=True` loading behavior is unchanged.

## Validation

On base b8100b74bf4f6563f402c20a1e1af685cbd2246e:
- Before the change, after consuming 8 of 12 one-MiB shards, at least 8 MiB of checkpoint tensor storage was still alive with either 1 or 2 loader threads. Both regression subcases failed.
- After the change, all 18 tests in `test/registered/unit/model_loader/test_weight_utils.py` passed, including bounded storage, bit-exact copies and release after exhaustion/early close. All 3 existing `test_default_model_loader.py` tests also passed.
- Targeted Ruff 0.15.1 lint/format, isort 7.0.0, codespell 2.4.1 and `git diff --check` passed.

Validation used Python 3.12 and CPU PyTorch 2.15.0 rather than the project's pinned 2.14.1. Full repository `pre-commit run --all-files` passed (exit 0) on both the fixed tree and pristine base after installing the official repository-required Rust 1.92 and nightly toolchains. No source files were changed by the hooks. Accelerator inference, full-model accuracy and hardware throughput benchmarks have not been run. No GPU performance claim is made.

AI assistance was used for investigation, implementation and tests; a separate AI review is not a human review.
