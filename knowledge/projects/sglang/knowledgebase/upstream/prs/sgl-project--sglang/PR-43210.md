## Motivation

Fix 5 failures in NPU diffusion CI:

- **D001 — MiniMax-H3 slowdown after #42370.** That PR made consistency tests request `quality="exact"`. For MiniMax-H3, this turns off the Cache-DiT mode enabled by the CI configuration, so the 2-NPU test no longer uses its intended acceleration.
- **D002 — GLM-Image requests rejected after #41585.** That PR added strict validation to `/generate`, but the schema omitted `image_grid_thw`, which GLM-Image sends to its autoregressive encoder. Valid GLM-Image requests therefore fail with HTTP 400 before generation.
- **D003 — JoyAI times out downloading its input image.** The test fetches an image from GitHub Releases while running. A network timeout stops the test before generation. 
- **D004 — failure analyzer blind to diffusion failures.** `Analyze failure report` only downloads `selected-test-logs-*`, so diffusion consistency failures (published as `diffusion-failures-*` artifacts) never appear in the report, and empty input is reported as `Failed: 0`.
- **D005 — MiniMax-H3 consistency regression after #38671.** That merged PR makes `num_inference_steps=50` run 50 denoising updates instead of 49, shifting the sampled trajectory. The Ascend golden pinned at `609c4cef` was generated on the old 49-update trajectory and no longer matches (min SSIM 0.74 vs threshold 0.92) while the performance check stays green.

## Modifications

- Let the MiniMax-H3 2-NPU test keep its configured Cache-DiT mode. Other tests keep their existing quality settings.
- Add `image_grid_thw` to the API schema and update the generated Python/Rust types. Include the encoder's response body in error logs so future validation failures are easier to diagnose.
- Download and cache JoyAI's input image during CI setup, through the CI proxy. Verify its checksum and install it atomically so parallel jobs can safely share the cache. The test then reads the local file; standalone runs can still use the original URL.
- Teach `Analyze failure report` to also download `diffusion-failures-*` artifacts, parse each partition's `consistency_failures/summary.json` into the failed list plus a dedicated metrics section, and state explicitly when no input artifacts were found instead of a misleading `Failed: 0`. Also move `continue-on-error` to step level — it is not a `download-artifact` input and logged a warning on every run.
- Bump the Ascend consistency GT pin to `2173af2f` (sgl-project/ci-data-diffusion). The MiniMax-H3 frames were regenerated by the NPU GT generation workflow on this branch (run 38069422051) with Cache-DiT enabled (steps=50, Fn=2, Bn=1, rdt=0.4) — the exact code path the test runs. CLIP/SSIM/PSNR thresholds are unchanged.

The input-image cache is inspired by #37426, which caches reference outputs for consistency checks. This PR uses the same prefetch approach for an input image and can merge independently.

## Follow-up: Ascend NPU quality choices

Tracked in #43351. Start with MiniMax-H3: define explicit quality choices for Ascend and how each choice controls Cache-DiT, then validate output consistency and latency on A3. Once that support is validated, the NPU test can select a quality tier directly and remove the test-side quality-pinning exception introduced here. Extend support to other Ascend diffusion models as their configurations are validated.

This is follow-up work; this PR preserves the existing MiniMax-H3 cache configuration.
