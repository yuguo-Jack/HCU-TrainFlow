# [Fix] benchmark: handle metadata-only completion chunks

[Upstream PR](https://github.com/sgl-project/sglang/pull/44556) · state: open · merged: False

## Original PR description

## Motivation

Usage/cache-only frames have `choices: []`, but the completions benchmark indexes `choices[0]` and marks successful requests as failed. Empty-text final chunks also lose their reported token count.

## Modifications

Read usage before handling text, skip empty choice lists, and add HTTP regressions.

## Accuracy Tests

All 8 component tests pass; the original client fails the metadata cases.

The loader supplies the native OS name during aiohttp import because this host's WMI query hangs.

Ruff, isort, test-entry checks and registration checks pass. Registration checks cover the sparse checkout, not omitted upstream files.
