# [Perf] [NPU] attention: Support mlaprolog for kimik3

[Upstream PR](https://github.com/sgl-project/sglang/pull/47373) · state: closed · merged: True

## Original PR description

## Motivation

Enable MLAProlog for Kimi K3’s no-RoPE MLA on Ascend, supporting BF16 and MXFP8 projection weights with BF16 KV cache.

- The existing MLAProlog path assumes a rotary embedding, but Kimik3 does not need rope. 
- Use mlaprolog V4 kernel to support mlaprolog without rope.

## Modifications

- Integrate `sgl_kernel_npu.operators.attention.mlaprolog_v4` for MLA without RoPE, passing `None` for sine and cosine inputs.
- Route A5 MLA preprocessing through MLAProlog, reusing existing BF16 and MXFP8 weight preparation.
- Correct the `v_head_dim` argument passed to `NPUFusedMLAPreprocess` and consume the common Q/K outputs without assuming a fixed return-tuple length.
- Automatically select the existing split QKV/G path when ModelSlim metadata indicates different quantization precisions for Q and G, keeping construction, forward execution, and weight loading consistent.
