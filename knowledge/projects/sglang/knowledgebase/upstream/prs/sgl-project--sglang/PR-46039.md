## Original PR description

## Motivation

The FLUX.2 XPU fusion test added by #41942 imports `flux_2` at module scope but registers in `base-a-test-cpu`, whose environment lacks `diffusers`. The file fails before any tests run with `ModuleNotFoundError: No module named 'diffusers'`.

This blocks unrelated PRs, including [the CPU job on #45076](https://github.com/sgl-project/sglang/actions/runs/39937200905/job/120359896858). The failing test file is identical on main at `535aeae2a709077e3d17f5efc48350319ac13fc9` and #45076 at `402c0652846c0dc6f1ce85395468de997c90c424`.

## Modifications

Move the non-XPU import regression to `base-b-kernel-unit-test-1-gpu-large`. Its existing workflow installs diffusion dependencies and exercises the intended CUDA-without-Intel-Triton import path. Keep the XPU registration and all test assertions unchanged.

## Validation

- Verified the CI registration parser selects CUDA kernel and XPU suites, with no CPU registration.
- Verified the destination workflow installs dependencies with `ci_install_dependency.sh diffusion`.
- All applicable pre-commit checks passed, including repository-wide registered-test validation.
- CUDA import execution and XPU numerical tests were not run locally; CI validation remains pending.

No model or kernel implementation changes.
