# Free raw image tensors before language-model execution to avoid prefill OOMs

[Upstream PR](https://github.com/sgl-project/sglang/pull/37536) · state: open · merged: False

## Original PR description

## Motivation

Large image prefills can OOM in the language model because raw image tensors remain on GPU after their embeddings have already been computed. Cache-hit and deduplicated inputs can retain these tensors too, and a loop-local reference can keep the last tensor alive across the language-model call.

This PR releases those unnecessary device references earlier, preserving a host copy for re-encoding if the embedding cache later evicts its entry. The returned embeddings and cache entries are unchanged.

## Modifications

- Offload top-level CUDA feature tensors immediately after each encode site and after each modality's embedding step, including cache-hit and deduplicated items.
- In the existing final cleanup loop of `general_mm_embed_routine`, drop the loop-local feature and precomputed-embedding references so neither survives into the language-model call.
- Leave host tensors, container-valued features and placeholders unchanged. No new option.

## Accuracy Tests

`test_mm_schedule_feature_offload.py` covers the three encode sites, cache hits, same-hash deduplication and the full embed routine, with weak-reference checks that the device feature is gone when the language model runs on CUDA. On CPU: 9 passed, 1 skipped (CUDA only). The related chunked-embedding, embedding-length and draft-embedding unit tests also pass (31 passed, 1 skipped in total). The CUDA parametrization has not been rerun.

## Speed Tests and Profiling

Moves the existing device-to-host copy earlier. Text-only requests do not enter this path. Throughput was not benchmarked.
