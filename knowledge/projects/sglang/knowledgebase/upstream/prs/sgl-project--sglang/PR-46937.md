# [Fix] anthropic: Preserve cache_salt for Messages requests

[Upstream PR](https://github.com/sgl-project/sglang/pull/46937) · state: closed · merged: True

## Original PR description

## Motivation

`/v1/messages` silently discards `cache_salt` during request validation and omits it when constructing the Chat Completions request. Messages requests therefore reach the unsalted cache namespace even when callers supply distinct salts.

## Modifications

Accept an optional `cache_salt` on Messages requests and forward it unchanged to the existing Chat Completions caching path. Add regression coverage for streaming and non-streaming requests with distinct, empty, null, and omitted salts.

## Accuracy Tests

- The new regression fails before the fix and passes after it.
- Local Anthropic unit suite: **73 passed, 30 subtests passed**.

```bash
PYTHONPATH=python python -m pytest test/registered/unit/entrypoints/anthropic/test_serving.py -q
```

The adjacent Chat protocol test `TestChatCompletionRequest.test_json_schema_strict_requires_json_boolean` fails four invalid-boolean subcases in this environment, reproduced on pristine upstream `faa56e2b` as well. No model accuracy evaluation was run.

## Speed Tests and Profiling

Not run. Post-patch server validation of same-salt reuse and different-salt cache isolation remains pending.
