# [MPS] Add capability-checked compiled MLX decode for Torch-owned models

[Upstream PR](https://github.com/sgl-project/sglang/pull/42938) · state: open · merged: False

## Original PR description

## Motivation

Add an experimental MLX compute path beneath the existing Torch MPS model runner: keep Torch model loading, weight ownership, KV pools and sampling, while executing an exported decode graph through `mx.compile`.

This follows the whole-region direction discussed in [RFC #32321](https://github.com/sgl-project/sglang/issues/32321) and [PR #36164](https://github.com/sgl-project/sglang/pull/36164), building on the Torch/MLX bridge work in [PR #36780](https://github.com/sgl-project/sglang/pull/36780).

The backend is opt-in. Eager MPS remains the default, and the existing native MLX path (`SGLANG_USE_MLX=1`) is unchanged. This implementation uses **direct Torch export to compiled MLX**.

## Modifications

- Add opt-in `--mps-execution-backend mlx-compiled` for dense, unquantized,
  single-rank decode batches up to 16. Prefill stays eager.
- Export the existing model forward and logits processor. Validate structure,
  operators and tensor metadata; unsupported regions log an eager fallback.
- Use AOT Metal radix attention over Torch-owned KV storage, with optional
  physical pages of 16/32/64 tokens. Default page size remains 1.
- Add bounded read-only greedy lookahead with scheduler lifecycle fences;
  Torch sampling and accepted-token KV commits remain authoritative.
- Support explicit custom-op MLX lowerings and reduce binding/greedy-sampling
  overhead without changing sampling semantics.
- Integrate paged allocation through the MPS platform hook and keep compiled
  decode setup separate from CUDA graph selection.

Build the Metal extension in the serving environment, then launch:

```bash
python python/sglang/kernels/aot/setup_metal.py install
SGLANG_USE_MLX=0 python -m sglang.launch_server \
  --model-path Qwen/Qwen3-0.6B --dtype bfloat16 \
  --mps-execution-backend mlx-compiled \
  --context-length 16384 --max-total-tokens 16384 \
  --max-running-requests 16 --mem-fraction-static 0.6
```

MPS is detected automatically. Compiled prefill, quantized/MoE/recurrent models,
LoRA, speculative decoding and distributed execution are out of scope.
