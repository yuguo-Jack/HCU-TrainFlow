# [Doc] beam: Offer Python and Docker commands in the cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/45991) · state: closed · merged: True

## Original PR description

## Motivation

The Beam cookbook only offered the `docker run` form of each command (`--gpus all`, `--shm-size 32g`, port and cache mounts, `--ipc=host`, the `lmsysorg/sglang:beam` image). Other cookbooks, such as MiniMax-M3.1, let readers switch between a Python and a Docker command, with Python selected first. Beam now does the same.

## Modifications

- `docs/src/snippets/configs/reflection/beam-1.0.jsx`: remove `runModes: ["docker"]`. Without it the engine shows the Python / Docker toggle with Python first, as for the other cookbooks. The `dockerImages` map stays for the Docker output.
- `docs/cookbook/autoregressive/Reflection/Beam-1_0.mdx`: "generate the Docker command" now reads "generate the launch command", and the "Install SGLang" box explains the toggle: the Python output is the bare `sglang serve` command to run inside a container from the `lmsysorg/sglang:beam` image, and the Docker output wraps the same command in `docker run`. The `docker pull` line is unchanged.

The flags of every recipe are unchanged.
