# [CI] codespell: Ignore miniTE blog name

[Upstream PR](https://github.com/sgl-project/sglang/pull/47522) · state: closed · merged: True

## Original PR description

## Motivation

The automated LMSYS blog card sync in https://github.com/sgl-project/sglang/pull/44825 fails `lint` because codespell flags the blog name **miniTE** as a misspelling of "minute":

```
docs/index.mdx:171: minite ==> minute
docs/index.mdx:172: miniTE ==> minute
docs/index.mdx:191: miniTE ==> minute
```

The text is synced verbatim from the blog, so the fix belongs in the codespell config rather than in the generated cards.

## Modifications

Add `minite` to `ignore-words-list` in `.codespellrc`. codespell lowercases words before the dictionary lookup, so this also covers `miniTE`.

## Verification

Ran `codespell` v2.4.1 (the version pinned in `.pre-commit-config.yaml`) on `docs/index.mdx` from #44825's head (`00971ec`):

- old `.codespellrc`: the 3 errors above, exit 65
- new `.codespellrc`: clean, exit 0
