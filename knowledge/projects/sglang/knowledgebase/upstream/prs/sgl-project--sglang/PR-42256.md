# [Test] diffusion: Cover residual dispatch and Qwen CUDA fallbacks

[Upstream PR](https://github.com/sgl-project/sglang/pull/42256) · state: open · merged: False

## Original PR description

## Motivation

ROCm tensors also report `is_cuda`, but the diffusion residual fast path contains NVIDIA PTX. Upstream #42391 already merged the HIP eligibility guard and simplified the native dispatch. This PR now adds regression coverage on top of that implementation; it changes no production kernel.

## Changes

- Exercise HIP rejection and the exact eager result for FP16/BF16/FP32 with full, row, token, and transposed-row gate layouts. A sentinel fails the test if the PTX custom op is attempted.
- Run the real CUDA residual fast path for FP16/BF16 with those four layouts, including the new transposed Triton path, and compare with eager at `atol=0, rtol=0`.
- Run the Qwen Q/K norm + RoPE/KV packing regression with native kernels available and deliberately unavailable, checking exact model output, prefix-cache ownership, and CUDA graph replay.
- Preserve upstream's NVIDIA-only Qwen suite and newer LoRA-format tests. Remove references to the deleted failed-runtime cache and old packing eligibility API.
