# [rust-server] fix rust dp listener port

[Upstream PR](https://github.com/sgl-project/sglang/pull/36225) · state: closed · merged: False

## Original PR description

## Summary

Each data-parallel replica now gets a separate HTTP port when the embedded Rust server is enabled. Previously the listener used `attn_dp_rank`, which is zero on every replica when attention data parallelism is off, so `--dp-size 2` made both servers try port 30000 and left port 30001 unavailable.

The fix uses `dp_rank`, which already holds the replica number. With attention data parallelism, the controller stores the computed attention rank in that same field, so the ports added by #33105 do not change; the existing `dp_size > 1` check also keeps single-replica and externally assigned ports unchanged.

## Reproduction

```bash
SGLANG_RUST_SERVER=1 sglang serve \
  --model-path meta-llama/Llama-3.2-1B-Instruct \
  --dp-size 2

curl --fail http://127.0.0.1:30000/health
curl --fail http://127.0.0.1:30001/health
```

Before the fix, the second scheduler reports that port 30000 is already in use and nothing listens on port 30001. After the fix, both health requests succeed.
