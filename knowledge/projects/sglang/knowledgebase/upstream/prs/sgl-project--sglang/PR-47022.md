Joy Image Edit's BF16 image MLP runs a 4096-to-16384 projection followed by a separate tanh-GELU. On RTX PRO 6000 Blackwell, the existing fused GEMM/GELU operator is faster for the model's large image-token dimension, while the smaller text projection regresses. The generic operator policy disables SM120 based on other model shapes.

This change opts only Joy's image MLP into the existing epilogue at `quality="high"`. It leaves the generic policy and text MLP unchanged. Eligibility requires SM120, BF16, contiguous batch-1 inputs with at least 7168 image tokens and the expected projection dimensions. The native single-reference buckets contain 7168–8192 image tokens. Active dynamic LoRA on the input projection, quantized/ineligible projections, unmatched devices, other shapes and `torch.compile` retain the original MLP. The quality decision is passed from the current request without persistent mutable model state; `exact` and `lossless` retain the original computation.

- Candidate: `4c135ea92d6b4cbb0ead69bb39976f7dbe995455`.

On 2026-10-28, the Joy model, fused-linear helper, regression-test file and documentation at latest main `990ee89877f668304761d7551d803ed6b93d1673` were verified byte-identical to this frozen baseline. The benchmark source SHAs remain unchanged.
