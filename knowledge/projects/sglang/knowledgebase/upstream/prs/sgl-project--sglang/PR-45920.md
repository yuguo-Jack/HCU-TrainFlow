# [CI] [NVIDIA] gb300: Restore the aarch64 rust-ext cache on ARM runners

[Upstream PR](https://github.com/sgl-project/sglang/pull/45920) · state: closed · merged: True

## Original PR description

## Motivation

`download-rust-ext` always restores `rust-ext-x86_64-cp312`. Jobs with no same-run artifact (`/rerun-test`, or re-runs after the artifact expires) get x86 modules on GB300 and rebuild the Rust extensions from source: install takes ~6 min instead of ~30 s.

```
cache_key_prefix: rust-ext-x86_64-cp312
Cache hit for: rust-ext-x86_64-cp312-44722fe8...
::warning::no prebuilt Rust extension .cpython-312-aarch64-linux-gnu.so for: server grpc multimodal mem_cache mem_cache_inspection; building from source
Prepared 1 package in 5m 55s
```

The aarch64 entries already exist on main (`rust-ext-aarch64-cp312-<same hash>`, seeded by `pr-test.yml` / `seed-rust-ext-cache.yml`).

## Modifications

Restore with `rust-ext-aarch64-cp312` on ARM64 runners. x86 behavior and the prefix lint are unchanged.
