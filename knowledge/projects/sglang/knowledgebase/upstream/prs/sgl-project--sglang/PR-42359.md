# [Test] diffusion: Verify retained performance failures after retry exhaustion

[Upstream PR](https://github.com/sgl-project/sglang/pull/42359) · state: open · merged: False

## Original PR description

## Motivation

Current main already batches the nine real performance-failure scenarios in one retry runner (#44508). The remaining integration test can stop after one attempt when it inherits an expired `SGLANG_DIFFUSION_RETRY_DEADLINE`, and it checks console output without verifying each final JUnit failure.

## Modifications

Clear the inherited deadline only for the seven-attempt exhaustion fixture. Verify the exact set of ten JUnit items, a retained `[performance]` failure for each of the nine scenarios, and the independent infrastructure timeout. Existing retry-budget tests still exercise the deadline policy. Production code, thresholds and retry counts are unchanged; only twelve lines are added to the current test file.
