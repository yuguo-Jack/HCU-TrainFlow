## Original PR description

## Summary

Port #42890 to the `sglang-miles` branch: a cherry-pick of `a832609b9`, including the reviewer's follow-ups (side-neutral flat top-logprob helpers, required `finished`, docs).

- `return_flat_raw_output_top_logprobs` returns output top-k candidates on the finished response as flat arrays in `meta_info` (`output_top_logprobs_{val,idx}_flat[_b64]`, `_shape`, `_null_prefix`) instead of nested `[logprob, token_id, text]` rows, without detokenizing every candidate.
- Chat completions accept the flag (requires `return_meta_info`) and default `return_flat_raw_top_logprobs_b64` to `true`; `/generate` keeps its defaults.
- Left out: the changes to `rust/sglang-processor/src/openai/chat.rs` and `test/registered/unit/api/v1/test_parity.py`, since neither file exists on this branch.

Consumers: radixark/sgl-router-for-miles#24 (the gateway forwards the new fields) and radixark/miles#3952 (the session server requests and decodes the arrays). Measurements and review are on #42890.
