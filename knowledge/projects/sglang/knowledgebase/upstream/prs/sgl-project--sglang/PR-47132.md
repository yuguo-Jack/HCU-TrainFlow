# [Feat] lora: Coordinate routing reuse through DP scheduler metadata

[Upstream PR](https://github.com/sgl-project/sglang/pull/47132) · state: open · merged: False

## Original PR description

## Motivation

LoRA managers that cache distributed routing need every rank to agree before skipping routing preparation. Carry that vote in the existing DP scheduler metadata exchange so an opt-in manager can avoid a separate synchronization collective.

This PR adds the coordination hook and batch plumbing. The default `LoRAManager` votes **false**, preserving existing routing preparation behavior.

## Modifications

- Add `can_reuse_dp_lora_routing(batch)` and one metadata column. Reuse requires unanimous agreement across all DP/TP/CP participants; inactive ranks veto it.
- Disable reuse when scheduler synchronization is skipped, a prefill is present, or decode graphs are ineligible.
- Carry the vote through schedule-batch copies, target forward batches, and graph replay views. Draft workers clear the target manager's vote. An opting-in manager must still validate the globally selected batch shape before reuse.

## Validation

- Focused scheduler, LoRA, graph replay, speculative coordination, and batch-lifecycle tests passed.
- Extended the existing Gloo test across 2, 3, 4, 5, 6, and 8 ranks; added coverage for a non-TP0/CP0 veto, inactive ranks, and conservative fallback conditions.
- All applicable pre-commit hooks passed.

No model accuracy or throughput benchmark is claimed: this change does not enable routing reuse in the default manager or change kernel execution.

-Robot

- The conditions in `_update_gather_batch`: skipped metadata, an extend batch on any rank, and an ineligible decode graph each force the flag to False.
- The flag's path through `ScheduleBatch`, `ForwardBatch` and the graph replay view, plus the places it gets cleared: draft workers, TBO child batches, and the DFlash v2 idle and zero-token verify batches.
- The new `ScheduleBatch` import in `lora_manager.py`: `schedule_batch.py` doesn't import any LoRA modules, so I found no import cycle.
