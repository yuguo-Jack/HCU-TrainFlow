[Upstream PR](https://github.com/sgl-project/sglang/pull/45288) · state: closed · merged: True

## Original PR description

## Motivation

Keep the NPU kernel dependency used by CI dependency installation and Docker image builds aligned on the same release.

## Modifications

- Update the default `SGLANG_KERNEL_NPU_TAG` from `2026.9.0.post9` to `2026.9.0.post10`.
- Apply the new version consistently to:
  - NPU CI dependency installation
  - NPU Dockerfile builds
  - Official NPU Docker image releases
  - Nightly NPU Docker image releases
