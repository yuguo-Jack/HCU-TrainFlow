# [Fix] function_call: Preserve Cohere tool calls after leading streamed text

[Upstream PR](https://github.com/sgl-project/sglang/pull/42261) · state: open · merged: False

## Original PR description

## Motivation

Fixes #42135.

With `cohere_command4`, a final streaming delta containing prose followed by a complete action block emits only the prose. The detector returns before parsing the block, so the client never receives its tool call.

For example, this decoded output in one delta:

```text
Let me check.<|START_ACTION|>[{"tool_call_id":"0","tool_name":"get_weather","parameters":{"city":"SF"}}]<|END_ACTION|>
```

| Result | Before | After |
| --- | --- | --- |
| Content | `Let me check.` | `Let me check.` |
| Tool calls | none | `get_weather` with arguments `{"city": "SF"}` |
| Final finish reason | `stop` | `tool_calls` |

## Modifications

Keep the leading prose while checking for the closing action marker. If the block is complete, return its calls together with that prose. If it is incomplete, emit the prose and keep waiting for the closing marker.

## Tests

- Nine registered CPU tests cover the final coalesced delta, every two-chunk split, character chunks, multiple calls in one block, incomplete markers, trailing prose on the next increment, unknown tools and plain text.
- Function-call unit suite: 587 tests passed.
- Local reproduction: 250 fixed decoded-output cases through `OpenAIServingChat._generate_chat_stream` with a stubbed token stream, checking SSE content, tool calls, terminal finish reasons and `[DONE]` in cumulative and incremental modes.
- Changed-file pre-commit passed.

Run on macOS arm64 with Python 3.12.14.
