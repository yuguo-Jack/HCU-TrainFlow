# feat: support temperature-scaled input logprobs

[Upstream PR](https://github.com/sgl-project/sglang/pull/36213) · state: closed · merged: False

## Original PR description

## Motivation

Off-policy distillation needs teacher token scores under `q_T(y | x) = softmax(z(x) / T)_y`. Input logprobs currently use unscaled logits, and a selected `q_1` logprob cannot be converted to `q_T` without the full-vocabulary normalizer. This is needed by [THUDM/slime#2325](https://github.com/THUDM/slime/pull/2325).

## Modifications

Add `input_logprob_temperature` to the Python Engine and `/generate` APIs. It defaults to 1 and accepts positive finite values, independently of decode sampling temperature. Apply it to input token, top-k, and selected-token scores across fast/reference, chunked, heterogeneous-batch, and multi-item scoring paths; leave raw next-token sampling logits unchanged. Responses echo the scoring temperature in `meta_info` when logprobs are requested.

The all-unit default path creates no temperature tensor and performs no division. The tokenized request field is appended to the defaulted wire tail, preserving the Rust server's positional prefix and default scoring behavior.

## Accuracy Tests

The four focused CPU suites (`test_logprob_fast_input`, `test_logprob_chunk_stitching`, `test_io_struct`, and `test_tokenizer_manager_rid_cleanup`) report 101 passed, 9 skipped, and 22 subtests passed on the rebased head. Coverage includes explicit temperature-scaled math, untouched sampling logits, fast/reference agreement, mixed request temperatures with zero-row requests, multi-item delimiter alignment, request validation, wire compatibility, and response metadata.

Changed-file pre-commit hooks and `git diff --check` pass. GPU execution and graph-pool borrowing have not been exercised locally.

## Speed Tests and Profiling

Not run. Default `T = 1` does not add a tensor transfer or division; non-unit temperatures add division only over input-scoring rows.
