# [Feat] lora: MoE LoRA stage kernels (13/21)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42880) · state: closed · merged: False

## Original PR description

Part 13 of 21 of the LoRA runtime stack (branch `lora-stack-12-moe-stages`, base `lora-stack-11-moe-tables`). The stack is cut from the development branch of #42284.

## What this part adds

Add the Triton stages of the MoE engine: dispatch into masked and contiguous
row domains with FP8 row quantization, the activation delta, fused B +
activation, the materialized and shared finalizes, the MoE grouped B and the
down-B-into-base epilogue, and row alignment helpers. Register them in the
lora kernel inventory.

Tests: activation-quant fusion, the contiguous FP8 gather, per-row B numerics
and routing-graph replay. The B + activation, down-B-into-base and finalize
stages are exercised through the runner in the MoE runner part.

- GB300 run r45: the tree of upstream main `c1c287a429` plus parts 01–13 imports every module this part changes and passes this part's tests together with every earlier part's unit tests: **399 passed, 20 warnings, 152 subtests passed in 28.46s** (excluding the tests that fail identically on the untouched base tree in that environment).

The complete 21-part tree equals the development branch of #42284 at `e7b7179a86` (the `6588053ef2` tree with four test-only follow-ups squashed into its dense commit: the admission/snapshot trim, the restored FP8 block-shape admission pin, a second trim that keeps only the tests guarding silent failures and adds pins for four coverage gaps, and restored numerical and packing coverage; production code is unchanged) minus the benchmark tools and the Triton MoE tuning tables, which follow in separate PRs.
