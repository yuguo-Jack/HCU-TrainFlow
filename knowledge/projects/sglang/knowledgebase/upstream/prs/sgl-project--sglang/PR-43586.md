# [diffusion] torch.compile: keep Qwen-Image-2.1 and Ulysses graphs whole

[Upstream PR](https://github.com/sgl-project/sglang/pull/43586) · state: closed · merged: True

## Original PR description

## Motivation

With `--enable-torch-compile`, Qwen-Image-2.1 on 2xGB300 is slower than eager: Ulysses compile 3.72 s vs eager 2.78 s, and vLLM-Omni's compile is 3.21 s. `TORCH_LOGS=graph_breaks` shows 32 graph breaks, all in every attention:

1. `QwenImage21Attention._project_qkv_packed` re-derives the packed `[3C, C]` weight view from storage pointers (`untyped_storage().data_ptr()`, `storage_offset()`) and runs a one-shot verification. Neither can be traced (`qwen_image21.py:432–441`).
2. Ulysses' overlapped input all-to-all (`turbo_layer.async_a2a_communicate`: `async_op=True` work handles on a side stream) cannot be traced (`turbo_layer.py:143`).
3. The 2-rank IPC transport's custom-class handles cannot be traced (`ipc_a2a.py`). It also logs `IPC all-to-all unavailable (UnsafeScriptObjectError ...)` and falls back anyway.

## Modifications

Only under `torch.compiler.is_compiling()`:

- `_project_qkv_packed` returns `None`, so the compiled graph keeps the plain q/k/v projections.
- Both `async_a2a_communicate` call sites in `USPAttention` take the existing synchronous `_usp_input_all_to_all*` path (NCCL `all_to_all_single`, which dynamo traces); inductor can still overlap it.
- `_ipc_ready_group` and `_usp_all_to_all_single` skip the IPC transports.

Eager is unchanged.

## Accuracy Tests

Eager takes the same code as before. Qwen-Image-2.1 1024², 40 steps, Ulysses 2: compile vs eager PSNR 27.0 dB, from inductor re-association (the compile path uses the same algorithms: plain vs packed GEMM, synchronous vs overlapped all-to-all).

## Speed Tests and Profiling

Qwen-Image-2.1 1024², 40 steps, 2xGB300, served. Median of 5 requests after 2 warmups, fresh server per arm. NUMA-bound workers (#43565), `--offload-during-compile false`.

| | main | this PR | eager | vLLM-Omni compile |
|---|---|---|---|---|
| Ulysses 2 compile | 3.719 s (32 breaks) | **1.918 s (2 breaks)** | 2.78 s | 3.21 s (`--usp 2`) |
| TP2 compile | 2.429 s (22 breaks) | 2.003 s (12 breaks) | 1.61 s | — |

TP2's remaining breaks are the TP all-reduce (`Communicator.get_world_size`), which is a follow-up. The last 2 Ulysses breaks are in VAE decode (`parallel_conv` context var).
