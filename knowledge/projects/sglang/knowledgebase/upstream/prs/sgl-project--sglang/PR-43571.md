# fix(spec): prefer decode and default EAGLE chunked prefill to 1024

[Upstream PR](https://github.com/sgl-project/sglang/pull/43571) · state: open · merged: False

## Original PR description

## Summary
Fixes multi-turn Mean TPOT inflation under EAGLE/NEXTN on Ascend NPU by:
1. Preferring running decode over starting new waiting prefills (including chunked continuations) when speculative decoding is active and mixed-chunk is off
2. Resetting a disabled \chunked_prefill_size\ (\<= 0\) to **1024** for the EAGLE family
