## Motivation

A unified pool containing full-attention KV, sliding-window KV and recurrent state dropped the model's convolution slice axis and silently used axis 0.

## Changes

Pass the configured convolution slice axis into the recurrent-state layout and update the literal layout expectation for an axis-1 model.

## Validation

Historical validation at `2fe3d50f12`: the layout golden passed, including the corrected convolution slice-axis expectation **0 → 1**. Later CPU review matched **418 layout values across 28 configurations**.

No dedicated GPU convolution run was performed for this fix.
