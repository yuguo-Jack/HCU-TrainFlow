# [Perf] diffusion: Drop LTX-2's all-valid prompt mask under lossless quality

[Upstream PR](https://github.com/sgl-project/sglang/pull/46106) · state: closed · merged: True

## Original PR description

Branch: mick/ltx2-drop-all-valid-prompt-mask (on main 02b983603d), commit 12b5588eb1

## Motivation

LTX-2's text connector replaces every padded prompt token with a learned register, so the mask it returns is all ones. The DiT still received it, and every prompt cross-attention became masked SDPA with an all-zero additive bias. cuDNN serves that with slower kernels. On B300: 1536x1024 tokens at d128 take 53.9 us with the bias and 25.6 us without, and 126x1024 at d64 take 40.2 us against 17.6 us. That is 96 masked calls per stage-1 step. TensorRT-LLM does not pass this mask either.

## Modifications

- `models/adapter/ltx_2_connector.py`: `LTX2TextConnectors.output_mask_is_all_valid` is true when the video connector has learned registers.
- `ltx_2/text_connector.py`: under `quality="lossless"` (the default), the stage stores no prompt or negative mask when the connector's mask is all valid. The DiT then runs unmasked prompt cross-attention. `quality="exact"` keeps the reference mask.

Adding a zero bias changes no attention score. Only the kernel, and with it the rounding, changes.

## Tests

`test_ltx2_prompt_mask_registers.py`: lossless drops both masks with and without CFG; exact keeps the all-ones masks; a connector without registers keeps its mask; `output_mask_is_all_valid` follows the registers.

## Accuracy Tests

4xB300 (2 GPUs), LTX-2 two-stage 768x512x121, CFG parallel + BCG, 4 prompts: PSNR against the masked run 17.9 / 20.6 / 24.4 / 15.1 dB.

Reference band for a rounding-only change on this workload: the same server with `quality="exact"` against the default `lossless` (which already mounts other rounding-moving fusions) gives LTX-2 PSNR 17.0 / 20.6 / 23.1 / 20.8 dB and LTX-2.3 18.1 / 19.3 / 17.6 / 20.4 dB over the same four prompts. The 40-step CFG trajectory amplifies any rounding difference to that level, so the e2e number shows only that the change stays inside the band every rounding change lands in.

CI: `ltx_2_two_stage_t2v` (2xH100) runs the lossless default, so its prompt cross-attention changes kernel on Hopper as well. Its consistency threshold is PSNR 30 dB, tighter than the band above, so its GT likely needs a refresh with this PR (`diffusion-ci-gt-gen.yml`). The LTX-2.3 cases pass no prompt mask and are unaffected.

## Speed Tests and Profiling

Kernel times above. Together with the FA4 routing for sub-tile sequences (separate PR), stage-1 steps go from 51.5 ms to 48.5 ms (synced stage timing, on top of the prompt K/V PR).
