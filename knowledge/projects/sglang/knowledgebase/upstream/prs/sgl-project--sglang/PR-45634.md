# [Perf] mem_cache: Skip unchanged chunk checkpoint row rewrites

[Upstream PR](https://github.com/sgl-project/sglang/pull/45634) · state: closed · merged: False

## Original PR description

## Motivation

An unfinished chunk checkpoint reconstructs the full tree index path and writes the request row even when insertion adopted the request's existing indices unchanged. Skip that redundant work when the matched prefix does not extend beyond the already protected prefix.

## Modifications

Keep the existing rebinding path for newly duplicated prefixes, finished requests and session caching. Preserve full inserted-length protection for SWA tombstones and retain the early return for rotation-tail rejection. This covers unfinished chunks; #43600 separately optimizes finished-request bookkeeping.

Add regression coverage for unshared inserts, successive chunks and duplicate-prefix adoption.
