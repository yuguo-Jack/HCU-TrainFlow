## Motivation
MiniMax-M3 silently ignored enabled thinking and rejected disabled thinking on the Anthropic Messages endpoint.
Fixes #43146.

## Modifications
Set `thinking_mode` to `"enabled"` or `"disabled"` in `apply_reasoning_enabled`, matching the read path and preserving existing template kwargs.

Add a regression test covering both modes.
