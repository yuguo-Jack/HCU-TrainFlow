# [CI] [AMD] diffusion: Skip the CUDA-only gpu-idle and Z-Image RoPE cache unit tests on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/46449) · state: closed · merged: True

## Original PR description

## What

Two diffusion unit tests that were added recently fail on ROCm. This change makes both of them skip the NVIDIA-only parts there:

- `test_ci_gpu_idle.py` imported `pynvml` at module level. ROCm images do not ship pynvml, so pytest fails to collect the file, and the collection error stops the whole unit-test step. The import now happens inside `test_gpu_idle_with_real_cached_allocation_and_other_process`, which is already skipped when `torch.version.cuda` is None. The mock-based test still runs on ROCm.
- `test_zimage_rope_cache.py` skipped only when `torch.cuda.is_available()` was False, and that is True on ROCm. `ZImageTransformer2DModel._get_rope_cache` returns `(None, None)` whenever `current_platform.is_cuda()` is False, so on ROCm the tests passed `None` into `torch.equal`. The class skip now uses the same platform check as the model.

## Why

The tests were added in #46025 and #46044. On the AMD multimodal-gen 1-GPU stage (rocm10 lane), they fail as follows:

- https://github.com/sgl-project/sglang/actions/runs/40171515273/job/121103200052 fails with `ERROR collecting sglang/multimodal_gen/test/unit/test_ci_gpu_idle.py` and `No module named 'pynvml'`.
- https://github.com/sgl-project/sglang/actions/runs/40171515273/job/121103200056 has 2 failures in `test_zimage_rope_cache.py`, both `TypeError: equal(): argument 'input' (position 1) must be Tensor, not NoneType`.

On main, these failures are currently hidden behind the Wan DiT import error that #46393 fixes.

## Test plan

- [x] `python -m py_compile` on both files.
- [x] Passed on MI300 (rocm10) in a dispatched `multimodal-gen-test-1-gpu-amd` run on this commit plus the Wan import fix (#46393/#46396), so collection gets past the existing error: https://github.com/sgl-project/sglang/actions/runs/40212339099
  - Partition 3 (https://github.com/sgl-project/sglang/actions/runs/40212339099/job/121226154409): `test_ci_gpu_idle.py` now collects. Both mock cases passed, the NVIDIA-only case skipped, and the unit step reported 1440 passed.
  - Partition 0 (https://github.com/sgl-project/sglang/actions/runs/40212339099/job/121226154359): both `test_zimage_rope_cache.py` cases skipped, and the unit step reported 1591 passed.
  - Partition 1's only failures are three `test_nomas.py` cases, added on main by #46124 and unrelated to this change.
- No behavior change on CUDA: both tests still run when `current_platform.is_cuda()` is True and pynvml is installed.
