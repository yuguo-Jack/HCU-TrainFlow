# feat(minimax-m3): integrate FlashInfer source MSA

[Upstream PR](https://github.com/sgl-project/sglang/pull/35731) · state: closed · merged: False

## Original PR description

## Motivation

MiniMax-M3 currently has an SM100 sparse-attention path, but it cannot consume the source-distributed FlashInfer MSA kernels from [flashinfer-ai/flashinfer#4355](https://github.com/flashinfer-ai/flashinfer/pull/4355). This change adds that integration for the released TP4, top-k 16, head-dim 128 configuration while preserving the existing backend as the A/B baseline.

## Modifications

- Add a `flashinfer` MiniMax-M3 MSA backend selected with `SGLANG_MINIMAX_MSA_BACKEND=flashinfer`.
- Route prefill, eager decode, and fixed-request CUDA Graph decode through the public FlashInfer source API, with persistent per-batch-size plans and page tables.
- Keep unsupported shapes and modes fail-closed, including explicit handling for page size, dtype, speculative decode, and variable-request graph capture.
- Add a reproducible three-repetition A/B harness with fresh servers, alternating order, fixed 32K/64K outputs, GPQA Diamond, a balanced 100-example LongBench-v2 slice, and 8K-to-1K serving sweeps at concurrency 1/8/32/128.
- Add public-contract and repetition-summary unit tests plus end-to-end validation documentation.

## Accuracy Tests

- `pytest -q test/registered/unit/test_minimax_msa_public_contract.py`: 7 passed.
- First baseline repetition: fixed short, 32K, and 64K expected outputs matched exactly; GPQA Diamond (198 examples) scored 0.7626; balanced LongBench-v2 (100 examples) scored 0.69.
- The full three-repetition candidate-vs-baseline gate is running on 4x GB300. It requires exact fixed-output parity and no candidate accuracy regression in either GPQA Diamond or LongBench-v2 for every paired repetition.

## Speed Tests and Profiling

- The 4x GB300 TP4 A/B run is in progress. Each backend uses a fresh server and identical 256-request, 8192-input/1024-output token-ID workloads at concurrency 1, 8, 32, and 128.
- Final per-repetition throughputs, medians, and speedups will be posted before this PR is marked ready.
