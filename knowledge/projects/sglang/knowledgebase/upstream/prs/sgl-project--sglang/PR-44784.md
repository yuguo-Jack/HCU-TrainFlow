# [Perf] mistral: Resume the compact-format JSON scan while streaming (34 KB args: 2.6 s to 43 ms)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44784) · state: open · merged: False

## Original PR description

When a Mistral model streams a tool call in the compact format (`[TOOL_CALLS]name[ARGS]{...}`, used by the newer Mistral, Magistral and Devstral templates), `MistralDetector.parse_streaming_increment` calls `_try_parse_compact_args_format` on every delta, and `_extract_json_value` walks the whole arguments buffer character by character in Python to see whether the JSON value has closed yet. The work per delta grows with the arguments already received, so a long call is quadratic: streaming 34 KB of arguments in 4 character deltas takes about 2.6 s of parser CPU on the event loop.

This change keeps the bracket/string scan state (depth, in_string, escape_next) of the last incomplete scan together with the text it covered. On the next call, if the new text still starts with that text and the JSON value starts at the same offset, the scan resumes from where it stopped instead of starting over. The check is a single `str.startswith`, and any other input falls back to the full scan, so results do not depend on how the text was chunked. The state is dropped as soon as a value closes.

Measured with the detector alone, median of 5 runs, 4 character deltas: 2.2 KB of arguments goes from 11.5 ms to 1.1 ms (10.7x), 8.5 KB from 167 ms to 5.3 ms (31.7x), 17 KB from 647 ms to 14.3 ms (45x) and 34 KB from 2622 ms to 42.6 ms (62x).

To check that behaviour is unchanged I ran the old and new detector side by side on 5000 random streams (compact and JSON array calls, several calls per stream, unknown tool names, braces, brackets and escaped quotes inside strings, truncated output, 1 to 8 character deltas) and compared every emitted event plus `detect_and_parse`; there were no differences across about 255k call events. The existing function call unit tests give the same results before and after, and I added a test that streams compact calls with braces and escaped quotes inside strings in 3 character deltas.
