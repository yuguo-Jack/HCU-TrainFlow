# [Test] [NPU] HiCache: Reduce host memory allocation

[Upstream PR](https://github.com/sgl-project/sglang/pull/48101) · state: open · merged: False

## Original PR description

## Motivation

The NPU hierarchical cache test previously relied on default ratio-based host sizing, which can reserve substantially more host memory than its small cache-reuse workload requires. Limit the host cache allocation and align the NPU allocator configuration with the other HiCache tests.

## Modifications

- Set `--hicache-size` to 1 GB for `test_npu_hierarchical_cache.py`.
- Set `PYTORCH_NPU_ALLOC_CONF` to `expandable_segments:True,pin_memory_expandable_segments:True` while preserving the existing process environment.

## Accuracy Tests

Not run. This is a test-only configuration change and does not modify model execution. Python syntax validation with `ast.parse` passed.

## Speed Tests and Profiling

Not run. No inference-speed impact is expected from this test configuration change.
