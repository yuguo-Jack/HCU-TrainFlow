# [Fix] diffusion: Ensure deterministic VAE decode on ROCm for Qwen-Image 2.1

[Upstream PR](https://github.com/sgl-project/sglang/pull/47820) · state: open · merged: False

## Original PR description

## Summary

Fixes #47801

On ROCm 7.2.1 with RDNA3 GPUs (gfx1100), `F.scaled_dot_product_attention` uses the math backend when `head_dim > 256`. This backend is not run-to-run deterministic at sequence length 4096 (1024x1024 images), causing VAE decode to produce slightly different outputs for identical inputs.

This fix wraps the SDPA call with `torch.use_deterministic_algorithms(True, warn_only=True)` when on ROCm and `head_dim > 256`, ensuring bitwise reproducible outputs while maintaining performance for other configurations.

## Changes

- Modified `QwenImage21AttentionBlock.forward()` in `python/sglang/multimodal_gen/runtime/models/vaes/autoencoder_kl_qwenimage21.py`
- Added ROCm detection and conditional deterministic algorithm flag
- Preserves and restores the previous deterministic algorithm state
