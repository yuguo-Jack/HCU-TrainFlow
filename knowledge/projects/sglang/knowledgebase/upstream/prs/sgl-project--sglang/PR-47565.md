# [Perf] diffusion: Pipeline Ulysses attention over head groups down to three waves

[Upstream PR](https://github.com/sgl-project/sglang/pull/47565) · state: closed · merged: True

## Original PR description

## Motivation

The auto group count keeps only groups whose attention call fills four waves of 128-row tiles. The groups attend on their own streams, so a call's tail overlaps the next group's start, and the four-wave floor is higher than needed. MiniMax-H3 at Ulysses 4 (14 heads per rank) gets 2 groups at 1280x704 and 1344x768 because 7 two-head groups fill 3.5 and 3.9 waves, yet 7 groups are faster.

## Modifications

- Lower the floor from 4 to 3 waves. H3 now auto-selects 7 groups at both shapes; the case behind the old floor (Wan 1.3B, one-head groups, 1.7 waves) still stays sequential.
- Test assertions for the group counts at known shapes added to `test_ipc_a2a_multi_gpu.py`.

## Accuracy Tests

Head grouping does not change bits on the pipelined backends: MP4 md5 identical to main in every arm (6/6 on FA4, 4/4 forced-cuDNN).

## Speed Tests and Profiling

4x B300 (stand-in for B200), MiniMax-H3 T2VA, 49 forwards, fresh server per arm, ABBA, 1 warmup + 3 timed, server-side `inference_time_s`:

| | 1280x704 | 1344x768 |
|---|---|---|
| main | 26.72 s | 31.94 s |
| this PR | 26.55 s (-0.17) | 31.78 s (-0.16) |

B200 runs this attention through cuDNN rather than FA4, so I also forced cuDNN on the B300: main -> this PR + the alignment-row PR is -0.14 s at 704 and -0.23 s at 768, md5 identical.
