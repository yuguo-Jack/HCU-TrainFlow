# [CPU] Temporarily disable subblock sparse attention test on Xeon CI

[Upstream PR](https://github.com/sgl-project/sglang/pull/43468) · state: closed · merged: True

## Original PR description

## Summary
- Temporarily disable CPU CI registration of the subblock sparse attention test while preserving its test code.
- Restore the registration by 2026-10-24 after fixing the CUDA-only `vsa` import at module load.

## Why
The Xeon CPU-only runner fails during test collection: `test_subblock_sparse_attention.py` imports MiniMax H3, which imports `vsa`; `vsa` calls `torch.cuda.get_device_capability(0)` at import time and raises `AssertionError: Torch not compiled with CUDA enabled`. The failure predates this change: https://github.com/sgl-project/sglang/actions/runs/37914966645/job/113768924536?pr=43334

## Validation
- SGLang CI AST collector recognizes this file as disabled in `stage-a-test-cpu-intel`.
- `pre-commit run --files test/registered/cpu/test_subblock_sparse_attention.py` passes.
