# fix(tokenizer_manager): give each parallel sample a distinct seed

[Upstream PR](https://github.com/sgl-project/sglang/pull/28805) · state: closed · merged: False

## Original PR description

## Motivation

With deterministic inference enabled, an `n > 1` request gives every choice the same sampling seed, so parallel samples reuse one random stream. This reduces useful rollout diversity even though the caller asked for multiple samples.

## Modifications

Derive choice `j` from `base + j`, wrapping within signed 64-bit arithmetic. The base is the explicit seed or the existing deterministic default of `42`; omitted seeds stay unset outside deterministic mode. Python native/OpenAI and Rust Chat/Completions follow the same rule, with offsets restarting for each prompt. Distinct streams can still produce identical text.

Validate public seeds as signed 64-bit values and carry the deterministic flag through the Rust server's typed startup handoff. Update the deterministic-inference docs and cover seed boundaries, Python batch expansion, and Rust HTTP-to-scheduler dispatch.

## Accuracy Tests

All 69 Rust OpenAI tests passed, including the seed boundary and actual HTTP dispatch regressions. GPU inference was not run on this CPU host.

To prevent potential out-of-range or overflow errors when the offset seed is passed to PyTorch or CUDA backends (which typically expect a 64-bit unsigned integer), it is safer to wrap the seed using a bitwise AND operation with `0xFFFFFFFFFFFFFFFF` (or modulo `2**64`). This ensures the seed remains a valid 64-bit unsigned integer even if the base seed is close to the maximum limit.

```suggestion
def _seed_for_parallel_sample(
    sampling_params: SamplingParams, sample_index: int
) -> SamplingParams:
    """Offset the seed for the sample_index-th parallel sample (unseeded: as-is).

    multinomial_with_seed hashes sampling_seed, so without this an n>1 request
    with a fixed seed yields N identical completions.
    """
    if sampling_params.sampling_seed is None:
        return sampling_params
    offset = copy.copy(sampling_params)
    offset.sampling_seed = (offset.sampling_seed + sample_index) & 0xFFFFFFFFFFFFFFFF
    return offset
```

```suggestion
    def test_seeded_samples_get_offset_seeds(self):
        base = SamplingParams(sampling_seed=42)
        seeds = [_seed_for_parallel_sample(base, j).sampling_seed for j in range(4)]
        self.assertEqual(seeds, [42, 43, 44, 45])
        # The base params must not be mutated.
        self.assertEqual(base.sampling_seed, 42)

    def test_large_seed_wrap_around(self):
        base = SamplingParams(sampling_seed=2**64 - 1)
        seeds = [_seed_for_parallel_sample(base, j).sampling_seed for j in range(2)]
        self.assertEqual(seeds, [2**64 - 1, 0])

    def test_unseeded_sample_is_returned_unchanged(self):
```
