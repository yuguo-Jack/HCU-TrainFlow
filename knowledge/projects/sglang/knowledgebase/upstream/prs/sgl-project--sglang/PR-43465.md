# [Feat] [AMD] DeepSeek-v4.1: Support prefill context parallel

## Motivation

Prefill CP for DeepSeek-V4.1 already works on CUDA, but on AMD it's still blocked. 
Long prompts (e.g. 100k) are slow to prefill on plain TP8, this PR turns it on for AMD HIP platform, validated on gfx950.

## Modifications

- `deepseek_v4_hook.py`: stop rejecting V4.1 for prefill CP on HIP, including with `--enable-decoder-swa-bounded-replay` (V4 is still rejected).
- `deepseek_v4_backend_hip_radix.py`:
  - Add a HIP `_forward_low_ratio_sources_cp` instead of previous CUDA version:
    - Compressor: all-gather the prompt and let every rank compress all tokens, so each rank has the full main KV and indexer K. The full extend reuses the same fused kernel as non-CP cases.
    - Indexer: only score this rank's rows.
  - `_low_ratio_index_topk`: drop the assert that rejected `rows_per_request` and pass it down to the HIP indexer.
  - Add `_first_rows`: on gfx950 `q_lora` can be an FP8 activation wrapper that can't be sliced with `[:n]`.
  - Bounded-replay tail under CP:
    - Reuse CUDA's `_late_layer_tail_cp_layout` to build the tail's own CP layout.
    - `init_forward_metadata_prefill` takes an optional `cp_metadata` for the tail: pad `swa_replay_start` and reindex rows with `local_index`.
    - `enter_late_layer_tail` / `exit_late_layer_tail` swap in and restore the CP metadata and DP buffer length, and cut candidate masks by each rank's local tail rows.
- `low_ratio_backend_hip.py`: pass `rows_per_request` into the HIP indexer so it knows how many local rows each request has.
- `deepseek_v4.py`: with HIP CP, put the tail outputs (including DSpark aux) back into the rank's full layout, because the CP runner gathers by that layout.
- `interleave.py`: on HIP, skip CP when a rank would get fewer than 16 tokens. aiter's group32 MXFP8 GEMM returns NaN for `wqkv_a` (N=1792, K=5120) at M=5~8. Left a TODO to drop this once the kernel is fixed.
- Remove the stale "V4.1 is rejected on HIP" case from `test_platform_prefill_cp_deprecation.py`.

## Server Command
```
TP=${TP:-8}
CP=${CP:-8}
MODEL=${MODEL:-/data2/models/DeepSeek-V4.1-Flash}
MEM_FRACTION=${MEM_FRACTION:-0.85}
CHUNKED_PREFILL_SIZE=${CHUNKED_PREFILL_SIZE:-8192}
ENGRAM_HOST=${ENGRAM_HOST:-0}
CP_ARGS=""
if [ "${CP}" -gt 1 ]; then
    CP_ARGS="--enable-prefill-cp --cp-strategy interleave"
fi

echo "TP: ${TP}"
echo "CP_ARGS: ${CP_ARGS:-<无>}"
echo "MODEL: ${MODEL}  ENGRAM_HOST: ${ENGRAM_HOST}"
echo "MEM_FRACTION: ${MEM_FRACTION}"
echo "CHUNKED_PREFILL_SIZE: ${CHUNKED_PREFILL_SIZE}"

export AITER_BF16_FP8_MOE_BOUND=0
export SGLANG_ENABLE_DSV41_ENGRAM_HOST_TABLE=${ENGRAM_HOST}
export SGLANG_DSV41_ENGRAM_HOST_TABLE_LAYOUT=per_rank
export SGLANG_USE_ROCM700A=0
export TORCH_BLAS_PREFER_HIPBLASLT=1

sglang serve \
  --trust-remote-code \
  --model-path ${MODEL} \
  --tp ${TP} \
  --mem-fraction-static ${MEM_FRACTION} \
  --speculative-algorithm DSPARK \
  --speculative-dspark-block-size 5 \
  --enforce-shared-experts-fusion \
  --fp8-gemm-backend aiter \
  --cuda-graph-max-bs-decode 128 \
  --max-running-requests 128 \
  --enable-decoder-swa-bounded-replay \
  --cuda-graph-backend-prefill disabled \
  --chunked-prefill-size ${CHUNKED_PREFILL_SIZE} \
  --reasoning-parser auto \
  --tool-call-parser auto \
  --host 0.0.0.0 \
  --port 30000 \
  --json-model-override-args '{"vision_n_layers":0}' \
  ${CP_ARGS} ${EXTRA_ARGS:-}
```
