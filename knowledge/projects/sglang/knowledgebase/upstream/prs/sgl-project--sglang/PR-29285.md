# [Spec] Unify draft runner accessor naming and remove dispatch band-aids

[Upstream PR](https://github.com/sgl-project/sglang/pull/29285) · state: closed · merged: False

## Original PR description

Unify the draft model's `ModelRunner` accessor to `draft_runner` across spec-v2 workers and remove the three duck-typed naming-dispatch helpers (`_draft_runner_of`, `_get_draft_model_runner`, and the eagle draft cuda-graph-runner `hasattr` fallback). A single `draft_runner` property on `BaseSpecWorker` now exposes the draft runner (None for NGRAM).

## Code Review

This pull request standardizes the speculative decoding codebase by renaming `draft_model_runner` to `draft_runner` across multiple files, simplifying runner retrieval, and removing redundant helper functions. The feedback suggests adding defensive checks (using `getattr`) when accessing `draft_runner` on draft workers to prevent potential `AttributeError` or `NoneType` errors, and directly using internal runners (like `self._draft_worker.model_runner` or `self.model_runner`) during initialization phases instead of relying on indirect properties.

If `dw.draft_runner` is `None` (or if `dw` does not have a `draft_runner` attribute), this code will raise an `AttributeError` when attempting to set `r.device_timer = timer`. To prevent potential runtime crashes, use `getattr` defensively and check if each runner is not `None` before accessing its attributes.

```suggestion
                runners = getattr(dw, "draft_runner_list", None) or [getattr(dw, "draft_runner", None)]
                for r in runners:
                    if r is not None:
                        r.device_timer = timer
```
