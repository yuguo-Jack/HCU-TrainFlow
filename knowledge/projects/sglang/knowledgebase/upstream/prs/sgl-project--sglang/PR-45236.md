# [CI] radix-cache: Split unified radix cache unit tests into topic files and a shared kit

[Upstream PR](https://github.com/sgl-project/sglang/pull/45236) · state: closed · merged: True

## Original PR description

- Split `test/registered/unit/mem_cache/test_unified_radix_cache_unittest.py` into six topic files under `test/registered/unit/mem_cache/unified_radix_cache/`: core, hicache, insert walk, KV events, load-back, and storage. `test_unified_radix_cache_rust.py` reruns all six on the Rust tree core and replaces `test_rust_unified_radix_cache_unittest.py`.
- Move the shared fixtures, fakes, config matrix, and tree-core inspectors into the `python/sglang/test/kits/unified_radix_cache/` kit, which has `config`, `fixtures` (builders and node accessors), `mixins` (shared test steps), and one module per topic. Test files keep only the tests.
- Declare each test's config needs with `requires_*` decorators. A config a test does not support is no longer generated, so it no longer shows up as a skipped case.
- Share the helpers that tests had repeated: match, storage dirs, in-flight requests, and buffer and file L3 storage fixtures.
- Point the downstream tree-core, linker, write-back ordering, and Mamba path-cap tests at the kit, and update `scripts/ci/rerun_test_groups.json` to the new paths.
- No behavior change: every test case that ran before still runs with the same outcome. The 1,211 config cases that were always skipped are no longer generated.
