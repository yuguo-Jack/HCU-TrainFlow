# [Perf] Add packed BF16 prefill for DeepSeek-V4.1 on B200/B300

[Upstream PR](https://github.com/sgl-project/sglang/pull/41512) · state: open · merged: False

## Original PR description

## Motivation

At TP4, DeepSeek-V4.1 has 16 attention heads per GPU, while stock BF16 sparse prefill computes a 64-head tile per query. This integrates the packed kernel from https://github.com/sgl-project/FlashMLA/pull/14, which fills that tile with four queries.

Depends on [FlashMLA #14](https://github.com/sgl-project/FlashMLA/pull/14). Update the FlashMLA dependency to the merged commit before merging this PR.

## Modifications

- Enable packing by default for the target model on B200 and B300 with 16 local heads and no attention context parallelism. Set `SGLANG_DSV41_PACKED_PREFILL=0` to disable it.
- Use packing from 512 query tokens for SWA and 4,096 for mixed attention, with stock attention below those thresholds. Both thresholds are configurable through the documented environment variables.
- Wire the FlashMLA packed API into SGLang’s Blackwell build and skip unused statistics conversions during serving.

## Accuracy Tests

20 CPU dispatch tests pass, including default-on and opt-out behavior. The GPU suite passes all 19 tests on B200 and B300, covering numerical agreement, partial groups, CUDA Graph replay, invalid inputs and the output-only path.

Full-model validation on 4×B200:

- All 756 real-attention comparisons passed, including partial groups, multiple requests and a 256K prefix.
- GSM8K: stock 90.67%, packed 90.75% across 1,319 questions.

[Validation methodology and numerical results](https://gist.github.com/vineelbhat/975eb2f42e0bdf9596c4fdf3f6ccf84f#file-sglang-quality-20260928-md).

## Speed Tests and Profiling

DeepSeek-V4.1-Flash on 4xB200 with TP4/EP4, 16K chunked prefill, and DSPARK. Each request prefills 16,384 new tokens and generates one token. p50 TTFT across 24 randomized-order stock/packed pairs per shape:

| Cached prefix | Stock p50 TTFT | Packed p50 TTFT | Change |
|---:|---:|---:|---:|
| 0 | 228.50 ms | 213.38 ms | -6.62% |
| 32K | 242.06 ms | 228.26 ms | -5.70% |
| 256K | 320.99 ms | 311.26 ms | -3.03% |

[Serving methodology and results](https://gist.github.com/vineelbhat/975eb2f42e0bdf9596c4fdf3f6ccf84f#file-sglang-serving-20260928-md). Kernel benchmarks are in the FlashMLA PR.

B300 kernel checks retain the same thresholds, with 1.98× speedup at 512 SWA queries and 1.28-1.96× at 4,096 mixed queries across the tested selection patterns. [B300 kernel validation](https://gist.github.com/vineelbhat/975eb2f42e0bdf9596c4fdf3f6ccf84f#file-b300-validation-20260928-md).
