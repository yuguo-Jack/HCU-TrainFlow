# [Feat] observability: Add configurable request log retention

[Upstream PR](https://github.com/sgl-project/sglang/pull/45617) · state: open · merged: False

## Original PR description

## Motivation

Request logs rotate hourly, but rotated files are never removed. Operators can now set a retention period for request log files; leaving it unset preserves the existing unlimited-retention behavior.

Fixes #41129

## Modifications

- Adds `--log-requests-retention-days` with positive integer validation.
- Deletes expired hourly rotations for the request logger at startup and every hour, including while the server is idle. Matching is limited to the logger's current `<hostname>_<rank>.log` filename and timestamp suffixes.
- Adds CPU regression coverage for deletion, filename isolation, unset behavior, and periodic cleanup without new log records.
- Related: #45343 changes request log filenames to include the process ID. This change follows the current `<hostname>_<rank>.log` naming; happy to rebase or adapt whichever change lands first.
