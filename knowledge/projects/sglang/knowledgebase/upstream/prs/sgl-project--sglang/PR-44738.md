## Motivation

Port the diffusion W8A8 support from #29048 into a separate PR. This adds online INT8 quantization for unquantized FP16/BF16 diffusion transformers on Ascend NPU. The SRT LLM and MoE changes from #29048 are outside this PR.

## Modifications

- Add `NPUOnlineW8A8DiffusionConfig` and its linear method: quantize weights after loading, dynamically quantize activations per token, and return outputs in the original FP16/BF16 dtype.
- Register `w8a8_int` for diffusion and forward `--quantization-ignored-layers` so selected layers stay in checkpoint precision.
- Reuse the shared Ascend dynamic INT8 linear backend, with optional RMSNorm and SwiGLU activation-quantization fusion and floating-point fallbacks.
- Update `--quantization` help and diffusion quantization documentation.

## Speed Tests and Profiling

User-reported MiniMax-H3 measurements transcribed from the three screenshots above, using an eight-NPU TP2/SP4 setup with Laser Attention and Cache-DiT enabled:

| Transformer precision | Denoising (s) | Decoding (s) | End to end (s) | Peak memory (MB) |
| --- | ---: | ---: | ---: | ---: |
| BF16 | 45.4250 | 4.1724 | 55.19 | 49,686 |
| W8A8 with exclusions | 39.0453 | 4.2005 | 49.91 | 45,110 |
| Full W8A8 | 41.8151 | 4.2087 | 51.01 | 34,440 |

The exclusion set is `token_refiner final_layer condition_proj adaln_proj`; the launch command above includes it. In these runs it gave the best reported audio quality and timing among the W8A8 configurations, at the cost of 10,670 MB more peak memory than full W8A8. The BF16 and full-W8A8 screenshots are dated October 19; the exclusion run is dated October 22. These are individual user runs, not a controlled repeated benchmark. No operator profiling or broader target-NPU accuracy suite is reported.
