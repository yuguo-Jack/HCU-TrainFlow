## Motivation

Port the diffusion W8A8 support from #29048 into a separate PR. This adds online INT8 quantization for unquantized FP16/BF16 diffusion transformers on Ascend NPU. The SRT LLM and MoE changes from #29048 are outside this PR.

## Modifications

- Add `NPUOnlineW8A8DiffusionConfig` and its linear method: quantize weights after loading, dynamically quantize activations per token, and return outputs in the original FP16/BF16 dtype.
- Register `w8a8_int` for diffusion and forward `--quantization-ignored-layers` so selected layers stay in checkpoint precision.
- Keep the W8A8 operations in the diffusion implementation without importing the SRT online-quantization module from #29048.
- Update `--quantization` help and diffusion quantization documentation.
