# [diffusion] comfyui: add FLUX.2 and FLUX.2 Klein to the integrated mode

## Motivation

The ComfyUI integrated mode has no adapter for FLUX.2 or FLUX.2 Klein.

## Modifications

- Checkpoint spec (`comfyui_checkpoints/flux2.py`) for ComfyUI's original BFL-layout file. The DiT geometry (hidden size, block counts, text width, guidance weights) is read from tensor shapes. The fused img/txt qkv is split, the halves of `final_layer.adaLN_modulation.1` are swapped, and `FluxConfig`'s existing name mapping covers the rest. fp8 / quantized files are rejected with an error.
- `Flux2Adapter` / `Flux2Executor`: flatten ComfyUI's 128-channel latent to tokens, build the position ids on the client so a stacked positive/negative batch works, apply `ReferenceLatent` conditioning (Klein editing, multiple references), and scale the 0..1 timestep to 0..1000. The family (dev, Klein distilled, Klein base) is chosen from the checkpoint through a small `pipeline_class_for` hook on the adapter.
- Three ComfyUI-only pipeline classes so the checkpoint spec and pipeline config are selected by pipeline name.
- The session cache now stores `condition_image_latent_ids` together with `image_latent`, so a restored reference latent always has its ids.
- Under `comfyui_mode`, the FLUX.2 denoiser takes the embedded guidance from the request, so `FluxGuidance` has an effect. It was ignored in favor of the pipeline config default. Other models are unchanged; Flux1 has the same gap and is left alone here.
- `flux2` in the `model_type` option, three example workflows (dev text-to-image, Klein text-to-image, Klein reference-image edit) and README notes.

## Accuracy Tests

- Same weights through ComfyUI's own `Flux` and through the SGLang DiT on CPU, with a stacked B=2 batch and two reference images of different sizes: max abs diff 2.4e-4 on outputs around 152 (guided) and 1.7e-4 on outputs around 71 (no guidance), about 1e-6 relative. Without the final-layer swap the same check is off by 99.5.
- GPU (L4), tiny random checkpoints through the real `Flux2Executor`: 5 of 5 pass (three families, stacked rows with reference images, request guidance reaches the worker).
- GPU (L4), real FLUX.2 Klein 4B distilled and base checkpoints, ComfyUI's loader vs this path on identical inputs: finite, cosine 0.9993 and 0.9992. Against an fp32 reference, ComfyUI's bf16 output is off by 4.1% (distilled) and 4.5% (base), and this path by 4.2% and 3.6%, so the difference is bf16 noise.
- Full `multimodal_gen` unit suite on a Mac vs clean `origin/main`: identical failure sets (176 failed, 10 errors on both, all environmental), 13 more tests pass on this branch.
- The new workflows validate against ComfyUI's real node definitions.

Not covered: FLUX.2 dev with real weights (60 GiB BF16, gated), sequence parallelism above 1, `torch.compile`, fp8 / quantized checkpoints (rejected), attention masks.

## Speed Tests and Profiling

No change to inference speed; this adds a new model path.
