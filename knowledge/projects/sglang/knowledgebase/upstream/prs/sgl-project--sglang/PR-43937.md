# [Fix] Relay multimodal embeddings for GLM-5.3-Flash PP speculative prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/43937) · state: open · merged: False

## Original PR description

## Motivation

GLM-5.3-Flash prepares vision-injected input embeddings on the first pipeline stage, but its MTP draft runs on the last stage. Without relaying these embeddings, multimodal draft prefill reaches `DeepseekModelNextN.embed_input_ids` with `mm_input_embeds=None` and raises an assertion.

## Modifications

Relay `mm_input_embeds` through the existing `PPProxyTensors` during EAGLE prefill, including intermediate stages. Restore the payload in the receiving stage's `ForwardBatch`, so the existing logits-output path supplies it to the draft worker.

The patch modifies the shared `Glm5NextForConditionalGeneration` wrapper in `glm5_next.py`. Reproduction and model-level validation were performed only with GLM-5.3-Flash; whether GLM-5.3 exhibits the same issue has not been established. Text-only, non-speculative, non-EAGLE, and decode paths add no embedding payload. No scheduler, attention kernel, or model-weight changes are included.

## Accuracy Tests

- Seven CPU regression tests pass with the fix; four fail against unmodified model-wrapper source. Coverage includes PP2/PP4 transport contracts, successive batches, auxiliary hidden states, and negative paths.
- Manual GPU smoke with GLM-5.3-Flash: two nodes with eight RTX 5090 GPUs each, TP8/PP2, FP8 KV, dual TileLang, EAGLE 5 steps / 6 draft tokens, chunk size 1024.
- A/B images use the same existing SM120 nightly runtime, with only the upstream model-wrapper file changed. Source baseline: `279f1fad907dd53044a7b68fcc45bd6a24467c9e`. This is not a full latest-main runtime qualification.
- Unmodified wrapper: automatic multimodal warmup fails on PP1 at `assert input_embeds is not None`; it cannot reach readiness for the explicit image request.
- Fixed wrapper: warmup passes; text control returns 391 for 17*23; a synthetic left-red/right-blue image is described correctly, including a repeated request and a 1281-token image-plus-text request spanning multiple chunks.

Actual distributed PP4 and cache-hit scenarios remain untested. Repeated image requests reported `cached_tokens=0`.

## Speed Tests and Profiling

No isolated communication-overhead benchmark yet. Only multimodal EAGLE prefill carries the additional embedding payload. Request timings are smoke-test observations, not performance claims.
