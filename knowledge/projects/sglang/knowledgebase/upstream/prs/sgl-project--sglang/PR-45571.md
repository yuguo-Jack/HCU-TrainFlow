## Motivation

- The NPU precise-test pipeline always runs the full base-b/base-c suites when the
  coverage-based recommendation is empty. When a PR only touches product code under
  `python/sglang/` and the baseline recommends nothing, those suite runs burn NPU
  runner hours without producing signal. An empty recommendation is only trustworthy
  in that case: changes to tests, scripts, or workflows are invisible to the coverage
  baseline, so those PRs must keep the full-suite fallback.
- `recommend-tests-from-coverage` still ran (downloading the OBS baseline and building
  the test-case map) after `pr-gate` had already failed — wasted work for a doomed run.
- The published `outputs.tar.gz` (~300 MB) bundled the raw per-test coverage data that
  only manual map rebuilds need, while the recommend job consumes just the covstub
  source tree; the raw data was also unreachable without shared-disk access.
- `setup-covstub` occupied an aarch64 NPU-pool runner with a CANN image selected by
  `set-image-config`, although it only does CPU work (tar + python).
- `coveragerc` omitted `python/sglang/test/` and `python/sglang/benchmark/`, so those
  module trees never entered the baseline map or the coverage reports.

## Modifications

- **Skip-all rule for empty recommendations**
  - `test_selector.py`: extract every changed path from the PR diff into
    `pr_changed_files.txt` (PR mode only).
  - `bucket_recommended_tests.py`: new `--changed-files` input; when nothing was
    recommended and every changed path is under `python/sglang/`, emit
    `should_run_<suite>=false` for all suites and surface an "All suites skipped"
    note in the step summary. Existing safety fallbacks (empty suite enumeration,
    failed step -> empty outputs) still yield full-suite runs.
  - `pr-test-npu.yml`: pass `pr_changed_files.txt` to the bucketing step.
- **Gate the recommend job on the PR gate**: `recommend-tests-from-coverage` now has
  `needs: pr-gate` and `if: !failure() && !cancelled() && ...`, so it is skipped once
  the gate fails.
- **Move `setup-covstub` off the NPU pool**: `runs-on: linux-amd64-cpu-4` with the
  fixed `ascend-ci/sglang:main-x86` image; dropped the `set-image-config` dependency
  (and its CANN image output); `pip` -> `python3 -m pip`.
- **Slimmer, split baseline artifacts**
  - `outputs.tar.gz` now packages only `outputs/covstub` (a few MB instead of ~300 MB).
  - Raw per-test coverage data is archived separately as `coverage-data.tar.gz`,
    uploaded as the `precise-test-coverage-data` artifact (14-day retention) and
    published to the shared disk (guarded, absent when no data was collected) for
    manual map rebuilds.
  - `htmlcov`/`htmlcov-npu` artifacts get `retention-days: 14`; the base-a coverage
    relay artifact drops from 7 to 1 day.
- **coveragerc**: stop omitting `*/sglang/test/*` and `*/sglang/benchmark/*` so those
  module trees are recorded in the baseline map and reports.
- Comment compression across `pr-test-npu.yml` and `coverage-collection-npu.yml`
  (no behavior change).
