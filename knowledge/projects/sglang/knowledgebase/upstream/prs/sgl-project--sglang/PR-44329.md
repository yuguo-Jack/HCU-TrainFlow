## Motivation

NPU diffusion startup emits warnings from CUDA-only features, legacy tensor serialization, and unsupported internal-format settings. This PR reduces unnecessary console output.

## Modifications

- Skip CUDA-only GELU fusion registration and numerics settings on NPU.
- Defer the MiniMax sparse-attention import until its backend is used.
- Use zip serialization for CPU tensors in worker configuration payloads.
- Avoid logging the same static fusion rejection repeatedly.
- Keep the existing numerics tests working on CPU. No new test cases are included.
