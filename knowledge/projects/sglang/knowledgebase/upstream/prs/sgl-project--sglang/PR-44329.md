## Motivation

NPU diffusion startup emits warnings from CUDA-only features, legacy tensor serialization, and an optional kernel package. Model loading also prints progress on every rank. This PR reduces that output and avoids enabling unsupported internal formats on Ascend 950 in the SRT initialization path.

## Modifications

- Skip CUDA-only linear+GELU fusion marking on NPU and apply CUDA numerics settings only on CUDA/ROCm. Keep the existing numerics tests runnable on CPU.
- Defer the MiniMax-H3 sparse-attention helper import until its backend is used.
- Use zip serialization for CPU tensors in worker configuration payloads.
- Cache static fusion rejections per model to avoid repeated checks and messages.
- Show component-loading progress only on rank 0.
- Import NPU kernel packages independently. Suppress only a missing top-level `custom_ops` package in diffusion; retain warnings for `sgl_kernel_npu` and other import failures.
- Use the context-free SoC query before rank selection and enable internal formats only for SoC versions below Ascend 950.
