# [Bugfix] Reject unsupported Qwen3 and FA3 DCP configurations

[Upstream PR](https://github.com/sgl-project/sglang/pull/39440) · state: closed · merged: False

## Original PR description

## Motivation

Qwen3 with TP2/DCP2 can fail during KV-cache writes because its projections produce four K/V heads while the cache expects eight.
FA3 also lacks the non-MLA DCP cache and attention handling.
These unsupported combinations currently reach execution instead of reporting a configuration error.

## Modifications

Reject `--dcp-size > 1` for `Qwen3ForCausalLM` and for non-MLA models that resolve either attention phase to FA3.
Raise a startup `ValueError` with `--dcp-size 1` as the workaround.
Use resolved backends so defaults and separate prefill/decode selections receive the same validation.

Add one regression test for Qwen3 with TP2/DCP2 and FA3.

## Accuracy Tests

No model or kernel changes.

## Speed Tests and Profiling

The change only affects startup validation.
