# [Fix] tests: Initialize DCP replay backend capability

## Original PR description

Initialize the DCP replay test backend's `skips_prefill_metadata_on_idle_dp_rank` capability to the `AttentionBackend` default (`False`). This prevents `test_replay_reuses_the_captured_gather_buffer` from raising `AttributeError` in CPU CI; production behavior and the test's buffer reuse assertions are unchanged.

Hi @BBuf, adding downstream CI evidence for this fixture correction, which has blocked two of my otherwise unrelated PRs. Thanks to mickqian for identifying and fixing it.

The failure in both cases is `TestDcpReplayMetadata.test_replay_reuses_the_captured_gather_buffer` raising:

```text
AttributeError: 'types.SimpleNamespace' object has no attribute
'skips_prefill_metadata_on_idle_dp_rank'
```

The mocked backend does not inherit `AttentionBackend`'s `False` default for this capability. Initializing it explicitly lets the replay test reach its existing buffer-reuse assertions without changing production behavior.
