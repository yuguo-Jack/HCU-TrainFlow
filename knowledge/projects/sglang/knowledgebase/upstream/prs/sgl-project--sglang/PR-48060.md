# [Feat] [Intel] diffusion: online MXFP8 on XPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/48060) · state: open · merged: False

## Original PR description

## Motivation

`--quantization mxfp8` on a bf16 checkpoint only has a Blackwell path; on Intel XPU every layer silently falls back to per-channel FP8.

## Modifications

On XPU, bf16 layers with K % 32 == 0 quantize to MXFP8 at load (sgl-kernel group-32 quantizer) and run oneDNN's block-scaled `torch._scaled_mm`; other layers keep the per-channel fallback, as on CUDA. `test_mxfp8_online_gemm.py` now also runs on XPU.

## Accuracy Tests

MXFP8 linear vs fp32 at Wan2.2-A14B 720p shapes: rel_l2 0.0375. Wan2.2-T2V-A14B 1280x720x81, 40 steps, with SageAttention V3: valid video, same scene as BF16 (PSNR 18.9 dB).

## Speed Tests and Profiling

1 Intel CRI card. Wan 720p linears (M=75600), quant + GEMM vs bf16: 1.23x (5120x5120) to 1.51x (FFN up). Wan2.2-T2V-A14B 1280x720x81, 40 steps, end to end with SageAttention V3: 1411.9 s -> 1274.8 s; transformer memory 26.6 GB -> 13.9 GB each.
