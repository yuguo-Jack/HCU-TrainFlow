# [Fix] scheduler: Drop prefill embedding overrides in `prepare_for_decode`

[Upstream PR](https://github.com/sgl-project/sglang/pull/45041) · state: closed · merged: True

## Original PR description

- `prepare_for_decode` clears `replace_embeds` and `replace_positions` along with `input_embeds`, so a request's `positional_embed_overrides` stop at its prefill instead of riding on the running batch into every decode step

Fixes a hang under DP attention: the stale overrides made the DP rank holding that request run its decode eagerly, so it entered a collective its peers never joined (reproduced with Qwen3-30B-A3B at TP 2, DP 2).
