# [Refactor] nemotron_h: Read the prefill shared expert's output from the caller's holder

[Upstream PR](https://github.com/sgl-project/sglang/pull/46551) · state: closed · merged: True

## Original PR description

- The Nemotron-H shared-expert break in the breakable prefill graph (`_launch_prefill_shared_expert`, with its capture stub `_capture_prefill_shared_expert`) returns nothing; the caller reads the output from `call.output`, on the `_PrefillSharedExpertCall` it creates before the break and passes as the last argument. Before, the break returned `call.output`, and at every replay the graph wrapper copied that tensor onto itself.
- `call.output` is the same tensor the break used to return on every path: the first eager run sets it in `launch`, the capture stub sets it inside the nested shared-expert graph, and each replay reruns that graph into it.
- No behavior change. The wrapper's replay copy was a copy of `call.output` onto itself, which `Tensor.copy_` skips (same storage, offset, strides and dtype), and nothing read the break's return value at replay.
- The changed path runs only for Nemotron-H prefill under the breakable CUDA graph on SM120; no test is added, since it needs that GPU.
