# [CI] test: Drop tests that never run in CI

[Upstream PR](https://github.com/sgl-project/sglang/pull/47603) · state: closed · merged: True

## Original PR description

- Remove the classes and methods that every CI lane skips through `skipIf(is_in_ci())`: `test_epd_disaggregation.py` (6 classes), `test_pp_single_node_extra.py` (2 classes, 2 methods), `test_mooncake_ep_small.py`, `test_disaggregation_hybrid_attention.py`, `test_disaggregation_hisparse.py`, `test_radix_attention.py`, `test_retract_decode.py`, `test_triton_sliding_window.py`, `test_generation_models.py`, `test_lora_moe_tp_logprob_diff.py`, `test_pp_gemma4.py`.
- `test_flashinfer_trtllm_fp8_fallback.py`: remove `TestBlockSizeDispatch`, which sat after `unittest.main()` and never ran. Its `deep_gemm` sub-case also fails on CPU runners, where DeepGEMM is not installed.
- Delete `unit/observability/test_cpu_monitor.py`, registered `nightly=True` in `base-a-test-cpu`, a combination no CI lane runs.
- `test_patch_tokenizer.py`: drop the same never-run nightly registration; the Intel CPU suite keeps running the file.
- Move the local-only triton and flashinfer classes of `test_spec_standalone.py` to `test/manual/spec/test_spec_standalone_backends.py`.
- Remove what the deletions left unused: `TestQwenPPAccuracy` (no tests left), `_has_nixl`, and two model constants.
- Drop 39 CPU unit-test cases that restate the implementation (an expected value copied from the function under test, a check that a mock was called, a test that overrides the method it calls) or repeat an assertion another case already makes, across 19 files under `unit/mem_cache`, `unit/models`, `unit/multimodal` and `unit/observability`; `TestTraceNullContext` goes with its only case.
- `unit/mem_cache/test_rust_tree_core.py`: its hash-backfill case is already run on the Rust tree core by `test_unified_radix_cache_rust.py`; move the remaining case (the Rust backend resolves, and its binding exposes no `inspect_*` method) into `test_tree_core_registry.py` and delete the file and its rerun-group entry.
- `test_longcat_flash_router_hpc_gemm.py`: remove `_assert_dispatches_to_hpc_gemm`, which no test calls.
- Kept on purpose: the `pass` override in `test_unified_radix_cache_kl_dsv4.py`, which stops that subclass from running an inherited test in CI, and the local-only classes in `test_quark_mxfp4.py`, which share a base class with the AMD cases in the same file.

No CI coverage loss: every removed case was skipped or unreachable in CI, or repeats an assertion that another case still makes, or restates the implementation.
