# [Test] tests: Fix tests broken by recent refactors and pytest helper collection

[Upstream PR](https://github.com/sgl-project/sglang/pull/46783) · state: open · merged: False

## Original PR description

## Motivation

Several tests fail under pytest after #36252, #21738 and #41280, or because module-level helpers named test_* are collected as tests.

## Modifications

- Port tests to the current APIs: runtime-context overrides, MultimodalProcessorOutput, run_sgl_eval.
- Rename test_* helpers so pytest stops collecting them.
- Skip Crusoe/KDA tests when their API key or server is absent.
- Set SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN for EAGLE3/DFlash drafts, as the speculative cookbook does.
- Add get/set_embed_and_head to Qwen2MoeForCausalLM (as in Qwen2) for EAGLE drafts.
- Return 0 instead of NaN from the dump comparator for all-zero tensors.

## Accuracy Tests

No model forward or kernel change.
Complete changes were test on A100 backend device environment.

## Speed Tests and Profiling

N/A, test-only change.>
