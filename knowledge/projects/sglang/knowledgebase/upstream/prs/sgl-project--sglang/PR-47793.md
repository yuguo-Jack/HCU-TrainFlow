# [Test] deterministic: Isolate backend arguments and fix sampling coverage

[Upstream PR](https://github.com/sgl-project/sglang/pull/47793) · state: open · merged: False

## Original PR description

## Motivation

Continues #30905 after inactivity closure; GitHub rejected reopening it. Current main still shares mutable server arguments between deterministic-test classes and sets the single-request sampling temperature after running the test.

## Modifications

Make common arguments immutable and return independent lists for every backend, including the new XPU case. Configure temperature before execution and tolerate cleanup after a failed server launch. Keep the regression scope in the test harness.

## Accuracy Tests

Four CPU harness regressions pass. Restoring the upstream helper makes three regressions fail (argument ownership, temperature ordering and failed-launch teardown). GPU/model-output runs remain pending upstream; no new GPU result is claimed.

## Speed Tests and Profiling

Test-only change; no serving performance claim.
