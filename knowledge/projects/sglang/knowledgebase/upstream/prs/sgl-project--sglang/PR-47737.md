# [Fix] disaggregation: Use the shared ZMQ context for staging prefetch sockets

[Upstream PR](https://github.com/sgl-project/sglang/pull/47737) · state: closed · merged: True

## Original PR description

## Motivation

`prefetch_staging_reqs` creates a new `zmq.Context()` for every decode endpoint it first talks to and never terminates it, so a prefill keeps one extra libzmq I/O thread per distinct decode endpoint for the life of the process. The sockets are already cached per endpoint; only their context leaks.

## Modifications

Create the prefetch sockets from `zmq.Context.instance()`.
