# [CI] [AMD] diffusion multimodal-gen-test: diffusion: give the native-encoder restoration test a single-process model-parallel group

[Upstream PR](https://github.com/sgl-project/sglang/pull/45764) · state: closed · merged: False

## Original PR description

### What
fix [multimodal-gen-test-1-gpu-amd (rocm10, linux-mi300-1gpu-sglang, 1)] fail
`test_native_encoder_restoration_checks_checkpoint_before_fallback` now requests the
`single_process_model_parallel` fixture that `test/unit/conftest.py` already provides.

### Why

The test exercises `TextEncoderLoader.load(...)`, whose customized path reads the
distributed groups:

- `text_encoder_loader.py:549` -> `get_encoder_data_parallel_group()` -> `get_world_group()`
  -> `assert _WORLD is not None` -> **`AssertionError: world group is not initialized`**
- one layer deeper, `text_encoder_loader.py:701` -> `get_folding_tp_group()`
  -> **`AssertionError: tensor model parallel group is not initialized`**

Nothing in the test sets up a process group, so the customized path raises, the loader
falls back to the native path, and the test's own
`mock.patch.object(loader, "load_native", side_effect=AssertionError("fallback"))`
sentinel fires. pytest reports the sentinel (`AssertionError: fallback`), which hides the
real cause one frame above it -- the test never reaches what it actually asserts, namely
that the checkpoint is validated *before* any fallback.
