# [Fix] Fallback to unquantized linear method for Qwen3.5 GDN in_proj_ba (#38854)

[Upstream PR](https://github.com/sgl-project/sglang/pull/39741) · state: open · merged: False

## Original PR description

Fixes #38854

### Motivation
When serving Qwen3.5 / Qwen3.6 GDN models (such as `XReyRobert/Qwopus3.6-27B-v2-GPTQ-Pro-v1`) with GPTQ / Marlin quantization, `in_proj_ba` has `num_v_heads = 48`, leading to total output dimension $N = 96$ ($48 \times 2$). Marlin requires `size_n % 64 == 0`. Because $96 \% 64 = 32 \neq 0$, quantizers (GPTQModel, AutoGPTQ) skip quantizing `in_proj_a` and `in_proj_b`, leaving them as unquantized BF16 weights in checkpoints.

Previously, SGLang built `in_proj_ba` as a GPTQ Marlin layer unconditionally, causing:
1. `Parameter ...in_proj_ba.weight not found in params_dict` (logged 96 times) as the BF16 weights were dropped.
2. `gptq_marlin_repack` crash during weight postprocessing (`size_n = 96 is not divisible by tile_n_size = 64`).

### Modifications
1. **Marlin Shape Divisibility & Fallback**:
   - In `python/sglang/srt/layers/quantization/marlin_utils.py`, enhanced `check_marlin_supports_layer` to accurately assess partition sizes with `tp_size` even before partition attributes are bound.
   - In `python/sglang/srt/layers/quantization/gptq/gptq.py`, updated `GPTQMarlinConfig.get_quant_method` to check `check_marlin_supports_layer(layer, self.group_size)` and fallback to `UnquantizedLinearMethod()` when partition dimensions are not divisible by Marlin tile requirements.
2. **Model Architecture Safeguard**:
   - In `python/sglang/srt/models/qwen3_5.py` and `python/sglang/srt/models/qwen3_next.py`, updated `create_ba_proj` to clear `quant_config` if partition size is not divisible by 64 under GPTQ / Marlin.
3. **Fused Shard Mapping**:
   - Added `"in_proj_ba": ["in_proj_b", "in_proj_a"]` and `"in_proj_qkvz": ["in_proj_qkv", "in_proj_z"]` to `_FALLBACK_FUSED_SHARDS` in `python/sglang/srt/layers/quantization/utils.py`.
   - Supported candidate shard checks in `get_dynamic_override`.
4. **Unit Tests**:
   - Added `test/registered/unit/models/test_qwen3_5_gdn_gptq_unquant_fallback.py` verifying shape validation, method fallback, dynamic override matching, and simulated sharded weight loading.
