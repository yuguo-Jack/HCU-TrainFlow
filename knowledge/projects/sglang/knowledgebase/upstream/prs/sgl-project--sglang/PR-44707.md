# [Doc] cookbook: Add RTX Spark Qwen3.6 NVFP4 recipe

[Upstream PR](https://github.com/sgl-project/sglang/pull/44707) · state: closed · merged: True

## Original PR description

Add a user-tested launch recipe for `nvidia/Qwen3.6-35B-A3B-NVFP4` on NVIDIA RTX Spark to the existing Qwen3.6 cookbook page. The config uses the shared Deployment component and preserves the reported command, including `extra_buffer`, memory fraction `0.8`, and `flashinfer_cutlass`.

The contributor reports **75 output tokens/s for a single request on SGLang `main`**. The page records this as generation speed; no P50 TPOT or aggregate throughput is inferred. The exact commit, workload lengths, runtime, and device memory configuration were not supplied. The nightly Docker fallback is labeled separately from the tested environment.

RTX Spark is declared in this model's `config.hardware`; hardware naming and published platform specifications are sourced from [NVIDIA](https://www.nvidia.com/en-us/products/rtx-spark/). This adds only the scoped recipe and does not migrate the existing legacy selector (the broader migration is already covered by #32959).
