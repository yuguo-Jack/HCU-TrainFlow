# [Doc] [Ascend] support-matrix: drop ngram match-window flags removed in #21225

[Upstream PR](https://github.com/sgl-project/sglang/pull/43662) · state: open · merged: False

## Original PR description

## Motivation

`--speculative-ngram-min-match-window-size` and `--speculative-ngram-max-match-window-size` were removed in #21225, but the Ascend support matrix (`docs/docs/hardware-platforms/ascend-npus/reference/support_features.mdx`) still lists them as supported server arguments. Passing either flag now fails at argument parsing.

## Modifications

- Remove the two rows from the speculative-decoding table of the Ascend support matrix. The remaining ngram rows match `python/sglang/srt/arg_groups/fields/spec.py`.

(The `--log-request-level` / `--target-lora-modules` typos in the same family of docs are already fixed by #38055, so they are not repeated here.)
