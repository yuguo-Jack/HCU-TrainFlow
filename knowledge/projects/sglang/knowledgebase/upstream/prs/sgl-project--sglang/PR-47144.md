## Motivation

The DeepSeek-V4-Pro B200 TP8 aggregate AgentX recipe points to a pruned nightly image, so it does not document the image measured by [InferenceX #4556](https://github.com/SemiAnalysisAI/InferenceX/pull/4556). This is the remaining cookbook coverage gap identified by its [Check 3 verdict](https://github.com/SemiAnalysisAI/InferenceX/pull/4556#issuecomment-6477569268).

## Modifications

- Update the existing aggregate c1/c4/c8 recipe to `lmsysorg/sglang:v0.5.22-cu130@sha256:e3a4f06001a29542fc4a8638536d9ffc5eb9c9942b08603c09b19a56eae4a1ae`, verified available on Docker Hub. The image records SGLang build `baa9befa381511cd4d56f83980951e5a45fffc6d`.
- Record the authorized sweep, recipe selectors and measured job links for the three aggregate and eight existing disaggregated points. The configurations are mirrored from SemiAnalysis submissions; the disaggregated image remains v0.5.21.
- Preserve all serving commands, environment variables, router/KV choices and unrelated cookbook cells. Dynamo remains `1.5.0.dev20260914` for the aggregate recipe.
