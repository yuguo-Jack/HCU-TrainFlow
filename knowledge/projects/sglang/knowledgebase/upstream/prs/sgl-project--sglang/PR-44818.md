## Original PR description

> Based on the single-token tri-projection slice. Review `6f603ba82b` (597 lines). Compare: https://github.com/yuychang/sglang/compare/up/b5a-tri-projection-b1...up/b5b-tri-projection-multitoken


## AITER prerequisites

None. This kernel is compiled from the SGLang tree. It only imports AITER FlyDSL helpers that are already on AITER main. [ROCm/aiter#6026](https://github.com/ROCm/aiter/pull/6026) is not used: the measured recipe compiles the vendored kernel (`SGLANG_OPT_HIP_K3_FLYDSL_SOURCE=sglang`).

## Modifications

- Add the gfx950 FlyDSL tri-projection kernel for more than one token.

The kernel builder stays one function because it is one kernel construction.
