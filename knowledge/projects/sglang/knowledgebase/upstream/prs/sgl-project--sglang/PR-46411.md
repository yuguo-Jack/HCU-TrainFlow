# [Refactor] multimodal: [MM refactor 5/9] Add a token-space multimodal processor

[Upstream PR](https://github.com/sgl-project/sglang/pull/46411) · state: open · merged: False

## Original PR description

## Motivation

The HF processor expands placeholders in the prompt text and tokenizes it again. RL and multi-turn callers already hold exact token IDs, and the trainer needs the same media features without a server.

## Modifications

- `expand_token_placeholders` replaces placeholder tokens with media tokens directly in the IDs.
- `TokenSpaceProcessor`, shared by trainer and serving, runs a per-model `TokenSpaceProcessStrategy`: process each media item, merge, expand, and return a `BatchFeature` with each media's `mm_spans`.
- Each call takes the media, the IDs and named options (devices, `compute_mrope_positions`), with no request kwargs; a trainer passes `worker_thread_device` to start the worker threads on its CUDA device.
- A registry maps architectures to strategies; nothing is registered yet.

## Tests

`test_mm_token_expansion.py` and `test_token_space_registry.py`.
