# [DCP] HiCache L2 for DSA models with MTP under decode context parallelism

[Upstream PR](https://github.com/sgl-project/sglang/pull/44122) · state: open · merged: False

## Original PR description

Follow-up to #43735. DSA models with EAGLE MTP can now enable `--enable-hierarchical-cache` with `--dcp-size > 1` (L2 only; L3, PD, HiSparse and LMCache stay rejected).

- The DSA index-K cache is replicated across DCP ranks, so its host mirror now spans the anchor's widened (logical) slot space instead of the per-rank rows, and addresses the device index without rank translation.
- Under DCP the MTP draft is registered as a sidecar host pool (the existing DSpark path, sized to logical slots) instead of being packed into the sharded KV rows.
- The HiCache DCP launch rule admits DSA MTP; the sidecar host-size estimate counts the widened slots.

Tests: a CPU unit case for the indexer host pool sizing in `test_hicache_dcp_host_pool.py`, and `test/registered/dcp/test_glm53_dcp2_hicache.py` (GLM-5.3-NVFP4 TP4 DCP2 MTP with HiCache L2: GSM8K plus the multi-turn KL cache-hit suite, bf16 KV, widened-page cache asserts).

Validation on 8xB300, GLM-5.3 FP8, TP4 DCP2 + MTP, bf16 KV, multi-turn KL (logprobs_match / prefill_hit / decode_hit):
- no HiCache: 0.015 / 0.013 / 0.013
- HiCache with forced host reloads (16k-token device pool, 26k tokens served from host): 0.012 / 0.016 / 0.013
- HiCache, normal pool: 0.019 / 0.015 / 0.016, GSM8K 0.930 (0.925 with fp8 KV)
