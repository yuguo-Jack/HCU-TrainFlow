# [Test] mlu: Add Cambricon MLU rotary embedding regression

[Upstream PR](https://github.com/sgl-project/sglang/pull/41637) · state: open · merged: False

## Original PR description

## Motivation

Add Cambricon MLU coverage for SGLang rotary embeddings and connect the
existing `RotaryEmbedding` implementation to the FlagTree Cambricon Triton
RoPE kernel.

## Modifications

- Add MLU backend detection.
- Route `RotaryEmbedding` to the Cambricon Triton RoPE implementation.
- Avoid the CUDA/vLLM fallback path on MLU.
- Preserve packed token layout handling.
- Make cosine and sine cache tensors contiguous for the MLU kernel.
- Add an MLU regression test comparing the Triton path with the native path.
