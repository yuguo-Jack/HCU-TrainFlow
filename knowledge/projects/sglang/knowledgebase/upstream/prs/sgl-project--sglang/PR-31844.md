# [AMD] ci: enable nested unit tests behind LAPACK/msgpack env skips

[Upstream PR](https://github.com/sgl-project/sglang/pull/31844) · state: closed · merged: False

## Original PR description

**Stacked on #31843 → #31483** (review on top of those; diff collapses as they merge).

## What

Enable 2 more nested `unit/` files on AMD via an environment-capability skip, and harden one flat test against a missing optional dep.

| File | Change |
|---|---|
| `unit/sana_wm/test_pipeline_config.py` (5 tests) | `skipif` when torch lacks LAPACK — `torch.linalg.inv` in the camera-pose path. Runs on **ROCm 7.2.0 + CUDA**; skips on the ROCm 7.0.0 image. |
| `unit/sana_wm/test_realtime_chain.py` (1 test) | same LAPACK skip |
| `unit/test_pi05_action_api.py` (1 test, flat) | `skipif` when `msgpack` is unavailable (absent in the rocm720 image; present on CUDA / ROCm 7.0.0). Fixes a **pre-existing** rocm720 red, unrelated to the nested work. |

The 2 nested files are added to `_AMD_READY_NESTED_UNIT_TESTS` + `_MM_GEN_FILE_BACKENDS`. The flat msgpack file already runs via the flat glob (no allowlist change).

### Enable 2 nested unit files on AMD behind env-dependency skips

Now that #31483 and #31843 have merged, this is a standalone PR: **1 commit, 5 files, +59/-0**.

| Change | Why |
|---|---|
| `sana_wm/test_pipeline_config.py` (5 tests), `sana_wm/test_realtime_chain.py` (1 test) | skip when torch lacks LAPACK — the camera-pose tests call `torch.linalg.inv` |
| `test_pi05_action_api.py::test_msgpack_roundtrip...` | skip when the optional `msgpack` dependency is absent |
| `gpu_cases.py` + `ci_coverage_report.py` | add the 2 nested files to the AMD allowlist / coverage classifier |

AMD-only: `_discover_unit_tests()` returns just the flat `unit/test_*.py` glob unless `current_platform.is_hip()`, so the CUDA lane never collects these nested files and stays byte-identical. No production code is touched.
