# [Fix] hicache: Skip empty auxiliary transfers

[Upstream PR](https://github.com/sgl-project/sglang/pull/45673) · state: closed · merged: True

## Original PR description

## Motivation

A buffer-only HiCache restore can need sliding-window KV while the full-attention KV is already resident. A deferred draft transfer derived from the full-attention pool then resolves to empty host and device indices.

`HybridCacheController._l2_transfers` skips the empty anchor transfer but still submits the empty auxiliary transfer. The CUDA copy can consequently launch with zero blocks and fail with `CUDA error: invalid argument`.

For example, when the transfer sizes are `FULL=0, DRAFT=0, SWA=64`:

```diff
- Submit DRAFT(0) and SWA(64).
+ Submit only SWA(64), preserving layer-completion notifications.
```

## Modifications

Skip an auxiliary transfer only when both resolved index tensors are empty. Unresolved indices still raise, and one-sided empty pairs are not silently dropped.

Extend the existing CPU dispatch tests to cover SWA-only restores, normal FULL/DRAFT/SWA restores, layer-completion notifications, and invalid inputs.
