## Purpose

- Add `check_weights(action="raw_checksum", names=[...])` so a P2P sender can verify the exact tensor bytes received before post-load transformations.
- Return SHA256 checksums for the requested named parameters through the existing runner selector and checksum response structure.
- Existing actions retain their behavior; the new work runs only when callers request `raw_checksum`.
