# [Feat] MiniMax-H3: add an opt-in four-step SMD sampling preset

[Upstream PR](https://github.com/sgl-project/sglang/pull/44739) · state: open · merged: False

## Original PR description

This adds the opt-in `smd-ref2va-4step` sampling preset for native MiniMax-H3 Ref2VA releases. It uses the [released student's](https://huggingface.co/zjwfufu/SMD-MiniMax-H3-Ref2VA-4step) four-step grid, including the shorter final interval and video/audio shifts of 12/3. Matching student weights or LoRA must already be loaded through the existing path.

The preset validates requests before encoding, uses a prefix of the serving grid for warmup, and keeps its dedup identity separate. Default schedules and dedup keys stay unchanged. The cookbook shows how to enable it in release metadata.

The main-branch conflict is resolved while preserving Pika H3 Flex's stochastic-sampling metadata, bundled LoRA loading, and argument order. SMD remains deterministic and rejects DMD/PDD combinations in metadata and timestep-stage validation. The unchanged pipeline initializer can load environment-selected PDD heads before that stage guard; full-pipeline early rejection is not established by these checks.

Isolated CPU checks passed for the actual sampling, metadata, admission, and timestep-stage code, with serving-bootstrap/protocol dependencies substituted and conftest disabled. They cover the merged Pika fields, SMD with bundled adapter metadata, incompatible combinations, and unchanged defaults. Default 1/4/50-step grids at shifts 12 and 3, plus the default dedup key, match the merged main exactly. Affected-file Ruff, isort, syntax, and diff checks passed.

The normal package entry point was also attempted against the complete checkout:

```bash
python -m pytest python/sglang/multimodal_gen/test/unit/test_minimax_h3_smd.py -q
```

Collection stopped in conftest because the local environment lacks `diffusers`; no normal-package tests ran. Full pipeline creation, student loading, GPU generation, and audio/video quality remain unverified. This stays a draft, with no speed or quality claim.

AI assistance was used for implementation and validation.
