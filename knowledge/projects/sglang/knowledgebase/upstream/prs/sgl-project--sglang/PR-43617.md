# [HiCache] Batch direct DMA transfers and overlap safe restores

[Upstream PR](https://github.com/sgl-project/sglang/pull/43617) · state: open · merged: False

## Original PR description

HiCache's direct path plans and submits transfers per layer, and restores wait for the previous forward even when their destination pages are safe. Move copy planning into native code, batch transfers by logical layer block, and add opt-in overlap with the previous forward.

- Keep fused Mamba slot clear/copy working with page-major views and reuse `page_first_direct` for BF16/MXFP8 host storage.
- Plan and coalesce indexed copies in C++, cache stable layout metadata, and batch copies across supported static KV, SWA, Mamba, and draft pools. Preserve existing paths for other pools and runtimes.
- Add `--hicache-load-block-layers` (default `1`). Completion covers payloads, scales, and auxiliary pools; Mamba follows its mapped logical layers. Supported Inkling CUDA graphs use persistent block-wait events.
- Add `--hicache-restore-backward-overlap` (default off). Allocators track reuse of recently freed pages; those restores retain the forward fence. Existing WAR ordering protects metadata, and Mamba request slots use forward-stream copy-on-write.

The six commits separate layout support, native planning, block waits, draft/scales ordering, pooled submission, and backward overlap.

On a synthetic GB300 BF16 KV transfer (512 MiB, 32 layers, 4 layers/block), median restore CPU submission was **1.924 → 1.391 ms**. Transfer interval was **2.711 → 2.891 ms**, and backup CPU submission was **1.243 → 1.385 ms**. This case shows lower restore CPU cost, with no bandwidth or backup improvement; event intervals include CPU enqueue gaps.

Validation: the initial targeted export suite passed 547 tests. The final Mamba scheduling revision passed 198 targeted tests and 31 subtests, including Python/Rust Mamba restore and fence coverage. Formatting and docs checks passed. One simulated NPU configuration failure reproduced on unchanged upstream and was excluded from the initial suite. End-to-end model serving has not been rerun for this export.
