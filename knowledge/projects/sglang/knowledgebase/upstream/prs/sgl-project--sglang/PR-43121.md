## AITER prerequisites

- [ROCm/aiter#6260](https://github.com/ROCm/aiter/pull/6260) — the matching rocminfo and JIT boot fix inside AITER (empty `rocminfo`, live device properties, generic torch streams). #6203, #6204 and #6205 are the older split of the same work.

SGLang's memory-capacity read does not import AITER. AITER still fails its own device probe on these hosts without #6260.

## Motivation

`get_amdgpu_memory_capacity()` reads the VRAM size from `rocminfo`. On some hosts `rocminfo` stops before it prints the pool sizes. The server then fails at startup with `ValueError: could not convert string to float: ''` (empty output) or `RuntimeError: rocm-smi error` (non-zero exit), even though the GPUs work.

## Modifications

- Skip lines that `rocminfo` prints without a number.
- If no line has a size, read `total_memory` from the live HIP devices and log a warning.
- Keep the existing error when `rocminfo` is not installed.
- Add CPU unit tests for parsing, empty or failed `rocminfo`, and the no-device error.

## Accuracy Tests
