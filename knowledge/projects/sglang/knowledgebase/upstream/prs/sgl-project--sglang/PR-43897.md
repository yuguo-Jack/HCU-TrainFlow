# [Scheduler] Commit step results through an in-flight step queue

[Upstream PR](https://github.com/sgl-project/sglang/pull/43897) · state: open · merged: False

## Original PR description

Stacks on #43896

- New `InflightQueue` with a step-counted commit rule: a launched step's record is committed once its step is at least `depth` steps old. It replaces `result_queue` in the overlap loops and the `last_batch` gate in the non-overlap loops, for the normal, PD prefill, and PD decode loops.
- `SGLANG_DEBUG_INFLIGHT_STEPS=1` (off by default) checks the queue's bounds and commit order.
- The rank-local grammar overlap sync asserts that it never runs under DP attention.
- The unreachable `PREBUILT` run paths and checks are deleted (scheduler, DP attention, TBO, result processing).

No behavior change.
