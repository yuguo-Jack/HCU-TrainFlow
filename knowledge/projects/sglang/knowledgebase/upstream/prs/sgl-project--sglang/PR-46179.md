# [Perf] dsa: Overlap CP KV gather with indexer computation

[Upstream PR](https://github.com/sgl-project/sglang/pull/46179) · state: closed · merged: True

## Original PR description

## Motivation

Overlap attention KV replication with independent DSA indexer computation during interleave CP prefills. Submit KV all-gather as soon as local KV is ready, before indexer projection/compression/scoring, including short prefills that skip MQA/top-k.

## Changes

- Instantiate `DSAInterleaveCPIndexerOverlap` only for DSA interleave CP prefills. Non-CP execution calls the original indexer and KV preparation directly.
- Co-locate the shared orchestration in `cp/interleave.py` and the stable BCG output adapter in `cp/bcg/interleave_bcg.py`. Remove the two standalone overlap modules and the requested unit test.
- Preserve producer readiness, consistent cross-rank collective ordering, the consumer join, FP8 byte transport, and cross-stream storage lifetime.
- Preserve the input-staging fast path for valid contiguous shards, zero padding for uneven shards, and live prefix/padding handling for BCG replay.
- No new server flag or expansion of ordinary-DSA BCG eligibility.

Current candidate: `51cef168bcb0805017ef14220a5992748ae1e897`. The review changes are split into CP gating/rename/test removal (`aab307c818`) and a separately verified pure relocation (`51cef168bc`).
