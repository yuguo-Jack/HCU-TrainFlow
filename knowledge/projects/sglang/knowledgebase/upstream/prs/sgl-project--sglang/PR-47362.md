## Motivation

Bumps the AITER pin for the two gfx1250 build stages (`gfx1250-rocm1000` and
`gfx1250-rocm1010`) from `2bb549102` to `26f4f1fb2`. This is a **gfx1250-only**
change — the gfx942 / gfx950 / shared pins (`285579b6…`, 8 occurrences) are left
untouched.

## Modifications

```
docker/rocm.Dockerfile
  L347 (gfx1250-rocm1000)  AITER_COMMIT_DEFAULT  2bb549102… → 26f4f1fb2…
  L370 (gfx1250-rocm1010)  AITER_COMMIT_DEFAULT  2bb549102… → 26f4f1fb2…
```
