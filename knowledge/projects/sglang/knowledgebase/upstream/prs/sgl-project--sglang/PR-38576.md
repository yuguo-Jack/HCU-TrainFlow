## Motivation

Currently the CUDA 13.4 container is a seperate Dockerfile, but we can combine it and gate all 13.4 specific changes using conditionals to make the build more maintainable.

For now the image is still built with the `release-docker-cu134-nightly.yml` workflow, but we can merge it with the normal one later too.

## Modifications

* Use CUDA 13.4 base image from `nvidia/cuda` instead of building from developer preview. **This image is not yet released.**
* Build `+cu134` variants of sglang-kernel, sgl-deep-ep, sgl-deep-gemm against same torch 2.15 nightly as the container and publish to the sglang github index.
