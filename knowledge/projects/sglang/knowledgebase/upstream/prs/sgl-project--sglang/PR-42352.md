# [RL] Return replay outputs through a Mooncake output store

[Upstream PR](https://github.com/sgl-project/sglang/pull/42352) · state: closed · merged: False

## Original PR description

> **Depends on:** #42349
> Stacked on the parent PR's branch. Review / merge the parent first.

## Summary
Optionally return routed experts, indexer top-k, and sampling masks via Mooncake, not `meta_info`.

## Motivation
Routed experts, indexer top-k, and sampling masks travel inline in meta_info as base64 or lists. For long RL rollouts they dominate the response size, and the trainer reads them right back into arrays.

## Usage
```bash
python -m sglang.launch_server --model-path <model> --enable-return-routed-experts \
  --output-store-backend mooncake --output-store-backend-extra-config \
  '{"master_server_address": "10.0.0.1:50051", "local_hostname": "10.0.0.2",
    "local_buffer_size": "1gb", "key_prefix": "rollout"}'
curl -s localhost:30000/generate -d '{"text": "Hi", "return_routed_experts": true,
  "return_outputs_via_store": true}' | jq '.meta_info.output_store_ref.fields'
# {"routed_experts": {"dtype": "int32", "shape": [<tokens>, <layers>, <topk>]}}
```

## Design Notes
- **Mental model:** an opted-in request keeps its replay outputs as tensors in `ReqState`; at the final response, `TokenizerManager` writes them off the event loop as one `MooncakeBundleTransfer` dict bundle and returns `meta_info["output_store_ref"]` (exported handle plus per-field dtype, shape) for readers with the same `key_prefix`; other requests are unchanged.
- With the store enabled, the detokenizer forwards these tensors unencoded in two new `BatchStrOutput` fields; the tokenizer encodes them for requests that did not opt in.
- `OutputStore` writes any `OutputStoreStash` Protocol; `TokenReplayStash` implements it for replay outputs.
- Store calls follow Miles `MooncakeObjectStore` ([`object_store.py` at 5d8dda0](https://github.com/radixark/miles/blob/5d8dda0b1acf8593d39baddbf03c56ca08611764/miles/utils/object_store.py)), except that the server never contributes a segment, and the ref also carries field shapes.
- The store reads only its JSON config, not `MOONCAKE_*` env vars.
- Streaming, PD, a missing backend, or chat without `return_meta_info` are rejected; a failed put returns 500.
- A put cancelled mid-write removes its object; undelivered batch, `n>1`, or chat bundles remain.
