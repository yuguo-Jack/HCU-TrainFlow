# [Fix] deepseek-v4.1: Keep the DSpark draft SWA out of the radix tree

[Upstream PR](https://github.com/sgl-project/sglang/pull/44673) · state: closed · merged: True

## Original PR description

- Under `--enable-encoder-swa-bounded-replay` the target already keeps SWA in a per-request window, but the DSpark draft still forced a paged SWA allocator, so the radix tree kept an SWA component only the draft used. Evicting the draft's SWA then cut prefix hits on Main KV the target could still reuse (#42716 skips the same match gate).
- The DSpark draft SWA now lives in a per-request ring on CUDA: `swa_ring_rows` (`req_pool_idx * ring + pos % ring`) and `get_draft_swa_ring_size` (sliding window + max draft tokens) own its layout for every reader and writer. No pool needs `needs_paged_swa_allocator`, so the tree holds no SWA component.
- Writes reuse the existing ring path (`_ring_inject_loc`, and `build_unified_commit_inject_layout` renamed to `build_ring_commit_inject_layout`), now keyed on the draft pool's `swa_req_ring_size` instead of the unified_kv gate.
- Reads: `get_dspark_swa_page_indices` builds the draft window from the ring (`BuildDsparkSwaRingIndices`), and the draft block writes its ring rows, both eagerly and in the graph.
- A request placed by a prefix hit starts its ring at the hit (`swa_req_ring_valid_from`), so the draft masks earlier positions instead of reading rows left by the slot's previous request.
- The ring is budgeted as a fixed reservation next to the request windows instead of per SWA token.

Only DeepSeek-V4.1 with encoder SWA bounded replay and DSpark on CUDA changes; HIP keeps the paged draft SWA, and every other configuration is unchanged. After a prefix hit, the draft attends only to rows written since the hit until its window fills again.

On DeepSeek-V4.1-Flash (4x GB300, TP4, DSpark, encoder replay), a prompt whose draft SWA was evicted by 400 other prompts re-hits 8448 of its 8565 tokens instead of 0. GSM8K stays at 98.0% with and without decoder replay, and the average accept length is 3.81 against 3.78 before.
