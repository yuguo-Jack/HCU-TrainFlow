## Motivation

In paged full-attention + Mamba serving, [truncated prefill chunks](https://github.com/sgl-project/sglang/blob/6cac4dc3fe9a4bf15009f300132c3c7a1853c210/python/sglang/srt/managers/schedule_policy.py#L1100-L1160) can end inside a KV page. A Mamba checkpoint at token 287 and a radix key ending at page boundary 272 can then both free page 34. [PR #39526](https://github.com/sgl-project/sglang/pull/39526) addresses checkpoint tracking, not chunk alignment.

## Modifications

Align truncated hybrid chunks to KV pages; defer if no full page fits. Keep final, untruncated tails unchanged. No user-facing documentation changes are needed.

## Accuracy Tests

- A historical parallel-sampling run hit a duplicate page free before the fix, but not in matched fixed runs; unchecked outputs were unchanged.
- On main `2e7c9d851c`, the prefill-adder suite passed `58/58` with a `datasets` stub. On the fix branch, two current-main serving waves completed four parallel-sampling requests with 2, 3, 4, and 2 samples; all HTTP calls and post-run probes returned 200 with the native KV-page invariant checker enabled. This is a serving smoke test, not a matched output comparison; the local kernel-version guard was bypassed because `sglang-kernel` 0.4.5 is older than main requires.

## Speed Tests and Profiling

RTX A6000, Qwen3.5-0.8B-Base: two warmed baseline/fix pairs, each with three 40-request rounds at concurrency 4. For 2–4 parallel samples, output throughput was 1,353–1,396 vs. 1,325–1,413 tok/s (baseline vs. fix); p95 HTTP latency also overlapped. No consistent speed change was observed. The historical failure did not trigger during this benchmark.
