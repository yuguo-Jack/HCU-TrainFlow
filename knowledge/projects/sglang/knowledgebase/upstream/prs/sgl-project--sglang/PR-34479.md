# [Fix] Decouple `--language-only` from encoder disaggregation

[Upstream PR](https://github.com/sgl-project/sglang/pull/34479) · state: closed · merged: False

## Original PR description

Makes `--language-only` mean one thing: serve the language half of a VLM, with no local vision tower. Where image features come from is decided by encoder registration (`--encoder-urls` or the `EncoderBootstrapServer`), not by this flag.

- The vision tower is now actually skipped, not built-and-left-empty, across the VLMs that support it.
- A multimodal request with no encoder available is rejected instead of silently falling back to local processing against an unpopulated tower.
- `--language-model-only` (#22867, #34262) is folded in as a deprecated alias; the checkpoint-declared `language_model_only` config key is unchanged.
