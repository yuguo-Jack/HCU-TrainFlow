# [Fix] tokenizer_manager: Reject generation requests on an embedding server

[Upstream PR](https://github.com/sgl-project/sglang/pull/44337) · state: open · merged: False

## Original PR description

## Motivation

One generation request kills an embedding server:

```bash
# server: --model-path BAAI/bge-base-en-v1.5 --is-embedding
curl -s http://127.0.0.1:30000/generate -H 'Content-Type: application/json' \
  -d '{"text": "hi", "sampling_params": {"max_new_tokens": 2}}'
```

`TokenizerManager._validate_one_request` rejects an embedding request on a generation server ("Please add `--is-embedding`"), but not a generation request on an embedding server. The request reaches the scheduler, which runs it through `forward_batch_embedding`, and the model's forward fails:

```
  File ".../sglang/srt/managers/tp_worker.py", line 275, in forward_batch_embedding
  File ".../sglang/srt/model_executor/runner/eager_runner.py", line 262, in _execute_decode
  File ".../sglang/srt/models/bert.py", line 374, in forward
    assert get_embedding == True
AssertionError
[...] SIGQUIT received. signum=None, frame=None. It usually means one child failed.
```

`/v1/completions` does the same. `/v1/chat/completions` only survives because BERT tokenizers have no chat template, so the chat layer fails first.

## Modifications

- `_validate_one_request` raises `ValueError` for a `GenerateReqInput` when the server is not a generation server, next to the existing check for the opposite case. The HTTP layer turns it into a 400: `This model is served as an embedding model and cannot generate text. Use /v1/embeddings or /encode, or launch the server without --is-embedding.`
- No internal caller is affected: `/health_generate`, warmup, `/v1/score` and `/v1/rerank` already build a `GenerateReqInput` only when `is_generation` is true.
- Regression tests:
  - CPU: `test_tokenizer_manager_model_type_validation.py` checks that a generation request on an embedding server is rejected, that the existing opposite check still fires, and that matching request types pass.
  - Server: `TestOpenAIV1Rerank.test_generation_request_is_rejected` sends `/generate` and `/v1/completions` to the cross-encoder embedding server, expects 400 for both, and checks that a rerank still works afterwards.
