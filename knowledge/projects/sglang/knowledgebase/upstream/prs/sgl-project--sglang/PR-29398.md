## Summary

Closes #29397

Adds the **first real-world custom logit processor example** to `examples/runtime/custom_logit_processor/`, demonstrating [Top-nσ](https://arxiv.org/abs/2411.07641) (Tang et al., ACL 2025) logit truncation.

The existing docs only show a dummy `DeterministicLogitProcessor`; this example gives users a complete, working reference for a custom processor that does meaningful logit-space filtering.

Based on: Tang et al., "Top-nσ: Not All Logits Are You Need", ACL 2025. [arXiv:2411.07641](https://arxiv.org/abs/2411.07641)

### What is Top-nσ?

A logit-space dynamic truncation method that uses the standard deviation of the logit distribution to set a filtering threshold:

```
threshold = max_logit - n * std_logit
logits[logits < threshold] = -inf
```

It operates **before softmax** (exactly where SGLang's custom logit processor pipeline runs — `_preprocess_logits` is called before temperature scaling) and adapts to distribution "peakiness":
- **Sharp distribution** (model certain): small std → narrow threshold → fewer candidates
- **Flat distribution** (model uncertain): large std → wide threshold → more candidates

### How it compares to existing truncation methods

| Method | Space | Truncation rule | Adaptive? |
|---|---|---|---|
| top_k | Probability | Keep top-k highest-probability tokens | ❌ Fixed count |
| top_p (nucleus) | Probability | Keep tokens until cumulative prob ≥ p | ✅ Adaptive count only |
| min_p | Probability | Keep tokens with prob ≥ max_prob × min_p | ✅ Relative threshold |
| top_nσ | **Logit** | threshold = max_logit − n × std | ✅ Dual-adaptive |

> Key distinction: sglang's top_k/top_p/min_p all operate **after softmax** (probability space); top_nσ operates **before softmax** (logit space).

## Changes

- **New example**: `examples/runtime/custom_logit_processor/top_n_sigma.py` — the processor definition + `/generate` and OpenAI chat completion usage

**No changes to framework code** — `SamplingParams`, the sampler, `custom_logit_processor.py`, and the README are all untouched. The processor is defined in the example file and injected per-request via the existing `custom_logit_processor` field.

### Processor implementation highlights

- **Fully vectorized** across the batch (no Python per-row loop)
- **std computed once** and reused for both the `std==0` guard and the threshold formula, avoiding a duplicate vocab-wide reduction
- **Argmax-invariant** by construction (the peak token always survives)

### Edge cases handled

| Case | Behavior |
|------|----------|
| `top_n_sigma <= 0` | Request skipped |
| `top_n_sigma` is None / non-numeric | Request skipped |
| `std == 0` (all logits equal) | Row skipped (no filtering) |
| NaN/Inf logits | Row skipped (finite guard) |
| Empty / None param list | Logits returned unchanged |

## Usage

```bash
# 1. Launch the server with the custom-logit-processor gate enabled
python -m sglang.launch_server \
    --model meta-llama/Meta-Llama-3-8B-Instruct \
    --enable-custom-logit-processor

# 2. Run the example
python examples/runtime/custom_logit_processor/top_n_sigma.py
```

The processor is serialized via `CustomLogitProcessor.to_str()` and passed per-request:

```python
import requests
from sglang.srt.sampling.custom_logit_processor import CustomLogitProcessor

class TopNSigmaLogitProcessor(CustomLogitProcessor):
    # ... (see example file for the full implementation)
    pass

response = requests.post("http://localhost:30000/generate", json={
    "text": "The capital of France is",
    "custom_logit_processor": TopNSigmaLogitProcessor.to_str(),
    "sampling_params": {
        "temperature": 0.8,
        "custom_params": {"top_n_sigma": 2.0},
    },
})
```

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Advanced indexing (`logits[rows_t]`) creates a copy of the selected rows on the GPU, and writing back (`logits[rows_t] = selected`) performs a scatter operation. For a typical LLM vocabulary size of 32k to 128k, allocating and copying a `batch_size x vocab_size` tensor on every single token generation step is a significant performance bottleneck and increases GPU memory fragmentation.

We can optimize this by computing `std` and `max` over the entire `logits` tensor and applying the mask in-place using a boolean `process_mask`. This avoids any advanced indexing, memory allocation, or copying on the GPU.

```python
        # Collect per-request n-sigma values and build a process mask.
        n_sigmas = []
        process_mask_list = []
        for params in custom_param_list:
            n = params.get("top_n_sigma") if params else None
            if n is not None and isinstance(n, (int, float)) and n > 0:
                n_sigmas.append(n)
                process_mask_list.append(True)
            else:
                n_sigmas.append(1.0)  # dummy value
                process_mask_list.append(False)

        if not any(process_mask_list):
            return logits

        device = logits.device
        dtype = logits.dtype

        n_sigmas_t = torch.tensor(n_sigmas, device=device, dtype=dtype).unsqueeze(-1)
        process_mask = torch.tensor(process_mask_list, device=device, dtype=torch.bool).unsqueeze(-1)

        # Compute std and max over the entire logits tensor to avoid advanced indexing copies.
        std_all = logits.std(dim=-1, keepdim=True)
        finite_mask = torch.isfinite(logits).all(dim=-1).unsqueeze(-1)
        nonzero_std_mask = std_all != 0
        final_process_mask = process_mask & finite_mask & nonzero_std_mask

        max_logits = logits.max(dim=-1, keepdim=True).values
        thresholds = max_logits - n_sigmas_t * std_all

        # Mask tokens below threshold in-place.
        logits.masked_fill_(
            (logits < thresholds) & final_process_mask, float("-inf")
        )
        return logits
```
