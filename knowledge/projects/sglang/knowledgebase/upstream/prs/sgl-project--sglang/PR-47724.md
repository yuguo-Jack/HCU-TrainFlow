# [Perf] diffusion: qknorm_complex_rope keeps two Q/K rows in flight per half-warp

[Upstream PR](https://github.com/sgl-project/sglang/pull/47724) · state: open · merged: False

## Original PR description

## Motivation

`qknorm_complex_rope` (the bit-exact RMSNorm + complex RoPE of Qwen-Image-2.1 attention prep) reaches about 3.2 TB/s on B200, half of what a plain copy of the same bytes does. Each half-warp loads one row, then waits on a reduction and the rotation before its store, so few bytes are in flight.

## Modifications

The kernel now takes the Q/K rows two at a time per half-warp: both rows' loads are issued before either row is normalized and rotated. `norm_rope_row` is split into `load_row` and `norm_rope_store`; the arithmetic is the same code, so the output stays bit-identical. Prefix copies, V copies and an odd tail row keep the existing one-row loop. The launch uses half as many blocks.

Wider variants were measured and are not used: 256/512 threads per block (no gain, slower at 512), and 4 or 8 rows per half-warp through arrays (slower).

## Accuracy Tests

Outputs of the single-tensor and the pack entry points are `torch.equal` to the previous kernel at 4352 and 9216 tokens (24 heads x 128).

- `python/sglang/multimodal_gen/test/unit/test_qwen_image21_cuda.py`: 28 passed (B200).
- `test/registered/kernels/ops/diffusion/test_complex_rope.py`: 43 passed (B200).
- `test/registered/kernels/ops/diffusion/test_model_fast_paths.py -k "qknorm or qwen"`: 33 passed; `test_ernie_qknorm_rope_is_bit_exact` fails the same way on unmodified main and does not use this kernel.

## Speed Tests and Profiling

B200, Q+K through the pack entry point, 24 heads x 128, three alternating runs each:

| tokens | before | after |
| --- | --- | --- |
| 4352 | 33.0 / 33.0 / 32.9 us | 31.0 / 31.0 / 30.9 us (-6%) |
| 9216 | 71.8 / 71.8 / 71.8 us | 65.3 / 65.4 / 65.2 us (-9%) |

End to end this is small: Qwen-Image-2.1 1024px, 40 steps, one B200, two alternating runs each, 2.20 / 2.20 s before and 2.19 / 2.18 s after (about -0.4%).
