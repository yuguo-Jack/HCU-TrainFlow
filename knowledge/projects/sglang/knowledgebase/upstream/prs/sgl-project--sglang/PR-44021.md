# [Feat] [CPU] model: Support LFM2.5 models on CPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/44021) · state: open · merged: False

## Original PR description

## Motivation

The LFM2.5 series models require the use of a causal 1D convolution operator; however, the current CPU-based implementation of this operator only supports a width of 4, meaning it cannot accommodate the model's width of 3.

## Modifications

- In `conv.cpp`, the existing BF16/VNNI kernels are extended using zero-padding to support a width of 4, while maintaining two historical values ​​in the state.
- Adjustments have been made to handle initial states for variable-length (varlen) sequences, write-backs for short sequences, and the protection of padding slots.

## Accuracy Tests

For LiquidAI/LFM2.5-8B-A1B model, the Acc of GSM8K benchmark is 90.51%. Other models in the LFM2.5 series perform similarly to CUDA on GSM8K.
