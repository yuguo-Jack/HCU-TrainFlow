# [CI] [XPU] nightly: Split Intel Main and Wheel workflows

[Upstream PR](https://github.com/sgl-project/sglang/pull/44108) · state: closed · merged: True

## Original PR description

## Motivation

`nightly-test-intel.yml` holds two independent nightlies on two crons under one name, "Nightly Test (Intel)":

- `nightly-xpu-kernel-main-{1,2,4,8}-gpu` (sglang main + sgl-kernel-xpu main, image `latest-kernel-main`) at 19:30 UTC
- `nightly-xpu-kernel-wheel-1-gpu` (pinned sgl-kernel-xpu wheel, image `latest`) at 17:00 UTC

Each run shows the other schedule's jobs as "skipped", and the two can't be told apart in the Actions UI. Split them into two workflows.

## Modifications

- `nightly-test-intel.yml` -> **Nightly Main Test (Intel)**: `nightly-xpu-kernel-main-{1,2,4,8}-gpu` + `check-all-jobs`, cron `30 19 * * *`.
- `nightly-test-intel-wheel.yml` (new) -> **Nightly Wheel Test (Intel)**: `nightly-xpu-kernel-wheel-1-gpu` moved unchanged + its own `check-all-jobs`, cron `0 17 * * *`, own concurrency group (`nightly-test-intel-wheel-...`).
- Both keep the `push` (`python/sglang/version.py`), `workflow_dispatch` and `workflow_call` triggers. The per-job `github.event.schedule != ...` guards are dropped since each file now has a single cron.
- `xpu-ci-job-monitor.yml`: the Actions snapshot, nightly job list (`yq` over both files, `sort -u`), per-job nightly reports, runner fleet report and status dashboard read both files. The per-model 1x/2x/4x/8x report uses kernel-main artifacts only and stays on `nightly-test-intel.yml`; its messages now say "Nightly Main Test (Intel)".
- `release-branch-cut.yml`: add a `run-nightly-tests-intel-wheel` job that calls `nightly-test-intel-wheel.yml` with the release ref, next to the existing `nightly-test-intel.yml` call, so release-branch validation still covers the wheel job after the split.

Both workflows keep `runs-on: intel-bmg-nightly`, served by a single runner, so jobs from the two workflows still run one at a time (as they do today across the two crons); if the wheel run overruns 19:30 UTC the Main jobs queue until it finishes.

The test fixes that were originally in the same PR are in #44100.
