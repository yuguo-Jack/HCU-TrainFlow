# Fix deepseek-recipe rendering: add tool namespace and action field support

[Upstream PR](https://github.com/sgl-project/sglang/pull/46370) · state: open · merged: False

## Original PR description

## Summary
- Fix Issue #46348: deepseek-recipe rendering differs from the checkpoint's encoding.py
- Add `namespace` field to `Function` class to support tool namespaces as expected by deepseek-recipe package (prevents "Tool names must be unique" errors when identical tool names exist in different namespaces)
- Add `action` field to `ChatCompletionMessageGenericParam` and `ChatMessage` to support action tags in assistant messages
- Update `Function._serialize` to preserve namespace field when set
- Update `ChatMessage._serialize` to preserve action field when set
- The `reasoning_content` field was already supported in the protocol and is preserved through the pipeline

## Test plan
- [ ] Verify that tools with namespaces are rendered correctly by deepseek-recipe
- [ ] Verify that assistant messages with action fields are formatted as action tags
- [ ] Verify that assistant messages with reasoning_content preserve it before tool results
- [ ] Run existing deepseek-recipe tests to ensure no regressions
- [ ] Test with the checkpoint's encoding.py to verify token-level match
