# [Perf] DSA: Skip the unused token-level paged MQA schedule under KPool

[Upstream PR](https://github.com/sgl-project/sglang/pull/44378) · state: open · merged: False

## Original PR description

## Motivation

GLM-5.3-Flash MTP 5/1/6 decode runs 6 `sm100_paged_mqa_logits_metadata` kernels per step, 2 in each gap between the verify, draft-extend and draft graphs. GLM-5.3 runs 3. The extra 3 build the token-level DeepGEMM schedule, which has no reader when `index_kpool > 1`. Every indexer layer is then `IndexerKPool`, and it reads only the pooled schedule.

## Modifications

- `DeepseekSparseAttnBackend` gets `needs_paged_mqa_schedule` (`index_kpool <= 1`), set once in `__init__`.
- When the flag is false, the backend no longer builds `paged_mqa_schedule_metadata` or its 2D ctx lens `paged_mqa_ctx_lens_2d`. That covers eager init, CUDA graph capture, graph replay and replay from precomputed metadata. Both fields stay `None`.
- The MTP sibling-copy path runs only with KPool metadata fusion, so its copy of these two fields is removed rather than skipped. A backend that needs the schedule now takes the full recompute there instead.
- The top-k v2 plan refresh is unchanged and still runs on every path.
- `_refresh_paged_mqa_ctx_lens_2d` replaces 3 copies of the same allocate-or-copy block.

Only `dsa_indexer.py` (`Indexer`) reads `paged_mqa_schedule_metadata` / `paged_mqa_ctx_lens_2d`. `IndexerKPool._get_topk_paged` takes the schedule from `pooled_paged_mqa_schedule_metadata` or `kpool_write_plan.pool_schedule_metadata`. `deepseek_v2.py` picks `IndexerKPool` for every layer, the MTP layer included, whenever `index_kpool > 1`.

Only GLM-5.3-Flash sets `index_kpool` (4); DeepSeek-V3.2 and GLM-5 through 5.3 use 1 and are unchanged.

## Accuracy Tests

sgl-eval 0.1.2 GSM8K, 200 examples, temperature 1.0, top_p 0.95, thinking on.

| Model | GSM8K before | GSM8K after | Accept length (conc. 1) before | Accept length after |
|---|---:|---:|---:|---:|
| GLM-5.3-Flash | 98.0% | 98.5% | 4.49 | 4.48 |

`test_dsa_metadata_replay.py` now also checks that KPool replay leaves `paged_mqa_schedule_metadata` and `paged_mqa_ctx_lens_2d` unset. With `test_dsa_kpool_metadata_fusion.py` and `test_dsa_metadata.py`: 12 passed (7 subtests) on GB300.
