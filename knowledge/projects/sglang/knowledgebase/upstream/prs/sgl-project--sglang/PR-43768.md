# [Fix] wan: fix opt-in Wan2.2 progressive mode and one-step transitions

[Upstream PR](https://github.com/sgl-project/sglang/pull/43768) · state: closed · merged: True

## Original PR description

- WanProgressiveDenoisingStage did not accept transformer_2, so progressive requests on Wan2.2-T2V-A14B failed with TypeError. Pass it through to the base stage.
- When no step reached the stage threshold (e.g. the 1-step warmup request), the transition landed at n_steps and raised IndexError. Fall back to the last step so the final step runs at full resolution.
