# [AMD] aiter: Update ROCm AITER pin to 285579b62 (gfx942/gfx950 only)

[Upstream PR](https://github.com/sgl-project/sglang/pull/45498) · state: closed · merged: True

## Original PR description

## Motivation

Update the ROCm images from AITER 2bb549102 to [ROCm/aiter@285579b62](https://github.com/ROCm/aiter/commit/285579b6211b0da30f35b91a890c29c823597cd1). The new pin is 151 upstream commits ahead of the current default and is the candidate validated by AITER Scout #172.
Scout #172 compared 285579b62 against 2bb549102 — the currently shipped pin — and returned NO_NEW_REGRESSION: of 276 matched cells, zero failed with both controls passing. The four non-pre-existing cells were each taken to hardware rather than argued from logs.

## Modifications

Update AITER_COMMIT_DEFAULT for the eight gfx942/gfx950 ROCm image flavors: 2bb549102 → 285579b62.
Note that this makes the pin non-uniform across stages for the first time since gfx1250 was unified onto the shared pin.

## Accuracy Tests

Not run locally; this Docker dependency update requires AMD GPU image/accuracy CI. Docker is not available in the local environment.
