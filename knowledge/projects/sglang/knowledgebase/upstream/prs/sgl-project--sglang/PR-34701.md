# fix(moe): narrow global expert IDs using the built runner

[Upstream PR](https://github.com/sgl-project/sglang/pull/34701) · state: open · merged: False

## Original PR description

## Problem

`StandardDispatcher` decides whether the AITER path keeps expert IDs global from the configured MoE backend. A quantization method may build a different runner: on ROCm, compressed-tensors W4A16 can be configured as `auto` while constructing a Triton runner.

With EP=4, the dispatcher then keeps global IDs up to 383, but the Triton align kernel allocates for 96 local experts. Warmup writes outside that buffer and terminates all four ranks with an illegal-address fault.

## Solution

Record the backend only after `MoeRunner` is constructed successfully. The dispatcher keeps its existing AITER inference, then uses the built runner only as negative evidence:

```text
new_use_aiter_runner = old_use_aiter_runner
                       and (runner is unknown or runner is AITER)
```

This can only disable an unsafe AITER/global-ID decision; it cannot enable one that was previously disabled. The separate `skip_local_expert_mapping` rules for FlashInfer consumers remain unchanged. A complete namespace capability for that mirror case is a separate follow-up, not part of this ROCm Triton fix.

## Validation

On 4x MI350X with the two-layer Kimi-K2.5 checkpoint:

- base `sglang-miles@cb05a44f3`: warmup ended in repeated `hipErrorIllegalAddress` / error 700, exit 137;
- final branch head `5db65a647`: `/health_generate` became ready, `/generate` returned tokens, and the log contained no memory fault;
- `test/registered/unit/lora/test_mem_pool_ep_unit.py`: 39 passed (plus 4 subtests), including successful and failed runner-construction state tests;
- the final combined MoE LoRA save/resume run with #34702 and Bridge #28 also completed;
- SGLang pre-commit hooks passed on every changed file.

The PR targets `sglang-miles`, not `main`. Local final-head validation is complete; maintainer `run-ci` / `bypass-maintenance` labels and AMD CI remain merge gates.
