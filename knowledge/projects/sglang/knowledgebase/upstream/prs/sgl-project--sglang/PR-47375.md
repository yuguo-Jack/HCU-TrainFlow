# [Fix] hicache: Allow fallback for namespaced cgroup paths

[Upstream PR](https://github.com/sgl-project/sglang/pull/47375) · state: open · merged: False

## Original PR description

## Summary

Allow HiCache host-memory sizing to fall back to the process cgroup limit when the process is inside a namespaced cgroup path that is not mirrored under `/sys/fs/cgroup`.

Pyxis/Enroot can expose a path such as `/slurm/...` in `/proc/self/cgroup` while mounting the allocation's cgroup directory as the container's cgroup root. In that case the existing joined path does not exist even though `/sys/fs/cgroup/memory.max` contains the correct limit.

## Validation

- Added unit coverage for the namespaced-path fallback.
- Ran the HiCache unit test.
- Ran Dynamo's two-worker HiCache launch flow end to end under Pyxis on H100 NVL; both workers started and a real chat-completion request returned HTTP 200.
