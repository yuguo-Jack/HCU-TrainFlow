# [Doc] sgl-router: Add GLM-5.3-Flash and DeepSeek-V4.1-Flash deployment examples

[Upstream PR](https://github.com/sgl-project/sglang/pull/46668) · state: closed · merged: True

## Original PR description

## Motivation

The router README has generic deployment snippets (`--model-id qwen3`) but no worked,
per-model setup. This adds `sgl-router/EXAMPLES.md`: two engines behind one router for
GLM-5.3-Flash and DeepSeek-V4.1-Flash, starting from each model's cookbook recipe.

## Modifications

- New `sgl-router/EXAMPLES.md`:
  - the engine flags cache-aware routing needs (`--kv-events-config`, `--load-publish-endpoint auto`);
  - the router flags (`--tokenizer-backend fast`, `--tokenizer-l1-cache-mb`, `--chat-routing reorg`, `--policy cache_aware`, admission caps);
  - `--affinity-mode prefer` vs `balanced`, including `--affinity-balanced-by running-requests`;
  - a tuning table and gotchas.
- `sgl-router/README.md`: link to it from "Related docs" and "Deployment examples".

## Validation (in progress)

Draft until real runs fill in the result tables. The runs use 4 x B300 with 2 x TP2 engines per
model: a smoke test, GSM8K via sgl-eval (router vs direct), routing probes, and an
open-loop prefer vs balanced comparison.
