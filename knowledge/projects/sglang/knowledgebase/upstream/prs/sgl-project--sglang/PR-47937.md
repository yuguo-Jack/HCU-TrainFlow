# [Fix] [NPU] dsv4: preserve empty PD state components across PP stages

[Upstream PR](https://github.com/sgl-project/sglang/pull/47937) · state: open · merged: False

## Original PR description

## Motivation

DeepSeek-V4 NPU PD pairs state components by their wire position. An A5 prefill PP stage containing C4 layers but no C128 layers currently omits both C128 components, while the full decode model registers them before C4:

| Peer | State components |
| --- | --- |
| P stage | SWA, C4 state |
| D full model | SWA, C128 state, C128 KV, C4 state |

The sender's C4 component is then paired with the receiver's C128 state and rejected by layout validation. This is independent of the A3 ring-stride issue in #47934.

## Modifications

- Preserve NPU C128 state, C128 KV and A5 C4 component slots when the full model has the corresponding compression ratio, even when the local PP stage has no buffers for that component.
- Publish `None` for an empty component's indices on both P and D. Keeping the slot alone is insufficient: computing its payload would access a request-state pool that this stage does not own.
- Add registration tests for C4-only, C128-only and locally empty compression buckets, and complete prefill/decode endpoint tests covering both empty and live payloads.

The existing layout/stride checks remain in place. This PR does not change C4 ring addressing or transfer backends.

## Accuracy Tests

Tested against main `e33cd0c3a10474c7a0f6efeb69ce2cf4b7a55021`:

- Three focused unit tests pass after importing the production modules in an Ascend environment (torch 2.10.0+cpu / torch_npu 2.10.0.post6, CANN 9.1). They check registration and execute the complete prefill/decode publication methods through mocked send boundaries. Empty callbacks are not called; live callbacks still produce their payloads.
- An additional CPU harness passes 14 A3/A5 PP schema and peer-layout cases, including full-model compression-ratio controls, plus the two complete empty-component endpoint checks. This harness extracts production AST methods and doubles import/allocation/network boundaries.
- Ruff 0.15.1 formatting and selected lint checks, isort 7 and `git diff --check` pass.

These are CPU fixture tests. A5 architecture selection is mocked in the registration test; no A5 device transfer or full-model PP run was performed.

## Speed Tests and Profiling

No performance claim. Empty components retain metadata slots and transfer no state bytes.
