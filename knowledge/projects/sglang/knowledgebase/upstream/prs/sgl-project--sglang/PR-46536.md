[Upstream PR](https://github.com/sgl-project/sglang/pull/46536) · state: closed · merged: True

## Original PR description

Wan imports the NVIDIA-only CuTe RoPE kernels during module discovery on non-NVIDIA platforms. Guard the imports with the existing CUDA platform predicate and short-circuit the fused path with the same predicate so those platforms use the existing unfused path.

Reconcile the current main XPU/ROCm guards into this single positive platform check. The final diff changes only wanvideo.py; main already contains the equivalent ZImage test guard.
