# [Perf] deepseek-v4.1: Reset request-window tags without a host sync

[Upstream PR](https://github.com/sgl-project/sglang/pull/45247) · state: closed · merged: True

## Original PR description

- `RequestWindow.reset` cleared a slot's tags with a scalar index_put (`tags[:, loc] = -1`), which blocks the host until the stream drains. It runs once per newly placed request with encoder SWA replay, so each such prefill step stalled the scheduler behind the GPU.
- It now uses `index_fill_`, which stays on the device. No behavior change: same rows, same value.
- Verification: DeepSeek-V4.1-Flash on GB300, DP2 attention + MegaMoE (EP2), DSpark, encoder and decoder replay on, a multi-turn agentic prefill trace at concurrency 512. py-spy put 44% of the scheduler main thread's samples on that line. In isolation, with GPU work queued, the old line held the host for 371 ms and `index_fill_` for 0.14 ms.
