# [NPU] Support Qwen4-Exp PLE CPU offload on Ascend

[Upstream PR](https://github.com/sgl-project/sglang/pull/39548) · state: open · merged: False

## Original PR description

## Motivation

Qwen4-Exp / Qwen3.8-Flash-Next PLE CPU offload currently reads the n-gram table directly from host memory. CUDA can dereference the raw pinned host pointer through UVA, but Ascend cannot; the first gather faults with `The DDR address of the MTE instruction is out of range`.

This PR adds an Ascend-specific host-memory mapping path so PLE embedding tables can remain in CPU memory while the NPU gather kernel accesses them safely.

## Modifications

- Add a platform hook for device-visible host-memory registration.
- Implement the NPU hook with `aclrtHostRegister` / `aclrtHostUnregister`.
- Make host mappings ownership-safe so mappings created by another component (for example torch_npu pinned memory) are borrowed rather than unregistered by SGLang.
- Page-align registered ranges while preserving the correct device pointer offset.
- Resolve the PLE gather pointer through the platform mapping.
- Keep the file-backed PLE backend CUDA-only because it relies on pageable mmap + on-demand paging + `MADV_DONTNEED` trimming.
- Make the PLE gather grid-strided. Ascend caps `coreDim` at 65535 while `tokens * ngram_heads` can exceed that (for example 131072 rows for an 8192-token prefill).
- Add unit tests for host-memory mapping ownership/alignment and the grid-stride gather path.

## Accuracy Tests

Tested on CANN 9.0 / Ascend 910 with Qwen3.8-Flash-Next:

- TP=1: CPU-offloaded PLE output matches the non-offloaded baseline token-for-token and logprob-for-logprob.
- TP=2: same result.
- An 8001-token prompt was included to exercise the grid-stride path.

## Speed Tests and Profiling

Measured on CANN 9.0 / Ascend 910:

- Registering a 32 GiB host mapping takes about 0.24 s.
- The mapping consumes no device memory (mapping, not copy).
- Host writes after registration are visible to the device.
- Random-row gather from mapped host memory: ~19 GiB/s.
- Same table device-resident: ~36 GiB/s.
