# [Fix] profiler: Handle memory snapshot failures

[Upstream PR](https://github.com/sgl-project/sglang/pull/39506) · state: open · merged: False

## Original PR description

## Motivation

When ROCm/PyTorch cannot serialize a `MEM` profiling snapshot, `_stop_profile` currently lets the exception escape before memory-history and profiler cleanup. This can terminate the scheduler rank and the TP service. Fixes #39442.

## Modifications

- Catch snapshot serialization failures and log them.
- Always disable memory-history recording after a `MEM` profile.
- Complete profiler teardown and return a failed `ProfileReqOutput` without raising.
- Preserve the original snapshot failure if cleanup also fails.

## Accuracy Tests

Not applicable. This change only handles profiling failures and does not change model outputs.
