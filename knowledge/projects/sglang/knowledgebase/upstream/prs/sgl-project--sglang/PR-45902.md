# [Fix] jit: Make SGLANG_JIT_CACHE_DIR default follow SGLANG_CACHE_DIR

[Upstream PR](https://github.com/sgl-project/sglang/pull/45902) · state: closed · merged: False

## Original PR description

## Motivation

`SGLANG_CACHE_DIR` is the knob that moves SGLang's on-disk caches: `SGLANG_DG_CACHE_DIR`, `SGLANG_CUTE_AOT_CACHE_DIR` and the third-party caches set by `redirect_third_party_caches()` all derive from it. The JIT kernel build cache does not. `cache_root()` and `_sailify_root()` fall back to a hardcoded `~/.cache/sglang/jit`, so `SGLANG_JIT_CACHE_DIR` has to be set separately.

We ran into this serving DeepSeek V4 Flash on short-lived GPU containers, with `SGLANG_CACHE_DIR` on a persistent volume so cold starts reuse compiled kernels and autotune results. Everything under `SGLANG_CACHE_DIR` was reused, but the `load_jit` kernels on the DSV4 attention path were rebuilt with nvcc on every boot until we also set `SGLANG_JIT_CACHE_DIR` by hand.

## Modifications

- `SGLANG_JIT_CACHE_DIR` now defaults lazily to `$SGLANG_CACHE_DIR/jit` through `_default_cache_subdir("jit")`, the same pattern as `SGLANG_DG_CACHE_DIR` and `SGLANG_CUTE_AOT_CACHE_DIR`. With `SGLANG_CACHE_DIR` unset the path is unchanged (`~/.cache/sglang/jit`), and an explicit `SGLANG_JIT_CACHE_DIR` still wins.
- `cache_root()` and `_sailify_root()` read the env value directly instead of each carrying its own fallback.
- The diffusion quantization doc now gives the default as `$SGLANG_CACHE_DIR/jit`.

One edge case changes: `SGLANG_JIT_CACHE_DIR=""` used to fall back to the default and is now used as given, the same way the other cache dir envs treat an empty value. Happy to keep the old fallback if you prefer.
