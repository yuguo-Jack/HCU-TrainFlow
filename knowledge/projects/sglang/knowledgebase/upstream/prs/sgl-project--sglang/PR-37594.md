# [Fix] mamba: Warn about prefill checkpoint capacity

[Upstream PR](https://github.com/sgl-project/sglang/pull/37594) · state: open · merged: False

## Original PR description

## Motivation

Refs #36935.

Hybrid Mamba/GDN prefix reuse can degrade under checkpoint eviction pressure even while the KV prefix remains resident. Add a conservative startup diagnostic when the KV token budget can span more chunked-prefill checkpoints than the full-precision Mamba pool can retain.

## Modifications

- Compare the integer-ceiling checkpoint estimate with the configured Mamba slot capacity.
- Restrict the diagnostic to radix caching with extra-buffer checkpoints. Skip no-buffer mode and the separate int8 checkpoint pool, whose capacity differs from the active Mamba pool.
- Cover rounding, sufficient capacity, disabled/unconfigured limits, and the startup call-site guards. This complements #38000 and #38018; it does not change eviction or prefix matching.

Synced with current `main` at `f2b73d4f9b4e64415b8d775b0f811c7801f1728b` on October 15, 2026.
