# [DSV4.1][PD][1/N] Support prefill node use cp parallel strategy

[Upstream PR](https://github.com/sgl-project/sglang/pull/40323) · state: closed · merged: True

## Original PR description

issue：https://github.com/sgl-project/sglang/issues/39700

This PR supports the use of the cp parallel strategy for the prefil nodes in the pd separation process. The development of other subsequent functions will be based on this PR. The specific progress can be viewed on the issue page above.And both the graphic and text modes have already supported the cp function.

## command
env
- branch: main
- b200*8

prefill：
```bash
GLOO_SOCKET_IFNAME=eth0 \
      NCCL_SOCKET_IFNAME=eth0 \
      MC_TE_METRIC=1 \
      MC_TE_METRIC_INTERVAL_SECONDS=1 \
      MC_INTRA_NVLINK=true \
      MC_INTRANODE_NVLINK=true \
      CUDA_VISIBLE_DEVICES=0,1,2,3 \
      SGLANG_MOONCAKE_CUSTOM_MEM_POOL=INTRA_NODE_NVLINK \
      SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1 \
      /root/miniforge3/envs/abing-v4.1/bin/sglang serve \
          --trust-remote-code \
          --model-path /upfs/models/deepseek-ai/DeepSeek-V4.1-Flash/ \
          --tp 4 \
          --ep 4 \
          --enable-prefill-cp \
          --cp-strategy interleave \
          --nnodes 1 \
          --node-rank 0 \
          --moe-runner-backend flashinfer_mxfp4 \
          --disaggregation-mode prefill \
          --disaggregation-transfer-backend mooncake \
          --speculative-algorithm DSPARK \
          --chunked-prefill-size 16384 \
          --max-prefill-tokens 16384 \
          --swa-full-tokens-ratio 0.05 \
          --mem-fraction-static 0.8 \
          --detokenizer-worker-num 8 \
          --tokenizer-worker-num 8 \
          --dist-init-addr ${p0}:5557 \
          --disaggregation-bootstrap-port 8761 \
          --host ${p0} \
          --port 30001 
```
decode：
```bash
GLOO_SOCKET_IFNAME=eth0 \
      NCCL_SOCKET_IFNAME=eth0 \
      SGLANG_REQUEST_STATE_WAIT_TIMEOUT=600 \
      MC_TE_METRIC=1 \
      SGLANG_SET_CPU_AFFINITY=1 \
      MC_TE_METRIC_INTERVAL_SECONDS=1 \
      MC_INTRA_NVLINK=true \
      MC_INTRANODE_NVLINK=true \
      CUDA_VISIBLE_DEVICES=4,5,6,7 \
      SGLANG_MOONCAKE_CUSTOM_MEM_POOL=INTRA_NODE_NVLINK \
      SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1 \
      /root/miniforge3/envs/abing-v4.1/bin/sglang serve \
      --trust-remote-code \
      --model-path /upfs/models/deepseek-ai/DeepSeek-V4.1-Flash/ \
      --tp 4 \
      --ep 4 \
      --moe-runner-backend flashinfer_mxfp4 \
      --disaggregation-mode decode \
      --cuda-graph-max-bs-decode 32 \
      --disaggregation-transfer-backend mooncake \
      --speculative-algorithm DSPARK \
      --max-running-requests 256 \
      --swa-full-tokens-ratio 0.05 \
      --mem-fraction-static 0.8 \
      --detokenizer-worker-num 8 \
      --tokenizer-worker-num 8 \
      --host ${d0} \
      --dist-init-addr ${d0}:5757 \
      --port 30002
```
