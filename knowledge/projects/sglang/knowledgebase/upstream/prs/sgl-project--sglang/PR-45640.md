## Motivation

FlashInfer TRT-LLM MoE allocates temporary scratch on each invocation. This causes memory usage spike during autotuning. Reusing persistent buffers per each maximum tuning token can significantly reduce the memory usage.

## Modifications

- Add `get_trtllm_moe_workspace()` with cached sizing and separate buffers per device and CUDA stream.
- Integrate workspace reuse into BF16, FP8, MXFP4, NVFP4, and MXINT4 paths.
- Preserve per-call allocation fallbacks for unsupported FlashInfer versions, deferred finalize, and oversized batches.
- Add workspace related unit tests.
