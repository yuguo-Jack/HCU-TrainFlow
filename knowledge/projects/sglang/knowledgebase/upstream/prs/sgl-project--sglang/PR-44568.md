# [Perf] [NVIDIA] scheduler: Pageable host staging and inline hidden-state/DSpark readback under Confidential Computing

[Upstream PR](https://github.com/sgl-project/sglang/pull/44568) · state: closed · merged: True

## Original PR description

## Motivation

Follow-up to the async device->host readback worker for NVIDIA Confidential Computing (CC). Two things it left on the table:

1. **Host staging stayed pinned.** Under CC host<->device copies go through a bounce buffer; this change selects pageable staging there through `is_pin_memory_available()`.
2. **Two batch kinds must not take the worker.** Batches that return hidden states, and DSpark batches, read views of CUDA graph buffers that the next replay rewrites. Only a copy queued right behind the forward on `copy_stream` reads them in time; a copy issued later from the worker thread can race the next replay.

## Modifications

- `is_pin_memory_available()` answers `False` under CC. `async_d2h()` already falls back to a pageable copy when it does, so the overlap scheduler's readback buffers and every other staged copy are pageable there. Off CC nothing changes: staging stays pinned.
- Both scheduler submit sites (`run_batch` and `launch_batch_sample_if_needed`) go through one `_copy_result_to_cpu` helper. Under CC it hands the readback to the worker unless the batch returns hidden states or runs DSpark; those stay inline on `copy_stream`, as before the worker existed.
- The prefill result-polling scheduler fake borrows the helper, as it already borrows `launch_batch_sample_if_needed`.

## Tests

`test/registered/unit/managers/test_async_d2h_copy_worker.py` gains two cases:

- `TestConfidentialComputeStaging`: `async_d2h` lands in pageable memory with the force override on and pinned memory with it off.
- `TestSchedulerReadbackRouting`: the source tensor is written behind a long `torch.cuda._sleep`, so a readback that does not wait for the forward reads zeros. Under CC only the plain batch gets a `HostCopyDone`; hidden-state and DSpark batches keep a CUDA event, and every host buffer is pageable. Each case was verified to fail with the corresponding branch removed.

Ran on a single GPU: the whole file (8 tests) and `test/registered/unit/disaggregation/test_prefill_result_polling.py` (20 tests) pass; `ruff`, `ruff format`, `isort` and `codespell` are clean with the repository's configuration. No CC host was available, so the behaviour under real CC was not measured here.
