# [Fix] benchmark: Count multi-turn input tokens in serving metrics

[Upstream PR](https://github.com/sgl-project/sglang/pull/46504) · state: open · merged: False

## Original PR description

## Motivation

Multi-turn serving benchmarks (including `agentic-trace`) report zero `total_input_tokens` and `input_throughput` even when each response contains a nonzero prompt-token count. `total_throughput` consequently includes only generated tokens, while `input_lens` and `cache_report` report the actual input lengths.

The multi-turn caller passes `input_requests=None` after flattening per-conversation outputs. `calculate_metrics` currently accumulates input tokens only when dataset rows are present. For two successful rounds with prompt lengths 100 and 200, two generated tokens each, and a two-second duration, it reports 0 input tokens and 2 total tokens/s instead of 300 input tokens and 152 total tokens/s.

## Modifications

- When dataset rows are unavailable, sum each successful output's `prompt_len` for the input-token total and derived throughput metrics.
- Preserve the existing single-turn dataset-length and text/vision accounting. Do not infer a modality breakdown from an aggregate response length.
- Extend the existing CPU-registered prompt-length tests to cover multi-turn totals/throughput, exclusion of failed rounds, and single-turn modality accounting.

## Accuracy Tests

This changes benchmark reporting only, not requests, model outputs, or cache accounting.

- The two new multi-turn regression tests fail against the original `calculate_metrics` (`0 != 300`) and pass with the fix.
- Focused prompt-length test file: 5 tests passed.
- Adjacent `test/registered/unit/bench/` tests: 19 passed, 13 subtests passed, using the checkout's benchmark/test sources with the existing Linux dependency environment.

## Speed Tests and Profiling

Not applicable: no inference or scheduling changes. The regression tests verify that the input and total throughput numerators include successful rounds' prompt tokens; output throughput is unchanged.
