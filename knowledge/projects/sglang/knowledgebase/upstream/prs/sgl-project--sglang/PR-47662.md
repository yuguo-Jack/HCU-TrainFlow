# [Fix] reasoning: Reject reasoning_effort outside the enum for M3

[Upstream PR](https://github.com/sgl-project/sglang/pull/47662) · state: closed · merged: True

## Original PR description

## Motivation

MiniMax-M3 accepts `reasoning_effort` in low / medium / high / xhigh / max. Other values, including `none` and `minimal`, used to be mapped to disabled thinking; they now return 400. Use `thinking.type=disabled` to turn thinking off.

This is a behavior change for M3 and M3.1 (both `minimax_m3_vl`): requests that sent `reasoning_effort=none` or `minimal` to disable thinking now get a 400. Other models are unaffected. A server-default effort outside the enum is still dropped rather than rejected.
