# [MPS][MLX] Fix default memory budgeting and KV write retention

[Upstream PR](https://github.com/sgl-project/sglang/pull/39676) · state: closed · merged: False

## Original PR description

## Motivation

Fixes #39675.

Long prompts on Apple Silicon can abort MLX inference with `kIOGPUCommandBufferCallbackErrorOutOfMemory`. MPS is missing from the device-capacity dispatch, so default memory sizing falls back to `mem_fraction_static=0.95` without calculating activation headroom from the device capacity. In addition, lazy writes into the shared MLX KV pool retain prior chunks' source arrays: evaluating token outputs and per-request caches does not evaluate those writes.

## Modifications

- Report `torch.mps.recommended_max_memory()` in MiB for MPS, matching the capacity basis used by MLX KV sizing. Metal's recommended working set is device-dependent, not a fixed fraction of system RAM or a guaranteed allocation limit.
- Submit shared KV pool writes with `mx.async_eval` so completed writes release their source graphs. The shared entry point covers prefill, chunk continuation, and decode KV writeback while preserving asynchronous execution.
- Add CPU coverage for MPS capacity/default budgeting and MLX coverage for source-array lifetime, long chunked prefills, and prefix reuse. The MLX tests use `CustomTestCase`, graceful server teardown, and `stage-b-e2e-mlx` registration.

## Accuracy Tests

Final local validation on Apple M4 / 24 GiB, macOS 15.7.9, Python 3.12.0, PyTorch 2.13.0, MLX 0.32.2:

- **238** server-argument tests passed.
- **75** related MLX tests passed, covering pool dtype, sliding-window caches, attention patching, pool contracts, and synchronous/asynchronous request routing.
- **2** new MLX regressions passed. Three consecutive 8,016-token requests produce 16 tokens each; prefix-cache hits preserve greedy output IDs and the server remains healthy. The memory-lifetime test also checks the stored K/V values.
- The lifetime regression fails against the original implementation: eight one-slot writes retain **16,777,312 bytes**, exceeding the **2 MiB** bound. It passes with this fix. The capacity/default-budget regressions also fail before the MPS dispatch change.
- All applicable pre-commit hooks passed for the four PR files, along with whitespace and test-registration checks.
