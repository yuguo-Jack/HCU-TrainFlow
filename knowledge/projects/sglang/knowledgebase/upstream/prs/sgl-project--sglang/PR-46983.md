## Motivation

The ROCm fused KV store uses the location IDs supplied by the model. For a unified sliding-window view requiring physical translation, those IDs can address the wrong storage unless the pool performs the write.

## Changes

- Disable the fused store when the window view requires translated physical write locations.
- Preserve eligibility for full-only and static-window storage, including the existing DCP exclusions.
- Extend the existing model-level fused-store gate tests.

## Validation

The expanded regression suite had **three failures on the old implementation and all seven cases passing after repair**. Later CPU probes also passed translated-window, static-window and DCP-mask cases.

These checks validate write routing and fused-store eligibility. **AMD hardware and ROCm kernels were not tested.**
