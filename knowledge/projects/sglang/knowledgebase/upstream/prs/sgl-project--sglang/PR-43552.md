# [Bugfix] Reject unsupported mask in /v1/images/edits instead of silently ignoring it

[Upstream PR](https://github.com/sgl-project/sglang/pull/43552) · state: open · merged: False

## Original PR description

Closes #43409

The edits endpoint declares `mask` for OpenAI API compatibility, but the
multimodal pipelines never consume a mask image, so an uploaded mask used to
be silently dropped and the caller got a successful response that looked as
if the mask had been applied. Fail loudly with 501 Not Implemented instead.

Adds a regression test under python/sglang/multimodal_gen/test/unit/.

AI-assisted disclosure: root cause located and patch written with the help of
an AI assistant; syntax, LF/BOM and the rejection logic verified locally
(Windows cannot import sglang due to the Unix-only `resource` module, so the
full pytest run happens on CI).
