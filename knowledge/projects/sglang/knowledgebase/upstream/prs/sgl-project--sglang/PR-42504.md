# [AMD] DeepSeek-V4.1: fold the MoE combine into the decode all-reduce on gfx950

[Upstream PR](https://github.com/sgl-project/sglang/pull/42504) · state: closed · merged: False

## Original PR description

In DeepSeek-V4.1-Flash decode, each mixture-of-experts (MoE) layer runs a separate reduction of the routed-expert outputs and then the tensor-parallel all-reduce. This draft folds the reduction into the decode all-reduce kernel, which already fuses the post step of the mHC (hyper-connection) residual mixing, so one launch and one pass over the hidden states are saved per layer.

- Predicted from the decode traces (MI355X, tensor parallel on 4 GPUs): about 1-2% less decode time per step without shared-expert fusion, less with it.
- Conservative expectation: about 0.5% higher output throughput.
- Status: draft without code.
