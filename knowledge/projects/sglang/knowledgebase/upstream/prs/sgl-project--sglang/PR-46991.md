## Motivation

Prefix-tree components currently derive their resources and geometry separately from KV storage. Build them from storage slots so component identity, window retention and checkpoint intervals come from the same plan.

## Changes

- Describe tree slots separately from token, window, state and block behavior families.
- Construct Python and native tree drivers from slot geometry and route resource effects through storage.
- Migrate custom component adapters and direct cache constructors, including the LLaDA image text encoder and page-shard allocation/eviction fixture.

Consolidate batch regressions, remove two redundant storage checks, and clarify tree/storage comments.
