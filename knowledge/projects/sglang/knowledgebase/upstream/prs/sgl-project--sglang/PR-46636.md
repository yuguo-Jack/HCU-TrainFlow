# [Fix] rust_server: Keep idle attention-DP ranks from parking on their ring

[Upstream PR](https://github.com/sgl-project/sglang/pull/46636) · state: open · merged: False

## Original PR description

## Motivation

With `SGLANG_RUST_SERVER=1`, every scheduler that hosts a Rust listener parks its idle loop for up to 1 s on its own request ring, and only a request on that ring wakes it. Under attention DP every step gathers all DP ranks, so a request on one listener wakes only its rank, which then waits in the gather until the other ranks' park times out. On 4x H100 (Qwen3-0.6B, `--tp 2 --dp 2 --enable-dp-attention`), every request took ~0.5 s vs 0.036-0.038 s with the Python server. The Python server only parks with `--sleep-on-idle`.

## Modifications

- Add `create_rust_server_idle_sleeper`: it returns no sleeper under attention DP unless `--sleep-on-idle` is set, and the scheduler uses it.
