# [multimodal] Stop each per-item feature shipping the whole packed buffer over IPC

[Upstream PR](https://github.com/sgl-project/sglang/pull/41015) · state: closed · merged: False

## Original PR description

**2 of 3** on multimodal feature handling (#41014, #41015, #41016). Independent of the other two.

## Motivation

`get_new_expanded_mm_items` splits one request-wide feature tensor into one slice per placeholder, so each image can be hashed and cached on its own. Those slices are **views**.

Pickle serialises a tensor's *entire underlying storage*, not the view, and `SGLANG_USE_PICKLE_IPC` selects pickle for tokenizer→scheduler IPC by default. So every item carries every other item's bytes, and a request with N images sends `N × total_bytes`.

The cost is quadratic in images per request, and every processor that packs and lets the scheduler split pays it.

## Modifications

One pass in `_create_tokenized_object`, on the tokenizer side of IPC and downstream of every processor:

```python
narrow_mm_features_to_own_storage(mm_inputs)
```

A tensor whose `untyped_storage().nbytes()` exceeds `numel() * element_size()` is copied into its own storage — one copy per oversized item, paid once, in place of N serialisations of the whole buffer.

Three details that matter:

- **Placement.** `_finalize_mm_items` looks like the natural home but is only reachable from `process_and_combine_mm_data`; several processors build their own `MultimodalDataItem`s and return a `MultimodalProcessorOutput` directly, never passing through it. `_create_tokenized_object` is where every path converges before serialisation.
- **A tensor that already owns its storage is returned untouched**, so an unsplit item or a single-image request pays nothing.
- **The type check is exact, not `isinstance`.** `TransportProxyTensor` keeps its transport metadata in an instance attribute set by `__new__`, which `clone()` does not run — cloning one yields a subclass whose `__getstate__` then fails on the missing `_metadata`. Subclasses and transport proxies own their own transport and are skipped.

## Result

Pickling a real split item list shows the whole effect: eight views of one packed buffer serialise to **8.00×** their own bytes, and to **1.00×** once narrowed. End to end that is **2.4× at four images and 2.9× at eight**, against this commit's own parent. A single-image request is unchanged, as expected — there is nothing to narrow.

## Tests

- New `test_feature_storage_narrowing.py`: contiguous and non-contiguous views copied out, a tensor owning its storage returned by identity, lists/tuples narrowed elementwise, the 8.00× → 1.00× ratio, and `TransportProxyTensor` left alone with its metadata intact.
- `test/registered/unit/multimodal/` green; `isort` / `ruff check` / `ruff format` clean.
