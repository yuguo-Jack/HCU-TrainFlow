# [sgl-router] Add --dp-rank-policy round_robin for --dp-aware

[Upstream PR](https://github.com/sgl-project/sglang/pull/43511) · state: open · merged: False

## Original PR description

## Motivation

With `--dp-aware`, a DP rank that no routing key or cached prefix decides always goes to the rank with the fewest router in-flight requests (#41974). In PD mode that is every decode rank. `sgl-model-gateway` also offered `--decode-policy round_robin`, which is what existing PD deployments that move to `sgl-router` were running. Without a round-robin choice that baseline cannot be reproduced, and least-in-flight cannot be A/B tested against it inside the same router.

## Modifications

- `--dp-rank-policy {least_in_flight,round_robin}`: requires `--dp-aware`; the default, `least_in_flight`, is the current behaviour.
- It only replaces the last step of `select_dp_rank`. A sticky or session key and the deepest cached prefix still decide first, so a conversation keeps its prefill rank.
- `round_robin` hands out a worker's ranks in turn from a per-worker cursor (`Worker::next_dp_rank_turn`). When several ranks tie on the deepest prefix, it rotates over those.
- `ModelConfig::dp_rank_policy`; the other `ModelConfig` literals take the default.
- README: the DP-rank routing section.

## Testing

- New tests:
  - `policies::dp_rank::tests::round_robin_takes_turns_regardless_of_load`
  - `dp_rank_routing::round_robin_gives_decode_ranks_turns`: PD decode ranks come out 0, 1, 2, 3, 0, 1, 2, 3.
  - `config::cli::tests::dp_rank_policy_requires_dp_aware`
- Passing: `cargo +nightly fmt --all -- --check`, `cargo clippy --locked --workspace --all-targets -- -D warnings`, `cargo test --locked --release --workspace -- --skip parity_matrix`.
- Fake 1P1D workers, each reporting 8 attention-DP ranks, behind `--policy sticky --routing-key-header X-SMG-Routing-Key --dp-aware --dp-rank-policy round_robin`, 256 streaming chats at concurrency 64 over 16 keys:
  - every decode rank got exactly 32 requests;
  - each key stayed on prefill rank `sha256(key) % 8`, and `bootstrap_room % 8` matched it.
- MI355X end-to-end A/B, `least_in_flight` vs `round_robin` on the same image: in progress; I will add the results here. Setup: DeepSeek-V4-Pro, 1 prefill + 1 decode engine, decode with DP attention over 8 ranks, AgentX trace replay at concurrency 192 to 512.
