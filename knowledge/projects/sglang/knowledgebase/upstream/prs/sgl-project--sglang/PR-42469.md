# [Docs] Align Ascend MemFabric install command with version table

[Upstream PR](https://github.com/sgl-project/sglang/pull/42469) · state: closed · merged: False

## Original PR description

## Motivation

#38437 updated the MemFabric-Hybrid version in the Ascend component table to `1.1.4`, but the source-install command below still uses `1.0.8`. Both CANN version tables on the page currently list `1.1.4`.

## Modifications

Change only the source-install command from `pip install memfabric-hybrid==1.0.8` to `pip install memfabric-hybrid==1.1.4`. No dependency files, Docker configuration, or other version pins are changed.
