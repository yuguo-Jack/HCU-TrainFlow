# feat: add opt-in top-k logprob normalization

[Upstream PR](https://github.com/sgl-project/sglang/pull/43441) · state: closed · merged: False

## Original PR description

## Motivation

Human:
Add opt-in top-k logprob normalization in SGLang for bounded logprob comparisons, including top-50 normalization.

## Modifications

AI:
- Add `SGLANG_LOGPROBS_TOPK_NORMALIZE` (default `0`, disabled). Setting it to `50` reports logprobs normalized over the global top-50 logits.
- Apply normalization to prefill, decode, score-only, and speculative logprob processing. Normalize the selected support in FP32 and floor other tokens at the normalized kth-place value, including requested-token and sampled-token logprobs.
- Reuse the selected top-k token IDs when assembling responses so floored tail tokens do not replace them. Reject top-logprob requests exceeding the selected support; use full-vocabulary normalization when k reaches the vocabulary size.
- Preserve upstream chunking and graph-pool borrowing, accounting for the dense normalization buffer. Document the setting and add registered CPU regression tests.

Sampling is unchanged. With tail flooring enabled, exponentiating all vocabulary entries does **not** produce a distribution summing to one; normalization applies to the selected support.
