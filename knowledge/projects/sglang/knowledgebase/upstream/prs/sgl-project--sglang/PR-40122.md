# [AMD] Fix CUDA-only tensor checks in speculative JIT wrappers

[Upstream PR](https://github.com/sgl-project/sglang/pull/40122) · state: closed · merged: False

## Original PR description

## What broke

After the speculative kernels moved to JIT by #40033 , their input check only admitted NVIDIA tensors. AMD tensors were rejected before any GPU work started.  `test_basic_sanity_eagle3.py` fails https://github.com/sgl-project/sglang/actions/runs/35292247566/job/105499225679#logs
<img width="2885" height="1671" alt="image" src="https://github.com/user-attachments/assets/86fd9eee-1f5a-4acd-ab8d-4e80fe71f868" />


## Fix

Use the existing platform-neutral GPU type in the four new checks. It maps to CUDA on NVIDIA and ROCm on AMD, so NVIDIA behavior stays unchanged.
