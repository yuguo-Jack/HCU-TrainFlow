# [Feat] lora: Dense execution plans (04/21)

[Upstream PR](https://github.com/sgl-project/sglang/pull/42871) · state: open · merged: False

## Original PR description

Part 04 of 21 of the LoRA runtime stack (branch `lora-stack-03-dense-plans`, base `lora-stack-02-dense-kernels`). The stack is cut from the development branch of #42284.

## What this part adds

Add the dense plan model (DensePlan, DenseLoraKind, table rows named by their
match fields), the plan loader with load-time validation and in-code defaults
for devices without a table, the default table, and the
SGLANG_LORA_DENSE_CONFIG_DIR override. Phase and architecture_for_capability
move to lora/utils for both engines.

Tests: plan and tile validation, defaults without a table, in-order row
matching, geometry rows per site, windowed and all-slots row rules.
