# [Fix] moe: Correctly route fused shared experts and normalize routed topk in grouped_topk

[Upstream PR](https://github.com/sgl-project/sglang/pull/47689) · state: open · merged: False

## Original PR description

## Motivation

In SGLang MoE routing (`python/sglang/srt/layers/moe/topk.py`), when models utilize fused shared experts (`num_fused_shared_experts > 0`, such as DeepSeek-V2 MoE architectures), the current implementations in `grouped_topk_gpu`, `biased_grouped_topk_impl`, and `fused_topk_native` contain placeholder logic using `torch.randint`:

```python
    if num_fused_shared_experts:
        topk_ids[:, -1] = torch.randint(
            low=num_experts,
            high=num_experts + num_fused_shared_experts,
            size=(topk_ids.size(0),),
            dtype=topk_ids.dtype,
            device=topk_ids.device,
        )
```

This causes severe correctness issues:
1. **Drops a routed expert**: It calls `torch.topk(k=topk)` and overwrites `topk_ids[:, -1]` with a random integer, discarding the last legitimately selected routed expert.
2. **Breaks multi-shared-expert models**: If `num_fused_shared_experts > 1` (e.g. DeepSeek-V2 has 2 shared experts), only one random shared expert slot is assigned, leaving the other shared experts never executed.
3. **Distorts routing weights**: Softmax normalization is performed across the wrong set of experts or perturbed by the placeholder assignment, corrupting output representations and causing generation to collapse.

## Modifications

1. **Deterministic Selection of Routed Experts**:
   - Compute `num_routed_topk = topk - num_fused_shared_experts if num_fused_shared_experts > 0 else topk`.
   - Perform `torch.topk` on the routed experts with `k=num_routed_topk`.
2. **Renormalize Routed Weights**:
   - Softmax/renormalize across only the selected `num_routed_topk` routed experts.
3. **Deterministic Appending of All Fused Shared Experts**:
   - Append all `num_fused_shared_experts` consecutive IDs (`[num_experts, ..., num_experts + num_fused_shared_experts - 1]`).
   - Assign exact scaling weights via `fused_shared_expert_weight(...)` (1.0 or `1.0 / routed_scaling_factor`).
4. **Unit Tests**:
   - Added `test_grouped_topk_with_fused_shared_experts` in `test/registered/kernels/ops/moe/test_fused_topk_deepseek.py` covering output shapes, exact shared ID sequence, weight normalization, and deterministic behavior.

## Accuracy Tests

- Tested on DeepSeek-V2 MoE layer parity (`num_routed=6, num_shared=2, intermediate=896`):
  - Cosine Similarity against reference ground truth: **1.000000**
  - Max Absolute Difference: **0.000977** (within FP16 rounding error).
- End-to-end document transcription on multi-page benchmarks:
  - 1-page, 3-page, and 15-page academic paper (17,824 tokens) parsed with 100% text fidelity (CER = 0.000).

## Speed Tests and Profiling

- No kernel regressions:
  - Preserves standard fast path when `num_fused_shared_experts == 0`.
  - Achieves steady 64.0 token/s decode throughput on Turing Tesla T10 with full CUDA graph capture (`bs=[1, 2, 4, 8]`).
