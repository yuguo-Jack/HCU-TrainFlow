## Modifications
This PR adds 3 complete test suites targeting the Ascend NPU platform, covering parameter effectiveness verification and functional validation. All test cases follow the existing test framework conventions and CI specifications, maintaining consistency with the current codebase.
1. **Linear Attention & ReplaySSM Parameter Validation Test**
    - Target parameters: `--linear-attn-verify-backend flashinfer`, `--enable-linear-replayssm-spec`
    - Validates whether the parameters take effect by checking characteristic startup log markers
    - Reuses standard server lifecycle management, health check and temporary log capture utilities
    - Registered to `full-2-npu-a3` nightly pipeline

2. **Legacy SMG gRPC Server Mode Test**
    - Target parameter: `--smg-grpc-mode` (legacy SMG gRPC server)
    - Verifies full startup flow through 7 gRPC readiness log markers + actual TCP port listening check
    - Implements real-time log tee output for in-place debugging
    - Registered to `full-1-npu-a3` nightly pipeline

3. **PD Disaggregation Decode Extra Slots Validation Test**
    - Target parameter: `--disaggregation-decode-extra-slots`
    - Verifies that extra slots correctly increase `c128_state_fixed` memory allocation in the DSV4 memory pool
    - Implements two-round comparison test (baseline vs extra_slots=64) with full process cleanup and resource release between rounds
    - Inherits from `PDDisaggregationServerBase` and follows the standard disaggregation test structure
    - Registered to `full-16-npu-a3` nightly pipeline
