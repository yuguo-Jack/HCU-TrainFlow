# [Test] managers: Check output_ids in the router grouping test

[Upstream PR](https://github.com/sgl-project/sglang/pull/47335) · state: closed · merged: True

## Original PR description

`test_multi_tokenizer_mixin.py::test_router_groups_token_output_without_speculative_decoding` fails on main with `AssertionError: None != [10, 20]`.

#47249 replaced the test's `decoded_texts` assertion with `prompt_tokens == [10, 20]`, while #47178 made `BatchTokenIDOutput.prompt_tokens` a Rust-server-only column that this fixture no longer sets. Each PR passed on its own; together the assertion reads `None`.

The assertion now checks `output_ids`, another per-row field the fixture sets, so the test still guards that grouping keeps per-row lists intact.
