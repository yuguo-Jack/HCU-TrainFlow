# [Fix] moe: Skip hash layers before topk_config in prefill routing paths

[Upstream PR](https://github.com/sgl-project/sglang/pull/48041) · state: closed · merged: True

## Original PR description

## Motivation

Fixes #48039.

Hash-routed MoE layers use `HashTopK`, which has no `topk_config` attribute. Two routing paths read `topk_config` before checking `is_hash`:

- the breakable-prefill dual-stream graph predicate
- the two vision top-k branches

Breakable prefill CUDA graph capture therefore raised:

```
AttributeError: 'HashTopK' object has no attribute 'topk_config'
```

Eager forward and `--cuda-graph-backend-prefill disabled` were unaffected because the leading breakable-graph check short-circuits.

## Modifications

- Check `is_hash` before accessing `topk_config` in `_can_dual_stream_graph`.
- Skip `vision_topk` for hash layers, preserving `HashTopK` with `input_ids`.

## Accuracy Tests

None. This changes only routing selection predicates; non-hash layers keep the same paths.
