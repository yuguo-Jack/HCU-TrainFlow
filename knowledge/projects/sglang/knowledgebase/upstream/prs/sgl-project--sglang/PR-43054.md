# [Spec] Fix DFLASH verify mask policy for wrapped attention backends

[Upstream PR](https://github.com/sgl-project/sglang/pull/43054) · state: closed · merged: True

## Original PR description

## Motivation

With DFLASH and split attention backends (`--prefill-attention-backend flashinfer --decode-attention-backend trtllm_mha`, default `--speculative-attention-mode prefill`), target-verify output is corrupted (GSM8K 0.03).

`resolve_dflash_verify_mask_policy` checks the skip list by class name, so `HybridAttnBackend` is not matched and verify CUDA graphs are captured with a custom mask. DFLASH replay always passes `custom_mask=None`, so FlashInfer runs the captured custom-mask kernel on a stale mask buffer.

## Modifications

- Resolve `HybridAttnBackend` / `TboAttnBackend` to the backend that runs `TARGET_VERIFY` before checking the skip list.
- FlashInfer: raise if a verify graph captured with a mask buffer is planned without a mask.
- Add unit tests.

## Accuracy Tests

Nemotron-3.5-Super NVFP4 + DFLASH (LiLiCorr), DGX SPARK(GB10), `lm_eval` GSM8K 5-shot:

|---|---|---|
| before | 0.027 / 0.005 | 3.75 |
| after | 0.923 / 0.848 | 5.51 |
| `--speculative-attention-mode decode` (reference) | 0.922 / 0.850 | 5.50 |

[by Claude Code] **Severity: functional | Confidence: High**

**Issue**

`_plan()` calls `call_begin_forward()` without `plan=`. The merge of main brought in #42753, which made `plan: KVLocPlan` a required keyword-only argument. `test_rejects_maskless_plan_on_masked_graph_wrapper` and all three `test_allows_consistent_plans` subtests now fail with `TypeError: call_begin_forward() missing 1 required keyword-only argument: 'plan'`. `flashinfer_backend` imports without a GPU, so these cases run in the CPU suite instead of being skipped.

**Fix**

Deleting this file, as asked in the thread on line 1, also removes the failure. If you keep it, pass a stand-in plan. `generate_attn_arg_prefill` is mocked, so nothing reads it:

```python
            spec_info=self._spec_info(custom_mask),
            plan=MagicMock(),
```

With this change, all 7 tests pass locally on CPU.
