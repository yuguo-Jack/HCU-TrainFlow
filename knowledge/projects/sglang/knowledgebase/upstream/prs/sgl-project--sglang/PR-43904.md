[Upstream PR](https://github.com/sgl-project/sglang/pull/43904) · state: open · merged: False

## Original PR description

Stacks on #43903

- New `DecodingBatch` owns every change to the running rows (join, leave, filter, retract, merge); the plan functions take it instead of a mutable `running_batch`.
- `running_batch` stays as a property over the rows.
