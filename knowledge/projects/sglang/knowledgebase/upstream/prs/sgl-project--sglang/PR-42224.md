# [NPU] add int8 LightingIndexer option to speedup it by 2X on A3 and A2

[Upstream PR](https://github.com/sgl-project/sglang/pull/42224) · state: open · merged: False

## Original PR description

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

A2 and A3 does not support FP8 lightingindexer. Add int8 quantization to speedup lighting indexer by 2x

## Modifications

Add int8 type for K cache for lighting indexer.
To enable int8 type set environment variable SGLANG_NPU_INDEXER_INT8=True

## Accuracy Tests
gsm8k shows 93% accuracy for int8 indexer cache

## Speed Tests and Profiling
The int8 lighting indexer itself is 2x faster than fp16

Test by sglang.benchmark.serving
python3 -m sglang.benchmark.serving --gsp-prompts-per-group 17 --host 127.0.0.1 --port 30000 --dataset-name generated-shared-prefix   --gsp-system-prompt-len 180000 --gsp-question-len 10828 --gsp-output-len 1 --gsp-num-groups 1 --backend sglang-oai-chat

average TTFT reduces from  67402 to 49125 (~-25%)
