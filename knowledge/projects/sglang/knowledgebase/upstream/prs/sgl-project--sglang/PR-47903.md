# [Feature] multimodal: [sglang-miles] Cache token-space media features per item before loading

[Upstream PR](https://github.com/sgl-project/sglang/pull/47903) · state: open · merged: False

## Original PR description

## Motivation

- The token-space processor loads and preprocesses every media item on every request, even when the same media came in moments earlier. Multi-turn chat resends every turn's media, and an RL trainer rebuilds each sample's processor tensors from the same media references the rollout engine already processed.
- `MultimodalPreprocessCache` serves only the legacy processors; token-space output was never cached.

## Modifications

- `TokenSpaceProcessor(item_feature_cache=...)` takes any map with `get` and `__setitem__`: a dict, an LRU, a disk cache. Each media item is keyed before loading by its source reference, its per-item kwargs (`video_metadata`), the request's devices, the checkpoint (`hf_config.name_or_path`), `mm_process_config` and the image processor backend. A hit skips loading and processing; misses are loaded and processed as before. Merge, expansion and span location still run per request, so the output is unchanged.
- Keys leave out the prompt, so samples and turns that share media reuse its features.
- Serving passes a `MultimodalPreprocessCache` sized by `--mm-preprocess-cache-size-mb`, but only with the new `--token-space-preprocess-cache-trust-url`: the keys are media URLs and paths rather than content, so a URL whose content changes would return stale features. The flag requires a positive cache size. `clear_preprocess_cache` now clears the cache.
- `build_cache_key` exposes the canonical-JSON digest `build_artifact_key` already used, and `_canonicalize` accepts PIL images by their content digest.
- `MultimodalPreprocessCache.__setitem__` gives it the map interface.

## Tests

`test_mm_token_expansion.py`: a later request with another prompt loads only its new image and matches an uncached processor's output; the same image on another device misses; processors sharing one map hit only for the same checkpoint and `mm_process_config`; serving uses the cache only with `--token-space-preprocess-cache-trust-url`. Fixture updates in `test_processor_async_call_sites.py`, `test_qwen_tokenized_media.py` and `test_processor_device_selection.py`.

Run on 1x H200 (`lmsysorg/sglang:dev`), each file in its own process: `test_mm_token_expansion.py`, `test_processor_device_selection.py`, `test_processor_trainer_import.py`, `test_processor_async_call_sites.py`, `test_token_space_registry.py`, `test_mm_token_expansion_start_len.py`, `test_preprocess_cache.py`, `test_media_artifact_processor.py`, `test_mm_process_config.py`, `test_server_args_namespaces.py` and `test_runtime_context_config_bags.py` pass. Two failures are the same on the unpatched base: `test_qwen_tokenized_media.py::test_selected_token_space_processor_keeps_the_scheduler_mrope_hook` when its file runs alone, and `test_server_args_docs_coverage.py::test_no_new_undocumented_flags`, which lists nine other flags and not the new one.
