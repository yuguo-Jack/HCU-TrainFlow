# sm120 support for trtllm mha prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/31959) · state: closed · merged: False

## Original PR description

currently sglang rejects trtllm_mha as a prefill backend on sm120 because the existing trt only supported sm100. 

but flashinfer  exposes trtllm_fmha_v2_prefill which supports SM120.

  ## Changes

  - Allow trtllm_mha prefill on SM120.
  - Route SM120 prefill to flashinfer.prefill.trtllm_fmha_v2_prefill. (https://docs.flashinfer.ai/generated/flashinfer.prefill.trtllm_fmha_v2_prefill.html)
  - Retain the existing prefill path on SM100.

  ## Motivation

  Running the following on SM120 previously failed during argument validation:

  sglang serve \
    --model Qwen/Qwen3.5-27B \
    --attention-backend trtllm_mha

  with:

  ValueError: TRTLLM MHA backend for prefill is only supported on
  Blackwell GPUs (SM100).

  The older FlashInfer TRT-LLM context-attention API also fails on SM120 with an unsupported-architecture error. FMHAv2 provides the required SM120 implementation.

  ## Validation

  Tested on an NVIDIA RTX PRO 6000 Blackwell Server Edition (SM120) with:

  - Qwen/Qwen3.5-27B
  - PyTorch 2.11.0+cu130
  - FlashInfer 0.6.14
  - BF16 KV cache
  - Page size 64
  - trtllm_mha for both prefill and decode
