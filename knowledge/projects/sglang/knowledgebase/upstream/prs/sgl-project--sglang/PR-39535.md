# [Fix] Pack non-contiguous weight tensors into flattened buckets

[Upstream PR](https://github.com/sgl-project/sglang/pull/39535) · state: closed · merged: False

## Original PR description

## Motivation

`FlattenedTensorBucket` packs each input with `tensor.flatten().view(torch.uint8)`. Flattening does not necessarily make a tensor contiguous: `torch.arange(8, dtype=torch.float32)[::2]` retains stride 2, and packing fails with `self.stride(-1) must be 1 to view Float as Byte`.

## Modifications

Make each flattened tensor contiguous before its byte view. This supports strided weight views without changing bucket metadata or the wire layout. Already-contiguous inputs need no additional copy from `contiguous()`.

Add exact CPU round-trip coverage for FP32, BF16 and FP16 tensors across contiguous, strided-vector, strided-matrix, transposed, scalar and empty layouts. Check names, dtype, shape, values and packed bytes.

Related #39264 optimizes receive-buffer allocation; this change is limited to sender packing and does not alter its allocation API or the mixed-dtype alignment contract.
