# Keep NIXL Mamba checkpoint keys separate by TP rank

[Upstream PR](https://github.com/sgl-project/sglang/pull/43594) · state: closed · merged: True

## Original PR description

## Motivation

MLA shares KV storage keys across TP ranks, but Mamba checkpoints are sharded. Give Mamba keys a TP rank/size suffix so one rank cannot overwrite another rank's checkpoint. Keep existing keys for other pools.

Old unranked Mamba objects are not reused because their owning rank is ambiguous.

Validation: real POSIX reproduction reads the other rank's state before the fix and the correct state after. Both copy and zero-copy regressions fail before and pass after. NIXL storage test module passes 22 tests and 2 subtests with one stress skip. GLM-5.3-Flash restart reproduces cross-rank corruption on main despite storage hits. After the fix, both 4096-token L3 restores preserve all 136 INDEXER/Mamba pages across four ranks. This validates buffered POSIX I/O.
