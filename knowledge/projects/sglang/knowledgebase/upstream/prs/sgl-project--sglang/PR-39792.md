# Fix unbounded chunk_idx growth in PD staging STAGING_REQ handler

[Upstream PR](https://github.com/sgl-project/sglang/pull/39792) · state: closed · merged: False

## Original PR description

Fixes #39764.

`STAGING_REQ` used to grow `chunk_staging_infos` to whatever `chunk_idx` arrived on the wire. Decode now rejects negative indices, non-positive page counts, and anything at or past the request's recorded page count (with a finite fallback cap if that span was never set). Mooncake and NIXL receivers record `_staging_total_pages` in `send_metadata`.

Unit test covers the huge-index OOM path and an in-range alloc.
