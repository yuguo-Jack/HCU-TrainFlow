# [diffusion] avoid redundant LoRA scaling while preserving exact numerics

[Upstream PR](https://github.com/sgl-project/sglang/pull/43028) · state: closed · merged: True

## Original PR description

Avoid redundant dynamic LoRA scale multiplications while preserving the current quality-tier contract. Unit scales are skipped in every tier; exact and requests without a forward context retain the original order of nonunit strength and request-scale multiplications. Combining those factors is restricted to requests that allow lossless.

The shared scaling helper is integrated with main’s dynamic-LoRA delta helper. Existing fused GEMM updates and row-parallel bias handling remain intact. The alpha/rank factor stays separate in the fallback path.

Regression coverage checks scale-operation counts by quality tier and compares exact outputs bit for bit on CPU and CUDA, including nonbinary strength/request scales (0.7 and 0.6). Targeted remote tests: 77 passed; scoped pre-commit passed. Final CI is tracked on the new head. No GT or accuracy thresholds were changed.
