# [CI] [NVIDIA] DSv4.1-Flash: Split GB300 accuracy test into one file per config

[Upstream PR](https://github.com/sgl-project/sglang/pull/44696) · state: closed · merged: True

## Original PR description

## Summary

- Split `test/registered/e2e/models/test_deepseek_v41_flash_gb300.py` into one file per server configuration, so each one partitions independently across the `4-gpu-gb300` runners instead of running all four servers back to back in a single file:
  - `test_deepseek_v41_flash_gb300_tp4ep4.py`: TP4 + EP4
  - `test_deepseek_v41_flash_gb300_dp4ep4.py`: DP-attention4 + EP4
  - `test_deepseek_v41_flash_gb300_bounded_replay_bcg.py`: TP4 + EP4 with decoder SWA bounded replay in breakable prefill graphs
  - `test_deepseek_v41_flash_gb300_trtllm_bounded_bcg.py`: TRT-LLM attention with bounded replay in breakable prefill graphs
- Move the shared DSPARK accuracy mixin (GSM8K + MMMU-Pro, draft-acceptance check) to `sglang.test.dsv41_flash_common`.
- Test coverage is unchanged: the same 4 configurations × 2 evals (8 cases), with the same thresholds.
