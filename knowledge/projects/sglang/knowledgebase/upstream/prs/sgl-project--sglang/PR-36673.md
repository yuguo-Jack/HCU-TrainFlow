## Motivation

Read subprocess stdout on a background thread in the CI test runner to avoid an EOF deadlock.

## Modifications

### 1. Read subprocess stdout on a background thread in `python/sglang/test/ci/ci_utils.py`

`run_unittest_files` reads subprocess output with a blocking `for line in process.stdout` loop before calling `process.wait()`. When the subprocess produces enough output to fill the pipe buffer, the loop can block indefinitely on EOF, causing a deadlock.

- Move the stdout-reading loop into a background daemon thread (`read_output`) started before `process.wait()`.
- `join(timeout=60)` on the reader thread so the main thread never blocks indefinitely on EOF.
