# [Feat] [CPU] model: Support Ling models on CPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/47855) · state: open · merged: False

## Original PR description

## Motivation

Add CPU platform support for the Ling series of models.

- `inclusionAI/Ling-3.0-flash`: Throws an error when `extra_buffer` is not set.
- `inclusionAI/Ling-3.0-tiny`: Convolution weights bypass the `dtype` check, causing FP32 data to be passed into a packed kernel that only supports FP16/BF16.

## Modifications
The following modifications have been made to address these issues:
- `inclusionAI/Ling-3.0-flash`: Added a platform capability check before selecting `extra_buffer`; falls back to `no_buffer` if unsupported.
- `inclusionAI/Ling-3.0-tiny`: For unsupported `dtype` values, the original weights are retained and AMX is disabled for that layer; low-precision weights continue to follow the existing execution path without forced precision conversion.
