## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111, #45311, #45513, #45749, #46005, #46506, #46547, #46807) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Pins two lanes to their `/use` runs**: Qwen3.5 FP8 H200 ([InferenceX #4455](https://github.com/SemiAnalysisAI/InferenceX/pull/4455), same head as #46807) and Muse Spark Open B300 ([InferenceX #4417](https://github.com/SemiAnalysisAI/InferenceX/pull/4417), merged 2026-10-28 and not on the dashboard yet). #46807 showed both as in progress.
2. **Moves DeepSeek-V4 B200 Dynamo+SGLang disagg back to its measured `main` run** ([InferenceX #3257](https://github.com/SemiAnalysisAI/InferenceX/pull/3257)): [InferenceX #4556](https://github.com/SemiAnalysisAI/InferenceX/pull/4556) (DSpark6 HiCache, still WIP) is no longer overlaid.
3. **Shows MiniMax-M3.1-Flash B300 at [InferenceX #4524](https://github.com/SemiAnalysisAI/InferenceX/pull/4524)'s head**, which now also changes the TP4 recipe `main` measured (FP8 draft KV, in progress).
4. **Keeps five merged Klaud-Cold image bumps that the InferenceX dashboard still does not show**, pinned to their `/use` runs (see below).
5. **Syncs to InferenceX `main`** (`67de4b34`) and overlays the InferenceX PRs in the table below.
