## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111, #45311, #45513, #45749, #46005, #46506, #46547, #46807, #46948, #47027, #47214, #47464) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Reverts #47560 and overlays its source PR instead.** #47560 added a hand-written module (`qwen3.8-flash-next-b300.jsx`) and extra section text to the Qwen3.8-Flash-Next page for the configurations of [InferenceX #4683](https://github.com/SemiAnalysisAI/InferenceX/pull/4683). This PR reverts it and overlays [InferenceX #4683](https://github.com/SemiAnalysisAI/InferenceX/pull/4683) through the sync. The same eight B300 configurations are now generated, pinned to the run #47560 cited:
   - TP1 at c1, 2, 12, 24, 48, 80.
   - TP4·EP4 at c1, 2.

   They replace the B300 key's earlier RadixArk-checkpoint configurations, as #4683 does in `nvidia-master.yaml`.
2. **Syncs to InferenceX `main`** (`c5e8b9b3`). These merged lanes now come from their dashboard runs:
   - MiniMax-M3.1-Flash GB300 SGLang: [InferenceX #4676](https://github.com/SemiAnalysisAI/InferenceX/pull/4676), [run 41054395691](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41054395691), 2026-10-31.
   - MiniMax-M3.1-Flash GB300 Dynamo+SGLang agg and disagg: [InferenceX #4698](https://github.com/SemiAnalysisAI/InferenceX/pull/4698), [run 41271829525](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41271829525), 2026-11-02. It follows [InferenceX #4686](https://github.com/SemiAnalysisAI/InferenceX/pull/4686).
   - DeepSeek-V4.1-Flash GB300 Dynamo+SGLang: [InferenceX #4595](https://github.com/SemiAnalysisAI/InferenceX/pull/4595) plus the append-only points of [InferenceX #4679](https://github.com/SemiAnalysisAI/InferenceX/pull/4679), [run 41081085818](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41081085818), 2026-10-30.

   #47623, #47699 and #47791 had edited the MiniMax data by hand for [InferenceX #4675](https://github.com/SemiAnalysisAI/InferenceX/pull/4675) / [#4676](https://github.com/SemiAnalysisAI/InferenceX/pull/4676) / [#4686](https://github.com/SemiAnalysisAI/InferenceX/pull/4686) / [#4698](https://github.com/SemiAnalysisAI/InferenceX/pull/4698). All four have since merged, and the sync regenerates the file from InferenceX `main` and the dashboard.
3. **Overlays seven more InferenceX PRs:**
   - Muse Spark Open, retuned per concurrency: B300 on the `20261030` nightly, GB300, B200 and GB200.
   - MiniMax-M3.1-Flash: GB200 Dynamo+SGLang config, and new B300 TP2 / TP4 points.
   - DeepSeek-V4.1-Flash GB300 SGLang on the `20261030` nightly.

- **Three new mirrored settings** (kept as submitted):
  - `DYN_TCP_CONNECT_TIMEOUT`: the Dynamo request-plane TCP connect timeout, on the MiniMax-M3.1-Flash GB200 / GB300 Dynamo+SGLang lanes.
  - `--prefill-decode-interval-min-bs`: applies `--prefill-decode-interval` only at or above that running batch size (#44001), on Muse Spark Open GB300.
  - `--strip-thinking-cache`: keeps only the prompt prefix of finished reasoning requests in the radix cache (#23315), on Qwen3.8-Flash-Next B300 c80 ([InferenceX #4683](https://github.com/SemiAnalysisAI/InferenceX/pull/4683)).
- **Variant sweeps.** The MiniMax-M3.1-Flash B300 key measures up to five variants of one shape at the same concurrency, for example TP2 at c48. When no single worker flag tells them apart, each deployment is now labeled with the flags that do, e.g. `--prefill-decode-interval 24 · --mem-fraction-static 0.93`. Deployments that one flag already separated keep their labels.
- **MiniMax GB300 Dynamo image.** The MiniMax-M3.1-Flash GB200 / GB300 Dynamo+SGLang lanes use `lmsysorg/sglang:nightly-cu134-20261030-e371881`. It is an arm64-only image whose config reports `SGLANG_BUILD_COMMIT=unknown`. The tag suffix and the installed `sglang-0.0.0.dev1+ge3718813e` both identify SGLang `e3718813`, which is now used for its KV-tier checks.
- The GLM-5.2 and GLM-5.3 data change only in their shared source block (the InferenceX `main` SHA and the overlay list).
