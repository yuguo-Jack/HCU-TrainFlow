## Motivation

KV readers and writers currently infer their address space from pool types and full/window roles. That makes shared draft storage and physical window writes depend on duplicated translation decisions.

## Changes

- Build the KV index translator from named subpool ID spaces and share those identities with fused drafts.
- Route window metadata and writes through the declared ID spaces, including identity, translated, static and DCP paths.
- Check target-verify support on the backend that executes verification instead of gating it by the speculative algorithm name.

Use `CustomTestCase` for the DCP address-mapping tests.

## Validation
