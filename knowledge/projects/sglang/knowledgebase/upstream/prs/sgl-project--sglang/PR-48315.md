# [Test] elastic-ep: Register NIXL EP CI coverage

[Upstream PR](https://github.com/sgl-project/sglang/pull/48315) · state: open · merged: False

## Original PR description

## Motivation

Register the existing manual NIXL EP test under `test/registered/ep/test_deepep_large.py` so CI can exercise NIXL EP coverage through the standard registered test rerun workflow. The NIXL 1.3.0 package is incompatible with the CI image's Torch 2.14 ABI, so the installer must select a NIXL release that provides the Torch-versioned extension.

## Modifications

- Install `nixl>=1.5.0` and the CUDA 13 binary package with `--no-deps`.
- Add the manual NIXL EP wrapper to `test/registered/ep/test_deepep_large.py`.
- Skip the existing DeepEP large tests in CI while retaining their local manual behavior.
- Keep the Elastic EP scale wrapper registered but skipped until its runtime path is ready for CI.
- Remove the temporary Mooncake PR #5063 wheel override used by the earlier validation-only branch.

## Accuracy Tests

Not run locally in this source-only registration change. The registered NIXL test provides the CI accuracy gate.

## Speed Tests and Profiling

Not applicable.
