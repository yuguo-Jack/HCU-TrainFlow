# [Fix] mamba: Skip exhausted checkpoint donation and retain request state

[Upstream PR](https://github.com/sgl-project/sglang/pull/43853) · state: open · merged: False

## Original PR description

## Motivation

An unfinished request can exhaust the Mamba pool while its matched prefix is
admission-locked. Optional checkpoint donation must skip allocation rather than
crash, and cleanup must retain the undonated checkpoint so immediate completion
can cache the full prefix.

## Changes

Integrate the original allocation commits from David Orman's #37619 unchanged,
preserving their history. Combine them with this PR's non-int8 cleanup guard.
The existing cleanup regression now calls the real cache.checkpoint pipeline
before finishing the request, covering the complete failure path rather than
calling cleanup directly.

The update is merge commit 141d8c992294ba3b40808c4be128144b08337ebc, with
parents 03a3d55305b2307cbeec42dfb53384f86017bcfc (this PR's published head) and
cd530ac217ac0a67b913f7083679c0890670d228 (#37619). It can update this PR without
rewriting published history. Allocation behavior comes from #37619; the distinct
follow-up fixes undonated checkpoint ownership and proves immediate finish.

The tested current head 43b4c9b9 also includes upstream main 51faf523 and the
required CI base b6778515 without rewriting either predecessor.

## Validation

- 30 relevant tests passed in the source-pinned Torch 2.14.1+cu130 SGLang runtime
  with real native imports, including 35 subtests. These cover exhaustion,
  cleanup, pool sizing, capacity admission and unified Mamba views.
- Normal and lazy full-pool checkpoint/finish lifecycle proofs retain 128 prefix
  tokens and return every Mamba slot exactly once. The prerequisite without the
  cleanup fix retained only 64 prefix tokens.
- Full configured pre-commit hooks passed on all three changed files.
- git diff --check passed; the merge is a fast-forward update of this PR's head.

The tests use real cache/pool classes with CPU fixtures. Mamba model inference,
accuracy, performance and full upstream CI remain unverified. Full upstream CI
requires authorization through the project's run-ci label.

Implementation and validation were assisted by Codex. The merge includes DCO
signoff and Codex attribution; the original prerequisite authorship is preserved.
