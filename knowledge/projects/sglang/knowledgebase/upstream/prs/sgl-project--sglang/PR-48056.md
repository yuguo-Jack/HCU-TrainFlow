# [Feat] diffusion: Add DM05 action inference

[Upstream PR](https://github.com/sgl-project/sglang/pull/48056) · state: closed · merged: False

## Original PR description

## Motivation

Add [DM05](https://github.com/dexmal/opendm) support to SGLang's action API.

## Modifications

- Add the DM05 prefix encoder, action expert, checkpoint loader and input/output transforms, using Transformers Gemma3 components.
- Support the Base, LIBERO, RoboTwin2 and MEM-Robodojo-Sim checkpoints through the existing scheduler, action transports, prefix cache and CUDA Graphs.
- Add unit tests, a pinned LIBERO HTTP test and a deployment guide.

The model implementation follows [OpenDM at fe1ed79](https://github.com/dexmal/opendm/tree/fe1ed79a22d81cc1bfbeb2b4418bbb79fc75fc50).

## Accuracy Tests

- CPU regression: **260 passed, 3 skipped** (CUDA-only and synchronous-cancellation cases).
- Model tests on RTX4090: **15 passed**; existing Flux3 Action regressions: **37 passed**.
- Four checkpoints, 38 fixed-input cases: full prefix K/V and normalized actions match OpenDM eager and native CUDA Graph outputs with matching runtime versions.
- LIBERO, 40 tasks: SGLang **1,964/2,000 (98.20%)**, OpenDM **1,967/2,000 (98.35%)**. Paired difference: −0.15 percentage points; fixed-task bootstrap 95% interval: [−0.75, +0.45].

GPU, LIBERO and latency results were collected before the final input-validation, grouping and metadata fixes; the neural implementation is unchanged.

The HTTP CI case is a smoke test. Component accuracy, golden-output and performance checks are disabled pending a DM05 fixture in the pinned CI data and an H100 baseline.

## Speed Tests and Profiling

RTX4090, LIBERO, B1/H10/10 denoising steps, prefix reuse off; 2 cold requests, 10 warmups and 50 measured requests per service:

| Service | Application P50 / P95 (ms) | HTTP client P50 / P95 (ms) |
| --- | ---: | ---: |
| OpenDM + JSON adapter | 192.104 / 194.071 | 234.769 / 238.929 |
| SGLang | 177.582 / 180.366 | 178.657 / 181.581 |

Application timing includes preprocessing and response encoding. OpenDM used Torch 2.11/Transformers 5.3; SGLang used Torch 2.14/Transformers 5.19. These compare the two service stacks.

Changed-file pre-commit and the documentation checks passed. Full-repository pre-commit passed all non-Rust hooks; four Rust hooks could not run without `cargo`/`rustup`, also on unmodified main.
