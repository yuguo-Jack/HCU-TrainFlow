# [Fix] [XPU] server_args: Disable decode graph on XPU when tp_size > 1

[Upstream PR](https://github.com/sgl-project/sglang/pull/47459) · state: closed · merged: False

## Original PR description

fixes #45034

### what changed
on intel xpu, decode graph capture does not record all-reduce collectives into XPUGraph replays, causing tp ranks to diverge and draft acceptance to collapse under tp > 1.

disables the decode graph with a warning in `handle_xpu_backends` when `device == "xpu"` and `tp_size > 1`. added unit tests for xpu tp=1 vs tp>1 decode graph resolution.
