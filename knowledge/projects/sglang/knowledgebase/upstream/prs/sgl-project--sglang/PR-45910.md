## Motivation

The [DeepGEMM release job](https://github.com/sgl-project/sglang/actions/runs/39866337913/job/120130535490) fails during dependency preflight because upstream removed `tilelang_ops.ref_mhc` after moving the mHC PyTorch reference into its test file.
