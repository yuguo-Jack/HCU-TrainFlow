# [Fix] diffusion/realtime: Keep frame payloads contiguous

[Upstream PR](https://github.com/sgl-project/sglang/pull/46250) · state: closed · merged: True

## Original PR description

## Motivation

Large realtime frame batches use two WebSocket messages: a MessagePack header
followed by the raw payload. Under send backpressure, the event listener could
insert an error response between them. Clients then interpreted the error as
video data. A failure while generating the next chunk could also cancel the
previous chunk's unfinished send before reporting the error.

## Changes

- Serialize frame output and invalid-event responses with a per-session lock.
- Finish pending output before reporting a subsequent generation error. Client
  disconnect and cancellation retain their existing cancellation paths.
- Extend existing realtime tests; preserve generation/send overlap.
- Correct the SANA-WM cookbook and client example to handle both inline
  `frame_batch` and `frame_batch_header` + binary payload.

No new configuration, output queue, payload copy, or model changes. Production
code changes are limited to two existing files (+15/-10).

## Validation

- Linux realtime suite: **2 failed, 152 passed** before the fix; **154 passed**
  afterward, including on the final head. The protocol regression uses the real
  WebSocket and output adapter with deterministic ASGI send backpressure.
- Real SANA-WM streaming server on **1x H200**, 256x256, 4 steps, seed 42:
  five sessions per revision covering normal completion, invalid events,
  disconnect and reconnect. A test-only 100 ms delay after header writes exposes
  the transport interleaving. Baseline corruption reproduced; with the fix,
  all four invalid-event responses arrived outside frame pairs and video
  payload hashes matched the clean baseline. Health remained HTTP 200.
- The optional refiner was disabled for this lifecycle test. This is not a
  full-quality benchmark, a speedup claim, or proof of failover/long-run HA.
- Pre-commit passes. No new GPU CI job is added.
