# [Bench] Fix bench_serving multi-turn reasoning handling and add --multi-turn-echo-reasoning

[Upstream PR](https://github.com/sgl-project/sglang/pull/39866) · state: open · merged: False

## Original PR description

## Motivation

The multi-turn client sends each round's assistant message back with `content` = reasoning + answer, which no real client does: OpenAI-style clients send `content` only, and Kimi K3's API requires `content` plus `reasoning_content`. For a thinking model this decides whether the chat template reproduces the generated tokens, and therefore how far a prefix-cache hit reaches on the next round.

## Modifications

- Track `reasoning_text` and `content_text` separately in the chat request paths. `generated_text` is unchanged for output accounting.
- Multi-turn rounds send `content` only by default. `--multi-turn-echo-reasoning` also sends `reasoning_content`.
- CPU tests for the field separation, the assistant message, and two-round requests against a fake server. Docs for the flag and `--gsp-num-turns`.

## Accuracy Tests

N/A, benchmark client only. `test/registered/bench_fn/test_bench_serving_reasoning_stream.py`: 15 passed.

## Speed Tests and Profiling

No engine change. Kimi-K3 (TP 8, 8xB300, `--reasoning-parser kimi_k3`), one two-round conversation per run, cache flushed before each:

```bash
python -m sglang.benchmark.serving --backend sglang-oai-chat --dataset-name generated-shared-prefix \
  --gsp-num-groups 1 --gsp-prompts-per-group 1 --gsp-num-turns 2 --gsp-system-prompt-len 1024 \
  --gsp-question-len 32 --gsp-output-len 2048 --disable-ignore-eos --num-prompts 1 \
  --max-concurrency 1 --warmup-requests 0 [--multi-turn-echo-reasoning]
```

Round 1 is identical in all runs (1,213 prompt tokens, ~390 generated, ~309 of them reasoning). Round 2, from the server's `Prefill batch` line:

| client | assistant message sent in round 2 | prompt tokens | cached | prefilled |
|---|---|---|---|---|
| before this PR | `content` = reasoning + answer | 1,686 | 1,152 | 534 |
| after, default | `content` = answer | 1,377 | 1,152 | 225 |
| after, echo flag | `content` = answer, `reasoning_content` = reasoning | 1,686 | 1,536 | 150 |

The default removes the 309 reasoning tokens from the prompt at the same hit depth. With `--multi-turn-echo-reasoning` the hit extends 384 tokens into the previous turn.
