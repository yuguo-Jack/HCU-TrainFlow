## Integration and behavior

`Li-brua:feat/dsv41-pdmux` and the spec branch share `fee732a7c9bbcf57dac315b939196583ac13e109`. There are exactly four feature commits above `5b5d72123935dc2a3fb341790796ec1a987d31ce`, with one commit per layer and no follow-up fixup/revert commits. This tracker has its own documentation branch.

- Use local running-batch stream selection, decode gather after selection, maximum DP token counts for split budgeting, a TP-only prefill group override and cached sampler request groups. No extra layer-count cap, raw-count snapshot or final bidirectional handoff fence.
- Retain HiCache progress/ownership, peer-work IDLE participation, per-slice prepare/pad/unpad and final-only NextN/DSpark extension/injection.
- Preserve DeepSeek metadata/backend isolation and model-specific stream/workspace protections required by unfinished split prefills.
