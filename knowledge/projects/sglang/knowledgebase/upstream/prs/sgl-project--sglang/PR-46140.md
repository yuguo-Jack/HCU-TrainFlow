# [Feat] quantization: Add the MiniMax-M3.1 NVFP4 MoE method

[Upstream PR](https://github.com/sgl-project/sglang/pull/46140) · state: closed · merged: True

## Original PR description

## Summary
`minimax_m3_nvfp4` quantization for the MiniMax-M3.1 checkpoint: NVFP4 experts on the TRT-LLM routed runner, MegaMoE, or Marlin, with the deferred-finalize handoff for the routed runner, plus the MiniMax VL config and model-config helpers.

## Changes to existing code
- `FusedMoE.supports_deferred_finalize` is also true for packed NVFP4 experts on the TRT-LLM routed runner.
- The FP4 deferred-finalize input check also accepts packed routed TopK.
- `QuantizationConfig.convert_mxfp8_to_block_fp8` (default `None`) lets a config decide whether its MXFP8 weights convert to block FP8 at load.
- MegaMoE and the FlashInfer TRT-LLM routed MoE treat `minimax_m3_nvfp4` as NVFP4 experts.

## Verification
- test_minimax_m31_nvfp4_trtllm_moe, test_mega_moe_deepgemm_api


Cut byte-for-byte from #45925 (MiniMax-M3.1-Flash support) at 10e655aa98.
