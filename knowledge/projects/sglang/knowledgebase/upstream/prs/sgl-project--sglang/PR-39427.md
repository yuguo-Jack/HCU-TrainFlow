- ClownBin · comment · 2026-09-17T08:08:54Z · [source](https://github.com/sgl-project/sglang/pull/39427#discussion_r4034556028)

File: `python/sglang/srt/models/deepseek_v4.py` · line 3494

[P1] Keep the public inference entrypoint under `torch.no_grad()`. The decorator newly added to `self.model.forward` does not cover `self.logits_processor(...)`/LM head. Normal eager decode and non-CP extend call this outer method without an enclosing inference/no-grad context, so the LM head starts recording an autograd graph for each request (and retains its input hidden states). This is a substantial memory/performance regression.
