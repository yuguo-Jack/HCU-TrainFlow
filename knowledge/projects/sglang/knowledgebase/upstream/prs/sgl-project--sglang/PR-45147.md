## Motivation

Current DeepSeek V4, V41's chat template doesn't render response format content, which is not aligned with DeepSeek's API doc: https://api-docs.deepseek.com/api/create-chat-completion/

<img width="953" height="397" alt="image" src="https://github.com/user-attachments/assets/b4f25c87-58a0-47e6-9b6d-9c88b9057c01" />

This PR injects the request's `response_format` into the system prompt so it can be rendered correctly.

Notes:
- **Unsupported Formats:** While SGLang supports additional response formats (such as structural tags), these are not supported according to the API documentation and are intentionally excluded from rendering.
- **DeepSeek Compatibility:** `json_schema` is converted to `json_object` by default to align with DeepSeek's official API specifications.

## Modifications

- Added `response_format` rendering into the system prompt construction.
- Filtered out unsupported format types (e.g., structural tags, text) to comply with official API specs.
