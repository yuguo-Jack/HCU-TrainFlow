Updates the `add-jit-kernel` agent skill.

- New `performance-cuda.md`: cost model for low-latency vs high-throughput kernels, B200 reference throughputs, SASS checks, SM100 notes (TMEM, `setmaxnreg`, tensor maps, PDL, clusters), and rules for comparing variants fairly.
- `SKILL.md`: links the new guide; documents header-library helpers that were missing (`once.h` / `logging.h`, `mbarrier.cuh`, `algorithm.cuh`, `gemm/dot_product.cuh`, fast activations, `fma_f32_bf16`, packed fp32 ops, `fast_mod_div_u32_t`, ordered atomics, shared-memory / L1 carveout runtime helpers); adds conventions (`TensorMatcher` style, `CHECK_HOST` / `CHECK_CUDA`, PTX wrapper naming, comments, when to promote a helper); uses `current_arch()` for Python-side arch gating; shows `parallel_compile` in tests; adds `ensure_alignment` to the scale example.

Docs only, no code changes.
