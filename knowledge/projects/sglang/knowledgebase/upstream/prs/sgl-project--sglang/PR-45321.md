# [Feat] alice-ai: add model and checkpoint MTP support

[Upstream PR](https://github.com/sgl-project/sglang/pull/45321) · state: open · merged: False

## Original PR description

## Motivation

Support [AliceAI-Foundation-80B-A3B-Base](https://huggingface.co/yandex/AliceAI-Foundation-80B-A3B-Base/blob/main/README_en.md), based on the [vLLM implementation](https://github.com/vllm-project/vllm/pull/57963).

## Modifications

- Add standalone AliceAI configuration, model, checkpoint weight mappings, and KDA cache registration.
- Reuse SGLang's existing KDA, attention, Attention Residual, and MoE implementations.
- Add the checkpoint MTP head through the existing NEXTN/EAGLE path, sharing the target embedding and LM head.
- Add 16 CPU unit tests covering configuration, routing, Attention Residuals, checkpoint loading, and MTP integration, plus a case in the existing fused QK norm/RoPE test for AliceAI's packed QKV layout and partial rotary dimensions.
