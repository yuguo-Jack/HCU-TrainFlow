# [Feat] diffusion: LRU eviction for LoRA merge cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/47605) · state: closed · merged: True

## Original PR description

Follow-up to #45834, split out per review.

## What
When free disk is short, evict the least recently used other merge cache stores before giving up on caching. A store's directory mtime is refreshed when it is adopted, so adoption order drives eviction order.

`get()` now returns `None` if another instance evicts the store between `is_complete()` and `get()`, instead of raising `FileNotFoundError`. That was the concern that led to splitting this out.

## Tests
`test_lora_merge_cache.py` (8 passed, CPU): LRU store is the one evicted under low space, and `get()` survives a store removed after `is_complete()`.
