# [Test] kda: Cover contiguous QKV graph inputs and asymmetric fallback

[Upstream PR](https://github.com/sgl-project/sglang/pull/47451) · state: open · merged: False

## Original PR description

## Motivation

The contiguous-QKV convolution implementation is now on main through #46738. The FlashInfer wrapper can materialize noncontiguous Q/K/V inputs, so numerical graph/eager comparisons alone would not detect a regression that reintroduces the three copies. The graph dispatch also needs coverage for unequal Q/K/V widths, where grouped output is invalid.

## Modifications

- Assert that the real convolution produces contiguous Q/K/V before the FlashInfer graph wrapper can copy them. Continue through the actual wrapper and existing capture/replay output and state comparisons.
- Exercise `kda_extend_in_graph` with unequal Q/K/V widths and check that the original split layout preserves the individual widths and tensor values.

Rebased onto main `180e7a154a46fac3f9381d68b451da1319e29c4f`; current head is `b2b5eb955c540d8c2254bae36665921bb82fc552`. This includes the upstream lint fix in #43902 (a duplicate `tree_cache` keyword in the unrelated decode queue test). The PR patch is byte-for-byte identical to the previously reviewed patch. The remaining diff contains only these two test files; it uses the production implementation from #46738, including its runtime output-plane pitch, and the input-copy helper from #47651.
