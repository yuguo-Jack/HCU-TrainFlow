# [Fix] multimodal: Prevent circular boundary wraparound in BaseMultimodalProcessor.get_mm_items_offset

[Upstream PR](https://github.com/sgl-project/sglang/pull/47884) · state: open · merged: False

## Original PR description

## Motivation

`BaseMultimodalProcessor.get_mm_items_offset` currently detects multimodal token span boundaries using circular shifts via `torch.roll(mask, 1)` and `torch.roll(mask, -1)`:

```python
mask = input_ids == mm_token_id
start_positions = (mask & ~torch.roll(mask, 1)).nonzero(as_tuple=True)[0]
end_positions = (mask & ~torch.roll(mask, -1)).nonzero(as_tuple=True)[0]
```

Because `torch.roll` wraps around circularly (`mask[-1]` rolls into index `0` and `mask[0]` rolls into index `-1`), any `input_ids` sequence that both starts (`input_ids[0] == mm_token_id`) and ends (`input_ids[-1] == mm_token_id`) with `mm_token_id` produces corrupted offsets:
1. **Single span covering the whole sequence** (e.g., `input_ids = [3]` or `[3, 3, 3]` with `mm_token_id = 3`): `start_positions` and `end_positions` are both empty, returning `[]` instead of `[(0, 0)]` / `[(0, 2)]`.
2. **Multiple spans touching both sequence boundaries** (e.g., `input_ids = [3, 3, 1, 2, 3, 3]` with `mm_token_id = 3`): index `0` is suppressed as a start position and index `N - 1` is suppressed as an end position, so `zip(start_positions, end_positions)` pairs the start of the second span (`4`) with the end of the first span (`1`), returning an inverted range `[(4, 1)]` instead of `[(0, 1), (4, 5)]`.

## Modifications

- Replace the circular `torch.roll(mask, 1)` and `torch.roll(mask, -1)` calls in `BaseMultimodalProcessor.get_mm_items_offset` with non-circular zero-padded slicing (`padded = torch.nn.functional.pad(mask, (1, 1), value=False)` followed by `padded[:-2]` and `padded[2:]`), handling empty `input_ids` cleanly.
- Add unit test `TestGetMmItemsOffset.test_boundary_spans_do_not_wrap_around` in `test/registered/unit/multimodal/test_base_processor_image_decode.py` covering empty sequences, all-multimodal sequences, boundary-spanning multi-image sequences, and interior spans.
