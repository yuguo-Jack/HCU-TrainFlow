# [Perf] [ROCM] diffusion: Bit-exact fast QK RMSNorm and fused RoPE for MiniMax-H3

[Upstream PR](https://github.com/sgl-project/sglang/pull/47569) · state: closed · merged: True

## Original PR description

## Motivation

On ROCm, H3 keeps the per-head QK RMSNorm on aten `rms_norm`. Its `vectorized_layer_norm_kernel` runs one 256-thread block per 128-wide row (~0.6 TB/s) after a `.contiguous()` copy of each strided q/k view of the fused QKV: QK norm plus that copy is 5.1% of a denoise step (43.7 ms/step) at 1280x704 on 4xMI355X.

## Modifications

- New Triton kernel `aten_head_rmsnorm_triton.py` that replays aten's arithmetic (4 contiguous squares per lane, shfl-down fold 16/8/4/2/1, rsqrtf, `w * (rstd * x)`) and reads the strided q/k views directly. It is used only after a first-sight `BitExactFusionGate` check against the eager path passes.
- Second commit: the bf16 NeoX RoPE (each product and the sum rounded to bf16, dims past rot_dim passed through) is applied in the same pass, behind its own first-sight gate.
- Tests added to `test/registered/kernels/ops/diffusion/test_norm.py` (fail on main, pass here).

## Accuracy Tests

Bitwise: MP4 md5 identical to main for every prompt checked (22/22 in the final 20-prompt run, which includes the other ROCm branches), plus the kernel unit test comparing against aten bit for bit.

## Speed Tests and Profiling

Setup for all numbers below: 4x MI355X, MiniMax-H3 T2VA, 1280x704 (SemiAnalysis "720p"), 124 frames, 49 forwards, Ulysses 4 + aiter, single stream. Each arm is a fresh server (1 warmup + 3 timed requests), ABAB across two rounds, base = main `75a5da7f`.

| | 720p median |
|---|---|
| main | 44.78 s |
| + QK norm | 42.51 s (-2.27 s) |
| + RoPE fusion | a further -0.17 s |

QK norm per step: 43.7 ms -> 7.1 ms.
