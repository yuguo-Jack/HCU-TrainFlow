## Original PR description

## Motivation

`embed_mm_inputs` clamps caller-owned IDs in place, destroying multimodal placeholders and potentially modifying a packed batch through a tensor view.

## Modifications

- Clamp a temporary tensor for the text-embedding lookup, matching the split-batch path.
- Test owned tensors and views across repeated calls: IDs/backing storage stay unchanged, and image/text embedding rows remain correct.
