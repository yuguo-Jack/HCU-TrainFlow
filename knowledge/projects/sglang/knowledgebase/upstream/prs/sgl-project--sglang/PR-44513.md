# [Fix] humming: Respect SGLANG_CACHE_DIR for cache and temporary files

[Upstream PR](https://github.com/sgl-project/sglang/pull/44513) · state: open · merged: False

## Original PR description

## Motivation

Humming defaults to `~/.humming` and locks outside `SGLANG_CACHE_DIR`. These files are therefore excluded from deployments that persist or prewarm the SGLang cache directory.

## Modifications

Add Humming to the existing third-party cache redirection:
- `HUMMING_CACHE_DIR` defaults to `$SGLANG_CACHE_DIR/humming/cache`.
- `HUMMING_TMP_DIR` defaults to `$SGLANG_CACHE_DIR/humming/tmp`.
