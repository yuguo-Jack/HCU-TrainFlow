## Code Review

This pull request adds support for warming up prefix caches using only the shared `system_prompt` portion of a dataset row, preventing formal requests from hitting 100% of the prefix cache. Feedback on the changes identifies a critical bug in `serving.py` where `test_request.system_prompt` is printed before checking if the attribute exists, which will raise an `AttributeError` for requests without this attribute.

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The debug print statement `print(f"{test_request.system_prompt=}")` is executed before checking if `test_request` actually has the `system_prompt` attribute. If `test_request` does not have this attribute, this will raise an `AttributeError`. Additionally, printing the entire system prompt (which can be very long) to stdout clutters the benchmark output. This debug print should be removed.

```python
    warmup_prompt = test_request.prompt
    warmup_prompt_len = test_request.prompt_len
    if (
        hasattr(test_request, "system_prompt")
        and test_request.system_prompt is not None
    ):
        warmup_prompt = test_request.system_prompt
        warmup_prompt_len = len(tokenizer.encode(warmup_prompt))
        print(
            f"Warmup with system_prompt only: {warmup_prompt_len} tokens "
            f"(full prompt: {test_request.prompt_len} tokens)"
        )
```
