# [Feature] Add public, non-fatal weight update refusal

[Upstream PR](https://github.com/sgl-project/sglang/pull/43597) · state: open · merged: False

## Original PR description

## Motivation

Fixes #43144.

Models and plugins with relocated weights or derived caches need a public way to refuse online updates. The existing declaration is private, and begin/reset bypass it. Checking runners only when their loaders start can also change the target before discovering that the draft cannot update.

## Modifications

- Accept `weight_update_unsupported_reason` on any model module, falling back to `_derived_weight_cache_error` when the public value is `None`. An empty string still declares refusal.
- Preflight every selected runner before beginning a session or mutating weights. This also extends the existing compensated mHC/HPC refusal to begin/reset. Rejected begin calls create no session and enter no barrier.
- Preserve read-only weight checks and typed failure responses. Inside an already-open distributed update, finish receiving before refusal so an already-broadcasting sender is not stranded.
- Document startup-determined, rank-uniform declarations and requiring successful begin before broadcast.

No cross-rank agreement or rollback after arbitrary loader failures is added.
