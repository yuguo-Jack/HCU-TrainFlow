# [Perf] openai: Skip unused prompt decoding

[Upstream PR](https://github.com/sgl-project/sglang/pull/44110) · state: open · merged: False

## Original PR description

## Motivation

For text-only chat requests on multimodal models, the Jinja path decodes and caches the full prompt even when the engine can use token IDs. Long agent histories miss that cache and repeat the decode work.

## Modifications

Keep prompt IDs for text-only requests and decode only when a caller needs text. Requests with media retain the decoded prompt and cache path, as do Responses, Moss-VL, and special-token fallbacks. Engine input stays the same. This can merge independently from the prompt-segment cache in #42187.

## Accuracy Tests

Focused chat conversion regressions and scoped formatting pass on the updated branch. Earlier checks with the real GLM-5.3-Flash tokenizer matched chat IDs, Responses text and image prompts against the comparison base. GPU serving on this branch remains unverified.

Run the unit suites with `python -m pytest` and formatting with `pre-commit run --files <changed-files>`.

## Speed Tests and Profiling

A local CPU benchmark on the previous PR revision used the real GLM tokenizer with text-only prompts of about 112K to 120K tokens. Median conversion time was 20.7 to 22.3 ms there, compared with 36.5 to 49.2 ms on the comparison base; the decoded-prompt cache retained 4.25 MB per turn on that base and 0 MB on the previous PR revision. Decoding the final prompt alone took 15 to 18 ms.
