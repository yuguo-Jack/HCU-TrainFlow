# [KVCR] Guard mode for the dense direct linker (stacked on #45650)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47514) · state: open · merged: False

## Original PR description

Stacked on #45650 (fork branch, so this targets main and shows its commits). Review only the top commit, 6c86ef35c4.

Guard mode for the dense KVCR direct linker, following vLLM's KVCR manager:
- Guard is used exactly when `kvcr_service_socket_path` is set, and it requires `compatibility_digest`. Without a socket, the linker uses process-local DRAM as before.
- Guard mode fails closed: a socket error raises `KVCRConfigError`, at start and after an engine reset, with no process-local fallback.
- It adds a Guard `router_hint` source. The kv_events publisher applies the Dynamo-format check and the owner topic only to `kvcr_inventory` sources.
- #45650's explicit `publish_inventory` is unchanged.

Follow-ups: hybrid pools #47535; salted event-hash hints #47681; DP hint sources #47682. Companion Dynamo change: ai-dynamo/dynamo#17737.
