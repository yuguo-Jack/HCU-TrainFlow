# [Doc] [NPU] cookbook: add A3 deployment scenarios to MiMo-V2-Flash

[Upstream PR](https://github.com/sgl-project/sglang/pull/45612) · state: open · merged: False

## Original PR description

## Motivation

Closes Ascend/sglang#1214.

The MiMo-V2-Flash cookbook had no Ascend NPU path. This PR adds the Ascend A3 deployment scenario to the cookbook page, mirroring the official Ascend best practice.

## Modifications

- `docs/src/snippets/autoregressive/mimo-v2-flash-deployment.jsx`: add an `A3` hardware option to the configuration selector. It emits the official Ascend best-practice 2-node PD-disaggregated recipe (prefill TP8/DP2, decode TP16 with EAGLE, plus the SGLang router), including the required CANN environment and tuning variables.
- `docs/cookbook/autoregressive/Xiaomi/MiMo-V2-Flash.mdx`: add an Ascend NPU installation note, an "Ascend NPU deployment (A3 Series)" section with PD disaggregation notes, and a verification warning about component version alignment for W8A8 accuracy.

## Performance validation

Measured on two A3 nodes with the exact recipe from the selector (1 prefill TP8/DP2 + 1 decode TP16 with EAGLE + router, W8A8 INT8 weights, SGLang 0.5.22). `sglang.bench_serving`, random dataset, 16k input / 1k output, 128 prompts, max concurrency 32, against the router endpoint:

| Metric | Result |
| --- | --- |
| Mean time per output token | 47.81 ms |
| Median time per output token | 39.70 ms |
| Median time to first token | 7287 ms (16k-token prompts) |
| Output throughput | 572.6 tok/s (peak 929 tok/s) |
