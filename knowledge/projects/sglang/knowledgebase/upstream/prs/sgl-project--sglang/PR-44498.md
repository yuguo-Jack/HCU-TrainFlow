# [Perf] multi-tokenizer: Group MultiTokenizerRouter outputs by tokenizer worker

[Upstream PR](https://github.com/sgl-project/sglang/pull/44498) · state: open · merged: False

## Original PR description

## Motivation

When `--skip-tokenizer-init` is set and `--tokenizer-worker-num` is greater than 1, scheduler outputs go through `MultiTokenizerRouter` instead of the detokenizer. The router currently sends one message per request, so a batch of 256 requests turns into 256 IPC sends. The detokenizer path already groups its sends by worker (#44288).

## Modifications

The router now uses the existing `_send_output_to_tokenizer_workers` helper for `BatchTokenIDOutput` and `BatchStrOutput`. Each tokenizer worker gets one sub-batch. If a batch can't be split, the helper falls back to per-request sends.

All other outputs, such as embeddings and single requests, behave as before.

## Accuracy Tests

N/A. This PR only changes how messages are routed between processes.

## Speed Tests and Profiling

The benchmark below sends real messages over `ipc://` sockets. Each tokenizer worker is its own process and checks that it receives all of its RIDs in order. Requests are assigned to workers round-robin. CPU only.

| batch / workers | messages: main → PR | main (ms/batch) | PR (ms/batch) | speedup |
|---|---|---:|---:|---:|
| 1 / 1 | 1 → 1 | 0.063 | 0.069 | 0.9x |
| 16 / 4 | 16 → 4 | 0.385 | 0.227 | 1.7x |
| 64 / 4 | 64 → 4 | 1.345 | 0.279 | 4.8x |
| 256 / 4 | 256 → 4 | 5.244 | 0.419 | 12.5x |
| 256 / 16 | 256 → 16 | 5.255 | 0.961 | 5.5x |

Absolute times depend on the machine. The message counts do not, and the speedup scales with how many requests share a worker. With one request per batch there is nothing to merge, so main and the PR are within a few µs of each other.

```python
# MultiTokenizerRouter return hop over real ipc:// sockets. Run on main and on this branch.
import asyncio
import multiprocessing as mp
import statistics
import tempfile
import time

import msgspec
import zmq

from sglang.srt.managers import multi_tokenizer_mixin as m
from sglang.srt.managers.io_struct import BatchTokenIDOutput, sock_recv
from sglang.srt.utils.network import get_zmq_socket

ITERS, TRIALS = 200, 5


def make_output(n):
    kw = {
        f.name: None if f.name in m._UNCHECKED_LENGTH_FIELDS else []
        for f in msgspec.structs.fields(BatchTokenIDOutput)
        if f.default is msgspec.NODEFAULT and f.default_factory is msgspec.NODEFAULT
    }
    kw.update(
        rids=[f"rid-{i}" for i in range(n)],
        finished_reasons=[None] * n,
        decoded_texts=["hello"] * n,
        decode_ids=[[1, 2, 3, 4]] * n,
        read_offsets=[0] * n,
        output_ids=[[5]] * n,
        skip_special_tokens=[True] * n,
        spaces_between_special_tokens=[True] * n,
        no_stop_trim=[False] * n,
        prompt_tokens=[128] * n,
        completion_tokens=[16] * n,
        reasoning_tokens=[0] * n,
        cached_tokens=[0] * n,
        retraction_counts=[0] * n,
        placeholder_tokens_idx=None,
        placeholder_tokens_val=None,
    )
    return BatchTokenIDOutput(**kw)


def tokenizer_worker(endpoint, conn, expected_rids):
    sock = get_zmq_socket(zmq.Context(), zmq.PULL, endpoint, bind=True)
    conn.send(0)
    while conn.recv():
        rids, msgs = [], 0
        while (out := sock_recv(sock)).rids:  # an empty batch ends the trial
            rids += out.rids
            msgs += 1
        assert rids == expected_rids * ITERS
        conn.send(msgs // ITERS)


def bench(batch, workers):
    out = make_output(batch)
    with tempfile.TemporaryDirectory() as d:
        endpoints = [f"ipc://{d}/{w}" for w in range(workers)]
        out.http_worker_ipcs = [endpoints[i % workers] for i in range(batch)]
        conns = []
        for w, endpoint in enumerate(endpoints):
            conn, child = mp.Pipe()
            args = (endpoint, child, out.rids[w::workers])
            mp.Process(target=tokenizer_worker, args=args, daemon=True).start()
            conns.append(conn)
        for conn in conns:
            conn.recv()
        router = m.MultiTokenizerRouter.__new__(m.MultiTokenizerRouter)
        router.socket_mapping = m.SocketMapping()
        loop = asyncio.new_event_loop()
        times = []
        for _ in range(TRIALS + 1):  # the first trial is warmup
            for conn in conns:
                conn.send(True)
            start = time.perf_counter()
            for _ in range(ITERS):
                loop.run_until_complete(router._distribute_result_to_workers(out))
            for endpoint in endpoints:
                router.socket_mapping.send_output(endpoint, make_output(0))
            msgs = sum(conn.recv() for conn in conns)
            times.append((time.perf_counter() - start) / ITERS * 1e3)
        for conn in conns:
            conn.send(False)
        return msgs, statistics.median(times[1:])


if __name__ == "__main__":
    for batch, workers in ((1, 1), (16, 4), (64, 4), (256, 4), (256, 16)):
        msgs, ms = bench(batch, workers)
        print(f"batch={batch} workers={workers} messages={msgs} ms/batch={ms:.3f}")
```
