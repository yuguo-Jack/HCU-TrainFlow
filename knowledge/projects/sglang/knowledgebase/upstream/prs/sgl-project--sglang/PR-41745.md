# [Refactor] nvfp4_online: Use explicit FlashInfer 4over6 config

[Upstream PR](https://github.com/sgl-project/sglang/pull/41745) · state: closed · merged: True

## Original PR description

## Motivation

@humansand

Use FlashInfer's explicit 4over6 API for online NVFP4 weight conversion, preserving the recipe pinned by #33621 while moving quantization settings into the online quantizer.

## Modifications

- **Recipe:** pass `NVFP44Over6Config(e4m3_max=448, err_mode="MSE", err_use_fast_math=True)` to `nvfp4_quantize(..., nvfp4_4over6=...)`; remove the four load-time 4over6 environment overrides.
- **Scale contract:** derive the E4M3 maximum from that same config. Preserve the existing per-tensor decode-scale arithmetic, zero-amax handling, and shared w1/w3 scale.
- **Ownership:** keep the exact-FP4-math environment scope in the online quantizer. A small reference-counted context reuses `temp_set_env`: the first caller sets the override, and the last caller restores the original value, including on exceptions. The lock covers only entry/exit bookkeeping; quantizer calls run concurrently.
- **Scope:** the shared helper covers `nvfp4_online` and nonserialized `modelopt_fp4` MoE weights. Keep the new FlashInfer import lazy. The generic loader retains its post-load CUDA synchronization/cache cleanup; activation recipe selection is unchanged. The monokernel weight observer still runs before `model.load_weights`; upstream FlashRL reload guards and ModelOpt layout/padding handling are preserved.

### Dependencies

- **Required API:** [flashinfer-ai/flashinfer#5152](https://github.com/flashinfer-ai/flashinfer/pull/5152), merged as [`7bcf91831e4640cf7b8983e8b7954e94a03746b3`](https://github.com/flashinfer-ai/flashinfer/commit/7bcf91831e4640cf7b8983e8b7954e94a03746b3).
- **Behavior baseline:** [sgl-project/sglang#33621](https://github.com/sgl-project/sglang/pull/33621), which pinned 448 / MSE / fast candidate-error evaluation for online weights.
- **Dependency satisfied:** [sgl-project/sglang#43494](https://github.com/sgl-project/sglang/pull/43494) pins [FlashInfer v0.7.1](https://github.com/flashinfer-ai/flashinfer/releases/tag/v0.7.1), which includes the required API. Use that upstream pin; this PR adds no package-pin changes or legacy fallback. The separate `FLASHINFER_DISABLE_FP4_QUANT_FAST_MATH` flag remains environment-based in 0.7.1.
