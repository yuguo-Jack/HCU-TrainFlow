# Fix UE8M0 scale rounding for DeepGEMM

## Original PR description

## Summary

Cherry-pick of #29956 (originally by @mmangkad).

Fix #29954 by making UE8M0 scale rounding bit-exact with DeepGEMM, as suggested in the issue. Replaces the floating-point `torch.pow(2.0, torch.ceil(torch.log2(x.abs())))` with a bit-exact implementation that extracts the FP32 exponent/mantissa and rounds up.

```diff
 def ceil_to_ue8m0(x: torch.Tensor):
-    return torch.pow(2.0, torch.ceil(torch.log2(x.abs())))
+    bits = x.abs().float().view(torch.int32)
+    exp = (bits >> 23) & 0xFF
+    mantissa = bits & 0x7FFFFF
+    exp = exp + (mantissa != 0).to(torch.int32)
+    exp = exp.clamp(1, 254)
+    return (exp << 23).view(torch.float32)
```
