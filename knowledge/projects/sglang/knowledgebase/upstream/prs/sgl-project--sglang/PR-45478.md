# [Feat] [CPU] model: Support Cosmos3 series models on CPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/45478) · state: closed · merged: True

## Original PR description

## Motivation

In a CPU-only environment, it is not possible to launch Cosmos3 series models; this is primarily because the startup phase requires importing CUDA-specific VSA components, which triggers an error.

Additionally, the `jdopensource/JoyAI-Echo` model also faces the same issue and relies on this solution.

## Modifications

Modify `video_sparse_attn.py`: Skip CUDA-specific VSA imports when running in a CPU environment, while leaving non-CPU branches unchanged.

## Accuracy Tests

When running in a CPU environment, the images and videos generated by Cosmos3 showed no anomalies.
