# [CI] base-b: Move kernel and unit tests that pass on the 5090 to 1-gpu-small

[Upstream PR](https://github.com/sgl-project/sglang/pull/46160) · state: open · merged: False

## Original PR description

## Summary

The H100 pool is the CI bottleneck: in the 2026-10-23 runner utilization report, `1-gpu-h100` ran at 75% utilization with a 117 min average queue (604 min max), while `1-gpu-5090` ran at 33% with a 13 min average queue.

This PR moves 27 light base-b test files (kernels/ops, moe, unit, layers, mem_cache, model_loading, prefill_only) from 1-gpu-large (H100) to 1-gpu-small (RTX 5090). Each change edits the `runner_config` of one `register_cuda_ci` line. Where the H100 estimate was more than 1.5x too low, `est_time` is raised to the measured 5090 duration. `test_nvfp4_marlin` was already registered on 1-gpu-small, so its 1-gpu-large duplicate is dropped.

A file moves only if:
- it passes on the 5090 (SM120, 32 GB) with the CI install and env,
- every test it skips on the 5090 also skips on H100, and
- if it launches a server, any architecture-dependent default it picks up is not what the test checks.

No coverage is lost.

| base-b per-commit est_time | main | this PR |
|---|---|---|
| 1-gpu-large | 124 files / 158.1 min | 96 / 150.8 min |
| 1-gpu-small | 157 files / 191.5 min | 184 / 205.4 min |

Partitions are sized from est_time by `compute_partitions.py`, so no workflow change is needed.

## Credit

This carries forward the file selection and validation from #44880 by @mmangkad (part of the #41231 series), re-applied on current main. That PR is stale, so this one replaces it.

## Validation

In #44880, all 28 files passed on the 1-gpu-5090 runners ([run 39360987525](https://github.com/sgl-project/sglang/actions/runs/39360987525)). Comparing against H100:
- `test_mhc_kernels` stayed on 1-gpu-large because its `test_hopper_*` cases need SM90.
- `test_topk_padded_region` and `test_fp8_utils` skip the same cases on both GPUs.
- `test_flash_mla_backends` skips every case on H100 and runs 14 on the 5090.
- `test_post_capture_kv_sizing` gets FlashInfer instead of FA3, but the sizing path it tests doesn't depend on the attention backend.

Since that run, main has changed one of these files (`test_dcp_lse_combine`: one line removed in #44803). All 28 files were rerun on the 5090 with `/rerun-test -c` on this PR and passed ([run 40024380043](https://github.com/sgl-project/sglang/actions/runs/40024380043)). The unittest skip counts match the #44880 run.
