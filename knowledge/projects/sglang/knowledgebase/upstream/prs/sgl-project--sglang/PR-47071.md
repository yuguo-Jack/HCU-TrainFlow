# [Fix] mem_cache: support prefix commits in unified MHA views

[Upstream PR](https://github.com/sgl-project/sglang/pull/47071) · state: closed · merged: True

## Original PR description

DFLASH overlap decoding with fused unified draft KV crashes during prefix commits because the MHA view rejects this write operation. Reuse the existing stride-aware prefix writer for unified views, including FP8 quantization, and preserve physical slot IDs in the CPU fallback.

Validation: both new regressions reproduce the original exception before the fix. After the fix, both complete test modules pass (20 unified MHA view tests and 8 prefix-store tests) on 1×H200 with PyTorch 2.14.1+cu130 and FlashInfer 0.7.2. Coverage includes BF16/FP8, partial and zero commits, invalid suffix locations, and unchanged neighboring arena bytes. Pre-commit passed. The full 8×B300 MuseSpark E2E was not rerun.
