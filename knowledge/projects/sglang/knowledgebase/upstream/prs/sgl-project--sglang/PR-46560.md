# [Fix] deepseek: fix stale kernel_api_logging import breaking AWQ weight loading on CUDA

[Upstream PR](https://github.com/sgl-project/sglang/pull/46560) · state: open · merged: False

## Original PR description

## Motivation

Loading any AWQ-quantized model on CUDA crashes at weight load with:

```
ModuleNotFoundError: No module named 'sglang.kernel_api_logging'
```

Full traceback (main @ fd5c52588f, 8xGPU, DeepSeek-V3.2-AWQ):

```
  File "python/sglang/srt/models/deepseek_v2.py", line 3436, in load_weights
    self.do_load_weights(weights, is_nextn)
  File "python/sglang/srt/models/deepseek_common/deepseek_weight_loader.py", line 550, in do_load_weights
    self.post_load_weights(is_nextn=is_nextn, weight_names=weight_names)
  File "python/sglang/srt/models/deepseek_common/deepseek_weight_loader.py", line 627, in post_load_weights
    awq_dequantize_f = awq_dequantize_func()
  File "python/sglang/srt/models/deepseek_common/utils.py", line 104, in awq_dequantize_func
    from sglang.kernel_api_logging import debug_kernel_api
ModuleNotFoundError: No module named 'sglang.kernel_api_logging'
```

Root cause: #35062 ([Misc] Clean up python/sglang package structure) moved
`kernel_api_logging.py` into the `sglang.kernels` subpackage, but the CUDA
branch of `awq_dequantize_func` was missed. The HIP and NPU branches of the
same function already import from the correct location, which makes the
inconsistency easy to confirm:

```python
# python/sglang/srt/models/deepseek_common/utils.py (main @ fd5c52588f)
if _is_cuda:
    from sglang.kernel_api_logging import debug_kernel_api          # line 104: stale path
elif _is_hip:
    from sglang.kernels.kernel_api_logging import debug_kernel_api  # correct
elif _is_npu:
    from sglang.kernels.kernel_api_logging import debug_kernel_api  # correct
```

`python/sglang/kernel_api_logging.py` does not exist on main;
`python/sglang/kernels/kernel_api_logging.py` does (`git ls-tree` confirms both).

## Modifications

One line in `python/sglang/srt/models/deepseek_common/utils.py`:

```diff
     if _is_cuda:
-        from sglang.kernel_api_logging import debug_kernel_api
+        from sglang.kernels.kernel_api_logging import debug_kernel_api
         from sglang.kernels.ops.quantization.awq_dequantize import awq_dequantize
```

## Verification

- 8xH20 GPU container (lmsysorg/sglang:nightly-dev-efa-20261026), DeepSeek-V3.2-AWQ:
  - Before: server dies at weight load with the ModuleNotFoundError above (reproduced twice).
  - After this one-line change: weight load completes, server serves requests normally end to end.
