# [Fix] mem_cache: guard lmcache idle check and re-run cache compatibility after model capability adjustments

[Upstream PR](https://github.com/sgl-project/sglang/pull/46002) · state: open · merged: False

## Original PR description

## Motivation

Fixes #45929.

When `--enable-lmcache` is combined with a disabled radix cache (either explicitly via `--disable-radix-cache` or automatically resolved for models that disable prefix caching in `handle_model_capability_adjustments` / `kv_cache_builder.py`), two issues occur:

1. **Resolution ordering gap**: `handle_cache_compatibility` runs at line 331 of `pipeline.py`, before `handle_model_capability_adjustments` (line 349). Models that force `disable_radix_cache=True` in `handle_model_capability_adjustments` bypass the `--enable-lmcache requires radix cache to be enabled` check in `handle_cache_compatibility`.
2. **Scheduler idle check crash**: When `disable_radix_cache=True`, `default_radix_cache_factory` returns a plain `UnifiedRadixCache` instead of `LMCacheUnifiedRadixCache`. At the first idle check, `Scheduler.is_fully_idle()` executes `elif self.enable_lmcache: idle &= not self.tree_cache.has_pending_cache_operations()`, raising `AttributeError: 'UnifiedRadixCache' object has no attribute 'has_pending_cache_operations'`.

## Modifications

- **`python/sglang/srt/arg_groups/pipeline.py`**: Re-run the idempotent `handle_cache_compatibility` hook after `handle_model_capability_adjustments` (alongside `handle_kv_cache_sharding`) so late `disable_radix_cache=True` declarations are validated against `--enable-lmcache` and `--enable-hierarchical-cache`.
- **`python/sglang/srt/managers/scheduler.py`**: Gate the `enable_lmcache` branch in `Scheduler.is_fully_idle()` on `not self.disable_radix_cache`.
- **`python/sglang/srt/mem_cache/base_prefix_cache.py`**: Add a default `has_pending_cache_operations(self) -> bool: return False` method on `BasePrefixCache` so any prefix cache implementation satisfies the interface contract without defensive `hasattr` checks.
- **Unit tests**: Add regression tests in `test/registered/unit/managers/test_scheduler_on_idle_load.py` and `test/registered/unit/server_args/test_server_args.py`.
