# [Test] [MUSA] sgl-kernel: Cover fused GEMV and MoE GEMV

[Upstream PR](https://github.com/sgl-project/sglang/pull/44431) · state: open · merged: False

## Original PR description

## Motivation

The MUSA AOT fused GEMV and fused MoE GEMV operators are exported through `sgl_kernel`, but they do not have direct numerical correctness coverage. This follows the MUSA operator-test work tracked in #16565 and complements #42357, which covers MUSA RoPE and fused mul-add.

## Modifications

- Add direct FP16/BF16 correctness tests for MUSA fused GEMV:
  - plain GEMV;
  - fused SwiGLU;
  - fused RMSNorm.
- Add direct FP16/BF16 correctness tests for MUSA fused MoE GEMV:
  - top-k expert routing;
  - routed-weight multiplication on/off;
  - SwiGLU on/off;
  - mixed valid/invalid expert IDs and zero-fill behavior.
- Compare against independent FP32 PyTorch references and verify read-only inputs remain unchanged.
- Extend the MUSA sgl-kernel path filter to cover the wrapper, dispatcher, build setup, MUSA sources, and this test.
- Run the new test explicitly in `sgl-kernel-unit-test-musa`.

FP8 and INT4 coverage are intentionally left for follow-up work because they require architecture-specific scale and packing cases.
