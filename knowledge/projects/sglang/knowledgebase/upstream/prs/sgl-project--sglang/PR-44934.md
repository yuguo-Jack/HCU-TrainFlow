# [Fix] [AMD] deepseek-v4.1: Reject attention DP with encoder SWA bounded replay on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/44934) · state: closed · merged: True

## Original PR description

- `--enable-encoder-swa-bounded-replay` with attention DP now fails at startup on ROCm. The ROCm attention backend replays prefix hits in a forward of their own instead of folding them into the extend, and only the attention-DP ranks that hit would enter that forward: with an MLP-sync gather of one count per rank it raises in `_set_execution_counts` on the first prefix hit, and with a gather of one count it would run the collectives on the hitting ranks alone.
- The check was dropped when #43813 enabled attention DP for the CUDA backend, which folds the replay.
- Adds a CPU unit test for the check.
- No behavior change on CUDA.
