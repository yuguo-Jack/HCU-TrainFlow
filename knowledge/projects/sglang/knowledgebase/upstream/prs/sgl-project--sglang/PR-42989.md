# [rust-server] preserve PD routing in chat and completions

[Upstream PR](https://github.com/sgl-project/sglang/pull/42989) · state: closed · merged: True

## Original PR description

Preserve:
- `bootstrap_host`
- `bootstrap_port`
- `bootstrap_room`
- `routed_dp_rank`
- `disagg_prefill_dp_rank`

from http requests to `/v1/chat/completions` and `/v1/completions`.

The Dynamo request types discarded these extensions, leaving the generated requests without PD routing metadata.

Use generated API carriers in the OpenAI wrappers and share bootstrap normalization with `/generate`. Each prompt's `n` choices retain its pairing room, so two prompts with room `41` and `n=2` produce `[41, 41, 42, 42]`. Host allocation limits include choice fan-out.
HTTP header overrides are outside this PR.

Fixes #39412.
