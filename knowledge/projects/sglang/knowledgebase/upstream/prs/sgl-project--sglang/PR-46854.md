# [Fix] [NPU] tests: Serve sgl_eval MMLU data from a prefetched archive

[Upstream PR](https://github.com/sgl-project/sglang/pull/46854) · state: open · merged: False

## Original PR description

## Motivation

The NPU MMLU accuracy cases cannot fetch their dataset on the CI runners. `sgl_eval` downloads the `cais/mmlu` archive with its own `httpx` client: it ignores `HF_ENDPOINT`, prints nothing while downloading and never retries, so a blocked or slow mirror is indistinguishable from a hang. The community runners can only reach Hugging Face through the mirror (direct `huggingface.co` returned `503` for several days in October), so the archive has to be staged before the test starts.

## Modifications

- `_npu-pr-test-stage.yml`: prefetch `data.tar` with `hf download cais/mmlu --include data.tar --local-dir` (goes through `HF_ENDPOINT`, has progress and retries), falling back to `curl` against the mirror, then export `SGLANG_EVAL_ARCHIVE_DIR`. `HF_HUB_DISABLE_XET=1` is set so the prefetch uses the classic HTTP path instead of the Xet CAS server that the mirror does not proxy. A failed prefetch only emits a warning, so the job degrades to the previous behaviour.
- `npu_eval_accuracy_kit.py`: add `honor_local_sgl_eval_archive()`. It matches a prefetched archive by URL basename, re-checks the digest with sgl_eval's own `_loader._file_sha256` (a stale or truncated copy falls back to the original download instead of grading other data), and runs the vendored `prepare.save_data()` with `URL` pointed at that local file. The prefetched archive lives outside the prepare work directory, so `urlretrieve()` cannot truncate the source it is reading. The shim is applied on import, so every NPU accuracy case benefits without per-test changes, and it declines to install when the installed sgl_eval does not expose either helper.
- `test_mmlu.py`: call the shim explicitly, so `TestMMLU` does not depend on some other case importing the kit first.

## Accuracy Tests

- `test_npu_sampling_backend.test_mmlu` (Qwen2.5-7B-Instruct, 64 questions, threshold 0.65), run through `nightly-1-npu-a3` on an A3 2-card runner:
  - the prefetched archive is picked up from `SGLANG_EVAL_ARCHIVE_DIR` (`/tmp/sgl_eval_archives/data.tar`, 159 MB);
  - `[METRIC] mmlu_score=0.796875`, `stop_rate=1.0`, `invalid=0.0`, `latency=32.3s`;
  - no `httpx` download and no `503` in the log, i.e. the dataset load is fully local.
