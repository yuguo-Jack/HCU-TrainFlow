# [Refactor] [NPU] diffusion: Reuse shared MXFP8 linear execution

[Upstream PR](https://github.com/sgl-project/sglang/pull/44365) · state: open · merged: False

## Original PR description

## Motivation

Diffusion ModelSlim MXFP8 duplicates the Ascend MXFP8 Linear post-load and forward path. Delegate to the shared implementation while preserving the offline checkpoint and per-call bias contracts.

## Modifications

- Allocate `ceil(K/32)` raw UE8M0 scale blocks and pad an odd block count before shared post-load processing, without requantizing checkpoint weights.
- Delegate post-load and forward to `NPUMXFP8LinearMethod` instead of duplicating activation quantization and matmul.
- Preserve updated per-call bias and noncontiguous input handling; add regressions for prepared layouts, partial scales, and shared execution.

## Accuracy Tests

- 3 tests passed in an isolated CPU harness loading the production adapter and shared method with NPU calls mocked. They cover layout/scale preparation, delegation, and updated bias, not NPU numerical equivalence.
- Ruff, isort, codespell, syntax, and diff checks passed. Full serving-package collection was not completed locally because dependencies are incomplete.
- Wan2.2 I2V-A14B offline ModelSlim MXFP8 generated a video successfully in earlier Ascend 950 testing of `TallMessiWu/sglang@6eb8e1dd1c`; the tester confirmed the video looked normal. This new main-based PR head has not been rerun on NPU. No numerical comparison or independent warmup benchmark was performed.
