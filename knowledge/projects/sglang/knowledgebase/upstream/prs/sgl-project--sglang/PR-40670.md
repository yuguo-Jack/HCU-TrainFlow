# [HiSparse] Support DSpark and MTP speculative decoding

[Upstream PR](https://github.com/sgl-project/sglang/pull/40670) · state: open · merged: False

## Original PR description

Add HiSparse KV swap and finalize support for DeepSeek V4 DSpark and DSA MTP, including memory sizing and Mooncake PD transfer.

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

Enable HiSparse KV offloading for multi-step speculative decoding with DeepSeek V4 DSpark and DSA-based EAGLE MTP.

## Modifications

  - Add multi-step HiSparse swap, metadata preparation, and accepted-token finalization kernels.
  - Integrate HiSparse speculative verification with DeepSeek V4 and DSA attention backends.
  - Support logical KV allocation and host-slot reservation during speculative decoding.
  - Account for speculative HiSparse state and draft KV buffers during memory pool sizing.
  - Add Mooncake PD transfer support for HiSparse target and draft KV caches.
  - Handle request completion, aborts, idle batches, and CUDA graph eligibility.
