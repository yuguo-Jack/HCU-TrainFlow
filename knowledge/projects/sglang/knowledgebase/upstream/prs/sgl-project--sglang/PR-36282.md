## Motivation

Fix an intermittent CI hang in the NPU e2e test framework and add first-class support for repeat/stress testing a single registered test case.

## Modifications

- `python/sglang/test/ascend/e2e/test_npu_performance_utils.py`: add a stdout idle watchdog and self-isolate each test into its own process group so a stuck or self-killed server no longer leaves a reparented forkserver holding the CI stdout pipe and hanging the job.
- `python/sglang/test/ascend/e2e/test_npu_accuracy_utils.py`: add an extra regex pattern to parse evalscope accuracy output.
- `.github/workflows/_npu-single-node-test-stage.yml`: add `loop_count` and `test_case` inputs to run a single test file directly, optionally looped N times.
- `.github/workflows/nightly-test-npu.yml`: add dedicated `nightly-perf-16-npu-a3-kimi-stress` and `nightly-perf-16-npu-a3-qwen3-235b` jobs and comment out the remaining nightly jobs for focused testing.
