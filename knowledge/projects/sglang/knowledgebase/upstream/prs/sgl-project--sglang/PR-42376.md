# test(checkpoint_engine): add CPU unit tests for checkpoint splitting and worker extension

[Upstream PR](https://github.com/sgl-project/sglang/pull/42376) · state: closed · merged: False

## Original PR description

## Motivation

checkpoint-engine 集成（RL 训练侧权重热更新，#41800 落地）目前完全没有
测试——整个 `test/` 树没有任何文件引用它。本 PR 为所有不需要 torchrun
集群和运行中服务器的部分补充 CPU 可运行覆盖。

## Modifications

- `test_update_split.py`：
  - `split_checkpoint_files` 的 ceil 分片：多余 rank 得空切片、只筛选
    .safetensors、全 rank 并集完整且互不重叠
  - `split_tensors`：用 `safetensors.torch.save_file` 向临时目录写入
    真实分片文件并手写 index.json，验证按 rank 的权重切分与张量值
    逐元素一致（真实 I/O 测试）
  - `check_sglang_ready` / `req_inference`：非组头 / 非源 rank 的
    提前返回门控；源 rank 发出的 IPC 请求体契约（`zmq_handles` 切片、
    `flush_cache`、`weight_version`）
  - `run_with_torchrun`：`--inference-parallel-size` 的空格与等号两种
    形式解析、默认值 8、torchrun 命令拼装、torchrun 不存在时的退出码 1
- `test_worker_extension.py`：
  - import 守卫：在干净子进程解释器中验证缺包时的报错信息
  - 基类访问器的 `NotImplementedError`；未知设备 UUID 的 `ValueError`
  - 向 `checkpoint_engine.worker.update_weights_from_ipc` 的正确分发
  - GPU / NPU 双路径的 UUID 握手键约定（`GPU-<uuid>` / `NPU-<uuid>`，
    与 impl 文档字符串中说明的 ParameterServer 键保持一致）
  - post-load 钩子：量化模块的 `process_weights_after_loading` 调用、
    `post_load_weights` 存在时调用、异常吞掉仅记 warning

worker 测试向 `sys.modules` 注入假的 `checkpoint_engine` 包，因为真实
包是可选依赖（`pip install sglang[checkpoint-engine]`），CI 环境中没有；
该假包仅对本测试模块生效。

## Accuracy Tests

- 共 26 个 CPU 测试用例，注册进 `base-a-test-cpu` 套件。
