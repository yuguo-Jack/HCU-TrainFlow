# [PDMux] Support bounded layerwise prefill for DeepSeek-V4.1-Flash

[Upstream PR](https://github.com/sgl-project/sglang/pull/42507) · state: closed · merged: False

## Original PR description

## Motivation

DeepSeek-V4.1-Flash needs a resumable forward to interleave long prefills with decode. Intermediate slices retain batch-owned mHC, Engram and tail state; only the final slice computes logits.

## Changes

- Reuse the ordinary mHC loop and retain combined/normalized carry across layer intervals. Prepare multimodal inputs once.
- Match the [pdmux-standard layer_split reference](https://github.com/Li-brua/sglang/tree/17761860ccbc6cea53b0c3625fa0c89880b48f9e): select streams from the local running decode batch, gather decode metadata after stream selection, budget layers from the maximum DP token count and use no additional layer-count cap.
- Switch only the full-TP communicator in the prefill scope and retain the sampler's request-replica group. Support capped-prefill/full-device-decode overlap.
- Preserve chunk stash/filter/abort ordering, release persistent activations at completion and install HiCache consumer fences on every slice.
- Enforce compressor-plan admission limits; protect shared-expert input aliasing, helper streams and shared workspaces for the DeepSeek model path.

Attention DP and speculative decoding remain gated until their dependent adapters. Shared runtime work overlaps [GLM core PDMux #42411](https://github.com/sgl-project/sglang/pull/42411).
