# [CI] diffusion: Run test_image_preprocessing in the diffusion unit suite

[Upstream PR](https://github.com/sgl-project/sglang/pull/46888) · state: open · merged: False

## Original PR description

## Motivation

`test/registered/unit/multimodal_gen/test_image_preprocessing.py` (added in #45733) imports `diffusers`, but it is registered to `base-b` / `1-gpu-small`, whose install (`python[dev,runai,tracing]`) does not include the `diffusion` extra. It passes only when the 5090 runner's venv still has `diffusers` from an earlier diffusion job, and fails otherwise:

```
from diffusers.image_processor import VaeImageProcessor
ModuleNotFoundError: No module named 'diffusers'
```

This failed `base-b-test-1-gpu-small (6)` in the scheduled run [40494205576](https://github.com/sgl-project/sglang/actions/runs/40494205576/job/122155674628); the same file passed in the previous scheduled run on a runner that happened to have `diffusers` installed.

## Modifications

Register the test to `diffusion-unit-1-gpu-h100`. That suite runs in the `multimodal-gen-unit-test` job, which installs with `ci_install_dependency.sh diffusion`. `test/registered/kernels/ops/diffusion/test_flux2_xpu_norm_fusions.py` is registered the same way.

The test keeps running on a GPU (H100 instead of 5090).
