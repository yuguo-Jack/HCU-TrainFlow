# [Doc] cookbook: add Ascend NPU deployment for Qwen3

[Upstream PR](https://github.com/sgl-project/sglang/pull/47386) · state: open · merged: False

## Original PR description

## Motivation

The Qwen3 cookbook covers NVIDIA/AMD/Intel GPUs and Intel CPUs, but has no Ascend NPU path, so users on Atlas 800I A3 have no cookbook-level recipe to copy. The Ascend NPU docs describe the platform but not the per-model launch commands.

## Changes

Add a new section **3.3 Deploying on Ascend NPUs (Atlas 800I A3)** to `docs/cookbook/autoregressive/Qwen/Qwen3.mdx`:

- prerequisite pointers to the Ascend NPU installation and quickstart pages
- a scenario table with validated launch commands for Qwen3-8B, Qwen3-32B, Qwen3-30B-A3B and Qwen3-235B-A22B
- the A3 `--tp-size` convention (one card exposes two dies → `--tp-size` = 2 × cards), `--attention-backend ascend --device npu`
- W8A8 / `--quantization modelslim` notes
- a short self-check (`/generate`) and benchmark pointer

Also update:
- section 3.1 to list Ascend NPUs and point at the new scenario table instead of the GPU/CPU command generator
- section 3.2 configuration tips with the Ascend-specific knobs
