# [Refactor] multimodal: Replace padding strategies with helpers

[Upstream PR](https://github.com/sgl-project/sglang/pull/44845) · state: closed · merged: True

## Original PR description

## Motivation

Multimodal token padding doesn't need a strategy object. Keep the model's `pad_input_ids` interface, but call the shared helpers directly.

## Modifications

- Add `pad_mm_tokens` and `pad_mm_token_pairs`, and migrate the model callers.
- Keep the old classes, constructor signatures and attributes as thin wrappers. No deprecation warnings.
- Cover token boundaries, slice reuse, input ownership, `data_offsets` and legacy configuration in the existing CPU tests.

The algorithm extraction is isolated in `36db17e4623`. [Reproduction scripts](https://gist.github.com/mickqian/f6bda44e57abf4690861685d0f2dd43b).
