# [Feat] nemotron_parse: Support Nemotron 3.5 Parse

[Upstream PR](https://github.com/sgl-project/sglang/pull/47500) · state: open · merged: False

## Original PR description

## Motivation

Support [nvidia/Nemotron-3.5-Parse](https://huggingface.co/nvidia/Nemotron-3.5-Parse) for document-image parsing. 

## Modifications

- Reuse existing RADIO vision encoder and add the model's content-normalized image positions and projection layers.
- Add causal visual-prefix mBART decoder, grouped-query attention and tied output weights.
- Reuse the checkpoint’s image processor and preserve image attachments in chat requests.

Support for the MTP head for Nemotron-3.5-Parse will be added in a follow-up PR.

## Accuracy Tests

Tested the [nvidia/Nemotron-3.5-Parse](https://huggingface.co/nvidia/Nemotron-3.5-Parse) checkpoint on B200, H100 and A100.

| GPU | Tested configuration | Result |
| --- | --- | --- |
| B200 | Default FA4 attention and graphs | Four strict reference pages and concurrent/repeated checks pass; 180/180 repeated-request content checks pass. |
| H100 | FA3 attention and default decode graphs; overlap enabled and disabled | Basic parsing checks pass, but mixed-length concurrent requests can omit a line. |
| A100 | Default FlashInfer decoder, with `--mm-attention-backend sdpa` | Matches the reference on the four document fixtures and concurrent/repeated checks; 180/180 repeated-request content checks pass. |

Fixtures cover a paragraph, a two-column page, a table and a chart. Chat image requests and four concurrent pages with different text and dimensions also pass on all three GPUs. Published Transformers reference checks from the model card pass on H100 and A100.

Tested TP1 on A100, H100 and B200, and TP2 on two H100 NVL GPUs, with chat, batched requests and concurrent images. Both A100 and H100 load and serve with default settings, but some two-column outputs differ in formatting or reading order, or omit a line. The omission can also be reproduced by slightly changing the value of one coordinate token in the Transformers reference (from model card), suggesting that small numerical differences during decoding might contribute. On A100, passing `--mm-attention-backend sdpa` avoided the omission on the tested pages. No reliable H100 workaround has been confirmed. Pipeline parallelism is not implemented in this PR.

## Speed Tests and Profiling

TP1 with default attention and graph settings. Prefix, image-embedding and preprocessing caches were disabled. Every request used a different 850×1050 rendered document image, covering paragraphs, two-column text, tables and charts.

Each of three repetitions used eight separate warmup documents at the measured concurrency, then 20 requests at concurrency 1 and 40 at concurrency 4. Decoding used normal EOS stopping, a 1,024-token output cap and repetition penalty 1.1. Timings include image preprocessing, vision encoding, prefill and decoding.

| GPU | Concurrency 1, pages/s | Concurrency 4, pages/s |
| --- | ---: | ---: |
| A100 80GB PCIe | 3.55–3.61 | 6.17–6.23 |
| H100 PCIe | 6.77–7.05 | 17.20–17.31 |
| B200 | 7.47–7.93 | 18.66–18.77 |

All 180 timed requests on each GPU contained the expected text, had valid boxes and ended on EOS. A100 used default Triton vision attention, without `--mm-attention-backend sdpa`. Caching was intentionally disabled for speed tests to avoid unrealistic speedups from re-processed documents.

cat > benchmark_parse.py <<'EOF'
import argparse
import base64
import json
import re
import sys
import time
from concurrent.futures import ThreadPoolExecutor
from pathlib import Path
from statistics import mean

import requests
from bs4 import BeautifulSoup


parser = argparse.ArgumentParser()
parser.add_argument("--url", default="http://127.0.0.1:30001")
parser.add_argument("--out", required=True)
parser.add_argument("--fixtures", type=Path, default=Path("parse-documents"))
parser.add_argument("--model-dir", required=True)
args = parser.parse_args()
sys.path.insert(0, args.model_dir)
from postprocessing import postprocess_document

root = args.fixtures
records = json.loads((root / "manifest.json").read_text())
assert len({item["pixel_sha256"] for item in records}) == len(records)
for item in records:
    item["image"] = (
        "data:image/png;base64,"
        + base64.b64encode((root / item["path"]).read_bytes()).decode()
    )
prompt = "</s><s><predict_bbox><predict_classes><output_markdown><predict_text_in_pic>"
models = requests.get(args.url + "/v1/models", timeout=30)
models.raise_for_status()
Path(args.out + ".models.json").write_text(json.dumps(models.json(), indent=2))


def parse_page(item):
    start = time.perf_counter()
    response = requests.post(
        args.url + "/generate",
        json={
            "text": prompt,
            "image_data": item["image"],
            "sampling_params": {
                "temperature": 0,
                "max_new_tokens": 1024,
                "repetition_penalty": 1.1,
                "skip_special_tokens": False,
            },
        },
        timeout=120,
    )
    elapsed = time.perf_counter() - start
    response.raise_for_status()
    return {
        "index": item["index"],
        "kind": item["kind"],
        "seconds": elapsed,
        "response": response.json(),
    }


def check_page(result):
    item = records[result["index"]]
    data = result["response"]
    doc = postprocess_document(prompt + data["text"], image_size=(850, 1050))
    text = BeautifulSoup(doc["markdown"], "html.parser").get_text(" ")
    text = " ".join(text.replace("**", "").split())
    missing = [
        phrase
        for phrase in item["expected_text"]
        if not re.search(r"(?<!\w)" + re.escape(phrase) + r"(?!\w)", text)
    ]
    checks = {
        "expected_text": not missing,
        "normal_eos": data["meta_info"]["finish_reason"]["type"] == "stop",
        "valid_boxes": bool(doc["blocks"])
        and all(
            len(block["bbox"]) == 4
            and 0 <= block["bbox"][0] <= block["bbox"][2] <= 1
            and 0 <= block["bbox"][1] <= block["bbox"][3] <= 1
            for block in doc["blocks"]
        ),
        "no_warnings": not doc["warnings"],
        "no_cached_prefix": data["meta_info"].get("cached_tokens", 0) == 0,
    }
    result.update(
        checks=checks, missing_text=missing, passed=all(checks.values()), document=doc
    )


runs = []
cursor = 0
for repetition in range(3):
    for concurrency, count in ((1, 20), (4, 40)):
        with ThreadPoolExecutor(max_workers=concurrency) as pool:
            warmups = list(pool.map(parse_page, records[cursor : cursor + 8]))
        cursor += 8
        selected = records[cursor : cursor + count]
        assert len(selected) == count
        cursor += count
        flush = requests.post(args.url + "/flush_cache", timeout=30)
        flush.raise_for_status()
        start = time.perf_counter()
        with ThreadPoolExecutor(max_workers=concurrency) as pool:
            outputs = list(pool.map(parse_page, selected))
        elapsed = time.perf_counter() - start
        for result in warmups + outputs:
            check_page(result)
        summary = {
            "repetition": repetition,
            "concurrency": concurrency,
            "requests": count,
            "seconds": elapsed,
            "pages_per_second": count / elapsed,
            "output_tokens_per_second": sum(
                result["response"]["meta_info"]["completion_tokens"]
                for result in outputs
            )
            / elapsed,
            "mean_latency_ms": 1000 * mean(result["seconds"] for result in outputs),
            "quality_passed": sum(result["passed"] for result in outputs),
            "cached_tokens": sum(
                result["response"]["meta_info"].get("cached_tokens", 0)
                for result in outputs
            ),
            "all_normal_eos": all(result["checks"]["normal_eos"] for result in outputs),
        }
        runs.append({**summary, "results": outputs, "warmups": warmups})
        Path(args.out).write_text(json.dumps(runs, indent=2))
        print(summary, flush=True)
assert cursor == len(records)
if any(run["quality_passed"] != run["requests"] for run in runs):
    raise RuntimeError(
        "Document checks failed; timings and all failed responses are preserved"
    )
EOF

**Issue**

The packed path relies on `cu_seqlens` to keep pages apart. When `SGLANG_VIT_ENABLE_CUDA_GRAPH=1`, `InternVisionEncoder.forward` ignores `cu_seqlens` and calls `InternViTCudaGraphRunner.run`. The runner builds `cu_seqlens = [0, S]` for the whole `[1, S, H]` input.
