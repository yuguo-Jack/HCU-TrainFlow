# [Fix] [NPU] diffusion: :bug: Auto-select FA for MXFP8 attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/45550) · state: open · merged: False

## Original PR description

## Summary

Continuation of #32041 by @hxhhhlalala, limited to its remaining automatic FA backend selection. The MXFP8 attention implementation landed in #39438; this follows the [maintainer's suggestion](https://github.com/sgl-project/sglang/pull/32041#issuecomment-6008020716) to submit backend selection separately. The original author is credited as a co-author.

With `SGLANG_DIFFUSION_ENABLE_MXFP8_ATTENTION=1` and a supported quantization config on Ascend, attention layers can currently default to SDPA unless FA is selected explicitly. Pass the layer's quantization config to the selector and reuse `resolve_mx_fa_scheme` to select FA automatically when no backend or layer default has been specified.

- Covers `LocalAttention`, `UlyssesAttention`, and `USPAttention`.
- Preserves explicit layer, global, CLI, component, and attention-role selections, as well as supported-backend constraints.
- Keeps automatic cross-attention selection unchanged. Device, operator, and dtype eligibility remain governed by the existing MXFP8 resolver.

Updated on 2026-10-22 with an ordinary merge of main `3d508d614f`; head `ceace1a8d3`. The feature remains a three-file backend-selection change. It has no unmerged source prerequisite and does not include the separate Linear refactor #44365. The original PR's kernel implementation, environment variable names, and historical performance results are not carried forward.

## Validation

- All 10 CPU unittest methods passed again on the updated head, covering online/offline config routing, opt-in and capability fallback, backend precedence, constraints, and all three layer constructors.
- The isolation harness uses the actual selector/resolver and layer constructor bodies, with package startup isolated and NPU capabilities mocked. Against current unmodified main `3d508d614f`, the constructor regression fails for all three self-attention layers because they select SDPA.
- Applicable Ruff hook rules, formatting, isort, codespell, syntax, test-placement/registration checks, and the PR diff check passed.
- Full runtime test collection remains unavailable locally: package startup fails on missing `orjson` before reaching the tests.

**Target validation is pending for this head:** run the existing Wan2.2 I2V ModelSlim MXFP8 checkpoint on Ascend 950 with the opt-in enabled and no explicit attention-backend override. Require both successful generation and the existing runtime message `Using MXFP8 quantized Ascend Flash Attention.`; successful generation alone could be a capability fallback. The disabled opt-in and explicit-backend precedence are covered by CPU tests, not new NPU runs. No NPU accuracy or performance result is claimed.
