# [Feat] linker: Add prefetch mode for the Mooncake external linker

[Upstream PR](https://github.com/sgl-project/sglang/pull/45600) · state: open · merged: False

## Original PR description



## Motivation

Layer-wise KV restoration can discover a cache-read failure after a request has entered its forward, causing the request to abort.

This PR adds an optional full-layer prefetch mode that detects restoration failures before admission, allowing the request to fall back to recomputation.

## Modifications

- Add `--linker-load-mode {layer_wise,prefetch}`, defaulting to `layer_wise`.
- Start prefetch from `_prefetch_kvcache()` and reuse Mooncake’s existing `load_thread` to read all layers into request-private GPU slots.
- Add a single asynchronous `prefetch()` interface. Publish completed KV to the radix tree only after all attention ranks confirm completion and success.
- On failure, wait for outstanding writes to stop, release private slots, and fall back to recomputation. Cancellation and reset also wait before recycling slots.
- Skip pending requests during admission so later ready requests can proceed.
- Preserve the default layer-wise scheduling, completion counters, and MLA broadcast path.

## Usage

```bash
--enable-unified-cache-external-linker \
--linker-load-mode prefetch
```
