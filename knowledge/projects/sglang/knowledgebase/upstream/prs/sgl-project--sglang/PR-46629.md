# [Test] rust-server: Drop two unit tests that mirror one-line delegations

[Upstream PR](https://github.com/sgl-project/sglang/pull/46629) · state: closed · merged: True

## Original PR description

## Motivation

Two Rust-frontend unit tests restate a single delegation with mocks and would only go red if the test itself were edited. That is the shape `.claude/rules/unit-test-admission.md` asks us to delete: a mirror test adds maintenance cost and breaks on refactors without catching bugs.

## Modifications

- `test/registered/unit/managers/test_scheduler_flush_cache.py`: remove `test_control_output_goes_to_the_embedded_rust_server`. It mocks both sinks and checks the `if self.rust_server is not None` branch of `Scheduler.send_control_output`. The `FlushCacheReqOutput` and `Scheduler` imports go with it; nothing else used them.
- `test/registered/unit/multimodal/rust/shared/test_rust_server_extension.py`: remove `test_startup_time_takes_the_engine_shape`. It mocks `time` and `psutil` and checks that `RustServer.set_startup_time` hands its input to `build_engine_startup_time`. The engine entrypoint builds the Python frontend's `startup_time` with the same helper, and `test_srt_endpoint.py::test_get_server_info` checks that shape end to end there.

No non-test code changes. Both files were run locally after the deletion: 11 passed.
