# [Refactor] RoPE: Support RotaryEmbedding class usage for DiT models

[Upstream PR](https://github.com/sgl-project/sglang/pull/44753) · state: open · merged: False

## Original PR description

## Motivation

Each DiT implements its own RoPE: the same flashinfer / AITER / eager cascade is written out four times across `wanvideo.py` and `lingbot_world.py`, and Z-Image has eleven RoPE call sites. `RotaryEmbedding` already exists to unify this. This PR moves Wan-Video, LingBot-World, Causal-Wan/LongLive2, Z-Image/Ming, ERNIE-Image and MiniMax-H3 onto the class and builds each model's frequency table once in its top-level `forward`, which gives them the class's fp32 complex and `npu_rotary_mul` paths off CUDA. CUDA keeps the kernel each model already had: flashinfer, triton (causal Wan), ERNIE's fused kernel with its bit-exact oracle, `sgl_kernel` (MiniMax-H3).

## Modifications

- `runtime/models/dits/wanvideo.py`: hand-written flashinfer branch replaced by the class; `complex_freqs` built once per forward.
- `runtime/models/dits/lingbot_world.py`: same as Wan; duplicated `cat([cos, sin])` cache builds removed.
- `runtime/models/dits/causal_wanvideo.py`: class with `use_flashinfer=False`, so CUDA stays on triton; `complex_freqs` hoisted.
 `_apply_rotary_emb`: the class's `forward_cuda` would move it to flashinfer and rebuild the cos/sin cache in every block. `complex_freqs` is built once in `CausalWanTransformer3DModel.forward` from the request-cached `freqs_cis` and threaded through the block as a keyword-only argument.
- `runtime/models/dits/longlive2.py`: forwards `complex_freqs` through the overridden block, matching the parent signature.
- `runtime/models/dits/zimage.py`: eleven RoPE call sites collapsed into two branches; tables built on every platform.
- `runtime/models/dits/ming_image.py`: builds its three tables via `_build_rope_cache`; otherwise Ming loses RoPE.
- `runtime/models/dits/ernie_image.py`: off CUDA/ROCm, QK-norm plus NeoX class on full-width cos/sin; CUDA untouched.
- `runtime/models/dits/minimax_h3.py`, `minimax_h3_vdn_attention.py`: off-CUDA branch uses a partial-rotation NeoX class, reaching `npu_rotary_mul`.
- `runtime/layers/rotary_embedding/base.py`: `use_flashinfer` flag; ROCm/MUSA use `forward_native`; full-width tables bypass flashinfer.
- `runtime/layers/rotary_embedding/utils.py`: NeoX `_apply_rotary_emb` accepts full-width tables whose halves differ (ERNIE).
- `runtime/layers/layernorm.py`, `runtime/layers/elementwise.py`: NPU fix for per-frame `[B, F, 1, C]` and batched modulation.
- `test/unit/test_zimage_rope_cache.py`: test host copies `_build_rope_cache` and unpacks the new 3-tuple.


### ROCm, MUSA and XPU

`RotaryEmbedding` now runs `forward_native` on ROCm and MUSA, as it already did on XPU. Before, these platforms fell back to `forward_cuda`, where flashinfer is not imported, so every call ended in the bf16 eager fallback of `apply_flashinfer_rope_qk_inplace`. `forward_native` uses the Triton kernel for interleaved cos/sin, fp32 rotate-half for NeoX, and an fp32 complex multiply for `complex_freqs`. Only a call that passes nothing but `cos_sin_cache` still goes to the eager fallback.

- **Unchanged:** Wan, LingBot-World and causal Wan / LongLive2 (the class hands cos/sin to the same `_apply_rotary_emb`); Z-Image with batched tables; ERNIE-Image and MiniMax-H3 on ROCm (their kernels are selected by `q.is_cuda`).
- **Z-Image, Ming (2D tables):** qk-norm as in main; RoPE is an fp32 complex multiply instead of the Triton `_apply_rotary_emb`.
- **ERNIE-Image, MiniMax-H3 on MUSA and XPU:** fp32 rotate-half through the class instead of bf16 eager code.
- **Already-merged users of the class** (flux, flux_2, qwen_image, glm_image, cosmos3video, joy_image, mova) and the instance inside `apply_qk_norm_rope`: on ROCm and MUSA they now take the paths above instead of the bf16 eager fallback.

## Accuracy Tests

On NPU, all migrated models generate the same output as main or a visually close one. Where outputs differ, the cause is one of two changes in how RoPE is computed. The bf16 eager path is replaced either by an fp32 complex multiply (interleaved models such as Wan) or by `torch_npu.npu_rotary_mul` (NeoX models such as MiniMax-H3). Both changes make RoPE more accurate without degrading generation quality, and the RoPE op itself becomes up to ~2x faster (profiled). The precision results below, together with the visual check, show that the NPU GT for Wan (`wan2_1_t2v_1.3b_1_npu`, `wan2_2_t2v_14b_w8a8_2npu`) and MiniMax-H3 (`minimax_h3_t2va_2npu`) can be safely regenerated.


#### RoPE precision on NPU (Wan2.2-A14B shapes: 720x1280, 24 frames, 40 heads x 128)

| RoPE on NPU | rel. L2 error vs fp64 | mean error, bf16 ulp | correctly rounded |
|---|---|---|---|
| fp64 rounded to bf16 (best possible) | 1.54e-03 | 0.23 | 100.0% |
| main: `_apply_rotary_emb`, bf16 | 2.28e-03 | 0.96 | 76.1% |
| this PR: `RotaryEmbedding`, fp32 complex | 1.54e-03 | 0.23 | 100.0% |

On main, the NPU fallback casts the cos/sin table to bf16 and does the rotation in bf16. The class rotates in fp32 and rounds once, so its output matches correctly rounded fp64.

<details><summary>Script</summary>

```python
"""RoPE precision on NPU at Wan2.2-A14B shapes (720x1280, 24 frames): main vs this PR, against fp64."""

import torch
import torch_npu  # noqa: F401

from sglang.multimodal_gen.runtime.layers.rotary_embedding import (
    RotaryEmbedding,
    _apply_rotary_emb,
)

T, H, W, HEADS, D = 6, 45, 80, 40, 128  # 6x45x80 latent tokens, 40 heads of 128


def angles(dtype, device):
    # Wan splits head_dim into [44, 42, 42] for (t, h, w), theta 10000.
    parts = []
    for dim, n, view in ((44, T, (T, 1, 1)), (42, H, (1, H, 1)), (42, W, (1, 1, W))):
        inv = 1.0 / 10000 ** (torch.arange(0, dim, 2, dtype=dtype, device=device) / dim)
        ang = torch.outer(torch.arange(n, dtype=dtype, device=device), inv)
        parts.append(ang.view(*view, -1).expand(T, H, W, -1))
    return torch.cat(parts, -1).reshape(T * H * W, -1)  # [S, D/2]


torch.manual_seed(0)
x = torch.randn(1, T * H * W, HEADS, D).bfloat16()

a = angles(torch.float64, "cpu")[:, None]
x1, x2 = x.double()[..., 0::2], x.double()[..., 1::2]
ref = torch.stack((x1 * a.cos() - x2 * a.sin(), x2 * a.cos() + x1 * a.sin()), -1).flatten(-2)

# fp32 table, as sglang builds it on NPU (no fp64 there).
a = angles(torch.float32, "npu")
cos, sin = a.cos(), a.sin()
xn = x.npu()
main = _apply_rotary_emb(xn, cos, sin, is_neox_style=False)  # Wan's NPU call on main
rope = RotaryEmbedding(head_size=D, rotary_dim=D, use_precomputed_cache=False)
pr, _ = rope(query=xn, key=xn, complex_freqs=torch.complex(cos, sin).unsqueeze(-2))

nonzero = ref != 0
bf16_ulp = torch.exp2(torch.floor(torch.log2(ref.abs())) - 7)
best = ref.bfloat16().double()


def row(name, out):
    out = out.cpu().double()
    err = (out - ref).abs()
    rel_l2 = (err.norm() / ref.norm()).item()
    mean_ulp = (err[nonzero] / bf16_ulp[nonzero]).mean().item()
    exact = (out == best).double().mean().item()
    print(f"| {name} | {rel_l2:.2e} | {mean_ulp:.2f} | {exact:.1%} |")


print("| RoPE on NPU | rel. L2 error vs fp64 | mean error, bf16 ulp | correctly rounded |")
print("|---|---|---|---|")
row("fp64 rounded to bf16 (best possible)", ref.bfloat16())
row("main: `_apply_rotary_emb`, bf16", main)
row("this PR: `RotaryEmbedding`, fp32 complex", pr)
```

#### RoPE precision on NPU (MiniMax-H3 shapes: 1344x768, 5 s, TP2, 28 heads x 128, rotary_dim 96)

| RoPE on NPU, same bf16 table | rel. L2 error vs fp64 | mean error, bf16 ulp | correctly rounded | dims 96:128 unchanged |
|---|---|---|---|---|
| exact result rounded to bf16 (lower bound) | 1.38e-03 | 0.18 | 100.0% | yes |
| main: `_apply_rope_cos_sin`, bf16 eager | 1.79e-03 | 0.43 | 85.1% | yes |
| this PR: `RotaryEmbedding` -> `npu_rotary_mul` | 1.38e-03 | 0.18 | 100.0% | yes |

MiniMax-H3 builds its cos/sin table in bf16 on every platform, and both paths read that table, so the reference is exact math on the same table and the rows compare only the arithmetic. `npu_rotary_mul` returns the correctly rounded result on every element. On main, the eager path rounds both products and the sum to bf16.

```python
"""RoPE precision on NPU at MiniMax-H3 shapes (1344x768, 5 s, TP2): main vs this PR, against fp64.

The model builds its cos/sin table in bf16 on every platform and both paths read
it, so the reference is exact math on that same table: the rows compare only the
arithmetic this PR changes.
"""

import torch
import torch_npu  # noqa: F401

from sglang.multimodal_gen.runtime.layers.rotary_embedding import RotaryEmbedding
from sglang.multimodal_gen.runtime.models.dits.minimax_h3 import (
    MiniMaxH3Rope,
    _apply_rope_cos_sin,
    _rope_cos_sin_cache,
)

T, H, W, HEADS, D, N_FREQ = 31, 24, 42, 28, 128, 16  # latent grid; 56 heads over TP2
ROT = 6 * N_FREQ  # 96 of 128 head dims

# The checkpoint supplies inv_freq; the docstring formula with base 10000 stands in.
rope = MiniMaxH3Rope(N_FREQ)
rope.inv_freq.copy_(
    10000.0 ** -(torch.arange(0, 2 * N_FREQ, 2, dtype=torch.float32) / (2 * N_FREQ))
)
grid = torch.stack(
    torch.meshgrid(torch.arange(T), torch.arange(H), torch.arange(W), indexing="ij"), -1
).reshape(1, -1, 3)
cache = _rope_cos_sin_cache(rope.npu()(grid.npu()), dtype=torch.bfloat16)  # [S, 48 cos | 48 sin]
cos_half, sin_half = cache.split(ROT // 2, dim=-1)

torch.manual_seed(0)
x = torch.randn(T * H * W, HEADS, D).bfloat16()
xn = x.npu()

c = torch.cat((cos_half, cos_half), -1).cpu().double()[:, None]
s = torch.cat((sin_half, sin_half), -1).cpu().double()[:, None]
xd = x.double()
x1, x2 = xd[..., :ROT].chunk(2, dim=-1)
ref = torch.cat((xd[..., :ROT] * c + torch.cat((-x2, x1), -1) * s, xd[..., ROT:]), -1)

# main: the eager branch of _apply_rope_qk, everything in bf16.
main = _apply_rope_cos_sin(
    xn,
    torch.cat((cos_half, cos_half), dim=-1).unsqueeze(1),
    torch.cat((sin_half, sin_half), dim=-1).unsqueeze(1),
)
# this PR: _apply_rope_qk hands the half-width table to the class.
rotary_emb = RotaryEmbedding(
    head_size=D, rotary_dim=ROT, is_neox_style=True, use_precomputed_cache=False
)
pr, _ = rotary_emb(query=xn.unsqueeze(0), key=xn.unsqueeze(0), cos=cos_half, sin=sin_half)
pr = pr.squeeze(0)

nonzero = ref != 0
bf16_ulp = torch.exp2(torch.floor(torch.log2(ref.abs())) - 7)
best = ref.bfloat16().double()


def row(name, out):
    out = out.cpu().double()
    err = (out - ref).abs()
    rel_l2 = (err.norm() / ref.norm()).item()
    mean_ulp = (err[nonzero] / bf16_ulp[nonzero]).mean().item()
    exact = (out == best).double().mean().item()
    tail = "yes" if torch.equal(out[..., ROT:], ref[..., ROT:]) else "no"
    print(f"| {name} | {rel_l2:.2e} | {mean_ulp:.2f} | {exact:.1%} | {tail} |")


print(
    "| RoPE on NPU, same bf16 table | rel. L2 error vs fp64 | mean error, bf16 ulp "
    "| correctly rounded | dims 96:128 unchanged |"
)
print("|---|---|---|---|---|")
row("exact result rounded to bf16 (lower bound)", ref.bfloat16())
row("main: `_apply_rope_cos_sin`, bf16 eager", main)
row("this PR: `RotaryEmbedding` -> `npu_rotary_mul`", pr)
```

<summary><b>Measurement script</b> </summary>

Reuses the helpers in `multimodal_gen/test/server/realtime_consistency.py`.
`run` writes an mp4, a lossless frame dump and `chunk_stats`; `compare` prints

```python
"""Headless LingBot-World realtime client: scripted camera, mp4 + frames + chunk_stats.

Run:
  python lingbot_rt_client.py run --tag main --image ref.jpg
  python lingbot_rt_client.py compare lingbot_out/main_frames.npz lingbot_out/branch_frames.npz
"""

import argparse
import asyncio
import json
from pathlib import Path

import numpy as np

from sglang.multimodal_gen.test.server.realtime_consistency import (
    collect_realtime_output,
    encode_realtime_frames_to_mp4,
    prepare_realtime_first_frame,
    summarize_realtime_perf_stats,
)


def parse_actions(spec: str) -> list[list[str]]:
    # "w:24,d:12,:12" -> 24 frames of ["w"], 12 of ["d"], 12 of [] (idle).
    actions: list[list[str]] = []
    for part in filter(None, spec.split(",")):
        keys, count = part.split(":")
        actions += [list(keys)] * int(count)
    return actions


def run(args) -> None:
    init = {
        "type": "init",
        "prompt": args.prompt,
        "first_frame": prepare_realtime_first_frame(args.image),
        "size": args.size,
        "fps": args.fps,
        "num_frames": args.num_frames,
        "seed": args.seed,
        "num_inference_steps": args.steps,
        "guidance_scale": 1.0,
        "max_chunks": args.num_chunks,
        # No realtime_output_format -> lossless delta-gzip RGB, needed for frame diff.
        "condition_inputs": {"camera_actions": parse_actions(args.actions)},
    }
    result = asyncio.run(
        collect_realtime_output(
            ws_url=args.url,
            init_payload=init,
            events=[],
            num_chunks=args.num_chunks,
            require_chunk_stats=True,
        )
    )

    out = Path(args.out_dir)
    out.mkdir(parents=True, exist_ok=True)
    (out / f"{args.tag}.mp4").write_bytes(
        encode_realtime_frames_to_mp4(result.frames, fps=args.fps)
    )
    np.savez_compressed(out / f"{args.tag}_frames.npz", frames=np.stack(result.frames))
    summary = summarize_realtime_perf_stats(
        result.chunk_stats, ignore_initial_chunks=args.ignore_initial_chunks
    )
    per_chunk = [
        {
            "chunk": s.chunk_index,
            "forward_ms": s.scheduler_forward_ms,
            "total_ms": s.chunk_total_ms,
        }
        for s in result.chunk_stats
    ]
    (out / f"{args.tag}_stats.json").write_text(
        json.dumps({"summary": summary, "per_chunk": per_chunk}, indent=2)
    )
    print(f"[{args.tag}] frames={len(result.frames)}")
    for key in (
        "avg_scheduler_forward_ms",
        "p95_scheduler_forward_ms",
        "avg_chunk_total_ms",
    ):
        print(f"  {key:28s} {summary[key]:9.1f}")
    fps_gen = (
        summary["total_frames"]
        / sum(s.chunk_total_ms for s in result.chunk_stats)
        * 1e3
    )
    print(f"  {'generated_fps (all chunks)':28s} {fps_gen:9.2f}")


def compare(args) -> None:
    a = np.load(args.a)["frames"].astype(np.float32)
    b = np.load(args.b)["frames"].astype(np.float32)
    n = min(len(a), len(b))
    if len(a) != len(b):
        print(f"frame count differs: {len(a)} vs {len(b)}, comparing first {n}")
    diff = a[:n] - b[:n]
    mse = (diff**2).reshape(n, -1).mean(axis=1)
    psnr = 10 * np.log10(255.0**2 / np.maximum(mse, 1e-10))
    print(
        f"max_abs_diff={np.abs(diff).max():.0f}  "
        f"mean_abs_diff={np.abs(diff).mean():.3f}"
    )
    print(f"PSNR dB: min={psnr.min():.2f}  mean={psnr.mean():.2f}  (100 = identical)")
    print("PSNR per frame:", " ".join(f"{p:.1f}" for p in psnr))


def main() -> None:
    parser = argparse.ArgumentParser()
    sub = parser.add_subparsers(dest="cmd", required=True)

    r = sub.add_parser("run")
    r.add_argument("--tag", required=True)
    r.add_argument("--url", default="ws://127.0.0.1:30000/v1/realtime_video/generate")
    r.add_argument("--image", required=True, help="first frame: local path or URL")
    r.add_argument(
        "--prompt",
        default="A slow aerial orbit around a pastel floating island hotel in the open "
        "ocean, hazy sunlight, turquoise water, clean horizon, cinematic but playful.",
    )
    r.add_argument("--size", default="832x480")
    r.add_argument("--fps", type=int, default=16)
    r.add_argument("--num-frames", type=int, default=9, help="frames per chunk")
    r.add_argument("--num-chunks", type=int, default=12)
    r.add_argument("--steps", type=int, default=4)
    r.add_argument("--seed", type=int, default=42)
    r.add_argument("--actions", default="w:48,d:24,:36", help="per-frame camera script")
    r.add_argument("--ignore-initial-chunks", type=int, default=2)
    r.add_argument("--out-dir", default="lingbot_out")
    r.set_defaults(func=run)

    c = sub.add_parser("compare")
    c.add_argument("a")
    c.add_argument("b")
    c.set_defaults(func=compare)

    args = parser.parse_args()
    args.func(args)


if __name__ == "__main__":
    main()
```
