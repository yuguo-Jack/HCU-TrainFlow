## Motivation

<!-- Describe the purpose and goals of this pull request. -->
Add xpu api for `indexed_scale_shift_bf16_` and `indexed_gate_bf16_` to use sycl kernels for better performance of Minimax-H3.
## Modifications

* Added import and usage of the `is_xpu` function from `sglang.kernels.ops.diffusion.common.platform` to detect if the code is running on XPU hardware. (`indexed_modulation_triton.py`)
* Conditionally imported XPU-specific kernel functions (`indexed_scale_shift_bf16_xpu`, `indexed_gate_bf16_xpu`) from `sgl_kernel` when running on XPU. (`indexed_modulation_triton.py`)
