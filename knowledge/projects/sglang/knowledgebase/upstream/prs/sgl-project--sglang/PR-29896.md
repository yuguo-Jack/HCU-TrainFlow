# [Fix] model_config: Derive scaling in the KimiVL, MiniCPM3, and DeepseekVL2 MLA branches

[Upstream PR](https://github.com/sgl-project/sglang/pull/29896) · state: open · merged: False

## Original PR description

## Motivation

Serving Kimi-VL, MiniCPM3 or MLA DeepSeek-VL2 with `--attention-backend flashinfer` fails while the backend is built:

```
AttributeError: 'ModelConfig' object has no attribute 'scaling'
```

The `KimiVLForConditionalGeneration`, `MiniCPM3ForCausalLM` and `DeepseekVL2ForCausalLM` (`use_mla=True`) branches of `ModelConfig._derive_model_shapes` select `AttentionArch.MLA` but never set `scaling`, and `flashinfer_mla_backend.py:856,1000` reads `model_runner.model_config.scaling` unconditionally. This is still the case on main `4eb606b2a`.

Fixes #29891 (closed by the stale bot; the bug is still on main).

## Modifications

1. KimiVL and DeepseekVL2 set `scaling` through the shared `_init_mla_scaling`, so a YaRN `rope_scaling` on their text config applies the mscale correction, as for DeepSeek.
2. MiniCPM3 sets `scaling = 1 / sqrt(qk_nope_head_dim + qk_rope_head_dim)` and copies `qk_nope_head_dim`. Its checkpoints ship a `longrope` `rope_scaling` with no `factor` (for example `openbmb/MiniCPM3-4B`), and `models/minicpm3.py` uses `qk_head_dim**-0.5` without mscale, so the YaRN path would be wrong for it and would log "rope_scaling missing 'factor'". This follows the BailingMoeV3 branch.
3. `test_model_config_shapes.py` covers the three branches, a YaRN KimiVL config and a MiniCPM3 longrope config, and checks that none of them logs a warning.

No backend, server or dependency change.

## Accuracy Tests

N/A for model outputs: these configurations failed at backend construction before, and nothing else changes.

On `3814e0235` (main `4eb606b2a`), `python3 test/registered/unit/configs/test_model_config_shapes.py`: Ran 9 tests, OK. The same test file on main errors with `AttributeError: 'ModelConfig' object has no attribute 'scaling'`. With the previous MiniCPM3 line (`_init_mla_scaling`), the longrope case fails on the missing-factor warning. With the real `openbmb/MiniCPM3-4B` config.json, the branch gives `scaling` 0.10206, equal to `96**-0.5`, with no warning.

An earlier version of this PR served Kimi-VL-A3B-Instruct on the FlashInfer MLA backend on an RTX PRO 6000 (SM120); that run was not repeated on this head.
