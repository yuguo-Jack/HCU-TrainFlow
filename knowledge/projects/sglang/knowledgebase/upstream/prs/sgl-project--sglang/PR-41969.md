# [Feat] [AMD] diffusion: Add Gluon FlashAttention backend for gfx1250

[Upstream PR](https://github.com/sgl-project/sglang/pull/41969) · state: open · merged: False

## Original PR description

## Motivation

**What**
Wan2.2 video generation on a 96-CU gfx1250 DPX partition takes 835.12 seconds with the new Gluon attention backend, compared with 933.66 seconds using AITER for the same warmed request.

**Why**
The opt-in `--attention-backend gluon_fa` backend provides architecture-specific dense attention for SGLang Diffusion. For long BF16 self-attention on 96-CU partitions, the existing global guards and stable online softmax add scans and repeated maximum updates and accumulator rescaling. Reusing the per-workgroup guarded fixed-shift schedule avoids that work for safe groups and retains stable recomputation for unsafe groups.

## Modifications

- Add the opt-in Gluon FlashAttention backend for gfx1250 with dense, noncausal BF16/FP16 MHA, head dimensions 64/128/256, and AITER fallback for unsupported workloads while preserving custom scale.
- Organize kernels by algorithm version and architecture; provide pipeline, ping-pong, and persistent schedules with runtime-length compilation reuse.
- Reuse local guarded attention for automatic BF16/D128 square attention at sequence lengths of at least 65,536 when the device reports 96 CUs. Preserve the existing FP16 selection, other CU counts, rectangular attention, custom scales, and explicit launch configurations.
- Keep numerical guard thresholds and stable retry arithmetic unchanged in the DPX update. No partition configuration or GPU clock changes are required.
- Add metadata selection boundaries and BF16 graph replay regressions for late maxima, isolated retries, zero values, denominator overflow, large uniform logits, and recovery to random input. Cover uneven lengths, storage offsets, and packed value strides.
- Update the attention-backend documentation with the 96-CU BF16 selection and DPX regression command.

## Accuracy Tests

The cleaned DPX update passes **475 tests and 78 subtests** across the gfx1250 kernel, execution-policy, DPX graph replay, and Gluon adapter suites in 68.99 seconds. All applicable pre-commit hooks pass. The new graph tests use an independent stable FP64 oracle with sampled query rows and every key; they retain the BF16 relative RMS bound of 0.003 and existing elementwise tolerances.

| Captured Wan input | BF16 relative RMS error versus FP64 | Bound |
| --- | ---: | ---: |
| High-noise self-attention | 0.002036 | 0.003 |
| Low-noise self-attention | 0.002056 | 0.003 |

All five full-model runs produced 193 frames at 1280×720. These validate generation completion and operator numerics; no perceptual video-quality score or multi-GPU result is claimed.

## Benchmarking and Profiling

Measured on one gfx1250 DPX/NPS2 partition with 96 CUs and 144 GiB, using `rocm/sgl-dev:v0.5.22-rocm10-mi45x-20261020`. The partition and its sibling were idle before measurement, and continuous host KFD monitoring observed no competing client during the reported runs.

Wan2.2-T2V-A14B-Diffusers: 1280×720, 193 frames, 8 inference steps, seed 42, BF16 attention, FP32 VAE decode, one GPU, native SGLang execution, request warmup, compilation disabled, and all offloads disabled. Generation and denoising times exclude startup and warmup.

| Backend | Runs | Generation (s) | Denoising (s) |
| --- | ---: | ---: | ---: |
| AITER at base `6c9f5e6d` | 1 | 933.66 | 915.28 |
| Gluon before DPX update, `afdc5a81` | 2 | 912.55 | 894.30 |
| Gluon with DPX update, `970677a5` | 2 | 835.12 | 816.83 |

The Gluon rows are medians from alternating before→after and after→before pairs. Generation latency decreases **8.48% versus the frozen Gluon head** and **10.55% versus the fresh AITER reference**. The two paired generation reductions are 8.44% and 8.53%; AITER has only one full-generation measurement.

Operator medians from 12 alternating paired rounds, including guards and retry dispatch:

| BF16 attention input | Frozen Gluon (ms) | DPX update (ms) | Latency reduction |
| --- | ---: | ---: | ---: |
| Captured Wan high-noise, original strides restored | 814.93 | 695.78 | 14.62% |
| Captured Wan low-noise, original strides restored | 813.51 | 694.21 | 14.67% |
| Synthetic 176,400-token self-attention | 842.99 | 747.20 | 11.36% |
| Cross-attention control, Sq=176,400 / Sk=512 | 3.5331 | 3.5366 | −0.10% |

For the first captured Wan input, the candidate required zero stable retries across 27,600 workgroups. A diagnostic single-call trace reduced GPU launches from six to two; global guard scans accounted for about 14 ms in the frozen trace. The active frozen stable kernel and candidate both had zero spills, so the measured gain is not attributed to spill removal.

Dispatch is based on CU count and shape, not a queried DPX mode. Other CU counts have policy coverage but were not timed on hardware. Retry frequency can change the gain for other inputs or models. Captured tensor values and strides were restored; allocation offsets were covered independently by numerical regression tests.

Run from the selected source checkout inside the image with the model mounted at `$MODEL`. Use `6c9f5e6d` for the AITER base, `afdc5a81` for frozen Gluon, or `970677a5` (also included in the current PR head) for the DPX update. The generation command is identical between AITER and Gluon except for `ATTENTION_BACKEND=aiter` versus `ATTENTION_BACKEND=gluon_fa`:

```bash
export PYTHONPATH="$PWD/python${PYTHONPATH:+:$PYTHONPATH}"
export SGLANG_DIFFUSION_PLATFORM_OVERRIDE=rocm
export TORCHINDUCTOR_MAX_AUTOTUNE=0 TORCHINDUCTOR_MAX_AUTOTUNE_POINTWISE=0
export ENABLE_CK=1 SGLANG_DIFFUSION_VAE_CHANNELS_LAST_3D=1
export HIP_VISIBLE_DEVICES=5 SGLANG_USE_ROCM_AITER_TGEMM=1
export PYTORCH_NO_HIP_MEMORY_CACHING=1 HIP_FORCE_DEV_KERNARG=0
export SGLANG_USE_ROCM_VAE_CONV2D_BF16=1 SGLANG_USE_ROCM_FLYDSL=0
export SGLANG_DIFFUSION_AITER_FP8_ATTN=0 FLASHINFER_DISABLE_VERSION_CHECK=1
export PROMPT="A cat and a dog baking a cake together in a kitchen. The cat is carefully measuring flour, while the dog is stirring the batter with a wooden spoon. The kitchen is cozy, with sunlight streaming through the window."
export MODEL=/models/Wan2.2-T2V-A14B-Diffusers/
export ATTENTION_BACKEND=gluon_fa
sglang generate --model-path "$MODEL" --log-level info --prompt "$PROMPT" \
  --negative-prompt " " --height 720 --width 1280 --num-inference-steps 8 \
  --num-frames 193 --seed 42 --save-output --num-gpus 1 \
  --vae-decode-precision fp32 --dit-layerwise-offload false \
  --dit-cpu-offload false --vae-cpu-offload false --text-encoder-cpu-offload false \
  --enable-torch-compile false --backend sglang --warmup-mode request \
  --attention-backend "$ATTENTION_BACKEND"
```
