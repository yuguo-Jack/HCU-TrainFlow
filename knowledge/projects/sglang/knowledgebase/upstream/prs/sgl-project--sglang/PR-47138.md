# [Fix] anthropic: attach inline system messages in place to preserve prefix cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/47138) · state: open · merged: False

## Original PR description

## Motivation

On system-first chat templates (Qwen, Llama, Mistral), inline `system` messages in the Anthropic `/v1/messages` conversation are merged into the leading system block by `_convert_to_chat_completion_request`. This rewrites the start of the rendered prompt every turn, invalidating the radix prefix cache and forcing a full re-prefill on every request.

The issue reporter measured: prefix cache hit rate **32% -> 96%**, mean TTFT **8.3s -> 0.5s** on a 94K-context agent session after applying this fix.

### Root cause

The conversion loop (lines 411-417 on main) hoists every inline `system` message into `openai_system_content`, which feeds the single leading `system` turn. As the conversation grows, new system instructions mutate the prefix shared by all prior turns, breaking cache matching.

## Modifications

Remove the hoisting loop. Instead, attach each inline system message to the **preceding** user or tool message, wrapped in `<system>...</system>` tags (via a new `_attach_inline_system` helper). If there is no preceding user/tool message (inline system is the first message), it becomes a standalone `user` message.

The top-level `system` field still populates the leading system block, so templates that require a system-first layout remain satisfied. Earlier turns are now immutable across requests, restoring prefix cache stability.

This follows the approach outlined in the issue by @xjdr-alt.

### Files changed

- `serving.py`: removed the inline-system hoisting loop; added `_attach_inline_system()` helper; updated the message conversion loop to call it for inline system messages.
- `test_serving.py`: updated 3 existing tests to assert the new attach-in-place behavior; added 4 new tests covering prefix cache stability, tool-result attachment, leading inline system, and constructed `AnthropicMessage` objects.
