# [Test] mem_cache: Free SWA peers below the eviction floor in the SWA repair test

[Upstream PR](https://github.com/sgl-project/sglang/pull/44777) · state: closed · merged: True

## Original PR description

- `test_write_back_swa_repair_backup_leaves_the_unbacked_parent_to_eviction` inserted a freshly allocated value with an SWA eviction floor of 4 but kept the SWA peers of its first 4 slots. Duplicates below the floor are freed full-only (#37481), since a request has already released their SWA while its window slid, so those peers leaked and the `swa.peer_released` invariant fired whenever invariant checks were on.
- The test now releases those SWA peers before the insert, as a request whose window slid past them would.

Test-only change; no behavior change. The regular base-a CPU suite runs with async assert off, so the failure showed only under `/rerun-test`, for example on #42716.
