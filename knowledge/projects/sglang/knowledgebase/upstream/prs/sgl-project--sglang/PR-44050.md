## Original PR description

# [Feat] speculative: Add native UBTree decoding for Ling3

## Motivation

This PR provides native SGLang inference support for the released UBTree draft checkpoints:

- [inclusionAI/Ling-3.0-tiny-UBTree](https://huggingface.co/inclusionAI/Ling-3.0-tiny-UBTree), paired with [Ling-3.0-tiny](https://huggingface.co/inclusionAI/Ling-3.0-tiny).
- [inclusionAI/Ling-3.0-flash-UBTree](https://huggingface.co/inclusionAI/Ling-3.0-flash-UBTree), paired with [Ling-3.0-flash](https://huggingface.co/inclusionAI/Ling-3.0-flash).

UBTree combines a parallel DFlash proposer with a learned bigram selector to build a proposal tree. The target verifies the tree in one forward pass and commits the accepted continuation. The draft checkpoints are used alongside their matching target models and share the target's token embeddings and LM head.

For KDA linear attention, saving a complete recurrent state for every proposal node adds memory traffic and temporary storage. This PR uses a shared pre-tree state and per-node factors, then folds only the accepted path into persistent state. It also includes checkpoint loading, tree construction, and fixed-width CUDA Graph execution in SGLang.

## Modifications

- Native UBTree serving for Ling3 Tiny and Flash: built-in algorithm registration, draft-checkpoint loading, selector caches, tensor-parallel vocabulary top-k, and proposal-tree construction.
- Factorized Triton KDA tree verification using a shared pre-tree recurrent state and root-to-node factors.
- Fused causal convolution and tree transformation to prepare factor-generation inputs with fewer intermediate launches and tensor transfers.
- Accepted-path KDA/convolution-state and target/draft-KV commit through a shared verification epilogue for eager execution and CUDA Graph replay.
- Fixed-width BS=1 full decode CUDA Graph execution covering draft proposals, target verification, and accepted-path commit.
- FA3 tree-verification metadata with a `QLEN_ONLY` visibility mask.
- NVIDIA L20X Triton 3.7.1 MoE forward and down-projection tuning configurations for Ling expert shapes.
- Component, selector, tree-topology, kernel, backend, and CUDA Graph replay regression tests.

## Supported Scope

| Item | Supported configuration |
|---|---|
| Target models | Ling-3.0-tiny and Ling-3.0-flash (`BailingMoeV3ForCausalLM`) |
| Released draft checkpoints | [Ling-3.0-tiny-UBTree](https://huggingface.co/inclusionAI/Ling-3.0-tiny-UBTree) and [Ling-3.0-flash-UBTree](https://huggingface.co/inclusionAI/Ling-3.0-flash-UBTree), both B16 |
| Ling3 Tiny verification | 49 nodes; TP1 startup validated |
| Ling3 Flash verification | 32 nodes; TP4 startup validated |
| Ling3 Flash draft blocks | 8 and 16 exercised during development; the linked release is B16 |
| Scheduling | One active request, greedy decoding, DP=1, PP=1 |
| Linear attention backend | Triton KDA |
| Full attention backend | FA3 for both target and draft, page size 1 |
| CUDA Graph | Fixed-width full decode, BS=1; prefill graphs and graph padding disabled |

**B16 is the draft block size, not the verification-tree width.** Select the runtime verification width with `--speculative-num-draft-tokens`; the current native path supports 32 or 49 nodes within the checkpoint's tree budget.

## Integration Boundary

This PR includes the SGLang runtime support needed to serve the two linked UBTree releases:

- draft-checkpoint loading and selector-cache materialization;
- proposal-node selection and tree construction;
- factorized KDA verification and recurrent-state management;
- accepted-path state and KV commit;
- FA3 tree metadata and CUDA Graph capture/replay.

Model training, checkpoint export, and model weights remain outside SGLang. The native serving path does not require an external Ling-Spec UBTree runtime plugin.

UBTree dispatch uses the built-in algorithm and explicit tree metadata. Backend regression tests cover the existing snapshot path alongside the new tree path.

Launch with `--speculative-algorithm UBTREE` and the matching `--speculative-draft-model-path`. The [Tiny model card](https://huggingface.co/inclusionAI/Ling-3.0-tiny-UBTree#serving-with-sglang) and [Flash model card](https://huggingface.co/inclusionAI/Ling-3.0-flash-UBTree#serving-with-sglang) provide full launch commands using the PR's [`asahi/ubtree` branch](https://github.com/AsaHIXx/sglang/tree/asahi/ubtree).
