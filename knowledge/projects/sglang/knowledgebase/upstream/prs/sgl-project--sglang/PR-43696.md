# [diffusion] comfyui: add SGLDCacheOptions for per-run Cache-DiT

[Upstream PR](https://github.com/sgl-project/sglang/pull/43696) · state: open · merged: False

## Original PR description

Adds an `SGLDCacheOptions` node that turns Cache-DiT on or off for a single run from the graph. It sets the options on a cloned MODEL, so toggling it never restarts the worker. The executor reads them from `transformer_options` and maps them to the per-request `enable_cache_dit` and `cache_dit_params`. The loader option stays as the fallback, and a per-run on/off wins over it.

Only MiniMax-H3 supports it. Other models send one independent step per request, so there is no step history to reuse, and the node rejects them with an error. TeaCache is not exposed because its state resets on timestep 0.

This is meant to line up with slimming `SGLDOptions` down to load-time options. If #43504 lands first I will rebase onto its `model_options` path.

Tested on CPU only (`test_comfyui_adapters.py`, `test_comfyui_generator.py`, 44 passed). GPU unit run is in the comments.
