# fix: forward PD routing fields in Anthropic Messages requests

[Upstream PR](https://github.com/sgl-project/sglang/pull/33076) · state: closed · merged: False

## Original PR description

## Motivation

External routers can attach SGLang PD routing metadata to OpenAI-compatible requests, but the Anthropic `/v1/messages` path currently drops that metadata when converting `AnthropicMessagesRequest` to `ChatCompletionRequest`. This prevents Anthropic-compatible requests from carrying fields such as `bootstrap_room` into the existing PD disaggregation flow.

## Modifications

- Add the five existing PD routing fields to `AnthropicMessagesRequest`.
- Forward them unchanged when constructing `ChatCompletionRequest`.
- Add a regression test covering all five fields.

This is limited to the Anthropic request conversion boundary. It does not modify OpenAI endpoints, response formats, or PD core logic.

Local checks:
- `scripts/ci/check_registered_tests.py`
- Python bytecode compilation for all changed files
- Field declaration/forwarding structural checks
- `git diff --check`

The focused runtime unit test is included and will run in CI; the local macOS checkout does not have the full SGLang runtime dependency set installed.
