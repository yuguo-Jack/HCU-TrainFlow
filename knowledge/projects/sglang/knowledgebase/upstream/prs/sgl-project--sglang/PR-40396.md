# [Spec][CUDA Graph] Capture compact verify token keys

[Upstream PR](https://github.com/sgl-project/sglang/pull/40396) · state: closed · merged: False

## Original PR description

## Motivation

Compact ragged verify replays CUDA graphs by packed token count, while decode graph capture still iterated request-batch keys and multiplied each key by the uniform request width. An aligned token grid could therefore advertise a runtime key that capture never materialized.

The capture and replay key sets need to be closed under the same token-tier selection rule.

## Modifications

- Build compact token tiers from the unfiltered request capture grid, rounded to the required TP/CP token alignment.
- Iterate compact capture in token-key space and derive request slots and token rows separately.
- Use the same geometry for graph capture, torch-compile decoration, and per-shape profiling.
- Require exact backend-key membership before graph admission.
- Preserve existing request-key behavior for static decode/verify graphs.
- Add closure/property coverage and direct capture-geometry regressions.

## Accuracy Tests

- Unit coverage for aligned token-tier construction and maximum-tier bounds.
- Exhaustive key-closure and slot-capacity properties over legal request/token geometries.
- Capture geometry, exact backend admission, missing-layout rejection, and unchanged static-key semantics.
