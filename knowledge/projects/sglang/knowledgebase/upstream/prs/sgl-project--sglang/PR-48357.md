# [Fix] kimi-k3: Resolve strict tool $refs into the root parameters schema

[Upstream PR](https://github.com/sgl-project/sglang/pull/48357) · state: closed · merged: True

## Original PR description

## Motivation

A Kimi-K3 request with a strict tool fails with HTTP 400 when the tool's `parameters` use a `$ref` that points into the root structure instead of into `$defs`:

```json
{
  "type": "object",
  "required": ["value"],
  "properties": {
    "value": {
      "type": "object",
      "properties": {
        "a": {"type": "string"},
        "b": {"$ref": "#/properties/value/properties/a"}
      }
    }
  }
}
```

```
Failed to compile structural_tag grammar: ... json_schema_converter.cc: Cannot find field value in #/properties/value/properties/a
```

The Kimi-K3 tool-call format emits each argument separately, so the structural tag compiles each argument value as its own JSON schema. A ref such as `#/properties/value/...` is then resolved against the argument schema, which no longer has that path. Refs into `$defs` / `definitions` are unaffected, because every argument schema already carries the root's definition pools.

## Modifications

All changes are in `function_call/kimik3_structural_tag.py`:

- `_is_root_structure_ref` tells a local ref into the root structure apart from a ref into `$defs` / `definitions`.
- `_localize_root_refs` copies every root-structure ref target into the argument schema's `$defs` under a fresh `root_ref_<n>` name and rewrites the ref to point there.
  - Root-structure refs inside a copied target are copied the same way, so ref chains and recursive schemas resolve.
  - Each ref is copied once.
  - Refs that do not resolve are left in place for the compiler to report.
- `_argument_value_variants` applies it to each type-restricted argument schema before compiling it. A schema without root-structure refs is returned unchanged.

## Tests

`test_kimik3_structural_tag.py` gains two tests:

- `test_strict_schema_resolves_refs_into_the_root_structure` covers three kinds of ref:
  - a ref to a sibling property,
  - a ref to an array's `items`,
  - a chain that mixes `$defs` and root-structure refs.
- `test_strict_schema_resolves_recursive_root_structure_refs` covers an `items` ref back to the argument itself.

Each test checks that a valid value is accepted and a wrongly typed one is rejected. Both tests fail on main and pass here with the pinned xgrammar 0.2.7. The rest of `test/registered/unit/function_call/` gives the same results before and after the change.
