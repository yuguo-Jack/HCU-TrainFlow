## Motivation

Attention consumers currently depend on concrete pool inheritance and duplicate decisions about layer routing, write IDs and speculative windows. Give consumers typed views and one route to each layer's storage.

## Changes

- Implement independent MHA, MLA and state views, including fused draft views.
- Route per-layer reads and writes through shared KV layer interfaces and consolidate iteration ID ownership.
- Centralize speculative window reads and preserve tree masks across FlashInfer planning and execution.
- Update HiCache layout checks and owner/window write routing for the new views.
- Migrate newly added EAGLE and DFlash test fixtures to the runner and iteration ID APIs.

Repair AITER fake-pool routing, move the unchanged FlashInfer numerical regression file to `kernels/ops/attention` with base coverage retained, and remove three obsolete stub-only tests.
