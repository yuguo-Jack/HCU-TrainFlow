## Motivation

Separate factories for full/window/state combinations duplicate layout grouping, sizing and construction decisions.

## Changes

Declare each layer's storage geometry and lifetime, derive a shared sub-pool plan, and build through one entry point. Centralize byte-budget sizing and the single-request feasibility floor, preserving fused-draft regions and request/state bindings.

## Validation

Historical validation at `638be96da4` / `bc0df1fbcf`:
- Factory-versus-builder comparison: **393 runs / 76,968 operations, 0 divergences**.
- **28 layouts and three capacity floors** matched.
- Fused-draft placement: **44 tests passed**; golden: **3 tests / 31 subtests passed**.

Later CPU review matched **418 layout values**. These results precede the latest rebase; no new serving run was performed.
