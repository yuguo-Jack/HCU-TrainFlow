# [Fix] auth: Require admin API key for weight update endpoints

[Upstream PR](https://github.com/sgl-project/sglang/pull/44270) · state: open · merged: False

## Original PR description

## Summary

Weight update endpoints modify persistent model state and should not be accessible with an ordinary API key alone. Following the pattern from #44242, add the `admin_api_key` check to 9 weight-related endpoints:

- `/update_weights_from_disk`
- `/update_weights_from_tensor`
- `/update_weights_from_distributed`
- `/update_weights_from_ipc`
- `/update_weight_version`
- `/init_weights_update_group`
- `/destroy_weights_update_group`
- `/begin_weight_update`
- `/end_weight_update`

When the server is started without `--admin-api-key`, these endpoints now return 400 instead of allowing access with just `--api-key`.

Note: This PR is based on main and may need a rebase after #44242 merges (both touch `test_http_server_auth_levels.py`).
