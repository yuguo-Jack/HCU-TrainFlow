# [Fix] [AMD] quark: Match aiter's column-major scale layout in the MXFP4 quant fake

[Upstream PR](https://github.com/sgl-project/sglang/pull/47908) · state: open · merged: False

## Original PR description

## Motivation

Quark MXFP4 W4A4 dense linears (`QuarkW4A4MXFP4`, Triton path) crash under `--enable-torch-compile` on ROCm because the fake impl of `sglang::aiter_dynamic_mxfp4_quant` declares a row-major block scale while aiter returns a column-major one; this PR allocates the fake scale the way aiter does. aiter's `dynamic_mxfp4_quant` returns `torch.empty((N/32, M)).T` with stride `(1, M)`, the fake returns a contiguous `(M, N/32)`, and Inductor emits an `assert_size_stride` from the fake that fails during CUDA-graph capture:

```
AssertionError: expected size 4==4, stride 1==128 at dim=0; expected size 128==128, stride 4==1 at dim=1
Error in op: torch.ops.sglang.aiter_dynamic_mxfp4_quant.default
```

Reproduced on MI355X at main@f85ca901e2 with `Qwen3-8B --quantization quark_mxfp4 --enable-torch-compile`; the server came up and generated normally with this fix. No default configuration reaches the path: it needs ROCm with `--enable-torch-compile` (off by default), plus checkpoints with Quark MXFP4 dense linears (e.g. layers 0-2 of GLM-5.3-Quark-MXFP4-AttnFP8) or online `--quantization quark_mxfp4`.

## Modifications

- Allocate the fake's block scale exactly like aiter: a `(ceil(N/32), M)` buffer, transposed.
- Add a regression test to `test_quark_mxfp4_asm.py` that runs the op under `FakeTensorMode` and checks the scale's shape and `(1, M)` stride. It needs a ROCm build with aiter but no GPU, so the file is also registered for AMD CI.

## Accuracy Tests

Not applicable: the fake only describes output metadata for tracing; eager numerics are unchanged.

The new test, run CPU-only at main@b45a36531c:

| tree | result |
|---|---|
| main | fails: stride `(65, 1) != (1, 37)` |
| scale allocated transposed, then `.contiguous()` | fails: stride `(65, 1) != (1, 37)` |
| `(M, N/32)` buffer transposed | fails: shape `(65, 37) != (37, 65)` |
| this PR | passes |
