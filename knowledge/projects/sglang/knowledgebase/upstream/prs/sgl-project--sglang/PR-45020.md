# [Refactor] memory-pool: Build unified page-envelope host pools from buffer info

[Upstream PR](https://github.com/sgl-project/sglang/pull/45020) · state: closed · merged: True

## Original PR description

## Motivation

Followup of #40917. `UnifiedPageEnvelopeHostPool` read the shared device region through `get_page_envelope_buffer()`, `get_contiguous_buf_infos()` and `grow_direction` on the device pool. The unified MHA pool now attaches a `PageEnvelopeBufferInfo` (backed allocation, registrable bytes, page view, page size and grow direction) to its `MHABufferInfo`, and the host pool and its shared backing are built from that description. The checks that full and SWA share one region and grow from opposite ends now run on the description.

Host layout, capacity and the transfer path are unchanged.

## Accuracy

gpt-oss with `--enable-unified-memory`, HiCache multi-turn KL with forced host hits against #40917, same commands on both sides. The assembled `UnifiedPageEnvelopeHostPool` pair, the H2D transfer sequence and KL are identical to the parent.
