## Motivation

`test/srt/` is retired, but three test files were reintroduced there and are outside `run_suite.py` discovery.

## Modifications

- Move both AITER guard tests to `test/registered/attention/`, preserving their AMD registrations and test bodies.
- Move the Mamba2 checkpoint-remapping test to `test/registered/unit/models/`, register it for CPU CI, use `CustomTestCase`, and update its run command.
- Reject `test/srt/` paths in pre-commit. The existing lint workflow runs these hooks with `--all-files`, so CI also rejects a legacy path restored by a merge. Document the supported locations in `test/README.md`.
