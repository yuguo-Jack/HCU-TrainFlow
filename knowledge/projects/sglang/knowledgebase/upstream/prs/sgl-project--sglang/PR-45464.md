## Motivation

Depends on #45463; only the last commit is new in this PR.

Each cached-prefix prefill runs a separate replay forward before its extend.

## Modifications

- HIP sets `folds_encoder_swa_replay` from `SGLANG_HIP_FOLD_ENCODER_SWA_REPLAY` (default on).
- Extend and late-layer tail rows are floored at their request's replay start via `encoder_swa_row_floor`; MLP-sync padding rows get floor 0. Unit test added.

## Accuracy Tests

GSM8K 5-shot, 1319 questions, same setup: main 0.889 -> 0.897 with the series.

## Speed Tests and Profiling

Measured with the full series (1/3-3/3) on 2x MI355X, TP2, DeepSeek-V4.1-Flash, DSpark, `--enable-encoder-swa-bounded-replay`, AgentX trace replay c64 PDI 8: TTT/GPU 157,543 -> 174,697 (+10.9%), TPOT p50 13.95 -> 11.84 ms, P90 interactivity 57.3 -> 65.5.
