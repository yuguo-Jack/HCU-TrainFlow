## Motivation

On qualified ROCm gfx95 + AITER configurations, the fused HiSparse swap-in kernel (plan + real KV
copy in one dispatch) overlaps poorly with shared-index (IndexShare) prefetch when prefetch is
disabled, and doesn't let skip-layers in a shared-index group reuse the anchor's miss plan without
re-planning. Splitting miss planning from the real KV copy lets skip layers replay a recorded plan
and lets the real copy use a wider grid, independent of whether the fused kernel's prefetch path is
in use.

## Modifications

- `hisparse_coordinator.py`: on ROCm gfx95 with AITER, and only for the DSA MLA KV pool (not DSV4,
  not MiniMax M3 — both have their own dedicated swap-in path and never go through this one),
  record the miss plan first and run a dedicated copy-only kernel for the real KV transfer, using a
  16-block grid for that copy. When `SGLANG_DISABLE_HISPARSE_PREFETCH` disables the shared-index
  prefetch stream, follower layers in a shared-index group still reuse the anchor's recorded plan
  and copy synchronously on the current stream instead of falling back to a full re-plan-and-copy.
  Prefetched copies keep their existing stream/event fork-copy-record-wait ordering. The qualification
  gate (`_can_use_separate_copy`) is a standalone function so it's testable without constructing a
  full coordinator.
- `model_runner.py`: `_can_use_synchronous_hisparse_shared(...)` decides whether
  `resolve_shared_index_layers` may keep the shared-index pattern under the prefetch kill-switch,
  requiring the HIP + AITER + gfx95 + DSA-pool combination.
- The planned-copy path raises at initialization if `SGLANG_DEBUG_HISPARSE_SKIP_IO` is also set,
  since the debug flag's elided-IO semantics are incompatible with requiring a real KV transfer;
  this check is scoped to the DSA MLA pool only (MiniMax M3 and DSV4 pools use their own swap-in
  paths and are unaffected).

## Tests

- `test/registered/unit/managers/test_rocm_hisparse_optimizations.py`: gate correctness
  (`_can_use_separate_copy` true/false for each of HIP/AITER/gfx95/DSV4/M3 individually), fallback
  to the original fused swap-in on every unsupported combination (HIP off, AITER off, gfx95 off,
  DSV4, M3), plan/copy ordering and grid size on the separate-copy path, shared-index synchronous
  reuse without the prefetch stream, pattern-invalidation fallback, and the prefetch kill-switch's
  interaction with `allow_synchronous_shared`.
- `test/registered/unit/model_executor/test_hisparse_shared_gate.py`: every one of the four runtime
  capabilities (`is_hip_backend`, `use_aiter`, `gfx95`, `is_hisparse_dsa_pool`) is individually
  required for `_can_use_synchronous_hisparse_shared`.
