# [srt] Inject "__req__" into custom_params only for custom logit processors

[Upstream PR](https://github.com/sgl-project/sglang/pull/43181) · state: closed · merged: True

## Original PR description

## Motivation

`Req.__init__` copies `sampling_params` and adds a `"__req__"` entry pointing at the request itself whenever `custom_params` is a dict. Only custom logit processors read that entry (`ThinkingBudgetLogitProcessor`, `DeepseekOCRNoRepeatNGramLogitProcessor`, `LocateAnythingBoxGrammarLogitProcessor`, and the user-supplied ones), but it was injected for every request that carried `custom_params`, including requests that only use `custom_params` for plain per-request options and attach no processor at all.

Each such `Req` became a reference cycle (`req -> sampling_params -> custom_params -> req`), so it could only be reclaimed by the cyclic garbage collector rather than by refcount when the scheduler dropped its last reference. Under sustained load that keeps finished requests, and everything they hold, alive until the next collector pass.

## Modifications

- `Req.__init__` adds the `"__req__"` entry only when `custom_logit_processor` is set. Processors still find their request under `"__req__"`; a request without one no longer references itself.
- Drop the comment in `sampling_params.py` that described the unconditional injection; the condition at the injection site now says when it happens.
- Add `test/registered/unit/managers/test_req_custom_params_ref.py` (CPU, `base-a-test-cpu`): with `gc` disabled, a `Req` carrying `custom_params` and no processor is freed when its last reference drops, and a `Req` with a processor still exposes itself under `"__req__"`. The first case fails on `main` and passes with this change.

## Accuracy Tests

Not applicable: no change to model outputs. Requests with a custom logit processor receive exactly the same `custom_params` dict as before.

## Speed Tests and Profiling

Not applicable: the only change on the hot path is one extra `is not None` check in `Req.__init__`.
