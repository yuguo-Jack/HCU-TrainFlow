# [LoRA] Support GDN in_proj_ba adapters for Qwen3.5

[Upstream PR](https://github.com/sgl-project/sglang/pull/31522) · state: open · merged: False

## Original PR description

## Motivation

Qwen3.5's GDN (GatedDeltaNet) hybrid linear-attention layers fuse the b/a input projections into a single `in_proj_ba` Linear. LoRA adapters trained against the unfused layout (HF / Megatron-Bridge export: separate `in_proj_b` + `in_proj_a`, or 2-way `in_proj_qkv` + `in_proj_z`) currently cannot be loaded — the weights don't map onto SGLang's fused module.

This ports sglang-miles #30499 to main.

## Modifications

- `lora/lora.py`: new `_normalize_in_proj_ba` — concatenates split `in_proj_b` + `in_proj_a` adapter weights into fused `in_proj_ba` (B rows `b|a`, A blocks stacked); for adapters already trained against the fused Linear (PEFT), replicates the shared `lora_A` 2x across the stacked b/a slots.
- `_normalize_in_proj_qkvz`: new branch for the Megatron-Bridge 2-way split export (`in_proj_qkv` + `in_proj_z` → `in_proj_qkvz`, repeating the qkv `lora_A` block 3x).
- `lora/utils.py`: `in_proj_b`/`in_proj_a` → `in_proj_ba` target-module normalization, `get_stacked_multiply(in_proj_ba) = 2`, target-module name matching.
- `models/qwen3_5.py`: `in_proj_ba` added to supported LoRA modules; `get_hidden_dim` returns `(hidden_size, linear_num_value_heads * 2)`.

## Accuracy Tests

On H200:

- **Format equivalence** (the new path): three synthetic adapters built from the same random tensors — split `in_proj_b`+`in_proj_a` vs merged `in_proj_ba` — produce **bit-identical** outputs on `Qwen/Qwen3.5-4B` (`max_abs_diff = 0.0e+00`, greedy output ids equal at tp1 and tp4), and both differ from base (adapter effect non-zero, max prompt-logprob diff 7.1e-02).
- **TP sharding**: tp4 runs show no shape asserts; tp1-vs-tp4 drift stays within the base model's own TP numeric envelope (mean 1.9e-02 vs base 1.2e-02).
- `test/registered/lora/test_lora_qwen3_5_4b_logprob_diff.py`: passed (dense GDN path incl. existing `in_proj_qkvz`).
- `test/registered/lora/test_lora_qwen3_5_35b_a3b_logprob_diff.py`: passed (MoE Qwen3.5, tp4).
- Regression `test/registered/lora/test_lora_tp.py` (CI subset): 2 passed.
