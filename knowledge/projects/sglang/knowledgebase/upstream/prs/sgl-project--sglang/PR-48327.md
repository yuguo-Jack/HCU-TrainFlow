# [Refactor] scheduler: Release in-step finishes through the request retirer

[Upstream PR](https://github.com/sgl-project/sglang/pull/48327) · state: closed · merged: True

## Original PR description

Requests that finish inside a step (EOS, length, stop, a sampling-mask abort, a discarded prefill, an embedding, a dLLM block, a PD decode prebuilt request) released their memory through seven hand-written sequences in output processing. They now all release through one entry, `RequestRetirer.release_finished(req, checkpoint=...)`: HiSparse clears its mapping of the row, then `release_kv_cache` frees it. Their output still goes out with the step through `stream_output`.

- Callers: `process_batch_result_prebuilt`, `process_batch_result_prefill` (generation and embedding, finished and discarded), `_handle_sampling_mask_abort`, `_handle_finish_state_updated_req`, and the dLLM `_finish_dllm_request_if_needed`.
- Kept per site: each site's `checkpoint` value; the decode offload branch (release after the D2H copy); the MLX `prepare_for_kv_cache_release` hook, which the prefill path still calls only for decoding requests in a mixed batch.
- The scheduler builds the beam coordinator and the retirer before the batch result processor, which now holds the retirer.
- `abort_queued` ends with the same `release_finished` call, so the memory release order (HiSparse rows, then KV and mamba state, each only when held) is written once.
- The test that lists functions outside the retirer still calling `release_kv_cache` drops these five.

No behavior change:
- The retirer calls HiSparse when its coordinator exists; the scheduler's coordinator is built exactly when HiSparse is enabled, which is what the old `get_memory().enable_hisparse` checks read.
- On the prefill path the MLX hook now runs before the HiSparse call instead of after; MLX and HiSparse are never enabled together.

## Test plan
- Tests that build the batch result processor get a real retirer through `release_only_retirer` (`sglang/test/scheduler_test_utils.py`), and patches of `release_kv_cache` move to the retirer module.
- The unit tests of the changed sites pass locally (397 tests).
