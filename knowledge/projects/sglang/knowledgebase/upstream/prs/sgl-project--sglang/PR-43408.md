# [diffusion] comfyui: Preserve odd-size MiniMax H3 ComfyUI layouts

[Upstream PR](https://github.com/sgl-project/sglang/pull/43408) · state: closed · merged: False

## Original PR description

## Summary

ComfyUI's MiniMax H3 PackedLayout signature uses the patch-padded latent height and width. The SGLang adapter compared those values to the original unpadded video tensor, so a 5x7 latent was rejected as stale even though its serialized layout correctly described the padded 6x8 grid. With fl2va keyframes, rejecting the layout raises `NotImplementedError` because the fallback cannot reconstruct ComfyUI keyframe positions.

This change compares the signature against height and width rounded up to the 2x2 patch size and adds a regression test with an odd 5x7 target and keyframe latent.

## Validation

- The production signature helper accepts the 5x7 -> 6x8 layout; the prior unpadded comparison rejects it.
- Changed Python files compile with Python 3.12; `git diff --check` passes.
- The full pytest case could not run in this environment: Python 3.9 is below this checkout's syntax requirements, while Python 3.12 does not have pytest or PyTorch installed.
- GPU end-to-end validation was unavailable because this machine has no NVIDIA runtime/device.
