# [Fix] [AMD] Keep QK-norm RoPE shuffles within logical warps

[Upstream PR](https://github.com/sgl-project/sglang/pull/47439) · state: open · merged: False

## Original PR description

## Summary

- use the native 64-bit HIP execution mask for the JIT QK-norm/RoPE kernel
- mirror each logical-warp mask across both halves of a wave64
- pass an explicit logical width of 32 to partial-RoPE shuffles
- add focused gfx950 partial-NeoX correctness coverage

## Motivation

The kernel is written around 32-lane logical warps, while HIP executes two of them in one wave64. A 32-bit mask and implicit shuffle width can select lanes from the other logical warp for partial-RoPE configurations.

This PR deliberately contains only the generic wave64 portability fix. The experimental MiMo DFLASH caller is excluded because it did not improve end-to-end throughput.

## Validation

- Python syntax and diff checks pass locally
- focused gfx950 GPU test is included; full GPU CI is intentionally left to the draft review cycle
