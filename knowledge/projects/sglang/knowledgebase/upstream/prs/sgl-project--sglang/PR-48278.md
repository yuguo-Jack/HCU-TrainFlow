## Motivation

`test/registered/spec/dspark/test_dspark_simulated_bonus.py` covers `sample_simulated_bonus`, which draws the DSpark bonus token at the simulated accept row when `SGLANG_SIMULATE_ACC_LEN` is set. It is registered only for AMD CI, so no NVIDIA run exercises this path, although it has changed recently (#46404, #46840).

## Modifications

- Register the test for CUDA CI (`base-b`, `1-gpu-small`, est. 10 s).

## Accuracy Tests

Not applicable; test registration only. The three tests pass on B300 (3 tests in 4.2 s).
