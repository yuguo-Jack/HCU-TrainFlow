# [Test] Fix MiniMax sparse FP8 attention GEMM imports

[Upstream PR](https://github.com/sgl-project/sglang/pull/37224) · state: closed · merged: False

## Original PR description

## Motivation

MiniMax sparse kernels were migrated from `sglang.srt.layers.attention.minimax_sparse_ops` to `sglang.kernels.ops.attention.minimax_sparse` in #30793.

The FP8 regression test `test_fp8_attn_gemm.py` was later introduced by #30971. Work on #30971 started before the kernel migration was merged, and this test retained the pre-migration import paths when it was eventually merged.

As a result, the test currently fails during collection on the latest `main` branch with:

```text
ModuleNotFoundError: No module named 'sglang.srt.layers.attention.minimax_sparse_ops.decode'
```
This PR updates those stale imports to the canonical kernel paths established by #30793, allowing the existing MiniMax FP8 attention GEMM regression tests to be collected and run again.

## Modifications

Updated 4 imports in:

```
python/sglang/srt/layers/attention/minimax_sparse_ops/tests/test_fp8_attn_gemm.py
```
The imports were changed from the pre-migration runtime paths:
```
sglang.srt.layers.attention.minimax_sparse_ops...
```
to the current kernel paths:

```
sglang.kernels.ops.attention.minimax_sparse...
```

## Validation

This PR only fixes test imports and does not affect model outputs or runtime behavior.

Validation before the fix:

```bash
python3 -m pytest -q
python/sglang/srt/layers/attention/minimax_sparse_ops/tests/test_fp8_attn_gemm.py
--collect-only
```
Result before the fix:
```

```
Result after the fix:
```
10 tests collected
```
