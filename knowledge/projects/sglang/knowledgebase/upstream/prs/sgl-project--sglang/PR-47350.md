# [Grammar] Emit compact JSON when --constrained-json-disable-any-whitespace is set (xgrammar)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47350) · state: closed · merged: False

## Original PR description

## Motivation

`--constrained-json-disable-any-whitespace` is documented as "Enforce compact representation in JSON constrained output". The xgrammar backend turns it into `compile_json_schema(any_whitespace=False)` without `separators`, so xgrammar falls back to the `json.dumps` default `(", ", ": ")`, and the grammar *requires* a space after every `,` and `:`.

Acceptance of each output for the schema `{"a": integer, "b": [integer]}`:

| `any_whitespace` | `separators` | `{"a":1,"b":[2,3]}` | `{"a": 1, "b": [2, 3]}` |
|---|---|---|---|
| `False` | `None` (today) | rejected | accepted |
| `False` | `(",", ":")` (this PR) | accepted | rejected |
| `True` | `None` | accepted | accepted |

These were checked on xgrammar 0.1.32 and 0.2.1. In the 0.2.1 sources, `JSONSchemaConverter` picks `", "` and `": "` when `separators` is unset, `any_whitespace` is false, and there is no indent.

The llguidance backend already emits compact JSON for this flag. It passes `whitespace_flexible=False`, and `JsonCompileOptions` defaults to `","` and `":"`. With llguidance 1.7.0 and those options, `{"a":1,"b":[2,3]}` is accepted and `{"a": 1, "b": [2, 3]}` is rejected.

Those separators tokenize at roughly one token per character. On a JSON-heavy workload we measured them at about 12% of output tokens.

## Modifications

Pass `separators=(",", ":")` to `compile_json_schema` when `any_whitespace` is `False`. The default (`any_whitespace=True`) and the builtin `$$ANY$$` JSON grammar are unchanged.

**Behavior change:** with the flag set, xgrammar outputs become `{"a":1}` instead of `{"a": 1}`. That is what the flag's help text describes, it matches llguidance, and the output is still valid JSON. The constrained-decoding test sets the flag in AMD CI; its JSON checks parse the output with `json.loads`, so they are unaffected.

## Accuracy Tests

Grammar acceptance is shown in the table above. End to end, a JSON-schema structured-output replay workload on an out-of-tree platform passes with the flag set.
