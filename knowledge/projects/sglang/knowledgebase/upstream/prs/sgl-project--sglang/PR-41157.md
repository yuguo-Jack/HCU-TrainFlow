# [Fix] benchmark: Separate LoRA server flags

[Upstream PR](https://github.com/sgl-project/sglang/pull/41157) · state: open · merged: False

## Original PR description

## Motivation

The LoRA benchmark launcher appends optional server flags without separators. Enabling two or more produces an invalid argument such as `--disable-custom-all-reduce--enable-mscclpp`.

## Modifications

- Separate the three optional flags in the constructed command.
- Add a CPU-only regression covering all eight flag combinations.
- Remove an existing redundant f-string prefix in the touched file so Ruff passes.

## Accuracy Tests

No model or inference code changes. `python -m pytest benchmark/lora/test_launch_server.py -q`: 1 passed (all eight combinations).

## Speed Tests and Profiling

Not applicable; this only fixes benchmark server command construction.
