## Motivation

<!-- Describe the purpose and goals of this pull request. -->

This PR integrates DSA attention and indexer operations with page-sharded KV caches for GLM-5.2. It separates logical page IDs from scratch addresses and routes fused indexer writes to both scratch and owner-local persistent storage while preserving existing quantization behavior. DSA and indexer fixtures and tests are consolidated into the attention test module, keeping general page-sharding coverage separate.
