# [Fix] glm5_next: Correct num_experts_per_tok default to 8

[Upstream PR](https://github.com/sgl-project/sglang/pull/44093) · state: closed · merged: True

## Original PR description

## Motivation

`Glm5NextTextConfig` (the GLM-5-Next / GLM-5.3-Flash config) defaults
`num_experts_per_tok` to `7`, but the model routes top-8. The released
GLM-5.3-Flash [`config.json`](https://huggingface.co/zai-org/GLM-5.3-Flash/blob/main/config.json) sets `num_experts_per_tok=8`, and the other expert
geometry defaults in this class already match that model
(`n_routed_experts=288`, `n_shared_experts=1`). The `7` default is inconsistent
with the model the class describes.

Real checkpoints always carry the value, so this is harmless at runtime, but the
default is misleading for anyone reading or instantiating the config without a
full `config.json`.

## Modifications

One-line change in `python/sglang/srt/configs/glm5_next.py`:
`num_experts_per_tok: int = 7` -> `num_experts_per_tok: int = 8`.

## Accuracy Tests

Not applicable — the value is overridden by every real checkpoint config; no
forward-path or output change.
