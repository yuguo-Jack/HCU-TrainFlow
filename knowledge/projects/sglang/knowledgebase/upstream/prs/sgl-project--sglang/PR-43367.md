## Motivation

[Wan2.2 ModelSlim W4A4F4 checkpoints](https://modelscope.cn/models/Eco-Tech/Wan2.2-T2V-A14B-Diffusers-MXFP-W4A4F4-DAOS) need packed FP4 weights, exported calibration data, and matching attention and precision paths to run in SGLang. This PR adds offline inference support on Ascend 950.

## Modifications

- Repack ModelSlim exports into Diffusers checkpoints, preserving quantization descriptors, smoothing scales, and Q/K rotations while packing FP4 weights.
- Support offline MXFP4/MXFP8 linears and timestep-based W4A4/W4A8 selection. Single-level MXFP4 weights remain ND; the existing dual-scale path retains its NZ requirement.
- Select FP8 or MXFP4 self-attention from checkpoint descriptors and apply exported Q/K rotations. MXFP4 attention requires the experimental CANN quantized-attention extension.
- Invalidate legacy Cache-DiT residual and calibrator histories when effective precision changes, forcing computation for both CFG branches. For the default 40-step schedule, this protects W4A8 → W4A4 at global step 2 and W4A4 → W4A8 at step 38; the final two steps also compute fully. Explicit checkpoint-policy transitions are detected automatically.
- Use token sharding for incompatible latent frame counts when allowed, reject an explicit sharding disable for those shapes, and use synchronous NPU-to-CPU component offload to avoid pinned-memory allocation failures.
