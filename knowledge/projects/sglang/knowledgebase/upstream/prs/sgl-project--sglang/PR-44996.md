# [CI] diffusion: Tighten H100 baselines and enable B200 performance checks

[Upstream PR](https://github.com/sgl-project/sglang/pull/44996) · state: closed · merged: True

## Original PR description

## Motivation

Several H100 performance references predate recent improvements and leave CI unable to catch regressions back toward those older costs. Tighten the stable references using recent scheduled main CI artifacts. B200 ModelOpt cases currently skip stage, denoise, and GPU-memory validation; enable those checks with references calibrated from their CI artifacts.

## Modifications

Update 35 timing and allocated-memory references across 11 cases in `h100.json`. Each changed metric has at least five independent comparable main runs, including the latest collected run, with matching testcase configuration and verified H100 job/artifact provenance.

Timing references use the observed maximum plus 5%; allocated-memory references use the maximum plus 1%, rounded upward to 0.01. Only references decreasing by at least 10% are changed; candidate max/min ratios are capped at 1.4 for timing and 1.1 for memory. Samples from cases with non-passing final reports are excluded. Multiple requests and retries within one run do not increase the independent-run count.

Existing relative/absolute tolerances remain unchanged. Only checks enabled for each testcase are tightened. B200/5090 references, host-memory limits without sufficient samples, consistency GT, and production code are unchanged.

Calibration sources (October 14–17, 2026):

## B200 performance coverage

Enable `run_perf_check` explicitly for all five existing B200 NVFP4 cases. Add a default-off factory option so the existing literal case list remains visible to static CI partition discovery; FP8/H100 cases retain their existing settings.

Calibrate the newly enabled stage, denoise, and GPU-memory checks from five independent main CI runs per case. Timing references use the observed maximum plus 5%; memory references use the maximum plus 1%. Add both reserved and allocated load/runtime peaks; the existing validator enforces allocated memory when available, while reserved memory is reported for context.

Previously active B200 E2E/load references, runner overrides, tolerances, and consistency checks remain unchanged. This enables coverage that was previously disabled; it does not change inference code.

B200 source runs: [38482436865](https://github.com/sgl-project/sglang/actions/runs/38482436865), [38554777367](https://github.com/sgl-project/sglang/actions/runs/38554777367), [38725436953](https://github.com/sgl-project/sglang/actions/runs/38725436953), [38979902269](https://github.com/sgl-project/sglang/actions/runs/38979902269), [39027561441](https://github.com/sgl-project/sglang/actions/runs/39027561441), and [39077836460](https://github.com/sgl-project/sglang/actions/runs/39077836460). Each selected case has a final PASS in its exact job log; earlier failures followed by successful retries are not mistaken for final failures. FLUX.2 uses the earlier matching-config run because the latest run failed during setup with Hugging Face HTTP 429. The older FLUX.2 model inputs, sampling parameters, weights path, and environment match the calibration configuration. The final factory change adds only the performance-validation opt-in.

## CI collection

Keep the B200 cases in the static parser’s supported literal-list format. Correct the inherited Inkling four-H100 registration to the existing `extra-b` suite, allowing global registered-test collection to complete. Test behavior and accuracy assertions are unchanged.

## Accuracy Tests

Data-only CI calibration; no model-output changes or new GPU generation performed.

## Speed Tests and Profiling

- Replayed historical metrics through the actual `PerformanceValidator` / `VideoPerformanceValidator` numeric validation methods and existing tolerances: 393 comparisons, no new failures.
- Verified all 35 changed effective-limit boundaries reject values accepted by the old limits.
- B200: 100 historical-data validator comparisons passed, with all 25 synthetic regression probes rejected across the five cases.
- The actual diffusion partition command discovers all five B200 cases; registered-test validation, pre-commit, and diff checks passed.

These are historical-artifact checks, not new inference speed measurements. No new GPU/model runs were used for calibration. Fresh H100/B200 CI remains the final regression check.
