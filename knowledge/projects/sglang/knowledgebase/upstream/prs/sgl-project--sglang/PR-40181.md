# fix: fail fast on DFlash anchor-first checkpoints

[Upstream PR](https://github.com/sgl-project/sglang/pull/40181) · state: closed · merged: False

## Original PR description

Fixes #40144

This adds an explicit check in `parse_dflash_draft_config` for checkpoints trained with the anchor-as-first-prediction layout. Currently, SGLang assumes the 1+N convention and serves these checkpoints silently with degraded acceptance. By rejecting configurations with `sample_from_anchor=True` or `query_zero_predicts_next=True`, we fail fast and match the behavior of vLLM.
