# [Fix] [NPU] attention: preserve GPT-OSS FIA sinks in prefill and eager decode

[Upstream PR](https://github.com/sgl-project/sglang/pull/44027) · state: open · merged: False

## Original PR description

## Motivation

GPT-OSS uses equal D64 Q/K and V heads with learned scalar attention sinks. With FIA enabled, prefill currently selects the BSND fallback because D64 is outside the general TND whitelist. That fallback omits `learnable_sink`; for full-attention layers it also passes `pre_tokens=-1`, which FIA rejects. The eager decode branch also passes learned sinks through BSND; it needs the TND sink layout and its cumulative query-length contract.

Fixes #44025.

## Modifications

Route equal D64 prefill attention with sinks through the existing TND sink branch. For eager decode with learned sinks, use contiguous packed TND queries, cumulative one-query sequence lengths, the matching causal/sliding mask, and the full-attention window value.

Add a registered NPU server regression using the genuine pretrained BF16 GPT-OSS-20B checkpoint, with prompts below and above the sliding-window length. Each prompt must generate more than one token, exercising eager decode as well as prefill. The test also checks prompt token counts and finite output token log probabilities. It is registered in `base-b-test-1-npu-a3`.

This change covers prefill and eager decode with learned sinks. The graph replay work in #33635 is separate.
