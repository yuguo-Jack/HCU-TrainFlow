# [NPU] Preserve GPT-OSS attention sinks in FIA prefill and eager decode

[Upstream PR](https://github.com/sgl-project/sglang/pull/44027) · state: open · merged: False

## Original PR description

## Motivation

GPT-OSS uses equal D64 Q/K and V heads with learned scalar attention sinks. With FIA enabled, prefill currently selects the BSND fallback because D64 is outside the general TND whitelist. That fallback omits `learnable_sink`; for full-attention layers it also passes `pre_tokens=-1`, which FIA rejects. The eager decode branch also passes learned sinks through BSND; it needs the TND sink layout and its cumulative query-length contract.

Fixes #44025.

## Modifications

Route equal D64 prefill attention with sinks through the existing TND sink branch. For eager decode with learned sinks, use contiguous packed TND queries, cumulative one-query sequence lengths, the matching causal/sliding mask, and the full-attention window value.

Add a registered NPU server regression using the genuine pretrained BF16 GPT-OSS-20B checkpoint, with prompts below and above the sliding-window length. Each prompt must generate more than one token, exercising eager decode as well as prefill. The test also checks prompt token counts and finite output token log probabilities. It is registered in `base-b-test-1-npu-a3`.

This change covers prefill and eager decode with learned sinks. The graph replay work in #33635 is separate.

## Accuracy Tests

Environment: Ascend 910_9382 (single A3); CANN 9.0.0; Python 3.11.15; torch 2.10.0+cpu with torch-npu 2.10.0; triton-ascend 3.2.1.dev20260530; Transformers 5.19.0; sgl-kernel-npu 2026.5.1 with an isolated, reviewed SwiGLU-OAI source overlay (not the unmodified stock package)..

Checkpoint: [`unsloth/gpt-oss-20b-BF16`](https://huggingface.co/unsloth/gpt-oss-20b-BF16/tree/5a6fe4c0c1a86147cb9dc1bb99486e61d12a3c9e), pinned revision `5a6fe4c0c1a86147cb9dc1bb99486e61d12a3c9e`, with its original 24-layer configuration and weights. Single NPU, TP=1, BF16, Q64/KV8/D64, page size 128, FIA enabled, and both graph backends disabled.

Validation required the independent SwiGLU-OAI UB-capacity fix in https://github.com/sgl-project/sgl-kernel-npu/pull/857. The original FIA source, patched FIA source, and registered test all used the same isolated kernel package containing that fix. The standalone dependency regression passed 7 test methods / 39 subcases without skips. Both sides use the original model configuration and weights. The observational run captures computed Q/K/V and learned sinks without rewriting them.

| Check | Result |
| --- | --- |
| Original FIA source at `b4822bae03589d0a127a0e5b1f06f0d28524f28b`, with the same kernel dependency | The real pretrained model fails during the original full-attention FIA path with the error below |
| Patched FIA prefill/eager decode source, real server, short and long prompts | Pass: 80/282 input tokens; each request generates 8 tokens with finite output token log probabilities |
| Actual pretrained prefill attention outputs from layer 0 (SWA128) and layer 1 (full attention), both prompts | All 46,336 observed token-heads pass; 0 precision failures; maximum relative L2 0.003780061955250345 (0.378%) under the fixed 1% gate |
| No-sink negative control, checked independently for each observed layer | All 4 captures reject the no-sink negative control, with 41,293 token-heads failing the unchanged precision gate in total |
| Registered server test, without the attention observer; more than one generated token per prompt | Pass: 1 registered test method / 2 HTTP subcases; 0 skips; exit code 0; each generates 8 tokens |
| Direct TND eager-decode operator numerical probe | 42 cases pass across D64/D128, contiguous and noncontiguous packed queries, paged KV, causal/full and SWA masks; independent sink/window/layout negative controls distinguish the incorrect paths |

The targeted prefill attention check uses actual pretrained Q/K/V and learned sinks, and compares the returned outputs against an independent CPU FP64 reference for every observed token/head. The fixed gate is relative L2 <= 1%, plus `sqrt(64) * 2^-134` for BF16 rounding, with finite values and exact expected-zero checks. The server runs the full 24-layer model; the real-model FP64 comparison observes only prefill outputs of layers 0 and 1. Eager decode is exercised by the multi-token server test; its operator-level numerical coverage is reported separately above. This is targeted attention correctness and server regression coverage, not a full task-quality benchmark.

The original and patched runs use the same isolated kernel dependency. The real-model runtime loaded the reviewed SwiGLU source before LF normalization; the published LF-only normalization has identical Python source after universal-newline decoding and also passed its standalone A3 regression.
