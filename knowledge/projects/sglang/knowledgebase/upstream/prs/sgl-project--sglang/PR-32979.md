# model: support Apertus 1.5

[Upstream PR](https://github.com/sgl-project/sglang/pull/32979) · state: open · merged: False

## Original PR description

## Summary

  This PR adds SGLang support for the Apertus v1.5 multimodal model family. Apertus accepts interleaved text, image, and audio inputs and generates text. Thanks to @AryanAhadinia For helping me with tool calling fix and QMT tests for prod online serving verification.

## Modifications

  - Add the Apertus v1.5 multimodal model implementation and processor.
  - Support HF-compatible prompt expansion, discrete image/audio token layout,
    per-artifact offsets, and multimodal embedding fusion.
  - Support raw media, `processor_output`, and `precomputed_embedding` inputs.
  - Register `swiss-ai/Apertus-v1.5-8B` for model testing and document the Apertus v1.5 family.
  - Add OpenAI-compatible E2E coverage for single-image, multiple-image, speech-audio, and interleaved image+audio requests.
 
  ## Transformers dependency

  This PR depends on [LINK](https://github.com/huggingface/transformers/pull/47662)

The linked Transformers PR is required to run the model and its E2E tests.

  ## Supported model

  - `swiss-ai/Apertus-v1.5-8B`
  - `swiss-ai/Apertus-v1.5-70B`

   ## Validation

  - OpenAI-server E2E coverage on `swiss-ai/Apertus-v1.5-8B`:

  ## Documentation

  Added the Apertus v1.5 family to the supported multimodal models page, including gated-model access and image/audio request examples.
