# [Fix] DWDP platform gate, device-timer CPU fallback, scripted-runtime and Flux/ComfyUI fixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/48368) · state: open · merged: False

## Original PR description

## Motivation
Platform-agnostic bug fixes split out of #37698. Fixes #31995.

## Modifications
- `handle_dwdp`: reject `--dwdp-size >= 2` on non-NVIDIA platforms at arg resolution instead of failing later on the missing `cuda` bindings.
- `DeviceTimer`: resolve the device module once and become a no-op on devices without timing events (e.g. CPU); `metrics_reporter` skips the occupancy sample there instead of publishing 0.
- Scripted runtime: the root node's permanent `lock_ref` reads as 0; launch with `cuda_graph_backend_prefill="disabled"` (the old `disable_prefill_cuda_graph` kwarg is gone).
- Intel AMX CPU suites skip off-CI when the host lacks AMX; in CI they still fail loudly.
- Flux/ComfyUI: raise a clear error when pooled embeds are missing; back-fill text seq lens in the ComfyUI latent-prep stage, which has no text-encoding stage.
