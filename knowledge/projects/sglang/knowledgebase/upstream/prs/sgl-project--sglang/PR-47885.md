# [NPU] Prototype opt-in fused masked attention for pi0.5

[Upstream PR](https://github.com/sgl-project/sglang/pull/47885) · state: open · merged: False

## Original PR description

## Motivation

Pi0.5 masked attention currently uses PyTorch SDPA in `LocalAttention`. On Ascend, representative isolated tests indicate that fused infer attention can be faster for the tested shapes. This draft explores routing a restricted NPU case to FIA.

Related to #47834.

## Prototype

- Gate the experimental path behind `SGLANG_EXPERIMENTAL_NPU_FIA_MASKED_ATTENTION=1`; the existing path remains the default.
- For 4D floating-point masks, check for zero and dtype-min-range values and fall back to SDPA for other values or fully masked rows.
- Convert the mask to the operator's skip-mask convention. Do not cache the decision on mutable tensors.

**Not ready for merge:** the threshold does not establish mask provenance or semantics for all callers. Maintainer feedback on carrying an explicitly typed/known pi0.5 mask through the attention interface would be welcome. The per-call checks can synchronize the device and must be evaluated for overhead.

## Evidence and validation

Prior 910C isolated microbenchmarks reported approximately 3x at BS=1 and 5.9x at BS=32 for FIA plus mask conversion versus SDPA. A separate same-node open-loop comparison using identical arrival-trace hashes observed lower FIA latency, but ran each variant once sequentially; repeat/alternating runs remain necessary. **Those results used a different, cached experimental patch; they are not measurements of the prototype in this PR, which deliberately avoids caching. No end-to-end performance claim is made for this implementation.**
