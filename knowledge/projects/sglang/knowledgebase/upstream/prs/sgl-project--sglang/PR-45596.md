# [Perf] attention: Combine zigzag PCP FlashAttention prefill launches

[Upstream PR](https://github.com/sgl-project/sglang/pull/45596) · state: open · merged: False

## Original PR description

## Motivation

`Zigzag PCP` splits each request's local queries into early and late segments. `FlashAttention` currently runs them separately, requiring two attention launches and an output concatenation per layer. Its varlen API already supports separate batch entries with independent KV lengths.

## Modifications

- Dispatch both segments in one varlen attention call using the existing combined zigzag metadata.
- Duplicate page-table rows once per forward batch and reuse them across layers, including the sliding-window page table where applicable.
- Remove the unused `cu_seqlens_k_new` argument from the CP callbacks; these calls read the KV cache without appending K/V.
- Keep the TRT-LLM-specific arguments and restore any padded output rows.
- Add a dispatch regression test and update CP strategy tests for the combined geometry.

## Accuracy Tests

4×H200; TP4, zigzag PCP4, EP4, FA3, BF16, page size 64.

DeepSeek-V2-Lite and GLM-4.7-Flash: deterministic inference, input lengths 8K/32K/64K, output lengths 1/16, 20 measured responses per case. **240/240 paired responses have identical text, generated token IDs and output logprobs (maximum absolute difference 0).** These are synthetic-input consistency checks, not task-accuracy evaluations.

GLM-4.7-Flash also matches exactly across all 240 ordinary-mode paired responses. V2-Lite also matches exactly across all 120 ordinary-mode paired responses.

Additional V2-Lite deterministic checks cover ragged batches `[17, 65, 513]` and `[2049, 4099]`, a 32K cached prefix followed by a 257-token suffix, and a cached ragged batch with 129/513-token suffixes. The prefix-hit requests report 32,768 cached tokens. All outputs and output logprobs match exactly. The separately profiled cold 32K/1 request also matches exactly.

CP strategy and MLA dispatch tests: **25 tests and 20 subtests passed**. Pre-commit passed for the five modified files.
