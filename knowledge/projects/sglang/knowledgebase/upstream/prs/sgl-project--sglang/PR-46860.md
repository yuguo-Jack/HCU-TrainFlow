# [Refactor] diffusion: normalize diffusers output layout in one place

[Upstream PR](https://github.com/sgl-project/sglang/pull/46860) · state: closed · merged: True

## Original PR description

Follow-up to #44888, from review feedback there https://github.com/sgl-project/sglang/pull/44888#discussion_r4333929856.

Output conversion now goes to one explicit contract: images (B, C, H, W), videos (B, C, T, H, W).

- `_convert_to_tensor` only makes things channels-first: images (B, C, H, W), videos (B, T, C, H, W), for NumPy, PIL and tensor inputs alike.
- New `_to_output_layout` maps that to the final layout in one step. Video vs image comes from the output attribute (`frames`/`video` vs `images`), so we no longer guess from shape.
- `_fix_output_shape` drops its 5D permute and the 4D video guess. It now only expands lower-rank images.

One behavior change: a 4D `images` tensor with B > 1 and C not in {1, 3, 4} used to be treated as a video. Now it stays an image.

Testing: CPU shape checks on NumPy BHWC/BTHWC, tensor BCHW/BTCHW/TCHW/CHW, PIL lists, and nested PIL/NumPy frame lists. All give the expected layout.
