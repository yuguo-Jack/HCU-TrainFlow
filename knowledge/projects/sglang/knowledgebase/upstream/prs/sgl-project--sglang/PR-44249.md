# [draft] [feat][AMD]Minimax-M3-mxfp4: share index top-k with a repeating pattern

[Upstream PR](https://github.com/sgl-project/sglang/pull/44249) · state: open · merged: False

## Original PR description

## Motivation

MiniMax-M3 on ROCm gfx95 shares one index top-k across a fixed number of sparse layers. A fixed size cannot express a repeating mix such as 2,3 or 3,4 or 4,5.  This PR enables this feature

## Modifications

- Add `SGLANG_MINIMAX_M3_INDEX_TOPK_PATTERN`, a comma-separated list of group sizes.
- Each number is one group. The first layer in the group searches. The next `number - 1` layers reuse that top-k. Then the next number starts a new group.
- `2,3`, `3,4`, and `4,5` all work. Any longer list of positive integers works the same way, for example `2,3,4` or `5,6`.
- The list repeats across the sparse layers.
- Leave the variable empty to keep `SGLANG_MINIMAX_M3_INDEX_TOPK_FREQ`.
- The pattern is read on ROCm gfx95 only, and only when two-batch overlap is off. Other platforms still use a group size of 1.

## How to run
After applying the PR, the below commands are used for replicating the experiments.

docker run -d --name minimax-m3-pattern23 \
  --network host --ipc host --shm-size 128g \
  --device /dev/kfd --device /dev/dri \
  --security-opt seccomp=unconfined \
  -v "${HOST_HF_HUB_CACHE}:/root/.cache/huggingface/hub" \
  -v "${SGLANG_SRC}:/sgl-workspace/sglang" \
  -e HF_TOKEN="${HF_TOKEN}" \
  -e HIP_VISIBLE_DEVICES=0,1,2,3 \
  -e SGLANG_USE_AITER=1 \
  -e SGLANG_USE_AITER_MOE_GU_ITLV=0 \
  -e SGLANG_USE_AITER_AR=1 \
  -e NCCL_IB_DISABLE=1 \
  -e NCCL_SOCKET_IFNAME=lo \
  -e ROCM_QUICK_REDUCE_QUANTIZATION=INT4 \
  -e SGLANG_WARMUP_TIMEOUT=20000 \
  -e SGLANG_MINIMAX_M3_INDEX_TOPK_FREQ=2 \
  -e SGLANG_MINIMAX_M3_INDEX_TOPK_PATTERN=2,3 \
  lmsysorg/sglang-rocm:v0.5.21-rocm724-mi35x-20261011 \
  python -m sglang.launch_server \
    --model-path amd/MiniMax-M3-MXFP4 \
    --tp 4 \
    --trust-remote-code \
    --reasoning-parser auto \
    --tool-call-parser auto \
    --quantization quark \
    --dtype bfloat16 \
    --chunked-prefill-size 32768 \
    --mem-fraction-static 0.85 \
    --context-length 131072 \
    --page-size 128 \
    --max-running-requests 256 \
    --watchdog-timeout 12000 \
    --dist-timeout 10800 \
    --enable-metrics \
    --enable-aiter-allreduce-fusion \
    --kv-cache-dtype fp8_e4m3 \
    --attention-backend aiter \
    --moe-runner-backend aiter \
    --port 8000
