# [Perf] deepseek-v4: Score a request's verify rows as one request in the C4 indexer

[Upstream PR](https://github.com/sgl-project/sglang/pull/45378) · state: open · merged: False

## Original PR description

[by Claude Code]

## Motivation

**What this PR does.** An MTP verify step checks several draft tokens per request (4 with the cookbook flags). In every DeepSeek-V4 model, the C4 indexer scores each token against its request's compressed index keys to choose which keys to attend to. Today the indexer passes DeepGEMM's scoring kernel each draft token as if it were a separate request. Since all 4 draft tokens of a request share the same keys, the kernel reads that request's keys from memory 4 times. This PR passes each request once with all of its draft tokens (DeepGEMM's `next_n` mode). The kernel then reads each key once and scores all 4 tokens against it. The scores are bit-identical; only the memory traffic changes. #45251 made the same change for the DSv4.1 ratio-1/2 indexers.

**Impact** (B200, DeepGEMM 0.2.2, 4 draft tokens):
- **Accuracy:** the scores match the current path bit for bit in all 48 shapes tested (FP8 and FP4, 2 and 4 draft tokens, 8-128 requests, 8K-128K context), so model outputs do not change.
- **Kernel speed:** 1.28x faster at 32 requests × 64K context (42.0 → 32.9 us), and 2.07x at 128 × 64K (186.3 → 90.2 us). At 16 or more requests it is never more than 1% slower in any of the 48 shapes.
- **End to end (estimate, not measured):** about 1% faster verify steps for DeepSeek-V4-Flash at 32 requests × 64K context. On main this kernel takes 4.3% of a verify step's GPU time, and this PR cuts its time by 22% at that shape.

## Modifications

**+47 / −16 runtime code (3 files), +45 tests (1 file).** No kernel changes.

- `group_verify_rows` (`dsv4/indexer.py`) reshapes the kernel inputs from one row per draft token to one row per request with `n` tokens: `q` to `[requests, n, ...]`, the lengths to `[requests, n]`, and the page table to one row per request. #45251's `paged_logits_args` (`v41_indexer/scoring.py`) now calls it too, so the reshaping lives in one place.
- The C4 indexer metadata gets `rows_per_request` (`deepseek_v4_backend.py`), which reuses #45251's scheduling path unchanged.
- The grouped path runs only for a static verify (fixed number of draft tokens per request) on the SM100 DeepGEMM kernels, with at least 16 requests. Below 16 requests at short context it was up to 1.2x slower than one row per token, so those batches keep the current path.

## Accuracy Tests

For every shape it times, the script below checks that the grouped call's scores equal the per-token call's bit for bit in each token's valid range. This held for all 48 shapes on B200. Since top-k receives identical scores, I did not run an end-to-end accuracy test.

CPU unit tests check that the reshaped inputs keep each token's query, length and page-table row, for FP8 and for an FP4 query/scale pair over a chunk of requests.

## Speed Tests and Profiling

Per-call time of the scoring kernel (`fp8_paged_mqa_logits`) from the script below (B200, DeepGEMM 0.2.2, FP8 cache, 4 draft tokens, 512 MB L2 flush before every call, median of 20 calls):

|---:|---:|---:|---:|
| 16 | 8K | 10.3 | 10.3 |

```python
"""DeepSeek-V4 C4 indexer logits for a static verify, per row vs grouped (sglang #45378).

Checks the grouped call's logits equal the per-row call's bit for bit in every row's
valid range, then times both (CUDA events, 512 MB L2 flush before every call). B200
with DeepGEMM and SGLang installed.

  python bench_c4_grouped_verify.py --next-n 4 --requests 16 32 128 --context 8192 65536 131072
  python bench_c4_grouped_verify.py --fp4 ...
"""

import argparse

import deep_gemm
import torch

from sglang.srt.layers.attention.dsv4.indexer import group_verify_rows

BLOCK_KV, HEAD_DIM, HEADS = 64, 128, 64


def verify_inputs(fp4, requests, next_n, context):
    """C4 indexer inputs of a static verify: request-major rows, compressed lengths
    (position + 1) // 4, a shuffled page table repeated per row."""
    torch.manual_seed(0)
    rows, dev = requests * next_n, "cuda"
    pages_per_seq = -(-(context // 4) // BLOCK_KV)
    num_pages = requests * pages_per_seq
    jitter = torch.randint(0, 64, (requests, 1))
    positions = context - next_n - jitter + torch.arange(next_n)
    lens = ((positions + 1) // 4).reshape(-1).to(torch.int32).to(dev)
    table = torch.randperm(num_pages, device=dev, dtype=torch.int32).view(requests, -1)
    q = torch.randn(rows, HEADS, HEAD_DIM, device=dev)
    k = torch.randn(num_pages * BLOCK_KV, HEAD_DIM, device=dev)
    weights = torch.randn(rows, HEADS, device=dev) / HEADS
    if fp4:
        from sglang.kernels.ops.kvcache.dsv4_fp4_index_k_cache import (
            store_fp4_index_k_cache,
        )
        from sglang.kernels.ops.quantization.fp4_indexer_quant import (
            quantize_fp4_indexer_tensor,
        )

        cache = torch.empty(num_pages, BLOCK_KV * 68, dtype=torch.uint8, device=dev)
        store_fp4_index_k_cache(
            k, cache, torch.arange(k.shape[0], device=dev), page_size=BLOCK_KV
        )
        q_fp4, q_sf = quantize_fp4_indexer_tensor(q)
        q = (q_fp4.view(rows, 1, HEADS, 64), q_sf.view(rows, 1, HEADS))
        cache = cache.view(num_pages, BLOCK_KV, 1, 68)
    else:
        scale = k.abs().amax(-1, keepdim=True) / 448.0
        k_fp8 = (k / scale).to(torch.float8_e4m3fn)
        cache = torch.cat(
            (
                k_fp8.view(torch.uint8).view(num_pages, -1),
                scale.view(num_pages, -1).contiguous().view(torch.uint8),
            ),
            dim=1,
        ).view(num_pages, BLOCK_KV, 1, HEAD_DIM + 4)
        q = q.to(torch.float8_e4m3fn).unsqueeze(1)
    return q, cache, weights, lens, table.repeat_interleave(next_n, dim=0)


def logits_call(fp4, q, cache, weights, lens, table, n):
    """The call run_paged_indexer makes with rows_per_request = n."""
    fn = deep_gemm.fp8_fp4_paged_mqa_logits if fp4 else deep_gemm.fp8_paged_mqa_logits
    q, glens, gtable = group_verify_rows(q, lens.unsqueeze(-1), table, n)
    schedule = deep_gemm.get_paged_mqa_logits_metadata(
        lens.view(-1, n), BLOCK_KV, deep_gemm.get_num_sms()
    )
    max_len = table.shape[1] * BLOCK_KV
    return lambda: fn(q, cache, weights, glens, gtable, schedule, max_len, False)


def cold_us(call, flush, iters=20):
    times = []
    for _ in range(iters + 3):
        flush.zero_()
        start, end = torch.cuda.Event(True), torch.cuda.Event(True)
        start.record()
        call()
        end.record()
        times.append((start, end))
    torch.cuda.synchronize()
    return sorted(s.elapsed_time(e) for s, e in times[3:])[iters // 2] * 1e3


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--fp4", action="store_true")
    ap.add_argument("--next-n", type=int, nargs="+", default=[4])
    ap.add_argument("--requests", type=int, nargs="+", default=[16, 32, 128])
    ap.add_argument("--context", type=int, nargs="+", default=[8192, 65536, 131072])
    args = ap.parse_args()
    flush = torch.empty(512 << 20, dtype=torch.uint8, device="cuda")
    print(f"{torch.cuda.get_device_name()}, DeepGEMM {deep_gemm.__version__}")
    print("| cache | next_n | requests | context | per row (us) | grouped (us) | ratio |")
    print("|---|---:|---:|---:|---:|---:|---:|")
    for n in args.next_n:
        for requests in args.requests:
            for context in args.context:
                inputs = verify_inputs(args.fp4, requests, n, context)
                per_row = logits_call(args.fp4, *inputs, 1)
                grouped = logits_call(args.fp4, *inputs, n)
                lens = inputs[3]
                a, b = per_row(), grouped()
                valid = torch.arange(a.shape[1], device="cuda")[None] < lens[:, None]
                assert torch.isfinite(a[valid]).all()
                torch.testing.assert_close(b[valid], a[valid], atol=0, rtol=0)
                t1, tn = cold_us(per_row, flush), cold_us(grouped, flush)
                print(
                    f"| {'fp4' if args.fp4 else 'fp8'} | {n} | {requests} | {context} "
                    f"| {t1:.1f} | {tn:.1f} | {tn / t1:.2f} |",
                    flush=True,
                )
                del inputs, a, b
                torch.cuda.empty_cache()


if __name__ == "__main__":
    main()
```
