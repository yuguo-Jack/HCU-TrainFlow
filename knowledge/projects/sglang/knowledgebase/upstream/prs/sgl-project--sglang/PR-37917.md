# [diffusion] Plan component residency from calibrated warmup records (2/4)

[Upstream PR](https://github.com/sgl-project/sglang/pull/37917) · state: open · merged: False

## Original PR description

Second of four stacked PRs split out of #35335. Base: the measurement layer. This layer is a **library of pure functions**: it plans, but nothing calls it yet.

## What it adds

- **Candidate enumeration.** `collect_residency_targets` lists every complete placement a component could take (resident, component offload, layerwise with N resident layers and M pinned layers) with its signed cost on each named resource: per-phase device headroom, transition-time headroom, host pin budget, host repack space.
- **Joint solve.** `plan_auto_residency` picks one complete placement per component across all ranks' reports: consensus candidates, binding phase constraints, a VRAM reserve, latency-equivalence tie-breaks, backed by `placement_budget.optimize_placement`.
- **Sizing helpers** for modules and layerwise managers (including `_EstimatedLayerwiseManager` for components that were never configured layerwise), the H2D-savings ranking the residency hint reuses, and the plan summary formatters.
- `host_memory_budget`: `HostPinBudget.release` / `for_local_worker`, the pin reserve, storage-deduplicated tensor sizing. `layerwise_offload`: the layer byte estimation helpers the planner sizes unconfigured managers with.

## Tests

`test_placement_budget` (the optimizer), `test_host_memory_budget`, and the solver tests in `test_auto_residency` (candidate frontiers, phase constraints, pins, consensus, promotions on GB10- and H100-shaped reports). All pure, no GPU.

## Stack

1. #37916 — measurement and record types
2. #37917 — planner as a pure library
3. #37918 — apply / validate / rollback wiring
4. #35335 — per-pipeline containment fixes and CI baselines

Every layer's tree is a prefix of #35335's; the union is byte-identical to the original branch merged with main.
