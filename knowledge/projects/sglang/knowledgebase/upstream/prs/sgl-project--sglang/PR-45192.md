# [Fix] diffusion: Validate config file root types

[Upstream PR](https://github.com/sgl-project/sglang/pull/45192) · state: open · merged: False

## Original PR description

## Motivation

`ServerArgs.load_config_file()` returned YAML and JSON roots without validating that they were mappings. Empty or null documents therefore returned `None`, while list and scalar roots failed later in CLI merging with errors such as `TypeError: 'bool' object is not iterable`.

Fixes #45182.

## Modifications

- Normalize YAML/JSON null roots (including empty and comment-only YAML) to an empty config.
- Reject list and scalar roots with a clear `ValueError` that identifies the received type and config path.
- Preserve valid mappings, CLI-over-config precedence, and existing parser/file-format exceptions.
- Add focused YAML, JSON, and real serve CLI regression coverage.

This contribution was prepared with AI assistance. The behavior and tests described below were executed in an isolated CPU environment.
