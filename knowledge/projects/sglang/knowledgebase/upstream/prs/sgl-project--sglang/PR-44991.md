## Motivation

Adding `enable_megamoe_for_layernorm_sp` inside the positional field order changes existing `ServerArgs` calls: zero-based argument 95, previously `disable_attn_tp_gather`, instead sets the new flag.

## Modifications

Restore the order of the remaining 536 legacy inputs, accounting for the intentional removal of `speculative_skip_dp_mlp_sync`. Freeze the 21 older fields previously appended by the collector; the final surviving legacy field is now at index 535.

Append newer built-in fields at indices 536–539: `enable_paged_experts`, `paged_experts_num_resident`, `enable_nvidia_megakernel`, then `enable_megamoe_for_layernorm_sp`. Keyword/CLI inputs and the new flag's `False` default are preserved. Unlisted extension fields remain supported.

Strengthen regression coverage with distinct neighboring boolean values, pinned field-name/index assertions, and a completeness check requiring every built-in input to have an explicit positional slot.
