## Motivation

Depends on #44480. The upstream base branch points to its exact rebased head `8851b72606ff11a288d70ba2fcd8ff628f90b753`; this PR still changes only the two positional-compatibility files.

Adding `enable_megamoe_for_layernorm_sp` inside the frozen field order reinterprets
existing positional `ServerArgs` calls. For example, argument 95 previously set
`disable_attn_tp_gather` and now enables the new option.

## Modifications

Restore all remaining 536 legacy input positions by removing the new option from the
frozen prefix and recording the 21 older fields that the collector had already
appended. The new option then appends after them. Its keyword/CLI inputs and
`False` default are unchanged.

Add constructor-binding and keyword/CLI regression tests to the existing
server-argument unit tests.
