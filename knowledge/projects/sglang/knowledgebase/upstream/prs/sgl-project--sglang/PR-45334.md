# [CI] radix-cache: Build unified radix cache test states through production paths

[Upstream PR](https://github.com/sgl-project/sglang/pull/45334) · state: closed · merged: True

## Original PR description

- Reach the states that white-box tests set up by hand through the production paths instead: real host backup, the per-node eviction step for SWA and Mamba tombstones, and the scheduler's `init_load_back` for restores. This replaces forced lock counts, raw tombstones, and hand-built transfers in the temp-lock, SWA commit load-back, SWA backup window, and auxiliary load tests.
- Use real requests and a real buffer pipeline in the buffer admission, anchor-lock outcome policy, and EAGLE buffer storage tests.
- Drive the SWA branching tests through `checkpoint`. The forward-overshoot test now asserts that the SWA slots beyond the window are freed at checkpoint. The finalize test becomes `test_hicache_swa_host_hit_counts_tombstones_inside_the_window`: a tombstone inside the window cuts the device prefix, and the tail from it on counts as a host hit.
- Check the cache-mode vs buffer-mode SWA backup window against real behavior in the storage tests.
- Drop tests that restate the implementation, duplicate another test, or cannot fail: cascade-evict on a forced Mamba lock, action-apply order, free-values order, the Mamba host-value predicate, the SWA backup collector identity, and tombstone cleanup under a forced parent lock.
- Fold five tests into the neighbours that assert the same path, keeping their unique assertions: evict-all into the tombstone cascade test, multiple-leaf eviction into eviction accounting, evict-to-host into host-leaf eviction, fresh Mamba slot publication into the Mamba state copy test, and the host-pool release into the dropped TP SWA prefetch test.
- Trim comments across the kit and the test files: history notes, PR and incident references, banners, docstrings that restate the test name or the next line, and inspector docstrings that duplicate the interface.
- No production code change; every remaining test case keeps its outcome.
