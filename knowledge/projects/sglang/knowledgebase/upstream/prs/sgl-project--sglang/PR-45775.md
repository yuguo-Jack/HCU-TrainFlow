# [Fix] diffusion: Restore the kernel registry import after #41894

[Upstream PR](https://github.com/sgl-project/sglang/pull/45775) · state: closed · merged: True

## Original PR description

- `sglang.kernels.ops.diffusion` fails to import on main: the `diffusion.flux3_video_qknorm_rope` entry added in #41894 carries a fifth field (a description), while #44690 changed `_SPECS` to four fields, so the registration loop raises `ValueError: too many values to unpack (expected 4)` and servers fail at startup.
- Drop the description from that entry.
- `rope/flux3_video_qknorm_rope_triton.py` imports `cuda_rsqrtf` and `round_bf16_to_fp32` from `sglang.kernels.ops.diffusion.common.numerics`, which no longer exists; import them from `sglang.kernels.numerics`, as the other bit-exact kernels do.
- `test/registered/unit/utils/test_diffusion_torch_fallback.py` fails at collection on main and passes with this change.

cc @niehen6174 @mickqian
