# [NPU] Add GLM-5.2-w8a8 2p2d PD separation GPQA accuracy test

[Upstream PR](https://github.com/sgl-project/sglang/pull/40550) · state: closed · merged: False

## Original PR description

## Motivation

Add an NPU accuracy test case for the GLM-5.2-w8a8 model with prefill-decode (PD) separation on Ascend.

## Modifications

- Add `test/registered/npu/accuracy/glm5_2/test_npu_glm_5_2_w8a8_2p2d_32p_gpqa.py`

  A nightly-only, disabled-by-default accuracy test that launches a 2p2d PD-separation cluster (2 prefill nodes + 2 decode nodes, 32 NPUs total) and evaluates GPQA Diamond accuracy. The deployment enables chunked prefill (CPP) and L2 hierarchical HiCache with the memfabric host-memory backend.

## Accuracy Tests

- Test is registered with `nightly=True` and `disabled="accuracy testcase"`, so it is collected but not run by default CI.
