## Motivation

Qwen-Image 2.1 FP8 inference repeats activation quantization for sibling projections and materializes intermediate BF16 tensors before quantization.

This PR reduces that overhead through shared-input quantization and two fused Triton kernels. Together, these optimizations reduced end-to-end latency by 3.96% on the tested RTX 4090 D workload.

## Modifications
- Share dynamic FP8 input quantization across Q/K/V and gate/up projections while retaining the original separate GEMMs.
- Fuse SiLU + multiplication + dynamic FP8 quantization before the MLP down projection.
- Fuse LayerNorm + modulation + dynamic FP8 quantization before image QKV and gate/up projections.
- Preserve intermediate BF16 rounding and use direct FP32-to-E4M3 conversion to avoid double rounding on SM89.
- Verify the norm and SiLU fusion paths against the existing implementation on first use, falling back on mismatch.
- Extract a shared ATen-compatible Welford reduction for the existing modulation kernel and the new norm/FP8 kernel.
- Share FP8 projection eligibility checks and use explicit forward branches instead of temporary keyword-argument dictionaries.
- Add numerical tests, runtime fallback coverage, and manual microbenchmarks.

The new kernels live under sglang.kernels.ops.activation and sglang.kernels.ops.layernorm.

Runtime dispatch is restricted to supported SM89, TP1, eager dynamic FP8 configurations. The two producer fusions initially target the measured [1, 4096, 4096] image-token shape used for 1024×1024 generation. Unsupported configurations retain the existing path.


## Accuracy Tests

Tested Qwen-Image-2.1-Turbo on one RTX 4090 D with 1024×1024 generation, eight steps, seed 42, and a fixed text prompt.

This demonstrates bit-exact output on the tested workload. 

## Speed Tests and Profiling

Configuration: RTX 4090 D, one GPU, Qwen-Image-2.1-Turbo, 1024×1024, eight steps, seed 42, TP1 eager execution, FP8 transformer and text encoder, conditioning cache disabled.

### Kernel performance

| Optimization | Before | After | Latency reduction | Speedup |
|---|---:|---:|---:|---:|
| Shared-input FP8 quantization | Separate quantization per projection | One quantization per group | Not measured separately | — |
| SiLU + mul + FP8 quantization | 0.569 ms | 0.273 ms | 52.0% | 2.08× |
| LayerNorm + modulation + FP8 quantization | 0.0832 ms | 0.0440 ms | 47.1% | 1.89× |

### Incremental end-to-end performance

Each row measures the benefit of adding that optimization to the preceding implementation.

| Optimization added | Before | After | Latency reduction |
|---|---:|---:|---:|
| Shared-input FP8 quantization | ~2.734 s | ~2.690 s | ~1.6% |
| SiLU + mul + FP8 quantization | 2.686 s | 2.618 s | 2.54% |
| LayerNorm + modulation + FP8 quantization | 2.866 s | 2.841 s | 0.85% |

### Combined end-to-end performance

Both paths use the same configuration, including unchanged upstream text_encoder=layerwise-offload. The baseline disables all three additions while retaining existing upstream optimizations.

| Metric | All three disabled | All three enabled | Latency reduction | Speedup |
|---|---:|---:|---:|---:|
| End-to-end | 2.957 s | 2.840 s | 3.96% | 1.041× |
| Denoising | 2.472 s | 2.354 s | 4.76% | 1.050× |

Measured using ABBA ordering across four fresh processes, each with one warmup followed by five hot requests. Results are medians over ten measured requests per path.

End-to-end measures the synchronized stage span from input validation through decoding, excluding model loading, warmup, queueing, output serialization, and network overhead.

Peak allocated memory remained 10.840 GiB. Peak reserved memory decreased from 14.178 GiB to 14.139 GiB, a reduction of 40 MiB.
