# [PD] Add Mori Fabric backend for rack level gfx1250 serving

[Upstream PR](https://github.com/sgl-project/sglang/pull/44283) · state: open · merged: False

## Original PR description

Co-developed with @maning00 
## Summary
Add a Mori Fabric backend for gfx1250  rack level PD disaggregation, alongside the existing RDMA backend. Use long-lived Fabric staging slots to isolate model compute memory from Fabric transfers.
## Status
Basic functionality is ready for AgentX multi-turn workloads. have completed in Long-running validation. 
- Fix a pre-existing framework/kernel bug that silently corrupts memory and causes out-of-bounds accesses independently of the PD staging path and verify the non-staging path.
- Optimize staging-buffer handling and reduce its memory overhead.
- Refactor the staging implementation and share common buffer-management logic 
- Reduce Mori-specific branching and share common logic across transfer backends.
