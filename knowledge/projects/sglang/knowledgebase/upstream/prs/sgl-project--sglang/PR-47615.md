# [Doc] [AMD] cookbook: Add GLM-5.2 MI355X AgentX recipe

[Upstream PR](https://github.com/sgl-project/sglang/pull/47615) · state: closed · merged: True

## Original PR description

## Motivation

Publish the GLM-5.2 MI355X configurations measured in [SemiAnalysisAI/InferenceX#4064](https://github.com/SemiAnalysisAI/InferenceX/pull/4064), the same way the NVIDIA lanes are mirrored in the Agentic Long-Context Deployment section (e.g. #45749) and the GLM-5.3 MI355X section was added in #46825. The Deploy panel's High-Throughput MXFP4 cell (#47331) covers only the DCP4 arm; this section covers all three arms.

## Modifications

Add "MI355X deployment measured with SemiAnalysis InferenceX" under the GLM-5.2 Agentic Long-Context Deployment section, with one launch command per arm on `lmsysorg/sglang-rocm:v0.5.22-rocm720-mi35x-20261028`:

- TP8·EP1, concurrency 1–4
- TP4·EP4 with HiCache (`--hicache-size 180`, write-through), concurrency 4–16
- TP4·EP4 with DCP4, concurrency 16–48. It runs without HiCache because SGLang rejects HiCache with `--dcp-size > 1` and EAGLE (`resolve_hicache_dcp_compatibility` in `arg_groups/hicache_hook.py`).

Commands follow the InferenceX recipe (`glm5.2/sglang/mi355x-fp4-mtp/agentic.yaml` at `faabb0d1`), without InferenceX-only settings (`--enable-metrics`, `--served-model-name`, `PYTHONNOUSERSITE`). `--max-running-requests` and `--cuda-graph-max-bs-decode` follow its per-concurrency rule (2× concurrency, graph capped at 64). Deploy panel cells are unchanged.
