# [Fix] detokenizer: Use chunk-relative read offsets after state eviction

[Upstream PR](https://github.com/sgl-project/sglang/pull/44722) · state: open · merged: False

## Original PR description

## Motivation

After detokenizer state eviction, the next incremental chunk rebuilds the state. Its read offset is still relative to the cumulative surrogate/decode buffer, which can skip fresh tokens, including short final chunks.

Related to #41236.

## Modifications

- Send a chunk-relative read offset, clamped to zero, before advancing `send_decode_id_offset`.
- Add offline CPU regression coverage using a real byte-level BPE decoder for prompt lengths, eviction points, batched/per-row decoding, split UTF-8, and stop trimming/retention.
