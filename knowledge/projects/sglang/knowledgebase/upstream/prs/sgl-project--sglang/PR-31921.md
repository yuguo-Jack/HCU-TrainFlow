# Add optional realtime TAEHV decode

[Upstream PR](https://github.com/sgl-project/sglang/pull/31921) · state: closed · merged: False

## Original PR description

## Summary

Add an opt-in realtime VAE decode path backed by [TAEHV](https://github.com/madebyollin/taehv) for Wan/LingBot-style realtime video sessions.

The default realtime VAE path is unchanged. TAEHV is only used when `--vae-config.taehv-checkpoint-path` is set, and the `taehv` package remains an optional external dependency.

## Changes

- Add `VAEConfig.taehv_checkpoint_path` and `--vae-config.taehv-checkpoint-path`.
- Keep a per-session `StreamingTAEHV` decoder and output queue in realtime VAE decode state.
- Cache the stateless TAEHV model on the VAE decode stage and create only the streaming wrapper per session.
- Convert realtime latents between SGLang/Wan `NCTHW` and TAEHV `NTCHW` layouts.
- Preserve TAEHV causal state across realtime chunks and reset it on the first chunk/session disposal.
- Slice the TAEHV output queue by frame count and preserve leftover frames across chunks.
- Add a unit test with a stubbed `taehv` module.

![critical](https://www.gstatic.com/codereviewagent/critical.svg)

There is a unit mismatch bug when managing the output queue. `target_frames` represents the number of individual frames, whereas `len(decode_state.taehv_output_queue)` represents the number of multi-frame chunks (each containing `t_upscale` frames). Comparing them directly leads to incorrect slicing and discards valid frames between chunks, causing visual glitches/gaps in the generated video. Instead, we should concatenate all available frames first, slice the exact number of frames needed, and keep any remaining frames in the queue.

```python
        decode_state.taehv_output_queue.extend(produced)
        if not decode_state.taehv_output_queue:
            raise RuntimeError("TAEHV produced no frames for realtime chunk")

        all_frames = torch.cat(decode_state.taehv_output_queue, dim=1)
        take = min(target_frames, all_frames.shape[1])
        if take == 0:
            raise RuntimeError("TAEHV produced no frames for realtime chunk")

        frames_ntchw = all_frames[:, :take].contiguous()
        remaining = all_frames[:, take:]
        decode_state.taehv_output_queue = [remaining] if remaining.shape[1] > 0 else []

        return frames_ntchw.permute(0, 2, 1, 3, 4).contiguous()
```

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Loading the TAEHV model from disk and moving it to the GPU on every new session creation introduces significant latency and memory overhead. Since the `TAEHV` model itself is stateless, we should cache it on the stage instance (`self`) and reuse it across sessions, only instantiating a new `StreamingTAEHV` wrapper per session.

```python
    def _get_or_create_taehv_streaming_decoder(
        self,
        decode_state: RealtimeVAEDecodeState,
        server_args: ServerArgs,
    ):
        if decode_state.taehv_streaming_decoder is not None:
            return decode_state.taehv_streaming_decoder

        if not hasattr(self, "_tiny_vae") or self._tiny_vae is None:
            checkpoint_path = self._taehv_checkpoint_path()
            if checkpoint_path is None:
                raise RuntimeError("TAEHV checkpoint path is not configured")

            try:
                from taehv import TAEHV
            except ImportError as exc:
                raise RuntimeError(
                    "TAEHV realtime decode requires the `taehv` package. "
                    "Install it and set SGLANG_REALTIME_TAEHV_CHECKPOINT_PATH "
                    "to a TAEHV checkpoint."
                ) from exc

            vae_dtype = PRECISION_TO_TYPE[server_args.pipeline_config.vae_precision]
            self._tiny_vae = TAEHV(checkpoint_path=checkpoint_path).to(
                get_local_torch_device(), vae_dtype
            )
            self._tiny_vae.eval()

        try:
            from taehv import StreamingTAEHV
        except ImportError as exc:
            raise RuntimeError(
                "TAEHV realtime decode requires the `taehv` package. "
                "Install it and set SGLANG_REALTIME_TAEHV_CHECKPOINT_PATH "
                "to a TAEHV checkpoint."
            ) from exc

        decoder = StreamingTAEHV(self._tiny_vae)
        decode_state.taehv_streaming_decoder = decoder
        return decoder
```

Accessing `os.environ` on every single forward pass of a realtime inference loop introduces unnecessary overhead. We should change `_taehv_checkpoint_path` to an instance method and cache the resolved path on the stage instance.

```suggestion
    def _taehv_checkpoint_path(self) -> str | None:
        if not hasattr(self, "_cached_taehv_checkpoint_path"):
            value = os.environ.get(self.TAEHV_CHECKPOINT_ENV)
            self._cached_taehv_checkpoint_path = value.strip() if value and value.strip() else None
        return self._cached_taehv_checkpoint_path
```
