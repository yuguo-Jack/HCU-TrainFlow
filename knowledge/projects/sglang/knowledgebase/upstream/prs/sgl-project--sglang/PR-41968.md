# [Feat] [NVIDIA] mamba2: Add compact speculative-state replay

[Upstream PR](https://github.com/sgl-project/sglang/pull/41968) · state: open · merged: False

## Original PR description

## Summary

Reduce Mamba2 speculative-decoding memory by replacing full candidate-state
snapshots with compact input records. FlashInfer reconstructs only the accepted
live/tracking states, leaving more memory for reusable checkpoints and active requests.
Enable with `--enable-linear-replayssm-spec`.

## Implementation

- Native FlashInfer `checkpointing_ssu` verifies candidates without modifying
  live state; `replayssm_materialize` eagerly commits accepted endpoints.
- Preserve convolution rollback, complete persistent checkpoints, and exact
  copies when tracking and live endpoints coincide.
- Include compact records and supporting buffers in pool sizing.

Code: [verify/commit adapter](https://github.com/NVShreyas/sglang/blob/8c4c8ce5a15e62817fd8838c08f93100ec078e42/python/sglang/kernels/ops/mamba/mamba2_spec_replay.py),
[configuration checks](https://github.com/NVShreyas/sglang/blob/8c4c8ce5a15e62817fd8838c08f93100ec078e42/python/sglang/srt/configs/mamba2_spec_replay.py).

Supported initially: SM100, main's pinned FlashInfer 0.7.1, BF16 activations/FP16 state,
head/state dimensions 64/128, EAGLE/NEXTN top-k 1 with four verification positions;
stochastic rounding supported. Unified/page-major pools, adaptive/ragged
verification, int8 checkpoints and combining with `--enable-linear-replayssm`
and PD disaggregation are unsupported. Deferred replay is not enabled.

## AgentX results

Public model: [NVIDIA Nemotron 3 Super 120B A12B NVFP4](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-NVFP4),
revision `ff433f5493e25d631c9f12b5d55c674229923d02`; one B200, TP1.
Both variants use Triton recurrent prefill, FP8 KV, FP16 recurrent state,
EAGLE three steps/four positions and **synthetic AL3.2527** (`match-expected`,
fixed-token mode). No offloading or unified pools.

### Public trace and replay settings

  [`semianalysisai/cc-traces-weka-062126-256k`](https://huggingface.co/datasets/semianalysisai/cc-traces-weka-062126-256k),

- Preserve recorded inter-turn delays, trajectory-start ratios0–1 and global
  idle-gap cap10s. AgentX trajectory warmup seeds measurement; flush cache before
  each point and use `first_turn_prefix` cache-busting. No extra session cap.

  `461037fbf` (`0.7.2+g461037fbf`) for both sides. “Stock” means the default
  snapshot path on that build, not pristine/latest main. These historical
  performance runs predate the current rebase and shared-flag cleanup; they are
  not a fresh throughput measurement of the current PR head.
- Shared serving settings: context1,048,576; prefill/chunk32768; page64;
  `extra_buffer`, tracking128; stochastic rounding/Philox5; memory fraction0.85;
  max-running256; graph cap256; `trtllm_mha`. AIPerf commit
  `754356e9a39acc6cc6afb242d123bb57c3fb6f75`.

| Session trees | Stock output tok/s | Replay output tok/s | Gain |
| ---: | ---: | ---: | ---: |
| 16 | 340.09 | 358.63 | +5.4% |
| 32 | 859.83 | 906.82 | +5.5% |
| 64 | 840.75 | 1,216.77 | **+44.7%** |

At C64, jointly usable prefix reuse rises **81.98% → 89.08%**, while the share
of raw Full-KV hits trimmed for recurrent compatibility falls **12.80% → 5.71%**.
Cache counters cover profiling plus drain, with <1s scrape-boundary uncertainty.
These are replay-only gains; SSD's additional benefit is reported in #42650.

All six points passed AgentX's `submission_valid` check. C16/C32 had no client
errors; C64 had one per variant (stock: connection reset; replay: empty-content
response), with 940/1249 successful requests. Both C64 runs reached the40s drain
timeout; error/cancellation attribution remains pending. The validity flag is
not a zero-error or accuracy certificate. Client ITL was zero, so no TPOT claim
is made here. Single runs, no confidence intervals; faster variants traverse
more turns, and configured synthetic AL does not guarantee identical realized AL.

# Shared server arguments, also used for the historical AgentX comparison below.

  --speculative-draft-model-path "$MODEL_PATH" --trust-remote-code --tp 1

  --page-size 64 --mamba-backend flashinfer --mamba-ssm-dtype float16
  --enable-mamba-cache-stochastic-rounding --mamba-cache-philox-rounds 5
  --mamba-radix-cache-strategy extra_buffer --mamba-track-interval 128
  --kv-cache-dtype fp8_e4m3 --mem-fraction-static 0.85 --max-running-requests 256
  --cuda-graph-max-bs-decode 256 --speculative-algorithm EAGLE
  --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4
