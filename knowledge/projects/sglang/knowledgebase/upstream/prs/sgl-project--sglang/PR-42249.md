# [Fix] diffusion: Preserve lazy quantization exports and per-backend lookup

[Upstream PR](https://github.com/sgl-project/sglang/pull/42249) · state: open · merged: False

## Original PR description

## Motivation

Upstream #42494 now defers diffusion quantization imports until registry lookup, fixing the cold `LinearBase` import cycle originally reported here. Its lookup still imports every backend and no longer exposes the configuration classes directly from the package. This PR resolves only the requested backend while retaining the previous package-level class exports, registry aliases, and custom registration behavior.

## Changes

Keep `QuantizationConfig` available during package initialization. Resolve and cache implementation classes through module `__getattr__`, and look up built-in configurations by their export name. Preserve `kitchen_int8` → `convrot_int8`, distinct ModelOpt configuration classes, and user-defined configurations.

Fresh-process regression tests cover `linear`, `hf_diffusers_utils`, the standalone AR module, and ConvRot config imports. Registry tests cover all built-ins, package exports, repeated lookups, the deprecated alias, and custom registration failures.
