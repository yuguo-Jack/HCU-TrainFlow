# [MemCache] Report no prefix sharing from a disabled `RadixCache`

[Upstream PR](https://github.com/sgl-project/sglang/pull/43197) · state: closed · merged: True

## Original PR description

- `RadixCache.supports_prefix_sharing()` returns `not self.disable`, matching `UnifiedRadixCache`; a disabled classic tree (and `PureSWARadixCache` / `FlexKVRadixCache`) no longer claims sharing
- On main this is reached only by a pure-SWA multimodal model on the transformers backend with `--disable-radix-cache`; there the SWA window is now also evicted at extend time, as `PureSWAChunkCache` does
- Set `disable` on the `test_swa_eviction_interval.py` fixture, which bypasses `RadixCache.__init__`
