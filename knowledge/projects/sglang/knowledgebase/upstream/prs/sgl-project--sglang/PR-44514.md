## Motivation

#43927 enables FlashInfer v2's default-tactic (`-1`) comparison on cache misses. Existing v1 winners are accepted before that comparison, and their cache paths did not change. Version the cache identity so fresh startup retunes these configurations with the expanded candidate set.

This continues v2 candidate-selection adoption with existing v1 persistence.

Measurement policy remains unspecified. Cache-disabled behavior, skip controls, streams, and distributed synchronization are unchanged. No managed-store migration or MegaMoE integration changes.
