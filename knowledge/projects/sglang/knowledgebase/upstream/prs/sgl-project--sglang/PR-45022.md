# [Fix] model-gateway: Return rate-limit token when queued client disconnects

[Upstream PR](https://github.com/sgl-project/sglang/pull/45022) · state: open · merged: False

## Original PR description

## Motivation

Fixes #45021.

When a queued request's client disconnects before `QueueProcessor` hands it a token, `permit_tx.send` fails because `permit_rx` was dropped with the handler. The result was ignored, so the token was taken from the bucket and never returned.

## Modifications

- In both `QueueProcessor::run` paths (immediate and after waiting), return the token to the bucket when `permit_tx.send(Ok(()))` fails.
- Add two regression tests that drive the real `QueueProcessor` with a dropped receiver. Both fail on the old code and pass with this change.
