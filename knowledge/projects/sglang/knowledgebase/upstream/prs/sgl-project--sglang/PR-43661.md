# [Doc] diffusion: document --kv-gather-degree instead of the nonexistent --sp-attention-mode

[Upstream PR](https://github.com/sgl-project/sglang/pull/43661) · state: open · merged: False

## Original PR description

## Motivation

`docs/docs/sglang-diffusion/ring_sp_performance.mdx` tells users to pass `--sp-attention-mode kv_gather`, but the diffusion CLI has no such flag, so every K/V-gather example on the page fails at argument parsing. K/V gather is selected with `--kv-gather-degree` (see `python/sglang/multimodal_gen/runtime/server_args/server_args.py` and `docs/docs/sglang-diffusion/api/cli.mdx`). The page also predates the `sp_degree=2` auto-selection of K/V gather, so its "default is Ulysses" statements were wrong at SP2.

## Modifications

- Replace `--sp-attention-mode` with `--kv-gather-degree` in the controls list, the comparison table, and all three example commands (`--kv-gather-degree` equals `--sp-degree`, as `_validate_parallelism` requires).
- State the actual defaults: `sp_degree=2` picks K/V gather, higher SP degrees pick Ulysses; pass `--ulysses-degree` to keep Ulysses at SP2.
- State the real constraint from `_adjust_parallelism`: K/V gather does not compose with `--ulysses-degree` or `--ring-degree` (previously described as "`ring_degree=1`").
