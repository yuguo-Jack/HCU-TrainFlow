# [NPU]glm5.2 optim origin dual stream

[Upstream PR](https://github.com/sgl-project/sglang/pull/38918) · state: open · merged: False

## Original PR description

## Motivation

The dual-stream approach for shared experts and routed experts is coarse-grained, which leads to core contention issues in GMM.

## Modifications

To address this issue, we introduce a fine-grained dual-stream scheme on GLM-5.2. Specifically, the shared expert's up-projection and down-projection matrix multiplications are scheduled to execute before and after the routed expert's GMM, respectively, thereby avoiding core contention.
