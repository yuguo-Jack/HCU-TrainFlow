# [CI] test-utils: Abort the test run when its server dies inside a `CustomTestCase` method

[Upstream PR](https://github.com/sgl-project/sglang/pull/45053) · state: closed · merged: True

## Original PR description

- `CustomTestCase._callTestMethod` watches `self.process` with `start_subprocess_fail_fast_watcher` (the watcher the PD fixture already uses) while the method and its retry run; when the server exits non-zero, the test runner exits at once with the server's exit status
- The watcher stops before `tearDown`, `tearDownClass`, and class cleanups, so their intentional kills do not trip it

No behavior change while the server stays up. When it crashes mid-method, the test file now ends at the crash and its remaining methods do not run; before, sgl-eval clients backed off on every request (about 5 minutes in a 200-example run) and CI then retried the whole method against the dead server.
