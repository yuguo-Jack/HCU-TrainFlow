# [Doc] GLM-5.3 cookbook: Pass --chat-template in the GLM-5.3 and GLM-5.3-Flash cookbook recipes

[Upstream PR](https://github.com/sgl-project/sglang/pull/45303) · state: closed · merged: False

## Original PR description

## Motivation

#45154 adds a built-in Python chat template for GLM-5.3 and GLM-5.3-Flash: prompts are identical token for token to the checkpoints' `chat_template.jinja`, rendering is 4.7-17x faster, and request preprocessing of long agent conversations is up to 2.3x faster. This PR makes the cookbook recipes select it explicitly, so every generated launch command uses it.

> [!IMPORTANT]
> Depends on #45154. This stays a draft until a release that includes it is published as `lmsysorg/sglang:latest`, because older builds reject `--chat-template glm-5.3` / `glm-5.3-flash` at startup.

## Modifications

- `docs/src/snippets/configs/zai-org/glm-5.3.jsx`: add `--chat-template glm-5.3` to the 27 NVIDIA cells (H200, B200, GB300, B300). The 15 AMD cells (MI355X, MI325X, MI300X) are unchanged because they pin `lmsysorg/sglang-rocm:v0.5.20-*`, which predates the flag; add it there when that image is bumped.
- `docs/src/snippets/configs/zai-org/glm-5.3-flash.jsx`: add `--chat-template glm-5.3-flash` to all 32 cells (the MI355X cells install SGLang from pip, so they get the flag with the same release as `:latest`).
- `GLM-5.3-Flash.mdx`: add the flag to the prose launch examples that serve chat requests (the encoder-disaggregation language server, prefill CP, and the PD prefill and decode servers). The encoder-only server does not render chat prompts, so it is unchanged.
- Both pages: a configuration tip on what the flag does, how `--reasoning-parser auto` / `--tool-call-parser auto` resolve with it, and how to serve a customized template instead (`--chat-template /path/to/chat_template.jinja`). The tip also scopes the flag to SGLang's default Python HTTP frontend: the Rust frontend (`SGLANG_RUST_SERVER=1`) renders GLM-5.3 from the checkpoint's template on its own and reads `--chat-template` as a file path, so its users leave the flag out.

The flag sits right before `--host`, so Playground additions such as the parsers, which are inserted before `--host`, follow it.

## Accuracy Tests

No model-output change: the flag selects a renderer whose prompt token ids equal the Jinja template's (differential fuzzing, serving-level, and online A/B results are in #45154).

## Speed Tests and Profiling

See #45154.
