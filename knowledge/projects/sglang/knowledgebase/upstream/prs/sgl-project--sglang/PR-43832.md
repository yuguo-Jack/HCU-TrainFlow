# [Fix] DSA: skip-topk pipeline handoff for owed outputs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43832) · state: closed · merged: True

## Original PR description

Fixes #43580

## Motivation

`DeepseekV2Model.forward` exports the stage output through `residual_batch.to_pp()` before checking whether a non-idle batch has rows that require DSA top-k indices. A residual-stream output may still be represented locally by an opaque `OwedOutput`, so reading `hidden_states.shape` after export raises `AttributeError` during the PP handoff.

## Modifications

- Read the row count from the exported `proxy_tensors["hidden_states"]` tensor.
- Use the same exported tensor when allocating empty top-k indices for the zero-row case, preserving its device and the existing `torch.int32` shape contract.
- Add a CPU regression that runs the real `DeepseekV2Model.forward` PP branch with an `OwedOutput`, exercises `residual_batch.to_pp()` / `ResidualStream.export()` for declared-sum and deferred-finalize outputs, and covers nonempty/empty rows.
