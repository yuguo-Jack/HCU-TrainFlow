# [NPU][CI] Increase e2e multi-node test timeout to 210 minutes

[Upstream PR](https://github.com/sgl-project/sglang/pull/39952) · state: closed · merged: True

## Original PR description

## Motivation

The `glm_5_2_w8a8_16p_gpqa` accuracy case (multi-node mix) takes ~168 minutes on Ascend NPU in passing runs, while the e2e test `LOCAL_TIMEOUT` is 10800s (180 minutes), leaving only ~12 minutes of headroom. The long chain-of-thought GPQA evaluation has run-to-run variance under speculative decoding + `temperature=1.0` sampling; a ~14-minute slowdown in one run tripped the 10800s timeout and failed the case.

## Modifications

- Bump `LOCAL_TIMEOUT` in `python/sglang/test/ascend/e2e/run_npu_e2e_test.py` from `10800` (180 minutes) to `12600` (210 minutes). This constant governs both `check_pods_ready` and `monitor_pod_logs` timeouts for the multi-node e2e tests.
