# [Perf] logprobs: Cut latency and memory with compact TP exchange

[Upstream PR](https://github.com/sgl-project/sglang/pull/44495) · state: open · merged: False

## Original PR description

## Summary

Avoid the full-vocabulary AllGather when computing prompt logprobs and Top-N. Exchange row statistics and selected candidates instead. Sampled rows keep the existing full-vocabulary path.

Combines #34402 and #34704 and preserves #40038's graph-pool borrowing.

ASIS
```text
TP-local logits -> full-vocabulary AllGather -> normalize / select
```

PR
```text
TP-local logits -> local statistics / Top-N -> compact exchange -> results
sampled rows    -> existing full-vocabulary path
```

## What changes

- Keep vocabulary logits sharded; gather only the information needed for requested scores.
- Use bounded CUDA selection/merge kernels, with existing fallbacks for unsupported cases.
- Preserve normalization, sampled-logit semantics, and graph-replay-safe output ownership.

## Results: Qwen, not a general all-model speedup

Qwen3-32B, TP4 on GB200, 8K input, Top-20, four output tokens.

**Earlier matched validation of the base implementation:**

| Logprob chunk | Gathered median | Distributed median | Latency reduction |
| --- | ---: | ---: | ---: |
| 64 | 383.3 ms | 373.3 ms | 2.6% |
| 128 | 372.9 ms | 322.2 ms | 13.6% |

The later local Top-N implementation measured **317.9 / 311.4 ms** at chunks 64 / 128 in candidate-only rechecks. These are **not fresh matched speedups**.

An earlier constrained-pool component test saved **306 MiB/GPU of additional driver-visible allocation**. This is not a current-head peak-HBM or extra-KV-capacity claim.

## Validation and limitations

- 38 local kernel cases pass; graph-budget/fallback/replay checks pass.
- 40 Qwen full-response comparisons match generated IDs and target/Top-N scores exactly.
- **GLM-5.2/5.3: no established E2E gain; 4K/8K correctness remains unqualified.** The long-context instability also reproduces on clean upstream without this PR.
- No model, attention, KV-cache, general sampler, or speculative-decoding changes.

**Still draft.** Upstream GPU CI is blocked by the draft gate; local validation is not a substitute for it.

### Performance provenance

- Matched Qwen source: `963e669e75`. Chunk 64 borrows on both paths; at chunk 128 the gathered path falls back. The subsequent base integration adds two int32 guards.
- Latest measured source: `4842902b9a`, integrated as `068b36c206`. Current head `a55b824be2` additionally fixes K=1 compilation; the measured K=20 branch is unchanged.
- Each Qwen arm: 20 timed requests, 10 no-logprob controls, verified post-warmup GC freeze. Warm-kernel steady state; cold JIT compilation is excluded. All samples retained.
- Latest chunk 64: median/mean/p90 = 317.918/318.362/324.875 ms. Chunk 128: 311.417/324.811/328.009 ms. Both chunk-128 tail samples, 396.230 and 497.741 ms, are retained. No tail-latency guarantee.
- Runtime: Torch 2.14.1+cu130, sglang-kernel 0.4.9, Triton 3.8, FlashInfer 0.7.1. Prefill chunk 8192; decode full graph bs1; prefill breakable graphs 1024/8192; radix cache off; borrowing enabled; concurrency one. Timings cover client whole-response wall time, excluding JSON parsing.

Memory source: `67c42dc289`, before the latest Top-N scratch. TP2, BF16, 2048 rows, vocabulary 202752, chunk 128, Top-N 20/5 and ragged probes. With a 192 MiB pool, gathered fallback uses 328 MiB versus 22 MiB extra driver-visible allocation for distributed borrowing. With a 512 MiB pool both borrow and both measure 22 MiB. These are synchronized component snapshots, not sampled physical peaks.

### Correctness and bounds

Local CUDA Top-N: K <= 32, 2048-column tiles, at most 2048 merge candidates, int32-safe scratch. Compact CUDA merge: TP <= 32, TP*K <= 1024, contiguous input and int32-safe offsets. FP32-packed IDs require vocabulary <= 2^24. Other cases retain fallbacks.

The existing row normalizer is unchanged. Equal-cutoff Top-N ties may return different valid IDs/order from monolithic Torch Top-N. Borrowing requires TP-uniform capacity/fallback and preserves outputs through replay; symmetric NCCL allocation disables borrowing.

Base validation included 20 CUDA compact packing/merge cases and 54 TP4/NCCL cases. The later Top-N implementation passed 23 local cases plus the unchanged TP2 replay gate. Review discovered and fixed a real K=1 compiler issue; the expanded current local suite passes all 38 cases. These are distinct test runs, not a claim that all base tests were rerun on the latest head.

GLM 1K checks pass, but all 80 long cross-path comparisons fail with repeated-run variation in both arms. A separate reproduction on unmodified upstream `92580581da`, under the same pinned runtime, repeats 4K/8K requests eight times per model. All 28 target-logprob comparisons first diverge at public index 2049; the first 2048 entries match exactly. Some no-logprob controls also change generated output. This demonstrates that the instability does not require our PR, not which component causes it. No GLM fix or speedup is claimed here.

### Reproduction

Use idle GPUs and the matching runtime/source. Historical results require their recorded commits. A focused current-head comparison:

```bash
python benchmark/kernels/bench_input_logprobs_serving.py \
  --model qwen --model-path /path/to/Qwen3-32B \
  --lengths 8192 --top-n 20 --cases baseline topn --output-tokens 4 \
  --prefill-chunk-size 8192 --logprob-chunk-size 128 --graph-pool-borrow \
  --cuda-graph-config '{"decode":{"backend":"full","bs":[1]},"prefill":{"backend":"breakable","bs":[1024,8192]}}' \
  --order 0 1 --warmups 2 --samples 20 --output /path/to/new-results
```

Repeat with chunk 64. The generic benchmark interleaves cases every round; the reported focused runs used controls every second round. Do not pool those protocols.

```bash
python -m pytest -q test/registered/unit/layers/test_local_logprob_topk.py
python -m pytest -q test/registered/unit/layers/test_compact_logprob_merge.py
python -m pytest -q test/registered/e2e/layers/test_logprob_memory_distributed.py
PYTHONPATH=python torchrun --standalone --nproc-per-node=4 test/manual/test_distributed_input_logprobs_tp.py
```
