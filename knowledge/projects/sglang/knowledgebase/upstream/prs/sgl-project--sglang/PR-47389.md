# [Feat] diffusion/pi05: Support action expert training

[Upstream PR](https://github.com/sgl-project/sglang/pull/47389) · state: open · merged: False

## Original PR description

## Motivation

Enable Pi0.5 action-expert training with external trainers such as RLinf, keeping the vision-language prefix frozen.

## Modifications

- Add differentiable forward interfaces and optional prefix hidden states.
- Use consistent operators for sampling and gradient replay.
- Add tests and documentation.

| Test | Result |
|---|---|

| PPO parity against eager execution | 12 runs × 2 updates; max gradient and weight error **0** |
| RLinf + LIBERO smoke test | 2 PPO iterations; **16 forward + 16 backward** CUDA Graph replays per iteration |

## Speed Tests and Profiling

Validated end-to-end PPO training through [RLinf/RLinf#1776](https://github.com/RLinf/RLinf/pull/1776), using SGLang for Pi0.5 actor forward/backward and rollout inference.

Benchmarked **LIBERO-Spatial on 2× RTX 4090**. One GPU handles training and inference; the other handles rendering. Actor/rollout offload, CUDA Graphs, and normalized-observation reuse are enabled.

Results are **seconds per training step**, averaged over five measured steps after ten warmup steps.

| Batch | Inference calls (s) | Full rollout (s) |
|---|---:|---:|
| 1 | 0.835 | 8.759 |
| 2 | 1.139 | 10.279 |
| 4 | 1.982 | 13.988 |

Inference calls include preprocessing, prediction, and output packing. Full rollout additionally includes environment interaction, trajectory transfer, and model offload/reload. Weight synchronization is excluded from both metrics.

SGLang completed 15 PPO updates at each batch size with finite actions, losses, and gradients. Native OpenPI, with fused `torch.compile` and the same offload settings, encountered CUDA OOM during weight synchronization at B=1/2/4.

Checkpoint: `RLinf/RLinf-Pi05-LIBERO-SFT`, BF16. Action horizon: 50; denoising steps: 3. PyTorch: `2.14.1+cu130`.
