# [NPU] [bugfix] Fix ascend sampling TypeError with min_p.

## Motivation

When using `--sampling-backend ascend` with requests that set min_p (and top_k within [1,1024]), the Ascend sampling path crashes with `TypeError: only integer tensors of a single element can be converted to an index `. 
The cause is that torch.max(probs, dim=-1) returns a tuple; when the tuple is multiplied by the min_ps tensor, Python raises TypeError .

<img width="1058" height="166" alt="image" src="https://github.com/user-attachments/assets/99bd2bc2-79e4-4c02-a6af-12d707428288" />


## Modifications

Compute `min_p_thresholds` with `max(dim=-1).values` to correctly handle the `min_p_thresholds` computation.
