# [diffusion] spectrum: bound forecaster history memory for video DiTs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43695) · state: open · merged: False

## Original PR description

ChebyshevForecaster preallocated an fp32 (history_size, numel) buffer per CFG branch and built (M + 1, numel) fp32 intermediates on every fit. For video DiTs this is tens of GiB (about 62 GiB per branch for Wan2.2-A14B at 832x480x81), so Spectrum ran out of memory at common video resolutions.

- Keep history as per-real-forward copies in the feature dtype, capped at history_size, instead of a preallocated fp32 buffer.
- Predict as a weighted sum over the history rows (weights from the same ridge solve), so no (M + 1, numel) coefficient matrix is materialized.
- For boundary MoE pipelines (Wan2.2-A14B), reset the high-noise expert's Spectrum state once the low-noise expert takes over; it does not run again in the request.
