## Original PR description

## Motivation

Agent skills and rules under `.agents/skills/` and `.claude/rules/` cite files that were moved, and guard tests that were deleted in #37436. The `sglang-runtime-context` skill still lists those deleted tests under "Guardrails (these fail CI)", which tells agents that a contract is CI-enforced when it no longer is.

## Modifications

- Moved files: `managers/template_detection.py` / `template_manager.py` -> `parser/`; `scheduler_profiler_mixin.py` -> `scheduler_components/profiler_manager.py`; `jit/utils/compile.py` -> `jit/utils/compile/`; `test_qknorm_complex_rope.py` -> `test_complex_rope.py`.
- Drop the reference to the deleted `test/registered/profiling/test_profile_v2.py`.
- `unit-test-admission.md`: use the existing `test_global_config_read_ratchet.py` as the ratchet-test example.
- `sglang-runtime-context`: mark the publish-order, readback-surface, no-copy and module-state rules as review-only (their tests no longer exist), drop the textual mutation ratchet, and remove deleted tests from the "where to read the code" list. Remaining guard references all point at existing tests.
