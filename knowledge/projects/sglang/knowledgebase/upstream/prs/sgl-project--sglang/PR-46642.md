# [Fix] sglang-mm: Accept media payloads at byte-budget boundaries

[Upstream PR](https://github.com/sgl-project/sglang/pull/46642) · state: open · merged: False

## Original PR description

-this is a follow-up to #32365. I encountered valid media payloads being rejected in `rust/sglang-mm/src/common/fetch.rs` when they exactly fit the remaining request byte budget. The reader reserved a full chunk before reading and needed another reservation just to check EOF.

-it now reserves up to the available allowance atomically and uses a bounded one-byte EOF probe. A probed byte is charged before appending, including when another reader refunds capacity. It preserves the per-source cap and adds boundary and concurrency regression tests.
