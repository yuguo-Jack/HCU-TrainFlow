# [CI] Fix EAGLE3 CUDA parity prefill chunk alignment

[Upstream PR](https://github.com/sgl-project/sglang/pull/43538) · state: closed · merged: True

## Original PR description

## Motivation

After #43444 added the startup alignment check, `TestEagle3ParityCUDA` fails in `setUpClass`: its inherited 1024-token prefill chunk is smaller than deterministic FlashInfer's default 4096-token split tile. This is inherited from main and surfaced in [PR #36345's CI job](https://github.com/sgl-project/sglang/actions/runs/38034523877/job/114164287887).

## Modifications

Set `chunked_prefill_size = 4096` on `TestEagle3ParityCUDA` so the speculative server satisfies the alignment requirement and the existing output-parity test can run. The override is scoped to the CUDA test; the shared fixture and XPU test retain their configuration.

## Accuracy Tests

All applicable pre-commit hooks passed, including Ruff lint/format, Python AST, and registered-test CI validation. `git diff --check` and a Python syntax check passed. Reviewed the reference-server launch path and class inheritance.

The existing GPU parity test was not run locally because this host has no CUDA GPU; GPU validation is pending CI.

## Speed Tests and Profiling

Not run: this change only adjusts a test's launch configuration.
