[Upstream PR](https://github.com/sgl-project/sglang/pull/43297) · state: closed · merged: True

## Original PR description

## Motivation

In `test_multi_lora_backend.py`, the base-model row of `[wizardLM, norwegian, None]` hits an exact fp16 tie, so greedy decoding can pick either token and the test flakes.

## Modifications

Run `test_ci_lora_models_multi_batch` with `rouge_l_tolerance=0.9`, which AMD already uses, instead of skipping the batch.
