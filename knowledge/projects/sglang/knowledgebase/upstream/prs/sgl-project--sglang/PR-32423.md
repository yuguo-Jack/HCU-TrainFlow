# [DSpark PD 2/3] Integrate hidden-state bootstrap into PD scheduling

[Upstream PR](https://github.com/sgl-project/sglang/pull/32423) · state: closed · merged: False

## Summary

This is the second PR in the DSpark PD hidden-state transfer stack.

Depends on: https://github.com/sgl-project/sglang/pull/32422

It integrates hidden capture and bootstrap into Prefill/Decode scheduling and PP coordination. Backend-specific RDMA and ACK handling remain outside this PR.

## Changes

### Decode

- Extend [`DecodeRequest`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/decode.py#L269-L283) with destination rows, PP slices, hidden offsets, and request completion state.

- Allocate the Decode receive window and build the PP layer layout during preallocation at [lines 1069-1319](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/decode.py#L1069-L1319).

- Send `hidden_start`, `hidden_len`, destination indices, target layers, radix policy, and PP slices through [`spec_metadata`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/decode.py#L1453-L1499).

- Release receive rows and drain completed ACKs in [`_release_pd_hidden_rows`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/decode.py#L2001-L2047).

- Validate chunk ordering, read received GPU rows, inject them into draft KV, and submit completion ACKs in [`_drain_pd_hidden_ready_chunks`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/decode.py#L2228-L2315).

- Commit a request only after both KV and hidden transfers complete at [lines 2418-2423](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/decode.py#L2418-L2423).

### Prefill and PP

- Probe metadata and hidden-row credits without side effects in [`_probe_bootstrap_ready`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/prefill.py#L445-L506).

- Validate metadata and commit capture state in [`_finalize_pd_hidden_bootstrap`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/prefill.py#L563-L610).

- Map chunk token ranges to absolute hidden offsets, select the local PP slice, allocate rows, and write captured tensors in [`_write_pd_hidden_rows_for_batch`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/prefill.py#L1210-L1369).

- Allow the PP rank owning the target layers to send streaming hidden chunks directly through [`send_dspark_owner_direct_hidden_for_batch`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/disaggregation/prefill.py#L1371-L1395).

- Make PP bootstrap admission deterministic and resource-aware in [`_pp_pd_get_bootstrapped_ids`](https://github.com/bytedance-iaas/sglang/blob/e3d8344ed6c9379ab0cf4e17180394d170cd24a8/python/sglang/srt/managers/scheduler_pp_mixin.py#L843-L870).

## Compatibility

Backends that do not advertise PD hidden streaming capability do not enter the transfer path. Existing KV, C128, DSA, and auxiliary-state transfer behavior is preserved.
