# [Speculative] Verify sampled drafts over a reduced token-map vocab

[Upstream PR](https://github.com/sgl-project/sglang/pull/45928) · state: closed · merged: False

## Original PR description

## What

Adds the reduced-vocab sampled-draft path used by R5: the draft samples over `--speculative-token-map` (49,152 tokens), then the proposal distribution is scattered into the target vocab before rejection sampling or block verification.

Stacked on #45233. Patch sha256: `d010972ddaecbb510b450e4fe99881f88c139a49a6f9a87c2cb5b5f9ee4f1982`.

## Issue

With `--speculative-token-map`, the draft proposal `q` is shaped over the reduced vocab while the verifier expects target-vocab `q`. `eagle_worker_v2.py` raises at startup on the mismatch, so sampled drafts cannot run on token-map configs.

## Fix

- `spec_utils.py`: scatter reduced-vocab `q` into the target vocab at the token-map ids; validate that ids are non-empty, in range, and unique.
- `eagle_worker_v2.py`: replace the startup rejection with map validation; carry the map through `EagleVerifyInput`; size idle-batch draft probabilities by the draft vocab.
- `eagle_utils.py`: scatter before the existing verify-kernel shape check.
- `eagle_draft_cuda_graph_runner.py`: size the graph draft-probability buffer by the draft vocab instead of the target vocab.
- Tests: CPU scatter/map tests, a block-verification args case, and a CUDA output-distribution test for both token and block verification.

## Validation

- Applies cleanly to #45233 head `612b93311b1d9f9a9e8c82d2fd63e960b6169aa0`.
- `git diff --check` and `py_compile` pass on every changed Python file.
- GPU validation is not run yet; the CUDA distribution test is included for CI/GPU.

Draft because the GPU path has not been exercised end-to-end.
