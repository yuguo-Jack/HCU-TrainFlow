# [CI] tests: Give each NIXL storage test its own temp directory

[Upstream PR](https://github.com/sgl-project/sglang/pull/44613) · state: open · merged: False

## Original PR description

## Motivation

`test/registered/unit/mem_cache/test_hicache_nixl_storage.py` is flaky on shared CI runners. `TestNixlUnified` and `TestNixlDirectIO` write to the fixed directories `/tmp/test_nixl_unified` and `/tmp/test_nixl_direct_io` and remove them in `tearDown`. When two jobs run on the same host, one job's `tearDown` deletes the other's files mid-test, and NIXL's POSIX registration fails, e.g. in `base-b-test-1-gpu-small (5)` on #44533:

```
POSIX path-mode open failed: nixl::FileFd("/tmp/test_nixl_unified/72/same_prefix_False_test_model_0_2_mamba"): No such file or directory
FAIL: test_mla_mamba_round_trip_keeps_each_tp_rank (zero_copy=False)
AssertionError: Lists differ: [False] != [True]
```

## Modifications

Both test classes now create their own directory with `tempfile.mkdtemp` in `setUp` (the existing `tearDown` still removes it). No product code changes.

## Test plan

- `test_hicache_nixl_storage.py`, whole file, 3 runs: 23 passed, 1 skipped (minio unavailable) each time.
- Concurrency repro, `TestNixlUnified` with 4 copies running at once, 3 rounds: on main 8 of 12 runs fail with the error above; with this change 12 of 12 pass.
- `black`, `isort`, `ruff check --select=F401,F821,F823,UP037` clean on the changed file.
