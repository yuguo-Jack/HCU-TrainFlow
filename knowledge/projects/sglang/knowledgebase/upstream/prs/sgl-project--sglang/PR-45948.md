# [Fix] diffusion: Keep the N-rank IPC all-to-all's flags and staging out of expandable segments

[Upstream PR](https://github.com/sgl-project/sglang/pull/45948) · state: closed · merged: True

## Original PR description

## Motivation

#43584 moved the 2-rank IPC all-to-all's exported buffers and the N-rank `_PipelinePool` onto `ipc_shareable_zeros`, but the N-rank transport's signal flags, timeout flag and exchange staging (from #43164) stayed plain `torch.zeros`. Under `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` those can land in expandable segments, whose IPC import calls `pidfd_getfd`. Containers without ptrace rights deny that syscall with EPERM.

Seen on a RunPod 4xB300 container (2026-10-22): every sequence-parallel server with more than two ranks logged `IPC all-to-all (multi-rank) unavailable (pidfd_getfd: Operation not permitted); using NCCL` (24 warnings across 6 runs: Wan2.2-A14B, Cosmos3, MiniMax-H3 4-GPU), so the copy-engine all-to-all and the head-grouped pipelined attention never ran.

It can also hang. Whether a plain `torch.zeros` buffer lands in an expandable block depends on each rank's allocator history, so one rank can import its peer's flags while the other fails. Init then deadlocks: one rank waits in `_share(timed_out)`'s `all_gather_object`, the other in the all-reduce where ranks agree on the outcome, until the NCCL watchdog aborts both (~10 min). On RunPod all four ranks happened to fail alike, which is why only the fallback was visible.

## Modifications

- `ipc_a2a_multi.py`: the signal flags, timeout flag and staging buffers come from `ipc_shareable_zeros`, like every other exported buffer. If sharing the flags still fails, the init error now says so.
- `ipc_a2a.py`: one docstring line on why `ipc_shareable_zeros` matters (`pidfd_getfd`).
- The NCCL fallback for hosts that genuinely cannot do CUDA IPC is unchanged.

Tests:
- `test/unit/test_ipc_a2a_lifecycle.py` (CPU, mocked): every buffer the N-rank path exports must come from `ipc_shareable_zeros`. On main the flags, timeout flag and staging fail it.
- `single_test_file/test_ipc_a2a_multi_gpu.py`: reruns the 2-rank multi-rank worker with `expandable_segments:True` under a seccomp filter that makes `pidfd_getfd` fail with EPERM.

## Speed Tests and Profiling
