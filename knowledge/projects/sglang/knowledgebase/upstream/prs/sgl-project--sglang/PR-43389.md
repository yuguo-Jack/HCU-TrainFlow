# [Fix] Preserve nullable string tool arguments

[Upstream PR](https://github.com/sgl-project/sglang/pull/43389) · state: open · merged: False

## Original PR description

## Motivation

Fixes #43149.

PoolsideV1Detector only recognized a scalar `schema["type"] == "string"`. Standard nullable string schemas represented with a type array or `anyOf` were decoded as numbers, booleans, or other JSON values, silently changing tool arguments.

## Modifications

- Reuse `infer_type_from_json_schema` when determining PoolsideV1Detector parameter types.
- Preserve raw argument text for nullable string schemas expressed with `type: ["string", "null"]` and `anyOf`.
- Add CPU regression coverage for both non-streaming and chunked streaming parsing.

## Accuracy Tests

Not applicable. This changes tool-argument type preservation only.

## Speed Tests and Profiling

Not applicable. The change only replaces a local schema-type check with the existing schema inference helper.
