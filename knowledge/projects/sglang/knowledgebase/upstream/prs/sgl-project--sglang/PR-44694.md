## Original PR description

## Summary

Add the Reflection Beam 1.0 deployment cookbook at:
https://docs.sglang.io/cookbook/autoregressive/Reflection/Beam-1_0

- Add a Docker deployment selector for B300, GB300, and H200, covering NVFP4, FP8, and BF16 where supported.
- Low-latency recipes use DFlash2 with block size 8. High-throughput recipes disable DFlash2; Blackwell NVFP4 uses attention DP, EP, and FlashInfer MegaMoE. H200 BF16 uses plain TP8 with automatic static memory fraction.
- Preserve all 16 verified recipes and recorded GSM8K scores, including their original evaluation-harness labels. This documentation port adds no new GPU measurements.
- Add a Reflection navigation group, cookbook overview card, and an OpenAI-compatible client example.
- Redirect the earlier `Beam-1.0` spelling to the canonical `Beam-1_0` URL.
