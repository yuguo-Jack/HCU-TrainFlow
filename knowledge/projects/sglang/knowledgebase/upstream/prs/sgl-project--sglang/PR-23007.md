# [sglang-miles] Improve weight checker with dtype/shape/device validation

[Upstream PR](https://github.com/sgl-project/sglang/pull/23007) · state: open · merged: False

## Original PR description

## Summary

- Adds metadata validation (dtype, shape, device) to `weight_checker.py` before value comparison
- Metadata mismatches are always treated as errors regardless of `should_compare`, since they indicate structural divergence rather than benign numerical differences (e.g. dequantized fp8)
- Skips value comparison when shapes differ (would raise), but still reports value diffs alongside dtype/device mismatches
- Fixes exact comparison to also check dtype match (`expect.dtype == actual.dtype and torch.all(expect == actual)`)

## Test plan

- [ ] Verify weight checker correctly reports dtype mismatches (e.g. fp16 vs fp32)
- [ ] Verify weight checker correctly reports shape mismatches and skips value comparison
- [ ] Verify weight checker correctly reports device mismatches
- [ ] Verify existing matching weights still pass as before
