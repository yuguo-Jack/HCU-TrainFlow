## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Dsv4.1's moe layers currently run on bf16 activations by default when a batch <= 256 tokens. Setting `AITER_BF16_FP8_MOE_BOUND=0` or `--monokernel-backend amd` switches them to FP8.

InferenceX does not accept changing precision through flags like these, because they also change the precision of the dspark draft layers. ([PR#4238](https://github.com/SemiAnalysisAI/InferenceX/pull/4238))

**This PR makes fp8 the default moe activation for V4.1 instead.**

## Modifications

<!-- Detail the changes made in this pull request. -->

The aiter moe runner passes `quant_dtype_a=fp8` to `fused_moe` instead of letting `AITER_BF16_FP8_MOE_BOUND` pick bf16 for small batches. 

**Other models (ex: dsv4) and other platforms are unchanged.**
