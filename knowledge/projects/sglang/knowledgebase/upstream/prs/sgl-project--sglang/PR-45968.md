## Motivation

The main contribution is cross-layer prefetching and chunked loading for
host-offloaded Engram tables. The existing path starts host-table reads at the
consuming layer and materializes full-batch embeddings. This puts cold host
accesses on the prefill critical path and increases temporary GPU memory.

This PR submits host reads ahead of consumption, overlaps them with intervening
layer computation, and projects/gates token chunks from bounded GPU buffers.
It targets cold-loading stalls after host offload. In the measured serving A/B,
mean TTFT decreased by **11.58%** and P90/P95/P99 TTFT decreased by
**32.76% / 27.03% / 32.71%**, respectively. The largest gains were in the early
request wave, matching the feature's cold-loading focus.

Existing host storage is reused. The feature is opt-in and disabled by default.

## Modifications

- Add a model-owned prefetch window with two current-layer chunk buffers and
  the first chunk of each look-ahead Engram layer. Reuse shared/per-rank host
  tables, existing FP8/E8M0 storage and TP sharding; retrieved rows remain BF16.
- Gather on a side stream, retain shard collectives on the consuming stream,
  and use CUDA events to protect buffer reuse. Preserve idle/uneven DP ranks,
  CP row ordering and late-layer row selection.
- Project and gate each chunk instead of accumulating full-batch embeddings.
  Allocate fixed staging before KV sizing; preserve history/multimodal behavior
  and add fixed CUDA graph and breakable graph integration hooks.
- Extend the existing gather kernel for strided 1D/2D indices and avoid a
  single-segment packing copy. Add unit, GPU, distributed and graph tests,
  plus reusable manual benchmark/checkpoint-check scripts.

Configuration:

```bash
SGLANG_ENABLE_DSV41_ENGRAM_HOST_TABLE=1 \
SGLANG_DSV41_ENGRAM_HOST_TABLE_LAYOUT=per_rank \
SGLANG_DSV41_ENGRAM_PREFETCH_CHUNK_SIZE=512 \
SGLANG_DSV41_ENGRAM_PREFETCH_LAYERS=1 \
python -m sglang.launch_server <existing serving arguments>
```

Chunk size defaults to 0 (disabled); positive sizes must be multiples of 128.
Look-ahead defaults to 1; 0 retains current-layer double buffering. Both host
layouts are supported. Per-rank prefetch rejects elastic EP at initialization.
Table-row staging is bounded by `(W + 2) * P * C * H * D * 2` bytes, where
`P` is the DP/CP segment count (1 for shared tables). Index, communication and
projection workspaces are additional.

The separate diffusion-registry tuple fix restores kernel namespace imports
in this checkout. Experimental records, measurement outputs and this PR draft
are kept outside the commits.

## Accuracy Tests

Validated locally on H20, PyTorch 2.13.0+cu130 / CUDA 13.0:

- 100 related CPU tests and 10 subtests; 9 single-GPU tests covering BF16,
  per-tensor FP8, block32 UE8M0 FP8, buffer reuse, recovery, history and graphs.
- Two-GPU TP/DP/CP suite covering shared/per-rank layouts, idle/uneven ranks,
  variable-length collectives and TP/DP graph replay.
- Gather comparison with an independent Torch oracle for contiguous, strided
  and transposed int32/int64 indices.
- Actual checkpoint WKV/gate weights, two Engram layers, 6144-to-25600
  projections, and compact host tables sampled from every hash column:
  retrieved rows and 16-token outputs exact; 1025-token projection/gate
  relative L2 error below 1.4e-5.

Serving validation covers eager execution; graph validation covers components
and integration fixtures. Full-model breakable prefill warmup encountered a
Repeat.cu shape error with prefetch disabled and remains a separate follow-up.
CUDA 12.8, Blackwell and full-model accuracy are pending validation. Local runs
used isolated compatible Python dependencies, kernel 0.4.8 with the existing
version-check override, and the Python radix-tree backend.

## Speed Tests and Profiling

Model: `DeepSeek-V4.1-Flash-1017`, H20 TP8, eager execution. Official
`sglang.benchmark.serving` client: 16 concurrent requests, 128 prompts,
4096 input / 512 output tokens, 16 warmups, client seed 73, zero prefix-cache
hits. Both groups completed all 128 requests. The feature group used C=512,
W=1; both groups used host-offloaded tables and the same serving configuration.

### TTFT: mean and tail latency

| Metric | Host synchronous | Host prefetch | Change |
| --- | ---: | ---: | ---: |
| Mean TTFT | 2244.78 ms | 1984.91 ms | **-11.58%** |
| Median TTFT | 1791.45 ms | 1782.35 ms | -0.51% |
| P90 TTFT | 3818.81 ms | 2567.73 ms | **-32.76%** |
| P95 TTFT | 5666.15 ms | 4134.72 ms | **-27.03%** |
| P99 TTFT | 9553.11 ms | 6428.68 ms | **-32.71%** |

Prefetch substantially reduces measured TTFT tail latency and lowers average
TTFT. About 79% of the aggregate TTFT reduction came from the first 16 requests,
highlighting the benefit during the early, cold-loading phase of this workload.
These are end-to-end serving measurements, rather than isolated host-read
timings. Server random seeds differed; numerical correctness is checked
separately by the tests above.

### Other serving metrics

| Metric | Host synchronous | Host prefetch | Change |
| --- | ---: | ---: | ---: |
| Duration | 697.27 s | 690.65 s | -0.95% |
| Output throughput | 93.99 token/s | 94.89 token/s | +0.96% |
| Mean TPOT | 166.02 ms | 164.90 ms | -0.67% |
| P95 TPOT | 171.78 ms | 176.47 ms | +2.73% |
| P99 TPOT | 173.19 ms | 179.37 ms | +3.57% |

### Bounded GPU staging

Real-weight, compact-table component check at 4096 tokens, C=512, W=1:

| Metric | Host synchronous | Host prefetch |
| --- | ---: | ---: |
| Allocator peak above common weights/inputs | 568 MiB | **397.375 MiB** |
| Persistent table-row staging | 0 MiB | 18 MiB |
| Allocation growth across three repetitions | 0 | 0 |

Chunked loading and projection reduce this component's peak allocation by
**30.04%**, including the fixed prefetch staging. This measures the Engram
component; both paths already keep their tables in host memory.

Reproduction tools: `test/manual/quantization/bench_engram_prefetch.py` and
`test/manual/quantization/check_engram_prefetch.py`. FP8-plus-scale direct
projection, independent ENP, DeepEP and ZOS integration are separate follow-ups.
