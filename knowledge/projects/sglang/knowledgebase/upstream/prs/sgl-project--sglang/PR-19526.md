# [Feat] qwen3: Support the perplexity-ai/pplx-embed-v1-0.6b embedding model

[Upstream PR](https://github.com/sgl-project/sglang/pull/19526) · state: open · merged: False

## Original PR description

Serve `perplexity-ai/pplx-embed-v1-0.6b` (architecture `PPLXQwen3Model`) as an embedding model.

```bash
python -m sglang.launch_server \
  --model-path perplexity-ai/pplx-embed-v1-0.6b \
  --is-embedding \
  --trust-remote-code \
  --dtype bfloat16 \
  --attention-backend flashinfer \
  --disable-radix-cache \
  --chunked-prefill-size -1
```

## Modifications

1. `PPLXQwen3Model` subclasses `Qwen3ForCausalLM` and sets every attention layer to `ENCODER_ONLY`. The checkpoint's `modeling.py` sets `is_causal = False` on every layer.
2. It pools with `PoolingType.MEAN`. The checkpoint's `1_Pooling/config.json` sets `pooling_mode_mean_tokens: true`. The `LAST` pooler inherited from `Qwen3ForCausalLM` gives cosine 0.20 to 0.81 against the real embedding.
3. `EntryClass` registers both `Qwen3ForCausalLM` and `PPLXQwen3Model`.
4. `test/registered/prefill_only/test_pplx_embedding.py` compares SGLang against the HF bidirectional mean-pooled output on 4 prompts and requires cosine > 0.999. It fails on the last-token pooler (min cosine 0.198) and passes with this PR (37 s on B300).

`--dtype bfloat16` is required. The checkpoint config says `float32`, and `--dtype auto` downcasts float32 to float16. In float16, 3 of 8 test texts return NaN embeddings, and a batch of 8 on flashinfer returns NaN for every text.

## Accuracy Tests

Reference: `AutoModel.from_pretrained("perplexity-ai/pplx-embed-v1-0.6b", trust_remote_code=True, dtype=torch.bfloat16)`, then the mean of `last_hidden_state` over all tokens, one text at a time. There are 8 texts: the 5 from the model card, 2 short QA texts, and one 401-token text. The runs use B300, transformers 5.19.0, the server command above, and this branch with main `14ad64c411` merged in.

| SGLang build | Pooling | Cosine vs HF, min | Cosine vs HF, mean |
|---|---|---|---|
| `b50bbd33c1` (before) | last token | 0.1984 | 0.4918 |
| `66ae01d638` (this PR), batch of 8 | mean | 0.9966 | 0.9995 |
| `66ae01d638` (this PR), one request per text | mean | 0.9973 | 0.9996 |

- 7 of the 8 texts are at 0.9998 or higher. The minimum is the 401-token text.
- The cosine between HF bf16 and HF fp32 is 0.9999 on every text, including the 401-token one.
- `--attention-backend triton` is within 0.0001 of flashinfer on every row.
- Cosine vs the checkpoint's int8 output (`round(tanh(x) * 127)`) is 0.9969 to 0.9996. Cosine is the metric the model card specifies.

Regression test:

```bash
python3 test/registered/prefill_only/test_pplx_embedding.py
```

## Follow-ups

- Mean pooling in `pool_hidden_states` runs `cumsum` in the model dtype across the whole batch. That is a candidate cause of the 401-token gap. It is not changed here.
