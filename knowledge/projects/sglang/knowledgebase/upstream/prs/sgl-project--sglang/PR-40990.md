# [sgl-router] Keep engine scoring local to each policy

[Upstream PR](https://github.com/sgl-project/sglang/pull/40990) · state: closed · merged: False

## Original PR description

## Motivation

Reorganized policies depend on legacy `policies/admission.rs` for engine comparisons and cache queue gates. Each policy should own its scoring rules directly.

## Modifications

- Give power-of-two and cache-aware their own local `score(engine) -> [u128; 5]` functions. Keys compare left to right, with lower values winning; there is no shared scoring module, score type, or comparator implementation.
- Power-of-two chooses its array fields by stage. Cache-aware ranks uncached prefix work first and uses its own prefill-pressure array for ties. Session-aware continues to delegate new placement to power-of-two.
- Keep cache queue gates local and remove reorg dependencies on legacy admission helpers.
- Choose the available load basis consistently within the sampled pair or cache candidate tier. Mixed queue-time availability falls back to token counts across that set, making cache sorting consistent. Integer counts and decode KV fractions retain exact ordering.
- Update the design documentation and cover mixed cache telemetry and large KV counters in regression tests.
