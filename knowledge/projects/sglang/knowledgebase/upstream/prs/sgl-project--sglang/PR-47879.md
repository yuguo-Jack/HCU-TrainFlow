# [Refactor] [NPU] dsv4: consume registered sgl-kernel-npu Transformer APIs

[Upstream PR](https://github.com/sgl-project/sglang/pull/47879) · state: open · merged: False

## Original PR description

## Motivation

Consume stable category APIs under `sgl_kernel_npu.operators` (`attention`, `kvcacheio`, `norm`, `rope`, and `moe`) for both original custom/native and released Transformer bindings. The kernel package owns backend selection and ABI adaptation; SGLang keeps model semantics and graph lifecycle.

## Changes

- Use registered sparse/mixed-quant attention, indexer, KV/indexer cache writers, mHC pre/post, partial RoPE, compressor and MoE gating APIs. All consumer imports follow the kernel repository's category layout; the former `operators.dsv4` imports are removed.
- Move packed-KV geometry and mHC BSND/operand-order conversion to sgl-kernel-npu. The kernel APIs register auto and torch_native plus a named backend: cann_ops_transformer for the existing adapters, torch_npu for MoE gating. auto selects the operator's production implementation.
- Preserve model-level DSpark metadata, graph capture/replay, cache allocation, standard torch/torch_npu calls and GPU paths in SGLang. Both MoE gating calls now use the registered kernel API, whose auto backend calls torch.ops.npu.npu_moe_gating_top_k; the separate gating-top-k-softmax fast path is unchanged.
- Query the kernel-selected KV format before allocation, covering released 608B/BF16-scale and original 640B/E8M0-scale rows. Cache writes pass canonical buffers without vendor-specific quantization attributes.
- Pass the existing CPU int32 query/KV length mirrors to the public metadata API, allowing the kernel to select legacy host metadata without a device-to-host copy during capture.
- Update dispatch and layout-consumer tests; retain the A5 slot-zero/-1-sentinel regression.

## Dependencies

Requires https://github.com/sgl-project/sgl-kernel-npu/pull/939 and a wheel containing its APIs before merge.

This branch builds on https://github.com/sgl-project/sglang/pull/47438, preserving the original author commit and merging main to resolve the memory-pool import conflict. The diff against main includes that original CANN migration plus this extraction.

## Validation

Formatting, isort, unused-import/undefined-name and Python syntax checks passed. Companion kernel CPU contracts/reference numerics and simulated old/new ABI tests: **129 passed, 9 skipped**. Independent execution of the changed consumer methods validated both allocation widths, canonical writer arguments and existing CPU mirrors.

Draft: the SGLang backend test cannot collect on this macOS host because Triton is unavailable. Real A3/A5 accuracy, graph replay and performance remain pending.
