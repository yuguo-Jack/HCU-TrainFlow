# [CI] diffusion: replace FLUX.1/2 nightlies and add FLUX.3 TP2 e2e

[Upstream PR](https://github.com/sgl-project/sglang/pull/44651) · state: open · merged: False

## Original PR description

Replace the FLUX.1-dev and FLUX.2-dev nightly comparison entries with separate FLUX.3 base and distilled cases, keeping their histories separate from the retired models.

Register the FLUX.3 Klein TP2 text-to-image case in `TWO_GPU_CASES`, using the shared `test_server_2_gpu.py` fixture and partition plan. Check the image API and 512x512 PNG output. Remove the duplicate standalone TP2 method and registration; extended batching/editing remains opt-in. Read standalone metadata from the canonical case configuration.

Keep the scheduling estimate separate from measured performance baselines. H100 calibration remains pending; the shared test continues to report a missing baseline until measurements are provided.

Restored standalone coverage exposes overlapping Q/K writeback in GLM Image after in-place CUDA RoPE. Concatenate the text prefix and rotated image stream instead, with a regression test through the real CUDA operator.
