# [Fix] disaggregation: Initialize the bootstrap server loop and runner before the server thread starts

[Upstream PR](https://github.com/sgl-project/sglang/pull/47725) · state: closed · merged: True

## Original PR description

## Motivation

`CommonKVBootstrapServer.__init__` starts the server thread, and only that thread assigns `_loop` and `_runner`. `close()` raises `AttributeError` when called before the thread reaches the loop setup, and when `_run_server` fails before the runner exists, the `finally` block raises a second `AttributeError` that replaces the logged error.

## Modifications

Initialize both fields to `None` in `__init__` and skip the cleanup of what was never created. One unit test calls `close()` on a server whose thread has not started.
