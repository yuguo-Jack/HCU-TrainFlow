# [Refactor] kernels/diffusion/tests: Prune new dead code and make silently skipped tests run

[Upstream PR](https://github.com/sgl-project/sglang/pull/48366) · state: open · merged: False

## Original PR description

## Motivation

This is the second pass of #44690. Three weeks after that PR, `python/sglang/kernels` had gained another 66K lines, `python/sglang/multimodal_gen` 43K and `test/registered` 162K. This PR removes what in that code is dead or redundant. More importantly, it fixes the places where CI is green without testing anything, and the runtime bugs found along the way.

**433 files, +5,551 / −13,052.**
- About 1.4K of the additions are tests moved to `test/manual/`, because no CI runner has the hardware or package they need.
- About 0.8K are shared test helpers that replace copies.

## Modifications

### Kernels (`python/sglang/kernels`, 108 files, −3.1K net)
- **Dead code** (each re-checked by whole-repo grep, incl. string targets):
  - 865 lines of `jit/csrc/moe/expert_specialization/*.cuh` that nothing loads;
  - ngram decode fast paths that were never wired in, and their benchmarks;
  - the MuseSpark `router_gemm` JIT kernel (the model only uses its token limit);
  - the test-only TextSeal standalone selector;
  - two unused LoRA MoE custom ops;
  - LPLB shmem helpers, `row_argmax` and `create_argmax_workspace`;
  - the f32x2 helpers left by a reverted PR;
  - `finish_flat_indexer_topk`;
  - the `small_field_copy` descriptor path;
  - an unloadable LoRA plans table;
  - losing `mla_qk_prep` variants (the default path is byte-identical on H200 and GB300 over 64 cases);
  - unused `use_tma`/`topk`/`config` parameters;
  - the MuseSpark softmax routing branches;
  - aliases, constants and re-exports nothing uses.
- **Classification** (#45112 rules):
  - `engram_gather_peer` (peer-memory read) → `communication`.
  - MSA-v1 `compact_dequant` (KV-cache gather + dequant) → `kvcache`.
  - The two diffusion op ids that targeted quantization/activation modules are renamed to their real groups; their facade re-exports are gone.
  - `qwen_moe_topk_output` moves to its only caller in `qwen2_moe.py`.
  - The gfx1250 per-token FP8 quant → `quantization`.
- **Arch queries:** about 15 sites that still probed the device by hand now use `sglang.kernels.arch` (#47782) with the same semantics. `argmax`/`softmax` JIT adopt `max_vec_bytes`. Import-time device-0 probes moved to call time.
- **Dedups:**
  - the gfx950 gluon MoE helpers (identical AMDGCN for all 68 cases);
  - the hipcc compile-and-load block;
  - the SM90 FP8 CuTeDSL LoRA class, now a subclass of its BF16 sibling (bit-exact on H200);
  - the gfx950 vattn HIP binding.
- **Env:** raw `os.environ` reads in kernels/models are declared in `environ.py` with the same names and defaults. Two settings are removed:
  - `SGLANG_HIP_MHC_BOUNDARY_WIDE_TILE`, a kill switch for a bitwise-identical tile;
  - `SGLANG_XPU_LN_MOD_NUM_WARPS`, a layout-only setting.
- **HiCache:** the page-unified layout is admitted only if both the write-back and the load-back JIT probes pass; until now the load-back probe was never called.
- **Docs:** cookbook lines that told users to set env vars nothing reads are removed.

### Diffusion (`python/sglang/multimodal_gen`, 118 files, −1.5K net)
- **Dead code:**
  - 7 disaggregation flags nothing read;
  - `--mask-strategy-file-path` (sliding-tile attention reads `--attention-backend-config mask_strategy_file_path=...`, and the error now says so);
  - the `/stats` timeout counter that was always 0;
  - vestigial `PortArgs` fields that leaked three temp files per construction;
  - about 25 unused helpers, constants and config fields;
  - test oracles moved out of runtime modules into the tests.
- **Shared helpers:**
  - four more hand-written verify-once gates use `BitExactFusionGate.run` / `can_attempt` (flux3 video VAE, FLUX.2 XPU, KL-VAE, Qwen-Image-2.1);
  - Wan and LingBot share one row-packing helper;
  - the duplicated Nomas helpers, OpenAI image/video/mesh API helpers and flux3's copy of the launcher conditions are merged;
  - the two disagreeing "unrecoverable device error" classifiers are now one.
- **Docs:**
  - `--enable-attention-backend-autotune` was documented but not a CLI flag; it is now one.
  - `ring_sp_performance.mdx` documented a flag that does not exist; it now uses the real `--kv-gather-degree`.

### Tests and CI
- **Deleted:**
  - tautologies (argparse pass-through, default and constant echoes, `inspect.getsource`/AST source tests, mock-the-SUT, torch-math);
  - duplicate cases and files;
  - benchmarks of test-local copies;
  - always-skipped tests;
  - `#47603` leftovers (dead model lists, a test that `return`s in CI);
  - tests with a hard-coded developer path.
- **Merged** copy-pasted fakes, fixtures and oracles into `python/sglang/test/` helpers. Two test classes were collected twice through imports (45 extra runs per CPU job).
- **Trimmed grids** with no coverage gain: page-unified dtype sweep (252 → 168 cases), MiniMax decode top-k (144 → 48).
- **Faster CPU gate:**
  - `test_runtime_context.py`: 132 s → 13 s;
  - `test_flashinfer_autotune_sync.py`: 30 s → 10 s;
  - three one-purpose files merged.
- **Moved to `test/manual/`:** tests that need NCCL ≥ 2.31.2, a private checkpoint, an unset env var, or 4 GPUs of a manual-only class; plus a benchmark CLI that lived in a registered test.
- **CI:**
  - the empty 8-GPU XPU nightly job is removed;
  - stale suite names, globs and `rerun_test_groups` entries are removed;
  - the Muse Spark HF token follows the runner, not the stage;
  - `comfy-kitchen` (no deps) is installed for the diffusion unit/B200 jobs, so its three tests stop skipping.

## Behavior changes
- Diffusion CLI:
  - the 7 unused disaggregation flags and `--mask-strategy-file-path` are now rejected;
  - `--srt-encoder-connection-timeout` takes effect and accepts floats.
- Diffusion `exact` requests no longer use the fused QKV GEMM (Wan, LingBot). `lossless` and `high` outputs are byte-identical to main.
- HiDream-O1 rejects `--flow-shift`/`--scheduler-class-override`, as it already does for its other fixed settings. HunyuanImage-3 honors a user `--flow-shift` instead of overwriting it.
- `/v1/images/edits` returns 400 when `mask` is given; it was silently ignored.
- The diffusion client treats `CUDA error:`, `HIP error:` and `torch.AcceleratorError` as unrecoverable, like the worker does.
- ROCm: no PDL in the Unlimited-OCR DASH / QK-norm gate kernels. The gfx1250 kpool indexer uses Triton `act_quant`, like the other two DSA paths.
- CuTe DSL LoRA prepare: SM120 now gets a clear `NotImplementedError` instead of compiling the SM100 class and failing.
- Removed env vars: `SGLANG_HIP_MHC_BOUNDARY_WIDE_TILE`, `SGLANG_XPU_LN_MOD_NUM_WARPS`. Newly declared boolean envs (`SGLANG_ROCM_SMALLM_FP8_BS`, `SGLANG_DISABLE_LFM_FUSED_CONV`) parse like every other `EnvBool`.

## Left alone (owner decisions, not in this PR)
- **AMD/NPU suites no workflow runs:** 55 AMD files (~8.9K lines) and 8 NPU files (~1.5K lines) register suites that no workflow invokes. `run_suite.py` does not validate AMD/NPU suite names. The list is in a comment below.
- **Cake softmax on SM100:** since the JIT branch went first (#47512), the Cake softmax can no longer be selected; its input domain is inside the JIT one.
- **MiniMax-H3 4-GPU H100 smoke suite:** `FILE_SUITES["4-gpu-h100"]` has no bridge file and no workflow, so its three cases never run.
- **Code waiting on #46693:** the gfx950 kernels from #46690–#46692 that #46693 wires.
- **Auto-residency probe:** unreachable since #45979 ("until a planner consumes it").
- **SubBlock ragged tail on sm_100:** `TestSubBlockNumerics::test_ragged_tail_reproduces_dense` returns NaN on the B200 lane and passes on sm_103 and sm_120. The kernel is not changed here, so the case is skipped on sm_100 until the tail path is fixed.
- **`topk_sigmoid` on ROCm:** every case of `test_moe_topk_sigmoid.py` failed on the MI300 jit-kernel lane, so the test stays CUDA-only.
- **`pr-test-sgl-kernel.yml` benchmark loop:** `|| echo` means the job cannot fail.
