## Motivation

Provide the small endpoint contract shared by the HiCacheStorage and direct-device KVCR integrations, without coupling their different memory layouts or adding a mandatory KVCR dependency.

- Require homogeneous source topology when applying rank offsets.
- Reuse existing typed request-hint plumbing; this does not establish a source lease or cache residency.
- Add four CPU contract cases, including optional-dependency-safe import coverage.
