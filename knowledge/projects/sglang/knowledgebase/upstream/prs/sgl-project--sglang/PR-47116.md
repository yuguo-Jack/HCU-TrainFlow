# [Fix] usage: Clamp reasoning tokens after stop truncation

[Upstream PR](https://github.com/sgl-project/sglang/pull/47116) · state: closed · merged: True

## Original PR description

Clamp reported reasoning tokens to the completion prefix retained after a stop condition. A verified block can contain tokens beyond that boundary, causing reasoning usage to exceed the emitted completion length.

Validated with CPU regression tests covering stops inside reasoning, around the reasoning end token, and inside content, for streaming/non-streaming and Python/Rust output paths. The new cases fail on main and pass with the fix.
