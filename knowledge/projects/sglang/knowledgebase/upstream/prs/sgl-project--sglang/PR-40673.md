# [NPU] Fuse DeepSeek-V4 decode compression metadata updates

[Upstream PR](https://github.com/sgl-project/sglang/pull/40673) · state: open · merged: False

## Original PR description

## Motivation

DeepSeek-V4 prepares decode compression metadata through several separate PyTorch operations before each NPUGraph replay. This PR fuses these updates into one Triton kernel to reduce dispatch overhead.

## Modifications

- Add the fused implementation to the existing `dsv4/metadata_kernel.py`, covering C4/C128 cache location copying and tail clearing, compression boundary detection and stable position compaction, and `start_pos` and `seqused` updates.
- Update existing graph buffers in place on the current stream, with kernel warmup before graph capture.
- Enable fusion by default through `SGLANG_NPU_DSV4_FUSED_DECODE_METADATA`. Setting it to `0` restores the original PyTorch implementation.
- Add tests covering compression boundaries, padding, missing locations, strided inputs, buffer reuse, and graph consumption.

## Accuracy Tests

- Four CPU tests passed using an isolated source harness.
- Two NPU tests were added for kernel correctness and graph replay with stream dependencies; these were skipped locally because NPU hardware was unavailable.
- Model-level accuracy evaluation has not been run.
- Ruff checks, formatting, and whitespace checks passed.

## Speed Tests and Profiling

With NPUGraph enabled and 8 concurrent decoding requests, the median server-reported decode throughput improved by 1.72%.

| Metric | Fusion disabled | Fusion enabled | Improvement |
| :--- | ---: | ---: | ---: |
| Median decode throughput (tokens/s) | 289.38 | 294.35 | +1.72% |
