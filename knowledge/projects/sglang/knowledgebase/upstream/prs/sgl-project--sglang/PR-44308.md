- nemanjaudovic · comment · 2026-10-14T16:38:56Z · [source](https://github.com/sgl-project/sglang/pull/44308#discussion_r4273584015)

File: `python/sglang/kernels/aot/csrc/elementwise/dsv4_norm_rope.cu` · line 148

Build failure: `dsv4_norm_rope.cu` doesn't compile for gfx950, gfx1201 or gfx1250 (or any multi-arch build that includes one of them).

  ```
  dsv4_norm_rope.hip:157: error: use of undeclared identifier 'kFP8Max'
  dsv4_norm_rope.hip:432: error: comparison between pointer and integer ('fp8x2_e4m3_t (*)(float, float)' and 'int')
  ```

`kFP8Max` is removed, and `pack_fp8` templated on `FP8_MAX`.


  Suggested fix - templating this variant on kmax:

  ```cpp
  #elif HIP_FP8_TYPE_OCP && !HIP_FP8_TYPE_FNUZ
  template <int FP8_MAX = 448>
  __device__ __forceinline__ fp8x2_e4m3_t pack_fp8(float x, float y) {
    constexpr float kMax = static_cast<float>(FP8_MAX);
    const float2 v{fmaxf(fminf(x, kMax), -kMax), fmaxf(fminf(y, kMax), -kMax)};
    return __hip_cvt_float2_to_fp8x2(v, __HIP_NOSAT, __HIP_E4M3);
  }
  ```
