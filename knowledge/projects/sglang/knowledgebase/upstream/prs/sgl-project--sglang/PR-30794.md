# Use DeepGEMM deduplication API

[Upstream PR](https://github.com/sgl-project/sglang/pull/30794) · state: closed · merged: False

## Original PR description

Use DeepGEMM config deduplication from this PR: https://github.com/sgl-project/DeepGEMM/pull/58
This reduces start time 
from 6:30 to 6:10 on B200 with DeepSeek-V3.2
and from 10:00 to 2:00 on B200 with a custom MOE model

We use the existing deduplication mechanism from DeepGEMM, which we exposed to Python API so it can be used in SGLang. The speed-up comes from removing config copies during warmup.

Related PR: https://github.com/sgl-project/DeepGEMM/pull/58
Related issue: https://github.com/deepseek-ai/DeepGEMM/issues/196
