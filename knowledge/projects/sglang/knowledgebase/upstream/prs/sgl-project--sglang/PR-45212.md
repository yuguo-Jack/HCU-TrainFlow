# [Fix] mamba: Skip zero-width conv pools in the MTP verify scatter

[Upstream PR](https://github.com/sgl-project/sglang/pull/45212) · state: closed · merged: True

## Original PR description

## Summary

Fixes the nightly `test_ling_2_6_flash.py` crash on the first MTP verify step:

```
ValueError: fused_conv_window_scatter_with_mask: dst entry dims (dims 2..3) must be contiguous; got shape=(28, 257, 0, 0) strides=(257, 1, 1, 1)
```

Lightning linear-attention layers (Ling-2.5/2.6, MiniCPM lightning hybrids) have no conv state, so their conv pool is zero-width. `dst.is_contiguous()` accepted it, but #44971's explicit stride check rejects it. The pool then falls back to the per-pair scatter, which raises.

- `scatter_mamba_states_after_mtp_verify` skips empty conv pairs, like the existing SSM guard, so mixed sets keep the single-launch path.
- `fused_conv_window_scatter_with_mask` returns early on an empty `dst`, as a safety net.

New `TestScatterAfterVerifyZeroWidthConv` and `test_ling_2_6_flash.py` both fail before the fix and pass after.
