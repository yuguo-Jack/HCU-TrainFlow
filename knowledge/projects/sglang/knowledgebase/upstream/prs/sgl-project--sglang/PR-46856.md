# [Fix] attention: Cover CUDA graph padding in verify state indices

[Upstream PR](https://github.com/sgl-project/sglang/pull/46856) · state: closed · merged: False

## Original PR description

Size the speculative verify state-index table for both eager and CUDA graph batch padding. Graph alignment can exceed the eager maximum, leaving the existing table too short for padded verify batches.

Preserve the row mapping for real requests and map additional padded positions to the existing reserved scratch row. This changes only the index-table length, not the state-buffer allocation or dtype.

Add CPU regression cases for graph-only padding, eager padding, and unpadded batches. Python syntax and diff checks passed; unit tests and GPU validation have not been run.
