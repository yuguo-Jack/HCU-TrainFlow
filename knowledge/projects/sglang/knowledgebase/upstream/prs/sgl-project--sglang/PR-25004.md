# [DP attn] Speed up decode gather and scatter by writing buffers once

[Upstream PR](https://github.com/sgl-project/sglang/pull/25004) · state: open · merged: False

## Original PR description

## Motivation

Closes https://github.com/sgl-project/sglang/issues/24938.

Before this change, every DP-attention decode step ran its gather and scatter as two passes over the destination buffer. With it, those kernels take about 20% less time on an H100 (median over 60 shapes), and median TPOT for DeepSeek-V3 on 8×H200 was 0.51% lower. The first pass zeroed the whole buffer and the second copied this rank's rows over part of it, so the copied rows were written twice by two bandwidth-bound passes.

## Modifications

Gather and scatter now call one Triton kernel that copies this rank's rows and writes zero to the rest of the destination, so each element is written once. The context-parallel path, the branch that copies nothing, and CPU builds keep the plain zero fill; CPU tests that drive DP gather swap in that fallback for both copies. A unit test checks the fused kernel against the two-step sequence, and a microbenchmark compares their speed.

## Accuracy Tests

In all 13 cases of the unit test's matrix on an H100, the fused kernel writes the same bits as the old fill-then-copy sequence. Commands and raw output are under Testing Done.

## Speed Tests and Profiling

On an H100 the fused path is faster in the median by about 20% across 60 shapes: 13% for gather and 21% for scatter. A serving run on 8×H200 when this PR was opened showed a 0.51% lower median TPOT (Welch's t, p ≈ 0.018), with throughput within noise.

## Testing Done

The parity check and the microbenchmark run on this PR's head, f099c6c6. Each compares the code path on main (zero fill, then memcpy_triton) with the fused kernel in the same process. Setup: NVIDIA H100 80GB HBM3, driver 580.159.04, CUDA 13.0, torch 2.14.0, triton 3.8.0, one GPU. The repo pins torch 2.14.1; both releases require triton 3.8.

<summary>Reproducer source: parity_bitwise.py</summary>

```python
#!/usr/bin/env python3
# Bitwise parity of memcpy_triton_with_zero_fill against dst.fill_(0) + memcpy_triton for the
# test file's cases, plus independent checks that the copied slice equals src and the rest is +0.
import sys

import torch

sys.path.insert(0, sys.argv[1])
from test_dp_attention_memcpy_zero_fill import _fused, _reference  # noqa: E402

BITS = {torch.bfloat16: torch.int16, torch.float16: torch.int16, torch.float32: torch.int32, torch.int32: torch.int32}
CASES = [
    ("gather_bf16", (8192, 7168), 1024, 2048, 1024, False, torch.bfloat16),
    ("scatter_bf16", (1024, 7168), 8192, 2048, 1024, True, torch.bfloat16),
    ("gather_int32", (8192,), 1024, 2048, 1024, False, torch.int32),
    ("zero_offset", (4096, 2048), 512, 0, 512, False, torch.bfloat16),
    ("full_coverage", (1024, 2048), 1024, 0, 1024, False, torch.bfloat16),
    ("end_offset_tail", (4096, 2048), 512, 3584, 512, False, torch.bfloat16),
    ("non_block_aligned", (999, 131), 333, 200, 333, False, torch.bfloat16),
]
for dtype in (torch.float16, torch.float32, torch.bfloat16):
    name = str(dtype).removeprefix("torch.")
    CASES.append((f"dtype_{name}_gather", (2048, 4096), 512, 1024, 512, False, dtype))
    CASES.append((f"dtype_{name}_scatter", (512, 4096), 2048, 1024, 512, True, dtype))

torch.manual_seed(0)
failures = 0
print(f"{'case':28} {'dtype':9} {'dst':>12} {'bit_equal_ref':>13} {'copy_ok':>7} {'zero_ok':>7} {'zeros':>10}")
for name, dst_shape, src_rows, offset, sz, offset_src, dtype in CASES:
    src_shape = (src_rows,) + tuple(dst_shape[1:])
    if dtype == torch.int32:
        src = torch.randint(0, 32000, src_shape, dtype=torch.int32, device="cuda")
    else:
        src = torch.randn(src_shape, device="cuda").to(dtype)
    offset_t = torch.tensor([offset], dtype=torch.int32, device="cuda")
    sz_t = torch.tensor([sz], dtype=torch.int32, device="cuda")
    kwargs = dict(dst_shape=dst_shape, src=src, offset_t=offset_t, sz_t=sz_t,
                  offset_src=offset_src, dtype=dtype, device="cuda")
    ref = _reference(**kwargs)
    out = _fused(**kwargs)
    torch.cuda.synchronize()
    bit_equal = torch.equal(out.view(BITS[dtype]), ref.view(BITS[dtype]))
    copied = out[0:sz] if offset_src else out[offset:offset + sz]
    expected = src[offset:offset + sz] if offset_src else src[0:sz]
    copy_ok = torch.equal(copied.view(BITS[dtype]), expected.view(BITS[dtype]))
    mask = torch.ones(dst_shape[0], dtype=torch.bool, device="cuda")
    if offset_src:
        mask[0:sz] = False
    else:
        mask[offset:offset + sz] = False
    rest = out[mask]
    zero_ok = bool((rest.view(BITS[dtype]) == 0).all().item()) if rest.numel() else True
    ok = bit_equal and copy_ok and zero_ok
    failures += not ok
    print(f"{name:28} {str(dtype).removeprefix('torch.'):9} {'x'.join(map(str, dst_shape)):>12} "
          f"{str(bit_equal):>13} {str(copy_ok):>7} {str(zero_ok):>7} {rest.numel():>10}")
print(f"cases={len(CASES)} failures={failures}")
sys.exit(1 if failures else 0)
```
