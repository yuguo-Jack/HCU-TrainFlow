## Summary
Adds the MiniMax-M3.1 cookbook page (`docs/cookbook/autoregressive/MiniMax/MiniMax-M3.1.mdx`) with a config-driven recipe file (`docs/src/snippets/configs/MiniMaxAI/minimax-m3.1.jsx`):

- NVIDIA B200 / B300 low-latency and high-throughput recipes (incl. MSA-V1 MonoKernel)
- AMD MI350X / MI355X recipes, MiniMax-M3.1-Flash (NVFP4, Quark MXFP4)
- DFlash2 speculative decoding
- PD disaggregation and HiCache (incl. Mooncake L3 tier)
- Links from the autoregressive intro, `docs.json`, and the MiniMax-M3 page
