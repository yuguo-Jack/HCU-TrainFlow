# [Intel GPU] Dispatch the DeepSeek V4 attention metadata ops on XPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/40614) · state: closed · merged: False

## Original PR description

## Motivation

Dispatch in `dsv4_attn_metadata_kernels.py` is keyed on `value.is_cuda`, so XPU
inputs fall through to the torch reference. The reference is not numerically
equivalent to the triton kernel it stands in for. In
`build_causal_swa_page_indices` the reference indexes `full_to_swa_mapping` with
-1, and torch wraps that to the last table entry, while the kernel stores the -1
sentinel. A wrapped index reads a real page instead of being treated as absent.

This is a correctness fix, not a performance change.

## Modifications

`_inputs_on_cuda` becomes `_inputs_on_accelerator` and answers true for XPU as
well, so `BuildPageTablePositions` and `BuildCausalSwaPageIndices` take the
triton arm there. The rename keeps the name honest now that it covers more than
CUDA; it is module-private with three call sites.

`ExpandPrefillCausally` is the exception and does not consult that helper on XPU.
Its triton kernel does not compile under triton-xpu 3.7.2, so a new `xpu`
classmethod calls the native `dsv4_expand_prefill_causally_out` op. Outputs are
caller-allocated at the padded width, which is what graph capture at a fixed
width needs.

CUDA and CPU behaviour is unchanged on every path.

## Accuracy Tests

The op this dispatches to is covered by `tests/test_dsv4_attn_metadata.py` in
sgl-kernel-xpu, which checks it against a Python reference across batch and
sequence-length grids, the padding tail, an empty batch, two negative controls
and graph replay.

Happy to add a dispatch-level unit test under `test/registered/xpu/` if you would
like the routing itself pinned, alongside the existing
`test_intel_xpu_linear_attn_dispatch.py`.

## Benchmarking and Profiling

None. This corrects which arm XPU takes; it is not a performance change.

## Dependency

Needs `dsv4_expand_prefill_causally_out` in sgl-kernel-xpu, which is
sgl-project/sgl-kernel-xpu#505. Kept as a draft until that lands.
