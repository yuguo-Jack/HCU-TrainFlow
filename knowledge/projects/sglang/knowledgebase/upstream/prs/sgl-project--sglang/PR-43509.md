# [Fix] Preserve NVFP4 writer scales for shared KV layers

[Upstream PR](https://github.com/sgl-project/sglang/pull/43509) · state: open · merged: False

## Original PR description

## Motivation

Gemma KV-sharing readers reuse the writer's cache layer ID. Loading their absent/default scales after the writer currently overwrites its calibrated NVFP4 pool scales with 1.0. This patch keeps scale ownership with the cache writer.

## Modifications

Skip attention modules marked `is_kv_shared_layer` during pool scale initialization. This is a three-line production change; ordinary layers, legitimate calibrated overrides, existing SM100 conversion, and uncalibrated writer defaults retain their behavior. Add an existing-suite CPU regression covering both traversal orders, absent/default/unrelated reader scales, and both SM100 conversion policies.
