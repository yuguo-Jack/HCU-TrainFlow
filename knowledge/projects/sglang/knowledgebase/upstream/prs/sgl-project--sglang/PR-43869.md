# [Docs] Add three multimodal flags to the server args table

[Upstream PR](https://github.com/sgl-project/sglang/pull/43869) · state: open · merged: False

## Original PR description

 ## Motivation

`--mm-preprocess-cache-size-mb`, `--mm-feature-transport` and `--mm-global-cache-backend` are registered but have no row in the server arguments table. You can only find them in `--help`.

## Modifications

- Add a row for each flag to `server_arguments.mdx`. The descriptions, defaults and choices come from the field declarations in `arg_groups/fields/mm.py`.
- Remove the three flags from `server_arguments_undocumented.txt`. The coverage test fails if a documented flag stays on that list.

Docs only, no code changes. No open PR documents these flags.
