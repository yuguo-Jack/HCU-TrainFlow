[Upstream PR](https://github.com/sgl-project/sglang/pull/45628) · state: closed · merged: True

## Original PR description

## Motivation

DeepSeek-V4.1 target gates route through `vision_topk`, which skips the `SGLANG_SIMULATE_UNIFORM_EXPERTS` / `SGLANG_SIMULATE_ROUND_ROBIN_EXPERTS` override in `select_experts`, so only the draft layers were balanced.

## Modifications

Move the override into `apply_routing_simulation` and call it from both `select_experts` and `_finish_vision_topk`.
