# [Doc] supported-models: Fix test suite path and command in support_new_models

[Upstream PR](https://github.com/sgl-project/sglang/pull/46011) · state: open · merged: False

## Original PR description

## Motivation

Fixes #34118.

The "Add the Model to the Test Suite" section of [Support New Models](https://docs.sglang.io/docs/supported-models/support_new_models#add-the-model-to-the-test-suite) no longer matches the repository:

- The `test_generation_models.py` link points to `test/registered/models/`, which returns a 404. The file now lives at `test/registered/e2e/models/test_generation_models.py`.
- The doc says to add the model to `ALL_OTHER_MODELS`, but the test file now uses a single `ALL_MODELS` list.
- The example command runs `TestGenerationModels.test_others`, which no longer exists. The current test method is `test_all_models`. The command also only works from the test's directory, which the doc didn't mention.

## Modifications

Docs only: `docs/docs/supported-models/support_new_models.mdx`

1. Updated the link to `https://github.com/sgl-project/sglang/blob/main/test/registered/e2e/models/test_generation_models.py`.
2. Renamed `ALL_OTHER_MODELS` to `ALL_MODELS`.
3. Updated the example command to:
   ```bash
   cd test/registered/e2e/models
   ONLY_RUN=Qwen/Qwen2-1.5B python3 -m unittest test_generation_models.TestGenerationModels.test_all_models
   ```

I checked each change against current `main`: the new link returns 200, `ALL_MODELS` is defined in the test file, `TestGenerationModels.test_all_models` exists, and `ONLY_RUN` is still how the test filters by model.

Note: #34156 and #40400 also change this link, but neither updates the list name or the command. This PR covers all three. (#34156 also points to `test/registered/models_e2e/`, which doesn't exist on current `main`.)
