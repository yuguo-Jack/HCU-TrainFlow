# [CI] [AMD] pr-test: Move tests in CUDA's extra tier to the AMD extra workflow

[Upstream PR](https://github.com/sgl-project/sglang/pull/46084) · state: closed · merged: True

## Original PR description

## What

Moves 24 tests out of the always-on AMD PR stages and into the AMD extra workflow (`pr-test-amd-extra.yml`, `run-ci` + `run-ci-extra`). They are the tests CUDA already keeps in its extra tier: the `basic_perf` throughput/latency/API tests, `test_torch_compile`, LoRA eviction/drainer/logprob-diff, the RL weight-update tests, `test_vlm_models` / `test_generation_models`, and the 4-GPU `test_pp_single_node_extra` / `test_lora_gpt_oss_20b_logprob_diff`.

## Why

On recent PR runs that reached the GPU stages, PR Test (AMD) took a median of about 4.3 h from start to the last job, against about 1.6 h for PR Test on CUDA. These 24 files account for about 125 min of AMD runner time per PR run, measured from the per-file `elapsed=` lines in job logs. The largest are `test_serving_throughput` (19 min), `test_pp_throughput` (12 min) and `test_torch_compile` (7.5 min).

## Notes for the reviewer

- A new suite, `extra-b-test-4-gpu-amd`, and its job take the two 4-GPU files, with the same container env as `stage-c-test-4-gpu-amd`.
- The extra-a jobs are now sharded 2 / 3 / 2. The existing comment argued for a single shard when the suite was ~4 min; with these files, 1-gpu-large is ~1.5 h.
- `pr-test-amd.yml` shards:
  - 1-gpu-small: 14 → 12, so 3 waves at `max-parallel: 4` instead of 4.
  - 1-gpu-large: 3 → 2.
  - 2-gpu-large: 2 → 1.
  - The `wait-for-stage-b-amd` counts are updated to match.
- ~~Scheduled `pr-test-amd.yml` runs still chain the extra workflow through `call-pr-test-amd-extra`, so main keeps this coverage twice a day.~~ **Correction:** that scheduled call was being skipped, because the skipped label gate on scheduled runs also skipped the jobs after it. So from this merge (Oct 24) until #47244 (Oct 29) these tests ran only on PRs labeled `run-ci-extra`, not on main. #47244 fixed the call, and scheduled runs now run the AMD extra suites.

Related: #46085 (large-model tests to nightly), #46086 (parallel shards). The three PRs are independent and merge cleanly in any order.
