## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR refreshes all six pages:

1. **Twelve open InferenceX PRs are overlaid** (table below). They add DeepSeek-V4 NVFP4 B300 Dynamo+SGLang, a knob-tuned GLM-5.2 FP8 B300 lane and DeepSeek-V4.1-Flash GB300 DEP2/DEP16 disaggregation. They also retune GLM-5.2 GB300 and B200, Qwen3.5 H200, Qwen3.8-Flash-Next B200 and B300, and Muse Spark Open B200 and GB200.
2. **The pages sync to InferenceX `main`** (`b9c6fc30`). Muse Spark Open gains H200 and H100 and a retuned B300.
3. **DeepSeek-V4.1-Flash GB300 SGLang** ([InferenceX #4033](https://github.com/SemiAnalysisAI/InferenceX/pull/4033), merged) is now shown as verified. Its merge was never ingested by the dashboard, so the lane is pinned to the run its `/use` comment named (details below).
4. **Pipeline-parallel workers are labeled correctly.** PP4 prefill workers used to read "prefill TP1"; they now read "prefill PP4".

## How the commands are produced

The pipeline is the same as in #44712, with these changes:

- **srt-slurm v2.59.** [InferenceX #4167](https://github.com/SemiAnalysisAI/InferenceX/pull/4167) moved InferenceX to srt-slurm v2.59.1, which adds a job-local OpenTelemetry collector to every Dynamo job.
  - [InferenceX #4180](https://github.com/SemiAnalysisAI/InferenceX/pull/4180) and [InferenceX #4300](https://github.com/SemiAnalysisAI/InferenceX/pull/4300) switch it off with `enabled: false`, so their jobs launch nothing for it. The renderer now drops such disabled service declarations.
  - An enabled collector would still stop the sync, so that a rule decides it.
  - Measured v2.59 lanes render exactly as their real runs launched: the worker commands and environments equal the job logs of Muse Spark Open H100 ([run 38925660934](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/38925660934)) and B300 ([run 38897356089](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/38897356089)), and Qwen3.8-Flash-Next H200 ([run 39109720946](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/39109720946)).
- **Never-ingested merges.** Some merged PRs get no Merge Ingest run, so the dashboard never receives their data. The pipeline now pins such a lane to the PR's successful `/use` run, as for [InferenceX #4033](https://github.com/SemiAnalysisAI/InferenceX/pull/4033). This applies only to merges older than two days, made after InferenceX's Merge Ingest workflow existed.
- **Release images.** The build commit of a release image (`v0.5.22-cu130` is `baa9befa`) can sit on a release branch, and the KV-tier check now fetches it. Without this, Qwen3.8-Flash-Next H200 would lose the Mooncake tier that #45039 offers.
- **Labels.** Worker shapes include pipeline parallelism ("prefill PP4"). This changes the labels, and so the share links, of 14 deployments: GLM-5.2 GB300 ([InferenceX #4300](https://github.com/SemiAnalysisAI/InferenceX/pull/4300)), Qwen3.5 NVFP4 GB300 ([InferenceX #4162](https://github.com/SemiAnalysisAI/InferenceX/pull/4162)), and the Qwen3.5 FP8 GB300 `pp-pareto` / `pp-midcurve` lanes.
- **Rules.** These are kept as submitted:
  - Dynamo-only (dropped in the SGLang-router variant):
    - worker flags `--router-mode`, `--router-replica-sync`, `--router-session-affinity-ttl-secs`, `--router-decode-active-request-weight`, `--active-decode-blocks-threshold`, `--active-prefill-tokens-threshold` and `--active-prefill-tokens-threshold-frac`;
    - env `DYN_ROUTER_ACTIVE_REQUEST_EXPIRY_SECS`, `DYN_ROUTER_QUEUE_THRESHOLD`, `DYN_TCP_CHANNEL_BUFFER`, `DYN_TOKENIZER`, `DYN_TOKENIZER_CACHE`, `DYN_TOKENIZER_CACHE_BYTES` and `DYN_SGL_GATEWAY_WORKERS`.
  - Serving configuration:
    - worker flags `--disaggregation-decode-enable-radix-cache` and `--default-chat-template-kwargs`;
    - env `SGLANG_DFLASH_EAGER_DRAFT_SAMPLER`, `SGLANG_DSA_MQA_LOGITS_FREE_MEM_FRACTION` and `TVM_FFI_CUDA_ARCH_LIST`.
- **Cluster environment** (#44228). The H100 cluster that runs Muse Spark Open H100 exports `NCCL_CUMEM_ENABLE=1`, as the worker fingerprint of run 38925660934 shows. Its commands carry it.

Each lane is still rendered at the exact commit of the run that produced its data, or at the PR head while in progress.
- **Removed (SA-only settings):** the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment).
- **Replaced with placeholders:** IPs, ports and NICs.
- **Derived variants:** router and KV-offload variants that were not run are derived and labeled "Derived — not run".

The data files are generated, so there is no hand-written code to review here.
