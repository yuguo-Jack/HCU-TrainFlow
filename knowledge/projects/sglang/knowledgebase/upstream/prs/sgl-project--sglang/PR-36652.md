# [Perf] DSv4/4.1-Flash: Improve TRTLLM-Gen Attention Accuracy and Performance

[Upstream PR](https://github.com/sgl-project/sglang/pull/36652) · state: open · merged: False

## Motivation

Follow-up to #30805 that fixes accuracy, enables all runtime features, and improves e2e perf by fusing/removing glue operations.

## Modifications

Manages metadata in a native-way to the TRTLLM-gen attention kernel API (also more closely matching how TRT-LLM integrates the kernel). Modifications regarding runtime features like DP + MTP that interact with this particular kernel, are handled specifically to this backend - generic issues are addressed in separate PRs.
