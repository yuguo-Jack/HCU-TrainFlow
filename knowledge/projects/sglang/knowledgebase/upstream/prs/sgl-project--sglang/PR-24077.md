# Extend Qwen3-VL EAGLE3 draft support

[Upstream PR](https://github.com/sgl-project/sglang/pull/24077) · state: open · merged: False

## Original PR description

## Motivation
Extend Qwen3-VL EAGLE3 draft model support to include draft models that ship with `Eagle3LlamaForCausalLM` as their `architectures` field (vLLM-style class name; e.g. [AngelSlim/Qwen3-VL-30B-A3B-Instruct_eagle3](https://huggingface.co/AngelSlim/Qwen3-VL-30B-A3B-Instruct_eagle3) ). The canonical SGLang arch name for these drafts is `LlamaForCausalLMEagle3`, so currently any draft published with the `Eagle3LlamaForCausalLM` alias fails to load because the model registry has no entry for that name.

## Modifications
- In `model_config._config_draft_model`, normalize the `Eagle3LlamaForCausalLM` alias to `LlamaForCausalLMEagle3` for draft models. This routes such drafts through the existing `LlamaForCausalLMEagle3` implementation without needing a registry alias or any new draft model code.
