# [Perf] dsv41: Use the fused ratio-2 compressor in the prefill graph

[Upstream PR](https://github.com/sgl-project/sglang/pull/46230) · state: closed · merged: True

## Original PR description

Inside the DeepSeek-V4.1 prefill CUDA graph, the ratio-2 compressor ran its torch path (dozens of small launches per source layer, plus a separate index-K store), because the fused compressor reads per-request extend offsets that were not graph-static. Eager extend already uses the fused kernel.

- The prefill graph's metadata carries `low_ratio_extend_offsets`, an int32 `[2, request slots]` tensor of each request's first row and row count, refreshed in place at replay. Slots past the batch hold no rows, and DP padding rows belong to no request.
- When the compressor uses the fused gate, the captured source projection writes `| kv | score |` rows into one buffer, and `_low_ratio_compress_fused` takes that projection (`projected=`) with the static offsets.
- Compressors without the fused gate keep the torch path and its separate `kv` and `score` buffers, unchanged.
