- 1am9trash · comment · 2026-09-08T03:30:22Z · [source](https://github.com/sgl-project/sglang/pull/38373#issuecomment-5578676917)

Hi, @hnyls2002 

Thanks for the refactor to remove hack env var. Here are some concerns.

The original name `unified` described a single per-layer buffer that concatenates the SWA and the compressed (C4/C128) cache, so attention indexes one pool instead of separate SWA / C4 / C128 pools.

The new name ring highlights how SWA is addressed: a per-request circular window, `req_slot * stride + pos % stride`, as opposed to a paged SWA token pool.

`ring` is a good name for the SWA addressing; the compressed half is still indexed as pages. Would `{paged, ring}` be easy to misread as "paging vs no paging"?

- amd-danli103 · comment · 2026-09-08T03:41:28Z · [source](https://github.com/sgl-project/sglang/pull/38373#issuecomment-5578787559)

hi @hnyls2002 , thanks for splitting layout out of SGLANG_HACK_FLASHMLA_BACKEND — that part I agree with. The layout should not live in a kernel HACK env. I'd rather not rename the layout to ring, though.

unified named the pool topology: one per-layer row address space that concatenates SWA and the compressed (C4/C128) region, so attention indexes one logical pool instead of separate SWA / C4 / C128 pools. That is still the thing this path is.

ring only names how the SWA prefix is addressed (`req_slot * stride + pos % stride`). The compressed half is still page-indexed (swa_pages + page_index), and C4/C128 compress *state* is already a per-request ring on the paged path too (`get_ring_size(4)` etc.). After the rename, ring means three different objects in the same files (SWA window, C4 state, the layout flag), which is easy to trip over.

So maybe `--dsv4-kv-layout {paged, unified}` matches what the flag actually selects, and we can leave the FLASHMLA env to the paged-layout kernel choice. If unified is too overloaded against UnifiedCache / enable_unified_memory, I would like to propose `{paged, swa-ring}` be the next-best pair — it at least says which ring, and does not claim the compressed half is a ring. 

Could you pls take these into consideration? Thank you so much!
