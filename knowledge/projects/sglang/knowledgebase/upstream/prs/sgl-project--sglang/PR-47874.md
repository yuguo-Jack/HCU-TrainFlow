# [Fix] SMG: Track in-flight requests for P2C in regular HTTP routing

[Upstream PR](https://github.com/sgl-project/sglang/pull/47874) · state: open · merged: False

## Original PR description

## Summary

Fix missing in-flight request tracking for `PowerOfTwoPolicy` in regular HTTP routing.

The regular HTTP router currently creates a `WorkerLoadGuard` only for `cache_aware` and `manual`. However, P2C also relies on `worker.load()` when comparing request loads.

This change adds `power_of_two` to the existing guard condition, reusing the established request lifecycle management.

## Changes

- Enable `WorkerLoadGuard` for `power_of_two`.
- Keep the fix minimal without changing other routing policies.

## Validation

The original issue was reproduced using three local mock workers, with `cache_aware` as a positive control.

The fix reuses the existing `WorkerLoadGuard` mechanism.

Post-fix validation and automated regression testing have not yet been documented.

## Related Issue

Fixes #47868

This is a narrowly scoped alternative to the broader approach proposed in #47871.
