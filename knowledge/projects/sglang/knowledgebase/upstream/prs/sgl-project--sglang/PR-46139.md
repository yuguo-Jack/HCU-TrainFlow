# [Feat] msa: Add MSA-v1 decode and NVFP4 KV cache kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/46139) · state: closed · merged: True

## Original PR description

## Summary
Standalone kernels for the MiniMax-M3.1 NVFP4 KV cache:
- MSA-v1 decode planning, FlashInfer decode wrapper, and compact NVFP4-to-FP8 dequant.
- NVFP4 K/V/index store.
- Page-row host/device transfer used by HiCache.

No caller in main yet; the backend that uses them is the next PR in the stack.

## Changes to existing code
None.

## Verification
The kernel tests import the NVFP4 pool and land with it in the next PR (test_msa_v1_decode_plan, test_minimax_m31_nvfp4, test_minimax_m31_page_row_views).


Cut byte-for-byte from #45925 (MiniMax-M3.1-Flash support) at 10e655aa98.
