# [Fix] diffusion: keep host-resident embedding scales on CPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/44223) · state: open · merged: False

## Original PR description

## Motivation

Host-resident INT8 embeddings can retain quantization scales on CUDA while their weights and lookup indices are on CPU, causing device mismatches during embedding lookup.

## Modifications

* Move the restored embedding module to CPU before installing host-gather hooks, keeping its weights, scales, and buffers together.
* Add CUDA regressions for rowwise and scalar INT8 embeddings.

## Accuracy Tests

Recorded validation: 14 focused tests passed.

The new regressions verify CPU weights and scales, CUDA outputs, and exact equality with the original embedding lookup.
