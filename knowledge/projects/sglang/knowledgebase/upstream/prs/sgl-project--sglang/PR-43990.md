# fix: normalize host logprob rows in scheduler

[Upstream PR](https://github.com/sgl-project/sglang/pull/43990) · state: open · merged: False

## Original PR description

## Motivation

The scheduler receives logprob rows from tensor and host-list backends. Unconditionally calling `.tolist()` on host-list rows raises `AttributeError` during decode or response construction.

## Modifications

Normalize logprob value/index rows only when they are tensors. Preserve already materialized Python lists, including targeted token-id rows, in the CPU move and decode paths. Add a regression that exercises host-list decode normalization.
