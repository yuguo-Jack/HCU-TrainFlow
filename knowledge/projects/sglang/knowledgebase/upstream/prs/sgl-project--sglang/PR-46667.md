# [Fix] function_call: preserve split InternLM tool call markers

[Upstream PR](https://github.com/sgl-project/sglang/pull/46667) · state: open · merged: False

## Original PR description

Fixes #46661

InternLM emits `<|action_start|>` and `<|plugin|>` as separate tokens. After the first streamed tool call, the detector currently clears the buffer when the next call's partial start marker arrives, so subsequent tool calls are dropped.

Keep a suffix that can still become the next start marker while continuing to suppress already-emitted text. Add a CPU regression test using the token-by-token chunking from the issue.

Tests:
- `python -m py_compile python/sglang/srt/function_call/internlm_detector.py test/registered/unit/function_call/test_internlm_detector.py`
- Isolated parser regression reproduces two calls with tool indexes 0 and 1.
- The focused pytest collection is blocked on this Windows host by SGLang's Linux-only `resource` dependency; CI should run the repository test in its supported environment.
