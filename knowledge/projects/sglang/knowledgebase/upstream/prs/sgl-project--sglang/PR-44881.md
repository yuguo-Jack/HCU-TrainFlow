# [CI] pr-test-npu: Temporarily disable recommend-tests-from-coverage job

[Upstream PR](https://github.com/sgl-project/sglang/pull/44881) · state: closed · merged: True

## Original PR description

## Motivation

The `recommend-tests-from-coverage` job in `pr-test-npu.yml` downloads the coverage baseline from the Huawei OBS bucket (`sglang-npu.obs.cn-southwest-2.myhuaweicloud.com/coverage/test_case_map.json`), which currently returns HTTP 403. Although the job has `continue-on-error: true`, its failure is not filtered out by the PR test health check's root-cause filter, so it cascades fast-fail to all `base-b-test-*` jobs and blocks PRs.

## Modifications

- Temporarily disable the `recommend-tests-from-coverage` job via `if: false`, keeping the original condition as a comment for easy re-enable once the OBS bucket is fixed.

Note: `analyze-failure-report` still runs (`!cancelled()` semantics tolerate skipped needs) and gracefully handles empty `coverage_paths`.
