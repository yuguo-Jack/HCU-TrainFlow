# [Fix] ci: Repair main after the #39728/#46990 merge race and RUSTSEC-2026-0414

[Upstream PR](https://github.com/sgl-project/sglang/pull/47078) · state: closed · merged: True

## Original PR description

## Motivation

`main` has been red since today's merges, and it fails every open PR:

- **ruff F821**: `python/sglang/srt/managers/cache_controller.py:885` uses `MLATokenToKVPool`, which is not imported. #39728 added that line while #46990 replaced the `MLATokenToKVPool` import with `MLAKVView`. The two PRs merged minutes apart.
- **cargo deny (sgl-router)**: the new advisory [RUSTSEC-2026-0414](https://rustsec.org/advisories/RUSTSEC-2026-0414) flags `pulldown-cmark 0.13.4`. The patched version is 0.13.5.
- **base-a-test-cpu**: `test/registered/unit/mem_cache/test_hicache_dcp_host_pool.py` fails with `ValueError: config namespace 'memory' not published`. #46990 added `test_storage_shard_identity_follows_mla_layout`, which calls `_generate_storage_config()`. #39728 made that path call `get_memory()` and mocked it in the tests that existed then, but not in this new one.

## Modifications

- `cache_controller.py`: `rank_replicated=isinstance(device_pool, MLAKVView)`, the same check #46990 uses for `is_mla_model` in this file. `MLATokenToKVPool` subclasses `MLAKVView`, so MLA pools behave as #39728 intended.
- `sgl-router/Cargo.lock` and `rust/Cargo.lock`: `cargo update -p pulldown-cmark --precise 0.13.5`. Only the lock changes; `Cargo.toml` is untouched.
- `test_hicache_dcp_host_pool.py`: patch `cache_controller.get_memory` to return `hicache_storage_key_scheme="rank-suffix"` in that test, as the file's other tests do.

## Checks

- `ruff check --select=F401,F821,F823,UP037` and `ruff format --check` (0.15.1) pass on the file.
- `cargo deny check licenses bans sources advisories` in `sgl-router`: all ok. The same command fails on `main` with RUSTSEC-2026-0414.
- On a B200 devbox, `test_hicache_dcp_host_pool.py` passes 18/18; without the mock it fails with 4 failures and 20 errors, the same `memory not published` error as CI. `test_hicache_unified_key_scheme.py` (24) and `test_hicache_l3_object_layout.py` (25) also pass.
- `cargo check` passes for `sgl-router --all-targets` and the `rust/` workspace.
