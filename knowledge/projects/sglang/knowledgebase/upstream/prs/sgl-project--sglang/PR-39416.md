# [BugFix] Require auth on PD bootstrap PUT /route

[Upstream PR](https://github.com/sgl-project/sglang/pull/39416) · state: closed · merged: False

## Original PR description

## Motivation

Fixes #39400. Unauthenticated `PUT /route` on the PD bootstrap HTTP server lets any reachable client overwrite `rank_ip`/`rank_port`. Decode trusts that table for KV-transfer metadata, so this is route poisoning (DoS or metadata theft).

## Modifications

- Mutating bootstrap endpoints (`PUT /route`, `POST /register_dp_rank`) require `Authorization: Bearer <token>` and fail closed if the token is missing or wrong.
- Token is `SGLANG_DISAGGREGATION_BOOTSTRAP_AUTH_TOKEN`, else `--api-key`, else an auto-generated secret written in the engine parent before scheduler spawn so tokenizer and scheduler share it. Multi-node prefill broadcasts rank-0's token.
- Prefill `register_to_bootstrap` sends the bearer header. `GET /route`, `POST /query_dp_ranks`, and `/health` stay unauthenticated so decode can still rendezvous.
