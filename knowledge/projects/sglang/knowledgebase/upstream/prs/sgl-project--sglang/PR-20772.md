## Motivation

See #20332.
The API is `--model-loader-extra-config '{"load_tp_by_experts": true}'`. Alternative name suggestions are welcome.
Correctness is ensured by extensive unit tests in test_ep_to_tp_transform.py, which compares the weights with vanilla TP loading.

## Modifications
Added `"load_tp_by_experts": true` API, which swaps TP parameters for EP parameters in `FusedMoE`. Without setting `load_tp_by_experts`, everything is no-op.
Weights are transformed back to what TP expects in `DeepseekV2WeightLoaderMixin` after weight loading.
server_args.py asserts against models that doesn't go through deepseek weight loading code path.
Support for other models can be added in later PRs, which needs to fix the assert and call `ep_to_tp_transform()` on each MoE layer.
