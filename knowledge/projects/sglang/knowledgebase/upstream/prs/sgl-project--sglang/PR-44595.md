# [Test] diffusion: Load NVFP4 block scales through the weight loader in tests

[Upstream PR](https://github.com/sgl-project/sglang/pull/44595) · state: closed · merged: True

## Original PR description

Fixes `test_flux2_swizzled_scale_checkpoint_flashinfer_trtllm_matches_cudnn`, which fails on main since #44418 moved swizzled-to-linear scale conversion into the scale parameter's weight loader. The test bypassed the loader, so swizzled scales were treated as linear.

- `_build_layer` loads scales via `weight_scale.weight_loader`.
- `weight_scale_device` moves the tensor in place so the `nvfp4_scale_layout` tag is kept (avoids double conversion for swizzled checkpoints).
- SwiGLU reload step uses the loader too.

Tested on B300: main 1 failed / 12 passed; with fix 13 passed.
