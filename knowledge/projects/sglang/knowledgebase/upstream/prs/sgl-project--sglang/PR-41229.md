# [Perf] [AMD] attention: Spread uneven Triton decode batches across XCDs

[Upstream PR](https://github.com/sgl-project/sglang/pull/41229) · state: closed · merged: True

## Original PR description

## Motivation

Fixes #41151.

HIP hands workgroups to the eight XCDs of an MI300-series GPU round-robin, and the Triton decode stage-1 kernels put the batch on the fastest grid axis, so with an even batch each request's workgroups stay on one XCD or a fixed subset of them. When the batch is uneven, from CUDA-graph padding rows (`seq_len=1`) or a mix of long and short requests, the XCDs that hold the long requests set the kernel time while the others idle.

On ROCm, the Triton backend is the default for Gemma 4, MiniMax-M3, Olmo 3 and EXAONE, and for MLA models whose heads per rank are not 16 or 128, such as Kimi-K2 at TP 8.

## Modifications

- `get_num_kv_splits_triton` also writes a one-element `uneven_batch` flag: 1 when the shortest decode sequence is still shorter than the longest after the existing near-uniform rule.
- On HIP, for an even batch, the stage-1 kernels read the flag and, when it is set, rotate the request index across the grid: by head and split in the per-head kernel, by split only in the grouped (GQA/MLA) kernel, so the head tiles of one request and split still share the KV they read. Balanced batches, odd batches and CUDA run as before.
- `TritonAttnBackend` passes the flag through, with a static buffer for CUDA graphs.

Outputs are bitwise identical with and without the rotation.

- siliangchen-amd · comment · 2026-10-18T13:20:04Z · [source](https://github.com/sgl-project/sglang/pull/41229#issuecomment-6250403316)

Thanks! @BBuf Rebased onto main and added `test_decode_attention_uneven_batch_graph_replay` to `test_triton_attention_kernels.py`, which runs in the AMD stage-b suite. It captures one decode graph and replays it over uniform, padded (`seq_len=1` rows) and ragged batches, refreshing the metadata through `_apply_cuda_graph_metadata` before each replay. Each replay has to see its own `uneven_batch` flag in the captured buffer and match an eager run without the rotation, for both the per-head and the grouped kernel. It passes on AMD GPUs, and it fails if the replay stops passing the flag buffer, if the flag gets stuck at 1, or if the rotation stops being a permutation.
