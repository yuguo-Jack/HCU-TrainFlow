# [Fix] hicache: Fix MooncakeStore None storage_config and address validation

[Upstream PR](https://github.com/sgl-project/sglang/pull/46802) · state: open · merged: False

## Original PR description

## Motivation

In `python/sglang/srt/mem_cache/storage/mooncake_store/mooncake_store.py`:
1. `MooncakeStore.__init__` accepts `storage_config: HiCacheStorageConfig = None` and guards `if storage_config is not None:` across every branch except `self.should_split_heads = storage_config.should_split_heads`, which raises `AttributeError: 'NoneType' object has no attribute 'should_split_heads'` when `MooncakeStore()` is initialized with the default `storage_config=None`.
2. In `standalone_storage` mode, `mem_pool.allocator` was accessed directly without guarding `mem_pool is None`, raising `AttributeError` instead of the descriptive `RuntimeError` when `mem_pool` is omitted.
3. `MooncakeStoreConfig.from_file()` and `MooncakeStoreConfig.load_from_extra_config()` checked `"master_server_address" not in config and "client_server_address" not in config` (membership only), whereas `MooncakeBaseStore._load_config()` checks `extra_config.get("master_server_address") is not None or extra_config.get("client_server_address") is not None`. When serialized configs contain `{"master_server_address": None, "client_server_address": None}`, `load_from_extra_config` / `from_file` did not raise `ValueError`.

## Modifications

- Guard `self.should_split_heads = bool(storage_config is not None and storage_config.should_split_heads)`.
- Check `if mem_pool is None or not isinstance(mem_pool.allocator, MooncakeHostTensorAllocator):` when validating `MooncakeHostTensorAllocator` in `standalone_storage` mode.
- Check `.get("master_server_address") is None and .get("client_server_address") is None` in `from_file()` and `load_from_extra_config()`.
- Add unit tests in `test/registered/unit/mem_cache/test_mooncake_ssd_offload_path.py`.
