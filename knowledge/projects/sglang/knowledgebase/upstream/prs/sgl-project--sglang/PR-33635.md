## Modifications

<!-- Detail the changes made in this pull request. -->

- **Implement `MellumAttention.forward_prepare_npu`**: Since each Mellum layer has its own `rotary_emb`, it cannot reuse the `Qwen3MoeAttention` shared cos/sin priming trick that computes cos/sin only at `start_layer`. Instead, each layer calls `rotary_emb.get_cos_sin_with_position` to compute its own RoPE cos/sin, then runs the fused `split_qkv_rmsnorm_rope` op for QKV split + RMSNorm + RoPE.

- **Fix hybrid SWA decode accuracy** (`ascend_backend.py`): Tighten the FIA v2 entry condition to `self.is_hybrid_swa and self.use_fia`, and add a `BSND`-layout path for SWA-layer decode — using the static `swa_mask` to encode the sliding window (since decode has `S1=1`, the kernel ignores `pre_tokens`), while other layers still use the `TND` path with `pre_tokens` and the fixed 2048-wide causal mask.

- **Align graph-replay CPU input attribute name** (`npu_graph_runner.py`): Add a branch in `_get_update_attr_name` so that the `use_fia + hybrid SWA + MHA` combination (i.e. Mellum running with FIA on NPU) returns the v2 kernel's parameter name `actual_seq_kvlen`, keeping the graph-replay seq-len key consistent with the `npu_fused_infer_attention_score_v2` formal parameter actually consumed in the forward pass (v1 kernel uses `actual_seq_lengths_kv`; v2 uses `actual_seq_kvlen`). This fixes the accuracy error in graph mode.
