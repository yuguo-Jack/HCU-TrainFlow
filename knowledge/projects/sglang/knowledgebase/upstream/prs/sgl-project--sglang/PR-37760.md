# [CI][NPU] Fix kimi_k2_6 16p in64k perf test and dsv4-flash testcases

## Motivation

1. The kimi_k2_6 W4A8 16p in64k/out1k performance test uses `--chunked-prefill-size 262144`. With the full 64K-token input prefilled in one chunk, peak activation memory is high and the server is prone to recomputation/oom-adjacent behavior on A3 devices, which destabilizes the nightly latency measurement. Reducing it to `32768` keeps prefill stable and restores reproducible end-to-end latency.
2. The DSV4-Flash perf/accuracy tests still use the legacy ZBAL env configuration, by the DEEPEP + war-barrier configuration along with tuned launch arguments (mem-fraction, max-prefill-tokens, chunked-prefill, kv-cache-dtype, warmup requests). `run_npu_testcase.sh` also needs to source the vendor custom-op env scripts to support DSV4-Flash.

## Modifications

- `test/registered/npu/performance/kimi_k2_6/test_npu_kimi_k2_6_w4a8_16p_in64k_out1k_100ms.py`: change `--chunked-prefill-size` from `262144` to `32768`.
- `test/registered/npu/performance/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_in32k_out1k_50ms.py`: replace ZBAL envs with DEEPEP (`DEEPEP_HCCL_BUFFSIZE=2048`, `SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=35`) and war barrier envs; add `SGLANG_SET_CPU_AFFINITY`, `HCCL_OP_EXPANSION_MODE=AIV`; add `--max-prefill-tokens 80000`; `mem-fraction-static 0.7 -> 0.68`; `kv-cache-dtype auto -> bfloat16`; `warmup_requests 0 -> 16`.
- `test/registered/npu/performance/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_in8k_out1k_50ms.py`: same env/arg changes as the in32k case.
- `test/registered/npu/performance/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_1p1d_16p_in8k_out1k_50ms.py`: replace ZBAL envs with DEEPEP + war barrier; add `SGLANG_NPU_USE_MULTI_STREAM`; prefill node `mem-fraction 0.62 -> 0.68`, `max-prefill-tokens 70000 -> 80000`, `chunked-prefill -1 -> 131072`; decode node `chunked-prefill 32768 -> -1`; drop 56 from cuda-graph bs list; `warmup_requests 0 -> 16`.
- `test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_w8a8_8p_gpqa.py`: `HCCL_BUFFSIZE 1400 -> DEEPEP_HCCL_BUFFSIZE 2048`; add war barrier envs.
- `python/sglang/test/ascend/e2e/run_npu_testcase.sh`: source `opp/vendors/customize` and `opp/vendors/custom_transformer` `set_env.bash` (with `|| true` tolerance) to adapt DSV4-Flash custom ops.
