# [CI] 1-gpu-small: Move 1-gpu-large tests that pass on the 5090

[Upstream PR](https://github.com/sgl-project/sglang/pull/41231) · state: open · merged: False

## Original PR description

## Summary

Run every base-b, base-b-kernel-unit, base-b-kernel-benchmark and extra-a file registered on 1-gpu-large (H100) on an RTX 5090 (SM120, 32 GB) with the CI install and environment, and move the ones that pass without losing coverage. A file with tests skipped on the 5090 only moves when those tests also skip on H100 (ROCm-, SM100- or missing-op-gated). The diffusion bcg, SANA-Video 2 and unit lanes move to the 5090 under the same rule.

Per-commit 1-gpu-large est_time against main (`f75232cb42`):

| Stage | main | this PR |
|---|---|---|
| base-b | 130 files / 169.5 min | 44 / 65.5 min |
| base-b-kernel-unit | 230 / 143.1 min | 25 / 28.7 min |
| base-b-kernel-benchmark | 67 / 22.9 min | 5 / 4.8 min |
| extra-a | 39 / 189.3 min | 22 / 136.9 min |
| **Total** | **524.8 min** | **235.9 min** |

About 289 min of per-commit H100 est_time moves to the 5090 pool, plus most of the diffusion unit lane (~30 min).

- base-b-kernel-unit: 203 files move. The kernel lane runs 4 shards on 1-gpu-small and 1 job on 1-gpu-large (was 1 and 2).
- base-b-kernel-benchmark: 62 of 67 files move to a new `benchmark-test-1-gpu-small` job.
- base-b: 85 files move; extra-a: 17 files move. Partitions are sized from est_time by compute_partitions.py.
- Split 9 files whose H100-bound classes (FA3, models that do not fit in 32 GB, an H100-tuned throughput floor) move to a sibling file on 1-gpu-large, so the rest of the file runs on 1-gpu-small: `test_deterministic`, `test_hicache_variants`, `test_spec_mixed_chunk`, `test_spec_standalone_extra`, `test_page_major_gpt_oss`, `test_page_major_qwen_hybrid`, `test_vision_openai_server_a`, `test_vlm_input_format`, `test_srt_engine`.
- Diffusion: the bcg job and `test_sana_video2` move to 1-gpu-5090. The unit suite runs on 1-gpu-5090; a new `multimodal-gen-unit-test-h100` job keeps the three files with H100-only cases (`test_kandinsky6_bf16_dtype`, `test_mxfp8_online_gemm`, `test_subblock_sparse_attention`).
- `test_nvfp4_marlin`, `test_convrot_int8` and `test_compressed_tensors_fp4_numeric` were already registered on 1-gpu-small; drop their 1-gpu-large duplicates.
- Raise est_time to the measured 5090 duration where the H100 estimate was more than 1.5x low (about 60 files).
- Point new kernel correctness tests and benchmarks at 1-gpu-small in test/README.md and the write-sglang-test / add-jit-kernel / ci-workflow-guide skills; 1-gpu-large stays for SM90-only kernels.

Kept on 1-gpu-large: FA3 / FlashMLA / DeepGEMM / HPC-Ops / SM90-only kernels; weights over ~26 GB or two resident models; H100-tuned perf thresholds; int8_scaled_mm (no SM120 kernel); lmms_eval (not installed on Blackwell runners); and files that fail on SM120 (Triton shared-memory limits, FlashInfer and deep-select top-k, dsv3_fused_a_gemm / tiny_gemm mismatches, EAGLE3 deterministic parity, the hicache TMA benchmark).

The H100-side est_time of the split-off sibling files is estimated, not measured.
