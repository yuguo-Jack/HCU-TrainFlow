# [CI] rust-server: Raise the ChunkEvent frame-size cap to 152 bytes

[Upstream PR](https://github.com/sgl-project/sglang/pull/44773) · state: closed · merged: True

## Original PR description

## Motivation

`cargo-workspace` (PR Test (Rust workspace)) fails on main and on every PR that runs it since #42637 merged:

```
---- message::response::tests::chunk_event_frame_stays_small stdout ----
ChunkEvent grew to 152 bytes; keep rare columns behind ChunkExtras
test result: FAILED. 330 passed; 1 failed
```

#42637 keeps the matched stop token in the per-chunk frame, which grows `ChunkEvent` from 144 to 152 bytes. That field is the intended change, not a rare column that belongs behind `ChunkExtras`.

## Modifications

`chunk_event_frame_stays_small` caps `ChunkEvent` at 152 bytes and notes why next to the assertion. No product code changes.

## Test plan

- `cargo test -p sglang-server --lib` on main with this change: 331 passed, 0 failed (`chunk_event_frame_stays_small` fails on main without it).
- `cargo fmt --all -- --check` clean.
