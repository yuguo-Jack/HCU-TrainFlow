# [CI] muse_spark: Use complete local checkpoints in model tests

[Upstream PR](https://github.com/sgl-project/sglang/pull/45428) · state: closed · merged: True

## Original PR description

## Motivation

close #45392

Muse-Spark fork CI can load cached weights but still fail with a gated-repository 403 when `AutoProcessor` probes `chat_template.json` using the Hub model ID ([failing job](https://github.com/sgl-project/sglang/actions/runs/39358812163/job/118528170786)). The B300 PD and B200 unified-memory tests now use complete local snapshots and skip model-credential setup on a cache hit.

## Modifications

- Add a Muse-Spark-specific test helper that checks `DEFAULT_MODEL_CACHE_DIR` and the current HF snapshot. It requires nonempty config, every indexed safetensors shard (or the single weight file), and the main model's tokenizer, processor, template, generation and quantization assets. DFlash only requires config and weights. Incomplete caches retain the Hub ID for normal downloading.
- Resolve the main checkpoint before credential setup in both tests. A cache hit skips reading `HF_MUSE_SPARK_TOKEN`, creating/starting `token_env`, and registering token cleanup. Hub fallback retains the existing credential lifecycle. Draft checkpoint resolution remains independent.
- Keep the generic `try_cached_model()` and its containing `test_utils.py` unchanged from the PR base.

## Accuracy Tests

- Applicable pre-commit hooks passed for all changed files.
- Local isolated cache checks passed against temporary filesystem fixtures, covering complete and incomplete checkpoints.
- Both test setup paths passed isolated smoke checks using the real HF cache resolver against temporary `refs/main`/snapshot directories. A guard raises if a cache hit reads `HF_MUSE_SPARK_TOKEN`; checks also verify existing `HF_TOKEN` is unchanged on hits and restored after fallback cleanup. This guard failed on the previous implementation and passes with this change.
- Verified `test_utils.py` and `test/registered/unit/model_loader/test_weight_utils.py` match the PR base byte-for-byte.
- Full unit-file execution was blocked during import by missing `orjson` in the local environment. B200/B300 GPU tests have not been run locally for this change.

Not applicable: no inference implementation or thresholds changed.
