# [DeepSeek-V4.1] Extend remaining fusion batch limits to 1024 rows

[Upstream PR](https://github.com/sgl-project/sglang/pull/47364) · state: open · merged: False

## Original PR description

Supersedes #41628, which was closed for inactivity.

## Motivation

Upstream now covers the original PR's larger-row norm/quantization fusions, scale-row addressing, scale padding and query RoPE/store fusion. The remaining change is extending the existing Blackwell decode/verification paths through 1,024 rows.

## Changes

- Extend the CUDA target-verification `wo_a` path and HC post-split dispatch through 1,024 rows.
- Extend the fused MoE all-reduce dispatch and deferred-output-shape range through 1,024 rows, retaining push-slot and counter capacity checks.
- Give DeepSeek-V4.1 TP4 a dedicated 12 MiB push slot and 1,024 counters. Its two slots across four ranks use 96 MiB per rank; other layouts retain their existing communicator capacity.

No CUDA kernels or arithmetic are changed. Superseded norm and RoPE implementations are omitted in favor of current upstream.

## Validation

The remaining limits and TP4 workspace sizes match the original PR. Python syntax and undefined-name checks pass. No full suite or GPU validation was rerun after the upstream merge.
