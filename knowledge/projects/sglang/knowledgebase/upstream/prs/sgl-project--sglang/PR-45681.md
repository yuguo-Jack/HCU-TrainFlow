## Motivation

Independent gate/up A factors require matching rank halves during expansion. The stock virtual-expert hook reused the gate half for the up output: with `x=1`, `A_gate=2`, `A_up=3`, `B_gate=5`, `B_up=7`, it produced `[10,14]` instead of `[10,21]`. Inactive routes and absent/disabled adapters also need complete private outputs without consuming stale or NaN payloads.

## Changes

- Keep one full-`2R` shrink and select the matching A half inside the existing expansion. Internal rank/half-width constants and half-local masks support ragged widths without another projection launch or tensor. The default expansion keeps its original formulas.
- Bound raw virtual IDs and adapter slots before histogram, address or payload formation. Preserve borrowed inputs, valid adapter 0 and original-width int64 validity; shared routing retains negative routes. Missing, disabled and out-of-range adapters cannot read private deltas or contribute NaN scores.
- Complete owned LoRA outputs in their existing kernels and guard capacity-grid programs before grouped division/modulo. Empty helpers preserve their return/output contracts. Activation and shared-outer rank reductions retain active arithmetic and rounding.
- Prepare paired per-expert gate-B/down-A routing once on the main stream, aligning at each stage's actual block size. Release the shared raw owner before projection buffers and the side-stream fork. Existing cache contracts and staged fallbacks remain for unsupported pairings, including global-ID EP.

- Remove unused expert-ID sanitizers and the unused metadata-bearing activation branch. Keep the production three-tensor activation and existing producer/reduction contracts.

## CI cadence

The CUDA virtual-expert and experimental shared-outer LoRA suites now run in opt-in `extra-a-test-1-gpu-small`. CPU runtime checks and the core routing-kernel tests remain in base CI; the existing XPU registration is preserved.

Across the stack, six existing CUDA file registrations move from base CI to extra/nightly, removing 854 estimated GPU-seconds from the default gate (registration estimates, not a measured wall-time saving). All test bodies, cases, inputs, assertions and tolerances are unchanged. Full before/after discovery validates 2,535 files and 3,077 registrations, with every moved file selected in its enabled destination suite. Configured hooks pass; native tests were not rerun for this registration-only update.
