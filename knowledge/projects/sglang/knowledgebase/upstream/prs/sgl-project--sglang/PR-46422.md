# [Feat] unified_cache: Support MHA / QSA + Mamba models with PLE slot states in the direct external linker

[Upstream PR](https://github.com/sgl-project/sglang/pull/46422) · state: open · merged: False

## Original PR description

## Motivation

The direct external linker (`--enable-unified-cache-external-linker`) accepts FULL + MAMBA models only when the full-attention pool is plain MLA (#44977, Kimi-K3). It also rejects any model whose Mamba pool carries registered slot states. Two families with cookbook linker options therefore fail at startup with `ValueError: The direct external linker supports FULL + MAMBA models only with a plain MLA pool ...`:

- Qwen3.5 (MHA + GDN). The AgentX tables on `Qwen3.5.mdx` offer the Mooncake linker as a KV offload option.
- Qwen3.8-Flash-Next / Qwen4-Exp (`Qwen3.8-Flash-Next.mdx`). Its full-attention layers are QSA: an MHA KV pool plus a paged compressed-K indexer cache. Its Mamba slots also carry the PLE short-conv windows and the N-gram history.

## Modifications

- `_build_mamba_device_pool_group` accepts an MHA full-attention pool, and a `QSATokenToKVPool` (MHA KV plus compressed indexer). An MHA KV entry stores each layer's K and V in one per-page object, the same layout as the Mamba + SWA group.
- QSA compressed indexer: a new `INDEXER` entry derived from the KV transfer. A full page holds whole compression groups (QSA requires `page_size % ratio == 0`), so full page `p` maps to compressed rows `[p * page_size / ratio, (p + 1) * page_size / ratio)`. The per-request pending ring is not transferred, because a linker hit always ends on a page boundary, where the pending group is empty.
- Mamba slot states: a new `MAMBA_SLOT_STATE` entry derived from the Mamba transfer. It packs the short-conv state of each PLE layer and the N-gram history row of the same slot. Each short-conv state loads on its own layer. The N-gram history is read before the first layer, so it loads with the first Mamba layer, which is the layer `get_ngram_context` already waits for. The Mamba + SWA group gains the same entry.
- Still rejected: int8 Mamba checkpoints, unified memory, DCP > 1, and packed MTP draft KV. The Qwen3.8-Flash-Next AgentX cell that runs MTP 3-1-4 therefore still needs packed-draft support, which is a follow-up.

## Accuracy Tests

The oracle follows `test_unified_cache_linker_kimi_linear.py`. Four LongBench prompts are cut to `PREFIX + 1` tokens and warmed, then extended with a 63-token random suffix. The 32 greedy output ids and logprobs from a device hit must equal those from a linker hit after `/flush_cache` (`cached_tokens_details.host == PREFIX`). Setup: 1x B300, TP1, Mooncake over TCP, `--page-size 64 --mamba-radix-cache-strategy extra_buffer --mamba-track-interval 128 --kv-cache-dtype fp8_e4m3`.

| Model | Setting | Tree | Result |
|---|---|---|---|
| Qwen3.5-2B | prefix 1024, deterministic | main | startup `ValueError` (plain MLA only) |
| Qwen3.5-2B | prefix 1024, deterministic | this PR | 4/4 ids equal, max abs logprob diff 0.0 |
| Qwen3.8-Flash-Next-NVFP4 | prefix 1024, flashinfer GDN | main | startup `ValueError` |
| Qwen3.8-Flash-Next-NVFP4 | prefix 1024, flashinfer GDN | this PR | 4/4 equal, diff 0.0 |
| Qwen3.8-Flash-Next-NVFP4 | prefix 1024, flashinfer GDN | this PR, slot states not transferred (control) | 0/4 equal, diff up to 5.5 |
| Qwen3.8-Flash-Next-NVFP4 | prefix 4096, deterministic | this PR | 4/4 equal, diff 0.0 |
| Qwen3.8-Flash-Next-NVFP4 | prefix 4096, deterministic | this PR, QSA indexer not transferred (control) | 0/4 equal, diff 1.8-2.8 |
| Qwen3.8-Flash-Next-NVFP4 | prefix 4096, deterministic | this PR, slot states not transferred (control) | 0/4 equal, diff 1.5-3.4 |

- The 4096 prefix exceeds the model's 2048-token indexer budget, so QSA top-k selection reads the restored compressed keys. At 1024 every token is selected and the indexer has no effect.
- Above the budget, the default kernels are not run-to-run deterministic: two device hits agree on only 1/4 at 4096. Those runs therefore use `--enable-deterministic-inference --attention-backend triton --linear-attn-{prefill,decode}-backend triton`, under which two device hits agree 4/4 with diff 0.0.
- The controls drop the named entry in a local build only.

## Tests

- `test_linker_pool_assembler.py`:
  - slot states load on their reader layers, with the N-gram history on the first Mamba layer;
  - no slot-state entry is built without side states;
  - a QSA full page maps to its compressed page;
  - an MHA full pool maps K and V of a layer to one transfer layer;
  - a DSA full pool is still rejected.
- 17 passed on CPU.
