## Implementation and review-update summary

This PR adds an **opt-in native MiniMax-H3 TP2 × Ulysses2 QKV ownership path**, enabled with `SGLANG_MINIMAX_H3_ULYSSES_GATHER_QKV=1`. It assigns only the attention heads owned by each TP/U rank at load time, exchanges hidden-state rows for local projection, and preserves the existing output communication. The supported path remains CUDA, unquantized native H3, Ring1 and memory/eager execution; unsupported configurations retain the original path, and LoRA/FSDP/compiled execution are not enabled by this change.

The current review follow-up is `ac4bc47c9bd27de3f657b0de51374050fa3cb656`: remove the two duplicated loading helpers, reuse the existing grouped-QKV copier with composed rank/size, retain the existing-loader fallback, and split reusable loader-only contracts into independent PR #38382. The remaining runtime PR is **7 files, +656/-16**. Current-head CPU integration, four-GPU regression, native quick correctness and three warmed native E2E pairs are complete; detailed commands, results, failed qualification and limitations are retained below. PR #38382 is test-only and its separate validation must not be conflated with these runtime results.

This is a scoped capacity/correctness optimization with workload-specific measurements, not a claim of broad deployment need or general acceleration. Upstream GPU CI and maintainer review remain outstanding.

## Motivation

MiniMax-H3 duplicates its TP-local QKV weights across Ulysses ranks. This adds 2.69 GiB per rank for TP2 × U2, even though each attention rank ultimately consumes only half of those heads.

This adds an opt-in host-memory capacity path that exchanges hidden-state rows and projects the rank's own QKV heads. Enable it with `SGLANG_MINIMAX_H3_ULYSSES_GATHER_QKV=1`.

## Modifications

- Load native grouped checkpoint rows directly into the TP/U-local QKV shard, with a reordered fallback for the existing loader.
- Overlap U2 hidden-row exchange with the local projection, join communication before projecting peer rows, and retain the existing output all-to-all and TP output projection.
- Build RoPE for the gathered row range and release the additional staging buffers before VAE decoding.
- Decide ownership before allocating weights. The path requires native unquantized H3, CUDA, TP2 × U2, Ring1, memory mode, eager execution, and no FSDP or LoRA. Unsupported configurations keep the original weights and execution. Live LoRA loading is rejected after sharding.
- Add unit coverage for eligibility and a checkpoint-free four-GPU regression covering native loading, head ownership, model construction, packed attention/RoPE, stream changes, buffer resizing, and cleanup.
