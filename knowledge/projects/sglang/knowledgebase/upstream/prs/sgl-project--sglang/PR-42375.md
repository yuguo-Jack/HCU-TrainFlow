# test(elastic_ep): add CPU unit tests for scale state machine and helpers

[Upstream PR](https://github.com/sgl-project/sglang/pull/42375) · state: closed · merged: False

## Original PR description

## Motivation

弹性专家并行模块（#41800 落地）目前只有 manual 多卡集成测试
（`test/manual/ep/test_elastic_scale.py`、`test_elastic_recover.py`）。
本 PR 补充一层互补的 CPU 单元测试，覆盖状态机与纯逻辑辅助函数——
不需要分布式环境，不需要 GPU。

## Modifications

- `test_elastic_ep_state.py`：
  - `ElasticEPState` 的 rank 张量语义：snapshot / sync 的克隆隔离、
    `reset()` 的保留槽位行为（预留位保持 inactive 直到对应 rank 加入）
  - `ElasticEPStateManager` 完整扩缩容状态机：request / begin / mark /
    commit / fail 的状态转移、recovery 锁死（`recovery_unsupported`
    后拒绝再次 request）、随 phase 变化的 `get_data_plane_ep_size`、
    `is_scaling` 矩阵（pending 中、有死 rank、健康、recovery 不支持）
  - 测试通过手工注入 `ElasticEPState` 绕过需要真实分布式环境的
    `init()` 路径
- `test_elastic_ep_helpers.py`：
  - scale cohort 在假 TCPStore 上的注册 / 查询往返
  - 全局 rank → 组内 rank 的映射与过滤
  - 存活并行组迭代（按 `unique_name` 排序、跳过已失效弱引用）
  - `elastic_expanded_world_enabled` 的门控逻辑
  - expert-location 广播时健康源 rank 的选取
- `test_expert_backup_parsers.py`：DRAM 权重备份路径的两个正则解析函数
  （专家 ID 提取、layer/expert/weight 三元组提取）

## Accuracy Tests

- 共 37 个 CPU 测试用例，注册进 `base-a-test-cpu` 套件。
