# [Fix] disaggregation: Fix unbounded memory growth via orphan bootstrap_room lifecycle purge (#39428)

[Upstream PR](https://github.com/sgl-project/sglang/pull/39623) · state: open · merged: False

## Original PR description

### What does this PR do?

Resolves #39428 by establishing end-to-end lifecycle management and cleanup for bootstrap rooms in Prefill-Decode (P/D) disaggregation.

#### Problem
In P/D disaggregation, inbound bootstrap ZMQ packets arriving at the prefill bootstrap socket unconditionally allocated entries in `self.transfer_infos[room]` and `self.req_to_decode_prefix_len[room]`. When decode instances injected orphan room IDs, or requests were aborted before KV transfer began, these allocations were never drained or popped, resulting in unbounded memory growth and worker OOM kills. Furthermore, immediately popping room status upon conclusion could cause `KeyError` during client polling.

#### Solution
1. **Pre-Authorization Admission Guard**: Pre-verify incoming `bootstrap_room` against scheduled prefill requests registered via `PrefillBootstrapQueue.create_sender()` (`register_prefill_room`). Unsolicited orphan rooms are dropped immediately, while preserving backwards compatibility when running in standalone mock test modes.
2. **Centralized Thread-Safe Purge**: Centralized all room teardown logic in `CommonKVManager._purge_room_state` protected by a re-entrant `_room_lock` (`RLock`), ensuring atomic cleanup across `transfer_infos`, `req_to_decode_prefix_len`, and `_deferred_ack_targets`.
3. **Bounded Terminal Status LRU Cache**: Retain concluded room statuses in `_terminal_status_cache` (bounded LRU, max 2048 entries) so polling decode clients receive definitive terminal status (`KVPoll.Success` or `KVPoll.Failed`) without triggering `KeyError`.
4. **O(1) Min-Heap TTL Sweeper**: Maintain a min-heap (`_room_expiry_heap`) with `SGLANG_DISAGGREGATION_ROOM_TTL` (default 15s). The sweeper checks only `heap[0]`, evicting stale unfinalized rooms without `O(N)` dictionary sweeps or GIL contention.
5. **Multi-Backend Parity**: Wired admission check, TTL tracking, and abort purge across Mooncake, Mori, and Nixl transfer backends, as well as in `CommonKVSender.clear()`.

### Testing
- Added unit test suite in `test/registered/unit/disaggregation/test_orphan_room_lifecycle.py` covering:
  - Admission guard filtering & backward compatibility
  - Thread-safe dictionary purging
  - Min-heap TTL expiration & evictions
  - Terminal status LRU bounding & poll safety
  - Sender `clear()` integration
- Ran existing disaggregation unit tests (`test_deferred_decode_kv_release.py`) to confirm zero regressions.
- Verified linting and formatting via `ruff check` and `ruff format`.
