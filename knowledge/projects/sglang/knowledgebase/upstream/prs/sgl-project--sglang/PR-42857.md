# [KDA] Support Helion MTP verification and harden prefill, decode

[Upstream PR](https://github.com/sgl-project/sglang/pull/42857) · state: closed · merged: True

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Enable Helion across KDA prefill, decode, and EAGLE/MTP verification for models such as GLM-5.3-Flash. The existing prefill adapter omits the raw-beta flag, bounded-gate decode bypasses the Helion packed kernel, and Helion target verification is missing.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Forward `beta_is_raw` in the Helion prefill adapter.
- Enable Helion packed decode for bounded-gate KDA.
- Add Helion chain/tree verification with per-candidate state snapshots and register the verify backend.
- Add numerical and dispatcher regression tests, including CUDA Graph coverage.

Existing backend defaults are unchanged. MTP verification uses state snapshots; ReplaySSM verification is outside this PR's scope.

## Accuracy Tests

<!-- If this pull request affects model outputs (e.g., changes to the kernel or model forward code), provide accuracy test results. -->

Validated GLM-5.3-Flash on 4 × H200 with Helion 1.4.0, using Helion for all three KDA phases and EAGLE with 5 steps, top-k 1, and 6 draft tokens.

GSM8K: 100 examples, 5-shot, 8 threads, two runs, max tokens 4096, temperature 0, `reasoning_effort=low`.

| Configuration | Run 1 | Run 2 |
| --- | --- | --- |
| Helion prefill + decode + verify, MTP516 | 99% | 99% |

Passed 11 GPU tests and 9 dispatcher tests (plus 5 subtests), covering numerical correctness, state snapshots, chain/tree verification, and CUDA Graph replay. Pre-commit checks passed.

## Speed Tests and Profiling

<!-- If this pull request impacts inference speed, provide benchmarking and profiling results. -->

Benchmarked GLM-5.3-Flash with PyTorch 2.14.1, Triton 3.8.0, and Helion 1.4.0. Both configurations use MTP516 and Prefill/Decode CUDA Graphs; each A/B comparison changes only the three KDA backend flags.

| Configuration | 4 × H200 | 4 × B200 |
| --- | --- | --- |
| Parallelism | TP4 / EP4 | TP4 / EP4 |
| DSA prefill / decode | TileLang | TRTLLM |
| KV dtype | BF16 | FP8 E4M3 |
| MoE runner | DeepGEMM | FlashInfer TRTLLM |
| Prefill CUDA Graph | Breakable, max tokens 8192 | Breakable, GLM default max tokens 4096 |

  --dsa-prefill-backend tilelang \
