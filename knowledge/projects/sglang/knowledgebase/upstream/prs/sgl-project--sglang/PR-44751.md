# [Fix] dsv41: Preserve tool-result image order and current-turn thinking

[Upstream PR](https://github.com/sgl-project/sglang/pull/44751) · state: closed · merged: True

## Original PR description

## Motivation

Port the upstream chat-encoding fix [deepseek-ai/DeepSeek-V4.1-Flash@314113f](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash/commit/314113f8a7dadb388215396ba5fbee2c610a04d6) into the V4.1 prompt encoder, which has the same two bugs:

1. **Tool-result images out of order.** `encode_messages()` collected images before tool messages were merged and tool results re-sorted by call order. When tool results arrive out of `tool_call` order and carry images, the prompt's `<｜deepseek_image｜>` placeholders are reordered but the returned image list keeps arrival order, so images bind to the wrong placeholders.
2. **`drop_thinking` drops current-turn reasoning across tool calls.** A merged tool-result-only user message counted as a new user turn, so the reasoning of the current-turn assistant message preceding the tool results was stripped. Tool results alone do not start a new user turn; the current turn's reasoning should be kept until a real new user request arrives.

## Modifications

In `python/sglang/srt/entrypoints/openai/encoding_dsv41.py`:

- `encode_messages` validates textual fields for image placeholders, then merges tool messages and sorts tool results by call order, and only then collects images — the returned image list now matches the placeholder order in the prompt.
- `merge_tool_messages` keeps structured tool content (list `content` / `content_blocks`) instead of flattening it to joined text.
- `find_last_user_index` skips user messages holding only tool results, so `drop_thinking` keeps the current turn's reasoning across tool calls and drops it once a new user request arrives. The existing `developer`-as-user-turn behavior is kept.

## Accuracy Tests

Prompt-encoding logic only; no model forward / kernel changes. Unit tests in `test/registered/unit/entrypoints/openai/test_serving_chat.py`:

- `test_dsv41_tool_result_images_follow_prompt_order` — 4 input formats (`content_blocks`, `tool_messages`, `tool_content_blocks`, `context`); asserts prompt-tail order, media URL order, and that inputs are not mutated. Subtests fail on pre-fix code.
- `test_dsv41_drop_thinking_without_tools` — current-turn reasoning kept across a tool result, dropped once a real new user turn arrives. Fails on pre-fix code.
- `test_dsv41_rejects_image_placeholder_in_text` — placeholder rejection for `user` and `tool` messages.

`test_serving_chat.py` full run: 159 passed. `test_deepseekv41_detector.py`: 10 passed. pre-commit clean.
