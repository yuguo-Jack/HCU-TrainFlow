# [Doc] environ: Correct default values in the env var reference

[Upstream PR](https://github.com/sgl-project/sglang/pull/47709) · state: open · merged: False

## Original PR description

## Motivation

Four rows in the environment variable reference state a default that does not match `python/sglang/srt/environ.py`.

| Variable | Reference | `environ.py` |
| --- | --- | --- |
| `SGLANG_SANITIZE_NAN_LOGITS` | `true` | `EnvBool(False)` |
| `SGLANG_MORI_QP_PER_TRANSFER` | `1` | `EnvInt(4)` |
| `SGLANG_MORI_NUM_WORKERS` | `1` | `EnvInt(4)` |
| `SGLANG_DETOKENIZER_MAX_STATES` | Default value based on system | `EnvInt(1 << 16)` |

The first row matters most: a reader would assume NaN logits are sanitized by default, but they are not unless the variable is set.

## Modifications

Correct the default in those four rows. Descriptions are unchanged.

I compared every row in the reference against `environ.py`, ignoring formatting differences such as `1` and `True`. These four are the only wrong defaults I found.

This is separate from #43663, which handles the two rows for variables that no longer exist. I left those rows alone.
