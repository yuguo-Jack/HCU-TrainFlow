# [Fix] test: Publish a server config in the FlashInfer runner format test

[Upstream PR](https://github.com/sgl-project/sglang/pull/45375) · state: closed · merged: False

## Original PR description

## Motivation

`test_flashinfer_dispatcher.py` has failed on main since #43363. That PR made the FlashInfer CUTLASS MoE runner read the disaggregation and schedule configs to size its autotune range, and updated the runner's own tests. This test still calls the runner without a published config, so every PR whose CPU partition includes it fails `base-a-test-cpu` (for example #43809):

```
ERROR: test_cutlass_preserves_prefill_and_decode_combine_formats (prefill=True)
  File ".../moe_runner/flashinfer_cutlass.py", line 175, in _cutlass_moe_tune_max_num_tokens
    if get_disagg().disaggregation_mode == "decode":
ValueError: config namespace 'disagg' not published
```

## Modifications

- `test_cutlass_preserves_prefill_and_decode_combine_formats`: publish a default server config for the call with `get_context().override_server_args()`, as the runner's own tune-range tests in `test_flashinfer_cutlass_swiglu_params.py` do.
- No change to non-test code.
