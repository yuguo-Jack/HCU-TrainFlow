## Motivation

#19745 ("Fix none-comparison (E711) warnings") was merged in March and cleaned up `== None` / `!= None` comparisons across the repo, including one line in `rpd_utils.py`:

```python
# before #19745
if min_time == None:
    raise Exception("Trace file is empty.")
# after
if min_time is None:
```

That PR missed three more in the same function, `rpd_to_chrome_trace`: the `start != None` conditions in the `rangeStringApi` / `rangeStringOp` / `rangeStringMonitor` assignments, in the end-time branch of the range filter builder.

This PR fixes those three lines with the exact same change `#19745` applied to the line next to them. After this, `python/sglang/` is fully clean under `ruff check --select=E711` — these are the last hits.

## Modifications

`start` is either None or a string from argparse (possibly with a `%` suffix for relative time). `!=` and `is not None` agree on every reachable value, so no behavior change.
