# [Scheduler] Drop finished rows before admission

[Upstream PR](https://github.com/sgl-project/sglang/pull/43902) · state: open · merged: False

## Original PR description

Stacks on #43901

- Finished rows leave the running batch at the top of the next plan, before admission, in every non-PD loop.
- PD decode drops finished rows before preallocation; the prealloc LoRA gate counts the adapters of in-flight decode rows.

Behavior change: under saturation, admission sees freed slots and headroom one or more steps earlier; #running-req, prefill stats, and `/v1/loads` stop counting finished rows after a prefill step; PD preallocation is sized from live rows only.
