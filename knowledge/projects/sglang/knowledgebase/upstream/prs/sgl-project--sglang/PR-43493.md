# [diffusion] comfyui: consolidate 6 unrelated plugin fixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/43493) · state: open · merged: False

## Original PR description

## Summary

Consolidates 6 unrelated, non-overlapping ComfyUI SGLDiffusion plugin fixes into one PR, 6 commits, to cut down on review/CI overhead:

1. **Implement `VideoInput.as_trimmed` and resolve cloud-uploaded video URLs.** `SGLDVideoInput` never implemented `as_trimmed`, which ComfyUI made abstract in ComfyUI#12107, so `SGLDiffusionGenerateVideo`/`SGLDiffusionGenerateH3` failed to instantiate their output on any ComfyUI since that change. Fixes #43190.
2. **Preserve odd-size MiniMax H3 ComfyUI layouts.**
3. **Fix ComfyUI session routing with DP.**
4. **Resend conditioning after an SGLD worker rebuild mid-run.** When `ensure_executor` rebuilds a dead worker mid sampler-run, the new worker's session cache starts empty, so stale `_sent_conds` bookkeeping dropped conditioning the new worker never had. Fixes #43189.
5. **Fix `QwenImageEditAdapter` dropping extra reference images.** Fixes #43116.
6. **Fix `SGLDiffusionServerAPI.get_model_info` hitting a 404.** It stripped `/v1` before building the request URL, but the server only registers `/models` under `/v1`, so every call 404'd and the ComfyUI "Load Server" node always failed. Also unwraps the OpenAI-style `{"object": "list", "data": [...]}` envelope the server actually returns.

Each commit touches a distinct file with no overlap between them, so there's no merge-conflict risk from bundling.

## Test plan

- Kept each original PR's regression test(s): `test_video_output.py`, `test_comfyui_h3.py`, `test_dp_routing.py`, `test_worker_rebuild_conditioning.py`, additions to `test_comfyui_adapters.py`, `test_server_info_endpoint.py`.
- `py_compile` clean on all touched files; full suite needs CI (no local `sglang` install in this environment).
