# [Refactor] multimodal: [sglang-miles] [MM refactor 4/9] Split feature transport and preprocessing placement out of the base processor

[Upstream PR](https://github.com/sgl-project/sglang/pull/46699) · state: closed · merged: True

## Original PR description

## Motivation

Port of #46410 ([MM refactor 4/9]) onto `sglang-miles`, stacked on #46696 (3/9).

## ⚠️ Conflicts resolved (4)

`git range-diff` against #46410: 8 identical, 8 different. Five come from the `sglang-miles`-only true on-policy check, one from `sglang-miles` predating #43043, and two are test-only (a time estimate, and a `test_precomputed_embedding_validation.py` hunk not ported because `sglang-miles`' copy lacks the edited line); comparing the whole ported diff with #46410's, the only extra lines are the true on-policy check below.

**1-3. True on-policy check in the preprocessing placement helpers** (`de-self the preprocessing placement helpers in place`, `lift ... out of the processor class`, `move ... to serving_preprocessing`)

`sglang-miles`' `preprocessing_competes_with_the_scheduler` and `fast_image_processor_device` also bail out on `is_true_on_policy_enabled()`:

```python
# after `pass rl_on_policy_target to serving_preprocessing`, the callers read both flags
if _is_cpu or rl_on_policy_target is not None or true_on_policy_enabled:  # true_on_policy_enabled: sglang-miles only
```

The three commits turn the helpers into static methods, lift them to module level and move them to `serving_preprocessing.py`; the check moves with them, and the import `base_processor.py` no longer uses is dropped. (`move the automatic processor worker count to serving_preprocessing` differs from #46410 only in this context.)

**4. Kimi K3 test** (`test(mm): exercise feature transport through MultimodalFeatureTransport`)

`sglang-miles` branched from `main` on 10-14 and lacks 3b932cde26 (#43043, 10-18, "harden Kimi image cache identity"), which reformatted the `runtime_context` import in `test_kimi_k25.py` and changed a `_cached_k3_artifact` argument; #46410 was written on top of it. Only what this commit adds is ported: the `MultimodalFeatureTransport` import and `processor._feature_transport = MultimodalFeatureTransport("cpu", base_gpu_id=0, skip_mm_pool=True)` in each test. The #43043 lines are out of scope here and arrive with the next rebase of `sglang-miles` onto `main`.

## Modifications

The sixteen commits of #46410: preprocessing placement helpers move to `serving_preprocessing.py`, CUDA IPC pool setup and CPU move helper to `transport/feature_transport.py`, feature transport state and methods into `MultimodalFeatureTransport`, and the automatic processor worker count to `serving_preprocessing.py`.

## Next

[MM refactor 5/9] Add a token-space multimodal processor, stacked on this branch.
