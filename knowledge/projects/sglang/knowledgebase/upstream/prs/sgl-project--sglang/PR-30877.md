# [3/N] [spec] support STANDALONE spec decoding with DP attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/30877) · state: closed · merged: False

## Original PR description

## Summary

Depends on #31537 and #31566.

STANDALONE spec decoding and DP attention are mutually exclusive. This PR enables STANDALONE spec decoding with DP attention, validated under `topk == 1` and `attn_tp_size == 1`.

### NOTE

- This PR focuses on correctness only.
- **Gated:** `topk > 1` and partial DP (`attn_tp_size > 1`).
- **Not verified (untested, not gated):** PD disagg, non-fa3/triton backends, MoE draft.

## Modifications

- **Enable STANDALONE + DP attention**
  - Narrow down `ValueError` guard in `_handle_eagle_family`, enabling STANDALONE + DP attention with `topk == 1` and `attn_tp_size == 1`.
  - Handle `NoneType` hidden states across DP pad/unpad in `ForwardBatch`.
  - Track `num_tokens_before_dp_padding` before DP padding to unpad draft forward after MLP all-gather.
  - Load and run draft inside the attention-TP group.
  - Remove `StandaloneDraftWorker`'s `init_attention_backends` / `init_cuda_graphs` overrides (avoid double-wrapping).
  - Add `num_tokens_before_dp_padding` to the TBO child allow list in `filter_batch`, so the new field (`None` on the child, set later by the child's own padding) can pass "unsupported field" check.
- **Add an e2e test:** test GSM8K accuracy + `accept_length` under concurrency and a bs=1 accept length check; add default model constants for STANDALONE + DP attn.

## Accuracy Tests

This pull request enables support for standalone speculative decoding with DP (Data Parallel) attention. It removes the previous restriction, handles cases where standalone mode lacks hidden states or backup hidden states, configures the correct capture hidden mode for idle ranks to prevent NCCL hangs, and runs the draft worker in the attention TP group when DP attention is enabled. A test suite is also added to verify the implementation.
