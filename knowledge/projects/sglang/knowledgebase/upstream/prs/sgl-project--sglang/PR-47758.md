# [Fix] disagg: Give the decode queue test scheduler a tree_cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/47758) · state: closed · merged: True

## Original PR description

> (auto generated by Claude)

#46395 made `process_decode_queue` read `self.tree_cache.linker`. The scheduler stub in `test_decode_queue_cleanup.py::test_publishes_while_retracted_requests_wait` has no `tree_cache`, so the test now fails on main with `AttributeError: 'types.SimpleNamespace' object has no attribute 'tree_cache'`, and `base-a-test-cpu` fail-fasts every PR in that partition.

The stub now gets `tree_cache=SimpleNamespace(linker=None)`, the "no pending linker offloads" case.

Validation: `/rerun-test` of the file on CPU CI.
