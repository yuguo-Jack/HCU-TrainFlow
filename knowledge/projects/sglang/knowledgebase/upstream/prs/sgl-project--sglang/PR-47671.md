# [Perf] speculative: Vectorize full verify attention mask construction in NGRAMWorker

[Upstream PR](https://github.com/sgl-project/sglang/pull/47671) · state: open · merged: False

## Original PR description

## Motivation

In `NGRAMWorker._prepare_for_speculative_decoding` (`python/sglang/srt/speculative/ngram_worker.py`), when `USE_FULL_MASK and not _is_cpu` is active, constructing the flattened verify `custom_mask` previously executed a per-request Python loop across the batch:

1. **Float32 pre-allocation (`4x` memory traffic):** `ones_masks` allocated `bs` separate `torch.ones((self.draft_token_num, batch.seq_lens_cpu[i]), device=self.device)` tensors in default `torch.float32` (4 bytes/element instead of 1 byte/element `torch.bool`).
2. **Redundant host-to-device copies & per-request kernel launches:** Even though `tree_mask.copy_(torch.from_numpy(mask), non_blocking=True)` at line 336 already copies the entire `(bs * draft_token_num * draft_token_num,)` `bool` mask onto `self.device`, the `for i in range(bs):` loop performed `bs` additional `torch.from_numpy(mask[i]).to(device=self.device, non_blocking=True)` transfers, `bs` `torch.cat(..., dim=1)` calls (promoting `bool` to `float32`), `bs` `.to(torch.bool)` cast kernels, and a final `torch.cat(tree_mask, dim=0)`.

## Modifications

- Extract `_prepare_full_verify_mask_buffer(*, seq_lens: torch.Tensor, seq_lens_sum: int, draft_token_num: int) -> tuple[torch.Tensor, torch.Tensor]` to pre-allocate a single flat `torch.ones((total_mask_size,), dtype=torch.bool, device=seq_lens.device)` buffer and compute the 1D destination scatter indices `dst_indices` vectorized from `batch.seq_lens` before `_prepare_draft_tokens(batch)`.
- After `reconstruct_indices_from_tree_mask_func` runs, scatter the already-on-device `tree_mask` in a single operation (`full_mask[dst_indices] = tree_mask; tree_mask = full_mask`), eliminating `4 * bs + 1` per-request allocations/transfers/concatenations per decode step (`~20x` speedup at `bs=64..128, seq_len=4096`).
- Add unit tests in `test/registered/unit/spec/test_ngram_full_mask.py` verifying bit-for-bit parity against the reference per-request concatenation path across batch sizes, `int32`/`int64` sequence lengths, and draft token counts.
