# [CI] [AMD] diffusion/minimax-h3: Skip the group-attend contract test on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/47971) · state: closed · merged: True

## Original PR description

## What

Skip `test_minimax_h3_dit_contract.py::test_group_attend_skips_only_the_trailing_alignment_rows` on ROCm. The test now requires CUDA and `torch.version.hip is None`, the same gate other diffusion unit tests use. No runtime code changes.

## Why

The test was added by #47566 and is gated only on `torch.cuda.is_available()`, which is true on ROCm. It builds a `DynamicCudnnSDPAImpl` directly. That backend is only selected by the CUDA platform; the ROCm platform never picks it. On ROCm, the test's shape (head size 128, 16400 rows) is not eligible for the cuDNN route, so `forward_varlen` falls through to the FlashAttention fallback, which imports `flash_attn`. The ROCm images do not ship that package, so the test fails with `ModuleNotFoundError: No module named 'flash_attn'` on every AMD run since it landed:

- https://github.com/sgl-project/sglang/actions/runs/41450911971/job/125295715205
- https://github.com/sgl-project/sglang/actions/runs/41371177861/job/125041848501

The test checks a CUDA backend contract, so a skip loses no ROCm coverage. NVIDIA runs are unchanged.
