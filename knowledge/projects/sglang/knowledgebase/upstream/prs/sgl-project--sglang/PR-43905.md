# [Scheduler] Decode a copy of the running rows

[Upstream PR](https://github.com/sgl-project/sglang/pull/43905) · state: open · merged: False

## Original PR description

Stacks on #43904

- A decode step is a shallow copy of the running rows; `absorb` writes it back at the next plan, except the DP extend-view fields, which are defined next to `convert_decode_to_extend`.
- A launched prefill joins the rows as a copy; DP conversion no longer swaps the running batch.
- The mixed-step mamba track plan is stated as a rule; under `SGLANG_DEBUG_INFLIGHT_STEPS`, absorb checks that the rows were untouched and the step is decode or its DP extend view.

No behavior change.
