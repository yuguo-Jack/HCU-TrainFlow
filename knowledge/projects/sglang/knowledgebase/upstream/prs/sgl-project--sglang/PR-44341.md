# [Perf] Gather the striped prefix KV for DSA extend under DCP (env-gated prototype)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44341) · state: open · merged: False

## Original PR description

## Motivation

Under `--dcp-size c`, DSA (GLM-5.3 / DeepSeek-V3.2 style) extend chunks take the decode-style path: per layer, Q is all-gathered to all heads, each rank attends over its owned top-k slice, and the partial outputs + LSE are exchanged with an all-to-all. For an 8192-token chunk that is ~0.8 GB of NVLink traffic per rank per layer with no overlap. Measured on 4xB300 with GLM-5.3 NVFP4: DCP4 prefill runs at 14-15k tok/s vs 22-25k tok/s for plain TP4, and on the AgentX c48 point prefill batches take ~69% of wall time even at a 97% cache hit rate.

## Change

Behind `SGLANG_ENABLE_DSA_DCP_EXTEND_GATHER_KV=1` (default off, no behavior change otherwise): DSA extend under DCP keeps the plain 16-head path, and inside the TRT-LLM DSA forward each layer all-gathers the striped latent prefix rows of the batch into a position-ordered scratch buffer that the sparse kernel reads directly (`dsa_dcp_gather.py`). One plan per extend batch (owned rows in position order, receive permutation, position page table, and a slot -> row map for the fused top-k output). No LSE merge, no Q gather, no page-table localization.

| 4xB300 NVFP4, 8k chunks | 32k prompt | 131k prompt |
|---|---|---|
| TP4 | 23-25k tok/s | 22k tok/s |
| TP4 + DCP4, today | 15.2k | 14.1k |
| TP4 + DCP4, this flag | 22.3k | 20.1k |

Profile (32k prompt, one rank): kernel busy 2,125 ms -> 1,790 ms (TP4: 1,292 ms); helix all-to-all, Q all-gather and their packing are gone, the remaining gap is the per-layer NCCL all-gather (latency-bound) and a slower TP all-reduce sharing the links.

## Status

Prototype. Still torch-level (index_select + NCCL all-gather per layer, no overlap); the fused pack/reorder kernels of #43515 apply to this buffer. The DCP2+MTP+HiCache KL kit run was interrupted by a devbox eviction after one prefill-hit sample read 0.0235 against the 0.02 threshold; re-validation pending before this leaves draft.
