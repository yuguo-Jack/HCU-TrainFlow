## Motivation

<!-- Describe the purpose and goals of this pull request. -->
This PR enables end-to-end support for the page_unified KV-cache layout in SGLang HiCache, integrating staged GPU-to-host write-back and JIT host-to-GPU load-back for MHA and MLA models. It connects the unified layout with topology-independent L3 storage keys, keeping cache data and object identities consistent across memory and storage. The initial integration supports the file backend with one chunk per page and includes configuration validation and round-trip tests.
