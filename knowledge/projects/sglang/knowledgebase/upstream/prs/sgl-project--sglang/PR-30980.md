# [Feat] [XPU] graph: Add full prefill graph

[Upstream PR](https://github.com/sgl-project/sglang/pull/30980) · state: open · merged: False

## Original PR description

## Motivation

Adds XPU support for the full prefill graph path, so prefill capture/replay can use the same full-graph backend contract as decode.

## Modifications

* Add XPU-side support for full prefill graph capture and replay.
* Initialize the prefill graph metadata for XPU full backend execution.
* Pass the extra full-prefill replay fields through the metadata path and handle capture-time padding correctly.
* Keep shared hybrid attention and short-conv state graph-safe across capture/replay.

`raw_page` was divided by `page_size` above, but `translate_loc_from_full_to_swa` indexes a mapping keyed by full-pool *token slot IDs*. For `page_size > 1`, this translates the wrong slot and can produce an incorrect SWA page table. Please translate the original token IDs first, then divide the full/SWA results into page IDs separately, and test hybrid SWA prefill with a multi-token page size.
