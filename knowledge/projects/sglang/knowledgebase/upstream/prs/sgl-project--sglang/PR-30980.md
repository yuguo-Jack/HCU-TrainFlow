[Upstream PR](https://github.com/sgl-project/sglang/pull/30980) · state: closed · merged: True

## Original PR description

## Motivation

Adds XPU support for the full prefill graph path, so prefill capture/replay can use the same full-graph backend contract as decode.

## Modifications

* Add XPU-side support for full prefill graph capture and replay.
* Initialize the prefill graph metadata for XPU full backend execution.
* Pass the extra full-prefill replay fields through the metadata path and handle capture-time padding correctly.
* Keep shared hybrid attention and short-conv state graph-safe across capture/replay.

- CaoE · comment · 2026-10-29T07:54:30Z · [source](https://github.com/sgl-project/sglang/pull/30980#issuecomment-6491152868)

> can you also cover `decode breakable` in UT?

`decode breakable` is not yet supported end-to-end (this limitation currently applies to both CUDA and XPU). Specifically, `DecodeCudaGraphRunner` wraps the full model forward returning `LogitsProcessorOutput` (a dataclass), whereas `BreakableCudaGraphBackend._alloc_full_buffer` currently only handles `Tensor`, `PPProxyTensors`, `tuple`, and `list`, triggering `TypeError: Unsupported BCG output type: <class '...LogitsProcessorOutput'>` during capture.

This PR has kept the backend routing wired in code to maintain architectural parity with CUDA, but updated `docs/docs/hardware-platforms/xpu.mdx` to reflect that `--cuda-graph-backend-decode` supports `full` and `disabled`, and explicitly listed `decode breakable` under the Limitations table. We plan to address dataclass/`LogitsProcessorOutput` support for BCG in a dedicated follow-up PR.

In CI, `SGLANG_IS_IN_CI` was unset, which made `is_in_ci()` return `False` and ran `bs=2, input_len=128` (256 tokens total). That exceeded the captured `[64, 128]` buckets and silently fell back to eager.

We have rewritten `test/registered/xpu/test_xpu_graph.py` to be comprehensive and strictly verified:
1. **Eligible workloads across captured buckets (`[64, 128]`)**:
   - `tok_len=32` (64 tokens total): exact bucket `64` hit + request slot padding `2 -> 4`.
   - `tok_len=48` (96 tokens total): bucket padding `96 -> 128` + request slot padding `2 -> 4`.
   - `prefix_extend`: two-stage extend with cached prefix, verifying full graph replay under `cu_seqlens_q != cu_seqlens_k`.
2. **Explicit replay assertions**: Spies on `prefill_cuda_graph_runner.backend.replay` and `decode_cuda_graph_runner.backend.replay` to assert graph replay happens on the exact target `ShapeKey` without falling back to eager.
3. **Correctness vs. eager**: Asserts prefill logits cosine similarity `> 0.999` and asserts greedy decoded token IDs match eager execution exactly (`assertEqual`).
4. **Performance telemetry**: Measures steady-state prefill latency and decode throughput after warmup.
