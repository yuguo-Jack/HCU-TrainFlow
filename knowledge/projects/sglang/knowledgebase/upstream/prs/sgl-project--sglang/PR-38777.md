# fix: zero the default Qwen3 classification bias

[Upstream PR](https://github.com/sgl-project/sglang/pull/38777) · state: open · merged: False

## Original PR description

## Motivation

Fixes #38768. Standard Transformers Qwen3 sequence-classification checkpoints have `score.weight` but no `score.bias`. SGLang currently keeps the randomly initialized bias, so these checkpoints silently produce `W @ h + b_init` instead of `W @ h`.

## Modifications

Initialize the existing classifier bias to zero. Checkpoints that explicitly provide `score.bias` still overwrite it through the existing weight loader. Add a CPU CI regression exercising both checkpoint shapes through the real classification constructor and `load_weights`; the unit test isolates the unrelated backbone with `nn.Identity`.

## Accuracy Tests

- Rebased onto `933668131` (includes the current required base `60878c3f`). On this base, the registered CPU regression still fails without the fix and passes both missing-bias and explicit-bias cases with it. `pre-commit run --all-files` passed, including Rust workspace checks.
- `PYTHONPATH=python python3 test/registered/unit/models/test_qwen3_classification_bias.py`: passed (missing-bias and explicit-bias subcases) on CPU with Python 3.12.13, PyTorch 2.13.0, and Transformers 5.15.0. The missing-bias case fails on upstream.
- Earlier validation also instantiated the complete native one-layer Qwen3 model with a tiny config (`hidden_size=8`, `num_labels=3`) and a real single-rank Gloo process group, without mocking the backbone. Loaded `score.weight`, then compared classifier outputs on fixed hidden states with `torch.nn.functional.linear(..., bias=None)`. Maximum absolute logit error: **0.320134 before, 0.0 after**. The fixed model's classifier also passes on an RTX 5060 Ti (PyTorch 2.13.0+cu130).
- This validates head initialization/loading and head-output parity; it is not a full transformer-forward or model-server accuracy benchmark.
- Pre-commit checks passed for both changed files, including registered-test validation.

## Speed Tests and Profiling

The change only zeroes a small bias once during construction; the forward path is unchanged.
