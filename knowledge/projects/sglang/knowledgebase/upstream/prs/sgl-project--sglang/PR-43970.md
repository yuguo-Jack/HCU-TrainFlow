## Motivation

Prefill_complete is gated by _validate_prefill_complete in \sglang\python\sglang\srt\arg_groups\pd_disaggregation_hook.py. The check rejected any transfer backend string other than "mooncake". This made prefill_complete effectively unusable on NPU.

## Modifications

Add "ascend" alongside "mooncake" in _validate_prefill_complete. No behavioural change for existing mooncake users.
