# [AMD] Kimi-K3: support aiter MegaMoEV2 fused EP MoE on ROCm

[Upstream PR](https://github.com/sgl-project/sglang/pull/41862) · state: closed · merged: False

## Original PR description

## Motivation

Enable aiter MegaMoEV2 (fused EP MoE on MORI shmem) for Kimi-K3 on ROCm (MI355X). It replaces the routed-expert path "MORI dispatch → aiter fused_moe → combine" with two fused kernels: dispatch + GEMM1 + SiTUv2, and GEMM2 + combine.

## Modifications

- New `python/sglang/srt/layers/moe/mega_moe_aiter_k3.py`: wrapper around `aiter.ops.flydsl.kernels.mega_moe.MegaMoEV2`.
  - Reuses the MORI backend's shmem (process group `mori`).
  - Reuses the already-shuffled A8W4 expert weights (`shuffle_weight_a16w4` / `shuffle_scale_a16w4`), so no extra weight copy.
  - One MegaMoEV2 instance shared by all layers; per-layer weights are swapped in before each call.
  - Ranks with no tokens send a dummy row to join the collective.
- `python/sglang/srt/models/kimi_k3.py`: in the latent MoE, call the wrapper instead of `self.experts` when enabled.
- Opt-in only. Default behavior is unchanged.
  - `SGLANG_AMD_USE_FLYDSL_MEGA_MOE=1` enables the path; it requires `--moe-a2a-backend mori`.
  - `SGLANG_AMD_FLYDSL_MEGA_MOE_MTPR` sets the per-rank token capacity (power of 2, default 8192; we use 4096 = chunked prefill size).

Dependency: aiter [#5804](https://github.com/ROCm/aiter/pull/5804) + branch [xyw/megamoe_tune_k3](https://github.com/ROCm/aiter/compare/main...xyw/megamoe_tune_k3) (`c6f47121`, adds SiTUv2 to MegaMoEV2), FlyDSL 0.3.4.1.

Based on `00a9a81b67`, the sglang commit in `lmsysorg/sglang-rocm:v0.5.19-rocm720-mi35x-20260916`, so results are reproducible with that image.

## Accuracy / Performance

Kimi-K3, 8×MI355X, TP8 EP8, a8w4, `--moe-a2a-backend mori`. Baseline: the same image and aiter PR5804 without MegaMoE (MORI + fused_moe).

gsm8k (5-shot, first 300): **0.9933** for both.

bench_serving, random 8k in / 1k out:

<details><summary>Launch command</summary>

```bash
export SGLANG_USE_AITER=1 SGLANG_AITER_K3_OPT=1 AITER_FLYDSL_FORCE=1 AITER_SITUV2_A8W4=1
export SGLANG_AITER_HONOR_EXPLICIT_MEM_FRACTION=1
export SGLANG_AMD_USE_FLYDSL_MEGA_MOE=1 SGLANG_AMD_FLYDSL_MEGA_MOE_MTPR=4096
python3 -m sglang.launch_server --model-path moonshotai/Kimi-K3 --trust-remote-code --language-only \
  --tp-size 8 --ep-size 8 --moe-a2a-backend mori \
  --kv-cache-dtype fp8_e4m3 --mem-fraction-static 0.85 --context-length 16384 --max-running-requests 16 \
  --chunked-prefill-size 4096 --attention-backend aiter --disable-radix-cache
```

</details>
