# [HiCache] Allow independent DeepSeek V4 SWA host ratio

[Upstream PR](https://github.com/sgl-project/sglang/pull/42554) · state: open · merged: False

## Original PR description

## Motivation

Addresses #42548. DeepSeek V4 sizes its paged SWA host pool from the small device SWA pool using the same `--hicache-ratio` as full KV. Under long-lived prefix workloads, SWA host windows can be evicted while their full KV still fits on host, so the SWA match validator rejects the prefix and it is recomputed.

## Modifications

- Add an optional `--hicache-swa-ratio` to size only the DeepSeek V4 paged SWA host pool. Unset preserves current behavior. For example, `--hicache-ratio 2 --hicache-swa-ratio 4` doubles SWA host capacity while leaving full KV and C128 at ratio 2.
- Reject invalid or zero-page ratios and layouts without a paged SWA host pool. Require explicit `--hicache-ratio` with the override because automatic host-memory sizing assumes one shared ratio.
- Add focused registered CPU tests for argument validation, page sizing, and the unsupported layout; document the flag and per-rank RAM impact.

This is an opt-in capacity control, not a change to SWA eviction policy. A finite host pool cannot guarantee that every idle prefix survives arbitrary churn. Operators should check startup allocation lines and available host RAM per rank.

## Accuracy Tests

No model forward, kernel, or sampling computation changes. The new flag changes only host-cache capacity. No model-scale accuracy replay was run; the available A10 cannot serve the issue's DeepSeek-V4.1-Flash MXFP4 configuration.

## Speed Tests and Profiling

No model-scale speed benchmark or reporter-workload replay was run. The expected benefit is avoiding recomputation when SWA host pressure causes otherwise host-backed prefixes to miss; no performance claim is made without that measurement.

## Validation

- `pre-commit run --all-files`, `git diff --check`, and Python compilation passed.
- Dependency-free execution of the changed sizing and argument-resolution functions passed for default, override, invalid, implicit-ratio, and zero-page cases.
