# [Fix] mem_cache: Skip Mamba checkpoint donation when slots are exhausted

[Upstream PR](https://github.com/sgl-project/sglang/pull/47680) · state: closed · merged: True

## Original PR description

## Motivation

Fixes #43204. When all Mamba state slots are held by active requests or locked prefixes, optional checkpoint donation can exhaust the pool and terminate the scheduler.

## Modifications

- Skip unfinished-request checkpoint donation when allocation remains unavailable after eviction.
- Keep strict failure for slots required by active request state or load-back.
- Extend CPU regression coverage to all three allocation-based checkpoint paths, successful allocation, and strict required allocation.

## Accuracy Tests

- Seven local behavioral cases against the edited methods passed using a simulated slot pool.
- The registered unit test could not collect on macOS because the SGLang import requires Triton. Linux CI is still needed to validate it in the repository environment.

## Speed Tests and Profiling

Not run; this changes the exhausted-pool fallback and does not change the successful allocation path's work.
