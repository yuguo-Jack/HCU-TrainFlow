# [Fix] mistral: Preserve closing brackets in streamed text

[Upstream PR](https://github.com/sgl-project/sglang/pull/44224) · state: open · merged: False

## Original PR description

## Motivation

The Mistral tool parser deletes `]` from ordinary streamed replies, corrupting code such as `items[0]` and Markdown links. Fixes #44219.

## Modifications

Preserve ordinary text. Consume one closing bracket only when ending a real tool-call array. Add regressions for split text and both Mistral tool formats.

## Accuracy Tests

37 parser tests and 6 subtests passed. The 6 new regression cases fail on the original code and pass with this fix. No model weights or accelerator needed.

## Speed Tests and Profiling

Only text parsing changes; no model or kernel changes. No inference benchmark was run.
