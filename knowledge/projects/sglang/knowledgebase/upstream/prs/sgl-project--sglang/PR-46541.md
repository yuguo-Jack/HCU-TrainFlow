## Motivation

<!-- Describe the purpose and goals of this pull request. -->
`--enable-torch-compile` cannot finish startup on DeepSeek-V4 / V4.1. During decode
CUDA graph capture, Inductor precompiles the mHC sinkhorn kernel and fails:
```
Triton compilation failed: _hc_mix_reduce_sinkhorn_kernel_0
triton.compiler.errors.CompilationError: at 1:0:
def _hc_mix_reduce_sinkhorn_kernel(
^
AttributeError("'NoneType' object has no attribute '_unflatten_ir'")
```

_hc_mix_reduce_sinkhorn_kernel declares part_mix_residual_ptr=None, and its two non-residual call sites omit the argument. torch's Triton-kernel higher-order operator does not bind an omitted parameter to its declared default, so the parameter is recorded with a None type and Triton's code generator fails on it. PyTorch has a fix for the general problem in progress: pytorch/pytorch#201081 (bind omitted Triton kernel params to their declared defaults).
