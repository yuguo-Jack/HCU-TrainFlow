# [Fix] mooncake: Await all transfer futures before reporting failures

[Upstream PR](https://github.com/sgl-project/sglang/pull/47171) · state: open · merged: False

## Original PR description

## Motivation

`MooncakeKVManager._await_transfer_futures` can return on the first non-zero status when deferred decode release is disabled, or raise immediately when one future raises regardless of that flag. Other submitted transfer tasks can still be running; `Future.cancel()` cannot stop a running task.

This PR makes the task-completion boundary consistent on the existing main path. It is the **independent future-settlement increment of SG06** in #47031, not the complete request-finalizer/source-drain implementation.

## Modifications

- Materialize the submitted futures, request cancellation of remaining tasks after a failure, and continue collecting all completions.
- Preserve the first non-zero status or first exception, reporting it after the remaining futures settle.
- Add deterministic regression interleavings for status/exception failures with deferred release both enabled and disabled, and for preserving the first exception after a later failure.

Adapted from the future-drain portion of downstream `10053303694ba99167f7e17c585757fe3cf851bb` (ybhe1110), on upstream `f2d31889258d22214d9541e40b1e1e6961ce95e7`. The source author is credited in the commit.

Related prior proposals #38961 and #31357 are closed without merging; #38961 also identified the early-return problem. This is a focused current-main task-settlement fix, not a resubmission of their full deferred-release/protocol changes.

**Safety boundary:** a completed future is not proof that a native transfer returning an error/timeout stopped its DMA. This PR does not relax the existing poisoned-room/drain-ACK rules and does not authorize earlier source/destination reclamation. Queued/parked source ownership, request-owned retryable cleanup and forward drain remain separate SG06 work after the interfaces in #38352 are available. No new Mooncake Store API or wire format is introduced.
