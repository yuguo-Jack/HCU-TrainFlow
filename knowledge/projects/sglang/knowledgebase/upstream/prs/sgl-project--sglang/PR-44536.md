# [Feat] hicache: Integrate MLA host dedup with UnifiedRadixCache

[Upstream PR](https://github.com/sgl-project/sglang/pull/44536) · state: open · merged: False

## Original PR description

## Motivation

MLA target KV is replicated across attention-TP ranks, so keeping a complete HiCache host copy on every rank reduces effective L2 capacity by roughly `attn_tp_size`. This PR completes the opt-in integration where one attention-TP rank owns the target MLA/DSA host payload and peer ranks retain only allocation metadata.

This is the integration follow-up to the already merged prerequisites:

- #36798 — chunked and copy-unit-aligned CUDA host registration for large pools.
- #36800 — allocator-only MLA/DSA host pools and the layerwise NCCL broadcast primitives.

It supersedes the closed #26691 after the feature was split for review. The branch is rebuilt as one integration commit on the latest `main`; it does not duplicate the merged primitives or add a HiRadixCache path.

## Design

### Strict opt-in boundary

`--enable-mla-hicache-host-dedup` defaults to false. With the flag disabled, no dedup context, communicator, dummy host pool, scheduler producer fence, or dedup transfer path is created. Existing L2 write/load helpers continue to run directly, with focused regression coverage for both paths.

### Host ownership and write path

- Attention-TP rank 0 allocates and writes the target MLA KV and DSA indexer host payload.
- Peer ranks use allocator-only target host pools so allocation IDs and radix metadata remain aligned without allocating duplicate payload buffers.
- Rank-local speculative draft sidecars remain real pools and are written on every rank.
- The dedup D2H stream waits for the model producer stream, while the current allocator transfer-event mechanism prevents device rows from being reused before the copy completes.

### Layerwise load path

For each target layer:

1. The source rank loads that layer from Host L2 into its final device rows.
2. The dedicated NCCL communicator broadcasts contiguous staging chunks.
3. Peers scatter the received KV and optional DSA indexer rows into their rank-local physical device rows.
4. Rank-local draft sidecars are restored on every rank.
5. The layer completion event is recorded.

The integration uses the current `L2TransferEngine` physical-index translation and host-layout leases. The dedicated communicator is drained before ranks resume model-TP collectives, avoiding circular communicator ordering. `SGLANG_MLA_DEDUP_CHUNK_TOKENS` controls the broadcast chunk size and defaults to 2048.

### Current-main compatibility

- Integrates with the declaration-driven DSA HostPool assembler.
- Propagates dummy mode from the target MLA pool to its DSA indexer pool.
- Skips indexer broadcast on shared-topk layers that own zero-row index buffers.
- Preserves logical page order across rank-local physical allocations.
- Prebuilds the current CP/TP/PP storage synchronization groups in consistent order.
- Resolves Unified Memory virtual device rows before broadcast/scatter.
- Releases the dedicated communicator during UnifiedRadixCache shutdown.

### Draft L2 and storage

MTP/EAGLE/DFLASH draft pools use rank-local Unified HiCache sidecars while dedup is enabled; they are never broadcast as target MLA data.

Target L3 is supported only by dedup-compatible backends (`None`/L2-only and `file`). Dummy ranks participate in synchronized prefetch decisions while only the source performs storage-to-host copies. Runtime attachment of incompatible backends is rejected. Draft L3 with dedup is rejected because rank-specific storage keys are not implemented.

## Supported configuration

- CUDA MLA and DSA target caches.
- Attention-TP size greater than one.
- UnifiedRadixCache / Unified HiCache.
- MLA FP4 is excluded because its per-rank scale payload is not broadcast.
- DSA cache layer split and DCP are rejected because their KV contents are rank-sharded rather than replicated.

| Average TTFT | 12 s | 6 s | -50% |
