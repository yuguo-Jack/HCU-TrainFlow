# [JIT] Clean up kernel headers: move runtime helpers, add once.h

[Upstream PR](https://github.com/sgl-project/sglang/pull/41147) · state: closed · merged: True

## Original PR description

> (auto generated by Claude)

## Motivation

Clean up the JIT kernel headers: move helpers that sit in the wrong header, make kernels reuse the existing runtime utilities instead of hand-rolling them, and unify host-side error checking and logging.

## Modifications

- `runtime.cuh`: move the L1 carveout helpers here from `utils.cuh` (`set_smem_carveout`, `set_prefer_l1_carveout`, `set_prefer_l1_carveout_with_occupancy`), and add `set_max_dynamic_smem`.
- `runtime.cuh`: add `init_per_device` / `set_max_dynamic_smem_per_device`, a relaxed per-device once-flag whose hot path is a single atomic load.
- `utils.cuh`: remove `prefer_l1_carveout` / `ensure_prefer_l1` and the `LaunchKernel` `prefer_l1` option (no remaining users), together with its test `test_launch_carveout`.
- Replace `allocator.h` with `once.h` (`init_once`, `CacheMap`, `CacheSet`), the host-side counterpart of the runtime helpers.
- Use the runtime helpers in `topk_v1`, `topk_v2`, `kpool_topk_transform`, `dsv3_fused_a_gemm`, `hicache_tma`, `hisparse`, speculative `sampling` and `wo_a_fused`. This replaces hand-rolled static once-guards, and stops `cudaFuncSetAttribute` from being called on every launch.
- `RuntimeDeviceCheck` / `CHECK_CUDA` accept both CUDA runtime (`cudaError_t`) and driver (`CUresult`) error codes, via `runtime::is_cuda_error` / `runtime::get_cuda_error_string`. The driver overload references `cuGetErrorString` only when a `CUresult` is actually checked, so other modules do not gain a `-lcuda` dependency.
- `utils.h`: `Error` exposes its stream directly through `SGL_PANIC`, so stream manipulators such as `std::endl` work; `CHECK_HOST` / `CHECK_CUDA` build on it and are fully qualified so they work outside `namespace sglang`.
- Add `logging.h`: `SGL_LOG_DEBUG` / `SGL_LOG_INFO` / `SGL_LOG_WARNING`, gated by `SGLANG_JIT_LOG_LEVEL` (registered in `environ.py`, default `WARNING`). The level is read once when each module is loaded.
- `convrot_int8`: include `tvm/ffi/extra/cuda/device_guard.h` explicitly instead of relying on `utils.cuh` pulling it in.
- Reuse `warp::get_lane_id` in `topk_bf16_small`, and mark `pack_w` / `unpack_w` in `c_plan` as host-device.

## Validation

- All touched JIT modules compile for sm_90a and sm_100a (`wo_a_fused` for sm_100a only), with the `topk_v2` cluster paths enabled; `convrot_int8` compiles for sm_120.
- `CHECK_CUDA` / `RuntimeDeviceCheck` / `CHECK_HOST` / `SGL_LOG_*` checked on success and failure paths for both error-code types, including a trailing user `else` binding to the user's `if`.
- Kernel correctness tests are left to CI.
