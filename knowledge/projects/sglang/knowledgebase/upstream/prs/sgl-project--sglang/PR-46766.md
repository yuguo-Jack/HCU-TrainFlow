# [Feat] model-loader: Support per-model Hub source prefixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/46766) · state: open · merged: False

## Original PR description

## Motivation

Some deployments need a main model from ModelScope and an EAGLE draft from Hugging Face. The global `SGLANG_USE_MODELSCOPE` switch cannot express this combination.

For example, [GLM-4.7-Flash is available on ModelScope](https://modelscope.cn/models/ZhipuAI/GLM-4.7-Flash), while [thoughtworks/GLM-4.7-Flash-Eagle3 is on Hugging Face](https://huggingface.co/thoughtworks/GLM-4.7-Flash-Eagle3). I could not find a same-ID ModelScope mirror of this draft.

```bash
sglang serve \
  --model-path modelscope://ZhipuAI/GLM-4.7-Flash \
  --speculative-algorithm EAGLE3 \
  --speculative-draft-model-path hf://thoughtworks/GLM-4.7-Flash-Eagle3
```

## Modifications

- Accept `hf://owner/repo` and `modelscope://owner/repo` for the model, tokenizer, and speculative draft model.
- Resolve explicit sources through the selected Hub SDK into local snapshots, then reuse the existing loaders. Authentication, caching, download directories, and revision arguments remain SDK-managed.
- Keep bare `owner/repo` IDs, local paths, remote-storage protocols, and automatic built-in draft selection unchanged. No environment switching or cross-Hub fallback.
- Support the LLM CLI and Python `Engine`; SGLang Diffusion is outside this scope.

To keep this change small, models download complete repository snapshots, potentially including alternate weight formats. Tokenizer-only and dummy loads fetch metadata only. Cross-repository `auto_map` references and unsupported loaders fail explicitly; pre-downloaded local paths remain available for those cases.

## Testing

```bash
PYTHONPATH=python python -m pytest --noconftest \
  test/registered/unit/test_model_hub.py \
  test/registered/unit/cli/test_utils.py \
  test/registered/unit/server_args/test_model_source_paths.py -q
# 59 passed, 6 subtests passed
```

Tests mock both Hub SDKs and cover mixed sources, legacy paths, revisions, tokenizer defaults, shared snapshots, failures, and implicit DSpark draft resolution. Changed-file pre-commit checks and `git diff --check` passed.

No GPU service or real model download was run. Mintlify validation was unavailable locally because its CLI is not installed. AI assistance was used.
