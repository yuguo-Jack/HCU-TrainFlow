# fix: prevent Q8 attenuation for low amplitude BF16 all-reduce inputs

[Upstream PR](https://github.com/sgl-project/sglang/pull/40198) · state: closed · merged: False

## Original PR description

Fixes #40084

This implements a mathematical fix for the attenuation of low amplitude BF16 blocks in QuickReduce Q8 quantization. When block maxima fall below approximately 1.9e-3, the reciprocal scale overflows FP16 maximum representable value of 65504. This causes the encoding scale to saturate, breaking the reciprocity with decoding scale and strongly attenuating the block. 

By using packed_max with an elevated kScaleEpsilon (0x01020102 for FP16), we bound the decoding scale from below so its reciprocal never exceeds 65504. The resulting encoding and decoding scales remain true reciprocals, eliminating the attenuation while safely quantizing the low amplitude signal. Tests have been updated to cover sub-cliff blocks.
