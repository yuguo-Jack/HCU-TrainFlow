# [Fix] sampler: Skip singleton token synchronization

[Upstream PR](https://github.com/sgl-project/sglang/pull/35830) · state: open · merged: False

## Original PR description

## Summary

- Skip sampler token-ID synchronization when the selected TP synchronization group has world size one, including attention-TP groups under DP attention.
- Preserve the existing `ReduceOp.MIN` synchronization for multi-rank groups and the current context-parallel group initialization.
- Add CPU regression coverage for grammar/forced-sync combinations and TP/attention-TP group selection, with and without context parallelism.

## Motivation

Grammar sampling currently calls `torch.distributed.all_reduce` directly. For a singleton sampler synchronization group, the reduction is an identity, but its first use can lazily initialize an NCCL communicator and allocate a large NET shared P2P pool. This can fail when GPU memory is constrained.

The sampler already retains its selected process group. Cache that same group's fixed world size and skip the collective when no cross-rank synchronization is needed.

Fixes #35826. Related: #8400 and NVIDIA/nccl#2363.
