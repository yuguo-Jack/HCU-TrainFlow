## Motivation
This PR adds pool-level MTP KV-cache sharding support for dense MLA and MHA models. The draft reuses the target’s allocator and shard layout while maintaining separate KV storage and scratch buffers. MTP-specific compatibility checks currently run during pool construction; we will move them into argument validation when those checks are added.
