# [MLX] Fix numerical stability of output logprobs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43648) · state: open · merged: False

## Original PR description

## Motivation

MLX output logprobs lose precision when temperature-scaled logits have a large common offset. For example, two equal logits of 10 at temperature 1e-5 produce -0.6875 instead of -log(2). Larger offsets can produce zero logprobs for both tokens.

## Modifications

Subtract each row's maximum before computing logsumexp. This stabilizes chosen-token, top-token, and requested-token logprobs without changing token sampling.

Add regression coverage for positive and negative offsets, low temperatures, independent batch rows, nonuniform distributions, and pre-scaled inputs.

Implementation and testing were assisted by Codex.

## Accuracy Tests
