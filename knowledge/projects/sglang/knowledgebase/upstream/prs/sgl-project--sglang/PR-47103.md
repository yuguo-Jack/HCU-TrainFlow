# [Perf] scheduler: Add opt-in stop-string tail reuse and prefix pruning

[Upstream PR](https://github.com/sgl-project/sglang/pull/47103) · state: open · merged: False

## Original PR description

## Motivation

Streaming requests with literal stop strings decode the same output tail during finish checking and stream-prefix checking. The prefix check also compares every possible prefix length even when the final character rules out all partial matches. This adds per-token CPU work on small-model, high-concurrency streaming workloads.

## Modifications

The optimization is opt-in and disabled by default. Set `SGLANG_ENABLE_STOP_STR_OPTIMIZATION=1` before starting the server to enable it. The setting is resolved once at import; the disabled path performs no memoization or prefix membership pruning, though a cached-boolean branch remains.

```bash
SGLANG_ENABLE_STOP_STR_OPTIMIZATION=1 python3 -m sglang.launch_server --model-path MODEL_PATH
```

`MODEL_PATH` is an existing supported Hugging Face model ID or local model directory; use your usual platform and parallelism arguments. Leave the variable unset (or set it to `0`) for the default path. Changing it requires restarting the service.

- Reuse the decoded tail for streaming literal-stop requests. The cache includes the complete tail token sequence and window/output lengths, and verifies tokenizer identity, so same-length output rewrites and tokenizer changes invalidate it.
- Keep nonstreaming and stop-regex requests on the uncached path. Regex windows can cover the entire output, so this change does not keep a second full-output token tuple for them.
- After preserving the full-substring check, skip partial-prefix comparisons if the tail's last character does not occur in the stop string. A nonempty matching suffix must end in a character from that stop string.

Tail-window selection, decoding semantics, finish-state transitions, and trimming are unchanged. This is a CPU optimization; it does not add GPU matching, synchronization, or token tables. Prior tail-cache attempts: #35246 and #41115. This version limits reuse to the streaming literal-stop path and combines it with a necessary-condition prefix guard.
