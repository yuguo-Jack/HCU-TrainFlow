# [Test] hicache: Accept session_ids in the L3 object-layout test's put stubs

[Upstream PR](https://github.com/sgl-project/sglang/pull/46570) · state: closed · merged: True

## Original PR description

## Motivation

`test/registered/hicache/test_hicache_l3_object_layout.py` fails on `main` (base-a CPU shard):

```
TypeError: TestHiCacheL3ObjectLayout.test_physical_primary_and_components_match_actual_write_keys.<locals>.put() got an unexpected keyword argument 'session_ids'
```

#44611 made `MooncakeStore` pass `session_ids` to `_put_batch_zero_copy_impl`. #40467, merged a few hours later, added this test with `put` stubs written against the older signature. Each PR passed on its own; together they leave `main` red, and every PR whose CI merges current `main` inherits the failure.

## Modifications

The two `put` stubs that replace `_put_batch_zero_copy_impl` now accept `session_ids=None`, matching the method's signature. Test-only change.
