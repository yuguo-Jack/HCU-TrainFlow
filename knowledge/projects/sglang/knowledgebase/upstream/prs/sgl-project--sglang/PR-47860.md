# [Fix] spec: Give the mocked draft decode backend a cache_loc_dtype in the inkling test

[Upstream PR](https://github.com/sgl-project/sglang/pull/47860) · state: closed · merged: True

## Original PR description

> (auto generated by Claude)

#47173 changed `EAGLEDraftExtendCudaGraphRunner._cache_loc_dtype()` from `torch.int64` to `self.backend.cache_loc_dtype`. `test_inkling_checkpoint_indices.py` builds that runner with `resolve_decode_backend` patched to a bare `Mock()`, so the dtype is now a `Mock` and the test fails on main with `TypeError: ones(): argument 'dtype' must be torch.dtype, not Mock`. Since it is a `base-b-kernel-unit` 1-gpu-large test, `jit-kernel-unit-test-1-gpu-large` fails for every PR.

The mocked backend now carries `cache_loc_dtype=torch.int64`, the value the runner used before #47173.

Validation: `/rerun-test` of the file on CI.
