## Motivation

Bug Fix: index_head_dim is a DSA-only field, but model_runner_kv_cache_mixin passes it to every MLA pool via get_mla_kv_pool_cls(), including the non-DSA branch (where it's always None). The base MLATokenToKVPool.__init__ doesn't accept it, so each out-of-tree backend must independently add the parameter to avoid a TypeError at startup.

https://github.com/sgl-project/sglang/blob/main/python/sglang/srt/mem_cache/memory_pool.py#L2713-L2727

## Modifications

drop index_head_dim from the non-DSA MLA branch in model_runner_kv_cache_mixin.py
