# [Fix] diffusion: fix colored seams in single-GPU Qwen-Image-2.1-Turbo VAE tiling

[Upstream PR](https://github.com/sgl-project/sglang/pull/47092) · state: closed · merged: True

## Original PR description

## Motivation

Native single-GPU VAE tiling for Qwen-Image-2.1-Turbo evaluates self-attention and convolutions independently within each tile, then blends overlapping outputs. Each position can attend only to that tile's keys and values, and some convolution dependencies are truncated. Native single-GPU tiling is therefore not mathematically equivalent to the untiled VAE, and can produce colored seams.

The default multi-GPU tiling path (`parallel_tiled_decode`) can also produce stitching artifacts. However, multi-GPU decoding also provides a separate `spatial_shard` path: it exchanges convolution halos at each layer and gathers the full spatial features for self-attention, preserving complete spatial dependencies and mathematical equivalence to untiled decoding. This PR therefore replaces only the single-GPU tiling algorithm, leaving the default multi-GPU tiling and `spatial_shard` algorithms unchanged.

The single-GPU text-to-image comparison below uses the same input at 3840×2144. Native tiling can produce grid-like stitching artifacts along horizontal and vertical tile boundaries, visible here as thin purple seams across the tabletop. These visible seams are absent from the untiled and patched outputs. The top row shows full-image previews; the bottom row shows matched crops at 1:1 pixel scale.

![Untiled, native-tiled and patched outputs with matched full-image views and crops](https://github.com/user-attachments/assets/48aa6c17-6909-4ed2-a3ee-c1a639038a21)

## Modifications

This method is enabled only for single-GPU execution. It tiles convolutions by valid output regions before and after global attention, covering both encoding and decoding.

- Partition the pre-attention feature map into disjoint valid regions (cores). Compute each core with its required neighboring halo, then assemble the valid regions into the complete feature map.
- Attention continues to use the native `AttentionBlock`.
- Evaluate subsequent convolutions on the original core grid. Propagate each final output region backwards to derive the required input windows, retain complete halos, crop redundant edges after each stage, and stitch the valid outputs.
- Apply `clamp(-1, 1)` after assembling the valid output regions in single-GPU decoding.

## Accuracy Tests

Seven CPU regressions cover full-versus-tiled encoding and decoding at non-tile-aligned boundaries, output range, single-GPU-only dispatch and native fallback for non-residual architectures.

~~~bash
PYTHONPATH=python python -m pytest -q \
  python/sglang/multimodal_gen/test/unit/test_qwen_image21_attention_barrier.py
~~~

Validation uses Qwen-Image-2.1-Turbo on one H20 in BF16: decoding at 1536×1536 and encoding at 1024×1024. Each case has one warmup and three formal calls, using the untiled output for the same input as the tensor-level reference.

## Speed Tests and Profiling

Single H20, BF16, batch 1, PyTorch 2.14.1/CUDA 13.0, cuDNN 9.24. Component measurements use identical inputs and synchronized wall time, with one warmup and three formal calls per case. Peak GPU memory is measured with PyTorch `max_memory_allocated` and includes the resident VAE and input. Detailed settings, aggregation and individual measurements are in `validation.json` ([validation bundle](https://github.com/user-attachments/files/34090707/qwen-image21-single-gpu-tiling-compact-pr-bundle.zip)).

### Encoding

All methods use the same input image. Differences are computed in FP32 across all output channels, and RMSE directly compares the encoded posterior moments with the untiled result.

| Resolution | Method | Time (s) | Peak GPU memory (GiB) | RMSE |
|---|---|---:|---:|---:|
| 1024×1024 | Untiled | 0.064 | 1.957 | 0.000000 |
| 1024×1024 | Native tiled | 0.201 | 0.727 | 3.533896 |
| 1024×1024 | Patched | 0.445 | 1.007 | 0.036352 |

### Decoding

All methods use the same latent. Differences are computed in FP32 across all output channels before conversion to 8-bit pixels, and RMSE directly compares the decoded output tensor with the untiled output.

| Resolution | Method | Time (s) | Peak GPU memory (GiB) | RMSE |
|---|---|---:|---:|---:|
| 1536×1536 | Untiled | 0.650 | 7.607 | 0.000000 |
| 1536×1536 | Native tiled | 1.363 | 0.857 | 0.013966 |
| 1536×1536 | Patched | 1.813 | 0.813 | 0.000897 |

### Full requests

End-to-end inference uses the SGLang Python API: one H20, Qwen-Image-2.1-Turbo, BF16, eight steps, guidance 1.0, quality="lossless", default VAE computation optimizations and text-encoder CPU offload.

The text-to-image case produces a 3840×2144 image. The image-to-image case uses three references: the output image and each preprocessed VAE input are 1536×1536, while all three original references are 1024×1024. Each row has one warmup and three formal requests. Time covers the full request and PNG saving; peak memory is sampled through NVML.

Compared with native tiling, the patched end-to-end requests take slightly longer with broadly unchanged peak memory, while restoring mathematical consistency with the untiled VAE and improving output accuracy.
