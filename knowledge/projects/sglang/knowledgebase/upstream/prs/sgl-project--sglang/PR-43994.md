# [Feat] [XPU] moe: Add FP8 MoE support

[Upstream PR](https://github.com/sgl-project/sglang/pull/43994) · state: open · merged: False

## Original PR description

## Motivation

Enable XPU FP8 MoE dispatch for FP8 quantization paths supported by the Xe2 FP8 W8A16 grouped GEMM implementation in `sgl-kernel-xpu`.

## Modifications

- Route supported XPU FP8 MoE quantization methods through `sgl_kernel.fused_experts`.
- Pass block quantization metadata for FP8 and MXFP8 MoE weights.
- Add XPU coverage for the supported FP8 MoE paths.

## Accuracy Tests

Add XPU tests covering:

- FP8 MoE with scalar weight scales.
- FP8 MoE with block weight scales.
- MXFP8 MoE.
- XPU dispatch for W8A8 FP8 MoE and compressed-tensors FP8 MoE.
