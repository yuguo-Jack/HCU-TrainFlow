# [Docs] Add Clef cookbook with selectable Clef Flash variant

[Upstream PR](https://github.com/sgl-project/sglang/pull/43235) · state: closed · merged: True

## Original PR description

## Motivation

Add one cookbook page for Cloudflare’s Clef 27B and Clef Flash 9B. Readers can select either model and generate a launch command for one B200, B300, or H200. Runtime support is merged in #42721.

## Modifications

- Pin Python installation to `sglang==0.5.22.dev20261009+g37ae292e6f` from [the requested nightly build](https://github.com/sgl-project/sglang/actions/runs/37897861964), using Python 3.10.

- Add Clef and Clef Flash variants to the deployment wizard, with matching `/v1/systemone` requests.
- Use only `--model-path`, `--host`, and `--port` in all six verified recipes. SGLang defaults select BF16 and TP=1.
- Use `lmsysorg/sglang:dev-clef` from [the Clef image build](https://github.com/sgl-project/sglang/actions/runs/37893990016).
- Document installation, images, the 16,384-token prompt limit, state truncation, and response fields. Include a captured Clef Flash response.
- Add the Cloudflare navigation entry and category card, and update the decision API reference.

## Accuracy Tests

Both models passed on one B300 and one H200 inside the published `lmsysorg/sglang:dev-clef` image, built from `bd2d73daa5afda6bcad8d479a834f2e70bbe9569` with PyTorch 2.14.1+cu130 and Transformers 5.19.0. The two GPUs ran concurrently; each GPU tested the models sequentially. All four configurations passed the exact three-flag launch, wizard cURL request, Python example, and four text/image cases (short and long state, with and without an image): 24 request/example checks total. Both long cases used 16,384 prompt tokens and preserved every question.

The pinned Python wheel `sglang==0.5.22.dev20261009+g37ae292e6f` also passed all four B300/H200 model configurations in fresh Python 3.10.22 virtual environments using the cookbook’s exact installation block. `uv pip check` passed for all 212 packages on each box, and another 24 request/example checks passed. Imports came from the new environments, with no system site-packages. No package overrides or extra serving flags were needed.

B200 previously passed the four text/image cases with SGLang `e122069670a74611be5a566c5a14f7b7422a1154`, PyTorch 2.14.1, and Transformers 5.17.0. These are serving smoke checks; accuracy was not benchmarked. The Docker launcher itself was not exercised.
