# [Feat] [AMD] deepseek-v4.1: Add full mono decode 

[Upstream PR](https://github.com/sgl-project/sglang/pull/44033) · state: open · merged: False

## Original PR description

## What this does

#43497 added the front mono kernel, K1, for DeepSeek-V4.1 decode on MI355X. It runs on 30 of the 40 backbone layers. Attention still runs through the normal SGLang kernels, followed by a separate fused FFN launch.

This PR completes the path:

1. K1 runs on all 40 backbone layers.
2. The existing sparse-attention indexer runs between K1 and K2 on the layers that need it.
3. K2 runs attention, the output projections, and the FFN in one kernel.

The path is opt-in with `SGLANG_ROCM_MONO_K2=1`, which also requires the existing mono decode and K1 flags. It handles decode and DSpark target-verify steps with 48 rows or fewer. Larger steps and draft layers stay on the normal path.

## Why

Without K2, SGLang only uses the front half of the mono path. It returns to the normal attention kernels and then launches the FFN kernel separately. K2 removes those launches from the decode path and keeps the work inside the fused kernel.

## Performance

The baseline is the #43497 image at `d4708ad`: K1 on 30 layers, normal attention, and the separate FFN launch. The PR image has K1 and K2 on all 40 layers.

Both runs used the same MI355X recipe: TP4, DSpark block size 5, AgentX concurrency 1, and one hour.

| | #43497 | this PR | change |
|---|---:|---:|---:|
| P90 tokens/s/user | 391.44 | 429.14 | +9.6% |
| P50 tokens/s/user | 317.13 | 352.67 | +11.2% |
| median time between tokens | 3.15 ms | 2.84 ms | 9.8% faster |
| mean time to first token | 1,132.11 ms | 1,099.98 ms | 2.8% faster |
| output tokens/s | 147.19 | 151.17 | +2.7% |

## Accuracy

Two comparisons, both on GPQA-Diamond and AIME25, with TP2, thinking on, DSpark block size 5, temperature 0.6, top-p 0.95, and four seeds.

The first comparison is K1 only, on the earlier image.

| | K1 on | mono off |
|---|---:|---:|
| GPQA-Diamond | 88.9% ± 1.6 | 88.5% ± 2.4 |
| AIME25 | 99.2% ± 1.7 | 92.5% ± 1.7 |

The second comparison is this pull request. One arm runs K1 and K2. The other arm is the same image with the mono kernel off.

| | K1 and K2 | mono off |
|---|---:|---:|
| GPQA-Diamond | 89.3% ± 0.8 | 88.6% ± 0.7 |
| AIME25 | 95.0% ± 3.3 | 92.5% ± 5.7 |

The official GPQA download was access-restricted, so both runs used a public copy of the same 198 questions.
