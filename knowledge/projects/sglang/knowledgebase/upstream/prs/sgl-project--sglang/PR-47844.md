# [Doc] [AMD] cookbook: Verify MiniMax-M3.1-Flash High-Throughput on MI355X

[Upstream PR](https://github.com/sgl-project/sglang/pull/47844) · state: closed · merged: True

## Original PR description

## Motivation & Modifications

Summary:
- MI355X High-Throughput cell for MiniMax-M3.1-Flash:
  - `HSA_USERPTR_FOR_PAGED_MEM=0`: back the HiCache host pools with `hipHostMalloc`. With registered pageable memory the first HiCache write hits a HIP illegal memory access on MI355X.
  - `--hicache-size 180 --hicache-write-policy write_back` instead of the default ratio (~350 GB per rank), so two TP4 servers fit on one host.
  - Default bf16 DSpark draft KV (drop `--speculative-draft-kv-cache-dtype fp8_e4m3`), as measured.
  - Mark the cell verified; replace the "not measured on MI355X" note.
- Image unchanged (`lmsysorg/sglang:dev-minimax-m31-flash-mi35x`).

## Accuracy Tests

GSM8K at 64 concurrent sessions with HiCache: 96.59 strict / 96.51 flexible.

## Speed Tests and Profiling

AgentX on MI355X, TP4 + HiCache: 90,168 tok/s per GPU at concurrency 64, P90 TTFT 1.21 s. Concurrency 48 also passed.
