# [Perf] [NPU] Increase GLM-5.2-W4A8C8 KV cache capacity with compact DSA indexer allocation

[Upstream PR](https://github.com/sgl-project/sglang/pull/44436) · state: open · merged: False

## Original PR description

## Motivation

Increase KV cache capacity for GLM-5.2-W4A8C8 on Ascend 910B4 by avoiding indexer cache allocation for DSA layers that reuse the previous layer’s top-k indices, while preserving model accuracy.

## Modifications

- Allocate indexer cache slots only for layers that compute top-k indices.
- Align NPU memory-budget sizing with the compact indexer allocation so the saved memory can be used for additional KV cache tokens.

## Accuracy Tests

The AIME26 mean accuracy remained unchanged before and after the change at **0.9333** (30 examples).

| Model | Dataset | Metric | Subset | Num | Score | Category |
|---|---|---|---|---:|---:|---|
| GLM-5.2-W4A8C8 | aime26 | mean_acc | default | 30 | 0.9333 | default |

## Speed Tests and Profiling
