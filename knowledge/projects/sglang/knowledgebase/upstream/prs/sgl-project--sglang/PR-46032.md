# [Doc] cookbook: Qwen3.5 MI355X FP8 agentic adds scheduler/tokenizer tuning from the InferenceX recipe

## Original PR description

## Motivation

Follow-up to #46017. The InferenceX sign-off for [SemiAnalysisAI/InferenceX#4374](https://github.com/SemiAnalysisAI/InferenceX/pull/4374#issuecomment-6360306728) flagged settings on `qwen3.5-fp8-mi355x-sglang-agentic-mtp` ([agentic.yaml](https://github.com/SemiAnalysisAI/InferenceX/blob/8b7a91b1da80d7faee61bddd96d3f9d5fdf4eae6/inferencex-e2e/benchmarks/single_node/srt-slurm-recipes/qwen3.5/sglang/mi355x-fp8-mtp/agentic.yaml)) that the cookbook did not document.

## Modifications

`docs/src/snippets/autoregressive/qwen35-deployment.jsx`

- 397B + MI355X + FP8 + HiCache now also emits `--chunked-prefill-size 16384 --max-prefill-tokens 16384 --scheduler-recv-interval 60 --stream-interval 50 --tokenizer-worker-num 6`, matching the recipe.

`docs/cookbook/autoregressive/Qwen/Qwen3.5.mdx`

- Update the "KV cache offloading (397B FP8 on MI355X)" bullet with those flags.
- Note that the benchmarked high-concurrency points pin `--hicache-size` per rank (253 GB at concurrency 32-56, 374 GB at 64-80), which overrides `--hicache-ratio 1.5`. It is left out of the command because it is sized per point.

The generated command for every other hardware, precision and toggle combination is unchanged.

## Accuracy Tests

Documentation-only; no runtime code path is touched.

## Benchmarking and Profiling

No change; the flags are taken from the InferenceX recipe benchmarked in #4374.
