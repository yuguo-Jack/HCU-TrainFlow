## Motivation

NPU graph execution uses device-specific runner subclasses for decode, EAGLE draft, draft extend, and multi-layer draft extend. These subclasses duplicate shared execution logic and make upstream changes harder to maintain.

This refactor lets GPU and NPU share runner implementations while keeping device-specific behavior in the graph backends.

## Modifications

Replace NPU-specific graph runners with shared decode and speculative runners.

Move NPU cache-location dtype, capture compilation, profiling, replay preparation, and Host sequence-length updates into NPUCudaGraphBackend.

Centralize update-attribute selection while preserving each stage’s sequence-length calculations and payload formats.

Preserve DFlash preparation, DSA/V4 update bypasses, multi-layer Host updates, and NPU shared-read event behavior.

Move CUDA profiling into a reusable backend helper and XPU profiling into the XPU backend.

Preserve upstream runner-selection hooks and fix NPU runner-class selection.

Add regression coverage for update payloads, replay preparation, graph admission, dtype selection, and profiling.
