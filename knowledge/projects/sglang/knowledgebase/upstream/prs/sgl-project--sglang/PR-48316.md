# [Fix] offload: Keep DSA indexer parameters resident on GPU under CPU offload

[Upstream PR](https://github.com/sgl-project/sglang/pull/48316) · state: open · merged: False

## Original PR description

### Motivation

When serving DSA models (e.g. GLM-5.3, DeepSeek-DSA) with V1 CPU weight offload () and the default breakable prefill CUDA graph backend, the server crashes on the first request:


**Root Cause:**
1. Under breakable prefill CUDA graphs, the DSA indexer () is captured as an eager break ().
2. During replay,  executes the break outside  ().
3. Since  parameters were offloaded to pinned CPU memory and only temporarily brought to GPU during layer , its weights remain on CPU during replay, causing the mm device mismatch error.

### Proposed Changes

In , keep the DSA indexer parameters () resident on device under offload, consistent with the existing treatment for .

Fixes #48260.
