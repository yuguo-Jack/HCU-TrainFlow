# Fix macOS linking for rust server

[Upstream PR](https://github.com/sgl-project/sglang/pull/39361) · state: open · merged: False

## Original PR description

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

`sglang-server` is manually built as a PyO3 extension by the Rust extension loader. On macOS, the linker fails because Python C API symbols are intentionally resolved at runtime by the host Python interpreter, but the required `-undefined dynamic_lookup` linker arguments are missing.


<!-- Describe the purpose and goals of this pull request. -->

## Modifications

<!-- Detail the changes made in this pull request. -->

- Add `pyo3-build-config` as a build dependency for `sglang-server`.
- Add `sglang-server/build.rs` to configure platform-specific PyO3 extension linker arguments.
- Apply `-undefined dynamic_lookup` automatically on macOS.
