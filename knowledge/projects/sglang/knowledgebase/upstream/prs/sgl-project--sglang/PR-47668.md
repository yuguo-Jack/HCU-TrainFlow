# [Feat] diffusion/model: Support Efficient-Large-Model/Open-H3-Regenerate-2K (MiniMax-H3 2K draft refiner)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47668) · state: open · merged: False

## Original PR description

## Motivation

Add [Efficient-Large-Model/Open-H3-Regenerate-2K](https://huggingface.co/Efficient-Large-Model/Open-H3-Regenerate-2K) to SGLang Diffusion. It is NVlabs/Sana's open replacement for MiniMax's closed H3-Regenerate-2K stage, and it refines an existing H3 draft at up to 2560×1440. The reference implementation is NVlabs/Sana `models/Open-H3-Regenerate-2K` (`sol-engine` branch).

The flow:

```
768P draft -> VAE encode -> 3D latent upscaler -> re-noise to sigma0 = 0.909
           -> 3 Euler steps (CFG off, MiniMax-H3 + merged LoRA + Sharp curve branches) -> VAE decode at 2560x1440
```

The DiT is the unmodified MiniMax-H3. The release adds three things on top:

- one merged FP32 LoRA (rank 576 = refiner 384 + LightX2V FL2VA Turbo 128 + LMS Sharp 64, on 312 linears);
- 50 LMS Sharp AdaLN branches driven by a timestep curve;
- LBH-123-AI's 3D-conv latent upscaler.

`--model-path Efficient-Large-Model/Open-H3-Regenerate-2K` serves it on the native MiniMax-H3 pipeline. A request is a `t2va` request that names the draft in `source_video`.

## Modifications

1. **Timestep-curve AdaLN branches** (`dits/minimax_h3.py`). Each block's AdaLN output can gain `B @ A @ curve(t)`, where `curve(t)` linearly interpolates a `[grid, 8]` table at the model timestep. `load_adaln_curve_branches` attaches the branches, and `B`'s rows are sharded with the projection. The model sets the curve coordinates once per forward, so the per-block, batched and layerwise-offloaded paths all see them. The branches are rejected together with the precomputed AdaLN cache.
2. **MiniMax-H3 3D latent upscaler** (`models/upsampler/minimax_h3_latent_upscaler.py`). A port of LBH-123-AI's ComfyUI node (MIT): a scale-conditioned ResBlock stack around a trilinear resize, with time untouched. It builds the architecture from the checkpoint and reproduces the node's `TARGET_DIMENSIONS` call.
3. **Per-model canvas area cap.** The canonical target may carry `max_pixels`, set by a model's sampling params, in place of H3's fixed 1344×768 cap. Base H3 requests are unchanged.
4. **Open-H3-Regenerate-2K.**
   - `MiniMaxH3RegenerateSourceStage` runs ahead of latent preparation:
     - It decodes the draft (24 fps, cover-crop, the reference's 121 + 3 held frames) and encodes it at its 768P (or 576P) canvas.
     - It upscales the latent to the request canvas and writes `(1 - σ0)·upscaled + σ0·noise` as the initial state.
     - The audio rows are held clean (σ = 0) for every step. They come from the draft's soundtrack by default, or from silence as in the reference.
     - The regular latent and timestep stages then leave that state untouched, so the H3 Euler loop and the decoder run unchanged.
   - Schedules match the reference: 3 steps `[0.909375, 6/7, 2/3, 0]`, or 2 steps from 0.7. `start_sigma` builds the shift-6 grid from another start.
   - **No overlay, no extra HF repo.** `MiniMaxH3Pipeline` can now load a release that ships only add-ons for the H3 base. `OpenH3RegeneratePipeline` names `base_model` / `base_revision` (MiniMax-H3 `6818f6c`, the revision the release pins; its weights are byte-identical to `42ed227` by LFS sha) and its `release_files`. Only those files are fetched from the model path. The release's 210 GB `base_model/` copy is never downloaded.
   - The 1025×8 curve table the release pins, which it does not redistribute, is one tensor of a Comfy-Org checkpoint. It is read from the local hub cache, or by HTTP byte range, then checked against the release's sha256 and cached.
   - Defaults so that a 2K refine fits one H200: the text encoder stays off the GPU between prompts, and the LoRA is merged into the DiT, as the reference does (`W = cast(W_fp32 + B @ A)`). Explicit flags still win.
   - Splits the audio-waveform encode out of the reference-audio path for reuse.
5. **Docs.** An "Open-H3-Regenerate-2K: 2K draft refinement" subsection in the MiniMax-H3 cookbook, and a model-catalog entry.

## Accuracy / Validation

Setup: 1×H200. The draft is a 5 s, 1344×768 H3 clip (124 frames). Output is 2560×1440, 124 frames, plus stereo audio. The prompt is the draft's own.

| `start_sigma` | Steps | Gen (warm) | Source stage | Refine | Decode |
|---|---|---|---|---|---|
| 0.909 (release default) | 3 | 177 s | 19 s | 98 s | 15 s |
| 0.6 | 3 | ~204 s cold | 19 s | 98 s | 16 s |

- Results match the community's findings on the release:
  - The default σ0 = 0.909 redraws the most detail (waves, sand, fur) and also redraws the subject; the cat loses its tabby stripes.
  - σ0 = 0.6–0.7 keeps identity close to the draft, with 2K detail.
- The low-noise runs show no artifacts from the encode or upscale path.
- Loading the base directly and loading through an overlay prototype produced byte-identical MP4s (same md5).
- Unit tests:
  - `test_minimax_h3_open_regenerate.py` (7): registry and request contract, the reference sigma schedules, the canvas cap, the curve-branch math, upscaler checkpoint loading, and base-release loading (nothing under `base_model/` is fetched).
  - With `test_minimax_h3_*.py`, `test_comfyui_h3.py`, `test_lora_format_adapter.py` and `test_server_args.py`: 605 passed, 3 xfailed, 204 subtests on H200, after rebasing on current main.

## Not yet done / known gaps

- **No direct numeric comparison against the NVlabs reference `infer.py` yet**, i.e. the same draft and seed side by side. That is pending.
- **The end-to-end numbers predate the rebase onto current main.** The feature code is unchanged. **The HTTP `/v1/videos` path with `source_video`, as in the cookbook example, has not been exercised yet**; validation so far used the Python API.
- **One H200 is tight at 2K.** Each run logs one CUDA caching-allocator retry. Multi-GPU (Ulysses) has not been tested.
- There is a ~40 s gap between the end of denoise and decode on long H3 sequences. It exists on main too (it shows up on ref2va as well), so it is out of scope here.
- Not covered: 4K (the reference upscales twice), the fast H3 VAE decoder, and Sol sparse attention.
- Noise RNG streams differ from the reference, so a seed does not reproduce its sample bit-for-bit.
