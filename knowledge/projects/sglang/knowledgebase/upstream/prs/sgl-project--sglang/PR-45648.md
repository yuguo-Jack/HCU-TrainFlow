## Motivation

Provide generic request-lifetime and inventory hooks for an optional KVCR direct linker while preserving current SGLang request-private load safety.

## Modifications

- Snapshot attempt-scoped router hints; release contexts without revoking accepted native transfers.
- Confirm sparse shared-prefix residency and preserve cancellation ownership across request-ID reuse.
- Publish lower-tier inventory only after rank-agreed successful offload; retain removal identity after GPU eviction/reset.
- Mark only opted-in CPU inventory as KVCR-owned. GPU inventory and engine clears remain framework-owned; never coalesce across owners.
- Preserve LoRA namespace identity and optional ownership fields in Python and Rust.
- Existing backends retain no-op/default hooks. No KVCR runtime implementation is introduced here.

Includes attributed Moein/Lin work and its adaptation to newer request-private loading. The old early-tree-publication behavior is not restored.

## Integration

The direct-device backend is a child. Dynamo ai-dynamo/dynamo#16827 provides the external state-agent bridge for opt-in **TP1 aggregated linker** workers. It does not enable the same bridge for HiCache or qualify TP>1/PD.

## Accuracy Tests

Recorded CPU checks: 90 wrapper cases and 24 event cases passed; the initial CPU run skipped 20 CUDA-dependent cases. A subsequent matching Linux production/inspection native build ran **all 110 wrapper cases with zero skips**, including the 20 GPU cases. Exact binary and source identities were verified. An initial test collection failure caused by UUID-vs-numeric CUDA visibility was preserved; only test launch configuration changed for the successful retry.

Locked Rust core/test/binding type checks and formatting also passed. Type checking alone is not a Cargo runtime-test pass.

## Speed Tests and Profiling

No isolated speed claim for generic hooks. The direct-linker leaf reports its exact model acceptance separately; Guard replacement, independent-inventory eviction/recovery and broader configurations remain separate gates.
