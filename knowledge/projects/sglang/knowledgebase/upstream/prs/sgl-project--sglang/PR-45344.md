# [Fix] kda: Pin prefill autotune configs under deterministic inference

[Upstream PR](https://github.com/sgl-project/sglang/pull/45344) · state: open · merged: False

## Original PR description

Triton autotunes the KDA gate cumsum kernel by timing, separately in every process and pipeline rank, and keeps no disk cache. Its configs fall into two groups whose sums round differently, so the greedy output of a server can change from one boot to the next.

With --enable-deterministic-inference, or with SGLANG_KDA_FIXED_AUTOTUNE=1 for attention backends that refuse that flag, the gate cumsum, chunk-local cumsum and chunk output kernels now run one fixed config each. Other autotuned kernels are unchanged.

On GLM-5.3-Flash with three pipeline ranks on SM120, 8 boots that recorded their picks showed the output following the gate kernel's pick on each rank. With that pick pinned to BS 16 and 4 warps, 6 of 6 boots reproduced the reference tokens on 64 of 64 prompts.
