# [Fix] sglang-radix-tree: Upgrade to PyO3 0.29 for Python 3.14 (cherry-pick #42807)

[Upstream PR](https://github.com/sgl-project/sglang/pull/44316) · state: closed · merged: True

## Original PR description

## Motivation

Cherry-pick of #42807 to `amd_march`.

`amd_march` still pins PyO3 0.22 in `rust/sglang-radix-tree`, which supports Python up to 3.13. On Python 3.14 images the Rust TreeCore (the default `SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND`) fails to build at startup and the scheduler exits:

```
error: the configured Python interpreter version (3.14) is newer than PyO3's maximum supported version (3.13)
RuntimeError: failed to build sglang.srt.mem_cache.rust_tree_core.mem_cache with Cargo
```

#42807 moves the crate to PyO3 0.29, which supports Python 3.14.

## Modifications

Same 4 files as #42807 (`rust/Cargo.toml`, `rust/sglang-radix-tree/{Cargo.toml,Cargo.lock,src/python_bindings.rs}`).

Conflict resolution: `python_bindings.rs` had two conflicts, both in methods that exist on `main` but not on `amd_march` (`is_write_through_compatible`, `inspect_get_component_host_lock_ref`). They were dropped, keeping `amd_march`'s version. All other bindings are converted as in #42807.
