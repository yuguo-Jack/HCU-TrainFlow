## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111, #45311, #45513) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR:

1. **Syncs to InferenceX `main`** (`746150a2`). Since #45513, `main` merged the four Muse Spark Open retunes and the GB300 Dynamo+SGLang lane, which are now measured. It also merged image updates (mostly to `v0.5.21-cu130` / `v0.5.22-cu130`) for 14 mirrored lanes on DeepSeek-V4, DeepSeek-V4.1, GLM-5.2, Qwen3.5 and Qwen3.8-Flash-Next.
2. **Overlays five open InferenceX PRs** (table below): a GLM-5.2 FP8 B200 retune with TP8 + DCP8 points, a DeepSeek-V4.1-Flash GB300 disaggregated topology and caching update, and three PRs carried over from #45513 that now have `/use` runs.
3. **Fixes three `pull/XXX` provenance links** (DeepSeek-V4.1 H200 since #45513, Muse Spark Open B200 / B300 new). Their InferenceX changelog entries were merged with a placeholder PR link; the links now name the PR that the measured commit belongs to.

## How the commands are produced

The pipeline is the same as in #45513, with these changes:

- **Merged lanes without dashboard rows.** A merged key whose newest dashboard changelog has no rows is pinned to its PR's authorized, successful `/use` run, if that run's commit has the key. This applies to [InferenceX #4176](https://github.com/SemiAnalysisAI/InferenceX/pull/4176) and [InferenceX #4227](https://github.com/SemiAnalysisAI/InferenceX/pull/4227) above. It is the same rule already used for merges that were never ingested.
- **Placeholder PR links.** A dashboard changelog that links `pull/XXX` is credited to the InferenceX PR that the measured commit belongs to.
- **Rules.** These are kept as submitted:
  - worker flags `--dcp-size`, `--prefill-delayer-max-delay-ms`, `--prefill-delayer-queue-min-ratio` and `--disaggregation-decode-polling-interval`;
  - the Mooncake master flag `--client_ttl`;
  - the Dynamo variable `DYN_EVENT_PLANE`.

Each lane is still rendered at the exact commit of the run that produced its data, or at the PR head while in progress.
- **Removed (SA-only settings):** the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment).
- **Replaced with placeholders:** IPs, ports and NICs.
- **Derived variants:** router and KV-offload variants that were not run are derived and labeled "Derived — not run".

The data files are generated, so there is no hand-written code to review here.
