# [Perf] deepseek-v4.1: Use reduce-scatter for CP MoE output

[Upstream PR](https://github.com/sgl-project/sglang/pull/47247) · state: open · merged: False

## Original PR description

## Motivation

The contiguous CP MoE output path all-reduces the full expert output and then selects each CP rank's local rows. When CP spans the entire TP group, reduce-scatter can directly produce the reduced local rows and reduce communication.

## Modifications

- Use `reduce_scatter_tensor` in `MoeRowTransport.return_output` for the contiguous CP output path.
- Enable it for CUDA tensors on non-HIP platforms when TP size, CP size, and TP group size match, and the row count is nonzero and divisible by CP size.
- Allocate the local output buffer and retain the existing all-reduce/split fallback for other cases.

## Accuracy Tests

- Manual four-GPU validation covered row ownership, empty and uneven inputs, noncontiguous inputs, fallback paths, and CUDA Graph replay. Exact-value checks passed for integer-valued inputs.
- BF16 results can differ because the reduction order changes; bitwise equivalence is not guaranteed.
- GSM8K: 1274/1319 correct with this change versus 1275–1279/1319 across unchanged baseline runs. Model-level accuracy parity is not yet established.

## Speed Tests and Profiling

Profiled DeepSeek V4.1 prefill on four H200 GPUs with TP=CP=EP=4, approximately 0.9\0.7\0.5 prefix-cache hit ratio.

The matched steps both use `[16240, 5120]` BF16 communication input and 40 MoE output collectives per rank. GPU kernel durations summed over those 40 calls:

| Rank | All-reduce baseline (ms) | Reduce-scatter (ms) | Reduction |
| --- | ---: | ---: | ---: |
| 0 | 68.346 | 52.673 | 22.93% |
| 1 | 71.672 | 57.369 | 19.96% |
| 2 | 59.915 | 50.691 | 15.40% |
| 3 | 60.526 | 44.981 | 25.68% |

Across six baseline and seven optimized nearby `bs=5` steps, mean MoE output communication time per rank decreased by 19.4%–21.7%. Mean forward GPU span, taking the slowest rank per step, changed from 606.244 ms to 595.320 ms in those samples.
