# Add DP‑Draft to run draft model with TP=1

[Upstream PR](https://github.com/sgl-project/sglang/pull/17418) · state: closed · merged: False

## Original PR description

## Summary
Add DP‑Draft so draft models run locally with TP=1 on each GPU while the target keeps full distributed parallelism, reducing unnecessary communication. DP‑Draft requires the spec‑v2 runtime and supports different draft models (e.g., DeepSeek‑NEXTN, Kimi‑K2‑Instruct‑Eagle3).
- RFC: https://github.com/sgl-project/sglang/issues/14343

## Key changes
- Add `--speculative-dp-draft` flag (EAGLE/EAGLE3 + spec‑v2 enabled).
- Add `patch_moe_parallel_groups` to safely override MoE TP/EP groups.
- Add `DPDraftWorker` / `_DPDraftGroup` to enable DP‑Draft execution.
- Notes
Model‑agnostic: DP‑Draft is architecture‑agnostic for the draft model as long as it runs on the EAGLE/EAGLE3 spec‑v2 path; it can be applied to a wide range of Eagle/NextN variants (e.g., Llama / Qwen2 / MistralLarge3 / DeepSeek / GLM4‑MoE).
Dense models are a better fit: For MoE drafts, EP=1 concentrates all experts on a single GPU and can lead to more fragmented kernel shapes, so throughput may not improve.
Communication‑heavy regimes: DP‑Draft reduces draft‑side cross‑GPU communication and synchronization , which is advantageous when communication overhead is a large fraction of step time.

## Test (H20‑3e 141GB， pd disaggregation，prefill tp8  decode tp16/ep16 + draft)
SGLANG_ENABLE_SPEC_V2=true \
SGLANG_ENABLE_JIT_DEEPGEMM=1 \
python3 -m sglang.launch_server \
  --model-path /path/to/Kimi-K2-Instruct \
  --speculative-draft-model-path /path/to/Kimi-K2-Instruct-eagle3 \
  --speculative-algorithm EAGLE3 \
  --speculative-num-steps 3 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 4 \
  --speculative-dp-draft \
  --attention-backend fa3 \
  --disaggregation-mode decode \
  --disaggregation-transfer-backend mooncake \
  --tp-size 16 \
  --dp-size 16 \
  --moe-a2a-backend deepep \
  --deepep-mode low_latency \
  --enable-dp-attention \
  --enable-dp-lm-head \
  --mem-fraction-static 0.7 \
  --cuda-graph-max-bs 16 \
  --max-running-requests 256 \
  --page-size 64
