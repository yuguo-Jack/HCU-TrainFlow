# [Feat] sgl-router: Fix cache-aware routing for MTP/EAGLE on hybrid (Mamba/KDA) models

[Upstream PR](https://github.com/sgl-project/sglang/pull/44252) · state: closed · merged: True

## Original PR description

Stacked on https://github.com/sgl-project/sglang/pull/44243.

## Motivation

With `--speculative-algorithm EAGLE` (MTP), cache-aware routing never matches on hybrid linear-attention models (Qwen3.5, GLM-5.3-Flash):

- The router picks bigram block hashing whenever `speculative_algorithm` is EAGLE-family (`classify_bigram`).
- The engine uses bigram radix keys for EAGLE only when the model has **no** Mamba/linear-attention layers (`unified_tree_core.py`, `rust_tree_core/adapter.py`).

So hybrid workers publish unigram block hashes, the router queries with bigram hashes, and same-prefix requests spread by load instead of following the cache.

## Modifications

Router only. `/server_info` already reports `uses_mamba_radix_cache`, so both discovery paths (`workers/introspect.rs`, primary; `state/kv_events/discovery.rs`, fallback) now use
`is_bigram = classify_bigram(speculative_algorithm) && !uses_mamba_radix_cache`.
No engine change is needed, so this also fixes routing for engines already deployed.

Known gap: `uses_mamba_radix_cache` comes from an architecture list (`arg_groups/overrides.py`), while the engine's bigram rule uses `uses_ssm_state()`. They agree for every hybrid model I checked (GLM-5.3-Flash / `Glm5NextForConditionalGeneration`, the Qwen3.5/3.8 family, Kimi Linear, NemotronH), except `MiniCPMSALAForCausalLM`. That model with EAGLE would still hash bigrams, which is no worse than today.

## Verification

- `cargo test --lib -- is_bigram introspect kv_events::discovery`: 35 passed, including a new test (EAGLE + `uses_mamba_radix_cache: true` gives `is_bigram=false`).
- End to end against the **stock** engine (no engine patch): 2× Qwen3.5-27B workers with the cookbook MTP flags (`--speculative-algorithm EAGLE --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4`), `--policy cache_aware`, and 11 same-prefix chat requests after flushing both caches:

| Router | `is_bigram` at subscribe | Split |
|---|---|---|
| base | `true` | 5/6 |
| this PR | `false` | 11/0 |
