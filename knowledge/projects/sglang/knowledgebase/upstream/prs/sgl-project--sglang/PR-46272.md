# [Perf] scheduler/hicache: Replace O(B^2) request and page list scans in ScheduleBatch.filter_batch, BatchResultProcessor, and RankMetadata

[Upstream PR](https://github.com/sgl-project/sglang/pull/46272) · state: open · merged: False

## Original PR description

## Motivation

While profiling CPU-side batch bookkeeping and HiCache storage metadata operations in SGLang, we identified three linear list-membership bottlenecks on hot paths:

1. **`ScheduleBatch.filter_batch` (`python/sglang/srt/managers/schedule_batch.py`)**:
   When `keep_indices is None`, `self.reqs[i] not in reqs_to_exclude` scanned `reqs_to_exclude` as a Python `list` for every request in `self.reqs`, taking $O(|\text{reqs}| \cdot |\text{reqs\_to\_exclude}|)$ time during running-batch filtering (`finishing_reqs`) and disaggregation prefill filtering.
2. **`SchedulerBatchResultProcessor.process_batch_result_prefill` (`python/sglang/srt/managers/scheduler_components/batch_result_processor.py`)**:
   During mixed chunked-prefill batches (`batch.decoding_reqs`), `req in batch.decoding_reqs` / `req not in batch.decoding_reqs` was evaluated up to three times per request in `batch.reqs` via linear `list` scans ($O(|\text{reqs}| \cdot |\text{decoding\_reqs}|)$), whereas `SchedulerMetricsReporter` (`metrics_reporter.py`) already precomputes an $O(1)$ `id(req)` set.
3. **`RankMetadata.confirm_write` / `delete_keys` (`python/sglang/srt/mem_cache/storage/hf3fs/mini_3fs_metadata_server.py`)**:
   Checking `if page_index not in self.free_pages:` scanned the `free_pages` list linearly on every released or deleted page ($O(P \cdot |\text{free\_pages}|)$).

## Modifications

- **`python/sglang/srt/managers/schedule_batch.py`**: Precompute `reqs_to_exclude_ids` as an $O(1)$ set of object IDs before building `keep_indices` in `ScheduleBatch.filter_batch` (**126.1x speedup** at 4,096 requests with 512 excluded: `17.21 ms` -> `0.136 ms`).
- **`python/sglang/srt/managers/scheduler_components/batch_result_processor.py`**: Lazily materialize `decoding_req_ids = {id(r) for r in batch.decoding_reqs}` once per batch when processing completed prefill/mixed chunks and reuse `is_decoding_req = id(req) in decoding_req_ids` across all three checks (**184.2x speedup** on mixed-batch membership checks at 4,096 decoding requests: `65.40 ms` -> `0.355 ms`).
- **`python/sglang/srt/mem_cache/storage/hf3fs/mini_3fs_metadata_server.py`**: Maintain a companion `free_pages_set: set[int]` alongside `RankMetadata.free_pages` across `reserve_and_allocate_page_indices`, `confirm_write`, `delete_keys`, `clear_all`, and `GlobalMetadataState.load_from_disk` (**819x speedup** releasing 2,000 pages against 50,000 free pages: `737.4 ms` -> `0.90 ms`).
- **`test/registered/unit/managers/test_schedule_batch_req_pool_indices.py`**: Add unit tests `TestFilterBatchReqsToExclude` and `TestHf3fsRankMetadataSet`.
