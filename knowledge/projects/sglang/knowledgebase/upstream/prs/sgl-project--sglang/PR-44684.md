# [Feat] HiSparse: Support DeepSeek-V4 with MTP and DSpark

[Upstream PR](https://github.com/sgl-project/sglang/pull/44684) · state: open · merged: False

## Original PR description

## Accuracy Validation

Evaluated **DeepSeek-V4-Flash-FP8** on GSM8K using **40-shot chat prompts**. The first 40 test examples were used as demonstrations, and the remaining **1,279 examples** were scored.

Actual prompt lengths ranged from **6,600 to 6,763 tokens**, ensuring every input exceeded the 4K boundary.

### Configuration

- **Hardware:** 8× H20-3e, TP=8.
- **Serving:** `dsv4` / `flashmla`, FP8 KV cache, 16K context, client concurrency=4.
- **Generation:** `temperature=0`, `top_p=0.95`; no explicit output-token cap or custom stop strings.
- **MTP:** EAGLE with 3 speculative steps, top-k=1, and 4 draft tokens.
- **DSpark:** block size=5.
- **HiSparse:** `top_k=512`, `device_buffer_size=1024`, `host_to_device_ratio=2`.
### Results

| Mode | HiSparse | Correct / Total | Accuracy |
|---|---|---:|---:|
| MTP | Disabled | 1241 / 1279 | **97.03%** |
| MTP | Enabled | 1237 / 1279 | **96.72%** |
| DSpark | Disabled | 1238 / 1279 | **96.79%** |
| DSpark | Enabled | 1238 / 1279 | **96.79%** |
