# [Perf] [AMD] GLM5: Fuse mHC boundaries and expose FP8 prequant on gfx950

[Upstream PR](https://github.com/sgl-project/sglang/pull/43016) · state: open · merged: False

## Original PR description

## Motivation

GLM-5.3-Flash executes mHC post mixing, the next stage's pre projection and square-sum, RMSNorm finalization, and per-token FP8 quantization as separate work.

This change integrates the packed-BF16 post/pre path from [AITER #6162](https://github.com/ROCm/aiter/pull/6162) and the fused RMSNorm plus FP8 quantization path from [AITER #6070](https://github.com/ROCm/aiter/pull/6070). Nonterminal FFN updates are deferred to the next layer's attention read, and the optional FP8 activation is exposed to the separate KDA PTPC consumer in [SGLang #38764](https://github.com/sgl-project/sglang/pull/38764).

## Modifications

- Cache packed mHC attention and FFN weights by parameter identity and version.
- Enable packed-BF16 mHC post/pre for validated GLM-5.3 prefill cells at `M={4096,8192,16384,131072}`.
- Defer nonterminal FFN updates and fuse 45 attention-to-FFN plus 44 FFN-to-next-attention boundaries.
- Keep terminal FFN write-back and pipeline-parallel handoff on explicit nondeferred paths, and thread the active forward phase through residual reads so token count alone cannot activate prefill dispatch.
- Integrate AITER 6070's `mhc_pre_quant` and `mhc_fused_post_pre_quant` APIs behind a consumer capability check.
- Preserve BF16 for decode and for every unsupported phase, shape, backend, layout, terminal boundary, pipeline-parallel handoff, missing AITER API, or absent consumer.

The complete stacked path is selected with:

```bash
SGLANG_USE_AITER=1
SGLANG_OPT_GLM53_KDA_PTPC_MODULES=qkv_proj,f_a_proj,g_a_proj,o_proj
```

## Accuracy Tests

Full GLM-5.3-Flash GSM8K, 1,319 examples, thinking enabled, temperature 1.0, top-p 0.95, sampling seed unset, and zero request errors:

| TP | PTPC-only | Unified mHC + PTPC | Delta |
| ---: | ---: | ---: | ---: |
| 4 | 97.27% | 96.89% | -0.38 pp |
| 8 | 96.97% | 96.97% | 0.00 pp |

Both arms used identical settings per TP. TP8 used a 131,072-token context, 1,200 evaluator threads, and 4,096 maximum output tokens. Decode CUDA graphs were enabled for TP4 and TP8.

Component validation: **22 tests passed, 5 subtests passed** on this branch. The stacked mHC/PTPC contracts passed **30 tests and 17 subtests**, and the combined AITER #6162/#6070 suite passed **37 tests**. Coverage includes phase gating, packed-weight cache invalidation, fallbacks, optional prequant handoff, terminal and pipeline-parallel boundaries, determinism, and graph replay.

## Speed Tests and Profiling

Environment:

- Hardware: AMD Instinct MI355X (`gfx950`)
- Docker image: `rocm/sgl-dev:v0.5.21-rocm724-mi35x-20261001`

Baseline source `c240e41bb3ce4d0576f438f0655be5f172815e03` and candidate snapshot `e856f0fce764d9d4f81ca51b1239d63075990153` differ only by the unified mHC integration. Both arms use model snapshot `03eb5366286afd40d2221b1d9c63a6dd1ba4832e`, AITER `471985e686444c9edbe80c3f1081442bfca89bbd`, and the same PTPC selector and serving arguments.

Complete boundary includes post mixing, the next pre projection and square-sum, and RMSNorm:

| Component | M | Decomposed path (us) | Packed post/pre (us) | Delta |
| --- | ---: | ---: | ---: | ---: |
| post/pre | 4,096 | 140.87 | 113.12 | -19.70% |
| post/pre | 8,192 | 264.26 | 221.75 | -16.09% |
| post/pre | 16,384 | 513.65 | 479.23 | -6.70% |
| post/pre | 131,072 | 4,208.11 | 3,678.42 | -12.59% |

Every enabled cell beats the decomposed path. Decode remains on the existing FP32 path.

### Fused finalization and quantization latency

The candidate adds fused RMSNorm finalization and per-token FP8 quantization to the packed post/pre path:

| Component | M | Packed post/pre (us) | Unified path (us) | Delta |
| --- | ---: | ---: | ---: | ---: |
| finalization/quant | 4,096 | 113.12 | 109.40 | -3.29% |
| finalization/quant | 8,192 | 221.75 | 216.10 | -2.55% |
| finalization/quant | 16,384 | 479.23 | 450.54 | -5.99% |
| finalization/quant | 131,072 | 3,678.42 | 3,482.73 | -5.32% |

The complete unified path is 12.29-22.34% faster than the decomposed baseline.
