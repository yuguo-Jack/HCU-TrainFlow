# fix(xpu): align TorchCodec with Torch 2.13

[Upstream PR](https://github.com/sgl-project/sglang/pull/40774) · state: closed · merged: False

## Original PR description

## Motivation

The XPU manifest pins `torch==2.13.0+xpu` but currently selects `torchcodec==0.13.0`. TorchCodec-XPU 0.13 targets Torch 2.12 and can downgrade or conflict with the existing XPU stack. TorchCodec-XPU 0.15 is the matching release for Torch 2.13 and requires the corresponding base TorchCodec 0.15 package.

## Modifications

- update the XPU manifest from `torchcodec==0.13.0` to `torchcodec==0.15.0`
- add `torchcodec-xpu==0.15.0` for Linux x86_64
- preserve the existing Torch 2.13.0+XPU and Triton-XPU stack

Related SGLang-Omni PR: https://github.com/sgl-project/sglang-omni/pull/2312

## Accuracy Tests

This is a dependency-manifest-only change and does not alter model numerics. Validation performed in the Intel XPU qualification environment:

- dependency resolution retained `torch==2.13.0+xpu` and `triton-xpu==3.7.2`
- `torchcodec==0.15.0` and `torchcodec-xpu==0.15.0` imported successfully with VAAPI-enabled FFmpeg 6.1
- `torchaudio.load` decoded a 24 kHz WAV successfully
- MiniCPM-o speech smoke returned HTTP 200 and a valid 3.72-second WAV
- XPU manifest assertions and repository pre-commit checks passed on the rebased head

Not applicable; this only corrects dependency selection.
