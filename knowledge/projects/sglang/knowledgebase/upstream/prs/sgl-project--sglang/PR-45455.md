# [Doc] cookbook: Add DeepReinforce Ornith-1.5

[Upstream PR](https://github.com/sgl-project/sglang/pull/45455) · state: closed · merged: True

## Original PR description

## Motivation

Provide an Ornith-1.5 deployment guide alongside the existing Ornith-1.0 cookbook.

## Modifications

Add an Ornith-1.5 cookbook page with interactive deployment commands for 9B, 35B-A3B, 122B, and 397B, plus the published 35B-A3B and 397B FP8 checkpoints. Recipes cover H100 and H200 where configured, including 8-GPU TP=8 deployment for 122B on both platforms. All examples use the `ornith-ai` model repositories, port 30000, and the `qwen3` / `qwen3_coder` parsers.

Document model architecture, sampling settings, OpenAI-compatible chat and tool calling, and agent integration using the official model cards and 122B configuration. Add the navigation entry, point the DeepReinforce overview card to 1.5, and retain the 1.0 page.

Includes a separate one-line fix removing an extra closing brace in `docs/src/snippets/configs/popular-models.jsx`, which otherwise prevents the documentation from parsing.

## Accuracy Tests

Documentation-only change; model forward code is unchanged. GPU inference and accuracy were not measured, so recipes retain the unverified status.

## Speed Tests and Profiling

Not applicable; no serving-performance changes or benchmark results are claimed.
