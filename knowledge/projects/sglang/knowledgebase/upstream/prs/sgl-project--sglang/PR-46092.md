# [Perf] dsv41: Add replicated and hybrid Engram host-table layouts

[Upstream PR](https://github.com/sgl-project/sglang/pull/46092) · state: closed · merged: False

## Original PR description

## Motivation

With `SGLANG_ENABLE_DSV41_ENGRAM_HOST_TABLE=1`, the existing layouts trade off as follows on a two-socket host:
- **`shared`**: one copy of each Engram table, which sits on whichever NUMA node first touches it. On nodes where shmem transparent huge pages are disabled, that copy also gets no huge pages. Ranks on the other socket then gather rows across the CPU interconnect, through small pages.
- **`per_rank`**: gets huge pages, but needs a reduce-scatter/all-reduce per lookup.

In DeepSeek-V4.1 prefill, the Engram gather on the far-socket ranks becomes a large share of each chunk. Mega MoE waits for the slowest rank, so that cost reaches every rank.

#40106 (`numa_shared`) addresses the cross-socket part with one memfd copy per NUMA node. It still uses shmem, so it gets no huge pages where shmem THP is `never`. This PR takes a different route, and the two can coexist.

## Modifications

`SGLANG_DSV41_ENGRAM_HOST_TABLE_LAYOUT` gains two values:
- **`replicated`**: a private copy of the full table per rank, in the anonymous huge-page mapping that `per_rank` already uses. With per-rank NUMA binding (the rank's CPU affinity covering its GPU's socket), first touch places the copy next to the GPU. Lookups gather locally with no collective, like `shared`. The cost is host memory: about the TP size times `shared`'s.
- **`hybrid`**: the shared copy plus huge-page per-rank shards. Forwards with at least `SGLANG_DSV41_ENGRAM_HYBRID_MIN_TOKENS` (default 4096) tokens summed over the DP ranks read the shards, which means prefill chunks. Smaller forwards (decode) read the shared copy. It uses roughly half the host memory of `replicated`.

Defaults are unchanged (`shared`). The scheduler-side staging added on main still applies to the full-row layouts.

## Accuracy and speed

DeepSeek-V4.1-Flash, DEP4, 128K prompts, on a CC 10.7 node with two CPU sockets and per-rank NUMA binding. Arms ran ABBA in one job:
- Both layouts substantially improve prefill throughput and single-request TTFT over `shared`.
- Decode is unchanged within noise.
- GSM8K is unchanged.
