# [Feat] PD: Validate speculative KV layout

[Upstream PR](https://github.com/sgl-project/sglang/pull/48129) · state: closed · merged: False

## Original PR description

## Summary

- Exchange an opt-in peer fingerprint through the Python and Rust PD bootstrap registries.
- Validate resolved checkpoint identity, speculation that requires prefill-injected draft KV, and one-to-one KV layouts before decode registration.
- Preserve legacy-peer behavior, heterogeneous EAGLE/NEXTN deployments, decode-only runtime overrides, and custom speculative algorithms.
- Reject inconsistent model or speculation identities across prefill ranks before publishing readiness.

## Why Mistral Large 4 needs this

Mistral Large 4 PD with DSpark materializes the draft model's context KV during prefill from target hidden states. Decode cannot rebuild those KV bytes from the transferred token metadata alone. The prefill and decode must therefore use the same checkpoint, DSpark configuration, and KV layout before any destination buffer is registered.
