# [Feat] diffusion: Add opt-in pi0.5 completion-boundary action batching

[Upstream PR](https://github.com/sgl-project/sglang/pull/44634) · state: closed · merged: True

## Original PR description

## Motivation

Continue #43528, originally implemented by @dadiaokua. Thanks for the implementation and Ascend validation. The original commits and authorship are preserved here; this PR adds the review fixes because maintainer edits are disabled on the original branch.

Pi0.5 requests with different denoising budgets can execute together up to the next completion boundary. Finished requests return actions; unfinished requests retain their original noise, Euler grid, latent, prefix and FCFS age before joining another compatible batch. Related to #43522.

## Modifications

- Keep the feature disabled by default. Only the denoising-budget signature is relaxed; other admission checks remain in place.
- Preserve FIFO ordering for controls and actions received in the same poll, without injecting arrival attributes into request objects.
- Compact parked prefix/latent slices and release grouped observation references so survivors do not retain retired requests' GPU storage. Already compact and server-cached prefixes avoid redundant copies.
- Restore batch dispatch logs and Prometheus metrics. Continuations retain their original ordering, but queue-wait measurements exclude earlier execution time.
- Add focused regressions and update the usage example.

Initial scope remains monolithic pi0.5, SP=1, no CFG parallelism or per-request action-expert offload. Stateful realtime and multi-output requests use the ordinary path. Prefix/action CUDA graphs remain disabled for segmented execution.

## Accuracy Tests

- 88 pi0.5 segment, scheduler, stage, API, prefix-cache and runtime tests passed again after merging latest main, at `884823db9129`, in an isolated H200 environment: PyTorch 2.14.1+cu130, Transformers 5.19.0, FlashInfer 0.7.1. The CUDA synthetic continuation/storage check also passed again on this head.
- The three regression cases fail on the original production code and pass with these fixes.
- A CUDA synthetic continuation test is bitwise equal to its unsplit Euler reference. Retained allocated memory for an eight-member prefix cohort drops from approximately 128 MiB to 16 MiB after compaction. This measures retained synthetic state, not full-model peak VRAM; compaction needs a transient copy.
- Pre-commit passed on all 12 files in the PR diff after merging main.

The original author's full-checkpoint Ascend TP1/TP2 checks are documented in #43528. They are not new CUDA validation. Full-checkpoint CUDA accuracy, multi-device validation and task quality remain pending.

## Speed Tests and Profiling

No E2E speedup claim. Full-model mixed/homogeneous-budget latency, throughput and peak-VRAM benchmarks remain pending. Historical downstream-prototype results in #43522 are not measurements of this implementation.
