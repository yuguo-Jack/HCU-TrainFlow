## Motivation

<!-- Describe the purpose and goals of this pull request. -->

#43482 added NIXL UCX support for `--disaggregation-ib-device`, but the generated `device_list` overrides `UCX_NET_DEVICES`. This can drop `lo` and cause NIXL initialization to fail on affected AMD RoCE hosts.

#45674 fixes the AMD e2e test configuration. This PR addresses the same compatibility issue in serving deployments.

## Modifications

<!-- Detail the changes made in this pull request. -->

Preserve explicit UCX device configuration with the following precedence:

1. An explicit backend `device_list` retains its existing behavior and overrides `UCX_NET_DEVICES`.
2. Otherwise, a non-empty `UCX_NET_DEVICES` takes precedence over `--disaggregation-ib-device`; the CLI selection is skipped with a warning.
3. When `UCX_NET_DEVICES` is unset or empty, CLI selection continues to support shared and per-GPU HCA mappings.

No environment variables are modified. Other transfer backends are unchanged.
