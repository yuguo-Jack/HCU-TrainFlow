[Upstream PR](https://github.com/sgl-project/sglang/pull/45255) · state: closed · merged: False

## Original PR description

## Motivation

Split #44747 into reviewable parts. This is the attention, memory and DFlash DP part, position 4 of 8 in the merge order below. Like every part it targets `main`; its branch also carries #45254, so its diff includes it.

## Modifications

Adds the shared runtime support Beam relies on:
- TRT-LLM MHA: mixed decode with FP8 KV, the fmha_v2 prefill workspace and page copies, unified page-table bounds.
- FlashInfer ragged prefill for sliding windows and cached prefixes.
- Unified hybrid SWA memory and SWA HiCache.
- DFlash with attention DP.
- FlashInfer MegaMoE all-to-all under attention DP, with an optional decode-only workspace (`SGLANG_FLASHINFER_MEGAMOE_DECODE_MAX_TOKENS_PER_RANK`).
- PD token-ID logprob streaming, the speculative metrics fallback, and the NCCL graph-buffer registration guard.
- The tests for all of the above.

This part still carries the cherry-picks made on the `beam` branch:
- #42930 (7 commits), #43168 and #43170, all merged upstream since. Each was picked before its final revision.
- #43169, which was closed in favor of #39294.
- The commits of #43216, still open.

They will be reverted or dropped when the parts are synced with main.

This part changes **44 files (+3,115 / -226)** beyond the parts its branch carries. The split commit carries the 18 `Co-authored-by` trailers of the Beam commits that touched these files.
