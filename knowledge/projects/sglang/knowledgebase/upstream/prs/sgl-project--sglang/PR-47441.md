# [Docs] [AMD] Add MiMo-V2.6 MI355X INT4 QuickReduce recipe

[Upstream PR](https://github.com/sgl-project/sglang/pull/47441) · state: open · merged: False

## Original PR description

## Summary

- add an eight-GPU MI355X launch recipe for MiMo-V2.6-Pro
- select AITER for MoE and attention
- explicitly enable `ROCM_QUICK_REDUCE_QUANTIZATION=INT4`
- retain the validated TP8/EP8 DFLASH topology

## Validation

Internal ITT/MLflow validation on the complete MI355X DFLASH stack showed INT4 QuickReduce improving the two long-context anchors by 3.24% and 3.63%. The final composed stack improved the 12-point OOB throughput geomean by 5.57% and scored 0.7121 on GPQA.

This remains a draft because the complete recipe composes pending DFLASH graph metadata, P1, P4, and AITER changes; this PR tracks the deployment/config part independently.
