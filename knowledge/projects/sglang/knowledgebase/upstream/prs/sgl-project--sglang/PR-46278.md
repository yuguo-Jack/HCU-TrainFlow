# [Feat] [NPU] dspark: Integrate native sampling and verification kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/46278) · state: closed · merged: True

## Original PR description

## Motivation

DSpark draft generation and verification on Ascend can benefit from dedicated NPU implementations of projection/add/argmax, temperature softmax, and draft acceptance.

This PR connects SGLang to the corresponding `sgl-kernel-npu` APIs and selects NPU implementations using actual tensor placement, including environments where `transfer_to_npu` aliases CUDA device checks.

Companion kernel PR: https://github.com/sgl-project/sgl-kernel-npu/pull/899.

## Modifications

- Route `MarkovGreedyStep` to the NPU implementation with native projection and dtype-correct addition before token selection.
- Route FP32 row argmax and DSpark greedy verification through the NPU argmax implementation.
- Dispatch temperature softmax and the shared DFlash/DSpark accepted-prefix and bonus-token calculation to dedicated NPU kernels.
- Add NPU dispatch tests covering device selection, numerical behavior, and integration boundaries.

`MarkovSampleStep` dispatch changes are excluded from the current diff.
