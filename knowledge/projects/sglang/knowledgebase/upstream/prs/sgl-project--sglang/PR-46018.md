# [Fix] humming: adapt integration to kernels 0.1.18

[Upstream PR](https://github.com/sgl-project/sglang/pull/46018) · state: closed · merged: True

## Original PR description

## Motivation

Bump `humming-kernels` from 0.1.12 to 0.1.18 and adapt the integration to the newer quantization APIs

## Modifications

- Use schema-based weight quantization and preserve static, secondary, and per-shard scales.
- Handle Hadamard quantization when loading CPU checkpoint weights.
- Preserve both input scale levels and allocate buffers using each MoE sublayer's input dtype.
- Align indexed MoE routes separately when `w13` and `w2` use different M tiles; validate DeepEP and masked quantization compatibility.
- Place Humming cache and temporary files under `SGLANG_CACHE_DIR`, preserving explicit overrides.
- Add unit and GPU regression coverage.

## Accuracy Tests

GSM8K, all 1319 questions, [sgl-eval](https://pypi.org/project/sgl-eval/) 0.1.3 (zero-shot chat, `temperature=0`, `max_tokens=4096`, thinking off, 32 concurrent requests). 1 × 8-GPU H20-3e node.
A = baseline SGLang (container image) + humming-kernels 0.1.12, B = this PR + humming-kernels 0.1.18. Launch commands are under [Benchmark](#launch).

| Model | A | B |
|---|---:|---:|
| DeepSeek-V4-Flash-0731 (TP4, DSPARK) | 96.66% | 97.12% |
| GLM-5.3-W4AFP8-AWQ (TP8, EAGLE) | 96.51% | 97.19% |
| Kimi-K2.6 (TP8, EAGLE3) | 97.42% | 97.50% |

No request errors on any arm; one run per arm.

## Benchmark

1 × 8-GPU H20-3e node, A and B back-to-back on the same GPUs, `bench_serving` with `temperature=0`, one warmup pass per point.

### Launch

All arms set `SGLANG_HUMMING_INPUT_QUANT_CONFIG='{"dtype":"float8e4m3"}'`. A and B use identical flags.

```bash
# DeepSeek-V4-Flash-0731 (GPUs 0-3)
python3 -m sglang.launch_server --model-path DeepSeek-V4-Flash-0731 --tp 4 --trust-remote-code \
  --speculative-algorithm DSPARK --mem-fraction-static 0.88 \
  --moe-runner-backend humming --quantization humming \
  --disable-radix-cache --context-length 270336 --stream-interval 1 --random-seed 1

# GLM-5.3-W4AFP8-AWQ
python3 -m sglang.launch_server --model-path GLM-5.3-W4AFP8-AWQ --tp 8 --trust-remote-code \
  --speculative-algorithm EAGLE --speculative-num-steps 5 --speculative-eagle-topk 1 --speculative-num-draft-tokens 6 \
  --mem-fraction-static 0.8 --reasoning-parser auto --tool-call-parser auto --disable-shared-experts-fusion \
  --moe-runner-backend humming --quantization humming \
  --disable-radix-cache --context-length 270336 --stream-interval 1 --random-seed 1

# Kimi-K2.6 (also SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1)
python3 -m sglang.launch_server --model-path Kimi-K2.6 --tp 8 --trust-remote-code \
  --speculative-algorithm EAGLE3 --speculative-draft-model-path Kimi-K2.6-Eagle3-Long-Context \
  --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4 \
  --reasoning-parser kimi_k2 --tool-call-parser kimi_k2 --disable-shared-experts-fusion \
  --moe-runner-backend humming --quantization humming \
  --disable-radix-cache --context-length 270336 --stream-interval 1 --random-seed 1
```
