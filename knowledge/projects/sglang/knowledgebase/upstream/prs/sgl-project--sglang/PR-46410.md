# [Refactor] multimodal: [MM refactor 4/9] Split feature transport and preprocessing placement out of the base processor

[Upstream PR](https://github.com/sgl-project/sglang/pull/46410) · state: open · merged: False

## Original PR description

## Motivation

Feature transport and preprocessing placement are methods on `BaseMultimodalProcessor`; a second serving processor would have to copy them.

## Modifications

- `MultimodalFeatureTransport` (`multimodal/transport/feature_transport.py`): the transport state and methods, held by the processor.
- `multimodal/serving_preprocessing.py`: placement device, automatic worker count and HF image token counts as functions.
- The base processor forwards to both, so model overrides keep working. The seven `refactor(move)` commits are proven byte-for-byte.

## Tests

Transport, device selection and processor tests, patched at the new modules.
