# [HiCache] Avoid full-store scans for uncached file prefix lookups

[Upstream PR](https://github.com/sgl-project/sglang/pull/42077) · state: open · merged: False

## Original PR description

## Motivation

Fixes #42070. With the default metadata-cache-disabled HiCache file backend, `batch_exists_v2` enumerates every stored file to answer a small prefix query. Lookup work therefore grows with unrelated cached pages.

This changes the uncached lookup to probe only requested component paths. #29716 added the optional metadata cache; this fixes the default uncached path without changing that option or its semantics. Issue-number and area-keyword searches found no open PR covering this fix.

## Modifications

- Replace the full-directory scan with per-target `os.path.isfile` checks, preserving the distinction between regular files and directories.
- Reuse the registered CPU file-backend suite for a regression covering KV/Mamba prefix hits, a `.bin` directory, external deletion, and empty queries while directory scanning is forbidden.
- Keep the metadata-cache-enabled path, key suffixes, pool hit policies and storage data format unchanged.

## Accuracy Tests

This is filesystem lookup scheduling, with no kernel, model-forward or sampling changes. No model accuracy evaluation was run; the checks below establish backend behavior, not model-level accuracy.

## Speed Tests and Profiling

CPU filesystem microbenchmark of the actual `batch_exists_v2` path on a warm local filesystem. Fixed 16 requested keys, KV plus Mamba (32 component paths), metadata cache disabled; seven paired runs per directory size, ten calls per arm per run, alternating arm order. Baseline method is extracted directly from main `41cbe65de05b209f3263942389267f79bd749d6a`. Times are medians of the seven per-run mean lookup times.

| Total files | Baseline lookup | Changed lookup |
| ---: | ---: | ---: |
| 1,000 | 0.436 ms | 0.089 ms |
| 10,000 | 4.153 ms | 0.083 ms |
| 50,000 | 22.107 ms | 0.090 ms |

At 50,000 files the baseline seven-run range was 21.573–23.797 ms, versus 0.085–0.141 ms changed. This establishes reduced lookup cost and scaling with requested paths rather than unrelated directory entries. **It is not an end-to-end inference throughput or TTFT benchmark.** No cold-cache, network-filesystem or GPU serving benchmark was run; dense queries requesting most files may have different tradeoffs.

```python
import ast
import json
import os
import statistics
import subprocess
import tempfile
import time
import types
from pathlib import Path

import sglang.srt.mem_cache.hicache_storage as storage
from sglang.srt.environ import envs

root = Path.cwd()
source = subprocess.check_output(['git', '-C', str(root), 'show', '41cbe65de05b209f3263942389267f79bd749d6a:python/sglang/srt/mem_cache/hicache_storage.py'], text=True)
tree = ast.parse(source)
cls = next(n for n in tree.body if isinstance(n, ast.ClassDef) and n.name == 'HiCacheFile')
method = next(n for n in cls.body if isinstance(n, ast.FunctionDef) and n.name == '_collect_existing_component_keys')
module = ast.Module(body=[ast.ImportFrom(module='__future__', names=[ast.alias(name='annotations')], level=0), method], type_ignores=[])
ns = vars(storage).copy()
exec(compile(ast.fix_missing_locations(module), '<baseline method>', 'exec'), ns)
baseline = ns['_collect_existing_component_keys']
changed = storage.HiCacheFile._collect_existing_component_keys
rows = []
with envs.SGLANG_HICACHE_FILE_BACKEND_STORAGE_DIR.override(''), tempfile.TemporaryDirectory(prefix='sglang-42070-bench-') as directory:
    config = storage.HiCacheStorageConfig(tp_rank=0, tp_size=1, pp_rank=0, pp_size=1, attn_cp_rank=0, attn_cp_size=1, is_mla_model=False, enable_storage_metrics=False, is_page_first_layout=True, model_name='benchmark', extra_config={'enable_metadata_cache': False, 'max_size': '0', 'min_free_space': '0'})
    b = storage.HiCacheFile(config, file_path=directory)
    keys = [f'key{i}' for i in range(16)]
    transfers = [storage.PoolTransfer(name=storage.PoolName.MAMBA)]
    for key in keys[:8]:
        Path(directory, b._get_component_key(key) + '.bin').touch()
    for key in keys[:4]:
        Path(directory, b._get_component_key(key, storage.PoolName.MAMBA) + '.bin').touch()
    previous = 12
    for total_files in (1000, 10000, 50000):
        for i in range(previous, total_files):
            Path(directory, f'unrelated-{i}.bin').touch()
        previous = total_files
        samples = {'baseline': [], 'changed': []}
        for run in range(7):
            order = [('baseline', baseline), ('changed', changed)]
            if run % 2:
                order.reverse()
            for name, fn in order:
                b._collect_existing_component_keys = types.MethodType(fn, b)
                result = b.batch_exists_v2(keys, transfers)
                assert result.kv_hit_pages == 4 and result.extra_pool_hit_pages == {storage.PoolName.KV: 8, storage.PoolName.MAMBA: 4}, result
                start = time.perf_counter()
                for _ in range(10):
                    assert b.batch_exists_v2(keys, transfers) == result
                samples[name].append((time.perf_counter() - start) * 1000 / 10)
        row = {'files': total_files, 'requested_component_paths': 32, 'baseline_ms_median': statistics.median(samples['baseline']), 'changed_ms_median': statistics.median(samples['changed']), 'baseline_ms_runs': samples['baseline'], 'changed_ms_runs': samples['changed']}
        row['ratio'] = row['baseline_ms_median'] / row['changed_ms_median']
        rows.append(row)
        print(json.dumps(row), flush=True)
```
