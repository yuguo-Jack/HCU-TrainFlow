# [Test] hicache: Isolate NIXL storage tests from background eviction

[Upstream PR](https://github.com/sgl-project/sglang/pull/46194) · state: closed · merged: False

## Original PR description

The basic NIXL storage tests start the production L3 cleaner. When host disk usage exceeds its watermark, the cleaner can legitimately evict a freshly written checkpoint before the round-trip assertion reads it.

Disable background eviction in `TestNixlUnified`'s storage fixture. The round-trip assertions and production defaults remain unchanged; the dedicated L3 cleaner suite continues to test eviction.

Validation: reproduced missing checkpoint reads with the real cleaner under a controlled high-watermark condition, then verified the candidate passes that condition. On an isolated development host, the storage fixture suite passed 13 tests with one existing optional skip, and the dedicated cleaner suite passed 9 tests. Pre-commit passed. The original CI runner's disk usage was unavailable, so this does not establish its unique failure cause.
