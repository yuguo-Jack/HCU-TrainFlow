# [Mamba] Allow skipping per-draft intermediate SSM state

[Upstream PR](https://github.com/sgl-project/sglang/pull/42790) · state: open · merged: False

## Original PR description

## Motivation

Speculative verify on hybrid linear-attention models (Qwen3-Next, Qwen3.5/3.6, KDA, ...) allocates `intermediate_ssm` in `MambaPool`: one recurrent-state snapshot per draft token per request, so rejected drafts can roll back by copying the last accepted snapshot. It is the largest piece of speculative scratch; for a Qwen3.6-35B-A3B-style GDN model with 4 draft tokens it is hundreds of MiB per request, and `KVCacheConfigurator` takes it out of the mamba budget.

A linear-attention backend that implements its own rollback never reads that buffer. Today the only way to skip it is `--enable-linear-replayssm-spec`, which is tied to ReplaySSM. This PR exposes the skip directly, so such a backend can turn off the allocation and its budget reservation without enabling ReplaySSM.

## Modifications

- `KVCacheConfigurator.allocate_intermediate_ssm: bool = True`, forwarded to `MambaPool` through `HybridReqToTokenPool` and the disaggregated `HybridMambaDecodeReqToTokenPool`. `UnifiedHybridReqToTokenPool` accepts it for signature parity and, like the other spec flags there, does not forward it.
- `MambaPool` skips `intermediate_ssm` when the flag is false, using the same branch ReplaySSM already uses. Conv intermediate windows are still allocated (conv rollback reads them).
- `_handle_max_mamba_cache` reserves intermediate memory only when the buffer is allocated (`reserve_intermediate_ssm`), for all three sizing paths.
- Default `True` keeps current behavior everywhere.

## Accuracy Tests

Not applicable: no kernel or model forward change, and the default leaves every code path as before. With the flag off, only the unused `intermediate_ssm` buffer and its budget reservation are skipped.

## Speed Tests and Profiling

Not applicable: no change to inference speed. With the flag off, the memory the buffer would have used stays in the mamba budget.
