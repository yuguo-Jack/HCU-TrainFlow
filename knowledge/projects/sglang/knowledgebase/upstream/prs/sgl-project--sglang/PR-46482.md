# [Feat] serving: add configurable --max-payload-size for HTTP bodies

[Upstream PR](https://github.com/sgl-project/sglang/pull/46482) · state: open · merged: False

## Original PR description

## Motivation

Large JSON request bodies (for example base64-encoded multimodal inputs) can exceed default HTTP/1.1 parser limits in Uvicorn and Granian, causing failed requests before they reach application code. Issue #6622 asks for a server flag to raise this limit.

## Modifications

- Add `--max-payload-size` to serving CLI arguments (default 10 MiB / 10485760 bytes).
- Wire the limit into all HTTP server launch paths in `http_server.py` (Granian + Uvicorn, including multi-worker).
- Document the flag in `server_arguments.mdx`.

Fixes #6622
