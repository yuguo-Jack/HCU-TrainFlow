# Add NCCL M2N receiver for Miles weight updates

[Upstream PR](https://github.com/sgl-project/sglang/pull/39990) · state: open · merged: False

## Original PR description

## Summary

Add the NCCL M2N receiver for disaggregated training-to-rollout weight refits, paired with [Miles #3304](https://github.com/radixark/miles/pull/3304).

[NCCL M2N](https://github.com/NVIDIA/nccl-extensions/tree/main/nccl_m2n) efficiently reshards tensors between different GPU meshes, supporting NVLink transfers through SMs or Copy Engines and RDMA scale-out transports. Install easily from [PyPI](https://pypi.org/project/nccl-extensions/): `pip install "nccl-extensions[cu13]"` (use `cu12` for CUDA 12; requires a compatible PyTorch/NCCL runtime).

## Design and features

- A manifest-driven receiver maps trainer shards into rollout TP/EP layouts and replicas. Per-trainer-PP communicators and independent CUDA streams support concurrent stage updates.
- Supports dense/expert BF16 and 128×128 block-FP8 expert refits, including canonical and packed UE8M0 scales, while preserving CUDA-graph-visible inference storage.
- Integrates with existing begin/end weight-update sessions and residual broadcasts, including safe teardown and target-only updates with a frozen draft. Existing broadcast behavior is unchanged. Open sessions cannot be reentered; failed M2N transfers require restarting the affected rollout engines before another update.

## Experiment and results

Paired Miles/SGLang run: DeepSeek-V4-Flash-FP8, GRPO on DAPO-Math-17k, **64 GB300 GPUs (16 nodes × 4 GPUs)**:

- Trainer: 8 nodes / 32 GPUs, TP1/CP1/PP8/EP4/ETP1.
- Rollout: 8 nodes / 32 GPUs, four TP8/EP8 engines, PP1/DP1.
- PP concurrency 2; 32 prompts × 8 samples; 4,096 maximum response tokens; CUDA graphs enabled; speculation off.

**Steady-state weight updates are ~9× faster than NCCL broadcast:** **15.26 s → 1.67 s** at step 12. M2N averages **1.72 s** over steps 1–19, excluding the **44.3 s** initial update/setup. Reward and train/rollout logprob-difference curves track the baseline over the 20-step comparison.
