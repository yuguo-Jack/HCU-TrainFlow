# [DSA] Support flashmla_sparse_q8  prefill  backend  on CUDA

[Upstream PR](https://github.com/sgl-project/sglang/pull/44217) · state: open · merged: False

## Original PR description


## Motivation

Enable flashmla_sparse_q8 DSA backend for prefill on CUDA, import performents for models such as GLM-5.3-Flash.

## Modifications

- Enable `flashmla_sparse_q8` prefill with TileLang decode for GLM-5.3-Flash’s raw FP8 KV layout on SM90, restricted to NoPE models with `kv_lora_rank=512`.
- Allow Q8 prefill to consume KPool top-k indices, including appended live-tail tokens.
- Route raw FP8 paged KV directly to the Q8 kernel using physical KV-pool indices.
- Pad top-k indices to a multiple of 128 with `-1` sentinels, preserving all valid tail tokens.
- Handle zero-dimensional RoPE queries without invoking the concat kernel.
- Preserve the raw 512-byte KV row layout shared by Q8 prefill and TileLang decode.

Depends on CUDA TileLang FP8 KV support from #42957.

## Accuracy Tests
Validated GLM-5.3-Flash on 4 × H200 with flashmla_sparse_q8 and  TileLang prefill .

```bash
sglang serve \
  --model-path /path/to/GLM-5.3-Flash \
  --served-model-name llm \
  --tp-size 4 \
  --mem-fraction-static 0.75 \
  --dsa-prefill-backend flashmla_sparse_q8 \
  --dsa-decode-backend tilelang \
  --kv-cache-dtype fp8_e4m3 \
  --moe-runner-backend triton \
  --ep-size 4 \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 5 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 6 \
  --host 0.0.0.0 \
  --port 8009 \
  --cuda-graph-backend-prefill breakable \
  --reasoning-parser auto \
  --tool-call-parser auto
```

Changes:
- Added a shared layout predicate for argument validation, backend validation, and KV pool allocation, checking backend pairing and geometry rather than model architecture.
- Restricted raw FP8 support to 512-dim NoPE KV with Q8 prefill and TileLang decode on SM90.
- Removed the PAGED fallback and whole-pool copy. Prefix requests now reuse the RAGGED path and gather the referenced context slots via page_table_1_flattened.
- Removed the redundant top-k padding and NoPE query-preparation branches, reusing the implementations from #41790.
- Restored the packed FP8 KPool guard.
- Updated the GLM-5.3-Flash cookbook and added regression tests.

Validation:
- 49 CPU tests and 29 GPU tests passed, including prefix gathering, live KPool tail tokens, and unsupported-layout rejection.
- The 8 Q8 helper cases also passed after rebuilding with an isolated JIT cache.

- pass@1 (averaged over two repeats): 92.53%
- pass@2: 92.57%
- No-answer, truncation, and request error rates: all 0%
