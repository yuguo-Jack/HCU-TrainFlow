## Motivation

When loading GLM-5.3-Flash using runai_streamer, tensors must be explicitly cloned to avoid reusing buffer memory; otherwise, incorrect weights are loaded.

- Before: GLM-5.3-Flash generated infinite exclamation marks (!) during inference due to corrupted/incorrect weights.
- After: Model weights load properly, and generation works as expected.

This PR supersedes #37370

## Modifications

1. Tiny refactor `_clone_if_runai_streamed_tensor` from multiple defitions into `weight_utils.py`
2. Fix a tiny bug about `glm_next.py`
