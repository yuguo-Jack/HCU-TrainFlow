# [Fix] [NPU] kimi-k3: Split QKV/G projections for mixed ModelSlim precision

[Upstream PR](https://github.com/sgl-project/sglang/pull/47811) · state: open · merged: False

## Original PR description

## Motivation

Kimi K3 ModelSlim checkpoints can use different quantization precisions for the Q and full-rank G projections. Merging Q/K/V/G into one projection then fails during model initialization because all shards of a fused layer must have the same precision.

## Modifications

- On NPU, use the existing ModelSlim `is_layer_skipped()` checks to select separate projections when Q and G have different precisions.
- Reuse the existing split construction and forward paths, and skip the fused QKV/G weight mapping for those layers.
- Keep the existing fused path for compatible checkpoints. This change is independent of KV-cache dtype and MLAProlog.

## Accuracy Tests

- Verified that this patch has the same stable patch ID as the QKV/G changes extracted from #46921.
- Verified that reapplying the extracted patch to the remaining C8 changes restores the complete original Git tree.
