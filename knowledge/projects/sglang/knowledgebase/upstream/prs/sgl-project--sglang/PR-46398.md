# [Fix] sgl-router: set TCP_NODELAY on accepted client connections

[Upstream PR](https://github.com/sgl-project/sglang/pull/46398) · state: open · merged: False

## Original PR description

## Motivation

Reported for `sgl-model-gateway` in #46067: axum Server accept loops keep Nagle on, so a small streamed SSE chunk can sit waiting for the peer's delayed ACK (~40 ms on Linux). #46076 fixes that for the gateway only.

`sgl-router` (the standalone KV-aware router, built by `docker/sgl-router.Dockerfile`) has the same gap: its inbound `axum::serve(listener, app)` on a raw tokio `TcpListener` (src/main.rs) sets no socket options after accept. Its outbound worker connections are already covered, because reqwest's `ClientBuilder` defaults to `tcp_nodelay(true)`.

## Modifications

- Wrap the inbound listener with axum's `ListenerExt::tap_io`; the hook sets `TCP_NODELAY` on every accepted client socket before the first byte is written, logging a `WARN` if the setsockopt fails (matches `rust/sglang-server`'s sock.rs behavior from #33269).
- Add a unit test (`accepted_client_sockets_get_nodelay`) that spins up `axum::serve` with the new wiring on an ephemeral loopback port, makes two real HTTP requests, and asserts inside the accept hook that `TCP_NODELAY` is set on each accepted socket and that the hook ran per connection.
- Scope notes: the native gRPC listener (tonic) is left unchanged (same listener parenting, but not exercised by the reported path), and no launch flag is added — matching the gateway fix in #46076, which also ships no configuration option.

No changes to worker clients, routing, or shutdown behavior.

## Speed Tests and Profiling

No serving benchmark was run for this PR (no GPU here). The mechanism and expected effect are those measured in #46067: idle streaming requests through the router saw ~38-42 ms stalls that disappeared with NODELAY (16/80 false; 0/80 after), p90 +36.5/+37.7 ms. The same strace verification command applies:

```
strace -f -yy -e trace=accept4,setsockopt -o router.strace \
    target/release/sgl-router --host 127.0.0.1 --port 8080 \
    --worker-urls http://127.0.0.1:8000
```

Streaming clients should now observe `setsockopt(fd, SOL_TCP, TCP_NODELAY, [1], 4)` on every accepted client socket.

AI assistance was used to investigate, implement, and locally validate this change (code checked against main at `dba22e9`).
