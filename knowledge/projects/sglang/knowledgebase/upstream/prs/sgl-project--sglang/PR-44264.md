# [Refactor] attention: TRTLLMHAAttnBackend inherits from AttentionBackend directly

[Upstream PR](https://github.com/sgl-project/sglang/pull/44264) · state: open · merged: False

## Original PR description

## Summary

`TRTLLMHAAttnBackend` inherited from `FlashInferAttnBackend` but reused very little from it. Almost all attention-specific behavior is overridden, and some inherited setup was allocated-but-never-used.

This PR changes the base class to `AttentionBackend` directly, inlining the only 4 attributes actually used from the old parent's `__init__`:
- `token_to_kv_pool`
- `kv_index_translator`
- `kv_cache_quant_method`
- `use_sliding_window_kv_pool` (via the overridden `_resolve_swa_kv_pool`)

It also moves `_kv_write_scales` (the single non-overridden parent method still called by this backend) into the class.

Zero behavior change — pure refactoring.

Resolves #28808.

Signed-off-by: bantianyue <bantianyue@gmail.com>
