## Motivation

DeepSeek-V4.1 differs from V4 in every layer that touches KV: it compresses at ratios 1/2 instead of 4/128, runs a two-level indexer (level-1 block candidates, level-2 QSLI rescore inside them), stores two different quantized row formats (FP8 E4M3 group 32 for the window side, packed FP4 E2M1 group 16 for the compressed side), and drives mHC residual mixing through CANN ops. The NPU backend only covered V4: `npu_kv_quant_sparse_attn_sharedkv` for attention, ratios 0/4/128, one indexer level, and the 584-byte A5 row. Enabling V4.1 on Ascend A5 therefore needs a new source/attention path, new pools, graph-capture support, PD/HiCache descriptors, and a few operator gaps closed (medium-row argmax, fp8/e8m0 byte views, copysign-free gating, w8a8 mxfp8 GEMM).

## Modification

### Attention backend (`hardware_backend/npu/attention/ascend_dsv4_backend.py`)

- Add `LowRatioCompressAscendBackendMixin` with three seams: **A** `_low_ratio_compress` runs the fused `ds41.compressor` (ratio 2) or the plain `wkv` projection (ratio 1), then RMSNorm + RoPE and a write into the ratio's compressed pool, handing the pre-RoPE latent to seam B; **B** `_low_ratio_index_topk` calls `ds41.indexer_prologue_k` (storage_mode 0/1) and then either level-1 top-k with candidate publish or level-2 QSLI rescore; **D** `_forward_low_ratio_attention` runs `ds41.mixed_quant_sparse_flash_mla` with the window and compressed sides as explicit sparse indices + lengths.
- Discriminate generations by `compress_ratios` (both report `KVLayout.V4` on NPU), reject cross-generation ratios, assert the fixed 64 query heads, and reject COMPACT ragged verify at startup.
- Metadata: `_build_dsv41_ratio_metadata` derives slots as `full_loc // ratio` (ratio 1 masks in place to keep token order, ratio > 1 stable-compacts), expands the full page table to the index pool granularity, and builds the QLI / QSLI dispatch tables from the batch's final KV length.
- aclgraph: allocate the low-ratio buffers at capture and refresh them in place on replay (decode, verify, DP-idle clear); keep `seq_lens_cpu_int` on one persistent buffer and refresh a dedicated live-row mask so an idle dummy verify window stays dead inside the replay.
- DSpark owns the V4.1 verify replay; EAGLE fails loudly instead of scattering compressed rows into the previous step's slots.

### Pools (`hardware_backend/npu/dsv4/dsv4_memory_pool.py`)

- `DSV41NPUSingleKVPool`: fully quantized rows (window FP8 E4M3 g32 / 544 B, compressed packed FP4 E2M1 g16 / 320 B), format picked by the pool's role rather than the layer's ratio (a ratio-1 compressed pool keeps the global page size but still takes the fp4 row).
- `DSV41NPUIndexerPool`: packed-fp4 index K and E8M0 scales kept in separate PA_ND buffers; no CUDA fused packed buffer allocated.
- Ratio-2 pending-pair state exposed as a physical `[blocks, ring, 2*D]` bank so `state_cache_3d` is valid for the A5 CYCLE ABI.
- `get_contiguous_buf_infos` describes the V4.1 pools for PD (KV, index K, index scale per ratio, one item per full page); C128 infos stay empty.

### Model / cache / allocator

- `deepseek_v4.py`: V4.1 skips per-head Q norm, disables the NPU multi-stream split (compressor + indexer is one ordered call), and collapses the mHC premix on NPU.
- `deepseek_v4_mhc.py`: NPU premix path (`npu_hc_pre` with the identity one-hot seed, empty-batch short circuit) and the A5 `cann_ops_transformer.mhc_post` (`mhc_post(x, hRes, hOut, hPost)`).
- DSpark / platform-stage / registry / OCR wiring for the V4.1 architecture.
- `kv_cache_configurator.py`: V4.1 stays on the generic SWA allocator (slots are `full_loc // ratio`), no C128 sidecar allocator.
- `registry.py`: attach the C128 component only when ratio-128 layers and a sidecar pool exist.
- `hybrid_pool_assembler.py`: register the NPU index K / scale PA_ND regions.

### Kernels and layers

- `row_argmax.py`: NPU medium-row argmax via one-operand `tl.max`/`tl.min` (the two-operand `tl.reduce` form does not survive Ascend triton-mlir-opt).
- `engram.py`: read the fp8 / E8M0 tables as bytes on A5 (no fp8 index or e8m0 cast), and replace `copysign` with `where` so capture does not fall back to a host copy.
- `fp8_utils.py`: dispatch 32x32-block w8a8 to `npu_w8a8_mxfp8_linear`.

### Tests

- New `test/registered/unit/npu/attention/test_npu_dsv41_low_ratio_backend.py`: CPU-runnable (pure torch + a `ds41` operator stub) coverage of row formats, pool factory, slot derivation, eager/graph parity, metadata builders, write ABI, and the verify/COMPACT guards.
- `test_deepseek_v4_platform_dispatch.py` covers the model-side dispatch.
- `5641902f10` is a lint follow-up only: line wrapping in `row_argmax.py`, `ascend_dsv4_backend.py` and the new test, one duplicate `is_npu` import removed from `fp8_utils.py`, one multi-line `if` collapsed. No behavior change.

This combined K cache also needs to survive PD handoff and HiCache reload.
