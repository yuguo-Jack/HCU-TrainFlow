# [Test] cpu: prune mirror and tautology cases from the per-commit CPU suite

[Upstream PR](https://github.com/sgl-project/sglang/pull/45672) · state: closed · merged: True

## Original PR description

## Summary

The per-commit CPU suite (`base-a-test-cpu`) grew to 860+ registered files. A full audit of every file against the unit-test admission rule (`.claude/rules/unit-test-admission.md`: each case must name a future diff that turns it red) found a large share of cases whose assertions restate the implementation: wire-format round trips asserted against the decoder's own output, one-predicate-per-case rejection truth tables, mock call-count blocks, and happy-path tautologies.

This PR removes them in three commits: 177 files changed, ~14.2k lines deleted, no production code touched.

## Changes

- **Whole-file deletions (21+5):** files whose every case is a mirror or is fully subsumed by a sibling suite — e.g. `test_uno_token_accounting.py` (re-computes the one-line `get_num_generated_tokens`), `test_radix_cache_slru_accuracy.py` (no external oracle; `test_evict_policy.py` pins the SLRU priority tuple directly), ROCm-only leaf-predicate tables, and `test_http_server_auth.py` (subset of `test_auth.py`).
- **Disaggregation case pruning (~200 cases):** wire round trips on `from_zmq` / pack / transfer-indices helpers, `test_pd_role_switch.py`'s 14-case `test_rejected_*` truth table, `test_encode_server.py`'s 50-case `TestEncoderDelivery` mock-permutation class. Kept: protocol ordering, failure injection, negative branches, cross-process contracts.
- **Case pruning across managers / spec / mem_cache / observability (~120 cases):** accessor mirrors, dict-semantics tautologies, constructor read-backs, and one 540-subtest sweep whose oracle re-implemented the rule it tested. Two cases that were unconditional CUDA skips in the CPU suite (dead coverage) are also removed.

## Verification

- `py_compile` on all touched files; `pytest --collect-only` clean on touched directories.
- Executed the pruned suites locally: disaggregation 672 -> 309 collected cases, all passing; managers 334 passed; spec/layers 203 passed; mem_cache 253 passed; observability/misc 229 passed. The remaining failures reproduce identically on main (missing native extensions in the local env).
- Every deletion was checked against the current file contents, not just the audit snapshot; a handful of audit-flagged cases that had since become load-bearing were kept (listed per-commit).
