# [Feat] wan2.2-s2v: Add a cache-dit block adapter

[Upstream PR](https://github.com/sgl-project/sglang/pull/44427) · state: open · merged: False

## Original PR description

`SGLANG_CACHE_DIT_ENABLED=1` failed every Wan2.2-S2V request with **"No block forward pattern matched"**. cache-dit swaps the iterated `ModuleList` for a single pseudo-block that runs the blocks itself, so the audio injector — which the caller drives by loop index between blocks — has to move inside the cached unit, or it fires once per step instead of at each injected layer.

## Changes
- **`WanS2VBlockRunner`**: one transformer block plus its audio injector, matching cache-dit's `Pattern_3` contract (first argument named `hidden_states`). It is held **outside the module tree** (`self._runs` tuple), so the block stays owned by `blocks` and `state_dict` keys and the layerwise-offload hooks are unchanged. `forward` iterates `block_runners` instead of `blocks`.
- **Registers `WanS2VTransformer3DModel`** with `blocks_attr="block_runners"` in `_CUSTOM_BLOCK_ADAPTER_SPECS`, and adds it to the registered-class test.

3 files, +49/−3.

## Results
2 × B60, 40 steps, defaults:

| shape | speedup | PSNR Y vs uncached |
|---|---|---|
| 576×768, SP=2 | **2.66×** | 25.85 dB |
| 1280×704, SP=4 | **2.62×** | 33.09 dB |

Run-to-run PSNR floor is 32.69 dB, so the 1280×704 case is within noise while 576×768 shows a real, content-dependent quality cost — cache-dit is opt-in via the env var and the **uncached path is unchanged**.

## Base
⚠️ **Stacked on #43279** (the S2V port), which this branch includes as its first commit — S2V does not exist on `main` yet. It is *independent of #43288*: that PR changes attention internals, while this one only replaces the block loop. Merge after #43279, in either order with respect to #43288.

## Testing
`test/unit/test_cache_dit_integration.py` covers the new registration.
