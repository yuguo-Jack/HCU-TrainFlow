# [Fix] diffusion: LTX-2.5 two-stage defaults to its 1920x1088 canvas

[Upstream PR](https://github.com/sgl-project/sglang/pull/47582) · state: closed · merged: True

## Original PR description

## Motivation

On >=130 GiB GPUs (H200, B200, B300), sglang's own 2-GPU LTX-2.5 two-stage cookbook preset (`--pipeline-class-name LTX2TwoStagePipeline`) does not start:

```
LTX-2 two-stage requires resolution divisible by 64, got (544x960)
```

The cause is the default size:

- `LTX25SamplingParams` defaults to 960x544. That is the one-stage canvas, and the two-stage pipeline uses it too.
- `LTX2HalveResolutionStage` needs each side to be a multiple of 64, so 960x544 cannot be halved.
- On these GPUs BCG is on by default for `LTX2TwoStagePipeline`, and its warmup runs at the sampling default, so startup fails.
- A two-stage request that omits its size fails the same way.

This was found by serving the 1920x1088, 121-frame two-stage workload with the cookbook command on 2x H200 and 4x B200.

## Modifications

- `configs/sample/ltx_2_5.py`: `LTX25SamplingParams` names its two-stage canvas (`two_stage_default_size = (1920, 1088)`, the official two-stage default). `_adjust` applies it under the two-stage pipeline when the request sets neither width nor height; an explicit size still wins.
  - The change stays in LTX-2.5's own sampling params. The per-pipeline registry is keyed by class name alone, so registering `LTX2TwoStagePipeline` for LTX-2.5 would also have changed LTX-2 and LTX-2.3.
- `runtime/warmup_request_builder.py`: the LTX two-stage warmup path reads the same canvas, so BCG captures the shape two-stage serves. As a guard for any other model, the BCG warmup no longer takes an LTX-2 two-stage default that the halve stage would reject; it falls through to the aligned representative shape.

## Accuracy Tests

No numerical change. An explicit request size is used as before, and one-stage LTX-2.5 keeps 960x544.

## Speed Tests and Profiling

2x H200: the cookbook preset with no size flags, LTX-2.5 distilled, two-stage, 1920x1088, 121 frames. The harness warms up 3 requests at 3 steps, then times 2 requests by the client.

| sglang | Result |
| --- | --- |
| main at 3a01d4cc, preset | server exits during warmup (error above) |
| this branch, preset | 9.396 s |
| main at 3a01d4cc, explicit `--width 1920 --height 1088` | 9.435 s |
