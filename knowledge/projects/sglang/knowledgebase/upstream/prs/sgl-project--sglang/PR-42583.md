# [Fix] mimo: Fix quadratic regex scans in the tool-call parser

[Upstream PR](https://github.com/sgl-project/sglang/pull/42583) · state: open · merged: False

## Original PR description

## Motivation

`MiMoDetector` (`mimo`) scans model output with three patterns that go quadratic when a closing tag (or the `>` ending a name) never arrives:

1. `<tool_call>(.*?)</tool_call>` `finditer` over the whole output rescans to the end from every opening tag.
2. `<function=([^>]+)>(.*?)</function>` and `<parameter=([^>]+)>(.*?)</parameter>` inside a block do the same for every `<function=` / `<parameter=`, including when no `>` follows the name. Streaming re-parses each complete block, so this also hits a single streaming call.

| Input | Before | After |
|---|---|---|
| 96 KB of repeated `<tool_call> `, non-stream | 10.8 s | < 1 ms |
| ~96 KB block with unclosed `<function=` / `<parameter=`, **one streaming call** | 9.7 – 11.2 s | fast |

Tool-call parsing runs synchronously on the tokenizer manager's event loop, so one such response stalls every in-flight request. Found with an Atheris fuzzing harness that records per-input parse time.

## Modifications

- `_iter_tool_call_bodies`: a linear `str.find` scan yielding the same `(end, body)` as the `finditer`.
- `_search_tag(text, prefix, close_tag, pos)`: a linear replacement for the function / parameter regexes that returns the same `(name, body, end)`. `[^>]+` always ends at the first `>`, and if the `>` or the closing tag is missing after one prefix, it is missing after every later prefix too, so the scan stops instead of retrying. An empty name (`<function=>`) moves on to the next prefix, as the regex does.
- The unused `tool_call_regex` / `func_regex` / `param_regex` attributes and `import re` are removed.
- Regression test in `test_function_call_parser.py` (fails on `main`, passes here).

## Accuracy Tests

- `_search_tag` vs the old regexes' `finditer` on 200k random strings: identical.
- Differential test of `main` vs patched detector, comparing `detect_and_parse` and every streaming result under random re-chunking: **0 mismatches** over 20k random plus 20k mutated well-formed inputs.
- `test/registered/unit/function_call/`: 630 passed.
