# [Perf] moe: Fill padded rows of large narrow buffers with a strided grid

[Upstream PR](https://github.com/sgl-project/sglang/pull/47115) · state: closed · merged: True

## Original PR description

## Motivation

`_fill_padded_rows` (`python/sglang/kernels/ops/moe/fill_padded_rows.py`) sets every padded row of a 2D buffer (rows `>= num_token_non_padded`) to a fill value with one Triton launch. The grid is one program per row, and a program whose row is live exits immediately. For a large buffer of narrow rows whose padding is a short suffix, the launch is therefore dominated by programs that do nothing, and its cost scales with the buffer rather than with the tail.

## Modifications

- For buffers with at least `2 * 1024` rows whose rows are at most 2 KB, the kernel launches 1024 programs (`STRIDED=True`). Program `p` owns rows `p, p + 1024, ...`; it starts at its last owned row and walks down while the row is padding. Padding is a suffix, so stopping at the first live row is exact. The pad count is still read from device memory inside the kernel, so the launch remains safe to capture in a CUDA/HIP graph.
- Every other shape keeps the one-program-per-row launch, as a separate compile-time branch (`STRIDED=False`): wider rows already stream at full bandwidth with one program per row.
- Both branches compute the row offset in int64. The previous int32 `row * stride_row` overflows for buffers with more than 2^31 elements.
- The result is bitwise identical to the eager `arange + (>=) + index_put_` reference on every shape; only the launch geometry changes. No new flags.

## Testing

- `test/registered/moe/test_topk_padded_region.py` gains `TestFillPaddedRowsStrided`: it patches the program cap down to 3 so that every residue class and every pad count (0 through rows + 2, including all-live and all-padding) is checked against the eager reference on 1 to 13 rows, then checks a large narrow-row buffer with the real cap. The existing tests in the file cover the per-row branch and CUDA-graph replay.
- On this branch, on one Blackwell GPU: `pytest test/registered/moe/test_topk_padded_region.py` gives 9 passed, 3 skipped (the HIP-only cases), 39 subtests passed; `pre-commit run --files` on both files passes.
