# [Fix] Preserve Gemma4 null and exponent tool argument types

[Upstream PR](https://github.com/sgl-project/sglang/pull/42549) · state: closed · merged: False

## Original PR description

## Motivation

Gemma4 tool calls currently turn bare `null` and exponent-form numbers such as `1e-05` into JSON strings. This breaks numeric/nullable tool schemas in both streaming and non-streaming responses.

Closes #41316.

## Modifications

- Parse bare `null` as JSON null and `e`/`E` exponent notation as numbers.
- Preserve integers, booleans, decimal numbers, delimited strings, and malformed bare-string fallback behavior.
- Extend the existing Gemma4 detector tests with nested values and non-streaming plus streamed chunks of one character, seven characters, and the complete message.

## Accuracy Tests

**251 tests and 59 subtests passed**, including all 18 Gemma4 tests. The new regression fails all eight subcases before the production fix and passes afterward.
