# [Perf] DSv4.1: Gather the compressor projection instead of the hidden states under prefill CP

[Upstream PR](https://github.com/sgl-project/sglang/pull/45114) · state: open · merged: False

## Original PR description

## Motivation

Under prefill CP, every DeepSeek-V4.1 layer with compress ratio 1 or 2 (38 of 40 layers in V4.1-Flash) all-gathers the prompt's hidden states and then recomputes the compressor projection for all tokens on every rank. Only the projection is consumed: `wkv(x)` at ratio 1 (bf16, 1 KB per token on V4.1-Flash) and `project_fused(x)` at ratio 2 (fp32 `| kv | score |`, 4 KB per token), versus 10 KB per token for the hidden states. Gathering the projection moves 10x / 2.5x fewer bytes, and each rank only projects its own rows.

## Modifications

- Project this rank's rows and gather the projection instead of the hidden states, in both the CUDA and the HIP `_forward_low_ratio_sources_cp`.
- `_low_ratio_compress` and `_low_ratio_compress_fused` accept the gathered projection, so the HIP extend keeps using the fused prefill store kernels.

Depends on #43465 (prefill CP for DeepSeek-V4.1 on AMD). The first commit is #43465 squashed onto main; only the second commit is new.

## Accuracy Tests

The projection is row-wise, so the result is numerically equivalent; per-row values can differ in the last bits if the GEMM picks a different kernel for the smaller M. Accuracy results will follow.

## Speed Tests and Profiling

Will follow, with the setup of #43465 (DeepSeek-V4.1-Flash, TP8 + prefill CP8, MI355X).
