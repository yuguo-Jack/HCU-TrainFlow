# [Fix] function_call: Keep a split InternLM start marker for the next call

[Upstream PR](https://github.com/sgl-project/sglang/pull/47140) · state: open · merged: False

## Original PR description

## Summary

Streaming `InternlmDetector` dropped every tool call after the first when `<|action_start|>` arrived in its own chunk. The full marker is `<|action_start|> <|plugin|>`, and those are separate added tokens, so a token-at-a-time stream splits them.

After the first call, a buffer that did not yet contain the full marker was cleared. The prefix is now kept until the next chunk finishes the marker. Non-streaming parsing is unchanged.

Fixes #46661

## Test

`python3 -m pytest test/registered/unit/function_call/test_internlm_streaming_detector.py -q`

The split-marker case returned only the Tokyo call before this change and returns Tokyo then Paris after it.
