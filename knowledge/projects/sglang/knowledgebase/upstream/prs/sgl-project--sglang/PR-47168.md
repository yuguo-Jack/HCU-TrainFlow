# [Fix] mem_cache: Default hicache_write_back_staging on MLAView

[Upstream PR](https://github.com/sgl-project/sglang/pull/47168) · state: closed · merged: True

## Original PR description

## Motivation

`test/registered/e2e/hicache/test_hicache_unified_memory.py` (`TestUnifiedMemoryHiCacheMLA`) fails in the scheduled PR Test Base run on `76d5b3ce0` ([job](https://github.com/sgl-project/sglang/actions/runs/40785158774/job/123156724989)). The server never starts:

```
attach_hybrid_pool_to_unified_cache failed
  File ".../hybrid_pool_assembler.py", line 225, in build_kv_host_pool
    write_back_staging=kv_pool.hicache_write_back_staging,
AttributeError: 'MLAView' object has no attribute 'hicache_write_back_staging'
```

`build_kv_host_pool` reads `kv_pool.hicache_write_back_staging` on the MLA path. `MHAView` and the `KVCache` base class default it to `None`, but `MLAView` (added in #46990) doesn't declare it.

## Modifications

Declare `hicache_write_back_staging = None` on `MLAView`, matching `MHAView`.

## Testing

Not run on a GPU locally; relying on CI (`extra-a-test-2-gpu-large`). `ruff format` and `ruff check` pass.
