# [Feat] QSA: Integrate compressed QSA with the unified hybrid memory pool

[Upstream PR](https://github.com/sgl-project/sglang/pull/44345) · state: open · merged: False

## Original PR description

## Motivation

Qwen4-Exp compressed QSA is currently rejected with `--enable-unified-memory`. Its persistent compressed index keys must stay with the corresponding full-attention KV pages when the unified allocator relocates them, and its attention/indexer paths must resolve virtual locations against the current page map.

This PR adds that integration for the QSA target pool and keeps non-final prefill chunks aligned to compression groups.

## Modifications

- Store full-attention K/V and compressed QSA index keys in one page envelope, with byte accounting and layer-specific views/translations.
- Resolve QSA eager and graph metadata, compressed-index writes, and sparse KV gathers through the unified page map. Disable the existing fused KV attention path for this layout.
- Initialize Qwen PLE side-state pools and register their slot-state lifecycle with the unified Mamba pool.
- Admit Qwen4-Exp through model overrides and align chunked-prefill continuations to the QSA compression ratio.
- Decline fused draft placement for QSA: the fused region carries K/V but does not carry independent QSA draft indexer state. Existing speculative budget guards remain in force; this PR does not claim new EAGLE/DFLASH support with unified memory.

Related: #39575 addresses unaligned QSA prefixes by handling cross-prefix groups on gfx950; this PR preserves alignment at scheduler chunk boundaries. #40143 expands speculative ring capacity and is separate from this integration.
