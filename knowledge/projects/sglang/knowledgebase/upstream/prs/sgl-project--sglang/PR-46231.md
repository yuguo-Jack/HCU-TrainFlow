# [Perf] dsv41: Feed wo_b the fused MXFP8 attention output in the prefill graph

[Upstream PR](https://github.com/sgl-project/sglang/pull/46231) · state: closed · merged: True

## Original PR description

Inside the DeepSeek-V4.1 prefill CUDA graph, the mega attention wrote a bf16 output through its eager break and `wo_b` quantized it to MXFP8 in a separate kernel. Outside the graph (eager prefill, decode), the attention already hands `wo_b` its fused MXFP8 output.

- `bcg_deepseek_v4_mega_attention_with_mxfp8_output`: the eager break writes the fp8 data and DeepGEMM-packed UE8M0 scales into buffers allocated in the graph; rows past the live tokens are zeroed. When the TMA-aligned scale stride of the live rows differs from the padded rows', the scales are written to a live-size buffer and copied back.
- `_mega_core` accepts an `(fp8, scale)` pair as `out`; `MQALayer._mega_mxfp8_output` is the one condition for both paths.
- `deepseek_v4_mhc.empty_deepgemm_mxfp8_scales` is split out of `empty_deepgemm_mxfp8_pair`.

The prefill graph now quantizes from the attention's fp32 accumulator, as the eager path does, instead of from its bf16 output, so its numerics follow eager prefill.
