# [Perf] [NVIDIA] deepseek-v4: Restore prefill graphs with bounded token buckets

[Upstream PR](https://github.com/sgl-project/sglang/pull/47741) · state: closed · merged: False

## Original PR description

## Changes

Restore automatic breakable prefill CUDA graphs for eligible DeepSeek-V4 CUDA workers using a bounded geometric token-bucket ladder. The existing automatic rule disables this path because the dense default ladder retains too much indexer scratch in the capture pool.

- Select `[512, 1024, 2048, 4096, 8192]` for an 8192-token ceiling, bounded by both chunked-prefill size and maximum prefill tokens. Preserve the existing decode configuration and other prefill fields.
- Apply the policy before scheduler collaborators read graph configuration. Preserve explicit backend/bucket/JSON overrides, legacy disable switches and the PD decode role; exclude PP, attention DP/CP/DCP, two-batch overlap and MoE all-to-all.
- Keep image-containing prefills eager for multimodal architectures that have not been allowlisted for breakable replay.

**Changed defaults:** eligible DeepSeek-V4 CUDA workers with automatically disabled prefill graphs now use the short breakable-prefill ladder. Other models keep their policy. To retain eager prefill, append `--cuda-graph-backend-prefill disabled` to an existing launch command. This patch does **not** change memory fraction, request limits, decode graph sizes, model precision or sampling defaults.
