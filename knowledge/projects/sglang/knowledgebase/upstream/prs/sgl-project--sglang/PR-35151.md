## Motivation

<!-- Describe the purpose and goals of this pull request. -->
Adds support for new quantized attention backends for ROCm. Mostly for gfx950, but a few work with gfx942 as well.

This PR adds a new backend, `AITER_QUANT`, which contains calls to different functions within AITER. The user can choose which format to use via cli:
```
--attention-backend AITER_QUANT --attention-backend-config format=X
```
Available formats are `bf16fp8`, `fp8`, `i8fp8`, `mxfp8`, `mxfp6` and `mxfp4`. The default is `fp8`.

These differ by implementation, performance and output quality. Depending on the stability of the model used, lower precision backends may already cause artifacts. This usage could benefit from other techniques such as hybrid attention (#21742, not applied in the examples below) to retain the quality.

## Modifications

<!-- Detail the changes made in this pull request. -->
- Adds a new backend, `AITER_QUANT`
- Removes deprecated backend `AITER_SAGE`
