# [Fix] io_struct: Reject per-request lists whose length differs from the batch size

[Upstream PR](https://github.com/sgl-project/sglang/pull/44333) · state: open · merged: False

## Original PR description

## Motivation

A batch request to `/generate` may carry one entry per request for several fields. When such a list has the wrong length, the request is accepted and fails later:

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:30000/generate \
  -H 'Content-Type: application/json' \
  -d '{"text": ["a", "b"], "sampling_params": [{"max_new_tokens": 2}]}'
# 500 Internal Server Error
```

`GenerateReqInput.normalize_batch_and_arguments` keeps the one-entry list, and `__getitem__` then raises `IndexError: list index out of range` for the second request. A list longer than the batch is silently truncated. `rid`, `image_data`, `return_hidden_states`, `watermark`, `extra_key`, `cache_salt` and `kv_hints` already check their length and return 400; the fields below did not:

- `sampling_params`
- `return_logprob`, `logprob_start_len`, `top_logprobs_num`, `return_sampling_mask`, `sampling_logprobs_mode`, `token_ids_logprob`
- `lora_path`, `custom_logit_processor`
- `video_data`, `audio_data`
- `bootstrap_host`, `bootstrap_port`, `bootstrap_room`, `bootstrap_pair_key`, `decode_tp_size`
- `EmbeddingReqInput`: `rid`, `sampling_params`

## Modifications

- Add `_check_batch_list_length(name, values, batch_size)` in `io_struct.py` and call it from each normalizer's list branch, before the parallel-sampling expansion. The error names the field and both lengths, for example `The length of sampling_params (1) should be equal to the batch size (2).`; the HTTP layer turns the `ValueError` into a 400 like the existing checks.
- `EmbeddingReqInput.normalize_batch_and_arguments` checks `rid` and `sampling_params` the same way.
- Regression tests in `test_io_struct.py`: for each field above, a list of length 1 and of length 3 on a 2-request batch is rejected, and a list of length 2 still reaches `req[1]`; the two embedding fields are covered in `TestEmbeddingReqInputGetItem`.
