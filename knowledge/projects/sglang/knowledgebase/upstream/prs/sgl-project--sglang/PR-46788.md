# [Feat] distributed: Use pre-created device groups for an engine inside a larger world

[Upstream PR](https://github.com/sgl-project/sglang/pull/46788) · state: open · merged: False

## Original PR description

## Motivation

Some runtimes need every device subgroup to be created by all processes of the torch.distributed world in lockstep, with the first device group being the whole world. An SGLang engine that runs inside such a world next to other engines cannot let `initialize_model_parallel` create its own WORLD_SIZE and TP/PP device groups. Examples are one runtime session hosting several small engines, or an engine co-located with other workers in one job.

This PR adds a small, backend-neutral way to hand the engine device groups that were created up front.

## Modifications

- New `parallel_state.set_precreated_device_groups(rank_base, groups)`, called before `init_distributed_environment`. While it is set:
  - `GroupCoordinator` shifts the engine's group ranks by `rank_base` and keeps only the groups that contain its own rank.
  - It takes their device groups from `groups[tuple(world_ranks)]`, and creates the CPU (gloo) groups with only their members (`use_local_synchronization=True`).
  - `init_distributed_environment` and `initialize_model_parallel` size the engine world as TP x PP instead of `torch.distributed.get_world_size()`.
- The `TpModelWorker` seed broadcast passes the caller's global rank (`world_group.ranks[rank_in_group]`), as the PP+spec branch next to it already does. When the seam is unset, this equals `tp_size * pp_rank + tp_rank`.
- When unset (the default), group construction is unchanged.
- Test: `test/registered/unit/distributed/test_parallel_state.py::test_precreated_device_groups_are_reused` (CPU, single-rank gloo world). The coordinator reuses the pre-created device group and creates its own CPU group. The test is also added to the file's `__main__` list.

## Accuracy Tests

Not applicable: no model or kernel change, and the default path is unchanged.

From a clean checkout (CPU):

```bash
python3 test/registered/unit/distributed/test_parallel_state.py
python3 -m pytest -q test/registered/unit/distributed/test_parallel_state.py -k precreated   # 1 passed
```

These passed on a downstream fork whose `python/` and `test/` trees match this repository's layout. The patch applies cleanly to this repository's main.

On an earlier version of this change, a caller that pre-creates the groups ran two TP=2 engines in one 8-process world, and both served requests correctly.
