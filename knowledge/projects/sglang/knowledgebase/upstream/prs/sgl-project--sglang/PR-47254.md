# [Fix] [AMD] attention: default consumer RDNA to Triton attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/47254) · state: open · merged: False

## Original PR description

## Motivation

On `main`, the default attention backend on ROCm is `aiter`, which has no RDNA (gfx11xx / gfx120x) kernels. An RDNA server with default flags therefore never comes up.

**Without aiter installed** (the normal setup on Radeon), the first decode CUDA graph capture fails:

```
File ".../layers/attention/aiter_backend.py", line 2023, in init_forward_metadata_out_graph
NameError: name 'reset_verify_attn_plan_cache' is not defined
```

**Passing `--attention-backend triton` is not enough either.** The Triton backend's Lean decode auto-gate turns Lean on, and its kernel needs more LDS than RDNA's 64 KiB:

```
triton.runtime.errors.OutOfResources: out of resource: shared memory, Required: 66560, Hardware limit: 65536.
```

`amd_march` fixed both in #42092 (merged): consumer RDNA defaults to Triton attention, and Lean's auto-gate stays off there unless requested explicitly. This PR ports that change to `main`, together with the `is_rdna` platform fact it relies on, which came from `amd_march`'s multi-arch work. Related: #36867 targets the same symptom with an aiter architecture allowlist. That list doesn't include gfx1250, so it would also move gfx1250 off aiter. This port only touches gfx11xx / gfx120x. #46912 is an alternative fix for the Lean LDS overflow (smaller tile); the two don't conflict. Context: #46900.

## Modifications

- `utils/common.py`: add `is_rdna_supported()` (gfx11xx and gfx120x; excludes gfx1250), identical to `amd_march`'s.
- `runtime_context.py`: expose it as the platform fact `is_rdna`.
- `model_override_base.py`: in the MHA branch on HIP, return `triton` when `is_rdna`, else `aiter` as before.
- `triton_backend.py`: when `enable_lean_attention` is unset (auto) on RDNA, use the standard decode kernel. An explicit `True` still enables Lean for bring-up.

CDNA is unchanged. On gfx950 (MI355X), `get_platform().is_rdna` is `False`, so the default stays `aiter` and Lean's auto-gate is untouched. `test_platform_context.py` passes (8/8).
