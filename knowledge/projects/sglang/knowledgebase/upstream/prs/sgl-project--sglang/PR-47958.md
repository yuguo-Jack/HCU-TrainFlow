## Motivation

With a negative prompt, FLUX.2-dev runs the negative (CFG) branch without RoPE position info, because `Flux2PipelineConfig.prepare_neg_cond_kwargs` returns `{}`.
This makes images over-saturated, and with `--enable-cfg-parallel` + torch.compile on torch 2.12 the two GPUs compile different graphs and the run hangs (SPMD check). 
This PR builds `freqs_cis` (rope) for the negative prompt the same way as for the positive prompt, as `Flux2KleinBasePipelineConfig` already does.
https://github.com/sgl-project/sglang/blob/17e94c4677d7beb58a89b104fd61b3768994e45e/python/sglang/multimodal_gen/configs/pipeline_configs/flux.py#L883-L900
