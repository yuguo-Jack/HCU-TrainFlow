# [Perf] deepseek-v4.1: Skip the request-window history check when invariant checks are off

[Upstream PR](https://github.com/sgl-project/sglang/pull/45276) · state: closed · merged: True

## Original PR description

- `RequestWindow.buffer` checks each SWA layer's history through `expect(_SWA_HISTORY_PRESENT, ...)` (#45223). The predicate `(tags[layer, src] == history_pos) | ~history_valid` was built before the call, so its three kernels ran on every SWA layer even with `SGLANG_INVARIANT_CHECK` off, the default.
- The check now runs only at WARN or above, the same gate other signal-only `expect` call sites use (`unified_hybrid_swa.py`, `dspark_planner.py`). It has no recovery action, so nothing changes at any level except the skipped launches when it is off.
- Verification:
  - DeepSeek-V4.1-Flash on GB300, DP2 attention + MegaMoE (EP2), encoder and decoder replay on, a multi-turn agentic prefill trace at concurrency 512: py-spy put 1.5-2.2% of the scheduler main thread's samples on the predicate line with the check off.
  - A GPU script on `RequestWindow`: matching history passes at STRICT; missing history passes at OFF (not checked) and raises a device-side assert at STRICT.
