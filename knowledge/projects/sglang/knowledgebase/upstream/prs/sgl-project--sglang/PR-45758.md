# [Perf] [AMD] GPT-OSS: Pick the gfx1250 W4A8 MoE backend, in-kernel GEMM 1 gather

[Upstream PR](https://github.com/sgl-project/sglang/pull/45758) · state: closed · merged: True

## Original PR description

## Motivation 

Add 2 switches for the gfx1250 W4A8 MoE path (aiter moe_gemm_a8w4):

- `SGLANG_GFX1250_W4A8_BACKEND=triton|gluon`: it passes `backend=` to both expert GEMMs. Unset keeps aiter's choice (gluon on gfx1250).
- `SGLANG_GFX1250_W4A8_KERNEL_GATHER=1`: by downcasting fewer rows and GEMM1 kernel knows has `gather_idx` set, we can avoid copying and quantizing costs.
