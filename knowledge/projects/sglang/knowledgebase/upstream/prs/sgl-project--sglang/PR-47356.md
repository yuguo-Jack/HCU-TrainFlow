# [Perf] sampling: Avoid full-prompt copies in custom thinking budget logit processor

[Upstream PR](https://github.com/sgl-project/sglang/pull/47356) · state: open · merged: False

## Original PR description

## Motivation

In `python/sglang/srt/sampling/custom_logit_processor.py`, `ThinkingBudgetLogitProcessor.__call__` materializes `req.origin_input_ids + req.output_ids` on every decode step to locate `think_start_id` and count generated thinking tokens, and accepts `bool` values (`True`/`False`) for `thinking_budget` since `isinstance(True, int)` is `True` in Python.

*(Note: rebased/updated after `#47196` landed the `DeepseekOCRNoRepeatNGramLogitProcessor` `window_size` tail slice on `main`.)*

## Modifications

- **`ThinkingBudgetLogitProcessor`**:
  - Added `_open_thinking_tokens_after_start(origin_input_ids, output_ids)` to locate the last `think_start_id` across `output_ids` and `origin_input_ids` via reverse search without concatenating `origin_input_ids + output_ids`.
  - Guarded `thinking_budget` validation with `not isinstance(thinking_budget, bool)` and guarded `req is None`.
- **Unit Tests**:
  - Added tests in `test/registered/unit/sampling/test_custom_logit_processor.py` covering `ThinkingBudgetLogitProcessor` across prompt and output boundaries and boolean `thinking_budget` rejection.

## Accuracy & Benchmark Tests
- `pytest test/registered/unit/sampling/test_custom_logit_processor.py -v` (`36 passed`)
