# [Diffusion] Fuse Anima AdaLN modulation and cache the FFI callable

[Upstream PR](https://github.com/sgl-project/sglang/pull/42608) · state: closed · merged: True

## Original PR description

## Motivation

With Anima's default 28-block configuration, each transformer forward evaluates 85 AdaLN modulation chains:

`LayerNorm(x) * (1 + scale) + shift`

Reuse the existing bit-exact modulation kernel to reduce intermediate tensor traffic and kernel launches. Also cache the shared kernel's exported FFI callable to avoid repeated function lookup.

## Modifications

- Route Anima's eager CUDA FP16/BF16 modulation through `modulate_scale_shift`.
- Convert strided scale/shift views into contiguous `[B, D]` rows when necessary, without copying the `[B, S, D]` activation.
- Cache the exported FFI callable.
- Preserve the original expression for CPU, FP32, and `torch.compile` tracing.

LayerNorm reduction, CUDA arithmetic, launch geometry, and the shared wrapper's eligibility checks, fallback, and error propagation remain unchanged.

## Correctness

Validated on H200 against baseline `affa261e3d`, with candidate `05bee50b2f`:

- **Anima AdaLN:** 36/36 bit-exact comparisons covering FP16/BF16/FP32, batch sizes 1/2, sequence lengths 17/1024/4096, hidden size 2048, and gated/ungated modules. Eligible cases assert fused dispatch; FP32 cases assert fallback. BF16 batch-2 CUDA graph replay also passes.
- **Shared callers:** 48 component cases per version cover FLUX, Ideogram, LingBot, and LTX-2 video/audio. Output byte hashes and dispatch counts match across versions. Five changed-input CUDA graph replays per version pass.
- **Existing tests:** 42 passed per version across the modulation kernel, FLUX/LTX model-site, LTX layout, and Anima test suites.
- **Full-model generation:** all 16 images across the two benchmark experiments have identical decoded pixels and PNG bytes.
- Pre-commit passes for both modified files.

The AdaLN and shared-caller checks use external validation scripts with synthetic inputs. No new repository unit tests are added. Other models were validated at the component level.

[Correctness report, test logs, and source provenance](https://github.com/cuzmi/sglang/tree/codex/pr-results/diffusion-prs/anima-modulate-fusion/rebase_validation)

## Performance

**Workload:** H200, BF16, TP1, FA attention, one 1024×1024 image, 30 steps, CFG 4, seed 42. `torch.compile` and CUDA graph are disabled.

**Model:** `circlestone-labs/Anima-Base-v1.0-Diffusers`, revision `073c3a9db359c31ad0e8aa268d15775473c2176c`.

Both versions run on the same GPU in ABBA + BAAB order. Each arm starts a fresh CLI process, performs a one-step same-resolution request warmup, and then measures one 30-step request: **four process samples per version**.

The metric is worker request wall time with CUDA synchronized at request boundaries. Both versions receive the same timing-only instrumentation, which is excluded from this PR. Model loading, warmup, output transport, and PNG saving are excluded. No profiler or per-stage synchronization is enabled.

| Version | Mean request (ms) | Range (ms) | Sample SD (ms) |
| --- | ---: | ---: | ---: |
| Baseline `affa261e3d` | 3185.73 | 3164.03–3229.58 | 29.95 |
| Candidate `05bee50b2f` | 3065.52 | 3051.42–3099.78 | 22.94 |

Mean latency decreases by **120.21 ms (3.77%)**. The ABBA and BAAB blocks separately show **3.98%** and **3.56%** reductions.

All eight requests complete 30 steps with identical outputs. Source hashes and timing instrumentation are verified for the experiment.

These results cover one fixed prompt, seed, resolution, and GPU instance. The two code changes are measured together; their individual contributions are not isolated.

<summary>Additional measurements and historical evidence</summary>

A separate eight-arm experiment using the unmodified native worker timer measured **3151.82 → 3016.00 ms (4.31% lower)**. That timer does not explicitly wait for CUDA completion before stopping. It ran on another H200 instance, so these samples are not pooled with the primary result, and the difference between experiments does not measure the CUDA tail.

Earlier experiments against `6fa3fe69e2` included an integration-only run that regressed by **4.93%** and a later combined run that improved by **4.15%**. The latter included duplicate-check removal already present in the current baseline. These historical results are retained in the archive and are not used as the current PR's performance result.

Historical profiling showed modulation launches decreasing from 510 to 170 in a denoising step containing 170 AdaLN calls. This was not reprofiled after rebasing.
