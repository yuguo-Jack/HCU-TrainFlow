# [Fix] [AMD] modelopt: Support ModelOpt FP8 Nemotron models on gfx950

[Upstream PR](https://github.com/sgl-project/sglang/pull/48089) · state: open · merged: False

## Original PR description

## Motivation

On MI355X (gfx950), SGLang rejects ModelOpt FP8 checkpoints such as `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-FP8` with `modelopt_fp8 quantization is currently not supported in ROCm.` Once allowed, Nemotron-H's automatic MoE runner choice picks `flashinfer_cutlass`, which ROCm does not have.

## Modifications

Allow `modelopt_fp8` on gfx95, and pick the Triton MoE runner for Nemotron-H ModelOpt FP8 on HIP when the runner is `auto`.

## Accuracy Tests

`nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-FP8` on two MI355X GPUs (TP2) scores 95.45% on the full GSM8K set, versus 95.15% for the BF16 model.

Co-author-with: @JessicaJiang-123
