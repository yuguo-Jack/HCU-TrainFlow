# [Fix] diffusion: Keep ComfyUI patches in the plugin and refresh H3 compatibility

[Upstream PR](https://github.com/sgl-project/sglang/pull/45730) · state: open · merged: False

## Original PR description

## Motivation

Follow up on #44841: ComfyUI compatibility patches belong inside the ComfyUI plugin. Simply moving them there would make spawned workers execute the plugin's eager node imports and pull in ComfyUI dependencies.

Live H200 validation also exposed an existing compatibility failure: the merged profile still pinned an older H3 source and replaced `minimax_h3_norm_modulate_active`, while current H3 uses `MINIMAX_H3_NORM_MODULATE.is_enabled`. Alignment mode therefore aborted during worker startup.

## Modifications

- Move `apps/comfyui_worker_patches/` into `apps/ComfyUI_SGLDiffusion/worker_patches/`, including tests, and update generator imports.
- Lazily load and cache node mappings when ComfyUI requests them, preserving the existing empty-mapping fallback without ComfyUI dependencies.
- Adapt the instance-local H3 patch to the current fusion gate after reviewing upstream changes, and refresh its source hash. Keep the strict source compatibility check.
- Add coverage for clean worker imports, custom-node registration, and the reviewed H3 source hash matching the checkout.

Runtime model sources, workflow options, and worker bootstrap behavior are unchanged. The two commits separate the package move from the H3 compatibility fix discovered during live validation.

## Accuracy Tests

Tested commit `8d0bd76487` on one H200 with the BF16 MiniMax H3 33B checkpoint, eager execution, PyTorch SDPA, no quantization/cache/LoRA. Test case: 384 x 256, 22 frames, 8 Euler steps, seed 123456.

- Ran a fresh native ComfyUI baseline and then SGLD default -> ComfyUI alignment -> default in the same parent process, through the actual ComfyUI node APIs. All four GPU generations completed.
- Confirmed the spawned worker logged `Worker patch applied: h3_comfyui_v1`, and changing alignment mode rebuilt the live worker in both directions.
- Aligned video/audio latents matched the fresh native ComfyUI baseline element-for-element (`max_abs = 0`). Both default runs matched each other exactly. Input conditioning, noise, and sigmas also matched.
- Decoded the aligned output through the video/audio VAEs and saved an MP4 containing 22 video frames and an audio track.
- 25 regression tests passed, including real multiprocessing spawn tests and the source-hash check. Pre-commit checks passed.
- The installed ComfyUI loader smoke test registered all 11 plugin nodes and the web extension.

Scope: the GPU test reused cached text conditioning and called node APIs directly; it did not submit a prompt through the HTTP queue or retest full-resolution workflows.
