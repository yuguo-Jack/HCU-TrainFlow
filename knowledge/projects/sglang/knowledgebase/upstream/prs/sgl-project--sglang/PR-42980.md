# [diffusion] Share SANA-WM refiner block computation

[Upstream PR](https://github.com/sgl-project/sglang/pull/42980) · state: closed · merged: True

## Original PR description

## Summary

Reuse the existing SANA-WM video block implementation in the chunked streaming refiner instead of maintaining a second copy of the same normalization, modulation, cross-attention, and FFN sequence.

Each caller passes its existing self-attention function. The streaming path retains its KV-prefix injection and capture behavior; the ordinary refiner retains its sink/current attention behavior. Neither attention implementation changes.

Two existing files, net 34 lines removed. No new helpers, classes, runtime settings, or test files.

## Validation Scope

- Existing SANA-WM unit tests.
- Old/new native Diffusers LTX-2 block and small transformer comparisons: CPU/CUDA, FP32/BF16, both RoPE layouts, batch 1/2, context boundaries, consecutive inputs, and KV capture/prefix modes.
- Exact comparisons of outputs, captured KV, weights, inputs, RNG state, and ATen operation sequence; source checks for the unchanged surrounding modules and equivalent block bodies.

This is code deduplication, not an attention optimization or a full-checkpoint E2E performance claim.
