# [Refactor] rust-server: Make the advertised listener host an overridable classmethod

[Upstream PR](https://github.com/sgl-project/sglang/pull/47954) · state: closed · merged: True

## Original PR description

## Motivation

`RustServer.gather_server_endpoints` publishes each attention-DP listener at the bound host, or, when the bind address is unspecified (`""`, `0.0.0.0`, `::`), at the address the node's interfaces answer on. That choice was inlined in the collective, so a deployment whose service discovery publishes a different one of the node's addresses (for example a container that is reachable from other nodes only through an address assigned by its orchestrator) had no way to advertise that address short of replacing the whole gather.

## Modifications

- Move the host choice into a new `RustServer._advertised_host()` classmethod (a classmethod because the gather runs before any server instance exists) and have `gather_server_endpoints` call it. A subclass can override the hook to advertise another address.
- No behaviour change: the default is still the bound host, else `get_local_ip_auto(fallback="127.0.0.1")`; the IPv4-bind/IPv6-address error still reads the bind host; the multi-node loopback warning is unchanged.
