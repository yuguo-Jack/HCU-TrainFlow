# [Kernel] Expose bundled FlashMLA MegaAttention kernels and APIs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43918) · state: closed · merged: True

## Original PR description

SGLang’s pinned FlashMLA source already contains MegaAttention, but the sgl-kernel build omits its fused kernels and exposes no callable APIs. Compile the fused prefill/decode kernels and weight permutations on SM100/SM103 and expose them through typed torch operators and a wheel-level Python module. Preserve the current dependency pin, legacy KV formats, SM90 support, and serving behavior.

This is the build/API prerequisite for a separate DeepSeek-V4.1 MegaAttention + NVFP4 serving integration.

Validation:
- CMake source-list checks for CUDA 12.8, 12.9, and 13.0 against the actual pinned FlashMLA source (22/64/64 paths verified; fused kernels only enabled for SM100 builds).
- Python syntax, lint, and formatting checks.
- Added SM100/SM103 numerical prefill, decode/prefill parity, and weight/scale permutation tests, plus a cold-L2 benchmark.
- [CUDA 13.0 ARM64 wheel build passed](https://github.com/sgl-project/sglang/actions/runs/38309395476/job/115011351258) on head `31c0f0c7ba2da34ab36b4d95c51a5711b1b61105`: all 16 fused instantiations and the C++ wrapper compiled, `flashmla_ops.abi3.so` linked, and the wheel was produced. The x86-64 build and GPU numerical tests are still pending.
