# Fix reasoning parser finalization in Responses streams

[Upstream PR](https://github.com/sgl-project/sglang/pull/33099) · state: closed · merged: False

## Original PR description

Chat Completions calls reasoning_parser.parse_stream_end() when a stream finishes to flush any buffered visible text.  The non-Harmony Responses streaming path did not perform this finalization step, so detectors that legitimately return visible reasoning or normal text from finish() could have their buffered output silently dropped.

The fix:
  - Extracts _emit_reasoning_delta() and _emit_normal_delta() helpers from the existing per-chunk event-emission code, eliminating duplication.
  - Calls parse_stream_end() exactly once after the engine chunk loop finishes, before item closure.
  - Routes finalization output through the same helpers used for normal parsed chunks.
  - Skips finalization when finish_reason is "abort", matching Chat Completions semantics.
  - Empty finalization output creates no extra events.

Tests validate:
  - Final reasoning text appears as a delta and in the completed response.
  - Final normal text appears as a delta and in the completed response.
  - Empty finalization emits no extra delta events.
  - Abort finish_reason skips parse_stream_end() entirely.
