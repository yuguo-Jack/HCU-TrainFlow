## Motivation

Add deepseek_v4_flash 1p1d accuracy case and register it to the nightly pipeline

## Modifications

1. Add accuracy test case test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_0731_w8a8_1p1d_16p_gpqa.py :

- Implement a multi-node PD-Sep accuracy test based on TestNpuAccuracyMultiNodePdSepTestCaseBase , reusing DEEPSEEK_V4_FLASH_0731_W8A8_MODEL_PATH from test_npu_performance_utils .
- Define the full PD-Sep deployment configuration:
  - Environment variables : common envs (including DSPARK/Spec V2, DeepEP, and HCCL related settings), plus node-specific overrides for Prefill ( HCCL_BUFFSIZE=2048 , long-sequence DeepEP parameters, etc.) and Decode ( HCCL_BUFFSIZE=1200 , SGLANG_NPU_SPLIT_SHARED_EXPERT_OVERLAP=1 , etc.).
  - Prefill node launch arguments : TP16/DP16, dsv4 attention backend, DeepEP normal mode, modelslim quantization, --disaggregation-mode prefill , Ascend transfer backend, --mem-fraction-static 0.68 , CUDA Graph disabled.
  - Decode node launch arguments : TP16/DP16, DeepEP low_latency mode, --disaggregation-mode decode , CUDA Graph decode batch sizes 1–10, DSPARK speculative decoding enabled ( --speculative-num-draft-tokens 6 , with a W8A8-quantized draft model).
  - Router arguments : --policy cache_aware .
- Add test class TestNPUDeepSeekV4Flash0731W8A8PDSEPGPQAHigh , evaluating the gpqa_diamond dataset with accuracy baseline 0.874, eval batch size 128, and generation config for Think High mode ( thinking=True , reasoning_effort=high , max_tokens=125000 ).
- Register the case via register_npu_ci as a nightly test (est_time=3600, currently marked disabled="accuracy testcase" ).
2. Update nightly pipeline .github/workflows/nightly-test-npu.yml :

- Add a new deepseek_v4_flash_w8a8_1p1d_16p accuracy test entry to the multi-node test matrix (prefill_size=1, decode_size=1, router_size=1, test_type: 'accuracy' , PD separation deployment), pointing to the new test case and integrating it into the nightly NPU e2e multi-node workflow.
