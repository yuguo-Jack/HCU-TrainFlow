# [Refactor] memory-pool: Assemble HiCache host pools from buffer info

[Upstream PR](https://github.com/sgl-project/sglang/pull/47928) · state: closed · merged: True

## Original PR description

## Motivation

Followup of #47714. HiCache assembly still chose host pools through pool type checks, attribute probes and per model branches, and every stack builder kept its own copy of the cache controller construction. The copies had already drifted: the MiniMax sparse stack did not pass `host_memory_mode`, so with `buffer_only` its tree and controller disagreed on the host memory mode. This PR makes the assembler pick host pools from the buffer info each device pool reports and shares the remaining setup.

## Modifications

- `_build_cache_controller` replaces the eight controller constructions and passes `host_memory_mode` everywhere.
- `_KvStrategy` replaces `_DsaStrategy` and `_PlainKvStrategy` and builds single KV stacks from the config that `prepare_host_pool_config` prepares for every root. Family strategies declare the pools they own through `StackStrategy.owns`, so the KV strategy no longer lists them.
- `build_kv_host_pool` chooses the MHA or MLA host from the buffer info type. The `use_mla` parameter, `is_mla_pool`, `collect_host_pool_infos` and `check_packed_kv_rows` are removed, since both host constructors already validate packed draft rows before allocating.
- MiniMax sparse stacks select each host from its buffer info. The NVFP4 pools report model layer ids so the index layers come from the infos instead of a private layer map.
- `getattr` probes are replaced by explicit attributes. The C128 allocator is passed when the C128 tree component exists.
- Mamba entries, device capacity and the MTP draft list use shared helpers.

Behavior change: the MiniMax sparse controller now follows `--hicache-host-memory-mode`. NPU bf16 MLA keeps the host row width from the pool, which differs from the width its buffer info reports.

## Accuracy

HiCache multi-turn KL with forced host hits on 10 models covering every assembly path touched here (MHA, MLA, MLA with draft, SWA with draft, unified SWA, Mamba with MTP, DeepSeek-V4 with MTP, MiniMax bf16, MiniMax NVFP4 with DSpark, QSA), main against this PR. Every model passes, and the assembly plan, the H2D copies and the host transfers are identical to main.
