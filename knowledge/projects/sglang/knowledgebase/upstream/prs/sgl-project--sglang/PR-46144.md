# [Fix] diffusion/disagg: Recompute automatic topology per role

[Upstream PR](https://github.com/sgl-project/sglang/pull/46144) · state: closed · merged: True

## Original PR description

## Motivation

Disaggregated launchers clone an already-normalized `ServerArgs`. Resetting only TP/SP/Ulysses/Ring leaves automatic HSDP, CFG and K/V-gather choices from the parent in each worker. For example, a two-GPU parent with a one-GPU encoder fails before loading with `num_gpus (1) must be >= and divisible by hsdp_shard_dim (2)`.

The standalone launcher also duplicates topology validation without accounting for Ulysses/Ring overrides, and both paths overwrite explicit generic TP/SP with unset role-specific values.

## Modifications

- Share role argument derivation between pool and standalone launchers. Recompute automatic topology for the role's device count; preserve explicit user settings and use the existing validation.
- Apply role-specific flags before generic flags, then automatic defaults. Document this precedence.
- Cover shrinking/growing role GPU counts, CFG, HSDP, K/V-gather, explicit overrides, invalid layouts and parent immutability in the existing test file.
- Isolate the existing offload-policy test's mocked memory from the actual host GPU name. This test also failed on the unmodified base on H200; policy and assertions are unchanged.

Production code: 51 additions / 89 deletions across two existing files. No new flags, production files or request-path work.

## Validation

Remote validation on 2x H200, Python 3.12.15, PyTorch 2.14.1+cu130, Diffusers 0.37.0 and Transformers 5.19.0; base `1e894eb92d403062cf21e2910dba888cad7adb9e`.

- Reproduced the parent-2-GPU / worker-1-GPU pool failure on the base; the same launch completes a real video request after the fix.
- **301 tests and 160 subtests passed** across `test_server_args`, `test_disagg_roles`, `test_launch_server_shutdown`, `test_load_inclusive_e2e` and `test_worker_bootstrap` with the final checkout installed editable.
- Real Wan2.1-T2V-1.3B serving: pool with a larger denoiser than the parent, pool Ulysses2, standalone Ulysses2, standalone generic TP2, monolithic Ulysses2 and monolithic TP2. Each deployment completed **two identical sequential requests**, returned 17 decoded 512x320 frames, reproduced its decoded-frame hash and left no live child processes after shutdown.
- Pre-commit passed.

## Accuracy Tests

GPU requests use FA, 4 inference steps and seed 42. Pool and standalone Ulysses2 outputs are bitwise identical after decoding. Monolithic and disaggregated outputs are not claimed to be bitwise identical: encoder layouts differ (measured PSNR 40.22 / SSIM 0.9743 for Ulysses2 and PSNR 37.89 / SSIM 0.9733 for TP2). No GT or thresholds changed.

Four-GPU coverage is argument-level only; real GPU validation here uses two GPUs and one model family.

## Speed Tests and Profiling

This fixes startup configuration and removes duplicate validation; no inference speedup claim or request hot-path change.
