# [Rust] Honor --disaggregation-bootstrap-port on prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/42620) · state: closed · merged: False

## Original PR description

## Motivation

With `SGLANG_RUST_SERVER=1`, a PD prefill server remaps the KV bootstrap port to its HTTP port and rejects an explicit, different `--disaggregation-bootstrap-port` at launch. Decode nodes and routers that use the default bootstrap port (8998) or a separate one therefore can't reach a Rust-mode prefill server without being reconfigured.

## Modifications

- The bootstrap registry is served on `--disaggregation-bootstrap-port` as well as on the HTTP listener.
- When the two ports differ, the base-port server binds a second listener before any worker starts. A port conflict then fails startup and releases every bound port.
- Both listeners share one registry. The separate listener also answers `/health` for decode heartbeats, and if it exits, the HTTP listener stops with it.
- Validation rejects a bootstrap port of 0 or one equal to the gRPC port.
- The launch-time aliasing of the bootstrap port to the API port, and its rejection of a different port, are removed.
- Tests:
  - Rust: the separate listener shares the API registry and fails on a port conflict; port 0 and the gRPC port are rejected.
  - Python: the bootstrap port is forwarded only on prefill; Rust prefill keeps the configured port.
  - The PD Rust e2e test comment is updated; that test still covers the shared-port layout.

## Tests

- `python -m pytest -q test/registered/unit/entrypoints/test_rust_server_dp_ports.py`: 20 passed.
- In `rust/`: `cargo test -p sglang-server` (336 passed), `cargo clippy -p sglang-server --all-targets -- -D warnings` and `cargo fmt --all -- --check` are clean.
- `pre-commit run --from-ref origin/main --to-ref HEAD`: all hooks pass.
- `test/registered/disaggregation/test_disaggregation_rust_server.py` on two A100s, run on a tree with all the related Rust-frontend PRs merged (Llama-3.1-8B-Instruct, nixl transfer; triton attention and pytorch sampling because of the local FlashInfer build; `test_gsm8k` skipped because it needs a dataset download): 5 passed with the test's shared API/bootstrap port, and 5 passed with a distinct `--disaggregation-bootstrap-port`. Current main refuses the distinct-port layout at launch with the `ValueError` this PR removes.
