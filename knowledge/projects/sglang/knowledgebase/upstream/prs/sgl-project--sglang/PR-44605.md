# [Feat] disaggregation: Let a KV transfer backend skip the checksum for an incomparable peer

[Upstream PR](https://github.com/sgl-project/sglang/pull/44605) · state: closed · merged: True

## Original PR description

## Motivation

The optional PD KV checksum (`--disaggregation-enable-kv-checksum`) digests the prefill rank's complete local KV for a request, and the decode rank re-digests its own local KV when the request enters a batch. That comparison only holds when both ranks hold the same bytes. Under a TP width mismatch between prefill and decode, a decode rank receives a head slice of what one prefill rank digested, or a concatenation of slices from several prefill ranks, so every request is reported as corrupted and aborted even though the transfer is correct.

The transfer backend is the component that knows, per prefill peer, whether the two layouts match. This PR gives it a way to say so.

## Modifications

- `BaseKVManager.should_verify_kv_checksum(bootstrap_addr) -> bool`, defaulting to `True`. A backend returns `False` for a peer whose digest is not comparable with this rank's local KV.
- `SchedulerDisaggregationDecodeMixin._verify_kv_checksums` consults the decode prealloc queue's KV manager before digesting a request and admits the request unverified when the backend answers `False`. Health checks and a zero expected checksum keep their existing fast paths; the in-tree backends keep the default and are unchanged.
- `test_kv_checksum.py`: a new case admits one request through the hook while a sibling with a bad digest is still aborted, which also exercises the index-based batch filtering on the skip path. The fake scheduler and request gain the prealloc queue and bootstrap address the production path reads.

https://github.com/sgl-project/sglang/pull/39729 proposes a layout signature carried in the metadata row to guard such topologies generically; this hook is the smaller per-backend opt-out and composes with it.

## Accuracy Tests

Not applicable: no change to model outputs. The checksum is a diagnostic that is off by default.

`python -m pytest test/registered/unit/disaggregation/test_kv_checksum.py` on one NVIDIA GPU: 18 passed (17 existing + 1 new). The new case fails without the decode-side hook and also fails if the skip path appends the request instead of its index, so it guards both.
