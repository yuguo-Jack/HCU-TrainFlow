# Disable DualGemm fusion for Inkling dense MLP

[Upstream PR](https://github.com/sgl-project/sglang/pull/43447) · state: closed · merged: True

## Original PR description

#41887 routed `LlamaMLP.forward` through a fused gate/up + SwiGLU kernel for unquantized MLPs at ≤16 tokens. `InklingDenseMLP` inherits that forward but uses interleaved gate/up weights and its own FP32 `InklingSwiglu`, which the fused path bypasses. Small-batch forwards through the unquantized dense layers therefore compute the wrong activation. `test_inkling_small_nvfp4` DSpark determinism fails (KL 0.0015 vs 1e-9):
- https://github.com/sgl-project/sglang/actions/runs/37922198403/job/113792765507

Turn the fusion off for `InklingDenseMLP`. Bisected to #41887 (parent KL 0.0, merge KL 0.00067). With this change, current main passes the full test file (all KL 0.0, gsm8k 0.890).
