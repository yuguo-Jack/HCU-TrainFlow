## AITER prerequisites

- [ROCm/aiter#6411](https://github.com/ROCm/aiter/pull/6411) — gfx950 tuned BF16 rows for the merged MoE front, loaded by `aiter.tuned_gemm.tgemm`. Without those rows `tgemm.mm` takes the default kernel.

## Motivation

The merged MoE front GEMM (`[router | latent | shared]`, N = 6016 or 4480, K = 7168) runs on the default BF16 GEMM. AITER has gfx950-tuned kernels for these shapes.

## Modifications

**`3b50cd5d52` run the ROCm merged MoE front through AITER's tuned BF16 GEMM**
- Send the merged MoE front GEMM to AITER tgemm inside a decode token window, for the full and Quark partial fronts.
- Gate it behind SGLANG_OPT_HIP_K3_TUNED_MOE_FRONT and its token bounds, off by default, and document them.

Switch: `SGLANG_OPT_HIP_K3_TUNED_MOE_FRONT` with `SGLANG_OPT_HIP_K3_TUNED_MOE_FRONT_MIN_TOKENS=1`. Everything is ROCm only; CUDA and other checkpoints keep the existing path.
