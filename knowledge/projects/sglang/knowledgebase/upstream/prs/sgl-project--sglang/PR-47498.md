# [Fix] nemotron: Accept transformers 5 layer type names

[Upstream PR](https://github.com/sgl-project/sglang/pull/47498) · state: open · merged: False

## Original PR description

## Motivation

transformers 5 writes Nemotron-H layer types as `linear_attention` and `full_attention`. `NemotronHConfig` only accepted `mamba` and `attention`, so those configs failed to load. Fixes #47444.

## Modifications

`linear_attention` maps to `mamba` and `full_attention` maps to `attention` before validation. The rest of the config still uses the legacy names.
