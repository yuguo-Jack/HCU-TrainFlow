## What

Register two Triton data movement parity tests in AMD 1-GPU PR CI:

- `test_gdn_fused_split_head_ratios.py` (6s) compares the GDN QKV split with PyTorch slicing across head ratios; its helper has a HIP path.
- `test_vocab_parallel_embedding.py` (13s) compares the Triton lookup with `torch.nn.functional.embedding` across dtypes, token IDs, and weight layouts.

Both tests run without a model or server. The active AMD small suite grows from 91 to 93 entries (+19 estimated seconds); the NVIDIA registrations are unchanged.
