# [Perf] diffusion: Cache FLUX.2 Klein reference K/V across steps

[Upstream PR](https://github.com/sgl-project/sglang/pull/47953) · state: open · merged: False

## Original PR description

Register `black-forest-labs/FLUX.2-klein-9b-kv` using the existing Klein pipeline. Reference tokens use timestep zero and isolated attention; `lossless` reuses their per-request K/V after the first step, while `exact` recomputes them. No new pipeline stage or server flag.

On one B200, two-reference 1024×1024 editing at four steps improves from **1.030 s to 0.661 s (35.8%)**. Same checkpoint, FA, eager, resident components; A–B–B–A with one warmup and three measured requests per block. All 12 saved PNGs are byte-identical. This compares caching with full recomputation of the KV checkpoint, not with the ordinary Klein checkpoint.

Validation: one attention isolation/reuse property, the B200 serving case comparing `lossless` against `exact`, 11 existing registry tests, and pre-commit pass. The serving case intentionally checks pipeline output rather than raw-component accuracy. The official Diffusers pipeline was also exercised (SSIM 0.907 / PSNR 23.78 dB against native output); official bitwise parity is not claimed.

Sequence parallel editing is explicitly rejected; CUDA-graph admission is left for follow-up. Multi-GPU execution was not validated.

Builds on the reference-isolation approach in the closed, unmerged #20879 and the [official Diffusers implementation](https://github.com/huggingface/diffusers/pull/13262). No active overlapping KV-support PR was found.

Restart the server for each A–B–B–A block. Send one warmup and then three timed requests per block; include output encoding/saving in the request time.

Submit multipart image uploads to `/v1/images/edits` using the two bear images from the existing `MULTI_IMAGE_TI2I_UPLOAD_sampling_params` fixture.

```bash
CUDA_VISIBLE_DEVICES=0 SGLANG_DIFFUSION_SYNC_STAGE_PROFILING=1 sglang serve --model-path black-forest-labs/FLUX.2-klein-9b-kv --backend sglang --attention-backend fa --disable-conditioning-cache --num-gpus 1 --tp-size 1 --ulysses-degree 1 --ring-degree 1 --performance-mode manual --dit-cpu-offload false --dit-layerwise-offload false --text-encoder-cpu-offload false --vae-cpu-offload false --enable-torch-compile false --enable-breakable-cuda-graph false --warmup-mode off --output-path outputs --port 31435 --master-port 32435 --scheduler-port 33435
```

Request fields:

```json
{
  "prompt": "The magician bear is on the left, the alchemist bear is on the right, facing each other in the central park square.",
  "size": "1024x1024",
  "num_inference_steps": "4",
  "guidance_scale": "1",
  "true_cfg_scale": "1",
  "seed": "42",
  "quality": "lossless",
  "response_format": "url",
  "output_format": "png"
}
```

For the recompute arm, replace only the cache argument after calling the config's original `prepare_pos_cond_kwargs`:

```python
from sglang.multimodal_gen.configs.pipeline_configs.flux import Flux2KleinKVCachePipelineConfig
prepare = Flux2KleinKVCachePipelineConfig.prepare_pos_cond_kwargs
def recompute(self, *args, **kwargs):
    result = prepare(self, *args, **kwargs)
    result["reference_kv_cache"] = None
    return result
Flux2KleinKVCachePipelineConfig.prepare_pos_cond_kwargs = recompute
from sglang.cli.main import main
main()
```

Use this script as the baseline CLI entrypoint with the same `serve` arguments. This is a benchmark ablation, not a new runtime option.
