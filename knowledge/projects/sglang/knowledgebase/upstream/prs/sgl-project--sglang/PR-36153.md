## Motivation

This PR enables Ulysses sp on CPU and adds a packed QKV kernel for the Ulysses all-to-all path.
After[ PR #35435](https://github.com/sgl-project/sglang/pull/35435) is merged, the Ulysses SP all_to_all_single path can use the group-aware CPU SHM implementation when the input meets the SHM eligibility requirements.

## Modifications

Add a CPU packed QKV kernel.
Integrate the packed QKV path into CPU Ulysses attention.
Enable Ulysses sequence parallelism on CPU.
Add unit test
