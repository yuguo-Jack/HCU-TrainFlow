# Fix flashinfer_megamoe transport rows undeclared sum group error

[Upstream PR](https://github.com/sgl-project/sglang/pull/46369) · state: open · merged: False

## Original PR description

## Summary
- Fix Issue #46316: When `flashinfer_megamoe` is used as the a2a backend with dp-attention, the transport rows declare `group=None` (because ep=True), but `MoeTransport.prepare_output()` was wrapping `MoEOutput` in `MoeFinalize` whose `completion_group=SumGroup.MOE_OUTPUT` fails validation against empty groups tuple.
- The fix checks if `self.rows.group is None` when `MoEOutput` is received, and if so, calls `hidden_states.get_merged()` to complete the merge immediately instead of wrapping in `MoeFinalize`.

## Test plan
- [ ] Verify that flashinfer_megamoe backend with dp-attention no longer raises "transport finalize owes an undeclared sum group" error
- [ ] Verify that other a2a backends (deepep, mooncake, nixl, mori, etc.) still work correctly
- [ ] Verify that non-ep configurations still work correctly
