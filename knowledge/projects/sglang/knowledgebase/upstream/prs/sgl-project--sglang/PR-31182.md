## Motivation

<!-- Describe the purpose and goals of this pull request. -->

In the current prefill‑decode separation setup, when prefill uses context parallelism (CP), only rank 0 is responsible for transmitting KV cache. As request concurrency increases, this becomes a transmission bottleneck. By adding a follow bootstrap room strategy, the KV cache transmission can be distributed relatively evenly across all ranks, alleviating the bottleneck.

<!-- Detail the changes made in this pull request. -->
