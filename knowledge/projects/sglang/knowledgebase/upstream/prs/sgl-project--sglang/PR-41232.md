Merge in this order.

## This PR

**Return DiffusionGemma output token scores through `/generate`.**


## Changes

- Return scores for emitted tokens and requested candidate tokens.
- Keep each request's final scores when a shared logits buffer is reused.
- Preserve score rows through batching and streaming.
- Clear unfinished canvas state after retraction. Keep tokens and scores already returned.
- Reject unsupported prompt logprobs.

Scores come from the denoiser. They are not causal sequence likelihoods or calibrated confidence.
