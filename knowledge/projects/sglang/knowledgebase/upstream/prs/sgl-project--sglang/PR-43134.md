# [diffusion] Skip LTX-2 SP masks only for globally unpadded sequences

[Upstream PR](https://github.com/sgl-project/sglang/pull/43134) · state: closed · merged: True

## Original PR description

LTX-2 constructs an all-true SP padding mask even when the complete sequence has no padding, which sends attention through the masked path instead of the fused backend. Skip that mask only when the global sequence is unpadded. A rank with a fully valid local shard must still provide a mask when another rank contains padding, so all ranks use the same attention and collective path.

- Record global video/audio padding during sequence sharding and carry it through the request.
- Use those flags for LTX-2 mask construction, including JoyEcho callers.
- Cover padded and unpadded video/audio shards, including uneven splits across ranks.

Continues #40755 by @jackyhkust and preserves the original commits and authorship. Thanks for the original optimization and tests.

The H100 audio consistency failure reported on #40755 still requires end-to-end CI verification; this change does not modify ground truth or consistency thresholds.
