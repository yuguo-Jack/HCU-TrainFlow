# [Doc] hicache: Fix MLA expansion in HiCache design doc

[Upstream PR](https://github.com/sgl-project/sglang/pull/46602) · state: open · merged: False

## Original PR description

## Motivation

I was reading the HiCache design doc and hit this line, where MLA is expanded as "Multi-Layer Attention":

> ... in contrast, for MLA (Multi-Layer Attention) models, all ranks hold the complete and identical KV data for each token ...

MLA is Multi-Head Latent Attention (DeepSeek's latent attention). This repo already spells it that way in `docs/docs/advanced_features/attention_backend.mdx` — "The support matrix is split into two parts: MHA (standard attention) and MLA (multi-head latent attention)" — so the HiCache design doc contradicts the attention-backend doc.

## Modifications

One line in `docs/docs/advanced_features/hicache_design.mdx`: the acronym expansion is corrected from "Multi-Layer Attention" to "Multi-Head Latent Attention".

No technical statement is changed. For MLA, all TP ranks hold the complete and identical KV data for each token, which is why only one rank needs to initiate the write-back.
