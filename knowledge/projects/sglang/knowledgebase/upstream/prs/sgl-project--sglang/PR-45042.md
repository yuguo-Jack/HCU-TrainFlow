# [Fix] scheduler: Clear stale `encoder_swa_reset` in `convert_decode_to_extend`

[Upstream PR](https://github.com/sgl-project/sglang/pull/45042) · state: closed · merged: True

## Original PR description

- `convert_decode_to_extend` sets `encoder_swa_reset` to `[False] * bs`: decode rows are never fresh placements, so the converted 1-token extends reset no encoder SWA window
- Regression test in `test_schedule_batch_convert_decode_to_extend.py`

Before, the flags left over from the batch's prefill made encoder SWA bounded replay fold extra replay rows into the converted batch that the DP padding never counted, and could raise its odd-prefix `ValueError` (DeepSeek-V4.1 under DP attention).
