# [CI] [AMD] rerun-test: Add `--amd` to rerun tests on their AMD runners

[Upstream PR](https://github.com/sgl-project/sglang/pull/48190) · state: open · merged: False

## Original PR description

## Motivation

`/rerun-test` reruns chosen test files on a PR, each on the runner it is registered for, but only for CUDA and CPU. A file registered with `register_amd_ci` gets "rerun-test.yml has no AMD job". So an AMD-only test, or the AMD registration of a shared test, cannot be rerun from a PR comment. The CI States tip still points every PR at `/rerun-test`.

## Modifications

- `/rerun-test --amd <specs>` and `/rerun-group --amd <groups>` run the specs on the AMD runners of their `register_amd_ci` suites instead of NV. A file registered on several AMD pools fans out to one dispatch per pool, as CUDA does. Without `--amd`, nothing changes for NV.
- `rerun-test.yml` gains an `amd` mode and a `rerun-test-amd` job. It brings up the CI container the way `pr-test-amd.yml` does (`ensure_vram_clear.sh`, `amd_ci_start_container.sh`, `amd_ci_install_dependency.sh`), then runs each file directly through `amd_ci_exec.sh`, like the CUDA job does. It uses `max-parallel: 2`, because AMD runners are shared with PR CI. The Docker Hub login is passed only when `pr_head_sha` is empty, so fork code never receives it. That is the same rule as `HF_MUSE_SPARK_TOKEN`.
- `partition_rerun_tests.py`: AMD estimates are used for partitioning and for the 60-minute limit. NV estimates are byte-identical to before.
- For now, the suite-to-runner table is `AMD_SUITE_RUNNERS`, kept in sync with the AMD workflows by `scripts/lint/check_amd_rerun_runners.py`. Once #47946 lands, it reads `amd_runner_configs` the way the CUDA path reads `runner_configs`, and the dict and the lint go away.
- The skill and the contribution guide document `--amd`.

## Verification

Offline, with a mocked GitHub API:

- All 3115 test specs resolve identically for NV. The only differences are the error texts for AMD-only files, which now suggest `--amd`.
- The NV `estimate_seconds` values (all files across 11 runners plus cpu) and the NV partitions are byte-identical.
- `--amd` resolves 372 (file, runner) entries and rejects nightly and disaggregation suites with a reason.

An end-to-end test of the command on this PR follows below.
