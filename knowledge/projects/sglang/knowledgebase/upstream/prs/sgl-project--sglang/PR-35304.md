# [Feat] [XPU] encoder: Support NomicBERT / ModernBERT embeddings and InternVL3_5

[Upstream PR](https://github.com/sgl-project/sglang/pull/35304) · state: open · merged: False

## Original PR description

Intel XPU model support for encoder embeddings and InternVL3_5 — the XPU-specific
model-enabling changes. The backend-agnostic fixes are reviewed separately: SEP-preserving
truncation in #39754 and the Hunyuan qk_norm reshape in #41160.

## Motivation

- **nomic-ai/nomic-embed-text-v1.5** (`NomicBertModel`) had no SGLang model, so the
  Transformers fallback raised `NotImplementedError: get_input_embeddings ...`.
- **ibm-granite/granite-embedding-english-r2** (`ModernBertModel`) fell back and
  crashed in the forward pass (`RuntimeError` in `set_kv_buffer`) — a bidirectional
  encoder routed through the paged decoder KV cache.
- **OpenGVLab/InternVL3_5-30B-A3B** (Qwen3-MoE backbone) crashed at load
  (`AttributeError: 'InternVLChatConfig' object has no attribute 'num_experts'`) and,
  once loading, hung/crashed the vision encoder under concurrent multimodal at tp>1
  (Level Zero USM-memcpy deadlock on a per-block device->host `.item()`; DEVICE_LOST
  batching ViT tiles).

(`BAAI/bge-base-en-v1.5` needs no new model file; it already runs on XPU as a `BertModel`.
#39754 keeps its trailing `[SEP]` when long inputs are auto-truncated.)

## Modifications

Encoder embeddings:
- `models/nomic_bert.py` (new): `NomicBertModel` — RoPE, SwiGLU, post-norm; SDPA,
  `AttentionType.ENCODER_ONLY`.
- `models/modernbert.py` (new): `ModernBertModel` — RoPE, local/global attention,
  GeGLU; SDPA, `ENCODER_ONLY`.
- `test/manual/prefill_only/test_xpu_encoder_embedding.py`: XPU embedding UT.

InternVL3_5 (XPU):
- `models/internvl.py`: read `num_experts` from `config.llm_config`; pass the host
  `max_seqlen` into the vision attention metadata; chunk the ViT forward to
  `SGLANG_VIT_MAX_TILES` tiles on XPU.
- `layers/attention/vision.py`: `VisionIntelXPUAttention` (XPU-only class) consumes
  the metadata's host `max_seqlen` instead of re-deriving it from GPU `cu_seqlens`.
- `environ.py`: add `SGLANG_VIT_MAX_TILES` (default 12 = InternVL per-image tile cap).

## Accuracy Test

Intel XPU (Arc Pro B60), vs the HuggingFace reference.

Encoders — MTEB SciFact NDCG@10 (300 queries / 5183 corpus), tp-1:

| Model | cosine vs HF | SciFact NDCG@10 | HF ref |
|---|---|---|---|
| nomic-ai/nomic-embed-text-v1.5 | 1.00000 | 0.6803 | (prefix-sensitive) |
| ibm-granite/granite-embedding-english-r2 (ModernBERT) | 1.0 fp32 / >=0.9999 bf16 | 0.6720 | 0.6815 |

InternVL3_5-30B-A3B — tp-4 (61.7 GB bf16): loads with 0 skipped params, MoE
initialized, multimodal smoke (red image -> "Red"); P1 lmms-eval **mathvision_testmini
38.2, mmmu_val 27.4**.

## Speed Test and Profiling

New encoder models are small SDPA (no KV cache). InternVL removes a per-block
device->host sync on XPU and bounds the ViT forward; non-XPU paths are unchanged.
