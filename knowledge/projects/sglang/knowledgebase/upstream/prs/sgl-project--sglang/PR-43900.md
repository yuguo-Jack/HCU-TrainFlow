# [Scheduler] Mark decode rows by count and extract the per-row decode commit

[Upstream PR](https://github.com/sgl-project/sglang/pull/43900) · state: open · merged: False

## Original PR description

Stacks on #43899

- A step marks its decode rows with `num_decode_rows` instead of a request list; `mix_with_running` sets it after its merge.
- The per-row decode commit is extracted from the decode result path as a function.
- The unused row role enum and the chunked request copy on batch copies are dropped; the speculative output stride is read once per decode step.

No behavior change.
