# [Fix] epd: Reject dequeued encoder requests when stopping during coalescing

[Upstream PR](https://github.com/sgl-project/sglang/pull/44209) · state: open · merged: False

## Original PR description

## Motivation

Stopping `EncoderScheduler` during same-turn image/audio coalescing can leave the first dequeued request unresolved. `_collect_batch()` has removed that request from the queue and yielded, but `_batch_worker()` has not yet received the returned batch. Its cancellation handler therefore sees an empty batch, and `stop()` can only reject requests still in the queue. The affected caller continues waiting until its request timeout.

## Modifications

- Dequeue the first request in `_batch_worker()` so its existing exception/cancellation cleanup owns the request before coalescing yields.
- Pass that request to `_collect_batch()`; retain the existing batch size and same-turn coalescing behavior.
- Add deterministic image/audio regression cases covering both the dequeued request and the still-queued request during `stop()`.
