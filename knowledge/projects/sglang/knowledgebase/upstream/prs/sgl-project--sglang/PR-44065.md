## Motivation

Refresh the cookbook's interactive **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983) on GLM-5.2, DeepSeek-V4, DeepSeek-V4.1, Qwen3.5 and Qwen3.8-Flash-Next against the latest InferenceX `main`. Only two open InferenceX PRs stay overlaid. The configurations are mirrored from SemiAnalysis submissions as raw launch commands, each linked to the run that measured it.

This PR adds the GLM-5.2 NVFP4 B300 Dynamo+SGLang aggregated TP4 submission from [InferenceX #3953](https://github.com/SemiAnalysisAI/InferenceX/pull/3953). It stops overlaying four open InferenceX PRs that are not ready for submission. Lanes that exist only in those PRs leave the pages, and lanes they had revised go back to their measured `main` versions. It also corrects two pipeline errors: the number of Dynamo frontends shown, and four GLM-5.2 GB200 lanes that were pinned to outdated runs. The Deployment panels are unchanged.

## How the commands are produced

The pipeline and rules are the same as in #42726, #43083, #43799 and #43983, with these changes:

- **Frontend node count.** The fix described above.
- **InferenceX's composed recipes.** InferenceX `main` now builds each srt-slurm recipe from a fragment plus shared blocks, and binds the matrix point at launch ([InferenceX #3805](https://github.com/SemiAnalysisAI/InferenceX/pull/3805), [#3809](https://github.com/SemiAnalysisAI/InferenceX/pull/3809), [#3818](https://github.com/SemiAnalysisAI/InferenceX/pull/3818), [#3820](https://github.com/SemiAnalysisAI/InferenceX/pull/3820) and [#3824](https://github.com/SemiAnalysisAI/InferenceX/pull/3824), merged on 2026-10-13). A lane pinned to such a commit (here only #3953, whose head merged that refactor) is rendered from the recipe that InferenceX's own binder (`infx generate`) produces at that commit. For #3953, this gives the same server commands as the pre-refactor head `caa2199e` did.
- **Dashboard refresh.** Recent dashboard dates are now re-fetched on every sync. This is how the GLM-5.2 GB200 re-pin above was found.
- **New keep rule.** `--prefill-delayer-max-delay-passes`, an SGLang scheduler setting for `--enable-prefill-delayer` that #3953 uses at c48.

Each lane is rendered at the exact commit of the run that produced its dashboard data. For an open PR, that is the run named by its authorized `/use` comment, or the PR head when there is none. SA-only settings are removed: the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment). Placeholders replace IPs, ports and NICs. Router and KV-offload variants that were not run are derived and labeled "Derived — not run".

- **Not mirrored.** `qwen3.5-fp8-h100-sglang-agentic` (H100 without MTP) has never produced dashboard data, so there is no run to pin it to.

The data files are generated, so there is no hand-written code to review here.
