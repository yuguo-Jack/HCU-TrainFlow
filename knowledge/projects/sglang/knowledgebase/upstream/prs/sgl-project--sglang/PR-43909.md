# [Test] Record the call order of every event loop on a fake scheduler

[Upstream PR](https://github.com/sgl-project/sglang/pull/43909) · state: open · merged: False

## Original PR description

Stacks on #43908

- A unit test drives each flat and pipeline event loop on a fake scheduler and compares the recorded call order with a golden log in a data file, covering PD overlap delayed sampling, profiler label spans, PD prefill without staging, and PD decode idle rounds with queued requests.
- `SGLANG_TEST_REGEN_EVENT_LOOP_ORDER=1` re-records the golden log.

Test only.
