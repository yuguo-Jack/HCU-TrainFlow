# [Feat] Diffusers: Add a video encoder registry

[Upstream PR](https://github.com/sgl-project/sglang/pull/45746) · state: open · merged: False

## Original PR description

Assisted by Deepseek Flash v4.1

This PR adds a small registry: a VideoEncoder protocol, register_video_encoder(), and an entry-point group (sglang.video_encoders) so a package can publish a backend without patching SGLang. The stage takes an optional encoder_name and resolves it through open_video_encoder(); None keeps the built-in default, so behaviour is unchanged for existing callers, including the None-means-fall-back-to-host-save contract when the encoder cannot handle the output.

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Currently SGLang is limited to the FFmpeg-based video encoder. Users may want the option of using different audio/video encoders with different capabilities or functionality. 

## Modifications

<!-- Detail the changes made in this pull request. -->

- Adds Video Encoders registry with `CudaVideoEncoder` as the default encoder
- Adds VideoEncoder protocol
