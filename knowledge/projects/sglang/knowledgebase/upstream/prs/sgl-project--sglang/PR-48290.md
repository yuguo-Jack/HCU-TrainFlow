# [Test] [NPU] kimi_k3: run the decode perf case via the aisbench prefix mode

[Upstream PR](https://github.com/sgl-project/sglang/pull/48290) · state: open · merged: False

## Original PR description

## Summary
- Switch the kimi_k3 pure-decode perf acceptance case to the official aisbench prefix-cache test path: repeat_rate=99 selects the prefix mode of run_aisbench.sh, where the aisbench_auto_tools_prefix toolkit builds a dataset whose requests share a 99% token prefix (short independent tails keep every row distinct, avoiding loader dedup) and runs its own per-DP warm-up before the measured pass.
- Remove the non-standard aisbench extensions from the previous PR: --api-type / --warmup-dp / --warmup-shape and the raw-completions config generator; the standard perf path of run_aisbench.sh is byte-identical to the upstream script again.
- Remove the gsm8k-shared-prefix dataset branch and generator from the e2e helpers; the decode case goes back to the plain gsm8k loader.
- Keep the CI-only fixes around the official prefix toolchain (venv reuse, tuna fallback, pyarrow<16 pin, toolkit config path handling, tokenizer trust_remote_code patch) - the official path cannot run inside the CI pod without them.

## Test plan
- [ ] Nightly Test (NPU): decode case Mean TPOT <= 30 ms with the official prefix mode
- [ ] Pure-prefill case unaffected (uses the standard perf path)
