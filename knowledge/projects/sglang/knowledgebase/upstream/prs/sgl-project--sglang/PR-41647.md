# [DSV4.1] Remove host syncs when building late-layer tail metadata

[Upstream PR](https://github.com/sgl-project/sglang/pull/41647) · state: closed · merged: False

## Original PR description

## Motivation

With `--enable-decoder-swa-bounded-replay`, each prefill pass still makes the host wait on the GPU 3–4 times while preparing attention metadata for the late-layer tail. #41659 removed the other prefill host syncs, and this PR removes the remaining ones.

## Modifications

- In `late_layer_tail_layout` and `_build_late_layer_tail_metadata`, copy the tail length lists to the GPU with `async_h2d` (added in #41659) instead of `torch.tensor(..., device=...)`, which blocks.
- In `_build_late_layer_tail_metadata`, pass `output_size=sum(tail_lens_cpu)` to the `repeat_interleave` that builds `low_ratio_req_indices`, so it no longer reads the total length back from the GPU.

Values are unchanged.
