# [Fix] [NPU] attention: fix page-rounded prefix KV gather for unaligned prefixes

[Upstream PR](https://github.com/sgl-project/sglang/pull/47857) · state: open · merged: False

## Original PR description

## Motivation

Enabling `--enable-mixed-chunk` with the pure-MLA path on the Ascend NPU backend crashes with `aclnnFusedInferAttentionScoreV4` error 561002 (DeepSeek-V2-Lite-W8A8):

`The last element(664) of actualSeqLengthsKv is not equal to the T(768) of key/value.`

Root cause: the MLA prefix branch gathers cached KV at page granularity (page size 128 is forced on NPU, each prefix is rounded up to whole pages), but the attention kernel receives exact per-request lengths. The TND tiling check requires the last `actual_seq_lengths_kv` element to equal the gathered row count, which only holds when every prefix is page-aligned. Chunked prefill always has page-aligned prefixes, so the bug stayed latent; mixed batches introduce decode rows with arbitrary `prefix = seq_len - 1` and crash (or silently misread in the no-rope MLA branch, which slices by exact offsets).

## Modifications

All in `python/sglang/srt/hardware_backend/npu/attention/ascend_backend.py`:

1. `init_forward_metadata`: build `flatten_prefix_row_index` (exact prefix row positions within the page-rounded gather output), only when some prefix is not page-aligned.
2. Extract the duplicated prefix-gather code into `_gather_prefix_kv` (shared by the TND and no-rope MLA branches); when the index exists, trim the gathered KV to exact rows before `kv_b_proj` decompression. Page-aligned workloads skip the trim entirely and keep the pre-fix tensor layout bit-for-bit.
3. `forward_mixed`: drop the `NotImplementedError` guard for pure MLA (without DSA) — a mixed batch is a varlen extend batch, and the extend path handles 1-token decode rows.

## Accuracy Tests

- Reproduced the crash with DeepSeek-V2-Lite-W8A8 on Ascend NPU (`--enable-mixed-chunk`, dp2); after the fix, mixed batches run through `forward_mixed -> forward_extend` and requests complete correctly.
- Added unit tests (`test_npu_ascend_backend.py` ): page-rounded prefix gathers with unaligned prefixes match dense reference attention, and the mocked TND kernel's tiling invariant reproduces the failure mode without the fix.

## Speed Tests and Profiling

None. Page-aligned prefixes skip the trim entirely; no dedicated benchmark was run.
