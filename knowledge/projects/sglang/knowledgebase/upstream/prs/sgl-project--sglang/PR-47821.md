## Motivation

During Kimi K3 startup prefill with attention DP, idle ranks can produce empty TopK tensors. The shared padding helper submits a zero-sized Triton grid, which NPU rejects with coreDim=0. This asynchronous error may surface later during DeepEP synchronization.

## Modifications

- Treat empty tensors as a no-op before launching the padded-row fill kernel.
- Preserve existing metadata validation and non-empty tensor behavior.
