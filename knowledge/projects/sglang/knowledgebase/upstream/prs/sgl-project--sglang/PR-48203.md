# [Feat] [Intel] dwdp: Add a Level Zero VMM backend for DWDP on XPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/48203) · state: open · merged: False

## Original PR description

## Motivation

Run DWDP on Intel XPU. Depends on #48202 (VMM backend interface); review only the last commit.

## Modifications

- `utils/xpu_vmm_utils.py`: `XpuVmmBackend` over Level Zero via ctypes (loader >= 1.28). Level Zero cannot map one page twice (oneapi-src/level-zero#536), so DWDP takes the remap path.
- `platforms/xpu.py`: returns `XpuVmmBackend`; free memory counts Level Zero physical memory via sysman.
- `unquant.py`: no padded expert row stride under DWDP. `environ.py`: `SGLANG_XPU_ZE_LOADER_SO_PATH`.
- Docs: "DWDP on Intel XPU" in `hardware-platforms/xpu.mdx`.
- XPU tests: generic VMM/prefetch tests registered for XPU, Level Zero granularity, gpt-oss-20b DWDP + TP control, P/D over NIXL, 2/4-card prefill perf gates.

## Accuracy Tests

gpt-oss-20b, GSM8K (sgl-eval 0.1.3, greedy, n=400), Arc Pro B60:

| Setup | Score |
|---|---|
| TP, 2 cards | 0.960 |
| DWDP, 2 cards | 0.965 |
| P/D: DWDP prefill (2) + TP decode (2), NIXL | 0.960 |

## Speed Tests and Profiling

B60 prefill, gpt-oss-20b, 2k-32k-token prompts: DWDP 1.20-1.29x TP on 2 cards, 1.17-1.49x on 4.
