# [Fix] [NPU] tests: Run the HiCache Mamba case with bfloat16 SSM kernels

[Upstream PR](https://github.com/sgl-project/sglang/pull/45593) · state: closed · merged: True

## Original PR description

<!-- Thank you for your contribution! Please follow these guidelines to enhance your pull request. If anything is unclear, submit your PR and reach out to maintainers for assistance. Join our Slack community at https://slack.sglang.io to discuss further. -->

## Motivation

`test_npu_hicache_mamba` fails on the A3 nightly because the Mamba SSM path inherited the dtype from the model config and ran in FP32, which the NPU kernels do not support. The case never pinned the SSM dtype, unlike the other Mamba coverage.

## Modifications

- `test_npu_hicache_mamba.py`: add `--mamba-ssm-dtype bfloat16` to `common_args`.

Verified in the `nightly-1-npu-a3` job of PR #45589 (same head content): the file now passes in 86.77 s and the launched server command carries `--mamba-ssm-dtype bfloat16`.

## Accuracy Tests

Not applicable: the test's assertions are unchanged, only the SSM compute dtype is pinned to the value the other Mamba cases already use.
