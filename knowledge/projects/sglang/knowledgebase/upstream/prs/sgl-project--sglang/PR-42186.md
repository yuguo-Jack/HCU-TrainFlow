# [Test] diffusion: Cover Kitchen INT8 row limits and benchmark split policy

[Upstream PR](https://github.com/sgl-project/sglang/pull/42186) · state: open · merged: False

## Original PR description

## Motivation

Main now defaults the Kitchen INT8 backend to one GEMM per layer through #44179, superseding this PR's original SM120-only production policy. The explicit row-limit environment overrides still need boundary coverage and a reproducible split/unsplit benchmark.

## Modifications

Keep current production code unchanged. Add twelve import-time environment-policy cases covering default/zero/4096/8192 row limits, custom minimum output width, and row/width boundaries. Load the policy module in isolation so tests do not replace class identities used by other backend tests. Retain an explicit `comfy_kitchen` ABBA benchmark, adapted to main's current policy.

## Validation

Main `913e91ed`, candidate `f9bae2fb`, RTX 5090 D v2, PyTorch 2.13.0+cu130:

- **38 passed**, no skips, across row-policy and full ConvRot backend tests, including real JIT kernels, shared-input/GELU helpers, FP16 inputs, LoRA and backend selection. All 975 imported repository source files match the candidate; changed-file pre-commit and diff checks pass.
- Benchmark: current Kitchen 0.2.40 main plus #224's attention-only correction (GEMM code unchanged), M/K/N = 32700/5376/16128, BF16 activations/bias, INT8 weights, ConvRot256. ABBA with five warmups and twenty CUDA-event measurements per arm; median of arm medians **12.479072 ms split → 10.535864 ms unsplit (15.57% less time)**, bit-exact outputs.

```sh
python -m pytest -q python/sglang/multimodal_gen/test/unit/test_kitchen_int8_row_split.py python/sglang/multimodal_gen/test/unit/test_convrot_int8_backends.py
python -m sglang.multimodal_gen.benchmarks.bench_kitchen_int8_row_split --rows 32700 --input-features 5376 --output-features 16128 --repeats 20
```

The measured unsplit benefit is already available in main; this test/benchmark-only PR introduces no additional inference speedup. The JIT backend is tested for compatibility but is not the backend timed above. Historical sampler results are not re-used as current-head serving evidence.

Implementation and verification used Codex assistance. No independent human review is claimed.
