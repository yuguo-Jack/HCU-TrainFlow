# [Perf] diffusion/pi05: Add opt-in pruning for fully masked cameras

[Upstream PR](https://github.com/sgl-project/sglang/pull/47396) · state: closed · merged: False

## Original PR description

## Motivation

Pi0.5 currently transfers and encodes every configured camera, including views masked out for the entire batch. Add an opt-in way to skip that work. The default remains unchanged because different vision batches, prefix lengths, and attention paths can change floating-point outputs.

## Modifications

- Add `drop_masked_cameras=False` to the Pi0.5 pipeline config.
- Use the same filtered camera order for prefix encoding and cache keys. Remove only views with an all-false CPU mask; retain mixed-validity views, non-CPU masks, and the original layout when every view would be removed.
- Add seven focused regressions for configuration, batch masks, cache keys, graph layout, fallback, and effective positions; document the numerical behavior in the existing cookbook.
