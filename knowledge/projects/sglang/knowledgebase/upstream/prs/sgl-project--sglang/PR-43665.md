# [Doc] gateway: fix WASM example and parser/protocol source locations

[Upstream PR](https://github.com/sgl-project/sglang/pull/43665) · state: open · merged: False

## Original PR description

## Motivation

The gateway docs point at source locations that no longer exist:

- `sgl_model_gateway.mdx` says the WASM examples are in `examples/wasm/` with `auth/`, `rate_limit/`, `logging/` subdirectories; they are in `sgl-model-gateway/examples/wasm/` as `wasm-guest-auth/`, `wasm-guest-ratelimit/`, `wasm-guest-logging/`.
- `sgl-model-gateway/README.md` sends readers to `src/tokenizer`, `src/reasoning_parser` and `src/tool_parser`, which were replaced by the `llm-tokenizer`, `reasoning-parser` and `tool-parser` crates.
- `classify_models.mdx` names `sgl-model-gateway/src/protocols/spec.rs`; the classify request/response types now come from the `openai-protocol` crate (re-exported as `crate::protocols`).

## Modifications

Update those three references. No behaviour change.

Not addressed here: the WASM examples' `wit_bindgen` path `../../../src/wasm/interface` (and the matching sentence in `sgl_model_gateway.mdx`) has pointed at a removed directory since #17746, so the examples do not build. That needs the WIT location from the `smg-wasm` crate and a WASM build to verify, so it is left for a separate change.
