# [Perf] diffusion/registry: Reduce model discovery work at startup

[Upstream PR](https://github.com/sgl-project/sglang/pull/46043) · state: closed · merged: True

## Original PR description

## Summary

Model discovery parses every component file and walks every expression in each model's forward implementation, although registration only needs class and assignment statements.

- Skip parsing helper files without `EntryClass`.
- Skip expression subtrees while preserving breadth-first declaration and alias ordering, including nested statements.
- Flatten the registration branches without changing the supported entry formats.

No new runtime flag, persistent cache, production file, or model import. Pipeline discovery and external-package registration keep their existing behavior. This is separate from the CLI backend-detection work in #43317.

## Validation

Compared main `4b273537dec5` with `41558c352e38` on a dedicated two-H200 environment: Xeon Platinum 8558P, approximately 2 TiB host RAM, Python 3.12.15, PyTorch 2.14.1+cu130, Diffusers 0.37.0, Transformers 5.19.0.

| Measurement | Before | After |
| --- | ---: | ---: |
| Registry discovery, 20 interleaved samples, median | 664 ms | 377 ms |
| Single-GPU process start to HTTP readiness, 3 paired samples, median | 30.26 s | 29.39 s |
| Ulysses2 process start to HTTP readiness, 3 paired samples, median | 30.02 s | 29.61 s |

The complete mapping of **110 models and 18 aliases** is unchanged. Discovery is faster by about 43%; that is not a 43% server-startup improvement.

The 12 real server launches use `Wan-AI/Wan2.1-T2V-1.3B-Diffusers`, cached checkpoint revision `0fad780a534b6463e45facd96134c9f345acfa5b`, offline Hub access, `--warmup-mode off`, and otherwise unchanged defaults. Each launch completes 4-step and 24-step requests at 512x320, 17 frames, seed 42; all 24 outputs were downloaded and decoded. Decoded-frame hashes match before/after within each GPU configuration. No live child processes remain after shutdown.

Startup measurements exclude model download and warmup. They are bounded measurements of this configuration, not a general speedup guarantee; first-request JIT time is not included or claimed as an improvement.

24 tests passed across `test_registry.py`, `test_external_model_package.py`, and `test_plain_component_loader.py`. Added coverage preserves nested declarations, aliases, and single/list/tuple entry formats without importing optional model dependencies. Pre-commit passed.

Production diff: one existing file, +50/-52; tests: +27 lines. No user-facing API or command changes, so no documentation update is needed.
