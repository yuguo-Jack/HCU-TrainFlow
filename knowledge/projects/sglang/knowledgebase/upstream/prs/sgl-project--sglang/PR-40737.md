# [Fix] session: Preserve input embeddings in session requests

[Upstream PR](https://github.com/sgl-project/sglang/pull/40737) · state: open · merged: False

## Original PR description

## Motivation

Fixes #40728. Requests that send `input_embeds` through `/open_session` currently reach session request construction without token IDs, causing a `TypeError` before the request is scheduled.

## Modifications

- Generate placeholder token IDs for first-turn session embedding requests, matching the normal request path.
- Forward `input_embeds` when constructing the session `Req`.
- Add regression coverage for streaming and non-streaming sessions.

Local validation:

- `pre-commit run --files python/sglang/srt/session/session_controller.py test/registered/unit/mem_cache/test_session_token_share_unit.py`: passed.
- `python3 -m py_compile python/sglang/srt/session/session_controller.py test/registered/unit/mem_cache/test_session_token_share_unit.py`: passed.
- A source-level regression harness reproduced the reported `TypeError` before the change and passed for both streaming modes after the change, verifying placeholder IDs and preserved embeddings.
- `PYTHONPATH=python python3 test/registered/unit/mem_cache/test_session_token_share_unit.py`: could not start because `orjson` is not installed in the local environment.
