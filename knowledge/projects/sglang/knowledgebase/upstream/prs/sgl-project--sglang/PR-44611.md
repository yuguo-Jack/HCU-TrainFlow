# [Feat] mem_cache: tag Mooncake linker offloads with the writing session

[Upstream PR](https://github.com/sgl-project/sglang/pull/44611) · state: open · merged: False

## Original PR description

## Motivation

Mooncake can attribute stored objects to a session (`ReplicateConfig.session_ids`, kvcache-ai/Mooncake#4683) and publishes the `session_id` on its stored KV events. An external router can then tell how much of each session's prefix lives in the shared store after GPU eviction; Dynamo's session prefix index consumes this (ai-dynamo/dynamo#16610). With the direct external linker, SGLang writes KV straight to Mooncake, but never passes the session.

## Modifications

- `UnifiedRadixCache.insert` exposes the inserting request's `session_id` (`insert_session_id`) while it applies the insert's actions.
- `UnifiedCacheLinker.offload` takes an optional `session_id`. The wrapper passes the insert's session with each `BackupKV` offload. The UMBP linker accepts and ignores it.
- `MooncakeDirectLinker` carries the session to `MooncakeStore.batch_set_v2` through `HiCacheStorageExtraInfo.extra_info["session_id"]`, with no storage interface change.
- `MooncakeStore` sets `ReplicateConfig.session_ids` on the put only when the installed Mooncake supports the field. Older Mooncake builds see no change.
- Offloads that do not come from `insert` (for example a chunked-prefill advance) stay untagged.

## Accuracy Tests

Not applicable: storage metadata only, no change to model outputs.

## Speed Tests and Profiling

Not applicable: one attribute assignment per insert and one per offload; no new RPCs.

Validation:

- New unit tests: the linker wrapper forwards the inserting session to `offload`; `MooncakeStore.batch_set_v2` attributes every put key to the session, and skips the field when `ReplicateConfig` lacks it.
- Live (same change on v0.5.21): DeepSeek-V4-Flash TP4 with `--enable-unified-cache-external-linker --unified-cache-external-linker-backend mooncake`, a Mooncake #4683 master with KV events over RDMA, and 8 Codex plus 4 Claude Code agent sessions. 13,767 of 13,771 Mooncake stored events carried the agent's session id; the 4 untagged were the store warmup keys.

Draft until kvcache-ai/Mooncake#4683 lands.
