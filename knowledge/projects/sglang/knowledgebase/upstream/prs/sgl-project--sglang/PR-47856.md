# [Fix] [NPU] diffusion: :bug: Fix native profiler selection and trace parsing

[Upstream PR](https://github.com/sgl-project/sglang/pull/47856) · state: open · merged: False

## Original PR description

## Motivation

Fix two failures in the Diffusion Ascend NPU profiling workflow:

1. The newer `torch_npu` patch-API fallback does not apply the requested profiler replacements. A `torch.profiler.profile` instance can therefore reach the NPU trace handler, which requires `prof_if`, and fail with `'profile' object has no attribute 'prof_if'`.
2. Diffusion workers are daemon processes. Native NPU trace parsing creates a multiprocessing pool and rejects that execution context with `The profiling data cannot be parsed during the daemon process`. Generation may complete while no parsed trace is produced.

The expected behavior is a usable trace from the native profiling workflow, without a separate user-run `analyse()` command. This is independent of #45550 and does not include its automatic attention-backend selection changes.

## Modifications

- Select `torch_npu.profiler` directly for NPU profile construction, scheduling, activities and callbacks instead of relying on global patches. Preserve the non-NPU path.
- Keep worker `daemon=True`. In daemon workers, finalize raw data locally and automatically parse the exact rank-local capture in a fresh Python interpreter at normal request completion. A short capture window can stop during denoising without inserting analysis into the remaining denoising steps.
- Wait for parsing and validate the resulting nonempty `trace_view.json`; a successful parser exit alone is insufficient because native analysis can log an error and return normally. Preserve raw data and `sglang_analysis.log` on failure.
- Bound parsing to 600 seconds and manage a separate parser process group, including timeout, interruption and parent-death cleanup. The parser interpreter does not initialize the SGLang runtime or inherit the worker's NPU context.
- Propagate parsing failures across the replica, and do not mask inference errors or cancellation with profiling cleanup errors.

No worker launch-policy, model-forward or quantization changes. The diff is one commit on main and has no unmerged source prerequisite.

Coverage includes backend ownership, the seventh-step callback, both steps in full-pipeline capture, request-finalization parsing, failure propagation, rank-local paths, missing artifacts, timeout, interruption and worker SIGKILL cleanup. NPU parsing and replica communication are mocked; this is not an NPU kernel or distributed e2e test.
