# feat(diffusion): add opt-in plane-major Ulysses QKV layout

## Original PR description

Keep the existing collective and default interleaved layout. Expose packed head/channel views for strided Sage quantization without a post-collective reorder.

Validated with 12 unit tests and real NCCL reference checks on two and four GPUs. AI-assisted.
