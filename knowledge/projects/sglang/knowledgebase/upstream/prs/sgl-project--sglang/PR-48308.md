## Modifications

- Port `mamba_chunk_scan_combined` and `selective_state_update` CPU kernels from #43513 to enable the models.
- Add existing conv state (has_initial_state_value=True) support in causal conv1d.
- `k=6` support for `biased_grouped_topk` for 30B models and `num_experts=512, k=22` support for `Nemotron-3-Super-120B-A12B`.
- Add fused ReLU2 activation support in `fused_experts_cpu`.
- Some tensor format updates in `mamba.py` to accomodate CPU backend impl.
- Ensure aligned packed/unpacked status of w13_weight and w2_weight in gated FFN/MoE to fix gibberish outputs.
