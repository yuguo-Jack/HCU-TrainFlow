# [Fix] diffusion/flux3: Make TP and SP ranks agree on sequential CFG

[Upstream PR](https://github.com/sgl-project/sglang/pull/46430) · state: open · merged: False

## Original PR description

## Motivation

Fixes #46429. `resolve_sequential_cfg` decides between packed and sequential CFG from each rank's own free memory ([L159](https://github.com/sgl-project/sglang/blob/5971f47bc8eacd8989cb6dd67e46b4fc6dbec2ad/python/sglang/multimodal_gen/runtime/pipelines_core/stages/model_specific_stages/flux3_image.py#L159)). The two paths issue different TP all-reduces and SP exchanges per step, so when the ranks decide differently their collectives no longer match, and the request hangs or fails (details in the issue).

## Modifications

- Take the MIN of free memory over the TP and SP groups before comparing, as `_cache_fits` already does in the Qwen-Image 2.1 stage ([L351-L358](https://github.com/sgl-project/sglang/blob/5971f47bc8eacd8989cb6dd67e46b4fc6dbec2ad/python/sglang/multimodal_gen/runtime/pipelines_core/stages/model_specific_stages/qwen_image21.py#L351-L358)).
- New test `test_sequential_cfg_is_agreed_across_ranks` in `test_flux3_image_stages.py` runs two CPU ranks, once as TP=2 and once as Ulysses SP=2, with rank 1 reporting 1 MiB free, and checks that both ranks choose sequential CFG. On main both subtests fail with `AssertionError: [False, True]`; with this change the file passes.

## Accuracy Tests

2x H200, `black-forest-labs/flux-3-image-klein-base` (base e262b44), TP=2, 2048x2048, 20 steps, with another process holding memory on GPU 1 only so that the ranks would split. Without this change the request got no response for 300 s; with it, both ranks chose sequential CFG and the request completed. Two runs with the change gave bit-identical images, and they are also bit-identical to the output without the change when memory is held on both GPUs, so that both ranks take the sequential path.

## Speed Tests and Profiling

Not measured. The change adds at most two CPU all-reduces of one int64 per denoise call, before the step loop.
