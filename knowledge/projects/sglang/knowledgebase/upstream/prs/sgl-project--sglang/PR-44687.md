# [Doc] cookbook: Add Muse Spark Open SWA ratio calculator

[Upstream PR](https://github.com/sgl-project/sglang/pull/44687) · state: closed · merged: True

## Original PR description

## Motivation

Muse Spark Open users need a starting value for `--swa-full-tokens-ratio` at their target context length. Add a calculator at the end of Deployment: a 100,000-token request produces `--swa-full-tokens-ratio 0.02048`.

## Modifications

- Add one context-length input (input + output tokens, up to 1,048,576), a theoretical balanced ratio, and a copyable launch flag. Zero and invalid inputs do not emit a flag.
- Compute `min(1, 2048 / L)` for the 2,048-token SWA window and explain the equal-length, steady-state assumptions, token-capacity versus memory ratios, and HiCache/DFLASH budgeting.
- Add boundary and invalid-input tests, with the calculator export evaluated in isolation as Mintlify loads it.
