# [DSV4.1] Support PP x PD x DSpark

[Upstream PR](https://github.com/sgl-project/sglang/pull/40321) · state: open · merged: False

## Original PR description

## Summary
- Add pipeline-parallel DeepSeek V4.1 model execution and PP-local attention handling.
- Support PP-aware hybrid KV/state pool allocation, CUDA graph buffers, and FlashInfer autotune synchronization.
- Generalize disaggregated DSpark state transfer across PP layouts.
- Add focused coverage for PP model execution, memory pools, server-argument validation, CUDA graph setup, and disaggregation metadata.

## Stack
Merge and review in this order; each branch contains all preceding layers:

1. [#36449](https://github.com/sgl-project/sglang/pull/36449): PP x PD for DeepSeek V4
2. [#36450](https://github.com/sgl-project/sglang/pull/36450): PP x PD x DSpark for DeepSeek V4
3. [#40321](https://github.com/sgl-project/sglang/pull/40321): PP x PD x DSpark for DeepSeek V4.1 **(this PR)**

## Accuracy Tests
- H20 end-to-end greedy GSM8K, 200 examples: 97.5% accuracy.
- DSpark acceptance rate: 0.5973; average accepted length: 3.988.

The deployment used for this end-to-end validation also contained local SM90 MXFP4 performance patches, so these results validate functional accuracy and speculative behavior, not isolated performance impact from this PR.

## Validation
- The transplanted tree exactly matches the previously validated `feat/dsv41-pp-dspark` branch.
- `git diff --check` passes.
- Local macOS rerun was unavailable because the system Python environment does not include pytest; CI should run the focused CPU suites added by this stack.
