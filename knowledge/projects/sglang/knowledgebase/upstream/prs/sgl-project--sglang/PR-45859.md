# [Feat] rust/grpc: Report orchestrator launch facts in api.v1 discovery

[Upstream PR](https://github.com/sgl-project/sglang/pull/45859) · state: open · merged: False

## Original PR description


## Motivation

Exposes new discovery fields to `api.v1` clients.

## Modifications

New fields:
- In `GetServerInfoResponse`:
    - `allow_auto_truncate` - to allow truncation of long prompts (instead of rejeciton)
    - `skip_tokenizer_init` - launch server without tokenizer
    - `num_reserved_tokens` - exact context-window budget under speculative decoding
    - Note: HTTP `/server_info` also gains `num_reserved_tokens`; it already carried `allow_auto_truncate` and `skip_tokenizer_init` from the launch args.
- In `GetModelInfoResponse`:
    - `model_type` - model family
    - `architectures` - HF architecture
- `DeploymentInfo.hicache_host_total_tokens` reports the KV host pool's realized capacity instead of `null`. The tree cache, host pools included, is built before the Rust server launches.
