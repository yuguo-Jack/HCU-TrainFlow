## Motivation
`fused_inplaced_qk_norm` and `fused_qknorm_rope_out_of_place` don't have XPU (SYCL) backends, they will fallback to torch native. This PR allows these two apis to optimized SYCL kernels on XPU.
<!-- Describe the purpose and goals of this pull request. -->

## Modifications

* Updated `_can_use_fused_qknorm_rope` to check for XPU and validate head dimension and packing constraints specific to the SYCL backend, including logging warnings for unsupported configurations.
* Modified `fused_inplace_qknorm_rope` to dispatch directly to the prebuilt SYCL kernel (`fused_inplace_qknorm_rope_xpu`) when running on XPU, bypassing JIT compilation.
* Updated `fused_qknorm_rope_out_of_place` to handle the absence of an out-of-place SYCL kernel by copying inputs and using the in-place kernel as a workaround.
