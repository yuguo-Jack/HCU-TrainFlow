# [Fix] moe: Run the shared-slot routing test without a published server config

[Upstream PR](https://github.com/sgl-project/sglang/pull/45448) · state: closed · merged: True

## Original PR description

- `TestSelectExpertsPerRankSharedSlots` (added in #44913) published server args in `setUp`, which makes `tp_size` readable as 1. Its `_route` then overrides `moe_ep_size=8`, so every test that routes through it fails the topology check:
  ```
  ValueError: parallel topology is inconsistent (set by override):
  tp_size == moe_ep_size * moe_dp_size * moe_tp_size
    1 != 8 * 1 * 1 (= 8)
  ```
- The override only set `disable_shared_experts_fusion`, which the routing path never reads: `resolve_shared_experts_config` reads it at model construction, and this test passes `SharedExpertsConfig` directly. Drop the `setUp`, matching `test_topk_padded_region.py`, which overrides the EP width around `select_experts` without a published config.
- Test-only change.
