# [Refactor] multimodal: [MM refactor 9/9] Expand only the new turn of a multimodal request

[Upstream PR](https://github.com/sgl-project/sglang/pull/46415) · state: open · merged: False

## Original PR description

## Motivation

Multi-turn RL rollouts resend the earlier turns' already-expanded IDs; expanding them again is wasted work.

## Modifications

- `mm_token_expansion_start_len` on `/generate` and chat requests: the expanded prefix length; only placeholders after it are expanded. A list gives one per prompt, repeated for `n > 1` like `input_ids`.
- Documented in `sampling_params.mdx`.
- Borrows the fix for token-space chat requests from dzorlu (#47400).

## Tests

`test_mm_token_expansion_start_len.py`, chat and call-site tests; the bitwise test sends each new turn partially expanded.
