## Original PR description

- Drop 34 tests from `test/registered/unit/mem_cache/test_unified_radix_cache_unittest.py` that cannot catch a bug another test would miss:
  - tests that restate the implementation, such as asserting the code's own `raise` or a constant copied from it;
  - tests whose only assertion is `sanity_check`, or whose assertion sits behind an `if` that can skip it;
  - tests whose only evidence is mock calls;
  - tests whose assertions another test already makes on the same path.
- No behavior change; every remaining test keeps its outcome.
