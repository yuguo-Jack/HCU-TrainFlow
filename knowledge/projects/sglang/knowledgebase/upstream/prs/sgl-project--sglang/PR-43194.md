## Motivation

<!-- Describe the purpose and goals of this pull request. -->

This PR fixes two issues:
1. In cosmos3, fp8 kernel will hit cuda illegal memory when sequence length is big.
2. turn on ulysses sequence parallelism support for action generation.

## Modifications

<!-- Detail the changes made in this pull request. -->
1. With 2 720p control videos, the full sequence length is 85560 tokens, super's down_proj input is 25600 wide. In that case 85600x25600 > 2^31. Currently, the tensor pointer y_ptr is int32, which is insufficient. The fix is cast g_id to int64 when calculating the element position.
2. remove NotImplementedError for action generation when sp > 1. Added some code refactor for sequence sharding.

## Accuracy Tests

<!-- If this pull request affects model outputs (e.g., changes to the kernel or model forward code), provide accuracy test results. -->
Did parity test for action generation with sp > 1.
