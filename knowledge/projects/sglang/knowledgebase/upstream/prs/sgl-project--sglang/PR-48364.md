# [Feat] [CPU] model: Support Intern-S2-Mobius models on CPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/48364) · state: open · merged: False

## Original PR description

## Motivation

The Intern-S2-Mobius series models fail to launch on CPU platforms.

- When `moe_runner_backend` is set to `auto`, the model override forces the backend to `triton_kernel` regardless of the platform.
- The current `topk_softmax_cpu` operator cannot handle models with `num_experts: 2560`.

## Modifications

- interns2_mobius.py: Force the use of `triton_kernel` exclusively on CUDA; for all other platforms (including CPU), retain the `auto` setting.
- Add a code path for the case of 2560 in `topk_softmax_cpu`.

## Accuracy Tests

Startup is normal, and the output is as expected.
