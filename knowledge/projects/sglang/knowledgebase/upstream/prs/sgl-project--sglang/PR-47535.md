# [KVCR] Hybrid-pool (FULL+MAMBA) direct linker (stacked on #47514)

[Upstream PR](https://github.com/sgl-project/sglang/pull/47535) · state: open · merged: False

## Original PR description

Stacked on #47514, which is stacked on #45650. Review only the top commit, 8e3c550b3e.

Direct linker for FULL+MAMBA hybrid pools:
- Maps KV and Mamba state pool groups. Unsupported layouts (MTP draft pools, ReplaySSM, strided envelope state, page-row KV) are rejected.
- The Mamba req_to_token pool receives the layer-transfer counter, so Mamba layers wait on the load.

G3 support was removed from this PR and will come later.
