# [MM] Scatter chunked multimodal embeddings without per-batch copies

[Upstream PR](https://github.com/sgl-project/sglang/pull/43316) · state: open · merged: False

## Original PR description

Depends on #43315 (ViT graph replays return owned output); this PR stacks on it.

## Motivation

During chunked prefill, `_get_chunked_prefill_embedding` concatenates each request's media rows (`torch.cat` in `_assemble_per_image_chunk`) and then the whole batch (`torch.concat`). The result is only consumed by `_scatter_mm_embedding`, which writes it into the text embedding by row index. Both concatenations are alive at once, so a chunk dominated by media tokens transiently holds two extra copies of its media rows next to the `[num_tokens, hidden]` text embedding. `torch.cat` of a single tensor still allocates, so one large image pays both copies. Dropping only the per-request copy does not lower the peak (see the benchmark below), because the batch copy and the text embedding are then alive together.

## Modifications

- The chunk assembly paths return `MMEmbeddingSegments`, the per-item row slices in sequence order (views of embedding-cache entries on cache hits). `_scatter_mm_embedding` takes that list and writes each run of pieces with the existing row-index `index_copy_`. Length trimming and the Qwen3-VL deepstack column split run per piece.
- Runs of small pieces are copied once into staging buffers of at most 64 MiB, one alive at a time, so many small images do not cost one launch per piece. A piece of 64 MiB or more is scattered without a copy.
- Pieces stay views of cache entries and encoder outputs until the scatter, so `DataEmbeddingFunc` results must not alias a buffer that a later call overwrites. Eager encoders return fresh tensors; #43315 makes the ViT graph runners do the same.
- The by-item path (HIP/NPU/XPU) no longer concatenates per request, so every accelerator path reaches the staged scatter without a full copy of the chunk's media rows.
- Precomputed embeddings: single-item requests skip the per-request concat. Multi-item requests still concatenate the request before slicing, as before.
- `_embedding_token_count` reads the row count of 2-D embeddings directly: 1.11 to 0.14 us per cache hit, about 1 ms per 1024 items.

API changes (all private to the multimodal scheduler): `get_embedding_and_mask` returns a list of pieces instead of one tensor, `_scatter_mm_embedding` takes a list, and `separate_deepstack_embeds` is called once per piece (only Qwen3-VL implements it, and its split is column-wise).

Unit tests:

- `test_embed_mm_inputs_matches_whole_sequence_reference` checks `embed_mm_inputs` against a whole-sequence merge built from sentinel rows on each assembly path: per_image, by_item, full_path (two multi-span requests), mixed_modality (image + video), deepstack and precomputed. Chunk windows start and end inside media spans or overlap none, and cached and precomputed embeddings are checked to be unchanged.
- `test_per_image_cache_hits_reach_the_scatter_as_views` asserts that cache hits reach the scatter as views of the cache entries. It fails on main.
- `test_scatter_of_row_pieces_matches_single_source` checks staged runs and lone pieces against a single-source scatter, and `test_scatter_frees_each_staging_copy_before_the_next` checks that at most one staging copy is alive.

## Speed Tests and Profiling

**Server peak.** Peak allocation inside `embed_mm_inputs` above the allocation at entry, measured in the Qwen3-VL-8B server (deepstack width 16384) with requests of five 1792x1792 images (15.7K tokens), one request at a time. Cache hits resend the same images behind a different text prefix. Values in MiB.

| Chunk | Embedding cache | ViT graph | main | #43315 | This PR |
| --- | --- | --- | --- | --- | --- |
| 16384 | miss | off | 2427 | 2427 | 2427 |
| 16384 | hit | off | 981 | 981 | 540 |
| 8192 | miss (chunk 1 / 2) | off | 1456 / 970 | 1456 / 970 | 1456 / 970 |
| 8192 | hit (chunk 1 / 2) | off | 512 / 469 | 512 / 469 | 320 / 293 |
| 16384 | miss, after capture | on | 1565 | 1960 | 1565 |
| 16384 | hit | on | 981 | 981 | 540 |

With eager ViT, the encoder's activations set the peak of cache-miss chunks for this model, so this PR lowers the peak of cache-hit chunks (images continued across chunks, repeated images) rather than the worst case. With ViT CUDA graphs the encoder runs in the graph pool, and this PR absorbs the copy that #43315 adds.

**Microbenchmark.** `embed_mm_inputs` on one NVIDIA Blackwell GPU: synthetic cache-resident image embeddings, hidden size 8192 (Qwen2.5-VL-72B), bf16, one 32K-token prefill chunk. Peak allocation above the inputs; mean of 20 calls; three interleaved rounds per arm (time ranges over the rounds; peaks were identical). "Per-request copy only" keeps the batch concat and drops the per-request one; "no staging" runs this PR with one `index_copy_` per piece.

```python
"""Synthetic embed_mm_inputs microbenchmark: cache-resident image embeddings,
one chunked-prefill batch. Run with PYTHONPATH=<sglang tree>/python."""

import hashlib
import json
import os
import sys
from types import SimpleNamespace
from unittest.mock import Mock

import torch

from sglang.srt.managers import mm_schedule
from sglang.srt.managers.mm_utils import embed_mm_inputs
from sglang.srt.managers.schedule_batch import Modality, MultimodalDataItem
from sglang.srt.runtime_context import get_context, get_parallel

# STAGING_BYTES=1 disables staging (one index_copy_ per piece) for comparison.
if os.environ.get("STAGING_BYTES"):
    from sglang.srt.managers import mm_utils

    mm_utils._SCATTER_STAGING_BYTES = int(os.environ["STAGING_BYTES"])

HIDDEN = 8192  # Qwen2.5-VL-72B hidden_size
CHUNK = 32768
VOCAB = 1024
DEV = torch.device("cuda:0")
DTYPE = torch.bfloat16


def _requests(name):
    """Return [(prefix_len, extend_len, [(start, end), ...])] per request."""
    if name == "1 request, 1 image":
        return [(0, CHUNK, [(16, CHUNK - 17)])]
    if name == "image crosses the chunk boundary":
        # Second chunk of a request whose single image spans both chunks.
        return [(CHUNK, CHUNK, [(CHUNK // 2, CHUNK // 2 + CHUNK - 1)])]
    if name == "8 requests x 4 images":
        ext = CHUNK // 8
        return [(0, ext, [(16 + i * 1000, 16 + i * 1000 + 999) for i in range(4)])] * 8
    if name == "256 images":
        ext = CHUNK // 16
        return [(0, ext, [(8 + i * 120, 8 + i * 120 + 119) for i in range(16)])] * 16
    if name == "1024 images":
        ext = CHUNK // 64
        return [(0, ext, [(4 + i * 28, 4 + i * 28 + 27) for i in range(16)])] * 64
    raise ValueError(name)


def _build(name, gen):
    mm_schedule.init_mm_embedding_cache(64 << 30)
    mm_inputs_list, prefix_lens, extend_lens, ids_list = [], [], [], []
    item_index = 0
    for prefix_len, extend_len, spans in _requests(name):
        seq_len = max(prefix_len + extend_len, max(e + 1 for _, e in spans))
        ids = torch.randint(0, VOCAB, (seq_len,), generator=gen)
        items = []
        for start, end in spans:
            item = MultimodalDataItem(
                modality=Modality.IMAGE, feature=torch.zeros(1), offsets=[(start, end)]
            )
            item.set_hash(10_000 + item_index)
            item_index += 1
            rows = torch.randn(end - start + 1, HIDDEN, generator=gen).to(DEV, DTYPE)
            mm_schedule.embedding_cache.set(
                item.hash, mm_schedule.EmbeddingResult(embedding=rows)
            )
            ids[start : end + 1] = item.pad_value
            items.append(item)
        mm_inputs_list.append(SimpleNamespace(mm_items=items))
        prefix_lens.append(prefix_len)
        extend_lens.append(extend_len)
        ids_list.append(ids[prefix_len : prefix_len + extend_len])
    input_ids = torch.cat(ids_list).to(DEV)
    return mm_inputs_list, prefix_lens, extend_lens, input_ids


def main():
    gen = torch.Generator().manual_seed(0)
    torch.manual_seed(0)
    embedding = torch.nn.Embedding(VOCAB, HIDDEN).to(DEV, DTYPE)
    encoder = Mock(side_effect=AssertionError("cache miss"))
    for name in [
        "1 request, 1 image",
        "image crosses the chunk boundary",
        "8 requests x 4 images",
        "256 images",
        "1024 images",
    ]:
        mm_inputs_list, prefix_lens, extend_lens, input_ids = _build(name, gen)

        def call():
            out, _ = embed_mm_inputs(
                mm_inputs_list=mm_inputs_list,
                extend_prefix_lens=prefix_lens,
                extend_seq_lens=extend_lens,
                input_ids=input_ids.clone(),
                input_embedding=embedding,
                multimodal_model=None,
                data_embedding_func_mapping={Modality.IMAGE: encoder},
                use_deepstack={},
            )
            return out

        for _ in range(3):
            out = call()
        del out
        torch.cuda.synchronize()
        base = torch.cuda.memory_allocated(DEV)
        torch.cuda.reset_peak_memory_stats(DEV)
        out = call()
        torch.cuda.synchronize()
        peak = torch.cuda.max_memory_allocated(DEV) - base
        digest = hashlib.sha256(
            out.view(torch.int16).cpu().numpy().tobytes()
        ).hexdigest()[:16]
        del out
        times = []
        for _ in range(20):
            start, end = (
                torch.cuda.Event(enable_timing=True),
                torch.cuda.Event(enable_timing=True),
            )
            start.record()
            out = call()
            end.record()
            torch.cuda.synchronize()
            times.append(start.elapsed_time(end))
            del out
        print(
            json.dumps(
                {
                    "scenario": name,
                    "peak_gib": round(peak / 2**30, 3),
                    "mean_ms": round(sum(times) / len(times), 3),
                    "digest": digest,
                }
            ),
            flush=True,
        )
        mm_schedule.embedding_cache = None
        torch.cuda.empty_cache()


if __name__ == "__main__":
    override = get_context().override_server_args(tp_size=1)
    override.install()
    try:
        with get_parallel().override(attn_tp_rank=0, attn_tp_size=1, tp_size=1):
            main()
    finally:
        override.restore()
    sys.exit(0)
```
