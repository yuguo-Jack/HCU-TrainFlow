# Add optional uint16/uint8 routed-experts wire encoding

[Upstream PR](https://github.com/sgl-project/sglang/pull/31219) · state: open · merged: False

## Original PR description

Routed expert responses use int32 by default. Setting `SGLANG_ROUTED_EXPERTS_DTYPE=uint16` or `uint8` reduces the raw payload size by 2× or 4×. Responses advertise the actual dtype, and IDs outside the selected unsigned range—including negative sentinels—fall back to lossless int32.

A shared host-side encoder handles both the detokenizer and `skip_tokenizer_init` paths. Dtype metadata follows each payload through multi-tokenizer workers and streaming/non-streaming OpenAI responses. The decoder uses the sender's dtype, defaults legacy payloads to int32, and optionally reshapes flat data into routing rows. Existing `return_meta_info` behavior and token-ID/speculative metadata handling are preserved.

Updated with `sgl-project/sglang:main` at `93809202a3`. Resolved the multi-tokenizer test conflict while retaining upstream grouped-routing tests and routed-expert dtype alignment coverage.
