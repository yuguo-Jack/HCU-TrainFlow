## Motivation

XPress adds a causal refiner to a DFlash draft, improving how tokens within a proposed block fit together. The public Qwen3-8B XPress checkpoint cannot currently use its refiner in SGLang. This change adds support through the existing DFlash speculative decoding path.


reference: https://github.com/vllm-project/vllm/pull/54448
Paper: https://arxiv.org/abs/2608.02438

## Changes

- Add `Qwen3XPressModel` support and load the published refiner weights, including folding the checkpoint's causal mixer for inference.
- Run Jacobi refinement with Triton kernels, using either top-C candidates or the full vocabulary.
- Integrate drafting into the DFlash CUDA Graph path, with an eager fallback. Target verification remains on the existing DFlash path.
- Reject unsupported configurations at startup: non-CUDA devices, TP > 1, incompatible vocabularies or dtypes, and non-dense target LM heads.
- Document setup and add mixer and Jacobi tests.
