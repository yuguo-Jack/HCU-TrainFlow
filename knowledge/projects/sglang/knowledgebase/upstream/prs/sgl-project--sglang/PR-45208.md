# fix(grpc): authenticate native RPCs with the server API key

[Upstream PR](https://github.com/sgl-project/sglang/pull/45208) · state: open · merged: False

## Original PR description

## Motivation

Native gRPC currently rejects `--api-key`, preventing authenticated SGLang engines from launching with a Dynamo sidecar.

## Modifications

Pass the configured key to both leader and metadata-only follower listeners. Authenticate every native RPC before dispatch using bearer metadata and constant-time token comparison. Missing, malformed or incorrect credentials return `UNAUTHENTICATED`; launches without a key retain their existing behavior.

Separate admin-key permissions and the standalone Rust server remain explicitly unsupported. This targets `sglang-miles` for the Miles sidecar integration.

## Validation

Includes real unary/streaming gRPC authentication tests, Python launch-argument checks and leader/follower key-forwarding coverage. End-to-end GPU integration validation is pending.
