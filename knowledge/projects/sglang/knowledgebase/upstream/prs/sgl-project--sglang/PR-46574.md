# [Fix] bench: account for native streaming tokens independently of visible text

[Upstream PR](https://github.com/sgl-project/sglang/pull/46574) · state: open · merged: False

## Original PR description

## Motivation

The native `/generate` benchmark client only reads `completion_tokens` and records TTFT/ITL when cumulative `text` is nonempty. A server can generate real tokens while returning empty text, for example when detokenization filters special tokens. Such requests retain TTFT=0, have no ITL samples, and can report the requested output limit instead of the actual generated count. TPOT then includes the unmeasured first-token wait.

For example, a request asking for 1024 tokens but returning five filtered special tokens was reported with output_len=1024 and TTFT=0. This change records the five reported tokens and timestamps generation events independently of visible text.

Related: #42000 and the closed, unmerged #36047. This also fixes collection and native token accounting, beyond filtering zero TTFT samples at aggregation time.

## Modifications

- Read native completion counts independently of text, including zero counts and text-free final summaries. Fail a native response missing completion counts instead of fabricating the requested output length.
- Record TTFT and ITL when cumulative completion counts increase in generation events, including empty text and token-ID-only responses. Ignore duplicate/zero-token messages for timing; preserve the last nonempty cumulative text.
- Exclude successful requests with unmeasured TTFT from TTFT/TPOT samples and per-token peak timelines, and issue a warning. Preserve their aggregate counts, throughput, end-to-end latency, and concurrency.
- Add eleven deterministic CPU regression tests covering filtered text, late visible text, speculative multi-token chunks, duplicate chunks, usage summaries, zero output, missing counts, and metric aggregation.

The existing zero-valued aggregate fallback when no latency samples exist is unchanged; an explicit warning identifies positive-output requests with missing measurements. This patch does not reconstruct per-token generation times inside a multi-token chunk or change model generation behavior.
