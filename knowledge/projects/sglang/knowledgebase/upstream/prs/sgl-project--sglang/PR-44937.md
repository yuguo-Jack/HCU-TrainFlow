# [Doc] cookbook: Add DeepSeek V4.1 Flash 1017 variant

[Upstream PR](https://github.com/sgl-project/sglang/pull/44937) · state: closed · merged: True

## Original PR description

## Motivation

Allow users to select DeepSeek-V4.1-Flash-1017 from the existing DeepSeek V4.1 cookbook while keeping the original Flash checkpoint as the default.

## Modifications

- Use the same config-driven variant/quantization/strategy/node matrix as the DeepSeek V4 cookbook.
- Add `flash` and `flash-1017` variants with `variant|quant` model-path mappings and 10 recipe cells per variant. Each 1017 recipe preserves the original launch flags, environment, images, and node count; only the selected checkpoint path changes.
- Mark the 1017 cells unverified pending GPU validation. Existing Flash cells retain their verification status.

The final diff changes only `docs/src/snippets/configs/deepseek-ai/deepseek-v4_1.jsx`. Both shared engines are unchanged.

## Accuracy Tests

Documentation-only change; no GPU accuracy run. Passed cookbook config checks and resolution checks using both unchanged shared engines across all 20 cells. Confirmed each of the 10 variant pairs has identical flags, environment, and node count, and the original checkpoint remains the default.
