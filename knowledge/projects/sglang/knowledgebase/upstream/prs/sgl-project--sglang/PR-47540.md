# [Fix] spec: Seed the DSpark MLA draft weights in the verify-rows test

[Upstream PR](https://github.com/sgl-project/sglang/pull/47540) · state: closed · merged: True

## Original PR description

- `test_dflash_mla.py::test_dspark_commits_verify_rows_through_mla_layer` compares the MLA rows the DSpark write path commits with `project_context_kv` exactly. It built `DSparkDraftModel` without setting its weights, and the linear layers allocate them with `torch.empty`. When that memory held NaN, both sides were NaN and the comparison failed on every element (CI: "Greatest absolute difference: nan").
- The test now seeds and fills the model's weights before comparing, as `test_matches_specforge_reference` in the same file does.

Checked locally: with `torch.empty` patched to return NaN-filled tensors, the old test fails with the same NaN diff and the new one passes. The file passes as a whole.

A/B on CI: `rerun-test.yml` dispatched 10 times on main and 10 times on this PR's head, each running `registered/unit/spec/test_dflash_mla.py` on `ubuntu-latest`. Main failed 1 of 10 with the same nan diff in `test_dspark_commits_verify_rows_through_mla_layer`; this PR passed 10 of 10.
