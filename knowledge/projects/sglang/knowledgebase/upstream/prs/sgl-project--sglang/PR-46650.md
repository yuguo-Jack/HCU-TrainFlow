# [Perf] [AMD] cuda-graph: breakable prefill graphs for prefix extends

[Upstream PR](https://github.com/sgl-project/sglang/pull/46650) · state: open · merged: False

## Original PR description

## Motivation

Prefix-extend batches (cache hits) skip the prefill CUDA graph and run eagerly.

## Modifications

With `SGLANG_ROCM_BCG_PREFIX_EXTEND` (default off), prefix extends run under breakable prefill graphs.

## Accuracy Tests

`test_prefill_cuda_graph_runner.py` and `test_multimodal_piecewise_cuda_graph.py`: 25 pass.

Full K3 stack on MI355X TP8 (DFlash, prod config) vs B300, McNemar:
- GPQA-D 89.4 vs 87.9 (p=0.55)
- AIME25 96.7 vs 93.3 (p=1.0)
- MATH500 92.2 vs 92.2 (p=1.0)
- MMLU-Pro 89.6 vs 90.0 (p=0.77)
- GSM8K 97.2%

## Speed Tests and Profiling

Not measured on its own. It is included in the full-stack K3 MI355X numbers in the other K3 PRs.
