# [Fix] cache: Support DeepSeek-V4.1 external linker pools

[Upstream PR](https://github.com/sgl-project/sglang/pull/44623) · state: open · merged: False

## Original PR description

## Motivation

DeepSeek-V4.1 external-linker startup dereferences an absent C4 pool. Its shared C1/C2 KV and indexer pools need explicit offload/restore mappings.

## Modifications

- Share C1/C2 buffer descriptions with HiCache and guard absent C4/C128 pools.
- Preserve target/draft SWA storage and support packed draft mappings in UMBP.
- Add regression tests for shared sources, indexer page views, and packed ranges.

## Validation

- 123 tests and 33 subtests pass; pre-commit checks pass.
- Two GB300 GPUs, DEP2 + DSpark + Mooncake: restore 8,192 tokens per rank after GPU-cache overwrite; 774 restored objects have zero byte-hash mismatches. Both ranks recover the original secret phrase.
- AgentX functional smoke with native acceptance: 4 conversation lanes, 60 s, 8 warmup requests and 6 timed requests, zero errors. No performance comparison.

Numerical accuracy remains open: ordinary GPU-cache hits in the same linker-enabled server also vary, and the KL probe hits an input-logprob length assertion. UMBP has unit coverage only.

Live tests used `b409c39401` plus this patch before rebasing; the five changed files are identical after rebase. Diagnostic hooks are excluded.
