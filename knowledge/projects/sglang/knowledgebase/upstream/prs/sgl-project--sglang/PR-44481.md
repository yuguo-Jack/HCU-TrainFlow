# [Test] diffusion: Avoid the tile-sharding rendezvous port race

[Upstream PR](https://github.com/sgl-project/sglang/pull/44481) · state: open · merged: False

## Original PR description

## Motivation

Fix the tile-sharding test failure tracked as T7 in #42752. `_free_port()` closes its socket before the three workers initialize their TCP rendezvous, leaving a window for another process to take the port.

## Modifications

Use a fresh `FileStore` in a temporary directory shared by the spawned workers. Keep the directory alive until `mp.spawn(..., join=True)` finishes. The Gloo collectives and decode assertions are unchanged.

## Accuracy Tests

CPU-only Linux, PyTorch 2.11.0+cu130 with CUDA hidden; real three-rank Gloo:
- Baseline and candidate: the same eight selected methods passed.
- Hold the selected legacy port open between selection and worker startup: baseline fails with `EADDRINUSE`; candidate passes without using that rendezvous port.

These checks used commit-bound exports of the relevant production functions/classes and unchanged test methods, with an import adapter to avoid installing the full SGLang/Diffusers stack. They do not qualify full-package imports or official CI. Syntax and `git diff --check` pass; full pre-commit was not run. No GPU/model run. AI-assisted change and validation.
