# [Fix] constrained: Share one compile among concurrent requests for a grammar key

[Upstream PR](https://github.com/sgl-project/sglang/pull/47223) · state: open · merged: False

## Original PR description

## Motivation

if you have multiple requests arrive with the same toolset, they will all independently compile tool grammars which wastes CPU time and has an impact on TTFT.

> `get_cached_or_future_value` only checks the cache of finished grammars, so a request that arrives while its grammar is still compiling starts another compile. A burst of N requests with a new schema compiles it N times.
> 
> That is expensive where nothing below SGLang caches compiles: `--reasoning-parser inkling` (json, regex and ebnf go through `_framing_compiler`, which has xgrammar's cache disabled) and `--grammar-backend outlines`. Plain xgrammar already shares an in-flight compile in its own cache, but each duplicate still holds an executor thread, so a burst larger than the executor stalls compiles of every other grammar.

## Modifications

- `BaseGrammarBackend` keeps each key's in-flight compile; a miss on that key waits on it instead of compiling again.
- Each request gets its own copy of the compiled grammar, initialized with its own reasoning flag, as on a cache hit.
- After an abort and at the end of each poll, the backend cancels and forgets the compiles no queued request waits on.
- A timeout caches its key as failed only if no other ready or queued request uses that compile, so one request's timeout does not reject later requests for the key.
- Both of these read only the queue and the synced ready/failed indexes, so every rank makes the same decision.
- Replaces `test_cache_miss_duplicate_key_submits_separate_futures`, which asserted the duplicate compiles.

## Accuracy Tests

Not affected: compiled grammars and token masks are unchanged.

## Speed Tests and Profiling

CPU, 8 vCPUs (12 executor threads), Qwen3-0.6B tokenizer, one new JSON schema; script below. Burst rows are ranges over two runs.

| Backend | Concurrent requests | Compiles | Wall time | CPU time |
|---|---:|---|---|---|
| xgrammar with Inkling's answer frame* | 8 | 8 → 1 | 19.2–19.5 s → 4.7–4.9 s | 130 s → 26–27 s |
| outlines | 4 | 4 → 1 | 16.0–16.9 s → 6.5–6.7 s | 28.4–28.6 s → 7.5–7.7 s |
| llguidance | 16 | 16 → 1 | under 0.1 s either way | |

After the change a burst takes about as long as one request (4.3 s with the Inkling frame, 6.6 s with outlines). With plain xgrammar, a request for a second schema queued behind 24 requests for the first was ready after 1.6 s before the change and 0.01 s after.

\* No Inkling tokenizer was available, so this uses Qwen3-0.6B's vocabulary padded to Inkling's special-token ids.

```python
"""Drive GrammarManager with N concurrent requests for one grammar key on CPU.

Run with PYTHONPATH pointing at the sglang `python/` tree under test. Reports how
many times the backend's dispatch ran, process CPU seconds, and wall seconds until
every request left the grammar queue. With --other, one request for an unrelated
schema is enqueued after the burst; the time until it is ready is reported.

Usage:
  python repro_concurrent_compiles.py --backend {xgrammar,xgrammar-framed,llguidance,outlines} \
      --n 16 [--tools 20] [--plain] [--other]
"""

import argparse
import json
import os
import resource
import time
from types import SimpleNamespace
from unittest.mock import MagicMock

from transformers import AutoTokenizer

from sglang.srt.constrained.grammar_manager import GrammarManager
from sglang.srt.runtime_context import SpawnRanks, get_context, publish, reset_context
from sglang.srt.server_args import ServerArgs

TOKENIZER = "Qwen/Qwen3-0.6B"


def big_schema(n_tools: int, plain: bool = False) -> str:
    """A tool-call-shaped schema: anyOf over n_tools objects with typed arguments.

    `plain` drops the keywords outlines rejects (bounds, formats, patterns).
    """
    if plain:
        return json.dumps(
            {
                "anyOf": [
                    {
                        "type": "object",
                        "properties": {
                            "name": {"const": f"tool_{t}"},
                            "arguments": {
                                "type": "object",
                                "properties": {
                                    "query": {"type": "string"},
                                    "limit": {"type": "integer"},
                                    "mode": {"enum": ["fast", "exact", f"mode_{t}"]},
                                    "flag": {"type": "boolean"},
                                },
                                "required": ["query", "limit", "mode", "flag"],
                            },
                        },
                        "required": ["name", "arguments"],
                    }
                    for t in range(n_tools)
                ]
            }
        )
    tools = []
    for t in range(n_tools):
        tools.append(
            {
                "type": "object",
                "properties": {
                    "name": {"const": f"tool_{t}"},
                    "arguments": {
                        "type": "object",
                        "properties": {
                            "query": {"type": "string", "maxLength": 200},
                            "limit": {"type": "integer", "minimum": 1, "maximum": 50},
                            "mode": {"enum": ["fast", "exact", f"mode_{t}"]},
                            "tags": {
                                "type": "array",
                                "items": {"type": "string", "pattern": "^[a-z]{1,12}$"},
                                "maxItems": 5,
                            },
                            "when": {"type": "string", "format": "date-time"},
                            "nested": {
                                "type": "object",
                                "properties": {
                                    "a": {"type": "number"},
                                    "b": {"type": "boolean"},
                                },
                                "required": ["a"],
                            },
                        },
                        "required": ["query", "mode"],
                    },
                },
                "required": ["name", "arguments"],
            }
        )
    return json.dumps({"anyOf": tools})


def make_backend(name: str, tokenizer):
    eos = [tokenizer.eos_token_id]
    if name == "xgrammar":
        from sglang.srt.constrained.xgrammar_backend import XGrammarGrammarBackend

        return XGrammarGrammarBackend(
            tokenizer, vocab_size=len(tokenizer), model_eos_token_ids=eos
        )
    if name == "xgrammar-framed":
        from xgrammar import TokenizerInfo, VocabType

        from sglang.srt.constrained.reasoner_grammar_backend import (
            ReasonerGrammarBackend,
        )
        from sglang.srt.constrained.xgrammar_backend import XGrammarGrammarBackend
        from sglang.srt.parser.inkling_tokenizer import (
            CONTENT_MODEL_END_SAMPLING,
            INKLING_SPECIAL_TOKEN_IDS,
        )
        from sglang.srt.parser.reasoning_parser import InklingDetector

        # Qwen3's vocabulary padded out to Inkling's special-token ids, so the
        # Inkling answer frame compiles against a full-size vocabulary.
        base = TokenizerInfo.from_huggingface(tokenizer).decoded_vocab
        size = max(INKLING_SPECIAL_TOKEN_IDS.values()) + 1
        vocab = list(base) + [b""] * (size - len(base))
        for token, token_id in INKLING_SPECIAL_TOKEN_IDS.items():
            vocab[token_id] = token.encode()
        info = TokenizerInfo(
            vocab,
            VocabType.RAW,
            vocab_size=size,
            stop_token_ids=[INKLING_SPECIAL_TOKEN_IDS[CONTENT_MODEL_END_SAMPLING]],
        )
        inkling_tok = SimpleNamespace(
            init_xgrammar=lambda: (info, None), decode=lambda ids, **_: ""
        )
        return ReasonerGrammarBackend(
            XGrammarGrammarBackend(inkling_tok, size),
            SimpleNamespace(detector=InklingDetector()),
            inkling_tok,
        )
    if name == "llguidance":
        from sglang.srt.constrained.llguidance_backend import GuidanceBackend

        return GuidanceBackend(
            tokenizer=tokenizer, n_vocab=len(tokenizer), eos_token_ids=eos
        )
    if name == "outlines":
        from sglang.srt.constrained.outlines_backend import OutlinesGrammarBackend

        return OutlinesGrammarBackend(tokenizer, whitespace_pattern=None)
    raise ValueError(name)


def leaf(backend):
    return getattr(backend, "grammar_backend", backend)


def make_manager(backend) -> GrammarManager:
    reset_context()
    server_args = ServerArgs(model_path="dummy", grammar_backend="none")
    publish(server_args, role="scheduler", ranks=SpawnRanks(world_rank=0))
    scheduler = MagicMock()
    scheduler.server_args = server_args
    scheduler.model_config.request_selectable_think_end_id_sequences = None
    scheduler.dp_tp_group.world_size = 1
    scheduler.dp_tp_group.first_rank = 0
    scheduler.dp_tp_group.is_first_rank = True
    scheduler.pp_group = None
    with get_context().override_server_args(skip_tokenizer_init=True):
        mgr = GrammarManager(scheduler)
    mgr.grammar_backend = backend
    mgr.SGLANG_GRAMMAR_MAX_POLL_ITERATIONS = 10**9
    return mgr


def make_req(schema: str, rid: str):
    req = MagicMock()
    req.rid = rid
    req.sampling_params.json_schema = schema
    req.sampling_params.regex = None
    req.sampling_params.ebnf = None
    req.sampling_params.ebnf_full_assistant = False
    req.sampling_params.structural_tag = None
    req.sampling_params.custom_params = None
    req.origin_input_ids = []
    req.require_reasoning = False
    req.grammar = None
    req.grammar_key = None
    req.grammar_wait_ct = 0
    req.finished.return_value = False
    return req


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--backend", required=True)
    parser.add_argument("--n", type=int, default=16)
    parser.add_argument("--tools", type=int, default=20)
    parser.add_argument("--other", action="store_true")
    parser.add_argument("--plain", action="store_true")
    args = parser.parse_args()

    tokenizer = AutoTokenizer.from_pretrained(TOKENIZER)
    backend = make_backend(args.backend, tokenizer)
    mgr = make_manager(backend)

    dispatches = []
    inner = leaf(backend)
    original = inner.dispatch_json

    def counting_dispatch_json(key_string):
        dispatches.append(key_string)
        return original(key_string)

    inner.dispatch_json = counting_dispatch_json

    schema = big_schema(args.tools, args.plain)
    # Shares no subschema with the burst's, so xgrammar's rule cache cannot help it.
    other_schema = json.dumps(
        {
            "type": "object",
            "properties": {f"field_{i}": {"type": "integer"} for i in range(8)},
            "required": [f"field_{i}" for i in range(8)],
        }
    )
    reqs = [make_req(schema, f"burst-{i}") for i in range(args.n)]
    other = make_req(other_schema, "other") if args.other else None

    cpu0, wall0 = time.process_time(), time.perf_counter()
    for req in reqs:
        mgr.process_req_with_grammar(req)
    if other is not None:
        mgr.process_req_with_grammar(other)
    other_ready = None
    while mgr.grammar_queue:
        for req in mgr.get_ready_grammar_requests():
            if req is other:
                other_ready = time.perf_counter() - wall0
    wall = time.perf_counter() - wall0
    cpu = time.process_time() - cpu0

    failed = [r.rid for r in reqs if r.set_finish_with_abort.called]
    distinct = len({id(r.grammar) for r in reqs})
    out = {
        "backend": args.backend,
        "n": args.n,
        "schema_chars": len(schema),
        "executor_workers": backend.executor._max_workers,
        "burst_dispatches": sum(1 for s in dispatches if s == schema),
        "cpu_s": round(cpu, 2),
        "wall_s": round(wall, 2),
        "distinct_grammar_objects": distinct,
        "failed": failed,
        "max_rss_mb": resource.getrusage(resource.RUSAGE_SELF).ru_maxrss // 1024,
    }
    if other is not None:
        out["other_key_ready_s"] = round(other_ready, 2)
    print(json.dumps(out), flush=True)
    os._exit(0)


if __name__ == "__main__":
    main()
```
