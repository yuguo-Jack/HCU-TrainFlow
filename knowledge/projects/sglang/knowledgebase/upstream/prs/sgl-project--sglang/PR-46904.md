# [Doc] server-args: Document four PD disaggregation flags

[Upstream PR](https://github.com/sgl-project/sglang/pull/46904) · state: open · merged: False

## Original PR description

## Motivation

`server_arguments_undocumented.txt` is the ratchet list of live `ServerArgs` flags that have no row in `server_arguments.mdx`. Its header says it "may only shrink". Four PD-disaggregation flags on it are user-facing knobs that people running PD deployments look for, but none of them is in the docs today:

- `--disaggregation-enable-kv-checksum`
- `--disaggregation-decode-retraction-backup`
- `--disaggregation-decode-extra-slots`
- `--disaggregation-decode-host-receive-threshold`

## Modifications

- I added a row for each flag next to the related flags already in the PD section (transfer backend, offload-kvcache, num-reserved-decode-tokens, polling interval).
- Descriptions, defaults and choices come straight from each field's `Arg(help=...)`, default value and `choices` in `python/sglang/srt/arg_groups/fields/disagg.py`, so the docs match the CLI. I didn't change any wording.
- I removed the four flags from `server_arguments_undocumented.txt`.

Docs only. No code changes.

## Duplicate check

I searched open PRs for `server_arguments_undocumented`, each flag name, and "backfill server arguments". None adds rows for these flags.
