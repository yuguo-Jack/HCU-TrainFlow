# [Fix] docker: update NVIDIA megakernel pin to tested commit

[Upstream PR](https://github.com/sgl-project/sglang/pull/47145) · state: closed · merged: True

## Original PR description

[codex/claude generated]

## Motivation

The CUDA Dockerfiles still pin `sgl-nvidia-mega` to `6fd7ac30371a45ef246bb9db2e3559c398156feb`, predating the compatibility fixes for current SGLang's Engram host tables and `MoeDeferredFinalize`, and the FlashMLA schedule-ahead correction.

## Modifications

Update `SGL_NVIDIA_MEGA_COMMIT` in both `docker/Dockerfile` and `docker/Dockerfile.cu134` to `54b428921749fef89fcbd043000f839ac9cc4638`. This includes sgl-project/sgl-nvidia-mega#27, sgl-project/sgl-nvidia-mega#28, and sgl-project/sgl-nvidia-mega#29, along with the intervening #20 and #26 changes. Only the two commit pins change.

## Accuracy Tests

`git diff --check` passes. No native-acceptance accuracy evaluation or Docker image build was run for this pin update.

## Speed Tests and Profiling

The exact plugin commit was tested with SGLang `59af99a873f39c3b281df0f9c609b3a0d3270726` on four GB300 GPUs, DeepSeek-V4.1 Flash, TP4, concurrency 1, DSpark block size 5. The server used `SGLANG_ENABLE_NV_MEGA_RUNTIME_OPTIMIZATION=1` and `--enable-nvidia-megakernel`, with the required TP-sync/Engram settings and AgentX golden acceptance of 3.51. Target and draft megakernels were active on all four ranks.

The 900-second AgentX screen completed 148 measured requests with zero errors or cancellations; client exit status and result validation passed. Total throughput was 6,904 tokens/s/GPU and p90 decode interactivity was 945.96 tokens/s/user. This is a single-arm performance screen, not an accuracy result or an A/B speedup comparison. CUDA 13.4 was not separately tested.
