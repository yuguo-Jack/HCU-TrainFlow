# [CI] npu: Remove internal cache-service references from NPU workflows

[Upstream PR](https://github.com/sgl-project/sglang/pull/46728) · state: closed · merged: True

## Original PR description

## Motivation

Our self-hosted Ascend CI runners access public package sources through a cluster-level squid caching proxy. The old internal `nginx-pypi-cache` mirror (`cache-service.nginx-pypi-cache.svc.cluster.local`) is being retired, so this PR removes every reference to it from the NPU CI workflows. pip/uv/apt/rustup then use the official public sources through the proxy.

## Changes (4 workflow files, -65 / +9)

- **`pr-test-npu.yml`** (2 job variants), **`diffusion-ci-gt-gen-npu.yml`** (2 job variants), **`_npu-single-node-test-stage.yml`**, **`_npu-pr-test-stage.yml`**: drop `TORCH_CACHE_URL` / `PYPI_CACHE_URL` / `UV_INDEX_URL` / `RUSTUP_CACHE_URL` env overrides, and remove the APT source rewriting (`cache-service :8081`) plus the `pip config set global.index-url / trusted-host` lines from the "Install dependencies" step
- **`pr-test-npu.yml`** coverage steps: the `regex` and `coverage==7.8.*` installs now use the tsinghua public mirror directly instead of trying the internal index first
- **`_npu-single-node-test-stage.yml` / `_npu-pr-test-stage.yml`**: `PIP_INDEXES` keeps only the public PyPI and tsinghua mirror entries; `PIP_TRUSTED_HOST` points at the public mirror

`scripts/ci/npu/npu_ci_install_dependency.sh` and `scripts/ci/utils/install_rustup.sh` are unchanged: with the env overrides gone, their existing public defaults (`https://download.pytorch.org/whl/cpu`, `https://pypi.org/simple/`, unset rustup mirror) apply.

## Test plan

- `grep -r "cache-service\|nginx-pypi-cache"` over the repo returns nothing
- All modified workflow files parse as valid YAML
