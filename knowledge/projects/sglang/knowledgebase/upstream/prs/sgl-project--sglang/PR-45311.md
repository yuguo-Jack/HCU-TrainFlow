## Motivation

The cookbook's **Agentic Long-Context Deployment** sections (#42726, #43083, #43799, #43983, #44065, #44228, #44654, #44712, #45039, #45111) mirror SemiAnalysis InferenceX AgentX submissions as raw launch commands, each linked to the run that measured it. The configurations are mirrored from SemiAnalysis submissions. This PR refreshes all six pages:

1. **Five open InferenceX PRs are overlaid** (table below). New in this round: a Qwen3.5 NVFP4 GB300 Dynamo+SGLang refresh and a DeepSeek-V4.1-Flash H200 SGLang update.
2. **The pages sync to InferenceX `main`** (`660b5a8d`). Several lanes that #45111 showed as in progress have merged and are now verified from the dashboard. Muse Spark Open GB300 enables HiCache above c6.
3. **Lanes no longer overlaid leave or revert.** The knob-tuned GLM-5.2 FP8 B300 lane ([InferenceX #3933](https://github.com/SemiAnalysisAI/InferenceX/pull/3933)) leaves the page. ## How the commands are produced

The pipeline is the same as in #45111, with these changes:

- **Agg/disagg siblings.** A key whose dashboard changelog names only its agg/disagg sibling is now pinned to that date only if the date has rows for its own lane. Before, GLM-5.2 B200 disagg would have dropped off the page after [InferenceX #4286](https://github.com/SemiAnalysisAI/InferenceX/pull/4286) re-swept only the aggregated lane.
- **Generated config files.** srt-slurm writes the Dynamo frontend's `--router-policy-config` file from the recipe's `worker_selection`. The renderer now captures it, and the page shows it as `router_policy_config.yaml`, like `nginx.conf`.
- **Rules.**
  - Kept as submitted: worker flag `--gc-threshold`; Dynamo frontend flags `--router-session-affinity-mode`, `--router-decode-active-request-weight` and `--router-policy-config` (file shown inline); env `SGLANG_GDN_CHUNK_H_BV`, `SGLANG_GDN_CHUNK_H_NUM_STAGES`, `SGLANG_EAGER_INPUT_NO_COPY` and `FLASHINFER_ROUTING_FORCE_BLOCK_PER_TOKEN`.
  - Removed: `--gc-warning-threshold-secs` (only logs a warning) and `HF_HUB_OFFLINE` (SA pre-stages the checkpoints; readers download them).

Each lane is still rendered at the exact commit of the run that produced its data, or at the PR head while in progress.
- **Removed (SA-only settings):** the benchmark harness, cluster paths and caches, telemetry, and InferenceX's synthetic speculative acceptance (disclosed per deployment).
- **Replaced with placeholders:** IPs, ports and NICs.
- **Derived variants:** router and KV-offload variants that were not run are derived and labeled "Derived — not run".

The data files are generated, so there is no hand-written code to review here.
