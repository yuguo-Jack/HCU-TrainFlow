# [Doc] install: Explain Python 3.13 Outlines build requirement

[Upstream PR](https://github.com/sgl-project/sglang/pull/47256) · state: open · merged: False

## Original PR description

Related to #47242.

## Motivation

SGLang 0.5.22 accepts Python 3.13, but its `outlines==0.1.11` dependency pins `outlines_core==0.1.26`, which has no CPython 3.13 wheel. Installation therefore falls back to a Rust source build and can fail with `can't find Rust compiler`. The installation page currently says Python 3.11 or higher without explaining this prerequisite.

## Modifications

- Surface the Python 3.13 source-build requirement before the pip/uv installation commands.
- Explain the dependency pin chain and the missing-wheel error in troubleshooting.
- Show a separate Python 3.12 environment as a way to avoid this dependency's source build, and link the official Rust installation guide for users who need Python 3.13.

This is a documentation follow-up. It does not upgrade Outlines, establish full Python 3.13 runtime compatibility, or resolve the dependency-packaging issue.
