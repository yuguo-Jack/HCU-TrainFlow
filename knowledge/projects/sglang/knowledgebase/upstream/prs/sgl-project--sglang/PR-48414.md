# [Feat] model: Add Kimi-K3.1 support

[Upstream PR](https://github.com/sgl-project/sglang/pull/48414) · state: open · merged: False

## Original PR description

Adds Kimi-K3.1 (`KimiK31ForConditionalGeneration`) with its Day-0 serving stack: DSA with decode context parallelism, PD disaggregation, DFlash speculative decoding, pipeline-parallel prefill, HiSparse, and the model's fused kernels.

The basic model support is split out in #48415 for review; this PR carries everything on top of it.

Model: https://huggingface.co/moonshotai/Kimi-K3.1-Pro
