# [Refactor] sgl-router: Move experimental/sgl-router to top-level sgl-router

[Upstream PR](https://github.com/sgl-project/sglang/pull/45414) · state: closed · merged: True

## Original PR description

Move sgl-router out of `experimental/` to a top-level `sgl-router/` directory.

## Modifications

1. **Pure rename**: `git mv experimental/sgl-router sgl-router`. All 290 files are 100% renames, so history and blame carry over (`git diff --name-status -M100% HEAD~3 HEAD~2` shows only `R100` entries).
2. **Path fixups**:
   - Relative paths that depended on directory depth:
     - `sgl-router/Cargo.toml`: `../../rust/sglang-{processor,api-types}` → `../rust/...`
     - `tests/e2e/k8s_integration/setup.sh`: `REPO_ROOT` now goes up one level fewer
     - The `PYTHONPATH` hint in `generate_array_content_fixture.py`
   - Repo-root path strings `experimental/sgl-router` → `sgl-router`:
     - `pr-test-sgl-router.yml`: the paths filter, rust-cache workspaces, `working-directory`, and the k8s build/pytest paths
     - `docker/sgl-router.Dockerfile` and `tests/e2e/k8s_integration/Dockerfile.router`
     - `.pre-commit-config.yaml`: the `rustfmt-sgl-router` hook
     - `.gitignore`: the `Cargo.lock` un-ignore. This matters for git only; Docker patterns are root-anchored, so the bare `Cargo.lock` line never excluded the router's lockfile from the Docker context.
     - READMEs, docstrings, and comments
   - Renamed `nightly-experimental-sgl-router-docker.yml` → `nightly-sgl-router-docker.yml` and its display name. Nothing references the filename, and the schedule/dispatch triggers move with it.

**Unchanged on purpose:** the published image tag `lmsysorg/sglang-staging:experimental-router-dev` and the dashboard `uid`, so existing pullers and imports keep working.

## Verification

- `cargo metadata --locked` resolves the new path deps; `cargo fmt --all -- --check` passes
- `cargo test --locked --release --workspace -- --skip parity_matrix` (the CI tier-2 command): 1596 passed, 0 failed
- `pre-commit run` on the changed files passes, including the renamed `rustfmt sgl-router` hook
- `setup.sh` resolves `REPO_ROOT`/`SGL_ROUTER_DIR` to the repo root and `sgl-router/`
- `router_binary_path()` resolves correctly with no env, with `CARGO_TARGET_DIR`, and with `SGL_ROUTER_BINARY`; an explicit `Gateway(binary=...)` still wins; `pytest --collect-only` in `tests/e2e` collects all 60 tests
- `git grep experimental/sgl-router` is empty
- `docker/sgl-router.Dockerfile`: all COPY sources exist. Reproducing its final builder-stage layout (only the files it copies, at `/work/sgl-router` + `/work/rust`) builds with `cargo build --locked --release --bin sgl-router`, and the binary runs
- **Not covered:** an actual `docker build` (no Docker here). PR CI doesn't build this image either, because `sgl-router-docker-build-test` is a placeholder; the nightly is the first real build. The k8s integration job does build `Dockerfile.router` once `run-ci` is set.
