# [Test] [AMD] moe: Avoid Python 3.11-only enterContext in test_fp8_moe_triton_runner_with_aiter

[Upstream PR](https://github.com/sgl-project/sglang/pull/45852) · state: closed · merged: False

## Original PR description

## What

`test/registered/amd/test_fp8_moe_triton_runner_with_aiter.py` enters its two runtime overrides in `setUp` with `self.enterContext(...)`. Replace both calls with the 3.10-safe `enter_scope` helper from `sglang.test.test_utils`, the same helper other tests already use.

## Why

`unittest.TestCase.enterContext` was added in Python 3.11. The ROCm 7.2 CI images run Python 3.10, so `setUp` raises `AttributeError: 'TestFp8MoeTritonRunnerWithAiter' object has no attribute 'enterContext'` before the test body runs. The test only runs on gfx94x with AITER, so the gfx942 rocm720 shard of `stage-b-test-1-gpu-small-amd` hits this. It started when the test was added in #44993.

Failing job (rocm720, shard 3): https://github.com/sgl-project/sglang/actions/runs/39645674470/job/119380620758

## Test plan

- `python -m py_compile` on the changed file passes, and `black --check` is clean.
- No GPU run locally. The test needs a gfx94x GPU with AITER.
- Passed on MI300 (rocm720) in a dispatched `stage-b-test-1-gpu-small-amd` run: https://github.com/sgl-project/sglang/actions/runs/39824174845/job/119983188771 (`test_fp8_moe_triton_runner_with_aiter.py` ran 1 test, OK). That run used this diff cherry-picked onto main `913e91ed`, because this branch's base predates #45845 and every shard there failed at test collection.
