# [MoE] Add opt-in NCCL EP LL CUDA Graph lifecycle

[Upstream PR](https://github.com/sgl-project/sglang/pull/38683) · state: closed · merged: False

## Original PR description

## Motivation

NCCL EP full decode CUDA Graphs need communication handles, buffers and routing descriptors to outlive captured executables. This change adds opt-in serialized Graph execution on the persistent-dispatcher implementation in #41353.

## Dependency and independent review

Depends on #41353 at `e1f7de17a521dd607e1bec62081f26121cf5c6cc`. The stack is #41353 → #38683 → #38886 → #38887 → #38888 → #39546. This PR publishes the prepared migration, remains Draft and still targets `main`; Files changed therefore also contains unmerged prerequisites.

[Review only this PR's increment](https://github.com/Laceprndpm/sglang/compare/e1f7de17a521dd607e1bec62081f26121cf5c6cc...045912705006c73f5fb88bfb392064e18df80001): **48 files, +5481/−241**. Current head: `045912705006c73f5fb88bfb392064e18df80001`.

## Modifications

- Add an independent Graph resource owner and retain bucket descriptors. Borrow and restore persistent eager handles around Graph work; release executables before handles and groups.
- Initialize and close dispatchers beneath model wrappers through the foundation fix. Keep rank-major eager initialization available and fix the stale TP-group accessor in the dispatcher factory.
- Integrate the migrated runner/pool lifecycle and argument validation in `arg_groups`. Graph execution remains opt-in and expert-major; prefill stays eager.
- This prerequisite does not add SBO/TBO or rank-major Graph execution.

## Validation status

No tests, benchmarks or model-quality runs were rerun during this publication. Existing feature regression cases are retained. Historical results belong to their recorded snapshots; they are not presented as fresh passes of this migrated head. Upstream CI status is separate.

Offline model preparation, paid-GPU queues, migration execution/report tooling and archived benchmark-result files are not included in this migrated feature chain. No new performance claim is made by this prerequisite PR.

**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Force NCCL EP to span the TP group**

When `--tp` is greater than one and `--ep` is omitted, this dispatcher communicates over the entire TP group, but `_A2A_EP_SPANNING_BACKENDS` in `arg_groups/overrides.py` does not include `nccl_ep`, so the MoE weights and `num_local_experts` remain configured for the default EP size of one. Nonzero ranks can therefore compute received tokens using the wrong local expert slots (or encounter incompatible buffer layouts). Include `nccl_ep` in the EP-size adjustment; this also ensures a later DeepEP fallback receives the required topology.
