# [Test] diffusion: align warmup and LoRA fixtures with runtime contracts

[Upstream PR](https://github.com/sgl-project/sglang/pull/47835) · state: closed · merged: True

## Original PR description

## Motivation

Fix two main-side diffusion unit failures exposed by [this CI job](https://github.com/sgl-project/sglang/actions/runs/41377478466/job/125060926429). They are unrelated to #47120's hash changes.

- #47474 added an expectation that an unservable two-stage warmup size remains unchanged, conflicting with the aligned fallback from #47582.
- #46255 added a LoRA reload test returning the nonexistent path `/adapter`; the file fingerprinting added by #45834 calls `os.stat` on that path.

Both introducing PRs passed CI on older merge snapshots that did not include the respective runtime changes.

## Modifications

- Expect the valid `768x448` fallback for `1000x600`, and verify two-stage warmup sizes through the real `LTX2HalveResolutionStage`.
- Keep one real temporary safetensors file through all alpha changes. Exercise actual file stat/read and assert that the alpha override reloads exactly once and restores the expected fused weights.

Only two test files change; runtime behavior is unchanged.

## Validation

On an isolated NVIDIA B200 development environment (Python 3.12, PyTorch 2.14.1+cu130):

- Main `ea2fda7fd23d`: both original failures reproduced at the expected assertion/file-stat boundaries.
- Candidate `d8b8b75f32aa`: **113 passed** across `test_cfg_parallel_warmup.py`, `test_fused_lora_compose.py`, `test_lora_merge_cache.py`, and `test_lora_pipeline.py`.
- Changed-file pre-commit passed. No model-serving or performance claim; this PR changes tests only.

- Exact-head [H100 targeted CI](https://github.com/sgl-project/sglang/actions/runs/41388112060) passed all four files (**113 tests**); [lint](https://github.com/sgl-project/sglang/actions/runs/41388047076) also passed. This is targeted coverage, not a full Base CI run.
