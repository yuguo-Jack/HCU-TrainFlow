# [Feat] kimi-k3: Run native MXFP4 MoE with Humming on Hopper

[Upstream PR](https://github.com/sgl-project/sglang/pull/33884) · state: open · merged: False

## Original PR description

## Summary

Run Kimi-K3's native MXFP4 checkpoint through the Humming MoE backend on
Hopper. Replaces #32778 (auto-closed when its `kimi-k3` base branch was
deleted after merging to main).

- `Mxfp4MoEMethod` gains a `use_humming` branch: with
  `--moe-runner-backend humming` the native MXFP4 checkpoint is bridged to
  Humming weight schemas — no `--quantization` flag needed.
- Expert weight-name resolution replaces the unconditional
  `weight_packed → weight` rename; unresolvable `.weight_packed` /
  `.weight_scale` tensors now raise instead of being silently skipped.
- SiTU activation support in the Humming runner, including a fused masked
  SiTU+quant fast path (`situ_and_mul_masked_post_quant`) for grouped-masked
  execution.
- Registered tests: fused SiTU/silu vs reference, FP8-dispatch group-scale
  preservation, SiTU config validation, dual expert-schema resolution.

Stacked on #31429 and #32033 (their commits appear in this diff until they
merge; the K3-specific changes are the top two commits).

## How to run

Server (2 nodes × 8 H20, tp16/ep16 + DSPARK; run on each node with
`--node-rank 0/1`):

```bash
python3 -m sglang.launch_server \
  --model-path Kimi-K3 --trust-remote-code \
  --tp-size 16 --ep-size 16 \
  --nnodes 2 --node-rank <0|1> --dist-init-addr <rank0-ip>:23456 \
  --moe-runner-backend humming \
  --kv-cache-dtype fp8_e4m3 --decode-attention-backend flashmla \
  --mamba-full-memory-ratio 0.074 --mem-fraction-static 0.85 \
  --speculative-algorithm DSPARK \
  --speculative-draft-model-path Kimi-K3-DSpark \
  --speculative-dspark-block-size 7 --enable-linear-replayssm-spec
```

Arms: baseline `--moe-runner-backend marlin`; humming W4A16 as above; humming
W4A8 additionally sets
`SGLANG_HUMMING_INPUT_QUANT_CONFIG='{"dtype": "float8e4m3"}'`.

Accuracy client:

```bash
python3 -m sglang.test.run_eval --eval-name gsm8k --api chat \
  --num-examples 1319 --num-shots 8 --num-threads 32 \
  --temperature 0 --max-tokens 1024 \
  --chat-template-kwargs '{"enable_thinking": false}'
```
