# [Feat] muse-spark: Infer hardware launch defaults and simplify cookbook recipes

[Upstream PR](https://github.com/sgl-project/sglang/pull/45683) · state: closed · merged: True

## Original PR description

## Motivation

Muse Spark deployment recipes repeat settings that can be inferred from the checkpoint and GPU. Resolve those defaults during startup so the B300/NVFP4 low-latency command can omit seven flags while keeping its intended runtime settings. Explicit user settings take precedence.


Blocked by next version release

## Modifications

- Detect Muse Spark NVFP4 quantization through the existing model configuration loader, including both embedded `quantization_config` and standalone `hf_quant_config.json`, and default to `modelopt_fp4`.
- Default NVFP4 MoE to `flashinfer_trtllm` on data-center Blackwell (SM100/SM103) and `marlin` on Hopper. Default Muse Spark static memory fractions to `0.8` on Blackwell and `0.85` on Hopper.
- Automatically enable MegaMoE for NVFP4 on data-center Blackwell when LayerNorm-SP is enabled, EP equals TP and exceeds one, and the worker is not a PD decode worker. Add `--no-enable-megamoe-for-layernorm-sp` as an explicit opt-out.
- Detect `DFlash2DraftModel` from draft metadata and default to FA4 on the supported NVIDIA platforms and eight draft tokens. Preserve explicit draft settings, including the DFlash block-size alias.
- Omit `--mm-feature-transport cpu` where CPU is already the runtime default. Keep the explicit override for the two-node GB300/BF16 recipe, where MNNVL may auto-select CUDA VMM.
- Resolve these settings before generic memory and backend defaults. Shorten NVIDIA Deployment recipes, preserve explicit BF16 memory budgets and AMD/CPU recipes, and make Playground's MegaMoE Off selection emit the new opt-out flag.

## Accuracy Tests

Parameter-resolution tests cover hardware selection, all MegaMoE enablement conditions, explicit overrides, DFlash2 metadata, CLI enable/disable behavior, and the full resolution pipeline with local target/draft configs in both ModelOpt metadata formats.

- CPU regression suite: **436 passed, 364 subtests passed, 1 skipped** across `test_server_args.py`, `test_model_overrides.py`, `test_server_args_cli_metadata.py`, and `test_server_args_namespaces.py`.
- Three tests were excluded because the local environment lacks optional `mlx` and `xgrammar` dependencies: `test_start_server_call_site_matches_native_signature`, `test_a_plugin_registered_parser_is_accepted`, and `test_the_names_that_lost_their_eager_import_are_still_attributes`.
- Checked all **24** Deployment combinations using the shared command builder, plus Playground MegaMoE opt-out/opt-in behavior.
- `pre-commit`, `git diff --check`, `mint validate`, and `mint broken-links` passed.

GPU inference accuracy has not been run for this change.

## Speed Tests and Profiling

Not run. This change resolves launch defaults and simplifies the cookbook; it does not modify inference kernels.
