# [Fix] test: Import sgl_kernel in the Arm64 MoE test

[Upstream PR](https://github.com/sgl-project/sglang/pull/48223) · state: closed · merged: True

## Original PR description

## Motivation

Fixes #48221.

`PR Test (Arm64) / build-test` fails on main since #47731:

```
AttributeError: '_OpNamespace' 'sgl_kernel' object has no attribute 'fused_experts_cpu'
```

`test_moe.py` uses `torch.ops.sgl_kernel` without importing `sgl_kernel`, so it depended on the `sglang` import chain loading the op library. That chain no longer does.

## Modifications

Add `import sgl_kernel  # noqa: F401` to `test/registered/cpu/arm64/test_moe.py`, same as the other CPU tests.
