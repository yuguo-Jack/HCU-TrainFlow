# [Fix] io-struct: reject empty embedding token IDs

[Upstream PR](https://github.com/sgl-project/sglang/pull/44336) · state: open · merged: False

## Original PR description

## Motivation

`EmbeddingReqInput(input_ids=[]).normalize_batch_and_arguments()` indexes `input_ids[0]` and raises `IndexError`. Reject the empty token list with `ValueError` before indexing so it follows the native encode/classify handlers' existing validation-error path.

This is specific to native request normalization; the OpenAI embeddings entry point already has its own empty-input validation.

## Modifications

- Add an empty-list guard to `EmbeddingReqInput` only.
- Cover the empty input and preserve both nonempty single-request and batched token inputs in the existing registered test file.
- Use the documented `maybe_stub_sgl_kernel()` test helper before production imports, allowing this CPU test file to run without the optional kernel extension.
