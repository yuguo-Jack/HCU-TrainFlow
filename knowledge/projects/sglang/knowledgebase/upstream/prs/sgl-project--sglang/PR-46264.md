# [Refactor] diffusion/linear: Share segmented row-parallel weight loading

[Upstream PR](https://github.com/sgl-project/sglang/pull/46264) · state: closed · merged: True

## Original PR description

## Motivation

Flux, Flux2, HunyuanVideo, Hunyuan3D and LongCat duplicate the same loader for a projection whose input is `[attention_shard | MLP_shard]`. A contiguous slice of the checkpoint has the right shape but selects the wrong columns.

## Modifications

- Let `RowParallelLinear(input_sizes=...)` shard each logical input segment independently. Ordinary row-parallel loading and all forward methods stay unchanged.
- Remove two model-local linear subclasses and three parameter-loader monkeypatches.
- Reuse the rank-local safetensors reader for segmented row inputs as well as fused column outputs. Keep selective reads; do not materialize the full checkpoint to handle the layout.
- Document the input layout contract in the new-model guide.

Seven existing production files: +89/-187 (98 fewer lines), no new production files. Tests and docs are in existing files.

## Accuracy Tests

Base: `f7af00d6913`; final production code: `aeb9c63528f` (the subsequent commit only initializes the regression test fixture).

Environment: 2x H200, Python 3.12.15, torch 2.14.1+cu130, transformers 5.19.0, diffusers 0.37.0, safetensors 0.8.0.

- 197 passed, 1 skipped, 32 subtests across linear loading, rank-local/FSDP loading, FP8, GGUF, FP4 capability/backend checks, ConvRot and LoRA tests.
- Independent test processes: checkpoint reader tests 8 passed / 6 subtests; linear loader tests 22 passed.
- Actual projection modules from all five models: BF16 TP1 and NCCL TP2 match the full projection reference. ModelOpt FP8 also checked for Flux, Flux2 and HunyuanVideo. These are layer integrations, not five full-checkpoint generations.
- Real FLUX.2-klein-4B HTTP generation: 512x512, 4 steps, seed 42, quality `exact`, TP1 and TP2, three identical requests per server. Each topology's decoded RGB pixels exactly match its corresponding main baseline on every request. No child processes or GPU allocations remain after shutdown.

The first end-to-end comparison caught the rank-local reader bypassing the segmented loader. This is fixed and covered by a real safetensors-to-final-parameter regression test, including replicated bias and TP2/TP4 layouts.

FP4 packed/block-scale layouts are covered by loader tests; FP4 GPU kernels were not run on H200.

## Speed Tests and Profiling

No runtime speedup claim: no forward code or collectives change. In the short HTTP smoke test, warmed requests were about 106-111 ms on both revisions; this is not a statistical performance benchmark. Startup timings are not compared because the first baseline included checkpoint download.
