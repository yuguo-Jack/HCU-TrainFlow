# [Feat] [NPU] hicache: Support layer-first split host transfers

[Upstream PR](https://github.com/sgl-project/sglang/pull/46604) · state: open · merged: False

## Original PR description

## Motivation

Support NPU HiCache host transfers with the `layer_first_kv_split` layout for MLA and DeepSeek V4.

## Modifications

- Resolve the NPU layer-first HiCache layout to `layer_first_kv_split` and validate incompatible storage-backend configurations.
- Add Memfabric-backed host allocation and AscendC page transfers for DeepSeek V4 paged and state pools. Reserve the combined host capacity before creating those pools.
- Add layer-first split allocation and transfer metadata for MLA K/V and Indexer buffers, including the FP8 packed-K case.
- Recognize `model.language_model` prefixes in ModelSlim checkpoint names.
