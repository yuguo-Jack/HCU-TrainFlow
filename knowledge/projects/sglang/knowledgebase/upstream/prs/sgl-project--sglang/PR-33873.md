# [Perf] [AMD] kimi-k2.5: Fuse MLA value projection with MXFP4 output quantization

[Upstream PR](https://github.com/sgl-project/sglang/pull/33873) · state: open · merged: False

## Original PR description

## Motivation

- In MXFP4 MLA decode on ROCm gfx95 (Kimi-K2.5-MXFP4), the absorbed value projection is a batched A16W4 GEMM that writes a BF16 tensor.
- `o_proj` immediately quantizes that tensor back to MXFP4 with `fused_flatten_mxfp4_quant`: one extra launch and a BF16 HBM round trip per MLA layer per decode step.
- Quantizing in the GEMM epilogue removes both. The kernel is 1.19-1.41x faster than the split pair at 1-64 decode tokens (table below).
- Independent of #32935 (key projection + RoPE + KV-cache write fusion).

## Modifications

- New Triton kernel `batched_gemm_a16wfp4_flatten_mxfp4_quant` in `sglang.kernels.ops.gemm.mla_value_bmm_mxfp4_hip`, registered as `gemm.batched_gemm_a16wfp4_flatten_mxfp4_quant` (Triton, HIP).
  - GEMM body derived from AITER `batched_gemm_a16wfp4`; uses AITER's tuned config lookup.
  - Keeps the split path's BF16 rounding point, so values and scales match it bit for bit.
  - Batch size stays out of the compile key, and out-of-range e8m0 scales are masked as in AITER.
- `rocm_absorb_v_bmm` uses it during AITER decode when `w_vc` and `o_proj` are MXFP4.
- Works in eager mode, `torch.compile` and HIP graph capture.

| New env var | Default | Effect |
|---|---|---|
| `SGLANG_OPT_HIP_FUSE_MLA_VALUE_MXFP4_QUANT` | `true` | `false` keeps the split GEMM + `fused_flatten_mxfp4_quant` |

Fused path conditions (anything else keeps the split path):

| Condition | Required |
|---|---|
| Platform | ROCm gfx95 with AITER |
| Forward mode / backend | decode or idle, `aiter` attention backend |
| Weights | MXFP4 `w_vc` and MXFP4 `o_proj` |
| Shape | `kv_lora_rank` 512, `v_head_dim` 128 (Kimi-K2.5; also DeepSeek-V3/R1 MXFP4) |
| Excluded | DSA, active LoRA on `kv_b_proj`, `SGLANG_EXPERIMENTAL_LORA_OPTI` |
| Kernel config | AITER config with `NUM_KSPLIT == 1` and `BLOCK_SIZE_N` dividing N; otherwise the op runs the split path internally |
