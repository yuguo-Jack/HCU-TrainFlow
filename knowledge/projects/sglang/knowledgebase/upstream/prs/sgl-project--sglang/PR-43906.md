# [Scheduler] Join prefills at launch and drop finished rows at commit

[Upstream PR](https://github.com/sgl-project/sglang/pull/43906) · state: open · merged: False

## Original PR description

Stacks on #43905

- In the normal and overlap loops, a finished prefill joins the running rows when its step launches, and finished rows leave when the step that finishes them commits; the plan-time join and its placeholder are gone.
- At the next plan, requests that left the rows are dropped from the last launched step's request list, so idle checks see the scheduler idle.

Behavior change: between launch and the next plan, the running rows are the requests still decoding (a mixed step's decode rows included, finished rows excluded). Readers of the running rows see that set: `/v1/loads`, DP balancing, the LoRA slot gauge, #running-req, and the in-flight and weight-version sets. With overlap and skip-finishing, the iteration after a commit that finishes the last rows sees the scheduler idle one step earlier.
