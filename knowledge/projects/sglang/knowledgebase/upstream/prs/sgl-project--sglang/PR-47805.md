# [Perf] diffusion: Use O(1) free-list sets in BuddyAllocator and deque in DisaggMetrics

[Upstream PR](https://github.com/sgl-project/sglang/pull/47805) · state: open · merged: False

## Original PR description

## Motivation

In disaggregated multimodal generation (`sglang.multimodal_gen.runtime.disaggregation`), both the memory transport layer (`BuddyAllocator` / `TransferTensorBuffer`) and the per-role sliding-window metrics collector (`DisaggMetrics`) perform avoidable linear-time or temporary-tensor operations on hot paths:

1. **`BuddyAllocator` (`transport/allocator.py`)**:
   - `_free[order]` is stored as a Python `list[int]`.
   - `allocate()` calls `self._free[o].pop(0)` to preserve FIFO block reuse and split blocks down to the target order — an $O(F)$ shift per split step where $F$ is the number of free blocks at that order.
   - `free()` checks `if buddy_offset in self._free[order]:` ($O(F)$ linear scan) followed by `self._free[order].remove(buddy_offset)` ($O(F)$ linear scan and shift) at each coalescing level.
   - Replacing `_free[order]` with an insertion-ordered `dict[int, None]` preserves identical FIFO allocation ordering (`next(iter(free_set))` + `del free_set[offset]`) while reducing allocation pop, buddy membership check, and buddy coalescing removal to $O(1)$.

2. **`TransferTensorBuffer.read_tensor` (`transport/buffer.py`)**:
   - Previously allocated a temporary empty PyTorch tensor on every read (`torch.tensor([], dtype=dtype).element_size()`) just to query the byte width of `dtype`.
   - `torch.dtype.itemsize` provides the exact element size directly in $O(1)$ without constructing a tensor object.
   - Also guards `pin_memory=torch.cuda.is_available()` when `device == "cpu"` so CPU-only environments and unit tests can instantiate `TransferTensorBuffer` without failing when no CUDA/accelerator pinned-memory allocator is registered.

3. **`DisaggMetrics` (`metrics.py`)**:
   - `_StageStats.samples`, `_TransferStats.durations_ms`, `_TransferStats.bytes_list`, and `_QueueStats.wait_durations_ms` used `list` with `while len(...) > window_size: list.pop(0)` on every recorded sample ($O(W)$ shift once the 1000-sample window is full).
   - Replacing `samples` with `collections.deque(maxlen=window_size)` and `_TransferStats` / `_QueueStats` lists with `collections.deque` (`popleft()`) makes window pruning $O(1)$.

## Modifications

- `python/sglang/multimodal_gen/runtime/disaggregation/transport/allocator.py`: Use `dict[int, None]` sets in `BuddyAllocator._free` for $O(1)$ FIFO pop and $O(1)$ buddy coalescing.
- `python/sglang/multimodal_gen/runtime/disaggregation/transport/buffer.py`: Compute `nbytes = math.prod(shape) * dtype.itemsize` in `TransferTensorBuffer.read_tensor` and use `pin_memory = torch.cuda.is_available()` on CPU pools.
- `python/sglang/multimodal_gen/runtime/disaggregation/metrics.py`: Use `collections.deque` in `_StageStats`, `_TransferStats`, and `_QueueStats`.
- `python/sglang/multimodal_gen/test/unit/test_disagg_allocator_and_metrics.py`: Add unit tests verifying `BuddyAllocator` FIFO reuse and coalescing, `TransferTensorBuffer` read/write round-trip, and `DisaggMetrics` sliding-window pruning.
