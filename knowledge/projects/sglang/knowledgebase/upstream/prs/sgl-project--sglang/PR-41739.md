# [MM] MultimodalInputs.merge: adopt the M-RoPE delta and clear its decode cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/41739) · state: closed · merged: False

## Original PR description

## Motivation

`MultimodalInputs.merge` (session continuation) drops the new turn's M-RoPE position delta when the earlier turn had none, and never clears `mrope_position_delta_repeated_cache`. Decode positions after a multimodal session continuation then come from a stale or missing delta.

## Modifications

- `merge()` adopts the other input's delta when self has none, and always clears `mrope_position_delta_repeated_cache`.
- `test/registered/unit/managers/test_mm_inputs_merge_mrope_delta.py`.
