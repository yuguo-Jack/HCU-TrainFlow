# Fix requested-token logprob handoff in P/D serving

[Upstream PR](https://github.com/sgl-project/sglang/pull/41455) · state: closed · merged: False

## Original PR description

P/D serving drops the first generated token's `token_ids_logprob` scores during handoff. A native one-token request can return its selected-token and top-k logprobs while `output_token_ids_logprobs` is empty. The same request succeeds through an aggregated worker; longer P/D responses can lose the first requested-score row and misalign subsequent rows.

Transfer the requested values and token IDs in the registered metadata buffers and append the first row on decode, alongside the existing selected/top-k scores. Retain the original scores when replaying a rebootstrap boundary. Check the transferred row length and IDs before committing output, and reset the length when a metadata slot is reused.

The fixed metadata supports up to 128 requested IDs. Wider P/D requests are rejected at tokenizer admission; aggregated requests retain their existing behavior. This adds two buffers to the P/D metadata layout, so both roles must run the updated version.

Validation:

- Added a regression that copies only registered buffers between independent prefill/decode allocations. It fails on unchanged upstream with empty requested-score rows, and passes with this fix. It covers requested IDs outside top-k, full capacity, shorter/empty/absent rows on slot reuse, replayed boundaries, and incomplete-metadata rejection.
- Added admission coverage for both P/D roles and the aggregated path.
- Actual production-module CPU imports and relevant tests: 91 passed, 11 skipped, 36 subtests passed (`test_disaggregation_wire.py`, `test_kv_checksum.py`, `test_flat_raw_top_logprobs.py`). The skipped cases require accelerator support. Ruff and diff checks passed (E402 excluded for the existing pre-import kernel-stub pattern in the tokenizer test).
- The backport passed 97 actual-image production import/unit tests (67 wire tests plus 30 logprob tests) in a bounded one-GPU ROCm allocation. This uses a frozen source overlay on the pinned image and does not execute model inference. The original model-serving failure and an aggregated score-path control are retained. The immutable backported image subsequently passed model-serving P/D validation on one MI355X node (P4+D4): both OFF and native-MTP3 arms returned complete two-ID requested-score rows for all 40 one-token probes (five fixed prefixes, eight repeats), with protocol, transfer, cancellation and role-readback gates passing. The original missing-row P/D failure and same-image aggregated control remain retained. These one-token responses had no draft-verification telemetry; this establishes requested-score transport completeness, not numerical equivalence or a speculative-decoding precision bound.

This change is independent of the early-send synchronization and ROCm projection fixes. It targets current upstream main and does not require those PRs to review the requested-score handoff.
