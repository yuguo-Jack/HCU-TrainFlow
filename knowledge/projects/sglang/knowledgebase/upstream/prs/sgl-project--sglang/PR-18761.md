## Modifications

<!-- Detail the changes made in this pull request. -->

**Changes:**

1. **Fix `bench_serving.py` regression from #18566** — `compute_random_lens` was changed to return `List[int]` (via `.tolist()`), but `sample_generated_shared_prefix_requests` calls `.reshape()` and `.item()` which require numpy arrays. Fixed by wrapping with `np.array()` before reshape and replacing `.item()` with `int()`. No impact on other callers. @hnyls2002 

2. **Increase 1-GPU nightly test timeout** — `--timeout-per-file` 600→900s, `timeout-minutes` 60→90 for MI30x and MI35x unit tests in both `nightly-test-amd.yml` and `nightly-test-amd-rocm720.yml`.

3. **Remove Kimi-K2 jobs** — superseded by Kimi-K2.5 (`nightly-8-gpu-kimi-k25`). rocm720 workflow match rocm700.

4. **Register missing suites** — add `nightly-amd-1-gpu` and `nightly-amd-1-gpu-mi35x` to `NIGHTLY_SUITES` in `run_suite.py`.
