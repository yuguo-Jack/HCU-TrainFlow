# [Refactor] sgl-kernel: Drop FlashMLA from the build

[Upstream PR](https://github.com/sgl-project/sglang/pull/45908) · state: open · merged: False

## Original PR description

#45893 moved every CUDA FlashMLA call to the `sgl-flash-mla` wheel, so nothing imports sgl-kernel's FlashMLA any more. This stops fetching and compiling the fork in sgl-kernel: `cmake/flashmla.cmake`, the two extension sources, the FlashMLA declarations in `sgl_kernel_ops.h`, `sgl_kernel.flash_mla` / `flash_mla_mega`, their tests and benchmark. XPU keeps its own ops in sgl-kernel-xpu.

The sgl-kernel wheel builds on x86_64 and aarch64 are the check; they passed once already on the pre-rebase version of these commits (run 39869014297, before it was cancelled by an unrelated push).
