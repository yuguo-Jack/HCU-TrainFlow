# feat(npu): support Kimi K3 PCP with FLA affine states

[Upstream PR](https://github.com/sgl-project/sglang/pull/35226) · state: closed · merged: False

## Original PR description

## Summary

- add NPU prefill context parallelism for Kimi K3 MLA and KDA
- implement KDA PCP with the FLA affine-state formulation: Q/K/V stay rank-local, each zigzag segment produces an affine `[H | M]` transform, and only those state transforms are gathered and composed in natural sequence order
- handle CP-aware causal-convolution state, recurrent-state updates, physical padding, uneven/ragged zigzag segments, and radix checkpoints
- preserve Kimi K3 PD disaggregation support when dSparK is enabled only on decode

This replaces the earlier sequence-to-head/head-to-sequence activation A2A draft. The final path does **not** use activation A2A.

## Kernel dependency

Depends on sgl-project/sgl-kernel-npu#745 for the NPU affine preprocess and fused affine merge kernels.
