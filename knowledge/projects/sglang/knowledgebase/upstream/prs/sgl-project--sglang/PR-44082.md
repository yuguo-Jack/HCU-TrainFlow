# [Fix] comfyui: Fix server-mode bugs in the SGLDiffusion plugin

[Upstream PR](https://github.com/sgl-project/sglang/pull/44082) · state: open · merged: False

## Original PR description

Fixes #44083. Split out of #43536 per review: these are the server-mode fixes, which were moved here as lower priority.

## Summary

Fixes for the SGLDiffusion ComfyUI plugin when it talks to an SGLD server. One commit per fix. Bug numbers below match the list in the issue.

- **Bug 1: server-mode nodes sent local paths a remote server can't read.** The generic video node sent a local temp path as `input_reference` and a client-side `output_path`; the H3 node built `file://` URIs for keyframes and references. Local references are now uploaded via multipart (a local video-to-video source goes up as `video_reference`), `output_path` is no longer sent (the result is downloaded if the server's path isn't local), H3 image conditions are embedded as base64 `data:` URIs, and local video/audio references against a confirmed-remote server raise a clear error.
- **Bug 2: `SGLDVideoInput` didn't implement ComfyUI's `VideoInput` contract.** `get_components()` returned a bare list and `save_to` dropped `format`/`codec`/`metadata`. The node now prefers ComfyUI's file-backed `VideoFromFile`, and the fallback fails loudly.
- **Bug 3: reported video width/height could be wrong.** The generic video node reported the requested size even when the server resolved a different one. It now reads the server's `size` field. (Same commit as bug 2.)
- **Bug 4: hardcoded 300s timeout on image requests.** Added a configurable `image_timeout` (default unchanged).
- **Bug 5: batched image inputs were silently truncated to the first image.** Now raises a clear error.
- **Bug 6: LoRA strength wasn't settable in server mode.** `/set_lora` accepts `strength`; it's now threaded through the client and node.
- **Bug 7: server-mode video jobs had no progress bar and ignored Cancel.** `generate_video` takes `progress_callback` / `check_interrupt`, wired to `comfy.utils.ProgressBar` and `throw_exception_if_processing_interrupted`. Limits: the server reports progress only as 0 then 100, and Cancel stops the client waiting but the server job keeps running (no abort endpoint yet).

## Tests

`test/test_sgld_server_mode.py` (new): 19 tests covering the fixes above, using stubbed `comfy`/`folder_paths` modules (no ComfyUI install or GPU). `test/test_h3_request.py` updated for the bug 1/6/7 behavior changes (base64 image URIs instead of `file://`, real temp files since the client now validates `file_path` locally); existing assertions kept. 30/30 pass on CPU.

Note: until #43536 lands, these tests need the sglang runtime importable, since the import guard that lets the plugin load without it is in that PR.
