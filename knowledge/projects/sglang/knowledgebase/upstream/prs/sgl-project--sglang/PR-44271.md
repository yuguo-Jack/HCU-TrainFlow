# [Perf] [AMD] mimo-v2.6: Fuse small-M QKV projection on gfx950

[Upstream PR](https://github.com/sgl-project/sglang/pull/44271) · state: open · merged: False

## Original PR description

## Summary

- fuse BF16 activation quantization and block-FP8 QKV projection for MiMo-V2.6 on gfx950
- extend the original M<=16 path through M=32 for DFLASH target verification
- tile M across multiple workgroups without changing the M>32 AITER fallback
- cover M=32 parity, fallback, and CUDA/HIP graph replay

## Validation

On the graph-fix + AITER #7027 baseline:

- 8k/c4 throughput: +5.52%
- 128k/c4 verify wall: 15.990 -> 14.842 ms (-7.18%)
- dense QKV block: 2.217 -> 0.119 ms/step
- GPQA: 0.7222
