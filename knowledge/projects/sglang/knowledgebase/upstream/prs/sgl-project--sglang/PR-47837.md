# [Test] linear: Expect replicated rows to skip TP symmetric memory

[Upstream PR](https://github.com/sgl-project/sglang/pull/47837) · state: closed · merged: True

## Original PR description

[by Claude Code]

Fixes #47836

## Motivation

#47744 (`009b167f109`) made `RowParallelLinear.forward` pass `disabled=True` to `use_symmetric_memory` when the layer is replicated (`parallel_group="replicated"`, so `tp_group is None`). It updated `test_kimi_mlp_parallel_groups.py`, but two tests in `test/registered/unit/layers/test_linear_parallel_groups.py` still expect `disabled=False` for the replicated group. As a result `base-b-test-1-gpu-small` fails on `main` for every PR that reaches stage B, for example [this job on #46082](https://github.com/sgl-project/sglang/actions/runs/41377853514/job/125064489554):

```text
FAIL: test_replicated_model_mlps_keep_weights_and_tp_output_allocation (model='ExaoneMoEMLP', group='replicated')
Expected: use_symmetric_memory(namespace(world_size=4, ...), disabled=False)
  Actual: use_symmetric_memory(namespace(world_size=4, ...), disabled=True)
```

## Modifications

Two assertions in `test_linear_parallel_groups.py` now follow the #47744 contract that replicated rows skip the TP symmetric-memory window:

- `test_row_partition_keeps_independent_reduction_and_allocation_policies`: expect `disabled=group == "replicated" or not symmetric`.
- `test_replicated_model_mlps_keep_weights_and_tp_output_allocation`: expect `disabled=group == "replicated"`.

Also fixes a second `main` breakage that reached this branch when it was updated with `main`: #30980 added `logger.info(...)` to `XPUGraphRunner.__init__` in `python/sglang/srt/hardware_backend/xpu/graph_runner/xpu_graph_runner.py` without defining `logger`, so `ruff` (F821) fails the `lint` job. This PR adds the missing `import logging` and `logger = logging.getLogger(__name__)`.
