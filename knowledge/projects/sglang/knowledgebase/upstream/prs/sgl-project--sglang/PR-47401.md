## Motivation

<!-- Describe the purpose and goals of this pull request. -->

HiCache rejects non-MLA models with `--dcp-size > 1`, even when the model and attention backend already support DCP. This PR enables GQA deployments to retain evicted prefixes in the L2 host cache and restore them without recomputing the full prefix.
It extends the DCP L2 infrastructure from [#33112](https://github.com/sgl-project/sglang/pull/33112) to the standard MHA/GQA host pool, including Qwen3.5's GQA/GDN hybrid cache.

## Modifications

<!-- Detail the changes made in this pull request. -->
- Pass DCP size/rank into the MHA host pool and preserve logical capacity accounting.
- Translate logical H2D/D2H indices to this rank's physical KV rows, using the same mapping for K and V.
- Preserve GDN checkpoint indices and account for physical transfer bytes per pool.
- Allow BF16 and FP16 KV; reject unsupported compositions and resolved quantized host pools.
- Add independent test cases to three existing test files: GPU copies, transfer accounting, and DCP L2 end-to-end coverage.

## Speed Tests and Profiling

<!-- If this pull request impacts inference speed, provide benchmarking and profiling results. -->
Hardware: NVIDIA A10 with PCIe interconnect. Software used for the recorded experiments: PyTorch 2.14.1/CUDA 13.0, Triton 3.8.0, Transformers 5.19.0.

Both experiments use 8 sessions × 2 scripted turns, a fixed 256-token continuation, and 128 output tokens per request. Inputs are identical across configurations; generated replies are not fed back. Cache is flushed before each case. No dedicated eviction requests are inserted into timed runs: pressure comes from the working set exceeding the configured L1 capacity.

Throughput includes both turns and the initial prefill. The latency values below describe the second, prefix-reuse turn.

### Qwen3.5-35B-A3B: long-context BF16 workload

TP8, Triton, decode CUDA graphs, `page_first/kernel`, 64K prefixes, concurrency 8. Each configuration was measured once. The GPU budget is deliberately limited to **196,608 physical KV rows per rank (~1.876 GiB)** and **128 GDN slots**; HiCache uses 20 GB/rank host budget. Logical KV capacity is multiplied by DCP size.
