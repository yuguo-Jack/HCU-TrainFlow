## Motivation

#45260 added a `post_load_weights()` call to `DeepseekV4ForCausalLMDSpark.load_weights()`. The lightweight model doubles in two existing CPU tests do not implement that hook, so the RunAI streaming-dequantization and shared-expert-fusion tests fail with `AttributeError` after loading their weights.

## Modifications

Add a no-op `post_load_weights()` hook to both test doubles. These tests do not construct draft stages or exercise mHC cache refresh; their existing weight-loading assertions remain unchanged. No production code changes.
