## Motivation

Unified KV refactors need checks that catch changes to byte layout, allocation identities and request-lifecycle behavior.

## Changes

Add literal layout fixtures covering full-attention, sliding-window and recurrent-state combinations, plus a deterministic allocator trace comparator. Share geometry builders and record allocation, translation, retirement and free results for comparison.

## Validation

Review follow-up: three isolated CPU regression checks passed. The production allocator CPU probe verified exhaustion/recovery and replayed 100 concrete operations with zero divergences.

Historical validation at `10a7784b3c` / `e49c1d1282`:
- Layout golden: **3 tests / 31 subtests passed**; all four planted mutations were detected.
- Historical allocator trace: four focused invocations, each with **64 seeded runs plus nine mixed-chain scenarios** (**73 runs / 12,968 operations**), **0 divergences**.
- Later CPU comparison matched **418 layout values across 28 configurations**.

These results precede the latest rebase; GPU trace replay was not rerun on this head.
