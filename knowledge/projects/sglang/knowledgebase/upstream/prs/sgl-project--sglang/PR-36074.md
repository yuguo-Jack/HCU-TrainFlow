Service startup and request scripts for `--grammar-backend llguidance` on Ascend NPU. The bitmask path is `GuidanceGrammar.apply_vocab_mask` -> `torch.ops.npu.apply_token_bitmask` when `logits.device.type == "npu"`.

### 1. Start the server

```bash
python -m sglang.launch_server \
  --model-path /path/to/model \
  --host 0.0.0.0 \
  --port 30000 \
  --attention-backend ascend \
  --grammar-backend llguidance
```

### 2. Send a constrained request

```bash
curl -s http://127.0.0.1:30000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"/path/to/model\",\"temperature\":0,\"max_tokens\":64,\"messages\":[{\"role\":\"user\",\"content\":\"Return the capital of France as JSON with keys name and population.\"}],\"response_format\":{\"type\":\"json_schema\",\"json_schema\":{\"name\":\"capital\",\"schema\":{\"type\":\"object\",\"properties\":{\"name\":{\"type\":\"string\"},\"population\":{\"type\":\"integer\"}},\"required\":[\"name\",\"population\"]}}}}"
```
