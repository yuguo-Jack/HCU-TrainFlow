# [DSpark] Add `SGLANG_DSPARK_USE_GREEDY_DRAFT`, an argmax draft accepted as one-hot

[Upstream PR](https://github.com/sgl-project/sglang/pull/43670) · state: closed · merged: True

## Original PR description

Stacks on #43669.

- `SGLANG_DSPARK_USE_GREEDY_DRAFT=1` (off by default) drafts every row by argmax, sampling requests included, and keeps no step logits, in the graph tail and in the eager path alike.
- The accept treats the draft as a one-hot distribution, which keeps the rejection and block-verification accepts exact: outputs still follow each request's sampling distribution, at a lower acceptance for high-temperature traffic.
- On a TP-sharded DeepSeek-V4 head each step gathers only per-block candidates. On a vanilla markov head a one-row step folds the bias GEMV, the add and the argmax into one kernel (`MarkovGreedyStep`, kept from before this stack).
- At temperature 0 the outputs are identical to the default draft's.
- Each draft step still broadcasts its tokens under the default `SGLANG_SPEC_TP_SYNC=all`, as every draft path now does; main's greedy-only fused paths skipped it. Narrowing the default sync set drops it.
- The fused kernel is used only when the head's bias is the plain `w2` GEMV of the previous token's embedding (vanilla heads; not Nemotron, gated or RNN) and `w2` has one row per base-logit column; otherwise the shared op runs.
- Tests: the one-row fused block runs the fused kernel, replays the eager block in a graph, and matches the FP32 argmax; which heads may fuse; a greedy draft returns argmax tokens and no step logits; the sampling accept receives a one-hot draft at the target vocab width.

No behavior change unless the variable is set.

## Verification

DeepSeek-V4.1-Flash on 4x GB300 with the recommended low-latency deployment (TP4, EP4, block size 5, `--cuda-graph-max-bs-decode 64`, custom allreduce on), random 2048-in / 1024-out, main and this branch back to back.

- `test_dspark_draft_graph.py`, `test_dspark_markov_sample.py`, `test_dspark_kernel_parity.py` and `test_block_verification.py` pass on GB300, as do `test_dspark_draft_block.py`, `test_dspark_greedy_draft_accept.py` and `test_spec_tp_sync.py`.
- Greedy draft at temperature 0, concurrency 1. "Sampling" is the graph tail from the lm_head on.

| server | TPOT (ms) | sampling (us/step) | whole draft (us/step) |
|---|---|---|---|
| main | 0.908 / 0.909 / 0.906 | 185.0 | 770.8 |
| this branch, greedy draft | 0.896 / 0.901 / 0.897 | 146.2 | 729.6 |

- GSM8K, 1319 questions, 5-shot, temperature 0, on an earlier revision of the stack: greedy draft 0.901 and 0.904 over two runs, main 0.906.
- ShareGPT at temperature 1: the greedy draft's accept length is about 14% lower than the default draft's, as expected from drafting by argmax.
