# [AMD][V4.1][*/N] Fix DP attention + TP MoE decode NaN and support bounded replay

[Upstream PR](https://github.com/sgl-project/sglang/pull/43077) · state: closed · merged: True

## Original PR description

## Motivation

With DP attention and a TP MoE, DeepSeek-V4.1-Flash decode on MI355X produced NaN in the MoE output under CUDA graph and crashed after a few minutes, and decoder SWA bounded replay was rejected for every DP attention layout. This PR fixes the crash and enables bounded replay for DP attention + TP MoE.

## Modifications

- Stage the aiter custom all-gather / reduce-scatter inputs through the pre-registered IPC pool during CUDA graph capture, so peers no longer read stale graph-pool data on replay (`SGLANG_AITER_CAPTURE_COPY_IN`, default 0; set 1 for DSv4.1 DP attention + TP MoE).
- For DP attention + TP MoE, write the real per-rank token count before every decode replay and zero the pad rows before the DP gather (`SGLANG_DP_MASK_PAD_ROWS`, default true, ROCm only).
- On ROCm, allow `--enable-decoder-swa-bounded-replay` with DP attention when the MoE is TP (`moe_a2a_backend none`) and attention TP is 1. Eager forwards all-gather each rank's late-layer row count and switch the DP gather sizes to it for the late layers.
- CUDA behaviour is unchanged: all of the above is gated to ROCm.

## Accuracy Tests

GSM8K 5-shot, 1319 questions, DSv4.1-Flash TP2 DP2 TP-MoE + DSpark: 0.896 (TP2 without DP attention: 0.894-0.906).

## Speed Tests and Profiling

AgentX c32, 3600 s, DSv4.1-Flash on 2x MI355X, TP2 DP2 TP-MoE + DSpark:
- before: crash after ~6 min -> NaN fix: 0 errors, 96,931 tok/s/GPU, P90 interactivity 70.7
- + bounded replay: 102,631 tok/s/GPU, P90 interactivity 88.9
