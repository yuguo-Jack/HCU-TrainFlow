# [Test] [NPU] deepseek_v4_flash: Switch FP8 4P GPQA test from EAGLE to DSPARK and add acceptance-rate test

[Upstream PR](https://github.com/sgl-project/sglang/pull/47023) · state: closed · merged: True

## Original PR description

## Motivation

Migrate the Ascend NPU DeepSeek-V4-Flash FP8 4P GPQA test from EAGLE to DSPARK speculative decoding, add a DSPARK acceptance-rate throughput test for the 950 (A5) environment, and load the extra custom ops that DSPARK requires on A5 from the shared NPU e2e launcher.

## Modifications

### 1. Enable DSPARK runtime environment (`python/sglang/test/ascend/e2e/run_npu_testcase.sh`)

Add three environment variables required to enable DSPARK for DeepSeek-V4 in the 950 environment:

- `SGLANG_DSPARK_A5_EXTRA_OPS_SO` — path to the custom ops shared library (`/usr/local/Ascend/extra-ops/vllm_ascend_C.cpython-312-x86_64-linux-gnu.so`).
- `ASCEND_CUSTOM_OPP_PATH` — prepend the custom_transformer vendor path (`/usr/local/Ascend/extra-ops/vendors/custom_transformer/`).
- `LD_LIBRARY_PATH` — prepend the custom_transformer `op_api/lib` path.

### 2. Model path and acceptance-rate assertion (`python/sglang/test/ascend/e2e/test_npu_performance_utils.py`)

- Change `DEEPSEEK_V4_FLASH_DEFAULT_MODEL_PATH` from `.../DeepSeek-V4-Flash` to `.../DeepSeek-V4-Flash-0731`.
- In `assert_metrics`, change the speculative acceptance-rate assertion from `assertGreaterEqual` to `assertGreater`, so `accept_length / --speculative-num-draft-tokens` must be strictly greater than the configured baseline. Both test cases that set `accept_rate` (the new `TestNPUDeepSeekV4FlashDSPARK` below and the existing `test_npu_deepseek_v4_flash_w8a8_8p_in8k_out1k_50ms.py`) now require `> 0.5` instead of `>= 0.5`.

### 3. Migrate FP8 4P GPQA test to DSPARK and add a DSPARK performance test (`test/registered/npu/accuracy/deepseek_v4_flash/test_npu_deepseek_v4_flash_fp8_4p_gpqa_a5.py`)

- Imports: move `BENCHMARK_TOOL_DEFAULT` from the `test_npu_accuracy_utils` import to the `test_npu_performance_utils` import (its home), and add `EVALSCOPE` (from `test_npu_accuracy_utils`) and `TestNpuPerformanceTestCaseBase`.
- On `TestNPUDeepSeekV4FlashFP84PGPQA`, set `benchmark_tool = EVALSCOPE` explicitly (was `BENCHMARK_TOOL_DEFAULT`; functionally identical since that default is `EVALSCOPE`). Class attributes `accuracy = 0.874`, `datasets = ["gpqa_diamond"]`, `few_shot_num = 0`, generation config, `timeout = 6000` are unchanged.
- Environment variables:
  - Replace `HCCL_BUFFSIZE=1024` with `DEEPEP_HCCL_BUFFSIZE=2560`.
  - Replace the commented-out `DEEPEP_HYBRID_DEPLOYMENT` with `SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=256`.
  - Replace `SGLANG_PROFILE_WITH_STACK=False` with `ASCEND_LAUNCH_BLOCKING=1`.
  - Add DSPARK env vars: `SGLANG_RAGGED_VERIFY_MODE=static`, `SGLANG_DSPARK_FAST_KERNEL=0`, `SGLANG_DSPARK_FAST_SAMPLING=0`.
- `other_args`:
  - Raise `--mem-fraction-static` from `0.72` to `0.73`.
  - Reduce `--max-running-requests` from `64` to `32`.
  - Trim `--cuda-graph-bs-decode` from `1 2 4 8 10 16` to `1 2 4`.
  - Replace `--attn-dp-size 4` with `--enable-dp-attention` and `--dp-size 4`.
  - Replace the EAGLE speculative config with DSPARK:
    - Remove `--speculative-algorithm EAGLE`, `--speculative-num-steps 2`, `--speculative-eagle-topk 1`, `--speculative-num-draft-tokens 3`.
    - Add `--speculative-algorithm DSPARK`, `--speculative-draft-model-path` (same checkpoint as the target model), `--speculative-draft-model-quantization fp8`, `--speculative-draft-attention-backend ascend`, `--speculative-num-draft-tokens 6`, `--speculative-dspark-block-size 5`.
  - Move `--quantization fp8` to the end of the arg list, after `--moe-a2a-backend deepep` / `--deepep-mode auto`.
- Update the class/method docstrings from EAGLE to DSPARK.
- Add a new performance test class `TestNPUDeepSeekV4FlashDSPARK` (`TestNpuPerformanceTestCaseBase`) reusing the same `other_args`/`envs`, with `benchmark_tool = BENCHMARK_TOOL_DEFAULT` (benchserving):
  - `dataset_name = "random"`, `input_len = 8000`, `output_len = 1000`, `num_prompts = 160`, `max_concurrency = 160`, `random_range_ratio = 1`, `warmup_requests = 32`, `request_rate = float("inf")`, `max_attempts = 3`.
  - `accept_rate = 0.5` (acceptance rate strictly greater than 0.5, per the tightened assertion in section 2).
  - `test_npu_deepseek_v4_flash_fp8_4p_dspark` runs `run_throughput()`.
