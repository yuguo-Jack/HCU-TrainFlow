# [Feat] grpc: Expose existing SIGTERM shutdown through runtime.v1

[Upstream PR](https://github.com/sgl-project/sglang/pull/41582) · state: open · merged: False

## Original PR description

## Motivation

Expose the existing configured SIGTERM shutdown procedure through `sglang.runtime.v1.SglangService/Shutdown` so a gRPC client can request engine shutdown.

## Modifications

- Add `Shutdown(ShutdownRequest) returns (ShutdownResponse)` with empty messages and regenerate the runtime bindings using the repository generator.
- Forward the RPC through `PyBridge` to `RuntimeHandle`, which queues `manager.signal_handler_class(manager).sigterm_handler` on the tokenizer-manager event loop. The existing SIGTERM handler and watchdog own readiness changes, draining, scheduler shutdown, and process cleanup.
- Return promptly after queueing the handler. The empty response acknowledges scheduling, not handler execution or shutdown completion, and may race connection closure. Repeated requests use the existing idempotent shutdown state. Follower metadata services retain `UNIMPLEMENTED`.
- Release the GIL while joining the gRPC server thread during teardown, so pending Python bridge calls can finish. Include a regression test for the reproduced deadlock.

The RPC uses existing SIGTERM semantics. It adds no separate admission policy or watch-delivery guarantee. This change is scoped to `runtime.v1`; `api.v1` is untouched.

## Accuracy Tests

Validated using Rust 1.93.1 (workspace pins 1.92), Python 3.12.14, and the rebuilt gRPC extension:

- `cargo +1.93.1 test --workspace -j 4`: **532 passed**, no failures or ignored tests.
- `PYTHONPATH=python python -m unittest test.registered.unit.entrypoints.test_grpc_bridge -v`: **7 passed**, including configured SIGTERM dispatch on the owning loop, concurrent calls, and unavailable-loop errors.
- With `SGLANG_TEST_GRPC_EXTENSION` set to the rebuilt library, `PYTHONPATH=python python -m unittest test.registered.unit.entrypoints.test_grpc_shutdown_rpc test.registered.e2e.grpc.test_shutdown -v`: **3 passed** in 63.312 seconds. The two real-listener tests cover concurrent empty acknowledgments, existing health/watch updates, and GIL-safe teardown. The real GPU test serves inference, invokes Shutdown, verifies readiness becomes unavailable and the listener/watch closes, then asserts engine exit code 0 within 60 seconds and scheduler exit.
- Real engine: Qwen3-0.6B, RTX 6000 Ada, TP=1, DP=1, CUDA 13.0, Torch 2.14.1+cu130, Triton attention, PyTorch sampling, CUDA graphs disabled. JIT artifacts were rebuilt against the matching CUDA 13 runtime after correcting the local toolkit layout. No GPU compute process remained afterward.
- A second `cargo +1.93.1 run -p sglang-api-codegen`: all checked-in artifacts reproduced byte-for-byte.
- Rust formatting, isort, Ruff formatting/lint, and `git diff --check`: passed.

Multi-rank and multi-node GPU shutdown were not run; this machine has one GPU.
