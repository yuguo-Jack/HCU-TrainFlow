# [Refactor] multimodal: [MM refactor 6/9] Serve token-space processors behind --enable-token-space-processor

[Upstream PR](https://github.com/sgl-project/sglang/pull/46412) · state: open · merged: False

## Original PR description

## Motivation

Serving needs the scheduler-facing output around the shared core.

## Modifications

- `TokenSpaceSGLangProcessor` wraps the core with the transport and placement from part 4; item offsets come from `mm_spans`.
- With the flag, `get_mm_processor` picks a registered strategy and otherwise keeps the legacy processor.
- `TokenSpaceServingSpec` holds per-model serving defaults (IO threads, video decode device, `mm_tokens`, the per-media item split, which defaults to legacy's), registered by architecture apart from the strategy. `--mm-process-config` can set `video_preprocessing_device` (e.g. `"cpu"`).
- Each item's hash covers its feature and the strategy's other item fields (e.g. `image_grid_thw`), so items with equal patches but different grids never share an embedding or KV cache.

## Tests

Wrapper (including item hashes), device selection, async call-site and server-args tests.
