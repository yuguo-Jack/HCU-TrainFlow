## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Fix two Score API validation gaps without changing scoring math or setwise semantics.

### 1. Count embedding overrides by item, not by character

**Problem:** `items="cat"` means one candidate item, just like `items=["cat"]`; it does not mean three items. Each entry in `item_embed_overrides` belongs to one item, not one character. Scoring already normalizes a bare string to one item, but override-count validation uses `len("cat") == 3`. This rejects valid requests and lets a character-count-sized override list pass the wrong check.

**Fix:** use the existing normalized `num_items` in both the count comparison and the error message. Bare strings require one override entry; list inputs still require one entry per item.

Illustrative example (with otherwise valid embedding inputs):

| Input | Override entries | Before | After |
|---|---|---|---|
| `items="cat"` | 1 | Rejects: incorrectly expects 3 | Accepts: one item, one override entry |
| `items="cat"` | 3 | Incorrectly passes the count check | Rejects: expects 1 |
| `items=["cat", "dog"]` | 2 | Accepts | Accepts: list behavior is unchanged |

### 2. Reject misaligned MIS hidden-state rows instead of silently dropping them

**Problem:** ordinary delimiter-based multi-item scoring (MIS) silently drops requested, non-null pooled hidden states when their row count is incorrect, even when the score rows are valid. The caller receives scores with `pooled_hidden_states=None` instead of learning that the response is inconsistent. This is defensive result validation, not a reproduced backend inference defect.

**Fix:** when hidden states are requested and non-null, require `num_items + 1` rows before removing the query-boundary row. Raise `RuntimeError` with the expected count, actual count, and request ID on a mismatch. Preserve absent/null fields and ignore unrequested hidden states.

Example: two items require three incoming rows: `[query, item0, item1]`.

| Incoming hidden-state rows (with valid scores) | Before | After |
|---|---|---|
| 2 rows, requested | Silently returns `pooled_hidden_states=None` | Raises `RuntimeError`: expected 3, got 2 |
| 3 rows, requested | Returns the two item rows | Unchanged: removes the query row |
| Absent/null, or not requested | Returns no hidden states | Unchanged |
