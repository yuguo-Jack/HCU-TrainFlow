# [GLM-5.3-Flash] Use top-k v2 for the k-pool indexer

[Upstream PR](https://github.com/sgl-project/sglang/pull/42200) · state: closed · merged: False

## Original PR description

## Summary

Route GLM-5.3-Flash's k-pool indexer to shared top-k v2, fusing pool selection, expansion, tail append and output mapping. Fix selector overflow with exact fp32 selection.

Reuse plans across layers and CUDA graphs; prefill chunks plan before logits. Export `topk_transform_kpool_v2` and `plan_topk_v2(out=...)`. Use default-on `SGLANG_OPT_USE_TOPK_V2`, with legacy fallback for unsupported layouts and pool sizes.

## Validation

**555 passed, 12 skipped** across 14 suites; pre-commit and diff checks pass. **928/928** Gaussian parity cases, **525/525** exact-selection cases, **200** stress iterations and **36** boundary cases pass. Racecheck: **zero hazards**.
