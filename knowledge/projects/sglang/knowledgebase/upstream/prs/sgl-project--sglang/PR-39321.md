# [NPU] [DOC] Add Ascend NPU (Atlas 800I A3) deployment scenarios to the GLM-5.2 cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/39321) · state: closed · merged: False

## Original PR description

> **Draft:** the docs and config are complete and pass all local checks. On-hardware verification on Atlas 800I A3 is pending (see Accuracy Tests below).

## Motivation

Refs Ascend/sglang#1211.

The GLM-5.2 cookbook has no Ascend NPU option, although the [Ascend NPU GLM-5.2 tutorial](https://docs.sglang.io/docs/hardware-platforms/ascend-npus/model-deployment/tutorials/glm_5_2) documents a single-node PD mixed recipe and a 1P1D PD disaggregation recipe. This PR adds both to the deploy panel, so you can pick **Atlas 800I A3** and get a command for each scenario.

## Modifications

### Commit 1: GLM-5.2 A3 data (`glm-5.2.jsx`, `GLM-5.2.mdx`)

| Deploy selection | Scenario | Key flags |
|---|---|---|
| A3 · W8A8 · Balanced · Single Node | 1×A3 PD Mixed (16 dies) | `--tp-size 16`, DeepEP auto, NEXTN 3-1-4 |
| A3 · W8A8 · High-Throughput · **PD Prefill (2 nodes)** | 2×A3 1P1D, prefill node | `--tp-size 16 --dp-size 4`, DeepEP normal, graph capture off, NEXTN 1-1-2 |
| A3 · W8A8 · High-Throughput · **PD Decode (2 nodes)** | 2×A3 1P1D, decode node | `--tp-size 16 --dp-size 16 --ep-size 16`, DeepEP low_latency, NEXTN 3-1-4 |

- Checkpoint: `Eco-Tech/GLM-5.2-w8a8` (msModelSlim W8A8, 774 GB; `--quantization modelslim`). The W8A8 chip appears only on A3. The checkpoint's MTP layer (layer 78) is stored as FLOAT per its `quant_model_description.json`, so every recipe passes `--speculative-draft-model-quantization unquant`.
- The PD roles sit in the **Nodes** row because each role is its own server started with `--nnodes 1`, so they don't fit a `multi-2` cell. The router command is in the page text.
- The recipes are transcribed from the tutorial. Flags the tutorial scripts use that `main` has deprecated are replaced with their current spellings: `--cuda-graph-bs` → `--cuda-graph-bs-decode`, `--cuda-graph-max-bs` → `--cuda-graph-max-bs-decode`, `--disable-cuda-graph` → `--cuda-graph-backend-{decode,prefill} disabled`, `--moe-dense-tp` → `--moe-dense-tp-size`. `--prefill-round-robin-balance` is dropped because it is a no-op `DeprecatedAction` on `main`.
- `dockerImages.a3` is set to `quay.io/ascend/sglang:cann9.0.0-a3-v0.5.16` (the tutorial's image). The PD roles use host networking, and the config adds `NETWORK_IFACE` / `PREFILL_IP` placeholders for `HCCL_SOCKET_IFNAME` and `ASCEND_MF_STORE_URL`.
- On A3, the Playground hides the cards that would emit CUDA-only flags (Attention, PD Disagg, HiCache, and the MoE EP degrees) and greys out the EAGLE presets with a reason: the NPU path is NEXTN.
- Page: the install section notes the CANN image, and Configuration Tips gains an Ascend section with a topology table, weights, host preparation, cross-node networking, the router command, and the verification status.
- All three cells are marked `verificationStatus: "in-progress"`, the same as the Kimi-K3 A3 cell in #35508.

### Commit 2: Playground fix (`_playground.jsx`, `authoring-reference.md`)

The A3 PD Prefill / PD Decode cells carry their own `--disaggregation-*` flags. The PD Disagg card is hidden on A3, but `applyAllDeltas` still ran its `apply`, which clears the `--disaggregation-*` family and then re-adds the role picked on the card. On A3 the card's role stays "off", so **the Playground command silently lost `--disaggregation-mode`** and turned the role recipe into a PD mixed one. The Deploy panel was not affected.

The fix skips an axis whose axis-level `showWhen(base)` hides its card, using the same predicate the renderer uses. There is one line of logic; the rest is comments and the documentation sync that `engine-axis.md` §3.4 asks for.

**No existing page changes behavior.** I scanned all 14 configs on `main` that declare a PD card. The bug only triggers when base cells carry `--disaggregation-*` flags *and* the card owns the role, and only GLM-5.2 meets both conditions: Kimi-K3 has PD cells but no card-owned role, and the other 12 configs have no PD cells.
