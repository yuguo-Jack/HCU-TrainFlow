# [Perf][DeepSeek-V4] Fuse inverse RoPE into wo_a FP8 quantization

[Upstream PR](https://github.com/sgl-project/sglang/pull/43786) · state: open · merged: False

## Original PR description

## Motivation

DeepSeek-V4 applies inverse RoPE to attention output before the `wo_a` projection. The CUDA UE8M0 FP8 path currently launches inverse RoPE separately, writes rotated BF16 values to memory, and reloads them for activation quantization.

This PR folds inverse RoPE into the `wo_a` quantization kernel, keeping rotated values in registers and preserving the intermediate BF16 rounding boundary. It complements [#39957](https://github.com/sgl-project/sglang/pull/39957), which fuses inverse RoPE with a small-batch BF16 wo_a projection. This PR instead quantizes the activation before the FP8 wo_a DeepGEMM path.

[#37658](https://github.com/sgl-project/sglang/pull/37658) introduced the analogous inverse-RoPE + FP8 input-quantization optimization on ROCm/aiter and the existing `SGLANG_OPT_FP8_WO_A_FUSED_INVROPE` flag. This PR extends that flag to the CUDA UE8M0 path. The BF16 and FP8 wo_a gates are mutually exclusive, so their reported speedups are not additive.

## Modifications

- Fuse inverse RoPE into the CUDA wo_a activation quantization kernel, rotating the last 64 dimensions of each 512-dimensional head.
- Preserve BF16 rounding before quantization, native packed-int32 UE8M0 scale storage and PDL dependencies.
- Issue position/frequency loads early and vectorize frequency loads; keep the selected launch configuration.
- Share the quantization / packed-scale epilogue and host tensor validation between fused and unfused kernels; reuse Python output allocation.
- Cache configuration-derived eligibility in `MQALayer.__init__`; check graph state, pre-applied inverse RoPE and current tensor properties at execution time.
- Reuse `SGLANG_OPT_FP8_WO_A_FUSED_INVROPE`, off by default, with existing fallbacks.
- Add only two focused GPU tests to the existing test file: production numerical equivalence and CUDA Graph replay with updated inputs. An existing CPU fixture that bypasses initialization receives the new attribute's default.

## Accuracy Tests

**Local GPU validation uses aiopt v0.5.21 on 8×B300.** It shares upstream's packed-int32 UE8M0 contract. On that backport:
- Both new tests passed: strided BF16 inputs, T ∈ {0,1,32,100,777,2047,8192,8193}, G ∈ {2,16}, FP8 codes, packed scales and strides; graph capture/replay with updated input.
- Serving startup completed decode CUDA Graph capture.
- Five greedy prompts, up to 64 generated tokens each: two additional independent baseline startups matched each other and the fused run on all returned texts.
- The first baseline startup differed on one prompt. Subsequent comparisons matched; the cause remains unresolved. Returned-text equality does not establish bitwise-equal logits or internal serving tensors.

These GPU results **predate cleanup commit `7c5d3eb7ce`**. That commit shares the quantization code and caches eligibility; updated GPU validation remains pending. No full model accuracy evaluation is claimed.

Local checks on the cleanup: Python syntax, Ruff, isort and clang-format passed. An exhaustive static eligibility comparison matched the previous predicate for configurations with attention output width equal to the configured head dimension.

### Non-main adaptation

The backport omits `and inv_rope is None` because v0.5.21 lacks that local variable. Main defines it, so this PR retains the guard to avoid double rotation. Local serving validation is on the available aiopt build; exact main validation is left to upstream CI/review.

```bash
python3 -m pytest -s test/registered/kernels/ops/attention/test_fp8_wo_a.py \
```

The numerical test covers T ∈ {0, 1, 32, 100, 777, 2047, 8192, 8193}, G ∈ {2, 16}, BF16 strided inputs, FP8 codes, packed scales and output strides. The graph test captures and replays with updated inputs.

### Server launch

Set `MODEL_PATH` to the local DeepSeek-V4-Pro weights. Run separately with `FLAG=1` (fused) and `FLAG=0` (baseline).

```bash
MODEL_PATH=/path/to/DeepSeek-V4-Pro
FLAG=1
export SGLANG_OPT_FP8_WO_A_FUSED_INVROPE="$FLAG"
export SGLANG_OPT_DEEPGEMM_MEGA_MOE_NUM_MAX_TOKENS_PER_RANK=8320

python3 -m sglang.launch_server \
    --trust-remote-code \
    --model-path "$MODEL_PATH" \
    --tp-size 8 --dp 8 --enable-dp-attention --enable-dp-lm-head \
    --load-balance-method round_robin --moe-a2a-backend megamoe \
    --disable-radix-cache --mem-fraction-static 0.835 \
    --swa-full-tokens-ratio 0.075 --chunked-prefill-size 65536 \
    --tokenizer-worker-num 32 --detokenizer-worker-num 32 \
    --enable-prefill-delayer --dist-init-addr 127.0.0.1:9500 \
    --host 0.0.0.0 --port 30000
```

Wait for inference readiness before sending probes. Stop all workers belonging to this server and verify its ports/GPU allocations have been released before starting the next arm.

### Greedy serving probe

Run once per startup, setting a distinct `ACC_OUT` filename; compare the returned texts across saved files.

```bash
ACC_OUT=acc_fused.json python3 - <<'PY'
import json
import os
import urllib.request

prompts = [
    "Explain in detail how a transformer neural network works, step by step.",
    "Write a Python function that returns the n-th Fibonacci number and explain it.",
    "What are the main causes of the French Revolution? Give a structured answer.",
    "Describe the process of photosynthesis and why it matters for life on Earth.",
    "Summarize the plot of Romeo and Juliet and its central themes.",
]
outputs = {}
for i, prompt in enumerate(prompts):
    payload = json.dumps({
        "text": prompt,
        "sampling_params": {"max_new_tokens": 64, "temperature": 0.0},
    }).encode()
    request = urllib.request.Request(
        "http://127.0.0.1:30000/generate",
        data=payload,
        headers={"Content-Type": "application/json"},
    )
    with urllib.request.urlopen(request, timeout=600) as response:
        outputs[str(i)] = json.loads(response.read())["text"]
with open(os.environ["ACC_OUT"], "w") as output:
    json.dump(outputs, output, ensure_ascii=False, indent=2)
PY
```
