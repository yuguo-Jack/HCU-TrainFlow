# [Docs][AMD] Update GLM-5.2 MI355X MXFP4 MTP recipe to 20261008 daily

[Upstream PR](https://github.com/sgl-project/sglang/pull/43718) · state: closed · merged: False

## Original PR description

## Motivation

Keep the GLM-5.2 MI355X MXFP4 five-step MTP cookbook commands in sync with the InferenceX AgentX recipe and its latest validated SGLang ROCm daily image, [SemiAnalysisAI/InferenceX#3851](https://github.com/SemiAnalysisAI/InferenceX/pull/3851). The command builder still pinned `…-20260923` and the page text `…-20260930`, and the two MTP cells did not carry the recipe's prefill chunk size, static memory fraction or HiCache host pool size.

## Modifications

- `dockerImages["mi355x|mxfp4"]`: `lmsysorg/sglang-rocm:v0.5.20-rocm720-mi35x-20260923` → `lmsysorg/sglang-rocm:v0.5.21-rocm720-mi35x-20261008`. As in #41109, this pin is shared by every MI355X MXFP4 cell.
- MI355X MXFP4 **Low-Latency** (TP8/EP1): `--chunked-prefill-size 131072` → `32768`, `--mem-fraction-static 0.80` → `0.85`.
- MI355X MXFP4 **High-Throughput** (TP4/EP4 HiCache): add `--chunked-prefill-size 32768`, and replace `--hicache-ratio 1.0` with `--hicache-size 180` (a 180 GB host KV pool per rank). `write_through` stays the default write policy.
- `GLM-5.2.mdx`: update the AMD MTP note to the new image and these settings. Add a short source-reference comment in the config.
- The Balanced and `mtp-314` cells, other precisions and other hardware are otherwise unchanged.

## Accuracy Tests

Documentation only; no code changes. This image and flag set were validated by [InferenceX run 38067578883](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/38067578883): all nine points (TP8/EP1 conc 1/2/4 and TP4/EP4 HiCache conc 4–16) passed, and GSM8K at TP4/EP4 conc 16 scored 0.9689 strict / 0.9719 flexible.

## Speed Tests and Profiling

No new measurements. The values come from the InferenceX recipe and the run above.
