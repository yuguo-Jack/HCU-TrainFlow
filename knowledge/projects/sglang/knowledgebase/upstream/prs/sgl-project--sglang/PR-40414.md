# [Kernel] Add out-of-tree linear-attention kernel registry

[Upstream PR](https://github.com/sgl-project/sglang/pull/40414) · state: closed · merged: False

## Original PR description

## Motivation

Out-of-tree hardware platforms currently have no stable way to provide GDN or KDA kernels after SGLang resolves the configured built-in backend. They must replace dispatcher internals instead.

## Modifications

- Add a `LinearAttnKernelBase` registry keyed by platform dispatch key, attention kind, and phase, following the existing `BaseFusedOp` OOT pattern.
- Resolve registered GDN and KDA factories after the built-in backend is selected.
- Preserve the selected fallback for in-tree platforms and unregistered combinations.
- Document the extension point and cover fallback and replacement dispatch.

## Accuracy Tests

In-tree platforms and unregistered combinations retain the existing kernel object, so this does not alter their model math. The staged integration passed the focused GDN, KDA, and state tests.

## Speed Tests and Profiling

Registry lookup runs only during dispatcher construction, not on the token path.
