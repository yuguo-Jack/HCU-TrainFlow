# [PyTorch] Skip FA 2.8.4 for unsupported arches in L3

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3772) · state: closed · merged: True

## Original PR description

# Description

#3403 added FA 2.8.4 to the L3 `FA_versions` arrays, but FA2's `setup.py` only emits
`-gencode` flags for 80, 90, 100, 110, 120 and 121, which causes error on sm107 (Rubin). 
```
RuntimeError: None of the requested CUDA architectures ['107'] are supported by CUDA 13.4
```
This PR maps an unrecognized capability onto its family base arch, so sm103 and
sm107 build FA2 as `compute_100f`/`sm_100`, and skips the FA2 iteration only when
neither the exact arch nor its family base is supported.
