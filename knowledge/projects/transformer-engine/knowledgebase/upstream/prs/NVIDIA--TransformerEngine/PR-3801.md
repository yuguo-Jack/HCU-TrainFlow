# Description

The next DLFW container release will use Ubuntu 26.04 and Python 3.14. This PR should fix all compatibility issues with Python 3.14. From what I can tell, these issues are exclusively limited to the CI environment, as only newer pytest and pylint versions are required.

Changes are exclusively Python package upgrades or linter fixes for pylint v4.
