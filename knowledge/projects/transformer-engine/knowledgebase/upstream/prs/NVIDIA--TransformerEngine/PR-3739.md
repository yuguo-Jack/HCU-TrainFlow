# [PyTorch] Keep None sentinels on the custom op device

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3739) · state: closed · merged: True

## Original PR description

# Description

Keep the empty tensors used to encode `None` on the operation's tensor device. Recent PyTorch nightly builds partition cross-device custom ops out of CUDA Graphs; TE's CPU sentinels therefore disable capture even when all computation runs on CUDA.

## Type of change

- [x] Bug fix (non-breaking change which fixes an issue)

## Changes

- Set the default device only while packing custom-op results, selecting it from flattened tensor inputs (including quantized buffers) and allowing leading CPU scalar inputs.
- Apply this in the shared real/fake registration path; forward, saved tensors, backward and autograd-free packing keep their existing signatures.
