# Fuse segmented MXFP8 quantization and projection gradient scaling

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3679) · state: open · merged: False

## Original PR description

Quantize aligned BF16 column segments directly into MXFP8 GEMM layouts, add optional distributed mean-scaling hooks to weight-gradient GEMMs, and avoid zero gradients for unused normalization outputs.

Candidate performance on GB300: isolated projection backward with mean scaling was 1.067x faster (8.358 → 7.836 ms). Combined with the Megatron attention-boundary changes, the 41-layer, 64-GPU training benchmark gained 1.50% E2E throughput (1503.26 → 1481.11 ms/step; 1.47% less step time), measured with repeated ABBA runs on the same GPUs. These are candidate measurements; the repository ports have not been retimed E2E.

Validation: 248 focused tests passed on GB300, covering exact payload and gradient parity, fallback layouts, streams, and CUDA graphs.
