# Fuse segmented MXFP8 quantization and projection gradient scaling

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3679) · state: open · merged: False

## Original PR description

Quantize aligned BF16 column segments directly into MXFP8 GEMM layouts, fold optional distributed mean scaling into weight-gradient GEMMs, and skip zero gradients for unused normalization outputs.

Candidate performance on GB300: projection backward with mean scaling was 1.067x faster (8.358 → 7.836 ms). Combined with the Megatron changes, the 41-layer, 64-GPU workload gained 1.50% E2E throughput (1503.26 → 1481.11 ms/step), from repeated ABBA runs on the same GPUs. The repository ports have not been retimed E2E.

Validation: 222 consolidated GPU tests passed on GB300 after rebuilding the merged source; all public CI checks pass.
