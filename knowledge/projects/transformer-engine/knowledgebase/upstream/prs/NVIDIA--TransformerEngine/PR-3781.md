# [PyT] Disable TE torch compilation in KV-cache CI tests

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3781) · state: closed · merged: True

## Original PR description

# Description

We've observed in our CI that on GB200, two BF16 TransformerLayer KV-cache cases can fail because earlier test parametrizations exhaust PyT's compilation limit for TE's bias+GELU helper. This results in the full-sequence (reference) and incremental paths (actual subject under test) can then use compiled and eager implementations with slightly different BF16 rounding. It's been observed that the first difference occurs in the MLP, not in attention or KV-cache handling. This just propagates further and then goes over the acceptable tol range in the test.

## Changes

It was decided to keep this test focused on KV-cache correctness by disabling TE's internal torch.compile helpers only for its pytest invocation. Disabling of torch.compile does not affect the subject under test directly (KV cache machinery) and hence it is deemed okay to use the env var to disable for this test's scope. Production behavior and other CI test commands are unchanged.
