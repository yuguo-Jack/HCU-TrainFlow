# Bound symmetric all-reduce scratch storage across input sizes

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3709) · state: open · merged: False

## Original PR description

# Description

Symmetric all-reduce retains a staging allocation for every distinct input size. A long-lived dynamic inference engine can therefore accumulate buffers for past prefill lengths, even though it only needs one size at a time.

Round the internal scratch allocation to a power-of-two capacity and reduce only the requested slice. Retaining the capacity buckets keeps old CUDA graph addresses valid while bounding their total storage to less than twice the largest bucket, per dtype, device and process group. The allocation helper's exact-size behavior and the existing zero-copy path remain unchanged.

This is an alternative implementation of the memory reuse proposed in #2037. It retains old allocations so captured graphs can continue to use them after capacity grows.
