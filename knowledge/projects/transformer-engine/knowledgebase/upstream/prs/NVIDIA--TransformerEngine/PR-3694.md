# [Common] Store swizzled MXFP8 rowwise scales directly in the register-resident

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3694) · state: open · merged: False

## Original PR description

TODO: let me review it

The GEMM-swizzled path of quantize_contiguous_kernel gathered each 16-byte scale run through warp shuffles and shared memory, then flushed it after a CTA barrier. Store each scale byte directly at its swizzled index instead, as the packed path does. Outputs are bit-identical; swizzled bf16 rowwise quantization is ~2.4% faster on average (up to ~5.5%) on GB200.
