<a href="#"><img alt="P1" src="https://greptile-static-assets.s3.amazonaws.com/badges/p1.svg?v=9" align="top"></a> **CUDA buffers lose stream tracking**

`record_stream()` now skips `scale`, `first_dims`, `last_dims`, and `tensor_offsets`, which the previous `get_data_tensors()` loop included. Grouped CUDA kernels read the shape and offset buffers.

If a caller queues work on another stream, calls `record_stream()`, and releases the wrapper, the allocator can reuse those untracked buffers before that work finishes. This can cause wrong results or invalid memory access. Record every CUDA tensor returned by `get_data_tensors()` and keep those buffers in the test.
