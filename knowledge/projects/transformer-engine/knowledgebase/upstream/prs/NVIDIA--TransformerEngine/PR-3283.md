<a href="#"><img alt="P1" src="https://greptile-static-assets.s3.amazonaws.com/badges/p1.svg?v=9" align="top"></a> **Backward drops the EP axis**

The public dispatch backward path passes `out_partition_spec=(leading,)`, with replicated trailing dimensions omitted. Slicing `out_partition_spec[:-1]` removes the leading EP axis, making `grad_topk_weights` fully replicated. But `sharded_impl` still returns only each rank's rows. The declared output shape then disagrees with the returned shape, breaking backward compilation even without TP.

Pad the spec to the output rank before replacing the hidden entry with `None`.

- greptile-apps[bot] · comment · 2026-10-21T18:36:55Z · [source](https://github.com/NVIDIA/TransformerEngine/pull/3283#discussion_r4340544173)

File: `transformer_engine/jax/cpp_extensions/ep.py` · line 990

<a href="#"><img alt="P1" src="https://greptile-static-assets.s3.amazonaws.com/badges/p1.svg?v=9" align="top"></a> **Combine defaults conflict with TP**

`EpCombinePrimitive.partition` now accepts a TP-sharded hidden dimension, but public `ep_combine` still defaults to replicating that dimension when `out_sharding` is omitted. With hidden width `H` and TP size two, the inner operation returns width `H/2`, while the declared output requires width `H` on each device. This breaks compilation.

Preserve the input hidden sharding in the default output, or gather the input before calling the inner operation.
