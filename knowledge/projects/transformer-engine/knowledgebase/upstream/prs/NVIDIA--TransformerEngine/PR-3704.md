# [Common] Give the grouped TMA descriptor updater internal linkage

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3704) · state: open · merged: False

## Original PR description

# Description

When TE is built with CUDA 12.x, the grouped MXFP8 activation functions (`nvte_group_gelu`, `nvte_group_dgelu`, and
the other grouped activations) return all-zero output, with no error, for groups whose tensors have different widths
(`VARYING_LAST_DIM` / `VARYING_BOTH_DIMS`). Details and the investigation are in #3703.

In short: `g_tensor_maps` in `grouped_tma.cuh` is `static __device__`, so each of the 17 `.cu` files that include
the header has its own copy. `update_tma_descriptors` is an externally linked template, and before CUDA 13.0 nvcc
emits mergeable host stubs for template kernels (`-static-global-template-stub` defaults to `false`), so all 17 files
end up launching one file's updater. That updater writes its own file's table. The grouped activation kernels read
their file's table, which nothing wrote, see `rows == 0` and return.

This PR makes `update_tma_descriptors` `static`, so its linkage matches `g_tensor_maps`: each file launches its own
updater, which writes the table its own consumer kernel reads. On CUDA 13.0+ this matches what nvcc already does by
default.

Fixes #3703

## Testing

RTX 5090 (CC 12.0), driver 570.195.03, Ubuntu 24.04, gcc 13.3, `main` at `33f3b356` (the commits since then don't
touch the changed file). Common library built directly with CMake (`-DCMAKE_CUDA_ARCHITECTURES=120`, Release).
`test_operator --gtest_filter='*GroupedFusedCastMXFP8*'`. "Launcher copies" = `nm -C libtransformer_engine.so | grep -c
'dispatch::common::update_tma_descriptors<__nv_bfloat16, __nv_fp8_e4m3>'`.

| Build | Launcher copies | Passed | Failed | Skipped |
|---|---:|---:|---:|---:|
| CUDA 12.8, `main` | 1 | 1,055 | **240** | 1,044 |
| CUDA 12.8, `main` + `-static-global-template-stub=true` | 17 | 1,295 | 0 | 1,044 |
| CUDA 12.8, this PR | 17 | 1,295 | **0** | 1,044 |
| CUDA 13.0, `main` | 17 | compile only | | |
| CUDA 13.0, `main` + `-static-global-template-stub=false` | 1 | compile only | | |

The CUDA 13.0 rows were compiled but not run (the machine's driver supports up to CUDA 12.8). The 240 failures are
`{CAST_ACT, CAST_DACT}` × 5 activations × the 24 varying-width shape cases. The wider
`*Grouped*:*MXFP8*:*mxfp8*:*Group*` sweep also goes from 240 failures to 0.

Notes:
- The tested build had the same one-word change without the new comment.
- Building `tests/cpp` with CUDA < 13.4 on current `main` needs a local workaround in `tests/cpp/test_common.h`
  (`if` → `if constexpr` in `TypeInfo::Helper::getType`); it's an unrelated compile error from #3325, described at
  the end of #3703. The library was unmodified apart from this PR.
- `pre-commit run --files transformer_engine/common/cast/core/grouped_tma.cuh`: all hooks pass.
