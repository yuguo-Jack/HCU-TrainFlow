# [JAX] Fix MoE bootstrap receive-capacity validation

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3618) · state: closed · merged: False

## Original PR description

# Description

Reject receive capacities that differ from the process's NCCL EP bootstrap signature before dispatch. The existing guard rejects larger capacities but accidentally permits smaller ones, contrary to its error message and the documented exact-match requirement. Keep the existing upper-bound check for the send token count.

The pinned NCCL EP dependency [rejects a receive buffer smaller than its fixed dispatch budget](https://github.com/NVIDIA/nccl-extensions/blob/809f71604370c9fcc3dd8fab260d62e2b65d5152/nccl_ep/nccl_ep.cc#L4667-L4672). This changes early validation, not kernel behavior or performance.

## Type of change

- [x] Bug fix (non-breaking change which fixes an issue)

## Changes

- Require `recv_capacity_per_rank == b_recv_pr` in the bootstrap compatibility guard.
- Add five host-side regression cases: smaller/larger receive capacity, smaller/equal send token count, and an excessive send token count.
