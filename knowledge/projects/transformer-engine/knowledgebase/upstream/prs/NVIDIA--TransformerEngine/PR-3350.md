<h3>Summary</h3>

Adds automatic cuDNN MegaMoE fusion for supported expert-parallel MoE sequences.
- Supported expert-parallel MoE blocks run through one fused cuDNN operation.
- Grouped tensors keep their grouped storage when they move or change dtype.

The new paths need fixes for result lifetimes, routing-channel consumers, and grouped dtype conversions.

Matching MoE calls share the same `output` buffer, and `fuser_forward()` returns the result written into it without copying.
