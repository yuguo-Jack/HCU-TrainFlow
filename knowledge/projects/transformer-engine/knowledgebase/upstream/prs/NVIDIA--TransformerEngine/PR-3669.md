# [Common] Forward the RHT matrix in NVFP4 quantize dispatch

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3669) · state: open · merged: False

## Original PR description


# Description

NVFP4 columnwise RHT on SM120/SM121 fails with `Assertion failed: rht_matrix != nullptr. Columnwise RHT requires an RHT matrix.` The scale-type dispatch wrapper introduced in #3325 accepts `rht_matrix` but passes `nullptr` to `quantize_transpose_impl`, discarding the valid matrix
provided by the SM120/SM121 path added in #3300.

Forward `rht_matrix` through the wrapper so columnwise RHT receives the supplied matrix. Calls that omit the optional argument continue to pass `nullptr`.

Related: #3062. This fixes the dropped-argument regression in #3325; the original shared-memory issue described in #3062 has a different cause.
