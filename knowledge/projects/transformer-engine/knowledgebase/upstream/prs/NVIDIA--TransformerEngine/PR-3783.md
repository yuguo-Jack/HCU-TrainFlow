# [Common] Make it easier to debug C++ UT failures

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3783) · state: closed · merged: True

## Original PR description

# Description

On CI now C++ unit tests run as one test case in serial. This is faster than running in parallel but if it fails we can't tell what's broken from the CI logs. This PR makes it easier to debug by dumping the log if it fails and also adds an env var so when you debug you can make run in parallel and use filters to run certain cases
