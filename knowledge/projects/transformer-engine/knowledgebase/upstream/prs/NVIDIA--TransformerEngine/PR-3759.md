# Remove dummy weight gradients from fused accumulation

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3759) · state: open · merged: False

## Original PR description

# Description

Remove dummy weight-gradient tensors from Transformer Engine's fused weight-gradient accumulation path. When the real gradient has been accumulated into `main_grad`, return `None` to autograd instead of allocating or reusing an unused dummy. This removes the dummy cache, zero-tensor handling, and extra gradient addition needed by tied embeddings.

This is paired with [Megatron-LM #4680](https://github.com/NVIDIA/Megatron-LM/pull/4680), which updates Megatron's gradient hooks and consumers for the `None` contract. PyTorch 2.6+ runs the accumulator hook on the parameter's device worker thread.

## Type of change

- [x] Code refactoring
- [x] Bug fix (non-breaking change which fixes an issue)

## Changes

- Return `None` for fused weight gradients already written to `main_grad` across linear, grouped linear, fused ops, and distributed-weight paths.
- Remove the dummy-gradient cache and its test helpers; update CUDA graph and grouped-operation expectations.
- Preserve distributed-weight finalize behavior when it returns `None` for a group.
