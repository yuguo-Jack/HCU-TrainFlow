# [PyTorch] Test sequence-parallel Linear with 3D inputs and small micro-batches

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3791) · state: open · merged: False

## Original PR description

# Description

The distributed `Linear` tests in `run_numerics.py` only use 2D inputs, so the sequence-parallel all-gathers never see the `[seq, micro-batch, hidden]` layout. #3720 shows what that misses. With the NVFP4 recipe, the 2.21.0 pre-release `d77ef88c` crashed in the backward all-gather of a row-parallel `Linear` with sequence parallelism when the micro-batch was 1, and the existing tests passed on it. #3628 later fixed the shape bookkeeping on main and on `release_v2.21`.

This PR adds a test for that layout. It is test-only.

Related: #3720, #3628

## Changes

- `tests/pytorch/distributed/run_numerics.py`: `test_linear_3d_input` runs a sequence-parallel `te.Linear`, column- and row-parallel, on `[seq, micro-batch, hidden]` inputs with micro-batch 1 and 3. The sequence has `WORLD_SIZE * SEQ_LEN` tokens, so every rank holds `SEQ_LEN` of them in the sequence-parallel layout. The test compares the output and the input gradient with a single-GPU `Linear`, using the existing helpers and tolerances. It runs for every recipe that `test_numerics.py` parametrizes.

## Testing

Two B300 GPUs (sm_103), TE built for `103a`, torch 2.14.1+cu130, cuDNN 9.24:

| TE | `test_linear_3d_input`, NVFP4 |
|---|---|
| `d77ef88c` (2.21.0 pre-release from #3720) | **fails**: row-parallel, micro-batch 1 in `swap_first_dims` ("Input is not allocated"); row-parallel, micro-batch 3 in `CheckScaleTensorShape` (`columnwise_scale_inv.shape == expected`). Both column-parallel cases pass, and so does the existing `test_linear`. |
| `7457e47d` (`v2.21.0`, includes #3628) | passes |
| main `63451d6b` | passes |

On main with this PR, `tests/pytorch/distributed/test_numerics.py` passes for all six parametrizations (None, fp8, mxfp8, fp8_cs, fp8_block_scaling, nvfp4): 6 passed. Black 24.4.2 with the repository's pre-commit options leaves the file unchanged.
