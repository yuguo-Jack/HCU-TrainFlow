<a href="#"><img alt="P2" src="https://greptile-static-assets.s3.amazonaws.com/badges/p2.svg?v=9" align="top"></a> **FP8 gradients become zero**

With the default 4 × 8192 tokens, this loss produces per-output gradients around 10⁻⁶. On the first DelayedScaling run, the backward E5M2 quantizer starts with a scale of 1, so those values round to zero before the backward GEMMs. The gradient comparisons can therefore pass without checking meaningful GEMM gradients. Please scale the loss or initialize the backward quantizer so this test exercises them.
