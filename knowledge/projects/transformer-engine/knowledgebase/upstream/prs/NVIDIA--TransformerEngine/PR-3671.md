# [PyTorch] Return the argmax from parallel_cross_entropy

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3671) · state: closed · merged: True

## Original PR description

The forward kernel of parallel_cross_entropy already scans every row of logits for its maximum. With the new keyword-only return_argmax=True it also returns the index of that maximum, so a caller that needs the predicted tokens, such as an accuracy metric, does not read the logits a second time.

The index is the one torch.argmax returns over the unsharded logits: the first one when several logits are equal. With tensor parallelism, each rank's local index travels with the statistics in the existing all-gather (one more FP32 column, as raw bits), and the first rank that holds the global maximum provides it. Without return_argmax the kernels compile as before; with it, loss and gradient are bit-identical.
