# Fix GitHub PyTorch lint on Ubuntu 26.04

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3736) · state: closed · merged: True

## Original PR description

# Description

Fix the GitHub PyTorch Python lint job after `ubuntu-latest` moved to Ubuntu 26.04 with Python 3.14. The pinned pylint 3.3.1 / astroid 3.3.11 crashes with `TreeRebuilder.visit_templatestr` while analyzing dependencies, causing unrelated PRs to fail.

## Type of change

- [x] Infra/Build change

## Changes

- Select Python 3.12 explicitly for the PyTorch Python lint job.
- Install `wheel`, required for pylint to analyze the `wheel.bdist_wheel` import in `transformer_engine/pytorch/setup.py` in the fresh Python environment.

## Validation

The resulting workflow is byte-identical to the version that passed all four lint jobs in [PR #3494 CI](https://github.com/NVIDIA/TransformerEngine/actions/runs/40023894445). `git diff --check` passes.

Baseline failure: [PyTorch Python job](https://github.com/NVIDIA/TransformerEngine/actions/runs/40021929154/job/120648364135). The same crash was found in all 16 completed non-docs PR runs examined on October 23.
