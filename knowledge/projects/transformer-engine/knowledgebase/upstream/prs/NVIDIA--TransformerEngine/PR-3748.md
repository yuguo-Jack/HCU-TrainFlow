# Fix LayerNormLinear dummy gradients for sharded weights

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3748) · state: closed · merged: True

## Original PR description

Use the original parameter shape for both fused-DDP dummy-gradient branches. Distributed weights can expose a full GEMM gradient buffer even though autograd expects a gradient matching the local parameter shard.

Add standalone LayerNorm/RMSNorm regression coverage for shard and full-weight shapes, both dummy branches, and two-microbatch gradient accumulation. Include the regression in the PyTorch L0 launcher.
