# [Common][Attention][cuDNN] Restore bucketed attention plan reuse

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3700) · state: open · merged: False

## Original PR description

## Summary

Restore plan reuse when packed THD sequence counts fall within the same batch bucket. Direct cumulative-length inputs contain only `actual_batch + 1` entries, so they cannot safely describe a larger bucketed batch without preparation.

Use the existing length and offset conversions for bucketed ragged graphs. This supplies the bucket-sized metadata and lets those calls share forward plans. Dense/nonbucketed direct paths and backward behavior are unchanged.

The cache regression repacks a fixed token count into different sequence counts and checks forward/backward graph and plan reuse.

## Validation

The restored source matches the earlier revision `4705bb6b`, which passed native output/gradient reference checks on GB200 with CUDA 13.5, cuDNN 9.25 and Frontend 1.29. Scoped pre-commit hooks and whitespace checks pass for the revert. Full frontend integration suites were not run locally; see [CI checks](https://github.com/NVIDIA/TransformerEngine/pull/3700/checks).
