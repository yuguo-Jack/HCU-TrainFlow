# [Common] Enable all activations for MXFP8 C++ Unittest

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3616) · state: closed · merged: True

## Original PR description

# Description

With #3137, C++ operator tests will run in sequential and it gets a lot faster than previously because previously they run in parallel which incurs lots of overhead for launching & cleaning up. Now, even if we enable all activations, they won't take that much time to run

|  | With all activations enabled | Only enable  GeLU |
|---|---:|---:|
| Full C++ suite | 23m 9.12s | **15m 5.80s** |
| MXFP8 test groups | 123\.82s | **54\.42s** |

(Before #3137 this takes around an hour so I'd say this is acceptable for us)
