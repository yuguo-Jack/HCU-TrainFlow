# [Common] Initialize unused THD half-buffer rows

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3686) · state: open · merged: False

## Original PR description

`thd_read_half_tensor` leaves trailing rows uninitialized. NaNs in these rows can reach valid FA4 output.

Zero the trailing rows in the existing kernel launch. Fix the K/V output offset for odd input row counts.

The FA4 test disables NaN filling and reuses memory from finite FP32 values. On GB300, it fails with the old kernel and passes with the fix.

Lint and formatting pass. Full-branch GPU tests are pending.
