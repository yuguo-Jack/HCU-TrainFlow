# [PyTorch] Reduce THD CP P2P input preparation overhead

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3687) · state: open · merged: False

## Original PR description

THD context-parallel attention repeats input preparation at each forward ring step. This adds CPU work and GPU kernel launches.

This change computes the sequence-length arrays and reads the second half of Q once per forward pass. It reads K and V halves in one kernel launch when their shapes match and the token count is even. These changes apply to inputs without padding between sequences.

The new tests compare prepared inputs with the previous implementation and cover causal and noncausal attention on four GPUs.

Local lint and formatting checks pass. GPU tests still need to run on this branch.
