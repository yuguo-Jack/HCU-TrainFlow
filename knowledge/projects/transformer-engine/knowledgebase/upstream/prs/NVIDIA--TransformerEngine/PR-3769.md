## Original PR description

# Description

The `libtransformer_engine.so` shared library implicitly depends on libpython when built CuTeDSL. This PR fixes the test executable build process so that the test executable links against libpython, but only when libtransformer_engine.so actually requires it.

Fixes nvbug 6988465
