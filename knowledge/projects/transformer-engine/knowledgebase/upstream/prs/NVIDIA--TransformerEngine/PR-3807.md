## Original PR description

# Description

This mhc kernel uses too much memory. On CI's 40GB A100 node, JAX takes 75% of memory and there is only 10GB left, and triton autotune will try to run every configs which uses more than 10GB memory causing OOM.

This PR trims some configs to reduce memory usage and autotune time for real users
