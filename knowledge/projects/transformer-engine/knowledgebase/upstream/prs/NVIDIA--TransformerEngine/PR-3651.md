# Guard zero-gradient blocks in the default FP8 block-scaling recipe

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3651) · state: open · merged: False

## Original PR description

# Description

Set the default backward-gradient `amax_epsilon` in `Float8BlockScaling` to `1e-12`. This gives zero-amax E5M2 gradient blocks a nonzero floor in the recipe, instead of requiring downstream projects to override the recipe instance. Forward input and weight quantization defaults remain unchanged.

Fixes https://github.com/NVIDIA/Megatron-LM/pull/7523/changes#r4211643974

## Changes

- Use `amax_epsilon=1e-12` for the default blockwise FP8 backward-gradient quantizer.
- Document the backward-only default.
- Test zero-gradient quantization and Linear backward, and compare ordinary nonzero-block quantization bitwise with the previous epsilon-zero setting.
