- timmoon10 · comment · 2026-10-14T18:44:51Z · [source](https://github.com/NVIDIA/TransformerEngine/pull/3634#discussion_r4274858728)

File: `tests/pytorch/distributed/run_gemm_with_overlap.py` · line None

The reference implementation is inconsistent between the high-precision and quantized cases. For high-precision, the reference values are in BF16 and we perform a BF16 GEMM, possibly with split-accumulator. For quantized compute, the reference values are in FP32 and we perform an FP64 GEMM without split-accumulator. See this PR's GEMM logic here: https://github.com/almogsegal/TransformerEngine/blob/9949b9fdd8b6b138a61f142471482c8ad9bc7e22/tests/pytorch/distributed/run_gemm_with_overlap.py#L611-L620

I propose two options:
1. Always keep the reference values in BF16.

```python
    if with_quantized_compute:
        inp_g.copy_(inp_fp8)
        if opts.comm_type == tex.CommOverlapType.AG:
            inp_g = te.distributed.gather_along_first_dim(inp_g, tp_group)[0]
        ker_g.copy_(kernel_t_fp8)
        if opts.bulk_overlap and opts.comm_type == tex.CommOverlapType.RS:
            bulk_inp.copy_(bulk_inp_fp8)
        elif ub_obj2 is not None:
            ker2_g.copy_(kernel2_t_fp8)

...

        ref_g, *_ = tex.general_gemm(
            ker_g,
            inp_g,
            out_dtype=torch.bfloat16,
            use_split_accumulator=ref_use_split_accumulator,
        )
```

2. Always perform the reference GEMM in FP64.

```python
    if with_quantized_compute:
        inp_g = inp_fp8.dequantize(dtype=torch.float32)
        if opts.comm_type == tex.CommOverlapType.AG:
            inp_g = te.distributed.gather_along_first_dim(inp_g, tp_group)[0]
        ker_g = kernel_t_fp8.dequantize(dtype=torch.float32)
        if opts.bulk_overlap and opts.comm_type == tex.CommOverlapType.RS:
            bulk_inp = bulk_inp_fp8.dequantize(dtype=torch.float32)
        elif ub_obj2 is not None:
            ker2_g = kernel2_t_fp8.dequantize(dtype=torch.float32)
    else:
        inp_g = inp_g.float()
        ker_g = ker_g.float()
        if opts.bulk_overlap and opts.comm_type == tex.CommOverlapType.RS:
            bulk_inp = bulk_inp.float()
        elif ub_obj2 is not None:
            ker2_g = ker2_g.float()

...

    ref_g = torch.matmul(inp_g.double(), ker_g.double().t())
```

I think option 1 is nicer since it requires fewer changes to the existing code.
