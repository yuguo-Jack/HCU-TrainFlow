# [PyTorch] Allow FlashAttention 2 head_dim > 192 on sm103

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3714) · state: open · merged: False

## Original PR description

# Description

`get_attention_backend` disables FlashAttention 2 for padded head dims in (192, 256] unless the device is in an exact allowlist, `((8, 0), (9, 0), (10, 0), (12, 0))`. sm103 (B300 / GB300) is not in it. So on sm103, every config with `max(head_dim_qk, head_dim_v)` in (192, 256] falls back to FusedAttention or UnfusedDotProductAttention, even when flash-attn is installed and requested. Examples are head_dim 256, or MLA with head_dim_v 256.

This is a regression:
- #2836 (merged 2026-06-04) removed the allowlist.
- #2629 (merged 2026-06-05) restored it in the hunk that added padded Q/V head dims.

#3360 reported the same problem on B300 and was closed by its author. As discussed there, this PR is the narrower fix: it adds only `(10, 3)` and leaves sm86/sm89 out.

The fallback also defeats an existing preference. For THD with dropout on `(10, 0)` and `(10, 3)`, `is_slow_fused_thd_dropout` disables FusedAttention so that FA2 is used. On sm103 with head_dim > 192, FA2 was already disabled by the allowlist, so the preference never applies.

Why a list entry rather than dropping the clause: flash-attn's hdim256 backward picks its kernel by opt-in shared memory per block. Below 144 KB (sm86/sm89/sm120 have 99 KB) it launches no kernel at all when dropout is enabled (Dao-AILab/flash-attention#3053). sm103 has 227 KB, the same as sm90 and sm100, so it takes the same backward kernel as sm100. The existing `(12, 0)` entry has that problem with dropout. It is tracked in #3711 and fixed separately.

## Changes

- Add `(10, 3)` to the FA2 head_dim > 192 allowlist. Update the debug message from "sm80/90/100+" (which wrongly suggested every sm100+ device) to "sm80/90/100/103/120".
- Add `test_fa2_large_head_dim_backend_selection` to `tests/pytorch/attention/test_attention_backend_selection.py`. It mocks the compute capability and the flash-attn version, like the FA4 cases in that file. It covers:
  - sm103 with padded head dim 224, 256, and MLA 192/256: FA2 is selected;
  - the 192 boundary, 264 (> 256) and 252 (not a multiple of 8): FA2 is not selected;
  - an sm100 control.
