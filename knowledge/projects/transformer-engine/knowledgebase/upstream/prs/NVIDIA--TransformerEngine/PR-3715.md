# [PyTorch] Keep FlashAttention 2 off for head_dim > 192 dropout backward on sm12x

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3715) · state: open · merged: False

## Original PR description

# Description

Fixes #3711.

flash-attn's head_dim 256 backward (`run_mha_bwd_hdim256`) picks its kernel by opt-in shared memory per block. Below 144 KB it launches no kernel at all when dropout is enabled, and returns without an error, so `dq`/`dk`/`dv` are never written. sm86, sm89, sm120 and sm121 all have 99 KB. Padded head dims 224 and 256 both use this kernel. The flash-attn side is Dao-AILab/flash-attention#3053; the check that used to reject this case was removed in Dao-AILab/flash-attention@bbb21d6.

TE's FA2 head_dim > 192 allowlist includes `(12, 0)`. Training with dropout at a padded head dim in (192, 256] on sm120 therefore selects FA2 and gets unwritten gradients. With flash-attn 2.8.3, a backward with `dq`/`dk`/`dv` pre-filled with NaN leaves them 100% NaN:
- on an RTX 5090 (sm_120, 101376 B opt-in shared memory per block), for head_dim 224 and 256 with `dropout_p=0.1`;
- not without dropout, and not at head_dim ≤ 192;
- not on B200 (232448 B), where every case computes.

This PR disables FA2 in exactly that case:
- padded head dim > 192;
- `attention_dropout > 0`;
- training mode;
- backward required;
- one of the 99 KB GPUs, `(8, 6), (8, 9), (12, 0), (12, 1)`.

Inference, dropout-free training and forward-only calls keep FA2. sm86/sm89/sm121 are already excluded by the allowlist for head_dim > 192. Listing them keeps the gate correct if that list is relaxed later.

## Changes

- `get_attention_backend`: a separate check right after the existing FA2 head-dim check. It turns FA2 off for the case above and logs the reason at debug level.
- `test_fa2_large_head_dim_dropout_backend_selection` in `tests/pytorch/attention/test_attention_backend_selection.py`, which mocks the compute capability:
  - sm120 with dropout at padded head dim 256, 224, and MLA 192/256: FA2 is not selected;
  - controls where FA2 stays selected: sm120 without dropout, in eval, forward only, and at head dim 192; sm100 with dropout.
