## Original PR description

# Description

Bump the maximum supported FlashAttention version from v2.8.3 to v2.8.4.

Currently, Transformer Engine (TE) caps FlashAttention at v2.8.3. However, newer commits on the FlashAttention main branch include changes that would be useful to TE users, such as those introduced in [Dao-AILab/flash-attention#2260](https://github.com/Dao-AILab/flash-attention/pull/2260).

Allowing FlashAttention v2.8.4 enables users to use TE with newer FlashAttention releases. I ran the test suite with the updated version, and the results were largely successful. The few failures appear to be related to my specific environment rather than the version bump itself.

Was there a specific reason for guarding against newer FlashAttention releases, or was it mainly intended to guard against potential API changes?

## Changes

* Increase the maximum supported FlashAttention version from v2.8.3 to v2.8.4.
* Validate the change with the existing test suite.
