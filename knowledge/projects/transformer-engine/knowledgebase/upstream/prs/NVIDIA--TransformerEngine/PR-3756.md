# [PyTorch] Fuse NVFP4 global scales and GEMM alpha in the grouped MLP

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3756) · state: open · merged: False

## Original PR description

Compute both operands' per-group NVFP4 global scales and their product (or its square root for dGLU) in one Triton launch instead of several eager elementwise kernels. Bit-identical to the eager ops; falls back to them for unsupported inputs.
