<h3>Summary</h3>

Adds an optional fixed-order reduction for MoE auxiliary loss while preserving the existing atomic path by default.

- MoE aux-loss callers can now choose a fixed-order reduction.
- PyTorch's aux-loss call offers deterministic mode for eager and graph calls.
- The fused MLA module keeps its extension import with the package imports.

No actionable issues were found. CUDA tests were not run.
