# Remove unused CustomClassHolder bases from Userbuffers wrappers

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3732) · state: closed · merged: True

## Original PR description

# Description

Remove unused `torch::CustomClassHolder` inheritance from the three C++ Userbuffers wrappers: `CommOverlapHelper`, `CommOverlap`, and `CommOverlapP2P`.

These classes are exposed through pybind11, with `std::shared_ptr` holders for the overlap classes. They are not registered as TorchBind classes and do not use the intrusive-pointer functionality supplied by `CustomClassHolder`. Removing the bases eliminates an unnecessary PyTorch dependency; the existing TE base classes and pybind11 bindings are retained.

## Type of change

- [x] Code refactoring

## Changes

- Remove the three `torch::CustomClassHolder` bases in `transformer_engine/pytorch/csrc/extensions.h`.

- Rebuilt and linked all 34 PyTorch-extension C++ translation units from this branch on one RTX 5880 Ada, PyTorch `2.15.0a0+875d815502`, CUDA 13.4. Reused the previously built common CUDA library; MPI, cuBLASMp, NVSHMEM and NCCL EP disabled.
- Four separate-process, one-rank GPU smoke tests passed: helper construction/destruction, CommOverlap, P2P AG, P2P RS. Verified TE base-class dispatch, exact BF16 buffer round-trips, communication streams, and Python ownership/release.
- Pre-commit, C++ L0 PyTorch lint (`CPP_ONLY=1`), license check and `git diff --check` passed.

Multi-GPU communication/GEMM overlap, optional backends, and the full L0 runtime suite were not run. This is not a complete stable-ABI migration. C++ consumers must rebuild against the updated class declarations.
