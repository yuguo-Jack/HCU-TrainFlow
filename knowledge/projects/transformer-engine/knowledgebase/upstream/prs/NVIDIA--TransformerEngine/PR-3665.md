## Original PR description

# Fix archive links across Transformer Engine publishing locations

## Description

Replace 94 publishing-location-dependent relative URLs in
`docs/documentation-archive.rst` with absolute `docs.nvidia.com` URLs.

At the published release-2.19 location, `../transformer-engine-releases/`
resolves to a URL containing the directory name twice. The absolute URLs
preserve the existing release paths and allow approved archive redirects to
continue handling retired versions.

The change preserves all 47 release entries, both links per release, labels,
and ordering. It does not change archive contents, banners, redirects, SDK
code, or supported-version policy.

## Type of Change

- [x] Documentation change

## Validation

- Before the patch, two of three focused regression checks failed for the
  expected relative-URL defect. After the patch, all three passed.
- All 94 canonical destinations reached HTTP 200 during the October 9 audit:
  50 on `archive.docs.nvidia.com` and 44 on `docs.nvidia.com`.
- All 94 final URLs retained the expected release-specific path.
- An isolated archive-page build with Sphinx 8.1.3,
  nvidia-sphinx-theme 0.0.9.post1, and pydata-sphinx-theme 0.19.0 passed with
  warnings treated as errors. The resulting HTML contains the 94 expected URLs.
- Link resolution was checked for unversioned docs, release-2.19 docs,
  archive-host docs, and GitHub Pages layouts.
- `git diff --check` passed.
- Local browser inspection confirmed the archive table renders at desktop and
  mobile sizes. The isolated preview theme logged an initial theme-mode reset
  to auto; this does not establish a clean full-site browser console.
