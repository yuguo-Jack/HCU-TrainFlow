<a href="#"><img alt="P1" src="https://greptile-static-assets.s3.amazonaws.com/badges/p1.svg?v=9" align="top"></a> **Replicated batches still fail**

With `ep=1`, no `dp_resource` or `fsdp_resource`, and another mesh axis spanning multiple devices, MoE assigns the batch only to `ep`. Once JAX removes that singleton axis, `_leading_axis_ok` still rejects the fully replicated spec: a leading `None` fails the allowed-axis check, and an empty spec fails the length check. Dispatch then raises `NotImplementedError`, so this valid `EP=1` case still cannot compile.

Allow fully replicated leading dimensions when `ep_size == 1` and add a regression test without a retained outer axis.
