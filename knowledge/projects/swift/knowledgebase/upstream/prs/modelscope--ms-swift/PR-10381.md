# PR information

Extract the HMAC-SHA256 authentication logic from hccl.py into a shared zmq_auth.py module, and apply it to both HCCL and NCCL checkpoint engines.

Changes:
- New zmq_auth.py: generate_auth_key(), send_auth_pyobj(), recv_auth_pyobj() with backward-compatible fallback when auth_key is empty
- hccl.py: delegate _send_pyobj/_recv_pyobj to shared module
- nccl.py: add auth_key to BroadcastOperation, engine, and MasterMetadata; replace raw send_pyobj/recv_pyobj with authenticated versions
- base.py: add auth_key field to MasterMetadata (shared by NCCL)
- __init__.py: export new auth helpers
- tests/megatron/test_zmq_auth.py: 22 tests covering round-trip, fallback, tamper/wrong-key/short-message rejection, REQ/REP and PUB/SUB threading, and engine integration

Security: crafted pickle from untrusted peer can never reach pickle.loads because HMAC is verified before deserialization.
