# PR information

Give models served by `swift deploy` free web search and page fetching with [Parallel Search MCP](https://docs.parallel.ai/integrations/mcp/search-mcp). Search uses Fast mode, with no Parallel account or API key needed.

Install the optional client dependencies and run `parallel_search.py` beside the existing [agent deployment example](https://github.com/georgeatparallel/ms-swift/blob/14f546a4973f2a2062d5ae681ad549933c2992c6/examples/deploy/agent/README.md). The client discovers tool schemas, executes search and fetch calls, and returns their results to the model. It also supports direct search and fetch without a model server. Existing clients stay unchanged. The agent client is non-streaming, caps tool text per call, and needs a tool-capable model.

I work at Parallel.
