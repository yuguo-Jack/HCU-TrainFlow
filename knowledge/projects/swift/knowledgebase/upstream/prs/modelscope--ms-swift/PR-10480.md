# PR information

Move the early --packing / --padding_free rejection off the model name and onto the framework's declarative template flag:

- Thx02Template / StartLuxTemplate declare support_padding_free = False; no model-specific code remains in SftArguments
- SftArguments._check_padding_free now reads template_meta.template_cls .support_padding_free (with the same None -> not is_multimodal fallback as the train pipeline) while parsing arguments, before the model is loaded
- StartLux previously inherited the flag from Qwen3_5Template without any rejection anywhere; it is now rejected like thx02
- update tests: thx02 packing rejection matches the generic message; olmo3 test covers both rejection paths (template opt-out vs flash-attention requirement)
