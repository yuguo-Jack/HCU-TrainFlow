# PR information

Fixes #10473

The eval metrics of the InfoNCE loss are returned as numpy scalars (`mean_neg` and `mean_pos` are `np.float32`, because the similarity matrix is float32), but the metrics are written to `logging.jsonl` by the printer callback, and `check_json_format` cannot serialize a numpy scalar: it falls back to `obj.__dict__`, which numpy scalars and arrays do not have. Training an embedding model with evaluation therefore died with

```text
AttributeError: 'numpy.float32' object has no attribute '__dict__'
  File "swift/utils/utils.py", line 58, in check_json_format
    for k, v in obj.__dict__.items():
```

This PR

- returns python floats from `InfonceMetrics`, matching the `Dict[str, float]` annotation of `compute_metrics`;
- converts numpy scalars (`np.generic` -> `item()`) and numpy arrays (`ndarray` -> `tolist()`) in `check_json_format`, and falls back to `repr` for objects without `__dict__` (e.g. a `set`) instead of raising.

The second change covers every other numpy value that reaches the json logging of ms-swift (`args.json`, `logging.jsonl`, `completions.jsonl`, `result.jsonl`), for example a metric of a custom eval callback.
