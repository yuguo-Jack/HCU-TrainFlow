# PR information

`external_plugins` declared in a checkpoint's args.json is no longer restored silently
- stash the declared plugins in 'ckpt_external_plugins' instead of importing them
- add the 'trust_remote_plugins' CLI flag and the SWIFT_TRUST_REMOTE_PLUGINS=1 environment variable as explicit opt-in
- log a warning before importing any external plugin
