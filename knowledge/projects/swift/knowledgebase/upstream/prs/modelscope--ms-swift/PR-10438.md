# fix(trainer): release the device cache of the active accelerator after offloading the model

[Upstream PR](https://github.com/modelscope/ms-swift/pull/10438) · state: open · merged: False

## Original PR description

`RolloutTrainerMixin.offload_model` moves the model's weights to the CPU and then releases the device cache so that the memory the weights occupied is available to the rollout engine. The release was written as `torch.cuda.empty_cache()`, which is a no-op on an Ascend NPU (and on MUSA/MPS): the freed memory stays in that accelerator's caching allocator instead of being handed back. The file already uses the shared helper for exactly this purpose — `swift.utils.torch_utils.empty_cache()` dispatches to `torch.npu` / `torch.musa` / `torch.mps` / `torch.cuda`, and `aggressive_empty_cache()` (already imported in this file) is built on it.

This change calls that helper at both release sites: the FSDP2 path and the default path. On a CUDA machine the behaviour is unchanged.

## Tests

`tests/utils/test_offload_model_cache_release.py` pins both release sites to the shared helper. It uses the stub-model style of `tests/utils/test_rollout_offload_order.py`, so it needs no installed accelerator, and it keeps the existing condition that an offload which moves nothing leaves the allocator alone.

| revision | result |
|---|---|
| `main` (`2286b035`) + this test file | the module never resolves the helper, so the patch target does not exist (`AttributeError: swift.rlhf_trainers.rollout_mixin.empty_cache`) |
| this branch | **3 passed** (CI) |

This machine has no GPU/NPU and not the runtime dependencies of the trainers, so the test itself was not executed here. The behavioural evidence comes from running the real `offload_model` of each revision (extracted from the file) against a stub module on CPU-only torch `2.8.0+cpu`, where `torch.cuda.empty_cache()` is a silent no-op:

| revision | `torch.cuda.empty_cache()` calls (cumulative) | shared `empty_cache()` calls (cumulative) |
|---|---|---|
| `main` | 1 (FSDP2 case), 2 (after the default case) | 0 |
| this branch | 0 | 1, 2 |

**Not tested:** the Ascend NPU offload end to end (no NPU here) and the DeepSpeed branch, which goes through the same default path.
