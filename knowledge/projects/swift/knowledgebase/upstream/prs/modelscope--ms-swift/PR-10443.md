# [CI] Remove internal cache-service references

[Upstream PR](https://github.com/modelscope/ms-swift/pull/10443) · state: closed · merged: False

## Original PR description

## Motivation

Our self-hosted Ascend CI runners access public package sources through a cluster-level squid caching proxy. The old internal `nginx-pypi-cache` mirror (`cache-service.nginx-pypi-cache.svc.cluster.local`) is being retired, so this PR removes its references from the NPU CI workflow.

## Changes (`citest_npu.yaml`, -8 / +1)

- Drop `UV_INDEX_URL` / `UV_INSECURE_HOST` / `PIP_INDEX_URL` / `PIP_TRUSTED_HOST`; the public Huawei Cloud Ascend index (`UV_EXTRA_INDEX_URL`) and the remaining uv settings stay
- Remove the APT source rewriting (`cache-service :8081`) and the two `pip config set` lines; the step is renamed from "Config mirrors" to "Install uv"

## Test plan

- `grep -r "cache-service\|nginx-pypi-cache"` over the repo returns nothing
- The workflow parses as valid YAML
