# PR information

Closes #7314.

The alignment dataset section explains how `rejected_response` replaces the messages after the last `user` turn, but it does not answer whether the message list can hold multiple negative responses. `Template._rlhf_encode` encodes exactly one chosen and one rejected sequence per sample (`swift/template/base.py`), and `TemplateInputs._compat_rejected_response` turns a `rejected_response` list into one rejected trajectory; several negatives are not aggregated per sample.

This PR adds one sentence to both the Chinese and English docs: the list is a single rejected trajectory (it may contain several messages, such as tool calls and results), and multiple negative responses for the same prompt require one sample per negative response with the prompt-side messages repeated.
