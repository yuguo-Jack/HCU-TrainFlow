# PR information

`split_list(..., contiguous=False)` converts its input to a NumPy array before splitting it. This can change element types (`[1, 'two']` becomes strings), turn tuples into lists, or raise `ValueError` for nested lists of different lengths.

Use stepped list slices to preserve the original elements and their identities while keeping the existing round-robin order. The contiguous path is unchanged.

Add seven regression and compatibility tests covering mixed types, ragged lists, tuple identity, both splitting modes, empty inputs, and more shards than items.
