# PR information

1. Kev now supports scoring multiple questions in a single forward pass: questions sharing the same state can utilize a shared prefix for computation—a feature applicable to both training and inference—with an automatic fallback to the original execution path when sharing is not possible.
2. A new `decision_branch.py` has been introduced to consolidate branching mechanisms across various models, replacing the legacy `omnijev_branch.py` and resulting in a cleaner directory structure.
3. `KevPointerHead` now includes a `forward_pointer` entry point, designed for use by branching paths.
4. The logic for attaching heads within the `Loader` has been generalized: the three model subclasses now only override specific hooks, eliminating redundant boilerplate code for patching.
