# PR information

Refs #10477

The same NPU hardware was referred to in four different ways across the documentation:
`Ascend NPU`, `华为 Ascend NPU`, `Huawei Ascend NPU` (already used by both installation
tables — `docs/source_en/GetStarted/SWIFT-installation.md:161` and
`docs/source/GetStarted/SWIFT-installation.md:162`), and `昇腾 NPU`. This PR aligns the
hardware labels and the Megatron-SWIFT Ascend pages with the existing
`Huawei Ascend NPU` wording. 9 lines, documentation only:

- `README.md:62`, `README_CN.md:59` — hardware-support feature list: `Ascend NPU` →
  `Huawei Ascend NPU`.
- `docs/source/GetStarted/Quick-start.md:10`, `docs/source_en/GetStarted/Quick-start.md:11`
  — the same feature-list sentence in the Quick-start guides. This is the one addition
  beyond the 5 lines planned in #10477: without it, the identical sentence would read
  differently in the READMEs and in Quick-start.
- `docs/source/GetStarted/SWIFT-installation.md:162` — ZH installation table:
  `华为 Ascend NPU` → `Huawei Ascend NPU`, matching the EN table above it.
- `docs/source/Megatron-SWIFT/Ascend.md:1,3`, `docs/source_en/Megatron-SWIFT/Ascend.md:1,3`
  — page title and the first sentence under it.

AI assistance was used to prepare this change; I reviewed every changed line and the
scope decisions above are mine.
