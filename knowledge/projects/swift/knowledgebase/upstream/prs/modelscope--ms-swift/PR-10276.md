# fix(megatron): defer full-vocabulary GKD teacher logits to forward_step

[Upstream PR](https://github.com/modelscope/ms-swift/pull/10276) · state: open · merged: False

## Original PR description

## Summary
- When `gkd_logits_topk` is unset, defer local teacher full-vocabulary logits to `forward_step` so only one `[S, V]` tensor is alive per micro-batch instead of one per rollout batch during preparation.
- Extract `_compute_teacher_output_local` for single-micro-batch teacher forwards; keep top-k teacher outputs eager at batch prep (small tensors).
- Add regression tests for defer vs eager paths and JIT computation in `forward_step`.

Fixes #10097
