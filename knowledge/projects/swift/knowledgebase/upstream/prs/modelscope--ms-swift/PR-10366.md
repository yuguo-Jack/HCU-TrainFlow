# PR information

Refs #8109

Mixing retrieval and classification data currently forces one global InfoNCE negative policy. Add optional infonce_config to DatasetMeta/custom_dataset_info for use_in_batch_negatives and hard_negatives, and batch each logical data source separately across all data-parallel ranks. Evaluation uses the same isolation; per-batch options reuse the existing InfoNCE implementation without changing process environment variables. Sources without opt-in keep the existing loader and loss path.

The sampler pads each source tail within that source (or drops it with drop_last); strict fetching prevents fallback into another source. Mixed datasets may represent absent negative_messages as null, which is now handled as no explicit negatives. Cross-rank configuration mismatches are rejected before optional embedding gathers. Streaming, group_by_length, sequence parallelism and Megatron are outside this minimal implementation. Paired English/Chinese documentation explains these constraints.
