# PR information

## What
Add SFT support for MiniCPM-V-4.7-1B and MiniCPM-V-4.7-35B-A3B with `transformers>=5.18.0`.

## Changes
- Reuse the 4.6 loader/template and register both 4.7 models.
- Adapt Canvas M-RoPE, mixed image/video inputs, and MoE/ZeRO-3 training.
- Keep packing/padding-free disabled.

## Validation
Both models passed 8-GPU SFT smoke tests in 4x/16x mode (2 optimizer steps per run), checkpoint reload/generation, native parity checks, and lint.
