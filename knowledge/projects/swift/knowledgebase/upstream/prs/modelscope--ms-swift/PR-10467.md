# PR information

Fixes #10465

Native evaluation fails with EvalScope 1.11.0 because `EvalType.SERVICE` was removed. Prefer `EvalType.OPENAI_API` when available, and retain the `SERVICE` fallback for older constant interfaces. This preserves the existing URL evaluation workflow.

Add regression tests using the installed EvalScope TaskConfig for Native backend dispatch, explicit/default API keys, preserved configuration, and the legacy SERVICE-only interface. Update the Chinese and English evaluation docs.

AI assistance: Codex assisted with implementation, tests, and this description. I reviewed the changes and personally reran the focused tests, dependency checks, and full-repository pre-commit locally. Supplementary compatibility and CPU CLI checks reported below were run with Codex assistance.
