# PR information

Full-vocabulary GKD fills the shorter model output with the other model's tail logits before softmax. This makes the loss depend on arbitrary logit offsets: with student `[0, 0]`, teacher `[0, 0, 0]`, temperature 1 and beta 0.5, adding 4 to every student logit changes the JSD from approximately 0 to 0.113680578 without changing either model's original distribution.

Keep unequal output widths supported by comparing the shared token-ID prefix `[0, min(student_vocab, teacher_vocab))`. Each model is normalized independently over that prefix before KL/JSD. Equal-width inputs bypass the alignment callback and keep the existing calculation. Extra tail logits do not enter this distillation objective, and student tail gradients are zero. This assumes matching token identities in the shared prefix; it does not implement cross-tokenizer mapping. When the extra entries are real tokens, the mismatch branch explicitly compares distributions conditioned on the shared vocabulary.

For Megatron and Ray, unequal TP partition widths give local columns different global token IDs. The mismatch branch gathers the wider side with autograd support and repartitions it onto the smaller side's global token ranges. Alignment runs inside the existing row chunks to bound the temporary gather size. Equal-width shards do not add communication, and the top-k path keeps its existing gather.

This PR changes only four production files. Regression checks were run locally without adding or modifying repository test files.

## Experiment results

- Existing `python -m pytest tests/train/test_gkd_loss.py -q`: **5 passed, 24 subtests passed** on CPU.
- Differential compatibility check: **144 cases** covering FP16/BF16/FP32/FP64, beta 0/0.5/1, temperatures 0.5/1/2, matching full vocabularies, top-k and empty positions. Loss, valid-token count and student gradients are bitwise identical to unmodified upstream on these unchanged paths.
- Temporary local regression checks: **6 passed, 54 subtests passed**, covering both mismatch directions, independent logit shifts, reference KL/JSD values and gradients, masking and empty positions in FP32/FP64. The original cross-model-padding implementation fails 18 of these subcases.
- Temporary CPU/Gloo checks at TP sizes **1, 2 and 4**: both mismatch directions and beta 0/0.5/1 match the unsharded reference in loss and full student gradients. The checks use production helpers, adapting only Megatron rank/group discovery and imports to the Gloo process group.
- `uvx pre-commit run --all-files`: passed.
- `git diff --check`: passed.

The full Megatron/CUDA runtime and model-training performance were not evaluated.
