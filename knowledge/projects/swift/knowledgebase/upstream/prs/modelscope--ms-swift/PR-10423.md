# PR information

Related issue: none. This addresses the GSPO + entropy filtering combination documented in [FAQ Q28](https://github.com/modelscope/ms-swift/blob/484e836d691a52fd8c1723137ee3d64c6e066683/docs/source/Instruction/Frequently-asked-questions.md#L210-L211).

With `importance_sampling_level="sequence"` and `top_entropy_quantile < 1`, the entropy mask removes per-token loss elements, but the remaining elements still depend on every completion logprob through the shared sequence importance ratio. Consequently, low-entropy tokens excluded by the mask can still receive direct policy gradients.

I keep the importance ratio computed from the full completion and reuse the existing GSPO-token gradient expression when an entropy mask is active. Its forward value remains the sequence ratio, so clipping still uses the same sequence-level value; each token's policy loss now differentiates through that token's logprob, allowing the existing entropy mask to select the intended gradient contributions.

The change is limited to the ordinary GRPO and Megatron loss methods: two production files, six added lines and two removed lines. GSPO without entropy filtering keeps its original gradient path. The existing token and sequence-token modes are unchanged, and KL remains outside entropy filtering. For vanilla GSPO with constant per-sequence advantages, the corrected policy gradient is the unfiltered GSPO gradient with the excluded token contributions removed. When token advantages or detached token weights vary, entropy filtering uses the existing GSPO-token gradient semantics explicitly through this branch.

## Experiment results

For two five-token completions with advantages +1 and -1, current policy equal to old policy, `beta=0`, and an entropy mask keeping only the first token of each completion:

| Positive-advantage completion | Before | After |
| --- | --- | --- |
| Selected token's logprob gradient | -0.02 | -0.10 |
| Each excluded token's logprob gradient | -0.02 | 0 |
| Nonzero logprob gradients across both completions | 10/10 | 2/10 |

Both scalar losses are zero because the two advantages cancel. The negative-advantage completion has the opposite gradient signs.
