## Summary

`encode_sample()` now resolves the rollout response prefix through
`get_response_prefix_ids()`, which calls `template._get_response_prefix()`. The local
`_FakeTemplate` in `tests/utils/test_opsd_teacher_images.py` predates that call, so four
teacher-image tests fail on `main` with:

```text
AttributeError: '_FakeTemplate' object has no attribute '_get_response_prefix'
```

This adds the missing hook to the fake template and returns `None`, matching a template without a
custom response prefix. Production code is unchanged.
