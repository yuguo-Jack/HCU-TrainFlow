# PR information

This adds ABKD as a loss in GKD, so users can try a broader family of distillation objectives within the existing training loop. Add these options to a GKD command:

```bash
--loss_type abkd \
--abkd_alpha 0.2 \
--abkd_beta 0.7
```

ABKD brings forward KL, reverse KL, and the alpha- and beta-divergence families into a unified two-parameter framework. The parameters adjust how the loss emphasizes teacher-student probability mismatches and the student's confidence—the hardness-concentration and confidence-concentration effects studied in our paper. This gives users more control over how probability mass is allocated during distillation.

A relevant use case is Alibaba Security AGI Lab's [XekRung technical report](https://arxiv.org/html/2605.00072v1#S4.SS1.SSS2), which adopts ABKD in place of traditional KL for on-policy distillation of compact models. The student generates responses online and learns from the teacher's token-level distributions along those trajectories, which fits ms-swift's GKD workflow.

I'm Guanghui Wang, the first author of [ABKD](https://proceedings.mlr.press/v267/wang25dz.html) ([ICML 2025 Oral](https://icml.cc/virtual/2025/oral/47175), top 1.0% of submissions). I'll maintain this integration and address review feedback.

The loss lives in the shared GKD module and is wired into HF, Megatron, and Ray. It reuses the existing masks, temperature, token chunks, and teacher top-k handling. The pointwise loss saves just the two log-probability tensors for its analytic backward. Full-vocabulary tensor parallelism uses the existing distributed normalization plus a vocabulary reduction. The JSD defaults stay the same, and the two ABKD parameters are independent of the existing `beta` option. English and Chinese docs include the configuration and top-k semantics.

## Experiment results

All 89 tests pass, including 79 cases that run on CUDA:

- 74 CUDA loss/gradient checks against an independent implementation of the paper's definition, covering FP32/BF16, full vocabulary and top-k, masking, temperature, zero-parameter limits, negative parameters, and vocabulary alignment.
- 5 real GKDTrainer runs on CUDA: JSD/ABKD with student-generated responses, plus ABKD with Liger, top-k, and an auxiliary SFT loss. Each checks the loss and gradients against separate model forwards, completes three optimizer steps, and verifies that the student updates while the teacher stays frozen.
- 4 two-process CPU/Gloo vocabulary-shard checks, the CLI-to-trainer configuration check, and the 5 existing GKD regression tests.

Tested with PyTorch 2.8.0 (CUDA 12.8), Transformers 5.19.0, TRL 0.29.1, and Liger 0.8.4.

```bash
python -m pytest tests/train/test_gkd_loss.py tests/train/test_abkd_loss.py \
    tests/train/test_abkd_trainer.py tests/train/test_abkd_distributed.py -q
```

The full repository pre-commit checks pass as well.
