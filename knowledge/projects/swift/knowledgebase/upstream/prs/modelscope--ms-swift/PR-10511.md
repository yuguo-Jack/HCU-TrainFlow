# fix(glm5_next): set reasoning_effort_needs_thinking = False to match GLM-5.3-Flash release template

[Upstream PR](https://github.com/modelscope/ms-swift/pull/10511) · state: closed · merged: False

## Original PR description

## Summary of Changes
The GLM-5.3-Flash release template always includes the "Reasoning Effort" system line, but the `GLM5NextTemplate` in ms-swift was dropping this line unless thinking was enabled. This was because `GLM5NextTemplate` inherited `reasoning_effort_needs_thinking = True` from `GLM5_2Template`. The fix sets `reasoning_effort_needs_thinking = False` on `GLM5NextTemplate`, matching the behavior of `GLM5_3Template` and ensuring the reasoning effort line appears in all training rows.

## Motivation & Context
Closes #10506

The issue caused a 20% difference in training loss during the first three steps of SFT on GSM8K. With the fix, the tokens match the release rendering on all 384 rows in all three settings (default, REASONING_EFFORT=low, and REASONING_EFFORT=low with enable_thinking=True).

## Verification
The fix can be verified by running the reproduction script provided in the issue. The output should show that the ms-swift encoding matches the release template encoding for all three settings.
