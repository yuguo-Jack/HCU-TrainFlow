# PR information

This PR adds MiniCPM-OCR-1.0 support for model loading and supervised fine-tuning.

Changes:

- Register the `minicpm_ocr` model type and chat template.
- Reuse the MiniCPM-V 4.6 model loader and multimodal processing.
- Default to 4x visual token compression, configurable through `DOWNSAMPLE_MODE`.
- Preserve the model’s thinking and non-thinking prefixes, including support for `--add_non_thinking_prefix true`.

Requires a Transformers build containing the `minicpm_ocr` implementation.

Validation:

- Completed full-parameter SFT on 8 × A100 GPUs with BF16 and DeepSpeed ZeRO-2.

When downsample_mode is 4x, use_vit_merger is false, so vit_merger receives no gradient.

```
# modeling_minicpm_ocr.py: MiniCPMOcrModel.get_image_features
downsample_mode = downsample_mode or self.config.downsample_mode
use_vit_merger = downsample_mode != '4x'          # 4x -> False
vision_output = self.vision_tower(..., use_vit_merger=use_vit_merger)
```

We recommend either freezing vit_merger when downsample_mode is 4x, or adding it to model._ddp_params_and_buffers_to_ignore (as MiniCPMVLoader does for resampler.pos_embed).
