## Summary

`check_json_format` handled only Python scalars and standard containers, then fell back to `obj.__dict__` for anything else. NumPy scalars (`np.float32`, `np.int64`, `np.bool_`) and arrays have no `__dict__`, so writing eval metrics such as the InfoNCE `mean_neg` / `mean_pos` values to `logging.jsonl` raised:

```text
AttributeError: 'numpy.float32' object has no attribute '__dict__'
```

This converts NumPy scalars with `.item()` and `np.ndarray` with `.tolist()`, then recurses through `check_json_format`, so nested arrays end up as plain Python values that `json.dumps` accepts. Non-NumPy values keep their previous behavior.
