# PR information

Depends on https://github.com/modelscope/twinkle/pull/367; merge that first.

twinkle's `TransformersModel` now balances the DP workload by default. This PR adds a switch for it:

- `TrainConfig.dp_balance` (default `True`); `--dp_balance false` turns it off.
- `builders/model.py` passes it to the twinkle `TransformersModel` constructor.
