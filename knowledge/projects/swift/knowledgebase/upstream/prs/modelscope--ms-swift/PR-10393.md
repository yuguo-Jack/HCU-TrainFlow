# PR information

This PR brings Megatron's existing dense/expert parallel divisibility checks forward into Swift's training argument processing. Invalid configurations receive actionable errors before the output-directory process-group initialization, while backend defaults and normalization behavior are preserved.

### Changes

- Add a lightweight preflight helper and invoke it at the start of `MegatronSftArguments.__post_init__`; pretraining and RLHF inherit the same entry point.
- Check `WORLD_SIZE % (TP * PP * CP) == 0` and `WORLD_SIZE % (ETP * EP * PP) == 0` when the global size is known.
- Match Megatron Core's `ETP=None` fallback to TP without rewriting the argument object. Omitted parameters keep their existing Swift defaults.
- Preserve existing world-size resolution: initialized default process group first, then WORLD_SIZE / _PATCH_WORLD_SIZE, with empty strings treated as unset. Defer the preflight for Ray drivers and processes without a reliable global size.
- Explain the offending values, product, remainder, and why ranks cannot form equal-sized dense/expert groups. Arithmetic type/zero-division failures receive context while retaining the original exception as the cause.
- Add bilingual documentation and regression tests.

### Compatibility boundaries

The preflight introduces no independent Python-type, sign, boolean, DP/Expert DP, or VPP restrictions. Derived DP remains backend-owned; VPP follows existing pipeline-layout normalization and is not an extra physical world-size factor. Other validation remains with the existing parser and backend. Passing this preflight does not establish that a raw input, model, topology, or training run is valid.

The change applies to Megatron SFT/PT/RLHF. The default Transformers backend and Megatron export entry point do not call this new training preflight. It adds no batch-size or model-structure checks and does not initialize communication.

### Example

For effective arguments `WORLD_SIZE=8, TP=3, PP=1, CP=1`:

```text
ValueError: Invalid Megatron parallel configuration: world_size (8) must be divisible by tensor_model_parallel_size (3) * pipeline_model_parallel_size (1) * context_parallel_size (1) = 3. Remainder: 8 % 3 = 2; ranks cannot be partitioned into equal-sized dense parallel groups.
```

With `WORLD_SIZE=8, TP=2, ETP=None, EP=4, PP=1, CP=1`, ETP resolves to 2 for checking, and the configuration passes these two rules. The original ETP=None value remains available for the backend to resolve.
