# PR information

Related issue: none. Found by code inspection and reproduced with constructed CPU calibration data.

Decision-model calibration fits `fold_head_t[fold]` and `fold_relative[fold]` on records outside `fold`, but then scores that fold with the entries for `1 - fold`. The reported out-of-fold ECE, Brier and NLL therefore use temperatures fitted on the scored records. Index both temperatures by the held-out fold instead.

Add regression coverage using the real Brier and NLL solvers, soft targets with analytic optimal probabilities, multiple question kinds per record, non-contiguous record IDs, and padded options. Document the existing small-sample fallback in both languages. The production temperatures fitted on all evaluation data and the fallback behavior are unchanged.
