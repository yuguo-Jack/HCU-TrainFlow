# PR information

Refs #10405 for the dynamic-chunking context. This fixes a separate teacher-field omission and does not claim to resolve the entire issue.

Dynamic-sample GRPO batches lose teacher_per_token_logps when the loss batch is
split into chunks. The rebuilt GRPOBatch defaults that field to None, silently
skipping the SDAR auxiliary loss despite teacher scores being available upstream.
Slice the teacher scores with the other per-sample signals, preserving None for
batches without a teacher. Add tests and paired documentation without changing
loss formulas, normalization or chunk weights.

AI assistance was used for implementation and validation. The human owner explicitly approved publication; human review and responsibility remain required.

Tested base: `1152aa7947238e11e7555b08195da4f93e290bf2`; candidate: `b13705a82b0a2fed7a999d3483c2b0091f660fcd`. No new runtime dependency.
