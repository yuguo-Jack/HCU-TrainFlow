# PR information

Fixes #10258.

`unwrap_model_for_generation` removed DeepSpeed ZeRO-3 optimizer hooks before yielding the model, but restored them only after a normal context exit. If generation raised, the model remained without those hooks even when the caller caught the error.

Wrap the yielded generation scope in `try/finally` so `add_hooks(model)` always runs. The original generation exception still propagates.

## Experiment results

- Before the fix, the regression test failed because the observed event sequence omitted `add-hooks`.
- `python -m pytest tests/utils/test_unwrap_model_for_generation.py -q`: 2 passed.
- Repository pre-commit hooks on both changed files: all passed (`flake8`, `isort`, `yapf`, whitespace, EOF, merge-conflict, and line-ending checks).

## Review and AI assistance

AI assistance was used for source review, implementation, and test drafting. Before submission, the human submitter manually reviewed every changed line and approved the behavior and test scope.

## Scope and risk

The production change is limited to exception-safe cleanup in the existing ZeRO-3 branch. Normal-path ordering remains `remove_hooks` -> generation -> `add_hooks`, and the test covers both normal and exceptional exits.
