# PR information

Refs #10314

One input sequence can predict several independent attributes with different label counts and loss functions. Add an opt-in --seq_cls_heads configuration to the existing generation-to-sequence-classification conversion: independent linear heads share pooling/backbone and combine weighted mean CE, BCE and MSE losses. Training labels and inference predictions are dictionaries keyed by head name; ordered configuration and head weights survive full and LoRA checkpoints. Existing single-head behavior is preserved.

This minimal implementation requires labels for every head and supports the ordinary Transformers conversion path with sequence_parallel_size=1. Missing-label masking, Megatron and alternative inference backends are outside this change. English and Chinese argument documentation is updated.

## Experiment results

Integration training was measured on main `fbc61cf2` plus this feature before rebasing onto `4dc1e2ad`. The intervening upstream commits add MiniCPM-V-4.7, a version bump, NPU documentation and a decision-loss fix; they do not change this feature's training paths. Focused tests and `pre-commit run --all-files` were rerun on the final submission. The final review also aligns multi-label decoding and metrics at zero logits, using logits directly to avoid sigmoid rounding near 0.5. Boundary tests pass in FP32, FP16 and BF16; loss, head initialization and label encoding are unchanged. Real CPU TransformersEngine checkpoint inference was rerun and stable over three repeats.

- python -m unittest discover -s tests/train -p test_seq_cls_heads.py -v: 5 passed, including FP64 value/gradient reference, gradcheck and FP32/FP16/BF16 decision-boundary coverage.
- pre-commit run --all-files: passed.
- Offline random Qwen2 (345472 parameters), FP32, Ascend 910B4-1, 12 optimizer steps: full multi-head eval loss 0.946539 -> 0.409688; LoRA 0.946539 -> 0.586215. Every head and backbone had finite nonzero gradients and parameter updates.
- Full/LoRA checkpoint self-reload output error: 0. Real TransformersEngine predictions were stable over 3 repeats.
- Step-6 resume to step-12: same recorded final loss; output difference from uninterrupted training 1.19e-7 on NPU.
- Default-path paired CPU 12-step training produced exactly equal checkpoint tensors. NPU default-path output difference was 2.38e-7, versus 4.77e-7 in same-main repeated training.
- These tiny-model checks establish functionality, not pretrained-model quality or throughput. No CUDA/multimodal/quantization validation is claimed.
