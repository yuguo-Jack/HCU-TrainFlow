# PR information
Add an Ascend LoRA training example for StartLux decision checkpoints using SWIFT's existing Qwen3.5 dense/MoE loaders and trainer. The example preserves the official prompt renderer, trains soft cross-entropy over legal candidate letters at the last prompt position, and freezes the original backbone, vision tower and vocabulary head. It exports ordinary PEFT adapters rather than a new model architecture.

Attention LoRA is the default; an optional language-linear scope also covers supported feed-forward projections while excluding vision and the vocabulary head.

The paired evaluator reloads an adapter, disables it for the baseline, verifies case-level split separation and scores original hard labels. The README includes the container, dependency pins, train/resume commands and the distinction between domain accuracy and seven-suite accuracy. FSDP validation runs after model and optimizer preparation.

## Experiment results
- `python -m unittest discover -s tests/trainers -p "test_startlux*.py" -v`: 8 CPU tests passed, including structured JSON evidence, language-linear LoRA isolation and a real two-process FSDP2 checkpoint regression.
- Changed-file `pre-commit` checks passed.
- Real StartLux-4B on Ascend: forward/backward, finite loss and gradient norms, optimizer updates, adapter save and full checkpoint state restore were exercised. An independent paired validation pass reloads the exported adapter.
- StartLux-35B-A3B: four-device FSDP completed real forward/backward, finite updates and checkpoint save. Two 64-GB devices cannot hold the current NPU FP32 master-weight preparation.
- The recipe uses sharded FSDP2 training checkpoints and a separate full PEFT inference export. The original pinned full-state adapter save/restore path fails the two-process numerical regression; sharded save/reload passes it. A two-device 4B NPU audit exactly matched all 304 restored adapter tensors before the next update. Continued training is not claimed bitwise equivalent; corrected 35B checkpoint-format validation remains pending. Old full-state checkpoints are rejected for FSDP resume.
- No seven-suite accuracy improvement is claimed. Fine-tuning quality remains a separate held-out evaluation gate; private records and experiment measurements are not included here.
