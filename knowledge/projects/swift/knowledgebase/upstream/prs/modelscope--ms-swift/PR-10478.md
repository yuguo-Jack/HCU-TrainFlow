# PR information
Fixes #10429

When encoding multi-turn samples whose generated assistant token sequences do not already contain the non-thinking response prefix, `replace_assistant_response_with_ids` previously restored that prefix only for the final assistant turn. Earlier turns consequently lacked the template prefix in the training input.

Apply the supplied response prefix independently to every generated assistant turn and assign zero loss to inserted prefix tokens. Preserve an already present, zero-masked prefix and keep sampled token values and their loss masks intact.

This change uses the sample-level prefix supplied by the training encoder. It does not introduce per-turn template metadata or support for changing the response prefix between turns.
