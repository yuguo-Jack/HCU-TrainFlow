# PR information

Fixes #10444

Kimi-VL video requests currently fail with `TypeError: 'NoneType' object is not iterable` during template encoding. Expand videos into timestamped image frames using the [official Kimi-VL cookbook](https://huggingface.co/blog/moonshotai/kimi-vl-a3b-thinking-2506#video-understanding), then reuse the existing image processor and image feature path.

The expansion preserves mixed image/video order, formats timestamps as `HH:MM:SS`, and sends frames to vLLM as images. Defaults match the cookbook: `VIDEO_FPS=1` and `VIDEO_MAX_SIZE=448`. The model registration advertises video support.
