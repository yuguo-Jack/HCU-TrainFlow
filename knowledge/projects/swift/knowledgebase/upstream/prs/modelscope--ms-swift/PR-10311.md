# fix: adapt colocate weight sync and sleep to vLLM 0.28+ API changes

[Upstream PR](https://github.com/modelscope/ms-swift/pull/10311) · state: closed · merged: True

## Original PR description

Upgrading to vLLM 0.31 broke GRPO LoRA colocate sync and R3 (router-replay) startup:

- vLLM [#39935](https://github.com/vllm-project/vllm/pull/39935): BaseLayerWithLoRA now owns load_weights, so sync names must be raw (drop the .base_layer. suffix); adapt add_base_layer_suffix_by_param_names with a runtime probe, keeping the legacy suffix for older vLLM.

- vLLM [#45635](https://github.com/vllm-project/vllm/pull/45636): sleep(level>=1) resets the prefix cache and the AuxOutput connector requires a prior pause(mode='keep'); route engine sleeps through vllm_sleep()/vllm_sleep_async() with a signature-probed fallback.

- vLLM [#53106](https://github.com/vllm-project/vllm/pull/53106): WeightsMapper.get_unstacked_mapper was renamed to get_rename_mapper; accept both in patched_load_adapter().
