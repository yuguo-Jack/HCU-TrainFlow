![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Using an internal PyTorch testing utility (`torch.testing._internal.distributed.fake_pg`) is risky as it's not part of the public API and can be changed or removed without warning in future PyTorch versions. This could break the fake process group functionality. It would be safer to find an alternative from the public API or vendor the necessary code if possible. If no alternative exists, this dependency should be clearly documented as a potential point of failure.
