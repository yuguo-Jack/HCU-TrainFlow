# PR information

Fixes #10466

`load_dataset` evaluates `get_seed(seed)` before calling `init_decision_augment`, even when augmentation is disabled and the initializer immediately returns. This advances a shared NumPy RandomState and changes downstream split/shuffle behavior.

Only initialize decision augmentation (and draw its seed) when `decision_augment_config is not None`. Keep the enabled augmentation path unchanged.

Add local-JSONL regression coverage for train/validation row order and subsequent RNG draws across split/no-split and shuffle/no-shuffle cases, plus an enabled JevPreprocessor augmentation control. Update both Chinese and English decision documentation.

AI assistance: Codex assisted with implementation, tests, and this description. I reviewed the changes and personally reran the focused tests, dependency checks, and full-repository pre-commit locally.
