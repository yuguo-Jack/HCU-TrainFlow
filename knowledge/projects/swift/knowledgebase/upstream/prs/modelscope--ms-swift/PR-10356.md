# PR information

Clarify the NPU local installation steps by separating environment preparation, ms-swift installation, and runtime setup.

The PyPI release and source installation are explicitly documented as **choose one**: use the PyPI release for regular use, or install from source if you need the latest code from the `main` branch or want to modify the source. After completing either option, proceed to the next step. This helps beginners avoid running both installation methods.

Also update the `triton-ascend` installation command. The Chinese and English documentation are updated consistently.
