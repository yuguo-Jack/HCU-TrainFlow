## Original PR description

# What does this PR do?

Fixes #5940.

Adds an optional `revision` to each Hugging Face dataset entry in `dataset_info.json` and forwards it to `datasets.load_dataset`. It accepts a branch, tag or commit SHA; omitting it preserves the default. Native Hugging Face Datasets cache behavior is unchanged.

Includes English and Chinese configuration docs and real CPU data-loading regressions using two published dataset commits with 298 and 300 records. The tests support the existing cold/online and warm/offline CI cache modes.

- Data-loader tests: online 6 passed; warm offline 5 passed, 1 network-only case skipped.
- `UV_NO_SYNC=1 PYTEST_ADDOPTS='-c pyproject.toml' make test`: 344 passed, 25 skipped, 3 xfailed, 4 xpassed.
- `make license` and `make build`: passed.
- Pre-commit on all six changed files: passed.
- Full `make quality` fails on pre-existing W293 at `src/llamafactory/model/patcher.py:486`. Full `make commit` also reports existing formatting in `data/template.py`, `data/tool_utils.py` and `v1/plugins/model_plugins/kernels/ops/rms_norm/supa_rms_norm.py` (under `src/llamafactory/`).
