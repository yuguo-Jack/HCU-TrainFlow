# fix(data): paste transparent images onto white background when converting to RGB

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10928) · state: open · merged: False

## Original PR description

# What does this PR do?

Fixes #10887

## Summary
When transparent images (`RGBA`, `LA`, `PA`, or palette `P` with transparency metadata in `image.info`) are converted directly using `convert("RGB")`, Pillow discards the alpha channel without compositing over a background. In PNG assets, transparent background pixels typically store `(0, 0, 0)` under the alpha mask, causing transparent regions to turn solid black. For diagrams, math charts, document scans, and UI screenshots featuring dark drawings or black text on a transparent background, this turns the entire image black-on-black and renders features invisible to vision-language models.

This PR introduces a `to_rgb()` helper that detects transparency, composites transparent images onto a clean white background (`(255, 255, 255)`), and returns RGB:
- Checks if `image.mode in ("RGBA", "LA", "PA") or "transparency" in image.info`
- Converts to `"RGBA"`, pastes onto a white `RGB` canvas using `image.getchannel("A")` as alpha mask
- Leaves non-transparent images or standard RGB images untouched
- Applied in `BasePlugin._preprocess_image` (used across all multimodal plugins and vLLM engine) and `_process_request` in `src/llamafactory/api/chat.py`
- Added unit tests in `tests/data/test_mm_plugin.py` covering RGBA, LA, palette with transparency, and RGB passthrough.
