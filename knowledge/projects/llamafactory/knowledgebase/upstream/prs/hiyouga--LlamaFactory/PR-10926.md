# [data] avoid mutating Qwen video frame inputs

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10926) · state: open · merged: False

## Original PR description

# What does this PR do?

Keep Qwen2-VL and Qwen3-VL video preprocessing from modifying a caller's list of frames.

When a video is supplied as an odd-length list of images or image paths, `Qwen2VLPlugin._regularize_videos` pads it by appending the last frame directly to that list. Qwen3-VL inherits the same behavior. Reusing a five-frame video at 2 fps changes the final Qwen3-VL prompt timestamp from `<2.0 seconds>` on the first pass to `<2.2 seconds>` on the second; repeated supervised preprocessing also produces different input IDs. Copy the list before padding so its contents and subsequent timestamps stay stable.
