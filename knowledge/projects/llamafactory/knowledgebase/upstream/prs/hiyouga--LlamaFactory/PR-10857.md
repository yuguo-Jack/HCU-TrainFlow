## Original PR description

# [deps] upgrade vllm to 0.28.0

# What does this PR do?

Fixes # (issue)

Raises the vLLM version ceiling from `<=0.11.0` to `<0.29.0` so the vLLM inference backend can be used on Intel XPU.

vLLM only publishes prebuilt Intel XPU wheels from 0.28.0 onwards, so every XPU build is rejected by the current check:

```
  File "src/llamafactory/hparams/parser.py", line 272, in _check_extra_dependencies
    check_version("vllm>=0.4.3,<=0.11.0")
ImportError: vllm>=0.4.3,<=0.11.0 is required for a normal functioning of this module, but found vllm==0.28.0+xpu.
```

### Changes

- `src/llamafactory/hparams/parser.py`: `vllm>=0.4.3,<=0.11.0` → `vllm>=0.4.3,<0.29.0`
- `requirements/vllm.txt`: same

No code changes are needed; `vllm_engine.py` works unmodified with 0.28.0.

### Testing

Intel Arc Pro B60, Python 3.12.13, vllm 0.28.0+xpu, torch 2.13.0+xpu, transformers 5.8.0.

```bash
llamafactory-cli chat examples/inference/qwen3.yaml infer_backend=vllm
```

| | Result |
|---|---|
| Before | `ImportError` above |
| After, 1 card | correct response |
| After, 2 cards (tensor parallel) | correct response |

Not tested on CUDA.
