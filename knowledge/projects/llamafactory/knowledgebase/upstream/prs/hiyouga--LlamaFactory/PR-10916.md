# [v1] Fix custom model export with FSDP2

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10916) · state: closed · merged: True

## Original PR description

# What does this PR do?

FSDP2's generated wrapper class causes save_pretrained() to copy PyTorch internal code and write an incorrect auto_map, preventing exported custom models from being reloaded.

For example, Ling's auto_map["AutoModelForCausalLM"] is incorrectly saved as:
  _fully_shard.FSDPBailingMoeV3ForCausalLM

The correct value points to the original model module and class:
  modeling_bailing_moe_v3.BailingMoeV3ForCausalLM

Temporarily restore the original model class during HF export and restore the FSDP2 wrapper in a finally block. Cover both final model saves and optional HF checkpoint exports.
