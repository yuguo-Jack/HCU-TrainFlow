[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10924) · state: open · merged: False

## Original PR description

# What does this PR do?

Add opt-in `drop_long_samples: true` for SFT datasets. Examples whose complete encoded length exceeds the effective cutoff are skipped before truncation, preserving complete answers for reasoning and math datasets. The length includes all conversation turns, template/multimodal tokens, and the final EOS. Ordinary SFT, packing, and neat packing share this behavior; packing keeps its existing one-position reservation. The default retains truncation.

Fixes #3995.

Fully filtered preprocessing batches return an explicit empty input column so both regular and streaming dataset mapping can skip them correctly. The examples guide documents the option.

Validation on Windows CPU, Python 3.12.13:

- 31 new regression cases: unchanged code gives 28 failed / 3 passed; the fixed processor/packing selection gives 49 passed. The Transformers 4.57.6 targeted combination gives 42 passed.
- Offline integration covers all 8 combinations of packing, streaming, and dropping. Real local JSON loading, alignment, tokenization, training/evaluation datasets, multiprocessing preprocessing, and a tiny GPT2 forward/loss pass; complete retained answers are checked.
- Full `pytest --import-mode=importlib tests/ tests_v1/ -q --maxfail=3`: 373 passed, 24 skipped, 4 xfailed, 3 xpassed, 1 failed. The failure is `test_fsdp2_save_pretrained_uses_original_model_class` because Windows Torch 2.7.1+cpu lacks `torch.distributed.HashStore`. The identical failure was reproduced on unchanged `9997aa07` in the same environment.
- All applicable pre-commit hooks and changed-file Ruff lint/format pass.
