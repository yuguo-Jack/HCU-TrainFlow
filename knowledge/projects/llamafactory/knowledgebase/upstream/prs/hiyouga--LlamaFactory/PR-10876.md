# [xpu] support profiler, module profiler and env report on Intel GPU

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10876) · state: open · merged: False

## Original PR description

# What does this PR do?

Fixes # (issue)

Adds Intel GPU support to three observability features that currently only handle CUDA and NPU:

- `enable_torch_profiler`: also record XPU activity. Today the trace on Intel GPU has CPU ops only.
- `profile_modules`: use `torch.xpu.Event` on XPU. Today it is disabled with "no supported accelerator".
- `llamafactory-cli env`: print XPU type, number, memory and driver version.

### Changes

- `src/llamafactory/train/callbacks.py`: add `ProfilerActivity.XPU` and the XPU event/synchronize functions.
- `src/llamafactory/extras/env.py`: add an XPU section, mirroring the CUDA one.
- `tests/train/test_callbacks.py`: new tests for the three features.

### Testing

**Intel Arc Pro B60** (torch 2.14.0+xpu, transformers 5.8.0)

- New tests: 3 passed
- Full suite: 345 passed (`main`'s 342 plus the 3 new tests)
- Profiler trace from a LoRA SFT run now includes XPU activity: 1,629 kernel events

**NVIDIA A100 80GB** (torch 2.13.0+cu130, transformers 5.8.0)

- New tests: 3 passed
