## Original PR description

# What does this PR do?

Add MiniCPM-OCR-1.0 supervised fine-tuning support.

- Register the model, `minicpm_ocr` reasoning template, and visual-module mappings for freezing and LoRA target selection.
- Reuse `MiniCPMV4_6Plugin` for the OCR processor's default 4x compression and support the native non-thinking prefix.
- Preserve supervised-token loss normalization under gradient accumulation for MiniCPM-OCR. Other models, including MiniCPM-V 4.6, retain the existing loss guard.

The native OCR loss accepts `num_items_in_batch`. Exempting OCR from the blanket `model_accepts_loss_kwargs = False` override lets Trainer normalize over all supervised tokens in the accumulation window. This avoids giving short answers disproportionate weight when microbatch answer lengths differ. Regression tests compare both accumulated loss and gradients against token-normalized cross-entropy.

The loss test uses `Trainer.get_batch_samples`, which is available in the supported older Transformers versions. The PR also contains two whitespace-only fixes required by the full-repository formatting checks. It contains no mock-data generator, local training configuration, or experiment documentation.

Dependency: an OCR-enabled Transformers implementation is required; a sufficiently high version number alone does not provide the architecture. Its installation currently requires opting out of the repository's conservative version check with `DISABLE_VERSION_CHECK=1`; this PR does not broaden the global dependency bounds. 

AI assistance was used for implementation and validation; attribution is included in the commits.

## Validation

```bash
pre-commit run --all-files
make style && make quality
make license
python -m build --no-isolation
MINICPM_OCR_MODEL_PATH=/path/to/MiniCPM-OCR-1.0 \
  CUDA_VISIBLE_DEVICES='' DISABLE_VERSION_CHECK=1 HF_HUB_OFFLINE=1 \
  python -m pytest -q \
    tests/data/test_minicpm_ocr.py \
    tests/train/test_minicpm_ocr_loss.py
```

- Full-repository pre-commit, Ruff 0.15.5, formatting, license, and wheel/sdist build checks passed.
- OCR-enabled Transformers 5.19.0.dev0: 8 tests passed, including native processor equivalence, non-thinking supervision masks, visual-module selection, and accumulated loss/gradient equivalence.
- Stock Transformers 4.55.0, 4.57.1, and 5.8.0: each passed 7 tests with the optional local OCR processor test skipped. These checks do not imply native OCR support in those releases.
- Full `make test` was attempted offline and stopped after five missing-test-fixture errors for `llamafactory/tiny-random-Llama-3`. The same five failures were reproduced on the unmodified upstream baseline. The full suite and multi-platform/GPU CI are not claimed to pass locally.

Full-parameter SFT was also validated on RIMES using 10,138 unique training samples, 8 A100 GPUs, BF16, DeepSpeed ZeRO-2, LR 5e-6, and three epochs. The best validation checkpoint was selected at epoch two. All 778 official test samples were evaluated with 4x compression, non-thinking mode, greedy decoding, and batch size 8.

| Model | CER ↓ | WER ↓ |
| --- | ---: | ---: |
| MiniCPM-OCR-1.0 | 5.67% | 15.78% |
| Fine-tuned model | 2.98% | 7.66% |

Metrics use complete predictions and annotation-free references. No output reached the generation length limit.
