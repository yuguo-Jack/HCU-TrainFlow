# [npu] Skip unnecessary gradients in NPU fused MoE backward

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10918) · state: closed · merged: True

## Original PR description

# What does this PR do?

Avoid unnecessary gradient computation and memory allocations in NPU fused MoE kernels when expert weights are frozen, such as during LoRA training.

Honor `ctx.needs_input_grad` in stacked and list-backed grouped matmul to save only tensors needed for backward and compute only the required gradients. Preserve input gradients so upstream trainable layers continue to receive gradients.
