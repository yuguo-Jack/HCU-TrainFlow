# fix(webui): quote POSIX command preview arguments

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10909) · state: open · merged: False

## Original PR description

# What does this PR do?

Quote POSIX shell arguments in the Web UI's command preview. Copying the preview currently splits scalar paths and list elements containing spaces, removes the quotes from JSON options, and interprets shell characters in values. Quote each scalar, list element, and serialized JSON object so the copied command receives the values entered in the UI.

Four regressions execute the generated command with a shell function that captures its arguments without starting training. They fail on the original base and pass with the fix. All applicable pre-commit hooks and Ruff checks pass for the changed files. Full hooks reproduce two existing formatting failures at the same base in `model/patcher.py` and `v1/plugins/model_plugins/kernels/ops/rms_norm/supa_rms_norm.py`.
