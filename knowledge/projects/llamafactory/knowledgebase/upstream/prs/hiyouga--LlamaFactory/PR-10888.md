# [data] composite transparent images on a white background

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10888) · state: open · merged: False

## Original PR description

# What does this PR do?

Fixes #10887.

`_preprocess_image` called `convert("RGB")` on RGBA, LA and transparent-palette images, which dropped the alpha channel without a background, so transparent pixels came out black and black lines on them vanished. It now composites such images onto a white background first. The API server in `api/chat.py` no longer converts to RGB as soon as it opens an image (it calls `load()` instead, so the stream is still read right away), so the same handling applies to images sent there. White matches what vLLM and lmms-eval do for transparency.

The new tests cover RGBA, LA and transparent-palette PNGs and fail on main at the background pixel (0 != 255). `tests/data/test_mm_plugin.py`: 18 passed, 2 skipped.

This fix was written with an AI coding agent pipeline and reviewed before I opened this PR.
