# [feature] add support for CIG-SFT loss

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10895) · state: open · merged: False

## Original PR description

## What does this PR do?

Refs #10894.

This PR adds opt-in CIG-SFT support to the existing Transformers SFT path. Before optimization, a frozen reference model runs teacher-forced forward passes on the original task input and an erased-input view, using the same gold response prefix. The conditional probability of each gold response token is read from both views; their log-probability difference is converted into a detached token credit that weights the SFT loss.

## Included in this PR

- full-parameter and freeze fine-tuning for text-only, single-turn SFT;
- dataset-level `cig_erased_prompt` and per-example `erased_prompt`;
- credit materialization with rank-sharded cache reuse;
- reference-model placement through the existing DeepSpeed and FSDP helpers;
- validation for configurations that are outside the current two-view implementation: packing, streaming datasets, multimodal erased views, non-standard backends, LoRA/OFT, prompt-token training, and masked-history training;
- an example YAML file, English and Chinese documentation, and unit tests;
- the standard SFT path remains available when `use_cig_sft_loss` is false.
