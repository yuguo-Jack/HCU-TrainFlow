# [CI] Remove internal cache-service references

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10914) · state: open · merged: False

## Original PR description

## Motivation

Our self-hosted Ascend CI runners access public package sources through a cluster-level squid caching proxy. The old internal `nginx-pypi-cache` mirror (`cache-service.nginx-pypi-cache.svc.cluster.local`) is being retired, so this PR removes its references from the NPU test workflow.

## Changes (`tests_npu.yml`, -6)

- Drop the "Set nginx-cache for Ascend CI" step: the APT source rewriting (`cache-service :8081`) and the `pip config set global.index-url / trusted-host` lines
- The following "Install uv" step is unchanged

## Test plan

- `grep -r "cache-service\|nginx-pypi-cache"` over the repo returns nothing
- The workflow parses as valid YAML
