## Original PR description

# What does this PR do?

Adds one line to the "Start cloud training" list in README.md: CloudGPU, which has a ready-made LLaMA-Factory template (web UI plus root SSH) on rented NVIDIA GPUs such as the RTX 4090, RTX 5090 and A100, billed by the minute. It gives users without a local GPU one more way to start LLaMA-Factory without installing anything.

Disclosure: I work on CloudGPU. It is a paid service, so I did not tag it "free" like the other entries. The link has no referral or affiliate code, only standard UTM tags so we can see how many visits come from this README. Happy to switch to a plain https://cloudgpu.app/marketplace link, reword the entry, or close this PR if paid providers don't belong in this list.
