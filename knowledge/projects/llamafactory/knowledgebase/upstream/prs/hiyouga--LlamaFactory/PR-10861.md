# [webui] add an optional modern layout for LLaMA Board (LLAMABOARD_UI=modern)

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10861) · state: closed · merged: False

## Original PR description

# What does this PR do?

Adds an **opt-in**, redesigned layout for LLaMA Board. The classic UI stays the default and is not changed;
set `LLAMABOARD_UI=modern` to try the new one:

```bash
LLAMABOARD_UI=modern llamafactory-cli webui
# Windows PowerShell: $env:LLAMABOARD_UI="modern"; llamafactory-cli webui
```

### What users get (only with `LLAMABOARD_UI=modern`)

- **Sidebar navigation** with pages (Model / Train / Evaluate & Predict / Chat / Export) instead of tabs; it collapses
  to an icon rail (Ctrl+B) and can be resized by dragging.
- **Two visual styles** ("Crisp" and "Soft"), each with a **light and a dark mode**, switched in the browser and remembered.
- The classic rows are grouped into **titled cards**; on Train and Evaluate the **run panel** (start / abort, progress,
  loss plot, logs) stays pinned on the right.
- **Model overview** on the Model page: architecture of the selected model (read from `config.json` in a local directory
  or the Hugging Face cache, never downloaded, with a few presets as fallback) and a strip showing which layers the
  chosen method trains (full / freeze / LoRA / QLoRA).
- **Relevance hints**: advanced groups show their current values in the header, and groups or fields that do not apply
  to the current stage / method / model are dimmed. Nothing is hidden or disabled, and no value is changed.
- **Banners** when a selected option needs a package that is not installed (DeepSpeed, GaLore, APOLLO, BAdam,
  vLLM / SGLang, gptqmodel, unsloth, liger-kernel, and jieba / nltk / rouge-chinese for BLEU / ROUGE), and when PPO is
  selected with a TRL version outside `0.8.6 <= trl <= 0.9.6`.
- **Command palette** (Ctrl+K) to jump to pages and parameters, and a live run indicator in the sidebar.
- **Responsive**: at <= 1360 px the run panel moves below the form; at <= 900 px the sidebar becomes a top bar.

### How it is built

- `src/llamafactory/webui/modern/` reuses the classic components unchanged: `create_top`, `create_*_tab` and
  `create_footer` build every control, default value, callback and the runner, and `Engine.resume` /
  `Engine.change_lang` are wired exactly as in `create_ui`. No training, inference, evaluation or export logic is
  duplicated.
- The containers those factories create are re-parented into cards before the `gr.Blocks` context exits
  (`layout.py`). Gradio binds events by component id, so callbacks are unaffected. After the moves the build checks
  that every managed component is still in the tree exactly once and raises otherwise; a component the layout does
  not know about (for example one added to a tab later) stays visible in a fallback area instead of being lost.
- Styling is a Gradio theme that maps Gradio variables to CSS tokens, plus one stylesheet. Gradio injects custom CSS a
  second time with a `.gradio-container… .contain` prefix and re-emits `@media` blocks only in that prefixed form, so
  `cssutil.py` anchors selectors at `html` and rewrites `@media` blocks into `html[data-lf-mq~=…]` rules that the small
  browser script keeps in sync with `matchMedia`.
- No new dependencies. The modern layout requires Gradio 5 and says so with a clear error; the classic UI keeps its
  current Gradio range.
- Shell texts in five languages: en / zh complete, ru / ko / ja cover navigation and headings and fall back to English
  elsewhere. Parameter labels still come from `locales.py`.

### Files

- New: `src/llamafactory/webui/modern/` (`interface.py`, `layout.py`, `cssutil.py`, `theme.py`, `strings.py`,
  `model_info.py`, `assets/style.css`, `assets/app.js`)
- Changed: `src/llamafactory/webui/interface.py` (environment switch in `run_web_ui`), `README.md` and `README_zh.md`
  (one line each)
- Tests: `tests/webui/test_modern_layout.py` (builds the modern UI, which fails if a component is lost or duplicated,
  and checks the CSS rewrite)
