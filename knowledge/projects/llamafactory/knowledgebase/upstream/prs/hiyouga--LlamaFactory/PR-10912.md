# [train] fix ollama modelfile export crash for dict-slot templates

[Upstream PR](https://github.com/hiyouga/LlamaFactory/pull/10912) · state: open · merged: False

## Original PR description

# What does this PR do?

Refs #9650

`export_model` writes the Ollama `Modelfile` after the merged model and tokenizer are already saved. For templates that use dict-valued slots (chatglm3 and yuan), `template.get_ollama_modelfile` raises `ValueError: Dict is not supported.`, so the export exits with an error and leaves an empty `Modelfile` behind.

This change renders the Modelfile before opening the file. If rendering raises `ValueError`, it logs a warning and skips the Modelfile, so the export completes with the weights and tokenizer. Templates that can be rendered behave as before. This removes the crash; it does not produce an Ollama Modelfile for chatglm3 or yuan.

Notes for review:
- The `except` covers any `ValueError` from `get_ollama_modelfile`. Today only the dict-slot path raises it.
- If `export_dir` already contains a Modelfile, it is left as is.
- Rendering dict slots for Ollama would be a fuller fix, but it needs a maintainer decision, so this PR only avoids the crash.
