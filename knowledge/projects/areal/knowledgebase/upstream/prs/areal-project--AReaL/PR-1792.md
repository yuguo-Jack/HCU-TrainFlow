# feat(engine): support native Flash-Next MTP-only SFT

[Upstream PR](https://github.com/areal-project/AReaL/pull/1792) · state: open · merged: False

## Original PR description

Qwen3.8 Flash-Next checkpoints (`qwen4_exp`) need a native Megatron-Bridge provider for MTP-only SFT. Add the provider and fixed-length text recipe, freeze the backbone and PLE table before distributed wrapping and optimizer construction, and preserve frozen PLE/vision payloads during HF export.

Pass the original token-domain supervision mask to native Megatron-Core MTP. Acceptance tools check independent parameter/optimizer ownership, frozen buffers, complete HF payload bytes, fresh-process recovery and nonempty parity observations. Reject non-MTP-only export when it would discard trained PLE updates.

Pinned main remains `1683e8e8fba70e296b4238aa3c2300defd192f17`. Current corrective commit `9dd7fad177bda6ace8ba31b5fdc85fd5667d6de0` follows `80e3dad3b4a043dd2a831b564390c89c87f3a190`. Preserve upstream DTE import relocation, unified AWEX adapter APIs, R3 behavior, optimizer checkpoint wrappers and padded concatenation. No config schema or dependencies were added.

The full-model parity job981550 failed before any numerical forward: the SFT dataloader returns a list of sample dictionaries, while the parity helper assumed a batched dictionary. Normalize with the same shared `concat_batch` used by production SFT before truncating every sample to512 tokens. Preserve all four samples and the required32 rank-summed comparisons. Baseline and fresh-process recovery paths are unchanged.

- Previous source0185566e:22 actual Python3.6 host tests and512 container tests. Optional AWEX adapter tests were not run because the fixed image lacks `awex.util.cuda_ipc`; this SFT recipe does not initialize those adapters.

Full-model acceptance is pending: full-source TP8/PP2/EP8/CP1 numerical parity with32 nonempty rank-summed observations, complete source HF roundtrip, five real16K updates with semantic freeze and optimizer isolation, save-after4/fresh-process restore and fifth-update comparison, and complete trained HF export. Job981550 is a failed attempt, not acceptance evidence. The correction uses a new immutable source/runtime and fresh chain; preparation is not a runtime result. Keep this PR a draft until the full chain passes.

Scope: CP1 fixed-length text SFT with native MTP-only updates. Large MoE/PLE allocations require the full16-GPU topology. User-specific resource scripts, runtimes, checkpoints and credentials are outside this PR.
