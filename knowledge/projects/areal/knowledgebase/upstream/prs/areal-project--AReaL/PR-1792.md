# feat(engine): support native Flash-Next MTP-only SFT

[Upstream PR](https://github.com/areal-project/AReaL/pull/1792) · state: open · merged: False

## Original PR description

Qwen3.8 Flash-Next checkpoints (`qwen4_exp`) need a native Megatron-Bridge provider for MTP-only SFT. Add the provider and fixed-length text recipe, freeze the backbone and PLE table before distributed wrapping and optimizer construction, and preserve frozen PLE/vision payloads during HF export.

Pass the original token-domain supervision mask to native Megatron-Core MTP. Acceptance tools check independent parameter/optimizer ownership, frozen buffers, complete HF payload bytes, fresh-process recovery and nonempty parity observations. Reject non-MTP-only export when it would discard trained PLE updates.

Current source `80e3dad3b4a043dd2a831b564390c89c87f3a190` directly parents pinned main `1683e8e8fba70e296b4238aa3c2300defd192f17`. Preserve upstream DTE import relocation, unified AWEX adapter APIs, R3 behavior, optimizer checkpoint wrappers and padded concatenation. The provider and entire MTP examples tree are unchanged from the previously validated source. No config schema or dependencies were added.

Validation on the current source:
- Full pre-commit passed.
- 8 selected CPU concat tests passed, covering padding, ordering, dtype and the new fast path.
- Fixed-container affected regression: 79 tests passed across five files, plus DTE relocation/lazy AWEX import smoke (job981403, top-level/batch/main worker COMPLETED0:0). Image, dependency-content manifest and actual imported module versions/paths/hashes verified. Auxiliary environment-discovery steps1–4 are retained as CANCELLED0:116 in raw accounting; the main worker passed.
- Megatron expert confirmed the engine change exactly matches the upstream patch and found no semantic merge defect.

The previous source `0185566e` passed 22 actual Python3.6 host tests and 512 container tests; these results remain historical and were not relabeled as current-source tests. Optional AWEX adapter tests were not run in the fixed image because its AWEX API lacks `awex.util.cuda_ipc`; this SFT recipe does not initialize those adapters.

Full-model acceptance is still pending: full-source TP8/PP2/EP8/CP1 numerical parity with32 nonempty rank-summed observations, complete source HF roundtrip, five real16K updates with semantic freeze and optimizer isolation, save-after4/fresh-process restore and fifth-update comparison, and complete trained HF export. Sealed same-source stage packages are prepared, but preparation is not a runtime result. Earlier training on older source is historical evidence only. Keep this PR a draft until the full chain passes.

Scope: CP1 fixed-length text SFT with native MTP-only updates. Large MoE/PLE allocations require the full16-GPU topology. User-specific resource scripts, runtimes, checkpoints and credentials are outside this PR.
