# test(ppo): isolate score centering tracker in unit tests

[Upstream PR](https://github.com/areal-project/AReaL/pull/1881) · state: closed · merged: True

## Original PR description

## Description

Give the score-centering loss tests a fresh `DistributedStatsTracker` for each test. Earlier tests can leave `n_valid_tokens` data on the module-level tracker with a different tensor shape, causing the four score-centering cases to fail in the full suite even though their loss calculations are valid.

This addresses the unit-test failure observed in [PR #1840's vLLM CI job](https://github.com/areal-project/AReaL/actions/runs/41611884661/job/125845856873?pr=1840). Production metric collection and shape validation are unchanged.
