# fix(utils): exhaust port candidates without duplicate draws

[Upstream PR](https://github.com/areal-project/AReaL/pull/1815) · state: closed · merged: True

## Original PR description

## Description

`find_free_ports()` currently samples with replacement and stops after `count * 10` attempts. Repeated excluded or occupied candidates can exhaust that budget while eligible free ports remain, which can prevent callers from allocating their service or launcher ports. This patch selects an independent random start and visits each candidate in the configured range at most once, stopping as soon as enough ports are found.

The implementation keeps allocation independent of the training RNG and preserves sorted results. A genuinely exhausted range still raises `ValueError` after all eligible candidates have been checked.
