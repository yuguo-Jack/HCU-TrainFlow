# fix(engine): backport SM90 GDN decode padding protection

[Upstream PR](https://github.com/areal-project/AReaL/pull/1806) · state: open · merged: False

## Original PR description

## Description

Backport [sgl-project/sglang#44014](https://github.com/sgl-project/sglang/pull/44014)
as an explicit AReaL source patch for SM90 FlashInfer GDN decode.

With padded decode CUDA Graphs, `cache_indices` contains `-1`. The SM90
Python gather/scatter path treats it as the last real state-pool slot.
Padded lanes can therefore overwrite live or cached recurrent state,
causing intermittent corrupted output in subsequent generation.

The backport passes the full pool and int32 indices to FlashInfer's indexed
decode API. It preserves the SM100+ branch, prefill and MTP code. It uses
AReaL's existing atomic, locked source-patch installer, validates input/output
hashes, refuses unknown sources, and is idempotent.

Apply **before starting servers**, in the SGLang interpreter:

```bash
python -m areal.engine.sglang_gdn_decode_padding
```

A disposable source copy can be checked without local GPU dependencies:

```bash
python -m areal.engine.sglang_gdn_decode_padding --target /path/to/gdn_flashinfer.py
```

**Runtime boundary:** installed application requires a separately provisioned
FlashInfer >= 0.6.18 runtime. AReaL currently pins SGLang 0.5.10.post1 with
FlashInfer 0.6.7.post3; that older FlashInfer is rejected before any write.
This PR does not change dependency pins or auto-enable the patch. Source
hashes cover SGLang 0.5.10.post1, 0.5.20 and the original upstream PR base
module, with the same SM90 fix adapted to their different call sites.
