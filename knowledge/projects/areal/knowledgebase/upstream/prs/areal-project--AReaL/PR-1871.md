# perf(megatron): Backport chunked logits optimizations to Ascend

[Upstream PR](https://github.com/areal-project/AReaL/pull/1871) · state: closed · merged: True

## Original PR description

## Description

Backport upstream Megatron LM-head and training memory optimizations to Ascend, reducing memory usage during vocabulary projection and loss computation.

This includes chunked LM-head loss, logits-storage reuse, optional FP32 projection operands, CP-safe vocabulary statistics, and TP gradient-norm fixes. The backport also includes Ascend/MindSpeed adaptations, profiling examples, updated CLI references, and NPU CI coverage.

The optimized path is opt-in through `megatron.enable_chunked_logits`, with sequence chunking controlled by `megatron.lm_head_loss_chunk_size` and FP32 projection operands controlled by `megatron.enable_fp32_lm_head`.

Backports #1460, #1497, #1562, #1574, #1555, and #1594.
