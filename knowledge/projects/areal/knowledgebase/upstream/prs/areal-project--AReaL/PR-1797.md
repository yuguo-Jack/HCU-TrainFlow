## Description

Add opt-in Score Centering (SC) to the vLLM-to-FSDP training path, using an additive correction to reduce off-policy drift in the actor update. Carry sampler top-k probabilities through rollout assembly, packing, and loss computation, with configuration validation and diagnostic metrics. Fix causal-mask construction for non-Qwen3 models using eager attention with packed sequences. SC is disabled by default; the attention-mask fix applies independently.

## Additional Context

### Score Centering

SC corrects policy-gradient drift between the sampler distribution `q` and trainer distribution `p`. For the sampler's top-k token set `H`, the trainer evaluates probabilities on the same token IDs and approximates the remaining sampler tail by rescaling the trainer tail:

```text
p_mass = sum_{v in H} p(v)
q_mass = sum_{v in H} q(v)

rho   = max(1 - q_mass, eps) / max(1 - p_mass, eps)
w(v)  = weight_fn(p(v) / q(v))
alpha = rho * weight_fn(1 / rho)

correction = sum_{v in H} stop_gradient(q(v) * w(v) - alpha * p(v)) * log p(v)
```

Tail masses use `eps = 1e-6` for numerical stability. Invalid top-k slots contribute zero mass. The residual coefficients are detached, so gradients flow through trainer log-probabilities only. On-policy, when `p = q`, the correction and its gradient vanish.

| `sc_mode` | `weight_fn(r)`                                          | Behavior                         |
| --------- | ------------------------------------------------------- | -------------------------------- |
| `none`    | `1`                                                     | Pure SC                          |
| `tis`     | `min(r, sc_clip_high)`                                  | Truncated importance weighting   |
| `mis`     | `r` inside `[sc_clip_low, sc_clip_high]`, otherwise `0` | Band-masked importance weighting |

`tis` requires a finite upper bound. `mis` requires finite, ordered bounds with a nonnegative lower bound and a positive upper bound.

#### Actor objective

SC uses an advantage-weighted REINFORCE objective with an additive centering term:

```text
loss_pg = reduce_valid_tokens(
    -stop_gradient(advantage) * log p(sampled_token)
    + stop_gradient(advantage) * correction
)
```

Reduction follows the configured policy-gradient aggregation. Setting `sc_reinforce_baseline=True` with SC disabled selects pure REINFORCE. Both paths replace the initially computed PPO surrogate; PPO statistics remain available for diagnostics. Configurations with both flags disabled retain the existing PPO objective.

#### Data flow and implementation

```text
vLLM top-k log-probabilities
    -> HttpGenerationResult / ModelResponse
    -> generation-chunk accumulation
    -> RLVR / OpenAI-compatible interaction assembly
    -> padding, microbatch splitting, and packing
    -> next-token alignment
    -> trainer log-probability gather
    -> SC correction and actor loss
```

- Propagate `sc_top_k` to generation requests and raise vLLM's `max_logprobs` cap as needed.
- Preserve top-k tensors through batching and packing, shifting them by one position to align with trainer logits.
- Pad absent log-probabilities with `-inf` to preserve zero probability mass, with finite-value sanitization in actor preprocessing.
- Inject trainer logits into the loss inputs only when SC is enabled.
- Use chunked log-softmax/gather autograd with numerical promotion to bound the additional normalization workspace.
- Record correction, `s_bar`, head masses, tail-mass ratio, correction loss, and gather/correction timings.

### Attention-mask fix

The non-Qwen3 branch of `_prepare_mb_list` previously passed:

```python
attention_mask = dict(full_attention=None, sliding_attention=None)
```

The Transformers Qwen2 implementation treats this dictionary as a prepared mask mapping and bypasses causal-mask construction. Eager attention consequently permits future-token attention and cross-sequence attention in packed batches.

The fix passes `attention_mask=None` for both packed and padded microbatch inputs. Transformers then constructs the causal mask and identifies packed sequence boundaries from resetting `position_ids`. The Qwen3 branch is unchanged.

### Experimental results

The experiment compares **REINFORCE + SC versus REINFORCE**, each with `recompute_logprob` on and off, over a 1,000-step training schedule.

- **Model:** Qwen2.5-1.5B-Instruct
- **Task:** GSM8K with GRPO-style advantages
- **Training:** FSDP, bf16, eager attention
- **Hardware:** Ascend 910 NPU
- **Software:** vLLM 0.23.0 and Transformers 5.5.4

| Group  | `use_score_centering` | `sc_reinforce_baseline` | Policy-gradient objective        |
| ------ | --------------------- | ----------------------- | -------------------------------- |
| SC-on  | `True`                | `False`                 | `-A * log p(a) + A * correction` |
| SC-off | `False`               | `True`                  | `-A * log p(a)`                  |

The masking fix reduces training–inference mismatch and improves top-k agreement.

### Configuration and compatibility

| Setting                       | Default | Purpose                                  |
| ----------------------------- | ------- | ---------------------------------------- |
| `actor.use_score_centering`   | `False` | Enable SC                                |
| `actor.sc_top_k`              | `128`   | Fallback top-k request size              |
| `actor.sc_mode`               | `none`  | Weighting mode                           |
| `actor.sc_clip_low`           | `0.0`   | Lower band bound for `mis`               |
| `actor.sc_clip_high`          | `inf`   | Upper bound for `tis` and `mis`          |
| `actor.sc_reinforce_baseline` | `False` | Pure REINFORCE baseline with SC disabled |

Generation-side `sc_top_k` controls the request size, with the actor setting providing a fallback. SC requires stochastic sampling, positive temperature, valid `top_p`, and zero frequency penalty. A bounded sampling `top_k` must cover the SC head.

The integration targets **vLLM + FSDP**. Unsupported combinations include Ulysses sequence parallelism with `sp_size > 1`, tree training, and `chat_template_type='concat'` multi-turn interactions with parent trajectories. VLM-specific top-k filtering is not included.

Missing SC inputs produce a warning and retain the existing loss path. Combining SC with `recompute_logprob=True` also emits a warning. Shared log-probability padding and attention masking affect SC-disabled paths as well as SC-enabled training.
