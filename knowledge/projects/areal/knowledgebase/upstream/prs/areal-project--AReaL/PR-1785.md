# feat(trainer): add composable actor loss objectives

[Upstream PR](https://github.com/areal-project/AReaL/pull/1785) · state: open · merged: False

## Original PR description

## Description

Add `actor.losses` for composing token objectives with independent support masks, reductions, and coefficients. Built-in policy, entropy, and MOPD objectives share an explicit callable contract with custom plugins.

An empty mapping preserves the existing actor objective. Each named term inherits `actor.loss_aggregation` unless it specifies its own reduction. The new `turn_mean` reduction averages supported-token means over active turns; existing token, sequence, prompt, and constant reductions remain available.

The implementation reuses the existing optimizer-step reduction contract and response-level schedule. Prompt groups can span optimizer steps, each term retains its original normalization support, and empty terms contribute differentiable zeros. MOPD continues to use immutable behavior log-probabilities. English and Chinese documentation cover configuration precedence, mask alignment, extension contracts, and compatibility limits.

## Related Issue

Depends on #1784 and uses the named-loss engine contract introduced by #1782. This PR targets the advantage-pipeline branch from #1784 so its diff contains only the loss changes; it will be retargeted to `main` after #1784 merges. No dedicated issue is associated with this change.

## Additional Context

The main review areas are per-term denominator isolation, prompt normalization across optimizer steps, prediction-aligned masks, and MOPD configuration precedence. Named coefficients replace implicit objective composition; MOPD settings still determine target and advantage preparation.

Explicit named objectives do not support legacy single-teacher `teacher_logp` or forward-dependent M2PO selection. Their existing unnamed paths remain available. Efficiency presets and separate process-reward routing are outside this PR.
