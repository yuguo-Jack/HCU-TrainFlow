# fix(utils): restore policy versions without an inference engine

[Upstream PR](https://github.com/areal-project/AReaL/pull/1841) · state: closed · merged: False

## Original PR description

## Description

`RecoverHandler.load(..., inference_engine=None)` restores model and optimizer state but leaves training engines at their initial policy version. Restore `last_global_step + 1` on every loaded training engine before returning, so training-only callers observe the checkpoint policy version. The existing inference weight-transfer handshake is unchanged.

## Validation and limitations

A paired real Megatron GPU checkpoint/optimizer restore using the same saved step observed policy version 0 before this change and the expected version 2 afterward. Both exported models matched all 311 source tensors (751,632,384 elements) exactly. A separate native v1 training-only replay integration fixture also matched an uninterrupted three-step run exactly after saving one step and restarting for the remaining two: all 311 checkpoint tensors at every step, precise loss/gradient/LR, and policy versions 0/1/2 matched. That integration fixture belongs to the trajectory-replay feature; this PR contains only the shared recovery correction and its focused tests.

Added two focused cases to the existing recovery suite for a single engine and an actor/critic mapping. Unit tests were prepared but not run by the agent; CI must execute them. Existing inference-handshake tests remain applicable. The native v2 `GatewayTrainController` recovery restriction is unchanged. No documentation or dependency changes are needed for this correction.

Full pre-commit checks passed in an isolated copy; the commit also passed the installed hooks. A source-level pre-publication review checked the recovery path and existing test seams; the formal PR/CI review remains pending.
