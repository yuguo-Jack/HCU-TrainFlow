# test(engine): adapt FSDP tests to support Intel GPUs (XPU)

[Upstream PR](https://github.com/areal-project/AReaL/pull/1833) · state: closed · merged: True

## Original PR description

## Description

This PR follows #PR1, which adds Intel GPU (XPU) support. Some existing FSDP tests still skip or fail on Intel GPUs because they use CUDA-specific device checks, tensor placement, or the NCCL backend.

This change makes those tests use AReaL's selected platform:

- `tests/test_fsdp_grad.py`: use `current_platform.device_type` for accelerator tensors and skip accelerator-dependent tests when the selected platform is CPU. This covers gradient norms, gradient clipping, and consistency between CPU-offload and accelerator paths.
- `tests/torchrun/run_fsdp_optimizer_dtype.py`: initialize the process group with `current_platform.communication_backend` instead of hardcoded NCCL.
- `tests/test_train_engine.py`: check that `eval_batch` returns a tensor on the selected platform's device type instead of requiring `is_cuda`.

This PR changes only tests and test helpers. On CUDA, the tests run the same checks with the same numerical tolerances, while the affected tests can now also run on XPU.
