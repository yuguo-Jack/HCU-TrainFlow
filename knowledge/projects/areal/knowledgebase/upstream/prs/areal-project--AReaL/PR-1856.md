# fix(proxy): reject empty proxy interaction exports on Ascend

[Upstream PR](https://github.com/areal-project/AReaL/pull/1856) · state: closed · merged: True

## Original PR description

## Description

Reject empty interaction exports from inline/subprocess proxy workflows on Ascend by raising an error instead of returning `None`. This lets the existing grouped-rollout error handling reject the whole group rather than continue with only its remaining members. Online-mode behavior is unchanged.
