# fix: update AWEX for tied weights in Ascend Geometry3K tests

[Upstream PR](https://github.com/areal-project/AReaL/pull/1862) · state: closed · merged: True

## Original PR description

## Description

Fix the first AWEX weight update in the Ascend Geometry3K test, where Qwen3.5-0.8B's tied output head was omitted from inference parameters. Pin AWEX to `2bff8835beb287ca853a52d463b697a0e3da3e81` in both A2 and A3 images; this preserves tied-weight aliases in the Qwen3.5 vLLM parameter iterator.

Enable AWEX with NPU/HCCL settings in the Geometry3K config, retain bridge-based export configuration, reduce graph capture sizes to `[4, 8, 16]`, and remove the explicit GDN prefill backend override.
