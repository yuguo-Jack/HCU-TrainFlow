# build: refresh Ascend images for CANN 9.2 and vLLM 0.30

[Upstream PR](https://github.com/areal-project/AReaL/pull/1857) · state: closed · merged: True

## Original PR description

## Description

Refresh the A2/A3 images to CANN 9.2.1 and vLLM 0.30.0 with updated MindSpeed, Megatron adaptor, Transformer Engine NPU, vllm-ascend, Mooncake, and FLA-NPU pins. Adapt the inference server imports and enable the exact-token scale-out endpoint for vLLM 0.30.

Install pinned upstream AWEX compatibility fixes and preserve that installation during application dependency setup. Remove the redundant local AWEX shim and the content-parts patch now included in vLLM; retain and update the exact-token validation patch.

## Related Issue

Related to #1612 (exact-token generation compatibility).
