# fix(trainer): drain single-teacher RTensor input caches

[Upstream PR](https://github.com/areal-project/AReaL/pull/1800) · state: closed · merged: True

## Original PR description

## Description

In single-controller distillation, teacher scoring localizes rollout RTensors into each teacher worker's `_fetch_buffer`, but step cleanup omits the teacher. Actor cleanup deletes the source shards without releasing these process-local copies, so teacher memory grows across training steps.

Include the single teacher in step cleanup for both training and rollout teachers. Add `RolloutController.clear_batches()` to send deduplicated shard IDs to every worker without refetching inputs or deleting source storage. Wait for all worker drains before propagating a failure. CPU regressions exercise repeated training steps with real RTensor serialization, storage, and worker cache eviction.

## Related Issue

Follow-up to #1209, covering the single-teacher consumer cache.
