## Original PR description

## Description

Backport MiMo-inspired RL training diagnostics to Ascend, covering training–inference log-probability differences, KL estimates and ratio tails, policy-version staleness, and advantage sign distributions.

Use compact scalar summaries for token-weighted averages and global extrema, with HCCL/MegatronAdaptor compatibility to preserve distributed reduction results.
