# perf(trainer): add a critic-free GAE fast path for Ascend

[Upstream PR](https://github.com/areal-project/AReaL/pull/1858) · state: closed · merged: True

## Original PR description

## Description

GAE computation on Ascend currently iterates over tokens even when no critic is present. When both `discount` and `gae_lambda` equal 1, this recurrence simplifies to a masked reward-to-go.

This PR adds a reverse-cumulative-sum fast path for that case, avoiding per-token tensor operations while preserving the original recurrence for critic-based or discounted configurations. It also adds CPU and GPU/NPU regression coverage and connects the single-device NPU cases to CI.
