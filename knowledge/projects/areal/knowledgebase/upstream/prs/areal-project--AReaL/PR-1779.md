# feat(engine): reclaim retained AWEX activation storage

[Upstream PR](https://github.com/areal-project/AReaL/pull/1779) · state: open · merged: False

## Original PR description

## Description

AWEX training can retain MCore/Transformer Engine activation storage after backward, reducing GPU memory available for phase transitions. Add scoped activation tracking and release after the complete backward, while preserving model parameter and buffer storage.

Tracking is enabled only when the engine has AWEX weight residency. Ordinary training does not install the patches or scan/mutate activation storage.

Split from #1613 in response to the independent memory-lifecycle review request: https://github.com/areal-project/AReaL/pull/1613#discussion_r4244759121. This feature is not required by the staged AdamW algorithm.

This draft needs independent storage-ownership and selective-recompute review before merge. Large-model AWEX integration and multi-node behavior remain to be validated on this standalone branch.
