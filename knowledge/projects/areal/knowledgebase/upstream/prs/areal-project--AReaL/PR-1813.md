# fix(examples): report the correct tau2 message class

[Upstream PR](https://github.com/areal-project/AReaL/pull/1813) · state: closed · merged: True

## Original PR description

## Description

The pinned tau2-bench fork hardcodes `AssistantMessage` in a validation error defined on the shared participant-message base class. As a result, invalid user-simulator messages are reported as assistant failures. Patch the validator when the Tau2 example loads so the error names the concrete message class, while preserving tau2's existing validity rules.
