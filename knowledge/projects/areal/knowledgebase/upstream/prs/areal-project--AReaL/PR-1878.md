# perf(trainer): reuse proximal logprobs and add probability diagnostics on Ascend

[Upstream PR](https://github.com/areal-project/AReaL/pull/1878) · state: open · merged: False

## Original PR description

## Description

Add `prox_logp_method="reuse"` for decoupled PPO on Ascend to reuse detached log-probabilities from the training forward, avoiding an additional proximal forward pass. This requires `use_decoupled_loss=True` and `ppo_n_minibatches=1`, while preserving rollout correction and policy gradients.

Also add `rollout_probs_diff` to track absolute probability differences between rollout and proximal policies before loss filtering, covering recomputed and reused proximal log-probabilities. The default behavior remains unchanged.

## Related Issue

Related to #1453 and #1457. This PR adapts proximal logprob reuse for Ascend, retaining explicit validation that `ppo_n_minibatches=1`.
