# fix(engine): correct Bridge context-parallel loss scaling

[Upstream PR](https://github.com/areal-project/AReaL/pull/1788) · state: closed · merged: True

## Original PR description

## Description

Megatron-Bridge enables per-token loss normalization for Qwen3.5-family models with context parallelism, but AReaL returned a mean-loss callback without token counts. This left Megatron without the expected gradient normalization and amplified both the language-model and MoE auxiliary gradients. Return weighted loss sums and CP-deduplicated counts in per-token mode, compensate for the differentiable CP all-gather, and delegate mixed-precision loss scaling to the optimizer. Preserve the existing mean-loss and evaluation paths.

Also apply the configured MindSpeed auxiliary-loss coefficient and balancing type before finalizing the NPU Bridge provider, so an explicit zero is honored instead of the provider's auxiliary-loss defaults. Add CPU regressions for normalization, callback contracts, and provider configuration.
