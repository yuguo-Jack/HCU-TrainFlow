## Original PR description

## Description

Harden the offline Autopilot analyzer introduced in this PR. The analyzer now preserves observed trainer spans that lack `global_step` as explicit per-worker evidence, applies the actual `MicroBatchSpec` defaults, and validates nested FSDP settings and benchmark trial schemas before producing tuning candidates.

The analyzer requires the resolved `config.yaml` saved by AReaL after Hydra composition. It rejects source files with `defaults` or unresolved `${...}` interpolations so the report cannot silently describe a different configuration from the run.

## Additional Context

The report separates measured elapsed-time findings from follow-up hypotheses. A phase share includes only recognized spans with valid `global_step`; spans without one remain visible in a separate worker-local table and are not summed across parallel workers. Benchmark candidates are advisory synthetic SFT measurements and must be validated under the target RL workload. The CLI does not modify configuration, launch jobs, or add dependencies.
