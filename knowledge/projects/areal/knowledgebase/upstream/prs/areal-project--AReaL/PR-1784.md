# feat(trainer): add composable advantage computation

[Upstream PR](https://github.com/areal-project/AReaL/pull/1784) · state: closed · merged: True

## Original PR description

## Description

Introduce a composable advantage computation pipeline through `actor.advantage`. Users can override outcome reward shaping, temporal estimation, process advantage shaping, or the complete computation with a built-in implementation or a dotted callable and serializable arguments.

The default pipeline reuses the existing GAE kernels and preserves PPO, PRM, and MOPD behavior, logical rollout normalization, truncation handling, and optimizer scheduling. Existing PRM configuration remains supported; explicit advantage-stage settings take precedence.

Custom outcome shaping can provide logical reward references in the same units as the shaped rewards. Plugin results are validated for shape, device, dtype, finite values, binary masks, and permitted field updates. English and Chinese documentation describe configuration, extension contracts, and compatibility behavior.
