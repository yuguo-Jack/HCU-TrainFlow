# feat(engine): configure Qwen vision freezing and visual cache reuse

[Upstream PR](https://github.com/areal-project/AReaL/pull/1826) · state: closed · merged: True

## Original PR description

## Description

Qwen VLM actors now freeze the vision encoder by default, with explicit CLI overrides for the vision model, projection, and language model. AWEX reuses visual embeddings only when the live actor parameters prove the vision encoder is frozen; otherwise successful weight-update cache flushes invalidate embeddings. The first successful flush always clears old visual state.
