# fix(examples): enforce Countdown arithmetic rules without eval

[Upstream PR](https://github.com/areal-project/AReaL/pull/1876) · state: closed · merged: True

## Original PR description

## Description

Countdown currently gives full reward to expressions such as `1.5 * 2`, `7 // 2`, and `3**2*5-7` even though they violate the task's arithmetic rules. Exponentiation chains can also block reward computation.

Replace `eval` with a bounded AST parser and exact rational arithmetic. Validate the actual integer operands, including their multiplicities, and allow only `+`, `-`, `*`, `/`, parentheses, and unary signs. Fractional intermediate results remain valid. Invalid expressions retain the existing format reward, and answer extraction and score tolerance are unchanged. This uses only the Python standard library.
