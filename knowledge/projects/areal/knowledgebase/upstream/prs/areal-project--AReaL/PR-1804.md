# fix(engine): adopt MindSpeed's GDN backend selector

[Upstream PR](https://github.com/areal-project/AReaL/pull/1804) · state: closed · merged: True

## Original PR description

## Description

Fix Qwen3.5 GatedDeltaNet initialization in Ascend images without FLA-NPU by loading the selected MindSpeed GDN operators for FSDP and Megatron. Update the A2/A3 MindSpeed, MegatronAdaptor, and TransformerEngineNPU source pins, cap PyArrow below 26 for the image's NumPy 1.26 runtime, and require Trackio >=0.35.0 to avoid resolver backtracking to an obsolete release.
