# fix: preserve rollout rewards across Arena retries

[Upstream PR](https://github.com/areal-project/AReaL/pull/1882) · state: open · merged: False

## Original PR description

## Description

An Arena episode can retain a failed retry with reward `0` and a successful sibling with reward `r`. When all leaves already have scores, episode reward assignment returns without setting the logical rollout reference. Group normalization then aborts with `Split rollout row rewards differ; supply an explicit rollout_reward for reward normalization.`

Carry the explicit episode reference independently of branch reward propagation. Preserve branch returns, existing references and response validation; a failed terminal response sets the new reference to zero. Already-discounted returns cannot acquire a missing reference after the fact.

Core continuations can also finish with a model failure after earlier completed turns. Validate the complete terminal receipt and retain attributable failures as zero-reward samples. Infrastructure failures, inconsistent outcomes and stale session flags remain rejected. The continuation budget belongs to the runner; no fixed three-turn ceiling is imposed. Legacy diagnostics match the shared typed proxy error message when Core omits its error code.
