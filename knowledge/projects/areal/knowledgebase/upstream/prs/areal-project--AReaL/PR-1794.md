# fix(engine): include vLLM internal DP in weight update ranks

[Upstream PR](https://github.com/areal-project/AReaL/pull/1794) · state: closed · merged: True

## Original PR description

## Description

Fix weight-update process group ranks for `xccl` weight updates with
vLLM internal data parallelism.

For dense models, vLLM resets each EngineCore's DP rank and size, so
`get_world_group().rank` does not distinguish internal DP replicas.
Compute the rank from `data_parallel_index`, the replica world size,
and the worker rank, then apply the external server offset. This prevents
duplicate ranks across internal DP replicas while preserving external
server offsets.

Add regression cases covering external server offsets and internal DP
ranks. Mark the tests as requiring vLLM and skip when it is absent.
