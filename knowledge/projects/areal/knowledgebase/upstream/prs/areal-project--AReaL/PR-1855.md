# feat(engine): support FSDP TP/CP score centering with TIS

[Upstream PR](https://github.com/areal-project/AReaL/pull/1855) · state: closed · merged: True

## Original PR description

## Description

Extend the merged SGLang/FSDP score-centering path to FSDP tensor parallelism and Ulysses context parallelism, and add score centering with truncated importance sampling (SC + TIS) through the existing `rejection_sampling` configuration.

- Normalize sampled-token and sampler-head probabilities across vocabulary shards without gathering full-vocabulary logits.
- Pad and partition sampler heads with CP token inputs, use labels shifted before partitioning, and differentiably gather log-probabilities and corrections before removing padding.
- Use detached current-trainer/sampler weights for TIS and center the weighted scores. The sampled term uses `min(p/q, upper)`; the correction is not multiplied by that sampled weight again.
- Preserve unweighted SC when `rejection_sampling=null` and ordinary PPO behavior when SC is disabled.

This builds on merged #1817 and #1822. It contains no Megatron support, custom kernel, new dependency, or new YAML field. Full local logits remain live. FSDP pipeline parallelism remains unsupported.

## Configuration

```yaml
actor:
  use_score_centering: true
  recompute_logprob: false
  use_decoupled_loss: false
  rejection_sampling:
    level: token
    metric: ratio
    action: clamp
    upper: 2.0
    lower: null
```

Use the existing allocation syntax for TP/CP, e.g. `fsdp:d1t2c2` for four trainer GPUs. Model vocabulary size must divide evenly across TP ranks, in addition to the model's attention-head constraints. SC still requires native SGLang sampler heads, temperature 1, and no sampling truncation or penalties.

Only token-level ratio clamping with no positive lower bound is supported. The existing cap default remains unchanged. Allowing `lower=0` for clamp also makes its existing normalized configuration round-trip correctly; masking still rejects zero lower bounds. Invalid or nonfinite caps and unsupported rejection modes fail explicitly.

## Learning experiment: supplied Countdown plot

![Countdown noisy-sampler training accuracy, seed 0, noise 0.02: FSDP TP2/CP2 SC+TIS, earlier SC, and no-SC baseline](https://raw.githubusercontent.com/ActuallyEdward/AReaL/9f7c607814a68e9156747d5485e95a7736557212/examples/math/score_centering_tis_countdown_noise002.png)

This is **training accuracy** on each noisy rollout batch, not clean held-out evaluation or a seed-averaged result. Historical legend names mean:

- **Blue:** FSDP TP=2/CP=2, score centering with token TIS cap 2.
- **Green (`main-reference`):** the earlier score-centering run without TIS.
- **Orange (`main-pg`):** the earlier REINFORCE run without score centering.

The combined run completed 300 updates. It sustains learning and broadly tracks the earlier SC curve in this experiment, while the displayed no-SC run collapses. This supports the combined configuration's end-to-end operation; it does **not** establish that TIS improves on SC alone, numerical equivalence across layouts, or a speedup.

Setup follows the earlier paper-style Countdown fixed-weight-noise experiment: Qwen3-0.6B, seed 0, 64 prompts × 8 responses per update, 512 total tokens, temperature 1 without top-k/top-p truncation, top-128 sampler metadata, group-mean-centered ±1 rewards, and SGD at constant LR 0.01. A fixed perturbation `delta = 0.02 * initial_weights * Normal(0,1)` is applied only to sampler exports; the trainer uses clean weights.

This is not a controlled TIS-only ablation. The earlier runs used a single trainer GPU and manually tied embedding/output weights; the combined run used TP2/CP2 and the engine's untied parameterization. The learning run predates this upstream rebase; the extracted implementation is checked separately below. The supplied image is preserved unchanged, with no personal W&B links.
