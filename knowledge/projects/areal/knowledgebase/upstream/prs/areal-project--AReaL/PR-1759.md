# fix(examples): preserve tau2 user simulator tool history

[Upstream PR](https://github.com/areal-project/AReaL/pull/1759) · state: closed · merged: True

## Original PR description

## Description

Preserve the user simulator's assistant tool calls and matching tool results when forwarding tau2 conversation history to the OpenAI-compatible client. The previous user-specific cleanup removed both, so the simulator could not see its own tool observations on later turns. Keep the existing removal of `tool_calls: null` for API compatibility.

Add a focused regression test for the tool-call/result pair and input-message immutability.
