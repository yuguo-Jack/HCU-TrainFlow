# feat(trainer): add configurable loss aggregation for Ascend

[Upstream PR](https://github.com/areal-project/AReaL/pull/1816) · state: closed · merged: True

## Original PR description

## Description

Add configurable policy-gradient loss aggregation for Ascend training through `actor.loss_aggregation`:

- `token-mean`: average over valid tokens; remains the default.
- `seq-mean`: average per-response token means.
- `traj-mean`: average per-trajectory token means, counting multi-row agent rollouts once.
- `prompt-mean`: average per-prompt token means, pooling tokens across the prompt’s rollouts.
- `constant`: divide each response’s token-loss sum by `actor.loss_aggregation_divisor`, then average across responses.

Prepare complete trajectory and prompt weights before optimizer and forward microbatch splitting, and integrate the matching normalization with FSDP, Megatron, and Archon. Keep Megatron auxiliary losses normalized by their original token counts, and preserve the original policy-gradient denominator when token filtering narrows the numerator.

Preserve logical trajectory boundaries through rollout collection, compute GRPO reward statistics per trajectory, and include trajectory identifiers in rollout dumps. Update the CLI reference and add loss, gradient, grouping, and reward-normalization regression coverage.
