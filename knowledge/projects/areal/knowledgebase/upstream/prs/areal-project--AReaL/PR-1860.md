# fix(trainer): backport explicit trajectory truncation tracking

[Upstream PR](https://github.com/areal-project/AReaL/pull/1860) · state: closed · merged: True

## Original PR description

## Description

Backport #1637 (`cc21ab977`) to `ascend`. PPO currently treats trajectories that fill the dynamically padded batch width as truncated, so a shorter length-limited response can be classified as complete while the longest normally stopped response is classified as truncated.

Propagate `stop_reason == "length"` as per-trajectory `is_truncated` metadata for reward masking and `no_eos_ratios`, and bootstrap this branch's inline token GAE from each trajectory's final valid token. Strip the metadata before model forwards and retain the existing heuristic for custom workflows that do not provide it. Remove the CUDA variants of the reward-normalization tests for the NPU branch while retaining CPU coverage.

## Related Issue

Backport of #1637. No separate issue.
