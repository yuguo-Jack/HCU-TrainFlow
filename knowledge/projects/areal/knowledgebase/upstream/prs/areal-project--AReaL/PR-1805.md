# ci: add two-step Ascend Geometry3K training test

[Upstream PR](https://github.com/areal-project/AReaL/pull/1805) · state: closed · merged: True

## Original PR description

## Description

Add a sequential Geometry3K training smoke test to the existing eight-NPU Ascend PR job. Qwen3.5-0.8B runs two GRPO updates with Megatron and vLLM both using d1p2t2, followed by evaluation on one example and an HF checkpoint save. The test requires normal trainer shutdown, two completed steps, one completed evaluation, and readable checkpoint weights.

Use one prompt with four completions per update, 16–32 generated tokens, FULL_DECODE_ONLY graph decoding, and MTP with three speculative tokens. Reuse the cached model and Geometry3K dataset, download the dataset when missing, preserve the runner's HCCL interface setting, and upload controller/worker logs plus completion evidence. Existing Qwen3.5 tests remain enabled.
