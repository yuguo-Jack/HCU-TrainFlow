# Add initial support for GLM-5.2/5.3 models on Ascend

[Upstream PR](https://github.com/areal-project/AReaL/pull/1789) · state: closed · merged: True

## Original PR description

## Description

This PR adds support for GLM-5.2 on Ascend using **MindSpeed Bridge**.

GLM-5.2 requires asymmetric pipeline parallelism to properly distribute model layers across pipeline stages. MindSpeed Bridge provides the necessary support for this configuration, enabling GLM-5.2 training with AReaL on Ascend.
