# [WIP] Parquet optimizations

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/273) · state: closed · merged: False

## Original PR description

- The reader now keeps recently decoded row groups in-memory instead of decoding the whole row group for every single row access. LRU cache is keyed by `(file, row_group, column)` with same size as open-file cache.
- Each file's row-group start offsets are computed once when it is opened, and the right row group is found with bisect instead of a linear scan.
- `close()` empties the cache.
- On a 1M row-group file, reading 50 rows went from **2.56s to 0.05s**
- Added unit tests for behavior
