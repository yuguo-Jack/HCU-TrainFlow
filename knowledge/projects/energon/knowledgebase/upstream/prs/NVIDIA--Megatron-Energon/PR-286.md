# feat(flavors): add Parquet dataset format

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/286) · state: open · merged: False

## Original PR description

## Summary

Adds Parquet as a crude tabular dataset format.

## Changes

- New `flavors/parquet/` (`ParquetDatasetFactory`, `ParquetShardListDatasetFactory` and their
  `Default*` variants, reader, `FileStore`, footer scanning).
- A single `.parquet` file is loaded directly; a directory of Parquet files is prepared with
  `energon prepare <dir>` into a manifest dataset.
- `part_filter` maps to Parquet columns, so unused columns are never read.
- Filter indexes support Parquet shards and single files.
- New optional dependency group `parquet` (`pyarrow>=14.0.0`), included in `all`; `uv.lock`
  updated accordingly.
- Docs: *Steps to Create a Parquet Dataset*, on-disk format, `part_filter` table.

## Tests

- New `tests/test_parquet_dataset.py`; Parquet case in `tests/test_filter_index.py`.

## Validation

- Full unit test suite on this layer: 165 tests passed (CPU).
- `ruff check`, `ruff format --check`, license headers: clean.
- Sphinx docs build (`-E -a`): no warnings.
