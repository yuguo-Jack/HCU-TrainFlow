## Summary

Extends sequence packing in the task encoder.

## Changes

- **Pushback:** `select_samples_to_pack` may return `PackedSamplesOutput(packs, pushback)`;
  pushed-back samples are re-queued before the next buffer fill.
- **Partial samples:** `PartialSample(sample, slice)` lets a selector split a sample across packs
  (slice semantics are task-defined; `postencode_sample` / `pack_selected_samples` apply it).
- **Packing groups:** `TaskEncoder.build_packing_groups()` returns `PackingGroupConfig`s, each
  with its own packing/shuffle buffer; group streams are blended afterwards.
- **Streaming packing:** `packing_buffer_size="stream"` with `TaskEncoder.select_next_pack()`
  and the new `StreamingPackingDataset` (pull-based, one pack at a time).
- `build_train_datasets` / `build_val_datasets` are split into smaller overridable steps
  (`_build_packing_postencode`, per-group branches); `build_batch` no longer takes
  `packing_buffer_size`.
- Docs: packing, task encoder, glossary, internals.

## Compatibility

- `CHECKPOINT BREAKING CHANGE`: packing state now includes pushback/carryover buffers.
- `API BREAKING CHANGE` (minor): signature of `TaskEncoder.build_batch` changed.

## Tests

- `test_dataset`: pushback, partial-sample carryover (incl. save/restore), streaming packing,
  failed/empty selections; `test_recipe`: packing groups.
