# refactor(recipe)!: remove dataset joining

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/282) · state: closed · merged: True

## Original PR description

## Summary

Removes the dataset *join* feature (`JoinedWebdatasetFactory`, `RecipeJoin`,
`join_dataset_loader`). Joining was rarely used and is superseded by auxiliary datasets
(`aux:` in recipes), which cover the same use cases with less machinery.

## Changes

- Deletes `flavors/webdataset/joined_webdataset.py`, `recipe/join_dataset_loader.py`, the join
  recipe nodes and the *Joining Datasets* docs page.
- `DatasetSampler` reads from a single reader again (no tuple of joined readers);
  `itar_reader` / `indexing` drop the join-specific code paths.

## Compatibility

- `API BREAKING CHANGE` / `RECIPE CONFIG BREAKING CHANGE`: `join:` recipes and the join classes
  are no longer supported.

## Review notes

- Almost pure deletion (+36 / −2083).

## Validation

- Full unit test suite on this layer: 138 tests passed (CPU).
- `ruff check`, `ruff format --check`, license headers: clean.
- Sphinx docs build (`-E -a`): no warnings.
