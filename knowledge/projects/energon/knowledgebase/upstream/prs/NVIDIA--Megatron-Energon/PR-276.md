# refactor(flavors): restructure dataset flavors around indexed, manifest and single-file bases

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/276) · state: closed · merged: True

## Original PR description

## Summary

Core restructuring of how prepared datasets are represented and read. This is the foundation
the later format layers (filter index, BinIdx, JSONL shards, Parquet) build on.

## Changes

- New `flavors/common/` package:
  - `DatasetSampler` (formerly `webdataset/sample_loader.py`): format-independent sampling
    of an `IndexedSampleReader`;
  - `common/manifest/` (`io`, `types`, `paths`, `write`, `sharder`, `empty_dataset_error`):
    the `.nv-meta` manifest format, decoupled from WebDataset;
  - `reader.py` / `sample_record.py`: reader protocols and the `SampleRecord` / `FilteredSample` types;
  - `aggregator_pool.py`, `sqlite.py` moved from `flavors/webdataset/`.
- New factory bases: `BaseIndexedDatasetFactory`, `BaseManifestShardListDatasetFactory`,
  `BaseSingleFileDatasetFactory`. WebDataset and JSONL factories are reimplemented on top of them.
- Dataset detection and construction: `flavors/dataset_type.py` and
  `flavors/dataset_factory_resolver.py` with priority-based
  `register_dataset_factory_provider` (applications can register providers that take
  precedence over the built-ins).
- Key-based access is separated from ordinal training access: per-flavor `FileStore`s
  (`webdataset/file_store.py`, `jsonl/file_store.py`).
- `part_filter` support for factories and `Cooker`s (parts that are filtered out are not loaded).
- `SampleDecoder` moved to the new `megatron.energon.decoders` package.
- `EPath.with_suffix(..., replace=False)` to append (instead of replace) a suffix; index
  files are now addressed as `<file>.idx`.
- `deprecated.py`: import shims (with `DeprecationWarning`) for all moved modules, e.g.
  `flavors.webdataset.metadata`, `structs`, `sample_loader`, `sharder`, `thread_local_sqlite`.
- Docs: new *Custom Dataset Factories* page; data preparation docs updated for manifest datasets.

## Review notes

- Large but mostly mechanical moves; GitHub's rename detection shows the moved files as renames.
- Behaviour should be unchanged for existing prepared WebDataset and JSONL datasets.
- `Metadataset` naming is intentionally kept here; the rename to `Recipe` is in the next-but-one PR.

## Compatibility

- `API BREAKING CHANGE`: modules moved; compatibility aliases are provided for the previous
  import paths where possible.

## Validation

- Full unit test suite on this layer: 141 tests passed (CPU).
- `ruff check`, `ruff format --check`, license headers: clean.
- Sphinx docs build (`-E -a`): no warnings.
