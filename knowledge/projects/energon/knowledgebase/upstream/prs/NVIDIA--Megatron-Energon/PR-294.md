# fix(flavors): review fixes for core flavor restructure

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/294) · state: closed · merged: True

## Original PR description

## Summary
- fix(tools): read DatasetSampler events in analyze-debug fallback - the sample loader was renamed, so `energon analyze-debug --force-loading-order` (and the automatic fallback) found no keys. Both event names are accepted now. Also passes the log source to the heatmap, without which the fallback crashed as soon as keys were found.
- refactor(flavors): drop unused filter index constants from manifest paths - `FILTER_*` in `manifest/paths.py` were unused and never released.
- fix(flavors): raise NotImplementedError from reader protocol stubs - readers subclass the protocols explicitly, so unimplemented methods (e.g. `ShardInfosITarReader.list_all_samples`, `IJsonlReader.get_path`) silently returned `None`.
- fix(flavors): truncate slices in shard debug print again - `ENERGON_DEBUG_SHARD_PRINT=1` printed every slice of every worker.
- docs(epathlib): clarify EPath.with_suffix replace semantics
- test(flavors): cover dataset type detection, deprecated paths and part filters

## Validation
- Full unit test suite on this branch: 157 tests OK (CPU).
- Restack check: layers 02–16 rebase onto this branch without conflicts and with unchanged layer diffs; full suite at the restacked top: 213 tests OK; the new tests pass at layers 03, 05, 07, 08, 10, 12, 14.
- Each new test fails without its fix (checked against the unfixed sources).
- `ruff check`, `ruff format --check`, license headers clean on every commit.

Note for layer 08: `BinIdxReader`/`BinIdxFileStore` do not implement `__len__`; `len()` on them now raises `NotImplementedError` instead of `TypeError`.
