# feat(flavors): add Megatron-LM BinIdx dataset format

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/284) · state: closed · merged: True

## Original PR description

## Summary

Loads Megatron-LM indexed datasets (`.bin` + `.idx`, `MMIDIDX` version 1) directly as crude,
pre-tokenized datasets — no conversion to WebDataset needed.

## Changes

- New `flavors/binidx/` (`BinIdxDatasetFactory`, `DefaultBinIdxDatasetFactory`, reader,
  `FileStore`). Pass the `.bin` path; the `.idx` file must sit next to it.
- Index arrays are read through `EPath.map` (memory-mapped locally, seek/read remotely).
- Registered with the dataset factory resolver, usable in recipes and with filter indexes
  (single-file sidecars); the payload is exposed as the logical part `tokens` for `part_filter`.
- Docs: data preparation section for BinIdx datasets.

## Tests

- New `tests/test_binidx_dataset.py`; BinIdx case in `tests/test_filter_index.py`.

## Validation

- Full unit test suite on this layer: 151 tests passed (CPU).
- `ruff check`, `ruff format --check`, license headers: clean.
- Sphinx docs build (`-E -a`): no warnings.
