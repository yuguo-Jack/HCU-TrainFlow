# feat(recipe): add byte-range and custom auxiliary filestore protocols

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/287) · state: open · merged: False

## Original PR description

## Summary

Extends auxiliary data sources in recipes (`aux:`), which cookers use to look up data by key.

## Changes

- `ByteRangeStore` with `byterange://` and `byterange+msc://` aux references: keys of the form
  `path/to/file#bytes=offset:size` read a byte range below the configured root, with
  `SourceInfo` provenance.
- `register_aux_filestore_protocol(protocol, factory)` and the `AuxFileStoreReference` base
  class: applications can add their own aux URI schemes (e.g. `zip://`), which also compose
  with EPath backends (`zip+msc://...`). `filesystem://` and `byterange://` are registered the
  same way.
- Docs: byte-range keys and a worked example for a custom protocol in *Crude Datasets*.

## Tests

- `test_crudedataset`: byte-range store and recipe usage; `test_recipe`: custom protocol
  registration, wrapped EPath protocol, unregistered protocols, duplicate registration.
