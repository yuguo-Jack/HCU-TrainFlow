## Summary

Adds prepared *directories of JSONL shards* as a first-class manifest dataset, and detects
stale JSONL indexes.

## Changes

- `energon prepare <dir>` on a directory with `.jsonl` files indexes every shard and writes an
  `.nv-meta` manifest (`.info.json`, `split.yaml`, `dataset.yaml`) with shard-level
  train/val/test splits (`--split-ratio` or `--split-parts`).
- `CrudeJsonlShardListDatasetFactory` / `DefaultCrudeJsonlShardListDatasetFactory`,
  `MultiJsonlReader`, `MultiJsonlFileStore`.
- `IJsonlIndexReader.is_current()`: an index older than, or inconsistent with, its JSONL file is
  rejected instead of silently returning wrong samples.
- Docs: *A Directory of JSONL Shards* section, CLI docs.

## Tests

- Shard-directory tests in `tests/test_jsonl_dataset.py` (multi-rank, recipe split selection,
  inline split config, stale index, `FileStore`), JSONL shard case in `test_filter_index.py`.

This line stamps `("JsonlShardList", global_idx)`. `_load_sample_raw` returns the inner dict, so that key is what ends up on the sample, and `MapDataset` prefixes it: `("MapDataset", i, "JsonlShardList", n)`. On restore, `MapDataset.restore_sample` passes `("JsonlShardList", n)` to `DatasetSampler.restore_sample`, which asserts `id == self.restore_key_kind`. The factory's `restore_key_kind` is the default `"Webdataset"`, so it raises `AssertionError` on `dataset_sampler.py` side.
