# Recreate epochized source iterators after checkpoint restoration

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/300) · state: open · merged: False

## Original PR description

Fixes #299.

Discard the cached source iterator when restoring or resetting an `EpochizeDataset`, so subsequent iteration starts from restored child state. Uninterrupted virtual epochs still reuse their iterator. Saved fields and checkpoint format are unchanged.

## Review changes

The regression now extends the existing crude-dataset checkpoint test. The original packed two-worker case still reconstructs a loader before restoration, as required by the active-worker API. The added zero-worker case explicitly enables virtual epochs, advances a live loader, restores its checkpoint in place, and compares all 100 resumed batch keys exactly. With the unchanged EpochizeDataset, that new case fails; restoring the patch passes both cases.

The prior revision had used the forbidden active-worker restoration path and omitted virtual epochs. Those test errors are corrected without weakening the loader guard or modifying packing buffers. No standalone synthetic dataset test is retained.

The use case is demonstrated with the repository's local end-to-end fixtures. This does not claim an observed production training incident.
