# Coalesce duplicate leaf datasets in weighted blends

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/268) · state: open · merged: False

## Original PR description

Closes #266.

## Change

Coalesce identical leaf datasets in weighted `Recipe` blends after flattening nested inputs. Preserve the first occurrence and sum its weights rather than creating duplicate sample streams with identical shuffle sequences. Warn when duplicates are combined.

Comparison retains the resolved path, effective split, dataset/split configuration filenames, tags, subset, shuffle settings, and auxiliary stores. Different configurations remain separate. Epochized repetitions and traversal-only inspection are unchanged. This branch targets the current `Recipe` API; it does not reinstate the removed Metadataset interfaces.

## Checkpoint compatibility

Coalescing changes the loader structure for blends that previously contained duplicate leaves. Do not restore older duplicate-stream checkpoints into the new coalesced layout. Exact save/restore sequence equality is tested for newly created coalesced blends.
