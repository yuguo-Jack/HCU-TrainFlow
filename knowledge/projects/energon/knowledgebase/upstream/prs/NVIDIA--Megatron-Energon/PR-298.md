# Preserve source position when limiting dataset windows

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/298) · state: open · merged: False

## Original PR description

Fixes #297.

Honor `reset_after_epoch=False` by retaining the source state at the end of a limited window. The current implementation resets unconditionally and resets a second time when the flag is enabled.

Check the offset iterator before advancing the source in `zip`. Otherwise, the loop reads and discards one source sample after reaching the limit, which would also skip a sample when continuation is enabled.

Document the continuation behavior. Add stateful-source regressions covering empty, short and oversized limits, explicit resets, consecutive windows, checkpoint restoration and uneven per-worker limits.

Validation on macOS CPU with Python 3.12.14 and PyTorch 2.14.1:

- `python -m pytest -q tests/test_dataset.py tests/test_limit_dataset.py`: 34 passed, plus 18 subtests.
- The limiter regressions expose the unexpected resets and extra reads on unchanged upstream code.
- Ruff lint, Ruff formatting and `git diff --check` pass.

No GPU or distributed multi-rank validation was performed.
