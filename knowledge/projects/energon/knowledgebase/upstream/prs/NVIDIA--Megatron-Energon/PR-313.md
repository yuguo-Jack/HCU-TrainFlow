## What does this PR do?

The agent guidance in #307 covers implementation and contribution workflows. Add a repository
skill for reviewing a PR once and helping humans prioritize likely bugs and regressions.

This PR is stacked on #307 and targets its `chore/agent-ready` branch.

- Add `.agents/skills/pr-review/SKILL.md` and list it in `AGENTS.md`. The existing
  `.claude/skills` symlink also exposes the skill to Claude Code.
- Report red for substantiated blockers, yellow for other concrete bugs or material review gaps,
  and green when the complete reviewed diff has no actionable bugs or unresolved concerns.
- Require findings to include priority, file/line evidence, a trigger and observable impact.
  Focus on Energon contracts such as exact resume, reproducibility, worker/rank distribution,
  dataset blending and resource lifecycle.
- Use the actual PR base and record both SHAs, including for stacked PRs. A changed base/head or
  missing diff makes coverage yellow. Return one advisory report in the conversation by default.
- Preserve mandatory human review for every color and leave GitHub publication to an explicit
  request.
