# fix(binidx): open files lazily and apply part filter in the reader

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/317) · state: closed · merged: True

## Original PR description

- Open the .bin and .idx files on first access instead of at build time, so forked loader workers no longer share one file offset, and reset them on close() so the dataset stays usable after a loader is closed.
- Pass the part filter to BinIdxReader, so filtering out `tokens` skips the .bin read instead of raising KeyError in DefaultBinIdxDatasetFactory.
- Add BinIdxReader.__len__.
- Make `energon prepare` report that BinIdx datasets need no preparation.
- Tests.
