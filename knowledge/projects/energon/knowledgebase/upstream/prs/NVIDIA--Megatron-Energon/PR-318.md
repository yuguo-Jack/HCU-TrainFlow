# fix(jsonl): address review feedback on JSONL shard datasets

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/318) · state: closed · merged: True

## Original PR description

- Stamp shard-list samples with the "Webdataset" restore key kind expected by the DatasetSampler, so `restore_sample` works for JSONL shard directories.
- Prefer tar shards over JSONL files when preparing a fresh directory, so WebDatasets with JSONL side files keep preparing as before.
- Check JSONL index freshness by size only; copies and uploads do not preserve modification times.
- Take shard counts from the manifest and validate each shard index lazily when the shard is first read instead of opening every index at startup.
- Do not report "Done" after a declined re-prepare, and fix the docs example to assign folder-based splits with `--split-parts`.
