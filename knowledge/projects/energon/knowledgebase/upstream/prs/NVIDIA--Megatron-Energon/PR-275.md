# chore: make ruff rule selection explicit and refresh lockfile

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/275) · state: closed · merged: True

## Original PR description

## Summary

Tooling-only groundwork for the Energon 8 refactoring stack. No library code changes.

- `pyproject.toml`: replace `extend-select = ["I"]` with an explicit
  `select = ["E4", "E7", "E9", "F", "I"]`, so the lint result no longer depends on ruff's
  default rule set. With this config `ruff check` passes on the current code base
  (it does not with the previous config and the current ruff version).
- `justfile`: drop the custom `--cache-dir .uv_cache` from `dev-sync` / `prod-sync`.
- `uv.lock`: refresh against the current `develop` dependencies (e.g. the
  `nvidia-sphinx-theme` switch).
