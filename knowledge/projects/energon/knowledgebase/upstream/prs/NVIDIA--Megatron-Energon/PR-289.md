## Summary

Recipe blend weights can now target a task-defined unit (e.g. tokens) instead of the number of
samples.

## Changes

- `@sample_size_metric("tokens")` registers a size function on the task encoder; a recipe blend
  selects it with `blend_weight_unit: tokens` (`samples` stays the default).
- `BlendDataset` compensates for emitted size with a soft deficit-based selection
  (tunable via `blend_sample_size_alpha` / `blend_sample_size_epsilon` on the task encoder);
  emitted sizes are part of the saved state.
- Nested dataset-weight blends must use the same unit.
- Docs: *Custom Blending*, recipe docs, internals.

## Compatibility

- `CHECKPOINT BREAKING CHANGE`: `BlendDataset` state includes the emitted sizes.

- `test_recipe`: size-based distribution and save/restore.
