# test: reuse Gloo workers across metric reductions

[Upstream PR](https://github.com/THUDM/slime/pull/2502) · state: open · merged: False

## Original PR description

## Summary

Reuse a Gloo worker group across the distributed metrics report paths for each DP/CP topology.

### Motivation

The always-on metrics checks launch separate groups for report paths that use the same topology. Reusing each group removes repeated distributed startup while retaining every report scenario and numerical comparison.

### Before and after

| Measurement | Base `540ea919` | This PR | Observed reduction |
| --- | ---: | ---: | ---: |
| Local pytest elapsed time | 140.91s | 78.15s | 62.76s, 44.5% |
| Hosted CI Execute step | [148s](https://github.com/THUDM/slime/actions/runs/40445960764/job/121997185495) | [37s](https://github.com/THUDM/slime/actions/runs/40634736953/job/122638975227) | 111s, 75% |
| Gloo worker-group launches | 27 | 9 | 18 fewer, 66.7% |

Local measurements used the same host and environment. Each timing row compares one run per version, not a benchmark average. Hosted runner and cache variation apply. The CI row measures the Execute step, not total workflow latency.

## Changes

Run the per-rollout train report, per-token train report, and multi-key rollout log reduction on one Gloo group per DP/CP topology.

Keep the complete topology matrix, fixtures, numerical comparisons, and tolerances. Each train report gets a fresh reduction tensor, so its in-place all-reduce cannot affect the next report. Every group is destroyed in `finally`.

For review, compare the consolidated worker's report paths with the old worker bodies, then check the parent assertions. The pytest nodes are grouped by topology. Production code is unchanged. This PR can land independently of the other CI optimizations.

## Testing

`OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH="$PWD" python tests/test_metric_report_dist.py` passed before and after the change with Python 3.10 and PyTorch 2.14.1+cpu.

Black 24.3.0, isort 5.13.2, Ruff 0.14.7, and `git diff --check` passed. Hosted checks passed at `ca761392`. GPU jobs remain label-gated and were skipped. The CPU/Gloo suite validates this change.
