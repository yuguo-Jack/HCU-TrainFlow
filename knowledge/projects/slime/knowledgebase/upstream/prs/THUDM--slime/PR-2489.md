# refactor(musa): migrate Slime bootstrap from musa_patch to musa_titan

[Upstream PR](https://github.com/THUDM/slime/pull/2489) · state: closed · merged: True

## Original PR description

## Summary

Replace the legacy `musa_patch` bootstrap with `musa_titan` while preserving
Slime's one-time accelerator initialization behavior.

## Changes

- Read `MUSA_TITAN_PATH` instead of `MUSA_PATCH_PATH`.
- Import `musa_titan` and maintain its path in `sys.path`.
- Prefer `apply_rl_patch()`, with `patch_after_import_torch()` as fallback.
- Update MUSA environment detection, backend selection, and error messages.
- Add tests for path injection, callback selection, fallback, and missing
  dependencies.

## Compatibility

Breaking change: MUSA launchers must set `MUSA_TITAN_PATH`. `MUSA_PATCH_PATH`
is no longer read, and the legacy `musa_patch` checkout should be removed from
`PYTHONPATH`.
