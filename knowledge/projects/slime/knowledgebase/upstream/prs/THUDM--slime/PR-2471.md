# feat: support NVIDIA Nemotron 3.5 Super VL (GRPO on GEO3K, Megatron backend)

[Upstream PR](https://github.com/THUDM/slime/pull/2471) · state: open · merged: False

## Original PR description

Adds support for nvidia/NVIDIA-Nemotron-3.5-Super on slime's Megatron backend with
a colocated SGLang rollout (88-layer Mamba2/MoE/attention hybrid decoder with a
C-RADIO vision tower).

What it adds
- Model providers built on MCore's HybridModel (slime_plugins/models/nemotron_h*.py)
  and the architecture flags (scripts/models/nemotron3*.sh).
- HF <-> Megatron weight mapping in both directions, including the RL weight sync.
- Megatron and SGLang patches (docker/patch/latest), MTP training and rollout,
  routing replay for hybrid stacks, SFT on VLM data, packed-sequence Mamba state fix.
- Example: examples/geo3k_vlm/run_geo3k_nemotron35.sh and README_nemotron35.md
  (design, implementation notes, test results and how to reproduce them).

Testing
- CPU unit tests: tests/test_nemotron_h_conversion.py, test_nemotron_h_vl_conversion.py,
  test_megatron_utils_misc.py (plus test_nemotron_h_vl_plugin.py with MCore >= 0.20).
- End-to-end on 4 nodes x 8 H100, TP2/EP32: train_rollout_logprob_abs_diff 0.0143 at
  step 0 (Qwen3.5 recipe: about 0.0135); eval 0.42 -> 0.71 over 48 rollouts. Full table
  in examples/geo3k_vlm/README_nemotron35.md.
