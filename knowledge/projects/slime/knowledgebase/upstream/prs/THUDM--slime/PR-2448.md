# [release] bump to v0.4.0

[Upstream PR](https://github.com/THUDM/slime/pull/2448) · state: closed · merged: True

## Original PR description

Upgrade Megatron Core to 0.19.2, Transformer Engine to 2.18, FLA to 0.5.2 and NCCL to 2.30.7. Use TE core and FlashAttention wheels, move integration policies into Slime, and reduce the Megatron patch while retaining compatibility with older interfaces.

Prepare release docs, stable patch snapshots and Docker version 1007a. Rename the publication command to `just release` and publish CUDA 12 before CUDA 13, retaining the unqualified latest tag for CUDA 12.

Validation: CPU regressions, four-node colocated/disaggregated training, PP2/PP4 with TMS, checkpoints and strict GLM logprob alignment pass. CUDA 12.9 Docker and clean Conda installation audits, pre-commit, and mocked release order/failure checks pass. CUDA 13 build/GPU validation has not been run.
