# Fix CI regressions and refresh long-context training examples

[Upstream PR](https://github.com/THUDM/slime/pull/2479) · state: closed · merged: True

## Original PR description

Pin the TMS pageable-host fallback, isolate CI temporary storage, and fix agent artifacts, sandbox polling and CPU test isolation.

Default maintained RL recipes to 128K responses (256K for GLM5.3), enable supported SC/R3 and memory-saving settings, migrate short-context Qwen recipes, and remove obsolete launchers. Align the CUDA 13 homepage generator and bilingual documentation.

Validation: affected GPU regressions, 20 generator tests, 31 strict CLI configurations, 72 shell syntax checks, and bilingual docs/browser checks passed. Flash generated 64 real samples (max 88764 tokens); replay with default checkpoint settings passed training, save, offload and weight sync. Full-length 128K/256K training remains unverified; extra debug recovery checkpointing encountered host-memory exhaustion.
