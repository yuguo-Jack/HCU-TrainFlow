# docs: update coding-agent example to the revised MiMo dataset

[Upstream PR](https://github.com/THUDM/slime/pull/2513) · state: open · merged: False

## Original PR description

The coding-agent README pins MiMo data from before the upstream removal of 96 code tasks. Following its full-data conversion still emits `format-code-task-000484`, whose mapped image returns `404 MANIFEST_UNKNOWN`, so image preparation stops. The converter follows the official mapping correctly.

Update the example to the fixed revision `e8e81e4945270b6212204bad99de1e598f7fb077`, use the same revision for both source files, and correct the task/row counts. Document regeneration in a fresh revision-specific `DATA_ROOT` and add a one-task data/image preparation smoke check with separate outputs. The fresh directory also avoids reusing old completed OCI bundles: a dataset SHA does not pin the contents of Docker tags.

Related to #2477.

<summary>Reproduce the data conversion counts</summary>

Run from the checkout with the example dependencies installed:

```bash
for revision in \
  639865fd3374018d6cb29b9fb82dd531406fcf5f \
  e8e81e4945270b6212204bad99de1e598f7fb077; do
  hf download XiaomiMiMo/MiMo-V2.6-RL-oss code.parquet image-mapping.jsonl \
    --repo-type dataset --revision "$revision" --local-dir "/tmp/mimo-$revision/data"
  python examples/coding_agent_rl/prepare_mimo.py \
    --data "/tmp/mimo-$revision/data" --output "/tmp/mimo-$revision/train-mixed.jsonl" \
    --agents codex claude_code
done
```

The CLI reports `5396` rows / `2698` tasks for the old revision and `5204` rows / `2602` tasks for the new revision. For the representative import, run the README's smoke commands with the new snapshot.
