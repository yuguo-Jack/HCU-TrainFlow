# test: reuse the single-rank whitening reference

[Upstream PR](https://github.com/THUDM/slime/pull/2504) · state: open · merged: False

## Original PR description

## Summary

Compute the fixed single-rank advantage-whitening reference once per module, then reuse it across the existing topology checks.

### Motivation

Every DP/CP topology currently recomputes the same reference from fixed `SEQS` and `REWARDS`. Sharing that reference removes redundant distributed startup. Each topology still needs its own independent actual run to check distributed correctness.

### Before and after

| Measurement | Base `540ea919` | This PR | Observed change |
| --- | ---: | ---: | ---: |
| Local pytest elapsed time | 89.95s | 36.97s | 52.98s less, 58.9% reduction |
| Gloo worker-group launches | 12 | 7 | 5 fewer, 41.7% reduction |
| Hosted CI Execute step | [48s](https://github.com/THUDM/slime/actions/runs/40445960764/job/121997185657) | [49s](https://github.com/THUDM/slime/actions/runs/40636495436/job/122644556438) | 1s more, 2.1% increase |

**The first hosted comparison shows no CI speedup.** The measured benefit is fewer startups and a local runtime reduction. Each timing row compares one run per version, not a benchmark average. Local runs used the same host and environment. Hosted runner and cache variation apply, so a hosted performance benefit remains unproven.

## Changes

Build the single-rank reference through a module-scoped fixture. The fixture stores a dictionary of primitive values, and tests only read it.

Every existing DP/CP topology still performs its own fresh distributed run, including `(1, 1)`. Each actual run keeps its own directory, process group, timeout guard, rank-agreement checks, and comparison with the reference. The reference now has a separate fixture directory.

For review, the change is limited to the new fixture and how the existing test receives its reference. The worker implementation, topology parametrization, and numerical comparisons remain unchanged. Production code and workflow registration remain unchanged. This PR can land independently of the other CI optimizations.

## Testing

`OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH="$PWD" python tests/test_advantage_whiten_cp.py` passed before and after the change with Python 3.10 and PyTorch 2.14.1+cpu.

Black 24.3.0, isort 5.13.2, Ruff 0.14.7, and `git diff --check` passed. Independent review confirmed that every topology still runs independently and that the shared reference is not mutated.

The hosted whitening job and reported checks passed at `1e55f8af`. Label-gated GPU jobs were skipped.
