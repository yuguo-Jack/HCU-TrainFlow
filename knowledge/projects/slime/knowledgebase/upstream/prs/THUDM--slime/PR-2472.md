## Original PR description

## Summary
- Port the Qwen3-30B-A3B FP8-experts deterministic train/rollout stack onto current `main`: DeepGEMM MoE alignment, residual checkpoint, `qwen3_moe_aligned` attention plugins, and SGLang deterministic patches.
- Add `--deterministic-sampling-seed-mode {group,sample}` with fail-closed dataset-state restore in sample mode, without regressing main's rollout transport/observability or `--force-fp8-ue8m0-scale`.
- Include sanitized run/quantize scripts, CPU unit tests in CI, and bilingual sampling-seed docs.
