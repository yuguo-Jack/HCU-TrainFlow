# test: reuse Gloo workers in score-centering checks

[Upstream PR](https://github.com/THUDM/slime/pull/2501) · state: open · merged: False

## Original PR description

## Summary

Reuse Gloo workers across score-centering cases that share a distributed layout.

### Motivation

These always-on CPU checks repeatedly start distributed workers for the same layout. Grouping the mode variants inside each worker removes repeated startup work while preserving the numerical scenarios and tolerances.

### Before and after

| Measurement | Base `540ea919` | This PR | Observed reduction |
| --- | ---: | ---: | ---: |
| Local pytest elapsed time | 300.07s | 92.21s | 207.86s, 69.3% |
| Hosted CI Execute step | [135s](https://github.com/THUDM/slime/actions/runs/40445960764/job/121997185408) | [59s](https://github.com/THUDM/slime/actions/runs/40634605770/job/122638556023) | 76s, 56.3% |
| Gloo worker-group launches | 30 | 9 | 21 fewer, 70% |

Local measurements used the same host and environment. Each timing row compares one run per version, not a benchmark average. Hosted runner and cache variation apply. The CI row measures the Execute step, not total workflow latency.

## Changes

- Reuse a Gloo worker group per layout within the regular and top-p gradient checks.
- Keep every mode, layout, disk path, numerical assertion, and tolerance. Each subcase creates fresh batches, arguments, logits, and gradients.
- Give disk subcases separate directories and include the subcase context in failures.

For review, compare the case helpers with the old worker bodies, then compare the worker-loop combinations with the old parametrization. Modes and disk variants now run inside the workers, so pytest groups them into fewer nodes. Production code is unchanged. This PR can land independently of the other CI optimizations.

## Testing

`OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH="$PWD" python tests/test_score_centering.py` passed before and after the change with Python 3.10 and PyTorch 2.14.1+cpu.

Black 24.3.0, isort 5.13.2, Ruff 0.14.7, compileall, and `git diff --check` passed. Hosted checks passed at `0333c795`. GPU jobs remain label-gated and were skipped. The CPU/Gloo suite validates this change.
