# Support fully async coding-agent RL with 128k Qwen contexts

[Upstream PR](https://github.com/THUDM/slime/pull/2474) · state: closed · merged: True

## Original PR description

Add one Qwen3.8-27B example with full MiMo data preparation, mixed Codex and Claude Code trajectories, and bounded compaction in sunabako sandboxes.

Keep live agent sessions across weight updates, retain completed siblings on retries, and train terminal sandbox outcomes with zero reward. Report speculative decoding and compaction counters without duplicate truncation metrics.

Support native TP/CP GDN and reduce packed-sequence and loss memory costs. Fix top-p metadata copies across CUDA streams and add regression coverage.

Document setup and operation for new users; keep experiment plans and runtime artifacts outside the repository.

Validation: pre-commit; 640 CPU tests passed, 1 skipped; launcher and README shell syntax; regenerated CI workflows.
