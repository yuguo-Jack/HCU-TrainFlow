# test: register Megatron bindings regression in CPU CI

[Upstream PR](https://github.com/THUDM/slime/pull/2458) · state: closed · merged: True

## Original PR description

The Megatron bindings regression test added in #2453 is missing from the fixed CPU matrix. It also has no direct-execution entry point, so `python tests/test_reloadable_process_group_megatron_bindings.py` exits successfully without running its assertion, and no `NUM_GPUS` declaration, so `run-ci-changed` defaults to eight GPUs.

This adds the standard pytest entry point and `NUM_GPUS = 0`, registers the existing test beside the other reloadable-process-group CPU tests, and regenerates the workflow with the official generator. The three-file diff adds 13 lines; production code and the critic fixture are untouched.

Validation on Linux, Python 3.12.14, pytest 8.3.5 and official PyTorch 2.14.1+cpu, using `/workspace/slime-cpu-setup/venv/bin/python` as `python`:

```bash
export CUDA_VISIBLE_DEVICES='' SLIME_ACCELERATOR=cpu
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 PYTHONDONTWRITEBYTECODE=1
export PYTHONPATH=. PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTEST_ADDOPTS='-p no:cacheprovider'
python tests/test_reloadable_process_group_megatron_bindings.py
python -m pytest tests/test_reloadable_process_group_megatron_bindings.py
python .github/workflows/generate_github_workflows.py
pre-commit run --files tests/test_reloadable_process_group_megatron_bindings.py .github/workflows/pr-test.yml.j2 .github/workflows/pr-test.yml
```

- Original direct execution at base `22a89f96835969a47055a659c588f46151f8b07a`: exit 0, no pytest session or assertion execution.
- Updated direct execution and pytest: each 1 passed, exit 0.
- Regression mutation in a temporary source copy: disabled only `_rebind_imported_collectives(replacements)`, retaining torch.distributed wrapping. The child exited normally; all three Megatron binding identity checks became false and the existing assertion failed (1 failed, exit 1).
- Official workflow generation: exit 0. Independent read-only review confirmed generated YAML exactly matches the template and reviewed the mutation evidence.
- All applicable configured pre-commit hooks and `git diff --check` passed. The reviewed patch was unchanged by hooks.

The test only spawns a subprocess, supplies fake Megatron bindings, patches function references and compares identities. It creates no process group, invokes no collective and allocates no accelerator tensor. Missing NumPy produced a warning but did not affect the test. This is local CPU coverage evidence; remote CI remains to run. No GPU, training, numerical validation or real Megatron collective validation was performed.

AI assistance: implemented and reviewed with OpenAI Codex.
