# Add Trustabl agent reliability check to CI

[Upstream PR](https://github.com/THUDM/slime/pull/2496) · state: open · merged: False

## Original PR description

Hi! We came across THUDM/slime while scanning open-source agent projects with [Trustabl](https://trustabl.ai), an open-source agent reliability scanner. It flagged a few things that may be worth a look:

- **Skill processes sensitive data** (`.claude/skills/add-rollout-function/SKILL.md`): This skill's body or description names a sensitive data class — passwords, tokens, SSNs, credit card numbers, PII, or private keys — without stating what it does with that data beyond naming it.

This PR adds a small GitHub Actions workflow (`.github/workflows/trustabl.yml`) so these checks run automatically:

- Runs on pushes to the default branch, on pull requests, and on demand
- Advisory only: the job uses `continue-on-error`, so it never fails your CI
- No secrets needed; findings show up in the repo's code scanning results
- Actions are pinned to commit SHAs, with read-only contents access

Some findings may be intentional. Happy to adjust the workflow, or to close this if it's not useful.
