# Add sunabako agent E2E and align top-p score centering

[Upstream PR](https://github.com/THUDM/slime/pull/2457) · state: closed · merged: True

## Original PR description

Use the published sunabako package for the Qwen3.8-27B MiMo example and single-host Codex training CI. Preserve original tokens and sampler replay metadata across agent turns, and normalize rewards over unique rollouts rather than fork counts.

Center the top-p SC correction with the existing non-top-p convention, without changing the non-top-p implementation or the weighted score gradient. Keep one sc_correction metric. Bump the Docker build version to nightly-dev-20261010a and document the measured CI configuration.

Validation: 134 SC tests and 176 agent/group/replay/transport tests passed. Real Qwen GDN CP=4 gradients match CP=1 within BF16 tolerance. The single-host 8-H100 E2E passed in 457 seconds with SC, top_p=0.95 and top_k=-1: MiMo SHL 10/10 tests, reward=1, exact token/replay audits, and actual updates on all 8 training ranks. R3 is disabled for this dense model.
