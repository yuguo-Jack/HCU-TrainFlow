# Support GLM-5.3 Flash training and bump Docker image

[Upstream PR](https://github.com/THUDM/slime/pull/2478) · state: closed · merged: True

## Original PR description

Add native Megatron KDA, no-RoPE sparse MLA, mHC, vision integration, checkpoint mappings, and contiguous allgather context parallelism. Provide a public 300B recipe with batch 128 and a 32768-token response limit.

Fix FP32 optimizer checkpoint refresh/resume and VLM expert weight routing. Reuse sparse MLA backward kernels across sequence lengths. Include the Megatron fixes in both Docker patch snapshots and bump the image version to nightly-dev-20261016b.

Validate full 300B three-step training at CP=1/2, CP=2/4 attention and multimodal gradient regressions, kernel precision, and release metadata.
