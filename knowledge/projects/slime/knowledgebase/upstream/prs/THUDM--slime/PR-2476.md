# [docker] Upgrade SGLang to 0.5.21 and align the CUDA 13 runtime

[Upstream PR](https://github.com/THUDM/slime/pull/2476) · state: closed · merged: True

## Original PR description

Preserve legacy CLI, YAML, model imports and weight-update APIs while adapting to SGLang's new configuration and weight-update sessions.

Align Docker and Conda with straw 0.1.3, the batch-invariant DeepGEMM 0.2.0 fork, and the TMS host-memory fallback. Retain DeepEP v1 alignment and pin Mooncake to the version validated after KV memory remapping.

Refresh the GLM deterministic patches and freeze the v0.5.21 patch stack. Enable CUDA compatibility libraries automatically at container startup.

Validated GLM deterministic and zero-difference layerwise checks, targeted streaming/recovery/checkpoint GPU CI, and new/legacy SGLang CPU contracts.
