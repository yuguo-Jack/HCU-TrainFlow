# perf(ppo): share sampled-token and score-centering normalization

[Upstream PR](https://github.com/THUDM/slime/pull/2487) · state: open · merged: False

## Original PR description

When top-k score centering is enabled, the actor currently computes sampled-token log-probabilities/entropy and sampler-head log-probabilities separately. Both paths normalize the same response logits and differentiate through the vocabulary. This change shares that work using the existing chunked, tensor-parallel top-k autograd helper.

For example, with 2,048 response rows, vocabulary size 151,936, 128 sampler heads, 256-row chunks, and metric-only entropy, the measured forward/backward component time falls from **31.163 ms to 17.091 ms (45.2% less time)**. These are fixed-logit component measurements; no end-to-end training speedup is claimed.

### Changes

- Gather the sampled token together with sampler-head IDs, sharing vocabulary normalization and a combined backward pass. Duplicate IDs accumulate in FP32.
- Compute entropy from the shared normalization, including its gradient when the entropy coefficient is nonzero.
- Recompute softmax in row chunks during backward; keep the original logits and row statistics rather than retaining another full softmax tensor.
- Wire the joint outputs into the Megatron actor's top-k SC path (`use_score_centering` and `rollout_top_p == 1.0`). Preserve top-p replay and non-SC execution paths.
- Fix zero-length response slicing so an empty response produces empty token IDs rather than the full sequence.

Full input logits are still retained. This does not fuse the output projection. No package dependencies or configuration flags are added.

### Component performance

Compared against the separate paths in base commit `a4202e0595467d9374d9a68d45a34f45c3f8d230`, using implementation commit `14db2f5ef6d2139fd829e892a4e8d5b04d008879`.

The 24-case matrix covers FP32 logits, rows `{128, 512, 2048}`, vocabulary sizes `{32768, 151936}`, 128 sampler heads, chunk sizes `{-1, 256}`, and entropy coefficients `{0, 0.01}`. Temperature is 0.8 and the SC weighting rule is TIS with upper clip 2. Both paths receive identical synthetic logits and sampler data. Entropy is computed in both cases, including when it is metric-only.

After five warmup pairs, each case uses 30 paired CUDA-event measurements, alternating original/joint and joint/original order. The timed region includes sampled log-probabilities, SC correction, entropy, and backward. It excludes the model/output projection, optimizer, rollout, and data loading. Percentages below are reductions in median component time: `100 * (1 - joint_median / original_median)`.

| Chunk setting | Cases | Median reduction across cases | Range across cases |
|---|---:|---:|---:|
| Default, unchunked (`-1`) | 12 | 16.3% | 8.7–39.0% |
| 256 rows | 12 | 39.6% | 35.0–53.1% |

All 24 measured cases improved. This is a synthetic workload sweep, not a guarantee across models, hardware, or training configurations.

```python
"""Fixed-logits, paired CUDA-event benchmark; no rollout or training timing."""
import importlib.util
import json
import math
import statistics
from pathlib import Path

import torch

from slime.utils.ppo_utils import calculate_joint_log_probs_and_entropy
from slime.utils.score_centering import importance_weights, score_centering_correction

spec = importlib.util.spec_from_file_location('baseline_ppo', 'baseline_ppo_utils.py')
base = importlib.util.module_from_spec(spec)
spec.loader.exec_module(base)
torch.set_num_threads(1)
torch.manual_seed(2026)
results = []
for n, vocab in [(128,32768), (512,32768), (2048,32768), (128,151936), (512,151936), (2048,151936)]:
    for entropy_coef in [0.0, 0.01]:
        for chunk_size in [-1, 256]:
            logits = torch.randn(n, vocab, device='cuda', requires_grad=True)
            ids = logits.detach().topk(128, dim=-1).indices
            targets = ids[:,0].clone()
            targets[::2] = (targets[::2]+173) % vocab
            # Truncated head has 80% sampler mass; remaining mass is represented by SC's tail.
            q = torch.randn(n,128,device='cuda').log_softmax(-1) + torch.tensor(0.8,device='cuda').log()
            sampled_q = q[:, 0].clone()
            # Use each head token's recorded sampler probability when present.
            matches = ids == targets[:, None]
            sampled_q = torch.where(matches.any(-1), (q * matches).sum(-1),
                                    torch.full_like(sampled_q, math.log(0.2 / (vocab - 128))))
            adv = torch.randn(n, device='cuda')
            def run(joint):
                logits.grad = None
                if joint:
                    sampled, head, entropy = calculate_joint_log_probs_and_entropy(
                        logits, targets, ids, None, chunk_size=chunk_size, temperature=0.8,
                        with_entropy_grad=entropy_coef != 0)
                else:
                    sampled, entropy = base.calculate_log_probs_and_entropy(
                        logits / 0.8, targets, None, with_entropy=True,
                        with_entropy_grad=entropy_coef != 0, chunk_size=chunk_size)
                    sampled = sampled.squeeze(-1)
                    head = base.calculate_topk_log_probs(logits, ids, None, chunk_size=chunk_size, temperature=0.8)
                correction, q_mass, p_mass = score_centering_correction(head, q, mode='tis')
                weight = importance_weights((sampled - sampled_q).exp(), mode='tis').detach()
                loss = (-adv * (weight * sampled - correction)).mean() - entropy_coef * entropy.mean()
                loss.backward()
                return loss.detach(), q_mass, p_mass
            old = run(False)[0].clone(); old_grad = logits.grad.clone()
            new = run(True)[0].clone(); new_grad = logits.grad.clone()
            rel = ((new_grad-old_grad).norm()/old_grad.norm()).item()
            assert rel < 2e-4, rel
            torch.testing.assert_close(new,old,atol=3e-6,rtol=3e-6)
            torch.testing.assert_close(new_grad,old_grad,atol=2e-6,rtol=2e-4)
            del old_grad,new_grad
            for _ in range(5):
                run(False);run(True)
            timings = {False:[],True:[]}
            for repeat in range(30):
                for joint in ([False,True] if repeat%2==0 else [True,False]):
                    start,end = torch.cuda.Event(enable_timing=True),torch.cuda.Event(enable_timing=True)
                    start.record();run(joint);end.record();end.synchronize()
                    timings[joint].append(start.elapsed_time(end))
            peaks = {}
            for joint in [False, True]:
                logits.grad = None
                torch.cuda.synchronize()
                before = torch.cuda.memory_allocated()
                torch.cuda.reset_peak_memory_stats()
                run(joint)
                torch.cuda.synchronize()
                peaks[joint] = torch.cuda.max_memory_allocated() - before
            med = {key:statistics.median(value) for key,value in timings.items()}
            result = dict(rows=n,vocab=vocab,heads=128,dtype='float32',chunk=chunk_size,temperature=0.8,
                          entropy_coef=entropy_coef,original_incremental_peak_bytes=peaks[False],joint_incremental_peak_bytes=peaks[True],original_ms=med[False],joint_ms=med[True],
                          reduction_percent=100*(1-med[True]/med[False]),gradient_relative_l2=rel,
                          original_samples_ms=timings[False],joint_samples_ms=timings[True])
            results.append(result)
            print(json.dumps({k:v for k,v in result.items() if not k.endswith('samples_ms')}),flush=True)
            Path('benchmark.json').write_text(json.dumps(results,indent=2))
            del logits
            torch.cuda.empty_cache()

```
