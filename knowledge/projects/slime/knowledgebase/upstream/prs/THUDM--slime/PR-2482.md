# Rewind Straw checkpoints in place with dataset cursor fallback

[Upstream PR](https://github.com/THUDM/slime/pull/2482) · state: closed · merged: True

## Original PR description

Restore saved prompts in the existing queue and remove later rollout indices and archives so training can save those steps again. Regenerate pending and ready outputs, and warn and resume from a readable dataset cursor (or offset zero) when rollout state cannot be restored.

Remove checkpoint branch bookkeeping, adapt recovery tests to the upstream layout, and update the Chinese/English guides and CI test references.

Validation: 346 CPU tests, two-node Ray rewind test, and pre-commit checks.
