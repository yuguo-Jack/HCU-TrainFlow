# Add MLPerf Llama 2 70B LoRA Recipe

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6476) · state: open · merged: False

## Original PR description

# What does this PR do ?

Cherry-pick the MLPerf Llama 2 70B LoRA GB200/GB300 performance recipes from #5735 and the 4-GPU CPU-offload swap from #6266 onto `main` and pin their layouts with unit tests.

# Changelog

- Add library PEFT recipe `llama2_70b_peft_config` (`recipes/llama/h100/llama2.py`) and a `recipes/llama/llama2.py` compatibility alias.
- Add GB200 Llama 2 70B LoRA perf recipes: `llama2_70b_peft_4gpu_gb200_fp8ds_config`, `llama2_70b_peft_8gpu_gb200_fp8ds_config`, `llama2_70b_peft_8gpu_gb200_nvfp4_config`, `llama2_70b_peft_72gpu_gb200_fp8ds_config`, `llama2_70b_peft_512gpu_gb200_fp8ds_config`.
- Add GB300 Llama 2 70B LoRA perf recipes: `llama2_70b_peft_4gpu_gb300_fp8ds_config`, `llama2_70b_peft_8gpu_gb300_fp8ds_config`, `llama2_70b_peft_72gpu_gb300_fp8ds_config`, `llama2_70b_peft_512gpu_gb300_fp8ds_config`.
- Add `_llama2_70b_precision_config()` and `_llama2_benchmark_common()` in `perf_recipes/llama/common.py` for the shared MLPerf precision, optimizer, DDP, model, scheduler, dataset, checkpoint, and tokenizer defaults.
- Export the new recipe factories from `perf_recipes/llama/__init__.py` and `recipes/llama/__init__.py`.
- Apply the #6266 4/8-GPU CPU-offload swap: enable offload on GB200 4-GPU (20 layers) and 8-GPU (11 layers); disable it on the matching GB300 recipes.
- Add `scripts/performance/utils/mcore_patches.py` and call `patch_skip_force_all_tensors_to_non_fp8()` from `run_script.py`.
- Accept `fp8_ds` in the performance CLI (`argument_parser.py`, `precision.py`).
- Coerce optimizer stats to Python scalars in `training_log` via `_coerce_log_scalar` to prevent logging data type error.
- Add `tests/unit_tests/recipes/test_llama2_70b_lora_perf_recipes.py` to pin parallelism, batch, LR, eval, CUDA graph, precision, and CPU-offload for the nine MLPerf recipes.
- Port-time fixes: use `get_model_config()` instead of `to_megatron_provider()`, map `optimizer.overlap_params` to `optimizer.overlap_param_gather`, and do not restore the retired Llama 2 7B helper.
