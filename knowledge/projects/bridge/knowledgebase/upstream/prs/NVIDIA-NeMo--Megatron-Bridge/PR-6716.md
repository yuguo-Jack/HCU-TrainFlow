# Remove the data_parallel_sharding_strategy in MFSDPv2's config valida…

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6716) · state: closed · merged: True

## Original PR description

## Problem

`ConfigContainer._validate_and_apply_megatron_fsdp_configs` unconditionally overwrote `ddp.data_parallel_sharding_strategy` with "optim_grads_params" under MFSDP v2. User-specified strategies were silently dropped, for example ZeRO-2 dense with ZeRO-3 experts in the DeepSeek-V3 HSDP recipe.

## Changes

  - Remove the forced override in config.py. MFSDP v2 maps every strategy to DTensor placements, so forcing ZeRO-3 is unnecessary.
  - Add the unit test test_fsdp_v2_preserves_sharding_strategies. It covers 4 dense strategies and 3 expert strategies. It checks that the values are unchanged after validation and that use_distributed_optimizer is still set to False.

## Testing

  - tests/unit_tests/training/test_config.py::test_fsdp_v2_preserves_sharding_strategies
