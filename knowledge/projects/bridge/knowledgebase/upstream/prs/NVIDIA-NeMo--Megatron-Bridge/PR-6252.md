# build: update image cuBLAS to 13.8.1

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6252) · state: closed · merged: True

## Original PR description

## What does this PR do?

Install cuBLAS 13.8.1 (archive version `13.8.1.7`) in the Megatron Bridge image, matching https://github.com/NVIDIA/Megatron-LM/pull/7685. The final NeMo Framework image inherits this runtime from the Bridge image.

## Changelog

- Download the official CUDA 13 cuBLAS archive for x86_64 or Arm SBSA before building native dependencies.
- Replace the existing toolkit headers and cuBLAS/cuBLASLt libraries so current linker paths resolve to the updated runtime; retain the archive license and clean up temporary files.
- Expose `CUBLAS_VERSION` as a build argument and preserve the base image's cuBLAS when `PRESERVE_BASE_RUNTIME=True`.
- Document the new archive-version argument separately from the framework base image's existing apt-version argument.

Version metadata: https://developer.download.nvidia.com/compute/cublas/redist/redistrib_13.8.1.json.
