# perf(recipes): enable NCCL EP for B200 and B300 Lightning BF16 and MXFP8

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6567) · state: closed · merged: True

## Original PR description

## Summary

Switch Nemotron 3.5 Lightning BF16 and MXFP8 performance recipes on B200 and B300 from HybridEP to NCCL EP.

- Enable the `flex` dispatcher with the `ncclep` backend and grouped tensors.
- Enable `NCCL_EP_HT_EM_PULL_PUSH=1` for EP8 within a single NVL8 domain.
- Remove HybridEP topology environment variables.
- Preserve parallelism, batch sizes, precision, recompute, and CUDA graph settings.
- Update recipe tests to verify the dispatcher and environment settings.

Changes cover four recipes: BF16 and MXFP8 on B200 and B300. NVFP4 recipes remain unchanged.

## Performance

Nemotron 3.5 Lightning 30B pretraining on 8 GPUs:

| GPU | Precision | Current TFLOPS/GPU | NCCL EP TFLOPS/GPU | Improvement |
| --- | --- | ---: | ---: | ---: |
| B200 | BF16 | 726.60 | 765.28 | **+5.32%** |
| B200 | MXFP8 | 853.74 | 898.04 | **+5.19%** |
| B300 | BF16 | 783.00 | 849.50 | **+8.49%** |
| B300 | MXFP8 | 882.00 | 961.10 | **+8.97%** |
