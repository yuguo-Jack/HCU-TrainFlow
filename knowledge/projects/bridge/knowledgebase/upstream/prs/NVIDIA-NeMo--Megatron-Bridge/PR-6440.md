## Summary
- Add `nemotron_3_ultra_pretrain_256gpu_gb200_bf16_ep16_deterministic_config`, wrapping the 256-GPU GB200 EP16 recipe with `apply_determinism_overrides`.
- The recipe assigns a static `cfg.env_vars` dict: `COMMON_RECIPE_ENV_VARS`, the new `DETERMINISM_ENV_VARS` (CUBLAS workspace, NCCL Ring, `NCCL_EP_HT_EM_AG_SCAN_MODE`, TE non-deterministic algo off, Mamba / causal-conv1d deterministic), and the existing Ultra/HybridEP values inline.
- Export the recipe from both `recipes/nemotronh` `__init__.py` files and add a unit test.
