## Original PR description

## Background

Nightly Megatron-Core bump for the main lane. This moves `3rdparty/Megatron-LM` and `.main.commit` from `3914483f` to `6e7e6ed4`, which adds 7 MCore commits:
- dist_ckpt fp8/fp4 streaming dequantization
- MFSDPv2 `partial_grad` now respects `grad_comm_dtype`
- removal of unused FSDP owner gather/scatter plans
- wide-residual operation selected at construction
- batch-invariant mean fix
- NCCL UBR gradient-buffer offload for RL
- seeded checkpoint load test

`.dev.commit` is unchanged.

## What changed

- `.main.commit` and the `3rdparty/Megatron-LM` gitlink now point to `6e7e6ed435e41af04fc41e7007ef862049153fdc`.
- `uv.lock` was regenerated with `uv lock --upgrade`, giving 9 patch or rc version updates. `uv lock --check` is clean.
- There are no Bridge source or test changes.

## Details

Local validation ran in a `docker/Dockerfile.ci` image built from this head. Diffusion dependencies were enabled for that validation image only.

CI's test template exports `NVTE_FLASH_ATTN_V2=1 NVTE_FLASH_ATTN_V3=0 NVTE_FLASH_ATTN_V4=0`. Two local rows first ran without that setting and failed inside FlashAttention 4 (`flash_attn.cute`) backward:
- `L0_Launch_megatron_fsdp`: a cutlass compiler error.
- Core unit shard 1/3: a 300s timeout.

Both passed when rerun with CI's setting. The MCore delta has no attention changes.

## Tested

All runs were on local H100s against head `39ce73df`.

Unit:
- Core shards 0/3, 1/3, 2/3: 4145, 4112 and 4110 passed.
- Diffusion: 573 passed.

Functional, all passed:
- `training_pretrain`, `training_local_checkpointing`, `training_distributed_save`, `training_finetune`, `training_resiliency`
- `megatron_fsdp` (9/9)
- `models_nemotron_omni`, `models_deepseek`
- `ckpts_mlm_to_mbridge_llama32_1b`, `ckpts_mbridge_to_mlm_llama32_1b`

Not counted as passed:
- `L0_Launch_recipes_deepseek`: the `deepseek_v4_toy` TestData is absent, so every case skips. Skipped at the requester's direction.
- `L0_Launch_models_muse_spark_open`: the image's transformers has no `muse_spark`, so every case skips.
