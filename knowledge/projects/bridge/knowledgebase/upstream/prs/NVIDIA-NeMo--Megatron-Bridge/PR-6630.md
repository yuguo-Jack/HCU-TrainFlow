# feat(model): add MiniCPM-o 4.5 understanding support

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6630) · state: closed · merged: True

## Original PR description

## Summary

Add MiniCPM-o 4.5 understanding support to Megatron Bridge for text, image, audio, and combined image/audio inputs.

- Reuse Qwen3 configuration and weight mappings, the shared GPT builder, and the existing perception-gradient synchronization utility.
- Compose MiniCPM-o’s native vision/audio encoders and projectors with the Megatron decoder.
- Support HF ↔ Megatron checkpoint conversion, excluding TTS weights while preserving native tokenizer, processor, and RoPE metadata.

## Validation

- Real TP2 checkpoint round-trip: all 1,220 understanding tensors match exactly.
- Four native HF CPU inference cases: original and exported checkpoints produce identical input embeddings and generated token IDs.
- Downstream eight-H800 RL smoke: 10 optimizer steps and complete 1,911-question validation; separate verl/verl-omni integration patches were required.
- Six focused CPU tests pass, including independent QKV and gate/up layout checks. Ruff checks pass.

## Scope and dependencies

Understanding and text output only. Supports dense TP with PP=CP=1 and SP disabled; TTS, streaming, packing, and LoRA are out of scope.

The shared CLI conversion test used a separate conversion-worker fix disabling backward-only gradient-accumulation fusion. Native HF inference used Transformers 4.51.0. These results establish functional integration and checkpoint round-trip correctness, not universal HF/Megatron numerical parity or training-quality gains.
