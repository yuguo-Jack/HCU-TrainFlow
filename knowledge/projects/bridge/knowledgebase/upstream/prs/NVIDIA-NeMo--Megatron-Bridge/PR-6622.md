# fix(recipe): use NCCL EP in DeepSeek V3 GB300 deterministic recipe

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6622) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Switch `deepseek_v3_pretrain_256gpu_gb300_fp8mx_deterministic_config` from the HybridEP override back to the base recipe's NCCL EP stack, so it differs from `deepseek_v3_pretrain_256gpu_gb300_fp8mx_config` only by the determinism settings.

# Changelog

- `perf_recipes/deepseek/gb300/deepseek_v3.py`: drop the `moe_flex_dispatcher_backend="hybridep"` / `moe_use_grouped_tensor=False` override, its TODO, and the HybridEP topology env vars (`NUM_OF_HYBRID_EP_RANKS_PER_NVLINK_DOMAIN`, `NUM_OF_TOKENS_PER_CHUNK_COMBINE_API`, `NVLINK_DOMAIN_SIZE`, `USE_MNNVL`); add the base recipe's `NCCL_EP_HT_EM_PULL_PUSH=1`.
- `tests/unit_tests/recipes/test_gb300_ncclep_perf_recipes.py`: assert the deterministic recipe uses the same `flex`/`ncclep` dispatcher and grouped tensor as the base recipe, carries no HybridEP env, and that its env is exactly the base env plus the determinism env.

## Validation

DeepSeek V3, 256x GB300 (64 nodes), MXFP8, TP1 PP2 EP32, GBS 4096, seq 4096, benchmark mock data, 50 iterations, `scripts/training/run_recipe.py`. A1 and A2 use this PR's deterministic recipe with `--deterministic`; B is the base (non-deterministic) recipe.

| Run | lm loss @50 | grad norm @50 |
|---|---|---|
| A1 (deterministic) | 8.120713 | 0.067 |

| B (base) | 7.224594 | 0.770 |

- **Run-to-run determinism:** A1 and A2 report identical lm loss and grad norm on all 50 iterations (at logged precision).
- **Determinism cost**, step time over iterations 20-50 (n=31 each):

| | mean (ms) | median (ms) |
|---|---|---|
| A1 | 10876.0 | 10862.5 |
| A2 | 10991.4 | 10956.7 |
| A (avg) | 10933.7 | 10909.6 |
| B | 10200.3 | 10152.6 |
| **Cost (A vs B)** | **+7.19%** | **+7.46%** |

- No errors, skipped, or NaN iterations in any run.
- Lint: ruff check, import sort, and format (pre-commit pin v0.9.9) pass on both files.
- Unit tests: not run locally; left to CI.

**Open question:** B's loss separates from A's after about iteration 30 (8.12 vs 7.22 at iteration 50). One B run can't tell normal run-to-run variance from an effect of the determinism settings; a second non-deterministic run is the follow-up.
