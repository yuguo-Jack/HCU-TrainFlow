## Original PR description

Bump `nvidia-cudnn-frontend` from 1.29.0 to [1.31.0](https://github.com/NVIDIA/cudnn-frontend/releases/tag/v1.31.0) on the latest release branch, `r0.7.0`, in the Bridge and final framework container overrides. Regenerate `uv.lock` independently against this branch's pinned MCore; only cuDNN Frontend changes version.

Companion main PR: #6430.

Validation:
- `uv lock --no-build-isolation` and `uv lock --check` passed in the CI container.
- `uv run pre-commit run --all-files` passed in the CI container with the existing environment (`UV_NO_SYNC=1`).
- `git diff --check` passed.
- The companion main-branch change passed all 67 tests in `tests/unit_tests/utils/test_gdn_utils.py` with Frontend 1.31.0 installed; those tests were not rerun on this release branch.
