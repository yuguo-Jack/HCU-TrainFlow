# docs(model): re-verify DeepSeek V4 Flash GB200 performance at the current recipe

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6467) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Re-verifies the DeepSeek V4 Flash `pretrain_performance.GB200` card leaf at the current perf recipe and records the measured layout and metrics. Follows @cuichenx's direction on #6463 (closed): perf recipes stay as tuned; the verification card is updated instead.

## Summary

The GB200 leaf recorded EP64 / GBS/MBS 2048/1 from its 2026-08-06 run at `3ecb452af`. #5845 later retuned `deepseek_v4_flash_pretrain_128gpu_gb200_fp8mx_config` to EP32 with 32 HybridEP ranks, so the card no longer described what its published command builds. The published command was re-run unchanged at `b53e66c47` and the leaf now records that run.

# Changelog

- `examples/model_verification_cards/deepseek-v4-flash/card.yaml` (`pretrain_performance.GB200`): `bridge_commit` b53e66c47, `last_verified` 2026-10-14, the five metrics from the run, `expected_result` layout PP1/EP32/CP1/TP1/DP4, GBS/MBS 2048/1.
- `docs/_static/model-verification/catalog-v1.json`, `docs/models/deepseek/deepseek-v4.md`, `docs/fern/.../deepseek-v4.mdx`: regenerated.
- `tests/unit_tests/recipes/test_verification_card_performance_layouts.py`: checks that the EP and GBS/MBS a verified performance leaf records match what its published recipe builds.

## Verification

- Published card command, unchanged, on 32 x 4 GB200, `nvcr.io/nvidia/nemo:26.08` with Bridge `b53e66c47` (MCore `1e3c0c62`): 50/50 steps, 0 skipped, 0 NaN. Resolved config: TP1/PP1/CP1/EP32/ETP1, GBS/MBS 2048/1, seq 4096, MXFP8, HybridEP (32 ranks per NVLink domain), full-iteration CUDA graph, forced routing, expert-rank capacity 1.5, paged stash. Loss 12.59972 -> 4.25929; last 10 steps 8146.440 ms, 731.830 TFLOP/s/GPU, 8061.248 tokens/s/GPU.
- New test, run in the same container: main's card fails `assert (64, 2048, 1) == (32, 2048, 1)`; this branch passes (2 passed).
- `validate_card.py` valid; catalog `--check` clean; pre-commit passed.

# Additional Information

- `pretrain_performance.GB300` (also drifted: card EP64/MBS1, recipe EP32/MBS2) and Nemotron 3 Super `pretrain_performance.GB300` (card EP64, recipe EP16 with the NCCL EP dispatcher) are not re-run yet; they keep their recorded evidence at their pinned commits and will follow in this PR or a follow-up. The new test covers only the re-verified GB200 leaf.
