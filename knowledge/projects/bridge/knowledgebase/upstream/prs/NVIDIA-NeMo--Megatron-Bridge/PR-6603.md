# feat(recipe): add DeepSeek V3 GB300 MXFP8 proxy

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6603) · state: closed · merged: True

## Original PR description

# What does this PR do?

Add a 64-GPU, PP=1 DeepSeek V3 GB300 MXFP8 debugging proxy matched to the VRNVL72 MXFP8 proxy introduced in #6046, including HybridEP and its runtime settings.

# Changelog

- Export `deepseek_v3_pretrain_64gpu_gb300_fp8mx_proxy_config`, selectable with `--gpu gb300 --compute_dtype fp8_mx --num_gpus 64 --config_variant proxy`.
- Use 13 decoder layers (3 dense + 10 MoE), plus 1 MTP layer; PP=1, no VPP, and no inherited interleaved layout.
- Keep TP=CP=ETP=1, EP=32, GBS=4096 and MBS=1, yielding dense DP=64, expert DP=2 and 64 microbatches per iteration.
- Build from the same HybridEP base as VRNVL72, without the production GB300 recipe's NCCL EP/grouped-tensor overrides. Match full-iteration CUDA graphs, cuTeDSL, combined-1F1B MoE overlap, precision, optimizer and per-layer dimensions.
- Match the HybridEP environment: 32 ranks per NVLink domain, 128-token combine chunks, NVLink domain size 72, and MNNVL enabled; remove the NCCL EP environment setting.
- Set `NVTE_ALLOW_NONDETERMINISTIC_ALGO=1` in **both 64-GPU MXFP8 proxies**, as requested, to allow the fused SwiGLU scale-gradient atomic reduction. The VRNVL72 proxy previously set zero; rerun that baseline for matched comparisons. TE revisions enforcing deterministic dprob reject this fused SwiGLU path when the setting is zero.
- Add complete GB300/VRNVL72 config/environment parity coverage, retain overlap and selector tests, and update the environment invariants and usage documentation.

Source-level checks confirm all other recipe functions are unchanged. These are not substitutes for full recipe construction or GPU execution.

- Type checking unavailable locally: `mypy` is not installed.
- GPU execution not run. Memory fit, capture/replay and steady-state performance require validation; the PP=1 reduced-depth proxy is not a direct predictor of full-scale throughput or convergence.
