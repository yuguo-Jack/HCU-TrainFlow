# cp: `docs(model): start the BAGEL FSDP card leaf from scratch (6586)` into `r0.7.0`

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6665) · state: closed · merged: True

## Original PR description

Manual cherry-pick of #6586 into `r0.7.0`.

#6586 merged to main on 2026-10-21 without a release label, so the cherry-pick bot never picked it up. It makes the BAGEL card's FSDP training leaf start from scratch instead of loading a checkpoint that no card item produces (NVBug 6964570). It also adds a doc-consistency test that checks that every published `checkpoint.load` path is written by a command in the same card.

#6599's `r0.7.0` cherry-pick needs this one first: #6599 extends that test, so without #6586 its cherry-pick conflicts on `r0.7.0`.

The change is identical to #6586 (same added and removed lines) and applies to `r0.7.0` without conflicts.

Checks on this branch:
- `validate_card.py`: the BAGEL card is valid, and 26 of 28 cards pass, the same as `r0.7.0` today. The two failures are the Super VL cards' missing HF revision (NVBug 6970566, addressed by #6616).
- `generate_model_verification_catalog.py --check`: up to date.
- `tests/unit_tests/doc_consistency` and the card-validator tests: 124 passed (117 on `r0.7.0` before this change).
- `pre-commit run --all-files`: passed.
