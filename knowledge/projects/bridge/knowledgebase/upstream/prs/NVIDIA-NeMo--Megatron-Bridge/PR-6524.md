[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6524) · state: open · merged: False

## Original PR description

## Summary
- Replace the git-installed cuDNN frontend (`CUDNN_FRONTEND_GIT_REF`, added in #6427) with the PyPI release `nvidia-cudnn-frontend==1.29.1`.
- `docker/common/fw_pyproject.toml`: bump the pin from 1.29.0 to 1.29.1.
- `pyproject.toml`: bump the `override-dependencies` pin to `==1.29.1`. It overrides MCore's `[cutedsl]==1.29.0`.
- `uv.lock`: regenerated with uv 0.7.2 (the CI version) against the pinned Megatron-LM commit. Only the `nvidia-cudnn-frontend` entries changed (version, wheel URLs and hashes, one specifier).
- `docker/Dockerfile.fw_final`: remove the `CUDNN_FRONTEND_GIT_REF` arg, the `--no-install-package nvidia-cudnn-frontend` special case, and the post-sync git install and check. `uv sync` now installs the wheel directly.
- `docker/README.md`: remove the build-arg row.
- `PRESERVE_BASE_RUNTIME=True` behaviour is unchanged.
