# build(security): require GitPython 3.2.1 on main

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6638) · state: closed · merged: True

## Original PR description

CVE-2026-114145 affects GitPython before 3.2.1. The `main` lockfile already resolves 3.2.1, but its dependency override and Framework system-Python install still allow an older vulnerable release.

Raise both minimums to GitPython 3.2.1 while retaining the `<4` upper bound. The lockfile's resolved package stays at 3.2.1; its override manifest reflects the new minimum.

Validation: `uv lock --check` in the project container, `uv run --no-sync pre-commit run --all-files`, and `git diff --check`. CI and a rebuilt image scan remain pending.
