# Adding Full CG to Kimi GB300 config + B200/B300 optimized configs

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/5168) · state: closed · merged: True

## Original PR description

Summary:

Enable the FP8-MX full-iteration CUDA graph tuning stack for Kimi GB300 and addition of DeepEP to B200/B300 performance recipes on the r0.5.0 release branch.

GB300:
enables moe_a2a_overlap
enables full-iteration CUDA graphs with cuda_graph_scope=[]
enables CuteDSL fused grouped MLP
enables FP8 dot-product attention
sets moe_flex_dispatcher_backend="hybridep" 

B200 and B300:
sets moe_flex_dispatcher_backend="deepep"
