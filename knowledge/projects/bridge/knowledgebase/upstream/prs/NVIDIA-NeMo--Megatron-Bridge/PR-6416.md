# docs: pin 0.4.2 links to models removed from main to v0.4.2

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6416) · state: open · merged: False

## Original PR description

## What does this PR do?

#6370 removed the retired model sources from `main`, but `docs/fern/versions/0.4.2/pages/index.mdx` still links to them on `main`. Link check now fails with six 404s on `main` ([scheduled run](https://github.com/NVIDIA-NeMo/Megatron-Bridge/actions/runs/38212983157)) and on every open PR.

This pins those six links to the `v0.4.2` tag, which is the release the page documents:

- `recipes/llama/llama2.py`
- `recipes/gemma/gemma2.py`
- `recipes/deepseek/deepseek_v2.py`
- `recipes/nemotronh/nemotron_nano_v2.py`
- `recipes/nemotron_vl/nemotron_nano_v2_vl.py`
- `models/llama_nemotron/`

All six return 200 at `v0.4.2`. Other links on the page are unchanged.
