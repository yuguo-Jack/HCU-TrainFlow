# fix(peft): preserve layer boundaries in wildcard selectors

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6407) · state: open · merged: False

## Original PR description

The documented PEFT selectors for layers 0 and 1 also match layers 10–19 because `wildcard_match` treats a literal path separator (`.`) as a regex wildcard. This can silently attach adapters to extra layers, or exclude those layers unexpectedly.

Escape periods before expanding `*`. A regression test exercises the existing `ModuleMatcher` target, exclusion and canonical-mapping paths over 24 layers. The production change is one line.

Evidence: the [documented layer selectors](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/2161fe922dc97e503eb1d52d644483066d8e99b0/docs/training/peft.md#L109) and [matcher helper](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/2161fe922dc97e503eb1d52d644483066d8e99b0/src/megatron/bridge/peft/utils.py#L757). This follows the selector-contract investigation prompted by [Automodel #4045](https://github.com/NVIDIA-NeMo/Automodel/pull/4045); no implementation was copied. Related [issue #1738](https://github.com/NVIDIA-NeMo/Megatron-Bridge/issues/1738) concerns unmatched targets, while this fixes overmatching. The candidate was carried forward from the [weekly landscape report](https://linear.app/nvidia/issue/MB-1745/weekly-landscape-learning-2026-10-03-pdt).
