# What does this PR do ?

Cherry-pick #6440 from `main` into `r0.7.0`: deterministic pretrain recipes for Nemotron 3 Ultra/Nano (GB200), Qwen3.5-9B (GB200) and Moonlight-16B (H100).

# Changelog

Picked with `git cherry-pick -x -s` (one commit, `3b91885d5`), rebased onto `r0.7.0` at `39ab66835` (#6439):

- Deterministic recipes for Nemotron 3 Ultra/Nano, Qwen3.5-9B and Moonlight-16B, with docs and unit tests.
- Adds `DETERMINISM_ENV_VARS` in `recipes/utils/environment_utils.py` and a small change in `training/initialize.py`.
- Switches the DSv3 GB300 deterministic recipe's `env_vars` to `**DETERMINISM_ENV_VARS`.

Conflict resolution (one, in `perf_recipes/deepseek/gb300/deepseek_v3.py`): `r0.7.0` already had the explicit determinism env block from #6439. I replaced it with `**DETERMINISM_ENV_VARS`, as in #6440. The resulting function matches `main`.

Not run locally: unit tests (no working Python env on the login node); relying on CI.
