# fix(build): pin leptonai for NeMo-Run API compatibility

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6576) · state: closed · merged: True

## Original PR description

## What does this PR do?

Pin `leptonai==0.27.3` in the NeMo Framework assembly's `override-dependencies` to restore NeMo-Run import compatibility.

NeMo-Run declares `leptonai>=0.26.6` but eagerly imports `leptonai.api.v1` types. Framework assembly resolved LeptonAI 0.47.1, which no longer ships that API, causing `import nemo_run` to fail and blocking HF-to-Megatron conversion and dependent inference tests. Version 0.27.3 retains the required API.

## Changelog

- Add the exact LeptonAI override and a comment explaining the compatibility constraint in `docker/common/fw_pyproject.toml`.
- No root lockfile change: the framework Docker build resolves this separate project during `uv sync`.

## Validation

- Passed all repository pre-commit hooks in a container using `uv run --no-project --with pre-commit pre-commit run --all-files`.
- Parsed the TOML and verified that the override appears exactly once.
- Passed `git diff --check`.
- Full framework image rebuild and runtime `import nemo_run` validation remain pending.
