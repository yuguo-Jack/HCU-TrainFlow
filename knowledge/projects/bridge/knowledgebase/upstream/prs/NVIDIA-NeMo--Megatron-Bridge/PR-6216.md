## Original PR description

# What does this PR do ?

Moves from M-FSDP to GTP for Nemotron 3 Ultra recipes on GB200 and GB300. GTP has better support for checkpointing, and is also convergence tested, along with better support for CUDA Graphs.

# Changelog

- Introduced _apply_nemotron_3_ultra_gtp function to configure GTP settings for dense weight sharding.

- Updated nemotron_3_ultra_pretrain_256gpu_gb200_fp8mx_config and nemotron_3_ultra_pretrain_256gpu_gb300_fp8mx_config to apply GTP settings.

- Added support for GTP sharding in the moe_latent_proj module to address memory pressure.
