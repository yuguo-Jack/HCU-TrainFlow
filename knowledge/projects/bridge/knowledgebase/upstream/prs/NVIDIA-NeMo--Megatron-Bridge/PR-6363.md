# docs(models): re-verify Nemotron Super H100 long-context SFT at a recipe-containing revision

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6363) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Nemotron 3 Super's `sft_long_context.H100` was marked verified at `44f3031a`, a revision where its `--recipe` (`nemotron_3_super_sft_16gpu_h100_bf16_32k_config`) did not exist. QA re-ran the published command at the card default `ffeb5a7a`, which contains the recipe, on 16 H100s; it passed, so the item stays verified with the measurements from that run.

# Changelog

- `examples/model_verification_cards/nemotron-3-super-120b-a12b/card.yaml`: drop the item pin (inherit `ffeb5a7a`); `last_verified` 2026-10-08; metrics and loss range from the QA run. Command, status and index unchanged.
- `docs/_static/model-verification/catalog-v1.json`, `docs/models/nemotron/nemotron3-super.md`, `docs/fern/.../nemotron3-super.mdx`: regenerated.

# Additional Information

- **Root cause:** item pin `44f3031a` predates the `_lowmem_` rename (`1e2a4d24`; squash `0bc1089f`, #5062); only `..._32k_lowmem_config` exists there, so the old metrics could not come from this command.
- **QA run** `20261008T212027Z-82a3b405`: import job 6209706 (8 H100, 7 min), SFT job 6209812 (16 H100, 37 min), both COMPLETED. Env: `nvcr.io/nvidia/nemo:26.06` (the card's base container); Bridge `ffeb5a7ae817`; MCore `6513e3e23d6b`; import re-run at the same revision.
- **Result:** 10 steps, GBS 2, pack 32768, TP1/PP8/CP2/EP2; 0 skipped / 0 NaN; checkpoint and `run_config.yaml` saved at iter 10.
- **Metrics** (card skill definitions, mean of the 10 logged rows incl. the step-1 cold start): loss 1.168852 -> 1.011637; 123114.400 ms; 6.890 TFLOP/s/GPU; 32768*2/(123.1144 s*16) = 33.270 tok/s/GPU. Step-1 loss matches the old record exactly.
- **Execution only:** QA harness runs `run_recipe.py` under srun on the same 2x8 layout with `dist.distributed_timeout_minutes=120`; the import used `UV_EXCLUDE_NEWER=2026-08-04` (current PyPI pulls huggingface-hub 2.x, which the container's transformers rejects).
- **Checks:** `validate_card.py` valid; `generate_model_verification_catalog.py --check` clean; card/catalog/doc-consistency tests 70 passed.
- **NVBug:** 6631246.
