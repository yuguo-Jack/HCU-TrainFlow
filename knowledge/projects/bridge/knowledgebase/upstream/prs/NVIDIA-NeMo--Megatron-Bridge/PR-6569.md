# test(conversion): protect reusable refit task contracts

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6569) · state: closed · merged: True

## Original PR description

# What does this PR do?

Protect conversion contracts used by M-to-N refit clients that reuse task plans, supply logical weight tensors, and assemble canonical local HF views. Existing tests did not directly compare real fused-expert exports with those views or cover filtered replacement-task iterators.

# Changelog

- Add a separate AutoBridge prebuilt-task test: supplied task iterators pass through unconsumed and bypass automatic FP8 task rebuilding. Preserve the existing export test unchanged.
- Check real streaming export with a filtered generator, a BF16 replacement payload, and repeated updates.
- Compare real fused down and gate/up exports against local HF views, including reverse expert task order and both transpose settings.
- Check PP/VP ownership and EP global names through the real task builder, including live parameter references and remote-PP placeholders.

Only two existing test files change. No production code, dependencies, workflows, or new functional jobs are added. Existing tests already cover unsupported local transforms, TP/ETP shard metadata, and FP8 weight/scale pairing and compact scale shapes.

# GitHub Actions CI

These unskipped unit tests are discovered by the existing core unit-test shards. CI is requested for the PR head.

Local validation: required pre-commit checks passed, including Ruff 0.9.9 and formatting. A native focused pytest attempt stopped during conftest import because Megatron-Core is unavailable in the local macOS environment; runtime validation is pending CI.
