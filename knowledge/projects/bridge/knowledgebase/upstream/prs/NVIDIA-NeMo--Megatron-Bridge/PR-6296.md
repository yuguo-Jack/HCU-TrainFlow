# fix(ci): prevent functional test filename shell injection

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6296) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Prevents PR-controlled functional-test filenames from becoming executable shell source on CI runners by encoding matrix strings and passing script names as quoted data.

# Changelog

- Use `jq` to encode JSON entries in the existing H100/GB200 active and flaky matrix loops.
- Pass `inputs.script` through an environment variable for logging and as a quoted positional argument to the existing container shell command.
- Extend the existing action tests to verify that shell characters in filenames remain literal through matrix generation, execution, and result logging, while preserving unit/functional launches and GCP startup behavior.

No filename allowlist checks are needed for this fix. Numeric timeout/GPU header validation is separated into #6298.
