# fix(recipe): remove ineffective grad_reduce_in_fp32 and align Wan 14B perf configs with DFM

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6485) · state: open · merged: False

## Original PR description

# What does this PR do ?

Removes the misleading/ineffective `cfg.ddp.grad_reduce_in_fp32 = True` assignment in `create_perf_config()` and aligns the Wan 2.1 14B (`wan_14b`) performance recipes (`gb200`, `gb300`, `h100`) with the reference configurations in `NVIDIA-NeMo/DFM` (`wan_perf_pretrain.py`).

With the updated `gb200` recipe (tested on 16x GB200 GPUs in BF16 via `scripts/performance/bootstrap.py` with default recipe arguments), end-to-end training throughput improves by **~49% (1.49x)** compared to the current `main` default configuration (and **~61% / 1.61x** on 16x GB300 GPUs). Detailed training logs and TFLOP/s metrics are available upon request—please feel free to reach out to me directly if needed.

# Changelog

- **`src/megatron/bridge/perf_recipes/_common.py`**:
  - Remove `cfg.ddp.grad_reduce_in_fp32 = True` from `create_perf_config()`. During `ConfigContainer.validate()`, `MixedPrecisionConfig.setup()` unconditionally overwrites `ddp.grad_reduce_in_fp32` with `mixed_precision.grad_reduce_in_fp32` (`bf16_mixed` defaults to `True`). Leaving `cfg.ddp.grad_reduce_in_fp32 = True` in `create_perf_config()` is a no-op for presets that define `mixed_precision.grad_reduce_in_fp32 = False`, and is misleading when inspecting recipe overrides.
- **`src/megatron/bridge/perf_recipes/wan.py`**:
  - Explicitly set `cfg.mixed_precision.grad_reduce_in_fp32 = False` for BF16 runs so gradient reduction runs in BF16 as intended by the `wan_14b` BF16 recipe.
  - Align `wan_14b` `gb200`, `gb300`, and `h100` recipes with `NVIDIA-NeMo/DFM`'s `wan_perf_pretrain.py` (`TP=2, CP=4`, `global_batch_size` scaling `2 * num_gpus` on H100 / `4 * num_gpus` on GB200 & GB300, `use_megatron_fsdp=True` with `nccl_ub=True` on GB200, and `use_megatron_fsdp=False` with `recompute_granularity=None` on GB300).
  - Enable `NVTE_NORM_FWD_USE_CUDNN=1`, `NVTE_NORM_BWD_USE_CUDNN=1`, and set `NVTE_FWD/BWD_LAYERNORM_SM_MARGIN=16` on Blackwell (`gb200`, `gb300`) consistent with other Blackwell recipes in `perf_recipes/`.
