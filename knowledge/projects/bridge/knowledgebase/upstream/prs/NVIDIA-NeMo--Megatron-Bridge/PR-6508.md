# test: restore distributed env vars after model test classes

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6508) · state: open · merged: False

## Original PR description

## What does this PR do?

Seven test classes set `MASTER_ADDR`, `MASTER_PORT`, `RANK`, `LOCAL_RANK` and `WORLD_SIZE` in `setup_class` and never unset them:

- `tests/unit_tests/models/qwen_vl/modelling_qwen3_vl/`: `test_rope.py`, `test_attention.py`, `test_transformer_block.py`, `test_utils.py` and `test_model.py`
- `tests/unit_tests/models/qwen3_asr/modeling_qwen3_asr/test_qwen3_asr_model.py`
- `tests/unit_tests/models/qwen_omni/modeling_qwen25_omni/test_omni_model.py`

`setup_class` runs before the autouse `reset_env_vars` fixture takes its per-test snapshot, so these values stay set for every later test in the pytest session, and any test that reads `WORLD_SIZE` sees `1`. I found this through #6500. Once that PR collects `tests/unit_tests/scripts/`, the benchmark `--dry-run` tests in `scripts/training/test_run_recipe.py` pick up `WORLD_SIZE=1` in a full shard and weak-scale from DP 16 to DP 1. #6500 makes those tests clear the variables themselves; this PR stops the leak at its source.

Each class now saves the five variables before overwriting them and restores them in `teardown_class`, after destroying the process group. This is the same pattern `TestQwen3OmniModel` in `modeling_qwen3_omni/test_omni_model.py` already uses.

## Verification

For each file, I ran its tests followed by a throwaway test that asserts none of the five variables is set, all in one pytest session (macOS, CPU torch, Transformer Engine stubbed):

- On `main`, the probe fails after all seven classes.
- On this branch, the probe passes after six of them, and each file's own test outcomes are unchanged.
- The exception is `modelling_qwen3_vl/test_utils.py` on a machine without CUDA. Its `setup_class` calls `torch.cuda.set_device` and initializes NCCL unconditionally, so it raises there, and pytest does not run `teardown_class` after a failed `setup_class`. On CI's GPU runners the setup succeeds and the restore runs.

`pre-commit run --all-files` passes.
