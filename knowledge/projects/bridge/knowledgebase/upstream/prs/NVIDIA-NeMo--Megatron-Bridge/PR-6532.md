# feat(nemotronh): implement symmetric memory collectives for GTP and DDP communication

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6532) · state: open · merged: False

## Original PR description

Added a new function `set_up_symm_mem_collectives` to configure NCCL symmetric-memory collectives for GTP and DDP communication. Updated relevant pretrain configurations across GB200, GB300, and VRNVL72 to utilize this new setup, enabling improved performance with NVLS. Added unit tests to verify the correct application of these settings in the recipes.
