# fix(recipe): restore DeepSeek V4 Flash GB200/GB300 perf layout verified on the model card

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6463) · state: closed · merged: False

## Original PR description

# What does this PR do ?

Restores the DeepSeek V4 Flash GB200/GB300 128-GPU MXFP8 perf recipes to the layout on the verified model card. Per Chen's comment, card evidence takes precedence; this restores the card-verified layout.

## Summary

The card's `pretrain_performance.GB200`/`.GB300` commands verified TP1/PP1/CP1/EP64/ETP1, GBS/MBS 2048/1, 64 HybridEP ranks per NVLink domain. #5845 later moved both recipes to EP32 (GB300 also MBS 2) with 32 HybridEP ranks, so the verified commands now build a different layout on main.

# Changelog

- `perf_recipes/deepseek/gb200/deepseek_v4.py`: EP 64, HybridEP ranks 64.
- `perf_recipes/deepseek/gb300/deepseek_v4.py`: drop EP32/MBS2 overrides (inherits EP64/MBS1), HybridEP ranks 64.
- `perf_recipes/deepseek/vrnvl72/deepseek_v4.py`: pin its own EP32/MBS2 so VRNVL72 keeps its current layout.
- `tests/unit_tests/recipes/test_deepseek_v4_flash_perf_recipes.py`: GB200/GB300 back to the card layout; VRNVL72 asserts its pin.

## Verification

- Red-green on GB200 (nemo:nightly 2026-10-14): origin/main recipes fail the GB200/GB300 tests (`assert 32 == 64`); the branch passes all 5 tests.
- Config build: GB200/GB300 resolve EP64, GBS/MBS 2048/1, HybridEP 64; VRNVL72 unchanged (EP32, MBS 2).
- 128-GPU perf runs not re-run; this restores the verified values.

Nemotron 3 Super GB300 NVFP4 (same NVBug) is out of scope: its recipe moved to the NCCL EP dispatcher, so EP64 alone would not match the card.
