Add Megatron-Bridge support for loading and exporting the released DeepSeek-V4.1-Flash checkpoint with the native Megatron-Core V4.1 model.

# Changelog

- Register `DeepSeekV41Bridge` and `DeepSeekV41ModelProvider`.                                                                                                                  
- Add native provider construction and configuration round-tripping for `DeepSeekV41Model`.                                                                                     
- Add HF-to-MCore and MCore-to-HF mappings for:                                                                                                                                 
  - attention and MoE physical layers                                                                                                                                           
  - HyperConnections                                                                                                                                                            
  - vision and aligner modules                                                                                                                                                  
  - Engram tables                                                                                                                                                               
  - DSpark draft modules                                                                                                                                                        
- Decode the checkpoint's block-32 FP8 weights and packed MXFP4 expert weights during import.                                                                                   
- Restore the released FP8 and packed MXFP4 layouts during export.                                                                                                              
- Stream Engram rows directly from SafeTensors, including uneven EP ownership and TP broadcasts, without materializing the full table.                                          
- Add unit coverage for mapping registration, quantized weight conversion, Engram row streaming, replicated buffers, and export conversion.
