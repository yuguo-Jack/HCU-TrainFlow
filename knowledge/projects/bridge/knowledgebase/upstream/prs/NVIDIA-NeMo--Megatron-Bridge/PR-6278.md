## Original PR description

# What does this PR do ?

Add Shensi model support to Megatron-Bridge: a sparse-attention Mixture-of-Experts family with its Hugging Face configuration, Megatron-Core provider, AutoBridge parameter mapping and tests.

Shensi is a sparse-attention Mixture-of-Experts family: every decoder layer picks one of three attention paths from a per-layer plan (compressed sparse attention, heavily compressed attention or a sliding window), the residual stream is a pool of streams that sublayers read from and write back into, layers are grouped into attention-residual blocks that may span pipeline stages, the leading layers are token-embedding-gated dense MLPs, and the routed experts of the remaining layers run through a low-rank bottleneck with an ERC auxiliary loss.

The hybrid attention itself is Megatron-Core's `dsv4_hybrid` path; this bridge adds what sits around it and maps the checkpoint both ways.

# Changelog

- configuration_shensi.py: HF-side config with the per-layer attention/MLP plans, the split RoPE parameters and validation, plus the Megatron-Core transformer config carrying the Shensi fields
- modeling_shensi.py: mHC hyper-connections, attention residuals (including their pipeline-state transfer), the MoE layout, selective fp32 keeping, the decoder layer, layer specs and the model
- shensi_provider.py: provider deriving the Megatron-Core fields from the config and building the decoder block and MTP specs
- shensi_bridge.py: AutoBridge entry for config and parameter mapping, covering the mHC mixers, attention-residual readers, compressor and indexer weights and the hash-MoE layers
- tests: unit tests for the attention-residual module and the bridge mappings, functional tests for the HF <-> Megatron round trip, the forward pass, right-padding behaviour and the provider/MTP configuration, registered in `tests/functional_tests/launch_scripts/h100/active/L0_Launch_models_shensi.sh`
- docs and registry: models/shensi/README.md documents the model, models/__init__.py registers the package and README.md lists it
