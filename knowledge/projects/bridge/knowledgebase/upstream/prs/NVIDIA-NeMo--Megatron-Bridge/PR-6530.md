# build(deps): require Transformers 5.20.1

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6530) · state: closed · merged: False

## Original PR description

Require Transformers 5.20.1 and refresh its lock entry so Bridge installations include native Beam configuration and modeling support. Retain the existing `<5.21` upper bound; no other locked package version changes.

This is the dependency prerequisite for removing the local Beam configuration fallback in #6528. The recipe PR carries the same dependency update so its tests can install native Beam while this PR is pending.

Validation: tested together with the native Beam cleanup in #6528 using NeMo 26.10 RC5 with only Transformers upgraded to 5.20.1. The focused Beam, H200/GB200 recipe, AutoBridge, model bridge, conversion utility and HF wrapper suites passed: 631 passed, 27 CUDA-only skips. Native Beam config roundtrips and tiny HF model construction/forward passed. Generated-document consistency and all-files pre-commit hooks passed. `uv lock --check --offline` also passed with uv 0.9.9 and the CI-pinned uv 0.7.2. This does not claim new GPU performance measurements.
