## Original PR description

# What does this PR do ?

**Draft — blocked on [NVIDIA/Megatron-LM #8234](https://github.com/NVIDIA/Megatron-LM/pull/8234). Do not merge until that PR lands and Bridge's Core dependency includes its generic serialization helpers.**

Adapt Bridge config serialization to the removal of Core's `_convert_value_to_dict()` subclass hook, preserving Bridge-specific constructor inputs.

# Changelog

- Normalize nested pipeline layouts, composite Hugging Face configs, and quantization recipes at Bridge's serialization boundary, without mutating live configs or rerunning constructors.
- Delegate ordinary dataclass serialization, callable encoding, and Transformer runtime-field exclusions to Core's generic helpers; preserve GTP shard constructor values.
- Update the GPT dataset, Mamba, and distillation serializers that directly called the removed hook. Their existing custom field policies remain unchanged.
- Update existing serialization tests to use the Bridge value serializer; add nested-layout/YAML, builder metadata, and nonmutation coverage.
- Leave the Core pin, dependencies, and CI configuration unchanged. The dependency update is separate from this compatibility patch.
