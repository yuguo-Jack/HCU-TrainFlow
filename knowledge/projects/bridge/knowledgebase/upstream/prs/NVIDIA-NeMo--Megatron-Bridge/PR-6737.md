# fix(quant): export quantized experts mapped with Column/RowParallelMapping

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6737) · state: closed · merged: True

## Original PR description

# What does this PR do ?

`save_hf_pretrained_modelopt` can now export quantized MoE experts that a bridge maps directly with `ColumnParallelMapping` or `RowParallelMapping`.

The quantized export packs each expert before the EP gather, through a local-expert copy of its mapping. Only `AutoMapping`, `GatedMLPMapping` and the fused expert mappings had one. The GLM-5.3-Flash bridge (#6044) maps the routed experts' `down_proj` with `RowParallelMapping`, so its export failed at every EP size, with grouped-GEMM and with sequential experts:

```
ModelOpt expert mapping validation failed: NotImplementedError: ModelOpt real-quant export cannot pack expert mapping RowParallelMapping before its EP gather
```

# Changelog

- `_local_expert_mapping` routes plain `ColumnParallelMapping` / `RowParallelMapping` experts to the existing `_LocalExpertColumnMapping` / `_LocalExpertRowMapping`. Subclasses are still rejected, as for the other mapping types (`test_custom_quantized_expert_mapping_is_rejected_before_ep_gather`).

# Tests

- New `test_parallel_expert_mapping_is_packed_before_ep_gather` (Column and Row): the expert is exported before the EP gather and matches ModelOpt's packing of the same weight. Both cases fail on `main` with the error above.
- `tests/unit_tests/models/test_modelopt_utils.py`: 80 passed (`nvcr.io/nvidian/nemo:26.10.rc9`).
- Tiny GLM-5.3-Flash (KDA + DSA layers, MoE, MTP, vision tower) from #6044 at e342d93 with this change, NVFP4 on the routed experts and dense MLP: the export at EP=2 and at TP=2 has the same 175 tensor names and values as ModelOpt's Megatron exporter at EP=2, including every NVFP4 weight and scale, and EP=2 matches TP=2 bit for bit. (Unrelated to this change, the bridge writes the mHC `hc_*_fn` and the indexer's `index_kpool_compress_ape` in their Megatron dtype, F32, where ModelOpt and the source use BF16.)
