## Original PR description

# What does this PR do ?

Fixes the local CG deletion bug that led to NCCL hang due to uncleared CG runners

# Changelog

- Introduced _delete_local_cuda_graph_runners to clear CUDA graph runners from each model chunk.
- Updated _delete_cuda_graphs to accept a model parameter for improved cleanup.
- Modified unit tests to validate the new cleanup functionality and ensure proper synchronization of CUDA graphs.
