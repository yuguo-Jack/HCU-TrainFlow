# build: fix MLflow and filelock scan findings on r0.7.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6659) · state: closed · merged: True

## Original PR description

## Summary
- Raise the MLflow minimum to 3.17.2 and update MLflow, mlflow-skinny, and mlflow-tracing in the lockfile to address CVE-2026-53995.
- Resolve filelock to 4.2.4, above the 4.2.1 fix for CVE-2026-112940.
- Override the transitive filelock requirement because multi-storage-client 0.51.0 still declares `filelock<4`.

## Validation
- Regenerated `uv.lock` in the NVIDIA PyTorch 26.09 container; only MLflow family and filelock package versions changed.
- `git diff --check` passed.

## Compatibility note
The filelock override crosses multi-storage-client's declared upper bound. Please validate its file locking paths in CI before merging. Remove the override when multi-storage-client supports filelock 4.

Advisories: https://github.com/advisories/GHSA-wqmh-qccw-pqwf and https://github.com/tox-dev/filelock/security/advisories/GHSA-v4x8-3wr5-3wq8
