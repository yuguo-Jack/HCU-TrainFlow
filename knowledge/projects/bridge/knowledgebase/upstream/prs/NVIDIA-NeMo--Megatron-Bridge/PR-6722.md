# perf(recipe): enable NCCL EP for Qwen3 on B200 and B300

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6722) · state: open · merged: False

## Original PR description

# What does this PR do ?

Enable NCCL EP for Qwen3 30B-A3B and 235B-A22B B200/B300 performance recipes, with the B200 settings from the fastest successful runs. This PR contains only Qwen3 changes.

# Changelog

- Use the NCCL EP flex dispatcher, grouped tensors, and `NCCL_EP_HT_EM_PULL_PUSH=1` for the 8-GPU 30B BF16/MXFP8 and 64-/256-GPU 235B BF16/MXFP8/NVFP4 recipes, including the MXFP8 large-scale variants. EP groups target a single NVL8 domain.
- Set `model.moe_flex_dispatcher_num_sms=32` for 30B MXFP8 on 8× B200.
- For 235B BF16 on 256× B200, disable `comm_overlap.overlap_param_gather`, `comm_overlap.align_param_gather`, `ddp.overlap_param_gather`, `ddp.align_param_gather`, and `optimizer.overlap_param_gather`. CUDA graphs remain disabled for this recipe.
- Set VP=2 for 235B NVFP4 on 256× B200; preserve the existing CUDA graph modes and other parallel settings.
- Extend dispatcher coverage to the B200/B300 Qwen3 recipes, update the old HybridEP test expectations, and restrict 235B layout assertions to 235B recipes.
