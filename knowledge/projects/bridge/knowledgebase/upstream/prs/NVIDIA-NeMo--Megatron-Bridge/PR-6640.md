# fix(build): preserve patched AnyIO in Framework images

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6640) · state: closed · merged: True

## Original PR description

# What does this PR do?

Prevent the Framework image's final dependency sync from selecting an AnyIO version below 4.14.2, the patched floor for CVE-2026-63374.

MCore already declares this minimum as a UV override, but `fw-final` resolves a separate project under `/opt/NeMo-FW`. It therefore needs its own override. LeptonAI 0.27.3 caps AnyIO at 4.9.0 and can downgrade an existing 4.15.1 installation during this later sync.

# Changelog

- Add `anyio>=4.14.2` to `docker/common/fw_pyproject.toml`'s existing `override-dependencies`.
- Preserve the Framework project's other dependency choices. No tracked Framework lockfile exists to regenerate.

Primary area: `area:build`.

# GitHub Actions CI

Local validation:

- `uv run pre-commit run --all-files` and `git diff --check` passed.
- The complete modified Framework project resolved successfully with `uv lock` against the existing image's local Export-Deploy, Evaluator, and Run sources: AnyIO 4.15.1 and LeptonAI 0.47.1. The generated lock manifest records the AnyIO override.
- A focused UV resolution check selected AnyIO 4.9.0 with LeptonAI 0.27.3 before the override, and AnyIO 4.15.1 with the override extracted from the modified configuration.
- Ten targeted LeptonAI 0.27.3 checks passed with each of AnyIO 4.9.0, 4.14.2, and 4.15.1 on Python 3.12.3. They cover Photon save/load, synchronous/asynchronous batching and concurrency, and disconnect cancellation.
- NeMo-Run's Lepton scheduler and executor imports passed with all three versions.

Compatibility checks ran in disposable copies of the existing `fw-final:pipe.75385261` image, changing only AnyIO. A full Framework image rebuild and live Lepton job submission were not performed locally.
