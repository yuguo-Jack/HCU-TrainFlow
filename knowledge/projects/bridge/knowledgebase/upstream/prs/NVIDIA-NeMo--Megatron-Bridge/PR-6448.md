## Original PR description

# What does this PR do ?

Remove the Nsight Systems EFA metrics plugin from all Linux target directories. The existing `target-linux-x64` glob leaves the plugin in ARM target directories.

# Changelog

- In `docker/Dockerfile.ci`, change the cleanup path to `/usr/local/cuda-*/NsightSystems-cli-*/target-linux-*/plugins/efa_metrics/`.

# GitHub Actions CI

- `uv run pre-commit run --all-files` passed in a Python 3.12 container.
- Temporary `/bin/sh` fixtures verified removal for x64, SBSA, and aarch64 across multiple CUDA/Nsight versions, preservation of unrelated plugins, and success when nothing matches.
- `git diff --check` passed.
- Full container rebuild has not been run.
