# docs(resiliency): replace removed upstream restart guide on r0.7.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6584) · state: closed · merged: True

## Original PR description

The upstream In-Process Restart Guide now returns HTTP 404, breaking the link check on unchanged resiliency documentation (including PR #6582). [NVRx PR #453](https://github.com/NVIDIA/nvidia-resiliency-ext/pull/453) removed the deprecated package and documentation after v0.7.0 and recommends in-job restart through `ft_launcher`.

Replace the dead related-guide link with the correctly named NVRx Fault Tolerance Usage Guide and clarify the version requirement in all three Markdown/MDX copies. Preserve Bridge's existing in-process capability description: both target branches lock NVRx 0.7.0, which still contains the deprecated APIs. No runtime or link-check configuration changes.

Validation: `UV_NO_SYNC=1 uv run pre-commit run --all-files` and `git diff --check` passed. Lychee 0.24.2 checked HTTP(S) links in all three changed pages with the workflow's request/status settings: 30 links, 17 unique, 9 OK, 21 non-HTTP links excluded, zero errors. Direct HTTP checks returned 404 for the old guide and 200 for the replacement. These are targeted page checks, not a full documentation build or repository-wide link scan. A fresh independent review covered both complete diffs before publication.

Release companion to #6583, targeting `r0.7.0` with the identical documentation patch. The release label is applied here; main intentionally has no auto-cherry-pick label because this companion is already open.
