# perf(recipe): use NCCL EP for GPT-OSS 120B BF16 on B200 and B300

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6542) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Switch the GPT-OSS 120B BF16 B200 and B300 perf recipes to the NCCL EP flex dispatcher, following the NCCL EP move already made for the GB200/GB300 MoE recipes.

# Changelog

- `perf_recipes/gpt_oss/b300/gpt_oss.py` (`gpt_oss_120b_pretrain_64gpu_b300_bf16_config`): HybridEP → NCCL EP via `_enable_ncclep`, keep `moe_use_grouped_tensor=True`, add `NCCL_EP_HT_EM_PULL_PUSH=1`, drop the four HybridEP topology variables.
- `perf_recipes/gpt_oss/b200/gpt_oss.py` (`gpt_oss_120b_pretrain_64gpu_b200_bf16_config`): alltoall → NCCL EP via `_enable_ncclep`, `moe_use_grouped_tensor=False` (faster on this eager, no-CUDA-graph recipe), add `NCCL_EP_HT_EM_PULL_PUSH=1`.
- New `tests/unit_tests/recipes/test_gpt_oss_nvl8_ncclep_perf_recipes.py`: both recipes use flex + ncclep, EP=8, pull/push on, no HybridEP variables, and the per-GPU grouped-tensor setting.

Pull/push mode is valid because EP=8 keeps every EP group inside one NVL8 domain; the test pins EP=8 so a later EP change has to revisit it.

# Performance

64 GPUs, BF16, mean iteration time over iterations 30–44.

**B200, internal CI (nightly image), MBridge `main` vs this PR:**

| | Dispatcher | Iteration time | TFLOPS/GPU |
|---|---|---|---|
| `main` (4f02f0fa0) | alltoall | 5,747 ms | 465.2 |
| this PR (ec1e287e1) | NCCL EP | 6,015 ms | 444.8 |

Both runs complete training. Both trip the CI performance check as an *improvement* against the stored B200 golden values, which are older than both; those goldens need a refresh after merge.

**Dispatcher A/B (NeMo 26.10 RC image, one or two runs per arm, runs within an arm agree within 0.8%):**

| | B300 | B200 cluster 1 | B200 cluster 2 |
|---|---|---|---|
| alltoall | — | 5,858 ms | 5,719 ms |
| flex + HybridEP | 4,986 ms | 6,099 ms (+4.1%) | — |
| NCCL EP, grouped tensors on | 5,016 ms (+0.6%) | 6,245 ms (+6.6%) | 6,081 ms (+6.3%) |
| **NCCL EP, grouped tensors off (B200 in this PR)** | — | **6,154 ms (+5.1%)** | **6,028 ms (+5.4%)** |
| NCCL EP, pull/push off | — | 6,449 ms (+10.1%) | 6,300 ms (+10.2%) |

- **B300:** NCCL EP is at parity with HybridEP.
- **B200:** NCCL EP is ~5% slower than the current alltoall recipe. About 4 points of that come from moving this eager recipe onto the flex dispatch path at all (HybridEP pays it too); NCCL EP vs HybridEP is +0.9% with grouped tensors off.
- Pull/push off is clearly slower, so it stays on.

The B300 numbers come from benchmark runs outside CI: CI currently has no B300 cluster to run the B300 test on.
