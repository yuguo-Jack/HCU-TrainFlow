# chore: AUT-2643 MCore main bump to 3ddfe0fe

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6688) · state: closed · merged: True

## Original PR description

## Background

This is the nightly bump of the Megatron-Core (MCore) `main` pin (AUT-2643). The pin moves from `ed9c2c8c` to `3ddfe0fe07efc73dbdc40d4a02acbc1c1f8a9f08`. That range has 10 MCore commits. `.dev.commit` does not change.

## What changed

- `.main.commit` and the `3rdparty/Megatron-LM` gitlink point to `3ddfe0fe`.
- `uv.lock` is regenerated with `uv lock --upgrade`. The upgraded packages are cachetools, dulwich, msgpack, openai, pyasn1, ruff, tensorstore and virtualenv.
- `tests/unit_tests/training/test_model_load_save.py`: the fixture for the paged-stash dropless test now uses fused SwiGLU (`gated_linear_unit=True`, `activation_func=F.silu`, `bias_activation_fusion=True`). After MCore #6828, `moe_paged_stash` on this GroupedTensor path needs fused SwiGLU or QuickGeGLU. The test assertions do not change.

## Details

- The MCore range changes no dependency files.
- The PR has 2 signed commits: `c96d867f` (pin and lock) and `e63f10f0` (test fixture).
