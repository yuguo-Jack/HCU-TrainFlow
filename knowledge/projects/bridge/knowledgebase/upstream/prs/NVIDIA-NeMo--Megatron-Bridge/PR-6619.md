# [training] fix: propagate in-process restart cleanup failures

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6619) · state: open · merged: False

## Original PR description

When in-process restart is enabled, a failure in `destroy_global_state()` or `GlobalState.reset_for_restart()` is logged and swallowed by Bridge's cleanup callback. NVRx's `ThreadedFinalize` does not forward worker exceptions, so finalization appears successful despite incomplete cleanup.

Record the cleanup error and relay it on the caller thread after the worker joins. This preserves successful cleanup and lets NVRx abort the retry on a finalization failure. Tests use native NVRx composition/threaded finalization with mocked CUDA access and cleanup endpoints.

Related upstream glue: NVIDIA/Megatron-LM#7029. Bridge owns its separate restart wrapper; no MCore patch or paired PR is needed. This applies to the documented in-process path with an NVRx release that includes the deprecated API.
