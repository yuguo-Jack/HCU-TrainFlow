# build(security): update Framework Python dependencies for r0.7.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6558) · state: closed · merged: True

## Original PR description

The 26.10 RC image contains cryptography 48.0.1, httpx2/httpcore2 2.6.0, and Tornado 6.5.6. The Framework image build now requires cryptography 50.x, httpx2/httpcore2 2.12+, and Tornado 6.5.8.

The Bridge cryptography override and `uv.lock` also move to cryptography 50.0.2. HTTPX2 and HTTPcore2 were already patched in the Bridge lockfile; the Framework override ensures the final image resolves patched versions when it installs NeMo-Run and Export-Deploy.

Validation: `uv lock` completed in the CI container; `uv run --no-sync pre-commit run --all-files` passed. A new Framework image build and vulnerability scan are needed to verify final installed versions on both architectures.

Label: `needs-more-tests` for dependency CI coverage.
