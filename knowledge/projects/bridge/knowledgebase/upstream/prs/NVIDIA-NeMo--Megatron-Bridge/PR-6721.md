## Original PR description

# What does this PR do ?

Adds a deterministic Nemotron 3.5 Lightning 8K pretraining recipe.

# Changelog

- `nemotron_3_5_lightning_pretrain_8k_deterministic_config` (new, GB200): wraps `nemotron_3_5_lightning_pretrain_8k_config` with `apply_determinism_overrides` and the GB200 environment of the Nemotron 3 Nano deterministic recipe. Exported from `megatron.bridge.recipes.nemotronh`.
- Tests for the new recipe in `tests/unit_tests/recipes/nemotronh/test_nemotron_3_nano.py`.

# Validation

- Measured on 8x GB200 (two nodes in one NVL72 rack), 20 steps, warm-started Lightning, RedPajama2 data:
  - Lightning with these settings: two runs on different racks match in float32 at every step (LM, MTP-1, MTP-2 and load-balancing losses, grad norm). 23.5 s per step against 19.6 s non-deterministic in the same allocation (mean of steps 11–20); rank-0 peak 175.9 / 181.2 GB allocated / reserved.
- `tests/unit_tests/recipes/nemotronh`: 107 passed.
- pre-commit on the changed files: passed.
