# build(security): require GitPython 3.2.1 on r0.7.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6637) · state: closed · merged: True

## Original PR description

CVE-2026-114145 affects GitPython 3.2.0 on the `r0.7.0` source scan. An attacker-controlled submodule path can place a Git hook before the path is rejected; a later Git operation can execute it.

Require GitPython >=3.2.1 in both the Bridge dependency override and the Framework image's system-Python install. Regenerate `uv.lock` from 3.2.0 to 3.2.1. The existing upper bound `<4` remains.

Validation: `uv lock` and `uv lock --check` in the project container, `uv run --no-sync pre-commit run --all-files`, and `git diff --check`. CI and a rebuilt image scan remain pending.
