# fix(model): preserve fractional Qwen3-Omni video positions

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6348) · state: open · merged: False

## Original PR description

# What does this PR do ?

Preserve fractional video time coordinates in Qwen3-Omni multimodal RoPE, matching the Hugging Face thinker implementation.

For example, with `second_per_grids=0.25` and `position_id_per_seconds=13`, the temporal coordinates should be `[0, 3.25, 6.5, 9.75]`. The current `.long()` turns them into `[0, 3, 6, 9]` before RoPE is applied. That also changes subsequent text positions and can change video/audio interleaving when a fractional video position is truncated onto an audio position.

# Changelog

- Use `.float()` instead of `.long()` for expanded temporal coordinates in `get_llm_pos_ids_for_vision`.
- Add CPU regression coverage for fractional and integral temporal coordinates, video/text position offsets and RoPE deltas, and video/audio interleaving.
