# feat(model): add Reflection AI Beam support

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6498) · state: closed · merged: True

## Original PR description

# What does this PR do?

Adds Megatron Bridge support for **Reflection AI Beam-1.0-501B-A23B**, including Hugging Face checkpoint conversion, model construction, inference, and H200 pretraining, full SFT, and LoRA PEFT recipes.

The integration registers `BeamForCausalLM` with `AutoBridge` and builds a native Megatron-Core `HybridModel` through `BeamModelConfig` and `BeamModelBuilder`. `BeamModelProvider` is also available for provider-based callers.

# Changelog

- Implement Beam's attention and MoE stack: mixed sliding-window RoPE/full-attention NoPE layers, SSMax query scaling, gated attention output, sandwich normalization, depth-scaled residuals, grouped sigmoid expert routing, FP32 router parameters, and output-logit soft-capping.
- Add bidirectional HF/Megatron configuration and tensor mappings, including attention-gate packing, expert weights and router bias, plus per-output-channel FP8 weight dequantization on import.
- Support builder-backed model families when merging and exporting LoRA adapters in `AutoBridge`. Add an overridable HF adapter `target_modules` hook so exported adapters select the intended modules.
- Add BF16 H200 library recipes for pretraining and full SFT on 128 GPUs, and LoRA PEFT on 16 GPUs, with documented long-context SFT settings.
- Add `--max-gpu-memory-gib` to the HF inference verifier to reserve loading headroom for large models.
- Add tests for configuration validation, modeling operations, tensor mapping round trips, FP8 import, adapter export, recipes, and inference-verifier options.
- Add the [model guide](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/8a0ebe5c7306f8349a60c2efbaea23f05612af94/examples/models/beam/README.md) and [verification card](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/8a0ebe5c7306f8349a60c2efbaea23f05612af94/examples/model_verification_cards/beam/card.yaml), and regenerate the verification catalog, model pages, and documentation navigation.

# Validation and scope

The verification card records CPU/GPU BF16 checkpoint round trips, HF/Megatron forward-pass comparison, deterministic Megatron inference, pretraining, SFT, long-context SFT, PEFT, checkpoint resume, and deterministic HF inference after SFT export. Its timing and throughput metrics are functional verification observations; this PR does not provide a canonical optimized pretraining benchmark result.

On the final PR head, core unit-test shards, diffusion unit tests, the import check, lint, copyright, documentation, and link checks passed. The [DeepSeek recipe L0 job](https://github.com/NVIDIA-NeMo/Megatron-Bridge/actions/runs/38897637873/job/117011109195) failed, so the aggregate NeMo CI result was not fully green.

The documented inference path uses legacy full-prefix generation; KV-cache inference is not verified. CPU conversion still requires one runtime GPU for Transformer Engine construction. HF loading requires a Beam-enabled Transformers build. The supplied training recipes are BF16; FP8 import support does not imply FP8 training recipes.
