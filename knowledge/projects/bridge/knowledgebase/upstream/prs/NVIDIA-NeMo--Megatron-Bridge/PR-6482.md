## What does this PR do?
Restores publication of the released Nemotron 3.5 Super VL and Nemotron-3.5 Super Text-only guides, reversing the publication restrictions introduced by #6380.

## Changelog
- Restore both guides in Sphinx and nightly Fern navigation and Nemotron indexes.
- Remove the temporary redirects and Sphinx exclusions that hid the guides.
- Remove catalog filtering and regenerate Supported Models from the current cards.
- Add regression coverage for both guides, navigation, catalog links, exclusions, and redirect absence.
- Preserve guide content, verification cards, model code, and current main changes.
