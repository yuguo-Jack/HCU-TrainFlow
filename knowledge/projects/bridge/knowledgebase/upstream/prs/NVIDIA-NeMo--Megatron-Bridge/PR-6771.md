## Original PR description

# What does this PR do?

Enable response-relative asymmetric diffusion attention and packed/unpacked causal context parallelism for NemotronLabsDiffusion, with native checkpoint RoPE configuration and attention optimizations.

# Changelog

- Add response-relative asymmetric attention metadata, masks, and position handling for noisy/clean sequences.
- Build diffusion masks lazily, compile block-mask construction, and use native grouped-query FlexAttention with a compatibility fallback.
- Resolve checkpoint RoPE into native Megatron provider fields, preserve FP32 rotary frequencies across dtype casts, and keep runtime RoPE modules out of serialized layer specs.
- Derive NemotronLabsDiffusion from the text-only Mistral provider, removing `hf_config` and unused vision fields while preserving text architecture and YaRN defaults. Update the CPT recipe to use the text-only parent.
- Enable embedding scattering for sequence parallelism and causal, cache-disabled AR attention with packed or unpacked context parallelism.
- Add unit and distributed parity coverage; preserve caller-owned layer specs on successful and failed model construction.
