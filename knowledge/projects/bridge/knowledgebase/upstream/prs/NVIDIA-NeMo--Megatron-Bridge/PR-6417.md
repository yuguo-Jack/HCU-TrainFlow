# feat(qwen3-omni): forward the native output processor

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6417) · state: open · merged: False

## Original PR description

## What does this PR do?

Forward Megatron Core's existing output processor through Qwen3-Omni Thinker, allowing external callers to return structured outputs such as log probabilities and entropy. The default tensor path remains unchanged.

## Changes

- Forward `output_processor` and its opaque context to the language model.
- Preserve structured callback results and gradients; update the shared Qwen3-VL text return annotations.
- Add tests for default outputs, context identity, gradients, structured results and exception propagation.

No new kernel, dependency, runtime workaround or performance claim is included.

## Validation

- 14 focused CPU tests and all repository pre-commit checks pass.
- TP1 and TP2/SP parity checks pass for normal/empty response masks, answer log probabilities, entropy and 133 populated parameter gradients.
- A real AVQA smoke completes one optimizer update on eight H800 GPUs with active callbacks, finite metrics, nonzero gradients and zero official-reward mismatches over 128 outputs; natural exit and resource release verified.

Tests above use Bridge `5f1250ac` / Core `a8a5977f` and a declared development runtime. They do not establish default dependency compatibility or end-to-end speedup. The changed production files are unchanged on current main.

Strict typing is not fully green: the tested Core pin has a module-discovery issue. With that corrected separately, the baseline has 71 diagnostics and this patch has 69, with no new diagnostics. The Core correction is outside this PR.

AI assistance was used for implementation and validation.
