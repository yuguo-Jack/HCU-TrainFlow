## Original PR description

# What does this PR do ?

Support NVCRE init containers for llmb K8s workloads

# Changelog

Added --nvcre_init_containers_json, forwarded to NvcreExecutor.init_containers, and
--nvcre_bridge_root (default /opt/Megatron-Bridge) so the generated command and
PYTHONPATH can use a Megatron-Bridge checkout that an init container placed in the
pod instead of the image's copy.
