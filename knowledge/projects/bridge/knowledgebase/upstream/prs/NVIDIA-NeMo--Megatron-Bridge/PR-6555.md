# fix(training)!: use DDP config to enable Megatron FSDP

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6555) · state: open · merged: False

## Original PR description

# What does this PR do ?

Use `DistributedDataParallelConfig.use_megatron_fsdp` as the single Megatron FSDP enablement flag, matching Megatron Core after its removal from `DistributedInitConfig`. Model wrapping, config validation, and parameter-norm logging all read `cfg.ddp.use_megatron_fsdp`.

# Changelog

- Remove Bridge's legacy `DistributedInitConfig.use_megatron_fsdp` field and synchronization between config objects. Existing configurations must replace `dist.use_megatron_fsdp` with `ddp.use_megatron_fsdp`.
- Migrate recipes, YAML overrides, functional fixtures, current documentation, and the FSDP skill. Preserve versioned 0.4.2 documentation.
- Cover both model-building paths, parameter-norm logging, and mutual exclusion with Torch FSDP2. Include WAN recipes and emerging optimizer validation added on current main.
- Preserve main's FP32 router handling and layerwise optimizer arguments while resolving the rebase conflicts.
