# build(security): pin Pillow 13.0.0 in Framework image

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6581) · state: closed · merged: True

## Original PR description

Megatron-Bridge `main` already resolves Pillow 13.0.0 in `uv.lock`, but the NeMo Framework image still explicitly installs Pillow 12.3.0 through `fw_pyproject.toml` and permits it in the Dockerfile's system-pip layer. That can leave the image with a vulnerable copy despite the Bridge lockfile.

Require Pillow >=13.0.0 in both Framework image install paths through a normal uv constraint and the system-pip install. This version fixes the seven Pillow findings reported by the 26.10 source scan, including CVE-2026-112393, CVE-2026-112896, CVE-2026-112900, CVE-2026-112396, CVE-2026-112404, CVE-2026-112403, and CVE-2026-112398.

Validation: the existing Bridge lockfile resolves Pillow 13.0.0; `uv run --no-sync pre-commit run --all-files` and `git diff --check` passed. A rebuilt image scan on amd64 and arm64 remains necessary to verify installed copies.
