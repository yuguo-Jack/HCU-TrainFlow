# refactor(recipe)!: rename vr200 GPU type and perf recipes to vrnvl72

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6419) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Renames the Vera Rubin NVL72 GPU type from `vr200` to `vrnvl72` in the performance recipes and launchers. `vr200` stays a deprecated CLI alias so existing callers keep working while they move over.

# Changelog

- Rename `src/megatron/bridge/perf_recipes/<family>/vr200/` to `.../vrnvl72/` for the 7 families (deepseek, gpt_oss, kimi, llama, nemotronh, qwen, qwen_vl) and the 53 `*_vr200_*` recipe functions to `*_vrnvl72_*`. Family `__init__` exports, `dump_perf_configs.py`, docstrings, READMEs and tests follow.
- GPU handling uses `vrnvl72`: `NUM_GPUS_PER_NODE_MAP`, the 4752 MHz `--peak_mem_clk` default, the NUMA divisor, override and topology sets, and the training launcher's hardware check.
- `--gpu vr200` is mapped to `vrnvl72` by an argparse `type=` callable (`LEGACY_GPU_ALIASES` in `scripts/performance/argument_parser.py`). Only `vrnvl72` is listed in the choices and help. The deprecation warning is logged on the launcher and global rank 0 only, because every rank re-parses the forwarded argv.
- Training launcher: a benchmark recipe name containing `_vr200_` resolves to the renamed `_vrnvl72_` recipe, with a warning, when that recipe exists (`LEGACY_HARDWARE_ALIASES` in `scripts/training/recipe_metadata.py`).
- Tests:
  - New `tests/unit_tests/scripts/performance/test_argument_parser.py`.
  - Alias cases in training `test_recipe_metadata.py`, `test_recipe_runner.py` and `test_setup_experiment.py`.
  - The performance dry-run test now also runs `--gpu vr200`. It asserts the canonical experiment name and the `4752,4752` memory-clock lock.

**Breaking change (Python API only).** Code that imports the old names directly must update:
- modules `megatron.bridge.perf_recipes.<family>.vr200.*` → `megatron.bridge.perf_recipes.<family>.vrnvl72.*`;
- the 53 functions `*_vr200_*_config` → `*_vrnvl72_*_config`;
- direct calls that pass `gpu="vr200"` to script helpers without argparse, and `NUM_GPUS_PER_NODE_MAP["vr200"]`.

Nothing in this repo imports the old names. The CLI keeps accepting `--gpu vr200` and `_vr200_` recipe names during the deprecation window. Removing the alias later means deleting the two alias tables (each comment points to the other), the help and README notes, and the alias test cases.
