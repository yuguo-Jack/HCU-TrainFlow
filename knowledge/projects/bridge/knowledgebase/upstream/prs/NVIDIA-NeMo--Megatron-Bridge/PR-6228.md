## Original PR description

# What does this PR do ?

Adds GTP + partial CG support to NT3 Ultra MXFP8 GB200/GB300 recipes
Also enables cuDNN Layernorm for both GB200 and GB300 recipes.

The GB200 config is also updated with NCCLEP support

# Changelog

- Partial CUDA graph for NT3 Ultra MXFP8 GB200/GB300 recipes
- Added GTP sharding for the moe_latent_proj module in Nemotron 3 Ultra GB200 configuration.
- Implemented local CUDA graph handling in training and validation processes.
- Updated tests to ensure proper validation of local per-layer CUDA graph modules.
- Improved error handling for unsupported local whole-layer captures.
