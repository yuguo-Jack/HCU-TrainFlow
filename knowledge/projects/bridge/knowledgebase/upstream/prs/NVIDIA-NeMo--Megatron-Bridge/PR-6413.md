# perf(recipe): add an 8-GPU GB300 MXFP8 pretrain recipe for Qwen3.5-VL 35B-A3B

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6413) · state: closed · merged: True

## Original PR description

Add qwen35_vl_35b_a3b_pretrain_8gpu_gb300_fp8mx_library_config, an MXFP8 Qwen3.5-VL 35B-A3B pretraining recipe for 8 GB300 GPUs. It starts from qwen35_vl_35b_a3b_pretrain_16gpu_gb300_bf16_config, keeps its parallel layout, CUDA graphs, recompute, batch shape and real routing, and adds:

- MXFP8 with FP8 parameter all-gather (bf16_with_mxfp8_mixed);
- Transformer Engine's CuTe DSL fused grouped MLP: the op fuser, the 32-wide GLU interleave and the NVTE_CUTEDSL_FUSED_GROUPED_MLP gate, which only work together;
- 32 flex-dispatcher SMs, with HybridEP's fused permute off: it requires identical dispatch, combine and preprocessing chunk sizes, and this recipe uses 64/128/64;
- the HybridEP preprocessing SMs, dispatch/expert-wgrad overlap, dispatch and preprocessing chunk sizes and cuDNN normalization of the configuration it was tuned on, which the 16-GPU recipe does not carry over;
- cuDNN GDN (gdn_kernel_backend="transformer_engine"), set only when Megatron-Core declares the field (NVIDIA/Megatron-LM#7583), with the same guard as _enable_gdn_conv_fusion.
