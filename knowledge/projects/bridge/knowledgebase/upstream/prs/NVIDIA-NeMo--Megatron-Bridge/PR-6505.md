# test: isolate config loader retry clock mocks

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6505) · state: open · merged: False

## Original PR description

The config loader retry tests patched attributes of Python's shared `time` module. Calls from unrelated consumers could enter the retry mock: the unit shard observed 509 sleep calls instead of two.

Isolate the loader's `time` reference with a wrapping mock before applying the existing sleep and jitter patches. Add a parametrized regression that injects unrelated sleeps and retains the exact retry-count and backoff assertions. Runtime code is unchanged.

Validation:
- Deterministic fail-before: the injected case fails with five sleep calls instead of two; 24 other cases pass.
- Pass-after, including after the main refresh: all 25 focused tests pass.
- Local source-loading harness bypassed eager package initializers because the available container's MCore is older; the actual loader and compatibility module were loaded from this checkout. This does not establish full CI success.
- All-file pre-commit, `git diff --check`, and independent review passed.

Cause: **3. Bridge bug** — test mocks modified shared standard-library state. No upstream Megatron-LM PR is causal. The exact background caller behind CI's 509 calls is not established; the isolation defect is reproduced independently.

Human review and successful current-head CI are required before merge.
