# fix(peft): support TE 2.21 FP8 grouped-expert LoRA

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6775) · state: closed · merged: True

## Original PR description

The MCore release bump in #6602 updates Transformer Engine to 2.21. Its private grouped-linear autograd function now takes `GroupedLinearFwdArgs`; Bridge's FP8 grouped-expert LoRA path still searches for the previous `non_tensor_args` tuple and raises `Unable to determine Transformer Engine grouped-linear argument layout`.

This draft is stacked on **#6602**, targeting `cherry-pick-6469-r0.7.0`. It adds the TE 2.21 call while retaining support for older TE versions. Adapter weights remain explicit differentiable tensor arguments; active-expert ordering and quantizers, CPU split sizes, training/inference dispatch, and backward precision overrides are preserved. No dependency pins change.

Upstream cause: [MLM #8792](https://github.com/NVIDIA/Megatron-LM/pull/8792) brings TE 2.21, including [TE #3606](https://github.com/NVIDIA/TransformerEngine/pull/3606)'s private grouped-linear refactor. This is a dependency-interface incompatibility.

Validation:
- 34 focused tests passed locally, including 12 new TE 2.21 interface/gradient cases, existing TE 2.14–2.19 and ROCm cases, and real TE 2.19 GPU FP8 forward/backward/inference.
- All 35 constructor fields match the exact TE source pinned by #6602.
- All-file pre-commit and diff checks passed; independent review found no issues.
- Strict mypy is not clean in these existing files: 265 diagnostics on the parent, 269 here; the four additional diagnostics concern the new test's untyped pytest decorators and existing mock-config fixture. No new production-code diagnostic.
- **Real TE 2.21 GPU execution still needs CI**; the local environment has TE 2.19. The existing GPU test that failed in #6602 remains enabled with unchanged numerical assertions.

Requested as a release-stack proposal; main is not changed. Coordinate the eventual target before merging #6602 so this draft is not left targeting a deleted branch.
