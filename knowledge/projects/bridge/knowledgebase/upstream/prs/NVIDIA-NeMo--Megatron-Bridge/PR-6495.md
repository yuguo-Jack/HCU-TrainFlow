# refactor(training): release DataLoader workers before process-group teardown

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6495) · state: open · merged: False

## Original PR description

# What does this PR do ?

 - After `_finish_train` returns, setup_output and iterator aliases still retain DataLoader iterators and their workers.
 - Release these references before destroying the process group so workers exit during normal training shutdown.
 - Orderly worker exits give process-lifecycle and profiling tools a more complete record / metrics.

# Changelog

- Drop references before destroying the process group so PyTorch can stop the workers during normal shutdown.
