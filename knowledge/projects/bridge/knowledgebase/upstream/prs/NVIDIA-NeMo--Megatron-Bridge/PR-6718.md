## Original PR description

# What does this PR do ?

Enable NCCL EP and grouped tensors for the six 64-GPU Nemotron 3 Super B200/B300 BF16, MXFP8, and NVFP4 performance recipes, aligning their execution settings with the fastest recorded reference runs.

# Changelog

- Use the NCCL EP flex dispatcher and `moe_use_grouped_tensor=True`; remove HybridEP-specific environment settings.
- B200: TP2 / PP1 / CP1 / EP8 / ETP1 with sequence parallelism and pull/push enabled. BF16/MXFP8 use selective `moe_act`, `layernorm`, and `core_attn` recompute; NVFP4 uses `moe_act` and `layernorm`.
- B200: enable scoped TE graphs for Mamba, attention, MoE routing, and MoE preprocessing for all precisions.
- B300: retain TP1 / PP1 / CP1 / EP8 / ETP1 and scoped TE graphs. BF16/NVFP4 retain `moe_act` and `layernorm` recompute; MXFP8 retains disabled recompute. Add `NVTE_TENSOR_HANDLE_POOL_SIZE_MB=128` and `TORCHINDUCTOR_COMPILE_THREADS=1`.
- Keep sequence length 8192, GBS512, and MBS1. Preserve model construction and MTP settings.
- Add/update focused regression tests. Lightning and Nano recipe functions are unchanged.
