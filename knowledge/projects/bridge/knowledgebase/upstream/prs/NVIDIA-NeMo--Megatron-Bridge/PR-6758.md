## Original PR description

# What does this PR do ?

Cherry-pick of #6496 into `r0.7.0`.

#6496 passes a padding mask to the Qwen3-VL MoE layers, so padding tokens stay out of routing and router statistics. It also runs the vision merger on the graph-padded rows (with the padded rows zeroed), so the merger sees a fixed row count per micro batch. See #6496 for details.

# Conflict resolution

None. The commit applies cleanly to `r0.7.0`.
