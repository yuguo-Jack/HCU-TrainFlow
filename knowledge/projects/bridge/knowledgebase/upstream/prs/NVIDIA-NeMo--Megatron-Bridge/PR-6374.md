## Original PR description

## Background

Nightly Megatron-Core bump for the `main` lane. MCore `main` is pinned at `8949def81eb744b9219e2d794c80265928c40a5b`, 6 commits after the previous pin `441a9874`. The dev lane is paused, so `.dev.commit` is unchanged.

## What changed

- `.main.commit` and the `3rdparty/Megatron-LM` gitlink now point to `8949def8`.
- `uv.lock` was regenerated with `uv lock --upgrade` (uv 0.7.2, matching `UV_VERSION`). The only package changes are absl-py 2.5.0→2.5.1 and tokenizers 0.23.2→0.23.3. MCore's `pyproject.toml` did not change, so Bridge's dependency metadata needed no edits.

## Details

The MCore delta touches:
- `_post_param_sync` in `param_and_grad_buffer`
- the fused softmax path, which now requires `window_size is None`
- an int64 offset in `batch_invariant`
- removal of the `NVTE_CUTEDSL` gate in experts (op-fuser path)
- `enable_custom_allgather=False` for HybridEP
- `rl_utils` param sync

Tests were chosen by tracing the Bridge code that uses these paths. The diffusion unit tests and the other functional launchers were excluded because nothing in them reaches the changed code.

`L0_Launch_recipes_deepseek` was skipped with maintainer approval. It runs 0 cases both locally and on `main` CI, because the DeepSeek-V4 toy model is not in the CI test data.

## Tested
