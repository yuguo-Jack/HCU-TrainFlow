```yaml
            'if any(.[]; .version == $ver) then . else .[0:1] + [{"version": $ver, "url": "https://docs.nvidia.com/nemo/megatron-bridge/\($ver)/"}] + .[1:] end' \
            docs/versions1.json > tmp.json && mv tmp.json docs/versions1.json
```

The [final commit already stages the inventory](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/3bf873e82302c3eabd4667167286488c37d0dc91/.github/workflows/release-freeze.yml#L140-L148), so insertion and labeling will be pushed together. This removes obsolete markers from named entries without creating a name or passing null to `sub` for nameless entries.
