# fix(model): support Muse Spark Open on Transformers 5.20

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6492) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Makes Muse Spark Open work with the released Transformers 5.20, which ships `transformers.models.muse_spark`.

# Changelog

- **Text-only HF export**: Transformers 5.20 has no text-only causal LM for Muse Spark. The exported `muse_spark_open_transformers_patch.py` now defines `MuseSparkForCausalLM` on `MuseSparkTextModel` with the VL output head (output multiplier and tanh soft-cap). Parameter names, the untied head, and the HF experts-backend detection are unchanged.
- **Bridge**: the text bridge is registered for model type `muse_spark_text`; `num_shared_experts`, which 5.20 removed from the config, is read as optional.
- **Docs and messages**: name Transformers 5.20 or later. The guarded `muse_spark` config registration in `__init__.py` stays, so environments with older Transformers keep working.
- **Tests**: toy configs drop `num_shared_experts` and set the audio `out_hidden_size` that 5.20 validates. New functional test: the exported text class reproduces the full model's text logits, also when reloaded through its `auto_map`.

The Transformers bump in `pyproject.toml`/`uv.lock` is left for a separate PR. Under CI's locked 5.17.0 the Muse Spark Open functional tests skip as before.
