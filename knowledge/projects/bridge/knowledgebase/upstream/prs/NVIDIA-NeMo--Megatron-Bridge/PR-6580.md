# build(security): update Pillow to 13.0.0 on r0.7.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6580) · state: closed · merged: True

## Original PR description

The 26.10 Megatron-Bridge source scan flags Pillow 12.3.0 on `r0.7.0` for seven high-severity findings: CVE-2026-112393, CVE-2026-112896, CVE-2026-112900, CVE-2026-112396, CVE-2026-112404, CVE-2026-112403, and CVE-2026-112398. Pillow 13.0.0 contains the upstream fixes.

Require Pillow >=13.0.0 through normal uv constraints in Bridge and the Framework image, and in the Framework system-pip install. Regenerate `uv.lock` so the source package scan resolves the fixed 13.0.0 release while allowing future patched versions.

Validation: `uv lock` completed in the project container; the lockfile resolves Pillow 13.0.0. `uv run --no-sync pre-commit run --all-files` and `git diff --check` passed. A rebuilt image scan on amd64 and arm64 remains necessary to verify installed copies.
