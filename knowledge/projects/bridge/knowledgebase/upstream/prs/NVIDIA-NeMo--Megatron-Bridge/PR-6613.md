## Original PR description

## Summary

- Record the NeMo 26.10 container as the BAGEL card's `base_container`; the previously recorded container cannot run the BAGEL leaves at the pinned commits.
- Make `fd8ab826` the card-wide `bridge_commit` (the previous default predates BAGEL support) and drop the now-redundant leaf overrides. This also moves `pretrain_fsdp` onto a usable commit.
- Refresh `hf_to_megatron_gpu`, `pretrain.H100` and `pretrain_fsdp.H100` from new runs of the card commands on that container (no extra package installs), update the summary to the current performance-disclaimer wording, and regenerate the catalog docs.

## Known gaps

- The GPU import needs the official BAGEL checkout importable in the worker; `convert.sh` has no option for this, so it cannot be expressed in the card command.

## Verification

- `validate_card.py`: valid.
- `hf_to_megatron_gpu`: fresh one-GPU reload of the imported checkpoint has no missing/unexpected keys; all 1,223 EMA tensors exactly match after undoing the QKV/GLU fusion, including the 56 input-norm sentinels.
- `generate_model_verification_catalog.py --check` and `tests/unit_tests/doc_consistency/test_model_verification_catalog.py`: pass.
