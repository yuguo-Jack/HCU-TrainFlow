## Original PR description

# What does this PR do ?
Log the DSA sparse indexer loss to W&B (and others).
Bridge training_log never flushed DSAIndexerLossLoggingHelper, so sparse indexer metrics never reached TB/W&B even when dsa_indexer_loss_coeff > 0.
