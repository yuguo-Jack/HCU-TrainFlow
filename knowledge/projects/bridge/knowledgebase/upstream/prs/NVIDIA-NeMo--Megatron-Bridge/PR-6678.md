## Original PR description

Manual cherry-pick of #6613 into `r0.7.0`.

The cherry-pick bot could not apply #6613. Its only test change removes the BAGEL FSDP throughput row from `test_validate_card.py`, and the rows around it differ on `r0.7.0`. This PR applies #6613 with that one row removed from `r0.7.0`'s version of the file; everything else is identical to #6613.

#6613 re-verifies the BAGEL card on NeMo 26.10 (NVBug 6964569). It records the 26.10 base container and pretrain metrics, documents installing `opencv-python-headless` (the 26.10 container no longer ships it), and marks the FSDP pretrain leaf unverified.

It applies cleanly to `r0.7.0` as it is today and on top of #6665 and #6676.

Checks on this branch:
- `generate_model_verification_catalog.py --check`: up to date.
- The catalog, published-command and card-validator tests: 74 passed.
- `pre-commit run --all-files`: passed.
