# What does this PR do ?

Refresh the Nemotron-3.5 Super VL and Nemotron-3.5 Super Text-only verification cards with the completed final-checkpoint replay results.

# Changelog

- Record the tested checkpoint revision while retaining `nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-BF16` as the release-facing HF ID and `nvcr.io/nvidia/nemo:26.08.01` as the verification container. Resolution of the release-facing ID to this revision was not independently verified.
- Refresh GPU import/export, base forward correlation and generation, H100/GB200 SFT and PEFT, and post-training export/reload results from the October 2–5 replay. Preserve all 22 recorded commands and the actual per-item Bridge source commits; these are historical execution results, not reruns on this PR's head.
- Record all five training metrics from the complete optimizer-step logs and resolved workload sizes. Preserve the original bounded workloads and convergence limitations; no tuning or recipe changes.
- Keep GB200 VL post-SFT natural-routing correlation failure explicit: 4/73 supervised positions below 0.99, minimum cosine 0.9761264324. A separate expert-ID-only replay passes 73/73, minimum 0.9987812042, while retaining HF router weights/normalization. This diagnostic does not establish natural-routing probability equality. Export/reload/generation status is separate.
- Mark pretraining/resume unverified for the new checkpoint instead of carrying forward previous-checkpoint evidence. H100 pretraining was incomplete; its dependent resume was deferred. CPU conversion, long context, and text-only pretrain/resume remain deferred. FSDP is outside this PR.
- Regenerate the catalog and both Markdown/Fern model-guide pairs without changing navigation.
