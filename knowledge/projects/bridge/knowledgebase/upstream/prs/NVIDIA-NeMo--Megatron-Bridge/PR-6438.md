# build: AUT-2524 bump MCore main to a98aed55

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6438) · state: closed · merged: True

## Original PR description

## Background

Nightly Megatron-Core bump for the `main` lane, moving Bridge's MCore pin to `a98aed55`. Bridge `main` has since moved its own pin to `8c815a4c`, an ancestor of `a98aed55`, and upstream `main` was merged in at `1edea5bc`.

## What changed

- `.main.commit` and the `3rdparty/Megatron-LM` gitlink now point to `a98aed553e25b4e86c59f50be54ac0ea4227b442`. `.dev.commit` is unchanged.
- `uv.lock` matches `main`. `uv lock --check` passes with uv 0.7.2, the `docker/Dockerfile.ci` pin. MCore's dependency metadata is unchanged at `a98aed55`.
- `L0_Launch_models_bert.sh` takes its coverage `--data-file`/`--source` paths from the repo root instead of a hardcoded `/opt/Megatron-Bridge`.

## Details

Tests were selected by tracing the MCore changes since `e30d863a`: distributed-optimizer checkpoint layout, deterministic GDN l2norm, empty hybrid PP stages, and inference stop/sampling. That gave 77 rows: 4 unit rows (Core in 3 shards, plus Diffusion) and 73 H100 functional launchers. After the `main` merge, 7 rows were re-run to cover its CUDA-graph validation/teardown and nemotronh perf-recipe changes.

## Tested

Run locally on H100 with the CI FlashAttention env (`NVTE_FLASH_ATTN_V2=1`, V3/V4 off).
- On merged head `52c1a6de` with image `sha256:68b61252df0c1a0eb6277494c99c2031fd0d042f08d82ae9864d8f7cef8d7e20`, 7 rows passed with 0 failures: Core unit shards 0-2 (4045, 4017 and 4043 tests), `L0_Launch_megatron_fsdp`, `L0_Launch_training_pretrain`, `L0_Launch_recipes_perf_config` and `L2_Launch_recipes_llama_cuda_graphs`.
- The other 68 selected rows passed on the pre-merge head with image `sha256:65858877`. Their results still apply: the MCore pin, Dockerfile and pyproject are unchanged, and no runtime code imports the packages bumped in the lock.
- 2 rows were not run, by requester decision, because their test data is missing: `L0_Launch_recipes_deepseek.sh` and `L1_Launch_recipes_glm_vl.sh`. Upstream CI skips them too.
- GitHub CI on this head: pending.
