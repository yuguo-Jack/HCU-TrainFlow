# chore(deps): AUT-2546 bump Megatron-Core main to 3888b348

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6509) · state: open · merged: False

## Original PR description

## Background

Nightly Megatron-Core bump for `main`. It moves the MCore main pin from `3914483f` to `3888b348` (11 commits). `.dev.commit` is unchanged.

## What changed

- `.main.commit` and the `3rdparty/Megatron-LM` submodule now point to `3888b34882eb85aecf6ec9ecc3f4020b7608b497`.
- `uv.lock` was regenerated with `uv lock --upgrade`:
  - nvidia-cutlass-dsl: 4.8.0 → 4.8.1
  - numba: 0.68.0 → 0.68.1rc2
  - protobuf: 7.36.2 → 7.37.0rc1
  - cuda-tile: 1.7.0rc2 → 1.7.0rc5
  - tooling: cachetools, platformdirs, python-discovery, ruff, tomlkit, virtualenv
- Merged `main` (`b35f7557`). The DeepSeek-V4 SFT test now matches `main`'s version from #6515, and this branch's earlier repair of it is dropped.
- `test_exaone4_provider.py`: #6401 moved Exaone4Bridge to builder-backed configs. The provider no longer has the plain `rope_scaling_{low_freq_factor,high_freq_factor,original_max_position_embeddings}` attributes, so this test failed on `main`.
  - The test drops those attributes from the expected provider.
  - It now checks that `megatron_to_hf_config()` exports the llama3 `rope_scaling` dict.
  - The failure is unrelated to MCore.

## Details

- Local runs set `NVTE_FLASH_ATTN_V2=1` and `V3`/`V4=0` to match the CI test template.
- `L1_Launch_recipes_glm_vl` is excluded and not counted as passed. All its cases skip because the `zai-org/GLM-4.5V` config is missing from the offline HF cache; CI skips it the same way.
- `L2_Launch_models_exaone` runs in CI only on schedule, on dispatch, or with the full-test-suite label.

## Tested

Local H100 runs used the validation image built from this bump merged with `main` (`bae386eb`):
- unit: 4/4 rows passed
- functional: 74/75 rows passed and 1 is excluded (see above); 0 failures
- After merging `b35f7557`, I reran the affected rows on the merged tree. The EXAONE row ran on the final tree.
  - Core unit shards 0–2: 12,692 passed
  - DeepSeek recipes: 5 passed; the MXFP8 case is skipped because it needs Blackwell
  - Bailing: 4 passed
  - EXAONE: 5 passed

Main CI is pending.
