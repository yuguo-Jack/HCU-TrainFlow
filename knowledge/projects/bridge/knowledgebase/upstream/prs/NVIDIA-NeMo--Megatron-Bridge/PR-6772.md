# docs(model): re-verify Qwen3.6 35B-A3B H100 pretraining at e7a6dbfec

## Original PR description

# What does this PR do ?

Re-verifies the H100 pretrain item of the Qwen3.6 35B-A3B verification card at Megatron-Bridge `e7a6dbfec`: the
card's 50-step DataComp command on 2x8 H100 in the card's `nvcr.io/nvidia/nemo:26.06` container.

Why: the leaf was recorded at `5db2290de` (2026-08-05). Since then #5970 (fused GDN conv1d and QK L2-norm kernels,
now on in this recipe) and #6695 (the model built from a builder-backed config) changed the code this command runs,
so the leaf no longer described what the command does on main. On the card's container the refreshed throughput
stays within 2 % of the earlier record; the refresh also corrects two leaf details listed below.

# Changelog

- `examples/model_verification_cards/qwen3.6-35b-a3b/card.yaml`, `pretrain.H100` leaf:
  - metrics from the run: loss 3.600145 → 3.062526, and over the last 10 steps 22,738.330 ms per step,
    132.830 model TFLOP/s/GPU and 5,764.364 tokens/s/GPU. At the recipe's 3e-4 peak learning rate the loss after
    warmup varies from run to run, so the final loss moves more than the throughput;
  - `last_verified: 2026-11-03` and a leaf `bridge_commit` (`e7a6dbfec`): the commit the run used, mounted with its
    pinned Megatron-Core over the card's container;
  - `checkpoint.save=null` in the command, because without it the run saves a full checkpoint (about 0.5 TB) at its
    last step; the expected result now says the run saved no checkpoint;
  - `enabled_features` lists the Transformer Engine CUDA graphs over `attn`, `moe_router` and `moe_preprocess`,
    which the recipe enables and the run used.
- The summary's H100 throughput sentence quotes the new value (132.830, approximately 133).
- Regenerated catalog docs: `docs/_static/model-verification/catalog-v1.json`, the Qwen3.6 35B-A3B model guide and
  its Fern mirror.

The other leaves are unchanged.

# Validation

- The run completed all 50 steps with zero skipped or NaN iterations and saved its post-setup `ConfigContainer`:
  TP1/PP2/CP1/EP8/ETP1, MBS 1, GBS 512, HybridEP.
- `validate_card.py`: valid. Catalog generator `--check`: current. `test_model_verification_catalog.py` and
  `test_validate_card.py`: 66 passed. `pre-commit run --all-files`: passed.
