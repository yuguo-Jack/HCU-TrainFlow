# Set SYS_ADMIN for nsys profiling on NVCRE

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6691) · state: open · merged: False

## Original PR description

(cherry picked from commit 7f009e70a62a09b8b9990a2258b2a2d2c8a8556a)

This feature requests SYS_ADMIN for nsys profiling on NVCRE. Where the driver sets RmProfilingAdminOnly=1, nsys records no GPU kernels without CAP_SYS_ADMIN. NsysPlugin now adds it to NvcreExecutor.capabilities and reports Error if the installed nemo_run cannot request capabilities.
