# build: bump cuDNN Frontend to 1.31.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6430) · state: open · merged: False

## Original PR description

Bump `nvidia-cudnn-frontend` from 1.29.0 to [1.31.0](https://github.com/NVIDIA/cudnn-frontend/releases/tag/v1.31.0) in the Bridge and final framework container overrides, and regenerate `uv.lock` with the updated Python 3.12 wheel hashes. Only cuDNN Frontend changes version; existing Transformer Engine, MCore, TileLang, and TVM FFI pins are preserved.

Companion release PR: #6431 (`r0.7.0`).

Validation:
- `uv lock --check` passed in the CI container.
- `uv run pre-commit run --all-files` passed in the CI container with the existing environment (`UV_NO_SYNC=1`).
- `uv run --no-sync python -m pytest tests/unit_tests/utils/test_gdn_utils.py -q -rA`: 67 passed with Frontend 1.31.0 installed, including the installed Frontend FROST version-floor and parser checks.
- `git diff --check` passed.

GPU kernels were not exercised locally because the host has an NVIDIA driver/library mismatch. L0/L1 CI is requested with `needs-more-tests`. No tests are quarantined.
