# fix(data): preserve native HF conversation fields for validation

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6378) · state: closed · merged: True

## Original PR description

## What does this PR do?

Prevent the Direct HF native adapter from silently discarding populated conversation fields. For example, a selected text `messages` prompt alongside structured `conversations` now reaches validation and is rejected. Two explicitly selected text columns named after chat fields remain valid.

Fixes NVBug 6900680.

## Changelog

- Preserve distinct source fields through native column renaming and reject populated destination collisions.
- Reject ambiguous multi-column chat rows during shared SFT preprocessing; preserve overlapping-alias precedence and selected text-column priority.
- Add real local-JSONL builder regressions and adapter coverage for conventional names, custom aliases, collisions, and null alternatives.

## Validation
