# feat(model): add Bridge-local Qwen4-Exp support

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6315) · state: open · merged: False

## Original PR description

# What does this PR do?

Add Qwen4-Exp text-decoder support with QSA, gated residuals, and per-layer embeddings implemented in Bridge. The model uses the existing Core GPT, GDN, MoE, and hyper-connection interfaces; the current Core submodule is pinned at `fbbe6eb5490de4c81c51bd8f715f333c91837fe4`.

This is an alternative to the native-Core implementation in #6123, which depends on NVIDIA/Megatron-LM#7393. The conversion mappings and base QSA/PLE/GR scaffolding are adapted from those PRs, as documented in the model README. The changes specific to this branch are the Bridge-local provider and model hooks, document-local QSA scoring, bounded grouped RMSNorm, and preservation of low-precision gate rounding under compile.

# Changelog

- Add a provider and layer specs for the Qwen4-Exp config, prepare raw token IDs for PLE, and expand residual streams before the decoder. A learned output mixer contracts them at the end.
- Score QSA blocks per document with bounded query chunks, avoiding the replicated query-by-block key tensor.
- Preserve the HF BF16/FP16 gate rounding boundaries in GR. Chunk grouped RMSNorm forward and first-order backward reductions, with a 64 MiB workspace budget excluding required outputs, gradients, and saved statistics.
- Add rank-local PLE shard loading and lazy shard export, plus numerical, mapping, provider, and small-model conversion tests.
