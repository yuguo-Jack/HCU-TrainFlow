# fix(nemotron-omni): gate sound merge on audio inputs

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6458) · state: closed · merged: True

## Original PR description

## Summary
- only merge projected sound embeddings when the batch carries authenticated audio inputs
- preserve generated occurrences of the sound-token vocabulary ID as ordinary text in image-only/text-only batches
- add a regression test for an image-only input containing that ordinary token ID

## Validation
- targeted Nemotron Omni regression test passed
- validated in a 4-node NeMo RL OSWorld smoke through rollout, old-policy logprobs, optimizer/refit, and `step_1` checkpoint
