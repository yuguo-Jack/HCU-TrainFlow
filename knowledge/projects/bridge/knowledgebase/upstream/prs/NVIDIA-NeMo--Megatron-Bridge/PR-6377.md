## Original PR description

# What does this PR do ?

Fix skill degradation between harnesses due to unofficial field usage.

- Skills used to have an unspecified (as per the agent skills spec) `when_to_use` field. It is now removed and its contents are now appended to the `description` field under a new "Use when" prefix, which is what's supposed to contain this information.
- Normalize another undocumented field between Claude Code and Codex: `user_invocable` → `user-invocable`

The `user-invocable` form seems to be more generally supported across the harness ecosystem (if `user_invocable` has any support at all).

- [Codex mentions, but doesn't use it, in a prompt file](https://github.com/openai/codex/blob/79773e8826aeb6bca09305728297908b0d5bc6c3/codex-rs/memories/write/templates/memories/consolidation.md?plain=1#L723)
