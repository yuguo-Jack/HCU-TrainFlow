# fix(inference): resolve coordinator addresses and release unused CUDA cache

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6535) · state: open · merged: False

## Original PR description

Dynamic inference can fail while binding the coordinator to a hostname, then run out of memory when NCCL allocates communicators after a large checkpoint load. Resolve the default coordinator hostname to an IPv4 address and release unused PyTorch cached memory once before constructing the dynamic engine. Explicit coordinator overrides, live model tensors, and the requested KV-cache budget remain unchanged.

Validation:

- Twelve focused entrypoint tests pass; the original source fails the new regression cases. Full pre-commit hooks and strict type checks on both changed files pass.
- The same full K-EXAONE 2.0 750B-A37B reproduction on 48 H100 GPUs (TP1/PP3/EP16/ETP1, original 20 GiB KV-cache) changes from coordinator binding and NCCL allocation failures to successful generation on all ranks. It produces the expected 16-token Korean answer naming Seoul; all recorded generation steps have finite logits and valid greedy tokens.
- A separate fresh load checks all 51,584 recorded tensors and completes on all 48 ranks. All 16 full-vocabulary vectors are finite, match the reference next token, and have recomputed cosine similarity 0.9999950. Independent review checked the raw before/after results and exact final commit.

The fix was tested as the exact candidate entrypoint in the reproduction runtime. Final test-only typing changes preserve those production bytes.

NVBug 6651530. The public-command verification and card update in #6294 remain separate work in progress; this PR does not claim that card is verified. Remote CI is pending.
