# docs(recipe): document TORCHINDUCTOR_COMPILE_THREADS=1 for Nemotron 3 Ultra H100 SFT

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6556) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Document that Nemotron 3 Ultra H100 full SFT needs `TORCHINDUCTOR_COMPILE_THREADS=1` exported at launch, and export it in the example `slurm_sft.sh`.

# Changelog

- `examples/models/nemotron/nemotron_3_ultra/slurm_sft.sh`: export `TORCHINDUCTOR_COMPILE_THREADS=${TORCHINDUCTOR_COMPILE_THREADS:-1}`.
- Example README, H100 Full SFT starting point: explain the export and why it is needed.
- `nemotron_3_ultra_sft_384gpu_h100_bf16_openmathinstruct2_packed_config`: comment next to the recipe environment (no functional change).
- Model card: the H100 SFT entry (still unverified) states the launch requirement; catalog docs regenerated.

# Why

NVBug 6674155. On Python 3.12 before 3.12.8 (the containers ship 3.12.3), Inductor's default pool of forked compile workers shuts down after 60 s idle and re-forks on the next compile; a worker forked while the old pool is shutting down can inherit a held lock and never return its job (pytorch/pytorch#200848). This recipe's twelve-stage first step compiles in bursts minutes apart on each rank, so its pools re-fork often, and a rank waiting for a lost compile job stalls its expert-parallel group and then the whole pipeline.

With `TORCHINDUCTOR_COMPILE_THREADS=1` exported at launch, Inductor compiles in the training process and creates no worker pool. Inductor reads the variable when `torch._inductor.config` is imported, which happens during `run_recipe.py`'s own imports, before the recipe environment is applied, so the recipe cannot set it.

# Verification

- [x] 48 nodes (384 H100s), recipe defaults with `TORCHINDUCTOR_COMPILE_THREADS=1` exported at launch: two QA runs completed all 100 steps (lm loss 0.381 → 0.233, no skipped or NaN iterations). A 10-step run of ours matched the losses of the default-pool runs, started no compile-worker processes, and took 1,827 s for the first step, compared with 1,835-1,850 s with the default pool.
- [x] `validate_card.py`, `generate_model_verification_catalog.py --check`, and `tests/unit_tests/doc_consistency/test_model_verification_catalog.py`, `tests/unit_tests/skills/create_model_verification_card/test_validate_card.py`, `tests/unit_tests/doc_consistency/test_nemotron_layout.py` (80 passed).
- [x] `pre-commit run --all-files`.
