# docs(model): verify Qwen3.6 35B-A3B text pretraining on GB200

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6719) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Records the verified GB200 pretrain item of the Qwen3.6-35B-A3B verification card: 100 steps of the `qwen35_text_35b_a3b_pretrain_8gpu_gb200_bf16_config` library recipe on 2x4 GB200 through `scripts/training/train.sh`, warm-started from the language model and MTP layer of the card's pinned revision.

# Changelog

- `examples/model_verification_cards/qwen3.6-35b-a3b/card.yaml`: `pretrain.GB200` is now verified, with its `train.sh` command, metrics, expected result and a leaf `bridge_commit` for the commit the run used (`0652ea797`, with its pinned Megatron-Core, on a NeMo 26.10 release-candidate container). The data is a bounded RedPajama2 prefix re-tokenized with the Qwen tokenizer.
- The item is labeled early and unoptimized: 240 model TFLOP/s per GPU, below the roughly 400 TFLOP/s per GPU GB200 BF16 readiness target. It is support verification, because the recipe's GBS 512, FP32 gradient path and lack of checkpoint saves differ from the text-pretraining cohort.
- Regenerated catalog docs: `docs/_static/model-verification/catalog-v1.json`, the Qwen3.6-35B-A3B model guide and its Fern mirror, and both model READMEs.
- `tests/unit_tests/skills/create_model_verification_card/test_validate_card.py`: adds the leaf's throughput inputs to `TRAINING_THROUGHPUT_INPUTS`.

# Validation

- The run: 100 steps on 8 GB200 GPUs, LM loss 2.203229 to 2.137179 with every step finite and none skipped; over the last 10 steps, 24,539 ms per step and 240.07 model TFLOP/s per GPU; peak memory 124.9 / 132.5 GiB allocated / reserved on rank 0. A second 100-step run of the same configuration on the same container matched it bit for bit (LM loss, MTP loss and grad norm) at every step.
- `skills/create-model-verification-card/scripts/validate_card.py`: valid.
- `scripts/docs/generate_model_verification_catalog.py --check`: the generated docs are current.
- `tests/unit_tests/doc_consistency/test_model_verification_catalog.py` and `tests/unit_tests/skills/create_model_verification_card/test_validate_card.py`: 66 passed.
- pre-commit on the changed files: passed.
