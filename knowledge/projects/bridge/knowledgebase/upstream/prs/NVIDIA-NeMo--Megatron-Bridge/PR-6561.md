# fix(nemotron-omni): backport video embedder export recovery to r0.7.0

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6561) · state: closed · merged: True

## Original PR description

## What does this PR do?

Backports #6488 (778ff90eeb21c3d0d0fc1b62045019241df88aad) to `r0.7.0`.

Image-only SFT omits the unused video embedder from the Megatron checkpoint, but the exported HF configuration still requires it. HF reload would therefore initialize that weight randomly. Export now recovers the pretrained weight from the original HF reference checkpoint, preserves an existing trained Megatron weight, and fails explicitly if a required weight cannot be recovered—even with `--not-strict`.

## Changelog

- Preserve MIMO route ownership and pipeline-stage ownership so recovery cannot replace a trained video weight.
- Use each model's configuration to determine whether the video weight is required, including Super-VL.
- Backport the regression tests and export documentation.
- Resolve the Super-VL conflict by retaining the release branch's existing language-config handling and adding only the video requirement helper.
