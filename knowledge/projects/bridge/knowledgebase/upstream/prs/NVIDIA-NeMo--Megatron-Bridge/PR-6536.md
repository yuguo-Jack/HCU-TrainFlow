# feat(decision): add CLM, CLEF and D1 post-training

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6536) · state: open · merged: False

## Original PR description

# What does this PR do ?

Add CLM/CLEF typed decision-head adaptation using existing native backbone providers, plus experimental D1 native models and conversion, with supervised and finite-option reward objectives and standalone tutorials.

# Changelog

- Add CLM projection heads and CLEF joint schema heads with released checkpoint loading.
- Add experimental D1-3B/Omni native providers, configuration and parameter mappings, answer-row/marker-head adaptation, and strict complete-state publisher-comparison tools.
- Add frozen-backbone head training and CLEF LoRA continuation, checkpoint persistence, and multi-metric evaluation.
- Add exact expected utility and optional sampled GRPO objectives, feedback-aware loss weighting, and revision-aware embedding caches.
- Add focused CPU tests and two-GPU functional tests for sequence-parallel gradient semantics and question-weighted data-parallel updates.
- Add fictional fixtures and output-free notebooks for supervised, contrastive and experimental calibration-aware continuation workflows.

# Validation

Local validation:

- Dependency-light CPU checks: 41 passed, one CUDA case skipped in an isolated namespace harness that bypasses suite-wide CUDA/TE registration and fixtures. This includes CLM comparisons with the public reference source at [d5f9ef0](https://github.com/Contrastive-LM/CLM/tree/d5f9ef0fd9bde185df0ceaad4f4ecc6cfe8c34f6).
- Ten CPU tests verify strict-checker rejection of missing persistent buffers/state keys, changed tensors/dtypes and broken tied-weight aliases. They exercise the checker with fixtures, not native provider conversion numerics.
- Tutorial helpers: four tests passed. All seven default notebook paths and tiny head/loss loops passed separate CPU checks.
- `uv run pre-commit run --all-files`: passed.

These CPU checks do not establish provider integration or full framework test-suite compatibility. On the supported framework environment, run the regular unit-test paths under `tests/unit_tests/decision`, `tests/unit_tests/models/clm`, `tests/unit_tests/models/clef`, `tests/unit_tests/models/d1`, `tests/unit_tests/models/hf_pretrained/test_auto_model.py` and `tests/unit_tests/training/post_training/test_decision.py`. The new distributed acceptance command is:

```bash
uv run python -m torch.distributed.run --nproc_per_node=2 -m pytest \
  tests/functional_tests/test_groups/decision/test_decision_distributed_gradients.py -v
```

This is a draft pending supported GPU/Megatron acceptance, including the new distributed functional tests and strict D1 publisher comparisons. Released-size D1-3B probability parity remains unresolved; tiny fixtures do not establish it. No trained weights, recorded model-quality results or executed notebook outputs are included. The Megatron-Core submodule remains unchanged.
