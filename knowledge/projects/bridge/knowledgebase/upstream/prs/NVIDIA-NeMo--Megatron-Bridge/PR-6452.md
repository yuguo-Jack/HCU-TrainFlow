# fix(build): install pinned cuDNN Frontend Git ref in fw-final

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6452) · state: closed · merged: True

## Original PR description

## What does this PR do?

Port #6427 and #6447 from `r0.7.0` to `main` so the `fw-final` image installs cuDNN Frontend from pinned commit `8924d4b41fd678ba1b98cd7f98bb78b222637573` on `feat/1.29.0-megatron`. Without the follow-up fix, the framework's dependency override replaces the explicit Git requirement with the registry wheel.

## Changelog

- Add the Docker-only `CUDNN_FRONTEND_GIT_REF` build argument and document it.
- Skip cuDNN Frontend during the framework sync, install the Git requirement with `--no-config`, and fail the build if the installed distribution does not record the requested commit.
- Preserve registry-wheel behavior when the argument is empty and base-runtime preservation when enabled.
