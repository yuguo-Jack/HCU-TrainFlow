# fix(misc): run Pyxis conversion and inference tasks from the repo root

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6625) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Fixes `convert.sh`/`infer.sh --executor slurm` resolving relative `work/...` paths in NeMo-Run's `/nemo_run/code` (card export cannot find its import) by running Pyxis tasks from `/opt/Megatron-Bridge`.

# Changelog

- `scripts/common/container_runtime.py`: add `run_from_container_repo_root` (`cd /opt/Megatron-Bridge` + `exec`, as the Enroot path does).
- `setup_conversion.py`, `setup_inference.py`: apply it for Slurm + Pyxis.
- Tests: Slurm Pyxis tasks cd into the repo root; local conversion unchanged; 3 existing main() tests stub the helper.

# Additional Information

- **Root cause:** NeMo-Run sets Pyxis `--container-workdir /nemo_run/code`; Pyxis rejects a second one. Training already chdirs in `run_recipe.py`.
- **Blast radius:** 126 slurm convert.sh/infer.sh commands with relative paths in 29/30 cards. Found by the #6615 bot review.
- **Regression?** No, broken since #4873/#4931.
- **Verification:** EOS 26.10.rc7, nemotron-3-nano-4b card. RED main: export 6324111 FileNotFoundError, infer 6324195 fails. GREEN: import 6324216 writes the checkout, export 6324292 loads it, infer 6324362 passes. Unit: 192 pass; new tests fail on main. Export then hits an unrelated GenerationConfig error.
- **NVBug:** 6978311.

This resolves relative paths against whatever is at /opt/Megatron-Bridge, which is only the user's checkout when it's mounted there, and card commands never carry that mount. A Qwen3-0.6B import with this PR and no checkout mount exits 0 ("GPU import complete: work/…"), but the checkpoint lands in the container's writable layer and is gone after the job; on main it at least stayed under the job's code/ dir. Could the launchers fail or warn when a relative path is used without a mount at /opt/Megatron-Bridge, and could the READMEs say relative paths resolve against the mounted checkout?
