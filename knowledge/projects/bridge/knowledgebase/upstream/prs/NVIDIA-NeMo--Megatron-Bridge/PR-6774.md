# fix(perf): accept full_iteration CUDA graph implementation

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6774) · state: open · merged: False

## Original PR description

# What does this PR do?

Allow the performance CLI to accept `--cuda_graph_impl full_iteration`, matching the current Megatron-Core API. Selecting it also clears inherited per-layer graph modules, which MCore rejects for full-iteration capture.

# Changelog

- Add `full_iteration` to `VALID_CUDA_GRAPH_IMPLS`; the CLI help picks up the new option automatically.
- Use the existing compatibility helper to normalize explicit full-iteration selection, while rejecting conflicting explicit scopes and preserving support for older MCore.
- Add six regression cases for inherited settings, accepted scope forms, conflicting scopes, and the legacy fallback.
