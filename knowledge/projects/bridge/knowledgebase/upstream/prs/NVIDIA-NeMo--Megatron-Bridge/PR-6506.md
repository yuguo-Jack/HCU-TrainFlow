# ci(autobot): enable formal review approvals

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6506) · state: closed · merged: False

## Original PR description

Autobot requires a default-branch policy before it can publish native APPROVE or REQUEST_CHANGES reviews. Without that opt-in, the workflow downgrades those verdicts to COMMENT.

Add `.github/autobot/review-config.yml` with `approval.enabled: true`. Permit active members of the existing repository engineering/maintainer and CI automation teams:

- `NVIDIA-NeMo/lm_team`
- `NVIDIA-NeMo/lm_maintainers`
- `NVIDIA-NeMo/automation`

The policy takes effect after merge to `main`; the review service checks the requester's active team membership before publishing a formal verdict.

Tested:

- `python3 -c 'from pathlib import Path; import yaml; p = yaml.safe_load(Path(".github/autobot/review-config.yml").read_text()); a = p["approval"]; assert a["enabled"] is True; t = a["eligible_teams"]; assert isinstance(t, list) and t and all(isinstance(x, str) and x and "/" not in x for x in t) and len(t) == len(set(t)); print("approval config valid")'` — passed YAML and approval-policy shape checks.
- `git diff --check HEAD^ HEAD` — passed.
- `gh api orgs/NVIDIA-NeMo/teams/<slug>` for every configured team — verified each team exists in the repository's organization.
