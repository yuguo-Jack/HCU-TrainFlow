# docs(model): backport Super VL card fixes to r0.7.0 (6599, 6600, 6601, 6616)

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6675) · state: closed · merged: True

## Original PR description

Backport the related Super VL verification-card corrections from #6599 (including #6600), #6601, and #6616 to `r0.7.0`.

The text-only card now uses the imported checkpoint for H100 SFT, publishes the two-node/eight-GPU conversion geometry, and computes the forward reference in-process on CPU instead of requiring an unpublished logits file. Both Super VL cards bind their model metadata to the public Hugging Face revision and retain explicit limits on which results establish verification at that revision. The generated catalog/pages and card-validation tests are included.

Merged main sources:
- #6599 (includes #6600): `4c8a14e1495836417663743a5d61f7e6d441299c`.
- #6601: `7e825224f9a955aa11230e42aef115422cea05e7`.
- #6616: `f46415dfb6eea58cb94f6c9997686262db344cfa`.

Release dependencies #6665 and #6669 are already merged. This update merges the current release into the existing branch and preserves its history. The combined backport keeps the card commands, results, and revision descriptions together. Open #6674 is not included.

Validation: 184 focused catalog, published-command, recipe-revision, schema and card-validator tests passed; all shipped cards passed validation; generated catalog/pages are up to date; all-file pre-commit and whitespace checks passed. Independent review covers the complete release diff and final signed commit. These are documentation and structural checks; no new GPU runs or runtime acceptance are claimed. Existing workflow limitations remain recorded in the cards.
