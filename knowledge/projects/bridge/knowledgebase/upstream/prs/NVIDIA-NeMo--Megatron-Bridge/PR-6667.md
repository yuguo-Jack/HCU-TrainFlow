# build: remove PyNvVideoCodec from release container

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6667) · state: closed · merged: True

## Original PR description

## Summary

- Remove PyNvVideoCodec from the system Python environment during `fw-final` assembly, after the Framework dependency install.
- Run `uv cache clean` at the end of `fw-final`. The scan also finds bundled FFmpeg in uv's unpacked wheel cache, which package uninstall does not clear. Installed packages use copy mode, so they do not depend on cached files.
- Delete the now unused PyNvVideoCodec FFmpeg patch script and patch file.

The intermediate `fw-base` image still installs PyNvVideoCodec as a vLLM dependency; its import-check exemption remains in place for Megatron-Bridge CI. GPU video decoding through vLLM's PyNvVideoCodec backend will be unavailable in `fw-final`.

## Validation

- `uv run --no-project --with pre-commit pre-commit run --all-files` in the local PyTorch container: passed.
- `git diff --check`: passed.
- Dockerfile build check parsed the modified Dockerfile with only its existing default-ARG warning.

A rebuilt Framework image and container scan are needed to confirm both the installed package and the cached FFmpeg library are absent.
