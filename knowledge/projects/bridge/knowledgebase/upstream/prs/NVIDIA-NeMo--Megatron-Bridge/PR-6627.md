## Original PR description

# What does this PR do ?

The default 64x GB300 MXFP8 recipe for Qwen3.5-VL 397B-A17B lacked six settings of the tuned configuration. Add them on top of the MXFP8 base:

- CuTe DSL fused grouped MLP (Transformer Engine op fuser, 32-wide GLU interleaving and NVTE_CUTEDSL_FUSED_GROUPED_MLP=1)
- vision-encoder CUDA graphs (attn and mlp scopes, cap of 1029 patches)
- precision-aware optimizer with BF16 Adam moments
- selective recompute of core attention and the GDN output norm
- 128-token HybridEP dispatch and preprocessing chunks
- LayerNorm SM margin of 16

The VRNVL72 397B recipe now builds from the shared MXFP8 base; its effective configuration is unchanged.
