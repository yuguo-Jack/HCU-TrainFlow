# docs(model): pin Super VL cards to the public HF revision

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6616) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Fixes both Nemotron 3.5 Super VL verification cards failing the repo's card validator, by pinning the public HF revision (including `--hf-revision` on `manual_forward_pass`) and re-verifying model-level items, five H100 training leaves and three full-VL GB200 leaves at it. Published verified leaves that were not re-run here are kept exactly as published.

# Changelog

- `examples/model_verification_cards/nemotron-3.5-super-vl-120b-a12b/card.yaml`: `hf_revision` 1f8953f7; `--hf-revision` on import, `manual_forward_pass` and inference; conversion and inference re-verified 2026-10-21; H100 `pretrain`, `sft`, `peft` and `checkpoint_resume` and GB200 `sft`, `sft_export_inference` and `peft` re-verified 2026-10-21 with leaf `bridge_commit` 19167581 (#6220). `manual_forward_pass` and H100 `sft_export_inference` keep their published status, pins and results.
- `examples/model_verification_cards/nemotron-3.5-super-vl-120b-a12b-text-only/card.yaml`: same pin; `--hf-revision` on import and `manual_forward_pass`; conversion and inference re-verified; H100 `peft` re-verified 2026-10-21 at the card commit 5e63b9d9. `manual_forward_pass` and H100/GB200 `sft`, `sft_export_inference` and GB200 `peft` keep their published status, pins and results.
- `tests/unit_tests/doc_consistency/test_verification_cards_validate.py`: runs the validator on every shipped card.
- `tests/unit_tests/skills/create_model_verification_card/test_validate_card.py`: unchanged; the audited TPS inputs match the leaves on this branch.
- `docs/`: regenerated catalog and the two model pages.

# Additional Information

- **Root cause:** #6220 blanked `model.hf_revision` and dropped `--hf-revision` from both `manual_forward_pass` commands, which `validate_card.py` rejects.
- **Revision:** 1f8953f7 is the current head. Its safetensors, config, code and tokenizer match the weight upload 629edd24 by LFS oid; later commits changed only README and docs files.
- **Verification (4x GB200, nemo:26.08.01, card commits):** both imports and exports pass. Exports match the pinned source exactly: 43,079 VL tensors and 42,683 text-only tensors. Both inference literals reproduce. The new test is RED on main (2 of 31 cards) and GREEN here.
- **Training re-verification (H100, nemo:26.08.01):** full-VL pretrain (200 steps, checkpoints at 100 and 200), SFT (200 steps), PEFT (500 steps) and resume from step 100 to 200 ran Bridge 19167581 (#6220) from the card's GPU import of 1f8953f7; all 500 resumed loss values (steps 101-200) are within 1% + 1e-6 of the reference. Text-only PEFT (500 steps) ran 5e63b9d9 from the card's text-only import and export of 1f8953f7. Each run executed the card command; metrics come from those logs.
- **GB200 re-verification (nemo:26.08.01 aarch64):** full-VL SFT (64 GPUs, 200 steps, checkpoints at 100 and 200), its post-SFT export plus strict native HF reload and image generation, and PEFT (16 GPUs, 500 steps, checkpoints at 250 and 500) ran Bridge 19167581 (#6220) from the card's GPU import of 1f8953f7, with the card commands; metrics come from those logs.
- **Text-only GB200 SFT and PEFT did not complete when re-run here** (card commit 5e63b9d9, also unchanged at 19167581): they reuse the Nemotron 3 Super H100 recipes, whose HybridEP environment (`NUM_OF_HYBRID_EP_RANKS_PER_NVLINK_DOMAIN=8`, `NVLINK_DOMAIN_SIZE=8`, `USE_MNNVL=0`) does not match four-GPU GB200 nodes; HybridEP stops in `cudaIpcOpenMemHandle` (invalid resource handle) before step 1. Adding `env_vars.NUM_OF_HYBRID_EP_RANKS_PER_NVLINK_DOMAIN=16 env_vars.NVLINK_DOMAIN_SIZE=72 env_vars.USE_MNNVL=1` to the PEFT command let a diagnostic run finish all 500 steps. These leaves are left as published; the result is reported on the NVBug.
- **Not pinned:** export commands still read the Hub default branch. With `--hf-revision`, export fails in this container: transformers 5.12.1 resolves the cache snapshot symlinks before looking up the remote-code modules. H100 post-SFT export with the card command ran out of GPU memory on 4x H100 when re-run here; that leaf is left as published.
- **Overlaps** #6599, #6600, #6601 and #6606 (same cards; they re-verified leaves on the public weights). Expect conflicts.
- **NVBug:** 6970566.
