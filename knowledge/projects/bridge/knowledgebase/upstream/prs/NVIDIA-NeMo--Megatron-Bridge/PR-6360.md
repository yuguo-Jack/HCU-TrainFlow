# Enable whole-block recompute for Qwen3VLSelfAttention

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6360) · state: open · merged: False

## Original PR description

Rename Qwen3VLSelfAttention.forward to _forward so it no longer overrides Attention.forward. Megatron-Core's Attention base class now dispatches through forward to optionally checkpoint the whole attention block when "attention" is in recompute_modules; overriding forward directly bypassed that dispatcher entirely, silently disabling whole-block recompute for this model's attention layers. Requires the corresponding Megatron-LM change https://github.com/NVIDIA/Megatron-LM/pull/7994 adding "attention" to recompute_modules.
