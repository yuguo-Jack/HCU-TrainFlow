## Original PR description

# What does this PR do ?

Migrate Qwen3.5 text and vision-language models to `HybridModel`, preserving HF checkpoint conversion, MTP, and pipeline parallelism. Fix rotary inputs for CUDA graph replay and add regression coverage and a model verification card.

Validated 100-step training and checkpoint resume; step-51 losses match, and step-100 losses differ by 0.057%.

[P2] Restore virtual-stage checks in language-only construction

**Failure:** With PP=2/VPP=2, calling either provider's `provide_language_model(vp_stage=1)` on PP rank 0 now passes `pre_process=True`. PP rank 1 at `vp_stage=0` similarly receives `post_process=True`. That places embedding/output processing on intermediate logical stages. The [previous implementation](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/32d7094ed873ba8fbba2f2a34088acb1bdce7ffa/src/megatron/bridge/models/qwen_vl/qwen35_vl_provider.py#L544-L546) delegated to GPTModelProvider, whose [stage logic](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/6452af72ace14f5ba28f54e6373792d8bbd022ee/src/megatron/bridge/models/gpt_provider.py#L281-L289) combines physical and virtual predicates.

**Correction:** Import `is_vp_first_stage` and `is_vp_last_stage`, set `vp_size = provider.virtual_pipeline_model_parallel_size` in `_provide_qwen35_language_model`, and replace the two flag expressions with:

```python
pre_process=(
    is_vp_first_stage(vp_stage=vp_stage, vp_size=vp_size)
    and is_pp_first_stage(pg.pp)
) if pre_process is None else pre_process,
post_process=(
    is_vp_last_stage(vp_stage=vp_stage, vp_size=vp_size)
    and is_pp_last_stage(pg.pp)
) if post_process is None else post_process,
```

Only the first logical stage should preprocess, and only the last should postprocess. Preserve explicit caller flags and non-virtual PP behavior. Keep stage arguments out of the reusable MIMO spec, whose [existing test](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/6452af72ace14f5ba28f54e6373792d8bbd022ee/tests/unit_tests/models/megatron_mimo/test_qwen35_vl_provider.py#L54-L79) requires their absence.

**Acceptance — proposed, not run:** Record `build_module` arguments for both providers with PP=2/VPP=2. For `(pp_rank,vp_stage)` values `(0,0),(1,0),(0,1),(1,1)`, assert `(pre_process,post_process)` equals `(True,False),(False,False),(False,False),(False,True)`. Also check explicit overrides remain unchanged and PP=1 without VPP defaults to `(True,True)`. Verify the suggested code before adopting it.

[P2] Apply vocabulary padding before constructing the language-only model

**Failure:** This path now constructs the reusable MIMO spec directly, whose [vocab_size is the raw provider value](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/6452af72ace14f5ba28f54e6373792d8bbd022ee/src/megatron/bridge/models/qwen_vl/qwen35_vl_provider.py#L578-L595). Both providers consequently ignore `should_pad_vocab=True`. For example, `vocab_size=131`, TP=2, and `make_vocab_size_divisible_by=128` forwards 131 instead of 256, leaving an indivisible vocabulary for tensor-parallel embeddings/output. The former [GPT provider path](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/6452af72ace14f5ba28f54e6373792d8bbd022ee/src/megatron/bridge/models/gpt_provider.py#L265-L271) and the [full VL constructor](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/6452af72ace14f5ba28f54e6373792d8bbd022ee/src/megatron/bridge/models/qwen_vl/modelling_qwen3_vl/model.py#L382-L398) both apply that policy.

**Correction:** Import `calculate_padded_vocab_size` from `megatron.bridge.utils.vocab_utils`. In `_provide_qwen35_language_model`, prepare the fresh spec before `build_module`:

```python
spec = provider.build_language_model_spec()
if provider.should_pad_vocab:
    spec.params["vocab_size"] = calculate_padded_vocab_size(
        provider.vocab_size,
        provider.make_vocab_size_divisible_by,
        provider.tensor_model_parallel_size,
    )
```

Pass `spec` instead of `provider.build_language_model_spec()` to `build_module`. Keep this adjustment local to this construction entry point: preserve the raw-vocabulary contract of `build_language_model_spec()` for MIMO callers. Padding-disabled sizes must remain exact, and already-aligned sizes must remain unchanged.

**Acceptance — proposed, not run:** For both providers, inspect the spec supplied to `build_module`: `131/TP2/divisor128/padding=True` must supply 256; `256/TP2/padding=True` must remain 256; and `131/TP1/padding=False` must remain 131. Separately retain the raw `provider.vocab_size` assertion in [test_language_model_spec_shape](https://github.com/NVIDIA-NeMo/Megatron-Bridge/blob/6452af72ace14f5ba28f54e6373792d8bbd022ee/tests/unit_tests/models/megatron_mimo/test_qwen35_vl_provider.py#L64-L79). A tiny two-rank model should construct successfully for the padded case. Verify the suggested code before adopting it.
