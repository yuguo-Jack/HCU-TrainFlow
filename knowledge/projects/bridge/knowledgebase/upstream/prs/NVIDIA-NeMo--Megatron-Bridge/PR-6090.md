# fix(perf): allow --moe_a2a_overlap false to disable A2A overlap

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6090) · state: open · merged: False

## Original PR description

# What does this PR do ?

Allow `--moe_a2a_overlap false` to disable MoE A2A communication overlap when a recipe enables it.

# Changelog

- Updated `_set_moe_a2a_overlap_overrides` in `scripts/performance/utils/overrides.py` to set `recipe.comm_overlap.overlap_moe_expert_parallel_comm = False` when `moe_a2a_overlap is False`.
- Changed default `moe_a2a_overlap` parameter to `None` so omitting the CLI flag preserves the recipe default.
- Added regression tests in `tests/unit_tests/scripts/performance/test_user_overrides.py` verifying `--moe_a2a_overlap false`, `--moe_a2a_overlap true`, and omitted behavior.
