# fix(perf): size Ultra HSDP instances from launch GPU count

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6318) · state: closed · merged: True

## Original PR description

Fixes Nemotron 3 Ultra weak scaling by passing the actual launch GPU count into its performance recipes instead of using a fixed count of 256. A 512-GPU launch now selects eight HSDP optimizer instances rather than four.

Applies to FP8-MX and NVFP4 recipes on GB200, GB300, and VR200. Preserves the existing optimizer-count formula, 256-GPU defaults, and explicit user overrides.
