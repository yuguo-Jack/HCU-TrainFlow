# fix(recipe): shard expert optimizer state over DP-outer in DSv3 GB300 HSDP recipe

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6764) · state: open · merged: False

## Original PR description

## Problem
`deepseek_v3_pretrain_256gpu_gb300_fp8mx_hsdp_config` set `expert_outer_dp_sharding_strategy = "no_shard"` while `outer_dp_sharding_strategy = "optim"`. Megatron-FSDP v1 applies `outer_dp_sharding_strategy` to expert parameters and ignores the expert field, but v2 honors it, so the recipe trained differently under v1 and v2.

## Changes
- Set `expert_outer_dp_sharding_strategy = "optim"` in the recipe so expert optimizer state is sharded over DP-outer under both v1 and v2.
- Add a unit test asserting the two outer sharding strategies agree.
