# build: AUT-2526 bump MCore main to 6911c751

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6432) · state: closed · merged: False

## Original PR description

## Background

Nightly Megatron-Core bump of the `main` lane. This moves the `3rdparty/Megatron-LM` submodule and `.main.commit` from `e0c5e186` to `6911c751`. `.dev.commit` is unchanged (`4a4de865`).

## What changed

- `.main.commit` and the `3rdparty/Megatron-LM` gitlink now point at `6911c751fdab0b9ef55eb3d4efa22f294aa4682c`.
- `pyproject.toml`: the TransformerEngine dependency metadata matches MCore's pin, `2.20.2+44f31bbe` (tip of `release_v2.20.2-nemo`).
- `uv.lock` regenerated with `uv lock --upgrade` using uv 0.7.2, which matches `UV_VERSION` in `docker/Dockerfile.ci`. `uv lock --check` passes.

## Details

MCore commits in the bump:
- #8102: CI routing only.
- #8036: TransformerEngine pin bump.
- #7828: request-local sampling seeds in `megatron/core/inference`.

The TransformerEngine delta is a single Python-only change to the SM100 CuTe fused grouped MLP, which H100 never reaches. The other lock bumps are patch-level transitive dependencies.

Tests were selected from this impact: all Core unit shards, plus `L1_Launch_vlm_inference`, which exercises SamplingParams and TextGenerationController. The diffusion unit tests and the other H100 functional launchers were excluded because nothing in them uses the changed modules.

## Tested

Local H100 runs on `merge(ce1b60ab, main@a2e80617)`, using an image built from that merge with the MCore pin verified:
- `Launch_Unit_Tests_Core` shard 0/3: 4022 passed
- `Launch_Unit_Tests_Core` shard 1/3: 3995 passed
- `Launch_Unit_Tests_Core` shard 2/3: 4010 passed
- `L1_Launch_vlm_inference`: passed

Shard 1/3 first stalled in FlashAttention-4 backward in `test_real_packed_multimodal_optimizer_step`. The local profile did not apply the FlashAttention policy that CI sets in `.github/actions/test-template/action.yml` (`NVTE_FLASH_ATTN_V2=1`, `V3=0`, `V4=0`). With those three variables set, the shard passed, including all 20 nemotron_omni tests. The other three runs used the profile's default FlashAttention auto-selection rather than CI's FA2 pin.

The bump does not change MCore's attention code. Main CI on this head is pending.
