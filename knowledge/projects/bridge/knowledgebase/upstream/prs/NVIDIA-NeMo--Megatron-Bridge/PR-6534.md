# build: use MCore release 50386731 and allow release revisions

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6534) · state: open · merged: False

## Original PR description

## What does this PR do?

Switch Bridge main to MCore's official `core_r0.20.0` release revision `5038673171e463b1486aca4e85dc36fcf6ffc712`, carrying the dependency change from #6523, and let CI validate official stable-release commits. The current validator rejects release-only commits before the Docker build ([failed job](https://github.com/NVIDIA-NeMo/Megatron-Bridge/actions/runs/39056340489/job/117465756222)).

## Changelog

- Set `.main.commit` and the MCore submodule gitlink from `6e7e6ed435e41af04fc41e7007ef862049153fdc` to `5038673171e463b1486aca4e85dc36fcf6ffc712`. This adopts the release line, which [diverges from the previous main pin](https://github.com/NVIDIA/Megatron-LM/compare/6e7e6ed435e41af04fc41e7007ef862049153fdc...5038673171e463b1486aca4e85dc36fcf6ffc712).
- Discover official branches matching `core_r<major>.<minor>.<patch>` and apply the existing ancestry check to their tips after checking `main` and `dev`.
- Preserve the official-repository restriction and existing PR/merge-queue approval rules. Release-looking refs with suffixes, nonnumeric versions, or nested paths do not qualify.
- Extend the existing local Git fixtures to accept a release-only tip and ancestor and reject commits available only through unapproved refs.

Main already includes #6523's TransformerEngine metadata and lock updates. Its existing `pyproject.toml` and `uv.lock` remain unchanged, preserving newer main dependencies. MCore's dependency metadata is identical at the old and new pins. `.dev.commit` is unchanged.

## Validation

- `uv lock --check` passed with CI's uv 0.7.2 and the selected release checkout in a CPU container (345 packages).
- `bash .github/scripts/test_docker_dependency_layers.sh` passed against the selected MCore release lockfile.
- Shell syntax checks, matching pin/gitlink checks, `git diff --check`, and all-file pre-commit passed.
- The updated validator accepted the exact selected SHA against the live official MCore repository; the old validator fails the new release-only fixture.
- No container build or GPU training run was performed. Runtime compatibility with main remains subject to CI.

## Additional information

Cherry-picks the effective dependency change from #6523's commit `dc558d32228631914e20735807b8e53cf35d05ad`. Backport release-branch validation to `r0.7.0` after merge to unblock #6523.
