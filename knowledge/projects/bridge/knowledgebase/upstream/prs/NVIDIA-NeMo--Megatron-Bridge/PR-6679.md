# perf(recipe): switch the Nemotron / Qwen3.5 / GLM 5.x GB200+GB300 MoE training recipes to NCCL EP and grouped tensor

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6679) · state: open · merged: False

## Original PR description

# What does this PR do ?

Switches the MoE training recipes under `src/megatron/bridge/recipes` for Nemotron 3 / 3.5, Qwen3 / Qwen3.5 (text
and VL) and GLM 5 / 5.2 on GB200 and GB300 from the HybridEP flex dispatcher to the NCCL EP flex dispatcher, in the
same way PR #6171 did for the GB300 perf recipes, and adds the one-GPU-per-rank device binding NCCL EP needs to the
library launch path (`pretrain()` -> `runtime_config_update`).

### Benchmarks (50 steps, mock data, ms per step averaged over iterations 30-45, same allocation per pair)

Before/after = HybridEP recipe on upstream main dec652474 vs this branch. Dispatcher-only = HybridEP with
`moe_use_grouped_tensor=True` vs this branch (isolates NCCL EP from the grouped-tensor change). Speedup =
hep/nep - 1. Container nemo 26.10.rc6 (TE 2.20.2, NCCL 2.31.2), MCore ebab48fc, GB300 NVL72.

| recipe | GPUs | before/after | dispatcher only |
|---|---|---|---|

| qwen3_30b_a3b_pretrain_8gpu_gb200_fp8mx | 8 | +11.2% | +5.1% |
