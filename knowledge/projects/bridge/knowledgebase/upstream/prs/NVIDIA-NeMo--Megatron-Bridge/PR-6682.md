# feat(recipe): add a Qwen3.5-35B-A3B dynamic-CP recipe on mock agentic data

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6682) · state: open · merged: False

## Original PR description

## Summary

Adds a recipe that trains the **full 40-layer Qwen3.5-35B-A3B (+MTP1)** on one four-GPU GB200 node with **dynamic context parallelism**, on **mock data** shaped like an agentic workload, and shows that dynamic CP is faster than static CP4 on it. The model and training configuration follow the Megatron-LM agentic SFT example by Zhongbo Zhu ([`420686e`](https://github.com/zhongbozhu/Megatron-LM/commit/420686e1a7e9d51d422e8ac1a18a35818843bb86)): TP1/PP1/base CP4/EP4, 64K context, MBS1, GBS32, per-token loss, MXFP8, FP32 Adam state offloaded to the host, HybridEP, full recompute. Its CoderForge data pipeline is **not** part of this PR.

```bash
uv run python -m torch.distributed.run --nproc_per_node=4 scripts/training/run_recipe.py \
    --recipe qwen35_text_35b_a3b_4gpu_gb200_fp8mx_dynamic_cp_config --mode pretrain \
    train.train_iters=200 scheduler.lr_decay_iters=200 scheduler.lr_warmup_iters=20
# static-CP4 baseline: add model.dynamic_context_parallel=false
```

**Result (NeMo 26.10 container):** over 200 steps (190 measured) on identical samples, **dynamic CP is +7.5% faster in throughput than static CP4 (13,069 vs 12,157 runtime tokens/s; 95% bootstrap interval +4.8% to +10.3%), with an 8.5% faster median step**, winning 161 of 190 paired steps.

**Merge status:** draft until NVIDIA/Megatron-LM#7048 merges. The MCore pin here is a temporary pointer to that PR's head.

## Validation

All runs on the `nvcr.io/nvidia/nemo:26.10` release container with MCore `e3165e9`.

**Mock-data recipe**, one GB200 node per run, 200 steps, steps 1-10 excluded as compilation warmup:

| Mode | Mean s/step | Median s/step | Runtime tokens/s | Median model TFLOP/s per GPU |
| --- | ---: | ---: | ---: | ---: |
| Static CP4 (`dp_balanced`) | 55.98 | 54.24 | 12,157 | 96 |
| Dynamic CP | 52.07 | 49.64 | 13,069 | 104 |

Dynamic CP is +7.5% faster in throughput (`compare_runs.py`; bootstrap 95% interval +4.8% to +10.3%), wins 161 of 190 paired steps (mean paired difference 3.9 s ± 0.7 s), and wins each of five consecutive 38-step blocks (+3.9% to +11.0%). The two runs used different nodes.

Absolute step times are about 25% higher than the earlier example-based runs in this PR (44.5 / 40.6 s on the 26.10 rc5 image). A control run of this recipe on the rc5 image matches the 26.10 release within 2.5% on identical steps 11-30, so the container is not the cause. The other differences are the mock-data generator, the MCore head (`68033c0` → `e3165e9`) and current Bridge main; not bisected.

**8-GPU CoderForge recipe** (`qwen35_text_35b_a3b_sft_8gpu_gb200_bf16_dynamic_cp_config`, review request to re-test on 26.10): two four-GPU nodes in one NVL72 rack, random init, the first 4,000 SWE-Rebench trajectories, 12 steps with the first four dropped:

| Configuration | Median step | Median TFLOP/s per GPU | Peak allocated (rank 0, first two steps) |
|---|---|---|---|
| Recipe: dynamic CP, full recompute, 16 loader workers | 79 s (was 88 s on 26.06.01) | 100 (90) | 100 GB |
| Static CP4 (`dp_balanced`) | 75 s (83 s) | 106 (93) | 99 GB |
| Recipe with 2 loader workers | 261 s (254 s) | 30 (31) | 99 GB |
| Selective recompute of `moe_act` and `layernorm` | 58 s (75 s over four steps, then NCCL OOM) | 132 (106) | 150 GB |

The conclusions hold: dynamic CP has nothing to gain on this stream (about nine in ten trajectories exceed the 32K cap) and is within noise of static; two loader workers starve the GPUs. Selective recompute now completes all 12 steps but peaks at 150 GB, so the recipe keeps full recompute's headroom.

**Unit tests** (CPU node, 26.10 container): the new `test_mock_gpt_sft.py`, `test_qwen35_dynamic_cp_mock_recipe.py` and `test_cuda_memory_fraction.py`, plus the affected `test_qwen35_text_recipes.py`, `test_qwen35_dynamic_cp_recipe.py`, `data/test_loaders.py`, `training/test_config.py` and `training/test_initialize.py`: 436 passed, 1 skipped. One test failed only because it needs CUDA (`test_native_energon_packing_allows_other_ep_dispatchers_with_fixed_width[flex]`: "Found no NVIDIA driver") and covers code this PR does not touch.

```bash

```
