# docs(model-card): verify K-EXAONE 2 distributed inference

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6294) · state: open · merged: False

## Original PR description

The K-EXAONE 2 inference card contained a worker command without its distributed launcher and an older completion. Replace it with the verified synchronous `infer.sh --task text-generation` command for 48 H100 GPUs, TP1/PP3/EP16/ETP1, the original 20 GiB KV-cache budget, and natural EOS stopping. Record the exact tested Bridge commit and October 18 result: 16 new tokens answering the Korean prompt with Seoul as the capital and largest city of South Korea.

Two complete-model runs through the public launcher produced the same literal completion. They used clean Bridge commit `27cacee9bfa562a00ed6b93ce7bbe88ce0cffdba` and its pinned Megatron-Core checkout in the NeMo Framework 26.10 release-candidate runtime. The card explicitly distinguishes that inference environment from the 26.08 base recorded for earlier checks. This PR branch includes runtime fix #6535, merged as `a7eaa195b8c0e60e9f631413181f3ace3801a697`. The inference entrypoint is byte-identical at the tested `27cacee9b`, reviewed `aa27147b`, and merged `a7eaa195b` revisions. The card retains the executed `27cacee9b` checkout and its Megatron-Core pin `8442db19`; merged main pins `ce852bfb`, so the recorded full-model result applies to the tested checkout and dependency combination.

Preserve the existing manual-forward result and the current Kimi card. Regenerate the verification catalog. NVBug 6651530.

Validation: card validator and generated-catalog consistency pass; 24 catalog tests pass; all-file pre-commit and `git diff --check` pass. Independent review inspected the complete public-run records and confirmed exact source bindings, all 48 ranks, the literal completion, and the original KV20/natural-EOS settings. Separate controlled runs provide the finite-logit and checkpoint-reload checks; those measurements are not attributed to the public-launcher runs.

Prepared with AI assistance; independently reviewed before publication.
