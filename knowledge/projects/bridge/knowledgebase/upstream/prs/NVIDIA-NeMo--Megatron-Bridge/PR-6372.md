# refactor(recipe): split DeepSeek full-iteration helper into independent toggles

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6372) · state: open · merged: False

## Original PR description

# What does this PR do ?

Split `_enable_deepseek_full_iteration` into independent toggles for full-iteration CUDA graphs, MoE A2A overlap, and the CuTeDSL fused grouped MLP, so each one can be turned on or off on its own like the `r0.5.0` workload-config flags.

# Changelog

- Add three helpers to `perf_recipes/_common.py`, one per feature in the `r0.5.0` `overrides.py` flags (`cuda_graph_impl` / `moe_a2a_overlap` / `cutedsl_fused_grouped_mlp`):
  - `_enable_full_iteration_cuda_graph`: `cuda_graph_impl="full_iteration"`, TE RNG tracker, NaN-loss check off, plus the dropless-MoE padding / capacity factor / paged-stash settings that full-iteration capture needs (what `set_full_iter_cg_configs` did in `r0.5.0`).
  - `_enable_moe_a2a_overlap`: `overlap_moe_expert_parallel_comm`, `delay_wgrad_compute`, `moe_shared_expert_overlap=False`.
  - `_enable_cutedsl_fused_grouped_mlp`: `use_transformer_engine_op_fuser`, `moe_mlp_glu_interleave_size=32`.
- Keep the `r0.5.0` coupling: `high_priority_a2a_comm_stream=True` and `moe_hybridep_num_sms_preprocessing=32` are applied only when **both** the fused grouped MLP and A2A overlap are enabled. The result does not depend on call order.
- Remove `_enable_deepseek_full_iteration` and its four HybridEP dispatcher assignments. For every caller, the library `deepseek_v3_pretrain_config()` already selects flex + HybridEP and `_benchmark_common` already sets `moe_hybridep_num_sms=32`. The GB300 NCCL EP variants switch the backend afterwards through `_enable_ncclep`, so dispatcher choice stays separate from graph capture.
- Update the B300 / GB200 / GB300 / VR200 DeepSeek V3 recipes to call the toggles explicitly.
- `deepseek_v3_pretrain_128gpu_gb300_fp8mx_hsdp_config` inlined the full-iteration and fused-MLP settings because it runs **without** A2A overlap. It now calls the two helpers it needs.
- Add `tests/unit_tests/recipes/test_perf_recipe_feature_toggles.py` (each toggle in isolation, both call orders for the joint settings, `comm_overlap=None`). Update the stub in `test_deepseek_vr200_perf_recipes.py`.

Recipe call sites now read:

```python
_benchmark_common(cfg)
_enable_full_iteration_cuda_graph(cfg)
_enable_moe_a2a_overlap(cfg)            # drop this line to run without A2A overlap
_enable_cutedsl_fused_grouped_mlp(cfg)  # must come after _benchmark_common (it turns the op fuser off)
```
