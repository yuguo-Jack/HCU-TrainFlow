## Original PR description

# What does this PR do ?

The Beam card's six model-level items could not be reproduced (pin 757805c7 is not in the public repo, HF revision 3ea13c81 returns 404); this re-verifies and re-pins them at public commit 21af081c with HF revision 06641076.

# Changelog

- `examples/model_verification_cards/beam/card.yaml`: model-level items re-pinned to 21af081c / 06641076, GPU commands moved to 4 x 4 GB200, evidence text updated; `model.hf_revision` set to 06641076.
- `docs/_static/model-verification/catalog-v1.json`, `docs/models/beam/beam.md`, `docs/fern/.../beam.mdx`: regenerated.
- `tests/unit_tests/doc_consistency/test_verification_card_recipe_revisions.py`: verified Beam model-level items must record a commit in repo history.

- **Root cause:** #6498 recorded pre-rebase PR-branch commits and a pre-release HF revision; 06641076 is the only public weights revision.
- **Verification:** all six items passed at 21af081c. GPU items ran on 4 x 4 GB200; CPU items ran on an H100 host with 2 TB of memory. Both exports match the source exactly: 38,366 tensors, 0 mismatches. Forward pass: token match True, cosine 0.999526.
