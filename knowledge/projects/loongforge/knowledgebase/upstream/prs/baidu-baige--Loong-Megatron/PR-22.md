# [llm] fix:skip unnecessary MLA attention mask allocation

[Upstream PR](https://github.com/baidu-baige/Loong-Megatron/pull/22) · state: open · merged: False

## Original PR description

## Background

ChunkPipe pretraining with a 512K sequence length and 8 chunks encounters OOM during the forward pass of the last chunk:

```text
File "megatron/core/transformer/multi_latent_attention.py", line 564, in concat_cached_chunk_key_value_mla
    mask_org = torch.ones(curr_len, total_concatenated_tokens, dtype=torch.bool,
torch.OutOfMemoryError: CUDA out of memory. Tried to allocate 32.00 GiB.
```

`concat_cached_chunk_key_value_mla` constructs a dense boolean mask of shape `[curr_len, total_concatenated_tokens]`. With a 512K sequence evenly divided into 8 chunks, the mask for the last chunk has a size of `65536 × 524288` bytes, requiring 32 GiB of GPU memory.

However, in the non-DSA MLA pretraining path, `forward()` already switches `attn_mask_type` to `causal_bottom_right`, where the attention kernel handles causal masking internally. Therefore, explicitly constructing this dense mask is unnecessary.

## Changes

Add a condition in `concat_cached_chunk_key_value_mla` to skip dense mask allocation when `causal_bottom_right` is used. The condition matches the one in `forward()`:

```python
uses_bottom_right = (
    not self.config.sft_chunkpipe_mode
    and self.config.experimental_attention_variant != "dsa"
)

if attention_mask is not None and not uses_bottom_right:
    # Original mask construction logic remains unchanged.
```

When `uses_bottom_right` is true, `adjusted_mask` is set to `None`, avoiding the unnecessary allocation.

The existing behavior is preserved for SFT and DSA paths.

## Scope and Impact

- Affects only the non-DSA MLA path in ChunkPipe pretraining.
- Eliminates the allocation of a dense mask of size `curr_len × total_concatenated_tokens` for each chunk forward pass.
- Also benefits recomputation forward passes when activation recomputation is enabled.
- Works with both uniform and non-uniform chunking. For example, with a 512K sequence split into 8 chunks, the first chunk has a length of 167040, and the original mask would require approximately 26 GiB. The new implementation reduces this allocation to zero.
- SFT ChunkPipe, DSA, and non-ChunkPipe paths remain unchanged.
