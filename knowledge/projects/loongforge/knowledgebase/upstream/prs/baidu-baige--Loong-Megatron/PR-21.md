# [llm] fix: Reduce RoPE Cache Memory Overhead and Fix Causal Mask Alignment in ChunkPipe

[Upstream PR](https://github.com/baidu-baige/Loong-Megatron/pull/21) · state: closed · merged: True

## Original PR description

## Problem

The MLA + ChunkPipe path has two issues:

- **Redundant cache memory usage:** `key_pos_emb_cache` stores identical RoPE keys for every attention head, resulting in unnecessary memory overhead.
- **Incorrect causal mask alignment:** In ChunkPipe, Q contains only the current chunk, while K/V span all tokens up to and including it, resulting in `s_q < s_kv`. The existing `causal` mask uses top-left alignment and cannot correctly handle this case.

## Changes

**Cache Memory Optimization:**

- `init_chunk_key_value_cache_mla`: Reduce the head dimension of `key_pos_emb_cache` from `num_attention_heads_per_partition` to `1`.
- `get_query_key_value_tensors`: Store the expanded tensor in a separate variable, `k_pos_emb_per_head`, for key concatenation only. Keep `k_pos_emb` single-headed for the gradient hook and cache write, avoiding unintended broadcasting in `grad + grad_from_prev_chunk` that would amplify the gradient across heads.
- `recover_key_value_up_proj_tensors`: Expand the cached tensor back to the full head dimension based on the number of heads in `k_no_pe`, with a shape check to avoid redundant expansion.

**Causal Mask Fix:**

- `forward`: Use `AttnMaskType.causal_bottom_right` for non-SFT ChunkPipe paths to ensure correct causal mask alignment for unequal Q/KV lengths. SFT uses the THD packed layout, so its existing padding-mask handling is preserved.
- `forward`: Explicitly pass `attn_mask_type` to `_checkpointed_attention_forward` to prevent selective recomputation from silently reverting to `self.attn_mask_type` (`causal`) and overriding the corrected mask type.

## Impact

- **Reduced memory usage:** For PP rank 0 with `kv_cache_chunk_size=22`, `max_chunk_size=13824`, 16 heads, head dimension 64, and BF16, the per-layer `key_pos_emb_cache` memory usage decreases from approximately 622 MB to 39 MB.
- **Correct causal masking:** `causal_bottom_right` aligns the causal mask with the end of the KV sequence, preventing valid tokens within the current chunk from being incorrectly masked. It also avoids fallback to the unfused attention path, which explicitly materializes the attention score matrix.
- **Consistent RoPE cache behavior:** The fused RoPE path previously wrote only head 0 to the cache, leaving the remaining heads zeroed. With a single-head cache, both RoPE paths now use the same storage layout.

## Scope

- Changes are limited to `megatron/core/transformer/multi_latent_attention.py`.
- Existing behavior for SFT ChunkPipe, non-ChunkPipe training, and inference paths remains unchanged.
