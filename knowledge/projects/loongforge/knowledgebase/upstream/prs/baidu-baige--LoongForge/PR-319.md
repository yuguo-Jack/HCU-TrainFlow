## Original PR description

## Summary

Document the validated FastWAM x LIBERO recipe and add FastWAM to the LIBERO benchmark guide.

### Changes

- `docs/source/embodied_tutorial/quick_start_fastwam.md` and `docs/source_zh/embodied_tutorial/quick_start_fastwam.md`
  - new "Validated Recipe (LIBERO 4-suite)" section: 8 GPUs, per-device batch 16, 20k steps, fp32 master, `CLIP_GRAD=1.0`, `linear_warmup_cosine_annealing`, DCP + async save;
  - notes on why the fp32 master copy is required, the cost of disabling clipping, and the required `dataset_stats.json`;
  - 2000-episode results table;
  - new "Evaluation" section pointing at the LIBERO benchmark page.
- `docs/source/embodied_tutorial/eval_docs/benchmarks/libero.md`
  - FastWAM added to the verified-model list, weights table, run command, key config fields, and the success table.
