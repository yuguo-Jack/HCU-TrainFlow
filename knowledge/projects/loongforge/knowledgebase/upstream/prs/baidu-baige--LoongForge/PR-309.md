# [llm] fix: enable V-dimension padding for MLA FlashAttention

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/309) · state: closed · merged: True

## Original PR description

## Background

DeepSeek MLA uses a Q/K head dimension of 192 and a V head dimension of 128. When `--enable-fa-within-mla` is enabled, the code forces the use of FlashAttention without enabling V-dimension padding accordingly. As a result, Transformer Engine (TE) cannot select a supported attention backend and raises the following error:

```text
ValueError: No dot product attention backend is available for the provided inputs.
```

The ChunkPipe path already enables V padding automatically, so this issue primarily affects the standard MLA path.

## Changes

When processing `--enable-fa-within-mla`, also set:

```python
args.padding_v_to_qk_dim = True
```

This pads V from 128 to 192 dimensions to match Q/K and satisfy FlashAttention's input requirements. The attention output is restored to the original V dimension in subsequent operations, preserving the model parameter shapes and final output dimension.

## Impact

- Affects only MLA models with `--enable-fa-within-mla` explicitly enabled.
- Non-MLA models and models without this option enabled are unaffected.
