# [data, scripts] feat: support Kimi K2.5 tool-calling SFT

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/87) · state: closed · merged: True

## Original PR description

## Summary

Add Kimi K2.5 tool-calling SFT data support and use HF chat templates to build OpenAI Chat Completions-style samples.

## Changes

- add an HF-backed Kimi K2.5 training chat template and OpenAI Chat Completions dataset format handling
- extend SFT tokenization/format utilities for `messages`/`tools` samples and tool-call labels
- add multimodal chat-mix flavors and route chat/packed-chat-mix encoders through the dataloader provider
- update SFT/VLM preprocessing, training setup, and data preprocessing tools for tool-calling and WDS workflows

## Usage

- Use the `openai_chat_completions` dataset format for tool-calling SFT data. Samples should provide a `messages` column and may provide a `tools` column.
- Select the `kimi-k2.5-hf` chat template so LoongForge uses the new HF/Jinja training template with assistant-generation spans.
- For multimodal WebDataset data, use the new `chat_mix` flavor for online samples and `packed_chat_mix` for offline-packed samples; each conversation keeps OpenAI-style `messages` plus optional `tools` metadata.
- Example dataset config section:

```yaml
openai_chat_completions:
  format: openai_chat_completions
  columns:
    messages: messages
    tools: tools
```
