# [train] fix: isolate async checkpoint Gloo collectives [BUG-259] 

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/283) · state: open · merged: False

## Original PR description

Fixes #259

Issue #259 caused a Gloo collective mismatch when DCP async checkpoint saving shared the default Gloo process group with StageTimers CPU all_gather.

This change:
- creates a dedicated Gloo process group for stage timing;
- routes StageTimers all_gather through that group;
- preserves the default process group for DCP async save;
- destroys the timing group before the default process group.

Validation:
- CPU/Gloo regression tests passed: 9 passed;
- real 8-GPU Pi05 FSDP run completed 30/30 steps with --save-format dcp --async-save;
- async and synchronous DCP checkpoints both resumed successfully from step 20 to step 30;
- resumed loss maximum relative difference was 0.182265%;
- checkpoints contained resume_meta.json and 8 DCP shards.
