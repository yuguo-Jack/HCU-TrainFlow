# [release, ci, tests] feat: add operator-controlled release workflow

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/275) · state: closed · merged: True

## Original PR description

## Summary

- Add an operator-controlled, `workflow_dispatch`-only Release workflow with independent build, regression, internal publication, and Docker Hub publication stages.
- Make formal releases tag-first: the Portal creates `v<version>` for a selected master commit, dispatches that tag, and the workflow verifies tag/version/master ancestry before production publication.
- Enforce strict SemVer formal tags (`vX.Y.Z` or `vX.Y.Z-rc.N`) and create a GitHub Release with generated notes only after all formal stages succeed.
- Route logical execution slots to operator-managed hosts while keeping machine topology and credentials runner-local.
- Add release regression evidence, model selection validation, trusted image handling, registry promotion, debug-tag cleanup, and security checks.
- Harden release logs by masking dynamic execution targets, storing the internal image repository as a secret, and using a non-user-scoped Docker config path.

## Changes

- Add per-request stage switches with GitHub-variable fallbacks and workflow-only manual triggering; pushing a Git tag never starts a release.
- Require a matching release tag for production publishing; build or regression failure exits before any registry push.
- Consolidate slot routing into `run_release_regression.sh` and remove the separate slot-wrapper script.
- Promote images with `regctl`; registry passwords are passed over stdin and removed with logout instead of appearing in remote command arguments.
- Record source SHA, execution slot, and image digest in release regression evidence.
- Consolidate release infrastructure tests into `test_release_infrastructure.py` and release request/model tests into `test_release_request.py`.
- Document the release version policy, separate release-bump PR, GitHub Release notes, runner naming constraints, and CI setup instructions.
