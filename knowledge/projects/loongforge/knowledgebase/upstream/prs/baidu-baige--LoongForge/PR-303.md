# [vla, docs] fix: harden eval completeness, resume, and repro metadata

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/303) · state: closed · merged: True

## Original PR description

## Summary
- Make eval completeness and resume semantics trustworthy: infrastructure failures are neither counted as completed nor included in success-rate denominators, and expected episode coverage is derived from task definitions.
- Record real reproducibility metadata for every run and expose structured reports through the unified entry point.
- Make CALVIN repro comparison work and harden sweep server startup/config handling.
- Correct the stale X-VLA LIBERO-object docs number.

## Changes
- F1: `INFRA_FAILURE_REASONS`, filtered `completed_episode_keys`, success-rate denominators exclude infra failures, added `infra_failed`.
- F2: expected coverage from task definitions, default completeness floor aligned to `episodes_per_task`, non-zero exit on incomplete coverage.
- F3: `run_manifest.json` + `resolved_config.yaml` + `effective_config.json`, with git/benchmark/checkpoint/protocol metadata.
- F4/F10: config mappings, `resume` default false, resume directory guard, checkpoint path/content validation (fail-fast before model load), replay directory guard, report trigger.
- F12: benchmark-aware repro keys (`sequence_idx` for CALVIN).
- Sweep: retry transient server bind failures; pass the expanded effective config to the policy server so server-side overrides take effect.
- Docs: correct the stale X-VLA LIBERO-object success-rate typo (79/100 -> 94/100).

## Test Plan
- Unit tests: 51 passed, 1 skipped; ruff clean.
- Real FastWAM + LIBERO: 4 suites x 10 tasks x 10 episodes = 400 episodes, 0 infra failures, 40/40 tasks with complete coverage.
- Protocol-aligned rerun reproduces the previous 50-episode run's first 10 episodes exactly: 400/400 match on success, steps, and failure_reason.
- Fault injection: killing the policy server produces an infra record and exit 2; resume retries that episode; checkpoint path/content mismatch, unsafe directory reuse, restart, timestamped output, and manifest-missing resume all verified end-to-end.
- `ci/sensitive_scan.py`: PASS (0 errors).
- CALVIN: live simulation unavailable in this environment; verified with CALVIN-schema records plus a real-LIBERO regression.
