# fix(vla): align the FastWAM LIBERO eval configs with the reproduced protocol

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/279) · state: closed · merged: True

## Original PR description

The four LIBERO eval configs did not match the protocol the 20k SFT eval was
measured with. Aligned: `max_steps` 0 -> 400/400/400/700 (0 fell back to the
adapter default 220/280/300/520), `env_seed_mode: per_task`, `run.seed: 42`,
`model.noise_seed: 42`, `episodes_per_task: 50`, `model.variant: uncond`.
The header now reports the reproduced result (spatial 97.00 / object 99.60 /
goal 97.20 / libero_10 94.20 % = 1940/2000 = 97.00% TOTAL) instead of the old
10x10 official-checkpoint smoke run.

Config-only: no runner or model code is touched.
