# [vla, scripts, tests, docs] perf: optimize DreamZero Wan2.1 14B FSDP training

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/323) · state: closed · merged: True

## Original PR description

## Change Summary

- Compile the whole causal attention block for Wan2.1-14B
  (`compile_causal_attention_block: true`) and move the once-only log out of the
  compiled region. Inside the compiled block its side effect became a Dynamo guard
  between the first forward and the activation-checkpoint recompute, which failed
  the first backward with a CheckpointError. The state-attention and
  context-parallel messages now print at construction time, so the block compiles
  as one graph and `@torch.compiler.disable` is no longer needed.
- Align `examples/embodied/dreamzero/run_dreamzero_wan21_14b_full_fsdp_finetune.sh`
  with the measured 14B recipe: keep the frozen VAE out of FSDP (bf16), bf16
  parameter unshard, explicit and overridable reshard/prefetch, transform-config
  validation, and cache features listed explicitly. Prompt embeddings stay opt-in
  (`--include-prompt-embs` plus `CACHE_PROMPT_EMBS=true`); enabling them skips the
  frozen text encoder but makes the cache several times larger.
- Command-line dotlists now win over the script's own dotlists. The script has to
  emit its dotlists after `"$@"` to keep them contiguous for argparse, which
  silently replaced user overrides such as
  `model.precomputed_cache.features.prompt_embs.enabled=true`.
- Keep whole-block compile off in `run_dreamzero_wan21_14b_lora_fsdp_finetune.sh`.
  Its default variable-length samples recompile the block for each new length,
  which fails in Inductor.
- Run the embodied regression target `dreamzero_wan21_14b_full_fsdp` in
  deterministic mode (`DETERMINISTIC_MODE`, off by default) and re-collect its
  chip-p baseline, because the compiled blocks make two identical runs differ by
  more than the gate.
- Docs (en/zh): performance switch table, the 14B control-group command, and the
  14B cache notes.

Modules affected: `vla`, `scripts`, `tests`, `docs`. No API or config-schema change.

## Validation

- The 14B full fine-tuning defaults are faster than before on 8 GPUs, with losses
  matching the reference runs.
- LoRA and full fine-tuning both run; the embodied target
  `dreamzero_wan21_14b_full_fsdp` passes under `bash tests/embodied/run.sh`.
