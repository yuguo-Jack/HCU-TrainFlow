# [docker, ci, docs] refactor: move dependency patches under third_party

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/290) · state: closed · merged: True

## Original PR description

## Change Summary

- What changed?
  - Move the root-level `patches/` directory to `third_party/patches/`.
  - Update `setup_env.py`, the GPU Dockerfile, the patch application script, documentation, and CI/pre-commit exclusion rules to use the new location.
  - Add the patch directory to `third_party/README.md` so the third-party layout documents both Loong-Megatron and TransformerEngine patches.
- Which issue or requirement does this address?
  - Organize repository-managed third-party dependencies and TransformerEngine patches under `third_party/`.
  - Keep source installation and Docker TransformerEngine setup aligned with the relocated patch files.
- Which modules are affected?
  - `setup_env.py`
  - `docker/Dockerfile`
  - `third_party/patches/`
  - CI and pre-commit path filters
  - English and Chinese repository/install documentation
