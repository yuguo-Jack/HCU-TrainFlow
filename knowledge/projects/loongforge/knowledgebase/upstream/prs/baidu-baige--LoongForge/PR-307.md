# [vla, data] feat: support VPP2 action and joint training

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/307) · state: open · merged: False

## Original PR description

## Change Summary

Add native VPP2 training for the LIBERO action stage and RoboDojo joint Video/Action stage through the shared `vpp2` model entry and configuration schema.

- Integrate the dataset adapters, transforms, collators, distributed samplers, strict pretrained-checkpoint loading, and DeepSpeed checkpoint/resume support.
- Reuse `FinetuneTrainer` with the existing per-module LR groups and a model-provided scheduler for the released joint-training recipe.
- Provide LIBERO DDP / DeepSpeed ZeRO-2 launchers and the RoboDojo ZeRO-2 CPU-offload launcher. Consolidate the VPP2 data and model modules to reduce directory nesting.

Validation of the final implementation:

- 182 focused CPU regression tests passed before the verification files were removed from the submission.
- Exact before/after agreement for the complete joint LR curve through 100,000 steps, optimizer parameter order/options, and tiny joint-model losses, gradients, parameter updates, optimizer state, and RNG with activation checkpointing enabled and disabled.
- Optimizer/scheduler restore tests passed across warmup and both cosine-stage boundaries. Full meta-model layouts, frozen modules, and parameter-group coverage also matched.
- Staged Python syntax, all three launcher shell syntax checks, and `git diff --check` passed.

Final-commit GPU verification reran both canonical LoongForge launchers (LIBERO and RoboDojo) on eight GPUs for 50 optimizer updates each at global batch 16. Both completed normally with 800 consumed samples, no NaN, and no skipped updates. All recorded loss channels and global pre-clip gradient norms matched the accepted community baselines and the pre-cleanup LoongForge runs exactly. RoboDojo LR matched exactly; LIBERO retained the previously documented Python-double LR rounding difference (maximum `8.47e-22`, identical in FP32), with exact LR agreement against pre-cleanup LoongForge. These were fresh native launches using system Python, without RNG/projection replay or extra training probes. Full-precision logs and comparison reports are retained locally.
