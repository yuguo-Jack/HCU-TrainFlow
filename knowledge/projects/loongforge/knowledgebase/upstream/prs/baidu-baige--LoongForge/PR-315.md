# [docs] docs: align Pi0.5 speedup with the published 3.00x result

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/315) · state: closed · merged: True

## Original PR description

## Summary

- The benchmark chart and the embodied README list Pi0.5 at 2.80x, while the
  published blog post reports 2.63x (bf16) and 3.00x (bf16 + TorchAO FP8).
  Readers comparing the two sources see a number that matches neither.
- Align the documented figure with the published 3.00x result.

## Changes

- `docs/assets/images/benchmark_image.py`: Pi0.5 row 2.80 -> 3.00
- `docs/assets/images/benchmark_speedup.png`: regenerated from the script above
- `loongforge/embodied/README.md`, `README_zh.md`: performance table 2.80x -> 3.00x

Row ordering is unchanged in both the chart and the tables — Pi0.5 stays second
behind DreamZero (4.38x), and the accent bar stays on DeepSeek-V3.2 Lite (5.04x).

## Test Plan

- Regenerated the PNG with `python docs/assets/images/benchmark_image.py`
  (matplotlib 3.10.7, Inter 4.1) and confirmed only the Pi0.5 bar and its label
  changed; the remaining pixel differences are text antialiasing from a
  different Inter/matplotlib build than the one that produced the committed PNG.
- `pre-commit run --files <changed files>`: all hooks pass.
