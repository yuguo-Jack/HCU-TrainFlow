# [vla, train, data, docs] feat: add LoongForge-VLDA training and LIBERO evaluation

[Upstream PR](https://github.com/baidu-baige/LoongForge/pull/285) · state: closed · merged: True

## Original PR description

## Change Summary

Add LoongForge-VLDA with two-stage LIBERO training and policy-server evaluation. Stage 1 initializes from OpenPI π₀.₅ base and V-JEPA 2 weights and learns the latent world model; Stage 2 initializes from Stage 1 and jointly learns world-conditioned action prediction.

- Add the VLDA model, configuration, three-stream Gemma integration, V-JEPA 2 encoder, teacher EMA, and checkpoint/statistics integration.
- Add a LeRobot v2 reader for embedded images, future frames, negative actions, and quantile normalization.
- Integrate VLDA with the shared dataset, trainer, model configuration, evaluation factory, and payload registries.
- Add an optional cosine-decay start step for Stage 2's warmup/hold/decay schedule. Its default of zero retains decay immediately after warmup.
- Add the `cookbook/loongforge-vlda/` guide, two 8-GPU training launchers, and LIBERO evaluation configuration. Keep internal and evaluation identifiers as `vlda`.
