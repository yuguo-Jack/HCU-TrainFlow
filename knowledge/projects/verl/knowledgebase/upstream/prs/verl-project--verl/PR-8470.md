**Serialize all image publications across workflow triggers.**

The build jobs are serialized per ref and architecture, but the merge jobs are not. Two runs can therefore publish the same mutable tag concurrently, and an older run can complete last and replace the newer manifest.

Because `workflow_dispatch` is not restricted to `main`, a ref-keyed group does not protect publications from other dispatch refs. Use one workflow-wide group.

<details>
<summary>Suggested fix</summary>
<dl>
<dd>

```diff
 on:
   schedule:
     - cron: "0 19 * * *"
+
+concurrency:
+  group: ${{ github.workflow }}
+  cancel-in-progress: false
```

</dd>
</dl>
