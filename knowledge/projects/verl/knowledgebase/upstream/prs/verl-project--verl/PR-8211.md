# [trainer] fix: preserve underscored UIDs in V1 replay buffer

[Upstream PR](https://github.com/verl-project/verl/pull/8211) · state: closed · merged: False

## Original PR description

### What does this PR do?

Keep prompt groups isolated in the V1 `ReplayBuffer` when a UID contains underscores.

Trajectory keys are `{uid}_{session_id}_{index}`, but the replay buffer recovers the UID with `key.split("_")[0]`. A UID such as `math_00017` maps to `math`. Its trajectories are then missed by sampling (sync mode raises "selected terminal groups with no materializable trajectories"), by DAPO reward classification, by failed-group detection and by clearing. UIDs that share a prefix can also be mixed or cleared together. The default trainer generates UUID4 UIDs (hyphens only), so default runs are not affected. The problem appears with custom or dataset-provided UIDs.

This PR parses the UID from the fixed suffixes (`key.rsplit("_", 2)[0]`) everywhere the buffer maps trajectory keys to groups.
