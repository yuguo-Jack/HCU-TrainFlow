# [packaging, doc] fix: remove unsupported legacy extras

[Upstream PR](https://github.com/verl-project/verl/pull/8502) · state: closed · merged: False

## Original PR description

### What does this PR do?

Removes the unsupported legacy `gpu`, `geo`, `prime`, `trl`, `mcore`, and `trtllm` extras from `setup.py`, leaving extras that are still declared in `pyproject.toml`. Updates the TensorRT-LLM installation instructions to install verl without the unavailable `.[trtllm]` extra and clarifies that TensorRT-LLM must be installed separately (or is already present in the recommended image).

Closes #8447.

### Why is this not duplicating an existing PR?

Searched open PRs for #8447 and for the stale TensorRT-LLM extra/package metadata. No open PR addresses this cleanup.

### Test

- `uv run --isolated --no-project --python 3.11 --with setuptools==84.0.0 -- python -X utf8 setup.py egg_info --egg-base <temp>` — passed; generated metadata no longer lists unsupported extras and retains current extras.
- `python -m py_compile setup.py` — passed.
- `git diff --check` — passed.
- No GPU tests are applicable; changes are limited to packaging metadata and installation documentation.
