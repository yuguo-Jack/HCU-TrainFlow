# [docker] fix: install a transformers version vllm 0.24.0 accepts in Dockerfile.stable.vllm

[Upstream PR](https://github.com/verl-project/verl/pull/8446) · state: closed · merged: False

## Original PR description

### What does this PR do?

`docker/Dockerfile.stable.vllm` installs `vllm==0.24.0` and later runs `pip install transformers==${TRANSFORMERS_VERSION}` with `TRANSFORMERS_VERSION=5.3.0`. That leaves the image with a transformers version below two lower bounds:

- `vllm==0.24.0` requires `transformers>=5.5.3` (PyPI metadata);
- verl's own `requirements.txt` requires `transformers>=5.5.3,!=5.6.0,<5.17`.

The pin dates from the vllm 0.20.2 image (#6393) and was not moved when vllm was bumped (#7101). This PR raises it to `5.5.3`, the lowest version that satisfies both.
