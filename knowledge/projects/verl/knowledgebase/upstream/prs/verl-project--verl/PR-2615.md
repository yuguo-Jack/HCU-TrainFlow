# [new recipe] Add Cosyvoice TTS GRPO training recipe based on veRL.

[Upstream PR](https://github.com/verl-project/verl/pull/2615) · state: open · merged: False

## Original PR description

This PR introduces a recipe using veRL to conduct RL training experiments on [cosyvoice2](https://github.com/FunAudioLLM/CosyVoice)![GitHub Repo stars](https://img.shields.io/github/stars/FunAudioLLM/CosyVoice) llm models.

Specifically, we conducted GRPO experiments and got below results:


| Model                                                 | Seed-TTS `test_zh` CER(%) ⬇️ | Cosyvoice3 `zero_shot_zh` CER (%)⬇️|Comment                                                                        |
|-|------------------------------------------------------|------------------------|--------------------------------------------------------------------------------|
| SFT (initialized from Qwen2-0.5B-Instruct)            | 1.81 %                 |4.83%| See [PR #1887](https://github.com/k2-fsa/icefall/pull/1887)                    |
| GRPO (this project, trained on AIShell-3)                | **1.06 %**             |4.03%|  See [here](https://github.com/nvidia-china-sae/mair-hub/tree/main/rl-tutorial/cosyvoice_llm)                    

Features:
1. Using  [Pytriton](https://github.com/triton-inference-server/pytriton) based [Sensevoice](https://github.com/FunAudioLLM/SenseVoice) ASR sever to achieve fast reward calculation.
2. Using phoneme error rate (PER) as the reward metrics.
3. Support both pretrained cosyvoice2 llm and custom sft version of cosyvoice2
