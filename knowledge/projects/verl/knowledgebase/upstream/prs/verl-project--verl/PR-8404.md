[Upstream PR](https://github.com/verl-project/verl/pull/8404) · state: closed · merged: True

## Original PR description

### What does this PR do?

This PR updates the Huawei Ascend 950 environment to Megatron-Core 0.18 and adds a Qwen3-30B-A3B MXFP8 GRPO training example.

Upgrade both Ascend 950 CANN 9.1.0 Dockerfiles from Megatron-Core 0.12 to 0.18 and update MindSpeed to core_r0.18.0.

Add MegatronAdaptor, TransformerEngineNPU, MindSpeed-Ops, MindSpeed-Bridge, and Megatron-Bridge v0.5.0 to the image installation steps.

Add a single-node, eight-NPU GRPO example with MXFP8 actor training and Ascend quantization for vLLM rollout.

Update the Chinese installation guide, Docker image dependency tables, and model and algorithm support documentation.
