# [worker]feat: Combine Reward Model score and Reward Function score

[Upstream PR](https://github.com/verl-project/verl/pull/2232) · state: open · merged: False

## Original PR description

### What does this PR do?

> Add **concise** overview of what this PR aims to achieve or accomplish. Reference related GitHub issues and PRs that help with the review.

Sometime we need to use both Reward Model and Reward Function in our algorithms.
I implemented a RewardManager that combines scores of the reward model and the reward function. Users can enable it by setting `reward_model.reward_manager=combine`. The score from the reward model will be passed to the reward function through the `rm_score` key in the `extra_info` and will participate in the weighted scoring of the reward function.
