## Original PR description

# Add Reward Model Training Support

This is essentially what we used to train OpenHands Critic described in this blog: https://www.all-hands.dev/blog/sota-on-swe-bench-verified-with-inference-time-scaling-and-critic-model

## Description
This PR adds support for training critics in VERL.

## Key Features
- Added FSDP-based reward model trainer (`fsdp_rm_trainer.py`)
- Implemented reward model dataset utilities for multi-turn dataset with intermediate reward / final reward
- Added configuration templates for reward model training
- Integrated with existing VERL infrastructure for distributed training
