# [ci, tests] fix: avoid writes to read-only Ascend model cache

[Upstream PR](https://github.com/verl-project/verl/pull/8343) · state: closed · merged: True

## Original PR description

### What does this PR do?

Set MEGATRON_CONFIG_LOCK_DIR to /root/.cache/temp/megatron-config-locks in the Ascend model workflow so config locks use a writable location.

Save generated critic models under pytest's tmp_path instead of ~/models/test_model, avoiding writes to the model cache and isolating artifacts between test cases.

Log CANN installation details and NPU status in the FSDP2 job to aid environment debugging.
