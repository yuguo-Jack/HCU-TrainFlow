**Use float32 for all three Omni RMSNorms.**

The Transformers implementations convert hidden states to float32 before computing the variance. `rms_norm_forward_npu` instead computes in `self.weight.dtype`. With fp16 or bf16 weights, this changes the normalized activations before attention and MLP execution. The same helper is bound to all three Omni norms.

**Honor each text MLP's configured activation.**

`Qwen3OmniMoeThinkerTextMLP` and `Qwen3OmniMoeTalkerTextMLP` both use `self.act_fn` from `config.hidden_act`. The patch replaces both forwards with `silu_forward_npu`, which always calls `torch_npu.npu_swiglu`.
