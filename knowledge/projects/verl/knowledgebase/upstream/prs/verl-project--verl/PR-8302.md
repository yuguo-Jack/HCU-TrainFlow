# [cfg] fix: honor actor.clip_ratio when asymmetric bounds are unset

[Upstream PR](https://github.com/verl-project/verl/pull/8302) · state: open · merged: False

## Original PR description

### What does this PR do?

Make `actor_rollout_ref.actor.clip_ratio` control the PPO clipping range when asymmetric bounds are unset. For example, setting only `clip_ratio=0.5` currently leaves both effective bounds at 0.2. Defaulting `clip_ratio_low` and `clip_ratio_high` to `None` enables the existing fallback to `clip_ratio`; explicitly configured asymmetric bounds keep their precedence.

The same defaults are updated in the distillation loss configuration, source YAML, and four generated reference configurations. The OPD parameter documentation also describes the optional bounds and their fallback to `clip_ratio`.

### API and Usage Example

```bash

```

This now selects a symmetric clip range of 0.5. Set `clip_ratio_low` and `clip_ratio_high` explicitly to select asymmetric clipping.

### Design & Code Changes

The policy losses already resolve each unset asymmetric bound through `clip_ratio`. The previous non-null defaults prevented that fallback. This patch changes configuration defaults and documents that behavior without changing the policy-loss formulas.
