# [fsdp] fix: Use blocking CPU offload copies on NPU

[Upstream PR](https://github.com/verl-project/verl/pull/8373) · state: closed · merged: False

## Original PR description

### What does this PR do?

Use blocking copies when offloading FSDP model shards from NPU to CPU to avoid exhausting the pinned host allocator across colocated workers. Preserve nonblocking copies on other devices.

AI assistance was used to prepare this metadata. Duplicate-work checks have not been run; nonduplication remains unverified.

### Test

Validation was not run. Added CPU-based parameterized tests for CUDA/NPU copy policy, optional cache clearing and call order, skipping handles with parameter offload enabled, preserving tensor values, and updating local shard references.

### API and Usage Example

No API changes. Existing calls to `offload_fsdp_model_to_cpu` select the copy policy by device type.

### Design & Code Changes

- Set `non_blocking=False` for NPU model offload and retain `True` for other devices.
- Add regression coverage in `tests/utils/test_fsdp_model_transfer_on_cpu.py`.
