# [megatron, training_utils] fix: account for padded tokens in dynamic batching for VLM

[Upstream PR](https://github.com/verl-project/verl/pull/8034) · state: closed · merged: False

## Original PR description

## Summary

Bound the dense input-token footprint of Megatron dynamic micro-batches, in addition to the existing effective-token budget. VLMs can materialize dense embeddings before packing, so `use_remove_padding=True` does not eliminate this peak.

For example, two sequences of 50,278 and 78,701 tokens plus 54 synthetic 128-token samples fit a 229,376-token effective budget, but a single dense batch contains 4,407,256 token positions. With this change and TP=2/CP=8 alignment, the reproducer produces three micro-batches with a maximum aligned dense footprint of 78,720 token positions.

## Changes

- Add optional per-sample `padded_seq_lens` to the existing micro-batch helpers. Require both the effective-token sum and `batch_size * max(padded_seq_lens)` to fit the existing budget.
- Supply TP/CP-aligned lengths for Megatron BSHD and VLM execution, including the existing mini-batch-wide BSHD padding target when configured.
- Reuse existing partitioning, forced-group checks, DP synchronization, and pipeline divisibility constraints. No new configuration option or batching algorithm is introduced.
- Extend the existing micro-batch tests with four regression cases covering skewed lengths, atomic groups, fixed padding width, oversized groups, sample preservation, and the unchanged default behavior.

Packed text-only execution, static batching, and dynamic CP scheduling are unchanged.

## Related work

Checked [open padding/budget PRs](https://github.com/verl-project/verl/pulls?q=is%3Apr+is%3Aopen+padded+budget). Related [PR #5338](https://github.com/verl-project/verl/pull/5338) proposes opt-in length-grouped batching for FSDP. This change instead enforces an additional constraint within the existing Megatron partitioner, including VLM remove-padding execution. No duplicate open Megatron fix was found during this check.
