# [ci] fix: ensure Ray cleanup after engine test failures

[Upstream PR](https://github.com/verl-project/verl/pull/7900) · state: open · merged: False

## Original PR description

### What does this PR do?

The previous ray.shutdown() only ran when the test reached its end. An exception skipped cleanup, leaving Ray initialized and workers alive, causing later tests to fail on repeated ray.init() or port conflicts. Register shutdown as a pytest finalizer so it runs even when tests fail.
