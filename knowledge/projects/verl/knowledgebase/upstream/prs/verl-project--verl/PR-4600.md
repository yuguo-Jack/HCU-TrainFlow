### What does this PR do?

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Using `self.max_prompt_length` (from `config.data.max_prompt_length`) for truncation could lead to `tensor size mismatch` errors during post-processing. The padding logic in `_agent_loop_postprocess` uses `self.prompt_length` (from `config.actor_rollout_ref.rollout.prompt_length`). If `self.max_prompt_length` is configured to be larger than `self.prompt_length`, the error this PR aims to fix will reappear.

To make this robust, we should truncate based on `self.prompt_length`. This also simplifies the `__init__` method, as `self.max_prompt_length` would no longer be needed and can be removed.

```suggestion
        if len(prompt_ids) > self.prompt_length:
            if self.truncation == "left":
                prompt_ids = prompt_ids[-self.prompt_length :]
            elif self.truncation == "right":
                prompt_ids = prompt_ids[: self.prompt_length]
            elif self.truncation == "middle":
                left_half = self.prompt_length // 2
                right_half = self.prompt_length - left_half
                prompt_ids = prompt_ids[:left_half] + prompt_ids[-right_half:]
            elif self.truncation == "error":
                raise RuntimeError(f"Prompt length {len(prompt_ids)} is longer than {self.prompt_length}.")
```
