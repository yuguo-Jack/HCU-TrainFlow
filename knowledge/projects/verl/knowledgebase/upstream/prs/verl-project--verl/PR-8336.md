# [ci] fix: unblock NPU unit tests

[Upstream PR](https://github.com/verl-project/verl/pull/8336) · state: closed · merged: True

## Original PR description

### What does this PR do?

Unblocks NPU CI while preserving GPU test behavior. MegatronAdaptor misinterprets pytest CLI flags and generates an invalid dataclass constructor; the NPU image has a newer ModelOpt version than GPU CI and exposes profiler enum rebinding.

### Checklist Before Starting

- [x] Searched for duplicates: [MegatronAdaptor](https://github.com/verl-project/verl/pulls?q=is%3Apr+is%3Aopen+MegatronAdaptor), [ModelOpt ignore](https://github.com/verl-project/verl/pulls?q=is%3Apr+is%3Aopen+modelopt+ignore). No other PR addressing these fixes was found.
- [x] Followed the PR title format.

### Test

Before the dependency-pin revision, all CI workflows passed on `d0fdbef2`, including [NPU](https://github.com/verl-project/verl/actions/runs/39780633016), [GPU](https://github.com/verl-project/verl/actions/runs/39780632986), and [CPU](https://github.com/verl-project/verl/actions/runs/39780632503).

- `python -m pytest -q tests/utils/test_torch_profile.py --tb=short`: **50 passed, 18 subtests passed**, both normally and with simulated NPU CUDA-enum rebinding.
- Original, unmodified ModelOpt tests with 0.44.0: **34 passed** in a local CPU harness using real quantization implementations; the same tests with 0.47.0 had 14 failures. The harness bypasses unrelated imports; full NPU CI of this revision is pending.
- Workflow YAML and all 11 shell blocks passed syntax checks.
- Launcher checks: 16 cases and eight spawn workers passed.
- AST comparison confirmed original non-NPU function bodies and existing decorators are preserved; only four `usefixtures` marks were added.
- `PYTHONPATH=. python /tmp/check_profiler_fixture_cleanup.py` (also with `--inject-failure`): real pytest setup/teardown checks confirmed only the four marked tests see the patch, and all four restore the prior NPU alias after success or deliberately injected assertion failures.
- `pre-commit run --files .github/workflows/npu_unit_tests.yml tests/utils/test_torch_profile.py --show-diff-on-failure` and `git diff --check`: passed.

### API and Usage Example

No public API or training behavior changes.

### Design & Code Changes

- Launch NPU pytest through `python -c` and `pytest.main([...])` to isolate arguments while preserving multiprocessing spawn.
- Pin `nvidia-modelopt==0.44.0` in NPU CI to match GPU CI. Restore the shared ModelOpt test file exactly to the base version; no ModelOpt test changes remain.
- Keep original profiler assertions and classes. One function-scoped fixture patches `ProfilerActivity.CUDA` only on NPU for four explicitly marked tests; its context manager restores the prior value after each test, including failures. Other tests and GPU execution are not patched. Use an explicitly unsupported device name for the NPU warning case.
