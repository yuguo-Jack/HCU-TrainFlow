# [sft_dataset] fix bugs and support filtering data

[Upstream PR](https://github.com/verl-project/verl/pull/321) · state: open · merged: False

## Original PR description

#### 1. Bug Fix
In the previous code, the `self.prompt_key` and `self.response_key` variables were of type `list`. This led to an issue where `self.dataframe[self.prompt_key]` and `self.dataframe[self.response_key]` returned objects of type `pandas.dataframe`. As a result, the `.tolist()` method could not be executed, causing errors in the relevant functionality.

To resolve this, I made the necessary adjustments to ensure that the data types are correctly handled. This allows the `.tolist()` method to be called successfully, thus fixing the bug and enabling the expected operations to be carried out smoothly.

#### 2. Feature Addition
In addition to the bug fix, I have implemented a new feature in the `SFTDataset._read_files_and_tokenize()` method. This new functionality filters out any data entries where the length is greater than the `max_length` parameter.
