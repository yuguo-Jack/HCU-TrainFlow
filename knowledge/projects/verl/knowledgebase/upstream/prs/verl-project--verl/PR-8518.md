# [rollout, vllm] feat: stream full weights through Ascend reload_weights

[Upstream PR](https://github.com/verl-project/verl/pull/8518) · state: open · merged: False

## Original PR description

### What does this PR do?

Feed one complete checkpoint-format iterator to the official `worker.reload_weights(weights_iterator=..., is_checkpoint_format=True)` API. Packed NPU IPC carries the weights; reload is the loading operation, not a third wire transport. The final ACK is sent only after the entire iterator has been consumed and final postprocessing succeeds. This branch also contains the preceding IPC and HCCL integration commits.

This is part 3 of a three-PR series. Depends on #8517 (and #8516). The branch targets upstream main and includes the preceding commits; review the incremental change [here](https://github.com/yeyunu/verl/compare/6168a527efae1f82ddb79478449ad76d93058bc2...cce30f059dd9b70ff7bef7d81ac6b8adf0ad9ae8). Rebase after the prerequisite merges before merging this PR.

### API and Usage Example

```bash
+actor_rollout_ref.rollout.custom.ascend_weight_update_mode=reload \
  +actor_rollout_ref.rollout.engine_kwargs.vllm.additional_config.weight_nz_mode=0
```

For reload, leave `weight_transfer_config.backend` unset or set it to `npu_ipc`. HCCL/NCCL and reload cannot be combined.

Use a compatible vLLM/vLLM-Ascend pair exposing the documented native APIs. This first version supports unquantized full weights; LoRA/QAT, a separately synchronized MTP drafter and delta payloads are rejected on the opt-in path. IPC/reload requires same-device colocation. HCCL additionally requires one node, replicated FSDP full-weight streams, at least two TP replicas, DP=PP=1 and no prefill/decode disaggregation. Native communication failures invalidate the adapter; restart workers before retrying. Default unconfigured paths retain their existing behavior.

### Design & Code Changes

- Add `custom.ascend_weight_update_mode: reload`, compatible with an unset backend or `npu_ipc`; reject conflicting backends before any transfer.
- Use the official packed consumer to feed reload with independently owned tensor storage. Keep one iterator and one finalization across all buckets.
- Validate reload capabilities and worker device identity during preflight. Reject early iterator termination and propagate source/loader errors.
- Add whole-stream, delayed-final-ACK, abort and preflight tests; extend the usage and validation documentation.

No Step5 model implementation, private checkpoint/data paths, training diagnostics, SGLang changes or NPU worker patches are included.
