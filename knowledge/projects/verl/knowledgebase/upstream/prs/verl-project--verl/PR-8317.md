# [docker] feat: DeepSeek-V4.1-Flash GB200 image for Megatron Lite + vLLM batch-invariant rollout

[Upstream PR](https://github.com/verl-project/verl/pull/8317) · state: open · merged: False

## Original PR description

### What does this PR do?

Adds a Dockerfile (plus README) for one GB200 image that runs DeepSeek-V4.1-Flash RL with bitwise train/inference logprobs: vLLM batch-invariant rollout ([vllm-project/vllm#62365](https://github.com/vllm-project/vllm/pull/62365) @ `da8922bf0f`), the Megatron Lite DeepSeek-V4.1 deployment-model actor ([ISEEKYAN/Megatron-LM#260](https://github.com/ISEEKYAN/Megatron-LM/pull/260), targeting ISEEKYAN/Megatron-LM#257), and verl. No verl source changes.

### Duplicate-work check

Searched open verl PRs for DeepSeek-V4.1 / Megatron Lite: only #7483 (LoRA for DeepSeek V4/V4.1 in vLLM), which is unrelated.

### Contents

- `docker/verl-dsv41-gb200/Dockerfile`: on top of a vLLM image built from #62365, installs Transformer Engine 2.20.2 (cu13 core wheel, torch extension built for sm100a), verl at the base commit and its runtime deps, Megatron Core/Lite runtime deps, fast-hadamard-transform and FlashMLA built against the image torch, and a `flash_attn.bert_padding` import shim re-exporting `verl.utils.npu_flash_attn_utils` (no flash-attn wheel exists for this torch; the shim has no dist-info, so transformers still treats flash-attn as absent). Every install is constrained to the base image's freeze; the final layer records any package that moved.
- `docker/verl-dsv41-gb200/README.md`: build commands, pinned versions, how to mount Megatron-LM, the launcher path and the validated recipe.

### Test

- The cluster this was validated on has no Docker, so **this Dockerfile has not been built as-is**. The same component set (same vLLM commit, TE 2.20.2, verl base commit, FlashMLA/cutlass/fast-hadamard-transform commits, shim) was assembled as an enroot image on GB200, with the same install steps.
- With that image: two-step RL through verl on 16 GB200 nodes (DeepSeek-V4.1 release, actor EP64 CP2, rollout DEP4 per node, DSpark, level-2 sleep): rollout vs actor logprobs 0 mismatching tokens at θ0/θ1/θ2 (3.6M / 4.0M / 3.8M valid tokens), `rollout_probs_diff_max` 0; checkpoint resume in a fresh Ray cluster bitwise; AIME 2024 mean@8 0.737 → 0.745. Details in ISEEKYAN/Megatron-LM#260.
