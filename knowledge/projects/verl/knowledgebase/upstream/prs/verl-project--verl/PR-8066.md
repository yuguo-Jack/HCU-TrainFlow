# [ci, hardware] fix: fix Ascend multinode GLM5.2 top-16-expert training CI

[Upstream PR](https://github.com/verl-project/verl/pull/8066) · state: closed · merged: True

## Original PR description

### What does this PR do?

Unset HCCL_OP_EXPANSION_MODE in the driver and Ray workers, and disable inter-node HCCS to use RoCE.

Increase worker memory requests and limits to 1536 GiB, update the default checkpoint path, and select CPU resources for SimpleStorage. Reduce the smoke run to 10 steps and move --config-name after the built-in Hydra overrides.
