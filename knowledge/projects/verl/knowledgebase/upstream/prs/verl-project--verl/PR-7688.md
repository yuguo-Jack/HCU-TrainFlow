[Upstream PR](https://github.com/verl-project/verl/pull/7688) · state: open · merged: False

## Original PR description


### What does this PR do?

DeepSeek-V4 true-on-policy GRPO/DAPO on verl + mLite + vLLM.

- **Composable actor, not a core patch:** built on Megatron Agent-Compose
  (mLite) under `experimental/lite/`. Model behavior is assembled through
  protocols and primitives instead of an invasive Megatron-core patch stack.
  The vLLM-aligned pieces can be reused by other models or swapped for a
  future SGLang path.
- **W8A8:** BF16 master weights, E4M3 block-FP8 deployment weights, dynamic
  FP8 activations. Actor and rollout share the same W8A8 path after reload.
- **Hopper and Blackwell:** validated on H100, GB200, and GB300.
- **Preview dependencies, later split/merge:**
  https://github.com/vllm-project/vllm/pull/54955,
  https://github.com/NVIDIA/Megatron-LM/pull/7050.
- **Exact 0-diff logprobs:** after update and reload,
  `training/rollout_probs_diff_* == 0` and `rollout_corr/k3_kl == 0` — not an
  epsilon threshold.
- **~10% perf overhead, still being optimized:** GB200 32-GPU, generate is
  nearly unchanged; the remaining gap is in the batch-invariant actor path.
