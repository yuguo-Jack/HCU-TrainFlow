# [model, fsdp, rollout, vllm] feat: Muse Spark NVFP4 GRPO with LoRA on FSDP2

[Upstream PR](https://github.com/verl-project/verl/pull/8257) · state: open · merged: False

## Original PR description

### What does this PR do?

Adds RL support for **Muse Spark 816B-A42B** (NVFP4 MoE) on the FSDP2 engine: GRPO with LoRA against a vLLM rollout that serves the NVFP4 checkpoint, rollout routing replay (R3), and adapter-only weight sync. verl has no Muse Spark model, so the PR adds a verl-native text model and an example, plus the generic changes the run needs. The trainer reads the same NVFP4 checkpoint as vLLM and dequantizes the routed experts to BF16 while loading its FSDP2 shards. Each commit can be reviewed on its own:

| # | Commit | Scope |
|---|---|---|
| 1 | `[fsdp] fix: bound the padded micro-batch size when use_remove_padding=False` | dynamic bsz without remove-padding |
| 2 | `[fsdp] feat: support R3 router replay` | FSDP engine, off by default |
| 3 | `[fsdp] feat: opt-in sharded FSDP2 init straight from safetensors` | `VERL_FSDP2_SHARDED_INIT=1` only |
| 4 | `[fsdp] feat: keep _keep_in_fp32_modules in fp32 FSDP units` | models declaring `_keep_in_fp32_modules` |
| 5 | `[fsdp, rollout] feat: stream model-native LoRA exports in adapter-only sync` | models defining `export_serving_lora` |
| 6 | `[rollout, vllm] fix: LoRA weight sync for checkpoint-quantized rollouts` | LoRA sync to vLLM |
| 7 | `[fsdp, model] feat: Muse Spark text model for FSDP2 LoRA RL` | `model_type == "muse_spark_text"` only |

**Dependency on vLLM.** The rollout needs a vLLM build that serves Muse Spark with LoRA on its fused attention
projection and routed experts. Those vLLM changes are being upstreamed separately.

### Test

- GPU: the example recipe on 4 nodes x 4 GB300, 150 steps from scratch. LoRA r32/α64 on attention, the MoE latent projections and the routed experts; GRPO with 32 prompts × 8 samples, lr 1e-5, 4096-token responses, R3. AIME-2024 mean@8 went from 0.56 to 0.85, and the train/rollout k3 KL stayed near 2×10⁻⁴.

![Muse Spark LoRA RL: AIME-2024 mean@8 and train/rollout k3 KL](https://github.com/andakai/verl/blob/8a16367eefcc92179eb99a9d8c476a9cad39fdb1/muse_spark_lora_rl_curves.png?raw=true)

### Usage

```bash
model_path=<Muse-Spark-Open-816B-A42B-NVFP4> bash examples/grpo_trainer/run_muse_spark_dapo_lora_fsdp.sh
```
