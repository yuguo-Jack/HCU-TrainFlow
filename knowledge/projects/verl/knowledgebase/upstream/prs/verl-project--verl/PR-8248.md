# [doc] fix: render display math in rollout_corr_math §3.2.2 derivation

[Upstream PR](https://github.com/verl-project/verl/pull/8248) · state: open · merged: False

## Original PR description

### What does this PR do?

Fixes the rendering of the "Formal derivation" in §3.2.2 *Policy Gradient Loss (with IS/RS Correction)* of [`docs/algo/rollout_corr_math.md`](https://verl.readthedocs.io/en/latest/algo/rollout_corr_math.html#policy-gradient-loss-with-is-rs-correction).

In steps 2–4, each `$$ … $$` block starts on the line right after the list item's text, with no blank line in between. MyST therefore parses it as inline double-dollar math within the paragraph, and the rendered page shows stray `$` signs around the equations (for example `$\( J(\theta) = … \)$`). This PR adds a blank line before each of the three blocks so they render as display math.
