# examples: add single-GPU 24GB GRPO + LoRA recipe (Qwen2.5-1.5B)

[Upstream PR](https://github.com/verl-project/verl/pull/8405) · state: open · merged: False

## Original PR description

## What

Add a single-GPU 24GB GRPO + LoRA example for Qwen2.5-Math-1.5B-Instruct.

Official GRPO recipes in `examples/grpo_trainer/` assume multi-GPU nodes (8x80G class).
Users with one 24 GB card (RTX 4090 / L4 / A10) hit OOM in rollout or actor update and have to
guess LoRA rank, vLLM memory fraction, and max response length. This PR pins a verified config.

## Changes

- `examples/grpo_trainer/run_qwen2_5_1p5b_lora_24g.sh`
- `examples/grpo_trainer/README.md`: add a "Single GPU (24 GB) + LoRA" section

## Config highlights

- Qwen2.5-Math-1.5B-Instruct, LoRA r=32 / alpha=32 / all-linear, FSDP
- vLLM colocate: `gpu_memory_utilization=0.45`, TP=1, `max_model_len=4096`
- `max_prompt_length=1024`, `max_response_length=3072`
- `train_batch_size=4`, `rollout.n=8`, `ppo_micro_batch_size_per_gpu=1`
- GRPO with KL loss (`kl_loss_coef=0.001`), `loss_agg_mode=token-mean`
- Explicit `use_shm=False`, `rollout.load_format=dummy`, `rollout.layered_summon=False`
  (the defaults OOM or stall on a single 24 GB card)

## Test

- Hardware: single RTX 4090 24 GB (AutoDL)
- Stack: torch 2.8.0+cu128, vllm 0.11.0, verl v0.8.0
- Command: `MODEL=... DATA=... bash examples/grpo_trainer/run_qwen2_5_1p5b_lora_24g.sh`
- Result: 20-step smoke passes (`step:0`/`step:1` in the logs, peak ~18 GB); also ran a
  600-step GRPO job with the same knobs (peak ~20 GB).

## Notes

This is intentionally an example/docs PR, not a core algorithm change. I tested it against
v0.8.0; happy to rebase/adjust names if `main` requires updated config keys.

**Do not let one epoch override `STEPS`.**

The trainer defines one epoch as `len(train_dataset) // train_batch_size`. With `train_batch_size=4` and the default `STEPS=300`, the dataset needs at least 1,200 rows to provide 300 steps in one epoch. A smaller `DATA` file can stop the run before the requested step count. Set an epoch limit that permits `STEPS`, or state the minimum dataset size required.
