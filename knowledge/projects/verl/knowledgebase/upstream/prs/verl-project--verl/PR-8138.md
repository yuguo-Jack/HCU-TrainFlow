# [doc, hardware, worker, trainer] feat: add GRPO support for TPU

[Upstream PR](https://github.com/verl-project/verl/pull/8138) · state: closed · merged: False

## Original PR description

### What does this PR do?

Adds a Qwen3-4B-Base GRPO launcher for 250 steps on 64 TPUs, with automatic Ray cluster startup through Kueue.

Complements [verl-hardware-plugin#38](https://github.com/verl-project/verl-hardware-plugin/pull/38) with FP32 trainer log-probabilities and TorchTitan configuration fixes.

### API and Usage Example

From the repository root:

```bash
cd examples/tpu/grpo/qwen3_4b_base_kueue_cluster_run
bash submit_qwen3_4b_base_250steps.sh
```

For a smoke test, append `--steps 2 --skip-validation`.

### Design & Code Changes

- Three launch scripts plus a README; runtime helpers are generated outside the repository.
- Creates a Kueue-managed JobSet that starts Ray and training.
- Uses FP32 TPU trainer log-probabilities and forwards TorchTitan seed, total steps, and checkpoint settings.
