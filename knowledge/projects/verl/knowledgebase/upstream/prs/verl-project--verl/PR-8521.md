**Apply the rollout override after multimodal test-specific settings.**

When `AGENT_LOOP_TOOL_AGENT_ROLLOUT_CONFIG` sets `n`, `multi_turn.max_parallel_calls`, `multi_turn.max_user_turns`, or `prompt_length`, the later multimodal assignments overwrite those values before manager initialization. This prevents the environment configuration from acting as the final override, unlike the analogous basic test.

Move the guarded merge from the fixture into each multimodal test immediately before `init_agent_loop_manager`.
