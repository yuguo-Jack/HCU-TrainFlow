<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/PyAV-Org/PyAV/releases">av's releases</a>.</em></p>
<blockquote>
<h2>v17.1.0</h2>
<h3>Breaking</h3>
<ul>
<li>Remove the undertested <code>av.option</code> and <code>av.descriptor</code> APIs, along with the related <code>Codec</code> and <code>Filter</code> descriptor accessors.</li>
</ul>
<h3>Features</h3>
<ul>
<li>Use FFmpeg 8.1.1 in the binary wheels by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a>.</li>
<li>Build Linux ARMv7 binary wheels by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a>.</li>
<li>Expose <code>AVCodecContext.global_quality</code> by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> in <a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2246">#2246</a>.</li>
<li>Expose <code>Stream.discard</code> so demuxing and seeking can skip unwanted streams by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2272">#2272</a>).</li>
<li>Add <code>Stream.set_display_matrix()</code> and <code>Stream.set_display_rotation()</code> to write the container display (rotation) matrix on output streams by <a href="https://github.com/hmaarrfk"><code>@​hmaarrfk</code></a> in <a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2287">#2287</a>.</li>
<li>Add <code>Container.video_codec_id</code> to force a specific video codec on a container by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2243">#2243</a>).</li>
</ul>
<h3>Fixes</h3>
<ul>
<li>Add <code>cython.final</code> to leaf classes, ensuring that they are not subclassed by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a>.</li>
<li>Warn that <code>CodecContext.decode()</code> is not memory safe in some cases.</li>
<li>Fix memory leaks in <code>FFmpegError</code>, <code>AudioLayout</code> channel layouts, and <code>Frame.opaque</code>, and break a reference cycle between <code>FilterLink</code> and <code>Graph</code> by <a href="https://github.com/lgeiger"><code>@​lgeiger</code></a>.</li>
<li>Reduce excessive logging lock contention by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2276">#2276</a>).</li>
<li>Fix a crash when accessing <code>Stream</code> from multiple threads under FFmpeg 8.1 by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2247">#2247</a>).</li>
<li>Fix a crash during <code>InputContainer</code> initialization by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2010">#2010</a>).</li>
<li>Fix <code>enumerate_input_devices</code> and <code>enumerate_output_devices</code> raising <code>AttributeError</code> by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> and <a href="https://github.com/kazuki"><code>@​kazuki</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2264">#2264</a>).</li>
<li>Map HTTP 429 to <code>HTTPTooManyRequestsError</code> instead of <code>UndefinedError</code> by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2267">#2267</a>).</li>
<li>Fix crash in <code>VideoFrame.to_ndarray()</code> and <code>to_image()</code> on bottom-up frames with a negative <code>line_size</code> by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2213">#2213</a>).</li>
<li>Make <code>Disposition</code> an <code>IntFlag</code> so <code>Stream.disposition</code> can be assigned without raising <code>TypeError</code> by <a href="https://github.com/HotariTobu"><code>@​HotariTobu</code></a>.</li>
<li>Assign parser-inferred <code>pts</code>, <code>dts</code>, and <code>duration</code> to packets from <code>CodecContext.parse()</code> by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/1919">#1919</a>).</li>
<li>Copy <code>time_base</code> in <code>add_stream_from_template()</code> by <a href="https://github.com/daveisfera"><code>@​daveisfera</code></a> in <a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2249">#2249</a>.</li>
<li>Fix the remux examples dropping keyframes that demux with no DTS, which produced audio-only output by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a> (<a href="https://redirect.github.com/PyAV-Org/PyAV/issues/1917">#1917</a>).</li>
<li>Fix subtitle UTF-8 handling by <a href="https://github.com/jbree"><code>@​jbree</code></a> in <a href="https://redirect.github.com/PyAV-Org/PyAV/issues/2271">#2271</a>.</li>
<li>Fix several incorrect <code>malloc</code> size calculations by <a href="https://github.com/WyattBlue"><code>@​WyattBlue</code></a>.</li>
</ul>
