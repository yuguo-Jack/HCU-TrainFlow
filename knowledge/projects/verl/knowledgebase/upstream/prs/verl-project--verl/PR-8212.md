# [trainer, cfg] feat: make old-log-prob entropy diagnostics optional

[Upstream PR](https://github.com/verl-project/verl/pull/8212) · state: closed · merged: False

## Original PR description

### What does this PR do?

Make the entropy computed during old-log-prob recomputation optional.

The PPO (`RayPPOTrainer`) and V1 trainers always request `calculate_entropy=True` when recomputing old log-probs, only to log `actor/entropy`. The actor update does not use this entropy; it requests its own according to `calculate_entropy` / `entropy_coeff`. Computing it adds an entropy pass over the full vocabulary to every recomputation (for example, the non-fused Megatron path clones the logits for it).

This PR adds `actor_rollout_ref.actor.calculate_old_log_prob_entropy`, which defaults to `true`, so behavior is unchanged by default. When it is `false`, both trainers skip entropy in this stage and omit `actor/entropy` from it. Actor-update entropy and entropy regularization are unaffected, and bypass mode still skips recomputation entirely. This PR does not measure memory or throughput savings.

### Test

Run from the repository root on CPU (Python 3.12, PyTorch 2.13):

```bash
PYTHONPATH=. python -m pytest tests/trainer/ppo/test_old_log_prob_entropy_on_cpu.py tests/trainer/ppo/v1/test_trainer_base_on_cpu.py -q
```

- With this PR: `28 passed`.
- The same test files against current `main`: `5 failed, 23 passed`.

The tests call the real trainer methods, NestedTensor/padding conversion, entropy aggregation and the log-prob debug metric. Worker and TransferQueue calls use doubles. Coverage includes the default, enabled and disabled settings, zero and non-zero entropy coefficients, unequal response lengths, internal masks, router replay and sum-pi-squared fields, and V1 bypass. They also check that the actor update still requests entropy according to its own config when this stage skips it. A full training loop has not been run.

### API and Usage Example

```bash
actor_rollout_ref.actor.calculate_old_log_prob_entropy=false
```

### Design & Code Changes

- `verl/trainer/config/actor/actor.yaml`, `verl/workers/config/actor.py` and the generated trainer configs: new field `calculate_old_log_prob_entropy: true`.
- `verl/trainer/ppo/ray_trainer.py` and `verl/trainer/ppo/v1/trainer_base.py`: pass the flag as `calculate_entropy`, and only fetch, store and aggregate entropy when it is set.
- `docs/examples/config.rst`: documents the option.
