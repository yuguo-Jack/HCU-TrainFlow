# [reward] fix: accept identical final boxed equations in prime_math

[Upstream PR](https://github.com/verl-project/verl/pull/8385) · state: closed · merged: False

## Original PR description

### What does this PR do?

Accept a final boxed equation that exactly matches the gold before answer-marker extraction truncates it after `=`. The shortcut applies only when the gold contains `=`; non-identical answers retain the existing extraction and grading path.

Also select the last occurrence across `\boxed` and `\fbox`, so an earlier correct box cannot override a later wrong answer.

Related to #8346; this addresses only the equation/extraction slice. Interval and numeric-tolerance problems remain open. #8347 is closed and is not a prerequisite. The issue author [welcomed this scope](https://github.com/verl-project/verl/issues/8346#issuecomment-6410710152) and offered separate Linux validation.

### API and Usage Example

No public API or configuration changes. For example, a response containing `\boxed{x - \sqrt{3}y + 2 = 0}` now receives credit when the gold is exactly `x - \sqrt{3}y + 2 = 0`.

Differently written but algebraically equivalent equations continue through the old graders. This change does not normalize units, variable names or function application.

### Design & Code Changes

The shortcut compares final-box content with the gold, apart from outer whitespace, before lossy answer-marker extraction.

The license checker also accepts `Copyright 2026 Individual Contributor:` for the regression file. It already accepts the 2025 personal form and 2026 company headers; this permits current-year personal attribution without using a company header or an incorrect year.
