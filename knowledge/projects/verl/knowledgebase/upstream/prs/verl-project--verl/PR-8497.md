# [rollout, vllm] fix: isolate Mooncake lookup RPC sockets per server

[Upstream PR](https://github.com/verl-project/verl/pull/8497) · state: open · merged: False

## Original PR description

### What does this PR do?

Fixes MooncakeStoreConnector lookup RPC socket collisions when multiple vLLM replicas run on the same host.

vLLM derives the lookup IPC path from `lookup_rpc_port`, hostname, and local DP rank. With the default `lookup_rpc_port=0`, separate replicas can reuse the same path when their local DP ranks overlap.

This change derives a stable per-job/per-server discriminator from the Ray job ID and actor name, and injects it as `lookup_rpc_port` unless the user explicitly configured one. Both dictionary/JSON configurations and hyphen/underscore argument spellings are supported.

### Test
- CPU tests: 37 passed.
- Same-node multi-replica Mooncake E2E:
  - 1 node × 8 A100 GPUs.
  - vLLM TP1 / DP4 / EP4, resulting in two rollout replicas on the same physical node.
  - `MooncakeStoreConnector`, `kv_role=kv_both`.
  - Completed one full training step with exit status 0.
  - `EADDRINUSE`: 0.
  - Mooncake initialization failures: 0.
  - Router errors/exceptions: 0.
  - Both vLLM server processes initialized and served generation successfully.
The DPEP coordinator emitted non-fatal out-of-order statistics warnings during shutdown/metrics collection. They did not affect generation or training completion.

### Design & Code Changes

- Generate a deterministic lookup RPC discriminator from the Ray job and server actor identities.
- Apply it only to MooncakeStoreConnector when no explicit value is provided.

**Cap the derived lookup port at five digits.**

vLLM builds the lookup socket path as `{VLLM_RPC_BASE_PATH}/lookup_rpc_port_{port}_host_{hostname}_dp_rank{dp_rank}`. With the default base `/tmp`, a 62-byte hostname, a 10-digit port, and a one-digit DP rank, the path is 108 bytes. The AF_UNIX `sun_path` limit is 107 bytes plus the terminating NUL, so the lookup socket bind can fail and the connector can fail to initialize. The previous default `0` produced a one-digit port that fits for any valid hostname. A port of at most five digits keeps the default path within the limit for hostnames up to 66 bytes.
