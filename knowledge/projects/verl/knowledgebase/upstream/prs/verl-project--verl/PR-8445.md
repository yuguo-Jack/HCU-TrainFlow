# [trainer] fix: correct the legacy trainer deprecation message

[Upstream PR](https://github.com/verl-project/verl/pull/8445) · state: closed · merged: False

## Original PR description

### What does this PR do?

Fixes the legacy trainer deprecation text in two places:

- `verl/trainer/main_ppo.py` logs "deprecated, and wil be removed in v0.9.0.Please set ...": a misspelling of "will", and a missing space between the two sentences.
- `RayPPOTrainer`'s `@deprecated` message has the same misspelling.

Both also promise removal in v0.9.0. `verl/version/version` on main is `0.10.0.dev` and the legacy trainer is still shipped, so the message now says "a future release" instead of a version that has already passed.
