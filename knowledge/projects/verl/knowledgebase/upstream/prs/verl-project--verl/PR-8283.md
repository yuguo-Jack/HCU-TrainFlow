# [rollout, fsdp, kernel] fix: apply the rollout's vocabulary mask to t…

[Upstream PR](https://github.com/verl-project/verl/pull/8283) · state: closed · merged: False

## Original PR description

…he actor and reference model

vLLM never samples some token ids (the out-of-tokenizer tail, plus the vision placeholders): it sets their logits to -inf before sampling. The actor and the reference model still compute probabilities over the full vocabulary, so the policy that is sampled from and the policy being trained differ. Nothing in training then keeps the actor's probability on those ids in check, and it can drift freely since they are never sampled and never penalized.

get_rollout_vocab_mask(rollout_name, tokenizer, processor), in workers/rollout/utils.py, is now the single definition of the masked ids; the vLLM server uses it instead of computing its own list. ActorRolloutRefWorker computes it once and passes it to both the actor and the reference engine via a new TrainingWorkerConfig.rollout_vocab_mask field. Other rollout backends (e.g. sglang) get None, since they do not mask anything today.

FSDPEngineWithLMHead sets the masked logits to -inf right after the temperature division, on both the eager and the fused-kernel path, mirroring what vLLM does. entropy_from_logits/entropy_from_logits_with_chunking now treat a -inf logit as contributing 0 (0 * log 0 = 0), avoiding NaN in both the value and the gradient. All ten model-specific fused forwards (dense_common/qwen2_vl/qwen3_vl/qwen3_5/glm4v, torch and Triton backends) take a banned_token_mask and pass it to the kernel: the torch fused kernel and the Triton kernel (linear_cross_entropy) both implement it, including correct behavior when an entire 1024-column tile is masked and for masked labels. The Liger, CANN, and VeOmni fused kernels raise NotImplementedError if a mask is requested; Megatron, TorchTitan, and Automodel log a warning that they still use the full vocabulary (today's behavior, unchanged).

Tested on CPU (new and updated unit tests, 139 passing) and on an H100 GPU: the masked Triton kernel against an eager reference for all three backward methods, flash-attn cross-entropy with -inf logits at vocab sizes 1000 and 151936, the torch fused path, and verl's own unmasked Triton correctness suite (unaffected by this change).
