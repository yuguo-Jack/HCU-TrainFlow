# [megatron] fix: align BSHD router replay with model token order

[Upstream PR](https://github.com/verl-project/verl/pull/8208) · state: closed · merged: False

## Original PR description

### What does this PR do?

Fix router replay for the V1 Megatron engine when `use_remove_padding=False` (BSHD layout).

Router replay currently packs routes and the R3 replay mask with the THD helpers: samples are concatenated without per-sample padding. A BSHD forward instead pads every sample to the micro-batch length (TP/CP/FP8 alignment and `forced_max_seqlen`), and after the sequence-parallel scatter the routers see tokens in sequence-major `[S, B]` order. For micro-batches with more than one sample, R2 records are therefore restored to the wrong positions, and R3 replay applies routes to the wrong tokens.

This PR builds the route and mask tensors with `preprocess_bshd_engine` using the model's padding target, flattens them sequence-major before the scatter, and reverses that order when restoring R2 records. The default THD layout, dynamic CP, contiguous CP and the legacy dense packed path are unchanged. Stored routes stay `int16`, and collectives keep using the existing bit-identical `uint8` view. BSHD aux/z-loss restrictions and dynamic-CP support are out of scope.

### API and Usage Example

No API change. BSHD router replay is enabled with the existing settings plus `actor_rollout_ref.actor.megatron.use_remove_padding=False`. The layout notes are added to `examples/router_replay/README.md`.

### Design & Code Changes

- `verl/utils/megatron/router_replay_utils.py`: `merge_router_topk_indices()` and `set_router_replay_data()` take keyword-only `data_format` and `forced_max_seqlen` arguments. The BSHD branch uses `preprocess_bshd_engine` / `postprocess_bshd_engine` plus a sequence-major flatten/unflatten pair. The THD branch is unchanged.
- `verl/workers/engine/megatron/transformer_impl.py`: computes `data_format` before router replay and passes it, together with `forced_max_seqlen`, to both calls.
- `examples/router_replay/README.md`: documents the BSHD layout and test scope.
