# [vllm] fix: patch MoE weight loaders for DeepSeek MTP

[Upstream PR](https://github.com/verl-project/verl/pull/8059) · state: closed · merged: True

## Original PR description

### What does this PR do?

The MoE weight-loader workaround skips DeepSeekMTP because it is not registered as a supported model. Its predictor also stores layers in a ModuleDict and nests each decoder under mtp_block, so the existing traversal cannot reach its expert parameters.

Register DeepSeekMTP, iterate ModuleDict values, and unwrap mtp_block for explicitly supported MTP classes. It enables the existing workaround attach expert weight loaders to the drafter's fused MoE parameters during weight synchronization.
