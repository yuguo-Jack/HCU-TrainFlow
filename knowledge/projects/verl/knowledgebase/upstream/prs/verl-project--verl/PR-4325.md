# [WIP][FSDP,Training] feat: Support FSDP2 FP8 training

[Upstream PR](https://github.com/verl-project/verl/pull/4325) · state: open · merged: False

## Original PR description

### What does this PR do?

This PR enables FP8 training support using FSDP2 (integrated with `torchao`) on the latest codebase.

This work is based on the previous attempt in PR <https://github.com/volcengine/verl/pull/1490> by @ [horsebridge](https://github.com/horsebridge). Since the architecture of `verl` has evolved significantly, the original PR had conflicts with the current `main` branch. This PR ports the implementation to align with the latest architecture and re-enables the FP8 capability.
