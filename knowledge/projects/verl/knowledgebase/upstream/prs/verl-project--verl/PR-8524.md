# [megatron] feat: configurable timeout for Megatron process groups

[Upstream PR](https://github.com/verl-project/verl/pull/8524) · state: open · merged: False

## Original PR description

### What does this PR do?

Adds `megatron.distributed_timeout_minutes` to `McoreEngineConfig` and passes it to `mpu.initialize_model_parallel`. Megatron-Core's process groups (NCCL and gloo) currently always get its default of 30 minutes. On large models, the first collective after a slow checkpoint load from a shared file system can exceed that and kill the job. The default `null` keeps the current behavior. The ref model follows the actor's value, since whichever engine initializes the process groups first sets their timeout.

Separately: `actor_rollout_ref.nccl_timeout` and `critic.nccl_timeout` (600 s) appear to be unused now. v0.6.0 passed them to `init_process_group`, but `engine_workers.py` calls `initialize_global_process_group_ray(timeout_second=None)`. This PR leaves them alone. Wiring them back up could be a follow-up; note that it would also shorten the default gloo timeout from 30 to 10 minutes.

### Test

Added to `tests/workers/config/test_engine_config_on_cpu.py`:
- default is `None` and 90 is accepted;
- 0, -1, `True` and 1.5 are rejected;
- `MegatronEngine._init_device_mesh` passes `distributed_timeout_minutes=90` to `initialize_model_parallel` and omits it when unset (with `mpu` monkeypatched, so it runs on CPU).

`pytest tests/workers/config/test_engine_config_on_cpu.py`: 18 passed; 7 of them fail on `main`.

### API and Usage Example

```bash
actor_rollout_ref.actor.megatron.distributed_timeout_minutes=90
critic.megatron.distributed_timeout_minutes=90
```

### Design & Code Changes

- `verl/workers/config/engine.py`: new `McoreEngineConfig.distributed_timeout_minutes: Optional[int] = None`, validated in `__post_init__`.
- `verl/workers/engine/megatron/transformer_impl.py`: forwarded to `initialize_model_parallel` only when set.
- `verl/trainer/config/engine/megatron.yaml`, `verl/trainer/config/ref/megatron_ref.yaml`: new key (ref interpolates the actor's); `_generated_ppo_megatron_trainer.yaml` regenerated.
