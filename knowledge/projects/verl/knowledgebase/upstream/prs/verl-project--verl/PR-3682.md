# [data] fix: Remove duplicated bos tokens in `RLHFDataset`

[Upstream PR](https://github.com/verl-project/verl/pull/3682) · state: open · merged: False

## Original PR description

### What does this PR do?

Currently, `RLHFDataset` first retrieves the raw prompt as a string here:

https://github.com/volcengine/verl/blob/327e813136c117a564f99995f6000dc685b19351/verl/utils/dataset/rl_dataset.py#L235-L237

https://github.com/volcengine/verl/blob/327e813136c117a564f99995f6000dc685b19351/verl/utils/dataset/rl_dataset.py#L283-L285

and later obtains `input_ids` by invoking the processor again here:

https://github.com/volcengine/verl/blob/327e813136c117a564f99995f6000dc685b19351/verl/utils/dataset/rl_dataset.py#L258-L261

https://github.com/volcengine/verl/blob/327e813136c117a564f99995f6000dc685b19351/verl/utils/dataset/rl_dataset.py#L286-L288

However, both of these operations prepend a BOS token, resulting in duplication.

This PR fixes the issue by removing the leading BOS token from the input of the second invocation.

<br/>


> [!NOTE]
> We should not remove the bos token from the raw prompt itself, since it is used later here:
> https://github.com/volcengine/verl/blob/327e813136c117a564f99995f6000dc685b19351/verl/utils/dataset/rl_dataset.py#L335

## Code Review

This pull request aims to fix an issue with duplicated beginning-of-sequence (BOS) tokens in the `RLHFDataset`. The change correctly removes the prefix BOS token before tokenization. However, the implementation is not robust against tokenizers that do not have a `bos_token` defined, which could lead to a runtime error. My review includes a critical fix to prevent this potential crash.

![critical](https://www.gstatic.com/codereviewagent/critical.svg)

The `self.tokenizer.bos_token` can be `None` for some tokenizers. In such cases, `raw_prompt.removeprefix(self.tokenizer.bos_token)` will raise a `TypeError`, causing the data loading to crash. To make this more robust, you should handle the case where `bos_token` is `None`.

```suggestion
                text=[raw_prompt.removeprefix(self.tokenizer.bos_token or "")],
```
