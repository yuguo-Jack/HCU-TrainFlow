# [trainer] fix: preserve session grouping for vectorized GRPO

[Upstream PR](https://github.com/verl-project/verl/pull/8100) · state: open · merged: False

## Original PR description

### What does this PR do?

Fix session grouping for `grpo_vectorized` in the V1 trainer. It currently skips the session-aware path, so rewards copied to intermediate outputs are counted repeatedly in the group mean and standard deviation.

Use each session's final output to compute advantages, then broadcast them to its other outputs, as `grpo` already does.

### Test

The regression runs the actual reward-copying postprocessor, with storage writes mocked. Three sessions with rewards `[1, 4, 5]` produce `[1, 4, 5, 5, 5, 5]` in storage. The reward-4 session gets advantage `-0.104031` before the fix and `+0.320256` afterward.

### API and Usage Example

No API or configuration changes. Applies to V1 multi-output sessions using `algorithm.adv_estimator=grpo_vectorized`.

- Add a regression test using the real reward-copying and serialization code.
