# [trtllm] fix: sleep mode ignores gpu_memory_utilization causing OOM

[Upstream PR](https://github.com/verl-project/verl/pull/5800) · state: open · merged: False

## Original PR description

Two issues in TRTLLMHttpServer._create_llm():

1. engine_kwargs containing kv_cache_config (e.g. {"dtype": "fp8"}) would overwrite the KvCacheConfig object via **engine_kwargs unpacking, losing free_gpu_memory_fraction. Fix: pop kv_cache_config from engine_kwargs and merge into KvCacheConfig constructor.

2. per_worker_gpu_share was always 1.0/max_colocate_count regardless of sleep mode. When sleep mode is enabled, TRT-LLM should only claim gpu_memory_utilization fraction of GPU memory so training can use the rest. Fix: use gpu_memory_utilization/max_colocate_count when sleep mode is enabled.

Tested with Qwen3-30B-A3B DAPO training (TP=2/EP=2, FP8 KV cache, enable_sleep_mode=true, gpu_memory_utilization=0.85) — previously OOM'd at step 16, now runs 32+ steps with no OOM.

There's a potential inconsistency here. If `engine_kwargs` contains an override for `free_gpu_memory_fraction` inside `kv_cache_config`, the `KvCacheConfig` object will correctly use it. However, the calculation for `per_worker_gpu_share` will still use the original `self.config.gpu_memory_utilization`. This can lead to inconsistent memory settings for the worker, potentially causing resource contention if the two values differ significantly.

To ensure consistency, we should determine the effective `gpu_memory_utilization` (respecting overrides) and use it for both `KvCacheConfig` and `per_worker_gpu_share`.

```python
        kv_cache_overrides = engine_kwargs.pop("kv_cache_config", {})

        # Build the full KvCacheConfig arguments, allowing overrides
        kv_cache_args = {
            "enable_block_reuse": self.config.enable_prefix_caching,
            "free_gpu_memory_fraction": self.config.gpu_memory_utilization,
        }
        kv_cache_args.update(kv_cache_overrides)

        kv_cache_config = KvCacheConfig(**kv_cache_args)

        if self.config.enable_sleep_mode:
            # Use the effective GPU memory utilization, including overrides, for consistency.
            per_worker_gpu_share = kv_cache_args["free_gpu_memory_fraction"] / self.max_colocate_count
        else:
            per_worker_gpu_share = 1.0 / self.max_colocate_count
```
