# [veomni] fix: Update the prepare_model_inputs method of VeOmniEngine to align with the latest modifications of VeOmni

[Upstream PR](https://github.com/verl-project/verl/pull/5598) · state: closed · merged: False

## Original PR description

### What does this PR do?

This PR aligns with the latest release (v0.1.7) of veomni and introduces lightweight optimizations to the veomni backend implementation:
1. Auto-replacement of `attn_implementation`:
   Referencing [veomni](https://github.com/ByteDance-Seed/VeOmni/blob/a18e9944d568f9007bf9647b6f7b528990e124dc/veomni/arguments/arguments_types.py#L566), the PR adds support for automatic replacement of `attn_implementation` when `sp>1`.

2. Optimization of `prepare_model_inputs` in VeOmniEngine:
   - Following [veomni](https://github.com/ByteDance-Seed/VeOmni/blob/a18e9944d568f9007bf9647b6f7b528990e124dc/veomni/data/data_collator.py#L339), the `prepare_model_inputs` method is optimized to support precomputation of `fa_kwargs`.
   - The calculation logic for `image_mask` and `video_mask` in VLM is optimized, enabling placeholder tokens to be retrieved directly from the model config.

This pull request updates the `VeOmniEngine` to align with recent changes in the VeOmni library. The main changes include refactoring the sequence parallelism data collator into standalone functions, and rewriting the `prepare_model_inputs` method to correctly handle VLM inputs and precompute flash attention arguments. A potential issue with accessing special token IDs for vision models has been identified, which could cause an `AttributeError` for some models.

The code directly accesses `self.module.config.image_token_id` and `self.module.config.video_token_id`. However, some HuggingFace VLM configurations (e.g., Qwen2-VL) use `image_token_index` and `video_token_index` instead. This will cause an `AttributeError` for those models. To improve compatibility, consider using `getattr` to handle both naming conventions.

```python
image_token_id = getattr(self.module.config, 'image_token_id', self.module.config.image_token_index)
video_token_id = getattr(self.module.config, 'video_token_id', self.module.config.video_token_index)
image_mask = model_inputs["input_ids"] == image_token_id
video_mask = model_inputs["input_ids"] == video_token_id
```
