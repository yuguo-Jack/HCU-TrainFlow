## Original PR description

### What does this PR do?

Add CPU contracts that follow Hermes and Kimi tool calls through the real parser, assistant-message construction, tool dispatch and reply assembly. Ten fixtures run through native tools and FunctionTool, checking IDs, invalid JSON, enabled/unknown tools, parallel limits, zero reward and reverse completion order.
