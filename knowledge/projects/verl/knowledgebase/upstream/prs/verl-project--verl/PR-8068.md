# Fix hydra argument-order and invalid config key breaking Ascend multinode GLM5.2 nightly CI

[Upstream PR](https://github.com/verl-project/verl/pull/8068) · state: open · merged: False

## Original PR description

The "E2E Ascend RayJob multinode GRPO GLM5.2 Top16 Megatron" nightly job was failing before the training script even reached the RayJob worker setup, due to two bugs in the launch invocation.

### Argument ordering (`unrecognized arguments`)
`--config-name` was appended via the `EXTRA` array *after* all the `key=value` hydra overrides (`DATA`, `MODEL`, `ACTOR`, `ROLLOUT`, `REF`, `TRAINER`). Hydra's argparse greedily consumes overrides as a single positional block; anything following an optional flag like `--config-name` is treated as unrecognized:
```
main_ppo.py: error: unrecognized arguments: ++ray_kwargs.ray_init.runtime_env.env_vars.VERL_VLLM_ASCEND_GLM52_PATCH='1' actor_rollout_ref.nccl_timeout=7200
```
Moved `--config-name='ppo_megatron_trainer'` to be the first argument passed to `main_ppo`, matching the convention already used in `examples/ascend_extras/grpo_trainer/run_glm5_2_megatron.sh`.

### Invalid config override
Fixing the ordering surfaced a second, previously-masked failure:
```
Could not override 'actor_rollout_ref.actor.megatron.vanilla_mbridge'.
Key 'vanilla_mbridge' is not in struct
```
`vanilla_mbridge` does not exist anywhere in the config schema (only `use_mbridge` is a real field on `McoreEngineConfig`). Removed the stray `actor_rollout_ref.actor.megatron.vanilla_mbridge=False` override.

### Change
File: `tests/special_npu/nightly_ci_ascend/run_grpo_glm52_top16_megatron_npu_multinode.sh`
```diff
 ACTOR=(
     ...
     actor_rollout_ref.actor.megatron.use_mbridge=True
-    actor_rollout_ref.actor.megatron.vanilla_mbridge=False
     actor_rollout_ref.actor.megatron.pad_bshd_to_minibatch_max=False
     ...
 )

 EXTRA=(
-    --config-name='ppo_megatron_trainer'
     "++ray_kwargs.ray_init.runtime_env.env_vars.VERL_VLLM_ASCEND_GLM52_PATCH='1'"
     actor_rollout_ref.nccl_timeout=7200
 )

 python3 -m verl.trainer.main_ppo \
+    --config-name='ppo_megatron_trainer' \
     "${DATA[@]}" ...
```
