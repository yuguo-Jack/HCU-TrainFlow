<h2>Patch release v5.20.2</h2>
<h1>Patch release: v5.20.2</h1>
<p>This patch notably solves an issue where some inputs could loose their original type inside <code>prepare_inputs_for_generation</code> in <code>generate</code>, leading to problems with multimodal models. It also fixes some other issues listed on the below commits.</p>
<p>It contains the following commits:</p>
<ul>

<li>Fix zero expert gradients in bfloat16 with expert parallelism and ep_size &lt; fsdp_size (<a href="https://redirect.github.com/huggingface/transformers/issues/49688">#49688</a>) by <a href="https://github.com/qgallouedec"><code>@​qgallouedec</code></a></li>
<li>Declare the input modalities of the VLMs that report text only (<a href="https://redirect.github.com/huggingface/transformers/issues/49677">#49677</a>) by <a href="https://github.com/qgallouedec"><code>@​qgallouedec</code></a></li>
<li>Avoid a host-to-device copy in eager_mask (<a href="https://redirect.github.com/huggingface/transformers/issues/49684">#49684</a>) by <a href="https://github.com/hmellor"><code>@​hmellor</code></a></li>

<p>Muse Spark Open is a multimodal mixture-of-experts model from Meta that takes text, images, audio, and video as input and generates text.
