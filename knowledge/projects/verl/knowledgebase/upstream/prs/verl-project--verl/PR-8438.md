# [megatron] refactor: modernize Megatron integration - centralize compatibility [1/5]

[Upstream PR](https://github.com/verl-project/verl/pull/8438) · state: open · merged: False

## Original PR description

### What does this PR do?

Roadmap item 1 of [RFC #8324](https://github.com/verl-project/verl/issues/8324), split from [integration preview #25](https://github.com/ISEEKYAN/verl/pull/25). Centralize bootstrap, engine, construction, per-model MTP and forward compatibility selection in `compat.py`. Each temporary feature records its reason, upstream links and retirement condition. Use per-process/per-model idempotence, retry failed installs, and avoid retaining discarded models.

### Checklist Before Starting

- [x] Searched existing work: [patch PR search](https://github.com/verl-project/verl/pulls?q=is%3Apr+is%3Aopen+megatron+patch), [RFC-linked PRs](https://github.com/verl-project/verl/pulls?q=is%3Apr+is%3Aopen+8324+in%3Abody).
- [x] Title follows the project format.

This consolidates installation boundaries; it does not duplicate #8338's recompute storage fix, #8031's MTP gradient fix, or #8029's parameter readiness fix. Existing replacement implementations remain until their feature slices are reviewed. In particular Core #8673 covers detach only and #8674 covers masked replay; neither alone retires the entire legacy adapter.

### Test

Slurm CPU, Torch 2.13.0+cpu / Core 0.21.0 / Transformers 5.16.1: **18 passed** using `python -m pytest --noconftest --import-mode=importlib -q tests/utils/megatron/test_compat_on_cpu.py tests/utils/test_megatron_mtp_dcp.py tests/utils/test_megatron_router_replay_dcp.py`. Covers native no-op/callable identity, install-once, failure/retry, per-model ownership/GC, later detach enablement, zero-MTP references, bootstrap and forward delegation, plus existing DCP/replay behavior. All-files pre-commit passes. CUDA/NPU/ROCm execution is not claimed.

### API and Usage Example

Engine/model setup uses `apply_engine_patches`, `apply_model_patches`, `apply_construction_patches` and `configure_forward`. Existing `patch_engine_mtp` delegates to the same boundary. Native/affected-version checks run before installers; semantic fixes without a validated retirement boundary remain explicit legacy entries.

### Design & Code Changes

Bootstrap precedes registry imports. Version guards skip obsolete writer/MLA imports on new Core. Optional-extension implementations keep their dependency probes. MTP/replay consumers are intentionally migrated in later roadmap items; merging an upstream PR does not change an installed package or a still-legacy consumer. The only global state tracks installation checks; model ownership uses weak references.
