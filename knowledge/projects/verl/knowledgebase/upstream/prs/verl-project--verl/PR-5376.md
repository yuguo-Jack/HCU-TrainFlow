# [tool] refactor: centralized tool registry and decorator-based registration

[Upstream PR](https://github.com/verl-project/verl/pull/5376) · state: open · merged: False

## Original PR description

### What does this PR do?

Refactors the tool registration system to use a centralized, decorator-based 
`ToolRegistry`, aligning with the existing AgentLoop pattern. Introduces `@register_tool("name")` decorator. Maintains full backward compatibility for `class_name` lookups. Directly addresses Q1 Roadmap item in [#4880.](https://github.com/verl-project/verl/issues/4880)

### Test

Added tests covering registry CRUD, built-in auto-registration, and config-based initialization.

### API and Usage Example

```python
@register_tool("myself")
class MyTool(BaseTool): ...

# config.yaml
tools:
  - tool_name: "myself"  # New registry lookup
    config: {type: native}
```

### Design & Code Changes

New: verl/tools/registry.py for the core registry logic.
Update: verl/tools/utils/tool_registry.py to support `tool_name` resolution.
Update: Applied `@register_tool` to all 7 built-in tool modules.
Refactor: `BaseTool` now uses logging instead of print.

The current implementation of `_ensure_builtin_tools_imported` uses a global flag `_builtin_tools_imported` which is not thread-safe. If `initialize_tools_from_config` is called from multiple threads concurrently for the first time, it could lead to a race condition where modules are imported multiple times. A cleaner and thread-safe approach is to use `functools.lru_cache` to ensure the import logic runs only once.

```suggestion
import functools


@functools.lru_cache(maxsize=None)
def _ensure_builtin_tools_imported():
    """Import built-in tool modules once so their ``@register_tool`` decorators fire."""
    _builtin_modules = [
        "verl.tools.gsm8k_tool",
        "verl.tools.geo3k_tool",
        "verl.tools.search_tool",
        "verl.tools.sandbox_fusion_tools",
        "verl.tools.image_zoom_in_tool",
        "verl.tools.mcp_base_tool",
        "verl.tools.mcp_search_tool",
    ]
    for mod_name in _builtin_modules:
        try:
            importlib.import_module(mod_name)
        except ImportError:
            logger.debug(f"Optional tool module {mod_name} not available, skipping.")
```
