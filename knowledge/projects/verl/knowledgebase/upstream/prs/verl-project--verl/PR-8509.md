# [trainer] fix: conditionally fetch token-level rewards

[Upstream PR](https://github.com/verl-project/verl/pull/8509) · state: open · merged: False

## Original PR description

### What does this PR do?

Fix PPO metrics collection when algorithm.use_kl_in_reward=false by only fetching token_level_rewards when they are produced. This preserves the original data-writing behavior and prevents missing-field errors without affecting KL-in-reward workflows.
