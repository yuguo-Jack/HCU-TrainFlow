### What does this PR do?

TPPO (Truncated PPO): An algorithm optimization for on-policy partial rollout on PPO. TPPO truncates long rollouts same as partial rollout, yet uses Extended GAE when calculating advantages. See https://arxiv.org/abs/2506.15050 for more details.
This PR applies TPPO on veRL from SEED implementation.
