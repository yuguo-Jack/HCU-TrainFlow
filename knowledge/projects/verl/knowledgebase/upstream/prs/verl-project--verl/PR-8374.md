# [fsdp] fix: Use blocking NPU copies when offloading model and optimizer state

[Upstream PR](https://github.com/verl-project/verl/pull/8374) · state: closed · merged: False

## Original PR description

### What does this PR do?

Use blocking NPU-to-CPU transfers for FSDP model shards and optimizer tensors to avoid exhausting the driver's pinned host-memory pool. Preserve nonblocking transfers for other devices.

AI assistance was used to prepare this metadata. Duplicate-work verification remains pending; no claim of uniqueness is made.

### Test

Validation was not run. Added CPU-based regression tests cover NPU and CUDA copy policies, shard storage aliases, native offload handle skipping, optional cache clearing, optimizer tensor replacement, metadata preservation, and empty optimizer state.

### API and Usage Example

No API changes. Existing offload calls automatically select the copy policy for the current device.

### Design & Code Changes

- Set `non_blocking=False` on NPU in both model and optimizer offload helpers.
- Add `tests/utils/test_fsdp_model_transfer_on_cpu.py` with mocked device transfers.
