# fix(reward): accept dict-shaped scores in PrimeRewardManager

[Upstream PR](https://github.com/verl-project/verl/pull/8262) · state: open · merged: False

## Original PR description

## Problem

`PrimeRewardManager` crashes the result-processing loop of `parallel_compute_score_async` with `KeyError: 0` whenever the reward function returns a dict such as `{"score": 1.0, "acc": true, "pred": "42"}` — exactly what `math_dapo.compute_score`, `rlla.compute_score` and several custom reward functions return. The exception is swallowed by `PrimeRewardManager.verify`, so the entire batch is silently scored 0.0 and the RL reward signal is destroyed.

## Fix

Handle dict-shaped results in the result-processing loop by extracting `result["score"]`, matching the existing behavior of `NaiveRewardManager`, `BatchRewardManager` and `DAPORewardManager`.

## Test

Added `tests/workers/reward_manager/test_prime_on_cpu.py` covering both dict and float score paths.

Fixes #8216
