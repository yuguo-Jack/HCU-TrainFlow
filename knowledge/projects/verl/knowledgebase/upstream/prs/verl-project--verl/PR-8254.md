# [hardware, doc] fix: TPU GRPO README missing setup commands and measured timings

[Upstream PR](https://github.com/verl-project/verl/pull/8254) · state: open · merged: False

## Original PR description

Following examples/tpu/grpo/README.md on a fresh project (verl f724e7f2, verl-hardware-plugin e5ab532, 2 x v6e-4 spot): the Artifact Registry repository and the GCS bucket are never created, and the bucket's region is not mentioned. With the bucket in another region the Qwen3-4B run did not reach a step in 80 minutes (the weights are read through the FUSE mount at ~18 MB/s); with a bucket in the cluster's region it starts in about 15 minutes.

This adds the three commands and the region note, and replaces the timings with measured ones: smoke test ~30 min end to end, 4B ~26 s/step average over 100 steps (GSM8K 0.41 -> 0.96).

Documentation only; no code changes.
