Using the `--remote` flag with `git submodule update` forces Git to fetch the latest commits from the remote tracking branches of the submodules instead of checking out the specific commits pinned in the `release/v0.8.0` branch. This makes the Docker build non-reproducible and can introduce breaking changes from untested upstream commits. Please remove the `--remote` flag.

```
    git submodule update --init --recursive && \
