### What does this PR do?
Set HF_DATASETS_CACHE to /root/.cache/temp/hf-datasets across Ascend test workflows. Also redirect Megatron config locks to /root/.cache/temp/megatron-config-locks for SFT, separate async, and nightly workflows.

Keep generated caches and lock files off read-only dataset and model mounts.
