# tentative approach to sync ref model

[Upstream PR](https://github.com/verl-project/verl/pull/794) · state: open · merged: False

## Original PR description

Try to address issue https://github.com/volcengine/verl/issues/779. That is implementing periodic synchronization between the reference model and the actor.

We've observed that the reference model and actor with the same rank exist in the same process, despite belonging to different worker groups. Here's our proposed solution:

1. Have the driver collect actor model IDs/addresses from the actor worker group
2. Pass this information to the reference worker group
3. Reference workers restore actors from the corresponding IDs
