# [algo, worker] refactor: async reward computation for 20% verl training speedup

[Upstream PR](https://github.com/verl-project/verl/pull/3548) · state: open · merged: False

## Original PR description

## What and Why

Refactor reward computation to support **asynchronous reward scoring**, especially for QA/Kefu scenarios where rewards are not directly available.

Previously, reward calculation was blocking and slow — now we decouple it via background threads, achieving **~20% end-to-end training speedup** in ReVR workloads.

## Changes

- Add `verl/workers/reward_manager/kefu_mthread.py`: async reward scorer using multithreading
- Support `reward_model.reward_manager=intelligent_kefu_async` in config/script
- Non-breaking: sync mode remains default; async is opt-in
- Minor refactor of reward pipeline for cleaner async integration

## Test

- Tested on internal QA dataset (10k samples)
- Training throughput ↑ 20%
- No accuracy drop observed

## Usage

In bash script or config:

```bash
--reward_model.reward_manager=intelligent_kefu_async
```

or in YAML:
```bash
reward_model:
  reward_manager: intelligent_kefu_async
```

The function is type-hinted to return a `bool`, but it returns `0` or `1`. This is inconsistent with the type hint and can lead to unexpected behavior. The function should return `True` or `False` to match its signature.

```python
def validate_hybird_format(response: str, prompt: str) -> bool:
    """
    Validate the usage of <think>...</think> tags in the response based on the prompt instructions.

    Rules:
    - If prompt ends with "\\think" or has no label, expect exactly one <think> section with non-empty content.
    - If prompt ends with "\\no_think", expect exactly one <think> section with empty content (exactly "\n\n").
    
    Returns True if the response matches the expected format, False otherwise.
    """
    prompt_text = prompt.strip()

    expects_think = False
    expects_no_think = False

    if prompt_text.endswith(r"no_think"):
        expects_no_think = True
    elif prompt_text.endswith(r"think"):
        expects_think = True
    else:
        # Default: assume thinking is expected if no explicit label
        expects_think = True

    # Use regex to find all <think>...</think> blocks (non-greedy, DOTALL to match newlines)
    pattern = re.compile(r"<think>(.*?)</think>", re.DOTALL)
    think_sections = pattern.findall(response)

    # Must have exactly one <think> block
    if len(think_sections) != 1:
        return False

    content = think_sections[0]

    if expects_think:
        # Content must be non-empty when stripped (not just whitespace or newlines)
        return content.strip() != ""

    elif expects_no_think:
        # Content must be exactly two newlines: "\n\n"
        return content == "\n\n"

    return False
```

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

`asyncio.run()` creates a new event loop on each call and cannot be called when an event loop is already running. This can cause issues in larger asynchronous applications. For consistency with `AsyncNativeRewardManager` and for better interoperability, it's preferable to get the current event loop and use `run_until_complete`.

```suggestion
        results = asyncio.get_event_loop().run_until_complete(self.async_compute_rewards(data))
```
