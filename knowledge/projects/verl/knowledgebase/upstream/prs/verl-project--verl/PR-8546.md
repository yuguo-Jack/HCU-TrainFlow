## Original PR description

Bumps [torchaudio](https://github.com/pytorch/audio) from 2.11.0 to 2.11.1.
<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/pytorch/audio/releases">torchaudio's releases</a>.</em></p>
<blockquote>
<h2>TorchAudio 2.11.1</h2>
<p>This is a minor release with no new feature. It's compatible with PyTorch 2.11 and later.</p>
<h3>Improvements</h3>
<p>[packaging] Build a single <code>py3-none</code> wheel per platform, covering all supported CPython versions including free-threaded builds (<a href="https://redirect.github.com/pytorch/audio/issues/4224">#4224</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4234">#4234</a>)
[packaging] Declare the <code>torch&gt;=2.11</code> dependency in the wheel metadata. It was previously unset (<a href="https://redirect.github.com/pytorch/audio/issues/4225">#4225</a>)
[packaging] Add the Python 3.15 classifier and <code>python_requires&gt;=3.10</code> to the wheel metadata (<a href="https://redirect.github.com/pytorch/audio/issues/4240">#4240</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4224">#4224</a>)</p>
<p>[Documentation] <a href="https://redirect.github.com/pytorch/audio/issues/4212">#4212</a>
[Code quality] <a href="https://redirect.github.com/pytorch/audio/issues/4229">#4229</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4231">#4231</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4230">#4230</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4232">#4232</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4184">#4184</a>, <a href="https://redirect.github.com/pytorch/audio/issues/4179">#4179</a></p>
<h3>Bug Fixes</h3>
<p>[CUDA] Only raise an error when torch and torchaudio were built with different CUDA major versions. Minor version mismatches are now allowed (<a href="https://redirect.github.com/pytorch/audio/issues/4226">#4226</a>)</p>
</blockquote>
