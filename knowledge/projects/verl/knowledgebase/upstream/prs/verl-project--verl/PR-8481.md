# [misc] fix: specify utf-8 encoding in setup.py for Windows compatibility

[Upstream PR](https://github.com/verl-project/verl/pull/8481) · state: closed · merged: False

## Original PR description

Signed-off-by: kkdoestech <letuankiet5939@gmail.com>
### What does this PR do?
On Windows systems where the locale encoding defaults to CP1252/ANSI, running `pip install -e .` fails with a `UnicodeDecodeError` when `setup.py` reads `README.md` and `version` without explicit encoding. This PR specifies `encoding="utf-8"` in `setup.py`.

### Checklist Before Starting
- [x] Search for similar PRs.
- [x] Format the PR title as `[{modules}] {type}: {description}`

### Test
Verified `pip install -e .` succeeds on Windows 11 without requiring `$env:PYTHONUTF8=1`.

### API and Usage Example
No API change.

### Design & Code Changes
- `setup.py`: Passed `encoding="utf-8"` to `open()` for `version` and `read_text()` for `README.md`.
