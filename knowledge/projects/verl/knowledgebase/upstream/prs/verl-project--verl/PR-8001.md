# [model, doc, test] fix: fall back to torch fused kernels on Ascend

[Upstream PR](https://github.com/verl-project/verl/pull/8001) · state: closed · merged: False

## Original PR description

### Status

Superseded by [#8143](https://github.com/verl-project/verl/pull/8143), merged on October 15, 2026, which implements Ascend fused linear cross-entropy through CANN / `torch_npu` and resolves [#7950](https://github.com/verl-project/verl/issues/7950).

This PR's unconditional Torch fallback would bypass that new CANN path. The original patch should therefore not be merged into current `main`.

### Original change

The reported Ascend 910B / CANN 9.0 failure occurred when the CUDA-oriented Triton output-head kernel exceeded the device's UB capacity.

This PR proposed handling an explicit `fused_kernel_options.impl_backend=triton` request by issuing a warning and selecting the native Torch backend when the Ascend runtime is available. It also added configuration documentation and CPU tests for backend selection.

### Validation recorded before the upstream CANN implementation

```bash
VERL_USE_EXTERNAL_PLUGINS=none PYTHONPATH=. python -m pytest -q \
  tests/models/test_fused_kernel_backend_on_cpu.py \
  tests/models/test_fused_kernels_ulysses_sp_on_cpu.py \
  tests/utils/test_experimental_torch_functional_on_cpu.py
```

Result: **38 passed** on the original PR revision. Changed-file Ruff checks, documentation date checks, compilation, and `git diff --check` also passed. Ascend 910B / CANN 9.0 execution was not validated locally.

These results cover the original backend-selection proposal. They do not validate compatibility with the subsequently merged CANN implementation.

### Relationship to the upstream solution

#8143 routes NPU `linear_cross_entropy` to CANN and includes a chunked PyTorch backward path for entropy gradients. It preserves a fused CE execution path on supported NPU installations. This PR's earlier blanket fallback is no longer the appropriate fix for #7950.

AI assistance was used for the implementation, tests, and preparation of this description.
