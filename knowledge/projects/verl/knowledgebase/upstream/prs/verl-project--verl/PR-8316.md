# [ckpt] fix: nixl checkpoint engine topology with a single rollout worker

[Upstream PR](https://github.com/verl-project/verl/pull/8316) · state: open · merged: False

## Original PR description

### What does this PR do?

Fix `NIXLCheckpointEngine.build_topology` for a topology with one rollout worker.

`next_agent_metadata` used a negative slice start. When
`rollout_world_size == 1`, that evaluates to `0`, returning all metadata
instead of no successor metadata and causing `build_process_group` to fail:

    AssertionError: rollout_kwargs[next_agent_metadata] must have length of 1

Use an index relative to `len(metadata)` instead. Topologies with two or more
rollout workers retain the same slice bounds.
