## Code Review

This pull request adds support for the Meituan LongCatFlash 562B model. The changes include updating model registries, adding a new experiment script, and various modifications to the distributed training and rollout infrastructure, particularly for sglang. The PR also introduces more robust code patterns and enhanced logging for debugging. My review has identified two critical issues. The first is a bug in the new experiment script where shell variables are used before they are defined, which will lead to incorrect behavior. The second is in the sglang rollout server, where using a `set` on GPU device IDs can disrupt the order and cause incorrect GPU assignments. Both issues need to be addressed to ensure the correctness of the new functionality.

File: `verl/workers/rollout/sglang_rollout/async_sglang_server.py` · line None

![critical](https://www.gstatic.com/codereviewagent/critical.svg)

Using `set()` on `worker_cuda_visible_devices` is problematic because it does not preserve the order of GPU IDs. The order in the `CUDA_VISIBLE_DEVICES` environment variable is crucial as it maps logical device indices (e.g., `cuda:0`, `cuda:1`) to physical GPUs. Scrambling this order can lead to incorrect GPU assignments and unpredictable behavior. To remove duplicates while preserving order, you can use `dict.fromkeys()` (for Python 3.7+).

```suggestion
                list(dict.fromkeys(worker_cuda_visible_devices[node_rank * self.gpus_per_node : (node_rank + 1) * self.gpus_per_node]))
```
