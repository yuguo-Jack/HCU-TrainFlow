### API and Usage Example

To resume from s3 and automatically use latest checkpoint in s3 put: 
trainer.resume_mode=auto
trainer.resume_from_path=s3://<bucket_name>/<path>

To resume from s3 at a specific step put:
trainer.resume_mode=resume_path
trainer.resume_from_path=s3://<bucket_name>/<path>/<step_folder>

To save to s3 bucket put: trainer.s3_checkpoint_dir=s3://<bucket_name>/<path>

Ensure that your local aws configuration is set to the correct region before running, you will also need to pip install boto3.

### Specific Changes

Add in S3 upload/download utility functions to verl/utils/s3_io.py
Change ray_trainer to resume from s3 checkpoint if an s3 path provided in trainer.resume_mode.
Change ray_trainer to save to s3 bucket if bucket is set in s3_checkpoint_dir
Change copy_to_local to accept S3 in addition to HDFS
Change hdfs_path to remote_path to accept s3 checkpoints
Implement auto resume from latest s3 checkpoint
