# feat(tpu): introduce Raiden checkpoint engine for high-speed TPU weight sync

[Upstream PR](https://github.com/verl-project/verl/pull/7905) · state: closed · merged: False

## Original PR description

DO NOT MERGE: this poc is only for single chip use-case.

Integrate Raiden (tpu-sync) weight synchronization backend for TPU-based
reinforcement learning (GRPO) training. This implementation leverages
direct D2H/H2D DMA transfers and socket-based P2P communication between
the trainer and vLLM sampler actors, replacing slow serialized checkpoint
reloads.

Benchmark Results (Qwen3-0.6B, 751.6M params, ~1.503 GB bfloat16 payload):
Evaluated on GKE Cloud TPU v6e cluster over 6 training steps:
- Trainer D2H DMA (TPU HBM -> Host DRAM):
  * Average latency: 0.1312s (131.19ms)
  * Effective throughput: 91.67 Gb/s (11.46 GB/s, 10.67 GiB/s)
- Sampler H2D DMA (Host DRAM -> TPU HBM):
  * Average latency: 0.0917s (91.73ms)
  * Effective throughput: 131.10 Gb/s (16.39 GB/s, 15.26 GiB/s)
- Raiden P2P Transfer (Trainer Host -> Sampler Host via TCP):
  * Average latency: 0.4184s (418.38ms)
  * Effective throughput: 28.74 Gb/s (3.59 GB/s, 3.35 GiB/s)
