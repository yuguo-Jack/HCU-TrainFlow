# [megatron] fix: backward through chunked vocab-parallel entropy

[Upstream PR](https://github.com/verl-project/verl/pull/8195) · state: closed · merged: True

## Original PR description

### What does this PR do?

With the Megatron engine, `entropy_from_logits_with_chunking=True` fails in backward whenever the entropy is part of the graph:

```
RuntimeError: one of the variables needed for gradient computation has been modified by an inplace operation: [torch.cuda.FloatTensor [1, 2048, 131072]], which is output 0 of AsStrided, is at version 4; expected version 2 instead.
```

`vocab_parallel_entropy_with_chunking` applies `_VocabParallelEntropy` to chunks that are views of one logits tensor. Its backward subtracts from the saved logits in place and adds back afterwards. All views share one version counter, so the first chunk's backward invalidates the logits the other chunks saved.

It only shows up when the update forward computes the entropy with chunking, e.g. `entropy_coeff != 0`, or `calculate_entropy=True` in bypass mode (no old-log-prob recompute, so the entropy comes from the update forward; `0 * entropy_loss` still backpropagates). Related: #1970.

Chunks now use an out-of-place backward, which costs one temporary of chunk size. The unchunked path keeps the in-place backward, so its memory use is unchanged.

### Test

`tests/special_distributed/test_tensor_dict.py::test_vocab_parallel_entropy` now also backpropagates through the chunked entropy and compares it with the unchunked gradient.

`torchrun --nproc-per-node=4 tests/special_distributed/test_tensor_dict.py` on 4 GPUs (TP2):

- `main` with the new check: all ranks fail with the error above.
- this PR: `test_vocab_parallel_entropy passes`, `test_vocab_parallel_sum_pi_squared passes`.

Found in a Nemotron-H 30B-A3B run at 256K context (Megatron engine, bypass mode, `calculate_entropy=True`, chunked entropy), which crashed on the first update.

### Design & Code Changes

- `verl/utils/megatron/tensor_parallel.py`: `_VocabParallelEntropy.forward` takes `inplace_backward` (default `True`); the chunked wrapper passes `False`. Backward returns `None` for the extra argument.
- `tests/special_distributed/test_tensor_dict.py`: chunked forward/backward check in the existing entropy test.
