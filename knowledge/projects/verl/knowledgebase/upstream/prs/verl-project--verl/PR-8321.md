<h3>Muse Spark Open</h3>
<!-- raw HTML omitted -->
<p>Muse Spark Open is a multimodal mixture-of-experts model from Meta that takes text, images, audio, and video as input and generates text. It has 816B total parameters (42B active per token) and a context window of up to 1,048,576 tokens shared across modalities. It is trained for agentic coding tasks such as multi-file editing, debugging, and tool use. Checkpoints are available in BF16 and NVFP4 formats.</p>

<h3>Ling 3.0</h3>
<p>Ling 3.0 Flash is a hybrid Mixture-of-Experts language model from InclusionAI. Its decoder groups five Kimi Delta Attention (KDA) layers with one Multi-head Latent Attention (MLA) layer. The MLA blocks use interleaved rotary embeddings and a head-wise output gate, and the feed-forward blocks combine routed and shared experts. It is natively supported in Transformers as <code>BailingHybridForCausalLM</code>, so it loads without <code>trust_remote_code=True</code>.</p>
<p><strong>Links:</strong> <a href="https://huggingface.co/docs/transformers/main/en/model_doc/bailing_hybrid">Documentation</a></p>

</ul>
<h3>Kolibri1</h3>
<p>Kolibri 1 is Aleph Alpha's mixture-of-experts reasoning model, focused on German and English. Each of its 50 layers routes every token to 6 of 384 experts using sigmoid routing, and adds one shared expert. Four sliding-window attention layers alternate with one full-attention layer, and RoPE is applied only in the sliding-window layers.</p>
