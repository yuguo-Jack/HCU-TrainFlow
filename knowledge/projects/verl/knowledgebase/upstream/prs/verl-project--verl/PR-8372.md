# [fsdp] fix: Avoid pinned host memory exhaustion during NPU CPU offload

[Upstream PR](https://github.com/verl-project/verl/pull/8372) · state: closed · merged: False

## Original PR description

### What does this PR do?

Use blocking CPU transfers for FSDP1 model shards and optimizer state on NPU to avoid exhausting pinned host memory across ranks. Preserve non-blocking transfers on other devices.

AI assistance was used to prepare this metadata. Duplicate-work status remains unverified; human review and relevant test execution are required before submission.

### Test

Validation was not run. Added CPU-based regression tests covering CUDA/NPU transfer flags, shard values and storage aliases, managed-handle skipping, optional cache clearing, optimizer tensor and non-tensor state preservation, and empty optimizer state.

No public API changes. Existing offload calls automatically select blocking transfers on NPU.
