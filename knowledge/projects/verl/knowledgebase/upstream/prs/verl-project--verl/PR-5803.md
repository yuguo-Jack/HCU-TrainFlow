## Code Review

This pull request refactors the prompt generation entry point by moving the core implementation to `main_generation_server` and introducing a backward-compatibility layer in `main_generation.py` to translate legacy CLI arguments. Example scripts and tests have been updated to use the new server and argument schema. A bug was identified in the `_translate_legacy_cli_args` function where the Hydra '+' prefix for configuration overrides is incorrectly stripped during translation, which could lead to runtime errors when adding new keys to the configuration.

The current implementation for translating legacy CLI arguments incorrectly drops the `+` prefix for Hydra overrides. This can lead to errors if the translated argument is not defined in the base configuration. For example, `+model.trust_remote_code=True` is translated to `actor_rollout_ref.model.trust_remote_code=True`, losing the `+` which is necessary to add a new key to the configuration.

The logic should be refactored to preserve the `+` prefix on all translated arguments if it was present on the original argument. The special handling for `data.output_path` which always adds a `+` should be kept.

```python
def _translate_legacy_cli_args(args: list[str]) -> list[str]:
    translated_args = []
    has_rollout_name = False
    saw_legacy_rollout_arg = False

    for arg in args:
        remapped = arg
        if "=" in arg:
            key, value = arg.split("=", 1)
            prefix = "+" if key.startswith("+") else ""
            normalized_key = key.lstrip("+")

            if normalized_key == "actor_rollout_ref.rollout.name":
                has_rollout_name = True

            if normalized_key in _LEGACY_ARG_EXACT_MAP:
                new_key = _LEGACY_ARG_EXACT_MAP[normalized_key]
                remapped = f"{prefix}{new_key}={value}"
            elif normalized_key == "data.output_path":
                remapped = f"+data.output_path={value}"
            else:
                for old_prefix, new_prefix in _LEGACY_ARG_PREFIX_MAP.items():
                    if normalized_key.startswith(old_prefix):
                        new_key = normalized_key.replace(old_prefix, new_prefix, 1)
                        remapped = f"{prefix}{new_key}={value}"
                        if old_prefix == "rollout.":
                            saw_legacy_rollout_arg = True
                            if new_key == "actor_rollout_ref.rollout.name":
                                has_rollout_name = True
                        break

        translated_args.append(remapped)

    if saw_legacy_rollout_arg and not has_rollout_name:
        translated_args.append("actor_rollout_ref.rollout.name=vllm")

    return translated_args
```
