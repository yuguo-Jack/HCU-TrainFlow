# [trainer] test: cover V1 TransferQueue critic field selection

[Upstream PR](https://github.com/verl-project/verl/pull/8501) · state: closed · merged: False

## Original PR description

### What does this PR do?

Adds CPU regression tests for V1 PPO's TransferQueue field selection. Both `_compute_advantage` and `_compute_metrics` must request `values` only when the critic is enabled, while preserving the critic-enabled request.

### Why is this not duplicating an existing PR?

Searched open PRs for `TransferQueue`/`use_critic` and critic value-request changes. No open PR covers these field-selection regression tests. This adds coverage for the fix in #8461 rather than reimplementing that fix.
