## Code Review

This pull request adds the functionality to save LoRA weights within the `FSDPSFTTrainer`. The implementation is functionally correct, but I've identified a significant performance issue in the method used to gather LoRA parameters for saving. The current approach can be inefficient in terms of memory and network bandwidth. I've provided a suggestion to optimize this process, which should improve checkpointing performance, especially in a distributed setting.

The current implementation for saving LoRA weights using `layered_summon_lora_params` is inefficient. It gathers the full parameters for each submodule on all ranks, which can be very slow and memory-intensive, potentially leading to out-of-memory errors on non-rank-0 GPUs. A more efficient approach is to gather the full state dictionary on rank 0 only and then extract the LoRA parameters. This significantly reduces network overhead and memory usage on non-primary ranks.

```python
        if self.lora and hasattr(self.fsdp_model, "peft_config"):
            from peft.utils import get_peft_model_state_dict
            from verl.utils.fsdp_utils import get_fsdp_full_state_dict

            lora_save_path = os.path.join(local_global_step_folder, "lora_adapter")
            if self.device_mesh.get_rank() == 0:
                local_mkdir_safe(lora_save_path)
            torch.distributed.barrier()

            try:
                # Use rank0_only=True for efficient state dict gathering.
                state_dict = get_fsdp_full_state_dict(self.fsdp_model, rank0_only=True)

                if self.device_mesh.get_rank() == 0:
                    peft_config = asdict(self.fsdp_model.peft_config.get("default", {}))
                    peft_config["task_type"] = peft_config["task_type"].value
                    peft_config["peft_type"] = peft_config["peft_type"].value
                    peft_config["target_modules"] = list(peft_config["target_modules"])

                    # Filter for LoRA parameters from the full state dict
                    lora_params = get_peft_model_state_dict(self.fsdp_model, state_dict=state_dict)

                    save_file(lora_params, os.path.join(lora_save_path, "adapter_model.safetensors"))
                    with open(os.path.join(lora_save_path, "adapter_config.json"), "w", encoding="utf-8") as f:
                        json.dump(peft_config, f, ensure_ascii=False, indent=4)
                    print(f"Saved LoRA adapter to: {lora_save_path}")
            except Exception as e:
                log_with_rank(
                    f"Save LoRA Adapter Error ({e})",
                    rank=self.device_mesh.get_rank(),
                    level=logging.WARNING,
                    logger=logger,
                    log_only_rank_0=True,
                )
            torch.distributed.barrier()
```
