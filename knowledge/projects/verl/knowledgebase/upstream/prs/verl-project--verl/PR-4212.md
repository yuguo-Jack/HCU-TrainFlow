# [tool] fix: Add missing __init__.py to mcp_clients for package inclusion & use timeout param in call_tool of McpClientManager.py

[Upstream PR](https://github.com/verl-project/verl/pull/4212) · state: open · merged: False

## Original PR description

### What does this PR do?

This PR fixes two issues in the tools/utils/mcp_clients subpackage:
- It put's an __init__.py into tools/utils/mcp_clients. So far this has been missing, which (given the current build settings) causes the entire directory to not be ignored when building the .whl.
- It actually put's the timeout parameter in tools/utils/mcp_clients/McpClientManager.py into use by awaiting client.call_tool_mcp(...) only for timeout seconds. Without that, stuck tool-executions will cause the entire ToolAgentLoop simply hang indefinitely which is especially problematic during training.
