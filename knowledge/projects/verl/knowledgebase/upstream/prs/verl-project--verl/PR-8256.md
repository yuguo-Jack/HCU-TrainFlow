### What does this PR do?

Title: `[model] fix: support Transformers 5 Qwen3.5 dynamic cache`

Transformers 5 stores Qwen3.5 gated-delta-net convolution and recurrent state
inside layer-scoped `DynamicCache` entries and exposes update methods instead of
the legacy top-level arrays. The verl training monkey patch still used the old
fields, so a cached forward failed before a GRPO update. Cached multi-token
continuations also need the previous convolution context and recurrent state.

This patch supports both legacy and Transformers 5 cache APIs, preserves state
through chunked continuation, and adds a CPU regression test for prefill,
multi-token continuation, single-token decode, and chunk/token equivalence.

### Design & Code Changes

- Resolve cache state from either legacy arrays or Transformers 5 layer entries.
- Use Transformers 5 cache update methods when available, with legacy fallback.
- Pass cached convolution/recurrent state into chunk continuation and retain
  only newly generated outputs.
- Request and store final recurrent state whenever a cache is active.
