<h2>TorchVision 0.29: ABI stability!</h2>
<p><a href="https://docs.pytorch.org/vision/0.29/">TorchVision 0.29</a> is out! It comes with two major changes: <strong>ABI stability</strong>, and <strong>deprecation of the image decoders and encoders</strong> (now in <a href="https://meta-pytorch.org/torchcodec/0.16/generated_examples/migration/torchvision_migration.html">TorchCodec</a>)!</p>
<h2>ABI Stability with torch 2.14</h2>
<p><strong>TorchVision is now ABI stable w.r.t. <code>torch 2.14</code></strong>! This means that <code>torchvision 0.29</code> will be compatible with future versions of <code>torch</code>: <code>2.15</code>, <code>2.16</code>, etc. You won’t need to install a new version of TorchVision when you upgrade torch.</p>
<p>As a result, we might stop releasing TorchVision in sync with pytorch. But <strong>TorchVision is still actively maintained and developed</strong>: we’ll still be pushing releases, just not with the same cadence.</p>

<h2>Image decoders and encoders are deprecated. Use TorchCodec!</h2>
<p><strong>The image decoders and encoders in <code>torchvision.io</code> are now deprecated, and they will be removed in a future release</strong>. They are now available in <a href="https://github.com/meta-pytorch/torchcodec/releases/tag/v0.16.0">torchcodec &gt;= 0.16</a>, where they are significantly more capable. You’ll just need to <code>pip install torchcodec</code>, and you can refer to <a href="https://meta-pytorch.org/torchcodec/0.16/generated_examples/migration/torchvision_migration.html">this migration guide</a> for migrating your code (most APIs for decoding are the same).</p>
<p>This finalizes a clear separation of concerns for the three media-processing libraries of PyTorch: <code>torchcodec</code> is for decoding and encoding all media (images, videos, and audio), while <code>torchvision</code> and <code>torchaudio</code> focus on the transforms.</p>
