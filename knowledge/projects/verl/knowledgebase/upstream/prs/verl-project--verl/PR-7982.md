# feat(tpu): add Raiden P2P weight synchronization engine for multi-host TPU RL

[Upstream PR](https://github.com/verl-project/verl/pull/7982) · state: closed · merged: False

## Original PR description

Introduce RaidenCheckpointEngine for direct socket-based peer-to-peer weight
synchronization between TorchTitan trainer and vLLM rollout workers on TPU v6e.

- Replaces Ray Plasma and /tmp disk caching with direct host-to-host TCP streaming,
  eliminating disk I/O bottlenecks and NVMe exhaustion risks.
- Implements optimized D2H/H2D DMA pipelines with verified 100% parameter norm parity.
- Achieves 7.73x faster weight sync on Qwen3-0.6B across 2 slices (16 TPU chips):
  reducing end-to-end sync latency from 16.32s down to 2.11s (1.01 GB/s throughput).
