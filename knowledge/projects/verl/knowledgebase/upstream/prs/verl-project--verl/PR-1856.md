### What does this PR do?
Fix progress bar calculation in `examples/sft/gsm8k/run_qwen_05_sp2.sh` training script to prevent unexpected training stops.

### High-Level Design
This PR addresses the incorrect calculation of `steps_per_epoch` which was causing training to appear to stop unexpectedly and generating unwanted warning messages.

### Specific Changes
1. Fixed the logic for calculating `steps_per_epoch` and `last_epoch_steps`
2. Added proper warning message handling
3. Improved progress bar visualization
4. Updated the training loop to handle step counts correctly

### API
No API changes. This is a bug fix for existing functionality.

### Usage Example
The script can be used as before, but now with correct progress indication:

```bash
bash examples/sft/gsm8k/run_qwen_05_sp2.sh
```

The fix has been verified by:
