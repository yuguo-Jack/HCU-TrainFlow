# [fsdp, trainer] fix: request values from TransferQueue only when critic is enabled

[Upstream PR](https://github.com/verl-project/verl/pull/8455) · state: closed · merged: False

## Original PR description

### What does this PR do?

- Fix GRPO training failures with newer TransferQueue versions that reject requests for missing fields. When the critic is disabled, `values` is not produced but was still requested during advantage and metrics computation.
- Fix Unsupported dispatcher fused in the Qwen3.5-35B FSDPTurbo example by
 replacing eager/fused with all2all and configuring use_fused_ops
 separately for actor and reference models.
