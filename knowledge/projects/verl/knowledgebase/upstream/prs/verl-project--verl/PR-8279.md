## Original PR description

### What does this PR do?

Adds the core `verl` changes for issue #16: Qwen2.5-Math-7B + FAPO-GenRM-4B training on Ascend with a Megatron actor, vLLM-Ascend rollout, and a colocated GenRM.

The delivery is paired with recipe PR https://github.com/verl-project/verl-ascend-recipe/pull/152. The recipe PR should be reviewed and merged together with this core PR.

### API and Usage Example

The new launcher can be run with environment variables for the Ascend topology and model paths:

```bash
TOTAL_GPUS=16 \
RM_GPUS=4 \
ACTOR_GPUS=12 \
TRAIN_TP=4 \
INFER_TP=4 \
GRM_TP=2 \
MODEL_MAX_POSITION_EMBEDDINGS=4096 \
TOTAL_TRAINING_STEPS=100 \
bash examples/ascend_extras/fapo_trainer/run_qwen2_5_math_7b_megatron.sh
```

The launcher derives the Actor maximum position length from the prompt and response budget by default, which matches Qwen2.5-Math-7B's 4096-token configuration.

- Add `examples/ascend_extras/fapo_trainer/run_qwen2_5_math_7b_megatron.sh` for Megatron + vLLM-Ascend FAPO training, including resource-pool wiring, NPU memory controls, optimizer offload, dynamic batching, and correct `reward.*` configuration.
