# [data] fix: accept null media columns in MultiTurnSFTDataset

[Upstream PR](https://github.com/verl-project/verl/pull/8420) · state: open · merged: False

## Original PR description

### What does this PR do?

`MultiTurnSFTDataset` crashes on SFT data that mixes text-only and image/video conversations when the text-only rows store `None` in the media column. That is what pandas/pyarrow write for a missing list cell, so it is the usual result of building such a dataset with a DataFrame.

`_build_messages` falls back to `[]` only when the column is **absent**:

```python
images = example[self.image_key] if self.image_key in example else []
videos = example[self.video_key] if self.video_key in example else []
```

If the column exists and holds `None`, the value reaches `assert image_offset == len(images)`, and the dataloader stops with:

```
File ".../verl/utils/dataset/multiturn_sft_dataset.py", line 287, in _build_messages
    assert image_offset == len(images), f"image_offset {image_offset} != len(images) {len(images)}"
TypeError: object of type 'NoneType' has no len()
```

`RLHFDataset._build_messages` already handles this case (`example.get(self.image_key, None) or []`, with the comment "When concatenating multimodal datasets, get will return None for samples without a modality column"). This PR applies the same rule to the SFT dataset. When the media value is `None`, the row is treated as having no media.

Minimal repro on `main` (2ab35292), CPU, Qwen3-VL-2B-Instruct processor:

```python
import pandas as pd; from io import BytesIO; from PIL import Image
from verl.utils import hf_processor, hf_tokenizer
from verl.utils.dataset.multiturn_sft_dataset import MultiTurnSFTDataset
buf = BytesIO(); Image.new("RGB", (64, 64), "red").save(buf, format="PNG")
pd.DataFrame([
    {"messages": [{"role": "user", "content": "<image>Describe."}, {"role": "assistant", "content": "Red."}],
     "images": [{"bytes": buf.getvalue()}]},
    {"messages": [{"role": "user", "content": "Hi"}, {"role": "assistant", "content": "Hello."}], "images": None},
]).to_parquet("mixed.parquet")
mp = "~/models/Qwen/Qwen3-VL-2B-Instruct"
ds = MultiTurnSFTDataset("mixed.parquet", hf_tokenizer(mp), {"max_length": 1024, "pad_mode": "no_padding"}, processor=hf_processor(mp))
ds[1]  # main: TypeError: object of type 'NoneType' has no len(); this PR: works
```

### API and Usage Example

No API change. Rows whose media value is `None` are now handled the same way as rows with `[]`.

### Design & Code Changes

- `verl/utils/dataset/multiturn_sft_dataset.py`: in `_build_messages`, read the media columns with `.get()` and map `None` to `[]`. The fallback uses an explicit `is not None` check rather than `or`, so array-like values never need to be evaluated as booleans.
- `tests/utils/dataset/test_multiturn_sft_dataset_on_cpu.py`: adds the regression test.
