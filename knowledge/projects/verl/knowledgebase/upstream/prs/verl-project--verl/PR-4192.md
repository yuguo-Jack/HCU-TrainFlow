## Original PR description

### What does this PR do?

Respect the max_tokens setting in sampling_params if it is present. Typically, max_tokens should be set to equal max_model_len - len(prompt_ids). However, other cases exist, for example, when you need to fit both the response and the next prompt into a fixed-size window for a subsequent call.

While this line correctly sets a default value for `max_tokens` if it's not already in `sampling_params`, using `dict.setdefault()` is more idiomatic and slightly more efficient for this purpose. It achieves the same result with a single dictionary operation and would be consistent with how `repetition_penalty` is handled just two lines below.

```suggestion
        sampling_params.setdefault("max_tokens", self.config.max_model_len - len(prompt_ids))
```
