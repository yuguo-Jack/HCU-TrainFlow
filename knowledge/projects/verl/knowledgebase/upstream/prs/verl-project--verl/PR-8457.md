# [fsdp, trainer] fix: request values from TransferQueue only when critic is enabled

[Upstream PR](https://github.com/verl-project/verl/pull/8457) · state: closed · merged: True

## Original PR description

### What does this PR do?

- Fix GRPO training failures with newer TransferQueue versions that reject requests for missing fields. When the critic is disabled, is not produced but was still requested during advantage and metrics computation.values
- Fix Unsupported dispatcher fused in the Qwen3.5-35B FSDPTurbo example by
replacing eager/fused with all2all and configuring use_fused_ops
separately for actor and reference models.

### Design & Code Changes

- Request values only when self.use_critic is enabled in _compute_advantage() and _compute_metrics(), avoiding missing-field errors with newer TransferQueue versions.
