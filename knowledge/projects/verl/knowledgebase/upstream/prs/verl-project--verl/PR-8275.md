## Original PR description

### What does this PR do?

Adds [Awesome-Perception-Aware-RLVR](https://github.com/zsxm1998/awesome-perception-aware-rlvr) to "Awesome Projects Built with `verl`" in README.md (one line, after the last entry).

The project is built on EasyR1 (a verl fork). It implements 19 perception-aware RLVR and on-policy distillation methods for vision-language models in one codebase, trains most of them in two controlled comparisons (RLVR on Qwen3-VL-4B, OPD on a Qwen3-VL-2B student), and provides one-click evaluation on 30+ multimodal benchmarks.
