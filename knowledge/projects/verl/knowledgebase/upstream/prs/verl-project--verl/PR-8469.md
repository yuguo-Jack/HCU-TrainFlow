# [hardware, recipe] feat: Qwen3.5-397B-A17B full-parameter GRPO recipe on TPU v7x (8K context, multi-replica rollout)

[Upstream PR](https://github.com/verl-project/verl/pull/8469) · state: open · merged: False

## Original PR description

### What does this PR do?

Adds full-parameter **Qwen3.5-397B-A17B** MoE GRPO support (including **8K thinking context** `512 + 7,680 = 8,192`, multi-replica vLLM rollout, Cloud TPU actor MFU reporting, and **torchtitan#142** fast `EP=8` Ring-of-Experts knobs) to `examples/tpu/grpo/run_qwen3_5_torchtitan.sh`, paired with `verl-hardware-plugin` `main` (`52ede0c`: #98–#103, #114) and [#115](https://github.com/verl-project/verl-hardware-plugin/pull/115).

- **`examples/tpu/grpo/run_qwen3_5_torchtitan.sh`:**
  - Exposes `USE_KL_LOSS`, `EXPERT_PARALLEL_SIZE`, `EP_CAPACITY_FACTOR`, `PARAM_DTYPE`, `OPTIMIZER_HOST_OFFLOAD`, `FP32_MASTER`, `ROLLOUT_EXPERT_PARALLEL_SIZE`, and `ROLLOUT_LOAD_FORMAT=dummy`.
  - Adds `USE_DYNAMIC_BSZ` (sets `actor.use_dynamic_bsz`, `rollout.log_prob_use_dynamic_bsz`, and `ref.log_prob_use_dynamic_bsz` together) and scales `DATA_MAX_LENGTH` / `MAX_TOKEN_LEN_PER_GPU` (`16384` tokens/rank for 397B fast EP).
  - Adds `torchtitan#142` fast-EP knobs (`EP_DISPATCHER=static`, `EP_TOKEN_CHUNKS=8`, `EP_PAIRED_GROUPED_MM=True`) plus **trainer-isolated** `TRAINER_SCOPED_VMEM_LIMIT_KIB=65472`, `SPARSECORE_OFFLOAD=True`, and `TRAINER_EXTRA_LIBTPU_INIT_ARGS` exported via `VERL_TPU_TRAINER_LIBTPU_INIT_ARGS` so `vLLM` rollout workers keep clean `LIBTPU_INIT_ARGS`.
- **`examples/tpu/grpo/Dockerfile`:**
  - Builds on `google-pytorch/torchtitan#142` (`b9eff0e298871cce5d84a3e1be521d667862e3c6`: compiled GatedDeltaNet + decay-grad fix, Tokamax Flash Attention, Pallas causal conv1d / gated RMSNorm, and Ring-of-Experts `EP=8` chunked pipelining) with `jax`/`jaxlib 0.12.0.1`, `tokamax 0.0.17`, and `libtpu 0.0.50`.
- **`verl/utils/flops_counter.py` & `verl/trainer/ppo/ray_trainer.py`:**
  - Adds BF16 peak FLOPS entries for Cloud TPU (`TPU v7x` `1153.5` TFLOP/s per TensorCore, `v6e` `918`, `v5p` `459`, `v5e` `197`), supports text-only `qwen3_5_text` / `qwen3_5_moe_text`, and streams `data.pt` directly to `gs://` (`/gcs_ckpt`) when zero-disk GCS checkpointing is active.
