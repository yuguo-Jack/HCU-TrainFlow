# [reward] fix: code reward counts a known wrong answer after test 10

[Upstream PR](https://github.com/verl-project/verl/pull/8022) · state: closed · merged: False

## Original PR description

### What does this PR do?

Fixes #8021. for codecontests/apps/codeforces/taco the code scorer re-runs only the first 10 tests after a failure and scores passed/10, so a program right on 1-10 and wrong on 11 got 1.0. now a wrong answer the full run already saw past test 10 is counted (10/11). timeouts and runtime errors keep the current behaviour since the second pass is there to give slow tests more time (#1921). sandbox_fusion gets the same rule so both paths still match
