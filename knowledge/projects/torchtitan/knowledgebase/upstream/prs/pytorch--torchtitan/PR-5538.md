# [graph_trainer] Remove obsolete EP chunking modes

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5538) · state: open · merged: False

## Original PR description

## AI-Generated Details

Prepared with Codex from the author's requested GraphTrainer cleanup.

The retired graph-chunk design left transformer-block wrappers, batch/sequence
selectors, fingerprint fields, and test variants in the eager EP path. Remove
those unsupported requirements and retain one explicit contract: split MoE
tokens before tracing, leaving attention and dense feed-forward modules intact.

The input is `(T, D)` with an even token count. Token masks remain aligned with
each local TP shard; both halves share the original auxiliary-loss denominator.
Remove the recursive structured-output wrapper and stale synthetic fixtures.
The supported configuration is `compile.ep_overlap.module_fqn =
"layers.*.feed_forward"`.

## Test Plan

The stack's actual tensor-mask contracts exercise TP1/TP2 slicing. The final
SPMD stack also passed real four-rank HybridEP training with deterministic
full forward/backward CUDA capture/replay. Validation belongs to the complete
SPMD stack; this PR does not independently claim the later async/paging features.

Changed-code lint passed. The unrelated existing video-loader optional-value
typing failure is outside this EP stack and is not changed.

## Scope

HybridEP-only eager EP overlap follows in the next changes. GraphPP is a
separate top-of-stack change; no native kernels or checkpoint formats change.
