# [graph_trainer] Remove obsolete EP chunking modes

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5538) · state: open · merged: False

## Original PR description

## AI-Generated Details

Prepared with Codex from the author's requested GraphTrainer cleanup.

The retired graph-chunk design left transformer-block wrappers, batch/sequence
selectors, fingerprint fields and test variants in the eager EP path. Remove
those unsupported requirements and retain one explicit contract: split MoE
tokens before tracing, leaving attention and dense feed-forward modules intact.

The input is `(T, D)` with an even token count. Token masks remain aligned with
each local TP shard; both halves share the original auxiliary-loss denominator.
Remove the recursive structured-output wrapper and stale synthetic fixtures,
including imports used only by those removed fixtures. The supported
configuration is `compile.ep_overlap.module_fqn = "layers.*.feed_forward"`.
The stale `MoE` test import is removed here, not left for a later stack PR.

## Verification

The actual tensor-mask contract exercises TP1/TP2 slicing. The owning-prefix
test passed; the same changed-file pre-commit command as CI passes its owned
checks, including the flake8 import check. The full SPMD stack also passed real
four-rank HybridEP training with native FA4 and deterministic full-F/B CUDA
capture/replay. This PR does not independently claim later async/paging features.

The unrelated existing video optional-value typing failure remains outside
scope and is unchanged. Other stack CI and multi-host results are not claimed.

## Scope

HybridEP-only eager overlap follows in the next changes. GraphPP is a separate
top-of-stack change; no native arithmetic or checkpoint format changes here.
