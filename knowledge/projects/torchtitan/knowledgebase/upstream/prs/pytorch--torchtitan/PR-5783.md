## Why

The preceding model PR rejects TP and EP. Flash-Next needs its four-stream
residuals and full-history PLE to follow the shared activation placements, and
its TP-replicated indexer must receive one globally normalized teacher update.
This PR supplies those sharding contracts using the existing SPMD/FSDP bridge.

For TP2/SP, PLE gathers token history and lexical feature shards before computing
its document-local update, then returns each token shard:

```text
residual rank 0: [T/2, 4D] -- gather -- PLE [T, 4D] -- return rank 0 tokens
residual rank 1: [T/2, 4D] -- gather -- PLE [T, 4D] -- return rank 1 tokens
lexical table:   [rows, F/2] per TP rank -> lookup -> gathered [T, heads, F]
teacher heads:  sum across TP -> block maximum -> replicated indexer KL
```

## What changed

- Enable TP1/TP2 with and without SP, and EP, through declarative model sharding.
  Reject degrees that split the two QSA KV heads before model construction.
- Preserve identical versus token-varying TP gradient semantics for grouped
  norms and unsharded linears; shard lexical-table features across TP.
- Sum teacher heads before block max pooling and count replicated indexer
  gradients once. Reduce detached teachers in packets of 16 query chunks
  (256 queries by default) while preserving SDPA and KL accumulation order.
- Add the TP2/EP2/SP debug recipe and a 273-token CPU oracle covering the
  256-query packet boundary, tail probabilities and TP gradient scaling.

PP and CP remain explicitly unsupported at this increment. This PR depends on
`[qwen3_8_fn] 1/n`.

## Numerics

The offline matrix uses one FP32 checkpoint, eight logical 64-token documents,
512 routing tokens and 504 CE tokens. All 190 reconstructed preclip parameter
gradients pass unchanged BF16 RMS/infinity bounds (`atol=1e-4`, `rtol=0.03125`);
all natural MoE/QSA sets agree. Replicas are checked exactly and counted once.
There is no fitted gradient rescaling. The exact-prefix captures were made at
`6bc85a249998f5ed4e1295143ad836324f6184be`; its amendment only adds early
rejection of invalid TP degrees and the associated CPU check/documentation.
Every valid TP1/TP2 config and forward/backward equation is unchanged.

| Layout | Global gradient norm ratio | Global cosine |
| --- | --- | --- |
| FSDP2 | 0.999999999996 | 1.0 |
| FSDP2/EP2 | 1.000000102204 | 0.999999990711 |
| TP2/EP2, SP disabled | 1.000062851570 | 0.999959733804 |
| TP2/EP2/SP | 1.000164114499 | 0.999959747135 |

The fixed native-choice checkpoint includes a separately disclosed conditioning
fixture. It fixes lexical feature zero to 1 and the corresponding key-projection
row in each stream to gain 0.125. That gain was selected using forward-only
criteria before observing its distributed gradients: raw key/query dot >= 1
and sigmoid(signed sqrt) <= 0.9. Actual GPU forwards satisfy raw minimum
1.0390625 and gate maximum 0.875 on all tokens/streams. Production math,
reference weights, C4 weights and comparison bounds are unchanged.

The original near-zero fixture is retained: one SP table entry exceeded its
original peak bound by 1.4%. Captured lookup vectors and token ownership agree
exactly; local VJPs attribute the difference to BF16 query drift amplified by
the signed-square-root gate near zero. The conditioned fixture checks placement
and normalization; it is not a claim of universal BF16 pointwise parity.

The teacher-packet refactor additionally passes a same-layout, same-checkpoint
10-step comparison on two GB300 GPUs, TP2/EP2/SP, seed 42, strict deterministic:
full-precision loss and gradient norm are bitwise identical under
`scripts/loss_compare.py --metrics loss,grad_norm --assert-equal`. Its local
before/after refs are `a43b124f8176d53c385bcdd2867b53f1f29dfe45` and
`4b2997e803b766f3b60d51cb580568a109d2ca51`; their sole difference is teacher
batching in `QSAInnerAttention.forward`. Those historical refs qualify the teacher-packet change and later TP4
rejection. The earlier logger migration is retained. The current base and
CPU/lint checks are listed separately above; GPU qualification is pending.
This PR makes no measured throughput claim.
