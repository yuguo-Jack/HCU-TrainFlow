# Add DSv3 TF32 router-gate backward override

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5395) · state: open · merged: False

## Original PR description

Fuse BF16 input conversion, TF32 GEMMs and BF16 output casts into one
CuTeDSL kernel per gradient. Preserve the pinned fbpackage gate policy,
forward and FSDP ownership. Use names distinct from the HiMidLo override.

GB300 [4096,7168] -> 256, native -> fused:
backward 179.37 -> 144.09 us; F+loss+B 216.46 -> 172.53 us;
peak allocated 310.50 -> 163.00 MiB. Bitwise and FSDP128 checks pass.
Keep default-off: 23.3% of the calibrated roofline, below the 90% gate.

One self-contained override, one CPU test file and one GPU test file.
The pinned runtime passes 39 tests; public main imports safely and
reports the missing native TF32 policy rather than substituting HiMidLo.
