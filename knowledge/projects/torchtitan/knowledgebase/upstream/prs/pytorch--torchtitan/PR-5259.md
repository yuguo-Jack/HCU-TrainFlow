# Fuse DSv3 sequence-wise loss forward/backward

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5259) · state: open · merged: False

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #5265
* #5264
* #5261
* __->__ #5259
* #5258

Fuse expert frequencies, score normalization, raw-loss reduction and score
gradients. Preserve native loss injection, metrics, scaling and MoE layout.

Keep kernels, custom operators, autograd and override in one file, with
one CPU test file and one GPU test file. Compose with the router factory
without changing either module's ownership.

Recorded GB300 FP32 [4096,256], native -> CuTeDSL:
Fwd 49.19 -> 7.48 us; Bwd 32.45 -> 3.50 us; F+B 79.98 -> 10.20 us.
Bitwise checks pass; roofline acceptance remains open. Requires CuTeDSL 4.8+.
