# [typing] Type decoder layer configurations

[Upstream PR](https://github.com/pytorch/torchtitan/pull/4912) · state: open · merged: False

## Original PR description

## Summary

Updated after #5345 landed, preserving the new `FeedForward` and `Attention` interfaces. This removes the remaining raw decoder-layer list tracked in #2936 without reintroducing the superseded structural protocol or optional MoE fields.

```text
TransformerBlock.Config[AttentionConfig]
  -> model-specific block Config
  -> Decoder.Config[BlockConfig]
     -> MTPDecoder.Config[BlockConfig]
```

Bind the standard, hybrid, multimodal, and MTP model configs to their concrete layer types; narrow builder results accordingly. Keep `layers` mutable and use `Sequence` only in the read-only NVFP4 helper. Remove four now-unneeded DeepSeek V3 argument suppressions.

The now-typed DeepSeek V4 checkpoint adapter narrows each layer's feed-forward/router config before adding hash-routing keys. This preserves the original PR's dense-first-layer fix while following the new feed-forward layout.

## Evidence

- **Before:** All three new regressions fail on upstream `f2bd97332`: generic configs are not subscriptable, and a dense first layer raises `AttributeError` in the V4 adapter. **After:** All three pass; the broader configurable/module/model-building/layout/state-dict selection is **95 passed**.
- **Before:** A local `assert_type` probe reports four failures because Llama 3 and DeepSeek V3 layer/attention types are `Any`. **After:** All four assertions pass, including mutable-list operations.
- Pyrefly on all 18 changed source files: **0 errors**, 7 existing suppressions, one existing redundant-cast warning. Full-project Pyrefly: **58 errors on both upstream and this branch**, with no added diagnostics; optional-dependency/API limitations remain.
- Full-tree non-type-checking pre-commit hooks pass after formatting. The full Pyrefly hook was also attempted and fails for the comparable baseline diagnostics; its unrelated auto-removals in checkpoint/loss scripts were restored.
- AST comparison verifies **200 executable functions across the 16 annotation-only model files are unchanged**. The V4 adapter's small runtime narrowing is separately regression-tested. Compilation and `git diff --check` pass.
- `pytest tests/ -x` stops at the same missing `renderers` import during collection on upstream and this branch; the full suite is not claimed to pass.

Local verification uses Python 3.12, cached nightly PyTorch and the pinned SPMD/remat/checkpointing dependencies. No CUDA training, multi-GPU, or deterministic-loss parity result is claimed; GPU-dependent Attention Gym and other optional integrations are unavailable locally. Maintainer workflow approval and upstream CI remain required.
