# [tests] Filter Rule for IntegrationTest

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5665) · state: closed · merged: False

## Original PR description

## Summary

Replaces the per-definition `skip_rocm_test: bool` and `disabled: bool` flags on
`IntegrationTestDefinition` with a general filter rule. All 23 `skip_rocm_test`
definitions and the single `disabled` definition are migrated, and selection
behavior is unchanged on every backend. The mechanism is backend-agnostic, so
new integration tests can reuse it directly.

## Background

Integration tests currently have no unified skip mechanism: skipping is spread
across per-definition booleans, and some of them, such as `skip_rocm_test`, are
tightly coupled to specific hardware.

## Design

Each definition takes an optional filter rule and a boolean condition evaluated
when the definition is created:

```python
    filter_rule: str | None = None
    """``"black_list"`` or ``"white_list"``; ``None`` means no filtering."""

    condition: bool | None = None
```

- `black_list`: skip when `condition` is true.
- `white_list`: skip when `condition` is false.
- No `filter_rule`: never filter.

The runner calls `should_skip()` for each definition in `_filter_tests()` and
reports the filtered cases separately in the log. Because `condition` is
evaluated at definition creation, it must be paired with a rule; `__post_init__`
rejects an unknown rule, a rule without a condition, a condition without a
rule, and a non-bool condition.

## Migration:

```diff
-            skip_rocm_test=True,
+            filter_rule="black_list",
+            condition=is_rocm(),
```

We also extracted the ROCm check that already existed inside
`has_rocm_capability` into `is_rocm()` in `torchtitan/tools/utils.py`, so these
rules check the runtime instead of relying on the runner's `--gpu_arch_type`
argument. `has_rocm_capability` now reuses it.

## Validation

Same runner logic across the CUDA and ROCm branches: CUDA 83 runnable / 0
filtered, ROCm 60 runnable / 23 filtered, matching the previous
`skip_rocm_test` counts.
