# [flux] Point default asset paths at the shipped locations

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5015) · state: closed · merged: False

## Original PR description

## Summary

`FluxEncoderConfig.autoencoder_path` and `Inference.prompts_path` still defaulted to `torchtitan/experiments/flux/...`. That tree is gone. Shipped recipes already override both fields:

- `autoencoder_path="assets/hf/FLUX.1-dev/ae.safetensors"` in `torchtitan_recipes/models/flux.py` and `torchtitan_recipes/tests/models/flux.py`
- `prompts_path="./torchtitan/models/flux/inference/prompts.txt"` in `torchtitan_recipes/tests/models/flux.py`

Anyone who builds `FluxEncoderConfig()` or `Inference()` without a recipe opens a missing path. `torchtitan/models/flux/inference/infer.py` reads `config.inference.prompts_path` directly. The prompts file shipped in-tree is `torchtitan/models/flux/inference/prompts.txt`. `ae.safetensors` is a user download and is not in git; the default only names the same path the recipes already use.

The example comment in `torchtitan/models/flux/run_infer.sh` pointed at `./torchtitan/models/flux/run_train.sh`, which does not exist. It now points at the repo-root `./run_train.sh`.

Recipe overrides are unchanged.
