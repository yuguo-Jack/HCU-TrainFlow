## Why

V4.1's released checkpoint includes its ViT, a padded 3x3 unshuffle aligner, image marker embeddings, and separate visual expert balancing. Treating image positions as ordinary text would also apply Engram to them and mix visual counts into the text balancing update.

**Example.**

```python
config = build_model_config(
    "debugmodel", parallelism=ParallelismConfig(), seq_len=128,
    vision_enabled=True,
)
# Preprocessing accepts flattened patches, grid_thw with time=1,
# and packed token_types for text/image markers/visual tokens.
```

## What changed

- Add per-image bidirectional ViT attention with two-axis RoPE, padded channel-major unshuffle, aligner, and marker replacement.
- Exclude visual positions from the Engram residual and update text/image expert counts and biases separately through optimizer hooks.
- Keep one batched visual-count reduction per active mesh; register it only when vision is enabled.
- Handle image presence on one FSDP rank with a zero-valued visual dependency on text-only ranks.
- Preserve stacked visual projection layouts and gather marker rows during distributed HF conversion.

Vision, aligner, and markers form an atomic config contract. Pixel inputs on a text-only model raise explicitly. Existing shared linear sharding constructors supply the visual projection layouts.

## User-facing changes

| Before | After |
| --- | --- |
| V4.1 accepts text only | Optional packed image inputs with paired encoder, aligner, and marker config |
| Text expert-balancing counts only | Text and image counts/biases updated separately |
| No visual HF weights mapped | Encoder, aligner, and markers round trip through HF |

The additional HF key translations are mechanical. Image isolation, token replacement, and distributed balancing introduce computation and ownership contracts.

## Numerics / performance

| Independent author check | Maximum absolute error |
| --- | --- |
| ViT outputs | `4.77e-7` |
| Aligner outputs | `6.71e-8` |
| Image-conditioned logits | `5.66e-7` |
| Isolated visual/SWA parameter gradients | `3.93e-8`, 67 tensors |

Two-rank FSDP training runs 10 steps with images on only one rank, default rematerialization, and actual optimizer hooks. Visual gradients are connected, routing counters reset, and visual balancing biases agree across ranks. Distributed HF export/restore reproduces every tensor exactly; reloading gives identical logits. This is a connectivity/checkpoint check, not FSDP-versus-single-rank multimodal gradient parity.

## Testing

22 model CPU tests, the single-GPU vision training test, and the two-GPU multimodal FSDP test passed. All-file pre-commit passed. CPU oracles guard image-grid isolation, RoPE, padded unshuffle order, visual-token Engram exclusion, optimizer counter lifetimes, and complete HF round trips.
