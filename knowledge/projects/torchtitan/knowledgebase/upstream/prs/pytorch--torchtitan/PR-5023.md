# [graph_trainer] Remove cuda_graph passes in graph_trainer by default

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5023) · state: closed · merged: True

## Original PR description

The main goal is to make GraphTrainer to work seamlessly with outer CUDA graph capture by default.
In torchtitan case - torchtitan trainer is doing cudagraph capture.

1. Removing cuda_graph.py passes from default passes
2. Preserve them in codebase and keep them tested on ci for users that would be constructing the set of passes on their own and can use them for some special cases like partial cudagraphs etc.
