# [CI Fix] Fix private Linear function import in GPU tests

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5421) · state: closed · merged: True

## Original PR description

Fix collection of `test_linear_inplace_wgrad_accum.py`, which currently aborts both the single- and multi-GPU unit-test jobs on main. The test added in #5399 imports `_LinearFunction` from the public package, but that private implementation is defined in `torchtitan.models.common.linear.linear` and is not re-exported.

Import the private function from its defining module and keep `Linear` on the public import path.

Validation:

- All five tests collected; four single-GPU cases passed locally.
- The multi-GPU case failed its existing addmm-call assertion under local PyTorch 2.14.0. The pre-#5399 version of that test reproduces the same failure; CI uses PyTorch 2.16 nightly.
- All non-Pyrefly pre-commit hooks passed. Full-tree Pyrefly reported 54 existing local dependency/type errors; unrelated automatic edits were reverted.

Fixes the collection error in [main GPU CI](https://github.com/pytorch/torchtitan/actions/runs/38778179219).
