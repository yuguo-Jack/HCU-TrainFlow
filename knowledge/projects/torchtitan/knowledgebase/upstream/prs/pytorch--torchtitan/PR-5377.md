# [BE] Document TorchFT timeout hierarchy and fix typos in experiment README

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5377) · state: closed · merged: True

## Original PR description

## Summary
- Fix two typos in `torchtitan/experiments/torchft/README.md` ("lossing" → "losing", "semi-synchronouse" → "semi-synchronous").
- Add a "Timeout configuration" section documenting the required timeout hierarchy for fault-tolerant training. Resolves #2899.

## Details
The timeout table documents the 7 timeout parameters (Python config + env vars) that must form a strict hierarchy so lower-level timeouts trigger recovery before higher-level ones kill the process. Values follow the configuration validated in #2899; parameter names cross-checked against `torchtitan/experiments/torchft/manager.py`, `trainer.py`, and `torchtitan/config/configs.py`.

## Test plan
Docs-only change, no code touched.
