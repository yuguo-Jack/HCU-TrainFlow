# [moe][perf] Triton grouped GEMMs for the no-grad expert MLP, any dispatcher (1/3)

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5521) · state: open · merged: False

## Original PR description

**TLDR:** `RoutedExperts` runs its expert MLP through a new `_expert_mlp` hook, and an opt-in override, `TritonRoutedExperts`, runs the hook's no-grad bf16 path as Triton grouped GEMMs on any dispatcher's expert-sorted rows. H100, DeepEP expand, Qwen3.5-35B-A3B experts: routed experts take 0.89-0.94x the time of the stock GEMMs at EP = 4, 0.83-1.00x at EP = 8.

**Stack** (3 PRs, merge bottom-up; this PR is in **bold**)

| # | PR | Independent? | Needs (stack positions) |
|---|---|---|---|
| **1** | **Triton grouped GEMMs for the no-grad expert MLP, any dispatcher** | **yes** | **—** |
| 2 | Triton routed experts: kernels read the routes, no dispatch | no | 1 |
| 3 | DeepEP at EP > 1: send each token once per rank | no | 2 |

**Problem**
1. **Today.** The generator's routed experts run w13 as `torch._grouped_mm` (plus a setup kernel), SwiGLU as another kernel, then w2 as `torch._grouped_mm`.
2. **Decode.** Each expert gets a few rows, but ATen's grouped GEMM computes 128-row tiles.
3. **So.** It reads the weights well below HBM bandwidth.
4. **Cost.** GB300, 34 tokens: w13 136 + w2 82 µs per layer, against a 137 µs weight-read floor.

**Solution**
1. **Hook.** `RoutedExperts._expert_mlp(routed_input_RD, offsets_E)` holds `w13 -> activation -> w2`, with the same remat pins.
2. **Override.** `TritonRoutedExperts._expert_mlp` calls `triton_expert_mlp_op` for no-grad bf16 SwiGLU with plain `GroupedLinear` w13/w2 and dims divisible by 256.
3. **Fallback.** Otherwise, or at 512+ rows per expert (the stock GEMMs win there), it calls the stock hook.
4. **Kernel.** Each block finds its expert from `offsets_E` (no schedule); SwiGLU runs on the fp32 accumulators; w2 uses programmatic dependent launch.
5. **Unchanged.** Dispatch, combine, training (grad on), quantized and non-bf16 configs.

```text
dispatch (any) -> [w13 + SwiGLU] -> [w2] -> combine (any)
```
