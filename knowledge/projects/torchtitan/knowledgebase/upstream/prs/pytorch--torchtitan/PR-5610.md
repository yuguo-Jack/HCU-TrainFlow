# [release/0.4][CI] Fix GPU validation test setup

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5610) · state: closed · merged: True

## Original PR description

## Why

Release GPU validation has two test-environment setup failures:

- `loss_compare.py` is staged without its `_checkpoint_test_config.py` dependency for non-RL suites.
- `HF_ASSETS_PATH` for Qwen3-0.6B is exported globally, causing the random-weight Qwen3.5 debug parity test to load an incompatible Qwen3-0.6B checkpoint.

## What

- Stage `_checkpoint_test_config.py` for every GPU validation suite.
- Scope the Qwen3-0.6B checkpoint path to its two parity tests and run the Qwen3.5 debug test without it, matching main CI.

## Validation

- `bash -n .github/scripts/validate_release_gpu.sh`
- `git diff --check`
- All non-Pyrefly pre-commit hooks pass. Pyrefly was skipped because this is a shell-only change and the temporary environment lacks project dependencies.
