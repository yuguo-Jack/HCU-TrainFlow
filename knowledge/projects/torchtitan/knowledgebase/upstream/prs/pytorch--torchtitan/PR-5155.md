# [skills][perf] Add local_compile_perf: speeding up models with local_compile regions

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5155) · state: closed · merged: True

## Original PR description

**TLDR:** Add the `local_compile_perf` skill: how an agent speeds up a model with `local_compile` regions. Used on 4 models, it cut the 16k step 13-69% vs upstream regions.

**What it contains** (`.claude/skills/local_compile_perf/`)
1. **Method:** measure eager vs regions vs per-layer compile, rank glue by gap x share, add the smallest region or rewrite.
2. **Patterns:** rewrites that compile well, with code, plus negative results.
3. **Guardrails:** graph budget, gating, AC, correctness in bf16 and fp32, measurement traps on a shared GPU.
4. **Output:** a stack of small PRs ordered by impact, a findings doc, a PR template.
5. **Unchanged:** no runtime code.

**How it was validated**
1. Agents followed it on upstream main; each run's feedback went back into the skill.
2. Results, 2-layer fwd+bwd at 16k packed tokens, 1x GB300, upstream regions -> stack:
```text
Kimi K3       304.6 -> 192.2 ms  (-37%)
DeepSeek-V3   184.5 -> 159.6 ms  (-13.5%)
DeepSeek-V4   240.1 ->  75.1 ms  (-69%)
GPT-OSS 20b    35.1 ->  24.2 ms  (-31%)
```

**Test plan**
Docs only, no runtime change.
