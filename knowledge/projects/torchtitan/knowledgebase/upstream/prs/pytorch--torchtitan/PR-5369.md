# [CI] Fix stale HybridEP test selectors

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5369) · state: closed · merged: True

## Original PR description

Fixes #5364.

The H100 integration and release validation scripts still selected and excluded `deepseek_v3_fsdp+hybridep+compile` after the test was renamed to `deepseek_v3_fsdp+hybridep`. The stale exclusion ran HybridEP before its dependency was installed, and the stale selection ran zero tests afterward.

Update `--exclude` and `--test_name` in both scripts to the registered test name. HybridEP is excluded from the base phase and selected after `/install_deepep.sh`. This PR changes only those four selectors.

Validation:
- CPU checks using the registered H100 suite and existing test filter confirm that both scripts select DeepEP v2 and HybridEP exactly once, each after its matching installer.
- `python -m pytest tests/unit_tests/cpu/test_integration_test_definitions.py -q`: 19 passed.
- `pre-commit run --all-files`: passed.
- `bash -n` for both changed scripts and `git diff --check`: passed.
- Pending: exact 8x H100 script and HybridEP forward/backward. The local host has 4x GB300 and does not have the CI image's `/install_deepep.sh`.
