## Original PR description

## Summary
CONTRIBUTING.md's "Loss" validation guidance tells contributors to fix seeds with `training.seed` and `training.deterministic`. Those fields no longer exist on `TrainingConfig`; they live on `DebugConfig` (`torchtitan/config/configs.py`), exposed as `config.debug.seed` / `config.debug.deterministic`. This updates the one line so the numerics-equivalence instructions point at real config fields.
