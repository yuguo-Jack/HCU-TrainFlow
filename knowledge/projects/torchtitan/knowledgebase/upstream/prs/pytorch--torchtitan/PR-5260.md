# Add an opt-in DeepSeek V3 shared-expert autograd override

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5260) · state: open · merged: False

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #5261
* __->__ #5260
* #5259
* #5258

Fuse the W13 GEMM, BF16 SwiGLU and hidden MXFP8 quantization for the
4096-token, 7168-wide, 2048-hidden shared expert. Fuse W2 DGRAD, SwiGLU
backward and packed-gradient quantization separately, retaining native dx
and both WGRAD GEMMs.

Use the recipe override interface, explicit autograd and separate custom
operator/Gluon kernel layers. Preserve W2's FSDP module boundary, gradient
hook order, native accumulation, save policies and checkpoint keys.

Port the handoff to the public MXFP8/FusedSwiGLU numerical contract.
Keep both flags off and ACCEPTED=False: bitwise checks pass, but the
independent p90 roof fractions of 81.3%/61.2% do not meet the 90% gate.

Validation includes raw-bit checks, FSDP128 FakePG ranks 0/127,
compilation and CUDA replay.
GB300 complete shared-FFN streaming F+B: 480.64 -> 468.42 us (2.54%).
Keep CPU/GPU tests in-tree and research benchmarks/docs external.

Validation: 224 tests and 30 subtests pass across the four-commit stack.

All non-Pyrefly lint hooks pass. The all-files type check reports the
same eight baseline dependency/API errors. Clean-wheel validation passes.
