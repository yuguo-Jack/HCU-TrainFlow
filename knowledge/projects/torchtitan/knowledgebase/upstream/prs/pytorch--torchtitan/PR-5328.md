# [pipeline] Add minimal model-owned shared-parameter hooks

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5328) · state: open · merged: False

## Original PR description

## Agent details

Prepared with AI assistance.

Model-owned physical replicas need synchronization after initialization/loading and gradient combination before clipping. Three private no-op hooks expose only those lifecycle boundaries and logical norm selection. Count logical parameters once while clipping every physical copy, preserving the ordinary optimizer path.
