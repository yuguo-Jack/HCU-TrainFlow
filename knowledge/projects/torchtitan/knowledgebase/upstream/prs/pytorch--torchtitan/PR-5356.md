# [Linear] Ignore inplace_wgrad_accum under torch.compile instead of raising

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5356) · state: closed · merged: False

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.18.0) (oldest at bottom):
* __->__ #5356

Raising under Dynamo never reaches the user: Dynamo treats the exception as a
graph break and reruns the frame eagerly, where the check passes. The forward
then mixes compiled and eager Linears, and activation checkpointing's recompute
diverges from it (CheckpointError in whole-model torch.compile + FullAC).

- uses_inplace_wgrad_accum returns False under Dynamo; the graph traces F.linear
- Keep the make_fx (GraphTrainer) raise, which does propagate
- Tests: compiled Linear/HiMidLo grads match flag off; FullAC + compile regression
