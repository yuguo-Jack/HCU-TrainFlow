Fix RL CPU test collection after #5375: `test_search_r1.py` imports `Controller` from `torchtitan.rl.controller`, whose package initializer does not export the class. Import it from its defining module, `torchtitan.rl.controller.controller`, matching the RL recipes.

Validation:

- All non-Pyrefly pre-commit hooks passed. Full-tree Pyrefly reported 54 existing local dependency/type errors; unrelated automatic edits were reverted.
- Local pytest advanced past the corrected import but is blocked by the older PyTorch 2.14 environment, which lacks `analyze_pipeline_activation_liveness`; validation with the CI nightly is pending.

Fixes the collection error in [main RL CPU CI](https://github.com/pytorch/torchtitan/actions/runs/38784083853/job/116591530714).
