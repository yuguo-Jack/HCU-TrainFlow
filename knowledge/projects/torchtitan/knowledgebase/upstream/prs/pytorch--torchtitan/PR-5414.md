## Original PR description

Related to #2354.

## Summary
The gpt-oss README listed supported features as bullets but did not have a Supported Parallelisms table like other model READMEs (llama3, DeepSeek-V3 #5379, Qwen #5378).
This PR adds that section covering FSDP/HSDP, TP, EP, CP, PP (Interleaved1F1B CI),
and the FlexInnerAttention zero-bubble limitation already documented in the README.

Docs-only change.
