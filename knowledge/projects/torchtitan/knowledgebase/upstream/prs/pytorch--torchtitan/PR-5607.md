# [attention] Put varlen windows in metadata

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5607) · state: closed · merged: True

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #5071
* __->__ #5607

**Human Summary**
This PR makes VarlenAttention interface aligns with FlexAttention. The main refactor is to move window_size to VarlenAttentionMetadata, aligning with FlexAttention that the metadata describes the attention mask logic.

**Agent Summary**
Keep window limits in attention metadata for both Flex and varlen. Full and sliding varlen attention share one forward path.

- Add window_size=(left, right) to VarlenAttentionMetadata.
- Add SlidingWindowVarlenInnerAttention and its Ulysses variant.
- Use sliding_window_size for both sliding backends. It counts visible tokens, including the query. A value of 4 becomes (3, 0) in varlen metadata.
- Update affected model configs, recipes, and vLLM window conversion.
- Test metadata sharing, window masks, precision, and CUDA Graph replay.
