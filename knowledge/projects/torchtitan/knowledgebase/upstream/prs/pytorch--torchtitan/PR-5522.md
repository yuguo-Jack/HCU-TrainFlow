# [moe][perf] Triton routed experts: kernels read the routes, no dispatch (2/3)

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5522) · state: open · merged: False

## Original PR description

**TLDR:** `triton_routed_experts_op` runs the no-grad routed experts as Triton kernels that read each token's routes directly: no dispatch copy, SwiGLU fused into w13, one fp32 combine. This PR runs it only when all experts are local (no RL recipe does); position 3 runs it at EP > 1 behind DeepEP: 0.71-0.82x the time of DeepEP expand + stock GEMMs at EP = 4.

**Stack** (3 PRs, merge bottom-up; this PR is in **bold**)

| # | PR | Independent? | Needs (stack positions) |
|---|---|---|---|
| 1 | Triton grouped GEMMs for the no-grad expert MLP, any dispatcher | yes | — |
| **2** | **Triton routed experts: kernels read the routes, no dispatch** | **no** | **1** |
| 3 | DeepEP at EP > 1: send each token once per rank | no | 2 |

**Problem**
1. **Today.** The dispatcher copies each token once per route into expert-sorted rows before the expert GEMMs.
2. **After the experts.** Each row is scaled by its score and the rows are summed back per token, rounding to bf16 per route.
3. **Position 1** makes the GEMMs faster but keeps the copy and the per-route combine.
4. **Cost.** No EP = 1 number (no recipe runs it); position 3 measures the EP > 1 path.

**Solution**
1. **Op.** `triton_routed_experts_op(x, scores, ids, w13, w2, ep_rank=0, ep_size=1)` runs four steps (below).
2. **EP > 1.** An id in `[ep_rank * E, (ep_rank + 1) * E)` (E = local experts) becomes a local id; another rank's expert or padding (-1) adds nothing. A compile-time flag, so EP = 1 runs the same kernels.
3. **Module.** `TritonRoutedExperts.forward` calls the op when all experts are local, position 1's gate holds and there is no output postprocess; otherwise position 1's path.
4. **Counts.** This path returns `None` from `count_tokens`, skipping a `(T, E)` bool sum per layer.
5. **Unchanged.** Training (grad on) runs the previous path.

```text
x, ids -> [route sort] -> [w13 + SwiGLU: reads x at each route's token] -> [w2: one row per route] -> [combine: sum score*row per token in fp32, round once]
```
