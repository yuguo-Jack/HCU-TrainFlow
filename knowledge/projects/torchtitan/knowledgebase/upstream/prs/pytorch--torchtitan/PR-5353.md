# Make graph capture backend-agnostic with torch.accelerator

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5353) · state: open · merged: False

## Original PR description

This PR makes the training step graph wrapper work on any accelerator instead of only on cuda. Currently, the wrapper calls torch.cuda directly, so supporting another backend, such as xpu means keeping a near-duplicate module, which has to track every change to the CUDA version and regressions over time. Pytorch offers a device generic torch.accelerator.Graph, so one wrapper can serve every backend that registers a graph implementation. 

torchtitan/distributed/cuda_graph.py becomes accelerator_graph. However, a new torchtitan/distributed/cuda_graph_backend.py module is added because cuda does not register a graph implementation with pytorch; it plugs into a new register_graph_backend and keeps cuda using torch.cuda.graph, which also preserves the kernel annotations needed by the  profiler.
