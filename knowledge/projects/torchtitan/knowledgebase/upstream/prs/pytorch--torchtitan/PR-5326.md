# [validation] Reuse validation data loaders deterministically

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5326) · state: open · merged: False

## Original PR description

Prepared with AI assistance.

Rebuilding validation input pipelines discards worker and source state every event. Retain the configured loader and restart its initial Grain cursor with shuffling disabled. Preserve each submodule's prior training/evaluation flag, including mixed-mode models, on both success and failure. Close retained resources at the owning lifecycle boundary. Restart is an explicit contract, not a rebuilding fallback.

```bash
python -m pytest tests/unit_tests/cpu/components/test_validator.py tests/unit_tests/cpu/components/data/test_grain_data.py -q
```
