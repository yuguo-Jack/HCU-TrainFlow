# [CI][lint] Fix torch_checkpointing 0.1.1 callback type

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5599) · state: closed · merged: True

## Original PR description

## Summary

Adapt the HF final-save callback to the `torch_checkpointing==0.1.1` callback API.

- Accept a single `CallbackArgs` object.
- Read the staged checkpoint directory from `args.path`.
- Update both the real-backend contract test and mocked final-save test.

## Root cause

#5596 replaced the previous Git commit dependency with the published `torch_checkpointing==0.1.1`. That release changed `pre_finalize_callback` from `Callable[[str, EventLogger], None]` to `Callable[[CallbackArgs], None]`, while TorchTitan still implemented the old two-argument signature.

This caused the Pyrefly failure and would also fail at runtime when the HF final-save callback was invoked.
