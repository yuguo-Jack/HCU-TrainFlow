# [rl] Add Qwen3-30B-A3B DAPO math config

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5598) · state: closed · merged: True

## Original PR description

**Summary:** Add two configs for Qwen3-30B-A3B DAPO math, one for bf16 and one for mxfp8. The mxfp8 config uses
`mxfp8_mega_fused_inference=True` for faster decode.

**Test Plan:**

End-to-end runs:

```
# mxfp8
python -m torchtitan.rl.train \
  --module torchtitan_recipes.rl.dapo_math \
  --config rl_dapo_qwen3_30b_a3b_math_8k_mxfp8 \
  --output-dir /tmp/qwen3_30b_a3b_math_8k_mxfp8

# bf16
python -m torchtitan.rl.train \
    --module torchtitan_recipes.rl.dapo_math \
    --config rl_dapo_qwen3_30b_a3b_math_8k \
    --output-dir /tmp/qwen3_30b_a3b_math_8k
```

Run configuration:
- 4x B200 trainer, DP4/TP1/EP4
- 4x B200 generator, DP4/TP1/EP4
- `num_prompts_per_train_step` = 32
- `num_samples_per_prompt` = 16
- 8K responses, 50 steps
- `mxfp8_mega_fused_inference=True` for mxfp8 run

Results:

| Steps 3-50 | BF16 | MXFP8 | MXFP8 vs BF16 |
|---|---|---|---|
| Step time | 24.3 s | 22.7 s | 1.07x faster |
| Forward/backward | 8.1 s | 8.2 s | about the same |
| Waiting for rollouts | 15.8 s | 13.6 s | 1.16x faster |
| Generator decode time per request | 20.2 s | 17.8 s | 1.14x faster |
| Generator queue time per request | 59 ms | 53 ms | effectively no queuing for either |
| Rollout reward, steps 3-50 / last 10 | 0.297 / 0.356 | 0.289 / 0.346 | -0.01 |
| AIME validation, before -> after | 0.10 -> 0.20 | 0.067 -> 0.17 | both +0.10 |

For larger speedups, increase concurrency by increasing:
- `num_prompts_per_train_step` = 32 -> 256
- `num_samples_per_prompt` = 16 (unchanged)
- `max_num_seq` [cap](https://github.com/pytorch/torchtitan/blob/5ca13c7332d667b954d5981765242e9f0456c141/torchtitan/rl/controller/controller.py#L602) = 512 -> 8192
- mxfp8 speedup: 1.12x step time, 1.16x decode time per request
