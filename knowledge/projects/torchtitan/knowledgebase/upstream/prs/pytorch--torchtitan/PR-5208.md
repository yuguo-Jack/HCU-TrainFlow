# [graph_trainer] Accumulate PP gradients in backward graphs

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5208) · state: closed · merged: True

## Original PR description

PP previously returned each microbatch parameter gradient to Python for accumulation.

Use one accumulating graph per PP backward path and stage. The first executed backward for each stage in a step zeroes its persistent accumulators; every full, split-dW, and multiplexed backward updates and returns the same handles; REDUCE_GRAD consumes the final handles once.

With the shared add-chain support from #5119, supported WGrad producers fuse into the accumulator when enabled. Unsupported producers retain explicit add_.

Validation: 90 focused WGrad and GraphPP runtime tests passed.
