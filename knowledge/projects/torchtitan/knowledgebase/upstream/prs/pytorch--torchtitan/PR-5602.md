# [release/0.4][CI] Use TorchAO nightly for CPU validation

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5602) · state: closed · merged: True

## Original PR description

## Summary

Align release CPU validation with main CI by installing TorchAO from the CPU nightly index while keeping Torch 2.15.0, TorchVision 0.29.2, and Triton 3.9.0 fixed.

The full CPU unit suite exercises NVFP4 grouped and MXFP8 APIs that are not present in `torchao==0.18.0`. This caused collection to fail before any tests ran. Main CPU, GPU, and integration CI already test against TorchAO nightly.

## Validation

- `pre-commit run --files .github/workflows/validate_rc.yaml`
- Imported the previously missing `nvfp4_grouped_mm` API from `torchao==0.19.0.dev20261023+cpu`
- `pytest tests/unit_tests/cpu/quantization/test_quantization.py -q` (63 passed)
