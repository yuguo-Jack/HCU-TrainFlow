# Add experimental Peri-LN support

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5612) · state: open · merged: False

## Original PR description

## Summary

This PR adds experimental support for Peri-Layer Normalization (Peri-LN) to TorchTitan.

I'm one of the authors of the Peri-LN paper, and I'd like to contribute an implementation that makes it easier to experiment with Peri-LN in TorchTitan.

## Changes

- Add a Peri-LN model implementation under `torchtitan/experiments/peri_ln/`.
- Add training recipes and documentation.
- Add CPU and GPU test code.
- Add a GitHub Actions workflow for CPU tests.
- Reuse existing TorchTitan infrastructure where possible.

## Feedback

Feedback on the implementation and its integration with TorchTitan would be greatly appreciated. I'm happy to make adjustments based on maintainer suggestions.

Thank you for considering this contribution!
