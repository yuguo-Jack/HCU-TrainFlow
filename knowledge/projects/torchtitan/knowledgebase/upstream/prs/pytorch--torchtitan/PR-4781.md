# [DistMuon] Accelerate NS SYRK with optional QuACK symmetric GEMM

[Upstream PR](https://github.com/pytorch/torchtitan/pull/4781) · state: open · merged: False

## Original PR description

### Motivation

DistMuon Newton-Schulz currently computes Gram matrices using PyTorch GEMM:

```python
G = X @ X.T
G2 = G @ G
```
Because both outputs are symmetric, QuACK's triangular symmetric GEMM kernel may reduce redundant computation.
This PR add an optional QuACK-backed path for DistMuon `X @ X.T` and `G @ G` acceleration, and keep the final `G_update @ X` operation on the PyTorch path. Also, the PyTorch bmm is kept as a fallback path.

### Benchmark

**Gram computation on Kimi K3-sized BF16 matrix shapes**

| Shape | PyTorch `bmm` | QuACK Gram | Speedup |
|---|---:|---:|---:|
| 1536 x 7168 | 0.2650 ms | 0.1356 ms | 1.95x |
| 18432 x 1536 | 7.4040 ms | 3.8504 ms | 1.92x |
| 12288 x 7168 | 15.3946 ms | 7.8265 ms | 1.97x |
| 7168 x 12288 | 9.4786 ms | 4.6829 ms | 2.02x |
| 3072 x 3584 | 0.4954 ms | 0.2679 ms | 1.85x |
| 3584 x 3072 | 0.5681 ms | 0.3438 ms | 1.65x |
| 7168 x 6144 | 4.7480 ms | 2.3577 ms | 2.01x |

**Full single-step Newton-Schulz speedup**

| Shape | PyTorch | QuACK | Speedup |
|---|---|---|---:|
| 1536 x 7168 | 0.6288 ms | 0.4704 ms | 1.34x |
| 3072 x 3584 | 1.5000 ms | 1.0773 ms | 1.39x |
| 7168 x 6144 | 15.0613 ms | 9.8875 ms | 1.52x |
