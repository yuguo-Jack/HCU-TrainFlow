# [KimiK3 Perf] Add local compilation and overrides fla kernel for Kimi attention residual

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5033) · state: closed · merged: True

## Original PR description

## Summary

- Add local compilation for Kimi K3 attention-residual aggregation.
- Add an opt-in fused Triton override adapted from Flash Linear Attention.

## Performance

### Real Kimi K3 operator shape

Single H100, BF16, forward + backward, `[T_local=2048, N=8, D=7168]` with a partial residual (9 effective sources). Speed: two runs/path, 25 warmups + 100 measurements/run. Memory: median incremental peak allocated over 20 cache-warmed measurements.

| Path | Median time | Speedup vs eager | Speedup vs local compile | Incremental peak | Memory vs eager |
| --- | ---: | ---: | ---: | ---: | ---: |
| Eager | 10.544 ms | 1.00x | - | 2.980 GiB | - |
| Local compile | 2.470 ms | **4.27x** | 1.00x | 1.351 GiB | **-54.7%** |
| Handwritten Triton | 0.723 ms | **14.58x** | **3.41x** | 0.328 GiB | **-89.0%** |

### Kimi K3 debugmodel end-to-end

Single H100, BF16, 2,048 tokens/step, SelectiveAC, CUDA graphs disabled. TPS: two 20-step runs/path, combined median of steps 4-20 (34 samples). Memory: maximum over steps 4-20 of a cache-warmed run. "Eager" disables only the attention-residual compile region.

| Path | Median TPS | Speedup vs eager | Speedup vs local compile | Peak active/device | Peak reserved/device |
| --- | ---: | ---: | ---: | ---: | ---: |
| Eager | 4,570 | 1.000x | - | 0.764 GiB | 0.898 GiB |
| Local compile | 4,795 | **1.049x** | 1.000x | 0.710 GiB (-7.0%) | 0.820 GiB (-8.7%) |
| Handwritten Triton | 4,627 | **1.012x** | 0.965x | **0.691 GiB (-9.5%)** | **0.803 GiB (-10.7%)** |

## Correctness

- Compiled and Triton forward/backward are checked against the eager same-dtype reference and an FP64 oracle for both partial-residual branches.
- Compiled output and input gradients are bitwise deterministic and batch invariant.
- 4-GPU Kimi debug training with FSDP+TP+EP and SPMD typechecking completed 10 steps; loss and grad norm matched across all ranks.
- `pytest -q tests/unit_tests/cpu/test_kimi_k3_config.py tests/unit_tests/gpu/test_kimi_attention_residual_override.py tests/unit_tests/gpu/test_kimi_k3_attention_residual.py tests/unit_tests/gpu/test_kimi_k3.py`
  - 12 passed, 10 subtests passed
