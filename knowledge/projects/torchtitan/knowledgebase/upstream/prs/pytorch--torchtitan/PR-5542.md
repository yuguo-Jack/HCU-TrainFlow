# [graph_trainer] Overlap HybridEP and paging across combined PP graphs

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5542) · state: open · merged: False

## Original PR description

## AI-Generated Details

Prepared with Codex from the author's GraphPP multiplexing design.

Interleaved1F1BCombined uses the companion native PyTorch schedule:
https://github.com/pytorch/pytorch/pull/201439

Multiplex independent forward/backward graphs without EP token chunking or
capacity division. Explicit source annotations preserve ownership and positional
ABI. Consume the earlier native request/input validator, tensor/mutation
dependencies and page FIFO/lifetime contracts. Existing pipeline code retains
receives, unshards, sends, gradient accumulation and callbacks.

Communication launches, including paging, prefer ready complementary-source
work among equally ranked nodes. The shared early-launch/late-wait scheduler
prefers launch-enabling compute over unrelated wgrad; no second scheduler or
timing heuristic. Consume the earlier high-priority streams, operation-only
resource controls, vectorized pager, live-prefix calibration and no-AC policy
unchanged. The eager terminal-wgrad reservation is empty for unchunked PP.
This update only rebases the PP consumer; it does not overwrite those owners.

Native varlen Flash selects FA4 on Blackwell. DualPipeV retains its native
two-stage-per-rank V mapping, full backward for combined actions and separate
dI/dW for bubbles. dI retains the required live-ins until dW produces parameter
gradients. There is no copied schedule, patched backend or synthetic acceptance
path. DeepEP and full-graph Inductor remain excluded.

Full-step CUDA capture includes every microbatch's distinct routing state.
The native experimental `graph_capture_record_stream_reuse` setting releases
storage only after graph dependencies prove asynchronous uses joined; keep it
equal in both arms. It does not replace annotations, ownership or waits.

CUDA graphs; 60 steps, throughput 11-50, profiler 59-60 and snapshot 60.

overlap-only 32/64-GPU runs remain pending. PyTorch is unchanged; owned lint/doc
