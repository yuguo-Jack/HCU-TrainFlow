# .gitignore: ignore .monarch/ and structured_logs/

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5462) · state: open · merged: False

## Original PR description

Ignore `.monarch/` (Monarch's job API writes `.monarch/job_state.pkl` and its logs into the launch directory) and `/structured_logs/` (written there when the dump folder is the repo root). Both have been committed by accident, and a committed `job_state.pkl` can break the next launch from a checkout of that commit.

NOTE: prevention only. Upstream launchers don't use Monarch's job API, and the default dump folder (`outputs/rl`) is already ignored.

**Test plan**
```
$ git check-ignore -v .monarch/job_state.pkl structured_logs/x.jsonl
.gitignore:56:.monarch/	.monarch/job_state.pkl
.gitignore:57:/structured_logs/	structured_logs/x.jsonl
```
On main the same command prints nothing (exit 1). A nested `torchtitan/rl/structured_logs/y.jsonl` stays unignored: the pattern is anchored to the repo root.
