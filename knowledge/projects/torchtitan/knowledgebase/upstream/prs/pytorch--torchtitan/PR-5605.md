# [release/0.4][CI] Stabilize LoRA chunked loss test

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5605) · state: closed · merged: True

## Original PR description

## Summary

Use deterministic, bounded decoder outputs in the LoRA chunked-loss unit test instead of running an unrelated FlexAttention decoder forward.

## Why

The test is intended to validate head-only LoRA/chunked-loss values and adapter gradients. With PyTorch 2.15 on AVX2 CPU, the extra FlexAttention forward can produce non-finite outputs, so both reference and chunked losses become NaN before the behavior under test is exercised.

This keeps production code unchanged and does not add a contiguous workaround for the PyTorch issue.
