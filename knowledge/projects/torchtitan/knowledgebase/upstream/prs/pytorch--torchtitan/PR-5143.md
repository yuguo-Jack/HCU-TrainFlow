# [kimi] Update and Make Kimi K3 B200 numerics reproducible

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5143) · state: closed · merged: True

## Original PR description

## Summary

- Disable Attention Gym KDA autotuning when PyTorch deterministic algorithms are enabled; ordinary training still autotunes.
- Refresh the Kimi K3 10-step B200 loss and gradient-norm golden after the attention-residual initialization change in #4881.
- Keep the existing `kimi_k3_debugmodel_mm_muon` recipe and FSDP2/EP2 topology unchanged.

## Why

The old golden predates #4881, which intentionally changed Kimi K3 attention-residual projections from truncated-normal to zero initialization.

While re-exporting it, two otherwise identical deterministic B200 runs diverged after step 1. A back-to-back diagnostic on the same runner reproduced both traces: Attention Gym's KDA autotuner can select numerically different valid schedules based on benchmark/cache state. Deterministic mode now skips that benchmark-dependent choice and uses the default schedule, matching TorchTitan's existing handling for other autotuned attention kernels.

## Numerical source

- Back-to-back B200 export: https://github.com/pytorch/torchtitan/actions/runs/37752597252
- Config: `kimi_k3_debugmodel_mm_muon`
- Topology: FSDP2/EP2 on two B200 GPUs
- Steps: 10
- Metrics: full-precision TensorBoard `loss` and `grad_norm`
- Golden SHA-256: `a261836fb1c17635d71f2a04b81b882e9b60ba08f6229091393861dc33160ae5`

Both sequential exports were byte-for-byte identical.
