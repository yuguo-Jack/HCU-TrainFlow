# [moe][perf] Move EP tokens between rank-major and expert-major order with gathers

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5162) · state: open · merged: False

## Original PR description

**TLDR:** the AllToAll dispatcher's eager permute/unpermute become gathers: -5.3 ms per MoE layer at 16k on every EP>1 step.

**Problem**
1. **Permute today.** `AllToAllTokenDispatcher._permute` reorders received rows with `x[perm]`.
2. **Its backward.** An accumulating `index_put`: a sort plus a zero fill.
3. **Unpermute today.** `_unpermute` writes `out[perm] = y`, a non-vectorized scatter.
4. **Where.** This runs eagerly in the regional-compile recipes, outside any region, on every EP>1 step.
5. **Cost.** 9.36 ms per MoE layer at 16k (DSv3 EP2 rank).

**Solution**
1. **A permutation's inverse is a gather.** No accumulation is needed.
2. **`_PermuteRows`** gathers by the permutation and backpropagates by gathering with its inverse.
3. **`_unpermute`** gathers by the inverse.
4. **Unchanged.** TorchAO's padded `_unpermute`.

```text
before:  fwd x[perm]          bwd index_put accumulate (sort + zero fill)
         fwd out[perm] = y    (scatter)
after:   fwd x[perm]          bwd g[inv_perm]
         fwd y[inv_perm]
```

**Results**
```text
_permute + _unpermute fwd+bwd, DSv3 EP2 rank (128 local experts), R = 8T rows x 7168 bf16,
random balanced counts, GPU kernel us, median [range] of 3 processes
4k   eager  2377 [2376-2466] -> 1077 [1076-1077]    compiled 1155 -> 698
16k  eager  9357 [9349-9357] -> 4082 [4080-4083]    compiled 4738 -> 2774
=> -5.3 ms per MoE layer at 16k, -1.3 ms at 4k (not visible in the EP=1 2-layer harness)
correctness: bitwise (pure row moves)
graphs: n/a (eager path; under an outer compile the inverse permutation adds two small scatters)
```

You may ask: why not compile the permutes? The eager gathers are close to the compiled version.

NOTE:
- Reaches every MoE recipe with AllToAll EP>1 (deepseek_v3_671b uses EP=2).
- Not tested: a real multi-GPU EP run, GraphTrainer with EP, H100.

**Test plan**
`pytest tests/unit_tests/cpu/test_expert_parallel.py -k test_permute_and_unpermute_match_indexing_with_grads`
