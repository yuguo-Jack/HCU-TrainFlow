## Original PR description

* #5265
* #5264
* __->__ #5261
* #5259
* #5258

Fuse log-softmax/NLL reduction and its gradient with compact saved state.
Preserve native MTP weighting, chunking, normalization and TP fallback.

Keep Gluon kernels, custom operators, autograd and override in one file,
with one CPU test file and one GPU test file.

Recorded GB300 local CE F+B: 3.734 -> 0.554 ms. Bitwise checks pass;
forward reaches 68.1% of the measured roof, so model dispatch stays off.
