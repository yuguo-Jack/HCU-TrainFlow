# [graph_trainer][perf] Extract noAllGather FSDP1 parameter prep in UNSHARD for PP

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5392) · state: closed · merged: True

## Original PR description

In case of no-FSDP parameters include some preparation ops, that must be done only once.
E.g. quantization, casts.

We do not want to repeat them in every microbatch and extract them with  FSDP all-gather chains into UNSHARD action.

Previously we did not run this extraction for FSDP1 case which resulted in duplication of quantization in every microbatch action. 

This PR enables this extraction for PP and no FSDP.
