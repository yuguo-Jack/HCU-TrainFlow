# [ci][rl] fix two RL CPU tests broken by merge order

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5332) · state: closed · merged: True

## Original PR description

**TLDR:** RL CPU Unit Tests is red on main. Two PRs changed an API while a new test that uses it merged next to them, so the test never got updated. This PR fixes both tests: pass the now-required `release_session_fn` in the delta-prompt test, and read the Terminal-Bench training taskset from `training_dataloader.dataset`. Test-only.

**Problem**
1. **Delta-prompt test.** `test_delta_prompts_rebuild_the_full_prompt_samples` calls `RolloutWorker._run_single_rollout` directly.
2. The routing-session release PR (2/5) made `release_session_fn` a required keyword of that method. It merged ~1.5 h after the delta-prompt test, and its base did not have the test.
3. The test fails with `TypeError: ... missing 1 required keyword-only argument: 'release_session_fn'`. It is the only failure in RL CPU Unit Tests on main today (1 failed, 432 passed).
4. **Terminal-Bench test.** The prompt-data checkpoint PR renamed `Rollouter.Config.train_dataset` to `training_dataloader`, an `IterableRLDataLoader.Config` that wraps the same dataset config under `.dataset`. It updated the recipe, but not this test.
5. Two tests in `test_verifiers_terminal_bench.py` fail with `AttributeError: 'Config' object has no attribute 'train_dataset'`. CI does not see this: the file skips without its optional dependency, and the CI step that installs it runs only one other test from this file.

**Solution**
1. Delta-prompt test: pass a no-op `release_session_fn`. The other test in the file already checks one release per rollout.
2. Terminal-Bench test: `config.train_dataset` -> `config.training_dataloader.dataset`, in 3 asserts.
3. No library code changes.

**Test plan**
```
CUDA_VISIBLE_DEVICES= HF_HUB_OFFLINE=1 python -m pytest -q tests/rl/unit_tests/cpu
main:     3 failed, 458 passed, 5 skipped
this PR:  461 passed, 5 skipped
```
CPU only, with the Terminal-Bench test dependencies installed except `harbor`. The 5 skips: CUDA-only, dist_moe, `harbor` (x2), one TODO.
