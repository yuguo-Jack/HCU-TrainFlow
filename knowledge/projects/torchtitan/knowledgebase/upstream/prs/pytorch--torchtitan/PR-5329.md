[Upstream PR](https://github.com/pytorch/torchtitan/pull/5329) · state: open · merged: False

## Original PR description

## Agent details

Prepared with AI assistance.

Place MTP1 and an embedding replica on the final virtual stage, keep canonical checkpoint keys, and reuse pipeline_llm for construction and scheduling. Shifted IDs remain rank-local inputs; only hidden activations cross pipeline edges. Split the existing PP group collectively when only the two embedding owners need communication. GraphTrainer and pipeline context parallelism remain explicit future work.
