# [Attn] Remove SDPA and use Varlen attention in Flux

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5296) · state: closed · merged: True

## Original PR description

This PR removes the core SDPA backend and moves Flux and GraphTrainer recipes to shared Varlen attention, reducing the number of attention implementations to maintain.

Flux keeps its existing `[B, L, D]` activations and packs Q/K/V only at attention calls. Per-sample document boundaries are built once per forward, preserving bidirectional attention within each sample and isolation between samples. Under CP, K/V are gathered before packing.

## Tests

Full Flux-dev and Flux-schnell (11.89B parameters), 8 H100s, BF16, FSDP=8, CP=1, full activation checkpointing, 256x256 images. Each backend ran 20 training steps using randomly initialized weights, the CC12M test shard, and offline tokenizers.

Original SDPA (`3210be8297`) vs Varlen (`d2ddc8d2d5`), both cuDNN. PyTorch 2.14.0+cu130 / cuDNN 9.24; seed 42, TF32 off, deterministic=False, CUDA graphs off.

### Numerics

Maximum differences across 20 steps:

| Model | Max absolute loss difference | Max relative grad_norm difference |
| --- | ---: | ---: |
| Flux-dev | 3.06e-05 | 0.0341% |
| Flux-schnell | 1.80e-04 | 0.1305% |

Both loss traces pass `rtol=1e-3, atol=1e-5`; Schnell's grad_norm exceeds this tolerance. These runs are not bitwise identical.

Separate 10-step `flux-debug` regression, seed 42 and strict determinism, CP=1/2: outputs, loss, grad_norm, gradients, and final weights match the previous Varlen implementation (`0b34e4ea36`) bitwise.

### Performance

Median of steps 11-20, including data loading, encoders, forward/backward, optimizer, and communication; CUDA-synchronized wall time, slowest rank.

| Model | Per-GPU batch x sequence | SDPA/cuDNN (s/step) | Varlen/cuDNN (s/step) | Slowdown |
| --- | --- | ---: | ---: | ---: |
| Flux-dev | 32 x 768 | 4.5748 | 4.5895 | +0.32% |
| Flux-schnell | 64 x 512 | 5.6795 | 5.6832 | +0.07% |

Schnell's 0.07% difference is within the observed step-to-step variation (5-6 ms standard deviation).
