# [release/0.4] Add RL suites to release GPU validation

## Original PR description

## Summary

- Backport #5589 onto `release/0.4` to exercise the release-branch RL validation flow.
- Update the release CPU smoke test for the current TorchTitan model API.
- Keep non-RL validation on the stable `torchao==0.18.0` release.

The CPU smoke test imported `ScaledDotProductInnerAttention`, which was removed in #5296, and used the old model-config and batched-input APIs. The follow-up commits use the current config and packed-token APIs and validate a forward pass with the real FlexAttention backend. CPU FlexAttention does not support backward, so release GPU validation remains responsible for training coverage.
