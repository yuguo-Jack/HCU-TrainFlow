# [graph_trainer][precompile] Precompile SPMD gradient-accumulation graphs

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5211) · state: open · merged: False

## Original PR description

## Summary

Single-stage GraphTrainer with multiple microbatches currently builds its first, repeated, and last scheduled forward/backward graphs on every worker.

This change reuses the existing scheduled-graph builder during precompile, serializes those graph modules and their call specifications, and loads them at runtime after validating the existing config fingerprint and resolved execution plan.

It keeps the existing precompile inputs, single-graph artifact path, and `--virtual-local-rank` launch contract unchanged. DistMoE precompile is out of scope.

## Tests

- 145 focused GraphTrainer tests passed.
- FSDP two-microbatch precompile smoke test generated all three scheduled graphs.
- Targeted pre-commit hooks passed except repository-wide Pyrefly failures in unrelated files/environment APIs.
