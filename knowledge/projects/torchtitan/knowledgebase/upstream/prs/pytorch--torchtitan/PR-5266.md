# Make the vision encoder CP-invariant, only dp_shard

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5266) · state: closed · merged: True

## Original PR description

Vision encoders use CP-invariant state/activations and DP-only FSDP. Declarative output boundaries sum CP gradients; decoder FSDP remains DP x CP. Mixed-mesh clipping and dummy vision forwards support PP.

### Performance

`31608b80a`; 4x GB300, 447M Kimi K3 encoder, BF16, TP=1, 4 images / 1,024 patches per DP rank, deterministic seed 42. Encoder + indexed fusion + backward + AdamW; excludes decoder/data loading. Two trials, each 10 warmup + 30 measured steps.

Before (CP-replicated encoder, DP x CP FSDP) -> after:

| DP / CP | Median step (ms) | Peak allocated (GiB) |
|---|---|---|
| 2 / 2 | 110.1 -> 111.8 (+1.6%) | 3.93 -> 5.18 |
| 1 / 4 | 111.1 -> 121.9 (+9.7%) | 3.93 -> 8.36 |

Runtime traces confirm the groups below. Collective times are isolated CUDA-event measurements: 1.67 GiB FP32 reduce-scatter; 3.5 MiB BF16 CP all-reduce.

| DP / CP | FSDP reduce-scatter group size | Reduce-scatter (ms) | CP output-gradient all-reduce (ms) |
|---|---|---|---|
| 2 / 2 | 4 -> 2 | 2.14 -> 1.78 (-17%) | 0 -> 0.072 |
| 1 / 4 | 4 -> 1 | 2.14 -> 0 (no collective) | 0 -> 0.076 |

Collective timings exclude gradient packing/copies and training rank-arrival skew. Communication savings did not improve overall step time.

### Numerics

`1b0680885` -> `31608b80a`; seed 42, strict deterministic mode, 10 steps, identical initial weights. TP=EP=PP=1 below. Outputs/loss/norms checked on all ranks; full gradients/parameters reconstructed for rank-0 comparison across different FSDP meshes. Errors are maximum absolute differences over 10 steps.

| Kimi K3 workload | Precision | DP / CP | Loss diff | Grad norm diff | Bitwise identical? |
|---|---|---|---|---|---|
| Multimodal debug, images | BF16 | 2 / 2 | 0 | 0 | Yes |
| Multimodal debug, text-only | BF16 | 2 / 2 | 0 | 0 | Except signed-zero gradients |
| Multimodal debug, images | BF16 | 1 / 4 | 0.00997 | 0.03125 | No |
| 447M encoder | BF16 | 2 / 2 | 0.000237 | 0.00356 | No |
| 447M encoder | BF16 | 1 / 4 | 0.000225 | 0.00183 | No |
| 447M encoder | FP32 | 2 / 2 | 2.38e-07 | 1.79e-07 | No |

- Multimodal runs reload baseline initial weights: seed 42 alone changed 16 encoder parameter tensors at CP2.
- Text-only outputs, loss, norm and updated parameters are byte-identical; one gradient tensor differs only in `+0/-0` at seven steps.
- CP4 multimodal first-step gradients match, but grouped BF16 clipping changes grad norm `2.578125 -> 2.5625` (FP64 reference: `2.577139`). CP aggregation order also changes rounding in the standalone encoder.
- CP=1 controls remain bitwise identical: 76,868 comparisons across DP4/TP1 and DP2/TP2 encoders, plus DP2/TP2/EP2 multimodal training. Full-training convergence remains untested.

### Validation

- 38 CPU tests and 2 subtests pass.
- Muse 1F1B: PP2/DP2 (text-only and image-bearing ranks) and PP2/CP2 pass 10 steps, 4 microbatches/step; finite parameters and successful updates. Other schedules untested. Non-deterministic mode required by CUDA grid-sample backward.
- Changed-file format/lint pass; full pre-commit blocked by GitHub SSH authentication.
