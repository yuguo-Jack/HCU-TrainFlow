# Fix EP shape live-outs by keeping same-root AllToAll dim-0 queries chunk-local

[Upstream PR](https://github.com/pytorch/torchtitan/pull/4651) · state: closed · merged: False

## Original PR description

## Summary

Fix EP overlap chunking failures caused by dimension-0 shape queries on same-root AllToAll outputs. These queries could incorrectly trigger full-output materialization and raise:

```text
ValueError: Chunk pass cannot materialize live-out without chunk dimension
```

## Changes

- Keep same-root AllToAll dimension-0 shape queries attached to chunk-local outputs, avoiding unnecessary full-output materialization.
- Preserve existing materialization behavior for other consumers.
- Add a CPU-only FakeTensor/FX regression test exercising `ep_overlap_chunk_pass` with dispatch/combine AllToAll operations and a symbolic shape guard.
  - Reproduces the original error before the fix and passes afterward.
  - Verifies that only the combine output requires concatenation.
