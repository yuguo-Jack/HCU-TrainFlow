# [rl] Fix model-specific attention scaling in vLLM

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5347) · state: closed · merged: True

## Original PR description

The vLLM attention replacement does not include model specific softmax scales which makes GPT-OSS and DeepSeek lose their YaRN-adjusted scaling.

I just exposed the scale as a property on the attention config and threaded it through to vLLM. Not sure if this is how you’d want it done.

KL mismatch went from 0.055 before to 0.0006 with GPT-OSS-20b. I didn't test deepseek.
