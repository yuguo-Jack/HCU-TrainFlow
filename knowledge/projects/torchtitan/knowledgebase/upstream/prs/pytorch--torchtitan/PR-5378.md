# [Docs] Add Supported Parallelisms to Qwen3.6/Qwen3.8 READMEs

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5378) · state: open · merged: False

## Original PR description

Related to #2354.

## Summary
The Qwen3.6 and Qwen3.8 READMEs did not document supported parallelisms, while other model READMEs (llama3, qwen3_5, flux, ...) do. Both models reuse the Qwen3.5 model implementation and parallelization, so this PR adds a `Supported Parallelisms` section to each README with the same table as Qwen3.5 (EP scoped to each model's MoE variant) and a link back to the Qwen3.5 docs.

Docs-only change.
