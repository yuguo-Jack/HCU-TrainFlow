# [graph_trainer] Schedule eager HybridEP with explicit completion

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5539) · state: open · merged: False

## Original PR description

## AI-Generated Details

Prepared with Codex from the author's eager HybridEP overlap design.

Native routing handles survive through backward; a distinct request owns each
launch's completion. Dispatch/combine and their backward operations expose
graph-visible waits with every tensor input retained until completion. Input
record-stream ownership lives at the native adapter, so eager allocation and
CUDA replay use the same lifetime contract.

The eager chunk pass emits source annotations. The overlap pass validates
native target/phase/request ownership, launches the paired exchanges early,
and postpones waits behind independent work while preserving tensor and
mutation dependencies. Do not infer roles from node names or shapes.

Prime SimpleFSDP parameter getters outside chunk ownership and validate shared
unshard/reduction chains before bucketing. Remove obsolete count-sync tags,
process-group rewrites, and synthetic chunk fixtures. Capacity-based,
non-blocking HybridEP is required; DeepEP and full-graph Inductor are not part
of this feature. Existing regional attention compilation is retained.

## Test Plan

Real native routing/storage/alignment/token-drop/gradient contracts passed on
two GPUs. Real four-rank same-chunk control/overlap comparisons passed exact
loss and gradient norms with whole-F/B CUDA capture/replay. Final-stack graph
inspection verified unique completion requests, exact keepalives and shared
FSDP chains; built-in GPU profiles confirmed communication/compute overlap.

```bash
python -m pytest torchtitan/experiments/graph_trainer/tests/test_numerics.py -v -k 'hybridep_eager_overlap_and_paging or TestHybridEPContracts'
```

The final SPMD stack measured 40.175 -> 37.613 ms, a 1.068x EP-only throughput
improvement in one clean run: four GB300s, six-layer DeepSeek V3 debug model,
hidden256/routed-intermediate4096, global4096 tokens, micro2048, DPshard2/TP2/
EP2/PP1, capacity4, seed42/deterministic. Twenty steps, throughput11-20;
separate profiler windows9-10/19-20. This is not a production-model or universal
speedup claim. Async graph-pool reserved memory rose1.510 ->1.904GiB.

Chunked and unchunked training are not promised bitwise equal. Scheduling-only
checks compare the same chunks and capacities. The unchanged video lint
baseline remains outside scope.
