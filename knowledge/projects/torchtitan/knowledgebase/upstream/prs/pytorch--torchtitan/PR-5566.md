# [models] Add GLM-5.2 training support

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5566) · state: closed · merged: False

## Original PR description

## Summary

- add a device-independent GLM-5.2 decoder with DSA, MLA, MoE, checkpoint conversion, and released/debug flavors
- add FSDP, TP/SP, CP, PP, and EP integration through TorchTitan's common model interfaces
- add the official one-layer NextN/MTP training path, recipe, state-dict mapping, and loss integration
- add CPU contracts, distributed integration definitions, and a reduced Hugging Face numerical validation entry point

## Validation

- `pytest tests/unit_tests/cpu/models/glm5 tests/unit_tests/cpu/models/base/test_module.py -q` (`49 passed`)
- GLM base GPU smoke: eager, 2 steps, all registered 1-8 GPU topologies
- GLM MTP GPU smoke: eager, 2 steps, single/DDP/FSDP/HSDP/TP/CP/EP and supported combined topologies
- `git diff --check`
- recipe construction for base and MTP debug configs

## Notes

- GLM-5.2 DSA uses a FlexAttention `BlockMask`; packed-sequence `varlen` does not represent its learned per-query Top-K key selection.
- PP+MTP remains a documented TODO, matching the current common MTP pipeline limitation. PP is supported for the base model, and MTP is validated with the other supported parallelisms.
