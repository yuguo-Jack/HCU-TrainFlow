# Require a human-written summary in PR descriptions

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5694) · state: closed · merged: True

## Original PR description

## Summary (human-written)
Follow PyTorch's AI-assisted guideline to require a human-written
summary. Contributors should be responsible for and understand
AI-assisted PRs. A human-written summary is a minimum requirement
to justify this.

## What Changed
- PR template: add a "Summary (human-written)" section at the top.
- CONTRIBUTING.md: add an "AI-assisted contributions" section that follows the PyTorch AI policy (https://github.com/pytorch/pytorch/blob/main/AI_POLICY.md).
- .claude/CLAUDE.md (AGENTS.md): agents never fill in the summary and never post to GitHub without the user approving the exact content.
- pr-description skill: leave the summary placeholder for the author, including in ghstack commit messages.
- pr-review skill: a missing summary or a leftover placeholder is a must-fix. The reviewer does not guess whether a human wrote it.

A fresh agent with no context was asked to fix a docstring and commit with a PR-ready message. It left the summary placeholder, filled in the other sections, and told the user to write the summary.
