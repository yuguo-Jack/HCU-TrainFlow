# [Muse] Consolidate Muse Spark and Muse Glimmer vision encoders

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5444) · state: closed · merged: True

## Original PR description

Remove Muse Glimmer vision encoder implementation to use Muse Spark's.

One change in Muse Spark vision encoder to match the Hugging Face implementation.
`self.rope_theta ** (-torch.arange(0, half_dim, 2, dtype=torch.float32, device=device) / half_dim`
changed to
`1.0 / (self.rope_theta ** (torch.arange(0, half_dim, 2, dtype=torch.float32, device=device) / half_dim)`
which are mathematically same.

## Equivalence testing
- Local numerical comparisons: nine CPU and nine CUDA cases against the original towers using HF frequency arithmetic. CPU results matched exactly. CUDA outputs, input gradients, and non-positional parameter gradients matched exactly; positional gradients used tolerance.
- Ten deterministic CPU AdamW steps per tower: loss, gradient norm, and updated parameters matched exactly with seed 42.
- GPU validation: six FSDP/HSDP placement, conditional-image, and CPU-offload tests passed, plus two standalone FlexAttention encoder/adapter backward cases. The standalone harness was removed from the patch.
- Checkpoint loads correctly
