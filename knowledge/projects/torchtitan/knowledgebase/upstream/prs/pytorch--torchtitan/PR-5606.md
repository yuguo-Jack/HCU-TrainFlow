# [release/0.4][CI] Stage source-test assets for RC validation

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5606) · state: closed · merged: True

## Original PR description

## Summary

- Link the installed test-recipe asset root to the staged source-test assets.
- Stage the Flux README at the repository-relative path used by its documentation test.

## Why

RC validation installs TorchTitan from TestPyPI, copies source tests to a temporary directory, and unsets `PYTHONPATH`. The installed synthetic multimodal recipes therefore resolve assets below `site-packages`, while the assets exist only in the staged source-test tree. The Flux README test similarly expects a source-tree file that was not staged.

This changes only the release-validation harness. It does not modify production code, package contents, or test assertions.

## Test plan

- Targeted pre-commit hooks pass.
- [TestPyPI rc3 CPU validation](https://github.com/pytorch/torchtitan/actions/runs/40041471302):
  - Python 3.12: full validation passes.
  - Python 3.11: all four resource tests pass; 1891 tests pass and the only remaining failure is the LoRA/chunked-loss NaN addressed separately by #5605.
