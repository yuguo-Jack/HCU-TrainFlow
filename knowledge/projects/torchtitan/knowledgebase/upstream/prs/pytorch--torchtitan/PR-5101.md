# Move FullAC to torch_remat

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5101) · state: closed · merged: True

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.18.0) (oldest at bottom):
* #5102
* __->__ #5101

----

* FullAC is now a fixed RegionAC preset with `save_regions=[]`, so every
  activation-checkpointing policy runs on torch_remat and the
  `torch.utils.checkpoint` path is removed. Measured on Qwen3 MoE and
  DeepSeek V3 at EP4, activation and peak memory are unchanged, steps are
  5-6 ms faster (routing decisions are retained instead of replayed), and
  losses are bitwise identical.
* Replay no longer re-runs forward side effects under FullAC: the aux-loss
  metric and the expert token counts are counted once. The `// 2`
  correction for FullAC token counts is removed.
* Flux checkpoints its blocks with torch_remat instead of `checkpoint_wrapper`.
* The dynamo LRU-cache workaround for PyTorch checkpointing with PP and Flex
  is removed.
* FullAC now requires `preserve_rng_state=False` and rejects `debug=True`,
  like the other policies.
