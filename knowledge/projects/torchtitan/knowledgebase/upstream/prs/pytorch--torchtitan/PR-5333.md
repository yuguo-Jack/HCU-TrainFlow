# [DeepSeek V3] Report LM and MTP pipeline metrics

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5333) · state: open · merged: False

## Original PR description

## Agent details

Prepared with AI assistance.

Preserve the weighted training objective while reporting detached LM, unweighted mean MTP, and combined metrics through the generic structured pipeline result API. Accumulate normalized contributions over microbatches and loss-owning DP/CP ranks, and use the LM term as the canonical validation loss.

Depends on https://github.com/pytorch/pytorch/pull/200644 for plain `{"loss": tensor, "metrics": {...}}` results and the optional `loss_results` container. No public result class or separate loss callback is required. This draft intentionally depends on that unmerged API; it does not silently degrade when the provider is missing. Require one detached export per pipeline microbatch and consistent metric names before aggregation, so missing exports or terms cannot silently disappear. GraphTrainer remains out of scope.
