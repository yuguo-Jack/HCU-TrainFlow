# [graph_trainer][numerics] Defer FSDP persistent-grad cast after accumulation to do it once and match eager

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5118) · state: open · merged: False

## Original PR description

Currently we are casting every grad before accumulation into persistent-grad-dtype (fp32).
Eager does it only once after accumulation. 
This was resulting in different numerics.

Before:

```python
accumulator_fp32 += grad0_bf16.float()
accumulator_fp32 += grad1_bf16.float()
```

After, matching eager FSDP:

```python
accumulator_bf16 += grad0_bf16
accumulator_bf16 += grad1_bf16
final_grad_fp32 = accumulator_bf16.float()
```

Fixes https://github.com/pytorch/torchtitan/issues/5043
