# [qwen3] Use the published rope_theta for the 235B-A22B flavor

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5634) · state: closed · merged: True

## Original PR description

The `235B-A22B` Qwen3 flavor sets RoPE theta to 5e6 ([flavors.py#L722](https://github.com/pytorch/torchtitan/blob/89e4339c963c138188c69655929722df98ef8441/torchtitan/models/qwen3/flavors.py#L722)). The published [Qwen/Qwen3-235B-A22B config.json](https://huggingface.co/Qwen/Qwen3-235B-A22B/blob/8efa61729e24bd65b1d152b5ab5409052aa80e65/config.json) has `rope_theta: 1000000.0`, and so does the FP8 variant. 5e6 is the value of the [2507 releases](https://huggingface.co/Qwen/Qwen3-235B-A22B-Instruct-2507/blob/ac9c66cc9b46af7306746a9250f23d47083d689e/config.json), which also use `max_position_embeddings: 262144`. This flavor uses 40960, the original release's value. The 30B-A3B flavor already uses the original 1e6.

So a model loaded from the HF checkpoint gets different rotary frequencies than it was trained with. This sets theta to 1e6. I found this by reading and testing the code.

Comparison on CPU against transformers:
- The full flavor's RoPE cache is compared with `Qwen3MoeRotaryEmbedding` built from the published config.json.
- A 1-layer model keeps the flavor's attention and RoPE (dim 4096, 64 q / 4 kv heads, head_dim 128). Only the MoE (8 experts, top-2, hidden 256) and the vocab (2048) are shrunk. It is loaded into `Qwen3MoeForCausalLM` through `Qwen3StateDictAdapter`, with the same random weights and 1024 tokens.

| | main | this PR |
|---|---|---|
| rotary frequencies that differ | 63 / 64 | 0 / 64 |
| max \|cos/sin - transformers\| at position 1024 / 4096 / 40959 | 1.865 / 1.984 / 1.997 | 0 / 0 / 0 |
| attention output max abs diff (max \|hf\| = 5.57) | 0.735 | 1.4e-6 |
| logits max abs diff (max \|hf\| = 6.72) | 7.57 | 3.0e-2 |
| argmax agreement | 10.6% | 99.4% |

The logits don't match to fp32 precision in either case, because the routed experts run as a bf16 grouped GEMM in torchtitan. The attention output does match.

Note: a 235B-A22B model trained from scratch in torchtitan with the old value will see different rotary frequencies after this change.

`pytest tests/unit_tests/cpu/models/test_build_model_config.py` passes, and `pre-commit run --files torchtitan/models/qwen3/flavors.py` passes.

I made this PR and directed its development, with AI assistance from Claude and GPT-6 Astra.
