# Make TorchTitan compile backend configurable

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5463) · state: open · merged: False

## Original PR description

## Summary

Makes the compile backend configurable for TorchTitan local compile regions, FlexAttention, and block-mask helpers. `inductor` remains the default.

## User Example

```python
config.model.local_compile_backend = "custom_device_backend"
config.model.local_compile_regions = ["loss", "cos_sin_rope"]
```

## Before the Change

```text
model.parallelize(regions)
  -> apply_local_compile(regions)
  -> torch.compile(region)                    # implicit Inductor

module import
  -> torch.compile(FlexAttention, options=...) # implicit Inductor
  -> torch.compile(create_block_mask)          # implicit Inductor
```

## After the Change

```text
model config backend
  -> TrainingEngine: set_local_compile_backend(backend)
  -> process-wide backend
       |
       +-> apply_local_compile(regions)
       |    -> torch.compile(region, backend=backend)
       |
       +-> first FlexAttention use
       |    -> torch.compile(FlexAttention, backend=backend)
       |
       +-> first block-mask use
            -> torch.compile(create_block_mask, backend=backend)
```
