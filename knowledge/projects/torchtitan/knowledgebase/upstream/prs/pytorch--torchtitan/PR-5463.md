# Make TorchTitan compile backend configurable

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5463) · state: closed · merged: True

## Original PR description

## Summary

Makes TorchTitan's local compile configuration extensible for out-of-tree device backends.

- Replaces `model.local_compile_regions: list[str]` with `model.local_compile: LocalCompileConfig`.
- `LocalCompileConfig` contains `regions: list[str]`.
- Moves local compile binding into `LocalCompileConfig.apply()`.
- Keeps Inductor as the base implementation.
- Lets an out-of-tree backend subclass `LocalCompileConfig` to change the compilation behavior used by `apply()`.

## Motivation

TorchTitan owns several compile boundaries: named `@local_compile` regions, FlexAttention, and `create_block_mask` helpers. A caller can select a backend for a `torch.compile` call it owns, but that does not configure TorchTitan's internal compile sites.

The configuration object gives an out-of-tree backend one extension point without adding a backend name or backend-specific logic to upstream model configuration.

## Design

The model config contains a `LocalCompileConfig`:

```python
@dataclass(kw_only=True, slots=True)
class LocalCompileConfig:
    regions: list[str] = field(default_factory=list)

    def apply(self) -> None:
        ...
```

The base implementation uses PyTorch's default Inductor backend. `apply()` binds the selected named regions and TorchTitan's always-compiled FlexAttention and block-mask helpers.

An out-of-tree backend subclasses the config and overrides its static compile hook. The inherited `apply()` method then uses that backend-specific behavior for every TorchTitan-owned local compile boundary:

```python
class CustomDeviceLocalCompileConfig(LocalCompileConfig):
    @staticmethod
    def _compile(reference, **compile_kwargs):
        compile_kwargs.pop("options", None)
        compile_kwargs["backend"] = "custom_device_backend"
        return torch.compile(reference, **compile_kwargs)


config.model.local_compile = CustomDeviceLocalCompileConfig(
    regions=["loss", "rope"],
)
```
