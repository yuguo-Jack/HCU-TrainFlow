# [dsv4] Build sparse-attention metadata per layer variant; merge the inner-attention classes

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5722) · state: open · merged: False

## Original PR description

## Why

DeepSeek-V4 implements its three sparse-attention policies in one class, so `Decoder._get_attention_metadata` builds a single metadata entry for every layer. Geometry that depends on `compress_ratio` — `cu_seqlens_k`, the HCA causal block mask, and the doc-local to pool-index remap — is therefore rebuilt inside each layer, `Indexer.select` is a static method called from `attention.py` on the indexer's internal `idx_q / idx_k / idx_w`, and the compressor re-derives per-document grouping from packed offsets on every call.

## What changed

- **`models/deepseek_v4/attention.py`**: one `DeepSeekV4InnerAttention` holds the implementation, and three empty-`Config` subclasses (`SlidingWindow` / `HeavilyCompressed` / `CompressedSparse`) give each variant its own metadata key. `build_attention_metadata` returns `cu_seq_cmp`, `cmp_base_T` and `causal_cmp_TK` once per variant, so layers no longer derive offsets or masks, and every module forward takes that metadata instead of bare offsets. `cmp_k`, `topk_indices` and `topk_scores` are keyword-only, so a layer without a compressed pool passes `None` without leaving the local-SPMD contract.
- **`models/deepseek_v4/compressor.py`**: the selection now lives in `InnerIndexer.forward`, which returns `(topk_indices, topk_scores)`, and `topk` is a selector constant. Because documents are packed ratio-aligned, the compressor regroups the whole packed stream and no longer needs document offsets. One `compressor` replaces `compressor` / `compressor_128`.
- **`components/data`**: `document_alignment` pads each packed document segment to a multiple of the alignment. DeepSeek-V4 recipes set it to `max(compress_ratios)` and `build_attention_metadata` asserts it, which is what lets the compressor drop per-document grouping.

## Testing

- DSV4 unit tests, indexer-loss, state-dict adapter, dist-Muon recipe and text packing tests pass (39 tests).
- A two-step stripped debug model (512-token context, four layers covering ratios 1/1/4/128) runs end to end, both eager and with `debug.spmd_typechecking=True`. The typecheck run found two layout bugs — 3-D attention activations declared with the 2-D dense placement — that are fixed here.

Draft for early feedback on the direction; the CP prototype builds on it.
