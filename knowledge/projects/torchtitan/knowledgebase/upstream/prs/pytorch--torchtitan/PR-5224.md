# [dist_moe][precompile] Register block-scaled operators before context construction

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5224) · state: open · merged: False

## Original PR description

## Summary

Precompiled block-scaled DistMoE graphs can reference custom operators before the first eager routed-experts call that normally registers them.

When the resolved DistMoE context uses block scaling, register those operators before constructing the context so artifact loading does not depend on an earlier eager invocation.
