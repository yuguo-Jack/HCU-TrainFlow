# [tests] Remove redundant test snapshots and clarify review guidance

## Why

Reduce test maintenance by removing redundant coverage and checks that unnecessarily lock in implementation details, while preserving meaningful regression tests.

## What changed

- Remove **65 test functions**: 43 core CPU, 11 core GPU, 8 RL CPU, and 3 experiment tests. Parameterized functions are counted once; this is not a count of expanded pytest cases. The complete inventory and per-test reasons are below.
- Remove one redundant 8-GPU `features` integration entry, `3d`, and its now-unused config factory. Keep `pp_dp_tp`, which runs the same training configuration with checkpoint save/load.
- Extend the existing `.claude/rules/tests.md` guidance to reject private-layout snapshots and assertions that only repeat mock calls, and require naming retained coverage before deleting a redundant test. The PR-review skill already references this rule file.
- Mechanically move four fused-SwiGLU checkpoint/adapter tests from the GPU suite to `tests/unit_tests/cpu/recipes/test_fused_swiglu.py`; retain the two accelerator forward-parity tests in the GPU suite. Test bodies and decorators are unchanged. Existing CI discovers both directories, so no workflow edit is needed.
- Mechanically remove imports, helpers, empty classes and section banners left unused by deleted tests. Retained test function bodies and decorators are unchanged (AST comparison against `8e3da8b50b`).

Production code, recipes, numerical goldens and CI workflow files are unchanged. In particular, these semantic RL guards remain:

- `tests/rl/unit_tests/cpu/test_rl_dist_moe_recipe.py::test_rl_integration_recipe_runs_dist_moe_on_both_roles`
- `tests/rl/unit_tests/cpu/test_model_defaults.py::test_rl_recipes_get_model_defaults` (LM-head precision and frozen routing across recipes)

The B200 integration and CPU RL workflows still invoke those checks. Compiler-lowering checks, model/dataset geometry checks, numerical/gradient comparisons and real-collective coverage also remain. The MoE backend-selection, Qwen 27B full-rematerialization, DAPO thinking-mode, 671B precision/fusion, dataset absolute-path and Generator finalizer and profiler output-directory guards are retained.

The four moved tests are retained and are not included in the deletion count:

- `TestFusedSwiGLU.test_saves_native_layout_without_copy`
- `TestFusedSwiGLU.test_fused_roundtrip`
- `TestFusedSwiGLUDistGemmComposition.test_overlapping_variant_keeps_w13_checkpoint_layout`
- `TestFusedSwiGLUHFAdapter.test_hf_adapter_roundtrip`
