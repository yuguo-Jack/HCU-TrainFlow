# [release/0.4][CI] Test GPU validation with TorchAO nightly

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5609) · state: closed · merged: True

## Original PR description

## Why

TorchAO 0.18.0 fails during B200 test collection with Triton 3.9 because its FP8 MoE autotune key names a nonexistent kernel argument. The fix is available in TorchAO nightly.

## What

- Install the latest CUDA 13.0 TorchAO nightly for non-RL GPU release validation.
- Keep Torch 2.15.0 and TorchVision 0.29.2 pinned to the release-test index.
- Verify that the installed TorchAO build is a nightly development version.

## Validation

- `bash -n .github/scripts/validate_release_gpu.sh`
- `git diff --check`
- Nightly resolution dry run: `torchao==0.19.0.dev20261024+cu130`
- All available pre-commit hooks passed except Pyrefly, which could not run in the temporary environment because project dependencies such as Torch were unavailable.
