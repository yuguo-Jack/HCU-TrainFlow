# [release/0.4] Validate release candidates with PyTorch 2.15 RC

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5588) · state: closed · merged: True

## Original PR description

The release/0.4 validation workflows still install PyTorch 2.14.0. Update the CPU job and every GPU suite to validate TorchTitan 0.4.0rc1 against the PyTorch 2.15.0 release candidate from the official test wheel index.

- Pin torch to 2.15.0 and torchvision to 0.29.2. The selected torchvision wheels declare torch>=2.14.0.
- Pin CPU validation's Triton to 3.9.0, matching the CUDA 13.0 torch wheel's triton~=3.9.0 requirement. GPU validation continues to install Triton transitively through torch and import/log its version at runtime.
- Retain torchao 0.18.0, the latest version available on the selected test indexes, and the GPU test/cu130 index for the CUDA 13.0 runners.

Validation: inspected official wheel metadata; resolved the CPU package set for Python 3.11 and 3.12; imported the selected torch, torchvision, torchao, and triton packages on Python 3.12 with both CPU and CUDA 13.0 torch; verified the installed GPU Triton satisfies torch's requirement. YAML parsing, all four GPU version blocks, shell syntax, and pre-commit checks for the changed files passed.

Full GPU dependency resolution was blocked by this development environment's access to pypi.nvidia.com. Full RC training/CI was not run. The full-repository pre-commit run reports 61 type-check errors in unchanged Python files; its unrelated automatic edits were discarded.
