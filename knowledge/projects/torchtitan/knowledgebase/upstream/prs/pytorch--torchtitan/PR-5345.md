# [MoE] Organize common modules and unify feed-forward fields

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5345) · state: closed · merged: True

## Original PR description

Group common MoE, Dist-MoE and linear implementations into sibling packages. Use one required `feed_forward` field for dense and MoE configs and modules, with `DenseFeedForward` and `MoE` sharing a `FeedForward` base. Remove mutually exclusive fields and redundant flags, and update checkpoint mappings, optimizer paths and GraphTrainer selectors.

Native MoE checkpoint keys change from `.moe.*` to `.feed_forward.*`; HF checkpoint mappings remain compatible.

Validation: focused config, optimizer, checkpoint and fused-SwiGLU tests passed. For the latest hierarchy change, Llama3 dense and Qwen3 MoE matched initialization, loss, grad norm, gradients and updated weights bitwise over 10 deterministic steps. All non-Pyrefly pre-commit hooks passed; scoped type checks introduced no new diagnostics. Broader validation is limited by local dependencies/APIs, including a LoRA compile failure also reproduced before this change.
