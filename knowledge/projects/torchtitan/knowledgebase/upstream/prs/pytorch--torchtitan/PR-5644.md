# [rl][docs] README: list Muse Spark as supported (text only)

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5644) · state: closed · merged: True

## Original PR description

Adds Muse Spark to the RL model support table in `torchtitan/rl/README.md`.

Muse Spark runs end to end in TitanRL: the DAPO-Math GB300 recipe (`muse_spark_816b_a42b_dapo_math_gb300_config`, #5581) and the Muse Spark 816B SWE-rebench RL smoke on GB300 described there.

The row says "text only", as for Qwen 3.5: the generator's vLLM model wrapper sets `supports_multimodal = False` and drops the vision encoder (`torchtitan/rl/generator/vllm/model_wrapper.py`), so RL rollouts are text even though the model has vision and audio encoders.
