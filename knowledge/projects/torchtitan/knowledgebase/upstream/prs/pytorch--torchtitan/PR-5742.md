[docs] Clarify PyTorch library ownership

## Summary (human-written)
Agents are confused by what "PyTorch libraries" means. They may treat
meta-pytorch repos as non-pytorch repo and request changes if we
use repos in the core parallelisms, which violates one of the core
principal.

## Why
The dependency rule does not define PyTorch libraries. This can incorrectly exclude libraries such as meta-pytorch/attention-gym.

## What changed
- Count pytorch/pytorch and meta-pytorch repos as PyTorch libraries.
- Keep complex techniques upstream, in pytorch/pytorch or a suitable meta-pytorch repo.
