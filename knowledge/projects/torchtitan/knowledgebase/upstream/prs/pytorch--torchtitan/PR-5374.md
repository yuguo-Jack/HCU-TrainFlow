# [transformers_modeling_backend] Keep the Titan MoE output for HF's bare consumers

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5374) · state: closed · merged: True

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.18.0) (oldest at bottom):
* #5102
* __->__ #5374

The default remat policy saves the Titan MoE's last region: `combine` with
EP, `shared_add` with shared experts, or `tp_output_reduction` with TP and no
sequence parallelism. A saved region is skipped during checkpoint replay and
its output is a placeholder unless a consumer declares that it needs the data.
Titan blocks consume the MoE output with the retained `ffn_residual` add, which
replay also skips, but HF decoder layers read it with bare ops that replay
re-runs: Qwen3 MoE's `residual + hidden_states`, and Gemma4's post-feedforward
norm. transformers_modeling_backend_moe_fsdp+tp+ep+cp has failed in backward
since #4893:

    RuntimeError: layers.3::mlp.routed_experts.token_dispatcher.combine.out
    is a placeholder for the output of remat.region
    'layers.3::mlp.routed_experts.token_dispatcher.combine' (recompute=False)

`_HFBatchedMoE.forward` is the boundary where the output leaves Titan code, so
it declares the output with `remat.recompute_needs_tensor`, as REMAT.md
prescribes for consumers outside the owning module. The output is now kept
from the forward to the backward, which a bare HF consumer requires. The
backend wraps HF linears and attention without Titan regions, so the MoE output
is the only saved Titan output that HF code reads.

Test: a tiny HF DeepSeek-V3 model through the real probe, swap and module
conversion path, under the default policy. Its shared experts make the MoE
output the saved `shared_add` output, so it reproduces the failure on one GPU
without EP; with the fix, loss and gradients match no checkpointing bitwise.
transformers_modeling_backend_moe_fsdp+tp+ep+cp (8 GPUs) now passes, and over
5 seeded deterministic steps its loss and grad_norm match a run without
activation checkpointing bitwise.

Fixes #5363
