# Fuse DSv3 MLA norm, MXFP8 and RoPE with CuTeDSL

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5265) · state: open · merged: False

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* __->__ #5265
* #5264
* #5261
* #5259
* #5258

Fuse Q/KV RMSNorm with dual MXFP8 quantization, up GEMMs with RoPE/K
assembly, and backward rotation/packing with gradient quantization.
Keep native FSDP refill, gradient policy, accumulation and remat owners.

GB300, 4096 tokens / 128 heads, BF16 storage, FP32 weight gradients:
Q forward 168.54 -> 115.96 us;
Q F+loss+B 1475.96 -> 1389.80 us.
KV forward 123.32 -> 88.31 us;
KV F+loss+B 2194.45 -> 2058.26 us.
Local chain timings exclude attention and collectives. Peak allocated
memory is unchanged: Q 2186.47 MiB, KV 2558.85 MiB; reserved memory falls.

Bitwise checks pass, including compiled autograd and FakePG FSDP128.
Keep experimental/default-off: stages reach 27.1-83.2% of the independent
roof at p90, below the 90% gate. Requires CuTeDSL 4.8+ on the pinned runtime.

One self-contained override file, one CPU test file and one GPU test file.
