 ## Summary

Add optional validation CUDA graphs with `validator.enable_cuda_graphs=True`. Training, validation, and optimizer graphs share the existing memory pool. Capturing eval first lets its temporary buffers share storage with training gradients.

- Keep scheduled step 1 eval. After training and optimizer warmup, run eager eval, then captured eval. This allows us to reuse the memory, otherwise we will see memory jump during the warmup.
- Preserve memory reuse through `_CUDAGraphGradientState`.
- Prepare PP metadata outside capture and finish PP/FSDP eval cleanup.
- Wait for checkpoint staging before eval can update model buffers.
- Document tensor lifetimes in cuda_graph.md
