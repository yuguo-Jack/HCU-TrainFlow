# [Muse Spark Open] Match the updated published chat template

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5464) · state: closed · merged: True

## Original PR description

## Summary

`MuseSparkRenderer` reimplements the checkpoint's `chat_template.jinja` token by token. The published template on [meta-models/Muse-Spark-Open-816B-A42B](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B) changed on 2026-10-15 (revision `0fb02478`), and the renderer no longer produced the same prompts. This PR aligns it with that revision:

- **Reasoning strength:** `low` is 8 and `medium` is 32 (were 16 and 64). `high` (256) and `xhigh` (512) are unchanged. `minimal` is gone from the template, so `MuseSparkRendererConfig(reasoning_effort="minimal")` now raises, as the template does.
- **Function schemas:** a schema without `additionalProperties` gets `"additionalProperties": false` appended, and missing or empty `parameters` render as `{"type": "object", "properties": {}, "additionalProperties": false}`. Schemas that already set `additionalProperties` are kept as is. The template describes these lines as "as the training renderer prints it".

The template also adds namespace tools and deferred tool loading (`defer_loading`, `deferred_render_mode`). The renderer does not implement those yet.

## Verification

- Compared against the published template with transformers' `apply_chat_template` and the checkpoint's tokenizer, over 5 conversations (user only, system + reasoning, tools with one and two tool calls and results, special-character escaping) at `low`, `medium` and `high`:
  - before: 12 of 15 differed (reasoning strength and tool schemas);
  - after: 0 differences, in text and in token ids.
  - Against the previous template revision, the old renderer had 0 differences, so these two changes are the whole gap.
- New unit tests in `tests/unit_tests/cpu/models/muse_spark/test_renderer.py` (the gated template is not vendored, so they assert the behavior directly):
  - reasoning strength for each effort, and `minimal` rejected;
  - `additionalProperties` appended when missing, kept when present, and the empty-parameters schema.
- 5 tests fail without the renderer change and pass with it; the file passes (16 passed, 3 existing xfails).
