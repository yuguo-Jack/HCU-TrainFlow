# [Attn] Default compatible models to Varlen attention

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5307) · state: closed · merged: True

## Original PR description

Make Varlen the default for standard attention layers in Llama3, Qwen3/3.5/3.6/3.8, DeepSeek-V3, Kimi K3, and Muse Glimmer, including their GraphTrainer/TorchFT variants. Recipes inherit the model default instead of repeatedly specifying Varlen.

- **CUDA graphs:** add a shared C4 document-capacity estimate, `max(16, ceil(tokens_per_microbatch / 512))`, based on each recipe's per-rank microbatch token budget. Emit a warning so users can tune it for their data.
- **Dtypes:** preserve FP16/BF16 V tensors and match Q/K to V's dtype. Keep the existing BF16 conversion for FP32 callers.
- **Flex exceptions:** preserve Kimi-K2 QK clipping, existing golden tests, Flex-specific CP tests, H100 GraphTrainer tests, A10G DeepSeek MLA tests, and selected Qwen multimodal recipes. FA2 requires equal Q/K/V head dimensions, so it cannot run MLA's Q/K=192, V=128 layout through Varlen.

Flux and GPT-OSS already default to Varlen. Linear, sparse, and vision attention are outside this change.

### Testing

| Comparison | Coverage | Result |
|---|---|---|
| New defaults vs explicit Varlen | 8 debug models, 10 steps each | Bitwise-identical outputs, losses, gradients, and updated weights |
| Eager vs compiled/traced Varlen | FP16/BF16/FP32; 6 GPU tests | Exact outputs, losses, and gradients |
| FP32 path vs previous BF16 conversion | 1 GPU test | Exact outputs and gradients |
| Varlen vs FP64 SDPA | 8 forward/backward tests | Relative L2 error <0.1% for FP16, <1% for BF16 |
| Ulysses CP2 vs unsharded Varlen | FP16/BF16, MHA/GQA, documents crossing CP boundaries | Loss relative error <=0.001%; output/gradient relative L2 error <0.1% for FP16, <1% for BF16 |
| Flex vs Varlen | Llama3 on C4, 10 steps with CUDA graphs | Max relative difference: loss 0.26%, gradient norm 0.58% |

All 11 golden-test configurations match the PR base, and 400 microbatches match bitwise. Golden values are unchanged; the full GPU golden suite was not rerun locally. 58 CPU tests passed. Full pre-commit passed except for previously identified local Pyrefly errors.
