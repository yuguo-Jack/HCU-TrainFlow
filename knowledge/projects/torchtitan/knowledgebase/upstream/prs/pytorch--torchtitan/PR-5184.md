# [CP] Support Qwen3.5 GDN CP

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5184) · state: closed · merged: True

## Original PR description

## Summary

Enable context parallelism for Qwen3.5's hybrid GatedDeltaNet/full-attention
decoder and multimodal input path.

- GatedDeltaNet layers use Attention Gym's native context-parallel convolution
  history exchange and recurrent-state composition.
- Full-attention layers use K/V all-gather CP with contiguous or head-tail
  partitioning, or Ulysses CP with contiguous partitioning.
- Multimodal preprocessing shards vision-bank indices with token IDs so each
  rank can select the correct rows from replicated vision-encoder outputs.

GatedDeltaNet and full-attention layers share one TorchTitan CP mesh and token
partition.

## Implementation

The integration follows Attention Gym's
[delta-rule context-parallel example](https://github.com/meta-pytorch/attention-gym/blob/main/examples/linear/delta_rule_context_parallel.py).

The local GatedDeltaNet implementation exposes shared convolution and recurrent
stages. The CP adapter replaces only the distributed pieces:

- `context_parallel_conv_history` supplies each local Q/K/V convolution with
  the preceding tokens it needs; and
- `context_parallel_gdn` composes recurrent state across sequence fragments and
  runs the local GDN computation.

`GatedDeltaNetMetadata` carries packed-sequence offsets and per-batch CP routing.
TorchTitan's load balancers expose their token fragments, and
[`ContextParallelRouting.from_fragments()`](https://github.com/meta-pytorch/attention-gym/pull/576)
builds routing that matches the partition used to shard model inputs. Kimi K3
KDA now reuses the same routing path instead of duplicating partition logic.

## Limitations

- GatedDeltaNet CP supports contiguous and head-tail partitions; PTRR does not
  expose the contiguous token fragments required by the stateful kernel.
- Consequently, the Qwen3.5 hybrid model supports contiguous or head-tail
  K/V all-gather CP. Ulysses requires contiguous partitioning.
- Current TorchTitan partitioning requires equal-sized fragments, where `T` is
  the token count and `C` is the CP degree:
  - contiguous: `T % C == 0`
  - head-tail: `T % (2 * C) == 0`

## Tests

Tested on NVIDIA H100 GPUs with Attention Gym commit `f6d636e5` (merged
[attention-gym#576](https://github.com/meta-pytorch/attention-gym/pull/576)).

- Targeted unit tests: 80 passed, 2 subtests passed.
- Two-GPU, 10-step integration tests passed for both K/V all-gather and
  Ulysses CP.

Deterministic BF16 runs compared CP=1 with CP=2 at commit `1b100f404`, using
the same seed checkpoint (`seed=42`), 2,048 tokens per step, and 10 training
steps. CP=2 used Attention Gym CP for GatedDeltaNet and either head-tail K/V
all-gather or contiguous Ulysses for full attention. CUDA graphs were disabled
for all runs. Values come from full-precision TensorBoard metrics; diffs are
absolute percentages relative to CP=1. Collective reduction ordering changes,
so the trajectories are not expected to be bitwise identical.
