# [graph_trainer] Overlap chunk-owned paged stashing with HybridEP

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5541) · state: open · merged: False

## Original PR description

## AI-Generated Details

Prepared with Codex from the author's annotation-based paging overlap design.

Bind live counts, final-consumer stash commits and reloads to their layer and
eager chunk. Explicit source roles identify stash, reload/prefetch, completion
wait and stash join operations. Preserve the manager's queue/freelist order
and every copy input's lifetime while scheduling independent EP/compute work.

Represent immediate non-pipeline residency in the graph rather than hidden
runtime aliases. Separate host overflow monitoring from the GPU reset/full-F/B
callable, retaining deferred reporting and optimizer-skip behavior through
CUDA capture/replay. Native page-copy/pop kernels are unchanged.

## Test Plan And Results

Existing real pager round trips, lifetime, overflow and unpaged-read checks
passed. The four-rank production numerical family passed both overlap and
paging with full CUDA graphs. Twenty-step checkpoints matched all293 tensor
leaves, non-tensor state and full-precision loss/gradient-norm series exactly.

Actual graphs verified final grouped-GEMM commits, unique native waits and
keepalives; built-in GPU traces showed EP/compute, paging/compute and page/EP
intersections. There were no OOMs or allocation retries.

On the six-layer DeepSeek V3 debug model (hidden256, routed intermediate4096),
four GB300s, global4096/micro2048, DPshard2/TP2/EP2/PP1, capacity4, strict seed42:
the same-saving-policy no-page baseline reserved4.756GiB versus3.332GiB with
paging on rank0, with29.94-30.79% less reserved memory across ranks. Step times
were35.760 versus35.435ms, approximately unchanged in one clean run.

Twenty steps, throughput11-20; separate built-in profiles9-10/19-20; CUDA page
factor2.1, page64, no CPU spill. Comparing paging to default SAC also changes
recomputation and is not an overlap-only comparison. H100/multi-host execution
is not claimed; unchanged video lint failure stays outside scope.
