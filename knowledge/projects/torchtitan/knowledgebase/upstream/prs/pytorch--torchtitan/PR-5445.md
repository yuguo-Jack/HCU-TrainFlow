# [Attn] Rename CP backends and relocate model attention modules

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5445) · state: closed · merged: True

## Original PR description

Stack: this PR -> #4760.

Separate naming and file organization from the MLA CP optimization in #4760: rename CP/vLLM backends consistently with `InnerAttention`, move DeepSeek/Kimi MLA classes into model-specific `attention.py` files, and update callers, including Muse Spark. Computation, parameter names, and initialization order are unchanged.

Validation: 163 CPU tests passed. DeepSeek V3 and text-only Kimi K3 debug models match main bitwise over 10 BF16/Flex training steps (seed 42, deterministic): initial/final weights, outputs, losses, gradients, and grad norms. Non-Pyrefly lint hooks passed; Pyrefly reports the same 53 diagnostics as main. GraphTrainer validation is blocked by the installed PyTorch missing `_is_cacheable_effect`.
