# [CP] Add graph-safe varlen K/V all-gather

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5071) · state: closed · merged: True

**Human Summary**
This PR supports AllgatherKV VarlenAttention. We need to fix the number of chunks and cannot use dynamic packing. Otherwise the implementation cannot be cuda graph.  As a result, we can support no load balancer and head-tail load balancer but we cannot support PTRR. With PTRR, there will too many chunks and will make the computation overhead too large to make CP useful.

**Agent Summary**
    Use fixed query chunks for CUDA Graph replay. Document boundaries can change between replays when the metadata capacity stays fixed.

- Add full and sliding varlen backends with sharded Q and all-gathered K/V.
- Use one varlen call for contiguous sharding and two for head-tail. The head-tail calls share the restored K and V buffers.
- Bound K/V slices by document length and sliding window to reduce backward gradient work.
- Support causal self-attention. Reject PTRR, cross-attention, and noncausal windows.
