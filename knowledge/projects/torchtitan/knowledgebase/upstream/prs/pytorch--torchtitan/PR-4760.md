# [CP] Optimize Kimi K3 MLA all-gather and Ulysses communication

[Upstream PR](https://github.com/pytorch/torchtitan/pull/4760) · state: open · merged: False

## Original PR description

Stacked on #5296 (`refactor_attn`), the replacement for #5295. Stack order: `main` -> #5296 -> #4760.

**The original optimization idea was inspired by this [MLA Ulysses CP proposal](https://gist.github.com/fegin/bd9bd9e9147ae1b11375dfb68815f78a).**

- **K/V all-gather CP**
  - Before: all-gather materialized K and V separately. K repeats `k_rope`
    across attention heads.
  - After: all-gather packed `[K_nope, V]` and head-shared `k_rope`, then
    materialize K locally.

  ```python
  # Before: materialize K before communication.
  # wkv_b produces packed_KV_local = [K_nope_local, V_local].
  K_nope_local, V_local = unpack(packed_KV_local)
  K_local = concat(K_nope_local, expand_per_head(k_rope_local))
  K_global = all_gather(K_local)
  V_global = all_gather(V_local)

  # After: communicate compact tensors and materialize K afterward.
  # wkv_b already produces packed_KV_local = [K_nope_local, V_local].
  packed_KV_global = all_gather(packed_KV_local)
  k_rope_global = all_gather(k_rope_local)
  K_nope_global, V_global = unpack(packed_KV_global)
  K_global = concat(K_nope_global, expand_per_head(k_rope_global))
  ```

- **Ulysses CP**
  - Before: use three all-to-alls for materialized Q, K, and V. K repeats
    `k_rope` across attention heads.
  - Approach 1 (current): use one all-to-all for Q + compact `[K_nope, V]`, plus one
    all-gather for headless `k_rope`.
  - Approach 2: use separate all-to-alls for Q and compact `[K_nope, V]`, plus one
    all-gather for headless `k_rope`.

  ```python
  # Before: materialize K, then move Q, K, and V from token to head sharding.
  K_nope_local, V_local = unpack(packed_KV_local)
  K_local = concat(K_nope_local, expand_per_head(k_rope_local))
  Q_by_head = all_to_all_token_to_head(Q_local)
  K_by_head = all_to_all_token_to_head(K_local)
  V_by_head = all_to_all_token_to_head(V_local)
  output_by_head = attention(Q_by_head, K_by_head, V_by_head)
  output_local = all_to_all_head_to_token(output_by_head)

  # Approach 1: combine Q and compact [K_nope, V] in one all-to-all.
  packed_Q_KV_by_head = all_to_all_token_to_head(
      concat(Q_local, packed_KV_local)
  )
  Q_by_head, packed_KV_by_head = split(packed_Q_KV_by_head)
  k_rope_global = all_gather(k_rope_local)
  K_nope_by_head, V_by_head = unpack(packed_KV_by_head)
  K_by_head = concat(
      K_nope_by_head,
      expand_per_head(k_rope_global),
  )
  output_by_head = attention(Q_by_head, K_by_head, V_by_head)
  output_local = all_to_all_head_to_token(output_by_head)

  # Approach 2: use separate all-to-alls for Q and compact [K_nope, V]
  # while keeping k_rope headless.
  Q_by_head = all_to_all_token_to_head(Q_local)
  packed_KV_by_head = all_to_all_token_to_head(packed_KV_local)
  k_rope_global = all_gather(k_rope_local)
  K_nope_by_head, V_by_head = unpack(packed_KV_by_head)
  K_by_head = concat(
      K_nope_by_head,
      expand_per_head(k_rope_global),
  )
  output_by_head = attention(Q_by_head, K_by_head, V_by_head)
  output_local = all_to_all_head_to_token(output_by_head)
  ```

## Tests

### Numerical comparison

CP=2, BF16, seed 42, 256 tokens per step, 100 steps. Values are
`before -> after (relative diff)`, comparing generic materialized K/V with
compact MLA.

| CP backend | Step | Loss | Grad norm |
| --- | ---: | --- | --- |
| K/V all-gather | 1 | `12.473673 -> 12.473673 (0.000%)` | `27.2500 -> 27.2500 (0.000%)` |
| K/V all-gather | 10 | `4.037894 -> 4.083763 (1.136%)` | `6.3125 -> 5.9062 (6.436%)` |
| K/V all-gather | 100 | `2.879660 -> 2.914417 (1.207%)` | `5.8438 -> 5.6562 (3.209%)` |
| Ulysses | 1 | `12.460487 -> 12.460487 (0.000%)` | `27.2500 -> 27.3750 (0.459%)` |
| Ulysses | 10 | `4.009133 -> 4.295489 (7.143%)` | `7.1875 -> 6.2188 (13.478%)` |
| Ulysses | 100 | `2.740203 -> 2.837717 (3.559%)` | `5.4688 -> 5.4062 (1.143%)` |

The BF16 backward reduction order changes, causing first-step gradient drift
and different subsequent optimizer updates.

### Performance

#### K/V all-gather CP

DeepSeek-V3 16B using the shared MLA backend, 4 H100 nodes (32 GPUs), CP=8,
FSDP=4, EP=8, 32,768 tokens per DP rank, HeadTail CP load balancing, and
100 steps. TPS/GPU is the rank-0 mean over steps 21-99; SD is across those
steps.

Runs: [baseline](https://www.internalfb.com/msl/studio/runs/mast/tt-mla16b-cp8-kvag-32k-before-r1-32-jessicazhong-g3rhbw7g), [packed K/V (`33cf00a03d`)](https://www.internalfb.com/msl/studio/runs/mast/tt-mla16b-cp8-kvag-32k-packed-r3-32-jessicazhong-wmfj77fh), and [compressed latent (`838df97049`)](https://www.internalfb.com/msl/studio/runs/mast/tt-mla16b-cp8-kvag-32k-latent-r3-32-jessicazhong-zh3q0kfg).

| Path | Input collectives | Mean TPS/GPU | Step SD | vs. baseline |
| --- | --- | ---: | ---: | ---: |
| Before: materialized K with per-head `k_rope` copies, and V | 2 all-gathers | `2939.3` | `790.0` | - |
| Packed `[K_nope, V]` + headless `k_rope` | 2 all-gathers | `2988.2` | `720.5` | `+1.66%` |
| Compressed `kv_c_normed` + headless `k_rope`; project K/V locally | 2 all-gathers | `2992.6` | `729.3` | `+1.81%` |

**At 32K, compressed latent is 0.14% faster than packed K/V, which is much smaller than step-to-step variation; no conclusive difference was measured.**

#### Ulysses CP

DeepSeek-V3 16B using the shared MLA backend, 4 H100 nodes (32 GPUs), CP=8,
FSDP=4, EP=8, 8,192 tokens per DP rank, and 100 steps. TPS/GPU is the rank-0
mean over steps 21-99; SD is across those steps.

Runs: [baseline](https://www.internalfb.com/msl/studio/runs/mast/tt-mla16b-cp8-baseline-e2e-r1-32-jessicazhong-ks4txnjp), [Approach 1](https://www.internalfb.com/msl/studio/runs/mast/tt-mla16b-cp8-a1-e2e-r7-32-jessicazhong-mz0r5mfs), and [Approach 2](https://www.internalfb.com/msl/studio/runs/mast/tt-mla16b-cp8-a2-e2e-r7-32-jessicazhong-w9k3h1lw).

| Approach | Input collectives | Mean TPS/GPU | Step SD | vs. baseline |
| --- | --- | ---: | ---: | ---: |
| Before: separate Q, V, and materialized K with per-head `k_rope` copies | 3 all-to-alls | `720.3` | `185.7` | - |
| 1 (current): combined Q + compact `[K_nope, V]` + headless `k_rope` | 1 all-to-all + 1 all-gather | `780.3` | `176.2` | `+8.34%` |
| 2: separate Q and compact `[K_nope, V]` + headless `k_rope` | 2 all-to-alls + 1 all-gather | `738.4` | `182.5` | `+2.52%` |

**Approach 1 is fastest in this run: +8.34% over the pre-PR baseline; Approach 2 is +2.52% over baseline.**
