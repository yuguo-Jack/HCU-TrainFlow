# [Docs] Add Supported Parallelisms to DeepSeek-V3 README

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5379) · state: open · merged: False

## Original PR description

Related to #2354.

## Summary
The DeepSeek-V3 README did not document supported parallelisms, while other model READMEs (llama3, qwen3_5, flux, ...) do. This PR adds a `Supported Parallelisms` section covering FSDP/HSDP, TP (+SP), CP, EP, PP (1F1B, Interleaved1F1B), selective activation checkpointing, and `torch.compile`.

Coverage matches the sharding set in `sharding.py`/`flavors.py` and the DeepSeek-V3 jobs in `tests/integration_tests/models.py` (e.g. FSDP2+TP2+CP2+EP8, CP2 with flex attention, Interleaved1F1B PP).

Docs-only change.
