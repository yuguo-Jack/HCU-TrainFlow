# [CI Fix][B200] Refresh Kimi K3 DistMuon golden

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5559) · state: closed · merged: True

## Original PR description

## Summary

- Refresh the Kimi K3 multimodal per-head DistMuon B200 golden.
- Preserve the strict equality comparison and ten-step coverage.

Fixes #5449.

## Root cause

#5399 intentionally changed the first accumulated weight gradient from a BF16 GEMM result later upcast to FP32 into a GEMM that produces FP32 directly. Kimi uses eight chunked LM-head losses even when outer gradient accumulation is one, so this changes the first WGRAD and the seven following in-place FP32 accumulations. The next optimizer update consequently changes losses from step 2 onward.

#5399 refreshed affected A10G goldens and #5423 refreshed MI350X goldens, but the Kimi B200 golden was omitted. The observed B200 sequence is bitwise identical across independent runs and later PyTorch nightlies:

- https://github.com/pytorch/torchtitan/actions/runs/38830975496
- https://github.com/pytorch/torchtitan/actions/runs/39182322613
- https://github.com/pytorch/torchtitan/actions/runs/39349362724

Step 1 loss and grad norm remain unchanged, matching the expected first-update boundary.
