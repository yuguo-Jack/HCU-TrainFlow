# Allow model imports without attn_gym

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5231) · state: closed · merged: True

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* __->__ #5231
* #5230

Installing attn_gym does not always work for all users. It requires a specific cutedsl version. Not all models currently require attn_gym. But the attention module started exporting KDA metadata after https://github.com/pytorch/torchtitan/pull/4639, which makes attn_gym import a requirement for all users -- users who were not able to install attn_gym couldn't run TorchTitan anymore.

This PR adds a proxy module to avoid this. In the longer term, we need to revisit how we import and use attn_gym.

Validation: 8 CPU regression tests passed. Muse Glimmer text completed 10 steps on 8 H100 GPUs with FSDP in a conda environment that doesn't have attn_gym installed.
