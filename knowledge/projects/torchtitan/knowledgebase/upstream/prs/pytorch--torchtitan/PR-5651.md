# [CI FIX] Add the MXFP8 DAPO math recipe to the RL optional-package skip list

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5651) · state: closed · merged: True

## Original PR description

**TLDR:** RL CPU Unit Tests has been red on main since the Qwen3-30B-A3B DAPO math recipes landed. `rl_dapo_qwen3_30b_a3b_math_8k_mxfp8` needs the optional `dist_moe` package to build, the CPU job doesn't install it, and the recipe wasn't on `_OPTIONAL_PACKAGE_RECIPES`. This PR adds it to the list.

**Problem**
1. `test_rl_recipes_get_model_defaults` builds every `rl_*` recipe and checks its fp32 lm_head and frozen MoE routing.
2. Recipes that need an optional package (a torchao nightly, `dist_moe`) are skipped through `_OPTIONAL_PACKAGE_RECIPES`.
3. The new MXFP8 recipe builds `DistMoeTransform(expert_precision="mxfp8")`, which reads `dist_moe.BlockScaledConfig`, so it raises `ModuleNotFoundError` without `dist_moe`.
4. It wasn't added to the list, and the RL CPU job doesn't run on ordinary PRs (only on main, `ciflow/rl` and a schedule). So the recipe PR was green, and main has been red on every run since 2026-10-24.

**Solution**
Add `rl_dapo_qwen3_30b_a3b_math_8k_mxfp8` to `_OPTIONAL_PACKAGE_RECIPES`. The BF16 30B recipe builds without `dist_moe`, so it stays checked.

**Results**
```text
test_model_defaults.py, main vs this PR
env                                    main                  this PR
CPU, no dist_moe (like the CI job)     1 failed, 4 passed    5 passed, 2 skipped
GB300, no dist_moe, no torchao         1 failed, 4 passed    5 passed, 2 skipped
GB300, with dist_moe                   5 passed, 2 skipped   5 passed, 2 skipped
```
The 2 skips are the verifiers recipe modules (verifiers not installed). With `dist_moe` installed, the MXFP8 recipe is still built and checked.

**Follow up**
- [ ] Run RL CPU Unit Tests on PRs that touch `torchtitan_recipes/rl/` or `tests/rl/`, so a recipe missing from the list fails on its own PR.

**Test plan**
```bash
pytest tests/rl/unit_tests/cpu/test_model_defaults.py -rs   # with and without dist_moe installed
pre-commit run --files tests/rl/unit_tests/cpu/test_model_defaults.py
```
