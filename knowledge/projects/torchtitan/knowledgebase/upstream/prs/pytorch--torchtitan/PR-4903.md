# [qwen3.5][cp] Add Gated DeltaNet Ulysses context parallel

[Upstream PR](https://github.com/pytorch/torchtitan/pull/4903) · state: closed · merged: False

## Original PR description

Related issue: #4902

## Summary
TorchTitan does not support context parallel for Qwen3.5.

Qwen3.5 mixes full attention with Gated DeltaNet. GDN is a recurrence along time, so a sequence shard does not give the causal conv or the recurrence a full timeline. `parallelize` rejects `context_parallel_degree > 1`.

This PR all-to-alls contiguous sequence shards onto heads before the conv and the recurrence, then all-to-alls back. Full attention uses the same contiguous shards through the existing Ulysses path. `context_parallel_load_balancer` stays None. The vision encoder is not covered.

## Performance
2× RTX PRO 6000, Qwen3.5-35B-A3B LoRA, one optimizer step, sequence **65536**:
- Without sequence split: **73.7 s/step**, peak **84.9 GiB** per GPU
- With sequence split: **15.2 s/step**, peak **47.0 GiB** per GPU

- MegaGimen · comment · 2026-10-07T18:48:14Z · [source](https://github.com/pytorch/torchtitan/pull/4903#issuecomment-6044568981)

Sorry that I missed your message. Yes. This PR is Ulysses for GDN. #4803 keeps the sequence in fragments and exchanges the conv history and the recurrent state. Here each rank holds a shard of the sequence, then all-to-alls that shard onto heads before the conv and the delta rule, and all-to-alls back. Full attention uses the same exchange. The local kernels still see the full timeline, on half the heads.

Both numbers are one optimizer step of Qwen3.5-35B-A3B LoRA on 2× RTX PRO 6000, sequence 65536.

Without the split, each GPU runs all 65536 tokens and all heads. That step peaks at 84.9 GiB on a 96 GiB GPU. With the split, the MoE and the rest of the block see 32768 tokens per GPU. Inside GDN and full attention, each GPU still walks all 65536 positions, but only half the heads. Peak is 47.0 GiB.

Half the tokens and half the heads is about a 2× cut in work per GPU. The step is 73.7 s → 15.2 s, almost 5×. The rest matches the memory: the unsplit run is up against the card, and the backward is carrying the full-sequence activations.

- MegaGimen · comment · 2026-09-28T20:35:20Z · [source](https://github.com/pytorch/torchtitan/pull/4903#discussion_r4126773261)

File: `torchtitan/models/qwen3_5/gdn.py` · line 260

The sequence/head exchange now lives in cp_attention.py as ulysses_tokens_to_heads and ulysses_heads_to_tokens. UlyssesCPInnerAttention and GatedDeltaNet both call those two functions.

GatedDeltaNet still does not call UlyssesCPInnerAttention.forward. That forward runs attention. GDN runs a causal conv and the gated delta rule, and it slices the conv weights, A_log, and dt_bias down to the heads on this rank. Only the exchange is shared.

Checked on 2 GPUs with a tiny Qwen3.5 (3 GDN layers, 1 full-attention layer, 32 tokens). The CP logits, gathered back together, match the single-GPU run. Max absolute difference is 0.
