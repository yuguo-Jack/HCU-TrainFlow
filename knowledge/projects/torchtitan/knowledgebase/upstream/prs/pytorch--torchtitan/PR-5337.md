# [TorchTitan] Load Kimi K3 compressed-tensors MXFP4 checkpoints

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5337) · state: open · merged: False

## Original PR description


Summary:
Select DCP's quantized Hugging Face reader for Kimi K3. The checkpoint stores routed experts as `weight_packed` and `weight_scale`, so `to_hf(..., to_quantized_layout=True)` names them `weight_packed` for the reader to dequantize, and `from_hf(..., is_quantized_layout=True)` maps them back, replacing the `ValueError` both raised for the quantized layout. A mismatched flag raises on the unmapped expert keys. The released index names the MXFP4 tensors, so `fqn_to_index_mapping` maps `X.weight_packed` to `X.weight` and drops `X.weight_scale`, as GPT-OSS does, instead of being set to `None`. HF saves now keep the released 96-file layout instead of writing one consolidated file. Preserve KDA parameter layouts while adapting the released checkpoint's padded A_log and flattened dt_bias shapes.

This change was prepared with assistance from an AI coding tool and reviewed by the author.
