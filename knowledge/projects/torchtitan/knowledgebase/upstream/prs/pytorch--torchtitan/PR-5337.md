# [TorchTitan] Load Kimi K3 compressed-tensors MXFP4 checkpoints

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5337) · state: closed · merged: True

## Original PR description


Summary:
Select DCP's quantized Hugging Face reader for Kimi K3. The checkpoint stores routed experts as `weight_packed` and `weight_scale`, so `to_hf(..., to_quantized_layout=True)` names them `weight_packed` for the reader to dequantize, and `from_hf(..., is_quantized_layout=True)` maps them back, replacing the `ValueError` both raised for the quantized layout. A mismatched flag raises on the unmapped expert keys. The released index names the MXFP4 tensors, so `fqn_to_index_mapping` maps `X.weight_packed` to `X.weight` and drops `X.weight_scale`, as GPT-OSS does, instead of being set to `None`. HF saves now keep the released 96-file layout instead of writing one consolidated file. Preserve KDA parameter layouts while adapting the released checkpoint's padded A_log and flattened dt_bias shapes. Pad A_log only with `to_quantized_layout=True`; ordinary HF exports retain `n_heads` entries for the Hugging Face model.

Text-only configs omit `vision_tower.*` and `mm_projector.*` from the HF save map. This prevents DCP consolidation from writing empty dtype headers for parameters that were not exported.

This change was prepared with assistance from an AI coding tool and reviewed by the author.

149 tests passed; the Muse Glimmer vision test was deselected because the local environment lacks FlashAttention 3, a failure also reproduced on main. The A_log regression tests failed on the unguarded padding and passed after the fix. Plain tensors and three-rank DTensors cover both layout flags, including an empty shard, with exact-value comparisons. The text-only export regression failed when consolidation retained vision entries, then passed real DCP save/consolidate/load after filtering them. The multimodal index test verifies that both vision and projector entries are retained when the encoder is enabled.

Formatting and all other pre-commit hooks passed except Pyrefly, which reports the same four dependency errors reproduced on main: two unsupported `autotune` arguments in AttentionGym and two missing `renderers.CustomRendererConfig` imports.

The earlier full `Kimi-K3` config check found 249,924 HF names and the same 249,924 names in the remapped released index across 96 files.
