# [WIP] [rl] Bump StickySessionRoutingStrategy max_sessions default to 262144

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5233) · state: closed · merged: True

## Original PR description

The current default is too small for a real use case. Bump it to 262144, which should be comfortably above the normal workload. Add a tuning instruction in its docstring, so user knows what we expect them to do with it.

The memory footprint is small (1,048,576 entries cost 139.5 MiB). So for now, it is a reasonable tradeoff to keep our codebase simple.
