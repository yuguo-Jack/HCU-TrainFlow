## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.12.0) (oldest at bottom):
* #5136
* __->__ #4984

Profiler.Config.cuspy switches CUDA activity collection from Kineto to Cuspy
(PM sampling, environment counters, sync events, graph dependencies, event-node
ids). With CUDA graphs on, the forward-backward graph is captured with a CUPTI
annotation config so replayed kernels keep their annotations.
