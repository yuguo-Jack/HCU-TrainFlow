# [graph_trainer] Reject unsupported FSDP symmetric memory

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5151) · state: closed · merged: True

## Original PR description

GraphTrainer uses SimpleFSDP, which does not support FSDP symmetric-memory scopes. 
Rejecting non-`None` `parallelism.fsdp_symm_mem_scope` to not mislead the user.

The main reason is that symm_mem fsdp does not numerically match symm_mem fsdp.
