# [MoE] Locally compile microbatch auxiliary loss statistics

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5252) · state: closed · merged: True

## Original PR description

## Summary

- locally compile the rank-local statistics for `MicrobatchWiseLoadBalanceLoss`
- avoid materializing the normalized `[T, E]` score tensor
- enable the region by default for DeepSeek V3
- keep CP/TP reductions and auxiliary-loss injection outside the compiled region

The post-router gather/normalize path was also tested, but is not included: it was 6.5% slower and did not reduce peak memory at the DeepSeek V3 shape.

## Performance

Single H100, FP32 router scores, DeepSeek V3 shape (`T=8192`, `E=256`, `K=8`), forward + backward, 10 warmup iterations and 50 measured iterations:

| Path | Median | Speedup | Incremental peak memory | Memory reduction |
|---|---:|---:|---:|---:|
| Eager | 0.274 ms | 1.00x | 40.06 MiB | - |
| Local compile | 0.203 ms | **1.35x** | 8.03 MiB | **32.03 MiB (80%)** |

This measures only the rank-local auxiliary-loss statistics, not end-to-end training.

## Numerics

Eager vs local compile on the benchmark shape:

| Value | Max absolute difference |
|---|---:|
| Expert counts | 0 |
| Normalized-score sums | 3.814697e-6 |
| Router-score gradient | 7.450581e-9 |
