## Why

#5353 renamed `torchtitan/distributed/cuda_graph.py` and `CUDA_GRAPH.md` to `accelerator_graph.py` and `ACCELERATOR_GRAPH.md`. #5711 fixed `disable_cuda_graphs` call sites and left these globs.

An accelerator_graph-only PR no longer gets `ciflow/rl`, so the RL workflows that label starts do not run, and the `cuda_graph` area no longer requests fegin. Nothing else under `ciflow/rl` matches that diff: not `torchtitan/rl/**`, `tests/rl/**`, `scripts/rl/**`, `torchtitan/trainer.py`, the checkpointer, data, `torchtitan/models/common/**`, qwen3_5, qwen3_8, or the RL workflow yaml names.

**Example.** A PR that only edits `torchtitan/distributed/accelerator_graph.py`:

| | Before | After |
| --- | --- | --- |
| `ciflow/rl` | not applied; RL workflows stay off | applied; RL workflows can run |
| area reviewers | `cuda_graph` does not match, so fegin is not requested | `cuda_graph` matches and requests fegin |

## What changed

Path metadata only. The label name `ciflow/rl`, the area name `cuda_graph`, and reviewer `fegin` are unchanged.

- `.github/labeler.yml`: `torchtitan/distributed/cuda_graph.py` -> `torchtitan/distributed/accelerator_graph.py`
- `.github/area_reviewers.yml`: `torchtitan/distributed/cuda_graph.py` and `torchtitan/distributed/CUDA_GRAPH.md` -> `torchtitan/distributed/accelerator_graph.py` and `torchtitan/distributed/ACCELERATOR_GRAPH.md`

`torchtitan/experiments/graph_trainer/cuda_graph.py` is a different file that still exists. The distributed area does not point at it.

## Alternatives considered

- Do not fold `accelerator_graph.py` under `torchtitan/models/common/**`. That glob already labels model changes, and it would not request fegin for the graph files.

## User-facing changes

None for training. CI label behavior only.

| Before | After |
| --- | --- |
| Editing `torchtitan/distributed/accelerator_graph.py` or `ACCELERATOR_GRAPH.md` does not add `ciflow/rl` and does not request fegin | Those edits add `ciflow/rl`, and the `cuda_graph` area requests fegin |

## Testing

`git grep` under `.github/` shows no remaining `torchtitan/distributed/cuda_graph.py` or `torchtitan/distributed/CUDA_GRAPH.md`. No GPU run. No new test: this is yaml path metadata.
