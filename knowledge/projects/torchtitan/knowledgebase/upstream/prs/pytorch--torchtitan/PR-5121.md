# [graph_trainer][numerics] Coalesce repeated FSDP gradient reductions

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5121) · state: open · merged: False

## Original PR description

A shared parameter can contribute to the backward graph through more than one path. The traced graph reduced each contribution separately and added the results:

```python
grad = reduce_grad(local_grad_0) + reduce_grad(local_grad_1)
```

Eager FSDP adds the local contributions first and runs its post-accumulate reduction once:

```python
grad = reduce_grad(local_grad_0 + local_grad_1)
```

With two contributions and 16 microbatches, this changes as many as 32 repeated reductions into local additions followed by one final reduction.

The graph builders now canonicalize their owned joint graph before extraction or partitioning. Every derived graph therefore sees the same form, while the extraction utility remains non-mutating and needs no extra full-graph snapshot.

The change also extracts reusable FX chain and metadata helpers into `common_utils.py` and reuses them in gradient and weight-gradient accumulation.

Validation: 52 focused tests passed across FSDP collective splitting, gradient accumulation, weight-gradient accumulation, and MTP tuple preprocessing.


```
  lm_head_grad =  grad_from_main_loss  + grad_from_mtp_loss
 ```
