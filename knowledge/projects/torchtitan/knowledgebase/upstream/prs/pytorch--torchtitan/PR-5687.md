# [dsv4] Simplify SwiGLU activation config names

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5687) · state: closed · merged: True

## Original PR description

## Summary (human-written)

rename configs of limited swiglu.

## Changes

Remove redundant `swiglu_` prefixes from activation configs:

- `LimitedSwiGLU.Config`: `swiglu_limit` -> `limit`.
- `ClampedSwiGLU.Config`: `swiglu_alpha` -> `alpha`, `swiglu_limit` -> `limit`.

Update callers and tests. Keep both classes and their behavior unchanged.

## Testing

194 tests passed. Eight 10-step feed-forward comparisons were bitwise identical to base `2db551367`. Full lint only encounters the existing PyAV type error.
