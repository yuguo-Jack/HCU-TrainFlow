# [dsv3][perf] Compile the MoE router as one region (router)

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5163) · state: closed · merged: False

## Original PR description

**TLDR:** the router's side-effect-free work becomes the `router` region: -0.65 ms per MoE layer at 16k with DSv3's 256 experts.

**Problem**
1. **Router today.** Gate, scores, group-limited top-k, gather, normalization and routing map run eagerly.
2. **Aux loss.** The load-balance loss's `[T, E]` sums run eagerly too.
3. **`torch.topk` under compile** is an ATen fallback in Inductor.
4. **Cost.** 1.73 ms fwd+bwd per MoE layer at 16k, 256 experts.

**Solution**
1. **Region.** `TokenChoiceTopKRouter._route` and the aux loss's `_token_sums` compile as the `router` region.
2. **Top-k without topk.** Under compile, `DeepSeekV3Router._select_experts` uses masked argmax rounds.
3. **Unchanged.** Expert counts and aux-loss injection (with the per-forward `aux_loss_denominator`) stay eager; the gate is upstream's `HiMidLoLinear`.
4. **Enabled per recipe:** deepseek_v3_671b and both Dist-MoE recipes, not the model default, so Kimi K2.x is unaffected.

**Results**
```text
DSv3 671B layers 2-3, flex attention, fwd+bwd wall, 1x GB300 (shared), median [range] of 3 fresh processes, no AC
16k (128-expert router)   160.06 [159.95-160.07] -> 159.76 [159.67-159.78] ms  (-0.2%)

op level, 256 experts, 8 groups, top-4 groups, top-8, aux loss, fwd+bwd kernel us, median of 3
4k     634 [627-636] ->  408 [406-409]
16k   1730 [1716-1735] -> 1079 [1076-1080]   => -0.65 ms per MoE layer

correctness: whole stack vs eager, bf16, 4k: max rel L2 / noise band 0.55, same as upstream's swiglu region alone
graphs: router._route 3, router._token_sums 3 (T 4k/8k/16k + no_grad)
```

You may ask: why not compile the router as written? Router glue 1.10 -> 0.83 ms at 16k, 256 experts; less than this.

NOTE: not tested: multi-GPU, QuantileBalancedTopKRouter (not validated, noted in code), H100.

**Test plan**
`pytest tests/unit_tests/cpu/test_deepseek_v3_moe.py tests/unit_tests/gpu/test_deepseek_v3_router_compile.py` (GB300: pass)
