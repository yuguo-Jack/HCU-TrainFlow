## Original PR description

Summary:
Follow up #5391.

Update launcher provisioning imports and controller setup to use the ActorSystem API. Pass allocated host meshes to the configured actor system and apply RL environment defaults before importing torch-dependent modules.

Remove redundant tests that compare method names, signatures, or a default configuration type. Existing behavioral tests cover router dispatch, Verifiers setup with the controller's arguments, Monarch provisioning, and trainer rank grouping.
