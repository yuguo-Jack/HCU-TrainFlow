# [DistMuon] Balance Owned and sharded compute placement

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5468) · state: open · merged: False

## Original PR description

Part 2 of #5278.

Owned-only balancing ignored other work in the same bucket. This PR accounts for fixed local work and jointly assigns unchanged Owned/Shard/BlockShard chunks using explicit `(rank, region)` mappings. Multiple chunks can share a rank; a common region planner packs them while preserving their original NS views. Matrix boundaries, NS kernels, and parameter/momentum storage remain unchanged.

### K3 real-training validation

K3 debugmodel, CC12M test data, 8xH100, EP8/FSDP8, sequence length 512; full forward/backward/optimizer. Comparing main `8a3f5bc` with this PR `c8ea2ea`: two completed pairs of 40 steps, excluding 10 warmup steps. The planned third pair was incomplete and is excluded.

| Metric | main (ms) | PR (ms) | Reduction |
|---|---:|---:|---:|
| DistMuon | 84.98 | 66.75 | 21.5% |
| Optimizer phase, including AdamW | 100.60 | 82.30 | 18.2% |
| Full training iteration | 563.36 | 537.20 | 4.6% |

Medians across the two trials: optimizer metrics use per-step max-rank CUDA-event medians; iterations use max-rank synchronized wall time over 30 steps, divided by 30. Results are specific to this debug configuration.

### Correctness

Seed 42 with deterministic mode: per-step loss and grad_norm match bitwise, as do checked Muon parameter/momentum states. All 8 FlexShard CPU tests pass, including the extended placement and plan-reuse regression.
