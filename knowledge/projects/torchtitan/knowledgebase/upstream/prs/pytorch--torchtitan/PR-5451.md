# [rl] Rubric.truncation_penalty: keep partial credit on truncated rollouts, add a penalty

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5451) · state: open · merged: False

## Original PR description

**TLDR:** `Rubric.Config.truncation_penalty` adds a fixed penalty to a truncated rollout's reward-fn score, so truncation ranks below finishing without losing partial credit.

**Problem**
1. Rewards can give partial credit, e.g. the fraction of tests that pass.
2. `truncation_reward` replaces that score with a constant: a truncated rollout that passed 9 of 10 tests scores like one that passed 0.
3. Leaving it None scores a truncated rollout exactly like the same rollout finished.

**Solution**
1. `truncation_penalty` (e.g. -0.2) is added once to the weighted score of a truncated rollout.
2. It shows in `reward_breakdown` as `truncation_penalty`; setting it together with `truncation_reward` raises.
3. Unchanged: finished and errored rollouts, and `truncation_reward`.

**Example**
```text
One truncated rollout that passed 9 of 10 tests (reward fn score 0.9):
truncation_reward=0.0      reward 0.0   same as passing 0 of 10
both None (default)        reward 0.9   same as finishing
truncation_penalty=-0.2    reward 0.7   breakdown {"tests": 0.9, "truncation_penalty": -0.2}
```

NOTE: no in-tree recipe sets it yet; it is for rewards with partial credit. Validation shares the rubric, so it sees the penalty too.
NOTE: `rollout_reward/component/truncation_penalty` logs the constant penalty, like `errored` does today; the rate is `rollout/truncation_rate`.

**Test plan**
```bash
pytest tests/rl/unit_tests/cpu/test_rubric.py   # 6 passed
pytest tests/rl/unit_tests/cpu                  # 485 passed, 9 skipped
```
- On main, 5 of the 6 fail. `test_truncation_reward_still_short_circuits_the_reward_fns` pins unchanged behavior and passes on main by design.
- The reward fn has weight 2.0, so a penalty wrongly scaled by the weight sum fails; the errored rollout runs with `error_reward=None`, so a penalty applied to any non-completed status fails.
