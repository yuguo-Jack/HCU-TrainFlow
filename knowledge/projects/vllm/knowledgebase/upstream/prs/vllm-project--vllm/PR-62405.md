# [Quantization] Use replace_parameter for params re-created in process_weights_after_loading

[Upstream PR](https://github.com/vllm-project/vllm/pull/62405) · state: open · merged: False

## Original PR description

**Depends on #62326; review only the last commit.**

## Overview

Part 2 of 3 of keeping the loaded parameter objects through `process_weights_after_loading` (PWAL). With #62326, `replace_parameter` keeps the registered object. This PR converts the PWAL sites that still register a fresh `torch.nn.Parameter` over a loaded one to `replace_parameter`.

## Claims

- `layer.x = Parameter(...)`, `setattr(layer, x, Parameter(...))` and no-op rewraps (`Parameter(layer.x.data)`) in PWAL now go through `replace_parameter`, so the loaded object (class, `weight_loader`, dim attributes) survives. This covers:
  - linear kernels: MXFP4, MXFP6, MXFP8, NVFP4 (CUTLASS, FlashInfer, FBGEMM, PyTorch, Humming scales), mixed precision (ExLlama, RDNA3, XPU);
  - compressed-tensors, Quark, INC, FBGEMM FP8, ModelOpt, AutoAWQ and online lm_head methods, and Marlin FP4 helpers;
  - `dispatch_cpu_unquantized_gemm`, CPU AMX MLA, and DeepSeek-V4 CPU attention.
- Coverage (whole-tree enumeration of PWAL-reachable sites on `main`, 1786 rows split across the three PRs): 141 sites converted here, plus 2 n/a rows inside the changed hunks. Deletes and renames in the same functions are left as on `main`; they are in the follow-up PR.

## Validation

- `pre-commit` passes.
- On GB200, `tests/quantization/test_keep_param_objects.py` and `tests/model_executor/test_utils.py` pass: 23 passed. This PR adds the `modelopt-fp8-pb-wo-linear` and `modelopt-mxfp8-linear` cases, which fail on #62326 alone.
- The end-to-end GB200 run is described in #62326. It compares `main`, #62326, and the top of the stack, which includes this PR. The rows that touch this PR's sites are below.

  | Config | GSM8K main / stack | Post-PWAL tensors |
  |---|---|---|
  | MiniMax-M3 MXFP8 (ModelOpt MXFP8 linear), TP4 | 0.859 / 0.859 | identical |
  | compressed-tensors W8A8 FP8 per-tensor + FP8 KV cache | 0.738 / 0.738 | identical |
  | same, Humming forced (reads `processed_weight_dims`) | 0.751 / 0.758 | identical |
  | same, Marlin forced | 0.738 / 0.734 | identical |

  - The same kernels are selected in both arms.
  - Every loader-visible param is the same object after PWAL; on `main`, 10% are for W8A8 FP8 and 49% for M3.

## Details

- Compressed-tensors W8A8 FP8 and ModelOpt FP8 per-tensor transpose the weight to (K, N). The kept param keeps its checkpoint dim tags, and the layout reaches Humming via `layer.processed_weight_dims` (added in #62326) instead of a retag.
- Where a site re-creates a param whose shape or dtype changes, `replace_parameter` rebinds `.data`; where the layout matches, it copies into the existing storage.
- `modelopt.py`, `quark_nvfp4.py`, `fbgemm_fp8.py`, `inc_wna16_linear.py` and `kernels/linear/nvfp4/humming.py` also delete or rename params. Only their `Parameter(...)` assignments are converted here.
