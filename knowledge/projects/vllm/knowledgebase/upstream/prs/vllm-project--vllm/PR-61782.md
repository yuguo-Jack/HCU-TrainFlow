# [CI] Run 4xH100 steps nightly only

[Upstream PR](https://github.com/vllm-project/vllm/pull/61782) · state: closed · merged: True

## Original PR description

## Purpose

Mark the last two 4-GPU H100 steps that still ran automatically on PRs as `optional: true`:

- `(H100) Elastic EP Scaling` (`expert_parallelism.yaml`)
- `(H100) LM Eval KV-Offload Large` (`lm_eval.yaml`)

On the shared `mithril-h100-pool` k8s cluster, 4/8-GPU pods sit Pending behind 1/2-GPU jobs until a node frees up enough GPUs, which shows up as long queue times on PRs. Same treatment as the 4xB200 steps in #61541. With `optional: true` the steps still run automatically on nightly (`NIGHTLY=1` / `ready-run-all-tests`) and show a manual "Run …" block on PRs.

After this, every H100 / B200 k8s step with `num_devices >= 4` is optional.

## Test Plan

Parsed all `.buildkite/test_areas/*.yaml` and confirmed every `h100` / `b200-k8s` step with `num_devices >= 4` now has `optional: true`.
