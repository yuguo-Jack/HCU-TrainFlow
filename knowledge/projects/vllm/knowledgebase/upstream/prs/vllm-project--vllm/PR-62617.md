# [Perf] 添加 RTX PRO 6000D 的可选 BF16 投影适配

[Upstream PR](https://github.com/vllm-project/vllm/pull/62617) · state: open · merged: False

## Original PR description



## Overview

为 RTX PRO 6000D 上已测的 GLM/MiMo 投影形状添加可选 CuTe 分派：加载期预编译 M1–4，运行时通过 opaque custom op 选择小批次路径。默认关闭。

来源：[Pro6000d-community公开实现与历史测试](https://github.com/PacoZhou1/Pro6000d-community/tree/d2c0ec3be319b7d8949778eefd15bb77fa693b8d)。贡献重点是尽可能为RTX PRO 6000D的具体模型算子做适配与优化；不主张此前无人优化该GPU或全球首次。

## Claims

- 按设备 CC12.0/156SM、层名、BF16 dtype 和五种形状限定适用范围；非目标输入保留 fallback。
- 准备和执行使用同一个非 PDL kernel 实例，并适配当前包含 output_dtype 的编译缓存键。
- 复用 vLLM 现有 CuTe 算术内核；本贡献是针对 6000D 的设备适配、运行时集成及验证，不是新数学内核。

## Details

历史集成在大batch跟踪时可能把fallback固定进编译图，本适配把行数判断保留在opaque op内。当前main的缓存键及M1 PDL实例不同，不能直接复制旧部署文件。显式FlashInfer BF16后端、bias和batch-invariant行为保留原处理。

去重：#60385 面向其它形状的 SM120 block-FP8，本改动是有设备/形状边界的 BF16 投影分派。未发现同主题的现有6000D PR。

底层vLLM、CuTe、B12X、SGLang及模型架构保留各自作者归属；不包含模型权重、业务数据、私有部署配置或私有项目Git历史。**本次移植使用了AI辅助。提交人已确认审阅本轮补丁并承担贡献责任，提交包含DCO Signed-off-by。**
