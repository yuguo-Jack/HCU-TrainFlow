# [Bugfix][Multimodal] Keep text-only deployments text-only on KV/EC consumers

[Upstream PR](https://github.com/vllm-project/vllm/pull/65648) · state: open · merged: False

## Original PR description

## Purpose

A text-only deployment of a Pixtral-based model fails at engine init when it is also a KV/EC consumer: `--limit-mm-per-prompt '{"image":0}'` together with a consumer `--kv-transfer-config` (`kv_consumer` or `kv_both`, e.g. a NixlConnector P/D decode worker or OffloadingConnector):

```
vllm.exceptions.VLLMValidationError: At most 0 image(s) may be provided in one prompt. (parameter=image)
```

*Root cause:* `_resolve_mm_embedding_inputs` enables `enable_mm_embeds` on every EC/KV consumer. With all limits at 0 that turns multimodal inputs back on (`supports_multimodal_inputs` is True whenever `enable_mm_embeds` is), the `MultiModalBudget` then sizes the image modality, and Pixtral's `get_dummy_inputs` builds one dummy image, which the limit of 0 rejects. A text-only deployment is never sent embeddings, so the resolution is now skipped there.

`--language-model-only` also sets every limit to 0, but an EC consumer started with it skips the encoder and still receives embeddings from the EC connector, so it keeps `enable_mm_embeds=True` (second commit).

<details><summary>repro_textonly.py</summary>

```python
import sys

from vllm import LLM, SamplingParams

model, connector = sys.argv[1], sys.argv[2]
kv_transfer_config = {
    "offloading": {
        "kv_connector": "OffloadingConnector",
        "kv_role": "kv_both",
        "kv_connector_extra_config": {"cpu_bytes_to_use": 1 << 30},
    },
    "nixl": {"kv_connector": "NixlConnector", "kv_role": "kv_consumer"},
}[connector]

llm = LLM(
    model=model,
    tokenizer_mode="mistral",
    config_format="mistral",
    load_format="dummy",
    limit_mm_per_prompt={"image": 0},
    kv_transfer_config=kv_transfer_config,
    max_model_len=4096,
    gpu_memory_utilization=0.3,
    enforce_eager=True,
)
out = llm.generate(["The capital of France is"], SamplingParams(max_tokens=8))
print("OK text request:", out[0].outputs[0].token_ids)
```

</details>

Run on 1x GB300. The model was a 2-layer Pixtral config (Mistral format, `vision_encoder` section) with the Magistral-Small-2509 `tekken.json`.
