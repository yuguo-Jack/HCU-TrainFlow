## Original PR description

## [ROCm][gfx1250] DeepSeek-V4: A8W8 block-scale preshuffle GEMMs with column-major activation scales

### Purpose
On gfx1250, FP8 block-scaled linears run aiter's Triton/Gluon B-preshuffle GEMM, which reads the activation scales column-major (`is_x_scale_transposed=True`). This PR feeds those scales in that layout end to end and fuses the shared-expert activation quant into `down_proj`.

**gfx1250 only. gfx950 (and all other platforms) behave exactly as before.**

### Changes
- `QuantFP8` (aiter group quant, `forward_hip`): emits column-major scales when `column_major_scales=True` on gfx1250. Other archs keep row-major.
- `AiterFp8BlockScaledMMKernel`: the B-preshuffle path (gfx1250, tuned shapes) quantizes activations with column-major scales. The Triton preshuffle wrapper derives `is_x_scale_transposed` from the scale strides.
- `is_triton_blockscale_bpreshuffle_gemm_tuned`: looks up the `gluon` config on gfx1250.
- `fused_mla_dual_rms_norm_group_quant`: allocates a column-major `q_scale` when `transpose_scale=True` (real and fake impls).
- DeepSeek-V4 (ROCm):
  - The fused q/kv norm quant emits transposed `qr` scales on gfx1250 for the `wq_b` preshuffle GEMM.
  - Shared expert: when `down_proj` runs the preshuffle GEMM, clamp + SiLU-mul + FP8 group quant is fused in a single `fused_clamp_act_mul` kernel, whose column-major scales feed `down_proj` directly.

### Test Plan
- Unit tests: `tests/models/test_deepseek_v4_rocm_*`, `tests/v1/attention/test_rocm_aiter_mla_sparse.py`, `tests/v1/attention/test_deepseek_v4_rocm_adaptive.py`, `tests/kernels/attention/test_rocm_triton_attn_dsv4.py`.
- gfx950 (MI355X): checked that nothing changes (CDNA4: `transpose_scale=False`, row-major `QuantFP8`, CK/ASM preshuffle unchanged).
- gfx1250: DeepSeek-V4-Pro serving benchmark and gsm8k.

### Test Results
- Unit tests: 160 passed on MI355X; pre-commit clean.
