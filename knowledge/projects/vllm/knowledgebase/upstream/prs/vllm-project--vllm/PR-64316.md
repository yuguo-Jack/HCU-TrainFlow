# [Doc] DeepSeek-V4-Pro: add B200 InferenceX AgentX presets

[Upstream PR](https://github.com/vllm-project/vllm/pull/64316) · state: closed · merged: True

## Original PR description

## Overview

Adds the B200 AgentX lane of [SemiAnalysisAI/InferenceX#4554](https://github.com/SemiAnalysisAI/InferenceX/pull/4554) (keys `dsv4-fp4-b200-vllm-agentic-mtp` and `dsv4-fp4-b200-vllm-agentic-mtp-lowconc`) to `recipes/models/deepseek-ai/DeepSeek-V4-Pro.yaml` as two opt-in tuned presets, following #63534. The recipe had no B200 AgentX coverage.

## Claims

- Two presets for the 0813 checkpoint with DSpark (six draft tokens), 13 points, each with its pinned image:

  | Preset | Strategy | Points |
  |---|---|---|
  | `b200_agentx_tp` | `single_node_tp`, TP8 | c1, c4 (low latency), c6, c10, c14 |
  | `b200_agentx_dep` | `single_node_dep` | DEP8 c64, c96, c128, c160, c192; TP4 x DP2 c32; TP2 x DP4 c48, c64 |

- Per-point `--max-num-seqs`, `--max-num-batched-tokens`, `--kv-cache-memory-bytes` and CUDA graph capture sizes are rendered as flags. The DP points add the Simple CPU KV tier (241.5 GB per rank) and the router tab's consistent-hash vLLM Router; the router's `--request-timeout-secs` and `--disable-retries` are in the runbook.
- Presets are opt-in; no existing rendering changes.
- Left out on purpose: `VLLM_PREFIX_CACHE_RETENTION_INTERVAL` (removed in v0.30.0, #55353; only c10 sets the flag, as the lane did), `--served-model-name`, and the benchmark's synthetic acceptance length.
- The TP presets keep `--no-enable-flashinfer-autotune` instead of the builder's `--disable-flashinfer-autotune`, which the pinned image does not define.

## Not a duplicate

No open PR touches this file's presets or adds B200 AgentX coverage.
