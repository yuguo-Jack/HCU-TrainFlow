# [CI] Raise fault-detection deadline 45s -> 75s in FT E2E test

[Upstream PR](https://github.com/vllm-project/vllm/pull/58264) · state: open · merged: False

## Original PR description

## Problem

`test_injected_fault_retry_recovers_all_ranks` has failed twice this week (dashboard #2028, #2037): the fault was injected and detected, but detection landed just past the 45s deadline on loaded CI hosts.

## Fix

Raise the deadline from 45s to 75s (slowest fallback is 30s; the margin was too thin for CI startup variance). The test's purpose (verify recovery) is unchanged.
