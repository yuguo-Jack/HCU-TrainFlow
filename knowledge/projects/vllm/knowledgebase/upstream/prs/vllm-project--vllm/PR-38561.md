# [Core] Batch invariant chunked prefill for mamba/hybrid models

[Upstream PR](https://github.com/vllm-project/vllm/pull/38561) · state: closed · merged: False

## Original PR description

## Purpose
This PR aims to enable batch invariance for hybrid mamba models like Nemotron 3 or Bamba. The mamba layers don't prevent models from passing the existing "bs1_vs_bsN" tests, but batch invariance breaks down as soon as chunked prefill or prefix caching come into play - scenarios not verified by the current tests. To fix this, this PR does two things when in batch-invariant mode:

- force chunked prefill to split prompts only at mamba chunk boundaries
- align prefix cache entries to mamba chunk boundaries

It does not affect behavior in the default, non-batch-invariant mode.

## Test Plan
Added new tests to verify those scenarios:

```
$ VLLM_TEST_MODEL="ibm-ai-platform/Bamba-9B-v2" pytest tests/v1/determinism/test_prefix_caching_batch_invariance.py
$ VLLM_TEST_MODEL="ibm-ai-platform/Bamba-9B-v2" pytest tests/v1/determinism/test_chunked_prefill_batch_invariance.py
```

Both of these tests fail without the changes from this PR.
