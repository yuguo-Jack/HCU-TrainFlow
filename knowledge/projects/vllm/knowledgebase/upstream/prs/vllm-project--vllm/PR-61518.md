## Validation

Validated on a remote Ubuntu x86_64 machine with Ryzen 9 9900X, Python 3.12.13 and PyTorch 2.13.0+cpu, against base `698e79f3bdbbe4fe7d6be6d91b358a7f430753ab`.

```sh

```

Native baseline: 2 failed, 3 passed. Patched: 5 passed. End-to-end CPU testing with LiquidAI/LFM2-350M completed 2 x 64 generated tokens and accepted 63/198 draft tokens. One prompt matched ordinary greedy decoding, while the other diverged. The unpatched speculative baseline produced incorrect output for both prompts. Remaining parity issues block claiming a complete end-to-end fix.

Applicable pre-commit checks passed. Upstream CI has not yet been evaluated for this draft.

## Details

End-to-end speculative output parity remains unresolved. This draft demonstrates the per-request CPU convolution contract. Ordinary decoding output was unchanged for both prompts. Related #44296 concerns GPU speculative wiring and #49650 centralizes CPU dispatch.
