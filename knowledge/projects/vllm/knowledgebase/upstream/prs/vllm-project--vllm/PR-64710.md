# [Rust Frontend] Bump the Rust toolchain to 1.100.0-beta.7

[Upstream PR](https://github.com/vllm-project/vllm/pull/64710) · state: open · merged: False

## Original PR description

## Purpose

Bump the Rust frontend toolchain from 1.95 to 1.100 (currently pinned to `1.100.0-beta.7`; 1.100.0 stable is due 2026-11-12). This PR is meant to stay draft until the stable release, then flip `channel` to `"1.100"` and merge. `tools/build_rust.sh`, the Buildkite Rust CI script, and the Docker builds all read the version from `rust-toolchain.toml`, so it is the only pin to update.

Required migration on the new toolchain (all errors under `--locked -- -D warnings`):

- `AtomicU64::fetch_update` is renamed to `try_update` (pure rename).
- Two test-module trait imports already covered by the parent module's `use super::*` are now reported as unused.
- New beta Clippy lints: `chunks_exact_to_as_chunks` (adopting `as_chunks` also drops two `try_into().expect(..)` conversions in tensor decoding), an extended `needless_range_loop`, `manual_filter`, and the `float_literal_f32_fallback` future-incompatibility lint.

`cargo fmt`, `cargo sort`, and `cargo deny bans` needed no changes.

The second commit adopts std APIs stabilized in 1.98–1.99 where they are a clear win:

- `String::from_utf8_lossy_owned` for owned decode output (resolves two existing TODOs; valid UTF-8 reuses the buffer instead of copying).
- `str::strip_circumfix` where a prefix and suffix must both be present.

Stacked on top: #64711 migrates `assert!(matches!(..))` to the newly stabilized `std::assert_matches!`.

## Duplicate-work check

No open PR bumps the Rust toolchain or migrates to `assert_matches!` (searched open PRs for "rust toolchain", "rust-toolchain", and "assert_matches").

## Test plan

On `rustc 1.100.0-beta.7 (fd8e211ae 2026-10-17)`, aarch64-unknown-linux-gnu:

- `cargo fmt --manifest-path rust/Cargo.toml --all -- --check`
- `cargo sort --workspace --check rust`
- `cargo deny --manifest-path rust/Cargo.toml --config rust/deny.toml check bans`
- `cargo clippy --manifest-path rust/Cargo.toml --workspace --all-targets --all-features --locked -- -D warnings`
- `cargo nextest run --manifest-path rust/Cargo.toml --workspace --all-features --locked --no-fail-fast` — 2412/2412 passed (13 skipped)
- `cargo build --manifest-path rust/Cargo.toml -p vllm-cmd --release --locked` (thin LTO + `panic = "abort"`), `vllm-rs --version` smoke OK

No behavior change intended; no model-affecting code touched, so no evals were run.

This change was prepared with AI assistance (Kimi Code CLI). The author reviewed every changed line and ran the tests above.
