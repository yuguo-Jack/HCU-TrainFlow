# [CI] Add Nightly to optional step labels and clarify vague names

[Upstream PR](https://github.com/vllm-project/vllm/pull/61186) · state: open · merged: False

## Original PR description

## Purpose

Optional steps in `.buildkite/test_areas/` only run in nightly builds, but most labels didn't say so, so you can't tell from a Buildkite job name whether a step runs per-PR or nightly. This PR adds `Nightly` right after the hardware prefix on all 77 optional steps:

- `:nvidia: (B200) LM Eval Humming Default TEMPORARY` → `:nvidia: (B200) Nightly LM Eval Humming Default TEMPORARY`
- `:nvidia: (DGX) Spark GPQA Eval (GPT-OSS)` → `:nvidia: (DGX) Spark Nightly GPQA Eval (GPT-OSS)`
- 9 labels already ended in `Nightly` (for example `(B200) Spec Decode Eagle Nightly`). For those, `Nightly` moves to the same position so every label follows one pattern.

Only `label:` strings change. Step keys, commands and devices are untouched. No other file in the repo references these labels. `test-amd.yaml`, `hardware_tests/` and `intel_jobs/` are out of scope.

### Renamed to match what they run

Six labels were vague or wrong about what the job tests. I renamed them based on their commands and kept the accelerator first. Step keys and AMD mirror labels are unchanged.

| Old | New | Runs |
|---|---|---|
| (H100) Distributed DP + EP | (H100) Nightly Torchrun DP+EP Example | `torchrun_dp_example_offline.py` TP2 DP4 EP |
| (A100) Distributed | (A100) Nightly Custom AllReduce + Multi-GPU Correctness | custom all-reduce, CA buffer sharing, 2-GPU basic correctness, Mixtral LoRA |
| (H100) Distributed Features | (H100) Nightly CP + DBO + RL Weight Transfer | context parallel, DBO, RLHF/weight transfer, DeepEP DP example |
| (B200) Distributed | (B200) Nightly Collectives + CP + DBO | all-gather/reduce-scatter, NCCL symm mem, MNNVL all-to-all, CP, DBO |
| (L4) V1 E2E | (L4) Nightly Spec Decode Draft Model TP | draft-model TP tests only |
| (H100) FP8 MoE Kernels | (H100) Nightly MoE Kernels | cutlass/flashinfer/triton/int8 MoE, more than FP8 |
