# [Bugfix] Bound prefix cache reuse by the first requested prompt score

[Upstream PR](https://github.com/vllm-project/vllm/pull/60960) · state: closed · merged: True

## Original PR description

## Overview

With `prompt_logprob_token_ids` and `skip_reading_prefix_cache=False`, a cache hit can skip requested scores. Cap prefix reuse at `prompt_logprob_start` so those rows are recomputed.

## Claims

Reuse the unscored prefix without dropping requested scores. Cache reads remain disabled by default for prompt scoring.

## Validation

Ten targeted cases, the Qwen3-0.6B model test and pre-commit passed. Batch-invariant scores matched exactly, including a single-host NIXL check. Default BF16 returned complete scores but differed by up to 0.29844; the cause remains unresolved.

```python
import argparse
import atexit
import json
import time
from pathlib import Path

import numpy as np
from transformers import AutoTokenizer

from vllm import LLM, SamplingParams, TokensPrompt


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("output", type=Path)
    args = parser.parse_args()
    import pyarrow.parquet as pq
    model = "Qwen/Qwen3-0.6B"
    revision = "c1899de289a04d12100db370d81485cdf75e47ca"
    data = pq.read_table(Path(__file__).with_name("mmlu.parquet")).slice(0, 8).to_pylist()
    tokenizer = AutoTokenizer.from_pretrained(model, revision=revision)
    prompts, starts = [], []
    for row in data:
        context = tokenizer.encode("Question: " + row["question"] + "\nAnswer:", add_special_tokens=False)
        for option in row["choices"]:
            suffix = tokenizer.encode(" " + option, add_special_tokens=False)
            ids = (context + suffix)[-4095:]
            prompts.append(TokensPrompt(prompt_token_ids=ids))
            starts.append(len(ids) - len(suffix) - 1)
    assert len(prompts) == 32 and min(starts) >= 0
    llm = LLM(
        model=model, revision=revision, dtype="bfloat16", max_model_len=4096,
        max_num_seqs=128, max_num_batched_tokens=8192,
        gpu_memory_utilization=0.65, enforce_eager=True, seed=233,
    )
    atexit.register(llm.llm_engine.engine_core.shutdown, timeout=30)
    arms = []
    # The first pair warms scorer kernels; retain three further pairs for timing.
    for skip in [True, False] * 4:
        assert llm.reset_prefix_cache()
        llm.generate(prompts, SamplingParams(temperature=0, max_tokens=1), use_tqdm=False)
        params = [
            SamplingParams(
                temperature=0, max_tokens=1, prompt_logprob_start=start,
                prompt_logprob_token_ids=[[token] for token in p["prompt_token_ids"][start + 1:]],
                skip_reading_prefix_cache=skip,
            )
            for p, start in zip(prompts, starts)
        ]
        begin = time.perf_counter()
        outputs = llm.generate(prompts, params, use_tqdm=False)
        elapsed = time.perf_counter() - begin
        rows = []
        for output, p, start in zip(outputs, prompts, starts):
            scores = output.prompt_token_id_logprobs
            assert scores is not None, (
                f"Missing scores: skip_cache={skip}, cached={output.num_cached_tokens}, "
                f"first_scored_row={start}"
            )
            assert scores.shape == (len(p["prompt_token_ids"]) - start - 1, 1)
            assert 0 <= (output.num_cached_tokens or 0) <= start
            rows.append({"scores": scores.tolist(), "cached_tokens": output.num_cached_tokens})
        arms.append({"skip_cache": skip, "elapsed_s": elapsed, "rows": rows})
        args.output.write_text(json.dumps({"prompts": prompts, "starts": starts, "arms": arms}))
        print("ARM", len(arms), skip, elapsed, sum(r["cached_tokens"] or 0 for r in rows), flush=True)
    for arm in arms[1:]:
        for reference, actual in zip(arms[0]["rows"], arm["rows"]):
            np.testing.assert_allclose(actual["scores"], reference["scores"], atol=1e-2, rtol=1e-3)
    assert any(r["cached_tokens"] for r in arms[1]["rows"])
    print("INTERVAL_OK", flush=True)


if __name__ == "__main__":
    main()
```

## Details

Both cache lookup paths use the same limit. Ordinary `prompt_logprobs` disable reuse. Connector requests set the skip flag before admission to prevent prompt truncation; MoRIIO's existing hybrid-producer hook ignores this flag and remains unverified.

Repository tests cover cache boundaries, connector admission and batch-invariant scoring. MMLU, compiled-boundary and NIXL runs are supplemental checks.

Thanks @Sunt-ing, I did a bit of additional rework on top of this: https://github.com/njhill/vllm/commit/5855a3541c6489618c477ae781c4aad14f06d444

In particular, `prompt_logprob_start` now also applies consistently to the top-k `prompt_logprobs` case.


- Scoring requests keep the local cache when a KV connector is configured:
  - The forced skip_reading_prefix_cache=True in add_request is gone.
  - Only the connector's external hit is dropped, through the new Request.skip_reading_external_kv.
  - NIXL, Mooncake, the offloading connector and simple-CPU-offload all use that same check.
- One cache limit on Request:
  - skip_reading_prefix_cache is folded into prefix_cache_hit_limit (0 means skip reading).
  - get_max_cache_hit_length(bound) replaces the property and the two duplicated clamp blocks in kv_cache_manager.py.
  - The limit is recomputed when a streaming session update arrives.
- prompt_logprob_start now applies to prompt_logprobs (top-K):
  - Validation is relaxed, and it requires the V2 runner and at least one scored row.
  - The MRV2 runner drops rows before the start, and the output pads those positions with None.
  - get_prefix_cache_hit_limit is a single rule, so top-K requests can reuse the unscored prefix.
- Cleanup: the start is stored once and shared by the top-K and token-ID paths (no more _TokenIdScores.start).
- Tests and docs:
  - New tests for the limit values and the None padding.
  - The model test now also covers top-K with a start and prefix reuse.
  - Tests that relied on the removed attribute are updated, and so is the connector scheduler assertion, which now expects 48 tokens for suffix scoring because the local cache is reused.
  - Docs updated.
