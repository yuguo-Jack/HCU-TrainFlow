# [MoE] Consolidate expert placement strategy resolution

[Upstream PR](https://github.com/vllm-project/vllm/pull/50113) · state: closed · merged: False

## Original PR description

## Purpose

Expert placement strategy was resolved in two stages: first by the module-level `determine_expert_placement_strategy` function and then by `ExpertMapManager._determine_placement_strategy`.

The two stages contained overlapping backend checks and split the placement policy across two locations. This PR consolidates the policy inside `ExpertMapManager` so the effective placement strategy is resolved once during initialization.

The change is intended to preserve existing placement behavior.

## Test Plan

- Add parameterized unit coverage for expert placement strategy resolution.
- Cover linear placement, disabled EP, single expert group, redundant experts,
  EPLB, unsupported backends, DeepEP low-latency, and NIXL EP.
- Verify the effective strategy through the public
  `ExpertMapManager.placement_strategy` property.
