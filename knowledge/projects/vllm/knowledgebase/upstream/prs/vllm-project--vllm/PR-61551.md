# [Docs] Add train-inference consistency agent skill

[Upstream PR](https://github.com/vllm-project/vllm/pull/61551) · state: closed · merged: True

## Original PR description



## Overview

Adds the `train-inference-consistency` agent skill under `.agents/skills/` (symlinked from `.claude/skills/`). It guides an agent through making RL training and vLLM rollout produce bitwise identical logprobs (true on-policy RL) while keeping rollout throughput close to the high-performance baseline.

## Claims

- A C0–C10 workflow with explicit pass criteria per gate, from module inventory and proxy model through inference batch / prefill-decode invariance, training forward and backward alignment, two-step RL acceptance, and delivery.
- Guides for the problems that come up on that path: mismatch localization and bisect, training forward and backward validation, which batch-invariant kernel each operator uses and what it costs, quantization conversion chain and QAT, rollout engine behavior (sampling seeds, prefix cache, MTP, R3), performance A/B, exact checkpoint resume, runtime provenance, and paired acceptance.
- The rules come from the DeepSeek-V4-Flash and Nemotron-3.5-Lightning NVFP4 consistency work, where `actor/ppo_kl` and rollout/training logprob diff are 0 at every step.
