# [Refactor] Migrate compressed-tensors MXFP4 MoE to the oracle

[Upstream PR](https://github.com/vllm-project/vllm/pull/56306) · state: open · merged: False

## Original PR description

   <!-- markdownlint-disable -->

   ## Purpose

   Migrate `CompressedTensorsW4A4Mxfp4MoEMethod` to the standard MXFP4
   MoE oracle flow as part of
   [#54959](https://github.com/vllm-project/vllm/issues/54959).

   Previously, the quantization method selected CUTLASS, XPU, or Marlin
   itself and directly handled CUTLASS scale swizzling and Marlin weight
   preparation.

   This PR:

   - Adds the native CUTLASS MXFP4 x MXFP4 backend to the MXFP4 oracle.
   - Moves W4A4 backend selection into the oracle.
   - Moves CUTLASS scale swizzling into the oracle's weight conversion.
   - Delegates Marlin preparation to the existing oracle conversion path.
   - Preserves the existing b12x checkpoint layout.
   - Simplifies the quantization method to weight creation, loading, and
     oracle delegation.

   This PR is limited to `CompressedTensorsW4A4Mxfp4MoEMethod`.
   `INCMxfp4MoEMethod` can be migrated separately.

   Checked open PRs using the issue number and relevant MXFP4/oracle
   keywords and found no overlapping work.

   ## Test Plan

  MXFP4 MoE kernel tests on an NVIDIA B200:

   ```bash
   python -m pytest tests/kernels/moe/test_mxfp4_moe.py -v
 ```

b12x/oracle integration tests:

 ```bash
   python -m pytest tests/kernels/moe/test_b12x.py -q
 ```

MXFP4 kernel-selection tests:

 ```bash
   python -m pytest \
     tests/kernels/quantization/test_mxfp4_kernel_selection.py -q
 ```

real-model inference on an NVIDIA B200 with:

 ```text
   olka-fi/Qwen3.5-35B-A3B-MXFP4
 ```

 The checkpoint uses:

 ```text
   architecture: Qwen3_5MoeForConditionalGeneration
   quant_method: compressed-tensors
   format: mxfp4-pack-quantized
   parameters: 35B total / 3B active
 ```

 The MoE backend was left as auto. Non-MoE components used Humming
 linear kernels, FlashAttention, and Triton GDN prefill to isolate the
 MXFP4 MoE path changed by this PR.
