# [Bugfix][Frontend] Preserve DeepSeek's unclosed final tool parameter

[Upstream PR](https://github.com/vllm-project/vllm/pull/58437) · state: open · merged: False

## Original PR description

## Purpose

Addresses the DeepSeek V4, V3.2, and V4.1 part of #57827. When a tool call ends without closing its final DSML parameter tag, final conversion drops that parameter. An unfinished `string="false"` value can also be dropped when it is not yet valid JSON.

This change preserves the trailing parameter in final conversion. During streaming, it defers invalid partial JSON until its type is stable, so later chunks cannot invalidate arguments already sent to the client.

Adds regression tests for streaming and non-streaming calls with string, numeric, and invalid JSON values.

Together, this PR, #58349 (MiniMax M2), and #58418 (GLM-4.7 MoE) cover all three parser cases reported in #57827. The issue should be closed once all three PRs have merged. This PR is distinct from #57707, which fixes Qwen3, and #53739, which changes the shared streaming engine.

AI assistance was used to develop this change.
