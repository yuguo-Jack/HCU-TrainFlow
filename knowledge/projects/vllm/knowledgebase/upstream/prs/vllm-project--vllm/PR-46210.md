# add torchcomms backend for xpu support

[Upstream PR](https://github.com/vllm-project/vllm/pull/46210) · state: closed · merged: False

## Original PR description

This PR adds a torchcomms backed device communicator path for vllm on XPU. The new TorchCommsCommunicator integrates with vllm's existing DeviceCommunicator and routes collectives via torchcomms/XCCL while preserving the existing XPU communicator as the default path.
