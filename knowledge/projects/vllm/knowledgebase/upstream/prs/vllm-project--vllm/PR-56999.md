# [XPU]Add support for weight cache on XPU device.

[Upstream PR](https://github.com/vllm-project/vllm/pull/56999) · state: open · merged: False

## Original PR description

Support weight cache for current XPU device, for now IPC is not supported, this PR adds the actual support path: when a tensor has no real IPC handle (XPU today), the daemon instead holds the weight on the host (pinned CPU memory) and streams it to the engine process over the existing Unix domain socket as raw bytes, still avoiding disk I/O and re-quantization on restart, at the cost of one per-engine H2D copy instead of a zero-copy device handle. On CUDA/ROCm the existing zero-copy IPC path is unchanged.
