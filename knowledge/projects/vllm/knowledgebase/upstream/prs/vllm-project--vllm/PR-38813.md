This pull request updates the MoRIIO registration format to align with the official vLLM router by modifying the message structure and parsing logic in the toy proxy server and connector. The review feedback identifies critical regressions where the removal of fields such as `dp_size`, `tp_size`, and `transfer_mode` from the registration payload and internal instance dictionaries will break the toy proxy's load balancing and state management logic, potentially leading to runtime errors.

The `instance` dictionary is missing several fields (`dp_size`, `tp_size`, `transfer_mode`) that are required for the proxy's logic. Specifically, `dp_size` is accessed in `handle_request` (line 240) for load balancing, and `transfer_mode` is needed by `_append_whole_dict_unique` to initialize the global `TRANSFER_TYPE`. Bypassing `_append_whole_dict_unique` prevents the proxy from correctly identifying the transfer mode, which will cause malfunctions in serial P-D execution (e.g., line 286). Additionally, providing default values for ports ensures robustness if the registration message is incomplete.

```python
                instance = {
                    "role": "P",
                    "request_address": f"http://{data['http_address']}/v1/completions",
                    "http_address": data["http_address"],
                    "zmq_address": data["zmq_address"],
                    "dp_size": data.get("dp_size", 1),
                    "tp_size": data.get("tp_size", 1),
                    "transfer_mode": data.get("transfer_mode", "WRITE"),
                    "handshake_port": int(MoRIIOConstants.DEFAULT_HANDSHAKE_PORT),
                    "notify_port": int(MoRIIOConstants.DEFAULT_NOTIFY_PORT),
                }
                # Parse zmq_address to extract ports (format: "handshake:6301,notify:61005")
                for part in data["zmq_address"].split(','):
                    if ':' in part:
                        key, value = part.split(':', 1)
                        if key == "handshake":
                            instance["handshake_port"] = int(value)
                        elif key == "notify":
                            instance["notify_port"] = int(value)

                with _list_lock:
                    if _append_whole_dict_unique(prefill_instances, instance):
                        print(f"Registered Prefill: {instance}")
```

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The registration message has been stripped of `dp_size`, `tp_size`, and `transfer_mode`. While this change aims to align with the official vLLM router format, these fields are essential for the `moriio_toy_proxy_server.py` example included in this repository. Without `dp_size`, the toy proxy cannot perform round-robin load balancing across data-parallel ranks, and without `transfer_mode`, it cannot correctly handle `READ` mode transfers. Most routers ignore unknown keys, so including these fields should maintain compatibility while preserving the functionality of the toy proxy.

```suggestion
                    data = {
                        "type": role,  # "P" or "D"
                        "http_address": http_address,  # Just host:port
                        "zmq_address": zmq_address,    # handshake:PORT,notify:PORT
                        "dp_size": self.moriio_config.dp_size,
                        "tp_size": self.moriio_config.tp_size,
                        "transfer_mode": self.mode.name,
                    }
```
