# [Bugfix] Read ColPali hidden size from vlm_config

[Upstream PR](https://github.com/vllm-project/vllm/pull/62714) · state: closed · merged: True

## Original PR description



## Overview

Read ColPali's projection input size from `config.vlm_config.text_config`, replacing the dict/object workaround added in #62627.

## Claims

- `hidden_size` comes from the same config vLLM builds the language model from (`vllm_config.with_hf_config(config.vlm_config)`).
- Works before and after huggingface/transformers#48282. That PR stopped parsing the top-level `text_config`, which is a leftover key in checkpoints like `vidore/colpali-v1.3-hf`, so it now stays a plain `dict`. `vlm_config` is a `PaliGemmaConfig` on every supported version.

## Validation

`AutoConfig.from_pretrained("vidore/colpali-v1.3-hf")`:

| Transformers | `type(config.vlm_config)` | `config.vlm_config.text_config.hidden_size` | `type(config.text_config)` |
|---|---|---|---|
| 5.16.1 (minimum supported, before #48282) | `PaliGemmaConfig` | 2048 | `GemmaConfig` |
| 5.20.0 (after #48282) | `PaliGemmaConfig` | 2048 | `dict` |

```bash
uv run --isolated --no-project --with transformers==5.16.1 python -c "
from transformers import AutoConfig
c = AutoConfig.from_pretrained('vidore/colpali-v1.3-hf')
print(type(c.vlm_config).__name__, c.vlm_config.text_config.hidden_size, type(c.text_config).__name__)"
```

`tests/models/multimodal/pooling/test_colpali.py` needs a GPU and was not run locally. CI covers it.
