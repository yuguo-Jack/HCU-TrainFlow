# [Model] Add longcat_next MLA/dual-attention recognition

[Upstream PR](https://github.com/vllm-project/vllm/pull/49407) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->
## Purpose

Adds `longcat_next` to two `model_type` allowlists in vLLM core that currently only recognize `"longcat_flash"`/`"longcat_flash_ngram"`. LongCat-Next reuses that backbone (`FlashNgramModel`, `FlashDecoderLayer`) unchanged, but ships under a different `model_type` string, so it falls through both checks today.

- **`gpu_model_runner.py` / `gpu/attn_utils.py`** — `num_attn_module` selection for `bind_kv_cache`'s layer-index parsing. LongCat's decoder layers have two MLA `Attention` modules per layer (e.g. `model.layers.0.self_attn.0.attn`), which needs `num_attn_module=2`.
  - Without it: `AssertionError: layer name ... should only contain one integer`
- **`model_arch_config_convertor.py`** — `is_deepseek_mla()`'s allowlist, which decides whether `get_head_size()` uses `kv_lora_rank + qk_rope_head_dim` (576, correct) or falls back to `hidden_size // num_attention_heads` (96, wrong).
  - Without it: `ValueError: Head dimension 96 is not supported by MLA.`

LongCat-Next's model/processor live in vLLM-Omni (integrated via the omni runner's `preprocess()` hook, not vLLM's native V2-runner ngram path), so this PR is scoped to just these two allowlists — no new files.

Companion PR (depends on this): vllm-project/vllm-omni#5299 

## Test Plan

- Unit: isolated checks against the real checkpoint (`meituan-longcat/LongCat-Next`) confirming `is_deepseek_mla()` → 576 and `num_attn_module=2` resolves the dual-attention layer names.
- E2E: 4×A100-40GB, TP=4, fp8 quantization, via the companion PR's deploy config — live server, 3 chat-completion requests (text/image/audio).

## Test Result

- E2E: all 3 requests succeeded (`finish_reason: stop`, no errors). Server healthy in ~5 min (74B/15-shard checkpoint, fp8).
- Not covered: generation-side stages, TP configs other than 4, CUDA graphs (`enforce_eager=True` throughout).
