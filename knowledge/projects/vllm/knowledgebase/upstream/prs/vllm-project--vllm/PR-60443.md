## Original PR description

## Overview

Use the preallocated maximum C128 sparse width in batch-invariant mode, so metadata and workspace shapes do not follow the longest request in the current batch. Keep adaptive width outside BI mode. During block-size-8 graph capture, discard the C128 boundary flag in both modes to keep replay state stable.
