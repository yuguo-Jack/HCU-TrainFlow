# [Misc] Use the b12x package shipped with flashinfer-python

[Upstream PR](https://github.com/vllm-project/vllm/pull/64765) · state: open · merged: False

## Original PR description

## Purpose

flashinfer-python 0.7.2 and later ship b12x and install it as a top-level `b12x` package, so `import b12x` already resolves to FlashInfer's copy with the `flashinfer-python==0.7.2.post1` that vLLM pins. The `b12x` extra still installs the standalone `b12x==1.5.1` package, which provides a second top-level `b12x` and overrides FlashInfer's copy depending on install order. The standalone repository is archived and development continues in FlashInfer.

This PR:
- turns the `b12x` extra into an empty list kept for backwards compatibility, like the `flashinfer` extra, so `pip install vllm[b12x]` keeps working and no longer installs the standalone package
- changes the unavailable-backend messages in the b12x attention and linear kernels to `The b12x backend requires flashinfer-python>=0.7.2` (0.7.2 is the first release that ships `b12x`), and updates the two tests that assert them
- drops the separate install step from the b12x docs pages and the commented-out Spark b12x lane in `.buildkite/test_areas/kernels.yaml`

No import paths change: `vllm/utils/b12x.py` keeps importing `b12x.*`.

Not a duplicate: no open PR changes the `b12x` extra or the b12x install path (searched open PRs for b12x).

## Test Plan

DGX Spark (GB10, SM121), image `vllm/vllm-openai:nightly-335dd77b0` with the Python `vllm/` tree and `tests/` from this branch overlaid, flashinfer-python 0.7.2.post1, torch 2.14.0+cu130, nvidia-cutlass-dsl 4.8.0, no standalone `b12x` installed.

Confirmed `b12x.__file__` is under `flashinfer/experimental/b12x/` and owned by `flashinfer-python`, and that every submodule `vllm/utils/b12x.py` loads imports from there.

```
pytest -v -s tests/model_executor/kernels/test_b12x_linear.py tests/model_executor/test_b12x_warmup.py tests/kernels/moe/test_b12x.py tests/v1/attention/test_b12x.py tests/kernels/quantization/test_block_fp8.py
pytest -v -s tests/quantization/test_auto_round.py -k b12x
```
