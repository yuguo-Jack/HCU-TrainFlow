## Original PR description

## Overview


 Enable SM90 small-head FlashMLA sparse prefill for DeepSeek V4.1 by passing the actual TP-local query heads instead of padding them to 64

Depends on https://github.com/vllm-project/FlashMLA/pull/26
<!-- Summarize the change in 1-2 lines. Link relevant issues and PRs. -->

## Claims

  - Use native 8/16/32-head sparse prefill on SM90.
  - Preserve padding for FP8 decode and other architectures.
