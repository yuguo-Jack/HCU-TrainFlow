# [Feature] Add session-scoped Agent Hint context management with kv-hints

[Upstream PR](https://github.com/vllm-project/vllm/pull/63904) · state: open · merged: False

## Original PR description

This branch combines two pieces on top of vLLM main:

- evan7ang's `kv-hints-g1` execution surface:
  - `vllm/v1/kv_hints/*`
  - `vllm/v1/core/kv_cache_priority.py`
  - transfer-backend seam and COPY_TO prefetch
- our session-scoped Agent Hint context management:
  - `agent_hint` / `messages=[]` management request
  - `SessionPrefixIndex`
  - `EngineCore.manage_context`
  - prefetch adapter over `OffloadingConnector`

The goal is to make one branch that can be installed directly to build an Ascend experiment image without juggling two overlays.

Conflict resolution:
- scheduler: keep both `BlockHash` and `eagle_proof_margin`
- connector: keep evan typed `request_free_prefetch`
- chat protocol: keep both `AgentHint` and `kv_hints_from_wire`
- gpu_worker: keep our `make_handler` + expedited-load structure, remove evan duplicate explicit handler

Validation:
- `py_compile` on changed files.
- 41 files changed vs latest main.
- Upstream CI is not yet running because the repo's pre-run label policy requires a human maintainer (`verified`/`ready` or >=4 merged PRs).

AI assistance was used. A human submitter must review every line and complete the upstream duplicate-work and CI checks.
