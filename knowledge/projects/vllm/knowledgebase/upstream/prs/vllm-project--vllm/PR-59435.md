# [Fast Start] Seed a replica's daemons from another, autotune table included

[Upstream PR](https://github.com/vllm-project/vllm/pull/59435) · state: closed · merged: False

## Original PR description




## Purpose

A second replica currently has to read the checkpoint again and repeat the FlashInfer autotune pass, even when a replica holding exactly the same shards is already running. This lets a daemon fill its shard from the corresponding rank of an already-loaded replica, and carries the source's autotune table along with the weights, so the new replica's first engine also skips the pass.

Two movers: `peer_ipc` (default) copies through CUDA IPC on one host, `rdma` pulls through the Mooncake TransferEngine across hosts. The cache fingerprints are compared before any copy, so a mismatched pairing is rejected rather than mirroring the wrong shard, and the mirror copies into its own memory so it does not depend on the source staying alive afterwards.
