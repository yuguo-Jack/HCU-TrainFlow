# [ROCm] Bump AITER to v0.1.25 and relax the DSv4.1 mono MoE tolerance

[Upstream PR](https://github.com/vllm-project/vllm/pull/61697) · state: closed · merged: True

## Original PR description

Re-land the AITER v0.1.25 bump (#61230, reverted in #61559). AITER v0.1.25's DSv4.1 tuned fused_moe rows pick fused-FP8 stage-1 kernels at TP4 whose MXFP8 scale rule differs from fused_dynamic_mx_quant_moe_sort, which the mono MoE follows, moving mono vs reference from 0.49% to 1.53% relative error. Raise the tolerance to cos > 0.9998, rel < 0.02 until ROCm/aiter#6548 is fixed.
