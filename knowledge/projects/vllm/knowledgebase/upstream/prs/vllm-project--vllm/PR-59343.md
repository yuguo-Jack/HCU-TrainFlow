# [NIXL] Share in-flight prefix loads across requests

[Upstream PR](https://github.com/vllm-project/vllm/pull/59343) · state: open · merged: False

## Original PR description

## Overview

Add opt-in sharing of unfinished NIXL prefix loads across requests with separate producer leases, following [RFC #59141](https://github.com/vllm-project/vllm/issues/59141) and dependent on [#57418](https://github.com/vllm-project/vllm/pull/57418).

Candidate `376f6836` incorporates parent `acc2479` and main snapshot `fcae5c98`. [NIXL-only comparison (16 files)](https://github.com/NolenLiang/vllm/compare/3ede47677ab1c43a6f79d1a0926e1b9b6a876378...376f6836b497b59ce556b24c568683a9773ce235); the full PR against main also includes the unmerged parent. Draft pending human review and personal test execution of this adaptation.

## Claims

- Concurrent consumers of the same leased physical producer prefix can share immutable complete destination blocks while retaining private writable tails. Each sibling has its own producer lease; matching tokens alone is insufficient.
- Followers release unused leases without another READ. Cancellation retains owner destinations and heartbeat until terminal transfer status; failures follow the parent's recompute/fail policy without rereading released follower leases.
- The rebased integration preserves the NIXL attachment callback and uses the parent's single queue removal/KV-holding transition. Existing tests now check stage counts through cancellation/completion and both receive-failure policies.

## Details

Initial scope is direct GPU pull, TP1/PP1/CP1, one full-attention cache group and prefix caching, enabled with `enable_shared_prefix_loads=true` and disabled by default. Unsupported layouts or missing producer block geometry retain independent loads. The owner keeps its full READ; followers share only complete prefix blocks before the last request token.

The parent supplies allocation, reference counting and failure propagation. NIXL adds producer/endpoint/geometry/physical-block compatibility and lease coordination. HTTP rejection cleanup tracks successful admission across child tasks. Unknown polling exceptions retain native handles; typed remote disconnect enters release, and a failed release retains the handle and blocks. Persistent unobservable native status does not promise bounded recovery.

This refresh addresses the parent's KV-holding queue and KV-fetch tracking changes. Keeping both the old pop and the parent's `skip_request` would remove a second waiting request or access an empty queue. The adaptation keeps the callback but lets the parent perform the transition once.

Before initial submission, open-PR searches found no competing #59141 implementation. [#55374](https://github.com/vllm-project/vllm/pull/55374) composes Store/NIXL ranges within one request; [#43509](https://github.com/vllm-project/vllm/pull/43509) handles best-of fan-out/early notifications. This follow-up shares an unfinished READ across distinct producer leases.
