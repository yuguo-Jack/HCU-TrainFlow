# [Bugfix][KV Connector] Pass hf3fs_metadata_server_url to Hf3fsMetadataClient

[Upstream PR](https://github.com/vllm-project/vllm/pull/62465) · state: open · merged: False

## Original PR description

## Overview

Pass the configured `hf3fs_metadata_server_url` to `Hf3fsMetadataClient` in both scheduler and worker initialization in `HF3FSKVConnector`. Fixes #62387.

## Claims

- Fixes issue #62387 where `HF3FSKVConnector` silently ignored `hf3fs_metadata_server_url` and defaulted to `http://localhost:18000`.
- Adds unit tests in `TestHF3FSKVConnectorMetadataServerUrl` verifying both scheduler and worker roles pass the configured URL.
- Guards `signal.SIGQUIT` registration with `hasattr` to prevent crashes on non-POSIX platforms.
