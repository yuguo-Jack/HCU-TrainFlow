# [Doc] Sync Kimi-K3 GB200 AgentX profiles with InferenceX #3748

[Upstream PR](https://github.com/vllm-project/vllm/pull/62542) · state: closed · merged: False

## Original PR description

## Overview

Syncs the Kimi-K3 GB200 InferenceX AgentX section with [SemiAnalysisAI/InferenceX#3748](https://github.com/SemiAnalysisAI/InferenceX/pull/3748) at [`240ad15`](https://github.com/SemiAnalysisAI/InferenceX/tree/240ad15404f7538ad5770c505ce4f78097206901/inferencex-e2e/benchmarks/multi_node/srt-slurm-recipes/kimik3/vllm/gb200-fp4/agentx), and adds both GB200 profiles to the recipe selector. It changes only `recipes/models/moonshotai/Kimi-K3.yaml`.

#62563 has been squash-merged, so this branch is no longer stacked. Current `main` is merged in: main's GB300 content is kept, plus this branch's GB200 blocks. Note that InferenceX #3748 is still in review; the NATS-removal smoke test is pending.

## Claims

- **Selector, GB200 + Multi-Node TP + Pipeline Parallel:**
  - Renders the aggregated TP8 x PP2 + DCP8 layout across four trays: K4 DSpark draft, TRTLLM_RAGGED prefill, BF16 Mamba state, gpu-mem 0.88, `--moe-backend auto`, `--language-model-only`.
  - Pins `--max-num-seqs 64` (the C=32 row).
  - Env: the lane's direct-DCP and Mooncake variables, `VLLM_MEMORY_PROFILER_ESTIMATE_CUDAGRAPHS=0` and `VLLM_RPC_TIMEOUT=600000`.
- **Selector, GB200 + Prefill/Decode + Dynamo:**
  - Renders one TP16 + DCP16 pool per role with the concurrency-16 settings: prefill 0.88/32/512, decode 0.92/32/160.
  - Includes the lane's env, `VLLM_ENGINE_READY_TIMEOUT_S=3600` / `VLLM_EXECUTE_MODEL_TIMEOUT_SECONDS=1800`, and `UCX_TLS=all` (the lane's default transports).
- **Guide, aggregated:** select the Python frontend (the lane did not enable the Rust one). Leave Spec decoding off. The builder's Mooncake option is a plain connector with a 100GB segment, so use the lane's connector and 200GB store. The command now includes the profiler, timeout and UCX memtype env.
- **Guide, disaggregated:**
  - Rewritten as per-role `python3 -m dynamo.vllm --disaggregation-mode prefill|decode` commands across four trays, with prefill `--kv-events-config`, from the run's launch lines.
  - Uses the parser flags `dynamo.vllm` accepts (`--dyn-tool-call-parser`, `--dyn-reasoning-parser`; the vLLM API-server flags are rejected).
  - Keep the default TP pools: the DEP decode pool renders an invalid TP1/DCP16 command.
  - Env adds the profiler and timeout variables and `ETCD_LEASE_TTL=600`.
  - States that NATS was running in the qualified run and that its removal has not been re-run on hardware.
- Names the `X-Dynamo-Session-Id` header and bumps `meta.date_updated`.
