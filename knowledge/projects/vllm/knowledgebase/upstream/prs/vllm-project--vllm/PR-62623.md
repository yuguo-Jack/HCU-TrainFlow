# [XPU][Test] Skip attention fusion splitting_ops check on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/62623) · state: closed · merged: True

## Original PR description

## Purpose

`tests/compile/test_config.py::test_splitting_ops_dynamic` fails on XPU: its attention-fusion block expects `splitting_ops == []` with `fuse_attn_quant=True`, but `XPUPlatform.check_and_update_config` force-disables `fuse_attn_quant` (the XPU attention backend does not support fused output quantization), so the attention splitting ops are kept. This moves that block into `test_splitting_ops_dynamic_attn_fusion`, skipped on XPU; the other checks still run on XPU.

Not a duplicate: no open PR touches this test (searched `test_splitting_ops_dynamic` / `tests/compile/test_config.py` XPU).

## Test Plan / Result

```
.venv/bin/python -m pytest tests/compile/test_config.py -k splitting_ops_dynamic -q
```
On XPU (B60): before = 1 failed; after = 1 passed, 1 skipped. `ruff check` / `ruff format --check` pass.
