# [Bugfix][Spec Decode] Log EAGLE draft RoPE parameters at startup

[Upstream PR](https://github.com/vllm-project/vllm/pull/61334) · state: open · merged: False

## Original PR description

## Overview

Make EAGLE/EAGLE-3 draft RoPE settings visible at startup, with a warning when omitted checkpoint settings resolve to base 10000 against a different target base. Fixes #61231 without changing the draft's numerical configuration.

## Claims

- Log the effective draft and target RoPE parameters, including the base and `rope_type`.
- Warn only for a missing-checkpoint-parameters fallback to base 10000; preserve explicit settings and nondefault runtime overrides.
- Account for Qwen3 Eagle3/PEagle defaults and explicit RoPE settings in Speculators' `transformer_layer_config`, and document where draft RoPE settings come from.

<summary>Config-only reproduction command</summary>

Run from the repository root. This fetches checkpoint configuration and tokenizer metadata, without model weights. Set `HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1` to reuse an existing cache, as in the October 29 validation.

```bash
VLLM_TARGET_DEVICE=cpu .venv/bin/python - <<'PY'
import logging
import torch
from vllm.config import VllmConfig, set_current_vllm_config
from vllm.config.model import ModelConfig
from vllm.config.parallel import ParallelConfig
from vllm.config.speculative import SpeculativeConfig
from vllm.model_executor.layers.rotary_embedding import get_rope

logger = logging.getLogger('vllm.config.speculative')
logger.setLevel(logging.INFO)
logger.addHandler(logging.StreamHandler())
logger.propagate = False
target = ModelConfig(
    'unsloth/Meta-Llama-3.1-8B-Instruct',
    max_model_len=512, skip_tokenizer_init=True, dtype='float32',
)
speculative = SpeculativeConfig(
    model='yuhuili/EAGLE3-LLaMA3.1-Instruct-8B', method='eagle3',
    num_speculative_tokens=3, target_model_config=target,
    target_parallel_config=ParallelConfig(),
)
with set_current_vllm_config(VllmConfig()):
    for name, hf in (
        ('draft', speculative.draft_model_config.hf_config),
        ('target', target.hf_text_config),
    ):
        rope = get_rope(
            128, max_position=hf.max_position_embeddings,
            rope_parameters=hf.rope_parameters, dtype=torch.float32,
        )
        print(f'{name}: {type(rope).__name__}, base={rope.base}')
PY
```

## Details

Transformers fills missing RoPE parameters during configuration loading, so the resolved config alone cannot distinguish an omitted base from an explicitly chosen base. Inspect the local/cached checkpoint config to make that distinction, using the requested revision and recognizing wrapped and Speculators configs. Skip the omission warning when the source config cannot be read or either model uses nested per-layer RoPE.

The diagnostic accounts for decoder-layer defaults while leaving configuration objects untouched. Keeping the draft's own settings preserves checkpoints intentionally trained with a base that differs from the target's.

**Related open implementations:** [#61320](https://github.com/vllm-project/vllm/pull/61320) and [#61321](https://github.com/vllm-project/vllm/pull/61321) also address #61231; neither is merged. This existing PR additionally covers Qwen3/PEagle defaults, Speculators' nested explicit settings, and revision-aware cache-only inspection.
