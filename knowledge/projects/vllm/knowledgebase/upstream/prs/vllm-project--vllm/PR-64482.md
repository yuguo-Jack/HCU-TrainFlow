## Overview

Adds B200 (SM100) plans for Qwen3.8-Flash-Next TP=1 BF16 linears; SM100 had TP=4 shapes only.

## Claims

- 1.35–2.24x over cuBLAS per projection; ≈ 0.6 ms saved per decode step at bs1.

## Validation

```
pytest tests/kernels/test_bf16_skinny_gemm.py -k qwen4_exp          → 38 passed, 99 skipped (B200)
qwen4_exp_low_latency_gemm vs F.linear (CUPTI, CUDA graph, 7 cells) → all faster, cold and hot L2
```
