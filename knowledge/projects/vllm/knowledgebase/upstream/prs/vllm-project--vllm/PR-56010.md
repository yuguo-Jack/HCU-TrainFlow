# [CI][XPU] Reject CUDA-IPC weight cache on non-CUDA/ROCm platforms

[Upstream PR](https://github.com/vllm-project/vllm/pull/56010) · state: closed · merged: True

## Original PR description

The weight cache daemon only exports real IPC handles for CUDA/ROCm tensors. On other platforms (e.g. XPU) it silently shipped every tensor by value in one pickle message instead, and any failure while doing so left the client with an opaque "Socket closed while receiving message" error instead of the real cause.

- Add `check_ipc_platform_support()`, called from both the engine loader and the daemon, to fail fast with a clear error on non-CUDA/ROCm platforms.
- Daemon: report handler exceptions back to the client instead of silently closing the connection.
- Skip `test_ipc_cache_cold_start_and_warm_restart` on non-CUDA/ROCm platforms.

Test: `pytest tests/model_executor/model_loader/test_weight_cache.py -v`
(passes/skips on XPU; CUDA behavior unchanged).
