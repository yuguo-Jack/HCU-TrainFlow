# [CI][Tests] Account for FP8 KV-cache rounding in MLA reference

[Upstream PR](https://github.com/vllm-project/vllm/pull/62067) · state: closed · merged: True

## Original PR description

## Overview

Make the MLA correctness reference account for FP8 KV-cache rounding. The reference currently uses the original BF16 values even when decode reads an FP8 cache, which can produce input-dependent assertion failures. Related: #62002.

## Claims

- Decode references use quantized/dequantized KV values; prefill references use rounded cached context and original new tokens.
- Preserve backend outputs, tolerances, and random-input generation. This changes only the existing test helper.

## Validation

Validated on **GB300 (SM103), CUDA 13.2, FlashInfer 0.7.2**, using the CI Python checkout `b5674c11ba`. CI uses **B200 (SM100), CUDA 13.0**; the original CI failure still needs confirmation there.

## Details

The captured FP8 query/cache values match the expected casts. Even FP64 attention on the actual FP8 Q/K/V differs from attention on the original inputs by 0.1568 on the reproduced input, exceeding the test's bound near that coordinate. The reference should model the cache format independently of the backend. It now applies the cache scale, FP8 rounding, and dequantization before computing expected attention, while preserving unquantized new tokens for prefill.

Duplicate-work check: #62047 addresses the same CI symptom by seeding each case. This PR takes a materially different approach: correct the cache representation in the reference while preserving varied inputs. Seeding does not resolve the demonstrated reference discrepancy on other valid inputs. TokenSpeed 2.0.2 and 2.0.3 produced identical outputs in the controlled reproduction.

```python
"""CPU check of the claim in vllm-project/vllm#62067 (test-only, not part of vLLM).

Replicates the SDPA reference of test_backend_correctness for the failing case (DeepSeek-R1 MLA, TP4 -> 32 heads,
GLM dims qk_nope 192 / rope 64 / v 256, kv_lora_rank 512, mixed_small, BF16, fp8 KV, k_scale 1). For each seed it
builds the reference twice: from the original BF16 cache (current test) and from the FP8-rounded cache (#62067:
decode reads every token from the cache, prefill reads cached context and BF16 new tokens). It reports how far the
two references are apart, in the test's own measure: max |a - b| and whether |a - b| > atol + rtol * |b|
(atol 0.15, rtol 0.01), i.e. whether a backend that matched the FP8 reference exactly would fail the old check.
Usage: python fp8_reference_check.py NUM_SEEDS
"""

import sys

import torch

SEQ_LENS, QUERY_LENS = [32, 40, 48, 56], [1, 1, 5, 5]
HEADS, NOPE, ROPE, V, LORA = 32, 192, 64, 256, 512
ATOL, RTOL = 0.15, 1e-2
FP8 = torch.float8_e4m3fn


def fp8_roundtrip(x, scale=1.0):
    limits = torch.finfo(FP8)
    return ((x.float() / scale).clamp(limits.min, limits.max).to(FP8).float() * scale).to(x.dtype)


def sdpa(q, k, v, mask, scale):
    out = torch.nn.functional.scaled_dot_product_attention(
        q.unsqueeze(0).transpose(1, 2).float(), k.unsqueeze(0).transpose(1, 2).float(),
        v.unsqueeze(0).transpose(1, 2).float(), attn_mask=mask, scale=scale)
    return out.transpose(1, 2).squeeze(0).to(q.dtype)


def references(seed):
    """Per sequence: (decode ref old, decode ref fp8, prefill ref old, prefill ref fp8)."""
    gen = torch.Generator().manual_seed(seed)
    dtype = torch.bfloat16
    scale = (NOPE + ROPE) ** -0.5
    w_uk = torch.randn(LORA, HEADS, NOPE, generator=gen).to(dtype) / LORA ** 0.5
    w_uv = torch.randn(LORA, HEADS, V, generator=gen).to(dtype) / LORA ** 0.5
    kv_b = torch.cat([w_uk, w_uv], dim=-1)
    rows = []
    for s_len, q_len in zip(SEQ_LENS, QUERY_LENS):
        ctx = s_len - q_len
        q = torch.randn(q_len, HEADS, NOPE + ROPE, generator=gen).to(dtype)
        kv_c = torch.randn(s_len, LORA, generator=gen).to(dtype)
        k_pe = torch.randn(s_len, 1, ROPE, generator=gen).to(dtype)
        mask = torch.ones(q_len, s_len, dtype=torch.bool)
        mask[:, ctx:] = torch.tril(torch.ones(q_len, q_len)).bool()
        q_nope, q_pe = q.split([NOPE, ROPE], dim=-1)

        def decode(kv, pe):
            q_mqa = torch.cat([torch.einsum("qnh,lnh->qnl", q_nope, w_uk), q_pe], dim=-1)
            k = torch.cat([kv, pe.squeeze(1)], dim=-1).unsqueeze(1).expand(-1, HEADS, -1)
            out = sdpa(q_mqa, k, kv.unsqueeze(1).expand(-1, HEADS, -1), mask, scale)
            return torch.einsum("qnl,lnv->qnv", out, w_uv).flatten(-2)

        def prefill(kv, pe):
            k_nope, v = torch.einsum("sl,lnh->snh", kv, kv_b).split([NOPE, V], dim=-1)
            k = torch.cat([k_nope, pe.expand(-1, HEADS, -1)], dim=-1)
            return sdpa(torch.cat([q_nope, q_pe], dim=-1), k, v, mask, scale).flatten(-2)

        kv_c8, k_pe8 = fp8_roundtrip(kv_c), fp8_roundtrip(k_pe)
        kv_c_pf = torch.cat([kv_c8[:ctx], kv_c[ctx:]])
        k_pe_pf = torch.cat([k_pe8[:ctx], k_pe[ctx:]])
        rows.append((decode(kv_c, k_pe), decode(kv_c8, k_pe8), prefill(kv_c, k_pe), prefill(kv_c_pf, k_pe_pf)))
    return rows


def main():
    seeds = int(sys.argv[1])
    worst = {"decode": (0.0, None), "prefill": (0.0, None)}
    fails = {"decode": 0, "prefill": 0}
    for seed in range(seeds):
        for path, idx in (("decode", 0), ("prefill", 2)):
            diff, fail = 0.0, False
            for row in references(seed):
                old, new = row[idx].float(), row[idx + 1].float()
                d = (old - new).abs()
                diff = max(diff, d.max().item())
                fail |= bool((d > ATOL + RTOL * new.abs()).any())
            fails[path] += fail
            if diff > worst[path][0]:
                worst[path] = (diff, seed)
    for path in worst:
        print(f"{path}: max |old ref - fp8 ref| = {worst[path][0]:.4f} (seed {worst[path][1]}); "
              f"seeds where a backend equal to the fp8 ref fails the old check: {fails[path]} / {seeds}")


if __name__ == "__main__":
    main()
```
