# [Bugfix] Handle empty and invalid YAML configs in --config parsing

[Upstream PR](https://github.com/vllm-project/vllm/pull/60319) · state: open · merged: False

## Original PR description

## Overview

Gracefully handles empty, comment-only, and non-mapping YAML configuration files supplied via `--config`, preventing unhandled `AttributeError` crashes during argument parsing.

Fixes #51618.

## Claims

- Treats empty and comment-only YAML files as an empty configuration (`{}`), avoiding `AttributeError: 'NoneType' object has no attribute 'items'`.
- Validates that parsed YAML configs are mappings (`isinstance(config, dict)`), raising a clear user-facing `ValueError` if a list or scalar is supplied.
- Adds regression unit tests in `tests/utils_/test_argparse_utils.py` for empty YAML, comment-only YAML, and non-mapping YAML inputs.

## Validation

1. **Unit Tests:**
   - Executed `test_empty_config_file` and `test_invalid_yaml_config_file` alongside existing `test_config_file` in `tests/utils_/test_argparse_utils.py`:
     - Empty YAML file -> parsed successfully with default/CLI flags preserved.
     - Comment-only YAML file -> parsed successfully.
     - Non-dict YAML files (list, scalar) -> raised expected `ValueError` with descriptive message.
2. **Lint & Code Style:**
   - `ruff check vllm/utils/argparse_utils.py tests/utils_/test_argparse_utils.py` -> Passed with 0 errors.
   - `ruff format --check vllm/utils/argparse_utils.py tests/utils_/test_argparse_utils.py` -> Clean.

## Details

In `vllm/utils/argparse_utils.py`, `FlexibleArgumentParser.load_config_file()` reads YAML files via `yaml.safe_load()`. When the YAML file is empty or contains only comments/whitespace, `yaml.safe_load()` returns `None`. The parser previously attempted to iterate directly over `config.items()`, resulting in an unhandled:
```text
AttributeError: 'NoneType' object has no attribute 'items'
```
Similarly, if a user provided a YAML file containing a YAML sequence (`- item`) or a scalar, `.items()` crashed with an obscure `AttributeError`.

The minimal, durable correction:
1. Normalizes `config is None` to `{}`.
2. Enforces mapping semantics by raising a descriptive `ValueError` when `not isinstance(config, dict)`.
