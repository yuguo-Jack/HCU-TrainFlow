# [SpecDecode] 添加 MiMo MTP 可选草稿 logit 校准

[Upstream PR](https://github.com/vllm-project/vllm/pull/62621) · state: open · merged: False

## Original PR description



## Overview

为 MiMo MTP 添加有限正数mimo_draft_logit_scale配置。采样和rejection cache消费相同scaled proposal logits，target logits与temperature保持不变；默认1.0。

来源：[Pro6000d-community公开实现与历史测试](https://github.com/PacoZhou1/Pro6000d-community/tree/d2c0ec3be319b7d8949778eefd15bb77fa693b8d)。贡献重点是尽可能为RTX PRO 6000D的具体模型算子做适配与优化；不主张此前无人优化该GPU或全球首次。

## Claims

- 非默认系数限定为MRV2、MiMo Pro/Flash、probabilistic drafting和standard rejection。
- 同一scaled logits也传给acceptance估计；配置纳入编译hash。
- 用显式配置替代原实验文件轮询；1.25只是历史试验值，不是全局推荐默认值。
