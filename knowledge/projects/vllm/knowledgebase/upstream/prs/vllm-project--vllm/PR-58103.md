# [Model] Add MarianMT encoder-decoder translation model

[Upstream PR](https://github.com/vllm-project/vllm/pull/58103) · state: closed · merged: False

## Original PR description

## Summary
Add MarianMT (Helsinki-NLP/opus-mt-*) as an encoder-decoder translation model.

## Details
- New `vllm/model_executor/models/marian.py` following the Whisper enc-dec pattern (registered via `@MULTIMODAL_REGISTRY.register_processor`, source text fed through `create_encoder_prompt`, forced decoder-start via `create_decoder_prompt`).
- Registered `MarianMTModel` in the model registry.
- Added an `_HfExamplesInfo` entry for test coverage.

## Test
- `tests/models/test_registry.py` passes for `MarianMTModel`.
- Registration + arch resolution verified (engine detects encoder-decoder).
