# [Feature][DSv4.1][NIXL] Support PCP Prefill with NIXL P/D

[Upstream PR](https://github.com/vllm-project/vllm/pull/61746) · state: open · merged: False

## Original PR description

## Overview

Enable text-only DeepSeek-V4.1-Flash P/D serving with PCP on the NIXL Prefill producer and PCP=1 on Decode.

Built on merged #59857 and stacked on #59325 and #59330. The remaining prerequisite commits are included with attribution; only the final commit, `af96945ccb`, implements this feature's model capability gate, focused tests and deployment documentation.

## Claims

- Allow GPU `NixlConnector` pull producers to use PCP with PP=DP=DCP=1 and synchronous scheduling; retain the existing model/backend restrictions and reject consumer PCP, push, bidirectional and custom connector paths.
- Reuse NIXL's canonical PCP-rank-0 transfer workers to carry compressed KV, indexer keys, the SWA tail and the compressor ring into a PCP1 decoder, including heterogeneous TP for replicated MLA caches.
- Preserve a matching N−1 handoff boundary and producer KV reclamation through the existing prerequisite fixes.

## Details

1. P stops before the final prompt token, computes the prefix with PCP and gathers cache writes/open ratio-2 state onto equivalent replicas.
2. D reads the compressed KV, indexer keys, SWA tail and per-request compressor ring from the PCP-rank-0 replica's TP workers. Non-transferring PCP ranks retain their synthetic completion notifications.
3. D resumes at N−1, computes the final prompt token and closes any pending ratio-2 pair using the transferred ring. NIXL completion notifications release the producer's replicas.

Both sides use NVIDIA CUDA, Model Runner V2, `FLASHMLA_SPARSE_DSV41`, the same KV dtype/block size and this revision. The initial configuration uses GPU buffers, eager execution, no prefix caching, no SWA bounded replay, no speculative decoding and no microbatching. The usage guide includes TP4/PCP2 Prefill and TP8/PCP1 Decode arguments. Both sides must keep handshake compatibility checks enabled; the inherited N−1 protocol change uses NIXL version 15 because main already assigned version 14 to the PLE metadata change.

This does not duplicate the open fixes: #59325 owns the generic replicated-PCP completion repair and #59330 owns the generic P/D endpoint change. They are reused here without a competing implementation. #58289 targets encoder-only Prefill, and #61121 optimizes packed-row transfer registration; neither enables this full-model V4.1 PCP/NIXL path. Main already includes the generic MoE padding fix from #60946.

Local CPU/static checks: `VLLM_TARGET_DEVICE=cpu .venv/bin/python -m pytest tests/models/test_deepseek_v41_pcp.py tests/v1/kv_connector/unit/test_nixl_connector_hma.py tests/v1/kv_connector/unit/test_nixl_connector.py tests/v1/kv_connector/unit/test_nixl_desc_geometry.py -k 'pcp or dsv41_nixl_handoff or mamba_n1 or ring_scratch' --confcutdir=tests -p no:cacheprovider -q` covers 57 passing cases; `pre-commit run --from-ref origin/main --to-ref HEAD` and `git diff --check origin/main` pass.
