# [Feature][DSv4.1][NIXL] Enable PCP Prefill with NIXL P/D

[Upstream PR](https://github.com/vllm-project/vllm/pull/61746) · state: open · merged: False

## Original PR description

## Overview

Follow-up to #59857, enabling text-only DeepSeek-V4.1-Flash PCP Prefill with NIXL P/D. Stacked on #59325 for replicated-PCP producer completion.

## Claims

- Allow GPU `NixlConnector` pull producers to use PCP, with PCP=1 on Decode.
- Allow fixed-length DSpark and optional APC with SWA bounded replay.
- Retain PP=DP=DCP=1 and synchronous scheduling. Consumer PCP, push, bidirectional transfer and custom connector paths remain unsupported.
