# [Feature][Quantization] Support compressed-tensors FP8 Marlin cache restarts

<!-- markdownlint-disable -->

## Overview

Allow serialized compressed-tensors W8A8 FP8 tensor/channel checkpoints to reuse Marlin-packed weights through the weight cache daemon. Follow-up to #63673 for #56049; the [five-file incremental diff](https://github.com/liusy58/vllm/compare/4d954d5d1289d3940116fdafca757a12aa363873...8aa5f2005b3f006d6a0b6f3164de48cca691c2aa) isolates this feature.

## Claims

- Preserve packed weights, reordered scales and padded/permuted bias across repeated IPC attachments without rerunning Marlin post-processing.
- Support tensor/channel FP8 weights with FP16/BF16 activations. Block FP8, MoE and other compressed-tensors schemes remain excluded.
- Preserve the CUTLASS path and existing model-output assertions. The FP8 format guide links directly to Marlin setup and limitations.

## Details

Marlin's constructor creates the runtime state, while its post-load hook repacks weights and transforms scales/bias. The existing processed-weight early return can therefore reuse the daemon tensors. The capability opt-in checks the actual Marlin kernel and rejects block strategy; no kernel or common loader interface changes.

This revision replays only the Marlin increment onto the current #63673 head `4d954d5d1289d3940116fdafca757a12aa363873`, removing conflicts inherited from the old stack and retaining maintainer changes already merged to main. It still depends on #63673; the incremental diff above excludes that prerequisite. It merges cleanly with main `625d2d74e` in the local merge-tree check.

Duplicate checks covered #56049, compressed-tensors IPC and Marlin FP8. #63673 supplies the prerequisite; #64182 covers AWQ/GPTQ; #42657 concerns ordinary W8A16 processing. None duplicates this W8A8 Marlin IPC feature.
