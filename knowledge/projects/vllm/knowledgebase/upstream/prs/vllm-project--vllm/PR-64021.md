# [CI] Remove codeowner for pre-commit allowlists

[Upstream PR](https://github.com/vllm-project/vllm/pull/64021) · state: closed · merged: True

## Original PR description



## Overview

Stop requesting @hmellor's review for edits to the pre-commit allowlists in `tools/pre_commit/*_allowlist.txt`.

## Claims

- PRs that only touch `test_tethering_allowlist.txt` (or future `*_allowlist.txt` files) no longer get an automatic codeowner review request; the rest of `tools/pre_commit` stays owned.

## Validation

CODEOWNERS uses the last matching pattern, and a pattern with no owners makes matching files unowned, so the new line overrides `/tools/pre_commit @hmellor` for the allowlists only.
