# [Model] Add Laya decision model (convaiinnovations/laya)

[Upstream PR](https://github.com/vllm-project/vllm/pull/58812) · state: open · merged: False

## Original PR description

## Purpose

Add Laya (`convaiinnovations/laya`) to vLLM as a pooling model.

This is the vLLM-side part, split out from the vLLM-Ascend integration PR so
that each repository carries only the change it needs. The Ascend-specific
pieces stay in the vLLM-Ascend PR and are not part of this one.

Laya is a 421M non-autoregressive decision model: a ModernBERT-large encoder
plus a 2-layer Transformer decision head. It never generates text — given a
`state` and typed questions it returns typed answers with calibrated
probabilities in a single forward pass, so there is nothing to parse and
nothing to hallucinate.

- `vllm/model_executor/models/laya.py`: `LayaForDecision`
- `vllm/model_executor/models/registry.py`: register `LayaForDecision`
- `vllm/config/vllm.py`: honor `VLLM_LAYA_ALLOW_FULL_CG=1` to allow a pooling
  model to run with full cudagraph

## Test Plan

Model loading and inference were validated on the Ascend backend through the
companion vLLM-Ascend PR. On the vLLM side the change is the model
registration and the config opt-in described above.
