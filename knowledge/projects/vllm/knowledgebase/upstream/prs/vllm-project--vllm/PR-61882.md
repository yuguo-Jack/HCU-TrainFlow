# [Refactor][MRV2] Split decode and mixed CUDA graph capture planning

[Upstream PR](https://github.com/vllm-project/vllm/pull/61882) · state: open · merged: False

## Original PR description

## Overview

Split MRV2 CUDA graph descriptor generation into decode-only and prefill/mixed builders. `_init_candidates()` retains the shared sorting and candidate indexing. Fixes #61881.

## Claims

Preserves the shared capture sizes, descriptor order and dispatch priorities. Adds regression tests for mode/LoRA selection and rounded-size deduplication.

## Validation

Baseline: `957d512e96`. H100, BF16, MRV2; both checkouts use the same native build.

- 87 tests passed on the updated branch, including 16 added cases; pre-commit passed.
- 960 configurations / 76,800 dispatch comparisons: identical capture plans, candidate lists and decisions.
- Composition with #56136 (`6ab4d6a43f`): reproduced the missing-import failure before the follow-up; both merge orders now produce the same conflict-free file, and all 46 combined planner/dynamic-SD tests pass.
- Follow-up Qwen3-4B/DFlash MRV2 smoke: 41 requests, dynamic K=5/3/1, FULL target/drafter replay, and nonzero acceptance.
- Qwen3 engine A/B: matching capture plans and actual FULL graph replay in every configuration below; nonzero speculative acceptance.

| Target / drafter | TP | Speculation |
|---|---:|---|
| Qwen3-8B | 1 | Disabled |
| Qwen3-8B / Qwen3-0.6B | 1 | K=3 |
| Qwen3-4B / DFlash | 1, 2 | Dynamic K=5/3/1 |
| Qwen3-4B / DSpark | 1 | Adaptive verification |

The full TP=1 workloads cover 128/4096 input tokens, 1/256 output tokens, concurrency 1/8/64 and staggered arrivals. Adaptive and TP=2 runs include varied chat/code prompts.

## Details

Decode planning retains speculative-length expansion, variable-length handling, rounding and deduplication; mixed planning retains its request-shape constraints. `FULL` keeps its mixed-routine semantics. Runtime dispatch and graph capture are unchanged.
Retains `defaultdict(list)` for descriptor aggregation, preserving the import needed when composed with #56136.

No duplicate refactor found in issue/PR searches. Related #56136 changes candidate ladders, #60265 changes the default capture ceiling, and #60989 adds standalone-draft graph support; this PR changes none of those policies.
