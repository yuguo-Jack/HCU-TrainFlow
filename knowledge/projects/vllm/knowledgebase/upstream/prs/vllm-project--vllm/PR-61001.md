## Overview

This is a first draft of a suggestion on the design of the monokernel abstraction layer. Feedback is encouraged and appreciated!

### Validation

Three types of validation needed to run a monokernel:
1. **Before model load**: check vllm_config and platform. _If no -> crash_
2. **After model load**: 
    1. **Model-wide check**: Ensure model is aligned with the monokernel. Example: requires mxfp4 moe backend. _If no -> crash_ 
    2. **Layer-wise check**: Ensure the layer is aligned with the monokernel. E.g. require layer not to be an MTP layer, i.e. `attn.layer_id <= num_hidden_layers`. _If no -> fallback_.
3. **At runtime** (every invocation): (1) once for all ranks: check row count, attn metadata (2) per rank: health check, poll, vote. If no -> fallback to vllm impl

Hence two types of methods:
- `refuse_*`. crash if not supported. Example: `refuse_config(vllm_config)`
- `skip_*`: fall back to native vllm impl if not supported. Example: `skip_layer(layer)`

### Abstractions 

Four abstractions:
1. `MonoOp`: key entrypoint of a _logical_ monokernel. This is the glue between model code and the flydsl monokernel. It can be used in place of an entire layer, or parts of a layer. Under the hood it can be a single launch or multiple (k1/k2), but from the outside it's considered a single fused operation.
    1. **Note:** here we deviate from https://github.com/vllm-project/vllm/issues/60904, which proposed two modes: "full layer" and "ffn" mode. We make this more general because PR's like https://github.com/vllm-project/vllm/pull/60683 wants both full-layer mode, ffn-mode, and k2-mode (i.e. o-proj --...--> MoE AR)
    2. To implement this, we use a sort of reverse injection to offload the decision of what layers should use "full mode" and "ffn mode" etc. We do this as follows: 
        1. The model (like `DeepseekV4Model`) creates a MonoOp in its constructor, and passes in its layers
        2. The MonoOp is responsible for determining what monokernel to use for layer `i`, and binds `self.layers[i].mono = selected_monokernel`
        3. The actual layer does: `if self.mono is not None: self.mono.forward(...)`, unaware of what it actually being called as a monoop. The MonoOp is the one deciding if it's "eager+mono_ffn" or "full layer",
4. `MonoSpec`: declaration of when the MonoOp can run
5. `MonoKernel`: the flydsl launcher
6. `MonoRuntime`: shared utilities, e.g. for managing scratch space


### Adding a new monokernel

A new monokernel writer needs to write three things

1. A `MonoSpec` literal declaring supported features and constraints.
4. A `MonoKernel` implementation: the FlyDSL kernel and its launch.
5. A `MonoOp` subclass: the glue between vLLM model and the flydsl monokernel. This includes code for determining whether to run the monokernel for the given problem shape, and converting model weights into the format expected by flydsl. 

### Deviations from RFC

1. We make MonoSpec arch specific. E.g. gfx942 and 950 might have different max_rows and support different features. Implemented wiht `MonoOp.variant(vllm_config) -> Self`.
2. We don't enforce "whole layer mode" and "ffn mode" only. You can instead run a monokernel for arbitrary parts of a layer using MonoOp: `self.mono.ffn_only[layer_id].forward()` or `self.mono.window[layer_id].forward()`.  
3.

```python
# vllm/models/deepseek_v41/amd/mono_decode.py

DSV41_MONO = MonoSpec(
    name="DSv4.1 mono decode",
    supports=frozenset({Feature.SPECULATIVE_DECODE}),
    tp_sizes=(2, 4),
    device_archs=("gfx950",),  # the kernels' ISA: scaled MFMA and MX formats
    widths=tuple(range(1, MAX_ROWS + 1)),
    kernel_module="vllm.models.deepseek_v41.amd.mono.runner",
    resident_blocks="BLOCKS",
    constraints=(_needs_a8w4_moe,),
    opt_in=lambda c: bool(envs.VLLM_ROCM_MONO_DECODE),
    on_refusal="raise",  # the opt-in was explicit: say why it cannot be served
)

class DSV41MonoDecode(MonoOp):
    spec = DSV41_MONO

    def __init__(self, vllm_config, layer: "DeepseekV4DecoderLayer") -> None:
        self.layer = layer

        self.vllm_config = vllm_config
        super().__init__(vllm_config)
        self._weights: MonoLayerWeights | None = None
        self._kernels: DSV41MonoLayer | None = None

    def refuse_model(self) -> list[str]:
        backend = getattr(experts.quant_method, "mxfp4_backend", None)
        if backend != Mxfp4MoeBackend.AITER_MXFP4_BF16:
            return [f"needs the AITER_MXFP4_BF16 MoE backend, not {backend}"]
        return []

    def skip_layer(self, layer: "DeepseekV4DecoderLayer") -> str:
        attn, ffn = layer.attn, layer.ffn
        if attn.layer_id >= hf.num_hidden_layers:
            return "draft layer"
        return ""

    def build(self) -> None:
        """Attach self to each layer. Here we make the decision on how to run the layer being substituted for the monokernel. 

       Example:
           - "ffn only" layers: record which layer this is, and disable reduction on the out projection
           - "whole layers": set the `mono` attribute on the layer
           - ... other layers can be treated differently if needed
"""
        self.rt = MonoRuntime(
            DSV41_MONO,
            self.vllm_config,
            peer_factory=peer_factory,
            epoch_words=EPOCH_WORDS,
        )
        for layer in self.mono_layers(self.layers):
            why_ffn_only = "Engram" if layer.engram is not None else None
            self.ffn_only[layer.attn.layer_id] = bool(why_ffn_only )
            layer.mono = self
            if why_ffn_only :
                layer.attn.wo_b.reduce_results = False
        if not self.ffn_only:
            self.skips.append("no layer with the kernels' seams and MoE")

    @property
    def kernels(self):
        if self._kernels is None:
            from vllm.models.deepseek_v41.amd.mono.runner import DSV41MonoLayer

            self._kernels = DSV41MonoLayer(self.rt)
        return self._kernels

    @property
    def weights(self):
        from vllm.models.deepseek_v41.amd.mono.runner import MonoLayerWeights

        layer = self.layer
        a, f = layer.attn, layer.ffn
        e, sh = f.experts.routed_experts, f.shared_experts
        self._weights = MonoLayerWeights(
            attn=None if self.ffn_only else self._attn_weights(a),
            hc_attn_fn=layer.hc_attn_fn)

    def skip_step(self, rows: int, tensors, whole_layer: bool) -> str:
        if not is_forward_context_available():
            return "no forward context"
        fc = get_forward_context()
        if not self.spec.graph_mode_ok(fc.cudagraph_runtime_mode):
            return f"{fc.cudagraph_runtime_mode} step"

    def forward(
        self,
        x: torch.Tensor,
        positions: torch.Tensor,
        residual: torch.Tensor | None,
    ):
        if residual is None or x.dim() != 2:
            return self._skip("first layer")
        tensors = (x, residual, post_mix, res_mix, pre_mix)
        step = self.step(x.shape[0], tensors, whole_layer=True)
        if not step:
            return self._skip(step.reason)
        attn = self.layer.attn
        logger.info_once(
            "DSv4.1 mono decode layer active (decode steps of <= %d rows)", MAX_ROWS
        )
        return self.kernels.forward(
            self.weights,
            x,
            residual,
            post_mix,
            ),
            comp_block_table=comp.block_table,
        )
```

DSV41_MONO_942 = replace(

    """The model: the seams and MoE routing these kernels need, either ISA."""

    def refuse_model(self):
        """These kernels read the experts in AITER's A8W4 MXFP4 layout."""
        ...

class DSV41MonoDecodeGfx942(DSV41MonoDecode):
    spec = DSV41_MONO_942

    def __init__(self, vllm_config, layers):
        super().__init__(vllm_config, layers)
        self._copy_weights_at_load()  # pre-load: the copies size the KV cache

    def skip_layer(self, layer):
        if why := super().skip_layer(layer):
            return why
        if get_tensor_model_parallel_world_size() != 4:
