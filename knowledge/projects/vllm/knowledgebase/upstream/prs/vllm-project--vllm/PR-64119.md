# [Fast Start] Support ModelOpt CUTLASS block FP8 cache restarts

[Upstream PR](https://github.com/vllm-project/vllm/pull/64119) · state: closed · merged: True

## Original PR description

## Overview

Enable CUDA IPC weight-cache restarts for serialized ModelOpt FP8_PB_WO linear weights. Part of #56049.

This is now independent, directly based on main `34d5de18cd8b`. [Review only this feature](https://github.com/liusy58/vllm/compare/34d5de18cd8baf9f5958e45720858939863a7264...d6dd5d7f978059899d2f266e28a038f9fada6122); head `d6dd5d7f9780`. Rebuilt in response to Zifeng’s request to decouple the stacked PRs.

## Claims

- Reuse processed weights/scales across engine restarts with the validated CUTLASS backend.
- Preserve exact outputs, shared storage and required Python metadata; unsupported configurations remain rejected.
- Include only this feature and its necessary common plumbing beyond merged main.

## Validation

B300, November 4, exact source hashes verified against this head:

| Check | Result |
|---|---|
| Layer/configuration regressions | 116 passed, 3 pre-existing skips in 251.81s |
| Real model: ordinary → fallback → IPC → second IPC | 1 passed in 113.40s |
| All changed-file pre-commit hooks | Passed, including mypy, ruff and CI test tethering |

Both IPC loads forbid fallback. Exact greedy outputs use `VLLM_BATCH_INVARIANT=1`; layer tests also verify shared pointers and unchanged tensors. The real model is `CedricHwang/qwen2.5-0.5b-modelopt-fp8-pb-wo`, pinned to `62bb490e7095973375c7b97b54b3af733d67c973`, with its checked-in configuration unchanged. The three legacy suite skips need unavailable local/offline checkpoints; the separate pinned IPC test did not skip. Partial output widths are covered by the real layer tests; this small full model has aligned widths.

```bash
CUDA_VISIBLE_DEVICES=7 HF_HUB_OFFLINE=1 PYTHONPATH=. .venv/bin/python -m pytest tests/quantization/test_modelopt.py -q -rs
CUDA_VISIBLE_DEVICES=7 HF_HUB_OFFLINE=1 PYTHONPATH=. .venv/bin/python -m pytest tests/model_executor/model_loader/test_weight_cache.py::test_ipc_cache_modelopt_block_fp8 -q -rs
pre-commit run --files $(git diff 34d5de18cd8baf9f5958e45720858939863a7264 HEAD --name-only)
```

The isolated runtime used Python 3.12, Torch 2.14/cu130, FlashInfer 0.7.2.post1, process-local CUDAcompat13.4, and reused stable extensions from `5d55ef159`. Relevant CUTLASS FP8 C++ is unchanged; unrelated HiSparse binding and removed Qutlass-wrapper changes are outside these tests. This is targeted smoke/output equivalence, not a pristine full-source rebuild, full accuracy evaluation, performance benchmark, or upstream GPU CI result. No new skips, retries or weakened assertions were added. GPU occupancy guards prevented launches onto busy GPUs; other workloads were untouched.

## Details

Opt in only kFp8Static128BlockSym with the CUTLASS block-FP8 kernel and the built-in partial-block format. Restore the logical output width for a padded trailing block without reprocessing weights. The tensor/channel implementation from #63754 is already on main; its maintainer-removed redundant tests are not reintroduced.

No dependency on any unmerged quantization PR remains. #63672 and #63754 are already merged.
