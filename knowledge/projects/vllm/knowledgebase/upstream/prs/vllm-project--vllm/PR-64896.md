# [Bugfix][DSA] Skip sparse indexer prefill work for empty chunks

[Upstream PR](https://github.com/vllm-project/vllm/pull/64896) · state: open · merged: False

## Original PR description

Fix the empty `max()` regression introduced by #59131  during MRV2 CUDA Graph initialization.

## Claims

- Skip prefill workspace allocation and scoring when `prefill.chunks` is empty.
- Preserve top-k initialization and the independent decode branch, including mixed batches.

## Validation

## Details

With capture size 64 and `--max-num-seqs=32`, MRV2 creates two-token requests. They exceed the indexer decode threshold of 1 but compress to zero KV entries (`2 // 4 = 0`), leaving `num_prefills > 0` with `prefill.chunks == []`.

#59131 sizes workspace from the largest actual chunk without handling an empty list. Ordinary warmup can skip indexer scoring through the short-context optimization; CUDA Graph capture disables that shortcut and exposes the failure.

The fix guards only prefill allocation and computation, preserving top-k initialization and subsequent decode processing. It introduces no device synchronization. Regression tests, CI selection, and troubleshooting docs are included.
