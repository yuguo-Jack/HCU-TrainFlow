# [Bugfix] Fast-fail DFlash2 FP16 speculative decoding

[Upstream PR](https://github.com/vllm-project/vllm/pull/55294) · state: open · merged: False

## Original PR description

## Motivation

Fixes #55250. DFlash2 drafts inherit the target dtype. Casting the
BF16-trained draft to FP16 can overflow its grouped-convolution residual
stream to `inf`/`NaN`; candidate selection then produces invalid drafts and
the target accepts none of them.

This reproduces on CUDA: `incoai/Qwen3.8-27B-DFlash2` with
`Qwen3.8-27B-FP8` had 0 accepted tokens from 1,100+ FP16 drafts, while the
same setup in BF16 reached 37-41% draft acceptance.

## Fix

Fail fast for `DFlash2DraftModel` with `--dtype float16` and instruct users
to use `--dtype bfloat16`, rather than silently running ineffective
speculative decoding.
