# [XPU][CI] Skip tests/compile/h100/test_startup.py on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/57509) · state: closed · merged: False

## Original PR description

## Purpose
tests/compile/h100/test_startup.py requires CUDA/H100. The `intel-ci` pipeline runs this test area's commands without honoring the `device` selector, executing the file on XPU where torch's compile cache ends up disabled, so every `cold_artifacts_saved`/`warm_artifacts_saved` assertion fails with `got 0`.

## Test Plan
Add `current_platform.is_cuda()` skip, same pattern used elsewhere in tests/compile/ (e.g. test_tp2_async_tp.py).

## Test Result
Module now collects as skipped on non-CUDA platforms; full run requires H100 hardware, exercised by existing CUDA CI.
