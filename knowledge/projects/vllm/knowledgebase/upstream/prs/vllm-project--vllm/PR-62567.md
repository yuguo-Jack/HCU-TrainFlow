# [CI] Keep the AMD mirrors of the nightly-only 4xL4 steps on PRs

[Upstream PR](https://github.com/vllm-project/vllm/pull/62567) · state: closed · merged: True

## Original PR description

## Purpose

#62564 made eight 4-GPU L4 steps `optional: true` (nightly only) to relieve the `l4-k8s` queue. An AMD mirror inherits `optional` from its step (`_get_amd_mirror_effective_step`: `amd.get("optional", step.optional)`), so their AMD mirrors stopped running on PRs too. AMD capacity is separate from L4 and AMD wants this per-PR coverage, so this sets `optional: false` on those eight mirrors:

- (MI355) Distributed NixlConnector PD accuracy
- (MI355) Distributed FlashInfer NixlConnector PD accuracy
- (MI355) Push NixlConnector PP prefill PD accuracy
- (MI355) DP EP Distributed NixlConnector PD accuracy
- (MI355) CrossLayer KV layout Distributed NixlConnector PD accuracy
- (MI355) Hybrid SSM NixlConnector PD accuracy
- (MI355) Distributed DP Extended
- (MI250) Pipeline + Context Parallelism

The L4 steps stay nightly only.

## Test Plan

Ran ci-infra `main`'s `_step_should_run` / `_amd_mirror_should_run` on the edited YAML with a diff touching each step's source dependency:
- PR build: 0/8 L4 steps auto-selected, 8/8 AMD mirrors auto-selected.
- Nightly build: 8/8 L4 steps and 8/8 AMD mirrors selected.
