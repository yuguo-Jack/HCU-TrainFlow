# [Core] Shared abstractions for specialized decode kernels

[Upstream PR](https://github.com/vllm-project/vllm/pull/61311) · state: open · merged: False

## Original PR description

_(the text below is written by myself)_

Purpose
1. increase standardization without imposing restrictions on kernel implementations
2. limit LoC changes in model files as a result from adding numerous specialized decode kernels

The kernels themselves will naturally remain difficult to review thoroughly, but **ideally model code should remain easy to review**. The abstraction layer should deliberately be made as thin as possible,

**Note: you can run with either `--monokernel` or `--specialized-decode monokernel`**

# Claims

1. Add `DecodeSpec` and `SpecializedDecode` abstractions in `vllm/models/common/specialized_decode/` 
2. Refactor DSv41 on gfx950 and gfx942 to use these abstractions
3. No regression

For details on point 1, see design doc in the end of the PR description.

# Validation 

Check no regression on dsv41

- Fangzhou-Ai · comment · 2026-10-22T21:19:35Z · [source](https://github.com/vllm-project/vllm/pull/61311#issuecomment-6351553812)

Hi @simondanielsson  thanks for the work!
