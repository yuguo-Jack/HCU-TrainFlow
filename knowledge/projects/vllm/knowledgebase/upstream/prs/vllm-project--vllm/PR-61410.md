# [Bugfix] Preserve integer tool argument precision

[Upstream PR](https://github.com/vllm-project/vllm/pull/61410) · state: open · merged: False

## Original PR description



## Overview

Fix precision loss when converting string tool arguments to schema-declared integers in the response-template parser.

## Details

The integer fallback previously converted strings through `float()`, which could round large values or small fractions. For example, `9223372036854775807.0` could become `9223372036854775808`, while `1e-400` could become `0`.

Use `Decimal` to check whether the original value is integral and convert it to an integer without losing precision. Keep the existing float-based validation and fallback behavior for unsupported values.

## Validation
