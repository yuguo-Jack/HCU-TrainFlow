# [KV Offload] Align KVCR cache recency with request prefixes

[Upstream PR](https://github.com/vllm-project/vllm/pull/60469) · state: closed · merged: True

## Original PR description

## Overview

Use KVCR’s `align_sequence()` API to align cached blocks in request-prefix order after load/store completion and refresh the processed prefix when a request finishes. Finalization excludes in-flight work and the uncommitted final sampled token.

Depends on #57646, which exposes the request token counts needed to identify the processed prefix. No matching implementation was found among open PRs.

## Validation

Regression tests added in `tests/v1/kv_offload/tiering/test_kvcr_tier.py` cover processed-prefix filtering, resident-prefix inclusion, and batching consecutive completions while preserving cross-request ordering. All pass.

AI-assisted implementation.
