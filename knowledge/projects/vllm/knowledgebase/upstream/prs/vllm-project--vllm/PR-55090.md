# [ROCm][Perf] Pad fp16/bf16 GEMM weight row stride for L2 cache

[Upstream PR](https://github.com/vllm-project/vllm/pull/55090) · state: closed · merged: True

## Original PR description

On gfx11 (RDNA3/3.5) a dense GEMM whose weight row stride is a multiple of 2048 bytes collide on the L2/MALL hashes, costing a large share of achievable bandwidth. Offsetting the row stride by one 128 B cache line dodges the collision.
This PR improves TTFT by up to 13% and TPOT by up to 3%.

We pad the row stride once in `UnquantizedLinearMethod.process_weights_after_loading`.
It has a minimal impact on memory consumption on affected layers only (1.29 % of weight memory for Qwen3-8B: 171 MiB on 12.94 GiB).

The predicate is `(K * element_size) % 2048 == 0`, so for bf16/fp16 it fires on any layer
with `K % 1024 == 0`. That covers most of the Llama/Qwen dense family: for Qwen3-8B all
four linears qualify (`qkv`/`o`/`gate_up` `K=4096` → 8192 B, `down` `K=12288` → 24576 B).

Gated on gfx11. This might also apply to gfx12, but we will need to measure and can enable as a follow up.

nit:

The routing behavior here is correctly scoped to gfx11 as far as I can trace it, but the code is creating this boolean condition, `use_skinny`, and then re-evaluating the conditions inside the block, which is confusing to reason about. 

This might be a bit chunky for this PR, but I recommend breaking the conditions down into separate checks and composing them, for clarity

e.g.
```
skinny_gemm_enabled = (
    envs.VLLM_ROCM_USE_SKINNY_GEMM
    and (on_gfx9() or on_gfx1x())
    and x.dtype in (torch.float16, torch.bfloat16)
    and k % 8 == 0
)

bias_ok = bias is None or bias.is_contiguous()
weight_dense = weight.is_contiguous()

# wvSplitK reads the weight row stride, so a gfx11 cache-aliasing-padded
# (K-contiguous) weight is fine; LLMM1 indexes off a raw pointer and needs dense.
weight_ok_for_wvsplitk = weight_dense or (on_gfx11() and weight.stride(1) == 1)

use_wvsplitk = (
    skinny_gemm_enabled and weight_ok_for_wvsplitk and bias_ok
    and m > 8 and 0 < n <= 5
)

use_llmm1 = (
    skinny_gemm_enabled and weight_dense and bias is None
    and m % 4 == 0 and n == 1 and k <= 8192
)

if use_wvsplitk or use_llmm1:
    x_view = x.reshape(-1, x.size(-1)).contiguous()
    if use_wvsplitk:
        out = ops.wvSplitK(weight, x_view, num_compute_units(), bias)
        return out.reshape(*x.shape[:-1], weight.shape[0])
    out = ops.LLMM1(weight, x_view, 4)                                         
    return out.reshape(*x.shape[:-1], weight.shape[0])
```
