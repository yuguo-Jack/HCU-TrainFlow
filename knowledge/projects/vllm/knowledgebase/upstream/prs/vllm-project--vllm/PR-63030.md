# [WIP][Spec Decode] Drafter early exit in a CUDA graph WHILE node

[Upstream PR](https://github.com/vllm-project/vllm/pull/63030) · state: open · merged: False

## Original PR description

Autoregressive drafters (MTP, EAGLE) can stop drafting on the GPU without a host sync, so async scheduling is preserved. With VLLM_DYN_DRAFT set, the captured FULL decode graph runs draft steps 1..k-1 inside one CUDA graph WHILE node; a Triton kernel decides after each step whether the batch's expected gain from the next draft position (from the acceptance estimator's confidences) clears a threshold that adaptive verification derives from its cost model each step ("cost"), or never stops ("full").

Adaptive verification still admits as many drafts as the CPU budgeted, since the CPU-built batch layout depends on it; admitted drafts at positions the drafter skipped are verified as placeholders through the invalid-draft path, so outputs are unchanged, and the acceptance estimator is graded only on drafted positions.

The loop body's TP collectives run on a split pynccl communicator with graphUsageMode=1, since NCCL's default graph mixing adds event nodes that a conditional body may not hold, and the body syncs vLLM's cached current stream with the capture stream.
