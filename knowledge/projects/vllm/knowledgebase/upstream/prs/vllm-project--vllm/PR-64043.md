# feat: Token-sharded sparse-MLA prefill for DeepSeek-V3 on SM120

[Upstream PR](https://github.com/vllm-project/vllm/pull/64043) · state: closed · merged: False

## Original PR description

Implements token-sharded sparse prefill for MLA attention used in DeepSeek-V3 on Blackwell (SM120).

Key features:
- Token sharding distributes prefill tokens across SMs
- Sparse attention using top-k indices from indexer
- fp8_ds_mla KV cache layout required
- SM120 (Blackwell) only, uses FlashInfer trtllm-gen sparse MLA kernel

AI usage disclosure: NO
