# [XPU] support adaptive verification for deepseek-v4

[Upstream PR](https://github.com/vllm-project/vllm/pull/62309) · state: open · merged: False

## Original PR description



## Overview

This PR enables the functionality of Deepseek-v4 adaptive verification, running on 8xB70 cards, with command:
```
vllm serve deepseek-ai/DeepSeek-V4-Flash-DSpark \
  --port 8000 \
  --tokenizer-mode deepseek_v4 --trust-remote-code \
  --tensor-parallel-size 8 --enable-expert-parallel \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.9 \
  --max-num-batched-tokens 8192 --max-num-seqs 16 \
  --compilation-config '{"cudagraph_mode":"FULL_DECODE_ONLY"}' \
  --speculative-config '{
    "method":"dspark",
    "model":"deepseek-ai/DeepSeek-V4-Flash-DSpark",
    "attention_backend":"FLASH_ATTN",
    "num_speculative_tokens":7,
    "draft_sample_method":"probabilistic",
    "enable_adaptive_verification":true
  }
```
