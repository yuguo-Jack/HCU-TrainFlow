## Code Review

This pull request refactors DeepSeek model implementations to consistently use fused projections for the indexer, specifically handling cases where weights are stored in FP8 by dequantizing them to BF16 during loading. It also automatically enables PDL environment variables for Hopper GPUs. Review feedback suggests improving ROCm compatibility by using the is_fp8 helper, addressing potential indexing errors and hardcoded dtypes in the dequantization logic, and adding logging for the automatic environment variable updates.

### vllm/model_executor/models/deepseek_v2.py (764-775)

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The calculation of `block_size` assumes `scale_inv` is at least 2D, which may lead to an `IndexError` if the checkpoint uses per-tensor or per-channel quantization (0D or 1D scales). Additionally, dequantizing to a hardcoded `torch.bfloat16` might cause issues if the model is running in `float16`. It's safer to use the parameter's own dtype.

```python
    fused_name = f"{layer_prefix}.wk_weights_proj.weight"
    param = params_dict[fused_name]

    if scale_inv.ndim > 0:
        block_size = weight_fp8.shape[1] // scale_inv.shape[-1]
        group_shape = GroupShape(block_size, block_size)
    else:
        group_shape = GroupShape.PER_TENSOR

    weight_dequant = scaled_dequantize(
        weight_fp8,
        scale_inv,
        group_shape=group_shape,
        out_dtype=param.dtype,
    )

    # Load the dequantized weight into shard 0 of the fused buffer.
    param.weight_loader(param, weight_dequant, 0)
```

### vllm/platforms/cuda.py (223-226)

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Automatically enabling PDL can have performance implications at large batch sizes. It is recommended to log this change so that users are aware that these environment variables are being set automatically.

```suggestion
        if cls.has_device_capability(90):
            for env_var in ("TRTLLM_ENABLE_PDL", "TORCHINDUCTOR_ENABLE_PDL"):
                if env_var not in os.environ:
                    os.environ[env_var] = "1"
                    logger.info("Auto-enabling %s for Hopper+ GPUs.", env_var)
```
