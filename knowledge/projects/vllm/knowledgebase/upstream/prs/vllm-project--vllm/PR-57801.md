## Original PR description

Fix DeepSeek V4.1 attention sink loading in the AMD/NVIDIA target and DSpark models. These four call sites reuse `load_padded_attn_sink` from #57797; they do not depend on the DeepSeek V4 call-site PR.



The helper takes the rank's TP slice once, reconstructs the padded runtime tensor, and calls the current parameter loader.



Dependency: #57797. GitHub currently compares this fork PR with upstream `main`, so the two helper files also appear in Files changed. The [V4.1-only delta](https://github.com/Ronald1995/vllm/compare/attn-sink-loader-helper...attn-sink-loader-dsv41) is four files. After #57797 merges, this PR can be rebased onto `main`.
