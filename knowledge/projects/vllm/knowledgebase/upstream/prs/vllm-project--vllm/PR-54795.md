# [Bugfix] Intersect per-worker KV cache layout support

[Upstream PR](https://github.com/vllm-project/vllm/pull/54795) · state: open · merged: False

## Original PR description

## Summary

Fixes #54710.

Pipeline-parallel workers can expose different KV-cache layout lists when
their local layers use different attention backends. Requiring those lists to
be byte-for-byte identical rejects valid hybrid models even when all workers
share a compatible layout.

Resolve the ordered intersection of the worker lists, preserving the first
worker's preference order. A `ValueError` is still raised when the lists are
truly disjoint. The existing mixed-shape, explicit-layout, and connector
selection logic then operates on the common candidates as before.

No open or historical PR references #54710 or this specific worker-layout
intersection fix (checked immediately before submission).
