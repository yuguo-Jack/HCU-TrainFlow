# [Bugfix][Core] Skip cascade prefixes during deferred KV frees

[Upstream PR](https://github.com/vllm-project/vllm/pull/55227) · state: closed · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Superseded by merged #61126, which removed cascade attention and explicitly lists this fix as unnecessary.

## Claims

- The original bug allowed retained KV references from finished requests to produce a false shared prefix.
- Current upstream no longer computes cascade prefixes or executes cascade attention.

## Validation

The current-upstream deferred-free suite passes without this patch. Reproducing the original scheduler scenarios with delayed frees now yields empty cascade metadata before and after the frees drain.

To run the related suites in a configured development environment:

```sh
.venv/bin/python -m pytest tests/v1/core
```

The original branch had CPU regression and OPT-125m GPU output validation. Those results establish the historical bug.

Upstream checks are stopped at contributor authorization; these local results do not establish a CI pass.

## Details

The conflicting code was deleted by #61126. Reintroducing it to retain this guard would undo that removal. This draft should be closed as superseded rather than rebased or sent for review.
