# [CPU] Enable INT4 and grouped-gemm MoE kernels on AVX-512

[Upstream PR](https://github.com/vllm-project/vllm/pull/59390) · state: open · merged: False

## Original PR description

## Purpose

The CPU INT4 W4A8 linear path and the x86 grouped-gemm MoE experts are gated on
`torch.cpu._is_amx_tile_supported()`. That check is stricter than what the kernels
actually need, so AVX-512 BF16 CPUs without AMX tiles (AMD Zen 4/Zen 5) never
select them:

- `CPUWNA16LinearKernel.process_weights_after_loading` clears `layer.use_w4a8`, so
  every INT4 linear falls back to `cpu_gemm_wna16` even with the default
  `VLLM_CPU_INT4_W4A8=1`.
- `CPUExpertsInt4`, `CPUExpertsInt8` and `X86CPUUnquantizedExperts` report
  `_supports_current_device() == False`.
