# [XPU] [bugfix] Unify device visibility handling for XPU and align device ID selection

[Upstream PR](https://github.com/vllm-project/vllm/pull/58079) · state: open · merged: False

## Original PR description

## Purpose

Extends PR #33308 to XPU and follows up on PR #56015
 

Adds `RAY_EXPERIMENTAL_NOSET_ZE_AFFINITY_MASK` to `XPUPlatform.ray_noset_device_env_vars`, so XPU follows the same device-visibility handling that #33308 unified for CUDA/ROCm, and removes the now-redundant manual `ZE_AFFINITY_MASK` override in `CoreEngineActorManager`.

## Test plan

This PR uses the same test command mentioned in https://github.com/vllm-project/vllm/pull/22500

`
vllm serve deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B --data-parallel-size 2 --tensor-parallel-size 1 --data-parallel-backend=ray --gpu-memory-utilization=0.8
`
