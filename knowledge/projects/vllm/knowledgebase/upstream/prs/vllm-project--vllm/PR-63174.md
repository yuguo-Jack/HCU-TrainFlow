# [Bugfix] Skip redundant weight tensor clones for loaders that yield owned tensors

[Upstream PR](https://github.com/vllm-project/vllm/pull/63174) · state: closed · merged: True

## Original PR description



## Overview

Drop the redundant weight-tensor clones for loaders whose iterators already yield caller-owned tensors: `runai_safetensors_weights_iterator` with `runai-model-streamer>=0.17.1` (clone kept for older versions), and the pooling-model adapter probe for runai and the other owned-tensor load formats.



## Claims

- `--load-format runai_streamer` no longer copies each weight tensor while loading, with `runai-model-streamer>=0.17.1`.
- Older streamers keep working: the iterator clones for them, so buffer reuse cannot corrupt weights.
- Pooling models no longer clone every weight in the `*ForCausalLM` / `*Model` prefix probe for runai, default safetensors/`pt`/`npcache`, `instanttensor`, `tensorizer`, `sharded_state` and `modelexpress`.
- Minimum `runai-model-streamer` is now 0.17.1 in the extras, Docker image and requirements.

## Details

**Root cause.** Before 0.17.1 the streamer can reuse its read buffers, so each tensor had to be cloned to stay valid. From 0.17.1, `stream_files(..., owned=True)` (the default) gives every yielded tensor to the caller and never reuses its memory, so the clone is a redundant copy.

**Changes.**

- `weight_utils.py`: pass `owned=True` when `stream_files` accepts it and yield tensors directly. Otherwise stream as before and clone. Detection is by the `owned` parameter, not a version string.
- `adapters.py`: the probe cloned every weight because the iterator "may reuse the tensor buffer". It now clones only when `load_config.load_format` is not in `_OWNED_TENSOR_LOAD_FORMATS`.
- Version bump to `>=0.17.1` in `setup.py`, `docker/`, and `requirements/test/xpu.{in,txt}` so new installs get the fast path
- Tests: renamed the runai iterator test (now asserts no clone), added a fake-streamer test with and without `owned`, and an adapter test that whitelisted formats do not clone.

**Whitelist.** `auto`, `hf`, `safetensors`, `mistral`, `pt`, `npcache`, `instanttensor` (`copy=True`), `tensorizer` (non-lazy deserializer caches independent tensors), `sharded_state`, `modelexpress` (delegates), `runai_streamer`, `runai_streamer_sharded`. `fastsafetensors` is excluded: 0.5.0 documents independent tensors, but 0.3.3 (the allowed minimum) only clones when `pg.size() == 1`. Custom or new load formats keep the clone until added.

**Limitations.** Only the listed iterators were reviewed; model-specific `load_weights` code may still copy. Tests ran on the 0.32.0 wheel plus overlay, not a source build of this branch.
