# [Perf][GLM-5.3-Flash][SM90] Shape-aware launch configuration for recurrent KDA

## Overview

Tune the GLM-5.3-Flash recurrent KDA launch on SM90 using a wider value tile and fewer pipeline stages for small grids. This refresh preserves the launch-grid fix merged in #56974.

## Claims

- On SM90, use `BV = min(next_power_of_2(V), 16)` and `num_stages = 2` when `N * HV <= 32`; larger grids keep `num_stages = 3`. `num_warps` stays 1. Other architectures retain the existing configuration.
- The original H20 measurements showed 6.0–18.7% improvement per speculative-verification kernel call across TP4/TP8 and 1–64 requests. These are measurements from before this rebase, not fresh measurements on the updated branch.
- The regression test compares output and in-place state against the default launch configuration for decode and speculative shapes.

### Previously reported H20 results

Configuration: `K = V = 128`, BF16 activations, FP32 recurrent state; baseline `BV=8`, `num_warps=1`, `num_stages=3`.

Speculative verification (`mtp=3`), per-call improvement:

| Requests | 1 | 2 | 4 | 8 | 16 | 32 | 64 |
|---------:|--:|--:|--:|--:|---:|---:|---:|
| TP8 | 16.5% | 18.7% | 17.7% | 14.3% | 6.0% | 6.4% | 9.2% |
| TP4 | 18.5% | 16.5% | 14.4% | 7.9% | 6.4% | 10.4% | 13.0% |

Pure decode at TP8: 10.1%, 10.2%, 8.1%, 4.1%, 1.6%, 1.3%, and 3.9% at the same request counts.

The original PR also reported:

- 9 recurrent KDA tests passed; output and state `max_abs_diff = 0.0` across the HV=8/HV=16 sweep.
- In-situ serving at 48 concurrent requests, 256 output tokens, speculative decoding enabled: kernel mean 50.4 → 48.7 µs across 2,312 calls, consistent across all eight TP ranks. The kernel accounted for approximately 4.3% of GPU kernel time.
- Greedy serving evaluation on 12 prompts × 256 tokens: no divergence beyond the serving stack's run-to-run nondeterminism; end-to-end throughput differences were within run-to-run variance. This PR claims a kernel improvement, without a demonstrated end-to-end throughput improvement.

## Details

The wider value tile amortizes repeated q/k/gate loads. The stage reduction is restricted to small grids; large grids retain the original stage count. The tuning was measured on H20; other SM90 devices were not benchmarked.

Duplicate-work check: the open-PR search for recurrent KDA found no other GLM-5.3-Flash SM90 launch-config PR. #56974 addresses the orthogonal gridDim.z limit and was merged on October 5. This refresh retains its `(N * HV, NV, NK)` launch grid and matching kernel indexing.

The earlier test-decorator resolution remains intact: the ROCm/CUDA layout check and the original NVIDIA-only SM90 test remain separate. Both changed files remain LF.

AI assistance was used for the original implementation and this rebase, static verification, and description update.
