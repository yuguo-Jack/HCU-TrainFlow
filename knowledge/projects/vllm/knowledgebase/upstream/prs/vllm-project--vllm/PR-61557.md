## Details

`StructuredOutputManager` changes (`vllm/v1/structured_output/__init__.py`)
- Rename `validate_tokens` to `trim_spec_tokens`; no longer trim the rejected invalid token
- Allow `grammar_bitmask` to handle unvalidated draft tokens; previously, all draft tokens were already validated by `validate_tokens`

Scheduling changes (`vllm/v1/core/sched/scheduler.py`):
- Remove the `StructuredOutputManager.validate_tokens` call on the async scheduling path

`StructuredOutputGrammar` changes:
- Ensure `StructuredOutputGrammar.accept_tokens` is atomic on failure: when it returns False (acceptance fails), grammar state is not updated
- Allow `StructuredOutputManager.grammar_bitmask` to call `StructuredOutputGrammar.accept_tokens` with unvalidated draft tokens, without an extra `StructuredOutputManager.validate_tokens` call
- Update to XGrammar backend to rollback accepted tokens when `StructuredOutputGrammar.accept_tokens` fails
- Update to Guidance backend to use `ll_matcher.try_consume_tokens` + rollback vs `ll_matcher.consume_tokens` to not advance matcher state when `StructuredOutputGrammar.accept_tokens` fails

`EngineCore` changes:
- Comment update only
