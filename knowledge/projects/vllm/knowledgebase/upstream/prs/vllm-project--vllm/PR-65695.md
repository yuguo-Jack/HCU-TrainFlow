# [Bugfix][Frontend] Report a tool call cut short by EOS as end_turn in Anthropic streaming

[Upstream PR](https://github.com/vllm-project/vllm/pull/65695) · state: open · merged: False

## Original PR description

## Overview

Fixes #65693. In `/v1/messages` streaming, a tool call whose streamed arguments never became JSON because generation stopped on EOS or a stop token id now ends with `stop_reason: "end_turn"` instead of `"tool_use"`, the way a call cut by a stop string already ends with `stop_sequence`.

## Claims

- Streamed arguments that are not JSON when generation stops naturally give `end_turn`, whether the chat layer finished with `tool_calls` or `stop`, and with a natural EOS or a stop token id.
- Complete calls, calls with no arguments streamed (empty or whitespace, as for a tool without parameters), `max_tokens` and stop strings map as before.
- The non-streaming path is unchanged. The issue explains why it needs a parser change instead.

## Validation

```

3 failed, 8 passed
# this branch
pytest tests/entrypoints/anthropic/test_anthropic_messages_conversion.py
141 passed
pytest tests/entrypoints/anthropic
167 passed
```

The server tests ran with `Qwen/Qwen3-0.6B` on an RTX 4070 Ti SUPER, with `VLLM_USE_FLASHINFER_SAMPLER=0` because FlashInfer's sampling JIT build fails on that machine. The live behaviour this fixes is in the issue: Qwen3.8-27B-FP8 on vLLM 0.32.0 finishing a stream with `tool_calls` and unterminated arguments when a stop token id falls inside them, and a Claude Code session whose call stopped on EOS.

## Details

`tool_cut` is passed only by the stream converter, where the streamed arguments are known. It is true when arguments were streamed and do not parse, which is when `tool_complete` is false for a reason other than a call without parameters. #60621 changes `_is_json` to treat empty or whitespace arguments as complete. This change leaves those calls alone, so the two compose.

Not a duplicate: #60621 covers calls with no arguments, #42213 covers a Chat Completions stream that stops before any tool delta, and #57707 and #59882 change how the qwen3 converter closes a parameter. None of them changes the stop reason of a call cut inside its arguments.
