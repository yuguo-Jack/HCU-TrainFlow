# [CI] Assert CPU scheduler metadata is present in group-head test

[Upstream PR](https://github.com/vllm-project/vllm/pull/62831) · state: closed · merged: True

## Original PR description

## Overview

Unblock `main` pre-commit mypy after #59082 typed `scheduler_metadata` as optional. The same one-line fix is already on #62712.

## Claims

- Fixes mypy `union-attr` on `tests/v1/attention/test_group_head_counts.py:135` (`Item "None" of "Any | None" has no attribute "view"`).
- Restores green pre-commit for `main` and for PRs that merge against current `main`.

## Validation

- Reproduced on `main` and on PR merge refs (e.g. #62712 pre-commit): mypy fails without the assert.
- Local `pre-commit` / mypy hook passes with this change.
- No other open PR found fixing this (searched `test_group_head_counts`, `scheduler_metadata`, related mypy wording).

## Details

#59082 returns `builder.build(...).scheduler_metadata`, which is typed `Any | None`, then immediately calls `.view(...)`. Mypy rejects that. `assert metadata is not None` narrows the type (and fails loudly if metadata is unexpectedly missing).

Same fix landed earlier on #62712 (`9d688f9e16`) to unblock that PR’s pre-commit; this PR puts it on `main` so every open PR does not need a local copy.
