# [Docs] Document NIXL KV connector metrics aggregation semantics

[Upstream PR](https://github.com/vllm-project/vllm/pull/58903) · state: open · merged: False

## Original PR description


## Purpose

Closes #41230.

Document the aggregation semantics for NIXL KV connector metrics across
multiple vLLM workers.

This documentation explains that:
- NIXL KV transfer statistics are collected independently by each worker.
- Underlying observations are combined across workers before reduction.
- Average transfer time, post time, and descriptor counts are calculated
  from the combined observations.
- P90 transfer and post times are calculated from the combined observations.
- Transfer volume and throughput are calculated using the aggregated
  total bytes and transfer duration.
- Transfer, handshake, and notification failures are grouped into
  `Num failed transfers`.
- KV expiration events are reported separately as `Num KV expired reqs`.

No production code changes are included.
