# [ROCm][CI] Add legacy AMD jobs for MI355 e2e and eval steps from test

[Upstream PR](https://github.com/vllm-project/vllm/pull/61719) · state: closed · merged: False

## Original PR description

These MI355 steps were added directly to test_areas/*.yaml in #56679 and have no job in test-amd.yaml, so the AMD CI pipeline never runs them. Add an optional job for each, copied from the test_areas definition:

- (MI355) Fusion E2E TP2 AR-RMS (Inductor Partition)
- (MI355) Fusion E2E TP2 AR-RMS (Dynamo Partition)
- (MI355) LM Eval Large Models Harness
- (MI355) Qwen3-Next-80B-A3B-Instruct MTP Async EPLB Accuracy

The existing Fusion E2E TP2 jobs only run test_tp2_ar_rms_fp8_fusions, and the LM Eval Large Models Harness and Qwen3-Next EPLB jobs only run on MI300. Existing jobs are unchanged.
