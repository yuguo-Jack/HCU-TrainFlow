# Updated TODO Doc in hadacore_transform

[Upstream PR](https://github.com/vllm-project/vllm/pull/58873) · state: open · merged: False

## Original PR description




## Purpose
Resolves an open `TODO` in `hadacore_transform_kernel` regarding the removal of `matrix_transpose_m8_n8_b16_inplace` to decrease latency. 

The TODO suggested finding an alternative storage method to avoid the transpose overhead. However, empirical testing on an RTX 3070 Ti (sm_86) confirms that the kernel is heavily memory-bandwidth bound. Removing the warp shuffles produces incorrect mathematical output while yielding **zero end-to-end performance improvement**, as the instruction latency is completely hidden behind global memory stalls. 

This PR removes the obsolete TODO and updates the documentation to reflect that the current transpose implementation is optimal given the memory bounds.
## Test Plan
