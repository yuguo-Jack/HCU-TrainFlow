# [CI] Run the heaviest 4xL4 steps nightly only

[Upstream PR](https://github.com/vllm-project/vllm/pull/62564) · state: closed · merged: True

## Original PR description

## Purpose

`l4-k8s` is pinned at 32 g6.12xlarge nodes (128 L4 GPUs): us-west-2 has had no spare g6 capacity since late September, so the cluster can't scale past that. Since Oct 12, PRs with L4 jobs grew about 44% (73 → 105 per weekday), and L4 GPU time rose from about 1,110 to 1,590 GPU-hours per weekday. 4-GPU pods need a whole free node and wait behind 1/2-GPU jobs, so at peak the L4 queue backs up for hours.

This marks the eight most expensive 4-GPU L4 steps `optional: true`. Together they are about 700 L4 GPU-hours per weekday (Oct 13–15):

| Step | GPU-h/day |
|---|---|
| (L4) Pipeline + Context Parallelism | ~256 |
| (L4) Distributed DP Extended | ~116 |
| (L4) Hybrid SSM NixlConnector PD accuracy | ~81 |
| (L4) CrossLayer KV layout Distributed NixlConnector PD accuracy | ~70 |
| (L4) Distributed FlashInfer NixlConnector PD accuracy | ~69 |
| (L4) Distributed NixlConnector PD accuracy | ~68 |
| (L4) Push NixlConnector PP prefill PD accuracy | ~21 |
| (L4) DP EP Distributed NixlConnector PD accuracy | ~20 |

They still run automatically on nightly (`NIGHTLY=1` / `ready-run-all-tests`), and a PR can still run them from the "Run …" block.

**AMD mirrors follow their steps.** A mirror inherits `optional` from its step (`_get_amd_mirror_effective_step`: `amd.get("optional", step.optional)`), so the eight AMD mirrors also become nightly-only, as the 4xH100/4xB200 nightly-only steps' mirrors already are.

The other seven 4-GPU L4 steps (RayExecutorV2, Rust Frontend Distributed, LoRA TP, Torchrun + Examples, Compile + Comm, Qwen4 Exp SP, EPLB Execution; ~200 GPU-h/day combined) stay automatic so PRs keep multi-GPU coverage of the core distributed paths.

## Test Plan

Ran ci-infra `main`'s `_step_should_run` / `_amd_mirror_should_run` on the edited YAML with a diff touching each step's source dependency:
- PR build: none of the 8 L4 steps or their 8 AMD mirrors auto-selected.
- Nightly build: all 8 L4 steps and all 8 AMD mirrors selected.
