# [Perf][DSv4.1] Bump FlashMLA to pass int64 positions to MegaAttn

[Upstream PR](https://github.com/vllm-project/vllm/pull/61971) · state: closed · merged: True

## Original PR description

## Overview

MegaAttn casts the RoPE positions from int64 to int32 in every layer because the FlashMLA fused norm + RoPE + attn + RoPE + cast kernels took int32. In a full CUDA graph each cast is a separate kernel: 40 per target forward on DeepSeek-V4.1-Flash. FlashMLA [d1a1c92](https://github.com/vllm-project/FlashMLA/commit/d1a1c92eff2cf558ddf49293828cd2bd21ca48c4) (vllm-project/FlashMLA#38) now takes int64 positions directly and rejects int32, so this PR bumps FlashMLA and drops the cast.

## Changes

- Bump FlashMLA `e2afa5f` -> `d1a1c92`. The only change in between is #38.
- Pass `positions` straight to `fused_norm_rope_attn_rope_cast_{decode,fwd}` in `flash_mla_mega_attn.py`.
- Same change in `benchmarks/kernels/benchmark_dsv41_mega_attn.py`, which would otherwise fail the new dtype check.

## Validation

Earlier revisions of this PR shared one int32 cast across layers within a forward context. These numbers come from that version, with DeepSeek-V4.1-Flash on 8 x GB300 across two nodes, DP8 x TP1 + EP, 64 requests/rank, 131,072 input tokens, 2,048 output tokens, DSpark with 5 draft tokens and full decode CUDA graphs:

| Target forward | Before | Shared cast |
|---|---:|---:|
| GPU time, median (ms) | 17.903 | 17.834 |
| GPU time, p10 / p90 (ms) | 17.847 / 17.996 | 17.793 / 17.941 |
| Kernels in the captured forward | 766 | 727 |

This revision removes all 40 casts, one more than the shared-cast version, and moves the conversion into the kernel. It has not been re-timed or rebuilt against the new FlashMLA yet.

```bash
pre-commit run --files cmake/external_projects/flashmla.cmake benchmarks/kernels/benchmark_dsv41_mega_attn.py vllm/models/deepseek_v41/nvidia/flash_mla_mega_attn.py
```

Pre-commit passed. No accuracy evaluation was run. RoPE math is unchanged, and the FlashMLA tests in #38 cover int64 positions.

Not a duplicate: no other open PR bumps FlashMLA to `d1a1c92` or removes this cast.
