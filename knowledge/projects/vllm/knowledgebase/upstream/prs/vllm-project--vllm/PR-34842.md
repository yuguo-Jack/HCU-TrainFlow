# [Bugfix][Kernel] Fix integer overflow in layernorm kernel index computations

[Upstream PR](https://github.com/vllm-project/vllm/pull/34842) · state: closed · merged: False

## Original PR description

Fix potential integer overflow in layernorm and quantized layernorm CUDA kernels when blockIdx.x * hidden_size exceeds INT_MAX.

With large token counts (e.g. 524289+ tokens) and typical hidden sizes (4096+), the expression blockIdx.x * hidden_size can overflow 32-bit int, causing out-of-bounds memory access and incorrect results.

Changes:
- Use int64_t for index variables (id, stride_id) in vectorized fused_add_rms_norm kernels
- Add static_cast<int64_t>(blockIdx.x) before multiplication with hidden_size in generic (non-vectorized) kernel index expressions
- Promote input_stride parameter from int to int64_t in quantized layernorm kernels, matching the non-quantized layernorm kernels

Fixes #22419
