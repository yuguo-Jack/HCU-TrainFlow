# [KV Events] Coalesce consecutive BlockRemoved events

[Upstream PR](https://github.com/vllm-project/vllm/pull/63390) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

The GPU block pool publishes one single-hash `BlockRemoved` per evicted block. This PR merges consecutive same-group removals into one event, so KV-event consumers (Dynamo, llm-d, vLLM Router) receive far fewer events with identical information. It also trims some per-block work when building events. Part of the P3 item in #63149 (measurements are also posted [there](https://github.com/vllm-project/vllm/issues/63149#issuecomment-6365914039)).

## Claims

- **74% fewer `BlockRemoved` events** in real serving (4,220 → 1,111), and **25% fewer wire bytes** in the CPU harness.
- **Same information, same order:** flattened per hash, the store/remove sequence is identical to `main` (9,938 operations compared).
- **No end-to-end throughput change.** The construction tweaks cut event-building CPU by ~18% in a CPU harness, but that is below noise end to end. I'm not claiming a speedup.

## Details

- **Coalescing.** `_emit_block_removed_events` appends to the last queued event when it is a `BlockRemoved` with the same `group_idx` and `medium`. A different group, a store or a clear in between starts a new event, which is why the flattened sequence matches `main`. `BlockRemoved.block_hashes` is already a list, and the contract proposed in #60616 says it "withdraws one copy of each listed hash". **Open question for reviewers:** is the coarser granularity acceptable to all consumers? If not, I'll drop this part.
- **Construction tweaks.** `maybe_convert_block_hashes` converts an event's hashes with one env read instead of one per hash; the single-hash helper is kept for other callers. `has_block_hash_extra_keys` skips the per-block extra-key loop when every result would be `None`; the output is unchanged (`[None] * n`).
- **Related open PRs** touching `_emit_block_removed_events`: #48933 (per-hash `remaining_copy_counts`, compatible since counts stay aligned per hash), #55092, #58508. Whichever lands second needs a small rebase.

```python
"""Check a recorded KV event stream the way a router would consume it.

usage: check_events.py <events_file> [<other_events_file>]

- Replays stores/removes into a per-(group, hash) copy count, as a
  consumer index does, and reports removals of hashes never stored.
- With two files, compares the flattened per-hash sequence of
  (kind, group, hash) — identical sequences mean the second stream carries
  the same information in the same order, only grouped differently.
"""

import sys
from collections import Counter

import msgspec

from vllm.distributed.kv_events import (
    AllBlocksCleared,
    BlockRemoved,
    BlockStored,
    KVEventBatch,
)

dec = msgspec.msgpack.Decoder(type=KVEventBatch)


def load(path):
    out = []
    with open(path, "rb") as f:
        data = f.read()
    i = 0
    while i < len(data):
        n = int.from_bytes(data[i : i + 4], "big")
        out.append(dec.decode(data[i + 4 : i + 4 + n]))
        i += 4 + n
    return out


def analyze(path):
    batches = load(path)
    counts: Counter = Counter()
    flat = []
    stats = Counter()
    for b in batches:
        for e in b.events:
            if isinstance(e, BlockStored):
                stats["stored_events"] += 1
                for h in e.block_hashes:
                    counts[(e.group_idx, h)] += 1
                    flat.append(("S", e.group_idx, h))
                stats["stored_hashes"] += len(e.block_hashes)
            elif isinstance(e, BlockRemoved):
                stats["removed_events"] += 1
                stats["removed_hashes"] += len(e.block_hashes)
                if len(e.block_hashes) > 1:
                    stats["multi_hash_removed_events"] += 1
                for h in e.block_hashes:
                    if counts[(e.group_idx, h)] <= 0:
                        stats["remove_of_unknown_hash"] += 1
                    else:
                        counts[(e.group_idx, h)] -= 1
                    flat.append(("R", e.group_idx, h))
            elif isinstance(e, AllBlocksCleared):
                stats["all_cleared"] += 1
                counts.clear()
                flat.append(("C", None, None))
    stats["batches"] = len(batches)
    stats["resident_hashes_at_end"] = sum(1 for v in counts.values() if v > 0)
    return stats, flat


a_stats, a_flat = analyze(sys.argv[1])
print("A", dict(a_stats))
if len(sys.argv) > 2:
    b_stats, b_flat = analyze(sys.argv[2])
    print("B", dict(b_stats))
    print("FLAT_SEQUENCE_IDENTICAL", a_flat == b_flat, len(a_flat), len(b_flat))
```

```python
"""CPU microbenchmark: scheduler step cost with KV cache events off vs on.

Drives the real v1 Scheduler with a fake model (one sampled token per request
per step). Run from the vLLM checkout:
  PYTHONPATH=. .venv/bin/python <this file> [--profile on_zmq]
"""

import argparse
import cProfile
import gc
import pstats
import random
import statistics
import time

import tests.v1.core.utils as U
from vllm.config import KVEventsConfig
from vllm.v1.outputs import ModelRunnerOutput

_RealVllmConfig = U.VllmConfig
EVENTS_CFG = None


def _patched_vllm_config(**kw):
    return _RealVllmConfig(**kw, kv_events_config=EVENTS_CFG)


U.VllmConfig = _patched_vllm_config


def make_cfg(mode):
    if mode == "off":
        return None
    if mode == "on_null":
        return KVEventsConfig(enable_kv_cache_events=True, publisher="null")
    if mode == "on_zmq":
        return KVEventsConfig(
            enable_kv_cache_events=True,
            publisher="zmq",
            endpoint=f"inproc://kvbench{random.random()}",
        )
    raise ValueError(mode)


def run(mode, args):
    global EVENTS_CFG
    EVENTS_CFG = make_cfg(mode)
    sched = U.create_scheduler(
        enable_prefix_caching=True,
        max_num_seqs=args.batch,
        max_num_batched_tokens=args.batch * args.prompt,
        num_blocks=args.num_blocks,
        block_size=args.block_size,
        max_model_len=args.prompt + args.max_tokens + 16,
    )
    import vllm.envs as envs
    envs.enable_envs_cache()  # as the engine does after startup
    rng = random.Random(0)
    shared = [rng.randrange(1000, 30000) for _ in range(args.shared_prefix)]
    reqs = U.create_requests(
        num_requests=args.num_requests,
        num_tokens=args.prompt,
        max_tokens=args.max_tokens,
        ignore_eos=True,
        block_size=args.block_size,
    )
    for r in reqs:
        uniq = [rng.randrange(1000, 30000) for _ in range(args.prompt - len(shared))]
        toks = shared + uniq
        r.prompt_token_ids[:] = toks
        r._all_token_ids[:] = toks
        r.block_hashes = []
        r.update_block_hashes()
        sched.add_request(r)

    nev = {"stored": 0, "removed": 0, "blocks": 0}
    orig_take = sched.kv_cache_manager.take_events

    def counting_take():
        evs = orig_take()
        for e in evs or []:
            n = type(e).__name__
            if n == "BlockStored":
                nev["stored"] += 1
                nev["blocks"] += len(e.block_hashes)
            elif n == "BlockRemoved":
                nev["removed"] += 1
        return evs

    if mode != "off":
        sched.kv_cache_manager.take_events = counting_take
    step_times = []
    t0 = time.perf_counter()
    while sched.has_requests():
        s = time.perf_counter()
        out = sched.schedule()
        ids = list(out.num_scheduled_tokens)
        done_prefill = [
            i
            for i in ids
            if sched.requests[i].num_computed_tokens + out.num_scheduled_tokens[i]
            >= sched.requests[i].num_prompt_tokens
        ]
        sched.update_from_output(
            out,
            ModelRunnerOutput(
                req_ids=ids,
                req_id_to_index={r: i for i, r in enumerate(ids)},
                sampled_token_ids=[
                    [rng.randrange(1000, 30000)] if r in done_prefill else []
                    for r in ids
                ],
                logprobs=None,
                prompt_logprobs_dict={},
                pooler_output=[],
            ),
        )
        step_times.append(time.perf_counter() - s)
    total = time.perf_counter() - t0
    sched.shutdown()
    run.nev = nev
    return total, step_times


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--num-requests", type=int, default=256)
    p.add_argument("--batch", type=int, default=64)
    p.add_argument("--prompt", type=int, default=1024)
    p.add_argument("--shared-prefix", type=int, default=512)
    p.add_argument("--max-tokens", type=int, default=256)
    p.add_argument("--block-size", type=int, default=16)
    p.add_argument("--num-blocks", type=int, default=8192)
    p.add_argument("--reps", type=int, default=3)
    p.add_argument("--modes", default="off,on_null,on_zmq")
    p.add_argument("--profile", default=None)
    args = p.parse_args()

    if args.profile:
        prof = cProfile.Profile()
        prof.enable()
        run(args.profile, args)
        prof.disable()
        pstats.Stats(prof).sort_stats("cumtime").print_stats(r"block_pool|kv_events|kv_cache_utils.py:(82|637|678|1187)|kv_cache_manager.py.*take_events|__init__|to_event")
        return

    modes = args.modes.split(",")
    res = {m: [] for m in modes}
    for _ in range(args.reps):
        for m in modes:  # interleave modes to cancel drift
            gc.collect()
            total, steps = run(m, args)
            res[m].append((total, statistics.median(steps), len(steps)))
            res.setdefault(m + "_ev", run.nev)
    base = min(t for t, _, _ in res[modes[0]])
    for m in modes:
        tot = min(t for t, _, _ in res[m])
        med = statistics.median(s for _, s, _ in res[m])
        print(
            f"{m:8s} total={tot:7.3f}s  median_step={med * 1e3:7.3f}ms  "
            f"steps={res[m][0][2]}  vs_{modes[0]}={100 * (tot / base - 1):+.1f}%  "
            f"events={res[m + '_ev']}"
        )


if __name__ == "__main__":
    main()
```
