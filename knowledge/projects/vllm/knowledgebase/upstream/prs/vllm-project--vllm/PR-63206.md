# [AuxOutput] use extensible token-aligned data format for mooncake data

[Upstream PR](https://github.com/vllm-project/vllm/pull/63206) · state: open · merged: False

## Original PR description



## Overview

Cherrypick https://github.com/vllm-project/vllm/pull/57968 and add one commit (https://github.com/vllm-project/vllm/commit/e7abc8ef1aef13411cd164fa0cb34c3bf9196d42) to make the mooncake connector storage format extendible to other token-aligned payloads in the future (R3, logprobs, hidden states, etc)

Use safetensor as the serialization format (to remove the need for an external codec). Following the RFC here: https://github.com/vllm-project/vllm/issues/61291
