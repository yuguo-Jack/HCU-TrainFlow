[Upstream PR](https://github.com/vllm-project/vllm/pull/64832) · state: open · merged: False

## Original PR description

## Overview

Add native text inference for [SenseNova-Loop-9B-Preview](https://huggingface.co/sensenova/SenseNova-Loop-9B-Preview), reusing Qwen3.5 layers with fixed-count loop execution and mHC routing.

No other open PR was found in searches for `sensenova` and `"SenseNova Loop"`.

## Claims

- Native checkpoint loading, tensor parallelism and decode CUDA Graphs.
- Shared weights with separate attention/recurrent state for each loop visit.
- Checkpoint SSM dtype defaults are respected; explicit overrides take precedence.

## Details

Loop parameters are tied after weight processing, with separate cache slots per visit. Loading therefore uses more weight memory than steady-state inference. SSM dtype handling reuses Qwen3.5's conditional-generation config hook.

`sharded_state` and `runai_streamer_sharded` are rejected before workers start: exports deduplicate shared weights before a fresh model has restored their aliases. Support is limited to unquantized text inference; further limits and launch examples are in the [model documentation](https://github.com/sufubao/vllm/blob/pr/sensenova-loop/docs/models/sensenova_loop.md).
