# [XPU][UT] Allow HF reference models to load LoRA adapters by adding PEFT to XPU test dependencies

[Upstream PR](https://github.com/vllm-project/vllm/pull/63694) · state: closed · merged: True

## Original PR description

## Overview

Add `peft>=0.20.0` to `requirements/test/xpu.in`. This enables HF reference models to load LoRA adapters. Hf-vs-vllm comparison tests on speech-to-text models failed on XPU because of missing peft to load audio adapter.

## Claims

- `peft` is not installed in vllm dependencies for XPU. Hfrunner with speech-to-text models requires `peft` to load audio adapters, otherwise the model will perform incorrectly and have wrong outputs. So hf-vs-vllm tests on speech-to-text models fail on XPU.
- For cuda and rocm, `peft` has been installed so those cases can pass.
- Installing peft will fix these ut failures where peft is required by Hfrunner to correctly run a speech model.

## Validation
### Before this PR
To reproduce:
```
pytest -s -v tests/models/multimodal/generation/test_granite_speech.py::test_models[10-128-2048-bfloat16-ibm-granite/granite-speech-3.3-2b-ibm-granite/granite-speech-3.3-2b]
pytest -s -v tests/models/multimodal/generation/test_transformers_audio.py::test_transformers_audio_generation[ibm-granite/granite-speech-3.3-2b]
```

result:
- the ut failed.
- Warnings point out that peft is not installed and the model will perform incorrectly. The warnings are like:
```
WARNING  transformers.models.granite_speech.modeling_granite_speech:modeling_granite_speech.py:506 Config indicates that a lora adapter should be present, but peft is not installed; this will cause the model to perform incorrectly when audio inputs are provided. Please install peft and reload the model!
```
### After this PR
to reproduce:
```
pip install --no-deps peft\>=0.20.0
pytest -s -v tests/models/multimodal/generation/test_granite_speech.py::test_models[10-128-2048-bfloat16-ibm-granite/granite-speech-3.3-2b-ibm-granite/granite-speech-3.3-2b]
pytest -s -v tests/models/multimodal/generation/test_transformers_audio.py::test_transformers_audio_generation[ibm-granite/granite-speech-3.3-2b]
```
result: the two cases passed.
