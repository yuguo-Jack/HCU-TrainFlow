## Original PR description

Syncs `rl/aux-output` with the latest remote `main` (`9a519c0585`) so the branch is no longer behind.

- Two merge commits bring in the 15 `main` commits the branch was missing (`40941f2c4b` first sync, then `9a519c0585` for the 3 newer ones).
- Preserves the branch-only design docs commit: `docs/design/rl_aux_output/*` (5 files, +642).
- After this PR, `git rev-list --count HEAD..origin/main` is 0 and the only diff against `main` is that docs commit.

The PR shows 17 commits because a merge-based sync necessarily lists every `main` commit it brings into the branch (15) plus the 2 merge commits. The file diff is only `main`'s own changes; no code changes beyond the sync.

#### DCO note

The DCO check reports 9 commits from `main` with mismatched sign-off lines (squash-merged commits whose author is the GitHub login while `Signed-off-by` carries the real name/email). They are upstream commits, not part of this branch:

- `20ca5e8` anhtra3889, `33f68ea` aoshen02, `20f0890` bzsuni, `e11a5ad` Dilber, `8b30f56` Dilber, `3d18166` Juntian Liu (missing), `aa59a19` Park Soobin, `6124981` Tevin Shi, `a801d9e` Jaeyeong Choi (@Jaeyeong-CHOI).

`main` history is not GPG-signed and the repo has no `.github/dco.yml` remediation mode, so any PR that merges `main` into a branch hits this. Re-running the check will not change it; a maintainer override is the only fix.
