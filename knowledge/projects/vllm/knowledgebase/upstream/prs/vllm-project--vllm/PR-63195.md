# [Perf][Spec Decode] Opt-in MTP draft prefill attention for the sampled rows only

[Upstream PR](https://github.com/vllm-project/vllm/pull/63195) · state: open · merged: False

## Original PR description



## Overview

During MTP draft prefill only the last row of each prefill request is sampled, but attention runs over every row. This adds an opt-in mode that computes draft prefill attention only for the sampled rows; KV is still written for every token.

## Claims

- New `SpeculativeConfig.prune_draft_prefill_attention` (default off), for single-module MTP with the FlashInfer backend (XQA or trtllm-gen decode).
- Off by default because the sampled rows run on the decode kernel, so results are not bitwise identical.
- Warns at load when enabled but not applicable; FULL CUDA-graph draft prefills keep full attention.
