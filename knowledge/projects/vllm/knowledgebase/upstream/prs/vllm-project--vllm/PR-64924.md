# [KV Connector] Remove the in-tree LMCache integration package

[Upstream PR](https://github.com/vllm-project/vllm/pull/64924) · state: open · merged: False

## Original PR description

## Purpose

Fixes #64790.

The in-tree LMCache package (`kv_connector/v1/lmcache_integration/`) can't be imported with any lmcache version vLLM supports (`requirements/kv_connectors.txt` asks for `>= 0.5.6`). So `use_native` and the in-tree MP fallback both fail at startup today.

This removes the package and:

- `LMCacheConnectorV1` always uses the adapter shipped with lmcache. `use_native` now raises a clear `ValueError` telling the user to drop it.
- `LMCacheMPConnector` imports its adapters from `lmcache.integration.vllm.vllm_multi_process_adapter` directly, with no in-tree fallback.

It also removes the code behind #62216 and #49556, which are both bugs in the deleted package.

The builtin `LMCacheMPConnectorUpstream` is left alone here. It is also broken on lmcache 0.5.6 (details in the issue), but whether to remove or update it is a separate call.

## Not a duplicate

I searched open PRs for the package name, `use_native` and the issue number. Four open PRs edit files in the deleted package (#40041, #54818, #56643, #58855) and none of them removes it.
