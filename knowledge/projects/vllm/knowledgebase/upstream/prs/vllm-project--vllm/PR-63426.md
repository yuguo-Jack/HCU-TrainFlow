# [ROCm][CI] Print the native backtrace of a fault in AMD CI pytest runs

[Upstream PR](https://github.com/vllm-project/vllm/pull/63426) · state: closed · merged: True

## Original PR description

- `amd_ci_fault_trap.c`: a SIGSEGV, SIGBUS and SIGABRT handler that prints the native backtrace, naming the library that faulted, and then lets the fault proceed as before
- `amd_ci_fast_exit.py`: load it underneath Python's faulthandler, so a fault prints the Python traceback and then the native one; an image without the library runs as before, with a one-line warning
- `Dockerfile.rocm`: build the library into the test image (one `cc` call, cached unless the source changes)
- `test_amd_ci_fast_exit.py`, CI configs: tests for the report and for a missing library, run when the `.c` file changes

When an AMD CI job crashes in native code, Python's faulthandler shows only the Python frames, so the log does not say whether the fault came from HIP, the ROCm runtime, Ray or a vLLM extension; now every native fault in a pytest run also prints the native frames, while the job's result stays exactly what it was. This PR first also turned a fault after pytest's summary into pytest's own exit status, because of [vllm/ci #96786](https://buildkite.com/vllm/ci/builds/96786), where every test passed and the process then died in interpreter teardown. #61939's fast exit now skips that teardown, no fault after the summary shows up in the AMD builds that ran with it ([15532](https://buildkite.com/vllm/amd-ci/builds/15532), [15739](https://buildkite.com/vllm/amd-ci/builds/15739)), and the mapping would also have turned a teardown SIGABRT green, so that part is dropped. The plugin keeps its name, so this does not conflict with #64132, which changes how the same plugin is installed. Follow-up to #61939; `pytest tests/tools/test_amd_ci_fast_exit.py` passes 11 tests (3 new) in 10 runs out of 10, and the library has not been built in AMD CI yet.

AI assistance (Claude Code) was used to draft this change. Every line was reviewed by the submitter.
