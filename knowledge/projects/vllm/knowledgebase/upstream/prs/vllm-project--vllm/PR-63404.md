# [Bugfix][Frontend] Reject unsupported nested Anthropic tool-result content

[Upstream PR](https://github.com/vllm-project/vllm/pull/63404) · state: open · merged: False

## Original PR description

## Overview

Reject unsupported block types inside Anthropic `tool_result.content` before message conversion. The adapter handles `text`, `image` and `tool_reference`; other nested blocks currently disappear while the request still succeeds.

The validator returns a bad request for unsupported nested types and preserves supported content. This is separate from top-level validation in #47747/#47877 and nested-image support in #35557.
