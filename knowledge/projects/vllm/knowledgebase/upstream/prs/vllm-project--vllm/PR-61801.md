# [Doc] Fix placeholder count in prefix caching multi-modal example

[Upstream PR](https://github.com/vllm-project/vllm/pull/61801) · state: open · merged: False

## Original PR description

## Overview
Fix the multi-modal hashing example in `docs/design/prefix_caching.md` so it agrees with the "only full blocks are cached" rule (Note 1 on the same page).

## Claims
- The example now has 4 full blocks, so every block in the list correctly has a hash.

## Validation
- Before: 8 text tokens + 41 placeholders + 1 end token = 50 tokens. With block size 16, Block 3 has only 2 tokens, so it is not full and must not be hashed. But the example shows a hash for it.
- After: 8 + 55 + 1 = 64 tokens = 4 full blocks of 16.
- This matches `get_request_block_hasher()` in `vllm/v1/core/kv_cache_utils.py`, which only hashes full blocks.

## Details
One-number doc change. I changed the placeholder count instead of removing Block 3's hash, so the rest of the example stays the same.
