# [Docs] Fix griffe missing-type warnings in XPress kernels

[Upstream PR](https://github.com/vllm-project/vllm/pull/63228) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Fixes the 29 `griffe: No type or annotation for parameter ...` warnings emitted by the docs build for `vllm/v1/worker/gpu/spec_decode/xpress/kernels.py` (added in #54448).

## Claims

- The `@triton.jit` kernels annotate pointer params as `tl.tensor` and size/stride params as `int`, matching existing kernels (e.g. `top_k: int` in `fused_moe.py`). Triton ignores `tl.tensor`; `int` pins the arg to i32, and all of these values (V, C, row strides) are far below 2^31, so codegen is unchanged.
- The Python launchers `fused_add_argmax_to_blk` and `fused_topc_argmax_to_blk` get `torch.Tensor` annotations.
- No runtime behavior change.
