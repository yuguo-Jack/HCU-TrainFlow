# [CI] Split (H200 MIG 35GB / MI355) PyTorch Fullgraph into named jobs

[Upstream PR](https://github.com/vllm-project/vllm/pull/56877) · state: closed · merged: False

## Original PR description

## What

Replace the single `pytorch-fullgraph-test` step with five named jobs, so the build timeline shows which fullgraph workload ran. Basic correctness is split by model and compile backend, and every job runs its own directory. The Smoke job runs every file at the `compile/fullgraph/` root with a `-maxdepth 1` find and no exclusions, so new root files run there by default, each in its own pytest process (#28965).

## Old

```text
pytorch-fullgraph-test   (H200 MIG 35GB) PyTorch Fullgraph  +  (MI355) mirror
  find compile/fullgraph/ -name 'test_*.py' -not -name 'test_full_cudagraph.py' | xargs -n1 pytest

tests/compile/fullgraph/
├── test_basic_correctness.py      # granite + bge-multilingual-gemma2, each: inductor pass then eager pass
├── test_full_cudagraph.py         # (L4) CUDAGraph Compatibility step, unchanged
├── test_full_graph.py
├── test_multimodal_compile.py
├── test_multiple_graphs.py
├── test_simple.py
└── test_toy_llama.py
```

## New

| Key (each with an `amd-<key>` MI355 DPX mirror) | Label suffix | Runs |
| --- | --- | --- |
| `pytorch-fullgraph-basic-correctness-granite-inductor` | PyTorch Fullgraph Basic Correctness Granite Inductor | `pytest compile/fullgraph/basic_correctness/granite_inductor` |
| `pytorch-fullgraph-basic-correctness-bge-multilingual-gemma2-inductor` | PyTorch Fullgraph Basic Correctness BGE Multilingual Gemma2 Inductor | `pytest compile/fullgraph/basic_correctness/bge_inductor` |
| `pytorch-fullgraph-basic-correctness-eager` | PyTorch Fullgraph Basic Correctness Eager | `pytest compile/fullgraph/basic_correctness/eager` (both models) |
| `pytorch-fullgraph-full-graph` | PyTorch Fullgraph Full Graph Models | `pytest compile/fullgraph/full_graph` |
| `pytorch-fullgraph-smoke` | PyTorch Fullgraph Smoke | `find compile/fullgraph/ -maxdepth 1 -name 'test_*.py' \| xargs -n1 pytest`, no exclusions |

The (L4) CUDAGraph Compatibility step now runs `pytest compile/fullgraph/cudagraph`.

```text
tests/compile/fullgraph/
├── basic_correctness/
│   ├── _basic_correctness.py                               # was test_basic_correctness.py; helper, not collected
│   ├── granite_inductor/test_granite_inductor.py           # was test_setting0, inductor pass
│   ├── bge_inductor/test_bge_multilingual_gemma2_inductor.py  # was test_setting1, inductor pass
│   └── eager/test_eager.py                                 # eager pass of test_setting0 and test_setting1
├── full_graph/test_full_graph.py                           # moved, unchanged apart from the relative import
├── cudagraph/test_full_cudagraph.py                        # moved, unchanged
└── test_multimodal_compile.py, test_multiple_graphs.py, test_simple.py, test_toy_llama.py   <- Smoke
```

## Notes

- `run_compile_correctness(setting, backend)` runs the same four compilation modes and comparison method (`generate_close` for inductor generation) as before, one backend per call. Node IDs change intentionally, to one test per model × backend.
- `pytorch-fullgraph-test` is retired; nothing else referenced it. The legacy `test-amd.yaml` job that ran `test_basic_correctness.py` now runs `compile/fullgraph/basic_correctness`, and the legacy recursive `find compile/fullgraph/` commands still match by filename. `compile.yaml`'s B200 trigger points at the moved `test_full_graph.py`.
- Local checks: test tethering passes, with and without legacy `test-amd.yaml`. Ruff passes and YAML parses. Each `compile/fullgraph` test file is claimed exactly once.
- AI assistance was used (Claude Code); the submitter reviewed the diff.

| BGE Multilingual Gemma2 Inductor | ~13:55 | ~15:00 | ~1:05 | checkout + image pull |

- The mirror jobs split the same way, and their predicted totals are within budget.
- Why five jobs: each model's inductor pass is about 12–13 min on its own, so the two can't share a job. Both eager passes together are about 7–8 min, one coherent job. Full Graph Models is one file at about 15.5 min. Smoke is four light files.
