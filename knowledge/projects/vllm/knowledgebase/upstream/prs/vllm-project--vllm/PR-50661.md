# [Model Runner v2] Enable BGE M3 pooling embed token_classify

[Upstream PR](https://github.com/vllm-project/vllm/pull/50661) · state: closed · merged: True

## Original PR description

## Purpose

Enable BGE-M3's combined `embed&token_classify` pooling task on Model Runner V2 for encoder-only models. This is the fourth step in the MRV2 pooling series. Once this PR lands, **encoder-only** pooling on MRV2 is complete for every in-tree pooling task:

| Task | Status |
| --- | --- |
| `embed`, `classify` | #48791 (merged) |
| `token_classify` | #50293 (merged) |
| `token_embed` | #50574 (merged) |
| `embed&token_classify` | this PR |

Today BGE-M3 does not fall back gracefully on V2, it fails to start. It is the only in-tree model declaring this task, and `get_pooling_task()` ranks `embed&token_classify` first, so it is selected by default and then rejected:

```text
ValueError: Model Runner V2 supports pooling tasks ['classify', 'embed', 'token_classify'], but this model selects 'embed&token_classify' from ['embed', 'embed&token_classify', 'token_classify', 'token_embed'].
```
