# [Doc] Sync Kimi-K3 GB200 AgentX profiles with InferenceX #4322

[Upstream PR](https://github.com/vllm-project/vllm/pull/62761) · state: closed · merged: True

## Original PR description

## Overview

Syncs the Kimi-K3 GB200 InferenceX AgentX section with [SemiAnalysisAI/InferenceX#4322](https://github.com/SemiAnalysisAI/InferenceX/pull/4322) at [`b7eee97`](https://github.com/SemiAnalysisAI/InferenceX/tree/b7eee972451f9297941d4cbe6d42d489d7ec8363/inferencex-e2e/benchmarks/multi_node/srt-slurm-recipes/kimik3/vllm/gb200-fp4/agentx), which builds on #3748 and moves both GB200 lanes to one vLLM nightly. It changes only `recipes/models/moonshotai/Kimi-K3.yaml`.

**This PR is stacked on #62542** (the #3748 sync): that PR's commits show here until it merges, and this one will be rebased onto `main` afterwards. Only the last commit is new. InferenceX #4322 is still in review.

## Claims

- **Selector, GB200 + Prefill/Decode + Dynamo:**
  - Both roles add `--mamba-ssm-cache-dtype bfloat16` and `PYTORCH_CUDA_ALLOC_CONF=max_split_size_mb:512`.
  - Decode `--max-num-batched-tokens` goes from 16384 to 1024. Decode batches at most 480 tokens; at the 16384 default the FlashInfer MoE autotune bucket needs a 2.9 GiB workspace that runs out of memory at 0.92 and hangs the other ranks.
  - Both roles add `NCCL_NET_PLUGIN=none`, and decode now gets `VLLM_KIMI_K3_SHARD_SP_SHARED_EXPERT=0`, which the lane sets on both roles (the selector rendered it for prefill only). Both are in #3748 too and were missing from #62542.
- **Guide, aggregated:** image moves to `nightly-e68efc68`, the same nightly as the disaggregated lane. The aggregated recipe is otherwise identical to #3748, so the selector is unchanged.
- **Guide, disaggregated:** image `nightly-e68efc68`, Dynamo `ffbbaaa6`, the new flags and env in both role commands, a concurrency-32 row (`S`=64, prefill 0.88/512, decode 0.92/320), and the NATS note replaced: the lane starts no NATS service and this is now covered by the qualified run.
- Left out as InferenceX-only or cluster-local: `*_eval` parser overrides (the guide already documents the parser flags), dev-mode and telemetry env, cache paths, `WITH_NVIDIA_PEERMEM=0`, AIPerf settings.
