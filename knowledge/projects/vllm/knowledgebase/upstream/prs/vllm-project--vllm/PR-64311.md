# [MM][CG] support ViT encoder cudagraph for DeepSeek-OCR2

[Upstream PR](https://github.com/vllm-project/vllm/pull/64311) · state: open · merged: False

## Original PR description



## Overview


Support ViT encoder cudagraph capture/replay for DeepSeek-OCR2, which tracked in #38175 . Follow the #43586 style.

## Test Plan


**Functional Test**
```
VLLM_USE_V2_MODEL_RUNNER=0 TRITON_ALLOW_NON_CONSTEXPR_GLOBALS=1 \
      python examples/generate/multimodal/vision_language_offline.py \
        -m deepseek_ocr2 --modality image --enable-vit-cuda-graph
```
**Benchmark**
Use a RTX 5070Ti 16GB
~~~bash
size=896
mode=graph
config='{"mode":0,"cudagraph_mode":"NONE","cudagraph_mm_encoder":true,"encoder_cudagraph_token_budgets":[576],"encoder_cudagraph_max_vision_items_per_batch":1}'
# For the eager run:
# mode=eager
# config='{"mode":0,"cudagraph_mode":"NONE"}'

vllm bench mm-processor \
  --model deepseek-ai/DeepSeek-OCR-2 \
  --dtype bfloat16 --max-model-len 2048 --max-num-seqs 1 \
  --gpu-memory-utilization 0.8 --dataset-name random-mm \
  --random-input-len 16 --random-output-len 1 \
  --random-mm-base-items-per-request 1 \
  --random-mm-num-mm-items-range-ratio 0.0 \
  --random-mm-bucket-config "{($size, $size, 1): 1.0}" \
  --random-mm-limit-mm-per-prompt '{"image": 1, "video": 0}' \
  --num-prompts 100 --num-warmups 5 --seed 42 --disable-tqdm \
  --metric-percentiles 50,99 --compilation-config "$config" \
  --output-json "/tmp/ocr2-mm-$size-$mode.json"
~~~
