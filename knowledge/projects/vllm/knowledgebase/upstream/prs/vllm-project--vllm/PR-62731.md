# [CI][ROCm] Remove MI300 Model Runner V2 steps

[Upstream PR](https://github.com/vllm-project/vllm/pull/62731) · state: closed · merged: True

## Original PR description

`:amd: (MI300) Model Runner V2 Distributed` timed out at the 45 min limit in the nightly [amd-ci#15028](https://buildkite.com/vllm/amd-ci/builds/15028).
No test failed: everything that ran passed, and the job was killed during `test_eagle_dp.py[FLEX_ATTENTION]`.
This PR raises `timeout_in_minutes` for that step from 45 to 55.

Updated: removing the MI300 Model Runner V2 steps instead of raising the timeout, in line with upstream (#54823).
