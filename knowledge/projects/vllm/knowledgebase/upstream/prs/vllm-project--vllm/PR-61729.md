# [Model] Add Clef 27B regression coverage and serving docs

[Upstream PR](https://github.com/vllm-project/vllm/pull/61729) · state: closed · merged: False

## Original PR description



## Overview

`Cloudflare/clef` (27B) already runs through the Clef-Flash implementation from #61308, but is absent from the supported-model table and processor regression matrix. Add its checkpoint to the existing matrix and document its `/v1/systemone` launch and supported inputs.

## Claims

- Exercise Clef 27B in the existing multimodal processor tests, including text/token prompts and processor-cache paths.
- List Clef and Clef-Flash together as multimodal decision models and document the 27B launch command and 16,384-token prompt bound.
- Clarify the shared model and read-strategy docstrings. Inference behavior is unchanged.

## Validation

Full `Cloudflare/clef` checkpoint at revision `0b331204bb13fbd2ca93a64df1956f5b55478ce5`, BF16, TP=1 on NVIDIA GB200, compared with the checkpoint's `joint_schema_model.py` loaded with `attn_implementation="sdpa"`.

Eight inputs cover text/JSON, Unicode and empty/omitted question instructions, one-option choices, state truncation at 16K, one/two images, video, and image+video. Prompt token IDs and question/option spans match the reference exactly in all eight cases. Each mode runs the eight requests sequentially and twice at concurrency 4:

| Mode | Requests | Highest-probability option matches | Max absolute probability difference |
|---|---:|---:|---:|
| Eager | 24 | 60/60 | 0.010056 |
| Default compile | 24 | 60/60 | 0.014783 |

Probabilities sum to one, input-token counts match the reference, output-token counts are zero, and `label_mass` is one. Top-level prompt overrides and audio inputs return 400. These are synthetic reference-parity checks, not a full decision benchmark. TP>1 and quantized checkpoints were not evaluated.

Serving configuration for the comparison:

```bash
vllm serve Cloudflare/clef \
  --revision 0b331204bb13fbd2ca93a64df1956f5b55478ce5 \
  --served-model-name clef --dtype bfloat16 \
  --max-model-len 16384 --max-num-batched-tokens 512 --max-num-seqs 8 \
  --gpu-memory-utilization 0.6 \
  --limit-mm-per-prompt '{"image":2,"video":1}' --skip-mm-profiling
# Add --enforce-eager for the eager comparison.
```

The reference comparison was run on base `4e0681ed56`. The model wrapper and the shared Clef-Flash rendering path are unchanged on the rebased branch. Focused tests and lint were rerun after rebasing onto `2abd479aee`:


Results on the rebased branch: 17 config/strategy tests passed, all 6 Clef/Clef-Flash processor cases passed, and all applicable pre-commit hooks passed.

On the original base, the shared pooler test also passed:
`.venv/bin/python -m pytest tests/models/multimodal/pooling/test_clef_omni.py -q` (1 passed).
An initial broader processor selection passed all six Clef/Clef-Flash cases but failed three Clef-Omni cases because of shared Hugging Face cache-lock permissions; the scoped Clef/Clef-Flash rerun passed all six cases.

## Details

The checkpoint advertises `Qwen3_5ForConditionalGeneration` and ships the same reference implementation as Clef-Flash. The existing converter detects `joint_head_config.json`, selects `ClefFlashForJointSchema`, and loads the separate head weights. The 27B head's 5120-wide backbone inputs are handled by its checkpoint configuration.

The registry extra automatically enters the existing Buildkite multimodal processor suite. This adds coverage without a new model class, test file, or CI job. The docs now put the shared Clef architecture in the multimodal table.

Duplicate checks found no open Clef 27B coverage/support PR. #61308 supplies the runtime implementation and this PR extends its checkpoint coverage and documentation. The open Clef-related PRs #61251 and #61473 address frontend performance and CI sharding respectively. Issue #60947 concerns pooling prefix-cache reads and is not addressed here.

AI assistance (Codex) was used to prepare the changes, inspect the shared implementation, and run the validation. The human submitter confirmed review of every changed line and completion of relevant test runs.
