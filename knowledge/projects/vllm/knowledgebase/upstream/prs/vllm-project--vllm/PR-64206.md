# [WIP][ROCm][MiniMax-M3] Fold routed scaling into the AITER top-k weights

[Upstream PR](https://github.com/vllm-project/vllm/pull/64206) · state: closed · merged: False

## Original PR description

Without shared-expert fusion, have the router fold routed_scaling_factor into the top-k weights instead of scaling the bf16 MoE output, and pass the factor to AITER's biased_grouped_topk, which applies it in-kernel, rather than multiplying the weights afterwards. Removes one elementwise kernel per MoE layer
