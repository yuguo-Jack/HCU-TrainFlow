# [CI][ROCm] Raise the MI355 MiniMax M3 MonoKernel timeout to 45 minutes

[Upstream PR](https://github.com/vllm-project/vllm/pull/63269) · state: closed · merged: True

## Original PR description

- Raise the `:amd: (MI355) MiniMax M3 MonoKernel` step timeout in `models_basic.yaml` from 20 to 45 minutes.

#62994 added `test_eagle3_verify_steps_match_native` (~8 minutes) to `models/minimax_m3/amd_specialized_decode`, so the step's first pytest command alone now takes about 19 minutes. With image pull and setup, the step hits its 20-minute limit and is killed before `test_index_cache_overrides.py` runs, although every test that ran passed ([build 96785](https://buildkite.com/vllm/ci/builds/96785/list?sid=01a166b2-6503-4133-b7ae-e51e595040d5&tab=output): 64 passed, 1 skipped in 19:05, then timed out). 45 minutes matches the `MiniMax M3 Specialized Decode` step in `test-amd.yaml`, which runs the same suite.

AI assistance (Claude Code) was used to draft this change. Every line was reviewed by the submitter.
