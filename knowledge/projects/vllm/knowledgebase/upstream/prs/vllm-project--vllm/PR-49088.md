# Extend benchmark_moe HF MoE shape parsing beyond Mixtral fallback

[Upstream PR](https://github.com/vllm-project/vllm/pull/49088) · state: open · merged: False

## Original PR description




## Purpose
`benchmark_moe`’s fallback (`else`) assumed Mixtral-style fields (`num_local_experts` / `num_experts_per_tok` / `intermediate_size` after `get_text_config()`). Many MoE HF configs use other names (`num_experts`, `n_routed_experts`, …), nested views, or list-valued fields, so shape resolution failed and the bench could not run.

This PR replaces that Mixtral-only fallback with a small generic HF MoE extractor (nested views + field aliases). Existing architecture-specific `elif` branches are unchanged.

## Test Plan
```bash
# resolve shape only (no weights)
python benchmarks/kernels/benchmark_moe.py --model <hf-id> --tp-size 1 --batch-size 1
```
