# [Bugfix][Frontend] Fix missing input logging for systemone

[Upstream PR](https://github.com/vllm-project/vllm/pull/62158) · state: open · merged: False

## Original PR description

## Overview

`/v1/systemone` now logs request receipt and input through the shared request logger, matching `/v1/decisions`.

## Claims

- Logs the rendered state once per request, including requests with multiple questions.
- Uses the existing log level, input truncation, and request logging controls.

## Validation

 Tests passed. Also tested locally with `Qwen/Qwen3-0.6B`.

## Details

The endpoint rendered the state for the read strategy but did not call `_log_inputs`. This change passes the same rendered state to the existing logger before dispatching the questions.
