# [Bugfix] Declare Qwen GDN QKV input mutations

[Upstream PR](https://github.com/vllm-project/vllm/pull/63092) · state: open · merged: False

## Original PR description

## Overview

Declare the QKV input mutable in both Qwen GDN core-op schemas. The convolution writes to this buffer in place; without the declaration, functionalization can lose that update.

## Claims

- Track input mutation for the standard and packed core ops.
- Preserve kernel arithmetic, backend selection and existing output declarations.

## Validation

Rebased onto `1ca0dfb9` on Oct 29, retaining the upstream GDN changes. Both CPU export regressions passed using the complete current GDN module, and applicable changed-file pre-commit checks passed. The C550 checks below are historical and have not been rerun on this head.

The CPU export regression fails both cases before the fix and passes both afterward:

```bash
VLLM_TARGET_DEVICE=cpu .venv/bin/python -m pytest --noconftest \
  tests/kernels/mamba/test_gdn_input_mutation.py -q
```

Python 3.12.15, torch 2.14.1+cpu, using the target GDN module and updated dependencies over an older checkout.

On MetaX C550 (MACA 3.8.0.23, torch 2.10.0+metax3.8.0.7), a real native GDN layer failed `opcheck(test_schema)` before the fix with `Argument qkv_or_qkvz is not defined as mutable but was mutated`. Batches 1 and 4 passed afterward. Six convolution checks also passed, covering in-place/output parity, state equality, the sibling Z view and compiled/eager equality.

The packed fused-norm entry has CPU export and packed-view convolution coverage, but no full GPU attention run. No model was loaded. These checks used the target source in compatible environments, not a complete rebuilt main.

Applicable pre-commit hooks passed, including mypy and CI test tethering. The existing Mamba kernel CI step selects the new tests.

## Details

The convolution's output aliases its input, including the QKV slice of a packed projection. Declaring the input mutable makes the write part of the exported program's mutation outputs. Related #52190 changes Kimi KDA registration rather than these Qwen ops.

AI-assisted implementation and validation; reviewed by the submitter.
