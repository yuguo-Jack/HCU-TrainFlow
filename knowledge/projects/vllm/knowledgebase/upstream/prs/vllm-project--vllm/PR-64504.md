# [Perf][GLM-5.3] Extend GLM low-latency BF16 GEMM table on SM103

[Upstream PR](https://github.com/vllm-project/vllm/pull/64504) · state: open · merged: False

## Original PR description



## Overview

Extends the SM103 (B300) GLM-5.2/5.3 low-latency BF16 GEMM table with the TP4 projections, shared expert gate_up and indexer wk; SM103 had TP8 q_b, qkv_a and eh_proj only.

## Claims

- B300, M ≤ 4: 1.11–2.37x over cuBLAS per projection (cold L2).

## Validation

```
pytest tests/kernels/test_bf16_skinny_gemm.py -k "glm or dsv3"   → 122 passed, 103 skipped (B300)
run_glm52_plan vs F.linear, every routed cell (CUPTI, CUDA graph) → all ≥ 1.05x cold and hot L2
```

| projection | (N, K) | routed M | M=1 cuBLAS → table (µs, cold L2) | speedup over routed M |
|---|---|---|---|---|
| q_b TP4 / indexer wq_b | (4096, 2048) | 1–3 | 8.83 → 5.76 | 1.11–1.53x |
| o_proj TP4 | (6144, 4096) | 1 | 15.26 → 11.20 | 1.36x |
| o_proj TP8 | (6144, 2048) | 1 | 8.06 → 7.26 | 1.11x |
| indexer wk + weights | (160, 6144) | 1–4 | 5.95 → 2.69 | 1.72–2.37x |
| shared gate_up TP8 | (512, 6144) | 1–4 | 7.90 → 3.81 | 1.71–2.08x |
| shared gate_up TP4 | (1024, 6144) | 1–4 | 8.51 → 5.02 | 1.42–1.69x |

## Details

Cells kept only if ≥ 5 % faster on cold and hot L2; shared expert down stays on cuBLAS. No e2e (needs 4–8 B300).
