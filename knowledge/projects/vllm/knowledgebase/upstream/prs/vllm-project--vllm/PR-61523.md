## Claims

Use lower-bound searches with the original floating-point comparison and stop after the extra candidate that selects the existing uniform fallback. Remove the full timestamp array.

## Validation

Validated on a remote Ubuntu x86_64 machine with Ryzen 9 9900X, Python 3.12.13 and PyTorch 2.13.0+cpu, against base `698e79f3bdbbe4fe7d6be6d91b358a7f430753ab`.

```sh
TRITON_DEFAULT_BACKEND=cpu VLLM_TARGET_DEVICE=cpu OMP_NUM_THREADS=2 PYTHONPATH=. ../.venv/bin/python -m pytest tests/multimodal/test_video.py --confcutdir=tests/multimodal -k glm -q
```

Baseline: all 3 bounded-work regression cases failed. Patched: 55 GLM tests passed, no skips. Sampling-only benchmark output hashes matched across all 3 backends for 30-second and 3600-second videos at 120 FPS; median time for the hour-long case decreased from 17.33/7.52/7.85 ms to 4.15/1.40/1.35 ms. Short-video GLM46V and GLMGA sampling had sub-millisecond overhead; this is not an end-to-end inference speedup claim.

Applicable pre-commit checks passed. Upstream CI has not yet been evaluated for this draft.

## Details

Benchmark measures frame selection only, not model inference. Related #55727 caps sampling parameters; this patch bounds frame-selection work while retaining the existing selection result.

AI assistance (OpenAI Codex) was used for analysis, implementation and validation. The submitter's human review remains pending.
