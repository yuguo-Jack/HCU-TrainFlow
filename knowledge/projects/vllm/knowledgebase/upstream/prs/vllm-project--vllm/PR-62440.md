# [CPU] Add AArch64 top-k and top-p sampling kernels

[Upstream PR](https://github.com/vllm-project/vllm/pull/62440) · state: open · merged: False

## Original PR description

## Purpose

This PR brings the CPU top-k/top-p sampling work from #43452 and #55874 to the current vLLM main branch while preserving the original commit authorship:

- Tianmu Li's commit adds the base C++ kernels and integration for top-k, top-p, and combined top-k/top-p sampling.
- Fadi Arafeh's commit adds the AArch64 implementation.

The final cleanup commit:

- removes the AVX512 and AVX2 sampling paths introduced by the base implementation;
- retains the AArch64 implementation and scalar fallbacks;
- removes the added AVX2 fast-exp macro and `-mfma` build flag;
- applies repository formatting; and
- adds `TestCpuTopkTopp` to the Arm CPU hardware CI kernel shard.
