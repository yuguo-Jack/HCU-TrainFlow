# [CI] Remove permanently skipped and never-runnable tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/60592) · state: open · merged: False

## Original PR description

## Overview

Remove tests, parametrizations and test-only helpers that are skipped on every CI runner or can never run (bare `@skip` for months or years, private or deleted checkpoints, `enable_test=False` entries, hardware no step provides). Part of a legacy-test audit; nothing here reduces coverage that actually executes today.

Legacy-test tracker: A1

## Claims

- Removes golden-string quantized-model tests that never run in CI and are pinned to unpublished or old checkpoints: `tests/models/quantization/test_mxfp4.py`, `test_modelopt.py`, and `test_nvfp4.py::test_models`.
- Removes 7 `test_embed_models_correctness` functions whose helper begins with `pytest.skip("Debug only…")`, so they never ran, plus all 36 `enable_test=False` MTEB family entries. With no users left, the `ModelInfo.enable_test` field and `VLLM_CI_NO_SKIP` go too.
- Removes long-skipped kernel and distributed tests:
  - `test_cutlass_int8_azp_bias_fold`: bare skip since 2024-08.
  - FlashInfer FP8-KV prefill/decode: skipped as "TODO" for about 20 months.
  - `test_stateless_process_group`: skipped as flaky since 2024-11.
- Removes LoRA model tests that are skipped on CUDA/ROCm "to avoid redundant model tests" (#42266) and that no Intel job runs. `test_default_mm_loras` stays because it runs on XPU.
- Removes `test_quark::test_mxfp4_gsm8k_correctness`, which needs a private AMD repo and 8 GPUs, and trims `test_ocp_mx_wikitext_correctness` to tp=1. Every step that runs `tests/quantization` is single-GPU.
- Removes `test_phimoe::test_models`: skipped on all platforms since #31632 because the HF remote code is broken.
- Removes the harmony Responses tests that can't fail in CI (web search, code-interpreter streaming). The personality test keeps its system-prompt check without the non-strict xfail and the keyword match.
- Removes `test_deepseek_fp8_block_moe_flashinfer_cutlass`: FlashInferExperts limits block FP8 to SM90, so it cannot run on B200.
- Removes dead params: the deleted SkipQKV FP8 checkpoint, the OOM `llama4_eagle` EPLB case, and `qwen2_5_vl_eagle3`, which has been skipped since it was added.

## Validation

- `python tools/pre_commit/check_test_tethering.py --all`: passes. No CI step referenced the deleted files.
- `pre-commit run --files <changed files>`: all hooks pass (ruff, mypy, auto-label, tethering).
- `pytest --collect-only -q` on every modified test file, the whole `pooling_mteb_test` directory, and the files that import `embed_utils`: 453 collected, 0 errors. `test_cutlass_scaled_mm.py` and `test_blackwell_moe.py` need CUDA to collect; they pass ruff and mypy.
- Collected test IDs before and after, against the branch base: the only IDs that disappear are the intended ones. Three are renamed: the harmony personality test, and the two wikitext IDs that lost the `tp_size` parametrize.
- GPU tests were not run locally. Every removed test was skipped on every CI runner, which is the premise of this PR.

## Details

- Left out because an open PR handles them: the min_tokens stale xfails (#47487), and jina-v3 `test_matryoshka`, which #59776 re-enables.
- Kept on purpose and worth a re-run rather than deletion:
  - The Blackwell MoE `test_llama4_..._flashinfer_cutlass` and `test_nemotron_fp8_moe_vllm_triton` cases, and `test_nemotron_fp8_moe_flashinfer_latency`. Their skip reasons look stale on current main (for example, `_supports_no_act_and_mul` now returns True since #36307).
  - `test_qwen3_next_..._trtllm`: a known bug.
  - The torchao tests: their skip asks for torchao 0.14/0.15, and CI now installs 0.17. They should be un-skipped in a separate PR.
- Removing `enable_test` drops the `VLLM_CI_NO_SKIP=1` switch, which ran every family member locally. Pooling maintainers: say so if you want to keep it.
- The Qwen2.5-VL EAGLE3 multimodal-profiling bug behind the `qwen2_5_vl_eagle3` skip deserves its own issue.
- Conflict to watch: #56870 lists `models/quantization/test_modelopt.py` and `test_mxfp4.py` in its new yaml. Whichever PR lands second needs to drop those two paths.
- Not a duplicate: open-PR searches across about 20 keyword sets found only the overlaps above.
