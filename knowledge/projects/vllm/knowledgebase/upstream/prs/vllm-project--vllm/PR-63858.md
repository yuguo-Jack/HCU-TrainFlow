# [Bugfix][HiSparse] Temporarily defer unpinning resident pages in P/D

[Upstream PR](https://github.com/vllm-project/vllm/pull/63858) · state: closed · merged: False

## Original PR description

## Purpose

Temporary workaround for a HiSparse P/D race (also addressed by #63827, with a GPU sync): an RDMA (NIXL) transfer into a reused indexer page can overwrite a resident page that an in-flight step still reads, corrupting that request's KV (outputs degenerate into a repeated token).

Once a P/D request (`do_remote_prefill`) arrives, an unpinned resident page stops being read immediately and its block returns to the pool only after the steps already scheduled have been processed. The same applies to the clean pages of a finished request. HiSparse without P/D is unchanged. Cost: in P/D, decode pages are read from host once written back. Known gap: pages unpinned before the first P/D request keep the old behavior. To be removed once a proper fix lands.
