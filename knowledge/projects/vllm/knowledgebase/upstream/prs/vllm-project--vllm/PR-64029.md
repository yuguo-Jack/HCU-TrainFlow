# [ROCm][Perf][Kimi-K3] Specialized decode K2: sentinel all-reduces, pre-AR loads, tagged x rows

[Upstream PR](https://github.com/vllm-project/vllm/pull/64029) · state: closed · merged: True

## Original PR description

Stacked on #61435 (the last commit is this PR).

K2 options as `K2Build.opt` bits, default on (`K2_OPT = 891`). All are bit-exact vs `opt=0` (= #61435):

- 1 / 16 / 32: o_proj / latent / final all-reduce through sentinel regions (plain bf16 words, deferred re-arm)
- 2: AttnRes slice loads issued before the all-reduce poll
- 8: x rows as tagged pairs to the router / latent GEMVs
- 64: shared-down tasks needed by up run first
- 256: router partials pushed straight to every rank
- 512: batched polls

The runner adds ~10 MB of peer memory and ~4 MB of scratch.
