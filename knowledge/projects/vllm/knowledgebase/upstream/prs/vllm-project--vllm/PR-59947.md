# refactor: unify FlashInfer utility modules (#31414)

[Upstream PR](https://github.com/vllm-project/vllm/pull/59947) · state: closed · merged: False

## Original PR description

## Summary

This PR unifies FlashInfer helper utilities into a single canonical module `vllm.utils.flashinfer`, resolving redundant utility locations across the repository.

- **Consolidated Helpers**: Migrated all FlashInfer MoE, FP8/FP4 weight alignment, layout transformation, and activation mapping utilities from `vllm.model_executor.layers.quantization.utils.flashinfer_utils` into `vllm.utils.flashinfer`.
- **Migrated Consumers**: Updated all production consumers (CuTeDSL, CUTLASS, TRT-LLM MoE, quantization layers, and Buildkite CI configs) to import from `vllm.utils.flashinfer`.
- **Removed Duplicate Module**: Safely removed `vllm/model_executor/layers/quantization/utils/flashinfer_utils.py`.
- **Preserved Lazy Loading & Type Safety**: Retained existing lazy FlashInfer import behavior and used `TYPE_CHECKING` guards to avoid circular imports.
- **Added Tests**: Added unit tests in `tests/utils_/test_flashinfer_utils.py` covering tensor transformations, padding logic, and activation mappings.

## What Changed

- **`vllm/utils/flashinfer.py`**: Added consolidated helpers (`swap_w13_to_w31`, `align_moe_weights_for_fi`, `align_fp4_moe_weights_for_fi`, `prepare_fp8_moe_layer_for_fi`, `activation_to_flashinfer_type`, etc.) and exposed them in `__all__`.
- **`vllm/model_executor/layers/quantization/utils/flashinfer_utils.py`**: Deleted redundant module.
- **Consumers & Tests**: Updated imports in MoE layers (`experts/`, `oracle/`), quantization utils (`b12x_moe.py`, `flashinfer_fp4_moe.py`), and test files.

## Testing & Verification

- **Smoke Tests**: Verified `import vllm.utils.flashinfer` and all 14 migrated symbols import cleanly without circular dependencies.
- **Unit Tests**: Ran tests for weight alignment, tensor swap, and activation mappings (`tests/utils_/test_flashinfer_utils.py`).
- **Cleanliness**: Confirmed zero leftover references to `flashinfer_utils` and verified `git diff --check` passes cleanly.

Fixes #31414
