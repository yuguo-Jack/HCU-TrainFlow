# [Bugfix][Tool Parser] Fix invalid streamed JSON for control characters in hy_v3 tool args

[Upstream PR](https://github.com/vllm-project/vllm/pull/62271) · state: open · merged: False

## Original PR description

## Overview

In HY V3 streaming mode, the `hy_v3` tool parser produces invalid JSON for tool-call arguments as soon as a string value contains a control character other than `\n`, `\r` or `\t`. To fix this, the partial value is now escaped with `json.dumps`, the same way `hy_v4` already does.

This matters for coding agents: terminal output with ANSI colour codes (`\x1b[31m...`) is routinely passed as a tool argument (e.g. saving a build log with a `write_file` tool), and every such streamed call currently fails to parse on the client. Non-streaming is unaffected, so the bug only shows up when streaming.

## Claims

- Streamed tool-call arguments are valid JSON and equal to the non-streaming arguments for any string value, including control characters.
- No change for values without such characters: printable text and `\\ " \n \r \t` are escaped exactly as before.
- Adds a regression test.

```python
"""HY V3 tool parser through vLLM's real chat-completion serving path.

The real model (tencent/Hy3-preview, ~299B params) can't run here, so the
engine is replaced by a fake that replays a fixed model output, tokenized
with the real Hy3 tokenizer and streamed one token per RequestOutput (like
AsyncLLM in DELTA mode). Everything after the engine is real vLLM code:
OpenAIServingChat, the hy_v3 tool parser and SSE chunk generation, both
streaming and non-streaming.

For each argument value, prints whether the streamed tool-call arguments are
valid JSON and equal to the non-streaming arguments.

Run from the vLLM clone:
  VLLM_TARGET_DEVICE=cpu PYTHONPATH=. .venv/bin/python <this file>
"""

import asyncio
import json

from tests.entrypoints.openai.chat_completion.test_serving_chat import (
    MockHFConfig,
    _build_mock_engine,
    _build_renderer,
    _build_serving_chat,
)
from vllm.entrypoints.openai.chat_completion.protocol import ChatCompletionRequest
from vllm.entrypoints.generate.base.protocol import RequestResponseMetadata
from vllm.outputs import CompletionOutput, RequestOutput
from vllm.tokenizers import get_tokenizer

MODEL = "tencent/Hy3-preview"
TOOLS = [
    {
        "type": "function",
        "function": {
            "name": "write_file",
            "parameters": {
                "type": "object",
                "properties": {
                    "path": {"type": "string"},
                    "content": {"type": "string"},
                },
                "required": ["path", "content"],
            },
        },
    }
]
VALUES = {
    "plain text": "hello world",
    "ANSI colour codes (terminal output)": "\x1b[31mERROR\x1b[0m: build failed",
    "form feed": "page1\x0cpage2",
    "backspace": "abc\x08d",
}


def model_output(content: str) -> str:
    return (
        "<tool_calls>\n<tool_call>write_file<tool_sep>"
        "\n<arg_key>path</arg_key>\n<arg_value>out.txt</arg_value>"
        f"\n<arg_key>content</arg_key>\n<arg_value>{content}</arg_value>"
        "\n</tool_call>\n</tool_calls>"
    )


def build():
    engine = _build_mock_engine()
    cfg = engine.model_config
    cfg.model = cfg.tokenizer = MODEL
    cfg.hf_config = cfg.hf_text_config = MockHFConfig(model_type="hy_v3")
    cfg.max_model_len = 4096
    engine.renderer = _build_renderer(cfg)
    serving = _build_serving_chat(engine, tool_parser="hy_v3", enable_auto_tools=True)
    return serving, get_tokenizer(MODEL)


def request_output(req, text, token_ids, finished):
    out = CompletionOutput(
        index=0,
        text=text,
        token_ids=token_ids,
        cumulative_logprob=0.0,
        logprobs=None,
        finish_reason="stop" if finished else None,
    )
    return RequestOutput(
        request_id=req.request_id,
        prompt=None,
        prompt_token_ids=[1, 2, 3],
        prompt_logprobs=None,
        outputs=[out],
        finished=finished,
    )


async def run(serving, tok, text, stream):
    req = ChatCompletionRequest(
        model=MODEL,
        messages=[{"role": "user", "content": "save the build log"}],
        tools=TOOLS,
        stream=stream,
    )
    ids = tok.encode(text, add_special_tokens=False)
    assert tok.decode(ids) == text, "tokenizer round-trip changed the text"

    async def results():
        if not stream:
            yield request_output(req, text, ids, True)
            return
        prev = ""
        for i in range(1, len(ids) + 1):
            cur = tok.decode(ids[:i])
            yield request_output(req, cur[len(prev):], [ids[i - 1]], i == len(ids))
            prev = cur

    common = dict(
        request=req,
        result_generator=results(),
        request_id=req.request_id,
        model_name=MODEL,
        conversation=[],
        tokenizer=tok,
        request_metadata=RequestResponseMetadata(request_id=req.request_id),
    )
    if not stream:
        parser = serving.parser_cls(tok, req.tools)
        resp = await serving.chat_completion_full_generator(parser=parser, **common)
        return [c.function.arguments for c in resp.choices[0].message.tool_calls]

    args = {}
    async for chunk in serving.chat_completion_stream_generator(**common):
        payload = chunk.removeprefix("data: ").strip()
        if not payload or payload == "[DONE]":
            continue
        for choice in json.loads(payload).get("choices", []):
            for tc in (choice.get("delta") or {}).get("tool_calls") or []:
                fn = tc.get("function") or {}
                args[tc["index"]] = args.get(tc["index"], "") + (fn.get("arguments") or "")
    return [args[i] for i in sorted(args)]


async def main():
    serving, tok = build()
    bad = 0
    for label, value in VALUES.items():
        text = model_output(value)
        ns = await run(serving, tok, text, stream=False)
        st = await run(serving, tok, text, stream=True)
        print(f"\n{label}: {value!r}")
        print(f"  non-streaming: {ns}")
        print(f"  streaming:     {st}")
        try:
            ok = len(ns) == len(st) == 1 and json.loads(st[0]) == json.loads(ns[0])
            print(f"  streamed args valid JSON, equal to non-streaming: {ok}")
        except json.JSONDecodeError as e:
            ok = False
            print(f"  streamed args INVALID JSON: {e}")
        bad += not ok
    print(f"\nmismatches: {bad}/{len(VALUES)}")


asyncio.run(main())
```

## Details

**Root cause.** While a string value is still open, `HYV3ToolParser` streams a JSON prefix without the closing quote and escapes the partial value by hand, handling only `\\ " \n \r \t`. Any other control character is sent raw, which is invalid inside a JSON string. When the call closes, the rest is sliced from `json.dumps(final_args, ensure_ascii=False)` by the number of characters already streamed. `json.dumps` writes those characters as escapes (`\u001b`, `\f`), so the offsets no longer match and part of the value is sent twice.

**Fix.** `escaped_val = json.dumps(partial_value, ensure_ascii=False)[1:-1]`. JSON escaping works per character, so the escaped prefix is always a prefix of the escaped full value. `ensure_ascii=False` matches the final `json.dumps`. This is the same line `hy_v4_tool_parser.py` already uses.

**Not a duplicate.** I searched issues and PRs for `hy_v3`, `HYV3ToolParser`, `hy_v3 streaming`, `hy_v3 escape` and `tool parser control character`. Nothing covers this. #59620 edits the same file (truncated streams) but not the escaping.
