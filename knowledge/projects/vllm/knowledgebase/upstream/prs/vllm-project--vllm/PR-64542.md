# [Perf] Optimize Garbage Collection at Init Time

[Upstream PR](https://github.com/vllm-project/vllm/pull/64542) · state: open · merged: False

## Original PR description

## Overview
Better optimizes garbage collection for at init time to speed up manually `gc.collect()`s in the KV cache allocation.

## Claims
Currently, there are a lot of direct `gc.collect` calls when initializing vLLM, which add up over time. We can improve the startup time by temporarily freezing gc before loading the model, then unfreezing, collecting, and refreezing later on. This is useful for excluding things like imports references from the heap scans.

This currently gives a mostly flat speedup in initialization time of 3-4 seconds per model at the moment on both the cold and hot paths.

You can also validate this directly by adding timing hooks around garbage collection. 
```python
import gc
import os
import time

os.environ["VLLM_ENABLE_V1_MULTIPROCESSING"] = "0"

from vllm import LLM

MODEL = "Qwen/Qwen3-0.6B"

# Timing and counts per generation
gc_secs = [0.0, 0.0, 0.0]
gc_counts = [0, 0, 0]
t0 = 0.0


def on_gc(phase: str, info: dict[str, int]) -> None:
    """Start / stop callbacks for garbage collection to help measure time diffs."""
    global t0
    if phase == "start":
        t0 = time.perf_counter()
        return
    gen = info["generation"]
    gc_secs[gen] += time.perf_counter() - t0
    gc_counts[gen] += 1

if __name__ == "__main__":
    gc.callbacks.append(on_gc)
    start = time.perf_counter()
    LLM(MODEL)
    startup = time.perf_counter() - start
    gc.callbacks.remove(on_gc)
    print(
        f"startup {startup:.2f}s  GC {sum(gc_secs):.2f}s  "
        f"gen0/1/2 secs {gc_secs[0]:.2f}/{gc_secs[1]:.2f}/{gc_secs[2]:.2f}  "
        f"counts {gc_counts[0]}/{gc_counts[1]}/{gc_counts[2]}"
    )
```

`collect()` already covers all generations (i.e., is default `2`) and AFAIK should promote survivors to gen 2 already, so there shouldn't be a need to sequentially collect on all generations like this. Instead, we should be able to just collect everything once, then sweep again on gen 0 to pick up anything that was exposed as garbage as a result of the first collect prior to freezing, which is less redundant
