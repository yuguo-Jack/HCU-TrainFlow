## Purpose

On SM90+ (Hopper / L20X), load fused MoE expert weights `B` with `tl.make_tensor_descriptor` so Triton can emit real **TMA** for `(BN, BK)` tiles. `B` is `(E, N, K)` with K contiguous; each expert is described as `(N, K)`, expert selected by base pointer offset. Pre-SM90 keeps the original pointer `tl.load` path. With `SWAP_AB`, use the TMA tile as-is; otherwise `tl.trans` before `tl.dot`.
