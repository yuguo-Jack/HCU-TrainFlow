# [Bugfix] Show topology-compatible DCP values in configuration errors

[Upstream PR](https://github.com/vllm-project/vllm/pull/64943) · state: open · merged: False

## Original PR description

## Purpose

Addresses the diagnostics slice of #64938. With PCP disabled, an explicit DCP that does not divide TP currently fails with only the divisibility error. Include the topology-compatible DCP values and a reminder that model/backend constraints may further restrict them. For example, TP=4/DCP=3 now reports `[1, 2, 4]`.

The validation condition, accepted configurations and exception type remain unchanged. The divisor list is computed only on the existing error path. No automatic selection, fallback, default, PCP/GQA policy, rank grouping or serving logic changes. The broader auto/fallback requests in #64938 remain out of scope.

Updated the context-parallel deployment guide. Reused `tests/test_config.py`, which Engine Core CI selects for config changes.
