# [Doc] Add batch-invariance errata for v0.20.0-v0.22.0 compute capability note

[Upstream PR](https://github.com/vllm-project/vllm/pull/62360) · state: open · merged: False

## Original PR description

Fixes #48875.

Adds an errata note to the Hardware Requirements section of the batch-invariance docs: Ampere (SM 8.x) support landed in #38427 and shipped in v0.20.0, while the v0.20.0 through v0.22.0 documentation incorrectly stated "9.0 or higher" for NVIDIA GPUs.

Why this is not a duplicate: #48875 is open with no linked PR addressing it. I checked the issue's comment thread and searched open PRs referencing the issue before writing this.

Validation: docs-only change, no tests applicable. Verified the claim against the code (`vllm/model_executor/determinism/batch_invariant.py` enables the batch-invariant Triton matmul when `is_device_capability_family(80)`, which is true for all SM 8.x) and confirmed #38427 is merged (merge commit `16a65e417`).

AI assistance: this PR was prepared with AI assistance. The full diff was shared with the human submitter for review before opening.
