# [KV Offload] Async CPU cache initialization for SimpleCPUOffloadConnector

[Upstream PR](https://github.com/vllm-project/vllm/pull/54792) · state: open · merged: False

## Original PR description

## Purpose

Follow-up on #42632, revision of #44127. Stacked on #51414/#54578.

Only the last 2 commits are new; [clean diff vs #54578](https://github.com/mistralai/vllm/compare/offloading-async-init...YannikHinteregger:async-init-simple-cpu-offload). The helpers commit is also offered directly into #54578 as [mistralai/vllm#2](https://github.com/mistralai/vllm/pull/2).

This PR:

* extracts #54578's chunked `cudaHostRegister` into a shared helper (`vllm/utils/host_memory.py`), with cuts aligned so no block copy can straddle two pinned regions
* implements async CPU offload initialization for `SimpleCPUOffloadConnector`, the same way #54578 does it for `OffloadingConnector`: opt-in `"async_init": true` allocates and pins the CPU buffer in the background while the engine already serves GPU-only; offloading activates once all ranks are ready

Not a duplicate: #54578 leaves this connector as a follow-up ([suggested here](https://github.com/vllm-project/vllm/pull/51414#issuecomment-5479330316)).
