# [Model] Nemotron-H: skip layers and override MoE top-k via hf_overrides

[Upstream PR](https://github.com/vllm-project/vllm/pull/64556) · state: open · merged: False

## Original PR description

## Purpose

Add two optional Nemotron-H config keys, so one checkpoint can be served at cheaper settings without rewriting it:

- `skip_layers`: decoder layers to drop. They load no weights and get no KV/Mamba cache.
- `moe_top_k`: active experts per token in every MoE layer of the main model, including per-layer `block_configs` models. The MTP draft keeps its own top-k.

Both are set via `--hf-overrides`. Startup fails with a clear error when:
- speculative decoding reads the output of a skipped layer,
- `--enable-return-routed-experts` is used with either key,
- `moe_top_k` exceeds the grouped-routing limit.

```bash
vllm serve nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB ... \
  --hf-overrides '{"llm_config": {"skip_layers": [79,80,81,82,83,84,85], "moe_top_k": 4}}'
```
