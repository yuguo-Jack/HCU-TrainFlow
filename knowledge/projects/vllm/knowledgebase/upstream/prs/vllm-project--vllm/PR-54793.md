# [Bugfix] Ignore empty projected KV-cache groups in PP

[Upstream PR](https://github.com/vllm-project/vllm/pull/54793) · state: open · merged: False

## Original PR description

## Summary

Fixes #54711.

Pipeline-parallel workers can legitimately receive an empty projection of a
global KV-cache group. For uniform groups, the configuration builder previously
iterated the group's global per-layer spec map instead of the worker's projected
layer list. That created `KVCacheTensor`s for layers owned by other workers;
allocation then failed with an unhelpful `StopIteration`.

The builder now intersects uniform specs with `group.layer_names`, so empty
projections produce no tensors while retaining the existing group identity used
by pipeline-parallel bookkeeping.

No open or historical PR references #54711 or this specific empty-projection
fix (checked immediately before submission).
