# [Bugfix][Kernel] Plan b12x NVFP4 W4A16 linear token counts at load time

[Upstream PR](https://github.com/vllm-project/vllm/pull/64766) · state: open · merged: False

## Original PR description

## Overview

On SM12x, a b12x NVFP4 W4A16 linear prepares a heuristic plan the first time it sees a token count. That preparation evicts the b12x MoE kernels compiled earlier in the same forward. On `nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB` with its attention re-quantized to `W4A16_NVFP4`, CUDA graph capture then fails:

```
RuntimeError: W4A16 fused MoE launch is not resolved for CUDA graph capture (m=32, moe_block_size=8, max_m_blocks=246)
```

This PR builds each layer's plan at load time and passes it on every call, as `ModelOptBlockQuantLinearMethod` already does. #65208 builds on it.

## Claims

- **Capture crash fixed:** the re-quantized checkpoint serves instead of failing at CUDA graph capture.
- **No preparation after the first call:** each layer's plan is prepared on its first call (the profile run), before CUDA graph capture, and every later call reuses it. The new test fails on `main` and passes here.
- **No speed or accuracy change** on the unmodified checkpoint: 163.9 vs 164.2 tok/s per user at C=1 and 1140 vs 1135 tok/s total at C=16, and MMLU-Pro 58.2 vs 57.5 (280 questions, within noise).
- Weight reloads still reuse packed storage (#64692).

On nightly `335dd77b`, the unmodified checkpoint also segfaulted once on its first requests, right after a lazy `BlockscaledQuery (...) was not prepared before its first use`. With this PR it served all 2,100 MMLU-Pro questions.

Not run: TP > 1 and SM121.

## Details

- **Root cause:** `apply_weights` called `blockscaled.mm` without a plan. b12x then built a default plan for each new row-count bucket and prepared it on first use, and preparation evicts kernels it does not retain, including the MoE kernels warmed up for capture.
- Inputs above the planned capacity run in capacity-sized chunks, so no call prepares on its own.
- Follow-up: other b12x linears without a plan can hit the same eviction.
