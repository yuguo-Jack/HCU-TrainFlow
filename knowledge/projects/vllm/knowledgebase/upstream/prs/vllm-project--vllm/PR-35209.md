**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Restore negated SP guard before residual scatter checks**

This guard is inverted: when `enable_sp` is set, the function now returns `False` immediately, so PP runs with sequence parallelism treat residual tensors as non-scattered and set `all_gather_tensors["residual"] = True` in `gpu_worker.execute_model`. That enables the TP all-gather transfer optimization for residuals that are actually TP-sharded, causing the send/recv path to reshape and exchange partial slices instead of the intended tensor layout, which can corrupt residual activations between pipeline stages. The early return should stay negated (and include `enable_sp_moe` if that mode is intended here).
