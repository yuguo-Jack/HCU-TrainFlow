# [Mypy] Fix mypy typing for model interfaces and H/I models

[Upstream PR](https://github.com/vllm-project/vllm/pull/54079) · state: closed · merged: True

## Original PR description

## Purpose

Continue the incremental mypy rollout tracked by [#26533](https://github.com/vllm-project/vllm/issues/26533) by enabling mypy for the H/I model files.

These files were excluded because their annotations did not precisely describe multimodal input unions, model interface overloads, optional configuration, and weight-loading helpers. This change tightens those contracts, adds explicit narrowing where runtime validation already exists, and removes the H/I entries from the mypy exclusion list. Enabling mypy for H/I models exposed that packed_modules_mapping was typed as class-only even though some models create instance-specific mappings. This PR corrects the SupportsLoRA and SupportsQuant interfaces and adds the resulting annotations required in affected C/G/Q models. These changes remain atomic because separating them produces an intermediate state that fails mypy CI.

## Reproducer

On `main`, remove these two entries from `EXCLUDE` in
`tools/pre_commit/mypy.py`:

```python
r"vllm/model_executor/models/[hH]",
r"vllm/model_executor/models/[iI]",
```

Then run:

```bash
.venv/bin/pre-commit run mypy-3.13 --all-files --hook-stage manual
```
