# [ROCm][Model] DeepSeek-V4.1 VL: stream language-model weights on ROCm

[Upstream PR](https://github.com/vllm-project/vllm/pull/62421) · state: closed · merged: True

## Original PR description


- `amd/vl_model.py` loads through `stream_language_model_first` instead of `sorted()`.
- `test_deepseek_v4_vl_stream_weights.py` runs on ROCm and resolves the V4.1 wrapper through the platform dispatcher, so each platform tests the class it runs.
- The AMD Basic Models (Other) step in `test-amd.yaml` and its `models_basic.yaml` mirror run the test.

#58857 replaced the checkpoint sort with `stream_language_model_first` in the V4 and NVIDIA V4.1 VL wrappers, but the AMD V4.1 copy kept `sorted()`, which holds every tensor the loader yields before the first copy. #58782 reports host OOM from that sort and includes the same idea in a larger ROCm change. The AMD child loader is per-tensor and finalizes MegaMoE and mHC weights only after its group, so it needs the group contiguous, not totally ordered. On MI355 the test passes 10/10 with this change; with `main`'s `amd/vl_model.py` the `v41` case fails at the mid-stream assertion. A full DeepSeek-V4.1 load was not run here (475 GiB checkpoint).

This overlaps #62298, which currently skips the ROCm `v41` case of this test; that skip goes away once this lands.

AI assistance (Claude Code) was used to draft this change. Every line was reviewed by the submitter.
