# [Spec Decode] Keep the trailing prefix-cache block for hybrid models

[Upstream PR](https://github.com/vllm-project/vllm/pull/61911) · state: open · merged: False

## Original PR description

## Description

MTP drops the trailing prefix-cache block to protect a draft lookahead slot. On hybrid models using Mamba `align` caching, that can discard thousands of reusable prompt tokens.

This changes `disable_eagle_block_drop` to auto (`None`) and resolves it after hybrid configuration: keep the block for EAGLE/EAGLE3/MTP with hybrid align prefix caching and exactly one prefill lookahead token. Explicit settings still win; other configurations retain the drop.

### Results

The table below uses **synthetic prompts and controlled cache-reuse workloads**, compared against vLLM v0.31.0 on 8× B300, TP8, seed42, with three alternating baseline/PR boot pairs. **MTP K2 uses normal rejection sampling; acceptance is not synthetically fixed.** GLM uses FP8 KV; Qwen3-Next uses BF16 KV. Both arms use FlashInfer/CUB top-k, not the default auto backend.

**Synthetic controlled benchmark: C32, 1,024 output tokens**, with total input lengths shown below (including cached tokens). Percentages are median paired latency reductions; positive means faster. Extension measures requests extending a cached prefix, excluding producer time.

| Input tokens | GLM extension TTFT | GLM extension TPOT | GLM cold TTFT | Qwen extension TTFT |
|---|---:|---:|---:|---:|
| 8,192 | +64.65% | +22.34% | −29.25% | +22.49% |
| 32,768 | +44.46% | +20.86% | −22.49% | −15.23% |
| 131,072 | +35.23% | +21.68% | −2.57% | −0.05% |

GLM C32 extension TTFT improves in every pair at each length, with one extra 1,152-token cache block reused. Cold requests regress, and Qwen's gains depend on the workload.

Separate **GLM native AgentX trace replay**, 900 seconds per arm, three pairs at each session concurrency:

| Session C | Pair | Mean TTFT reduction | Mean ITL reduction | Output tok/s gain |
|---|---:|---:|---:|---:|
| 8 | 1 | +2.04% | +15.22% | +0.61% |
| 8 | 2 | +6.70% | +15.87% | +1.93% |
| 8 | 3 | +7.31% | +1.94% | −18.03% |
| 32 | 1 | −2.01% | −9.89% | −0.42% |
| 32 | 2 | +1.67% | +3.72% | +2.28% |
| 32 | 3 | +0.45% | +7.92% | +2.44% |

AgentX throughput is inconsistent. Fixed-duration replays complete different request subsets; the C8 pair3 drop is unexplained.

Known-answer retrieval checks passed across cold, warm, and divergent branches on every boot. Exact prose equality also varied in baseline controls, including target-only BF16, so these checks establish functional correctness rather than arbitrary-output equivalence.
