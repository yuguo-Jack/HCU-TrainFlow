# [CI] Stage ci-infra#825: shard Entrypoints Integration (API Server) automatically

[Upstream PR](https://github.com/vllm-project/vllm/pull/62523) · state: open · merged: False

## Original PR description

## Overview

Draft, not for merge. A staging PR for vllm-project/ci-infra#825, so a scoped build can run its generator on a real GPU job.

`entrypoints-integration-api-server` runs `PYTHONPATH=/vllm-workspace pytest ... entrypoints/serve/dev/rpc`. That `PYTHONPATH` replaces the one the shard setup exports, so pytest couldn't import the shard plugin. ci-infra#825 also copies the plugin into `python3`'s site-packages.

## Claims

- The step moves from 4 fixed pytest-shard jobs to `automatic_shard` (5 planned shards). The rpc command loses its `if` guard; the plugin runs it only in the shard holding its tests.
- The AMD mirror isn't enrolled here and isn't in the scoped build.

## Validation

- Planned with ci-infra#825's generator against main's timings, and ran every shard's commands against a mock test tree: each test runs exactly once.
- Scoped build with `VLLM_CI_BRANCH` set to ci-infra#825's branch, also covering three already-enrolled steps (`entrypoints-unit-tests`, `engine-1-gpu`, `amd-entrypoints-unit-tests`) as regression checks of the new setup line.

## Details

Will be closed after the build; the real enrollment follows once ci-infra#825 merges.
