## Original PR description

Fixes #60205.
Refreshes P2P/NIXL data-plane state when a peer reconnects after a control-plane timeout. Stale remote registrations and sessions are replaced so subsequent KV transfers use the peer’s current NIXL metadata.
Adds focused reconnect coverage for the transport, session, and manager paths.
