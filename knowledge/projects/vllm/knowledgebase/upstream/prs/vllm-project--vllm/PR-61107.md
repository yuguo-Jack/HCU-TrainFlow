# [Fusion] Fuse Qwen MoE shared MLP activation quantization

[Upstream PR](https://github.com/vllm-project/vllm/pull/61107) · state: open · merged: False

## Original PR description

Related to #43501. Follow-up to [@mgoin's request](https://github.com/vllm-project/vllm/issues/43501#issuecomment-5716717828) to roll out manual fusion in model batches.

Route Qwen2MoeMLP through the existing manual activation/quantization fusion. This covers Qwen1.5-MoE, Qwen2-MoE and the reused Qwen3Next MLP, including shared experts. The shared-expert gate still uses the original input.

Native FP8 engagement needs #57514's consumer-key exposure. No kernel or consumer changes are included here.

## Tests

1× H100 80GB, TP1, with nightly binaries:

- Shared-expert FP8 regression: passes with the change, fails without it.
- Qwen2-57B-A14B FP8 with #57514: fusion runs in all 28 shared MLPs. With #59514 too, sampled GSM8K scored 204/256 → 207/256; compiled throughput rose 0.9–1.8% (three runs). Without #59514, throughput was unchanged.
