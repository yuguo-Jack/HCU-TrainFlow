# [MoE Refactor] Add MoEKernelOracle ABC base class and migrate Unquantized oracle

[Upstream PR](https://github.com/vllm-project/vllm/pull/44231) · state: closed · merged: False

## Original PR description

## Summary

Part 1/N of #37753 — Unify MoE Oracles with Class Structure.

Introduces `MoEKernelOracle(ABC, Generic[BackendT])` as the abstract base class for all MoE kernel selection oracles, and migrates the unquantized oracle as the reference implementation.

## Current State

9 oracle modules (`unquantized.py`, `fp8.py`, `nvfp4.py`, `mxfp4.py`, `mxfp8.py`, `int8.py`, `w4a8.py`, `w4a8_int8.py`, `int_wna16.py`) each implement the same 4-operation pattern with copy-pasted helpers (`_make_log_backend`, `_make_log_unsupported`, `_return_or_raise`). No shared interface exists — each module is an island of convention.

## What This PR Does

### 1. Adds `MoEKernelOracle` ABC (`oracle/base.py`)

```python
class MoEKernelOracle(ABC, Generic[BackendT]):
    @abstractmethod
    def select_backend(self, moe_config) -> tuple[BackendT, ...]: ...
    @abstractmethod
    def convert_to_kernel_format(self, backend, layer, w13, w2) -> ...: ...
    @abstractmethod
    def make_quant_config(self, moe_config, backend) -> FusedMoEQuantConfig: ...
    @abstractmethod
    def make_kernel(self, quant_config, moe_config, backend, experts_cls, ...) -> FusedMoEKernel: ...

    # Shared helpers (previously copy-pasted across 9 files)
    @classmethod
    def _make_log_backend(cls, backend, available_backends=None) -> str: ...
    @classmethod
    def _make_log_unsupported(cls, backend, reason) -> str: ...
```

### 2. Migrates `UnquantizedOracle` (`oracle/unquantized.py`)

`UnquantizedOracle(MoEKernelOracle[UnquantizedMoeBackend])` implements all 4 abstract methods. The existing module-level wrapper functions (`select_unquantized_moe_backend`, `convert_to_unquantized_kernel_format`, `make_unquantized_moe_kernel`, `backend_to_kernel_cls`, `map_unquantized_backend`, `_get_priority_backends`) are **preserved unchanged** — they now delegate to the class methods.

### 3. Exports from `oracle/__init__.py`

```python
from vllm.model_executor.layers.fused_moe.oracle.base import MoEKernelOracle
from vllm.model_executor.layers.fused_moe.oracle.unquantized import UnquantizedOracle
```

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| ABC with `Generic[BackendT]` | Each oracle has its own backend enum; generics give type-safe method signatures |
| Keep module-level wrappers | Zero changes required from callers like `unquantized_fused_moe_method.py` |
| `_make_log_backend` takes optional `available_backends` | Some oracles log the candidate list (fp8, unquantized); others don't (int_wna16) |
| `backend_to_kernel_cls` and `map_backend` remain `@staticmethod` | These are pure lookup functions — no instance state needed |
| Migrate unquantized first | It's the simplest oracle (no quantization params) and was already cleaned up in #36286 |
