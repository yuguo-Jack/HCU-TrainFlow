# [WIP] Switch vLLM to The Rock when on AMD hardware

[Upstream PR](https://github.com/vllm-project/vllm/pull/49470) · state: closed · merged: False

## Original PR description




## Purpose
This PR switches vLLM to use The Rock on AMD hardware.  Three main things:
1) Update Dockerfile.rocm_base to use wheels when possible and install The Rock
    * Pytorch to be installed from wheel if exists, else build from source
    * Same as above for any other lib there is a wheel for
    * Switch to Python 3.14.6: Needed for next version of Quark for example, and possibly other dependencies
2) Update Dockerfile.rocm 
    * Update to handle issues encountered when switching to The Rock
    * Preserve the version of Triton here, since it seems work better
3) Requirements
    * Need 3.14 compatible dependencies
    * Anything currently "removed" or "unpinned" needs to be revisited, so we can get the most compatible versions
  
This is a work in progress.  

1) Must first build and verify base docker.  
2) Must begin testing in CI with resulting vLLM docker
     * Much has been done already with the UFB docker files, but in order to switch over to The Rock, this seems necessary
     
     
## Test Plan
Run Full CI passes to verify.  Goal is that there will be no difference.
## Test Result
Hope to not introduce any problems.
