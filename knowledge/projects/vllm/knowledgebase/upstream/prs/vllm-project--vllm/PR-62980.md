# [Bugfix] Support online quantization of Kimi K3 NVIDIA projections

[Upstream PR](https://github.com/vllm-project/vllm/pull/62980) · state: closed · merged: True

## Original PR description

## Purpose

Fix online quantization of the Kimi K3 NVIDIA projections, e.g.

```
--quantization-config '{"targets":{"*.in_proj_qkvgfab":"mxfp8","*.fused_qkv_a_g_proj":"mxfp8","*.routed_expert_down_proj":"mxfp8","*.routed_expert_up_proj":"mxfp8"}}'
```

Three places in the model broke:

- **KDA input projection padding.** `in_proj_qkvgfab` pads each TP-local row block for alignment. No checkpoint shard covers that padding, but online processing counted it toward the layer's expected load size, so the layer never reached completion and every KDA layer was deferred to `finalize_layerwise_processing`, keeping all its buffered checkpoint tensors alive until the end of loading. The projection now declares `weight_loader_numel` without the padding. Online processing also rebuilds the weight from uninitialized storage, so the padding is re-zeroed after each shard load (both `weight_loader` and `weight_loader_v2`).
- **Routed output transform.** `KimiRoutedOutputTransform` fused the residual add as `residual.addmm_(x, up_proj.weight.t())`, bypassing the quantized linear method and its scales. The fused add is now used only for an unquantized up-projection; otherwise the layer is called and the residual added in place.
- **Latent MoE tail kernels.** They multiply by the raw `up_proj.weight`, so `LatentMoERunner` now enables the fused tail path (and deferred MoE finalize) only for an unquantized up-projection.

## Test Plan

```
pytest tests/model_executor/model_loader/test_reload.py -k nvidia_kda_online_loading
pytest tests/models/kimi_k3/test_latent_moe_tail.py -k deferred_finalize
```

The new KDA test (adapted from the reproducer in #61950) loads the merged projection through online processing for 96 heads (padded) and 128 heads (no padding), TP ranks 0 and 3, and both weight loaders (in forward and reverse shard order). It checks that the layer finishes loading, every source tensor is released, the loaded rows match the checkpoint, and the padding is zero (uninitialized storage is filled with NaN to catch it).

End to end: Kimi K3 MXFP4 on GB300, 2P1D (TP8 prefill x 2, DEP16 decode, 32 GPUs), DSpark K4, AgentX agentic traces at concurrency 240 for 3600 s, with and without online MXFP8 quantization of the KDA/MLA input projections, routed expert projections, and (decode only) `o_proj` and the shared experts.
