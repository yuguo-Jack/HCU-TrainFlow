## Original PR description

## Purpose

At the moment, activation override is not possible to target:

https://github.com/vllm-project/vllm/blob/02a3c6dfc56c8776179a2e1c4fe01df270188f71/vllm/model_executor/layers/fused_moe/oracle/mxfp4.py#L321-L322

This PR adds support for `--quantization-config.moe.activation null` to explicitely mean user-requested UNQUANTIZED activations, in the same way as https://github.com/vllm-project/vllm/pull/51808.
