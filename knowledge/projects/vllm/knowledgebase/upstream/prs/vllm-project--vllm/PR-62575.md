# [CI/Build] Drop CUDA 12.9 from the release pipeline

[Upstream PR](https://github.com/vllm-project/vllm/pull/62575) · state: closed · merged: True

## Original PR description



## Overview

Drop CUDA 12.9 from the release pipeline (`.buildkite/release-pipeline.yaml`). CUDA 13.0 is already the default variant, so this stops building and publishing the extra `cu129` wheels and Docker images.

## Claims

- Removes 9 release-pipeline steps:
  - `Build wheel - {x86_64,aarch64} - CUDA 12.9`
  - `Build release image - {x86_64,aarch64} - CUDA 12.9`, and the Ubuntu 24.04 versions of both
  - `Create multi-arch manifest - CUDA 12.9`, and its Ubuntu 24.04 version
  - `Publish nightly multi-arch image to DockerHub - CUDA 12.9`
- Removes the `cuda-12-9` and `cuda-12-9-ubuntu-24-04` targets from `publish-release-images.sh` and from the DockerHub publish matrix.
- Removes the unused `CUDA_ARCH_{X86,AARCH64}_CU129` env vars.
- Nothing is added. The CUDA 13.0, Rubin CUDA 13.4, ROCm, XPU and CPU steps are unchanged.

## Validation

- Compared the step labels in the YAML before and after the change: exactly the 9 CUDA 12.9 steps are gone, no steps were added, and no `depends_on` points at a missing key/id.
- The DockerHub publish matrix is now `cuda-13-0, cuda-13-0-ubuntu-24-04, rocm, rocm72, xpu, cpu`.
- `bash -n` and shellcheck pass on `publish-release-images.sh`, and `pre-commit run` passes on the changed files.
- No release build has been run yet. A release or nightly build of this branch should show no CUDA 12.9 jobs.

## Details

- After the next release, the `vllm/vllm-openai:*-cu129*` DockerHub tags and the `cu129` wheel variant (both nightly and release) will stop getting updates.
- **Follow-up needed:** `setup.py` (`detect_system_cuda_variant`) still maps CUDA 12 torch to the `cu129` precompiled-wheel variant. For CUDA 12 users, `VLLM_USE_PRECOMPILED=1` will no longer find wheels for new commits. That fix and the install-doc updates (`gpu.cuda.inc.md` still says the default is 12.9) are left out to keep this PR to the pipeline.
- Duplicate check: no open PR removes CUDA 12.9 from the release pipeline. #55387 changes the default CUDA from 13.0 to 13.2 and does not touch cu129.
