# [Bugfix][HiSparse] Order shared host writes with a step counter

[Upstream PR](https://github.com/vllm-project/vllm/pull/61234) · state: open · merged: False

## Original PR description



## Overview

Alternative to #60941 for the same HiSparse TP hang. Instead of adding a CPU barrier on steps with no scheduled tokens, TP rank 0 publishes each step's host writes as a step index in the shared host pool, and the other ranks wait for that exact index.

## Claims

- Fixes the TP group hang that occurs when a rank's host falls a step behind rank 0 on steps without scheduled tokens (#60941).
- No CPU barrier is added on any step.

## Validation

H100 (ibm-h100-1). Both harnesses (collapsed below) drive the real `HiSparseConnectorWorker.start_step`/`finish_forward`, using the real vLLM TP group. Only the transfer, restore and host-mirror paths are stubbed; they are empty in these runs. Each step with tokens runs matmuls plus an all-reduce, and the given rank's host sleeps before `start_step`.

## Details

**Root cause.** With a shared host pool, rank 0 records two alternating IPC events, and every rank's stream waits on the one from the previous step. A stream wait binds to the event's latest record when the wait is issued. On a step with no forward, rank 0 can re-record an event before a lagging rank has issued its wait on it. That rank then binds to a record queued behind a forward that needs that same rank, and the group deadlocks.

**Fix.** The counter lives in one extra page at the end of the shared pool (`allocate_hisparse_host_pools`), pinned like the rest of the pool. In `start_step`, rank 0's stream waits on its own previous host writes, then `cuStreamWriteValue64` writes the step index. The other ranks' streams `cuStreamWaitValue64(>= step)`. A lagging rank waits for exactly the step it needs, which never depends on that rank, so no ordering on the host is required on any step. Rank 0 keeps local (non-IPC) events for its own ordering and for the host sync in `_copy_host_blocks`.

- The step index comes from `start_step` calls, which the alternating events already assumed are identical across TP ranks.
- The driver calls go through `cuda.bindings`, as `simple_kv_offload/cuda_mem_ops.py` already does. HiSparse is CUDA-only.
- Peers now also wait for rank 0's draft-layer mirror and post-forward transfer DMAs submitted at the start of the step. Rank 0's own forward already waits on these, so this adds no latency to the group.

**vs #60941.** #60941 is a 4-line fix that adds a TP CPU barrier on every step without scheduled tokens. On steps with tokens, it relies on rank 0's staging host sync in `_finish_mirror_phase` to order the record. This PR removes the race itself, so steps with tokens no longer depend on that sync. In exchange it uses driver stream memory operations and one extra pool page.

```python
"""Drive the real HiSparseConnectorWorker.start_step/finish_forward under TP,
with the shared pool from allocate_hisparse_host_pools and its step counter.

Also checks ordering: rank 0's stream writes the step index into the shared
pool behind slow GPU work each step; after start_step every other rank reads
it on its stream and counts reads older than the previous step.

Real IPC host-write events (_create_hisparse_host_events), real vLLM TP group
(barrier/broadcast), real slot-mapping staging sync on rank 0. Only the
transfer/restore/host-mirror paths are stubbed (they are empty here anyway).

torchrun --nproc-per-node N real_worker_hang.py MODE
  MODE  zero_next | zero_now | tokens   (rank 1 held 0.5 s before step 5)
        stress:SEED                     (random zero-token steps and delays)
"""
import os
import random
import subprocess
import sys
import threading
import time
from types import SimpleNamespace
from unittest.mock import MagicMock

import torch
import torch.distributed as dist

from vllm.config import VllmConfig, set_current_vllm_config
from vllm.distributed import get_tp_group
from vllm.distributed.parallel_state import (
    init_distributed_environment,
    initialize_model_parallel,
)
from vllm.distributed.kv_transfer.kv_connector.v1.hisparse import worker as wm
from vllm.distributed.kv_transfer.kv_connector.v1.hisparse.connector import (
    HiSparseConnectorMetadata,
)

mode = sys.argv[1]
rank = int(os.environ["RANK"])
world = int(os.environ["WORLD_SIZE"])
torch.cuda.set_device(rank)
device = torch.device("cuda", rank)

with set_current_vllm_config(VllmConfig()):
    init_distributed_environment(world, rank, "env://", rank, "nccl")
    initialize_model_parallel(tensor_model_parallel_size=world)

import mmap
from vllm.v1.hisparse.runtime import (
    allocate_hisparse_host_pools,
    hisparse_host_write_counter,
)

page = mmap.PAGESIZE
cfg = SimpleNamespace(
    instance_id=f"semtest{os.environ['MASTER_PORT']}",
    parallel_config=SimpleNamespace(data_parallel_index=0),
)
(pool,), _, region = allocate_hisparse_host_pools(
    cfg, [4 * page], 4, page, use_shared_host_pool=True
)
is_writer = wm._is_hisparse_host_writer(region)
assert is_writer == (rank == 0)

MAX = 4096
w = object.__new__(wm.HiSparseConnectorWorker)
w.shared_host_region = region
w.is_host_writer = is_writer
w.host_write_events = (torch.Event(), torch.Event())
w.host_write_event = w.host_write_events[1]
w._next_host_write_event = 0
w._host_write_counter = wm._HostWriteCounter(hisparse_host_write_counter(region))
w._host_write_step = 0
handle = SimpleNamespace(
    slot_mapping=torch.full((MAX,), -1, dtype=torch.int64, device=device),
    runtime=SimpleNamespace(resident_source_index=0),
    all_context_pages_resident=True,
)
w.cache_handles = [handle]
w._slot_mapping_staging = (
    wm._SlotMappingStaging(
        stream=torch.cuda.Stream(device=device),
        event=torch.cuda.Event(),
        slots=torch.empty(MAX, dtype=torch.int64, pin_memory=True),
    )
    if is_writer
    else None
)
w._draft_mirror_pending = False
w._post_forward_transfers = []
w._pending_dma_descriptors = __import__("collections").deque()
w._dma_free_descriptors = []
w._dma_submitted = False
w._per_layer_mirrored = set()
w._submitted_mirror_layers = set()
w._forward_ready_event = torch.cuda.Event()
w._pending_invalid_block_ids = []
w._completed_host_copy_dst_ids = []
for name in ("_restore_pages", "_submit_transfers", "_enqueue_host_mirror"):
    setattr(w, name, MagicMock())
torch.cuda.synchronize()
dist.barrier()

if mode.startswith("stress"):
    seed = int(mode.split(":")[1])
    rng = random.Random(seed)
    steps = 300
    plan = [rng.random() < 0.35 for _ in range(steps)]  # True = zero tokens
    delays = [
        (rng.randrange(world), rng.uniform(0.0, 0.08)) if rng.random() < 0.25 else None
        for _ in range(steps)
    ]
else:
    steps = 10
    zero = {"zero_next": 6, "zero_now": 5, "tokens": None}[mode]
    plan = [s == zero for s in range(steps)]
    delays = [(1, 0.5) if s == 5 else None for s in range(steps)]

step = -1
done = threading.Event()


def watchdog():
    if not done.wait(30):
        util = subprocess.run(
            ["nvidia-smi", "--query-gpu=index,utilization.gpu", "--format=csv,noheader"],
            capture_output=True, text=True,
        ).stdout
        print(f"rank{rank} HANG at step {step}, util: "
              + util.strip().replace("\n", " | "), flush=True)
        os._exit(2)


threading.Thread(target=watchdog, daemon=True).start()
a = torch.randn(4096, 4096, device=device, dtype=torch.bfloat16)
published = pool[:8].view(torch.int64)
stale = torch.zeros((), dtype=torch.int64, device=device)
step_value = torch.zeros(1, dtype=torch.int64, device=device)
meta = HiSparseConnectorMetadata(None, (), (), {}, True, {})
for step in range(steps):
    zero_tokens = plan[step]
    if delays[step] and delays[step][0] == rank:
        time.sleep(delays[step][1])  # slow host work before start_step
    n = 0 if zero_tokens else 16
    w.start_step(meta, None, [], num_tokens=n)
    if rank != 0 and step > 0:
        stale += (published.to(device, non_blocking=True)[0] < step - 1).long()
    if not zero_tokens:
        y = a
        for _ in range(8):
            y = y @ a
            dist.all_reduce(y, group=get_tp_group().device_group)
            y = y / 4096
    if rank == 0:
        y = a
        for _ in range(4):
            y = y @ a
        step_value.fill_(step).add_((y[0, 0] * 0).long())
        published.copy_(step_value, non_blocking=True)
    w.finish_forward()
torch.cuda.synchronize()
assert stale.item() == 0, f"rank{rank} read {stale.item()} stale host writes"
done.set()
print(f"rank{rank} PASS zero_steps={sum(plan)} stale=0", flush=True)
os._exit(0)
```
