# feat(moriio): park requests instead of busy-waiting on handshakes (Gap 6)

[Upstream PR](https://github.com/vllm-project/vllm/pull/63855) · state: open · merged: False

## Original PR description

## Summary

- Replace `sleep(0.001)` busy-wait loops in `save_kv_layer` and `start_load_kv` with a park-and-return pattern
- Requests whose handshake is still in progress are deferred to `_parked_write_reqs` / `_parked_read_reqs` and processed on the next call
- Parked requests that exceed `transfer_timeout` are dropped with a warning
- One slow or dead peer no longer stalls the entire batch

Related: ROCm/mori#759

- [ ] Existing `test_moriio_connector.py` still passes
