# [Bugfix] Honor per-layer INC datatype and packing overrides

[Upstream PR](https://github.com/vllm-project/vllm/pull/63991) · state: open · merged: False

## Original PR description

## Summary

Fixes #63990.

The INC parser uses global datatype/packing/backend values for per-layer overrides, selecting the wrong scheme for FP8_BLOCK layers in an INT4 checkpoint. Resolve these fields per layer and include them in fused-projection consistency checks. The `get_layer_config()` tuple API is unchanged.

Companion exporter fix: https://github.com/intel/auto-round/pull/2543.

## Tests

- 15 parser tests passed; Ruff lint/format passed.
- Qwen3-0.6B: mixed loading, scheme assertions, and generation passed.
- Qwen3-8B: full MMLU/HellaSwag/GSM8K runs completed, with scheme assertions.

Local runs used B200 and vLLM 0.29.0 binaries with the patched parser, not a latest-main build. Targeted parser tests were rerun after rebase without the global conftest (missing `tblib`).
