## Purpose

Declare the TP gathered full LM head as a derived buffer and recompute it after source weights are stable. Return the owned stable tensor to logits consumers, and avoid clearing its allocation on load. Register suppression indices as a static non-persistent buffer rather than a weight-derived cache. Adds repeated refresh coverage that checks object identity, addresses, and values.
