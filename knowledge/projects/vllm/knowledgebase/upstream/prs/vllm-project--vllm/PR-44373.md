# fix(tracing): dual-emit legacy and current OTel GenAI token attributes

[Upstream PR](https://github.com/vllm-project/vllm/pull/44373) · state: open · merged: False

## Original PR description

Purpose
Fix #44358. vLLM's tracing emits two span attributes that are deprecated in the OTel GenAI semantic conventions:

gen_ai.usage.prompt_tokens → renamed to gen_ai.usage.input_tokens
gen_ai.usage.completion_tokens → renamed to gen_ai.usage.output_tokens
This PR dual-emits both the legacy names and the current spec names so existing dashboards and collectors keep working during the migration window. The legacy names can be dropped in a future PR once adoption of the new names is widespread.

No existing PR addresses this — confirmed via gh pr list --repo vllm-project/vllm --state open --search "44358 in:body"
