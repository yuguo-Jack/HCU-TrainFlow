# [ROCm][Perf] Fuse MXFP8 activation quant into the 1x32 dot_scaled linear for M≤16

[Upstream PR](https://github.com/vllm-project/vllm/pull/63969) · state: closed · merged: False

## Original PR description

This PR fuses MXFP8 activation quantization into the ROCm `dot_scaled` GEMM kernel for M≤16 on gfx950 (MI355X).

**Key changes:**
- Eliminates separate `mxfp8_e4m3_quantize` kernel launch by quantizing bf16 activations in-register during GEMM
- Uses `QUANT_ROWS = min(16, next_pow2(M))` rows per K-tile, repeated to fill 16-row MFMA tile
- K loop uses constexpr BLOCK_K for loop unrolling/pipelining
- Fused for K≤1024 (M≤16) and K=2048 (M≤4); larger shapes use existing path

**Performance (MI355X):**
- 1.14x–1.64x speedup for K≤1024 at M=1–16
- 1.03x–1.27x for K=2048 at M=1–4

**Constraints:**
- bf16 only (fp16 triggers FP16 overflow clamp)
- Disabled under `VLLM_BATCH_INVARIANT`
- Bitwise identical output validated via new test `test_rocm_mxfp8_fused_act_quant_bitwise_eq_unfused`

The optimization targets small-batch decode where separate quant launch overhead dominates.

Closes #63915
