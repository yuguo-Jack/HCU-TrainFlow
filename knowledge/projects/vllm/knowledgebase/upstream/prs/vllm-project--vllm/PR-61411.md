# [CPU][Zen] Update zentorch to 2.14.0.1 & enable float16 on Venice and later

[Upstream PR](https://github.com/vllm-project/vllm/pull/61411) · state: closed · merged: True

## Original PR description

- AMD ships AVX512-FP16 from 6th Gen EPYC (Venice) onwards, so make the dtype list reflect what the part can actually do instead of assuming no Zen CPU can.

- `float16` is accepted on Zen CPUs that report AVX512-FP16, and still rejected (auto-downcast to `bfloat16`) on Turin and earlier. No behavior change on any currently-shipping part.

- Bumps the zentorch pin from `2.13.0.1` to `2.14.0.1` in `setup.py` and the matching Buildkite `ZENTORCH_VERSION`. [2.14.0.1](https://pypi.org/project/zentorch/2.14.0.1/) is the release whose notes read *"functional support for running LLMs using float16 precision with vLLM on 6th Gen AMD EPYC™ processors"*.
