# [ROCm] Monitor FlyDSL JIT compilation after warmup

[Upstream PR](https://github.com/vllm-project/vllm/pull/62481) · state: open · merged: False

## Original PR description

## Purpose

Add FlyDSL hook so compilations at runtime warns or fail like the other backends (cutedsl, triton, ...).

E.g. https://github.com/vllm-project/vllm/pull/60645 enabled flydsl GDN by default, but there's no way to see when the flydsl compilation takes place. 

With specialized decode kernels written in flydsl becoming more common, this can help us avoid runtime compilation latency spikes.
