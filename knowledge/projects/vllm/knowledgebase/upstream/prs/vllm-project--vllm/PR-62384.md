## Original PR description

## Overview

Extend #62183 to support DeepSeek-V4.1-Flash decoder-side SWA bounded replay with PCP and APC, including prefix-hit continuation.

## Claims

- Retain each request's global trailing window on its original PCP owners while preserving cached compressed KV and indexer keys.
- Keep prompt-logprobs rows and existing non-PCP behavior; padded peers participate in the same collectives and only real outputs are scattered back.

## Details

Reuse the existing replay batch, gather kernel and attention builders. Each PCP rank-local `InputBatch` carries compact PCP metadata: the unpadded global token count, per-segment global query and sequence-length bounds, and the PCP+DCP gather bound. Decoder replay derives local trailing rows and the same global kept-token padding bound on every rank without carrying the global batch or adding a PCP collective. Replay-start upload is deferred until PCP/DP agreement confirms replay is needed. Select local slots before compaction, gather them in rank-major order, and align MoE routing IDs with the compact rows. Batches that would not shrink after padding keep full execution.

Unlike #61554's APC-disabled cold-prefill path, this builds on #62183 for APC prefix hits and derives replay bounds from existing global PCP metadata. It retains the existing PCP restrictions and eager execution requirement, with no scheduler or configuration changes. The branch is rebased on #62183 now in main. AI assistance was used for implementation and static checks.
