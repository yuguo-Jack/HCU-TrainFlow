# [XPU][CI] Fix test_tp1_fp8_fusions rms_quant_fusion on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/63975) · state: closed · merged: True

## Original PR description

Root cause: On XPU, compressed-tensors FP8 W8A8 checkpoints default to the weight-only W8A16 path unless kernel_config.linear_backend is set, so no activation quant op is emitted and RMSNorm+quant fusion finds 0 matches. 

Reproduce cmd:
pytest -v -s tests/compile/fusions_e2e/test_tp1_quant.py -k 'inductor_partition and (FLASHINFER and not +rms_norm and (not +quant_fp8 or +quant_fp8 and (qwen3 or deepseek)) or llama-3)'
pytest -v -s tests/compile/fusions_e2e/test_tp1_quant.py -k 'llama-3'
pytest -v -s tests/compile/fusions_e2e/test_tp1_quant.py -k 'inductor_partition and not +rms_norm and not +quant_fp8'
