- qli88 · comment · 2026-06-11T15:11:15Z · [source](https://github.com/vllm-project/vllm/pull/44623#discussion_r3397042615)

File: `tests/kernels/core/test_activation.py` · line 128

1. The GPU initialization and cleanup logic for this test group includes hard-coded snippets (e.g., in https://github.com/vllm-project/vllm/blob/main/tests/conftest.py#L295), which can lead to unexpected cleanup issues when running on cuda:1.

2. This test does not involve any cross-GPU operations. If it runs successfully on one GPU, it should behave the same on others. Therefore, running it on two different GPUs in separate rounds is unnecessary.

For the same reason, I did not update conftest.py to remove the hard-coded snippets—the test is inherently designed to run on a single GPU at a time.
