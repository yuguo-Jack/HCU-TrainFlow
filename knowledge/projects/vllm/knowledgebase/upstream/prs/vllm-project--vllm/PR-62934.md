# [ROCm][CI] Move NFS-affected MI300 test groups to MI355

[Upstream PR](https://github.com/vllm-project/vllm/pull/62934) · state: closed · merged: True

## Original PR description

## Rationale

The analysis covered 1,524 amd-ci builds since Sep 25 and 14,541 job logs from Oct 10-20. 

For each group and checkpoint-size bucket, the median model-loading time defines the normal load baseline. A run is affected when a same-size load takes more than 2x baseline and adds more than 120 seconds. Normal runtime is the median of successful jobs without an affected load, while affected runtime is the median job runtime among affected runs. Groups were ranked by the total runtime above normal accumulated by affected runs, divided by all observed runs, with at least 15 runs required to avoid low-sample outliers.

AI-assisted tooling was used to analyze the historical CI job metadata and logs; the results and proposed changes were manually reviewed.
