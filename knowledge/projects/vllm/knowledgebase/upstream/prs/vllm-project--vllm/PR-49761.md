# Add Gemma4 B200 FP8 optimized path

[Upstream PR](https://github.com/vllm-project/vllm/pull/49761) · state: open · merged: False

## Original PR description

**Summary**

Adds a Gemma4-specific optimized FP8 path for B200/SM100.

This includes:

- gated-MLP FP8 CUTLASS epilogue with GELU pair activation
- fused row-amax path for the activated gated output before the down projection
- SM100 CUTLASS dispatch tuning for Gemma4 FP8 shapes
- Python routing from `Gemma4MLP` into the optimized custom ops

**Performance**

In matched internal testing on Gemma4 31B FP8 / B200, this optimized path showed approximately **9% end-to-end latency speedup** versus the baseline runtime for the same serving configuration.

Detailed benchmark artifacts can be shared separately with reviewers.

**Validation**

Validated out of tree on a B200 node using a patched `vllm/vllm-openai:latest` runtime image.

Configuration:

- model: `RedHatAI/gemma-4-31B-it-FP8-Dynamic`
- hardware: B200 / SM100
- attention backend: FlashInfer
- attention config: TRT-LLM attention enabled
- KV cache dtype: FP8
- speculative decoding: Gemma assistant draft model with 3 draft tokens
- request count: 100 direct OpenAI-compatible chat completion requests

Validation completed:

- rebuilt vLLM's native CUDA/CUTLASS extension from this branch so the new custom ops were present at runtime
- patched the rebuilt extension and Python routing changes into a runtime image
- verified the new custom ops were registered:
  - `cutlass_scaled_mm_gemma4_gated`
  - `cutlass_scaled_mm_gemma4_gated_amax`
- started `vllm serve` successfully
- completed 100/100 chat completion requests successfully

**Accuracy Validation**

MMLU was run as a 0-shot loglikelihood multiple-choice eval using `lm-eval` through the OpenAI-compatible completions endpoint.

| Run | Serving config | Accuracy |
|---|---|---:|
| Stock FP8 vLLM baseline | RedHatAI FP8 weights, FP8 KV cache, assistant spec3 | 46.2897% |
| Optimized FP8 path | RedHatAI FP8 weights, FP8 KV cache, assistant spec3 | 46.2826% |

The optimized FP8 path differs from the stock FP8 baseline by -0.0071 percentage points, approximately 1 question out of 14,042.

GSM8K validation:

| Run | Strict exact match | Flexible extraction |
|---|---:|---:|
| Optimized run | 97.2707% | 97.1948% |
