# [ROCm] Skip RTLD_GLOBAL libtorch_cpu.so promotion when HSA_TOOLS_LIB is set

[Upstream PR](https://github.com/vllm-project/vllm/pull/64752) · state: open · merged: False

## Original PR description

  ## Overview
  Skip the RTLD_GLOBAL promotion of libtorch_cpu.so when HSA_TOOLS_LIB is
  set, indicating an external HSA profiling tool (e.g. rocm-trace-lite) is
  active.  The RTLD_GLOBAL promotion and external HSA tools are mutually
  exclusive — only one can be active at a time.  When HSA_TOOLS_LIB is not
  set, behavior is unchanged.

  ## Root cause
  PR #56190 added `_maybe_promote_torch_symbols_for_rocm()` which loads
  libtorch_cpu.so with RTLD_GLOBAL before `import torch` to enable
  torch.profiler GPU tracing on ROCm.  This unconditionally pulls
  libhsa-runtime64 into the global symbol scope, which breaks external
  HSA profiling tools that were previously working.  The
  rocprofiler_configure symbol exported by libtorch_cpu.so and the
  HSA_TOOLS_LIB OnLoad callback both try to register with
  libhsa-runtime64 for queue interception; when libtorch_cpu.so is loaded
  RTLD_GLOBAL first, it shadows the external tool's registration and
  prevents its OnLoad callback from firing — resulting in zero GPU kernel
  records captured.

  ## Changes
  - Added an early return in `_maybe_promote_torch_symbols_for_rocm()`
    when `HSA_TOOLS_LIB` is set, skipping the RTLD_GLOBAL promotion so
    the external tool's intercept path works correctly.
  - Added docstring explaining the mutual exclusivity and why the skip is
    necessary.

  ## Tests
  - Verified default behavior (HSA_TOOLS_LIB unset): libtorch_cpu.so is
    promoted with RTLD_GLOBAL as before, torch.profiler GPU tracing
    works correctly.
  - Verified with HSA_TOOLS_LIB set: RTLD_GLOBAL promotion is skipped,
    external HSA profiling tool's OnLoad callback fires successfully and
    GPU kernel records are captured.
