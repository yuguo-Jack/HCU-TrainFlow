## Original PR description

## Overview

Follow-up to #62561: fill the remaining gaps in the B300 part of **Dynamo disaggregated serving on B300 and GB300** for the [SemiAnalysisAI/InferenceX#4231](https://github.com/SemiAnalysisAI/InferenceX/pull/4231) lane ([run 39112710364](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/39112710364)). Guide text only in `recipes/models/deepseek-ai/DeepSeek-V4.1-Flash.yaml`; the command builder output does not change (B300 builder overrides were intentionally left out in #62561).

## Claims

- **Co-located prefill engines:** up to four DEP2 prefill engines share a B300 node. Add the per-engine `CUDA_VISIBLE_DEVICES`, `VLLM_NIXL_SIDE_CHANNEL_PORT`, KV-event port (`--kv-events-config` endpoint and the sidecar's `DYN_VLLM_KV_EVENT_PORT`) and `--data-parallel-rpc-port`, plus `VLLM_NIXL_SIDE_CHANNEL_HOST` (it defaults to localhost, which breaks cross-node NIXL).
- **EFA prerequisite:** name the installer the lane used (aws-efa-installer 1.50.0, Ubuntu 24.04 debs plus `libhwloc15`), give an `ldd` check for NIXL's LIBFABRIC plugin, and say to expose `/dev/infiniband` to the container.
- **Decode graphs:** the c2048 point steps by 24 above 480 (to 792), not 6.
- **Frontend:** name the `X-Dynamo-Session-Id` header that carries the conversation ID.
- **PD layout note:** the generic "TP8 per role on 8-GPU nodes" sentence now points to the DEP lanes.

## Validation

- Values come from the run's engine/sidecar launch lines and env (per-engine GPUs, side-channel and KV-event ports, DP RPC ports) and the lane's setup script.
- `node scripts/validate-source.mjs --source vllm --dir <this checkout>/recipes` in vllm-project/recipes passes; `git diff --check` is clean.
- Rendered every hardware x strategy x feature selection before and after: no change. Merges cleanly with #62541 (same file).

## Details

Excluded as InferenceX harness only: synthetic acceptance, AIPerf/trace replay, Slurm, telemetry and health checks.
