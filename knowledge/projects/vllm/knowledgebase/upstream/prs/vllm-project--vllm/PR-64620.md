# [MoE] Load fused expert weights with one weight_loader call per shard

[Upstream PR](https://github.com/vllm-project/vllm/pull/64620) · state: open · merged: False

## Original PR description



## Overview

Load a fused `[E, ...]` expert tensor with one `weight_loader` call per shard instead of one per expert and shard, when equivalent. AI assistance (Claude Code) was used to prepare this PR; I reviewed every changed line.

## Claims

- Online weight sync of Qwen3.5-397B-A17B (TP4, online MXFP8 experts): **8.0 s → 3.6 s**.
- Identical parameters to the per-expert loop, for bf16, fp8 and packed uint8 weights, including layerwise reload with a post-load repack (FlashInfer TRTLLM).

## Validation

- `test_moe_weight_loading_padded.py::TestLoadFusedExpertsAtOnce`: the real `weight_loader` across dtypes, TP ranks, gated/non-gated and transposed checkpoints; one 3-D call per shard, bit-identical to the per-expert path.
- `test_reload.py::test_reload_fused_expert_tensors_from_device`: reloads `tiny-random/qwen3.5-moe` from fused tensors on the device; every parameter bit-identical to the initial load.
- GB300, Qwen3.5-35B-A3B, `--moe-backend flashinfer_trtllm`, online `fp8_per_block` and `nvfp4_per_token`: `reload_weights` from device tensors takes the single call for every expert param and restores greedy output token-for-token.
- VR200, Qwen3.5-35B-A3B, online `mxfp8` (FlashInfer TRTLLM MXFP8 MoE) and `fp8_per_block`: zero the experts with `reload_weights` from device tensors, then reload the real ones; all 120 expert params take the single call and all 813 parameters are bit-identical to the initial load, as on `main`.

```
$ pytest tests/kernels/moe/test_moe_weight_loading_padded.py -k FusedExpertsAtOnce
38 passed                                   # GB300, VR200
$ pytest tests/model_executor/model_loader/test_reload.py -k reload_fused_expert_tensors_from_device
1 passed                                    # this PR, GB300 and VR200
1 failed                                    # main
E       AssertionError: assert 0 == (3 * 4)
```

The NVIDIA "Model Executor" CI step is disabled, so `test_reload.py` runs only on the AMD MI300 mirror.

## Details

Under layerwise reload every `weight_loader` call is wrapped and replayed (1536 calls per layer at 512 experts). `weight_loader` already handles a 3-D tensor of all experts (`full_load`), so the loop is unnecessary when local expert i is global expert i.

The single call is used only for `w13_weight` / `w2_weight` whose loader is `RoutedExperts.weight_loader` (custom loaders such as Quark int4 keep the loop), with no expert map, fused shared experts or expert substitution, a tensor covering every local expert, a source not in host memory, no `is_transposed`, and not `gpt_oss_mxfp4`.
