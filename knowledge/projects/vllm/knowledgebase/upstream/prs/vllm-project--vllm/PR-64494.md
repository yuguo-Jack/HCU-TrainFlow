# [Kernel] Add size-gated PDL to silu_and_mul_nvfp4_quant

[Upstream PR](https://github.com/vllm-project/vllm/pull/64494) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Adds programmatic dependent launch (PDL) to the fused SiLU-mul + NVFP4 quant kernel (`silu_and_mul_nvfp4_quant`)
- `griddepcontrol.wait` + `launch_dependents` at kernel start (sm90+).
- The placement is quite aggressive, hence there is a gate `M * N/16 <= SMs * 4096` (there is regression for large M)

## Claims

- **−4.7 % (C=1), −4.1 % (C=4), −4.6 % (C=16)** TPOT, mean of 3 alternating rounds on Qwen3.8-27B-NVFP4 TP1 (8k in / 1k out); C=64 in noise. TTFT neutral (gate off at prefill chunks).
- **Bitwise identical** outputs and scale bytes; PDL changes no math.

## Validation

### Chain microbenchmark (primary)

- Real production chain per layer — `scaled_fp4_quant(x)` → gate_up `mm_fp4` → `silu_and_mul_nvfp4_quant` → down `mm_fp4` (FlashInfer CuTe-DSL calls as deployed)
- captured in one CUDA graph over 6 distinct layers (~1.2 GB of weights, HBM-cold). 20 graph replays timed with CUDA events; 5 fresh processes per arm, arms interleaved and shuffled per round.

### E2E (vllm serve + vllm bench serve, random dataset)

Qwen3.8-27B-NVFP4, TP1, 1× B300, default CUDA graphs, `--language-model-only`, `vllm bench serve` random dataset with `--ignore-eos`. Median TPOT (ms), mean of 3 rounds, A B A B on one GPU plus a base-only run; base same-arm spread ±0.4 % at C=1, ±2.0 % at C=64 (PR spread at C=1: ±0.01 %).

| Workload (8k/1k) | base → PR | Δ |
|---|---:|---:|
| C=1 | 5.424 → 5.169 | −4.7 % |
| C=4 | 6.143 → 5.894 | −4.1 % |
| C=16 | 8.546 → 8.154 | −4.6 % |
| C=64 | 16.671 → 16.533 | −0.8 % (in noise) |

The effect exceeds the MLP-chain prediction (−1.33 µs × 64 layers ≈ −1.6 %): all four linears per layer (qkv, o, gate_up, down) are PDL-launched `mm_fp4`s, so the overlap propagates along the whole per-layer chain. TTFT neutral: ~196 (base) vs ~193 ms (PR) at C=1 — the 8k prefill chunks sit off-gate.

### Correctness

- `pytest tests/kernels/quantization/test_silu_mul_nvfp4_quant.py`: 20/20 pass (B300), including #63382's scale-padding cases.
- Bitwise: FP4 data + all scale bytes identical PR vs base on 8 shapes (M = 1, 3, 64, 555, 558, 2048 at I = 17408 — straddling the gate at 557 — and M = 1, 256 at I = 512), md5 of raw bytes.
