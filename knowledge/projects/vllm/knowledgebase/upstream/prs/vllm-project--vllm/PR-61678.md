# [CI/Build] Fix test_deepseek_v41_mxfp8_scale_loading after #57797

[Upstream PR](https://github.com/vllm-project/vllm/pull/61678) · state: closed · merged: True

## Original PR description

#57797 removed `get_tensor_model_parallel_rank` from `vllm.models.deepseek_v41.nvidia.model`, since attention sinks now load through their `weight_loader`. `test_deepseek_v41_mxfp8_scale_loading` still monkeypatches it there, so all 4 cases fail with `AttributeError` ([build 94813](https://buildkite.com/vllm/ci/builds/94813), H200 Quantization shard 3/4). The model only reads the world size now, and TP slicing happens in the linear layers, so the rank is patched on `linear` only.

The Quantization step's `source_file_dependencies` don't include `vllm/models/deepseek_v41/nvidia/model.py`, so #57797's CI did not run this test.

Test: `pytest tests/quantization/test_fp8.py -k test_deepseek_v41_mxfp8_scale_loading` on DGX Spark (GB10), upstream main 47232f3c7f: 4 failed before the fix, 4 passed after (all 17 `-k deepseek_v41` tests pass).

AI assistance (Claude Code) was used; I reviewed the change and ran the test above.
