# [Core][Perf] Trim per-step overhead in KV block pool hot paths

[Upstream PR](https://github.com/vllm-project/vllm/pull/61570) · state: closed · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Trims scheduler-side CPU work in the KV cache block pool and block hashing, with no behavior change: block hashes are byte-identical and block assignments are unchanged. On an H100 it does **not** move TTFT. It saves about 24–75 µs of scheduler CPU per step, against 33–66 ms of GPU time per prefill step.

## Claims

- **No behavior change.**
  - On a CPU replica of the hybrid layout, block assignments, KV copies and zeroing ops match `main` (fingerprint over 416 steps).
  - In every e2e run, both sides take the same number of scheduler steps.
- **Less EngineCore CPU** for layouts with many blocks per request (thread CPU time, H100):
  - `KVCacheManager` -14% to -20%.
  - `Scheduler.schedule` -13%.
  - No change with large blocks (Qwen3.5 default, 544-token blocks).
- **TTFT unchanged** within run-to-run noise for 32k and 128k prompts.

## Validation

**E2E on 1× H100 80GB.** Both sides use one precompiled install at the merge base `12b005eefa`. Only `block_pool.py` and `kv_cache_utils.py` are swapped between `main` and the PR, and rounds alternate.

vllm serve <model> --seed 0 --enable-prefix-caching --max-model-len 131584 \
  --max-num-batched-tokens 2048 --gpu-memory-utilization 0.90 [model flags]
vllm bench serve --backend vllm --model <model> --dataset-name random \

  --num-prompts {16,8} --max-concurrency 1 --ignore-eos --seed {1,2}

The three model configurations:

| Config | Layout |
|---|---|
| Qwen3-0.6B | One full-attention group, 16-token blocks. YaRN ×4 (`max_position_embeddings` 131072); long input is 130048 tokens. |
| Qwen3.5-0.8B (`--language-model-only`) | Hybrid model. Default settings pad all four groups and the hashes to 544 tokens. |
| Qwen3.5-0.8B + `--prefix-match-unit 16` | 544-token groups over 16-token hashes. This is the coarse hash view (`BlockHashListWithBlockSize`). |

I did not benchmark a model whose groups keep *different* block sizes. That case appears only in the synthetic micro-benchmark below.

|---|---|---|---|---|---|

How to read the table:
- **TTFT** is the median of per-round mean TTFT, at concurrency 1. There are 3 + 3 rounds per config, and 7 + 7 for unit 16.
- **CPU** is thread CPU time inside EngineCore, recorded by a benchmark-only timing hook in separate runs. Unit 16 has 3 + 3 runs whose ranges do not overlap; the other configs have 1 + 1. Most `KVCacheManager` time is spent inside `schedule`, so the two columns overlap.

"""Micro-benchmark for KV cache block pool hot paths (CPU only)."""

import argparse
import random
import statistics
import time

import torch

from vllm.sampling_params import SamplingParams
from vllm.utils.hashing import sha256
from vllm.v1.core.kv_cache_manager import KVCacheManager
from vllm.v1.core.kv_cache_utils import get_request_block_hasher, init_none_hash
from vllm.v1.kv_cache_interface import (
    FullAttentionSpec,
    KVCacheConfig,
    KVCacheGroupSpec,
)
from vllm.v1.request import Request

HASH_BLOCK_SIZE = 16


def make_manager(block_size: int, num_blocks: int) -> KVCacheManager:
    # block_size != HASH_BLOCK_SIZE adds a second group at the hash block size,
    # forcing the hybrid coordinator and BlockHashListWithBlockSize.
    sizes = [block_size] if block_size == HASH_BLOCK_SIZE else [block_size, 16]
    config = KVCacheConfig(
        num_blocks=num_blocks * len(sizes) * block_size // HASH_BLOCK_SIZE,
        kv_cache_tensors=[],
        kv_cache_groups=[
            KVCacheGroupSpec(
                [f"layer{i}"],
                FullAttentionSpec(
                    block_size=bs,
                    num_kv_heads=1,
                    head_size=1,
                    dtype=torch.float32,
                ),
            )
            for i, bs in enumerate(sizes)
        ],
    )
    return KVCacheManager(
        config,
        max_model_len=1 << 20,
        scheduler_block_size=block_size,
        hash_block_size=HASH_BLOCK_SIZE,
        enable_caching=True,
    )


def make_request(rid: str, prompt_len: int, rng: random.Random) -> Request:
    params = SamplingParams(max_tokens=16)
    params.update_from_generation_config({}, eos_token_id=100)
    return Request(
        request_id=rid,
        prompt_token_ids=[rng.randrange(1000, 30000) for _ in range(prompt_len)],
        sampling_params=params,
        pooling_params=None,
        block_hasher=get_request_block_hasher(HASH_BLOCK_SIZE, sha256),
    )


def run_prefill(block_size: int, prompt_len: int, chunk: int, num_reqs: int):
    """Chunked prefill of unique prompts; later requests evict earlier ones."""
    rng = random.Random(0)
    blocks_per_req = prompt_len // block_size + 2
    manager = make_manager(block_size, blocks_per_req * 3)
    reqs = [make_request(f"r{i}", prompt_len, rng) for i in range(num_reqs)]
    t0 = time.perf_counter()
    for req in reqs:
        computed, num_computed, _ = manager.get_computed_blocks(req)
        first = True
        while req.num_computed_tokens < prompt_len:
            n = min(chunk, prompt_len - req.num_computed_tokens)
            if first:
                out = manager.allocate_slots(req, n, num_computed, computed)
                first = False
            else:
                out = manager.allocate_slots(req, n)
            assert out is not None
            req.num_computed_tokens += n
        manager.free(req)
    return time.perf_counter() - t0


def run_hasher(prompt_len: int, num_reqs: int):
    rng = random.Random(1)
    prompts = [
        [rng.randrange(1000, 30000) for _ in range(prompt_len)]
        for _ in range(num_reqs)
    ]
    hasher = get_request_block_hasher(HASH_BLOCK_SIZE, sha256)
    params = SamplingParams(max_tokens=16)
    params.update_from_generation_config({}, eos_token_id=100)
    t0 = time.perf_counter()
    for i, p in enumerate(prompts):
        Request(
            request_id=f"h{i}",
            prompt_token_ids=p,
            sampling_params=params,
            pooling_params=None,
            block_hasher=hasher,
        )
    return time.perf_counter() - t0


def bench(name, fn, repeats):
    fn()  # warmup
    times = [fn() for _ in range(repeats)]
    print(
        f"{name:<48} median {statistics.median(times) * 1e3:9.2f} ms  "
        f"min {min(times) * 1e3:9.2f} ms"
    )


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--repeats", type=int, default=7)
    args = parser.parse_args()
    init_none_hash(sha256)
    r = args.repeats
    bench(
        "prefill 32k prompt, bs16, chunk 2048, x8",
        lambda: run_prefill(16, 32768, 2048, 8),
        r,
    )
    bench(
        "prefill 128k prompt, bs16, chunk 2048, x2",
        lambda: run_prefill(16, 131072, 2048, 2),
        r,
    )
    bench(
        "prefill 128k prompt, groups bs64+bs16, chunk 2048, x2",
        lambda: run_prefill(64, 131072, 2048, 2),
        r,
    )
    bench(
        "prefill 2k prompt, bs16, chunk 512, x200",
        lambda: run_prefill(16, 2048, 512, 200),
        r,
    )
    bench("hash 32k prompt, x8", lambda: run_hasher(32768, 8), r)


if __name__ == "__main__":
    main()

"""CPU repro of the Qwen3.5 + --prefix-match-unit 16 KV cache layout:
1 full-attention group + 3 Mamba(align) groups, all 544-token blocks,
16-token hashes. Times request hashing and the block-pool prefill loop."""

import random
import statistics
import time

import torch

from vllm.sampling_params import SamplingParams
from vllm.utils.hashing import sha256
from vllm.v1.core.kv_cache_manager import KVCacheManager
from vllm.v1.core.kv_cache_utils import get_request_block_hasher, init_none_hash
from vllm.v1.kv_cache_interface import (
    FullAttentionSpec,
    KVCacheConfig,
    KVCacheGroupSpec,
    MambaSpec,
)
from vllm.v1.request import Request

BLOCK, HASH, CHUNK = 544, 16, 2048


def make_manager(num_blocks):
    groups = [
        KVCacheGroupSpec(
            ["attn"],
            FullAttentionSpec(
                block_size=BLOCK, num_kv_heads=1, head_size=1, dtype=torch.float32
            ),
        )
    ] + [
        KVCacheGroupSpec(
            [f"mamba{i}"],
            MambaSpec(
                block_size=BLOCK,
                shapes=(1, 1),
                dtypes=(torch.float32,),
                mamba_cache_mode="align",
            ),
        )
        for i in range(3)
    ]
    return KVCacheManager(
        KVCacheConfig(num_blocks=num_blocks, kv_cache_tensors=[], kv_cache_groups=groups),
        max_model_len=1 << 20,
        scheduler_block_size=BLOCK,
        hash_block_size=HASH,
        enable_caching=True,
    )


def run(prompt_len, num_reqs):
    rng = random.Random(0)
    params = SamplingParams(max_tokens=1)
    params.update_from_generation_config({}, eos_token_id=100)
    prompts = [
        [rng.randrange(1000, 30000) for _ in range(prompt_len)] for _ in range(num_reqs)
    ]
    mgr = make_manager((prompt_len // BLOCK + 4) * 4 * 3)
    hasher = get_request_block_hasher(HASH, sha256)
    t0 = time.perf_counter()
    reqs = [
        Request(
            request_id=f"r{i}",
            prompt_token_ids=p,
            sampling_params=params,
            pooling_params=None,
            block_hasher=hasher,
        )
        for i, p in enumerate(prompts)
    ]
    t_hash = time.perf_counter() - t0
    t0 = time.perf_counter()
    for req in reqs:
        computed, n, _ = mgr.get_computed_blocks(req)
        first = True
        while req.num_computed_tokens < prompt_len:
            k = min(CHUNK, prompt_len - req.num_computed_tokens)
            out = (
                mgr.allocate_slots(req, k, n, computed)
                if first
                else mgr.allocate_slots(req, k)
            )
            assert out is not None, "allocation failed"
            first = False
            req.num_computed_tokens += k
            mgr.new_step_starts()
        mgr.free(req)
    t_pool = time.perf_counter() - t0
    return t_hash, t_pool


init_none_hash(sha256)
for prompt_len, num_reqs in ((32768, 8), (131072, 2)):
    run(prompt_len, num_reqs)
    res = [run(prompt_len, num_reqs) for _ in range(5)]
    h = statistics.median(r[0] for r in res) * 1e3
    p = statistics.median(r[1] for r in res) * 1e3
    print(f"{prompt_len // 1024:>4}k x{num_reqs}  hashing {h:8.2f} ms   block pool {p:8.2f} ms")

# sitecustomize.py, active only with KVTIME_DIR set
"""Benchmark-only timing hook (identical on both sides). Active only when
KVTIME_DIR is set: wraps KV cache manager entry points, request block hashing
and Scheduler.schedule, and periodically writes cumulative ns/calls per pid."""

import atexit
import importlib.abc
import importlib.util
import json
import os
import sys
import threading
import time

OUT_DIR = os.environ.get("KVTIME_DIR")
_stats: dict[str, list[int]] = {}


def _dump():
    if not _stats:
        return
    path = os.path.join(OUT_DIR, f"kvtime-{os.getpid()}.json")
    with open(path + ".tmp", "w") as f:
        json.dump(_stats, f)
    os.replace(path + ".tmp", path)


def _timed(name, fn):
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter_ns()
        c0 = time.thread_time_ns()
        try:
            return fn(*args, **kwargs)
        finally:
            # [wall ns, calls, thread CPU ns]; CPU time excludes GIL waits,
            # since request hashing runs on EngineCore's input thread.
            s = _stats.setdefault(name, [0, 0, 0])
            s[0] += time.perf_counter_ns() - t0
            s[1] += 1
            s[2] += time.thread_time_ns() - c0

    return wrapper


def _patch_kv_cache_manager(mod):
    cls = mod.KVCacheManager
    for n in ("get_computed_blocks", "allocate_slots", "free", "cache_blocks"):
        setattr(cls, n, _timed(f"KVCacheManager.{n}", getattr(cls, n)))


def _patch_kv_cache_utils(mod):
    orig = mod.get_request_block_hasher

    def get_request_block_hasher(*args, **kwargs):
        return _timed("request_block_hasher", orig(*args, **kwargs))

    mod.get_request_block_hasher = get_request_block_hasher


def _patch_scheduler(mod):
    mod.Scheduler.schedule = _timed("Scheduler.schedule", mod.Scheduler.schedule)


PATCHES = {
    "vllm.v1.core.kv_cache_manager": _patch_kv_cache_manager,
    "vllm.v1.core.kv_cache_utils": _patch_kv_cache_utils,
    "vllm.v1.core.sched.scheduler": _patch_scheduler,
}


class _Finder(importlib.abc.MetaPathFinder):
    def find_spec(self, fullname, path, target=None):
        if fullname not in PATCHES:
            return None
        sys.meta_path.remove(self)
        try:
            spec = importlib.util.find_spec(fullname)
        finally:
            sys.meta_path.insert(0, self)
        orig_exec = spec.loader.exec_module

        def exec_module(module):
            orig_exec(module)
            PATCHES[fullname](module)

        spec.loader.exec_module = exec_module
        return spec


def _dump_loop():
    while True:
        time.sleep(0.5)
        _dump()


if OUT_DIR:
    os.makedirs(OUT_DIR, exist_ok=True)
    sys.meta_path.insert(0, _Finder())
    threading.Thread(target=_dump_loop, daemon=True).start()
    atexit.register(_dump)

## Details

- **`cache_full_blocks`** sliced every remaining prompt hash on each prefill chunk. It now slices only up to `num_full_blocks`, and `BlockHashListWithBlockSize` serves forward slices with one strided list slice.
- **`_remove_cached_block_hashes` and `_insert_block_hash`** skip map work for blocks without a hash, which is most blocks that `get_new_blocks` hands out.
- **`generate_block_hash_extra_keys`** appends each key source in place, instead of concatenating four lists per block. `start_mm_idx` is advanced as a cursor. There is no separate guard that would duplicate the list of key sources.
- **Docstrings.** Fixed two stale ones (`hash_block_tokens`, `FreeKVCacheBlockQueue`).
- **Overlap with #55092.** It edits lines next to `_remove_cached_block_hashes`, so a trivial rebase may be needed. No open PR covers these changes.
