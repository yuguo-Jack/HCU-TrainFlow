# [Bugfix][Kernel] Honor leading strides in SM90 blockwise FP8 GEMM

[Upstream PR](https://github.com/vllm-project/vllm/pull/56248) · state: open · merged: False

## Original PR description

## Purpose

The SM90 blockwise FP8 CUTLASS caller reconstructs packed strides from the logical
matrix shape, even when `cutlass_scaled_mm` receives aligned tensor views with
padded leading dimensions. This reads incorrect input/weight rows and can write
into output padding. For example, an A view with shape `(4, 256)` and stride
`(384, 1)` is incorrectly addressed as if its row stride were 256.

Pass `a.stride(0)`, `b.stride(1)`, and `out.stride(0)` into the CUTLASS operand and
epilogue strides. When `swap_ab` is enabled (`M % 4 != 0`), the output is viewed
as a column-major transpose, so its leading stride belongs in component 1.
Block-scale layouts continue to describe the logical matrix dimensions.

Related to #55534 (SM90 blockwise only). This does not duplicate #55537: that PR
covers the common and SM90 tensorwise callers and explicitly leaves blockwise
callers out of scope, as confirmed in the
[author's comment](https://github.com/vllm-project/vllm/pull/55537#issuecomment-5613376816).
Issue comments and open/recently merged PR searches were checked on 2026-09-10.

```python
"""Compare real-model outputs before/after lossless FP8 weight-row padding.

Run in the vLLM development environment on H20, once per kernel build:
  HF_HUB_OFFLINE=1 VLLM_ALLOW_INSECURE_SERIALIZATION=1 .venv/bin/python \
    eval_sm90_blockwise_model.py --variant baseline --output result.json
The serialization setting is only for this process's trusted local callback.
This is a local contribution-validation artifact, not an upstream test.
"""

import argparse
import hashlib
import json
import time
from pathlib import Path


def pad_blockwise_weights(model):
    import torch

    from vllm.model_executor.kernels.linear.scaled_mm.cutlass import (
        CutlassFp8BlockScaledMMKernel,
    )

    changed = []
    for name, layer in model.named_modules():
        method = getattr(layer, "quant_method", None)
        kernel = getattr(method, "fp8_linear", None)
        if not isinstance(kernel, CutlassFp8BlockScaledMMKernel):
            continue
        weight = layer.weight
        assert weight.ndim == 2 and weight.stride(1) == 1
        rows, cols = weight.shape
        padded = torch.zeros(
            (rows, cols + 128), dtype=weight.dtype, device=weight.device
        )
        view = padded[:, :cols]
        view.copy_(weight)
        assert torch.equal(view.view(torch.uint8), weight.view(torch.uint8))
        old_stride = list(weight.stride())
        weight.data = view
        changed.append(
            {
                "name": name,
                "shape": list(weight.shape),
                "before_stride": old_stride,
                "after_stride": list(weight.stride()),
                "kernel": type(kernel).__name__,
            }
        )
    assert changed, "The model did not select the targeted CUTLASS block FP8 kernel"
    return changed


def generate_cases(llm, prompts, params):
    results = []
    for batch_size in (1, 3, 4):
        started = time.perf_counter()
        outputs = llm.generate(prompts[:batch_size], params, use_tqdm=False)
        assert len(outputs) == batch_size
        assert all(
            output.outputs[0].cumulative_logprob is not None for output in outputs
        )
        results.append(
            {
                "batch_size": batch_size,
                "elapsed_seconds": time.perf_counter() - started,
                "outputs": [
                    {
                        "token_ids": list(output.outputs[0].token_ids),
                        "text": output.outputs[0].text,
                        "cumulative_logprob": output.outputs[0].cumulative_logprob,
                    }
                    for output in outputs
                ],
            }
        )
    return results


def compare_cases(before_cases, after_cases):
    assert len(before_cases) == len(after_cases)
    token_match = logprob_match = True
    for before, after in zip(before_cases, after_cases):
        assert before["batch_size"] == after["batch_size"]
        assert len(before["outputs"]) == len(after["outputs"])
        for a, b in zip(before["outputs"], after["outputs"]):
            token_match &= a["token_ids"] == b["token_ids"]
            logprob_match &= a["cumulative_logprob"] == b["cumulative_logprob"]
    return token_match, logprob_match


def main():
    import torch
    import vllm
    import vllm._C_stable_libtorch as native

    from vllm import LLM, SamplingParams

    parser = argparse.ArgumentParser()
    parser.add_argument("--model", default="Qwen/Qwen3-0.6B-FP8")
    parser.add_argument(
        "--revision", default="e5be08033360965ceca7b0ffd72d521a51331ce0"
    )
    parser.add_argument("--output", type=Path, required=True)
    parser.add_argument("--variant", choices=["baseline", "patched"], required=True)
    args = parser.parse_args()
    llm = LLM(
        model=args.model,
        revision=args.revision,
        dtype="bfloat16",
        kernel_config={"linear_backend": "cutlass"},
        enforce_eager=True,
        enable_prefix_caching=False,
        max_model_len=1024,
        max_num_seqs=8,
        max_num_batched_tokens=1024,
        gpu_memory_utilization=0.25,
        seed=0,
    )
    prompts = [
        "The capital of France is",
        "A short Python function that adds two numbers:\n",
        "Explain why the sky appears blue in one sentence:",
        "Translate to English: 今天的天气很好。\n",
    ]
    params = SamplingParams(temperature=0, max_tokens=32, logprobs=1)
    # Warm the ordinary inference path before recording it.
    llm.generate(prompts[:1], params, use_tqdm=False)
    packed = generate_cases(llm, prompts, params)
    repeated_packed = generate_cases(llm, prompts, params)
    repeat_match = compare_cases(packed, repeated_packed)
    assert all(repeat_match), (
        "Unmodified model is not deterministic; probe is inconclusive"
    )
    layers = llm.apply_model(pad_blockwise_weights)
    padded = generate_cases(llm, prompts, params)
    token_match, logprob_match = compare_cases(packed, padded)
    result = {
        "variant": args.variant,
        "model": args.model,
        "revision": args.revision,
        "torch": torch.__version__,
        "gpu": torch.cuda.get_device_name(),
        "capability": torch.cuda.get_device_capability(),
        "vllm_source": vllm.__file__,
        "native_library": native.__file__,
        "native_sha256": hashlib.sha256(Path(native.__file__).read_bytes()).hexdigest(),
        "padded_layers": layers,
        "packed": packed,
        "repeated_packed": repeated_packed,
        "repeat_control_identical": all(repeat_match),
        "padded": padded,
        "tokens_identical": token_match,
        "cumulative_logprobs_identical": logprob_match,
        "scope": "Eager FP8 model layout equivalence; not a task accuracy benchmark",
    }
    args.output.parent.mkdir(parents=True, exist_ok=True)
    args.output.write_text(json.dumps(result, ensure_ascii=False, indent=2) + "\n")
    print(
        json.dumps(
            {"tokens_identical": token_match, "logprobs_identical": logprob_match}
        )
    )
    raise SystemExit(0 if token_match and logprob_match else 1)


if __name__ == "__main__":
    main()

```

Following the [integration feedback in #55534](https://github.com/vllm-project/vllm/issues/55534#issuecomment-5644534773), checked this PR at

All 30 cases satisfy the proposed inner-stride, minimum-leading-dimension and
stride-divisibility requirements. The leading strides below are in elements;
each row covers M=3/4/128 and both BF16/FP16 outputs.

| Layout | A leading stride | B leading stride | Output leading stride |
| --- | --- | --- | --- |
| Packed | 256 | 256 | 384 |
| Padded A | 384 | 256 | 384 |
| Padded B | 256 | 384 | 384 |
| Padded output | 256 | 256 | 512 |
| All padded | 384 | 384 | 512 |

A/B/output shapes are `(M,256)`, `(256,384)`, and `(M,384)`. Every leading stride
is a multiple of 16 and at least the corresponding logical extent. All slices
start at storage offset zero; transposing B does not move its pointer. They
therefore preserve the backing CUDA allocations' pointer alignment. The packed
reference operands also satisfy the guards. No layout change is needed.

An isolated Git-index composition check confirms that #55537 applies cleanly
on top of this PR. #56480 and #56659 each overlap the test insertion after
`test_cutlass_fp8_blockwise_scale_gemm`; that shared test hunk will need
reconciliation when one of those PRs lands. Their kernel changes are disjoint.
Landing #55537 first follows the suggested integration order.
