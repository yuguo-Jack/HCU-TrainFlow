# [Bugfix] GLM 5.3 compat w/ parser: ignore enable_thinking 

[Upstream PR](https://github.com/vllm-project/vllm/pull/54276) · state: closed · merged: False

## Original PR description

## Purpose

GLM-5.3 chat template no longer declares `enable_thinking`, but `Glm47MoeParser` still honored `enable_thinking=False` from `chat_template_kwargs`

Users who leave `enable_thinking=False` in kwargs with a 5.3 template may expect the usual no-op. However, the parser will still treat it as a request to disable reasoning separation which results in CoT leaks


## Test Plan

Served `zai-org/GLM-5.3` and sent `extra_body={"chat_template_kwargs": {"enable_thinking": false}}`

## Test Result

Before: reasoning text leaks in `delta.content`.
After: reasoning correctly arrives in `delta.reasoning`
