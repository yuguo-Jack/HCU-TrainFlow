# fix(security): handle prompt_embeds in XD-RoPE position init

[Upstream PR](https://github.com/vllm-project/vllm/pull/54232) · state: closed · merged: False

## Original PR description

Replace the fatal assertion in _init_xdrope_positions that crashes the EngineCore when prompt_token_ids is None. When only prompt_embeds are provided (e.g. /v1/completions with prompt_embeds and no token ids), derive the sequence length from the embeddings tensor and use dummy token IDs, mirroring the fix applied to _init_mrope_positions for CVE-2026-55514.

Without this fix, a single embeddings-only request on an XD-RoPE model (e.g. HunyuanOCR) with --enable-prompt-embeds terminates the entire server process, affecting all concurrent clients.

Addresses GHSA-5q78-j82c-2vr2.
