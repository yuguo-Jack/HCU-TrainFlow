# [Perf] Async logits proc and sampling metadata state update

[Upstream PR](https://github.com/vllm-project/vllm/pull/23383) · state: closed · merged: False

## Original PR description

Mentioned by @WoosukKwon in https://github.com/vllm-project/vllm/issues/23233.

The work to update logits processor states and construct the sampling metadata be deferred in model runner `execute_model` to overlap CPU with forward pass.

This has an advantage of taking the logits processor `update_states` calls off the critical path, and means we can trade off a bit of efficiency for simplicity in the API design.

There should be some incremental benefit as we migrate hard-wired sampling parameters into logits processors since their state updates are still happening in `_update_states()` before the forward pass.
