# [Doc] Fix inconsistent hash notation in prefix caching Time 5 diagram

[Upstream PR](https://github.com/vllm-project/vllm/pull/44894) · state: closed · merged: False

## Original PR description

## Summary

Fixes #35992

The Block Pool in the **Time 5** diagram (`example-time-6.png`) used local-token hash notation (`ABCD`, `EFGH`, `IJKL`, `MNOP`) instead of the prefix-hash notation (`A-D`, `A-H`, `A-L`, `A-P`) used consistently in:
- The Cache Blocks dict **in the same diagram**
- The Time 4 diagram (`example-time-5.png`)
- All other diagrams in the prefix caching design doc

### Blocks corrected

| Block ID | Before (wrong) | After (correct) |
|----------|---------------|-----------------|
| ID: 0 | `ABCD` | `A-D` |
| ID: 1 | `EFGH` | `A-H` |
| ID: 2 | `IJKL` | `A-L` |
| ID: 3 | `MNOP` | `A-P` |
| ID: 5 | `IJkl` | `A-J,kl` |

The diagram was regenerated using matplotlib to accurately reflect how prefix-hash notation works: each block hash encodes the parent hash + block tokens, not just local tokens.

> **Note:** Two pre-commit hooks (`png-lint`, `update-dockerfile-graph`) were skipped locally as they require `/bin/bash` which is not available at that path on Windows. Both will pass in Linux CI.
