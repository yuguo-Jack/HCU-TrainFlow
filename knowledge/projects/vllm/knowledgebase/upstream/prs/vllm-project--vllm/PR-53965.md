# [Bugfix] Preserve parallel HY-V3 calls delivered in one streaming delta

[Upstream PR](https://github.com/vllm-project/vllm/pull/53965) · state: closed · merged: True

## Original PR description

## Purpose

HY-V3 streaming silently dropped parallel tool calls when more than one complete call arrived in a single engine delta. The parser completed the first call, retained the remaining text in `_buffer`, and returned. If generation had already ended, no later delta arrived to drain that buffer. This change drains only additional complete calls, emits them with sequential indices, and leaves single-call and incomplete-call handling unchanged.

## Reproducer

Run this against `main`, then against this branch:

```python
import json
from unittest.mock import MagicMock

from vllm.entrypoints.openai.chat_completion.protocol import (
    ChatCompletionRequest,
    ChatCompletionToolsParam,
    FunctionDefinition,
)
from vllm.tool_parsers.hy_v3_tool_parser import HYV3ToolParser

tokenizer = MagicMock()
tokenizer.init_kwargs = {}
tokenizer.get_vocab.return_value = {
    "<tool_calls>": 1,
    "</tool_calls>": 2,
}
request = ChatCompletionRequest(
    model="test",
    messages=[],
    tools=[
        ChatCompletionToolsParam(
            function=FunctionDefinition(
                name="get_weather",
                parameters={
                    "type": "object",
                    "properties": {"city": {"type": "string"}},
                },
            )
        )
    ],
)
text = (
    "<tool_calls>"
    "<tool_call>get_weather<tool_sep>"
    "<arg_key>city</arg_key><arg_value>Beijing</arg_value>"
    "</tool_call>"
    "<tool_call>get_weather<tool_sep>"
    "<arg_key>city</arg_key><arg_value>Hangzhou</arg_value>"
    "</tool_call>"
    "</tool_calls>"
)


def summarize(calls):
    return [
        (call.function.name, json.loads(call.function.arguments)) for call in calls
    ]


parser = HYV3ToolParser(tokenizer)
print("nonstream", summarize(parser.extract_tool_calls(text, request).tool_calls))

parser = HYV3ToolParser(tokenizer)
delta = parser.extract_tool_calls_streaming(
    previous_text="",
    current_text=text,
    delta_text=text,
    previous_token_ids=[],
    current_token_ids=[parser.tool_calls_start_token_id],
    delta_token_ids=[parser.tool_calls_start_token_id],
    request=request,
)
print("stream", summarize(delta.tool_calls))
```
