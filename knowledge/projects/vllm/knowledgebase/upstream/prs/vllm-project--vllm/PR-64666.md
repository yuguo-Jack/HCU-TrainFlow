# [Docs] Fix dead links to moved llm-d, Dynamo, TPU, Ray and Tensorizer pages

[Upstream PR](https://github.com/vllm-project/vllm/pull/64666) · state: closed · merged: True

## Original PR description



## Overview

Fix nine dead external links in the docs. Each one now points at the page's current location.

## Claims

- llm-d integration page: the `kv-management`, `workload-autoscaling` and `flow-control` pages moved to `/docs/architecture/kv-management`, `/docs/operations/autoscaling` and `/docs/operations/traffic/flow-control`.
- Dynamo integration page: `docs/kubernetes/README.md` no longer exists in ai-dynamo/dynamo. The link now goes to the published Kubernetes introduction on docs.nvidia.com.
- TPU links (`.nav.yml`, `features/README.md`, `features/quantization/README.md`): tpu-inference split `recommended_models_features/` into `recommended_models/` and `features/`. The nav entry now points at Recommended Models. The two feature-support notes point at the Feature Matrix, and the quantization one links its `#quantization-support` section.
- `design/metrics.md`: Kubernetes WG Serving was archived, so the link now uses `kubernetes/community/tree/main/archive/wg-serving`.
- `usage/security.md`: the Ray security page moved from `ray-core/security.html` to `ray-security/index.html`.
- `models/extensions/tensorizer.md`: CoreWeave removed its Tensorizer docs page, so the link now goes to the `coreweave/tensorizer` repository.

## Validation

- Ran `lychee --scheme https 'docs/**/*.md'` on main to find the dead links.
- Checked every old URL with `curl -sL` (all return 404) and every new URL (all return 200). I also confirmed that each new page covers the same topic, e.g. the Ray page still states that anyone who can reach the cluster can run arbitrary code.

## Details

Only links are changed, plus the TPU link text where the target page was renamed. I left `deployment/integrations/llamastack.md` alone: Llama Stack is now ogx-ai/ogx and its inline vLLM provider has been removed, so that page needs a content update and not just a link swap.
