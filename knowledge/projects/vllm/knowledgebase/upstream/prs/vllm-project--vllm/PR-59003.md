# [Weight Reload][MegaMoE] Rebuild module-owned packed expert buffers

[Upstream PR](https://github.com/vllm-project/vllm/pull/59003) · state: open · merged: False

## Original PR description

## Purpose

Declare routed MegaMoE packed weights/scales as derived buffers for DeepSeek V4 NVIDIA/XPU and Kimi K3. Kernel tuple properties read the current owned buffers rather than retaining stale temporary tensors. Stage new checkpoint sources until packing completes, then commit new values into the existing graph-visible storage.

Native shared experts own all four packed tensors as well. Keep the shared projection loader topology, release raw storage after conversion, and skip unused serial PWAL to avoid retaining another processed copy. The enclosing MoE participates in completion when shared sources change. Adds repeated routed reload coverage and updates shared ownership assertions. XPU's existing unsupported runtime guard remains in place; this does not enable an XPU MegaMoE backend.

## Merge order

Merge #53509 first, then this PR. The branch starts directly from main and includes no prerequisite PR commits. It is not stacked. FlashInfer alpha ownership (#59002) can merge afterwards; opaque FlashInfer packed weights are outside this native ownership implementation.

Tracks #57895 and ports the MegaMoE portion of aoshen02/vllm#56. Source-dropping transforms require a complete routed/shared checkpoint source group; this does not enable selective reload.
