# [Attention] Add P256 MiniMax M3 indexer CP layout

[Upstream PR](https://github.com/vllm-project/vllm/pull/63671) · state: open · merged: False

## Original PR description

## Summary

- Add contiguous P256 index-K storage for TP2 and TP4 while keeping logical ranking blocks at 128 tokens.
- Update the indexer writer, scorers, and MSA sparse-attention reads for the P256 layout.
- Preserve the existing P128 behavior.

Depends on [#61929](https://github.com/vllm-project/vllm/pull/61929). Until that PR merges, GitHub includes its parent CP changes in this diff. The companion P128/P256 kernels are in [vllm-project/MSA#46](https://github.com/vllm-project/MSA/pull/46).

## Validation

CPU offload update: built-in `SimpleCPUOffloadConnector` with the CPU backend now retains index-K sharding. Added TP2/TP4 store/overwrite/reload checks followed by indexer output and graph-replay comparisons. GPU roundtrip and full-model prefix-reload validation are pending; the E2E measurements below do not cover this new combination.

### GB300 full-model P256 E2E

Tested stacked vLLM `9b2a28e075874de0c3b4aa8abaaa5987cbc2af4e` with MSA `b41e5f2cd6b2500507117980696e556c983143e6` on single-node GB300 (SM103), P256, TP2/TP4. The fixed workload used ISL 163840, OSL 8192, steady C14 and mixed 14+1, EAGLE3 `k=3` with synthetic acceptance length 2.78, NVFP4 weights and main KV, FP8 index cache, chunked-prefill budget 8192, prefix caching off, and CUDA Graph enabled. These are matched-source, same-node CP-on→CP-off pairs with one post-warmup measured instrumented cohort per cell. No stability interval is claimed. Warmup, smoke, accuracy, profiler, failed, and unpaired runs are excluded.

GPU validation is manual and outside CI.

## Memory and scope

P256 changes the physical page layout; it does not change the logical B128 ranking unit or the `1 / TP` index-K storage reduction from #61929. Main-KV/index-K packing and auto-selection are outside this PR.

The rewritten stack is diff-clean and all commits carry DCO sign-offs. GPU validation is manual and outside CI. AI assistance was used.
