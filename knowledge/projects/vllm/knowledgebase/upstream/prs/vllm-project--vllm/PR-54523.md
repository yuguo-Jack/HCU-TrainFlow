## Purpose

**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Validate DP before reconfiguring independent ranks**

For non-MoE models using request-level data parallelism, `EngineCoreProc.run_engine_core` calls `reconfigure_for_independent_dp_rank()` before constructing the worker, which changes `data_parallel_size` to 1. Because this manager is only validated later during model-runner initialization, the new condition always sees 1 and never raises, so dense MLA GPU models can enter the unsupported PCP+DP path. Perform this validation before the per-rank reconfiguration or preserve the original DP size for the check.
