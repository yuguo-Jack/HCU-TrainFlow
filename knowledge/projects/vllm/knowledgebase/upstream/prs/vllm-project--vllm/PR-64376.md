# [CI] Remove reintroduced CUDA CCCL from ROCm test requirements

[Upstream PR](https://github.com/vllm-project/vllm/pull/64376) · state: closed · merged: False

## Original PR description

## Overview

Restore the ROCm test lockfile exclusion from #64302 by removing the two lines reintroduced in #61699 (7b87062308).

## Claims

- Fixes the observed main-branch `pip-compile-rocm` failure: regenerating the lockfile no longer modifies it.

## Validation

- `uvx pre-commit run pip-compile-rocm --files requirements/test/rocm.txt`: reproduced the failure on main and generated exactly this two-line deletion; rerunning passed.
- `git diff --check`: passed.
- `uvx pre-commit run --files requirements/test/rocm.txt`: all applicable hooks passed.

- The separate git commit-hook environment could not install ShellCheck due to a local certificate error; commit hooks were bypassed after the explicit checks above passed.

- Model evaluation is not applicable: this only corrects the generated ROCm test dependency list.
- First failing main run: https://github.com/vllm-project/vllm/actions/runs/40778340620. Its parent passed: https://github.com/vllm-project/vllm/actions/runs/40772514088.

## Details

The existing hook already passes `--no-emit-package nvidia-cuda-cccl`. The accidentally restored package and its `via` comment are removed on regeneration, causing pre-commit to fail with “files were modified by this hook.” This patch is the hook's generated output.

Duplicate checks covered #61699 comments and open PR searches for `61699 in:body`, `cccl`, `rocm pre-commit`, and `64302 in:body`. No existing PR addresses this regression. The related #64366 upgrades numba and does not contain this deletion. This restores main's CI rather than performing cosmetic cleanup.

AI assistance (Codex) was used to investigate, regenerate the lockfile, and validate this change.
