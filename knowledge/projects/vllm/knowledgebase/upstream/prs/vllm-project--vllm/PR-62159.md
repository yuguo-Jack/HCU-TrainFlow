# [Bugfix][Core] Emit full reuse events for converged hybrid connector hits

[Upstream PR](https://github.com/vllm-project/vllm/pull/62159) · state: open · merged: False

## Original PR description

## Overview

Restore full prefix-cache reuse events for converged hybrid hits selected by a KV connector. This fixes missing `BlockStored` notifications without changing cache-hit lengths, allocation, or scheduling.

## Claims

- A nonzero, converged hybrid hit now emits the same full-report events as the regular lookup when events are enabled.
- Incremental reporting and disabled events remain silent; divergent hits are not prematurely reported.
- Scheduler fallback still publishes each reused group exactly once.

## Details

`Scheduler._get_local_prefix_cache_hit` selects `get_computed_blocks_for_connector` for capable connectors. Unlike `get_computed_blocks`, its successful per-group return path did not emit full reuse reports. The patch reuses the coordinator's existing emitter, guarded by a nonzero converged hit and the existing reporting switches. It does not add a second cache lookup.

Duplicate searches for `get_computed_blocks_for_connector` and `kv_cache_report_mode` and inspection of adjacent PR patches found no fix for this converged missing-event path. #57358 addresses sparse event encoding, not this omitted call; #54302 changes divergent-hit reconciliation, not the converged case. This PR deliberately does **not** solve sparse event encoding or change divergent-hit policy; it may need rebasing if #57358 changes the emitter's signature.
