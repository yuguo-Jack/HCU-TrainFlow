# [Test] Make the determinism tests runnable for MLA models

[Upstream PR](https://github.com/vllm-project/vllm/pull/61105) · state: open · merged: False

## Original PR description

## Purpose

Make the existing determinism tests runnable for MLA models such as DeepSeek-V3.1 and Kimi-K2-Thinking by fixing two test setup problems:

- `test_decode_logprobs_match_prefill_logprobs` hardcodes `FLASH_ATTN`, which does not support MLA. Use `DEFAULT_BACKEND`, selecting `TRITON_MLA` when it is in `BACKENDS` and retaining `FLASH_ATTN` for the default model.
- `test_logprobs_bitwise_batch_invariance_ragged_chunked_prefill` loads the tokenizer without `trust_remote_code`, so Kimi-K2-Thinking's tokenizer cannot load. Pass `trust_remote_code=True`.
