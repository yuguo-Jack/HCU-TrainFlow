# Fix Xid 31 MMU fault in EP16 CUDA-graph replay during reduce_scatterv

[Upstream PR](https://github.com/vllm-project/vllm/pull/59646) · state: open · merged: False

## Original PR description

**Title: Fix Xid 31 MMU fault in EP16 CUDA-graph replay (reduce_scatterv)**

**Description**: Fixes #59607.

**Bug:** During CUDA graph capture (e.g., EP16 piecewise mode), pynccl.reduce_scatterv and all_gatherv bake Python-computed slice addresses (data_ptr) directly into the graph. On replay, if per-rank batch distributions change, these hardcoded pointers become stale and point to invalid memory, triggering Xid 31 MMU faults.

**Fix:**

Implemented a graph-safe fallback in cuda_communicator.py when heterogeneous sizes are detected during graph capture.
The fallback pads the inputs to the maximum size and uses uniform ncclReduceScatter/ncclAllGather (which have fixed/stable tensor addresses), safely slicing the padding away afterward.
Added safety warnings in pynccl.py to catch any future usage that might accidentally bake stale pointers into CUDA graphs.
