Although helpful for most common use cases, such a label would not be entirely correct. Specifically, Blackwell refers to _all_ SM12.0 GPUs listed here: https://developer.nvidia.com/cuda/gpus. Also, Blackwell _could_ include Blackwell Ultra, which includes other systems not mentioned (e.g. B300) making the label, Blackwell a leaky abstraction. I would recommend instead, a link to the reference documentation so users can read the latest, supported list of GPUs.
