# [Bugfix] Fix support_torch_compile positional type check off by one

[Upstream PR](https://github.com/vllm-project/vllm/pull/60214) · state: open · merged: False

## Original PR description

## Summary

Fixes the off by one error in `@support_torch_compile` decorator's positional argument type validation.

Fixes #60202

## Problem

The decorator includes `self` in the annotations list but not in the args list, causing each argument to be checked against the previous parameter's annotation.

## Solution

- Skip `self` parameter: `list(sig.parameters.values())[1:]`
- Catch `TypeError` from `isinstance()` on parameterized generics
