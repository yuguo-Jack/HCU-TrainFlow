# [ROCm][Perf][MiniMax-M3] MonoKernel: serve EAGLE3 verify steps

[Upstream PR](https://github.com/vllm-project/vllm/pull/62994) · state: closed · merged: True

## Original PR description

## Summary
`--monokernel` (MiniMax-M3 FFN MonoKernel, #62712) previously refused speculative decoding. The fused FFN launch is per-row and reads no KV cache, so EAGLE3 verify rows need only host-side changes:
- The config refusal accepts `eagle3` (all other spec methods are still refused).
- Routing drops the one-token-per-request checks: a decode step with <= 16 rows and no prefill runs fused (eager or FULL graph); larger or mixed steps run stock.
- The mono layer loop captures EAGLE3 aux hidden states.

No kernel changes and no core vLLM changes.

## Results (MI355X, TP4, MT-Bench, FULL graphs, EAGLE3 k=3)
Identical flags on both arms except `--monokernel`. Two interleaved rounds, which agreed within 0.04 ms.

| Concurrency | ITL p50 stock -> mono | Output tok/s stock -> mono | Acceptance length |
|---|---|---|---|
| 1 | 6.98 -> **6.11 ms (-12.5%)** | 383 -> **435 (+13.6%)** | 2.78 / 2.78 |
| 2 | 8.03 -> **7.25 ms (-9.7%)** | 617 -> **683 (+10.7%)** | 2.74 / 2.76 |
| 4 | 9.11 -> 9.01 ms (-1%) | 1019 -> 1028 (+0.9%) | 2.83 / 2.79 |

Above 4 requests (more than 16 verify rows), steps run stock, so behavior is unchanged.

GSM8K 5-shot (500 samples, paired): mono+EAGLE3 0.892 vs stock+EAGLE3 0.900 (-0.8 pp, 95% CI [-3.7, +2.1], McNemar p=0.69).

## Serve command
```bash
VLLM_ROCM_USE_AITER=1 VLLM_USE_BREAKABLE_CUDAGRAPH=0 VLLM_ROCM_USE_AITER_MOE=1 \
VLLM_ROCM_USE_AITER_FUSION_SHARED_EXPERTS=1 VLLM_ROCM_SHUFFLE_KV_CACHE_LAYOUT=1 \
vllm serve amd/MiniMax-M3-MXFP4 --block-size 128 --trust-remote-code \
  --compilation-config '{"cudagraph_mode":"FULL_DECODE_ONLY","cudagraph_capture_sizes":[1,2,4,8,12,16,24,32,48,64]}' \
  --tensor-parallel-size 4 --attention-backend TRITON_ATTN \
  --kv-cache-dtype fp8 --attention-config '{"indexer_kv_dtype":"fp8"}' --moe-backend aiter \
  --speculative-config '{"method":"eagle3","model":"Inferact/MiniMax-M3-EAGLE3","num_speculative_tokens":3}' \
  --monokernel   # omitted for the stock arm
```
Capture sizes in multiples of 4 are recommended: MRV2 rounds spec graph sizes to multiples of 4, so without 12, three requests pad to a 16-row graph.
