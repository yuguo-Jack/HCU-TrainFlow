# [PD] Guard bidirectional KV reuse for rewritten history

## Original PR description

## Purpose

  Fixes #43094.

  This PR guards bidirectional KV reuse in the multi-turn disaggregated proxy. The proxy now validates that the next request is the expected chat/completion continuation before
  attaching cached decode-node KV blocks to the prefill request.

  If the response contains reasoning/tool/function-call fields that the proxy cannot reconstruct exactly, it skips caching that turn and falls back to recompute on the next
  request. This prevents incorrect KV reuse when clients strip reasoning traces or rewrite assistant history between turns.

  Also updates the NIXL bidirectional transfer docs to describe the fallback behavior.

  AI assistance was used for this PR.
