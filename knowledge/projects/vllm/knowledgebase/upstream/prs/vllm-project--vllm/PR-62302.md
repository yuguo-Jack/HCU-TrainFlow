## Purpose

Routed experts return (`--enable-return-routed-experts`, used for MoE routing replay / R3 in RL trainers) has no documentation on `main`: #42434 reverted the page added in #39917. The only page online is the v0.21.0 snapshot (https://docs.vllm.ai/en/v0.21.0/training/routed_experts_replay/). It describes the reverted API (`prompt_routed_experts`, nested lists, `int16`, a `-1` sentinel for cached positions), and `latest` returns 404.

## What changes

- New `docs/training/routed_experts.md`. It covers the flag and its `AuxOutputConfig` form, the startup requirements and incompatibilities, why prefix caching is required (aux output connector), the output format for offline, `/v1/*completions` and `/inference/v1/generate`, `routed_experts_prompt_start`, and limitations.
- A link from `docs/training/rlhf.md`.
- A redirect in `mkdocs.yaml`: `training/routed_experts_replay.md` -> `training/routed_experts.md`.
