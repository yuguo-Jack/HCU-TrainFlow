# [XPU] [CI] Fix flaky get_new_cpu_stored_events in offloading connector tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/59177) · state: open · merged: False

## Original PR description

## Why

`test_fs_tiering_offloading` sometimes fails with AssertionError: No CPU stored events received. MockSubscriber.get_new_cpu_stored_events() only polls for 1s, then returns empty instead of waiting for the drain deadline. With a real fs tier, disk I/O can delay the CPU BlockStored event past 1s, causing flakiness. Test-only issue, not OffloadingConnector.

## Fix
Keep polling until _EVENT_DRAIN_TIMEOUT if no CPU stored event has been seen. After one arrives, return on the next idle poll.
