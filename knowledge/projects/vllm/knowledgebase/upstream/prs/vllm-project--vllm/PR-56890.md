# [CI] Split (H200 MIG 35GB / MI300) Model Executor into four named jobs

[Upstream PR](https://github.com/vllm-project/vllm/pull/56890) · state: closed · merged: False

## Original PR description

## What

Replace the single `model-executor` job with four named jobs that each run whole directories of `tests/model_executor`, keeping `main`'s `-m '(not slow_test)'` filter. Core is the catch-all: it runs `model_executor/` minus the directories the other three jobs own, so new tests run by default.

## Old

```text
model-executor   (H200 MIG 35GB) Model Executor  +  (MI300) mirror with its own commands
  pytest model_executor -m '(not slow_test)'
  pytest entrypoints/openai/completion/test_tensorizer_entrypoint.py
```

## New

| Key (each with an `amd-<key>` MI300 mirror) | Runs (all with `-m '(not slow_test)'`) |
| --- | --- |
| `model-executor-tensorizer` | `model_loader/tensorizer_loader` |
| `model-executor-sharded-state-weights-registry` | `model_loader/sharded_state`, `model_loader/weights`, `model_loader/registry` |
| `model-executor-reload` | `model_loader/reload`, then `entrypoints/openai/completion/test_tensorizer_entrypoint.py` |
| `model-executor-core` | `pytest model_executor --ignore=` the five directories above (catch-all) |

```text
tests/model_executor/
├── test_routed_experts_capture.py, test_sleep_mode_tensor_ownership.py, test_triton_dispatcher.py   <- Core
├── warmup/  mrope/  quantization/  models/  custom_ops/  utils/  layers/  kernels/  offloader/      <- Core
└── model_loader/
    ├── test_model_load_with_params.py, fastsafetensors/instanttensor/runai loaders                  <- Core
    ├── tensorizer_loader/                                                                           <- Tensorizer
    ├── sharded_state/test_sharded_state_loader.py, weights/, registry/                              <- Sharded State, Weights and Registry
    └── reload/test_reload.py                                                                        <- Reload
```

## Notes

- Each MI300 mirror has its own `commands` for its unit (the two exports plus its pytest lines, no `apt-get`), replacing the whole-suite mirror commands from #58607. Triggers are `main`'s list, shared through one anchor per lane.
- The 2-GPU Distributed Models job (NVIDIA, its MI300 mirror, legacy MI300 and Intel) runs `sharded_state/` with `-m 'distributed(num_gpus=2)'`, so tp=1 cases no longer run on both the 1-GPU and 2-GPU lanes. Two ROCm-only test-isolation fixes are included (Gemma hidden-act, NVFP4A16 reload skip).
- Tethering passes with and without legacy `test-amd.yaml`. The legacy MI300 job still runs `pytest model_executor` whole, and every moved path is swept (including the Intel `--deselect`).
- AI assistance was used (Claude Code); the submitter reviewed the diff.
