# [Kernel][ROCm] kv split decoding kernel for RDNA3/4

[Upstream PR](https://github.com/vllm-project/vllm/pull/58156) · state: open · merged: False

## Original PR description

## Purpose
The default decoding attention implementation for gfx1100/gfx1201 performs bad when ctx length is getting long, so a triton KV-split decoding attention for AMD RDNA3/RDNA4(gfx1100/gfx1201) is implemented to replace default 2d paged attention kernel.

## Test Plan
Test the kernel performance and numerical correctness on the gfx1100/gfx1201. 

## Test Result
Speedup (CUDA-graph timed, kernel only), batch=1, 2 KV heads:

GPU: gfx1100, model: Qwen3.8 27B, TP2 shape

ctx	unsplit	split
1024	0.038 ms	0.008	4.9×
4096	0.141	0.012	11.7×
16384	0.599	0.031	19.1×
