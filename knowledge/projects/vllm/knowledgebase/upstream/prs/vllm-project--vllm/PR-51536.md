## Original PR description

## Purpose

  Fix `MiniMAXGemmaRMSNorm` crashing on non-CUDA platforms (CPU, AWS Neuron, TPU, and any other platform where FlashInfer is unavailable).

  Closes #51200.
  
  ### Root cause

  `nvidia/model.py`'s `MiniMAXGemmaRMSNorm.forward` unconditionally imported and
  called FlashInfer's `gemma_rmsnorm` / `gemma_fused_add_rmsnorm` CUDA kernels.
  The `__init__.py` dispatcher routes every non-ROCm platform to the `nvidia/`
  package, so CPU, Neuron, and TPU all hit the FlashInfer import at forward time
  and crash with:

  RuntimeError: CUDA driver is a stub library

  ### Fix

  - **Promote shared kernels**: Move the Triton Gemma RMSNorm implementation
    (previously duplicated in `amd/ops/gemma_rmsnorm.py`) into
    `common/ops/gemma_rmsnorm.py`. The kernels are pure Triton and
    platform-neutral; the AMD file becomes a thin re-export shim.
  - **Add platform guard**: `MiniMAXGemmaRMSNorm.forward` now checks
    `x.is_cuda`. CUDA tensors take the FlashInfer fast path (behaviour
    unchanged). All other platforms fall back to the shared Triton
    implementation.

  This is complementary to PR #45881 (XPU support), which adds a dedicated
  `xpu/` package. This PR covers all remaining non-CUDA platforms without
  requiring a new per-platform package.

  ## Test Plan

  New test file: `tests/kernels/test_minimax_m3_common_ops.py`

  ```bash
  pytest tests/kernels/test_minimax_m3_common_ops.py -v

  Tests cover:
  - common/ops/gemma_rmsnorm: correctness vs fp32 PyTorch reference for plain
  norm and fused-add-residual, across shapes and dtypes (bf16, fp16)
  - Strided (non-contiguous) input handling — mirrors the qkv.split slice
  pattern used by q_norm/k_norm
  - Regression for #51200: MiniMAXGemmaRMSNorm.forward on a CPU tensor no
  longer crashes (plain and fused-residual paths)
  - AMD shim symbol identity check — ensures amd/ops still exports the same
  callable objects after the refactor

  Test Result

  Tests pass on CPU (Triton CPU backend). CUDA path is unchanged from before
  this PR — FlashInfer is still used on CUDA tensors.
