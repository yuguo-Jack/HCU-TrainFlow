# [XPU][CI] Add genai_perf to XPU test requirements 

[Upstream PR](https://github.com/vllm-project/vllm/pull/63660) · state: open · merged: False

## Original PR description

**Summary**:

Add `genai_perf>=0.0.8` to `requirements/test/xpu.in`, matching `cuda.in`. It pulls in `pytest-mock` (as on cuda/cpu/rocm); `tests/compile/test_aot_compile.py::test_partition_wrapper_applied_on_aot_load` uses the `mocker` fixture and errors on XPU without it.

`xpu.txt` is regenerated with `uv pip compile`, with the `genai-perf` transitive pins constrained to the versions in `cuda.txt`. This adds 15 packages (`genai-perf==0.0.16`, `pytest-mock==3.14.0`, `plotly==5.24.1`, `sqlalchemy==2.0.41`, ...) and leaves existing pins unchanged.

**Validation**:

Earlier run with `pytest-mock==3.14.0` installed directly: `pytest tests/compile/test_aot_compile.py -k test_partition_wrapper_applied_on_aot_load` on XPU -> 1 passed (was "fixture 'mocker' not found"). The `genai_perf`-based requirements are validated by the Intel CI image build in this PR.

AI assistance (GitHub Copilot) was used; reviewed by the submitter.
