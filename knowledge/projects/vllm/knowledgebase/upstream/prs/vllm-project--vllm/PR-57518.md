# LoRA device lookup falls through to packed weights when repacking clears weight

[Upstream PR](https://github.com/vllm-project/vllm/pull/57518) · state: closed · merged: False

## Original PR description

I hit #57503 while looking at the XPU W4A8 path. After post-load repacking the layer registers weight as None and keeps everything in weight_packed, so the LoRA wrapper crashes on None.device before it ever reaches the packed fallback.

This changes the checks in _get_lora_device to skip empty tensors instead of just checking the attribute exists. I ran a small standalone check with a weight=None plus weight_packed layer and it now resolves to the packed device, normal and GPTQ style layers still work, and ruff is clean on both touched files.
