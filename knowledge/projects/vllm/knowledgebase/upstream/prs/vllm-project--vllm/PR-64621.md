# [Perf][GDN] Use FlashInfer's regular prefill route for short batches

[Upstream PR](https://github.com/vllm-project/vllm/pull/64621) · state: open · merged: False

## Original PR description



## Overview

Pass `use_cp=False` to FlashInfer's GDN prefill for batches under 8192 prefill tokens; keep `"auto"` above. AI assistance (Claude Code) was used to prepare this PR; I reviewed every changed line.

## Claims

- FlashInfer's chunk-parallel (CP) route has a fixed ~175 µs cost per call; at TP ≥ 2 it is picked for nearly every short prefill chunk. Up to ~4k tokens the regular route is 1.4–5.7× faster per call.
- Agentic multi-turn replay, Qwen3.5-397B-A17B, TP4, 64 concurrent sessions: steady-state generation throughput +2.7%.

## Validation

Per-call time (µs), GB300, FlashInfer 0.7.2.post1, Qwen3.5-397B-A17B head counts per TP rank:

| prefill lens | TP2 auto | TP2 regular | TP4 auto | TP4 regular | TP8 auto | TP8 regular |
|---|---|---|---|---|---|---|
| 512 | 190 | 32 | 194 | 34 | 190 | 34 |
| 2048 | 177 | 67 | 182 | 66 | 185 | 66 |
| 4096 | 174 | 124 | 181 | 119 | 180 | 119 |
| 6144 | 174 | 180 | 181 | 172 | 178 | 172 |
| 8192 | 172 | 235 | 181 | 230 | 175 | 226 |

Outputs of both routes agree to bf16 precision. The existing GDN tests, which cover both routes, pass on GB300:

<summary>Benchmark script</summary>

```python
import sys

import torch
from flashinfer.gdn_prefill import chunk_gated_delta_rule

TP = int(sys.argv[1])
HV, HK, D = 64 // TP, 16 // TP, 128


def case(lens):
    T = sum(lens)
    cu = torch.tensor([0, *torch.tensor(lens).cumsum(0)], dtype=torch.int32, device="cuda")
    q = torch.nn.functional.normalize(torch.randn(T, HK, D, device="cuda"), dim=-1).bfloat16()
    k = torch.nn.functional.normalize(torch.randn(T, HK, D, device="cuda"), dim=-1).bfloat16()
    v = torch.randn(T, HV, D, device="cuda").bfloat16()
    g = torch.rand(T, HV, device="cuda") * 0.1 + 0.9
    beta = torch.rand(T, HV, device="cuda")
    s0 = torch.randn(len(lens), HV, D, D, device="cuda") * 0.01
    return q, k, v, g, beta, s0, cu


def run(a, use_cp):
    q, k, v, g, beta, s0, cu = a
    return chunk_gated_delta_rule(q=q, k=k, v=v, g=g, beta=beta, initial_state=s0,
                                  output_final_state=True, cu_seqlens=cu, use_cp=use_cp)


def timeit(fn, n=200):
    for _ in range(10):
        fn()
    torch.cuda.synchronize()
    start, end = torch.cuda.Event(True), torch.cuda.Event(True)
    start.record()
    for _ in range(n):
        fn()
    end.record()
    torch.cuda.synchronize()
    return start.elapsed_time(end) / n * 1000


for lens in ([512], [2048], [4096], [6144], [8192], [32768]):
    a = case(lens)
    print(lens, f"{timeit(lambda: run(a, 'auto')):.1f}", f"{timeit(lambda: run(a, False)):.1f}")
```
</details>

## Details

The total prefill token count is known on the host and bounds every sequence's length, so the route is chosen without a sync. 8192 is the measured crossover.
