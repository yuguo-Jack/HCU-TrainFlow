# [Doc] Document the DeepSeek-V4.1-Flash B200 AgentX profile in the guide and command builder

[Upstream PR](https://github.com/vllm-project/vllm/pull/62541) · state: closed · merged: True

## Original PR description

## Overview

Document the B200 vLLM AgentX lane from [SemiAnalysisAI/InferenceX#3837](https://github.com/SemiAnalysisAI/InferenceX/pull/3837) (head `d2d90439`, [run 38438383633](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/38438383633)) in `recipes/models/deepseek-ai/DeepSeek-V4.1-Flash.yaml`, in both the guide and the command builder. Supersedes vllm-project/recipes#1106 (recipes moved here in #61302).

## Claims

- **Guide** (under **AgentX tuning on NVIDIA GPUs**): all 17 qualified points. TP4 c1–c128 (per-point `--max-num-seqs`, batched tokens 4096/8192, capture 4092/8190, decode-replay graphs from c16); TP2 c1; DEP2 c8–c32 (`--max-num-seqs` per DP rank 16/32, capture 576 at c8/c16, 4096 graphs and `--prefill-schedule-interval 64` at c24/c32); DEP4 c64–c128 (8192 batched tokens, capture 8190, interval 48 at c96/c128); DEP2 host KV at c64/c128 (32 GiB native offload per DP rank, 0.955, `--max-num-seqs 48` per rank, interval 1, capture 576).
- **Command builder** (B200 only): Tensor Parallel renders the TP2 c1 settings (FlashInfer autotune, 0.97, V2 runner, THP Engram). Data + Expert Parallel renders the DEP2 c24/c32 engine settings (FlashInfer sparse MLA, autotune + MegaMoE, Engram in host memory with embedding across DP, 0.97, V2 runner).
- The guide's builder pointer names the 0909 checkpoint the lane used, the opt-in Speculative decoding and Text only toggles, and the DP size to pin (with the router's `--intra-node-data-parallel-size`).
- The **Blackwell TP and DEP** section notes the B200 exception.

## Validation

- Builder renders compared against the run's launch lines: Tensor Parallel matches TP2 c1 flag for flag; Data + Expert Parallel matches DEP2 c24 except `--data-parallel-size` (the builder's single-node DEP spans the node; the guide says to pin 2 or 4).
- Rendered every hardware x strategy x feature selection: only B200 Tensor Parallel and Data + Expert Parallel change (16 of 1848 renders).
- `node scripts/validate-source.mjs --source vllm --dir <this checkout>/recipes` passes; merges cleanly with the B300 follow-up to #62561.

## Details

Per-concurrency values stay in the guide because the builder renders one preset per strategy. The speculative-decoding feature keeps the shared NVIDIA default (no B200-specific override). Excluded as InferenceX harness only: synthetic acceptance, AIPerf/trace replay, Slurm and telemetry.
