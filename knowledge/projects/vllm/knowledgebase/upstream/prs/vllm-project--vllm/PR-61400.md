[Upstream PR](https://github.com/vllm-project/vllm/pull/61400) · state: closed · merged: False

## Original PR description



## Summary

This PR refactors the FA version validation logic in [vllm/vllm_flash_attn/flash_attn_interface.py](vllm/vllm_flash_attn/flash_attn_interface.py) by replacing the repeated version-specific checks with a centralized mapping table.

The goal is to make validation and unsupported-reason lookup easier to extend and easier to read without changing the current behavior of the FA support checks.

## What changed

- Added a `_FA_SUPPORT_CHECKS` mapping from FA version to its validation helper
- Kept the same validation semantics for FA2, FA3, and FA4
- Reused the same mapping in:
  - `is_fa_version_supported`
  - `fa_version_unsupported_reason`

## Why

The previous logic repeated the same pattern for each supported FA version. This refactor makes the code easier to maintain and reduces the chance of drift when adding future FA versions.
