# [Security] Contain Sentence Transformers module files

[Upstream PR](https://github.com/vllm-project/vllm/pull/61430) · state: open · merged: False

## Original PR description

## Overview

Sentence Transformers `modules.json` could direct Pooling and Dense module loaders to files outside a local model directory. Validate each module path before reading configuration or weights, including resolved symlink targets.

## Changes

- Add a shared module-file path check for Pooling and Dense configuration reads.
- Apply the same check to Dense `model.safetensors` and `pytorch_model.bin` reads.
- Propagate invalid-path errors through projector construction so loading fails closed.
- Cover absolute paths, parent traversal, directory and file symlinks, malformed path types, and valid local weights.

## Codepath coverage

The check covers pooling detection, Dense configuration loading, and Dense projector weight loading. These startup paths are shared by embedding and pooling serving routes, including `/v1/embeddings`, `/invocations`, and `/pooling`, and by offline pooling.

## Duplicate-work check

Reviewed open and merged PRs touching the same loaders and related Sentence Transformers behavior, including #55359, #60978, #60750, #60825, #54533, #33720, and #53555. None adds containment at these module file reads. A fresh open-PR search before submission found no overlapping fix.

## Validation

- Focused tests: 25 passed, 449 deselected on macOS with `--noconftest` (the repository's global test cleanup segfaults on this host). The selection includes existing schema tests and new rejection and valid-loading tests.
- Changed-file pre-commit hooks: passed.
- Full-file pre-commit run: existing platform-specific mypy and nonroot-entrypoint failures on macOS, unrelated to changed files.
- The submitting human confirmed line review and the requested Linux served-PoC validation. Quantitative model evaluation results were not provided; this change rejects invalid model files before inference and does not alter output for valid models.

## Details

The module folder was previously joined to `config.json` or a weight filename and passed to file-loading helpers. The shared helper rejects absolute paths, parent traversal, and non-string folders. For local models, it also resolves the complete target path and rejects targets outside the model directory, including a symlinked final file. A dedicated exception passes through the existing broad loader exception handlers.

AI assistance was used to prepare this change.
