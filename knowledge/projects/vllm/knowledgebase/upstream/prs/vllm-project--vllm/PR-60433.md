# [BugFix] Keep newlines in Olmo3 tool-call arguments

[Upstream PR](https://github.com/vllm-project/vllm/pull/60433) · state: open · merged: False

## Original PR description

Fixes #60421

`Olmo3PythonicToolParser` joined every non-empty line with `", "`. That turned newlines inside a string into commas, and it turned a call written across several lines into invalid Python, so the call came back as plain text.

Newlines now separate calls only when they are outside string literals and brackets. A pretty-printed call stays one call, and a triple-quoted string keeps its newlines. A regex miss still falls through to `ast.parse`, so a call the old pattern skipped is accepted when it is a list of calls.

`tests/tool_parsers/test_olmo3_tool_parser.py`: 28 passed.
