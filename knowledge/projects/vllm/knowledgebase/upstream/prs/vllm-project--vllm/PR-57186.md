# [Rust Frontend] Support chat completion output logging

[Upstream PR](https://github.com/vllm-project/vllm/pull/57186) · state: open · merged: False

## Original PR description

## Purpose
Add Python-compatible chat completion output logging to the Rust Frontend:

  - Support `--enable-log-outputs` and `--no-enable-log-outputs`.
  - Support `--enable-log-deltas` and `--no-enable-log-deltas`.
  - Log non-streaming outputs, streaming deltas, and completed streaming outputs.
  - Include reasoning and tool calls.
  - Require `--enable-log-requests` for output logging.

## Test Plan

```
cargo test --manifest-path rust/src/server/Cargo.toml output_logging
cargo test --manifest-path rust/src/cmd/Cargo.toml output_logging
cargo fmt --manifest-path rust/src/cmd/Cargo.toml --all -- --check
```

## Example
The only controlled-text difference is Python single quotes (") versus Rust double quotes ('):

#### Case 1: --enable-log-outputs --enable-log-deltas
Python output:
```
Generated response: output: 'The capital of France is Paris.', finish_reason: stop
Generated response (streaming delta): output: 'The', finish_reason: None
Generated response (streaming delta): output: ' capital', finish_reason: None
Generated response (streaming delta): output: ' of', finish_reason: None
Generated response (streaming delta): output: ' France', finish_reason: None
Generated response (streaming delta): output: ' is', finish_reason: None
Generated response (streaming delta): output: ' Paris', finish_reason: None
Generated response (streaming delta): output: '.', finish_reason: None
Generated response (streaming complete): output: 'The capital of France is Paris.', finish_reason: streaming_complete
```

Rust output:
```
Generated response: output: "The capital of France is Paris.", finish_reason: stop
Generated response (streaming delta): output: "The", finish_reason: None
Generated response (streaming delta): output: " capital", finish_reason: None
Generated response (streaming delta): output: " of", finish_reason: None
Generated response (streaming delta): output: " France", finish_reason: None
Generated response (streaming delta): output: " is", finish_reason: None
Generated response (streaming delta): output: " Paris", finish_reason: None
Generated response (streaming delta): output: ".", finish_reason: None
Generated response (streaming complete): output: "The capital of France is Paris.", finish_reason: streaming_complete
```

#### Case 2: --enable-log-outputs --no-enable-log-deltas
Python output:
```
Generated response: output: 'The capital of France is Paris.', finish_reason: stop
Generated response (streaming complete): output: 'The capital of France is Paris.', finish_reason: streaming_complete
```

Rust output:
```
Generated response: output: "The capital of France is Paris.", finish_reason: stop
Generated response (streaming complete): output: "The capital of France is Paris.", finish_reason: streaming_complete
```
