# [Security] Strip uppercase hex addresses from client error messages

[Upstream PR](https://github.com/vllm-project/vllm/pull/56728) · state: closed · merged: False

## Original PR description

## Summary
Client-facing error sanitization strips CPython object-repr memory addresses, but the hex character class was lowercase-only. Pillow formats `id()` with uppercase hex, so those addresses were returned to clients unchanged. This widens the character class so both cases are stripped.

## Changes
- `vllm/entrypoints/serve/exception_handling/utils.py`: match uppercase hex in the address sanitizer.
- `tests/entrypoints/serve/exception_handling/test_error_sanitization.py`: cover uppercase literals, a live Pillow `repr()`, and a processor-failure message that interpolates a real image.

## Codepath coverage
- All HTTP paths that use `create_error_response()` (`/tokenize`, `/v1/chat/completions`, `/invocations`, Anthropic `/v1/messages`, render/derender, SageMaker, and the global exception handlers).
- Direct `sanitize_message()` callers: Anthropic streaming errors, speech-to-text WebSocket errors, Cohere router/serving, HTTPException and validation-error handlers.
- There is a single sanitizer definition; widening it covers every caller.

## Duplicate-work check
Searched open and merged PRs for `sanitize_message`, error sanitization, and `exception_handling/utils`. Open #52120 tightens a different (path) regex for ReDoS and does not change the address pattern. Open #35492 adds a Responses WebSocket transport that calls the existing sanitizer. Merged #45119 applied the sanitizer to Anthropic and STT error paths without widening the hex class. No open or merged PR closes this gap.

## Tests
- `test_address_stripped[pil-image-repr]`: uppercase Pillow-style repr is stripped.
- `test_strips_address_from_live_pil_image_repr`: real `repr(Image)` with A–F hex digits is stripped.
- `test_strips_address_from_processor_failure_message`: interpolated live image in a processor failure string is stripped.
- Existing lowercase BytesIO cases still pass.
