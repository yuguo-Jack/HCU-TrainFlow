# [ROCm][CI] Raise MI300 Core Operation Kernels timeout to 90 min

[Upstream PR](https://github.com/vllm-project/vllm/pull/63760) · state: closed · merged: True

## Original PR description

## Purpose
`:amd: (MI300) Core Operation Kernels` timed out at the 45 min limit on every attempt in [ci#97263](https://buildkite.com/vllm/ci/builds/97263) and [ci#97107](https://buildkite.com/vllm/ci/builds/97107). 
#61862 moved this mirror to `automatic_shard: true` but kept the 45 min timeout of one fixed shard. When the pipeline generator can't fetch main's timings, which happened in both builds, the step runs as one unsharded job, and a full run on MI300 takes about 70 min.
This PR raises `timeout_in_minutes` for the AMD mirror from 45 to 90, so that fallback completes.
