## Validation: kernel breakdown

Kimi-K3 on 8x MI355X, 32k input / 32 output, concurrency 32, TP8 + DCP8, 
Both traces show the same step type: a mixed prefill step with one 7,680-token prompt chunk and 3 spec decodes (15 tokens).

Compare the copy kernels only. Other kernel times differ with the weights.

### KDA layer: 20 → 12 kernels

| # | Before | µs | After | µs |
|---|---|---:|---|---:|
| 1 | in_proj GEMM (FlyDSL FP8) | 294.3 | in_proj GEMM (FlyDSL FP8) | 287.2 |
| 2 | f_b_proj GEMM | 21.0 | f_b_proj GEMM | 22.6 |
| 3 | `index_select` q,k,v spec rows | 8.6 | **removed** | |
| 4 | `index_select` g spec rows | 10.6 | **removed** | |
| 5 | `index_select` beta spec rows | 5.2 | **removed** | |
| 6 | `vectorized_gather` q,k,v prompt rows | 24.7 | **removed** | |
| 7 | `vectorized_gather` g prompt rows | 12.6 | **removed** | |
| 8 | `_scatter_gather` beta prompt rows | 5.4 | **removed** | |

### GLA (MLA) layer with DCP: 29 → 27 kernels

Only the decode query path changes. The other 24 kernels are the same.

| Before | µs | After | µs |
|---|---:|---|---:|
| NCCL all-gather (decode q) | 28.3 | NCCL all-gather (decode q) | 29.2 |
| copy: rank-major → token-major | 5.8 | one strided copy into 128-head storage | 5.7 |
| copy: `repeat` to pad 96 → 128 heads | 6.3 | **removed** | |
| copy: `contiguous` | 4.1 | **removed** | |
| MLA decode (asm cprr) | 35.8 | MLA decode (asm cprr), reads the padded storage as a view | 35.8 |

**Removed per GLA layer: 2 copy kernels, 10.5 µs** (16.2 → 5.7 µs).
