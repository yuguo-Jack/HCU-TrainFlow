# [Bugfix][Kernel] Fix cooperative top-k dispatch on SM110

[Upstream PR](https://github.com/vllm-project/vllm/pull/56102) · state: closed · merged: True

## Original PR description


## Purpose
On Jetson AGX Thor (SM110), the QSA top-k dispatcher selects `cooperative_topk` because SM110 satisfies `has_device_capability(90)`. The cooperative kernel requests a 16-block cluster, but Thor supports a maximum cluster dimension of eight, causing model warmup to fail.

Exclude SM110 from the cooperative path so it uses the existing `persistent_topk` fallback.

## Test Plan
Manually reproduced the cooperative top-K launch failure on Jetson AGX Thor (SM110) on Qwen3.8 Next Flash and verified successful server startup and inference with the persistent top-K fallback.
