```python
      torch.testing.assert_close(
            torch.tensor(vllm_scores, device=reference_scores.device),
            expected_scores,
            atol=2e-2,
            rtol=2e-2,
        )
```

we can adjust that to whatever strictness you want. 

Let's decide on the oracle first and I can propagate the changes to similar instances in the pr.
