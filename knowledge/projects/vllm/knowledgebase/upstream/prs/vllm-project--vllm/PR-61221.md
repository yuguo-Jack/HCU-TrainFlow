# [Bugfix][Kimi-K3] Cover persistent scheduling in vision FA4 warmup

[Upstream PR](https://github.com/vllm-project/vllm/pull/61221) · state: open · merged: False

## Original PR description

Kimi-K3 vision warmup deduplicates FA4's persistent and nonpersistent variants, leaving some image requests to compile kernels during inference. Include `is_static_persistent` in the warmup key and probe the 257-token boundary.

Validation: `pytest tests/models/kimi_k3/test_vision_fa4_warmup.py -q` produced **two baseline failures and two patched passes** on B300 with a v0.30.0 overlay. The cases exercise the vision-attention wrapper and compare outputs against float32 SDPA. Affected source and tests are unchanged after rebase; pre-commit hooks passed. Full-model startup/latency and a connection to production hangs remain unverified.

No equivalent open fix found (October 13); #48156 and #50760 target other warmup providers.
