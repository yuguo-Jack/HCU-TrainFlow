[Upstream PR](https://github.com/vllm-project/vllm/pull/45511) · state: open · merged: False

## Original PR description

## Purpose

Partially addresses #39613.

This PR fixes two documentation drift items from the docs audit:

- Removes `best_of` from the feature and hardware compatibility matrices because the V1 guide documents `best_of` as removed in vLLM V1.
- Clarifies environment variable docs so they no longer state that every environment variable read by vLLM is `VLLM_`-prefixed, and documents that `VLLM_PORT` seeds internal port allocation rather than configuring the API server port.
