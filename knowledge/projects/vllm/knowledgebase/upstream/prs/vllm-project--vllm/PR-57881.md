# [BreakableCG] Add eager break for Mamba-family ops

[Upstream PR](https://github.com/vllm-project/vllm/pull/57881) · state: closed · merged: True

## Original PR description




## Purpose
Add eager break for Mamba-family ops under breakable CUDA graphs

Ops listed in `CompilationConfig._attention_ops` are excluded from CUDA graphs via FX graph splitting. That only works under `torch.compile`.

This PR applys these splitting into breakable cudagraph.

- zhenwei-intel · comment · 2026-10-09T03:29:17Z · [source](https://github.com/vllm-project/vllm/pull/57881#issuecomment-6073682249)

> Why we need to add this?

With `torch.compile` + PIECEWISE, ops in `CompilationConfig._attention_ops` (including `mamba_mixer`, `mamba_mixer2`, `short_conv`, `linear_attention`, `olmo_hybrid_gdn_full_forward`) are used as splitting ops, so they run eagerly outside the cudagraph.

Under breakable graph, these ops will be captured, causing mamba models failure issues. This PR adds `@eager_break_during_capture` to these ops so the breakable path matches the existing PIECEWISE behavior.
