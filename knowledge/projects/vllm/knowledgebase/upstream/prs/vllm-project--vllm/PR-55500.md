**Remove `+` list-element option forms when replacing a nested parameter.**

`FlexibleArgumentParser` accepts `--compilation-config.cudagraph_capture_sizes+` as an individual list element. This candidate set does not include the `+` form, so a sweep override leaves stale list elements in the generated command and then adds the normalized replacement value.

Add `+` variants for nested parameter candidates. Add a regression case with spaced and inline `+` values.
