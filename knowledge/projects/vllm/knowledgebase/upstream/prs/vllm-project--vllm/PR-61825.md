# [Bugfix][Frontend] Reject Cohere REQUIRED tool choice without tools

[Upstream PR](https://github.com/vllm-project/vllm/pull/61825) · state: closed · merged: True

## Original PR description



## Overview

Reject Cohere Chat v2 requests that select `tool_choice="REQUIRED"` without a nonempty tools list, as required by the [Cohere specification](https://docs.cohere.com/reference/chat). Both chat and render endpoints now return a Cohere-shaped HTTP 400 before downstream processing.

## Claims

- Reject omitted, null and empty `tools` when tool choice is REQUIRED.
- Preserve valid required-tool requests and existing behavior for NONE or unspecified tool choice.

## Details

The Cohere request model checks the tool-choice enum but lacks cross-field validation. Conversion constructs a shared `ChatCompletionRequest` before assigning tools and tool choice, bypassing its construction-time invariant. With no tools, rendering parameters then discard the requested tool choice. Add the check to the Cohere request model using the existing `VLLMValidationError` path.

Minimal baseline reproduction, without model weights:

```python
from vllm.entrypoints.cohere.protocol import CohereChatV2Request

CohereChatV2Request(
    model="m",
    messages=[{"role": "user", "content": "Use a tool."}],
    tool_choice="REQUIRED",
)
```

Upstream `9cede34a6` accepts this input, converts the choice to `"required"`, and then produces rendering parameters with `tool_choice=None`. This change raises `VLLMValidationError(parameter="tool_choice")` during request parsing. The same before/after behavior was verified for explicit null and empty tools.

Searches of open, closed and merged PRs on 2026-10-15 found no matching fix. Related [#52467](https://github.com/vllm-project/vllm/pull/52467) standardizes existing validation errors, [#60309](https://github.com/vllm-project/vllm/pull/60309) maps handler exceptions to client error responses, and [#60586](https://github.com/vllm-project/vllm/pull/60586) fixes JSON-schema forwarding; none adds this cross-field validation.
