# [Model] Warn when D3 checkpoints use a generation architecture override

[Upstream PR](https://github.com/vllm-project/vllm/pull/62845) · state: open · merged: False

## Original PR description

## Summary

Add a warning when a D3 code-readout checkpoint is configured with
`Qwen3_5ForConditionalGeneration`.

This architecture selects the generic generation path rather than native D3
classification. The warning explains that users should remove an explicit
architecture override to allow native D3 detection.

## Changes

- Detect `decision_config.json` with format ID `d3-code-readout-v1` when the
  configured architecture is `Qwen3_5ForConditionalGeneration`.
- Warn about the generation architecture override without changing the
  explicitly configured architecture.
- Add tests for the warning, unrelated or malformed decision configs, native
  D3 detection, and Clef detection precedence.

## Scope

This change adds a diagnostic warning only. It does not change model
selection, inference behavior, GDN kernels, or D3 scoring.
