# [Model] Add native support for Lfm2BidirectionalModel

[Upstream PR](https://github.com/vllm-project/vllm/pull/62201) · state: open · merged: False

## Original PR description



## Overview

Add initial PyTorch-native support for [Lfm2BidirectionalModel](https://huggingface.co/LiquidAI/LFM2.5-Embedding-350M) with minimal changes to the existing LFM2 implementation. 

Implement noncausal short conv over packed sequences, with request-boundary and padding
masking, encoder-only attention, and CLS pooling.
