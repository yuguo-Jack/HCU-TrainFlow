# [Build][CUDA] Raise CUDA compiler version gates for cooperative_topk (12.8) and DeepGEMM (12.9)

[Upstream PR](https://github.com/vllm-project/vllm/pull/65511) · state: open · merged: False

## Original PR description



## Overview

Fixes the stale CMake CUDA compiler gates reported in #65440 to prevent source build failures when targeting CUDA 12.6.

## Claims

- Raises `cooperative_topk` CUDA compiler gate from 12.0 to 12.8, matching CCCL async-bulk and mbarrier API requirements.
- Raises DeepGEMM SM90 CUDA compiler gate from 12.3 to 12.9, matching `compatibility.hpp` static assertions.

## Validation

- On CUDA compiler versions < 12.8, `cooperative_topk` is bypassed cleanly instead of raising CCCL overload errors.
- On CUDA compiler versions < 12.9, DeepGEMM gracefully falls back to the stub `_deep_gemm_C` target instead of failing the static assertion.

## Details

1. `csrc/cooperative_topk.cuh` invokes `cuda::ptx::mbarrier_try_wait_parity` and `cuda::ptx::cp_async_bulk`, introduced in CUDA 12.8 CCCL. The existing gate of 12.0 caused build failures on CUDA 12.6.
2. DeepGEMM's `csrc/utils/compatibility.hpp` static-asserts `CUDA_VERSION >= 12090`. Raising the CMake gate from 12.3 to 12.9 ensures the stub target is selected on CUDA < 12.9.
