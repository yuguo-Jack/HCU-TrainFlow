## Overview

Format tensor shapes and array indexing as inline code in three MiniMax-M3 AMD docstrings, fixing the seven unresolved cross-references that abort strict API documentation builds.

Fixes #64469. The [failing Read the Docs build](https://app.readthedocs.org/projects/vllm/builds/35491049/) contains the original warnings.

## Claims

- Render the shapes and indexing literally, avoiding unintended `head`, `:n`, and `r` cross-references.
- Keep the change to three docstrings; the AST is identical after removing docstrings.
