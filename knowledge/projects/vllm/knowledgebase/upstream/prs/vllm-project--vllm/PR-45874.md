# [Misc] Add test suite for PoolsideV1ReasoningParser

[Upstream PR](https://github.com/vllm-project/vllm/pull/45874) · state: closed · merged: False

## Original PR description

---
## Summary
- Adds a hermetic, CPU-only pytest suite for `PoolsideV1ReasoningParser`
  (`vllm/reasoning/poolside_v1_reasoning_parser.py`), which previously had
  no test coverage.
- Pins the override contract that distinguishes this parser from its
  parent `DeepSeekV3ReasoningParser`: a reverse-walk `is_reasoning_end`
  that stops at the most recent `<assistant>` token, preventing a stale
  `</think>` from a prior assistant turn from registering as the current
  turn's reasoning end.

## Motivation
`PoolsideV1ReasoningParser` overrides `is_reasoning_end` to scope the
backward walk to the current assistant turn. Without coverage, a future
refactor of the base reasoning parsers (or a change to the dispatch in
`DeepSeekV3ReasoningParser`) could silently regress the override and
produce false positives in multi-turn conversations. The tests pin the
behavior with a minimal in-process fake tokenizer so they require no
network and run on CPU only.

## Changes
- New file: `tests/reasoning/test_poolside_v1_reasoning_parser.py` (10 tests).
  Covers: registry resolution of `"poolside_v1"`; constructor `ValueError`
  when the tokenizer vocab is missing `<assistant>`; inner-parser dispatch
  via `chat_template_kwargs={"thinking": True/False}`; reverse-walk
  semantics (end-after-assistant True, start-before-end False, no markers
  False, empty input False); the scoping contract (stale `</think>` before
  a more recent `<assistant>` returns False); identity-parser branch
  always returns True.
- No production source changes.

## Test Plan
- `pytest tests/reasoning/test_poolside_v1_reasoning_parser.py -v` — 10
  passed locally on a CPU-only box (teardown `RuntimeError: Cannot access
  accelerator device` from the global cleanup fixture is environmental
  and unrelated to the suite).
- `pre-commit run --files tests/reasoning/test_poolside_v1_reasoning_parser.py`:
  all hooks pass (ruff, ruff-format, mypy, SPDX, typos, etc.).

## Test Result
