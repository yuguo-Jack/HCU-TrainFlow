# [Feature] Support Eagle3 speculative decoding with Pipeline Parallelism

[Upstream PR](https://github.com/vllm-project/vllm/pull/45985) · state: closed · merged: False

## Original PR description




## Purpose

Enable **Eagle3 speculative decoding to work with Pipeline Parallelism (PP > 1)**. Currently, when the target model is split across pipeline stages, auxiliary hidden states (collected from layers 2, N/2, N-3) residing on non-last PP ranks are silently discarded — the drafter receives fewer aux states than expected and `combine_hidden_states` fails with a k-axis shape mismatch.

This PR adds **centralized PP aux propagation via forward hooks**, requiring **zero changes to any model forward methods**. It works for all Eagle3-capable models (Llama, Qwen2, Qwen3MoE, DeepseekV2, MiniMaxM2, GPT-OSS, Gemma4, etc.).

**Root cause:** Every Eagle3-capable model's `forward` returns `IntermediateTensors({"hidden_states", "residual"})` on non-last PP ranks (e.g. `llama.py:425-428`, `deepseek_v2.py:1319-1322`), dropping locally-collected aux states. There is no mechanism to carry aux states across PP stages.

**Solution:** A single utility module (`eagle3_pp_utils.py`) that:
1. Registers `forward_hook` on decoder layers to capture aux states (uniform across all models since all vLLM decoder layers return `(hidden_states, residual[, ...])`)
2. Wraps `forward` to pack/unpack aux states via `aux_layer_{i}` keys in `IntermediateTensors`
3. Wraps `make_empty_intermediate_tensors` to pre-allocate placeholders for incoming aux states

Changes:
- `interfaces.py`: Add `AUX_HIDDEN_STATE_TENSOR_PREFIX` constant + `extract_aux_hidden_states()` helper
- `eagle3_pp_utils.py` (new): `install_eagle3_pp_aux_propagation()` — hook + wrapper installation
- `gpu_model_runner.py`: Extend aux layer configuration to **all PP ranks** (not just last); add `_eagle3_uses_aux_hidden_state()` rank-independent check + `_configure_eagle3_pp_aux_for_non_last_rank()`

Non-invasive: PP=1 and non-Eagle3 code paths are completely unaffected (the wrapper returns early when `world_size == 1`).

## Test Plan

Unit tests added in `tests/v1/spec_decode/test_eagle3_pp_aux.py` (25 cases, 8 test classes). Run with:

```bash
.venv/bin/python -m pytest tests/v1/spec_decode/test_eagle3_pp_aux.py -v
```

Test coverage:
- `extract_aux_hidden_states`: None/empty/single/multiple/non-sequential indices
- Install guards: PP=1 skip, no-aux skip, idempotency, valid install
- Forward wrapper (non-last rank): aux packed into IntermediateTensors, hidden_states preserved
- Forward wrapper (last rank): incoming + local aux merge, no-incoming edge case
- `make_empty_intermediate_tensors` wrapper: first rank / non-first rank / all-local
- **Simulated PP=2 end-to-end aux flow**: rank 0 packs → rank 1 receives & merges
- Hook edge cases: aux_layer 0 skip, 3-element output (HunYuan), PPMissingLayer not hooked
- `_eagle3_uses_aux_hidden_state`: rank-independent config check

All tests use mocked `get_pp_group` + dummy decoder layers; no real multi-GPU hardware required.

## Test Result

Core logic verified via standalone scripts:
- `extract_aux_hidden_states` sorting/packing: all 5 cases pass
- PP=2 simulated aux flow (6-layer model, aux_layers=(2,4)): rank 0 captures 1 aux (value=2.0), rank 1 receives 1 + captures 1, drafter gets 2 aux states

```text
Rank 0 packed 1 aux states
  aux_layer_0 value (layer 1 output): 2.0
Rank 1 received 1 incoming aux, captured 1 local aux
  Total aux for drafter: 2
  aux[0] (from rank 0, layer 1): 2.0
  aux[1] (from rank 1, layer 3): 12.0
PP=2 aux flow simulation PASSED!
```
