# [Docs] Update SPEED-Bench preparation script documentation

[Upstream PR](https://github.com/vllm-project/vllm/pull/65382) · state: open · merged: False

## Original PR description



## Overview

SPEED-Bench preparation script is migrating from [Nemo Skills](https://github.com/NVIDIA-NeMo/Skills) to [Nemo Gym](https://github.com/NVIDIA-NeMo/gym). This PR updates the documentation for the updated preparation script.

## Claims

* New script prepare the splits the same format as the previous script.
* New v1.1 data still works with vllm bench.


## Validation

1. Tried to run the one-liner for downloading the data: `curl -LsSf https://raw.githubusercontent.com/NVIDIA-NeMo/Gym/refs/heads/main/benchmarks/speed-bench/prepare.py | python3 - --format raw --config all`: data was created as expected with the same format.
2. After that, successfully ran the example in the docs: 
```bash
vllm serve meta-llama/Llama-3.3-70B-Instruct \
    --speculative-config $'{"method": "eagle3",
    "num_speculative_tokens": 3,
    "model": "nvidia/Llama-3.3-70B-Instruct-Eagle3"}'
```

```bash
vllm bench serve \
    --model meta-llama/Llama-3.3-70B-Instruct \
    --dataset-name speed_bench \
    --dataset-path "<YOUR_DOWNLOADED_PATH>/data/speed_bench" \
    --num-prompts -1
```



## Details

SPEED-Bench preparation script is moving repositories, and is going to be maintained only in the Gym repo, hence the documentation update is needed.
