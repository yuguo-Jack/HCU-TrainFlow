# [ROCm] Add AITER RoPE+KV cache and dual RMSNorm fusion for MLA

[Upstream PR](https://github.com/vllm-project/vllm/pull/41099) · state: closed · merged: False

## Original PR description

## Summary

This PR adds AITER's fused RoPE + KV cache kernels for DeepSeek MLA models on AMD ROCm. Combines RoPE application, KV cache writes, and dual RMSNorm into optimized fusion paths.

### Key Features
- **Fused Dual RMSNorm**: Uses AITER's `fused_qk_rmsnorm` 
- **Fused RoPE + KV Cache (Prefill)**: Single kernel for RoPE and cache write
- **Fused BMM + RoPE + KV Cache (Decode)**: Combines matmul, RoPE, and cache write
- **FP4 and FP8 Support**: Separate optimized kernels for both quantization formats

### AITER Kernels Used
- `fused_qk_rmsnorm` - Dual RMSNorm fusion
- `fused_qk_rope_cat_and_cache_mla` - RoPE + KV cache (prefill)
- `fused_fp4_bmm_rope_cat_and_cache_mla` - FP4 BMM + RoPE + KV cache (decode)
- `fused_fp8_bmm_rope_cat_and_cache_mla` - FP8 BMM + RoPE + KV cache (decode)

### Testing

Verified on GSM8K benchmark with DeepSeek-V3:
```bash
export VLLM_ROCM_USE_AITER=1
export VLLM_USE_AITER_FUSED=1
export HIP_VISIBLE_DEVICES=0,1,2,3,4,5,6,7

lm_eval \
  --model vllm \
  --model_args "pretrained=deepseek-ai/DeepSeek-V3,tensor_parallel_size=8,max_model_len=8192,max_num_batched_tokens=131072,gpu_memory_utilization=0.9,dtype=bfloat16,kv_cache_dtype=fp8,trust_remote_code=true" \
  --tasks gsm8k \
  --num_fewshot 5 \
  --batch_size auto \
  --limit 500
```
