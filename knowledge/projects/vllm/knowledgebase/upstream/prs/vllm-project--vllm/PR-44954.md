# Fix DP drafter hang near max model length

[Upstream PR](https://github.com/vllm-project/vllm/pull/44954) · state: open · merged: False

## Original PR description

## Purpose

Fixes #44185.

This PR fixes a vLLM hang during MTP speculative decoding with DP + EP near
`max_model_len`.

A similar issue has already been fixed in `vllm-ascend`. This PR applies the fix
to the main vLLM code path.

While verifying this issue on the latest vLLM main branch, Qwen3.5-35B-A3B model
loading failed due to a separate Qwen3.5 MoE expert weight mapping regression.
That loading issue is fixed separately in #44953. After applying the loader fix,
the original DP + EP + MTP hang could be reproduced and verified on the latest
vLLM code.

When serving a MoE model such as Qwen3.5-35B-A3B with data parallelism, expert
parallelism, and MTP speculative decoding enabled, the server can hang after the
client request has already returned `200 OK`.

The issue can be reproduced with:

```bash
vllm serve /root/autodl-tmp/models/Qwen3.5-35B-A3B/ \
  --max-model-len 2048 \
  --max-num-batched-tokens 256 \
  --trust-remote-code \
  --enable-expert-parallel \
  --data-parallel-size 2 \
  --speculative_config '{"method":"mtp", "num_speculative_tokens":3}' \
  --enforce-eager
```

Then send a request whose sequence length is close to `max_model_len`.

Before this fix, the client may receive a successful response, but the server
keeps printing messages such as:

```text
No available shared memory broadcast block found in 60 seconds. This typically
happens when some processes are hanging or doing some time-consuming work
```

When a request is close to `max_model_len`, one DP rank may set
`input_fits_in_drafter=False` and skip the drafter path. However, another DP rank
may still enter the drafter path, for example through a dummy run. With an MoE
drafter, this can desynchronize collective communication across ranks and cause a
deadlock.

This PR synchronizes the drafter-run decision across DP ranks before entering the
drafter path. If any DP rank cannot run the drafter for the current step, all DP
ranks skip the drafter for that step.
