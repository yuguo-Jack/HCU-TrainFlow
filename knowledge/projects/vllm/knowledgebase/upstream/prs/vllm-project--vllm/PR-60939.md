# Fail fast on oversized multimodal encoder inputs

[Upstream PR](https://github.com/vllm-project/vllm/pull/60939) · state: closed · merged: False

## Original PR description

Fixes #60819. A multimodal request with one uncached encoder input larger than the per-step encoder capacity can never be scheduled, but the scheduler previously deferred it forever. Detect this impossible admission before scheduling, finish the request with an error, and log the input size and capacity. Adds a scheduler regression test.
