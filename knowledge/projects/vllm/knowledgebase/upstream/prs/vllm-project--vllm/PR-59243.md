## Purpose

Add experimental DP2×TP1 ⇄ DP1×TP2 reconfiguration at drained rollout/update boundaries on a fixed two-GPU pool. Rebuild TP-dependent state and load a complete native IPC checkpoint while preserving EngineCore, workers, PIDs, and the bootstrap world.

Initial scope: offline `external_launcher`, dense BF16 Llama, eager MRV2, and unpacked IPC. This remains a development draft with upstream integration coverage and broader model evaluation pending.

Related #44994 changes DP/EP with fixed TP. This PR adds TP layout changes and full refit. The pre-submission search found no equivalent open PR.

Additional validation covered IPC/reload regressions, repository static checks, and local two-GPU transition/refit tests.

## Test Result

- CPU regression selection: 74 tests and 5 subtests passed. All 16 applicable static checks passed.
- Tiny Llama GPU tests passed for prepare/cancel, repeated transitions and weight updates, rejection and failure paths, process identity, and disk reload.
- Tied and untied models each completed 10 round trips with no observed memory growth after warmup. Maximum HF logprob error across the GPU checks was below 0.016 against a 0.03 tolerance.

Long-loop tests used explicit KV budgets. Automatic profiling, custom all-reduce and prefix-cache hits were checked separately. The GPU harness is currently local, and pretrained model evaluation remains pending.

AI assistance: Codex assisted with implementation and testing, and Codex and Claude provided code review.
