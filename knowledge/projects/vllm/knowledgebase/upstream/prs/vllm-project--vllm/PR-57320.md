# [Feature] Skip MLA weight absorption when weights are pre-processed

[Upstream PR](https://github.com/vllm-project/vllm/pull/57320) · state: open · merged: False

## Original PR description




## Purpose

Under `--load-format ipc_cache` the weight cache daemon already absorbed `kv_b_proj` into `W_UK_T / W_UV` and exports them. Re-running the absorption in the engine writes into the daemon's shared allocations, so skip it when `is_weights_pre_processed()` and `W_UV` came from the daemon.
