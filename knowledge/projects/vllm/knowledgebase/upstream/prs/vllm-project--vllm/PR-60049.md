# [Bugfix][MRV2] Preserve dummy tokens across PIECEWISE padding

[Upstream PR](https://github.com/vllm-project/vllm/pull/60049) · state: open · merged: False

## Original PR description

## Overview

Fix MRV2 `draft_model` adaptive profiling startup when PIECEWISE padding expands draft input beyond its compiled range. Initially discovered during Gemma3 Prefix-LM validation for [#60040](https://github.com/vllm-project/vllm/pull/60040), then independently reproduced on upstream with **Qwen/Qwen3-1.7B (target) + Qwen/Qwen3-0.6B (draft)** on **TRITON_ATTN and ROCM_ATTN**, confirming a shared MRV2 dummy-path bug independent of #60040's Prefix-LM changes.

## Claims

- Preserve valid dummy query counts across PIECEWISE input padding, retaining room for draft correction tokens.
- Keep trailing tokens marked as padding and write context positions only for valid queries; preserve FULL dummy query reshaping.
- Cover padding/context behavior and PIECEWISE dispatch with two focused tests, including a FULL varlen control.

## Validation

Actual **`vllm serve`** runs and HTTP requests on a single gfx1151 Radeon 8060S, BF16, AITER disabled, `VLLM_GPU_SYNC_CHECK=error`. All patched runs show nonzero draft acceptance and FULL/PIECEWISE execution in native metrics/logs. No worker monkeypatches or profiling skips.

## Details

`_dummy_run` reserves eight correction slots (1024 → 1016), but PIECEWISE dispatch pads to 1024 and dummy preparation counts that padding as valid queries. Draft expansion then produces 1032 tokens. Passing valid and padded counts separately through `InputBatch.make_dummy` restores the distinction already used for real requests.

This fixes the additional startup bug discovered while testing #60040; #60040's Prefix-LM changes are used only for Gemma3 integration validation and are not included in this patch. Qwen3 + Triton reproduces the problem without Prefix-LM.

Duplicate check (2026-10-05): no direct duplicate found. #54065/#54077 adjust profiling splits, #56182 separates profiling passes, #58984 handles DP request padding, and #55990 refactors standalone drafting
