# [Bugfix] Stop offline beam search at the context limit

[Upstream PR](https://github.com/vllm-project/vllm/pull/64728) · state: closed · merged: True

## Original PR description



## Overview

Fix offline `LLM.beam_search()` raising `VLLMValidationError` when a beam reaches the model's context limit during generation. Return the completed beams instead of submitting another token step.

## Claims

- Mark beams that reach the context limit as completed with `finish_reason="length"`, preserving their tokens, logprobs and cumulative scores.
- Other prompts in the same batch continue generating.
- Candidate ranking and EOS handling remain unchanged.

## Validation

GPU validation used DeepSeek-R1-Distill-Qwen-1.5B with `max_model_len=128`, prompt lengths of 127, 124 and 16 tokens, and `max_tokens=8`.

- On base `c817cc0f8b`, the regression fails when beam search submits a subsequent request with 128 prompt tokens.
- With the fix, the three prompts return 1, 4 and 8 generated tokens per beam, respectively. Assertions cover token/logprob lengths, cumulative scores and `finish_reason="length"` for beams reaching the context limit.
- Existing beam-search tests: **74 passed, 5 deselected**.
- All applicable pre-commit hooks pass.

Original error:

```text
vllm.exceptions.VLLMValidationError: The decoder prompt (length 128) plus the number of requested output tokens (at least 1) is longer than the maximum model length of 128. Make sure that `max_model_len` is no smaller than the number of text tokens (prompt + requested output tokens).
```

Local validation used the branch's Python source with existing `d14f72c7fe` build artifacts, rather than a full native rebuild. TinyLlama and ROCm were not run locally.

The regression is included in the existing NVIDIA/AMD Samplers CI jobs:

```sh
.venv/bin/python -m pytest tests/samplers/test_beam_search.py \
  -k stops_at_context_limit_per_prompt -v
```

## Details

Offline beam search repeatedly submits one-token requests. Previously, candidates remained active after reaching the context limit, so the next request failed input validation.

After the existing candidate sort and beam-width selection, move full-context beams into the completed list with `finish_reason="length"`. This keeps termination independent for each prompt and reuses the existing final ranking. Initial prompts that leave no room for generation remain subject to the existing input validation.
