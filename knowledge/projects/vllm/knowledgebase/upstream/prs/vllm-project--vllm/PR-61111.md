# [EPLB] Make migration peer limit configurable

[Upstream PR](https://github.com/vllm-project/vllm/pull/61111) · state: open · merged: False

## Original PR description

Related to #31671. Follow-up to [@ilmarkov's request](https://github.com/vllm-project/vllm/pull/52641#pullrequestreview-5078315210) on #52641.

Add `migration_max_peers` to configure concurrent sends and receives per rank in async EPLB migration batches. The default stays 1 and batching remains opt-in.

## Tests

4× H100 80GB across 2 nodes, with nightly binaries:

- EPLB tests: 38 passed, 1 skipped. NIXL transfers matched exactly at limits 1/2/4.
- Qwen3-30B-A3B at limit 2: all 8 arithmetic checks matched before and after rebalancing.

Higher limits showed no transfer speedup in the TCP microbenchmark.
