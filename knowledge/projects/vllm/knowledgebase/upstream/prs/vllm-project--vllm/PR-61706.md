# [ROCm][CI] Add legacy AMD jobs for standalone test_areas AMD steps

[Upstream PR](https://github.com/vllm-project/vllm/pull/61706) · state: closed · merged: False

## Original PR description

These AMD steps are defined directly in test_areas/*.yaml (not as a mirror of an NVIDIA step) and have no job in test-amd.yaml, so the AMD CI pipeline never runs them. Add an optional job for each, copied from the test_areas definition:

- (MI355) Fusion E2E TP2 AR-RMS (Inductor Partition) (#56679)
- (MI355) Fusion E2E TP2 AR-RMS (Dynamo Partition) (#56679)
- (MI355) LM Eval Large Models Harness (#56679)
- (MI355) Qwen3-Next-80B-A3B-Instruct MTP Async EPLB Accuracy (#56679)
- (MI355 DPX) Native Quantization Kernels (#57599)
- (MI355) DeepSeek-V4.1 Mono Decode Numerics (#60397)

The existing Fusion E2E TP2 jobs only run test_tp2_ar_rms_fp8_fusions, and the LM Eval Large Models Harness and Qwen3-Next EPLB jobs only run on MI300. Existing jobs are unchanged.
