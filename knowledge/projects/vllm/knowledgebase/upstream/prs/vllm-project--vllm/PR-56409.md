# [Build] Extract legacy HIP and MoE CMake configuration

[Upstream PR](https://github.com/vllm-project/vllm/pull/56409) · state: open · merged: False

## Original PR description

## Purpose

The legacy HIP `_C` and shared `_moe_C_stable_libtorch` build definitions are embedded in the top-level `CMakeLists.txt`. Extract them into focused CMake files, with additional CUDA MoE source selection and Marlin generation in a separate include. The main file becomes 226 lines shorter while retaining the original configuration order, source lists, compiler flags, target definitions, and linking behavior.

Closes #56407.
Part of #9129; this does not complete or close the parent tracking issue.

This complements #41432, which explicitly leaves `_C` and `_moe_C` restructuring for a follow-up. That PR covers `_C_stable_libtorch` and `_rocm_C`; this change covers the current legacy HIP `_C` and `_moe_C_stable_libtorch` targets. Issue comments and open PR searches for the tracking issue and CMake/MoE extension work were checked; no duplicate extraction was found.

## Test Plan

Preserve CMake command order and verify configuration equivalence, then validate CUDA and ROCm builds before marking this draft ready for review.

## Test Result

- `.venv/bin/python -m pytest --noconftest tests/test_cmake_utils.py -v`: **3 passed**. Standalone CMake utility tests ran without the heavyweight repository fixtures.
- `.venv/bin/pre-commit run --files CMakeLists.txt cmake/hip_extension.cmake cmake/moe_extension.cmake cmake/moe_extension_cuda.cmake`: **passed**.
- `git diff --check`: **passed**.
- Temporary before/after CMake harness: expanding the includes reproduced all original commands in order. Target definitions, source flags, link libraries, and generator calls matched across six CUDA/HIP configurations (CUDA 11.8/12.8/13.0; HIP with and without a bundled runtime). Compilation and generator execution were stubbed, so this is configuration-equivalence validation, not a GPU build test.

- Model evaluations: not run; no kernel or model behavior changes are intended.
