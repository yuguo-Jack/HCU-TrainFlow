# [Model] Add Reflection Beam

[Upstream PR](https://github.com/vllm-project/vllm/pull/62074) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Add day-0 support for Reflection's Beam-1.0 (`BeamForCausalLM`), a 501B-parameter MoE with 23B active parameters, and its DFlash2 drafter (`DFlash2BeamDraftModel`). This is the model slice of #61978.

Builds on #62042 (merged). This PR doesn't need FlashInfer nightly. The `beam` reasoning and tool parsers are in #62052. The fused MNNVL all-reduce (with Beam's norm and MoE-finalize epilogue) is split out into a stacked follow-up PR. MegaMoE support (attention DP + expert parallelism on FlashInfer CuTeDSL), which does need FlashInfer nightly, follows in #62073.

## Claims

- **Architecture:**
  - hybrid sliding-window (RoPE) and full-attention NoPE layers with SSMax;
  - per-head Q/K norm and a sigmoid output gate;
  - DeepSeek-V3-style MoE with an FP32 router;
  - sandwich norms and depth-scaled residuals.

  It runs with tensor, data or expert parallelism. `BeamConfig` and the model follow the released `config.json` schema (`layer_types`, `mlp_layer_types`, per-type `rope_parameters`); behavior the release does not configure is fixed rather than switchable.
- **Fused kernels for Blackwell**, under `vllm/models/beam/nvidia`: attention, norm/residual boundaries, and DFlash2 context ops. TP all-reduce uses vLLM's standard path in this PR.
- **DFlash2 speculative decoding:** works with FP8 KV cache and adaptive verification. The Beam drafter is self-contained and does not subclass the Qwen3 DFlash classes.

## Validation

**Serving:** Beam-1.0 NVFP4 + DFlash2 (7 draft tokens), TP8 on GB200, SPEED-Bench `throughput_1k` low-entropy subset, greedy decoding. *Measured on the previous revision, which included the fused all-reduce; re-run on this revision pending.*

```bash
vllm serve reflection/Beam-1.0-501B-A23B-NVFP4 -tp 4 --max-num-seqs 128 \
  --reasoning-parser beam --tool-call-parser beam --enable-auto-tool-choice \
  --kv-cache-dtype fp8 --attention-config '{"backend":"FLASHINFER"}' \
  --kernel-config '{"enable_flashinfer_autotune":false}' \
  --speculative-config '{"method":"dflash","model":"reflection/Beam-1.0-501B-A23B-DFlash2","num_speculative_tokens":7,"attention_backend":"FLASH_ATTN"}'
```

**Unit tests** on this branch, GB200. These need no checkpoint: the construction test builds a small random-weight Beam and generates with it (TP/EP up to 4). The released `config.json` files for `reflection/Beam-1.0-501B-A23B` and `-NVFP4` also load through `get_config` (9 NoPE layers, 3 dense layers).
