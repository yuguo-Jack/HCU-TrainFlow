# [Bugfix][Attention] Gracefully handle CUDA builds without FlashAttention extensions

[Upstream PR](https://github.com/vllm-project/vllm/pull/63287) · state: open · merged: False

## Original PR description

## Purpose

Fixes #63267.

On CUDA builds where the compiled FlashAttention extensions (`_vllm_fa2_C` / `_vllm_fa3_C`) are not present (such as Jetson Thor `sm_110` or custom trimmed CUDA builds):

1. **Import-time failure**: `vllm/v1/attention/backends/fa_utils.py` unconditionally executes `from vllm.vllm_flash_attn import ...` when `current_platform.is_cuda()`, while `vllm/vllm_flash_attn/__init__.py` raises `ImportError` at import time when neither `_vllm_fa2_C` nor `_vllm_fa3_C` is available. This prevents `ModelConfig` construction and any model module import from succeeding even when non-FA backends (e.g., `TRITON_ATTN` or `FLASHINFER`) are used.
2. **Backend auto-selection**: `is_flash_attn_varlen_func_available()` hardcoded `return True` for CUDA, and `FlashAttentionBackend.supports_combination()` did not check whether `get_flash_attn_version(...)` returned `None` for standard FP16/BF16 KV cache configurations. As a result, `FLASH_ATTN` was still auto-selected and later failed inside `FlashAttentionImpl.forward` with `AssertionError: FlashAttention version not detected.`

### Changes

- **`vllm/v1/attention/backends/fa_utils.py`**: Mirror the ROCm branch by wrapping the CUDA `vllm.vllm_flash_attn` import in `try ... except ImportError`, tracking `_CUDA_FLASH_ATTN_AVAILABLE`, and providing lazy-raising stubs when the extensions are absent. Update `is_flash_attn_varlen_func_available()` to return `_CUDA_FLASH_ATTN_AVAILABLE` on CUDA.
- **`vllm/v1/attention/backends/flash_attn.py`**: In `FlashAttentionBackend.supports_combination()`, check `get_flash_attn_version(...) is None` on CUDA so `FlashAttentionBackend` reports itself unsupported when no FlashAttention version is available, allowing `get_attn_backend` to fall through to other valid backends.
- **`tests/kernels/attention/test_flash_attn_interface.py`**: Add `test_fa_utils_import_and_backend_validation_without_fa_extensions` covering both `fa_utils` import and `FlashAttentionBackend.supports_combination` when FA extensions are absent.
