# [Model] Add NemotronLabsDiffusion support with tri-mode inference

[Upstream PR](https://github.com/vllm-project/vllm/pull/58387) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Add native Nemotron Labs Diffusion 3B/8B text-model support: masked block diffusion and ordinary autoregressive inference. This builds on #48279 and is the foundation for #60287 and #60288; tracking issue #60283 covers the stack.

## Claims

- Load the Ministral backbone and untied diffusion head using checkpoint dimensions and RoPE settings.
- Use causal prompt prefill/block commit and bidirectional masked denoising, with literal per-request temperatures.
- Support ordinary AR through `hf_overrides={"ar_mode": true}`.
- Defer linear speculation as requested in review. There are no changes to `gpu/model_runner.py` or the model-state interface in this version.
- Use the Transformers v5 `PreTrainedConfig` name required by current main.

## Validation

Rebased onto upstream main `1a3a7a8f01a8c1a3184151b8185072efda11daab`.

CPU-only tests of the complete stacked branch: **93 passed, 9 skipped**. This runs the sampling-parameter suite and the Nemotron model unit/configuration suite with CUDA disabled. The nine skips are CUDA/checkpoint-gated cases, not GPU validation.

The applicable full pre-commit suite passed, including type checking, test tethering and forbidden-import checks. GPU-serving and model-quality evaluations have **not** been rerun after this rebase. CUDA/checkpoint-gated tests must not be counted as passing GPU validation.

Historical public 3B results, before this rebase:

| Mode | Correct / total | GSM8K accuracy |
| --- | ---: | ---: |
| Confidence-based diffusion | 1,155 / 1,319 | 87.57% |
| Ordinary AR | 1,182 / 1,319 | 89.61% |

Diffusion was evaluated at `83594fb280`; AR at `0df15ea7e5`. Configuration: official 3B checkpoint, BF16, H100, TP=1, Triton attention, eager backbone, temperature 0, concurrency 8, context 1,024 and maximum 750 generated tokens. Diffusion used block size 32 and confidence threshold 0.9. These are historical scores, not measurements of the new head.

Reproduction commands:

## Details

The previous implementation, including linear speculation, is preserved at [deferred/nemotron-linear-spec-20261009](https://github.com/sajadn/vllm/tree/deferred/nemotron-linear-spec-20261009). A separate follow-up can restore its speculative sampler, configuration, prefill-logit hook and tests without holding up masked decisions.

The diffusion warmup guard remains because masked diffusion does not support structured-output grammar masks. Vision inputs are outside this change. Mixed-batch logprob bookkeeping and unsupported pipeline-parallel configurations are addressed by #60287, not claimed fixed in this foundation. The original fork's 3B diffusion result of 1,161/1,319 versus this implementation's historical 1,155/1,319 remains unexplained. No new speedup, long-context, quantization or multi-GPU accuracy claim is made.
