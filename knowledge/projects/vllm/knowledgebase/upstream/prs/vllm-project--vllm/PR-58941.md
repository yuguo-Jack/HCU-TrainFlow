# [Bugfix][Frontend] Preserve streaming chunk boundaries in RequestOutputCollector

[Upstream PR](https://github.com/vllm-project/vllm/pull/58941) · state: closed · merged: True

## Original PR description

## Purpose

**Bug:** `RequestOutputCollector` (`vllm/v1/engine/output_processor.py`) keeps a single `self.output` slot and merges DELTA outputs into it when the producer runs ahead of the consumer. `RequestOutput.add()` overwrites `finish_reason`, so for streaming-input (resumable) sessions the per-chunk boundary marker (a `finish_reason` on a non-finished output) is erased when a merge spans a chunk boundary — the consumer sees two chunks' replies glued together.

**Fix:** `RequestOutputCollector` keeps its original single-slot merging. A new `StreamingInputOutputCollector` subclass, constructed only by `_add_streaming_input_request` (`vllm/v1/engine/async_llm.py`), adds a `_backlog` deque: while the slot or the backlog tail carries a chunk boundary, incoming outputs are queued into / merged within the backlog instead of being merged into the boundary output, and `get`/`get_nowait` promote backlog entries into the slot in FIFO order. Exceptions remain terminal (they clear the backlog and take over the slot). Non-streaming requests use the base collector and are unaffected.

Thanks @sawsa307. Instead of making these changes to the common `RequestOutputCollector` class,

Instead could we have a separate streaming-input-specific subclass used by `_add_streaming_input_request`, something like this:

```python
class StreamingInputOutputCollector(RequestOutputCollector):
    """Collector for streaming-input requests. Doesn't merge across input
    chunk boundaries (a finish_reason on a non-finished output)."""

    def __init__(self, output_kind: RequestOutputKind, request_id: str):
        super().__init__(output_kind, request_id)
        self._backlog: deque[RequestOutput] = deque()

    def put(self, output: RequestOutput | PoolingRequestOutput | Exception) -> None:
        if isinstance(output, Exception):
            self._backlog.clear()
        elif self._backlog or _is_chunk_boundary(self.output):
            assert isinstance(output, RequestOutput)
            if self._backlog and not _is_chunk_boundary(self._backlog[-1]):
                self._backlog[-1].add(output, aggregate=self.aggregate)
            else:
                self._backlog.append(output)
            return
        super().put(output)

    def _promote(self, output):
        if self._backlog:
            self.output = self._backlog.popleft()
            self.ready.set()
        return output

    async def get(self) -> RequestOutput | PoolingRequestOutput:
        return self._promote(await super().get())

    def get_nowait(self) -> RequestOutput | PoolingRequestOutput | None:
        return self._promote(super().get_nowait())
```
