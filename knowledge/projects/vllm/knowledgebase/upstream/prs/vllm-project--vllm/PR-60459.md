# [Frontend] Add CLI configuration for HTTP keep-alive timeout

[Upstream PR](https://github.com/vllm-project/vllm/pull/60459) · state: open · merged: False

## Original PR description

## Overview

Related to #25700.

Add `--http-timeout-keep-alive` configuration for the Python frontend. The setting is available through CLI and YAML, then reaches the Python API server, CPU render server, and Rust frontend.

## Claims

- Adds `--http-timeout-keep-alive` and rejects negative values.
- Preserves `VLLM_HTTP_TIMEOUT_KEEP_ALIVE` for existing deployments.
- Resolves values with this precedence: explicit CLI/YAML > legacy environment variable > default of 5 seconds.
- Forwards the resolved value to the Rust frontend through its JSON bootstrap payload.
