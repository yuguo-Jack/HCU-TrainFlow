# [Perf][EPLB][DSv4] Add a symm_mem weight-migration backend and fuse MegaMoE replica mapping

[Upstream PR](https://github.com/vllm-project/vllm/pull/62009) · state: closed · merged: True

## Original PR description



## Overview

This PR makes EPLB cheaper for DeepSeek-V4.1-Flash, running DP attention with EP MegaMoE on multi-node NVLink. It does three things:

- adds an opt-in `symm_mem` weight-migration backend;
- fuses EPLB's logical→physical replica mapping and expert-load recording into the DeepGEMM MegaMoE staging kernels;
- takes async EPLB's host work off the decode critical path.

Not a duplicate. No open or merged PR adds a symmetric-memory EPLB backend or fuses the MegaMoE mapping. #61176 and #61839 enable EPLB for the ROCm AITER MegaMoE backend. Related: #61767 (`cpu_all_reduce_`, reused here), #57549, #56716, #61643. #61395 (EPLB for the V4.1 DSpark draft) runs together with this PR in the GB300 validation.

## Claims

- With this PR and #61395, EPLB raises DeepSeek-V4.1-Flash decode throughput on GB300 NVL72 by +12.0% at DEP16 and +25.0% at DEP32 with 72 req/rank, and by +26.2% at DEP32 with 128 req/rank. At DEP32 with 128 req/rank, main-model MegaMoE drops from 14.7 to 7.6 ms per step. Earlier GB200 runs on an older build showed smaller gains; see Validation.
- `symm_mem`: senders push expert rows into the receiver's `expert_buffer`, which is allocated in CUDA symmetric memory. There is no staging buffer, and it needs no memory beyond `expert_buffer`. Cross-node peer copies run at about 800 GB/s, against about 88 GB/s for NIXL, and a 40-layer rearrangement transfers in 0.3–0.6 s at DEP32.
- MegaMoE layers no longer launch a separate EPLB mapping kernel, which saves 5–6 µs per layer. The replica choice is shared with the router through one Triton helper, so physical ids and load counts match `eplb_map_to_physical_and_record` exactly.
- Async EPLB no longer adds a GPU→host sync to the decode loop. It also raises on every rank when the worker fails on any rank, instead of stalling.

## Details

**`symm_mem` backend**
- The receive buffer is one symmetric `uint8` buffer per EP group, set up with a single rendezvous and carved into per-tensor views. The backend checks the NVLink/MNNVL domain before allocating.
- Senders and receivers derive each receive row from the global placement with the same helper, so `add_recv` is a no-op. Push backends get every rank's rows through a new `recv_rows` argument to `set_transfer_context`. This argument is optional and other backends ignore it.
- Each `execute()` runs two CPU barriers. GPU spin barriers can deadlock against MegaMoE's cooperative launches.
- Rejected with elastic EP. The buffer lives outside the caching allocator, so sleep mode does not free it.

**Fused mapping**: `fused_moe/eplb_triton.py` holds the replica hash, map lookup and gated load count. The MXFP8/BF16 and NVFP4 staging kernels call it, and so does the router kernel. Routed-experts capture still sees logical ids.

**Async EPLB**
- Per-layer maps are committed with pinned non-blocking copies, and the worker thread fences `expert_buffer` reuse.
- Balancedness stats are read back non-blocking and logged in order once they land.
- `should_record_tensor` is rewritten only when its value flips.
- The per-step "all ranks ready" check runs over `cpu_all_reduce_`. A gloo ring all-reduce costs several ms per step at DP16/DP32.

**Also**
- `logical_to_physical_map` is sized to R+1 slots unless elastic EP is on.
- `compute_logical_maps` is vectorized.
- DeepSeek V4.1 decoder-replay padding and dummy rows are marked as padding, which complements #61643.

**CI**: the `symm_mem` execution tests need NVLink peers. They are added to the optional 8×H100 "Distributed DP + EP" job; the 4×L4 EPLB job skips them. The MegaMoE staging test needs SM100.

**Limitations**
- In mixed prefill/decode serving, per-rank prefill imbalance bounds the step. There, EPLB mostly lowers tail TTFT rather than raising throughput.
- Likely rebase overlap with #61786, #59168 and #41141. Offline placements without elastic EP (#41141) could exceed R+1 replicas.
