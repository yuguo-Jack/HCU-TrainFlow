# [Perf][Spec Decode] Skip redundant DSpark context projections for long prefills

[Upstream PR](https://github.com/vllm-project/vllm/pull/63710) · state: open · merged: False

## Original PR description

## Overview

Reduce redundant DeepSeek-V4.1 DSpark computation during long prefills by selecting the context rows needed by sliding-window attention before running the hidden-state and context-KV projections.

The implementation uses GPU request boundaries, preserves FULL CUDA graph context staging, and enables the optimization through an explicit model contract.

## Claims

- Improve output throughput by 3%～4% on DeepSeek-V4.1-Flash-1017 with 8× H20-3e GPUs, TP8+EP, and a 64K-input/128-output workload.
