# [Feat][BI][2/N] add batch-invariant DeepSeek V4 support (compressor)

[Upstream PR](https://github.com/vllm-project/vllm/pull/64870) · state: open · merged: False

## Original PR description

- Add CUDA batch-invariant compressor execution using existing Triton kernels and FP32-output BI projections.
- Support main KV FP8 and indexer FP8/MXFP4 caches while preserving non-BI behavior and existing hardware restrictions
- Test real compressor  forward()  across C4/C128, requiring byte-identical states and KV/scales for individual, mixed, and reordered requests.
