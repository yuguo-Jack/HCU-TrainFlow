# [Frontend] Replace images with a note for text-only models on /v1/messages

[Upstream PR](https://github.com/vllm-project/vllm/pull/59618) · state: open · merged: False

## Original PR description

## Purpose

Related to #58647 (gpt-oss row: "Images are dropped").

On `/v1/messages`, a text-only model now gets the text `[Image omitted: this model cannot read images.]` in place of each image.

Today, text-only models handle images in two different ways, and both break agent sessions:

- **HF-template models** (e.g. Qwen3-0.6B) reject the request with `400 … is not a multimodal model`. When Claude Code's Read tool returns an image, the image stays in the history, so every later request in the session fails too.
- **gpt-oss (Harmony)** drops the image silently, so the model describes an image it never saw. Reading a plain red 64×64 PNG through Claude Code's Read tool, gpt-oss-120b described "a deep blue background … an abstract, stylized 'W' shape … in a lighter cyan hue".

With the note, the model knows an image was there and can say it can't see it, and the session continues. A model "accepts images" when it has a multimodal config and its per-prompt image limit is above 0. Models with image input are unaffected.

Image support is read from `model_config` on each request (an `_image_input` property), so the handler gains no new state. The replacement is one pass over the converted OpenAI messages, so it works wherever the converter places images. It also works if #58823 moves tool-result images into the tool message.

**Design note:** the other option is to reject images consistently with a 400. I went with the note because, for an agent client, a 400 caused by something in the history cannot be fixed by the next request. Happy to change it if reviewers prefer the 400.

**Not a duplicate:** searched open PRs for Anthropic image handling and Harmony content validation. #58823 moves tool-result images into the tool message, which is still needed for multimodal models. #47052 adds 400s for unsupported content types on the Harmony path, not for images on text-only models.

## End-to-end: Claude Code versions × direct and LiteLLM

The `image` scenario of `cc_e2e.py` (below) has Claude Code read a plain red 64×64 PNG with its Read tool, asks for the main color in one word ("answer UNKNOWN if you could not see it"), then sends a follow-up. Model: gpt-oss-120b (text-only). **main** is the base commit. **fix** is this PR merged with #59616 and #59617. LiteLLM is 1.103.1 with `hosted_vllm`, which sends Claude Code's requests to `/v1/chat/completions`. Claude Code 2.0.70, 2.1.75, 2.1.139, 2.1.199 and 2.1.286 were each run 3 times per cell (15 runs per cell).

| | main | fix |
|---|---|---|
| **direct (`/v1/messages`)** | invented a color in **11/15** (black, blue, dark-blue, teal, indigo, …) | invented a color in **0/15** (answers UNKNOWN or says it can't see the image) |
| **via LiteLLM (`/v1/chat/completions`)** | 1/15 | 5/15 |

No turn failed in any cell, so the session always continued after the image.

What this shows:
- **Direct:** the fix removes the invented descriptions on every tested version.
- **Through LiteLLM:** LiteLLM puts the image inside the `tool` message and calls `/v1/chat/completions`, which this PR doesn't touch, so main and fix run the same code there. The 1/15 vs 5/15 difference is sampling noise (6/30 combined). On that endpoint, gpt-oss (Harmony) still drops the image without telling the model, and HF-template text-only models still return `400 … is not a multimodal model` (not run in this matrix). Applying the same note on `/v1/chat/completions` would be a separate, OpenAI-API-facing change.

3. Save this as `cc_e2e.py`. It drives a real multi-turn Claude Code session and prints a verdict:

```python
"""Run a real Claude Code session against an Anthropic-compatible endpoint.

Scenarios:
  overflow  Read N large files, one per turn, so the conversation outgrows the
            server's context window, then ask for every secret word. PASS when
            every turn succeeds; "recalled" counts the words that survived
            compaction, which depends on the model's summary.
  image     Read a plain red PNG, ask for its color, then send a follow-up.
            PASS when no turn fails and the model names no color other
            than red (a text-only model should answer UNKNOWN).

Usage:
  python cc_e2e.py --claude ./node_modules/.bin/claude \
      --base-url http://localhost:8000 --model openai/gpt-oss-120b \
      --scenario overflow [--env CLAUDE_CODE_AUTO_COMPACT_WINDOW=65536]

Only the standard library is needed. Point --base-url at vLLM for
Claude Code -> vLLM (/v1/messages), or at a LiteLLM proxy for
Claude Code -> LiteLLM -> vLLM (/v1/chat/completions).
"""

import argparse
import json
import os
import random
import re
import shutil
import struct
import subprocess
import sys
import tempfile
import zlib

OTHER_COLORS = {
    "black",
    "blue",
    "brown",
    "cyan",
    "gold",
    "gray",
    "green",
    "grey",
    "indigo",
    "magenta",
    "maroon",
    "navy",
    "orange",
    "pink",
    "purple",
    "silver",
    "teal",
    "turquoise",
    "violet",
    "white",
    "yellow",
}
WORDS = ["alpha", "beta", "gamma", "delta", "epsilon", "zeta", "theta", "kappa"]


def red_png(size: int = 64) -> bytes:
    raw = b"".join(b"\x00" + b"\xff\x00\x00" * size for _ in range(size))

    def chunk(tag: bytes, data: bytes) -> bytes:
        crc = zlib.crc32(tag + data) & 0xFFFFFFFF
        return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", crc)

    header = struct.pack(">IIBBBBB", size, size, 8, 2, 0, 0, 0)
    return (
        b"\x89PNG\r\n\x1a\n"
        + chunk(b"IHDR", header)
        + chunk(b"IDAT", zlib.compress(raw))
        + chunk(b"IEND", b"")
    )


def setup(
    scenario: str, work: str, files: int, lines: int
) -> tuple[list[str], list[str]]:
    """Write the scenario's files into work; return (prompts, expected words)."""
    rng = random.Random(0)
    if scenario == "image":
        with open(os.path.join(work, "logo.png"), "wb") as f:
            f.write(red_png())
        return [
            "Use the Read tool on logo.png and describe the image.",
            "What is the main color of logo.png, in one word? "
            "If you could not see the image, answer UNKNOWN.",
            "Reply with the single word OK.",
        ], []
    secrets = []
    for i in range(1, files + 1):
        secret = f"{rng.choice(WORDS)}{i}"
        secrets.append(secret)
        with open(os.path.join(work, f"part{i}.txt"), "w") as f:
            for n in range(lines):
                text = " ".join(rng.choice(WORDS) for _ in range(10))
                f.write(f"part{i} line {n}: {text}\n")
            f.write(f"END OF PART {i}: the secret word is {secret}\n")
    prompts = [
        f"Use the Read tool to read part{i}.txt in full and tell me its secret word."
        for i in range(1, files + 1)
    ]
    prompts.append("List every secret word you found so far, one per line.")
    return prompts, secrets


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--claude", required=True, help="path to the claude binary")
    ap.add_argument("--base-url", required=True)
    ap.add_argument("--model", required=True)
    ap.add_argument("--scenario", choices=["overflow", "image"], required=True)
    ap.add_argument("--files", type=int, default=6)
    ap.add_argument("--lines", type=int, default=550, help="~20 tokens per line")
    ap.add_argument("--env", action="append", default=[], help="extra KEY=VALUE")
    ap.add_argument("--log", help="write Claude Code's stream-json output here")
    args = ap.parse_args()
    # Claude Code runs from a temporary directory, so resolve the path first.
    claude = os.path.abspath(shutil.which(args.claude) or args.claude)

    home, work = tempfile.mkdtemp(), tempfile.mkdtemp()
    prompts, secrets = setup(args.scenario, work, args.files, args.lines)
    env = {
        "PATH": os.environ.get("PATH", "/usr/bin:/bin"),
        "HOME": home,
        "TERM": "xterm",
        "ANTHROPIC_BASE_URL": args.base_url,
        "ANTHROPIC_API_KEY": "dummy",
        "DISABLE_AUTOUPDATER": "1",
    }
    for var in (
        "ANTHROPIC_MODEL",
        "ANTHROPIC_DEFAULT_OPUS_MODEL",
        "ANTHROPIC_DEFAULT_SONNET_MODEL",
        "ANTHROPIC_DEFAULT_HAIKU_MODEL",
        "CLAUDE_CODE_SUBAGENT_MODEL",
    ):
        env[var] = args.model
    env.update(kv.split("=", 1) for kv in args.env)

    proc = subprocess.Popen(
        [
            claude,
            "-p",
            "--verbose",
            "--input-format",
            "stream-json",
            "--output-format",
            "stream-json",
            "--allowedTools",
            "Read",
        ],
        cwd=work,
        env=env,
        text=True,
        stdin=subprocess.PIPE,
        stdout=subprocess.PIPE,
        stderr=subprocess.DEVNULL,
    )
    results, compactions = [], 0
    with open(args.log or os.devnull, "w") as log:
        for i, prompt in enumerate(prompts, 1):
            msg = {"type": "user", "message": {"role": "user", "content": prompt}}
            proc.stdin.write(json.dumps(msg) + "\n")
            proc.stdin.flush()
            result = None
            for line in proc.stdout:
                log.write(line)
                event = json.loads(line)
                if event.get("subtype") == "compact_boundary":
                    compactions += 1
                if event.get("type") == "result":
                    result = event
                    break
            if result is None:
                print(f"turn {i}: claude exited", flush=True)
                results.append((True, ""))
                break
            text = str(result.get("result") or "")
            results.append((bool(result.get("is_error")), text))
            status = "ERROR" if result.get("is_error") else "ok"
            print(f"turn {i}: {status:5} {text[:110]!r}", flush=True)
    proc.stdin.close()
    proc.wait(timeout=120)

    errors = sum(err for err, _ in results)
    summary = {
        "scenario": args.scenario,
        "turns": len(prompts),
        "failed_turns": errors,
        "compactions": compactions,
    }
    if args.scenario == "overflow":
        final = results[-1][1] if len(results) == len(prompts) else ""
        summary["recalled"] = f"{sum(s in final for s in secrets)}/{len(secrets)}"
        ok = errors == 0 and len(results) == len(prompts)
    else:
        answer = results[1][1].strip().lower() if len(results) > 1 else ""
        # The image is plain red: any other color was made up.
        words = re.findall(r"[a-z]+", answer)
        invented = sorted(set(words) & OTHER_COLORS)
        summary["color_answer"] = answer[:40]
        summary["invented_colors"] = invented
        ok = errors == 0 and len(results) == len(prompts) and not invented
    summary["verdict"] = "PASS" if ok else "FAIL"
    print(json.dumps(summary), flush=True)
    return 0 if ok else 1


if __name__ == "__main__":
    sys.exit(main())
```
