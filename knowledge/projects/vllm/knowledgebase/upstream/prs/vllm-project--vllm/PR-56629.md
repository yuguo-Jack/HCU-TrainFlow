# [5/N] Share HiSparse host cache across TP ranks (reopens #52760)

[Upstream PR](https://github.com/vllm-project/vllm/pull/56629) · state: closed · merged: True

## Original PR description

## Summary

Share the replicated HiSparse MLA host cache across local TP ranks using one mmap-backed pool. TP rank 0 writes the shared pool; peers wait on its IPC events before reading it. Other executor and parallel layouts retain private pools.

This reopens #52760 against `main`. The original PR was automatically closed when [3/N] (#53781) merged and its base branch, `feat/hisparse-mla-decode-main`, was deleted.

I am not the original author of this work; I reopened the existing PR so it can continue through review. Credit goes to **Chao Lei (@LCAIZJ)**, the original PR author, and **Matthew Bonanni (@MatthewBonanni)** for their implementation and follow-up work. The original commit authorship, co-author credits, and sign-offs are preserved, including my previous follow-up fixes.

The 11 original shared-host-cache commits rebased cleanly onto `main` with unchanged patches. The preceding metrics commit is already covered by merged #56061. A follow-up simplifies shared-region initialization as described below.

## Implementation

- Resolve shared/private host-pool mode and the physical host-block stride in the cache planner and propagate them through `KVCacheConfig`.
- Check physical host RAM in the mmap creator only and populate the shared backing once.
- Reuse `SharedOffloadRegion`'s existing barrier with the TP CPU group instead of introducing file locks. The creator populates before the barrier; the file is unlinked after all workers have mapped it, protecting against backing-file leaks after SIGKILL.
- Keep the ordinary offload population path close to `main`. The shared-region diff is reduced from 164 changed lines to 85.
- Preserve initialization rollback and cleanup of every successful CUDA host registration. Registration boundaries remain aligned with transfer geometry.
- Extend the existing multiprocess test to cover replicated-slot visibility, creator-only population, and cleanup after SIGKILL; remove the redundant standalone sharing test.
- Correct the documentation to describe the single TP writer and remove the stale claim that `num_gpu_blocks_override` overrides host capacity.
