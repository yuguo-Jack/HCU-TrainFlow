# [Perf][Gemma4][V1] Enable and optimize KV-sharing fast prefill and decode metadata

[Upstream PR](https://github.com/vllm-project/vllm/pull/60445) · state: open · merged: False

## Original PR description

## Overview

This pull request enables and optimizes KV-sharing fast prefill (You Only Cache Once / YOCO architecture) in vLLM V1 across attention utilities, worker runtime, and model configuration:

1. **Auto-Enablement of Fast Prefill**: In `vllm/model_executor/models/config.py`, automatically initializes `kv_sharing_fast_prefill = True` in `Gemma4Config.verify_and_update_config` when KV-shared layers are detected (`num_kv_shared_layers > 0`), speculative decoding is inactive (`speculative_config is None`), pipeline parallelism is unitary (`pipeline_parallel_size == 1`), and non-diffusion (`DiffusionGemmaForBlockDiffusion not in architectures`). This ensures out-of-the-box acceleration for `gemma-4-E2B-it` and `gemma-4-E4B-it` without requiring explicit CLI flags.
2. **Piecewise CUDAGraph Integration & Compiled Cross-Decoder Norm**: In `vllm/model_executor/models/gemma4.py`, moves `self.norm` into `Gemma4CrossDecoderLayers` (matching how `Gemma4SelfDecoderLayers` holds `embed_tokens` and `per_layer_projection_norm`) so `torch.compile` and `CUDAGraphMode.PIECEWISE` fuse and capture `self.norm` directly inside the compiled `cross_decoder` subgraph rather than executing eagerly outside `torch.compile`. Removes redundant `positions` buffer copy before `self.self_decoder`, equips `Gemma4Model.fast_prefill_forward` with piecewise CUDAGraph dispatch for cross-decoder execution, pre-allocated static tensor buffers, zero-copy decode fast-path, and sliced assignment `self_decoder_hidden_states[logits_indices_padded[:num_logits_indices]] = cross_hidden_states[:num_logits_indices]` to ensure padding tokens are never copied.
3. **Analytical Range Construction for Single-Logit Requests**: In `vllm/v1/attention/backends/utils.py`, when `common_attn_metadata.max_logits_per_req == 1 and num_logits_indices == num_reqs`, by the pigeonhole principle every request in the batch samples strictly 1 token, guaranteeing that `decode_query_start_loc` is identical to `[0, 1, 2, ..., num_reqs]`. Constructing `decode_query_start_loc` directly via `torch.arange` on GPU and CPU replaces 6 GPU kernel launches (`torch.bucketize`, `torch.zeros`, `torch.ones_like`, `scatter_add_`, `fill_`, `torch.cumsum`) and 1 PCIe D2H transfer with 1 GPU `torch.arange` kernel (net reduction of 5 GPU kernel launches and 1 PCIe D2H copy).
4. **Pure-Decode Step Preparation Guard**: In `vllm/v1/worker/gpu_model_runner.py`, guards `_prepare_kv_sharing_fast_prefill(logits_indices)` with `and max_query_len > 1`, completely skipping redundant GPU buffer copy/fill (`kv_sharing_fast_prefill_logits_indices`) and CUDAGraph dispatch on pure-decode steps (`max_query_len == 1`).
5. **Metadata Class and Custom Backend Factory Memoization (`@functools.lru_cache`)**: In `vllm/v1/attention/backends/utils.py`, dynamic creation of `class KVSharingFastPrefillAttentionMetadata(metadata_cls, KVSharingFastPrefillMetadata)` inside `FastPrefillAttentionBuilder.build()` invoked `typing._ProtocolMeta.__new__` (`ABCMeta.__new__`) and `dataclasses.fields()` on every forward step. Added `_get_fast_prefill_metadata_cls(metadata_cls: type)` cached via `@functools.lru_cache`, creating the wrapper class once per underlying metadata class. Decorated `create_fast_prefill_custom_backend` with `@functools.lru_cache` so identical `(prefix, underlying_attn_backend)` pairs reuse the same `AttentionBackend` and `FastPrefillAttentionBuilder` classes across layers and KV-cache groups.
6. **Pure-Decode Step Same-Group Attention Metadata Reuse**: In `vllm/v1/worker/gpu_model_runner.py`, within each KV cache group (`kv_cache_gid`), donor layers (`attn_gid=0`) and recipient layers (`attn_gid=1`) share the exact same `KVCacheSpec`. On pure-decode steps (`logits_indices_padded is None` and `not for_cudagraph_capture`), both builders produce identical attention metadata for the same `(kv_cache_gid, kv_cache_spec, cascade_attn_prefix_len)`. Introduced `same_group_decode_cache` in `_build_attention_metadata`, allowing recipient attention groups to directly reuse the already-built `attn_metadata_i` without invoking `builder.build(...)` a second time.

Duplicate-work check: verified via `gh pr list --repo vllm-project/vllm --search "KV-sharing fast prefill"` and `gh issue list` that no open pull request addresses KV-sharing fast prefill auto-enablement, piecewise CUDAGraph execution, or single-logit metadata specialization in V1.

## Claims

- **End-to-End Out-of-the-Box Serving Speedup (`enforce_eager=False`, torch.compile + CUDAGraphs)**:
  - On `gemma-4-E2B-it`: delivers **1.34x - 2.06x** speedup on prefill-heavy workloads (up to **+106.0% throughput gain**, latency drops from 416.45 ms to 202.28 ms at BS16), **1.01x - 1.75x** speedup on balanced workloads (up to **+75.0% throughput gain**, latency drops from 229.28 ms to 131.18 ms at BS16), **1.04x - 1.21x** speedup on decode-heavy workloads at BS8-BS16 (up to **+21.0% throughput gain** at BS16), and **1.95x - 2.10x** speedup on long-context 4K prefill workloads (up to **+110.0% throughput gain**, latency drops from 500.73 ms to 238.37 ms at BS4).
  - On `gemma-4-E4B-it`: delivers **1.41x - 1.54x** speedup on prefill-heavy workloads (up to **+54.1% throughput gain**, latency drops from 685.48 ms to 444.75 ms at BS16), **1.11x - 1.45x** speedup on balanced workloads (up to **+45.3% throughput gain**, latency drops from 367.97 ms to 253.29 ms at BS16), **1.02x - 1.20x** speedup on decode-heavy workloads at BS4-BS16 (up to **+19.9% throughput gain** at BS16), and **1.52x - 1.57x** speedup on long-context 4K prefill workloads (up to **+56.7% throughput gain**, latency drops from 767.06 ms to 489.57 ms at BS4).
  - `gemma-4-12B-it`, `gemma-4-26B-A4B-it`, and `gemma-4-31B-it` are not affected by this PR as they have no `kv_shared_layers` (`num_kv_shared_layers = 0`, so `kv_sharing_fast_prefill` remains `False`).
- **Zero Regression on Non-Shared Architectures**:
  - Exactly **0.99x - 1.01x parity** (median **1.00x**) across all batch sizes and scenarios on `gemma-4-12B-it` and `gemma-4-31B-it` (dense non-shared), and **0.98x - 1.00x** (median **0.99x**) on `gemma-4-26B-A4B-it` (MoE non-shared), verifying clean zero-overhead bypass.
- **Metadata Kernel Speedup (Regime 1: Single-Logit Fast Prefill Metadata)**:
  - Speeds up `make_kv_sharing_fast_prefill_common_attn_metadata` by **4.22x - 5.28x** (typical **4.8x - 5.2x**, median **4.94x**, saving ~0.17 ms per prefill step) across batch sizes 1 to 64 and query lengths 512 to 4096.
- **Pure-Decode Buffer Preparation Speedup (Regime 2: Pure-Decode Step Prep)**:
  - Speeds up pure-decode metadata preparation by **5.33x - 5.67x** (saving ~0.041 ms per decode step) across batch sizes 1 to 64.
- **Multi-Logit / Speculative Decode Fallback Parity (Regime 3: Spec-Decode Fallback)**:
  - Exactly **1.00x (+0.0%)** parity on multi-logit requests (`max_logits_per_req > 1`), confirming zero regression on speculative decoding paths.
- **Lossless Numerical & Bit-Level Parity**:
  - **100.0% Bit-Exact** across all 30 microbenchmark cases (`bit_exact_pct = 100.0%`, `within_1ulp_pct = 100.0%`, `max_abs_diff = 0.0`, `cosine_sim = 1.00000`). All metadata fields (`query_start_loc`, `query_start_loc_cpu`, `max_query_len`, `num_actual_tokens`) match baseline exactly.
  - **100.0% exact token generation match** across all evaluated Gemma 4 models in end-to-end serving across all 4 campaigns.

"""Benchmark PR2: KV-Sharing Fast Prefill Sync Elimination & Decode Guard."""

from __future__ import annotations

import argparse
import inspect
from pathlib import Path
import sys
from typing import Any, Callable, Dict, List, Optional, Tuple

import torch

try:
    sys.path.insert(0, str(Path(__file__).parent))
    from common_harness import (
        compute_parity_metrics,

        run_branch_comparison,

except ImportError:

    def compute_parity_metrics(base: Any, feat: Any) -> Dict[str, float]:
        if isinstance(base, dict):
            ms = [compute_parity_metrics(base[k], feat[k]) for k in base]
            return {
                "bit_exact_pct": float(sum(m["bit_exact_pct"] for m in ms) / len(ms)),
                "within_1ulp_pct": float(sum(m["within_1ulp_pct"] for m in ms) / len(ms)),
                "max_abs_diff": float(max(m["max_abs_diff"] for m in ms)),
                "cosine_sim": float(min(m["cosine_sim"] for m in ms)),
            }
        b_cpu, f_cpu = base.detach().cpu(), feat.detach().cpu()
        if b_cpu.numel() == 0:
            return {"bit_exact_pct": 100.0, "within_1ulp_pct": 100.0, "max_abs_diff": 0.0, "cosine_sim": 1.0}
        exact = float((b_cpu == f_cpu).float().mean().item() * 100.0)
        max_diff = float((b_cpu.double() - f_cpu.double()).abs().max().item())
        return {
            "bit_exact_pct": exact,
            "within_1ulp_pct": exact,
            "max_abs_diff": max_diff,
            "cosine_sim": 1.0 if max_diff == 0.0 else 0.0,
        }

    def measure_cuda_latency(fn: Callable[[], Any], warmup: int = 20, reps: int = 50) -> float:
        torch.cuda.synchronize()
        for _ in range(warmup):
            fn()
        torch.cuda.synchronize()
        starts = [torch.cuda.Event(enable_timing=True) for _ in range(reps)]
        ends = [torch.cuda.Event(enable_timing=True) for _ in range(reps)]
        for i in range(reps):
            starts[i].record()
            fn()
            ends[i].record()
        torch.cuda.synchronize()
        times = sorted(s.elapsed_time(e) for s, e in zip(starts, ends))
        return float(times[len(times) // 2])

    def run_branch_comparison(*args, **kwargs):
        raise RuntimeError("run_branch_comparison requires common_harness.py")


CASES: List[Tuple[str, str, int, int, int]] = []
for ql in [512, 2048, 4096]:
    for B in [1, 2, 4, 8, 16, 32, 64]:
        CASES.append((f"KV Sharing Fast Prefill Metadata (B={B}, max_query_len={ql}, sample=1)", "regime1", B, ql, 1))
for B in [1, 4, 8, 16, 32, 64]:
    CASES.append((f"KV Sharing Pure-Decode Step Prep (B={B}, max_query_len=1, max_tokens=8192)", "regime2", B, 1, 1))
for B, ml in [(1, 2), (8, 2), (32, 4)]:
    CASES.append((f"KV Sharing Spec-Decode Fallback (B={B}, max_query_len=512, max_logits={ml})", "regime3", B, 512, ml))


def warmup_gpu():
    x = torch.randn(1024, 1024, device="cuda", dtype=torch.float32)
    for _ in range(50):
        _ = torch.matmul(x, x)
    torch.cuda.synchronize()


def _make_common_meta(B: int, max_query_len: int, max_seq_len: int):
    from vllm.v1.attention.backends.utils import CommonAttentionMetadata

    device = torch.device("cuda:0")
    qsl = torch.arange(0, (B + 1) * max_query_len, max_query_len, dtype=torch.int32, device=device)
    seq_lens = torch.full((B,), max_seq_len, dtype=torch.int32, device=device)
    dummy = torch.zeros(1, dtype=torch.int32, device=device)
    return CommonAttentionMetadata(
        query_start_loc=qsl,
        query_start_loc_cpu=qsl.to("cpu"),
        seq_lens=seq_lens,
        num_reqs=B,
        num_actual_tokens=B * max_query_len,
        max_query_len=max_query_len,
        max_seq_len=max_seq_len,
        block_table_tensor=dummy,
        slot_mapping=dummy,
        causal=True,
        seq_lens_cpu_upper_bound=max_seq_len,
    )


def setup_regime1_metadata(B: int, max_query_len: int = 512):
    device = torch.device("cuda:0")
    meta = _make_common_meta(B, max_query_len, max_query_len)
    logits_indices = torch.arange(max_query_len - 1, B * max_query_len, max_query_len, dtype=torch.int64, device=device)
    padded = torch.zeros(max(B * 2, 128), dtype=torch.int64, device=device)
    padded[:B] = logits_indices
    meta.logits_indices_padded = padded
    meta.num_logits_indices = B
    meta.max_logits_per_req = 1
    return meta


def setup_regime2_metadata(B: int):
    device = torch.device("cuda:0")
    meta = _make_common_meta(B, 1, 128)
    logits_indices = torch.arange(0, B, 1, dtype=torch.int64, device=device)
    return meta, logits_indices


def setup_regime3_metadata(B: int, max_logits_per_req: int, max_query_len: int = 512):
    device = torch.device("cuda:0")
    meta = _make_common_meta(B, max_query_len, max_query_len)
    logits_list = [
        req_idx * max_query_len + max_query_len - max_logits_per_req + k
        for req_idx in range(B)
        for k in range(max_logits_per_req)
    ]
    logits_indices = torch.tensor(logits_list, dtype=torch.int64, device=device)
    num_logits = B * max_logits_per_req
    padded = torch.zeros(max(num_logits * 2, 128), dtype=torch.int64, device=device)
    padded[:num_logits] = logits_indices
    meta.logits_indices_padded = padded
    meta.num_logits_indices = num_logits
    meta.max_logits_per_req = max_logits_per_req
    return meta


def run_worker(out_path: Optional[str] = None) -> Dict[str, Any]:
    from vllm.v1.attention.backends.utils import make_kv_sharing_fast_prefill_common_attn_metadata
    from vllm.v1.worker.gpu_model_runner import GPUModelRunner

    warmup_gpu()
    has_guard = "max_query_len > 1" in inspect.getsource(GPUModelRunner._build_attention_metadata)
    buf = torch.zeros(8192, dtype=torch.int64, device="cuda:0")
    results = {}

    for name, regime, B, ql, ml in CASES:
        if regime == "regime1":
            meta = setup_regime1_metadata(B, max_query_len=ql)
            run_fn = lambda m=meta: make_kv_sharing_fast_prefill_common_attn_metadata(m)
        elif regime == "regime2":
            meta, logits_indices = setup_regime2_metadata(B)
            if not has_guard:
                def run_fn(m=meta, b=B, li=logits_indices):
                    buf[:b].copy_(li)
                    buf[b:] = li[-1]
                    m.logits_indices_padded = buf[:b]
                    m.num_logits_indices = b
                    m.max_logits_per_req = 1
                    return make_kv_sharing_fast_prefill_common_attn_metadata(m)
            else:
                def run_fn(m=meta):
                    m.logits_indices_padded = None
                    m.num_logits_indices = None
                    m.max_logits_per_req = None
                    return make_kv_sharing_fast_prefill_common_attn_metadata(m)
        else:
            meta = setup_regime3_metadata(B, max_logits_per_req=ml, max_query_len=ql)
            run_fn = lambda m=meta: make_kv_sharing_fast_prefill_common_attn_metadata(m)

        for _ in range(5):
            _ = run_fn()
        torch.cuda.synchronize()
        latency_ms = measure_cuda_latency(run_fn, warmup=20, reps=50)
        out_meta = run_fn()
        results[name] = {
            "latency_ms": latency_ms,
            "tensor": {
                "query_start_loc": out_meta.query_start_loc.cpu(),
                "query_start_loc_cpu": out_meta.query_start_loc_cpu,
                "max_query_len": torch.tensor([out_meta.max_query_len], dtype=torch.int64),
                "num_actual_tokens": torch.tensor([out_meta.num_actual_tokens], dtype=torch.int64),
            },
            "extra": f"tokens={out_meta.num_actual_tokens}, max_q={out_meta.max_query_len}",
        }

    if out_path:
        torch.save(results, out_path)
    return results


def print_comparison_table(data_base: Dict[str, Any], data_feat: Dict[str, Any]):
    print("| Case | Base (ms) | Feat (ms) | Speedup | Gain (%) | Bit-Exact (%) | Within 1-ULP (%) | Max Diff | Cos Sim | Extra |")
    print("| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |")
    for case, cb in data_base.items():
        if case not in data_feat:
            continue
        cf = data_feat[case]
        base_ms, feat_ms = cb["latency_ms"], cf["latency_ms"]
        speedup = base_ms / max(feat_ms, 1e-6)
        pct_gain = (speedup - 1.0) * 100.0
        parity = compute_parity_metrics(cb["tensor"], cf["tensor"])
        diff_str = f"{parity['max_abs_diff']:.2e}" if parity["max_abs_diff"] > 0 else "0.0"
        extra_str = f"{cb.get('extra', '')} -> {cf.get('extra', '')}"
        print(
            f"| {case} | {base_ms:.3f} | {feat_ms:.3f} | {speedup:.2f}x | {pct_gain:+.1f}% | "
            f"{parity['bit_exact_pct']:.1f}% | {parity['within_1ulp_pct']:.1f}% | {diff_str} | "
            f"{parity['cosine_sim']:.5f} | {extra_str} |"
        )


def run_standalone(save_path: Optional[str] = None):

    for name, r in results.items():

def get_model_gpu_mem(model_name: str) -> float:
    if "31B" in model_name:
        return 0.92
    if "26B" in model_name:
        return 0.90
    if "12B" in model_name:
        return 0.88
    return 0.85


def run_worker(model_name: str, out_path: str, kv_sharing_fast_prefill: Optional[bool] = None):
    from transformers import AutoTokenizer
    from vllm import LLM, SamplingParams

    llm_kwargs: Dict[str, Any] = {
        "model": model_name,
        "load_format": "dummy",
        "seed": 42,
        "enforce_eager": False,
        "max_model_len": 8192,
        "enable_prefix_caching": False,
        "gpu_memory_utilization": get_model_gpu_mem(model_name),
        "limit_mm_per_prompt": {"image": 0, "video": 0, "audio": 0},
    }
    if kv_sharing_fast_prefill is not None:
        llm_kwargs["kv_sharing_fast_prefill"] = kv_sharing_fast_prefill

    llm = LLM(**llm_kwargs)
    burn_a = torch.randn(2048, 2048, device="cuda", dtype=torch.bfloat16)
    burn_b = torch.randn(2048, 2048, device="cuda", dtype=torch.bfloat16)
    for _ in range(50):
        _ = torch.mm(burn_a, burn_b)
    torch.cuda.synchronize()
    del burn_a, burn_b

    tokenizer = AutoTokenizer.from_pretrained(model_name)
    filler_tokens = tokenizer.encode(
        "The rapid development of artificial intelligence enables efficient hardware execution. "
        "High performance computing and continuous batching accelerate deep learning serving workloads. ",
        add_special_tokens=False,
    )

    results: Dict[str, Any] = {"model": model_name, "kv_sharing_fast_prefill": kv_sharing_fast_prefill, "cases": {}}
    for campaign_name, in_len, out_len, batch_sizes in CAMPAIGNS:
        active_bs = [bs for bs in batch_sizes if bs <= 4] if "31B" in model_name else batch_sizes
        prompt_ids = (filler_tokens * math.ceil(in_len / len(filler_tokens)))[:in_len]
        prompt_str = tokenizer.decode(prompt_ids)

        for bs in active_bs:
            case_key = f"{campaign_name}_bs{bs}"
            prompts = [prompt_str] * bs
            sp = SamplingParams(max_tokens=out_len, temperature=0.0, seed=42, ignore_eos=True)
            for _ in range(5):
                llm.generate(prompts, sp, use_tqdm=False)

            gc.collect()
            gc.disable()
            times_ms, final_token_ids = [], []
            try:
                for it in range(7):
                    torch.cuda.synchronize()
                    t_start = time.perf_counter()
                    outputs = llm.generate(prompts, sp, use_tqdm=False)
                    torch.cuda.synchronize()
                    times_ms.append((time.perf_counter() - t_start) * 1000.0)
                    if it == 0:
                        final_token_ids = [list(o.outputs[0].token_ids) for o in outputs]
            finally:
                gc.enable()

            steady_ms = float(np.percentile(times_ms, 20))
            total_tok_s = (bs * (in_len + out_len)) / (steady_ms / 1000.0)
            gen_tok_s = (bs * out_len) / (steady_ms / 1000.0)
            results["cases"][case_key] = {
                "campaign": campaign_name,
                "batch_size": bs,
                "in_len": in_len,
                "out_len": out_len,
                "latency_ms": round(steady_ms, 2),
                "total_tok_s": round(total_tok_s, 2),
                "gen_tok_s": round(gen_tok_s, 2),
                "token_ids": final_token_ids,
            }

    with open(out_path, "w") as f:
        json.dump(results, f, indent=2)


def run_benchmark(selected_models: List[str] = ALL_MODELS):
    orig = subprocess.check_output(["git", "-C", VLLM_REPO, "rev-parse", "--abbrev-ref", "HEAD"], text=True).strip()
    if orig == "HEAD":
        orig = subprocess.check_output(["git", "-C", VLLM_REPO, "rev-parse", "HEAD"], text=True).strip()

    baseline_ref = "b6d8e8afd9"
    feature_branch = "lucianommartins/gemma4-pr2-kv-sharing-sync"
    script_path = str(Path(__file__).resolve())
    env = os.environ.copy()
    env["PYTHONPATH"] = f"{VLLM_REPO}:{env.get('PYTHONPATH', '')}"
    env["PYTHONUNBUFFERED"] = "1"

    jobs = [{"model": m, "explicit_flag": None, "suite": "default"} for m in selected_models]
    jobs += [{"model": m, "explicit_flag": True, "suite": "explicit_true"} for m in selected_models if "E2B" in m or "E4B" in m]

    def make_out_path(prefix: str, job: Dict[str, Any]) -> str:
        slug = job["model"].split("/")[-1].replace("-", "_").lower()
        tag = "default" if job["explicit_flag"] is None else "explicit_true"
        return f"/tmp/pr2_e2e_{prefix}_{slug}_{tag}.json"

    try:
        for job in jobs:
            for prefix, ref in [("base", baseline_ref), ("feat", feature_branch)]:
                out_p = make_out_path(prefix, job)
                subprocess.check_call(["git", "-C", VLLM_REPO, "checkout", "-q", ref])
                if os.path.exists(out_p):
                    os.remove(out_p)
                cmd = [PYTHON_ENV, script_path, "--mode", "worker", "--model", job["model"], "--out", out_p]
                if job["explicit_flag"] is not None:
                    cmd.extend(["--kv-sharing-fast-prefill", str(job["explicit_flag"])])
                subprocess.check_call(cmd, env=env)
    finally:
        subprocess.check_call(["git", "-C", VLLM_REPO, "checkout", "-q", orig])

    e2e_results: Dict[str, Any] = {"suites": {"default": {}, "explicit_true": {}}}
    for suite_key in ["default", "explicit_true"]:
        rel = [j for j in jobs if j["suite"] == suite_key]
        for job in rel:
            short_model = job["model"].split("/")[-1]
            b_path, f_path = make_out_path("base", job), make_out_path("feat", job)
            if not (os.path.exists(b_path) and os.path.exists(f_path)):
                continue
            b_data, f_data = json.load(open(b_path)), json.load(open(f_path))
            model_res = {}
            for campaign_name, in_len, out_len, batch_sizes in CAMPAIGNS:
                for bs in batch_sizes:
                    ck = f"{campaign_name}_bs{bs}"
                    if ck not in b_data["cases"] or ck not in f_data["cases"]:
                        continue
                    cb, cf = b_data["cases"][ck], f_data["cases"][ck]
                    base_ms, feat_ms = cb["latency_ms"], cf["latency_ms"]
                    base_tps, feat_tps = cb["total_tok_s"], cf["total_tok_s"]
                    b_toks, f_toks = cb.get("token_ids", []), cf.get("token_ids", [])
                    matches = sum(sum(1 for x, y in zip(bt, ft) if x == y) for bt, ft in zip(b_toks, f_toks))
                    total_t = sum(max(len(bt), len(ft)) for bt, ft in zip(b_toks, f_toks))
                    match_pct = (matches / max(total_t, 1)) * 100.0
                    model_res[ck] = {
                        "scenario": campaign_name,
                        "batch_size": bs,
                        "in_len": in_len,
                        "out_len": out_len,
                        "base_ms": base_ms,
                        "feat_ms": feat_ms,
                        "e2e_speedup": round(base_ms / max(feat_ms, 1e-6), 3),
                        "base_total_tok_s": base_tps,
                        "feat_total_tok_s": feat_tps,
                        "throughput_speedup": round(feat_tps / max(base_tps, 1e-6), 3),
                        "token_match_pct": round(match_pct, 1),
                    }
            e2e_results["suites"][suite_key][short_model] = model_res

    with open(RESULTS_FILE, "w") as f:
        json.dump(e2e_results, f, indent=2)


def main():

## Details

### Root Cause
In models using KV-sharing architectures (such as Gemma 4 E2B/E4B), non-shared layers execute full attention across all sequence tokens, whereas shared layers only compute attention for newly sampled prompt tokens (fast prefill). In upstream `main` (`b6d8e8afd9`), fast prefill was disabled by default (`kv_sharing_fast_prefill = False`), leaving users with full prefill computation across all shared layers and forfeiting massive throughput improvements.

Furthermore:
1. `make_kv_sharing_fast_prefill_common_attn_metadata` unconditionally ran a generalized scatter/histogram pipeline to compute per-request decode token counts:
   - `torch.bucketize` to map logit indices to request IDs.
   - `torch.zeros` and `torch.ones_like` tensor allocations.
   - `scatter_add_` to count decode tokens per request.
   - `torch.empty`, `fill_(0)`, and `torch.cumsum` to construct `decode_query_start_loc`.
   - Non-blocking D2H transfer `decode_query_start_loc.to("cpu", non_blocking=True)` to populate `decode_query_start_loc_cpu`.
   While avoiding host-blocking synchronizations, executing 6 GPU kernel launches and a PCIe transfer introduces fixed kernel launch overhead per prefill request. For single-logit sampling (`max_logits_per_req == 1`), every request contributes exactly 1 token, making dynamic histogram computation redundant.
2. On pure-decode steps (`max_query_len == 1`), `GPUModelRunner._build_attention_metadata` did not guard `_prepare_kv_sharing_fast_prefill(logits_indices)`, unconditionally executing GPU buffer copy and fill over 8192 tokens (`kv_sharing_fast_prefill_logits_indices`) even though `make_kv_sharing_fast_prefill_common_attn_metadata` immediately returns when `max_query_len == 1`.
3. In `Gemma4Model`, `self.norm` was applied eagerly outside `torch.compile` after `cross_decoder` on every step, rather than being captured inside `Gemma4CrossDecoderLayers` alongside the decoder layers, and redundant buffer copy of `positions` occurred before `self_decoder`.

### Design & Implementation
1. **Config Auto-Enablement in `config.py`**: When `num_kv_shared_layers > 0`, `speculative_config is None`, `parallel_config.pipeline_parallel_size == 1`, and `DiffusionGemmaForBlockDiffusion not in architectures`, `Gemma4Config.verify_and_update_config` automatically sets `kv_sharing_fast_prefill = True` in `CacheConfig`, enabling fast prefill by default for all KV-sharing models while preserving explicit user overrides.
2. **Piecewise CUDAGraph & Model Optimizations in `gemma4.py`**:
   - Moved `self.norm` into `Gemma4CrossDecoderLayers` so `torch.compile` and `CUDAGraphMode.PIECEWISE` fuse and capture `self.norm` inside the compiled `cross_decoder` subgraph, returning normalized hidden states directly without eager post-processing.
   - Removed redundant `self.positions[:batch_size].copy_(positions)` before `self.self_decoder`.
   - Integrated piecewise CUDAGraph dispatch for the cross-decoder when `self._use_piecewise_cudagraph and num_padded in self._cudagraph_capture_sizes and (orig_runtime_mode == CUDAGraphMode.PIECEWISE or compilation_counter.num_cudagraph_captured > 0)`. This allows cross-decoder piecewise CUDAGraph replay on prefill batches even when `total_tokens > 512` (`orig_runtime_mode == CUDAGraphMode.NONE`), while avoiding default stream capture errors during `_warmup_kernels` (`num_cudagraph_captured == 0`).
   - Removed `.clone()` in `fast_prefill_forward`, directly indexing into pre-allocated static GPU buffers (`self.positions`, `self.hidden_states`, `self.per_layer_inputs`).
   - Added a dedicated decode fast path when `logits_indices_padded is None` to bypass index lookup operations.
   - Sliced assignment: `self_decoder_hidden_states[logits_indices_padded[:num_logits_indices]] = cross_hidden_states[:num_logits_indices]`, ensuring padding tokens are never copied.
3. **Pigeonhole Specialization in `utils.py`**: When `common_attn_metadata.max_logits_per_req == 1 and num_logits_indices == num_reqs`, each request samples strictly 1 token. Therefore, `decode_query_start_loc` is guaranteed to be `[0, 1, ..., num_reqs]`. We directly construct `torch.arange(0, num_reqs + 1, device=device, dtype=query_start_loc.dtype)` on GPU and `torch.arange(0, num_reqs + 1, device="cpu", dtype=query_start_loc.dtype)` on CPU. This replaces 6 GPU kernel launches (`torch.bucketize`, `torch.zeros`, `torch.ones_like`, `scatter_add_`, `fill_`, `torch.cumsum`) and 1 PCIe D2H transfer with 1 GPU `torch.arange` kernel.
4. **Pure-Decode Guard in `gpu_model_runner.py`**: Added `and max_query_len > 1` to the KV-sharing condition in `GPUModelRunner._build_attention_metadata`. On pure-decode steps (`max_query_len == 1`), buffer staging and CUDAGraph dispatch are bypassed, saving ~0.04 ms per decode step and aligning V1 `GPUModelRunner` with V2 `FastPrefillHelper.prepare`.
5. **Metadata Class Memoization & Factory Caching in `utils.py`**:
   - `_get_fast_prefill_metadata_cls(metadata_cls: type)`: Decorating this class factory with `@functools.lru_cache` eliminates dynamic creation of `class KVSharingFastPrefillAttentionMetadata(metadata_cls, KVSharingFastPrefillMetadata)` and `typing._ProtocolMeta.__new__` / `dataclasses.fields()` on every forward step, constructing the wrapper class once per unique metadata type.
   - `create_fast_prefill_custom_backend`: Decorating with `@functools.lru_cache` ensures identical `(prefix, underlying_attn_backend)` pairs reuse the same custom backend and builder classes across layers and KV-cache groups.
6. **Pure-Decode Same-Group Attention Metadata Reuse in `gpu_model_runner.py`**:
   - On pure-decode steps (`logits_indices_padded is None` and `not for_cudagraph_capture`) with `kv_sharing_fast_prefill=True`, donor layers (`attn_gid=0`) and recipient layers (`attn_gid=1`) within each KV-cache group share the exact same `KVCacheSpec` and `cascade_attn_prefix_len`.
   - `same_group_decode_cache: dict[tuple[int, KVCacheSpec, int], AttentionMetadata]` captures the built metadata from `attn_gid=0` and directly serves `attn_gid=1`, eliminating duplicate `builder.build(...)` execution on pure-decode steps.
7. **Speculative Decoding Fallback**: When `max_logits_per_req > 1` (e.g. speculative decoding draft tokens), execution falls back to the generalized `scatter_add_` + `cumsum` path, guaranteeing 100.0% numerical compatibility and zero regression.
