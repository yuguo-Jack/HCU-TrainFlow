# [CI] Avoid nested CUPTI control in bench forward profiles

[Upstream PR](https://github.com/vllm-project/vllm/pull/62300) · state: open · merged: False

## Original PR description

## Overview

Stop calling `cudaProfilerStart`/`cudaProfilerStop` while `torch.profiler` owns CUPTI for `vllm bench forward --profile-dir`.

PR #61692 added both mechanisms around the same graph replays. The new H200 Benchmarks CLI test passed once in PR build #95582, then failed in daily builds #95663 and #95703 on two different hosts with an empty trace plus `bufferCompleted called with unknown buffer`. This keeps the CUDA profiler markers for the Nsight Systems path (without `--profile-dir`) and lets `torch.profiler` exclusively own CUPTI for the JSON/Perfetto path.
