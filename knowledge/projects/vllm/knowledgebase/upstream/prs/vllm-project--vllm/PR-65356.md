# [Bugfix] Fix DeepSeek-V4.1-Flash boot failure on SM120 (RTX PRO 6000 Blackwell): allow 64-page block size for sparse-MLA and indexer backends

[Upstream PR](https://github.com/vllm-project/vllm/pull/65356) · state: open · merged: False

## Original PR description

## Problem

DeepSeek-V4.1-Flash (hybrid full sparse-MLA + SWA + indexer + compressor) fails to boot on **SM120** (RTX PRO 6000 Blackwell / RTX 6000D) with two distinct block-size failures, because SM120 falls into the untested `else 128` buckets of the sparse-MLA and indexer backends:

| Config | Result |
|---|---|
| block 128 (vLLM's choice for SM120) | config passes → kernel init crashes: `Assertion error: block_kv == 32 or block_kv == 64` (flashinfer `csrc/apis/attention.hpp`) |
| block 64, unpatched | config error: `No common block size for 64 (FLASHINFER_MLA_SPARSE_DSV41: [128])` |
| block 64, sparse backend patched | config error: `No common block size for 64 (DEEPSEEK_V41_INDEXER: [128])` |
| block 64, both patched (this PR) | ✅ boots and serves |

## Root cause

flashinfer's SM120 sparse-MLA/SWA kernels accept only 64-token pages — the same layout as the Hopper family (flashinfer#4380). 128-page is only valid on SM100, which runs the TRTLLM-gen/FlashMLA path. Both backends hard-code the 128 assumption for everything that isn't Hopper, so upstream effectively never booted DSV4.1 on SM120.

## Fix

Two one-line conditional updates (SM100/Hopper behavior unchanged):

1. `flashinfer_sparse.py` — the DSV41 sparse backend's `get_supported_kernel_block_sizes` now returns `[64]` on SM120
2. `indexer.py` — `DeepseekV41IndexerBackend.get_supported_kernel_block_sizes` now treats SM120 like Hopper (64-page). The arch-12 fp4/fp8 indexer kernels support this layout; validated with `indexer_kv_dtype=mxfp4`.

## Validation

- Boots and serves on 8x RTX 6000D (TP8 + EP, DSpark speculative decoding, 1M context) in continuous production across multiple nodes
- Full acceptance suites pass (multi-tool agent traces, 128K–1M needle/math ladders, streaming-drop, fuzzed protocol cases)
- SM100 paths untouched: the conditional only adds SM120 to the 64-page branch
