# [Model][Hardware][AMD] Fuse DSR1 Input Projection with Dual RMS + Quant

[Upstream PR](https://github.com/vllm-project/vllm/pull/62746) · state: open · merged: False

## Original PR description

## Overview

This PR adds an AITER fusion pass for the MLA input projection. It fuses the GEMM, the q/kv RMSNorm and the q per-token FP8 quant. Requires https://github.com/ROCm/aiter/pull/6850.

## Claims

- MI355X, DeepSeek-R1 MXFP4 `fused_qkv_a_proj` (N=2112, K=7168): GEMM + q/kv RMSNorm + q per-token FP8 quant is 0.9–5.2 µs faster per layer for decode batches M <= 256, -5% to -40%.
