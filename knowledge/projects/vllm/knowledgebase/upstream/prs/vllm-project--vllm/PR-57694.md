# [Docs][KV Connector][NIXL] Document stats aggregation semantics (CLI vs Prometheus)

[Upstream PR](https://github.com/vllm-project/vllm/pull/57694) · state: open · merged: False

## Original PR description

Closes #41230.

Adds a subsection to the NixlConnector usage guide explaining how
NixlKVConnectorStats.aggregate()/.reduce() (used for the periodic CLI
log line) and NixlPromMetrics (used for the /metrics endpoint) compute
their numbers independently from the same raw transfer data — so CLI and
Prometheus percentiles/averages for the same window aren't expected to
match exactly. Also documents the failure-only-interval edge case in
is_empty().

Docs-only change, no code touched.

This PR description and doc wording were drafted with AI assistance
(Claude) and reviewed by the submitter before opening.
