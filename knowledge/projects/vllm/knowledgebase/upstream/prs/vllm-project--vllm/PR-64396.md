# [CI][XPU] Extend batch-invariance tests in Intel CI

[Upstream PR](https://github.com/vllm-project/vllm/pull/64396) · state: closed · merged: True

## Original PR description

## Overview
Until now the `:intel: (BMG) Batch Invariance` job only ran the XPU unit tests and the online PowerMoE script, so regressions in `test_batch_invariance.py` on XPU were not caught.

This adds to the existing job:
- `v1/determinism/test_batch_invariance.py` (single card, TRITON_ATTN)
- `test_batch_invariance.py -k "bs1_vs_bsN or without_batch_invariance_should_fail"` with TP=2
  (covers the fixed-rank-order XCCL reduction from #55881)

and widens `source_file_dependencies` to `tests/v1/determinism/`.

`test_matmul_batch_invariant.py` also passes on XPU but is left out for now since it is on the test-tethering allowlist; it will be added in a follow-up.

## Test Plan
Ran the job's command on 8x Arc Pro B60

## Test Results

| Command | Result | Time |
|---|---|---|

| run-xpu-batch-invariance.sh | passed | 190s |

Sequential total ≈ 20 min, within the job's 60 min timeout.
