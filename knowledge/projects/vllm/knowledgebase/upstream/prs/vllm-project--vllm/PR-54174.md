## Overview

Add D-Spark speculative decoding for [Ling 3.0 Flash](https://huggingface.co/inclusionAI/Ling-3.0-flash) using the official [Ling D-Spark draft](https://huggingface.co/inclusionAI/Ling-3.0-flash-dspark). The Ling draft is normalized onto the existing Qwen3 D-Spark runtime; no new drafter is added.

## Claims

- `LingDSparkModel` drafts are validated against a `BailingMoeV3ForCausalLM` target and mapped to `Qwen3DSparkModel`. The draft checks shared with Qwen3-Omni D-Spark now live in one helper (`_validate_qwen3_dspark_draft`).
- `BailingMoeV3` exposes the auxiliary hidden states D-Spark needs (`SupportsEagle3`).
- The draft's `block_size` is the default `num_speculative_tokens`; an explicit value still takes precedence.
- On hybrid MLA targets, a DFlash/D-Spark draft whose KV page would exceed the target page uses a smaller KV block that fits the target page, instead of inflating the target's MLA/KDA pages (or failing page-size unification).

## Details

**Draft KV block size.** Ling pairs an MLA/KDA hybrid target with a dense MHA draft. The hybrid alignment raises the global block size until the MLA page covers the KDA state, for example 512 tokens at TP=4. At that block size the draft's MHA page is about 3.6x the target page. MLA pages cannot be padded, so page-size unification fails.

`_DFlashAttention.get_kv_cache_spec` now picks the largest block size that meets three conditions:

- it divides the global block size, so the scheduler LCM is unchanged;
- the backend runs it directly, without splitting the block;
- its page fits in the target page (`cache_config.mamba_page_size_padded`).

Unification then pads the draft page up to the target page. For Ling 3.0 Flash this gives 128 tokens at TP=1/2/4/8, with 88.9% of each draft page used. No core KV-cache code is changed.

The E2E engine log confirms the geometry: target block 512, Mamba page padded by 0.70%, and an LCM of 512 across KV cache groups.

The draft's dense MHA KV (32 KV heads) is much larger per token than the target's MLA KV. Adding the draft reduces KV capacity from 13.9M to 3.1M tokens at TP=4. That cost comes from the draft architecture, not from the block size.

**Scope.** Only hybrid MLA targets use this path. Non-MLA hybrid targets with larger DFlash drafts, such as Qwen3.5 + DFlash, keep their current behavior.
