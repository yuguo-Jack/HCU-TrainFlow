# [Frontend][Responses] Reject empty assistant message content with 400 instead of 500

[Upstream PR](https://github.com/vllm-project/vllm/pull/64941) · state: open · merged: False

## Original PR description

Fixes #64940.

An assistant message with an empty content list (`{"type": "message", "role": "assistant", "content": []}`) passed request validation but crashed the render path with `IndexError` in `_construct_message_from_response_item`, returning a 500. This rejects it at validation with a clear 400, following the precedent of #55974.
