# [CI][Tests] Remove timing dependence from Engram prefetch synchronization test

[Upstream PR](https://github.com/vllm-project/vllm/pull/65439) · state: closed · merged: True

## Original PR description



## Overview



```test_engram_shared_prefetch_stream_waits_per_layer``` passes in isolation but fails in the full miscellaneous-kernel shard on Rubin and GB200. The test inserts a fixed GPU delay and assumes the second lookup must remain incomplete when the first consumer finishes. However, the second lookup finishing does not prove that the consumer waited for it.

This change observes the actual ```torch.cuda.Stream.wait_event``` calls during consumption and verifies that the consumer waits only on its own layer’s completion event. The observer forwards calls to the original CUDA implementation, preserving real GPU execution. Both lookups and the exact numerical comparison (rtol=0, atol=0) remain unchanged.
