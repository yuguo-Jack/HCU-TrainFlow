## Original PR description

### Overview

Fix for currently [failing on main](https://buildkite.com/vllm/ci/builds/94697/list?jid=01a13933-6e95-4963-9ccf-e08c7dabdbc0&tab=output) CI job `(CPU) Multimodal Processor Shard 1`. Failing test is `tests/models/multimodal/processing/test_common.py` because of model baidu/Unlimited-OCR in last commit renamed model type from `unlimited-ocr` to `unlimited_orc`, see [commit](https://huggingface.co/baidu/Unlimited-OCR/commit/8249d20b2822a7d8a4c22c8d8c9069b5ac36bda3).
