# [Pooling] Preserve reranker tokenization with document limits

[Upstream PR](https://github.com/vllm-project/vllm/pull/57666) · state: closed · merged: True

## Original PR description

## Purpose

For non-separator rerankers, a positive `max_tokens_per_doc` could change the prompt and score even when it didn't truncate the document. This limits the document first, then tokenizes the combined prompt once. Separator-based rerankers are unchanged.

## Reproducer

```bash
CUDA_VISIBLE_DEVICES=0 VLLM_USE_V2_MODEL_RUNNER=1 .venv/bin/python - <<'PY'
from vllm import LLM, PoolingParams

llm = LLM(
    model="tomaarsen/Qwen3-Reranker-0.6B-seq-cls",
    runner="pooling",
    dtype="half",
    seed=17,
    trust_remote_code=True,
    hf_overrides={"use_sep_token": False},
    enforce_eager=True,
    max_model_len=128,
    max_num_batched_tokens=128,
    gpu_memory_utilization=0.25,
)
try:
    for name, limit in (("uncapped", None), ("nonbinding_100", 100)):
        extra = None if limit is None else {"max_tokens_per_doc": limit}
        out = llm.score(
            "alpha ",
            "beta gamma delta epsilon",
            pooling_params=PoolingParams(use_activation=False, extra_kwargs=extra),
            tokenization_kwargs={"add_special_tokens": False},
            use_tqdm=False,
        )[0]
        print(f"{name}: ids={list(out.prompt_token_ids)} raw={out.outputs.score:.12f}")
finally:
    llm.llm_engine.engine_core.shutdown()
PY
```
