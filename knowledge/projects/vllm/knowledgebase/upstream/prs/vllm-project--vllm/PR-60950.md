# [BreakableGraph][Bugfix] Bailing V3: make KDA attention an eager break

[Upstream PR](https://github.com/vllm-project/vllm/pull/60950) · state: open · merged: False

## Original PR description



## Overview


Running Bailing V3 with breakable cudagraph fails during graph capture on XPU:

    VLLM_USE_BREAKABLE_CUDAGRAPH=1 vllm serve inclusionAI/Ling-3.0-tiny-fp8 --trust_remote_code

    File ".../bailing_moe_v3.py", line 1067, in _forward
        zero_idx = state_indices[~has_initial_state]
    torch.AcceleratorError: CUDA error: operation not permitted when stream is capturing

Under the default compile + piecewise_cudagraph path, `vllm::bailing_v3_kda_attention` is registered in splitting_ops, so the compile + graph execution path works correctly without issues.

This PR adds `eager_break_during_capture` to `BailingMoeV3KDA._forward` to align the breakable CUDA Graph behavior with the default path.
