# fix(anthropic): pass tools=None in _detect_merge_inline_system (#61919)

[Upstream PR](https://github.com/vllm-project/vllm/pull/61920) · state: open · merged: False

## Original PR description

### What type of PR is this?
Bug fix

### Description
In `AnthropicServingMessages._detect_merge_inline_system`, the chat template is probed by rendering a sample conversation to determine whether inline system messages require merging. Models whose chat templates check `tools is not none` (such as `allenai/Olmo-3-7B-Instruct`) attempt `tools | tojson` when `tools` is not passed to `render()`, triggering a `TypeError: Object of type Undefined is not JSON serializable`.

Passing `tools=None` when rendering the probe conversation satisfies templates that check `tools is not none`, allowing them to cleanly bypass the tool block and evaluate whether system message merging is necessary without error, while keeping exception handling narrowly scoped to `jinja2.TemplateError`.

Closes #61919
