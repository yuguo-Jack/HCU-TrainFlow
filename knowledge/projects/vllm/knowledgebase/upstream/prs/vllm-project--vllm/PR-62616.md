## Overview

Add `kaldi-native-fbank` to the XPU test requirements, which `FireRedASR2Processor` needs. It is already in the cuda/rocm test requirements. Fixes Intel CI failure: https://buildkite.com/vllm/intel-ci/builds/14740#01a156e9-87c0-4a3e-8d41-4d921d8fb0a5

## Claims

- `test_model_tensor_schema[allendou/FireRedASR2-LLM-vllm]` no longer fails with `ModuleNotFoundError: No module named 'kaldi_native_fbank'` on XPU.

## Validation

With `kaldi-native-fbank==1.22.3` installed, on an Intel XPU :

```
pytest "tests/models/multimodal/processing/test_tensor_schema.py::test_model_tensor_schema[allendou/FireRedASR2-LLM-vllm]"
1 passed
```

## Details

No duplicate: searched open PRs for "kaldi-native-fbank xpu" and "FireRedASR2 xpu" and found none. `xpu.txt` was edited by hand to match the `cuda.txt` pin (1.22.3), not regenerated with `uv pip compile`.
