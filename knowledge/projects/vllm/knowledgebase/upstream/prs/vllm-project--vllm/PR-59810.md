# [Bugfix][DBO] Fix crash when merging auxiliary hidden states

[Upstream PR](https://github.com/vllm-project/vllm/pull/59810) · state: open · merged: False

## Original PR description



## Overview

With DBO and DFlash, the target model returns `(hidden_states, [aux_0, ...])` for each microbatch. The merge helper handles only flat tuples, so it passes the auxiliary lists to `torch.cat` and crashes:

```text
TypeError: expected Tensor as element 0 in argument 0, but got list
```

## Claims

Concatenate corresponding tensors recursively, preserving the tuple/list structure and token order. Apply the fix to both GPU runner helpers and extend their existing regression tests.

## Validation

On two B300 GPUs with Qwen3-30B-A3B + DFlash, DP=2/TP=1/EP, DeepEP high throughput and eager Triton attention:

```text
Before: DBO on -> first batched generation request returns HTTP 500
After:  DBO on -> all 32 requests complete; token IDs match DBO-off main
```

| GSM8K, 256 questions | Control | With fix |
| --- | --- | --- |
| Qwen3-30B-A3B + DFlash, MRV1 (control: DBO off) | 237/256 | 237/256 |
| DeepSeek-V2-Lite-Chat, MRV1 (DBO on both) | 172/256 | 172/256 |
| DeepSeek-V2-Lite-Chat, MRV2 (DBO on both) | 172/256 | 172/256 |

Each pair matches all **32 smoke token sequences** and **256 GSM8K answer texts and predictions**. Runs use batch-invariant mode; Qwen accepted **54.93%** of draft tokens. Tested main: `fa212b8dc5`; fix: `f7454f7f3f`.

- **49 tests passed**, including nested outputs, eager interleaving and CUDA graph replay. All six nested-output regression cases fail on main.
- Pre-commit and Linux Python 3.12 mypy passed.

## Details

This extends the flat-tuple fix in #40789. Oct 2 searches found no open PR covering nested-output merging; #45378 and #48659 address separate slot-mapping and attention-cache bugs. Neither is needed for the tested configuration.

MRV2's helper has the same merge bug, but MRV2 DBO + speculation remains gated. Full-model CUDA graph runs hit a DeepEP capture timeout on main as well as the preliminary candidate; only eager full-model serving and the focused graph regression passed.
