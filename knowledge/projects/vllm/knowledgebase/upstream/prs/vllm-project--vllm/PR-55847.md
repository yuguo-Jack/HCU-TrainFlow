# [CPU] Torch fallbacks for Model Runner V2 kernels on CPU without Triton

[Upstream PR](https://github.com/vllm-project/vllm/pull/55847) · state: open · merged: False

## Original PR description

## Purpose
The V2 model runner (vllm/v1/worker/gpu) carries 57 launchable @triton.jit entry points, so it cannot start on a CPU without Triton. requirements/cpu.txt installs the triton-cpu wheel for platform_machine == "x86_64" only, so that gap is the non-x86 CPU targets This adds torch equivalents for the 13 that the per-step path reaches, under `vllm/v1/worker/cpu/`, installed at import time so no shared GPU code changes, and relaxes the `HAS_TRITON` requirement for CPU only.


## Test Plan
```bash
VLLM_USE_V2_MODEL_RUNNER=1 vllm bench throughput \
  --model <model> --dtype bfloat16 \
  --random-input-len 128/1024 --random-output-len 128/1024 --num-prompts 256 \
  --max-num-seqs <batch> --seed 0
```
