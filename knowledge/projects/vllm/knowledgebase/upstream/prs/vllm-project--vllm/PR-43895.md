## Original PR description

## [PERF] Vedic 4-bit MatMul for MLA Attention — 3.5x CPU speedup

### Problem
vLLM MLA attention bottleneck (`mla_attention.py:128`): large matmuls dominate CPU inference.

### Solution
Custom 4-bit quantized matmul with block-8 unpacking and INT8 accumulation.

### Benchmarks (CPU, 128x1536 @ 1536x1536)

| Metric | FP32 | This PR | Improvement |
|--------|------|---------|-------------|
| Latency | 274 ms | **78 ms** | **3.5x faster** |
| Weight memory | 9216 KB | **1152 KB** | **87.5% reduction** |
| Throughput | 2.2 GFLOPS | **7.8 GFLOPS** | **3.5x** |

### Integration
```python
# In mla_attention.py, replace line 69:
q_nope = vedic_4bit_matmul(q_c, self.W_UQ_packed, self.W_UQ_scale).view(Sq, N, P)
```

Weights packed once at load time. No CUDA required. Tested on Android/Termux.

**Suggestion:** The overflow check on lines 34-35 is broken: performing `N * K` as signed `int64_t` on line 34 is undefined behavior if it overflows, so the compiler may legally optimize away the post-hoc division check on line 35.
