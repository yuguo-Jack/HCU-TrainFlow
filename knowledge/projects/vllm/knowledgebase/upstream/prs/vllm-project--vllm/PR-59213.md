# [Bugfix][Mistral] Map arbitrary tool call IDs instead of truncating

[Upstream PR](https://github.com/vllm-project/vllm/pull/59213) · state: open · merged: False

## Original PR description

## Purpose

Fixes #59212.

Instead of keeping the last 9 chars, keep IDs that are already valid and hash the others to 9 base62 chars. Calls and results get the same mapping, and it's stable across turns. Also removes the per-call warning (#58647).

Not duplicating anything: #47739 is about generated IDs for `tool_choice="required"`.

## Test Plan

```
pytest tests/tokenizers_/test_mistral.py tests/renderers/test_mistral.py tests/parser/mistral
pytest tests/entrypoints/openai/chat_completion/test_serving_chat.py -k mistral
```

## Test Result

New tests (v3 + v13 tokenizers, long/short/non-alphanumeric/shared-suffix IDs): 6/9 fail on main, all pass with this PR. Existing suites pass, ruff clean.
