# [ROCm][Perf] Batch short TurboQuant verify blocks and enable split-KV

[Upstream PR](https://github.com/vllm-project/vllm/pull/61264) · state: open · merged: False

## Original PR description

## Overview

Batch short TurboQuant continuation/verification requests and preserve their real query blocks so the existing attention kernel can reuse KV history and select split-KV. Actual vLLM HTTP serving on MI355X improves **2.71x, 1.66x and 1.14x** across the three eager speculative-decoding cells below.

Follow-up to AMD's #47896. No Triton kernel body or cache-format change. This closes both launcher selection and backend integration: a launcher-only change left the backend issuing attention separately for each request.

The large gains are specific to eager execution. Default graph-enabled serving is measured separately below; these are not universal serving speedups.

## Claims

- Short SoA continuation batches with an explicit maximum query length of at most 32 use one batched attention call, real query offsets, and the existing decode-sized/split-KV policy. First prefills keep their original raw-K/V path; long/mixed batches retain per-request handling.
- No new GPU-to-host read or synchronization, scheduler change, or stored-cache-format change. All six Triton kernel bodies are unchanged.
- ROCm D256 uses the existing launcher-side query rotation, avoiding the fused rotation's 262144-byte LDS request on a device with a 163840-byte limit.

```python
"""Run against one already-started baseline or patched vLLM server."""
import asyncio
import json
import os
import time

import aiohttp
from transformers import AutoTokenizer

URL = os.environ.get('SERVER_URL', 'http://127.0.0.1:8000')
MODEL = os.environ.get('MODEL', 'Qwen/Qwen2.5-3B-Instruct')
TOKENIZER = AutoTokenizer.from_pretrained(
    MODEL, revision='aa8e72537993ba99e69dfaafa59ed015b17504d1'
)
UNIT = TOKENIZER.encode(
    'The red fox visits the blue lake. The green bird visits the yellow tree. ',
    add_special_tokens=False,
)
ENDING = TOKENIZER.encode(
    '\nContinue repeating the following text exactly: The red fox visits the blue lake. '
    'The green bird visits the yellow tree.\n', add_special_tokens=False,
)


def prompt(length, index):
    prefix = TOKENIZER.encode(f'Document {index:06d}.\n', add_special_tokens=False)
    body = (UNIT * ((length + len(UNIT) - 1) // len(UNIT)))
    return prefix + body[:length - len(prefix) - len(ENDING)] + ENDING


async def request(session, ids, output):
    start = time.perf_counter()
    first = last = None
    tokens = []
    usage = None
    async with session.post(URL + '/v1/completions', json={
        'model': 'qwen', 'prompt': ids, 'max_tokens': output, 'temperature': 0,
        'ignore_eos': True, 'stream': True, 'return_token_ids': True,
        'stream_options': {'include_usage': True},
    }) as response:
        assert response.status == 200, await response.text()
        async for line in response.content:
            line = line.decode().strip()
            if not line.startswith('data: ') or line == 'data: [DONE]':
                continue
            data = json.loads(line[6:])
            if data.get('usage'):
                usage = data['usage']
            for choice in data.get('choices', []):
                delta = choice.get('token_ids') or []
                if delta or choice.get('text'):
                    last = time.perf_counter()
                    if first is None:
                        first = last
                    tokens.extend(delta)
    assert usage['prompt_tokens'] == len(ids)
    assert usage['completion_tokens'] == len(tokens) == output
    return {'ttft': first - start, 'tpot': (last - first) / (output - 1),
            'output_ids': tokens}


async def cell(session, length, concurrency, output, warmup=False):
    for _ in range(20):
        async with session.post(URL + '/reset_prefix_cache') as response:
            assert response.status == 200
            reset = await response.json()
        if reset['success']:
            break
        await asyncio.sleep(.25)
    else:
        raise RuntimeError('Prefix-cache reset failed')
    semaphore = asyncio.Semaphore(concurrency)

    async def one(index):
        async with semaphore:
            return await request(session, prompt(length, index + (500000 if warmup else 0)), output)

    count = concurrency if warmup else 2 * concurrency
    start = time.perf_counter()
    records = await asyncio.gather(*(one(i) for i in range(count)))
    duration = time.perf_counter() - start
    print(json.dumps({'input': length, 'concurrency': concurrency, 'output': output,
                      'warmup': warmup, 'seconds': duration,
                      'tokens_per_second': count * output / duration, 'records': records}))


async def main():
    cells = json.loads(os.environ.get('CELLS', '[[1024,16,128],[8192,16,128],[8192,64,128]]'))
    async with aiohttp.ClientSession(timeout=aiohttp.ClientTimeout(total=900)) as session:
        for length, concurrency, output in cells:
            await cell(session, length, concurrency, 16, warmup=True)
            await cell(session, length, concurrency, output)


asyncio.run(main())
```

## Details

The unified kernel already has per-query causal masking. The original launcher classified multi-row verify blocks as prefill-like; the backend also expanded short continuations into synthetic single-token requests and launched separately per sequence. Passing real offsets and batching short continuation requests removes those integration costs while selecting the existing 3D kernel. Long blocks, caller tile overrides, `force_2d`, the 1024-token split threshold and conservative missing-maximum fallback retain their behavior. This does not implement the full-graph metadata changes proposed in #53410.

The previously reported **2.785x** AgentX result used SGLang calling AMD's public vLLM kernel. It motivated the PR, but is not this PR's vLLM serving result. The table above supplies that missing validation.
