# [Perf] Add VLLM_GC_THRESHOLDS to set GC thresholds after the heap freeze

[Upstream PR](https://github.com/vllm-project/vllm/pull/62086) · state: open · merged: False

## Original PR description

## Purpose

EngineCore, the GPU workers and the API server freeze their startup heap but keep CPython's default GC thresholds, so under high request load EngineCore still spends a noticeable share of each step in gen-1/gen-2 collections. This adds an opt-in `VLLM_GC_THRESHOLDS` (e.g. `50000,20,100`), applied in `freeze_gc_heap()` right after the freeze. Unset keeps the current behaviour.

## Test Plan

New unit test in `tests/utils_/test_gc_utils.py`. GLM-4.5-Air TP8 on H200, `enable_return_routed_experts`, 400 concurrent `/inference/v1/generate` requests: `50000,20,100` gives +3.0% to +4.5% generation tok/s (2 nodes; EngineCore GC time 4.6% -> 0% of wall time).

AI assistance (Claude) was used; all changes were reviewed by the submitter.
