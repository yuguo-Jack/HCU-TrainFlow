# Rewrite worker block tables after SWA eviction

[Upstream PR](https://github.com/vllm-project/vllm/pull/42276) · state: open · merged: False

## Original PR description

Fixes #42273

Summary:
- Track requests whose CPU-side block tables are rewritten by SWA skipped-block removal.
- Have the scheduler send the full rewritten block table for those cached requests instead of only incremental new blocks.
- Update both worker block-table paths to overwrite rows when a rewrite is requested.
- Add scheduler/core/worker regressions for SWA eviction and block-table replacement.

## Code Review

This pull request implements a mechanism to handle block table rewrites for cached requests, specifically addressing scenarios where Sliding Window Attention (SWA) eviction replaces earlier logical slots with null blocks. The KVCacheManager and KVCacheCoordinator now track when a block table is updated, and the Scheduler communicates this via a new block_table_rewrite_req_ids field in CachedRequestData. Correspondingly, the GPU model runners have been updated to overwrite the block table instead of appending when a rewrite is signaled.
