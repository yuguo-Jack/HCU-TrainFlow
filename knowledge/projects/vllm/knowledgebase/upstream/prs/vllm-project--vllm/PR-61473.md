## Overview

Enroll five NVIDIA CI steps in automatic runtime sharding, selecting long jobs from the [duration ranking](https://vllm-ci-dashboard.vercel.app/jobs) over the preceding 12 hours. Batch 1 of five independently based changes.

The initial pooling failure came from an older base that predates merged [#61409](https://github.com/vllm-project/vllm/pull/61409): the CPU Clef test created a CUDA context through pinned memory without initializing torch, so later forked engines failed. This PR is now rebased onto main including that fix. The temporary whole-step spawn workaround was removed. Build 94581 validates the rebased five enrollments. The subsequent MoE test-only fix has focused sharded and unsharded runs below; the other four jobs retain 94581 results because the helper default remains unchanged.

Humming B200 also hits the existing main per-tensor FP8 MoE scale regression from #56997. Existing open fix [#61412](https://github.com/vllm-project/vllm/pull/61412) addresses the identical assertion; this PR does not duplicate it. Clean unsharded main control [94583](https://buildkite.com/vllm/ci/builds/94583#01a136d0-39ca-4844-ba60-180284854f35) reproduces the identical assertion: 13 passed and 1 failed, matching the sharded outcomes. Passing validation remains dependent on that fix; failed-run timing is not an approval-quality performance comparison.

The clean unsharded FP8 MoE control [94583](https://buildkite.com/vllm/ci/builds/94583#01a136d0-39c6-4fed-ba65-19782ec0b6bd) fails all 32 first-command cases with CUDA reinitialization after fork. The DeepGEMM revision pinned by #59482 calls `_C.init` on import; its [locality initialization](https://github.com/vllm-project/DeepGEMM/blob/a981d8e3a58e877b7f53e63707de5834312fb710/deep_gemm/_C.py#L813) allocates CUDA tensors. This PR allows an explicit method in `multi_gpu_test` and uses the existing spawn helper for four functions in the two affected files; other callers retain their existing default. Nested GPU workers already initialize their own workspace. Paired validation: sharded [94599](https://buildkite.com/vllm/ci/builds/94599) and unsharded [94630](https://buildkite.com/vllm/ci/builds/94630), both at the same commit with recording and telemetry off. Sharded build 94599 now passes all three shards: 88 tests, with both plugin commands verified on every shard. The initial control [94600](https://buildkite.com/vllm/ci/builds/94600) reached 81 passing cases before its 45-minute timeout. Its automatic retry was canceled. Replacement 94630 uses the existing `SKIP_TIMEOUT=1` pipeline-generation override with identical test commands and code; its full runtime comparison remains pending. The earlier passing nightly predates the dependency changes and is not a valid performance comparison.
