# Make `load_weights` completely optional

[Upstream PR](https://github.com/vllm-project/vllm/pull/49038) · state: closed · merged: False

## Original PR description

Part of https://github.com/vllm-project/vllm/issues/48972

Infrastructure changes:
- Add `autoload_weights` and use it in weight loaders and runners. This creates it's own `AutoWeightsLoader` if the model doesn't have a `load_weights` method
- When the model has no `load_weights` method, auto apply any `hf_to_vllm_mapper` in `AutoWeightsLoader._load_module` as the model is recursed into

---

Work split into other PRs:
- #51665 - `lm_head` is now dealt with as a special case during weight loading depending on the contents of the checkpoint. We no longer need to manually add skips in for each model's `load_weighs`
- #53106 - Remove `skip_prefix` and `skip_substrs` from `AutoWeightsLoader`. These arguments duplicate the behaviour achievable with the mapper. Convert all uses of these arguments to mapper mappings
