# Docs/nixl kv metrics aggregation semantics

[Upstream PR](https://github.com/vllm-project/vllm/pull/58617) · state: open · merged: False

## Original PR description

## Purpose

Document the aggregation semantics of NIXL KV connector transfer metrics so users correctly interpret the CLI log line in multi-rank (TP > 1) deployments.

Fixes #41230

Stats from each TP rank are concatenated before summary statistics (avg, P90, throughput) are computed. This was not clearly documented and has caused confusion — e.g. treating "Throughput (MB/s)" as aggregate system throughput or "Num successful transfers" as per-engine.

Changes:
- Module-level docstring in `vllm/distributed/kv_transfer/kv_connector/v1/nixl/stats.py` explaining the rank-aggregation model and the meaning of each logged field
- Improved `aggregate()` and `reduce()` docstrings with explicit multi-rank semantics
- Documented the `observe → aggregate → reduce → log` pipeline in `metrics.py`

## Test Plan

Documentation-only change. No runtime behavior modified.
