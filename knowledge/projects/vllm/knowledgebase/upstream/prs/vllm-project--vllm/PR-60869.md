# [HiSparse] Prefault the shared host pool in parallel

[Upstream PR](https://github.com/vllm-project/vllm/pull/60869) · state: closed · merged: True

## Original PR description

Related to #60072.

HiSparse's shared host pool was prefaulted by one worker. Split that work across TP workers and wait for all shards before CUDA registration. Keep the wait and error handling in the shared allocator so both HiSparse and replicated KV offload release peers when setup fails.

Earlier tests on 4 H200s with a 128 GiB pool showed about 35% faster pool setup. Validation at `0db43832fa` on 2 H100s: 123 worker, shared-region, and KV-layout tests passed, along with two-worker failure, GPU-copy, and cleanup checks.

Full GLM startup time has not been measured.

This is for startup performance. CUDA registration worked without the extra barrier in these tests.
