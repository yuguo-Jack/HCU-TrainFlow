# [Spec Decode] Clean up AR speculator decode path

[Upstream PR](https://github.com/vllm-project/vllm/pull/65528) · state: closed · merged: True

## Original PR description

## Purpose
Rename the AR speculator decode methods like so:
- `_decode` => `_run_multi_step_decode`
- `_generate_draft` => `_decode`
- `_fused_multi_step_decode` => `_run_fused_multi_step_decode`
- `_generate_fused_drafts` => `_fused_multi_step_decode`

as well as some other minor cleanups, such as moving the `num_reqs` override:
```
num_reqs = min(num_reqs, dp_sync_state.num_reqs)
```
into the shared `_run_multi_step_decode` method.
