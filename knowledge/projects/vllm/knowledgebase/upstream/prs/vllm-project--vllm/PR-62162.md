## Details

Only the static certification gate needs production changes beyond #62160: runtime canonical mapping already operates on attention tensors and the scheduler already handles chunked-local windows. Tests verify these paths rather than introducing another mapping or scheduler implementation.

Usage: set `canonical_layout: true` in `OffloadingConnector`'s `kv_connector_extra_config` on every sharing instance. For filesystem reuse use `spec_name: "TieringOffloadingSpec"`, a CPU budget and a shared FS secondary tier as in the archived harness. This extends the supported cache types for that existing option; the canonical-layout usage documentation is being added in #61822, so this PR does not duplicate its guide.

Duplicate-work check: no open PR implements this chunked-local gate extension. #61822 is documentation, #51691 is quantization, and #60782 is a shared-region refactor. Recurrent/Mamba and general filesystem/object-store test infrastructure claimed by others in #61886 remain outside this change.

Limits: random tiny weights establish execution/cache correctness, not trained-model quality or throughput. The sharded model has one near-tied argmax change among 240 contexts in each direction; tolerance passes, but tokenwise/bitwise equality is not claimed. No TP4 GPU, CUDA Graph or multi-node validation. GPU/native extensions use baseline `8e25bbca19`; latest-main mergeability was checked separately.
