# [ROCm][CI] nixl_integration/test_edge_cases.py fails when AITER on

[Upstream PR](https://github.com/vllm-project/vllm/pull/63227) · state: open · merged: False

## Original PR description

## Overview

/v1/kv_connector/nixl_integration/run_edge_case_test.sh fails when AITER is on. The cause is, AITER-on will make vLLM choose ROCM_AITER_FA as the attention backend, which uses different attention kernels for different cases (prefill only, extend, and decode only), so compared with the reference result (from a single vLLM server), the target tokens are generated from different attention kernels. Since this test is to verify that KV cache is correctly transferred, the tolerance is very stringent so the test fails.

The solution is: with AITER=on, force vLLM to use ROCM_AITER_UNIFIED_ATTN backend, which always calls the same attn kernel. This way we keep the original purpose of this test --- the KV cache transfer is correct.
