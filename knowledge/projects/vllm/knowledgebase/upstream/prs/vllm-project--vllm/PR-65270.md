# [MRV2][Spec Decode] Fix mixed draft-model warmup token budget

[Upstream PR](https://github.com/vllm-project/vllm/pull/65270) · state: open · merged: False

## Original PR description

## Overview
Draft-model initialization with speculative decoding can fail during mixed prefill/decode warmup:
```
AssertionError: Shape: 2050 out of considered ranges: [(1, 2048)]
```

The warmup creates one synthetic decode request and one synthetic prefill request, but builds the scheduler inputs directly and bypasses the scheduler's correction-slot reservation. The extra query slots for these requests were missing from the warmup token budget, allowing the resulting shape to exceed max_num_tokens.

When a speculator is enabled, cap the warmup token count at max_num_tokens - num_warmup_reqs * num_extra_query_per_req. Skip the warmup if the adjusted budget is too small for a mixed step.

This fixes a regression in the mixed warmup path added by [#56492](https://github.com/vllm-project/vllm/pull/56492).
