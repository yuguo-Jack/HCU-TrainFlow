# [MM] Support mm_device_do_normalize for Gemma 4

[Upstream PR](https://github.com/vllm-project/vllm/pull/65577) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Closes #65573. Adds `mm_device_do_normalize` support to Gemma 4, following #64487 (Gemma 3). No other PR covers it.

Gemma 4's processor only rescales by 1/255, so with the flag on it sends raw `uint8` patches and the model rescales them on the device. That's 4× fewer pixel bytes than `float32`: 7.7 MB → 1.9 MB for a 280-token image.

## Changes

- `gemma4_mm.py`: set the flag, build the input norm, and apply it in one helper before `patch_embedder` for images, video and the encoder CUDA graph. Patches are channel-last, so it normalizes them as `(pixels, 3)` into the model dtype. Capture buffers are `uint8` with the flag on.
- `test_video_cache_is_independent_of_image_kwargs` pins the flag off. Its per-request `rescale_factor` does nothing once the processor stops rescaling, as with the other models that support the flag.
- `Gemma4UnifiedForConditionalGeneration` (encoder-free, its own image path) opts out with `supports_mm_device_do_normalize = False`; supporting it can follow.
- PPL test entry for Gemma 4 E2B, as requested.
- Docs table entry.

## Validation

- New `test_mm_device_do_normalize`: raw `uint8` image and video pixels, normalized on device, equal the CPU path. It fails without this change.
- New `test_embed_patches_normalizes_channel_last_patches`: different per-channel mean/std land on the right pixels.
- CPU with dummy weights on a shrunk model: flag on vs off gives bit-identical logprobs for one image, two images and a video.
- PPL test (`generation_ppl_test/gemma.py`, Gemma 4 E2B added next to Gemma 3; `hf_ppl` 71.009 measured with Transformers on an L40), RTX A6000, bf16, at 171213e: flag off and on both give 70.973 (−0.05%); with `cudagraph_mm_encoder` 70.918 (−0.13%) off and 70.757 (−0.36%) on. 4 passed.
- `test_gemma4.py`: 43 passed. `test_common.py -k gemma-4-E2B`: 3 passed. pre-commit passed.
