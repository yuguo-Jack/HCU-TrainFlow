# [Pooling] Speed up ColBERT reranking with batched token heads

[Upstream PR](https://github.com/vllm-project/vllm/pull/64269) · state: closed · merged: True

## Original PR description

## Purpose

Batch token-embedding casts and projections across requests, then finish slicing and normalization per request only when their settings differ. This removes repeated ColBERT head launches without adding kernels or GPU-specific tuning.

## Claims

- Higher ColBERT throughput with matching settings; mixed dimensions/normalization now also share projection.
- Late chunking, chunked prefill and batch-invariant execution retain the existing path and output ownership. This complements #62940's task-dispatch optimization.

## Validation
