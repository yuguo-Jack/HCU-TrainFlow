# [Perf] Run Whisper log-mel on the GPU worker

[Upstream PR](https://github.com/vllm-project/vllm/pull/62492) · state: open · merged: False

## Original PR description



## Overview

Whisper log-mel moves off the renderer's single multimodal thread and onto the GPU worker. The processor ships float32 PCM as `audio_pcm`, and `embed_multimodal` runs the Hugging Face formula. Fixes #62355.

Draft #62413 is a separate change that combines this issue with #62352. This branch is only #62355.

## Claims

- Resampled mono audio is published as CPU float32 `audio_pcm` (`MultiModalFieldConfig.batched("audio")`, `keep_on_cpu` false). `input_features` is no longer published.
- `audio_pcm` is merged as passthrough after `call_hf_processor`, so `_postprocess_output` does not cast it to the model dtype.
- Encoder prompt length stays `WhisperProcessingInfo.get_num_audio_tokens()` (`max_source_positions`) for a 1 s clip and a 30 s clip. The duration-based `get_num_audio_tokens` remains the streaming usage counter.
- Whisper hashes include `audio_ipc_schema=whisper_pcm_f32_v1` on a copy of the processor kwargs. A bare UUID misses an unsalted entry because the key makes `has_hash_factors` true.
- The worker runs the extractor log-mel in float32 on `conv1.weight.device`, casts to `conv1.weight.dtype`, then calls `get_encoder_outputs`. `torch.stft` stays eager.
- Log-mel `input_features` with no `audio_pcm` raises in `embed_multimodal`.

## Validation

First cut. No GPU worker run, so this description has no speedup number.

Local CPU check, without importing vLLM (`/opt/anaconda3/bin/python`, torch 2.5.1, transformers 5.14.0.dev0, CUDA unavailable):

```bash
python -c "import tests.models.multimodal.processing.test_whisper_logmel as t; t.test_log_mel_matches_cpu_extractor()"
```

That compares `whisper_log_mel_spectrogram` to `WhisperFeatureExtractor` with `atol=1e-5` and `rtol=1e-5` for a short clip, exact `n_samples`, an over-long clip, a two-clip batch (each clip keeps its own max), `_torch_extract_fbank_features` on a pre-padded batch, and shared dither noise. On this CPU the max abs diff was 0.0, including a 100-sample clip. The test still uses a tolerance: GPU `torch.stft` is not bit-identical to CPU. The `.contiguous()` on magnitudes matches transformers 5.16 and 5.19 and does not change values.

`ruff check` and `ruff format --check` passed on the four touched files. `python -m py_compile` passed. The Whisper processor tests import vLLM and were not executed here: torch 2.5.1 cannot import current vLLM (`list[int]` custom-op schemas, and `torch._inductor.custom_graph_pass` is absent).

## Details

The renderer thread runs `WhisperFeatureExtractor._torch_extract_fbank_features` at `device="cpu"` inside the single `_mm_executor` worker, then the GPU worker starts at `conv1`. This commit moves that same STFT onto the worker for Whisper only.

`WhisperMultiModalProcessor._get_hf_mm_inputs` takes the resampled waveform out of the HF batch and stores CPU float32 `audio_pcm` on the passthrough dict. Empty `hf_data` skips the feature extractor. Pad, truncate, dither, STFT, and mel filters run later from the loaded `WhisperFeatureExtractor` (`cached_feature_extractor_from_config`). `do_normalize` stays off. `center=True` and the other `torch.stft` defaults stay. Per-clip max is over time, then bins. Mel time is `n_samples // hop_length` (stock 3000), so conv2 yields `max_source_positions` (stock 1500).

The STFT is in `WhisperForConditionalGeneration.embed_multimodal`. `WhisperEncoder.forward` still starts at `gelu(conv1)`. `UltravoxWhisperEncoder.forward` replaces that method and still expects mel. Qwen2-Audio, Qwen3-ASR, Ultravox, GLM-ASR, Moss, and Voxtral are unchanged. Voxtral's STFT is already on the worker. This PR does not CUDA-graph the encoder and does not change the batched conv stem (#62352).

The schema key is applied inside `_get_mm_hashes` on a replaced `ProcessorInputs`, so the extractor kwargs stay unsalted. In-memory processor caches, `_mm_processor_only_cache`, worker `encoder_cache`, and EC `cross_encoder_cache` entries stored under the old hash miss. API servers and Whisper workers roll onto this commit together. Clearing `clear_mm_cache` and those caches drops the orphaned unsalted entries. Replaying an old log-mel payload leaves `audio_pcm` empty, and `embed_multimodal` raises.

AI assistance: Grok. The `/pr-checklist` skill was applied before opening this draft. Design stays inside the Whisper processor and embed path; the model runner and scheduler are untouched. Performance evidence is the CPU numeric check above. A GPU worker timing is still required before any speedup claim.
