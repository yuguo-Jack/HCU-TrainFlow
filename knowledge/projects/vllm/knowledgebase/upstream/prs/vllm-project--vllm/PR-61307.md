## Overview

Correct the rejected-draft detectability claim in `docs/features/watermarking.md`,
as discussed in the existing [#56105 comment](https://github.com/vllm-project/vllm/issues/56105#issuecomment-6130247561).

## Claims

- Clarify that accepted drafts can weaken detectability and target-only Gumbel
  recovery strength depends on residual uncertainty.
- Explain that a peaked residual can weaken the signal and a residual supported
  on one token leaves no key-dependent token choice.
