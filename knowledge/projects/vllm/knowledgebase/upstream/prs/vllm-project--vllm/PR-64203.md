# [Bugfix][Model] Honor tokenizer revision for Engram token maps

[Upstream PR](https://github.com/vllm-project/vllm/pull/64203) · state: open · merged: False

## Original PR description



## Overview

Fix Engram token-map construction when the configured tokenizer revision differs from the model revision.


## Claims
- Load the Engram tokenizer using `model_config.tokenizer_revision`.
- Add regression coverage for distinct model and tokenizer revisions.

## Validation

- pytest -q tests/kernels/test_engram.py — 109 passed;

## Details

NgramHashState previously loaded its tokenizer using the model revision. When a separate tokenizer revision is configured, this can produce an Engram token map inconsistent with the tokenizer that generated the input token IDs. The loader now uses the resolved tokenizer revision.

AI assistance was used to implement and validate this change.
