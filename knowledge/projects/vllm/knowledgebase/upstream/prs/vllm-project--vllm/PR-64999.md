## Original PR description



## Overview

#64425 overlap in_proj_ba with in_proj_qkvz by checking `default_unquantized_gemm`. However, #62956 (merged yesterday) changes all CUDA dispatch to `cuda_unquantized_gemm`, hence the overlap didn't run. The fix is a 1-line change.

`tests/models/qwen3_5/test_gdn_ba_overlap.py` is added to catch this regression in the future.
