# [MyPy] Fix mypy errors in easy tests/v1/kv_connector files (kv-A)

[Upstream PR](https://github.com/vllm-project/vllm/pull/55542) · state: closed · merged: True

## Original PR description

Co-Authored-By: Claude Fable 5.1

## Purpose

PR **kv-A** of #49569: fix the mypy errors in the "easy" files under `tests/v1/kv_connector/`.

Preparatory PR per the plan: `tests/v1/kv_connector` stays in `SEPARATE_GROUPS`; kv-C moves it to `SILENT_GROUPS` once kv-B (#55901) is done.

Not a duplicate: #51043 and #55485 do not touch this directory, and the only other open PR here addressing mypy errors is kv-B (#55901), which touches a disjoint set of files.

Fixes follow the same priority as PRs 1 to 4: `assert x is not None` narrowing, then precise annotations, then `cast()`, and scoped `# type: ignore[code]` only for intentional test stubs. A few test literals were corrected to the real types (e.g. `set` instead of `list`, `bytes` block hashes).

After merging current `main`, the diff covers 16 test files. Three files from the original 19 (`test_handshake_pp_aggregation.py`, `test_hf3fs_client.py`, `test_tp_mapping.py`) dropped out: `main` disabled `arg-type` and `assignment` under `tests/` (#59428), so their ignores became unused, and they are now clean without changes.

One kv-B file is touched: `unit/utils.py` gets `TestExampleConnector.__test__ = False` (one line), because the class is now imported into a test module for an `isinstance` narrow and pytest would otherwise try to collect it. Its remaining 4 mypy errors are left for kv-B/kv-C.

## Test Plan

```bash
FILES=$(git diff --name-only main...HEAD)
KV_A=$(echo "$FILES" | grep -v 'unit/utils.py')   # utils.py's remaining errors are out of scope

# silent mode, the strictness kv-C will enforce
.venv/bin/mypy --python-version 3.11 --follow-imports silent --warn-unused-ignores $KV_A

# hooks as CI runs them
pre-commit run --files $FILES

.venv/bin/python -m pytest -q $(echo "$FILES" | grep '^tests/v1/kv_connector/unit/test_')
```

## Test Result

- mypy 1.20.2, `--follow-imports silent`, Python 3.11: the 16 files go from 28 errors (in 15 files) on `main` to 0, with no unused ignores.
- pre-commit (`mypy`, `ruff-check`, `ruff-format`, `typos`): pass.
- pytest on 14 touched unit files: `115 passed`. `test_moriio_tp_ack.py` was not run locally (needs `msgpack`); `test_spec_decode_acceptance.py` needs the PD server harness and was not run; its prompt loading was checked to give identical output with the new tokenizer.

AI assistance: prepared with Claude Code (Claude Fable 5.1); I reviewed every changed line and ran the commands above locally. A maintainer later merged `main` and pushed follow-up fixes (prepared with Claude Code): removing ignores made unused by #59428, `isinstance` narrowing for two `dataclasses.replace()` calls and the MoRIIO heartbeat `stdin`, and scoping the `test_flexkv_connector.py` ignores to `[attr-defined]`.
