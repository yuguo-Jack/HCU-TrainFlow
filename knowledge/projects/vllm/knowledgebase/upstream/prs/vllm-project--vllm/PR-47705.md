# [Rust Frontend] Beam search support for completions and chat completions

[Upstream PR](https://github.com/vllm-project/vllm/pull/47705) · state: open · merged: False

## Original PR description

## Purpose

Implement beam search in the Rust frontend via the `use_beam_search` request parameter, including `length_penalty`, for both completions and chat completions endpoints. The implementation matches Python's `BeamSearchOnlineMixin.beam_search()` behavior: token-by-token orchestration with per-step `max_tokens=1` + `logprobs=2*beam_width` engine calls, candidate selection by cumulative logprob, and final beam ranking by length-penalized score.

This contributes to "Beam search via the existing use_beam_search request parameter, including length_penalty" in the Rust frontend feature parity roadmap (#44280).
