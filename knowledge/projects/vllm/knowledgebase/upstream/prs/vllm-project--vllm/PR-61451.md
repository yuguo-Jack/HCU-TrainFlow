# [Perf][Spec Decode] Skip bonus-logit reduction for short drafts in rejection sampling

[Upstream PR](https://github.com/vllm-project/vllm/pull/61451) · state: closed · merged: True

## Original PR description



## Overview



Identify the bonus logit in the V2 rejection sampler by request boundary rather than `local_pos >= num_speculative_steps`, so the full-vocab reductions are skipped on the bonus row of requests verified with fewer drafts than `num_speculative_steps`.
Follow-up to #60945.

## Claims



- A bonus logit helper `_is_bonus_logit` is added. The bounds check introduced by #60945 is now part of `_is_bonus_logit`, and `num_speculative_steps` triton kernel arg is replaced with `num_logits`.
- `_compute_local_logits_stats_kernel` and `_compute_local_residual_mass_kernel` no longer run full-vocab max/sum-exp (target and draft) or residual-mass reductions on the bonus row of a request with `num_drafts < num_speculative_steps`. Previously that work was done and never read.
