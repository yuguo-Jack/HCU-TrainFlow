# [Spec Decode][MRV2]Add LongSpark

[Upstream PR](https://github.com/vllm-project/vllm/pull/63115) · state: open · merged: False

## Original PR description

## Overview

Add native in-process LongSpark speculative decoding to Model Runner V2, with configurable draft lengths and reproducible serving benchmarks. See the [LongSpark paper](https://arxiv.org/abs/2609.37029) and [reference implementation](https://github.com/Hao-Yuan-He/LongSpark).

## Claims

- Register the `draftfreekv` checkpoint format, `DraftFreeKVModel`, and the `longspark` method; the target remains the sole owner of persistent K/V.
- Support `1 <= num_speculative_tokens <= checkpoint block_size`, defaulting to the full block. The checkpoint's trained block shape is preserved while only the requested proposal prefix is sampled and verified.
- Provide BF16 Global/Raw/Local/Markov kernels and use vLLM's CUDA Graph capture-size schedule for supported greedy drafting.
- Document [startup, `vllm bench serve` commands, and two LongSpark/DFlash performance tables](https://github.com/HaizhouPeng/vllm/blob/add-longspark/README.md#longspark), with the contract in the [feature guide](https://github.com/HaizhouPeng/vllm/blob/add-longspark/docs/features/speculative_decoding/longspark.md).

## Validation

### Serving benchmark results

Measured at one **RTX PRO 6000 Blackwell** Server Edition with **Qwen3-4B**, **BF16**, **7speculative tokens** for both methods, and fixed 256-token outputs. Each condition was run once; startup and warmup are excluded. Throughput is output tokens/s; draft throughput is proposed draft tokens divided by benchmark seconds. Acceptance length includes the bonus token.
