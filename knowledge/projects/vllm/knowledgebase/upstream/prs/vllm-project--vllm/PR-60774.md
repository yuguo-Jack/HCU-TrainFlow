## Original PR description

Fixes #60629.

PlotEqualTo and PlotNotEqualTo now parse `true`/`false` as booleans when filtering boolean columns, while preserving existing string and numeric filtering behavior.

Added regression tests covering boolean, nullable boolean, and string columns.
