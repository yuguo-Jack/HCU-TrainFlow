# [Bugfix][LoRA] Map lm_head LoRA to batch tokens for prompt logprobs (…

[Upstream PR](https://github.com/vllm-project/vllm/pull/62049) · state: open · merged: False

## Original PR description



## Overview

Fixes #51594: with an lm_head LoRA, `prompt_logprobs` silently drop the adapter's lm_head delta, and in mixed batches they pick up other requests' adapters. This fixes both model runners with one mechanism. It supersedes #51597 (V1 path, @jialoop-git) and #53842 (MRV2 path, @HuskyLYL), who are credited as co-authors.

## Claims

- `prompt_logprobs` include the lm_head LoRA delta of each request's own adapter, on both V1 and MRV2 (the default since #53183).
- In a batch that mixes adapters, a request's prompt logprobs are no longer affected by other requests' adapters (including requests with no adapter).
- Also covers the MRV2 `prompt_logprob_token_ids` path (#56984), which neither of the two earlier PRs handles.
- No change when LoRA is disabled or the model has no lm_head LoRA layer, and no change to the sampling path.

## Validation

**Reproducer**: Qwen3-8B (untied embeddings), two random adapters on `q_proj,v_proj,lm_head` plus a copy of adapter A with lm_head stripped. Six requests: no-adapter, chunked-prefill (3000 tokens, `max_num_batched_tokens=2048`), and mixed adapters. Each request is scored in one batch and alone, and compared per token against HF+PEFT. """Repro / validation for vllm-project/vllm#51594.

```python
lm_head LoRA delta is dropped from prompt_logprobs. We compare per-token
teacher-forced logprobs from HF transformers + PEFT (reference) against
vLLM prompt_logprobs, for a batch mixing two adapters and no adapter.

  python 51594_prompt_logprobs.py make-adapters --out DIR
  python 51594_prompt_logprobs.py hf   --adapters DIR --out hf.pt
  python 51594_prompt_logprobs.py vllm --adapters DIR --out vllm.pt
  python 51594_prompt_logprobs.py compare hf.pt vllm_a.pt vllm_b.pt ...

The model runner (V1 vs MRV2) is selected with VLLM_USE_V2_MODEL_RUNNER.
"""

import argparse
import os
from pathlib import Path

import torch

MODEL = os.environ.get("MODEL", "Qwen/Qwen3-8B")  # untied embeddings
README = Path(__file__).resolve().parents[1] / "vllm" / "README.md"

# Adapter A: lm_head + q/v. A_nolmhead: same tensors minus lm_head.
# Adapter B: different seed, lm_head + q/v.
ADAPTERS = {"A": 1, "A_nolmhead": 2, "B": 3}

# (name, prompt length, text offset, adapter). Length 3000 > the
# max_num_batched_tokens=2048 used below, so it is chunk-prefilled; 1500 and
# 3000 cross MRV2's 1024-row prompt-logits chunk.
REQUESTS = [
    ("r0_A_400", 400, 0, "A"),
    ("r1_B_1500", 1500, 500, "B"),
    ("r2_none_37", 37, 2000, None),
    ("r3_A_3000", 3000, 300, "A"),
    ("r4_B_400", 400, 1200, "B"),
    ("r5_Anolm_400", 400, 0, "A_nolmhead"),
]


def all_ids(tok):
    ids = tok(README.read_text())["input_ids"]
    while len(ids) < 8000:
        ids = ids + ids
    return ids


def req_ids(tok):
    ids = all_ids(tok)
    return {name: ids[off:off + n] for name, n, off, _ in REQUESTS}


def make_adapters(out):
    from peft import LoraConfig, get_peft_model
    from safetensors.torch import load_file, save_file
    from transformers import AutoModelForCausalLM

    base = AutoModelForCausalLM.from_pretrained(MODEL, torch_dtype=torch.bfloat16)
    cfg = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.0,
                     target_modules=["q_proj", "v_proj", "lm_head"])
    for name, seed in [("A", 0), ("B", 1)]:
        torch.manual_seed(seed)
        model = get_peft_model(base, cfg)
        # PEFT zero-inits B; give it random values. lm_head gets a large
        # delta (several nats) so a missing delta is unmistakable.
        for pname, p in model.named_parameters():
            if "lora_B" in pname:
                std = 0.3 if "lm_head" in pname else 0.002
                torch.nn.init.normal_(p, std=std)
        model.save_pretrained(f"{out}/{name}")
        base = model.unload()  # drop LoRA layers, reuse base weights
    # A_nolmhead: copy of A with its lm_head tensors removed.
    src, dst = Path(out, "A"), Path(out, "A_nolmhead")
    dst.mkdir(parents=True, exist_ok=True)
    sd = load_file(src / "adapter_model.safetensors")
    sd = {k: v for k, v in sd.items() if "lm_head" not in k}
    save_file(sd, dst / "adapter_model.safetensors")
    (dst / "adapter_config.json").write_text(
        (src / "adapter_config.json").read_text())
    print("saved adapters to", out, "| A_nolmhead keys:", len(sd))


def token_lp(logits, ids):
    lp = torch.log_softmax(logits.float(), -1)
    return lp[:-1].gather(1, ids[1:, None])[:, 0]


def run_hf(adapters, out):
    from peft import PeftModel
    from transformers import AutoModelForCausalLM, AutoTokenizer

    tok = AutoTokenizer.from_pretrained(MODEL)
    model = AutoModelForCausalLM.from_pretrained(
        MODEL, torch_dtype=torch.bfloat16, device_map="cuda")
    model = PeftModel.from_pretrained(model, f"{adapters}/A", adapter_name="A")
    for name in ("A_nolmhead", "B"):
        model.load_adapter(f"{adapters}/{name}", adapter_name=name)
    model.eval()
    res = {}
    for name, ids in req_ids(tok).items():
        x = torch.tensor([ids], device="cuda")
        with torch.no_grad():
            with model.disable_adapter():
                res[name + "/base"] = token_lp(model(x).logits[0], x[0]).cpu()
            for ad in ADAPTERS:
                model.set_adapter(ad)
                res[name + "/" + ad] = token_lp(model(x).logits[0], x[0]).cpu()
    torch.save(res, out)
    for name, _, _, ad in REQUESTS:
        if ad:
            eff = (res[f"{name}/{ad}"] - res[f"{name}/base"]).abs().mean()
            print(f"hf {name}: mean |lora - base| = {eff:.3f} nats")


def run_vllm(adapters, out):
    os.environ["VLLM_ENABLE_V1_MULTIPROCESSING"] = "0"
    from vllm import LLM, SamplingParams
    from vllm.inputs import TokensPrompt
    from vllm.lora.request import LoRARequest

    llm = LLM(MODEL, enable_lora=True, max_lora_rank=16, max_loras=3,
              max_model_len=4096, max_num_batched_tokens=2048,
              gpu_memory_utilization=0.6, seed=0,
              enforce_eager=os.environ.get("EAGER", "1") == "1")
    def _runner_name(worker):
        r = worker.model_runner
        return type(r).__module__ + "." + type(r).__name__

    runner_name = llm.collective_rpc(_runner_name)[0]
    print("model runner:", runner_name)

    ids = req_ids(llm.get_tokenizer())
    loras = {ad: LoRARequest(ad, i, str(Path(adapters, ad).resolve()))
             for ad, i in ADAPTERS.items()}
    sp = SamplingParams(max_tokens=1, temperature=0, prompt_logprobs=0)

    def to_lp(o, toks):
        return torch.tensor([d[t].logprob for d, t in
                             zip(o.prompt_logprobs[1:], toks[1:])])

    res = {"runner": runner_name}
    # 1) all requests in one batch (mixed adapters + no adapter)
    prompts = [TokensPrompt(prompt_token_ids=ids[n]) for n, *_ in REQUESTS]
    reqs = [loras[ad] if ad else None for *_, ad in REQUESTS]
    outs = llm.generate(prompts, sp, lora_request=reqs)
    for (name, *_), o in zip(REQUESTS, outs):
        res[f"batch/{name}"] = to_lp(o, ids[name])
    # 2) each request alone
    for (name, *_, ad), p in zip(REQUESTS, prompts):
        o = llm.generate([p], sp, lora_request=loras[ad] if ad else None)[0]
        res[f"single/{name}"] = to_lp(o, ids[name])
    torch.save(res, out)
    print("saved", out)


def compare(hf_path, paths):
    hf = torch.load(hf_path)
    for p in paths:
        r = torch.load(p)
        print(f"\n== {p}  [{r['runner'].rsplit('.', 1)[-1]}]")
        print(f"{'mode/request':24s} {'|vllm-hf_lora|':>15s} "
              f"{'|vllm-hf_base|':>15s} {'|hf_lora-base|':>15s}  verdict")
        for mode in ("batch", "single"):
            for name, _, _, ad in REQUESTS:
                v = r[f"{mode}/{name}"]
                ref = hf[f"{name}/{ad}"] if ad else hf[f"{name}/base"]
                base = hf[f"{name}/base"]
                d_ref = (v - ref).abs().mean().item()
                d_base = (v - base).abs().mean().item()
                eff = (ref - base).abs().mean().item()
                ok = d_ref < 0.1 * max(eff, 1e-9) or d_ref < 0.05
                print(f"{mode + '/' + name:24s} {d_ref:15.4f} {d_base:15.4f} "
                      f"{eff:15.4f}  {'OK' if ok else 'BAD'}")


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("mode", choices=["make-adapters", "hf", "vllm", "compare"])
    ap.add_argument("files", nargs="*")
    ap.add_argument("--adapters")
    ap.add_argument("--out")
    a = ap.parse_args()
    if a.mode == "make-adapters":
        make_adapters(a.out)
    elif a.mode == "hf":
        run_hf(a.adapters, a.out)
    elif a.mode == "vllm":
        run_vllm(a.adapters, a.out)
    else:
        compare(a.files[0], a.files[1:])
```

## Details

**Root cause.** `LogitsProcessorWithLoRA` → `punica.add_lora_logits` maps logits rows to adapters through `prompt_mapping_meta`, which is built from `sampler_indices`: one row per *sampled* token. Prompt logprobs call `compute_logits` on *prompt* hidden states. As a result, the kernel only processes rows `[0, num_reqs)` and gives row `i` the adapter of request `i`. Every other row gets no delta, and rows near the start of the batch get other requests' adapters.

**Fix.** `PunicaWrapperBase.token_logits_rows(start, end)` is a context manager that points `prompt_mapping_meta` at `token_lora_indices[start:end]` (the per-token mapping) for one `compute_logits` call and restores the sampled-row mapping on exit, including on exceptions. It is exposed through `LoRAModelManager` → `WorkerLoRAManager` → `LoRAModelRunnerMixin`, and each prompt-logprob call site wraps its `compute_logits` call:
- V1 `_get_prompt_logprobs_dict`;
- MRV2 `compute_prompt_logprobs_with_chunking`;
- MRV2 `compute_prompt_token_id_logprobs`.

Compared with #51597/#53842, this needs no second punica wrapper or `LoRAMapping` and no runner-specific mapping logic. It also gives each runner a single call site, so new logits-on-non-sampled-rows paths only need to add a `with` block. Both PRs also add a `get_lm_punica_wrapper` with different definitions, so they can't be merged together as-is.

**Why V1 too.** MRV2 is the default, but V1 is still selectable and has the same bug (validated above). The V1 change is two lines.

**Tradeoffs / limitations.**
- `prepare_tensors` is a small host-synchronizing op. With the fix it runs twice per prompt-logprob logits chunk, only when LoRA is enabled and the model has an lm_head LoRA layer, wrapped in `gpu_sync_allowed()`. The decode/sampling path is untouched. Restoring once after the chunk loop would save one call per chunk. I kept the per-call `with` because it gives each call site one line and leaves the sampled mapping intact on exceptions.
- The CPU and XPU punica wrappers index `sampler_indices` directly in `add_lora_logits`, so they likely have the same bug. They keep the no-op default and a TODO for now. I don't have hardware to validate them.
