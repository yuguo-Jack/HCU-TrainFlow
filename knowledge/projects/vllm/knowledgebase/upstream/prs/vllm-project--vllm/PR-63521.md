# [Bugfix][Frontend] Log the unsupported ORCA header format by name

[Upstream PR](https://github.com/vllm-project/vllm/pull/63521) · state: open · merged: False

## Original PR description

## Overview

Log the requested format, not the builtin `format`, when `endpoint-load-metrics-format` is unsupported.

## Claims

- The warning now names the unsupported format (for example `foo`) instead of `<built-in function format>`.

## Validation

`pytest tests/entrypoints/serve/utils/test_orca_metrics.py` (CPU, no GPU needed): the new test fails before (logged text contains `built-in function format`) and passes after.

## Details

`create_orca_header` passed `format` (the Python builtin) to the warning instead of `metrics_format`. One-word fix plus one unit test.
