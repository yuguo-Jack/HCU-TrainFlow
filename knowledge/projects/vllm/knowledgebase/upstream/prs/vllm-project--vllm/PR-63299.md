# [Bugfix][CPU][CI] Accept assigned nodes in the no-Triton worker test

[Upstream PR](https://github.com/vllm-project/vllm/pull/63299) · state: closed · merged: True

## Original PR description

## Overview

Update the `test_cpu_worker_without_triton` stub so it accepts the assigned-node argument added in #62867.

## Claims

- The test no longer raises `TypeError` when `CPUWorker` calls `get_visible_memory_node(assigned_node_ids)`.

## Validation

Buildkite CI #96834, on #61628, failed with:

`TypeError: <lambda>() takes 0 positional arguments but 1 was given`

## Details

#62867 passes `assigned_physical_gpu_ids` into `get_visible_memory_node`. The test still replaced that function with `lambda: [0]`. The stub now accepts the argument and still returns node `[0]`.

No open PR updates this test. AI assistance was used.
