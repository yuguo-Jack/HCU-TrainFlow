# [Bugfix][Model] Fix DiffusionGemma vision prefix masking

[Upstream PR](https://github.com/vllm-project/vllm/pull/62814) · state: open · merged: False

## Original PR description



## Overview

Fixes #62705. Propagate DiffusionGemma image-prefix ranges into MRV2 attention metadata and apply vision bidirectional masking only to sliding layers.

## Claims

- Image prefill uses the configured vision mask with FA4 and Triton; full layers retain causal prompt attention.
- FA4 preserves per-request causal/noncausal mask semantics when image prefill shares a batch with denoising.
- Uniform denoise/commit FULL graphs remain supported. Prefill/mixed batches use eager or piecewise execution to avoid freezing optional image-range arguments into generic FULL graphs.

## Details

DiffusionGemma overrides `ModelState.prepare_attn` without forwarding `mm_req_doc_ranges`. It also uses per-request causal tensors, which FA4's mm-prefix path previously excluded. The fix reuses `compute_mm_prefix_ranges`, supplies the CPU sequence-length bound, slices active request offsets, and reuses Gemma4's full-layer range clearing. FA4's existing CuTe mask factory accepts persistent per-request causal flags without GPU host reads.

Generic FULL prefill/mixed graph coverage is reduced on an MM-prefix engine, including for its text requests; uniform denoise/commit graphs remain. Language-only engines retain existing support. No throughput improvement is claimed. Strict sync diagnostics fail on both baseline and patch at the unchanged sampler `if just_converged.any()`; no suppression or sampler change is included.

Duplicate checks refreshed before submission: #62437 is merged frontend joint/image reads; #49202 addresses denoise rectangular SWA; #62516 adds Blackwell FlashInfer mixed-causal support. #50539 changes oversized-range filtering and #56813 caches default-state ranges; neither propagates ranges from DiffusionGemma's custom state. Newer #63033/#63044 fix PaliGemma whole-prompt prefix attention; neither changes DiffusionGemma custom-state range propagation. No frontend, scheduler, native kernel, or denoise rectangular-SWA change is included here.
