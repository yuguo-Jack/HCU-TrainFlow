# [Doc] Kolibri 1 reasoning and tool-call parsing via HF response template

[Upstream PR](https://github.com/vllm-project/vllm/pull/62885) · state: closed · merged: True

## Original PR description



## Overview

We now have a response template in the Kolibri HF checkpoints and can use the `hf` parsers in vLLM.
This PR just adds documentation on what to set.

## Claims

Having a single source of truth for parser settings (response template) and documenting correct use is a gain for user who want to use Kolibri models. 

## Validation
