## Code Review

This pull request is a significant refactoring that reorganizes the kernel abstraction directory structure. The changes are well-structured and aim to provide a more stable import interface for linear kernels, which is a great improvement for maintainability.

I've identified a few high-severity issues related to the parsing of the `VLLM_DISABLED_KERNELS` environment variable and the format of the generated kernel names. These could lead to incorrect behavior or user confusion when configuring disabled kernels. Please see my detailed comments for suggestions on how to address them.

Overall, this is a solid refactoring effort. Once the identified issues are resolved, this will be a valuable improvement to the codebase.
