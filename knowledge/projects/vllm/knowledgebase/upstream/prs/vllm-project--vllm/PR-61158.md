# [XPU] refine memory release for sleep mode

[Upstream PR](https://github.com/vllm-project/vllm/pull/61158) · state: closed · merged: True

## Original PR description



## Overview

Fix an XPU teardown crash where sleep-mode tests pass their assertions but subsequently abort with `pure virtual method called` during `empty_cache()`. `XpuMemAllocator.release_pools()` previously dropped allocator wrappers after
releasing the Python MemPool references. However, live tensors can outlast those wrappers, leaving outstanding allocations that still require the allocator for later cleanup. Dropping the allocator too early allows deferred frees to call into an
already-destroyed allocator.
