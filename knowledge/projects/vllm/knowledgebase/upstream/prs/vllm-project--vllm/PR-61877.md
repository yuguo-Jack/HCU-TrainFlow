# [Rust Frontend] Add per-request speculative decoding metrics

[Upstream PR](https://github.com/vllm-project/vllm/pull/61877) · state: closed · merged: True

## Original PR description

## Summary

Adds speculative-decoding acceptance statistics to per-request metrics in the Rust OpenAI frontend.

This is a follow-up to #59314, which added the base per-request timing metrics support. It is not duplicate work: the Rust Chat Completions and Completions routes do not currently propagate the engine's per-request speculative-decoding statistics. This PR reuses the converter already used by `/inference/v1/generate`.

- exposes `metrics.speculative_decoding` for `/v1/chat/completions` and `/v1/completions`
- supports both non-streaming and streaming responses
- emits streaming metrics only on the final usage chunk
- keeps timing metrics and speculative-decoding metrics independently configurable
- reuses the existing speculative-decoding conversion shared with `/inference/v1/generate`

The response follows the existing Python/OpenAI per-request metrics schema, including summary and detailed speculative-decoding modes.
