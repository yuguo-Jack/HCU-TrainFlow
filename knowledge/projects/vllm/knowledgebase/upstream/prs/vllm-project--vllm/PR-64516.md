# [Hardware] Keep current_stream() in sync with torch.accelerator.set_stream

[Upstream PR](https://github.com/vllm-project/vllm/pull/64516) · state: open · merged: False

## Original PR description

## Overview

`current_stream()` in `vllm/utils/torch_utils.py` returns a stream that vLLM caches by wrapping `torch.cuda.set_stream`. `torch.accelerator.set_stream` calls `torch._C._accelerator_setStream` directly, so it skips that cache. This wraps it the same way and moves the two `set_stream` calls that rely on the cache to the accelerator API.

Refs #30679

## Claims

- `current_stream()` follows `torch.accelerator.set_stream`, as it already does for `torch.cuda.set_stream` and `with torch.cuda.stream()`.
- The first-use setup in `current_stream()` and `UBatchContext.update_stream()` now use `torch.accelerator.set_stream`.

## Validation

RTX 5070 Ti, torch 2.14.0+cu130, vLLM from source without a build, so conftest is skipped:

```
python -m pytest --noconftest -p no:cacheprovider tests/utils_/test_torch_utils.py -k follows_accelerator_set_stream -q
```

Before (main):
```
E  assert <torch.cuda.Stream device=cuda:0 cuda_stream=0x249a6b9b6f0> == <torch.cuda.Stream device=cuda:0 cuda_stream=0x249a6b9b930>
tests\utils_\test_torch_utils.py:191: AssertionError
1 failed, 39 deselected
```

After:
```
1 passed, 39 deselected
```

The rest of `tests/utils_/test_torch_utils.py` gives the same results before and after. Its failures here are local only (`psutil` and `cbor2` not installed, no compiled `vllm._C`). `tools/pre_commit/check_torch_cuda.py` passes on all Python files. I could not run ruff or mypy locally.

## Details

- Not a duplicate. #39798 (same RFC row, closed as stale) moved the wrapper to `torch.accelerator.set_stream`, so `with torch.cuda.stream()` and `torch.cuda.graph` capture, which call `torch.cuda.set_stream`, would stop updating the cache. #58082 moves the `set_stream` calls in the v2 runner's `async_utils.py`. This PR does not touch that file, and with it those calls keep the cache in sync.
- A lint rule for `torch.cuda.set_stream(` can follow once #58082 lands.
- On XPU, `torch.accelerator.set_stream` will now update the cache too. I have not tested on XPU.
