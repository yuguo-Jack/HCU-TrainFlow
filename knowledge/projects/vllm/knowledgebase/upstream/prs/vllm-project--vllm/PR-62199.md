# [Bugfix][Frontend] Match DeepSeek-V4.1 encoder to the 1017 reference encoding

[Upstream PR](https://github.com/vllm-project/vllm/pull/62199) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Match the Python DeepSeek V4.1 encoder to the updated reference [`encoding/`](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017/tree/main/encoding). Rust counterpart: #62200.

Affects both V4.1-Flash checkpoints (launch and 1017). DeepSeek fixed the turn handling in both repos ([launch `314113f`](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash/commit/314113f8a7dadb388215396ba5fbee2c610a04d6), 1017 release); their `encoding/` is now identical. The image-token check has been in the reference since launch.

## Claims

- Tool results alone no longer start a new user turn, so reasoning before a tool call is kept.
- Literal `<｜deepseek_image｜>` in message text or reasoning returns 400.
- All five reference golden prompts match. V4 is unchanged.

## Examples

**1. Tool call in thinking mode, with no `tools` field in the request**

```python
[{"role": "user", "content": "What's the weather in Paris? Answer in Fahrenheit."},
 {"role": "assistant", "content": "", "reasoning": "Tool returns Celsius; convert to Fahrenheit.",
  "tool_calls": [{"id": "c1", "type": "function", "function": {"name": "get_weather", "arguments": "{\"city\": \"Paris\"}"}}]},
 {"role": "tool", "tool_call_id": "c1", "content": "{\"temp_c\": 20}"}]
```

Before (reasoning dropped):
```
<｜User｜>What's the weather in Paris? Answer in Fahrenheit.<｜Assistant｜></think>

<｜DSML｜ calls>...
```
After (reasoning kept, same as the reference encoder):
```
<｜User｜>What's the weather in Paris? Answer in Fahrenheit.<｜Assistant｜><think>Tool returns Celsius; convert to Fahrenheit.</think>

<｜DSML｜ calls>...
```

**2. Literal image token in text**

```python
[{"role": "user", "content": "hi <｜deepseek_image｜>"}]
```

Before: accepted, so the prompt has an image placeholder with no image. After: 400.

## Validation

- `pytest tests/tokenizers_/test_deepseek_v41.py tests/tokenizers_/test_deepseek_v4.py`: 84 passed. The new tests fail on main.
- E2E on 8x H100 (TP8, recipe H100 flags, DeepSeek-V4.1-Flash-1017): the prompt keeps the tool-call reasoning and matches the reference encoder; the literal image token returns 400.
- GSM8K (chat, thinking off, 1319 questions): 0.970.

## Details

Not a duplicate: #60792 (image order) and other open V4.1 tokenizer PRs don't change turn boundaries or placeholder validation. Fixtures are copied from the 1017 repo (MIT).
