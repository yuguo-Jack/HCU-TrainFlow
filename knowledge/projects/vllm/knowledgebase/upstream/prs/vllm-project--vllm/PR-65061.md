## Original PR description

## Overview

Every causal row runs in one call on the unsplit sparse decode kernel, reading the fp8 SWA and nvfp4 compressed caches directly; sparse_paged_indices derives each token's slots and lengths from (request, position) only.

Split from #62365 by @aoshen02 and rebased onto current main (190df0b90).
