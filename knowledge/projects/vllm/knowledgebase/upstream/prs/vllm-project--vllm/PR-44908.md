## Summary

Fix a Python syntax error in the Pipeline Parallelism code example in `docs/configuration/optimization.md`.

The `model` argument string was missing its closing quote, making the snippet invalid Python:

**Before:**
```python
llm = LLM(
    model="meta-llama/Llama-3.3-70B-Instruct,
    tensor_parallel_size=4,
    pipeline_parallel_size=2,
)
```

**After:**
```python
llm = LLM(
    model="meta-llama/Llama-3.3-70B-Instruct",
    tensor_parallel_size=4,
    pipeline_parallel_size=2,
)
```
