# [Bugfix] Skip optional vision import for text-only warmup

[Upstream PR](https://github.com/vllm-project/vllm/pull/65617) · state: open · merged: False

## Original PR description

## Overview

Avoid importing Qwen3-VL's optional vision dependencies during kernel warmup for text-only models. Fixes #65390.

## Claims

- Text-only startup no longer imports `qwen3_vl` (and therefore `torchvision`) from the Qwen-VL warmup path.
- Qwen3-VL models keep the existing vision warmup behavior because model construction has already loaded their implementation module.
- A regression test exercises the public warmup entry point with a plain text model and verifies that the vision module is not imported.

## Validation

- Before the fix, running `_warm_vision(torch.nn.Linear(1, 1), cpu)` with `torchvision` imports blocked raised `ModuleNotFoundError` from `qwen3_vl.py`.
- After the fix, the same reproducer completes and prints `text-only warmup skipped optional vision import`.
- `VLLM_TARGET_DEVICE=empty VLLM_PLUGINS='' python -m pytest -q --confcutdir=tests/model_executor tests/model_executor/test_qwen_vl_triton_warmup.py::test_qwen_vl_warmup_skips_vision_import_for_text_model` (`1 passed`)
- `ruff check` and `ruff format --check` pass for both changed files.
- `python -m compileall` and `git diff --check` pass.

The existing real Qwen3-VL warmup test was left unchanged. It requires `torchvision`, which is absent from the local CPU-only environment, so that path is left to the regular CI environment.

## Details

`kernel_warmup()` calls the Qwen-VL warmup for every model. `_warm_vision()` then imported `qwen3_vl` before checking whether the loaded model contained a Qwen3 vision tower. On a lean ROCm runtime, that import reached Transformers' Qwen image processor and failed because `torchvision` was not installed.

The fix checks `sys.modules` first. Qwen3-VL model construction necessarily loads the implementation module, while text-only models do not. This avoids importing optional vision packages for unrelated models without masking missing dependencies for an actual Qwen3-VL model.

This change was prepared with assistance from OpenAI Codex. The human submitter reviewed the diff and remains responsible for the implementation and validation.
