# [Bugfix] Warn when prefix caching is inert on hybrid models (block_size > max_model_len)

[Upstream PR](https://github.com/vllm-project/vllm/pull/48402) · state: open · merged: False

## Original PR description

Fixes #48401.

Hybrid Mamba2 models (like NemotronH) raise the cache block size to match the mamba layout (8320 tokens here). Prefix caching only records a full block, so when `max_model_len` is smaller than the block size, no request can ever fill a block and the cache never hits. Prefix caching does nothing, with no warning.

Evidence (same model and GPU, only max_model_len differs):
- max_model_len 4096 (< block size 8320): prefix_cache_hits = 0 out of 10608 queries.
- max_model_len 16384 (> block size 8320): hits = 16640 out of 38448 (~43%).

So prefix caching is inert whenever block_size > max_model_len. This PR adds a warning at startup for that case. One warning, no behavior change.
