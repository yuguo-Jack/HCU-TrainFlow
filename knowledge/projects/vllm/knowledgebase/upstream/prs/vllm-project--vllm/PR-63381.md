# [Feature] Add DoSA prefill indexer on SM100

[Upstream PR](https://github.com/vllm-project/vllm/pull/63381) · state: open · merged: False

## Original PR description

## Overview

Add an opt-in DoSA indexer for DSA prefill on SM100. It scores a seed subset,
screens keys with score bounds, and refines the surviving candidates.

Depends on #64749. This PR contains the DoSA operator and serving integration;
the shared fixes are reviewed separately in that prerequisite PR.

## Claims

- Supports 32/64 index heads with FP8 index keys on SM100 and CUDA 13.
- At near-1M context, GLM-5.2 TTFT improves by **2.40× with Q16K** and
  **2.45× with Q32K**. Previously published DeepSeek-V3.2 results reach **1.83×**.

## Validation

Rebased onto upstream `8a2a5e4c40f9`. GLM-5.2 was remeasured across all six
contexts with both stock and DoSA on the same eight SM100 GPUs, client host,
NICs and communication settings. All 96 requests completed successfully.

TTFT uses SQLite 3.53.4 source prefixes, FP8 KV and TP8/EP8. Each speedup is
stock / DoSA, using the median of three formal requests after one warmup.
Requests use fresh IDs, a prefix-cache reset, a two-token output budget and
default EOS. Here 1K = 1024 tokens.

| Context | GLM Q16K | GLM Q32K | DeepSeek Q16K | DeepSeek Q32K |
| --- | ---: | ---: | ---: | ---: |
| 128K | 1.0076× | 1.0035× | 0.93× | 0.88× |
| 256K | 1.1238× | 1.1166× | — | — |
| 384K | 1.2155× | 1.2168× | 0.97× | 0.97× |
| 512K | 1.3668× | 1.3762× | 1.02× | 1.02× |
| 768K | 1.8033× | 1.8235× | 1.33× | 1.35× |
| ~1M | 2.3992× | 2.4463× | 1.80× | 1.83× |

DeepSeek rows retain the previously published latency measurements. Requests
above its 163840-token context use a 1048576-token server limit for
extrapolation. These source prefixes measure latency, not independent agent tasks.

The published evaluation on our fixed 100-request LongBench-v2 subset reports
GLM-5.2 **54% with stock → 58% with DoSA (+4 percentage points)**.
The answer differences come from choosing different valid keys at equal
indexer scores. The [LongBench-v2 evaluation guide](https://github.com/llm-sys/dosa-vllm/blob/33f5da8eabdd8f77a1733ab322312f7a4653e23e/docs/features/dosa_longbench_v2.md)
provides the cohort, protocol, A/A control and reproduction commands.

The rebased stack passes 107 focused tests, including all 10 retained DoSA GPU
cases covering H32/H64 native scoring, capacity recovery, cross-stream reuse,
strided output and packed batch/fallback, plus the affected upstream SM100 GLM
projection and graph paths.

## Details

Enable with `--attention-config '{"indexer_dosa": true}'`. The existing indexer
remains the default. Scratch and private graphs are owned and accounted for by
the workspace manager; selection state is local to each invocation. Capacity
and numerical admission failures use exhaustive recovery.

Shared RoPE cache-capacity, manual-fusion budget/range and worker-startup fixes
are submitted separately in #64749. Both benchmark arms include these fixes.

The [DoSA-only diff](https://github.com/llm-sys/dosa-vllm/compare/dsa-shared-fixes...dosa-main)
contains **5,894 changed lines across 24 files**. The prerequisite contains
226 changed lines; the combined stack is 2,782 changed lines smaller than the
original PR. Once #64749 merges, this PR will be rebased onto `main` to retain
only the DoSA feature commit.

Related PRs [#60618](https://github.com/vllm-project/vllm/pull/60618) and
[#48726](https://github.com/vllm-project/vllm/pull/48726) fuse scoring and
selection. DoSA adds a seed threshold and certified screening before sparse
refinement; the existing dense scorer and TopK remain available for fallback.

[Complete TTFT reproduction: installation, inputs, servers and client](https://github.com/llm-sys/dosa-vllm/blob/24cf7e1669234334e8f16fdd83744e2d9fb562d8/docs/features/dosa.md#ttft-reproduction).
