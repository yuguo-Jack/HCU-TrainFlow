# [Perf][GDN] Allocate GDN core output uninitialized, write FlashInfer prefill in place

## Overview

Small optimizations for FlashInfer GDN prefill
- Replace `torch.zeros()` in GDN core attn output with `torch.empty()`
- FlashInfer GDN prefill writes directly to output buffer, eliminating memcpy
- Feed FlashInfer GDN prefill kernel `exp(g)` from the producer + use int32 `cu_seqlens` without cast.

## Claims

- Qwen3.8-27B: e2e TPOT c1 −1.9% on the #51012 base, −0.4..−0.7% on main.
- **GSM8K unchanged**: Qwen3.8-27B-NVFP4 0.865 → 0.862, Qwen3-Next-80B-NVFP4 0.8848 → 0.8893 (noise); and under the exact #28182 failure recipe (conc 250), no-zeroing 0.9287 vs zeroed 0.9204.
