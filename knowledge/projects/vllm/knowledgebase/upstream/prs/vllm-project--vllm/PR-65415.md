# fix(logits_processor): apply soft capping before scaling in get_top_k…

[Upstream PR](https://github.com/vllm-project/vllm/pull/65415) · state: open · merged: False

## Original PR description

## Description
Fixes #65401.

In `LogitsProcessor.get_top_k_tokens`, when `return_log_probs=False`, the selected top-k values were processed in the wrong order:
```python
# Before (Incorrect order)
if self.scale != 1.0:
    values = values * self.scale
if self.soft_cap is not None:
    values = torch.tanh(values / self.soft_cap) * self.soft_cap
```

However, the ground truth transformation order in `forward()` applies soft capping before scaling:
```python
if logits is not None:
    if self.soft_cap is not None:
        logits = logits / self.soft_cap
        logits = torch.tanh(logits)
        logits = logits * self.soft_cap

    if self.scale != 1.0:
        logits *= self.scale
```

Because scaling and soft capping do not commute when `scale != 1.0` and `soft_cap is not None`, the resulting `top-k values` differed from `forward()`.

This PR reorders the post-processing in `get_top_k_tokens` so that `soft_cap` is computed before `scale`, ensuring mathematical consistency with `forward()`.

```python
import torch
from vllm.config import VllmConfig, set_current_vllm_config
from vllm.model_executor.layers.logits_processor import LogitsProcessor
from vllm.model_executor.layers.vocab_parallel_embedding import (
    VocabParallelEmbedding,
)

# Mock vLLM configuration context
with set_current_vllm_config(VllmConfig()):
    # Create an embedding layer with vocab_size=3, hidden_dim=1
    head = VocabParallelEmbedding(
        3, 1, params_dtype=torch.float32, padding_size=1, disable_tp=True
    )
    with torch.no_grad():
        # Set raw logits for 3 tokens to [4.0], [1.0], and [-2.0]
        head.weight.copy_(torch.tensor([[4.0], [1.0], [-2.0]]))

    # Configure both scale=2.0 and soft_cap=3.0 to trigger non-commutative behavior
    processor = LogitsProcessor(3, scale=2.0, soft_cap=3.0)
    hidden_states = torch.ones(1, 1, dtype=torch.float32)

    # 1. Compute full logits via standard forward path (ground truth)
    full_logits = processor(head, hidden_states)

    # 2. Compute top-k candidates via get_top_k_tokens
    ids, values = processor.get_top_k_tokens(head, hidden_states, k=2)

    # 3. Gather full logits at the selected top-k token IDs as expected values
    expected = full_logits.gather(-1, ids)

    print("ids:", ids.tolist())
    print("top-k values:", values.tolist())
    print("full logits at the same ids:", expected.tolist())

    # 4. Assert candidate values strictly match the expected full logits
    torch.testing.assert_close(values, expected)
    print("✅ Test Passed: top-k values match expected logits!")
```
