# [ROCm][MoRIIO] Release write-prefill blocks when sidelined

[Upstream PR](https://github.com/vllm-project/vllm/pull/58108) · state: closed · merged: False

## Original PR description

Under MultiConnector (e.g. [CPUOffload, MoRIIO]), a decode request can sideline MoRIIO on the load path → update_state_after_alloc is called with num_external_tokens == 0 and sent an empty block_notify_list. In write mode the producer rejects the empty notify and holds its deferred write-prefill blocks until timeout, exhausting the prefill pool under warm concurrency. Release those blocksand skip the notify instead.

**Unti test added :**
  tests/v1/kv_connector/unit/test_moriio_connector.py::test_write_mode_sidelined_by_multiconnector_releases_blocks_and_skips_notify

Test fails without the fix, passes with it.
