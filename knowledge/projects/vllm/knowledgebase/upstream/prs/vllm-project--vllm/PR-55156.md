## Original PR description

## Purpose

  Draft Phase 2 implementation for #49529: adopt `ldmatrix.s8.s4` in
  Machete’s W4A8-INT8 path.

  The initial commit enables only the narrow Machete QQQ
  configuration needed to instantiate and test the Phase 2 path:

  - INT8 activations and `uint4b8` weights.
  - FP16 group scales with group size 128.
  - FP32 channel and token scales.
  - One fixed `128x16`, `1x1x1` H100-oriented schedule.
  - Focused correctness coverage for `M=64`, `K=4096`, `N=4096`.

  Subsequent commits in this draft will add the W4A8 prepacked-layout
  update, the `ldmatrix.s8.s4` shared-memory-to-register copy atom, bit-
  exact coverage, and H100 validation.

  This does not duplicate #50096: that PR changes Marlin, while this work
  implements the separate Machete Phase 2 path.

  Related to #49529.

  ## Test Plan

  - Build vLLM with the generated Machete QQQ specialization.
  - Run:

    ```bash

      -v -k test_machete_qqq

  - Add bit-exact packed-nibble coverage after the copy atom is implemented.
  - Validate on H100.
  - Collect and report performance data only after CUDA 13.4 GA.
