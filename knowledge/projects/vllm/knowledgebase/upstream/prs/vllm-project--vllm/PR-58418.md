## Original PR description

## Purpose

Addresses the GLM-4.7 MoE part of #57827. When a tool call ends without closing its final `</arg_value>` tag, final conversion drops that argument. This change preserves it.

Adds streaming and non-streaming regression tests for both closed and unclosed final values. This is separate from #58349, which fixes MiniMax M2, and #53739, which changes the shared streaming engine.

AI assistance was used to develop this change.
