# [Quantization] Add ModelOpt IQ2_XS, IQ2_XXS, and Q8_0 support via b12x

[Upstream PR](https://github.com/vllm-project/vllm/pull/59604) · state: open · merged: False

## Original PR description

## Summary

Add metadata-driven ModelOpt block quantization support through b12x for IQ2_XS, IQ2_XXS, and Q8_0 checkpoints on SM120/SM121 GPUs, including packed linear/MoE weights, Q8_0 embeddings/vectors, and NVFP4 W4A16 linear execution.

```text
config.json per-layer quantization metadata
  -> ModelOpt block codec selection
  -> packed weight loading and tensor-parallel slicing
  -> b12x kernel preparation before CUDA graph capture
  -> BF16-activation execution
```

This is a republication of Luke Alonso's #59486 from `askliar/vllm`, following our discussion about moving the submission so Luke can review the integration. The three source commits are squashed into one commit authored and committed by Andrii Skliar. Includes focused pre-commit fixes for loader type annotations and accelerator test APIs. This PR is intended to replace #59486; it does not introduce an independent implementation. #59486 remains open at submission time.

AI assistance was used in the original implementation/testing and to prepare this republication and description.

- lukealonso · comment · 2026-10-01T15:33:55Z · [source](https://github.com/vllm-project/vllm/pull/59604#discussion_r4157303172)
