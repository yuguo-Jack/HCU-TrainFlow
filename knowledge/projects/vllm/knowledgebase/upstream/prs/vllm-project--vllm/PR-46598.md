# [Misc] Add remediation hints to MTP and PCP context-parallel errors

[Upstream PR](https://github.com/vllm-project/vllm/pull/46598) · state: open · merged: False

## Original PR description




## Purpose

Hi! I'm new to vLLM and starting from good first issues. While looking at
#28407, I found the DCP error message was already improved in #40053 — but
the neighboring **MTP** and **PCP** assertions in
`check_attention_cp_compatibility` still raise bare errors with no hint on
how to recover. This PR gives them the same actionable style:

- **MTP**: suggest `--cp-kv-cache-interleave-size 1` or disabling speculative decoding.
- **PCP**: suggest disabling via `--prefill-context-parallel-size 1`.

Note: no backend currently sets `supports_pcp`, so the PCP hint only
suggests disabling it rather than switching backends.

## Test Plan
