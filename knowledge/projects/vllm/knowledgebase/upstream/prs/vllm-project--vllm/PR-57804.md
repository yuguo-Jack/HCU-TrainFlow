### What changed in this revision

The earlier revision reindented the whole tail of `load_weights` to drop an `else`, which also moved `maybe_remap_kv_scale_name` in front of the sink handling. That is unrelated to the sink write and changes behavior for a non-sink path. This revision keeps the sink branch self-contained: narrow, load through the current loader, `loaded_params.add`, `continue`. The diff is now the sink branch only.
