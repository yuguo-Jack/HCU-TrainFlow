# Share DeepSeek V4.1 CPU KV across TP ranks

[Upstream PR](https://github.com/vllm-project/vllm/pull/65373) · state: open · merged: False

## Original PR description

Declare DeepSeek V4.1's main KV, indexer K and compressor state TP-replicated so the existing CPU offloading sharing path activates. No cache-interface, planner or connector changes.

8× H100, TP=8, 20 GiB GPU KV per rank and the same 64 GiB total CPU KV budget. Seeded replay of 3,072 requests across 407 LongBench v2 contexts, concurrency 8, chunks=1, up to 128 output tokens.

| Metric | Stock offloading | Shared-host prototype |
| --- | ---: | ---: |
| Requests/s | 0.961 | 5.785 (**6.02×**) |
| Output tokens/s | 25.60 | 146.09 (**5.71×**) |
| p95 TTFT | 11.30 s | 0.95 s |

Tests: 93 focused checks passed on 1× NVIDIA H100 80GB. The three producer regressions fail on the base revision and pass with the fix. All applicable pre-commit hooks passed.
