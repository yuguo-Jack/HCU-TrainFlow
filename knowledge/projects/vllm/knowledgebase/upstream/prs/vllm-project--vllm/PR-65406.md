# [Bugfix][MoE] Count the expert down-projection bias once under TP

[Upstream PR](https://github.com/vllm-project/vllm/pull/65406) · state: open · merged: False

## Original PR description

## Overview

`RoutedExperts.weight_loader` copied the full `w2_bias` to every TP rank, so the row-parallel down projection added it `tp_size` times before the all-reduce. Only TP rank 0 now keeps it, as gpt-oss's own loader already does. Fixes #65405.

## Claims

- Biased experts loaded through the generic loader are correct at TP>1. TP=1, EP (where `tp_rank` is 0 on every rank) and gpt-oss's native loader are unchanged.

## Validation

New test `TestLoadWeightsExpertBias::test_down_bias_owned_by_tp_rank_zero` in `tests/kernels/moe/test_moe_weight_loading_padded.py`. It builds a real `FusedMoEConfig`, `ExpertMapManager` and `RoutedExperts` for `(tp_size, tp_rank)` in `(1, 0)`, `(2, 0)`, `(2, 1)`, `(4, 3)`, loads a nonzero bias through `load_weights`, and checks that rank 0 holds the bias and every other rank holds zeros.

```bash
pytest -v "tests/kernels/moe/test_moe_weight_loading_padded.py::TestLoadWeightsExpertBias::test_down_bias_owned_by_tp_rank_zero"
pytest -q tests/kernels/moe/test_moe_weight_loading_padded.py tests/model_executor/model_loader/test_gpt_oss_weight_loading.py "tests/model_executor/model_loader/test_reload.py::test_padded_moe_reload_releases_each_layer"
```

End to end on CPU with `FusedMoEFactory(has_bias=True)`, the TP=2 and TP=4 error before the fix is exactly `(tp_size - 1)` times the bias term, and 0 after it (numbers in the linked issue).

Full model on CPU through `LLM(model_impl="transformers")`, fp32, eager: a tiny saved HF checkpoint (Mixtral router/attention/decoder with a `ModuleList` of biased `LlamaMLP` experts, 1 layer, 2 experts), so loading goes through `TransformersRoutedExperts` and the generic `RoutedExperts.weight_loader`. Not run: GPU, and no public pretrained checkpoint (I haven't found one with per-expert biases that loads through the Transformers backend).

## Details

The check reads `moe_config.tp_rank`, the rank inside the group the down-projection all-reduce spans. With DP/PCP folded into TP that is the flattened rank. With EP, and with sequence-parallel MoE (which requires EP), `tp_rank` is 0 on every rank, so each rank keeps the bias of the experts it owns.

No open PR covers this branch (searched `w2_bias` and `moe bias tp_rank`). The open reload PRs #61287, #50523 and #65353 don't touch `routed_experts.py`.
