# [Perf][Qwen3.8] Add SM103 skinny GEMM plans for TP=1

[Upstream PR](https://github.com/vllm-project/vllm/pull/64650) · state: closed · merged: True

## Original PR description

## Overview

Adds B300 (SM103) plans for Qwen3.8-Flash-Next TP=1 BF16 linears (DGX Station GB300 recipe); SM103 had TP=4 shapes only. Also adds the SM103 case to the per-arch plan correctness test.

## Claims

- 1.26–3.06x over cuBLAS per cell on cold L2, faster on hot L2 too; ≈ 0.52 ms saved per decode step at bs1.

## Validation

```
pytest tests/kernels/test_bf16_skinny_gemm.py -k qwen4_exp          → 41 passed, 130 skipped (B300)
qwen4_exp_low_latency_gemm vs F.linear (CUPTI, CUDA graph, 14 cells) → all faster, cold and hot L2
```
