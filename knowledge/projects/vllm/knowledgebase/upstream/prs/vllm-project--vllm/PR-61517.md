## Validation

Validated on a remote Ubuntu x86_64 machine with Ryzen 9 9900X, Python 3.12.13 and PyTorch 2.13.0+cpu, against base `698e79f3bdbbe4fe7d6be6d91b358a7f430753ab`.

```sh
TRITON_DEFAULT_BACKEND=cpu VLLM_TARGET_DEVICE=cpu OMP_NUM_THREADS=2 PYTHONPATH=. ../.venv/bin/python -m pytest tests/kernels/mamba/cpu/test_cpu_state_indices.py --confcutdir=tests/kernels/mamba/cpu -q
```

Native baseline: 6 failed, 2 passed. Patched: 8 passed. End-to-end CPU testing with yujiepan/mamba2-codestral-v0.1-tiny-random completed 2 x 64 generated tokens and accepted 2/375 draft tokens, but speculative output still differed from ordinary greedy decoding. The unpatched speculative baseline also differed. This draft does not establish complete speculative-decoding correctness.

Applicable pre-commit checks passed. Upstream CI has not yet been evaluated for this draft.

## Details

End-to-end speculative output parity remains unresolved. This draft only demonstrates the native state-indexing contract; do not treat it as a complete speculative-decoding fix. Ordinary decoding output was unchanged for both prompts. Related #54505 addresses CPU prefix-cache wrappers.

AI assistance (OpenAI Codex) was used for analysis, implementation and validation. The submitter's human review remains pending.
