# [CI][XPU] Ignore test_reload.py on Intel CI

[Upstream PR](https://github.com/vllm-project/vllm/pull/61740) · state: closed · merged: True

## Original PR description

## Overview

Skip `tests/model_executor/model_loader/test_reload.py` entirely on Intel CI (`--ignore` instead of deselecting one test ID), since XPU does not currently support model reload for several model paths exercised in this file.

## Claims

- Fixes the Intel XPU CI "Model Executor" job failure: `test_attention_sink_deepseek_hy_loading_uses_parameter_loader` fails for `deepseek_v41` and `hy_v4` on XPU.
- https://buildkite.com/vllm/intel-ci/builds/14200#01a13bcc-ff3d-4e62-8a9b-b344fcc659b5 — `4 failed, 882 passed, 181 skipped` in this file.

## Validation

```
$ cd tests && python -m pytest --collect-only model_executor -m "not slow_test" \
    --ignore="model_executor/layers/test_rocm_unquantized_gemm.py" \
    --ignore="model_executor/model_loader/tensorizer_loader/test_tensorizer.py" \
    --ignore="model_executor/model_loader/test_reload.py" -q
```
