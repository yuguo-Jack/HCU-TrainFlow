# Support OFI backend for MORI connector

[Upstream PR](https://github.com/vllm-project/vllm/pull/62396) · state: open · merged: False

## Original PR description



## Overview

The MoRIIOConnector currently supports only RDMA and XGMI bakends. The changes here adds supports for OFI libfabric as backend. 

## Claims
The changes here adds supports for OFI libfabric as backend for MoRIIOConnector. The changes to MORI lib to support OFI libfabric was added via the following PR:

https://github.com/ROCm/mori/pull/674

## Details
Supporting OFI back end requires a small change where
1. A new back end type "ofi" is introduced. This must specified under kv_connector_extra_config.
2. The back end type and corresponding config is passed at MORI IO engine instantiation time. If the backend type is OFI, the MORI IO lib (part of RoCM MORI repo) determines the best suited OFI provider on the system and initializes it.
3. A default OFI back end configuration is assumed, it is not configurable at present.
