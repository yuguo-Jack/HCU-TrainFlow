# [CI] Use test models from the vllm-project Hub org

[Upstream PR](https://github.com/vllm-project/vllm/pull/64762) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Point CI at `vllm-project/*` copies of every checkpoint it used from a personal Hub account, to reduce supply-chain risk.

## Claims

- `tiny-random-{Llama,Gemma2,DeepseekV2}ForCausalLM` and `Ilama-3.2-1B` now live under `vllm-project` and are listed in the [CI collection](https://huggingface.co/collections/vllm-project/ci-69cbfc30455b12ac0c6b9b91).
- The old `hmellor/*` names redirect, so nothing breaks before or after this merges.
- 122 checkpoints from other personal accounts were duplicated into `vllm-project` under their original names. Each copy's README and collection note records the source repo and commit.
- Third-party org checkpoints (e.g. `nm-testing`, `hf-internal-testing`) are unchanged.
- `docs/contributing/model/tests.md` and `tests/AGENTS.md` now ask for new CI checkpoints to go in `vllm-project` rather than personal accounts.
