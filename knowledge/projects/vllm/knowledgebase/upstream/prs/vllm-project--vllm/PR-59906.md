# docs: add Gemma 4 Models tool-calling section

[Upstream PR](https://github.com/vllm-project/vllm/pull/59906) · state: open · merged: False

## Original PR description

The tool-calling guide lists every model-specific parser except Gemma 4, even though --tool-call-parser gemma4 (+ --reasoning-parser gemma4) ships and works (verified live against AWQ/GPTQ quants on v0.22.1). This adds the missing section following the file's conventions: supported models, native tool_call syntax with delimited string args, flags, and the thinking-default-off note with a link to reasoning outputs.
