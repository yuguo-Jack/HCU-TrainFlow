# [Model] Add Raon-1-mini support

[Upstream PR](https://github.com/vllm-project/vllm/pull/64217) · state: closed · merged: False

## Original PR description

## Overview

Add native support for [KRAFTON/Raon-1-mini-preview](https://huggingface.co/KRAFTON/Raon-1-mini-preview), a 28.8B-total / 4.3B-active hybrid MoE model.

**I'm working on making simple & clean code. When I'm ready then, I will re open this PR.**

## Claims

- Add model/config registration and checkpoint loading for 18 RDA + seven NoPE MLA layers, four-stream mHC, and SiTU MoE.
- Reuse upstream ModelOpt MXFP8/NVFP4 implementations, MLA, hybrid-state handling, and DFlash2 interfaces. No MoE backend is forced.
- Add `raon_1` reasoning/tool parser adapters and optional RDA/mHC kernels, with config/parser tests and documentation.

## Validation

- **Passed:** 11 CPU config/parser tests, complete pre-commit hooks, exact-base wheel build/install, and native model/tokenizer/parser import checks. All 20 changed vLLM source files match the wheel.
- **Passed:** pinned public checkpoint integrity checks, target/draft config pairing, and NVFP4 mixed-precision config resolution.
- **Pending:** real GPU generation, numerical/model-quality comparisons, backend/kernel execution, shared KDA regressions, DFlash2/cache/graph correctness, and serving benchmarks. No speedup or production-parity claim is made. Dependencies were reused read-only; a clean dependency-resolved installation remains pending.

```bash
VLLM_TARGET_DEVICE=cpu PYTHONPATH=. .venv/bin/python -m pytest \
    tests/transformers_utils/test_raon1_mini_config.py \
    tests/parser/engine/test_raon1_mini.py -q
```

## Details

RDA applies independent write-gate scaling after convolution, preserving raw convolution history. Shared KDA calls retain `value_scale=None`. MXFP8/NVFP4 backend suitability will be checked separately with SiTU on the target GPU.

Optional `raon_fast` kernels currently require SM10x, TP1, BF16 convolution history, FP32 recurrent state, the default SD layout, and a CUDA/C++ build toolchain. PP, EP, and RecoverSSM are unsupported.

Duplicate check: authenticated issue/PR searches for Raon and the proposed head branch found no existing matches on 2026-10-28.

AI assistance: OpenAI Codex assisted with implementation and preparation. Human line-by-line review and end-to-end validation confirmation are still pending.
