# Added online regression coverage for Qwen3 reranker template behavior

[Upstream PR](https://github.com/vllm-project/vllm/pull/45316) · state: closed · merged: False

## Original PR description

## Purpose

This PR adds online regression coverage for the Qwen3 reranker template path because original Qwen3 reranker models depend on the documented `qwen3_reranker.jinja` chat template to construct the scoring prompt correctly. The test guards against regressions where `/score `or `/rerank` silently fall back to plain `query/document tokenization` and ignore `--chat-template`, which was the behavior reported in #[39784](https://github.com/vllm-project/vllm/issues/39784). It checks both endpoints against locally rendered template tokenization, so future changes to scoring preprocessing have a clear online parity signal.

## Test Plan
