# [Perf][Attention] Cache FlexAttention K/V cache views per tensor

[Upstream PR](https://github.com/vllm-project/vllm/pull/65395) · state: open · merged: False

## Original PR description

## Summary

`FlexAttentionImpl` re-derived its K/V cache views from the `kv_cache` tensor on
every call: the transpose/split in `do_kv_cache_update`, and the transpose/split
plus the flatten in the decoder `forward` path. These views depend only on the
`kv_cache` tensor storage/shape/strides, which are fixed once the cache is
allocated, so deriving them per call is pure host overhead on the eager critical
path and multiplies by `num_layers` per step.

Cache the derived views per `kv_cache` tensor identity, mirroring the
FlashAttention fix in #64571: `_get_kv_views` keyed on the tensor, rebuilt when
the profiling cache is replaced by the real one, and cleared in both
`_cleanup_profiling_kv_cache` and `clear_layer_kv_caches` via the
`_kv_view_cache` attribute convention so the profiling buffer is not pinned.

This addresses the `flex_attention.py` backend of #64572. The `_kv_view_cache`
teardown hunks share the attribute-name convention introduced by #64571;
whichever lands first makes the other a trivial rebase.

Related: #59534, #64571, #64572

## Testing

`pytest tests/v1/attention/test_flex_kv_view_cache.py` — 5 passed (CPU-only):
cache hit returns identical view objects, views match the direct derivation and
flatten to the expected shape, the cache rebuilds when the tensor is replaced,
teardown clears it, and an in-place write through the cached view aliases the
underlying `kv_cache` storage.

Host time per forward-path derivation vs a cached-view hit (CPU, N=4000 after
warmup, blocks=1000/block=16/kv_heads=4/head=128): **7.95 µs → 0.13 µs/call**.
`pre-commit` clean (ruff, ruff-format, mypy).

## Duplicate check

`gh pr list --state open --search "flex_attention kv view ..."`: no open PR
caches the Flex KV views. Triton (#64890) and `hpc_attn` (claimed by another
contributor) are the other #64572 backends; this PR is the `flex_attention.py`
one only.
