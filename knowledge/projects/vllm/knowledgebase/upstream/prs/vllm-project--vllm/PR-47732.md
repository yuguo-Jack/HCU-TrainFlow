## Original PR description

# Add FP8 W8A8 Block Kernel Configs for NVIDIA GeForce RTX 4090D

## Problem

RTX 4090D is the most widely adopted 48GB AI accelerator in the Chinese market, yet vllm currently has **zero** tuned FP8 kernel configs for this GPU. Every 4090D user sees:

```
Using default W8A8 Block FP8 kernel config. Performance might be sub-optimal!
```

## Solution

This PR adds **13 pre-tuned W8A8 Block FP8 kernel configs** for `NVIDIA_GeForce_RTX_4090_D`, autotuned on 4× RTX 4090D hardware.

### Config Coverage

| N | K | M-dimensions tuned |
|---|---|---|
| 256 | 7168 | 2048, 3072, 4096 |
| 576 | 7168 | 2048, 3072, 4096 |
| 1536 | 1536 | 2048, 3072, 4096 |
| 1536 | 7168 | 2048, 3072, 4096 |
| 2048 | 512 | 2048, 3072, 4096 |
| 2304 | 7168 | 2048, 3072, 4096 |
| 7168 | 128 | 2048, 3072, 4096 |
| 7168 | 1024 | 2048, 3072, 4096 |
| 7168 | 1152 | 2048, 3072, 4096 |
| 7168 | 16384 | 2048, 3072, 4096 |
| 7168 | 18432 | 2048, 3072, 4096 |
| 24576 | 7168 | 2048, 3072, 4096 |
| 32768 | 512 | 2048, 3072, 4096 |

Key shapes covered:
- **N=7168, K=16384** — DeepSeek V4 attention projections
- **N=24576, K=7168** — Large MLP intermediate projections
- 7 of 13 (N,K) combinations are **entirely new** to vllm's config directory

## Verification

- Generated via SGLang/KT autotune on 4× RTX 4090D
- Each config file matches vllm's expected format: `N={N},K={K},device_name=NVIDIA_GeForce_RTX_4090_D,dtype=fp8_w8a8,block_shape=[128,128].json`
- Config loading path: `vllm/model_executor/layers/quantization/utils/configs/`
- Device name matches `torch.cuda.get_device_name()` output: `NVIDIA_GeForce_RTX_4090_D`
