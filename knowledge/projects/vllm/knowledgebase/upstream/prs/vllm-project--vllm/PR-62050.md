# [compile] Remove layer_name from unified_kv_cache_update

[Upstream PR](https://github.com/vllm-project/vllm/pull/62050) · state: open · merged: False

## Original PR description

### Purpose
This pull request removes the `layer_name` string parameter from the `unified_kv_cache_update` custom operator signature. 

By hoisting this layer-specific identifier out of the operator call, `torch.compile` (Dynamo/Inductor) can cleanly recognize the execution patterns as identical across all sequential blocks. This prevents graph fragmentation into separate artifacts per layer and successfully slashes cold-start compilation overhead for large model architectures (like Qwen and DeepSeek).

Closes #33267

### Test Plan
1. **Mock Tracing Validation**: Verified via a custom compilation trace script that running a `torch.compile` loop across sequential decoder block mockups executes seamlessly without graph fragmentation or caching trace errors when dropping layer-specific string tokens from the operator signature.
2. **Regression Check**: Ensured structural alignment with the context-hoisting patterns established in previous architectural updates (#32805 and #33184).
