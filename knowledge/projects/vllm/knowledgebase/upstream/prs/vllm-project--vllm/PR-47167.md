# [Tool Parser] poolside_v1: migrate to the declarative parser engine

[Upstream PR](https://github.com/vllm-project/vllm/pull/47167) · state: open · merged: False

## Original PR description

Re-implements the poolside_v1 tool parser (poolside Laguna) on the declarative parser engine instead of the standalone regex parser. Laguna emits the GLM-4.7 tool-call format verbatim (<tool_call>name<arg_key>k</arg_key><arg_value>v</arg_value> </tool_call>, function name inline with no newline separator), so it is backed by a new PoolsideParser whose poolside_v1_config mirrors glm47_moe_config. This inherits the engine's incremental string streaming and schema-aware argument coercion. This was initially suggested to us by @sfeng33 in #46486.
