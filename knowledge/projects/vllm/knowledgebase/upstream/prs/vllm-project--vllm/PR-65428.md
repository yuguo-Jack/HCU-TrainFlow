# [Bugfix][CI] Keep the chat template on NixlConnector PD + SD acceptance prompts

[Upstream PR](https://github.com/vllm-project/vllm/pull/65428) · state: closed · merged: True

## Original PR description



## Overview

Fixes `(MI355) NixlConnector PD + Spec Decode acceptance`, which has failed since [#65245](https://github.com/vllm-project/vllm/pull/65245) landed ([amd-ci #15764](https://buildkite.com/vllm/amd-ci/builds/15764#01a1a0db-a963-418a-a1cd-a003f97c4f00)). The test's MT-Bench prompts lost their chat template; dropping `backend="openai-chat"` from the `get_samples()` args restores it.

## Claims

- Test-only, one-line fix. The prompts are byte-identical to those before [#65245](https://github.com/vllm-project/vllm/pull/65245).
- EAGLE3 acceptance length: 1.928 (FAIL, expected 2.600 ± 5%) → 2.583 (pass).
- No open PR addresses this failure: none touches this test or references [#65245](https://github.com/vllm-project/vllm/pull/65245).

## Details

**Root cause.** [#65245](https://github.com/vllm-project/vllm/pull/65245) made `get_samples()` skip the client-side chat template for chat backends, since those endpoints apply it server-side. This test declares `backend="openai-chat"` but sends the prompts to `/v1/completions` with `add_special_tokens=False`. The prompts therefore reached the server with no chat template and no BOS, and acceptance dropped at every draft position. Without `backend`, the test builds its prompts the same way the standalone baseline in `tests/v1/spec_decode/test_acceptance_length.py` does.

**Bisect.** Earlier nightlies consistently scored 2.603. The ROCm, PyTorch and Triton versions are identical between the passing and failing images. Overlaying each candidate commit's Python sources onto the last passing image (`5cdeea9`) gave `8b30f56` ([#65245](https://github.com/vllm-project/vllm/pull/65245)) as the first bad commit.

**Limitation.** With identical prompts, EAGLE3 scores 2.583 rather than 2.603. That shift is deterministic and comes from other engine changes that landed the same day. It is within tolerance, so the baseline is left unchanged.

AI assistance was used for the bisect, root-cause analysis, and this description. The submitter reviewed the change and ran the validation above.
