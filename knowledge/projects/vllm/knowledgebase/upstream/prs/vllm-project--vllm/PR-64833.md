# [ROCm][Step5] Require CDNA3 or newer for the sparse attention layers

[Upstream PR](https://github.com/vllm-project/vllm/pull/64833) · state: closed · merged: True

## Original PR description

- model.py: `_validate_sparse` raises `NotImplementedError` when `get_cdna_version() < 3`.
- supported_models.md: the ROCm Step-5 note states the CDNA3 requirement.

Follow-up to #61837. The Step-5 entry point sends every ROCm GPU to `amd/`, so on CDNA2 or RDNA the model builds and loads its weights, then fails at the first CSA forward inside the FP8 indexer kernels with an error that never mentions the hardware. The NVIDIA path already raises at startup for unsupported compute capabilities. This does the same on ROCm. `< 3` keeps gfx1250, which reports CDNA5, eligible, since `_validate_sparse` already has a gfx1250-specific check. No open PR touches this check; #61945 changes the shared Step-5 kernels, not `amd/model.py`.

Tested on MI350X: `get_cdna_version()` returns 4, so the guard passes, and pre-commit is clean. The Step-5 model tests have not been rerun yet because the GPUs on my node are busy; I will add the results before marking this ready.
