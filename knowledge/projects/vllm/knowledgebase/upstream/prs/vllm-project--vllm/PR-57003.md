# Add Agnes 3.0 Flash model support

[Upstream PR](https://github.com/vllm-project/vllm/pull/57003) · state: open · merged: False

## Original PR description

## Purpose

Agnes 3.0 Flash checkpoints use Qwen3.5 hybrid attention with different checkpoint names and an extra parallel FFN in each decoder layer. vLLM currently does not recognize `AgnesForConditionalGeneration`. With the AutoRound GPTQ checkpoint, loading also stops at `parallel_ffn.gate_proj` because vLLM builds a fused `gate_up_proj`.

This PR registers the Agnes configuration and model, translates the attention and FFN tensor names, and sums the parallel FFN with the existing Qwen3.5 MLP. It also handles the checkpoint's unquantized GDN, vision, and MTP weights. The approach is based on the [Agnes team's SGLang implementation](https://huggingface.co/Agnes-AI/Agnes-3.0-Flash/blob/main/sglang_patch/README.md), which likewise reuses Qwen3.5 and maps Agnes's attention names. vLLM keeps the parallel FFN as a separate branch so its computation and GPTQ projections remain separate.

I found no open vLLM issue or PR matching Agnes in upstream searches on September 15, 2026.

## Test Plan

- `/opt/venv/bin/python -m pytest tests/models/multimodal/test_mapping.py -k agnes -v -p no:cacheprovider` in the B70 XPU image with this branch's files installed.
- `/opt/venv/bin/python -m pytest tests/models/test_registry.py -k AgnesForConditionalGeneration -v -p no:cacheprovider` in the same image.
- `uv tool run --offline ruff check` and `uv tool run --offline ruff format --check` on the eight changed files.
- Text-only serving of `urakozz/Agnes-3.0-Flash-W4A16-AutoRound-GPTQ` on Intel Arc Pro B70 with XPU Graph, `--language-model-only`, and a 2048-token maximum context after the image rebuild.

## Test Result

- All five checkpoint-mapping cases passed, including GPTQ `qweight`, `qzeros`, and `scales`.
- The Agnes registry import test passed.
- Ruff lint and formatting checks passed for all eight changed files.
- An earlier source overlay with the same Agnes adapter loaded all six GPTQ shards, returned HTTP 200 from `/health`, and answered two deterministic text prompts with `42` and `Paris` on XPU Graph. Serving from the committed branch is pending the image rebuild.
- Python compilation and `git diff --check` passed. Formal accuracy evaluation, multimodal inputs, and MTP serving have not been tested.
