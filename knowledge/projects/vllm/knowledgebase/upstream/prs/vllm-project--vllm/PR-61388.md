## Original PR description

## Overview

Restore complete routed-expert rows when model-level sequence parallelism shards tokens across TP ranks and DP=1 has no DP metadata. Related platform-specific work: https://github.com/vllm-project/vllm-ascend/pull/18502.

## Claims

- Identify TP shards using the existing `BatchDescriptor.num_tokens` (or `DPMetadata` for multi-DP), gather in rank order, and trim SP padding.
- Reuse the descriptor in eager, graph, microbatch and decoder-replay contexts; no extra `ForwardContext.num_tokens` field or count-only caller arguments.
- Preserve multi-DP layout priority and reject malformed shard grouping explicitly, including under optimized Python.

## Details

The previous DP=1 path wrote only the received TP shard, leaving later routing rows stale. Restore the local token axis before buffer assignment. Layer bounds are checked before collectives and gather inputs are contiguous.

The pre-SP count must survive model-level sharding: `is_padding` can itself become a TP shard and is not a reliable count source. The existing batch descriptor retains the original size, including in compact decoder-replay contexts. Creating that descriptor for eager execution removes duplicate state and three count-only caller edits (production diff for this refinement: net -11 lines).

This updates the existing TP fix rather than opening a duplicate. Microbatch write offsets (#57184) and decoder-replay row retention (#61643) remain separate concerns, unchanged here. The restoration helper shares one layout error, reads the declared `DPMetadata.local_sizes` field directly, and retains the existing layout priority. Tests use actual `DPMetadata` objects.

**What it asserts.** For every request it rebuilds the whole batch from each TP rank's *raw pre-capture shard* (recorded by the probe in the next comment), concatenates the shards in TP-rank order, trims to the pre-SP forward token count, and compares **every token/layer/expert id** against the `routed_experts` array returned by `/v1/completions`. "All ids in range" / "rows are nonzero" are not used as criteria.

```python# SPDX-License-Identifier: Apache-2.0
"""End-to-end model reproducer for TP-sharded routed-expert capture at DP=1.

This is the model-level reproducer that vLLM PR #61388 ("[Bugfix][MoE]
Restore TP-sharded routed-expert capture for DP=1") lists as pending, outside
CI: it needs a DeepSeek V4/V4.1 checkpoint and two GPUs, so it is deliberately
not collected by any Buildkite job (the filename does not match pytest's
``python_files``) and must be run by path.

The bug
-------
With ``data_parallel_size == 1``, ``ParallelConfig.use_sequence_parallel_moe``
is false, so the forward context carries no ``dp_metadata``. DeepSeek V4/V4.1
(and Kimi K3) still shard tokens across TP *at the model level* for their
MegaMoE backends - ``_use_sequence_parallel`` only needs EP, TP > 1 and a
MegaMoE backend. The capture callback therefore receives ``ceil(N / TP)`` rows,
and the pre-fix capturer wrote exactly those rows into the DP-1 buffer, leaving
rows ``[ceil(N / TP), N)`` holding whatever an earlier forward left there.
Only TP rank 0 publishes the auxiliary output, so the stale rows reached the
client as if they were the second half of the batch.

What this checks
----------------
For each request it compares the ``routed_experts`` array returned by
``/v1/completions`` against a reference rebuilt from every TP rank's *raw*
pre-capture shard (see ``tests/models/routed_experts_capture_probe.py``):
shards are concatenated in TP-rank order and trimmed to the pre-SP forward
token count, which is exactly the batch the captured rows must describe. It
also asserts that the publishing rank's capture buffer holds that same batch,
which separates a capture bug from an auxiliary-output plumbing bug. Every
token/layer/expert id is compared; "all ids are in range" or "rows are
nonzero" are not used as criteria.

Cases (the rows of the PR's required-model-validation table):

1. six-token prefill, TP=2, EP, DP=1 - all six rows equal the shard reference;
2. three-token prefill - the fourth, SP-padded row is trimmed away;
3. two different six-token batches on one worker - the second batch keeps no
   stale ids from the first;
4. single-token prefill and decodes - no capture-only gather, TP0's rows are
   what is returned;
5. CUDA graph execution (env-gated by ``VLLM_ROUTED_EXPERTS_E2E_GRAPH=1``) -
   returned real-token rows match the eager reference, no hang;
6. complete-batch control on an ordinary MoE path (env-gated by
   ``VLLM_ROUTED_EXPERTS_E2E_CONTROL=1``, default on) - TP=2 + EP + DP=1 with
   no model-level token SP captures the whole batch without a capture gather,
   and its routes equal a TP=1 run of the same model.

How to run
----------
With a checkpoint whose MoE backend supports capture (Blackwell only, see
below)::

    export VLLM_ROUTED_EXPERTS_E2E_MODEL=/path/to/deepseek-v4-checkpoint
    export VLLM_ROUTED_EXPERTS_E2E_BACKEND=deep_gemm_mega_moe   # or

With a real MegaMoE model, cases 1-3 must fail on the base (partial batch
written) and pass on the fix; case 4 is a control that passes on both.

Where it can run, and what ``EMULATE_SP`` is for
------------------------------------------------
All three members of ``MEGA_MOE_BACKENDS`` refuse to bind below SM100/SM103:
``get_deep_gemm_mega_moe_backend`` raises for anything but SM100
(``vllm/model_executor/layers/fused_moe/deep_gemm_mega_moe.py``) and
``FlashInferMoeEpBackendSpec.supports_current_device`` accepts only (10, 0) and

Hopper/Ampere host cannot start the model-level sharding the DP=1 bug lives in,
whatever the weights are. ``VLLM_ROUTED_EXPERTS_E2E_EMULATE_SP=1`` covers that
gap: the probe slices the capture input into ``ceil(T / tp)``-row TP shards,
padded the way ``sp_reduce_scatter`` pads, so the real capture code, the real
TP all-gather and the whole engine path run on the layout the bug is about.
Everything else stays real; only "which rows the capture is handed" is
emulated, and the run says so in every summary it prints.

def _prompt(slot: int, count: int) -> tuple[int, ...]:
    """Distinct, uncached, tokenizer-valid ids for one request."""
    base = _PROMPT_BASE + slot * 32
    return tuple(base + index for index in range(count))


@dataclass(frozen=True)
class _Record:
    seq: int
    tp_rank: int
    dp_rank: int
    layer_id: int
    num_tokens: int
    num_padding: int
    gathers: int
    ids: np.ndarray
    buffer_rows: np.ndarray


@dataclass
class _Step:
    index: int
    num_tokens: int
    num_padding: int
    layer_ids: tuple[int, ...]
    shards: dict[int, dict[int, np.ndarray]] = field(default_factory=dict)
    buffers: dict[int, dict[int, np.ndarray]] = field(default_factory=dict)
    gathers: dict[tuple[int, int], int] = field(default_factory=dict)

    @property
    def num_real(self) -> int:
        return self.num_tokens - self.num_padding

    @property
    def first_layer(self) -> int:
        return self.layer_ids[0]

    def shard_sizes(self, layer_id: int) -> dict[int, int]:
        return {rank: rows.shape[0] for rank, rows in self.shards[layer_id].items()}


@dataclass
class _Trace:
    steps: list[_Step]
    bounds: list[tuple[int, int]]
    sharded: list[bool]
    trimmed: list[bool]
    gathers: list[int]
    reference: dict[int, np.ndarray]
    published: dict[int, np.ndarray]
    publish_rank: int

    @property
    def total_rows(self) -> int:
        return sum(end - start for start, end in self.bounds)

    @property
    def max_gathers(self) -> int:
        return max(self.gathers, default=0)

    @property
    def layers(self) -> list[int]:
        return sorted(self.reference)


@dataclass(frozen=True)
class _ServerSpec:
    name: str
    model: str
    args: tuple[str, ...]
    env: dict[str, str]
    probe: bool


@dataclass
class _Result:
    tokens: tuple[int, ...]
    prompt_tokens: int
    generated: int
    routed: np.ndarray
    records: list[_Record]
    case: str
    tag: str | None = None

    @property
    def expected_rows(self) -> int:
        return self.prompt_tokens + self.generated - 1


def _write_tiny_tokenizer(model_dir: Path, vocab_size: int) -> None:
    """A byte-level-free WordLevel tokenizer, enough for token-id prompts."""
    import json

    from tokenizers import Tokenizer, models, pre_tokenizers

    vocab = {"<unk>": 0, "<s>": 1, "</s>": 2, "<pad>": 3}
    vocab.update({f"tok{index}": index for index in range(4, vocab_size)})
    tokenizer = Tokenizer(models.WordLevel(vocab=vocab, unk_token="<unk>"))
    tokenizer.pre_tokenizer = pre_tokenizers.Whitespace()
    tokenizer.save(str(model_dir / "tokenizer.json"))
    (model_dir / "tokenizer_config.json").write_text(
        json.dumps(
            {
                "tokenizer_class": "PreTrainedTokenizerFast",
                "unk_token": "<unk>",
                "bos_token": "<s>",
                "eos_token": "</s>",
                "pad_token": "<pad>",
                "model_max_length": 512,
                "clean_up_tokenization_spaces": False,
            }
        )
    )


def _dummy_model_dir(arch: str) -> Path:
    """Materialize a weights-free model dir (config + tokenizer, no weights)."""
    import json

    model_dir = ARTIFACT_DIR / f"dummy-{arch}"
    if (model_dir / "config.json").exists():
        return model_dir
    model_dir.mkdir(parents=True, exist_ok=True)
    spec = _DUMMY_ARCHES[arch]
    (model_dir / "config.json").write_text(json.dumps(spec.config, indent=2))
    _write_tiny_tokenizer(model_dir, spec.tokenizer_vocab)
    (model_dir / "generation_config.json").write_text(
        json.dumps(
            {
                "bos_token_id": 1,
                "eos_token_id": 2,
                "pad_token_id": 3,
                "do_sample": False,
            }
        )
    )
    print(f"[routed-experts-e2e] wrote weights-free {arch} model to {model_dir}")
    return model_dir


def _target_model() -> tuple[str, tuple[str, ...], bool]:
    """(model path, extra serve args, whether it uses a MegaMoE backend)."""
    override = os.environ.get("VLLM_ROUTED_EXPERTS_E2E_MEGA_MOE", "")
    if MODEL:
        mega = override != "0"
        return MODEL, (), mega
    arch = DUMMY_ARCH or "mixtral"
    spec = _DUMMY_ARCHES[arch]
    # Emulation replaces the model-level sharding, so no backend is needed.
    mega = spec.needs_mega_moe and not EMULATE_SP and override != "0"
    return str(_dummy_model_dir(arch)), spec.serve_args, mega


def _control_model() -> tuple[str, tuple[str, ...]]:
    if CONTROL_MODEL:
        return CONTROL_MODEL, ()
    if DUMMY:
        spec = _DUMMY_ARCHES["mixtral"]
        return str(_dummy_model_dir("mixtral")), spec.serve_args
    return "", ()

    args = [

def _main_spec(
    *, enforce_eager: bool, probe: bool = True, inject: str | None = None
) -> _ServerSpec:
    env = {"VLLM_USE_V2_MODEL_RUNNER": "1"}
    if inject is None and EMULATE_SP:
        # Force the DP=1 sharded layout the fix is about; see EMULATE_SP.
        inject = "shard"
    if inject:
        env["VLLM_ROUTED_EXPERTS_E2E_INJECT"] = inject
    model, model_args, mega = _target_model()
    name = "eager" if enforce_eager else "graph"
    return _ServerSpec(
        name=f"main-{name}" + (f"-{inject}" if inject else ""),
        model=model,
        args=_moe_serve_args(
            tp_size=TP_SIZE,
            expert_parallel=True,
            backend=MOE_BACKEND if mega else None,
            enforce_eager=enforce_eager,
        )
        + model_args,
        env=env,
        probe=probe,
    )

def _injected_spec(mode: str) -> _ServerSpec:
    """Server whose capture input is rewritten to force one layout branch."""
    return _main_spec(enforce_eager=True, inject=mode)


def _control_spec(*, tp_size: int, probe: bool) -> _ServerSpec:
    """Ordinary MoE path: TP+EP but no model-level token sharding."""
    model, model_args = _control_model()
    args = _moe_serve_args(
        tp_size=tp_size,
        expert_parallel=tp_size > 1,
        backend=None,
        enforce_eager=True,

    # tiny-mixtral publishes a sliding window that AuxOutput retention rejects.
    if "TitanML/tiny-mixtral" in model:

    return _ServerSpec(
        name=f"control-tp{tp_size}",
        model=model,
        args=args + model_args,
        env={"VLLM_USE_V2_MODEL_RUNNER": "1"},
        probe=probe,
    )


class _Harness:
    """Runs one server at a time (each spec needs every GPU) and reads dumps."""

    def __init__(self, artifact_dir: Path) -> None:
        assert PROBE_MODE in ("worker-extension", "sitecustomize"), (
            f"VLLM_ROUTED_EXPERTS_E2E_PROBE_MODE={PROBE_MODE!r} is not supported"
        )
        self.root = artifact_dir
        self.dump_dir = artifact_dir / "dumps"
        self.dump_dir.mkdir(parents=True, exist_ok=True)
        self.tag_path = self.dump_dir / "current_tag"
        self.shim_dir = artifact_dir / "probe_shim"
        self._write_probe_shim()
        self._stack = contextlib.ExitStack()
        self._client = None
        self._active: str | None = None
        self._requests = 0
        print(
            f"[routed-experts-e2e] artifacts: {self.root}\n"
            f"[routed-experts-e2e] probe mode: {PROBE_MODE}"
        )

    def close(self) -> None:
        self.tag_path.unlink(missing_ok=True)
        self._stack.close()
        self._client = None
        self._active = None

    def _write_probe_shim(self) -> Path:
        self.shim_dir.mkdir(parents=True, exist_ok=True)
        (self.shim_dir / "vllm_re_capture_probe.py").write_text(
            "import importlib.util as _ilu\n\n"
            f"_PATH = {str(_PROBE_MODULE)!r}\n"
            "_NAME = 'vllm_re_capture_probe_impl'\n"
            "_spec = _ilu.spec_from_file_location(_NAME, _PATH)\n"
            "_impl = _ilu.module_from_spec(_spec)\n"
            "_spec.loader.exec_module(_impl)\n"
            "_impl.install()\n\n"
            "ProbeWorkerExtension = _impl.ProbeWorkerExtension\n"
        )
        if PROBE_MODE == "sitecustomize":
            # Fallback injection: every interpreter on PYTHONPATH imports this.
            (self.shim_dir / "sitecustomize.py").write_text(
                "import os\n\n"
                'if os.environ.get("VLLM_ROUTED_EXPERTS_DUMP_DIR"):\n'
                "    import vllm_re_capture_probe  # noqa: F401\n"
            )
        return self.shim_dir

    def _server_env(self, spec: _ServerSpec) -> dict[str, str]:
        env = dict(spec.env)
        env["VLLM_ROUTED_EXPERTS_DUMP_DIR"] = str(self.dump_dir)
        if spec.probe:
            entries = [str(self.shim_dir)]
            entries += [
                entry
                for entry in os.environ.get("PYTHONPATH", "").split(os.pathsep)
                if entry
            ]
            env["PYTHONPATH"] = os.pathsep.join(entries)
        return env

    def _ensure(self, spec: _ServerSpec) -> None:
        if self._active == spec.name:
            return
        self.close()
        args = list(spec.args)
        if spec.probe and PROBE_MODE == "worker-extension":
            args += [
                "--worker-extension-cls",
                "vllm_re_capture_probe.ProbeWorkerExtension",
            ]
        print(f"[routed-experts-e2e] starting {spec.name}: {' '.join(args)}")
        server = self._stack.enter_context(
            RemoteOpenAIServer(
                spec.model,
                args,
                env_dict=self._server_env(spec),
                max_wait_seconds=STARTUP_TIMEOUT,
            )
        )
        self._client = server.get_client(timeout=REQUEST_TIMEOUT)
        self._active = spec.name
        if spec.probe:
            self._warm_up(spec)

    def _warm_up(self, spec: _ServerSpec) -> None:
        """Burn one request with no dump tag: profiling, JIT and graph capture
        (lazy or not) happen here, never inside a measured request."""
        self._client.completions.create(
            model=spec.model,
            prompt=list(_prompt(_WARMUP_SLOT, 1)),
            max_tokens=1,
            temperature=0.0,
            extra_body={"return_token_ids": True, "ignore_eos": True},
        )

    def generate(
        self,
        spec: _ServerSpec,
        tokens: tuple[int, ...],
        *,
        max_tokens: int,
        case: str,
        dump: bool = True,
        request_timeout: float | None = None,
    ) -> _Result:
        self._ensure(spec)
        self._requests += 1
        tag = f"{spec.name}-{self._requests}-{uuid.uuid4().hex[:8]}" if dump else None
        if tag is not None:
            self.tag_path.write_text(tag)
        extra: dict[str, Any] = {}
        if request_timeout is not None:
            extra["timeout"] = request_timeout
        try:
            response = self._client.completions.create(
                model=spec.model,
                prompt=list(tokens),
                max_tokens=max_tokens,
                temperature=0.0,
                extra_body={"return_token_ids": True, "ignore_eos": True},
                **extra,
            )
        finally:
            self.tag_path.unlink(missing_ok=True)
        choice = response.model_dump()["choices"][0]
        token_ids = choice.get("token_ids") or []
        records = _read_records(self.dump_dir, tag) if tag else []
        return _Result(
            tokens=tokens,
            prompt_tokens=int(response.usage.prompt_tokens),
            generated=len(token_ids),
            routed=_decode_routed_experts(choice.get("routed_experts"), case),
            records=records,
            case=case,
            tag=tag,
        )

def _device_name() -> str:
    try:
        import torch

        if not torch.cuda.is_available():
            return "no CUDA device"
        major, minor = torch.cuda.get_device_capability()
        return f"{torch.cuda.get_device_name()} (SM{major}{minor})"
    except Exception as exc:  # pragma: no cover - defensive
        return f"unknown device ({exc!r})"


def _decode_routed_experts(encoded: str | None, case: str) -> np.ndarray:
    assert encoded is not None, (
        f"{case}: the response carried no routed_experts. Check that "
        "--enable-return-routed-experts is active, that the model runner is V2 "
        'and that prefix caching is enabled ("AuxOutput Connector requires '
        'prefix caching").'
    )
    array = np.load(io.BytesIO(pybase64.b64decode(encoded)))
    assert array.ndim == 3, f"{case}: routed_experts must be [tokens, layers, topk]"
    return array.astype(np.int32)


def _read_records(dump_dir: Path, tag: str) -> list[_Record]:
    records: list[_Record] = []
    for path in sorted(dump_dir.glob(f"{tag}.*.bin")):
        data = path.read_bytes()
        offset = 0
        while offset < len(data):
            if data[offset : offset + 4] != _MAGIC:
                raise _HarnessError(f"{path.name}: corrupt probe dump at {offset}")
            (
                _magic,
                seq,
                tp_rank,
                dp_rank,
                layer_id,
                num_tokens,
                num_padding,
                n_rows,
                topk,
                gathers,
                buffer_rows,
            ) = _HEADER.unpack_from(data, offset)
            offset += _HEADER.size
            count = n_rows * topk
            ids = np.frombuffer(data, dtype=np.int32, count=count, offset=offset)
            offset += count * 4
            count = buffer_rows * topk
            rows = np.frombuffer(data, dtype=np.int32, count=count, offset=offset)
            offset += count * 4
            records.append(
                _Record(
                    seq=seq,
                    tp_rank=tp_rank,
                    dp_rank=dp_rank,
                    layer_id=layer_id,
                    num_tokens=num_tokens,
                    num_padding=num_padding,
                    gathers=gathers,
                    ids=ids.reshape(n_rows, topk).copy(),
                    buffer_rows=rows.reshape(buffer_rows, topk).copy(),
                )
            )
    return records


def _split_steps(records: list[_Record]) -> list[list[_Record]]:
    """Split one rank's records into forwards: the layer id restarts each time."""
    steps: list[list[_Record]] = []
    current: list[_Record] = []
    previous: int | None = None
    for record in records:
        if previous is not None and record.layer_id <= previous:
            steps.append(current)
            current = []
        current.append(record)
        previous = record.layer_id
    if current:
        steps.append(current)
    return steps


def _merge_step(index: int, group: dict[int, list[_Record]]) -> _Step:
    _, records = next(iter(group.items()))
    layer_ids = tuple(record.layer_id for record in records)
    step = _Step(
        index=index,
        num_tokens=records[0].num_tokens,
        num_padding=records[0].num_padding,
        layer_ids=layer_ids,
    )
    for rank, records in group.items():
        if tuple(record.layer_id for record in records) != layer_ids:
            raise _HarnessError(
                f"forward {index}: TP rank {rank} captured layers "
                f"{tuple(r.layer_id for r in records)}, another rank captured "
                f"{layer_ids}; the ranks did not run the same forward"
            )
        for record in records:
            if (record.num_tokens, record.num_padding) != (
                step.num_tokens,
                step.num_padding,
            ):
                raise _HarnessError(
                    f"forward {index}: TP rank {rank} reports token count "
                    f"({record.num_tokens}, padding {record.num_padding}), "
                    f"another rank reports ({step.num_tokens}, padding "
                    f"{step.num_padding})"
                )
            step.shards.setdefault(record.layer_id, {})[rank] = record.ids
            step.buffers.setdefault(record.layer_id, {})[rank] = record.buffer_rows
            step.gathers[(record.layer_id, rank)] = record.gathers
    return step


def _group_steps(records: list[_Record], tp_size: int) -> list[_Step]:
    if not records:
        raise _HarnessError(
            "no capture records were dumped. The probe did not run in the "
            "worker processes; see probe_notes.log in the artifact directory. "
            "Try VLLM_ROUTED_EXPERTS_E2E_PROBE_MODE=sitecustomize if "
            "--worker-extension-cls is not honoured on this stack."
        )
    by_rank: dict[int, list[_Record]] = {}
    for record in records:
        by_rank.setdefault(record.tp_rank, []).append(record)
    if any(rank < 0 for rank in by_rank):
        raise _HarnessError(
            "the probe could not resolve a TP rank for some captures, so the "
            "shards cannot be ordered; run with vLLM's distributed state "
            "initialized as usual and report this"
        )
    expected_ranks = set(range(tp_size))
    if set(by_rank) != expected_ranks:
        raise _HarnessError(
            f"capture records came from TP ranks {sorted(by_rank)}, expected "
            f"{sorted(expected_ranks)}"
        )
    per_rank = {
        rank: _split_steps(sorted(records, key=lambda record: record.seq))
        for rank, records in by_rank.items()
    }
    counts = {rank: len(steps) for rank, steps in per_rank.items()}
    if len(set(counts.values())) != 1:
        raise _HarnessError(
            f"TP ranks captured a different number of forwards: {counts}; a "
            "rank skipped or repeated a forward"
        )
    return [
        _merge_step(index, {rank: steps[index] for rank, steps in per_rank.items()})
        for index in range(next(iter(counts.values()), 0))
    ]


def _layer_reference(
    step: _Step, layer_id: int, tp_size: int
) -> tuple[np.ndarray, bool, bool]:
    """Rebuild one forward's routing rows for one layer from the raw shards.

    Returns:
        The unpadded batch's rows, whether the shards were TP-split, and
        whether any row had to be trimmed from the gathered batch.

    """
    sizes = step.shard_sizes(layer_id)
    ranks = sorted(sizes)
    padded = step.num_tokens
    real = step.num_real
    if padded <= 0 or real <= 0:
        raise _HarnessError(
            f"forward {step.index}: the probe saw no forward token count, so "
            "the shards cannot be trimmed to the batch. The capturer's context "
            "must expose num_tokens (or a batch descriptor with num_tokens)."
        )
    if all(size == padded for size in sizes.values()):
        # No token sharding: every rank holds the whole batch.
        return step.shards[layer_id][ranks[0]][:real], False, padded > real
    shard_n = (padded + tp_size - 1) // tp_size
    unexpected = {rank: size for rank, size in sizes.items() if size != shard_n}
    if unexpected:
        raise _HarnessError(
            f"forward {step.index} layer {layer_id}: capture was fed "
            f"{sizes} rows per TP rank for a {padded}-token forward at "
            f"tp_size={tp_size}; expected {padded} on every rank (no sharding) "
            f"or {shard_n} (TP shard)"
        )
    gathered = np.concatenate([step.shards[layer_id][rank] for rank in ranks], axis=0)
    return gathered[:real], True, gathered.shape[0] > real


def _build_trace(records: list[_Record], tp_size: int) -> _Trace:
    steps = _group_steps(records, tp_size)
    publish_rank = min(steps[0].shards[steps[0].layer_ids[0]])
    reference: dict[int, list[np.ndarray]] = {}
    published: dict[int, list[np.ndarray]] = {}
    bounds: list[tuple[int, int]] = []
    sharded: list[bool] = []
    trimmed: list[bool] = []
    gathers: list[int] = []
    cursor = 0
    for step in steps:
        step_sharded = False
        step_trimmed = False
        for layer_id in step.layer_ids:
            rows, was_sharded, was_trimmed = _layer_reference(step, layer_id, tp_size)
            step_sharded = step_sharded or was_sharded
            step_trimmed = step_trimmed or was_trimmed
            reference.setdefault(layer_id, []).append(rows)
            buffer = step.buffers.get(layer_id, {}).get(publish_rank)
            if buffer is not None:
                published.setdefault(layer_id, []).append(buffer)
        bounds.append((cursor, cursor + step.num_real))
        cursor += step.num_real
        sharded.append(step_sharded)
        trimmed.append(step_trimmed)
        gathers.append(max(step.gathers.values(), default=0))
    return _Trace(
        steps=steps,
        bounds=bounds,
        sharded=sharded,
        trimmed=trimmed,
        gathers=gathers,
        reference={
            layer: np.concatenate(chunks, axis=0) for layer, chunks in reference.items()
        },
        published={
            layer: np.concatenate(chunks, axis=0)
            for layer, chunks in published.items()
            if len(chunks) == len(steps)
        },
        publish_rank=publish_rank,
    )


def _summary(label: str, result: _Result, trace: _Trace) -> str:
    per_step = ", ".join(
        f"#{step.index}: {step.num_real} tokens / "
        f"{step.shard_sizes(step.first_layer)} rows per rank"
        for step in trace.steps
    )
    return (
        f"[{label}] returned rows={result.routed.shape[0]} "
        f"(prompt {result.prompt_tokens} + generated {result.generated} - 1), "
        f"reference rows={trace.total_rows}, captured layers={len(trace.layers)}, "
        f"publishing rank={trace.publish_rank}, "
        f"sharded={trace.sharded}, sp-padding trimmed={trace.trimmed}, "
        f"capture gathers per forward={trace.gathers}; steps: {per_step}"
    )


def _mismatch_examples(
    got: np.ndarray, expected: np.ndarray, start: int, layer_id: int, limit: int = 5
) -> list[str]:
    rows = np.flatnonzero((got != expected).any(axis=1))
    examples = []
    for offset in rows[:limit]:
        examples.append(
            f"  token {start + int(offset)} layer {layer_id}: got "
            f"{np.array2string(got[offset], max_line_width=200)} expected "
            f"{np.array2string(expected[offset], max_line_width=200)}"
        )
    if rows.size > limit:
        examples.append(f"  ... and {rows.size - limit} more rows")
    return examples


def _check_capture(label: str, result: _Result, tp_size: int) -> _Trace:
    """Assert the returned routes equal the raw-shard reference, end to end."""
    trace = _build_trace(result.records, tp_size)
    print(_summary(label, result, trace))
    _warn_if_routing_is_degenerate(label, trace)
    problems: list[str] = []
    if result.routed.shape[0] != result.expected_rows:
        problems.append(
            f"{label}: response returned {result.routed.shape[0]} routed-expert "
            f"rows, expected prompt + generated - 1 = {result.expected_rows}"
        )
    if trace.total_rows != result.expected_rows:
        problems.append(
            f"{label}: the capture covered {trace.total_rows} rows but the "
            f"response returned {result.expected_rows}. Either a forward was "
            "recorded that is not part of this request (replay or warmup step) "
            "or a forward is missing"
        )
    if not problems:
        for layer_id in trace.layers:
            expected_layer = trace.reference[layer_id]
            for step, (start, end) in zip(trace.steps, trace.bounds):
                got = result.routed[start:end, layer_id]
                expected = expected_layer[start:end]
                if got.shape != expected.shape:
                    problems.append(
                        f"{label}: forward {step.index} layer {layer_id}: "
                        f"response rows {got.shape} != reference {expected.shape}"
                    )
                    continue
                if not np.array_equal(got, expected):
                    problems.extend(
                        [
                            f"{label}: forward {step.index} layer {layer_id}: "
                            f"{int((got != expected).any(axis=1).sum())} of "
                            f"{got.shape[0]} rows differ from the raw-shard "
                            f"reference",
                            *_mismatch_examples(got, expected, start, layer_id),
                        ]
                    )
            published = trace.published.get(layer_id)
            if published is None:
                continue
            expected_layer = trace.reference[layer_id]
            if published.shape != expected_layer.shape:
                problems.append(
                    f"{label}: layer {layer_id}: TP rank {trace.publish_rank}'s "
                    f"capture buffer holds {published.shape[0]} rows for a "
                    f"{expected_layer.shape[0]}-row batch; the capture wrote a "
                    "partial batch (capture, not the auxiliary-output path, is "
                    "wrong)"
                )
            elif not np.array_equal(published, expected_layer):
                problems.extend(
                    [
                        f"{label}: layer {layer_id}: TP rank "
                        f"{trace.publish_rank}'s capture buffer does not hold "
                        "the whole batch (capture, not the auxiliary-output "
                        "path, is wrong)",
                        *_mismatch_examples(
                            published, expected_layer, 0, layer_id, limit=3
                        ),
                    ]
                )
    if problems:
        detail = "\n".join(problems)
        pytest.fail(f"{detail}\nprobe notes:\n{_probe_notes_text()}")
    return trace

def _warn_if_routing_is_degenerate(label: str, trace: _Trace) -> None:
    """Flag weights whose routing cannot show a stale row.

    Dummy ("dummy" load format) or degenerate weights can route every token to
    the same experts; then a stale row is indistinguishable from a fresh one by
    value. The capture-buffer shape check still catches a partial write, but the
    value comparison stops being evidence, so the run has to say so.
    """
    flat = [
        layer_id
        for layer_id in trace.layers
        if len(np.unique(trace.reference[layer_id], axis=0)) <= 1
    ]
    if flat:
        shown = ", ".join(str(layer_id) for layer_id in flat[:8])
        more = f" (+{len(flat) - 8} more)" if len(flat) > 8 else ""
        print(
            f"[{label}] WARNING: every token routed to the same experts in "
            f"{len(flat)} of {len(trace.layers)} captured layers [{shown}{more}]; "
            "stale rows cannot be told apart by value with these weights, so "
            "only the capture-buffer shape check discriminates here"
        )


def _compare_rows(
    label: str, got: np.ndarray, expected: np.ndarray, note: str = ""

    assert got.shape == expected.shape, (

    if np.array_equal(got, expected):
        return
    differing = (got != expected).any(axis=2)
    examples = []
    for row, layer in zip(*np.nonzero(differing)):  # noqa: B905 - numpy arrays

        )
        if len(examples) >= 5:
            break
    pytest.fail(
        f"{label}: {int(differing.sum())} (token, layer) pairs differ from the "
        f"reference{note}\n" + "\n".join(examples)
    )
```

## Model end-to-end reproducer for the DP=1 sharded capture (2/2): the validation probe

`RoutedExpertsCapturer.capture` receives only this rank's rows, so no single rank holds the whole batch: the reference has to be the raw per-rank shards. This probe records, for every capture call and every TP rank, the tensor the capture path is fed (read *before* the capture logic can gather it), the rows the call leaves in that rank's buffer, whether the call performed a TP collective, and the forward token count before model-level SP (`ForwardContext.num_tokens`, falling back to `batch_descriptor.num_tokens` so it also works on the base revision).

It changes nothing on disk: the test puts a generated shim on `PYTHONPATH` and starts the server with `--worker-extension-cls vllm_re_capture_probe.ProbeWorkerExtension`, so vLLM resolves the class - importing this module - inside every worker before the model is built. Dumping is gated on a `current_tag` file that the test rewrites per request, so warmup, profiling and graph-capture forwards are never recorded.

It can also force a capture-input layout, which is how the DP=1 branches can be exercised on a host where no `MEGA_MOE_BACKENDS` backend binds (`get_deep_gemm_mega_moe_backend` requires SM100; `FlashInferMoeEpBackendSpec.supports_current_device` accepts only (10,0)/(10,3)):

* `shard` - slice the batch into `ceil(T/tp)`-row TP shards, padded the way `sp_reduce_scatter` pads, so the real capture code and a real TP all-gather run on the layout the bug is about;
* `already-gathered` - hand over the complete SP-padded batch;
* `unexpected` - hand over a row count that matches no branch, to check that the capture fails closed.

```python# SPDX-License-Identifier: Apache-2.0
# SPDX-FileCopyrightText: Copyright contributors to the vLLM project
"""Validation-only instrumentation for the routed-experts capture reproducer.

The probe records, for every ``RoutedExpertsCapturer.capture`` call and every
TP rank: the tensor the capture path is fed (this rank's shard, read *before*
the capture logic can gather it), the rows the call leaves in this rank's
capture buffer, whether the call performed a TP collective, and the forward
token count before model-level sequence parallel (SP).

That is the only way to get a per-rank reference for a capture that is
supposed to write a whole batch from TP shards: a single batch's routing is
split across ranks, so no single rank holds the answer, and comparing against
a differently sharded run (TP=1) is not exact because the router's floating
point reduction order changes with the shard shape.

This module changes nothing on disk. The reproducer puts a generated shim
directory on ``PYTHONPATH`` and starts the server with
``--worker-extension-cls vllm_re_capture_probe.ProbeWorkerExtension``, so vLLM
resolves the extension class - importing this module - inside every worker
process before the model is built. See
``tests/models/deepseek_v41_routed_experts_capture_e2e.py``.

Dumping is off unless ``VLLM_ROUTED_EXPERTS_DUMP_DIR`` is set *and* that
directory holds a ``current_tag`` file. The reproducer rewrites the tag before
each request, so warmup, profiling and CUDA-graph capture steps are never
recorded.

Record layout, appended as
``<dump dir>/<tag>.rank<tp_rank>.<pid>.bin``::

    <4s magic><q seq><i tp_rank><i dp_rank><i layer_id><i num_tokens>
    <i num_padding><i n_rows><i topk><i gathers><i buffer_rows>
    <int32 ids[n_rows, topk]><int32 buffer[buffer_rows, topk]>

``num_tokens`` is the forward token count before model-level SP, including
batch padding, or ``-1`` when the producer does not report one; ``num_padding``
counts trailing padding rows within it. ``ids`` is what the capture path was
fed on this rank and ``buffer`` is ``device_buffer[:buffer_rows, layer_id]``
read right after the call. Files are appended and flushed per record, so a
crashed run still leaves usable dumps.
"""

from __future__ import annotations

import os
import struct
import time
from pathlib import Path
from typing import Any

ENV_DUMP_DIR = "VLLM_ROUTED_EXPERTS_DUMP_DIR"
ENV_INJECT = "VLLM_ROUTED_EXPERTS_E2E_INJECT"
TAG_FILENAME = "current_tag"
NOTES_FILENAME = "probe_notes.log"

# Layouts the capture path can be fed, used to force a branch E2E:
#   "shard": slice the batch into TP shards (with the ceil-div padding
#     sp_reduce_scatter applies), so a model that would hand over the whole
#     batch exercises the DP=1 sharded branch. This is how the sharded layout
#     can be reached on GPUs where no MegaMoE backend can bind (all three are
#     SM100/SM103 gated), with the real capture code and a real TP gather.
#   "already-gathered": gather the shard first, so the capture sees the
#     complete SP-padded batch and must trim it without gathering again;
#   "unexpected": feed a row count that matches no branch, so the capture
#     must fail closed instead of writing a partial batch.
INJECT_MODES = ("shard", "already-gathered", "unexpected")

_MAGIC = b"RXD1"
_HEADER = struct.Struct("<4sqiiiiiiiii")
_INSTALLED_ATTR = "_routed_experts_capture_probe_installed"


class ProbeWorkerExtension:
    """Worker extension whose import installs the probe.

    ``--worker-extension-cls`` makes vLLM resolve this class inside every
    worker process before the model is built, which imports this module. The
    body is intentionally empty: only the import has an effect.
    """


def install() -> bool:
    """Wrap ``RoutedExpertsCapturer.capture`` with the dumping recorder.

    Returns:
        True if the wrapper is installed, False if the probe is disabled or
        vLLM's capture module could not be patched.

    """
    dump_dir = os.environ.get(ENV_DUMP_DIR)
    if not dump_dir:
        return False
    directory = Path(dump_dir)
    try:
        from vllm.model_executor.layers.fused_moe import routed_experts_capturer
    except Exception as exc:  # pragma: no cover - defensive
        _note(directory, f"import failed: {exc!r}")
        return False
    capturer_cls = getattr(routed_experts_capturer, "RoutedExpertsCapturer", None)
    if capturer_cls is None:  # pragma: no cover - defensive
        _note(directory, "RoutedExpertsCapturer not found")
        return False
    if getattr(capturer_cls, _INSTALLED_ATTR, False):
        return True
    setattr(capturer_cls, _INSTALLED_ATTR, True)

    recorder = _Recorder(directory, routed_experts_capturer)
    original = capturer_cls.capture

    def capture(self: Any, layer_id: int, topk_ids: Any) -> None:
        recorder.capture(original, self, layer_id, topk_ids)

    capturer_cls.capture = capture
    _note(directory, f"installed pid={os.getpid()}")
    return True


class _Recorder:
    """Per-process recorder; one append-only file per (tag, TP rank)."""

    def __init__(self, dump_dir: Path, module: Any) -> None:
        self._dir = dump_dir
        self._module = module
        self._seq = 0
        self._tp_rank: int | None = None
        # Error notes are capped so a broken dump cannot flood the log; layout
        # notes are emitted once per (tag, TP rank), so the reproducer can
        # always confirm which layout a request was fed.
        self._error_notes = 0
        self._layout_noted: set[tuple[str, int]] = set()

    def capture(
        self, original: Any, capturer: Any, layer_id: int, topk_ids: Any
    ) -> None:
        tag = _read_tag(self._dir)
        if tag is None:
            original(capturer, layer_id, topk_ids)
            return

        module = self._module
        ids = context = None
        try:
            ids = _to_int32(topk_ids)
            ctx = module.get_forward_context()
            num_tokens = _forward_token_count(ctx)
            num_padding = _padding_rows(ctx, num_tokens)
            context = (num_tokens, num_padding, self._rank(capturer))
        except Exception as exc:
            self._note_error(f"capture metadata failed: {exc!r}")

        if context is not None:
            try:
                topk_ids = self._inject(tag, capturer, topk_ids, context[0])
            except Exception as exc:
                self._note_error(f"injection failed: {exc!r}")

        gathers = 0
        real_get_tp_group = module.get_tp_group

        def counting_get_tp_group() -> Any:
            nonlocal gathers
            gathers += 1
            return real_get_tp_group()

        module.get_tp_group = counting_get_tp_group
        try:
            original(capturer, layer_id, topk_ids)
        except BaseException as exc:
            self._note_error(f"capture raised {type(exc).__name__}: {exc}")
            raise
        finally:
            module.get_tp_group = real_get_tp_group

        if ids is None or context is None:
            return
        try:
            num_tokens, num_padding, tp_rank = context
            rows = _buffer_rows(capturer, layer_id, num_tokens, num_padding)
            self._write(
                tag,
                tp_rank,
                capturer,
                layer_id,
                num_tokens,
                num_padding,
                gathers,
                ids,
                rows,
            )
        except Exception as exc:
            self._note_error(f"dump failed: {exc!r}")

    def _inject(self, tag: str, capturer: Any, topk_ids: Any, num_tokens: int) -> Any:
        """Rewrite the capture input to force a layout branch (test only).

        The dump always keeps the rank's original tensor, so the reference the
        reproducer rebuilds is unaffected by the injection.
        """
        mode = os.environ.get(ENV_INJECT)
        if not mode or num_tokens <= 0:
            return topk_ids
        tp_size = max(int(getattr(capturer, "tp_size", 1)), 1)
        shard_n = (num_tokens + tp_size - 1) // tp_size
        rows = int(topk_ids.shape[0])
        rank = max(self._rank(capturer), 0)
        if mode == "shard":
            if rows != num_tokens:
                # Already a shard (the real model-level SP path): leave it.
                self._note_layout(
                    tag,
                    rank,
                    f"{tag}: shard injection skipped, capture already has "
                    f"{rows} rows for a {num_tokens}-token forward",
                )
                return topk_ids
            start = min(rank * shard_n, max(rows - 1, 0))
            local = topk_ids[start : start + shard_n]
            if local.shape[0] < shard_n:
                # sp_reduce_scatter pads with ceil-div, so every rank holds
                # exactly shard_n rows; the extra ones are trimmed downstream.
                pad = topk_ids[: shard_n - local.shape[0]]
                local = _concat(local, pad)
            self._note_layout(
                tag,
                rank,
                f"{tag}: injected shard layout: {rows} rows -> {local.shape[0]} "
                f"rows on tp_rank {rank} for a {num_tokens}-token forward",
            )
            return local.contiguous()
        if mode == "already-gathered":
            if rows == num_tokens and tp_size > 1:
                # Unsharded input (emulated layout): shard it the way the model
                # would, then gather back into one padded batch.
                start = min(rank * shard_n, max(rows - 1, 0))
                local = topk_ids[start : start + shard_n]
                if local.shape[0] < shard_n:
                    pad = topk_ids[: shard_n - local.shape[0]]
                    local = _concat(local, pad)
            else:
                local = topk_ids
            gathered = self._module.get_tp_group().all_gather(local.contiguous(), dim=0)
            self._note_layout(
                tag,
                rank,
                f"{tag}: injected already-gathered batch: {rows} rows -> "
                f"{gathered.shape[0]} rows for a {num_tokens}-token forward",
            )
            return gathered
        if mode == "unexpected":
            # A row count that matches none of the capturer's layouts, equal on
            # every rank so the failure is not a rank disagreement.
            forbidden = {num_tokens, shard_n, shard_n * tp_size}
            count = 1
            while count in forbidden:
                count += 1
            if rows >= count:
                injected = topk_ids[:count]
            else:
                repeats = (count + rows - 1) // rows
                injected = topk_ids.repeat(repeats, 1)[:count]
            self._note_layout(
                tag,
                rank,
                f"{tag}: injected unexpected batch: {rows} rows -> {count} rows "
                f"for a {num_tokens}-token forward at tp_size={tp_size}",
            )
            return injected.contiguous()
        raise ValueError(f"unknown {ENV_INJECT}={mode!r}")

    def _rank(self, capturer: Any) -> int:
        if self._tp_rank is None:
            try:
                from vllm.distributed.parallel_state import (
                    get_tensor_model_parallel_rank,
                )

                self._tp_rank = int(get_tensor_model_parallel_rank())
            except Exception:
                self._tp_rank = None
        if self._tp_rank is not None and self._tp_rank >= 0:
            return self._tp_rank
        # Encode the DP rank so a rank-less run still writes distinct files.
        return -1 - int(getattr(capturer, "dp_rank", 0))

    def _write(
        self,
        tag: str,
        tp_rank: int,
        capturer: Any,
        layer_id: int,
        num_tokens: int,
        num_padding: int,
        gathers: int,
        ids: Any,
        rows: Any,
    ) -> None:
        self._seq += 1
        path = self._dir / f"{tag}.rank{tp_rank}.{os.getpid()}.bin"
        with open(path, "ab") as handle:
            handle.write(
                _HEADER.pack(
                    _MAGIC,
                    self._seq,
                    tp_rank,
                    int(getattr(capturer, "dp_rank", 0)),
                    layer_id,
                    num_tokens,
                    num_padding,
                    int(ids.shape[0]),
                    int(ids.shape[1]),
                    gathers,
                    int(rows.shape[0]),
                )
            )
            handle.write(ids.tobytes())
            handle.write(rows.tobytes())

    def _note_layout(self, tag: str, tp_rank: int, message: str) -> None:
        """One layout note per (tag, TP rank): enough for the reproducer to
        confirm which layout a request was fed, without one line per layer."""
        key = (tag, tp_rank)
        if key in self._layout_noted:
            return
        self._layout_noted.add(key)
        _note(self._dir, message)

    def _note_error(self, message: str) -> None:
        # Keep a broken dump from flooding the log with one line per layer.
        if self._error_notes < 8:
            self._error_notes += 1
            _note(self._dir, message)


def _read_tag(dump_dir: Path) -> str | None:
    try:
        tag = (dump_dir / TAG_FILENAME).read_text().strip()
    except OSError:
        return None
    return tag or None


def _forward_token_count(ctx: Any) -> int:
    """Forward token count before model-level SP, including batch padding."""
    num_tokens = getattr(ctx, "num_tokens", None)
    if num_tokens is None:
        descriptor = getattr(ctx, "batch_descriptor", None)
        num_tokens = getattr(descriptor, "num_tokens", None)
    return -1 if num_tokens is None else int(num_tokens)


def _padding_rows(ctx: Any, num_tokens: int) -> int:
    is_padding = getattr(ctx, "is_padding", None)
    if is_padding is None or num_tokens < 0:
        return 0
    try:
        return int(is_padding[:num_tokens].sum().item())
    except Exception:  # pragma: no cover - defensive
        return 0


def _buffer_rows(
    capturer: Any, layer_id: int, num_tokens: int, num_padding: int
) -> Any:
    import numpy as np
    import torch

    buffer = capturer.device_buffer
    if num_tokens < 0 or layer_id >= buffer.shape[1]:
        return np.zeros((0, buffer.shape[2]), dtype=np.int32)
    wanted = max(num_tokens - max(num_padding, 0), 0)
    rows = min(wanted, buffer.shape[0])
    return buffer[:rows, layer_id].detach().to("cpu", torch.int32).numpy()


def _to_int32(tensor: Any) -> Any:
    import numpy as np
    import torch

    return np.ascontiguousarray(tensor.detach().to("cpu", torch.int32).numpy())


def _concat(first: Any, second: Any) -> Any:
    import torch

    return torch.cat((first, second), dim=0)


def _note(dump_dir: Path, message: str) -> None:
    try:
        dump_dir.mkdir(parents=True, exist_ok=True)
        stamp = time.strftime("%Y-%m-%dT%H:%M:%S")
        with open(dump_dir / NOTES_FILENAME, "a") as handle:
            handle.write(f"{stamp} {message}\n")
    except OSError:  # pragma: no cover - defensive
        pass
```

```python
def sp_reduce_scatter(x):                     # vllm/models/common/ops/sequence_parallel.py
    tp_size = get_tensor_model_parallel_world_size()

```
