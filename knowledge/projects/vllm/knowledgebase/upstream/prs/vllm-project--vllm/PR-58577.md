# fix(kv-transfer): configurable timeout and retry for Mooncake bootstrap query

[Upstream PR](https://github.com/vllm-project/vllm/pull/58577) · state: closed · merged: False

## Original PR description

Fixes #58543

This PR addresses the hardcoded 5s timeout on the Mooncake decode-side bootstrap query, which causes terminal failures during long producer-side cold starts (e.g. Triton JIT compilations).

Changes:
1. Adds `VLLM_MOONCAKE_BOOTSTRAP_QUERY_TIMEOUT` env var (default: 30s) to `vllm.envs`.
2. Implements a bounded retry mechanism with exponential backoff (up to 3 retries, 2s backoff) on the `GET /query` endpoint in `_connect_to_prefiller_bootstrap` to handle transient unresponsiveness.
