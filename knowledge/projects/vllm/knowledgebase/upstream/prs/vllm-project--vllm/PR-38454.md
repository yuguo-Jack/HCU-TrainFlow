# [ROCm][Test] Add hybrid block size and RDNA4 backend selection tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/38454) · state: open · merged: False

## Original PR description

## Summary

Adds 7 new tests to `tests/v1/attention/test_rocm_attention_backends_selection.py` covering two previously untested ROCm code paths:

### V1 — Hybrid model block size regression guard (Issue #36994)
- `test_hybrid_model_block_sizes_accepted`: Parametrized over block sizes 16, 32, 784, 1056, 544, 512 (real Qwen3.5/Qwen3-Next sizes). Verifies `RocmPlatform.get_attn_backend_cls()` selects `ROCM_ATTN` without raising.
- `test_supports_block_size_rocm_attn`: Unit test for `RocmAttentionBackend.supports_block_size()` — asserts multiples of 16 pass, non-multiples rejected.

### V2 — RDNA4/gfx1151 backend selection (zero coverage before)
- New `mock_on_gfx1x` fixture for simulating RDNA3/RDNA4 devices.
- `test_gfx1x_rdna_attention_backend_selection`: Parametrized over 4 cases (default, TRITON_ATTN, AITER+fallback, ROCM_ATTN).
- `test_aiter_fa_rejected_on_gfx1x`: Asserts ROCM_AITER_FA raises ValueError on non-mi3xx hardware.
- `test_gfx1x_with_triton_flash_attn_enabled`: Verifies flash_attn_triton only affects ViT path, not main decode.

**Test-only change. Zero production code modified.**
