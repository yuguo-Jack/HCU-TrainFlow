## Summary

Adds `tests/reasoning/test_step3_reasoning_parser.py` — the `Step3ReasoningParser` previously had zero test coverage.

- 14 parametrised cases covering streaming and non-streaming extraction across: simple reasoning, complete reasoning (no content), no content (all reasoning), multiple lines, shortest output, `<think>` prefix with no end token, and empty string.
- 3 focused tests:
  - `test_think_prefix_not_stripped` — documents that Step3 keeps `<think>` in the reasoning string (unlike DeepSeekR1, which strips it).
  - `test_think_end_token_required` — verifies the constructor raises `RuntimeError` when the tokenizer lacks `</think>`.
  - `test_is_reasoning_end_streaming` — verifies the streaming end-token check uses only the current delta IDs.

Uses `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B` tokenizer as a lightweight stand-in; both parsers share the `</think>` special token.
