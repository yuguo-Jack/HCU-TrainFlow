# [Bugfix][Spec Decode] Generalize sliding-window draft AOT safeguard

[Upstream PR](https://github.com/vllm-project/vllm/pull/64404) · state: open · merged: False

## Original PR description

Co-authored-by: @zhentaocc (Zhentao Chen), @whatghost (Yuyang Gao) and @zhangnju (Ning Zhang) from AMD

## Overview

Move the existing DFlash sliding-window AOT-schedule safeguard into
`DraftModelSpeculator`, so every sliding-window drafter—including EAGLE-4
draft prefill and chain decode—uses metadata consistent with its own KV
geometry.

## Claims

- Disable FlashAttention's model-global AOT schedule for sliding-window draft
  attention groups.
- Apply the safeguard to both runner-owned draft-prefill builders and
  drafter-owned chain builders.
- Leave target-only groups and full-attention drafters unchanged.
- Remove the now-redundant DFlash-only implementation.

## Details

FlashAttention's AOT split schedule is inferred from model-wide attention
geometry. A target and its external drafter can use different sliding-window
layouts. DFlash already disabled the schedule for its own draft builders, but
other `DraftModelSpeculator` users did not, and draft prefill can reuse the
runner's separate metadata builders.

The shared helper filters by the actual draft layer names and by the draft KV
cache spec's sliding window. It changes only builders exposing an enabled
`aot_schedule` attribute.
