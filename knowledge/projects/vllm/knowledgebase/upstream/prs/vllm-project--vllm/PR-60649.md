# fix(benchmarks): support boolean values in sweep plot filters

[Upstream PR](https://github.com/vllm-project/vllm/pull/60649) · state: open · merged: False

## Original PR description

PlotEqualTo and PlotNotEqualTo previously fell back to raw strings when float parsing failed, causing "true" and "false" filter strings to never match boolean DataFrame columns. This resolves boolean targets to bool when comparing against boolean-valued series (including nullable series with missing values), while preserving literal comparisons for string columns and existing float/inf behavior.

Fixes #60629
