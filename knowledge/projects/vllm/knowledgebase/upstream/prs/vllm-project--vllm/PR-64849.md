## Overview

Add `tests/utils_/test_math_utils.py` covering `prev_power_of_2`, `largest_power_of_2_divisor`, and `round_up_to`, which previously had no tests anywhere in `tests/`.

## Claims

- 32 boundary cases for three bit-twiddling helpers whose off-by-one errors propagate into block-size and alignment math.
- CPU-only, no GPU, no downloads.

## Validation

- `pytest tests/utils_/test_math_utils.py -v` locally: 32 passed.
- `ruff check` and `ruff format --check` clean.
- Also verified via the standard path (real `vllm` import chain and repo conftest, no stubbing, no `--noconftest`): 32 passed.

## Details

- Cases cover exact powers, values between powers, non-positive inputs, exact matches, gaps, and the above-all-values `None` case for `round_up_to`.
