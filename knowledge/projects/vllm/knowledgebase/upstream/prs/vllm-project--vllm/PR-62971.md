# [Doc] DeepSeek-V4.1-Flash: fix TP4 c32 max-num-seqs in the B200 AgentX guide

[Upstream PR](https://github.com/vllm-project/vllm/pull/62971) · state: closed · merged: True

## Original PR description

## Overview

Follow-up to #62541 and #62954. The B200 AgentX guide for DeepSeek-V4.1-Flash lists the TP4 c32 point with `--max-num-seqs 64`, but [SemiAnalysisAI/InferenceX#3837](https://github.com/SemiAnalysisAI/InferenceX/pull/3837) runs it with 128 (`max-num-seqs: [8, 8, 16, 32, 128, 256]` for c1, 4, 8, 16, 32, 128). This changes that one table cell from 64 to 128.

The router paragraph this PR originally added is already covered by #62954, so it is dropped.

## Validation

- Guide text only; the TP4 per-concurrency values are not rendered by the command builder.
- `node scripts/validate-source.mjs --source vllm --dir <this checkout>/recipes` passes.
