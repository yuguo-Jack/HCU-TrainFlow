# [Build] Find compatible published wheels for precompiled installs

[Upstream PR](https://github.com/vllm-project/vllm/pull/58871) · state: closed · merged: True

## Original PR description

## Purpose

Addresses the gap where recent commits on vLLM main don't exist in the wheels index in the 1-2 hours it takes to populate them. When VLLM_USE_PRECOMPILED is enabled and the VLLM_PRECOMPILED_WHEEL_LOCATION is not a path, this logic will walk backwards through 20 commits in git history to find a commit base that does exist on the vLLM wheels index. It will then attempt to identify if compilation affected source source (`csrc/`, `cmake/`, `CMakeLists.txt`, `setup.py`, `pyproject.toml`, `vllm/_custom_ops.py`, and `rust/`) has diverged since the that selected precompiled commit. If changes do exist an editable install may or may not cause a failure. For example metadata changes to `pyproject.toml` wont do anything, or comments in `csrc`, but it could just as easily cause install failure or succeed at buildings but fail at runtime. To combat this it will warn the use of said precompiled wheel
