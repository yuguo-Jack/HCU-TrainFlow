# [Feature][Frontend] Add periodic usage updates to Anthropic streaming

[Upstream PR](https://github.com/vllm-project/vllm/pull/59444) · state: open · merged: False

## Original PR description

## Purpose
Anthropic's `/v1/messages` API sends one or more `message_delta` events (https://platform.claude.com/docs/en/build-with-claude/streaming#event-types) for requests where `stream=true`. These events may show cumulative token counts in the usage field of the event.
vLLM only reports a single usage event once the entire message has been sent out.

This PR adds the option to send periodic/continuous usage update events similar to what is already supported on the `/v1/chat/completions` endpoint for streaming requests.
The interval at which usage events are send can be configured using the newly added `VLLM_ANTHROPIC_USAGE_STREAM_INTERVAL` environment variable.
By default, it is disabled.
