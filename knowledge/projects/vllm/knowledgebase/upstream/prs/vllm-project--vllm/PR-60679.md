# [CI][AMD] Gate Aiter MHA FA on dtype

[Upstream PR](https://github.com/vllm-project/vllm/pull/60679) · state: closed · merged: True

## Original PR description

## Overview

AMD CI will soon switch to Aiter on by default. Gating Aiter MHA FA on supported dtypes passes previously failing tests.

## Claims

Fixes failures in the testgroups
+ (MI300) Entrypoints Integration (Multimodal)
+ (MI300) Multimodal Models (Extended Pooling)
+ (MI355 DPX) Entrypoints Integration (Multimodal)
+ (MI355 DPX) Multimodal Models (Extended Pooling)

## Validation

Locally succesful pytest runs on the affected testgroups.

Buildkite CI run based on this PR with `VLLM_ROCM_USE_AITER=1`, https://buildkite.com/vllm/amd-ci/builds/14347/list, shows the above 4 test groups succeed. The test groups fail in the reference Aiter on CI run, https://buildkite.com/vllm/amd-ci/builds/13642/list, that does not include this PR.

## Details

Without the dtype gate, the server crashes on startup during the ViT/audio encoder's attention call with:

```
NotImplementedError: Unsupported dtype for MHA
```
