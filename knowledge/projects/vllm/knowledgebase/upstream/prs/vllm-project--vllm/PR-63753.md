# [Fast Start] Seed compiled caches through the D2D transport

[Upstream PR](https://github.com/vllm-project/vllm/pull/63753) · state: open · merged: False

## Original PR description

## Overview

This PR extends daemon-to-daemon warmup cache seeding to FlashInfer compiled artifacts.

## Claims

- Reuses the existing D2D `SeedTransport` control plane.
- Transfers FlashInfer cubins and JIT compilation artifacts through Mooncake.
- Allows a target daemon to install compatible artifacts before model construction, avoiding repeated JIT compilation.

## Validation

- End-to-end validation on NVIDIA B300 with a K3-like MoE model.
- Cold daemon startup: approximately 337 seconds.
- Daemon startup with transferred compiled artifacts: approximately 34 seconds.
- Target logs confirmed successful compiled-cache adoption and no repeated JIT module builds.
- Both configurations successfully mapped 465 tensors through the zero-copy IPC path.

## Details

The source daemon creates a versioned and checksummed cache bundle. The target validates and installs the bundle atomically before loading the model.

The existing D2D control plane exchanges the manifest, while Mooncake carries the compiled-cache payload using the selected TCP or RDMA protocol. The target falls back to local compilation when the remote cache is unavailable or incompatible.

Autotune artifact reuse is handled by the preceding PR; this PR focuses on compiled runtime artifacts.
