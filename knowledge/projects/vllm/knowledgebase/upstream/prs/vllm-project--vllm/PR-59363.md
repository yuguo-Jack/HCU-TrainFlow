# [Test][Metrics] Cover MRV2 CUDA graph runtime statistics

[Upstream PR](https://github.com/vllm-project/vllm/pull/59363) · state: open · merged: False

## Original PR description

## Purpose

Add regression coverage for MRV2 CUDA graph runtime statistics reaching the frontend logging table, following the fix in #52358 and the missing coverage noted in #52728.

The test runs a short generation through `AsyncLLM`, calls `do_log_stats()` directly, and checks for a populated FULL decode row when metrics are enabled. It also checks that disabling metrics suppresses the table. It extends the existing metrics suite and GPU CI job; no production code changes.

Issue and PR searches found no overlapping regression test. This covers the existing logging table, separate from the Prometheus counter proposed in #37576.

## Test Plan

```sh
VLLM_WORKER_MULTIPROC_METHOD=spawn .venv/bin/python -m pytest \
  tests/v1/metrics/test_engine_logger_apis.py -v -s
```

To check that the test catches missing forwarding, temporarily set `cudagraph_stats=None` on both MRV2 output paths, run the enabled case, then restore the code and rerun.
