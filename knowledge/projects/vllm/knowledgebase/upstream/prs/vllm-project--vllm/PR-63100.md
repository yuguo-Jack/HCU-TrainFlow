# [Bugfix][Compilation] Align speculative graph sizes with query and TP widths

[Upstream PR](https://github.com/vllm-project/vllm/pull/63100) · state: open · merged: False

## Original PR description

## Purpose

With sequence parallelism enabled, speculative graph sizes must be divisible
by both `uniform_decode_query_len` and the tensor-parallel width. The current
`max()` rejects valid coprime combinations: a query width of 5 with TP2 or TP4
raises `ValueError`, although common multiples 10 and 20 exist.

Use `math.lcm()` and retain the existing rounding and size-limit behavior.
The regression covers coprime widths, divisible widths, and disabled sequence
parallelism without silently changing `enable_sp`.

This is a direct fix for the tested `releases/v0.26.0` baseline
`568afb3a13806beb53bb2e6bd518269357b237c0`.
