# [Deepseek-V4-P2-03] Decode index kernels

[Upstream PR](https://github.com/vllm-project/vllm/pull/60444) · state: open · merged: False

## Original PR description

## Overview

Add CUDA-only C4/C128 sparse decode index assembly to vLLM's existing stable `_C` extension. The two operators combine selected compressed-cache and sliding-window positions into ordered indices and valid lengths. This PR provides the primitive; it does not switch decode routing or add a shared library.

## Test

Built `_C_stable_libtorch` independently on H100. With that extension:

```bash
uv run --no-project python -m pytest --confcutdir=tests/kernels \
    tests/kernels/attention/test_flashmla_sparse.py::test_fused_decode_indices_match_existing_pipeline -q
```

**4 passed**, with exact index and length parity against the existing pipeline. Model-level evaluation requires an enabled runtime path and was not run for this primitive.

An **unpublished** current-`main` merge candidate also rebuilt `_C_stable_libtorch` on H20 and passed the same **4 cases**. These are not CI results on the current PR head.
