![critical](https://www.gstatic.com/codereviewagent/critical.svg)

The `sample` method returns an array of floats, as shown in the PR description's test. However, these samples are used for values like number of turns or tokens, which must be integers. Downstream code, such as `range(nturns)`, will fail with a `TypeError` if it receives a float.

The returned samples should be rounded and cast to integers, similar to how `LognormalDistribution` handles its samples.

```suggestion
    def sample(self, size: int = 1) -> np.ndarray:
        samples = np.random.exponential(self.scale, size=size)
        if self.max_val:
            samples = np.minimum(samples, self.max_val)
        return np.round(samples).astype(int)
```

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The `__init__` method is missing validation for the `scale` parameter. The scale for an exponential distribution must be a positive number. Additionally, the type hint for `scale` is missing. It's good practice to validate inputs and provide type hints for clarity and robustness. Other distributions in this file, like `LognormalDistribution`, already perform input validation.

```suggestion
    def __init__(self, scale: float, max_val: int | None = None) -> None:
        if scale <= 0:
            raise ValueError("Exponential distribution scale must be positive.")
        self.scale = scale
        self.max_val = max_val
```
