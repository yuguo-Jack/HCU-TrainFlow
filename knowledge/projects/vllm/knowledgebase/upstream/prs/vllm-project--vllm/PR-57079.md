# [ROCm][Opt] DeepSeek-V4 optimizations

[Upstream PR](https://github.com/vllm-project/vllm/pull/57079) · state: open · merged: False

## Original PR description

This supplies two optimizations.

Commit 377052e enables aiter Triton MXFP4 MoE on gfx942 (MI300/MI325). It is substantially faster than vllm's reference, but it is currently incorrectly gated for gfx950 only.

Commit ee22950 restores compiled forward_native in SiluAndMulWithClamp for ROCm and XPU (compilation is currently being inadvertently disabled). This supplies a modest performance boost to all models using this layer.

Decode throughput numbers (context 32768, bs=1, MI325, on top of PR #39168):

| config | base | +MoE | +both |
|---|---:|---:|---:|
| DS4-Pro TP4 | 22.39 | 46.49 | 50.19 (**2.24×**) |
| DS4-Flash TP1 | 32.72 | — | 64.43 (**1.97×**) |
