# [Model] Deprecate PaliGemma support.

[Upstream PR](https://github.com/vllm-project/vllm/pull/65409) · state: open · merged: False

## Original PR description



## Overview

- PaliGemma currently produces incorrect multimodal outputs in vLLM. vLLM applies causal attention to all tokens, while PaliGemma requires bidirectional attention for image tokens (PrefixLM).  #14565

Fixing it depends on FlexAttention soft-cap support, with no clear timeline #27938. Recommendation: deprecate the model family, or at minimum raise a hard error for multimodal use and document the limitation prominently.


- We need to optimize the logging for chunked prefill and prefix caching for the PrefixLM model.
