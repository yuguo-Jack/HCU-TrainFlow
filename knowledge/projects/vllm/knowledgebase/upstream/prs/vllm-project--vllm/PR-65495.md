# [CI][Test] Validate manual NVFP4 fusion in NVIDIA Qwen mixed-precision test

[Upstream PR](https://github.com/vllm-project/vllm/pull/65495) · state: closed · merged: True

## Original PR description



## Overview



The mixed-precision Qwen test expects four compiler-generated activation/quantization fusions—one per MLP—but the current NVIDIA Qwen implementation uses ```CompilationMode.NONE``` and performs these fusions
explicitly through maybe_fused_act_quant.

The test still reads the compiler’s fusion counter, which remains zero because the compiler pass does not run. Consequently, it fails with: Could not find 4 act_quant_fusion (found 0)

This is an outdated test expectation, rather than evidence of missing runtime fusion or a numerical mismatch. The original assertion reproduces on both Rubin and GB200.

This change updates the test to validate the current implementation:

* Require exactly one _C.silu_and_mul_nvfp4_quant operation in each of the four real MLPs, using inputs with 1 and 17 tokens.
* Verify that the downstream projection receives the expected packed QuantizedActivation, including its quantization key, dtype, and shapes.
* Compare each MLP’s output against the unfused activation/projection chain using the existing NVFP4 correctness criterion.
* Correct the fixture comment that incorrectly states the model has no manual fusion.

 The original model configuration and both test parameterizations remain. No production code or existing numerical tolerances are changed.

Following #51012 and #61107, NVIDIA Qwen uses explicit activation/quantization fusion with compilation disabled. This test retained its compiler-pass expectation, causing it to report zero matches despite runtime fusion executing correctly. Update it to validate the model’s actual fusion path.

## Validation



Validation on Rubin and GB200 produced 37 passed per GPU: two adapted E2E cases and 35 existing compiler, manual-fusion, and ModelOpt detection checks. A negative control disabling fusion in one layer correctly failed on both GPUs, confirming that the test detects missing fusion.
