# [Bugfix][Frontend] Keep Muse tool call arguments valid JSON for non-f…

[Upstream PR](https://github.com/vllm-project/vllm/pull/62412) · state: open · merged: False

## Original PR description

…inite values

_decode_value used json.loads without allow_nan=False, so NaN/Infinity and overflowed exponents like 1e999 (including nested in arrays/objects) were re-emitted as bare tokens that are not valid JSON (RFC 8259), giving strict clients an unparseable arguments string. Keep such values as the raw string. Targets the shared muse_tool_parser after the Glimmer parser refactor; adds a parametrized RFC8259 regression test.
