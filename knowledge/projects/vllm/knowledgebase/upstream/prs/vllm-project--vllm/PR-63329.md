# [Perf]Support Humming MXFP8 grouped output projection for DeepSeek V4/V4.1

[Upstream PR](https://github.com/vllm-project/vllm/pull/63329) · state: open · merged: False

## Original PR description



## Overview
Add Humming support for MXFP8 grouped output projection (WO-A) in DeepSeek V4 and V4.1. This enables `--linear-backend humming` to retain quantized WO-A weights and execute grouped GEMM with BF16/FP16 activations.



## Claims


- Add Humming to CUDA MXFP8 BMM kernel selection, after DeepGEMM and before emulation.
- Support multiple output groups per rank by packing each group as a Humming expert.
- Route DeepSeek V4’s Humming WO-A through its selected kernel and restrict V4.1’s fused WO-A path to the compatible DeepGEMM backend
