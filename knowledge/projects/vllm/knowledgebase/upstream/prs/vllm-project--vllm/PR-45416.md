## Summary
- Document that CUDA graphs consume extra GPU memory and can OOM during capture after successful model load.
- Show how to reduce CUDA graph memory by limiting `cudagraph_capture_sizes`.
- Add CLI examples for both `--cudagraph-capture-sizes` and `--compilation-config`.
