# [Transformers backend] Migrate ModernBERT embedding, reranker and token classification models

[Upstream PR](https://github.com/vllm-project/vllm/pull/59206) · state: open · merged: False

## Original PR description

## Overview

Migrate `ModernBertModel` (embedding), `ModernBertForSequenceClassification` (reranker) and `ModernBertForTokenClassification` to the Transformers modeling backend. This is the first encoder-only migration, chosen because ModernBERT needs neither `token_type_ids` nor RoBERTa's position offset, which the backend does not support yet.

`modernbert.py` keeps only the base model and its layers, which `ColBERTModernBertModel` and `ColModernVBert` still use.

## Claims

- All three ModernBERT architectures resolve to the Transformers backend and match HF (fp32) and their MTEB references.
- **Classifier heads** (`fusers/classifier.py`): a new `ClassifierFuser` traces the HF `For*Classification` model and adopts everything between the pooled hidden states and `classifier`/`score` (ModernBERT's `head`: dense, activation, norm). The head runs in the model dtype and only the classifier in `head_dtype`. This is most of the PR's ~250 new runtime lines. A generic trace replaces per-model head code, so later encoder migrations get their heads for free. #61349 (DistilBERT) currently adds a per-model head table instead.
- **Unmatched heads fail closed**: if no head matches, the classifier alone is used only when it reads the last hidden state (RoBERTa, decoders' `score`). Otherwise (DistilBERT, BERT's `pooler_output`, DeBERTa's `pooler`) loading raises instead of returning wrong scores.
- **Token classification**: new `TransformersForTokenClassification`.
- **`classifier_pooling`**: if the config sets it (`"cls"` or `"mean"`) and the user did not set a pooling type, it is used. `gte-reranker-modernbert-base` uses `"mean"`.
- **Bidirectional sliding window**: Transformers' window includes both boundaries, so encoder models get `sliding_window + 1`, as native `modernbert.py` already did.
- **Scale expressions**: `AttentionFuser` now resolves simple arithmetic (`**`, `*`, `/`, unary `-`) on literals and `self.<attr>`, needed for ModernBERT's `scaling=self.head_dim**-0.5`.
- **Online FP8 tolerance** widened from 2e-3 to 2.5e-3 in `test_modernbert_fp8.py`. Both implementations quantize the same 88 linears with one per-tensor scale each. Unquantized, the backend is closer to the reference than native. With FP8 it lands 5e-4 further away (see below).
- Known regression: ModernBERT has no TP plan in Transformers and its packed `Wqkv` is not fused, so it has no tensor parallelism. The model is ~150M params.
