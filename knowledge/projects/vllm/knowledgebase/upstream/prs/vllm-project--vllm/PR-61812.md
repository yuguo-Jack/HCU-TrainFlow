# [Bugfix] Fix Apertus streaming scientific notation

[Upstream PR](https://github.com/vllm-project/vllm/pull/61812) · state: closed · merged: True

## Original PR description



## Overview

Fix corrupted scientific-notation arguments in Apertus streaming tool calls.

## Details

The parser could emit incomplete numbers before receiving their exponents. Since streamed arguments cannot be retracted, a value such as `-2e-3` could produce invalid arguments like `-20.002`.

Exclude `Allow.NUM` during incremental parsing to avoid emitting incomplete numeric values. Final parsing and incremental string streaming remain unchanged.

Numbers may be delayed until a terminating delimiter arrives.

## Validation

Added three regression cases covering positive and negative exponents, including numbers inside arrays.
