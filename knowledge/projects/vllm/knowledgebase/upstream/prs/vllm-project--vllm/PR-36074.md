# [Docs] Add doc note about building for free-threaded Python.

[Upstream PR](https://github.com/vllm-project/vllm/pull/36074) · state: open · merged: False

## Original PR description

## Purpose

This is intended to help people who wish to try running vLLM on free-threaded Python.  It is still experimental but getting more testers would be helpful.  I plan to keep that repo up-to-date in terms of instructions.

## Test Plan

I've tested building vLLM with CUDA, ROCm, and CPU options, using those instructions.  Not all features of vLLM work (e.g. ray and opencv are missing, for example).  However,  text inference with various models, like SmolLM2-360M-Instruct, seems to work.

## Test Result

I'm able to start the vLLM server and have a working inference server.
