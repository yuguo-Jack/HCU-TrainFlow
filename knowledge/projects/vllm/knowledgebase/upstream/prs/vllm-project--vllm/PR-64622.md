# [Startup] Skip the CUDA graph memory profile when its estimate is disabled

[Upstream PR](https://github.com/vllm-project/vllm/pull/64622) · state: open · merged: False

## Original PR description



## Overview

With `VLLM_MEMORY_PROFILER_ESTIMATE_CUDAGRAPHS=0`, startup still runs `profile_cudagraph_memory()` and then ignores the result. Skip it. AI assistance (Claude Code) was used to prepare this PR; I reviewed every changed line.

## Claims

- Qwen3.5-35B-A3B, TP1, GB300, warm caches: startup **95.1 s → 72.5 s** with the estimate disabled.
- No change with the estimate enabled (the default).

## Validation

```
$ pytest tests/v1/worker/test_gpu_worker.py -k cudagraph_memory_profile_runs_only_when_applied
2 passed                                    # this PR (CPU and GB300)
1 failed, 1 passed                          # main
>       assert calls == ([1] if estimate_enabled else [])
```

## Details

The warning for the disabled estimate stays, without the suggested `--gpu-memory-utilization` it needed the estimate for.
