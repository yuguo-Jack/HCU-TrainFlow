# [Bugfix][Multimodal] Fix Qwen3-ASR audio preprocessing parity

[Upstream PR](https://github.com/vllm-project/vllm/pull/57146) · state: closed · merged: True

## Original PR description

## Purpose
Fixes #56981.

Qwen3-ASR currently inherits Omni's waveform padding and forces a Whisper feature extractor, which can change audio features and placeholder counts relative to the checkpoint's upstream processor.

Following the review feedback, this revision:

- Uses the upstream Transformers `Qwen3ASRProcessor` and removes the bundled processor and its registration.
- Requires Transformers >=5.13.0 and updates the corresponding test metadata.
- Uses `BaseMultiModalProcessor` without Omni's waveform padding.
- Processes clips independently and packs valid features, preserving parity across differently sized clips and partial cache hits.
- Preserves text-only and precomputed-feature inputs.

Both checkpoint formats remain supported: the original checkpoint declares `WhisperFeatureExtractor`, while the native `-hf` checkpoint declares `Qwen3ASRFeatureExtractor`.

No shared Omni/VL implementation, model weights, encoder kernels, or speculative-decoding behavior is changed.

### Model validation

Tested both `Qwen/Qwen3-ASR-0.6B` and `Qwen/Qwen3-ASR-0.6B-hf` with both Transformers versions.

Each run compared raw audio against independently computed upstream features in the same vLLM engine, using 32 LibriSpeech test-clean utterances plus 32 near-hop-boundary variants. Settings: single H100, BF16, greedy decoding, eager execution, `max_num_seqs=1`, and processor/prefix caches disabled.

All four model/version combinations matched prompt IDs and generated token IDs on 64/64 clips. Raw/reference WER was 2.8846% in every run. This is a bounded correctness evaluation, not a full-split accuracy or speed benchmark.

Environment: Python 3.13.15, PyTorch 2.13.0+cu130, and NumPy 2.4.6. Tests used this checkout's Python source with existing vLLM 0.29 CUDA extensions, not a fresh CUDA build. Full upstream CI remains necessary. Realtime and forced-aligner checks cover preprocessing, not complete streaming or timestamp-accuracy evaluation.
