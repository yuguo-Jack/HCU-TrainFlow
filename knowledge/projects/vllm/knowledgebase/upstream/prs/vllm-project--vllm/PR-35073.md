## Code Review

The refactoring of the linear kernel abstraction directory is a significant improvement in modularity and organization. However, there are critical issues in the test suite and utility files due to renamed functions and missing exports. Specifically, `init_fp8_linear_kernel` was renamed to `create_w8a8_fp_kernel` but remains used in `tests/utils.py`. Also, `tests/kernels/quantization/test_scaled_mm_kernel_selection.py` is broken due to the removal of old class names from the centralized export. Finally, the kernel selection logic should be more robust against unsupported platforms to avoid a `KeyError`.

Directly indexing `possible_kernel_modules` with `current_platform._enum` will raise a `KeyError` if the platform is not present in the dictionary. While the current platforms are covered, using `.get(..., [])` is more robust and ensures that the function proceeds to raise a descriptive `ValueError` later if no kernels are found.

```suggestion
    for kernel_module in possible_kernel_modules.get(current_platform._enum, []):
```
