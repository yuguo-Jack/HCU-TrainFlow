# [MRV2] Pass FULL replay context to synchronous KV loads

[Upstream PR](https://github.com/vllm-project/vllm/pull/60636) · state: open · merged: False

## Original PR description

## Overview

Pass the actual FULL graph mode to MRV2's synchronous KV-load pre-forward hook, so a connector can wait for its loads before graph replay bypasses Python layer hooks. This is the standalone FULL-context fix extracted from #58968.

Rebased onto main `bfa7e5b7afe40ebe48288801a2baf5c1135cd881`. This remains an independent child of closed #58968.

## Claims

- Run `kv_connector.pre_forward()` under a forward context whose runtime mode is `CUDAGraphMode.FULL` on the FULL replay branch.
- Preserve eager/piecewise paths and avoid an additional DP batch-coordination operation.

```text
FULL context -> pre_forward / synchronous load wait -> graph replay
```

## Details

`ActiveKVConnector` starts synchronous loads during `pre_forward()`. Without a caller-provided context it constructs a default context. MoRI's READ path distinguishes FULL replay, which must finish all required reads before replay, from execution that can wait through per-layer hooks. The missing FULL context can therefore select the wrong existing wait path.

This changes only the FULL call site and its tests. It adds no connector capability, does not introduce a new READ barrier and does not depend on the MultiConnector ownership or speculative-readiness split. #57700 explicitly left this context correction to #58968; #48464 concerns MRV1 imperative lifecycle helpers, not this MRV2 replay call site.

**Merge impact:** reversible code change; MRV2 FULL pre-forward hooks. An existing connector's FULL-specific waiting behavior can now run at this call site. No throughput or latency equivalence is claimed.

#60808 changes MoRIIO to await all READs before any forward; if it lands first, MoRI no longer relies on FULL mode for that decision. This PR separately preserves the common MRV2 replay-context contract. #60637 handles output publication after draft writes, not input loading.

AI assistance was used for implementation, rebase, regression checks and this description. Human line-by-line review and the runtime acceptance items above remain pending. No performance improvement is claimed.
