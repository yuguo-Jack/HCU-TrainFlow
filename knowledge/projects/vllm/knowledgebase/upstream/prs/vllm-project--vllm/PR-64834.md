# [CI][XPU] Use supported block sizes in UCX backend tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/64834) · state: open · merged: False

## Original PR description

## Overview

The UCX tests hard-code 16-token blocks, but XPU FlashAttention requires multiples of 64. Reuse `maybe_update_block_size(16)` for both cache configurations. This PR fixes the setup failure without changing the four test cases or assertions.

**Note** We should merge this after https://github.com/vllm-project/vllm/pull/64897 lands.

## Validation

- **Main:** [three cases fail](https://buildkite.com/vllm/ci/builds/98753#01a18dfc-43d9-4ef8-8436-81d6ebae41ad) with `No common block size for 16 (FLASH_ATTN: [MultipleOf(64)])`.
- **Branch:** isolated CPU check accepts 64; non-XPU stays at 16.
