# [Doc] Make agent test rules defaults with stated exceptions

[Upstream PR](https://github.com/vllm-project/vllm/pull/62993) · state: open · merged: False

## Original PR description

## Purpose

Follow-up to #62601, addressing @tomasruizt's review (https://github.com/vllm-project/vllm/pull/62601#pullrequestreview-5597769386).

- State that the rules in `tests/AGENTS.md` are defaults: an agent may deviate when one does not fit, and must say why in the PR. Weakening a test to make it pass stays forbidden.
- Add the trade-off between end-to-end tests (robust to refactors, slow) and unit tests on pure functions (fast, partial coverage), and encourage factoring logic into pure functions.
- Allow mocks for objects that are impractical to construct, with the reason stated in the test.
- Allow seeded statistical assertions (p-value, confidence interval) when sampling itself (temperature > 0) is under test.
- In `AGENTS.md`, prefer adding a case to an existing parametrized test, then extending existing tests, before writing a new one.
