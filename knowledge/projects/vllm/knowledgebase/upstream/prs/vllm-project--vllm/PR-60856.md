# [Bugfix][Rust Frontend] Decode current NIXL connector stats

[Upstream PR](https://github.com/vllm-project/vllm/pull/60856) · state: open · merged: False

## Original PR description

## Overview

Rust's strict `NixlStats` decoder rejected two fields emitted by current Python NIXL stats. In `MultiConnector` payloads, that caused the NIXL child to be treated as opaque data, so the Rust metrics recorder dropped its transfer histograms. The recorder also omitted handshake/notification failures from the combined failure counter and did not export late notifications.

## Claims

- Decode current Python NIXL `MultiConnector` stats while retaining compatibility with payloads that omit newer fields.
- Record NIXL transfer histograms and align the Rust failed-transfer counter with Python by including transfer, handshake, and notification failures.
- Export `vllm:nixl_num_notifications_after_expiry` from the Rust frontend.
- This does not duplicate [#58563](https://github.com/vllm-project/vllm/pull/58563): that PR adds descriptor-driven metrics for other connectors and explicitly leaves NIXL on its existing typed path. This change fixes that typed path and completes the Rust metric coverage.

## Validation

- `cargo test --manifest-path rust/Cargo.toml -p vllm-engine-core-client kv_connector_stats_are_recorded_into_mooncake_and_nixl_metrics` — passed (1 test); verifies the combined failure count and late-notification counter.
- `cargo test --manifest-path rust/Cargo.toml -p vllm-engine-core-client python_msgpack_fixtures_match_rust_encoding_and_record_nixl_metrics` — passed (1 test); decodes the Python-generated fixture and checks rendered failure, expiry, and histogram metrics.
- `cargo fmt --manifest-path rust/Cargo.toml --all --check`, `git diff --check`, and commit pre-commit hooks — passed.

## Details

EngineCore sends `MultiConnector` stats as a map from connector class name to its stats payload. Current Python NIXL stats include `num_failed_handshakes` and `num_notifications_after_expiry`; the Rust `NixlStats` used `deny_unknown_fields` but did not declare these fields. Serde therefore rejected the typed NIXL child, the flattened `other` map retained it as opaque data, and the recorder ignored it.

The relevant flow is: (1) the P/D connector accumulates transfer and notification outcomes, (2) EngineCore serializes connector stats into the `MultiConnector` MessagePack payload, and (3) the Rust frontend decodes NIXL stats and records the matching Prometheus metrics. Adding the missing fields with defaults keeps older payloads compatible. The recorder now groups transfer, handshake, and notification failures under the existing failed-transfer counter, keeps the dedicated notification-failure counter for compatibility, and records notifications received after expiry separately.

The regression extends the Python-generated MessagePack fixture and asserts the decoded fields and rendered counters, including a failed handshake, a failed notification, and two notifications after expiry.
