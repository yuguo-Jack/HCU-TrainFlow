# [Spec Decode] Add AdaFlash model support

[Upstream PR](https://github.com/vllm-project/vllm/pull/64214) · state: open · merged: False

## Original PR description

## Overview

Add support for the AdaFlash drafter [`AdaFlash/Qwen3-8B-AdaFlash`](https://huggingface.co/AdaFlash/Qwen3-8B-AdaFlash) for `Qwen/Qwen3-8B`. It is served through the existing DFlash path (`method="dflash"`) with a fixed number of speculative tokens.

```bash
vllm serve Qwen/Qwen3-8B \
    --speculative-config '{"method": "dflash", "model": "AdaFlash/Qwen3-8B-AdaFlash", "num_speculative_tokens": 15}'
```

## Claims

- The released AdaFlash checkpoint loads and runs as a drafter.
- Output is identical to autoregressive decoding, with 1.8x to 5.7x higher throughput on GSM8K, and about 1.2x higher than the official DFlash drafter.

## Validation

Setup: 1x H800, Qwen3-8B (BF16), MRV2, batch-invariant mode. Benchmark: GSM8K, 256 requests per run, single run per cell. DFlash is the official [`z-lab/Qwen3-8B-DFlash-b16`](https://huggingface.co/z-lab/Qwen3-8B-DFlash-b16); both drafters use `num_speculative_tokens=15`.

Output throughput in tok/s (speedup over autoregressive):

| Concurrency | Autoregressive | DFlash | AdaFlash |
| --- | --- | --- | --- |
| 1 | 138.8 | 654.2 (4.71x) | **794.7 (5.72x)** |
| 32 | 3189.2 | 6353.2 (1.99x) | **7500.1 (2.35x)** |
| 64 | 4535.4 | 6881.6 (1.52x) | **8237.5 (1.82x)** |

At each concurrency, all three methods produce identical outputs for all 256 requests (223, 222 and 220 of 256 correct at concurrency 1, 32 and 64).

Accuracy and acceptance on the full GSM8K test set (1319 questions) with the existing `test_dflash_correctness`, using the AdaFlash draft model (run locally; the test file is unchanged in this PR):

| Accuracy | Mean acceptance length |
| --- | --- |
| 0.888 | 4.53 |

Registry check: `pytest tests/models/test_registry.py -k hf_registry_coverage` passes.

## Details

`AdaFlashQwen3ForCausalLM` subclasses `DFlashQwen3ForCausalLM` and only overrides `load_weights`. The checkpoint has 64 tensors: the 58 standard DFlash tensors plus 6 `thresh_head_two_model.*` tensors for AdaFlash's length head, which are skipped here since the head is not used. The checkpoint's `config.json` declares `DFlashAdaFlashDraftModel`; the `DFlash` prefix is needed because `EAGLEConfig` prefixes any other draft architecture name with `DFlash`. Existing DFlash code is unchanged.
