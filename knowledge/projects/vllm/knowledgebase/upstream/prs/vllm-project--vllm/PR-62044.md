# [Bugfix][AuxOutput] Fix routed-experts store overflow at full KV

[Upstream PR](https://github.com/vllm-project/vllm/pull/62044) · state: closed · merged: False

## Original PR description

## Purpose

With `enable_return_routed_experts`, the engine crashes once KV usage reaches 100%: `BlockObjectStoreError` is raised in the AuxOutput writer thread.

The routed-experts store is sized to the KV cache. A finished or preempted request's KV blocks are reused at the next schedule, but its keys are released only after the in-flight step is processed, so at full KV the referenced keys exceed the store.

Fix: size the store at the KV block count plus the most blocks the scheduler can reuse and re-key before those deferred releases arrive (`(max_concurrent_batches - 1) * (cdiv(max_num_batched_tokens, hash_block_size) + max_num_seqs)`). Also send hashes only for scheduled blocks and stop rescanning the whole store on every `put` when it is full.

## Test Plan

Updated unit tests. Reproduced with GLM-4.5-Air TP8 at full KV: crashes on v0.31.0, runs clean with this change.

AI assistance (Claude) was used; all changes were reviewed by the submitter.
