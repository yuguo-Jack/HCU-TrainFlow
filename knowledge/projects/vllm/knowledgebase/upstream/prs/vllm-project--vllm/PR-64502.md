# [LoRA] Add multi-CTA shrink

[Upstream PR](https://github.com/vllm-project/vllm/pull/64502) · state: open · merged: False

## Original PR description



## Overview

Add an multi-CTA LoRA shrink kernel, enabled with `VLLM_LORA_SHRINK_USE_MULTICTA=1`.

## Claims

Reduce K partitions within a CTA cluster, avoiding floating-point atomics, global partial-result buffers, and a separate reduction kernel.

## Validation

Tested on one NVIDIA H20-3e (143,771 MiB), BF16, TP=1, using Qwen/Qwen3-4B and `nissenj/Qwen3-4B-lora` (rank 8, q/v projections). All evaluation and benchmark requests target the loaded adapter.

**vllm serve**
```
VLLM_LORA_SHRINK_USE_MULTICTA=0 vllm serve "Qwen/Qwen3-4B"
--served-model-name qwen3-base --host 127.0.0.1 --port 8000 \
--gpu-memory-utilization 0.8 --enable-lora --max-loras 1 \
--max-lora-rank 64 --lora-modules gsm8k-lora="/path/to/adapter" \
--no-enable-prefix-caching --seed 42
```
