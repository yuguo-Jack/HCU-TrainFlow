# [Bugfix][Kernel] Mask the per-key gate load in fused recurrent KDA

[Upstream PR](https://github.com/vllm-project/vllm/pull/61814) · state: open · merged: False

## Original PR description



## Overview
Fixes #61802.
Mask the per-key gate (`gk`) load in the fused recurrent KDA kernel so non-power-of-2 key dims don't read out of bounds.
Adds a new test to prevent regression.


## Claims
- Fixes an unmasked `tl.load(p_gk)` when BK > K (padded block).
- No behavior change for power-of-2 K.

## Validation
```
pytest tests/kernels/fla/test_fused_recurrent_kda_non_pow2.py

```


## Details
`BK` is padded to next power of 2. `lanes >= K` loaded unmasked `gk`, feeding `exp()` into `b_h`. 
Other memory accesses in this kernel already use `mask_k`.
