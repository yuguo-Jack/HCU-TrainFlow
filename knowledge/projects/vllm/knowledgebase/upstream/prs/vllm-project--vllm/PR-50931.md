# [ModelRunner v2] Enable decoder token-wise pooling

[Upstream PR](https://github.com/vllm-project/vllm/pull/50931) · state: closed · merged: True

## Original PR description

## Purpose

Advances #41286 by enabling decoder token-wise pooling on Model Runner V2. The pooling already supports chunked accumulation, but MRV2 filtered `token_embed` and `token_classify` for non-encoder models. This removes that flag.

This unblocks text decoder embedding models, reward/process-reward models, and rerankers. 

## Reproducer

```bash
VLLM_USE_V2_MODEL_RUNNER=1 \
.venv/bin/python -m pytest \
tests/models/language/pooling/test_all_pooling_plus_chunked_prefill.py::test_decoder_token_embed_model_runner_v2 -q
```
