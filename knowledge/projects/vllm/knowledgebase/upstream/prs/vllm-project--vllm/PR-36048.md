# [Kernel][Test] Add unit tests on cutlass moe

[Upstream PR](https://github.com/vllm-project/vllm/pull/36048) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Purpose: Add unit tests for `run_cutlass_moe_w4a8_fp8`:

  - `test_run_cutlass_moe_w4a8_fp8_no_graph` — non-graph path with workspace-independence
    check and a numerical reference (run `torch_experts` on dequantized weights and
    compare with `assert_close(atol=1e-1, rtol=1e-1)`).
  - `test_run_cutlass_moe_w4a8_fp8_with_expert_map` — expert-parallelism path with a
    numerical reference (every token lands on a local expert, output must equal
    `torch_experts` over local weights with shifted topk_ids).
  - `test_cutlass_moe_w4a8_fp8_modular` — drives `CutlassExpertsW4A8Fp8` through
    `FusedMoEKernel` end-to-end.

  Also fixes the fake op for `cutlass_encode_and_reorder_int4b_grouped` in
  `vllm/_custom_ops.py`: the layout tensor was hard-coded to `device="cpu"`, but the
  real op places it on `b.device()`. The fake now uses `device=b.device` to match.

  After merging `main`, the `FusedMoEKernel.apply()` signature picked up four new
  required args (`activation`, `global_num_experts`, `expert_map`,
  `apply_router_weight_on_input`); updated the `run_8_bit` and `run_with_expert_maps`
  helpers to pass them.

## Test Plan

  ```bash
  pytest -v tests/kernels/moe/test_cutlass_moe.py
  ```

## Test Result

Local run on `gb-nvl-057-compute06` (aarch64, sm_100 Blackwell, `VLLM_USE_PRECOMPILED=1`):

  - Pre-existing 8-bit cases that are exercised by the precompiled wheel on this hardware:

    ```bash
    pytest -k "8_bit and True-True" tests/kernels/moe/test_cutlass_moe.py
    ```

    → **98 passed, 273 deselected in 30.33s** — confirms the `FusedMoEKernel.apply()`
    signature fix restores the pre-existing 8-bit test coverage that the `main` merge
    surfaced.

  - The remaining `[False-False-*]` 8-bit parametrizations and the three new W4A8 tests
    fail locally with `cudaErrorNoKernelImageForDevice` because the precompiled wheel
    ships no sm_100 binaries for those cutlass kernels. They will be validated by vLLM CI
    (which has Blackwell-capable builders) or by a from-source build. Lint/type-check
    pass on the changed files locally (`ruff-check`, `ruff-format`, `mypy-3.12`).
