# [Bugfix][HiSparse] Inject backend in connector unit test

[Upstream PR](https://github.com/vllm-project/vllm/pull/64240) · state: open · merged: False

## Original PR description

## Summary

Make `test_draft_layer_rows_mirrored_after_drafter` independent of the active hardware platform by injecting a mock HiSparse backend before constructing `HiSparseConnectorWorker`.

PR #62592 moved backend selection into the worker constructor. The test currently installs only a method mock after construction, so Intel BMG nightly CI now fails first with `RuntimeError: The current platform does not support HiSparse` even though the test uses CPU tensors and a fake DMA implementation.

## Failure evidence

Nightly main build #97886, Intel BMG V1 shard 2:

- `test_draft_layer_rows_mirrored_after_drafter[FULL]`
- `test_draft_layer_rows_mirrored_after_drafter[NONE]`

Both fail during `HiSparseConnectorWorker(...)`, before reaching the test's existing fake `swap_blocks_batch` implementation.
