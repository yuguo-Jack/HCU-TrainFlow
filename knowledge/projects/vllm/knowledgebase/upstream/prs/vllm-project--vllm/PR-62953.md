# [Bugfix][MRV2] Coordinate final CUDA graph redispatch across DP ranks

[Upstream PR](https://github.com/vllm-project/vllm/pull/62953) · state: open · merged: False

## Original PR description

## Overview

Coordinate the **final**, rank-local CUDA graph redispatch result in MRV2's ordinary DP padding path. If final modes or token padding diverge, fall back to eager collectively and record that choice in `DPSyncState`.

**Draft: two-GPU component A/B completed; full-model end-to-end validation and model evaluations are still pending. This is not a confirmed fix for a production MegaMoE grid-sync timeout.**

## Claims

- Detect post-coordination mode divergence even when both ranks initially selected FULL.
- Detect unequal final graph padding even when both ranks remain FULL.
- Preserve FULL replay when final mode and padding agree; propagate `eager=True` with the original per-rank token counts when falling back.

Both ranks start with FULL; local batches are 10 requests/60 tokens and 64 requests/384 tokens, uniform query length 6.

| --- | --- | --- |
| Rank 0 ceiling 256, rank 1 ceiling 1024 | NONE-384 / FULL-384, but both sync states say `eager=False` | NONE-60 / NONE-384, both `eager=True`, both share raw token vector `[60,384]` |
| Both ceilings 1024; rank 0 rounds 384 to 480, rank 1 has 384 | FULL-480 / FULL-384, inconsistent sync vectors `[480,480]` / `[384,384]` | Collective eager fallback with shared raw vector `[60,384]` |

```python
"""Two-GPU component test, not a full-model or MegaMoE fault reproducer.

Run the exact upstream/fixed dp_utils modules against real vLLM graph captures
and process groups. The installed vLLM supplies graph/runtime dependencies;
their versions are recorded, rather than claiming a full main engine run.
"""
import argparse
import ast
from datetime import timedelta
import importlib.util
import json
import os
from pathlib import Path
import socket
import sys
import time

import torch
import torch.distributed as dist
import torch.multiprocessing as mp


def load_sync(version):
    path = Path(__file__).with_name(f"dp_{version}.py")
    spec = importlib.util.spec_from_file_location(f"probe_{version}", path)
    module = importlib.util.module_from_spec(spec)
    sys.modules[spec.name] = module
    spec.loader.exec_module(module)
    return module


def install_main_cpu_collective():
    # Compatibility backport in this test process only: v0.31 lacks this API.
    # Execute main's unmodified Gloo algorithm, not a canned collective result.
    from vllm.distributed.parallel_state import GroupCoordinator
    source = Path(__file__).with_name("distributed_main.py")
    tree = ast.parse(source.read_text())
    selected = [ast.ImportFrom("__future__", [ast.alias("annotations")], 0)]
    selected.extend(n for n in tree.body if isinstance(n, ast.FunctionDef) and n.name == "cpu_all_reduce_")
    selected.extend(n for n in tree.body if isinstance(n, ast.Assign) and any(isinstance(t, ast.Name) and t.id == "_CPU_ALL_REDUCE_TAG_BASE" for t in n.targets))
    scope = {"torch": torch}
    exec(compile(ast.fix_missing_locations(ast.Module(selected, [])), str(source), "exec"), scope)
    def cpu_all_reduce(self, tensor):
        return scope["cpu_all_reduce_"](tensor, self.cpu_group)
    GroupCoordinator.cpu_all_reduce_ = cpu_all_reduce


def worker_body(rank, port, args):
    import vllm
    from vllm.config import CompilationConfig, CUDAGraphMode, ModelConfig, ParallelConfig, SchedulerConfig, VllmConfig, set_current_vllm_config
    from vllm.distributed.parallel_state import init_distributed_environment, initialize_model_parallel, get_dp_group, destroy_model_parallel, destroy_distributed_environment
    from vllm.v1.worker.gpu.cudagraph_utils import CudaGraphManager

    os.environ.update(RANK=str(rank), LOCAL_RANK=str(rank), WORLD_SIZE="2")
    install_main_cpu_collective()
    torch.cuda.set_device(rank)
    cap = 256 if args.case == "asymmetric" and rank == 0 else 1024
    sizes = [n for n in [60, 120, 240, 256, 384, 768, 1024] if n <= cap]
    if args.case == "padding" and rank == 0:
        sizes = [60, 120, 240, 480, 768, 1024]
    compilation = CompilationConfig(cudagraph_mode=CUDAGraphMode.FULL_DECODE_ONLY,
                                    cudagraph_capture_sizes=sizes, max_cudagraph_capture_size=cap)
    compilation.post_init_cudagraph_sizes()
    config = VllmConfig(model_config=ModelConfig(model="/work/tiny-model", skip_tokenizer_init=True, max_model_len=1024),
                       compilation_config=compilation,
                       scheduler_config=SchedulerConfig.default_factory(max_num_seqs=128, max_num_batched_tokens=1024, max_model_len=1024),
                       parallel_config=ParallelConfig(data_parallel_size=2, data_parallel_rank=rank,
                                                      data_parallel_size_local=2, distributed_executor_backend="external_launcher"))
    with set_current_vllm_config(config):
        init_distributed_environment(world_size=2, rank=rank, local_rank=rank,
                                     distributed_init_method=f"tcp://127.0.0.1:{port}", backend="nccl", timeout=timedelta(seconds=30))
        initialize_model_parallel(backend="nccl")
        manager = CudaGraphManager(config, torch.device("cuda", rank), CUDAGraphMode.FULL_DECODE_ONLY, 6)
        x = torch.arange(1024, dtype=torch.float32, device=f"cuda:{rank}")
        y = torch.zeros_like(x)

        def create_forward(desc, warmup):
            size = desc.num_tokens
            return lambda _mode: torch.add(x[:size], 1.0, out=y[:size])

        manager.capture(create_forward)
        print("CAPTURE " + json.dumps({"rank": rank, "cap": cap,
              "sizes": config.compilation_config.cudagraph_capture_sizes,
              "graphs": [str(desc) for desc in manager.graphs]}), flush=True)
        sync_module = load_sync(args.version)
        num_reqs, num_tokens = (10, 60) if rank == 0 else (64, 384)
        desired = manager.dispatch(num_reqs, num_tokens, 6, 0, max_query_len=6)
        assert desired.cg_mode == CUDAGraphMode.FULL, desired
        group = get_dp_group()
        durations = []
        result = None
        for _ in range(args.steps):
            start = time.perf_counter()
            desc, state = sync_module.sync_cudagraph_and_dp_padding(
                manager, desired, num_tokens, num_reqs, 6, 2, rank, max_query_len=6)
            durations.append((time.perf_counter() - start) * 1e6)
            result = {"rank": rank, "cap": cap, "initial": desired.cg_mode.name,
                      "final": desc.cg_mode.name, "tokens": desc.num_tokens,
                      "eager": state.eager, "tokens_across_dp": state.num_tokens_across_dp.tolist(),
                      "enters_swa_collective": desc.cg_mode == CUDAGraphMode.NONE}
            if desc.cg_mode == CUDAGraphMode.FULL:
                manager.run_fullgraph(desc)
            else:
                create_forward(desc, False)(CUDAGraphMode.NONE)
        torch.cuda.synchronize()
        torch.testing.assert_close(y[:desc.num_tokens], x[:desc.num_tokens] + 1.0)
        pair = [None, None]
        dist.all_gather_object(pair, result, group=group.cpu_group)
        mismatch = (pair[0]["final"] != pair[1]["final"] or
                    (not pair[0]["eager"] and pair[0]["tokens"] != pair[1]["tokens"]))
        expect_mismatch = args.case in ("asymmetric", "padding") and args.version == "before"
        assert mismatch == expect_mismatch, pair
        if args.version == "after" and args.case in ("asymmetric", "padding"):
            assert all(p["eager"] and p["tokens_across_dp"] == [60, 384] for p in pair), pair
        if args.case == "control":
            assert all(p["final"] == "FULL" and not p["eager"] and p["tokens_across_dp"] == [384, 384] for p in pair), pair

        # This bounded Gloo group represents the guarded CPU collective only.
        # No waiting CUDA kernel, assertion, or GPU reset is used in the test.
        bounded = dist.new_group(ranks=[0, 1], backend="gloo", timeout=timedelta(seconds=4))
        collective_outcome = "skipped"
        if result["enters_swa_collective"]:
            try:
                dist.monitored_barrier(group=bounded, timeout=timedelta(seconds=4), wait_all_ranks=True)
                collective_outcome = "completed"
            except RuntimeError as error:
                assert args.case == "asymmetric" and args.version == "before", str(error)
                collective_outcome = "bounded_timeout"
        outcomes = [None, None]
        dist.all_gather_object(outcomes, collective_outcome, group=group.cpu_group)
        if args.case == "asymmetric" and args.version == "before":
            assert outcomes == ["bounded_timeout", "skipped"], outcomes
        elif args.case in ("asymmetric", "padding") and args.version == "after":
            assert outcomes == ["completed", "completed"], outcomes
        else:
            assert outcomes == ["skipped", "skipped"], outcomes
        summary = {"version": args.version, "case": args.case, "runtime_vllm": vllm.__version__,
                   "torch": torch.__version__, "rank": rank, "pair": pair,
                   "guarded_collective": outcomes, "steps": args.steps,
                   "sync_us_median": sorted(durations)[len(durations)//2],
                   "sync_us_p99": sorted(durations)[min(len(durations)-1,int(len(durations)*0.99))],
                   "gpu_elementwise_output_correct": True}
        Path(f"/work/{args.version}-{args.case}-rank{rank}.json").write_text(json.dumps(summary, indent=2))
        print("RESULT " + json.dumps(summary), flush=True)
        dist.destroy_process_group(bounded)
        destroy_model_parallel()
        destroy_distributed_environment()


def worker(rank, port, args):
    try:
        worker_body(rank, port, args)
    finally:
        from vllm.distributed.parallel_state import destroy_model_parallel, destroy_distributed_environment
        destroy_model_parallel()
        destroy_distributed_environment()


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--version", choices=["before", "after"], required=True)
    parser.add_argument("--case", choices=["asymmetric", "control", "padding"], required=True)
    parser.add_argument("--steps", type=int, default=100)
    args = parser.parse_args()
    with socket.socket() as sock:
        sock.bind(("127.0.0.1", 0))
        port = sock.getsockname()[1]
    mp.spawn(worker, args=(port, args), nprocs=2, join=True)
```

## Details

The first DP coordination agrees on the initial mode and largest input token count. It then redispatches that count through each rank's local graph manager. Local redispatch can fall back to NONE or round up differently; the existing return path neither reconciles these final results nor updates the hardcoded `eager=False`.

The patch exchanges final mode/token-count pairs using the existing CPU collective. A mismatch, or any final NONE, selects eager on all ranks using each rank's original unpadded inputs. Agreed graph results retain their common padding. The existing skip-coordination behavior is mirrored.

**Scope and remaining work:**
- The constructed failure requires different effective graph inventories. Different request/context lengths alone do not establish it; the identical-inventory control does not diverge.
- Initial eager/all-idle and DBO early returns are unchanged. Reuse/drafter paths and DBO are not comprehensively fixed or validated by this change.
- No complete LLM/OpenAI entry-point run, actual SWA/MegaMoE deadlock reproduction, DSpark acceptance/accuracy evaluation, `VLLM_GPU_SYNC_CHECK=error` serving run, or full-main regression suite has been completed.
- A maintained regression test and representative end-to-end measurements remain to be added before considering this ready to merge. The extra per-step CPU coordination cost may motivate a different contract/inventory-agreement design.

**Related work / duplicate check:** #54798 and #54810 implement a broader, default-off execution-contract stack initially restricted to MiniMax-M3 MRV2 DP+EP; this proposal is a small final-redispatch guard in the existing ordinary path, without a new scheduler policy or contract cache. #62209 adds sparse prefill captures, not final DP consensus. These are related design alternatives, not claims that the broader problem is otherwise unaddressed.
