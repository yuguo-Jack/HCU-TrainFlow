# [DeepSeek-V4-P1] Align dense and masked SiLU FP8 quantization via shared Triton arithmetic

[Upstream PR](https://github.com/vllm-project/vllm/pull/59863) · state: open · merged: False

## Original PR description

## Scope

This is the P1 split of #62365 for dense and expert-masked SiLU-Mul FP8 quantization. Under `VLLM_BATCH_INVARIANT=1`, the masked path reuses the dense Triton arithmetic and launch contract, so the same token produces the same FP8 bytes and scale words on both paths.

- No new test file.
- No new BI CUDA operator; the BI path calls the existing Triton quantization implementation.
- The persistent CUDA fallback remains the non-BI path.
- Packed-scale tails are zeroed and short launches use token-tile scheduling rather than a fixed capacity threshold.
