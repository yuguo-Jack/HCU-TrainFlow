# [KV Connector] Warn when MultiConnector's first-hit load leaves tokens a later connector reported

[Upstream PR](https://github.com/vllm-project/vllm/pull/63014) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

`MultiConnector` loads each request from the first child, in config order, that reports new matched tokens, and computes the rest locally even when a later child reported more. A wrong order fails silently; this PR logs a warning when that happens and documents the rule. Related: #54240.

## Claims

- Logs a warning, once per (chosen, larger) connector pair, when a later connector reported more new tokens than the chosen one, with both counts and the number of tokens computed locally.
- Documents the selection rule and the `[OffloadingConnector, NixlConnector]` ordering pitfall in `docs/features/disagg_prefill.md` and the class docstring.
- No behavior change: connector selection, prompt-token counters and greedy outputs are identical to main in both connector orders.

## Validation

**Setup.** One prefill and one decode instance, one B300 GPU each, running `Qwen/Qwen3-8B` with `--max-model-len 16384 --enable-prefix-caching`:

- **Image:** `vllm/vllm-openai:nightly` (0.32.1rc1.dev197+g8e2beaa3b), whose `multi_connector.py` is identical to main at 9d61ade. The "this PR" rows bind-mount this PR's file.
- **Connectors:** P runs `NixlConnector` (`kv_producer`). D runs `MultiConnector` with `OffloadingConnector` (8 GB of CPU memory) and `NixlConnector` (`kv_consumer`), in the order given in the table.
- **Proxy:** `tests/v1/kv_connector/nixl_integration/toy_proxy_server.py`.
- **Prompts:** 8 requests sent one at a time, each a 2,048-token shared prefix followed by a unique 6,145-token body of random common English words with fixed seeds, with 32 greedy output tokens.
- **Making the CPU tier hold more than GPU memory:** D first serves one request with the same prefix, so its CPU tier holds the prefix. Before each measured request, `POST /reset_prefix_cache` on D drops its GPU prefix cache and keeps the CPU tier. This stands in for GPU eviction under memory pressure.

| D connector order | Code | Prompt tokens computed on D | Prompt tokens loaded on D | NIXL transfers | TTFT median, requests 2-8 | Warnings |
|---|---|---|---|---|---|---|
| `[Offloading, Nixl]` | main | 49,160 (6,145 per request) | 16,384 (CPU tier, 2,048 per request) | 0 | 0.203 s | 0 |
| `[Offloading, Nixl]` | this PR | 49,160 | 16,384 | 0 | 0.206 s | 1 |
| `[Nixl, Offloading]` | main | 0 | 65,544 (NIXL) | 8 | 0.138 s | 0 |
| `[Nixl, Offloading]` | this PR | 0 | 65,544 | 8 | 0.141 s | 0 |

- **Token counts** are deltas of `vllm:prompt_tokens_by_source` on D over the 8 requests.
- **P was unaffected.** It computed the same 51,208 prompt tokens in all four runs, and its `vllm:kv_cache_usage_perc` returned to 0, so P released its blocks even when D did not pull them.
- **TTFT.** The first request with NIXL first (0.9-1.3 s) includes the one-time NIXL handshake, which is why the table uses requests 2-8.
- **Greedy outputs.** They are identical between main and this PR in both orders (8/8). With `[Offloading, Nixl]` they also match a single instance without connectors (8/8). With `[Nixl, Offloading]`, 6 of 8 diverge from the single instance at output token 2-5, identically on main and this PR and across reruns, so this comes from the P/D path, not from this change.

Warning from the second row:

```
MultiConnector loads request <id> from connector 0 (OffloadingConnector), the first one reporting a hit, with 2048 new tokens, although connector 1 (NixlPullConnector) reported 8193. Only one connector loads a request, so the remaining 6145 tokens are computed locally. If this is not intended, list the connector expected to cover the most tokens first. Logged once per connector pair.
```

```python
"""Repro client for MultiConnector load selection (public model, synthetic text).

1. D computes one request that starts with the shared prefix S, so D's CPU
   tier (OffloadingConnector) stores S.
2. For each test request: reset D's GPU prefix cache (CPU tier kept), then send
   S + unique body through the P/D proxy. This sets up "the CPU tier holds a
   longer prefix than HBM", which HBM pressure produces naturally.
3. Report per-request TTFT, outputs, and the deltas of the prompt-token source
   counters on D and P.
"""

import argparse
import hashlib
import json
import random
import time
import urllib.request

WORDS = (
    "time year people way day man thing woman life child world school state family "
    "student group country problem hand part place case week company system program "
    "question work government number night point home water room mother area money "
    "story fact month lot right study book eye job word business issue side kind head "
    "house service friend father power hour game line end member law car city name "
    "team minute idea body information back parent face level office door health "
    "person art war history party result change morning reason research girl moment "
    "air teacher force education river table window garden market letter music paper"
).split()


def text(seed: int, n_words: int) -> str:
    r = random.Random(seed)
    return " ".join(r.choice(WORDS) for _ in range(n_words))


def post(url: str, body: dict | None = None, timeout: float = 600) -> dict:
    data = json.dumps(body or {}).encode()
    req = urllib.request.Request(url, data=data, headers={"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=timeout) as r:
        raw = r.read()
    return json.loads(raw) if raw.strip() else {}


def metrics(port: int) -> dict[str, float]:
    with urllib.request.urlopen(f"http://127.0.0.1:{port}/metrics", timeout=30) as r:
        out: dict[str, float] = {}
        for line in r.read().decode().splitlines():
            if line.startswith("#") or not line.strip():
                continue
            name, _, value = line.rpartition(" ")
            if "_bucket" in name or "_created" in name:
                continue
            name = name.split("{")[0] + ("{" + name.split("source=")[1].split(",")[0].rstrip("}") + "}"
                                         if "source=" in name else "")
            if any(k in name for k in ("prompt_tokens_by_source", "nixl", "kv_offload_total", "num_preemptions",
                                       "kv_cache_usage", "num_requests_running", "num_requests_waiting")):
                out[name] = out.get(name, 0.0) + float(value)
        return out


def reset_gpu_prefix_cache(port: int) -> int:
    # Fails while blocks are held (e.g. in-flight CPU offload stores); retry.
    for attempt in range(1, 101):
        if post(f"http://127.0.0.1:{port}/reset_prefix_cache").get("success"):
            return attempt
        time.sleep(0.1)
    raise RuntimeError("reset_prefix_cache kept failing")


def is_gauge(name: str) -> bool:
    return "kv_cache_usage" in name or "num_requests_" in name


def delta(a: dict, b: dict) -> dict:
    return {k: round(b[k] - a.get(k, 0.0), 3) for k in sorted(b) if b[k] - a.get(k, 0.0)}


def stream_completion(port: int, model: str, prompt: str, max_tokens: int) -> tuple[float, float, str]:
    body = {"model": model, "prompt": prompt, "max_tokens": max_tokens, "temperature": 0, "stream": True}
    req = urllib.request.Request(f"http://127.0.0.1:{port}/v1/completions", data=json.dumps(body).encode(),
                                 headers={"Content-Type": "application/json"})
    t0 = time.perf_counter()
    ttft, pieces = None, []
    with urllib.request.urlopen(req, timeout=600) as r:
        for raw in r:
            line = raw.decode().strip()
            if not line.startswith("data:") or line == "data: [DONE]":
                continue
            chunk = json.loads(line[5:])
            piece = chunk["choices"][0].get("text", "") if chunk.get("choices") else ""
            if piece and ttft is None:
                ttft = time.perf_counter() - t0
            pieces.append(piece)
    return ttft or float("nan"), time.perf_counter() - t0, "".join(pieces)


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", required=True)
    ap.add_argument("--proxy-port", type=int, default=8000)
    ap.add_argument("--p-port", type=int, default=8100)
    ap.add_argument("--d-port", type=int, default=8200)
    ap.add_argument("--prefix-words", type=int, default=2048)
    ap.add_argument("--body-words", type=int, default=6144)
    ap.add_argument("--requests", type=int, default=8)
    ap.add_argument("--max-tokens", type=int, default=32)
    ap.add_argument("--out", required=True)
    args = ap.parse_args()

    prefix = text(0, args.prefix_words)
    prompts = [prefix + "\n\n" + text(1000 + i, args.body_words) for i in range(args.requests)]
    tok = lambda s: len(post(f"http://127.0.0.1:{args.p_port}/tokenize", {"model": args.model, "prompt": s})["tokens"])
    prefix_tokens, prompt_tokens = tok(prefix), [tok(p) for p in prompts]

    post(f"http://127.0.0.1:{args.d_port}/v1/completions",
         {"model": args.model, "prompt": prefix + "\n\n" + text(999, args.body_words), "max_tokens": 1,
          "temperature": 0})
    time.sleep(3)

    d0, p0 = metrics(args.d_port), metrics(args.p_port)
    rows = []
    for i, prompt in enumerate(prompts):
        attempts = reset_gpu_prefix_cache(args.d_port)
        ttft, e2e, out = stream_completion(args.proxy_port, args.model, prompt, args.max_tokens)
        rows.append({"i": i, "prompt_tokens": prompt_tokens[i], "ttft_s": round(ttft, 4), "e2e_s": round(e2e, 4),
                     "reset_attempts": attempts, "output_sha1": hashlib.sha1(out.encode()).hexdigest()[:12]})
        print(json.dumps(rows[-1]), flush=True)
    time.sleep(2)
    d1, p1 = metrics(args.d_port), metrics(args.p_port)

    ttfts = sorted(r["ttft_s"] for r in rows)
    summary = {
        "prefix_tokens": prefix_tokens,
        "mean_prompt_tokens": sum(prompt_tokens) / len(prompt_tokens),
        "ttft_mean_s": round(sum(ttfts) / len(ttfts), 4),
        "ttft_median_s": ttfts[len(ttfts) // 2],
        "d_delta": {k: v for k, v in delta(d0, d1).items() if not is_gauge(k)},
        "p_delta": {k: v for k, v in delta(p0, p1).items() if not is_gauge(k)},
        "d_gauges_after": {k: v for k, v in d1.items() if is_gauge(k)},
        "p_gauges_after": {k: v for k, v in p1.items() if is_gauge(k)},
        "rows": rows,
    }
    with open(args.out, "w") as f:
        json.dump(summary, f, indent=1)
    print(json.dumps({k: v for k, v in summary.items() if k != "rows"}, indent=1))


if __name__ == "__main__":
    main()
```

## Details

**How it happens.** On a decode instance with `[OffloadingConnector, NixlConnector]`:

1. GPU memory evicts part of a shared prefix, such as a system prompt. Blocks are freed tail first, so the tail goes first.
2. The CPU tier still holds that part, so `OffloadingConnector` reports a hit of a few blocks for the next request that P has already prefilled.
3. Being first in the list, it claims the request. `NixlConnector` is never asked to transfer, and D recomputes the rest of the prompt.
4. Nothing is logged.

We hit this in a P/D deployment and found it only through the prompt-token counters.

**Not a duplicate of #54240.** That PR adds an opt-in `range_aware` load policy so that several connectors can each load a range of the prompt. It keeps first-hit as the default, so this warning and the docs still apply with it. I found no other open PR that changes MultiConnector's load selection.

**Design.** The selection logic is unchanged; the warning only reads the counts that `get_num_new_matched_tokens` already collects. It is logged once per connector pair to keep logs quiet under load.

**Limitations:**

- The warning compares token counts only. Preferring an earlier, faster connector that covers fewer tokens can be intentional, hence "if this is not intended".
- It shows that the situation occurred, not how often; `vllm:prompt_tokens_by_source` shows how often.
- The reproduction forces the eviction with `/reset_prefix_cache`. How often it happens under real memory pressure depends on the workload.
