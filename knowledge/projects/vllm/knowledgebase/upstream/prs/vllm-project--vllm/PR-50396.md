File: `vllm/model_executor/layers/quantization/inc/schemes/inc_wna16_moe.py` · line 309

**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Pass configured parameters to the MoE activation**

When ARK is selected for an int4 MoE with configured activation parameters, this call silently uses `ApplyMoEActivationConfig` defaults because no `activation_config` is passed. Consequently, a configured SiLU clamp is ignored (corrupting model outputs), while SITU and `SWIGLUOAI_UNINTERLEAVE` can fail their required-parameter assertions. Preserve the layer/MoE clamp, alpha, beta, and SITU parameters when invoking the activation, and cover the ARK execution path with a behavioral correctness test rather than only backend-routing tests.
