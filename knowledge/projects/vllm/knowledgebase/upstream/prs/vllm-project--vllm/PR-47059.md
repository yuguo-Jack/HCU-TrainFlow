# Torch Stable ABI pre-commit hook

[Upstream PR](https://github.com/vllm-project/vllm/pull/47059) · state: closed · merged: False

## Original PR description

## Purpose
Adds a pre-commit hook (check-stable-abi) to guard the ongoing libtorch stable ABI migration. The hook scans C++/CUDA sources under `csrc/` and flags new uses of unstable PyTorch headers and legacy C++ APIs in code paths that should stay on the stable ABI.

Sources that still legitimately use the unstable ABI are skipped via ignore lists in check_stable_abi.py. This list should shrink as the CPU and ROCm builds move toward the stable ABI.

**Limitations:**
Regex-only: does not analyze transitive includes through project headers (e.g. a stable-looking include that pulls in torch/all.h internally). A compile-based CI check is planned as a follow-up.

cc @janeyx99 @Harry-Chen
