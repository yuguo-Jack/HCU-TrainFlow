# [CI] Bump Transformers version to 5.22.0

[Upstream PR](https://github.com/vllm-project/vllm/pull/64529) · state: closed · merged: True

## Original PR description

## Overview

Bump Transformers to [v5.22.0](https://github.com/huggingface/transformers/releases/tag/v5.22.0). Follows #64049.

## Claims

- `requirements/common.txt` allows `transformers >= 5.16.1, < 5.23.0`, and CI pins 5.22.0.
- The only breaking change in 5.22 (huggingface/transformers#49679, EP styles moved out of `tensor_parallel.py`) does not touch vLLM: nothing imports `transformers.distributed` or the moved classes.
- 5.22 adds a native `RadioModel` (`q/k/v_proj`, `o_proj`), which vLLM's RADIO loader already maps, so only `test_radio.py` needed updating. Its weight-loading test also compared uninitialized (possibly NaN) parameters, which is fixed here too.

## Validation

- No tests are gated on 5.22 (`min_transformers_version`/skip markers).
- `test_radio.py` on B200 with 5.22: 10 passed.
- Qwen2.5-VL PPL on B200: 22.2441 (+0.30%) on both 5.21.1 and 5.22, so the PPL job's failure is not from this bump.

```bash
pytest tests/models/multimodal/pooling/test_radio.py
pytest "tests/models/multimodal/generation_ppl_test/test_qwen.py::test_ppl" -k model_info1
```
