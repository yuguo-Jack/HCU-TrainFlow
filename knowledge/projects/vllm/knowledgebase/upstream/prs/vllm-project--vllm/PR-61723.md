# [Tests][XPU] Skip modelopt_fp4 online MoE re-quantization test on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/61723) · state: closed · merged: True

## Original PR description

## Overview

Skip the newly added `requantization_modelopt_nvfp4_fp8_moe` online-quantization test on XPU, since it loads a modelopt NVFP4 checkpoint whose base quantization format (`modelopt_fp4`) is not supported on XPU at all.

## Claims

- Fixes the Intel XPU CI "Quantization test" job failure introduced by #60276: `test_online_quantization[False-requantization_modelopt_nvfp4_fp8_moe]`.

## Validation

Root cause confirmed on actual XPU hardware:

```
$ python -m pytest tests/quantization/test_online.py -k requantization_modelopt_nvfp4_fp8_moe -v
...
E   pydantic_core._pydantic_core.ValidationError: 1 validation error for ModelConfig
E     Value error, modelopt_fp4 quantization is currently not supported in xpu.
```

After the fix, both the analogous existing `requantization_nvfp4_mxfp4_moe` case and the new `requantization_modelopt_nvfp4_fp8_moe` case skip cleanly on XPU:

```
$ python -m pytest tests/quantization/test_online.py -k "requantization_modelopt_nvfp4_fp8_moe or requantization_nvfp4_mxfp4_moe" -v
tests/quantization/test_online.py::test_online_quantization[False-requantization_nvfp4_mxfp4_moe] SKIPPED
tests/quantization/test_online.py::test_online_quantization[False-requantization_modelopt_nvfp4_fp8_moe] SKIPPED
2 skipped in 7.53s
```
