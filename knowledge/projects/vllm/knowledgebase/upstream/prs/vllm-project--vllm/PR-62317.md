# [KV Connector][NIXL] Read only a group's own regions in hybrid SSM transfers

[Upstream PR](https://github.com/vllm-project/vllm/pull/62317) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

In the NIXL hybrid (attention + SSM) descriptor path, every attention group read **all** registered regions. When some regions hold only another group's layers, every attention block re-reads those bytes, which that group's own descriptors already transfer. On GLM-5.3-Flash this made ~38% of the wire bytes duplicates.

`register_kv_caches` now records which transfer groups have layers in each region. `_compute_desc_ids` addresses only a group's own regions, for both attention and SSM groups. This generalizes the existing `CircularBufferSpec` special case (`_scratch_region_indices`, removed). The wire format is unchanged. See the example at the bottom.

## Results

P TP2 → D TP2 on separate GB300 nodes, pull mode, fp8 KV, scrambled KV pool, 2 runs per point.

| Model | ISL | Bytes / req (before → after) | Descs | Xfer avg | GSM8K via P/D (before → after) |
|---|---|---|---|---|---|
| GLM-5.3-Flash | 32k | 859,615,744 → 565,391,872 (−34%) | 950 → 646 | ~8.4 → ~5.2 ms | |
| GLM-5.3-Flash | 100k | 2,177,711,104 → 1,348,099,072 (−38%) | 2150 → 1306 | ~20.5 → ~12.4 ms | 81.8% → 80.6% (run-to-run 80.8–82.8%) |
| Qwen3.5-122B-A10B | 32k / 100k | identical | identical | | 40.8% → 41.2% (non-P/D 41.2%) |

- **Byte model:** a byte-level model of the descriptor layout reproduces every pre-fix measurement exactly (9 points). The 283,136 B left above the useful bytes is the tail page aliasing an indexer region and being read at the indexer's block length. That is region identity (base-address keying), which #57662 fixes, so it is out of scope here.
- **Unaffected layouts:** layouts where every group has a layer in every region (pure attention, non-SSM models through the fast path, Qwen3.5/Nemotron-style hybrids) produce the same descriptor ids as before.

## Notes for reviewers

- **Remote descriptor ids use the local group→region map.** This adds no new assumption. The hybrid path already builds remote ids from local `_ssm_region_indices`, `_ple_group_index` and `_scratch_region_indices`, and the handshake asserts identical per-region block lengths for hybrid MLA+SSM. If P and D group layers differently, per-group `block_ids` would already disagree.
- **SSM descriptor layout:** each SSM layer owns `ssm_regions_per_layer` consecutive descriptors, in `_ssm_region_indices` order. The layout is unchanged; only the subset of slots read changes.
- **Not a duplicate:** no open PR fixes this. #57662 is complementary: it keys regions by `(base_addr, block_len)`, i.e. what a region *is*, while this PR fixes which groups *own* it. Both touch the same lines in `register_kv_caches`, so whichever lands second needs a small rebase.

## Example: what main does at runtime

This is the layout of the new unit test (`kda_only_tensor=True`): one MLA group M and two KDA groups Ka and Kb, where Ka has one extra layer. There are 4 blocks per region, all drawn from one shared pool, so each block id belongs to exactly one group.

**1. `register_kv_caches`** keys regions by base address:

| Region | Tensor | Layers in it | `region_group_ids` |
|---|---|---|---|
| r0 | tensor0 | mla.0, kda_a.0, kda_b.0 | -1 (shared) |
| r1 | tensor1 | mla.1, kda_a.1, kda_b.1 | -1 (shared) |
| r2 | tensor2 | kda_a.2 | 1 (Ka) |

`_ssm_region_indices = [0, 1, 2]`. The hybrid path never consults `region_group_ids`.

**2. Local descriptor list:** one handle holding two views of the same tensors.
- FA descriptors are `d = r*4 + block`, giving d0–d11.
- SSM descriptors are `d = 12 + (slot*4 + k)*4 + block`, giving d12–d59 (4 sub-descriptors per layer).

**3. A request with `block_ids = ([1], [2], [3])`** takes the hybrid path in `_compute_desc_ids`:

| Group | main | This PR |
|---|---|---|
| M | `arange(num_regions)` → d1, d5, **d9** | d1, d5 |
| Ka | `arange(num_ssm_regions)` → slots r0, r1, r2 | slots r0, r1, r2 |
| Kb | `arange(num_ssm_regions)` → slots r0, r1, **r2** | slots r0, r1 |

- **d9** is tensor2 at block 1. Block 1 belongs to M, but M has no layer in tensor2.
- **Kb's r2 slot** is tensor2 at block 3. Block 3 belongs to Kb, but Kb has no layer in tensor2.

No layer ever writes those pages. Reading them doesn't corrupt anything, but every byte is wasted.

**On GLM-5.3-Flash** (11 DSA, 34 KDA in 4 groups, 11 `KPOOL_TAIL` layers; 40 regions per rank):
- The d9 case is every DSA block re-reading the 8 KDA-only regions (2.2 MB each) and the 10 tail-only regions (2 KB each).
- The Kb case is the two 8-layer KDA groups each reading one empty slot.

At 100k that is 829,612,032 of the 829,895,168 duplicate bytes measured. The remaining 283,136 B are the #57662 aliasing case.
