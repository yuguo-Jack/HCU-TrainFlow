# [Doc] Document ExampleConnector migration

[Upstream PR](https://github.com/vllm-project/vllm/pull/52373) · state: open · merged: False

## Original PR description

## Purpose

Document the migration from `SharedStorageConnector` to `ExampleConnector` and refresh the KV connector inventory in the disaggregated-prefill guide.

Related to #49399.

## Changes

### Add a migration note

Add a warning callout to `docs/features/disagg_prefill.md` that:

- States that `SharedStorageConnector` was renamed to `ExampleConnector` in #30201.
- Shows the updated `--kv-transfer-config` snippet.
- Clarifies that existing configurations only need to change the `kv_connector` value; `shared_storage_path` remains unchanged.

### Refresh the connector inventory

Replace the stale statement that the page supports “9 types of connectors” with the current `KVConnectorFactory` inventory:

- Document all 16 registered connector implementations.
- Group the connectors by purpose, including examples/debugging, LMCache, NIXL, local offloading, and other implementations.
- Note that availability can depend on the platform and optional dependencies.
- Keep the existing commonly used connector examples directly below the inventory.

## Scope

This is a documentation-only change. It does not change connector behavior, add a deprecated alias, or update external blog/tutorial examples.
