## Original PR description

## Purpose

This PR addresses a few consistency improvements across seqwise/tokwise:

1.  Fixed missing `None` guard for matryoshka dimensions in `TokenEmbeddingPoolerHead`.
2.  Make the `tokwise` public API consistent with `seqwise`  by exporting the analogous TokenPoolingFn and
  TokenPoolingHeadFn defined in tokwise/poolers.py
3. Added return type annotations  for `pooler_for_token_classify` , `pooler_for_embed`, and` pooler_for_classify`.
