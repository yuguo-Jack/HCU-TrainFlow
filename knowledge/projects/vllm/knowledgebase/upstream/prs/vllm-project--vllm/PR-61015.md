# [Misc][Attention] Warn when Triton attention is auto-selected on pre-…

[Upstream PR](https://github.com/vllm-project/vllm/pull/61015) · state: open · merged: False

## Original PR description

## Purpose

Part of #60821. Complements #55380 (FlashInfer restore on SM75); this PR does not change backend selection.

On pre-SM80 GPUs (e.g. Turing/T4), FlashAttention is unavailable and FlashInfer is currently disabled on SM75, so auto-selection falls back to `TRITON_ATTN` or `FLEX_ATTENTION`. With current Triton these kernels don't use tensor cores on these GPUs, so prefill is much slower, and users get no indication why.

This PR:
- Logs a one-time warning in `CudaPlatform.get_attn_backend_cls` when a Triton-based backend is auto-selected on a GPU with compute capability < 8.0.
- Adds a note to `docs/design/attention_backends.md` (Automatic Selection).
- Adds unit tests in `tests/v1/attention/test_pre_sm80_backend_warning.py`.

The warning is not emitted when the user explicitly selects a backend, and it does not suggest switching backends, since no faster backend is currently available on SM75.
