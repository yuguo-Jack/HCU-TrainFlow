# [Model Loader] Refill derived tensors with refill_derived (mHC broadcast, Muse Spark ROCm router planes, FlashInfer/b12x sinks)

[Upstream PR](https://github.com/vllm-project/vllm/pull/65526) · state: open · merged: False

## Original PR description



## Overview

Replaces the hand-rolled "assign on the first load, `copy_` in place afterwards" pattern with `refill_derived` (#64692) in four more places. Part of RFC #54477, tracker F8. Mirrors aoshen02/vllm#238 (authored by aoshen02), opened against `main`; the branch is two commits on top of upstream main 65a904538d.

## Claims

- `refill_derived` replaces the hand-written pattern in:
  - `finalize_mhc_broadcast_weights` in DeepSeek-V4 NVIDIA and DeepSeek-V4.1 NVIDIA / AMD.
  - `_router_planes` in Muse Spark ROCm.
  - FlashInfer and b12x fp32 attention sinks (#48251). For an fp32 source, `.to(fp32)` returns the source itself, so the `copy_` is a no-op and the alias is kept.
- This is an equivalent rewrite with no behavior change: `refill_derived` copies in place when shape, dtype and device match, and assigns otherwise.
- 6 files, −35 / +14.
