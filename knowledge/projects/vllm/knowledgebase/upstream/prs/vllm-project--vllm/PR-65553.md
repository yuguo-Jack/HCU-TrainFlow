# [GLM 5.3 Perf] Enable fp8 kv cache for glm 5.3 flash draft model dspark, 960MB GPU memory saved each rank

[Upstream PR](https://github.com/vllm-project/vllm/pull/65553) · state: open · merged: False

## Original PR description



## Overview

Let the DSpark draft inherit FP8 KV cache when GLM-5.3-Flash automatically selects FP8, instead of falling back to BF16.

With TP=4 and a full 2,048-token draft window, at 48 such requests, that is 960 MiB less draft KV data per GPU (3.75 GiB across four GPUs).

## Test

```bash
alias glm_serve_dspark="c 4 -- vllm serve $MODEL    --trust-remote-code     -tp 4     --load-format fastsafetensors     --gpu-memory-utilization 0.88     --enable-prefix-caching     --host 0.0.0.0     --port 9256     --max-model-len auto     --max-num-seqs 48     --kv-cache-dtype fp8     --speculative-config '{\"method\":\"dspark\",\"model\":\"$DRAFT_MODEL\",\"num_speculative_tokens\":8}'"
```
