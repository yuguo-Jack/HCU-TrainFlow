# [CI/Build] Add batch-invariance auto-label rule

[Upstream PR](https://github.com/vllm-project/vllm/pull/65238) · state: closed · merged: True

## Original PR description

## Overview

Add auto-label rules for the new `batch-invariance` label, so that all batch-invariance and determinism work can be found with one filter. 

## Claims

- **PRs (mergify):** a PR gets the label if it changes a file whose path contains `batch_invariant`, `batch-invariant` or `determinism`. It also gets the label if its title names batch invariance or determinism.
- **Issues (keyword workflow):** an issue gets the label if its title names batch invariance or determinism. Bodies are not checked.
- **Title patterns:**
  - batch- or TP-invariance
  - an uppercase `BI` tag
  - determinism, non-deterministic, not reproducible or run-to-run
  - batch-dependent
  - "identical / same / repeated runs, requests or calls"
- **Bare "deterministic":** PRs only. Issue titles use it for crashes that always reproduce, such as "deterministic illegal address".

## Validation

I ran both rules against every open item on 2026-11-02: 2,758 issues and 7,045 PRs, with their file lists.
- **Mergify:** I copied the regexes out of the edited `mergify.yml` and ran them with Python `re`.
- **Issue workflow:** I ran the real `github-script` code from the edited workflow in Node, with stubbed `context`/`github` objects.

| | Matched | False positives | Related but missed |
| --- | ---: | ---: | ---: |
| Open PRs | 106 | 10 | 10 |
| Open issues | 41 | 3 | 14 |

- **How I checked for misses:** I compared the matches against 13 GitHub searches (these also search comments) and read every result the rules did not catch.
- **PR false positives:** large formatting or lint PRs that happen to touch the batch-invariance files, plus "deterministic suffix mapping" and "batch size dependency" in the title.
- **Missed issues:** they mention batch invariance only in the body.
- **Backfill:** I already applied the label by hand to the 158 related open items (`is:open label:batch-invariance`).

`pre-commit run --files .github/mergify.yml .github/workflows/issue_autolabel.yml` passes, including actionlint and "Check auto-label rules still match real files".
