# [Bugfix][Rust Frontend] Export corrupted request metric

[Upstream PR](https://github.com/vllm-project/vllm/pull/59937) · state: closed · merged: True

## Original PR description



## Overview

The Rust frontend already decoded `EngineCoreOutput.num_nans_in_logits`, but the value was discarded before request metrics were recorded. Consequently, `/metrics` did not expose `vllm:corrupted_requests_total`, even when engine-core detected NaNs in request logits.

Track corruption across the complete request lifecycle and export the request-level counter already provided by the Python frontend. This restores visibility into numerical corruption that may indicate model, kernel, or hardware problems.
