# [CI] Run the remaining 4xL4 steps nightly only

[Upstream PR](https://github.com/vllm-project/vllm/pull/62883) · state: closed · merged: True

## Original PR description

## Purpose

Follow-up to #62564, which made the eight heaviest 4-GPU L4 steps nightly-only. This marks the remaining seven `optional: true`, so no 4xL4 step runs automatically on PRs:

| Step | PR L4 GPU-h/day | share of PR builds it ran in |
|---|---|---|
| (L4) LoRA TP (Distributed) | ~110 | 22% |
| (L4) RayExecutorV2 | ~80 | 26% |
| (L4) Distributed Torchrun + Examples | ~35 | 25% |
| (L4) Rust Frontend Distributed | ~29 | 28% |
| (L4) Distributed Compile + Comm | ~12 | 18% |
| (L4) EPLB Execution | ~12 | 15% |
| (L4) Qwen4 Exp SP | ~3 | 18% |
| **total** | **~281** (≈40% of PR L4 GPU time) | |

Measured from Buildkite jobs on PR builds between #62564 landing (Oct 19 22:15 UTC) and Oct 21 06:00 UTC, GPU-hours = job duration × `num_devices`.

Same as #62564:
- Labels get the `[Nightly]` prefix.
- They still run on nightly (`NIGHTLY=1` / `ready-run-all-tests`), and a PR can run them from the "Run …" block.
- The AMD mirrors keep running on PRs (`optional: false` on the mirror), as #62567 did for the first eight.

PRs keep multi-GPU NVIDIA coverage through the 2-GPU L4 steps (e.g. Distributed Comm Ops, Distributed Model Tests, NixlConnector PD accuracy core, Plugin Tests).

## Test Plan

Ran ci-infra `main`'s `_step_should_run` / `_get_amd_mirror_effective_step` / `_amd_mirror_should_run` on the edited YAML with a diff touching each step's first source dependency:
- PR build: 0/7 L4 steps selected, 7/7 AMD mirrors selected.
- Nightly build: 7/7 L4 steps and 7/7 AMD mirrors selected.
