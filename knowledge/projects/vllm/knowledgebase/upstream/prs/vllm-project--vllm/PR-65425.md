# [ROCm][CI] Restore the Torch Stable ABI Audit mirror with a locked audit tool

[Upstream PR](https://github.com/vllm-project/vllm/pull/65425) · state: closed · merged: True

## Original PR description

## Overview

Restores the `(MI300) Torch Stable ABI Audit` mirror that #63608 disabled, by locking `torch-abi-audit` in the ROCm test requirements instead of installing it at job runtime.

## Claims

- Closes the only AMD parity gap in the Torch ABI area, 0% to 100%.
- Drops the runtime `uv pip install` that got the job disabled.

## Validation

`.buildkite/check-torch-abi.py` on a gfx950 build:

```
>>> Auditing vLLM extension modules for PyTorch stable ABI compliance
Torch stable ABI check passed.
```

## Details

`torch-abi-audit` is in `requirements/test/cuda.in` but was missing on the ROCm side, so the mirror added in #50519 had to fetch it during the job. Declaring it in `requirements/test/rocm.in` removes that, which is the condition #63608 asked for.

Pinned to `0.0.1` to match the cuda and cpu locks. The first CI run rebuilds the runtime and test-deps images, since `requirements/test/rocm.txt` feeds their key; the stack key is untouched.
