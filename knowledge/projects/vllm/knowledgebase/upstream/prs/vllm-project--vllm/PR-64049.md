# [CI] Bump Transformers version to 5.21.1

[Upstream PR](https://github.com/vllm-project/vllm/pull/64049) · state: closed · merged: True

## Original PR description



## Overview

Bump Transformers to [v5.21.1](https://github.com/huggingface/transformers/releases/tag/v5.21.1). Follows #61983.

## Claims

- `requirements/common.txt` allows `transformers >= 5.16.1, < 5.22.0`.
- CI pins 5.21.1, which adds huggingface/transformers#50080 on top of 5.21.0. That fixes the `rope_scaling` setter regression from huggingface/transformers#49515, which broke remote-code configs (Phi-3/3.5, Phi-4-multimodal, InternVL2, InternLM2.5, Step-3.7), `Step5Config` and the EAGLE3 speculators config (`rope_theta=None`).
- MiniCPM-V 4.6 passes `downsample_mode` to `find_best_resize`/`get_refine_size` on 5.21, which made it required and changed alignment in `"4x"` mode.
- Keye-VL-1.5's remote processor breaks on 5.21 (`convert_to_rgb` rejects tensors); Keye was removed in #64287.
- The 5.21 TP plan changes (huggingface/transformers#49570) do not affect the Transformers modeling backend, which detects vocab embeddings itself.

## Validation

- First `/ci run nightly` on 5.21.0 ([build 97620](https://buildkite.com/vllm/ci/builds/97620)): 37 of 41 failures came from the bump. The other 4 also fail on `main`.
- `test_common.py -k MiniCPM-V-4_6`: 3 failed on Transformers `main` without the fix, 3 passed with it, and passes on 5.20.
- Configs vLLM resolves for 384 checkpoints (test registry plus speculator drafts), 5.20 vs Transformers `main` vs `main` + #50080: only Step-5-Preview and `nm-testing/Llama3_2_1B_speculator.eagle3` change on `main`, and both match 5.20 with the fix.
- The package mirror lacks 5.21.1, so only the pin lines were edited (`pip-compile` skipped locally); CI pre-commit verifies the lockfiles.
- Second `/ci run nightly` on `v5.21-release` ([build 97995](https://buildkite.com/vllm/ci/builds/97995)): 7 failures, all also failing on `main` (HiSparse/MLA attention, Humming Activation, BMG V1).
- `/ci run` on 5.21.1 (identical code to `v5.21-release`): pending.
