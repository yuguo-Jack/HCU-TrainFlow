# docs: Add Apple Silicon/Metal execution requirements to quickstart

## Original PR description

## Summary
This PR adds clarity to the quickstart documentation for Apple Silicon (vLLM-Metal) users by:

1. **Enhanced compatibility warning** at the top of the quickstart explaining that vLLM-Metal uses MLX (not PyTorch) and requires MLX-optimized models
2. **Model compatibility note** in the offline inference section warning users that standard models like `facebook/opt-125m` won't work with Metal backend
3. **Recommended alternative** pointing users to MLX-community models from Hugging Face
