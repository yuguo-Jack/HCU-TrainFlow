# Add routed-expert prefix omission for AuxOutput

[Upstream PR](https://github.com/vllm-project/vllm/pull/57966) · state: open · merged: False

## Original PR description



## Purpose

Add opt-in routed-expert prefix omission on top of the AuxOutput implementation introduced in #45635.

In multi-turn agentic RL, callers can retain routes returned by earlier requests. Returning those routes again for a cached prefix adds redundant output assembly and transfer costs.

This PR:
- Adds `--enable-omit-prefix-routed-experts`, requiring routed-expert return and prefix caching.
- Records `request.num_cached_tokens` from the first successfully admitted cache hit and preserves it across preemption and cache resets.
- Starts route emission at the maximum of the existing output start and `num_cached_tokens`, excluding omitted prefix blocks from payload materialization.
- Requires a stable `x-session-id` and incorporates it into the existing cache salt, with idempotent handling across render and generate paths.

When omission is enabled, callers are responsible for retaining previously returned routes and correctly assembling them with newly returned routes. Behavior with omission disabled remains unchanged.

This PR does not add KV offloading support or change expert storage dtype, worker-side capture, or D2H transfers.

Related RFC: #56402.
