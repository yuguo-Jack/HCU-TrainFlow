# [Bugfix][Model Loader] Reject colliding sharded checkpoint part filenames

[Upstream PR](https://github.com/vllm-project/vllm/pull/62455) · state: open · merged: False

## Original PR description

## Overview

`ShardedStateLoader.save_model()` can silently overwrite earlier checkpoint parts when a custom filename pattern renders the same name for multiple parts. Plan the parts and validate their rendered filenames before writing any files.

Related: #52110 added validation against PP/TP rank filename collisions. This fixes collisions between parts within one rank; it does not change parallel rank validation.

## Claims

- Reject colliding part filenames before modifying an existing checkpoint or writing a partial export.
- Cover missing and escaped `{part}` fields, as well as lossy formatting that causes a later part to collide with an earlier one.
- Preserve default naming, shard boundaries, tensor contents, and valid single-file patterns that do not contain `{part}`.

## Details

The exporter previously rendered and wrote each part immediately, without checking whether a later part would reuse the same filename. Checking only for a `{part}` placeholder is insufficient: `{part!s:.1}` maps both part 1 and part 10 to `1`.

The change first builds the same part dictionaries as before, renders all filenames, and checks uniqueness. It then writes the planned parts. Planning retains additional Python dictionaries/references; it does not clone tensor storage. There is no new dependency, configuration option, or serving-path work.

This is not a transactional checkpoint writer: unrelated filesystem/write failures can still leave a partial export, as before. It does not change the policy for an existing output directory, recover an already overwritten export, or address arbitrary filesystem aliases. Integer-only formatting of `{part}` during loading is an independent existing limitation because the loader substitutes `"*"`; this PR does not expand pattern syntax.

Duplicate-work check on 2026-10-19: searched open and closed PRs by sharded-state titles, the loader name, `{part}`, filename/collision/overwrite terms, and inspected #52110's discussion. #51352 changes the offline example's output-directory validation, #61432 addresses strided tensors, and #62231 addresses attention-scale round trips. None of those is the same part-filename collision fix. No new public Issue was opened for this independently reproduced defect.

<summary>Reproduce the manual single-GPU export/reload check</summary>

Save the following as `gpu_roundtrip.py` outside the vLLM checkout. It is a manual integration check, not part of the proposed source change or a performance benchmark. Run from the patched repository root after installing vLLM and downloading `Qwen/Qwen3-0.6B` at revision `c1899de289a04d12100db370d81485cdf75e47ca`. Point `--model` at that local snapshot and `--output` at an empty results directory.

```python
"""Manual single-GPU integration check; run each phase in a fresh process.

Not a performance benchmark. The export and reload phases must use the same
checkout, environment, model metadata, and deterministic generation settings.
"""

import argparse
import hashlib
import json
from pathlib import Path
import shutil
import subprocess

import torch

from vllm import LLM, SamplingParams


PROMPTS = [
    "Hello, my name is",
    "The capital of France is",
    "Write a Python function to add two numbers:",
    "Explain what a computer does in one sentence:",
]
PATTERNS = {
    "default": None,
    "custom": "custom-rank-{rank}-part-{part}.safetensors",
}


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("phase", choices=["export", "reload"])
    parser.add_argument("--model", type=Path, required=True)
    parser.add_argument("--output", type=Path, required=True)
    parser.add_argument("--variant", choices=PATTERNS, default="default")
    args = parser.parse_args()
    args.output.mkdir(parents=True, exist_ok=True)
    checkpoint = args.output / args.variant
    extra = {}
    if args.phase == "export":
        model_path = args.model
    else:
        model_path = checkpoint
        extra = {
            "load_format": "sharded_state",
            "model_loader_extra_config": {"pattern": PATTERNS[args.variant]},
        }
    llm = LLM(
        model=str(model_path),
        dtype="float16",
        tensor_parallel_size=1,
        max_model_len=2048,
        max_num_seqs=1,
        gpu_memory_utilization=0.7,
        enforce_eager=True,
        seed=0,
        **extra,
    )
    outputs = llm.generate(
        PROMPTS, SamplingParams(temperature=0, max_tokens=32, ignore_eos=True)
    )
    tokens = [list(result.outputs[0].token_ids) for result in outputs]
    record = {
        "phase": args.phase,
        "variant": args.variant,
        "sha": subprocess.check_output(
            ["git", "rev-parse", "HEAD"], text=True
        ).strip(),
        "loader_sha256": hashlib.sha256(
            Path("vllm/model_executor/model_loader/sharded_state_loader.py").read_bytes()
        ).hexdigest(),
        "torch": torch.__version__,
        "cuda": torch.version.cuda,
        "gpu": torch.cuda.get_device_name(0),
        "token_ids": tokens,
        "texts": [result.outputs[0].text for result in outputs],
    }
    reference = args.output / f"{args.variant}-export.json"
    if args.phase == "export":
        checkpoint.mkdir(exist_ok=False)
        llm.llm_engine.engine_core.save_sharded_state(
            path=str(checkpoint),
            pattern=PATTERNS[args.variant],
            max_size=16 * 1024**2,
        )
        shards = sorted(checkpoint.glob("*.safetensors"))
        assert len(shards) > 1, "Workload must actually export multiple parts"
        record["shard_files"] = [file.name for file in shards]
        for file in args.model.iterdir():
            if file.is_file() and file.suffix in {".json", ".txt", ".model", ".jinja"}:
                shutil.copy2(file, checkpoint / file.name)
    else:
        expected = json.loads(reference.read_text())
        assert record["sha"] == expected["sha"]
        assert record["loader_sha256"] == expected["loader_sha256"]
        assert tokens == expected["token_ids"], "Reloaded greedy token IDs differ"
        record["exact_token_ids_match"] = True
    result_path = args.output / f"{args.variant}-{args.phase}.json"
    result_path.write_text(json.dumps(record, indent=2) + "\n")
    print(f"PASS: {result_path}", flush=True)


if __name__ == "__main__":
    main()
```

```bash
for variant in default custom; do
  for phase in export reload; do
    PYTHONPATH=. HF_HUB_OFFLINE=1 .venv/bin/python ../gpu_roundtrip.py "$phase" \
      --variant "$variant" \
      --model /path/to/local/Qwen3-0.6B \
      --output /path/to/empty/results
  done
done
```

Each phase runs in a separate Python process. The export phase generates the reference token IDs, writes actual shards, and copies model metadata. The reload phase loads those shards and asserts exact equality of generated token IDs.
