# [Bugfix][HiSparse] Preserve host prefix publication after request completion

[Upstream PR](https://github.com/vllm-project/vllm/pull/59007) · state: closed · merged: True

## Original PR description

With HiSparse, a request can reach EOS or its output limit in the same step that reports completed host writes. The scheduler handles the final token and cleans up the request before processing the transfer acknowledgements from that same output. Any prefix publication still waiting for those acknowledgements is discarded, leaving valid host KV unavailable for reuse.

This PR preserves the publication information and host-page references until acknowledgement, then publishes the valid pages for reuse.
