# [Bugfix][LoRA] Skip MoE-LoRA shrink/expand when no LoRA is active

[Upstream PR](https://github.com/vllm-project/vllm/pull/65051) · state: closed · merged: True

## Original PR description

## Overview

Skip the MoE-LoRA shrink/expand launches when there are no active LoRAs, fixing a segmentation fault on XPU in `test_fused_moe_lora_kernel_zero_grid_no_crash[two_kernel]` ([Intel CI build 16155](https://buildkite.com/vllm/intel-ci/builds/16155#01a19356-b9b6-4244-a603-173c195758e5)). Follow-up to #64653.

## Claims

- `_fused_moe_lora_shrink` / `_fused_moe_lora_expand` no longer launch a Triton grid with a zero dimension when `num_active_loras == 0`.
- The output is left unchanged in that case, as the existing test asserts.

## Validation

- Before: `pytest tests/lora/test_fused_moe_lora_kernel.py -k zero_grid_no_crash` on XPU (Arc Pro B60, torch 2.14) -> `Fatal Python error: Segmentation fault`.
- After: `pytest tests/lora/test_fused_moe_lora_kernel.py` on XPU -> 463 passed.
- `ruff check` / `ruff format --check`: passed.
