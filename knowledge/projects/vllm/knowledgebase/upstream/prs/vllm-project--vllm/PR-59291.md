# [Test][MRV2] Cover draftless thinking-budget row mapping

[Upstream PR](https://github.com/vllm-project/vllm/pull/59291) · state: open · merged: False

## Original PR description

Refs #59272.

## Summary

Replaces the original Model Runner V1 patch with Model Runner V2 coverage, as requested in review.

Model Runner V2 does not use the MRV1 `cu_num_tokens` dictionary that caused every request to map to row 0 on a draft-less speculative step. Its no-draft path sets `expanded_idx_mapping == idx_mapping`, giving each request one logits row, and `ThinkingBudgetState` applies forcing through that explicit row-to-request mapping.

This PR adds a two-request GPU regression test that reproduces the important boundary condition: both requests have exhausted their thinking budgets, the speculative step has no drafts, and both corresponding logits rows must independently force the reasoning end token. This protects the V2 invariant against the cross-request row corruption described in #59272.

## Why there is no implementation change

The reported failure is specific to the deprecated MRV1 layout calculation. The equivalent V2 path already has the correct mapping, so carrying the MRV1 fix forward would change a non-default runner without addressing the maintainer's request. The updated PR tests the supported implementation instead of claiming a V2 bug that is not present.
