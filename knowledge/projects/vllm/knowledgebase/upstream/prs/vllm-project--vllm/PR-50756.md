# [Feature][Core] Allow expert override for insufficient KV cache capacity

[Upstream PR](https://github.com/vllm-project/vllm/pull/50756) · state: open · merged: False

## Original PR description

## Summary
- Add `VLLM_ALLOW_INSUFFICIENT_KV_CACHE` as an expert-only startup override.
- Keep the default hard failure when max_model_len does not fit the estimated KV cache budget.
- When explicitly enabled, downgrade only that capacity failure to a detailed warning and continue.
- Preserve the hard failure for `available_memory <= 0`.

Refs #50509
