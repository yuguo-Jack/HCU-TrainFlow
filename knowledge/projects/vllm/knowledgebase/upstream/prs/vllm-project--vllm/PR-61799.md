# [Bugfix][LoRA] Account for CLIP CLS rows in LLaVA tower mappings

[Upstream PR](https://github.com/vllm-project/vllm/pull/61799) · state: open · merged: False

## Original PR description

## Overview

Count CLIP's CLS row before feature selection when sizing LLaVA tower LoRA buffers and building each image's mapping. Ten images produce 5,760 selected embeddings, but the tower processes 5,770 rows; using the selected count can fail engine profiling or map later rows to the wrong adapter. Connector counts and non-CLIP configurations keep their existing behavior.

This covers the LLaVA item in #61608. The related #62097 handles LLaVA-NeXT-Video in a different model file; it does not replace this fix.

## Claims

- LLaVA's CLIP tower count includes CLS rows before feature selection; connector and non-CLIP counts keep their existing behavior.
- The review follow-up removes only the newly added regression file and leaves the runtime implementation unchanged.

## Validation
