# [Bugfix][DP] Ignore stale per-engine coordinator stats

[Upstream PR](https://github.com/vllm-project/vllm/pull/52936) · state: open · merged: False

## Original PR description

## Summary

- track scheduler stats positions independently for each data-parallel engine
- accept delayed cross-engine reports and same-step metric refreshes
- warn and ignore only reports that move backwards for the same engine
- keep per-engine tracking aligned with Elastic EP scale-up and scale-down

## Problem

The coordinator compared reports from independent DP engines against one global
`(wave, step)` position. A valid report from a slightly slower engine could
therefore be classified as out of order after a faster engine had advanced,
producing large volumes of false warnings under concurrent DP workloads.

## Duplicate check

I searched open PRs and issues for the exact warning text and for DP coordinator
stale-stat fixes. I did not find another open PR implementing per-engine stats
ordering. The unrelated search results address model support, KV admission, or
other DP failures rather than this coordinator warning.
