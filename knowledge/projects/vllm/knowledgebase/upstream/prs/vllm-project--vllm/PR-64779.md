# [Deps] Upgrade to huggingface_hub 2

[Upstream PR](https://github.com/vllm-project/vllm/pull/64779) · state: closed · merged: True

## Original PR description



## Overview

Require `huggingface_hub >= 2.0.0` and lock CI to 2.4.0. Depends on #63122.

## Claims

- Hub 1.32+ deduplicates Xet files across repos in the cache, so checkpoints copied into `vllm-project` (#64762) share disk with any other repo that has the same files.
- `tokenizers >= 0.23.3` (0.23.2 caps hub < 2) and `timm >= 1.0.30` (older timm imports `repo_type_and_id_from_hf_id`, removed in hub 2) are bumped alongside.
- The xpu lockfile also moves `datasets` 5.0.1 -> 5.1.0.

## Validation

```console
$ uv run --with huggingface_hub==2.4.0 --with tokenizers==0.23.3 --with timm==1.0.30 \
    pytest tests/v1/kv_connector/unit/test_mooncake_connector.py \
      tests/plugins_tests/lora_resolvers/test_hf_hub_resolver.py tests/transformers_utils
2 failed, 282 passed
```

The 2 failures are `test_register_worker_{retries_on_read_timeout,raises_after_max_attempts}`, which mock top-level `httpx` while the connector uses `httpx2` under hub 2; #63122 fixes them. `timm.create_model("hf-hub:...")` loads under hub 2.4.0. Lockfiles were compiled against pypi.org because the HF mirror lacks `transformers==5.22.0`.
