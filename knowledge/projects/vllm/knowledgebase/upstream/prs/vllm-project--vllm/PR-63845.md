# feat(moriio): add version/mode compatibility check to connector handshake (Gap 12)

[Upstream PR](https://github.com/vllm-project/vllm/pull/63845) · state: closed · merged: False

## Original PR description

## Summary

- Add `MORIIO_HANDSHAKE_VERSION` constant and `handshake_version`/`mode` fields to `MoRIIOAgentMetadata` so mismatched peers are rejected during the ZMQ handshake
- `_validate_handshake_compat()` in `MoRIIOConnectorWorker` checks:
  - Version mismatch (hard reject via `HandshakeError`)
  - Same-mode peers, e.g. both READ or both WRITE (soft warning)
  - Block length mismatch (hard reject)
  - Attention backend mismatch (soft warning)
- Legacy peers (version=0 / missing fields) accepted with warning for rolling upgrades
- Unit tests for field defaults, msgspec round-trip, and legacy peer decode

Related: ROCm/mori#759

- [ ] `test_moriio_handshake_compat.py`: field defaults, msgspec round-trip, legacy peer decode, constant verification
