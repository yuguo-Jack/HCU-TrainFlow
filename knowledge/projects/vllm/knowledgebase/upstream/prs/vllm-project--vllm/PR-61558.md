# [Bugfix][Multiproc] Fail fast on remote worker disconnects

[Upstream PR](https://github.com/vllm-project/vllm/pull/61558) · state: open · merged: False

## Original PR description

## Overview

Propagate remote-worker and coordinator disconnects through the multiprocessing executor's failure/shutdown path. Local process sentinels cannot detect a worker exiting on another host. **Depends on #53597; merge that prerequisite first.**

Reuse ZMQ disconnect monitors and cancellable response reads; preserve buffered replies, ordinary receive timeouts, and normal shutdown. No heartbeat protocol or new configuration. This does not fix the original CUDA fault, silent network partitions, or inherited stale utility replies.
