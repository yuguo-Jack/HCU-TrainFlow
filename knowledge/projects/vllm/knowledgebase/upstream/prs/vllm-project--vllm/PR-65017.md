# [Distributed] Make the shm tensor arena's slot count and slot size configurable

[Upstream PR](https://github.com/vllm-project/vllm/pull/65017) · state: closed · merged: False

## Original PR description

## Purpose

The shm tensor arena (`--enable-shm-tensor-arena`) has a fixed slot count and slot size. With large images at high concurrency, requests exceed the arena and fall back to the slow path (pickled tensors): we counted 1,300+ fallbacks in one 8-row image sweep. This adds `--shm-tensor-arena-slots` and `--shm-tensor-arena-slot-mb` (defaults = today's values) so deployments can size the arena for their traffic.

Open question for maintainers: whether you prefer these knobs or a structural fix (arena that grows, or slot sizing from the model's max mm payload).

## Test Plan

- Unit test for the option plumbing and defaults.

## Test Result

MiniMax-M3 VL (image) on MI355X, TP2, 8-row image sweep, 128 slots x 48 MB vs default (A B B A): arena fallbacks 1,300+ → 0, TTFT **+9.1%** better, output throughput +0.2% (neutral).
