## Original PR description

## Purpose

Adds AI Badgr as an optional hosted GPU launch path for vLLM users.

The value is that vLLM deployments require GPU capacity, health checks, endpoint management, and cost control. This documentation update gives users another way to launch a preconfigured vLLM endpoint on hosted GPU infrastructure without changing existing deployment paths.

AI Badgr launch template:

https://aibadgr.com/gpu/launch?template=vllm

Example command:

```bash
badgr serve template vllm --max-cost 5
```

This is a documentation-only change and does not modify vLLM runtime behavior, APIs, scheduling, serving logic, model execution, or performance.
