# [Logging] Add JIT compilation progress log for FlashInfer

[Upstream PR](https://github.com/vllm-project/vllm/pull/38462) · state: closed · merged: False

## Original PR description

Fix #38246 — FlashInfer silently JIT-compiles CUDA kernels on first use, potentially taking several minutes with no log output, making it appear as a hang.

## Changes

- `vllm/utils/flashinfer.py`: add `_install_jit_build_logging()` which patches `flashinfer.jit.JitSpec.build` at module import time. Every FlashInfer JIT compilation (attention decode/prefill, MLA, sampling, etc.) goes through this method, so a single patch covers all call-sites.
- `vllm/v1/attention/backends/flashinfer.py`: remove the previous attention-specific logging from `fast_plan_decode`.

## Expected log output

```
INFO: FlashInfer is JIT-compiling CUDA kernels (<module_name>). This may take several minutes...
INFO: FlashInfer JIT compilation complete (<module_name>, took X.X s).
```

## Test plan

Logging-only change with no logic modifications. Manual verification confirms logs fire only when compilation actually occurs (`JitSpec.build` is not called for pre-built AOT binaries).
