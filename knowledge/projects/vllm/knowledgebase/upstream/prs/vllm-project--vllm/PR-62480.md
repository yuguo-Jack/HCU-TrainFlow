# [ROCm][Kernel] Add W4A8 MoE decode kernel for RDNA3/RDNA3.5 (gfx11)

[Upstream PR](https://github.com/vllm-project/vllm/pull/62480) · state: open · merged: False

## Original PR description

Add moe_w4a8_decode_rdna3, a fused int4-weight x int8-activation MoE decode op for gfx11, and the opt-in WNA16 MoE backend rdna3_w4a8 (--moe-backend rdna3_w4a8).

The op reads the TritonWNA16Experts weight layout directly (uint8 codes, optional nibble-packed zero points), quantizes activations to int8 per 32 values and reduces with v_dot4_i32_iu8 in three launches without atomics. Rdna3W4A8Experts uses it for up to 8 tokens with SiLU and falls back to the Triton WNA16 kernels otherwise.

On Strix Halo (gfx1151) with Qwen3.6-35B-A3B UINT4-G128 at batch size 1 this lowers routed-expert time from 14.4 to 4.27 ms per token and TPOT from 29.41 to 20.62 ms (512 in / 512 out); GSM8K 100q is 87% vs 88% with Triton.
