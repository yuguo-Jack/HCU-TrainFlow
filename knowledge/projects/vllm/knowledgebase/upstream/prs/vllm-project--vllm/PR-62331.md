## Overview

Explain the implicit reasoning-end masking introduced in #61574, following the [documentation request](https://github.com/vllm-project/vllm/pull/61574#pullrequestreview-5543234444).

## Claims

- Clarify the exception to `enable_in_reasoning=False`: engine-based parsers mask single-token implicit ends that cannot start the request's grammar.
- Explain that grammar-valid implicit ends, explicit reasoning ends and other reasoning tokens remain allowed by this reasoning-phase mask.
