# [Spec Decode] Support the Liquid LFM2.5-VL DSpark drafter

[Upstream PR](https://github.com/vllm-project/vllm/pull/61352) · state: open · merged: False

## Original PR description

## Overview

Enable `LiquidAI/LFM2.5-VL-3B` with its official DSpark drafter, reusing vLLM's existing dense DSpark implementation.

## Claims

- Normalize the draft architecture, interleaved RoPE flag, and confidence-head layout before model inspection.
- Expose trained LFM2 target features through the VL wrapper and include speculative history in ShortConv cache planning.
- Add focused regression tests and a documented usage example.

## Details

The published drafter is attention-only and Qwen3-shaped; no new draft class, scheduler, runner, or kernel is added. Target capture reconstructs full residual streams using the existing layer-index convention.

Open/closed searches found no direct integration duplicate. [SGLang #40651](https://github.com/sgl-project/sglang/pull/40651) implements a different engine and uses `tugot17/mango-9`. Related vLLM PRs [#44296](https://github.com/vllm-project/vllm/pull/44296) and [#59600](https://github.com/vllm-project/vllm/pull/59600) address target rollback and ShortConv drafter recovery, respectively; those paths are unchanged here.

Pipeline-parallel capture is unsupported. CUDA graphs, mixed batches, async scheduling, adaptive verification, and prefix caching were not evaluated for this pair.

AI assistance (Codex) was used for implementation, review, and validation. The human submitter reviewed every changed line and ran the relevant tests/model evaluations.
