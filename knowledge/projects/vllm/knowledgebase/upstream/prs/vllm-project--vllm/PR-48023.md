# [Bugfix][Spec Decode] Draft model inherits model_weights when target is loaded from object storage

[Upstream PR](https://github.com/vllm-project/vllm/pull/48023) · state: open · merged: False

## Original PR description

## Purpose

Fix #42060: with `--load-format runai_streamer` and an `s3://` model, enabling MTP speculative decoding crashes at drafter load:

```
RuntimeError: Cannot find any safetensors model weights with ~/.cache/vllm/assets/model_streamer/<hash>
```

**Root cause:** for object-storage models, `ModelConfig` rewrites `model` to a local config-only cache dir (no safetensors) and keeps the URL in `model_weights`. Draft models that share the target checkpoint (`mtp`, `dspark`) are built from `target_model_config.model`, so their `model_weights` stays empty and the RunAI loader falls back to the config-only cache dir.

**Fix:** in `DraftModelSpeculatorConfig.configure()` (`vllm/v1/worker/gpu/spec_decode/speculator_config.py`), right after the draft `ModelConfig` is constructed, inherit `target_model_config.model_weights` whenever the draft shares the target checkpoint path. MTP and DSpark both go through this method.

### Relation to #42079 (merged 2026-08-21, which closed #42060)

#42079 seeds the draft model source with `target_model_config.model_weights or target.model`; since #63205 that seed lives in `MTPSpeculatorConfig.default_model()`, which `SpeculativeConfig.__post_init__` only calls when `speculative_config.model is None`. In the real `runai_streamer` path, `speculative_config.model` already arrives populated with the local config-only cache dir, so the seed never runs and the drafter still fails with the error above — E2E analysis and a standalone repro at https://github.com/vllm-project/vllm/pull/42079#issuecomment-4785438700. The two fixes are therefore complementary, not duplicates:

| path | `model is None` (e.g. plain `LLM(speculative_config={"method": "mtp", ...})` with no `model`) | `model = <local streamer cache dir>` (production runai path) |
| --- | --- | --- |
| seed in `MTPSpeculatorConfig.default_model()` (#42079) | ✅ sets draft source to the S3 URL | ❌ not called |
| draft-config inheritance (this PR) | ✅ | ✅ |

`test_mtp_draft_inherits_weights_when_model_is_prefilled_cache_dir` pins the second column and asserts the #42079 seed did not run.

**Note for #61715 reviewers:** that PR's `_inherit_dspark_weights_uri` implements the same checkpoint-sharing inheritance at the loader layer for DSpark. If this PR lands first, 61715 can drop its copy; this config-level version also covers MTP.

### Rebase note (2026-11-02)

#63205 moved draft `ModelConfig` construction out of `vllm/config/speculative.py` into the speculator config classes, which deleted the block this fix used to live in. Rebased onto current `main`: `speculative.py` is now untouched, the inheritance moved to `DraftModelSpeculatorConfig.configure()` unchanged (with the trimmed comment from review), and the two regression tests adopt the same patch target (`vllm.config.ModelConfig`) and mock fields that #63205 gave #42079's test.
