# [Model] Add Mistral Large 4

[Upstream PR](https://github.com/vllm-project/vllm/pull/64534) · state: open · merged: False

## Original PR description

Mistral Large 4 support for vLLM, shared as an open working branch. This PR is not meant to be merged as is; generic pieces are being upstreamed in separate PRs.

- Mistral-Large-4-1T-A52B (FP8) and -NVFP4 on model runner V2
- Sparse MLA with the DSA indexer, cross-layer KV sharing, SSMax
- DSpark speculative decoding
- DCP/PCP long context, NIXL P/D, HiSparse host KV offload
- NVIDIA (Blackwell, Hopper) and AMD ROCm (MI350 Series) kernels

Recipe: https://recipes.vllm.ai/mistralai/Mistral-Large-4-1T-A52B

AI assistance was used for this change.
