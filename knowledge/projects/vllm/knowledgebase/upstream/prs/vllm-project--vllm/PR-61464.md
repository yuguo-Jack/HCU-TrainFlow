# [MRV2][DBO] Support DBO with speculative decoding and DCP

[Upstream PR](https://github.com/vllm-project/vllm/pull/61464) · state: open · merged: False

## Original PR description

Lift the V2 runner's rejection of DBO combined with speculative decoding or decode context parallelism (prefill context parallelism stays gated).

Spec decode:
- Draft prefill (EAGLE/MTP, extract_hidden_states) reuses the target's full-batch attention metadata and slot mappings, and its FULL graphs read the target builders' buffers. A microbatched step only builds them per microbatch, so build the full-batch metadata after the forward when a speculator is present.
- Split uniform multi-token batches (verification) on a request boundary. A midpoint split cuts a request in two whenever the request count is odd, so neither microbatch is a uniform decode and backends that need uniform decodes run them down the prefill path, which FULL graphs cannot capture. The split uses the DP-agreed uniform token count, or the graph's own for FULL replay, so ranks and capture/replay agree.

DCP: per-microbatch dcp_local_seq_lens slicing (#55212) and per-microbatch DCP communication buffers were already in place; only the gate remained.

Add GSM8K e2e tests for V2 DBO with ngram spec decode and with DCP.

How about the NgramGPUSpeculator? In the `propose` it does not really use the `att_metadata`.
I guess we do not want to call `ubatch_state.build_full_batch_attn` for it.

How about adding a new field in the class BaseSpeculator?

```patch
 class BaseSpeculator(ABC):
     num_query_per_req: int = 1
     # Extra query slots reserved per request outside the regular queries.
     num_extra_query_per_req: int = 0
+    needs_target_attn_metadata: bool = True
```

This way the NgramGPUSpeculator can opt out while the others can keep requiring it (with the default `True`).

```patch
class NgramGPUSpeculator(BaseSpeculator):
     """V2-compatible GPU n-gram speculator."""
 
     supports_mm_inputs = False
+    needs_target_attn_metadata = False
     draft_logits = None

```

and the check can become:

```patch
-if ubatch_state is not None and self.speculator is not None:
+if ubatch_state is not None and (
+    self.speculator is not None and self.speculator.needs_target_attn_metadata
+):
     # Draft prefill reuses the target's full-batch attention metadata.
     attn_metadata, slot_mappings_by_layer = ubatch_state.build_full_batch_attn()
```
