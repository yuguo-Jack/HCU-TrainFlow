# [Feature] Red-Green watermarking

[Upstream PR](https://github.com/vllm-project/vllm/pull/60738) · state: open · merged: False

## Original PR description



## Overview

Adds the red-green watermark of [Kirchenbauer et al. (2023)](https://arxiv.org/abs/2301.10226). The implementation is built on top of the watermarking infrastructure introduced in #53916 / #54053.

## Claims

- `--watermark-config '{"algorithm": "red_green", "key": 42}'` adds `delta` (default 2.0) to the logits of a green list. The green list is computed using the Philox PRF from the key and the last `context_width` tokens (default 4).  The variable `gamma` (default 0.25) specifies the probability of each token being in the green list.
- `RedGreenWatermarkDetector` returns a one-sided binomial p-value for a given token sequence.
- Speculative decoding works with `allow_target_only_watermarking: true`. Drafts are verified against the watermarked logits, so accepted, corrected and bonus tokens all follow the watermarked distribution.

## Validation

Tests: `tests/watermarking/test_red_green.py` (new), the red-green golden candidates (`tests/watermarking/golden_candidates.py`, `watermarking_goldens.json`), `tests/watermarking/test_watermarking_e2e.py`, `tests/test_config.py`, `tests/model_executor/test_watermark_sample_warmup.py`.

## Details

- **Fused sampling:** `philox_red_green_sample` adds the green bias and draws the token in one Triton kernel. It uses the same per-request seed and position noise as vLLM's regular sampler.
- **Logprobs:** processed logprobs report the logits before the bias, same as GumbelWatermarker.
- **Speculative decoding:** `philox_green_bias` materializes the biased logits for verification, and standard rejection sampling runs against them. As for the other watermarks, probabilistic drafting (`draft_sample_method: probabilistic`) and standard rejection sampling are required.
- **Detection:** without the watermark, each scored token is green with probability `gamma`, independently. So for unwatermarked text the green count is Binomial(n, gamma), and the p-value is its upper tail.
- **Docs:** `docs/features/watermarking.md` has a red-green section with usage.
