## Original PR description

## Purpose

Three more slow NVIDIA steps move to automatic sharding, following #60492, #60662, #60757 and #60858:

| Step | Before | Planned shards (est. min) |
|---|---|---|
| `model-executor` (H200 MIG 35GB) | ~48 min | 3 × 15.7 |
| `language-models-tests-hybrid` (H200 MIG 35GB) | 2 fixed pytest shards, ~45 min each | 3: 14.9 / 14.9 / 15.3 |
| `pipeline-context-parallelism-4-gpus` (4×L4) | ~42 min | 3: 17.7 / 16.4 / 6.3 |

- Language Models (Hybrid) drops its `--num-shards/--shard-id` args and `parallelism: 2`. Its AMD mirror keeps fixed pytest shards (`parallelism: 2` moves into the mirror), because `automatic_shard` covers NVIDIA steps only.
- The Hybrid plan needs vllm-project/ci-infra#772. Without it, the planner counts the 5 files that have no `hybrid_model` tests at the step median, plans 6 shards, and still goes over budget. It never loses tests either way.

## Test Plan

Buildkite build https://buildkite.com/vllm/ci/builds/94188, running only these three steps with the ci-infra branch. I'll add wall time, GPU time and test counts against main here.
