# [CI] Shard Model Executor and L4 Pipeline + Context Parallelism automatically

[Upstream PR](https://github.com/vllm-project/vllm/pull/61202) · state: closed · merged: True

## Original PR description

## Purpose

Two more slow NVIDIA steps move to automatic sharding, following #60492, #60662, #60757 and #60858:

| Step | Before | Planned shards (est. min) |
|---|---|---|
| `model-executor` (H200 MIG 35GB) | ~48 min | 3 × 15.7 |
| `pipeline-context-parallelism-4-gpus` (4×L4) | ~44 min | 3: 17.7 / 16.4 / 6.3 |

Language Models (Hybrid) was in the first version of this PR and is now left on its fixed shards. Each of its jobs builds mamba and causal-conv1d from source (~15 min), so a third shard cost +26% GPU time.

## Test Plan

[Buildkite build 94188](https://buildkite.com/vllm/ci/builds/94188) ran only these steps. Every shard passed, and the shard plugin was active for every pytest command. The baseline is main nightly 94125.
