# [CI] Label recipe PRs and link their recipes.vllm.ai preview

[Upstream PR](https://github.com/vllm-project/vllm/pull/63248) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Labels PRs that change `recipes/` with `recipe` and comments a link to the PR's own recipes.vllm.ai preview, the way `label-documentation` links the Read the Docs preview. Previews are built by vllm-project/recipes (#1167, #1168, #1169) and triggered from here by #63259.

## Claims

- New Mergify rule `label-recipe`. When a PR touches `recipes/`, it adds the `recipe` label and comments `https://vllm-recipes-git-preview-vllm-pr-{{number}}-inferact-inc.vercel.app`.
- `recipes/README.md` tells contributors that recipe PRs get a preview.

## Validation

- `pre-commit run --files .github/mergify.yml recipes/README.md`: passes, including `check_label_rules.py` (`^recipes/` matches real files) and markdownlint.
- The preview pipeline on the recipes side was tested in vllm-project/recipes#1167: a lock pinned to this repo's PR #63244 head (a fork PR) syncs and builds, and renders that PR's recipe.

## Details

- Previews are rebuilt a few minutes after each push via #63259's `repository_dispatch`. The label is what vllm-project/recipes' hourly fallback searches for (one API call instead of scanning the files of ~6.6k open PRs) when a dispatch was missed, and it's a normal area label for triage.
- The comment goes up before the first preview finishes building, so the link 404s for a few minutes, the same as the Read the Docs comment.
- The `recipe` label doesn't exist yet. Mergify creates it on first use, but a maintainer may want to create it first to set its color and description.
- Not a duplicate: no other open PR adds recipe labeling or previews.
