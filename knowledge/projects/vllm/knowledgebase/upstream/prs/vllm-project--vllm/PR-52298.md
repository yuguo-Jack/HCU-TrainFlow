## Original PR description

## Purpose

Related to #51660. Reject unsupported Guidance tokenizers during request validation, before EngineCore initialization.

Explicit `guidance` requests now validate the tokenizer conversion paths used by `GuidanceBackend`. When `auto` cannot use xgrammar, unsupported tokenizers also exclude Guidance without introducing an automatic fallback to outlines. Existing Mistral behavior, including Tekken support and the non-Tekken fallback, is preserved.

The update preserves current main's JSON validation coverage. A current search for open PRs referencing #51660 found only this PR; related Guidance work addresses structural tags or grammar serialization, rather than this tokenizer validation failure.
