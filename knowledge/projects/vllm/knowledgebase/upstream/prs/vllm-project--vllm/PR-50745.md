# [Doc] Add ARM+NVIDIA GB10 embedding notes to GPU CUDA installation

[Upstream PR](https://github.com/vllm-project/vllm/pull/50745) · state: open · merged: False

## Original PR description

### Purpose
Add documentation notes for using vLLM's embedding mode on the ARM + NVIDIA GB10 platform.

Users on the NVIDIA GB10 (DGX Spark) with the NGC container `nvcr.io/nvidia/vllm:26.01-py3` may encounter an `AttributeError` when using the `--convert embed` flag with MoE models like Qwen3MoE. This has been confirmed as a container-specific packaging issue, not an upstream vLLM bug (see #49657). This PR documents the known issue and its solutions to save users significant debugging time.

### Test Plan
- Built the documentation locally with `make -C docs clean html` and verified the new section renders correctly.
- No code changes are involved.

### Test Result
Documentation builds successfully. The new "ARM + NVIDIA GB10 (DGX Spark) Notes" section appears correctly in the GPU installation guide.
