# [Bugfix][KV Connector][NIXL] Support heterogeneous P/D TP for mixed MLA models

[Upstream PR](https://github.com/vllm-project/vllm/pull/61581) · state: open · merged: False

## Original PR description

## Overview

Fixes the NIXL KV-transfer crash when a P/D disaggregated deployment uses **heterogeneous TP** (e.g. prefill TP16 + decode TP8) with a **mixed MLA** model — a model that combines a replicated MLA latent cache with head-sharded attention regions (GLM-5.3 `GlmMoeDsaForCausalLM` with `sparse_mla_force_mqa`, i.e. MLA + DSA sparse-attention indexer). Extends the per-region classification introduced in #44583 to heterogeneous-TP page geometry.

## Claims

- Heterogeneous P/D TP works for mixed MLA models: prefill TP16 + decode TP8 and prefill TP8 + decode TP16 both complete full benchmarks with correct output quality.
- Pure-MLA (DeepSeek-class), pure-GQA, and symmetric-TP deployments keep their existing behavior — every change is gated on conditions only hybrid + mixed-TP produce.
- Measured on GLM-5.3 785B fp8 (8xH200): `1P×TP16 + 2D×TP8` = 0.81 req/s vs 0.48 req/s for the best symmetric split (**+68%**) — prefill is compute-bound (wider TP wins) while decode is latency-bound (smaller TP group wins); heterogeneous TP lets each role sit at its optimum.

## Validation

Live on an 8xH200 cluster, GLM-5.3 785B fp8, full request-load benchmarks per config:
- D>P (prefill TP8 + decode TP16): EPP registration 3s, full benchmark, quality ok
- D<P (prefill TP16 + decode TP8): EPP registration 2s, full benchmark, quality ok
- Symmetric TP8/8 and TP16/16: unchanged behavior
- Pure-MLA and pure-GQA models: unchanged (execution-tested)

Unit tests added: `tests/v1/kv_connector/unit/test_tp_mapping.py::TestMixedMLAHeterogeneousTP` (26 existing tests still pass, including the MLA+DCP source-rank cases).

## Details

**Root cause.** Four layers each individually look correct for pure-MLA and pure-GQA models — only their combination, applied to a hybrid model under mixed TP, fails:

1. **Validation** — the handshake asserted "replicated regions must have equal lengths on P and D", but the DSA indexer's per-rank page scales with heads/TP (2:1 between TP8 and TP16) → assertion → decode-engine death on first request.
2. **Classification** — a model-wide `use_mla` flag forced replicated treatment onto the head-sharded indexer regions, bypassing the per-region spec classification from #44583.
3. **Mapping** — the GQA branch's head-dedup collapsed: MLA models report `total_num_kv_heads=1` (MQA semantics), so "which remote ranks hold my heads?" computed one source instead of two.
4. **Read execution** — a "pure MLA reads exactly once" assert rejected the legitimate two-source read the corrected plan produced.

**Fix** (each piece gated):
- `base_worker.py`: per-region spec classification decides REPLICATE vs SPLIT (no model-wide override); replicated-region assert relaxed to a warning when `tp_ratio != 1`; a spec-replicated region transfers at SPLIT granularity when its local page exceeds the remote page (head-scaled storage) — on both the remote descriptor build and the local receive-side chunks; a page-aware `has_split_attn_regions` signal is computed at the `compute_tp_mapping` call site.
- `tp_mapping.py`: `compute_tp_mapping` accepts `has_split_attn_regions` (region-level truth — group-representative specs cannot detect mixed regions, so the default keeps legacy behavior); the GQA head-dedup is bypassed when the signal is set and the dedup collapsed below `abs_tp`, keeping all sources with positional head slots.
- `pull_worker.py`: the single-read assert is relaxed when the engine's TP mapping has multi-source attention groups.

Symmetric TP never trips any gate: equal TP on both sides means head-sharded regions have equal page sizes, the mapping collapses to identity, and every legacy assumption holds.

Limitations: the dedup bypass uses positional slots (the head-based math degenerates under MQA semantics), which is correct for head-scaled storage but would be suboptimal for a hypothetical model with genuinely replicated GQA heads under mixed TP — the region-level signal gates this case out.
