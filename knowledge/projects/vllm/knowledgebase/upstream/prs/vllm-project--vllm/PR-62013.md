# [Refactor][Attention] Make MLA DCP collectives pluggable

[Upstream PR](https://github.com/vllm-project/vllm/pull/62013) · state: open · merged: False

## Original PR description

## Overview

Make MLA DCP query gather, A2A reduction and KV gather replaceable through `CustomOp`.

## Claims

- The custom ops own computation and fallbacks; workspaces hold buffers/views.
- Preserve CUDA/ROCm/XPU dispatch, `VLLM_USE_DIRECT_DCP_*` controls and existing GPU kernels/fallbacks.

## Validation

243 CPU tests and scoped hooks passed. Prior GPU validation/benchmarks at `3c7baf6`: 196 four-B200 tests and compiled OOT checks passed; identical collective kernels/counts and all 115,200 paired token IDs. This fix leaves CUDA/ROCm execution unchanged. XPU/TPU/OOT hardware was not tested.

Same four B200s; two-layer dummy-weight DeepSeek-V2-Lite, BF16 TP4/DCP4, CUDA graphs. Three paired runs × 15 timed batches after warmup; prefill + 64-token generation. Median ms (range of run medians):

| Path / batch / prompt | Main | PR | Change |
|---|---:|---:|---:|
| Direct / 4 / 32 | 96.3 (95.7–96.9) | 96.0 (94.8–97.8) | -0.4% |
| Direct / 16 / 256 | 167.2 (166.9–171.8) | 166.2 (163.7–170.2) | -0.6% |
| Fallback / 4 / 32 | 100.6 (92.6–108.5) | 102.3 (98.4–114.7) | +1.7% |
| Fallback / 16 / 256 | 180.7 (172.1–184.1) | 186.2 (175.5–188.9) | +3.0% |

Batch 16 logprobs match exactly. Batch 4 varies by up to 0.00195, also observed within unmodified main. Fallback batch 16 is 2–3% slower across pairs; unchanged kernels do not establish zero wrapper overhead. [Results and reproduction](https://gist.github.com/andylolu2/1d9d564e623bb444d7d06da5b2549193).

## Details

CUDA/ROCm/XPU retain existing paths under Inductor's global `none`; explicit per-op disable selects Torch. CPU/TPU/OOT inherit native dispatch, avoiding GPU-only kernels and CUDA-only plugin overrides.

Related: [#60218](https://github.com/vllm-project/vllm/pull/60218), [#60606](https://github.com/vllm-project/vllm/pull/60606), [#50009](https://github.com/vllm-project/vllm/pull/50009), [#61922](https://github.com/vllm-project/vllm/pull/61922); none provides generic collective overrides.
