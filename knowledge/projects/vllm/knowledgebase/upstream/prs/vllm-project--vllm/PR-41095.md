# [ROCm] Add AITER fused dual RMSNorm for MLA

[Upstream PR](https://github.com/vllm-project/vllm/pull/41095) · state: open · merged: False

## Original PR description

## Summary

This PR adds AITER's fused dual RMSNorm kernel for DeepSeek MLA models on AMD ROCm.

- **Fused Dual RMSNorm**: Uses AITER's `fused_qk_rmsnorm` to combine Q and KV RMSNorm operations in a single kernel
- **BF16 Output**: Returns unquantized BF16 tensors to preserve downstream quantization flexibility

### Accuracy Testing
Verified on GSM8K benchmark:

export HIP_VISIBLE_DEVICES=0,1,2,3,4,5,6,7

File: `vllm/model_executor/layers/mla.py` · line 183

![critical](https://www.gstatic.com/codereviewagent/critical.svg)

The `q_c` tensor is not updated in the fused path, but it is used later by the indexer (line 214) if `is_sparse` is True. In the original code and the unfused path, `q_c` is updated with the normalized version. This will cause incorrect results for sparse MLA models (like DeepSeek-V3) when fusion is enabled because the indexer will receive un-normalized latent vectors. Reassigning the result to `q_c` ensures consistency with the unfused path and downstream usage.

```suggestion
                q_c, kv_c_normed = mla_dual_rmsnorm_op(
                    q_c,
                    self.q_a_layernorm.weight,
                    self.q_a_layernorm.variance_epsilon,
                    kv_c,
                    self.kv_a_layernorm.weight,
                    self.kv_a_layernorm.variance_epsilon,
                )
                q = self.q_b_proj(q_c)[0]
```

File: `vllm/model_executor/layers/mla.py` · line None

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

Using `is_linear_fp8_enabled()` to check for AITER availability is inappropriate here as this is an MLA-specific optimization. If a user enables MLA optimizations via `VLLM_ROCM_USE_AITER_MLA=1` but disables FP8 linear optimizations, this fusion will be incorrectly disabled. It is better to use `is_mla_enabled()` which correctly checks both the main AITER toggle and the MLA-specific toggle.

```suggestion
    _AITER_AVAILABLE = rocm_aiter_ops.is_mla_enabled()
```
