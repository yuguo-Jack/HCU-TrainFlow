# [Build] Update deep_gemm git tag for locality_domain update

[Upstream PR](https://github.com/vllm-project/vllm/pull/61491) · state: closed · merged: True

## Original PR description


## Overview
Update DeepGEMM to the top of this PR https://github.com/vllm-project/DeepGEMM/pull/35.

The current DeepGEMM pin computes balanced SM locality domains during deep_gemm initialization. On a 60-SM MIG device, that reaches an existing balancing error during vLLM import, even when locality features are unused (see https://github.com/vllm-project/vllm/pull/59482#issuecomment-6150173498). This PR updates both the CMake dependency and standalone installer to cleonard530/DeepGEMM@6af2d3a, which restores lazy C++ locality initialization using stable PyTorch APIs.
~~The legacy balancing issue remains and can still surface when balanced locality domains are requested.~~
