# [Bugfix]MooncakeConnect add query timeout and retry

[Upstream PR](https://github.com/vllm-project/vllm/pull/55923) · state: closed · merged: True

## Original PR description

## Purpose
Improve Mooncake bootstrap metadata query reliability when the prefiller responds slowly or encounters transient connection failures.
- Set an explicit HTTP timeout of 60 seconds.
- Retry httpx.RequestError up to 3 total attempts, with a 100ms interval.
- Include attempt numbers and exception types in failure logs.
- Preserve existing metadata processing and completion notification behavior.
