# [Model][Hardware][AMD] Fuse MLA Attention + Per-token FP8 Quant

[Upstream PR](https://github.com/vllm-project/vllm/pull/63861) · state: open · merged: False

## Original PR description



## Overview

Fuse the `o_proj` per-token FP8 input quant into the MLA `W_UV` BMM. The fusion is handled by `MLAAttnQuantFusionPass` and only activates on ROCm with AITER enabled.

For decode, AITER fuses the per-token FP8 quant into the reduce step of the BMM.

Depends on https://github.com/ROCm/aiter/pull/6727.

## Claims

- gsm8k accuracy is unchanged.
- Per decode step and layer: the W_UV BMM + separate per-token quant kernel are replaced by a split-K BMM whose reduce step also does the per-token FP8 quant.

## Validation

### Commands

```bash
# serve
export VLLM_ROCM_USE_AITER=1
export VLLM_ROCM_QUICK_REDUCE_QUANTIZATION=INT4
export VLLM_ROCM_USE_AITER_FUSION_SHARED_EXPERTS=1
export VLLM_ROCM_USE_SKINNY_GEMM=0
export VLLM_ROCM_USE_AITER_FP8BMM=1

vllm serve $MODEL \
  --tensor-parallel-size 8 \
  --gpu-memory-utilization 0.9 \
  --dtype auto \
  --kv-cache-dtype fp8 \
  --max-num-batched-tokens 8192 \
  --no-enable-prefix-caching \
  --disable-uvicorn-access-log \
  --max-model-len 32768 \
  --max-num-seqs 512 \
  --trust-remote-code \
  -cc.use_inductor_graph_partition=True \
  -cc.pass_config.fuse_rope_kvcache_cat_mla=True \
  -cc.pass_config.fuse_attn_quant=True

# bench
vllm bench serve \
  --model $MODEL \
  --backend vllm \
  --trust-remote-code \
  --base-url http://localhost:8000 \
  --dataset-name random \
  --random-input-len 1024 \
  --random-output-len 1024 \
  --num-prompts $((CONC * 10)) \
  --max-concurrency $CONC \
  --request-rate inf \
  --ignore-eos \
  --percentile-metrics "ttft,tpot,itl,e2el" \
  --save-result

# accuracy
lm_eval \
  --model local-completions \
  --model_args "model=$MODEL,base_url=http://localhost:8000/v1/completions,num_concurrent=64,max_retries=3,tokenized_requests=False,tokenizer_backend=None,trust_remote_code=True" \
  --tasks gsm8k \
  --num_fewshot 20 \
  --seed 42
```
