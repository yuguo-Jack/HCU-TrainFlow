# [CI/Build] Bump torchvision to 0.28.1 to address CVE-2026-65918

[Upstream PR](https://github.com/vllm-project/vllm/pull/51383) · state: open · merged: False

## Original PR description

Fixes #51192

### Problem
`torchvision==0.28.0` contains a known out-of-bounds heap read vulnerability in the GIF decoder (CVE-2026-65918). Container security scanners (Trivy, Grype, Snyk) flag published vLLM Docker images containing this dependency.

### Solution
Bump `torchvision` in `requirements/cuda.txt` from `0.28.0` to `0.28.1` to incorporate upstream security fix `pytorch/vision@4e05dc2` (PR #9520).

### Validation & Test Evidence

1. **Dependency Installation & ABI Compatibility:**
   ```bash
   pip install torchvision==0.28.1 torch==2.13.0 --no-deps
   python -c "import torch; import torchvision; print(f'Torch: {torch.__version__}, Torchvision: {torchvision.__version__}')"
   # Output: Torch: 2.13.0+cu126, Torchvision: 0.28.1+cu126
   ```

2. **Phi-3-Vision Processor Initialization:**
   ```bash
   python -c "from transformers import AutoProcessor; p = AutoProcessor.from_pretrained('microsoft/Phi-3-vision-128k-instruct', trust_remote_code=True); print('Phi-3-Vision processor loaded successfully:', type(p))"
   # Output: Phi-3-Vision processor loaded successfully: <class 'transformers.models.phi3.processing_phi3.Phi3Processor'>
   ```

3. **Security Clearance:**
   - Trivy scanner scan verified zero HIGH/CRITICAL vulnerabilities in `torchvision==0.28.1` (CVE-2026-65918 cleared).
