## Details

Related work: #61584 reserves construction-time scratch across workspace slots. This layer owns reusable NIXL receive tensors, handles and shared-expert events/outputs for multiple active microbatches; construction-time reservation does not provide that receive-buffer lifetime guarantee. Closed #39033 also proposed dynamic shared-expert output slots, so that portion should be reconciled rather than treated as novel.

Additional receive snapshots and events increase memory and setup cost; correctness and performance on GPU remain unverified.

The original combined upstream PR vllm-project/vllm#57184 was closed in favor of this split. OpenAI Codex assisted with code and PR preparation.
