# [CI][Bugfix] Fix flaky port race in test_coordination_store_held_only_by_the_online_dp_master

[Upstream PR](https://github.com/vllm-project/vllm/pull/64348) · state: closed · merged: True

## Original PR description



The test reserved data_parallel_rpc_port with get_open_port(), which binds port 0 and releases it. launch_core_engines then creates the coordination TCPStore on a kernel-assigned port before binding the handshake socket to the reserved port, so the kernel can hand the freed port to the store and the bind fails with "Address already in use" (seen in the mp and elastic-ep cases).

Use port 0 so the handshake socket picks a free port at bind time.
