# [Bugfix][Structured Output][v0.31] Honor resolved backends and mask widths

[Upstream PR](https://github.com/vllm-project/vllm/pull/62284) · state: open · merged: False

## Original PR description


## Purpose

Backport the per-resolved-backend compiler cache and model-vocabulary mask normalization from #62246 to the official `releases/v0.31.0` branch (`db9527a46873454610df6dbedf79a36d6bf1a7f6`). This is a release-base adaptation of that existing PR, not a second proposed implementation for main.

In `backend=auto`, validation can select guidance for one request and xgrammar for the next. The 0.31 manager caches only its first backend and sends later requests to it regardless of their validated backend. With a guidance request first, a subsequent named structural-tag request reaches guidance's old-format serializer and raises `KeyError: 'triggers'` before any model inference. The paired native regression below reproduces that failure on the exact unmodified release base.

Cache each resolved backend, use it for that request, and fill backend-native work masks before copying bounded rows into the model-vocabulary transport mask. Preserve unique cumulative row indices in mixed/parallel batches. Shut down both existing executors before destroying all cached compilers.

The 0.31 reasoner, constraint-start, validation/acceptance and existing flow tests are retained. The newer main-only implicit-reasoning-end / `ConstraintBounds` feature is not backported. No model name, checkpoint, forced backend, frontend, scheduler or GPU kernel change is introduced.

Related work: #55153 extends guidance's structural-tag serializer; #61892 changes the Rust/gRPC backend selection; #49625 rejects mixed backends instead of supporting the independently validated choices. Those are different approaches/paths. #62246 is the explicit source dependency. Public issue comments and bounded duplicate checks are retained in the review packet. A fresh authenticated release-base structured-output search returned no match, and the four issue-linked PRs above were rechecked before submission. The earlier broad area search remained incomplete (first50 of76, with the second page rate-limited); this is not an exhaustive absence claim.
