# [Quantization][FP8] Replace bare asserts with descriptive exceptions in fp8.py

[Upstream PR](https://github.com/vllm-project/vllm/pull/44342) · state: open · merged: False

## Original PR description

Bare `assert` statements in fp8.py raise unhelpful `AssertionError` with 
no message when triggered. This PR replaces 9 such asserts with proper 
`ValueError` or `NotImplementedError` exceptions that include context 
about what went wrong and how to fix it.

Changes:
- `Fp8OnlineLinearMethod.process_weights_after_loading`: assert → 
  NotImplementedError explaining block_quant is not yet supported in 
  online quant path
- `Fp8MoEMethod.create_weights`: assert → ValueError explaining 
  serialized checkpoint is required
- `Fp8MoEMethod.apply_monolithic`: 2 asserts → ValueError with clear 
  method routing guidance
- `Fp8MoEMethod.apply`: 2 asserts → ValueError with clear method 
  routing guidance
- `Fp8OnlineMoEMethod.__init__`: 3 asserts → ValueError with specific 
  constraint explanations including the actual violating value

No behavioral changes — only error message quality is improved.
