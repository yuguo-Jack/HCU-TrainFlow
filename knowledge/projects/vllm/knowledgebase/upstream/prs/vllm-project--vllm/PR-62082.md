## Overview

Add retry-observable external Elastic EP operations and bounded native submission.
The native coordinator owns resize execution; an HTTP caller need not remain
connected through preparation, draining, joining, and collective commit.

Follow-up to #43202 and related to #42515 and
[Dynamo DEP #13121](https://github.com/ai-dynamo/dynamo/issues/13121).

## Claims

- Preserve synchronous `/scale_elastic_ep`, optional operation/runtime IDs,
  retained latest-operation replay, and atomic effective-topology evidence.
- Add `/submit_elastic_ep`: validate and retain an immutable request, acknowledge
  local participation promptly, and observe its native-owned execution through
  the existing status endpoint. Caller disconnect does not cancel that execution.
- Bind each local receipt to operation, instance, base-topology token, absolute
  target, drain timeout, and owned range. Refuse conflicting replay, unresolved
  supersession, stale instances, and delayed new requests after a successor.
- Keep correlated status/replay reachable while inference admission is closed,
  including on a retired API process. Retired owners refuse new work before
  replacing their successful retirement receipt. Acceptance is not collective completion
  and completion is not a current inference-health signal.

## Details

Reuse the existing coordinator, epoch-scoped TCPStore and native resize path.
The API process owns one tracked execution task and one latest immutable local
receipt, not an additional transaction framework. A new request uses the current
instance and opaque topology token; replay uses its original immutable body.
Observe delivery/completion per existing client as well as collective topology.
No receipt is expired by wall-clock timeout. Runtime restart changes the instance
and invalidates old authority.

Ray and ordinary synchronous launches keep their existing APIs. Automatic
bootstrap (#62973) and native local-range resizing
([follow-up](https://github.com/julienmancuso/vllm/pull/1)) remain separate. Packed
composition requires the local-range delegation to forward operation identity;
this standalone PR does not import their bootstrap/process ownership changes.

Duplicate checks found no other bounded external submission proposal; #62973
supplies launch discovery, not this operation contract. AI assistance was used
for code, tests, documentation, and checks. The human submitter remains responsible
for reviewing the complete diff and native qualification.
