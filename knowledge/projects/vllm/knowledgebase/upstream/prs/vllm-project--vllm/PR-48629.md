# [Bugfix][Model] Honor nested Ministral3 Llama 4 scaling

[Upstream PR](https://github.com/vllm-project/vllm/pull/48629) · state: open · merged: False

## Original PR description

## Purpose

Fixes the remaining nested Llama 4 query-scaling gap in #48621.

`MistralAttention` reads only the top-level `llama_4_scaling` mapping, while Transformers-native `Ministral3Config` stores `llama_4_scaling_beta` and `original_max_position_embeddings` in `rope_parameters`. Without the duplicate top-level mapping, vLLM skips the intended query scaling at and beyond the original context length.

Fall back to the nested fields when the top-level mapping is absent. Preserve top-level precedence and leave scaling disabled when the nested fields are incomplete. Retain five focused tests covering lookup precedence, the Transformers config, attention initialization, incomplete configuration, and the context-length boundary.
