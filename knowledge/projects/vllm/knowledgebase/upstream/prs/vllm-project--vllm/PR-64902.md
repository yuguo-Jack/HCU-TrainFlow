# [MoE] Release cached allocator blocks before mapping MegaMoE symmetric memory

[Upstream PR](https://github.com/vllm-project/vllm/pull/64902) · state: open · merged: False

## Original PR description

## Overview

With expert parallelism (EP > 1), DeepGEMM allocates the MegaMoE symmetric buffer through `torch.distributed._symmetric_memory`, which maps it with the CUDA driver, outside the PyTorch caching allocator. After the profile run, the allocator can hold most of the GPU in cached free blocks, and the driver allocation then fails with `CUDA driver error: out of memory` although that memory is free. With a single EP rank, DeepGEMM uses a plain `torch` allocation, which reuses the cached blocks, so it is not affected. `get_symm_buffer` now calls `torch.accelerator.empty_cache()` before it creates a buffer. This runs once per buffer key, not per forward.

Split from #62365 by @aoshen02.

## Changes

- `vllm/model_executor/layers/fused_moe/deep_gemm_mega_moe.py`: `torch.accelerator.empty_cache()` before the first creation of each symmetric buffer.
- `tests/kernels/moe/test_deep_gemm_mega_moe.py`: `test_deep_gemm_mega_moe_symm_buffer_releases_cached_blocks` (CUDA, any GPU) stubs the DeepGEMM constructor and checks that 256 MiB the test left cached were released before the constructor was called.

```python
"""Create the real DeepGEMM MegaMoE symmetric buffer while the caching allocator
holds almost all free GPU memory (vllm#64902). Single rank, real deep_gemm.

MODE=fill: cache all but MARGIN_MIB of free memory in the allocator first.
MODE=nofill: control, no cached blocks. Run with PYTHONPATH=<tree>.
"""
import os, traceback
from types import SimpleNamespace
import torch
import torch.distributed as dist

rank = int(os.environ.get("RANK", "0")); world = int(os.environ.get("WORLD_SIZE", "1"))
local = int(os.environ.get("LOCAL_RANK", "0"))
torch.cuda.set_device(local)
if world == 1:
    dist.init_process_group("nccl", init_method="tcp://127.0.0.1:%s" % os.environ.get("PORT", "29611"),
                            world_size=1, rank=0, device_id=torch.device("cuda", 0))
else:
    dist.init_process_group("nccl", device_id=torch.device("cuda", local))
import vllm.model_executor.layers.fused_moe.deep_gemm_mega_moe as mm
mm.get_ep_group = lambda: SimpleNamespace(device_group=dist.group.WORLD, world_size=world)

tokens = int(os.environ.get("MAX_TOKENS", "8192"))
cfg = SimpleNamespace(scheduler_config=SimpleNamespace(max_num_batched_tokens=tokens),
                      compilation_config=SimpleNamespace(static_forward_context={}))
experts = mm.DeepGemmMegaMoEExperts(
    cfg, num_experts=256, num_local_experts=256 // world, experts_start_idx=rank * (256 // world), top_k=8,
    hidden_size=4096, intermediate_size=2048, activation=mm.MegaMoEActivation(),
    weight_format=mm.MEGA_MOE_MXFP4, max_num_tokens=tokens)
torch.cuda.synchronize()

GiB, MiB = 2**30, 2**20
def state(tag):
    free, total = torch.cuda.mem_get_info()
    print(f"rank{rank} {tag}: driver_free={free / GiB:.2f} GiB reserved={torch.cuda.memory_reserved() / GiB:.2f} GiB "
          f"allocated={torch.cuda.memory_allocated() / GiB:.2f} GiB", flush=True)

if os.environ.get("MODE", "fill") == "fill":
    margin = int(os.environ.get("MARGIN_MIB", "256")) * MiB
    free, _ = torch.cuda.mem_get_info()
    block = torch.empty(free - margin, dtype=torch.uint8, device="cuda")
    del block  # stays cached in the allocator
state("before get_symm_buffer")
try:
    buf = experts.get_symm_buffer()
    torch.cuda.synchronize()
    state("after get_symm_buffer")
    print(f"RESULT rank{rank} get_symm_buffer OK", type(buf).__name__)
except Exception as e:  # noqa: BLE001
    state("after failure")
    print(f"RESULT rank{rank} get_symm_buffer FAILED:", type(e).__name__, str(e).splitlines()[0][:300])
    traceback.print_exc()
dist.destroy_process_group()
```
