# [Refactor][DSv4.1] Remove duplicated code

[Upstream PR](https://github.com/vllm-project/vllm/pull/64974) · state: closed · merged: True

## Original PR description



## Overview

Remove code that `deepseek_v41` duplicates from `deepseek_v4`. No behavior change.

## Claims

- Ops that `deepseek_v41` carried as byte-identical copies of `deepseek_v4` are removed and imported from `deepseek_v4` instead: the Triton kernels `quantize_and_insert_k_kernel`, `remap_flashinfer_index` and `fill_short_context_topk_indices`, and the FlashInfer sparse helpers `get_flashinfer_dsv4_workspace`, `packed_block_span`, `pad_to_supported_q_heads` and `required_sm120_sparse_topk`. They lose their leading underscore now that another package imports them.
- Removed the `hf_config_int` / `scheduler_config_int` helpers. Warmup always receives the engine's `VllmConfig`, so the warmup code now reads `sliding_window` / `index_topk` directly, and the `max_num_batched_tokens <= 0` early return is dropped (the field is validated `>= 1`).
- `deepseek_v41/nvidia` imports `DeepseekV4MixtureOfExperts` from `deepseek_v4/nvidia` instead of keeping its own copy, since its MoE subclasses the V4 one. The ROCm model keeps its copy because its MoE has a different base.
