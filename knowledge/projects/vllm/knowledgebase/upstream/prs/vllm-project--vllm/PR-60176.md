## Details

MultiConnector requires every child to support HMA. Automatic configuration can therefore disable HMA only on one peer, while the other keeps it enabled. The handshake compares the effective state, not merely whether users supplied the same flags.

The workaround is intentionally conditional: HMA cannot be disabled for the documented SSM/Mamba or HiSparse configurations, and matching HMA alone does not guarantee compatibility. The transfer safety check remains unchanged.

Duplicate checks found no open PR for `60124 in:body` or the same HMA troubleshooting text. #59584 covers authentication/side-channel troubleshooting; #60113 changes heterogeneous KV-group transfer; #48882 changes subclass validation; #42620 implements LMCache HMA support.
