# [Bugfix][Frontend] Preserve leading DeepSeek V4 developer instructions

[Upstream PR](https://github.com/vllm-project/vllm/pull/63497) · state: open · merged: False

## Original PR description

## Overview

Fixes #63480. Preserve leading developer instructions that DeepSeek V4/V4.1 thinking cleanup silently discards, in both Python and Rust frontends.

## Claims

- Convert only nonempty developer messages in the initial system/developer preamble that would actually be dropped: thinking and effective `drop_thinking` are enabled, and no tools are rendered.
- Preserve native behavior for chat, tools, developer-only/nonleading/trailing turns, and empty-content validation.
- Preserve exact V4 instruction separators and assistant generation headers.
