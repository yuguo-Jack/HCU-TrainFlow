# fix(anthropic): preserve requested model alias in messages response

[Upstream PR](https://github.com/vllm-project/vllm/pull/51514) · state: open · merged: False

## Original PR description

Co-authored-by: @lazypool


## Purpose

Fixes #51266.

### Problem
When vLLM is launched with multiple model aliases (--served-model-name alias-a alias-b), the requests to the Anthropic Messages API (POST /v1/messages) specifying a secondary alias (alias-b) received responses where the model field was canonicalized to the primary alias (alias-a).

### Impact on Anthropic Clients
Anthropic clients and agentic tools like Claude Code record the returned model name in the assistant message and perform turn-by-turn model equality checks (request.model == previous_assistant_message.model). Because "alias-a != alias-b", Claude Code concluded that a model switch occurred across turns and stripped thinking blocks from the conversation history, breaking multi turn agentic tool use loops.

### Solution
- Updated "AnthropicServingMessages.create_messages" to pass "request.model" into "messages_full_converter" and "message_stream_converter"
- messages_full_converter: sets model = requested_model or generator.model
- message_stream_converter: sets "model = requested_model or origin_chunk.model" on the "message_start" event
- This preserves the requested model identity for Anthropic clients without altering the shared OpenAI serving path or its test contracts (PR #24663)

## Test Plan
Added unit tests in "tests/entrypoints/anthropic/test_anthropic_messages_conversion.py":
1. test_requested_model_alias_preserved: verifies non-streaming responses return the requested alias (alias-b) instead of the canonical "generator.model" (alias-a).
2. test_default_model_when_requested_model_is_none: verifies safe fallback to generator.model when requested_model is not supplied.
3. test_stream_converter_preserves_requested_model_alias: verifies streaming converter's message_start event emits the requested alias (alias-b).

Run commands:
```bash
# Run targeted alias preservation tests
