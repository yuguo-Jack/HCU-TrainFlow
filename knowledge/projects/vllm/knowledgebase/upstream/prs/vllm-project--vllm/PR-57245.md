# [LoRA] Add DeepSeek V4.1 text and vision adapter support

[Upstream PR](https://github.com/vllm-project/vllm/pull/57245) · state: open · merged: False

## Original PR description




## Purpose

Resolve #57166

Enable LoRA for the DeepSeek V4.1 multimodal model, including its language model, vision tower, and connector. The multimodal wrapper currently lacks LoRA registration, while the grouped attention output projection and compressor projection call GEMMs directly and bypass adapter application.

- Register the supported packed projections and multimodal module mapping, excluding the MTP draft head from adaptation.
- Apply the grouped output projection's LoRA contribution for both BF16 and FP8 base weights, including gathering LoRA-A for fully sharded adapters. Add the compressor's adapter contribution while preserving the base GEMM's FP32 output.
- Scope tower and connector adapter metadata to each image using its original batch index, including when images are distributed across TP ranks. Restore batch metadata after encoding, including on exceptions. Count only the patch rows processed by each module, excluding image-span delimiters.
- Avoid retaining temporary single-slice adapter tensors in the Triton pointer caches. Add regression coverage in the existing LoRA test files.

## Test Plan

- Write and run newly added test cases
- End to end test with verl LoRA RL using Megatron backend https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6199
