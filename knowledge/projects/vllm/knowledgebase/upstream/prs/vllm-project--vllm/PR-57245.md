# [LoRA] Add DeepSeek V4.1 language-model adapter support

[Upstream PR](https://github.com/vllm-project/vllm/pull/57245) · state: closed · merged: True

## Original PR description

## Purpose

Addresses #57166.

Enable language-model LoRA for DeepSeek V4.1, including when processing multimodal inputs. The multimodal wrapper currently lacks LoRA registration, while the grouped attention output projection and compressor projection call GEMMs directly and bypass adapter application.

- Register language-model packed projections and the multimodal module mapping, excluding the MTP draft head from adaptation.
- Apply LoRA contributions to the grouped output projection and compressor projection, preserving the compressor's FP32 base output.
- Disable GEMM-RS when LoRA is enabled to avoid bypassing the `wo_b` adapter.
- Preserve streaming checkpoint loading and defer finalization until loading is complete.

Tower/connector LoRA and dynamic multimodal adapter mappings are deferred to a follow-up. The vision tower and connector remain frozen, and their original encoding paths are preserved.
