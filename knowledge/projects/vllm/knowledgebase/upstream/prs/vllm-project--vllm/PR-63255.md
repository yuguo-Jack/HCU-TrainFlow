# [Feature] PCP O-Proj TP: move split/restore logic into an intermediate `PCPOProjTP` layer

[Upstream PR](https://github.com/vllm-project/vllm/pull/63255) · state: open · merged: False

## Original PR description

This refactors #53422 so that all PCP O-Proj split/restore logic lives in one class, `PCPOProjTP`. It sits between the attention implementation and an ordinary `RowParallelLinear`. Linear methods only declare gather descriptors. Attention calls the layer through the original O-Proj interface and adds a single early hook.

The branch also ports #53422 onto current `main` at `544f182d9f`. The only conflicts were adjacent additions in `vllm/config/vllm.py` and an import line in `modelopt.py`; both sides are kept.

## Layering

```text
attention impl ──o_proj(x) / pre_attention_hook──▶ PCPOProjTP ──quant_method.apply──▶ RowParallelLinear
                                                       └──gather / switch──▶ TPWeightSwitchMixin (descriptors)
```

## `PCPOProjTP` (`vllm/model_executor/layers/pcp_o_proj_tp.py`)

| API | Role |
| --- | --- |
| `linear_shard_kwargs(vllm_config)` | Returns `tp_rank`/`tp_size` for the flattened TP×PCP grid, or `{}` when the feature is disabled. |
| `maybe_create(linear, vllm_config)` | Wraps the linear layer, or returns `None` when the feature is disabled. |
| `enable_weight_switch()` | Builds local/full weight aliases. Runs automatically after post-load processing through a delegating linear method. |
| `select_path(has_prefill)` | Returns `WEIGHT_ALL_GATHER` (prefill or mixed) or `TOKEN_EXCHANGE` (decode only). |
| `pre_attention_hook(attn_metadata=None, *, layer_name=None)` | Fixes the path for this forward and launches the async weight gather when needed. Prefers the PCP-global `global_has_prefill`. |
| `__call__(x)` | Drop-in for `RowParallelLinear.__call__`: same input, same `(output, bias)` / `output` return. |

Model usage:

```python
self.o_proj = RowParallelLinear(..., **PCPOProjTP.linear_shard_kwargs(vllm_config))
self.o_proj_tp = PCPOProjTP.maybe_create(self.o_proj, vllm_config)
# forward
if self.o_proj_tp is not None:
    self.o_proj_tp.pre_attention_hook(layer_attn_metadata)
...
return (self.o_proj if self.o_proj_tp is None else self.o_proj_tp)(output)[0]
```

- The linear layer stays registered as `o_proj`, so weight names, loading and post-load processing are unchanged.
- **DeepSeek V2/V3 MLA:** passes `PCPOProjTP` as `MLAModules.o_proj`. The wrapper's `self.o_proj(attn_out)` call is unchanged; the only addition is one `pre_attention_hook(layer_name=...)` call.
- **DeepSeek V3.2:** adds the hook and selects `o_proj_tp` at the final O-Proj call.

## Descriptor-driven weight switching (`tp_weight_switch.py`)

- `TPWeightGatherSpec` gains an optional `layout: TPWeightGatherLayout`.
  - `ConcatTPWeightLayout` is the default for tensors that concatenate directly on the sharded axis.
  - `NvFp4SwizzledBlockScaleLayout` handles the CUTLASS 128x4 swizzled block scales (unswizzle, `uint8` gather, reswizzle).
- `TPWeightSwitchMixin` builds every gather part from the descriptors. Support is implied by a non-empty `tp_weight_gather_specs`, so the `supports_tp_weight_switch` class flag is removed.
- `ModelOptLinearMethod` now has only its descriptors plus its NVFP4/CUTLASS-kernel validation. The ~120-line custom gather-part override is removed.

```python
tp_weight_gather_specs = (
    TPWeightGatherSpec("weight", gather_dim=1, make_full_contiguous=True),
    TPWeightGatherSpec("weight_scale", gather_dim=1, layout=NVFP4_SWIZZLED_BLOCK_SCALE_LAYOUT),
)
```

## Removed from `linear.py`

- `PCPOProjRowParallelLinear`, `PCPOProjLinearMethod` and `get_pcp_o_proj_batch_has_prefill`.
- The only remaining PCP-related addition there is the optional `tp_rank`/`tp_size` arguments on `RowParallelLinear`.

## Unchanged computation

- **Prefill or mixed batches:** async PCP all-gather of the TP weight shard, overlapped with attention, then the standard TP-local O-Proj.
- **Decode-only batches (`TOKEN_EXCHANGE`):** decode queries are replicated across PCP ranks, so each rank multiplies its slice of the input features by its resident weight shard and the results are summed across PCP. This is not a literal all-to-all; a true token A2A would need sharded decode ownership and could be added as another branch inside `PCPOProjTP`.

## Tests and docs

- `tests/model_executor/layers/test_pcp_o_proj_tp.py` is rewritten against `PCPOProjTP`, with new cases for path selection and the disabled feature.
- `docs/design/pcp_o_proj_tp.md` gains a "Module structure" section, path names and the new baseline commit.
- The full-model accuracy, memory and serving tables in the doc are from the previous branch and have not been rerun after this refactor.
