## Original PR description

## Purpose

Second AMD batch after #61817. Turns on `automatic_shard` for the native AMD mirrors of four steps whose CUDA side already shards (#60662, #60757). Only the flag changes; no commands or tests.

| Mirror | Command | Planned shards |
|---|---|---:|
| `amd-entrypoints-unit-tests` | one `pytest` over `entrypoints` unit tests | 2 |
| `amd-entrypoints-integration-speech_to_text` | one `pytest` | 2 |
| `amd-pytorch-compilation-passes-unit-tests` | the mirror's own `pytest` commands | 3 |
| `amd-v1-sample` | `export` setup, one `pytest` over `v1/sample` | 2 |

## Test Plan

- Planned each mirror with ci-infra main's `runtime_shard.plan_step` against this branch and main's `amd-<key>` timings on the mirror's own queue.
- Rendered each mirror with the pipeline generator and ran every shard's `VLLM_TEST_COMMANDS` against a mock test tree, as a PR build and with main's `pytest -p ci_otel` wrapper: every test of every command ran in exactly one shard, with the same env.
- `/ci run`, then compare each mirror's shards against its single job on main.
