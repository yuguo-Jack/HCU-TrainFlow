# [BugFix][Attention] Fixed UnboundLocalError in cascade attention meta…

[Upstream PR](https://github.com/vllm-project/vllm/pull/55674) · state: open · merged: False

## Original PR description

## Purpose
TritonAttentionMetadataBuilder.build() and RocmAttentionMetadataBuilder.build() raise UnboundLocalError when using cascade.
this Error occurs because prefix_scheduler_metadata is only assigned in the else. flash_attn.py already init it as None before the if statemate. I have done the same to fix the error to maintain consistency did that for other variables as well.

## Test Plan
Added test_builder_build_with_cascade_attention in tests/v1/attention, parametrized over both
builders, using common_prefix_len > 0 to exercise the cascade branch.

## Test Result
Fails with UnboundLocalError before the fix, passes after.
