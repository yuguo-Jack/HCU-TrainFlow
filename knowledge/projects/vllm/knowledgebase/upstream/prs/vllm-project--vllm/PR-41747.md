## Code Review

This pull request refactors the Mixture-of-Experts (MoE) implementation by centralizing gating logic within the FusedMoE layer. It updates the forward methods and internal runner functions to make router_logits an optional parameter and adds assertions to ensure consistent state when an internal gate is used. As a result, the forward logic in several models—including AXK1, DeepSeek, EXAONE, Qwen3, and Step3.5—has been simplified by removing manual gate computations. I have no feedback to provide.
