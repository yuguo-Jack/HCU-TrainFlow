# [KV Offload] Describe complete stores from request context

[Upstream PR](https://github.com/vllm-project/vllm/pull/63696) · state: closed · merged: True

## Original PR description

## Summary

Step B of the split from #52103, built on merged #63695.

- Build complete-chunk `BlockStored` payloads from the request carried by the raw store event and the existing key position in `ReqContext`. Partial tails still use the current metadata snapshot.
- Keep the existing block-granular `BlockRemoved` expansion from saved metadata. Chunk-key removals are deferred so this PR does not change the removal contract for downstream consumers.
- The previous delayed-request-status patch has been dropped; this PR does not change transfer-job or request-status handling.

## Scope

This remains draft. #59599 aligns block extra keys and should land before this is finalized. Follow-ups will handle partial tails and, with downstream coordination, chunk-key removals.
