# [Bugfix][Benchmark] Parse decode metrics as Prometheus samples

[Upstream PR](https://github.com/vllm-project/vllm/pull/56919) · state: open · merged: False

## Original PR description

## Purpose

Splitting Prometheus lines on whitespace leaves speculative and diffusion counters at zero when a model label contains spaces or samples include timestamps. Use the existing prometheus_client parser and treat invalid metric responses as unavailable.

Searches for fetch_spec_decode_metrics, fetch_diffusion_metrics and the label/timestamp failure found no competing open fix.

## Test Plan

`.venv/bin/python ../verify_serve_metrics.py`

The local CPU harness executes the exact added test functions and the production metric functions with real Prometheus-generated text. Full vLLM imports are unavailable in this Mac environment; serving and GPU evaluation were not run.

## Test Result

Six label/timestamp cases fail before; all ten cases pass after, including ordinary labels and non-metric responses. Changed-file pre-commit and Python 3.12 mypy pass.
