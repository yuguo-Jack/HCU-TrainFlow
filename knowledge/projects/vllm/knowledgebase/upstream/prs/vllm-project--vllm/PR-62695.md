# [Bugfix][DeepEPv2] Handle missing ibstat gracefully

[Upstream PR](https://github.com/vllm-project/vllm/pull/62695) · state: open · merged: False

## Original PR description

## Summary

This PR contains **two bugfixes**:

### 1. DeepEPv2 ibstat Handling (#62677)
DeepEPv2's bandwidth detection using `ibstat` fails with `ZeroDivisionError` in containerized environments. The SM count is used for optimization heuristics only; missing it does not prevent operation.

**Fix:** Wrap `get_theoretical_num_sms()` in try-except and log a warning.

### 2. FA3 Split-KV Cudagraph Wrong Logits (#62626)
FA3 combine kernel tile scheduler is **frozen at capture time** but replayed with a **different batch shape**, causing grid mismatch and wrong logits.

**Root cause:** Dummy batch has `max_seqlen_q = ceil(num_tokens / num_reqs)` but scheduler must handle worst case: one request with all tokens.

**Fix:** Set `seq_lens_cpu_upper_bound = num_tokens` for FULL graphs to ensure scheduler matches replay reality.

## Fixes
- #62677 — DeepEPv2 initialization fails on B300 clusters without ibstat
- #62626 — FA3 split-KV returns wrong logits with FULL cudagraph mode
