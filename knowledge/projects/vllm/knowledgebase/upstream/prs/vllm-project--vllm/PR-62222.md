# fix(moe): reject humming backend for online mxfp8 quantization

[Upstream PR](https://github.com/vllm-project/vllm/pull/62222) · state: open · merged: False

## Original PR description

The humming MoE backend expects pre-quantized checkpoint scales and crashes during weight conversion with a bare KeyError: \'weight_scale\' when paired with online MXFP8 quantization. This passes is_online=True from Mxfp8OnlineMoEMethod to the MXFP8 oracle so explicit --moe-backend humming raises a clear ValueError with suggested alternatives while auto-selection skips humming in favor of triton. Pre-quantized ModelOpt checkpoints continue to resolve to humming unchanged.

Fixes #62136
