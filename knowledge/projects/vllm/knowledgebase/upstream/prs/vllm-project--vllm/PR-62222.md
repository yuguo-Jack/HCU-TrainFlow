# fix(moe): add humming weight conversion in mxfp8 oracle

[Upstream PR](https://github.com/vllm-project/vllm/pull/62222) · state: closed · merged: False

## Original PR description

The humming MoE backend expects per-block weight scales installed prior to format conversion, causing a KeyError: 'weight_scale' during online MXFP8 setup. Rather than rejecting the backend, this introduces `convert_to_mxfp8_moe_kernel_format` in `oracle/mxfp8.py` to register the scale tensors and execute the Humming schema transformation directly.

Fixes #62136
