# [GLM5.3 Perf] Enable dspark fp8 kv cache for draft model, 5.38 GB GPU Memory saved per rank

[Upstream PR](https://github.com/vllm-project/vllm/pull/63841) · state: closed · merged: True

## Original PR description



## Overview

Enable dspark fp8 kv cache for draft model, perf nearly the same, but we save a lot of gpu memory

AI Analysis:

```bash
For RedHatAI/GLM-5.3-speculator.dspark at TP4, the three draft attention layers store 6,144 K/V values per token per GPU. That is 12 KiB in BF16 versus 6 KiB in FP8: a calculated saving of 6 KiB per cached token per GPU. At 8,192 cached tokens, the saving is 48 MiB per GPU.
An earlier run with the same FP8 DSpark behavior reported 940,736 KV cache slots and 47.18 GiB of cache per GPU. Holding that slot count and cache layout fixed, a BF16 draft would require approximately 52.56 GiB per GPU: 5.38 GiB more per GPU, or 21.53 GiB across TP4. At a fixed cache memory budget, this corresponds to approximately 11.4% more token slots.
```

So 5.38 GB saved each rank in the default config
