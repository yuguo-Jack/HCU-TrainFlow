## Original PR description

## Summary

This PR adds AITER's fused RoPE + KV cache kernels for DeepSeek MLA models on AMD ROCm. Uses a simplified unified fusion approach with dual RMSNorm optimization.

### Key Features
- **Fused Dual RMSNorm**: Uses AITER's `fused_qk_rmsnorm`
- **Unified RoPE + KV Cache Fusion**: Single kernel for both prefill and decode

### AITER Kernels Used
- `fused_qk_rmsnorm` - Dual RMSNorm fusion
- `fused_qk_rope_cat_and_cache_mla` - Unified RoPE + KV cache (prefill & decode)

- gemini-code-assist[bot] · comment · 2026-04-28T06:03:16Z · [source](https://github.com/vllm-project/vllm/pull/41101#discussion_r3151888392)

File: `vllm/model_executor/layers/attention/mla_attention.py` · line 579

![critical](https://www.gstatic.com/codereviewagent/critical.svg)

When `use_fused_path` is true, the KV cache update is handled by the fused kernel inside `forward_impl`. However, `self.impl.do_kv_cache_update()` is called unconditionally in this `forward` method before `forward_impl`. This results in a redundant and incorrect write to the KV cache, as it uses `k_pe` before RoPE has been applied. This call should be conditional and skipped when `use_fused_path` is true to prevent incorrect cache state and unnecessary operations.

- gemini-code-assist[bot] · comment · 2026-04-28T06:03:16Z · [source](https://github.com/vllm-project/vllm/pull/41101#discussion_r3151888393)

File: `vllm/_aiter_ops.py` · line 896

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The fake implementation uses `torch.empty_like(q_c)`, which preserves the dtype of the input tensor `q_c`. However, the docstring for the real implementation (`_rocm_aiter_mla_dual_rmsnorm_impl`) specifies that it returns `bfloat16` tensors. If the model is running with a different dtype (e.g., `float16`), this will create a dtype mismatch in the traced graph, which can lead to runtime errors. To ensure correctness, the fake implementation should explicitly create tensors with `torch.bfloat16` dtype.

```suggestion
    out1_normed = torch.empty(q_c.shape, dtype=torch.bfloat16, device=q_c.device)
    out2_normed = torch.empty(kv_c.shape, dtype=torch.bfloat16, device=kv_c.device)
```
