# [Perf][KV Offload] Speed up CPU-only Tiering startup

[Upstream PR](https://github.com/vllm-project/vllm/pull/64754) · state: open · merged: False

## Original PR description

## Overview

Use the existing CPU worker buffers for CPU-only Tiering and skip the scheduler’s unused mapping. Depends on #59547, which leaves Tiering on the shared layout.

## Claims

One paired DeepSeek-V4.1-Flash TP8+EP run on 8 H100s, same JIT archive: **382 → 250 s startup (35% shorter); 134.6 → 26.6 s KV initialization**.

## Validation

Four valid completions/run. Adapted frozen-runtime tests: `pytest --noconftest test_factory_frozen.py -k tiering` and `pytest --noconftest test_tiering_frozen.py`: **82 passed**; eight-GPU byte-exact roundtrip passed. Pre-commit passed for all changed files.

## Details

The measured `23cdd3b` overlay used 515.36 GiB physical versus 512 GiB control. This branch uses #59547's padding-budgeted sizing; exact-branch full-model validation remains pending. Canonical and secondary paths remain shared; graceful shutdown is unresolved.
