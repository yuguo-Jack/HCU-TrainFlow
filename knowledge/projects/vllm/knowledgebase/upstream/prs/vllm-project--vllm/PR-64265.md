# [Rust Frontend] Run utility calls to completion when the caller is cancelled

[Upstream PR](https://github.com/vllm-project/vllm/pull/64265) · state: closed · merged: True

## Original PR description

## Purpose

`EngineCoreClient::call_utility` fans a utility request out to every engine and waits for the replies. Dropping its future ran `UtilityCallGuard`, which unregistered the waiters, but since vllm-project/vllm#46051 each request is sent by a task on the client's ZMQ runtime, so requests already handed off were still sent and the engines executed them. Cancellation only abandoned the client-side bookkeeping, and the replies arrived with no waiter.

So a caller cannot tie state to a call's completion: anything it holds is released when its future is dropped, which can be before the engines see the request. vllm-project/vllm#63870 needs exactly that: readiness withdrawn for a pause must stay withdrawn until the engines have handled it, even if the HTTP or gRPC client that sent `/pause` disconnects.

This PR makes a utility call run to completion once its requests are prepared. The first commit moves the fan-out unchanged from `EngineCoreClient` to `ClientInner`, which owns the socket; the second changes it:

- The caller registers the waiters and encodes the requests, borrowing the arguments.
- One task on the client runtime sends the requests directly and collects every reply, so a utility call spawns once rather than once per engine through `send_to_engine`. The task unregisters the waiters of requests that failed to send.
- The caller awaits that task and decodes the replies, so neither the arguments nor the result type need `'static`.

Dropping the returned future now only stops waiting. `UtilityCallGuard` is removed. A call that fails while preparing still unregisters the waiters it allocated. If the client runtime shuts down during a call, the caller gets a `ClientClosed` error.

Not a duplicate: no open PR changes Rust utility call cancellation (searched `rust utility call cancel` and `call_utility`).
