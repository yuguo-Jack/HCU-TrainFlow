# [Recipe] Kimi-K3: add B300 AgentX aggregated Mooncake preset

## Original PR description

## Purpose

Adds the `b300_agentx_agg` preset to `recipes/models/moonshotai/Kimi-K3.yaml`, documenting the qualified InferenceX AgentX lane `kimik3-fp4-b300-vllm-agentic-dspark` from [SemiAnalysisAI/InferenceX#4381](https://github.com/SemiAnalysisAI/InferenceX/pull/4381) (pinned to `809f704`). It serves one 8-GPU B300 node with TP8 + DCP8, the Inferact DSpark draft, and an embedded RDMA Mooncake DRAM tier. B300 previously had only the generic Blackwell baseline.

- **Scope:** single-node aggregated, one hardware (`b300`), strategy `single_node_tp`. Opt-in (not `default`), because the lane carries benchmark-only settings.
- **Points:** concurrency 1, 4, 8, 12, 14, 16, 24, 28. DSpark K is 7 at c1, 5 at c4-8, 3 at c12-28. Each point sets `--max-num-seqs` (2x concurrency) and its CUDA graph capture sizes.
- **Image:** `vllm/vllm-openai@sha256:8c1434bfee7d7626eef78ef70600434ffba4a1b8813cb1d1c8707ad25f47035e`.
- **Left out, with reasons (in the runbook):** `--disable-uvicorn-access-log`, `PYTHONNOUSERSITE` and the benchmark client variables (harness/logging only); `RDMAV_DRIVERS` and `WITH_NVIDIA_PEERMEM` (specific to the lane's cluster).
- **Notes:** the recipe has no DCP selector, so the DCP8 flags are written in the preset. `--disable-flashinfer-autotune` from the Blackwell baseline is removed in favour of the lane's `--enable-flashinfer-autotune`.
