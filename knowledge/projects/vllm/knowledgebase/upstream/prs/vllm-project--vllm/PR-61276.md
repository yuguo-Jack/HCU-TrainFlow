# [Transformers backend] Run the output head of causal models

[Upstream PR](https://github.com/vllm-project/vllm/pull/61276) · state: open · merged: False

## Original PR description

## Overview

The Transformers modeling backend assumes every causal LM's output head is `lm_head`, plus `logit_scale`/`final_logit_softcapping` from the config. This PR runs the model's own `ForCausalLM` head instead, generalising #61246 (Ettin / ModernBERT decoder). Depends on #65446.

## Claims

- The model's `ForCausalLM` class (from Transformers or remote code) is built on meta with its base model stubbed to return `inputs_embeds` and its output embeddings calling vLLM's `lm_head`, so whatever it applies after the base model (scale, soft cap, dense -> act -> norm transform) runs as written.
- A probe at init sends heads that are only the projection (most models, e.g. Llama, Qwen, Mistral, Gemma) down the existing `lm_head` path, unchanged from `main`.
- Fixes the logprobs of models whose scale was ignored on `main` (Granite, GraniteMoe, HyperCLOVAX `logits_scaling`; greedy output was unaffected), and lets heads with a transform (Ettin / ModernBERT decoder, Roberta-likes) load.
- Under TP, kept heads run on all-gathered logits, so vocab-wide ops and `lm_head` LoRA work.
- Heads that cannot run without their base model (e.g. Mamba reads `lm_head.weight.dtype`) raise at init instead of producing wrong logits.

## Validation

Max |logprob difference| vs HF float32 (bf16, 4 prompts x 32 greedy tokens, B200), and throughput with `--model-impl transformers`:

| Model | Native | `main` | PR TP=1 | PR TP=2 | Output tok/s `main` -> PR |
|---|---|---|---|---|---|
| `ibm-granite/granite-3.3-2b-instruct` (scale) | 0.051 | **1.242** | 0.075 | 0.109 | 16,582 -> 17,133 |
| `google/gemma-2-2b-it` (soft cap) | 0.083 | 0.061 | 0.061 | 0.073 | 15,909 -> 17,226 |

bf16 noise is ~0.1; throughput is one run each, so the gain is noise rather than a speedup.

```bash
vllm bench throughput --model <model> --model-impl transformers --input-len 1024 --output-len 256 --num-prompts 1000 --gpu-memory-utilization 0.6
pytest tests/models/transformers/test_backend.py
```

Tests: all 58 `test_backend.py` tests pass on B200 (including 17 output head tests) with the `wrapper.py` fix from #65446, which `test_output_head_transform` (Ettin) needs.
