# docs: update CPU Docker images to reference Docker Hub instead of AWS ECR

[Upstream PR](https://github.com/vllm-project/vllm/pull/34882) · state: closed · merged: True

## Original PR description

## Purpose

Follow-up to #32032 and closes #33708.

PR #32032 added the pipeline to publish CPU images to Docker Hub
(`vllm/vllm-openai-cpu`). This PR updates the CPU installation
documentation to recommend the Docker Hub images instead of the AWS ECR
images.

## Changes

**`docs/getting_started/installation/cpu.x86.inc.md`**
- Replace `public.ecr.aws/q9t5s3a7/vllm-cpu-release-repo:latest` with `vllm/vllm-openai-cpu:latest`
- Add example for pulling a specific versioned tag
- Update Docker Hub gallery link (replacing ECR gallery link)
- Update `docker run` example to use Docker Hub image name

**`docs/getting_started/installation/cpu.arm.inc.md`**
- Replace `public.ecr.aws/q9t5s3a7/vllm-arm64-cpu-release-repo:latest` with `vllm/vllm-openai-cpu:latest-arm64`
- Update versioned tag from `vllm-arm64-cpu-release-repo:v${VLLM_VERSION}` to `vllm/vllm-openai-cpu:v${VLLM_VERSION}-arm64`
- Update Docker Hub gallery link
- Update `docker run` example

## Docker Hub Image Tags (from annotate-release.sh)

| Tag | Description |
|-----|-------------|
| `vllm/vllm-openai-cpu:latest` | Multi-arch manifest (x86_64 + arm64) |
| `vllm/vllm-openai-cpu:v<VERSION>` | Multi-arch manifest, specific version |
| `vllm/vllm-openai-cpu:latest-x86_64` | x86_64 only |
| `vllm/vllm-openai-cpu:latest-arm64` | ARM64 only |

## Test Plan

- Verified image names match the publish commands in `.buildkite/scripts/annotate-release.sh`
- Docker Hub repository: https://hub.docker.com/r/vllm/vllm-openai-cpu/tags
