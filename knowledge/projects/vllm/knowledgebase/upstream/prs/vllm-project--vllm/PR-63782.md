# [DRAFT][Perf] Pin FlashInfer CuTe-DSL kernels for all small-M Qwen3.8 BF16 GEMMs

[Upstream PR](https://github.com/vllm-project/vllm/pull/63782) · state: closed · merged: False

## Original PR description

## Overview

On GB300, `--linear-backend auto` now runs the small-M BF16 GEMMs of Qwen3.8 at TP1 with FlashInfer's CuTe-DSL kernels (direct, warp split-K, cluster split-K) at tactics pinned per weight shape and token count, instead of cuBLAS. The table covers 7 weight shapes (attention qkv/o, GDN in_proj_qkvz/in_proj_ba/out_proj, MLP gate_up/down, MTP fc) at 1-16 tokens, the decode and MTP-verify range.
