# fix(benchmarks): use platform FP8 dtype in MoE quant config

[Upstream PR](https://github.com/vllm-project/vllm/pull/54071) · state: open · merged: False

## Original PR description

## Summary

`benchmarks/kernels/benchmark_moe.py` casts MoE expert weights with `FP8_DTYPE` (`current_platform.fp8_dtype()`, e4m3fnuz on gfx942) then builds `FusedMoEQuantConfig` with hardcoded `torch.float8_e4m3fn`.

`FusedMoEQuantConfig.use_fp8_w8a8` is `quant_dtype == current_platform.fp8_dtype()`. On FNUZ those disagree, so `use_fp8_w8a8` is False and `--dtype fp8_w8a8` tuning dies in the unquantized path.

This change sets `quant_dtype = FP8_DTYPE` so the config matches the weight cast.

Fixes #54067
