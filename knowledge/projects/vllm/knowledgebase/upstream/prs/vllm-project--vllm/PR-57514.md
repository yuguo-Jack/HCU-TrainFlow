# [Fusion] Enable manual fusion in DeepseekV2, Mistral, Qwen2 and Qwen3MoE

[Upstream PR](https://github.com/vllm-project/vllm/pull/57514) · state: open · merged: False

## Original PR description

This PR adds the `maybe_fused_act_quant` interface for act+mul+quant manual fusion to the following models:
- DeepseekV2
- Mistral
- Qwen2
- Qwen3MoE

Currently, only DeepseekV2 and Qwen2 are being tested due to the limited kernel support (manual fusion currently only supports dynamic group + static per-tensor fused kernels). Dynamic per-tensor fused kernel has been implemented here https://github.com/vllm-project/vllm/pull/58664

#### Testing
```
pytest tests/compile/fusions_e2e/test_tp1_quant.py::test_tp1_fp8_fusions
pytest tests/model_executor/test_manual_fusion_models.py
```

This PR also includes changes from https://github.com/vllm-project/vllm/pull/55338

Made with the help of Claude, all code has been manually reviewed.
