# [ROCm][DSv4.1] KV-only insert for the DSpark context KV

[Upstream PR](https://github.com/vllm-project/vllm/pull/60076) · state: open · merged: False

## Original PR description

## Overview

The DSpark context KV insert built a zero query of [tokens, local heads, 512] and ran the fused Q+KV insert on it, then dropped the query.
This PR enables the KV-only fused_deepseek_v4_kv_rope_insert (#56441), as the NVIDIA DSpark model already does.

## Claims
MI355X, 16,384 context tokens per call: no extra memory, 18-19 us per call instead of 163-602 us.

test_dspark_context_kv_matches_query_insert, CUDA-only so far, now also runs the ROCm function on ROCm (byte-exact against the query insert, all four cache records, with and without graph replay).

This leads to less memory usage (no dummy query tensor) and faster kv insert for dspark.

Deepseek-v4 ROCm DSpark has the same issue but this PR focuses on dsv41.
