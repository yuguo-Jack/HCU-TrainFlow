# [Bugfix][KV Connector] Pair non-divisible hybrid MLA block sizes in NixlConnector

[Upstream PR](https://github.com/vllm-project/vllm/pull/61002) · state: closed · merged: True

## Original PR description

NixlConnector now pairs P/D blocks of a hybrid MLA model when neither block size divides the other. That happens when P and D run different TP on ROCm. Kimi-K3 with P TP2 (2944-token blocks) and D TP1 (5760) used to fail the handshake and now runs.  Hybrid block sizes follow the TP-sharded SSM page, so P and D pick different sizes when their TP differs. On CUDA, MLA backends force 64-token kernel blocks, so the sizes always divide. ROCm AITER MLA accepts any kernel block size, so `block_size_ratio` asserts. During the handshake, `_split_remote_blocks` now views the remote blocks as gcd-sized kernel blocks (2944 → 23 × 128). The existing `block_size_ratio > 1` path then pairs them with D's 45 sub-blocks and zeroes the untransferred tail. This only applies to hybrid MLA with plainly strided remote regions. With prefix caching on, D still rejects such pairs through the existing hybrid check, as on CUDA.

- Hybrid MLA P/D with non-divisible block sizes transfers in gcd-sized units (128 tokens for Kimi-K3) instead of asserting at the handshake.
- Pairs that work today never reach the new code, so they are unaffected.

On MI355 with AITER MLA:
- `test_prefix_cache.py -k pd-tp2-dep2` (Kimi-K3): failed the handshake before; now 4/4 pass, 10/10 runs.
- Also added a new `test_hetero_non_divisible_block_sizes`: 28 fail before, 28 pass after.

The model-level runs used `moonshotai/Kimi-Linear-48B-A3B-Instruct` with NIXL P/D, 5 interleaved runs per column, each with fresh servers. Values are mean ± sd.

| `vllm bench serve` (4096 in / 128 out, conc 16) | Before | After |
|---|---|---|
| P TP2 → D TP1, equal 2048 blocks: req/s | 3.478 ± 0.077 | 3.480 ± 0.045 |
| P TP2 → D TP1, equal 2048 blocks: TPOT (ms) | 29.54 ± 0.65 | 29.36 ± 0.55 |
| P TP2 → D TP1, 1024 → 1920: req/s | handshake assert | 3.432 ± 0.027 |

| gsm8k strict-match (5-shot, n=1319) | Before | After |
|---|---|---|
| P TP2 → D TP1, equal 2048 blocks | 0.8748 ± 0.0034 | 0.8748 ± 0.0025 |
| P TP2 → D TP1, 1024 → 1920 | handshake assert | 0.8748 ± 0.0020 |
| P TP1 → D TP2, 1920 → 1024 | handshake assert | 0.8732 ± 0.0031 |

The existing ROCm NIXL P/D accuracy groups also pass.
