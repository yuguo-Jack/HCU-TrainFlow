## Original PR description

Fixes #31414

**Purpose**
This PR resolves the naming confusion between `vllm.utils.flashinfer` and `vllm.model_executor.layers.quantization.utils.flashinfer_utils` by renaming the latter to `flashinfer_moe.py`. Since the utilities in this file are strictly MoE-specific (e.g. `FlashinferMoeBackend`, weight layout conversions for FP4/FP8 MoE), renaming it to `flashinfer_moe.py` makes its scope obvious and avoids mixing general flashinfer utilities with MoE-specific ones. This implements Option 2 from the issue discussion. All import sites have been updated accordingly.
