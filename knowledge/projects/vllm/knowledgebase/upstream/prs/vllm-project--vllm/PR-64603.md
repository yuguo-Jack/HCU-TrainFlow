# [Kernel] --linear-backend=flashinfer: use FI backend="auto" with default settings for linear GEMMs

[Upstream PR](https://github.com/vllm-project/vllm/pull/64603) · state: open · merged: False

## Original PR description

## Overview

Allow to select best implementation of linear gemm from Flashinfer. This new approach uses auto backend in autotuner that sweeps over all available backends since https://github.com/flashinfer-ai/flashinfer/pull/6392 was recently merged in new FI v0.7.2.post1 and integrated to vLLM https://github.com/vllm-project/vllm/pull/63466.

Currently, I use default value of PDL flag in FI (PDL=false). This still does not allow to sweep over some gemm kernels implementations in FI that use PDL=true. In parallel to this PR I will open a PR to FI that enables sweep over both PDL=false and PDL=true in case default value is set.
After PR in FI is merged and a new FI release is bumped in vllm, I will set --linear-backend to `flashinfer` by default to enable us using the most performant gemm kernel in runtime.
