# v1: replace Triton logprob kernels with native PyTorch for 100x speedup

[Upstream PR](https://github.com/vllm-project/vllm/pull/63919) · state: open · merged: False

## Original PR description

## Summary

This PR replaces the slow Triton kernels `_topk_log_softmax_kernel` and `_ranks_kernel` in `vllm/v1/worker/gpu/sample/logprob.py` with native PyTorch operations (`torch.logsumexp`, `torch.gather`, `torch.topk`).

## Motivation

As reported in issue #55577, the Triton kernels are ~100x slower than native PyTorch operations for prompt logprobs on long sequences (e.g., 16.8s to 0.13s for 8K tokens with vocab size 128K).

The Triton kernels perform iterative reductions over the vocabulary dimension (chunked by BLOCK_SIZE=1024), which is heavily memory-bound. PyTorch's native `torch.topk` uses optimized CUDA radix-selection and warp-level reduction kernels tailored for tensor core architectures, and `torch.logsumexp` leverages fast vectorized memory reads.

## Changes

1. **`compute_token_logprobs`**: Replaced Triton kernel with:
   ```python
   lse = torch.logsumexp(logits, dim=-1, keepdim=True)
   logprobs = logits.gather(-1, token_ids) - lse
   ```

2. **`compute_topk_scores`**: Replaced `_ranks_kernel` with:
   ```python
   sampled_logits = logits.gather(-1, sampled_token_ids.unsqueeze(-1))
   token_ranks = (logits >= sampled_logits).sum(dim=-1, dtype=torch.int64)
   ```

3. **Removed**: Unused Triton kernels (`_topk_log_softmax_kernel`, `_ranks_kernel`), unused constant `_MAX_TOPK_BLOCK`, and unused `numpy` import.

4. **Preserved**: `_fill_logprob_token_ids_kernel` (still needed for custom `logprob_token_ids` per request).

## Performance

From issue #55577 benchmarks (RTX 4090, Llama-3.1-8B, V=128,256, T=8192, K=32):

| Component | Triton (before) | PyTorch (after) | Speedup |
|-----------|-----------------|-----------------|---------|
| Chunk 0:1024 | ~2.10s | 0.012s | **175x** |
| Full 8k Prompt Logprobs | **16.80s** | **0.13s-0.19s** | **~100x** |
| Total Request Latency | 18.2s (~450 tok/s) | 1.61s (~5,087 tok/s) | **11.3x** |
