# Add tuned fused_moe config for Qwen3-Coder-Next-FP8 on NVIDIA GB10

[Upstream PR](https://github.com/vllm-project/vllm/pull/45949) · state: closed · merged: False

## Original PR description

Benchmarked on a single NVIDIA DGX Spark (GB10) for the Qwen3-Coder-Next-FP8 MoE shape (E=512, N=512, fp8_w8a8, block_shape=[128,128]). No existing config was found for this device, so vLLM fell back to the default config with a 'performance might be sub-optimal' warning on every boot.

## Purpose 
No tuned fused_moe config exists for NVIDIA GB10 (DGX Spark). vLLM falls back to a default config and logs a "performance might be sub-optimal" warning on every boot when serving Qwen3-Coder-Next-FP8 on this hardware.

## Test Plan
Ran vLLM's fused_moe kernel tuning benchmark on a single DGX Spark (GB10)  for the shape used by Qwen3-Coder-Next-FP8 (E=512, N=512, fp8_w8a8, block_shape=[128,128]). 

## Test Result
With the config in place, vLLM picks up the tuned kernel parameters automatically and the "Using default MoE config" warning no longer appears on startup. I think there's a mild speed boost from this but I didn't capture A/B test results.
