# Rename flashinfer_utils.py → flashinfer_moe.py for clarity

[Upstream PR](https://github.com/vllm-project/vllm/pull/49867) · state: closed · merged: False

## Original PR description

The coexistence of `flashinfer_utils.py` and `flashinfer.py` was confusing. Rename `flashinfer_utils.py` → `flashinfer_moe.py` to make it clear that this module contains MoE-specific utilities (weight layout conversions, activation type translation, scaling factor handling), while `vllm/utils/flashinfer.py` holds general FlashInfer availability checks and GEMM/attention wrappers.

Pure rename — no behavioral changes. All 12 import sites updated.

Closes #31414
