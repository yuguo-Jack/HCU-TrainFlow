# [CI][Intel] Skip ROCm-only test_topk_gating_enabled_by_cdna on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/61932) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Skip the ROCm/CDNA-only `test_topk_gating_enabled_by_cdna` test in the Intel XPU Model Executor CI job.

## Claims

- Excludes a test that is specific to AMD CDNA3/CDNA4 + AITER MoE from the Intel XPU CI run, where it adds no coverage.

## Validation

Verified locally with `pytest --collect-only` in `tests/`:

```
pytest --collect-only -q model_executor -m "not slow_test" \
  --ignore="model_executor/layers/test_rocm_unquantized_gemm.py" \
  --ignore="model_executor/model_loader/tensorizer_loader/test_tensorizer.py" \
  --ignore="model_executor/model_loader/test_reload.py" \
  --deselect="tests/model_executor/test_enabled_custom_ops.py::test_topk_gating_enabled_by_cdna"
# 1100/1109 tests collected (9 deselected), confirming all 5 parametrized
# cases of test_topk_gating_enabled_by_cdna are excluded along with the
# pre-existing 4 slow_test-marker deselections.
```

## Details

`test_topk_gating_enabled_by_cdna` exercises `rocm_aiter_ops.is_topk_gating_enabled()` behavior gated on AMD CDNA3/CDNA4 + AITER MoE and is not applicable to Intel XPU. A single `--deselect` naming the test function (without parameter IDs) correctly excludes all of its parametrized variants, as long as the nodeid path is given relative to the pytest rootdir (`tests/...`), matching the style already used elsewhere in this file.
