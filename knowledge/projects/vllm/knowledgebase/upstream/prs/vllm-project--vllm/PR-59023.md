# [ROCm][Kimi-K3] bf16 router GEMM and fused MLA output gate

[Upstream PR](https://github.com/vllm-project/vllm/pull/59023) · state: open · merged: False

## Original PR description

## Purpose

Add two Kimi-K3 ROCm decode optimizations on gfx950:

1. Extend the existing low-token FP32-logit router GEMM to Kimi-K3's
   BF16-weight `7168 x 896` gate for up to 9 tokens. Larger batches and
   unsupported layouts retain the `torch.mm(..., out_dtype=torch.float32)` or
   `F.linear` fallback.
2. Fuse MLA's `attn_out * sigmoid(g_proj)` into one Triton kernel, replacing
   separate sigmoid and multiply launches. Non-contiguous or mismatched
   tensors retain the torch expression.

The router path coexists with upstream's ROCm BF16x3 tier: BF16x3 continues to
serve FP32 router weights at larger batches, while this change serves the
Kimi-K3 BF16 weight at low M.

No other open PR implements the `7168 x 896` BF16-weight route or fused Kimi-K3
MLA output gate.

Router kernel on MI355X:

| Tokens | `torch.mm` | Kernel |
|---:|---:|---:|
| 1 | 11.03 us | 2.62 us |
| 4 | 11.10 us | 4.13 us |
| 8 | 11.14 us | 6.15 us |
| 9 | 11.16 us | 7.28 us |
| 14 | 7.72 us | 9.40 us (not selected) |

The fused gate replaces 4.07 + 4.41 us of launches per layer with a 4.19 us
kernel, about 0.1 ms per decode step. A same-node conc-1 proxy comparison with
the gate present in both arms improved estimated p90 interactivity from 173.86
to 178.33 tok/s when enabling the router kernel.

## Test Plan

Extend the existing router kernel and dispatch tests, and test the Kimi-K3
gate kernel directly:

```bash
python3 -m pytest -q \
  tests/kernels/test_rocm_fp32_router_gemm.py \
  tests/kernels/test_gate_linear_rocm_dispatch.py \
  tests/models/kimi_k3/test_amd_sigmoid_gate.py
```

Coverage includes:

- all existing FP32 router shapes plus BF16-weight correctness at 0–9 tokens;
- custom-op dispatch at the 9/10-token fallback boundary;
- gate eligibility through constructor and late `set_out_dtype`;
- rejection on gfx942, bias, unsupported shapes, and non-FP32 logits;
- fused sigmoid-gate parity for BF16/FP16/FP32 and non-contiguous fallback.

