# [Bugfix] [Docs] Return 501 for thinking models in v1/systemone

[Upstream PR](https://github.com/vllm-project/vllm/pull/63509) · state: closed · merged: False

## Original PR description

Co-authored-by: Codex

## AI Disclosure
Codex was used to help read and write code, and to write unit tests.


## Overview



Fixes #61215.

If the `<think>` block is the last token in the model prompt template, it returns 501 because /v1/systemone requires the first token to be the answer. Thinking models instead reply with thoughts that are noise when converted to probabilities expecting an answer.

## Claims


Fixes issue linked above. Before, thinking-only models would return noise rather than a proper probability.

## Validation


Added a unit test, and locally verified with the original reproduction steps that the issue no longer occurs.

## Details


This PR mainly detects qwen thinking-only checkpoints, using the <think> block in their prompt. If it is not present, then other thinking-only models will encounter similar issues.
