# benchmarks: add speculative decoding analysis script

[Upstream PR](https://github.com/vllm-project/vllm/pull/49825) · state: open · merged: False

## Original PR description

## Purpose

Adds `benchmarks/benchmark_spec_decode_analysis.py` — a dedicated script for profiling the speculative decoding efficiency curve across different speculation lengths (gamma).

**Gap this fills:** the existing `benchmarks/` scripts measure aggregate throughput and latency but none of them sweep `num_speculative_tokens` (gamma) to show *how* acceptance rate, speedup, and memory change as gamma increases. This is the key decision variable when configuring speculative decoding in production.

**What it records per gamma value:**
- Draft token acceptance rate (read from `SpecDecodeWorkerMetrics` when available; estimated from observed speedup as fallback using `alpha = (speedup - 1) / gamma`)
- Output throughput (tokens/s)
- Mean / P50 / P95 / P99 request latency (ms)
- GPU memory allocation (GB)
- Speedup vs. baseline (no speculative decoding)

Results are printed as a formatted table and optionally saved to JSON via `--output-json`.

## Test Plan

```bash
# Baseline only (no draft model)
python benchmarks/benchmark_spec_decode_analysis.py \
    --model meta-llama/Llama-3.1-8B-Instruct \
    --num-prompts 200

# Full gamma sweep
python benchmarks/benchmark_spec_decode_analysis.py \
    --model meta-llama/Llama-3.1-8B-Instruct \
    --speculative-model meta-llama/Llama-3.2-1B-Instruct \
    --gamma-sweep 1 2 4 6 8 \
    --num-prompts 200 \
    --output-json results.json
```
