# [Kernel][Quantization][XPU] Tensor-descriptor path for fused_moe_kernel_gptq_awq (int4)

[Upstream PR](https://github.com/vllm-project/vllm/pull/52652) · state: open · merged: False

## Original PR description

## Purpose

Adds a tensor-descriptor (TD) path to `fused_moe_kernel_gptq_awq` for `int4_w4a16`, mirroring the one [#42436](https://github.com/vllm-project/vllm/pull/42436) added to `fused_moe_kernel` (RFC [#42545](https://github.com/vllm-project/vllm/issues/42545)). A is gathered with `tensor_descriptor.gather`; packed int4 B is loaded as bytes and unpacked with `tl.interleave`. `int8_w8a16` keeps the pointer path.

TD is taken when `VLLM_TRITON_USE_TD` resolves on (default on XPU, opt-in elsewhere) and `moe_use_td_hw_supported()` holds (XPU, CUDA sm100+). The launcher falls back to the pointer path for:
- `BLOCK_SIZE_M < 8`: `gather()` minimum. The CUDA WNA16 default config emits 1/2/4 via `TritonWNA16Experts.apply`.
- `BLOCK_SIZE_M == 32`: TD is ~40% slower there on Arc Pro B60 (see Test Result).
- `M == 1`: descriptor setup does not pay off.
- `K % BLOCK_SIZE_K != 0`: same bail-out as `invoke_fused_moe_triton_kernel`.
- `BLOCK_SIZE_K < 32`: the packed-byte descriptor needs a 16-byte inner block.

Overlap: [#52577](https://github.com/vllm-project/vllm/pull/52577) masks the pointer-path B load, which this PR moves under `else:`. The conflict is textual only. No open PR adds TD to this kernel.

## Test Plan

```
pytest -v tests/kernels/moe/test_moe.py -k "wn16 or wna16"
```

- `test_fused_moe_wn16`: a new `use_td` leg compares TD against the pointer path (1 bf16 ULP) and the reference. A launch spy asserts which path actually ran.
- `test_fused_moe_wn16_td_forced_config`: forced `BLOCK_SIZE_M=8` and an N-tail config.
- `test_wna16_triton_launcher_td_gate`: fallback decisions, using a fake kernel.

A new Intel CI step runs the command above. No Intel step ran `tests/kernels/moe` before.

Kernel benchmark: `fused_experts` latency, `Qwen/Qwen1.5-MoE-A2.7B-Chat-GPTQ-Int4` shapes (E=60, N=1408, K=2048, top-k 4, group 128), default tiles, median of 7 rounds with TD and pointer legs interleaved. Pointer-vs-pointer on identical code differs by ≤0.5%.

E2E: `vllm serve Qwen/Qwen1.5-MoE-A2.7B-Chat-GPTQ-Int4 --quantization moe_wna16 --moe-backend triton --enforce-eager --no-enable-prefix-caching`, measured with `vllm bench sweep serve`. Accuracy: `lm_eval --tasks gsm8k --num_fewshot 5` with the same engine args.
