# [Kernel] 支持 RTX PRO 6000D 的可选 B12X FP8 尾部投影

[Upstream PR](https://github.com/vllm-project/vllm/pull/62618) · state: open · merged: False

## Original PR description



## Overview

为 B12X 增加可选的 N3392/K4096 FP8 投影适配：权重输出维补至3456，计算后恢复3392的逻辑宽度。仅针对已测6000D SKU，默认关闭。

来源：[Pro6000d-community公开实现与历史测试](https://github.com/PacoZhou1/Pro6000d-community/tree/d2c0ec3be319b7d8949778eefd15bb77fa693b8d)。贡献重点是尽可能为RTX PRO 6000D的具体模型算子做适配与优化；不主张此前无人优化该GPU或全球首次。

## Claims

- 保留逻辑参数和weight loader形状，支持bias及2D/3D输出恢复。
- 重载时保留权重与scale的存储地址，避免CUDA Graph持有旧storage。
- 开关只扩大这一形状的B12X eligibility，不更改全局后端优先级。

## Details

复用B12X算术内核，保持同一scale block布局，裁回逻辑输出后加bias。B12X须已安装并被选择。DS4 M4 packed-route属于外部voipmonitor/b12x项目，不包含在此PR中。

去重：#48588 是 CUTLASS 的非对齐N padding，本PR针对B12X及6000D适用边界；不主张发明零补齐机制。QKV loader #57508 已由原作者合并，未重复提交。

底层vLLM、CuTe、B12X、SGLang及模型架构保留各自作者归属；不包含模型权重、业务数据、私有部署配置或私有项目Git历史。**本次移植使用了AI辅助。提交人已确认审阅本轮补丁并承担贡献责任，提交包含DCO Signed-off-by。**
