# [ROCm][Step5] Enable shared Step5 Triton kernels

[Upstream PR](https://github.com/vllm-project/vllm/pull/61945) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Port #61727's fused Step5 kernels to ROCm, complementing #61837's model/cache backend. Stacked on `f50c275cc651`; [incremental diff](https://github.com/YukioZzz/vllm/compare/f50c275cc651bd88a036402b85249d4a6f2c2b87...step5-rocm-triton-compat).

## Claims

- Share preparation, summary, scoring, and gated attention kernels in `step5/common/ops`, with HIP-compatible math, launches, and pointer stores.
- Reuse `_prepare_main` for SWA preparation. Support 4/8/16 indexer heads; use BF16 dot operands on ROCm while retaining FP8 summary storage.
- Keep changing capacities, strides, and slot counts as runtime parameters to avoid recompilation.

## Validation

**21 kernel/adapter tests passed** on MI355X, covering scoring, mixed request lengths, memory layouts, and partial KV writes, with unchanged tolerances.

Local integration with #61837 (`bf2ccfc`): **4×MI355X, TP4, Step-5-Preview FP8, BF16 KV, PIECEWISE graphs**. GSM8K: **96.89% (1278/1319)** with currency-compatible answer extraction.

| Workload | #61837 | Local fused integration |
|---|---:|---:|
| GSM8K, 1,319 questions, concurrency 64 — elapsed time | 432.86 s | **401.64 s** |
| Random 8k/1k, concurrency 8 — output tokens/s | 171.25–177.56 | **188.56–190.34** |
| Random 8k/1k ±20%, concurrency 8 — output tokens/s | 165.62–166.11 | **184.56–184.99** |

Ranges span two runs with identical requests and settings across implementations. Fused paths were confirmed on all four workers.

## Details
