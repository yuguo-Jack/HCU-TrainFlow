# [Bugfix][KV Offload][P2P] Quarantine consumer slots until writes settle

[Upstream PR](https://github.com/vllm-project/vllm/pull/61667) · state: open · merged: False

## Original PR description

## Overview

Fixes #61532 by retaining consumer CPU destination slots when a P2P load fails before remote WRITE completion is confirmed. This follows the [consumer-only scope requested in the issue](https://github.com/vllm-project/vllm/issues/61532#issuecomment-6165941559) and builds on the producer fix already merged in #59790.

## Claims

- An abort-ack timeout for a sent fetch reports failure once and makes the keys miss, while keeping their slots unavailable to other requests.
- A late completion/abort acknowledgement releases quarantined slots without reporting the failed load as successful. Session close preserves quarantine when confirmation can no longer arrive.
- Never-sent fetches fail safely on handshake failure, cancellation or load timeout. Retired queued messages cannot be sent later, including after request-ID reuse.
- Quarantined slots remain counted as pending writes until confirmation. Cache reset rejects unresolved quarantine, including failures first discovered while draining, and retries when a late terminal confirmation makes the drain safe.

## Details

1. The producer starts a WRITE into CPU slots reserved by the consumer.
2. The consumer's abort-ack timer expires, or its session closes. Neither event establishes that the WRITE has stopped, so immediately recycling these slots can let a late WRITE corrupt a different request.
3. `memory_safe=False` separates request failure from permission to reclaim memory. The tiering manager removes failed keys from lookup while keeping their chunk IDs quarantined. A subsequent memory-safe result releases the IDs without recording a second completion.

Track the queued Fetch object until handoff to the transport, so a retired message cannot match a newer load with reused request/round IDs. Never-sent fetches fail locally without sending an abort. The send gate also checks the original load deadline, so a delayed handshake cannot flush an already-expired fetch before the timeout walk. This addresses the [delayed-handshake review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4283622153). Connection liveness is checked before recording handoff, so later queued fetches remain safe after an earlier send kills the connection. A raising send on a live connection remains conservatively unsafe because it may already have exposed destination IDs. This also addresses the [dead-connection review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4274467514). This addresses the [queued-fetch review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4274078909).

CPU write occupancy and tier promotion/write gauges stay charged throughout quarantine and decrease only on confirmed release; failure is counted once. This addresses the [accounting review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4274078928).

P2P draining stops on an unconfirmed unsafe result instead of waiting forever. It checks result safety before returning idle, including when a disconnect has removed the last session. This addresses the [reaped-session drain review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4283622168). Reset consumes results before rejecting an unsafe drain. If a late terminal result confirms safety during that poll, reset retries the interrupted tier and drains the remaining tiers. A typed `UnsafeTransferError` keeps unrelated drain errors visible. This also addresses the [late-confirmation reset review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4275023865). This addresses the [drain review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4274467527).

The connector scheduler notifies finished requests before draining the manager, allowing a bound producer round with parked jobs but no active NIXL transfer to settle. Each successful notification is recorded once. Flush IDs, request deletion and job/stale bookkeeping changes are committed only after the manager reset succeeds. If quarantine rejects reset, request/job records remain usable for retry and late worker completion; normal metadata construction skips further stores and duplicate finish notifications for already-signaled requests. Successful resets still deliver worker flush IDs and ignore old completions. This addresses the [producer ordering review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4290287893) and the [rejected-reset review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4289843026).

Late terminal notifications carry whether their failure was already reported. They still release quarantine, but do not add a finished request ID to the failure set again; session close likewise omits already-reported failures. Results also carry local request completion, including queued cancellations and buffered results, so a first failure arriving after request cleanup cannot restore a stale failure ID. A reused ID starts with fresh load state. This also addresses the [cancelled-fetch cleanup review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4275023850). This addresses the [request-failure review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4274467538).

Rebased onto `9cede34a674c` after the [merge-conflict notice](https://github.com/vllm-project/vllm/pull/61667#issuecomment-6190452982). This retains upstream lookup deadlines/cleanup and the new manager lock/tier-poll thread. The quarantine regression now covers both unsafe results and late safe release through `poll_tiers()` under the manager lock, in addition to step/drain paths. The CUDA generation run enabled the upstream default tier-poll thread.

Validated `TransferDone` and `AbortAck` messages already buffered by the control transport still settle existing loads after a disconnect is observed. Other messages stay suppressed, so draining the inbox cannot start new fetches or handshakes. Unconfirmed loads remain unsafe at close, and malformed terminal messages cannot release their slots. This addresses the [buffered-terminal review](https://github.com/vllm-project/vllm/pull/61667#discussion_r4280126143).

The latest rebase retains upstream promotion-latency recording and NIXL agent-removal changes. A promotion's initial failed completion records one latency sample while its write occupancy stays charged; late terminal confirmation releases that occupancy without recording another completion or latency. The existing quarantine regression covers this combination.

The default `memory_safe=True` preserves existing results from other secondary tiers. No producer transport or server behavior is changed. Chunk IDs are converted to a list at the existing session boundary to satisfy its `Sequence[int]` contract.

Tradeoff: if a peer never confirms completion, or the session is closed, quarantined capacity remains unavailable until engine shutdown. Reset rejects that state instead of recycling potentially live WRITE targets. Stop peers before restarting the engine. Producers must also contain #59790 so an abort acknowledgement really means the WRITE is terminal.

```python
"""Exercise real P2P sessions and UCX writes with GPU-produced payloads.

No transport states are mocked. A child producer is SIGSTOPped while a
WRITE is PROC/PEND. The abort-ack timer is shortened to avoid ZMQ heartbeat
expiry; production source files are unchanged. CPU-primary quarantine and
release use the actual allocator APIs; scheduler result routing is covered
separately by the repository regression tests.
"""

import argparse
import faulthandler
import gc
import json
import multiprocessing as mp
import os
import signal
import socket
import subprocess
import sys
import time
import traceback
import uuid
from pathlib import Path

import numpy as np
import torch
import zmq

from vllm.v1.kv_offload.base import LookupResult, ReqContext, make_offload_key
from vllm.v1.kv_offload.tiering.p2p.control.zmq import ZmqTransport
from vllm.v1.kv_offload.tiering.p2p.data.nixl import NixlTransport
from vllm.v1.kv_offload.tiering.p2p.session import P2PSession
from vllm.v1.kv_offload.tiering.p2p.session import client as client_module

BLOCKS = 64
BLOCK_BYTES = 16 * 1024 * 1024
PAYLOAD = 90
REQUEST = "lifetime-probe"
KEYS = [make_offload_key(f"probe-{i}".encode(), 0) for i in range(BLOCKS)]


def free_port():
    with socket.socket() as sock:
        sock.bind(("127.0.0.1", 0))
        return sock.getsockname()[1]


def producer(control_port, consumer_id, consumer_pid, management):
    data = control = session = None
    try:
        gpu = torch.full((BLOCKS, BLOCK_BYTES), PAYLOAD, dtype=torch.uint8, device="cuda")
        payload = gpu.cpu().numpy()
        del gpu
        torch.cuda.empty_cache()
        local_id = f"127.0.0.1:{control_port}"
        reported = False

        class PausingNixlTransport(NixlTransport):
            def write_blocks(self, peer_id, local_idxs, remote_idxs):
                nonlocal reported
                os.kill(consumer_pid, signal.SIGSTOP)
                transfer_id = super().write_blocks(peer_id, local_idxs, remote_idxs)
                if transfer_id is not None and not reported:
                    state = self._agent.check_xfer_state(self._inflight[transfer_id].handle)
                    management.send({"event": "submitted", "state": state})
                    if state in ("PROC", "PEND"):
                        management.send({"event": "running", "states": [state]})
                        reported = True
                        os.kill(os.getpid(), signal.SIGSTOP)
                os.kill(consumer_pid, signal.SIGCONT)
                return transfer_id

        data = PausingNixlTransport(f"producer-{os.getpid()}", memoryview(payload), num_threads=1)
        assert data.available, "NIXL transport unavailable"
        control = ZmqTransport(local_id, "127.0.0.1", control_port)
        control._zmq_ctx.setsockopt(zmq.LINGER, 0)
        control._router.setsockopt(zmq.LINGER, 0)
        session = P2PSession(consumer_id, local_id, data, BLOCK_BYTES, "0")
        management.send({"event": "listening"})
        supplied = completed = False
        end = time.monotonic() + 120
        while time.monotonic() < end:
            if management.poll() and management.recv() == "quit":
                break
            for conn in control.poll():
                session.attach_connection(conn)
            if session.ready and not supplied:
                session.add_stored_blocks(REQUEST, KEYS, list(range(BLOCKS)), 100)
                supplied = True
            session.poll()
            if data._inflight and not reported:
                states = [data._agent.check_xfer_state(x.handle) for x in data._inflight.values()]
                if any(s in ("PROC", "PEND") for s in states):
                    management.send({"event": "running", "states": states})
                    reported = True
                    os.kill(os.getpid(), signal.SIGSTOP)
            if reported and not data._inflight and not completed:
                management.send({"event": "terminal"})
                completed = True
            time.sleep(0.001)
        else:
            raise TimeoutError("producer exceeded 120 seconds")
    except Exception:
        management.send({"event": "error", "traceback": traceback.format_exc()})
        raise
    finally:
        if session is not None:
            session.close()
        if data is not None:
            data.close()
        if control is not None:
            control.close()


def run_case(mode):
    from vllm.v1.kv_offload.cpu.shared_offload_region import SharedOffloadRegion
    from vllm.v1.kv_offload.tiering.manager import CPUPrimaryTierOffloadingManager

    faulthandler.dump_traceback_later(45, repeat=True)
    client_module._ABORT_ACK_TIMEOUT_S = 0.5
    parent_pipe, child_pipe = mp.get_context("spawn").Pipe()
    consumer_port, producer_port = free_port(), free_port()
    consumer_id = f"127.0.0.1:{consumer_port}"
    producer_id = f"127.0.0.1:{producer_port}"
    process = mp.get_context("spawn").Process(target=producer, args=(producer_port, consumer_id, os.getpid(), child_pipe))
    region = data = control = session = primary = view = None
    paused = False
    events = []
    watchdog = None
    def checkpoint(name):
        print(json.dumps({"stage": name, "case": mode, "pid": os.getpid()}), flush=True)

    try:
        region = SharedOffloadRegion(f"probe_{uuid.uuid4().hex}", BLOCKS, None, BLOCK_BYTES, BLOCK_BYTES)
        primary = CPUPrimaryTierOffloadingManager(BLOCKS, region)
        view = primary.get_kv_memoryview()
        np.frombuffer(view, dtype=np.uint8).fill(0)
        ctx = ReqContext(req_id=REQUEST)
        prepared = primary.prepare_write(KEYS, ctx)
        assert prepared is not None
        chunk_ids = [int(i) for i in prepared.store_spec.chunk_ids]
        data = NixlTransport(f"consumer-{os.getpid()}-{mode}", view, num_threads=1)
        assert data.available
        control = ZmqTransport(consumer_id, "127.0.0.1", consumer_port)
        control._zmq_ctx.setsockopt(zmq.LINGER, 0)
        control._router.setsockopt(zmq.LINGER, 0)
        process.start()
        assert parent_pipe.poll(120), "producer startup timed out"
        event = parent_pipe.recv()
        assert event["event"] == "listening", event
        conn = control.connect(producer_id)
        session = P2PSession(producer_id, consumer_id, data, BLOCK_BYTES, "0", conn=conn)

        def tick():
            control.poll()
            result = session.poll()
            while parent_pipe.poll():
                event = parent_pipe.recv()
                assert event["event"] != "error", event
                events.append(event)
            return result

        end = time.monotonic() + 20
        while not session.ready and time.monotonic() < end:
            tick()
            time.sleep(0.001)
        assert session.ready, "session handshake failed"
        checkpoint("handshake_ready")
        watchdog = subprocess.Popen([sys.executable, str(Path(__file__).with_name("resume-target-watchdog.py")), str(os.getpid()), str(process.pid)])
        session.request_blocks(1, REQUEST, KEYS, chunk_ids)
        end = time.monotonic() + 15
        while not any(e["event"] == "running" for e in events) and time.monotonic() < end:
            result = tick()
            assert not result.loads, ("WRITE completed before it could be stalled", result.loads, events)
            time.sleep(0.001)
        assert any(e["event"] == "running" for e in events), "no running WRITE observed"
        os.kill(process.pid, signal.SIGSTOP)
        paused = True
        checkpoint("producer_stopped")
        bytes_at_stall = int(np.count_nonzero(np.frombuffer(view, dtype=np.uint8)))
        assert bytes_at_stall < BLOCKS * BLOCK_BYTES, "target already received the complete WRITE"

        if mode == "timeout":
            session.finish_request(REQUEST)
            end = time.monotonic() + 3
            failures = []
            while not failures and time.monotonic() < end:
                failures.extend(tick().loads)
                time.sleep(0.002)
            assert len(failures) == 1 and failures[0].success is False
            assert failures[0].memory_safe is False, failures
        else:
            closed = session.close()
            assert closed.failed_jobs == [1], closed

        checkpoint("unsafe_failure_observed")
        primary.quarantine_write(KEYS)
        replacement = [make_offload_key(b"replacement", 0)]
        assert all(primary.lookup(k, ctx) is LookupResult.MISS for k in KEYS)
        assert primary.prepare_write(replacement, ctx) is None, "unsafe slot was reused"
        try:
            primary.reset_cache()
        except RuntimeError as exc:
            assert "quarantined slots" in str(exc)
        else:
            raise AssertionError("reset_cache reclaimed unsafe slots")
        checkpoint("quarantine_assertions_passed")
        os.kill(process.pid, signal.SIGCONT)
        paused = False

        end = time.monotonic() + 30
        safe = []
        while time.monotonic() < end:
            if mode == "timeout":
                safe.extend(tick().loads)
                if safe:
                    break
            else:
                while parent_pipe.poll():
                    events.append(parent_pipe.recv())
                if any(e["event"] == "terminal" for e in events):
                    break
            time.sleep(0.002)
        if mode == "timeout":
            assert len(safe) == 1 and safe[0].memory_safe is True, safe
            assert safe[0].success is False
        else:
            assert any(e["event"] == "terminal" for e in events), events
        checkpoint("terminal_confirmation_observed")
        assert np.all(np.frombuffer(view, dtype=np.uint8) == PAYLOAD), "late WRITE payload differs"
        checkpoint("late_payload_verified")
        sample = torch.from_numpy(np.frombuffer(view, dtype=np.uint8)[:65536].copy())
        assert torch.equal(sample.cuda().cpu(), sample)
        checkpoint("consumer_gpu_roundtrip_passed")

        if mode == "timeout":
            primary.release_quarantined_write(chunk_ids)
            assert primary.prepare_write(replacement, ctx) is not None
        else:
            assert primary.prepare_write(replacement, ctx) is None
        return {"case": mode, "passed": True, "bytes": BLOCKS * BLOCK_BYTES,
                "bytes_at_stall": bytes_at_stall,
                "source_gpu": torch.cuda.get_device_name(0), "torch_cuda": torch.version.cuda,
                "abort_ack_timeout_s": client_module._ABORT_ACK_TIMEOUT_S,
                "slots_reused_before_confirmation": False,
                "quarantine_released": mode == "timeout", "events": events}
    finally:
        checkpoint("cleanup_started")
        if watchdog is not None:
            watchdog.wait(timeout=35)
        if process.pid and process.is_alive():
            os.kill(process.pid, signal.SIGCONT)
        if process.pid and process.is_alive():
            parent_pipe.send("quit")
            process.join(8)
            if process.is_alive():
                process.terminate()
                process.join(5)
        if session is not None:
            session.close()
        if data is not None:
            data.close()
        if control is not None:
            control.close()
        if view is not None:
            view.release()
        if primary is not None:
            primary.shutdown()
        del session, data, control, primary, view
        gc.collect()
        if region is not None:
            region.cleanup()
        checkpoint("cleanup_finished")


if __name__ == "__main__":
    faulthandler.enable()
    parser = argparse.ArgumentParser()
    parser.add_argument("--case", choices=["timeout", "close"], default="timeout")
    parser.add_argument("--output", type=Path)
    args = parser.parse_args()
    result = run_case(args.case)
    if args.output:
        args.output.write_text(json.dumps(result, indent=2))
    print(json.dumps(result, indent=2))
```

**`resume-target-watchdog.py`**

```python
"""Resume only our probe's target once its producer has SIGSTOPped itself."""
import os
import signal
import sys
import time
from pathlib import Path

target_pid, producer_pid = map(int, sys.argv[1:])
deadline = time.monotonic() + 30
try:
    while time.monotonic() < deadline:
        try:
            status = Path(f"/proc/{producer_pid}/status").read_text()
        except FileNotFoundError:
            break
        state = next(line for line in status.splitlines() if line.startswith("State:"))
        if state.split()[1] in ("T", "t"):
            print("Watchdog: producer stopped; resuming probe target", flush=True)
            break
        time.sleep(0.005)
finally:
    try:
        os.kill(target_pid, signal.SIGCONT)
    except ProcessLookupError:
        pass
```
