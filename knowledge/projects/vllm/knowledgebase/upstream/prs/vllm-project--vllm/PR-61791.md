# [UMBP][3/10] Add shared lookup, transfer, hybrid, and observability

[Upstream PR](https://github.com/vllm-project/vllm/pull/61791) · state: open · merged: False

## Original PR description

This PR is split from the original full PR: https://github.com/vllm-project/vllm/pull/58568

Add compact whole-block load and store plans, plus transfer cancellation.
Coordinate asynchronous lookup with hybrid and Mamba groups. Full-attention hits stay prefix-closed, and Mamba or sparse groups restore their own state.
Add partial hash hits, KV events, eviction reporting, and transfer metrics.

Implementation only. These behaviors stay in the shared connector, above any runtime. Tests are in the next PR:

```bash
.venv/bin/python -m pytest -q \
  tests/v1/kv_connector/unit/test_umbp_async_lookup.py \
  tests/v1/kv_connector/unit/test_umbp_events.py \
  tests/v1/kv_connector/unit/test_umbp_hybrid.py
```
