## Original PR description

## Overview

Under EP, route the AITER Triton W4A16 and W4A4 MoE over local experts only, as ROCm/ATOM does: the aiter top-k feeds `ep_sort_routing`. Follow-up to #59255.

## Claims

- DeepSeek-V4-Pro EP8: 1.1–2.6x output throughput vs #59255 (global routing). It now beats `triton_unfused` at every concurrency.
- gpt-oss-120b EP8: 1.1–2.0x, with no regression at conc 1.
- W4A4 EP fix: it already accepted EP but indexed local weights with global expert ids.
