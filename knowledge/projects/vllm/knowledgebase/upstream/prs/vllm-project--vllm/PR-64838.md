# [Mamba] Postpone --mamba-cache-mode removal to v0.34.0

[Upstream PR](https://github.com/vllm-project/vllm/pull/64838) · state: closed · merged: True

## Original PR description



## Overview

Postpone the removal of the deprecated `--mamba-cache-mode` flag from v0.33.0 to v0.34.0. The v0.33.0 release branch has already been cut with the flag still in place, so the removal (#63830) can only land in the next release.

## Claims

- The `--mamba-cache-mode` deprecation warning and `--help` text now say the flag will be removed in v0.34.0 instead of v0.33.0. No behavior change.

## Validation

- `pre-commit run`: passed.
- Help text check:

```
$ python -c "from vllm.engine.arg_utils import EngineArgs; from vllm.utils.argparse_utils import FlexibleArgumentParser; p = EngineArgs.add_cli_args(FlexibleArgumentParser()); print(next(a for a in p._actions if '--mamba-cache-mode' in a.option_strings).help)"
--mamba-cache-mode is deprecated and will be removed in v0.34.0. It has no effect: Mamba prefix caching follows --enable-prefix-caching.
```

## Details

- The deprecation was added in #60043 with a v0.33.0 removal target. `releases/v0.33.0` was cut on 2026-10-26 and still ships the flag, so the message is now inaccurate for users of v0.33.0.
- The CLI reference docs are generated from this `help=` text, so no separate docs change is needed.
- Not a duplicate: no other open PR changes this deprecation target; #63830 (same author) performs the actual removal and will target v0.34.0.
