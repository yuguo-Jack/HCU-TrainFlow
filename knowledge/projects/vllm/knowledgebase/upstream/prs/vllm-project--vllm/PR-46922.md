# docs: add OpenAI server production hardening checklist

[Upstream PR](https://github.com/vllm-project/vllm/pull/46922) · state: closed · merged: False

## Original PR description

## Summary
- Add a concise production hardening checklist for the OpenAI-compatible HTTP server.
- Emphasize reverse proxy / gateway allowlisting, feature flag review, trusted artifact handling, and sensitive logging policy.
- Keep the wording aligned with existing vLLM security guidance and avoid introducing new vulnerability claims.

## Why
The existing security guide already documents the important assumptions: API key auth is not a full server boundary, several operational endpoints should not be exposed, dynamic LoRA loading requires trusted access, tool servers need isolation, and model/cache artifacts are trusted inputs.

This PR turns those scattered points into an operator-facing checklist so production users have a single place to review before exposing vLLM behind an API or gateway.

## Test plan
- Docs-only change.
- Verified the checklist references existing public security guidance.
