# [Bugfix][Spec Decode] Synchronize adaptive DSpark decisions across TP ranks

[Upstream PR](https://github.com/vllm-project/vllm/pull/56831) · state: open · merged: False

## Original PR description

## Purpose

Adaptive DSpark derives its verification budget from rank-local confidence state. Small differences across TP ranks can therefore produce different total budgets or per-request boundaries, causing divergent execution layouts and possible collective hangs.

This change makes rank 0 authoritative for both values:

- broadcast the selected draft budget;
- broadcast partial-allocation capacities before building request boundaries.

The adaptive policy remains enabled and unchanged. Related to #54011. I found no open PR implementing this TP-consensus fix.

## Test Plan

- Unit coverage for TP1/2/4/8 with deliberately different rank-local confidences.
- Real NCCL TP2 and TP4 tests on H100s with Qwen3-4B and the official `deepseek-ai/dspark_qwen3_4b_block7` draft.
- Natural adaptive rank tracing, GSM8K correctness, and concurrency-128 serving stress.

## Test Result

- `pytest tests/v1/spec_decode/test_adaptive_verification.py -q`: 33 passed in the CUDA validation environment.
- `pre-commit run --files ...`: passed all applicable hooks.
- Injected rank drift: original code produced 20 consensus mismatches at both TP2 and TP4; patched code produced 0. Each run covered 120 compiled allocation cases and CUDA-graph boundary replays.
- Natural adaptive execution remained active: TP2 had 568 partial-budget steps; TP4 had 559. Budget and request-boundary traces matched exactly across all ranks.
- Patched TP2 and TP4 each completed 2,304/2,304 requests at observed concurrency 128 with no request failures or hangs.
- GSM8K completed all 1,319 samples with no invalid or empty responses. TP2: 86.20% original vs 86.43% patched; TP4: 85.75% vs 85.44% (net -4 answers, treated as finite-sample variation rather than equivalence proof).

The original issue's TP8/H20/DeepSeek-V4 environment was not available for end-to-end validation.
