# [Doc] Fix stale references in metrics, transcription, and spec decode docs

[Upstream PR](https://github.com/vllm-project/vllm/pull/61672) · state: open · merged: False

## Original PR description



## Overview

Fix three stale references in the docs: a link using the removed `gh-pr:` shorthand, an outdated `_preprocess_speech_to_text` snippet in the transcription contributor guide, and mismatched link text in the speculative decoding guide.

## Claims

- `docs/design/metrics.md`: the "unclear reasons" link used the `gh-pr:` shorthand, which the docs no longer rewrite, so it rendered as a broken relative link. It now uses the full GitHub URL. This was the last `gh-pr:` link in `docs/`.
- `docs/contributing/model/transcription.md`: the "Relevant server logic" snippet cited `vllm/entrypoints/openai/speech_to_text.py`, which no longer exists. It now cites `vllm/entrypoints/speech_to_text/base/serving.py`, and the abbreviated body reflects the current flow:
  - decoding and chunking run in a thread pool via `_decode_and_chunk_speech_async` and `split_audio`, replacing inline `load_audio` and `self._split_audio`;
  - prompts are rendered with `self.renderer.render_cmpl_async`;
  - the function returns `(engine_inputs, duration, chunk_start_offsets)`.
- `docs/features/speculative_decoding/README.md`: the link text said `tests/spec_decode/e2e`, but the link points to `tests/v1/spec_decode`. The text now matches the target.

## Validation

- The new URL resolves to the intended review comment (`gh api repos/vllm-project/vllm/pulls/comments/1710417152` returns `.../pull/7279#discussion_r1710417152`).
- `tests/v1/spec_decode` exists, so the relative link is valid.
- Checked the snippet line by line against `_preprocess_speech_to_text` and `_decode_and_chunk_speech` in `vllm/entrypoints/speech_to_text/base/serving.py` on `2c74fd1873`. Every name it shows exists there. Steps a model implementer doesn't need (language detection, chunk offsets, `verbose_json` handling) are elided with `...`, as in the original.
- `pre-commit run --files <the 3 files>`: all hooks passed or were skipped (typos, markdownlint-cli2 passed).

## Details

- I'm new to vLLM and going through the docs to get familiar with the codebase. I used Claude Code to cross-check doc references against the current code, then verified each finding and reviewed the transcription flow myself before updating the snippet.
- Docs-only; no code changes.
- Not a duplicate: I searched open PRs for each file and for the specific references. #51670 and #60150 edit other sections of `metrics.md`. #49414 edits the "Chunking" bullet just above the snippet in `transcription.md`, not the snippet itself. None touch these lines.
- The snippet stays abbreviated so it points readers to the `get_generation_prompt` hook without mirroring the full function, which would go stale again quickly.
