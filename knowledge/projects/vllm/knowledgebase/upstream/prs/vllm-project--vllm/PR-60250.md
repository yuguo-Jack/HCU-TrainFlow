# [ROCm] Enable the rms_norm_gated custom op by default (Qwen3.8-27B)

[Upstream PR](https://github.com/vllm-project/vllm/pull/60250) · state: open · merged: False

## Original PR description

## Overview

On ROCm the gated RMSNorm of Qwen3-Next / Qwen3.5-family GDN layers (`RMSNormGated`) compiles to two Inductor kernels per layer because `rms_norm_gated` is off in the default `custom_ops`, and the existing FLA path (`rmsnorm_fn`) is not a
registered op that `torch.compile` can trace. This PR wraps that call in a custom op (`vllm.fla_rms_norm_gated`) and enables
it by default on ROCm for unquantized models (quantized models keep the original kernels; `-rms_norm_gated` opts out). One Triton launch replaces two.
