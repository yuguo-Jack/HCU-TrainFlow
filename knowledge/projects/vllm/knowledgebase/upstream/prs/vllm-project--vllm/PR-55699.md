# [Bugfix][Frontend] Stop SSL certificate watchers when HTTP serving exits

[Upstream PR](https://github.com/vllm-project/vllm/pull/55699) · state: closed · merged: True

## Original PR description

When the HTTP server returns normally or raises an exception, SSL certificate watcher tasks currently survive because cleanup only runs in the signal shutdown handler. Move cleanup into `serve_http` finalization so it also runs on those exit paths. Regression tests cover successful and failed server exits, alongside the existing certificate refresh test.

Duplicate check: searched open PRs for `SSL refresher`, `ssl cleanup`, and `certificate watcher`; no existing PR addresses this lifecycle bug. Related merged #45489 changes test synchronization, not server cleanup.

- Changed-file pre-commit checks passed, including Ruff and mypy.
- No model inference evaluation was run; the change only stops certificate watchers after HTTP serving exits and does not modify inference behavior.
