# [Bugfix][Spec Decode] Keep speculator limits in sync after auto-fit

[Upstream PR](https://github.com/vllm-project/vllm/pull/60513) · state: open · merged: False

## Original PR description



## Overview

After `--max-model-len auto` reduces the context limit, MRV2 speculators can retain the original limit. Read the resolved limit from `ModelConfig` and cap draft attention metadata to it.

## Claims

- Keep draft sequence bounds within the fitted block-table capacity.
- Preserve a smaller draft-model limit.

## Details

`DraftModelSpeculator` is created before memory profiling. It cached `max_model_len` and passed its construction-time draft limit to attention metadata after auto-fit. FlexAttention derives its logical block count from that metadata.

Following the `ModelState` fix in #58149, the speculator now reads `max_model_len` from `ModelConfig`. The metadata limit is `min(draft_max_seq_len, max_model_len)`.

No issue or PR covers this. #58149 fixed the same stale copy in `ModelState`; #57964 covers rotary-cache sizing.
