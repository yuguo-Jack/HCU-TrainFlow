# [MM][CG] Support ViT full CUDA graph for Intern-S1

[Upstream PR](https://github.com/vllm-project/vllm/pull/64634) · state: open · merged: False

## Original PR description

## Overview

Add ViT full CUDA graph support for Intern-S1 (`InternS1ForConditionalGeneration`) through `SupportsEncoderCudaGraph`, for images and videos. Part of #38175. It follows the InternVL integration in #41759.

HF-format InternVL3 checkpoints (`InternVLForConditionalGeneration`) are registered to the same class, so they get the encoder graph too. I ran the same parity and logprobs tests on `OpenGVLab/InternVL3-1B-hf`, and both pass. So I added a docs row for it as well.

## Claims

- Intern-S1 now captures and replays encoder CUDA graphs for images and videos when `cudagraph_mm_encoder` is on. Before this change, the graph manager was never built for Intern-S1, so its encoder always ran eagerly, with no warning.
- Graph output is bit-identical to eager output on the same padded batch. I checked 6 cases on Model Runner V2 and on V1.
- Accuracy is not lower. MMStar is 64.87% with the graph and 64.00% without, and 96.9% of answers are identical. Two eager runs that differ only in `max_num_seqs` both score 64.00%, but they still disagree on 26 answers. So the gap is noise.
- Speed on one L40S is mixed:
  - Encoder replay is 1.68× faster for a 1-tile image and 1.24× faster for 2 tiles. Intern-S1-mini sends one tile per image by default.
  - From 4 tiles up, the vision tower is compute-bound. The graph is neutral there (0.99–1.02×).
  - A tile count between two budgets is padded up to the next budget. That costs 25–30% (0.68–0.76×).
  - In the offline `vllm bench mm-processor` run, the default power-of-two budgets make the encoder 18% slower at 1 image per request, and 7% slower at 4. Finer budgets cut that to 3% and 1.5%.
  - Median TTFT at concurrency 1 was lower in both of 2 paired runs: 89.7 → 84.4 ms and 84.4 → 78.6 ms. That gap is about as large as the run-to-run spread. At 10 req/s there was no clear difference.

## Validation

Setup: 1× NVIDIA L40S (48 GB), the CUDA 13.0 build and torch 2.14.0. The model is `internlm/Intern-S1-mini`. The runner is Model Runner V2, the default.

The tests below ran on main at `0106c8abc` with this PR applied. The MMStar and speed numbers come from an earlier run on `537a79f0f`, one day older. That run also passed the parity test with `VLLM_USE_V2_MODEL_RUNNER=0`. The PR's code and the Intern-S1 model files are the same on both. I then rebased onto current main. The newer commits don't change the model or the encoder graph code.

**Before the change.** The local parity test fails with `no encoder CUDA graph manager; encoder ran eager`.

**Tests**

- `pytest tests/models/multimodal/generation/test_vit_cudagraph.py -m core_model -k "interns1 or internvl"`: image and video pass. The new entry uses dummy weights, like `glm4_1v`. The log shows `Captured 5 graphs` with budgets `[256, 512, 1024, 2048, 4096]`.
  - Like every entry in this file, it only checks that the output is not empty. So it passes even if the graph stays off.
  - The local tests below check parity and graph hits.
- Greedy logprobs with the graph on vs off (2 images and an 8-frame video): `check_logprobs_close` passes. The graph had 4 hits and 0 misses.
- `VLLM_GPU_SYNC_CHECK=error` during image and video generation: no syncs.
- Mutation check: two deliberate bugs each make the parity test fail.
  - Video replay passes frames under `pixel_values_videos` instead of `pixel_values`. The manager skips keys it did not record, so the graph replays a stale input buffer. The 8-frame video then differs from eager by up to 10.69.
  - Tiles are sliced by item index instead of by cumulative tile offset. The batch with 3 + 1 tiles then differs by up to 9.56.
- `tests/models/test_initialization.py::test_can_initialize_large_subset` passes for both `InternS1ForConditionalGeneration` and `InternVLForConditionalGeneration`.

**Graph vs eager on synthetic 448×448 tiles** (budgets `[256, 1024, 2048]`, up to 4 items per batch)

| Case | Tiles in the replayed graph | Same as eager on the same batch | Max abs diff vs unpadded eager |
|---|---|---|---|
| 1 image, 1 tile | 1 | bit-identical | 0 |
| 1 image, 2 tiles | 4 (2 padding) | bit-identical | 0.219 |
| 2 images, 3 + 1 tiles | 4 | bit-identical | 0 |
| 1 image, 9 tiles (over every budget) | eager fallback | bit-identical | 0 |
| video, 8 frames | 8 | bit-identical | 0 |
| video, 5 frames | 8 (3 padding) | bit-identical | 0 |

# SPDX-License-Identifier: Apache-2.0
# SPDX-FileCopyrightText: Copyright contributors to the vLLM project
"""Local-only checks for Intern-S1 encoder CUDA graphs (vllm#38175).

Not part of the PR (ignored via .git/info/exclude). Both tests fail until
InternS1ForConditionalGeneration implements SupportsEncoderCudaGraph, because
the runner silently skips the graph manager for models without the protocol.
"""

import os
from functools import partial

import pytest
import torch

from vllm.multimodal.video import sample_frames_from_video
from vllm.platforms import current_platform

from ...utils import check_logprobs_close

pytestmark = pytest.mark.skipif(
    not current_platform.is_cuda(), reason="Requires CUDA graphs"
)

# The HF-format InternVL (InternVLForConditionalGeneration) uses the same class.
MODEL = os.environ.get("INTERNS1_MODEL", "internlm/Intern-S1-mini")
TILE = 448
TOKENS_PER_TILE = 256
BUDGETS = [256, 1024, 2048]
NUM_VIDEO_FRAMES = 8

# (modality, tiles per item, tiles in the replayed graph or None for eager,
# expected (new hits, new misses)). Hits and misses count items, not replays.
# Eager bf16 output changes with batch size (vLLM is not batch-invariant), so
# each case is checked bit-exactly against eager on the batch the graph ran:
# zero padding included, which the manager adds up to the captured tile count.
BATCHES = [
    ("image", [1], 1, (1, 0)),  # exactly the 256-token graph
    ("image", [2], 4, (1, 0)),  # 512 tokens: 1024-token graph, 2 padding tiles
    ("image", [3, 1], 4, (2, 0)),  # two items packed into one 1024 replay
    ("image", [9], None, (0, 1)),  # 2304 tokens: over every budget, so eager
    ("video", [NUM_VIDEO_FRAMES], 8, (1, 0)),  # exactly the 2048-token graph
    ("video", [5], 8, (1, 0)),  # 1280 tokens: 2048-token graph, 3 padding frames
]


def chatml(content: str) -> str:
    return f"<|im_start|>user\n{content}<|im_end|>\n<|im_start|>assistant\n"


def runner_kwargs(cudagraph_mm_encoder: bool) -> dict:
    compilation_config: dict = {"cudagraph_mm_encoder": cudagraph_mm_encoder}
    if cudagraph_mm_encoder:
        compilation_config.update(
            encoder_cudagraph_token_budgets=BUDGETS,
            encoder_cudagraph_max_vision_items_per_batch=4,
            encoder_cudagraph_max_frames_per_batch=NUM_VIDEO_FRAMES,
        )
    return dict(
        dtype="bfloat16",
        trust_remote_code=True,
        max_model_len=8192,
        max_num_seqs=2,
        limit_mm_per_prompt={"image": 4, "video": 1},
        compilation_config=compilation_config,
        # Lowered when the GPU job is shared with other work.
        gpu_memory_utilization=float(os.environ.get("INTERNS1_GPU_MEM", "0.9")),
    )


def find_manager(runner):
    encoder_runner = getattr(
        getattr(runner, "model_state", None), "encoder_runner", None
    )
    if encoder_runner is not None:  # Model Runner V2
        return encoder_runner.cudagraph_manager
    return getattr(runner, "encoder_cudagraph_manager", None)  # Model Runner V1


def make_batch(modality, tiles, device, dtype, seed):
    gen = torch.Generator().manual_seed(seed)
    pixels = torch.randn(sum(tiles), 3, TILE, TILE, generator=gen)
    pixels = pixels.to(device=device, dtype=dtype)
    num_patches = torch.tensor(tiles, dtype=torch.int64)
    # Eager parsing requires a token id, but the encoder never reads it.
    token_id = torch.tensor(0, dtype=torch.int64)
    if modality == "image":
        return dict(
            pixel_values=pixels, image_num_patches=num_patches, image_token_id=token_id
        )
    return dict(
        pixel_values_videos=pixels,
        video_num_patches=num_patches,
        video_token_id=token_id,
    )


def check_encoder_graph(worker, batches):
    runner = worker.model_runner
    manager = find_manager(runner)
    assert manager is not None, "no encoder CUDA graph manager; encoder ran eager"
    assert manager.is_captured()
    model = runner.get_model()
    dtype = runner.model_config.dtype
    supports_video = manager.supports_modality("video")

    results = []
    with torch.inference_mode():
        for seed, (modality, tiles, graph_tiles, (new_hits, new_misses)) in enumerate(
            batches
        ):
            if modality == "video" and not supports_video:
                continue
            kwargs = make_batch(modality, tiles, runner.device, dtype, seed)
            pixels = next(v for k, v in kwargs.items() if k.startswith("pixel_values"))
            before = manager.get_cumulative_stats()
            actual = [out.clone() for out in manager.execute(kwargs)]
            after = manager.get_cumulative_stats()
            unpadded = model.embed_multimodal(**kwargs)
            num_pad = 0 if graph_tiles is None else graph_tiles - sum(tiles)
            if num_pad:
                padded = torch.cat(
                    [pixels, pixels.new_zeros(num_pad, *pixels.shape[1:])]
                )
                flat = model.extract_feature(padded).flatten(0, 1)
                same_batch = flat[: sum(tiles) * TOKENS_PER_TILE].split(
                    [n * TOKENS_PER_TILE for n in tiles]
                )
            else:
                same_batch = unpadded

            assert len(actual) == len(same_batch) == len(unpadded) == len(tiles)
            max_abs_vs_unpadded = 0.0
            min_cos_vs_unpadded = 1.0
            for output, reference, eager, n in zip(actual, same_batch, unpadded, tiles):
                assert output.shape == (n * TOKENS_PER_TILE, eager.shape[-1])
                assert torch.isfinite(output).all()
                assert torch.equal(output, reference), (
                    f"{modality} {tiles}: graph differs from eager on the same batch "
                    f"by {(output - reference).abs().max().item()}"
                )
                max_abs_vs_unpadded = max(
                    max_abs_vs_unpadded, (output - eager).abs().max().item()
                )
                min_cos_vs_unpadded = min(
                    min_cos_vs_unpadded,
                    torch.nn.functional.cosine_similarity(
                        output.float().flatten(), eager.float().flatten(), dim=0
                    ).item(),
                )
            assert after["graph_hits"] - before["graph_hits"] == new_hits
            assert after["graph_misses"] - before["graph_misses"] == new_misses
            results.append(
                dict(
                    modality=modality,
                    tiles=tiles,
                    graph_tiles=graph_tiles,
                    bit_exact_vs_same_batch=True,
                    max_abs_vs_unpadded=max_abs_vs_unpadded,
                    min_cos_vs_unpadded=min_cos_vs_unpadded,
                )
            )

    stats = manager.get_cumulative_stats()
    assert stats["token_budgets"] == BUDGETS
    return dict(supports_video=supports_video, batches=results, stats=stats)


def encoder_stats(worker):
    manager = find_manager(worker.model_runner)
    return None if manager is None else manager.get_cumulative_stats()


def test_interns1_encoder_graph_matches_eager(vllm_runner, monkeypatch):
    """Graph replay equals eager on synthetic tiles; oversized input falls back."""
    monkeypatch.setenv("VLLM_ALLOW_INSECURE_SERIALIZATION", "1")
    with vllm_runner(MODEL, **runner_kwargs(cudagraph_mm_encoder=True)) as model:
        (result,) = model.llm.collective_rpc(
            partial(check_encoder_graph, batches=BATCHES)
        )
    print(f"Intern-S1 encoder graph vs eager: {result}")


def test_interns1_generation_matches_eager(
    vllm_runner, image_assets, video_assets, monkeypatch
):
    """Greedy logprobs with the encoder graph on match a graph-off run."""
    monkeypatch.setenv("VLLM_ALLOW_INSECURE_SERIALIZATION", "1")
    image_prompts = [chatml("<IMG_CONTEXT>\nWhat is in this image?")] * len(
        image_assets
    )
    images = [[asset.pil_image] for asset in image_assets]
    video_prompts = [chatml("<video>\nDescribe this video in one sentence.")]
    videos = [sample_frames_from_video(video_assets[0].np_ndarrays, NUM_VIDEO_FRAMES)]

    def generate(runner, video: bool):
        outputs = runner.generate_greedy_logprobs(
            image_prompts, max_tokens=32, num_logprobs=5, images=images
        )
        if video:
            outputs += runner.generate_greedy_logprobs(
                video_prompts, max_tokens=32, num_logprobs=5, videos=videos
            )
        return outputs

    with vllm_runner(MODEL, **runner_kwargs(cudagraph_mm_encoder=True)) as model:
        (stats,) = model.llm.collective_rpc(encoder_stats)
        assert stats is not None, "no encoder CUDA graph manager; encoder ran eager"
        (probe,) = model.llm.collective_rpc(
            partial(check_encoder_graph, batches=BATCHES[:1])
        )
        video = probe["supports_video"]
        graph_outputs = generate(model, video)
        (stats,) = model.llm.collective_rpc(encoder_stats)
    assert stats["graph_hits"] > 1, stats

    with vllm_runner(MODEL, **runner_kwargs(cudagraph_mm_encoder=False)) as model:
        eager_outputs = generate(model, video)

    check_logprobs_close(
        outputs_0_lst=eager_outputs,
        outputs_1_lst=graph_outputs,
        name_0="eager",
        name_1="graph",
    )
    print(f"Intern-S1 generation: video={video}, encoder stats {stats}")

# SPDX-License-Identifier: Apache-2.0
# SPDX-FileCopyrightText: Copyright contributors to the vLLM project
"""Local-only (git-ignored): encoder graph replay vs eager latency on one batch."""

import os
import statistics
from functools import partial

import pytest
import torch

from vllm.platforms import current_platform

from .test_interns1_vit_cg_local import find_manager, make_batch

pytestmark = pytest.mark.skipif(not current_platform.is_cuda(), reason="CUDA only")

BUDGETS = [256, 512, 1024, 2048, 4096]
# One image with this many tiles per measurement; 3, 5 and 12 are padded.
TILES = [1, 2, 3, 4, 5, 8, 12, 16]


def time_ms(fn, warmup=5, iters=30):
    for _ in range(warmup):
        fn()
    torch.accelerator.synchronize()
    times = []
    for _ in range(iters):
        start = torch.cuda.Event(enable_timing=True)
        end = torch.cuda.Event(enable_timing=True)
        start.record()
        fn()
        end.record()
        end.synchronize()
        times.append(start.elapsed_time(end))
    return statistics.median(times)


def measure(worker, tiles_list):
    runner = worker.model_runner
    manager = find_manager(runner)
    assert manager is not None and manager.is_captured()
    model = runner.get_model()
    rows = []
    with torch.inference_mode():
        for n in tiles_list:
            kwargs = make_batch(
                "image", [n], runner.device, runner.model_config.dtype, n
            )
            eager = time_ms(lambda: model.embed_multimodal(**kwargs))
            graph = time_ms(lambda: manager.execute(kwargs))
            rows.append(
                dict(tiles=n, eager_ms=round(eager, 3), graph_ms=round(graph, 3))
            )
    return rows


def test_interns1_encoder_latency(vllm_runner, monkeypatch):
    monkeypatch.setenv("VLLM_ALLOW_INSECURE_SERIALIZATION", "1")
    with vllm_runner(
        "internlm/Intern-S1-mini",
        trust_remote_code=True,
        dtype="bfloat16",
        max_model_len=8192,
        max_num_seqs=2,
        limit_mm_per_prompt={"image": 1, "video": 0},
        gpu_memory_utilization=float(os.environ.get("INTERNS1_GPU_MEM", "0.9")),
        compilation_config={
            "cudagraph_mm_encoder": True,
            "encoder_cudagraph_token_budgets": BUDGETS,
            "encoder_cudagraph_max_vision_items_per_batch": 1,
        },
    ) as model:
        (rows,) = model.llm.collective_rpc(partial(measure, tiles_list=TILES))
    print("TIMING tiles eager_ms graph_ms speedup")
    for r in rows:
        print(
            f"TIMING {r['tiles']} {r['eager_ms']} {r['graph_ms']} "
            f"{r['eager_ms'] / r['graph_ms']:.3f}"
        )

OUT = os.path.join(os.environ["PROJECT"], ".cache/mmstar/preds-{}.json")
SUFFIX = "\nAnswer with the option's letter from the given choices directly."


def extract_letter(text: str) -> str:
    match = re.search(r"\b([ABCD])\b", text.strip())
    return match.group(1) if match else ""


def run(mode: str) -> None:
    import pandas as pd
    from PIL import Image
    from transformers import AutoTokenizer

    from vllm import LLM, SamplingParams

    df = pd.read_parquet(DATA)
    tokenizer = AutoTokenizer.from_pretrained(MODEL, trust_remote_code=True)
    requests = []
    for row in df.itertuples():
        messages = [{"role": "user", "content": "<IMG_CONTEXT>\n" + row.question + SUFFIX}]
        prompt = tokenizer.apply_chat_template(
            messages, tokenize=False, add_generation_prompt=True, enable_thinking=False
        )
        image = Image.open(io.BytesIO(row.image)).convert("RGB")
        requests.append({"prompt": prompt, "multi_modal_data": {"image": image}})

    llm = LLM(
        MODEL,
        trust_remote_code=True,
        max_model_len=8192,
        limit_mm_per_prompt={"image": 1, "video": 0},
        gpu_memory_utilization=float(os.environ.get("INTERNS1_GPU_MEM", "0.6")),
        compilation_config={"cudagraph_mm_encoder": mode == "on"},
        # off-seq32 is the noise control: still eager, but a smaller batch
        # changes how images are grouped, as the encoder graph does.
        **({"max_num_seqs": 32} if mode == "off-seq32" else {}),
    )
    outputs = llm.generate(requests, SamplingParams(temperature=0.0, max_tokens=8))
    preds = [extract_letter(o.outputs[0].text) for o in outputs]
    records = [
        dict(index=int(r.index), category=r.category, answer=r.answer, pred=p, raw=o.outputs[0].text)
        for r, p, o in zip(df.itertuples(), preds, outputs)
    ]
    with open(OUT.format(mode), "w") as f:
        json.dump(records, f)
    acc = sum(r["pred"] == r["answer"] for r in records) / len(records)
    unparsed = sum(r["pred"] == "" for r in records)
    print(f"MMSTAR {mode}: accuracy {acc:.4f} on {len(records)} questions, unparsed {unparsed}")
    # Interpreter exit can hang on engine teardown; stop the engine, then exit.
    llm.llm_engine.engine_core.shutdown(timeout=60)
    sys.stdout.flush()
    os._exit(0)


def compare(name_a: str = "on", name_b: str = "off") -> None:
    on, off = (json.load(open(OUT.format(m))) for m in (name_a, name_b))
    assert [r["index"] for r in on] == [r["index"] for r in off]
    print(f"MMSTAR compare {name_a} vs {name_b}")
    per_cat: dict[str, list[int]] = defaultdict(lambda: [0, 0, 0])
    for a, b in zip(on, off):
        c = per_cat[a["category"]]
        c[0] += a["pred"] == a["answer"]
        c[1] += b["pred"] == b["answer"]
        c[2] += 1
    agree = sum(a["pred"] == b["pred"] for a, b in zip(on, off))
    print(f"MMSTAR agreement: {agree}/{len(on)} identical predictions")
    print(f"MMSTAR {'category':<26}{name_a:>10}{name_b:>11}")
    for cat, (a, b, n) in sorted(per_cat.items()):
        print(f"MMSTAR {cat:<26}{a / n:>10.3f}{b / n:>11.3f}")
    a = sum(v[0] for v in per_cat.values()) / len(on)
    b = sum(v[1] for v in per_cat.values()) / len(off)
    print(f"MMSTAR {'overall':<26}{a:>10.4f}{b:>11.4f}")


if __name__ == "__main__":
    compare(*sys.argv[2:4]) if sys.argv[1] == "compare" else run(sys.argv[1])

## Details

- **Copy, not shared code.** `interns1.py` is already its own version of the InternVL model code, with its own `pixel_shuffle`, `extract_feature` and input parsing. So I copied the InternVL protocol methods instead of sharing them, which keeps `internvl.py` untouched. Qwen2-VL, Qwen2.5-VL and Qwen3-VL also each keep their own copy. I'm happy to move them into a mixin if you prefer.
- **One buffer.** Intern-S1's vision tower uses plain ViT attention on fixed 448×448 tiles. It has absolute position embeddings and no rotary embeddings. So `pixel_values` is the only recorded buffer. Each video frame is one tile, so video replay copies frames into the same buffer.
- **Differences from InternVL.** The keys are `pixel_values` and `pixel_values_videos`. `vision_config.image_size` is a list. Modality is detected from the video key.
- **Example.** I added `interns1` to `MODELS_SUPPORT_VIT_CUDA_GRAPH` and removed `enforce_eager=True` from `run_interns1`. With eager mode on, the encoder graph is never built, so `--enable-vit-cuda-graph` would do nothing. Without the flag, the example now runs compiled with decoder CUDA graphs, like `run_internvl`.
- **E-only test.** Intern-S1 is not added to `test_eonly_vit_cudagraph_outputs`. That test only covers `qwen3_vl` and `qwen3_5` today.
- **`image_embeds` inputs.** With `cudagraph_mm_encoder` and `--enable-mm-embeds` both on, a request with precomputed image embeddings crashes the engine in `sanity_check_mm_encoder_outputs`. InternVL3-1B on current main crashes the same way. The cause is in the shared graph manager: an embeddings-only batch produces no item specs, so the manager returns an empty list. I left this out of scope and can open a separate issue. With the graph off, both models work.
- **Data-parallel ViT.** Intern-S1 has no `supports_encoder_tp_data`. So `mm_encoder_tp_mode=data` falls back to weights mode, as before. This PR does not change that.
- **Not tested.**
  - TP>1 and the full Intern-S1 (InternViT-6B with qk-norm, which needs TP). Both use the same code path.
  - ROCm. The CI entry also runs in the AMD mirror, and I have no ROCm GPU to check it.
- **Not a duplicate.** I claimed Intern-S1 on #38175, and no open PR adds encoder CUDA graphs for it. #48129 adds tower and connector LoRA for Intern-S1. That is a different feature that touches the same class.
