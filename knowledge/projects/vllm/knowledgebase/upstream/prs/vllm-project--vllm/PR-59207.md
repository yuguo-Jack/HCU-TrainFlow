# [Bugfix] Implement fail-fast blocking during the startup phase

[Upstream PR](https://github.com/vllm-project/vllm/pull/59207) · state: open · merged: False

## Original PR description

## Purpose
Fix #58653 

**Proposed Changes**

1. **Startup Fail-Fast Gate** (`vllm/config/vllm.py`):
   - In `_verify_kv_transfer_compat`, check if `model_config.is_hybrid` is True, `SimpleCPUOffloadConnector` is enabled, and `cache_config.user_specified_block_size` is True.
   - If detected, fail fast by raising a descriptive `ValueError` explaining the misalignment issue and instructing the user to omit `--block-size` so that vLLM can automatically compute the aligned block size.
   - Non-hybrid models or hybrid models without KV offload are unaffected.
2. **Connector Defense-in-Depth** (`vllm/v1/simple_kv_offload/manager.py`):
   - In `SimpleCPUOffloadScheduler.__init__`, assert that hybrid configurations containing `MambaSpec` reject `user_specified_block_size=True`, ensuring no invalid state bypasses startup checks.
3. **Observability Foundation** (`vllm/v1/simple_kv_offload/manager.py` & `vllm/distributed/kv_transfer/kv_connector/v1/simple_cpu_offload_connector.py`):
   - Introduce `OffloadIOStats` to record cumulative `total_stored_blocks` (incremented on store completion) and `total_loaded_tokens` (incremented on cache hit).
   - Expose `get_offload_io_stats()` on both `SimpleCPUOffloadScheduler` and `SimpleCPUOffloadConnector` for programmatically inspecting offload health.

## Test Plan

Added unit tests covering startup validation, connector defense-in-depth, and IO statistics tracking:
1. `tests/v1/kv_connector/unit/test_config.py`:
   - `test_hybrid_gdn_rejects_explicit_block_size_with_simple_kv_offload`: Asserts `ValueError` when explicit block size is configured on hybrid models with SimpleCPU offload.
   - `test_hybrid_gdn_allows_omitted_block_size_with_simple_kv_offload`: Verifies omitting block size succeeds.
   - `test_hybrid_gdn_allows_explicit_block_size_without_kv_offload`: Verifies backward compatibility when KV offload is disabled.
2. `tests/v1/kv_connector/unit/test_simple_cpu_offload_connector.py`:
   - `test_connector_get_offload_io_stats`: Verifies scheduler exposes `OffloadIOStats` while worker returns `None`.
3. `tests/v1/simple_kv_offload/test_scheduler.py`:
   - `test_hybrid_scheduler_rejects_user_specified_block_size`: Verifies defense-in-depth in scheduler constructor.
   - `test_offload_io_stats_tracks_stores_and_loads`: Simulates request lifecycle, verifies cumulative stored blocks and loaded tokens increment correctly.
