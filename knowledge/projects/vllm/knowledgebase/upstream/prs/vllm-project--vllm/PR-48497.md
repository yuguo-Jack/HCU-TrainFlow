[Upstream PR](https://github.com/vllm-project/vllm/pull/48497) · state: closed · merged: True

## Original PR description

## Purpose

Pooling configuration precedence is currently described only at a high level and is scattered across model-specific guidance. This docs only change documents the current resolution chain in one place: user-provided `--pooler-config` fields, supported Sentence Transformers metadata, and architecture or task defaults. It also distinguishes embedding normalization from classification activation, qualifies the behavior of standard DispatchPooler adapters versus custom poolers, and provides a no-weight-load snippet for inspecting the resolved configuration.

This is a follow up from the pooling logging config in [48030](https://github.com/vllm-project/vllm/pull/48030).
