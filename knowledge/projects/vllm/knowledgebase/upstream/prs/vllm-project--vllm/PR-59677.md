# [ROCm][CI] Align AMD commands that differ between test-amd.yaml and test_areas

[Upstream PR](https://github.com/vllm-project/vllm/pull/59677) · state: open · merged: False

## Original PR description

Some AMD test groups run the same command in test-amd.yaml and in the test_areas mirror, but with a different version or flags. Use the more recently changed side in both places:

- (MI300) Quantization: torchao 0.17.0 -> 0.18.0 in test_areas, matching test-amd.yaml (#53009).
- (MI355 DPX) Language Models (Extended Generation): use the fix-rocm-7.0-warp-size-constexpr mamba branch in test-amd.yaml, matching test_areas (#57877).
- (MI300) MoE Kernels: run test_modular_kernel_combinations with AITER enabled in test_areas, matching test-amd.yaml (#57074).
- (MI355 DPX) Basic Correctness Models: run with VLLM_TARGET_TEST_SUITE=MI355 in test_areas, as test-amd.yaml does.
