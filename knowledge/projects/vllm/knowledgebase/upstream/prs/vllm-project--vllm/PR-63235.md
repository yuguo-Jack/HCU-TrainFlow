# [CI] Stop running everything for kv_connectors.txt and check-torch-abi.py

[Upstream PR](https://github.com/vllm-project/vllm/pull/63235) · state: open · merged: False

## Original PR description

## Purpose

`.buildkite/ci_config.yaml` runs the whole pipeline when a PR touches any `run_all_patterns` file. Two entries don't need that:

- **`requirements/kv_connectors.txt`** is not in the image. It is installed at test time by `.buildkite/scripts/install-kv-connectors.sh`, only in the steps that call it, and only on CUDA 13 (ROCm installs `kv_connectors_rocm.txt`, CUDA 12 `kv_connectors_cu12.txt`). Since #63609 those steps are disabled on `ci`.
- **`.buildkite/check-torch-abi.py`** is run only by the `torch-stable-abi-audit` step, which already lists it in `source_file_dependencies`.

This drops both from `run_all_patterns`.

## Test Plan

With ci-infra `main`'s generator functions on the edited config:

| changed file | run all | steps picked by `source_file_dependencies` |
|---|---|---|
| `requirements/kv_connectors.txt` | no (was yes) | the steps that declare it |
| `.buildkite/check-torch-abi.py` | no (was yes) | `torch-stable-abi-audit` |
| `csrc/foo.cu`, `requirements/common.txt` | yes (unchanged) | – |

The ci-selector on a change to `check-torch-abi.py` picks `torch-stable-abi-audit` and no GPU test steps.
