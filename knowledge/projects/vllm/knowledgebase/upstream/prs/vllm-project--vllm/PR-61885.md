# [torch.compile] Migrate ObservabilityConfig to hash_factors

[Upstream PR](https://github.com/vllm-project/vllm/pull/61885) · state: open · merged: False

## Original PR description

## What

Migrates `ObservabilityConfig.compute_hash` from the old opt-in
`safe_hash(str(list))` pattern to the opt-out
`get_hash_factors` + `hash_factors` pattern introduced in #26468.

## Why

Part of #39479 (TODO #3: "Uniform use of `normalize_value` &
`hash_factors` across configs with a `compute_hash` function").

The old implementation returned a constant hash regardless of config
values:

```python
# Old: hash is always the same — it hashes an empty list
factors: list[Any] = []
hash_str = safe_hash(str(factors).encode(), usedforsecurity=False).hexdigest()
