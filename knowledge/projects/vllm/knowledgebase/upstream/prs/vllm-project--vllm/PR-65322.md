# [ROCm][Perf] W4A16: retune int4 skinny GEMM decode tuples for gfx115x

[Upstream PR](https://github.com/vllm-project/vllm/pull/65322) · state: closed · merged: True

## Original PR description

## Summary

Retunes the `wvSplitK_int4_g` dispatch for batch 1–5 on gfx1151 and gfx1150; gfx1152/gfx1153 reuse the gfx1150 rules (not measured there). Rules apply to grouped weights whose activations fit LDS; every other case and every other target keep their current tuple.

| Target | Batch | Applies when | Tuple (YTILE/UNRL/A_CHUNK/WvPrGrp) |
|---|---|---|---|
| gfx1151 | 1 | K ≤ 8192, M ≥ 512 | 2/1/32/32 |
| gfx1151 | 2 | K ≤ 1536 or M ≥ 4096 | 2/1/16/32 |
| gfx1151 | 3–4 | M ≥ 256 | M ≥ 512: 2/1/16/32, else 1/2/16/16 |
| gfx1151 | 5 | sym, M ≥ 2048 | 2/1/16/32 |
| gfx1150/1152/1153 | 1 | 512 ≤ K ≤ 8192 (≤ 3584 for bf16 asym) | M ≥ 1024: 2/2/32/32; M ≥ 256 and (K ≤ 4096 or asym): 1/2/32/16 |
| gfx1150/1152/1153 | 2 | f16, 1024 ≤ K ≤ 2048 | K > 1536: 4/2/32/12, else 4/1/16/32 |
| gfx1150/1152/1153 | 3 | f16, 256 ≤ M < 2048 | 2/2/32/16 |
| gfx1150/1152/1153 | 4 | not bf16 asym, M ≥ 256, 512 ≤ K ≤ 2048 | M ≥ 2048: 2/1/16/32, else 2/1/32/12 |
| gfx1150/1152/1153 | 5 | M ≥ 1024, K ≥ 1024 | 4/1/16/12 |

Tiles only batch 1 launches are now built for N = 1 alone, and the symmetric-only UNRL = 8 tile for symmetric weights alone. Spilling kernels go from 151 to 1 on gfx1151 (the existing f16 g32 UNRL = 8 tile, 2 VGPRs, unchanged) and from 144 to 0 on gfx1150. The rules come from a YTILE/UNRL/A_CHUNK/WvPrGrp sweep over 38 decode shapes (f16/bf16, sym/asym, group 32/128).
