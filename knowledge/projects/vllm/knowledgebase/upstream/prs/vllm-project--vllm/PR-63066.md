# [XPU][CI] Fix test_basic_cumem on XPU in XpuMemAllocator

[Upstream PR](https://github.com/vllm-project/vllm/pull/63066) · state: closed · merged: False

## Original PR description

Fixes the Intel CI failure in `test_basic_cumem` (intel-ci build 15032): `XpuMemAllocator.sleep()` called `torch.xpu.empty_cache()` directly, so the test's `torch.accelerator.empty_cache` hook saw 0 calls. Now it uses `torch.accelerator.empty_cache()` and synchronizes before unmapping in the free callback, matching the CUDA `CuMemAllocator`.

Not a duplicate: no open PR touches this (searched `xpumem empty_cache`, `test_basic_cumem XPU`).

Validation: root-caused from the CI log; could not run the test locally (local env lacks libcuda for the test import). Needs Intel CI to confirm.

AI assistance (GitHub Copilot) was used; reviewed by the submitter.
