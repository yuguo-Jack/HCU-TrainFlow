# [Model] Support MiniCPM-V 4.7

[Upstream PR](https://github.com/vllm-project/vllm/pull/58674) · state: closed · merged: True

## Original PR description

Add support for MiniCPM-V 4.7, scheduled for release soon.

The architecture is close to 4.6. The main addition is canvas 3D M-RoPE: the
thumbnail is resampled over the slice canvas, and slices and row newlines take
positions from their geometry.

Other changes:
- Video placeholders no longer emit `<image_id>` local ids; 4.7 was trained
  without them.
- 4.6 refactored to be inheritable. Default behavior unchanged.
- Fix canvas `rope_delta` missing `+1`, matching qwen2_vl / qwen3_vl.
- Restore literal `\n` in output. The tokenizer decodes newlines as the two
  chars `\` + `n` (id 1639). Code blocks, inline code, LaTeX and tool call
  arguments are left untouched.

Testing:
- Canvas positions and rope_delta match the transformers 4.7 reference
  (PR #48979) token for token, 7/7 cases.
- 12 tests pass, ruff check and ruff format clean.
- No open PR covers this.

AI assistance was used.
