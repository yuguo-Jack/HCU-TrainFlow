# [Bugfix] Fix MOSS-Audio meta initialization

[Upstream PR](https://github.com/vllm-project/vllm/pull/63629) · state: closed · merged: True

## Original PR description

Root cause: Model Runner V2 constructs the audio tower on the meta device on non-first pipeline stages. MOSS-Audio reads a tensor value with `.item()` during encoder initialization, which fails on meta tensors.

Fix: Compute the downsampled mel dimension with equivalent Python integer arithmetic instead of tensor operations.
