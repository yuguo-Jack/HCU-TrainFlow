# [MRV2][Spec Decode]Adapt cudagraph for draft model

[Upstream PR](https://github.com/vllm-project/vllm/pull/60989) · state: open · merged: False

## Original PR description

## Overview
Enable CUDA graph capture and replay for Model Runner V2 draft-model speculators, as follow-up work to [#43091](https://github.com/vllm-project/vllm/pull/43091). 

## Claims
- Move `SpeculatorCudaGraphManager` into the shared `spec_decode` package and initialize prefill/decode managers in `DraftModelSpeculator`.
- Capture standalone AR prefill and multi-step decode with the selected CUDA graph mode, including full-graph replay and piecewise execution.

## Validation
Ran the offline draft-model spec-decode evaluation with `FULL_AND_PIECEWISE` on Qwen3-32B / Qwen3-1.7B using 400 MT-Bench prompts, temperature 0, and 256 output tokens:

```
python examples/features/speculative_decoding/spec_decode_offline.py \   
 --method draft_model \    
--model-dir /shared/models/modelscope/models/Qwen/Qwen3-32B \    
 --draft-model /shared/models/modelscope/models/Qwen/Qwen3-1.7B \    
--num-spec-tokens 3 \    
--dataset-name hf \    
--dataset-path philschmid/mt-bench \    
--num-prompts 400 \    
--temp 0 \    
--output-len 256 \    
--max-model-len 10000 \    
--cudagraph-mode FULL_AND_PIECEWISE \
--gpu-memory-utilization 0.95
```
