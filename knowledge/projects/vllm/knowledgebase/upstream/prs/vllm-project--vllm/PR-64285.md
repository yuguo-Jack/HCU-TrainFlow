# [XPU][CI] Enable streaming input e2e test on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/64285) · state: closed · merged: True

## Original PR description

## Overview
Remove the cuda-only skip in `tests/v1/e2e/general/test_streaming_input.py` and run it in the Intel CI `E2E Core` job.

## Claims
- `test_streaming_input.py` is no longer skipped on non-CUDA platforms. The skip reason ("V1 currently only supported on CUDA") is outdated: V1 is the default engine and runs on XPU.
- The test now runs on Intel BMG in the `:intel: (BMG) E2E Core` job.
