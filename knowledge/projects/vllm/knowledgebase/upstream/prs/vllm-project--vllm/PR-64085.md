# [Misc] Revert "[NIXL] Bump NIXL version to 1.5.1" (#63817)

[Upstream PR](https://github.com/vllm-project/vllm/pull/64085) · state: closed · merged: True

## Original PR description



## Overview

Revert #63817, returning the NIXL pin to 1.5.0 in `requirements/kv_connectors.txt` (CUDA 13) and `requirements/kv_connectors_cu12.txt` (CUDA 12).

**Reason:** 

The NIXL team is calling back the 1.5.1, as there is a incidental bump of libfabric version (2.7.0) included, which would impact EFA users.

## Claims

- CUDA 12 and CUDA 13 images go back to NIXL 1.5.0, the version pinned before #63817.
- Clean `git revert` of 7a1ebe4ef5. No later commit touches these lines.

## Validation

- Dependency resolution, x86_64 and aarch64, both files: `nixl`, `nixl-cu12` and `nixl-cu13` all resolve to 1.5.0.
  ```bash
  uv pip compile --python-version 3.12 --python-platform x86_64-manylinux_2_28 --torch-backend cu129 requirements/kv_connectors.txt
  # repeated for aarch64-manylinux_2_28 and requirements/kv_connectors_cu12.txt
  ```
- `pre-commit run --files requirements/kv_connectors.txt requirements/kv_connectors_cu12.txt`: passed.
- No GPU run. 1.5.0 was the pin in `main` until #63817 merged on 2026-10-26.

## Details

This also undoes the LIBFABRIC changes from 1.5.1: the plugin goes back to needing libfabric 1.20 or newer instead of 2.7 or newer, and the ai-dynamo/nixl#2425 fix for context-independent CUDA allocations is no longer included.

**Not a duplicate:** no open PR reverts #63817.
