# [Feature] Add Winnow read strategy to the Decisions API

[Upstream PR](https://github.com/vllm-project/vllm/pull/60713) · state: open · merged: False

## Original PR description

## Overview

Add an explicit Winnow read strategy to the Decisions API, preserving the model’s trained prompt and candidate-token protocol.

This PR depends on the still-open #60465, pinned at `4f5fd1e2f93ff16e8fec2b731fbed61eceb77f66`, and reuses the shared structured decision backend from #59299.

## Claims

- Render canonical Winnow state, questions, and options instead of a generic chat prompt.
- Support predicate, choice, and score answers through existing Decisions response types.
- Apply external conditional temperature while preserving raw full-vocabulary confidence.

## Details

The generic strategy JSON-quotes choice values and uses a chat prompt, which differs from Winnow’s trained serialization. Explicit strategy selection isolates this model-specific behavior while retaining existing generic routing and response semantics.

Temperature rescales conditional candidate probabilities. Confidence remains the raw engine probability of the selected candidate. A checkpoint-specific residual calibration is external, rather than baked into these weights.

This PR does not duplicate #60465’s endpoint implementation or #60676’s LiquidAI/Jev image work. AI assistance was used to implement, test, and document the contribution. The submitting human confirmed review of every changed line and execution of the relevant tests.
