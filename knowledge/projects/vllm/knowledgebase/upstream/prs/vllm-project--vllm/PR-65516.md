# [Attention/TopK] Compact hit_mask candidates via __ffs and BLSR in sampled_topk

[Upstream PR](https://github.com/vllm-project/vllm/pull/65516) · state: open · merged: False

## Original PR description

Iterate only set bits in hit_mask using (m &= m - 1u) and (__ffs(m) - 1) instead of running a 32-iteration bit-test loop per thread in sampled_topk() (7.91x micro-benchmark speedup).
