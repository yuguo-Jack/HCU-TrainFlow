# [Core] Add VLLM_NIXL_DISAGGREGATION_BACKEND env var for NIXL backend selection

[Upstream PR](https://github.com/vllm-project/vllm/pull/33185) · state: closed · merged: False

## Original PR description

Fixes #33169

## Purpose
Add an environment-variable based configuration option for selecting the NIXL disaggregation transport backend.

Previously, switching between NIXL backends (e.g., UCX vs LIBFABRIC) required changing `kv_transfer_config.kv_connector_extra_config`. This PR introduces:
- `VLLM_NIXL_DISAGGREGATION_BACKEND`

### Behavior / Priority
- If `VLLM_NIXL_DISAGGREGATION_BACKEND` is set, it overrides `kv_transfer_config.kv_connector_extra_config["backends"]`.
- If unset, behavior is unchanged (falls back to config / default `["UCX"]`).

- `python -m compileall`: PASS

```
