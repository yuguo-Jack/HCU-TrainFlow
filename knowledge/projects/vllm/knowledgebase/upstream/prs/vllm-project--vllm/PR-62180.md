# [Test][Spec Decode] Regression test for #61443 (GLM-5.3-Flash DFlash shape) on draft-layer tags

[Upstream PR](https://github.com/vllm-project/vllm/pull/62180) · state: open · merged: False

## Original PR description

Follow-up to #61455: the stacked test PR (andakai/vllm#8) staged this regression test against the pre-merge branch; this ports it onto main.

Covers the #61443 shape — MLA + align-mode Mamba target layers plus a DFlash2 drafter of plain GQA sliding-window layers tagged as draft layers the way the runner tags them. Asserts that under the generic packed layout, exactly the group holding the drafter's tagged layers is flagged `is_eagle_group` (EAGLE last-block drop applies to the drafter) while the align-mode Mamba groups stay unflagged, and that no "could be identified as the draft model's" warning fires.

Test-only change; supersedes andakai/vllm#8.
