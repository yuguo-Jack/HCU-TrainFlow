# Add MoE tuning config for RTX PRO 6000 Blackwell (E=512,N=512,fp8_w8a8)

[Upstream PR](https://github.com/vllm-project/vllm/pull/58085) · state: open · merged: False

## Original PR description

Tuning config for Qwen3-Coder-Next (E=512,N=512 MoE dimensions, FP8 quantization) on NVIDIA RTX PRO 6000 Blackwell Server Edition. Generated using vLLM's benchmark_moe.py across 1920 kernel configurations and 15 batch sizes.

## Purpose
No pre-built MoE tuning config existed for NVIDIA RTX PRO 6000 Blackwell Server Edition when running Qwen3-Coder-Next (E=512,N=512 MoE dimensions, FP8 quantization) — vLLM was falling back to default, unoptimized settings and logging "Using default MoE config. Performance might be sub-optimal!". This PR adds the tuning config generated for this GPU.

## Test Plan
Ran vLLM's benchmark_moe.py with --model Qwen/Qwen3-Coder-Next-FP8, --dtype fp8_w8a8, --tp-size 1, tuning across 1920 kernel configurations for 15 different batch sizes on a real RTX PRO 6000.

## Test Result
Generated config file was validated with vLLM — the model started up successfully with the new config and served requests at the expected throughput.
