## Summary
- Clarifies that NixlConnector selects transport backends through `kv_connector_extra_config.backends`.
- Notes that `NIXL_BACKEND` / `VLLM_NIXL_BACKEND` are not vLLM transport override knobs for NixlConnector.
- Adds an AWS EFA / LIBFABRIC example using `FI_PROVIDER=efa` plus `kv_connector_extra_config.backends`.
