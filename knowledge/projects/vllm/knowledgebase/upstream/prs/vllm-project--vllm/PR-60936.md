# [Perf][DSv4.1] Parallelize prefill Top-K/SWA index combination

[Upstream PR](https://github.com/vllm-project/vllm/pull/60936) · state: open · merged: False

## Original PR description

## Overview

Parallelize DeepSeek-V4.1 prefill Top-K/SWA index combination over tokens. Select one token per program for Top-K and two for SWA-only work, recovering small-shape performance while retaining the large-shape kernel improvement.

The approach follows [SGLang #41658](https://github.com/sgl-project/sglang/pull/41658). Benchmark baselines include the sentinel initialization from [#60613](https://github.com/vllm-project/vllm/pull/60613); this PR does not independently claim that correctness fix.

## Claims

- On B300, the real 16K/ratio2 combination shape takes 20.480 µs versus 49.152 µs for the sentinel-correct baseline in the specified cold-L2 microbenchmark. Small cold-L2 Top-K approximately matches baseline; SWA-only differences are mixed.
- The final selector completed a real two-B300 model run: **158,747 input tok/s at 64K/c8**, 20-sample median, versus a historical baseline of 157,799. The descriptive difference is **+949 tok/s (+0.60%)**, not a controlled causal speedup claim.
- Preserve exact integer output semantics and full sentinel padding. Seven committed GPU core cases and independent reference/replay checks passed. Six automated image integration cases are dependency-blocked, and final-selector matched model A/B is outstanding; these limits remain explicit below.

## Details

- Use a device-side upper-bound search for request ownership, preserving zero-query requests, nonzero query bases, invalid Top-K slots and bounded-replay SWA indices. Request/token counts remain runtime parameters.
- Choose the token tile using `TOP_K`, already present in the compilation key. The same helper supplies warmup compilation, launch grid and runtime tile size. No sequence-length threshold or single-request special case is added.
- Write the complete aligned output row, including `-1` tails, removing a separate fill. Preserve lengths and invalid-slot positions without compacting them. Model precision, selected attention indices and required computation are unchanged.


The same tile helper is used by warmup and runtime. The final formatted module SHA256 `5ec5d95f93e28e858daff0e0dc6f555e9c51ff15abe2f6fe477fce3e0da2aaad` is AST-identical to the independently GPU-tested selector. Broader request-count/kernel performance, Hopper/ROCm and full multimodal quality remain unvalidated. Outstanding automated validation: resolve the unchanged gated-config fixture dependency and run the six image cases. A matched whole-model comparison is still needed to attribute a stable end-to-end speedup to the final selector.

Prior duplicate checks found no matching token-parallel prefill implementation within the searched scope. #60091 concerns the ROCm Torch path, #56638 reuses the common kernel, and #60444 concerns decode indices. Preserve credit to SGLang #41658 and coordinate with sentinel-fix #60613.
