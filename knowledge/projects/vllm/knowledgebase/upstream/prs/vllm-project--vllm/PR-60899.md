# [Doc] Add k8s-aibom to deployment integrations

[Upstream PR](https://github.com/vllm-project/vllm/pull/60899) · state: closed · merged: True

## Original PR description



## Overview

Adds a `docs/deployment/integrations/k8s-aibom.md` page for [k8s-aibom](https://github.com/GoogleCloudPlatform/k8s-aibom), an open-source Kubernetes controller that produces a CycloneDX ML-BOM per serving workload, with vLLM as a natively detected runtime.

## Claims

- One short page in the existing integrations directory, same shape as the KubeAI and KAITO pages; no navigation changes (the directory is globbed).
- Links to the sibling pages it composes with (KubeAI, KServe, KubeRay, llm-d, production stack) rather than repeating them.

## Validation

- `markdownlint` with `tools/pre_commit/.markdownlint.yaml` passes on the new file.
- The page appears under Deployment → Integrations in the docs build (globbed directory, alphabetical).
- The install and plugin commands are the ones in the project's README, in the llm-d guide (`guides/runtime-inventory`), and in the vLLM production stack chart (optional `k8s-aibom` dependency).

## Details

k8s-aibom is already wired into two vLLM-ecosystem projects (production-stack as an optional chart dependency, llm-d as a guide) and into KubeAI as an optional subchart; this page gives vLLM users one place to find it. Detection is read-only toward the cluster and image-pattern based for vLLM (Docker Hub, GHCR, ROCm, ECR, Vertex Model Garden and LMCache image forms), so nothing here depends on vLLM internals.
