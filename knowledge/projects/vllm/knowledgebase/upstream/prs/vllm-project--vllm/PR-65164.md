## Original PR description

This PR is part of https://github.com/vllm-project/vllm/issues/43224. It is largely based on https://github.com/vllm-project/vllm/pull/45855 and SGLang's implementation of residual stream. Currently, implementing Residual Stream on Qwen3, more models are to follow.

#### E2E testing
Ran e2e inference with the following configs for the `LLM` object
```
CONFIGS = {
    # Baseline: stream runs but no AR is owed (tp_size == 1).
    "tp1": dict(model="Qwen/Qwen3-0.6B", tensor_parallel_size=1),
    # The path under test: deferred PARTIAL sums + fused AR at TP2, eager.
    "tp2_eager": dict(model="Qwen/Qwen3-0.6B", tensor_parallel_size=2,
                      enforce_eager=True),
    # Same, but through CUDA graphs: capture/profiling batches can exceed the
    # FlashInfer AR workspace cap -> exercises the unfused fallback path.
    "tp2_graphs": dict(model="Qwen/Qwen3-0.6B", tensor_parallel_size=2),
    # Quant-fused variant (FP8 static per-tensor scale).
    "tp2_fp8": dict(model="RedHatAI/Qwen3-0.6B-FP8-BLOCK",
                    tensor_parallel_size=2),
    # Regression: PP>1 must disable deferral (reduce_results=True, FULL).
    "pp2": dict(model="Qwen/Qwen3-0.6B", tensor_parallel_size=1,
                pipeline_parallel_size=2),
    # Control: Qwen2 is unmigrated (supports_residual_stream=False); must be
    # bit-for-bit identical to stock behavior.
    "qwen2_control": dict(model="Qwen/Qwen2.5-0.5B-Instruct",
                          tensor_parallel_size=2),
}
```
