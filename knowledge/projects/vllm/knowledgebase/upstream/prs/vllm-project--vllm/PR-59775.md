## Original PR description



## Overview

This PR removes a stale TODO(hc): cp_gather_cache need support scaled kvcache comment above cp_gather_cache.

## Claims

Scaled and quantized (e.g., FP8) KV cache gathering has already been fully implemented in the codebase via the highly-specialized gather_and_maybe_dequant_cache kernel (which uses compile-time sequence dimensions and specialized fp8::scaled_convert logic).

The gather_and_maybe_dequant_cache function already has scaled kv cache support implemented. and the functioned is hooked up in the relevant attention backends.
Because this functionality was built as a separate kernel rather than modifying the byte-wise cp_gather_cache, this TODO is no longer relevant and can be safely removed to prevent confusion for future contributors.

## Details

The kernel gather_and_maybe_dequant_cache already implements kv cache gathering with highly optimized on-the-fly dequantization.
