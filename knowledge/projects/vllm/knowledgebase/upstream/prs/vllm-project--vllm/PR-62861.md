## Details

Keep the test in the existing canonical-mapping suite and reuse its spec/cache/config helpers and `_store_all` / `_load_one`. A small setup helper derives each rank's mappings through `derive_canonical_mappings` and verifies that all requested layers take the portable path. The parametrized test owns reference generation, storage, loading and byte comparisons.

The references use a local seeded generator and signed-byte tensors. Writer payloads and reader expectations use head-axis `chunk()` calls, independently of the implementation's copy runs. Each layer uses one reference page; the existing replica-rotation test covers block-dependent writer selection. Distinct layer data and an intentionally different layer insertion order avoid relying on the dictionary order to associate a mapping with its reference.

Scope is the split-NHD, head-sharded mapping contract for eight KV heads and TP1/TP2. This does not exercise GPU transfers, window eviction, filesystem/object-store persistence or inference. It adds no production changes or dependencies.
