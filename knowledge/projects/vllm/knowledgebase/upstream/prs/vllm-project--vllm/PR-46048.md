## Original PR description

## [Model][GDN] Add prefix caching support for 'all' mode in Qwen3.5

### Motivation

GDN-based hybrid models (like Qwen3.5) previously only supported `mamba_cache_mode='none'` for prefix caching — meaning SSM states were always recomputed from scratch. This PR enables the `'all'` mode which caches cumulative compressed state at block boundaries, providing significant TTFP (time-to-first-token) savings for workloads with shared prefixes (system prompts, RAG contexts, multi-turn chat).

### Summary

Implement full prefix caching for GDN (Gated Delta Network) layers in `mamba_cache_mode='all'`. SSM state snapshots are saved at every block boundary during prefill, allowing subsequent requests with shared prefixes to skip recomputation by restoring cached states directly.

### Key Changes

| File | Change |
|------|--------|
| `vllm/model_executor/layers/mamba/gdn/qwen_gdn_linear_attn.py` | Block-by-block sequential processing for multi-block prefills with intermediate state saving; float32→bf16→float32 round-trip for precision consistency |
| `vllm/v1/attention/backends/gdn_attn.py` | Compute prefix caching block indices (`last_computed_token`, `last_scheduled_token`) in metadata builder for 'all' mode |
| `vllm/v1/worker/gpu_model_runner.py` | Pass `num_computed_tokens` to GDN attention metadata for cache restoration boundaries |
| `vllm/model_executor/models/qwen3_5.py` | Register Qwen3.5 model for `SupportsMambaPrefixCaching` protocol |
| `vllm/platforms/interface.py` | Add startup warning about minimum prefix length threshold for cache hits |
| `tests/v1/attention/test_gdn_metadata_builder.py` | Unit tests for block index computation (3 new test cases) |
| `tests/v1/e2e/general/test_gdn_prefix_cache.py` | E2E correctness tests verifying output determinism after cache restore (new file) |

### Design Decisions

1. **Block-by-block processing**: When a prefill spans multiple blocks, the chunk kernel is called once per block to produce correct float32 final states at each boundary. This avoids relying on bfloat16 intermediate states from the kernel's internal `h` tensor.

2. **Precision round-trip**: After saving each block's state to bfloat16 cache, we immediately reload it back to float32 for the next block's initial_state. This guarantees that block-by-block computation matches cache-restored computation bit-for-bit.

3. **Minimum prefix threshold warning**: In `'all'` mode, block_size is typically 2048 tokens (model-dependent). A startup warning informs users that prefixes shorter than this will not produce cache hits.

4. **Isolated 'all' vs 'align' mode logic**: The new prefill path is gated behind `is_cache_all`, ensuring zero impact on existing `'align'` and `'none'` mode behavior.

### Usage

```bash
vllm serve Qwen/Qwen3.5-0.8B \
  --enable-prefix-caching \
  --mamba-cache-mode all \
  --enforce-eager
```
