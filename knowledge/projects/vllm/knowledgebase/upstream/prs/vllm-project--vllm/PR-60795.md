# [Bugfix][Benchmark] Reject colliding sweep result directories

[Upstream PR](https://github.com/vllm-project/vllm/pull/60795) · state: open · merged: False

## Original PR description



## Overview

Reject benchmark-sweep combinations that generate the same result directory before starting work or reading cached measurements. Keep existing paths unchanged for valid sweeps.

Fixes #60794.

## Claims

- Serving, workload, and startup sweeps reject colliding generated paths before starting a child process or writing result files.
- Check the complete selected combination matrix, including collisions caused by joining names from both axes.
- Exclude pairs disabled by `--link-vars`; valid existing cached results still load from their original paths.
- Configuration collisions remain fatal with `--continue-on-error`, preventing another experiment's measurements from being reused.

## Details

Names can be distinct before filename sanitization but become the same output path. The cached-result branch then reads the first experiment's `run=0.json` and attaches the second experiment's overrides to those measurements. Separate unique names on each axis can also collide when concatenated.

Use one shared path-set validator before iteration in all three runners. Each runner supplies its existing path builder, and serving/workload use the existing linked-variable predicate. This adds one preflight pass and stores one path per selected combination. Directory encoding, valid cached filenames, process cleanup, and model execution remain unchanged. Duplicate generated paths are treated as configuration errors, including repeated combinations that would otherwise use the same result directory.

Overlap checks covered open sweep PRs and path/sanitization/collision keywords. Related PR #60328 validates names after `str()` conversion; it does not validate the final combined path. The original sanitized-name reproducer still failed when that PR's changed parameter module at `7e7eb7ba4063eccef73eaf470d6ccf6c96ea2355` was applied. This change operates at result planning and covers the selected matrix across all three runners.
