# [CI][ROCm] Mirror split V1 attention groups on MI355

[Upstream PR](https://github.com/vllm-project/vllm/pull/58691) · state: closed · merged: False

## Original PR description

- Add `mi355_1` mirrors and matching native AMD jobs for all four V1 attention groups: Sparse MLA, MLA Correctness, Dense/SSM, and DCP/MLA Backends/ROCm; retain three-way MLA correctness sharding.
- Exercise native ROCm and AITER dense attention, normal no-sink AITER sparse MLA, DSv4/DSv4.1 DSpark window graph replay, and the supported FlashAttention MLA prefill fallback.
- Fix the native ROCm sliding-window boundary exposed by these tests, and make the KV-connector selector test independent of the ambient AITER MHA setting.

[#57063](https://github.com/vllm-project/vllm/pull/57063) splits the B200 V1 attention suite, while [#50519](https://github.com/vllm-project/vllm/pull/50519) adds its earlier whole-suite AMD mirror and references the old MLA test path. This follow-up reconciles those layouts and adds numerical tests where existing AMD coverage checked only selection, metadata, or a different kernel path. It is a draft targeting `main` and must wait for **both #50519 and #57063** to merge, then be rebased to retain just this follow-up.

OpenAI Codex assisted with implementation and local validation.
