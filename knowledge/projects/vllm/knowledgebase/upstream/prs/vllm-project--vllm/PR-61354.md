# [Bugfix][XPU] Fix INC ARK weight loading for small TP shards

[Upstream PR](https://github.com/vllm-project/vllm/pull/61354) · state: open · merged: False

## Original PR description

Issue: Qwen3.5 and Qwen3.6 INT4 AWQ fail on TP4 with tensor size mismatch 0 vs 2

Root cause: auto_round_kernel's QuantLinear preallocates buffers with floor-rounded shapes (e.g. qzeros width `out // 32 * bits`), which become 0 for narrow TP shards such as Qwen3.5 GDN in_proj_ba at TP=4, causing copy_() to fail with a shape mismatch.

Fixed: Assign the loaded qweight/qzeros/scales directly instead, since post_init() only relies on the actual tensor shapes.
