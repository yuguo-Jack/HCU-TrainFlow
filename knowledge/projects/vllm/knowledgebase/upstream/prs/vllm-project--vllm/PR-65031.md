# Map `developer` role to `system` in MistralRenderer

[Upstream PR](https://github.com/vllm-project/vllm/pull/65031) · state: closed · merged: False

## Original PR description

## Summary

- Requests using `"role": "developer"` fail with a `ValidationError` when served with `--tokenizer-mode mistral` because `mistral-common` only accepts `system`/`user`/`assistant`/`tool` roles
- The HF renderer already handles this with `_convert_developer_to_system()`, but the Mistral renderer passes messages through unchanged
- Adds the same developer-to-system conversion in `MistralRenderer.render_messages()` and its async variant, applied before both `parse_chat_messages` and `apply_chat_template`

## Test plan

- `test_convert_developer_to_system`: verifies the helper converts developer→system without mutating the original list
- `test_developer_role_renders_with_mistral_tokenizer`: verifies the renderer applies the conversion before passing messages to the tokenizer

Fixes #64793
