# [CI][Benchmarks] Fix attention smoke test backend names and failure exit status

[Upstream PR](https://github.com/vllm-project/vllm/pull/63177) · state: closed · merged: True

## Original PR description



## Overview



The attention benchmark smoke test uses flash flashinfer, but the benchmark now requires the exact backend names FLASH_ATTN FLASHINFER. Both configurations therefore report Unknown backend.

These errors were caught and recorded without changing the process exit status. The command returned 0, allowing CI to report success even though neither benchmark ran successfully.

This change:

* Updates benchmarks.yaml to use FLASH_ATTN FLASHINFER.
* Makes the benchmark exit with status 1 when any configuration fails, after reporting results and writing requested JSON/CSV output.
* Applies the same failure check before the profiling path’s early return.
* Documents the corrected command and exit behavior.

PR #45728 (https://github.com/vllm-project/vllm/pull/45728) addressed obsolete arguments in the same smoke test but retained the lowercase backend names.
