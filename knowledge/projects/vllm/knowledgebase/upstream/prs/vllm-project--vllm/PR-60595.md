# [CI][ROCm] Drop MI300 MRv2 groups and other dead pipeline leftovers

[Upstream PR](https://github.com/vllm-project/vllm/pull/60595) · state: open · merged: False

## Original PR description

## Overview

Drop the five MI300 "Model Runner V2 *" groups from `test-amd.yaml`, plus three small dead pipeline leftovers.

Legacy-test tracker: A5

## Claims

- Removes the MI300 Model Runner V2 groups. MRv2 has been the default since #53183, and every path they ran is still run by a regular AMD group: `v1/engine`, `v1/e2e/general`, `entrypoints/llm`, distributed `basic_correctness`, async-llm/eagle DP, pipeline-parallel, `v1/spec_decode`, eagle/speculators/MTP e2e, and examples.
- Deletes the deprecated `.buildkite/test-pipeline.yaml` stub (CI moved to `test_areas` in Feb 2026) and the phantom `run-amd-test.py` entry in `ci_config_rocm.yaml`'s `run_all_patterns`.
- Drops the `ROCM_ATTN` branch in the NIXL PD sweep script. `vllm/platforms/rocm.py` excludes `ROCM_ATTN` for KV connectors, so that branch can never be selected.

## Validation

- `pre-commit run` on the changed files passes, including test tethering (no test loses its CI job).
- A repo-wide grep (vllm/, tests/, benchmarks/, examples/, tools/, docs/, .buildkite/) finds no remaining reference to any deleted file.
- Edited yamls parse; the explicit-key and test-tethering hooks pass.
- GPU tests not run locally; CI covers them.

## Details

- On ROCm, MRv1 is still the default only for DeepseekV32, DeepseekV4 and GlmMoeDsa (`vllm/config/vllm.py`), so the removed groups were already exercising the default path.
- Expect a small textual conflict with #60480, which edits the hunk next to this one.
- Split out of the original #60591 cleanup so each part reviews on its own. Part of a legacy-test audit; no test that currently runs is affected. Not a duplicate: open-PR searches found no PR removing these files.
