# [Kernel] Use expanding ldmatrix for Marlin W4A8

[Upstream PR](https://github.com/vllm-project/vllm/pull/50096) · state: closed · merged: False

## Original PR description

## Description

- Add a standalone CUDA probe that validates the `x1`, `x2`, and `x4` forms of PTX 9.4 `ldmatrix.sync.aligned.m8n16.shared::cta.s8.s4`, including signed-nibble expansion and direct INT8 MMA operand-B mapping.
- Add a symmetric W4A8-INT8 Marlin repack layout using eight K-major `m8n16` matrices per 32×32 tile, and replace the legacy load-and-dequant sequence with two expanding `x4` loads for eligible kernels.
- Compile and enable the path for matching SM90, SM100, SM107, SM110, and SM120 feature-specific targets with CUDA 13.4+, while retaining existing paths elsewhere and rejecting unsupported W4A8-INT8 act-order configurations.
- Complete Phase 0 and Phase 1 for the symmetric Marlin `kU4B8` path without changing checkpoint formats, Machete, MoE, or zero-point paths.

Partially addresses #49529.
