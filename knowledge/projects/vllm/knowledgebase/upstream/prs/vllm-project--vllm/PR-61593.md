## Overview

This PR enables GeLU_Tanh activation support required for W4A8 quantized Gemma4 MoE models.


## Validation

-Add support for GeLU(Tanh) activation.
-Enable execution of W4A8 Quantizated Gemma4 MoE architecture.

This PR resolves the runtime error "No W4A8 Int8 MoE backend supports the deployment configuration." when running quantized Gemma4 MoE.
