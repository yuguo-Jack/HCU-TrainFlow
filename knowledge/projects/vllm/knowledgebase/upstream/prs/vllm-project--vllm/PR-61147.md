# [Bugfix][Tool Calling] Fix doom loop with strict-mode empty-argument tools

[Upstream PR](https://github.com/vllm-project/vllm/pull/61147) · state: open · merged: False

## Original PR description

## Summary

Fixes #50989.

When a tool has `strict: true` and empty parameters (`"properties": {}, "required": [], "additionalProperties": false`), xgrammar generates a degenerate grammar `root ::= [ \n\t]*` — whitespace-only with no exit condition. The model loops on whitespace tokens indefinitely (doom loop).

**Fix** (`vllm/tool_parsers/structural_tag_registry.py`):
- For vLLM-defined structural tags (hermes, minimax, etc.): `get_function_parameters()` returns `True` (unconstrained) when the schema has no properties, avoiding the degenerate grammar.
- For xgrammar-builtin structural tags (Qwen, DeepSeek): `_dump_tool_for_xgrammar()` omits `strict: true` when parameters have no properties, so xgrammar uses unconstrained argument generation.

The model already knows to output `{}` for no-argument tools — the grammar was the obstacle.
