# [Perf][Model] Build Phi4MM Conformer streaming mask on target device

[Upstream PR](https://github.com/vllm-project/vllm/pull/47225) · state: open · merged: False

## Original PR description


Replace the NumPy/CPU adaptive_enc_mask construction in Conformer _streaming_mask with equivalent torch operations on the target device. This preserves mask semantics while avoiding CPU tensor creation and host-to-device copies in the encoder forward path.

## Purpose
This PR updates the Phi4MM Conformer streaming mask construction to use torch-native operations on the target device.

Previously, `_streaming_mask()` built the mask via NumPy/CPU tensor logic and returned a CPU tensor that was later copied to the model device. The new implementation computes the same boolean mask directly with PyTorch ops on the target device, avoiding CPU tensor creation and host-to-device copy in the encoder forward path.

This preserves the existing mask semantics while making the encoder forward path more device-local and compile/graph friendly.
