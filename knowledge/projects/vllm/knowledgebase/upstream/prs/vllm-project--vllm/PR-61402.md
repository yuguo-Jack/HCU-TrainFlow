# [ROCm] Use mfma_r4_w4 for long gfx942 FP8 MQA logits

[Upstream PR](https://github.com/vllm-project/vllm/pull/61402) · state: open · merged: False

## Original PR description



The gfx942 flydsl picker selects mfma_r4_w2 when the query is at least 2048 and the KV length is at least 8192. Passing mfma_r4_w4 uses four waves and leaves the KV tile at 128.



## Overview

This PR makes the small change of using 4 waves instead of 2 for FP8 MQA logits kernel under these conditions:
 - on gfx942 
 - query length >= 2048
 - KV length >= 8192

## Claims



## Validation

Tested on MI325X with tencent/Hy4-preview-FP8. Median time to first token dropped about 23% at 8k/1k, concurrency 8. At 64k/1k, concurrency 4, the median was about 1% slower and the mean was about 8% slower.
