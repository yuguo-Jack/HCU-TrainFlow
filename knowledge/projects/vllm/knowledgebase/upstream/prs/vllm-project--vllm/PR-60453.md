# [DeepSeek-V4-P2-04] Reuse DeepSelect for deterministic sparse top-k

[Upstream PR](https://github.com/vllm-project/vllm/pull/60453) · state: open · merged: False

## Original PR description

## Scope

This is the P2-04 split of #62365, rebased onto current `main`. It implements the batch-invariant sparse top-k path by reusing the existing `vllm.model_executor.layers.indexer_topk.deep_select_topk` wrapper.

- No new CUDA operator, `top_k.cu`, CMake entry, or torch binding.
- No new test file; the dispatch check is added to the existing `tests/kernels/test_top_k_per_row.py`.
- Non-BI dispatch remains unchanged.
- BI DCP/PCP is rejected explicitly because the distributed merge has a different tie-break contract. BI decode requires one request-local row per query row and zero row starts.
- The diff is 99 added lines including the test.
