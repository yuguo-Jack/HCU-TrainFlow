# [DeepSeek-V4-P2-04] Isolate deterministic sparse top-k selection

[Upstream PR](https://github.com/vllm-project/vllm/pull/60453) · state: open · merged: False

## Original PR description

## Overview

Use one deterministic sparse top-k selector for batch-invariant prefill and decode. A composite score/request-local-index key fixes ties and output order without depending on a request's packed-buffer offset. Unsupported BI DCP/PCP selection fails explicitly; non-BI selection is unchanged.

The CUDA selector is registered in vLLM's existing stable `_C` extension and uses the existing top-k test file.

## Test

On an **unpublished** current-`main` merge candidate, the stable `_C` extension rebuilt on H20 and **7 targeted top-k tests passed** against that build. The earlier H100 integration run also passed these cases. These are not CI results on the current PR head; full-model evaluation remains unrun.
