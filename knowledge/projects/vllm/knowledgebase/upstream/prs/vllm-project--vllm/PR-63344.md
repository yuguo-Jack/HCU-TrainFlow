# [Doc][ROCm] Document DeepSeek-V4.1-Flash MI355X AgentX TP2 profiles

[Upstream PR](https://github.com/vllm-project/vllm/pull/63344) · state: closed · merged: True

## Original PR description

## Overview

Document the DeepSeek-V4.1-Flash MI355X TP2 AgentX scheduling profiles from [InferenceX #4409](https://github.com/SemiAnalysisAI/InferenceX/pull/4409). The official recipe already covers the base serving stack but omits the running-sequence caps for client concurrencies 16 and 32.

## Claims

- Make c16 (`8192` batched tokens / `4` running sequences) and c32 (`8192` / `8`) derivable from the MI355X + FP8 (0909) command, with a graph capture cap of `1024`.
- Document the qualified image digest and profile-specific launch additions while preserving generic builder defaults and existing TP4 reproduction guidance.
- Keep real DSpark block rejection in production commands and identify synthetic acceptance as throughput-measurement behavior.

## Details

The smaller prefill chunk and running-sequence caps reduce prefill/decode interference for these workload profiles; additional clients queue. These values belong in workload-specific guidance rather than generic builder defaults.

The audited [InferenceX configuration at `9ab3d80f`](https://github.com/SemiAnalysisAI/InferenceX/blob/9ab3d80f7698a4a46521a71b36e023419e05f30f/inferencex-e2e/benchmarks/single_node/srt-slurm-recipes/dsv41flash/vllm/mi355x-fp4-mtp/agentic.yaml) and [master configuration](https://github.com/SemiAnalysisAI/InferenceX/blob/9ab3d80f7698a4a46521a71b36e023419e05f30f/inferencex-e2e/configs/amd-master.yaml#L1513) identify the launch checkpoint, image and active search points. TP4 c16/c32 was excluded from that sweep and is not claimed as qualified.

Non-duplication: searches across open and merged PRs in vLLM and recipes found no coverage of these MI355X c16/c32 settings. The older [recipes #1106](https://github.com/vllm-project/recipes/pull/1106) is closed and concerns NVIDIA B200; the remaining older MI355X proposals concern the base stack or earlier graph sizing. This update belongs in this repository's canonical `recipes/models/` source following [vLLM #61302](https://github.com/vllm-project/vllm/pull/61302).
