# [Bugfix][AuxOutput] Retain routed experts while a KV cache tier holds their blocks

[Upstream PR](https://github.com/vllm-project/vllm/pull/62591) · state: closed · merged: True

## Original PR description

## Purpose

Split from #58328, after #62392 and #62489.

The routed-experts store evicts by its own LRU, so a prefix hit can reuse KV whose routed experts are gone, and the worker fails with `BlockObjectStoreError`.

- **Retention:** the scheduler tracks, from KV cache events, which blocks still have routed experts and tells the worker which to retain and release.
- **Hit capping:** a local hit past the retained blocks is dropped. An external hit is trimmed to what the connector can load (new `KVConnectorBase_V1.external_load_alignment`, full attention only), or dropped if it loads only whole hits.
- **Store sizing:** the store starts at the KV cache size and grows with a warning instead of failing.

Not handled: hits before `routed_experts_prompt_start` still need retained outputs, and hybrid Mamba hits ending mid-block are dropped.
