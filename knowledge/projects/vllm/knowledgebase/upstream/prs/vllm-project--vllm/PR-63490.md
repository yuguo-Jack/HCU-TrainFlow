## Overview

Moves two ROCm pieces of #63232 into their own PRs, so that #63232 gets smaller:

- DBO under pure TP + the hipBLASLt handle warm-up: #63483 (against main).

## Claims

- Default serving does not change. SP runs only with `VLLM_ROCM_MINIMAX_M3_SP_PREFILL=1`; DBO under pure TP needs `--enable-dbo` with TP only. The M3.1-Flash recipe uses neither.
- The 14 engine files that the DBO change touched return to the branch base (7879f3687b) byte for byte. The DBO guard in `amd/indexer_nvfp4.py` stays: it uses `dbo_enabled()`, which main already has.
- 44 files, +38 -8776: 28 files removed (SP and its kernels and tests, `tests/v1/worker/test_dbo_pure_tp.py`), 16 edited.
