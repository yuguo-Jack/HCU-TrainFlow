# [Bugfix][KV Connector] MoRIIO: treat FINISHED_STOPPED as producer decode completion

[Upstream PR](https://github.com/vllm-project/vllm/pull/62020) · state: open · merged: False

## Original PR description

Fixes #61389

## What the issue was
On the prefill (producer) side, a request with `do_remote_decode=True` and `max_tokens=1` that samples EOS or a stop token as its first token finishes with `FINISHED_STOPPED`. MoRIIO ignored this status, so the prefill KV blocks were never exported and the decode side got no remote block metadata.

## Why it happened
`MoRIIOConnectorScheduler.request_finished()` in `vllm/distributed/kv_transfer/kv_connector/v1/moriio/moriio_connector.py` only continued when `request.status == FINISHED_LENGTH_CAPPED`. `check_stop()` sets `FINISHED_STOPPED` before the length cap is checked, so the method returned `(False, None)` early. The NIXL connector (`nixl/pull_scheduler.py`) already accepts both statuses.

## The fix
Accept `FINISHED_LENGTH_CAPPED` and `FINISHED_STOPPED`. Other statuses (e.g. aborted) still return early. Two files, 46 insertions, 3 deletions.

## Not covered
No end-to-end test with a real MoRIIO P/D deployment (needs ROCm hardware). I did not audit other MoRIIO paths for similar status assumptions.

## Validation
Run:
- `ruff check` and `ruff format --check` on both changed files: pass.
- `python -m py_compile` on both files, `git diff --check`: pass.
- An isolated harness that executes the actual `request_finished` method body (extracted from the source) with stubbed dependencies, before and after the change. Before: `FINISHED_STOPPED` returned `delay_free=False, params=None`. After: `delay_free=True`, params with `remote_block_ids` returned, request tracked for deferred send. `FINISHED_LENGTH_CAPPED` unchanged; `FINISHED_ABORTED` still returns `(False, None)`.

Not run: the new pytest tests (`tests/v1/kv_connector/unit/test_moriio_routing.py`). torch is not installable in my environment, and the module imports vLLM. Please run them locally; the stop-status case should fail without the source change and pass with it.
