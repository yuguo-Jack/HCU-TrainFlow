## Original PR description

Use the same text config as the PaliGemma backbone. Transformers 5.20 leaves the legacy top-level text_config as a dictionary, which breaks ColPali initialization.



## Overview
Fix ColPali initialization with Transformers 5.20.2 by reading the projection hidden size from `vlm_config.text_config`.
