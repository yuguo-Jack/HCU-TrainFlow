# [CI] Remove redundant Ubuntu 24.04 release variant

[Upstream PR](https://github.com/vllm-project/vllm/pull/63413) · state: closed · merged: True

## Original PR description

## Overview

Remove the redundant Ubuntu 24.04 CUDA release variant, including its build jobs, staging manifest, and Docker Hub publication. The default CUDA images already use Ubuntu 24.04.

## Claims

- Remove two duplicate image builds (x86_64 and aarch64), the extra ECR multi-arch manifest, and its publish dependency.
- Remove the `cuda-13-0-ubuntu-24-04` publishing target and matrix entry. No new `-ubuntu2404` tags or aliases are published.
- Document migration to the default tags, including per-architecture tags.

## Validation

- `bk pipeline validate --file .buildkite/release-pipeline.yaml` — passed against the official Buildkite schema.
- `bash -n .buildkite/scripts/publish-release-images.sh` — passed.
- `.venv/bin/pre-commit run --files .buildkite/release-pipeline.yaml .buildkite/scripts/publish-release-images.sh docs/getting_started/installation/gpu.cuda.inc.md` — passed.
- `git diff --check` — passed.
- Local Python/PyYAML validation: all pipeline dependency references resolve; no Ubuntu variant build, manifest, or publish-matrix entry remains.
- Invoking the removed publishing target exits with usage/status 2 before external commands. Source comparison confirms the default CUDA and other publishing bodies are unchanged from the base commit.

No full Docker build or registry publication was run. Model evaluations are not applicable: only release orchestration and docs change. Human review and release-pipeline validation remain required before merge. Rendered docs preview verification remains pending.

## Details

The Dockerfile defaults to `UBUNTU_VERSION=24.04` and `GDRCOPY_OS_VERSION=Ubuntu24_04`. Both previous release variants passed `CUDA_VERSION=13.0.2`, the same per-architecture manylinux builder and CUDA architecture list, and the same KV-connector setting. The explicit Ubuntu overrides were redundant.

Users of `latest-ubuntu2404` or versioned `-ubuntu2404` tags must switch to the default tags for future releases. This change does not delete previously published registry tags.

Duplicate-work check: searched open PRs for `ubuntu2404`, Ubuntu release duplication, and release deduplication. Reviewed #46711, which adds registry caching rather than removing duplicate builds. No associated issue was supplied.
