# [Bugfix][MoE] Size the FlashInfer one-sided dispatch for experts that quantize their own inputs

[Upstream PR](https://github.com/vllm-project/vllm/pull/59134) · state: open · merged: False

## Original PR description

## Purpose

With a block-FP8 MoE, `--moe-backend flashinfer_cutlass` and `--all2all-backend flashinfer_nvlink_one_sided`, `FlashInferExperts.expects_unquantized_inputs` is True, so the one-sided prepare step dispatches the BF16 activations and the CUTLASS kernel quantizes them itself. `make_fp8_moe_kernel` builds the prepare/finalize before the experts and passes no `input_dtype`, so `flashinfer_one_sided_dispatch_layout` sizes the MoeAlltoAll workspace for FP8 rows plus FP32 1x128 scales. For hidden size 2560 and top-k 10 that is 2,720 bytes per token (2560 + 80 + 80 for top-k ids and weights) where 5,200 are dispatched.

FlashInfer lays out the dispatch payloads from the actual tensor sizes of each call, puts the combine region right after them, and checks both against the per-rank workspace size. An undersized workspace therefore works until a step's largest per-rank token count gets close to the size the workspace was reserved for (`max_num_batched_tokens`), and then combine raises `workspace insufficient for combine payload region`. For the shapes above that happens at about 76% of `max_num_batched_tokens`. On main this makes the configuration below fail at startup: the profile run dispatches `max_num_batched_tokens` tokens on every rank and combine raises that error, so the engine never comes up.

This PR:

- `make_fp8_moe_kernel` builds standard-format experts before the prepare/finalize (they do not depend on it) and passes `input_dtype=moe_config.in_dtype` when `experts.expects_unquantized_inputs`, the same way #57176 sizes the dispatch for per-token NVFP4. Batched-format experts are still built after the prepare/finalize, from its max tokens and dispatcher count.
- `make_eep_staged_quant_method`, which rebuilds the prepare/finalize for elastic EP, passes `input_dtype` from the existing experts' `expects_unquantized_inputs`. It passed none before, so the rebuild also dropped the per-token NVFP4 sizing from #57176.

Experts that quantize before the dispatch (DeepGEMM, Triton without LoRA) keep the FP8 + scales layout.

**Not a duplicate.** I searched open PRs for `flashinfer_nvlink_one_sided`, `one-sided dispatch`, `one_sided_dispatch_layout`, `expects_unquantized_inputs`, `defer_input_quant all2all`, `combinePayloadOffset` and `workspace insufficient for combine`. #57176 (merged) fixed the same sizing for per-token NVFP4 only. #57073 adds a new all-to-all backend that reuses `flashinfer_one_sided_dispatch_layout`, #50030 changes FP8 backend selection only, and #49335 fixes MXFP8 scale swizzling after the dispatch; none of them changes how the FP8 dispatch is sized.

**Not covered:** `TritonExperts` defers input quantization only once a MoE LoRA context is attached, which happens after the kernel is built, so FP8 MoE LoRA with the one-sided dispatch still reserves FP8 rows.

```python
"""Reproduce what happens when the FlashInfer one-sided workspace is sized for block-FP8
dispatch (hidden bytes + fp32 1x128 scales) but BF16 activations are dispatched, as with
FLASHINFER_CUTLASS block-FP8 experts (expects_unquantized_inputs=True).

    python repro_undersized_layout.py [--layout fp8|bf16] [--world-size 2]

Every row a rank dispatches encodes (source rank, token index) in small integers that are
exact in BF16. Each rank checks that it received exactly the tokens routed to it, intact,
then combines with identity experts and checks every token comes back as
x * (number of distinct destination ranks).
"""

import argparse
import os
import traceback

import torch
import torch.multiprocessing as mp

HIDDEN, TOP_K, NUM_EXPERTS, MAX_TOKENS = 2560, 10, 64, 4096
FRACTIONS = (0.25, 0.5, 0.7, 0.75, 0.8, 1.0)


def make_inputs(src, t):
    g = torch.Generator(device="cuda").manual_seed(1000 * src + t)
    topk_ids = torch.rand(t, NUM_EXPERTS, device="cuda", generator=g).topk(TOP_K, dim=1)
    topk_ids = topk_ids.indices.to(torch.int32)
    topk_w = torch.rand(t, TOP_K, device="cuda", generator=g)
    tok = torch.arange(t, device="cuda")
    x = (torch.arange(HIDDEN, device="cuda") % 7 + 1).repeat(t, 1).float()
    x[:, 0] = src + 1
    x[:, 1] = tok // 128
    x[:, 2] = tok % 128
    return x.to(torch.bfloat16).contiguous(), topk_ids, topk_w


def worker(rank, world_size, port, dp_port, layout, queue):
    try:
        os.environ.pop("CUDA_VISIBLE_DEVICES", None)
        torch.accelerator.set_device_index(rank)
        from vllm.config import VllmConfig, set_current_vllm_config
        from vllm.config.parallel import ParallelConfig
        from vllm.distributed.parallel_state import (
            ensure_model_parallel_initialized,
            get_dp_group,
            init_distributed_environment,
        )

        cfg = VllmConfig()
        cfg.parallel_config = ParallelConfig(
            data_parallel_size=world_size,
            data_parallel_rank=rank,
            _data_parallel_master_port_list=[int(dp_port)],
        )
        with set_current_vllm_config(cfg):
            init_distributed_environment(
                world_size=1, rank=0, distributed_init_method=f"tcp://localhost:{port}",
                local_rank=rank,
            )
            ensure_model_parallel_initialized(1, 1)

        from vllm.distributed.device_communicators.all2all import (
            FlashInferNVLinkOneSidedManager,
        )

        manager = FlashInferNVLinkOneSidedManager(get_dp_group().cpu_group)
        if layout == "fp8":  # what vLLM main computes for block FP8
            x_bytes, sf_bytes = HIDDEN, HIDDEN // 128 * 4
        else:  # what is actually dispatched
            x_bytes, sf_bytes = HIDDEN * 2, 0
        manager.initialize(
            max_num_tokens=MAX_TOKENS, top_k=TOP_K, num_experts=NUM_EXPERTS,
            hidden_size=HIDDEN, x_bytes_per_token=x_bytes, x_sf_bytes_per_token=sf_bytes,
        )
        a2a = manager.moe_alltoall
        per_rank = NUM_EXPERTS // world_size
        pattern = (torch.arange(HIDDEN, device="cuda") % 7 + 1).float()
        results = []
        for frac in FRACTIONS:
            t = int(MAX_TOKENS * frac)
            x, topk_ids, topk_w = make_inputs(rank, t)
            try:
                recv_x, recv_ids, _ = a2a.dispatch(
                    token_selected_experts=topk_ids, input_payloads=[x, topk_ids, topk_w],
                    runtime_max_tokens_per_rank=t, invalid_token_expert_id=-1,
                    expert_id_payload_index=1,
                )
                torch.accelerator.synchronize()
                recv_x = recv_x.view(world_size, t, HIDDEN).float()
                recv_ids = recv_ids.view(world_size, t, TOP_K)
                bad = 0
                for src in range(world_size):
                    _, src_ids, _ = make_inputs(src, t)
                    want = torch.nonzero((src_ids // per_rank == rank).any(-1)).flatten()
                    rows = recv_x[src][(recv_ids[src] // per_rank == rank).any(-1)]
                    got = (rows[:, 1] * 128 + rows[:, 2]).long()
                    bad += int((rows[:, 0] != src + 1).sum())
                    bad += int((rows[:, 3:] != pattern[3:]).any(-1).sum())
                    bad += int(got.numel() != want.numel() or
                               not torch.equal(got.sort().values, want))
                manager.combine_into(
                    payload=recv_x.to(torch.bfloat16).contiguous(),
                    runtime_max_tokens_per_rank=t, output=(out := torch.empty_like(x)),
                )
                torch.accelerator.synchronize()
                n_dst = sum((topk_ids // per_rank == r).any(-1).int() for r in range(world_size))
                bad_out = int((out.float() != x.float() * n_dst[:, None]).any(-1).sum())
                status = f"dispatch errors={bad}, wrong combined tokens={bad_out}/{t}"
            except Exception as e:  # noqa: BLE001
                status = f"EXCEPTION {type(e).__name__}: {str(e).splitlines()[0][:160]}"
            results.append((frac, t, status))
            torch.distributed.barrier(group=get_dp_group().cpu_group)
            if status.startswith("EXCEPTION"):
                break
        queue.put((rank, manager.workspace_size, results))
        manager.cleanup()
    except Exception:
        queue.put((rank, None, traceback.format_exc()))


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--layout", choices=["fp8", "bf16"], default="fp8")
    p.add_argument("--world-size", type=int, default=2)
    a = p.parse_args()
    from vllm.utils.network_utils import get_open_port

    mp.set_start_method("spawn")
    port, dp_port = str(get_open_port()), str(get_open_port())
    q = mp.Queue()
    procs = [mp.Process(target=worker, args=(r, a.world_size, port, dp_port, a.layout, q))
             for r in range(a.world_size)]
    for pr in procs:
        pr.start()
    outs = [q.get(timeout=900) for _ in procs]
    for pr in procs:
        pr.join(timeout=60)
    for rank, ws, res in sorted(outs, key=lambda o: o[0]):
        print(f"== layout={a.layout} rank {rank} workspace_size_per_rank={ws}")
        if isinstance(res, str):
            print(res)
            continue
        for frac, t, status in res:
            print(f"   runtime tokens/rank {t:5d} ({frac:.0%} of {MAX_TOKENS}): {status}")


if __name__ == "__main__":
    main()
```
