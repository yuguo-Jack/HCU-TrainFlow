# [Config] Move V2-only checks into V1 model runner unsupported features

[Upstream PR](https://github.com/vllm-project/vllm/pull/64830) · state: closed · merged: True

## Original PR description

use_v2_model_runner special-cased HiSparse, custom speculative methods and watermarking to force Model Runner V2. These are just features the V1 model runner doesn't support, so list them in
_get_v1_model_runner_unsupported_features() alongside the other V2-only features and let _validate_v1_model_runner() reject them.

Since V2 is already the default, use_v2_model_runner no longer needs to inspect them. The behavior change is that watermarking with VLLM_USE_V2_MODEL_RUNNER=0 now raises instead of silently overriding the env var, consistent with the other V2-only features.
