## Original PR description

## Overview

Restore the requested `[..., out_features]` shape after FlashInfer FP8 linear. The base class flattens activations for GEMM and passes `output_shape`, but this backend returns the flattened result. Reshape that same result with a view; quantization, scales, bias and GEMM operations are unchanged.

Follows #44728, which closed without merging. The separate non-contiguous-input work in #37620 is outside this fix.
