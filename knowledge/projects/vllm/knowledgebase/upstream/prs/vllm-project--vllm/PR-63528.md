# [ROCm][MiniMax-M3.1] Improve TP4 decode and native INT4 reduction

[Upstream PR](https://github.com/vllm-project/vllm/pull/63528) · state: closed · merged: False

## Original PR description

## Overview

Improve MiniMax M3.1 TP4 decode on MI355X with context-parallel NVFP4 indexing, batch-sharded sampling, bounded native MXFP8 tile tuning, and a faster native INT4 QuickReduce transport. Stacked on #63232 at `8d0f05a0c33c91cc4d3f0a6f189474420af47174`.

## Claims

- The original CP, sampler and native MXFP8 changes improved one-hour C32 throughput **1.35%** and mean ITL **5.85%** in their matched comparison.
- The added native TP4 INT4 transport reduces cold public-API collective latency **34.4%** at M256×6144: **32.90 → 21.57 µs**.
- A separate clean one-hour C32 comparison of the transport shows **2.18% lower P90 ITL**, **7.702 → 7.534 ms**, equivalent to **2.23% higher P90 interactivity**. Throughput is flat (**+0.03%**).

These are separate measurements, with the configurations below; the percentages are not additive.

## Validation

All serving comparisons use four MI355X GPUs per arm, the same pinned AMD Quark checkpoint, TP4, seven drafts with synthetic AL4.04, NVFP4 main/index KV, BF16 draft KV, DBO and prefix caching. Software: Torch 2.13.0+rocm10.0.0, Triton 3.8.0+git669b31ac, AITER 0.1.26, fastokens 0.2.0.

| --- | ---: | ---: | ---: |
| Original CP + sampler + native MXFP8: output tokens/s | 1278.25 | 1295.45 | +1.35% |
| Same comparison: mean ITL, ms | 6.458 | 6.080 | −5.85% |
| Same comparison: mean TTFT, ms | 486.94 | 497.61 | +2.19% |

| Native INT4 transport: mean TTFT, ms | 472.084 | 467.688 | −0.93% |

The original combined-patch comparison used historical index-top-k frequency 2. The transport comparison uses **frequency 1** and reverses the GPU placements from the first screening pair. Each comparison has one run per arm, 354 completed warmups per arm, and zero request errors. The larger 6.9% interactivity effect in the first transport screening pair did not reproduce; it is excluded from the claims. The two arms of the transport comparison share the same separate draft-attention patch; only the native extension changes. That attention patch is outside this PR. There is no end-to-end claim for all changes combined on a fresh final-branch replay.

Cold collective measurements use the public `QuickAllReduce` API, the same physical four-GPU group, A–B–B–A startup order (two runs per revision), seven samples/run, and five HIP-graph replays/sample. Inputs rotate through more than 400 MiB. Each sample takes the maximum across ranks; the table reports the median of the two run medians. Allocation, reference computation, setup, capture and warmup are outside timing; codec, casts, peer transfers and flags are inside.

```python
# SPDX-License-Identifier: Apache-2.0
# SPDX-FileCopyrightText: Copyright contributors to the vLLM project
"""Measure public INT4 QuickReduce with cold inputs and every rank timed.

Run the same command on each revision, using the same physical GPU group:

    VLLM_ROCM_QUICK_REDUCE_QUANTIZATION=INT4 \
    VLLM_ROCM_QUICK_REDUCE_CAST_BF16_TO_FP16=1 \
    VLLM_ROCM_QUICK_REDUCE_MAX_SIZE_BYTES_MB=512 \
    .venv/bin/python -m torch.distributed.run --standalone --nproc-per-node=4 \
        benchmarks/kernels/benchmark_rocm_int4_quick_reduce.py --output result.json

The input footprint must exceed the GPU last-level cache. Output is reused.
Allocation, reference reduction, setup and a device barrier are outside timing.
The measured boundary includes the complete public native collective, including
its codec, peer communication, flags and BF16 casts. This is not a serving test.
"""

import argparse
import datetime
import hashlib
import json
import math
import os
import statistics
import subprocess
from pathlib import Path


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--rows", nargs="+", type=int, default=[192, 256, 512, 2048])
    parser.add_argument("--hidden-size", type=int, default=6144)
    parser.add_argument("--working-set-mib", type=int, default=400)
    parser.add_argument("--warmup-replays", type=int, default=5)
    parser.add_argument("--replays", type=int, default=5)
    parser.add_argument("--samples", type=int, default=7)
    parser.add_argument("--output", type=Path)
    args = parser.parse_args()
    assert all(
        n > 0
        for n in [
            *args.rows,
            args.hidden_size,
            args.working_set_mib,
            args.warmup_replays,
            args.replays,
            args.samples,
        ]
    )
    os.environ.setdefault("TORCH_NCCL_BLOCKING_WAIT", "1")

    import torch
    import torch.distributed as dist
    import vllm._C

    import vllm
    from vllm.distributed.device_communicators.quick_all_reduce import (
        QuickAllReduce,
        QuickReduceRegime,
    )

    local_rank = int(os.environ["LOCAL_RANK"])
    torch.cuda.set_device(local_rank)
    device = torch.device("cuda", local_rank)
    assert torch.version.hip, "This benchmark requires ROCm."
    timeout = datetime.timedelta(minutes=3)
    dist.init_process_group("gloo", timeout=timeout)
    rank, world = dist.get_rank(), dist.get_world_size()
    assert world == 4, "This reproducer measures local TP4."
    gpu_group = dist.new_group(backend="nccl", timeout=timeout)
    qr = None
    rows = []
    try:
        qr = QuickAllReduce(dist.group.WORLD, device)
        assert not qr.disabled, "Enable INT4 QuickReduce on supported local GPUs."
        assert qr.qr_quant_level == QuickReduceRegime.INT4 and qr.use_fp16_kernels
        generator = torch.Generator(device=device).manual_seed(14293 + rank)
        barrier = torch.zeros(1, device=device)
        events = [
            (torch.cuda.Event(enable_timing=True), torch.cuda.Event(enable_timing=True))
            for _ in range(args.samples)
        ]
        for m in args.rows:
            if rank == 0:
                print(f"Checking M={m}, then cold graph timing", flush=True)
            payload = m * args.hidden_size * 2
            slots = max(2, math.floor(args.working_set_mib * 1024**2 / payload) + 1)
            inputs = torch.randn(
                (slots, m, args.hidden_size), device=device, generator=generator
            ).bfloat16()
            output = torch.empty_like(inputs[0])
            eligible = qr.should_quick_allreduce(inputs[0])
            if not eligible:
                rows.append({"shape": [m, args.hidden_size], "eligible": False})
                continue
            quantized = (
                qr.qr_quantization_min_size is None
                or payload >= qr.qr_quantization_min_size
            )
            worst_rms = 0.0
            # Check every rotating input before capture, including the final one.
            for inp in inputs:
                reference = inp.float()
                dist.all_reduce(reference, group=gpu_group)
                qr.quick_all_reduce(inp, out=output)
                torch.cuda.synchronize()
                assert torch.isfinite(output).all()
                rms = (
                    (
                        (output.float() - reference).square().sum()
                        / reference.square().sum().clamp_min(1e-30)
                    )
                    .sqrt()
                    .item()
                )
                assert rms < (0.15 if quantized else 0.01), (m, rank, rms)
                worst_rms = max(worst_rms, rms)
            expected_last = output.clone()
            graph = torch.cuda.CUDAGraph()
            dist.barrier()
            with torch.cuda.graph(graph):
                for inp in inputs:
                    qr.quick_all_reduce(inp, out=output)
            for _ in range(args.warmup_replays):
                graph.replay()
            torch.cuda.synchronize()
            samples = []
            for start, end in events:
                dist.barrier()
                dist.all_reduce(barrier, group=gpu_group)
                start.record()
                for _ in range(args.replays):
                    graph.replay()
                end.record()
                torch.cuda.synchronize()
                samples.append(start.elapsed_time(end) * 1000 / (args.replays * slots))
            torch.testing.assert_close(output, expected_last, rtol=0, atol=0)
            rows.append(
                {
                    "shape": [m, args.hidden_size],
                    "payload_bytes": payload,
                    "eligible": True,
                    "codec": "INT4" if quantized else "FP",
                    "slots": slots,
                    "active_input_bytes": inputs.numel() * 2,
                    "relative_RMS_max": worst_rms,
                    "samples_us": samples,
                    "every_cold_input_checked": True,
                    "graph_final_output_exact_match": True,
                }
            )
            graph.reset()
            del graph, inputs, inp, output, reference, expected_last
        properties = torch.cuda.get_device_properties(device)
        local = {
            "rank": rank,
            "local_rank": local_rank,
            "device": torch.cuda.get_device_name(device),
            "arch": properties.gcnArchName,
            "fully_connected": qr.fully_connected,
            "peer_accessible": [
                (i == local_rank or torch.cuda.can_device_access_peer(local_rank, i))
                for i in range(world)
            ],
            "cases": rows,
        }
        gathered = [None] * world
        dist.all_gather_object(gathered, local)
        if rank == 0:
            summary = []
            for index, row in enumerate(rows):
                if not row["eligible"]:
                    summary.append(row)
                    continue
                maxima = [
                    max(r["cases"][index]["samples_us"][sample] for r in gathered)
                    for sample in range(args.samples)
                ]
                median = statistics.median(maxima)
                summary.append(
                    {
                        "shape": row["shape"],
                        "codec": row["codec"],
                        "median_MAX_rank_us": median,
                        "MAX_rank_samples_us": maxima,
                        "minimum_local_input_output_GBps": 2
                        * row["payload_bytes"]
                        / (median * 1000),
                    }
                )
            package_root = Path(vllm.__file__).resolve().parent.parent
            git = subprocess.run(
                ["git", "-C", str(package_root), "rev-parse", "HEAD"],
                capture_output=True,
                text=True,
            )
            native = Path(vllm._C.__file__).resolve()
            with native.open("rb") as stream:
                native_sha = hashlib.file_digest(stream, "sha256").hexdigest()
            report = {
                "completed_utc": datetime.datetime.now(datetime.UTC).isoformat(),
                "torch": torch.__version__,
                "hip": torch.version.hip,
                "vllm": vllm.__version__,
                "commit": git.stdout.strip() if git.returncode == 0 else None,
                "native_extension_sha256": native_sha,
                "benchmark_sha256": hashlib.sha256(
                    Path(__file__).read_bytes()
                ).hexdigest(),
                "world_size": world,
                "gpus": os.environ.get("HIP_VISIBLE_DEVICES"),
                "environment": {
                    k: v
                    for k, v in os.environ.items()
                    if k.startswith("VLLM_ROCM_QUICK_REDUCE_")
                },
                "arguments": {
                    **vars(args),
                    "output": str(args.output) if args.output else None,
                },
                "boundary": "Public native collective only, including codec, peer "
                "traffic, flags and casts. Cold rotating inputs, reused output; "
                "RCCL device barrier immediately before each sample, untimed. "
                "Minimum local bytes counts one input read and one output write; "
                "it is not a network-bandwidth measurement or serving score.",
                "ranks": gathered,
                "summary": summary,
            }
            if args.output:
                with args.output.open("x") as stream:
                    json.dump(report, stream, indent=2)
                    stream.write("\n")
            print(json.dumps(report, indent=2), flush=True)
        dist.barrier()
    finally:
        if qr is not None:
            qr.close()
        if dist.is_initialized():
            dist.destroy_process_group()


if __name__ == "__main__":
    main()

```

## Details

The CP initializer no longer rejects every DBO configuration at startup; the existing runtime guard retains the local fallback for actual microbatches. Seven-draft verification uses two existing four-row score tiles per request. TP4, gfx950, DCP size 1 and explicit `indexer_decode_cp` remain required. CP buffers add about 33 MiB/rank at a 1M context limit. AMD model wrappers expose the existing local-logit hooks for target and DSpark batch-sharded sampling. Eleven host-dispatch lines tune four native MXFP8 projection shapes at 33–64 rows (QKV only 49–64), preserving the representation and arithmetic.

The new transport coalesces peer accesses and parallelizes flag polling while preserving the existing INT4 codec, scales, addition order and BF16 casts. It is gated to gfx950, TP4, INT4 and BF16-to-FP16 casting. Other modes keep the existing transport. It adds 348 kernel lines and raises measured VGPR use from 87 to 128 and private storage from 0 to 72 bytes; the serving benefit is modest despite the larger collective speedup. Existing thresholds and the default codec are unchanged. Enable it with `VLLM_ROCM_QUICK_REDUCE_QUANTIZATION=INT4`; QuickReduce remains disabled by default.

Duplicate-work checks read #63232's discussion and searched open PRs for its number, MiniMax CP/DBO/indexer/sampling, native MXFP8 tuning, and TP4 INT4 QuickReduce. #59478 changes the backend to AITER FlyDSL; this patch retains the native implementation and its checked arithmetic. #61020/#61021 are fused epilogues, #61099 concerns offset width, and #55346 changes saturation behavior. #62509 has a broader native tile table and QKV quantization fusion; this PR retains the four bounded tile choices already measured here. The earlier distinction from #45875 was documented in its discussion before this draft was opened. No second PR for the native transport is being opened.

The additional packed MXFP8 backend, draft-attention follow-up, MoE sorting and fused scale/add experiments are outside this update. Performance results from those variants are not claimed here. Raw all-rank traces, benchmark scripts and request logs are preserved in the investigation artifacts.

AI assistance was used to investigate, implement and validate this change. The submitting human's earlier line-review/test confirmation covers the original 13-file change. Human review and execution of relevant tests for the newly added transport lines remain pending; the PR stays draft and no re-review is requested.
