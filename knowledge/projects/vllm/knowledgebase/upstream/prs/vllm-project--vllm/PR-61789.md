## Original PR description

This PR is split from the original full PR: https://github.com/vllm-project/vllm/pull/58568

Add the runtime-neutral object model, transfer plans, and `IUMBPRuntime` scheduler/worker contracts.
Add the `UMBPStoreConnector` facade and the request lifecycle for lookup, load, store, and block ownership.
Keep UMBP transport out of the scheduler and model runner. This slice registers no MORI backend.

Implementation only. Contract tests are in the next PR:

```bash
.venv/bin/python -m pytest -q tests/v1/kv_connector/unit/test_umbp_core.py
```
