# [XPU][FP8] Use per-token dynamic FP8 activation quantization

[Upstream PR](https://github.com/vllm-project/vllm/pull/61362) · state: open · merged: False

## Original PR description



## Overview



Use per-token dynamic FP8 activation quantization instead of per-tensor quantization.
- for better performance
- for better compatablity with xpu graph (during graph execution, padding can cause per-tensor quantization to capture uninitailized values (nan/inf) via `max` op, causing the acc issues. per-token quantization can avoid this issue.）
