# [Refactor] Unify BlockStored event construction in cache_partial_block

[Upstream PR](https://github.com/vllm-project/vllm/pull/57339) · state: open · merged: False

## Original PR description

Replace the inline BlockStored(...) in cache_partial_block with a call to _build_block_stored_event, consistent with cache_full_blocks and emit_cached_block_events. Update the method's docstring to reflect all three callers.

## Purpose
`cache_partial_block` was constructing `BlockStored` events inline, duplicating the fields already centralized in `_build_block_stored_event` (token_ids slice, lora_id/lora_name, medium, session_id). This is inconsistent with `cache_full_blocks` and `emit_cached_block_events`, which both use that helper.

This PR replaces the inline construction in `cache_partial_block` with a call to `_build_block_stored_event`, and updates the method's docstring to reflect all three callers: the two write paths (`cache_full_blocks`, `cache_partial_block`) and the cache-hit path (`emit_cached_block_events`).
