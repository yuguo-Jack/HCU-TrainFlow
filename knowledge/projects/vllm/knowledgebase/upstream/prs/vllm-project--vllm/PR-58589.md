# [Bugfix][ROCm][GLM-5.2] Stop forcing skip_final_all_reduce on AMD DSA model path

[Upstream PR](https://github.com/vllm-project/vllm/pull/58589) · state: closed · merged: True

## Original PR description

## Purpose

`vllm/models/deepseek_v32/amd/model.py` (DeepSeek-V3.2, GLM-5.2 on ROCm) forces `skip_final_all_reduce = True`. With a reducing combine (MoRI, DeepEP) `MoERunner` asserts:

```
AssertionError: skip_final_all_reduce requires an un-reduced fused output
```

## Changes

The MoE output is summed over TP in the next `fused_allreduce_rms_norm`.

- `skip_final_all_reduce` only for non-reducing combines (no all2all, `allgather_reducescatter`).
- If the combine reduces or the layer is sequence-parallel, the output is complete on every TP rank: zero it on TP rank > 0.
