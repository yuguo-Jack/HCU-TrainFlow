# [Bugfix][KV Connector][ROCm] MoRIIO hybrid READ: skip locally cached prefix pages

[Upstream PR](https://github.com/vllm-project/vllm/pull/62190) · state: open · merged: False

## Original PR description

## Overview

Draft, written with Claude Code; stays draft until the submitter reviews every line. MoRIIO hybrid (KDA/Mamba) READ re-reads attention pages the decoder already caches; this reads only external-token pages.

Not duplicates: #48471 (non-hybrid length mismatch), #62165 (SWA tail clipping). Rebased on #60867.

## Claims

- With a decoder prefix-cache hit, hybrid READ moves only the full-attention pages for tokens `[N-1-E, N-1)` (`N` prompt length, `E` final `num_external_tokens`). KDA/Mamba and state attention groups are unchanged.
- Full-attention tables that do not cover that range raise `MoRIIOError` instead of being tail-aligned.
- No throughput claim: the tested workload is prefill-queue bound.

- 3600 s agentic replay, concurrency 48: 4273 succeeded, 9 empty-content errors (unpatched: 9).
- No accuracy eval: skipped pages are the decoder's own cached pages.

## Details

Root cause on the decoder:

1. The local prefix hit covers `[0, L)`, so `E = N - 1 - L`.
2. `update_state_after_alloc` gets complete attention tables, cached pages included.
3. `_align_read_blocks` paired P and D tables by length and tail, so READ also covered `[0, L)`.
4. Fix: per full-attention group, slice both by page `[(N-1-E) // B, ceil((N-1) / B))`, `B` = its block size x DCP when sharded; window-clipped and state groups keep `_align_read_blocks`.

```diff
 for local, remote, read_block_size in zip(..., self._attn_read_block_sizes):
-    self._align_read_blocks(local, remote, self._max_decode_tail_blocks)
+    if read_block_size is None:  # window-clipped or state group
+        self._align_read_blocks(local, remote, self._max_decode_tail_blocks)
+    else:
+        self._select_read_attention(request, E, local, remote, read_block_size)
```

- Contract change: a shorter decoder table (the removed test's receive suffix) now raises; a real `KVCacheManager` case and the GPU run pass complete tables.
