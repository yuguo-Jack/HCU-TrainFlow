# [CI][ROCm] Run ROCm-capable tests that are currently skipped on AMD

[Upstream PR](https://github.com/vllm-project/vllm/pull/62298) · state: open · merged: False

## Original PR description

Removes or narrows ROCm skips on 112 test sites that pass on MI355, and wires the tests whose files no AMD step ran into the AMD CI steps. This is one draft that I will split into smaller PRs by area (engine/V1, kernels, models, CI config).

- Engine / V1: widen `is_cuda()` gates to `is_cuda_alike()` and drop stale ROCm skips in the worker, sampler, KV connector/offload, EC connector, DP and spec-decode tests (51 sites, 42 files).
- Kernels: unskip attention, MoE, top-k, mamba, mHC, compressor-KV and quant kernel tests; make the fnuz-gated fp8 references use `current_platform.fp8_dtype()` (39 sites, 28 files including `quant_utils.py`).
- Models and quantization: unskip the inkling, QSA reference, mistral3 patch-embed, mimo-v2 sinks and model-init tests, plus `test_compressed_tensors.py`, `test_auto_round.py` and `test_fp8.py` params (22 sites, 13 files).
- Where only some params fail on ROCm, the skip is narrowed to those params with a true reason instead of removed (4 partial sites).
- CI config: add the tests that no AMD step ran to the matching steps in `test-amd.yaml` and their `test_areas/` mirrors, and move `test_gdn_aiter_flydsl.py` and `test_mla_backends.py` to the `VLLM_ROCM_USE_AITER=1` command.
- No `vllm/` source changes. Tests that need a source fix stay skipped, and the fixes are listed below.
