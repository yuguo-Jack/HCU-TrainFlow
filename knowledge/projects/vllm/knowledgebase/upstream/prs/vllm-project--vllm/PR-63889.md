# [Perf][KV Offload] Reduce KVCR adapter overhead

[Upstream PR](https://github.com/vllm-project/vllm/pull/63889) · state: closed · merged: True

## Original PR description



## Overview

Reduce Python overhead in KVCR pin acquisition, transfer descriptor construction, and completion handling. Builds on #60469.

## Claims

- Avoid redundant key-set checks and key conversions during pin acquisition.
- Convert NumPy chunk IDs to Python integers in bulk and cache the NIXL agent name used by descriptors.
- Skip unused successful-key accumulation on fully successful completion while preserving partial-failure reporting.

## Validation

Extended tests added in `tests/v1/kv_offload/tiering/test_kvcr_tier.py` cover reordered and invalid pin jobs, Python-integer descriptors, and successful and partially failed transfers.

AI-assisted implementation.
