# [Doc] MiniMax-M3.1-Flash: update the GB200 AgentX presets

[Upstream PR](https://github.com/vllm-project/vllm/pull/64909) · state: closed · merged: True

## Original PR description

## Overview

Update the GB200 AgentX presets of MiniMax-M3.1-Flash (`gb200_agentx_agg`, `gb200_agentx_pd`) to the Dynamo + vLLM lanes of [SemiAnalysisAI/InferenceX#4632](https://github.com/SemiAnalysisAI/InferenceX/pull/4632) (head `93621314`). Only touches `recipes/models/MiniMaxAI/MiniMax-M3.1-Flash.yaml`.

- **Frontend:** `DYN_TOKENIZER=fastokens` (Dynamo's fastokens tokenizer backend). Frontend tokenization of 100K+ token prompts drops from about 150 ms to about 1 ms per request, which comes straight off TTFT.
- **Mooncake pool:** 150 GB to 190 GB per rank. Run etcd, NATS, the Mooncake master and the frontend on a host without engine workers, so the trays' host DRAM goes to the pool.
- **Prefill:** `--gpu-memory-utilization` 0.88 to 0.92. **Decode:** drop `VLLM_MAX_ASYNC_KV_ADMITS_PER_STEP`, which had no measurable effect.
- **Measured points:** adds 2 prefill + DEP8 (224, 256 sessions), 3 prefill + DEP8 at 288, and 3 prefill + DEP16 at 320 and 360. The table, tuning rules and source revision are updated.

## Validation

- Measured in the lane's sweep ([run 41084082993](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/41084082993)): 2 prefill + DEP8 at 224/256 sessions: 94.2k/98.8k tok/s/GPU at 250/244 tok/s/user; 3 prefill + DEP8 at 288: 93.2k at 230; 3 prefill + DEP16 at 280/320/360: 70.4k/77.3k/85.4k at 302/291/284; 4 prefill + DEP16 at 352: 74.5k at 284. TTFT p90 is 1.8-5.3 s across the points.
