# [Docs] Diff against the merge base in the docs build gate

[Upstream PR](https://github.com/vllm-project/vllm/pull/64554) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Make the Read the Docs gate in `docs/pre_run_check.sh` only count docs-affecting files changed by the PR itself.

## Claims

- PRs that touch no docs-affecting files no longer build docs just because `main` gained docs changes since the PR last merged it.

## Validation

[Build 35503122](https://app.readthedocs.org/projects/vllm/builds/35503122/) for #64357 (no docs changes) continued the build because #64362 and #38741 touched `examples/` and `docs/` on `main` after the PR's last merge of `main`. Locally, against that commit:

| Check | Exit code | Result |
| --- | --- | --- |
| `git diff --quiet origin/main 537df9bd -- <paths>` (before) | 1 | build continues |
| `git diff --quiet origin/main...537df9bd -- <paths>` (after) | 0 | build cancelled |

## Details

The merge base is reachable on RTD because `post_checkout` already runs `git fetch origin main --unshallow`. If it ever isn't, `git diff` errors and the gate falls through to building, as before.
