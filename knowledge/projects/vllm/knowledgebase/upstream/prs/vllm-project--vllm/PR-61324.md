# [BugFix][Quantization] Surface FP8 kernel rejection reasons for fp8_per_channel

[Upstream PR](https://github.com/vllm-project/vllm/pull/61324) · state: open · merged: False

## Original PR description

## Overview

Make `quantization="fp8_per_channel"` fail with the scaled-mm chooser's per-kernel rejection reasons instead of a post-allocation Marlin-only guard. Fixes #61316.

## Claims

- `MarlinFP8ScaledMMLinearKernel.can_implement` rejects per-token activation FP8 (W8A16 weight-only) with an explicit reason.
- Marlin still accepts per-tensor activation configs used by the W8A16 / online per-tensor fallback path.
- When no earlier FP8 kernel can implement a PTPC config, `choose_scaled_mm_linear_kernel` raises with the full `Reasons:` list, including Marlin's rejection (no silent Marlin selection).
- `Fp8PtpcOnlineLinearMethod.create_weights` selects the kernel before allocating weights and prefixes chooser failures with `quantization="fp8_per_channel"`.

## Details

**Root cause:** Marlin's `can_implement` returned `(True, None)` for every config. For PTPC (`kFp8DynamicTokenSym` + `kFp8StaticChannelSym`), earlier kernels may be rejected (no Cutlass FP8, no torch FP8 scaled_mm, etc.), Marlin is selected, and the collected `failure_reason_list` is discarded. A later isinstance guard in `Fp8PtpcOnlineLinearMethod.create_weights` then raised a generic "Requires SM89+ / ROCm MI3xx" message after `super().create_weights()`.

**Approach:** Reject per-token activation in Marlin so the chooser either falls through to a real W8A8 kernel (e.g. ChannelWiseTorch when available) or raises with all rejection reasons. Move PTPC kernel selection before weight allocation and wrap chooser `ValueError`s with an `fp8_per_channel` prefix while preserving the Reasons list.

**Tradeoff:** Devices that previously selected Marlin for PTPC and then crashed will now either succeed via an earlier capable kernel or fail earlier with actionable Reasons. Per-tensor / W8A16 Marlin paths are unchanged.

**Not duplicating:** Searched open PRs for `#61316`, `fp8 rejection reasons`, and `failure_reason_list`. Related open work (#57600) gates Marlin on weight group shapes only; it does not reject per-token activation or fix the PTPC error path.
