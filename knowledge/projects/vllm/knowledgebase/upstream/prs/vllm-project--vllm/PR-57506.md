# [Bugfix][KV Offload] Isolate handler tensor references

[Upstream PR](https://github.com/vllm-project/vllm/pull/57506) · state: open · merged: False

## Original PR description

## Summary

Fix shared handler reference ownership in CPU KV offload.

Before this change, the store and load handlers received the same mutable
`cpu_tensors` list. When one handler cleared its tensor references during
shutdown, it also cleared the other handler's list. Each handler now owns its
own reference container; the tensor objects and backing storage are not copied.

## Changes

- Give each `SingleDirectionOffloadingHandler` its own tensor-reference lists.
- Preserve the existing shutdown and shared-region cleanup behavior.

## Tests

No model evaluation is required because this change does not affect model
