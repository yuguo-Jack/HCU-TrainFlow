# [Docs] Document hybrid NIXL startup requirements

[Upstream PR](https://github.com/vllm-project/vllm/pull/65472) · state: open · merged: False

## Original PR description

## Overview

Document the startup requirements for hybrid SSM/Mamba disaggregated serving:
NIXL's DS convolution-state layout and the connector's HMA capability.
Closes #54387.

## Claims

- The NIXL usage guide shows `export VLLM_SSM_CONV_STATE_LAYOUT=DS` and makes
  clear that both prefill and decode instances need the setting.
- The general guide explains `SupportsHMA`, the requirement for every
  `MultiConnector` child, and the default behavior for unsupported connectors.
- The compatibility matrix links directly to the setup instructions.

## Validation

Checked each statement against the current layout selector, NIXL worker
assertion, HMA configuration policy, connector factory, and connector classes.
An independent review also checked the source claims and documentation links.

```bash
VLLM_TARGET_DEVICE=cpu VLLM_PLUGINS='' API_AUTONAV_EXCLUDE='re:^vllm\.(?!distributed(?:\.|$)).*' .venv/bin/python -m mkdocs build
```

Applicable pre-commit hooks and the MkDocs build pass. API generation was
limited to the distributed modules; unrelated omitted-reference warnings
remain, with no warnings for the three edited pages. The rendered sections
were inspected and all 11 checked section/API links resolve.
This changes documentation only; no runtime behavior, model output, or
performance change is claimed, so GPU tests and model evaluations do not apply.

## Details

The existing compatibility matrix reports hybrid support, but the usage guide
does not expose the layout required by the NIXL worker's startup assertion.
Add the setting to the prerequisites and cross-link it from the overview and
matrix so it can be found before launching the servers.

This follows up on closed, unmerged #54489. It incorporates the review's request
for exported shell syntax and a capability rule with examples rather than an
exhaustive connector list that can go stale. The issue timeline and open-PR
searches found no active replacement. Developed with AI assistance.
