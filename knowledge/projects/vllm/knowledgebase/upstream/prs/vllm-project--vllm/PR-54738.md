## Original PR description

## Purpose

`docs/design/hybrid_kv_cache_manager.md` still described the manager as it was in v0.10.1; current is v0.28.0. Two claims from that version no longer match current code, and some newer manager classes went undocumented.

## Changes

- `HybridKVCacheCoordinator` is no longer limited to two KV cache groups — documented the general fixed-point cache-hit search.
- Mamba prefix caching is implemented, not "work in progress".
- Listed the newer `SingleTypeKVCacheManager` subclasses (RSWA, circular-buffer, chunked-local, cross-attention, attention-sink).

## Test plan

Docs-only change. Verified each claim against current source (`vllm/v1/core/kv_cache_coordinator.py`, `vllm/v1/core/single_type_kv_cache_manager.py`). `pre-commit` docs lint passed locally.
