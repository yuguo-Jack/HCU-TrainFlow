# [Frontend] Reject API keys for the Python gRPC server

[Upstream PR](https://github.com/vllm-project/vllm/pull/64988) · state: closed · merged: False

## Original PR description

## Overview

Make every Python gRPC launch path fail during startup when `--api-key`, a config-file API key, or `VLLM_API_KEY` is configured, instead of silently ignoring a setting the server cannot enforce.

## Claims

- Reject `--api-key` and API keys loaded from `--config` for `vllm serve --grpc`.
- Reject the equivalent `VLLM_API_KEY` environment variable for `vllm serve --grpc`.
- Apply the same check at the `serve_grpc()` boundary so the standalone `python -m vllm.entrypoints.launchers.grpc_server` entry point is covered.
- Keep the Rust frontend's `--grpc-port` path unchanged.
- Avoid treating `vllm launch render --grpc --api-key ...` as the Python gRPC server; that command still starts the HTTP renderer, where API keys work.
- Document the incompatibility in the CLI help/API-key reference and the gRPC section of the security guide.

## Details

The Python gRPC launcher has no authentication interceptor and never reads `args.api_key`. The shared serve parser nevertheless accepts `--api-key`, so the process starts successfully while the requested authentication is not applied.

This change handles both ways an API key can be configured: `args.api_key` from the CLI/config and `envs.VLLM_API_KEY` from the environment. Validation runs in `ServeSubcommand.validate()` for early feedback and again at the start of `serve_grpc()` so direct launcher invocations are covered before engine initialization.

The auth check is no longer part of the shared serve-argument validator because `vllm launch render` reuses that parser but starts an HTTP server. It remains valid there to provide `--grpc` with `--api-key`.

Duplicate-work check: no open PR was found for this fail-fast behavior. #49020 and #56046 are open docs-only fixes for the incorrect `--grpc-port` documentation, and #42721 (an incomplete API-key support PR) was closed for inactivity.
