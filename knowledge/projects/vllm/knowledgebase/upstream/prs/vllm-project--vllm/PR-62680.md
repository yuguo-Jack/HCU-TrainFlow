# [CI][AMD] Deselect distributed tests in the MI300 Model Executor step

[Upstream PR](https://github.com/vllm-project/vllm/pull/62680) · state: closed · merged: True

## Original PR description

## The failure

`(MI300) Model Executor` in [AMD CI nightly 15028](https://buildkite.com/vllm/amd-ci/builds/15028), the only failure among 1282 passing tests:

```
FAILED model_executor/model_loader/test_weight_cache.py::test_ipc_cache_cold_start_and_warm_restart_tp2_ep - RuntimeError: Engine core initialization failed.
```

The root cause is in the second worker:

```
AssertionError: DP adjusted local rank 1 is out of bounds for 1 devices.
```

## The cause

[#55490](https://github.com/vllm-project/vllm/pull/55490) added `test_ipc_cache_cold_start_and_warm_restart_tp2_ep` with `@pytest.mark.distributed(num_gpus=2)` and, in the same commit, added `and (not distributed)` to the pytest command in `.buildkite/test_areas/model_executor.yaml`, for the H200 step and its AMD mirror alike. `.buildkite/test-amd.yaml` kept `-m '(not slow_test)'`, and that step runs on `agent_pool: mi300_1`, so a tp=2 test is collected on a single GPU and the second worker has no device to bind.

## The change

The same filter as the upstream step. Collection over `model_executor` goes from 1342 selected and 33 deselected to 1341 and 34; the tp=2 test is the only one removed.

## Tests

The test itself is healthy: with two GPUs visible it passes on MI300 (gfx942, ROCm 10.0), 1 passed in 267.66s. With one GPU visible it reproduces the CI assertion verbatim, and with this change it is deselected instead of collected.
