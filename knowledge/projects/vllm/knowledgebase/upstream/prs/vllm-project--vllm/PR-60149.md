## Overview

NVIDIA-Nemotron-Labs-Dory1.0-4B-BF16 is a latent-recurrent / looped large language Model (LLM) trained by NVIDIA. This is the full-precision (BF16) release of Dory1.0-4B. The model employs normalized-GPT architecture with interleaved hybrid sliding window attention (SWA) and full attention layers. By repeatedly applying a shared block of layers, Dory1.0-4B can trade inference compute for accuracy by changing the loop count.

- shan18 · comment · 2026-10-10T16:36:39Z · [source](https://github.com/vllm-project/vllm/pull/60149#issuecomment-6099769162)

Yes, we looked into the Transformers backend. Dory isn’t directly compatible with its current implementation.

Dory is a looped transformer that shares layer weights across loops but keeps a separate KV cache per loop by default.
* The backend creates one attention instance per layer_idx and rejects duplicates, so per-loop caches would need backend support for virtual attention layers. 
* The backend expects every layer to dispatch attention, but half of Dory's layers are MLP-only.
* Dory also has learned per-vocabulary logit scaling that the backend's generic LM head does not handle.

The native implementation keeps all of this self-contained, without changing engine code.
