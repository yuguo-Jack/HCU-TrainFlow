# [Bugfix][CPU] Reject unavailable WNA16 operator

[Upstream PR](https://github.com/vllm-project/vllm/pull/55824) · state: open · merged: False

## Original PR description

## Summary

Fixes #55613.

On CPU builds where the compiled `torch.ops._C.cpu_gemm_wna16` operator is not registered, reject `CPUWNA16LinearKernel` during kernel selection with a clear reason instead of allowing execution to fail later with an opaque `AttributeError`. This covers the current AVX2-only behavior; it does not claim to add a portable AVX2 WNA16 implementation.

## Changes

- Check the registered PyTorch custom op before accepting the CPU WNA16 kernel.
- Add CPU-only unit coverage for both registered and missing operator states.

## Duplicate check

Checked issue #55613 and searched open vLLM PRs for `55613`; no open PR was found for this issue. The change is limited to the first requested item in the issue.

Tested this on an AVX2-only CPU (Intel i5-12400, WSL2 Ubuntu 24.04, CPU nightly wheel `0.32.1rc1.dev36+ge68efc685`), in case it helps.

In that wheel `cpu_gemm_wna16` is not registered. I applied this PR's `cpu.py` diff to the installed wheel (it applied cleanly) and loaded `Qwen/Qwen2.5-0.5B-Instruct-AWQ` with `quantization="awq", enforce_eager=True`:

- **Before:** `AttributeError: '_OpNamespace' '_C' object has no attribute 'cpu_gemm_wna16'` during the first forward pass.
- **After:** a `ValueError` at kernel selection, including `CPUWNA16LinearKernel cannot implement due to: torch.ops._C.cpu_gemm_wna16 is not registered; CPU WNA16 requires a build with WNA16 CPU support`.

One thing I noticed: the new test file raised `TypeError: ... unexpected keyword argument 'has_g_idx'` for me, since `MPLinearLayerConfig` no longer has that field on current `main`. When I removed that one line locally, the two tests passed with the change and failed without it. It may just need a rebase.

A few limits: I patched the wheel rather than building this branch, the unit tests monkeypatch the helper, and I only tried this one AWQ model on this one CPU.

I used an AI assistant (Claude) to help run and summarize these checks; I ran them on my machine.
