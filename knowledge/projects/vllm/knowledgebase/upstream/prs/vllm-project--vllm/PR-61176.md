# [ROCm][DSv4] Enable EPLB on AITER MegaMoE

[Upstream PR](https://github.com/vllm-project/vllm/pull/61176) · state: open · merged: False

## Original PR description

## Summary
- AITER MegaMoE no longer rejects `--enable-eplb`.
- Physical expert slots follow the DeepGEMM placement: routed experts, then redundant copies. `(n_routed + num_redundant_experts)` must divide the EP size.
- Logical top-k ids are mapped to physical ids before MegaMoEV2, and EPLB swaps the shuffled MXFP4 rows in place.

Bench 8k/1k at concurrency 512. The load log should move from about 0.71 to about 0.97 after the first rebalance. Do not compare absolute tok/s with SGLang.

| EPLB on, no rearrange | 0.965 |
| EPLB on, 11 rearranges | 0.9475 |
