# [Bugfix][Kimi-Linear] Honor --mamba-ssm-cache-dtype for the KDA recurrent state

[Upstream PR](https://github.com/vllm-project/vllm/pull/61245) · state: open · merged: False

## Original PR description



## Overview

Kimi-Linear fails at startup with `--mamba-ssm-cache-dtype bfloat16`. Same bug as #59147 (GLM-5.3-Flash), in the KDA layer Kimi-Linear uses (`KimiGatedDeltaNetAttention`).

## Claims

- Kimi-Linear starts and serves with `--mamba-ssm-cache-dtype bfloat16`. On main it hits `assert self.page_size_padded >= page_size` during engine init.
- Default (`auto`, float32 state) is unchanged.
- With the bf16 state, GSM8K is within 2 questions of the float32 state, and the KV cache holds 47% more tokens on 1xH200.

## Details

`KimiLinearForCausalLM.get_mamba_state_dtype_from_config` passes `mamba_ssm_cache_dtype`, but `KimiGatedDeltaNetAttention.get_state_dtype` did not. The hybrid block-size alignment uses the model-level dtype (bf16), so `mamba_page_size_padded` is sized for a bf16 state, while the layer's `MambaSpec` is built with a float32 state that is about twice as large.

Passing the dtype exposed a second issue: `chunk_kda_with_fused_gate` returns a float32 final state, and the prefill write-back `recurrent_state[idx] = last_recurrent_state` fails with `Index put requires the source and destination dtypes match`. This PR casts it to the cache dtype, the same as the Kimi-K3 KDA layer does after the same kernel. The decode kernels already cast on store.

Kimi-K3 is not affected: its KDA layer (`KimiK3DeltaAttention`) already passes the dtype.

ROCm: this layer is shared, but `amd/linear.py` still drops the flag at the model level. #58743 changes that line, so this PR leaves it alone. Until then, on ROCm with this flag the layer uses a bf16 state padded to the float32 page size, so it does not hit the assert. Not tested on ROCm.

Not a duplicate: searched open and closed PRs and issues for Kimi-Linear / `mamba_ssm_cache_dtype` / KDA state dtype. #59147 fixed only GLM-5.3-Flash, and #58743 covers only the ROCm Kimi-K3 path.
