# [Feature][Frontend] Control the log level of request JSON body using env var

[Upstream PR](https://github.com/vllm-project/vllm/pull/60630) · state: closed · merged: True

## Original PR description


## Overview

This PR adds an option to change the log level used for logging the request body JSON. 
This PR is related to the previously merged PR: https://github.com/vllm-project/vllm/pull/58163

## Claims

* Default behavior is not changed: default log level for the request body JSON is DEBUG when `--enable-log-requests` is set.
* Setting `VLLM_REQUEST_BODY_LOG_LEVEL=INFO` with `--enable-log-requests` makes all requests' JSON body will be logged in INFO log level.
* Setting `VLLM_REQUEST_BODY_LOG_LEVEL=NONEXIST` will show a warning to the user that this log level does not exist, and request body logging will be skipped.

## Details

**Motivation:** Previously, logging just the request JSON body would require turning on the DEBUG log, which can be very heavy. In some cases, like running agentic benchmarks, we want to gather the requests for an option to replay these requests.

**Design decisions:**
The user can choose the log level for the request JSON body logging using an environment variable, while maintaining backward compatibility with the DEBUG log that was the behavior before.
