# Add `sm_107` for Rubin

[Upstream PR](https://github.com/vllm-project/vllm/pull/49387) · state: closed · merged: True

## Original PR description

## Summary

- enable CUDA 13.4's native SM107 target for Vera Rubin
- allow SM107 to reuse compatible SM100-family kernels across the CUDA, DeepGEMM, FlashMLA, and QuTLASS builds
- resolve exact architecture matches before family fallbacks, preventing `10.0f` from masking `10.7f`

This follows [PyTorch #190654](https://github.com/pytorch/pytorch/pull/190654). I also checked its review feedback and mirrored the corrected boundaries here: CUDA 13.4 is included with `VERSION_GREATER_EQUAL`, and SM107 handling does not overwrite other architecture selections.

For interim validation, PyTorch CI produced `torch-2.14.0a0+git90e4943` from the PR head, and that branch pins Triton commit `4774139fe59ed0a3adbdd8590a41f5295ad7d5eb`, available from the official PyTorch nightly index as `triton==3.8.0+git4774139f`. This PR does not permanently pin the CI wheel because the artifact is expiring and CPython 3.10-only; using the PyTorch Git branch directly would require building PyTorch from source.
