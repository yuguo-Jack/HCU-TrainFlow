# [CI] Bump pre-commit hooks (except ruff)

[Upstream PR](https://github.com/vllm-project/vllm/pull/64349) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Bumps the pre-commit hooks to their latest releases, except ruff, and pins every hook by commit SHA with a version comment. Supersedes #42618.

## Claims

- Hook bumps: typos v1.43.5 → v1.51.1, clang-format v21.1.2 → v23.1.3, markdownlint-cli2 v0.21.0 → v0.24.0, actionlint v1.7.7 → v1.7.12, shellcheck-py v0.11.0.1 → v0.11.0.1-1, uv-pre-commit 0.11.1 → 0.13.6.
- typos v1.51.1 finds 2 real typos, which are fixed (`elpased`, `natually`). It also flags 3 names that must stay as they are, which are ignored: `stride_bse`, numpy's `flags.writeable` and CLIP's `pre_layrnorm` weight name. These are the same fixes as #42618, which targeted v1.46.1 and went stale.
- clang-format v23 changes 3 C++/CUDA files, whitespace only (`T & dst` → `T& dst`, `FP16Vec8 ::` → `FP16Vec8::`).
- Every `rev` is now frozen to a SHA in pre-commit's own `# frozen: <tag>` format, so `pre-commit autoupdate --freeze` only touches hooks with a new release. The bump command is documented in `.pre-commit-config.yaml` and in the Linting section of the contributing guide.
- Not included: ruff v0.17 goes in its own PR, because it turns on ISC004 (177 sites) and formats Markdown code blocks by default, which breaks mkdocs `--8<--` snippets.

## Validation

- `pre-commit run --all-files --hook-stage manual` passes locally on every changed hook. The mypy and `test-nonroot-entrypoint` hooks fail locally for macOS-only reasons, but both are unchanged by this PR.
