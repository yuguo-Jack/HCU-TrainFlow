# [feat] Introduce platform-owned RoPE implementations

[Upstream PR](https://github.com/vllm-project/vllm/pull/58988) · state: open · merged: False

## Original PR description

Separate PyTorch RoPE specs from per-device overrides and select the platform or baseline spec during initialization. Call spec.rope directly from the layer while keeping model configuration and frequency generation in model logic.

Preserve custom-op configuration, FoPE semantics, cache dtype handling, and AITER refresh behavior. Document spec inheritance and wire compact regression coverage into XPU CI.
