# Graceful KVCR guard shutdown

[Upstream PR](https://github.com/vllm-project/vllm/pull/63865) · state: open · merged: False

## Original PR description

## Summary

Stop KVCR’s idle peer polling when engine shutdown begins, while keeping active transfer jobs visible until they finish.

## Changes

- Signal shutdown from EngineCoreProc to the KVCR adapter.
- Make has_pending_work() report only active transfer jobs after that signal.
- Add tests for Guard-backed and in-process KVCR tiers.
