# [Model] Add Nemotron 3.5 ASR transcription support

[Upstream PR](https://github.com/vllm-project/vllm/pull/59827) · state: closed · merged: True

## Original PR description



## Overview


Adds complete-audio transcription support for `nvidia/nemotron-3.5-asr-streaming-0.6b`.

Related to #47455. Native cache-aware realtime streaming is intentionally out of scope for this PR; the required persistent streaming-state and lifecycle support is being explored separately in the vLLM-Omni RFC: https://github.com/vllm-project/vllm-omni/issues/5212.

## Claims



- Supports transcription through `/v1/audio/transcriptions`.
- Reuses Transformers encoder, RNN-T predictor, and joint-network components with model-local vLLM processing and execution adapters.
- Supports batched greedy RNN-T decoding with isolated per-request state.
- Does not modify dependency versions or generic serving/scheduler logic.

## Validation



Local environment: RTX 4060 Laptop GPU, Python 3.12.3, PyTorch 2.11.0+cu130, Transformers 5.16.1.

**Commands run**:

```bash
python -m pytest \
  tests/models/multimodal/processing/test_nemotron3_5_asr.py \
  tests/models/multimodal/test_nemotron3_5_asr.py \
  tests/entrypoints/speech_to_text/transcription/test_nemotron3_5_asr.py -q

python -m pre_commit run --from-ref upstream/main --to-ref HEAD
```

**Results**:

- 31 focused tests passed.
- All applicable pre-commit hooks passed.
- Real-checkpoint transcription completed for 26.3-second, 30-second, and five-minute WAV inputs.
- The 26.3-second transcript matched Transformers exactly.
- The 30-second and five-minute inputs completed successfully but produced empty transcripts, so these were treated as execution smoke tests rather than accuracy checks.

## Details



The implementation targets Model Runner V2 with eager execution and currently supports TP=1 / PP=1. It performs greedy RNN-T decoding with isolated per-request acoustic and predictor state.

Because RNN-T token selection happens inside the model-specific decoding loop, the adapter exposes synthetic selected-token logprobs to vLLM’s sampler. These values preserve the selected token but must not be interpreted as model confidence. Unsupported execution and sampling features are documented in the model notes.

Native cache-aware realtime streaming is outside the scope of this PR and is being explored separately in the linked vLLM-Omni RFC.

AI assistance was used during implementation and review. The resulting code and changes were manually reviewed, tested, and validated locally before submission.
