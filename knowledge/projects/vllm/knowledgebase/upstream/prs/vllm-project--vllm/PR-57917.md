# [Spec Decode] Enable GLM-5.2 DSpark under pipeline parallelism

[Upstream PR](https://github.com/vllm-project/vllm/pull/57917) · state: open · merged: False

## Original PR description

## Summary

Enable GLM-5.2 (`DeepseekV32ForCausalLM`) to support DSpark speculative
decoding under pipeline parallelism by extending the community #50514
`relay_aux_hidden_states` mechanism to the DeepSeek-V3.2 backbone.

## Motivation

#50514 introduced `supports_aux_hidden_states_over_pp` and the
`relay_aux_hidden_states` / `pack_local_aux_hidden_states` /
`collect_remote_aux_hidden_states` family to carry DSpark/EAGLE-3 aux
hidden states across PP stages. This covers DeepSeek-V4, Kimi-K3, Llama,
and Qwen2.

GLM-5.2 reuses the DeepSeek-V3.2 (`deepseek_v32`) backbone but does not
set `supports_aux_hidden_states_over_pp`, so DSpark under PP cannot relay
aux hidden states across stages — `collect_remote_aux_hidden_states`
returns `[]` and the draft never sees upstream aux. This PR fills that
gap.

## Modifications

All changes are in `vllm/models/deepseek_v32/nvidia/model.py` (+16, -5):

1. **Inherit `EagleModelMixin`**: `DeepseekV32Model` now inherits
   `EagleModelMixin` and sets `supports_aux_hidden_states_over_pp = True`,
   enabling the #50514 relay path for GLM-5.2.

2. **Fix `set_aux_hidden_state_layers` bypass**: The parent
   `DeepseekV2ForCausalLM.set_aux_hidden_state_layers` directly assigns
   `self.model.aux_hidden_state_layers = layers`, bypassing
   `EagleModelMixin._set_aux_hidden_state_layers` and leaving
   `_aux_slot_base_cached` at 0. This breaks
   `collect_remote_aux_hidden_states`. Override to call
   `self.model._set_aux_hidden_state_layers(layers)`.

3. **Switch to capture-after**: Change `if idx in aux` to
   `if idx + 1 in aux` (and move the capture after the layer call). This
   aligns with the `bisect_right` base-offset used by `pack_local` /
   `collect_remote`. Without this, an aux layer at a PP stage boundary
   (e.g. aux 39 at stage start 39) is mis-assigned and the relay index
   collides.

4. **Integrate relay in forward**: Add `collect_remote_aux_hidden_states`
   at the top, `pack_local_aux_hidden_states` in the non-last-rank
   return, and merge `remote_aux + aux_hidden_states` on the last rank.

## Verification

Aux layer assignment with `aux = [2, 20, 39, 58, 75]`, `pp = 4`,
`partitions = [19, 20, 20, 19]`:

| Stage | start | base | local aux | pack indices |
|-------|-------|------|-----------|--------------|
| 0 | 0 | 0 | [2] | [0] |
| 1 | 19 | 1 | [20, 39] | [1, 2] |
| 2 | 39 | 3 | [58] | [3] |
| 3 | 59 | 4 | [75] | [4] |

Last rank collects `aux_states_0..3` and adds local `aux_states_4`,
yielding `[2, 20, 39, 58, 75]` — matching the draft config's
`aux_hidden_state_layer_ids`.
