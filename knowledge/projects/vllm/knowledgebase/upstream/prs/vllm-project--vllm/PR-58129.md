# docs: clarify NIXL KV connector metrics aggregation semantics

[Upstream PR](https://github.com/vllm-project/vllm/pull/58129) · state: open · merged: False

## Original PR description




## Purpose
Fixes #41230.

The NIXL KV connector logs transfer metrics (like Num successful transfers and Throughput) without documenting that these values are aggregated across all tensor-parallel ranks. This has confused users who expect per-rank or system-wide totals.

This PR adds documentation to clarify the existing behavior:

Added a class docstring to NixlKVConnectorStats explaining that metrics are aggregated across all TP ranks before summary statistics are computed.

Added an inline comment in reduce() clarifying that throughput is an average per-rank throughput, not aggregate system throughput.

Added a class docstring to NixlPromMetrics documenting the observe -> aggregate -> reduce -> log pipeline and the fact that stats arrive pre-aggregated.

No logic changes. Documentation only.

## Test Plan
No additional tests are required for this change since it is documentation only. The docstrings and comments were reviewed manually to ensure they accurately reflect the existing behavior in stats.py.
