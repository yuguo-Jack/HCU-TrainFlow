# feat(moriio): add handshake receive timeout with retry and backoff (Gap 3)

[Upstream PR](https://github.com/vllm-project/vllm/pull/63856) · state: open · merged: False

## Original PR description

## Summary

- Set `zmq.RCVTIMEO`/`zmq.SNDTIMEO` (5s) on the DEALER socket in `_moriio_handshake` so `recv_multipart()` no longer blocks forever
- On timeout (`zmq.Again`), retry the full handshake with exponential backoff (1s, 2s, 4s, 8s, 16s)
- After 5 retries, raise `HandshakeError` with diagnostics
- Listener side is already idempotent — no changes needed

Related: ROCm/mori#759

## Test plan

- [ ] Existing `test_moriio_connector.py` still passes
- [ ] Dead peer triggers timeout + retry log messages instead of hanging forever
- [ ] Healthy handshake completes on first attempt with no behavior change
