# [KV Offload] Preserve packed layouts for layer-wise KV cache

[Upstream PR](https://github.com/vllm-project/vllm/pull/59265) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Let built-in CPU KV offloading retain the allocator's compatible packed layout
for layer-wise recipes. Fourth follow-up: #56155 -> #56156 -> #56116 -> this PR.
Related RFC: #57445.

## Claims

- Avoid forcing the default `LBHNC` connector layout for layer-wise recipes,
  allowing compatible packed attention/state-cache allocation.
- Reuse existing packed-row transfers for quantized payloads, scales, and
  recurrent-state bytes without conversion or new transfer kernels.
- Keep existing homogeneous and HiSparse layout behavior unchanged.

## Validation

- Scoped pre-commit checks pass, including mypy (Python 3.11), Ruff, formatting,
  test tethering and Markdown checks:
  `pre-commit run --hook-stage manual --files <incremental changed files>`.
- CPU source isolation passes eight prerequisite test-body cases, 36 resolver
  combinations, four constructor-hook cases with unrelated runtime isolated,
  17 platform/offload-layout cases, eight ModelOpt factory cases and five
  real-config normalization cases. These are not full-vLLM pytest.
- Earlier Nano TP4 serving tests exercised CPU offload/reload and recomputation
  with CUDA graphs and exact in-process output matching. This is historical
  evidence, not a fresh GPU result or a cross-process determinism claim.
  Fresh GPU/offload-runtime validation and PR1's new GPU constructor tests
  remain pending.

## Details

The implementation adds five production lines. It preserves the fixed recipe
and topology and transfers the complete backing row, including unused space.
It does not introduce compact CPU slots or certify NIXL P/D, LMCache, secondary
tiers, or cross-topology cache transfer. Related #53544, #56953, #57216, and
#57824 do not duplicate this layout integration.

Restacked onto #56155's test-only alignment; the offloading patch is unchanged.
