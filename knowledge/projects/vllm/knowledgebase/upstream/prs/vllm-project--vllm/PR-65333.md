# [XPU][UT]Pin platform in GDN AITER FlyDSL resolver tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/65333) · state: closed · merged: False

## Original PR description



## Overview

To fix `_resolve_gdn_prefill_backend` checks `current_platform.is_xpu()` before the ROCm and non-ROCm branches (added in #56835). On an XPU host, an explicit `aiter_flydsl` request therefore returns `triton` instead of reaching the `RuntimeError`.The tests only mock `is_rocm` / `is_cuda`, so the result depended on the platform they ran on.
