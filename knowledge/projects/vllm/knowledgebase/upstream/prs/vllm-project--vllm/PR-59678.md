## Original PR description

These AMD test groups are mirrored in test_areas/*.yaml but have no job in test-amd.yaml, so the AMD CI pipeline never runs them. Add an optional job for each, copied from the mirror definition:

- (MI300) Multimodal Models (PPL)
- (MI300) Spec Decode DeepSeek MTP Parallel Load
- (MI300) Spec Decode AL DFlash Nightly
- (MI300) Spec Decode AL DSpark Nightly
- (MI355 DPX) FP4 and INT4 MoE Kernels
- (MI355 DPX) Qwen4 Exp
