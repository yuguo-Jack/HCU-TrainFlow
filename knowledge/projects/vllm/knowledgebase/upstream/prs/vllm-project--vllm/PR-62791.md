# [Bugfix][Benchmark] Take openai-audio input tokens from server usage

[Upstream PR](https://github.com/vllm-project/vllm/pull/62791) · state: open · merged: False

## Original PR description

## Overview

`vllm bench serve --backend openai-audio` reports the wrong input token count for every transcription request. The audio datasets set `prompt_len` from a text prompt the request never sends, and the client ignores `usage.prompt_tokens`. This reads `prompt_tokens` from the usage chunk, as the completions and chat clients already do.

## Claims

- On Whisper the bench reported 8 input tokens per request, the tokens of the dataset prompt "Transcribe the audio.". The server reports `100 × audio seconds + 4` (304 for a 3 s clip, 2,504 for 25 s).
- Total input tokens now match the server. Output tokens were already correct.

## Validation

New test in `tests/benchmarks/test_endpoint_request_func_timing.py`, over the completions, chat and audio clients: `prompt_len` takes the server's usage value. It fails for audio on `main`. `tests/benchmarks/` passes (194) and pre-commit is clean.

RTX 3080, `openai/whisper-tiny`, 18 clips from 3 s to 25 s cut from vLLM's `mary_had_lamb` and `winning_call` test assets, `--dataset-name custom_audio`:

| | `main` | this branch | server `usage.prompt_tokens` |
|---|---|---|---|
| total input tokens | 144 | 21,757 | 21,757 |

Total token throughput is computed from total input tokens, so it rises with this change. Request rate and output tokens are unchanged. The request on the wire carries no prompt field.

## Details

The server's `vllm:prompt_tokens_total` metric rose by 72 on the same run, 4 per request, so it counts the decoder prompt without the audio, while `usage` counts both. I left that alone; the bench follows `usage` as it does for the other backends.

The legacy `benchmarks/backend_request_func.py` reads `prompt_tokens` for no backend, so it is out of scope.

No issue or PR covers this. AI assistance (Claude) was used to find this and write the change and test. I reviewed every line and ran the tests and GPU comparison.
