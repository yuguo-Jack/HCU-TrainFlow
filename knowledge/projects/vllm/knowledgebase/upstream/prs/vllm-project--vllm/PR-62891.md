# [MyPy][9/N] Parent rollups and enable `tests/`

[Upstream PR](https://github.com/vllm-project/vllm/pull/62891) · state: open · merged: False

## Original PR description

## Overview

PR 9 of #49569, the last step. It cleans up the leftover mypy errors in the parent test directories, then removes `"tests"` from `SEPARATE_GROUPS` so all of `tests/` is checked with `follow_imports=silent`.

Opening as a draft while the work is in progress. **Do NOT merge until all PRs done in #49569.**

Closes #49569

## Claims

Progress (counts from mypy 1.20.2, `--follow-imports silent`, on main as of 2026-10-21):

- [x] `tests/compile`: 3 errors fixed, now enforced
- [x] `tests/v1` loose files: 1 error fixed (enforced once `v1/core`, `v1/engine` and `v1/kv_connector` are done)
- [ ] `tests/distributed`: 108 errors, mostly `DeviceCommunicatorBase | None`
- [ ] `tests/models` loose files: 39 errors
- [ ] `tests` root loose files: 41 errors, about half in `test_config.py`
- [ ] Remove `tests`, `tests/models` and `tests/v1` from `SEPARATE_GROUPS`, and drop the `tests/**` entries from `SILENT_GROUPS`

No test behaviour changes. These are type fixes only.

## Validation

For each directory, following the pattern in #49569:

```bash
mypy --python-version 3.11 --follow-imports silent --warn-unused-ignores <dirs>
pre-commit run -a mypy
```

Plus a `group_files()` check that each moved directory routes to the `''` group.

So far: `tests/compile` and `tests/v1/test_serial_utils.py` are clean (64 files, no issues), and `ruff check` / `ruff format` pass. I didn't run the touched tests locally (no CUDA box), so CI is the check there.

## Details

- `tests/compile` goes into `SILENT_GROUPS` as one entry and replaces its four sub-directory entries. Just deleting it from `SEPARATE_GROUPS` wouldn't do anything because the `tests` root group would still claim its files.
- `tests/v1` can't go in `SILENT_GROUPS` yet. It's matched first, so it would enforce the unfinished sub-directories early.
- One side effect: new test files added under an enforced directory get type-checked, so open PRs adding tests there may hit mypy errors on rebase.

Not a duplicate. PR 9 is claimed in #49569, and no other open PR touches these directories or the
mypy grouping.
