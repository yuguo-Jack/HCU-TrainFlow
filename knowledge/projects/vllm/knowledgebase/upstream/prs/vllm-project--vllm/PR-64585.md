# [NIXL][CI/Build] Bump NIXL to 1.5.2 and drop source build for Rubin

[Upstream PR](https://github.com/vllm-project/vllm/pull/64585) · state: closed · merged: True

## Original PR description

## Overview

Use the released NIXL 1.5.2 wheels in the Rubin CUDA 13.4 image and stop building NIXL from source there. NIXL 1.5.2 ships a NIXL EP extension built for torch 2.16, which the Rubin prerelease uses, so the `BUILD_NIXL=true` workaround from #60090 is no longer needed. Fixes the gap tracked in ai-dynamo/nixl#2297 (now closed).

Related: #64579 bumps `requirements/kv_connectors.txt` to the same version for the default images. <!-- merge order / rebase note, see Details -->

## Claims

- `requirements/rubin-prerelease.txt`: `nixl` 1.4.1 -> 1.5.2.
- `requirements/kv_connectors.txt`: `nixl` 1.5.0 -> 1.5.2 (same line as #64579).
- `.buildkite/release-pipeline.yaml`: the nightly "aarch64 - Rubin CUDA 13.4" build drops `--build-arg BUILD_NIXL=true` and its TODO, so it installs the PyPI wheels.

## Validation

- `nixl-cu13==1.5.2` wheels from PyPI (cp312) contain `nixl_ep_cpp_torch216`:
  - `manylinux_2_28_aarch64`: torch 2.12, 2.13, 2.14, 2.15, 2.16
  - `manylinux_2_28_x86_64`: includes torch 2.16
  - Reproduce: `pip download --no-deps --only-binary=:all: --platform manylinux_2_28_aarch64 --python-version 3.12 nixl-cu13==1.5.2 && python -m zipfile -l nixl_cu13-*.whl | grep nixl_ep_cpp_torch`
- `requirements/rubin-prerelease.txt` pins `torch==2.16.0.dev20261009+cu134`, so the 216 variant is the one that gets loaded.
- TODO before submitting: build the aarch64 Rubin image without `BUILD_NIXL` and check that the NIXL EP extension loads (`import nixl_ep_cu13` on a GPU host, or the same `nixl_ep_cpp_torch216` glob the Dockerfile check uses).
- Not run: NixlConnector P/D serving on Rubin hardware.

## Details

- The source build added in #60090 is kept (`BUILD_NIXL` ARG, `tools/build_nixl_with_torch215_for_rubin.py`, `docker/versions.json`) as an opt-in escape hatch for future torch nightlies that get ahead of NIXL releases. No CI job sets it after this change. <!-- or remove it; see author notes -->
- Updated the installation doc, which said NIXL's release wheels lack NIXL EP for the Rubin PyTorch nightly. <!-- only if the doc edit is added -->
