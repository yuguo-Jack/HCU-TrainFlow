# [Bugfix][KV Connector] Restore state after KV load rejection

[Upstream PR](https://github.com/vllm-project/vllm/pull/53298) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Fixes #49250 and addresses the stale-placeholder/request-stall mechanism in #45138. When a synchronous external KV load fails under `kv_load_failure_policy="recompute"`, restore accepted request state in the scheduler and Model Runner V2 before decoding resumes.

## Claims

- Retire discarded in-flight output without changing the recovered request state.
- Restore V2 token history, sequence length, penalty counts, speculative state, and Mamba alignment state from the scheduler's accepted position.
- Order repair of shared KV blocks, prevent new prefix-cache hits on invalid blocks, and transfer unfinished repair ownership when an owner leaves after failure handling.

## Details

Scheduler rollback alone leaves device state from discarded frames. An explicit `rewound_req_ids` signal restores V2 state, while scheduler barriers prevent dependent requests from reading shared blocks before repair is safe. These parts address the same recovery sequence; there is no connector-specific special case.

### Follow-up: same-parent mechanism ablation

I ran a fresh 72-cell ablation: three modes, four source variants, baseline/reject, and three cold repetitions.

- **S**: scheduler repair only
- **W**: minimal rewind marker plus worker device-offset rewind, without the scheduler repair
- **P**: exact PR head

| Mode | C | S | W | P |
|---|---|---|---|---|
| sync OPT-125M | FAULT 3/3 | FAULT 3/3 | RECOVERED 3/3 | RECOVERED 3/3 |
| async OPT-125M | FAULT 3/3 | FAULT 3/3 | FAULT 3/3 | RECOVERED 3/3 |
| async EAGLE3 (2 drafts) | FAULT 3/3 | FAULT 3/3 | FAULT 3/3 | RECOVERED 3/3 |

`RECOVERED` means exact token-ID equality with the no-connector baseline. All baselines were stable. Every reject run promised one 16-token block, rejected it before copying KV, and exercised Model Runner V2; M3 also recorded nonzero EAGLE3 draft work.

This isolates the two parts of the fix:

- the worker device-offset rewind is necessary in all three modes;
- that rewind plus minimal marker plumbing is sufficient for sync; and
- the scheduler repair is additionally necessary for async and async EAGLE3.

An independent verifier re-read the raw results, logs, and connector events and reproduced all three classifications.

One control cell completed generation but needed a forced child-process kill during shutdown. Its functional evidence is intact, but this run does not establish clean resource shutdown. This is a new prospectively classified ablation and does not relabel the earlier M1 result.

rejected path matched full recomputation. So the existing `run.sh` can still
fail even when recovery is correct: its final `cmp` uses successful external
reuse as the recovery oracle. The appropriate oracle here is connector-free
recomputation at the same decode configuration. I have documented that

```python
# SPDX-License-Identifier: Apache-2.0
"""Repro: with kv_load_failure_policy="recompute", a sync-load failure leaves the
failed blocks in the prefix cache. If the request that should recompute them goes
away first (aborted / preempted), a later request with the same prefix gets a
local prefix-cache hit on blocks whose KV was never loaded nor recomputed."""
from collections.abc import Callable

import pytest

from vllm.v1.request import Request, RequestStatus

from .utils import (
    create_mock_connector,
    create_model_runner_output,
    create_request,
    create_scheduler,
    create_vllm_config,
)

NUM_PROMPT_BLOCKS = 10
NUM_EXTERNAL_BLOCKS = 8
INVALID_BLOCK_IDX = 2


def _matched(table: dict[str, int]) -> Callable[[Request, int], tuple[int, bool]]:
    def f(request: Request, _: int) -> tuple[int, bool]:
        return table.get(request.request_id, 0), False

    return f


def _scheduler(policy: str):
    vllm_config = create_vllm_config()
    vllm_config.kv_transfer_config.kv_load_failure_policy = policy
    sched = create_scheduler(vllm_config)
    sched.connector = create_mock_connector()
    sched.connector.request_finished.return_value = (False, None)
    sched.connector.take_events.return_value = ()
    return sched


@pytest.mark.parametrize("policy", ["recompute", "fail"])
@pytest.mark.parametrize("how", ["abort", "preempt"])
def test_failed_sync_blocks_not_reused_before_recompute(policy, how):
    sched = _scheduler(policy)
    bs = sched.block_size
    n = NUM_PROMPT_BLOCKS * bs
    a = create_request(request_id=1, num_tokens=n, common_prefix_len=n)
    table = {a.request_id: NUM_EXTERNAL_BLOCKS * bs}
    sched.connector.get_num_new_matched_tokens.side_effect = _matched(table)

    sched.add_request(a)
    out = sched.schedule()
    a_blocks = out.scheduled_new_reqs[0].block_ids[0]
    bad = a_blocks[INVALID_BLOCK_IDX]
    sched.update_from_output(
        out, create_model_runner_output([a], invalid_block_ids={bad}, use_eos=False)
    )

    # The external copy is gone (that is why the load failed), so from now on
    # only the local prefix cache can serve this prefix.
    table.clear()

    # A goes away before it gets to recompute the failed block.
    if how == "abort":
        sched.finish_requests([a.request_id], RequestStatus.FINISHED_ABORTED)
    elif a.request_id in sched.requests:
        # As the scheduler does under KV pressure: pop from running, then preempt.
        sched.running.remove(a)
        sched._preempt_request(a, 0.0)

    # B: same prompt, no external hit -> only the local prefix cache can serve it.
    b = create_request(request_id=2, num_tokens=n, common_prefix_len=n)
    sched.add_request(b)
    out2 = sched.schedule()
    # Every request scheduled now attends to its tokens before this step's chunk;
    # none of those may sit in the failed, never-recomputed block.
    for req_id, n_sched in out2.num_scheduled_tokens.items():
        req = sched.requests[req_id]
        reused = req.num_computed_tokens - n_sched
        (blocks,) = sched.kv_cache_manager.get_block_ids(req_id)
        assert bad not in blocks[: reused // bs], (
            f"policy={policy} how={how}: {req_id} treats {reused} tokens as computed, "
            f"including block {bad} whose load failed and was never recomputed"
        )
```
