## Overview

Enrolls the remaining Models (basic, multimodal, language) jobs in `automatic_shard`: 22 jobs (14 steps and 8 AMD mirrors). Part of a series that enrolls every remaining test step, split by test area for review. Commands change only where noted below.

## Claims

| Step | Plan | AMD mirror |
|---|---|---|
| `dsv41-mono-decode-layers-gfx942-amd` | 1 shard | none |
| `basic-models-tests-initialization` | 1 shard | 1 shard |
| `kimi-k3-unit-tests-b200` | 1 shard | 1 shard |
| `dsv41-mono-decode-numerics-amd` | 1 shard | none |
| `kimi-k3-specialized-decode-amd` | 1 shard | none |
| `dsv4-mono-decode-numerics-amd` | 1 shard | none |
| `qwen4-exp-unit-tests` | 1 shard | 1 shard |
| `inkling-unit-tests-b200` | 1 shard | 1 shard |
| `qwen4-exp-unit-tests-mi300` | 1 shard | none |
| `glm5next-unit-tests` | 1 shard | 1 shard |
| `step5-unit-tests` | 1 shard | none |
| `multi-modal-models-standard-3-llava-qwen2-vl` | 1 shard | 1 shard |
| `multi-modal-accuracy-eval-small-models` | 1 shard | 1 shard |
| `dsv41-mono-decode-numerics-tp8-amd` | 1 job until main times it (new step) | none |
| `language-models-test-extended-pooling` | already enrolled | 5 shards |

- One-shard and one-job plans run the same tests as on main, as one job, and split by themselves once their tests grow.
- Plans of 2 or more shards cost one extra job setup per shard and bring each shard under the 20-minute target.

## Validation

- Planned each step and mirror with ci-infra main's planner against main's timings; every plan is within 10% of the same plan run as one job.
- The sharding harness (each shard's commands run against a mock test tree, as a PR build and as main with the OTel wrapper) shows every test runs exactly once wherever a plan has 2 or more shards.
- Every step and mirror passes on recent main runs, nightly included.
- `/ci run` (98459, and 98557 on this head) plus a scoped build (98470) for the optional steps and AMD mirrors: every enrolled job passed, and every shard finished under 22 minutes. The MI355 Extended Pooling mirror ran the same 114 passed and 1 skipped as main's fixed shards.

## Details

- **Language Models (Extended Pooling) AMD mirror** drops its fixed `parallelism: 4` and pytest-shard flags; its NVIDIA step is already enrolled, so the planner splits it.
- **Not plain pytest** steps (shell scripts, `torchrun`, examples) are enrolled too; the generator keeps them as one job. Standalone AMD steps plan like any other since vllm-project/ci-infra#871.
- **caplog.** Files that assert on logs sit in one-shard plans here, so their order in the process doesn't change.
- **Timeouts unchanged.** `timeout_in_minutes` stays per job. Fallback-aware timeouts belong in a central timeout setting.
