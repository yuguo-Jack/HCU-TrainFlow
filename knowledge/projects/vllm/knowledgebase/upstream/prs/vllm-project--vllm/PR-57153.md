## Original PR description

Fixes #57117. Not duplicating any open PR (checked: no open PR references #57117 or touches security.md for this).

**What changed** (docs-only, `docs/usage/security.md`):
- Moved `/pause`, `/resume`, `/is_paused`, `/init_weight_transfer_engine`, `/update_weights`, `/get_world_size` from production operational-control into the `VLLM_SERVER_DEV_MODE=1` section, plus the remaining dev RLHF weight-update routes (`/start_weight_update`, `/start_draft_weight_update`, `/finish_weight_update`, `/update_weight_version`, `/weight_info`). Verified each against `vllm/entrypoints/serve/dev/rlhf/api_router.py` (registered only via `register_vllm_dev_api_routers`, gated on `VLLM_SERVER_DEV_MODE`).
- Added flag-gated `POST /fault_tolerance/apply` + `GET /fault_tolerance/status` section (gated on `--enable-fault-tolerance`, verified in `launchers/api_server/routers.py`), with the limited-instruction note per @jperezdealgaba's comment (`instruction` allowlisted to `{"retry"}`, verified `_ALLOWED_INSTRUCTIONS`).
- Added `/metrics` to utility endpoints (verified Prometheus mount in `instrumentator/metrics.py`).
- Qualified Security Implications items 2–3 for the new categorization.

**Tests:** docs-only change; no code touched. Verified route inventory by grepping the routers listed above. No model/behavior impact, so no evals.
