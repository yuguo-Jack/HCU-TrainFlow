## Overview


Error msg:
```bash
E         [rank0]:   File "/opt/venv/lib/python3.12/site-packages/vllm/benchmarks/forward/capture.py", line 157, in _capture_and_time
E         [rank0]:     torch.cuda.Event(enable_timing=True, external=True),
E         [rank0]:     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
E         [rank0]:   File "/opt/venv/lib/python3.12/site-packages/vllm/v1/worker/xpu_model_runner.py", line 67, in _xpu_event
E         [rank0]:     return torch.xpu.Event(*args, **kwargs)
E         [rank0]:            ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
E         [rank0]: TypeError: Event.__new__() got an unexpected keyword argument 'external'
```
https://github.com/vllm-project/vllm/issues/61339 adds `external` argument to torch.cuda.Event. which argument is not supported by xpu.Event, so this pr currently drops it.
