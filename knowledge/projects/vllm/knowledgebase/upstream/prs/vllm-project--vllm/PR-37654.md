To ensure backward compatibility with older `xgrammar` versions that may not support the `backend` parameter, it's safer to check for its existence before calling `apply_token_bitmask_inplace`. This prevents a potential `TypeError` at runtime if an older version of the library is used.

```python
        import inspect
        if "backend" in inspect.signature(xgr.apply_token_bitmask_inplace).parameters:
            xgr.apply_token_bitmask_inplace(
                logits_float32,
                grammar_bitmask,
                indices=index_tensor,
                backend=bitmask_backend,
            )
        else:
            if bitmask_backend != "auto":
                logger.warning(
                    "The installed version of xgrammar does not support the 'backend' "
                    "parameter. The 'bitmask_backend' setting will be ignored."
                )
            xgr.apply_token_bitmask_inplace(
                logits_float32, grammar_bitmask, indices=index_tensor
            )
```
