# feat: support logprobs auxoutput

[Upstream PR](https://github.com/vllm-project/vllm/pull/61953) · state: open · merged: False

## Original PR description

## Overview

Add opt-in generated-token logprobs through the auxiliary-output path. Follow #45635, split from #60789.

When enabled, requests can return logprobs from prefix-cache-backed auxiliary artifacts instead of recomputing them through the default logprobs output path. 

## Claims

- Add `aux_output_config.enable_return_logprobs` to enable the feature.
- Add per-request opt-in through:
  ```python
  SamplingParams(
      logprobs=5,
      extra_args={"aux_output_enabled": True},
  )

- Preserve the existing default logprobs path and output format.
- Return generated-token logprobs with token ids, values, and ranks equivalent to the default path.
- Preserve correctness across prefix-cache reuse, chunked prefill, speculative-token rejection, and cache-boundary token changes.
- Reduce steady-state decode overhead by tracking dirty logprob blocks instead of scanning every cached block on every step.

## Details

- The scheduler now carries logprob fingerprints, logprob block hashes, prompt lengths, and block-boundary token ids to the worker.
- The worker stores generated-token logprob rows in a variable-sized block store keyed by generation, request configuration, KV block hash, and boundary token id.
- Auxiliary logprob rows are transferred asynchronously and indexed only after the D2H copy has completed.
- Published rows are tracked by block start. Only blocks marked dirty by newly captured rows are scanned and serialized.
- Complete blocks are reclaimed after all outputs in the current batch have consumed them, preserving same-batch prefix reuse.
- Existing routed-expert auxiliary output behavior remains supported.
- Request validation rejects unsupported combinations such as prompt logprobs, full-vocabulary logprobs, custom logprob token-id layouts, non-raw logprob modes, and online weight updates.

## Limitations

- The auxiliary path currently supports generated-token logprobs only.
- Prompt logprobs and full-vocabulary logprobs are not supported.
- Custom logprob token-id layouts are not supported.
- Prefix caching is required for the auxiliary logprob configuration.
- The feature is intended for the CUDA-like V1 generation path.
- A target-GPU benchmark result should be attached before merge to quantify latency overhead and confirm the expected decode improvement.

# SPDX-FileCopyrightText: Copyright contributors to the vLLM project
"""Compare the default and auxiliary generated-logprobs serving paths.

Measures the end-to-end serving path (scheduling, sampling, async output
copies, artifact publication, replay), which ``vllm bench forward`` excludes.

Modes
-----
default : prefix caching + regular logprobs path
aux     : same engine/sampling settings; only ``aux_output_enabled`` and
          ``aux_output_config.enable_return_logprobs`` differ
control  : (``--include-control``) no logprobs, no prefix caching. Gives the
          cost of logprobs themselves and a noise-floor reference.

Scenarios: prompt_len x batch x top_k x output_len x {cold, warm}
  cold = fresh random prompts, prefix cache reset before every iteration
  warm = same prompts re-run after an untimed populate pass

What is reported
----------------
* Latency per mode: median / p95 / p99 / std / CV, cached tokens.
* default -> aux median-latency ratio with a hierarchical, paired bootstrap
  95% CI (resamples engine restarts, then samples within each restart), plus
  how many restarts had aux slower than default.
* Decode step latency derived from output_len=1 vs output_len=N
  (``(e2e - prefill) / (N - 1)``), for each mode and the aux/default ratio.
  This is the number to watch for per-step overhead of the aux pipeline.
* Prefix-cache speed-up (cold/warm) per mode.
* Cost of logprobs (default vs control) and a noise-control ratio.
* Validity checks (all recorded as issues, exit code 1 if any):
    - cold iterations must hit 0 cached tokens, warm iterations must hit
      (almost) all cacheable tokens;
    - default vs aux generated tokens / logprobs must match for every request
      and iteration checked (``--quality-iters``);
    - warm replay vs the populate pass must agree up to the first greedy
      divergence, and a divergence must be a near-tie (fp16 prefix-cache
      numerics; tail recompute uses a different kernel layout than cold).

Engine restarts: ``--repeat N`` recreates every engine N times and alternates
the mode order (``--mode-order alternate``), so slow drift (GPU clocks, other
tenants) is not attributed to one mode.

Example::

    python benchmarks/benchmark_aux_output_logprobs.py \
        --model facebook/opt-125m --enforce-eager \
        --prompt-lens 512,2048 --batch-sizes 1,4 \
        --top-ks 0,5,20 --output-lens 1,32 \
        --warmup-iters 3 --iters 15 --repeat 3 --include-control \
        --output-json aux-logprobs-benchmark.json

Quick smoke run: ``--quick``.

``--max-overhead-pct`` / ``--max-decode-overhead-pct`` turn the CI upper bound
into a pass/fail budget. Without them timing never fails the run.
"""

        values = [int(item) for item in value.split(",") if item]

            f"expected comma-separated integers: {value}"
        ) from error

        raise argparse.ArgumentTypeError("need at least one non-negative integer")
    return values

    return values

def _make_prompts(
    args: argparse.Namespace,
    vocab_size: int,
    prompt_tokens: int,
    batch_size: int,
    repeat: int,
    tag: int,
) -> list[dict[str, list[int]]]:
    """Deterministic random prompts.

    Depends only on (seed, shape, repeat, tag) -- not on the mode -- so that
    default and aux see identical prompts and their outputs can be compared.
    Tags: 0 = warm base prompts, 1.. = cold iteration, 10000+ = scenario
    warmup, 20000+ = global warmup.
    """
    if vocab_size <= 1001:
        raise ValueError(f"tokenizer vocabulary is too small: {vocab_size}")
    rng = np.random.default_rng([args.seed, prompt_tokens, batch_size, repeat, tag])
    return [
        {
            "prompt_token_ids": rng.integers(
                1000, vocab_size - 1, size=prompt_tokens, dtype=np.int64
            ).tolist()
        }
        for _ in range(batch_size)
    ]


def _params(
    args: argparse.Namespace, mode: str, top_k: int, output_tokens: int
) -> SamplingParams:
    return SamplingParams(
        temperature=0,
        max_tokens=output_tokens,
        # top_k == 0 -> only the sampled token's logprob is returned.
        logprobs=None if mode == "control" else top_k,
        ignore_eos=True,
        detokenize=False,
        extra_args={"aux_output_enabled": True} if mode == "aux" else None,
    )


def _make_llm(args: argparse.Namespace, mode: str) -> LLM:
    config: dict[str, Any] = {
        "model": args.model,
        "dtype": args.dtype,
        "max_model_len": args.max_model_len,
        "enforce_eager": args.enforce_eager,
        "enable_chunked_prefill": True,
        "max_num_batched_tokens": args.max_num_batched_tokens,
        "enable_prefix_caching": mode != "control",
        "gpu_memory_utilization": args.gpu_memory_utilization,
        "trust_remote_code": args.trust_remote_code,
        "seed": args.seed,
    }
    if args.async_scheduling != "auto":
        config["async_scheduling"] = args.async_scheduling == "on"
    if mode == "aux":
        config["aux_output_config"] = {"enable_return_logprobs": True}
    return LLM(**config)


def _block_size(llm: LLM) -> int:
    try:
        return llm.llm_engine.vllm_config.cache_config.block_size
    except AttributeError:
        return 16


def _vocab_size(llm: LLM) -> int:
    tokenizer = llm.get_tokenizer()
    return getattr(tokenizer, "vocab_size", None) or len(tokenizer)


def _run_generate(
    llm: LLM, prompts: list[dict[str, list[int]]], params: SamplingParams
) -> tuple[float, Any]:
    if torch.cuda.is_available():
        torch.cuda.synchronize()
    start = time.perf_counter()
    outputs = llm.generate(prompts, params, use_tqdm=False)
    if torch.cuda.is_available():
        torch.cuda.synchronize()
    return (time.perf_counter() - start) * 1000.0, outputs


def _compact(outputs: Any) -> list[tuple[list[int], list[dict[int, float]] | None]]:
    """Keep only token ids and {token_id: logprob} rows (cheap to store)."""
    compact = []
    for output in outputs:
        sample = output.outputs[0]
        rows = None
        if sample.logprobs is not None:
            rows = [
                {token_id: lp.logprob for token_id, lp in row.items()}
                for row in sample.logprobs
            ]
        compact.append((list(sample.token_ids), rows))
    return compact

def _first_divergence(left: Sequence[int], right: Sequence[int]) -> int:
    n = 0
    for a, b in zip(left, right):
        if a != b:
            break
        n += 1
    return n


def _check_rows(
    ref: Sequence[dict[int, float]],
    got: Sequence[dict[int, float]],
    atol: float,
    what: str,
    max_missing: int,
) -> None:
    if len(ref) != len(got):
        raise AssertionError(f"{what}: row count {len(ref)} != {len(got)}")
    for pos, (r, g) in enumerate(zip(ref, got)):
        common = r.keys() & g.keys()
        if not common:
            raise AssertionError(f"{what}[{pos}]: no common tokens")
        missing = max(len(r), len(g)) - len(common)
        if missing > max_missing:
            raise AssertionError(
                f"{what}[{pos}]: {missing} tokens differ between top-k sets"
            )
        for token_id in common:
            diff = abs(r[token_id] - g[token_id])
            if diff > atol:
                raise AssertionError(
                    f"{what}[{pos}] token={token_id}: |{r[token_id]:.4f} - "
                    f"{g[token_id]:.4f}| = {diff:.4f} > {atol}"
                )


def _compare_until_divergence(
    ref: Any, got: Any, atol: float, max_missing: int
) -> int:
    """Compare logprobs up to the first greedy divergence; return #diverged.

    A divergence is acceptable only if the flipped token is a near-tie in the
    reference distribution (when it can be verified, i.e. top_k > 0).
    """
    if len(ref) != len(got):
        raise AssertionError(f"batch size {len(ref)} != {len(got)}")
    diverged = 0
    for i, ((ref_ids, ref_rows), (got_ids, got_rows)) in enumerate(zip(ref, got)):
        if ref_rows is None or got_rows is None:
            raise AssertionError(f"req{i}: logprobs missing")
        limit = min(len(ref_ids), len(got_ids))
        n = _first_divergence(ref_ids, got_ids)
        if n < limit:
            diverged += 1
            row = ref_rows[n]
            if len(row) > 1:  # top_k > 0: the near-tie can be verified
                if ref_ids[n] not in row or got_ids[n] not in row:
                    raise AssertionError(
                        f"req{i}: diverged at {n}, flipped token not in top-k"
                    )
                gap = abs(row[ref_ids[n]] - row[got_ids[n]])
                if gap > 2 * atol:
                    raise AssertionError(
                        f"req{i}: diverged at {n} with non-tie gap {gap:.4f}"
                    )
        upto = min(n + 1, limit)
        _check_rows(ref_rows[:upto], got_rows[:upto], atol, f"req{i}", max_missing)
    return diverged


def _compare_modes(
    default_out: Any, aux_out: Any, atol: float, allow_divergence: bool
) -> int:
    """default vs aux for identical prompts/state: expected to be identical."""
    if allow_divergence:
        return _compare_until_divergence(default_out, aux_out, atol, max_missing=1)
    if len(default_out) != len(aux_out):
        raise AssertionError("batch size differs")
    for i, ((d_ids, d_rows), (a_ids, a_rows)) in enumerate(zip(default_out, aux_out)):
        if d_ids != a_ids:
            raise AssertionError(
                f"req{i}: generated token ids differ at position "
                f"{_first_divergence(d_ids, a_ids)}"
            )
        if d_rows is None or a_rows is None:
            raise AssertionError(f"req{i}: logprobs missing")
        _check_rows(d_rows, a_rows, atol, f"req{i}", max_missing=1)
    return 0

def _stats(samples_ms: Sequence[float]) -> dict[str, float | int]:
    values = np.asarray(samples_ms, dtype=np.float64)
    std = float(values.std(ddof=1)) if len(values) > 1 else 0.0
    mean = float(values.mean())
    return {
        "n": len(values),
        "mean_ms": mean,
        "median_ms": float(np.median(values)),
        "p95_ms": float(np.percentile(values, 95)),
        "p99_ms": float(np.percentile(values, 99)),
        "std_ms": std,
        "cv_pct": std / mean * 100.0 if mean else math.inf,
    }


def _bootstrap(
    series: dict[str, list[np.ndarray]],
    stat: Callable[[dict[str, np.ndarray]], float],
    iterations: int,
    seed: int,
) -> np.ndarray:
    """Hierarchical paired bootstrap.

    ``series[name]`` is a list over engine restarts of 1-D sample arrays. Each
    iteration resamples restarts (same indices for every series, so pairing is
    kept) and then samples within each chosen restart.
    """
    rng = np.random.default_rng(seed)
    restarts = len(next(iter(series.values())))
    results = np.empty(iterations, dtype=np.float64)
    with np.errstate(divide="ignore", invalid="ignore"):
        for i in range(iterations):
            idx = rng.integers(0, restarts, restarts)
            pooled = {
                name: np.concatenate(
                    [runs[j][rng.integers(0, len(runs[j]), len(runs[j]))] for j in idx]
                )
                for name, runs in series.items()
            }
            results[i] = stat(pooled)
    return results


def _ci(boots: np.ndarray) -> tuple[float, float]:
    finite = boots[np.isfinite(boots)]
    if len(finite) == 0:
        return math.nan, math.nan
    low, high = np.percentile(finite, [2.5, 97.5])
    return float(low), float(high)

def _build_scenarios(args: argparse.Namespace) -> list[Scenario]:
    return [
        Scenario(prompt, batch, top_k, out, state)
        for prompt in args.prompt_lens
        for batch in args.batch_sizes
        for top_k in args.top_ks
        for out in args.output_lens
        for state in ("cold", "warm")
    ]


def _run_mode(
    args: argparse.Namespace,
    mode: str,
    repeat: int,
    scenarios: Sequence[Scenario],
) -> tuple[dict[str, ScenarioRun], list[str]]:
    issues: list[str] = []
    llm = _make_llm(args, mode)
    try:
        block_size = _block_size(llm)
        vocab = _vocab_size(llm)
        caching = mode != "control"

        def reset() -> None:
            if caching:
                llm.reset_prefix_cache()

        # Global warmup: process-level one-time costs, largest shape.
        for i in range(args.warmup_iters):
            prompts = _make_prompts(
                args,
                vocab,
                max(args.prompt_lens),
                max(args.batch_sizes),
                repeat,
                20000 + i,
            )
            reset()
            _run_generate(
                llm,
                prompts,
                _params(args, mode, max(args.top_ks), max(args.output_lens)),
            )

        runs: dict[str, ScenarioRun] = {}
        for s in scenarios:
            params = _params(args, mode, s.top_k, s.output_tokens)

            # Per-scenario warmup: lazily-initialised kernels/shapes must not
            # leak into the first measured sample.
            for i in range(args.scenario_warmup):
                prompts = _make_prompts(
                    args, vocab, s.prompt_tokens, s.batch_size, repeat, 10000 + i
                )
                reset()
                _run_generate(llm, prompts, params)

            base = None
            replay_ref = replay_warm = None
            if s.state == "warm":
                base = _make_prompts(
                    args, vocab, s.prompt_tokens, s.batch_size, repeat, 0
                )
                reset()
                _, populate_outputs = _run_generate(llm, base, params)  # populate
                replay_ref = _compact(populate_outputs)
                for _ in range(args.scenario_warmup):  # warm-path shapes
                    _run_generate(llm, base, params)

            samples: list[float] = []
            generated: list[int] = []
            cached: list[float] = []
            quality: list[Any] = []
            for it in range(args.iters):
                if s.state == "cold":
                    prompts = _make_prompts(
                        args,
                        vocab,
                        s.prompt_tokens,
                        s.batch_size,
                        repeat,
                        1 + it,
                    )
                    reset()
                else:
                    prompts = base
                elapsed_ms, outputs = _run_generate(llm, prompts, params)
                samples.append(elapsed_ms)
                generated.append(sum(len(o.outputs[0].token_ids) for o in outputs))
                cached.append(statistics.mean(o.num_cached_tokens or 0 for o in outputs))
                if it < args.quality_iters and mode != "control":
                    quality.append(_compact(outputs))
                if s.state == "warm" and it == 0 and mode != "control":
                    replay_warm = _compact(outputs)

            # ---- validity of the measurement itself ------------------------
            max_cacheable = (s.prompt_tokens - 1) // block_size * block_size
            if not caching:
                if max(cached) > 0:
                    issues.append(f"{s.name}: control mode reported cached tokens")
            elif s.state == "cold":
                if max(cached) > 0:
                    issues.append(
                        f"{s.name}: cold iteration hit the prefix cache "
                        f"(max cached={max(cached):.0f})"
                    )
            elif min(cached) < max_cacheable - block_size:
                issues.append(
                    f"{s.name}: warm iteration missed the cache "
                    f"(min cached={min(cached):.0f}, cacheable={max_cacheable})"
                )

            runs[s.name] = ScenarioRun(
                samples_ms=samples,
                generated_tokens=generated,
                cached_tokens=cached,
                quality=quality,
                replay_ref=replay_ref,
                replay_warm=replay_warm,
            )
            st = _stats(samples)
            print(
                f"[aux_logprobs] repeat={repeat} mode={mode:<7} {s.name:<48} "
                f"median_ms={st['median_ms']:9.3f} p95_ms={st['p95_ms']:9.3f} "
                f"cv={st['cv_pct']:5.1f}% cached={statistics.mean(cached):7.1f}",
                flush=True,
            )
        return runs, issues
    finally:
        del llm
        gc.collect()
        if torch.cuda.is_available():
            torch.cuda.empty_cache()

def _raw_dump(
    results: dict[str, dict[str, list[ScenarioRun]]],
) -> dict[str, dict[str, list[dict[str, Any]]]]:
    return {
        mode: {
            name: [
                {
                    "samples_ms": run.samples_ms,
                    "generated_tokens": run.generated_tokens,
                    "cached_tokens": run.cached_tokens,
                }
                for run in runs
            ]
            for name, runs in per_scenario.items()
        }
        for mode, per_scenario in results.items()
    }


def _report(
    args: argparse.Namespace,
    scenarios: Sequence[Scenario],
    results: dict[str, dict[str, list[ScenarioRun]]],
    modes: Sequence[str],
) -> tuple[dict[str, Any], list[str]]:
    issues: list[str] = []
    report: dict[str, Any] = {
        "latency": [],
        "default_vs_aux": [],
        "decode_step": [],
        "cache_speedup": [],
        "logprob_cost": [],
        "replay": [],
    }

    def per_run(mode: str, name: str) -> list[np.ndarray]:
        return [np.asarray(r.samples_ms) for r in results[mode][name]]

    def pooled(mode: str, name: str) -> np.ndarray:
        return np.concatenate(per_run(mode, name))

    def median(mode: str, name: str) -> float:
        return float(np.median(pooled(mode, name)))

    has_pair = "default" in modes and "aux" in modes
    has_control = "control" in modes

    # ---- 1. latency table ---------------------------------------------------
    noisy = 0
    for s in scenarios:
        print(f"\n[aux_logprobs] scenario={s.name}")
        for mode in modes:
            st = _stats(pooled(mode, s.name))
            cached = statistics.mean(
                c for r in results[mode][s.name] for c in r.cached_tokens
            )
            noisy += st["cv_pct"] > 10.0
            report["latency"].append(
                {
                    "mode": mode,
                    "scenario": asdict(s),
                    "stats": st,
                    "mean_cached_tokens": cached,
                    "samples_per_restart": [r.samples_ms for r in results[mode][s.name]],
                }
            )
            print(
                f"[aux_logprobs]   mode={mode:<7} median_ms={st['median_ms']:9.3f} "
                f"p95_ms={st['p95_ms']:9.3f} p99_ms={st['p99_ms']:9.3f} "
                f"cv={st['cv_pct']:5.1f}% cached={cached:7.1f}"
            )
    if noisy:
        print(
            f"\n[aux_logprobs] WARNING: {noisy} mode/scenario cells have CV > 10%; "
            "increase --iters/--repeat or check for GPU contention."
        )

    # ---- 2. default -> aux ---------------------------------------------------
    if has_pair:
        print("\n[aux_logprobs] ===== default -> aux (median latency ratio) =====")
        for index, s in enumerate(scenarios):
            series = {"d": per_run("default", s.name), "a": per_run("aux", s.name)}

            def ratio(p: dict[str, np.ndarray]) -> float:
                return float(np.median(p["a"]) / np.median(p["d"]))

            point = ratio({k: np.concatenate(v) for k, v in series.items()})
            low, high = _ci(
                _bootstrap(series, ratio, args.bootstrap_iters, args.seed + index)
            )
            per_restart = [
                float(np.median(a) / np.median(d))
                for d, a in zip(series["d"], series["a"])
            ]
            slower = sum(r > 1.0 for r in per_restart)

            quality = "PASS"
            diverged = 0
            try:
                for d_run, a_run in zip(results["default"][s.name], results["aux"][s.name]):
                    for d_out, a_out in zip(d_run.quality, a_run.quality):
                        diverged += _compare_modes(
                            d_out, a_out, args.logprob_atol, args.allow_token_divergence
                        )
            except AssertionError as error:
                quality = f"FAIL: {error}"
                issues.append(f"{s.name}: default vs aux {error}")

            budget = ""
            high_pct = (high - 1.0) * 100.0
            if args.max_overhead_pct is not None and high_pct > args.max_overhead_pct:
                budget = f" OVER-BUDGET(>{args.max_overhead_pct:.1f}%)"
                issues.append(
                    f"{s.name}: overhead CI high {high_pct:+.2f}% exceeds "
                    f"--max-overhead-pct={args.max_overhead_pct}"
                )
            report["default_vs_aux"].append(
                {
                    "scenario": asdict(s),
                    "median_ratio": point,
                    "overhead_pct": (point - 1.0) * 100.0,
                    "ci95_overhead_pct": [(low - 1.0) * 100.0, high_pct],
                    "per_restart_ratio": per_restart,
                    "quality": quality,
                    "diverged_requests": diverged,
                }
            )
            print(
                f"[aux_logprobs] {s.name:<48} overhead={(point - 1) * 100:+7.2f}% "
                f"CI95=[{(low - 1) * 100:+7.2f}%, {high_pct:+7.2f}%] "
                f"aux_slower_in={slower}/{len(per_restart)} restarts "
                f"quality={quality}{budget}"
            )

    # ---- 3. decode step latency ---------------------------------------------
    long_out = max(args.output_lens)
    if 1 in args.output_lens and long_out > 1:
        print(
            f"\n[aux_logprobs] ===== decode step latency "
            f"(out={long_out} vs out=1, ms per step) ====="
        )
        steps = long_out - 1
        for prompt in args.prompt_lens:
            for batch in args.batch_sizes:
                for top_k in args.top_ks:
                    for state in ("cold", "warm"):
                        pre = Scenario(prompt, batch, top_k, 1, state).name
                        e2e = Scenario(prompt, batch, top_k, long_out, state).name
                        row: dict[str, Any] = {
                            "prompt": prompt,
                            "batch": batch,
                            "top_k": top_k,
                            "state": state,
                            "out": long_out,
                        }
                        text = []
                        for mode in modes:
                            step = (median(mode, e2e) - median(mode, pre)) / steps
                            row[f"{mode}_ms"] = step
                            text.append(f"{mode}={step:7.3f}")
                        if has_pair:
                            series = {
                                "d_e": per_run("default", e2e),
                                "d_p": per_run("default", pre),
                                "a_e": per_run("aux", e2e),
                                "a_p": per_run("aux", pre),
                            }

                            def step_ratio(p: dict[str, np.ndarray]) -> float:
                                return float(
                                    (np.median(p["a_e"]) - np.median(p["a_p"]))
                                    / (np.median(p["d_e"]) - np.median(p["d_p"]))
                                )

                            point = step_ratio(
                                {k: np.concatenate(v) for k, v in series.items()}
                            )
                            low, high = _ci(
                                _bootstrap(
                                    series,
                                    step_ratio,
                                    args.bootstrap_iters,
                                    args.seed + 7919,
                                )
                            )
                            row.update(
                                aux_over_default=point, ci95=[low, high]
                            )
                            text.append(
                                f"aux/default={point:5.2f}x CI95=[{low:5.2f}, {high:5.2f}]"
                            )
                            high_pct = (high - 1.0) * 100.0
                            if (
                                args.max_decode_overhead_pct is not None
                                and high_pct > args.max_decode_overhead_pct
                            ):
                                text.append("OVER-BUDGET")
                                issues.append(
                                    f"decode step prompt={prompt} batch={batch} "
                                    f"top_k={top_k} {state}: CI high "
                                    f"{high_pct:+.1f}% exceeds "
                                    f"--max-decode-overhead-pct="
                                    f"{args.max_decode_overhead_pct}"
                                )
                        report["decode_step"].append(row)
                        print(
                            f"[aux_logprobs] prompt={prompt} batch={batch} "
                            f"top_k={top_k} {state:<4} " + " ".join(text)
                        )

    # ---- 4. prefix-cache speed-up ---------------------------------------------
    cache_modes = [m for m in modes if m != "control"]
    if cache_modes:
        print("\n[aux_logprobs] ===== prefix-cache speed-up (cold / warm) =====")
        for prompt in args.prompt_lens:
            for batch in args.batch_sizes:
                for top_k in args.top_ks:
                    for out in args.output_lens:
                        cold = Scenario(prompt, batch, top_k, out, "cold").name
                        warm = Scenario(prompt, batch, top_k, out, "warm").name
                        row = {
                            "prompt": prompt,
                            "batch": batch,
                            "top_k": top_k,
                            "out": out,
                        }
                        text = []
                        for mode in cache_modes:
                            speedup = median(mode, cold) / median(mode, warm)
                            row[f"{mode}_speedup"] = speedup
                            text.append(f"{mode}={speedup:5.2f}x")
                        report["cache_speedup"].append(row)
                        print(
                            f"[aux_logprobs] prompt={prompt} batch={batch} "
                            f"top_k={top_k} out={out:<3} " + " ".join(text)
                        )

    # ---- 5. cost of logprobs + noise floor ------------------------------------
    if has_control:
        print("\n[aux_logprobs] ===== control (no logprobs, no prefix cache) =====")
        deviations = []
        for s in scenarios:
            if s.state == "cold":
                warm_name = Scenario(
                    s.prompt_tokens, s.batch_size, s.top_k, s.output_tokens, "warm"
                ).name
                deviations.append(median("control", warm_name) / median("control", s.name))
        if deviations:
            worst = max(deviations, key=lambda v: abs(v - 1.0))
            print(
                f"[aux_logprobs] noise floor: control warm/cold median="
                f"{statistics.median(deviations):.3f} worst={worst:.3f} (expect ~1.0)"
            )
            report["noise_floor"] = {
                "median": statistics.median(deviations),
                "worst": worst,
            }
        if "default" in modes:
            for s in scenarios:
                if s.state != "cold":
                    continue
                cost = median("default", s.name) / median("control", s.name)
                report["logprob_cost"].append(
                    {"scenario": asdict(s), "default_over_control": cost}
                )
                print(
                    f"[aux_logprobs] {s.name:<48} "
                    f"default(logprobs+prefix cache)/control={cost:.3f}"
                )

    # ---- 6. replay consistency (warm vs populate pass) ------------------------
    print("\n[aux_logprobs] ===== replay consistency (warm vs populate pass) =====")
    for mode in modes:
        if mode == "control":
            continue
        for s in scenarios:
            if s.state != "warm":
                continue
            diverged = 0
            status = "PASS"
            try:
                for run in results[mode][s.name]:
                    diverged += _compare_until_divergence(
                        run.replay_ref,
                        run.replay_warm,
                        args.logprob_atol,
                        max_missing=2,
                    )
            except AssertionError as error:
                status = f"FAIL: {error}"
                issues.append(f"{mode} {s.name}: replay {error}")
            report["replay"].append(
                {
                    "mode": mode,
                    "scenario": asdict(s),
                    "status": status,
                    "diverged_requests": diverged,
                }
            )
            print(
                f"[aux_logprobs] mode={mode:<7} {s.name:<48} {status} "
                f"token_diverged={diverged} (fp16 prefix-cache numerics, informational)"
            )
    return report, issues

def _mode_order(args: argparse.Namespace, repeat: int) -> list[str]:
    aux_first = args.mode_order == "aux-first" or (
        args.mode_order == "alternate" and repeat % 2 == 1
    )

def main() -> int:
    args = _parser().parse_args()
    if args.quick:
        args.prompt_lens, args.batch_sizes = [512], [2]

    return 0 if not issues else 1
