# [CI] Split (B200) V1 Attention into Sparse MLA, MLA, DCP, Dense/SSM, and ROCm jobs

[Upstream PR](https://github.com/vllm-project/vllm/pull/57063) · state: closed · merged: False

## Original PR description

## What

Replace the opaque two-replica `(B200) V1 Attention` hash shard with named jobs for Sparse MLA, MLA Correctness, Dense and SSM, and a shared job for the three short units (DCP, MLA Backends, ROCm). Each job runs whole semantic directories; only MLA Correctness uses pytest sharding within its own directory.

## Old

```text
(B200) V1 Attention Shard %N [v1-attention-b200]
└── pytest v1/attention --num-shards=2
```

## New

| Buildkite job | key | whole coverage unit | replicas |
|---|---|---|---:|
| `(B200) V1 Attention / Sparse MLA` | `v1-attention-b200-sparse-mla` | `sparse_mla/` | 1 |
| `(B200) V1 Attention / MLA Correctness Shard %N` | `v1-attention-b200-mla-correctness` | `mla/correctness/` | 3 |
| `(B200) V1 Attention / Dense and SSM` | `v1-attention-b200-dense-ssm` | `dense/` + `ssm/` | 1 |
| `(B200) V1 Attention / DCP, MLA Backends and ROCm` | `v1-attention-b200-dcp-mla-backends-rocm` | `dcp/` + `mla/backends/` + `rocm/` | 1 |

## Notes

- The three short units share one worker, each as its own `pytest` invocation, so process isolation is unchanged and a failure still names the unit it came from. Separately they measured about three minutes of pytest between them, which does not justify three checkouts and three container startups.
- `test_mla_backends.py` is split three ways: its correctness tests go to `mla/correctness/test_mla_backend_correctness.py`, a verbatim move of `main`'s two tests. The shared bodies go to the non-collected `tests/v1/attention/_mla_backends.py`, which keeps `main`'s `_prefill_backend_dimension_params` and `_run_backend_correctness`. The remaining tests go to `mla/backends/`. Collected cases match `main` apart from the path, and a new prefill backend is covered without a new file.
- Every top-level `tests/v1/attention` test file moves into a unit. The shared job also runs any test file added later at the `v1/attention` or `v1/attention/mla` root. `tests/v1/worker/test_mamba_hybrid_model_state.py` imports the GDN builder test from `ssm/`.
- The H100 job and its MI300 mirror keep their existing whole-area sharding (#57238 follows up on those). Earlier validation comments describe superseded layouts. AI assistance was used.
