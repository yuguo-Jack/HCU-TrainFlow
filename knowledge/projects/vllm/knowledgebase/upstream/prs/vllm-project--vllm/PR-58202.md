# [Frontend] Add watermark_config.enforce to prevent per-request watermark opt-out

[Upstream PR](https://github.com/vllm-project/vllm/pull/58202) · state: open · merged: False

## Original PR description

## Purpose

Fixes #58191.

A server started with `--watermark-config` still lets any caller disable watermarking for a single request by sending `"watermarking": false`. The server cannot guarantee that every output carries a watermark, which defeats server-side enforcement for provenance or compliance. RFC #53916 states that watermarking "cannot be modified by downstream consumers", yet the current code allows exactly that.

## Changes

Add an opt-in `enforce` field to `WatermarkConfig`, defaulting to `False` for compatibility.

With `enforce=True`, `GPUWatermarkSampler.add_request` ignores per-request `watermarking=False` and logs a warning. Existing decoding limitations remain unchanged: greedy decoding is not watermarked, and watermark detection is not guaranteed for every output.

Extend the existing GPU regression test to cover enforcement enabled and disabled. Both cases passed on a Tesla T4 with `facebook/opt-125m`.

Usage:

    --watermark-config '{"key": 12345, "enforce": true}'

## Test Plan

Serve `facebook/opt-125m` and send two `/v1/completions` requests with the same `temperature=0.7` and `seed=42`, one with `watermarking: true` and one with `false`. Run once with `--watermark-config '{"key": 12345}'` and once with `--watermark-config '{"key": 12345, "enforce": true}'`.

## Test Result

Tested on an A100 with `facebook/opt-125m`.

**Without `enforce`** — the `false` request escapes the watermark and returns different text (HTTP 200, no warning):

- `watermarking=true` → `for a great nation, it was the world's greatest country...`
- `watermarking=false` → `, I fell in love with a girl. But when I came to the realization...`
- outputs differ: **True**

**With `enforce: true`** — the `false` request is overridden and returns the same watermarked output, and the server logs a warning:

- `watermarking=true` → `for a great nation, it was the world's greatest country...`
- `watermarking=false` → `for a great nation, it was the world's greatest country...`
- outputs identical: **True**

Server log:

`WARNING [gpu_sampler.py:47] Watermarking is enforced by the server (watermark_config.enforce=True); ignoring the request's watermarking=False.`
