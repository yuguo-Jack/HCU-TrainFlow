# [Doc] MiniMax-M3.1-Flash: add GB300 InferenceX AgentX presets

[Upstream PR](https://github.com/vllm-project/vllm/pull/64821) · state: closed · merged: True

## Original PR description

## Overview

Adds the GB300 AgentX lane of [SemiAnalysisAI/InferenceX#4662](https://github.com/SemiAnalysisAI/InferenceX/pull/4662) (key `minimaxm31flash-fp4-gb300-vllm-agentic-dspark`) to `recipes/models/MiniMaxAI/MiniMax-M3.1-Flash.yaml` as three opt-in tuned presets. The recipe's GB300 AgentX presets cover only the Dynamo lanes; this lane serves directly with vLLM on one 4-GPU tray.

## Claims

- Three presets with the seven-token DSpark draft (three tokens for DEP4), 13 points, each with its pinned image:

  | Preset | Strategy | Points |
  |---|---|---|
  | `gb300_agentx_tp4` | `single_node_tp`, TP4 | c1, c4, c8, c16, c24, c32, c40 |
  | `gb300_agentx_dep4` | `single_node_dep` | DEP4 c64, c96, c128 |
  | `gb300_agentx_tp2` | `single_node_tp`, TP2 | c28, c32, c36 |

- Per-point `--max-num-seqs`, `--max-num-batched-tokens`, `--long-prefill-token-threshold`, `--prefill-schedule-interval`, `--gpu-memory-utilization`, `--watermark` and CUDA graph capture sizes are rendered as flags. The TP2 points add the Simple CPU KV tier (482 GB per engine); the DEP4 points use the router tab's consistent-hash vLLM Router, and the router's `--request-timeout-secs` and `--disable-retries` are in the runbook.
- Presets are opt-in; no existing rendering changes.
- Left out on purpose: `--served-model-name` and the benchmark's synthetic acceptance length.
