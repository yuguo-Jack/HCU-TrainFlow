# [ROCm] Use unified decode fallback for sliding-window AITER FA

[Upstream PR](https://github.com/vllm-project/vllm/pull/39640) · state: open · merged: False

## Original PR description

## Summary

The decode path in `rocm_aiter_fa.py` already documents that sliding-window attention should bypass `paged_attention_v1` and use the unified attention fallback, but the condition only checked small head sizes. This patch moves that rule into a small helper, applies it in the decode branch, and adds a narrow regression test that locks the sliding-window case in.

## Why this isn't duplicate work

- Checked nearby ROCm issue and PR activity for the same area, including `gh pr list --repo vllm-project/vllm --state open --search "sliding window unified_attention ROCM_AITER_FA"`
- Checked adjacent `rocm_aiter_fa` lanes such as `#33761`, `#39192`, and `#39527`
- The open work I found in this file is about KV-cache layout or broader kernel changes; I did not find an open PR that covers this decode fallback condition.

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The use of `importlib` and dynamic module loading for a sibling module within the same repository is unnecessary and makes the test brittle. Standard absolute imports should be used instead, which is the practice followed throughout the vLLM codebase. This also avoids potential issues with double-imports or incorrect module resolution and simplifies the test code significantly. Since `rocm_aiter_fa_utils.py` does not have any ROCm-specific dependencies, it is safe to import on any platform.

```python
from vllm.v1.attention.backends.rocm_aiter_fa_utils import should_use_unified_decode_fallback


def test_small_head_size_uses_unified_decode_fallback():
    assert (
        should_use_unified_decode_fallback(
            head_size=32,
            sliding_window=(-1, -1),
        )
        is True
    )


def test_sliding_window_uses_unified_decode_fallback():
    assert (
        should_use_unified_decode_fallback(
            head_size=128,
            sliding_window=(-1, -1),
        )
        is False
    )
    assert (
        should_use_unified_decode_fallback(
            head_size=128,
            sliding_window=(255, 0),
        )
        is True
    )
```
