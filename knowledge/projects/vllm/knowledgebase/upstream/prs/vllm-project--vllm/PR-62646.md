# [CI][ROCm] Mirror the Distributed Preload group on MI355

[Upstream PR](https://github.com/vllm-project/vllm/pull/62646) · state: closed · merged: True

## Original PR description

- Add a `:amd: (MI355) Distributed Preload` mirror of the L4 group on `mi355_2`, in `distributed.yaml` and `test-amd.yaml`
- Exclude `distributed` tests from the AMD Model Executor job in `test-amd.yaml`, matching the shared step

#55490 added the `:nvidia: (L4) Distributed Preload` group, which runs the TP2 + expert-parallel cold start / warm restart test in `test_weight_cache.py`, and dropped `distributed` tests from the shared Model Executor step. The AMD-only Model Executor entry in `test-amd.yaml` was not updated, so that single-GPU job still collected the two-GPU test, and nothing ran it on AMD hardware. On 2x MI355 the group passes 10/10 in about 2m45s per run.

AI assistance (Claude Code) was used to draft this change. Every line was reviewed by the submitter.
