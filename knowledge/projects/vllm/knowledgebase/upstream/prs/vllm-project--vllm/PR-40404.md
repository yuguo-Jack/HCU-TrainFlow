The function name `_custom_add_int64` is duplicated from line 61. While the IR registry handles this correctly because of the decorator, it makes the test code confusing and harder to maintain. Additionally, the names `_custom_add_int16` and `_custom_add_int64` are misleading as they don't reflect the masking logic being tested. Consider renaming them to something more descriptive like `_custom_add_mask_a`, `_custom_add_mask_b`, and `_custom_add_mask_a_and_b`.

```suggestion
def _custom_add_mask_a_and_b(
    a: Tensor, b: Tensor, mask: Tensor, mask_a: bool, mask_b: bool
) -> Tensor:
    return a.masked_fill(mask, 0) + b.masked_fill(mask, 0)
```
