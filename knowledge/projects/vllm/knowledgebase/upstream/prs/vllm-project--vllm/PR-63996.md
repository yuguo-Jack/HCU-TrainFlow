# [Model][Spec Decode] Refactor #41834 with useful improvements

[Upstream PR](https://github.com/vllm-project/vllm/pull/63996) · state: closed · merged: True

## Original PR description

## Overview

#41834 has been stale for a while, and many key contributions have been superseded by other PRs. This PR extracts the useful parts of that huge PR and conducts end-to-end experiments on two Sparks to ensure it works well. The authorship is also acknowledged.

## Claims

In general, this PR comprises:

- **mHC residual reuse.** For a `8192` token prefill setup, this saves 256 MiB VRAM.
- **No `_mtp_hidden_buffer` under DSpark.** DSpark does not need and access these memories and this saves another 256 MiB VRAM per card.
- **Stale MRV1 drafter layout caches.** This is a real bugfix but only for V1 runner. This fixes the drafter layout cache and increases the accept rate from 51% to 63%, same as V2 runner.

## Validation

Reproduced on two Sparks. I did several end-to-end experiments using DeepSeek-v4-Flash and ensured that the tokens output is the same.

No performance regression is observed, and I confirm the VRAM savings and draft acceptance rate benefits.
