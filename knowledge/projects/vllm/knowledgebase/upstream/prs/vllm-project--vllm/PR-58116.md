# [Bugfix][Frontend] Aggregate completion cached tokens

[Upstream PR](https://github.com/vllm-project/vllm/pull/58116) · state: open · merged: False

## Original PR description

Problem: Batched completion responses report cached_tokens from only the first streamed prompt or the last non-streamed prompt. The reported value is incomplete and streaming results depend on completion order.

Solution: Track streamed cached token counts by prompt index and sum non-streamed results across the batch. Add regression tests for batched and out-of-order streaming responses.
