# [Quantization][INC] Support hybrid INT4+FP8 AutoRound checkpoints via maybe_update_config

[Upstream PR](https://github.com/vllm-project/vllm/pull/46322) · state: open · merged: False

## Original PR description

## Summary

Fixes #46311. Replaces #46312 (which was based on v0.23.0; this branch targets the refactored `inc/` directory on `main`).

`INCConfig` never overrode `maybe_update_config`, leaving the base-class no-op to run. For hybrid AutoRound checkpoints where attention/shared-expert layers are FP8 (with per-block `weight_scale_inv` scales) and expert FFN layers are INT4 AutoGPTQ, this meant:

- FP8 layers were never detected
- `weight_scale_inv` parameters were never registered in `params_dict`
- The weight loader silently skipped them (`Parameter X not found in params_dict, skip loading`)
- All FP8 attention forward passes produced garbage tokens

The model loaded without error, making this failure silent and hard to diagnose.

## Changes

**`vllm/model_executor/layers/quantization/inc/inc.py`** (+86 lines, single file)

- `maybe_update_config`: scans safetensors metadata for `float8_e4m3fn` weights that have a sibling `.weight_scale_inv` tensor, infers `weight_block_size` from the weight/scale shape ratio, constructs `Fp8Config`. No weights are loaded during the scan — metadata only.
- `_is_layer_fp8(prefix)`: checks whether a prefix belongs to the detected FP8 set, with fused-module awareness (e.g. a fused `in_proj_qkvz` covering `in_proj_qkv` + `in_proj_z` shards).
- `get_quant_method`: when `layer_config.quantized` is False, check `_is_layer_fp8` first and return `Fp8LinearMethod(fp8_config)` instead of `UnquantizedLinearMethod`.
- `apply_vllm_mapper`: remap `fp8_layers` through the HF→vLLM name mapper so prefix matching survives the rename step.

## Test plan

- [x] Tested on SM12.1 (NVIDIA GB10 / DGX Spark, CUDA 13.0.2) with `kleybrink/Qwen3.6-35B-A3B-Hybrid-INT4-FP8-MTP`:
  - Startup: `INC hybrid checkpoint: detected 250 FP8 layers (block_size=[128, 128])`
  - `CutlassFp8BlockScaledMMKernel` selected for FP8 layers; `MarlinLinearKernel` for INT4 experts
  - Zero `weight_scale_inv not found` warnings
  - Coherent completions confirmed across short/medium/long prompts
- [x] INT4-only AutoRound checkpoints unaffected: `maybe_update_config` returns early when no `float8_e4m3fn` weights are found
