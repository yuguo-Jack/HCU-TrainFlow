# [Perf][KV Offload] Vectorize direct-layout descriptor fill across layers

[Upstream PR](https://github.com/vllm-project/vllm/pull/65082) · state: open · merged: False

## Original PR description

## Overview

`_fill_direct_ops` builds the (src, dst, size) copy descriptors for every GPU<->CPU KV transfer in the `OffloadingConnector`. It loops over the layer refs and calls `compute_sub_block_ptrs` twice per ref, so one transfer costs 32 calls on an 8B model and 80 on 70B TP8, even for a single block. This PR fills all refs in one numpy broadcast.

## Claims

- Same descriptors, same order. Only the direct layout changes, canonical is untouched.
- `_fill_direct_ops` is 3-75x faster depending on layer count and transfer size (table below).
- On the engine core thread, the fill drops from 1.26% to 0.18% of samples during stores and 2.74% to 1.06% during loads. End-to-end req/s is flat, so the win is CPU headroom per transfer, not throughput.

## Validation

- New `test_direct_fill_matches_per_ref_pointers` checks the vectorized fill against `compute_sub_block_ptrs` called ref by ref, for both directions, blocks_per_chunk 1/3/4, every skip offset, refs sharing a tensor, and row stride bigger than page size. Breaking the formula fails it.
- `pytest tests/v1/kv_offload/cpu/test_gpu_worker.py` on H200: 40 passed before, 46 after. `pre-commit` is clean.

Microbench of `_fill_direct_ops` alone, median µs over 2000 iterations, H200 host (Xeon 8468). bpc = GPU blocks per CPU chunk.

```python
import time
import numpy as np
import torch
from vllm.utils.math_utils import cdiv
from vllm.v1.kv_offload.base import CanonicalKVCacheRef
from vllm.v1.kv_offload.cpu import gpu_worker as gw


def old_fill(h, g_idx, group_src, group_dst, group_size, s_skip, d_skip, a_src, a_dst, a_sz, op_idx):
    num_bytes = 0
    for ref in h.layer_refs_per_group[g_idx]:
        t, end = ref.tensor_idx, op_idx + group_size
        gw.compute_sub_block_ptrs(group_src, h.src_blocks_per_chunk, a_src[op_idx:end], h.src_tensors[t], skip_count=s_skip)
        gw.compute_sub_block_ptrs(group_dst, h.dst_blocks_per_chunk, a_dst[op_idx:end], h.dst_tensors[t], skip_count=d_skip)
        a_sz[op_idx:end] = ref.page_size_bytes
        num_bytes += group_size * ref.page_size_bytes
        op_idx = end
    return op_idx, num_bytes


def handler(num_layers, page, bpc, gpu_to_cpu, rows=2048):
    gpu = [torch.empty(rows, page, dtype=torch.int8) for _ in range(num_layers)]
    cpu = [torch.empty(rows, page * bpc, dtype=torch.int8) for _ in range(num_layers)]
    refs = [[CanonicalKVCacheRef(tensor_idx=i, page_size_bytes=page) for i in range(num_layers)]]
    h = gw.SingleDirectionOffloadingHandler.__new__(gw.SingleDirectionOffloadingHandler)
    h.src_tensors, h.dst_tensors = (gpu, cpu) if gpu_to_cpu else (cpu, gpu)
    h.layer_refs_per_group = refs
    h.src_blocks_per_chunk = 1 if gpu_to_cpu else bpc
    h.dst_blocks_per_chunk = bpc if gpu_to_cpu else 1
    h._direct_group_ptrs = [gw.build_direct_group_ptrs(refs[0], h.src_tensors, h.dst_tensors, h.src_blocks_per_chunk, h.dst_blocks_per_chunk)]
    return h


def median_us(fn, iters=2000):
    for _ in range(50):
        fn()
    ts = []
    for _ in range(iters):
        t0 = time.perf_counter_ns()
        fn()
        ts.append(time.perf_counter_ns() - t0)
    ts.sort()
    return ts[len(ts) // 2] / 1e3


rng = np.random.default_rng(0)
for name, layers, page in [("Llama-3-8B", 32, 64 << 10), ("Qwen3-30B-A3B", 48, 32 << 10), ("Llama-3-70B TP8", 80, 8 << 10)]:
    for bpc in (1, 4):
        for gpu_to_cpu in (True, False):
            h = handler(layers, page, bpc, gpu_to_cpu)
            for n in (1, 16, 128, 512):
                gs = rng.integers(0, 2048, cdiv(n, h.src_blocks_per_chunk))
                gd = rng.integers(0, 2048, cdiv(n, h.dst_blocks_per_chunk))
                bufs = [np.empty(layers * n, dtype=np.int64) for _ in range(3)]
                ref = [b.copy() for b in bufs]
                args = (0, gs, gd, n, 0, 0)
                old_fill(h, *args, *ref, 0)
                h._fill_direct_ops(*args, *bufs, 0)
                assert all((a == b).all() for a, b in zip(bufs, ref))
                t_old = median_us(lambda: old_fill(h, *args, *ref, 0))
                t_new = median_us(lambda: h._fill_direct_ops(*args, *bufs, 0))
                print(name, "store" if gpu_to_cpu else "load", bpc, n, f"{t_old:.1f}", f"{t_new:.1f}")
```

## Details

The per-ref inputs to `compute_sub_block_ptrs` (base pointer, row stride, sub-block size, page size) never change after init, so this computes them once per group as `(num_refs, 1)` columns and broadcasts over the block indices. Caching `data_ptr()` is safe because the handler holds the tensor views for its lifetime, and sleep mode re-maps at the same address.

The step is ~20 ms and this saves 100-500 µs of host work per transfer, which is why req/s doesn't move. The saving scales with layer count, and it is on the engine core thread right before the forward pass.

#56076 moves `compute_sub_block_ptrs` into `pointer_utils.py`. Happy to rebase onto it once it lands.
