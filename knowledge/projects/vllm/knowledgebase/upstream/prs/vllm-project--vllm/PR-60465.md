# [Feat] Add text-only OpenAI Decisions API MVP

[Upstream PR](https://github.com/vllm-project/vllm/pull/60465) · state: open · merged: False

## Original PR description

## Overview

Adds a text-only `/v1/decisions` endpoint following the [OpenAI API format](https://developers.openai.com/api/docs/guides/decisions).

Builds on #59299 and #60677, now merged into `main`. This PR is one commit on top of the current `main`.

## Claims

Supports predicate, choice, and score questions using shared label reads under `vllm/entrypoints/openai/decisions`. Both `/v1/decisions` and `/v1/systemone` are available by default on supported generation models and return 501 when a read strategy is unsupported. The new endpoint accepts text strings or user messages and returns ordered answers with probabilities and token usage.

## Validation

- 95 CPU tests passed on the rebased commit, including DiffusionGemma strategy coverage, current cache-salt/tracing behavior, HTTP error handling, logging, limits, Qwen tokenization, and shared generative scoring. All-files pre-commit with the CI manual stage passed.
- Local SDK/schema checks passed without model inference.
- Qwen3-0.6B GPU end-to-end tests on a DGX Spark: all 15 endpoint tests passed without an endpoint flag before this rebase. The run used `--gpu-memory-utilization 0.35` to share the device. The current checkout could not rerun GPU tests because its NVIDIA driver is unavailable.
- A small balanced Qwen3-0.6B factual eval through `/v1/decisions` scored 8/16: 6/12 predicates and 2/4 choices. All six true predicates received probabilities below 0.5. Direct Chat Completions with the same predicate prompt also returned `false` for a true case, so this result needs a stronger-model follow-up. Live OpenAI comparison remains pending.

## Details

For this MVP: no images or refusal scoring, and at most 64 questions and 26 choices. Confidence is not calibrated to OpenAI's models.

Duplicate checks found no other open PR for this endpoint. #59299 added the shared backend and #60677 ungated `/v1/systemone`; this PR moves shared modules under `openai/decisions` and adds the OpenAI-format endpoint. Built with Codex assistance.
