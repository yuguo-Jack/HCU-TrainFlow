# [Frontend] Remove dead helpers and sync type annotations in entrypoints and config

[Upstream PR](https://github.com/vllm-project/vllm/pull/63304) · state: open · merged: False

## Original PR description

## Overview

Remove unreferenced dead helpers, type aliases, and unreachable branches across `vllm/entrypoints/`, correct stale docstrings and comments, and synchronize the `environment_variables` `TYPE_CHECKING` annotations with runtime defaults in `vllm/envs.py`.

Per review feedback, the deprecation helpers in `vllm/config/utils.py` are **kept**: this PR no longer touches that file (restored in faacbe2fd6). The original `SpeculativeConfig` assert simplification was superseded by #63205, which moved that logic into `NgramSpeculatorConfig.configure()`; only the docstring corrections remain for that file.

## Claims

- Removes the unused `ServeContext` dataclass and the vestigial `GenerateBaseServing.request_id_prefix` `ClassVar` in `vllm/entrypoints/generate/base/serving.py` (plus now-unused imports), and the unused `RendererRequest`/`RendererChatRequest` protocols in `vllm/entrypoints/serve/engine/typing.py` — zero remaining references (grep + mypy).
- Removes the unreachable fallback in `_parse_score_content` (`vllm/entrypoints/pooling/scoring/utils.py`): with `wrap_dicts=False`, `parse_chat_message_content_parts` always returns `[ConversationMessage(...)]`, so the `if parse_res:` guard, the extra `create_parser()`, and the `"Only one multi-modal item is supported"` branch are dead. Behavior-preserving — the returned value is the same early-return path.
- Removes the dead `if tool_server is not None:` branch after `tool_server: ToolServer | None = None` in `vllm/entrypoints/openai/api_server.py`, and fixes its deprecation message (`vllm server` -> `vllm serve`).
- Corrects stale docstrings: `prompt_lookup_min`/`prompt_lookup_max` in `vllm/config/speculative.py` (actual defaults are 5, not 1; neither is required — each defaults to the other when only one is set, per `NgramSpeculatorConfig.configure()`), `MetricSnapshot` -> `list[Metric]` in `vllm/entrypoints/llm.py`, and the `--api-key` authenticated path-prefix list in `vllm/entrypoints/common/cli_args.py` (`/cohere` is also authenticated).
- Synchronizes `TYPE_CHECKING` env annotations in `vllm/envs.py` with their runtime defaults (`VLLM_CPU_KVCACHE_SPACE`, `VLLM_SKIP_P2P_CHECK`, `VLLM_DP_MASTER_IP`, `VLLM_XGRAMMAR_CACHE_MB`), adds 7 missing entries, and fixes the `compile_factors()` lists.
