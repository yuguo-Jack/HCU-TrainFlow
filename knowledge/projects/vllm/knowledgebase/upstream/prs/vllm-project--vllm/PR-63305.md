## Original PR description



## Overview

Update stale source file paths in Buildkite `source_file_dependencies` (`.buildkite/intel_jobs/distributed_intel.yaml`, `.buildkite/test-amd.yaml`) and fix outdated file paths, CLI subcommands, and endpoint references across documentation and README files.

## Claims

- Updates `.buildkite/intel_jobs/distributed_intel.yaml` (`vllm/distributed/kv_transfer/kv_connector/v1/nixl_connector.py` -> `vllm/distributed/kv_transfer/kv_connector/v1/nixl/`) and `.buildkite/test-amd.yaml` (`vllm/v1/spec_decode/` -> `vllm/spec_decode/`) so Buildkite file-change triggers match current paths.
- Updates `docs/cli/README.md` (`vllm bench {latency,serve,throughput}` -> `vllm bench {forward,mm-processor,serve,startup,sweep}`), `docs/serving/online_serving/README.md` (adds pooling `/pooling`, `/classify`, `/score`, `/v1/rerank`, `/v2/rerank` endpoints to the endpoint table), and `docs/serving/online_serving/openai_compatible_server.md` (`vllm/entrypoints/openai/protocol.py` -> `vllm/entrypoints/openai/chat_completion/protocol.py`).
- Updates moved source and test paths in `docs/design/model_runner_v2.md`, `docs/features/context_extension.md`, `docs/features/disagg_encoder.md`, `docs/features/ec_cpu_connector.md`, `docs/usage/troubleshooting.md`, `examples/features/logits_processor/README.md`, `tests/compile/README.md`, `vllm/models/minimax_m3/amd/specialized_decode/README.md`, and `rust/src/chat/tests/templates/vllm_examples/README.md`.

## Details

- **Root cause:** Several directory moves (`vllm/v1/spec_decode/` -> `vllm/spec_decode/`, `nixl_connector.py` -> `nixl/`, `vllm/worker/model_runner.py` -> `vllm/v1/worker/gpu/model_runner.py`, `openai/protocol.py` -> `openai/chat_completion/protocol.py`, `rust/src/chat/src/renderers/hf/` -> `rust/src/chat/src/template/`, and `vllm bench` subcommand updates) left stale paths in docs and two Buildkite configs.
- **Duplicate-PR check:** Searched open PRs via `gh pr list --repo vllm-project/vllm --state open --search "distributed_intel.yaml nixl"` and excluded `.buildkite/test_areas/engine.yaml` & `samplers.yaml` (covered by #51345) and `docs/usage/security.md` (covered by #57153).
- **AI assistance:** AI assistance was used to audit documentation and Buildkite path references and prepare this PR; all changes were reviewed and verified locally.
