# [Bugfix][Spec Decode] Initialize Mistral EAGLE weight-loader state

[Upstream PR](https://github.com/vllm-project/vllm/pull/65449) · state: closed · merged: True

## Original PR description

## Overview

Fix draft weight loading for Mistral EAGLE models, including [Mistral Small 4 EAGLE](https://huggingface.co/mistralai/Mistral-Small-4-119B-2603-eagle).

## Claims

- Initialize the shared-expert state used by the inherited weight loader.
- Initialize `hidden_size`, which the inherited forward path reads during sequence-parallel gathering.

## Details

`EagleMistralLarge3Model` inherits `load_weights` and `forward` from `DeepseekV2Model` but skips its constructor. The draft constructor does not initialize the shared-expert state that the weight loader reads, so loading fails even for a dense draft.

Use the same helper as the parent to derive fused shared-expert layers from the constructed model. This also preserves the parent's policy checks if a draft contains MoE layers.

Based on Ruben Debien's open [#61369](https://github.com/vllm-project/vllm/pull/61369), adapted to the per-layer shared-expert API introduced by [#61457](https://github.com/vllm-project/vllm/pull/61457). The earlier patch initializes the old boolean flag using a helper that no longer exists on main.
