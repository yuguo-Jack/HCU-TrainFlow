# [CI] Improve (NCCL and torch) symmetric memory allreduce test coverage

[Upstream PR](https://github.com/vllm-project/vllm/pull/35543) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Purpose
- Add test_symm_mem_allreduce.py and test_nccl_symm_mem_allreduce.py to H100 and B200 2-GPU distributed test jobs so they run on hardware where symmetric memory is actually supported (previously only ran on L4 where the tests self-skip).

- Add test_allreduce_thresholds.py: comprehensive unit tests for all NVIDIA allreduce backend dispatch thresholds (NCCL symm mem donut boundaries, PyTorch symm mem max_size per arch/world_size, custom AR thresholds, cross-backend consistency). Runs in mandatory 4-GPU job.

- Enable VLLM_USE_NCCL_SYMM_MEM=1 for Qwen3-235B LM eval on H100 (TP=4) to provide e2e coverage of the NCCL symm mem path with accuracy validation.

- Fix test_symm_mem_allreduce.py crash on H100/B200 caused by `VllmConfig.__post_init__` calling `model_config.get_hidden_size()` when fuse_allreduce_rms is auto-enabled on Hopper/Blackwell.

## Test Plan

Ran all the tests added/changed on H100 and B200
