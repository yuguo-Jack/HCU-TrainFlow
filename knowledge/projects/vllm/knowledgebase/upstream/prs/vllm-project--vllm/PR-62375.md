# [Benchmark][XPU] Support XPU in forward bench graph capture/profiling

[Upstream PR](https://github.com/vllm-project/vllm/pull/62375) · state: closed · merged: True

## Original PR description



## Overview
Follow after PR: https://github.com/vllm-project/vllm/pull/61692 
`vllm bench forward --profile-dir` captures and profiles its one-shot forward graph with CUDA-only APIs, so `tests/benchmarks/test_forward_cli.py::test_bench_forward` fails on XPU with `AssertionError: No activities specified for the profiler`.

## Claims

- `test_bench_forward` now passes on XPU.
- No behavior change on CUDA/ROCm.

## Validation

Ran on real XPU (BMG, 8 devices) hardware:

```
python -m pytest tests/benchmarks/test_forward_cli.py -v

# 6 passed

```

AI assistance (GitHub Copilot CLI) was used to investigate the Intel CI failure, implement this patch, and validate it on XPU hardware. Human review and testing were performed before submission.
