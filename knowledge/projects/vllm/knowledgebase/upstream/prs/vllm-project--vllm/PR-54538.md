# [Cleanup] Decouple MoE FlashInfer utils into flashinfer_moe and clean up imports

[Upstream PR](https://github.com/vllm-project/vllm/pull/54538) · state: closed · merged: False

## Original PR description

Fixes #31414

#### Motivation & Context
`vllm.utils.flashinfer` (general FlashInfer GPU kernel availability checks and GEMM helpers) and `vllm.model_executor.layers.quantization.utils.flashinfer_utils` (MoE-specific weight layout / activation translation) suffered from confusingly similar module names and risk of cyclic imports between `utils` and `model_executor`.

#### Description of Changes
- Renames `flashinfer_utils.py` to `flashinfer_moe.py` to make module scopes explicit and self-documenting.
- Updates all 12 in-tree import sites across `vllm/model_executor` and `tests/kernels/moe/`.
- Leaves a backward-compatibility deprecation shim in `flashinfer_utils.py` to ensure third-party extensions do not immediately break.
- Passes all pre-commit, ruff format, and kernel unit tests.
