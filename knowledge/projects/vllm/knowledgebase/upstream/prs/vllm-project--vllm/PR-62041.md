# [MRV2] Collect KV transfer results before the drafter runs

[Upstream PR](https://github.com/vllm-project/vllm/pull/62041) · state: closed · merged: True

## Original PR description

With a speculator, collect the KV connector's transfer results right after sampling and defer only `wait_for_save()` and `clear_connector_metadata()` until after the drafter, via a new `finalize_step()`. Finished loads are then reported without waiting for the drafter, and async loads start before it.

Note this doesn't involve any changes to the KVConnector interface itself.
