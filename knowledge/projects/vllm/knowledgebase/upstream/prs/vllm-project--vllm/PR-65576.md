# [docker] Install AWS EFA in the main image; build DeepEP-EFA separately

[Upstream PR](https://github.com/vllm-project/vllm/pull/65576) · state: open · merged: False

## Original PR description

- Install EFA 1.51.0 (minimal: libfabric, aws-ofi-nccl, hwloc) in vllm-openai-base when INSTALL_KV_CONNECTORS=true.
- Drop the EFA Mooncake wheel swap; mooncake-transfer-engine 0.3.14 includes the EFA transport.
- Rename Dockerfile.efa to Dockerfile.deepep_efa. It now only rebuilds DeepEP for GIN over EFA and sets the aws-ofi-nccl NCCL plugins. IMAGE_USER restores the base's user for non-root bases.
- Rename the release images and publish target from -efa to -deepep-efa.
