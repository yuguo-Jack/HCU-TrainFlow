# [ROCm][CI] fix test_pynccl for test_pynccl_multiple_allreduce_with_vllm with VLLM_ROCM_USE_AITER=1

[Upstream PR](https://github.com/vllm-project/vllm/pull/61756) · state: open · merged: False

## Original PR description



## Overview


Fixes a test in `tests/distributed/test_pynccl.py` which would switch to AITER implementation but not properly capture the graph as a result. Disables custom all_reduce functions.

## Claims


Fixes a failing test case when AITER is on.


## Validation


```
VLLM_ROCM_USE_AITER=1 python3 -m pytest -v -s \
  tests/distributed/test_pynccl.py::test_pynccl_multiple_allreduce_with_vllm
```
## Details
Add `set_custom_all_reduce(False)` to `multiple_allreduce_with_vllm_worker_fn`. 

Reason is that this file was intended to test pynccl not custom all_reduce functions. This is evident in the size of the tensor which is fp32 and size 16*1024*1024 elements (64MB). vLLM custom all_reduce does not handle sizes this large. So it intentionally used pynccl. But AITER supports sizes up to 64MB by default.

A separate test will be implemented in a future PR that can test AITER's behavior in this fashion.
