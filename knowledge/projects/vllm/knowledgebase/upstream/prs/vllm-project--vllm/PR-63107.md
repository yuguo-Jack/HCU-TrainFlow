This layer additionally carries each DBO microbatch's physical destination offset through the runner, snapshots staged routing rows, and restores the connector-visible logical order. It does not replace the routing-hook changes in #62441; integration must preserve both source layout and staged destination semantics.

This builds on vLLM's existing route reconstruction and handles the separate staged-offset case. No speedup is claimed.
