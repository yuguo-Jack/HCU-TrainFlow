## Original PR description

## Overview

Add the missing opt-in MiniMax-M3 MI355X MXFP4 AgentX preset from [InferenceX #4418](https://github.com/SemiAnalysisAI/InferenceX/pull/4418). Replace the stale #2959 guide-only reproduction with the current pinned-image profile, without changing general serving defaults or existing presets.

## Claims

- Twelve points: TP4 at c1/4/5/8/10/12/15/20/24/32 enables `--monokernel`; TP2 c1/c2 omits it. Each has `max-num-seqs = 2 × concurrency`, Model Runner V2, and no offload or expert parallelism.
- Pin `nightly-df6603f...@sha256:81899892...`, the exact MXFP4 target/GQA EAGLE3 K3, AITER target/draft attention and MoE, FP8 KV/indexer, full-decode capture list, environment, parsers and thinking mode from the resolved source.
- Production commands retain real target verification. Synthetic AL2.78 is described only for throughput reproduction. Baseline, other variants/hardware and the four existing presets remain unchanged.

The pinned monokernel handles supported physical decode widths 1–16; larger/mixed steps use ordinary decode. This documents the measured profile and makes no general performance/accuracy guarantee.
