# [Feature][Model] Add native DistilBERT sequence classification support

## Original PR description

## Purpose

Add native vLLM support for `DistilBertForSequenceClassification` with `--runner pooling` for sequence classification tasks.

DistilBERT has several architectural differences that require a dedicated implementation:

- Uses word and position embeddings only (no token-type embeddings)
- Separate Q/K/V projections (`q_lin`, `k_lin`, `v_lin`, `out_lin`)
- Layer normalization after each residual connection (`sa_layer_norm` after attention, `output_layer_norm` after FFN)
- Classification head has an extra `pre_classifier` linear + ReLU before `classifier` , both are top-level checkpoint keys       remapped via `WeightsMapper`
