# [Bugfix][ROCm][MiniMax-M3] Reject IndexCache overrides that miss text_config

[Upstream PR](https://github.com/vllm-project/vllm/pull/63082) · state: closed · merged: True

## Original PR description

## Overview

MiniMax-M3 reads its IndexCache settings (#47269) from `text_config`, so the documented top-level `--hf-overrides` form is silently ignored. This PR rejects that form on ROCm with an actionable error and fixes the docstring.

## Claims

- On ROCm, top-level `use_index_cache`, `index_topk_freq` or `index_skip_topk_offset` raise `ValueError` when `ModelConfig` is built, and the error gives the nested override. Before, the server started with IndexCache off and no log.
- The nested form is unchanged and is what the docstring now documents.
- The docstring drops the GSM8K-based "negligible accuracy impact" claim.

## Validation

MI355X, ROCm 7.2.3, `main` at `12c01a22e`:

```bash
pytest tests/models/minimax_m3/test_index_cache_overrides.py -v
# this PR:           3 passed
# main + this test:  2 failed (Failed: DID NOT RAISE ValueError), 1 passed
```

`vllm serve MiniMax-M3-MXFP4 --tensor-parallel-size 4 --load-format dummy ... --hf-overrides '{"use_index_cache": true, "index_topk_freq": 4}'`:

- `main`: starts and serves requests; nothing reports the override as ignored.
- This PR: exits after 10 s, before EngineCore starts, with `MiniMax-M3 reads IndexCache settings from text_config, so top-level use_index_cache, index_topk_freq would be ignored. Pass them as --hf-overrides '{"text_config": {"use_index_cache": true, "index_topk_freq": 4}}'.`
- This PR with the nested form: starts and serves requests.

## Details

`--hf-overrides` updates the outer `MiniMaxM3Config`, while the language model and `_should_skip_index_topk` read `config.text_config` (the same pitfall as #54289). The check is a `MODELS_CONFIG_MAP` entry that reads the keys from `hf_overrides`. It is ROCm only because the NVIDIA model does not implement IndexCache. Launches using the top-level form now fail at startup instead of running without IndexCache. `vllm/model_executor/models/config.py` is added to the MI355 MiniMax M3 CI steps.

GSM8K prompts fit within the 2048-token sparse top-k window, where IndexCache has no effect. A long-context proxy shows a cost: teacher-forced NLL of a ~1K-token unseen file after 12K-131K tokens of same-package Python sources (24 samples, MXFP4, TP4, one run per configuration):

| IndexCache | off | freq 2 | freq 4 | freq 8 |
|---|---|---|---|---|
| mean NLL | 0.703 | 0.747 | 0.781 | 0.854 |
| samples worse than off | - | 21/24 | 21/24 | 24/24 |

```python
"""Long-context teacher-forced NLL probe for sparse-attention approximations (e.g. IndexCache).

build: nll_longctx.py build <model_dir> <out.jsonl>
    Concatenates Python sources from one package directory into 32K/64K/128K-token
    contexts and appends the head of an unseen file as the scored target.
score: nll_longctx.py score <samples.jsonl> <port> <model> <out.json>
    Sends token ids to /v1/completions with prompt_logprobs and reports the mean
    NLL of the target tokens per sample.
"""

import glob
import json
import os
import sys
import urllib.request

ROOTS = ["vllm", "torch", "transformers", "aiter"]
SITE = "/usr/local/lib/python3.12/dist-packages"
TARGET_TOKENS = 1024


def build(model_dir, out):
    from transformers import AutoTokenizer

    tok = AutoTokenizer.from_pretrained(model_dir, trust_remote_code=True)
    dirs = []
    for root in ROOTS:
        for d in sorted(glob.glob(os.path.join(SITE, root, "**/"), recursive=True)):
            files = sorted(glob.glob(os.path.join(d, "*.py")))
            if len(files) >= 12:
                dirs.append((d, files))
    samples = []
    for i, ctx in enumerate([32768] * 8 + [65536] * 8 + [131072] * 8):
        d, files = dirs[(i * 7919) % len(dirs)]
        ids, used = [], 0
        for f in files[:-1]:
            text = f"# file: {os.path.relpath(f, SITE)}\n" + open(f, errors="ignore").read() + "\n"
            ids += tok.encode(text, add_special_tokens=False)
            used += 1
            if len(ids) >= ctx:
                break
        ids = ids[:ctx]
        tgt_file = files[-1] if used >= len(files) - 1 else files[used]
        tgt = tok.encode(f"# file: {os.path.relpath(tgt_file, SITE)}\n" + open(tgt_file, errors="ignore").read(),
                         add_special_tokens=False)[:TARGET_TOKENS]
        samples.append({"id": i, "dir": os.path.relpath(d, SITE), "ctx": len(ids), "ids": ids + tgt, "n_target": len(tgt)})
        print(f"sample {i}: dir={samples[-1]['dir']} ctx={len(ids)} target={len(tgt)}", flush=True)
    with open(out, "w") as f:
        for s in samples:
            f.write(json.dumps(s) + "\n")


def score(path, port, model, out):
    res = []
    for line in open(path):
        s = json.loads(line)
        body = json.dumps({"model": model, "prompt": s["ids"], "max_tokens": 1, "temperature": 0,
                           "prompt_logprobs": 0}).encode()
        req = urllib.request.Request(f"http://localhost:{port}/v1/completions", data=body,
                                     headers={"Content-Type": "application/json"})
        r = json.loads(urllib.request.urlopen(req, timeout=1800).read())
        plp = r["choices"][0]["prompt_logprobs"]
        n = s["n_target"]
        nll = []
        for pos in range(len(s["ids"]) - n, len(s["ids"])):
            entry = plp[pos] or {}
            lp = entry.get(str(s["ids"][pos]))
            nll.append(-lp["logprob"])
        res.append({"id": s["id"], "ctx": s["ctx"], "nll": sum(nll) / len(nll)})
        print(f"sample {s['id']} ctx={s['ctx']} nll={res[-1]['nll']:.4f}", flush=True)
    by_ctx = {}
    for r in res:
        by_ctx.setdefault(r["ctx"] // 1024, []).append(r["nll"])
    summary = {"mean_nll": sum(r["nll"] for r in res) / len(res),
               "by_ctx_k": {k: sum(v) / len(v) for k, v in sorted(by_ctx.items())}, "samples": res}
    json.dump(summary, open(out, "w"), indent=1)
    print("mean_nll", summary["mean_nll"], "by_ctx_k", summary["by_ctx_k"])


if __name__ == "__main__":
    if sys.argv[1] == "build":
        build(sys.argv[2], sys.argv[3])
    else:
        score(sys.argv[2], int(sys.argv[3]), sys.argv[4], sys.argv[5])
```
