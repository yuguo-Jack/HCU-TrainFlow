# [Fast Start] Support compressed-tensors CUTLASS FP8 weight-cache restarts

[Upstream PR](https://github.com/vllm-project/vllm/pull/63673) · state: open · merged: False

## Original PR description

## Overview

Enable CUDA IPC weight-cache restarts for serialized compressed-tensors tensor/channel FP8 linear weights. Part of #56049.

This is now independent, directly based on main `34d5de18cd8b`. [Review only this feature](https://github.com/liusy58/vllm/compare/34d5de18cd8baf9f5958e45720858939863a7264...4d954d5d1289d3940116fdafca757a12aa363873); head `4d954d5d1289`. Rebuilt in response to Zifeng’s request to decouple the stacked PRs.

## Claims

- Reuse processed weights/scales across engine restarts with the validated CUTLASS backend.
- Preserve exact outputs, shared storage and required Python metadata; unsupported configurations remain rejected.
- Include only this feature and its necessary common plumbing beyond merged main.

## Validation

B300, November 4, exact source hashes verified against this head:

| Check | Result |
|---|---|
| Layer/configuration regressions | 10 passed, 59 deselected in 22.66s |
| Real model: ordinary → fallback → IPC → second IPC | 1 passed in 141.02s |
| All changed-file pre-commit hooks | Passed, including mypy, ruff and CI test tethering |

Both IPC loads forbid fallback. Exact greedy outputs use `VLLM_BATCH_INVARIANT=1`; layer tests also verify shared pointers and unchanged tensors. The Llama8B test used the existing local RedHatAI/Meta-Llama-3.1-8B-FP8 snapshot `881d74b74ad8ebe8775fb178b1fd0c935477f1bc`, substituted for its HF alias, with GPU memory utilization 0.12. Assertions and all four loading paths are unchanged.

```bash
CUDA_VISIBLE_DEVICES=7 HF_HUB_OFFLINE=1 PYTHONPATH=. .venv/bin/python -m pytest tests/quantization/test_compressed_tensors.py -k compressed_fp8_preprocessed -q -rs
CUDA_VISIBLE_DEVICES=7 HF_HUB_OFFLINE=1 PYTHONPATH=. .venv/bin/python -m pytest tests/model_executor/model_loader/test_weight_cache.py::test_ipc_cache_compressed_fp8 -q -rs
pre-commit run --files $(git diff 34d5de18cd8baf9f5958e45720858939863a7264 HEAD --name-only)
```

The isolated runtime used Python 3.12, Torch 2.14/cu130, FlashInfer 0.7.2.post1, process-local CUDAcompat13.4, and reused stable extensions from `5d55ef159`. Relevant CUTLASS FP8 C++ is unchanged; unrelated HiSparse binding and removed Qutlass-wrapper changes are outside these tests. This is targeted smoke/output equivalence, not a pristine full-source rebuild, full accuracy evaluation, performance benchmark, or upstream GPU CI result. No new skips, retries or weakened assertions were added. GPU occupancy guards prevented launches onto busy GPUs; other workloads were untouched.

## Details

Only an actual CUTLASS FP8 linear kernel opts in. IPC restores the transposed layout metadata, dynamic input-scale state, and attention-scale host metadata without transforming shared tensors again.

The common compressed-tensors scheme capability bridge and attention-buffer restoration are also necessary in independent #63976. Neither PR requires the other. If both merge, retain both narrow capability cases; the shared hook may need a textual conflict resolution.
