# [Chore] Port more vendored configs and processors to upstream Transformers

[Upstream PR](https://github.com/vllm-project/vllm/pull/60823) · state: open · merged: False

## Original PR description

## Overview

Follow-up to #60623. Ports the vLLM code for 6 more models to the upstream Transformers 5.16.1 schemas, and deletes their vendored configs and processors (9 files). Also fixes registry entries that kept models out of CI.

Related PRs:
- **#61392:** the DeepSeek-V4 part of this PR, split out.
- **#61813:** the MiniMax-M3 part of this PR, split out.
- **#61883:** the Inkling part of this PR, split out.
- **#47438:** a stale draft (last updated 2026-07-16) with a partial OpenCUA fix. This PR supersedes it.

## Claims

- Deletes the vendored configs for `step3p5`, `muse_glimmer`, `cosmos3_edge`, `colpali`, `colmodernvbert` and `qianfan_ocr`. It also deletes the vendored `cosmos3_edge` and `muse_glimmer` processors, and the model code now reads the upstream fields:
  - **Step3p5:** reads `layer_types` / `mlp_layer_types` / per-type `rope_parameters`. Upstream `Step3p7TextConfig` is registered in `_CONFIG_REGISTRY`, because the hub remote code fails validation.
  - **MuseGlimmer and Cosmos3-Edge:** they consume upstream processor outputs. Cosmos3-Edge reorders upstream's merge-window patches back to raster order before SigLIP2.
  - **ColPali:** reads PaliGemma from `vlm_config`.
  - **Qianfan-OCR:** a small adapter maps the upstream vision fields onto InternViT's.
  - **ColModernVBERT:** `ModernVBertModel` is mapped to `ColModernVBertForRetrieval`.
- **Fixes:**
  - **ColModernVBERT:** the vendored config dropped the checkpoint's sliding-window `rope_theta` (160000 → 10000). vLLM now matches the HF reference.
  - **Step-3.5-Flash MTP:** built with an `IndexError` before; it now builds.
  - **InternS1-Pro:** failed to initialize (`model_config` was not set).
  - **OpenCUA:** Transformers v5 builds a processor's sub-processors from its `__init__` signature, which here only exposed `tokenizer`, so the processor had no `image_processor`. Fixed by overriding `get_attributes`.
  - **Kimi-K2.5:** the spec-decode image token is now read from `image_token_id`. `ModelConfig.is_quantized()` now uses the arch config, so it sees quantization configs nested in `text_config`.
- Renames the vendored `InternVL{,Image,Video}Processor` to `InternVLChat*`, so they stop shadowing the upstream classes.
- **Registry entries CI was skipping:**
  - FireRedASR2, FunASR and InternS1 caps removed; they work on Transformers v5.
  - Isaac and InternS1-Pro caps narrowed to the HF comparison.
  - Phi-4-reasoning-vision and OpenCUA pinned to the compatible `refs/pr/8` and `refs/pr/10` (OpenCUA's cap narrowed to the HF comparison).
  - Cohere2-MoE switched to the renamed `CohereLabs/North-Mini-Code-1.0`.
- **Kept vendored:**
  - `qwen3_asr`: upstream silently loads the original nested checkpoints with default sizes.
  - Step3p7 and MiniMax-M3 processors: upstream tiles differently, or lacks the opt-in resize modes.
