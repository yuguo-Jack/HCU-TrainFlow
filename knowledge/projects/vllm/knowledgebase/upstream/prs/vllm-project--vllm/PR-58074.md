# [Model] Use circular buffer for DeepSeek V4 C128 state

[Upstream PR](https://github.com/vllm-project/vllm/pull/58074) · state: open · merged: False

## Original PR description

## Summary

DeepSeek-V4 C128 compressor state is request-local bounded history rather than reusable attention KV cache. On CUDA, representing it with SlidingWindowMLASpec allocates more blocks than the state requires.

This PR stores CUDA C128 state in one CircularBufferSpec block per request, reducing its KV-cache footprint. C4 and CPU/ROCm/XPU remain on their existing paged layouts. These can be in the follow-up PRs and tests.

## Implementation

- Size each ring for 128 history rows plus speculative lookahead.
- Address rows as block_id * capacity + position % capacity.
- Use Triton to build ring/tail metadata and skip padding or null blocks.
- Let CuTeDSL read current-chunk rows from raw inputs and older rows from the ring before saving the new tail, preventing wraparound overwrite.
- Keep C4 and non-CUDA backends unchanged.

## Results

- TP4+EP and DP2×TP2+EP serving passed
- NIXL PD GSM8K accuracy: 0.9469
- Mooncake PD (TP2 prefill + TP2 decode + EP) GSM8K accuracy: 0.9515
- SimpleCPUOffload GSM8K accuracy: 0.955
- KV capacity: `335,514 → 478,421` tokens (`+42.6%`)

This change was developed with AI assistance and manually reviewed and validated by the submitter.

### State Management & Cache Locality Analysis

1. **Ring Buffer Pointer Mechanics**:
   Replacing contiguous re-allocations of the C128 recurrent state tensor with an in-place modular ring buffer (`state_idx = (step + seq_len) % buffer_size`) removes repeated memory copies along the recurrent dimension during multi-step autoregressive decoding.

2. **CUDA Graph Tensor Identity**:
   Because the circular buffer maintains a static tensor allocation across decoding steps, graph capture preserves fixed memory pointers for the recurrent state kernel, preventing graph invalidation.

```python
# Verification of modular indexing
def update_c128_state(state_buffer: torch.Tensor, new_state: torch.Tensor, step: int) -> torch.Tensor:
    slot = step % state_buffer.shape[0]
    state_buffer[slot].copy_(new_state)
    return state_buffer
```
