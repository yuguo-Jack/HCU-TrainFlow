# [Doc] MiniMax-M3: document the B300 NVFP4 InferenceX AgentX aggregated profile

[Upstream PR](https://github.com/vllm-project/vllm/pull/63395) · state: closed · merged: True

## Original PR description

## Overview

Document the B300 NVFP4 AgentX lane of [SemiAnalysisAI/InferenceX#4357](https://github.com/SemiAnalysisAI/InferenceX/pull/4357) (head `b7c06012`, key `minimaxm3-fp4-b300-vllm-agentic-mtp`) in `recipes/models/MiniMaxAI/MiniMax-M3.yaml`, modeled on the B200 section from #63163. B300 had no section or builder overrides for this profile.

## Claims

- New guide section **B300: InferenceX AgentX aggregated (vLLM)**: one aggregated worker on a single 8-GPU B300 node (TP8 and TP4 at one client, TP4 at 24/36/40 clients), GQA EAGLE3 draft with three tokens, image `vllm/vllm-openai:nightly-ac68c3087215e0a4f3cdfa218508c6aada57235d@sha256:98adb2311118263a453ec0acd5d4b72bda3db26cecc0fe8ffc94b9ab03c951f9` (vLLM `0.30.1rc1.dev396+gac68c3087` in the run logs).
- Per-point table (`--max-num-seqs` 2/2/7/60/60, `--max-num-active-seqs` 12 and 15 on the 36/40-client host-offload points, `VLLM_FLASHINFER_ALLREDUCE_BACKEND` trtllm/trtllm/mnnvl/auto/auto), the CUDA graph capture-size lists, the SimpleCPUOffload config and the full `vllm serve` command.
- Builder: B300 overrides matching the existing B200 ones: the GQA draft with FlashInfer draft attention and local argmax reduction, and NVFP4 `--enable-prefix-caching`, `--max-num-batched-tokens 16384`, `--gpu-memory-utilization 0.95`, `--stream-interval 20` and `--no-enable-flashinfer-autotune` with the lane's image. The image predates the `--disable-x` aliases (#61479), so the B300 override and command use `--no-enable-flashinfer-autotune`.
- `meta.date_updated` bumped to 2026-10-23.

## Validation

- `node scripts/validate-source.mjs --source vllm --dir <this checkout>/recipes` passes (vllm-project/recipes @ `92a63ed`).
- Rendered every variant x hardware x strategy x feature set x frontend (35,904 renders) before and after: 476 changed, all on B300 (the GQA draft override reaches every variant on B300, as on B200), 0 errors before and after.
- The builder's B300 + NVFP4 + GQA + Text-only + Thinking + Single-node TP render matches every static serving flag and environment variable of the lane except `--tensor-parallel-size` (builder 1, lane 4/8), `--enable-chunked-prefill` (in the guide command) and `minimax_m3_msa_decode_backend` (builder `cutlass`, lane unset; the guide says to drop it).
- Per-point values taken from the effective recipe at the PR head and checked against the run config and the engine non-default-args line of all five server logs of run 39490622498: TP, `--max-num-seqs`, `--max-num-active-seqs`, `--gpu-memory-utilization`, capture sizes, all-reduce backend and the offload config agree for every point.
- Merged current `main` (`224b2f54`); merges cleanly with the open H200 section in #63391.

## Details

Excluded as InferenceX-only: concurrency lists, synthetic acceptance (`rejection_sample_method: synthetic`, mentioned in the guide only as how the throughput points were measured), `KV_OFFLOADING`/`TOTAL_CPU_DRAM_GB` benchmark labels, AIPerf and trace-replay settings, `--served-model-name`, `PYTHONNOUSERSITE`, the health-check settings. No cluster-specific workarounds were found in the lane.
