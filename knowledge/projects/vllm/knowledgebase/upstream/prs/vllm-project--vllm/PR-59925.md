# [DeepSeek-V4-P3] deterministic MoE DeepEP

[Upstream PR](https://github.com/vllm-project/vllm/pull/59925) · state: open · merged: False

## Original PR description

## Overview

Wire DeepSeek-V4's supported MoE/DeepEP low-latency path for batch-invariant execution. Stable expert selection, token-local quantization, rank-synchronous dispatch capacity, and graph-safe metadata are separate parts of the contract; unsupported kernels fail closed.

- Use the supported DeepGEMM expert backend and stable router GEMM. Align masked/contiguous SiLU x Mul FP8 scales, routed-expert clamp, and accumulation.
- Stage DeepEP LL dispatch at `VLLM_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK` (default **128**). The rank-wide token maximum sets the stage count, so empty tail stages still join collectives. Shared experts run once for the full local batch.
- Avoid live GPU-to-host expert maxima during graph capture; choose the shared-expert auxiliary stream on MNNVL only when its preconditions hold.
