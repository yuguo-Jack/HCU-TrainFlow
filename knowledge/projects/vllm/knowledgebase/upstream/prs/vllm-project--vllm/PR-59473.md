# fix(flash_linear_attention): mask out-of-bounds lanes to prevent NaN propagation

[Upstream PR](https://github.com/vllm-project/vllm/pull/59473) · state: open · merged: False

## Original PR description

Fixes #59404

In `flash_linear_attention/ops/chunk_o.py`, the vendored copy dropped the mask and `other` fill from the upstream implementation. Without `other=0.0` on the load and a `tl.where` mask, out-of-bounds lanes hold undefined values which propagate NaN/inf when exponentiated (via `exp(b_g)` and `exp(b_g[:, None] - b_g[None, :])`).

This matches upstream by hoisting `o_t` and `m_t` above the `USE_G` block and properly loading with an explicit fill and mask.
