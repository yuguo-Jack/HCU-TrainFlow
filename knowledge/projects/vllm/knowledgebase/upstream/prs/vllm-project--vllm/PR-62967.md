# [Bugfix][gRPC] Drain in-flight RPCs and engine work within --shutdown-timeout

[Upstream PR](https://github.com/vllm-project/vllm/pull/62967) · state: closed · merged: True

## Original PR description



## Overview

`vllm serve --grpc` ignores `--shutdown-timeout`. On SIGTERM it cancels in-flight RPCs after a hardcoded 5 s (`server.stop(grace=5.0)`). It then calls `AsyncLLM.shutdown()` without a timeout, so EngineCore gets the default 5 s join before SIGKILL. This PR spends the `--shutdown-timeout` budget instead: in-flight requests finish, then EngineCore drains work that outlives an RPC, such as NIXL prefill blocks that the decode side has not read yet, until the same deadline plus a 5 s teardown floor.

Related: #61562 (drain order for the multi-API-server HTTP path), #41383 (NIXL KV cache lease), #55102 (previous fix to this launcher).

## Claims

With `--shutdown-timeout N > 0`:

- SIGTERM makes the gRPC server refuse new RPCs at once (`UNAVAILABLE`). In-flight RPCs run to completion for up to N s, and never less than the 5 s they get with the default `0`, so setting a timeout is never less graceful than not setting one. Today they are cancelled after 5 s with `UNAVAILABLE: Cancelling all calls`.
- EngineCore keeps serving until no RPC that could still send it a request is in flight and AsyncLLM has no request left. RPCs are counted from the moment the server dispatches them, so a request that reached the server before SIGTERM is served even if it is still arriving, being preprocessed or queued in EngineCore. EngineCore then drains what outlives an RPC until N s plus a 5 s teardown floor. A prefill instance in a NIXL P/D deployment keeps the blocks it has handed off until the decode instance reads them. Today it is SIGKILLed about 5 s after SIGTERM, and the decode request fails under the default `kv_load_failure_policy="fail"`.
- RPCs still running at the deadline (`max(N, 5 s)`) are cancelled, and their requests are aborted while EngineCore is still running.
- An RPC that carries no request, such as a router's `SubscribeKvEvents` stream, does not hold shutdown: it is cancelled 5 s after EngineCore stops.
- A second SIGTERM or SIGINT cancels all RPCs at once.
- The process exits within `max(N, 5 s) + 5 s`, plus the time to kill what is left.
- `--shutdown-timeout 0` (the default) keeps the current behavior. `AsyncLLM.shutdown()` now runs off the event loop there too.

With `--shutdown-timeout 2`, 8ba921b0b3 gave in-flight RPCs exactly 2 s, so the stream was cut at +2.0 s (170/4000). Its decode leg also failed: EngineCore's deadline was about 7 s, and the read came at +8 s. With a request still being preprocessed at SIGTERM, cbe28ee5e9 started EngineCore's shutdown 0.1 s after SIGTERM. `AsyncLLM.shutdown()` closes the renderer's executor first, so the request failed while its image was being processed: `INVALID_ARGUMENT: multimodal placeholder validation failed: cannot schedule new futures after shutdown`.

**Why the overlapped variant aborts in-flight prefills.** When SIGTERM arrived, its prefill server logged `EngineCore: draining in-flight requests count=16`: the second wave had reached the server before SIGTERM but was still in EngineCore's input queue behind the first step. EngineCore rejects every request it reads once its shutdown has started (`_reject_add_in_shutdown`), so those 15 came back as aborts. With this PR the prefill server logged `MPClient: start timeout=64.6s`: EngineCore was signalled 0.4 s after SIGTERM, once all 32 prefills were done.

"""Reproducer for `vllm serve --grpc` ignoring --shutdown-timeout.

Needs `pip install "vllm[grpc]"` (grpcio + smg-grpc-proto). Start the servers
yourself (commands in the PR description), then:

  # 1) in-flight stream on SIGTERM
  python grpc_shutdown_repro.py stream --addr localhost:50051 --pid <server pid>

  # 2) control: plain prefill -> decode handoff, no SIGTERM (must succeed first)
  python grpc_shutdown_repro.py pd --prefill localhost:50051 --decode localhost:50052

  # 3) NIXL handoff: SIGTERM the prefill after its RPC returns, read on decode
  python grpc_shutdown_repro.py handoff --prefill localhost:50051 \
      --prefill-pid <prefill pid> --decode localhost:50052 --delay 8

  # 4) slow preprocessing at SIGTERM: a Qwen3-VL server (SMG_VLLM_MM_PROCESSOR=inprocess)
  #    fetches the request's image from a local server that answers after
  #    --media-delay s; SIGTERM lands --sigterm-after s after the request is sent
  python grpc_shutdown_repro.py mm --addr localhost:50051 --pid <server pid> \
      --model-dir <Qwen3-VL dir> --media-delay 1.5 --sigterm-after 0.05

Options for stream and handoff:
  --hold [KIND]        keep an RPC open on the SIGTERMed server that only ends
                       when the client or server ends it: a router's
                       SubscribeKvEvents stream (kv-events, needs the server's
                       --kv-events-config), or a reflection stream (reflection,
                       the default, works on any server)
  --second-sigterm S   send another SIGTERM S seconds after the first
handoff only:
  --concurrency K --sigterm-during-prefill [--sigterm-delay S]
                       K prefills with distinct prompts, SIGTERM S seconds
                       (default 0.3) after sending them, while they run
  --wave2 W --wave-gap G
                       send the last W of them G seconds after the others, so
                       they reach a server that is busy with the first ones

Prompt token ids are synthetic; any model with a vocabulary > 30000 works. The
stream must outlive the old 5 s grace by a wide margin, so pick --max-tokens
for the model's single-stream speed (e.g. 4000 with --enforce-eager).
"""

import argparse
import json
import os
import random
import signal
import threading
import time
import uuid
from collections import Counter
from concurrent.futures import ThreadPoolExecutor
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from io import BytesIO
from urllib.parse import parse_qs, urlsplit

import grpc

from grpc_reflection.v1alpha import reflection_pb2, reflection_pb2_grpc
from smg_grpc_proto import vllm_engine_pb2 as pb
from smg_grpc_proto import vllm_engine_pb2_grpc as pb_grpc
from smg_grpc_proto.generated import common_pb2


def make_request(input_ids, max_tokens, stream, kv=None):
    kwargs = {}
    if kv is not None:
        kwargs["kv_transfer_params_json"] = json.dumps(kv)
    return pb.GenerateRequest(
        request_id=str(uuid.uuid4()),
        tokenized=pb.TokenizedInput(input_ids=input_ids),
        sampling_params=pb.SamplingParams(
            max_tokens=max_tokens, temperature=0.0, ignore_eos=True
        ),
        stream=stream,
        **kwargs,
    )


def prompt(args, i):
    if args.concurrency == 1:
        return list(range(1000, 1000 + args.prompt_len))
    # Distinct prompts so the prefills miss every prefix cache.
    rng = random.Random(i)
    return [rng.randrange(1000, 30000) for _ in range(args.prompt_len)]


class ExitWatcher:
    """Records when pid exits, polling from the moment SIGTERM is sent."""

    def __init__(self, pid, second_after=None):
        self.pid = pid
        self.exited = None
        os.kill(pid, signal.SIGTERM)
        self.sigterm = time.monotonic()
        self.thread = threading.Thread(target=self._poll, daemon=True)
        self.thread.start()
        if second_after is not None:
            timer = threading.Timer(second_after, self._second)
            timer.daemon = True
            timer.start()

    def _second(self):
        if self.exited is None:
            os.kill(self.pid, signal.SIGTERM)
            print(f"second SIGTERM at {self.since()}", flush=True)

    def _poll(self):
        while True:
            try:
                if psutil.Process(self.pid).status() == psutil.STATUS_ZOMBIE:
                    break
            except psutil.NoSuchProcess:
                break
            time.sleep(0.05)
        self.exited = time.monotonic()

    def since(self, t=None):
        return f"+{(time.monotonic() if t is None else t) - self.sigterm:.1f}s"

    def report(self, timeout):
        self.thread.join(timeout)
        if self.exited is None:
            return "still running"
        return f"{self.since(self.exited)} after SIGTERM"


class Hold:
    """An RPC that stays open until the client or the server ends it."""

    def __init__(self, addr, kind):
        self.release = threading.Event()
        self.ended = None
        self.result = None
        channel = grpc.insecure_channel(addr)
        if kind == "kv-events":
            stub = pb_grpc.VllmEngineStub(channel)
            self.responses = stub.SubscribeKvEvents(common_pb2.SubscribeKvEventsRequest())
            self.responses.initial_metadata()  # the stream is up
        else:
            # The client never half-closes the request stream.
            def requests():
                yield reflection_pb2.ServerReflectionRequest(list_services="")
                self.release.wait()

            stub = reflection_pb2_grpc.ServerReflectionStub(channel)
            self.responses = stub.ServerReflectionInfo(requests())
            next(self.responses)  # the stream is up
        self.thread = threading.Thread(target=self._drain, daemon=True)
        self.thread.start()

    def _drain(self):
        try:
            for _ in self.responses:
                pass
            self.result = "OK"
        except grpc.RpcError as e:
            self.result = f"{e.code().name}: {e.details()}"
        self.ended = time.monotonic()

    def report(self, watcher, timeout):
        self.thread.join(timeout)
        self.release.set()
        if self.ended is None:
            return "still open"
        return f"{self.result}, ended {watcher.since(self.ended)} after SIGTERM"


def run_stream(args):
    hold = Hold(args.addr, args.hold) if args.hold else None
    stub = pb_grpc.VllmEngineStub(grpc.insecure_channel(args.addr))
    ids = prompt(args, 0)
    tokens, finish, error, watcher = 0, None, None, None
    try:
        for resp in stub.Generate(make_request(ids, args.max_tokens, stream=True)):
            if resp.HasField("chunk"):
                tokens += len(resp.chunk.token_ids)
            else:
                finish = resp.complete.finish_reason
            if watcher is None and tokens > 0:
                watcher = ExitWatcher(args.pid, args.second_sigterm)
                time.sleep(0.5)
                try:
                    late = pb_grpc.VllmEngineStub(grpc.insecure_channel(args.addr))
                    next(iter(late.Generate(make_request(ids, 1, stream=False))))
                    print("late RPC: accepted (unexpected)")
                except grpc.RpcError as e:
                    print(f"late RPC: {e.code().name}")
    except grpc.RpcError as e:
        error = f"{e.code().name}: {e.details()}"
    t_end = time.monotonic()
    if watcher is None:
        raise SystemExit(f"stream produced no tokens: finish={finish} error={error}")
    print(
        f"stream: tokens={tokens}/{args.max_tokens} finish={finish} error={error} "
        f"ended={watcher.since(t_end)} after SIGTERM"
    )
    if hold is not None:
        print(f"held RPC: {hold.report(watcher, args.exit_timeout)}")
    print(f"server exit: {watcher.report(args.exit_timeout)}")


def generate(stub, req, timeout=None):
    """One non-streaming Generate: (complete, error)."""
    try:
        complete = None
        for resp in stub.Generate(req, timeout=timeout):
            complete = resp.complete
        return complete, None
    except grpc.RpcError as e:
        return None, f"{e.code().name}: {e.details()}"


def prefill_then_decode(args, sigterm_pid=None):
    prefill = pb_grpc.VllmEngineStub(grpc.insecure_channel(args.prefill))
    decode = pb_grpc.VllmEngineStub(grpc.insecure_channel(args.decode))
    prompts = [prompt(args, i) for i in range(args.concurrency)]
    hold = Hold(args.prefill, args.hold) if sigterm_pid and args.hold else None
    pool = ThreadPoolExecutor(args.concurrency)

    watcher = None
    first = len(prompts) - getattr(args, "wave2", 0)
    futures = []
    t_send = time.monotonic()
    for i, ids in enumerate(prompts):
        if i == first and i:
            time.sleep(args.wave_gap)
        futures.append(pool.submit(
            generate, prefill,
            make_request(ids, 1, stream=False, kv={"do_remote_decode": True})))
    if sigterm_pid and args.sigterm_during_prefill:
        time.sleep(max(t_send + args.sigterm_delay - time.monotonic(), 0))
        watcher = ExitWatcher(sigterm_pid, args.second_sigterm)
    prefills = [f.result() for f in futures]
    t_prefilled = time.monotonic()
    errors = [e for _, e in prefills if e]
    reasons = Counter(c.finish_reason for c, _ in prefills if c)
    handed_off = sum(1 for c, _ in prefills if c and c.kv_transfer_params_json)
    print(f"prefill done: {handed_off}/{len(prefills)} handed off "
          f"finish={dict(sorted(reasons.items()))} errors={errors[:3]}")
    if watcher is not None:
        print(f"prefill RPCs returned {watcher.since(t_prefilled)} after SIGTERM")
    elif sigterm_pid:
        watcher = ExitWatcher(sigterm_pid, args.second_sigterm)
    time.sleep(args.delay)

    jobs = []
    for ids, (complete, _) in zip(prompts, prefills):
        if complete is not None and complete.kv_transfer_params_json:
            params = json.loads(complete.kv_transfer_params_json)
            req = make_request(ids, args.max_tokens, stream=False, kv=params)
            jobs.append(pool.submit(generate, decode, req, args.exit_timeout))
    decodes = [j.result() for j in jobs]
    ok = [c for c, _ in decodes
          if c and c.finish_reason == "length" and len(c.output_ids) == args.max_tokens]
    finishes = sorted({f"{c.finish_reason}:{len(c.output_ids)}" for c, _ in decodes if c})
    errors = [e for _, e in decodes if e]
    print(f"decode: {len(ok)}/{len(prompts)} ok (finish:tokens {finishes}, "
          f"max_tokens={args.max_tokens}) errors={errors[:3]}")
    if hold is not None:
        print(f"held RPC: {hold.report(watcher, args.exit_timeout)}")
    if watcher is not None:
        print(f"prefill exit: {watcher.report(args.exit_timeout)}")


def run_handoff(args):
    prefill_then_decode(args, sigterm_pid=args.prefill_pid)


class SlowMedia:
    """Serves one random PNG over HTTP, each answer after ?delay= seconds."""

    def __init__(self, size):
        from PIL import Image

        buf = BytesIO()
        Image.frombytes("RGB", (size, size), os.urandom(size * size * 3)).save(buf, "PNG")
        png = buf.getvalue()

        class Handler(BaseHTTPRequestHandler):
            def do_GET(self):
                time.sleep(float(parse_qs(urlsplit(self.path).query)["delay"][0]))
                self.send_response(200)
                self.send_header("Content-Type", "image/png")
                self.send_header("Content-Length", str(len(png)))
                self.end_headers()
                self.wfile.write(png)

            def log_message(self, *args):
                pass

        self.server = ThreadingHTTPServer(("127.0.0.1", 0), Handler)
        threading.Thread(target=self.server.serve_forever, daemon=True).start()

    def url(self, delay):
        port = self.server.server_port
        return f"http://127.0.0.1:{port}/image.png?delay={delay}&n={uuid.uuid4().hex}"


def run_mm(args):
    from transformers import AutoTokenizer

    text = (
        "<|im_start|>user\n<|vision_start|><|image_pad|><|vision_end|>"
        "Describe this image.<|im_end|>\n<|im_start|>assistant\n"
    )
    ids = AutoTokenizer.from_pretrained(args.model_dir).encode(text, add_special_tokens=False)
    media = SlowMedia(args.image_size)
    stub = pb_grpc.VllmEngineStub(grpc.insecure_channel(args.addr))

    def request(delay):
        return pb.GenerateRequest(
            request_id=str(uuid.uuid4()),
            tokenized=pb.TokenizedInput(input_ids=ids, original_text=text),

## Details

**Root cause (P/D flow, NIXL pull mode)**

1. The router sends the prefill leg to P with `kv_transfer_params={"do_remote_decode": true}`.
2. P runs prefill. `request_finished` delays the block free and grants a lease (`kv_lease_duration`, 30 s by default). The Generate RPC returns the handoff params: block ids and the side-channel host and port.
3. The router sends the decode leg to D. D starts heartbeating P as soon as the request enters its scheduler, which extends the lease while the request waits.
4. SIGTERM reaches P. `server.stop(grace=5.0)` returns at once, because the prefill RPC has already finished. `AsyncLLM.shutdown()` then runs without a timeout, so `CoreEngineProcManager.shutdown(None)` calls `shutdown(procs, None)`, which sends SIGTERM, joins for 5 s, and then sends SIGKILL. EngineCore's drain mode (`_handle_shutdown`) would keep stepping while `Scheduler.has_finished_requests()` still counts requests waiting on delayed connector frees, but EngineCore is killed before D reads.
5. D schedules the request, and its NIXL handshake or read fails. With `kv_load_failure_policy="fail"` the request finishes with an error. With `"recompute"`, D recomputes the prompt.

The more decode requests that are queued and heartbeating against blocks held by one prefill, the more requests a single prefill restart fails. Plain streams are also cut: any RPC still running 5 s after SIGTERM is cancelled.

**Fix**

With `shutdown_timeout > 0`, one deadline covers both:

1. `server.stop(grace=max(N, 5 s))` refuses new RPCs at once and resolves when no RPC is live; grpc.aio resolves `stop()` once no live RPC remains. RPCs still running at the deadline are cancelled, which aborts their requests. The 5 s minimum is the grace RPCs already get with `0`.
2. EngineCore keeps running normally while anything could still send it a request. An `_InflightRpcs` server interceptor counts the in-flight `VllmEngine` RPCs, excluding subscriptions (`SubscribeKvEvents`): an RPC counts from the moment the server dispatches it, before its request message is received, until the task that grpc.aio serves it in finishes, whether or not its handler ran. `AsyncLLM.get_num_unfinished_requests()` covers requests that outlive their RPC. Both are checked every 0.1 s, and idle has to hold on two checks in a row, which covers an RPC that gRPC accepted before SIGTERM but has not yet handed to its task. The interceptor costs about 10 µs of server CPU per RPC and nothing measurable per streamed message: in a grpc.aio micro-benchmark on the same machine, 153.5 → 163.0 µs per unary call and 16.6 → 16.7 µs per streamed message. EngineCore has to keep running: it rejects every request it reads once its shutdown has started, including ones the frontend forwarded before SIGTERM (the in-flight row) and ones still being preprocessed (the preprocessing row). Running normally, it also keeps serving NIXL reads.
3. `AsyncLLM.shutdown(timeout=remaining + 5 s)` then runs in an executor, as `launcher.py` does. EngineCore receives SIGTERM, enters drain mode, finishes connector work such as unread NIXL blocks, and exits. The 5 s floor keeps EngineCore's teardown (KV connector, device memory, shm) from being skipped when a request used the whole budget; before this PR it always had a 5 s join.
4. RPCs still open 5 s after EngineCore has stopped, such as a `SubscribeKvEvents` stream, are cancelled.
5. A second SIGTERM or SIGINT calls `server.stop(None)`, which cancels every RPC and so aborts their requests. EngineCore is then left with connector work only.

**Why EngineCore is not signalled at SIGTERM, unlike HTTP**

The in-flight row. The HTTP path signals the engine first and relies on `_reject_add_in_shutdown` for requests that arrive during the drain; #61562 documents that requests still queued at that point return `finish_reason=abort`. Here `server.stop()` already refuses new requests, so EngineCore does not need to reject any, and keeping it running until the in-flight requests are done serves all of them. Connector work gets the same deadline either way.

**Limitations**

- RPCs still running at `max(N, 5 s)` are cancelled.
- A prefill holding blocks that no decode will read waits for the lease to expire (`kv_lease_duration` after the last heartbeat) or until `max(N, 5 s) + 5 s`.
- The 5 s floor covers a normal teardown. An EngineCore whose workers do not exit within `VLLM_WORKER_SHUTDOWN_TIMEOUT_SECONDS` takes longer, and is SIGKILLed at the deadline plus 5 s when a request used the whole budget.
- A second signal does not cut connector work short.
- An RPC that gRPC accepted before SIGTERM but has not handed to its task within one check interval (0.1 s) is not counted yet, and its request can be rejected by EngineCore, as on the HTTP path.
- Supervisors must allow more than `max(N, 5 s) + 5 s`; for example, Kubernetes `terminationGracePeriodSeconds` must exceed that.
- The Rust frontend's `--grpc-port` listener is a separate path and is not changed.

No open PR touches this shutdown path. #56886 is the Rust frontend's discovery withdrawal, and #61562 is the HTTP multi-API-server path.
