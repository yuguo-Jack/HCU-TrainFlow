# [Bugfix]: A timed-out overflow dequeue permanently desynchronizes the shm_broadcast stream

[Upstream PR](https://github.com/vllm-project/vllm/pull/64234) · state: open · merged: False

## Original PR description



## Overview
Fixes https://github.com/vllm-project/vllm/issues/64239
With overflow, the ring slot holds only a 1-byte marker and the payload travels
over ZMQ. The reader committed the slot when the `with acquire_read(...)` block
exited, i.e. before `dequeue` received the payload. If that receive timed out,
the slot was already consumed and the payload stayed forgotten in the socket, so
the next overflow dequeue returned the *previous* message's payload — the wrong
object, silently, with no sequence number or ack to catch it. This PR moves the
receive inside the slot's lifetime, so a timed-out message is redelivered
instead of shifting the stream.

## Claims

- A timed-out overflow `dequeue` no longer consumes the ring slot; the message
  is redelivered on the next call.
- Caller exceptions after delivery still release the slot (previous `finally`
  semantics preserved).
- Remote-reader path, tensor arena and wire format unchanged.

## Validation

- `python -m pytest tests/distributed/test_shm_broadcast.py -q` -> 61 passed
  (60 existing + `test_overflow_timeout_keeps_slot_for_redelivery`).
- CI does not exercise a real `collective_rpc` timeout with >16 MiB payloads.

## Details

Root cause: exiting `with acquire_read(...)` sets the read flag and advances
`current_idx`, but the payload was read *after* the block. The protocol has no
sequence number or ack, so a timeout caused a permanent, silent shift.

Reachable via `collective_rpc`, which dequeue worker responses with a timeout
(default 300s); responses >= `VLLM_MQ_MAX_CHUNK_BYTES_MB` (default 16 MiB) take
the overflow path.

Fix: receive the payload inside the slot's lifetime and raise
`_PayloadNotDelivered` (a `TimeoutError` subclass) to tell `acquire_read` to
skip the commit; the commit is extracted into `_commit_read()`. Tradeoff: a
timed-out message is retried rather than dropped.
