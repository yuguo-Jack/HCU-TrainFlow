# feat(parser): parser cache for streaming chat derender

[Upstream PR](https://github.com/vllm-project/vllm/pull/58417) · state: open · merged: False

## Original PR description

Part of #57571.

implements the parser cache on OnlineDerenderer for streaming chat derender to avoid redundant history replay on each chunk.

summary:
- in-memory lru parser cache directly on OnlineDerenderer instance keyed by (request_id, choice_index)
- cache entries store (parser, detok_state, chunk_count, timestamp)
- on cache hit with matching chunk count, reuses the parser and incremental detokenizer state directly and skips replay
- pops entry while in use; if parse_delta fails the entry is dropped
- finish chunks evict from cache, abandoned streams expire via ttl
- opt-in via `--parser-cache-size` with default 0 (off switch)
- added on/off parity and cache lifecycle unit tests + updated derenderer docs

tool call id changes have been pulled out for a separate pr as discussed.

cc @hickeyma

- hickeyma · CHANGES_REQUESTED · 2026-10-12T10:33:04Z · [source](https://github.com/vllm-project/vllm/pull/58417#pullrequestreview-5489511217)

Thanks for the PR @devtyagi3909. This doesn't match what we agreed in #57571 however, so I'm requesting changes before I review the code.

The cache isn't wired in. `ParserCacheManager.get`/`put` are never called, so the flag does nothing and replay still runs on every chunk. It needs to go into `_derender_chat_stream_parsed`. From the design we settled on, it's also missing:

- `detok_state` and the chunk count in the entry
- taking the entry out while it's in use and not putting it back if `parse_delta` raises
- the TTL and eviction on the finish chunk
- the lock and dict on the `OnlineDerenderer` instance with `--parser-cache-size 0` as the off switch

The tool call ID changes should come out. We agreed on a separate PR, done in `online_derenderer.py` where `tc.id` is already rewritten. Here they change `make_tool_call_id` and the regular chat completions streaming path which wasn't in scope. Same for the `OpenAIServingChat` changes.

Tests and update to doc is missing. The on/off parity tests are important to be added..

Can you resolve DCO and rebase? Please change `Closes #57571` to `Part of`, since the tool call ID work is still open.
