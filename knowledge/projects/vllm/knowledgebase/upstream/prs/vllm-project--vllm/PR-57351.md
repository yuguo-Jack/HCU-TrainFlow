# [Bugfix][NVFP4 MoE] Pad gated intermediate for FlashInfer/CUTLASS

[Upstream PR](https://github.com/vllm-project/vllm/pull/57351) · state: open · merged: False

## Original PR description

Fixes #57125.

FLASHINFER_CUTLASS NVFP4 MoE raised `NotImplementedError` when TP sharding left stacked gate+up rows unaligned for `swizzle_blockscale` (Qwen3.8-Flash-Next, intermediate 640, TP=4 → pad_size 64). Pad each projection before swizzle, same 64/128 rule as the TRTLLM path, and record the padded intermediate size.

#48624 is related but still open; it always aligns gated to 128, drops the padded size, and has no test for this raise.

```
PYTHONPATH=. .venv/bin/python -m pytest tests/quantization/test_trtllm_nvfp4_hidden_dim_padding.py -v --noconftest
```

5 passed.

AI assistance was used to investigate the NVFP4 MoE padding path and implement this change. Every changed line has been reviewed by the human submitter.
