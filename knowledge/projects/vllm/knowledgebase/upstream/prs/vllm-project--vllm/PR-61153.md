# [Bugfix][Spec Decode] Refresh block verification RNG per round

[Upstream PR](https://github.com/vllm-project/vllm/pull/61153) · state: open · merged: False

## Overview

Fixes the cross-round RNG reuse that biases V2 block verification at nonzero temperature. Closes #61114.

No open PR found by issue-number search addresses this bug; the broader speculative-decoding search results are unrelated feature/model work.

## Claims

- Gives each block-verification round a request-local RNG stream keyed by its starting position.
- Applies the round key to acceptance uniforms and probabilistic draft Gumbel noise, including the shared DFlash2/LiLiCorr candidate walk and watermark fallback.
- Preserves existing standard-verification RNG streams and batch invariance.

## Validation

- Exact issue reproducer encoded as a 100,000-request CUDA regression; all five generated positions remain within `0.01` of the expected `P(token=0) = 0.5`.
- Full neighboring CUDA suites:
  - `python -m pytest -q tests/v1/worker/test_gpu_gumbel_sample.py tests/v1/spec_decode/test_rejection_sampler_utils.py`
  - Result: `83 passed`.
- End-to-end V2 generation on an NVIDIA RTX 3050:
  - Model: `Qwen/Qwen3-0.6B`
  - Config: n-gram drafter, `num_speculative_tokens=2`, `rejection_sample_method="block"`, temperature `0.8`, 16 output tokens.
  - Result: engine initialized with the V2 runner and completed generation successfully.
- Full DFlash2/LiLiCorr CUDA suites: `52 passed`.
- Full Gumbel-watermark and rejection-sampler CUDA suites: `87 passed`.
- The focused multi-round candidate-walk and non-null watermark round-key tests: `3 passed`.
- All changed-file pre-commit hooks passed, including Ruff, mypy, test tethering, SPDX, and import-policy checks.

## Details

Block verification evaluates every draft row, including rows after the ultimately accepted prefix. Those uniforms become conditioned on the current round's outcome. Keying them only by `(seed, absolute_position)` reuses that conditioned randomness when a later round revisits the same position. Probabilistic draft Gumbel draws have the same cross-round problem.

The fix mixes the round's starting position into the request seed. That position strictly advances after every round, is available to both drafting and verification, and is independent of batch composition. The extra work is one integer mix in block mode, with no CPU/GPU synchronization or mutable per-request counter. Standard verification remains unchanged.
