# [Bugfix][Model Loader] Validate local safetensors metadata headers

[Upstream PR](https://github.com/vllm-project/vllm/pull/57975) · state: closed · merged: False

## Original PR description

## Purpose

Related to #29762. Reject incomplete local safetensors headers before using their declared length as a read size. A Git LFS pointer saved as `.safetensors` now produces an error identifying the path and explaining how to download the actual checkpoint, rather than a misleading memory failure.

Preserves valid JSON metadata, including `__metadata__`. This does not address MemoryErrors from valid checkpoints, validate tensor payloads, or change model loading or quantization behavior.

Duplicate check: the open issue-number search finds this PR only. The related weight-verification and index-assignment PRs address different loader behavior.

## Test Plan

Tiny temporary files cover valid headers with and without `__metadata__`, empty/short length prefixes, declared lengths exceeding the file (including `2**64 - 1`), and a recognizable Git LFS pointer. No model download or GPU is required.

```bash
.venv/bin/python -m pytest tests/transformers_utils/test_utils.py -q

.venv/bin/pre-commit run mypy-3.12 --hook-stage manual --files vllm/transformers_utils/utils.py tests/transformers_utils/test_utils.py
git diff --check
```

## Test Result

- Before the fix: 5 failed, 6 passed. Failures exposed short-prefix errors, acceptance of a truncated header, an overflowing read size, and a Git LFS pointer producing `MemoryError`.
- After rebasing onto upstream `4f1451679088e5832bce0965a254295c854aaa09`: 11 passed, 15 warnings in 0.04s on macOS ARM64 / Python 3.12. Warnings concern the unbuilt source version and deprecated Torch JIT APIs.

- Rechecked removal of `skip_global_cleanup`: the first existing test passed, then the repository cleanup fixture segfaulted in `torch.accelerator.empty_host_cache` (exit 139). Retained the repository-supported marker. Test assertions and other fixtures remain intact.
