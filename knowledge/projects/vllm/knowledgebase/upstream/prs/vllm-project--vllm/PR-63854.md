## Summary

- Add `MORIIO_HANDSHAKE_VERSION` constant and `handshake_version`/`mode` fields to `MoRIIOAgentMetadata`
- `_validate_handshake_compat()` in `MoRIIOConnectorWorker` checks version mismatch (hard reject), mode mismatch (warn), block_len mismatch (hard reject), attn_backend mismatch (warn)
- Legacy peers (version=0) accepted with warning for rolling upgrades
