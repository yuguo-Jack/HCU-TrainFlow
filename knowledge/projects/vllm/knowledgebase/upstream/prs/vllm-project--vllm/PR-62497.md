# [Test][Multimodal] Add end-to-end CLI test for vllm bench mm-processor

[Upstream PR](https://github.com/vllm-project/vllm/pull/62497) · state: open · merged: False

## Original PR description

## Overview

Adds an end-to-end CLI test for `vllm bench mm-processor`, which previously had only argument- and dataset-level coverage.

## Claims

- Runs the CLI on `Qwen/Qwen2-VL-2B-Instruct` with dummy weights and 3 random-mm image requests; asserts success, completion, finite per-stage timings, and encoder invocation.
- Runs in the existing "Benchmarks CLI" CI group; no CI or runtime code changes.

## Validation

Covered by the `Benchmarks CLI` group (H200 MIG 18GB). CI result will be linked here once the run completes.

## Details

`--load-format dummy` and `--enforce-eager` keep the run small. Asserting `preprocessor_total_ms` catches stats-output regressions that an exit-code-only test would miss.
