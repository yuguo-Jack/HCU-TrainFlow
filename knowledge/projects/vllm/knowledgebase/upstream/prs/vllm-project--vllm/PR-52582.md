# fix: avoid overlapping stores in XPU KV cache kernel

[Upstream PR](https://github.com/vllm-project/vllm/pull/52582) · state: open · merged: False

## Original PR description

## Summary

Fix overlapping stores in the DeepSeek V4 XPU qnorm/RoPE KV kernel.

The KV branch previously performed a bulk store across all 512 KV
elements before separately storing the rotated RoPE region. These
stores overlap in the RoPE region and can result in nondeterministic
KV cache contents.

The bulk store is now masked to `NOPE_DIM`, matching the existing
Q-branch pattern:

```python
tl.store(kv_out_base + offs, kv_full, mask=offs < NOPE_DIM)
