# [KV Connector] Preserve divergent hybrid hits with mixed connectors

[Upstream PR](https://github.com/vllm-project/vllm/pull/63041) · state: open · merged: False

## Original PR description

## Overview

Fixes #62862. A mixed `MultiConnector` now preserves divergent local hybrid prefix hits when a capable child such as NIXL can restore the missing recurrent state. An incapable child cannot be selected at that divergent boundary.

## Claims

- Advertise divergent-hit support when any child supports it, and route divergent lookups only to capable children. If none matches, the scheduler falls back to the shared local cache boundary.
- Add scheduler regressions for both child-selection outcomes and a real P/D serving regression using NIXL plus offloading on Qwen3.5-0.8B.

## Validation

Both outputs matched. This is a one-run functional and transfer-volume check, not a throughput or RDMA benchmark. The new serving test failed with the original capability check (`0` local hits, unchanged transfer bytes) and passed with the fix (`576` local hits, fewer transfer bytes).

## Details

1. On decode, local full-attention blocks can survive farther than the recurrent-state cache. The original `all(...)` capability check disabled the divergent path for NIXL plus offloading even when NIXL could restore state.
2. `MultiConnector` now reports support if any child is capable. At a divergent boundary it asks only capable children for an external match, including nested composites.
3. If no capable child matches, the existing scheduler reconciliation uses the shared local boundary. Regular, non-divergent connector selection is unchanged.
4. The new integration case sends two requests through prefill, NIXL transfer, and decode. It checks deterministic output, a nonzero second-request local hit, and reduced NIXL transfer bytes.

Duplicate-work check on 22 October 2026: issue #62862 has no linked open PR or comments, and searches for `62862`, `MultiConnector divergent`, and `supports_divergent_local_hybrid_hits` found no PR for this behavior. Open #52774 backfills a divergent boundary from the offloading store; this change covers mixed-connector capability and safe selection when NIXL supplies the match.
