# [Bugfix][Tool Parser] Buffer partial opening marker across streaming chunks for InternLM2

[Upstream PR](https://github.com/vllm-project/vllm/pull/57504) · state: open · merged: False

## Original PR description

## Purpose
Fixes #57490.

When the tool call opening token `<|action_start|><|plugin|>` arrives split across streaming chunks (e.g. 1-character or 8-character token deltas), the parser previously advanced `self.position = len(current_text)` and leaked `<|action_start|` or `<|action` as content, permanently dropping the tool call. Additionally, non-streaming `extract_tool_calls` raised `JSONDecodeError` on malformed inputs and dropped valid tool calls due to a missing return statement.

This PR resolves these issues:
1. Buffers partial delimiter candidates using `partial_tag_overlap` so no fragment of `<|action_start|><|plugin|>` is prematurely streamed as plain text content.
2. Accurately extracts the action body, tool name, and incrementally streams arguments diff.
3. Resets streaming state when starting a new stream.
4. Handles malformed JSON gracefully in non-streaming mode.
5. Clears obsolete xfail markers in `tests/tool_parsers/test_internlm2_tool_parser.py` and adds dedicated regression test `test_streaming_split_opening_marker`.
