# [Bugfix][CPU]-Support-grouped-INT8-WNA16-MoE

[Upstream PR](https://github.com/vllm-project/vllm/pull/65314) · state: open · merged: False

## Original PR description

## Motivation

Fixes #65070. CPU WNA16 MoE supported grouped INT4 weights but had no expert
implementation for grouped INT8 weight-only layers, so mixed INT4/INT8
compressed-tensors checkpoints failed during backend selection.

## Modifications

- Add a CPU grouped-INT8 WNA16 fallback that dequantizes weights to BF16 and
  reuses the existing AMX unquantized MoE kernel.
- Keep the existing optimized INT4 CPU path unchanged.
- Add coverage for INT8 capability selection and grouped dequantization.
