# [CI][ROCm] Raise data_parallel_offline.py --timeout in AMD Torchrun + Examples

[Upstream PR](https://github.com/vllm-project/vllm/pull/62520) · state: open · merged: False

## Original PR description

Loading ibm-research/PowerMoE-3b from the shared HF cache took 578s and 621s in amd-ci nightlies. The example kills its worker after the default 300s --timeout, and the job then hangs until the 55-minute job timeout. Pass --timeout 900 in the MI300 job in test-amd.yaml and the MI355 mirror in test_areas/distributed.yaml.
