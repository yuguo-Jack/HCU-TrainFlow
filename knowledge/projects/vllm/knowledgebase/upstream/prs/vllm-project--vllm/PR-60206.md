# [CPU] Collapse MRV2 staged writes and buffer pool on CPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/60206) · state: open · merged: False

## Original PR description

## Overview

Adds CPU stand-ins for the MRV2 buffer mechanisms that exist only to manage a separate device: the pinned round-robin buffer pool and staged writes. Installed through the existing vllm/v1/worker/cpu/shm.py patch hook, so no shared or GPU code changes.

| Class | Upstream | CPU override |
| --- | --- | --- |
| `UvaBufferPool` | Rotates `max_concurrency` pinned buffers, copying the source into the next one each step, so a host write cannot land in a buffer an in-flight DMA is still reading | Returns the source directly; no pool, no rotation, no copy |
| `UvaBackedTensor` | Keeps an unpinned source and republishes it into a pool buffer each step | `gpu` *is* the source, so republishing returns a view |
| `StagedWriteTensor` | Accumulates writes into four lists, then one H2D transfer plus one Triton scatter kernel | `stage_write` assigns in place and `apply_write` is a no-op; also collapses `uva_instead_of_gpu` to a direct allocation |
