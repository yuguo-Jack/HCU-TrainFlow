# [Fast Start] Stop preload groups when a daemon rank exits

[Upstream PR](https://github.com/vllm-project/vllm/pull/63692) · state: closed · merged: True

## Original PR description

## Overview

When a later preload rank exits after READY, the launcher can stay blocked joining an earlier, healthy rank and leave sibling daemons running. Supervise every rank through startup and serving, preserve the original failure status, and clean up the entire group. Related to #56049.

## Claims

- Detect any rank's exit after READY without waiting for an earlier rank to exit first.
- Preserve the failing rank's status before terminating siblings; report signal deaths as `128 + signal` and unexpected clean exits as status 1.
- Terminate and reap started ranks on failure or launcher signals, escalating to `kill()` after a shared ten-second grace period. Stop the health endpoint during cleanup.

## Details

The old serving path joins processes in creation order, so failure of a later rank does not wake a join on an earlier live rank. Startup also derives the exit status after terminating siblings, losing the original signal status. One supervision loop now checks all exits; after readiness it waits on process sentinels. A `finally` block cleans up the processes that actually started, including partial startup and explicit launcher shutdown.

This is launcher failure handling, separate from the engine-side daemon-loss detection merged in #62734. It does not add automatic engine restart or the roadmap's proposed `--supervise` serving mode. The merge preserves the daemon-to-daemon seed configuration from #63088 and reuses the current test helper's log collection.

The regression is selected by the existing distributed preload test steps; their dependencies now include the launcher source. The preload guide documents shutdown, failure status, and stale socket behavior after forced termination. No scheduler/model-runner changes or steady-state GPU synchronization.

Duplicate checks on October 26 covered #56049 and its comments and open PR searches for preload supervision, rank exit, and weight-cache shutdown. No existing PR implements this launcher fix; #62734 addresses the separate engine lifetime contract, and #63088 adds daemon-to-daemon seeding.
