# [Bugfix] Reject heterogeneous vocab with local argmax reduction

[Upstream PR](https://github.com/vllm-project/vllm/pull/51564) · state: closed · merged: False

## Original PR description

## Purpose

Fixes #51561.

The local-argmax path returns before the heterogeneous-vocabulary mask and draft-to-target mapping run. Rejecting the two flags together in `SpeculativeConfig` prevents this unsupported combination from silently reaching the sampler. Other flag combinations are unchanged.

This is separate from #42775 (optional vocabulary padding) and #54780 (tokenizer mode/revision handling). The issue and related PRs were rechecked on September 7.

- Ruff 0.14.0 check/format, whitespace checks, and six relevant repository check scripts pass: SPDX headers, lazy imports, forbidden imports, CUDA API usage, config validation, and boolean context managers.

These Windows CPU checks load the current production configuration module and the unchanged test functions, with transitive dependencies from the previous checkout. They are not a full current-main installation or full-file test run. Ruff explicitly classifies `vllm` as first-party because the checkout is sparse.
