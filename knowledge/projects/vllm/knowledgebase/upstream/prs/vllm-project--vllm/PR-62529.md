# [Tests] Add TP2 PCP2 canonical mapping byte coverage

[Upstream PR](https://github.com/vllm-project/vllm/pull/62529) · state: open · merged: False

## Original PR description



## Overview

Add CPU-only canonical KV mapping byte tests for TP=2, PCP=2, as requested by @Etelis in #61886.

## Claims

- Cover split/packed NHD and HND layouts with interleave sizes 1 and 2 (8 cases).
- Verify canonical reconstruction and per-rank readback against independent reference bytes.
- Preserve existing portability restrictions without production changes.

## Validation

- **35 passed** — full canonical mapping test suite.
- **8/8 mutation tests** detected deliberately incorrect PCP token placement while tiling still passed.
- All applicable pre-commit hooks passed.

```bash
VLLM_TARGET_DEVICE=cpu .venv/bin/python -m pytest -v \
  tests/v1/kv_connector/unit/offloading_connector/test_canonical_mapping.py
```

## Details

Existing tiling and round-trip tests can miss symmetric byte-placement errors. These tests use independently generated K/V, token, and head reference data to verify exact placement.

Reuses existing helpers. CPU-only, 57 lines added to one test file. No GPU execution or production changes.

Related PRs #62160 and #62162 address separate functionality.
