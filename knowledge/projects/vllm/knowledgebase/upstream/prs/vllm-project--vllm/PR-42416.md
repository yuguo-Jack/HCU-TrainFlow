# [Bugfix] Mask stop tokens during structured output

[Upstream PR](https://github.com/vllm-project/vllm/pull/42416) · state: closed · merged: False

## Original PR description

## Purpose

Fixes #42403.

Structured output grammars should not allow EOS/stop tokens while the grammar is still in a non-terminal state. This masks the request's stop token ids from the structured-output bitmask before grammar termination, while preserving normal stop behavior once the grammar has terminated.

**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Avoid masking the backend-provided final EOS mask**

For the outlines and guidance backends, the step after the grammar reaches an accepting state still has `grammar.is_terminated()` return false so that `fill_bitmask()` can emit the required EOS/stop-token-only mask (see `backend_outlines.py` lines 155-159 and `backend_guidance.py` lines 205-208). Masking every `all_stop_token_ids` here removes that only legal terminating token, so structured-output requests using those backends can no longer finish cleanly and may end up with all logits masked to `-inf`. This needs to distinguish “grammar not yet complete” from the backend's final EOS-emission state before clearing stop tokens.
