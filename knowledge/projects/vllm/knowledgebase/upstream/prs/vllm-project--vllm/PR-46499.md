# [Benchmark] Add Gumbel sampler benchmark for speculative decoding

[Upstream PR](https://github.com/vllm-project/vllm/pull/46499) · state: closed · merged: False

## Original PR description

## Summary

Adds a targeted benchmark for the V1 GPU worker Gumbel-max sampler used by Model Runner V2 sampling and Eagle-style speculative decoding.

The default shapes mirror the regression report in #40755:

- `num_tokens=40`, `num_reqs=40`, `vocab_size=151936`
- `num_tokens=240`, `num_reqs=40`, `vocab_size=151936`

The benchmark covers processed-logits writeback by default and can also compare:

- sample-only vs processed-logits writeback via `--include-sample-only`
- default fp32 Gumbel noise vs opt-in fp64 via `--include-fp64`
- scalar draft-step output columns vs per-token output columns via `--scalar-output-col`

For `num_tokens > num_reqs`, the default uses per-token output columns to avoid repeated writes to the same request/column slot during a multi-draft-token microbenchmark. `--scalar-output-col` is still available for measuring the current scalar draft-step path directly.
