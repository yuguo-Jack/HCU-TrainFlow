# [Model][Spec Decode] Migrate Medusa to the Flat Model layout

[Upstream PR](https://github.com/vllm-project/vllm/pull/61357) · state: closed · merged: False

## Original PR description



## Overview

First slice of #61024's "Migrate speculative model code to Flat Model" bullet (RFC #44219). Moves the Medusa draft-model implementation from the legacy `vllm/model_executor/models/` layout into the new `vllm/models/<name>/<hw>/` layout.

## Claims

- Moves `vllm/model_executor/models/medusa.py` to `vllm/models/medusa/common/medusa.py` + a package `__init__.py`, and repoints the `MedusaModel` entry in `registry.py` to `vllm.models.medusa`.
- No logic change. The only diff inside the moved file is fixing `from .utils import maybe_prefix` to the now-external `from vllm.model_executor.models.utils import maybe_prefix` (verified by diffing old vs. new file content).
- Medusa needs only a `common/` directory, no `nvidia`/`amd`/`cpu`/`xpu` split: it's pure `torch.nn` (`Linear`, `SiLU`, `LogitsProcessor`, `ParallelLMHead`), no custom kernels, and has no dependency on any base model's architecture code (unlike e.g. `llama_eagle.py`, which imports `LlamaForCausalLM` directly and so can't move independently of a Llama migration). That made it the first candidate out of the ~30 remaining legacy drafter files.

## Details

**Convention followed:** matches already-migrated families (`deepseek_v32`, `kimi_k3`, `glm5next`, etc.) -- `vllm/models/<name>/__init__.py` re-exporting from `common/<name>.py`. Medusa is the first fully `common`-only package in the new layout (no existing family currently skips the `nvidia`/`amd` split entirely), since it has nothing hardware-specific to split out.

**Duplicate-work check:** searched open issues/PRs (`gh issue list`/`gh pr list`, several keyword variants) before starting; found no PR doing this specific migration. One unrelated open PR (#48715, a large personal-fork rebase) happens to touch `medusa.py` incidentally among dozens of unrelated files -- not a competing Flat Model migration.

**Scope:** this PR only moves Medusa. The other ~30 legacy drafter files (EAGLE/EAGLE3, MTP variants, DFlash) are out of scope here; most are entangled with their own not-yet-migrated base model and need to be scoped individually.

This PR is a draft while the e2e validation gap above is resolved.
