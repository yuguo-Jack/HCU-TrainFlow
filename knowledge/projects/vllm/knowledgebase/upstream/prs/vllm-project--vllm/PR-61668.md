# [Perf][HiSparse] Reuse pinned host pool after graph profiling

[Upstream PR](https://github.com/vllm-project/vllm/pull/61668) · state: closed · merged: True

## Original PR description

HiSparse allocates and pins its host KV pool during profiling, then repeats that work for serving. Keep one engine-scoped pool, keyed by `instance_id`, and reuse its backing for the real KV cache.

Profiling teardown detaches temporary layer caches; connector shutdown or failed initialization releases the pool. This removes the per-layer ownership and preservation flags, leaving CUDA-graph teardown unchanged from main.

Adopts Matthew’s approach in [Etelis/vllm#9](https://github.com/Etelis/vllm/pull/9). Refs #60072; complements #60869.
