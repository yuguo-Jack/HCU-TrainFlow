# [CI] Disable all L4 jobs

[Upstream PR](https://github.com/vllm-project/vllm/pull/62106) · state: closed · merged: False

## Original PR description

## Purpose

Disable all L4 jobs on CI by marking every step with `device: l4` in `.buildkite/test_areas/` as `optional: true` (37 steps across 14 files; the 3 L4 steps that were already optional are unchanged).

Optional steps are not auto-selected on PR or main builds, but they stay listed in the **Run more jobs** input step, so they can still be run by hand. Re-enabling means removing the `optional: true # L4 CI disabled` lines.

Notes:
- No other step `depends_on` any of these L4 step keys, and none have AMD mirrors, so nothing else changes.
- Nightly builds (`NIGHTLY=1`) select every step regardless of `optional`, so L4 jobs will still run in nightly.

## Test Plan

- Parsed all `test_areas/*.yaml`, checked that every `device: l4` step now has `optional: true`.
