# [DeepSeek-V4-P2-01] Make sparse prefill request-local in BI mode

[Upstream PR](https://github.com/vllm-project/vllm/pull/60442) · state: open · merged: False

## Original PR description

## Overview

Make sparse FlashMLA prefill request-local under `VLLM_BATCH_INVARIANT=1`. Each request determines its own gather dimensions, chunk plan, and canonical top-k order, independent of co-batched requests. Default grouped prefill and decode are unchanged; existing cache utilities and the FlashMLA backend are reused.
