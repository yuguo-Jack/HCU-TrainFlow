# feat: add windowed hidden-state capture for vLLM rollout

[Upstream PR](https://github.com/vllm-project/vllm/pull/57736) · state: open · merged: False

## Original PR description

## Overview

This PR adds request-local windowed hidden-state capture for rollouts. Consumers can request hidden states for selected response positions instead of collecting the full response.

The MRV2 optimization copies captured rows asynchronously into pinned CPU memory and reuses output completion synchronization to make the results ready before they are returned.

Implements the windowed capture contract discussed in #56916.

## Key results

- Window capture reduces GPU-to-CPU transfer volume by 93.75% in the measured workload.
- With CUDA graphs enabled, window capture achieves **1.0858x throughput on Qwen3.5-0.8B** and a **1.1033x median paired speedup on DeepSeek-V4.1-Flash**, compared with full-response capture in the same optimized implementation.
- **21 GPU tests passed**, including CUDA Graph output-buffer reuse and completion synchronization.

## Validation

The benchmark runs 128 requests in batches of 16, with two measured rounds after warmup. The requested response window is `[128, 160)`.

Both capture modes export the same 32 hidden-state rows as Base64. Full capture first transfers the complete response to CPU; window capture transfers only the requested rows. The benchmark measures generation and CPU export after warmup, using the same workload and implementation for all four modes.

# SPDX-License-Identifier: Apache-2.0

"""GPU rollout benchmark for PR #57736; same-version full vs window capture.

Run from an editable PR checkout on a CUDA Linux host:
    uv run --no-sync --python .venv/bin/python \
        benchmarks/benchmark_hidden_state_capture.py --model Qwen/Qwen3-8B

Uses fixed-size request batches to compare capture modes under a reproducible
workload. Both capture modes export the same selected window as Base64.
The benchmark records generation, export, and host-copy overhead separately.
"""

import argparse
import base64
import json
import os
import random
import statistics
import subprocess
from pathlib import Path
from time import perf_counter

os.environ.setdefault("VLLM_WORKER_MULTIPROC_METHOD", "spawn")

import numpy as np
import torch

from vllm import LLM, SamplingParams
from vllm.v1.hidden_state_capture import HiddenStateCapturePlan

SCENARIOS = ("off", "full", "window", "never")


def parse_args():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--model", default="Qwen/Qwen3-8B")
    parser.add_argument("--input-tokens", type=int, default=512)
    parser.add_argument("--output-tokens", type=int, default=512)
    parser.add_argument("--window-start", type=int, default=128)
    parser.add_argument("--window-size", type=int, default=32)
    parser.add_argument("--batch-size", type=int, default=16)
    parser.add_argument("--requests", type=int, default=128)
    parser.add_argument("--rounds", type=int, default=5)
    parser.add_argument("--warmup-waves", type=int, default=1)
    parser.add_argument("--dtype", choices=("bfloat16", "float16"), default="bfloat16")
    parser.add_argument("--gpu-memory-utilization", type=float, default=0.85)
    parser.add_argument("--enforce-eager", action="store_true")
    parser.add_argument("--seed", type=int, default=1234)
    parser.add_argument("--atol", type=float, default=0.02)
    parser.add_argument("--rtol", type=float, default=0.02)
    parser.add_argument("--result", type=Path, default=Path("capture_benchmark.json"))
    args = parser.parse_args()
    for name in (
        "input_tokens",
        "output_tokens",
        "window_size",
        "batch_size",
        "requests",
        "rounds",
        "warmup_waves",
    ):
        if getattr(args, name) <= 0:
            parser.error(f"--{name.replace('_', '-')} must be positive")
    if (
        not 0
        <= args.window_start
        < args.window_start + args.window_size
        <= args.output_tokens
    ):
        parser.error("the window must lie inside the generated response")
    if args.requests % args.batch_size:
        parser.error("--requests must be divisible by --batch-size")
    return args


def plans_for(scenario, count, args):
    if scenario == "off":
        return None
    if scenario == "full":
        start, end = 0, args.output_tokens
    elif scenario == "window":
        start, end = args.window_start, args.window_start + args.window_size
    else:
        start = args.output_tokens + 128
        end = start + args.window_size
    return [
        HiddenStateCapturePlan.from_window(
            request_id=f"bench-{i}",
            prompt_len=args.input_tokens,
            start=start,
            end=end,
            collection_id="gpu-benchmark",
            coordinate="response",
            min_rows=end - start,
        )
        for i in range(count)
    ]


def selected_states(output, scenario, args):
    capture = output.hidden_state_capture
    if scenario in ("off", "never"):
        if capture is not None:
            raise RuntimeError(f"{scenario}: unexpected captured result")
        if (
            scenario == "never"
            and output.hidden_capture_skip_reason != "ended_before_window"
        ):
            raise RuntimeError(f"unexpected skip: {output.hidden_capture_skip_reason}")
        return None
    if capture is None:
        raise RuntimeError(f"capture failed: {output.hidden_capture_skip_reason}")
    if capture.hidden_states.device.type != "cpu" or capture.copied_bytes <= 0:
        raise RuntimeError("expected actual GPU-to-CPU capture")
    start = args.input_tokens - 1
    if scenario == "full":
        expected = np.arange(start, start + args.output_tokens)
        rows = capture.hidden_states[
            args.window_start : args.window_start + args.window_size
        ]
    else:
        start += args.window_start
        expected = np.arange(start, start + args.window_size)
        rows = capture.hidden_states
    np.testing.assert_array_equal(capture.hidden_positions, expected)
    if capture.hidden_states.shape[0] != len(expected):
        raise RuntimeError("hidden-state row count does not match positions")
    return rows


def generate(llm, prompts, params, plans):
    return llm.generate(prompts, params, hidden_state_capture=plans, use_tqdm=False)


def validate(llm, prompts, params, args):
    reference_tokens = None
    reference_states = None
    max_error = 0.0
    for scenario in SCENARIOS:
        outputs = generate(
            llm, prompts, params, plans_for(scenario, len(prompts), args)
        )
        tokens = [list(out.outputs[0].token_ids) for out in outputs]
        if any(len(ids) != args.output_tokens for ids in tokens):
            raise RuntimeError("generation did not produce the requested token count")
        if reference_tokens is None:
            reference_tokens = tokens
        elif tokens != reference_tokens:
            raise RuntimeError(f"{scenario}: generated tokens differ from capture-off")
        rows = [selected_states(out, scenario, args) for out in outputs]
        if scenario == "full":
            reference_states = [row.clone() for row in rows]
        elif scenario == "window":
            for actual, expected in zip(rows, reference_states):
                torch.testing.assert_close(
                    actual, expected, atol=args.atol, rtol=args.rtol
                )
                max_error = max(
                    max_error, (actual.float() - expected.float()).abs().max().item()
                )
        del outputs, rows
    print(
        f"Correctness PASS: all scenarios, batch={len(prompts)}, "
        f"max_abs_error={max_error:.6g}",
        flush=True,
    )
    return {"batch_size": len(prompts), "max_abs_error": max_error}


def run_round(llm, prompts, params, scenario, args, round_id):
    plans = plans_for(scenario, args.batch_size, args)
    generation_s = export_s = 0.0
    copied_bytes = copy_wait_ms = encoded_bytes = 0
    ttft_ms, mean_itl_ms = [], []
    for offset in range(0, len(prompts), args.batch_size):
        wave = prompts[offset : offset + args.batch_size]
        started = perf_counter()
        outputs = generate(llm, wave, params, plans)
        generation_s += perf_counter() - started

        # Validate outside the measured generation and export regions.
        for out in outputs:
            count = len(out.outputs[0].token_ids)
            if count != args.output_tokens:
                raise RuntimeError(f"expected {args.output_tokens} tokens, got {count}")
            selected_states(out, scenario, args)
            if out.metrics is None or out.metrics.first_token_ts <= 0:
                raise RuntimeError("missing engine timing metrics")
            stats = out.metrics
            ttft_ms.append(stats.first_token_latency * 1000)
            if count > 1:
                mean_itl_ms.append(
                    (stats.last_token_ts - stats.first_token_ts) * 1000 / (count - 1)
                )
            if out.hidden_state_capture is not None:
                copied_bytes += out.hidden_state_capture.copied_bytes
                copy_wait_ms += out.hidden_state_capture.copy_ms

        # Same final window and encoding work for full and window capture.
        started = perf_counter()
        if scenario in ("full", "window"):
            for out in outputs:
                states = out.hidden_state_capture.hidden_states
                if scenario == "full":
                    states = states[
                        args.window_start : args.window_start + args.window_size
                    ]
                byte_view = states.contiguous().view(torch.uint8).numpy()
                encoded = base64.b64encode(memoryview(byte_view))
                encoded_bytes += len(encoded)
                del encoded
        export_s += perf_counter() - started
        del outputs

    total_s = generation_s + export_s
    return {
        "round": round_id,
        "scenario": scenario,
        "generation_s": generation_s,
        "generation_plus_export_s": total_s,
        "generation_output_tokens_s": args.requests * args.output_tokens / generation_s,
        "end_to_end_output_tokens_s": args.requests * args.output_tokens / total_s,
        "ttft_p95_ms": float(np.percentile(ttft_ms, 95)),
        "per_request_mean_itl_p95_ms": float(np.percentile(mean_itl_ms, 95))
        if mean_itl_ms
        else None,
        "d2h_mib_per_request": copied_bytes / args.requests / 2**20,
        "copy_wait_ms_per_request": copy_wait_ms / args.requests,
        "cpu_export_ms_per_request": export_s * 1000 / args.requests,
        "base64_bytes_per_request": encoded_bytes / args.requests,
    }


def git_head():
    try:
        return subprocess.check_output(
            ["git", "rev-parse", "HEAD"],
            cwd=Path(__file__).resolve().parents[1],
            text=True,
            stderr=subprocess.DEVNULL,
        ).strip()
    except (OSError, subprocess.CalledProcessError):
        return "unknown"


def main():
    args = parse_args()
    if not torch.cuda.is_available() or torch.version.cuda is None:
        raise SystemExit("This benchmark requires an NVIDIA CUDA GPU and CUDA PyTorch.")
    import vllm

    metadata = {
        "args": {
            key: str(val) if isinstance(val, Path) else val
            for key, val in vars(args).items()
        },
        "git_head": git_head(),
        "vllm": vllm.__version__,
        "torch": torch.__version__,
        "cuda": torch.version.cuda,
        "gpu": torch.cuda.get_device_name(0),
        "gpu_memory_gib": torch.cuda.get_device_properties(0).total_memory / 2**30,
        "environment": {
            key: value
            for key, value in os.environ.items()
            if key
            in (
                "CUDA_VISIBLE_DEVICES",
                "VLLM_WORKER_MULTIPROC_METHOD",
                "VLLM_BATCH_INVARIANT",
                "VLLM_USE_V2_MODEL_RUNNER",
                "VLLM_ATTENTION_BACKEND",
                "VLLM_GPU_SYNC_CHECK",
                "CUDA_LAUNCH_BLOCKING",
            )
        },
        "scope": (
            "TP=1 PP=1; fixed-size batches; final hidden state; "
            "Base64 encoding of selected window"
        ),
        "copy_timer_scope": (
            "Host-side allocation/submission for async capture; "
            "blocking capture also includes any associated wait"
        ),
    }
    print(json.dumps(metadata, indent=2), flush=True)
    llm = LLM(
        model=args.model,
        dtype=args.dtype,
        seed=args.seed,
        tensor_parallel_size=1,
        pipeline_parallel_size=1,
        max_model_len=args.input_tokens + args.output_tokens + 16,
        max_num_seqs=args.batch_size,
        gpu_memory_utilization=args.gpu_memory_utilization,
        async_scheduling=False,
        enable_prefix_caching=False,
        enforce_eager=args.enforce_eager,
        disable_log_stats=False,
    )
    tokenizer = llm.get_tokenizer()
    source = tokenizer.encode(
        "Explain how GPUs accelerate matrix multiplication and model inference. "
        "Give several examples and continue with technical details. ",
        add_special_tokens=False,
    )
    if not source:
        raise RuntimeError("tokenizer produced an empty prompt")
    prompts = []
    for i in range(args.requests):
        shift = i % len(source)
        rotated = source[shift:] + source[:shift]
        ids = (rotated * ((args.input_tokens + len(rotated) - 1) // len(rotated)))[
            : args.input_tokens
        ]
        prompts.append({"prompt_token_ids": ids})
    params = SamplingParams(
        temperature=0,
        max_tokens=args.output_tokens,
        min_tokens=args.output_tokens,
        ignore_eos=True,
        detokenize=False,
    )
    correctness = validate(llm, prompts[: args.batch_size], params, args)
    for scenario in SCENARIOS:
        print(f"Warmup: {scenario}", flush=True)
        for _ in range(args.warmup_waves):
            outputs = generate(
                llm,
                prompts[: args.batch_size],
                params,
                plans_for(scenario, args.batch_size, args),
            )
            del outputs

    print(
        "\nround scenario  gen_s    total_s   tok/s     TTFTp95  meanITLp95  "
        "D2HMiB/req  copy_host_ms/req  export_ms/req",
        flush=True,
    )
    records = []
    rng = random.Random(args.seed)
    for round_id in range(1, args.rounds + 1):
        order = list(SCENARIOS)
        rng.shuffle(order)
        for scenario in order:
            row = run_round(llm, prompts, params, scenario, args, round_id)
            records.append(row)
            itl = row["per_request_mean_itl_p95_ms"]
            itl_text = f"{itl:.3f}" if itl is not None else "N/A"
            print(
                f"{round_id:5d} {scenario:8s} {row['generation_s']:8.3f} "
                f"{row['generation_plus_export_s']:9.3f} "
                f"{row['end_to_end_output_tokens_s']:9.2f} "
                f"{row['ttft_p95_ms']:8.3f} {itl_text:>10s} "
                f"{row['d2h_mib_per_request']:11.4f} "
                f"{row['copy_wait_ms_per_request']:17.3f} "
                f"{row['cpu_export_ms_per_request']:13.3f}",
                flush=True,
            )
            args.result.parent.mkdir(parents=True, exist_ok=True)
            args.result.write_text(
                json.dumps(
                    {
                        "metadata": metadata,
                        "correctness": correctness,
                        "records": records,
                    },
                    indent=2,
                ),
                encoding="utf-8",
            )

    print("\nSummary: median [min, max] across rounds", flush=True)
    for scenario in SCENARIOS:
        rows = [row for row in records if row["scenario"] == scenario]
        for key in (
            "generation_plus_export_s",
            "end_to_end_output_tokens_s",
            "d2h_mib_per_request",
        ):
            values = [row[key] for row in rows]
            print(
                f"{scenario:8s} {key:30s} {statistics.median(values):.4f} "
                f"[{min(values):.4f}, {max(values):.4f}]"
            )
    speedups = []
    for round_id in range(1, args.rounds + 1):
        by_mode = {row["scenario"]: row for row in records if row["round"] == round_id}
        speedups.append(
            by_mode["full"]["generation_plus_export_s"]
            / by_mode["window"]["generation_plus_export_s"]
        )
    print(
        "\nWindow vs full, median paired total-time speedup: "
        f"{statistics.median(speedups):.4f}x",
        flush=True,
    )
    print(f"Raw results saved to: {args.result.resolve()}", flush=True)
    print("meanITLp95: P95 of per-request mean ITL.")
    print("copy_wait_ms_per_request: measured host-side copy overhead.")


if __name__ == "__main__":
    main()

## Details

MRV2 queues D2H copies into fresh pinned CPU buffers. The existing AsyncOutput completion event ensures that copying finishes before those buffers are read. Other capture-helper callers retain the blocking default.

For single-GPU synchronous scheduling with CUDA graphs enabled, the implementation uses non-sleeping output-event waits. Other configurations retain sleeping waits. Completion is still checked before results are consumed.

All four benchmark modes use the same output-event wait policy, making the full-versus-window comparison consistent. The optimized path combines selective D2H transfer with the MRV2 copy/synchronization improvements.

The Qwen3.5-0.8B benchmark uses a single GPU; the DeepSeek-V4.1-Flash benchmark uses TP=4 and PP=1. Both use synchronous scheduling with CUDA graphs enabled.

## 第一性原理：审计所采用的必要契约

R1. 对 L 个 prompt token，第 j 个生成 token 由 h[L-1+j] 预测。因此 response [a,b) 对应 absolute [L-1+a,L-1+b)。这里返回的是预测该 response token 的 hidden state，不是消耗该 token 后的下一位置状态。RFC #56916 明确规定这一语义。
R2. 一个实际 forward 的第 i 个请求占用 query_start_loc[i:i+2] 指定的行，其绝对起点为该 forward 开始前的 computed token 数。必须先对所有请求推进 row offset，再按各自窗口取交集；不能按采集请求重新紧密编号。
R3. speculative forward 可以产生未被接受的候选 row。GPU 先按窗口复制，scheduler 再按实际交付的 token 区间过滤；同一 mask 必须用于 positions 和 states。
R4. CPU payload 可读必须晚于 D2H 完成，且 graph output 在覆盖前必须完成读取。MRV2 当前在 main stream 排队复制，output-copy stream wait_stream(main_stream) 后记录 event，get_output 同步 event，建立传递的 happens-before。blocking=True/False 不改变这个就绪契约。
R5. 每个请求独立拥有 plan/buffer；窗口完成和请求终止需要清理 worker plan。输出结果不得因为 DELTA coalescing、内部 ID 改写或 FINAL_ONLY 延迟而丢失。
R6. 校验对象必须是实际执行的参数；不支持的组合应明确拒绝或返回说明，不能先校验另一份参数再执行不兼容请求。
R7. copied_bytes/copy_ms 是提交或执行过的复制开销，不应因 row 后来被过滤、重算或没有新 token 而消失。有效 row 数和复制开销是不同指标。
R8. capture 未开启时不应引入无关调度、模型输出或全局等待策略变化；性能优化需要对应 feature-off 和 CPU 开销证据。

与 RFC 对照：响应坐标、半开窗口、稀疏 hidden_positions 为准、短样本/min_rows、request-local 状态等设计有合理依据。aux capture 只复用模型已有 speculative aux outputs，不能采任意未配置层；PCP/DCP、async scheduling、adaptive verification、encoder-decoder 均被拒绝。以上是支持范围，不是全组合通过证明。
