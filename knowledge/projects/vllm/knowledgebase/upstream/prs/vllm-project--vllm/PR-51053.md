Depends on #50494; must not merge before #50494. This PR is based on #50494 and will be rebased onto `main` after #50494 merges, leaving only the Kimi-K3 follow-up commit.

## Purpose

#50494 adds member-identity routing for pipeline-parallel NIXL push with attention-only HMA layouts. It still explicitly rejects `PP > 1` when the hybrid KV cache contains Mamba/SSM state.

Kimi-K3 uses unified physical cache pages shared by KDA (Mamba/SSM) and MLA layers. This PR extends the member-identity framework from #50494 to:

- route PP-sharded Kimi KDA+MLA members to the corresponding full-model consumer regions;
- build member-major MLA and Mamba conv/SSM descriptors;
- preserve kernel-block geometry for MLA and logical-state geometry for SSM;
- keep decode-side PP and missing, duplicate, ambiguous, or inconsistent member identities fail-closed.
