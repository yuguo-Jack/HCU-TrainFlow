# [Cleanup][Gemma4] Remove tool_parsers/gemma4_utils.py in favor of Transformers v5 chat parsing API

[Upstream PR](https://github.com/vllm-project/vllm/pull/46969) · state: closed · merged: False

## Original PR description

## Purpose

Closes #45605

Restores `vllm/tool_parsers/gemma4_utils.py` as a backward-compatible deprecated wrapper, rather than deleting it outright, to avoid breaking existing user code that imports `parse_tool_calls` or `has_tool_response_tag`.

Both functions now emit `DeprecationWarning` directing users to `tokenizer.parse_response()` from Transformers v5. Internal logic (regex tiers, `_parse_gemma4_args`) is unchanged.

Also updates the stale cross-reference in `vllm/reasoning/gemma4_utils.py` from `tokenizer.parse_chat_response()` to `tokenizer.parse_response()` from Transformers v5.

Note: PR #39070 (bugfix on `gemma4_utils._parse_tool_arguments`) remains relevant since the file is now restored. PR #46475 (adds unit tests for utility modules) is unaffected.

AI assistance was used in authoring this change.
