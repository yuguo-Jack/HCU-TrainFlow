# [ROCm][Feature][MiniMax-M3.1-Flash] Support aiter_sparse_pa on TP2

[Upstream PR](https://github.com/vllm-project/vllm/pull/64581) · state: open · merged: False

## Original PR description



## Overview

MiniMax-M3.1-Flash has 4 KV heads, so with TP2 each rank owns 2 heads. AITER's `aiter_sparse_pa` previously required exactly 1 KV head per rank (==TP4). This PR changes so it also supports 2 heads per rank (or really, >=1 heads).

**Benefit**: In PD disagg, the prefill node can benefit from low TP size. Hence we want to run TP2 with a fast attn kernel
