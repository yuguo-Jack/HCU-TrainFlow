# [XPU] Fix Kimi-Linear model dispatch

[Upstream PR](https://github.com/vllm-project/vllm/pull/63531) · state: closed · merged: True

## Original PR description

This PR is for model enabling, and may not be the most performant way
To successfully run kimi, we also rely on a MLA fix(https://github.com/vllm-project/vllm/pull/63530)

Kimi-Linear currently falls through to the NVIDIA implementation on XPU. It fails while importing the CUDA-only CUTLASS GEMM code; disabling that path still leaves calls to fused MLA ops that are not available on XPU.

Use the existing implementation in `amd.linear` for Kimi-Linear on XPU. Despite the directory name, its portable KDA/MLA path runs on XPU. This reuses existing code rather than adding a separate XPU implementation. Kimi-K3 and MTP keep their current routes. Update the existing ReplaySSM expectation to match the selected implementation.
