# [Bug][HiSparse] Scale shutdown grace period and bound worker joins to prevent ~90s stalls (#61859)

[Upstream PR](https://github.com/vllm-project/vllm/pull/62166) · state: open · merged: False

## Original PR description

## Description

This PR addresses **Issue #61859**, resolving the ~90-second shutdown stall encountered when tearing down HiSparse servers with large pinned host pools (e.g., TP8). 

### Root Cause
1. **Unpin Contention**: Every TP rank calls `cudaHostRegister` on the entire shared `/dev/shm` mmap (`allocate_hisparse_host_pools`). During teardown, graceful unpinning takes considerable time (scaling at roughly `0.15s` per GiB, e.g., ~13.5s for 128 GiB).
2. **Expired Grace Period**: The default worker grace period (`VLLM_WORKER_SHUTDOWN_TIMEOUT_SECONDS = 5`) expired prematurely, forcing premature SIGTERM and SIGKILL fallbacks.
3. **EngineCore Deadlock**: EngineCore blocked indefinitely during multiprocessing atexit process joins on daemon workers without a bounded timeout, leading to silent hangs that required API server force-kills.

### Key Changes Made
1. **Dynamic Shutdown Timeout Scaling (`multiproc_executor.py`)**:
   - Updated `_ensure_worker_termination()` to accept `vllm_config`.
   - Dynamically scales the worker shutdown grace period based on the HiSparse host pool size:
     $$\text{timeout} = \max(\text{VLLM\_WORKER\_SHUTDOWN\_TIMEOUT\_SECONDS}, \lceil \text{pool\_gib} \times 0.15 \rceil)$$
   - Logs the calculated grace period clearly during teardown.
2. **Bounded Worker Process Joins**:
   - Introduced bounded joins (`p.join(timeout=1.0)`) in worker termination loops (for both graceful exits and post-SIGTERM/SIGKILL paths) to reap child processes and prevent Python's multiprocessing atexit hook from blocking indefinitely.
3. **Accurate HiSparse Unpin Logging (`runtime.py`)**:
   - Updated `release_pinned_state()` to include shared host region cleanup within the measured timing block and account for its capacity in freed bytes, logging accurate unpin metrics (`HiSparse: unpinned X GiB of host pool in Y.Ys`).
4. **Unit Tests & Regression Coverage**:
   - Added `test_ensure_worker_termination_scales_timeout_for_hisparse`, `test_ensure_worker_termination_fallback_timeout`, and `test_ensure_worker_termination_forced_kill_joins_procs` under `tests/v1/executor/test_multiproc_executor_timeout.py`.
   - Added connector test coverage under `tests/v1/kv_connector/unit/test_hisparse_connector.py`.
