# [Perf] Kimi K3 Specialized Decode: CuTeDSL Optimized GB300 (1.5-2x)

[Upstream PR](https://github.com/vllm-project/vllm/pull/61867) · state: closed · merged: True

## Original PR description



## Overview

(this PR description was manually written by me)

This is an NVIDIA-developed specialized implementation of Kimi K3 for GB300 that achieves 1.5-2x decode speedups. It supports:
- TP8 and TP16 on GB300
- NoSpec (up to B64) and DSpark verification with 3-7 draft tokens (up to 64 tokens -- B8 for DL7, B16 for DL3)
- Decode context parallelism with DCP=TP (DCP-off also supported)

It is enabled opt-in via `--additional-config '{"decode_backend": "latency_specialized"}'`. All changes are localized to `vllm/models/kimi_k3/nvidia/`.

## Claims

With FP8 KV Cache, FP32 SSM Cache, and model-provider weights:
- TP16, ISL 1, no speculation: decode step **1.79-1.92x faster than stock at B1-B8** (3.90 vs 7.38 ms at B1).
- TP16, DSpark DL7, synthetic acceptance 6: **1.53-1.71x decode tok/s at B1-B8**.
- DL7, ISL 32k, DCP on: **1.36-1.50x (TP8)** and **1.53-1.75x (TP16)** decode tok/s.
- AIME25, GPQA-Diamond and MRCR v2 8-needle match stock within about one standard error, with and without speculation.

## Details

### vLLM Integration

No weight changes were made in this model implementation: it is fully compatible with Aggregated vLLM serving, and falls back to the default implementation for prefills, mixed batches, and large batches.

The specialized decode runtime is implemented via _composition_: a SpecializedDecode object owned by the Kimi LLM model, built when supported (see `unsupported(...)`), and called during forward(). The runtime can opt-out of a batch (e.g. when it has too many tokens) by checking `decode.plan(...) is None`, and fall back to stock forward.

I considered a few alternate designs but ultimately feel like this is the cleanest integration. It uses the ModelState protocol to build the runtime object and hook into initialize_kv_cache().

The rest of the integration is organized into subfolders, e.g. `vllm/models/kimi_k3/specialized_decode/nvidia/cutedsl/kda/` with the specialized implementation(s) for each component.
