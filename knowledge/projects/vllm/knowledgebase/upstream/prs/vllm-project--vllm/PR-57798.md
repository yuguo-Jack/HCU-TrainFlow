# [Bugfix][RL] Load DeepSeek V4 attention sinks through weight_loader

[Upstream PR](https://github.com/vllm-project/vllm/pull/57798) · state: closed · merged: False

## Original PR description

Fix DeepSeek V4 target, MTP, and DSpark sink loading in one model-family PR. The 10 changed call-site files cover CPU/XPU/AMD/NVIDIA target models and XPU/AMD/NVIDIA draft models.



Each site passes its checkpoint tensor and rank head range to `load_padded_attn_sink` from #57797. TP slicing remains in that helper and happens once. The helper builds the full padded runtime tensor and calls the current parameter loader.



Dependency: #57797. Because the shared helper branch is in a fork, GitHub currently compares this PR with upstream `main` and also displays the two helper files. The V4-only delta is [here](https://github.com/Ronald1995/vllm/compare/attn-sink-loader-helper...attn-sink-loader-dsv4-target). After #57797 merges, this PR can be rebased onto `main` and its helper files will disappear from Files changed.
