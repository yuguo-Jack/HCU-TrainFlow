# [Bugfix][Structured Output] Fix race condition in GuidanceBackend.compile_grammar

[Upstream PR](https://github.com/vllm-project/vllm/pull/49083) · state: open · merged: False

## Original PR description

Replace self.serialized_grammar with a local variable to eliminate a race condition in concurrent grammar compilation. The shared instance attribute allowed one request's grammar spec to overwrite another's under the default async thread-pool compilation path, causing silent cross-request schema contamination.
