# [Kernel] Fuse logit softcapping into a single Triton kernel

[Upstream PR](https://github.com/vllm-project/vllm/pull/41779) · state: open · merged: False

## Original PR description

## Purpose

Fuse the 3-op logit softcapping path (`div → tanh → mul`) in
`LogitsProcessor` into a single Triton kernel, eliminating 2 intermediate
tensor allocations and 2 extra kernel launches.

Benefits all models using `final_logit_softcapping` (Gemma 2/3/4, Grok, etc).

## Test Plan

```bash
python benchmarks/kernels/bench_softcap.py
```

The use of `tl.extra.libdevice.tanh` is specific to NVIDIA GPUs. To ensure the kernel is portable across all hardware backends supported by vLLM (such as AMD/ROCm), it is recommended to use `tl.math.tanh` or `tl.tanh` instead.

```suggestion
    x_fp32 = tl.math.tanh(x_fp32)
```

- gemini-code-assist[bot] · comment · 2026-05-06T03:17:28Z · [source](https://github.com/vllm-project/vllm/pull/41779#discussion_r3192783935)

File: `vllm/model_executor/layers/softcap_kernel.py` · line 39

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The Triton kernel uses linear indexing (`X_ptr + offsets`), which assumes the input tensor is contiguous. If a non-contiguous tensor is passed, the kernel will read and write incorrect memory locations. Additionally, `torch.empty_like` preserves the memory layout of the input, so the output would also be non-contiguous if the input is, leading to corrupted results.

```suggestion
    logits = logits.contiguous()
    n_elements = logits.numel()
    out = logits if inplace else torch.empty_like(logits)
```

- gemini-code-assist[bot] · comment · 2026-05-06T03:17:28Z · [source](https://github.com/vllm-project/vllm/pull/41779#discussion_r3192783936)

File: `vllm/model_executor/layers/logits_processor.py` · line None

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The `softcap_logits` function defaults to `inplace=True`. When `self.logits_as_input` is `True`, `logits` is a reference to the `hidden_states` tensor. Modifying it in-place introduces a side effect that can break other components expecting the original hidden states to remain unchanged. The previous implementation was out-of-place and avoided this issue.

```suggestion
                logits = softcap_logits(logits, self.soft_cap, inplace=False)
```
