# [Doc] Document /inference/v1/generate request/response fields and DP rank header

[Upstream PR](https://github.com/vllm-project/vllm/pull/62305) · state: closed · merged: True

## Original PR description

## Purpose

`POST /inference/v1/generate` (token-in/token-out) has no field reference. A web search only surfaces the v0.20 pages, which show the old response format and no way to target a data-parallel rank. `docs/training/sampling_mask.md` also still says the endpoint returns logprob IDs as `token_id:<id>` strings; it now returns an integer `token_id`.

## Changes

- `docs/serving/online_serving/token_in_token_out.md`: how `--enable-scale-out` / `--tokens-only` register the endpoint (and the 403 otherwise), a curl example, request and response field tables, and the `X-data-parallel-rank` header. Existing sections and anchors (`#output-modes`, `#weight-versions`, `#aborting-requests`) are unchanged.
- `docs/training/sampling_mask.md`: `token_id:<id>` strings come from the OpenAI endpoints with `return_tokens_as_token_ids`; `/inference/v1/generate` returns an integer `token_id`.
- `examples/scale_out/token_generation_client.py`: docstring points to the page.
