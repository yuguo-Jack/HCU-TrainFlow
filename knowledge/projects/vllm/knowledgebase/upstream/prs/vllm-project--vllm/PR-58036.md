# [BugFix][CPU] Intersect NIXL KV affinity with sched_getaffinity

[Upstream PR](https://github.com/vllm-project/vllm/pull/58036) · state: open · merged: False

## Original PR description

## Summary

- On CPU, `NixlConnector` reserved one core per NUMA node from host sysfs and called `sched_setaffinity` without intersecting the process cpuset.
- In containers (e.g. Kubernetes static CPU manager), those cores are often outside the cgroup, so init fails with `OSError: [Errno 22] Invalid argument`.
- Intersect each NUMA node's CPUs with `os.sched_getaffinity(0)` before reserving; skip nodes with no overlap. Unit tests cover the issue's cpuset example.

Fixes #58033
