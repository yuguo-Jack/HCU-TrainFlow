# [ROCm] Fix ROCm Attention Backend Slection

[Upstream PR](https://github.com/vllm-project/vllm/pull/42798) · state: open · merged: False

## Original PR description

1. Move `ROCM_AITER_FA` ahead of `ROCM_ATTN`. When AITER MHA is explicitly enabled via env vars (`VLLM_ROCM_USE_AITER=1` + `VLLM_ROCM_USE_AITER_MHA=1`).
2. Skip `ROCM_ATTN` when the model uses sliding-window attention, since `ROCM_ATTN` is currently very slow on SWA.

![high](https://www.gstatic.com/codereviewagent/high-priority.svg)

The `model_config` variable is retrieved using `getattr` with a default of `None`. If `model_config` is `None`, the subsequent call to `model_config.get_sliding_window()` will raise an `AttributeError`. A null check should be added to ensure safety, as `VllmConfig` allows `model_config` to be `None` by default.

```suggestion
    model_config = getattr(vllm_config, "model_config", None)
    return model_config is not None and model_config.get_sliding_window() is not None
```
