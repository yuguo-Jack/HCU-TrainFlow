# [Doc] Document DeepSeek-V4.1-Flash B300 aggregate AgentX config

[Upstream PR](https://github.com/vllm-project/vllm/pull/62670) · state: closed · merged: True

## Original PR description



## Overview

Document the DeepSeek-V4.1-Flash B300 aggregate AgentX config from [SemiAnalysisAI/InferenceX#4332](https://github.com/SemiAnalysisAI/InferenceX/pull/4332) ([run 39351570949](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/39351570949)). The recipe already covers B200 aggregate and B300/GB300 Dynamo disaggregated serving; B300 aggregate is missing. No open PR covers it.

## Claims

Guide text only, in `recipes/models/deepseek-ai/DeepSeek-V4.1-Flash.yaml`. The command builder output does not change.

- New subsection **Aggregate serving on B300** under `## AgentX tuning on NVIDIA GPUs`, with the image, checkpoint and a link to the full InferenceX config.
- One table gives per-point `--max-num-seqs`, `--max-num-batched-tokens`, `--prefill-schedule-interval` and attention backend for TP4 (c1, c8, c16), DEP2 (c8–c64) and DEP2 with KV offload (c128, c192).
- TP4: THP Engram tables, `decode_backend=latency_specialized`, and capture size 5 for the one-request DSpark draft graph.
- DEP2: MegaMoE, Engram embedding across DP, consistent-hash vLLM Router; at c128 and c192, `SimpleCPUOffloadConnector` with lazy offload, 50 GiB per DP rank.

## Validation

- All values come from the InferenceX recipe at #4332 head `ad96b211`. All 9 benchmark points and both accuracy evals (TP4 c16, DEP2 offload c192) passed in the run above.
- `node scripts/validate-source.mjs --source vllm --dir <this checkout>/recipes` in vllm-project/recipes passes, and `pre-commit` passes.
- No GPU run for this PR.

## Details

`decode_backend=latency_specialized` for DSv4.1 comes from #61868 and #61869, which are not yet on `main`; the guide says so and names the image (`vllm/vllm-openai:cu134-nightly-x86_64-dev-20261019-mk`, public on Docker Hub). Every other flag and config key exists on `main`. The per-point settings are too specific for the general command builder, so this follows #62561 and stays in the guide.
