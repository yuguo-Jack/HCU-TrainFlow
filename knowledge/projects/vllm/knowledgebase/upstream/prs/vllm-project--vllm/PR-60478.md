## Overview

This pull request optimizes Gemma 4 multimodal processing in `vllm/model_executor/models/gemma4_mm.py` and adds comprehensive unit and kernel accuracy tests in `tests/kernels/core/test_gemma4_vision_rope.py` and `tests/models/multimodal/processing/test_gemma4_mm_optimizations.py`. It accelerates vision/audio preprocessing, projection, and multimodal serving across all 5 Gemma 4 model architectures (`google/gemma-4-E2B-it`, `google/gemma-4-E4B-it`, `google/gemma-4-12B-it`, `google/gemma-4-26B-A4B-it`, and `google/gemma-4-31B-it`):

1. **Batched Vision Spatial Pooling (`Gemma4VisionPooler`)**: Replaces the sequential per-image and per-frame Python loops over `vt.pooler(...)` with resolution-grouped batched pooling and standardization, plus an identity-pooling mask guard (`pooling_kernel_size == 1`), delivering up to **27.60x** speedup on multi-frame video pooling (**100.0% bit-exact**).
2. **Fused Vision/Audio RMSNorm via `vllm_c` (`Gemma4VisionRMSNorm`)**: Replaces eager HuggingFace `Gemma4RMSNorm` modules across the vision and audio towers with `Gemma4VisionRMSNorm(RMSNorm)` (credit to `@cjackal`), dispatching directly to `ir.ops.rms_norm.impls["vllm_c"]` (`csrc/layernorm_kernels.cu`) for both scaled (`with_scale=True`) and unscaled (`with_scale=False`) RMSNorm while preserving loaded parameter references and safe fallback guards. Delivers **2.83x - 9.40x** speedup (**100.0% bit-exact / 1-ULP**).
3. **Fused 2D Rotary Position Embeddings (`fused_vision_2d_rope`)**: Fuses 4-quarter axial 2D rotary position embeddings into a single Triton kernel (`_vision_2d_rope_kernel`, tuned with `num_warps=2`, broadcast stride handling, and empty-tensor guards), integrated cleanly via a vLLM `Gemma4VisionAttention` component swap in `_optimize_hf_multimodal_tower` without global module-level monkey-patching of `transformers`. Delivers **3.21x - 6.83x** speedup (**96.3% - 96.4% within 1-ULP**, cosine similarity **0.999998**).
4. **O(1) Full-Attention Layer Prefix Mask Clearing**: Replaces per-step string splitting of attention layer names with precomputed frozen set indices (`self._full_attn_layer_idxs`) and bounded memoized lookup (`self._cached_full_attn_layer_names`), reducing bidirectional attention prefix clearing overhead by **3.12x - 3.29x** (**100.0% bit-exact**).

Duplicate-work check: verified via `gh pr list --repo vllm-project/vllm --search "Gemma 4 vision pooler 2D RoPE"` and `gh issue list` that no open pull request addresses vision pooler batching or 2D RoPE fusion for Gemma 4.

## Claims

- **Realistic End-to-End V1 Serving Speedup (`enforce_eager=False`, `torch.compile` + CUDAGraphs)**:
  - On `gemma-4-E2B-it`: delivers **1.25x - 1.35x** speedup on single-image prefill, **1.13x - 1.28x** speedup on 4-image multi-modal prefill, and **1.16x - 1.25x** speedup on steady-state multimodal serving across batch sizes 1 to 8.
  - On `gemma-4-E4B-it`: delivers **1.13x - 1.22x** speedup on single-image prefill, **1.17x - 1.29x** speedup on 4-image multi-modal prefill, and **1.06x - 1.13x** speedup on steady-state multimodal serving across batch sizes 1 to 8.
  - On `gemma-4-26B-A4B-it` (MoE): delivers **1.25x - 1.33x** speedup on single-image prefill, **1.26x - 1.27x** speedup on 4-image multi-modal prefill, and **1.11x - 1.19x** speedup on steady-state multimodal serving across batch sizes 1 to 8.
  - On `gemma-4-31B-it` (Dense): delivers **1.14x - 1.16x** speedup on single-image prefill, **1.15x** speedup on 4-image multi-modal prefill, and **1.04x - 1.07x** speedup on steady-state multimodal serving across batch sizes 1 to 4.

  - `gemma-4-E2B-it`: **1.63x - 1.85x** speedup across single/multi-image and video frame configurations.

  - `Gemma4VisionModel + Pooler 2-layer`: **1.63x - 1.75x** speedup across single/multi-image and video configurations.

  - Cosine similarity of **0.99993 - 0.99997** across full 16-layer and 27-layer SigLIP vision pipelines with batched pooling and linear projection, and **0.99991 - 0.99999** on 8-layer Conformer audio pipelines.

  - `google/gemma-4-12B-it` (unified encoder-free architecture) verified with zero regressions (**1.00x** parity guard in vision pipeline; **1.03x - 1.17x** in text prefill).

    def measure_cuda_latency(fn: Callable[[], Any], warmup: int = 5, reps: int = 25) -> float:
        torch.cuda.synchronize()
        for _ in range(warmup):
            fn()
        torch.cuda.synchronize()
        start_events = [torch.cuda.Event(enable_timing=True) for _ in range(reps)]
        end_events = [torch.cuda.Event(enable_timing=True) for _ in range(reps)]
        for i in range(reps):
            start_events[i].record()
            fn()
            end_events[i].record()
        torch.cuda.synchronize()
        times = sorted([s.elapsed_time(e) for s, e in zip(start_events, end_events)])
        return float(times[len(times) // 2])

def print_comparison_table(data_base: Dict[str, Any], data_feat: Dict[str, Any]):
    header = (
        f"| Case | Base (ms) | Feat (ms) | Speedup | Gain (%) | "
        f"Bit-Exact (%) | Within 1-ULP (%) | Max Diff | Cos Sim | Extra |"
    )
    separator = "| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |"
    print(header)
    print(separator)
    for case, cb in data_base.items():
        if case not in data_feat:
            continue
        cf = data_feat[case]
        base_ms = cb["latency_ms"]
        feat_ms = cf["latency_ms"]
        speedup = base_ms / max(feat_ms, 1e-6)
        pct_gain = (speedup - 1.0) * 100.0
        tb = cb.get("tensor")
        tf = cf.get("tensor")
        if tb is not None and tf is not None:
            parity = compute_parity_metrics(tb, tf)
        else:
            parity = {"bit_exact_pct": 100.0, "within_1ulp_pct": 100.0, "max_abs_diff": 0.0, "cosine_sim": 1.0}
        extra_b = cb.get("extra", "")
        extra_f = cf.get("extra", "")
        extra_str = f"{extra_b} -> {extra_f}" if (extra_b or extra_f) else ""
        diff_str = f"{parity['max_abs_diff']:.2e}" if parity['max_abs_diff'] > 0 else "0.0"
        print(
            f"| {case} | {base_ms:.3f} | {feat_ms:.3f} | {speedup:.2f}x | "
            f"{pct_gain:+.1f}% | {parity['bit_exact_pct']:.1f}% | "
            f"{parity['within_1ulp_pct']:.1f}% | {diff_str} | "
            f"{parity['cosine_sim']:.5f} | {extra_str} |"
        )


def run_standalone(save_path: Optional[str] = None):
    print("Running PR6 benchmark in standalone mode on active branch...")
    results = run_worker(out_path=save_path)
    print("\n| Test Case | Latency (ms) | Extra |")
    print("| :--- | :---: | :--- |")

    if save_path:

    return results


def main():

def compute_parity_metrics(base: Any, feat: Any) -> Dict[str, float]:
    if isinstance(base, (tuple, list)):
        metrics_list = [compute_parity_metrics(b, f) for b, f in zip(base, feat)]
        return {
            "bit_exact_pct": float(sum(m["bit_exact_pct"] for m in metrics_list) / len(metrics_list)),
            "within_1ulp_pct": float(sum(m["within_1ulp_pct"] for m in metrics_list) / len(metrics_list)),
            "max_abs_diff": float(max(m["max_abs_diff"] for m in metrics_list)),
            "cosine_sim": float(min(m["cosine_sim"] for m in metrics_list)),
        }
    if isinstance(base, dict):
        metrics_list = [compute_parity_metrics(base[k], feat[k]) for k in base]
        return {
            "bit_exact_pct": float(sum(m["bit_exact_pct"] for m in metrics_list) / len(metrics_list)),
            "within_1ulp_pct": float(sum(m["within_1ulp_pct"] for m in metrics_list) / len(metrics_list)),
            "max_abs_diff": float(max(m["max_abs_diff"] for m in metrics_list)),
            "cosine_sim": float(min(m["cosine_sim"] for m in metrics_list)),
        }

    assert isinstance(base, torch.Tensor) and isinstance(feat, torch.Tensor)
    base_cpu, feat_cpu = base.detach().cpu(), feat.detach().cpu()
    total_elems = base_cpu.numel()
    if total_elems == 0:
        return {"bit_exact_pct": 100.0, "within_1ulp_pct": 100.0, "max_abs_diff": 0.0, "cosine_sim": 1.0}

    elem_exact = (base_cpu.contiguous().view(torch.uint8) == feat_cpu.contiguous().view(torch.uint8)).all(dim=-1)
    bit_exact_pct = float(elem_exact.float().mean().item() * 100.0)

    base_f, feat_f = base_cpu.float(), feat_cpu.float()
    diff = (base_f - feat_f).abs()
    max_abs_diff = float(diff.max().item()) if diff.numel() > 0 else 0.0

    if base_cpu.dtype == torch.bfloat16:
        a_i, b_i = base_cpu.view(torch.int16), feat_cpu.view(torch.int16)
        same_sign = (a_i >= 0) == (b_i >= 0)
        ulp = torch.where(same_sign, (a_i.int() - b_i.int()).abs(), torch.tensor(999999, device=base_cpu.device))
        ulp = torch.where((a_i == b_i) | ((base_cpu == 0) & (feat_cpu == 0)) | (diff <= 1e-6), 0, ulp)
        within_1ulp = ulp <= 1
    else:
        within_1ulp = diff <= 1e-4
    within_1ulp_pct = float(within_1ulp.float().mean().item() * 100.0)

    if total_elems > 1:
        base_d, feat_d = base_f.flatten().double(), feat_f.flatten().double()
        norm_b, norm_f = torch.linalg.norm(base_d), torch.linalg.norm(feat_d)
        if norm_b == 0 or norm_f == 0:
            cos_sim = 1.0 if norm_b == norm_f else 0.0
        else:
            denom = torch.clamp(norm_b * norm_f, min=1e-12)
            cos_sim = float(torch.clamp((base_d * feat_d).sum() / denom, -1.0, 1.0).item())
    else:
        cos_sim = 1.0 if max_abs_diff == 0.0 else 0.0

    return {
        "bit_exact_pct": bit_exact_pct,
        "within_1ulp_pct": within_1ulp_pct,
        "max_abs_diff": max_abs_diff,
        "cosine_sim": cos_sim,
    }


def measure_cuda_latency(fn: Callable[[], Any], warmup: int = 5, reps: int = 20) -> float:
    torch.cuda.synchronize()
    for _ in range(warmup):
        fn()
    torch.cuda.synchronize()

    start_events = [torch.cuda.Event(enable_timing=True) for _ in range(reps)]
    end_events = [torch.cuda.Event(enable_timing=True) for _ in range(reps)]

    for i in range(reps):
        start_events[i].record()
        fn()
        end_events[i].record()

    torch.cuda.synchronize()
    times = sorted([s.elapsed_time(e) for s, e in zip(start_events, end_events)])
    return float(times[len(times) // 2])

- lucianommartins · comment · 2026-10-13T17:25:29Z · [source](https://github.com/vllm-project/vllm/pull/60478#issuecomment-6151261663)

thanks for the detailed benchmarks and for putting together `lucianommartins/my-vllm#1`, @cjackal!

you are spot-on: because the HF vision and audio towers run in eager mode outside the compiled decoder graph, `vllm_c` (`ir.ops.rms_norm.impls["vllm_c"]`) avoids the Python/Triton launch overhead on small/medium batches (`B=1..16`) while removing the custom Triton RMSNorm kernel.

I integrated your `Gemma4VisionRMSNorm` (`vllm_c`) changes from `lucianommartins/my-vllm#1` (with `Co-authored-by`), rebased onto `main`, and added a few small fixes and unit tests (`tests/models/multimodal/processing/test_gemma4_mm_optimizations.py`):
1. **Preserved `Gemma4VisionAttention` 2D RoPE patching:** Restored `if module.__class__.__name__ == "Gemma4VisionAttention":` in `_optimize_hf_multimodal_tower` (which was accidentally dropped in the `my-vllm#1` diff when removing the old `Gemma4RMSNorm` branch).
2. **Weight & device preservation:** Added `if with_scale: new_norm.weight = child.weight` when replacing `Gemma4RMSNorm` children so pre-loaded/GPU-resident weights are preserved, and guarded `Gemma4VisionRMSNorm.forward` with `if x.is_cuda and 2 <= x.ndim <= 4 and x.numel() > 0:` before dispatching to `vllm_c`.
3. **2D RoPE & Pooler hardening:** Tuned `_vision_2d_rope_kernel` with `num_warps=2`, added broadcast stride (`cos.shape[0] == 1`) and empty-tensor guards, and added an identity-pooling mask guard (`pooling_kernel_size == 1`) in the batched pooler.

With `vllm_c` RMSNorm + fused 2D RoPE + batched spatial pooling, full 27-layer `Gemma4VisionModel` + Pooler latency drops from **79.21 ms -> 39.16 ms (2.02x)** on single images and **83.63 ms -> 40.72 ms (2.05x)** on 16 video frames, and 8-layer `Gemma4AudioModel` reaches **1.28x–1.42x**. Ready for CI whenever you have a chance!
