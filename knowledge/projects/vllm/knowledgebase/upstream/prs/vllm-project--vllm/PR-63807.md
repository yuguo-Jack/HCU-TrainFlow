# [Bugfix][NIXL] Serialize stale engine cleanup with the handshake lifecycle

[Upstream PR](https://github.com/vllm-project/vllm/pull/63807) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Fix a duplicate-cleanup assertion when NIXL TTL eviction races with another handshake lookup, and prevent old teardown from deleting state belonging to a new connection. Reuse `_handshake_lock` to serialize eviction, native teardown, handshake publication, and activity updates.

Related: #56317, #59877, #62571, #59957. #56317 protects the agent-map pop but not the whole cleanup lifecycle. #59877 addresses native agent thread safety, which does not make transitions across multiple Python state collections atomic. #63144 handles agent recreation across sleep/wake; #62571 handles deferred notifications. These address different mechanisms.

This PR does not include push cancellation, LMCache, model, or scheduler changes.

## Claims

- Concurrent TTL scans do not assert because another thread has already removed the same engine.
- Cleanup is idempotent, and reconnection state is not published before old native teardown finishes.
- Preserve in-flight transfer protection and upstream draft TP mapping cleanup.
- No claim of fixing all NIXL/native/shutdown races, improving throughput, or eliminating performance overhead.

## Details

A production decode worker exited along this path (sanitized call stack):

```text
start_load_kv
  _send_heartbeats
    _ensure_handshake
      _evict_stale_engines
        _cleanup_remote_engine
          assert engine_id in self._remote_agents
AssertionError
```

In push mode, the engine thread reaches `_ensure_handshake` through heartbeats, while the writer thread reaches it through `_send_registration_to_p`. A possible interleaving is:

1. Thread A finds an expired peer, pops its remote agent, and starts native teardown.
2. The agent is gone, but its activity timestamp has not yet been removed.
3. Thread B performs another handshake lookup/TTL scan, selects the same peer, and asserts during cleanup.

The existing RLock now serializes this lifecycle; repeated cleanup is harmless, and eviction is deferred while handshakes are pending. The production stack matches the controlled reproduction, but the available logs cannot uniquely establish the incident's exact thread interleaving.

The tradeoff is that lookups using the same lock wait during native teardown, and pending handshakes delay TTL reclamation. No new lock or protocol is introduced, and model computation is unchanged. Production tail latency under frequent reconnections remains unquantified.

<summary>Controlled native NIXL reproducer (CPU DRAM / UCX, not a GPU inference benchmark)</summary>

```python
"""Real vLLM lifecycle + NIXL/UCX DRAM probe, with controlled thread timing.

No model, GPU, RDMA, or PD frontend. The pause forces a legal race window;
agent registration, descriptors, removal, reconnection and READ are native.
Handshake metadata is supplied in-process instead of through the wire protocol.
"""
from __future__ import annotations
import argparse
from concurrent.futures import ThreadPoolExecutor, TimeoutError
import hashlib
import inspect
import json
import threading
import time
import traceback
import uuid
from pathlib import Path
from types import SimpleNamespace

import numpy as np
from nixl._api import nixl_agent, nixl_agent_config
from vllm.distributed.kv_transfer.kv_connector.v1.nixl.base_worker import NixlBaseConnectorWorker

parser = argparse.ArgumentParser()
parser.add_argument('--rounds', type=int, default=10)
args = parser.parse_args()
module_path = Path(inspect.getfile(NixlBaseConnectorWorker))
print(json.dumps({'source': str(module_path), 'sha256': hashlib.sha256(module_path.read_bytes()).hexdigest(), 'rounds': args.rounds}), flush=True)

class Wrapper:
    def __init__(self, agent):
        self.agent = agent
        self.entered = threading.Event()
        self.release = threading.Event()
        self.pause = False
        self.removes = 0
        self.releases = 0
    def __getattr__(self, name):
        return getattr(self.agent, name)
    def remove_remote_agent(self, name):
        if self.pause:
            self.entered.set()
            if not self.release.wait(5):
                raise TimeoutError('teardown barrier timed out')
        self.agent.remove_remote_agent(name)
        self.removes += 1
    def release_dlist_handle(self, handle):
        self.agent.release_dlist_handle(handle)
        self.releases += 1

results = []
for iteration in range(args.rounds):
    token = uuid.uuid4().hex
    local = nixl_agent('local-' + token, nixl_agent_config(backends=['UCX']))
    peer = nixl_agent('peer-' + token, nixl_agent_config(backends=['UCX']))
    src = np.full(4096, (iteration % 251) + 1, dtype=np.uint8)
    dst = np.zeros_like(src)
    local_reg = local.register_memory([(dst.ctypes.data, dst.nbytes, 0, '')], 'DRAM')
    peer_reg = peer.register_memory([(src.ctypes.data, src.nbytes, 0, '')], 'DRAM')
    peer_md = peer.get_agent_metadata()
    wrapper = Wrapper(local)
    w = object.__new__(NixlBaseConnectorWorker)
    w.shutdown = lambda: None  # Probe explicitly owns/tears down native resources.
    w.nixl_wrapper = wrapper
    w._handshake_lock = threading.RLock()
    w._handshake_futures = {}
    w._engine_ttl = 1
    w._engine_last_active = {}
    w._engine_clock_offset = {}
    w._remote_agents = {}
    w._engine_by_address = {}
    w._failed_remote_engines = set()
    w._invalid_remote_engines = set()
    w._recving_transfers = {}
    w._recving_metadata = {}
    w.transfer_topo = None
    for field in ('dst_xfer_side_handles', 'kv_caches_base_addr', 'dst_num_blocks', 'dst_region_num_blocks', 'dst_region_group_ids', 'dst_uses_region_group_mapping', 'dst_region_mem_types', 'tp_mappings', 'draft_tp_mappings'):
        setattr(w, field, {})
    handshake_errors = []
    w._log_failure = lambda **kw: handshake_errors.append(str(kw))
    w.xfer_stats = SimpleNamespace(record_failed_handshake=lambda: None)
    w._handshake_initiation_executor = ThreadPoolExecutor(1)
    def handshake(host, port, tp, eid, *rest):
        name = local.add_remote_agent(peer_md)
        handle = local.prep_xfer_dlist(name, [(src.ctypes.data, src.nbytes, 0)], 'DRAM')
        w.dst_xfer_side_handles[eid] = {0: handle}
        return {(0, 0): name}, 0.0
    w._nixl_handshake = handshake
    agents, _ = handshake('localhost', 1234, 1, 'peer')
    w._remote_agents['peer'] = agents
    w._engine_last_active['peer'] = time.perf_counter() - 10
    wrapper.pause = True
    errors = []
    timings = []
    def lookup():
        start = time.perf_counter()
        try:
            future = w._ensure_handshake('peer', 'localhost', 1234, 1)
            if future is not None:
                future.result(timeout=5)
        except Exception:
            errors.append(traceback.format_exc())
        finally:
            timings.append(time.perf_counter() - start)
    with ThreadPoolExecutor(2) as pool:
        a = pool.submit(lookup)
        assert wrapper.entered.wait(5), 'did not reach real native teardown'
        second_started = threading.Event()
        def second_lookup():
            second_started.set()
            lookup()
        b = pool.submit(second_lookup)
        assert second_started.wait(5)
        try:
            b.result(timeout=0.02)
        except TimeoutError:
            pass  # Correctly locked lookup waits for native teardown.
        wrapper.release.set()
        a.result(timeout=5)
        b.result(timeout=5)
    wrapper.pause = False
    w._handshake_initiation_executor.shutdown(wait=True)
    assert not handshake_errors, handshake_errors
    assert 'peer' in w._remote_agents
    local_handle = local.prep_xfer_dlist('', [(dst.ctypes.data, dst.nbytes, 0)], 'DRAM')
    h = local.make_prepped_xfer('READ', local_handle, [0], w.dst_xfer_side_handles['peer'][0], [0])
    state = local.transfer(h)
    deadline = time.monotonic() + 5
    while state not in ('DONE', 'ERR') and time.monotonic() < deadline:
        state = local.check_xfer_state(h)
    assert state == 'DONE', state
    local.release_xfer_handle(h)
    assert np.array_equal(src, dst), 'real post-reconnect READ corrupted data'
    local.release_dlist_handle(local_handle)
    w._cleanup_remote_engine('peer', log_eviction=False)
    local.deregister_memory(local_reg)
    peer.deregister_memory(peer_reg)
    row = {'round': iteration, 'errors': errors, 'lookup_seconds': timings, 'native_removes': wrapper.removes, 'native_descriptor_releases': wrapper.releases, 'post_reconnect_read_ok': True}
    results.append(row)
    print(json.dumps(row), flush=True)
    del w, wrapper, local, peer
print(json.dumps({'summary': True, 'rounds': len(results), 'failed_rounds': sum(bool(r['errors']) for r in results), 'read_ok': sum(r['post_reconnect_read_ok'] for r in results)}), flush=True)

```

Run `UCX_TLS=tcp,self UCX_NET_DEVICES=lo UCX_RCACHE_MAX_UNRELEASED=1024 .venv/bin/python native_lifecycle_probe.py --rounds 10` against the baseline and patched Python sources. Inspect the final `failed_rounds`, not just the exit code: the script catches thread exceptions so it can continue verifying post-reconnection READs.
