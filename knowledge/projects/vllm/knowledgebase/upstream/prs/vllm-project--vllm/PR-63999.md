# [Bugfix] Forward launch grid to Triton kernel overrides

[Upstream PR](https://github.com/vllm-project/vllm/pull/63999) · state: closed · merged: True

## Original PR description





## Overview

The kernel dispatcher's KernelOverride dropped the caller's launch grid, so platforms could not remap grids (e.g. to physical core counts). Triton kernel implementations are now swapped in directly, launching natively and staying inlinable as Triton device functions; non-Triton implementations are wrapped, receive the grid via __getitem__, and delegate compile-only warmup.

This PR fixes three gaps in the Triton kernel dispatcher: (1) the launch grid is now forwarded to overrides instead of being dropped, (2) Triton device functions called from inside other kernels can be overridden without breaking the outer kernel's compilation, and (3) JIT warmup is delegated to the override instead of failing.
