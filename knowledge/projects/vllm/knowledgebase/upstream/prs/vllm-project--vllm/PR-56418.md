# [Bugfix][Frontend] Preserve namespaced custom tools in Responses

[Upstream PR](https://github.com/vllm-project/vllm/pull/56418) · state: open · merged: False

## Original PR description

## Purpose

After #57322, top-level custom tools work, but custom tools inside a namespace are still omitted from function-tool conversion and name mapping. This change preserves namespaced custom tools throughout Responses rendering, output generation, and explicit input-item history replay.

For example, a custom tool `emit` inside namespace `sandbox` is rendered as `sandbox__emit`, returned as a `custom_tool_call` with `name="emit"` and `namespace="sandbox"`, and restored to `sandbox__emit` when replayed. Streaming classification uses the flattened tool name so a namespaced function is not misclassified when a top-level custom tool has the same local name.

The existing rejection of unsupported custom grammar formats now also applies inside namespaces. This patch reuses the custom-tool shim and decoding behavior merged in #57322.
