# [ROCm] Enable AITER by default

[Upstream PR](https://github.com/vllm-project/vllm/pull/48890) · state: closed · merged: False

## Original PR description

Enable AITER by default on ROCm by changing the default value of `VLLM_ROCM_USE_AITER` from `False` to `True`.

AITER unlocks the best performance on ROCm. Enabling it by default allows ROCm users to benefit from AITER without requiring additional environment configuration.
