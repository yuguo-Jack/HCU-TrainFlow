# [CI] Shard the AMD mirrors of the DP, RayExecutorV2 and batch invariance steps automatically

[Upstream PR](https://github.com/vllm-project/vllm/pull/61861) · state: closed · merged: True

## Original PR description

## Purpose

Third AMD batch. Turns on `automatic_shard` for the native AMD mirrors of four multi-GPU steps whose CUDA side already shards (#60858). Only the flag changes; no commands or tests.

| Mirror | Command shape | Planned shards |
|---|---|---:|
| `amd-distributed-dp-tests-2-gpus` | `export` setup, `TP_SIZE=... DP_SIZE=...` prefixes, 2 GPUs per shard | 2 |
| `amd-distributed-dp-tests-4-gpus` | the same plus a test-ID command, 4 GPUs per shard | 2 |
| `amd-rayexecutorv2-4-gpus` | `export` setup, `-k`, a `TARGET_TEST_SUITE=...` prefix, 4 GPUs per shard | 2 |
| `amd-batch-invariance-h100` | `export` and `pip install` setup, `VLLM_TEST_MODEL=...` prefixes, test IDs with `-k` | 2 |

## Test Plan

- Planned each mirror with ci-infra main's `runtime_shard.plan_step` against this branch and main's `amd-<key>` timings on the mirror's own queue.
- Rendered each mirror with the pipeline generator and ran every shard's `VLLM_TEST_COMMANDS` against a mock test tree, as a PR build and with main's `pytest -p ci_otel` wrapper: every test of every command ran in exactly one shard, with the env from the `export` lines and command prefixes.
- `/ci run`, then compare each mirror's shards against its single job on main.
