## Original PR description

## Purpose

Move [aoshen02/vllm-state-transition-verifier](https://github.com/aoshen02/vllm-state-transition-verifier) (at `8c81325`) into the `vllm-state-transition-verifier` branch of this repo under `tools/state_transition_verifier/`, so the tooling lives next to vLLM instead of in a personal repo.

It contains:

- `scripts/vllm_weight_update_client/`: a trainer-free client that pushes a local Hugging Face safetensors checkpoint into a running vLLM server through the NCCL weight-transfer engine (`start_weight_update` → metadata/update buckets → `finish_weight_update`), plus validation scripts (fixed-token oracle, GSM8K, pre/post comparison) and provenance sidecars.
- `scripts/rl_source_snapshot.py`: pins the exact source a container ran for an RL experiment (snapshot commit, clean worktree, import-path and file-hash verification).

The files are copied as-is; the only edits are `ruff check --fix` and `ruff format`. The branch is not meant to be merged into `main`; `main` will get a short pointer in the weight-transfer docs.
