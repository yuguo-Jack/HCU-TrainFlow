# [Feature][AuxOutput] Add Profile-based indexer replay for sparse models

[Upstream PR](https://github.com/vllm-project/vllm/pull/62915) · state: open · merged: False

## Original PR description

## Overview

Extend the raw Indexer Replay foundation in #49555 with Profile-described sparse
selection formats and model-specific adapters. Implements the remaining formats
from #47280 and depends on #49555; merge that PR first.

## Claims

- Describe model identity, producer/consumer layer mappings, selection semantics,
  fixed storage widths and codec versions in `AuxOutputProfile`.
- Add DeepSeek V4.1 compressed coordinates, GLM-5.3 KPool, Qwen4Exp QSA,
  Step5 per-KV-group regions and HY-V4 model hooks.
- Add lossless Pool/QSA decoding and optional packed delivery with profile
  metadata. Keep the raw `indexer_topk` API supported for uniform decoded shapes.

These are implementation claims; real model/backend correctness is not yet validated.

## Details

This is a planned dependent split of #49555, not a competing implementation.
Duplicate checks read #47280/comments and open related Indexer Replay PRs. The
base PR now contains ordinary raw-int32 replay; this PR adds formats that
need metadata to interpret, expand or group their selections.

DeepSeek V4's ordinary raw C4A capture is already in #49555. This follow-up
adds optional Profile metadata to that existing adapter; it does not introduce
the V4 capture path. Compression of KV coordinates alone needs no replay codec.

**Review only this second part:**
[incremental comparison](https://github.com/Ronald1995/vllm/compare/indexer-topk...codex/indexer-profile-models).
GitHub requires this upstream PR to target `main` because the upstream repository
does not contain the fork's `indexer-topk` branch. Its Files changed therefore
includes the prerequisite until #49555 merges. Rebase after that merge before
requesting maintainer review. Do not merge this PR first.

Profiles distinguish token IDs, compressed-cache coordinates, ordered Pool/Block
selections, count columns, causal tails and grouped Region IDs. Packed mode avoids
expansion through HTTP; raw mode decodes on final output assembly. Heterogeneous
source shapes require packed output. AMD QSA keeps its raw selection format.
V4.1's decoder replay retains capture rows when Indexer is the only AuxOutput.

Current AuxOutput PP/DCP/PCP, adaptive-verification and remote-PD restrictions
remain. MiniMax-M3 has been audited but has no adapter. Rust receives the engine
wire fields; Rust HTTP delivery remains unsupported. GPU graphs, real TP/DP,
model quality and overhead need later evidence. SHM retains immutable first-writer
semantics. See `docs/training/indexer_replay.md` for format and usage details.

Shared SHM block buffering, keys, publication and materialization live in artifacts.py and use generic AuxOutput names. Preemption uses the existing deferred request teardown to clear temporary blocks before resumption. Capture follows the model execution contract; row snapshots carry no per-token/source write-validity bitmap. Capture hooks are guarded by actual scoring execution, and existing forced-scoring settings for replay on short dense prefills are retained.

Scheduler and EngineCoreOutput use indexer_topk consistently with frontend output assembly and Rust engine IPC; the positional wire field order is preserved.

AI assistance was used. The human submitter must review every changed line and
run/accept validation before requesting maintainer review or claiming verified support.
