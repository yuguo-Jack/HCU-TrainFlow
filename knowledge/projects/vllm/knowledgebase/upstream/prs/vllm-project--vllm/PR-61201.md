# [CI] Shard PyTorch Fullgraph automatically

[Upstream PR](https://github.com/vllm-project/vllm/pull/61201) · state: open · merged: False

## Original PR description

## Purpose

`(H200 MIG 35GB) PyTorch Fullgraph` takes 55–67 min. This makes it one plain pytest over the directory and sets `automatic_shard: true`, following #60492 and the later batches.

**Why it used `find | xargs`:** #28625 added that command for two reasons:
- **Auto-inclusion:** a new `test_*.py` in the directory runs with no CI change.
- **Isolation:** each file ran in its own pytest process, to avoid #28965. A test that **forks** a child process fails with "Cannot re-initialize CUDA in forked subprocess" once another file in the same process has initialized CUDA.

#28965 was auto-closed as stale and never fixed. The runtime sharder handles plain pytest commands only, and it puts a different mix of files in one process on each build. So instead of keeping the per-file workaround, this removes the forking:

- **`test_multimodal_compile.py`:** `@pytest.mark.forked` becomes `@create_new_process_for_each_test("spawn")`.
- **`test_full_graph.py`:** `@create_new_process_for_each_test()` becomes `("spawn")`. With no argument it forks on CUDA.
- **The other three files** (`test_simple`, `test_toy_llama`, `test_multiple_graphs`) already spawn.

Spawn runs each test in a fresh interpreter, so CUDA state from other files doesn't matter. The command keeps auto-inclusion:

```
pytest -s -v compile/fullgraph --ignore=compile/fullgraph/test_full_cudagraph.py
```

The AMD mirror keeps the `find | xargs` command.

## Test Plan

- **[Build 94186](https://buildkite.com/vllm/ci/builds/94186), single pytest before this change:** the shard that ran `test_multimodal_compile.py` alongside other files hit #28965.
- **[Build 94440](https://buildkite.com/vllm/ci/builds/94440), this PR:** all 4 shards passed.
  - **Tests:** 38 passed and 1 skipped, the same as main. Shard 4 ran `test_multimodal_compile`, `test_multiple_graphs`, `test_simple` and `test_toy_llama` in one process, which is the mix that failed before.
  - **Wall time:** 66 → **24.1 min**. Shards took 21.4, 21.7, 24.1 and 12.5 min.
  - **Job-minutes:** 66.2 → 79.7 (+20%). About 4 min of that is spawn startup in `test_full_graph`: its 15 tests each re-import torch and vLLM, instead of forking.
