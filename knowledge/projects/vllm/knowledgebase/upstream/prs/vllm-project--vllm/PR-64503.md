# [Security] Enforce request template trust for structured decisions

[Upstream PR](https://github.com/vllm-project/vllm/pull/64503) · state: closed · merged: True

## Original PR description



## Overview

Enforce the server's request-template trust setting on `/v1/systemone` before engine admission or prompt rendering. Ordinary template kwargs and explicit template-trust opt-in remain supported.

## Claims

- Requests containing `chat_template_kwargs.chat_template` return the standard 400 error when `--trust-request-chat-template` is disabled.
- The check precedes strategy dispatch, covering every structured-decisions strategy.

## Validation

The route tests use the real HF and online renderers with an external test engine. All 12 trust-policy cases pass. Without the production change, the nonempty untrusted override returns 200 instead of 400, and the empty override fails the expected trust-error assertion (2 failed, 10 passed). Relevant baseline output:

```text
FAILED test_systemone_enforces_request_template_trust[template_kwargs4-False]
E       assert 200 == 400
FAILED test_systemone_enforces_request_template_trust[template_kwargs5-False]
E       assert '--trust-request-chat-template' in "these chat options end the prompt differently, so the labels' tokens are unknown"
```

The opted-in template is evaluated and its `MARKER-42-EVAL` output is checked in the engine prompt.

A real-server regression was added to the existing structured-decisions E2E suite; successful real-model validation remains pending. No model evaluation claim is made.

## Details

The structured-decisions handler forwarded request template kwargs directly into its read strategy, which can call the shared chat preprocessing method without the trust validation used by other routes. This reuses `OnlineRenderer.validate_chat_template` at the handler boundary. All strategies pass through it. No rendering algorithm or model preprocessing changes are included. The structured-decisions documentation states the default rejection and the opt-in flag.

Duplicate-work check: reviewed open structured-decisions validation, thinking-template, rendering, and model-support diffs, including #62472, #61216, #61251, #60745, #60713, #62402, and #63589. None enforce this control on this handler. The earlier merged template-validation changes in #50300, #50195, and #25794 cover other paths. Current main still lacks the check.

AI assistance was used to investigate, implement, and validate this change. Published at the maintainer’s explicit request with the local validation limits above; real-model validation remains pending.
