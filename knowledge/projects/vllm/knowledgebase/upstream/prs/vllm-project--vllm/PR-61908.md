## Original PR description

## Overview
Adds AWQ-v2 quantization format support with 64KB direct GPU DMA page-aligned weights and pre-swizzled Marlin 16x64 INT4 tensor core tile layouts to eliminate host CPU un-packing and repacking latencies during model loading. Link to spec: AWQ_V2_SPECIFICATION.md.

## Claims
- **Direct GPU DMA Mapping:** 64KB alignment guarantees raw tensor offsets match hardware virtual memory page boundaries, allowing zero-copy direct NVMe-to-VRAM transfers.
- **Eliminates Host CPU Repack:** Pre-swizzles weights into Marlin cooperative matrix layouts at quantization time rather than spending 15-45 seconds dynamically repacking nibbles on host CPU cores during engine initialization.
- **Full Backward Compatibility:** Falls back transparently to standard AWQ v1 decompression when reading legacy v1 checkpoints.
