# [ROCm][CI] Contain the MI355 DP + EP exit-time abort

[Upstream PR](https://github.com/vllm-project/vllm/pull/62286) · state: closed · merged: True

## Original PR description

- Drop `optional: false` from the MI355 DP + EP mirror so it inherits the parent's `optional: true` and stops gating PR builds
- Export `NCCL_RAS_ENABLE=0` in the mirror's commands, with a TODO to drop it once ROCm/rocm-systems#13572 is fixed
- Export `TORCH_CPP_LOG_LEVEL=INFO` so ProcessGroupNCCL teardown is logged per process group

Since the ROCm 10 image became the default (#58761), the torchrun DP + EP example finishes generating on all eight ranks, and about 15 s later one to five ranks abort on the main thread with `terminate called without an active exception` (https://buildkite.com/vllm/ci/builds/95651, https://buildkite.com/vllm/ci/builds/95663). The root cause is still under investigation; it does not reproduce with two ranks, and vLLM already defaults `NCCL_RAS_ENABLE=0` on ROCm, so the export here only pins it for this step rather than fixing the abort. The commands are listed on the mirror because `env:` does not reach the AMD test container, and the teardown logs (about 60 lines per rank) should show which process group, if any, stalls before the abort.

AI assistance (Claude Code) was used to draft this change. Every line was reviewed by the submitter.
