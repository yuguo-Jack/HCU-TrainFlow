# [Model] 接入 MiMo V2 checkpoint 的多层 MTP

[Upstream PR](https://github.com/vllm-project/vllm/pull/62619) · state: open · merged: False

## Original PR description



## Overview

为 MiMo V2 Pro/Flash 保留checkpoint实际的1–3层MTP深度，各预测模块读取同一target hidden state；多层运行要求Model Runner V2。Omni保留单层行为。

来源：[Pro6000d-community公开实现与历史测试](https://github.com/PacoZhou1/Pro6000d-community/tree/d2c0ec3be319b7d8949778eefd15bb77fa693b8d)。贡献重点是尽可能为RTX PRO 6000D的具体模型算子做适配与优化；不主张此前无人优化该GPU或全球首次。

## Claims

- 加载模块数受checkpoint层数与num_speculative_tokens共同限制。
- MiMo模块不串接前一草稿层的hidden state；其它模型保留既有串接行为。
- 增加层数边界、编译hash及runner检查；属于6000D部署工作中的模型集成，不是6000D独有算法。
