# [MM] Keep device input normalization fused when encoder compilation is enabled

[Upstream PR](https://github.com/vllm-project/vllm/pull/59195) · state: closed · merged: True

## Original PR description

## Purpose
Keep device input normalization on its fused kernel when compile_mm_encoder=True.

Encoder compilation changes the default `custom_ops` setting to `none`. Pixtral’s `pixtral_patch_embed()` runs outside the compiled transformer blocks, so Inductor cannot fuse its normalization call. Without this change, `FusedMMInputNorm` falls back to the eager PyTorch path.
