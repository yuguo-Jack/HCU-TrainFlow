# [ROCm][MiMo] Add experimental FP8 blockscale mono MLP

[Upstream PR](https://github.com/vllm-project/vllm/pull/63021) · state: closed · merged: False

## Original PR description

## Scope

Adds an opt-in experimental gfx950 eager-decode kernel for MiMo-V2 dense MLPs. It fuses SwiGLU, per-128 FP8 activation quantization, and the FP8 blockscale down projection without materializing the activated intermediate tensor.

Enabled only with `VLLM_ROCM_MIMO_MONO_MLP=1`; requires gfx950, TP1/TP8, BF16 activations, FP8 E4M3 weights with FP32 128x128 scales, eager execution, M<=16, and non-preshuffled down weights. All other cases retain the current path.

## Validation

- `ruff check` passed on changed sources.
- Real gfx950 TP8 MiMo-V2.6-Pro server reached the experimental path on all ranks: local gate `(4,4096)`, weight `(6144,2048)`, scale `(48,16)`.
- Focused blockscale numeric test passed for TP8 local shard.
- Synthetic M=1 local-shard GPU timing: 0.0300 ms mono vs 0.0430 ms staged AITER activation-quant plus blockscale GEMM. This is not an end-to-end throughput claim.
- GSM8K 8-question five-shot smoke: 1.000 accuracy, 0 invalid; it is not a full evaluation.

## Limits

The kernel recomputes SwiGLU per N=128 output tile to remove the activated tensor. It is intentionally experimental; graph capture and unsupported layouts fall back.

AI assistance was used for implementation and validation.
