# feat(DSv4): wait for per-layer KV loads before attention

[Upstream PR](https://github.com/vllm-project/vllm/pull/56762) · state: open · merged: False

## Original PR description




## Purpose

DeepSeek V4 owns its attention call and registers directly into static_forward_context, so it never reaches @maybe_transfer_kv_layer and never gets the connector wait that decorator provides. With a layer-wise KV connector the asynchronous loads are then unordered against the compute that reads them, and the model reads KV that has not landed.

Add maybe_wait_for_kv_layer() alongside maybe_transfer_kv_layer, carrying the same guards, and call it from DeepseekV4Attention._prepare_and_attn before the KV insert, the indexer and the compressor touch this layer's caches.
