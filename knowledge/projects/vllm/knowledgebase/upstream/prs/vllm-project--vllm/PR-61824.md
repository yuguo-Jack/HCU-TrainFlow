# [MRV2][Spec Decode] Optimize DSpark with local argmax reduction

[Upstream PR](https://github.com/vllm-project/vllm/pull/61824) · state: open · merged: False

## Original PR description

## Overview

This PR introduces local argmax reduction for DSpark speculative decoding to reduce Tensor Parallel (TP) communication overhead during draft token sampling.

Previously, DSpark gathered full vocabulary logits across TP ranks before applying Markov bias and selecting draft tokens. However, greedy sampling only requires the token with the highest score, making the full-vocabulary All-Gather unnecessary.

This PR performs argmax locally on each TP rank after applying the corresponding Markov bias, and then uses a lightweight All-Gather to determine the global winning token.

## Validation

This optimization reduces the amount of data exchanged during TP synchronization from full-vocabulary logits to a pair of values per TP rank and draft step. The expected benefit is lower communication overhead and improved speculative decoding performance, particularly for large vocabularies and communication-bound workloads.

Benchmark results will be added after validation.

## Details

- **Local Logits Computation:** Skip the full-vocabulary All-Gather during LMHead computation and retain vocabulary-sharded logits on each TP rank.
- **Local Argmax Reduction:** Apply the corresponding local slice of Markov bias and compute the local maximum score and its global token ID.
- **Lightweight TP Communication:** All-Gather only the local maximum score and token ID from each TP rank to determine the global argmax.
- **Preserve Sampling Semantics:** Maintain sequential Markov dependencies, vocabulary index mapping, padding handling, and deterministic argmax tie-breaking.
