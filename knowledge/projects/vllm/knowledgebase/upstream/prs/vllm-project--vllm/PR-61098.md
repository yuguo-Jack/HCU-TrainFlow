# WIP: [Bugfix][Model] Preserve all Kimi-Audio embeddings in batched requests

[Upstream PR](https://github.com/vllm-project/vllm/pull/61098) · state: open · merged: False

## Original PR description

## Overview

Preserve all Kimi-Audio embeddings when multiple requests are batched. The current implementation takes only the first item's embeddings and silently leaves later audio placeholders unfused.

## Claims

- Batched embedding fusion agrees with processing each request separately, including unequal audio lengths and chunked prefill windows.
- Text-only positions, output dtype, and the existing (text + audio) * sqrt(2) formula are preserved.

## Validation

Draft: not ready for merge. Full-model generation evaluation and human line-by-line review remain outstanding; no end-to-end serving result is claimed.

On macOS arm64, Python 3.12.13 and PyTorch 2.14.1, using the actual imported model method with a small text embedding layer:

```sh
.venv/bin/python -m pytest tests/models/multimodal/processing/test_kimi_audio_embed.py -q
```

Before: 6 failed, 2 passed. After: 8 passed. Tests cover list/tuple/batched tensor forms, fp32/bf16, two distinguishable audio items, interleaved text, scheduled windows, and text-only inputs.

`pre-commit run --files vllm/model_executor/models/kimi_audio.py tests/models/multimodal/processing/test_kimi_audio_embed.py` passed. The standard precompiled installation could not find a cu130 arm64 wheel; Python-level tests ran against the checkout with common dependencies installed. These unit tests do not establish full-model accuracy or GPU serving correctness.

## Details

The engine gathers per-item embeddings in scheduled request order, while the model previously selected `multimodal_embeddings[0]` and truncated the positions to that item's length. Reuse the existing multimodal merge helper for the entire collection, save text at the mask, and apply the existing fusion formula. No encoder, scheduler, or shared helper changes.

Duplicate-work searches of open upstream PRs for `Kimi audio embedding`, `"Kimi-Audio"`, and `"kimi_audio.py"` did not identify the same embedding fusion fix. No upstream issue number is associated with this change. AI assistance (OpenAI Codex) was used to investigate, implement, and test this draft. Human review and model evaluation are explicitly pending.
