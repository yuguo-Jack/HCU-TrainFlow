# [Doc] Document DeepSeek-V4.1-Flash B300 and GB300 Dynamo disaggregated profiles

[Upstream PR](https://github.com/vllm-project/vllm/pull/62561) · state: closed · merged: True

## Original PR description

## Overview

Document the DeepSeek-V4.1-Flash Dynamo + vLLM **disaggregated** AgentX profiles for B300 ([SemiAnalysisAI/InferenceX#4231](https://github.com/SemiAnalysisAI/InferenceX/pull/4231), [run 39112710364](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/39112710364)) and GB300 ([SemiAnalysisAI/InferenceX#4266](https://github.com/SemiAnalysisAI/InferenceX/pull/4266)). The InferenceX sign-off verifier asked for these settings in the upstream recipe ([verdict](https://github.com/SemiAnalysisAI/InferenceX/pull/4231#issuecomment-6278365602)). #62534 covers the aggregated profile and the sidecar flow. This PR merges #62572 (@peilii), which documented the same B300 profile.

## Claims

Guide text only, in `recipes/models/deepseek-ai/DeepSeek-V4.1-Flash.yaml`. The command builder output does not change.

- `## B200 scheduling and KV offload` becomes `## AgentX tuning on NVIDIA GPUs`, and gets a new subsection **Dynamo disaggregated serving on B300 and GB300**.
- One table gives the topology for each benchmark point: DEP2 prefill engine count, decode DEP size, decode `--max-num-seqs` and `VLLM_MAX_ASYNC_KV_ADMITS_PER_STEP`.
- One flag block gives the settings that both roles share on both GPUs. A second table gives the per-GPU differences: NIXL backend (LIBFABRIC over EFA or UCX over MNNVL), transport env, cumem allocator, DSpark rejection sampling, Engram offload, host KV size, prefill token budget and EPLB redundant experts.
- Prefill: `MultiConnector` of `push_as_nixl` and `SimpleCPUOffloadConnector` (70 GiB on B300, 80 GiB on GB300, lazy offload), `--prefix-cache-retention-interval 32768`, and graph sizes.
- Decode: NIXL consumer, `--no-enable-prefix-caching`, `--enable-eplb` over `symm_mem`, and the rules for batched tokens and graph sizes.
- Frontend and sidecars: the Dynamo frontend command and env (KV router, session affinity, thresholds off, tokenizer and TCP settings), the sidecar startup deadline, and the engine startup timeouts.
- The Dynamo section points to the new subsection instead of to Dynamo's examples.

## Validation

- All values come from the InferenceX recipes at #4231 head `5fafe8cc` and at #4266 head. The B300 values match the qualified run.
- The YAML parses, and every JSON value in the new subsection parses.
- Every vLLM flag and config key in the subsection exists on `main`. `push_as_nixl` and `VLLM_MAX_ASYNC_KV_ADMITS_PER_STEP` are only in the dev images, and the subsection names those images.
- No GPU run for this PR.

## Details

The earlier revision added `b300` builder overrides. They are removed, because the AgentX lane settings (DEP2 prefill engines, connector stack, EFA env, per-point decode sizes) are too specific for the general command builder, and the builder cannot express most of them. The GB300 rows cite InferenceX #4266, which is still open; update them if its final sweep changes the points.
