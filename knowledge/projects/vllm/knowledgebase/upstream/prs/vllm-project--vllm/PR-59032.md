# [Bugfix][Benchmark] Fix bench serve result serialization

[Upstream PR](https://github.com/vllm-project/vllm/pull/59032) · state: open · merged: False

## Original PR description

## Summary

Fix several inconsistencies in bench serve result files:

- Track pooling E2EL latency in the PyTorch benchmark export and record failed pooling requests.
- Leave per-request arrays out of summary JSON and PyTorch export metadata.
- Record the warmup count and use null for output-token metrics when the tokenizer is skipped.

This changes result serialization only; it does not change request execution or model output.

## Testing

- Ruff check and format on the changed Python files: passed.
- Python compileall on the changed files: passed.
- Focused serialization checks for exporter grouping, tokenizer-less metrics, and summary/detailed arrays: passed.
- Full pytest was not run locally on macOS arm64; the checkout does not have the vLLM runtime and test dependencies installed. Regression tests are included for CI.

No model evaluation was needed because inference behavior is unchanged.

Fixes #58969. I checked the issue and open PRs before submitting. PR #55809 covers new server-side timing arrays, a separate change.
