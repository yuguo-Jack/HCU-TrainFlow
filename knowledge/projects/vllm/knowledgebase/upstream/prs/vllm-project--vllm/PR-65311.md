# [ROCm][Multimodal][MiniMax-M3] Sequence-parallel vision encoder for single-image batches

[Upstream PR](https://github.com/vllm-project/vllm/pull/65311) · state: open · merged: False

## Original PR description

## Purpose

With `--mm-encoder-tp-mode data`, each rank runs the whole vision encoder for the images it receives. With one image per request and small batches, one rank encodes a large image while the others idle. This adds an opt-in sequence-parallel path for MiniMax-M3's vision encoder for single-image batches: the image's patch rows are split across the TP ranks (`VLLM_MINIMAX_M3_VIT_SP`, with `_ROWS`, `_MAX_ITEMS`, `_MIN_PATCHES` thresholds). Default off.

## Test Result

- TP2 microbenchmark: 1.6% error vs a 1-GPU forward (bf16 level); 2048x1600 image 116.8 → 85.1 ms.
- Serving, MI355X TP4 (8-row image sweep, one pass each): +1.8% geomean (768x1024 c16 row +4.2%).

If reviewers prefer, the env vars can become a `MultiModalConfig` option.
