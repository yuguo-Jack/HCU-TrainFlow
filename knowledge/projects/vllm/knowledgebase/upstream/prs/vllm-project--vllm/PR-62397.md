# [DO NOT MERGE][XPU][CI] Debug TP=2 XCCL startup hang in v1/shutdown

[Upstream PR](https://github.com/vllm-project/vllm/pull/62397) · state: open · merged: False

## Original PR description

Temporary debug PR, not for merge. Loops Intel CI `v1/shutdown` 8x and adds `[xccl-diag]` logs and faulthandler dumps in `XPUWorker.init_device` to find where the TP=2 startup hangs (~50% failure rate on intel-ci). Also prints `/dev/shm/psm_*` counts per iteration.

Why not a duplicate: no open PR investigates this hang; this one only gathers CI evidence.

Validation: `bash -n` on the new script only; 8 TP=2 shutdown tests passed locally x2 iterations (no repro).

AI assistance (GitHub Copilot) was used; submitter reviewed all changes.
