# [CI][XPU] Lower memory utilization for compile correctness embedding …

[Upstream PR](https://github.com/vllm-project/vllm/pull/64484) · state: open · merged: False

## Original PR description

## Purpose

`compile/fullgraph/test_basic_correctness.py::test_compile_correctness[*-test_setting1]` (BAAI/bge-multilingual-gemma2) fails on XPU before running anything:

```
ValueError: Free memory on device xpu:0 (22.18/22.71 GiB) on startup is less than desired GPU memory utilization (0.98, 22.26 GiB).
```

The test passes `--gpu-memory-utilization 0.98`; an XPU device has ~0.5 GiB already reserved at startup, so the startup free-memory check rejects it. Use 0.95 on XPU only (CUDA/ROCm keep 0.98).

Not a duplicate: searched open vllm-project/vllm PRs for `test_compile_correctness gpu-memory-utilization XPU`; none found.

## Test Plan / Result

```

VLLM_TEST_DEVICE=xpu pytest -q "compile/fullgraph/test_basic_correctness.py::test_compile_correctness[False-test_setting1]"
VLLM_TEST_DEVICE=xpu pytest -q "compile/fullgraph/test_basic_correctness.py::test_compile_correctness[True-test_setting1]"
```
Before: `[False-test_setting1]` fails with the ValueError above. After: both `1 passed` (399s and 453s).
