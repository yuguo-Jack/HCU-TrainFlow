## Overview

Add opt-in native offline CTC word timestamps for NVIDIA Nemotron 3.5 Transcribe, retaining the generated transcript and reporting alignment failures explicitly.

Follow-up to native model support in [[#64282](https://github.com/vllm-project/vllm/pull/64282)](https://github.com/vllm-project/vllm/pull/64282).

## Claims

- Load the checkpoint’s trained CTC head and tokenizer only when `hf_overrides={"enable_ctc_timestamps": True}` is set.
- Add `transcribe_with_word_timestamps()`, returning the original `RequestOutput`, `word/start/end` units, and per-request alignment errors.
- Capture acoustic states during the target encoder forward and align the final accepted transcript, including MTP K=2. The drafter does not load another CTC head.
- Defer windowed CTC scoring until generation finishes. Normalize over the full vocabulary before retaining the required columns on the CPU, and manage capture ownership across cache reuse, eviction, preemption, and cleanup.
## Validation

Locally validated on one A800-SXM4-80GB with BF16, MRV2, eager execution, and prefix caching disabled. Environment: Torch 2.14.0+cu130, CUDA 13.0, Transformers 5.19.0.

- **CPU regressions:** 56 tests passed. The final 7 capture-store cases were rechecked after restoring an ownership-transition assertion.
- **Static checks:** All 18 applicable repository hooks passed, including type checking and CI test-selection checks.
- **Real-weight LLM tests:** Ordinary decoding and MTP K=2 passed, covering capture, cache reuse, truncation, caller-owned parameters, and cleanup. MTP tests assert nonzero drafted and accepted tokens.
- **Independent BF16 head comparison:** Identical inputs and checkpoint weights were compared against pinned NeMo code. All 6 cases and 30 stage gates passed the numerical tolerance checks, with no argmax disagreements across 3,566 valid-frame comparisons.
- **Upstream / CTC-off / CTC-on controls:** All 180 corresponding outputs and 6,495 same-prefix candidate-score rows matched in each comparison.
- **Previously differing clips:** All four original clips passed three repeated plain/capture/reuse triplets on the current implementation.
- **Long-input checks:** Synthetic English 10-minute and 1-hour inputs passed alignment and offset checks with ordinary decoding and MTP K=2. Chinese counterparts retained their transcripts and returned explicit alignment errors for `汐`, which is absent from the checkpoint’s CTC vocabulary.
- **CTC memory observation:** The tested 1-hour English CTC phase added approximately 100.6 MiB to the Torch-allocated GPU peak. This does not represent total process memory.

The real-weight tests passed before the subsequent test-only simplification; production code remained unchanged. After simplification, both GPU test cases collected successfully, and a CPU renderer comparison confirmed identical semantic engine inputs for the refactored prompt builder. The GPU tests were not rerun after that refactor.
