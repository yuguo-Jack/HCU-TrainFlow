# [Model] Muse Glimmer: reuse in-tree RMSNorm / GemmaRMSNorm

[Upstream PR](https://github.com/vllm-project/vllm/pull/64920) · state: closed · merged: True

## Original PR description

## Overview

Replace the model-local `MuseGlimmerRMSNorm` (added in #51655) with the existing `RMSNorm` and `GemmaRMSNorm` CustomOps. The output is bit-identical in bf16.

## Claims

- Removes the model-local `MuseGlimmerRMSNorm` class. All norms in the model now use the shared CustomOps, so they get are enabled for the OOT-platform swapping.
- No numerical change: each replacement matches the old class bit-for-bit in bf16.
- No checkpoint or weight-loading change: parameter names and shapes are unchanged.

## Validation

Old class vs replacement, bf16, A100, x = 257×5120, both `forward_native` and `forward_cuda`:

| Norm (old config) | Replacement | Result |
|---|---|---|
| `with_scale=False` (`qk_norm`, `embed_norm`, `perception_emb_norm`) | `RMSNorm(dim, has_weight=False)` | bit-exact |
| `weight_offset=1` (4 sandwich norms) | `GemmaRMSNorm(dim)` | bit-exact |
| final `norm` | `RMSNorm(dim, dtype=torch.float32)` | bit-exact |

# 2 passed

## Details

The old class covered three cases, each of which already exists in-tree:

- **No weight:** `norm(x.float()).type_as(x)` is `RMSNorm(has_weight=False)`.
- **`(1 + w)` sandwich norms:** these are HF's `MuseGlimmerTextCenteredRMSNorm`, a copy of Gemma's norm, so `GemmaRMSNorm` matches.
- **Final norm:** HF computes `(norm(x.float()) * w.float()).type_as(x)`. The in-tree op multiplies in the weight's dtype, so the weight is kept in fp32 to match HF's single cast. The fp32 weight survives the bf16 default dtype at init and `default_weight_loader`. The trade-off is that the fused `vllm_c` kernel requires matching weight/input dtypes, so this one norm (once per forward) takes the native PyTorch path instead.

Not in scope: Gemma2-style fused residual-add in the decoder layer, which would change `forward`.

No open PR touches this: searched open PRs for `MuseGlimmerRMSNorm`, `MuseGlimmer RMSNorm` and `muse_glimmer norm`.
