# [Feature][MoE] Allow a shared routed-expert row restorer

[Upstream PR](https://github.com/vllm-project/vllm/pull/64689) · state: open · merged: False

## Original PR description

## Overview

Allow MoE implementations to provide an optional shared routing-row restorer, so backends such as vLLM-Ascend can restore their token layout without replacing `capture()`. The existing upstream recovery algorithm remains the default.

Related to #61539. This consolidates the smaller implementation from #65321 into this PR.

## Claims

- Bind the first available `restore_routed_experts_rows(topk_ids, ctx)` method once for all captured layers. Existing capture sources need no changes.
- Preserve `_restore_local_topk_ids(topk_ids, ctx)`, capture/router signatures, microbatch offsets and buffer writes.
- Limit production changes to `routed_experts_capturer.py`; no changes to MoERunner, MegaMoE, ModelRunner or ForwardContext.

## Validation

The previous head (`a109c1d`) produced **79 passed, 10 skipped** on CPU. The current head (`329840b`) replaces the broad parametrized test with two focused cases: exact buffer writes from one custom restorer, and use of the current forward context across two distinct layers. These cases have not yet been rerun on the current head.

Applicable pre-commit checks (including mypy and CI test selection) and `git diff --check` passed on the previous head; current-head local validation is pending. GPU-dependent skips are not graph-replay validation.

## Details

The selected restorer must handle every captured MoE layer using the current forward context, without depending on its provider's layer-specific state. It owns any required communication and padding removal. Providers must keep collectives rank-consistent and graph-replay safe.

This retains upstream shape inference and existing buffer semantics; it does not add per-layer restoration strategies or combine records written to the same layer slot.

### vLLM-Ascend integration

A local adapter was checked against the pre-rebase #65321 revision with 35 isolated CPU tests and 20 subtests. These exercise callback binding and restored buffer contents, including padded MC2/SP rows, with mocked collectives. NPU/HCCL, full-model serving and graph replay have not been validated for this implementation.
