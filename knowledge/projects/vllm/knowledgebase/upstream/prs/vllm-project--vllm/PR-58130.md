# [BugFix] Keep Hunyuan streaming parser stripping </answer>

[Upstream PR](https://github.com/vllm-project/vllm/pull/58130) · state: closed · merged: False

## Original PR description

## Summary

Fixes #58127.

`DelegatingParser` marks reasoning ended when Hunyuan enters the answer section, so later deltas were passthrough and leaked `\n</answer>`. Opt-in `post_reasoning_stream_filter` keeps those deltas on the Hunyuan state machine so the closing marker is stripped, matching non-streaming.
