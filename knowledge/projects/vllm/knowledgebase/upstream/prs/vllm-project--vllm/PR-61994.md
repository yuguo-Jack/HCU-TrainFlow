# [Spec Decode] Support PCP with DSpark for DeepSeek-V4.1

[Upstream PR](https://github.com/vllm-project/vllm/pull/61994) · state: closed · merged: True

## Original PR description



## Overview
Enable fixed-length DSpark speculative decoding with DeepSeek-V4.1-Flash Prefill Context Parallelism (PCP) on NVIDIA CUDA, extending the standalone PCP path from #59857. Preserve compressor rollback states and keep replicated draft proposals consistent across PCP ranks.


## Claims
- Retain and publish compressor ring tails across PCP ranks so rejected speculative suffixes can resume at an earlier position without losing the predecessor needed by ratio-2 compression.
- Broadcast draft tokens and, for probabilistic drafting, their corresponding logits from PCP rank 0 before target verification. The shared DFlash path also synchronizes confidence values when adaptive verification is enabled; V4.1 PCP still rejects adaptive verification.
- Cover PCP2/4, 0/5/9 speculative tokens, ring capacities 8/16, partial rejection, odd/even accepted prefixes, empty local ranks, and decode-owner changes through the existing compressor regression.
