# [Perf][Reasoning] Cut decoding overhead in Muse Spark Open's reasoning parser

[Upstream PR](https://github.com/vllm-project/vllm/pull/62728) · state: open · merged: False

## Original PR description



## Overview

`MuseReasoningParser.is_reasoning_end_streaming` re-decoded and regex-scanned the full token history on every call. The structured-output manager and `parse_delta` call it every step, so the cost grew quadratically with sequence length. This also covers `muse_glimmer`.

Fixes #54453.

## Claims

- `parse_delta` reuses the tool-handoff verdict `extract_reasoning_streaming` already computed for the same ids, so this check no longer decodes.
- The structured-output path incrementally decodes new tokens with prior context, falling back to a full decode when needed. Verdicts matched `is_reasoning_end` in the tests and differential checks below.
- Parser CPU time for 8,192 tokens streamed after a 2,280-token prompt drops from 5.69 s to 0.16 s for Muse and from 15.71 s to 0.16 s for Glimmer (these are synthetic parser-level timings not serving throughput).

```python
"""Parser-level CPU benchmark of the Muse reasoning-end check, before and after.

Streams one reasoning message after a long prompt. Time is the parser's
cumulative time over the stream (median and range of RUNS uninstrumented
passes). Decoded tokens and peak Python memory come from one more pass.

- engine: is_reasoning_end_streaming on a growing ConstantList, called once
  per step as the structured-output manager does.
- api: DelegatingParser.parse_delta once per delta, which includes the
  parser's unchanged streaming extraction.

"before" is main's is_reasoning_end_streaming (a full decode every call).
GPT-2 stands in for the Muse tokenizer, which is not public.
"""

import statistics
import time
import tracemalloc
from types import SimpleNamespace

from transformers import AutoTokenizer

from vllm.parser import ParserManager
from vllm.reasoning.muse_glimmer_reasoning_parser import MuseGlimmerReasoningParser
from vllm.reasoning.muse_reasoning_parser import MuseReasoningParser
from vllm.v1.utils import ConstantList

RUNS = 3
PROSE = "Let me check the next step of the plan before answering the user. "
ANGLE = "if a < b and <tag> is set, compare x<y before <atem:invoke echoing. "
CASES = [  # path, parser, text, output tokens, chunk
    ("engine", "muse", PROSE, 1024, 1),
    ("engine", "muse", PROSE, 4096, 1),
    ("engine", "muse", PROSE, 8192, 1),
    ("engine", "muse", PROSE, 8192, 8),
    ("engine", "muse", ANGLE, 8192, 1),
    ("engine", "muse_glimmer", PROSE, 8192, 1),
    ("api", "muse", PROSE, 1024, 1),
    ("api", "muse", PROSE, 4096, 1),
    ("api", "muse", PROSE, 8192, 1),
    ("api", "muse_glimmer", PROSE, 8192, 1),
]


class BeforeMuse(MuseReasoningParser):
    def is_reasoning_end_streaming(self, input_ids, delta_ids):
        return self.is_reasoning_end(list(input_ids))


class BeforeGlimmer(MuseGlimmerReasoningParser):
    def is_reasoning_end_streaming(self, input_ids, delta_ids):
        return self.is_reasoning_end(list(input_ids))


class CountingTokenizer:
    def __init__(self, tokenizer):
        self.tokenizer = tokenizer
        self.decoded = 0

    def decode(self, ids):
        self.decoded += len(ids)
        return self.tokenizer.decode(ids)


def run_engine(tokenizer, reasoning_cls, name, prompt, chunks):
    parser = reasoning_cls(tokenizer)
    history = list(prompt)
    all_token_ids = ConstantList(history)
    elapsed = 0.0
    for _, delta_ids in chunks:
        history.extend(delta_ids)
        start = time.perf_counter()
        parser.is_reasoning_end_streaming(all_token_ids, delta_ids)
        elapsed += time.perf_counter() - start
    return elapsed


def run_api(tokenizer, reasoning_cls, name, prompt, chunks):
    parser = ParserManager.get_parser(
        tool_parser_name=name, reasoning_parser_name=name, enable_auto_tools=True
    )(tokenizer)
    parser._reasoning_parser = reasoning_cls(tokenizer)
    request = SimpleNamespace(tools=None, tool_choice=None, include_reasoning=True)
    elapsed = 0.0
    for i, (text, delta_ids) in enumerate(chunks):
        start = time.perf_counter()
        parser.parse_delta(
            text,
            delta_ids,
            request,
            prompt_token_ids=prompt if i == 0 else None,
            finished=False,
        )
        elapsed += time.perf_counter() - start
    return elapsed


def measure(run, tokenizer, *args):
    times = [run(tokenizer, *args) for _ in range(RUNS)]
    counter = CountingTokenizer(tokenizer)
    tracemalloc.start()
    run(counter, *args)
    peak = tracemalloc.get_traced_memory()[1]
    tracemalloc.stop()
    return times, counter.decoded, peak


def fmt(times):
    return f"{statistics.median(times):.3f} s ({min(times):.3f}-{max(times):.3f})"


def main() -> None:
    tokenizer = AutoTokenizer.from_pretrained("gpt2")
    prompt = tokenizer.encode(
        "<|start|>system<|message|>" + PROSE * 160 + "<|eom|>"
        "<|start|>user<|message|>hi<|eom|><|start|>assistant"
    )
    print(f"Prompt {len(prompt)} tokens, {RUNS} timed runs per cell.\n")
    print(
        "| Path | Parser | Text | Output tokens | Chunk | Time before | Time after "
        "| Decoded before | Decoded after | Peak mem before | Peak mem after |"
    )
    print("|" + "---|" * 11)
    for path, name, filler, length, chunk in CASES:
        output = tokenizer.encode(" to=self<|message|>" + filler * (length // 8))
        output = output[:length]
        chunks = [
            (tokenizer.decode(output[i : i + chunk]), output[i : i + chunk])
            for i in range(0, len(output), chunk)
        ]
        run = run_engine if path == "engine" else run_api
        before, after = (
            (BeforeGlimmer, MuseGlimmerReasoningParser)
            if name == "muse_glimmer"
            else (BeforeMuse, MuseReasoningParser)
        )
        t0, d0, m0 = measure(run, tokenizer, before, name, prompt, chunks)
        t1, d1, m1 = measure(run, tokenizer, after, name, prompt, chunks)
        text = "prose" if filler is PROSE else "`<`-heavy"
        print(
            f"| {path} | {name} | {text} | {len(output)} | {chunk} | {fmt(t0)} "
            f"| {fmt(t1)} | {d0:,} | {d1:,} | {m0 / 2**20:.1f} MiB "
            f"| {m1 / 2**20:.1f} MiB |"
        )


if __name__ == "__main__":
    main()
```

## Details

- API path: `parse_delta` passes the same id list to `extract_reasoning_streaming` and `is_reasoning_end_streaming`. For that exact object the check returns `_tool_handoff_done`, so the phase flips on the same text the handoff uses.
- Engine path: up to 8 checkpoints keyed by the verified token prefix. Classification is skipped when neither the new text nor the trailing marker-overlap window contains '<'.
- Limitations: the prefix comparison and window copies are still O(history) per call. Split byte-fallback characters are re-decoded from the saved context until complete. A full decode is needed when no usable checkpoint exists or context validation fails.
- Related: #54454.
