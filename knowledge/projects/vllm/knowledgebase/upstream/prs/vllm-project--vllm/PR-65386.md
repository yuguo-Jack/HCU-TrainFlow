# Minimax m3.1 dspark drafter monokernel

[Upstream PR](https://github.com/vllm-project/vllm/pull/65386) · state: open · merged: False

## Original PR description



## Overview

Add flydsl monokernel for Minimax M3.1 drafter.

## Claims
The drafter in M3.1 is quite large. A large part of it came from attention, but even after optimizing this there were gains to be had by making it a monokernel.

## Details
