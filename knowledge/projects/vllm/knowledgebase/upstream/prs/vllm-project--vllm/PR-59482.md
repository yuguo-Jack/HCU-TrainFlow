## Original PR description

## Purpose
This is to point to the torch stable ABI branch of DeepGEMM (not yet merged upstream, see https://github.com/vllm-project/DeepGEMM/pull/21). This is "stacked" on top of https://github.com/vllm-project/vllm/pull/48962 with the only difference being the git tag and removing DeepGEMM from the `ALLOWED_UNSTABLE_LIBRARIES` list in `check-torch-abi.py` CI check  (see the last 2 commits).  

This PR continues the libtorch stable ABI migration (see https://github.com/vllm-project/vllm/issues/26946) for vLLM
