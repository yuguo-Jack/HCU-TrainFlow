# [ROCm][Perf][Kimi-K3] Fuse shared-expert down-proj into the latent-MoE tail GEMM

[Upstream PR](https://github.com/vllm-project/vllm/pull/58723) · state: open · merged: False

## Original PR description

## Purpose

On ROCm, `ROCmLatentMoERunner`'s sharded tail runs two GEMMs before the final
all-reduce of every Kimi-K3 MoE layer:

- the shared-expert down projection, a K-sharded partial `[M, 768] -> [M, 7168]` (TP8), and
- the routed latent up projection, N-sharded `[M, 3584] -> 896` columns, `addmm_`'d into the shared partial.

```
SE down:         [M, 768]  x [768, 7168]    (SE intermidiate 6144/8)
routed up_proj:  [M, 448]  x [448, 7168]    (latent 3584 / 8)
fused:           [M, 1216] x [1216, 7168]
```

The shared expert returns its pre-activation `gate_up`; SiTU and the concat run as one compiled
kernel via `CustomOp.maybe_compile`. Enabled at load when AITER is on, the tail is shardable,
weights are bf16, and the model is not `torch.compile`d.
