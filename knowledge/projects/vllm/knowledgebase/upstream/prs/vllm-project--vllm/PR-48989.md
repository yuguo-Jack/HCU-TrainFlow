The need for updating the block span formula
  - fp8_ds_mla tensors have padding between elements (576-byte UE8M0 alignment), so stride > data size.
  - block_len must be the actual byte span of one block, not the data content.
  - The span formula measures from the first to last element within the block, avoiding overrun on the final block.
  
  _block_len = 1 + sum((s - 1) * st for s, st in zip(shape[1:], stride[1:]))_
