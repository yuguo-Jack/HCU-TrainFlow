# [CI][ROCm][Disagg] Add DeepSeek-V3 NIXL accuracy steps

[Upstream PR](https://github.com/vllm-project/vllm/pull/62007) · state: open · merged: False

## Original PR description

## Purpose

Add DeepSeek-V3 disaggregated prefill/decode accuracy steps that use NIXL over UCX RDMA on MI350, next to the existing MoRIIO steps. Read uses `NixlConnector`. Write uses `NixlPushConnector` for 1P1D TP8, 1P1D EP8, and 2P2D EP16.

The 2P2D EP16 write step needs https://github.com/vllm-project/vllm/pull/62055. That change keeps push heartbeats and outgoing WRITE polling on the writer thread, so a blocked NIXL call cannot miss an expert-parallel collective.

## Changes

- `pipeline-disagg.yaml`: six DeepSeek-V3 steps. Read (`NixlConnector`): 1P1D TP8, 1P1D EP8/DP8, 2P2D EP16/DP16. Write (`NixlPushConnector`): 1P1D TP8, 1P1D EP8/DP8, and 2P2D EP16/DP16.
- `run-slurm-disagg-test.sh`, `run_xPyD_disagg.slurm`: add `KV_CONNECTOR` (default `MoRIIOConnector`) and pass it to the containers. For NIXL, start vllm-router with `--kv-connector nixl` and fixed `--prefill`/`--decode` URLs, because NIXL has no discovery service.
- `vllm_disagg.sh`: when `KV_CONNECTOR` is `NixlConnector` or `NixlPushConnector`, use that name in the NIXL KV transfer config (UCX backend). On 2P2D EP16 prefill, set `--gpu-memory-utilization 0.75`. At 0.85 the AITER MoE sort buffer runs out of memory. EP8 stays at 0.85.
- `cluster.sh`: for either NIXL connector, set UCX defaults for the ionic RoCE NICs (RC verbs on `ionic_0`, GPU-direct RDMA) and run accuracy with one concurrent request. The router flag stays `--kv-connector nixl` for both.

MoRIIO steps do not change. All new settings apply only when `KV_CONNECTOR` is `NixlConnector` or `NixlPushConnector`.

Requirement: the image's UCX must support `rc_verbs` on ionic NICs that report `max_srq=0`. The results below used UCX 1.22 with that support. The 2P2D EP16 write result also used the writer-thread ownership from #62055.

## Test plan

UCX environment (the same on every node):

```bash
export UCX_TLS=rc_verbs,ud_verbs,tcp,self,rocm
export UCX_NET_DEVICES=ionic_0:1,lo
export UCX_IB_GID_INDEX=1
export UCX_UD_VERBS_ETH_DGID_CHECK=n
export UCX_IB_GPU_DIRECT_RDMA=yes
export UCX_RMA_PPLN_ENABLE=y
export UCX_PROTO_EMULATION_ENABLE=n
export UCX_KEEPALIVE_INTERVAL=inf
export UCX_UD_VERBS_RX_QUEUE_LEN=1024
export UCX_RCACHE_MAX_UNRELEASED=1024
```

KV config (`kv_role` is `kv_producer` on prefill and `kv_consumer` on decode):

```bash
KV='{"kv_connector":"NixlConnector","kv_role":"kv_producer","kv_load_failure_policy":"recompute","kv_connector_extra_config":{"backends":["UCX"],"kv_lease_duration":180}}'
```

Write uses the same commands with `"kv_connector":"NixlPushConnector"`.

TP8, prefill (port 8100) and decode (port 8200, `kv_consumer`):

```bash
vllm serve DeepSeek-V3 --host $PREFILL_IP --port 8100 --tensor-parallel-size 8 \
  --trust-remote-code --kv-cache-dtype fp8 --max-model-len 32768 \
  --gpu-memory-utilization 0.85 --kv-transfer-config "$KV"
```

EP8/DP8, prefill:

```bash
vllm serve DeepSeek-V3 --port 20005 -tp 1 --data-parallel-size 8 --data-parallel-size-local 8 \
  --data-parallel-address $PREFILL_IP --data-parallel-rpc-port 13345 \
  --enable-expert-parallel --all2all-backend mori_high_throughput --enforce-eager \
  --no-enable-prefix-caching --api-server-count 8 --trust-remote-code \
  --kv-cache-dtype fp8 --max-model-len 32768 --gpu-memory-utilization 0.85 \
  --kv-transfer-config "$KV"
```

EP8/DP8, decode: the same command with `--data-parallel-address $DECODE_IP`, `--all2all-backend mori_low_latency`, no `--enforce-eager`, `--gpu-memory-utilization 0.75`, and `kv_consumer`.

2P2D EP16/DP16 uses the same EP command with `--data-parallel-size 16` on four nodes. Prefill uses `--gpu-memory-utilization 0.75`. The second prefill node and the second decode node join headless with `--data-parallel-start-rank 8`. The router points only at the two masters. Write uses `NixlPushConnector` and the #62055 writer.

Router (`--intra-node-data-parallel-size 1` for TP8, `8` for EP8 and EP16):

```bash
vllm-router --vllm-pd-disaggregation --kv-connector nixl \
  --prefill http://$PREFILL_IP:8100 --decode http://$DECODE_IP:8200 \
  --worker-startup-timeout-secs 1800 --port 30000 --host 0.0.0.0 \
  --intra-node-data-parallel-size 1 --policy round_robin \
  --prefill-policy round_robin --decode-policy round_robin
```

For 2P2D EP16 the router uses `--worker-startup-timeout-secs 7200` and `--intra-node-data-parallel-size 8`.

Accuracy:

```bash
lm_eval --model local-completions --tasks gsm8k \
  --model_args model=DeepSeek-V3,base_url=http://127.0.0.1:30000/v1/completions,num_concurrent=1,tokenized_requests=False,trust_remote_code=True
```

Script checks: `bash -n` on all changed scripts, YAML parse, NIXL KV config parses as JSON, router arguments checked for 1P1D TP8, 1P1D EP8 and 2P2D EP16, `git diff --check`.

## Results

GSM8K (5-shot) exact_match. KV moved GPU memory to GPU memory over `rc_verbs/ionic_0`.

| Config | Connector | flexible-extract | strict-match |
|---|---|---|---|
| 1P1D TP8 | NixlConnector | 0.92 | 0.92 |
| 1P1D EP8/DP8 | NixlConnector | 0.94 | 0.94 |
| 2P2D EP16/DP16 | NixlConnector | 0.964 | 0.964 |
| 1P1D TP8 | NixlPushConnector | 0.98 | 0.98 |
| 1P1D EP8/DP8 | NixlPushConnector | 0.94 | 0.94 |
| 2P2D EP16/DP16 | NixlPushConnector | 0.96 | 0.96 |

The 2P2D EP16 write row used the writer-thread ownership from #62055.
