## Overview

**JUST FOR DEMO, DO NOT MERGE.** This branch exists only to measure what the three build-time PRs do *together*; nothing in it is new. It is `main` plus, in order:

- #62716 - paged attention instantiations generated from one variant list, Navi set not instantiated without gfx11/gfx12, `<torch/all.h>` trimmed
- #62717 - topk softplus-sqrt instantiations split per (gating dtype, indices dtype) and per wavefront size
- #62718 - skinny GEMMs split per kernel family, `<torch/all.h>` trimmed

Each of them is reviewed on its own; the joint build time is the only thing this branch is for.
