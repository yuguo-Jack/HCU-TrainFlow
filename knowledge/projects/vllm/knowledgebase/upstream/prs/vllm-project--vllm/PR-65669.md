# [CPU][Zen] Update zentorch to 2.14.0.2

[Upstream PR](https://github.com/vllm-project/vllm/pull/65669) · state: open · merged: False

## Original PR description

Moves the `zen` extra and the Buildkite Zen CPU image build from zentorch `2.14.0.1` to `2.14.0.2`, [released on PyPI on 4 Nov 2026](https://pypi.org/project/zentorch/2.14.0.2/). This is the v6.1 GA whl.


## Validation

```
$ pytest -q tests/test_zentorch_version_pin.py
1 passed
```

The pin test parses both files and checks the zentorch version tracks the torch pin in `requirements/cpu.txt` (`2.14.0` → `2.14.0.x`).

Wheels are published for CPython 3.10 through 3.14 on `manylinux_2_28_x86_64`, so every interpreter the CPU jobs build against is covered.
