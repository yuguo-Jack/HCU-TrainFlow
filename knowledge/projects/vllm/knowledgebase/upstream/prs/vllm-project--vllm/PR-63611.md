## Changes

- L2 prefetches: TP8 B2-8 started up to three prefetch kernels in each layer. They took SMs and HBM bandwidth from the experts and the MoE tail. This PR removes them. B1 keeps its prefetch for the next attention.
- MLA split count: at B1-2, #61867 set more splits than tokenspeed. This added partial results to write and reduce. This PR uses the tokenspeed split count.
- MoE tail: TP8 B3-4 used a different tail than B5-8. Now B3-8 use the same tail.
- Early release: KDA now releases the o-proj at entry, and routing releases the experts at entry. The consumers wait for their inputs. At TP16, only B1 releases KDA early, because the fused o-proj reads its inputs at launch.
- Router: at TP8 B1, each rank computed all 896 router rows. Now each rank computes only its shard.
- KDA gate: B2 and higher use the MMA gate mode. This PR removes the scalar gate mode.
- Pregrouped experts: B9-32 used a separate one-CTA kernel to group the routes. Now the experts kernel groups them.
- Shapes: B3-8 input projections run in one wave (TP8 MLA, TP16). TP16 B3-8 experts use 136 CTAs, so the shared expert runs at the same time.
