# [XPU][CI] Skip test_deep_sleep_lora_tp2 on non-CUDA platforms

[Upstream PR](https://github.com/vllm-project/vllm/pull/62679) · state: closed · merged: True

## Original PR description

Skips `test_deep_sleep_lora_tp2` on non-CUDA/ROCm platforms to fix the Intel CI failure ([intel-ci build 14791](https://buildkite.com/vllm/intel-ci/builds/14791#01a1583b-796e-48a1-b418-f77d75a8ba30)).

#62358 keeps LoRA state in the `runtime` pool so it survives level-2 sleep, but only when `is_cuda_alike()`. On XPU the state stays in the `weights` pool and is discarded, so the test fails. Supporting XPU would need a workaround for nested memory pools in the XPU allocator, so the test is skipped there for now.

Validation: `pytest ... -k deep_sleep_lora` on XPU is expected to skip (same `skipif` form as `test_sleep_cudagraph_pool`); not run locally since the test module cannot be collected on my host (`libcuda.so.1` missing).

AI assistance (GitHub Copilot) was used; I reviewed every changed line.
