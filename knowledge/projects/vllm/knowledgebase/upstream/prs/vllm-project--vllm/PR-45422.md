## Original PR description

## Summary
- Add a TurboQuant KV cache section to the quantized KV cache documentation.
- List the user-facing `kv_cache_dtype` TurboQuant presets.
- Clarify that TurboQuant compatibility depends on the model architecture, attention backend, head dimension, and cache layout, and that FP8/auto are the portable fallback.

## Why this is not duplicating an existing PR
- Checked open PRs with:
  - `gh pr list --repo vllm-project/vllm --state open --search 'TurboQuant Gemma4 KV cache docs'`
  - `gh pr list --repo vllm-project/vllm --state open --search 'turboquant kv-cache dtype docs'`
- Found several TurboQuant implementation PRs, but no open PR specifically documenting the public `kv_cache_dtype` presets in the quantized KV cache guide.
