# [Perf][Humming] Skip the redundant MoE input copy before the w13 GEMM

[Upstream PR](https://github.com/vllm-project/vllm/pull/59340) · state: closed · merged: True

## Original PR description

## Purpose

`HummingExpertsBase` always passed the `quanted_gate_up_input` workspace to `may_process_input`, so Humming copied the w13 input into it even when there was nothing to apply (no quantization, Hadamard transform, activation, scatter or valid-token bound). In that case this passes no output buffer and the GEMM reads the input directly.
