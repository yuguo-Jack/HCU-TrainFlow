# [Docs] Add Giga-Embeddings bidirectional Qwen3 usage to embed docs

[Upstream PR](https://github.com/vllm-project/vllm/pull/60854) · state: closed · merged: True

## Original PR description

Close #60708 

As per feedback, the model works with `--hf-overrides` so a native 
implementation isn't needed. This PR documents the pattern for 
`ai-sage/Giga-Embeddings-instruct-480M-0826` and other decoder-only 
bidirectional embedding models that declare custom architecture names.

### Changes
- Added `ai-sage/Giga-Embeddings-instruct-480M-0826` to the Qwen3 row 
  in `docs/models/pooling_models/embed.md`
- Added a note explaining how to serve bidirectional decoder-only models 
  using `--hf-overrides` when their architecture name isn't registered
