# [Bugfix] Validate Kimi attention layer configuration

[Upstream PR](https://github.com/vllm-project/vllm/pull/50909) · state: open · merged: False

## Original PR description

## Purpose

`KimiLinearConfig` previously only asserted that `kda_layers` and
`full_attn_layers` were non-`None`, without validating their contents.

vLLM selects KDA layers using membership in `kda_layers` and treats the
complement as full attention. A malformed configuration could therefore
silently select the wrong attention implementation.

This PR validates that both layer lists:

* contain integer, non-boolean, 1-based layer indices;
* contain no duplicate or out-of-range indices;
* do not overlap;
* exactly cover the decoder stack.

Valid released Kimi-Linear and Kimi-K3 configurations are unchanged.
