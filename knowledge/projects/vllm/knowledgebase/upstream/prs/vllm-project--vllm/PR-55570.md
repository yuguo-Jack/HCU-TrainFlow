# [BugFix]  Added validation in _get_runner_type() to check model Arch

[Upstream PR](https://github.com/vllm-project/vllm/pull/55570) · state: open · merged: False

## Original PR description

Fixes: #55554




## Purpose
Adds validation in _get_runner_type() to check if the model architecture
  supports --runner pooling when explicitly specified. If not, it raises a
  ValueError immediately instead of allowing progression to weight loading
  where KeyError: layers.0.attention.wk.weight would occur.

## Root Cause:
  When --config-format mistral is used with --runner pooling for Mistral
  models, the architecture gets incorrectly resolved to LlamaForCausalLM via
  MODEL_FOR_CAUSAL_LM_MAPPING_NAMES[hf_config.model_type], which expects .k_proj
  keys but Mistral checkpoints use .wk keys, causing KeyError at weight loading.

## Changes:
  - vllm/config/model.py: Added 9 lines of validation in _get_runner_type()
