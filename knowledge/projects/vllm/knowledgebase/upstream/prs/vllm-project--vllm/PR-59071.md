# [Bugfix][KV Connector][NIXL] Read a GQA draft's head slice from a PCP x DCP prefill

[Upstream PR](https://github.com/vllm-project/vllm/pull/59071) · state: open · merged: False

## Original PR description

Stacked on #58471 (the first four commits are that PR; review only the last commit, a85e65683a).

## Purpose

A TP1 PCP×DCP prefiller exposes its PCP ranks as NIXL transfer ranks and shards the MLA target by token. Since #56723 a non-MLA draft (e.g. DSpark) runs there without DCP, so every prefill rank holds all draft heads for all tokens at the same block IDs. #58471 raises `NotImplementedError` for this pairing (DCP > 1), so a PCP8×DCP8 prefiller cannot feed a TP8 decoder with a DSpark draft.

- Map the draft by the prefill's real TP (transfer TP // PCP). Each decode rank reads its head slice from prefill rank `tp_rank % transfer_tp`; handshake sizes are checked against the real TP.
- Pull draft blocks only from that rank, paired as a non-DCP read would pair them, in both the per-group and region-mapped (#57389) paths. MLA regions keep their DCP slices, and done-notification counts are unchanged.
- Accept any layout with contiguous heads per page on both sides. The DCP prefill needs a block-outer layout (`VLLM_KV_CACHE_LAYOUT=BLHNC`).
- Register head-sharded draft layers as their own NIXL regions. Block-outer groups alias at byte 0, so the first draft layer was merged into the first MLA layer's region, then transferred as MLA-sized bytes and made the region shared (which region-mapped DCP pulls reject).

Unsupported combinations still raise `NotImplementedError`: prefill real TP > 1 with DCP, decode DCP, decode TP below the prefill transfer TP.

## Test Plan

- New unit tests in `tests/v1/kv_connector/unit/{test_nixl_connector,test_nixl_connector_hma,test_nixl_desc_geometry}.py` (mapping/offset/size checks for PCP8×DCP8 → TP8, layout acceptance, rejection cases, per-group and region-mapped pulls with the draft from one rank, the aliased-region fix).
- GPU: GLM-5.3 + `RedHatAI/GLM-5.3-speculator.dspark` (DSpark7, fixed verification), PCP8×DCP8×EP8 prefill → TP8×EP8 decode with HiSparse + native offload, 2× 8×H200, NIXL, `VLLM_KV_CACHE_LAYOUT=BLHNC` on both roles.

## Test Result

- Unit: NIXL connector unit suite passes except 3 pre-existing failures that need a real engine (`test_abort_timeout_on_prefiller` ×2, `test_fewer_blocks_with_hma[gemma]`).
- gsm8k (5-shot, 200 samples, through the P/D router): **0.930**; 100% of prompt tokens served as external KV hits; 0 failed NIXL transfers.
- Draft-KV integrity: on a copy task inside the draft's 2048-token sliding window, DSpark acceptance through P/D matches decoder-local prefill on the same prompts (8K: 0.86 vs 0.87, 32K: 0.84 vs 0.86, 100K: 0.87 vs 0.89). A scrambled draft transfer shows up as a large gap here (previously ~0.3-0.45 vs ~0.57 local).
