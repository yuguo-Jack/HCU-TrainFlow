# [Compressed-Tensors] [REAP] Non-uniform expert sparsity

[Upstream PR](https://github.com/vllm-project/vllm/pull/61916) · state: open · merged: False

## Original PR description

## Purpose ##
* Enable non-uniform expert sparsity, achieved through applying REAP to a model

## Changes ##
* Add `QuantizationConfig.get_num_experts_for_layer` which optionally exposes a new number of experts per layer
* Add logic to support parsing sparsity configs for compressed-tensors
* Add support for qwen3 and qwen3_next architectures
  * For models which do not fully standardize on `FusedMoEFactory`, these model-specific changes are required
  * For models which do standardize on `FusedMoEFactory`, non-uniform sparsity support is integrated

### Example `moe_sparsity_config` ###

```json
{
  "num_experts": 256,
  "quantization_config": {
    "quant_method": "compressed-tensors",
    "moe_sparsity_config": {
      "method": "prune",
      "num_experts": [
        null,
        129,
        253,
        128,
        128
      ]
    }
  }
}
```

## Testing ##
* Added tests for parsing
* Added tiny test models with <1.5 perplexity on the given prompt
