[Upstream PR](https://github.com/vllm-project/vllm/pull/48002) · state: open · merged: False

## Original PR description

## Summary
- Track when a tool name is extracted from a raw JSON-envelope argument buffer.
- For no-converter parser-engine configs, stream only the arguments or parameters value instead of leaking envelope syntax after the name field.
- Add streaming/non-streaming parity regressions for Hermes-style JSON envelopes across single-delta and char-by-char streams.

Fixes #47977
