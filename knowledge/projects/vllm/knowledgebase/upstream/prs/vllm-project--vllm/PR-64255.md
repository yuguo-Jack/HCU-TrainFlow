# [XPU][UT] Register XPU FlashAttn MLA backend in test_mla_backends

[Upstream PR](https://github.com/vllm-project/vllm/pull/64255) · state: open · merged: False

## Original PR description



## Overview

to fix UT issue [3129](https://jira.devtools.intel.com/browse/VLLMZ-3129)

It register the FLASH_ATTN_MLA backend enum to the implementation class XPUFlashAttnMLABackend.

After enabled FLASH_ATTN_MLA on XPU, where XPUPlatform selects XPUFlashAttnMLABackend. test_mla_backends.py resolves backends with AttentionBackendEnum.get_class(), which returns the CUDA FlashAttnMLABackend, so on XPU it ran the CUDA implementation and cases failed. Registering the XPU class lets this test run the right backend on XPU.
