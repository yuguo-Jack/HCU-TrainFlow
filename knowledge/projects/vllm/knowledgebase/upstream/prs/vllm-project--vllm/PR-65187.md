# [ROCm][CI] Wait for GPU memory to clear before sleep mode tests on al…

[Upstream PR](https://github.com/vllm-project/vllm/pull/65187) · state: closed · merged: False

## Original PR description

…l ROCm

MI300 Basic Correctness Sleep Mode: test_deep_sleep_fp8_kvcache and test_deep_sleep_async fail at startup because the previous spawned test's ~21 GiB has not been released yet (170.6/191.98 GiB free against 176.63 GiB requested). The memory is released shortly after: the next test in the same job starts with the GPU clean.

The gpu_memory_cleared fixture already handles this but only ran on gfx950. Run it on all ROCm GPUs and allow up to 60s for the release.
