# [ROCm][Model] DeepSeek-V4: add VLLM_ROCM_DSV4_BPRESHUFFLE to keep FP8 weights reloadable for RL weight sync

[Upstream PR](https://github.com/vllm-project/vllm/pull/63604) · state: closed · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

On ROCm with AITER, DeepSeek-V4 B-preshuffles three FP8 weights once after loading and never again, so `reload_weights` crashes and an RL weight sync **silently** corrupts every later rollout. This PR adds `VLLM_ROCM_DSV4_BPRESHUFFLE` (default `1`, unchanged) to keep those weights in checkpoint layout; verl-project/verl#8371 sets it to `0` for verl's rollout servers.

## Claims

- `VLLM_ROCM_DSV4_BPRESHUFFLE=0` makes weight reloads of DeepSeek-V4 on ROCm + AITER lossless (no parameter changes, same greedy tokens), through vLLM's `reload_weights` and through verl's FP8 refit. With the default, `reload_weights` crashes and verl's refit silently rewrites the three preshuffled weights.
- Default behaviour is unchanged (`1`).
- Needed for RL on gfx942, where AITER is mandatory for DeepSeek-V4: the sparse-attention indexer has no other ROCm path there ("requires AITER or a supported native architecture (gfx950/gfx11)").

## Validation

Reproducer: a 1-layer DeepSeek-V4-Flash-Base checkpoint (embedding, `layers.0`, head; built from the official one), TP1, `VLLM_ROCM_USE_AITER=1`, `kv_cache_dtype=fp8`, gfx942. The script generates greedily, reloads the checkpoint's own tensors, snapshots every parameter / buffer / cached tensor attribute before and after, and generates again. A no-reload control run measures run-to-run nondeterminism.

| reload path | `VLLM_ROCM_DSV4_BPRESHUFFLE` | attention preshuffled | tensors changed by reloading the same weights | greedy tokens after reload | max \|Δlogprob\| (no-reload control) |
|---|---|---|---|---|---|
| verl FP8 refit (`prepare_quanted_weights_for_loading` → `load_quanted_weights` → `process_quanted_weights_after_loading`) | `1` (default) | yes | 3: `fused_wqa_wkv`, `wo_b`, `shared_experts.gate_up_proj` (~98% of the elements) | **changed** | **2.68** (0.090) |
| verl FP8 refit | `0` | no | 0 | same | 0.095 (0.097) |
| `model_runner.reload_weights(weights_path=...)` | `1` (default) | yes | — | — | **crashes** in `_copy_and_restore_kernel_tensors`: `AttributeError: 'DeepseekV4ROCMAiterMLAAttention' object has no attribute '_wqa_wkv_scale'` |
| `model_runner.reload_weights(weights_path=...)` | `0` | no | 0 | same | 0.091 (0.091) |

```python
"""Replay an RL weight sync on an in-process vLLM DeepSeek-V4 engine (verl's FP8 refit, or --native reload_weights).

The checkpoint's own tensors are streamed back through verl's quantized-weight path
(prepare -> load_quanted_weights -> process), which is what an RL step does with the
weights VeOmni exports; a lossless refit must reproduce the greedy tokens and logprobs.
"""

import argparse
import glob
import os

os.environ.setdefault("VLLM_ENABLE_V1_MULTIPROCESSING", "0")

import torch
from safetensors import safe_open

PROMPTS = [
    "The capital of France is",
    "Question: What is 12 * 13? Answer:",
    "def fibonacci(n):",
]


def model_runner_of(llm):
    core = llm.llm_engine.engine_core
    core = getattr(core, "engine_core", core)
    return core.model_executor.driver_worker.worker.model_runner


def generate(llm):
    from vllm import SamplingParams

    outs = llm.generate(PROMPTS, SamplingParams(temperature=0.0, max_tokens=24, logprobs=0))
    res = []
    for o in outs:
        c = o.outputs[0]
        res.append((list(c.token_ids), [lp[t].logprob for lp, t in zip(c.logprobs, c.token_ids)]))
    return res


def checkpoint_tensors(model_dir):
    for path in sorted(glob.glob(os.path.join(model_dir, "*.safetensors"))):
        with safe_open(path, "pt", device="cuda") as f:
            for name in f.keys():
                yield name, f.get_tensor(name)


def describe(model, needle):
    for name, p in model.named_parameters():
        if needle in name:
            print(f"[refit] {name}: {type(p).__name__} {p.dtype} {tuple(p.shape)} subclass_type="
                  f"{getattr(p, 'subclass_type', None)} loader={getattr(p, 'weight_loader', None)}", flush=True)
            return


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--model", required=True)
    p.add_argument("--rounds", type=int, default=2)
    p.add_argument("--native", action="store_true", help="reload through vLLM's own reload_weights instead of verl's refit")
    p.add_argument("--gpu-memory-utilization", type=float, default=0.5)
    p.add_argument("--kv-cache-gb", type=float, default=None, help="fix the KV cache size instead of profiling free memory")
    args = p.parse_args()

    from verl.utils.vllm.vllm_quant_utils import (
        apply_vllm_quant_patches,
        load_quanted_weights,
        prepare_quanted_weights_for_loading,
        process_quanted_weights_after_loading,
    )

    apply_vllm_quant_patches()
    from vllm import LLM

    llm = LLM(model=args.model, tensor_parallel_size=1, max_model_len=2048, gpu_memory_utilization=args.gpu_memory_utilization,
              **({"kv_cache_memory_bytes": int(args.kv_cache_gb * 2**30)} if args.kv_cache_gb else {}),
              kv_cache_dtype="fp8", enforce_eager=True, enable_prefix_caching=False)
    runner = model_runner_of(llm)
    model = runner.model
    base = generate(llm)
    describe(model, "layers.0.attn.fused_wqa_wkv.weight")
    describe(model, "layers.0.attn.wo_b.weight")
    attn = next(m for m in model.modules() if hasattr(m, "_wqa_wkv_scale"))
    print(f"[refit] VLLM_ROCM_DSV4_BPRESHUFFLE={os.environ.get('VLLM_ROCM_DSV4_BPRESHUFFLE', '(unset)')} "
          f"attention preshuffled={attn._wqa_wkv_scale is not None}", flush=True)

    def snapshot():
        state = {n: p.detach().to("cpu", copy=True) for n, p in model.named_parameters()}
        state.update({f"buffer:{n}": b.detach().to("cpu", copy=True) for n, b in model.named_buffers()})
        # Derived caches that kernels read but that are neither parameters nor buffers.
        registered = {id(t) for t in list(model.parameters()) + list(model.buffers())}
        for mod_name, mod in model.named_modules():
            for attr, value in vars(mod).items():
                if isinstance(value, torch.Tensor) and id(value) not in registered and value.numel() > 1:
                    state[f"attr:{mod_name}.{attr}"] = value.detach().to("cpu", copy=True)
        return state

    control = generate(llm)
    same_tokens = all(a[0] == b[0] for a, b in zip(base, control))
    max_lp = max(max(abs(x - y) for x, y in zip(a[1], b[1])) for a, b in zip(base, control))
    print(f"[refit] control (no refit): same_tokens={same_tokens} max|dlogprob|={max_lp:.3e}", flush=True)

    for r in range(args.rounds):
        before = snapshot()
        if args.native:
            runner.reload_weights(weights_path=args.model)
            loaded = []
        else:
            state = prepare_quanted_weights_for_loading(model)
            loaded = load_quanted_weights(list(checkpoint_tensors(args.model)), runner)
            process_quanted_weights_after_loading(model, state)
        torch.cuda.synchronize()
        now = snapshot()
        changed = []
        for name, old in before.items():
            new = now.get(name)
            if new is None or new.shape != old.shape or new.dtype != old.dtype:
                changed.append((name, "layout", f"{tuple(old.shape)}/{old.dtype} -> "
                                f"{None if new is None else (tuple(new.shape), new.dtype)}"))
            elif not torch.equal(new.view(torch.uint8) if new.element_size() == 1 else new, old.view(torch.uint8) if old.element_size() == 1 else old):
                diff = (new.float() - old.float()).abs()
                changed.append((name, "value", f"max|d|={diff.max().item():.3e} n={int((diff > 0).sum())}/{diff.numel()} "
                                f"ratio={(new.float().abs().sum() / old.float().abs().sum().clamp_min(1e-30)).item():.4f}"))
        print(f"[refit] round {r}: {len(changed)} tensors changed", flush=True)
        for c in changed[:40]:
            print("[refit]   ", *c, flush=True)
        after = generate(llm)
        same_tokens = all(a[0] == b[0] for a, b in zip(base, after))
        max_lp = max(max(abs(x - y) for x, y in zip(a[1], b[1])) for a, b in zip(base, after))
        nan = sum(x != x for a in after for x in a[1])
        print(f"[refit] round {r}: loaded={len(loaded)} same_tokens={same_tokens} "
              f"max|dlogprob|={max_lp:.3e} nan={nan}", flush=True)


if __name__ == "__main__":
    main()
```

End to end on gfx942: verl GRPO on DeepSeek-V4-Flash-Base (a 4-layer version on one node, the full model on two nodes), vLLM TP8 rollouts with AITER and `VLLM_ROCM_DSV4_BPRESHUFFLE=0`, FP8 weight sync every step. Rollout and trainer token probabilities stay consistent after every sync (verl's `training/rollout_actor_probs_pearson_corr`).

Unit test: `tests/models/test_deepseek_v4_rocm_bpreshuffle.py` (CPU; checks that with the switch off the attention weights keep the loaded data and the forward takes the non-preshuffled GEMM, and that the default still preshuffles).

Run against the image's vLLM: without this PR both cases fail (the variable does not exist); with only the `rocm.py` change reverted, the switch-off case fails because the weights come back shuffled; with this PR both pass. The test runs in the `models_basic` Buildkite step. CI has no job that reloads a DeepSeek-V4 checkpoint on ROCm with AITER, so that GPU path is covered by the reproducer above, run outside CI on gfx942.

Image: `vllm/vllm-openai-rocm:nightly-rocm100-e4a5b5537344b103ed10de7764378ef09604ef3d` (amd-aiter 0.1.26). The two DeepSeek-V4 files are identical between that commit and `main`; `vllm/envs.py` differs only in unrelated variables.

## Details

Root cause: `DeepseekV4ForCausalLM.process_weights_after_loading` (ROCm) runs `prepare_attn_preshuffle` (`fused_wqa_wkv`, `wo_b`) and `prepare_gateup_preshuffle` (shared-expert `gate_up_proj`) once after the initial load. Nothing re-applies them after a reload: the layerwise reload (`initialize_layerwise_reload` → `load_weights` → `finalize_layerwise_reload`) re-runs each layer's quantization post-processing but not the model-level hook, and external refit paths (verl) do the same. Since `replace_parameter` now keeps the original parameter object, the reload no longer fails loudly (it used to raise `'Parameter' object has no attribute 'load_merged_column_weight'`); the shuffled weights are simply overwritten.

With `0` those three linears run through aiter's non-preshuffled blockscale GEMM, the same path as DeepSeek-V4's other FP8 linears and as gfx1250 today (where the preshuffle is already skipped); the compressor GEMM fusion is unaffected. The throughput difference was not benchmarked.

Limitations: a complete fix would make the preshuffle part of the reload lifecycle (or move it into the linear kernel's `process_weights_after_loading`, as `AiterFp8BlockScaledMMKernel` does on gfx1250), so that RL could keep the faster GEMM. DeepSeek-V4.1's ROCm attention has the same pattern and is not changed here. verl sets `VLLM_ROCM_DSV4_BPRESHUFFLE=0` for its rollout servers on ROCm (verl-project/verl#8371).
