# [CI] Remove the unused run-benchmarks harness and genai-perf test deps

[Upstream PR](https://github.com/vllm-project/vllm/pull/60594) · state: open · merged: False

## Original PR description

## Overview

Remove the old `run-benchmarks.sh` benchmark harness, which no pipeline reads, and the `genai_perf` / `tritonclient` test dependencies that only it needed.

Legacy-test tracker: A5

## Claims

- Deletes `.buildkite/scripts/run-benchmarks.sh`, `performance-benchmarks/scripts/launch-server.sh`, `tests/nightly-tests.json` and `tests/genai-perf-tests.json`. None of them has a reader in this repo, ci-infra, or the perf/vllm dashboards.
- Drops `genai_perf` and `tritonclient` from `requirements/test/cuda.in`, `rocm.in` and `nightly-torch.txt`. The regenerated lock files only lose packages, with no version bumps: genai-perf, tritonclient, perf-analyzer, optuna, statsmodels, sqlalchemy, alembic, fastparquet, kaleido, responses and their deps.
- Lists `pytest-mock` explicitly. It only arrived transitively and is used by `tests/compile/test_aot_compile.py`.

## Validation

- `pre-commit run` on the changed files passes, including test tethering (no test loses its CI job).
- A repo-wide grep (vllm/, tests/, benchmarks/, examples/, tools/, docs/, .buildkite/) finds no remaining reference to any deleted file.
- pip-compile (cuda, rocm, cpu) and the nightly-torch sync hook pass.
- No `import` of any dropped package in vllm/, tests/, benchmarks/, examples/ or tools/.
- GPU tests not run locally; CI covers them.

## Details

- This is the one part of the cleanup that changes the CI test image. Any failure would be an `ImportError` in a test that relied on a dropped package transitively, so CI is the real check.
- Conflicts with stale draft #38302, which edits `run-benchmarks.sh`.
- Split out of the original #60591 cleanup so each part reviews on its own. Part of a legacy-test audit; no test that currently runs is affected. Not a duplicate: open-PR searches found no PR removing these files.
