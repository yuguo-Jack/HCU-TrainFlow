# [DeepSeek-V4-P5] Rewrite matmul_persistent with a split-K plan

[Upstream PR](https://github.com/vllm-project/vllm/pull/59952) · state: open · merged: False

## Original PR description

## Scope

Add a deterministic split-K plan for `matmul_persistent` on long-K, skinny-N projections. The split plan depends only on `(K, N)` and dtype, while `M` changes only the scheduling path. Partial results reduce in ascending K order, apply bias once, and round once.
