# [Bugfix][Pooling] Restore GTE-Qwen2 EOS handling on Transformers v5

[Upstream PR](https://github.com/vllm-project/vllm/pull/57315) · state: open · merged: False

## Original PR description

## Purpose

Fix missing EOS tokens for GTE-Qwen2 on Transformers v5 and re-enable its embedding evaluation. Related to #38379. This replaces the previous test-only approach and no longer depends on [Transformers #48542](https://github.com/huggingface/transformers/pull/48542). No other open GTE tokenizer fix was found.

GTE's custom initializer overwrites the post-processor with an empty template. Keep normal tokenizer loading and repair only this known case: restore the saved template when present, or add EOS for the legacy ByteLevel assets that explicitly require it. Preserve working templates, custom initialization and explicit EOS overrides. Also preserve the original tokenizer class when saving the cache wrapper so vLLM can reload it.

## Test Plan

```bash
.venv/bin/python -m pytest tests/tokenizers_/test_registry.py tests/tokenizers_/test_hf.py tests/tokenizers_/test_basic.py -k 'not tokenizer_like_protocol' -q
```

Also run `tests/models/language/pooling_mteb_test/test_gte.py::test_embed_models_mteb[model_info9]` through a local runner with FP16, eager mode, `gpu_memory_utilization=0.8`, `max_num_seqs=2`, and model/batch token limits of 8192. Model revision: `a9af15a6372d7d6b25e9fb07c2ccb9e1fe645644`.

## Test Result

Validated after merging main at `9f07d023d`, with unpatched Transformers `ffddd25146e4`:

- 49 tokenizer tests passed; 1 unrelated protocol test deselected.
- STS12: 0.7584408921, reference 0.7584734590, within the unchanged 0.0005 tolerance.
- Pre-commit and Python 3.12 mypy passed.

Additional local checks matched all 6,216 STS12 inputs against the Transformers v4 token IDs and covered truncation, padding, pairs, save/reload and simulated upstream fixes. Exporting the original remote code does not fix raw Transformers reloads; the compatibility repair applies when loading through vLLM.

CI follow-up: added explicit tokenizer type checks in the GTE tests. All 25 GTE tokenizer tests pass with unpatched Transformers 5.18.0; pre-commit and mypy for Python 3.10–3.13 pass. The model evaluation results above are from the earlier revision.
