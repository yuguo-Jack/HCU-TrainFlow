# [Bugfix] Report reasoning and cached tokens in chat derender usage

[Upstream PR](https://github.com/vllm-project/vllm/pull/64041) · state: open · merged: False

## Original PR description

## Overview

`/v1/chat/completions/derender` now fills `usage.completion_tokens_details.reasoning_tokens` from the reasoning parser and `usage.prompt_tokens_details` from the generate usage, in batch and stream mode, as `/v1/chat/completions` does. Fixes #64038

## Claims

- Batch and stream chat derender report `completion_tokens_details.reasoning_tokens` when a reasoning parser is configured. Before: `null`.
- Both pass `prompt_tokens_details` through from the generate usage. Before: `null`.
- Stream with `n > 1` keeps `completion_tokens_details` `null` (see Details).
- 3 new tests (fail on the base commit, pass here), 2 extended; both derender test files pass in full.

M = "Qwen/Qwen3-0.6B"

    r.raise_for_status()
    return r.json()

chat = {"model": M, "messages": [{"role": "user", "content": "Say hello"}], "max_tokens": 64}
gen_req = post("/v1/chat/completions/render", chat)
prompt_ids = gen_req["token_ids"]
out_ids = tok.encode(
    "<think>\nThe user wants a greeting.\n</think>\n\nHello!", add_special_tokens=False
) + [tok.convert_tokens_to_ids("<|im_end|>")]

gen_usage = {
    "prompt_tokens": len(prompt_ids),
    "completion_tokens": len(out_ids),
    "total_tokens": len(prompt_ids) + len(out_ids),
    "prompt_tokens_details": {"cached_tokens": 8},
}
choice = {"index": 0, "token_ids": out_ids, "finish_reason": "stop"}

batch = post("/v1/chat/completions/derender", {
    "model": M, "chat_request": chat, "prompt_token_ids": prompt_ids,
    "generate_response": {"request_id": "b", "usage": gen_usage, "choices": [choice]},
})
stream = post("/v1/chat/completions/derender", {
    "stream": True, "model": M, "chat_request": {**chat, "stream": True},
    "prompt_token_ids": prompt_ids,

})
print("message:", json.dumps(batch["choices"][0]["message"], ensure_ascii=False))
print("derender batch  usage:", json.dumps(batch["usage"]))
print("derender stream usage:", json.dumps(stream["chunk"]["usage"]))

    f"completion_tokens_details.reasoning_tokens={parser.count_reasoning_tokens(out_ids)}, "

)

```python
"""Stream with n=2: send one chunk with <think> for each index, then send the
usage chunk with index 0's stream_state.

Compares usage.completion_tokens_details.reasoning_tokens with the sum of the
reasoning tokens over both indices.
"""
import json
import sys

import requests
from transformers import AutoTokenizer

from vllm.parser import ParserManager

BASE = sys.argv[1] if len(sys.argv) > 1 else "http://localhost:18100"
M = "Qwen/Qwen3-0.6B"
tok = AutoTokenizer.from_pretrained(M)

def post(path, body):
    r = requests.post(BASE + path, json=body)
    r.raise_for_status()
    return r.json()

chat = {"model": M, "messages": [{"role": "user", "content": "Say hello"}], "n": 2, "stream": True,
        "stream_options": {"include_usage": True}}
gen_req = post("/v1/chat/completions/render", chat)
prompt_ids = gen_req["token_ids"]
end = tok.convert_tokens_to_ids("<|im_end|>")
out0 = tok.encode("<think>\nShort.\n</think>\n\nHi!", add_special_tokens=False) + [end]
out1 = tok.encode("<think>\nA much longer thought about greetings here.\n</think>\n\nHello there!",
                  add_special_tokens=False) + [end]

parser = ParserManager.get_parser(reasoning_parser_name="qwen3", tokenizer=tok)(tok, None)
r0 = parser.count_reasoning_tokens(out0)
r1 = parser.count_reasoning_tokens(out1)

states = {}
for idx, ids in ((0, out0), (1, out1)):
    resp = post("/v1/chat/completions/derender", {
        "stream": True, "model": M, "chat_request": chat, "prompt_token_ids": prompt_ids,
        "prompt_tokens": len(prompt_ids),
        "generate_chunk": {"request_id": "n2", "choices": [
            {"index": idx, "token_ids": ids, "finish_reason": "stop"}]},
    })
    states[idx] = resp["stream_state"]

gen_usage = {
    "prompt_tokens": len(prompt_ids),
    "completion_tokens": len(out0) + len(out1),
    "total_tokens": len(prompt_ids) + len(out0) + len(out1),
}
for idx in (0, 1):
    resp = post("/v1/chat/completions/derender", {
        "stream": True, "model": M, "chat_request": chat, "prompt_token_ids": prompt_ids,
        "prompt_tokens": len(prompt_ids), "stream_state": states[idx],
        "generate_chunk": {"request_id": "n2", "choices": [], "usage": gen_usage},
    })
    print(f"usage chunk sent with state of index {idx}:", json.dumps(resp["chunk"]["usage"]))

print(f"index 0 reasoning_tokens={r0}, index 1 reasoning_tokens={r1}, coupled would report sum={r0 + r1}")
print(f"completion_tokens from generate (both indexes) = {len(out0) + len(out1)}")
```

## Details

`/v1/chat/completions` counts `reasoning_tokens` with the reasoning parser and keeps the generate server's `cached_tokens`; both derender paths built `UsageInfo` from the token counts alone ([`derender/serving.py` L183-L192](https://github.com/vllm-project/vllm/blob/39e6a1aafcaea1b90c515dacfc3a20835756758c/vllm/entrypoints/scale_out/derender/serving.py#L183-L192), [`online_derenderer.py` L888-L897](https://github.com/vllm-project/vllm/blob/39e6a1aafcaea1b90c515dacfc3a20835756758c/vllm/renderers/online_derenderer.py#L888-L897)). Batch now counts in `_parse_and_assemble` with the parser that parsed the choice; stream counts over every token streamed so far on the usage chunk, and `prompt_tokens_details` passes through from the generate usage. With `n > 1` the stream usage chunk carries one index's `stream_state`, so the count can't cover every choice; `completion_tokens_details` stays `null` there, documented in `derenderer.md`.

Out of scope: batch `prompt_tokens` still defaults to 0 without `request.prompt_tokens`, and `output_mode="derender"` on `/inference/v1/generate` (#63103). A generate server with `--enable-prompt-tokens-details` and the GPU parity test were not run.
