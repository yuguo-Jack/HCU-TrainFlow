# [Bugfix][NIXL] Keep push progress off model thread

[Upstream PR](https://github.com/vllm-project/vllm/pull/62055) · state: open · merged: False

## Original PR description

## Purpose

Fix a `NixlPushConnector` hang in 2P2D EP16.

The model thread was calling NIXL for heartbeats and outgoing WRITE completion polling. If one rank blocked in either call, it missed the next expert-parallel collective and the request timed out.

This change is required by the 2P2D EP16 write step in https://github.com/vllm-project/vllm/pull/62007.

## Changes

- Move push heartbeat processing to `nixl-push-writer`.
- Move outgoing WRITE completion polling to `nixl-push-writer`.
- Return completed and failed request IDs to the model thread through a queue.
- Keep WRITE completion and failure accounting under the transfer lock.
- Serialize writer NIXL calls with handshake setup.
- Add unit coverage for thread ownership and WRITE completion accounting.

The change is limited to `NixlPushConnector`.

## Test plan

Set the UCX environment on all four nodes:

```bash
export UCX_TLS=rc_verbs,ud_verbs,tcp,self,rocm
export UCX_NET_DEVICES=ionic_0:1,lo
export UCX_IB_GID_INDEX=1
export UCX_UD_VERBS_ETH_DGID_CHECK=n
export UCX_IB_GPU_DIRECT_RDMA=yes
export UCX_RMA_PPLN_ENABLE=y
export UCX_PROTO_EMULATION_ENABLE=n
```

Use this KV configuration on prefill:

```bash
KV='{"kv_connector":"NixlPushConnector","kv_role":"kv_producer","kv_load_failure_policy":"recompute","kv_connector_extra_config":{"backends":["UCX"],"kv_lease_duration":180}}'
```

Use the same configuration on decode with `"kv_role":"kv_consumer"`.

Start the prefill master:

```bash
vllm serve DeepSeek-V3 --port 20005 -tp 1 \
  --data-parallel-size 16 --data-parallel-size-local 8 \
  --data-parallel-address $PREFILL_MASTER --data-parallel-rpc-port 13345 \
  --enable-expert-parallel --all2all-backend mori_high_throughput \
  --enforce-eager --no-enable-prefix-caching --api-server-count 8 \
  --trust-remote-code --kv-cache-dtype fp8 --max-model-len 32768 \
  --gpu-memory-utilization 0.75 --kv-transfer-config "$KV"
```

Start the second prefill node with the same command and:

```bash
--headless --data-parallel-start-rank 8
```

Start the decode master with the prefill command adjusted to:

```bash
--data-parallel-address $DECODE_MASTER \
--all2all-backend mori_low_latency \
--kv-transfer-config "$KV"
```

Remove `--enforce-eager` on decode. Start the second decode node with `--headless --data-parallel-start-rank 8`.

Start the router:

```bash
vllm-router --vllm-pd-disaggregation --kv-connector nixl \
  --prefill http://$PREFILL_MASTER:20005 \
  --decode http://$DECODE_MASTER:20005 \
  --worker-startup-timeout-secs 7200 --port 30000 --host 0.0.0.0 \
  --intra-node-data-parallel-size 8 --policy round_robin \
  --prefill-policy round_robin --decode-policy round_robin
```

Run GSM8K:

```bash
lm_eval --model local-completions --tasks gsm8k \
  --model_args model=DeepSeek-V3,base_url=http://127.0.0.1:30000/v1/completions,num_concurrent=1,tokenized_requests=False,trust_remote_code=True
```

Run static checks:

```bash
pre-commit run --files \
  vllm/distributed/kv_transfer/kv_connector/v1/nixl/push_worker.py \
  tests/v1/kv_connector/unit/test_nixl_push_connector.py
```

## Results

2P2D EP16/DP16 completed with GSM8K exact_match `0.96`.

Regression runs also completed:

- 1P1D TP8: `0.96`
- 1P1D EP8/DP8: `0.92`

All runs used GPU-direct `rc_verbs/ionic_0` for inter-node KV WRITE.
