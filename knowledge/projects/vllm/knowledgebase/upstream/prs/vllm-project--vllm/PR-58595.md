# [KV Offload] Add compact filesystem files

[Upstream PR](https://github.com/vllm-project/vllm/pull/58595) · state: open · merged: False

## Original PR description

Related to #56871 and #56953. Add opt-in `compact_groups: true` for supported packed BLHNC filesystem files, removing unused padding from unequal cache groups. CPU storage is unchanged; the extra copies can slow reloads, so the default remains `false`. The refreshed configuration retains sliding-window metadata alongside packed-layout certification.

## Tests

- Current source `2e0dbc8a02`: 185 configuration, filesystem-tier, metrics and file-mapper tests passed. These CPU tests ran in a CUDA environment with 1× NVIDIA H100 80GB visible.
- pre-commit, including mypy, passed.

Historical validation on 1× NVIDIA H200:

- 228 focused and compatibility tests passed.
- Synthetic GPU → CPU → filesystem → CPU → GPU roundtrip passed with exact KV bytes; the smaller group's file fell from 408 to 256 KiB, and the two-file total from 816 to 664 KiB.
- O_DIRECT reload microbenchmark, 32 files: 102 → 83 MiB, but median reload rose from 42.59 to 62.09 ms, supporting the opt-in default.
