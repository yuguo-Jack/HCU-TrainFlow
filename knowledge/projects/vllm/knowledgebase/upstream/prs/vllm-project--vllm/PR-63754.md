# [Fast Start] Support ModelOpt CUTLASS FP8 weight-cache restarts

[Upstream PR](https://github.com/vllm-project/vllm/pull/63754) · state: closed · merged: True

## Original PR description

## Overview

Enable serialized ModelOpt per-tensor and per-channel FP8 linear weights to be reused by the weight-cache daemon with CUTLASS. Related to #56049; depends on #63672 for restoring CUTLASS's logical output width.

Incremental review: https://github.com/liusy58/vllm/compare/35711168b0135573234bbaa4bd8f9e8fe32647e8...7f75449765425d759565d3a770d829070d909f99 (the GitHub diff against main includes the prerequisite).

## Claims

- Enable CUDA IPC for ModelOpt `FP8` and `FP8_PER_CHANNEL_PER_TOKEN` linear layers using CUTLASS and the default format scheme.
- Restore the transposed-weight layout metadata without transposing, requantizing, padding, or mutating the daemon's already processed weights/scales a second time.
- Keep other ModelOpt FP8 backends and block FP8 unsupported; existing FP4/MXFP8 capability rules are unchanged.

## Details

The daemon currently rejects every ModelOpt FP8 linear method even when CUTLASS can consume the processed tensor layout. Opt in only the two plain FP8 weight schemes with the actual selected CUTLASS kernel and no format wrapper. The engine restores `processed_weight_dims=(0, 1)` and returns before post-load weight transformations. CUTLASS logical width is initialized from configuration by #63672, so padded shared weights still produce the original output width.

The existing L4 preload CI step now selects the real ModelOpt IPC test and the six layer cases, with dependencies on the changed ModelOpt source and tests. The preload feature guide documents the formats, matching daemon/engine kernel configuration, and exclusions. Local validation used B300; L4 CI has not been run locally. No new scheduler/model-runner path or steady-state GPU synchronization.

Duplicate checks on October 26 covered #56049 and its comments, issue-linked PRs, and open searches for ModelOpt FP8 preload/pre-processed weights. #63672 covers online quantization and NVFP4, #63673 covers compressed-tensors FP8, and #62036 covers W4A16 NVFP4 layerwise reload; none implements this serialized ModelOpt FP8 IPC path. This branch includes main `373614f66d`.
