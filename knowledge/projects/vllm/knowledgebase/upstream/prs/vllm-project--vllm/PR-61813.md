# [Chore] Use upstream Transformers MiniMaxM3VLConfig

## Overview

Split from #60823: replaces the vendored MiniMax-M3 config and ports the MiniMax-M3 code to the upstream Transformers `MiniMaxM3VLConfig` schema.

Related PRs:
- **#60823:** the larger unvendoring PR this is split from; MiniMax-M3 has been dropped from it.
- **#61392:** the same split for DeepSeek-V4.

## Claims

- Registers upstream `MiniMaxM3VLConfig` for `minimax_m3_vl` in `_CONFIG_REGISTRY`, because the hub remote code uses the old schema.
- `vllm/transformers_utils/configs/minimax_m3.py` shrinks to `MiniMaxM3MTPConfig`, a subclass of upstream `MiniMaxM3VLTextConfig` for standalone MTP checkpoints (`model_type: "minimax_m3_mtp"`). These copy the main model's 60-entry per-layer lists, which upstream rejects for a 1-layer config, so the subclass keeps the leading entries the MTP layer reads. No public checkpoint uses this format, but private ones may.
- The NVIDIA and AMD model code, indexers and vision tower read the upstream fields:
  - `layer_types` / `mlp_layer_types` replace `sparse_attention_config["sparse_attention_freq"]` / `moe_layer_freq`.
  - `index_*` fields replace the rest of `sparse_attention_config`.
  - `rope_parameters` replaces `rope_theta` / `partial_rotary_factor` / `rope_scaling`.
  - The vision tower reads `spatial_merge_size` / `temporal_patch_size` directly.
- Upstream reports `hidden_act="silu"` and drops `swiglu_beta`, so the `swigluoai` check is removed and beta is fixed at 1.0, the value in every checkpoint and in the upstream reference model. `sparse_init_block` and `sparse_score_type` fall back to the indexer's defaults (`0`, `"max"`), which also match every checkpoint.
- **Fix:** re-saved checkpoints in the upstream schema (e.g. `lukealonso/MiniMax-M3-NVFP4`) failed with "Unsupported activation: silu"; they now build.
- No numerics change: greedy outputs are bit-identical to `main`, and GSM8k and GPQA Diamond match.
- Open MiniMax-M3 PRs that add reads of the old field names will need a rebase once this lands: #60930, #61370, #57909, #59653, #57832, #60528.
