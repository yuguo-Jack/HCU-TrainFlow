# [Benchmarks] Add model-free EngineCore IPC microbenchmark

[Upstream PR](https://github.com/vllm-project/vllm/pull/60380) · state: open · merged: False

## Original PR description

## Overview

Add a model-free serialization and cross-process IPC benchmark. Fixes #46121.

## Claims

- Measure Msgpack encode/decode and ZMQ echo round trips over IPC or localhost TCP.
- Report p50/p90/p99, operations/s, wire bytes and inline/aux frame counts as JSONL.
- Use the serving socket helper, `copy=False` and the configured zero-copy threshold.

## Validation

```sh
.venv/bin/python benchmarks/benchmark_engine_ipc.py --mode serialization --iterations 1000
.venv/bin/python benchmarks/benchmark_engine_ipc.py --transport ipc --iterations 1000
.venv/bin/python benchmarks/benchmark_engine_ipc.py --transport tcp --iterations 1000
.venv/bin/python -m pytest tests/v1/test_serial_utils.py -q
```

All three modes completed for 128, 255, 256, 257, 4096 and 1048576 bytes, with decoded payload checks. Existing tests: **12 passed**. Full pre-commit passed on the new script. Also checked empty arrays, zero warmup, a 1024-byte configured threshold and rejection of invalid CLI values.

One run per mode, 100 warmups and 1000 measured iterations per size. AMD EPYC 9V74 (5 exposed CPUs), Linux 6.18.44, Python 3.12.14, pyzmq 27.2.0 / libzmq 4.3.5, msgspec 0.22.0, NumPy 2.3.5.

| Array bytes | Frames | Serialization p50 (µs) | IPC p50 (µs) | TCP p50 (µs) |
|---:|---:|---:|---:|---:|
| 255 | 1 | 2.70 | 123.59 | 143.15 |
| 256 | 2 | 2.43 | 141.53 | 169.72 |
| 1048576 | 2 | 2.43 | 391.74 | 368.34 |

These runs overlapped on a shared host. The numbers demonstrate the tool and frame boundary, not an optimization or transport comparison.

## Details

The echo worker runs in a separate spawned process; the timed round trip includes encoding and decoding at both ends. Payload size is one uint8 array, not total wire size. Startup, warmup and the final content check are outside the measured loop. Sockets use temporary IPC paths or dynamically assigned localhost ports, with timeouts and worker cleanup.

This is a synthetic, single-request-at-a-time microbenchmark. It does not measure engine scheduling, asynchronous pipelining, model execution or serving throughput; no inference code changes or model evaluation are involved.

No matching open PR was found by issue-number and IPC benchmark searches. The issue's June ownership comments have no linked implementation. AI assistance was used to implement and validate this change.
