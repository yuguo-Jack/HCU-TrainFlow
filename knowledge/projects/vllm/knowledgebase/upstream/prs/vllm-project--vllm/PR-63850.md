# [CI][ROCm] Preflight idle-GPU check in test_pp_cudagraph

[Upstream PR](https://github.com/vllm-project/vllm/pull/63850) · state: closed · merged: True

## Original PR description

 ## Summary
- `distributed/test_pp_cudagraph.py` (ROCm) waits for GPU memory to settle before starting a server, so a just-exited process's VRAM lingering on a shared CI host doesn't trip vLLM's startup free-memory check.
- Reuses the existing `wait_for_memory_to_settle()` from `tests/utils.py` — the same utility `vllm_runner` already uses for this exact problem. No new helper code, no changes to shared test infrastructure at all; this PR is a single-file, 1-call-site change.
