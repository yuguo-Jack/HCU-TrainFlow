# [ROCm][DSv4] AITER MegaMoEV2 Integration For DeepSeek V4

[Upstream PR](https://github.com/vllm-project/vllm/pull/59685) · state: closed · merged: True

## Original PR description

## Description
This PR integrates [AITER's MegaMoEV2](https://github.com/ROCm/aiter/blob/main/aiter/ops/flydsl/kernels/mega_moe/mega_moe_v2.py) for DeepSeek-V4. The new backend is opt-in via `--moe-backend aiter_mega_moe`. MegaMoEV2 is a FlyDSL implementation that fuses the routed experts (EP dispatch, MXFP4 GEMM1 + SwiGLU, GEMM2, combine). In this example config I profiled, it boils down into four kernels per layer `megamoe_prepare`, `megamoe_stage1`, `megamoe_stage2`, `ep_combine_intranode`.
<img width="3185" height="355" alt="image" src="https://github.com/user-attachments/assets/e65d2308-6160-4184-9ab7-6d3a22511834" />

The current implementation of `--moe-backend aiter` instead had 10 kernels plus an extra `__amd_rocclr_copyBuffer` in the config that I profiled (MoRI EP) for comparison.

From my testing, MegaMoEV2 requires >4GB for `MORI_SHMEM_HEAP_SIZE`, so I have set the default to 8G in this PR. MoRI has a descriptive error message if you override this to a smaller value.

## Usage 
Requirements (enforced in the code):
- gfx950
- DP + EP  (`--enable-expert-parallel`, TP=1, PP=1)
- MoRI all2all backend
- no EPLB

Example server: `VLLM_ROCM_USE_AITER=1 MORI_SHMEM_HEAP_SIZE=8G vllm serve /models/DeepSeek-V4-Pro --data-parallel-size 8 --enable-expert-parallel --all2all-backend mori_high_throughput --moe-backend aiter_mega_moe`

## Performance and Accuracy

I've evaluated lm_eval scores as well as performance for several shapes with and without DSpark. All tests used the following serve commands (with `--moe-backend` varied accordingly):

**No DSpark**: `VLLM_ROCM_USE_AITER=1 MORI_SHMEM_HEAP_SIZE=8G vllm serve /models/DeepSeek-V4-Pro --tokenizer-mode deepseek_v4 --data-parallel-size 8 --enable-expert-parallel --all2all-backend mori_high_throughput   --no-enable-prefix-caching --port 8000 --moe-backend {aiter, aiter_mega_moe}`

**DSpark** (`num_speculative_tokens=3`):
```
VLLM_ROCM_USE_AITER=1 MORI_SHMEM_HEAP_SIZE=8G  \
vllm serve /models/DeepSeek-V4-Pro-DSpark --tokenizer-mode deepseek_v4 \
  --data-parallel-size 8 --enable-expert-parallel --all2all-backend mori_high_throughput \
  --no-enable-prefix-caching --port 8000 \
  --moe-backend {aiter, aiter_mega_moe} \
  --speculative-config '{"method":"dspark","num_speculative_tokens":3,"draft_sample_method":"greedy"}'
```
