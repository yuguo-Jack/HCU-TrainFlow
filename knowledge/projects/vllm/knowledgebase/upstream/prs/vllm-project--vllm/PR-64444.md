# [Bugfix][KV Offload] Publish successful stores to lookup state

[Upstream PR](https://github.com/vllm-project/vllm/pull/64444) · state: closed · merged: True

## Original PR description

## Summary

Builds on the invalidation approach in #61187. When this instance successfully stores keys to a filesystem or object-store tier, it publishes them as present in the tier's lookup state. This updates cached misses and prevents older pending or in-flight probes from overwriting the store result.

Unlike #61717, this preserves cross-request miss reuse instead of probing again for every request. It handles successful stores by this instance only; writes from other instances to shared storage remain out of scope, so this does not close #61658.
