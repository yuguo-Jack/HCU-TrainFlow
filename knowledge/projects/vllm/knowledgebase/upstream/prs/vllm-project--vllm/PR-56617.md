# [Bugfix][Pooling] Release cached queries when Flash scoring is cancelled

[Upstream PR](https://github.com/vllm-project/vllm/pull/56617) · state: open · merged: False

## Original PR description

## Overview

Finish Flash late-interaction request cleanup before releasing cached queries, including repeated cancellation and model batches still executing through Ray. This builds on the basic cache-release implementation in #58975.

## Claims

- Stop and join query/document producers before aborting remaining requests, and protect cleanup from repeated cancellation.
- Add an opt-in `wait_for_inflight_batches` argument to collective RPC so an executing batch cannot recreate a query cache after release.
- Preserve pending batch outputs and scheduler metadata, including Ray compiled-DAG outputs that can only be consumed once.

## Details

The serving regression focuses on repeated cancellation during abort and cache release. The DP argument-forwarding test has been removed, and the unchanged worker implementation uses its existing tests. Request-error/producer-stop behavior and one-shot batch result/exception preservation retain separate tests. The diff is 332 changed lines including tests, with 110 in production code.

#58975 already supplies basic cache release and private document IDs; this PR reuses that worker API. The remaining gaps are producer completion, interrupted cleanup and ordering against submitted batches. Existing retryable/non-retryable request-error behavior is preserved.

Ray model execution and ordinary worker RPCs run on different threads. The opt-in wait consumes queued outputs in execution order and preserves them for the scheduler before issuing cleanup. If a batch fails, its exception is preserved and propagated. Default collective RPC calls retain their existing behavior.

The A10 checks used complete target Python packages with an existing image's native artifacts, TP=DP=PP=1. They are functional cancellation/scoring smoke tests, without ranking-quality or performance evaluation. Main already passes ordinary stage-boundary cancellation after #58975; the older baseline leak result is not a claim about this main revision. The Ray reproducer does not establish multi-GPU or distributed deployment coverage.

```python
"""CPU Ray compiled-DAG reproducer; run against main and the PR checkout."""
import inspect
import threading
import time
from collections import deque
from functools import partial
from types import SimpleNamespace

import ray
import torch
from ray.dag import InputNode, MultiOutputNode

from vllm.pooling_params import LateInteractionParams, PoolingParams
from vllm.v1.engine.core import EngineCore
from vllm.v1.executor.ray_executor import RayDistributedExecutor
from vllm.v1.outputs import ModelRunnerOutput
from vllm.v1.pool.late_interaction_runner import LateInteractionRunner


@ray.remote(num_cpus=1)
class Worker:
    def __init__(self):
        self.runner = LateInteractionRunner(enable_flash=False)
        self.gate = threading.Event()
        self.started = False
        self.events = []

    def execute_model_ray(self, inputs):
        self.started = True
        self.events.append("batch started")
        assert self.gate.wait(30)
        self.runner.postprocess_pooler_output(
            [torch.ones((2, 4))],
            [PoolingParams(late_interaction_params=LateInteractionParams(
                mode="cache_query", query_key="A", query_uses=1))],
            ["A"], [True],
        )
        self.events.append("cache written")
        return ModelRunnerOutput(req_ids=["A"], req_id_to_index={"A": 0})

    def execute_method(self, method, *args, **kwargs):
        return getattr(self, method)(*args, **kwargs)

    def release(self, keys):
        self.events.append("cleanup")
        self.runner.release_queries(keys)

    def open_gate(self):
        self.gate.set()

    def state(self):
        return self.started, self.events, sorted(self.runner._query_cache)


def main():
    ray.init(num_cpus=2, include_dashboard=False, log_to_driver=False,
             object_store_memory=100 * 1024 * 1024)
    worker = Worker.remote()
    with InputNode() as inputs:
        graph = MultiOutputNode([worker.execute_model_ray.bind(inputs)])
    dag = graph.experimental_compile()
    timer = None
    try:
        executor = SimpleNamespace(forward_dag=dag, has_connector=False,
                                   workers=[worker])
        executor.collective_rpc = partial(
            RayDistributedExecutor.collective_rpc, executor)
        scheduled = SimpleNamespace()
        future = RayDistributedExecutor._execute_dag(
            executor, scheduled, None, non_block=True)
        deadline = time.monotonic() + 30
        while not ray.get(worker.state.remote())[0]:
            assert time.monotonic() < deadline
            time.sleep(0.01)
        core = SimpleNamespace(batch_queue=deque([(future, scheduled, future)]),
                               model_executor=executor)
        wait = "wait_for_inflight_batches" in inspect.signature(
            EngineCore.collective_rpc).parameters
        timer = threading.Timer(1, lambda: ray.get(worker.open_gate.remote()))
        timer.start()  # Independent of cleanup returning, including on branch.
        EngineCore.collective_rpc(
            core, "release", args=(["A"],),
            **({"wait_for_inflight_batches": True} if wait else {}))
        queued = core.batch_queue[0][0]
        output = queued.result(timeout=30)
        timer.join()
        _, events, cache = ray.get(worker.state.remote())
        assert output.req_ids == ["A"]
        assert cache == ([] if wait else ["A"])
        if wait:
            assert queued.result() is output  # No second CompiledDAGRef read.
        print("ref:", type(future.ref_or_refs).__name__)
        print("wait:", wait, "events:", " -> ".join(events))
        print("cache:", cache, "output:", output.req_ids)
        print("queued future replaced:", queued is not future)
    finally:
        if timer:
            timer.join(15)
        dag.teardown()
        ray.kill(worker)
        ray.shutdown()


if __name__ == "__main__":
    main()
```
