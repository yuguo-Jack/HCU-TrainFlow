# [Fast Start] Support compressed-tensors CUTLASS block FP8 cache restarts

[Upstream PR](https://github.com/vllm-project/vllm/pull/63976) · state: open · merged: False

## Original PR description

## Overview

Enable CUDA IPC weight-cache restarts for serialized compressed-tensors 128×128 block FP8 linear weights. Part of #56049.

This is now independent, directly based on main `34d5de18cd8b`. [Review only this feature](https://github.com/liusy58/vllm/compare/34d5de18cd8baf9f5958e45720858939863a7264...d8f56f42ec4e9a8bfc020de0e6e0b786994f7edd); head `d8f56f42ec4e`. Rebuilt in response to Zifeng’s request to decouple the stacked PRs.

## Claims

- Reuse processed weights/scales across engine restarts with the validated CUTLASS backend.
- Preserve exact outputs, shared storage and required Python metadata; unsupported configurations remain rejected.
- Include only this feature and its necessary common plumbing beyond merged main.

## Validation

B300, November 4, exact source hashes verified against this head:

| Check | Result |
|---|---|
| Layer/configuration regressions | 16 passed, 46 deselected in 17.25s |
| Real model: ordinary → fallback → IPC → second IPC | 1 passed in 118.06s |
| All changed-file pre-commit hooks | Passed, including mypy, ruff and CI test tethering |

Both IPC loads forbid fallback. Exact greedy outputs use `VLLM_BATCH_INVARIANT=1`; layer tests also verify shared pointers and unchanged tensors. The real model is `RedHatAI/Qwen3-0.6B-FP8-BLOCK`, pinned to `5def00c475640c0527e3a7067b1a26b94decefb5`, with its checked-in configuration unchanged.

```bash
CUDA_VISIBLE_DEVICES=7 HF_HUB_OFFLINE=1 PYTHONPATH=. .venv/bin/python -m pytest tests/quantization/test_compressed_tensors.py -k 'preprocessed or test_scheme_selection' -q -rs
CUDA_VISIBLE_DEVICES=7 HF_HUB_OFFLINE=1 PYTHONPATH=. .venv/bin/python -m pytest tests/model_executor/model_loader/test_weight_cache.py::test_ipc_cache_compressed_block_fp8 -q -rs
pre-commit run --files $(git diff 34d5de18cd8baf9f5958e45720858939863a7264 HEAD --name-only)
```

The isolated runtime used Python 3.12, Torch 2.14/cu130, FlashInfer 0.7.2.post1, process-local CUDAcompat13.4, and reused stable extensions from `5d55ef159`. Relevant CUTLASS FP8 C++ is unchanged; unrelated HiSparse binding and removed Qutlass-wrapper changes are outside these tests. This is targeted smoke/output equivalence, not a pristine full-source rebuild, full accuracy evaluation, performance benchmark, or upstream GPU CI result. No new skips, retries or weakened assertions were added. GPU occupancy guards prevented launches onto busy GPUs; other workloads were untouched.

## Details

Only the actual CUTLASS block-FP8 kernel with 128×128 blocks opts in. IPC retains the untransposed layout and dynamic group-128 activation state. Tensor/channel FP8 from #63673 is not included in this branch.

This includes the minimal compressed-tensors capability bridge and attention-buffer restoration shared with #63673, so it can land first. Neither PR requires the other. If both merge, retain both narrow capability cases; the shared hook may need a textual conflict resolution.
