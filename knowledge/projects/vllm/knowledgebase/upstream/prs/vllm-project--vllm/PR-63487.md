# [Bugfix] Propagate EngineDeadError on AsyncLLM output_handler cancellation

[Upstream PR](https://github.com/vllm-project/vllm/pull/63487) · state: open · merged: False

## Original PR description

## Overview
Notify active request collectors with EngineDeadError when the background output_handler task is cancelled in AsyncLLM.

## Motivation & Behavior Change
- In Python 3.8+, asyncio.CancelledError derives from BaseException so it bypassed the \except Exception\ block in \output_handler\.
- When \output_handler\ is cancelled (e.g., during \AsyncLLM.shutdown()\ or worker cancellation), active request collectors never received an error notification and remained blocked indefinitely on \wait self.ready.wait()\.
- **Behavior change**: Pending requests now fail fast with \EngineDeadError\ instead of hanging. When shutting down with zero active requests, \propagate_error\ is a clean no-op over empty states.
- Re-raises \syncio.CancelledError\ so the background task cleanly transitions to cancelled.
