# [rust][tool-parser] Add step3 tool parser

[Upstream PR](https://github.com/vllm-project/vllm/pull/46369) · state: open · merged: False

## Original PR description

## Overview

Adds the Rust frontend Step3 StepTML tool parser associated with #44280. Select it explicitly with `--tool-call-parser step3`.

## Claims

- Parses single and parallel tool calls, schema-typed arguments, and surrounding text.
- Accepts both the canonical `function<｜tool_sep｜>` prefix and the prefix-free Python fixture format, including markers and tags split across streamed chunks.
- Preserves special tokens and registers `step3` by exact name, keeping Step3p5 routing separate.

## Validation

Rebased onto `main` at `a98247ab4db686ee03c66d5feb3c761e52a2f8ab`. The rebase preserves upstream HF and MiMo registrations and tests; the Step3 implementation is unchanged.

On the pinned Rust 1.95 toolchain:

```bash
cargo test --manifest-path rust/Cargo.toml -p vllm-parser
# 563 passed; one existing doctest ignored
cargo fmt --manifest-path rust/Cargo.toml --all -- --check
cargo clippy --manifest-path rust/Cargo.toml -p vllm-parser --all-targets -- -D warnings
git diff --check upstream/main...HEAD
```

All checks above passed. Chat validation on Linux ARM64 with Rust 1.95 also passed:

```bash
cargo test --manifest-path rust/Cargo.toml -p vllm-chat --lib -- --test-threads=1
# 352 passed
```

Linux validation used the exact PR Rust source snapshot in `rust:1.95-slim-bookworm` (digest `sha256:d7482085ff5b415f84dba5647ae71606650bdef00db7aeb69f4b3d170c3e4082`), with build-essential, pkg-config, libssl-dev, protobuf-compiler, cmake, and git installed. The macOS chat build is blocked by the unchanged upstream engine client's `socket2::Socket::domain()` call, which is unavailable on macOS. Serial execution avoids the existing audio tracing test's interference under parallel execution.

No GPU-backed Step3 model-generation evaluation was run. Deterministic parser and chat unit tests validate parsing of already-generated text. Full model roundtrip and chat integration suites were not rerun on this base.

## Details

Reuses buffered-event parsing, marker scanning, and schema conversion without new dependencies or changes to other parser contracts. Arguments are emitted after a complete tool-call block. Malformed or incomplete blocks return a parsing error.

Duplicate-work check: current main has no Rust Step3 tool parser. #52946 implements the distinct Step3p5 `<tool_call><function=...><parameter=...>` protocol and identifies #46369 as separate; other Step3 tool-parser fixes target Python.

AI assistance was used for implementation, rebase, and validation. The human submitter remains responsible for reviewing the changed lines and defending the contribution.
