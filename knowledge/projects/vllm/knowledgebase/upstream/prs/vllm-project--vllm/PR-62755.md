# [Doc] Add Pixeltable framework integration guide

[Upstream PR](https://github.com/vllm-project/vllm/pull/62755) · state: open · merged: False

## Original PR description

## Overview

Add a Pixeltable framework integration guide at `docs/deployment/frameworks/pixeltable.md`, next to the other framework pages.

The author, Pierre Brunelle, is a Pixeltable cofounder.

## Claims

- Documents installing Pixeltable and running vLLM in-process as a computed column through `pixeltable.functions.vllm.chat_completions`.
- Documents calling a vLLM OpenAI-compatible server through `pixeltable.functions.openai` by setting `OPENAI_BASE_URL` and `OPENAI_API_KEY`.

## Validation

- Checked the examples against `pixeltable/functions/vllm.py` and the OpenAI client factory on pixeltable `main`. Public vLLM UDFs are `chat_completions(messages, *, model, engine_args=None, sampling_params=None)` and `generate(prompt, *, model, engine_args=None, sampling_params=None)`. The OpenAI client accepts `base_url` from `OPENAI_BASE_URL` or the `openai` section of the Pixeltable config.
- `pre-commit run --files docs/deployment/frameworks/pixeltable.md` passed, including `markdownlint-cli2` and `typos`.
- Documentation only. No model evaluation.

## Details

Pixeltable users run inference inside tables. This page follows the Deployment → Frameworks guides (Haystack, LiteLLM): install steps, a short example, and a link to the Pixeltable vLLM tutorial.

`docs/.nav.yml` lists the `deployment/frameworks` directory, so the new page is included without a nav edit.

Related: #48790 adds a different page at `docs/serving/integrations/pixeltable.md`. This change is the frameworks deployment guide and also shows the OpenAI-compatible server path. It does not edit the serving integrations section.
