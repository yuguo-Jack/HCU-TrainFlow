# [Doc][ROCm] Align Kimi-K3 MI355X AgentX recipe with InferenceX #4393

[Upstream PR](https://github.com/vllm-project/vllm/pull/63520) · state: closed · merged: True

## Original PR description

## Overview

Align the authoritative Kimi-K3 MI355X AgentX guide with [InferenceX #4393](https://github.com/SemiAnalysisAI/InferenceX/pull/4393), replacing the previous [#4215 alignment](https://github.com/vllm-project/vllm/pull/62273). This updates only `recipes/models/moonshotai/Kimi-K3.yaml`.

## Claims

- All ten documented lanes use TP8/DCP8/A2A and fused KDA prefill on `nightly-rocm100-df6603f0583375f244d1ac6d36265462b7490392`.
- Only resident c1 enables `latency_specialized` and V2, without target online FP8 quantization or a KV connector; other lanes retain their source quantization/offload settings.
- An explicit resident/offload selector distinguishes the two c4 lanes. Production/eval commands use real block verification; synthetic acceptance remains in a separate throughput-only section.

## Validation

Passed locally against recipes renderer `f7e8b4ac02716ffd5938c9c3a594960d314cdc2f` (`VLLM_CHECKOUT` is the tested vLLM checkout):

```bash
pre-commit run --files recipes/models/moonshotai/Kimi-K3.yaml
# In the recipes renderer checkout, with a local vllm source override:
node scripts/validate-source.mjs --source vllm --dir "$VLLM_CHECKOUT/recipes"
node scripts/sync-sources.mjs
node scripts/build-recipes-api.mjs
pnpm test:overlay
pnpm test:schema
pnpm test:guide-html
```

Actual synthesis of 16 MI355X TP8/Python feature/offload combinations produced identical Serve, Docker, Verify and Bench commands before/after. The local browser rendered the ten-row guide and separate production/synthetic blocks; MI355X/Python/speculative decoding/DCP/Simple selectors worked without JavaScript errors. The fresh preview lacked provider-logo assets (404s only under `/providers/`).

The source validator/API build covered 217 recipes; overlay/schema/guide checks passed 7/4/17 tests. Executed the guide's actual Bash with a stub `vllm` for every lane and compared arguments, JSON and environment against InferenceX's real recipe binder: **10/10 match**, including draft lengths, graph captures, target quantization and connector settings. Unsupported selectors (resident c2, offload c1, unknown profile) exit before invocation; `bash -n` passes.
