## Details

Related work: #61156 caps the static NIXL reservation and relies on synchronized chunking from #60900. This layer retains the reservation upper bound and derives each call's aligned capacity from synchronized padded execution slices, never rank-local real token counts. The two capacity contracts need reconciliation before merge.

vLLM #61156 bounds static NIXL dispatch and uses synchronized chunking; this layer selects per-call capacity from the synchronized execution slice. Reconcile the two approaches before merge. No throughput improvement is claimed.
