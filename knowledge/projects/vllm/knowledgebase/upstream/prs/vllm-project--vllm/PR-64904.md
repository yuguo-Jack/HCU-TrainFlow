# [Bugfix][Structured Output] Preserve raw scores before grammar masking

[Upstream PR](https://github.com/vllm-project/vllm/pull/64904) · state: open · merged: False

## Original PR description

## Overview

Return structured-output raw scores from the unmasked logits, while sampling from grammar-masked logits. Fixes #64809; the previous attempt in #64811 is closed.

## Claims

- `raw_logprobs` and `raw_logits` keep their pre-grammar values in both GPU runners, including speculative target and bonus scores.
- Grammar masking now runs after raw-score computation in V1, and on the sampler's working copy in V2. V2 verification reuses its chunk-sized FP32 buffer instead of retaining an extra copy of the entire logits batch.
- Processed scores still use the constrained distribution. Batches without raw-score requests keep the existing in-place mask path.

## Validation

The original real-model regression failed before the fix: a raw log probability changed from about `-3.265147` to `-0.175932` when a grammar was added.

On the revised implementation:

Rebased onto `51c6dfd` and adapted the verification callback and regression to the upstream `logprobs_dims` interface. After the rebase, all 98 sampler/chunking tests, five real-model regressions and applicable changed-file pre-commit hooks passed locally.

- Four `facebook/opt-125m` regressions passed: V1/V2 × raw logprobs/logits.
- A real V2 n-gram run accepted draft tokens and matched ordinary generation's tokens and raw scores, with batch-invariant mode enabled and the original `1e-4` tolerance.
- The rejection-sampler and chunking test files passed: **98 tests**. The new chunk test uses real sampler and mask-worker instances, reversed grammar request order, an unconstrained request, padded mask rows, and greedy/seeded temperature sampling.
- Applicable pre-commit hooks passed, including mypy and Buildkite test tethering. The existing V1 Sample and V1 Executor + Worker jobs select these tests.

"""Compare the clone-based intermediate commit with deferred grammar masking."""
from dataclasses import replace
import gc
import importlib.util
import json
from pathlib import Path
import statistics
import subprocess
import tempfile
import time

import numpy as np
import torch

from vllm.config import SpeculativeConfig, VllmConfig
from vllm.sampling_params import SamplingParams
from vllm.v1.worker.gpu.input_batch import InputBatch, InputBuffers
from vllm.v1.worker.gpu.sample.sampler import Sampler
from vllm.v1.worker.gpu.spec_decode.rejection_sampler import RejectionSampler, get_max_chunk_logits
from vllm.v1.worker.gpu.states import RequestState
from vllm.v1.worker.gpu.structured_outputs import StructuredOutputsWorker


snapshot = tempfile.TemporaryDirectory()


def published(name, relative):
    path = Path(snapshot.name) / (name + '.py')
    path.write_bytes(subprocess.check_output([
        'git', 'show', 'd9598b175be3e745f5e35a2cc5abbb99e053a8a7:' + relative
    ]))
    spec = importlib.util.spec_from_file_location(name, path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


old_rejection = published('published_rejection', 'vllm/v1/worker/gpu/spec_decode/rejection_sampler.py')
old_mask = published('published_mask', 'vllm/v1/worker/gpu/structured_outputs.py')
device = torch.device('cuda')
num_reqs, width, vocab = 576, 16, 32768
rows = num_reqs * width
batch = InputBatch.make_dummy(num_reqs, rows, InputBuffers(num_reqs, rows, device))
cu = np.arange(0, rows + 1, width, dtype=np.int32)
batch = replace(batch,
    cu_num_logits_np=cu,
    cu_num_logits=torch.from_numpy(cu).to(device),
    expanded_idx_mapping=torch.repeat_interleave(batch.idx_mapping, width),
    expanded_local_pos=torch.arange(width, dtype=torch.int32, device=device).repeat(num_reqs),
)
req_states = RequestState(num_reqs, 32, rows, width - 1, vocab, device)
sampler = Sampler(VllmConfig(), num_reqs, vocab, device, req_states)
for i in range(num_reqs):
    sampler.add_request(i, SamplingParams(temperature=0.7, seed=7, logprobs=2))
sampler.apply_staged_writes()
config = SpeculativeConfig(method='ngram', num_speculative_tokens=width - 1)
old = old_rejection.RejectionSampler(sampler, config, device)
new = RejectionSampler(sampler, config, device)
old_worker = old_mask.StructuredOutputsWorker(rows, vocab, device, width)
new_worker = StructuredOutputsWorker(rows, vocab, device, width)
bitmask = np.zeros((rows, vocab // 32), dtype=np.int32)
bitmask[:, 0] = 2  # Only token 1 is valid at every grammar position.
logits = torch.zeros((rows, vocab), device=device)
draft = torch.ones(rows, dtype=torch.int32, device=device)
pos = torch.arange(width, device=device).repeat(num_reqs)
chunk_limit = get_max_chunk_logits(vocab)
torch.cuda.synchronize()


def run(mode):
    logits.zero_()
    torch.cuda.synchronize()
    torch.cuda.reset_peak_memory_stats()
    started = time.perf_counter()
    if mode == 'published':
        raw = logits.clone()
        old_worker.apply_grammar_bitmask(logits, batch, batch.req_ids, bitmask)
        output = old._verify_in_chunks(logits, batch, None, draft, pos, chunk_limit, (2, 0), raw)
    else:
        apply = new_worker.prepare_grammar_bitmask(batch, batch.req_ids, bitmask)
        output = new._verify_in_chunks(logits, batch, None, draft, pos, chunk_limit, (2, 0), apply)
    torch.cuda.synchronize()
    seconds = time.perf_counter() - started
    peak = torch.cuda.max_memory_allocated() / 2**20
    sampled, counts, scores, _ = output
    assert torch.all(sampled == 1)
    assert torch.all(counts == width)
    expected = -np.log(vocab)
    torch.testing.assert_close(scores.logprobs[:, 0], torch.full((rows,), expected, device=device))
    return {'peak_allocated_mib': peak, 'seconds': seconds}


results = {}
for mode in ['published', 'revised']:
    run(mode)  # Compile and warm up before measuring.
    gc.collect()
    samples = [run(mode) for _ in range(3)]
    results[mode] = {'runs': samples,
        'median_peak_allocated_mib': statistics.median(x['peak_allocated_mib'] for x in samples),
        'median_seconds': statistics.median(x['seconds'] for x in samples)}
    print(mode, json.dumps(results[mode]), flush=True)
results['config'] = {'requests': num_reqs, 'rows_per_request': width, 'vocab': vocab,
    'chunk_rows': chunk_limit, 'logits_mib': rows*vocab*4/2**20, 'gpu': torch.cuda.get_device_name()}
print(json.dumps(results, indent=2), flush=True)
Path(__file__).with_name('review-memory-rebased-20261102.json').write_text(json.dumps(results, indent=2))

## Details

The runners previously masked logits before the samplers could compute raw scores. Following @StevenZhangzhexu's suggestion, the mask is now deferred when raw scores are requested. V1 selects the matching mask rows after gathering speculative target/bonus rows. V2 stages the mask once, keeps request/position mapping on device, and subtracts each chunk's starting row in the mask kernel. Rows outside that chunk and unused speculative positions are skipped.

The V2 callback shares the existing sampling-parameter copy. If no other processor needs a copy, it creates one for the current chunk so the raw logits remain intact. Each chunk launches a mask kernel; the mask itself is not recopied between chunks. Stream dependencies protect mask-buffer initialization and reuse without adding a host synchronization.
