# fix: [Feature]: Support `Phi4Flash` model in V1

[Upstream PR](https://github.com/vllm-project/vllm/pull/44963) · state: open · merged: False

## Original PR description

## Summary

`Phi4FlashForCausalLM` was dropped when V0-only pieces were removed. The model file was deleted, the architecture stayed in `_PREVIOUSLY_SUPPORTED_MODELS`, its Mamba block still depended on V0 cache management, and its differential attention path no longer had a V1 backend.


## Root cause

`Phi4FlashForCausalLM` was dropped when V0-only pieces were removed. The model file was deleted, the architecture stayed in `_PREVIOUSLY_SUPPORTED_MODELS`, its Mamba block still depended on V0 cache management, and its differential attention path no longer had a V1 backend.


## What changed

- Added `vllm.model_executor.models.phi4flash.Phi4FlashForCausalLM`.
- Added `vllm.model_executor.models.phi4flash.SambaYModel` and `vllm.model_executor.models.phi4flash.SambaYDecoderLayer`.
- Added `vllm.model_executor.models.phi4flash.SambaYAttention` with V1 attention wiring and KV sharing for YOCO layers.
- Added `vllm.model_executor.models.phi4flash.Phi4FlashMamba` as a V1 `MambaBase` layer and `vllm.model_executor.models.phi4flash.Phi4FlashYocoCrossMamba` for the stateless cross-gating path.
- Added `vllm.v1.attention.backends.differential_flash_attn.DifferentialFlashAttentionBackend` and `vllm.v1.attention.backends.differential_flash_attn.DifferentialFlashAttentionImpl`.
- Registered `AttentionBackendEnum.DIFFERENTIAL_FLASH_ATTN` in `vllm.v1.attention.backends.registry`.
- Restored `Phi4FlashForCausalLM` to the active model registry in `vllm.model_executor.models.registry`.
- Added the example entry for `Phi4FlashForCausalLM` in `tests.models.registry` with prefix caching disabled.
