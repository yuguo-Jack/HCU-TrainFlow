# [bugfix] nemotron-super-35-vl-make-sure-all-layers-are-loaded

[Upstream PR](https://github.com/vllm-project/vllm/pull/59664) · state: closed · merged: False

## Original PR description



## Overview

Nemotron Super vision checkpoints include `vision_projector.vision_final_layernorm.{weight,bias}`, but the native loader silently discards these tensors and omits the layer from feature extraction. Load and apply the final vision LayerNorm.

## Claims

- Load the final vision layer norm in nemotron vl encoder, if it is part of the model

## Validation

- Verify that the model loads the layer
- Sanity accuracy - GSM8K and video-mme-ci-short-100-evs_0_5, no significant gain/loss of accuracy (we know the final layer has little effect on most use cases)
