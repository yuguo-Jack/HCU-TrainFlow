# [XPU][UT] Use W8A8 FP8 linear kernel instead of W8A16 on XPU in modernbert_fp8 unit test

[Upstream PR](https://github.com/vllm-project/vllm/pull/63281) · state: closed · merged: True

## Original PR description

## Overview

In modernbert_fp8 unit test, use W8A8 fp8 linear kernel instead of W8A16 on XPU to align with CUDA and make it pass.

## Claims

- On XPU, this ut will call W8A16 fp8 linear kernel `XPUW8A16FP8LinearKernel` and fail.
- On CUDA, this ut calls the W8A8 kernel `CutlassFP8ScaledMMLinearKernel` by default, and it can pass. Using W8A16 kernel `MarlinFP8ScaledMMLinearKernel` will also make the ut fail on cuda.
- This PR uses `XPUW8A8FP8LinearKernel` on XPU by setting `"linear_backend": "xpu"` in this case to resolve the issue.

here is the score summary for a clearer comparison:
```
reference: 0.748193353
XPU W8A16: 0.7448422 (fail)
XPU W8A8: 0.7494126 (pass)
CUDA W8A16: 0.7448861 (fail)
CUDA W8A8: 0.7474482 (pass)
```

So I suppose the hard-coded reference was actually calculated with W8A8 on cuda.
