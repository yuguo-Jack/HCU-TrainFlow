# [XPU][UT] Add and Fix 2-card bitsandbytes plugin CI test case on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/62852) · state: closed · merged: False

## Original PR description

## Overview

Add 2-GPU bitsandbytes plugin test cases to Intel CI. Use `--no-deps` during installation of `vllm-bnb-plugin` to preserve versions of certain packages (eg, `intel-sycl-rt==2026.1.1`), because `pip install vllm-bnb-plugin` will downgrade `intel-sycl-rt` to `2026.1.0` and cause oneccl error during xpugraph capture.

## Claims

- Add the bitsandbytes tests marked `distributed(num_gpus=2)` to Intel CI jobs (only add yaml and not add to CI run)
- Regular plugin installation `pip install vllm-bnb-plugin` downgrades `intel-sycl-rt` from 2026.1.1 to 2026.1.0 to satisfy pytorch wheel's dependency, causing oneccl errors during XPUGraph capture and incorrect outputs.
- Installing bitsandbytes and vllm-bnb-plugin with `--no-deps` fixes the issues.

## Validation
### Before this PR
To reproduce the failure (refer to https://github.com/vllm-project/vllm/pull/48761/changes#diff-3322e76c17515e1831a906d43b18575ce0c5ff1d95c09d655ad833d501429780R163 and also [cuda CI](https://github.com/vllm-project/vllm/blob/main/.buildkite/test_areas/plugins.yaml#L125)):
```
pip install vllm-bnb-plugin\>=0.0.1 && pytest -v -s tests/plugins_tests/bitsandbytes -m 'distributed(num_gpus=2)'
```

Results:
-  `intel-sycl-rt==2026.1.1` was removed and `intel-sycl-rt==2026.1.0` was installed
- four failed and errors were reported during captureing XPUGraphs like:
```text
2026-10-21 06:55:16:(186429) |ERROR| [__safe_call_impl:51] [onecclAllReduce] caught std::exception: ext_oneapi_get_graph() can only be called on recording queues.
```


### After this PR
To reproduce:
```
pip install --no-deps "bitsandbytes>=0.48.1" "vllm-bnb-plugin>=0.0.1" && pytest -v -s tests/plugins_tests/bitsandbytes -m 'distributed(num_gpus=2)'
```

Result: four passed. 

## Details
### Root cause
The [XPU CI image](https://github.com/vllm-project/vllm/blob/7d5335936c40306063a29fc4e2ccbe71b280e40c/docker/Dockerfile.xpu#L271) explicitly installs `intel-sycl-rt==2026.1.1` and `oneccl==2022.1.2`, while the installed PyTorch 2.14.0 wheel still pins these packages to `2026.1.0` and `2022.1.1`, respectively.

### Candidate fixes
1. Pending on the usage of a newer pytorch release in vllm docker image for XPU. [PyTorch PR #195128](https://github.com/pytorch/pytorch/pull/195128) updates `intel-sycl-rt` to `2026.1.2` and oneCCL to `2022.1.2`, which are present in `release/2.15` branch. This solution is clean but creates a dependency on the adoption of newer torch in vllm.
2. **[Implemented in this PR]** Install bitsandbytes and vllm-bnb-plugin with `--no-deps`. This allows the ut to pass on the current xpu stack.
