# [Model] Enable --mm-encoder-tp-mode data for MiMo-V2.6

[Upstream PR](https://github.com/vllm-project/vllm/pull/64179) · state: closed · merged: True

## Original PR description

## Overview

Using `--mm-encoder-tp-mode data` on MimoV2.6 exposed a bug - under data parallel the vision attention collapsed `tp_size` to 1 but kept the process's tensor-parallel rank, so on any rank > 0 the per-head slice started past the end of the head range and the sink effect was silently dropped.

## Claims

- advertise `supports_encoder_tp_data`, and collapse the rank together with the size.

## Validation

```bash
pytest tests/models/multimodal/test_mimo_v2_omni.py   # 4 passed, 2 skipped here; 3 of the 4 fail on main
```

End to end, TP4, MiMo-V2.6-Flash-MOPD, one boot per mode:

| | `--mm-encoder-tp-mode data` | default (`weights`) |
|---|---|---|
| image probes | 6/6 | 6/6 |
| 4-digit OCR, 24 images | 24/24 | 24/24 |
| multi-image conversation | 8/8 | 8/8 |


## Details

This change is a correctness and availability fix, we do not claimed any performance gain.
