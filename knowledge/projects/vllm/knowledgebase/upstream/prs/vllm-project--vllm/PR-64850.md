## Overview

Extend `tests/utils_/test_collection_utils.py` (which previously covered only `is_list_of_numbers`, `common_prefix`, and `swap_dict_values`) with tests for `as_list`, `chunk_list`, `full_groupby`, and `LazyDict`, which had no tests anywhere in `tests/`.

## Claims

- 12 new cases, including the `full_groupby` distinction that motivates the helper (non-contiguous values group together, unlike `itertools.groupby`) and `LazyDict` lazy evaluation, caching, and `KeyError` behavior.
- CPU-only, no GPU, no downloads.
