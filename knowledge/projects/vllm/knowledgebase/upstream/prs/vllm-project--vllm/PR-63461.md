# [Feature][Rust Frontend] Support scale-out request cancellation

[Upstream PR](https://github.com/vllm-project/vllm/pull/63461) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Add `POST /inference/v1/abort_requests` to the Rust frontend behind `--enable-scale-out`, replacing the 501 placeholder. Related: #44280.

## Claims

- Cancel public request IDs through the existing mapping and background cancellation path.
- Accept string/list IDs, reject invalid input, and treat an empty list as a no-op.

## Validation

Base regression: 501 instead of 200; fixed: 200. Four targeted tests and all 513 server library tests passed. Clippy, fmt and pre-commit passed.

```sh
cargo +1.95 test --manifest-path rust/Cargo.toml --locked \
  -p vllm-server --lib --all-features scale_out_abort_
```

Real-model/GPU tests were not run. Upstream pre-commit was blocked by the contributor gate.

## Details

200 means accepted for background cancellation. Non-object bodies and invalid ID types return 400, stricter than Python at the base revision. #63302 addresses Python validation; this change adds the Rust route.

AI-assisted with OpenAI Codex; the contributor reviewed the diff and ran the targeted tests.
