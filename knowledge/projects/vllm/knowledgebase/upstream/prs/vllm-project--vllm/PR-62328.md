# [Frontend] Configure request body log level through LoggingConfig

[Upstream PR](https://github.com/vllm-project/vllm/pull/62328) · state: open · merged: False

## Original PR description

## Overview

Add `request_body_log_level` to `--logging-config` and use the resolved value in both API and render servers, following the [post-merge request on #60630](https://github.com/vllm-project/vllm/pull/60630#issuecomment-6213158669).

## Claims

- JSON, dotted CLI and YAML settings override `VLLM_REQUEST_BODY_LOG_LEVEL`.
- Existing environment defaults, level aliases, invalid-level warning behavior and body truncation remain supported.

## Validation

```bash
uv run --offline --no-project --python .venv/bin/python -m pytest \
  tests/entrypoints/serve/utils/test_request_logger.py \
  tests/entrypoints/launchers/test_cli_args.py tests/test_logger.py \
  tests/entrypoints/launchers/render/test_app_state.py -q
```

113 passed. All applicable pinned pre-commit hooks passed, including mypy and test CI wiring.

Normal render-server HTTP checks confirmed INFO/DEBUG overrides in both directions and environment-only compatibility. All three changed-source response JSONs matched the baseline.

A normal API-server GPU smoke check with a local two-layer synthetic Llama and dummy weights returned four identical token IDs, text and usage before/after; the CLI-selected INFO body record was emitted with an environment default of DEBUG. This checks configuration and serving, not model quality or performance. Both sources logged `EngineDeadError` during requested shutdown after successful generation; owned processes exited and no serving-time error was observed.

## Details

The string field retains Python logging aliases and warn-and-skip behavior for invalid legacy values, including when `--log-level` or `--log-config-file` reconstructs the configuration. Logger/handler thresholds still apply.

This does not duplicate #62108, which guards serialization when logging is disabled, or #58712, which adds color/stream configuration. Their changes are outside this patch. AI assistance was used for investigation, implementation and validation.
