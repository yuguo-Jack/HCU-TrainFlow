# [BI] Add the batch-invariant CUDA op library

[Upstream PR](https://github.com/vllm-project/vllm/pull/65052) · state: open · merged: False

## Original PR description

## Overview

csrc/batch_invariant/ and its Python wrappers: K32 block-scaled GEMM, fused SiLU-mul + group quant, deterministic radix top-k, sparse paged indices, SWA-first index combine, position-based top-k lengths and replay gather, ordered expert permute/combine. Built with the CUDA gencode flags.

Split from #62365 by @aoshen02 and rebased onto current main (190df0b90).
