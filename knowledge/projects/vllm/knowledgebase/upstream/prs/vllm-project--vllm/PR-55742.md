# [ROCm] W4A16: add group size and sym/asym to profiler scope labels

[Upstream PR](https://github.com/vllm-project/vllm/pull/55742) · state: open · merged: False

## Original PR description

Extend the profiler scopes in `RDNAHybridW4A16LinearKernel` to report group size and symmetric vs asymmetric on top of `MxNxK` shapes to help reading the profile.

Labels become, for example:
```
wvsplitk_int4 1x256x1024 g=32 asym
hybrid_triton_w4a16 64x256x1024 g=128 sym
```
Testing: verified under torch.profiler on gfx1151 that all four combinations (decode/prefill x sym/asym) emit the intended label; pytest tests/kernels/quantization/test_rdna_hybrid_w4a16.py passes unchanged.
