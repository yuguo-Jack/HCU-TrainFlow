# [Rust Frontend] Support logprob_token_ids on OpenAI endpoints

[Upstream PR](https://github.com/vllm-project/vllm/pull/59549) · state: closed · merged: True

## Original PR description

## Overview

Add `logprob_token_ids` support to the Rust `/v1/chat/completions` and `/v1/completions` endpoints. Related to the selected-token item in #44280; [scope claim](https://github.com/vllm-project/vllm/issues/44280#issuecomment-5914657390).

## Claims

- Forward non-empty token selections through the existing text/engine sampling path instead of silently dropping the field; preserve the Python frontend's empty-list fallback.
- Return the selected candidates and sampled token in streaming and non-streaming responses without applying the natural top-k cut again.
- Enforce the logprobs prerequisite and completion prompt-only echo restriction, reusing existing token-count and vocabulary validation.

```json
{"model":"selected-logprobs-eval","messages":[{"role":"user","content":"The capital of France is"}],"temperature":0,"max_tokens":4,"logprobs":true,"top_logprobs":1,"logprob_token_ids":[0,1,2]}
```

## Details

The shared sampling types already support selected-token logprobs, but the two OpenAI request types omit the field and conversion hard-codes it to `None`. The change clears natural top-k sampling for a non-empty selection and uses the existing all-candidates response option for chat. No sampler, engine protocol, GPU code or dependency changes are included.

Non-duplication: merged #56406 fixes gRPC conversion; #46427 adds `/generative_scoring`, #45569 addresses broader validation, and #57394/#49320 concern Python empty-list validation. None exposes selected IDs on these two Rust OpenAI routes. #59518 and #58711 also touch shared Rust chat candidate deduplication. This PR now dedupes chat `top_logprobs` by token ID before the `top_logprobs` cut, so a sampled token that is also selected (or the top-1 token) appears once, matching Python.

Evaluation used the exact Rust patch and Python source at `cff08b461e08` with the same model snapshot, while reusing torch 2.13.0+cu132 and precompiled native extensions from the existing runtime. It was not a complete native rebuild. Rust 1.98 locally raises a newer lint in unchanged multimodal tensor code; pinned Rust 1.95 Clippy passes.

AI assistance was used for investigation, implementation and validation. The human submitter reviewed the patch and authorized this submission.
