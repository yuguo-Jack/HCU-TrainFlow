# [Bugfix][Distributed] Unpack misaligned packed tensors

[Upstream PR](https://github.com/vllm-project/vllm/pull/65009) · state: open · merged: False

## Original PR description

## Overview

Fixes #64936. A three-byte `uint8` tensor followed by an `int64` tensor currently crashes packed weight transfer because the second slice is misaligned. Clone only misaligned contiguous slices before restoring their dtype, preserving the existing wire format and aligned views.

## Claims

- Restore misaligned tensors exactly while retaining support for non-contiguous packed buffers.
- Include alignment copies in the NCCL consumer's readiness event and stream lifetime tracking, so deferred callbacks can safely read them from another buffer slot.
- Exercise CPU and GPU unpacking, misaligned broadcast/IPC roundtrips, and deferred consumer reads using the existing test suites.

## Details

Packed buffers concatenate raw bytes without padding. A contiguous slice retains its original storage offset, so `.contiguous()` alone cannot make an odd-offset slice safe to reinterpret as a wider dtype. Keep the existing contiguous conversion, then clone only if the resulting offset is not divisible by the dtype's item size.

Cloning adds asynchronous GPU work and independent storage. The NCCL consumer therefore records readiness after unpacking and records the unpacked tensors on the relevant streams. This protects both packed views and alignment copies when layerwise reload retains tensors for a later callback. No additional host/device synchronization is introduced. Misaligned tensors incur a copy, and stream tracking now covers each unpacked tensor.

Tests extend the existing deferred-consumer scenarios with float64 weights after four-byte prefixes and introduce odd-byte prefixes into broadcast and real IPC roundtrips. Hardware validation of these scenarios remains pending.

No overlapping open PR was found when searching by #64936 and packed-tensor/alignment terms before implementation on November 1, 2026. AI assistance was used for investigation, implementation, and validation. The human contributor reviewed the initial alignment change; the follow-up compatibility and stream-safety changes are included for review.
