# [Model] Support Ming3-ASR (inclusionAI/Ming-3.0-asr-tiny)

[Upstream PR](https://github.com/vllm-project/vllm/pull/63585) · state: closed · merged: True

## Original PR description



## Overview



Add native support for [inclusionAI/Ming-3.0-asr-tiny](https://huggingface.co/inclusionAI/Ming-3.0-asr-tiny). 

vLLM-Omni will be updated to use cls/func from upstream vLLM (after next release) to support models incorporating Ming-3-asr as a component (e.g., `inclusionAI/Ming-3.0-audio-flash`)

## Claims

- Support native `inclusionAI/Ming-3.0-asr-tiny` model
- Online serving, offline inference
- Transcription of multiple languages and dialects; features such as full-history no-repeat n-gram blocking
- Benchmarking and validating

3. online serving

Launch server:
```bash
vllm serve inclusionAI/Ming-3.0-asr-tiny --trust-remote-code

# with optional full-history no-repeat n-gram blocking
vllm serve inclusionAI/Ming-3.0-asr-tiny \
  --trust-remote-code \
  --logits-processors \
  vllm.model_executor.models.ming_v3_asr_logits_processor:NoRepeatNGramLogitsProcessor
```

Send a request:
```bash
curl http://localhost:8000/v1/audio/transcriptions \
  -F model=inclusionAI/Ming-3.0-asr-tiny \
  -F file=@audio.wav \
  -F temperature=0 \
  -F max_completion_tokens=256 \
  -F 'vllm_xargs={"no_repeat_ngram_size":10}'
```

## Details

ASR model should be supported in vLLM rather than vLLM-Omni, while vLLM-Omni could use an ASR model from upstream vLLM as a component in another model (I'll update in vLLM-Omni after next releasing). 

This PR:
- Supported Chinese, English, and dialect transcription, with optional topic, hotword, and dialogue context.
- Reused vLLM’s Bailing MoE V3 backbone and Whisper encoder, with a Transformers-based audio frontend and model-specific checkpoint mapping.
- Added optional full-history no-repeat n-gram blocking through the existing Model Runner V2 plugin interface.
- Included model registration, processing and API tests, an offline example, and a deployment recipe.

References:
https://huggingface.co/inclusionAI/Ming-3.0-asr-tiny
https://github.com/inclusionAI/Ming-3.0-asr
