# [Bugfix][Reasoning] Stop kimi_k2 reasoning end check at the current turn

[Upstream PR](https://github.com/vllm-project/vllm/pull/61385) · state: open · merged: False

## Original PR description



## Overview

Fixes #61384

kimi_k2 treated the last turn's `</think>` as the end of the current turn's reasoning. This sets `turn_boundary_tokens` on `kimi_k2_config` so the check stops at the current turn, same as qwen3/glm (#54089, #56635).

## Claims

- K2-Thinking turn 2+ and tool loops: streaming splits reasoning/content correctly again
- structured outputs on those turns apply after `</think>`, not from token 0
- no change for turn 1, K2.5 (thinking on or off), or continued assistant messages

## Validation

New tests in `tests/reasoning/test_kimi_k2_reasoning_parser.py` use the parser from `ParserManager.get_parser("kimi_k2", "kimi_k2")`, streaming and non-streaming, plus `resolve_reasoning_ended`. They cover first turn, second turn and tool loop, each with a plain answer and a tool call, plus guards for K2.5 and continued turns.

- main: 4 failed, 12 passed (second turn and tool loop cases)
- this PR: 16 passed

```
pytest tests/reasoning/test_kimi_k2_reasoning_parser.py
pytest -n 2 tests/tool_parsers/test_kimi_k2_tool_parser.py tests/parser/test_parse.py tests/parser/test_streaming.py tests/parser/engine/test_parser_engine.py tests/parser/engine/test_engine.py tests/tool_parsers/test_structural_tag_registry.py  # 552 passed
pre-commit run --files <changed files>
```

Also checked with the real K2-Thinking chat template and tokenizer: streaming matches non-streaming on every turn, and the structured output grammar starts right after `</think>`.

No end-to-end run, K2-Thinking is ~1T params. The change is parser only, and K2.5 and K2-Thinking share the same tokenizer.

## Details

Every Kimi turn starts with `<|im_user|>`, `<|im_assistant|>` or `<|im_system|>` (tool results use `<|im_system|>`), so those are the boundaries. `KimiK2Parser` overrides `extract_content_ids`, so this only changes `is_reasoning_end`. Tool parsing and kimi_k3 are untouched.

Not a duplicate: #54089 and #56635 only covered qwen3/glm, and #49318 touches this file for an unrelated arg coercion fix. No open issue or PR for this.
