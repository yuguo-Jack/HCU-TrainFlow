File: `vllm/benchmarks/serve.py` · line 2308

dataset_name is the loader type, not the dataset. Every --dataset-name hf run records "hf" whatever --dataset-path points at (VisionArena, AIMO, MT-Bench...), and custom and sharegpt runs record the same value for any input file. Grouping results by this key therefore merges different workloads, which is what the description says it enables. Suggest recording the path next to it: result_json["dataset_path"] = args.dataset_path
