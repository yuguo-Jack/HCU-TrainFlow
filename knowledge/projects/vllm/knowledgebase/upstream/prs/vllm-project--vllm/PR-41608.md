<blockquote>
<h1>Change Log</h1>
<p>All notable changes to this project will be documented in this file.</p>
<p>The format is based on <a href="http://keepachangelog.com/">Keep a Changelog</a>
and this project adheres to <a href="http://semver.org/">Semantic Versioning</a>.</p>
<h2>[4.0.0]</h2>
<p>Fourth major release with significant API simplification and breaking changes.</p>
<h3>Breaking Changes</h3>
<h4>Exceptions Removed</h4>
<ul>
<li><code>BucketFullException</code> and <code>LimiterDelayException</code> have been removed</li>
<li>Rate limiting now uses blocking behavior instead of exception-based flow control</li>
</ul>
<h4>Limiter Constructor Simplified</h4>
<ul>
<li>Removed <code>clock</code> parameter - each bucket now manages its own clock via <code>bucket.now()</code></li>
<li>Removed <code>raise_when_fail</code> parameter - no exceptions are raised</li>
<li>Removed <code>max_delay</code> parameter - blocking is now controlled per-call</li>
<li>Removed <code>retry_until_max_delay</code> parameter</li>
<li>Added <code>buffer_ms</code> parameter (default 50ms) for clock drift tolerance</li>
</ul>
<h4>Clock Changes</h4>
<ul>
<li><code>TimeClock</code> removed - use <code>MonotonicClock</code> instead</li>
<li><code>SQLiteClock</code> removed - buckets now manage their own time</li>
<li><code>TimeAsyncClock</code> renamed to <code>MonotonicAsyncClock</code></li>
<li>Clock is no longer passed to Limiter; buckets have built-in <code>now()</code> method</li>
</ul>
<h4>try_acquire API Changes</h4>
<ul>
<li>New signature: <code>try_acquire(name=&quot;pyrate&quot;, weight=1, blocking=True, timeout=-1)</code></li>
<li><code>blocking=True</code> (default): blocks until permit is acquired</li>
<li><code>blocking=False</code>: returns <code>False</code> immediately if bucket is full</li>
<li>Added <code>try_acquire_async()</code> for proper async acquisition with asyncio.Lock</li>
</ul>
<h4>Decorator API Changes</h4>
<ul>
<li>Old: <code>limiter.as_decorator()(mapping_func)(target_func)</code> where mapping returns <code>(name, weight)</code></li>
<li>New: <code>limiter.as_decorator(name=&quot;...&quot;, weight=...)(target_func)</code> with direct parameters</li>
</ul>
<h4>BucketFactory Changes</h4>
<ul>
<li><code>schedule_leak(bucket, clock)</code> now <code>schedule_leak(bucket)</code> - no clock parameter</li>
<li><code>create(clock, bucket_class, ...)</code> now <code>create(bucket_class, ...)</code> - no clock parameter</li>
</ul>
<h3>New Features</h3>
<ul>
<li>Context manager support: <code>with Limiter(...) as limiter:</code> and <code>with bucket:</code></li>
<li><code>limiter.close()</code> method for resource cleanup</li>
<li><code>limiter_factory</code> module with convenience functions:
<ul>
<li><code>create_sqlite_limiter()</code></li>
<li><code>create_inmemory_limiter()</code></li>
<li><code>init_global_limiter()</code></li>
</ul>
</li>
</ul>
