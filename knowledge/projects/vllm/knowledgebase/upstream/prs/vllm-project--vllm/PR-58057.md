# [Bugfix] [Rust Frontend][Parser] Recover DeepSeek DSML invokes without a calls opener

[Upstream PR](https://github.com/vllm-project/vllm/pull/58057) · state: open · merged: False

## Original PR description




## Purpose

DeepSeek can emit a complete DSML `invoke` without the opening `calls` marker. The Python frontend already handles this case, but the Rust frontend returns the raw DSML as `content` and produces no tool call ([#48931](https://github.com/vllm-project/vllm/issues/48931)).

  Recognize complete invokes for declared tools when the opener is missing, aligning Rust's final `content` and `tool_calls` with Python for this case. Preserve incomplete or invalid candidates as text, and cover split streaming input, multiple invokes, and a subsequent wrapped call.
