## Overview

Add the MI325X AgentX preset for DeepSeek-V4.1-Flash from [InferenceX #4617](https://github.com/SemiAnalysisAI/InferenceX/pull/4617). The existing recipe describes MI325X serving but does not expose this lane's TP8, TP4 and TP2 operating points in the builder.

## Claims

- Add 18 opt-in points, with concurrency 1/2/4/8/16/32 for each topology, scoped to the measured 0909 checkpoint.
- Generate the pinned image and production settings, including TP4 monokernel, topology-specific Engram placement and TP2 scheduler/graph budgets.
- Preserve real speculative verification in serving commands; document the separate AgentX throughput controls and evaluation scope.

## Details

This follows the structured preset approach in [#63560](https://github.com/vllm-project/vllm/pull/63560). Searches of open and merged recipe work found no MI325X AgentX preset for #4617; the merged generic MI325X update [#62713](https://github.com/vllm-project/vllm/pull/62713) and the existing presets do not cover these operating points.

The preset stays opt-in and uses existing synthesis support. TP8/TP2 explicitly remove the inherited monokernel flag; TP4 retains it. Synthetic acceptance length is only documented as an InferenceX throughput control, while generated serving and accuracy commands keep real block verification. The runbook discloses the pinned TP4 draft FFN activation behavior and the unresolved InferenceX qualification question; documenting the configuration does not resolve that separate review.

AI assistance was used to prepare the recipe, inspect upstream evidence and validate generated output.
