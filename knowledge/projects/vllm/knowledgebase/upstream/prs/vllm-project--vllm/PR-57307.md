# [Tools] Recipes sweep workflow

[Upstream PR](https://github.com/vllm-project/vllm/pull/57307) · state: closed · merged: True

## Original PR description

## Purpose

Add benchmark-backed runtime tuning in dependency order:

```text
TP/DP layout -> max concurrency -> scheduler settings
```

This PR adds:

* parallel-layout sweep generation
* concurrency discovery
* scheduler tuning
* per-DP-replica scheduler seeds
* model-aware parallel-layout validation
* NUMA-aware Xeon binding for TP/DP sweeps
* recommendation generation
* standalone HTML reporting and visualization
* documented full and individual sweep workflows

The complete workflow is generated with:

```bash
python3 tools/recipes/recipe_json_to_vllm_config.py \
  --model meta-llama/Llama-3.1-8B-Instruct \
  --hardware xeon6 \
  --detect-hardware \
  --input-tokens 128 \
  --output-tokens 128 \
  --concurrency 32 \
  --ttft-sla-ms 3000 \
  --tpot-sla-ms 100 \
  --generate-full-sweep
```

Individual parallel-layout, concurrency, and scheduler stages can also be generated separately.
