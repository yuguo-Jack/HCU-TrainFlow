# [Dependency] Update Humming and remove NVFP4 scale workaround

[Upstream PR](https://github.com/vllm-project/vllm/pull/61556) · state: closed · merged: True

## Original PR description

This PR updates the Humming version used by vLLM, introducing initial support for the Rubin architecture, full support for the Blackwell architecture, and significant optimizations for existing architectures.

This PR also reverts the changes introduced in https://github.com/vllm-project/vllm/pull/60337, as the underlying issues have already been fixed in the latest version of Humming, eliminating the need for additional hook calls in vLLM.
