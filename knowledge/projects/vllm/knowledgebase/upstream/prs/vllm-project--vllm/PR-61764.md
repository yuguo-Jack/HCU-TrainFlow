# [Bugfix][EC Connector] Allocate producer control ports at startup

[Upstream PR](https://github.com/vllm-project/vllm/pull/61764) · state: open · merged: False

## Original PR description

## Overview

Multiple EC producers on the same host can collide on a fixed control port. Bind each producer's socket to an OS-assigned port at startup and advertise it through `ec_transfer_params.peer_port`.

## Claims

- Remove the EC-specific host and port variables. Reuse vLLM's `get_ip()` and existing `VLLM_HOST_IP` override; allocate the port automatically.
- Use an instance- and DP-specific NIXL identity to avoid replica collisions.

## Details

Bind port `0` on the serving socket and read `LAST_ENDPOINT`, avoiding a separate port-reservation race. Consumers use the advertised endpoint. Deployments must allow access to dynamically allocated ports.

No equivalent open change was found in upstream EC port title searches. AI assistance was used; human review is pending.
