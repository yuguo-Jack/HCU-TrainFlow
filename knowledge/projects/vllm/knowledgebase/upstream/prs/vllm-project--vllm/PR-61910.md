# [Bugfix][Models] Fix Olmo-Hybrid GDN fused conv1d weight loader and register mapper (#61849)

[Upstream PR](https://github.com/vllm-project/vllm/pull/61910) · state: open · merged: False

## Original PR description

### What does this PR do?

Fixes a crash when loading `allenai/Olmo-Hybrid-7B` (and other Olmo-Hybrid checkpoints) due to two coupled defects in weight mapping and fused conv1d loading:

1. **Missing Mapper Registration in `OlmoHybridForCausalLM`**: `OlmoHybridModel` defines `hf_to_vllm_mapper` with the shard mappings for `.q_conv1d`, `.k_conv1d`, `.v_conv1d`, and `.linear_attn` projections. However, `OlmoHybridForCausalLM` did not declare `hf_to_vllm_mapper = OlmoHybridModel.hf_to_vllm_mapper` nor pass `mapper=self.hf_to_vllm_mapper` in `load_weights()`. Consequently, checkpoint weights were processed without shard mapping.
2. **Missing `shard_id` Attribute Resolution in `_make_fused_conv1d_weight_loader`**: When `AutoWeightsLoader._load_param` invokes a parameter's weight loader, it calls `weight_loader(param, weight_data)` where shard information is attached as `weight_data.shard_id`. The loader's `loaded_shard_id` parameter defaulted to `None` and did not inspect `getattr(loaded_weight, "shard_id", None)`, leading to `dims[loaded_shard_id]` evaluating as `dims[None]` and raising `TypeError: list indices must be integers or slices, not NoneType`.

### Changes

- Registered `hf_to_vllm_mapper = OlmoHybridModel.hf_to_vllm_mapper` on `OlmoHybridForCausalLM` and passed `mapper=self.hf_to_vllm_mapper` to `loader.load_weights()`.
- Updated `_make_fused_conv1d_weight_loader` to extract `getattr(loaded_weight, "shard_id", None)` when `loaded_shard_id is None`.
- Added support for pre-fused conv1d weights matching the fused layer shape.
- Added explicit bounds check and actionable `ValueError` messaging on invalid or missing shard configurations.
- Added unit tests in `tests/model_executor/model_loader/test_olmo_hybrid_weight_loader.py` covering explicit shard IDs, attribute-based shard IDs, pre-fused weights, and error cases.

Fixes #61849.
