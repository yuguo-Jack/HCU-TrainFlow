# [Bugfix][Spec Decode] Propagate dictionary hf-overrides to speculative draft models

[Upstream PR](https://github.com/vllm-project/vllm/pull/63909) · state: open · merged: False

## Original PR description

## Overview
Ensures dictionary-based --hf-overrides (e.g. CLI JSON overrides for YaRN RoPE or multimodal parameters) are recursively merged into speculative draft model configs.

## Claims
- Fixes SpeculativeConfig.compose_draft_hf_overrides discarding dictionary overrides.
- Ensures speculative draft models inherit RoPE scaling parameters (e.g. yarn, factor, mrope_section) from the CLI.
- Prevents context length mismatches and illegal memory access when context exceeds native draft bounds.
- Adds unit tests in tests/config/test_speculative_dict_hf_overrides.py.

## Validation
- Tested with 400K context benchmarks using YaRN overrides and MTP on Qwen3.8 Flash Next.
- Added unit tests verifying dictionary and callable override composition.

## Details
SpeculativeConfig.compose_draft_hf_overrides previously only checked if callable(target_hf_overrides). When passing JSON via CLI --hf-overrides, the parsed dictionary was dropped for the draft model.
