# [Bugfix][Core] Cache final multimodal boundaries for Mamba siblings

[Upstream PR](https://github.com/vllm-project/vllm/pull/56818) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

Fix the first incremental multimodal sibling's prefix-cache miss on Mamba-attention hybrid models by retaining a state at the producer's final multimodal boundary. Addresses the reproduced 4-image -> 5-image case in #43587.

## Claims

- Make a block-aligned Mamba state available before the sibling diverges.
- Add at most one extra split per uninterrupted prefill pass and one retained checkpoint per multimodal request.
- Preserve the tested identical-prompt and text-only cache-hit counts.

```python
import os

from PIL import Image
from transformers import AutoTokenizer
from vllm import LLM, SamplingParams

model = os.environ["MODEL"]
size = int(os.environ.get("IMAGE_SIZE", "224"))
tokenizer = AutoTokenizer.from_pretrained(model, local_files_only=True)
image = Image.new("RGB", (size, size), (128, 128, 128))
llm = LLM(
    model=model,
    tensor_parallel_size=2,
    dtype="bfloat16",
    enforce_eager=True,
    enable_prefix_caching=True,
    max_model_len=8192,
    max_num_batched_tokens=8192,
    max_num_seqs=4,
    gpu_memory_utilization=0.26,
    kv_cache_memory_bytes=2 * 1024**3,
    limit_mm_per_prompt={"image": 5, "video": 0},
    mm_processor_kwargs={"max_pixels": size**2},
    seed=0,
)


def prompt(n, repeats=300, tail=0):
    items = [{"type": "text", "text": "Task description.\n\nHistory:\n"}]
    for i in range(n):
        items += [
            {"type": "text", "text": f"\n--- Turn {i + 1} ---\n"},
            {"type": "image", "image": image},
        ]
    items.append({
        "type": "text",
        "text": "\n" + "Follow these instructions carefully. " * tail + "\nWhat next?",
    })
    messages = [
        {"role": "system", "content": "You are a helpful assistant. " * repeats},
        {"role": "user", "content": items},
    ]
    value = {"prompt": tokenizer.apply_chat_template(
        messages, add_generation_prompt=True, tokenize=False,
    )}
    if n:
        value["multi_modal_data"] = {"image": [image] * n}
    return value


def run(name, value, skip=False):
    output = llm.generate([value], SamplingParams(
        temperature=0, max_tokens=16, skip_reading_prefix_cache=skip,
    ), use_tqdm=False)[0]
    print(name, len(output.prompt_token_ids), output.num_cached_tokens)
    return list(output.outputs[0].token_ids)


try:
    for repeats in (30, 300):
        assert llm.reset_prefix_cache()
        run(f"pad_{repeats}_prime_4", prompt(4, repeats))
        run(f"pad_{repeats}_replay_4", prompt(4, repeats))
        cached = run(f"pad_{repeats}_increment_5", prompt(5, repeats))
        reference = run(f"pad_{repeats}_uncached", prompt(5, repeats), skip=True)
        assert cached == reference
    assert llm.reset_prefix_cache()
    run("long_tail_prime_4", prompt(4, tail=500))
    cached = run("long_tail_increment_5", prompt(5, tail=500))
    reference = run("long_tail_uncached", prompt(5, tail=500), skip=True)
    assert cached == reference
    assert llm.reset_prefix_cache()
    run("text_prime", prompt(0, tail=500))
    cached = run("text_replay", prompt(0, tail=500))
    reference = run("text_uncached", prompt(0, tail=500), skip=True)
    assert cached == reference
finally:
    llm.llm_engine.engine_core.shutdown()
```

## Details

Matching attention hashes are insufficient when Mamba `align` has no state before the sibling's divergence. A producer with a long text tail can retain only an end-of-prompt state that is already past the next request's shared prefix.

This change exposes `Request.last_mm_feature_end`, stops prefill at its physical-block-aligned position, and retains that checkpoint through the existing replay-boundary mechanism. It changes no model math, CUDA kernels or model-runner APIs. Shared prefixes shorter than one physical Mamba block still cannot reuse a state; preemption may recompute the extra split.

The baseline's zero-hit 448px output anomaly was isolated in three repeats: a discovered 2112-token junction changes chunking and BF16 gate projections; disabling only that junction restores the skip-cache output. This explains that reproducer, not the unresolved long-output failures above.

Unlike the application-directed checkpoint APIs in #55873/#55875/#55876, this uses one automatic final-MM boundary. #60888 optimizes checkpoint export rather than selecting that boundary; #55868/#60033/#60524 address separate GDN numerical paths. Those numerical changes are not included in this PR.
