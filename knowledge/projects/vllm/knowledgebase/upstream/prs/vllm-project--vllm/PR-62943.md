# [Doc] Document kv_load_failure_policy in the MooncakeStoreConnector guide

[Upstream PR](https://github.com/vllm-project/vllm/pull/62943) · state: open · merged: False

## Original PR description

## Summary
The MooncakeStoreConnector guide did not mention `kv_load_failure_policy`. With the default `"fail"`, a failed KV load returns an empty response, which surprises anyone running a store-backed deployment.

## Changes
- Describe `kv_load_failure_policy`: accepted values, the default, and what each one does.
- Add a config example that uses `"recompute"` for store-backed setups.

## Testing
- Docs build and pre-commit markdown checks
