## Original PR description

## Purpose

`docs/design/cuda_graphs_multimodal.md` maintains the support matrix for multimodal encoder CUDA graphs. 

GLM-5.3-Flash (`Glm5NextForConditionalGeneration`) already supports them on main — it inherits the full `SupportsEncoderCudaGraph` implementation from `Glm4vForConditionalGeneration` — but is missing from the matrix. 

This PR adds the row (image ✅ / video ✅); no code changes.

Duplicate-work check (per AGENTS.md): no open PR covers GLM-5.3-Flash in this matrix. No new CI test: the capability is inherited, not new code, and the shared parent implementation already carries coverage; same reasoning as the docs-only precedent in #44720.
