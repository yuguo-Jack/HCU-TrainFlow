## Details

[vllm-iluvatar](https://github.com/Deep-Spark/vllm-iluvatar) is out-of-tree vLLM plugin for [Iluvatar CoreX](https://www.iluvatar.com) GPUs. Deep-Spark is Iluvatar CoreX's open-source organization in GitHub.
The plugin currently supports vLLM v0.27.1, and support for v0.31.0 is in progress. We will keep it aligned with vLLM's roadmap and release cadence.
