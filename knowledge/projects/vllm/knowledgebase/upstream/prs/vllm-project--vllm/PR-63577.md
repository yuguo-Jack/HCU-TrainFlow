# [Perf][Distributed] Read peers in rank-rotated order in the one-shot custom all-gather

[Upstream PR](https://github.com/vllm-project/vllm/pull/63577) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->

## Overview

The one-shot custom all-gather (`cross_device_all_gather`, used by `sp_all_gather` for sequence parallelism) makes every rank read rank 0's shard first, then rank 1's, and so on. All peers pull from one source GPU at a time. This PR starts each rank at its own shard and issues the loads from all sources before the stores. The output bytes do not change.

## Claims

- Faster SP all-gather at every measured size on 8 x A100-SXM4-40GB (NVSwitch), in CUDA graphs: -25 % at 128 tokens per step, -41 % at 1024, -57 % at 2176. At 1024 tokens and above it is now also faster than NCCL.
- Exact: the kernel is a copy; the output is bitwise equal to `torch.distributed.all_gather_into_tensor` at 8 to 3072 tokens.
- No change to barriers, buffers, size limits, launch configuration or routing.

## Validation

**Kernel (8 x A100-SXM4-40GB, NVSwitch, vLLM 5555a2d8f image, CUDA graph of 50 back-to-back calls, hidden 2560 BF16, time per call, max over ranks).** The new loop ran on vLLM's own `CustomAllreduce` object (same barriers, Signal buffers and registered input buffer) through a JIT build of the patched kernel; the unpatched loop built the same way reproduces the time of `sp_all_gather` (16.7 vs 16.5 us at 8 tokens, 115.0 vs 115.0 us at 2048).

| Tokens per step (shard per rank) | NCCL | `sp_all_gather` today | This PR | Bitwise equal to NCCL |
|---|---|---|---|---|
| 8 (5 KiB) | 27.9 us | 16.5 us | 12.1 us | yes |
| 128 (80 KiB) | 21.9 us | 17.5 us | 13.2 us | yes |
| 512 (320 KiB) | 37.4 us | 32.2 us | 22.5 us | yes |
| 1024 (640 KiB) | 52.4 us | 55.6 us | 32.6 us | yes |

Rotating the start alone gives most of the gain at large sizes (2176 tokens: 57.6 us); issuing all loads first adds the gain at small sizes (128 tokens: 19.8 us rotated only).

**Serving (two A/B jobs, 4 pairs, both orders):** Qwen3.8-Flash-Next-FP8 on 8 x A100-SXM4-40GB, TP8 + EP + DCP4 with sequence-parallel hyper-connections (96 SP all-gathers per step), MLPerf agentic multi-turn workload, 32 sessions, 1 h per arm, the change applied through a JIT build of the patched kernel. Goodput = requests within TTFT <= 2.93 s and TPOT <= 21.74 ms.

|---|---|---|---|---|
| 1 (this first) | 3.42 / 2.87 | 14.39 / 14.75 ms (-2.4 %) | 21.45 / 26.00 ms | 3.27 / 2.50 req/s |

- TPOT P50 is lower in all 4 pairs (-2.0 to -3.3 %), in line with the kernel estimate (about -0.4 ms per decode step, about -7 ms per 2k-token prefill step).
- The tail and goodput gaps are not reliable: most baseline arms of both jobs ran slower than every earlier baseline run of the same setup (earlier: QPS 3.30-3.34, TPOT P95 21.6-21.9 ms, goodput 3.07-3.18 req/s), and pair 4 is worse at P95. For comparison with those earlier runs, the two best arms with this change reached goodput 3.27 and 3.32 req/s.
- The claim of this PR is the kernel speedup and the median TPOT gain; no tail-latency claim.

**Tests:** the existing all-gather correctness tests cover the changed kernel (`tests/distributed/test_comm_ops.py`, `tests/models/*/test_sequence_parallel.py`). Not yet run with an in-tree build of this branch; the measured kernel is the same loop compiled against the 5555a2d8f headers (bench and extension in the collapsed block below).

**Not measured:** Hopper or Blackwell GPUs, 2, 4 and 6 GPUs. The MNNVL Lamport all-gather is a different kernel and is not changed.

## Details

**Root cause.** In `cross_device_all_gather` the outer loop goes over `src_rank = 0 .. ngpus-1` in the same order on every rank, and each thread has one 16 B load in flight per iteration. So for most of the kernel all ranks read the same peer: that peer's outgoing NVLink bandwidth is shared by all readers while the other links are idle.

**Fix.** Each thread reads source `(rank + i) % ngpus` for `i = 0 .. ngpus-1`, loads all `ngpus` packs into registers, then stores them. At any moment each GPU is read by about one peer, and each thread has `ngpus` independent loads in flight. Registers: `ngpus` x 16 B per thread (128 B at 8 GPUs) under the existing `__launch_bounds__(512, 1)`.

**Trade-offs.** None found in the measured range; every size got faster.

**Not done yet:** in-tree build and test run of this branch; other GPUs and GPU counts.

```cuda
// vLLM's one-shot custom all-gather (csrc/custom_all_gather_reduce_scatter.{cu,cuh}, main 5555a2d8f) with the
// copy loop as a variant; same barriers, Signal buffers and registered input buffer as the CustomAllreduce object
// that vLLM created (fa). Test-only JIT extension for the A/B; headers in vllm_csrc/ are copies from 5555a2d8f.
//   variant 0: vLLM's loop (every rank reads rank 0, then 1, ...)
//   variant 1: rank r reads r, r+1, ... (each source is read by one peer at a time)
//   variant 2: variant 1 with the 16 B loads of all sources issued before the stores
#include <torch/extension.h>
#include <c10/cuda/CUDAStream.h>
#include <c10/cuda/CUDAException.h>
#include "custom_all_reduce.cuh"
#include "custom_all_gather_reduce_scatter.cuh"

namespace vllm {

template <int ngpus, int variant>
__global__ void __launch_bounds__(512, 1)
    all_gather_variant(RankData* _dp, RankSignals sg, Signal* self_sg, CopyPack* __restrict__ result, int rank,
                       int size_per_rank) {
  auto dp = *_dp;
  int tid = blockIdx.x * blockDim.x + threadIdx.x;
  int stride = gridDim.x * blockDim.x;
  barrier_at_start<ngpus>(sg, self_sg, rank);
  if constexpr (variant == 2) {
    for (int idx = tid; idx < size_per_rank; idx += stride) {
      CopyPack packs[ngpus];
#pragma unroll
      for (int i = 0; i < ngpus; ++i)
        packs[i] = reinterpret_cast<const CopyPack*>(dp.ptrs[(rank + i) % ngpus])[idx];
#pragma unroll
      for (int i = 0; i < ngpus; ++i) result[((rank + i) % ngpus) * size_per_rank + idx] = packs[i];
    }
  } else {
#pragma unroll
    for (int i = 0; i < ngpus; ++i) {
      int src_rank = variant == 0 ? i : (rank + i) % ngpus;
      auto src = reinterpret_cast<const CopyPack*>(dp.ptrs[src_rank]);
      auto dst = result + src_rank * size_per_rank;
      for (int idx = tid; idx < size_per_rank; idx += stride) dst[idx] = src[idx];
    }
  }
  barrier_at_end<ngpus, true>(sg, self_sg, rank);
}

}  // namespace vllm

void custom_all_gather_variant(int64_t _fa, torch::Tensor inp, torch::Tensor out, int64_t _reg_buffer,
                               int64_t reg_buffer_sz_bytes, int64_t variant) {
  auto fa = reinterpret_cast<vllm::CustomAllreduce*>(_fa);
  auto stream = at::cuda::getCurrentCUDAStream(inp.get_device());
  TORCH_CHECK(inp.scalar_type() == out.scalar_type());
  TORCH_CHECK(inp.numel() * fa->world_size_ == out.numel());
  TORCH_CHECK(inp.is_contiguous() && out.is_contiguous());
  int64_t size_bytes = inp.numel() * inp.element_size();
  TORCH_CHECK(size_bytes <= reg_buffer_sz_bytes && size_bytes % sizeof(vllm::CopyPack) == 0);
  auto reg_buffer = reinterpret_cast<void*>(_reg_buffer);
  C10_CUDA_CHECK(cudaMemcpyAsync(reg_buffer, inp.data_ptr(), size_bytes, cudaMemcpyDeviceToDevice, stream));
  auto ptrs = fa->buffers_.at(reg_buffer);
  int size_per_rank = size_bytes / sizeof(vllm::CopyPack);
  int threads = 512;
  int blocks = std::min(vllm::defaultBlockLimit, (size_per_rank * fa->world_size_ + threads - 1) / threads);
  auto result = reinterpret_cast<vllm::CopyPack*>(out.data_ptr());
  TORCH_CHECK(fa->world_size_ == 8, "test extension: 8 GPUs only");
#define LAUNCH(V)                                                                                         \
  vllm::all_gather_variant<8, V><<<blocks, threads, 0, stream>>>(ptrs, fa->sg_, fa->self_sg_, result, \
                                                                   fa->rank_, size_per_rank)
  if (variant == 0) LAUNCH(0);
  else if (variant == 1) LAUNCH(1);
  else LAUNCH(2);
#undef LAUNCH
}

PYBIND11_MODULE(TORCH_EXTENSION_NAME, m) { m.def("custom_all_gather_variant", &custom_all_gather_variant); }
```

```python
"""SP all-gather at Qwen3.8-Flash sizes on 8 x A100 (NVSwitch): vLLM's serving path (sp_all_gather, custom one-shot),
NCCL, and the copy-loop variants of ag_rot.cu on vLLM's own CustomAllreduce object (same barriers and buffers). Each op inside one CUDA graph of N
back-to-back ops, as coll_bench.py. Every variant output is checked bitwise against NCCL. Test-only, no model.
Run with torchrun --nproc-per-node 8."""
import json
import os
from pathlib import Path

import torch
from torch.utils.cpp_extension import load

from vllm.config import VllmConfig, set_current_vllm_config
from vllm.distributed.parallel_state import (get_tp_group, graph_capture, init_distributed_environment,
                                             initialize_model_parallel)
from vllm.models.common.ops.sequence_parallel import sp_all_gather

HIDDEN = 2560
TOKENS = [8, 32, 128, 256, 512, 1024, 2048, 2176, 3072]  # whole step; each rank holds tokens / 8
VARIANTS = [0, 1, 2]
OPS_PER_GRAPH, REPLAYS, WARMUP = 50, 20, 5
HERE = Path(__file__).resolve().parent


def emit(kind, **fields):
    if torch.distributed.get_rank() == 0:
        print(kind, json.dumps(fields), flush=True)


def time_op(op, device):
    for _ in range(WARMUP):
        op()
    torch.cuda.synchronize()
    with graph_capture(device=device) as context:
        graph = torch.cuda.CUDAGraph()
        with torch.cuda.graph(graph, stream=context.stream):
            for _ in range(OPS_PER_GRAPH):
                op()
    start, end = torch.cuda.Event(enable_timing=True), torch.cuda.Event(enable_timing=True)
    for _ in range(WARMUP):
        graph.replay()
    torch.cuda.synchronize()
    torch.distributed.barrier()
    start.record()
    for _ in range(REPLAYS):
        graph.replay()
    end.record()
    torch.cuda.synchronize()
    per_op = torch.tensor([start.elapsed_time(end) * 1000 / REPLAYS / OPS_PER_GRAPH], device=device)
    torch.distributed.all_reduce(per_op, op=torch.distributed.ReduceOp.MAX)
    del graph
    return round(per_op.item(), 2)


def main():
    rank, world = int(os.environ["RANK"]), int(os.environ["WORLD_SIZE"])
    device = torch.device("cuda", int(os.environ["LOCAL_RANK"]))
    torch.cuda.set_device(device)
    os.environ["TORCH_CUDA_ARCH_LIST"] = "8.0"
    build = Path(os.environ.get("AG_BUILD", "/tmp/agbench-build"))
    build.mkdir(parents=True, exist_ok=True)
    ext = load(name="ag_rot", sources=[str(HERE / "ag_rot.cu")], build_directory=str(build),
               extra_include_paths=[str(HERE / "vllm_csrc")], extra_cuda_cflags=["-O3"], verbose=False)
    with set_current_vllm_config(VllmConfig()):
        init_distributed_environment(world, rank, "env://", int(os.environ["LOCAL_RANK"]), "nccl")
        initialize_model_parallel(tensor_model_parallel_size=world)
        tp = get_tp_group()
        emit("GPU", name=torch.cuda.get_device_name(device), world=world, torch=torch.__version__)
        ca = tp.device_communicator.ca_comm
        emit("CA", disabled=ca.disabled, max_all_gather_size=ca.max_all_gather_size)
        for tokens in TOKENS:
            shard = torch.randn(tokens // world, HIDDEN, dtype=torch.bfloat16, device=device)
            reference = torch.empty(tokens, HIDDEN, dtype=torch.bfloat16, device=device)
            torch.distributed.all_gather_into_tensor(reference, shard)
            out = torch.empty_like(reference)
            row = {"tokens": tokens, "shard_bytes": shard.numel() * 2}
            row["nccl"] = time_op(lambda: tp.all_gather(shard, dim=0), device)
            row["vllm_sp"] = time_op(lambda: sp_all_gather(shard), device)
            for variant in VARIANTS:
                def op(variant=variant):
                    ext.custom_all_gather_variant(ca._ptr, shard, out, ca.buffer_ptrs[ca.rank],
                                                  ca.max_all_gather_size, variant)
                out.zero_()
                op()
                torch.cuda.synchronize()
                equal = torch.tensor([int(torch.equal(out, reference))], device=device)
                torch.distributed.all_reduce(equal, op=torch.distributed.ReduceOp.MIN)
                row[f"v{variant}"] = time_op(op, device)
                row[f"v{variant}_equal"] = bool(equal.item())
            emit("AG", **row)
    torch.distributed.destroy_process_group()


if __name__ == "__main__":
    main()
```
