## Overview

## Validation

- Planned each step and mirror with ci-infra main's planner against main's timings; every plan is within 10% of the same plan run as one job.
- The sharding harness (each shard's commands run against a mock test tree, as a PR build and as main with the OTel wrapper) shows every test runs exactly once wherever a plan has 2 or more shards.
- Every step and mirror passes on recent main runs, nightly included.
- `/ci run` (98460) plus a scoped build (98471) for the optional steps and AMD mirrors on this head: every enrolled job passed, and every shard finished under 22 minutes.

## Details

- **Not plain pytest** steps (shell scripts, `torchrun`, examples) and standalone AMD steps are enrolled too; the generator keeps them as one job.
- **caplog.** Files that assert on logs sit in one-shard plans here, so their order in the process doesn't change.
- **Timeouts unchanged.** `timeout_in_minutes` stays per job. Fallback-aware timeouts belong in a central timeout setting.
