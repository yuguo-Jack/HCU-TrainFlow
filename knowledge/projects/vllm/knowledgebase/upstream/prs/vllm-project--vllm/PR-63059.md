# [Rust Frontend] Accept Gemma 4 tool calls without the call prefix like Python

[Upstream PR](https://github.com/vllm-project/vllm/pull/63059) · state: closed · merged: True

## Original PR description

## Overview

Some Gemma 4 checkpoints open a tool call with a bare `<|tool_call>:name{...}` instead of `<|tool_call>call:name{...}` (vllm-project/vllm#53431). vllm-project/vllm#53444 made the Python Gemma4 parser accept it; the Rust Gemma4 parser still requires `call:` and falls back to raw text. This PR accepts the bare opener in Rust too.

## Claims

- `<|tool_call>:get_weather{location:<|"|>London<|"|>}<tool_call|>` now parses into the same tool call as the documented `call:` form, in streaming and non-streaming chat. Before, the parse failed, the response had no tool call, and the raw markup appeared in `content`.
- Outputs using `call:` are unaffected: `call:` is still tried first, and the header parser only runs right after `<|tool_call>`, so a colon in content or argument values is not affected.

## Validation

Commands from `.buildkite/scripts/run-rust-frontend-cargo-ci.sh` (`style-clippy` and `test`), run from the repo root:

- New test `gemma4_accepts_bare_tool_call_opener_at_every_split`: text containing a colon, a bare-opener call, then a documented call; checks content and both calls for the full input and for every two-chunk split. It fails on the base with `ParsingFailed`.

## Details

The change is one winnow `alt` in `tool_call_header_event` (`rust/src/parser/src/unified/gemma4.rs`), the Gemma4 parser's header state, which streaming and non-streaming share. Gemma4 has no output grammar in Rust (nor in Python), so constrained generation is unchanged; this is parsing leniency only. If a bare-opened call later fails to parse, `reset()` rebuilds the recovery text with `call:`, as it already normalizes the header.

Out of scope: the no-brace fallback from the same Python PR (`<|tool_call>call:name prose<tool_call|>`) and parenthesized arguments (`call:name(...)`).

Not a duplicate: no open PR changes the Rust Gemma4 tool-call header.
