## Overview

Fixes #53284: use the rendered Qwen3 prompt to recognize an already closed reasoning block, so a plain generated answer is returned as content rather than reasoning.

Updated on October 6: rebased onto `b0b23a48d4` and resolved the conflicts with #58604. The batched path keeps #58604's per-prompt parser and `set_prompt_token_ids()` call and parses through `parse_with_prompt()`. The legacy `ReasoningParser` interface is unchanged.

## Claims

- Qwen3's current-turn prompt state is respected in Chat and Responses (streaming and non-streaming), and in Batch Chat; historical reasoning markers do not select the new turn's state.
- Prompt-closed answers have zero reasoning tokens; explicit thinking and cumulative streaming reasoning accounting remain intact.
- Existing `parse()` signatures and legacy reasoning plugins remain compatible. Responses still reuses streamed output items instead of reparsing them.

```python
"""Local HTTP smoke checks for the prompt-closed Qwen3 parser fix."""

import json

import httpx


MODEL = "Qwen/Qwen3.5-2B"
client = httpx.Client(base_url="http://127.0.0.1:18080", timeout=180)
messages = [{"role": "user", "content": "Reply with exactly the word OK."}]
chat = dict(model=MODEL, messages=messages, max_tokens=32, temperature=0, seed=0)


def post(path, payload):
    response = client.post(path, json=payload)
    response.raise_for_status()
    return response.json()


def events(path, payload):
    with client.stream("POST", path, json=payload) as response:
        response.raise_for_status()
        for line in response.iter_lines():
            if line.startswith("data: ") and line != "data: [DONE]":
                yield json.loads(line[6:])


def record(name, result):
    print(json.dumps({"case": name, **result}, ensure_ascii=False), flush=True)


for include in (True, False):
    result = post("/v1/chat/completions", {**chat, "include_reasoning": include})
    message = result["choices"][0]["message"]
    record(f"chat_include_reasoning_{include}", result)
    assert message["content"].strip() == "OK"
    assert not message.get("reasoning")
    assert result["usage"]["completion_tokens_details"]["reasoning_tokens"] == 0

content, reasoning, usage = "", "", None
for event in events(
    "/v1/chat/completions",
    {**chat, "stream": True, "stream_options": {"include_usage": True}},
):
    if event.get("usage"):
        usage = event["usage"]
    for choice in event.get("choices", []):
        content += choice["delta"].get("content") or ""
        reasoning += choice["delta"].get("reasoning") or ""
record("chat_stream", dict(content=content, reasoning=reasoning, usage=usage))
assert content.strip() == "OK" and not reasoning
assert usage["completion_tokens_details"]["reasoning_tokens"] == 0

result = post(
    "/v1/chat/completions",
    {**chat, "max_tokens": 128, "chat_template_kwargs": {"enable_thinking": True}},
)
record("chat_explicit_thinking", result)
assert result["choices"][0]["message"].get("reasoning")
assert result["usage"]["completion_tokens_details"]["reasoning_tokens"] > 0

result = post(
    "/v1/chat/completions/batch",
    {
        **chat,
        "messages": [
            messages,
            [{"role": "user", "content": "Reply with exactly the word YES."}],
        ],
    },
)
record("batch_chat", result)
assert [c["message"]["content"].strip() for c in result["choices"]] == ["OK", "YES"]
assert all(not c["message"].get("reasoning") for c in result["choices"])

responses = dict(
    model=MODEL,
    input="Reply with exactly the word OK.",
    max_output_tokens=32,
    temperature=0,
)


def response_text(result):
    assert not any(item["type"] == "reasoning" for item in result["output"])
    assert result["usage"]["output_tokens_details"]["reasoning_tokens"] == 0
    return "".join(
        part["text"]
        for item in result["output"]
        if item["type"] == "message"
        for part in item["content"]
        if part["type"] == "output_text"
    )


result = post("/v1/responses", responses)
record("responses", result)
assert response_text(result).strip() == "OK"

stream_text = ""
completed = None
for event in events("/v1/responses", {**responses, "stream": True}):
    if event["type"] == "response.output_text.delta":
        stream_text += event["delta"]
    elif event["type"] == "response.completed":
        completed = event["response"]
assert completed is not None
record("responses_stream", dict(stream_text=stream_text, response=completed))
assert response_text(completed) == stream_text
assert stream_text.strip() == "OK"
print("All 7 serving smoke cases passed.", flush=True)
```

## Details

The template can close `<think>...</think>` without setting `chat_template_kwargs.enable_thinking=false`. Complete-output parsing previously lost the rendered prompt context and started from the configured default reasoning state.

The shared change addresses that missing context in the unified parsing contract and its serving callers. `Parser.parse_with_prompt()` defaults to the existing `parse()` behavior; `DelegatingParser` supplies the fallback for legacy parsers. `ReasoningParser` itself is unchanged. The Qwen-specific current-turn marker scan stays in `vllm/parser/qwen3.py`. The adapter preserves the selected state when replaying tokens for reasoning counts. There are no scheduler, model-runner, kernel, or dependency changes, and no throughput claim.

The rebase preserves upstream's Responses streamed-item reuse and Batch Chat tests. Added coverage includes direct and delegated parsing, streaming finalization/counting, history/tool-example boundaries, prompt propagation, and a legacy parser with no prompt-aware hook. The capability is documented in its interface docstring; no new user-facing configuration is introduced.
