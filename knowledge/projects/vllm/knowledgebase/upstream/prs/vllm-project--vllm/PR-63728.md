# Refactor mathematical expressions in in hybrid KV cache manager doc

[Upstream PR](https://github.com/vllm-project/vllm/pull/63728) · state: closed · merged: False

## Original PR description



## Overview

Fix the `'_' allowed only in math mode` warnings in `docs/design/hybrid_kv_cache_manager.md`.

## Claims

- Removes the LaTeX warnings caused by underscores inside `\text{}` in the formulas.
- The formulas now render as code blocks.

## Validation

Docs-only change. Checked in GitHub's markdown preview that the code blocks render correctly and no formula errors remain. The full MkDocs build is pending the CI label.

## Details

Identifiers such as `block_size` and `kv_hidden_size` used bare underscores in LaTeX text mode, which is not allowed. Replacing the formulas with code blocks avoids the problem, and the identifiers match how they appear in the code. Happy to switch to escaped LaTeX (`\text{block\_size}`) if maintainers prefer.
