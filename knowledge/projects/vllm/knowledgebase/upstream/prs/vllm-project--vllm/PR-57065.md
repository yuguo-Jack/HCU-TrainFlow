# [CI] Move (H200 MIG 35GB / MI355 DPX) Multimodal Models (Standard) 4 core tests into standard/

[Upstream PR](https://github.com/vllm-project/vllm/pull/57065) · state: open · merged: False

## Original PR description

## What

Move the wholly-core multimodal tests under `standard/`, and split the core weight-mapper test out of `test_mapping.py`. Nothing else changes: the same tests run in the same jobs and processes.

## Old

```text
models/multimodal/
├── generation/{test_interleaved,test_memory_leak}.py
├── pooling/{test_llava_next,test_phi3v,test_prithvi_mae}.py   # beside pooling/conftest.py
└── test_mapping.py          # unit and core tests mixed
```

## New

```text
models/multimodal/
├── test_mapping.py          # mapping unit tests
└── standard/
    ├── test_interleaved.py
    ├── test_mapping.py      # core weight-mapper test
    ├── memory_leak/test_memory_leak.py   # run as a directory by its own command
    └── pooling/             # the three core pooling files
        └── conftest.py      # re-exports pooling/'s release_gpu_memory_between_tests
```

## Notes

- `standard/pooling/conftest.py` re-exports the autouse `release_gpu_memory_between_tests` fixture from `pooling/conftest.py`, so the moved pooling tests keep reclaiming VRAM between engines. I re-exported it rather than moving it up to `tests/models/multimodal/conftest.py`, which would have added the cleanup to every multimodal test. `--fixtures-per-test` shows it applied to all 6 moved cases.
- `test_gemma_ragged_audio.py` no longer moves here. #56901 moves it into `generation/audio/` with the other audio models.
- No marker or shard count changes. Standard 4 runs `pytest models/multimodal/standard/memory_leak -m core_model` in its own process as before, and the CUDA, MI355 DPX and Intel catch-alls `--ignore` the `standard/memory_leak` directory instead of the file.
- Stack: this PR and #56901 are both based on `main` and conflict only in the Standard 4 command paths, so whichever lands second needs a rebase. #57067 contains both. #57066 was dropped. Local checks: tethering `--all`, YAML parse, Ruff. One scoped build on #57067's head validates the combined layout. AI assistance was used.

## Expected runtime and overhead

Routing only: the same tests run in the same jobs and processes, so neither runtime nor worker-minutes change.
