# [Test] Cover detokenize=False in offline beam search

[Upstream PR](https://github.com/vllm-project/vllm/pull/49541) · state: open · merged: False

## Original PR description

Offline counterpart of #46422. Sets `detokenize=False` on the per-step sampling params in the offline beam search path, and threads it through the structured-output beam path as well, so intermediate beam candidates are not detokenized on every step.

This does not fix the Whisper slowdown reported in #49197. That one is the per-beam encoder recompute called out in the FIXME in `vllm/entrypoints/generate/beam_search/utils.py`, which is a separate change.

Not benchmarked on GPU.

## Test

`tests/samplers/test_beam_search_offline.py` covers both the plain and the structured-output beam paths and runs without a GPU.

## Pull request overview

This PR reduces CPU overhead in the **offline** beam-search implementation by disabling per-step incremental detokenization, aligning offline beam search behavior with the already-optimized **online** beam search path.

**Changes:**
- Set `detokenize=False` in offline beam search’s per-step `SamplingParams` to avoid unused per-token/per-candidate decoding work.
- Propagate `detokenize` into per-beam `SamplingParams` when structured outputs are enabled.
- Add a GPU-free unit test to guard that offline beam search builds per-step sampling params with detokenization disabled.
