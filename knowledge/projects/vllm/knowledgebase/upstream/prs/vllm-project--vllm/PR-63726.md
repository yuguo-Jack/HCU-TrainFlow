# [Recipe][AMD] Refresh Kimi-K3 PD configurations

[Upstream PR](https://github.com/vllm-project/vllm/pull/63726) · state: closed · merged: True

## Original PR description



## Overview

Document the current Kimi-K3 FP4 prefill/decode configurations for MI355X in [InferenceX#4391](https://github.com/SemiAnalysisAI/InferenceX/pull/4391), using TP8/DCP8 workers, FP8 KV and MoRIIO RDMA.

## Claims

- 1P1D c8 uses K7 DSpark, FP32 SSM and one sequence per worker. Decode uses the V2 `latency_specialized` backend with graph sizes `[1, 8]`; KV stays on GPU.
- The four offload points use K4, BF16 SSM and prefill-only SimpleCPUOffload with a fixed 2399 GB host-memory budget across eight ranks.
- The standalone example uses official nightly images and the 1P1D c48 configuration. The scaling table covers all five points, with sequence/graph formulas and the c8 exceptions.

| Configuration | P / per-D max sequences |
| --- | --- |
| 1P1D c8 | 1 / 1 |
| 1P1D c48 | 96 / 96 |
| 1P2D c24 | 48 / 24 |
| 1P2D c48 | 96 / 48 |
| 1P3D c24 | 48 / 16 |

## Validation

- Official recipe renderer: `CI=true node scripts/validate-source.mjs --source vllm --dir ../vllm-k3-recipe-refresh-1026/recipes`.
- Extracted 1P1D c48 example: `bash -n` and both P/D command dry-runs passed; serving parameters match the checked c48 configuration, retaining the original per-host MoRIIO ports.
- [InferenceX sweep, attempt 5](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/40301194088/attempts/5) passed at configuration revision `a2555a52`: benchmarks and all selected eval jobs passed for all five points, including the 0.8-offload configurations. Throughput runs use golden acceptance; evals use real block verification. The tested worker build is `c50aca14416ef29f6ed0ed256302f30646726dcd`; exact worker/router digests remain in the linked InferenceX configuration. Later nightly builds have not been GPU-validated here.

## Details

Updates the existing AMD MoRIIO standalone guide and launcher. Serving uses probabilistic DSpark drafting with real block verification; benchmark golden acceptance settings remain in InferenceX. Launcher validation covers command generation; GPU results come from the InferenceX harness. No open PR was found covering this MI355X PD refresh; the existing Kimi-K3 recipe PR #62668 targets Ascend.
