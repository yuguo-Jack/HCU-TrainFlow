# [Model] Add ColUltraVBERT late-interaction retrieval model

[Upstream PR](https://github.com/vllm-project/vllm/pull/62237) · state: closed · merged: True

## Original PR description



## Overview

Adds `ColUltraVBertForRetrieval` for [athrael-soju/ColUltraVBERT](https://huggingface.co/athrael-soju/ColUltraVBERT),
a 255M-parameter late-interaction retriever for visual documents. vLLM loads the checkpoint's Sentence Transformers
package and returns L2-normalized 768-d token vectors through `token_embed`, scored by MaxSim.

## Claims

- vLLM serves `ColUltraVBertForRetrieval` for text and page images with `runner="pooling"`.
- ViDoRe nDCG@5 matches the reference within 0.001.

## Validation

```bash
pytest tests/models/multimodal/pooling/test_colultravbert.py tests/models/test_registry.py
pytest "tests/models/test_initialization.py::test_can_initialize_large_subset[ColUltraVBertForRetrieval]"
```

All pass: the 11 ColUltraVBERT tests (7 tile-cap cases against grids from the checkpoint's image
processor), the registry (409 passed, 11 skipped) and the initialization test.

Parity against the checkpoint's Sentence Transformers `MultiVectorEncoder` on 32 ViDoRe pages and 32 queries, with
identical token ids:

| dtype | Pages, mean cosine (min item) | Queries, mean cosine (min item) | MaxSim top-1 agreement |
| --- | ---: | ---: | ---: |
| fp32 | 0.99987 (0.9987) | 0.99987 (0.9961) | 100% |
| bf16 | 0.9971 (0.9955) | 0.9966 (0.9561) | 100% |

The lowest tokens are tile separators and query padding tokens, which also move between the reference's own fp32 runs.

ViDoRe nDCG@5 (bf16), same harness:

| Task | Reference | vLLM |
| --- | ---: | ---: |
| DocVQA | 0.5263 | 0.5257 |
| TabFQuAD | 0.9251 | 0.9257 |

## Details

Follows `colmodernvbert.py`, with these differences:

- UltraBERT text encoder: RMSNorm and SwiGLU layers alternating sliding-window and full attention, each with its own
  RoPE base. UltraBERT's `sliding_window` is an inclusive radius, so vLLM gets `sliding_window + 1`.
- RMSNorm after the connector's projection.
- Pages tile through vLLM's Idefics3 processing at a 3,072 px longest edge, capped at 27 tiles of 512 px plus a global
  view; the cap lowers the longest edge per image in 512 px steps, as the checkpoint's image processor does.
- The pooler applies the package's `1_Dense` projection.
- `ColUltraVBertConfig` is vendored, because UltraBERT needs transformers 5.20 and vLLM pins below it.

Pages use the prompt `User:<image>Describe the image.<end_of_utterance>\nAssistant:`; queries append ten
`<end_of_utterance>` tokens. The docs include an `LLM.encode` example.
