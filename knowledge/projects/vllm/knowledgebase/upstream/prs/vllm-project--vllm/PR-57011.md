# [Core][Model Loader] Add sleep/wake/reload lifecycle hooks to model loader

[Upstream PR](https://github.com/vllm-project/vllm/pull/57011) · state: open · merged: False

## Original PR description

## Purpose
Add optional lifecycle hooks so a custom model loader can react to GPU-memory-validity transitions around `Worker.sleep()` / `Worker.wake_up()`:

- `on_sleep(level)` called before `Worker.sleep(level)` frees GPU memory the loader made resident.
- `on_wake_up(tags)` called after `Worker.wake_up(tags)` restores GPU memory.
- `reload_weights_inplace(vllm_config, model_config, model)` called from `GPUModelRunner.reload_weights()`. Returns False by default, falling back to the existing implementation, a loader that writes weights into the model itself overrides it and returns True.

First two hooks are no-ops and `reload_weights_inplace` returns `False` by default, so existing loaders are unaffected.

Motivating use case: the ModelExpress loader serves weights to other workers over P2P/RDMA directly from GPU memory. It needs to stop serving before that memory is invalidated by sleep, and needs to resume serving once weights are valid again.

`docs/features/sleep_mode.md` documents all three hooks under "Custom model loaders".

## Test Plan
Added new tests to `test_modelexpress_loader.py`:
- `test_modelexpress_loader_delegates_sleep_hooks` - `on_sleep`/`on_wake_up` delegate to the wrapped loader with the correct arguments.
- `test_modelexpress_loader_tolerates_missing_sleep_hooks` - no `AttributeError` when the wrapped loader predates these hooks.
- `test_modelexpress_loader_reloads_weights_inplace` - `reload_weights_inplace` delegates to the wrapped loader's `reload_model` and returns True.
- `test_modelexpress_loader_without_reload_model_falls_back` - `reload_weights_inplace` returns False when the wrapped loader has no `reload_model`, preserving the generic fallback path.

## Benchmark: sleep level 2 / wake up

Qwen3-Next-80B-A3B-Instruct, 2 replicas. One replica is put to sleep at level 2 and woken up; on wake it reloads its weights.

- **Default loader:** reads the safetensors from NFS on VAST storage. The page cache is dropped between sleep and wake, so the reload reads from storage rather than memory.
- **Model Express:** pulls the weights over RDMA from the other replica.

| Loader | Wake up |
|---|---:|
| Default loader | 49.639 s |
| Model Express | **7.705 s** |
