# [ROCm][CI] Drop LD_PRELOAD from the subprocess env in test_amd_ci_fast_exit

[Upstream PR](https://github.com/vllm-project/vllm/pull/64708) · state: closed · merged: True

## Original PR description

## Purpose
`:amd: (MI250) Docker Build Metadata` has been failing since today's nightly (Oct 30), after [#61939](https://github.com/vllm-project/vllm/pull/61939) added the `amd_ci_fast_exit` pytest plugin and its tests. Failing run: [ci#98597](https://buildkite.com/vllm/ci/builds/98597/list?jid=01a18b6a-f5da-4f82-b9be-fe27164bdb2f&tab=output) (2 of 2 attempts). Four tests in `tools/test_amd_ci_fast_exit.py` fail because the pytest subprocess they start ends with SIGSEGV:
```text
FAILED tools/test_amd_ci_fast_exit.py::test_a_passing_run_exits_zero_despite_the_teardown_crash - AssertionError: Fatal Python error: Segmentation fault
FAILED tools/test_amd_ci_fast_exit.py::test_a_failing_run_keeps_its_exit_status - assert -11 == <ExitCode.TESTS_FAILED: 1>
FAILED tools/test_amd_ci_fast_exit.py::test_python_exit_handlers_still_run - assert -11 == 0
FAILED tools/test_amd_ci_fast_exit.py::test_a_nested_in_process_session_does_not_end_the_outer_one - AssertionError: Running 2 items in this shard
```

The plugin lets pytest exit before native teardown, so a crash there cannot fail a run whose tests passed. It turns itself off when a kernel recorder is loaded, and one of its checks is `rocprofiler` in `LD_PRELOAD`. The tests run pytest in a subprocess through `_run`, which removes the recorder variables `ROCP_TOOL_LIBRARIES` and `CUDA_INJECTION64_PATH` from the subprocess environment, but not `LD_PRELOAD`.

The nightly runs with the kernel recorder enabled, which puts `librocprofiler-sdk.so` in `LD_PRELOAD`. The subprocess inherits it, so the plugin turns itself off, and the teardown crash the tests simulate ends the process with SIGSEGV (`-11`). Builds without the recorder do not set it, so the tests pass there.

This PR removes `LD_PRELOAD` from the subprocess environment in `_run`, like the other recorder variables, and adds an `LD_PRELOAD` case to `test_off_when_disabled_or_a_kernel_recorder_needs_native_teardown`, so all three recorder checks are covered. Test-only change; the plugin is unchanged.

## Test Plan
MI300X (gfx942), in the `rocm/vllm-dev:ci_base` image, with the ROCProfiler SDK preloaded as in the nightly:
```bash
cd tests
LD_PRELOAD=/usr/local/lib/python3.12/dist-packages/_rocm_sdk_devel/lib/librocprofiler-sdk.so \
  pytest -v -s tools/test_amd_ci_fast_exit.py
```
