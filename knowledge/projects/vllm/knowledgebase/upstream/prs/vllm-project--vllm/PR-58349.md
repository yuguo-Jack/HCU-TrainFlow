# [Bugfix][Frontend] Preserve MiniMax M2's unclosed final tool parameter

[Upstream PR](https://github.com/vllm-project/vllm/pull/58349) · state: open · merged: False

## Original PR description



## Purpose

Addresses the MiniMax M2 part of #57827. When the model closes `</invoke>` without closing the final `</parameter>`, final conversion drops that tool argument. This change preserves the trailing argument while keeping earlier complete arguments intact.

Adds non-streaming and streaming regression tests for this case.

`VLLM_TARGET_DEVICE=cpu .venv/bin/python -m pytest --confcutdir=tests/parser/engine tests/parser/engine/test_minimax_m2.py -v`

Run the repository's commit hooks.

- No model evaluation was run. This post-generation text conversion is covered by CPU-only parser tests.
