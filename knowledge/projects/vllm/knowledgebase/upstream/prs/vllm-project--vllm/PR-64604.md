# [CI] Enroll Language Models steps that build mamba (waits on #58795) in automatic sharding (6 jobs)

[Upstream PR](https://github.com/vllm-project/vllm/pull/64604) · state: open · merged: False

## Original PR description



## Overview

**Draft until #58795 merges.** Enrolls the three Language Models steps that build mamba-ssm and causal-conv1d from source, and their AMD mirrors, in `automatic_shard` (6 jobs). The source builds take most of a job's setup, and every shard would repeat them; #58795 prebuilds both in the test image, after which sharding these pays for itself. Part of the series that enrolls every remaining test step (#64590-#64599).

## Claims

| Step | Change | AMD mirror |
|---|---|---|
| `language-models-test-extended-generation` | enrolled | enrolled |
| `language-models-tests-granite-l4-compatibility` | enrolled | enrolled |
| `language-models-tests-hybrid` | fixed 2-way pytest-shard split becomes automatic | same |

## Validation

- `split_check.py`: no step runs the whole suite in each of its jobs.
- `/ci run` once #58795 has merged and this branch is rebased; until then the mamba builds would repeat per shard.

## Details

- **Hybrid** drops `parallelism: 2` and its `--num-shards/--shard-id` flags (step and mirror), so the planner owns the split.
- **Timeouts unchanged.**
