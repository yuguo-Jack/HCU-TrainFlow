## Overview

Bump `humming-kernels[cu13]` to 0.1.18 and remove the temporary `DeviceInfo` monkey patch from #61858. Keep its fullgraph compilation regression test and Buildkite trigger unchanged.

## Claims

- Use the upstream device-instance caching fix in [humming#149](https://github.com/vllm-project/humming/pull/149), which is included in v0.1.18.
- Remove the 60-line workaround from the lazy Humming facade while retaining regression coverage.

## Details

The workaround in #61858 guarded private attribute lookups and cached device information to avoid constructing the extension object inside a compiled forward. Humming 0.1.18 includes the upstream fix, so vLLM can use the package directly. The facade is restored exactly to its pre-#61858 implementation; the test and CI configuration are unchanged.

Duplicate checks: reviewed #61858 and its comments, and searched open PRs for `61858 in:body`, `humming`, and `"0.1.18"`. No open PR implements this upgrade and workaround removal. This follows up on the merged workaround rather than duplicating it.
