# [Bugfix][Core] Validate prompt token ids when skip_tokenizer_init is set

[Upstream PR](https://github.com/vllm-project/vllm/pull/62911) · state: closed · merged: True

## Original PR description

## Purpose

`Renderer.validate_token_ids` skips the vocab range check when there is no
tokenizer, so with `--skip-tokenizer-init` out-of-range prompt token ids are
not rejected. This runs the check whenever token ids are present, using the
model vocab size as the bound when there is no tokenizer.

No existing PR covers this.

## Test Plan

- pre-commit on the changed files
- New test `test_out_of_vocab_token_skip_tokenizer_init`

## Test Result

- pre-commit passes.
- On CPU with gpt2, id 999999 now raises `Token id 999999 is out of
  vocabulary` with and without `skip_tokenizer_init` (ran with
  `gpu_memory_utilization=0.2`, not enough free RAM for the test default).
