**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Pad token routing before comparing graph-padded rows**

When token-classification prefill uses a PIECEWISE CUDA-graph bucket (or DP token padding), `GPUModelRunner._preprocess` sends the model `num_tokens_padded` rows, while `InputBatch.make_lora_inputs` builds `token_lora_indices` from only `num_scheduled_tokens`. Thus any non-exact bucket makes these sizes differ and this assertion aborts the request (and removing it alone leaves the following indexing/`torch.where` shapes mismatched); pad the routing indices with `-1` or restrict the full-head logic to the real-token rows.
