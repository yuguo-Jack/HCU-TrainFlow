# [CI][macOS] Make RunAI test dependencies platform-aware

[Upstream PR](https://github.com/vllm-project/vllm/pull/58811) · state: open · merged: False

## Original PR description

## Purpose

`requirements/test/cuda.in` unconditionally requires `runai-model-streamer`, but that package only publishes wheels for Linux x86_64 and aarch64. On Apple Silicon, resolving this source requirement set therefore fails before contributors can install unrelated test tools or run the platform-independent tests in the RunAI loader suite.

This PR:

- restricts `runai-model-streamer` to the platforms for which wheels exist;
- skips only the tests that actually need RunAI on unsupported platforms, while keeping the dependency-free loader and configuration tests active;
- adds native macOS CI coverage for resolving `requirements/test/cuda.in` and running the RunAI loader test directory; and
- includes requirement input files in the macOS uv cache key.

Linux x86_64/aarch64 behavior is unchanged. This intentionally covers the source `cuda.in` requirement set; the generated `requirements/test/cuda.txt` used by `requirements/dev.txt` is a Linux CUDA lock and remains outside the macOS workflow.

### Duplicate check

I searched open issues and PRs for `runai-model-streamer` with macOS, Darwin, platform markers, and `requirements/test/cuda.in`. I found no open work implementing this fix. #43886 only bumps RunAI Model Streamer to 0.16.0; that release also publishes Linux-only wheels, so it does not resolve the macOS installation failure.

## Test Plan

- `uv pip install --dry-run -r requirements/test/cuda.in --index-strategy unsafe-best-match`
- `.venv/bin/python -m pytest -q -ra tests/model_executor/model_loader/runai_streamer_loader`
- `pre-commit run`
- `git diff --check`

No model evaluation is needed because this changes dependency/platform gating and CI coverage only; model execution and output behavior are unchanged.

## Test Result

- Dependency resolution passed: 337 packages resolved on macOS arm64.
- RunAI loader suite passed: 48 passed, 15 skipped. Fourteen skips require the unsupported RunAI package; one is the pre-existing disabled GCS test.
- All applicable pre-commit hooks passed, including Ruff, actionlint, generated requirement checks, test tethering, mypy, SPDX, lazy-import, and forbidden-import checks.
- `git diff --check` passed.
