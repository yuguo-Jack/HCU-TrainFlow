[Upstream PR](https://github.com/vllm-project/vllm/pull/61474) · state: closed · merged: True

## Original PR description



## Overview

Enroll five NVIDIA CI steps in automatic runtime sharding, selecting long jobs from the [duration ranking](https://vllm-ci-dashboard.vercel.app/jobs) over the preceding 12 hours. Batch 2 of five independently based changes.

## Claims

Preserve the test commands and discovery scope while assigning tests using main timing data. Existing AMD fixed shards retain their effective commands and parallelism. Actual wall-time and cost improvements await Buildkite validation.
