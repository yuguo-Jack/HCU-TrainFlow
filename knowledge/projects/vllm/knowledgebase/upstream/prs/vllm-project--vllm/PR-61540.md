# [Docs] Document NIXL KV connector metrics aggregation semantics

[Upstream PR](https://github.com/vllm-project/vllm/pull/61540) · state: open · merged: False

## Original PR description

Resolves #41230.

## Summary
Document the metrics aggregation semantics of the NIXL KV connector, which were previously undocumented and caused user confusion in multi-rank (TP > 1) deployments.

## Changes
- `vllm/distributed/kv_transfer/kv_connector/v1/nixl/stats.py`: expanded `NixlKVConnectorStats` docstring explaining that stats are aggregated across all TP ranks before `reduce()` computes summary stats, with per-metric semantics (Num successful transfers / Avg MB per transfer / Throughput / P90); clarifying comments in `aggregate()` and `reduce()`.
- `vllm/distributed/kv_transfer/kv_connector/v1/metrics.py`: documented the `observe()` -> `aggregate()` -> `reduce()` -> `log()` pipeline on `KVConnectorLogging`, noting stats arrive pre-aggregated across workers.

## Test plan
Docs-only change (docstrings/comments); no functional code touched.
