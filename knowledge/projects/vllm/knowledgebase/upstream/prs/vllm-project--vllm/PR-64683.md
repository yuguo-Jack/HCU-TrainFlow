# [Model] Add Apriel Voice support

[Upstream PR](https://github.com/vllm-project/vllm/pull/64683) · state: open · merged: False

## Original PR description

## Overview

Adds native support for [Apriel Voice 27B Preview](https://huggingface.co/ServiceNow-AI/Apriel-Voice-27B-preview), a speech-language model that combines a Whisper speech encoder with a Gemma 4 backbone. The model accepts audio, text, and image inputs and generates text responses and tool calls.

## Claims

- Add `AprielVoiceModel` and `AprielVoiceConfig`, including multimodal processing, audio projection, and checkpoint weight loading.
- Reuse the existing Gemma 4 language and vision implementations, reasoning and tool parsers, and speculative decoding support.
- Add supported-model documentation and an example checkpoint in the model test registry.

## Validation

- All applicable pre-commit checks passed on the changed files.
- GPU serving validation on one H100 covered text, audio, and image inputs; reasoning; tool calling with pre-tool speech; streaming; and tool-response handling.
- Speculative decoding was validated with the Gemma 4 assistant, including nonzero draft-token acceptance. Serving checks ran with `VLLM_GPU_SYNC_CHECK=error`.

Validation covers functional serving. GPU validation preceded the upstream refresh; the Apriel Voice implementation is unchanged. Local checks were rerun after the refresh. Full benchmark evaluation and upstream CI remain outstanding.

## Details

Audio features are encoded by Whisper and projected into the Gemma 4 embedding space. Image inputs use the existing Gemma 4 vision path. The model-specific configuration preserves the wrapped backbone when saved and reloaded.

Serving configuration from the model card (four GPUs):

```bash
VLLM_MAX_AUDIO_DECODE_DURATION_S=1800 vllm serve \
    ServiceNow-AI/Apriel-Voice-27B-preview \
    --trust-remote-code \
    --served-model-name Apriel-Voice-27B \
    --dtype bfloat16 \
    --host 0.0.0.0 --port 8000 \
    --max-model-len 262144 \
    --max-num-batched-tokens 16384 \
    --tensor-parallel-size 4 \
    --gpu-memory-utilization 0.95 \
    --speculative-config '{"model":"google/gemma-4-26B-A4B-it-assistant","num_speculative_tokens":3}' \
    --default-chat-template-kwargs '{"enable_thinking":true}' \
    --enable-auto-tool-choice \
    --tool-call-parser gemma4 \
    --reasoning-parser gemma4
```

`--trust-remote-code` is required for the checkpoint's Hugging Face processor. Additional serving details are documented in `docs/models/supported_models/apriel_voice.md`. The model card provides architecture details and evaluation results.

Pre-tool speech is enabled by default (`enable_pretool_speech=true`) when the conversation contains audio and tools are supplied. The chat template prompts a short natural-language preface before a tool call. Disable this automatic instruction server-wide with:

```bash
--default-chat-template-kwargs '{"enable_thinking":true,"enable_pretool_speech":false}'
```

Or override it per request through the OpenAI Python client's extra body:

```python
extra_body={"chat_template_kwargs": {"enable_pretool_speech": False}}
```

No overlapping open PR adds Apriel Voice model support.
