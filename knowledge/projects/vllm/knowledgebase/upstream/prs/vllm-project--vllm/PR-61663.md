# [Bugfix][EPLB] Track sliding window load per logical expert to prevent misattribution (#60685)

[Upstream PR](https://github.com/vllm-project/vllm/pull/61663) · state: closed · merged: False

## Original PR description

### Summary
Fixes #60685.

Currently, EPLB collects token loads in `expert_load_window` by physical expert slot (`[expert_load_window_size, num_moe_layers, num_physical_experts]`). In `rearrange()`, historical loads are converted to logical experts using the active `physical_to_logical_map`:
```python
logical_expert_load_window.scatter_add_(
    dim=-1,
    index=physical_to_logical.masked_fill(
        physical_to_logical < 0, invalid_idx
    )
    .unsqueeze(0)
    .expand_as(expert_load_window)
    .long(),
    src=expert_load_window,
)
```
When `step_interval < window_size` (or in Async EPLB where layers commit new maps at staggered steps), applying the newly rearranged map across the entire historical window falsely attributes past tokens in physical slot $p$ to whichever logical expert was newly assigned to slot $p$.

### Solution
1. **Direct Logical Recording at Step Time**: Record sliding window loads directly per logical expert at step time in `_record_step_expert_load`, using each layer's active `physical_to_logical_map` at that step. This guarantees that historical steps retain their true logical attribution across rearrangements.
2. **Zero Allocation in Step Path**: Preallocate `logical_load_buffer: (num_moe_layers, num_logical_experts + 1)` in `EplbModelState` so that step recording performs zero GPU memory allocations in the hot path.
3. **Simplified Rearrange Aggregation**: Window load aggregation in `rearrange()` simplifies to `expert_load_window.sum(dim=0)`, completely eliminating intermediate 3D tensor allocations and `scatter_add_` operations.
4. **Clean Elastic EP Scaling**: Removed physical padding of `expert_load_window` in `reconfigure_physical_expert_slots` because logical expert dimensions are invariant to EP size changes.
5. **Unit Tests**: Added deterministic unit tests in `tests/distributed/test_eplb_utils.py` verifying mapping correctness, unmapped slot filtering, and historical preservation across expert swaps (reproducing #60685).
