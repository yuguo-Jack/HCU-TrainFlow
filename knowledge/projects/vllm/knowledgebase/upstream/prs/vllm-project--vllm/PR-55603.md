## Purpose
fixes #55509 
We see value error with `gpu_memory_utilization` ... or decreasing `max_model_len` being reason, 
where as it is because of the attention , which can be set in launch command or not, like for example if we have --kv-cache-dtype fp8 it automatically goes to flashinfer and this message without making user aware about attention backend being the reason will have them confused.

So may change is pretty small, it tries to find attention backend, and adds that info in already exisisting value error.
