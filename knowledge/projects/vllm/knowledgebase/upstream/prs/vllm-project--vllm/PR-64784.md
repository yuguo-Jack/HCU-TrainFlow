# [ROCm][CI] Fix GPU memory startup flakes in PP and sleep mode tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/64784) · state: open · merged: False

## Original PR description

MI250 Pipeline + Context Parallelism: test_pp_cudagraph and test_pipeline_parallel fail when the worker on cuda:0 finds 58.0-58.4 GiB free against the 58.87 GiB requested by the default 0.92 utilization. Idle MI250 GPUs report ~2.7 GiB in use, so there is no headroom left. Use 0.85 on ROCm for these small models.

MI300 Basic Correctness Sleep Mode: test_deep_sleep_fp8_kvcache and test_deep_sleep_async start while the previous spawned test still holds ~21 GiB. The gpu_memory_cleared fixture only waited on gfx950; make it wait on all ROCm GPUs.
