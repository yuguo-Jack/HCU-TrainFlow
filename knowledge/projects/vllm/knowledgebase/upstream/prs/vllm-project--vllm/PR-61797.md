# [UMBP][9/10] Add lazy GPU cache offloading

[Upstream PR](https://github.com/vllm-project/vllm/pull/61797) · state: open · merged: False

## Original PR description

This PR is split from the original full PR: https://github.com/vllm-project/vllm/pull/58568

Select reusable prefix blocks from the GPU free queue for optional lazy offload.
Close full-attention prefix chains before a lazy store is submitted, and keep source blocks pinned until the transfer finishes.
Recheck authoritative residency and retry transient lookup failures without crashing the scheduler.

Implementation only. `lazy_offload` defaults to false, and the umbrella serving tables use that default. Tests are in the next PR.

Commit: `47a1beb0c8`. Review slice of [vllm-project/vllm#58568](https://github.com/vllm-project/vllm/pull/58568) for [RFC #57187](https://github.com/vllm-project/vllm/issues/57187).
