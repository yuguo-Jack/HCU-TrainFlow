[Upstream PR](https://github.com/vllm-project/vllm/pull/62638) · state: closed · merged: True

## Original PR description

## Purpose

`tests/tool_use/mistral/test_mistral_tool_calls.py::test_tool_call_none_with_tools[ministral-3b]` intermittently fails on XPU: streaming and non-streaming greedy outputs match for the first ~100 chars, then diverge at the end ("...for you." vs "...If so, I'll fetch ... in Fahrenheit."). This is numerical noise on near-tied logits (prefix caching is already disabled), not a parser issue; the same test passed 3/3 on rerun. On XPU the exact-equality assertion is relaxed to "common prefix >= half of the shorter output"; other platforms keep exact equality.

Not a duplicate: no open PR touches this test.
