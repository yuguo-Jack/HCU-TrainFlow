"Hi team! Just wanted to note that I've implemented the SequenceParallelismMoEPass requested in https://github.com/vllm-project/vllm/issues/29139. The pass safely intercepts the FX graph and rewrites AllReduce -> RMSNorm -> SequenceParallelChunk into a much more efficient ReduceScatter -> RMSNorm. I also handled the AsyncTP compatibility by swapping AllGather -> RMSNorm to RMSNorm -> AllGather. Looking forward to seeing the performance bumps on the CI once a maintainer can drop the ready label to trigger the test suite!"
