## Original PR description

## Overview

`test_plan_uses_state_params` calls `_SM90State.plan()`, which calls `torch.cuda.is_current_stream_capturing()`. On CPU-only torch builds this raises `RuntimeError: Tried to instantiate dummy base class _cuda_isCurrentStreamCapturing`. Patch it to return False in the test, as other tests in the repo already do.

## Test Plan
`pytest -q tests/v1/attention/test_flashinfer_mla_sparse_sm90.py`

## Test Result
Pass on a CPU-only build, where `test_plan_uses_state_params[kv_dtype0/1]` previously failed.
