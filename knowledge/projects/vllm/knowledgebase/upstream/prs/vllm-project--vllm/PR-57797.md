# [Bugfix][RL] Load attention sinks through weight_loader for layerwise reload

[Upstream PR](https://github.com/vllm-project/vllm/pull/57797) · state: closed · merged: True

## Original PR description

## Overview

Attention sink writes bypassed parameter `weight_loader` callbacks, leaving stale sink values after layerwise reload during RL weight updates. Register checkpoint-backed sinks with a common TP loader and factory, and route model loading through the registered callbacks.

This consolidates and supersedes #57798, #57801, #57803, #57804, #57805, and #57806.

## Claims

- DeepSeek V4/V4.1, HY-V4, MiMo-V2 (including MTP and Omni MTP), GPT-OSS, Laguna, and Qwen3-DFlash load sinks through their current parameter loader; GPT-OSS preserves MXFP4, Quark and other quantization dispatch.
- The loader partitions global checkpoint heads once, writes the local shard in place, and restores padded heads to `-inf`. The factory initializes sinks to `-inf` and registers the loader.
- Regression coverage checks changed sink values across two layerwise reloads, TP sharding, padding, storage preservation, quantization dispatch and pipeline-stage skips.

## Details

A dedicated sink loader derives shard length from the checkpoint rather than the runtime parameter: DeepSeek pads its runtime sink, so `sharded_weight_loader(0)` would use the wrong shard length. Unpadded sinks use the same loader without reconstructing storage. Checkpoint heads must divide evenly across TP ranks.

The loader keeps the divisibility check and relies on tensor slicing and the default loader for incompatible shapes. Empty checkpoints are no longer explicitly rejected. Lifecycle rationale stays here rather than in long helper docstrings.

Tests in the existing CI-selected `test_reload.py` and `test_weight_utils.py` suites cover actual model dispatch for MiMo MTP/Omni MTP, Laguna, DFlash, GPT-OSS, DeepSeek V4/V4.1 and HY-V4. The DeepSeek/HY-V4 tests replace the current loader and verify the unsliced global checkpoint reaches it exactly once for each load. AST factory-name scanning and redundant empty/padding tests were removed.

No full-model accuracy evaluation, real-checkpoint end-to-end reload, TP>2 or multi-node run was performed. Pipeline parallelism is covered by the skip-path test. Backend-converted sink copies and GPT-OSS expert reload follow-ups are outside this PR; their behavior is unchanged.

## Non-test concision

**`load_attention_sink` (weight_utils.py).** Of its four checks, only the divisibility check catches something nothing else does.

| Check | Why it can go |
|---|---|
| one-dimensional | a wrong shape already fails `default_weight_loader`'s size assertion |
| `local_heads > param.numel()` | `param[:local_heads]` then has fewer elements than the slice, so the same assertion fires |
| empty checkpoint | guards a checkpoint that doesn't exist; the old code didn't check it |

Also:
- `if param.numel() > local_heads:` isn't needed; `fill_` on an empty slice is a no-op.
- The three-paragraph docstring repeats the PR description's lifecycle rationale, and the comment above the empty check restates the error.

A minimal version:

```python
def load_attention_sink(param: torch.Tensor, loaded_weight: torch.Tensor) -> None:
    """Load this rank's heads of a global sink; padded heads are set to -inf."""
    tp_size = get_tensor_model_parallel_world_size()
    if loaded_weight.numel() % tp_size:
        raise ValueError(
            f"Attention sink heads ({loaded_weight.numel()}) must be divisible "
            f"by tp_size ({tp_size})"
        )
    local_heads = loaded_weight.numel() // tp_size
    start = get_tensor_model_parallel_rank() * local_heads
    default_weight_loader(param[:local_heads], loaded_weight.narrow(0, start, local_heads))
    param.data[local_heads:].fill_(-float("inf"))
```

The `make_attention_sink` docstring can be one or two lines as well.

**Keeping one dedicated loader is right.** For unpadded sinks this duplicates `sharded_weight_loader(0)`. But that loader takes the slice length from the parameter, which is wrong for the padded DeepSeek sink, while the deleted Laguna/DFlash code took it from the checkpoint. The model-side changes are already minimal; HY-V4's diff is mostly de-indentation.

## Tests

- Remove the AST scan `test_attention_sink_uses_common_factory`. It checks that a class contains a call named `make_attention_sink`, not that the parameter is registered, loaded or reloaded, and an aliased import would fail it falsely.
- Remove the stray `@pytest.mark.parametrize("quant_method", ...)` on the helper `_gpt_oss_container`; the helper isn't collected, so the mark does nothing.
- Drop `test_attention_sink_loader_restores_padding`: the shape matrix starts from a zero tail and asserts `-inf`, and the reload test corrupts the storage first. The empty-checkpoint test only adds a message assertion, and can go with the trimmed validation above.
- **Coverage gap:** the per-model dispatch tests don't exercise the DeepSeek or HY-V4 `load_weights`. One small spy test that the unsliced checkpoint reaches the sink's current `weight_loader` for each would close it.

## Follow-ups (outside this PR)

- **CPU attention with a non-bf16/fp32 sink stays stale after reload.** `cpu_attn.py:431-439` replaces `self.sinks` with an fp32 copy on the first forward, and the CPU backend has no `process_weights_after_loading` to refresh it.
  - This affects GPT-OSS / MiMo / Laguna / DFlash running fp16 on CPU. DeepSeek is unaffected because its sink is created as fp32.
  - It isn't introduced by this PR: the copy was stale before too. Keeping `_sinks_source` and refreshing in PWAL, as FlashInfer and b12x do, would fix it.
- **GPT-OSS expert weights and biases are still written with bare `param.copy_`**, the same bug class for layerwise reload.
- **An end-to-end check would be worth adding.** Reloading the same checkpoint can't distinguish main from this PR. Reload a checkpoint with changed sinks and compare per-tensor checksums against a cold load of that checkpoint:
  - on main, only the sink tensors should differ; with this PR, nothing should;
  - for DeepSeek V4, use a non-MegaMoE backend, since MegaMoE's routed experts also don't update on reload on main.

The same script contains a control that reproduces the pre-PR loading shape (indexed `params[name][:n].copy_(...)`, no `weight_loader`). After a layerwise reload it never receives the new checkpoint values — it keeps the old value or, for a non-deferred layer, uninitialized materialized memory:

```text

        (after [0.0,0.0,0.0,0.0] cold [0.0,1.0,2.0,3.0] new [100,101,102,103])
```

The mechanism is `copy_` into a meta tensor being a silent no-op (`torch.empty(4, device="meta").copy_(x)` raises nothing), so the direct write disappears during reload while the wrapped loaders are replayed. This confirms the bug premise of the PR at the mechanism level.

## Contrast tests: the sink only reloads through its `weight_loader` (not committed)

Following the review discussion about whether the suite actually shows the *before/after* behaviour, I wrote a self-contained contrast test and ran it on H20. **It is deliberately not pushed** - the file lives only in the cluster worktree and in this comment.

### What it proves

| Proposition | Arm | Result on H20 |
| --- | --- | --- |
| Pre-fix code (`params_dict[name][:n].copy_(...)`) cannot update the sink on reload | `pre_fix` (the deleted code, reproduced verbatim in the test) | sink never receives the new slice; the sibling parameter does reload |
| Fixed code updates the sink in place | `fixed` (factory + registered loader + production reload lifecycle) | new per-rank slice, padding restored to `-inf`, `data_ptr` unchanged |

Both arms run the *same* production layerwise lifecycle (`record_metadata_for_reloading` → `initialize_layerwise_reload` → load → `finalize_layerwise_reload`) and both assert that a non-sink parameter of the same layer is reloaded, so a passing `pre_fix` arm is impossible unless the bug regressed.

The `pre_fix` arm reproduces exactly what this PR deletes:

```python
# DeepSeek V4 / V4.1, HY-V4, GPT-OSS, MiMo-V2, Laguna, Qwen3-DFlash used to do:
if any(attr in name for attr in SINK_ATTRS):
    local = loaded_weight.numel() // tp_size
    start = tp_rank * local
    param[:local].copy_(loaded_weight[start : start + local])   # bypasses weight_loader
```

During reload the parameter is a meta tensor, and `copy_` into a meta tensor is a silent no-op, so the write disappears.

### Structure (71 cases)

| Tier | What it builds | Cases |
| --- | --- | --- |

```python# SPDX-License-Identifier: Apache-2.0
def legacy_sink_load_weights(self, weights):
    """Pre-fix sink handling: direct indexed copy, no ``weight_loader``.

    ``load_weights`` used to special-case sink names and copy the TP-local slice
    straight into the parameter. That bypasses the loader wrapper the layerwise
    reload installs, so the copy targets a meta tensor and silently disappears.
    """
    from vllm.model_executor.model_loader import weight_utils

    params = dict(self.named_parameters())
    tp_size = weight_utils.get_tensor_model_parallel_world_size()
    tp_rank = weight_utils.get_tensor_model_parallel_rank()
    loaded = set()
    for name, loaded_weight in weights:
        param = params[name]
        if any(attr in name for attr in SINK_ATTRS):
            local = loaded_weight.numel() // tp_size
            start = tp_rank * local
            param[:local].copy_(loaded_weight[start : start + local])
        else:
            loader = getattr(param, "weight_loader", default_weight_loader)
            loader(param, loaded_weight)
        loaded.add(name)
    return loaded

class _ConfigOverride:
    """Delegate attribute lookups to a base object, replacing the given keys.

    ``__getattribute__`` rather than ``__getattr__``: the replaced names are real
    fields on the wrapped config objects, so ``__getattr__`` never runs.
    """

    def __init__(self, base, **overrides):
        object.__setattr__(self, "_base", base)
        object.__setattr__(self, "_overrides", overrides)

    def __getattribute__(self, name):
        overrides = object.__getattribute__(self, "_overrides")
        if name in overrides:
            return overrides[name]
        return getattr(object.__getattribute__(self, "_base"), name)

def _patch_tp(monkeypatch, tp_rank, tp_size, module=None):
    """Point the loader (and a model module under test) at one TP rank."""
    from vllm.model_executor.model_loader import weight_utils

    targets = [weight_utils] if module is None else [weight_utils, module]
    for target in targets:
        monkeypatch.setattr(
            target,
            "get_tensor_model_parallel_rank",
            lambda rank=tp_rank: rank,
            raising=False,
        )
        monkeypatch.setattr(
            target,
            "get_tensor_model_parallel_world_size",
            lambda size=tp_size: size,
            raising=False,
        )


def _expected_sink(checkpoint, tp_rank, tp_size, runtime_heads):
    local = checkpoint.numel() // tp_size
    return torch.cat(
        (
            checkpoint[tp_rank * local : (tp_rank + 1) * local],
            torch.full((runtime_heads - local,), -float("inf")),
        )
    )


def _reload_cycle(model, weights, act_dtype=torch.float32):
    """Run the production layerwise reload lifecycle over ``weights``."""
    record_metadata_for_reloading(model)
    initialize_layerwise_reload(model)
    model.load_weights(weights)
    finalize_layerwise_reload(model, SimpleNamespace(dtype=act_dtype))

# Tier 1: synthetic tiny model, one sink created by the production factory
# ---------------------------------------------------------------------------
class _TinySinkModel(nn.Module):
    """A tiny model whose sink comes from ``make_attention_sink``."""

    def __init__(self, runtime_heads=8):
        super().__init__()
        self.attn_sink = make_attention_sink(runtime_heads, torch.float32)
        self.proj = nn.Parameter(torch.zeros(16), requires_grad=False)
        self.proj.weight_loader = default_weight_loader

    def load_weights(self, weights):
        params = dict(self.named_parameters())
        loaded = set()
        for name, weight in weights:
            param = params[name]
            param.weight_loader(param, weight)
            loaded.add(name)
        return loaded


@pytest.mark.parametrize("tp_rank", [0, 1])
@pytest.mark.parametrize("tp_size", [1, 2])
@pytest.mark.parametrize("legacy", [True, False], ids=["pre_fix", "fixed"])
def test_tiny_model_sink_reload_contrast(monkeypatch, tp_rank, tp_size, legacy):
    """Only the loader path survives a layerwise reload.

    ``pre_fix`` reproduces the deleted direct copy: the reload writes into a meta
    tensor, which silently does nothing, so the sink keeps its old storage and
    never receives the new checkpoint values.
    """
    if tp_rank >= tp_size:
        pytest.skip("rank does not exist for this TP size")

    model = _TinySinkModel(runtime_heads=8)
    if legacy:
        monkeypatch.setattr(type(model), "load_weights", legacy_sink_load_weights)
    _patch_tp(monkeypatch, tp_rank, tp_size)

    checkpoint = torch.arange(4, dtype=torch.float32)
    assert model.load_weights(
        [("attn_sink", checkpoint), ("proj", torch.ones(16))]
    ) == {"attn_sink", "proj"}
    kernel_sink = model.attn_sink
    assert torch.equal(
        kernel_sink.detach().float(),
        _expected_sink(checkpoint, tp_rank, tp_size, kernel_sink.numel()),
    )

    updated = checkpoint + 100.0
    _reload_cycle(
        model,
        [("attn_sink", updated), ("proj", torch.full((16,), 7.0))],
    )

    after = model.attn_sink
    new_slice = _expected_sink(updated, tp_rank, tp_size, after.numel())
    local = 4 // tp_size
    if legacy:
        # The bug: the reloaded slice never reaches the sink. It keeps the old
        # value or uninitialized materialized memory, depending on the layer.
        assert not torch.equal(after[:local].detach().float(), new_slice[:local])
    else:
        assert torch.equal(after.detach().float(), new_slice)
    # Both arms keep the original storage, and both reload the sibling parameter:
    # a failure here would mean the reload pipeline never ran.
    assert after.data_ptr() == kernel_sink.data_ptr()
    assert torch.equal(model.proj, torch.full((16,), 7.0))

@pytest.mark.parametrize("legacy", [True, False], ids=["pre_fix", "fixed"])
@pytest.mark.parametrize("family", sorted(TINY_SINK_MODULES))

def test_real_module_sink_reload_contrast(
    dist_init, monkeypatch, family, legacy, tp_rank
):
    """A real sink module reloads its sink only through the registered loader."""
    module, sink_name, global_heads = TINY_SINK_MODULES[family]()
    sink = getattr(module, sink_name)
    assert inspect.unwrap(sink.weight_loader) is load_attention_sink
    assert torch.isinf(sink.detach()).all() and (sink.detach() < 0).all()
    for param in module.parameters():
        initialize_single_dummy_weight(param)

    model = _WrappedAttention(module)
    if legacy:
        monkeypatch.setattr(type(model), "load_weights", legacy_sink_load_weights)
    _patch_tp(monkeypatch, tp_rank, tp_size=2)

    name = f"attn.{sink_name}"
    checkpoint = torch.arange(global_heads, dtype=torch.float32)
    local = global_heads // 2
    kernel_sink = sink
    assert model.load_weights([(name, checkpoint)]) == {name}
    assert torch.equal(
        kernel_sink[:local].detach().float(), checkpoint.chunk(2)[tp_rank]
    )
    if not legacy:
        # Only the loader restores the padded heads to -inf; the deleted copy
        # left them at whatever value the dummy initialization produced.
        assert torch.isinf(kernel_sink[local:]).all()
        assert (kernel_sink[local:] < 0).all()

    updated = checkpoint + 100.0
    _reload_cycle(model, [(name, updated)], act_dtype=torch.bfloat16)

    after = getattr(module, sink_name)
    new_slice = _expected_sink(updated, tp_rank, 2, after.numel())
    if legacy:
        # Compare the head slice only: the padded heads differ in both arms.
        assert not torch.equal(
            after[:local].detach().float(), updated.chunk(2)[tp_rank]
        )
    else:
        assert torch.equal(after.detach().float(), new_slice)
    assert after.data_ptr() == kernel_sink.data_ptr()
```
