# [KV Cache] Bound packed hidden-state pages and retain MRV2 CUDA graphs

[Upstream PR](https://github.com/vllm-project/vllm/pull/59037) · state: closed · merged: False

## Original PR description

## Overview

**Closing this draft:** full-model hidden-state extraction now works on unmodified main. The remaining memory-sizing and CUDA-graph improvements are deferred to prioritize enabling extraction for other models. See the updated evidence in #59024.

Keep GLM-5.3-Flash hidden-state extraction within the native packed BLHNC cache stride and preserve MRV2 piecewise CUDA graphs. Follows up on #59024, updating this existing draft rather than creating a duplicate. Basic extraction now works on main, these changes address memory use and graph selection.

## Claims

- Size hidden-state blocks to fit native packed pages while preserving block-size divisibility.
- Allow the connector to read logical cache views with either LBNHC or BLHNC strides.
- Retain MRV2 breakable graphs when cache-only attention rules out full capture.

## Details

The auxiliary-state capture and generic packed-layout prerequisites (#56983 and #57169) are merged and excluded from this diff. Main now contains the underlying extraction support, but packed hidden-state pages retain the native token block size and can inflate the shared cache stride. MRV2 also misses breakable graph availability when resolving cache-only attention's graph mode.

Reuse the existing divisor helper and logical tensor indexing. Regression coverage checks GLM-shaped cache sizing, native-page isolation, strided extraction, and mixed-length concurrent requests. The minimum hidden-state block is one token, so a single token larger than the native page still increases the stride. No steady-state synchronization is added.

Full-checkpoint results cover prompt extraction with prefix caching disabled. Generated-token extraction and performance remain unvalidated. AI assistance was used.
