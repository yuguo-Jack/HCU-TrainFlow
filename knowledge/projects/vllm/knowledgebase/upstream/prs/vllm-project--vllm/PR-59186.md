# [Bugfix][Core] Fix filesystem KV offload waits during shutdown

[Upstream PR](https://github.com/vllm-project/vllm/pull/59186) · state: closed · merged: False

## Original PR description

## Purpose

Fix two shutdown races in the filesystem KV-offload thread pool:

- `shutdown()` resets `_inflight_jobs` to zero when cancelling queued tasks. An already-running job can then finish and decrement it to -1, causing a subsequent `wait_idle()` to block indefinitely even after every worker has exited.
- After `shutdown(wait=False)`, `wait_idle()` can observe the cleared count and return while a worker is still copying data.

Do not decrement the cleared count after shutdown. When shutdown has started, join workers outside the condition lock before returning from `wait_idle()`. Queued tasks remain cancelled, including the queued portion of a partially executed job.
