# [Misc] Remove tool name from warn logs

[Upstream PR](https://github.com/vllm-project/vllm/pull/59294) · state: closed · merged: True

## Original PR description


## Purpose

Tool names are user input and must be kept private. 

Previously, WARN logs for malformed tool calls did include tool names, e.g.:
```
Tool call 'my_tool' has arguments that are not valid JSON (420 chars); coercing to an empty object so the conversation can continue.
```

After this change, the WARN log does no longer print sensitive information:
```
Tool call has arguments that are not valid JSON (420 chars); coercing to an empty object so the conversation can continue.
```

Upside: vllm can be used in privacy-relevant applications without custom patches
Downside: debugging is more complex in case of malformed tool calls. We could add DEBUG logs that include the tool name, if strongly desired.
