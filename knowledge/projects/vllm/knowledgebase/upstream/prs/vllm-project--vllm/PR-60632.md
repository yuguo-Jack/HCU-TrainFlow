# [Model][LoRA] Support LoRA for EmbeddingGemma2Model

[Upstream PR](https://github.com/vllm-project/vllm/pull/60632) · state: open · merged: False

## Original PR description



## Overview

Enable LoRA for `EmbeddingGemma2Model` (`google/embeddinggemma-2`), added in #60254. Adapters attach to the language model only, so a single engine can serve LoRA-adapted text queries and base-weight image queries in the same batch.

## Claims

- `--enable-lora` works with `EmbeddingGemma2Model`. Before this change, startup fails with `EmbeddingGemma2Model does not support LoRA yet.`
- `get_mm_mapping()` routes LoRA to `language_model`. The vision and audio towers and their connectors keep base weights, and tower/connector LoRA stays disabled.
- Per-request adapters: in one `LLM.embed` call, a request with a `LoRARequest` gets the adapted embedding. Requests without one, including image inputs, return the base embedding.

## Details

- The change mirrors `Gemma4ForConditionalGeneration`: `SupportsLoRA` plus `get_mm_mapping()`. `packed_modules_mapping` (`qkv_proj`, `gate_up_proj`) was already declared, and the text model already uses vLLM parallel linear layers, so no layer changes are needed.
- `supports_tower_connector_lora` is left at its default (`False`). Embedding adapters for this model target the text decoder, and enabling tower LoRA would need `get_mm_lora_token_counts()`.
- Image tokens pass through the language model, so a LoRA request with an image input applies the adapter to those tokens as well, the same as Gemma 4. Serving base image embeddings means sending image requests without a `LoRARequest`.
- Adds the missing `EmbeddingGemma2Model` row to the multimodal embedding models table, with LoRA marked.
- Not a duplicate: before starting, I searched open and closed PRs and issues for EmbeddingGemma2, `embedding_gemma2` and LoRA on embedding/multimodal pooling models. #60254, #60289, #60280 and #60295 added and stabilised the model without LoRA. Open PRs #60631 (Triton prefill tiles) and #60009 (tensor registration) are unrelated.

Usage:

```python
from vllm import LLM
from vllm.lora.request import LoRARequest

llm = LLM("google/embeddinggemma-2", runner="pooling", enable_lora=True, max_lora_rank=32)
adapter = LoRARequest("nordic", 1, "/path/to/adapter")
out = llm.embed(
    ["task: search result | query: rød cykel",
     {"prompt": "<|image|>", "multi_modal_data": {"image": image}}],
    lora_request=[adapter, None],
)
```
