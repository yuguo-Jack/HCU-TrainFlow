# [Model] Add Jina v2 embedding support

[Upstream PR](https://github.com/vllm-project/vllm/pull/60393) · state: open · merged: False

## Original PR description

## Overview

Add native embedding support for `jinaai/jina-embeddings-v2-small-en`. Fixes #48127.

## Claims

- Load `JinaBertForMaskedLM` checkpoints for mean-pooled embeddings without remote code.
- Support Jina's ALiBi attention and GeGLU layers using existing BERT and parallel layers.
- Correct CPU bidirectional ALiBi to penalize absolute distance; preserve causal attention.

## Validation

Built all three CPU extension variants from source. On CPU with eager execution, compared six texts (including empty input, Chinese and 602 tokens) against the upstream HF model under Transformers 4.57.6. Native inference used Transformers 5.18.0. The HF reference also matched Sentence Transformers exactly.

| Configuration | Minimum cosine similarity | Maximum absolute error |
| --- | ---: | ---: |
| FP32, TP=1 | 0.9999998 | 1.13e-6 |
| FP32, TP=2 | 0.9999999 | 8.94e-7 |
| BF16, TP=1 | 0.9999808 | 0.01104 |

- `pytest tests/kernels/attention/test_cpu_attn.py -k bidirectional_alibi -q`: 6 passed. The bidirectional case failed before the kernel fix.
- `pytest tests/models/language/pooling/test_embedding.py -k jina_embedding_batching -q`: 1 passed; single and mixed-length batch outputs agree.
- `pytest tests/models/test_registry.py -k JinaBert -q`: 1 passed.
- Full pre-commit passed for all changed files. Remote CI and docs are blocked by the contributor authorization gate.

<summary>Reproduce the embedding comparison</summary>

Use the source checkout's `.venv/bin/python`. Keep the old HF dependency isolated, since upstream Jina remote code imports `transformers.onnx`, which was removed in Transformers 5.

```bash
uv pip install --target /tmp/jina-hf4 'transformers==4.57.6'
PYTHONPATH=/tmp/jina-hf4 .venv/bin/python - <<'PY'
import torch
from transformers import AutoModel, AutoTokenizer
name = 'jinaai/jina-embeddings-v2-small-en'
revision = '44e7d1d6caec8c883c2d4b207588504d519788d0'
texts = ['The quick brown fox jumps over the lazy dog.', 'A small sentence.',
         '', '你好，世界。', 'Embedding models turn text into vectors.', 'hello ' * 600]
model = AutoModel.from_pretrained(name, revision=revision, trust_remote_code=True,
    code_revision='f3ec4cf7de7e561007f27c9efc7148b0bd713f81',
    max_position_embeddings=1024).eval()
inputs = AutoTokenizer.from_pretrained(name, revision=revision)(
    texts, padding=True, return_tensors='pt')
with torch.inference_mode():
    hidden = model(**inputs).last_hidden_state
    mask = inputs['attention_mask'].unsqueeze(-1)
    embeddings = (hidden * mask).sum(1) / mask.sum(1)
torch.save({'texts': texts, 'embeddings': embeddings}, '/tmp/jina-reference.pt')
PY
cat > /tmp/check-jina.py <<'PY'
import os
import torch
import torch.nn.functional as F
from vllm import LLM

def main():
    ref = torch.load('/tmp/jina-reference.pt', weights_only=True)
    llm = LLM(model='jinaai/jina-embeddings-v2-small-en',
        revision='44e7d1d6caec8c883c2d4b207588504d519788d0',
        runner='pooling', trust_remote_code=False, enforce_eager=True,
        dtype=os.getenv('JINA_DTYPE', 'float32'),
        tensor_parallel_size=int(os.getenv('JINA_TP', '1')),
        max_model_len=1024, max_num_seqs=6, max_num_batched_tokens=1024)
    actual = torch.tensor([out.outputs.embedding for out in llm.embed(ref['texts'])])
    print(F.cosine_similarity(actual, ref['embeddings']).min().item())
    print((actual - ref['embeddings']).abs().max().item())

if __name__ == '__main__':
    main()
PY
VLLM_CPU_KVCACHE_SPACE=1 .venv/bin/python /tmp/check-jina.py
# Repeat with JINA_DTYPE=bfloat16 or JINA_TP=2, binding CPU threads per rank.
```

## Details

Jina uses no absolute position embeddings and has a bias-free fused gate projection followed by a biased output projection and residual layer norm. The new model reuses BERT attention/weight loading and the existing embedding pooler. CPU attention previously applied signed ALiBi distance to noncausal sequences, producing cosine similarities of only 0.93–0.97 on two short texts.

Checked issue comments, issue-number PR searches and Jina-v2/CPU-ALiBi searches; no matching open PR was found. Existing CPU PRs concern GEMM tiling or Zen decoder dispatch.

GPU execution and quantization were not tested. The HF comparison runs outside CI because its remote implementation requires Transformers 4; native registration, batching and kernel regressions run in existing CI suites. AI assistance was used.
