# [ROCm] [fusion] support ROCm aiter fusion of per tensor quant + rmsnorm

[Upstream PR](https://github.com/vllm-project/vllm/pull/52831) · state: closed · merged: True

## Original PR description

## Purpose

Reland #32419 with current structure. This PR matches the abstract `torch.ops.vllm_ir.rms_norm` /
`torch.ops.vllm_ir.fused_add_rms_norm` ops introduced by the vLLM IR work.

## Testing

`tests/compile/passes/test_fusion.py`: **71 passed, 24 skipped**. The new
per-tensor parameters pass at both `eps=1e-5` and `eps=1e-6`.


### Fusion firing

Symbol counts in the compiled `rank_0_0/model` artifact,
`amd/Llama-3.3-70B-Instruct-FP8-KV` TP=8, stock vs this PR:

| symbol | stock | this PR |
|---|---:|---:|
| `rocm_aiter_fused_rms_fp8_per_tensor_static_quant` | 0 | 14 |
| `rocm_aiter_fused_add_rms_fp8_per_tensor_static_quant` | 0 | 39 |
| `rocm_aiter_per_tensor_quant_default` | 32 | 14 |

53 fused ops created; 18 of 32 standalone per-tensor quant calls consumed.


### Performance

`amd/Llama-3.1-8B-Instruct-FP8-KV`, TP=1, random 1024/128, 64 prompts,
concurrency 8. Two discarded warmup runs, then three measured runs per arm.

|---|---|---|---|
