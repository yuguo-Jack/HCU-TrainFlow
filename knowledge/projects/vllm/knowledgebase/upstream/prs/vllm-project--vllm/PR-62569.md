# [MoE] Add uniform subset MoE routing

[Upstream PR](https://github.com/vllm-project/vllm/pull/62569) · state: open · merged: False

## Original PR description

## Overview

Add `uniform_subset` to the MoE routing simulator. This mode limits random routing to a configured expert prefix.

```text
uniform_subset
  read subset_size
  validate top_k <= subset_size <= num_experts
  select top_k distinct experts from [0, subset_size)
  assign weight 1.0 to each selected expert
```

## Claims

- Adds the `uniform_subset` routing strategy.
- Adds `VLLM_MOE_ROUTING_SIMULATION_SUBSET_SIZE`.
- Selects experts uniformly without replacement from `[0, subset_size)`.
- Rejects missing or invalid subset settings.
- Keeps the default routing path unchanged.

## Details

Use the strategy with these environment variables:

```bash
export VLLM_MOE_ROUTING_SIMULATION_STRATEGY=uniform_subset
export VLLM_MOE_ROUTING_SIMULATION_SUBSET_SIZE=<N>
```

The strategy selects `top_k` distinct experts for each token. All selected experts receive weight `1.0`.

The subset is the fixed prefix `[0, N)`. The strategy does not select a random subset from all experts.

The simulator ignores learned router logits in this mode. Therefore, this mode supports performance testing only.

Simulated routing does not produce valid model output.

The implementation rejects these configurations:

- `subset_size` is missing.
- `subset_size` is less than `1`.
- `subset_size` exceeds `num_experts`.
- `top_k` exceeds `subset_size`.

**Door:** Two-way. Reverting this commit removes the new strategy.

**Blast radius:** MoE routing simulation only. The default routing path does not use this code.
