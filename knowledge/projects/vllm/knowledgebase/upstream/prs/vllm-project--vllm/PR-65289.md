# [Feature][AuxOutput] Replay ordinary raw indexer selections (rl/aux-output)

[Upstream PR](https://github.com/vllm-project/vllm/pull/65289) · state: closed · merged: True

## Original PR description

Retargets the branch behind #49555 at `rl/aux-output`.

Same commits as #49555 (head `indexer-topk`); this PR only changes the base so the RL branch can carry the AuxOutput indexer-replay work.

Note: `rl/aux-output` is currently behind `main`, so the diff includes the main updates the branch has merged since; the feature commits are the same as in #49555.

Summary of the change:
- Capture ordinary sparse-attention TopK selections through the existing AuxOutput SHM connector and return them as `int32` `[tokens, sources, topk]` rows.
- Expose them as `CompletionOutput.indexer_topk` (offline) and as a base64 `.npy` field on Python Chat/Completions and token-in/token-out responses.
- Wire the Rust token-in/token-out frontend (wire ndarray, aggregation, `/inference/v1/generate`).
- Support DeepSeek V3.2 / V4 / GLM-5.x DSA and the shared MLA reference path, with DBO-aware capture offsets.

Validated on SGP H20e: TP2/TP8 memory and KV capacity, DP2xTP2 runtime, concurrent-request isolation, Rust workspace tests (2455 passed), clippy and fmt clean.
