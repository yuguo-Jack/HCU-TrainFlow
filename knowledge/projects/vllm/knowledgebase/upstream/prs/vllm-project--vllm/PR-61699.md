# [Bugfix][Spec Decode] Honor standalone draft load config

[Upstream PR](https://github.com/vllm-project/vllm/pull/61699) · state: closed · merged: True

## Original PR description

<!-- markdownlint-disable -->

## Overview

Honor `draft_load_config` for standalone drafts on both model runners and MRV2 hidden-state extraction. These loaders previously inherited the target's load config.

## Claims

- Apply the existing `ipc_cache` disk fallback and MRV2 pipeline-safe loader fallback.

## Validation

- Focused worker suites: 19 passed after rebasing; pre-commit and diff checks passed.
- Standalone GPU validation before rebasing (GB10, Qwen3-1.7B / Qwen3-0.6B, TP=PP=DP=1): baseline IPC loading failed on both runners; fixed loading succeeded with 45/51 draft tokens accepted and all 64 output tokens matching target-only generation.
- Hidden-state loading, distributed PP, and explicit draft overrides remain unvalidated end to end. GPU validation was not repeated after rebasing.

```bash
.venv/bin/python -m pytest tests/v1/worker/test_gpu_extract_hidden_states_speculator.py tests/v1/worker/test_gpu_model_runner_v2.py -q
```

## Details

Reuse `get_draft_load_config()` and MRV2's `get_pp_safe_draft_load_config()`.

Duplicate checks found no equivalent standalone fix; Related: [#55337](https://github.com/vllm-project/vllm/pull/55337) covers EAGLE loading.
