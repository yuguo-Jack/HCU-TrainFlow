# [Bugfix][Qwen2.5-VL] Honor video fps for temporal M-RoPE

[Upstream PR](https://github.com/vllm-project/vllm/pull/47736) · state: closed · merged: True

## Original PR description

## Purpose

Qwen2.5-VL currently loses video metadata before calling the HuggingFace processor. Since the HF video processor refactor, `second_per_grid_ts` is computed from `video_metadata.sampled_fps`; when vLLM drops that metadata, pre-decoded videos fall back to a default sampled fps instead of the request/video fps. That value drives the temporal M-RoPE scale used by the model, so videos tagged at 1fps and 30fps get the same temporal spacing in vLLM.

This fixes the Qwen2.5-VL path by keeping video metadata in the data parser, splitting `(video, metadata)` tuples before the HF processor call, and forwarding `video_metadata` so HF can compute `sampled_fps` from the real frame metadata. The dummy video builder also attaches synthetic metadata, matching the Qwen3-VL pattern and keeping memory profiling inputs valid once metadata is required.

Scope: the Qwen2.5-VL processor path. Qwen2-VL does not capture `second_per_grid_ts` in the same way, so that would be a separate change. vLLM's video loader already attaches metadata for URL/file inputs; the changed behavior is that bare pre-decoded video arrays without metadata now fail clearly instead of silently using a fallback fps.

Duplicate-work check: I did not find an open PR covering Qwen2.5-VL video metadata forwarding. PR #23058 is Qwen2.5-Omni only, PR #43198 only lets video frame sampling use a request `fps` override, PR #45555 only adds loader-side metadata that this path still dropped, and PR #47407 only bounds M-RoPE positions.

## Test Plan

Run a real `Qwen/Qwen2.5-VL-3B-Instruct` `LLM.generate` path on an RTX 4090, instrument the live model's `iter_mm_grid_thw`, and compare the temporal `t_factor` for the same video tagged as fps=1.0 and fps=30.0 before, after, and after reverting the fix. Add one CPU regression case to the existing Qwen2-VL processor test file to assert `second_per_grid_ts` tracks fps, run affected Qwen2.5-VL video tests, and run ruff on all changed files.

`qwen25vl_fps_e2e.py`

```python
import os
import subprocess

import numpy as np

os.environ.setdefault("VLLM_USE_FLASHINFER_SAMPLER", "0")
os.environ.setdefault("VLLM_ENABLE_V1_MULTIPROCESSING", "0")

import vllm
import vllm.model_executor.models.qwen2_5_vl as q25


def git_head():
    try:
        return subprocess.check_output(
            ["git", "rev-parse", "HEAD"], text=True
        ).strip()
    except Exception:
        return "unknown"


print(f"git_head={git_head()}")
print(f"vllm_import={vllm.__file__}")

captured = []
orig_iter = q25.Qwen2_5_VLForConditionalGeneration.iter_mm_grid_thw


def patched_iter(self, mm_features):
    for item in orig_iter(self, mm_features):
        captured.append(float(item[4]))
        yield item


q25.Qwen2_5_VLForConditionalGeneration.iter_mm_grid_thw = patched_iter

from vllm import LLM, SamplingParams

MODEL = os.environ.get("MODEL", "Qwen/Qwen2.5-VL-3B-Instruct")

num_frames = 64
video = np.zeros((num_frames, 56, 56, 3), dtype=np.uint8)
for frame_idx in range(num_frames):
    video[frame_idx, :, :, 0] = (frame_idx * 5) % 256

prompt = (
    "<|im_start|>user\n"
    "<|vision_start|><|video_pad|><|vision_end|>"
    "Describe the video.<|im_end|>\n"
    "<|im_start|>assistant\n"
)
llm = LLM(
    model=MODEL,
    max_model_len=8192,
    limit_mm_per_prompt={"video": 1, "image": 0},
    gpu_memory_utilization=0.55,
    enforce_eager=True,
    trust_remote_code=True,
)


def metadata(fps):
    return {
        "fps": fps,
        "duration": num_frames / fps,
        "total_num_frames": num_frames,
        "frames_indices": list(range(num_frames)),
        "video_backend": "opencv",
        "do_sample_frames": False,
    }


results = {}
for fps in (1.0, 30.0):
    captured.clear()
    llm.generate(
        {
            "prompt": prompt,
            "multi_modal_data": {"video": [(video, metadata(fps))]},
        },
        SamplingParams(max_tokens=4, temperature=0.0),
    )
    results[fps] = list(captured)
    print(f"input_fps={fps} captured_t_factors={captured}")

fps_ignored = results[1.0] == results[30.0] and bool(results[1.0])
t1 = results.get(1.0, [None])[0]
t30 = results.get(30.0, [None])[0]
print(f"t_factor(fps=1)={t1}  t_factor(fps=30)={t30}")
print(f"FPS_IGNORED_E2E={fps_ignored}")
print("expected_if_honored: fps=1 -> t_factor~4.0 ; fps=30 -> t_factor~0.13")
```
