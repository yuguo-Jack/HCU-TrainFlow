## Overview

- For quantization like FP8 and FP4 etc, we need to do some scales weights transform in `load_weights`, which cause `load_weights` logic quite messy and difficult to read.
- This PR try to make `WeightsMapper` to do weights transform as well, so that we can keep them clean.
