# [Perf][MRV2] Compute text-only M-RoPE positions on the GPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/63209) · state: open · merged: False

## Original PR description



## Overview

M-RoPE models such as Qwen3.5 build and stage a per-request `[num_dims, prompt_len]` position table on the host in Model Runner V2, even for text-only requests, which have the same plain positions in every channel. This lets opted-in models compute those positions in the existing position kernel instead.

## Claims

- New `SupportsMRoPE.supports_linear_text_mrope` flag: the model declares that `get_mrope_input_positions` returns sequential positions with no position delta when there are no multimodal features. Qwen3.5 opts in.
- Without multimodal ingress (`ModelConfig.supports_multimodal_inputs` is false), the runner allocates no staged prefill-position buffer and skips the host position table for every request.
- With multimodal ingress, text-only requests skip the host table via a per-request flag; multimodal requests (including EVS pruning) keep the staged path.
- Positions are bit-identical; default behaviour, no new option. Models without the flag are unchanged.

## Validation

Not run yet. Planned:

```bash
pytest -v tests/v1/worker/test_mrope_rope_state.py tests/v1/worker/test_gpu_row_offsets_i64.py::test_rope_positions_high_row
```

plus a GSM8K check and a serving benchmark on a Qwen3.5/3.6 model, text-only and with multimodal ingress.

## Details

The kernel gains constexpr modes, so models without the flag compile the same kernel as before. A request with multimodal features in a deployment without multimodal ingress raises instead of getting wrong positions. Tests compare the computed and staged positions over chunked prefill, the prefill tail and multi-token decode, with mixed text-only/multimodal batches.

Open #62732 changes the same code (`RopeState.stage_prefill_positions`, and `DefaultModelState.add_request` skipping `init_prefill_positions` for remote-prefill position state). Whichever lands second must clear `text_only` in every staging path and must not touch `prefill_delta` in linear mode. No other open PR covers this.
