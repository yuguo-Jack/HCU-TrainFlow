# [Bugfix][Perf] Exclude draft-only buckets from min_num_layers in KV cache grouping

[Upstream PR](https://github.com/vllm-project/vllm/pull/65490) · state: open · merged: False

## Original PR description

## Overview
When `_get_kv_cache_groups_uniform_page_size` groups KV cache specs by `(is_draft, type_id, page_size_bytes)`, it previously computed `min_num_layers` across **all** buckets—including draft-only buckets (`spec.is_draft=True`). When a hybrid target model (such as `Qwen3_5ForConditionalGeneration` / Qwen3.5-4B with 24 Mamba GDN layers and 8 FullAttention layers) is paired with a speculative decoding drafter whose attention bucket has only 1 layer (e.g., a 6-layer hybrid DFlash drafter with 5 Mamba layers + 1 FullAttention layer, or a 1-layer EAGLE/EAGLE3 drafter), the 1-layer draft bucket causes `min_num_layers` to collapse to `1`.

As a result, `_get_kv_cache_groups_uniform_page_size` splits every target bucket into 1-layer KV cache groups (`[1] * 38` = 38 KV cache groups instead of `6` groups of `[8, 8, 8, 8, 5, 1]`), inflating per-step KV cache coordinator/manager iteration, block-table slicing, and attention metadata construction across 38 groups on every prefill and decode step.

This PR computes `min_num_layers` and `max_num_layers` over **target-model buckets** (`not all(spec.is_draft for spec in specs)`) when any non-draft bucket is present, and suppresses the false-positive layer-padding warning for draft-only buckets that have fewer layers than `min_num_layers`.

## Claims
- Reduces KV cache group count on hybrid target + draft models (`Qwen3.5-4B` + `z-lab/Qwen3.5-4B-DFlash`) from **38 groups (`[1]*38`) to 6 groups (`[8, 8, 8, 8, 5, 1]`)**.
- On NVIDIA H100 NVL (512-query production JSON benchmark, $k=8$, concurrency 1), reduces **p95 E2E latency by 31.44 ms (`440.17 ms -> 408.73 ms`, -7.1%)** and **mean TTFT by 13.57 ms (`84.50 ms -> 70.93 ms`, -16.1%)**.

## Validation

### 2. Unit Tests
```bash

```
- Added `test_uniform_page_size_groups_ignore_draft_bucket_size` verifying both a hybrid target + hybrid DFlash drafter (`24 Mamba + 8 FullAttention` target + `5 Mamba + 1 FullAttention` draft -> `6` groups of sizes `[8, 8, 8, 8, 5, 1]`) and a hybrid target + 1-layer EAGLE attention drafter (`5` groups of sizes `[8, 8, 8, 8, 1]`).

## Details
- In `_get_kv_cache_groups_uniform_page_size` (`vllm/v1/core/kv_cache_planning.py`):
  - Separate `target_bucket_sizes` (`not all(spec.is_draft for spec in specs)`) from draft-only buckets.
  - Compute `min_num_layers` and `max_num_layers` from `target_bucket_sizes` when non-empty (falling back to all buckets if all specs are draft).
  - Skip the `is_kv_cache_page_size_uniform` padding warning for draft-only buckets whose layer count is smaller than `min_num_layers`, since draft KV cache groups are indexed only by draft layers and never require dummy layer padding on the target model.
