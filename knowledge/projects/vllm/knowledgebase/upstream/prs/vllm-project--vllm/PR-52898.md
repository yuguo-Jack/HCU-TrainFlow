# [Docs] Clarify Mamba cache mode comments in hybrid block-size alignment

[Upstream PR](https://github.com/vllm-project/vllm/pull/52898) · state: closed · merged: False

## Original PR description

## Purpose

Clarify the comments in `Platform._align_hybrid_block_size()` so they describe
the actual `mamba_cache_mode` branches.

The existing comments describe the `"all"` branch as using prefix caching and
the `else` branch as not using prefix caching. This is misleading because
`mamba_cache_mode="align"` also operates with prefix caching enabled.

The updated comments distinguish:

- `"all"` mode
- `"none"` and `"align"` modes

This is a comment-only change and does not modify runtime behavior.

Closes #52895.

## Duplicate-work check

I searched existing issues and open PRs for the affected comments and Mamba
cache-mode terminology. I did not find an existing PR that updates these
comments.

Related PR #46778 documents Mamba/hybrid prefix caching more broadly, but it
does not modify the comments in `vllm/platforms/interface.py`.
