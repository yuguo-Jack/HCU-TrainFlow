# [Perf] Skip the M-RoPE warmup when every holder of the RoPE fuses it

[Upstream PR](https://github.com/vllm-project/vllm/pull/60246) · state: closed · merged: True

## Original PR description



## Overview

The Qwen-VL Triton warmup calls the model's first `MRotaryEmbedding` with the attention's head counts so `triton_mrope` is compiled for the shape `MRotaryEmbedding.forward` gets. Attention with `use_fused_qk_norm_rope_gate` never calls `forward`: `fused_qk_rmsnorm_rope_gate` reads `rotary_emb.cos_sin_cache` directly. When that attention is the only holder of the rope, the warmup compiles a specialization nothing launches. It is now skipped in that case.

## Claims

- The M-RoPE warmup and its `Warmed M-RoPE Triton kernels.` log are skipped only when every module holding the rope as a child sets `use_fused_qk_norm_rope_gate` (Qwen3-Next-style attention on CUDA with the output gate, NeoX RoPE and a half dtype).
- Any other holder keeps the warmup. Qwen4Exp keeps it, because its QSA indexer holds the same rope and is not fused.

## Validation

On main (`6ad2e06c4a`) with this commit:

```text
pytest -q tests/model_executor/test_qwen_vl_triton_warmup.py
5 passed
```

`test_mrope_warmup_launches_triton_shapes` is parametrized over the holders of the rope: the model itself without the flag (the existing case), one fused holder, and a fused plus a non-fused holder. The fused-only case skips the warmup and the other two launch all three shapes. Checking the flag with `any(...)` fails the mixed case, and dropping the early return fails the fused-only case.

## Details

The warmup came with #54797. `triton_mrope` takes the head counts and `head_dim` as constexprs, so the warmup's specialization only helps a caller of `MRotaryEmbedding.forward` with the attention's shapes. The check looks at the modules that hold the rope instead of any module in the model, so an unrelated fused module cannot turn the warmup off.

No open PR addresses this: searches for the M-RoPE warmup return the PR that added it and unrelated RoPE fusion work.
