## Original PR description



## Overview

Fix gate/up LoRA delta placement for GPT-OSS when `enable_mixed_moe_lora_format=True`.

## Claims

- Map separate gate/up deltas onto the interleaved output channels expected by `SWIGLUOAI`.
- Add a standalone GPT-OSS mixed-format regression test.

## Validation

Validated using a test code based on `tests/lora/test_gptoss_tp.py`, with the same prompt, adapter, and expected output. With `enable_mixed_moe_lora_format=True`, the expected-prefix assertion fails before the fix and passes afterward.

Before: SELECT AVG(Working_Horses) FROM farm WHERE Total_Horses > 5000;
After:  SELECT avg(Working_Horses) FROM farm WHERE Total_Horses  >  5000
