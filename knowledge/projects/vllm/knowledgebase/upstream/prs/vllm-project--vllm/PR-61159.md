# [Model] Add TeleOCR support

[Upstream PR](https://github.com/vllm-project/vllm/pull/61159) · state: open · merged: False

## Original PR description



## Overview

Add built-in support for [TeleOCR](https://github.com/caipeng328/TeleOCR), using the existing Qwen2.5-VL vision stack and a Qwen3 text decoder.

## Claims

- Register `TeleOCRForConditionalGeneration` without replacing the Qwen2.5-VL architecture globally.
- Initialize Qwen3 with `hf_text_config`, including its head dimension and Q/K normalization, while retaining the existing multimodal processor and weight-loading path.
- Add an example to the model initialization test registry and document the required architecture override. The official model-specific plugin is not needed.

## Validation

All applicable staged-file pre-commit hooks passed during `git commit`, including mypy, Ruff, SPDX, Markdown, and test-tethering checks. `git diff --check 3fe917abb13160d60bea5330399f5c09ca282348 HEAD` passed. The squash retains the exact previously validated code tree.

```bash
vllm serve /task/models/TeleOCR --host 127.0.0.1 --port 18193 \
  --served-model-name TeleOCR --trust-remote-code --enforce-eager \
  --max-model-len 4096 --gpu-memory-utilization 0.3 \
  --hf-overrides '{"architectures":["TeleOCRForConditionalGeneration"]}'
```

## Details

The published checkpoint advertises Qwen2.5-VL, but its text decoder is Qwen3. Selecting the ordinary Qwen2 decoder therefore gives the wrong attention implementation. Passing the outer multimodal config to Qwen3 also fails because text attributes such as `vocab_size` are nested. A protected decoder-construction hook lets TeleOCR select Qwen3 with the text sub-configuration and reuse the vision implementation. The default Qwen2.5-VL construction is preserved.

Before submission, searches for TeleOCR, NaviDC, and NaviOCR found no existing matching PR. This adds a dedicated built-in architecture instead of the official external vLLM 0.11 plugin's global replacement. AI assistance was used to implement, validate, and prepare this contribution.
