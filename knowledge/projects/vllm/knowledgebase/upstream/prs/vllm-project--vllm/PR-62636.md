# [Bugfix][Model][Quantization][qwen3_5] Pass quant config to Qwen3.5 embeddings

[Upstream PR](https://github.com/vllm-project/vllm/pull/62636) · state: open · merged: False

## Original PR description

## Overview

Pass `quant_config` and `prefix` to the Qwen3.5 embedding layer, based on the [[original patch script](https://huggingface.co/ISTA-DASLab/Qwen3.8-27B-3Bit-GSQ/blob/main/patch_vllm_qwen35_embedding.py)](https://huggingface.co/ISTA-DASLab/Qwen3.8-27B-3Bit-GSQ/blob/main/patch_vllm_qwen35_embedding.py). Once merged, this fix will eliminate the need to manually patch vLLM to run the GSQ-quantized Qwen3.8-27B model.

## Validation

Successfully ran the GSQ-quantized Qwen3.8-27B model in Docker using vLLM v0.30.0 with the patch applied. Not yet tested on upstream `main`.
