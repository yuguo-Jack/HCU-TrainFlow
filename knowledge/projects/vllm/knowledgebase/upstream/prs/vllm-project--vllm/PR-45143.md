## Purpose

benchmark_serving_multi_turn.py logs raw parsed arguments namespace directly using logger.info(args)

when running benchmark_serving_multi_turn.py with authentication parameters like  --api-key  and  --header .
 Logs expose plaintext credentials like  api_key='sk-xxx'  and  header=[('X-Custom-Token', 'secret-value')] , risking credential leaks in shared logs, CI artifacts, or monitoring
 
Logger should record non-sensitive runtime parameters while hiding keys and custom header values.
