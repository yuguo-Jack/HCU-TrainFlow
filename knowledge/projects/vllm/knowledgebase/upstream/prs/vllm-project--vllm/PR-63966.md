# [Perf][Quantization] Prefer Humming over Marlin for int4 g128 on SM100

[Upstream PR](https://github.com/vllm-project/vllm/pull/63966) · state: closed · merged: False

## Original PR description

## Summary

On SM100 (Blackwell/B200), prefer **Humming kernel** over **Marlin** for dense int4 symmetric group-128 weights. This extends the previous work from PR #56997 (SM90/H100) to SM100.

## Changes

- Modified  in  to include compute capability 100 (SM100/Blackwell) alongside 90 (SM90/H100).

## Performance Claims (B200, Qwen3.8-27B-INT4)

- **3.1x faster 4k prefill** (555.5ms → 179.6ms)
- **TTFT 2.6-3.6x lower** across concurrency levels 1/8/32
- **Decode TPOT unchanged** (flat)

## Testing

-  -> 27 passed, 1 skipped
-  -> Using HummingLinearKernel
-  -> Using MarlinLinearKernel (group-32 and zero-point weights keep Marlin as Humming is 5-6% slower at decode)
