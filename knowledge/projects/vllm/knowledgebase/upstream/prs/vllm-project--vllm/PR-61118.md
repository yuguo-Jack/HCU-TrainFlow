# [Bugfix] Disable sequence-parallel MoE under batch invariance

[Upstream PR](https://github.com/vllm-project/vllm/pull/61118) · state: open · merged: False

## Original PR description

## Purpose

With `VLLM_BATCH_INVARIANT=1`, MoE models served with data parallelism, tensor parallelism and expert parallelism at the same time (DP > 1 and TP > 1 with `--enable-expert-parallel`) are not batch invariant: the logprobs of a request change with the other requests in the batch, already in the prefill step, and sampled tokens diverge. The same models pass as TP=4, as DP=4 x TP=1 with expert parallelism, as TP=2 with expert parallelism, and as DP=2 x TP=2 without expert parallelism.

The difference is the MoE input layout. For DP > 1, TP > 1 and EP, `ParallelConfig.use_sequence_parallel_moe` is true and the models feed the experts sequence-parallel inputs: each DP replica's tokens are split across its TP ranks (`sequence_parallel_chunk`, with padding to a multiple of TP) before the all-gather dispatch over the EP group, and the combined expert outputs are re-assembled with a TP all-gather (for example `vllm/model_executor/models/qwen3_moe.py`, `Qwen3MoeSparseMoeBlock.forward`). On that path the result for a token depends on the other tokens in its replica. Both the NVFP4 (Humming) and the W4A16 (Triton) MoE experts fail on it and both pass on the other layouts, so it is the dispatch path, not an expert kernel. The non-sequence-parallel path (all-gather across the DP group, experts, reduce-scatter, TP all-reduce of the expert outputs) is batch invariant.

This PR keeps the non-sequence-parallel path in batch-invariant mode for the `allgather_reducescatter` all2all backend, the only backend that has such a fallback (the DeepEP / MoRI / NIXL backends require sequence-parallel inputs and are left unchanged), and logs the switch the same way the existing override of `pass_config.enable_sp` / `fuse_gemm_comms` under batch invariance does (`vllm/config/vllm.py`, see #56370). Nothing changes when `VLLM_BATCH_INVARIANT` is unset. Making the sequence-parallel path itself batch invariant would be the better long-term fix, as the existing TODO for the compiler pass already says.

## Test Plan

- Online bitwise check (32 prompts, `temperature=0.6`, fixed seed, `max_tokens=8`, each prompt alone (bs=1) vs all 32 batched, per-step top logprobs compared bitwise; "ragged" uses 1024-2048-word prompts), server started with `VLLM_BATCH_INVARIANT=1`, 4x GB300 (SM103), `main` at `d09ff77637`:
  - `nvidia/Qwen3-30B-A3B-FP4` (ModelOpt NVFP4, HUMMING NvFp4 MoE backend when EP is on): DP=2 x TP=2 + EP on `main` (twice) and on `main` + this PR; regression runs DP=4 x TP=1 + EP and TP=4 on `main` + this PR.
  - `RedHatAI/Qwen3-30B-A3B-Instruct-2507-quantized.w4a16` (Triton W4A16 MoE): DP=2 x TP=2 + EP before and after, on a `main` tree that also carries the pending #61038 fix for that MoE path (the W4A16 legacy MoE dispatch is batch dependent on `main` by itself).
  - Isolation runs on `main` / the same tree without this PR: DP=2 x TP=2 without EP, DP=2 x TP=2 + EP with `--disable-custom-all-reduce`, TP=2 + EP without DP.
- Unit test: `tests/config/test_parallel_config.py` (new) for the three `ParallelConfig` properties.

"""Batch-invariance check against a running OpenAI-compatible vLLM server.

Mirrors tests/v1/determinism/test_online_batch_invariance.py: N random prompts,
BS=1 (one request per prompt, sequential) versus one batched request with all
prompts; sampled tokens and per-step logprobs must match bitwise.
"""
import argparse
import json
import random
import sys
import time

import openai


PROMPT_TEMPLATES = [
    "Question: What is the capital of France?\nAnswer: The capital of France is",
    "Q: How does photosynthesis work?\nA: Photosynthesis is the process by which",
    "User: Can you explain quantum mechanics?\nAssistant: Quantum mechanics is",
    "Once upon a time in a distant galaxy, there lived",
    "The old man walked slowly down the street, remembering",
    "In the year 2157, humanity finally discovered",
    "To implement a binary search tree in Python, first we need to",
    "The algorithm works by iterating through the array and",
    "Here's how to optimize database queries using indexing:",
    "The Renaissance was a period in European history that",
    "Climate change is caused by several factors including",
    "The human brain contains approximately 86 billion neurons which",
    "I've been thinking about getting a new laptop because",
    "Yesterday I went to the store and bought",
    "My favorite thing about summer is definitely",
]


def _random_prompt(min_words: int = 1024, max_words: int = 1024 * 2) -> str:
    """Copy of tests/v1/determinism/utils.py::_random_prompt (same templates, padding and RNG use)."""
    base_prompt = random.choice(PROMPT_TEMPLATES)
    if max_words < min_words:
        max_words = min_words
    target_words = random.randint(min_words, max_words)
    if target_words > 50:
        padding_text = " This is an interesting topic that deserves more explanation. " * (target_words // 50)
        base_prompt = padding_text + base_prompt
    return base_prompt



def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--base-url", required=True)
    ap.add_argument("--model", required=True)
    ap.add_argument("--tests-dir", default=None, help="unused; kept for the caller")
    ap.add_argument("--num-prompts", type=int, default=32)
    ap.add_argument("--max-tokens", type=int, default=8)
    ap.add_argument("--min-words", type=int, default=10)
    ap.add_argument("--max-words", type=int, default=50)
    ap.add_argument("--seed", type=int, default=12345)
    ap.add_argument("--temperature", type=float, default=0.6)
    ap.add_argument("--ragged", action="store_true", help="every other prompt is 1024-2048 words")
    a = ap.parse_args()

    random.seed(a.seed)
    if a.ragged:
        prompts = [
            _random_prompt(a.min_words, a.max_words) if i % 2 == 0 else _random_prompt(1024, 2048)
            for i in range(a.num_prompts)
        ]
    else:
        prompts = [_random_prompt(a.min_words, a.max_words) for _ in range(a.num_prompts)]
    sp = dict(temperature=a.temperature, top_p=1.0, max_tokens=a.max_tokens, seed=42, logprobs=5)
    client = openai.OpenAI(base_url=a.base_url, api_key="EMPTY", timeout=1800)

    def req(prompt):
        for attempt in range(4):
            try:
                return client.completions.create(model=a.model, prompt=prompt, **sp).model_dump()
            except Exception:
                if attempt == 3:
                    raise
                time.sleep(0.5 * 2**attempt)

    def extract(choice):
        lp = choice.get("logprobs") or {}
        return list(lp.get("token_ids") or lp.get("tokens") or []), lp.get("token_logprobs")

    t0 = time.time()
    bs1 = [extract(req(p)["choices"][0]) for p in prompts]
    t1 = time.time()
    choices = req(prompts)["choices"]
    assert len(choices) == len(prompts), f"BS=N choices {len(choices)} != {len(prompts)}"
    bsn = [extract(c) for c in choices]
    t2 = time.time()

    mismatches = []
    for i, ((ta, la), (tb, lb)) in enumerate(zip(bs1, bsn)):
        if la is None or lb is None:
            mismatches.append((i, "missing logprobs"))
        elif ta != tb:
            mismatches.append((i, f"tokens differ: {ta} vs {tb}"))
        elif len(la) != len(lb):
            mismatches.append((i, f"steps {len(la)} vs {len(lb)}"))
        else:
            for t, (x, y) in enumerate(zip(la, lb)):
                if x != y:
                    mismatches.append((i, f"step {t} logprob {x!r} vs {y!r} (abs diff {abs(x - y):.3e})"))
                    break
    print(json.dumps({
        "model": a.model, "num_prompts": len(prompts), "max_tokens": a.max_tokens, "ragged": a.ragged,
        "bs1_seconds": round(t1 - t0, 1), "bsN_seconds": round(t2 - t1, 1), "mismatches": len(mismatches),
    }))
    for i, m in mismatches:
        print(f"MISMATCH prompt {i}: {m}")
    if mismatches:
        print(f"BATCH_INVARIANCE_VIOLATED {len(mismatches)}/{len(prompts)} prompts")
        sys.exit(1)
    print(f"BATCH_INVARIANCE_OK {len(prompts)}/{len(prompts)} prompts")


main()
