## Purpose

  ## Summary

  This PR adds vLLM transcription support for NVIDIA Parakeet TDT
  (`nvidia/parakeet-tdt-0.6b-v3`).

  Parakeet TDT is different from Whisper-like encoder-decoder ASR models. It is a
  TDT/RNNT-style ASR model: the audio encoder output is decoded by Parakeet’s
  prediction decoder + joint network over encoder frames and duration symbols. It
  does not naturally fit vLLM’s normal autoregressive “call decoder once per next
  token” contract.

  To integrate it with vLLM’s generation loop, this PR precomputes the full greedy
  TDT transcript sequence from each encoder output, stores that sequence by request
  ID, and then returns forced logits for the already-decoded token at each vLLM
  decode step. This keeps vLLM’s scheduler, sampler, streaming, and OpenAI
  transcription APIs in the normal path while adapting Parakeet’s non-standard
  decoder behavior.

  ### Key implementation details:

  - Adds Parakeet TDT model/config/processor support.
  - Uses audio encoder outputs to greedily decode the full Parakeet token sequence
    once per request.
  - Stores precomputed token sequences in request-keyed model state.
  - During decode, emits logits that force the token matching the request ID and
    decode position.
  - Adds model-level transcription stop-token handling because the HF tokenizer
    metadata does not expose Parakeet’s semantic EOS as a normal tokenizer
    `eos_token` / special token.
  - Strips Parakeet special markers such as `<blank>` and `<|endoftext|>` from both
    non-streaming and streaming transcription outputs.
  - Enforces eager execution for Parakeet through a model-specific config hook.
    This avoids CUDA graph replay reusing stale request-keyed forced-token state.

  ### Difference from other ASR models

  Whisper-like ASR models use a decoder that naturally generates token-by-token
  from decoder inputs, and tokenizer EOS handling is usually available through the
  standard tokenizer configuration.

  Parakeet TDT instead produces its transcript through TDT/RNNT greedy decoding
  over encoder frames. The whole output sequence is known after running that
  decoder, and vLLM’s decode loop is used to expose those tokens through the
  standard transcription/generation machinery.

  Because this integration replays a precomputed greedy sequence, Parakeet in vLLM
  does not implement beam search or arbitrary sampling behavior.

import asyncio, time, os
from openai import AsyncOpenAI
from vllm.assets.audio import AudioAsset

model = os.environ["PARAKEET_TEST_MODEL"]
audio_path = str(AudioAsset("mary_had_lamb").get_local_path())
client = AsyncOpenAI(base_url="http://localhost:8766/v1", api_key="x")

async def one(i):
  with open(audio_path, "rb") as f:
      r = await client.audio.transcriptions.create(
          file=f, model=model, language="en",
          response_format="json", temperature=0.0,
      )
  return i, r.text

async def main():
  N = 8
  t0 = time.time()
  results = await asyncio.gather(*[one(i) for i in range(N)])
  ok = sum("Mary had a little lamb" in t and "<|endoftext|>" not in t for _, t in results)
  for i, t in results:
      print(f"[req {i}] {t[:60]!r}")
  print(f"\n{ok}/{N} correct in {time.time()-t0:.1f}s")
  assert ok == N, "concurrent transcriptions corrupted each other"
  print("V2 CONCURRENCY PASS")

asyncio.run(main())

The `greedy_decode` implementation has two significant issues:

1. **Performance**: It calls `self.encoder_projector` (a linear layer) inside a nested loop for every encoder frame. This results in thousands of small kernel launches, which is extremely inefficient. The entire `encoder_output` should be pre-projected once before entering the loop.
2. **Correctness**: There is a bug in the `time_idx` increment logic. If `symbols_added` reaches `max_symbols_per_step` and the last predicted `skip` was greater than 0, `time_idx` is incremented twice (once by `skip` and once by the safety increment at the end of the outer loop). This will cause the decoder to skip frames incorrectly. The safety increment should only occur if `need_loop` is still `True` (meaning the last `skip` was 0).

```python
    def _joint_logits(
        self,
        encoder_state: torch.Tensor,
        decoder_state: torch.Tensor,
    ) -> torch.Tensor:
        return self.joint(encoder_state, decoder_state)

    @torch.inference_mode()
    def greedy_decode(self, encoder_output: torch.Tensor) -> list[int]:
        cfg = self.config
        device = encoder_output.device
        token_ids: list[int] = []
        state: tuple[torch.Tensor, torch.Tensor] | None = None
        last_token: int | None = None

        # Pre-project encoder outputs to avoid redundant linear layer calls in the loop
        encoder_projected = self.encoder_projector(encoder_output)

        time_idx = 0
        out_len = int(encoder_output.shape[0])
        while time_idx < out_len:
            encoder_frame_projected = encoder_projected[time_idx : time_idx + 1]
            symbols_added = 0
            need_loop = True
            skip = 1

            while need_loop and symbols_added < cfg.max_symbols_per_step:
                label = cfg.blank_token_id if last_token is None else last_token
                pred_state, next_state = self.decoder.predict(label, state, device)
                logits = self._joint_logits(encoder_frame_projected, pred_state)[0]

                token_logits = logits[: cfg.vocab_size].float()
                duration_logits = logits[cfg.vocab_size :].float()
                score, token = token_logits.max(0)
                del score

                duration_idx = int(duration_logits.argmax().item())
                skip = cfg.durations[duration_idx]
                token_id = int(token.item())
                if token_id == cfg.blank_token_id and skip == 0:
                    skip = 1

                if token_id != cfg.blank_token_id:
                    token_ids.append(token_id)
                    state = next_state
                    last_token = token_id

                symbols_added += 1
                time_idx += skip
                need_loop = skip == 0

            if need_loop:
                time_idx += 1

        token_ids.append(cfg.eos_token_id)
        return token_ids
```
