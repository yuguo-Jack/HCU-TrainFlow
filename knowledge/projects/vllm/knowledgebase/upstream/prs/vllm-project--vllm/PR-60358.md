## Original PR description



## Overview

Enable HiSparse on ROCm/gfx950, extending #57602 with HIP host-memory registration, sparse MLA execution, and ROCm regression coverage.

## Claims

- Add BF16/FP8 sparse MLA support, shared TP host pools, and MTP/graph-path support on ROCm
- Reduce temporary residency-lookup allocations and batch clean-page release
- Fix host-memory ownership and shutdown cleanup handling
- Add regression coverage and wire relevant tests into ROCm Buildkite jobs

## Details

The implementation adapts wave64 kernels, registered host-memory views, graph-stable buffers, and bounded fused mirroring for ROCm. Residency lookup avoids expanding entire resident-table rows; larger union-resolution workloads use device-global scratch when needed.
