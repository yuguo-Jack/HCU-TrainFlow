# [MM] Mistral vision Encoder CG support 

[Upstream PR](https://github.com/vllm-project/vllm/pull/56277) · state: closed · merged: True

## Original PR description

Enable encoder CUDA Graphs for Mistral multimodal models using the Pixtral vision encoder, covering both `PixtralForConditionalGeneration` and `Mistral3ForConditionalGeneration`

The implementation packs variable-resolution image patches into fixed-capacity graph buffers and precomputes attention metadata, rotary embeddings, and patch-merger indices. Unsupported attention configurations fall back to eager execution.
It also keeps `max_seqlen` on CPU because attention backends call `.item()` on it during capture.

## Relation to existing work

PR #54214 independently implements the native Pixtral path and overlaps part of this change.

This implementation additionally covers `Mistral3ForConditionalGeneration` path, validates actual serving on Mistral Large 3 NVFP4 with TP=4, supports the relevant FlashAttention, FlashInfer, Triton, and ROCm AITER metadata paths, and includes reproducible profiling and performance scripts.

Still adding @jzakrzew as co-author as their PR has some nice capacity-aware padding and work looks solid :)
