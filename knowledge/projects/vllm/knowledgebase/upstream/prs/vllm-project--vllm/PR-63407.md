## Original PR description

## Overview

Update the B300 NVFP4 AgentX section of `recipes/models/MiniMaxAI/MiniMax-M3.yaml` to the latest [SemiAnalysisAI/InferenceX#4357](https://github.com/SemiAnalysisAI/InferenceX/pull/4357) configuration (key `minimaxm3-fp4-b300-vllm-agentic-mtp`), following #63395.

## Claims

- Image is now `vllm/vllm-openai:nightly-49cb2bbf71cfd36ee5aa33d1e184b1cddff55294@sha256:8c1434bfee7d7626eef78ef70600434ffba4a1b8813cb1d1c8707ad25f47035e`; the builder's B300 `docker_image` is updated to match.
- Points are TP8 at 1 client, TP4 at 20 and 24 clients, and TP2 at 24 and 28 clients with SimpleCPUOffload (749 GB). The TP4 1-client and TP4 36/40-client points are removed.
- The per-point table gains a `--gpu-memory-utilization` column (0.95, and 0.92 for TP2), and the `--max-num-seqs`, `--max-num-active-seqs`, all-reduce backend and CUDA graph size lists follow the new points. The TP2 points use `minimax_m3_msa_decode_backend: cutlass`.
- The vLLM version string for the previous image is removed.

## Not a duplicate

No open PR touches this section; this follows the merged #63395.
