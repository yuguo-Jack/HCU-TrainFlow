# What does this PR do?
**PR 2 of 4** re-slicing #7239 (after #7380, now merged). It moves the SSM code into `megatron/core/ops/ssm`: shared helpers (`causal_conv1d_cp`, packing, checkpointing, inference mixin), Mamba2 (mixer, context parallel, SSD kernels), GDN/GDN2, GDP and the chunkwise-CP adapters. Every old module path remains as a deprecated forwarder.

The branch is **generated from current `main`** by a script rather than rebased, and is regenerated whenever `main` changes the moved files: a conflict resolution that keeps the forwarder side would silently drop those changes. The latest regeneration (on `a71470918`) picks up #8529 (the FP32 beta sigmoid in the GDP mixer, now in `gdp/mixer.py`; its new test imports the canonical path), #8172 (`gdp/decode_prepare.py` became `gdp/prepare.py`, with a new `gdp_prefill_prepare`), #8221 (`mamba2/batch_invariant_decode_rows.py`) and the other SSM changes since. The script output is the move; re-running it on `main` reproduces this diff apart from the manual steps listed below.

Two commits:

1. **`ops: write patches through deprecated forwarders and forward re-exported names`** (helper change, reviewable on its own)
   - Before this, `mock.patch("old.path.name")` or `monkeypatch.setattr` on a forwarder only shadowed the name on the forwarder; the implementation kept the original. Forwarders now send writes to the module the name is read from, and record the value each write replaced: deleting the name, which is how `mock.patch` and (on pytest 9.2+) `monkeypatch.undo` remove a patch, restores it, so nested patches unwind in order. A forwarder with several targets refuses writes rather than guessing.
   - `deprecated_module(..., exports={name: defining_module})` serves the names a historical package re-exported, so canonical packages do not have to keep that surface.
   - Megatron's two by-name spec loaders read `vars(module)`, which skips a forwarder's `__getattr__`: `spec_utils.import_module` (used for `--spec` and for `(module, name)` `ModuleSpec`s) and the inference-counterpart lookup in `megatron/training/argument_utils.py`. Both now fall back to `getattr`/`dir`, so a spec recorded under an old path keeps loading after a move. Checkpoints record their `--spec`, and `--use-checkpoint-args` replays it. On normal modules the inference lookup returns the same spec as before for all 13 stack specs in `hybrid_layer_specs`.
   - Tests: synthetic write-through (including nested patches and delete-to-undo), exports and spec-loading tests, an `EXPORTS` table whose entries must name modules that exist, a check that canonical `ops` package `__init__` files re-export nothing, and string constants (patch targets, module names) in the canonical-path check.
2. **`ops/ssm: move ...`** (the generated move)
   - The 45 moved modules change only in import lines; 28 are byte-identical. Relative imports that still resolve are kept.
   - Canonical package `__init__` files hold only their docstrings. The historical package-level names of `megatron.core.ssm.ops`, `megatron.core.ssm.ops.gdp` and `megatron.core.ssm.gated_delta_net` (including `HAVE_TE_GDN` and `gdp_prefill_prepare`, added on `main` since the first version, and the `None` fallback of the two optional `ssm.ops` entry points) live on those forwarders. In-tree code imports each name from its defining module.
   - Updated for the new paths: determinism kernel manifest and `test_manifest.py`, `tools/process_group_usage_allowlist.json`, `CODEOWNERS` (`megatron/core/ops/ssm/` keeps `@NVIDIA/hybrid-model`, and the `@NVIDIA/batch-invariant` entry follows `batch_invariant_decode.py`), `TRITON_CACHE_MANAGER` in the examples, the determinism docs, and string paths in tests (`mock.patch` targets, `test_autotune_interception.py`).

#!/usr/bin/env python3
"""Move the SSM operation code into ``megatron/core/ops/ssm`` and leave deprecated forwarders.

Run from the repository root on a clean checkout of ``main``::

    python ops_move_ssm.py

The script only moves files (``git mv``), rewrites import paths and path strings, and writes
the forwarder modules and the ``FORWARDED`` table. Formatting (isort, black) runs afterwards.
"""

from __future__ import annotations

import ast
import importlib.util
import re
import subprocess
from pathlib import Path

ROOT = Path.cwd()
CORE = "megatron/core"

# Old module file -> new module file, relative to megatron/core.
FILE_MOVES = {
    "ssm/causal_conv1d.py": "ops/ssm/common/causal_conv1d_cp.py",
    "ssm/utils.py": "ops/ssm/common/checkpointing.py",
    "ssm/ssm_inference.py": "ops/ssm/common/inference.py",
    "ssm/packed_seq_helpers.py": "ops/ssm/common/packed_seq.py",
    "ssm/triton_cache_manager.py": "ops/ssm/triton_cache_manager.py",
    "ssm/gated_delta_product.py": "ops/ssm/gdp/mixer.py",
    "ssm/gdp_context_parallel.py": "ops/ssm/gdp/context_parallel.py",
    "ssm/mamba_context_parallel.py": "ops/ssm/mamba2/context_parallel.py",
    "ssm/mamba_mixer.py": "ops/ssm/mamba2/mixer.py",
}
# Old package -> new package. Every module directly inside moves under the same name.
PACKAGE_MOVES = {
    "ssm/ops": "ops/ssm",
    "ssm/ops/common": "ops/ssm/common",
    "ssm/ops/mamba2": "ops/ssm/mamba2",
    "ssm/ops/gdp": "ops/ssm/gdp",
    "ssm/gated_delta_net": "ops/ssm/gated_delta",
    "ssm/context_parallel": "ops/ssm/context_parallel",
}
# Historical package-level exports. The canonical packages export nothing; these names stay
# available on the deprecated paths only, each resolved from its defining module.
LEGACY_EXPORTS = {
    "megatron.core.ssm.ops": {
        "mamba_chunk_scan_combined_varlen": "megatron.core.ops.ssm.mamba2.ssd_combined",
        "causal_conv1d_varlen_fn": "megatron.core.ops.ssm.common.causal_conv1d_varlen",
    },
    "megatron.core.ssm.ops.gdp": {
        "chunk_gated_delta_product_varlen": "megatron.core.ops.ssm.gdp.chunk",
        "fused_recurrent_gated_delta_rule_update": "megatron.core.ops.ssm.gdp.fused_recurrent",
        "gdp_decode_prepare": "megatron.core.ops.ssm.gdp.prepare",
        "gdp_prefill_prepare": "megatron.core.ops.ssm.gdp.prepare",
        "build_gdp_chunk_descriptors": "megatron.core.ops.ssm.gdp.metadata",
        "max_gdp_chunk_counts": "megatron.core.ops.ssm.gdp.metadata",
    },
    "megatron.core.ssm.gated_delta_net": {
        "HAVE_FLA": "megatron.core.ops.ssm.gated_delta.common",
        "HAVE_FLA_GDN2": "megatron.core.ops.ssm.gated_delta.gdn2",
        "HAVE_TE_GDN": "megatron.core.extensions.transformer_engine",
        "GatedDeltaNet": "megatron.core.ops.ssm.gated_delta.gdn",
        "GatedDeltaNet2": "megatron.core.ops.ssm.gated_delta.gdn2",
        "GatedDeltaNetSubmodules": "megatron.core.ops.ssm.gated_delta.common",
        "causal_conv1d": "megatron.core.ops.ssm.gated_delta.common",
        "chunk_gated_delta_rule": "megatron.core.ops.ssm.gated_delta.common",
        "chunk_gdn2": "megatron.core.ops.ssm.gated_delta.gdn2",
        "get_parameter_local_cp": "megatron.core.ops.ssm.gated_delta.common",
        "l2norm": "megatron.core.ops.ssm.gated_delta.common",
        "tensor_a2a_cp2hp": "megatron.core.ops.ssm.gated_delta.common",
        "tensor_a2a_hp2cp": "megatron.core.ops.ssm.gated_delta.common",
        "torch_chunk_gated_delta_rule": "megatron.core.ops.ssm.gated_delta.gdn",
        "torch_chunk_gdn2": "megatron.core.ops.ssm.gated_delta.gdn2",
    },
}
# The historical package returned None for these when their kernels could not be imported.
OPTIONAL_EXPORTS = {"megatron.core.ssm.ops": ("mamba_chunk_scan_combined_varlen", "causal_conv1d_varlen_fn")}

# Text files whose path strings and dotted module names are rewritten.
REWRITE_SUFFIXES = {".py", ".md", ".sh", ".json", ".yaml", ".yml", ".rst", ".txt"}
# The deprecated-path regression suite names the old paths on purpose; it is edited by hand.
# test_ops_init.py checks the historical package exports and moves into that suite.
SKIP_PREFIXES = ("tests/unit_tests/ops/", "tests/unit_tests/ssm/ops/test_ops_init.py", "CHANGELOG.md")

COPYRIGHT = "# Copyright (c) 2026, NVIDIA CORPORATION. All rights reserved.\n"


def dotted(path: str) -> str:
    """``megatron/core/ssm/ops/__init__.py`` -> ``megatron.core.ssm.ops``."""
    path = path[: -len(".py")] if path.endswith(".py") else path
    path = path[: -len("/__init__")] if path.endswith("/__init__") else path
    return path.replace("/", ".")


def plan_moves() -> dict[str, str]:
    """Old file -> new file, repository-relative."""
    moves = {f"{CORE}/{old}": f"{CORE}/{new}" for old, new in FILE_MOVES.items()}
    for old_pkg, new_pkg in PACKAGE_MOVES.items():
        for path in sorted((ROOT / CORE / old_pkg).glob("*.py")):
            moves[f"{CORE}/{old_pkg}/{path.name}"] = f"{CORE}/{new_pkg}/{path.name}"
    return moves


MOVES = plan_moves()
MODULES = {dotted(old): dotted(new) for old, new in MOVES.items()}
PACKAGES = {dotted(f"{CORE}/{old}"): dotted(f"{CORE}/{new}") for old, new in PACKAGE_MOVES.items()}


def map_module(name: str) -> str:
    """Map a dotted name through the longest moved module or package prefix."""
    parts = name.split(".")
    for i in range(len(parts), 0, -1):
        prefix = ".".join(parts[:i])
        if prefix in MODULES:
            return ".".join([MODULES[prefix], *parts[i:]])
    return name


DOTTED_RE = re.compile(r"(?<![\w.])megatron\.core\.ssm(?:\.[A-Za-z_]\w*)+")
PATH_RE = re.compile(r"(?<![\w/])megatron/core/ssm(?:/[A-Za-z_]\w*)+(?:\.py|/)?")


def map_path(match: re.Match) -> str:
    text = match.group(0)
    trailing = "/" if text.endswith("/") else ""
    is_file = text.endswith(".py")
    stem = text.rstrip("/")
    stem = stem[: -len(".py")] if is_file else stem
    old = stem.replace("/", ".")
    new = map_module(old)
    if new == old:
        return text
    new_path = new.replace(".", "/")
    if is_file:
        # A stale reference to a module that is now a package points at the package directory.
        if (ROOT / f"{stem}.py").exists() or f"{stem}.py" in MOVES:
            return f"{new_path}.py"
        return f"{new_path}/"
    return new_path + trailing


def package_of(path: str) -> str:
    return dotted(str(Path(path).parent))


def resolve(node: ast.ImportFrom, package: str) -> str:
    if not node.level:
        return node.module or ""
    return importlib.util.resolve_name("." * node.level + (node.module or ""), package)


def rewrite_import_statements(path: str, text: str, new_path: str | None) -> str:
    """Rewrite import statements that a textual prefix substitution cannot express.

    * ``from <legacy package> import name`` splits by the module that defines each name.
    * ``from megatron.core.ssm import moved_module`` binds the moved module under its old name.
    * Relative imports in moved files keep their form when they still resolve after the move.
    """
    try:
        tree = ast.parse(text)
    except SyntaxError:
        return text
    lines = text.splitlines(keepends=True)
    old_package = package_of(path)
    new_package = package_of(new_path) if new_path else old_package
    edits = []
    for node in ast.walk(tree):
        if not isinstance(node, ast.ImportFrom):
            continue
        module = resolve(node, old_package)
        indent = re.match(r"\s*", lines[node.lineno - 1]).group(0)
        groups: dict[str, list[str]] = {}
        if module in LEGACY_EXPORTS:
            for alias in node.names:
                target = LEGACY_EXPORTS[module].get(alias.name) or map_module(module)
                groups.setdefault(target, []).append(
                    alias.name + (f" as {alias.asname}" if alias.asname else "")
                )
        elif any(f"{module}.{alias.name}" in MODULES for alias in node.names):
            for alias in node.names:
                full = f"{module}.{alias.name}"
                if full in MODULES:
                    parent, _, base = MODULES[full].rpartition(".")
                    local = alias.asname or alias.name
                    groups.setdefault(parent, []).append(
                        base if base == local else f"{base} as {local}"
                    )
                else:
                    groups.setdefault(map_module(module), []).append(
                        alias.name + (f" as {alias.asname}" if alias.asname else "")
                    )
        elif node.level and new_path:
            target = map_module(module)
            if importlib.util.resolve_name("." * node.level + (node.module or ""), new_package) == target:
                continue
            names = [a.name + (f" as {a.asname}" if a.asname else "") for a in node.names]
            parent, _, base = target.rpartition(".")
            source = f".{base}" if parent == new_package else target
            groups[source] = names
        else:
            continue
        statement = "".join(
            f"{indent}from {source} import {', '.join(names)}\n" for source, names in groups.items()
        )
        edits.append((node.lineno, node.end_lineno, statement))
    for start, end, statement in sorted(edits, reverse=True):
        lines[start - 1 : end] = [statement]
    return "".join(lines)


def rewrite_text(text: str) -> str:
    text = DOTTED_RE.sub(lambda m: map_module(m.group(0)), text)
    return PATH_RE.sub(map_path, text)


def forwarder(old: str, new: str) -> str:
    return (
        f'{COPYRIGHT}\n"""Deprecated import path; use ``{new}``."""\n\n'
        "from megatron.core.ops._compat import deprecated_module\n\n"
        f'__getattr__, __dir__ = deprecated_module(__name__, "{new}")\n'
    )


def legacy_forwarder(old: str, new: str) -> str:
    exports = "".join(f'        "{name}": "{module}",\n' for name, module in LEGACY_EXPORTS[old].items())
    call = f'deprecated_module(\n    __name__,\n    "{new}",\n    exports={{\n{exports}    }},\n)\n'
    doc = (
        f'"""Deprecated import path; use ``{new}``.\n\n'
        "The historical package-level names resolve from the modules that define them.\n"
    )
    optional = OPTIONAL_EXPORTS.get(old)
    if not optional:
        return (
            f'{COPYRIGHT}\n{doc}"""\n\nfrom megatron.core.ops._compat import deprecated_module\n\n'
            f"__getattr__, __dir__ = {call}"
        )
    names = ", ".join(f'"{name}"' for name in optional)
    return (
        f"{COPYRIGHT}\n{doc}"
        "The optional kernel entry points keep their historical value of ``None`` when their\n"
        'kernels cannot be imported.\n"""\n\n'
        "from megatron.core.ops._compat import deprecated_module\n\n"
        f"_forward, __dir__ = {call}\n"
        f"_OPTIONAL = ({names})\n\n\n"
        "def __getattr__(name: str) -> object:\n"
        '    """Resolve ``name`` like any forwarded name, keeping the optional ``None`` fallback."""\n'
        "    try:\n"
        "        return _forward(name)\n"
        "    except ImportError:\n"
        "        if name in _OPTIONAL:\n"
        "            return None\n"
        "        raise\n"
    )


def strip_to_docstring(text: str) -> str:
    """Keep the header comments and module docstring of a package ``__init__``."""
    tree = ast.parse(text)
    doc = tree.body[0]
    assert isinstance(doc, ast.Expr) and isinstance(doc.value, ast.Constant), "no docstring"
    return "".join(text.splitlines(keepends=True)[: doc.end_lineno])


def forwarded_table() -> str:
    entries = "".join(f'    "{old}": ("{new}",),\n' for old, new in MODULES.items())
    exports = "".join(
        f'    "{old}": {{\n' + "".join(f'        "{n}": "{m}",\n' for n, m in names.items()) + "    },\n"
        for old, names in LEGACY_EXPORTS.items()
    )
    return (
        f'{COPYRIGHT}\n"""Deprecated -> canonical module table for the SSM / sparse-attention move.\n\n'
        'Generated alongside the forwarder modules; keep the two in sync.\n"""\n\n'
        f"FORWARDED = {{\n{entries}}}\n\n"
        "# Names each historical package re-exported, and the module that defines each. The\n"
        "# canonical packages export nothing; these stay available on the deprecated paths only.\n"
        f"EXPORTS = {{\n{exports}}}\n"
    )


def git(*args: str) -> str:
    return subprocess.run(["git", *args], check=True, capture_output=True, text=True).stdout


def main() -> None:
    assert not git("status", "--porcelain"), "run on a clean checkout"
    tracked = git("ls-files").splitlines()
    new_of = {old: new for old, new in MOVES.items()}

    # 1. Rewrite every tracked text file in place (moved files keep their old location for now).
    for path in tracked:
        if path.startswith(SKIP_PREFIXES) or Path(path).suffix not in REWRITE_SUFFIXES:
            continue
        file = ROOT / path
        original = file.read_text()
        if "megatron" not in original and not path.startswith(f"{CORE}/ssm/"):
            continue
        text = original
        if path.endswith(".py"):
            text = rewrite_import_statements(path, text, new_of.get(path))
        text = rewrite_text(text)
        if text != original:
            file.write_text(text)

    # 2. Move, then strip the historical exports from the canonical package __init__ files.
    for old, new in MOVES.items():
        (ROOT / new).parent.mkdir(parents=True, exist_ok=True)
        git("mv", old, new)
    for old_package in LEGACY_EXPORTS:
        init = ROOT / MODULES[old_package].replace(".", "/") / "__init__.py"
        init.write_text(strip_to_docstring(init.read_text()))

    # 3. Leave a forwarder at every old path and record it in the regression table.
    for old, new in MOVES.items():
        old_name, new_name = dotted(old), dotted(new)
        body = (legacy_forwarder if old_name in LEGACY_EXPORTS else forwarder)(old_name, new_name)
        (ROOT / old).write_text(body)
        git("add", old)
    table = ROOT / "tests/unit_tests/ops/deprecated_paths.py"
    table.write_text(forwarded_table())


if __name__ == "__main__":
    main()

## Planned follow-ups
This PR stays a pure move. The `HAVE_*` availability flags the moved code still carries (the README's selector rules apply to new code) are removed in follow-up PRs, one per family, each with its own behaviour notes and GPU run:
1. **Triton guards**: drop `HAVE_TRITON` / `HAVE_TRITON_LIBDEVICE` and their asserts from the kernel modules. `import megatron.core` already requires Triton, so these never fire.
2. **GDN**: `gated_delta/backends.py` selectors bound at construction with `require()`, replacing `HAVE_FLA` / `HAVE_FLA_GDN2`.
3. **GDP**: `gdp/backends.py` covering the FLA and CuTeDSL recurrences and chunkwise-CP backends, replacing `HAVE_FLA`, `HAVE_CUTEDSL_GDP`, `HAVE_FLA_GDP_CP`, `HAVE_CUTEDSL_GDP_CP`, `HAVE_MAMBA_SSM`, `HAVE_EINOPS`.
4. **Mamba2**: `mamba2/backends.py`, replacing `HAVE_MAMBA_SSM`, `HAVE_SSM_OPS_VARLEN`, `HAVE_EINOPS`.

Each keeps the old names available on the deprecated forwarders. `HAVE_GTP` and `HAVE_TE_GDN` belong to `tensor_parallel` and `extensions` and are out of scope.
