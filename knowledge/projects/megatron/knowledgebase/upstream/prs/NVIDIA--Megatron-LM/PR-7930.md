# [MFSDP] Integrate split residual units with static prefetch

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7930) · state: closed · merged: False

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Make MFSDP v2 manage `ShortcutMoEBlock` and the separate residual readers and writers introduced by #7952. This prevents residual writes from gathering completed branches again and retaining their full weights through the forward pass.

Shortcut blocks call attention and MoE helpers directly, bypassing the enclosing layers' `__call__` hooks. The adapter therefore shards the shortcut block and its routed experts, while leaving those helper-only layers under the block's ownership. Residual-stream replay additionally gets independent residual and norm units so replay invokes the required weight-gather hooks.

Register the residual operations and routed experts in execution order, with one registered owner per module. Update expert checkpoint/GTP classification for the relocated expert path. Ordinary `load_state_dict` accepts both the names on current `main` and the older combined residual names.

Targets `main` after #7952 merged and includes the remaining shortcut fixes from #7809 and #7781. The generic MFSDP scheduler and residual math are unchanged.

## Validation

- **198 cases passed on each of four GPU ranks**, plus **four TP/CP cases on each of two ranks**; no skipped or failed cases.
- MFSDP/reference loss parity across five training steps with expert parallelism, overlap, norm recomputation, and residual-stream replay. Split-unit tests also check exact outputs, input/parameter gradients, and updated weights.
- Writer prefetch, released full expert buffers after forward, no outstanding gathers after backward, and distributed model/optimizer checkpoint resume.
- A wide-residual shortcut model checkpoint exported from current main loads strictly on this branch with bitwise-equal outputs on all four ranks. The older combined residual names also load strictly and produce bitwise-equal outputs.

Migration of old distributed model and optimizer checkpoints remains unvalidated. No new 64-GPU memory or latency result is claimed for this rebased revision.
