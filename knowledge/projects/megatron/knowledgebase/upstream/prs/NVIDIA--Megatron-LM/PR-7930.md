# [MFSDP] Integrate split residual units with static prefetch

## What does this PR do?

Integrate separate wide-residual readers and writers with MFSDP. A shared residual FSDP unit can prefetch a completed branch on its second invocation and retain gathered weights. This change registers the separate modules in `reader → branch → writer` execution order so the existing static traversal can schedule them independently.

The construction-mode class refactor and caller migrations are in #7952. This PR contains:

- Parameterized residual and norm unit selection for residual-stream replay, including the fix from #7819.
- Execution-order registration in Transformer and Mamba layers.
- Shortcut-MoE ownership of interleaved residual operations and routed experts, with one registered owner per module and ordinary references for partial-forward helpers.
- Expert-name classification and checkpoint handling for the relocated `routed_experts` path, plus the integration regression tests.

The generic MFSDP scheduler and residual math are unchanged. Ordinary `load_state_dict` accepts original legacy model keys; migration of existing distributed checkpoints and optimizer state is not validated.

Depends on #7952, which is stacked on #7781. The head includes the refactor as an ancestor. GitHub currently shows `pull-request/7781` as the base; it will be retargeted to `pull-request/7952` once the refactor mirror exists. Until then, the [integration-only comparison](https://github.com/wujingyue/Megatron-LM/compare/refactor/wide-residual-construction...feat/mfsdp-split-residual) isolates this PR's changes.

This remains a draft design preview and an alternative to #7929. Shared-layer MTP still requires #7757, which is not included. Related: #7777. Retarget this PR to `main` before merging; retarget it before merging its base PR.

The source tree is identical to validated revision `01d7ae599`: **125 tests passed on each of four GPU ranks**, plus **four TP/CP cases on each of two ranks** (508 rank/case checks). The split only changes ancestry.

Coverage includes eager/replayed forward and gradient parity, MFSDP training and clipping, writer prefetch, completed-branch weight release, Shortcut-MoE traversal, legacy model-key loading, and distributed model/AdamW checkpoint resume. This preview makes no memory or latency claim for the revised registration structure.
