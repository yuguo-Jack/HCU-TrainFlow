# Let the TRT-LLM distributed converter take the model's process groups

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8059) · state: closed · merged: False

## Original PR description

Depends on #8049 (and #6293). Please review the diff from #8049's head: [scoped diff](https://github.com/Connor-XY/Megatron-LM/compare/d89eccea46...yx/pstate-c-export-converter-groups).

**Why.** `DistributedTRTLLMModelWeightsConverter` takes its TP and PP groups from the global parallel state, and `TRTLLMHelper` cannot pass others. A model loaded on its own grid exports another grid's TP/PP sizes and ranks in its TRT-LLM mapping, and the vocabulary gather runs over the wrong group.

**What.**
- The converter and `TRTLLMHelper.get_trtllm_pretrained_config_and_model_weights` take an optional `pg_collection`; the helper forwards it to the converter.
- Without one, the converter warns once with `ProcessGroupFallbackWarning` (deprecated in 0.21, removed in 0.23) and reads `tp` and `pp` from the global grid as before, through `resolve_process_groups`.
- A collection without `tp` or `pp` raises `ValueError`; `None` groups keep the existing `RuntimeError`, so nothing exports a TP1/PP1 mapping by accident.
- The distributed export example passes its model's collection.

**Tests.** On 4 GPUs: a TP=2 `HyperCommGrid` collection of distinct communicators converts, with every global read patched to raise, to the same weights as the global path; the fallback warns once; incomplete collections raise; the helper forwards the collection without needing TensorRT-LLM. These fail on #8049's head. The existing export tests match. In the integration run on 4 GPUs, `test_trtllm_distributed_gpu_converter.py` has 6 passed vs 1 on main: this PR's 4 new test cases pass, and so does `test_requires_model_parallel_groups` from #6293. `test_trtllm_helper.py` has 1 passed and 1 skipped: the new forwarding test passes, and `test_exceptions` skips because TensorRT-LLM is not installed. In the integration run, this PR's test files show no regressions against main.

**Compatibility.** New optional arguments only. Callers that pass none get one warning.

The branch was synced with main 77391e71cc on 2026-11-01 by a merge commit, which had no conflicts, so existing commits and review links stay valid.
