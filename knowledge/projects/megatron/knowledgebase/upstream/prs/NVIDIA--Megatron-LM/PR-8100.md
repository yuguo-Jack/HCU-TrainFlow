# Validate the present request subset in inference functional tests

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8100) · state: closed · merged: False

## Original PR description

The inference validator explicitly permits a subset of golden request IDs, but subsequently iterates all golden IDs and crashes with KeyError for missing requests. Iterate the present subset and reject empty request results so the validation cannot pass vacuously.

Validation: two baseline regressions fail and three focused CPU tests pass, including a token mismatch control. Black, isort and Ruff passed. GPU inference was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
