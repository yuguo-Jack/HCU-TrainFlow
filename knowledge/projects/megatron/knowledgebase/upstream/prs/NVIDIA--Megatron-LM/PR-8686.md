# [MFSDP] Add group-local SUM fallback for mixed gradient communication dtypes

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8686) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Adds the group-local SUM fallback proposed in #7751, allowing MFSDP v1 to handle mixed gradient communication dtypes while retaining division fusion for compatible groups.

For example, an FSDP unit containing BF16 gradients for FP8 weights and FP32 norm/router gradients can now run with fusion enabled.

## Changes

- Compare reduction operators and PREMUL_SUM dtypes/factors before each group reduction.
- Explicitly scale incompatible buckets once and use SUM; retain PREMUL_SUM for compatible groups.
- Split all-reduce batches at dtype boundaries, including DP-Outer. Keep mixed-dtype reduce-scatter calls coalesced.
- Preserve BF16 and single-rank scaling, AVG normalization, per-token scaling, and communication dtype overrides.
- Update configuration documentation and add distributed regression tests.

## Testing

Run from the repository root:

```bash
python tests/test_utils/python_scripts/download_unit_tests_dataset.py \
  --assets-dir /opt/data

NCCL_MAX_NCHANNELS=1 NCCL_NVLS_ENABLE=0 \
python -m torch.distributed.run \
  --standalone --nproc-per-node=4 \
  -m pytest -q \
  tests/unit_tests/distributed/mfsdp_v1/test_mfsdp_gradient_reduce.py \
  tests/unit_tests/distributed/mfsdp_v1/test_mfsdp_parameter_grouping.py \
  tests/unit_tests/distributed/mfsdp_v1/test_mfsdp_mixed_precision_policy.py \
  --maxfail=1 --tb=short -o addopts=
```

The tests exercise production MFSDP buffers and real NCCL collectives. Each bucket is compared against an independent explicit-scale + SUM reference with `rtol=0` and `atol=0`. Sharded outputs are compared with the corresponding reference shard.

The 130 new cases cover all four sharding strategies, reversed bucket order, different factors, compatible-group fusion, AVG/per-token scaling, DP=1, dtype overrides, frozen parameters, accumulation, and DP-Outer all-reduce.

The total includes 130 new cases and eight existing grouping/mixed-precision tests.
