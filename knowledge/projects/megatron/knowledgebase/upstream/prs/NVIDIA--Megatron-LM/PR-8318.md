# What does this PR do?
Unit tests in CI have intermittent hangs, most notably in the GDN unit tests, but also in other test suites more rarely.

This is due to [pytorch#200848](https://github.com/pytorch/pytorch/issues/200848). torch >= 2.10 forks worker processes, and locks break under forking in Python < 3.12.8 or Python 3.13.0.

The fix is setting `TORCHINDUCTOR_QUIESCE_ASYNC_COMPILE_POOL=0`. This PR does that, and also undoes various previous patches meant to work around this issue.

Related: #7742 #8120 #8148 #8310 #5476 #5473
