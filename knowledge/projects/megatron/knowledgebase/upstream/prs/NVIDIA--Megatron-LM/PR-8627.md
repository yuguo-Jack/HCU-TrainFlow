# ci: collect per-test functional coverage on demand

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8627) · state: open · merged: False

## Original PR description

Run [40628051353](https://github.com/NVIDIA/Megatron-LM/actions/runs/40628051353) ran 80 H100 and 35 GB200 functional tests, but its coverage artifacts contain only unit-test data. We need executed Python paths per functional test before evaluating a 10–20% test-count reduction with less than 5% coverage loss.

Together, the `Collect functional coverage` and `Run functional tests` labels select the merge-queue functional matrix (L1, mergegroup cadence, one repeat, lightweight off) and instrument each disposable workload container. The coverage label alone does not expand the matrix or enable collection: full-suite queue approval, `ALLOW_PR_RUN_ALL_TESTS`, and functional-run serialization remain applicable. The collector traces Python subprocesses and multiprocessing workers under `megatron/`, retains rank/phase contexts and separate retry databases, and uploads line/branch reports, recipe metadata, and expected matrices. Existing workload validation and exit codes are preserved; ordinary CI remains uninstrumented.

The analyzer requires successful data for every expected test and a consistent source/run identity. It reports per-test/exclusive coverage and proposes greedy 10%/20% reductions with cumulative line AND branch loss strictly below 5% on EACH platform. It does not remove tests. Python overlap does not establish native-kernel, numerical, topology, or assertion equivalence; candidate lists require review, including observed worker ranks.

Validation: 100 targeted CPU tests passed. After requiring both labels, all 92 workflow configuration tests passed again, along with the queue-policy regression check. Black, isort, pylint and Ruff checks passed; both new utilities pass mypy. Full launcher typing is limited locally by the unavailable `nemo_run` dependency. Initial GitHub pre-flight/configuration/linting passed. GPU collection awaits queue admission; the repository currently sets `ALLOW_PR_RUN_ALL_TESTS=false`.

Usage and limitations: `docs/developer/functional_coverage.md`.
