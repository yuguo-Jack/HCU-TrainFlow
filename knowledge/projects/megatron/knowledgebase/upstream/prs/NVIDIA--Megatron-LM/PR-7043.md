# fix: account for DSA top-k sparsity and indexer cost in FLOPs

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7043) · state: closed · merged: True

## Original PR description

Port the DSA FLOPs accounting from #6753 and #7157 to `main` for standard GPT and hybrid models. Previously, hybrid `D` layers contributed no attention/indexer FLOPs, while the standard path used ordinary MLA attention costs.

## Changes

- Share explicit-parameter counters in `megatron/training/logging/dsa_flops.py`. `dsa_layer_flops()` returns one attention layer's forward FLOPs; callers multiply by the DSA layer count and apply the common x3 training expansion.
- Count indexers separately using their loss-dependent backward factors: forward only with loss disabled; projection x2 and scoring x3 for dense KL, or scoring `1 + 2 * sparse_scale` for sparse KL.
- `dsa_indexer_flops(num_dsa_layers=...)` accepts **all DSA attention layers**, including MTP and layers reusing an index. It derives actual indexer executions from sharing settings and layer positions. Decoder and MTP numbering are handled separately; repeated MTP counts each execution. Hybrid models use pattern positions, including numbering across non-DSA layers.
- Support `kpool > 1`: gate projection, complete-pool key reduction, compressed causal scoring, and attention over selected pools plus the optional incomplete tail. KPool requires disabled indexer loss, matching runtime. Attention and indexer share the pool-pair sum; indexer arithmetic stays in one helper.

Changes are limited to the DSA logging module, training integration and FLOPs tests. Existing non-DSA counters and tests are preserved.

## Validation

- **199 CPU FLOPs tests passed**; 20 CUDA accumulator tests deselected. Includes independent goldens, KPool sizes 2/4/8, tail modes, sharing, MTP, fractional lengths and ten comparisons with runtime KPool token selection.
- **41,640 exact numerical comparisons** against `a4385191a` validate the final helper simplification, plus 32 matching validation/zero-layer outcomes. Formatting, lint, copyright and environment-aware type checks pass.
- **OCI-HSG, 4 x GB200, BF16, TP2/DP2, unfused DSA:** four KPool configurations at `a4385191a` each completed 5/5 optimizer steps: standard pool=4 with tail on/off; hybrid with two MTP depths and sharing, pool=4/tail on and pool=8/tail off. All losses/norms were finite, with zero skipped/NaN iterations. Eight broader standard/hybrid/MTP smokes passed at `6b46fe8ad`.

The final helper simplification has exact CPU parity with the GPU-tested implementation; GPU training was not rerun after it. The squash commit preserves the exact file tree of `914c37679`. GPU coverage does not include fused cuDNN DSA, packed THD training or eight-GPU accumulator topologies.

## Accounting limits

Packed batches expose only `sum(L)` and `sum(L^2)`: KPool uses the length-weighted mean with interpolation, so individual document/pool boundaries remain approximate. Pool softmax, positional bias, top-k selection, teacher recomputation and KL operations are excluded. The pre-existing ordinary DSA short-THD approximation and hybrid MTP norm/projection gap are unchanged.
