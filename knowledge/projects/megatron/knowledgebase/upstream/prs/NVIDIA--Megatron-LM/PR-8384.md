# Record opt-in GH200 sm90 tuning candidate and qualification gaps

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8384) · state: open · merged: False

## Original PR description

Record an explicitly selected GH200 `sm90` tuning candidate and its failed model-qualification gates. The 25-kernel/42-entry candidate passes the finite component replays, but one MLA model process differs numerically and the three model families do not meet the preregistered timing gate. Keep the JSON under performance-test tuning candidates, outside packaged defaults, so this PR does not automatically change deterministic-mode kernel selection.

The table was built from 63 MLA RoPE/mHC/SSD shapes at 2k, 8k and 32k tokens: 3264 finite candidate observations, with 12 invalid observations retained in the raw record. MLA/mHC use a wildcard minimizing worst-case slowdown plus per-key overrides when they improve that worst case by more than 5%; SSD uses one minimax entry per key. Invalid/nonpositive candidates are excluded and valid coverage of every compared case is required. Rebuilding the candidate reproduces all 42 choices exactly.

Measured environment: NVIDIA GH200 480GB, aarch64, driver 595.58.03, PyTorch 2.14.1+cu130, CUDA runtime 13.0, Triton 3.8.0, Mamba SSM 2.3.2.post1. H100 was swept separately under NGC 26.09; different-runtime choices are not merged.

Validation and unresolved gates:

- All 63 shapes passed two independent processes, each with two ordered replays, comparing all returned outputs/input gradients and configuration digests. No foreign GPU work was observed. Pinning-only failed six SSD gradient cases, so ordered reductions are necessary in addition to fixed candidate selection.
- A frozen 27-case GPT/HybridModel forward/backward/SGD comparison ran three families × three modes × three independent processes, four warmup plus ten measured steps. Every loss was finite and every process exited zero, but one of three **MLA table-mode** processes differed in loss/parameter/gradient digests. Its recorded configuration digest was unchanged. mHC/SSD table-mode digests were stable; the auto SSD control varied.
- Paired table/auto geometric-mean median-step ratios (two-sided 95% Student-t interval on log ratios, n=3): **MLA 1.120 [0.495, 2.531]; mHC 1.484 [0.642, 3.429]; SSD 0.972 [0.697, 1.356]**. None meets the frozen upper-bound <=1.05 gate. These small/noisy measurements establish no model speedup.
- Five diagnostic MLA table processes on the second GH200 matched their initial states, losses and gradients. An isolated MLA kernel memcheck reported 0 errors; racecheck reported 0 hazards. These do not explain or invalidate the original-host mismatch. On the original host, six additional table and three cheapest processes with explicit initial parameter/input hashes reproduced the mismatch: one table process differed from its first loss onward, three final parameter tensors and twelve final gradient tensors differed, while all initial parameters, input tokens and table-choice hashes were identical. The other five table runs and all three cheapest controls matched. Three further table processes repeated the original four-warmup/ten-measured-step protocol and matched initial parameters, inputs, losses, final parameters, gradients and choices. These additional passing samples do not erase either earlier failure series or explain the mismatch. The original failure remains unresolved.
- JSON schema/readability, exact kernel-choice equality to the replayed candidate, 25-kernel/42-entry count, and `git diff --check` passed. No production kernel is changed. Promotion into `megatron/core/tuning/tables` requires passing model gates; this PR makes no claim that promotion is ready.

The [public reproduction record](https://github.com/0z5a/Megatron-LM/tree/hopper-validation-evidence/validation/hopper-20261020) contains the raw sweep, exact builder, component audit, model protocol and all 27 model result files. Original failures and interrupted windows are preserved. This is bounded synthetic evidence, not model convergence or arbitrary-Hopper qualification.
