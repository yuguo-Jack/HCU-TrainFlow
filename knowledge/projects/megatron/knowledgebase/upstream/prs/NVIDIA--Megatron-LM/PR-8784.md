# Fix mHC unit boundaries for hook-driven MFSDP v2

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8784) · state: open · merged: False

## Original PR description

## What does this PR do?

Fix the default hook-driven MFSDP v2 unit boundaries for HybridModel with mHC. The split-layer mHC fast path calls inner-layer helpers directly, bypassing the inner layer's forward hooks and leaving parameters sharded when compute consumes them.

Use the called mHC wrapper as the unit instead, while preserving separate expert-DP sharding. Explicit unit policies and combined-1F1B scheduling are unchanged; this fix is independent of #7582.

## Validation

Extend the MoE reference test to cover mHC, two-microbatch accumulation, and five clipped SGD steps, comparing reduced gradients, updated parameters, and losses against an unsharded reference.

- Black, isort, Pylint, and Ruff passed.
- Four GB200 GPUs: mHC on/off passed on all four ranks, including EP2/expert-DP2, two accumulated microbatches, and five SGD updates. Gradients, updated parameters, and losses match the unsharded reference within the existing tolerances.
- The mHC/MTP/MXFP8 smoke passes the original first-forward failure, then fails in backward: `mla_up_proj` recomputation requests rowwise MXFP8 data that is unavailable. End-to-end qualification of that recipe remains blocked.
