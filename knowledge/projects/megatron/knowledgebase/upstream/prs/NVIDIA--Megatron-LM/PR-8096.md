# Resolve Common Pile setup script location before changing directories

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8096) · state: closed · merged: False

## Original PR description

Invoking the Common Pile setup script through a relative path fails when it resolves BASH_SOURCE after changing into the temporary work directory. Resolve its directory first so the adjacent dataset script is found.

Validation: regression executes the actual directory-discovery shell phase with a relative path; baseline exits with a missing-directory error and the fix locates the adjacent script. bash -n, isort, Black and Ruff pass. HPC prerequisites, cloning, downloads and preprocessing were excluded; no full HPC run was performed.
