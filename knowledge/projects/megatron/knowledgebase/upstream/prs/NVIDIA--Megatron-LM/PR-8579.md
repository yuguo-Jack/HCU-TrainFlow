# fix(ddp): use math.isclose for gradient scaling factor asserts

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8579) · state: closed · merged: True

## Original PR description

Exact float equality in the DDP scaling factor validation is fragile: the two sides are computed via different division orders, so rounding can differ for some DP sizes. `1/72/3 == 1/216` happens to hold, but `1/72/5 != 1/360` `(0.0027777777777777775 vs 0.002777777777777778)`, which failed at 360 GPUs. Compare with math.isclose instead.

### Add coverage for the division-order failure

The [changed constructor assertion](https://github.com/NVIDIA/Megatron-LM/blob/8a8743cef146d5594167140db17bba8dc96dc3c0/megatron/core/distributed/distributed_data_parallel.py#L333-L342) fixes a rounding-sensitive case, but this PR adds no test that distinguishes the fix from the old equality. The existing [DDP test](https://github.com/NVIDIA/Megatron-LM/blob/8a8743cef146d5594167140db17bba8dc96dc3c0/tests/unit_tests/distributed/test_distributed_data_parallel.py#L39-L57) uses DP sizes 2 and 8; the [expert gradient-sync matrix](https://github.com/NVIDIA/Megatron-LM/blob/8a8743cef146d5594167140db17bba8dc96dc3c0/tests/unit_tests/distributed/test_grad_sync_with_expert_parallel.py#L278-L298) varies expert sizes between 1 and 2. With averaged collectives, one optimizer instance, DP=360 and expert DP=5, `(5 / 360) / 5 != 1 / 360`: the base assertion rejects a valid configuration. Reintroducing that assertion would therefore remain unprotected by a targeted regression.

Add a constructor-level test to [the DDP test module](https://github.com/NVIDIA/Megatron-LM/blob/8a8743cef146d5594167140db17bba8dc96dc3c0/tests/unit_tests/distributed/test_distributed_data_parallel.py). Mock communication and buffer allocation, but execute the production validation. The invariant is that rounding-equivalent scales pass without changing the prescaling factors, while a materially inconsistent reduction group still fails.

**Suggested addition—not executed; verify before adopting:**

```python
@pytest.mark.parametrize("dp_size,edp_size", [(216, 3), (360, 5)])
def test_ddp_accepts_rounded_expert_scale(monkeypatch, dp_size, edp_size):
    from types import SimpleNamespace

    import megatron.core.distributed.distributed_data_parallel as ddp_module

    def group(size):
        return SimpleNamespace(size=lambda: size, rank=lambda: 0)

    dp = group(dp_size)
    edp = group(edp_size)
    singleton = group(1)
    groups = {
        "dp_group": dp,
        "dp_cp_group": dp,
        "intra_dp_cp_group": dp,
        "expt_dp_group": edp,
        "intra_expt_dp_group": edp,
        "tp_group": singleton,
        "pp_group": singleton,
        "ep_group": group(dp_size // edp_size),
    }
    monkeypatch.setattr(
        ddp_module.ProcessGroupCollection,
        "setup_process_groups_for_ddp",
        staticmethod(lambda *args, **kwargs: groups),
    )
    monkeypatch.setattr(ddp_module, "log_single_rank", lambda *args, **kwargs: None)
    monkeypatch.setattr(
        ddp_module,
        "_ParamAndGradBuffer",
        lambda *args, **kwargs: SimpleNamespace(gradient_scaling_factor=args[7]),
    )
    monkeypatch.setattr(ddp_module, "partition_buckets", lambda *args, **kwargs: [])

    def wrap():
        module = torch.nn.Module()
        module.dense = torch.nn.Parameter(torch.ones(1))
        module.expert = torch.nn.Parameter(torch.ones(1))
        module.expert.allreduce = False
        return DistributedDataParallel(
            TransformerConfig(num_layers=1, num_attention_heads=1, hidden_size=4),
            DistributedDataParallelConfig(average_in_collective=True),
            module,
        )

    if dp_size == 360:
        assert (edp_size / dp_size) / edp_size != 1.0 / dp_size
    model = wrap()
    assert len(model.buffers) == len(model.expert_parallel_buffers) == 1
    assert model.buffers[0].gradient_scaling_factor == 1.0
    assert model.expert_parallel_buffers[0].gradient_scaling_factor == edp_size / dp_size

    groups["intra_expt_dp_group"] = group(edp_size + 1)
    with pytest.raises(AssertionError):
        wrap()
```

**Acceptance and preservation:** the valid 360/5 case should fail against base and pass against head; the neighboring 216/3 case should pass on both. Both must retain dense prescaling `1.0` and expert prescaling `edp_size / dp_size`. An inconsistent expert reduction group—size 6 for expert DP=5—must still raise on both. Retain the existing summed/averaged and multi-instance gradient-sync assertions, plus the [GTP regression assertions](https://github.com/NVIDIA/Megatron-LM/blob/8a8743cef146d5594167140db17bba8dc96dc3c0/tests/unit_tests/distributed/test_distributed_data_parallel.py#L176-L198): dense scaling remains `1/dp_cp_size`, and expert scaling remains `(1/dp_cp_size) * (egtp/gtp)` for both directions of the GTP/EGTP relationship. Per-token loss must continue to bypass these comparisons and use unit prescaling.
