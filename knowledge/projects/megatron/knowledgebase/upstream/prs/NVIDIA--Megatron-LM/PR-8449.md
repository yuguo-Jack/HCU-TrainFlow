# Avoid redundant reduce-scatter (all-to-all / fp32 reduction) for DP size = 1

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8449) · state: closed · merged: True

## Original PR description

Avoid redundant reduce-scatter (all-to-all / fp32 reduction) for DP size = 1

Introduce a new _CompletedWorkHandle class for handling synchronous reduce-scatter operations in single-rank scenarios. Update the reduce_scatter_with_fp32_accumulation function to return this handle when async_op is False, ensuring correct tensor copying behavior for single-rank cases.
