# [M-FSDP v2] Register all-gather input buffers

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8950) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

Register symmetric all-gather inputs alongside outputs on each mesh axis. This lets NCCL use symmetric all-gather when send and receive buffers occupy separate allocations, including intermediate views in multi-axis gathers. Parameter allocation policies are unchanged.

Extend existing tests with independent symmetric input/output combinations and MXFP8 plane checks through CUDA Graph capture and replay.

Validation: Four GB200 GPUs passed 160/160 rank cases across old and fixed implementations, including CUDA Graph capture/replay. Native-window observations reproduce missing input windows on the old implementation and verify complete input coverage after the fix. Black, isort, Ruff and kernel determinism coverage checks pass.

Code provenance: Original changes; no external code copied.
