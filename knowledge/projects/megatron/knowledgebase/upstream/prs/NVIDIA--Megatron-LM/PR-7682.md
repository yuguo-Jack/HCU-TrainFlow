# Fix vocab-parallel MTP loss for TP>1

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7682) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

`process_mtp_loss` currently passes the caller's `runtime_gather_output` to the MTP head.
That flag is meant to control the logits returned to the caller.
But MTP logits are never returned: they go straight into `compute_language_model_loss`.

`compute_language_model_loss` has a vocab-parallel cross-entropy that infers each rank's vocab slice from the tensor width.
If the caller passes `runtime_gather_output=True` with TP>1, `compute_language_model_loss` gets full-width tensors on every GPU. But it does not account for this; it assumes it still has TP-split tensors. The loss ends up wrong, and so is the grad.

To fix this issue, we could either:

 * Change `compute_language_model_loss` to be able to handle `runtime_gather_output=True`
 * Remove the `runtime_gather_output` option altogether

The second option seems better to me, because `process_mtp_loss` does not return logits,
and `runtime_gather_output=True` is only meant to play a role when logits are returned.
