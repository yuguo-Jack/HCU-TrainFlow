# What does this PR do?

Fixes the NeMo Lens links in `docs/user-guide/observability/`: Lens renamed its docs from `.md` to `.mdx`, so every `github.com/NVIDIA-NeMo/Lens/blob/main/docs/...md` link returned 404.

## Issue tracking

Linked issue: none (small docs fix)

## Changes

- 18 links across 6 files now point to the `.mdx` paths (architecture, optional-dependency, testing, backends, configuration, distributed-tracing, instrumentation, logging-bridge, metrics, resources, span-groups). Each target exists in the Lens repo, and all of them return 200.
- `docs/user-guide/sampling.md` is left as is: it no longer exists in the Lens repo under either extension.
