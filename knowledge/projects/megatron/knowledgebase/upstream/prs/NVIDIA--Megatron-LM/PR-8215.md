# What does this PR do?
- Adds an opt-in config flag: `moe_hybridep_enable_custom_allgather` in `TransformerConfig`, default `False`, which also creates a `--moe-hybridep-enable-custom-allgather` command-line flag. It is passed through the token dispatcher and `hybrid_ep_dispatch` into `init_hybrid_ep_buffer`.
- Only enables it on fixed DeepEP builds. DeepEP's version string didn't change with the fix, so the check uses the fact that https://github.com/deepseek-ai/DeepEP/pull/682 also changed the Python default of `enable_custom_allgather` from `True` to `False`. On an older build, a request to enable it gets a warning and stays on NCCL.
