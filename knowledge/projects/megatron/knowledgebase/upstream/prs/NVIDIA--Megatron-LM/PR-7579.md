## What does this PR do?

Adds two model-independent primitives used by the stacked wide-residual implementation in #6716:

- `ResidualConnection`, an `nn.Module` protocol that validates architecture-specific residual reads and writes while preserving module-hook dispatch;
- structured streamwise read and writeback operations with native PyTorch references and fused Triton forward/backward implementations for BF16, FP16, and FP32.

Forward-only inference can use the fused kernels for decode-sized batches without specializing Triton compilation on the runtime batch size. Training and residual-stream replay retain the same kernel-selection limits so recomputation reproduces the original forward arithmetic.

This prerequisite PR intentionally does **not** add wide-residual configuration, model construction, optimizer routing, or Transformer/GPT integration. Those remain in the follow up PR #6716.
