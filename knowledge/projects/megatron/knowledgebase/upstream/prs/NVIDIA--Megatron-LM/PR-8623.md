# test: Reduce workers in synthetic GPT preprocessing

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8623) · state: open · merged: False

# What does this PR do?

Reduce the worker pool used by the synthetic GPT preprocessing round-trip test.

## Motivation

This correctness test preprocesses three small synthetic JSONL inputs, but starts 10 pool workers per input on every pytest rank. Across eight CI ranks, that creates about 240 pool-worker starts for a small workload.

Two workers retain multiprocessing coverage while reducing that process fan-out. The separate worker-selection sweep still launches pools of 2, 4, and 8 workers. It exercises worker selection rather than repeating the round-trip assertions at every pool size.

## Change

Change `--workers` from 10 to 2 in `test_preprocess_data_gpt`. This is a one-line diff. The tokenization, indexed-dataset, and merge assertions still run.

## Results

| Metric | Before | After |
| --- | --- | --- |
| Pool-worker starts, derived for three inputs across eight CI ranks | About 240. | About 48, an 80% reduction. |
| Warm, offline one-rank median call time | 6.38 seconds. | 6.35 seconds, effectively unchanged. |
| CPU time for this test on eight ranks on B200, median of three interleaved runs | 214 seconds. | 164 seconds, about 23% less. |
| Wall time for the same runs | 36.0 seconds. | 33.6 seconds, within the run-to-run variation. |

The verified resource reductions are fewer pool-worker starts and less CPU time. The count excludes unchanged partition processes. The CPU time includes torchrun and pytest startup. The timings do not establish a wall-time improvement.

The test took roughly 49 seconds per rank in the sampled [eight-rank CI job](https://github.com/NVIDIA/Megatron-LM/actions/runs/40615303300/job/122578207118). Its post-change H100 runtime is still unmeasured.

## Validation

The existing round-trip test passed before and after in three interleaved pairs through `torch.distributed.run --nproc-per-node 1 -m pytest tests/unit_tests/data/test_preprocess_data.py::test_preprocess_data_gpt`, with `OMP_NUM_THREADS=1` and warmed, offline tokenizer assets. Every run reported matching raw, processed, and merged documents.

Canonical Black, isort, Pylint, and Ruff checks passed. Optional mypy was unavailable.

The data unit-test directory also ran on eight ranks on an eight-GPU B200 node, with this branch merged into main, and its results matched main. That environment used PyTorch 2.13.0+cu130 and the pinned Transformer Engine revision. It was not the CI image.
