# What does this PR do?

The fused pre-GDR gate backward accumulates `A_log` and `dt_bias` gradients with atomics. Add an ordered reduction when the existing deterministic setting requests it, while preserving the default autotuned atomic reduction.

When `use_deterministic_mode()` returns `True`, each program writes independent FP32 partial sums and the caller reduces them on the existing stream. The tile comes from the shared `autotune_configs` selector; that same config determines scratch capacity and launch parameters. This supports explicit block-size overrides and runtime mode changes without a fixed 128×16 launch.

With determinism disabled, the original autotuner, candidate list and atomic accumulation remain in use, with the original accumulator size. Pinning autotune by itself does not enable ordered arithmetic. The deterministic selector uses the existing block-size/min-cost selection, not tuned-table lookup.

Full pre-GDR fusion still rejects model `deterministic_mode=True`; this PR does not enable deterministic execution of the entire fused model. No activation-offload code changes are included.
