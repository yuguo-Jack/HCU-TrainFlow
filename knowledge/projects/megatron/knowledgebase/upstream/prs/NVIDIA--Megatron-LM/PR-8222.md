# Use weak-key membership for MFSDP context roots

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8222) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

`FsdpContext._roots` only needs weak membership after construction. Store it as `WeakKeyDictionary[nn.Module, None]` instead of `IndexedOrder`, and reverse a list of its keys in `finalize()` when building backward prefetch order. Remove the now-unused `IndexedOrder.__contains__()` and `__reversed__()` methods.

Follow-up to #6369.
