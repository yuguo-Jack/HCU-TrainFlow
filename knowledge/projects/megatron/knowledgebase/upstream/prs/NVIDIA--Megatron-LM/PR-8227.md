# [DSv4.1] V4.1 training builder and packed pipeline plans

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8227) · state: open · merged: False

## Original PR description

Select the V4.1 builder from training arguments, prepare typed PP plans from ContextParallelBatch, preserve logical packed lengths and account for actual indexer producers. Support static `dp_balanced` variable-length scheduling with contiguous CP; dynamic CP remains unsupported. Include smoke and MXFP8 configuration guidance.

Depends on #8226, which consumes #7678 and #8223/#8224/#8225. MoK is a separate dependency in #8210; this PR does not port its implementation. Keep this PR based on `pull-request/8226` while the dependent stack is reviewed.

Validation: H100 pipeline tests, 8-GPU DP2/EP2/PP2/CP2 train/save/resume, VPP, one-layer full recompute and 16K CP2 sparse-loss training passed. The assembled stack completed 12 steps on 16 GB200 GPUs at TP1/PP2/VPP4/EP8/CP4, sequence length 16K, with distributed Muon and MoK, for both BF16 and MXFP8 model/indexer recipes. All ranks completed without skipped iterations or NaNs. This proxy has Engram and CUDA graphs disabled; it does not establish released-model convergence or full-model cross-branch gradient parity.

After excluding the first two steps, median iteration time was 27,279.8 ms for BF16 and 29,087.65 ms for MXFP8 (308.46 and 289.29 achieved TFLOPS/GPU under the common counting formula). These are assembled-stack results, not performance attributed solely to this training integration. See the integration snapshot's validation notes for configuration and limits.
