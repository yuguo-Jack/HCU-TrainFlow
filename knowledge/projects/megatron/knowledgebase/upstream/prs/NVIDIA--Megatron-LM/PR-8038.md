# Use the MLP's TP group in TE fused MLPs and require a CP group for CP attention

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8038) · state: closed · merged: False

## Original PR description

**Why.** `TEFusedMLP` builds its Transformer Engine ops with the global tensor-parallel size and group, and `TEFusedMLPWithGroupedLinear` picks its code path by the global TP size. An MLP built with an explicit `tp_group` on other ranks, for example a model on its own grid, then reduces its row-parallel output over the wrong ranks or skips the reduction, and returns wrong results without an error. With `context_parallel_size > 1`, `TEDotProductAttention` passes `get_process_group_ranks(pg_collection.cp)` to TE. When `cp` is unset or `None`, that is every rank of the job and TE gets no CP group, so attention silently runs without context parallelism.

**What.**
- `_get_te_ops_tensor_parallel_context` takes the TP group from its caller. `TEFusedMLP` passes `self.tp_group`, the group `MLP` gives FC1 and FC2, and the grouped MLP picks its path by that group's size. Five global reads are removed.
- `TEDotProductAttention` raises `ValueError` for context parallelism without a CP group.

**Tests.** `tests/unit_tests/extension/test_te_extension_process_groups.py` runs both fused MLPs on a TP grid laid out unlike the global one, with the `parallel_state` accessors patched to raise, and compares outputs and gradients with the unfused MLP, with and without sequence parallelism. It also checks that attention rejects a missing CP group. Before the 2026-11-01 sync, the new tests failed on main and passed here on 4 GPUs, and extension, TE-wrapper determinism and transformer-block tests matched main. In the integration run (main 77391e71cc with all #6307 PRs merged) on 4 GPUs, all 11 tests in `test_te_extension_process_groups.py` pass; main does not have this file. `tests/unit_tests/transformer/test_te_fused_mlp_with_grouped_linear_spec.py` gives 26 passed and 1 skipped, the same as main. In the integration run, this PR's test files show no regressions against main.

**Compatibility.** On the standard grid the module's group is the global TP group, so nothing changes. Context-parallel attention built without a CP group now raises instead of running without CP.
