# What does this PR do?

Two fixes for HybridEP with a static expert-rank budget (`--moe-expert-rank-capacity-factor`):

1. **Mask padding under an expert-rank budget.** `_HybridEPManager.setup_metadata()` removes the routes and weights of padding rows only when the run is fully dropless. With a rank budget, padding rows are still dispatched: they use receive-buffer and expert rows and count against the budget, so a rank can go over budget and force a rerun of the step. This commit masks padding whenever per-expert capacity (`--moe-expert-capacity-factor`) is off. The static budget size is unchanged, real tokens keep their routes, and the masking needs no host sync, so it also works in captured CUDA graphs.
2. **Restore the static budget after the dropless rerun.** `PagedStashRunner` reruns an over-budget step dropless by clearing the capacity factor, and `setup_metadata()` then drops the static budget (`num_permuted_tokens`) for the rerun. Afterwards the runner restored only the factor, so a partial CUDA graph whose replay skips `setup_metadata()` (`moe_preprocess` scope) kept dispatching without the budget, through HybridEP's host-synced dynamic path, on later steps. The dispatch managers now get `disable_expert_rank_capacity()` / `restore_expert_rank_capacity()`; on HybridEP they save and restore the static budget together with the factor. NCCL EP is unchanged, and a captured TE whole-MoE graph still raises instead of rerunning.

With per-expert capacity off, padding takes none of the expert-rank budget, and replays keep the static budget after a rerun. Found while benchmarking NVIDIA/Megatron-LM#6479, whose packed sequences are padded to a fixed per-rank capacity.

## Tests

- `test_token_dispatcher.py`: padding rows lose routes and weights under a rank budget while valid rows and the budget are unchanged (bool and dense routing maps); per-expert capacity keeps its fixed routes; a CUDA-graph-captured `setup_metadata()` replayed with four padding masks matches eager exactly.
- `test_hybridep_manager.py` (CPU, fake HybridEP): every rerun microbatch dispatches dynamically; `PagedStashRunner` restores the factor and static budget after the step, and a dispatch that skips `setup_metadata()` uses it; a captured whole-MoE graph still raises; drop-and-pad keeps its static size.
- The new padding-mask tests and the budget-restore test fail on dev without the corresponding commit. On 8×H100, a per-test comparison against dev (router, dispatcher, paged-stash, HybridEP manager and quantile-balancing tests) shows no test that fails only with this PR.
