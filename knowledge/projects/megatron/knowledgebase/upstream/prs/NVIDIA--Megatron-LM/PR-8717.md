# What does this PR do?

Expose native spatial merge geometry and spatial-output counting through the existing vision encoder registry, without constructing a model.

`EncoderSpec` currently records whether an encoder has a native spatial merger, but not its numeric reduction. Add `spatial_merge_size`, an effective per-axis `spatial_reduction` including pixel shuffle, and `num_spatial_embeddings(img_h, img_w)` for processed, aligned image dimensions. Record the existing 2x2 merger defaults for Pixtral-Large, Qwen and Kimi. For example, 14-pixel patches with a 2x2 merger map a 112x224 image to 32 spatial outputs.

The field is appended with a default, preserving existing constructor positions and field values. Existing model construction, configuration application, and image/video counters are unchanged. The new count is explicitly spatial-only: pooling, class/tile tokens, temporal compression and separate runtime geometry overrides remain with existing accounting code.
