# Fix MFSDP v2 parameter gathering for hybrid mHC layers

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8554) · state: open · merged: False

## Original PR description

## What does this PR do?

Makes MFSDP v2 gather parameters correctly for hybrid layers wrapped by mHC (`HyperConnectionHybridLayer`).

## Implementation

- mHC calls the inner layer's helper methods directly, which skips the `__call__` hooks, so the inner layer's parameters were left ungathered. `HyperConnectionHybridLayer` is now an FSDP unit and keeps the parameters of its inner `TransformerLayer` or `MambaLayer`, as `ShortcutMoEBlock` already does. Routed experts keep their own units.
- With mHC recompute, the inner layer's layernorms are replayed before the wrapper's `pre_backward()`. They become their own units so their hooks gather parameters and reduce the replay gradients.

## Validation

A new test, `test_mcore_mhc.py`, compares the loss with and without MFSDP v2 for attention and MoE layers, with and without mHC recompute. It passes on 4 GB200 (OCI).
