# fix: repair H100 dynamic inference functional tests

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8855) · state: open · merged: False

## Original PR description

Fix four consistently failing H100 dynamic-inference cases without quarantining them or weakening their assertions.

- **Both routing-replay variants:** allow legacy Transformer Engine pickle metadata only in these trusted CI checkpoint configurations, matching sibling tests that load the same checkpoint.
- **GPT-OSS SWA:** clear unwritten varlen-attention padding before projection and native MoE routing, including BF16 inference. Before the fix, changing PyTorch's uninitialized-memory fill policy changed generated tokens. After the fix, independent H100 runs under both policies produce identical 16 tokens and 20 log probabilities. Refresh the H100 output reference for this initialized-padding behavior.
- **Optimized SwiGLU:** refresh only the H100 expected log probabilities for the current backend. All 30 expected tokens and the comparison tolerance remain unchanged. Current output exactly reproduces the earlier main failure; restoring pre-#4743 router-weighting arithmetic reproduces the older failure but does not restore the stale reference.

The blanket dynamic-inference quarantine is removed; recipe scopes match the base branch. Reference updates preserve timing, throughput, and memory baselines.
