# Count DSv4 attention FLOPs in HybridModel training metrics

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

The current HybridModel FLOPs calculation omits C/H/W attention layers. Count their query/KV/output projections, window attention, compression, ratio-4 indexer and sparse attention, and ratio-128 attention. Read layer counts and MTP depth from the actual hybrid pattern, and use DSv4's head dimension rather than an uninferred MLA argument default.

Reuse main's real-token and squared-sequence-length statistics for packed batches. Packed Top-K saturation remains an estimate based on token-weighted mean sequence length; the existing statistics do not retain individual document lengths. Keep the existing forward/backward FLOPs convention and include MTP normalization/projection work.

Related to #5795. Adapted from the DSv4 accounting in #5142, #5358, and #5762. Independent of #7336 and #7469. This changes reported FLOPs, not model execution speed.
