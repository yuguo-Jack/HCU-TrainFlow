# What does this PR do?

Extend opt-in `gdn_core_attn` activation offloading to GDN2 and Transformer Engine CUDA graphs for GDN/GDN2 training.

Reuse the existing recurrence scope, differentiable prefetch anchor, commit before output normalization, transfer streams and pinned-memory pool. Keep TE layer-graph replay on the caller's autograd stream to preserve ordering with shared graph pools. Native pre-GDR kernels and autotuning are unchanged.

GDN2 keeps sigmoid gate outputs resident when gate backward already retains their storage: the differentiable write gate, and the differentiable erase gate without head expansion. Expanded erase gates and frozen gates remain eligible for offload. This avoids transfers that cannot free the original GPU storage.

Support is BF16/FLA only: attention/whole-layer TE capture, `gdn_norm_out` recomputation and delayed offload. Graph offload requires PyTorch >= 2.9, TE >= 2.14 and positive graph warmup. Set `NVTE_CPU_OFFLOAD_V1=1` before launch. GDN2 requires `fla.ops.gdn2`. FP8/FP4, full recomputation and local/full-iteration graphs are unsupported. See [usage and configuration](https://github.com/Pinoeer-kingxi/Megatron-LM/blob/1f6eab9ce2453cf55cfeac57add2ed80540f31a7/docs/developer/gdn_activation_offloading.md).

## Memory and runtime

The before/after comparison trains the complete eight-block GDN2/attention model: hidden size 1024, vocabulary 4096, linear key/value heads 8/16, head dimension 128, embeddings, MLPs, vocabulary loss and native BF16 Adam. Both arms enable offloading and whole-layer TE graphs on one A6000, with sequence 2048, four microbatches, unfused pre-GDR, norm recomputation off, fraction 1 and the default 1,048,576-element threshold.

Three fresh-process pairs alternate arm order. Each arm trains three native steps, captures graphs, warms up three replay steps and times ten optimizer steps. Timing includes zeroing, forward/backward/finalization, eager Adam and CUDA completion; inputs, capture and snapshots are excluded.

| Metric | Before, `d18040ba5a` | After, `367d014c7b` |
| --- | ---: | ---: |
| Median of process-median step times | 451.71 ms | 424.91 ms |
| Median peak reserved | 4944 MiB | 4922 MiB |
| D2H and H2D bytes per step, combined | 3200 MiB | 2880 MiB |
| Retained pinned buffers | 54 | 48 |

Paired median step time falls 5.93% (5.89–5.95%); additional reserved savings are 22 MiB (20–38 MiB), with unchanged allocated peaks. Nsight records 10% fewer transfer bytes and unchanged kernel name/count multisets. This measures the gate-selection change with offloading enabled in both arms. Transfer overhead remains substantial.

Historical offload-on/off results at `f19ebc5b1da1c9b0075eecfd2f93fc6ca4b3ba8d`, before this change, used the same sequence, microbatch count and graph settings:

| Model | Allocated-peak change | Reserved reduction, paired median [range] | Step-time increase, paired median [range] |
| --- | --- | --- | --- |
| Qwen3.5-0.8B, 24 text blocks | +512 bytes | 444 MiB [442, 446] | +21.00% [20.68%, 21.11%] |
| GDN2, 8 blocks | approximately +1 MiB | 258 MiB [248, 286] | +96.45% [96.05%, 96.66%] |

These are measurements of `f19ebc5b1`, not the adjusted GDN2 implementation. The earlier four-block stack at `043e3173451bea74e63c02b197867bf356ad72e9` saved 192 MiB allocated (16.88%) with +58.42% runtime; it excluded vocabulary loss, optimizer updates and CUDA graphs ([raw evidence](https://github.com/Pinoeer-kingxi/Megatron-LM/tree/34371ca51fa2dffb5c362f1c52c89b1801670226/gdn-followup-20261016)).

The option remains disabled by default. Upstream GPU CI, four-card GDN2 composition, pretrained GDN2 and a continuous 200-step graph run are not covered.
