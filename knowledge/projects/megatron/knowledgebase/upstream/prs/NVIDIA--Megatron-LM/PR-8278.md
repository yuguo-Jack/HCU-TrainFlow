# What does this PR do?

Emits canonical training objective and numeric events from values already materialized by Megatron's reporting path.

This is PR 5 of 7 and is intended to be reviewed relative to PR 4.

## Summary

- Maps existing host scalar loss, learning-rate, loss-scale, and norm values to telemetry events.
- Preserves the existing reporting cadence and reporting-rank selection.
- Avoids new device synchronization, tensor materialization, or training computation.
