# Inference: remove the disable_ep_consensus flag

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7926) · state: open · merged: False

## Original PR description

# What does this PR do ?

Removes the inference `disable_ep_consensus` flag (`--inference-disable-ep-consensus`) and the engine control-loop branch that skipped the EP-group consensus all-reduce. The consensus path, throttled by `ep_consensus_interval`, becomes the only path.

Removed:
- `InferenceConfig.disable_ep_consensus` (`megatron/core/inference/config.py`) and the engine attribute + branch in `run_engine_with_coordinator` (`megatron/core/inference/engines/dynamic_engine.py`)
- `--inference-disable-ep-consensus` (`megatron/training/arguments.py`) and `inference_disable_ep_consensus` (`megatron/training/config/inference_config.py`)
- `test_disable_ep_consensus` and the `DummyEngine` attribute (`tests/unit_tests/inference/test_data_parallel_inference_coordinator.py`)
- the two docs references (`docs/mcore-inference-user-guide.md`, `tests/functional_tests/dynamic_inference_functional_tests.md`)

Breaking change: scripts that pass `--inference-disable-ep-consensus` will fail to parse. No functional-test recipe or example in the repo uses it.
