# What does this PR do?
Standardize configuration lifecycle ownership: section validation is parameterless and local; cross-section validation and derivation belong to the container.

- Move RNG/model derivation into the shared container, preserving legacy CLI/YAML model-adapter binding.
- Move scheduler/training/optimizer and RL/training/DDP relationships into zero-input container methods. Keep framework-owned `cfg.finalize()` once-only and preserve derivation order.
- Cross-config derivations are inline in container `_finalize()`. Finalization assigns derived values directly; on failure they may remain populated, but `_finalized` stays false. `validate()` remains read-only.
- Keep pre-container CLI validation at the parsing boundary, including inference-deployment checks that the training container cannot express yet.
- Logger/profiler already meet this lifecycle API contract and are unchanged. Pending CheckpointConfig #8558 is not pulled into this PR.
- Preserve config fields, checkpoint serialization, CLI behavior, and copyright years. This does not redesign existing constructor normalization.
