# What does this PR do?
This is the second of four stacked PRs that introduces a simplified version of DSA. These stacked PRs split PR #[6869](https://github.com/NVIDIA/Megatron-LM/pull/6869).

**Indexer + Training** This PR adds simplified DSA over GQA: a learned indexer selects the top-k keys each query attends to, and main attention runs over only that subset of keys. A summary of the changes in each file is included below.

**Wiring**: This PR also adds the necessary wiring. `DSGroupedSelfAttention` subclasses `SelfAttention` and replaces `submodules.core_attention` with `DSGQACoreAttention`. The original dense core attention is passed through as `dense_core_attention` and instantiated only when `dsa_fwd_skip_dsa` or `dsa_fwd_use_dense_attn` is set — the former runs plain dense attention with a zero indexer loss, the latter runs dense attention for the output while still training the indexer against it. Both are necessary for each stage of DSA training.

`attention.py` gains one hook, `_get_core_attention_extra_kwargs`, returning `{}` by default. DSA needs `hidden_states` inside core attention because the indexer projects from it rather than from Q/K/V.

| File | Change |
|---|---|
| `megatron/core/transformer/experimental_attention_variant/dsa_gqa.py` | **New.** Simplified indexer over GQA: `DSGroupedSelfAttention`, `DSGQACoreAttention`, the simplified indexer, the PyTorch reference sparse-attention paths (dense-mask and gather), and the indexer KL loss. |
| `megatron/core/transformer/experimental_attention_variant/dsa_layer_specs.py` | **New.** `dsa_stack_spec`, derived from upstream's `hybrid_stack_spec`. |
| `megatron/core/transformer/experimental_attention_variant/dsa.py` | Query and key chunked top-k helpers (`fused_qk_topk_chunked`, `_merge_topk_scores`), and indexer loss |
| `megatron/core/transformer/attention.py` | Two base-class hooks: `_get_core_attention_extra_kwargs` (pass extra inputs into core attention) and `_dynamic_core_attention_forward` (raises by default so DSA + dynamic batching fails loudly instead of silently running dense). Needed to pass indexer parameters into Attention forward. |
| `megatron/core/transformer/transformer_config.py` | 31 `dsa_*` fields and validation. Adds six rope fields to base config because the GQA indexer builds its own `RotaryEmbedding` from `config`. |
