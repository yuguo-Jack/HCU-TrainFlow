# What does this PR do?

Add a fast path for uniform greedy sampling in TorchSampling, avoiding request bucketing and redundant indexing when all active requests use top_k=1 and top_p=0.0.

This is a follow-up to https://github.com/NVIDIA/Megatron-LM/pull/7754. The sampling optimization was originally included in that GDP inference PR and was separated at @santhnm2's request so it can be reviewed independently.

The fast path uses per-row argmax, preserves optional gather indices and caller-owned output buffers, and supports speculative token-to-request mappings. Other sampling policies continue through the existing bucketed path.

This PR includes the sampling implementation and its regression test. The GDP kernel and CUDA graph changes remain outside this PR.

### Performance

Re-measured after rebasing onto main e592c042d (includes #7828) on one GB300 in the `mcore_ci_dev` CI image: seeded 48-layer GDP hybrid (800M recipe shape), batch 32, BF16, local CUDA graphs, torch sampling backend, greedy requests. S=4 adds three MTP depths (`num_speculative_tokens=3`). Synchronized wall time per full decode step; two jobs × two ABBA cycles, 8 processes per arm; speedup is the median of paired ratios.

| Decode mode | main | This PR | Speedup |
| --- | --- | --- | --- |
| S=1 | 3.717 ms | 3.585 ms | 1.044× |
| S=4 | 6.925 ms | 6.058 ms | 1.143× |

The sampling call alone (32 requests, 131k vocab) is 2.2× faster for the base decode sample, 5.1× for the 128-row speculative verify, and 3.2× per MTP draft sample. Generated tokens matched exactly across all processes and both arms.

### Validation

Rebased onto main; the conflict with #7828 in `sample_kernel` is resolved by running the greedy shortcut before the request-seed setup. Greedy rows ignore seeds, and the engine already rejects seeded speculative requests. A determinism replay test for the shortcut is added, because `torch_sampling.py` is now a registered determinism kernel source.

On four GB300 GPUs in the CI image, both arms pass the inference sampling, request-seed, text-generation-controller, MTP CUDA-graph, GDP inference, dynamic-engine and determinism-kernel tests, with identical skips.
