## What does this PR do?

Install `nvidia-cudnn-frontend[cutedsl]==1.31.0` in the dev environment, upgrading from 1.29.0. Regenerate `uv.lock` with uv 0.7.2 in the Megatron-LM CI container. Only cuDNN Frontend changes version; existing transitive dependencies and compatible build/Transformer Engine lower bounds are preserved.

Upstream release: https://github.com/NVIDIA/cudnn-frontend/releases/tag/v1.31.0
