# What does this PR do?
**PR 3 of 4** re-slicing #7239. **Stacked on #7453**: the first two commits in this diff are that PR's; review the last commit, `ops/attention: move ...`. It moves the sparse-attention operation code from `megatron/core/transformer/experimental_attention_variant` into `megatron/core/ops/attention`. Every old module path remains as a deprecated forwarder.

Like #7453, the branch is **generated by a script** on top of the SSM move rather than rebased, and is regenerated whenever `main` changes the moved files. The latest regeneration is on the #7453 head built from `a71470918` (`c80af85c5` and `6ae7c9ed6`). It picks up #7617 (the TileLang `tilelang_dsa.py` changes, now in `ops/attention/dsa/kernels/`, and its two new shape tests, which import the canonical path), #7156 (DSA over GQA in the hybrid model: the new `dsa_gqa.py` and `dsa_layer_specs.py`), #8414 and #7521. The script output is the move; re-running it on `ops-move/2-ssm` reproduces this commit apart from the manual steps listed below.

## Layout
| Old (`transformer/experimental_attention_variant/`) | New (`megatron/core/`) |
| --- | --- |
| `dsa.py` | `ops/attention/dsa/modules.py` |
| `dsa_{cudnn_kernels,indexer_loss,kernels,layout,masking,tilelang_kernels}.py` | `ops/attention/dsa/` (same names) |
| `dsa_min_memory.py`, `dsa_min_memory_triton.py` | `ops/attention/dsa/` (same names) |
| `dsa_gqa.py` (DSA over GQA, #7156) | `ops/attention/dsa/dsa_gqa.py` |
| `ops/` (TileLang kernels; a namespace package) | `ops/attention/dsa/kernels/` |
| `csa.py` | `ops/attention/csa/modules.py` |
| `csa_utils/` (including `cp_utils`, `csa_indexer_loss_kernels`, `packed_layout`, `packed_sparse_attention`) | `ops/attention/csa/kernels/` |
| `absorbed_mla.py` | `ops/attention/mla.py` |
| `deepseek_v4_hybrid_attention.py` | `ops/attention/dsv4.py` |
| `deepseek_v4_hybrid_attention_module_specs.py` | `models/gpt/` (a spec builder is model assembly) |
| `dsa_layer_specs.py` (DSA-over-GQA hybrid stacks, #7156) | `models/hybrid/` (derives from `hybrid_layer_specs`) |

`dsa_layer_config.py` and `dsv4_layer_config.py` stay where they are; they move with the layer configs in PR 4. They are the only modules left in `experimental_attention_variant` that are not forwarders.

- `dsa_gqa.py` is a DSA operation (the simplified indexer and the core and self-attention modules for DSA over GQA), so it joins the other DSA modules. `dsa_layer_specs.py` only assembles hybrid stacks from `hybrid_stack_spec` and `gated_delta_product_stack_spec`, so, like the DSv4 module specs, it moves next to the specs it builds on. The docstring's `--spec` example now names the new path; the old one keeps working, because #7453's helper commit lets `spec_utils.import_module` and `_hybrid_inference_stack_spec` resolve names that a forwarder serves through `__getattr__`. With the old path, `--spec ...experimental_attention_variant.dsa_layer_specs dsa_stack_spec` loads the canonical `dsa_stack_spec`, and the inference lookup returns the same result as the new path (`None`, since the module defines no `*_inference_stack_spec`).
- Moved modules change only in import lines; 18 of 31 are byte-identical. The exceptions are the DSA backend table in `dsa_kernels.py`, which names its adapter modules as strings for `import_module`, and the `--spec` usage line in the `dsa_layer_specs.py` docstring. Relative imports that still resolve are kept.
- Every old path has a `deprecated_module` forwarder, including a new forwarder `__init__.py` for the old `ops/` directory, which had none. No old attention package re-exported names, so no forwarder needs `exports=`; the canonical package `__init__` files hold only their docstrings. `FORWARDED` gains 32 entries, which also activates the `DSAttention` canonical-identity and pickle test.
- Updated for the new paths: the determinism kernel manifest, `tools/process_group_usage_allowlist.json`, `CODEOWNERS` (`megatron/core/ops/attention/` keeps the `@NVIDIA/transformer` reviewers of the old path), string paths in tests (`mock.patch` targets, backend module names, the TE-free `dsa_layer_specs` import check), and the ops README layout (`csa/kernels/`, `dsa_gqa.py`).
- The two spec builders take the owners of their new directories: `models/gpt/` (`@NVIDIA/gpt`) and `models/hybrid/` (`@NVIDIA/hybrid-model`).

## How it was generated
```bash
git switch -c ops-move/3-attention ops-move/2-ssm
python ops_move_attention.py   # script below; template was the #7453 script
```
Manual steps after the script:
- the `CODEOWNERS` line;
- re-sorted the two renamed keys in `tools/process_group_usage_allowlist.json` (`check_process_group_usage.py --update` refuses to write while `main` itself fails that check on unrelated files);
- `isort` and `black` on the changed Python files under `megatron/core` and `tests`, and `isort` on the two changed `megatron/training` files;
- merged ten implicitly concatenated patch-target strings that black had put on one line (nine in `test_attention_variant_dsa.py`, one in `test_attention_variant_dsa_gqa.py`);
- the `csa/kernels/` and `dsa_gqa.py` entries in the ops README layout.

Differences from the #7453 script: package prefixes are mapped too (needed for the `ops/` namespace package); a relative import is kept only when every name still resolves to the same target, and is otherwise rewritten relative to the file's new package; `from <old package> import <module>` lines written out in text (a code string run in a subprocess) are rewritten too; the new package docstrings are written by the script; a forwarder `__init__` is written for an old directory that had none; `FORWARDED` entries are appended to the existing table.

Verify the move: `git diff -M -C --find-copies-harder HEAD~1 HEAD` shows the moved modules as `C094`–`C100`. Git also pairs the new forwarder `__init__.py` of the old `ops/` directory with another forwarder; that file is new.

#!/usr/bin/env python3
"""Move the sparse-attention operation code into ``megatron/core/ops/attention``.

Run from the repository root on a clean checkout of the SSM move (``ops-move/2-ssm``)::

    python ops_move_attention.py

The script only moves files (``git mv``), rewrites import paths and path strings, and writes
the forwarder modules, the new package docstrings and the ``FORWARDED`` entries. Formatting
(isort, black) runs afterwards.
"""

from __future__ import annotations

import ast
import importlib.util
import re
import subprocess
from pathlib import Path

ROOT = Path.cwd()
CORE = "megatron/core"
EAV = "transformer/experimental_attention_variant"

# Old module file -> new module file, relative to megatron/core.
FILE_MOVES = {
    f"{EAV}/absorbed_mla.py": "ops/attention/mla.py",
    f"{EAV}/csa.py": "ops/attention/csa/modules.py",
    f"{EAV}/deepseek_v4_hybrid_attention.py": "ops/attention/dsv4.py",
    f"{EAV}/dsa.py": "ops/attention/dsa/modules.py",
    f"{EAV}/dsa_cudnn_kernels.py": "ops/attention/dsa/dsa_cudnn_kernels.py",
    f"{EAV}/dsa_gqa.py": "ops/attention/dsa/dsa_gqa.py",
    f"{EAV}/dsa_indexer_loss.py": "ops/attention/dsa/dsa_indexer_loss.py",
    f"{EAV}/dsa_kernels.py": "ops/attention/dsa/dsa_kernels.py",
    f"{EAV}/dsa_layout.py": "ops/attention/dsa/dsa_layout.py",
    f"{EAV}/dsa_masking.py": "ops/attention/dsa/dsa_masking.py",
    f"{EAV}/dsa_min_memory.py": "ops/attention/dsa/dsa_min_memory.py",
    f"{EAV}/dsa_min_memory_triton.py": "ops/attention/dsa/dsa_min_memory_triton.py",
    f"{EAV}/dsa_tilelang_kernels.py": "ops/attention/dsa/dsa_tilelang_kernels.py",
    # Spec builders are model assembly; each joins the specs it builds on.
    f"{EAV}/deepseek_v4_hybrid_attention_module_specs.py": (
        "models/gpt/deepseek_v4_hybrid_attention_module_specs.py"
    ),
    f"{EAV}/dsa_layer_specs.py": "models/hybrid/dsa_layer_specs.py",
}
# Old package -> new package. Every module directly inside moves under the same name.
PACKAGE_MOVES = {f"{EAV}/ops": "ops/attention/dsa/kernels", f"{EAV}/csa_utils": "ops/attention/csa/kernels"}
# The layer configs (dsa_layer_config, dsv4_layer_config) stay; they move with the other
# layer configs in the next PR of the stack. No old package re-exported names, so no
# forwarder needs ``exports=``.

# Docstrings of the new canonical packages; each holds its contract and re-exports nothing.
NEW_PACKAGES = {
    "ops/attention": (
        "Attention operation modules and kernels.\n\n"
        "Organized by operation family:\n\n"
        "* `dsa` -- DeepSeek sparse attention over MLA and over GQA: the indexer and attention\n"
        "  modules, layout and masking helpers, the indexer loss, the TileLang and cuDNN\n"
        "  backends and the minimum-activation DSA-GQA path.\n"
        "* `csa` -- compressed sparse attention: compressors, indexers and attention modules\n"
        "  with their SBHD and packed THD kernels.\n"
        "* `mla` -- absorbed multi-latent attention.\n"
        "* `dsv4` -- DeepSeek-v4 hybrid attention, built on the CSA modules.\n\n"
        "Model assembly, module specs, layer configs and inference cache allocation stay outside\n"
        "this package. Packages here do not re-export; import each name from the module that\n"
        "defines it.\n"
    ),
    "ops/attention/dsa": (
        "DeepSeek sparse-attention operation modules, kernels and backend adapters.\n\n"
        "Reference attention accepts SBHD or packed THD queries/keys; top-k indices are\n"
        "BSJ and use -1 for invalid keys. Mask/layout helpers define packed and CP index\n"
        "spaces. Indexer loss reduces teacher probabilities over the supplied TP group;\n"
        "``modules`` owns CP all-gathers, parameters and operation checkpoint behavior;\n"
        "``dsa_gqa`` provides the simplified indexer and core attention for DSA over GQA.\n"
        "Cross-layer index-sharing coordination and training-wide logging remain external.\n\n"
        "Fused backends may return None for unsupported runtime shapes/layouts, preserving\n"
        "the reference fallback. Backward, dtype and capture support are backend-specific.\n"
        "Construction binds concrete hooks; this package adds no runtime registry.\n"
        "Importing it alone does not load TileLang, cuDNN, FlashMLA or Hadamard kernels.\n"
    ),
    "ops/attention/dsa/kernels": (
        "TileLang kernel bodies and their autograd adapters, loaded only when requested.\n"
    ),
    "ops/attention/csa": (
        "Compressed sparse-attention modules and kernels.\n\n"
        "Queries are SBHD, shared KV is SBD, and top-k indices are BSJ with -1 for invalid\n"
        "keys; the packed THD path takes final physical indices and explicit process groups.\n"
        "Attention returns SB(HD); teacher log mass is detached FP32. Kernels own no\n"
        "parameters. ``modules`` owns compressors, indexers, rotary embeddings, learnable\n"
        "sinks and operation checkpoint behavior. Cross-layer index sharing is coordinated by\n"
        "model assembly. See each callable for dtype and gradient details; bit-exact\n"
        "determinism is not certified.\n"
    ),
}

# Text files whose path strings and dotted module names are rewritten.
REWRITE_SUFFIXES = {".py", ".md", ".sh", ".json", ".yaml", ".yml", ".rst", ".txt"}
# The deprecated-path regression suite names the old paths on purpose; it is edited by hand.
SKIP_PREFIXES = ("tests/unit_tests/ops/", "CHANGELOG.md")

COPYRIGHT = "# Copyright (c) 2026, NVIDIA CORPORATION. All rights reserved.\n"


def dotted(path: str) -> str:
    """``megatron/core/a/b/__init__.py`` -> ``megatron.core.a.b``."""
    path = path[: -len(".py")] if path.endswith(".py") else path
    path = path[: -len("/__init__")] if path.endswith("/__init__") else path
    return path.replace("/", ".")


def plan_moves() -> dict[str, str]:
    """Old file -> new file, repository-relative."""
    moves = {f"{CORE}/{old}": f"{CORE}/{new}" for old, new in FILE_MOVES.items()}
    for old_pkg, new_pkg in PACKAGE_MOVES.items():
        for path in sorted((ROOT / CORE / old_pkg).glob("*.py")):
            moves[f"{CORE}/{old_pkg}/{path.name}"] = f"{CORE}/{new_pkg}/{path.name}"
    return moves


MOVES = plan_moves()
MODULES = {dotted(old): dotted(new) for old, new in MOVES.items()}
# Packages, including the namespace package ``ops`` that has no ``__init__``.
PACKAGES = {dotted(f"{CORE}/{old}"): dotted(f"{CORE}/{new}") for old, new in PACKAGE_MOVES.items()}
RENAMES = {**PACKAGES, **MODULES}


def map_module(name: str) -> str:
    """Map a dotted name through the longest moved module or package prefix."""
    parts = name.split(".")
    for i in range(len(parts), 0, -1):
        prefix = ".".join(parts[:i])
        if prefix in RENAMES:
            return ".".join([RENAMES[prefix], *parts[i:]])
    return name


OLD_DOTTED = dotted(f"{CORE}/{EAV}")
DOTTED_RE = re.compile(rf"(?<![\w.]){re.escape(OLD_DOTTED)}(?:\.[A-Za-z_]\w*)+")
PATH_RE = re.compile(rf"(?<![\w/]){re.escape(CORE)}/{re.escape(EAV)}(?:/[A-Za-z_]\w*)+(?:\.py|/)?")


def map_path(match: re.Match) -> str:
    text = match.group(0)
    trailing = "/" if text.endswith("/") else ""
    is_file = text.endswith(".py")
    stem = text.rstrip("/")
    stem = stem[: -len(".py")] if is_file else stem
    old = stem.replace("/", ".")
    new = map_module(old)
    if new == old:
        return text
    new_path = new.replace(".", "/")
    if is_file:
        # A stale reference to a module that is now a package points at the package directory.
        if (ROOT / f"{stem}.py").exists() or f"{stem}.py" in MOVES:
            return f"{new_path}.py"
        return f"{new_path}/"
    return new_path + trailing


def package_of(path: str) -> str:
    return dotted(str(Path(path).parent))


def resolve(node: ast.ImportFrom, package: str) -> str:
    if not node.level:
        return node.module or ""
    return importlib.util.resolve_name("." * node.level + (node.module or ""), package)


def relative_to(source: str, package: str) -> str:
    """Spell ``source`` relative to ``package`` when it lives in that package."""
    if source == package:
        return "."
    if source.startswith(package + "."):
        return "." + source[len(package) + 1 :]
    return source


def rewrite_import_statements(path: str, text: str, new_path: str | None) -> str:
    """Rewrite import statements that a textual prefix substitution cannot express.

    * ``from <old package> import moved_module`` binds the moved module under its old name.
    * Relative imports keep their form when they still resolve after the move; otherwise
      they become relative to the file's new package, or absolute when the target is outside.
    """
    try:
        tree = ast.parse(text)
    except SyntaxError:
        return text
    lines = text.splitlines(keepends=True)
    old_package = package_of(path)
    new_package = package_of(new_path) if new_path else old_package
    edits = []
    for node in ast.walk(tree):
        if not isinstance(node, ast.ImportFrom):
            continue
        module = resolve(node, old_package)
        indent = re.match(r"\s*", lines[node.lineno - 1]).group(0)
        groups: dict[str, list[str]] = {}
        if node.level and all(
            f"{resolve(node, new_package)}.{alias.name}" == map_module(f"{module}.{alias.name}")
            for alias in node.names
        ):
            # The relative import still names the same modules and objects after the move.
            continue
        if any(f"{module}.{alias.name}" in RENAMES for alias in node.names):
            for alias in node.names:
                full = f"{module}.{alias.name}"
                if full in RENAMES:
                    parent, _, base = RENAMES[full].rpartition(".")
                    local = alias.asname or alias.name
                    groups.setdefault(parent, []).append(
                        base if base == local else f"{base} as {local}"
                    )
                else:
                    groups.setdefault(map_module(module), []).append(
                        alias.name + (f" as {alias.asname}" if alias.asname else "")
                    )
        elif node.level:
            names = [a.name + (f" as {a.asname}" if a.asname else "") for a in node.names]
            groups[map_module(module)] = names
        else:
            continue
        if node.level:
            groups = {relative_to(source, new_package): names for source, names in groups.items()}
        statement = "".join(
            f"{indent}from {source} import {', '.join(names)}\n" for source, names in groups.items()
        )
        edits.append((node.lineno, node.end_lineno, statement))
    for start, end, statement in sorted(edits, reverse=True):
        lines[start - 1 : end] = [statement]
    return "".join(lines)


# ``from <old package> import <moved module>`` written out in text, such as a code string run
# in a subprocess; real import statements were already rewritten from the syntax tree.
FROM_IMPORT_RE = re.compile(
    rf"\bfrom ({re.escape(OLD_DOTTED)}(?:\.\w+)*) import (\w+)(?: as (\w+))?(?=\s*$)", re.MULTILINE
)


def map_from_import(match: re.Match) -> str:
    module, name, alias = match.groups()
    if f"{module}.{name}" not in RENAMES:
        return match.group(0)
    parent, _, base = RENAMES[f"{module}.{name}"].rpartition(".")
    local = alias or name
    return f"from {parent} import {base}" + ("" if base == local else f" as {local}")


def rewrite_text(text: str) -> str:
    text = FROM_IMPORT_RE.sub(map_from_import, text)
    text = DOTTED_RE.sub(lambda m: map_module(m.group(0)), text)
    return PATH_RE.sub(map_path, text)


def forwarder(old: str, new: str) -> str:
    doc = f'"""Deprecated import path; use ``{new}``."""'
    if len(doc) > 100:
        doc = f'"""Deprecated import path.\n\nUse ``{new}``.\n"""'
    return (
        f"{COPYRIGHT}\n{doc}\n\n"
        "from megatron.core.ops._compat import deprecated_module\n\n"
        f'__getattr__, __dir__ = deprecated_module(__name__, "{new}")\n'
    )


def package_init(doc: str) -> str:
    # A one-line docstring closes on its own line; a longer one closes on the line after.
    doc = doc.rstrip("\n") if "\n" not in doc.rstrip("\n") else doc
    return f'{COPYRIGHT}\n"""{doc}"""\n'


def forwarded_entries() -> str:
    old_packages = {old: new for old, new in PACKAGES.items() if old not in MODULES}
    return "".join(f'    "{old}": ("{new}",),\n' for old, new in {**MODULES, **old_packages}.items())


def git(*args: str) -> str:
    return subprocess.run(["git", *args], check=True, capture_output=True, text=True).stdout


def main() -> None:
    assert not git("status", "--porcelain"), "run on a clean checkout"
    tracked = git("ls-files").splitlines()

    # 1. Rewrite every tracked text file in place (moved files keep their old location for now).
    for path in tracked:
        if path.startswith(SKIP_PREFIXES) or Path(path).suffix not in REWRITE_SUFFIXES:
            continue
        file = ROOT / path
        original = file.read_text()
        if "megatron" not in original and not path.startswith(f"{CORE}/{EAV}/"):
            continue
        text = original
        if path.endswith(".py"):
            text = rewrite_import_statements(path, text, MOVES.get(path))
        text = rewrite_text(text)
        if text != original:
            file.write_text(text)

    # 2. Create the new packages, then move.
    for package, doc in NEW_PACKAGES.items():
        init = ROOT / CORE / package / "__init__.py"
        init.parent.mkdir(parents=True, exist_ok=True)
        init.write_text(package_init(doc))
        git("add", str(init.relative_to(ROOT)))
    for old, new in MOVES.items():
        (ROOT / new).parent.mkdir(parents=True, exist_ok=True)
        git("mv", old, new)

    # 3. Leave a forwarder at every old path, including old packages that had no ``__init__``.
    old_inits = {
        f"{CORE}/{old}/__init__.py": f"{CORE}/{new}/__init__.py"
        for old, new in PACKAGE_MOVES.items()
        if f"{CORE}/{old}/__init__.py" not in MOVES
    }
    for old, new in {**MOVES, **old_inits}.items():
        (ROOT / old).write_text(forwarder(dotted(old), dotted(new)))
        git("add", old)

    # 4. Record the forwarders in the regression table.
    table = ROOT / "tests/unit_tests/ops/deprecated_paths.py"
    text = table.read_text()
    head, sep, tail = text.partition("\n}\n")
    assert sep and head.lstrip().startswith("#") and "FORWARDED = {" in head, "unexpected table"
    table.write_text(head + "\n" + forwarded_entries().rstrip("\n") + sep + tail)


if __name__ == "__main__":
    main()
