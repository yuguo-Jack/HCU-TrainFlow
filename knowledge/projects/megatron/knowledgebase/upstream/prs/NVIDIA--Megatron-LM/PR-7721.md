# What does this PR do?

Selecting `load_workloads(container_tag="fixture", environment="dev", tag="latest")` against the complete recipe set raises `KeyError: 'tag'` on a functional workload instead of selecting the tagged unit-test workloads.

The optional-field guards use `hasattr(dotdict(...), field)`, but `dotdict.__getattr__ = dict.get` returns `None` for missing fields, so `hasattr` always succeeds. Use dictionary lookup with a default for tag, environment, and platform filtering.

The regressions exercise the full current recipe set and all three production filters with matching, nonmatching, and missing fields.
