# bug fix: preserve saved-tensor observer until CUDA graph capture

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8850) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Fixes a bug introduced by https://github.com/NVIDIA/TransformerEngine/pull/3523, introduced in TE 2.21 (#8792).

Keep the saved-tensor observer enabled when `create_cudagraphs()` is called before any training graphs have been recorded. GRPO's forward-only old/reference logprob passes can reach this empty-create path before the first training forward. Previously, the outer `finally` removed the observer even though no capture had occurred.
