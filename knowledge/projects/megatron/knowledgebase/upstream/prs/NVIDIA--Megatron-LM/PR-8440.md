# Reject nonzero padded GTP Muon momentum before distributed NS

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8440) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Distributed GTP Muon retains alignment padding during Newton–Schulz. Nonzero or non-finite momentum in those rows can contaminate the global normalization and Gram matrix, changing updates to real weights.

Validate the padded momentum and raise `ValueError` when any padded entry is nonzero, including NaN or infinity. Leave the input unchanged. Handle partial padding and fully padded shards, and propagate the failure across GTP and, when TP is also a sharding axis, TP. Every NS participant raises before any momentum gather, normalization, or Gram all-reduce.

This validation adds scalar validity reductions for padded parameters. Raising a Python `ValueError` based on CUDA contents necessarily synchronizes with the host, even though there is no explicit `.item()` call. Unpadded parameters skip the new check. Existing logical-shape scaling is unchanged.

## Validation

- Expanded padded tests cover six GTP/TP layouts, including either TP or GTP larger, with zero, finite nonzero, tiny nonzero (`1e-30`), NaN, and both infinities. Poison only one rank; assert that all participants raise before a momentum gather or NS and that the input remains unchanged.
- Passed all 36 padded validation cases plus three unpadded parity cases on eight CPU/Gloo ranks. The test workers ran with CUDA device literals and process-group bootstrap adapted for CPU; the public optimizer, EO v0.4.0 math, and collectives were real, with unavailable GPU imports isolated. Unmodified main fails the rejection regression test.
- `tools/autoformat.sh`: Black, isort, pylint, and Ruff passed. With EO source available, mypy reports the same four errors as unmodified main. `git diff --check` passed.
- GPU/NCCL tests remain unrun locally. CI validation command:

```bash
python -m torch.distributed.run --nproc-per-node=8 -m pytest -q \
  tests/unit_tests/generalized_tensor_parallel/test_gtp_muon.py \
  -k padded_distributed_parity
```
