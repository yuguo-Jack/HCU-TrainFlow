# [Dev] [DO NOT MERGE] DSA training optimizations: reference stack

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8835) · state: open · merged: False

## Original PR description

> **Do not merge.** This is a reference and tracking PR. It collects the DeepSeek Sparse Attention (DSA) training work developed for GLM-5.x and GLM-5.3-Flash into one stack on `dev`, as a reference for models built on DSA. Each piece that is already under review upstream is carried as one squash commit, marked "(PR N)". Those PRs, and future per-feature PRs, are the merge vehicles. The GLM-5.2/5.3 integration stack (#6944) and the GLM-5.3-Flash stack (#8400) build on this one and carry only non-DSA work.

The feature guide added by the last commit, `docs/user-guide/features/dsa.md`, documents every option, its default, the rules between options, and the library versions.

## Known issues and overlaps

- **#6472 removes `DSAttention._get_index_share_topk_holder`**, which Megatron-Bridge's GLM hybrid attention overrides.
- **#6793** (approved, `main`) isolates the index-share holder during recompute with a different design. #6472/#7107 need to be reconciled with it.
- **#7813** proposes a configurable cuDNN top-k tie-break that overlaps commits 10 and 13.
- **Experimental backends.** DeepSelect has no tagged release; the tuned build used here is published at buptzyb/DeepSelect@ee633040be. DeepGEMM was measured on 2.8.2+5081f85; dev pins 2.8.0. MXFP8 selection recall is below the BF16 scorer's (see the guide).
- **Determinism coverage.** The kernel-determinism coverage check flags several DSA sources whose determinism tests this stack does not edit.
