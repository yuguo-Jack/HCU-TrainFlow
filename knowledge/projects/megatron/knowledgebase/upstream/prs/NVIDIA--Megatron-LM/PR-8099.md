# Reject non-finite confidence in community assignment decisions

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8099) · state: closed · merged: False

## Original PR description

Infinity in model analysis is clamped to confidence 1.0, allowing malformed confidence values to satisfy the automatic assignment threshold. Treat non-finite confidence as the default before clamping.

Validation: non-finite numeric and string forms fail the baseline regression and pass with the fix; valid confidence remains unchanged. CPU unit tests use the actual helper and no external mutations. Test formatting, source import sorting, and Python compilation pass.
