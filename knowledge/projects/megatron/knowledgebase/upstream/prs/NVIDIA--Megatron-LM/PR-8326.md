# Fix MFSDP v2 checkpoint test setup and teardown

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8326) · state: closed · merged: True

## Original PR description

## What does this PR do?

Fix an order-dependent failure in the MFSDP v2 checkpoint test. In #8274, PR CI selected `test_ep_fsdp_checkpoint_roundtrip` (added by #8230) before the expert-parallel tests. The checkpoint test did not request `distributed_setup`, so `DBuffer.is_symmetric_memory` could lock in PyTorch's default CUDA symmetric-memory backend, even when querying an ordinary tensor. All 16 subsequent expert-parallel cases then failed in setup when the fixture tried to select NCCL: `Backend can not be changed after use.`

- Request `distributed_setup` explicitly in `test_ep_fsdp_checkpoint_roundtrip`, selecting NCCL before model-parallel initialization.
- Clear DTensor's sharding-propagation cache before the fixture destroys process groups. Once the checkpoint test uses this teardown, cached meshes can otherwise refer to destroyed groups in the next parameterized case. This applies the adapter cleanup fix from #6215 to the shared fixture, with a TODO referencing #7322.

The fixture remains opt-in. The adapter fixture refactor in #7710 is independent of this two-file fix.

## Validation

Tested on two RTX A6000 GPUs with NGC 26.08 / PyTorch `2.14.0a0+4fdf77b940.nv26.08`, using `torch.distributed.run` and the `not flaky and not flaky_in_dev` marker filter:

- Run checkpoint EP=1 and EP=2 first, followed by `test_expert_parallel.py`, `test_annotation.py`, and `test_dbuffer.py`: **50 passed, 36 skipped per rank**. The 16 expert-parallel cases pass setup and skip because they require EP=4; the other skips require more ranks. Four-rank execution remains for CI.
- With only the explicit fixture dependency, EP=2 after EP=1 fails with `Could not resolve the process group registered under the name 3`. Adding the cache clear resolves this failure.
- Black, isort, Ruff, Pylint, and diff whitespace checks passed. Existing test bodies and parameterization are preserved.
