# [DSv4.1] V4.1 text model composition on HybridStack

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8226) · state: open · merged: False

## Original PR description

Compose V4.1 CSA2, Engram and single-pass mHC on the existing HybridStack layer loop. A model-owned live-field schema carries state through PP/VPP, one-layer full recomputation and explicit Torch/TE graph capture. Include direct/HF config conversion and correct shared-hash checkpoint replica metadata.

Dependencies: #7678 (generic tensor state), #8223, #8224 and #8225. The draft includes prerequisite history so it builds; the model-specific change is https://github.com/FDecaYed/Megatron-LM/commit/241a76cb48f1a6e678512f1dcc86a76a472b3643. The generic state code follows @guihong-nv's #7678, with local Gloo wait and test-lifecycle follow-ups. Composition is adapted from @guihong-nv in #7500/#7501 and @hxbai in #7224. Rebase away prerequisite commits as they land; the final merge target is main.

Validation on H100: eager/checkpoint/PP gradient parity, PP2/CP2 and VPP2 transport, Torch and TE capture with two in-flight slots, and 8-GPU DP2/EP2/PP2/CP2 training plus checkpoint save/resume passed. Full/Reindex/Reuse capture passed; Engram-bearing and variable-token MoE layers are explicitly excluded from capture. Black/isort/Ruff/Pylint and diff checks passed.

Scope: text backbone only; no vision, DSpark or automatic CLI graph warmup. Small proxy models qualify functionality, not released-model convergence or production performance.

Synchronized the current prerequisite heads and their CI test-contract fixes. Revalidated Torch/TE graph replay, typed PP transport, CP parity, fused mHC recomputation, VPP and 8-GPU combined training after the mHC/CSA2 performance updates.
