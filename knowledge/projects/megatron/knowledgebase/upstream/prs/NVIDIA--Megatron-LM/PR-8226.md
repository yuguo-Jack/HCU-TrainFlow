# [DSv4.1] V4.1 text model composition on HybridStack

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8226) · state: open · merged: False

## Original PR description

Compose V4.1 CSA2, Engram and single-pass mHC on the existing HybridStack layer loop. A model-owned codec/adapter declares live KV, indexer, mHC and token state, then uses the generic APIs from #7678 for PP/VPP, one-layer full recomputation and explicit Torch/TE graph capture. Include direct/HF config conversion and shared-hash checkpoint metadata.

Dependencies: #7678, #8223 (mHC), #8224 (CSA2) and #8225 (Engram). The PR remains based on `pull-request/7678`; generic capture/transport changes belong to #7678. Other prerequisites remain in the stack until their bases are updated.

The model adapter preserves FP8 recompute and graph contexts; model configuration restricts MXFP8 indexer selection to V4.1 CSA2. Composition follows @guihong-nv's #7500/#7501 and @hxbai's #7224.

Validation: H100 checkpoint/PP owner-gradient tests, Torch/TE Full/Reindex/Reuse graph profiles, 8-GPU DP2/EP2/PP2/CP2 train/save/resume, VPP, full recompute and 16K CP2 training passed. The assembled stack also completed the 16-GB200 BF16 and MXFP8 proxy recipes with distributed Muon, static packed data and MoK. That proxy has Engram and CUDA graphs disabled; their correctness coverage comes from the separate component/integration tests. It is not a convergence or full-model cross-branch gradient-parity claim.

Scope: text backbone, TP1; no vision, DSpark or automatic CLI graph warmup. Engram-bearing and variable-token MoE layers remain outside layer capture. Keep the dependent stack draft while the generic execution API is reviewed.
