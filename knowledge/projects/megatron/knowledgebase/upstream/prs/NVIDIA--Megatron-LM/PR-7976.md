# fix(inference): support request-local FlashInfer sampling seeds

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7976) · state: closed · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Enable request-local seeded sampling in dynamic FlashInfer inference. Pass per-request `seed` and absolute token-position `offset` tensors through all four sampling dispatches, including saved positions for pending logits during async overlap. Reserve a disjoint 2^32-draw interval per token for rejection sampling.

Group seeded requests by filter mode so batch mates cannot change their sampling algorithm. Sample unseeded requests with the shared generator; seeded draws leave its state untouched. Allow seeded FlashInfer requests through engine admission while preserving speculative-seeding and missing-metadata errors.

**Draft — merge after the FlashInfer dependency bump.** Depends on #7828, the merged [per-row tensor-indexing fix](https://github.com/flashinfer-ai/flashinfer/pull/5745), and [FlashInfer #6251](https://github.com/flashinfer-ai/flashinfer/pull/6251) for batch-independent Philox subsequences. The current dependency pin does not include the required fixes. The batch-reordering tests now pass normally against the upstream patch, and the engine backend restriction is removed in this draft.
