# [MFSDP] Bypass gradient packing when inner reduction is unnecessary

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8949) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

When gradients can reach their accumulation placements without inner communication, MFSDP still allocates a packing buffer and copies gradients through it. Accumulate directly into `main_grad` instead, including HSDP/HFSDP with a singleton inner DP axis.

Each parameter group computes `requires_inner_reduction` from its existing mesh and gradient placements. Groups requiring communication retain the packed path. Other groups accumulate on the inner reduction stream in `main_grad.dtype`, avoiding communication-dtype casts. Explicit stream dependencies keep source gradients alive until accumulation finishes.

The local path preserves microbatch accumulation, both `zero_grad` modes, and deferred outer reduction. It intentionally removes `grad_comm_dtype` rounding from local accumulation.

## Related work

This PR covers gradient packing and local accumulation. #8828 separately reuses model-weight storage. **Both target `main`, have no dependency on each other, and can merge in either order.** This PR's placement check does not require the weight-view or alias APIs in #8828.

Fused gradient scaling is implemented separately in #8393, which is stacked on this PR using the `pull-request/8949` base. Retarget #8393 to `main` before merging this PR so its review remains open. No isolated performance gain is claimed here.

## Validation

Agent-run checks of the gradient-only branch, without #8828's weight optimization, in the development CI Docker image on two RTX A6000 GPUs:

- Gradient accumulation and CUDA-graph tests: **13 passed per rank**, three MXFP8 cases skipped, one symmetric-memory case excluded.
- Test-selection checks: **27 passed**.
- Black, isort, Pylint, and Ruff passed; optional mypy was unavailable.

`test_grad_comm_dtype.py` is renamed to `test_gradient_accumulation.py`, preserving its three existing tests and adding training parity for replicated DP, singleton-inner HSDP/HFSDP, and both `zero_grad` modes. A separate CUDA-graph test covers local accumulation with an outer reduction stream. MXFP8 hardware execution and larger meshes remain unverified on Ampere.

### Update the buffer-allocation tests for singleton meshes

With `torchrun --nproc-per-node=1`, the retained [plain-parameter dtype test](https://github.com/NVIDIA/Megatron-LM/blob/457e530bbf11061cadf8c8b29605e1d3cf075a8e/tests/unit_tests/distributed/mfsdp_v2/test_gradient_accumulation.py#L65-L98) now fails in all three parametrizations. The new [routing predicate](https://github.com/NVIDIA/Megatron-LM/blob/457e530bbf11061cadf8c8b29605e1d3cf075a8e/megatron/core/distributed/fsdp/src/megatron_fsdp/experimental/parameter_group.py#L619-L626) correctly selects local accumulation for its one-rank `Shard(0)` mesh, so `allocate_partial_grad_buffer()` is never called and `allocated_dtypes` is `[]`. The assertion still requires one allocation. The [MXFP8 test](https://github.com/NVIDIA/Megatron-LM/blob/457e530bbf11061cadf8c8b29605e1d3cf075a8e/tests/unit_tests/distributed/mfsdp_v2/test_gradient_accumulation.py#L144-L161) similarly requires two allocations on Blackwell, although neither group needs packing on one rank.

Keep the local path and update both tests to distinguish singleton meshes from communicating meshes. Replace the [plain assertion](https://github.com/NVIDIA/Megatron-LM/blob/457e530bbf11061cadf8c8b29605e1d3cf075a8e/tests/unit_tests/distributed/mfsdp_v2/test_gradient_accumulation.py#L96) with:

```python
expected_dtypes = [expected_comm_dtype] if distributed_setup.world_size > 1 else []
assert allocated_dtypes == expected_dtypes, allocated_dtypes
```

Replace the [MXFP8 assertion](https://github.com/NVIDIA/Megatron-LM/blob/457e530bbf11061cadf8c8b29605e1d3cf075a8e/tests/unit_tests/distributed/mfsdp_v2/test_gradient_accumulation.py#L161) with:

```python
expected_dtypes = [expected_comm_dtype] * 2 if distributed_setup.world_size > 1 else []
assert allocated_dtypes == expected_dtypes, allocated_dtypes
```

These expectations follow the tests’ fixed placements: singleton meshes must allocate no packing buffer; larger meshes must retain one allocation per parameter group. Preserve all three dtype-policy cases, the public-gradient dtype checks, the MXFP8 group/policy checks, and the hardware skip.

**Proposed acceptance checks:** Run both parametrizations with one and two CUDA ranks, using Blackwell for MXFP8. One rank must produce `[]`; two ranks must produce `[expected_comm_dtype]` for the plain group and `[expected_comm_dtype] * 2` for MXFP8. The retained dtype assertions must also pass.
