# Reuse compiler caches for GDN norm fusion unit tests

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7987) · state: closed · merged: False

## Original PR description

## What does this PR do?

Persist compiler caches for the GDN gated output norm fusion unit-test bucket so repeated CI runs can reuse compiled kernels. In [this H100 run](https://github.com/NVIDIA/Megatron-LM/actions/runs/37801915793/job/113414234258), pytest took 30m48s; cold compilation contributes to the repeated cost.

The launcher places Triton, TorchInductor, and TileLang caches under the existing repository bind mount. The composite action restores them best-effort using a namespace derived from the platform, GPU model/capability, Python, installed packages, Torch revision, CUDA version, and dependency/build inputs. Framework content keys continue to validate individual kernels when source changes. Only successful trusted main-branch Testmon baseline runs publish reusable caches.

All 138 test node IDs and numerical assertions remain unchanged. Full, Testmon-selected, and baseline runs retain their existing selection behavior; cache misses compile normally and single-nodeid execution requires no earlier warm-up test. This PR is independent of the other unit-test runtime changes.

## Validation

- 21 focused CPU tests passed for cache identity invalidation, optional restoration/publication guards, and actual launcher environment/bind-mount wiring across full/enforce/baseline modes with absent or existing cache directories.
- An existing BF16 strided GDN norm forward/backward test passed in separate one-rank GPU processes with cold and then persisted caches on RTX 6000 Ada: 2.41s cold, 0.98s warm pytest runtime. Five compiled artifacts retained identical content hashes and modification times, confirming real Triton cache reuse.
- This local check does not establish end-to-end H100 bucket savings; Inductor and TileLang were checked for environment support and wiring, without a complete GPU bucket benchmark.
- `BASE_REF=main CHECK_ONLY=true SKIP_DOCS=false bash tools/autoformat.sh`: Black, isort, Pylint and Ruff passed. The script's nonblocking mypy step reports missing PyYAML stubs and NeMo Run type metadata.
- `git diff --check` passed.
