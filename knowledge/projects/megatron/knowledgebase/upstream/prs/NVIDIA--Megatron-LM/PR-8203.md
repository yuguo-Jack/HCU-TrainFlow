# Fix FP8/FP4 context loss during GDN and KDA recompute

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8203) · state: closed · merged: True

## Original PR description

When selective `gdn` recomputate is enabled with FP8/FP4, checkpoint replay loses TE's quantization context. Projection GEMMs fall back to BF16 during recomputation and backward. With MXFP8 parameter gathering enabled, this can also cause a missing `main_grad` error.

Use `te_checkpoint` for FP8/FP4 in GDN and KDA to preserve the quantization context, keeping the existing checkpoint path for non-quantized configurations.

Validated with 12 GPU regression cases and a single-node, four-GPU Qwen-style proxy covering MXFP8, NVFP4, and MXFP8 parameter gathering.
