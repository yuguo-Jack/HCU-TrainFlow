# What does this PR do?

Keep `--enable-gpt-oss` on YaRN for both the rotary module and the embedding constructor, so the published GPT-OSS recipe does not also add a learned absolute position table.

## What changed

`modelopt_gpt_hybrid_builder` set `config.position_embedding_type = "yarn"` and still passed `args.position_embedding_type` into `GPTModel` and `HybridModel`. `examples/post_training/modelopt/conf/openai/gpt-oss-20b.sh` never sets `--position-embedding-type`, so that argument stays at the CLI default, `learned_absolute`.

`GPTModel` uses the config attribute for `YarnRotaryEmbedding` and the constructor argument for `LanguageModelEmbedding`. The embedding allocates `position_embeddings` only for `learned_absolute` and adds it in forward. The recipe's table is 40960 × 2880 (about 236 MB in bf16), with no GPT-OSS weights to load into it. `HybridModel` uses only the constructor argument, so the same flag never enabled YaRN on a hybrid export.

The builder now passes `yarn` into both constructors when `--enable-gpt-oss` is set. The CLI argument itself is left unchanged. YaRN factors on the config are unchanged.

## Tests

`tests/unit_tests/post_training/test_gpt_oss_position_embedding.py` builds through `modelopt_gpt_hybrid_builder` with the recipe's position type:

- GPT export: rotary type is `yarn`, and `embedding.position_embeddings` is absent.
- Hybrid export: constructor type is `yarn`, and the learned table is absent.
- `--enable-gpt-oss` off with `learned_absolute` still allocates the table.

Ran these three tests against the real builder function. They fail on `ef8cd10b8` and pass with this change. Full `pytest` collection of Megatron was not run here: this machine has no `modelopt` or Transformer Engine, and the local torch builds cannot import `megatron.core`.

`BASE_REF=main CHECK_ONLY=true bash tools/autoformat.sh` reports the new test as already black and isort clean. `model_builder.py` is outside that script's `megatron/core` and `tests/` paths. Local pylint 3.3.5 stops on `.pylintrc` option `bad-builtins` before it scores the file.
