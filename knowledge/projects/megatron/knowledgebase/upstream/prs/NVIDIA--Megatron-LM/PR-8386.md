# build: update Pillow to 13.0.0 on core_r0.20.0

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8386) · state: closed · merged: True

## Original PR description

Megatron-LM's `dev` extra resolves Pillow 12.3.0, which is affected by seven newly disclosed Pillow vulnerabilities (CVE-2026-112393, CVE-2026-112896, CVE-2026-112900, CVE-2026-112396, CVE-2026-112404, CVE-2026-112403, and CVE-2026-112398). Pillow 13.0.0 is the upstream patched release.

Require Pillow >=13.0.0 in the `dev` extra and regenerate `uv.lock`. The lockfile retains the reproducible 13.0.0 resolution while permitting future patched releases.

Validation: `uv lock` and `uv lock --check` passed inside the Megatron-LM CI container with CUDA 13.4; `git diff --check` passed. CI should validate the dependency with the full project environment.
