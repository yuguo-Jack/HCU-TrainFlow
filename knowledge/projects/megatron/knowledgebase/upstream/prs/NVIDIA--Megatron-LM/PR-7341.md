# Support independent expert optimizer instances in MFSDP v2

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7341) · state: open · merged: False

## Original PR description

## Summary

  Building on #7277, this change adds `expert_num_distributed_optimizer_instances` so dense and expert parameters can use independent instance counts.

  - Defaults to `num_distributed_optimizer_instances`, preserving existing behavior.
  - Reuses outer process groups when instance counts match.
