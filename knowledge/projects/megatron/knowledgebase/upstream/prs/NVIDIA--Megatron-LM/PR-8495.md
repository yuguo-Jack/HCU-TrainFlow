# [dev] Add CPU DCP schedulers, cost models and async lookahead

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8495) · state: open · merged: False

## Original PR description

Variable-length DCP training can select either independent in-tree CPU solver and prepare one future schedule while the current batch trains. Both solvers run on the existing classic CP ProcessGroups/TE path, without a custom native transport build. Candidate widths are supported power-of-two divisors of DP×CP; starts align to each group's width. Search remains enabled, and the baseline-only diagnostic is opt-in.

Includes the lightweight and DynamicUSP solvers, all three cost models and their unchanged parameter/provenance/license assets, a persistent CUDA-hidden CPU worker, sync/async controls and telemetry, logical/physical length gathering, dataloader/rerun/training integration, topology-aware heuristic scheduling over legal classic groups, packaging, docs and tests. Generic planner geometry retains arbitrary-width support; DynamicUSP retains its original aligned power-of-two allocation policy. The temporary upstream U8 all-to-all/ring cost profile is a scheduling proxy, not a native-P2P calibration.

This is the prerequisite split from #6801 and targets `dev` `ff20ed54650dd47ba21989767dfc0068d8c6f73e`. Native transport, logical CP descriptors, functional arbitrary CP, and attention/MoE/MTP/layout changes remain in #6801, which also depends on NVIDIA/TransformerEngine#3420. This PR has no dependency on that TE change. Actual diff: **39 files, +7,218/-58**.
