# Batch packed MTP context-parallel boundary exchanges

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8389) · state: closed · merged: True

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

Packed MTP currently exchanges CP boundary tokens once per document. This change batches all documents into one boundary vector per neighbor per roll, and vectorizes local packed rolls and HSM boundary translation.

With zigzag CP > 1, physical document lengths must be divisible by `2 * cp_size`; invalid lengths raise `ValueError`. Slots after the final document roll as a separate segment, ending in zero.

Port of [#609](https://github.com/NVIDIA-NeMo/nv-mistralai-megatron/pull/609), retaining public main's first/last-dimension support, contiguous layout, and communication on the CP group. Original SHA references are in the commit messages.

Validation: formatting/lint and focused CPU/Gloo checks passed. GPU tests were not run; `mypy` was unavailable.
