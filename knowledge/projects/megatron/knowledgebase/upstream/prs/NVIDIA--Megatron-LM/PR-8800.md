# Add shared-parameter looped decoder execution for training

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8800) · state: open · merged: False

## Original PR description

For a decoder with physical layers `0,1,2,3`, setting the shared middle to `[1,3)` with three total executions now runs `0,1,2,1,2,1,2,3`. Layers remain registered once, so Parameters, optimizer allocation, layer numbers and checkpoint layer axes retain physical-layer semantics. Final normalization runs once after the suffix. The default repeat count is one.

This is an intentionally limited training primitive for the ordinary `TransformerBlock` forward path. It does not complete Dory model support or close #8576. `GPTModel` is deprecated for new features, so API placement and acceptance of this initial scope need maintainer agreement; `HybridModel` explicitly rejects the options rather than silently ignoring them.

The first version accepts dense BF16, TP=PP=CP=EP=1, DP1/2, ordinary Megatron DDP and optional distributed Adam with communication overlap disabled. Unsupported recompute, quantization, offload, CUDA graphs, FSDP, MTP, heterogeneous/special residual paths, schedule-plan execution, cached inference and intermediate extraction fail early.

A small prerequisite fix gives each native Torch Adam parameter its own restored step tensor. Without it, an ordinary non-looped checkpoint resume increments a shared counter once per parameter and changes the next update. A CPU regression reproduces the original mismatch with real Torch AdamW updates.

Validation uses an independently constructed flat decoder with reference Parameters tied by physical layer. It checks outputs, all parameter gradients, one FP32-master Adam update, optimizer allocation, ordinary/sharded model keys, and distributed checkpoint restore plus the next update. Restored master weights and moments are poisoned with NaN before loading and compared after loading; native distributed optimizer common metadata is also read from disk.

The acceptance harness uses rank-distinct causal-LM samples and an equivalent single-model global-batch reference; distributed Adam comparisons cover only each rank's owned gradient shards and aggregate optimizer moment sizes across DP. Repeat counts 1/2/3 with both optimizer modes preserve 5,322,240 parameters and 10,644,480 Adam moment elements for the four-layer hidden-256 model.

Related unit/regression tests: **149 passed, 19 skipped** (missing TE or additional GPUs). Changed Python files pass isort, Black, Ruff and Pylint checks.

Validation environment: one RTX 4090 24GB, PyTorch 2.12.1+cu130, local transformer backend in the existing AutoDL container, not the pinned CI image. DP1 NCCL output, gradient, update and resumed-next-update comparisons are bit exact. Supplemental DP2 Gloo diagnostics use two processes sharing that GPU and an external adapter disabling CUDA communication coalescing unsupported by Gloo; those are not two-GPU NCCL qualification.

Two distinct GPU NCCL validation and Transformer Engine validation remain outstanding. This PR stays draft while those hardware/backend checks and the API/scope discussion are pending.

Refs #8576.
