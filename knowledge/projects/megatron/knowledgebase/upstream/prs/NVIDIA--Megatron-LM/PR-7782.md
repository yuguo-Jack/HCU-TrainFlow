# fix(moe): keep expert RNG seeds distinct across pipeline stages

# What does this PR do?

Gives the pipeline rank its own stride in the expert RNG seed, so experts on different pipeline stages no longer start from identical weights.

`_set_random_seed` offsets the seed by `100 * pp_rank` and `model_parallel_cuda_manual_seed` adds `100 * ep_rank` on top, so the expert seed depended only on `pp_rank + ep_rank`. With pp 4 / ep 8 that is 11 distinct expert seeds for 32 shards.

- `model_parallel_cuda_manual_seed()` takes an optional `pp_rank` (default 0) and adds `(1 << 24) * pp_rank` to the expert seed only. The stride sits above the remat strides, so the expert remat seeds derived from it stay distinct too. It defaults to 0 instead of falling back to `parallel_state` like the other ranks: the per-stage offset is a `_set_random_seed` convention, and this avoids a new global read in `megatron/core`.
- `_set_random_seed()` passes its `pp_rank`.

Seeds on pipeline stage 0 are unchanged, and so are the data-parallel and tensor-parallel streams on every stage and any direct caller of `model_parallel_cuda_manual_seed()` that does not pass `pp_rank`. Expert init does change on pipeline stages >= 1, so golden values of the MoE functional tests with pp >= 2 will need a refresh.

#4828 reworks the strides in the same function but keeps the `100 * pp_rank` offset in `_set_random_seed`, so it pushes the collision out to large pp rather than removing it (numbers in the issue). The change here is one line in that function and easy to rebase either way.

## Testing

Added `test_expert_parallel_seed_differs_across_pipeline_ranks`, which runs `_set_random_seed` for (pp=0, ep=1) and (pp=1, ep=0) and compares the expert tracker states.

I have no GPU on this machine, so I ran the new test on CPU with the CUDA generator calls aliased to the CPU generator: it fails on `main` (identical states) and passes on this branch. The rest of `test_random.py` and the functional tests need CI.

The repro script from the issue, same CPU setup:

| | `main` (e998be0) | this branch |
|---|---|---|
| expert seed (pp=0, ep=1) | 2358 | 2358 |
| expert seed (pp=1, ep=0) | 2358 | 16779574 |
| identical expert init | True | False |

Distinct expert seeds over all (pp, ep, etp) ranks, seed arithmetic only: pp 4 / ep 8 goes from 11 to 32 of 32, pp 8 / ep 64 / etp 4 from 284 to 2048 of 2048.
