# Decide CUDA graph reuse from the graphed module's pipeline group

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8032) · state: closed · merged: False

## Original PR description

**Why.** `CudaGraphManager` reuses graphs across microbatches only without pipeline parallelism, and reads the PP size from the global grid in `__init__`. Modules create the manager in `GraphableMegatronModule.__init__`, before they store their `pg_collection`, so a model on its own grid gets the global grid's decision. For example, a PP=2 model on a global PP=1 grid reuses graphs, and their static buffers, across interleaved microbatches. Without an initialized global grid, building a graphed layer fails. The training loop also does not pass the model's collection to `TECudaGraphHelper`, which then builds its capture P2P schedule and FP8 amax group from the global grid.

**What.**
- `CudaGraphManager` resolves the pipeline group on the first call:
  - from its own `pg_collection` argument;
  - otherwise from the graphed module's collection, where `pp=None` means no pipeline parallelism;
  - only when neither sets `pp`, from the global grid, reading just the pipeline group.
- `MambaLayer` stores its `pg_collection`.
- `train()` passes the model's collection to `TECudaGraphHelper`.

**Tests.** New tests cover a function-wrapped module, `TransformerLayer` and `MambaLayer`, each with a global PP of 1 and a model PP of 2, and the reverse, while the collection shim is patched to fail. They failed on main when checked before the sync. A seventh new test checks that a module without a collection keeps the global fallback. On 4 GPUs against its base, `test_cuda_graphs.py` has 83 passed here vs 76 on the base: the 7 new tests pass and no existing test regresses. Before the sync, `test_mamba_layer.py` also matched main. In the integration run, this PR's test files show no regressions against main.

**Compatibility.** No change on the standard grid. Modules without a collection keep the global fallback. `CudaGraphManager.reuse_cudagraphs` is `None` until the first call.
