# ci: Restore AWS H100 image builds to CPU runners

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8241) · state: closed · merged: True

## Original PR description

Cache population started running AWS H100 image builds on GPU runners after #8102 removed the maintainer CPU override. These builds fail during ECR login with `error storing credentials ... not implemented`, preventing scheduled Testmon baseline refreshes. Example: https://github.com/NVIDIA/Megatron-LM/actions/runs/38616202277/job/116032036408.

Restore `nvidia-ci-aws-cpu` for maintainer AWS H100 image builds. Keep the exported `matrix.runner` unchanged so Testmon baseline jobs continue using GPU runners. GCP builds, GB200 builds, and external contributor runner routing retain their existing behavior.
