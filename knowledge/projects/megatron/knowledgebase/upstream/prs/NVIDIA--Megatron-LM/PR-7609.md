I found two issues: the new dispatcher changes two-stage KDA's rounding contract, and the sigmoid specialization lacks the required bit-exact replay coverage. I inspected all nine changed files and their directly affected paths. Tests weren't executed.

### 1. Preserve two-stage KDA's single-rounding normalization

**Failure:** When both `kda_two_stage_gates=True` and `gdn_gated_output_norm_fusion=True`, the new [KDA dispatcher](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/megatron/core/ssm/gated_delta_net/kda.py#L251-L265) bypasses the existing [two-stage normalization branch](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/megatron/core/ssm/gated_delta_net/kda.py#L273-L281), which deliberately rounds only after normalization and sigmoid gating. The replacement kernel instead [rounds normalization before gating](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/megatron/core/fusions/fused_gated_norm.py#L64-L75) and [rounds its incoming normalization gradient](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/megatron/core/fusions/fused_gated_norm.py#L128-L139). Those boundaries match direct-gate KDA, not two-stage KDA.

A source-derived counterexample is CUDA BF16 `x=ones(1,1,1,128)`, BF16 gate logits of one, contiguous FP32 normalization weights of `1.00390625`, epsilon `1e-6`, and zero-centered gamma disabled. Final-only rounding produces BF16 `0.734375`; rounding normalization first produces `0.73046875`. These values are derived from the formulas, not an executed test. The existing [two-stage precision regression](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/tests/unit_tests/ssm/test_kda_gate_precision.py#L77-L95) checks final-only rounding but doesn't enable the new option.

**Correction:** Two-stage KDA already uses the fused FLA `rms_norm_gated` implementation. Preserve that path rather than imposing the direct-gate materialization boundaries. Immediately after `validate_gated_norm(...)` in `_apply_gated_norm`, insert:

```python
            if self.two_stage_gates:
                return self._apply_gated_norm_unfused(x, gate)
```

This keeps enabled-call validation before dispatch and leaves direct-gate KDA on the new sigmoid specialization. Update the [execution documentation](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/docs/developer/gdn_ew_fusion.md#L75-L80) to distinguish two-stage KDA's existing FLA fusion and final-only rounding from the shared Triton path. Please verify the suggested insertion before adopting it.

**Preservation and acceptance:** Extend the two-stage precision regression to enable this option: the counterexample above should produce `0.734375` both enabled and disabled, and the existing random-input mean absolute error assertion `< 2e-5` should remain satisfied. Add enabled/disabled two-stage module comparisons for outputs, input gradients, normalization-weight gradients, and low-rank projection gradients, including `gdn_norm_out` recomputation. Retain the configured epsilon, zero-centered weight adjustment, and flattened per-head result. Keep the existing direct-gate parity and fused-call-count assertions—one forward call, or two with recomputation—and the disabled-path upstream-rounding regressions unchanged. GDN's SiLU dispatch must remain unchanged.

### 2. Add bit-exact replay coverage for the sigmoid specialization

**Failure:** This PR changes both Triton kernels and KDA's kernel dispatch, but none of their registered determinism tests changes. The existing [output-norm replay test](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/tests/unit_tests/determinism/kernels/test_gated_norm.py#L18-L65) only calls `GatedDeltaNet._apply_gated_norm`, so it never compiles the new sigmoid branch. The added tolerance-based parity tests don't establish repeated-run bit equality. This misses the pinned review rubric's required kernel replay coverage. The [coverage gate](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/tools/check_kernel_determinism_coverage.py#L163-L183) also returns violations for this changeset without an exemption; this is a source-derived result, not a CI run.

**Correction:** Extend the existing replay matrix through the real KDA dispatcher while retaining GDN coverage. The following is a suggested patch to the [replay test](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/tests/unit_tests/determinism/kernels/test_gated_norm.py):

```diff
 from megatron.core.ssm.gated_delta_net.gdn import GatedDeltaNet
+from megatron.core.ssm.gated_delta_net.kda import KimiDeltaAttention
@@
+@pytest.mark.parametrize("variant", ["gdn", "kda"])
 @pytest.mark.parametrize("zero_centered", [False, True])
@@
-def test_output_norm_replays(zero_centered, strided_gate, batch, length, heads, dim, cp):
+def test_output_norm_replays(zero_centered, strided_gate, batch, length, heads, dim, cp, variant):
@@
             self.value_head_dim = dim
+            self.two_stage_gates = False
@@
-            result = GatedDeltaNet._apply_gated_norm(self, x, gate)
-            assert result.shape == x.shape
+            attention = GatedDeltaNet if variant == "gdn" else KimiDeltaAttention
+            result = attention._apply_gated_norm(self, x, gate)
+            expected_shape = x.shape if variant == "gdn" else (x.numel() // dim, dim)
+            assert result.shape == expected_shape
@@
-            GatedNorm(), (x, gate), replays=3, contention=True, what="GDN output RMSNorm/SiLU"
+            GatedNorm(), (x, gate), replays=3, contention=True, what=f"{variant} output gated norm"
```

KDA's source is registered in two manifest entries. The shared `gated_delta_net` entry already names this replay file, but [the `kda_recurrence` entry](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/tests/unit_tests/determinism/kernels/manifest.py#L199-L205) only names the unchanged recurrence test. Retain that test and extend its tuple to:

```python
        tests=(K + "test_dev_sync_kernels.py", K + "test_gated_norm.py"),
```

Update that entry's notes and the [output-fusion entry's notes](https://github.com/NVIDIA/Megatron-LM/blob/aa54d82dc7ea35fa99391cd5a57aefde9597832f/tests/unit_tests/determinism/kernels/manifest.py#L690-L696) to name the KDA sigmoid output path. Please verify this proposed patch before adopting it.

**Preservation and acceptance:** Keep every existing GDN shape, strided-gate, and zero-centered-weight case, plus the existing KDA recurrence replay. For each added direct-gate KDA case, require byte-identical outputs and all three gradients—input, gate, and normalization weight—across three replays with side-stream contention. Retain the fused-call assertion and require KDA's flattened output shape rather than GDN's four-dimensional shape. The coverage check over the PR's changed files with no exemption should return no violations. This replay coverage must not remove the production rejection of `deterministic_mode=True`.
