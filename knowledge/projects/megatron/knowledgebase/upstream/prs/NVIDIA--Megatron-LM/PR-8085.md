# Preserve the API error after main pipeline retries are exhausted

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8085) · state: closed · merged: False

## Original PR description

When every main-pipeline query failed, retry exhaustion referenced an uninitialized pipelines variable and replaced the original API failure with UnboundLocalError. Re-raise the last API error after the third attempt and avoid sleeping with no retry left.

Validation: actual most_recent_pipeline tests cover all attempts failing and third-attempt recovery; baseline fails the error-preservation test, fixed source passes both tests and checks the two backoff delays. CPU-only fixtures; Ruff, Black and isort pass.
