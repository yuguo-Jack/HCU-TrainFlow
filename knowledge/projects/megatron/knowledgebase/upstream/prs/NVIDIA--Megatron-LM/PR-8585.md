# [MFSDP] Group execution settings in SchedulePolicy

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8585) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Move `register_hooks` and `grad_accumulation_count` into the existing frozen `SchedulePolicy`, alongside its forward/backward prefetch sizes. Pass the policy through to `FsdpModule` so hook registration and gradient completion use the same per-module configuration.

This keeps per-module execution settings together instead of adding separate arguments to `fully_shard`. Callers using the two former top-level keywords must now pass them through the policy:

```python
fully_shard(
    model,
    mesh=mesh,
    placements=placements,
    schedule_policy=SchedulePolicy(
        register_hooks=False,
        grad_accumulation_count=count,
    ),
)
```

Update the MCore adapter and existing explicit-scheduler tests. Defaults remain automatic execution hooks and one gradient callback per owned trainable parameter. The state-dict safety hook remains independent of execution hooks; extend its existing regression test to cover both policy settings.

### Put SchedulePolicy descriptions beside their fields

**Finding:** The new public configuration fields in [SchedulePolicy](https://github.com/NVIDIA/Megatron-LM/blob/58cabe71cea1ed9666b15a6aabf339650e807fe7/megatron/core/distributed/fsdp/src/megatron_fsdp/experimental/schedule.py#L24-L41) have descriptions only in the class-level `Attributes` section. This is a static documentation/style violation, not a demonstrated execution failure.

**Correction:** Move the descriptions from `Attributes` to the corresponding declarations. Replace the class header, docstring, and fields at lines 20–41 with the following, retaining the existing `__post_init__` method unchanged:

```python
@dataclass(frozen=True)
class SchedulePolicy:
    """Control prefetching and execution scheduling for one FSDP module."""

    forward_prefetch_size: int | None = None
    """Forward prefetch budget in parameter elements.

    `None` prefetches one successor; 0 disables prefetching.
    """

    backward_prefetch_size: int | None = None
    """Backward prefetch budget in parameter elements.

    `None` prefetches one successor; 0 disables prefetching.
    """

    register_hooks: bool = True
    """Register automatic forward/backward execution hooks.

    Disable when an external scheduler drives the FSDP lifecycle explicitly.
    The state-dict safety hook remains registered independently.
    """

    grad_accumulation_count: int | None = None
    """Total parameter-gradient callbacks per reduction window.

    Includes separate GraphTasks and delayed weight gradients. `None` defaults
    to one callback per owned trainable parameter. The scheduler must declare
    the complete count before sharding the unit.
    """
```

**Preservation:** Keep the frozen decorator, field order, annotations, defaults, and validation unchanged. Retain the documented distinctions between default versus disabled prefetching, automatic versus externally driven execution, unconditional state-dict safety, and default versus explicitly declared gradient callback counts. The replacement changes documentation only; the inspected runtime consumers continue receiving identical values.
