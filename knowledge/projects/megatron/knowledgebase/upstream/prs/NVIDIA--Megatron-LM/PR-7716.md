# What does this PR do?

An encoding partition that raises before `q.put()` exits, but the parent waits indefinitely on `q.get()`. Poll the queue with a timeout, inspect child exit codes, and terminate/join remaining workers when reporting a failure. Check sentence-splitting worker exit codes before encoding as well.

This is an AI-assisted draft. Human author review and NVIDIA GPU/CI validation are pending.
