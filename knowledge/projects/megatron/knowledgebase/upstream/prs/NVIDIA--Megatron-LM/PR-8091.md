# Count each discovered result file once in golden statistics

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8091) · state: open · merged: False

## Original PR description

When multiple batch logs refer to the same run output, discovery returns the same result file repeatedly. This weights one run multiple times in sample counts and tolerance statistics. Keep each discovered result path once, matching the direct discovery fallback.

Validation: the focused CPU regression fails on the baseline and the complete regression file passes with the fix. Black, isort and Ruff passed for the test. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
