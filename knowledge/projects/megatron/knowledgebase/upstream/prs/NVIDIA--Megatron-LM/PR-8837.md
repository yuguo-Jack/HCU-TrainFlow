# Avoid rebuilding ordinary FP32 Adam state during checkpoint loading

# What does this PR do?

Avoid rebuilding ordinary TE FusedAdam's FP32 moments during distributed checkpoint loading when the existing storage is already compatible. Both checkpoint-target construction and final optimizer restoration can otherwise temporarily hold a second copy of the moments.

For the exact TE FusedAdam class with precision-aware optimization disabled, ordinary FP32 parameter shards and matching FP32 moments, use PyTorch's public optimizer loader. It preserves compatible tensor storage while retaining parameter-ID mapping, parameter-group validation, and metadata restoration. Other configurations keep the inner optimizer's existing loader, including TE-owned master weights, capturable mode, hooks, subclasses, and incompatible tensor representations. Checkpoint formats and serialized values are unchanged.

## Validation

Synthetic tensors and generated checkpoints only, with PyTorch 2.14.0a0 (NGC 26.09), CUDA 13.4, and Transformer Engine 2.19.0+5e52befd:

- 16 new tests pass on one GPU.
- 35 tests pass on each of two GPU ranks, including existing parameter-group and mixed-dtype optimizer tests.
- Both `dp_reshardable` and `fully_reshardable` checkpoint round trips restore exact optimizer state and produce two subsequent updates identical to the reference. These exercise the optimizer checkpoint APIs with unchanged DP topology; topology-changing resumes and the training-level `load_checkpoint()` entry point are not covered by this suite.
- Fresh and initialized metadata restoration enforce a peak-allocation bound; initialized moments also retain their storage pointers.
- The four allocation/checkpoint regression cases fail against unmodified public `main` at the allocation or storage-identity assertions.
- Black, isort, Pylint, Ruff, and the kernel-determinism coverage check pass.

Reproduce the two-GPU suite:

```bash
python -m torch.distributed.run --standalone --nproc-per-node=2 -m pytest -q \
  tests/unit_tests/optimizer/test_distrib_optimizer_state_reuse.py \
  tests/unit_tests/optimizer/test_param_group_identifier_keys.py \
  tests/unit_tests/optimizer/test_distrib_optimizer_mixed_dtypes.py
```
