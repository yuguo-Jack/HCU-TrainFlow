## What does this PR do?

Select `StreamwiseSigmoidWideResidualConnection`'s operation at construction with required `mode="read"` or `mode="write"`. The reader owns `read_map`; the writer owns `write_map` and optional retention. `forward` no longer takes `operation`. Transformer, Mamba, residual replay, and existing test callers use separate reader/writer instances of the same class.

This is a numerical no-op: the residual maps, read/write math, and Triton operators are unchanged. This PR contains no MFSDP unit-selection or prefetch-order changes and no shortcut ownership relocation. Those are isolated in #7930.

Residual parameter paths change from `residual_connection*` to `residual_read*` / `residual_write*`. Ordinary `load_state_dict` accepts the original model keys. Migration of existing distributed checkpoints and optimizer state is not validated.

Stacked on #7781 via `pull-request/7781` to keep that existing prerequisite out of the review. #7930 depends on this refactor. Retarget dependent PRs before merging their base, and retarget this PR to `main` before merging. Related: #7777.
