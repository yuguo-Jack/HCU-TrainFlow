# Fix fused RoPE indexing for packed sequences

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8377) · state: open · merged: False

## Original PR description

Fix fused RoPE indexing when packed (THD) inputs provide one frequency row per token. For CP=1 with matching token and frequency counts, use TE's fused SBHD kernel on a `[T, 1, H, D]` view so frequency rows continue across sequences. Other per-token layouts fall back to the unfused implementation; shared position tables keep the fused THD path.

Port of [NVIDIA-NeMo/nv-mistralai-megatron#744](https://github.com/NVIDIA-NeMo/nv-mistralai-megatron/pull/744) onto public `main`. Both original commits are retained separately with unchanged patches, authorship, author dates, subjects, and original commit-message content. Each includes a `cherry picked from commit` reference and is signed and signed off.
