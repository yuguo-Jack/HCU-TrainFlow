# fix(ddp): scale grad buffers with fused _foreach_mul_ for device-tensor factors

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8352) · state: open · merged: False

## Original PR description


finalize_model_grads() scales gradients by 1 / num_tokens as a 0-D CUDA tensor so the step stays CUDA-graph safe. `grad_data *= scaling_factor` then runs PyTorch's broadcasting, dtype-casting elementwise kernel, which reaches only ~1.5 TB/s for BF16 grad buffers on GB300.

Scale grad_data and the extra main grads with torch._foreach_mul_, casting the factor to each tensor dtype so the fused path is taken. Results are bitwise identical to `*=`, which also casts the factor to the tensor dtype before multiplying. Python floats, CPU tensors and non-0-D tensors keep the existing `*=` path.

GB300, CUDA-graph timing of 1,027,604,480-element buffers:
  BF16 grads: 2804 us -> 733 us (3.83x)
  FP32 grads: 2348 us -> 1239 us (1.89x)
