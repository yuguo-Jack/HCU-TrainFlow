# [DSA] Let the DSA-over-GQA indexer reuse the fused QKV norm output

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8448) · state: open · merged: False

## Original PR description

# What does this PR do?

Lets the DSA-over-GQA simplified indexer take its input from the norm already fused into the attention's QKV projection, instead of recomputing that norm.

The simplified indexer must see the same normalized activation as the main Q projection. With TE layer specs that norm is fused into `linear_qkv` (`LayerNormLinear`), which only returns the GEMM output, so today `_normalized_indexer_input` recomputes the RMSNorm/LayerNorm in fp32 PyTorch on every DSA layer, in every forward. This change asks the fused module to also return the normalized activation its GEMM consumed and hands that to the indexer.

## Changes

- **`TELayerNormColumnParallelLinear`**: new constructor option `return_layernorm_output` (default `False`), passed to TE. When set, `forward` returns `(output, bias, layernorm_output)`. The default keeps the existing two-output contract. A `supports_layernorm_output(config)` classmethod reports support.
- **`InferenceLayerNormColumnParallelLinear`**: same option on the inference-optimized path. Supported only with `tensor_model_parallel_size == 1`; with TP > 1 the normalized input lives in a reused symmetric all-gather buffer (or arrives pre-normalized from the fused reduce-scatter), so construction raises instead.
- **`Attention`**: a `_needs_qkv_layernorm_output()` hook (default `False`). When a subclass returns `True`, `get_query_key_value_tensors(..., return_layernorm_output=True)` appends the norm output, which is passed to `_get_core_attention_extra_kwargs` as `qkv_layernorm_output`. Nothing changes for attention classes that do not opt in.
- **`DSGroupedSelfAttention`**: opts in at construction when `linear_qkv` supports it, and then passes the returned norm output to DSA core attention as the indexer input, with no norm left to apply. It keeps recomputing the norm when the QKV module has no fused norm output, and when QKV runs quantized (FP8/FP4 or a quantization recipe): there, returning the norm output would replace TE's fused quantized norm with a separate quantization. If a module built to return the norm output does not, it raises.

Training semantics are unchanged: the indexer input stays detached, and the attention path's gradients are those of the recompute path.

## Tests

- `tests/unit_tests/extension/test_te_layernorm_column_parallel_linear.py`: the returned norm output matches a reference RMSNorm, with and without a returned bias; the main output and gradients match the default module; the inference-optimized module returns it at TP=1 and reports no support for TP > 1.
- `tests/unit_tests/transformer/test_attention_variant_dsa_gqa.py`: opt-in rules; for both the TE and the inference-optimized DSA specs, the reused indexer input equals the recomputed one and the indexer scores match; training gradients of the input, QKV weight and norm weight match the recompute path; non-DSA self-attention does not request the norm output and keeps its outputs.
