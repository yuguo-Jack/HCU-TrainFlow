# [DSv4.1] V4.1 Engram on shared EP embedding tables

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8225) · state: open · merged: False

## Original PR description

Add V4.1 tokenizer-aware hashing and gated conditional memory on shared EP-sharded embedding tables. Carry causal token history across contiguous CP cuts and reset it at packed document boundaries, using explicit process groups. Keep Q/K norm gamma as vectors, matching the reference and main's standard no-decay/scalar-optimizer classification.

Independent prerequisite based on main. Shared EP embedding adapted from @BestJuly in #7231; V4.1 Engram adapted from @guihong-nv in #7501 and @hxbai in #7224.

Validation: EP lookup/gradients, CP history and RNG preservation passed. Direct reference-branch SBHD/packed comparisons produced identical hashes; maximum forward/gradient relative L2 errors were 2.4e-7 (FP32) and 5.4e-6 (BF16). The assembled stack passed 8-GPU DP2/EP2/PP2/CP2 checkpoint save/resume with the vector norm layout. The existing FP32 mHC PP/VPP parity test now selects IEEE GEMMs without changing tolerances. Synchronized with main at e8a302ac5b.

Shared test fix: THD parity tests use nonblocking NCCL communicators so CP teardown completes; their numerical checks are unchanged.
