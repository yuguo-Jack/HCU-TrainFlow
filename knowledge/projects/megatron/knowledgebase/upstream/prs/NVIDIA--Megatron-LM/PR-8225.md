# [DSv4.1] V4.1 Engram on shared EP embedding tables

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8225) · state: open · merged: False

## Original PR description

Add V4.1 tokenizer-aware hashing and gated conditional memory on shared EP-sharded embedding tables. Carry causal token history across contiguous CP cuts and reset it at packed sequence boundaries, using explicit process groups.

Independent prerequisite, based on main. Shared EP embedding implementation adapted from @BestJuly in #7231; V4.1 Engram adapted from @guihong-nv in #7501 and @hxbai in #7224.

Validation: two-rank EP lookup/gradient and shard-metadata checks, CP hash/history and RNG-preservation tests passed. The assembled stack passed H100 SBHD/THD, PP/VPP, CP2 and 8-GPU DP2/EP2/PP2/CP2 training with Engram; checkpoint save/resume passed with model-side shared-buffer replica metadata. Black/isort/Ruff/Pylint and diff checks passed.

Revalidated with the refreshed V4.1 stack, including EP/CP history, PP/VPP and multi-GPU training. No Engram algorithm change is needed for the mHC/CSA2 performance updates.
