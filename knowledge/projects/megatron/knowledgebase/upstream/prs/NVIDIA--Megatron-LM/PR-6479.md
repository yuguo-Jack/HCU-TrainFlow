# [dev] Share CUDA graph slots across dynamic CP variants

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6479) · state: open · merged: False

# What does this PR do?

Lets dynamic context parallelism (DCP) use layer-wise Transformer Engine CUDA graphs. Each CP size gets its own graph bank, and all banks share one TE memory pool. DSv4/MLA backward metadata moves into saved tensors, the only state that shared graph memory protects.

**Depends on** NVIDIA/TransformerEngine#3353 (`make_graphed_callables(_graph_memory_slots=...)`). Without it, DCP + CUDA graphs raises at construction; other runs are unaffected. Packed Gated DeltaNet capture (Qwen3.5) is left to a follow-up PR.

## Design

- **Banks.** `TECudaGraphHelper` captures every power-of-two CP size from `--min-dynamic-context-parallel-size` to DP×CP with that size's runtime group (#7045). At replay, a layer picks its bank from `PackedSeqParams.local_cp_size` and checks the microbatch's CP group against it.
- **Shared memory.** One slot ring, sized from the liveness of every PP/VPP schedule the DCP scheduler can produce. Saved-tensor and gradient arenas are colored so live frames never share storage; variants of a slot share addresses, so memory scales with the largest variant, not the number of banks.
- **Capture state.** THD capture seeds a bounded RoPE table and `cu_seqlens` per bank; the DCP scheduler honors `thd_max_packed_sequences`, and each step's microbatch count is checked against the captured range.
- **DSv4/MLA.** CSA sparse attention, cuDNN sparse attention, the fused DSA indexer loss and fused MLA RoPE keep their backward metadata in `save_for_backward` instead of `ctx` attributes. Eager numerics are unchanged.

**Changes for runs without DCP** (shared paths, each fixing a dev inconsistency): metadata-only THD padding on middle PP stages uses the CP-local length like the first stage; the CP=1 `dp_balanced` scheduler gathers on the equivalent DP×CP group; fixed-CP THD capture seeds the full RoPE table; attention-only replay passes the real `PackedSeqParams` to the eager MLP; PP stages without graphable layers join the slot-ring all-reduce; `delete_cuda_graphs()` no longer asserts that graphs exist.

## Tests

New unit tests cover the slot plan (including a property test over PP 2/4/8 × VPP 1/2/4 schedules), bank selection and lifecycle (`test_thd_cuda_graph.py`, `test_transformer_layer.py`), hybrid mHC + MoE replay vs. eager across banks (`test_hybrid_dcp_cuda_graph.py`), `train()` helper construction from default arguments, the DSv4/MLA saved-tensor paths and the dynamic-CP config rules. ## Limitations

- CP sizes and DP×CP must be powers of two.
- Dynamic-CP graphs need `--cuda-graph-impl transformer_engine` with `cuda_graph_dynamic_microbatches`; `full_iteration`/`local` graphs, `step_batch_size_schedule`, delayed wgrad, EP overlap, `moe_paged_stash` and mamba scopes are rejected.
- CI skips the TE-slot tests until NVIDIA/TransformerEngine#3353 is in the pinned TE.
