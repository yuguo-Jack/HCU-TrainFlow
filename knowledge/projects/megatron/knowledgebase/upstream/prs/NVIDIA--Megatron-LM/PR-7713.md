# fix(optimizer): require layer-wise mode for distributed Muon

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7713) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Require `use_layer_wise_distributed_optimizer=True` when `optimizer="muon"` and `use_distributed_optimizer=True`. Previously the emerging-optimizer factory accepted that combination without layer-wise mode and constructed replicated optimizer state, silently ignoring the requested optimizer distribution.

Raise `ValueError` for the invalid configuration after deprecated optimizer names are normalized, preserving `dist_muon` compatibility and validation under `python -O`. Plain Muon without `use_distributed_optimizer` remains supported. Other optimizers are unchanged.

## Validation

- Extend the existing Muon validation and layer-wise tests to cover rejection, explicit layer-wise mode, and the deprecated alias; no new test module or fixtures.
- Two-GPU focused run of the existing Muon class and optimizer configuration tests: 8 passed per rank.
- The existing validation test also passed on both GPU ranks with `PYTHONOPTIMIZE=0` and `PYTHONOPTIMIZE=1` after the `ValueError` change.
- Configured Black, isort, pylint and ruff checks passed. The workstation formatting wrapper requires a newer Git version, so these checks ran directly in the test container. Optional mypy still reports existing factory typing errors.
- Independent review completed with no blocking findings.

This validates the optimizer configuration only; it does not inspect independently configured DDP model chunks. No optimizer update rules or checkpoint formats change.
