# Unify mHC and WR replay coordination

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7923) · state: closed · merged: True

## Original PR description

## Summary

First incremental refactor toward #7888.

Replace three duplicated recompute planners—Transformer mHC, Hybrid mHC, and Wide Residual—with shared residual-recompute planning functions.

- Share block-boundary planning, per-forward manager allocation, and finalization.
- Preserve atomic ShortcutMoE pairs and existing CUDA-graph manager transport.
- Cache immutable boundaries while keeping checkpoint managers fresh per forward.
- Preserve existing entry points and return formats; align active mHC helper
  validation with configuration requirements.

No changes to model math, kernels, parameter names, or which operations are replayed.

Finalization retains the existing single-terminal-tensor replay trigger. General auxiliary-state and multi-edge replay support is outside this PR and will be designed against the shared state/boundary contract from #7224.
