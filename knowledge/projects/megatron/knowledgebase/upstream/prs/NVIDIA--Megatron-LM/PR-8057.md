# Require pipeline groups and warn on global fallbacks in transformer code

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8057) · state: open · merged: False

## Original PR description

Depends on #8049 (and #6293). Please review the diff from #8049's head: [scoped diff](https://github.com/Connor-XY/Megatron-LM/compare/64aea4dcb...yx/pstate-b10-transformer-defaults).

**Why.** `TransformerBlock` read `pg_collection.pp` behind `hasattr`, which is always true because an unset field reads as `None`. A collection without `pp` gave every stage pipeline rank 0, so with PP=2 stage 1 silently built stage 0's layers with stage 0's layer numbers. `TransformerLayer` and `Float16Module` had the same gap, and the block and layer defaults read the global grid without a warning.

**What.**
- Under pipeline parallelism, `TransformerBlock`, `TransformerLayer` and `Float16Module` require `pp` and reject `None`; without pipeline parallelism `pp` may stay unset. The block and layer also require `tp`.
- An omitted collection goes through `resolve_process_groups`: one `ProcessGroupFallbackWarning` per owner (removed in 0.23), building only the 16 fields the layers' modules read, each the same global group as before.
- `Float16Module` takes `pg_collection`, and warns when neither it nor the wrapped module has one.
- MTP: the `pp_rank` fallbacks of the layer offset and count, and the `metric_avg_group` fallback of `process_mtp_loss`, warn. The acceptance-count guard reads no globals: vocab-sharded logits need `tp_group`.

**Tests.** New `test_transformer_process_groups.py` has 24 cases; 20 fail on #8049's head. The default path is checked for one warning, identical groups, layers and bitwise-equal outputs (TP=2, PP=2). Block, layer, GPT, BERT, hybrid, MoE, GTP, vision, MTP and dist-checkpointing suites match the base on 4 GPUs.

**Compatibility.** Groups on the standard grid are unchanged. Megatron Bridge sets `pp` in every collection it builds; modules built without a collection, and MTP spec builders called without `pp_rank`, now warn. Land after #8022, or BERT warns.

Part of #6307.
