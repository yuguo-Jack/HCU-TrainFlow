# Skip language-model kernel warmup on encoder-only ranks

# What does this PR do?

Skip language-model kernel warmup on encoder-only ranks.

When `pretrain` receives a GPT/Hybrid configuration with encoder-only `MultiModuleProcessGroupCollection` groups, it selects the first encoder's TP group and runs language-model kernel warmup, including native vocabulary cross-entropy. The language configuration does not describe that encoder's kernels or shapes.

Check language-module ownership before selecting a TP group or entering warmup. Preserve language TP selection for colocated ranks and the existing explicit/global process-group paths. Pipeline and MTP warmup behavior on language-model ranks is unchanged.

## Validation

- The four new encoder-only regression cases fail on unmodified `main` and pass with this change.
- Full `tests/unit_tests/training/test_kernel_warmup.py` suite: 48 cases pass on one GPU.
- Full suite on two GPUs: all 48 cases pass on each rank.
- Repository autoformat checks pass for Black, isort, Pylint, and Ruff; `git diff --check` passes.

Coverage includes GPT/Hybrid configs, one or multiple encoder modules, language-only and colocated modules, explicit process groups, and the global TP fallback. Existing GPU tests exercise native CE forward/backward, RNG preservation, and warmup storage cleanup.
