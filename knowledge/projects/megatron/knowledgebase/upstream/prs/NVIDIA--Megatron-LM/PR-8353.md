# Fix GDN prefill CUDA graph replay with single-update GDP

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8353) · state: closed · merged: True

## Original PR description

FLA's capture-time chunk metadata can outlive its cache ownership and become stale when the live sequence layout changes, causing incorrect results or illegal memory accesses during prefill graph replay.

Run dynamic GDN prefill through the in-tree GDP recurrence with one Householder update and the in-tree variable-length convolution. Let the inference context own padded chunk descriptors and refresh them in place before replay, keeping workspace capacity and launch grids stable. Pass both descriptor buffers and the mixer's Householder count explicitly.

Add changing-layout graph replay coverage, enable prefill graph parity coverage in the dynamic engine, and parameterize the existing GDP replay determinism test over one and two Householder updates.
