# refactor(fsdp): Use DBuffer owner APIs and direct P2P receives

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8178) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

Owner gather/scatter duplicates DBuffer metadata in `GroupOwnerLayout` and receives through temporary tensors before copying into destinations. This PR uses the sharded-side DBuffer directly and receives into destination views.

Changes:

- Change gather's source and scatter's destination from tensor dictionaries to `DBuffer`; pass `tensor_to_owner` separately:

  ```python
  gather(source: DBuffer, destination: dict[int, torch.Tensor], *, tensor_to_owner: dict[int, int])
  scatter(source: dict[int, torch.Tensor], destination: DBuffer, *, tensor_to_owner: dict[int, int])
  ```

- Remove `GroupOwnerLayout`, its `from_group` constructor, and `select_ge_2d_params`. Callers select participating tensor indices.
- Change `assign_owner_work(layout, mesh, tensor_indices, cost_fn)` to `assign_owner_work(buffer, tensor_indices, cost_fn)`, deriving eligible ranks from the buffer's actual placements instead of assuming `RowAtomic`.
- Remove per-peer receive buffers, gather concatenation, and final receive-buffer copies. Require gather destinations and scatter sources to be contiguous full tensors with matching element counts, dtype, and device. Scatter sends slices as views and receives directly into DBuffer shards.
- Explicitly support one-dimensional sharded meshes, using the actual `RowAtomic`, `BlockAtomic`, or `TensorAtomic` placement. Remove tensor-index sorting and rename the rank-offset ordering helper to `_get_sorted_rank_ranges`.

Tests exercise separate computed-input and scratch DBuffers, all three placements, subgroup global ranks, dictionary traversal order, and preservation of owner-local shards, excluded tensors, and padding.

Owner assignment still operates on one buffer per call. The cross-group API in #7974 and the optimizer caller in #7519 require adaptation to these interfaces.

Validation after rebasing onto `b597bd1fa`:

- Ran `test_owner_planning.py` and `test_gather_scatter.py` through `torch.distributed.run` on two RTX A6000 GPUs: 8 passed and 11 skipped per rank. The skipped cases require three or four ranks.
- Updated the gather/scatter test to use main's extracted `layout_builder` functions.
- `tools/autoformat.sh` check mode completed successfully: Black, isort, Ruff, and mypy passed; Pylint rated the code 10/10 with its unsupported `bad-builtins` configuration diagnostic. `git diff --check` passed.

Follows #8177 (merged). Original owner-compute work by @janEbert. Related to #5533.
