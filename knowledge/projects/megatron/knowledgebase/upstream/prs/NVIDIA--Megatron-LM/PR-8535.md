# [Dev] fix(gpt): keep experimental attention specs on MTP-only pipeline stages

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8535) · state: open · merged: False

## Original PR description

## Summary

When the last pipeline (or virtual pipeline) stage holds only MTP layers, its local decoder block spec is empty. Both MTP spec builders took their "no decoder layers" branch before looking at `experimental_attention_variant`, and fell back to the standard-attention layer spec. A DSA (or other experimental-attention) model with an MTP-only last stage therefore built its MTP layer with ordinary attention on that stage, silently changing the architecture. Such stages are legal and used in practice, for example VPP layouts that end in `|m*7L`.

- `gpt_builders.gpt_builder`: with `experimental_attention_variant` set, the MTP layer spec now comes from the global experimental-attention pattern (the last entry of `get_transformer_layer_with_experimental_attention_variant_spec`) before the empty-stage fallback. The experimental-attention branch in the `else` arm, which could never run, is removed.
- `megatron.training.models.gpt.mtp_block_spec`: when the stage has no local decoder spec and `experimental_attention_variant` is set, it uses the same experimental-attention pattern instead of `_te_or_local_layer_spec`.

Models without `experimental_attention_variant`, and stages that hold decoder layers, are unchanged.
