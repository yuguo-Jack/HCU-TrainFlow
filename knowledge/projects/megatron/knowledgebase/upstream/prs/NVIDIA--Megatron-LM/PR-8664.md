# What does this PR do?
<!-- Add a one line overview of what this PR aims to accomplish. -->

Let pipeline stages agree on a frozen-prefix gradient boundary, so that when only the later decoder layers are trainable (for example LoRA on the decoder half of DeepSeek-V4.1), stages that lie entirely before the first trainable layer skip their backward.

## Implementation details

- A later pipeline stage receives its input over P2P as a tensor that always requires grad, so it cannot tell on its own whether anything upstream is trainable. `sync_pipeline_gradient_boundaries` takes the minimum, over all stages, of the first decoder layer with a trainable parameter (0 when a pre-process module such as the embedding is trainable) and stores it on every decoder.
- Both pipelined schedules call it before their first microbatch. The result is cached; `reset_gradient_boundary_cache` clears it after `requires_grad` changes.
- When no decoder layer is trainable (for example only the final norm or the output layer is), the boundary stays past the last layer, so every stage runs its layers under `no_grad`.
- `backward_step` sends zero input gradients when autograd never reached a stage input, which keeps the classic P2P path in step with the previous stage.
- `infer_gradient_boundary_layer`, `get_cached_gradient_boundary_layer`, `first_local_layer_index` and `resolve_gradient_boundary` give the decoder blocks one place to find the boundary for a forward.
- `detach_state` copies a forward-local state object (dataclasses, dicts, lists, tuples) with detached tensor leaves, for cutting cross-layer state at the boundary.
- `TransformerBlock` and `HybridStack` run the frozen prefix under `no_grad`, detach the hidden state where the first trainable layer starts, and detach the output of a stage that lies entirely before it. Full recompute runs the frozen prefix without checkpoints and counts the recompute window from the boundary.
- `test_gradient_boundary_pipeline.py` compares gradients against a full backward on GPT and hybrid models with PP=2 and PP=4, eager and full recompute, including all-frozen decoders.

## Known limitations

- Multi-module pipelines do not sync the boundary yet; their stages keep full autograd.
