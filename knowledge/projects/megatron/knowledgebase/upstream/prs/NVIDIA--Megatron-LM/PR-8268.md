# What does this PR do?
The streaming chat path decoded with `DecodeStream(skip_special_tokens=True)`, which drops every added token flagged `special`. The non-streaming path drops only the tokenizer's special-tokens map (`all_special_tokens`) and trailing EOS ids. Chat tokenizers commonly flag their reasoning and tool-call markers as special without putting them in that map (e.g. `<think>`, `</think>`, `<tool_call>`, `</tool_call>`), so in a stream the reasoning parser never saw `</think>`: the answer and the tool-call markup ended up in `reasoning_content` and no tool call was parsed. Thinking-disabled streams and every non-streaming reply were unaffected.

Decode with `skip_special_tokens=False` and drop exactly the ids the non-streaming path drops: `all_special_ids` and the model EOS ids (`model_eos_token_ids`), from both the generated tokens and the prompt prefill. Tokens in the special-tokens map (BOS/EOS/pad) are still dropped.
