# build: update AnyIO to address CVE-2026-63374

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8228) · state: closed · merged: True

## Original PR description

## Change

Update the locked AnyIO version from 4.9.0 to 4.15.1 to address CVE-2026-63374 (patched in 4.14.2). Add a minimum-version override so future lockfile regenerations retain a patched version. This override is necessary because NeMo Run's transitive LeptonAI 0.27.3 dependency still declares `anyio<=4.9.0`.

## Validation

- `uv lock --check` passed in the Megatron-LM dev CI container.
- Imported AnyIO 4.15.1, LeptonAI 0.27.3, NeMo Run, and HTTPX in that container; an asynchronous HTTPX request through `MockTransport` passed.
- `git diff --check` passed.

The LeptonAI metadata override needs CI compatibility validation; the focused smoke check does not cover every LeptonAI path. No GPU test was run locally because the host NVIDIA runtime has a driver/library mismatch.

Reference: https://github.com/advisories/ghsa-82r6-8w77-94w6
