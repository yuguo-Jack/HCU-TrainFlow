# build: fix filelock CVE-2026-112940 on core_r0.20.0

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8481) · state: closed · merged: True

## Original PR description

## Summary
- Resolve filelock to 4.2.4, above the 4.2.1 fix for CVE-2026-112940.
- Override the transitive filelock requirement because multi-storage-client 0.51.0 still declares `filelock<4`.

## Validation
- Regenerated `uv.lock` with `uv lock --upgrade-package filelock` in the NVIDIA PyTorch 26.09 container.
- `git diff --check` passed.

## Compatibility note
The override crosses multi-storage-client's declared upper bound. Please validate its file locking paths in CI before merging. The override should be removed when multi-storage-client supports filelock 4.

Advisory: https://github.com/tox-dev/filelock/security/advisories/GHSA-v4x8-3wr5-3wq8
