# Add optional GDP log-decay clamp

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8926) · state: open · merged: False

## Original PR description

## Summary

Adds `--gdp-g-clamp-value`, an optional lower bound on GDP's per-token log decay `g`, applied before the recurrent kernel in training, dynamic-batching prefill and decode. Unset (the default) leaves `g` unchanged.

- `TransformerConfig.gdp_g_clamp_value`: a positive magnitude; `g` is clamped to a minimum of `-value`. Non-finite or non-positive values are rejected.
- `GatedDeltaProductMixer._clamp_g` applies it out of place in `_compute_gating` (training and static prefill), `ssm_decode` and `ssm_prefill`, so the zero-decay Householder copies stay zero and both inference paths match training.
- When loading arguments from a checkpoint, a saved value is restored unless one is given on the command line, so an older checkpoint can be resumed with the clamp turned on.

## Tests

- `tests/unit_tests/ssm/test_gdp_g_clamp.py`: the clamp and its gradient mask, gating values and gradients through `_compute_gating`, the value forwarded to the decode recurrence and to the dynamic-batching prefill scan, config validation and checkpoint-argument restore.
- `tests/unit_tests/determinism/kernels/test_ssm_kernels.py`: bit-exact replay of `_compute_gating` under side-stream contention, with and without the clamp.
