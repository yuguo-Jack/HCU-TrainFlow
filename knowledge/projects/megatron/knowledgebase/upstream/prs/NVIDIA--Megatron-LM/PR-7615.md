- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

A fixed mock length of `n` currently produces `n - 1` valid training tokens after appending EOD and applying the next-token shift. Generate `n` content tokens so, for example, a 65536-token configuration produces 65536 valid tokens before alignment padding, capped at `--seq-length`.

Apply this convention to distribution, CSV, and verification modes. Adjust the shared MockSFT THD/SBHD padding and truncation, and mask padding by position so EOD remains a valid target when it is also the pad token. Preserve the existing vocabulary bounds and document the length convention in the CLI help.

### Suggested repair for the inline compatibility finding

This mirrors the dataset’s CP/SP padding divisor and leaves the preceding `total_cp_ranks` selection intact:

```python
        cp_divisor = (
            args.data_parallel_size * args.context_parallel_size * 2
            if args.dynamic_context_parallel
            else (args.context_parallel_size * 2 if args.context_parallel_size > 1 else 1)
        )
        sp_divisor = args.tensor_model_parallel_size if args.sequence_parallel else 1
        padding_divisor = cp_divisor * sp_divisor
        max_padded_length = (
            (args.seq_length + padding_divisor - 1)
            // padding_divisor
            * padding_divisor
        )
        if args.max_seqlen_per_dp_cp_rank is None:
            args.max_seqlen_per_dp_cp_rank = getattr(args, "max_seqlen_per_cp_rank", None)
        if args.max_seqlen_per_dp_cp_rank is None:
            args.max_seqlen_per_dp_cp_rank = (
                max_padded_length + total_cp_ranks - 1
            ) // total_cp_ranks
        assert total_cp_ranks * args.max_seqlen_per_dp_cp_rank >= max_padded_length, (
            f'Packed sequence buffer size ({total_cp_ranks * args.max_seqlen_per_dp_cp_rank}) '
            f'must be >= padded single sequence max length ({max_padded_length})'
        )
```
