# Backport MoK, THD attention graphs, and DSv4 FLOPs to core_r0.20.0

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8929) · state: closed · merged: True

## Original PR description

Backport MoK, packed THD attention CUDA graphs, and DSv4 FLOPs accounting to `core_r0.20.0` in one PR. Each feature retains its own signed cherry-pick commit.

| Main PR | Source commit | Change |
| --- | --- | --- |
| #8210 | `a153d5d3f543479e44637d4d62ad402e48ef4a7a` | MoK MoE backend, shared-expert gate, parameter/checkpoint ownership, and pinned MoK dependency |
| #8361 | `631e146322af891b0c79b8d5a53bc579a69f01f3` | TE attention graph capture/replay for bounded THD packs; replaces #5783 |
| #7972 | `e1afbb93db5cad5b7b652d10998bd4802cdbb89c` | W/C/H attention and MTP FLOPs accounting using real packed-token statistics |

Release adaptations:

- MoK keeps release's routing implementation and uses its existing TE/BF16 recomputation APIs. Main-only MoonEP and dispatcher-input hooks are absent on release and are not introduced here.
- THD graphs require the static packing alignment/padding helpers introduced by #7047 (`ea99fdfce50a592f9090c37ca2d51a82327898af`). Include those helpers, the padding option, and calls from the release packing loader. Hybrid now requests the existing layout-aware CP utility so contiguous data is actually contiguous; GPT retains its tuple API. Padding masks follow token order on every pipeline stage, and fixed graph metadata retains logical/physical document boundaries. Preserve release's `hybrid_context_parallel` name; dynamic-CP migration is not included. Hybrid skips local FLOPs-stat accumulation when the scheduler already supplies global iteration totals.
- FLOPs keeps release's args-only calculator interface and adapts the new tests accordingly. No dataset/config migration is included.

Validation on the combined release branch:

- 145 focused tests passed: FLOPs, MoK configuration/parameter contracts and module construction, model-parallel config, CLI restrictions, and packed metadata.
- After the layout correction, all 88 focused cases passed on both ranks in a two-GPU run: 81 token/mask/metadata cases across contiguous/zigzag/tuple outputs, CP ranks, PP stages and graph modes; a Hybrid caller check; two FLOPs-stat ownership checks; and four real TP2/CP1 or TP1/CP2 process-group cases. The old implementation failed the new contiguous token-order check before the correction.
- All 10 GPU routing/reference and bit-exact replay cases passed, including forward/backward checks and stream contention.
- Formatting, import ordering, Ruff, Python syntax, and kernel determinism coverage checks passed. Pylint reports no code diagnostics in changed core/test files when the obsolete repository `bad-builtins` option diagnostic is disabled. Explicit entrypoint lint also reports existing unused-import/line-length diagnostics outside the correction. Advisory mypy reports existing/type-stub diagnostics.
- Local full THD graph replay is **not validated**: Ada SM89 with TE 2.19 rejects the fused-attention configuration in the eager reference before capture. Release CI uses TE 2.21. Blackwell MoK execution and PP/VPP graph replay still require CI; source-PR GPU results are not counted as release validation.

Independent review of the final layout correction found no remaining concrete issues. Opened as a draft for combined release CI and review. Base: `f95792aeb8f09d95effed777dfd6d0c5cc814783`.
