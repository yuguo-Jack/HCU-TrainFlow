# Add optional decoder token-embedding RMSNorm for hybrid models

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8415) · state: open · merged: False

## Original PR description

## What does this PR do?

Add opt-in `--normalization RMSNorm --post-embedding-rmsnorm` support to normalize the hybrid decoder input once before its first layer. This is the parallel main-branch port of [NVIDIA-NeMo/nv-mistralai-megatron#794](https://github.com/NVIDIA-NeMo/nv-mistralai-megatron/pull/794), source commit `3c1e7dde01eb6353ff2eb8aaadd26285d04f15c8`.

The learned norm lives at `decoder.input_norm`, so standalone text and externally assembled MiMo embeddings use the same boundary. It runs before wide-residual or mHC expansion, preserves the incoming residual dtype, and is absent from later pipeline stages and auxiliary MTP stacks. The option is disabled by default and requires RMSNorm.

The architecture flag is checked on checkpoint resume and restored by `--use-checkpoint-args`; older checkpoints without the flag retain the disabled architecture. The learned weight participates in sharded checkpoints.

## Main-branch adaptations

- Use current `HybridStack` layer-config and checkpoint test APIs; main already handles missing sharded offsets.
- Keep main's existing optimizer policy for one-dimensional norm weights. The source fork's configurable RMSNorm decay is a separate feature, also proposed in [#8246](https://github.com/NVIDIA/Megatron-LM/pull/8246), and is not required by this PR.
- Cover both wide-residual and mHC expansion, and register BF16/FP32 bit-exact forward/backward replay under GPU contention in the determinism manifest.

Tests cover configuration/CLI defaults, checkpoint restoration and mismatch rejection, text/MiMo paths, norm ownership, residual precision, gradients, optimizer grouping, state-dict roundtrips, and TP=2/CP=2 sequence-parallel behavior. Documentation is included.
