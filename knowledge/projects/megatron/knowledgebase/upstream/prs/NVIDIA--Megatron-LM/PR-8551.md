# Pin the SM in the cuDNN DSA backward head-padding test

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8551) · state: open · merged: False

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

Makes `test_cudnn_attention_backward_pads_small_local_head_count` independent of the GPU it runs on.

The test replaces the cuDNN DSA module with a fake, but `_run_sparse_attention_backward` still reads the real device capability to choose the query-head padding. Below SM90 that lookup raises `cudnn fused DSA requires SM90+ (Hopper or later), got SM89.`, so the test fails on an L40S even though no cuDNN kernel runs. The test now pins `_current_sm` to SM90, the same way `test_cudnn_flash_mla_sm100_uses_smallest_supported_head_padding` pins SM100. The expected shapes are the SM90 padding (8 heads padded to 64). SM100 also pads 8 heads to 64, so the test checks the same thing on Hopper and Blackwell as before.
