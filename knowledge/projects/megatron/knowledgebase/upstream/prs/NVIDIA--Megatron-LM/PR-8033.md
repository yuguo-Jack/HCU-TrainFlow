# Honor the caller's pipeline rank in custom layouts and the checkpoint converter

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8033) · state: closed · merged: False

## Original PR description

## Why

With a `pipeline_model_parallel_layout`, `get_transformer_layer_offset()` and `get_num_layers_to_build()` dropped the `pp_rank` they were given, so the layout used the global pipeline rank, and it took the virtual pipeline size from the global grid. A model on its own pipeline grid (PP=2 under a global PP=1) built stage 0's layers on every rank.

## What

- Pass `pp_rank` on to the layout, which uses its own virtual pipeline size (interleaved when greater than 1).
- `tools/checkpoint` selects stages with `set_pipeline_model_parallel_rank()`, but models read the rank of their pipeline group: the converter's fake group, which stayed at 0. The loader and saver now set that rank, and the loader initializes a single-process gloo group, as the saver does. This also fixes PP > 1 conversions, which built every stage as stage 0: uneven splits (`num_layers_in_first/last_pipeline_stage`) got the first stage's layers, and later stages with tied embeddings failed a first-stage check.

## Tests

Measured on this branch before the sync with main:

- `tests/unit_tests/transformer/test_pipeline_parallel_layer_layout.py`: explicit `pp_rank` with the global accessors patched to raise, the default path, and a `TransformerBlock` on its own PP=2 grid. 8/8 pass on 4 GPUs; 6 fail on main.
- `tests/unit_tests/tools/checkpoint/test_checkpoint_converter_pipeline_stages.py`: the stages the loader and saver build. 5/5 pass; 3 fail on main, 5 without the converter commit.
- Existing layout, layer-offset and `tools/checkpoint` tests: same as main.
- End to end, a save → convert → load round trip (plain, layout, uneven 5+3, and layout at TP2/PP2) reproduces the weights exactly on this branch and fails on main.

In the integration run (all #6307 PRs merged onto main) on 4 GPUs, `test_pipeline_parallel_layer_layout.py` passes 15/15 and `test_checkpoint_converter_pipeline_stages.py` passes 9/9. Both counts include tests that later campaign PRs add to these files. Neither file exists on main, and this PR's test files show no regressions against main.

## Compatibility

Without `pp_rank` the global rank is used; standard runs are unchanged. With distributed initialized, the loader sizes tensor-parallel layers from its fake groups, like the saver, so it can load TP>1 checkpoints.
