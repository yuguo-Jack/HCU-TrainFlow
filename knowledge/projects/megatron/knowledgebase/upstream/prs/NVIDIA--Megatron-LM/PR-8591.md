# Remove quadratic chunk overlap sweeps from plan validation

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8591) · state: open · merged: False

## Original PR description

torch's DefaultSavePlanner validates the merged global plan on the
coordinator with _validate_global_plan, whose chunk-overlap check sweeps
along the largest tensor dimension and compares each chunk with every
chunk still active on it. Megatron shards MoE expert weights along a
leading expert axis (num_experts fragments) plus the (E)GTP split of one
feature axis, and the largest dimension of such a tensor is a feature
dimension that is either unsharded or split only (E)GTP ways. The sweep
therefore keeps up to num_experts chunks active per slice and
degenerates to O(n^2) per key. Nothing waits on a collective with the
coordinator during this step (decentralized planning), so the other
ranks finished their save and idle.

Add strategies/global_plan_validation.py, which performs the same three
checks (bounds, overlap, volume coverage) with the same verdict and
messages but picks the overlap algorithm from the chunk layout: a
duplicate search when every dimension is a regular grid (every layout
Megatron writes), a per-cell 1-D interval sweep when exactly one
dimension is irregular, and torch's pairwise check otherwise. Route
MCoreSavePlanner._create_global_plan through it, with a
create_global_plan shim for torch < 2.7.

Skip dedup_save_plans as this is already handled in TorchDistSaveShardedStrategy.
