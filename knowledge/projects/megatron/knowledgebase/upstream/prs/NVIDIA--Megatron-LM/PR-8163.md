# Stop logging checkpoints as wandb artifacts and keep private args out of the wandb config

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8163) · state: closed · merged: True

## Original PR description

Every save logged the checkpoint as a wandb model artifact holding only a file:// reference to a cluster path, and every load called use_artifact on it. Nothing reads these, the references dangle once --save-retain-interval deletes the checkpoint, and each log_artifact call made wandb re-serialize the run config. Remove wandb_utils and its two call sites.

The wandb config was vars(args) itself, so any private runtime state attached to args (underscore-prefixed attributes) was serialized into the config at setup and again on each config sync, which is expensive when that state is large. Exclude underscore-prefixed attributes.
