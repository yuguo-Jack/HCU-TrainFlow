## Original PR description

For PRs targeting `main` with Testmon selection enabled, merge latest `main` into the CI workspace before comparing source fingerprints against the baseline. Use `git merge --no-commit --no-ff`, log the before/after diff summary, and add incoming changed paths to the validated mandatory-test list. The workflow does not commit or push the merge to the contributor's branch.

Pass the resolved main SHA and merged tree ID to GPU jobs. After the action's checkout, merge that same main commit and verify the workspace tree matches the CPU selector, including when selection falls back to full buckets. Merge conflicts or tree mismatches stop execution. Missing or stale PR metadata retains the full-bucket fallback.
