# Use explicit fixtures for MFSDP v2 optimizer checkpoint tests

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Optimizer checkpoint tests use xUnit setup and teardown, bypassing `distributed_setup`. Convert them to module-level tests with an explicit `process_group_collection` fixture that depends on `distributed_setup` and uses the shared model-parallel cleanup helper.

This lets NCCL symmetric-memory backend selection return to `distributed_setup` and removes the session-scoped autouse fixture added in #8013. It completes the fixture conversion for this test file, following #8354.

All four parameterized checkpoint cases retain their computations, assertions, and parameters. Pytest node IDs change because the test class is removed. The remaining MFSDP v2 tests that lack a `distributed_setup` dependency exercise pure layout or execution-order helpers.

## Validation

- Two RTX A6000 GPUs: all four optimizer checkpoint cases followed by `test_nccl_ub_enables_symmetric_memory` passed in one fresh torchrun process: **5 passed per rank**.
- AST comparison confirmed unchanged test bodies, decorators, and parameterizations after replacing class state with the explicit fixture argument and normalizing docstring indentation.
