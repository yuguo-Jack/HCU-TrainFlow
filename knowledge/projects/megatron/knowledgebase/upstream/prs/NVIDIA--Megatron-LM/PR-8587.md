# Optionally wait for the backward PP receive on the EP comm stream

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8587) · state: open · merged: False

## Original PR description

Add ep_overlap_pp_bwd_wait_on_comm_stream (default off). With EP A2A overlap, the combined 1F1B chunk schedule then waits for the backward pipeline receive (pre_backward) on the communication stream and records the backward chunk's event there, instead of blocking the computation stream. The received gradient only gates the backward chunk, whose first layer op (combine backward) runs on the comm stream, so a late receive no longer holds back the paired forward layer. Every backward node waits on the chunk event, so ordering is kept.

Adds a unit test that delivers the backward gradient like a late pipeline receive and checks parity with the reference and the stream the receive is waited on.
