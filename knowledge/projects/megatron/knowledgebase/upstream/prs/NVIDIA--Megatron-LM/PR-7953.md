## Original PR description

## What does this PR do?

Remove `/usr/local/cuda-*/NsightSystems-cli-*/target-linux-x64/plugins/efa_metrics/` at the end of the dev Docker image’s `main` stage to address `CVE-2026-27143`. The cleanup runs as root after the expensive dependency builds, preserving reuse of their cached layers. The `jet` stage inherits the cleaned `main` image. The glob covers installed CUDA and Nsight Systems versions, and `rm -rf` succeeds when the plugin is absent.
