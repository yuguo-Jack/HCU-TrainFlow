# [fsdp, tensor_parallel] fix: preserve local linear gradient accumulation

# What does this PR do?

Fix fused local `ColumnParallelLinear` / `RowParallelLinear` weight gradients under Megatron-FSDP v1 when the main-gradient buffer must retain contributions across microbatches. With two microbatches contributing 8 and 96 per weight, the current call overwrites the first contribution and produces 96 instead of 104.

Pass `accumulate=not overwrite_main_grad` to `_wgrad_gemm`, preserving overwrite for gradients reduced on every backward. Initialize that policy immediately after FSDP creates its parameter/gradient buffers, using the existing per-parameter `_reduces_grad_every_backward` predicate. This also covers pure `no_shard` with the default `fsdp_unit_modules=None`, where unshard hooks are skipped. The existing unshard-time refresh remains in place.

The regression test checks all four sharding strategies, FP32/BF16 parameters, `no_shard` with and without a registered FSDP unit, and two accumulation cycles separated by `zero_grad_buffer()`. A bit-exact replay test covers both overwrite and accumulation in the FP32 wgrad buffer; its test file is already registered for `tensor_parallel_layers` in the determinism manifest.

`--confcutdir` avoids unrelated global data-download fixtures for these self-contained tests. Overriding `addopts` avoids the installed pytest duration reporter's `TypeError` at session completion; no test assertions are disabled.

For the separate `no_shard`, no-unit reproduction (both FP32 and BF16), the expected values for the two optimization cycles are 104 and 152. Unmodified main produces 96 and 144, with all 256 weight-gradient entries differing by 8 in each cycle. The actual initialization fix sets `overwrite_main_grad=False` before the first forward and produces 104 and 152 exactly. The second cycle starts with `zero_grad_buffer()` and changes the second microbatch contribution, so it also checks reset behavior.

An initial matrix additionally tried `optim_grads_params` without any registered FSDP unit; that reaches an existing division by zero while calculating the suggested communication unit size. The final test uses registered units for parameter sharding and retains explicit no-unit coverage for `no_shard`. The initial failed run and all per-rank logs were preserved.
