# What does this PR do?

Adds `AttnBackend.cudnn` as an enum alias of `AttnBackend.fused`, so `--attention-backend cudnn` selects TE's FusedAttention, which is cuDNN attention.

`cudnn = 2` shares the value of `fused`, so Python makes it an alias: `AttnBackend.cudnn is AttnBackend.fused`. Iteration and the argparse `choices` help text still list only `fused`, and every existing `== AttnBackend.fused` check keeps working. No behavior changes for current users.

The motivation is naming. Users don't know that "fused" is cuDNN, or that it runs the same flash algorithm (online softmax). Companion TE PR: NVIDIA/TransformerEngine#3738 adds `NVTE_CUDNN_ATTN` as an alias of `NVTE_FUSED_ATTN` and names cuDNN in the backend-selection logs. This PR does not depend on it: Megatron still sets `NVTE_FUSED_ATTN`.
