# Detect additional GPU platforms and check performance baselines before launch

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8376) · state: open · merged: False

## Original PR description

On H200, GH200, B300 or GB300, the inference performance launcher currently cannot infer the platform key. Add those names with superchip patterns before their contained discrete-GPU names, preserving explicit `PLATFORM` overrides.

Check that the case has a baseline for the selected platform before launching the server. A missing baseline now fails immediately with instructions for `RECORD_BASELINE=1` or `SKIP_COMPARE=1`; both explicit modes continue to bypass the comparison requirement. This avoids completing an expensive benchmark only to discover that no comparison exists.

Validation: `bash -n`, `git diff --check`, and 45 checks of the exact launcher preflight prefix using yq 4.44.3: nine GPU-name strings × present baseline, missing platform key, missing file, record mode and skip mode. These are shell checks, not B300/GB300 hardware validation. No model performance result is claimed.
