# Fix context-parallel normalization of masked training losses

## What does this PR do?

When a three-value loss callback returns CP-local loss sums and valid-token counts, the microbatch-averaged training path divides by each shard's local count. DDP then averages those gradients over DP × CP. Unequal masks therefore change the training objective: with one valid token, CP=2 halves the gradient and CP=4 reduces it to one quarter of the unsharded reference.

Reduce a cloned token count over the explicit CP group, normalize with the complete sequence's count, and compensate DDP's CP averaging. Pass that group through the non-pipelined, pipelined, and interleaved forward paths. Preserve the returned local count and metric aliases, the per-token/global-batch normalization path, and legacy two-value callbacks. Existing callers without an explicit group retain a documented MPU compatibility fallback.

This adds one scalar all-reduce per microbatch on the final pipeline stage when CP>1 and `calculate_per_token_loss=False` for a three-value loss callback. No performance improvement is claimed.
