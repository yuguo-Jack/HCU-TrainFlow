# MakeTE cross entropy hand the MXFP8 LM head an MXFP8 gradient

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8590) · state: open · merged: False

## Original PR description

Add TransformerConfig.cross_entropy_mxfp8_grad (default off). With the MXFP8 LM head (fp8_output_proj) and Transformer Engine's fused cross entropy, the language model binds grad_fp8_format (E5M2 for fp8='hybrid', else E4M3) to its cross entropy, and te_parallel_cross_entropy passes an MXFP8Quantizer as TE's grad_quantizer. The loss backward then returns the logits gradient already in MXFP8, which the LM head uses without quantizing it again.

The gradient has the bytes the LM head's own quantization produces, so loss and gradients are unchanged. The option is rejected without fp8_output_proj, without TE fused cross entropy, and with MuP (its logit scaling sits between the LM head and the loss). It needs a TE whose parallel_cross_entropy accepts grad_quantizer.
