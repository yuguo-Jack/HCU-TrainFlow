# Skip unit tests that need more ranks than the launch provides

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8171) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?
Three unit tests hard-code a parallel layout that needs 8 ranks and fail instead of skipping on smaller launches (e.g. a 4-GPU GB300 node):

- test_hybrid_model_with_custom_process_groups builds a TP x CP x PP grid with DP 1, so it needs exactly 8 ranks;
- TestDynamicContext.test_gqa_high_tp_partition_heads uses TP 8;
- TestMambaContextParallel.test_forward uses CP up to 8.

They raised "world_size (4) is not divisible by 8" from initialize_model_parallel. test_gqa_high_tp_partition_heads also left the model-parallel state torn down, so every later test in TestDynamicContext failed with "expert model parallel group is not initialized".

Check Utils.world_size before initializing model parallel and skip, as test_contiguous_sequence_roll.py already does. 8-rank CI runs are unchanged.
