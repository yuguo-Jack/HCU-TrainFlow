# What does this PR do?

This is **DCP V2 2/4**. It makes MoE auxiliary-loss accounting follow the effective runtime CP topology carried by each packed microbatch.

- Threads `PackedSeqParams` through TransformerLayer → MoELayer → Router, including eager fine-grained callables and the hybrid shortcut route.
- Uses TP-only reduction for runtime CP1 and runtime CP followed by TP for larger CP groups.
- Preserves local valid-token counts across in-place all-reduces while computing global counts for auxiliary-loss scaling.
- Applies runtime topology to auxiliary and sequence-auxiliary loss, preserving static behavior and DP metric averaging.
- Preserves the helper's single-group positional API; the same `reduce_group` argument also accepts an ordered tuple.
- Validates sequence-packing requirements for HybridEP/all-to-all dispatch.

Router z-loss was removed from this PR's scope during review; it is not changed here. CUDA graph support is also outside this change.

Original change authored by @zhongbozhu in [zhongbozhu/Megatron-LM@052d110](https://github.com/zhongbozhu/Megatron-LM/commit/052d110a09e3a1bcc9bac553d76838a6cbc84008). Source lineage includes #4359. The follow-up retains @ilml's local-count/in-place-reduction fix.
