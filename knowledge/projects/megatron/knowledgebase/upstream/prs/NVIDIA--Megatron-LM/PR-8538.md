# fix(distributed): reduce sequence parallel gradients per parameter

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8538) · state: open · merged: False

## Original PR description

Gradient finalization currently skips SP-marked parameters when the root model has `sequence_parallel=False`. A composite model can enable SP in its vision transformer while leaving language SP off, so those vision LayerNorm gradients must still be summed across TP ranks.

Use each parameter's `sequence_parallel` marker independently of the root flag. Keep average-gradient precedence, QK-normalization handling, frozen/unused parameters, and TP1 behavior unchanged. Related to NVIDIA-NeMo/Megatron-Bridge#6662.

Validation:
- Two H100 ranks: `TestAllReduceLNGrads` — 9 passed, 1 expected skip (root SP with TP1). New cases cover independent module SP, rank-distinct gradients, and unmarked/frozen/unused parameters; existing normalization and embedding checks also pass.
- Black, isort, Ruff, and pylint pass on both changed files. The `autoformat.sh` wrapper requires Git >=2.31; this workstation has 2.25.1, so its component tools were run directly. Optional mypy reports missing local PyTorch/pytest dependencies and existing typing findings outside this change.
- Fresh independent review completed with no blocking findings. Signed commit and DCO included.

No external code was copied.
