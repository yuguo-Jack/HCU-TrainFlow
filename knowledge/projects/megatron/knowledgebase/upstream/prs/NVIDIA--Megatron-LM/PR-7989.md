# Run mHC kernel tests in a dedicated single-worker H100 bucket

## Original PR description

## What does this PR do?

Move `test_fused_mhc_kernels.py` into a dedicated latest H100 unit-test bucket and launch it with one worker. These local kernel/reference comparisons perform no distributed communication; the current eight-worker launch repeats compilation and autotuning on every rank. In [this H100 run](https://github.com/NVIDIA/Megatron-LM/actions/runs/37801915793/job/113414234172), four backward cases consumed about 444 seconds of the general bucket's pytest runtime.

The existing bucket finder excludes the file from the general bucket once it has its own entry. All numerical cases, assertions, tolerances, and node IDs are unchanged. Legacy continues to use its own checkout's recipe.

Full runs, Testmon baseline generation, and selected runs all use the same recipe and worker count. Testmon runtime metadata now includes world size, rejecting incompatible caches and using the existing full-run fallback. A selected node ID can run independently with an empty compiler cache. Existing baselines need regeneration after the compatibility inputs change.

The runner allocation remains eight GPUs; this change removes duplicate test processes and shortens the general bucket's critical path. It does not change scheduling to allocate a single-GPU runner. This PR is independent of the other unit-test runtime changes.
