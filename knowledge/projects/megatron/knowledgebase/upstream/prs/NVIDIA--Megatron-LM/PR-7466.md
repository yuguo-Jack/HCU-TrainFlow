## What does this PR do?

Fixes #7464. Label smoothing in vocabulary-parallel cross entropy now uses the global vocabulary size and global mean log-probability.

The current forward pass averages only the local vocabulary shard and can take `log(0)` after softmax underflow. The fix reduces the shifted-logit sum across the TP group before logits are exponentiated, then computes the global mean log-probability from that sum and the global log normalizer. Backward uses the same global vocabulary size.

Related: #737 and the closed, unmerged #5522. This implementation also addresses finite losses for large logits; it does not depend on #5522 being merged.
