# [feat] enable cuda graph for the language_model sub module in VLM models

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4519) · state: open · merged: False

## Original PR description

# What does this PR do ?
  This pr enables cuda graph for the language_model sub module in VLM models (e.g. Qwen3-VL).
                                                                                                                                                                           
  When using CUDA graphs, `TECudaGraphHelper` traverses model chunks to                                                                                                    
  locate the decoder via `get_attr_wrapped_model`. For Vision-Language                                                                                                     
  Models such as Qwen3-VL, the decoder is nested under a `language_model`                                                                                                  
  wrapper, so the traversal returned the VLM container instead of the                                                                                                      
  actual decoder. This caused a mismatch when computing graphable layers.                                                                                                  
                                                                                                                                                                           
  Add an explicit unwrap step: after resolving `chunk_with_decoder`, check                                                                                                 
  for a `language_model` attribute and descend into it before proceeding.                                                                                                  
  This ensures the CUDA graph logic operates on the correct decoder object                                                                                                 
  regardless of whether the model is a plain language model or a VLM.
