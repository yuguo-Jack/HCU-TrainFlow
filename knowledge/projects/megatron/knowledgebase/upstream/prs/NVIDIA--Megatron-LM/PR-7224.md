# DeepSeek-V4.1-Flash Support Tracker

Last updated: 2026-09-18

This PR tracks DeepSeek-V4.1-Flash support in Megatron Core and provides a consolidated reference implementation. **This PR will not be merged.** Changes will be upstreamed through separate PRs linked here.

Current scope: text-only training, excluding vision and Engram.

## Progress

Checked items indicate implementation in this reference branch.
Validation coverage varies by feature.

- [x] Generalized state interface and cross-layer state sharing
- [x] CSA2 attention (SWA/Full / Reindex / Reuse) and indexer loss
- [x] Single-pass mHC and Hybrid model integration
- [x] Packed sequence support and fused kernels
- [x] Initial PP/VPP, CP, activation recompute, and CUDA Graph integration
- [ ] Complete GPU and distributed end-to-end validation
- [ ] Performance benchmarking and tuning
- [ ] Upstream changes through focused PRs
