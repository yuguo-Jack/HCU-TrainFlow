# What does this PR do?
Removes the per-request `Generation log probs is None` warning from the chat completions endpoint. Every chat completion served without log probs (the common case) logged a WARNING carrying the full JSON-dumped result, flooding server logs under load. Log probs being absent is expected, not an error.
