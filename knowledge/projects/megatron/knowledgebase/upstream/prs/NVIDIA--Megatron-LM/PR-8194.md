## Original PR description

## Purpose and relationship to the existing ports

Draft main-based companion for #7441, completing its **packed THD/static-CP attention/indexer determinism** coverage. The automated Mirror Dev to Main run for #7441 did not create a mirror: the source PR has no `mirror-to-main` label. The previous packed integration #7921 is closed without merging.

This is intentionally not a second monolithic copy of every #7441 change:

| Area | Main landing path |
| --- | --- |
| Stable Top-K, SBHD forward ordering, attention/indexer backward | #7708 (shared prerequisite, temporarily included here) |
| Packed THD/static CP, padding and forward/replay ordering | This draft, adapted from the two packed commits of #7921 |
| TE operation-fuser grouped-MLP probability gradients | Existing independent #7769; not duplicated here |
| Deterministic router auxiliary-loss guard | Already present on main through its dedicated auxiliary-loss-fusion option |

The branch starts from main `3bb482c487cd447a2b40a3bf076ab14cad514e13` and temporarily carries the three shared #7708 commits. Please land/reconcile #7708 first, then rebase this draft to keep the remaining packed-only diff. Its current scope includes the shared prerequisite so the branch is buildable against main; it does not target a bot `pull-request/*` branch.

## Changes

- Pass explicit deterministic mode through packed indexer Top-K and both packed attention backward paths, preserving default-mode dispatch and static CP process-group plumbing.
- Preserve compressed-first compact key order between no-grad and training forwards, with sink-only padded rows and no mutation of caller-owned index tensors.
- Keep clipped-KL/indexer gradients, global real-token normalization, and deferred CP reductions from the existing port.
- Remove main's now-obsolete blanket rejection of packed deterministic mode. Keep backend/layout/static-CP validation, and test both mode settings against valid and invalid inputs. Unsupported deterministic runtimes and dense indexer backward still fail at their respective wrappers.
- Mark the five parameterized SM100 attention/indexer regression cases for the GB200 lane. On #7708's current CI, H100 skips those cases and the GB200 bucket excludes their unmarked file; this draft explicitly selects them.
- Reconcile the single test-import conflict by retaining both main's `cp_utils` use and the packed port's `packed_sparse_attention` use.

Scratch allocation follows #7708's per-call cuDNN allocation strategy. This does **not** copy #7441's shared device-global workspace cache or resolve the outstanding review on that dev implementation.

- Kernel determinism coverage checker: passed for all nine changed files; no exemption label or test disabling.
- 39 CPU-adapted exact-source numerical/replay/dispatch cases passed for the shared helpers.
- 10 exact-source CPU packed-wrapper/layout cases passed, including padding preservation, deterministic compaction and the new layout-validation regression.
- Structural check confirms explicit GB200 selection for the five SM100 regression variants.
- `git diff --check` and local signature/sign-off verification passed.

**Validation boundary:** Osaka has no GPU. These isolated CPU probes bypass GPU package/conftest initialization and stub kernel/collective work; they do not certify CUDA, CP1/2/4, graph replay, or the rebased branch's end-to-end numerics. Optional mypy still reports missing training dependencies/existing typing issues and is not certified clean. The earlier GB300 results documented in #7708/#7921 are provenance, not a claim that this new head passed GPU tests.

Keep this PR **draft** pending exact-head GPU CI (including the real packed CP and SM100 cases), reconciliation with #7708, and the required reviews. No performance claim and no whole-recipe determinism certification are made.
