# What does this PR do?

Provide an mRoPE tensor when capturing Transformer Engine CUDA graphs. When multi-latent attention is disabled, the graph helper includes rotary inputs for RoPE but omits mRoPE, so replay silently drops position embeddings and produces different losses and gradients from eager execution. The captured tensor provides the input shape; replay supplies the actual embeddings.

This affects graph training independently of activation offloading. In BF16 Qwen3.5-0.8B language-model training with local pretrained weights and tokenized training data at `aecc0e8116912554f27a62a51ad2aeca479a7f9e`, eager and graph states match before capture and diverge on the first replay with offloading disabled. Vision and MTP were not included.
