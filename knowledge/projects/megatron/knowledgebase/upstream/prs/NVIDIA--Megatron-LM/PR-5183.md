## Summary

`test_gumbel_determinism` compares two `FlextronRouter` instances bit-for-bit after copying weights. The Gumbel path is torch-seeded, but `FlextronRouter.forward()` also samples `hard_sample` from Python `random.random()`. If the two forwards draw different hard/soft branches, the bit-exact assertion can fail even though the Gumbel seed path is deterministic.

This change seeds Python `random` identically before each router forward in the test, restores the previous Python RNG state afterward, and removes the `flaky_in_dev` quarantine. Production router behavior is unchanged.
