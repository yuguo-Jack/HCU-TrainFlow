# ci(review): use github app token for label swaps

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8688) · state: closed · merged: True

## Original PR description

## Background

Auto Swap Labels uses `secrets.PAT` to evaluate CODEOWNERS team approvals and update review-stage labels. The built-in `github.token` cannot read organization team memberships.

## What changed

- Mint a short-lived installation token for the existing [nemo-automation-bot](https://github.com/apps/nemo-automation-bot), using `vars.COMMUNITY_BOT_ID` and `secrets.COMMUNITY_BOT_KEY`.
- Restrict the token to Megatron-LM with `members: read` and `pull_requests: write`, and pass it to `swap_pr_labels.py` as `GH_TOKEN`.
- Reduce the built-in token to `contents: read` and `actions: read` for checkout and artifact downloads.

## Details

The community App has organization membership access; the release App (`BOT_ID` / `BOT_KEY`) does not. Token creation uses the same pinned `actions/create-github-app-token` revision as the existing Community Bot workflow. It runs only after a valid PR number is available and automatically revokes the token when the job finishes.
