# Add deterministic per-source training subsets and pool preparation

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8847) · state: open · merged: False

## Original PR description

## What does this PR do?

Add deterministic per-source training subsets to the GPT data pipeline. A training blend can specify `(weight, prefix, probability)` triples: mixture weights retain their meaning, while each probability selects a fixed prefix of a seeded permutation of indexed sequence IDs. This lets runs share nested eligible-data pools independently of their sample counts or training horizons.

The implementation wires the subset seed and probabilities through the shared GPT/Hybrid/cache configuration, GPT and FIM datasets, and fast-cache metadata generation. Active downsampling contributes to cache identity; probability one preserves legacy ordering and cache keys. Unsupported split/dataset combinations fail early. Cached-logit distillation rejects effective downsampling, including when hash checks are disabled.

`python -m tools.prepare_data_subsets` builds nested token-budget blends from native local indexes, preserving weights and source order. It supports integer token storage such as uint16/int32, reports actual token counts after whole-sequence overshoot, and refuses to overwrite an output directory. Documentation includes generic examples. Selection is over indexed sequences; it is whole-document selection only when preprocessing emits one sequence per document.

## Validation

- **269 native CPU tests passed:** 67 data/config tests, 37 subset-tool tests, 75 provider-parity cases, and 90 metadata/distillation tests. The 67 data/config tests were rerun successfully after rebasing onto current public main.
- Generated numeric-weight blends were loaded through the real parser, C++ dataset helpers, tokenizer and GPTDataset builder. Retained sequence IDs and token totals matched the helper summary for uint16/int32 sources and nested budgets.
- The repository autoformatter passed Black, isort, Pylint and Ruff. Its advisory mypy step still reports 60 diagnostics; it is non-gating in the repository script. New typing diagnostics introduced by this change were resolved.
- GPU/distributed training was not run. The provider-parity selection excluded 28 GPU/model-parallel cases.
