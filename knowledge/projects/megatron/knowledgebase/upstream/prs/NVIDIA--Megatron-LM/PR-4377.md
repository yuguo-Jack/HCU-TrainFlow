- asolergi-nv · comment · 2026-04-23T14:24:28Z · [source](https://github.com/NVIDIA/Megatron-LM/pull/4377#issuecomment-4305232064)

Thanks for the fix, the fallback path was definitely broken. Two things worth tightening before merge though:

 - The three autograd Functions actually import three different extensions (scaled_masked_softmax_cuda, scaled_upper_triang_masked_softmax_cuda, scaled_softmax_cuda) and the causal / non-masked paths will still crash if only one of them is missing. Probably worth probing all three. Also, I'd catch ImportError rather than ModuleNotFoundError — we've hit cases on mismatched CUDA/PyTorch builds where the .so loads but throws on an undefined symbol, which wouldn't be caught here.
 - Minor, but if someone explicitly set scaled_masked_softmax_fusion=True and silently gets the torch path, that's a pretty painful thing to debug later. A one-shot warning would save someone a bad afternoon.
