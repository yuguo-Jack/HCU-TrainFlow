# Fix 32-bit input offsets in batch-invariant weighted SwiGLU

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7651) · state: closed · merged: True

## Original PR description

Fixes #7650.

The weighted SwiGLU kernel derives input addresses from a 32-bit `xoffset`. When an input row starts at element `2^31`, the address wraps and CUDA reports an illegal memory access. Cast `xoffset` to `int64` before calculating the address.

The new test reproduces the fault on `main` and passes on this branch. I also extended the existing replay test to cover a second block size, as required by the repository's determinism check.

I ran the three weighted SwiGLU tests, the replay test, Black, and the kernel coverage check locally. The large test skips when less than 6.5 GiB of GPU memory is free. I did not run the full suite.
