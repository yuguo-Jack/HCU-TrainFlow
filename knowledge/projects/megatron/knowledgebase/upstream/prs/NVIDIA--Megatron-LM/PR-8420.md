# Compile the CuTeDSL GDP chunkwise-CP boundary variants at the first forward

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8420) · state: closed · merged: True

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

Packed batches can expose new GDP CP boundary cases several steps into training, triggering kernel compilation while other ranks wait. Run all four preceding/following-summary cases on a small dummy shard at the first forward so those variants are compiled upfront.

Applies to the CuTeDSL GDP backend with chunkwise CP > 1. Covering different token and sequence counts with the same compiled kernels requires `gdp-attn-fused >= 0.5.2`. Adds a test that checks for later compilations.

Unchanged cherry-pick of [#726](https://github.com/NVIDIA-NeMo/nv-mistralai-megatron/pull/726): `461b7eced0` → `9676afc65d`. The original author, message, coauthor, and source SHA reference are preserved.

Validation: formatting, lint, syntax, and kernel-determinism coverage checks passed. GPU tests and benchmarks were not rerun; `mypy` was unavailable.

### Add bit-exact replay coverage for the new warmup dispatch

The [first-forward warmup](https://github.com/NVIDIA/Megatron-LM/blob/f3369ffb732efd43ed36386817ca65cb57c18206/megatron/core/ssm/context_parallel/gdp_cutedsl.py#L138-L166) now executes four GPU forward/backward protocols before processing real inputs. However, the [added regression test](https://github.com/NVIDIA/Megatron-LM/blob/f3369ffb732efd43ed36386817ca65cb57c18206/tests/unit_tests/ssm/test_gdp_chunkwise_context_parallel.py#L261-L276) only checks compilation counts: it discards the output and all five input gradients. Numerical differences between the first, warming execution and subsequent executions would therefore go undetected. This is a coverage gap, not an observed numerical failure.

The light-review rubric requires bit-exact coverage for changed external-library GPU dispatch, consistent with the [repository requirement](https://github.com/NVIDIA/Megatron-LM/blob/e4eb89b3bb3bb55c31606ee9d672038e17caa2a0/docs/developer/determinism/testing.md#L10-L38). The [current manifest](https://github.com/NVIDIA/Megatron-LM/blob/f3369ffb732efd43ed36386817ca65cb57c18206/tests/unit_tests/determinism/kernels/manifest.py#L695-L706) explicitly records CuTeDSL GDP as uncovered and does not register this backend.

**Correction:** add a guarded CuTeDSL CP replay test under the determinism kernel suite and register this backend as a dispatch source. Parameterize all four preceding/following-summary combinations, keeping one backend instance across replays so the reference execution performs warmup and later executions skip it. The invariant is that warmup cannot change real outputs or gradients.

A suggested test core, after constructing the nonzero operands and packed layout used by the new regression, is below. It needs `dataclasses.replace`, the packed-summary wrappers, and `assert_replays_bit_exact`; verify it on supported hardware before adopting:

```python
backend = CuTeDSLGatedDeltaProductCPBackend(recompute_chunk_num=1)

def replay(q, k, v, g, beta):
    local_inputs = replace(inputs, q=q, k=k, v=v, g=g, beta=beta)
    summary, local = backend.cp_forward_prepare(local_inputs)
    prefix = CPForwardPackedSummary(summary.packed.unsqueeze(0)[:num_preceding])
    output, saved = backend.cp_forward_apply(local, prefix)
    summary, backward = backend.cp_backward_prepare(torch.ones_like(output), saved)
    suffix = CPBackwardPackedSummary(summary.packed.unsqueeze(0)[:num_following])
    gradients = backend.cp_backward_apply(backward, suffix)
    return (output, *gradients)

assert_replays_bit_exact(
    replay,
    (inputs.q, inputs.k, inputs.v, inputs.g, inputs.beta),
    replays=3,
    backward=False,  # The callable already returns all five gradients.
)
```

**Preservation and acceptance — proposed, not executed:** on supported SM100 hardware, require byte-identical output and each input gradient between the first and subsequent executions for every boundary combination. Retain strided q/k, contiguous v, multiple packed sequences, and recompute coverage; keep the existing assertion that later boundary cases add no compilation calls. Preserve the existing [BLH, packed-THD, and selective-recompute equivalence cases](https://github.com/NVIDIA/Megatron-LM/blob/f3369ffb732efd43ed36386817ca65cb57c18206/tests/unit_tests/ssm/test_gdp_packed_seq.py#L437-L483). Explicitly skip when the optional package or required hardware is unavailable, without an unconditional optional import.

Static inspection covered both changed files and their directly affected GDP adapter, mixer, collective, and testing contracts. GPU tests were not executed.
