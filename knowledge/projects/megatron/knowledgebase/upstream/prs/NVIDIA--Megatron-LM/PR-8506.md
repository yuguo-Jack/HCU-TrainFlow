# Support disaggregated KV handoff when TP exceeds the KV-head count

# What does this PR do?

Supports disaggregated KV handoff for models whose TP size exceeds their KV-head count (e.g. Nemotron-3 Nano: 2 KV heads at TP4), where `Attention` replicates each KV head across `tp_size // num_query_groups` TP ranks.

**Problem.** `KVShardLayout` only modelled an even head split. For replicated heads, `compute_buffer_geometry` silently dropped the layout (`heads_per_partition * tp_size != num_kv_heads_global`), so the exported transfer metadata lacked `num_kv_heads_global`. The coordinator then rejected the engines with `model-parallel ranks advertise inconsistent KV transfer geometry`.

**Change.**
- `KVShardLayout` accepts heads and TP that nest in either direction (the same rule as `TransformerConfig`) and maps a replicating rank to head `tp_rank // (tp_size // num_heads)`, matching `Attention`. New helpers: `kv_replicas()`, `kv_replica_index()`.
- `plan_kv_reshard` pairs each destination with the source replica whose index equals the destination's own replica index, taken modulo the source replica count. This spreads reads across replicas and keeps homogeneous layouts rank-to-rank. The choice depends only on the (src, dst) pair. That matters because the NCCL push side plans against its own layout alone and must agree with the receivers.
- `compute_buffer_geometry` no longer silently drops the layout. A genuine `heads_per_partition` mismatch now raises.

EP/ETP source deduplication is unchanged.

## Testing

- `test_kv_reshard.py`: reassembly sweep over replicated layouts (replicated→replicated, →split, whole→replicated, replica count + PP change, MQA, replicated→multi-head); replica pairing; plan pairwise-consistency (single-source plan == its share of the full plan); invalid head/TP rejection.
- `test_kv_transfer_backends.py`: TP4 over 2 KV heads exports a layout on every rank and passes the coordinator's transfer-signature check (fails before this change).
- `test_nccl_transfer_backend.py`: real-GPU NCCL push/pull extended with replicated layouts (TP 2→2, 2→1, 1→3 with 1 KV head; 4→2 with 2 KV heads, needs 6 ranks).
- End to end (4x GB200, tiny GPT with 1 KV head, greedy, NCCL backend, coordinator + `MegatronLLM`):
  - prefill TP2 → decode TP2: tokens and logprobs bitwise identical to a non-disaggregated TP2 run.
  - prefill TP2 → decode TP1 and TP1 → TP2: all tokens identical to the non-disaggregated decode-TP baseline; logprob deltas at the bf16 cross-TP level.
