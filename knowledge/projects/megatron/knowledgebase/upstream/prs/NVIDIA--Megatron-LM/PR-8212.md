# fix(optimizer): avoid TE state copies in distributed checkpoint metadata

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8212) · state: open · merged: False

## Original PR description

## What does this PR do?

Avoid temporary copies of GPU optimizer state when DistributedOptimizer saves or restores group metadata with Transformer Engine FusedAdam. Near the GPU memory limit, the existing roundtrip through TE's tensor-state serialization can cause checkpoint resume to OOM even when the final optimizer state fits.

For the exact TE FusedAdam class on TE 2.18+, initialize missing state directly in its final representation, serialize group metadata without unscaling tensor state, and restore group metadata while preserving existing state buffers. Parameter-state checkpoint loading remains responsible for restoring tensor contents. Older TE, other optimizers, subclasses, and optimizers with registered load hooks retain their existing path.
