# Avoid duplicate workloads from repeated test-case selections

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8071) · state: open · merged: False

## Original PR description

Selecting a test case more than once in the comma-separated test_cases filter duplicates its workload, potentially scheduling the same training job repeatedly. Treat the selection as a set while preserving the workload order.

Validation: three CPU selection regressions fail on the baseline and pass with the fix. Black, isort and Ruff passed. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
