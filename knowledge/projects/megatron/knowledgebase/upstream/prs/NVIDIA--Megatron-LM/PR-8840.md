# [dev] Capture packed-sequence Gated DeltaNet / KDA layers in chunk-wise CUDA graphs

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8840) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

`cuda_graph_impl="chunk_wise"` (PR #5258) rejects every GDN-family layer together with `--sequence-packing-scheduler`: the FLA kernels derive their chunk indices on the host from the *values* of `cu_seqlens` and cache them by tensor identity, so a captured block graph, whose static boundary buffers are refreshed in place, would replay the pack layout of the capture sample.

This PR admits two kernel paths that read the boundaries on the device:

- Gated DeltaNet on `gdn_kernel_backend="transformer_engine"` (cuDNN `gated_delta_net`, plans by shape; capture once, replay six packings: outputs and all gradients bitwise equal to eager).
- KDA when the installed flash-linear-attention provides `chunk_kda(use_graph=True)` (>= 0.6.0, detected through the kernel signature, so the current 0.5.1 pin keeps rejecting KDA until the dependency is bumped).

Both without context parallelism or with static headwise CP. FLA GDN, GDN2, chunkwise CP, dynamic CP and the fused pre-GDR path stay rejected with a message naming the blocking setting.

Megatron-side changes:

- `PackedSeqParams.cu_seqlens_validated` + `packed_seq_idx_on_device`: the chunk replay validates each pack on the host once per microbatch before writing it into the static buffers; the metadata rebuilt inside the graph carries a device-built per-token sequence index.
- `_GDNBase._resolve_cu_seqlens(validated=...)`: the layers skip their device-to-host checks when the replay validated the pack; a layer whose kernel path cannot replay other packs refuses validated metadata.
- Per-layer support check (`packed_chunk_graph_blockers()` on GDN / KDA / GDN2, run by the chunk block before the first capture and the first replay): the config gate keys on `experimental_attention_variant`, which GDN layers built from a hybrid layer pattern (`G`) do not carry.
- `causal_conv1d_packed_masked`: the packed causal convolution as a fixed-shape `torch.autograd.Function` masked by the sequence index (FLA's varlen conv sizes its grid on the host); saves only the bf16 input, recomputes taps in backward, fp32 accumulation.
- `packed_gated_delta_net_chunk_graph_blockers` replaces the unconditional rejection; the generic THD CP layout-conversion rejection no longer fires for headwise CP under chunk graphs.

**Tests**

- `test_thd_cuda_graph.py::TestPackedGatedDeltaNetChunkGraph`: GDN (TE backend) and KDA models, chunk-wise capture, four packings replayed in two orders vs eager (loss and every gradient), undersized pack rejected on the host; cp=1 and headwise cp=2 (torchrun x2) pass on GB200 (26.07 image, TE 2.20, cudnn-frontend 1.29.0; KDA with FLA 0.6.0, skips on 0.5.x). Hybrid `G*` stack: FLA backend rejected at the block, TE backend admitted.
- `test_cuda_graphs.py::test_chunk_config_packed_gated_delta_net_support_matrix`: admitted / rejected boundary.
- `test_ssm_kernels.py::test_causal_conv1d_packed_masked_replays` and `test_dev_sync_kernels.py::test_kda_recurrence_packed_graph_mode_replays`: bit-exact replays plus reference checks.
- E2E: 4-layer GDN/attention model, TE backend, headwise CP4, varlen 1K-8K packs, eager vs chunk graphs: per-step loss within 1.2e-3 relative, no NaN.

**Known issue outside this PR**

cuDNN frontend 1.29.0 keeps process-wide GDN plan/handle state; a second cuDNN GDN model instance in one process can crash in its first forward (same shapes after the first was released, or after a hybrid stack's capture). Training builds one model and is unaffected; the test class only builds (never runs) the hybrid stack because of this. To be reported to the cuDNN frontend / TE owners.

**Not in this PR**

flash-linear-attention bump to 0.6.0 (needed for KDA in CI), GDN2, chunkwise CP, the FLA GDN backend (needs upstream `USE_GRAPH` guards), fused pre-GDR under packed chunk graphs.
