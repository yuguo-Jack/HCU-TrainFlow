# Pass formatter arguments separately in the lint helper

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8063) · state: open · merged: False

## Original PR description

The lint helper passes a complete command string to subprocess.check_call with shell=False, so Python searches for an executable named after the entire command. Pass an argument list instead; filenames containing spaces remain one literal argument.

Validation: standalone CPU unittest regressions exercise the actual helper with isolated fixtures and mocked external boundaries. The regression fails on the base commit and passes with this fix. Python compilation and test formatting pass. No live Slack or team mutations were performed. The commit is signed and includes its sign-off.


Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
