# What does this PR do?
Removes `ModelParallelConfig.cpu_offloading_weights`, which is passed into TransformerEngine.

This parameter used to do something in TE 2.2, but it was deprecated, and later on as of TE 2.10 it does nothing at all.

This will require matching changes in Megatron Bridge.
