### Add a regression test for non-deepcopyable builders

The [new derivation logic](https://github.com/NVIDIA/Megatron-LM/blob/41855abf5400c5523246f5782e641a520bf78bf5/megatron/core/transformer/experimental_attention_variant/dsa_layer_specs.py#L64-L88) deliberately avoids copying optional-dependency builders. The [existing DSA spec tests](https://github.com/NVIDIA/Megatron-LM/blob/41855abf5400c5523246f5782e641a520bf78bf5/tests/unit_tests/transformer/test_attention_variant_dsa_gqa.py#L154-L182) check module selection, upstream nonmutation, and mixer differences, but do not exercise a builder that rejects deepcopy. With dependencies installed, those assertions also pass under the old implementation, leaving the import-failure mechanism unpinned by a unit test.

**Suggested addition** to that test file, using its existing imports:

```python
from dataclasses import replace

from megatron.core.transformer.experimental_attention_variant.dsa_layer_specs import (
    _with_dsa_gqa_attention,
)


class _UncopyableBuilder:
    def __call__(self, *args, **kwargs):
        raise AssertionError("Spec derivation must not instantiate builders")

    def __deepcopy__(self, memo):
        raise TypeError("cannot pickle 'cell' object")


@pytest.mark.parametrize("upstream", [hybrid_stack_spec, gated_delta_product_stack_spec])
def test_dsa_derivation_does_not_copy_optional_builders(upstream):
    mixer = replace(upstream.submodules.mamba_layer, module=_UncopyableBuilder())
    source = replace(upstream, submodules=replace(upstream.submodules, mamba_layer=mixer))
    derived = _with_dsa_gqa_attention(source)

    assert derived.submodules.mamba_layer is mixer
    assert derived.submodules.attention_layer is not source.submodules.attention_layer
```

**Preservation and acceptance:** This proposed test should return normally for both upstream stacks; reverting to whole-stack deepcopy should raise the synthetic `TypeError`. Retain the existing assertions that both derived stacks use `DSGroupedSelfAttention`, neither upstream attention module changes, and the two mixers remain different. Also check that separate derivations receive distinct indexer specs and retain the upstream dense-attention builder for warmup. The invariant is selective copying without instantiating builders or mutating upstream specs—not restoring whole-stack deepcopy.
