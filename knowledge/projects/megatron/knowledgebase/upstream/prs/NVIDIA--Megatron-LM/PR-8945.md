### Add an EGTP-remat regression case

The [new grouped-activation test](https://github.com/NVIDIA/Megatron-LM/blob/a074351af0b28de6143bf4eb9e542336bb8897c0/tests/unit_tests/dist_checkpointing/models/test_moe_experts.py#L182-L207) leaves `expert_gtp_remat_size=1`. In that configuration, `expt_dp` and `expt_dp_gtp_remat` [are aliases](https://github.com/NVIDIA/Megatron-LM/blob/a074351af0b28de6143bf4eb9e542336bb8897c0/megatron/core/parallel_state.py#L1697-L1717). Selecting `self.dp_group` instead of `self.dp_group_gtp_remat` would therefore still pass, leaving the rematerialization-specific part of this fix unprotected. With EGTP-remat size 2, that selection gives rematerialization peers duplicate main-replica IDs, which [checkpoint integrity validation rejects](https://github.com/NVIDIA/Megatron-LM/blob/a074351af0b28de6143bf4eb9e542336bb8897c0/megatron/core/dist_checkpointing/validation.py#L458-L474). The invariant is one owner for the shared activation object across ETP, EP, expert-DP, and EGTP-remat.

Extend this test to remat sizes 1 and 2. Preserve its existing replica-ID assertion and full-model save for size 1. For size 2, save only the activation entries: the current [test helper's process-group builder](https://github.com/NVIDIA/Megatron-LM/blob/a074351af0b28de6143bf4eb9e542336bb8897c0/megatron/core/transformer/moe/moe_utils.py#L1763-L1783) doesn't populate `expt_gtp_remat`, so simply parameterizing the full-model save would also exercise unrelated, unsharded linear-weight setup.

Proposed patch for [the grouped-activation test](https://github.com/NVIDIA/Megatron-LM/blob/a074351af0b28de6143bf4eb9e542336bb8897c0/tests/unit_tests/dist_checkpointing/models/test_moe_experts.py#L177-L207), to verify before adopting:

     @pytest.mark.skipif(
@@
-    def test_grouped_te_activation_extra_state_tracks_expert_dp_replica(self, tmp_path_dist_ckpt):
+    def test_grouped_te_activation_extra_state_tracks_expert_dp_replica(
+        self, tmp_path_dist_ckpt, expert_gtp_remat_size

@@

-            2, 1, expert_model_parallel_size=2, expert_tensor_parallel_size=1, order="tp-ep-dp-pp"

The remat-size-2 case must produce eight distinct activation replica IDs with exactly one main replica. Changing the activation DP coordinate to `self.dp_group` must fail that case while the existing remat-size-1 full-model save remains valid.
