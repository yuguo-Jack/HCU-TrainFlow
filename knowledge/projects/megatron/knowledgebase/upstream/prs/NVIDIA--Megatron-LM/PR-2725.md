# docs: fix MoE GPU-count formulas, Mistral launch args, and typos

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/2725) · state: open · merged: False

## Original PR description

Fixes the MoE GPU-count calculation and two errors in the Mistral launch arguments, plus documentation typos across six files.

## Changes

- Replace `TP × PP × CP × EP × DP` with separate attention (`TP × CP × PP × DP`) and expert (`EP × ETP × PP × EDP`) GPU-count formulas. Define the parallelism dimensions, explain how DP and EDP are derived, and link to the MoE documentation.
- Fix the missing continuation backslash after `--attention-softmax-in-fp32` and correct `--disable-bia-linear` to `--disable-bias-linear` in the Mistral instructions.
- Correct the documentation build guide's reference from NeMo RL to Megatron Core.
- Fix wording in the fusion guide and capitalization, hyphenation, and spacing in the BERT and GPT API guides.

## Formula scope

The GPU-count formulas describe standard MoE parallel folding with GTP/EGTP rematerialization factors set to 1. Configurations with larger rematerialization factors require accounting for those additional dimensions.

## Validation

- Compared all six changed files with upstream `main` at `07046cc6b8b7479ba05e6b47ed25f3f8e6634573`; the issues addressed by this PR remain present.
- Checked the parallelism formulas against process-group initialization for the standard configuration.
- Documentation-only changes; no training or runtime tests were run for this refresh.
