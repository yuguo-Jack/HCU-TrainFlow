# What does this PR do?

Forward-only evaluation before training warmup can leave the activation-offload policy based on empty saves. Fraction zero can start copying when later microbatches grow, and chunk progression can advance before all forward groups have run. Separately, a fallback reload can read before D2H completes, and pooled D2H writes can overwrite a buffer still used by queued H2D.

Preserve warmup across forward-only schedules, keep fraction-zero groups resident, advance chunks by remaining forward groups, and order the existing transfer streams before reading or reusing pinned storage. This PR changes the shared manager and its three native schedule call sites; it adds no GDN scope or numerical kernel change.

Tests cover explicit phase/process-group routing, growing saved tensors at fractions zero and one, delayed D2H, and pooled H2D buffer reuse. The generic tests use the existing `core_attn` scope. The fraction policy applies after warmup; warmup can still copy eligible tensors to collect size statistics.
