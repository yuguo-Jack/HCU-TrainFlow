# refactor(hybrid): add LayerInputs call shape and core layer interface

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8265) · state: open · merged: False

## Original PR description

Hybrid layers currently require separate call signatures in the hybrid loop, checkpoint replay, shortcut blocks, and MTP depths. This adds `layer(hidden_states, LayerInputs)` across those paths and an experimental `LayerInterface` for cores that return additive updates. This is PR 1 of the five-part hybrid-layer interface refactor.

The change adds per-core and skeleton adapters, transitional `GraphableMegatronModule` dispatch, and `MoESubmodules.pre_norm` (defaulting to `IdentityOp`). MoE cores return routed and shared-expert outputs as separate addends while preserving dispatcher stream waits and cleanup. Hash routers retain token-ID gating, and checkpoint replay uses the same exact `MambaLayerConfig` predicate for chunkwise CP metadata as eager execution. Unsupported cross-attention calls fail explicitly, and the mHC recompute error points to the supported configuration.

Custom layers supplied to `HybridStack` must accept the new call shape; the migration guide documents this contract. Legacy forward APIs, the GPT `TransformerBlock` path, checkpoint names, CUDA-graph argument sets, functional recipes, and golden values are preserved. Scheduling, two-phase execution, and recurrent-state protocols remain follow-ups.
