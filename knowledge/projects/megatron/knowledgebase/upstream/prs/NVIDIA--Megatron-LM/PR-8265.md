# Refactor: Cleanup hybrid model interfaces and standardize layer interfaces

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8265) · state: open · merged: False

## Original PR description

Hybrid execution needs a common call contract for interchangeable layers. Separately, models, blocks, and helpers need a way to pass shared arguments without repeating long argument lists. This PR addresses both needs with shared input-packing machinery and a separate layer interface. This is PR 1 of the five-part hybrid-layer interface refactor.

- `@bind_aux_inputs` is an argument-packing utility. It packs and unpacks named values through `AuxInputs`, reducing argument lists for layers and non-layer code such as models, blocks, and helpers. Using it does not make a component implement `LayerInterface`, require interchangeable behavior, or impose a return format. The decorator alone preserves the method's natural result.
- Inheriting `LayerInterface` opts a layer into the common call contract: `layer(hidden_states, aux_inputs)` returns `(hidden_states, LayerAuxOutputs)`. Inheritance automatically binds `forward`, including subclass overrides; cores do not also need a decorator. Output normalization comes from this inheritance, not from argument packing. `LayerAuxOutputs.bias` carries any bias left for the caller to apply.

The caller determines whether a common layer contract is needed. Attention, MLP, MoE, and recurrent cores use `LayerInterface` because callers can substitute them. TransformerLayer, MambaLayer, ShortcutMoEBlock, and the hybrid mHC wrapper also use it because HybridStack calls them interchangeably. HybridStack and MTP use argument packing while retaining their own return formats. Argument packing is not restricted to layers or layer wrappers.

The shared inputs are read-only. Binding selects the method's named arguments and passes remaining fields downstream through `aux_inputs` when declared. Existing explicit-argument calls retain their natural results. The migration guide documents custom HybridStack layers, which must support the common layer call contract.
