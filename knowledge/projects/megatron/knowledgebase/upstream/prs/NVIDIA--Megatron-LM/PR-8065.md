# Recognize copyright headers following executable script shebangs

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8065) · state: open · merged: False

## Original PR description

Executable Python scripts keep their shebang on the first line, but the copyright checker only accepted the copyright notice at byte zero. Permit a notice immediately after a shebang while continuing to reject notices below executable code.

Validation: standalone CPU unittest regressions exercise the actual helper with isolated fixtures and mocked external boundaries. The regression fails on the base commit and passes with this fix. Python compilation and test formatting pass. No live Slack or team mutations were performed. The commit is signed and includes its sign-off.
