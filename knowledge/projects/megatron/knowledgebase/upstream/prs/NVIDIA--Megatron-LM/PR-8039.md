# Extract build_process_group_collection from initialize_model_parallel

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8039) · state: open · merged: False

## Original PR description

**Why.** `initialize_model_parallel()` creates the process groups of the standard grid and writes them into about 50 `parallel_state` globals. `ProcessGroupCollection.use_mpu_process_groups()` copies them back out, and code that needs the standard grid without the globals (inference sub-grids, Megatron-Bridge) rebuilds it with its own code. This PR adds one builder that later migration steps can use.

**What.**
- `build_process_group_collection(*, ...)` creates the groups and returns `(ProcessGroupCollection, StandardGridExtras)` without setting any `parallel_state` global. It takes the keyword arguments of `initialize_model_parallel()` except the virtual-pipeline size and the deprecated `hybrid_context_parallel`. Every collection field is set, to `None` where this rank is not a member or the group is not built. `StandardGridExtras` holds what the collection has no field for: Gloo groups, the TP x DP group, GTP-inclusive partial DP groups, dynamic CP groups and global rank lists.
- The body is the previous one with locals instead of globals: same groups, order, `group_desc`, `pg_options`, backend and timeout.
- `initialize_model_parallel()` keeps its signature, registers the result in the existing globals and returns the collection.

**Tests.**
- New `test_build_process_group_collection.py` (fails on main): the returned collection holds the objects `use_mpu_process_groups()` returns; with every accessor patched to raise and another grid registered, the builder reproduces the registered grid's ranks and changes no global; rank-offset windows.
- A parity harness on 8- and 16-rank CPU worlds over 49 and 62 configurations: every `new_group` call, barrier, global, accessor and shim field matches main.
- Existing suites match main on 4 GPUs.

**Compatibility.** The signature is unchanged; the return value is new. If building fails nothing is registered, and a rank outside a group no longer keeps that group's rank list from an earlier initialization.

**Landing order.** If #6259 lands first, its two Gloo collection fields must be set here too. #8026 conflicts at the end of `initialize_model_parallel()`; resolve by keeping this side. The API shape (tuple return, `StandardGridExtras`) is open for discussion.

Part of #6307.
