# What does this PR do?
Make `cfg.rng` authoritative for seed, DP-random initialization, and RNG tracker selection while preserving the existing CLI and checkpoint compatibility.

- Read owned seed and DP-random-init values from the run config in initialization, datasets, runtime consumers, and checkpoint handling, without args snapshots or writes back into live args.
- Keep `te_rng_tracker` and `inference_rng_tracker` in RNGConfig; retain Core's model fields as derived copies for its standalone API. Runtime initialization reads `cfg.rng`.
- Preserve `--te-rng-tracker`, `--inference-rng-tracker`, and their existing CUDA-graph normalization.
- Copy tracker settings one-way through a single finalizer called by container validation and the two shared CLI/YAML transformer-config factories. No per-entrypoint synchronization. Factories use parsed inputs only before a run config is registered; afterward they use `cfg.rng`, including when legacy args disagree or are absent.
- Resolve native CUDA-graph tracker requirements before seeding. Explicit/native/YAML inference sampling seeds remain model-owned.
- Preserve lazy/skipped seeding, parallel seed offsets, and checkpoint compatibility. Saved run config supplies checkpoint DP RNG policy, with a legacy-args fallback for older checkpoints.
- Based on merged #7568; independent of #7587 and targeting `main`. No unrelated formatting cleanup.
