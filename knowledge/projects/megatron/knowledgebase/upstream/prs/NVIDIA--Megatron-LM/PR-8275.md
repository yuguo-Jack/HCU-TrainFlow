# What does this PR do?

Defines the canonical trainer and checkpoint spans and gives each attempted training iteration a stable one-based telemetry step.

This is PR 2 of 7 and is intended to be reviewed relative to PR 1.

## Summary

- Adds training-step, forward/backward, optimizer, reporting, and checkpoint span contexts at existing trainer boundaries.
- Separates the attempted telemetry step from the completed-iteration count, including resume and rejected-optimizer-step behavior.
- Preserves call order and exception propagation while ensuring span contexts detach cleanly.
