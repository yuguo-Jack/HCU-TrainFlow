- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Limit the Approve Test Queue to two distinct active PRs per author per target branch. If an author already has two queued or running PRs targeting `main`, skip their third PR and continue to other eligible authors. PRs targeting another branch have a separate allowance, including within the `others` and external queues.

Count successful approvals immediately and deduplicate PRs across queued/running snapshots. Existing queue-wide concurrency and test-label restrictions remain in effect.

Only the approval workflow and its existing regression script change.
