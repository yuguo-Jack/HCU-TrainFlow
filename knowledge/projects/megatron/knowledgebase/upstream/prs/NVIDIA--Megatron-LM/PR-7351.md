# MInf: start_text_gen_server wait for replicas init

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7351) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?
`start_text_gen_server` returns immediately after `Process.start()`, before replicas have bound their sockets. Immediately pinging this URL afterwards (which is done by NeMo Gym) will see a window where connections are refused.

This is particularly bad when looking at the inference API, which has a `serve(blocking=False)` method which claims that it "returns once the HTTP frontend is up". Currently, it does not in fact do this; it may return before the HTTP frontend is up.

This PR makes `start_text_gen_server` wait for every replica to be responsive before returning.
