# Extract MFSDP context and centralize module metadata

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6369) · state: closed · merged: True

## Original PR description

## What does this PR do?

Extract `FsdpContext` from `module.py` into `context.py` and give it ownership of module roots and names. This separates shared streams, construction state, and prefetch ordering from the per-module hook lifecycle. `module.py` imports the context normally; the context operates on `nn.Module` objects without importing `FsdpModule`.

- Keep `finalize()` on the context and identify participating modules through registration membership. Successful FSDP initialization registers each module, and `fully_shard()` continues to reject children from another context.
- Store roots in the existing weak `IndexedOrder` collection and names in a `WeakKeyDictionary`. Collect them directly during traversal and preserve reverse root order for backward prefetch. Add membership and reverse iteration to `IndexedOrder`.
- Have `FsdpModule.name` and `is_root()` delegate to context lookups, both guarded by `ensure_finalized()`. Finalization no longer writes private fields on modules.
- Add one regression test verifying that deleting a model immediately releases its root and child modules while the context remains alive, without forcing garbage collection.

Registration membership deliberately selects modules belonging to this context. It differs from the previous `isinstance` checks for unregistered FSDP instances or foreign FSDP children attached after wrapping.

## Validation

- Context, fully-shard, and GPU-storage release tests passed on two RTX A6000 GPUs in the dev CI container. Nine cases requiring four GPUs were skipped.
- The lifetime regression passed without `gc.collect()`.
- Import checks and ordered-collection membership, reverse-iteration, and weak-reference checks passed.
- Black, isort, Pylint, Ruff, and `git diff --check` passed. Optional mypy was unavailable in the container.
