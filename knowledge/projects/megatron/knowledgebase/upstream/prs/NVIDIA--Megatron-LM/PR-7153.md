# What does this PR do?

Integrates first-class HybridModel config lists with standard training, checkpoint handling, runtime metrics, and the Puzzle example. Core support from #7555 is now merged into `main`.

## Dependency and review scope

The branch incorporates upstream `main` at `1ac85e91a`, including the #7555 merge (`bc9a10e90`). The merged core parser, `HybridLayerEntry` API, cloning, MTP, rotary, pipeline, and validation behavior are preserved. The remaining diff against `main` is 13 files (+1255 / -76).

**PR recovery required:** copy-pr-bot closed this PR when it deleted `pull-request/7555`. GitHub rejects reopening because that base is missing, and rejects changing the base while the PR is closed. A maintainer/bot must temporarily restore the old base, then reopen and retarget this PR to `main`. Do not merge into the `pull-request/7555` mirror. The updated code is pushed to the existing fork branch; no upstream ref was created or modified.

The remaining changes are:

- Training/configuration-builder support that forwards the original config list and synchronizes inferred MTP depth.
- Model-owned heterogeneous FLOP reporting and list-derived MoE metadata, preserving current hash-router and scheduled-microbatch reporting conventions.
- Scalar checkpoint-family detection and compatibility checks. Architecture objects are omitted from both checkpoint arguments and serialized run-config metadata; resume uses the supplied Python definition.
- The full-size Puzzle example under `examples/hybrid/puzzle`, updated for the current run-config initialization lifecycle.
- Two focused builder regressions covering unchanged list forwarding and parent run-config dict/YAML serialization.

There is no Puzzle functional-test recipe, optimizer workaround, or dependency upgrade in this PR.

At commit [`cc0e970ffa8f7979e3c830335472293b467bd8aa`](https://github.com/NVIDIA/Megatron-LM/commit/cc0e970ffa8f7979e3c830335472293b467bd8aa), a separate validation harness loaded the local `NVIDIA-Nemotron-Labs-3-Puzzle-75B-A9B-BF16` Hugging Face checkpoint and completed **20 optimizer steps plus one evaluation batch on all 16 ranks**. SLURM job `7205385` completed with exit `0:0` in 18m36s. This result is specific to the tested commit.

- **Environment:** four GB200 nodes with four B200 GPUs each, verified within one NVLink domain; ARM64 image `gitlab-master.nvidia.com/adlr/megatron-lm/mcore_ci_dev:main`. The runtime used this tag; its manifest digest was not independently verified.
- **Configuration:** full decoder and MTP head; TP1/PP1/CP1/EP16/ETP1; sequence length 2048; microbatch 1; global batch 32; BF16; HybridEP; full uniform recomputation; precision-aware Adam; deterministic mock data (seed 1234), checkpoint tokenizer, and fresh optimizer state.
- **Weight loading:** the validation-only post-wrap importer required complete source/target coverage, matching shapes, and exact copied values. It covered all 42,683 source tensors and preserved all 41 FP32 router biases per rank. The PR's tracked files were unchanged.
- **Checks:** 20 focused importer tests and the existing tiny Puzzle forward/backward test passed. Every rank completed training and evaluation with finite LM/MTP losses and gradients, zero skipped optimizer iterations, and verified changes in sampled embedding and MTP projection parameters.
