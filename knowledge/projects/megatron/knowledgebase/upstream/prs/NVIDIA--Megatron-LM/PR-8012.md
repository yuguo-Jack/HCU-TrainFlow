### Honor `include_special_tokens` in batch encoding

**Failure:** Construct two otherwise identical GigaToken-backed tokenizers using the local HuggingFace fixture, one with `include_special_tokens=True` and one with `False`, then call `tokenize_batch(["hello"])`. Both configurations reach this identical raw backend call: the flag is stored on the wrapper but is never passed through [GigaToken initialization](https://github.com/NVIDIA/Megatron-LM/blob/b6b8dc7398f9217196173026ee058c8ffdd081f7/megatron/core/tokenizers/utils/utils.py#L18-L24). Consequently, changing it cannot change batch postprocessing. However, [scalar tokenization](https://github.com/NVIDIA/Megatron-LM/blob/b6b8dc7398f9217196173026ee058c8ffdd081f7/megatron/core/tokenizers/text/libraries/huggingface_tokenizer.py#L311-L317) explicitly distinguishes these modes. For this BOS-adding fixture, the enabled mode must include the inserted BOS and the disabled mode must omit it; at least one batch mode therefore disagrees with `tokenize("hello")`.

**Correction:** Make the successful branch of `HuggingFaceTokenizer.encode_batch` apply automatic special-token postprocessing according to `self.include_special_tokens`, restoring `tokenize_batch(texts).to_list() == [tokenize(text) for text in texts]`. `MegatronHFTokenizer` inherits this method and needs the same semantics. The external GigaToken option signature is not available in the mounted source, so verify its batch API before choosing a keyword or adapter. Do not repair this by filtering special-token IDs from the completed output: explicitly supplied special tokens must remain even when automatic insertion is disabled.

**Preservation and acceptance (proposed checks, not executed):** Add a real-backend test using the existing local HF fixture with `use_gigatoken=True`, parameterized over both flag values. Compare batch rows against scalar results for `["hello", "", "<|begin_of_text|>hello"]`; verify that plain `"hello"` gains BOS only in the enabled mode, while the explicitly supplied BOS remains in both. Retain row order, ragged `ak.Array` output, and parallel delegation. In [the new mock tests](https://github.com/NVIDIA/Megatron-LM/blob/b6b8dc7398f9217196173026ee058c8ffdd081f7/tests/unit_tests/tokenizers/test_tokenizer.py#L1240-L1303), initialize the flag in `_bare_hf_tokenizer` and update delegation assertions for both settings. Retain the assertions that missing GigaToken raises `ModuleNotFoundError` without calling the backend, disabled GigaToken raises `NotImplementedError`, and unsupported libraries do not delegate.
