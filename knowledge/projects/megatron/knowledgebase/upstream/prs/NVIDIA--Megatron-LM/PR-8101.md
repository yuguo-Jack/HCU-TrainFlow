# Reject nonfinite inference memory metrics

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8101) · state: closed · merged: False

## Original PR description

NaN peak-memory measurements pass both lower and upper regression bounds because ordered comparisons with NaN are false. Infinite golden and measured values can also pass. Require finite scalar values and finite post-warmup list samples before checking the median.

Validation: three baseline regressions fail and four focused CPU tests pass, including preservation of warmup exclusion. Black, isort and Ruff passed. GPU inference was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
