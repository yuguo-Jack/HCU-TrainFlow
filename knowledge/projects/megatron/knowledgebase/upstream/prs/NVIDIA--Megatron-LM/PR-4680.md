# Remove Dummy Wgrad Complexity

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4680) · state: open · merged: False

## Original PR description

# What does this PR do?

Remove Megatron's dummy weight-gradient contract for fused `main_grad` accumulation. When a module has already written its real weight gradient to `main_grad`, its autograd weight gradient may be `None`. The DDP post hook accepts that state after `grad_added_to_main_grad` is set. Tied embedding and output weights no longer need a zero dummy gradient and its extra accumulation.

This is paired with [TransformerEngine #3759](https://github.com/NVIDIA/TransformerEngine/pull/3759), which removes dummy gradients returned by TE modules. PyTorch 2.6+ schedules the accumulator hook using the parameter's device worker thread.

Megatron FSDP v1 registers a post hook on the parameter's `AccumulateGrad` node instead of a tensor post-accumulate hook: the tensor hook is skipped when fused wgrad returns `None`, while the node hook still runs and lets FSDP process the gradient already in `main_grad`. The delayed-wgrad callback remains on its existing path.

## Validation on GB200

Matched-base comparisons used Megatron `9dd63d992a59` and TE `83d8c4e3370b`, with PR #4680 and TE #3759 changes applied only to **Remove Dummy**. GPT DDP, fused FSDP v1, and local-transformer GTP ran in alternating Main/Remove Dummy pairs on the same nodes. DSV3 used separate four-node allocations. All completed runs had finite losses and zero skipped/NaN iterations; FSDP and local GTP loss and gradient statistics matched within each pair. Tied-embedding DDP also passed a functional smoke test.

| Workload (pairs) | Main performance | Remove Dummy performance | Change | Average last train loss, Main / Remove Dummy | Max allocated GPU memory, Main / Remove Dummy |
| --- | ---: | ---: | ---: | ---: | ---: |
| GPT 8B DDP (2) | 548.10 TFLOP/s/GPU | 547.05 TFLOP/s/GPU | −0.19% throughput | 0.0046061585 / 0.004657772 | 27.43 / 27.08 GB |
| Small GPT, fused FSDP v1 (3) | 40.50 ms/iteration | 40.00 ms/iteration | −1.23% iteration time | 6.780934 / 6.780934 | 0.251 / 0.235 GB |
| GPT 8B shape, local-transformer GTP (3) | 245.27 TFLOP/s/GPU | 245.30 TFLOP/s/GPU | +0.01% throughput | 0.007115405 / 0.007115405 | 65.95 / 65.77 GB |
| DSV3 16-expert proxy DDP, BF16 communication (1) | 12.655 s/step | 12.223 s/step | −3.41% iteration time | 8.150826 / 8.157526 | 168.39 / 167.40 GB |
| DSV3 16-expert proxy DDP, MXFP8 communication (1) | 8.063 s/step | 7.768 s/step | −3.66% iteration time | 9.381094 / 9.380785 | 167.25 / 166.26 GB |

GPT DDP pair 1 was excluded because its Main throughput was an outlier. Memory is maximum allocated: rank 0 early in training for GPT/FSDP/GTP, and the mean of all 16 ranks' train-end maxima for DSV3. DSV3 timing is indicative because the variants used different allocations; its MXFP8 pair used the same separate [Megatron #8302](https://github.com/NVIDIA/Megatron-LM/pull/8302) validation patch on both sides. These short runs check numerical behavior, not long-horizon convergence. TE-backed GTP with Remove Dummy completed 100 iterations (job 3207500); Main and Megatron-only with TE Main both failed on the first backward because the dummy gradient did not match the sharded weight's shape. FSDP v2 fused wgrad was not tested.
