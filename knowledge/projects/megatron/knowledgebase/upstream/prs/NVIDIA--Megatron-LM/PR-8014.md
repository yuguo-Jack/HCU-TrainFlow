# What does this PR do?

Support sequence-level MoE auxiliary loss for variable-length THD packed sequences while preserving the flattened tensor layout.

The data path now records logical sequence ownership before context-parallel sharding and carries the rank-local mapping in `PackedSeqParams`. The router uses that mapping to compute per-sequence probability sums, expert counts, and valid-token denominators without materializing a dense `[max_seqlen, batch, hidden]` tensor. Physical alignment padding is represented by a sentinel sequence ID and excluded from the loss.

This also:

- preserves the existing fixed-width `tokens_per_sample` path;
- supports contiguous and zigzag CP layouts, intermediate PP stages, TP/SP execution, fused routing, per-token loss scaling, and unused padded boundary slots;
- avoids splitting variable packed sequence metadata across training MLP chunks;
- rejects unsupported Transformer Engine graph capture and falls back to eager execution for local partial MoE graphs;
- adds bit-exact determinism coverage for the segmented router accumulation.
