# Fix decoding of configured byte-level special tokens

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8795) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

`ByteLevelTokenizer.ids_to_text()` passes configured BOS, EOS, and PAD IDs above 255 to `bytes()`, which raises even when those IDs are inside the configured vocabulary.

Remove these configured non-byte IDs before decoding. Preserve existing byte-range behavior, including the default EOS/PAD values, and retain errors for unregistered non-byte IDs below the additional-special-token range.

Fixes #8793.

## Validation

- Added 27 cases covering BOS/EOS/PAD IDs at 256, 257, and 511, both decoding entry points, repeated specials, UTF-8 text, additional special tokens, byte-range controls, and invalid IDs.
