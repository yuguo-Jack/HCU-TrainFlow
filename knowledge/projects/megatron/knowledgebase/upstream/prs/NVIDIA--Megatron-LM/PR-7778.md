# What does this PR do?

Make `cfg.dist` authoritative for distributed initialization and its training-loop consumers, preserving existing CLI behavior.

- Read backend, rank-local device selection, timeouts, process-group policies, flight-recorder settings, lazy initialization, JIT disabling, gradient alignment, and Torch FSDP2 selection from the run config.
- Register configuration before runtime services, once per startup path. Keep the existing duplicate-initialization guard.
- Keep `use_megatron_fsdp` only in `cfg.ddp`, removing its duplicate from `cfg.dist` without changing the CLI flag. Other DDP settings remain outside this migration.
- Keep distributed metadata consistent with the config without modifying legacy arguments.
