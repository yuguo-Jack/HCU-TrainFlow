# What does this PR do?
This is the fourth of four stacked PRs that introduces a simplified version of DSA. These stacked PRs split PR #6869.

This PR wires the simplified DSA indexer into the main training loop. There are four main features included:

**Freezing:** `--dsa-train-indexer-only` freezes every parameter outside an indexer submodule, which is needed for phase one of long-context DSA training.

**Resetting:**  `--dsa-reset-indexer-on-load` reinitializes the indexer on a checkpoint that lacks one, while the backbone resumes where it stopped.

**Optimizer state after a reset:** Clears the indexer's moments and step count while leaving the backbone's untouched, and refreshes the indexer's master weights so the optimizer does not overwrite the new values on the next step. 

**Indexer logging:** The indexer trains with its own learning rate, so the logging reports it separately from the backbone's.

| File | Change |
|---|---|
| `megatron/training/training.py` | Parameter freezing for `--dsa-train-indexer-only`, indexer reset-on-load and the optimizer-state handling that follows it, indexer LR logging, and the indexer-loss layer-count denominator. |
| `megatron/training/checkpointing.py` | Restores model-defining DSA args; asserts trainability mode is unchanged when loading optimizer state. |
| `megatron/training/arguments.py` | 10 `--dsa-*` flags and their validation. |
| `megatron/training/argument_utils.py` | Applies DSA RoPE configuration from args. |
| `megatron/training/utils/common_utils.py` | `get_model_to_optimizer_param_map`, used by the reset path to locate master weights. |
