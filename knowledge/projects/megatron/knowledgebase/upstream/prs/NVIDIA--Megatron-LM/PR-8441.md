# Decouple dataset and DataLoader seeds from model initialization

## What does this PR do?

Changing `--seed` currently changes both model initialization and dataset shuffling/worker RNGs, so comparing weight initializations also changes the data stream.

Add optional `--data-seed` (`rng.data_seed` in config) to independently control dataset construction and DataLoader worker seeding. For example:

```bash
--seed 1234 --data-seed 5678
```

Holding `--data-seed` fixed allows changing the model/training seed while retaining the data stream. Omitting it preserves existing dataset seeds and worker seeding, including runtime parallel-rank offsets. The cyclic sampler’s existing epoch-based permutations are unchanged.

Wire the effective data seed through GPT, hybrid/Flex, BERT, T5, VLM, MiMO and finetuning data paths, offline cache preparation, and cached-logit dataset identity. Model initialization continues to use `--seed`. Document the CLI and cache/distillation behavior.
