# Never delete newer checkpoints with `--save-retain-interval`

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8165) · state: closed · merged: True

## Original PR description

Saving a checkpoint deleted whichever iteration the tracker named before it, guarded only by inequality, so a run restarted from an earlier iteration deleted the newer checkpoint ahead of it: a restart from scratch saved iteration 100 and deleted 2700.  Require the previous iteration to be strictly older.
