# Document the parallel_state deprecation and its replacement

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6257) · state: open · merged: False

## Original PR description

Global `parallel_state` accessors cannot select an independent model's parallel grid. Document caller-provided `ProcessGroupCollection` / `ProcessGroup` arguments as the migration path, mark 59 accessors with replacement guidance, and clarify where the compatibility shim remains appropriate.

Include current dense/expert, GTP-remat, and dynamic CP group mappings, global versus group-local rank conversion, optional-group and initialization semantics, and the limits of physical pipeline-stage helpers. This is documentation-only: executable ASTs for both Python files are unchanged from main (`77391e71cc`). Upstream #7045 renamed the hybrid DP×CP accessor to `get_dynamic_data_context_parallel_groups` (keeping `get_hybrid_data_context_parallel_groups` as a deprecated alias); the deprecation note now sits on the new accessor. Upstream #7047 added the `dynamic_cp` and `dynamic_tp_cp` fields to `ProcessGroupCollection`. The note on `get_dynamic_data_context_parallel_groups` points to `pg_collection.dynamic_cp[group_size]`, and the three dynamic group accessors main added since this PR was written carry the standard deprecation note. The guide maps the dynamic (formerly hybrid) groups to `dynamic_cp` and `dynamic_tp_cp`, keyed by runtime CP size, and only Gloo groups have no corresponding collection fields.

Validation: Black 26.3.0, isort, Ruff, pylint, syntax, and `git diff --check` pass. The local mypy run reports the same 13 dependency/type diagnostics as main. The lint and mypy results are from the branch before the sync; after the sync, `git diff --check` passes and the merge changes only docstrings and the guide. No GPU execution is needed for this documentation-only change. The PR touches no test files, and the integration run of all #6307 PRs on main shows no regressions against main.

The branch was synced with main 77391e71cc on 2026-11-01 by a merge commit, so existing commits and review links stay valid. The merge had no conflicts; its message lists the docstring and guide updates for main's changes.
