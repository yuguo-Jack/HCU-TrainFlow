# [MoE] Support masked native router replay with exact recomputation

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Extend `RouterReplay.set_target_indices(..., replay_mask=None)` with an optional per-token mask. Valid rows replay rollout expert IDs; other rows retain native top-k (including group-limited selection). Return gathered current scores so router gradients remain intact. Cache the **resolved forward routes**, including native rows, for backward recomputation instead of making a second routing decision.

Omitting the mask preserves full replay. Per-microbatch masks follow the existing FIFO queue, clear with indices, and invalid/missing input fails explicitly.

## Issue tracking

Related to #8672 and [verl Modern Megatron integration RFC](https://github.com/verl-project/verl/issues/8324). Builds on the existing native R3 replay API; this does not duplicate #4256 or the experimental/lite work in #7050.

- Covers mixed/full/native masks, score gradients, FIFO and clear/error behavior, and recomputation with changed score ordering.
- Registered CPU/CUDA determinism test checks exact expert IDs, values and independently specified gradients across eight repetitions. Both CPU and CUDA cases passed on H100.
