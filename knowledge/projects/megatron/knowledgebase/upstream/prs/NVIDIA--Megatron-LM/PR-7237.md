# Discard core attention outputs during selective recomputation

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7237) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

Make selective `core_attn` recomputation release the attention output retained by the output projection, reducing activation memory with fused attention.

In our fused-attention comparison, enabling ordinary `core_attn` checkpointing did not reduce peak activation memory. The output projection still saves the core-attention output for its weight gradient. This PR replaces ordinary checkpointing with `CheckpointWithoutOutput`: discard the attention output after projection and restore it before projection backward consumes it. The existing selective-recompute configuration remains the entry point.

Register recomputation on the projection output so that restoration precedes both projection backward and optional output-gate backward. When `mla_up_proj` recomputation is also enabled, register its hook first on the same tensor: restore Q/K/V, then recompute core attention.

Reject selective `core_attn` recomputation combined with `attn_proj` activation offloading during configuration validation, because both manage the projection-input storage. Remove the obsolete fused-attention recomputation warning and update the existing documentation to classify `core_attn` as output-discarding checkpointing.

## Issue tracking

Related to [#1886](https://github.com/NVIDIA/Megatron-LM/issues/1886), which reports no memory reduction with `core_attn` checkpointing and uses fused attention in its reproducer. This change improves memory savings by releasing the attention output retained for projection backward.

  - The [rewritten checkpoint](https://github.com/NVIDIA/Megatron-LM/blob/af19152ef2cf1137f96f41b3e1f00dc850f66850/megatron/core/tensor_parallel/random.py#L970-L1026) points the restored layernorm output's storage at the recomputed data. - **What is preserved.** With Q-LoRA, with up-projection-only recompute, and with up-projection plus core attention, the up-projection is still recomputed before core attention.

This change registers up-projection replay on the projection output **before** the enclosing layer registers its [input-layernorm restoration hook](https://github.com/NVIDIA/Megatron-LM/blob/091d511c133395734cbffe805191959cfbd6430a/megatron/core/transformer/transformer_layer.py#L743-L749) on the same tensor.
