# What does this PR do?

A fresh run with `--split-sentences --partitions 1` currently exits successfully after producing the `_ss.jsonl` intermediate. The `continue` bypasses encoding, so neither the requested `.bin` nor `.idx` exists until a second invocation. Remove that early continuation so the first invocation splits and tokenizes.

This is an AI-assisted draft. Human author review and NVIDIA GPU/CI validation are pending.
