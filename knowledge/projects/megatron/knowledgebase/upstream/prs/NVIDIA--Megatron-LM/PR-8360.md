# Add independent sigmoid input scales for MoE routers and experts

# What does this PR do?

Add two independent fixed sigmoid-input controls, both defaulting to `1.0`:

- `--moe-router-sigmoid-input-scaling-factor a`: compute router scores from `sigmoid(a * logits)`. The positive, finite multiplier is shared by training, fused/unfused routing, auxiliary losses, z-loss, observations, and inference. Expert selection bias remains unscaled after sigmoid. Non-identity scaling promotes FP16/BF16 logits to FP32, requires sigmoid MoE routing without Sinkhorn, adds no checkpoint tensors, and is restored by `--use-checkpoint-args`.
- `--moe-latent-sigmoid-input-scale kappa`: change only the sigmoid argument in routed latent experts' SwiGLU/SiTU activations. Preserve the multiplicative branches and SiTU tanh inputs, and leave dense/shared activations unchanged. The value must be finite; non-unit values require latent MoE and gated SiLU. Keep the same value when loading a checkpoint.

The expert control implements the request in [the review comment on #8111](https://github.com/NVIDIA/Megatron-LM/pull/8111#issuecomment-6102145239). Latent down/up projection gains remain in #8111. The two PRs target `main` independently; neither depends on the other.

Thread the expert scalar through eager and custom fused SwiGLU, hard-clamped SwiGLU, and SiTU, including biased and router-weighted variants. The fused backward includes the sigmoid chain-rule factor and uses the scaled activation for router-probability gradients. TE native activations fall back to the standard path for non-unit expert scales. The TE op fuser and inference-optimized expert kernels reject unsupported non-unit values explicitly.

The comment at the router multiplication and the README describe calibrating the router gain from random-init activations: sweep the multiplier using fixed weights/inputs, maximize the squared Jacobian norm of L2-normalized selected gate scores, then validate on held-out contexts and independent router draws. This is a local sensitivity criterion for RMS-normalized independent-expert mixtures, not a full-network criticality result. With zero gate bias and `std(W) = c_init / sqrt(hidden_size)`, use `a = c_target / c_init`; the model-specific example `0.5506 / 0.9 ~= 0.6118` is not a default. Calibrate expert activation scaling separately.

## Validation

- Four GPU ranks: **373 passed, 6 expected skips per rank** in both regression-first and scalar-sweep-first test orders. Covers router scaling, numeric CLI/config validation and checkpoint argument restoration; expert eager/fused forward and input/bias/probability gradients; dense/shared scoping, TE fallback, and existing MLP/router/activation regressions.
- **26 selected GPU bit-exact replay cases passed per rank**, including scaled router scores, scaled SwiGLU/SiTU activations and complete latent MoE layers.
- **48 FP32/BF16 default-scale cases** match the pre-move production activation modules bit-exactly in forward and backward.
- The scalar-sweep test module resets compiler caches at teardown so it does not exhaust the specializations used by subsequent activation regression tests. The previously failing order now passes on the same GPU node.
- Kernel determinism coverage and `git diff --check` pass.
