# Enable MFSDP v2 recompute weight planes in the MCore adapter

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8803) · state: closed · merged: False

## Original PR description

Enable #8432's backward-plane policy in the MCore adapter when MXFP8 parameter gathering and activation recomputation are configured. Selective MLA and root-owned MTP recomputation can invoke child modules without re-entering their owning FSDP unit, so backward must also make the forward weight representation available.

Depends on #8432; this PR targets `pull-request/8432` and contains only the adapter integration and its regression test. The policy conservatively gathers both MXFP8 layouts for recomputing models. Models without recomputation retain the existing per-phase behavior. Finer per-unit selection can be optimized separately.

Validation:
- Added one parametrized regression covering selective output-discard and full reentrant checkpointing, comparing losses, complete local gradients, and updated weights with no recomputation over three SGD steps.
- Black, isort, Pylint, Ruff, and `git diff --check` passed. The formatter's advisory mypy step reports missing Torch/TE imports in the workstation environment.
- Four-GPU validation: all nine focused tests passed on every rank (36 total), with zero failures/skips and a clean exit. This includes the new selective/full regression and #8432's parity, plane-readiness, and default phase-gather tests.
- Flash integration with #8784 and a separate graph-cleanup change passed both reduced-depth (16 updates) and full-shape (110 updates) runs, with finite printed losses/gradient norms, zero NaN/skips, all-rank capture-completion reports, and clean shutdown. These mock-data runs do not establish convergence or PP/VPP compatibility.
