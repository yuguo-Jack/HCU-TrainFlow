# Preserve test names when matching golden-value artifact prefixes

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8094) · state: closed · merged: False

## Original PR description

Golden artifact matching removed every logs- occurrence from artifact names, corrupting legitimate test identifiers such as logs-resume or restore-logs-state and silently skipping their golden values. Remove only the leading artifact prefix.

Validation: actual artifact matcher checks both affected identifiers plus an ordinary test; two baseline failures and all three fixed cases pass. CPU-only identifier tests; Ruff, Black and isort pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
