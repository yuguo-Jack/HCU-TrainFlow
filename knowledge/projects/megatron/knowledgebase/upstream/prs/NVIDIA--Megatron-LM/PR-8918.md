# Fix native NCCL UB initialization and CLI defaults for MFSDP v2

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8918) · state: open · merged: False

## Original PR description

Initialize an MFSDP mesh-axis NCCL backend before symmetric-memory rendezvous only when it is cold, preserving the existing communicator on subsequent calls. Keep automatic manual-registration/double-buffer defaults specific to MFSDP v1 so `--use-nccl-ub` can reach the native v2 path without an unsupported configuration.

Validation:

- Exact main-based commit: 28/28 checks on four GB200 GPUs, covering CLI defaults and native cold/warm AVG collectives with communicator reuse.
- Separate integration source: 28/28 checks through the real CLI/wrapping path, including BF16/MXFP8 full-step CUDA Graph updates and UB OFF/ON gradient/weight comparisons with unchanged tolerances.
- Tested with NCCL 2.30.7, GIN2, and allocator graph-capture reuse disabled. D19 performance and other runtime modes remain unqualified.

Code provenance: original Megatron-LM changes; no code copied from another repository.
