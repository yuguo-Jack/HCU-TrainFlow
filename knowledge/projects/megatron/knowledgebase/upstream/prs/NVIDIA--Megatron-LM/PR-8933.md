# What does this PR do?

Adds opt-in logit-space quantile balancing for ungrouped sigmoid MoE routers. When sigmoid scores are very small, score-space histograms can place many tokens in a few bins. Selecting experts and estimating the balancing bias in logit space gives those scores more resolution.

With `--moe-router-qb-bias-space logit`, expert selection uses `logits + bias` instead of `sigmoid(logits) + bias`, and the global-batch histogram records the `(k+1)`-th biased logit minus each expert's raw logit. Expert contribution weights and their gradients still use the original sigmoid scores. Score-space QB remains the default.

- Adapt histogram bounds to the pooled range with 10% headroom.
- Support the unfused path and Transformer Engine's matching `qb_bias_space` API. Reject older fused implementations explicitly and bypass the score-only Triton inference kernel.
  - See the companion TE PR: https://github.com/NVIDIA/TransformerEngine/pull/3805
- Use distinct checkpoint keys for logit-space bias and bounds to prevent interpreting score-space state in the wrong units. Converting an existing model requires separate calibration; this change does not implement that workflow.
