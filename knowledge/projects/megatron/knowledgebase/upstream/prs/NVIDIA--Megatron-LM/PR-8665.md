# Replace DSv3 convergence proxies with DSv4 Flash on GB300

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8665) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Replace the four DSv3 convergence cases with reduced DSv4 Flash proxies on GB300 using DSv4-tokenized SlimPajama and its paired HuggingFace tokenizer.

The proxies retain 14 logical layers (28 HybridModel layers), 64 experts, and TP1/PP2/EP8 and TP1/PP4/EP16 layouts. They exercise window/CSA/HCA attention, four mHC streams, three hash-routing layers, natural top-6 sqrtsoftplus routing, MTP, and MXFP8. Both release/weekly aliases initially stop at 1,000 steps while retaining the training LR schedule.

Resolve tokenizer vocabulary before HybridModel validation in a private runtime YAML per node. Enable gradient-buffer reuse for MXFP8 parameter all-gather and preserve NVLink node segments in the fault-tolerant launcher. Add blocking weekly/release GB300 CI orchestration while preserving asynchronous nightly behavior.

## Measured goldens

All four golden files are generated from complete observed trajectories using the repository extractor, with full precision and the existing five-step CI sampling grid. Dense evidence verifies every training step. Each layout's two aliases have identical initial settings and share that layout's measured trajectory.

| Layout | GPUs | Steps | LM loss, first → last | MTP loss, first → last |
| --- | ---: | ---: | ---: | ---: |
| TP1 / PP2 / EP8 | 32 GB300 | 1,000 | 12.5786 → 6.3881 | 12.5933 → 6.8686 |
| TP1 / PP4 / EP16 | 64 GB300 | 1,000 | 12.5602 → 6.3968 | 12.6364 → 6.8806 |

Both runs completed successfully, saved checkpoint 1,000, and had finite losses/gradients with zero NaN or skipped iterations. The frozen measured source was `e2668ac985f4edde4d91ecc1c95be49e3c4db8a4`; all 3,153 tracked source files remained unchanged.

## Validation

- Fifteen focused CPU tests passed for CI generation, run identity, bridge selection, notifications, and timeouts.
- Golden finiteness, full-precision markers, required metrics, sampling grids and extraction/download hashes passed; `tools/check_golden_values.py` passed all four files.
- YAML, pipeline/alias parity, recipe mapping, shell syntax, formatter, lint and type checks passed.
- Both layouts passed optimizer checkpoint-resume smoke tests.
- The repository-pinned NVRx 0.7.0 supports the segment option. The cuDNN frontend 1.32 overlay passed imports, GPU Hadamard, CSA replay tests and the actual-container launcher preflight.
- Training used NeMo 26.10rc7 with the pinned cuDNN overlay and matched SlimPajama assets; W&B was disabled and TensorBoard enabled. This is not a claim that the exact CI image has been exercised.
- An earlier PP2 attempt failed during a node-localized NCCL checkpoint-plan gather. A fresh full-optimizer save/reload diagnostic and the independent 1,000-step rerun passed. No failed-attempt training state or metrics were promoted.
