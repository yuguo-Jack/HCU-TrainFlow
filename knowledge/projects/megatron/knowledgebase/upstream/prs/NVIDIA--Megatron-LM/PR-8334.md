# What does this PR do?
Re-architects the internals of `CheckpointWithoutOutput` (output-discarding recompute, `megatron/core/tensor_parallel/random.py`) without changing its public API or any call site. It also makes `checkpoint()` a plain call when no autograd graph is recorded.
