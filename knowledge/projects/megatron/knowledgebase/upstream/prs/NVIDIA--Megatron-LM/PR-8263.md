# What does this PR do?
<!-- Add a one line overview of what this PR aims to accomplish. -->

Seed both model constructions in `test_checkpoint_load_without_microbatch_calculator` with `torch.manual_seed(123)`.

The fixture seeds CUDA RNGs, but this test initializes its model weights on the CPU. Without an explicit CPU seed, data-parallel ranks can construct different reference weights. The legacy `torch` checkpoint saves rank 0's replica, so other ranks compare the restored weights against a different reference. Earlier tests can accidentally align CPU RNG states and mask the failure.

This is a two-line, test-only change. The restored model is still zeroed before loading, and the separate pre-load seed of 987 and all weight/output/RNG assertions remain unchanged. No production code or copyright changes.
