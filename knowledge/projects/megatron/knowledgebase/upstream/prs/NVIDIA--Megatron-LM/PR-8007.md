# Fix test-state restoration with frozen cuDNN flags

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8007) · state: open · merged: False

## Original PR description

## Summary

When a test imports PyTorch's internal test helpers, cuDNN flags become frozen. Main's process-state fixtures then raise during teardown while restoring settings, even when the test itself passes.

Related main attention output-gate PR: #8008.

## Changes

- Restore captured cuDNN settings through the flag setter used by PyTorch's own context manager.
- Preserve the frozen policy and uncaptured enabled, benchmark-limit, and precision settings, with compatibility for versions lacking the precision argument.
- Add real locked/unlocked and changed/unchanged restoration regressions.

## Test plan

- Canonical unit-test runner on 8 H100 GPUs: all ranks passed the four new regression cases with no failures or skips.
- The original main restoration function reproduces the frozen-flags error in the same environment.
- Official main autoformat checks passed Black, isort, Pylint, and Ruff.

Validation used the cached CI-derived Torch 26.04 environment, not a fresh install from main's current lockfile. This infrastructure fix is kept separate from the attention output-gate feature.
