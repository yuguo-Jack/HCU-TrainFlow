## What does this PR do?

Restore the tensor-value assertion in `TestSerialization.test_empty_load`.

The test gives rank 3 the main replica containing `[3, 3]`, while other tensor replicas contain different values. After loading, it checks the returned keys but discards the result of the tensor-value comparison. Consequently, an incorrect payload such as `[4, 4]` can pass the test.

Add the missing `assert` to enforce the existing expectation that the loaded tensor contains the values saved by rank 3. The change is one line in `tests/unit_tests/dist_checkpointing/test_serialization.py`.
