# Run the MXFP8 LM head and fused MLA K/V RoPE quant in FP4 models

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8582) · state: open · merged: False

## Original PR description

fp8_output_proj now also applies to FP4 models: the LM head (TELMHeadColumnParallelLinear) runs under its own MXFP8 (E4M3) autocast, since an FP4 model has no FP8 context. use_fused_mla_kv_rope_quant is accepted with fp4, and _is_mxfp8_attention_active recognises NVFP4/custom recipes with FP8 DPA when Transformer Engine runs attention in MXFP8 (NVTE_DPA_FP8_RECIPE=MXFP8BlockScaling).
