# fix(tests): honor tmpdir for mimo checkpoint scratch

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8460) · state: closed · merged: True

## Original PR description

## Background / motivation

The heterogeneous MiMo checkpoint round-trip test creates two full 20-layer checkpoints under the repository root. On a runner with a 64 GiB checkout volume, this exceeds the volume limit and the pod is evicted before the comparison produces a verdict.

## What changed

- Let `tempfile.mkdtemp` use Python's configured temporary directory, including `TMPDIR`.

## Details

- Remove only `dir=_REPO_ROOT` from the scratch allocation.
- The launcher working directory, checkpoint save/load arguments, exact comparison, GPU requirement and final cleanup stay the same.

## Tested

- `uv run --no-project --with black==26.3.0 black --check tests/functional_tests/test_cases/mimo/mimo_hetero_gtp_checkpoint_round_trip/test_checkpoint_round_trip.py` — unchanged.
- Python AST/scratch smoke check: evaluated the candidate's actual `tempfile.mkdtemp` call with a temporary `TMPDIR`; verified allocation under that directory and removal by `shutil.rmtree`.
- `git diff --check` — passed.
- Full 8-GPU checkpoint round trip remains to be run; the local checks verify scratch placement, not checkpoint correctness.
