# Support routed-only MoK, SiTU-GLU, and TP for latent MoE

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8677) · state: open · merged: False

## Original PR description

## What does this PR do?

Extend MoK backend with routed-only execution, allowing MCore to retain shared experts and latent projections with their native precision handling.

Ports #8497 on top of the merged #8210. Supersedes #8631.

- Support native shared-expert execution and models without shared experts, while preserving existing fused shared/gated behavior.
- Enable TP with sequence parallelism and ETP=1
- Support SiTU-GLU independently of shared-expert fusion through main's existing activation configuration.

## External dependency

MoK [PR #9](https://github.com/QiZhangNV/mixture-of-kittens/pull/9) for routed-only execution and SiTU-GLU support.

## Validation

Tested on four GB300 GPUs:

- 117 tests passed per rank, with 8 existing late-initialization skips.
- Five real MoK bit-exact replay cases passed, including routing-probability and parameter-gradient replay.
- Independent composition and TP-gradient reference tests passed.
- Thirteen MoELayer/TE/DDP numerical comparisons passed across BF16/MXFP8 and TP1/2/4, including shared/no-shared execution and nested recomputation.
- Formatting/lint and kernel determinism coverage checks passed.

Full-model E2E benchmarks were not run.

## Code provenance

Intra-repository port of #8497 at `8dc4a6e7`; existing license and copyright notices are retained. MoK remains a separately pinned dependency.
