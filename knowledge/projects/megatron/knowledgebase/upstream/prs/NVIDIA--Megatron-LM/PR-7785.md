# fix(optimizer): preserve hybrid Adam group steps after resume

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7785) · state: open · merged: False

## Original PR description

## What does this PR do?

Preserve the GPU Adam group step in `HybridDeviceOptimizer` when synchronizing sub-optimizer state. After restoring a checkpoint with partial CPU offload, HDO currently copies the restored group step into FusedAdam before every update without recording FusedAdam's advanced counter. Saving after update 1 and resuming through updates 2 and 3 leaves the GPU counter at 2 rather than 3, changing Adam bias correction and subsequent parameter updates.

Copy each GPU group's live step back to its corresponding HDO parent group after an update. Map groups through their original parameters because CPU-only groups are absent from the GPU optimizer. CPU Adam retains its per-parameter counters; learning-rate and weight-decay changes continue to propagate from HDO. This also preserves GPU steps in HDO checkpoints when all parameters remain on GPU.

## Validation

- Real two-rank distributed optimizer with BF16 parameters, precision-aware Adam, and CPU-offload fractions 0, 0.625, and 1. Save after update 1, construct a fresh optimizer, load the distributed checkpoint, and run two more updates. Compare model parameters, optimizer tensors including FP32 masters, and GPU group counters exactly against uninterrupted training.
- A separate actual TE FusedAdam test covers CPU-only, mixed, and GPU-only parameter groups, exact resumed parameters/state, and learning-rate/weight-decay forwarding.
- Before the fix: both GPU-containing cold-resume cases fail; fully CPU-offloaded control passes. The multi-group counter regression also fails.
- After the fix: all four new cases pass on each of two GB200 GPUs.
- 50 existing offload tests pass: Adam/SGD, CPU/GPU/mixed placement, overlapping transfers, parameter groups, and native-FP32 checkpoint coverage (24 separate overlap tests deselected).
- `tools/autoformat.sh`: Black, isort, pylint, and Ruff pass. Its non-gating mypy stage reports missing torch/pytest/Transformer Engine imports in the separate lint environment.
