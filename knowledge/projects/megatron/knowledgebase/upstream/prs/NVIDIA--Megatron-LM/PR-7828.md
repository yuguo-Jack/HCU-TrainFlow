# feat(inference): support request-local sampling seeds

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7828) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Add optional request-local sampling seeds to dynamic Torch inference and both OpenAI-compatible completion endpoints. With a shared generator, moving a request between batches changes its draws even when its logits are unchanged. Explicit `seed` assigns each draw by request seed and absolute token position, independently of request IDs, batch slots, or other requests' RNG consumption.

- Validate and serialize nonnegative int64 seeds; track them through the existing aligned request metadata.
- Keep temperature/top-k/top-p filtering batched. Generate noise independently for seeded rows without advancing the shared generator; omitted seeds keep the existing sampling path.
- Give HTTP choice/prompt `i` seed `(seed + i) % 2**63`, including streaming submissions.
- Preserve the pending logits' token positions when async overlap prepares successor state before sampling.
- Reject seeded FlashInfer, speculative, static, and custom-metadata-without-seed configurations rather than silently ignoring the seed.

The convention is to fail the requests via `add_event_error_nontransient` instead of directly raising errors:
```
seed_error = None
if request.sampling_params.seed is not None:
    if self.context.config.sampling_backend != "torch":
        seed_error = "Request-local seeds require sampling_backend='torch'"
    elif self.context.config.num_speculative_tokens:
        seed_error = "Request-local seeds do not yet support speculative decoding"
    elif "seed" not in self.context.request_metadata:
        seed_error = "Request-local seeds require seed in request metadata"
if seed_error is not None:
    request.status = Status.FAILED
    request.add_event_error_nontransient(ValueError(seed_error))
```

`replace` is not entirely safe to use on the sampling params. The sampling params' `__post_init__` does things like
```
            warnings.warn(

followed immediately by
```
self.return_prompt_top_n_logprobs = False

That is to say, it sets some parameters internally, but warns against setting them externally.

For now, I think `replace(params, seed=(params.seed + index) % (2**63), return_prompt_top_n_logprobs=False)` is fine, but beware in the future.
