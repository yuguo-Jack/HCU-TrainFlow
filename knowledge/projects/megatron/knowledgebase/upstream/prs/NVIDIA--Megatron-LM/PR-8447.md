# [inference] Take argmax for greedy batches in FlashInfer sampling

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8447) · state: open · merged: False

## Original PR description

## What does this PR do?

Greedy batches in the FlashInfer sampling backend (`--inference-dynamic-batching-sampling-backend flashinfer`) now take the argmax of the logits, as `TorchSampling` already does, instead of a full-vocabulary softmax followed by a top-k sampling kernel.

- **When it applies:** every active request is greedy (top-k 1) and none uses top-p. The check reads the pinned CPU sampling metadata (`active_request_metadata`), so it adds no device sync. The sampler already runs eagerly, never inside a CUDA graph.
- **What is unchanged:** batches that mix greedy and non-greedy requests, batches with a top-p request, and the speculative path (per-token sampling parameters via `token_to_request_index`) keep the existing kernel dispatch.

## Why

For a greedy batch the result is the argmax regardless, but the FlashInfer path still launched a softmax over the vocabulary and a top-k sampling kernel. In a long-context greedy decode trace, those took ~140 µs per step (~110 µs softmax, ~29 µs sampling); the argmax takes ~10 µs.

## Tests

In `tests/unit_tests/inference/contexts/test_dynamic_context.py`, next to the existing FlashInfer sampling tests:

- `test_flashinfer_sample_kernel_greedy_batch_takes_argmax`: an all-greedy batch (with `gather_indices`, with and without `output`) returns the argmax and launches no FlashInfer kernel.
- `test_flashinfer_sample_kernel_non_greedy_batches_sample`: a greedy row next to a top-k 5 row, greedy rows next to a top-p row, and an all-greedy speculative batch still go through the matching FlashInfer kernel.
- `test_flashinfer_greedy_sampling_matches_torch_greedy` (CUDA + FlashInfer): the greedy tokens equal `TorchSampling`'s top-k 1 result, at temperature 1.0 and 0.7.
- `test_flashinfer_sample_kernel_dispatch`: its context now carries `active_request_metadata`, which the greedy check reads.
