# What does this PR do?

https://github.com/NVIDIA/TransformerEngine/pull/3584 makes it clear about when will the fused implementation be applicable, before this API change, we rely on an undocumented contract between TE and Mcore to both use 256 padding alignment to trigger fused mlp operation which is fragile and not accurate.
