# Stop waiting for canceled and skipped main pipelines

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8084) · state: open · merged: False

## Original PR description

Continuous main-status polling treated canceled and skipped pipelines as pending even though neither state can become successful. Remove these terminal statuses from the wait set so polling terminates.

Validation: actual is_pending tests cover all four terminal statuses and five active statuses; canceled/skipped fail on baseline and both tests pass after the fix. CPU-only fixtures; Ruff, Black and isort pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
