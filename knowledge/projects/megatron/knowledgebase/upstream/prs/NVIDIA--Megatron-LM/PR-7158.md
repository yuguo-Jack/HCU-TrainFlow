# What does this PR do?
This is the third of four stacked PRs that introduces a simplified version of DSA. These stacked PRs split PR #[6869](https://github.com/NVIDIA/Megatron-LM/pull/6869).
 
 This PR lets DSA indexer gradients be clipped under their own L2 norm, separately from the rest of the model. The indexer is trained by a KL objective against the attention distribution, and its gradients are roughly an order of magnitude smaller than the backbone's (in an 8B run, 0.009 against 0.108). Because clip_grad_norm takes a single global norm over every trainable parameter, the indexer's update would be scaled by a coefficient the backbone determines. 

To clip a subset of the parameters, the parameters are partitioned into an indexer bucket and a non-indexer bucket. The split is opt-in: dsa_indexer_clip_grad = None keeps the existing single-norm behavior, and any value enables two norms, with that value as the indexer's threshold.
