# What does this PR do?
This is the third of four stacked PRs that introduces a simplified version of DSA. These stacked PRs split PR #[6869](https://github.com/NVIDIA/Megatron-LM/pull/6869).
 
This PR replaces the optimizer's single global step counter with one clock per parameter group, an partitions groups into two buckets so a subnetwork that is reset mid-run can carry its own clock while the rest of the model continues. This is necessary because phase 1 of DSA training freezes all model parameters except DSA indexer parameters. A summary of the modified files is provided below.

To ensure that each parameter keeps its correct step count for momentum, we give each parameter group its own clock. We also modify assertions that ensured all parameters had the same step, and relax them to separate non-indexer parameters from indexer parameters.

| File | Change |
|---|---|
| `megatron/core/optimizer/optimizer.py` | `is_dsa_indexer` param-group identifier; separate grad-norm computation and clipping for indexer vs backbone. |
| `megatron/core/optimizer/distrib_optimizer.py` | Per-parameter-group optimizer step clocks, so a reset indexer restarts at step 0 while the backbone continues. Required by `--dsa-reset-indexer-on-load`. |
| `megatron/core/optimizer/optimizer_config.py` | `dsa_separate_indexer_grad_clip`, `dsa_indexer_clip_grad`. |
| `megatron/core/optimizer_param_scheduler.py` | Indexer learning-rate logging (`get_indexer_lr_for_logging`). |
| `megatron/core/optimizer/__init__.py` | Param-group plumbing for the indexer split. |
