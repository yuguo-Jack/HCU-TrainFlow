# ci: group CPU test selection before the GPU matrix

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8381) · state: closed · merged: True

## Original PR description

PR #8019 lists every unit-test bucket twice in the Actions UI, once for CPU selection and once for GPU execution. Group PR test selection into one CPU job per platform named `unit tests selection`, then expand only the GPU job as a matrix of buckets that need tests.

Keep the existing H100 and GB200 recipe parser jobs and pass their complete bucket lists into the reusable unit-test workflow. Full-suite runs skip selection and execute all parsed buckets. Python handles the bucket loop and matrix generation; a small inline workflow adapter calls GitHub's cache and artifact SDKs.

The existing selector, cache format, per-bucket plan artifacts, and full-suite policy are unchanged. Coverage continues to use the original parser outputs, and the GB200 container image remains an output of its parser job. GPU jobs start after their platform's selection finishes; an unexpected selection or artifact-upload failure stops that platform's GPU dispatch.

Validation:
- 88 tests passed in `tests/test_utils/test_testmon_workflow.py`, including grouped selection, full-mode execution with skipped selection, and coverage validation.
- Black, isort, Ruff, and `git diff --check` passed.
- `_unit-tests.yml` passes Actionlint. `cicd-main.yml` retains two existing missing-`script` input errors in the functional-test jobs, also reproduced on the base commit.

Follow-up to #8019. Example of the current duplicate rows: https://github.com/NVIDIA/Megatron-LM/actions/runs/39505667208.
