# Avoid rebuilding precision-aware optimizer state during checkpoint resume

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7288) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

Avoid redundant inner-optimizer reconstruction during checkpoint resume for eligible precision-aware TE FusedAdam: FP32 moments, FP32 master configuration (including raw BF16 master remainders), and unquantized primary parameters. The public loader can cast and rebuild an entire copy of already allocated state, causing resume OOM even when the final model and optimizer state fit.

Initialize final TE storage once when needed, then restore matched parameter-group metadata directly while preserving live parameters and optimizer-state tensors. Eligibility checks both the configuration and the actual optimizer's master/moment representation, requires the exact TE FusedAdam class and a callable initializer, and fails closed for missing or nonempty load-hook registries. Quantized FP8/FP4 primary parameters, reduced-precision states, custom subclasses, hooks, ordinary Adam and CPU offload retain the public loader.

The guard checks actual primary storage: the training CLI defaults `fp8_recipe` to `delayed` even when FP8 is disabled, so excluding that recipe would incorrectly disable the optimization for normal BF16 training.

The bypass concerns the **inner loader**. `dp_reshardable` checkpoint targets can alias eligible live TE state. `fully_reshardable` loads intermediate CPU buffers and subsequently copies their slices through its existing parameter-state loader. Those format-specific restorations still run. Checkpoint keys, serialized values and formats are unchanged; no checkpoint conversion or separate BF16 format patch is required.

TE 2.0's one-argument initializer and TE >= 2.1's per-parameter remainder argument are handled separately. This fixes a previously dormant callback that resume now invokes; BF16 remainders are enabled only for BF16 parameters, not neighboring FP32 parameters.

## Earlier numerical investigation and remaining coverage limits

The original 128-token run was not bitwise repeatable, including between identical patched resumes. Later 2,048-token deterministic runs on original pinned patch `ae676f6`, with TE 2.18 and 288 GH200 GPUs, matched checked restored and next-update tensors; eight empty groups differed in step metadata. Those historical results remain attributed to that revision.

Captured-input replay reproduced the first observed computation difference in BF16 atomic accumulation during unfused MoE unpermute, without executing an optimizer or checkpoint loader. The operation's existing deterministic path removed that captured difference. This identifies the reproduced boundary, not every possible later source of variability.

The separate 4,096-token reference OOMed in its next backward, so no resume comparison completed. Earlier full-master fully-reshardable reference attempts OOMed during checkpoint saving; the balanced layout and existing CPU-gather option used above allowed the complete reference to finish.

`fully_reshardable` with BF16 master remainders has a separate, pre-existing dtype failure on pristine upstream and is outside this patch. The older TE initializer signature is tested with an adapter over current TE, not an older compiled runtime. FSDP and full FP8/FP4 training resumes are not newly qualified here.

"""One-GPU allocation reproducer for Megatron-LM PR #7288.

Runs the real DistributedOptimizer metadata loader and production TE initializer.
Only distributed shard construction is replaced with the minimum shard metadata.
This measures allocation; use the PR's regression tests for numerical/DCP checks.
Run each checkout and remainder mode in a fresh Python process.
"""

import argparse
import gc
import hashlib
import json
import subprocess
import time
from pathlib import Path
from types import SimpleNamespace
from unittest.mock import patch


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--remainders", action=argparse.BooleanOptionalAction, default=True)
    parser.add_argument("--chunks", type=int, default=8)
    parser.add_argument("--chunk-numel", type=int, default=4 * 1024**2)
    parser.add_argument("--expected-head", help="Optional exact checkout commit assertion")
    parser.add_argument("--output", type=Path)
    args = parser.parse_args()
    if min(args.chunks, args.chunk_numel) < 1:
        parser.error("chunks and chunk-numel must be positive")
    if args.output and args.output.exists():
        parser.error("output already exists; use a new result filename")

    import torch
    import transformer_engine
    from transformer_engine.pytorch.optimizers import FusedAdam

    from megatron.core.optimizer import (
        OptimizerConfig,
        _get_megatron_optimizer_based_on_param_groups,
        distrib_optimizer,
    )
    import megatron.core.optimizer as optimizer_module

    source = Path(distrib_optimizer.__file__).resolve()
    initializer_source = Path(optimizer_module.__file__).resolve()
    git = subprocess.run(
        ["git", "-C", str(source.parent), "rev-parse", "HEAD"],
        capture_output=True, text=True, check=False,
    )
    head = git.stdout.strip() if git.returncode == 0 else None
    if args.expected_head and head != args.expected_head:
        parser.error(f"loaded checkout is {head}, expected {args.expected_head}")
    if args.expected_head:
        dirty = subprocess.check_output(
            ["git", "-C", str(source.parent), "status", "--porcelain", "--untracked-files=no"],
            text=True,
        )
        if dirty.strip():
            parser.error("expected-head verification requires a clean tracked source tree")
    if not torch.cuda.is_available():
        parser.error("one CUDA GPU and a working Transformer Engine installation are required")
    torch.cuda.set_device(0)
    params = [torch.nn.Parameter(torch.full(
        (args.chunk_numel,), 0.5, device="cuda", dtype=torch.bfloat16,
    )) for _ in range(args.chunks)]
    config = OptimizerConfig(
        optimizer="adam", lr=0.01, bf16=True, use_distributed_optimizer=True,
        use_precision_aware_optimizer=True, store_param_remainders=args.remainders,
    )
    if config.store_param_remainders != args.remainders:
        parser.error("this Transformer Engine version disabled the requested remainder mode")

    def wrap(inner, optimizer_config, grad_scaler, initialize, **kwargs):
        wrapper = object.__new__(distrib_optimizer.DistributedOptimizer)
        wrapper.optimizer = inner
        wrapper.config = optimizer_config
        wrapper.ddp_config = SimpleNamespace(use_megatron_fsdp=False)
        wrapper.grad_scaler = grad_scaler
        wrapper.init_state_fn = initialize
        wrapper.model_param_group_index_map = {
            p: (i, j) for i, group in enumerate(inner.param_groups)
            for j, p in enumerate(group["params"])
        }
        param_map = {p: {"gbuf_world": range(p.numel())} for p in params}
        wrapper.gbuf_ranges = [{"buffer": [{"param_map": param_map}]}]
        return wrapper

    with patch("megatron.core.optimizer.DistributedOptimizer", side_effect=wrap):
        wrapper = _get_megatron_optimizer_based_on_param_groups(
            config, model_chunks=[torch.nn.Module()],
            param_groups=[{"params": params, "wd_mult": 1.0,
                           "param_names": [f"p{i}" for i in range(len(params))]}],
            pg_collection=SimpleNamespace(tp=None, expt_tp=None),
        )
    assert type(wrapper.optimizer) is FusedAdam
    inner = wrapper.optimizer
    assert inner.store_param_remainders == args.remainders
    metadata = wrapper.state_dict()
    metadata["optimizer"]["param_groups"][0]["step"] = 2

    def storage_addresses():
        return {(i, key): value.data_ptr() for i, p in enumerate(params)
                for key, value in inner.state.get(p, {}).items()
                if isinstance(value, torch.Tensor)}

    results = []
    for phase in ("fresh", "initialized"):
        addresses_before = storage_addresses()  # Integers only; retain no old tensors.
        gc.collect()
        torch.cuda.empty_cache()
        torch.cuda.synchronize()
        start = torch.cuda.memory_allocated()
        torch.cuda.reset_peak_memory_stats()
        began = time.perf_counter()
        wrapper.load_state_dict(metadata)
        torch.cuda.synchronize()
        elapsed = time.perf_counter() - began
        final = torch.cuda.memory_allocated()
        peak = torch.cuda.max_memory_allocated()
        results.append({
            "phase": phase, "start_allocated_bytes": start,

def _step(inner, params, step):
    for param in params:
        grad = torch.linspace(-0.2, 0.3, param.numel(), device=param.device) + step * 0.01
        param.grad = grad.to(param.dtype)
        param.decoupled_grad = grad
    inner.step()

The pointer checks document the mechanism (the DCP targets stay the live tensors), but no test asserts the property the change is for: that the final `load_state_dict` does not allocate a second copy of the state. Measuring the growth of `max_memory_allocated` over the allocation before that call catches a regression to the rebuilding loader directly: I ran the assertion below in all four `dp_reshardable` cases, and the growth is 0 bytes on this branch while on `main` it is exactly the size of the live optimizer state (one full second copy; the bound of one FP32 copy of the largest parameter, 4,096 bytes here, is the eager-initialisation transient with full masters). A second small point: `pointers` is collected after `sharded_state_dict(is_loading=True)`, which is what populates the state through the new eager branch, so asserting it is non-empty keeps the identity assertions from passing vacuously if that ever changes (it holds today on both commits).
