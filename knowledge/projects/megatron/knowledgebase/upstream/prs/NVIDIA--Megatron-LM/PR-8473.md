# What does this PR do?
Make TrainState available in CallbackContext for the training callback system.

## Issue tracking
Fixes #8438

## Description
This addresses the follow-up task from #3555 where `TrainState` became the source of truth across Megatron training state.

Changes:
- Added `train_state: TrainState | None = None` to `CallbackContext` dataclass with type annotations and docstring.
- Updated `CallbackManager.callback_context` field availability documentation.
- Assigned `callback_manager.callback_context.train_state = get_train_state()` in `pretrain()` prior to `on_setup_start` and `on_data_init_start`.
- Updated `tests/unit_tests/training/test_callbacks.py` to assert `train_state` accessibility and default value.
