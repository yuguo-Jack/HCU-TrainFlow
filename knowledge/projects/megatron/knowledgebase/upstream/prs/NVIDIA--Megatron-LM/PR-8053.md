# Take the batch-invariant MoE EP size from the token dispatcher

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8053) · state: closed · merged: False

## Original PR description

**Why.** The batch-invariant MoE unpermute sums the experts of each EP rank into one partial and adds the partials in rank order, so the EP size decides the summation tree. It read that size from the global parallel state, so a dispatcher with its own EP group on another grid was combined by the global grid's split. With EP=2 under a global EP of 1, all experts land in one partial, and the result no longer matches the rank-ordered combine this path mirrors.

**What.**
- `moe_utils.unpermute` and `batch_invariant.unpermute` take an optional `ep_size`.
- `MoEAlltoAllTokenDispatcher.combine_postprocess` passes its own `ep_size`. It is the only dispatcher that reaches this path, because batch-invariant MoE training requires the AlltoAll dispatcher.
- Callers that pass nothing keep the global EP size through a commented fallback.

**Tests.** New `test_batch_invariant_unpermute.py` uses one token whose four expert outputs sum differently for EP=1, 2 and 4. It checks:
- that `ep_size` decides the split, with every global accessor patched to fail;
- the global fallback when nothing is passed;
- the AlltoAll dispatcher on 2-rank EP groups under a global EP of 1, with the globals patched to fail.

The first and last cases fail on main. Before the 2026-11-01 sync, the dispatcher, batch-invariant RL and MoE determinism suites passed on 4 GPUs, as on main.

In the integration run (main 77391e71cc with all #6307 PRs merged, against main itself), `test_batch_invariant_unpermute.py` passes on 4 GPUs: 6 passed, including tests that another #6307 PR adds to the file. Main does not have this file. `test_token_dispatcher.py` runs there on 8 GPUs (two nodes) and exits with an error on main and with the campaign alike, without recording per-test results, so the run gives no per-test comparison for it.

**Compatibility.** `ep_size` is a new optional argument. There is no change on the standard grid, where the dispatcher's EP group is the global one. The summation code is unchanged, so the PR needs the `determinism-exempt` label.

The branch was synced with main 77391e71cc on 2026-11-01 by a merge commit that lists each conflict and its resolution, so existing commits and review links stay valid.
