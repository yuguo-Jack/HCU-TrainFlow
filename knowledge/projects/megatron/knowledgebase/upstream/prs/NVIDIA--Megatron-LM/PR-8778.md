## What does this PR do?

Rebased onto `main` at `362cff32d`. Main now contains the prerequisite execution-order refactor, so this PR contains only the scheduling change in commit `6069a4db9`.

A PP/VPP schedule issues several autograd backward calls through one shared FSDP context. Ending recording after the first backward captures only part of that schedule. With caller-managed gradient synchronization, finish recording at `finish_grad_sync()` after all microbatches, and check that subsequent replay has consumed the complete trace. Per-autograd deferred module cleanup remains in place.

Select recorded mode for PP/VPP and EP overlap, reject registration-mode ambient contexts for these schedules, and record compute events from the combined-1F1B hooks. Evaluation gathers on demand without consuming the training trace. Ordinary eager training retains registration mode. Both modes use main's single cursor and lookahead, including lookahead across forward/backward phase changes.
