# fix: preserve expert topology for all-gather overlap groups

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8812) · state: closed · merged: False

## Original PR description

## Summary

`create_all_gather_groups()` reconstructs expert data-parallel ranks with a hard-coded axis order and zero rank offset. With a non-default initialization topology, its expert all-gather communicator can therefore differ from the expert data-parallel communicator.

Preserve the expert replica rank lists resolved by `initialize_model_parallel()` and reuse them when creating the separate all-gather groups. Clear the saved lists on teardown. The dense path already follows this pattern.

Update the expert-group regression test to call the real helper and check matching rank membership and distinct communicators for both default and non-default axis order.

Related: #4261 and #5754. This is a current-main alternative to retaining rank-generator objects.
