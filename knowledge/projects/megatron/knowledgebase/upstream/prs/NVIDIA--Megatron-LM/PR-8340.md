# What does this PR do?
Removes the parallel ModelOpt model-construction path (`megatron/post_training/model_builder.py`: `ModelOptGPTModelBuilder`, `ModelOptHybridModelBuilder`, `ModelOpt*ModelConfig`, `modelopt_gpt_hybrid_builder`). ModelOpt models are now built by the stock `GPTModelBuilder` / `HybridModelBuilder` from a regular, serializable `GPTModelConfig` / `HybridModelConfig`.

## Design
- **Config, not builder subclasses.** `megatron.post_training.model_config.modelopt_model_config_from_args()` returns a stock config with the ModelOpt layer spec (from the `--export-*` flags) and a few `TransformerConfig` tweaks (GPT-OSS YaRN, `qk_l2_norm`, `moe_apply_probs_on_input`, offline `num_layers=0`). MTP keeps the standard decoder spec (`mtp_layer_spec`), as the old builder did.
- **Declarative setup.** A new `ModelConfig.transformations: ModelTransformConfig` field holds the QAD train target, LSQ scale LR and TE layernorm remapping. It serializes with the model config, so a reloaded config rebuilds the same model.
- **Distillation is a run-level setting.** It lives in `PretrainConfigContainer.distillation: DistillationConfig`, next to the student's `checkpoint`, not in the student's model config. It holds:
  - the teacher checkpoint (path and format);
  - the resolved `teacher_model` config, from the teacher YAML, read once at CLI translation;
  - the KD loss settings: `intermediate_layer_pairs`, `logit_layers`, `skip_lm_loss`, `kd_loss_scale`, `logit_kl_temperature`, `logit_kl_topk`.

  `--export-kd-cfg` is read into the loss fields. It does not inherit from ModelOpt's `DistillationConfig`: that would make modelopt a hard dependency of every training run and put live loss objects into the saved config. Only non-default loss values are passed to ModelOpt. Inference containers have no distillation section.
- **Hooks rebuilt from config.** On each build, `ModelBuilder.pre_wrap_hook()` composes the hooks in `megatron.post_training.model_hooks`, before Float16Module/DDP wrapping, in this order:
  1. Restore `modelopt_state`, from the run container's `checkpoint.load`.
  2. QAD freeze.
  3. LSQ.
  4. TE load hook.
  5. User `pre_wrap_hooks`, including the training freezes.
  6. KD conversion, from the run container's `distillation`.

  The ordering holds by construction. No hook tags or insertion tricks are needed.
- **Teacher.** The teacher is built by the same builder class as the student. Its weights are still loaded after mixed-precision wrapping (`load_kd_teacher_checkpoint`), never inside the hook.
- **Validation.** `DistillationConfig.validate` checks the config itself. `DistillationConfig.validate_student` checks the KD compatibility of the student:
  - VPP
  - `tp_comm_overlap`
  - TE cross-entropy
  - matching student/teacher TP/PP/CP/EP/`pipeline_dtype`

  The container adds the `manual_gc` check. They run before any model is allocated.
- **Run-container construction.** `cfg.build_models()` is the single entry point. It supplies the checkpoint, distillation, FSDP and placement settings. `InferenceConfigContainer.model_build: ModelBuildConfig` holds the inference execution policy (device, DDP wrapping, mixed-precision wrapper), and the distributed builder accepts an explicit `device=` (e.g. CPU export). `MimoModelBuilder` accepts the new kwargs.
- **Model type.** It is inferred instead of read from `--export-model-type`. `pretrain_gpt.py`, `pretrain_hybrid.py` and flextron pass the type. The post-training scripts treat a model as hybrid iff `--hybrid-layer-pattern` is set.

## Behavior changes / deprecations
- The KD teacher is now built with the student's layer-spec flags; before, it ignored some of them.
- `--freeze-all-layers` / `--freeze-base-model-for-mtp` freezes now always run before the KD conversion.
- `--export-model-type` is **deprecated** (default `None`). It is still honored, e.g. for a hybrid model without a layer pattern. It warns, and it raises if it contradicts the entry point or the layer pattern. Before this change, a hybrid ModelOpt run that omitted it silently built a GPT config.
- The `model_config_cls=` parameter of `gpt_config_from_args` / `hybrid_config_from_args` is removed. So is the private `_freeze_base_for_mtp` alias; `--freeze-base-for-mtp` still works.
- `--modelopt-enabled` is **deprecated**. ModelOpt configuration is inferred from a ModelOpt checkpoint or from ModelOpt-specific options, and the distillation loss and pipeline shape adjustment are selected from the built model.
- `DistillationConfig.kd_cfg` (a path to the loss YAML) is **deprecated**. Setting it warns and reads the YAML into the loss fields. The `--export-kd-cfg` flag is unchanged.
- The serialized `_builder_` key is accepted for compatibility but ignored. The `_target_` class determines the builder.
- The per-layer parameter-count print in the old hybrid builder is dropped.
- The QAD and flextron hybrid functional-test configs no longer pass `--export-model-type`.

## Not in this PR
- Distillation redesign (`TeacherSource`, `LossSpec`, moving the KD engine into MCore).
- Removing the `args.finetune` teacher-load workaround.
- Lifting the VPP and TE-cross-entropy KD restrictions.
- Making `load_checkpoint` read `CheckpointConfig` instead of args.
