# [DSv4.1] Single-pass mHC

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8223) · state: open · merged: False

## Original PR description

Carry each sublayer's FP32 pre-mix coefficients explicitly into the next sublayer, including entry/exit handling. Compile the FP32 mapping and let fused post-mixing kernels store in the activation dtype, retaining FP32 coefficient math and bias-gradient reduction.

Independent prerequisite based on main. Original changes by @guihong-nv in #7500 and @hxbai in #7224, split and adapted here.

Validation: native/fused output and gradient checks, autocast, deterministic replay, Torch/TE layer capture and distributed stack regression passed on H100. An 8K/hidden-2048 forward-backward probe takes 3.66 ms versus 4.27 ms for the reference branch. The existing FP32 PP/VPP parity test now explicitly selects IEEE GEMMs; its tolerances are unchanged. Synchronized with main at e8a302ac5b.

Shared test fix: THD parity tests use nonblocking NCCL communicators so CP teardown completes; their numerical checks are unchanged.

Direct mapping-parameter reads now call `ensure_params_ready` before use, so distributed-optimizer parameter-gather overlap completes even when Linear.forward hooks are bypassed. This fix passed repeated 16-GPU steps and the assembled BF16/MXFP8 proxy runs.
