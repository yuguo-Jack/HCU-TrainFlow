# [DSv4.1] Single-pass mHC

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8223) · state: open · merged: False

## Original PR description

Carry each sublayer's FP32 pre-mix coefficients explicitly into the next sublayer, including entry/exit handling. This provides V4.1 single-pass mHC while preserving existing mHC behavior. Compile the FP32 coefficient mapping and let fused post-mixing kernels store directly in the activation dtype, retaining FP32 coefficients and accumulation.

Independent prerequisite, based on main. Original changes by @guihong-nv in #7500 and @hxbai in #7224, split and adapted here.

Validation: H100 native/fused output and gradient tests, coefficient precision, autocast and graph replay passed. The assembled V4.1 stack also passed PP/VPP, full recompute and 8-GPU training. Black/isort/Ruff/Pylint and diff checks passed.

Performance: an 8K-token, hidden-size-2048 H100 forward/backward probe improved from 6.17 ms to 3.66 ms; the same probe on the source implementation was 4.27 ms. The existing state/PP/CP design and runtime options are unchanged.
