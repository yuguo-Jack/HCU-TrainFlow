# datasets: publish complete index caches atomically

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8196) · state: open · merged: False

## Original PR description

## what changed

stage dataset index arrays on the same filesystem, replace their final paths after all writes finish, and publish the description last. gpt, blended, and masked datasets use the same save path. cache names, formats, and existing read paths stay unchanged.

fixes #8189.

## why

an interrupted `numpy.save` currently leaves a truncated file that passes the cache hit check on restart. staging keeps incomplete writes away from the final paths. a normal restart rebuilds an incomplete cache, and existing readers keep their original mappings during replacement.

this prevents new torn writes. caches already damaged by earlier runs need rebuilding. power-loss durability and fast-cache-load synchronization are outside this change.
