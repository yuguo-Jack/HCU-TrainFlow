# Standardize MFSDP v2 adapter tests on pytest fixtures

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8354) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

Mixing pytest fixtures with xUnit-style setup and teardown has led to duplicated lifecycle management and confusion about which setup a test needs and when cleanup runs. Class-owned state also hides dependencies that would be clearer as explicit test arguments.

Standardize the four MFSDP v2 adapter test files on module-level tests with explicit pytest fixtures. Fixture dependencies express the setup order, and cleanup stays with the resources each fixture creates. This preserves the distributed setup and teardown ordering established in #7710 while giving these tests one consistent lifecycle model.

The test computations, assertions, tolerances, markers, and all 34 parameterized cases are unchanged, verified by comparing the Python ASTs against the PR base. Pytest node IDs change because the test classes are removed.

Validation on two RTX A6000 GPUs:

- All four files: **29 passed, 5 skipped per rank**. Fresh training-before-NCCL-user-buffer sequence: **2 passed per rank**.
- Test-selection suite: **27 passed**.
- Black, isort, Pylint, and Ruff passed; mypy was unavailable.

Local validation used NGC 26.08; CI targets NGC 26.09. The five skipped cases require Blackwell hardware or four ranks.
