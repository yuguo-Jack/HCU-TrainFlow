# Fused router: TE fused_topk_with_score_function for the eager top-k/softmax/scatter chain and the router bias gradient f

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8128) · state: open · merged: False

## Original PR description

TE fused top-k/softmax router kernel enabled; router bias grad from the BGRAD epilogue.

Tests: see commits

---
Measurement (2026-10-12, GPT-OSS 20B, VR200 2x4x3, MXFP8, one run per state, same seed): with this change the step time was 0.2606 s against 0.2621 s with the fused router but the stock `grad_output.sum` bias gradient, and 0.2574 s before either; the BGRAD epilogue on the [tokens, 32] router wgrad GEMM costs about 4.7 ms/step there. The submission image no longer carries it. Kept open as a draft for the record; not recommended for merge without a different kernel strategy for skinny N.
