# Stream local Newton-Schulz batches in LayerShardedMuon

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8379) · state: closed · merged: True

## Original PR description

LayerShardedMuon retains Newton–Schulz inputs and outputs for the entire local parameter group even when `muon_ns_batch_size` is small. This change builds local inputs one batch at a time, applies each batch's updates immediately, and scales the orthogonalized output in place. The routed path retains the materialized `_run_ns` interface. Defaults are unchanged.

This is the public-main port of [NVIDIA-NeMo/nv-mistralai-megatron#771](https://github.com/NVIDIA-NeMo/nv-mistralai-megatron/pull/771). Public main already handles empty NS-home assignments and single-rank domains through `_homes_set` and unconditional layer-wise wiring, introduced in [#6683](https://github.com/NVIDIA/Megatron-LM/pull/6683). This port therefore carries the remaining memory improvement and regression coverage while preserving that dispatch and public main's SYRK validation.

The tests cover bitwise parity with the per-matrix loop at batch size 1, batched NS at larger sizes, Nesterov input construction per chunk, and the unwired TP fallback. They use public main's `muon_tp_mode='layer_sharded'` for dense and expert buckets; the source branch's separate `muon_expert_tp_mode` option is unavailable here.
