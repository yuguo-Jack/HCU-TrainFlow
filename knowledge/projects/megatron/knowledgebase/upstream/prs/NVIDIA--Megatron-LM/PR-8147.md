# Fuse the Q/K RMSNorm into TE's single-QKV RoPE path

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8147) · state: open · merged: False

## Original PR description

This PR lets Megatron-LM's attention take the fused single-QKV RoPE path with per-head Q/K RMSNorm by passing the TE RMSNorm weights into `apply_fused_qkv_rotary_pos_emb`, instead of splitting QKV and running the norm and RoPE separately.

It relies on [this TE PR](https://github.com/NVIDIA/TransformerEngine/pull/3673) that lets that kernel apply the norm; with an older TE, or with L2Norm/LayerNorm QK-norms, nothing changes and the split path stays.

The tests compare fused vs split attention outputs and gradients on the same layer, and replay forward and backward bit-exactly (registered in the kernel determinism manifest).
