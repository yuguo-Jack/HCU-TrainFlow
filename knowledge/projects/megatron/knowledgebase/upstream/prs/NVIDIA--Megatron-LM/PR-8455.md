# fix(dist-opt): checkpoint padding-only DP shards

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8455) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## Problem

Saving a `dp_reshardable` distributed-optimizer checkpoint asserts with `empty bucket encountered` when a DP shard contains only padding. Parameters are aligned to 64-element boundaries, and small parameters at large DP×CP sizes can leave an entire shard inside an alignment gap.

For example, two 24-element parameters form a bucket laid out as `[24 | 40 padding | 24 | 40 trailing padding]`. With four 32-element shards, rank 1 owns only interior padding and rank 3 owns only trailing padding.

## Change

- Skip shards that contain only trailing padding, outside the checkpoint tensor's unpadded extent.
- Write interior-padding shards so the global checkpoint tensor remains fully covered, using optimizer-state keys, dtypes, and device from a locally owned parameter.
- Skip restoring parameter state for shards that own no parameters.
- Add a save/load regression test covering both padding cases with 4 or 8 ranks and checking exact optimizer-state equality after restoration.

This ports NVIDIA-NeMo/nv-mistralai-megatron#800 to upstream main. Upstream also needs the trailing-padding handling that was already present in that fork.

## Validation

- Local syntax, `git diff --check`, Black, pinned isort 5.13.2, and Ruff checks pass.
- The corresponding fork fix previously passed the four-GPU regression run (9 selected tests per rank); its new regression failed without the fix. An equivalent backport also passed focused Adam/distributed-optimizer and layer-wise Muon `dp_reshardable` save/load checks.
- **The exact upstream port has not yet been GPU-tested.** This PR remains a draft pending that validation. Full autoformatter/pylint checks have not been run locally.
- The larger NT4 production save/resume validation is not claimed as complete.

Coverage boundary: the fixture ensures every rank owns a parameter in another bucket. A rank with no owned parameters anywhere is not covered; padding-state construction still relies on a locally owned parameter as its template. Separate compact-Muon gather issues are outside this change.
