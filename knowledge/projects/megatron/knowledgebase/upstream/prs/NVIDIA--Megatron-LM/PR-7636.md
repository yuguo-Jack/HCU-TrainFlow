# Clean up MFSDP parameter-group annotations

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7636) · state: closed · merged: True

## Original PR description

Clean up experimental MFSDP parameter-group annotations by removing unnecessary quotes and moving `get_containing_parameter_group()` below `FsdpParameterGroup` so its return annotation can reference the class directly.

Replace the empty no-TE `QuantizedDBuffer` placeholder class with a `DBuffer` alias. Add a comment explaining that the `UnavailableError` string in `quantized_dbuffer.py` is required by the CI import checker.

Validation after rebasing onto `6e7e6ed43`:
- Ran `test_parameter.py`, `test_fully_shard.py`, `test_grad_comm_dtype.py`, and `test_quantization.py` through `torch.distributed.run` on two RTX A6000 GPUs: 42 passed and 15 skipped per rank. Nine cases require four GPUs; six MXFP8 cases require Blackwell hardware. The rebase preserves main's new `grad_comm_dtype` behavior.
- An ad hoc import check with Transformer Engine simulated as unavailable passed: the buffer alias, native dtype fallback, and unowned-parameter lookup work.
- `tools/autoformat.sh` check mode completed successfully: Black, isort, and Ruff passed; Pylint rated the code 10/10 with its unsupported `bad-builtins` configuration diagnostic. Advisory mypy reported three errors: two missing Transformer Engine typing declarations and `Cannot assign to a type` for the fallback alias.
