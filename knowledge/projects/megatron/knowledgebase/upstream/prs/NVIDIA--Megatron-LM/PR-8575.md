# What does this PR do?
Megatron-FSDP backward-prefetch fix: stop counting buckets that need no all-gather against the prefetch size.

**Prefetch size.** `_extend_by_prefetch_size` counted every bucket toward `suggested_AG_prefetch_size`, including buckets that are not sharded on the gathering group and need no all-gather. A large unsharded bucket (e.g. local experts with expert DP-Shard of 1) used up the whole budget, so the dense buckets behind it were gathered on demand. Such buckets now count zero.
