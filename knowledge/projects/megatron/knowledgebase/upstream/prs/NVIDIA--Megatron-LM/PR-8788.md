# What does this PR do?
With `--log-params-norm`, `calc_params_l2_norm` called `stop_communication()` on each FSDP model chunk, which reset the all-gather pipeline and threw away the param all-gathers the optimizer step had just started for the next fwd. The norm now reads the DTensor shards directly and leaves those gathers in flight.
