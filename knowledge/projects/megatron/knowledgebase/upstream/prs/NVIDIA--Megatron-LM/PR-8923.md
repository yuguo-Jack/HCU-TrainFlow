# Deprecate the DeepGEMM dense batch-invariant GEMM backend

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8923) · state: open · merged: False

# What does this PR do?

Deprecates the DeepGEMM dense GEMM backend of batch-invariant mode (`batch_invariant_backend="deepgemm"`).

That backend routed `aten::mm` / `aten::addmm` through DeepGEMM's `bf16_gemm_nn`. `te_native` (the default) keeps the native cuBLASLt kernels with a starved workspace, is the configuration verified bitwise-identical to the TE training forward, and needs no extra dependency, so the dense DeepGEMM path is removed:

- `"deepgemm"` is still accepted, with a `DeprecationWarning`, and runs as `te_native`. `TransformerConfig`, `enable_batch_invariant_mode` and `set_batch_invariant_mode` all map it, so existing configs and scripts keep working.
- `_mm_deepgemm` and the DeepGEMM branches of `mm_batch_invariant` / `addmm_batch_invariant` are removed; `_BATCH_INVARIANT_BACKENDS` is now `("triton", "te_native")`.
- **Not removed:** DeepGEMM's bf16 grouped GEMMs. The `triton` backend's MoE experts (`TEGroupedMLP`) and the `torch` inference backend's BF16 experts still use them, so the `[batch_invariant]` extra and the `HAVE_DEEPGEMM_BF16` checks for those paths stay.
- Docs (`docs/mcore-inference-user-guide.md`) and the config docstring describe the deprecation and which paths still need DeepGEMM.

Tests:
- Removed `tests/unit_tests/inference/test_batch_invariant_deepgemm_stride.py` (it tested the removed dense path) and its manifest entry.
- Replaced the DeepGEMM-backend fp32-router test in `test_te_layers_batch_invariant.py` with a deprecation test (warning, and the active backend is `te_native`).
- Ran on GB200: `test_te_layers_batch_invariant.py` (43 passed, 1 skipped); `test_moe_batch_invariant.py`, `test_vllm_fused_moe_batch_invariant.py` and the inference determinism kernels on 4 GPUs (48 passed, 18 skipped per rank); a `TransformerConfig(batch_invariant_backend="deepgemm")` builds as `te_native` with the warning. Lint and the determinism coverage check pass.
