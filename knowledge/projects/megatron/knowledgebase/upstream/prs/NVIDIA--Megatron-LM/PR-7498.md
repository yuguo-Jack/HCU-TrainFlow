# Fix MTP loss normalization across context parallel ranks

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7498) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Fix MTP loss normalization across context-parallel ranks. A rank with no original LM targets can receive a shifted MTP target and discard its gradient because the current per-token normalization multiplies by its zero local count. Even an all-ones mask gives different weights after CP partitioning.

Reduce original and shifted token counts over the explicit CP group, compensate CP averaging in legacy mode, and apply consistent weighting to logged MTP loss. CP=1 behavior and the existing DP/microbatch objective are preserved. There are no parameter, checkpoint-format, or public-signature changes; CP>1 adds one two-scalar collective per MTP depth.

Related to NVIDIA-NeMo/Megatron-Bridge#6103 and NVIDIA-NeMo/Megatron-Bridge#6105. The Bridge PR forwards the mask; this companion fixes normalization in Megatron-Core once the mask reaches the model.

## Tests

- Add a two-GPU functional test using a complete GPT+MTP model, the training schedule, Megatron DDP, and `finalize_model_grads`. Compare every parameter's gradient against CP=1 for seven masks, MTP depths 1/3, both normalization modes, and two accumulated microbatches. The empty mask must produce exactly zero gradients. Register the test for H100 dev/lts functional CI.
- Add focused unit coverage for token, hidden-state, and shared-head gradients, plus logged loss, with packed/unpacked layouts and all single-target positions.
- On two H100s, the functional test fails **19/28** combinations before the fix and passes **28/28** after it. The boundary-crossing case has 100% MTP gradient error in per-token mode before the fix. After the fix, the maximum per-parameter relative gradient error is **1.041%**, below the **2.5%** BF16 tolerance.
- The focused unit suite now includes 12 additional depth-3 conditioning-mask cases, covering CP-boundary invalid tokens and all-valid/all-invalid controls, both normalization modes, and packed/unpacked layouts. An independent token-gradient calculation also checks the effective-mask denominator at every depth. All 21 cases pass on each of two GPUs with NCCL (`pytest --noconftest`, avoiding unrelated dataset setup).
- Earlier native CPU/Gloo validation of the main patch passed 2,534 comparisons, including exhaustive eight-token masks and unequal microbatch accumulation. Four-process checks also covered two independent CP groups with different data.

Reproduce the functional test:

```bash
CUDA_DEVICE_MAX_CONNECTIONS=1 uv run python -m torch.distributed.run \
  --standalone --nproc-per-node=2 \
  -m tests.functional_tests.test_cases.gpt.gpt_mtp_cp_gradients.test_gradients
```
