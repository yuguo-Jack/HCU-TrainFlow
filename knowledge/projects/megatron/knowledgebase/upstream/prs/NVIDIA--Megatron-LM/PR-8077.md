## Original PR description

The concentration CLI crashes comparing None with an integer when MTP trace records mix omitted and explicit optional head indices. Use a numeric sort key while preserving distinct layer identities.

Validation: real JSONL CLI regression fails on baseline and passes fixed; isort, Black and Ruff pass for the regression file. CPU tooling only; no GPU inference run. The full autoformat script reaches the pylint stage but pylint is unavailable in the local lightweight environment.
