# Use shared residual dispatch for mHC

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8669) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

Routes mHC through the `ResidualConnection` contract refined in #8657, so mHC and Wide Residuals share Transformer-layer scheduling. The dedicated mHC layer inherits the base attention and MLP schedules instead of duplicating them.

## Changes

- Add parameterless read/write adapters that invoke the existing mHC owners and carry the residual and predicted maps between operations. Parameter names, state-dict keys, and owner hooks are preserved.
- Share one numerical write helper between eager execution and checkpoint replay. Output-discard replay covers aggregation and nonterminal writes; projection retains its independent checkpoint.
- Preserve mHC's residual selection, norm checkpointing, gradient scopes, and terminal-write behavior through the shared schedule.

The existing mHC manager entry point remains in use; manager/context unification is deferred to the layer PR.

## Issue tracking

Depends on #8657.
