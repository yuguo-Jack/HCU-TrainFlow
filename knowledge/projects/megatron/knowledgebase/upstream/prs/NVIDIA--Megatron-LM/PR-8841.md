# Fused kernels for shortcut MoE wide residual layernorm 

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8841) · state: open · merged: False

## Original PR description

Add a fused kernel path for wide-residual hybrid models with shortcut- connected MoE (--wide-residual-shortcut-moe-kernel-fusion). At each shortcut boundary one Gluon kernel mixes the residual streams with the branch updates, writes the new FP32 residual, and emits the RMSNorm readers that consume it (BF16, or an MXFP8 handoff to the next GEMM). The backward pass fuses the matching gradient stages, and checkpointed residuals are reconstructed by forward replay instead of being stored (--residual-stream-recompute-num-layers).

Forward schedules (GB300):
- Training and long prefill: tuned per-shape configs for the production widths and a small decision tree for other shapes (hidden 3072-16384, 1-6 streams), 85-90% of peak DRAM at 4K+ rows.
- Inference: each row's loads are issued before any store, configs come from a decision tree over rows/hidden/streams/readers/precision, and decode rows split across an sm_90+ CTA cluster that exchanges partial sums of squares through distributed shared memory. Launches are programmatic dependents (PDL) on sm_90+.

Residual writes are bit-identical across schedules and match checkpoint replay; reader outputs differ by at most one BF16 ulp between schedules. Adds unit, determinism (CUDA-graph replay), MXFP8, shape and model tests.
