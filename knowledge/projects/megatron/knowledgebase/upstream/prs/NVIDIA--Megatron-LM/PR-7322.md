# Use local optimizer tensors in MFSDP v2 until checkpointing

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7322) · state: open · merged: False

## Original PR description

## What does this PR do?

Keep MFSDP v2 optimizer-facing parameters, gradients, and optimizer state as local tensors during training. Repeated DTensor construction and dispatch add Python overhead; distributed layouts already live in MFSDP's buffers. Construct DTensor views only at checkpoint boundaries, where global shapes and sharding metadata are needed. Related to #7264.

Rebased onto `main` at `2052769557dcf7045c4091d1996f0bc59afeb80e` and consolidated into one commit.

The review fixes are included:
- `--log-params-norm` reads local shards and their buffer layouts. It does not construct DTensors. The existing MFSDP v1 DTensor norm interface and reduction grouping are preserved.
- Per-token gradient normalization (#7711) scales finalized local gradients.
- Independent dense/expert sharding tests (#7728) inspect the owning buffers' layouts instead of expecting runtime DTensors.
- The newer MFSDP Muon path uses local weights, gradients, and momentum.
- Preserve current `main`'s expert-parallel checkpoint support, empty-shard handling, and refresh of compute weights after loading. Checkpoint wrappers do not replace optimizer parameters or leak into live state.

## Validation

On two RTX A6000 GPUs:
- **142 distinct tests passed per rank**, with 32 skips for hardware/topology requirements. This covers native and MCore checkpoints, EP=1/2 checkpoint round trips, tied parameters and aliases, empty shards, accumulation, clipping, gradient statistics, hybrid sharding, memory, and all 16 Muon reference-loss comparisons.
- Twelve new regression cases compare parameter norms with full weights and compare token-normalized gradients and three SGD updates with a dense reference across all four sharding strategies. Norm coverage includes frozen parameters and aliases, and checks the existing DTensor norm interface.
- The real `pretrain_gpt.py` entry point completed six BF16 MoE updates with EP=2, four microbatches/update, `--calculate-per-token-loss`, and `--log-params-norm`.
- Repository `tools/autoformat.sh` passes Black, isort, Pylint, and Ruff checks. Its advisory mypy step reports 37 diagnostics versus 55 on unchanged `main`, with no added diagnostics.
- Numerical tolerances are unchanged. The `Run functional tests` label is enabled for CI; the local runs do not replace Blackwell or larger-topology CI coverage.

These numbers do not establish the incremental benefit under the current NT4 manual-GC/grouped-weight configuration.

## Compatibility

Bare model/base-optimizer `state_dict()` calls expose local shards. Distributed checkpoints must use the native MFSDP save/load helpers or MCore's `state_dict_for_save_checkpoint` and optimizer `sharded_state_dict` interfaces. Elementwise optimizer state is wrapped with the parameter's checkpoint layout and unwrapped after loading. This does not add support for factored optimizer state or address buffer-layout construction overhead.

- ahmadki · comment · 2026-10-29T13:41:22Z · [source](https://github.com/NVIDIA/Megatron-LM/pull/7322#discussion_r4413039362)

File: `megatron/core/distributed/fsdp/src/megatron_fsdp/experimental/parameter_group.py` · line 692

With `.grad` now local, PP>1 with tied embeddings crashes on iteration 1 in `finalize_model_grads._full_embedding_grad`: `TypeError: Input must be a DTensor, got Tensor.` (2 GPUs, `--pipeline-model-parallel-size 2`; the base commit trains). No v2 test covers PP>1.

The fix, in `_allreduce_embedding_grad` before `_full_embedding_grad`: view the local grad through its group's DTensor, which shares storage, so `_copy_embedding_grad_back` writes into `.grad`:
```python
if ddp_config.use_megatron_fsdp and orig_grad is not None and not isinstance(orig_grad, DTensor):
    group = get_containing_parameter_group(weight)
    index = next(i for i, p in enumerate(group.fsdp_parameters) if p.sharded is weight)
    orig_grad = group.pre_optimizer_main_grad.get_dtensor(index)
```
With it, PP=2 trains bit-identically to the base commit.

(The crash actually happens in `finalize_model_grads.py`, but that file isn't in the diff, so I'm anchoring the review here, where `.grad` becomes local.)
