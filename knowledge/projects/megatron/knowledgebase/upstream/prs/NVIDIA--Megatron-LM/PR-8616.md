# What does this PR do?

This PR introduces a complete, high-fidelity Simplified Chinese translation of the project README (`README.zh.md`) and configures bidirectional navigation between `README.md` and `README.zh.md`.

- `README.zh.md`: Complete translation covering project overview (Megatron-LM vs. Megatron Core), Megatron Bridge integration, quickstart & source installation instructions, memory limits with `MAX_JOBS`, latest news & blogs, project directory structure tree, performance benchmarking on GB300 NVL72 / GB200, roadmap links, resources, and academic citations, with a community volunteer translation disclaimer at the bottom.
- `README.md`: Added bidirectional `English | 简体中文` language switcher with an absolute GitHub link for PyPI rendering safety.
