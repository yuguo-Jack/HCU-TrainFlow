# Handle MXFP8-dispatched GroupedTensors in the 1F1B overlap and paged stashing

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7992) · state: open · merged: False

## Original PR description

With MXFP8 token dispatch (moe_dispatch_fwd_dtype="mxfp8"), Transformer Engine's NCCL-EP dispatch hands the experts a per-expert GroupedTensor; with moe_combine_bwd_dtype="mxfp8" the expert-output gradient is one too. Two paths fail on it.

The paged-stash schedule hook is an identity autograd Function on the expert input, whose output autograd derives with view_as, which a GroupedTensor does not support. Put the hook on the probs instead: they feed the same fused expert op.

The 1F1B A2A overlap schedule calls record_stream on node inputs and output grads and frees inputs by resizing their storages. A GroupedTensor cannot run record_stream when the experts receive different token counts, and its buffers are the ones the expert op saves for backward. Record the streams on its buffers and drop the grouped tensor's references to them.
