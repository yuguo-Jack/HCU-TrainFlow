# Sort TensorBoard event files using their actual paths

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8078) · state: open · merged: False

## Original PR description

read_tb_logs_as_list discovers events in both the requested directory and its results subdirectory, but obtains modification times using the root directory plus basename for every file. This raises FileNotFoundError for valid results-only events and prevents chronological ordering across both directories. Sort the discovered paths directly.

Validation: two regressions write and read real TensorBoard event files. Both fail on the baseline; the fix passes them and the existing common utility suite (61 tests). Black, isort and Ruff passed. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
