# refactor(fsdp): Extract global layout builders

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7962) · state: open · merged: False

## Original PR description

## What does this PR do?

Separate MFSDP layout construction from `GlobalLayout` metadata by moving the row/block-atomic and tensor-atomic packing algorithms into `layout_builder.py`. Update buffer, parameter-group, and test callers to use the standalone builders.

`GlobalLayout` retains structural validation in `__post_init__` and placement-compatibility validation in `validate_for_row_atomic` / `validate_for_tensor_atomic`. Builders validate their outputs, and buffers continue checking compatibility when an existing layout is reused with different placements. Packing and validation behavior are unchanged.
