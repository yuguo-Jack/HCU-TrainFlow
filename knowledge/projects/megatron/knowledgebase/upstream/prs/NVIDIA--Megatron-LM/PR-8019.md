# What does this PR do?

Selective unit CI currently allocates GPU runners before discovering that a bucket has no affected tests. Move Testmon dependency selection to `ubuntu-latest` and launch H100/GB200 test jobs only when a validated selection or full-suite fallback requires them.

- Read dependency fingerprints without importing the GPU test suite. Pass affected test files to GPU execution in both production and experimental phases.
- Preserve mandatory tests mapped to changed source directories, using the existing validated PR-files artifact, recipe exclusions, and GB200 markers.
- Validate the image, source, rank inventory, and runtime before consuming a plan. Missing or incompatible evidence falls back to full execution. Explicit-file buckets also run fully when the source SHA differs from the baseline.
- Handle absent coverage only when every expected bucket has a verified empty selection.

The cache schema advances to v2 to record collected tests across all ranks. Existing caches fall back to full execution until main publishes a fresh baseline. The repository variable and label controls for selective testing remain in place.
