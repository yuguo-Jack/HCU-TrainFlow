# What does this PR do?

`dist_checkpointing.dict_utils.diff()` reports tensors with different shapes as equal when they broadcast. It compares with `torch.all(x1 == x2)`, so:

```python
diff({"w": torch.ones(1, 4)}, {"w": torch.ones(8, 4)})  # ([], [], [])  - no mismatch
diff({"w": torch.zeros(4)}, {"w": torch.zeros(4, 1)})   # ([], [], [])  - no mismatch
```

`diff()` backs the cross-rank common state dict check (`validation.py`, `_validate_common_state_dict`) and many checkpoint round-trip tests, so a tensor saved with the wrong shape can pass them silently.

This PR checks shapes before comparing values. A shape difference is reported as a mismatch, with both shapes added to the debug data. Tensors with equal shapes are compared exactly as before.


- Without the fix: the new test fails.

I tested on CPU only, with PyTorch 2.14.1. I could not run the GPU checkpoint tests that call `diff()`; if any of them relies on two differently shaped tensors comparing equal, CI will show it here.
