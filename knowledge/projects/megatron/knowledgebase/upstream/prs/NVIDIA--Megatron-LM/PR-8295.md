# Support standard DCP save/load with MFSDP v2 state-dict hooks

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8295) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Make standard PyTorch/DCP checkpointing work with MFSDP v2's packed shards and separate compute weights. State-dict hooks attach the correct shard offsets before DCP saves or loads, and `model.load_state_dict()` refreshes BF16 compute weights from the restored main weights before the next forward pass.

The model and optimizer hooks call V2 preprocessing functions that derive metadata from `GlobalLayout` and the local buffer range, without collectives. The preprocessing functions handle module prefixes and optimizer parameter IDs; the existing explicit metadata helper remains available. Standalone checkpoint helpers rely on these hooks instead of repeating preprocessing and weight refresh.

For MCore models wrapped in `Float16Module`, attach FSDP ownership and checkpoint hooks to the inner model, where the wrapper delegates state-dict operations. Preserve the wrapper for forward execution.

## Validation

- Two GPUs: **32 passed, 1 skipped per rank**, covering checkpointing, optimizer checkpointing/steps, shared pipeline context, and focused adapter tests. EP=4 is skipped because only two GPUs are available.
- A plain BF16 `nn.Module` saves and loads with DCP and finishes with `model.load_state_dict()`, without manual metadata preprocessing or compute-weight refresh. Its forward output matches exactly, including nested FSDP units.
- EP=1/2 regression coverage loads through the unwrapped inner model and compares resumed losses exactly. The no-collective test now covers automatic metadata hooks as well as the explicit helper.
- Fresh end-to-end BF16 EP=2: save steps 1–2, restart in a new process for steps 3–4, and compare with an uninterrupted four-step run. Logged losses, all **84 model/Adam tensors**, and optimizer/scheduler metadata match exactly (459 entries).
- Black, isort, and Ruff pass; Pylint reports only the existing `bad-builtins` configuration warning. Mypy reports three existing adapter import/call diagnostics and no new diagnostics.
