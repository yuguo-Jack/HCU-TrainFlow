## What does this PR do?

Temporarily disable `hybrid_llama3_proxy_mfsdp_v2_cuda_graph` in the H100 development MR and GitHub merge-queue suites by changing its scopes to `mr-broken` and `mr-github-broken`.

Two queue jobs reproduce the same validation failure in all three attempts: only metric steps 1–3 are available against 50 golden steps, despite training stdout reaching iteration 50. This blocks queue entries on loss and memory checks. The test, configuration, and golden values remain available for investigation and re-enabling.

## Issue tracking

Related to #8218. This quarantine does not resolve the underlying metric logging/extraction issue; keep the issue open until the test can be re-enabled.
