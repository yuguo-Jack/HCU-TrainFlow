# [main] feat(attention): Native Attention Residuals (AttnRes) with Block Attention Residuals

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8827) · state: open · merged: False

## Original PR description

Port dev PR #6840.

Native implementation of Attention Residuals (AttnRes, arXiv:2603.15031): replaces the fixed residual accumulation with per-token softmax attention over depth sources (token embedding, completed depth-block sums, and the running intra-block partial sum). Each self-attention and MLP sublayer aggregates the sources with its own zero-initialized pseudo-query; the final output head aggregates all sources before the final layernorm. Supports Block AttnRes (depth blocks), pipeline parallelism (including interleaved VPP), and multi-token prediction. `attn_res_impl` selects the eager / torch.compile / FLA aggregation backend; `attn_res_norm_fusion` folds the consuming RMSNorm into the FLA kernel.

Ported onto current main from the clean dev implementation of PR #6840, independent of KDA / Mixture-of-Kittens. Reconciled with main's current residual architecture:
- uses main's dedicated HyperConnectionTransformerLayer (#8424) rather than re-adding it; AttnResTransformerLayer builds on main's TransformerLayer hooks (_run_input_layernorm / _pre_mlp_layernorm_and_residual / _apply_mlp_bda_step, input_is_normalized);
- AttnRes exit processing routes through TransformerBlock.postprocess_for_layer_schedule, whose mHC contraction uses main's API (enable_mhc_connections / HyperConnectionModule.output_contract / mhc_num_residual_streams);
- dev's enable_hyper_connections renamed to main's enable_mhc_connections throughout.

AttnRes is mutually exclusive with enable_mhc_connections, wide_residual and moe_shortcut_connection.

Deliberately deferred (reporting/test-only, not the mechanism): AttnRes FLOPs accounting in num_floating_point_operations, and AttnRes cases in test_fine_grained_activation_offloading.py.
