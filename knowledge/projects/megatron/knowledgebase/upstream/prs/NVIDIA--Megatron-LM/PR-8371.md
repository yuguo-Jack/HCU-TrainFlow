# Honor RoPE arguments in Nemotron MIMO language provider

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

The Nemotron MIMO language provider hardcodes `position_embedding_type="none"`, so `--position-embedding-type rope` silently constructs a language model without RoPE. Honor the requested position embedding type in both the language config and model spec, and forward the rotary base, rotary percentage, and sequence-length interpolation factor to `MambaModel`.

Add regression coverage for explicit `none`, default RoPE geometry, and custom RoPE geometry, and supply the rotary arguments in the existing context-parallel test fixture. This ports the fix from NVIDIA-NeMo/nv-mistralai-megatron#784 to current Megatron main.
