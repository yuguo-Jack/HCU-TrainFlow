# [Dev] Add output gating to absorbed MLA

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8006) · state: closed · merged: True

## Original PR description

## Summary

Enable `attention_output_gate` in absorbed MLA, including the default DSA path, with headwise and elementwise gates applied before the output projection.

Main counterpart: #8008.

## Changes

- Add gate projections to the GPT and hybrid DSA specifications, including gate gradients during recomputation and deferred weight-gradient execution.
- Share FP32 sigmoid output gating across Attention, MLA, and KDA while preserving each caller's casting and compilation policies. Unify headwise layout handling while retaining numerical compatibility with scalar attention.
- Add independent numerical and distributed regressions for packed sequences, TP/SP/CP, selective recomputation, deferred gradients, disabled gating, and checkpoint shard metadata.
- Skip the optional cuDNN parity case when CUDA, SM90+ hardware, or its kernel dependencies are unavailable; supported environments still exercise the real fused path.
- Update existing DSA module-spec and disabled-gate test fixtures to cover the added gate projection while retaining context-parallel restoration and recomputation checks.
- Isolate compiled gate parity cases from shared compiler state and require both the actual and independent reference paths to compile, retaining bit-exact output and gradient checks.

### What was checked and found sound

**Shared gate helper** ([attention_output_gate.py](https://github.com/NVIDIA/Megatron-LM/blob/8de13004f3f9dc6cc0ed7ec7170f8e423c2c1388/megatron/core/transformer/attention_output_gate.py)). Every caller keeps its previous precision and compile behaviour:
- **Attention, scalar per-head gate:** still eager, still casts the scale to the input dtype before multiplying.
- **Attention `_apply_output_gate`:** still compiled with `jit_fuser`, still multiplies by the FP32 scale and casts afterwards.
- **MLA per-head gate:** still compiled, casts before multiplying.
- **MLA per-element gate:** still eager, casts before multiplying.
- **KDA:** compiled, leaves the product in its natural dtype, and the caller applies the final `.to(x_dtype)`.
- Shape checks match what the old inline MLA checks enforced.

**Absorbed MLA / DSA gate** ([absorbed_mla.py](https://github.com/NVIDIA/Megatron-LM/blob/8de13004f3f9dc6cc0ed7ec7170f8e423c2c1388/megatron/core/transformer/experimental_attention_variant/absorbed_mla.py)):
- **Gate input:** the post-LayerNorm `hidden_states`. The spec sets `fuse_input_layernorm: False`, and gating combined with `mla_down_proj_fusion` is already rejected in the config.
- **Projection:** a column-parallel linear produces the TP-local head slice and gathers the sequence-parallel input, which matches the existing assert `core_attn_out.shape[0] == hidden_states.shape[0]*TP`.
- **Placement:** applied after the V up-projection and the recompute discard, before `linear_proj`.
- **Deferred weight gradients:** included in `backward_dw`, which the EP-overlap scheduler reaches through `layer.self_attention.backward_dw`.
- **LayerNorm recompute:** included in `set_for_recompute_input_layernorm`.

**Checkpoints:** the key `linear_gate.weight` and its row sharding are the same in the training `AbsorbedMLASelfAttention` spec and the inference `MLASelfAttention` DSA spec in [hybrid_layer_specs.py](https://github.com/NVIDIA/Megatron-LM/blob/8de13004f3f9dc6cc0ed7ec7170f8e423c2c1388/megatron/core/models/hybrid/hybrid_layer_specs.py#L163-L317).

**Unused-identifier check (mandatory):** the new `linear_gate` field, `gate_projection_size`, and the helper's `granularity` and `cast_mode` arguments all have real uses at runtime.
