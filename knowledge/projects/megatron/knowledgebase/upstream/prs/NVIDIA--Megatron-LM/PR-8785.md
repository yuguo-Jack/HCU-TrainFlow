# Make all `HybridStackSubmodules` specs optional

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8785) · state: open · merged: False

## Original PR description

- [X] I, the PR author, have personally reviewed every line of this PR.

The submodules for `HybridStack` construction are now queried at runtime when trying to access each of them individually, so we don't _need_ to ensure they're passed as arguments for all the provided specs in `hybrid_layer_specs.py`.

Also clean up some of the outdated neighboring type hints while we're at it.

Two changes are needed: preserve the existing missing-spec exception contract, and add coverage for the newly nullable ordinary recipes. Static review only; tests were not executed.

### 1. Preserve `ValueError` for missing selected specs

**Failure:** The [new shared guard](https://github.com/NVIDIA/Megatron-LM/blob/1ad87cb4fd279a2d9f461d8cb184d477ee9433a8/megatron/core/models/hybrid/hybrid_block.py#L433-L439) raises `AssertionError` where the replaced branches raised `ValueError`. Selecting CSA with `HybridStackSubmodules()` is one concrete trigger. Both parameterizations of the unchanged [CSA regression test](https://github.com/NVIDIA/Megatron-LM/blob/1ad87cb4fd279a2d9f461d8cb184d477ee9433a8/tests/unit_tests/ssm/test_hybrid_block.py#L550-L558) therefore receive the wrong exception. The existing [missing-GDN2 test](https://github.com/NVIDIA/Megatron-LM/blob/1ad87cb4fd279a2d9f461d8cb184d477ee9433a8/tests/unit_tests/ssm/test_hybrid_block.py#L1434-L1441) and [missing-fused-MLA test](https://github.com/NVIDIA/Megatron-LM/blob/1ad87cb4fd279a2d9f461d8cb184d477ee9433a8/tests/unit_tests/models/test_hybrid_model.py#L1358-L1365) likewise explicitly require `ValueError`.

**Correction:** In `_assert_submodule_configured`, replace the assertion with this explicit configuration check:

```python
        if getattr(submodules, attr_name, None) is None:
            raise ValueError(
                f"Tried to build a `{attr_name}` for `{self.__class__.__name__}`, but the "
                f"`{submodules.__class__.__name__}` doesn't have a `{attr_name}` spec configured."
            )
```

The CSA test also matches the old diagnostic. If retaining the new, field-specific message, replace its `pytest.raises` line with:

```python
    missing_spec_name = "csa_qk_layernorm_layer" if qk_layernorm else "csa_layer"
    with pytest.raises(ValueError, match=missing_spec_name):
```

**Preservation and acceptance:** Reject only the selected missing recipe: `csa_layer` without QK normalization, `csa_qk_layernorm_layer` with it, `mla_layer` for ordinary MLA, `mla_fused_down_proj_layer` for fused MLA, `gdn_layer` for ordinary GDN, and `gdn2_layer` for GDN2. For each pair, configuring only the selected recipe must succeed; configuring only its alternative must raise `ValueError` naming the missing field. Retain the CSA test's `[expected_spec] * 3` selection and global layer numbers `8/9/10`, the GDN2 test's `GatedDeltaNet2`/`SelfAttention` assertions, and the MLA tests' fused-versus-unfused type assertions and successful no-MLA case. These are proposed checks, not executed results.

### 2. Cover omission versus an explicit no-op recipe

**Coverage gap:** The [eight ordinary defaults changed from `IdentityOp` to `None`](https://github.com/NVIDIA/Megatron-LM/blob/1ad87cb4fd279a2d9f461d8cb184d477ee9433a8/megatron/core/models/hybrid/hybrid_block.py#L78-L89), but no tests accompany that behavior change. The existing [routing test](https://github.com/NVIDIA/Megatron-LM/blob/1ad87cb4fd279a2d9f461d8cb184d477ee9433a8/tests/unit_tests/ssm/test_hybrid_block.py#L77-L138) supplies the populated standard stack, so it cannot establish missing-selected rejection or distinguish omission from an explicitly configured no-op. This is a testing gap, not a separate claimed runtime failure.

**Correction:** Add targeted parameterized coverage in that test file. The following proposed test uses its existing imports/helpers plus `from megatron.core.transformer.identity_op import IdentityOp`:

```python
@pytest.mark.parametrize(
    "symbol,spec_name",
    [
        (Symbols.MAMBA, "mamba_layer"),
        (Symbols.GDN, "gdn_layer"),
        (Symbols.KDA, "kda_layer"),
        (Symbols.ATTENTION, "attention_layer"),
        (Symbols.DS_ATTENTION, "dsa_layer"),
        (Symbols.MLA, "mla_layer"),
        (Symbols.MLP, "mlp_layer"),
        (Symbols.MOE, "moe_layer"),
    ],
)
@pytest.mark.parametrize("recipe", [None, IdentityOp, ModuleSpec(IdentityOp)])
def test_optional_ordinary_layer_specs(monkeypatch, symbol, spec_name, recipe):
    config = MLATransformerConfig(num_layers=1, hidden_size=64, num_attention_heads=4)
    submodules = HybridStackSubmodules(**({spec_name: recipe} if recipe is not None else {}))

    def make_stack():
        return HybridStack(
            config=config,
            submodules=submodules,
            layer_config_list=validate_segment_layers(symbol, config),
            pre_process=False,
            post_layer_norm=False,
            post_process=False,
            pg_collection=_make_pg_collection(),
        )

    if recipe is None:
        def unexpected_build(*args, **kwargs):
            pytest.fail("A missing selected recipe reached build_module")

        monkeypatch.setattr(hybrid_block_module, "build_module", unexpected_build)
        with pytest.raises(ValueError, match=spec_name):
            make_stack()
    else:
        block = make_stack()
        assert len(block.layers) == 1
        assert isinstance(block.layers[0], IdentityOp)
```

**Preservation and acceptance:** Each omitted selected recipe must fail before construction with the intended configuration exception and field name. Both a bare class and `ModuleSpec` must remain accepted when explicitly supplied, while every unrelated recipe remains `None`. Retain the existing routing test's matching-spec, exact per-layer-config-object, and layer-number assertions. The suggested code has been traced against the constructor and `build_module` contracts, but the author must verify both proposed changes before adoption.
