# MInf: Allow forward pass to write directly into buffer

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?
Currently, the forward pass of a model writes into a new buffer and returns it. It is not possible for the forward pass to write into a pre-established buffer.

This PR fixes that by using the pre-existing `out=` argument that allows for this functionality.

Stacked on top of #8236.
