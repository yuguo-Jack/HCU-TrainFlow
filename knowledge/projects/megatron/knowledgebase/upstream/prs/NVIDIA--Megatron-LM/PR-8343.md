# What does this PR do?

Crop each MiMo Whisper row to its real mel length before the encoder layers, so the padded tail is not in the convolution or the attention. Fixes #8324.

## Notes

`HFWhisperEncoderWrapper` still calls `WhisperEncoder.forward` only when both lengths are missing, and that path still requires 3000 frames. With `feature_lengths`, each row is cropped to that mel length and run through conv1, GELU, conv2, GELU, positions, the real encoder layers, and layer norm. `seq_lengths` without `feature_lengths` raises, because `2 * seq_lengths` is not invertible.

`capped_whisper_lengths` caps mel at 3000. Sample counts 1, 160, 159, 161, 16000, and 479999 keep today's token count. 480000 and 480001 samples become mel 3000 and 1500 tokens. `calculate_num_mel_frames` is unchanged. `modeling_whisper.py` is not vendored. `tests/unit_tests/models/mimo/test_mimo_audio_submodules.py` is not retargeted.

`--finetune-whisper-encoder` and `--all-audio-clips` are `store_true`, default off, and registered only in `examples/mimo/train.py` `add_mimo_args`. They are not in `megatron/training/arguments.py` or `run_avlm_train.sh`. `--freeze-vit` is untouched. The finetune flag is read in the early `get_args()` try and passed into the encoder constructor. The HF wrapper does not import `parallel_state` and does not use column or row parallel linears. When finetune is on and the TP group is larger than 1, each trainable Whisper parameter gets a SUM all-reduce divided by that group's world size.

`--all-audio-clips` keeps every file in `audios` order and expands `<audio>` with one split. `str.replace` is not used for that expansion.

AI assistance was used (Grok). This is a first-cut draft. `tests/unit_tests/models/mimo/test_hf_whisper_encoder_crop.py` was run here with pytest `--noconftest`: 13 passed. The run loaded the touched modules without importing `megatron.core`, because this machine's torch build cannot import it (Python 3.13 Dynamo, no Transformer Engine). No training job was run. `tools/autoformat.sh` was not run. Black 26.3.0 and isort were applied to the new test file only.
