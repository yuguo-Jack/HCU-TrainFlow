# [FSDP] Preflight uneven DTensor checkpoint metadata

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6573) · state: closed · merged: False

## Original PR description

**Incremental review:** [Files changed](https://github.com/NVIDIA/Megatron-LM/pull/6573/files) against `dev`.

## Summary

- add a rank-invariant metadata contract before uneven-DTensor checkpoint collectives
- validate the raw state-dict key/metadata manifest before SWiGLU/GDN preprocessing can enter divergent per-tensor collectives
- batch manifest and shard-composition validation per `DeviceMesh`, while replacing Python object shape exchange with fixed-size tensor collectives
- raise the same actionable `CheckpointingException` on all participating ranks when metadata or shard composition differs

Related to #4910.

This change addresses the watchdog-hang failure mode and makes the underlying mismatch observable. It does not manufacture missing optimizer entries or claim to fix the root cause of rank-local optimizer-state asymmetry.

## Validation

On 2 x NVIDIA A100-PCIE-40GB:

- `torchrun --standalone --nproc-per-node=2 -m pytest -q tests/unit_tests/distributed/mfsdp_v1/test_mfsdp_uneven_dtensor.py`
  - 22 passed, 6 skipped on each rank (the skipped cases require a larger 2-D mesh)
- real uneven-DTensor PyTorch DCP save/load round trip passed
- tiny Megatron FSDP model-only checkpoint E2E passed: train -> save -> load/resume -> train -> save
- negative optimizer-checkpoint E2E reproduced a raw manifest mismatch (35 keys on rank 0, 31 on rank 1) and both ranks failed fast with the same preflight error instead of hanging
- Ruff, isort check-only, `py_compile`, and `git diff --check` passed

The full CPU-offload optimizer-save path is still blocked earlier by PyTorch's DTensor `.pin_memory()` NYI in `HybridDeviceOptimizer`; the negative E2E therefore targets the checkpoint preflight boundary directly.

## Performance

Preprocessing microbenchmark: two ranks, uneven sharded DTensors, 5 warmups and 50 timed rounds, reporting the median max-rank wall time.

| DTensors | Baseline | This PR | Improvement |
|---:|---:|---:|---:|
| 37 | 22.80 ms | 12.72 ms | 44.2% |
| 41 | 26.38 ms | 14.07 ms | 46.7% |
| 64 | 41.93 ms | 21.67 ms | 48.3% |

Interleaved real Megatron model-only checkpoint A/B on the same two GPUs:

| Operation | Baseline | This PR | Improvement |
|---|---:|---:|---:|
| First save | 546.26 ms | 375.13 ms | 31.3% |
| Warm second save | 156.72 ms | 78.72 ms | 49.8% |

Load time was essentially unchanged/noisy (381.85 ms baseline vs. 391.70 ms here), so no load-speedup claim is made.
