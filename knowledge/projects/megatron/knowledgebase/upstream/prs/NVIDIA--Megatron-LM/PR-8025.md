# Scatter LLaVA's language-model input over the model's TP group

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8025) · state: closed · merged: False

## Original PR description

**Why.** With sequence parallelism, `LLaVAModel._process_embedding_token_parallel` split the combined text and image embeddings with `scatter_to_sequence_parallel_region` and no group, which means the global TP group. The language model it feeds is built on `self.pg_collection.tp`. A LLaVA model given a collection that differs from the global grid kept the wrong sequence chunk on each rank, and the backward all-gather collected gradients from the wrong ranks.

**What.** Pass `self.pg_collection.tp` to the scatter.

**Tests.** The new `tests/unit_tests/models/test_llava_process_groups.py` gives the model its own TP=2 groups while the global grid has TP=1, and makes the global TP accessors raise. It checks the chunk each rank keeps and the gradient gathered in backward. Before the sync with main 77391e71cc, the test failed on main and passed here on 4 GPUs, and `test_llava_model.py` and `test_llava_training.py` gave the same results as on main. In the integration run on 4 GPUs, the new test passes (1 passed); main does not have this file.

**Compatibility.** No change on the standard grid, where `self.pg_collection.tp` is the global TP group.

The branch was synced with main 77391e71cc on 2026-11-01 by a merge commit with no conflicts, so existing commits and review links stay valid.
