# Remove a `fork` used to delete old checkpoints

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8166) · state: closed · merged: True

## Original PR description

Removes a `fork` that was used to delete old checkpoints when `save_retain_interval` is set. Instead, the code uses `threading.Thread`, which should release the GIL between every file delete operation. Also cleans up code that is now dead with this change.
