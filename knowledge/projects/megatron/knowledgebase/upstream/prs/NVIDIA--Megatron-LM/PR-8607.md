# [MFSDP] Clarify scheduling and execution-order test coverage

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8607) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Rename `test_annotation.py` to `test_schedule.py` and update its module description to reflect FSDP execution scheduling and lifecycle ordering observed through NVTX ranges. Its six tests and helpers are unchanged.

Keep `test_execution_order.py` focused on the `ExecutionOrder` class. Replace the test that called `FsdpModule._prefetch_parameter_groups` and mocked its private unshard method with `test_lookahead_tracks_repeated_module_calls`. It uses real `nn.Module` objects and public `advance()` / `next_item()` methods to check repeated-call successors, non-consuming lookahead, sequence boundaries, and cursor reset across two cycles.
