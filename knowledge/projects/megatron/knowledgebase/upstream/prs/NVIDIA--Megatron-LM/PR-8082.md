# Wait when the CI resource queue reaches its concurrency limit

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8082) · state: closed · merged: False

## Original PR description

The resource gate admitted a new pipeline when older pending/running pipelines already occupied every slot: its count comparison allowed one job beyond the configured concurrency. Treat a full queue as busy.

Validation: actual ci_is_busy unit test checks empty, below-limit, exactly-full, and over-limit queues; exactly-full fails on baseline and all four cases pass with the fix. CPU-only API fixtures; Ruff, Black and isort pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
