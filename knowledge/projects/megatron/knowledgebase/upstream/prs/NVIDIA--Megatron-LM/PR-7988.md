# Reuse MoE communication setup across grouped tensor tests

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7988) · state: closed · merged: False

## Original PR description

## What does this PR do?

Reuse the common distributed topology and HybridEP communication buffer across grouped-tensor MoE test cases. In [this H100 run](https://github.com/NVIDIA/Megatron-LM/actions/runs/37801915793/job/113414234385), six HybridEP parity cases took about 449 seconds in total while repeatedly constructing the same communication resources.

A class-scoped fixture now owns those resources. Each case still constructs and seeds fresh models, restores its environment and experimental flag, drains outstanding communication, and releases its NCCL-EP context. The finalizer releases HybridEP before destroying process groups. All 28 node IDs, parameter layouts, numerical assertions, and skip conditions remain intact.

The fixture initializes for any selected case, including a single parameter selected by Testmon; no earlier test or warm-up is required. This PR is independent of the other unit-test runtime changes.
