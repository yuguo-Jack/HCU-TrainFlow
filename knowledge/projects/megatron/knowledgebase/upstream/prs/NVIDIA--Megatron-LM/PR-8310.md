# What does this PR do?

Temporarily quarantine `TestGatedDeltaNet.test_gpu_forward_thd_correctness` in development CI with `flaky_in_dev`. GDN2 THD stalls have repeatedly exhausted merge-queue jobs, including [#8230](https://github.com/NVIDIA/Megatron-LM/actions/runs/39008208275/job/117325569822) and [#7727](https://github.com/NVIDIA/Megatron-LM/actions/runs/39017331762/job/117352664823) on October 17.

Both jobs stalled in `[2-False-2-gdn2]` (TP2, CP2, SP disabled). Per-rank artifacts capture outstanding Inductor compilation waits, including backward compilation, while peers time out in NCCL all-to-all/all-reduce. Automatic retries then reach the one-hour job limit. The TP1/CP1 variant has also stalled repeatedly, as recorded in #7742 and [#8222's queue job](https://github.com/NVIDIA/Megatron-LM/actions/runs/38851923390/job/116815779445).

A GDN2-specific override delegates to the shared test body and adds the marker without marking the shared GDN method. This quarantines the method's six parameterizations as a family; it does not assert that every parameterization independently failed. Two SP parameterizations already skip inside the test body. The other 48 GDN2 module cases remain selected in dev, and the THD cases retain LTS eligibility. Assertions, tolerances, fixtures, and production code are unchanged.

The existing quarantine from #8148 applies to `test_parallel_gated_delta_net2_correctness`; it does not cover this separate THD module method.

## Validation

- Ran actual pytest collection through `torch.distributed.run` before and after the change across GDN, GDN2, and standalone GDN2 parallel buckets. All **205 node IDs** remain present; exactly the six GDN2 THD cases gain `flaky_in_dev`, with every other effective marker unchanged.
- With the dev CI marker expression, GDN remains **139 selected**, GDN2 changes **54 → 48 selected**, and standalone GDN2 parallel remains deselected. The LTS marker expression still selects all **205 cases**, including all 60 in the GDN2 module bucket.
- Collection validation only: no GPU test bodies or LTS-container execution were run. The override relocates the six THD cases within unfiltered/LTS collection order; other cases retain their relative order.
- Black, isort, Ruff, mypy, and `git diff --check` passed. `tools/autoformat.sh` encountered the existing unsupported Pylint `bad-builtins` option; the remaining checks were run separately, and Pylint exited successfully with only that obsolete option removed from a temporary config.

## Issue tracking

Related to #7742; keep the issue open. This is temporary CI containment. Remove the marker after the compiler stall is fixed and the affected THD layouts pass repeated cold-cache and warm-cache runs on the development image without retries or watchdog timeouts.
