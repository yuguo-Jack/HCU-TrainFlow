# What does this PR do?

Adds an overridable hook, `DSv4HybridAttention._post_o_group_proj(attn_out, q_compressed)`, between the grouped output projection (wo_a, `linear_o_group_proj`) and `linear_proj` (wo_b). By default it returns `attn_out` unchanged, so the forward pass, the backward pass and the state dict are bitwise unchanged.

Why: Some DSv4-style models transform the grouped output projection result before wo_b, for example with an output gate computed from the q latent: `out = wo_b(gate(wo_a(core_out), q_latent))`. Today that requires copying all of `forward()`; with this hook, a subclass overrides one method.

- `attn_out`: the wo_a output, `[s, b, output_projection_groups * output_projection_lora_rank]`, or `[t, 1, ...]` for packed THD.
- `q_compressed`: the `q_layernorm` output, reshaped to the leading dims of `attn_out`.
- The return value becomes the `linear_proj` input. The docstring states the override contract:
  - Keep the shape and dtype of `attn_out`.
  - Do not save the returned tensor, or one that shares its storage, for backward; the `attn_proj` offload group force-releases it.
  - Override `backward_dw` if the override builds TE linears under `delay_wgrad_compute`.
- No new config or spec fields. The name avoids the inherited `Attention._apply_output_gate`, which takes gate logits.

A main twin can follow as a separate PR; the method and its call site apply unchanged there.

## Tests

- GPU, one GB300 (sm_103, TE 2.16), `test_dsv4_hybrid_attention.py`: 56 passed at this commit and 50 passed at the base (7b66fcc08), no failures or skips. The new tests check that:
  - the default is the identity;
  - for SBHD and packed THD input, an override gets the wo_a output and the `q_layernorm` output, still in the autograd graph, and its return value is the input of the `attn_proj` offload group and of `linear_proj`;

  - without an override, the output equals `linear_proj` applied to the wo_a output, bitwise; with a learnable sigmoid gate, the gate gets the output of a real `q_layernorm`, and gradients reach the gate, `linear_o_group_proj`, `linear_q_down_proj` and `linear_proj`.
