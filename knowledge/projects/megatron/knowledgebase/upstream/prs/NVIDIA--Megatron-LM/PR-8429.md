# What does this PR do?
Fix MoonEP full-iteration CUDA graph capture after one warmup, including repeated MTP layers.

- Prepare invalidated forward pointer tables from warmed GTP storage before capture, without advancing prefetch or issuing an all-gather.
- Run warmup on the capture stream so retained MoonEP/TE autograd state does not introduce a backward dependency on an uncaptured stream.

Main already contains the separate FC1/FC2 chains and GTP scratch-lifetime fixes (#8345, #7780, #8503). This PR adds no ring-reset mechanism.

The integration test compares eager loss and every parameter gradient with BF16/MXFP8 graph replays, with and without repeated MTP. It exercises virtual-expert transfers, shared persistent-ring slots, changing inputs, reset, and recapture. HSM is disabled for this fixed-input comparison; it does not test optimizer updates or convergence.
