[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8087) · state: closed · merged: False

## Original PR description

After two or more missed scheduled rotations, the manager removes only one expired shift and assigns another expired oncall user. Remove expired shifts until reaching the current shift before updating the active team.

Validation: actual rotation helper regression reproduces three expired shifts before a current one. It fails on baseline and passes after the fix; external GitHub/Slack operations are mocked. CPU test formatting and Python compilation pass. No live team mutations or GPU training were performed.
