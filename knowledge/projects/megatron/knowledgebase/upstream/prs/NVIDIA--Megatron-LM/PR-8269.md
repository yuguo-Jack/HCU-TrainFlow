## What does this PR do?

The PR template currently does not ask authors to declare code provenance. Add a choice between independent development and documented external code, with source URLs/revisions, affected files, applicable licenses, required attribution, and an author acknowledgment.

Add an explicit `AGENTS.md` instruction prohibiting copying or adapting code from other repositories and requiring provenance review before opening a PR.
