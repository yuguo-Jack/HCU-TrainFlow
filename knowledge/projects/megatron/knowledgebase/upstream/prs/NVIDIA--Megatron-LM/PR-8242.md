# fix(batch-invariant): full-reduction mean returned the sum

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8242) · state: closed · merged: True

## Original PR description

Under batch-invariant mode, `x.mean()` / `torch.mean(x)` reach `mean_batch_invariant` with an empty dim list and return the sum (and `dim=None` raises).
Treat an empty or None dim as all dimensions, as `aten::mean` does; adds a unit test.
