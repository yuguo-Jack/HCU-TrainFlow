# Add a PEFT pre-wrap hook to training model setup

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7529) · state: open · merged: False

## Original PR description

## What does this PR do?

Add an optional config-driven PEFT hook to training model setup. Configured adapters are applied to model chunks before distributed wrapping and optimizer construction. The hook preserves user-owned hooks and places requested freeze hooks after adapter insertion. Config export rejects PEFT objects whose constructor state cannot be serialized.

## Issue tracking

Related to #7269. This PR provides the training integration seam; the migrated performant LoRA, canonical LoRA, and DoRA components are tracked by #7271, so it does not close #7269.
