# What does this PR do?

Separate MFSDP v2 module backward completion (`post_backward`) from parameter gradient completion (`post_accumulate_grad`). Shared invocations can release full weights before their shared gradients finish accumulating.

`post_backward` handles weight release and the module phase. A full-backward hook triggers it when input gradients arrive; otherwise the context runs it at autograd completion. The deferred-callback infrastructure, frozen-weight fix, scheduler callback registration, and frozen-weight regression are inherited from #8113. `post_accumulate_grad` packs and reduces gradients immediately when the existing parameter countdown or TE completion hooks report readiness. There is no pending-reduction flag or required ordering between the two callbacks. The combined-1F1B scheduler uses the gradient-completion registration too.

`post_backward()` uniformly frees full weight storage while retaining parameter bindings. `context.finish_grad_sync()` restores sharded bindings for every group, including frozen parameters. This keeps full-shaped bindings available for TE's delayed `.grad` assignment without a TE-specific branch or additional state. `post_accumulate_grad()` only packs and reduces gradients. Delayed wgrad without `caller_managed_grad_sync=True` is now rejected during hook registration.

Stacked on #8113 (`50e361943`), with GitHub base/diffbase `pull-request/8113`; #7854 has merged. The [prepared graph-counting follow-up](https://github.com/wujingyue/Megatron-LM/compare/90cf9109bf4a4eb494e9543fe2a65ff05be83f04...08c7c99f4b417af88d5d31d1333a0f0f5accfc2b) uses this separation and reduces zero-count units after backward setup. #7815's head/base remain unchanged until this draft has a `pull-request/7902` mirror.

Operation names distinguish parameter bindings from storage at both module and parameter-group levels:

- `unshard()`: materialize full weights and bind full parameters.
- `reshard()`: bind sharded parameters and release full weight storage (module-level composition).
- `bind_sharded_parameters()` / `bind_unsharded_parameters()`: change parameter references only.
- `release_unsharded_storage()`: free full storage without changing bindings.
- `reduce_gradients()`: reduce packed gradients at the parameter-group level. The module's `post_accumulate_grad()` lifecycle callback orchestrates packing and reduction.

The terminology cleanup passes formatting/lint and a syntax-tree equivalence check after normalizing renames and helper extraction; no training behavior changed or GPU tests were rerun for it.

The memory measurement above is a small synthetic probe. Functional proxy measurements are below. Backward prefetch still uses static module order. Invocation-aware prefetch and shared reentrant checkpointing are outside this change.

**Known limitation:** PyTorch full backward hooks track positional tensor inputs only. MCore TransformerLayer calls pass `hidden_states` by keyword, so these units currently retain their full weights until the final callback even when their hidden states require gradients. This can increase full-model peak memory substantially; the positional-input memory probe above does not measure that effect. The shared-invocation guard remains necessary for repeated-layer MTP under this behavior.
