# ci: Mark flaky dynamic inference functional tests as broken

# What does this PR do?

Marks six flaky dynamic inference functional tests as broken by moving each recipe entry to the `-broken` variant of its existing scopes. The entries are kept, so each test can be re-enabled by dropping the suffix.

| Test | Platform | Scope |
|---|---|---|
| `gpt_dynamic_inference_tp1_pp1_583m_cuda_graphs_fp8_logitsmatch` | H100 | `[mr]` → `[mr-broken]` |
| `gpt_dynamic_inference_tp2_pp2_ep2_gptoss_20b_swa` | H100, GB200 | `[mr]` → `[mr-broken]` |
| `gpt_dynamic_inference_tp4_etp1_pp1_ep8_16B_routing_replay_async_sched` | H100 | `[mr]` → `[mr-broken]` |
| `gpt_dynamic_inference_tp4_etp1_pp1_ep8_16B_routing_replay_prefix_cache_cudagraph_async_sched` | H100 | `[mr]` → `[mr-broken]` |
| `gpt_dynamic_inference_tp4_pp1_ep4_16B_inference_optimized_swiglu_logitsmatch` | H100 | `[mr, mr-github-broken]` → `[mr-broken, mr-github-broken]` |
| `gpt_dynamic_inference_tp4_pp1_ep4_16B_inference_optimized_swiglu_logitsmatch` | GB200 | `[mr, mr-github]` → `[mr-broken, mr-github-broken]` |
| `hybrid_gdp_dynamic_inference_tp1_pp1_dp8_800m` | H100 | `[mr, mr-github]` → `[mr-broken, mr-github-broken]` |

Verified with `recipe_parser.load_workloads` before and after the change (`environment=dev`, every cadence, H100/GB200/GB300). These six tests drop out of the GitLab `mr` selection and the GitHub `mr-github` (`L1`) selection. No other test is added to or removed from any scope.
