# fix(pipeline): AUT-2700 preserve schedule input storage across streams

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8823) · state: closed · merged: True

## Original PR description

## Background

`ScheduleNode` records input storage on its consumer stream only when `free_input=True`. Retained inputs can lose their final reference during asynchronous backward, allowing producer-stream allocations to overwrite storage still in use.

## What changed

- Record every tensor input on the consumer stream.
- Add a two-stream regression for both `free_input` modes, with allocator pressure and exact gradient assertions.

## Details

This source repair is separate from #8814. It adds no synchronization, weakens no assertions, and changes no CI or dependency inputs.

```mermaid

  A[Producer input] --> B[Record consumer stream]
  B --> C[Forward and backward]
  C --> D[Storage safe to reuse]
```
