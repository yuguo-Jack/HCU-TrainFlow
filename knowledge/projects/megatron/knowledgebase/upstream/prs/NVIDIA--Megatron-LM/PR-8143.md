# Take the MTP acceptance argmax from TE's cross entropy

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8143) · state: closed · merged: True

## Original PR description

In training, MTP's acceptance-rate metric finds the argmax of each MTP head's logits with torch.argmax, or a vocab-parallel max and two all-gathers, right after the loss has scanned the same logits for their maximum. TE's parallel_cross_entropy can return that argmax (return_argmax=True).

te_parallel_cross_entropy and te_cross_entropy take return_argmax and return (loss, argmax), with None when TE lacks the option. LanguageModule.compute_language_model_loss takes return_argmax and passes it on when the selected cross entropy accepts it. process_mtp_loss asks for the argmax in training when the loss callable takes return_argmax, and _compute_mtp_acceptance_counts uses it, computing the argmax as before when it is None. The counts are unchanged: TE's index is the first maximum over the full vocabulary, as with torch.argmax.
