# ci: Fail linting on training imports from Megatron Core

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7903) · state: closed · merged: True

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Fail the existing linting job when a Python file under `megatron/core` imports `megatron.training` or one of its submodules. Run Ruff's `TID251` rule over the entire core tree after installing the existing linting tools, emitting GitHub file/line annotations. Declare the `megatron` namespace package so relative imports are also checked, and ignore `noqa` suppressions for this check.

This adds no dependencies and leaves the existing formatting checks unchanged. Runtime imports through `importlib` are outside this static check's coverage.

## Existing violations

**This draft is expected to fail the new lint step until the existing violations are removed.** On the current `main` baseline, Ruff reports four imports in `megatron/core/inference/text_generation_server/dynamic_text_gen_server/vlm_dynamic_inference.py`, lines 23–26: `get_args`, `get_model`, `print_rank_0`, and the checkpoint-loading helpers. This PR adds enforcement only; it does not exempt or refactor those imports.
