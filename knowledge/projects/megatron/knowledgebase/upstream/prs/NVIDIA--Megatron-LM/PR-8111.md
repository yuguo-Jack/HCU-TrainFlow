# What does this PR do?

Latent MoE changes expert input and routed-output scale as latent width changes. Add two independent opt-in projection gains:

- `--moe-latent-projection-scaling`: multiply hidden-to-latent projection output by `sqrt(hidden_size / moe_latent_size)` before expert dispatch.
- `--moe-latent-up-projection-scaling`: independently multiply latent-to-hidden output by the same gain, after optional normalization and projection, before shared expert addition.

Both default to disabled. Apply the gains in the common training/inference preprocessing and postprocessing paths, including projection biases when present. Router inputs, shared-expert outputs, activation definitions, initialization, and checkpoint tensor shapes are unchanged. The options require positive latent width and MoE experts. Reuse the same flags when resuming or serving a checkpoint.

This PR contains projection gains only. Router and expert activation sigmoid-input controls, including the request in [the review comment](https://github.com/NVIDIA/Megatron-LM/pull/8111#issuecomment-6102145239), are in #8360. Both PRs target `main` independently and merge cleanly together.

The README documents initialization dependence and independent down/up/normalization ablations. Up-projection gain is generally unnecessary with latent fan-in-aware initialization. No training-quality improvement or end-to-end variance preservation is assumed.

- iloshchilov · comment · 2026-10-10T21:02:45Z · [source](https://github.com/NVIDIA/Megatron-LM/pull/8111#issuecomment-6102145239)

Could we also add an independent, user-defined sigmoid-input scale, e.g. `--moe-latent-sigmoid-input-scale`, defaulting to `1.0`?

The down-projection gain scales the entire expert input. We also need the ability to adjust only the sigmoid argument:

$$
\sigma(v)\\rightarrow\\sigma(\kappa v).
$$

This would allow tuning sigmoid sensitivity while leaving the multiplicative branches and SiTU’s tanh arguments unchanged. It should be independent of both projection gains and apply only to routed latent experts.

Please update the fused backward as well, including the $\kappa$ chain-rule factor, and check forward/backward agreement with the unfused reference for a non-unit scale.
