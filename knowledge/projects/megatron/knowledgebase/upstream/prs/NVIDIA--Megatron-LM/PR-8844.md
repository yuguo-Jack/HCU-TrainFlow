# Cache `get_start_time_from_progress_log`'s output within a training run

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8844) · state: closed · merged: True

## Original PR description

`get_start_time_from_progress_log` is called multiple times in a training run (every checkpoint in the
`compute_throughputs_and_append_to_progress_log` function), however, it reads and parses the same file every time to find the start time. Cache the result and avoid multiple file reads.
