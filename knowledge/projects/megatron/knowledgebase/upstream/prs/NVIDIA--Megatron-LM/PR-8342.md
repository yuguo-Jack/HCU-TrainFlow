# What does this PR do?

Honor sequence lengths on the vendored NeMo flash-attention path (`attn_impl="fa"`) at tensor-parallel size 1. Unequal lengths are packed with a broadcast mask and passed to flash-attn v2 `flash_attn_varlen_func` (`cu_seqlens` is int32). The packed `(Ttot, d_out)` tensor is projected, then scattered back. Zero-token batches return zeros before either flash kernel. Lengths that are missing or all equal to `T` stay on `flash_attn_func`. The SDPA path, the Transformer Engine path, and RoPE are unchanged. `supports_audio` stays false, and MiMo stays on HF Whisper.

`AudioProjection.forward_packed` still rejects `stack_factor != 1` and checks that packed rows match `sum(lengths)` before the projector. Audio decode names `self.decoders`. `validate_input_modalities` raises `NotImplementedError` for audio prefill. `serialize_multimodal_data` names audio preprocessing before the generic modality error.

`examples/audio/run_nemo_transformer_audio_tp1.py` checks the legacy SDPA conv `output_mask` for two unequal mel lengths. Its flash-attention compare runs only when CUDA and flash-attn are importable, and `main()` runs only under `__main__`.

Drafted with AI assistance (Grok). No GPU run was performed and no timings were measured. `tools/autoformat.sh` was not run: it fetches the NVIDIA autoformatter remote and expects the CI lint container. `black`, `isort`, and `ruff` were run on the touched files only.

Unit tests were added. They were not collected through `megatron.core` on this machine (CPython 3.13, torch 2.5.1 cannot import `megatron.core`). The flash-attention contract file was executed by loading the encoder under a stubbed package (`pytest --noconftest`: 12 passed). The example import guard passed with `pytest --noconftest` (2 passed). Projector, decode, modality-validation, and serialization message checks were run against stub-loaded modules. That is not an official `megatron.core` pytest run.
