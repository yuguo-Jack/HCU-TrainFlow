# What does this PR do?
Parity with modern Gym and NeMo RL.

Megatron RL stops receiving most request-related data from the OpenAI RESTful endpoint. It only receives text. Instead, it reads everything else directly from the engine using a stager.

Unlike NeMo RL, Megatron RL cannot rely on TQ. Instead it uses the pre-existing TQ-like implementation: the inference "ledger".

Rollout banking has to be heavily modified to account for this.
