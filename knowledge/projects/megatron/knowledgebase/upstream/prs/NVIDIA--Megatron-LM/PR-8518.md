# Fix FP16 offline KD tail reconstruction and near-equality gradients

## What does this PR do?

Fix numerical failures in offline logits distillation while retaining exactly K FP16 values and K selected vocabulary indices per token.

For a confident teacher, FP16 normalized log-probabilities can round the largest probability to one, destroying a tail that is later reconstructed with `1 - sum(top_k)`. For example, logits `[0, -30]` have a tail near `9.36e-14`, far below the existing `1e-8` ghost-tail floor. Close student/teacher distributions can also lose the KL gradient to cancellation.

The first commit stores K-1 logits relative to an implicit-zero maximum, using the freed value for a directly reduced tail log-sum-exp (format 3). The loss computes coarse forward KL over the selected tokens plus the aggregate tail, with stable normalization, cancellation-resistant near-equality arithmetic, and an explicit backward that preserves the dominant gradient. Vocabulary workspaces are chunked, and the complete TP-replicated loss is not reduced twice.

The second, separate commit adds optional-to-review per-token adaptation (format 4): round-trip both reference logits and normalized top-K log-probabilities through the cache dtype and select the lower coarse `KL(teacher || decoded_cache)`. A redundant sign bit records the mode without increasing storage. `--logits-save-encoding-metric tail` instead minimizes tail probability error; K=1 retains the fixed reference encoding. The adaptive commit can be dropped independently.

## Compatibility and limits

- Existing format-1/2 caches retain their original reader and loss semantics; format-3 caches remain supported.
- New dumps use format 4 and require the updated reader. Use a fresh cache directory; mixed or unknown formats are rejected.
- Top-P exclusions are folded into the aggregate tail before quantization. TP selection and tail reduction remain collective.
- FP16 still changes the teacher target: exact zero gradient is at the decoded target. The aggregate tail does not recover individual omitted teacher logits.
- Minimizing tail error can increase coarse KL; KL is the default.

Related public foundation: #5482. Numerical motivation: [A Fix for Softmax and Cross-Entropy](https://arxiv.org/abs/2610.31642). The compact cache representation and selector are implemented here.
