# Preserve GDP gate storage under chunkwise context parallelism

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8517) · state: closed · merged: True

## Original PR description

## Background

`gdp_in_proj` recomputation discards the projection outputs after forward, but GDP currently makes a contiguous copy of the output gate before gated RMSNorm. RMSNorm retains this copy for backward, leaving a full gate activation live even when projection recomputation is enabled.

## Summary

- Keep the gate as a view of projection storage at microbatch size 1 with CP1 or chunkwise CP, so the checkpoint also discards and restores the norm's saved gate.
- The CP1 change is cherry-picked from internal repo, authorship is kept.
