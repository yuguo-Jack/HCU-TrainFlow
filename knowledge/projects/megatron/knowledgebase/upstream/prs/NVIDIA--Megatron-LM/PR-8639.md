# Add weighted knowledge distillation loss for MTP training

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8639) · state: open · merged: False

## Original PR description

Add configurable CE and temperature-scaled teacher-to-student KL weights for MTP, with a detached teacher, cached normalizers, vocabulary-parallel reductions, and compiled local kernels. Preserve upstream normalization and integrate masking, context and sequence parallelism, early backward, and KD metrics.

Include numerical and gradient tests, compiled replay coverage, and usage documentation. Validation on four GB200 GPUs: 64 KD cases pass per rank in both compiled and eager modes, plus 4 bit-exact replay cases per rank.
