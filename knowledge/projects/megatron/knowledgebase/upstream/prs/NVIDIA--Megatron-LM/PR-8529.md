# Compute the GDP beta sigmoid in FP32 to preserve gradients

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8529) · state: closed · merged: True

## Original PR description

## Summary

`GatedDeltaProductMixer._compute_gating` computed `beta = b.sigmoid()` in the input dtype. In BF16 the sigmoid rounds to exactly 1 for logits at or above about 6.25, and autograd saves that rounded output for backward, so `sigmoid * (1 - sigmoid)` evaluates to 0 and the beta gradient vanishes for saturated heads.

This PR computes the sigmoid in FP32 and casts the result back to the input dtype (`b.float().sigmoid().to(b.dtype)`). The forward values passed to the GDP kernels are unchanged, while backward uses the unrounded FP32 sigmoid and keeps a nonzero gradient. The fused inference prepare kernels (`gdp_decode_prepare`, `gdp_prefill_prepare`) already compute the sigmoid in FP32 and are not affected.

## Testing

- Added `tests/unit_tests/ssm/test_gdp_beta_sigmoid.py`, which checks for both the CuTeDSL and non-CuTeDSL layouts that the BF16 beta values match a plain BF16 sigmoid bit for bit, and that the gradient matches an FP64 reference within one BF16 rounding unit, including nonzero gradients for logits where the BF16 sigmoid saturates to 1.
