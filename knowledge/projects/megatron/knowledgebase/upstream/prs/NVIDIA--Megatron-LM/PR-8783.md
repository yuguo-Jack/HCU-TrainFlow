# What does this PR do?
Adds Colocate MIMO vision encoder with decoder enabling dynamic CP. Depends on https://github.com/NVIDIA/Megatron-LM/pull/7048 and https://github.com/NVIDIA/Megatron-LM/pull/8680 to be merged and then rebase. 

To test E2E, we need to add Qwen specific logic and use this branch: https://github.com/zhongbozhu/Megatron-LM/commits/codex/mimo-dcp-colocate-e2e/
