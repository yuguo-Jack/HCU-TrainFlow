# Overlap MFSDP v2 outer gradient reduction on a dedicated CUDA stream

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8395) · state: closed · merged: False

## Original PR description

The final microbatch’s DP-outer reduction currently shares the inner reduce-scatter stream. The next parameter group waits on that stream before packing its gradients, so a long outer reduction can stall backward computation.

This PR moves the deferred DP-outer reduction to a dedicated outer_reduce_scatter_stream owned by the FSDP context:

Wait for the producing inner reduction before launching outer communication.
Allow subsequent gradient packing and inner reductions to proceed while outer communication runs.
Join both reduction streams in finish_grad_sync() before consuming the finalized gradients.
Establish the outer-stream dependency at backward entry for CUDA Graph capture.
Keep fused expert-gradient scaling on the stream that finalizes the gradients.
The change preserves the existing reduce_partial_gradients() API, persistent gradient buffers, and all-gather path.

Validation

- Full MFSDP v2 unit suite passed, including CUDA Graph and stream-synchronization coverage.
- The combined optimization stack completed 20 DSv4 Flash HSDP iterations on 128 GB200 GPUs with full-iteration and optimizer CUDA Graphs, with no skipped or NaN iterations.
- Related to #6973, which addresses the same overlap opportunity. This implementation keeps the existing gradient-reduction API and performs the stream switch inside the final-microbatch branch.
