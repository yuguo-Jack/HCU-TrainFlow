# Fix DSv4 fused RoPE autograd aliasing

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7643) · state: open · merged: False

## Original PR description

## Problem

`DSv4HybridSelfAttention` used the in-place fused RoPE wrapper for Q and KV when `apply_rope_fusion=True`. The attention path aliases the rotated KV tensor as both key and value, so the kernel's direct writes can bypass autograd version tracking and corrupt the training graph. This matches the BF16 iteration-2 NaN failure reported in #5317.

## Fix

Use the existing `fused_mla_rope_out_of_place` wrapper for the Q and KV training inputs. It clones the tensor before invoking the same fused kernel, preserving the fused implementation while isolating tensors retained by autograd and the K/V alias.
