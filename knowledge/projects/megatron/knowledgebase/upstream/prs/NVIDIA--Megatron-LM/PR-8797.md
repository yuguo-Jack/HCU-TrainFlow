# What does this PR do?

Remove redundant `model_type` arguments from the training APIs and their callers.

**Depends directly on #8234; independent of #8444.** This cleanup was split out of #8444 to keep the VLM migration focused. Retarget to main before merging or deleting the parent branch.

- Remove enum forwarding through `pretrain()`, model/optimizer setup, model builders, finetuning, and RL setup; update in-tree callers and existing tests together.
- Remove dead legacy-args assignments. Startup telemetry identifies the model through its config class.
- Remove the three unused Core schedule reads of `model_type` and the remaining builder-level assignments, including MIMO and post-training conversion. Schedules no longer require the attribute.
- Preserve legacy enum definitions for checkpoint deserialization; existing concrete model constructors and the public utility remain unchanged.
- Leave conversion CLI model-family selectors and unrelated inference/export enums unchanged. No new config fields.

**API impact:** downstream callers of these training APIs/builders must stop passing `model_type`. Builders no longer add a `model_type` attribute; Core schedules no longer require one.
