# Fix distributed checkpoint keys for split wide residuals

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8605) · state: open · merged: False

## Original PR description

## Problem

#7952 renamed wide-residual modules from `residual_connection*` to `residual_read*` / `residual_write*`. Its `load_state_dict` hooks handle ordinary model dictionaries, but distributed checkpoint loading looks up `ShardedTensor.key` before those hooks run. A checkpoint containing `layers.0.residual_connection_self_attn.read_map.logit` therefore fails when the new model requests `layers.0.residual_read_self_attn.read_map.logit`.

## Fix

Preserve the pre-split external checkpoint names in `WideResidualTransformerLayer.sharded_state_dict()` and `WideResidualMambaLayer.sharded_state_dict()`, using the existing residual compatibility map. Dictionary keys retain the current module hierarchy; only checkpoint metadata keys change. Read maps, write maps, and learned retention are covered. New saves also retain the original external names.

The production change is 32 added lines in two files. There are no changes to residual computation, parameter ownership, FSDP wrapping, or the checkpoint loader. This is independent of #8312 and applies to DDP as well as MFSDP.

## Validation

On two RTX A6000 GPUs, based on `main` at `364eef70a`:

- The existing wide-residual and residual-contract suites passed **73 tests per rank**, with no skips or failures. The production files and these tests are unchanged since that run.
- Repository `tools/autoformat.sh` passed Black, isort, Pylint, Ruff, and Mypy on the unchanged production files.

No new regression test is included. Loading a full historical NT4 checkpoint and optimizer-state resume were not tested.

## Compatibility limit

This restores the original checkpoint namespace. It does not automatically detect or migrate distributed checkpoints written after #7952 using the intervening `residual_read*` / `residual_write*` names; those checkpoints need a key migration. Ordinary model `state_dict` keys and their existing load hooks are unchanged.

## Code provenance

No code copied from external repositories. The mapping uses this repository's existing compatibility prefixes and checkpoint utility.

### Add a regression for distributed checkpoint names

**Coverage gap:** The existing [Transformer checkpoint test](https://github.com/NVIDIA/Megatron-LM/blob/fde642669387c3a93cfb21cb4b15b0841609eea7/tests/unit_tests/transformer/test_wide_residual_connection.py#L885-L927) and [Mamba legacy-load test](https://github.com/NVIDIA/Megatron-LM/blob/fde642669387c3a93cfb21cb4b15b0841609eea7/tests/unit_tests/ssm/test_mamba_residual_state.py#L316-L338) exercise ordinary `state_dict` loading, not `ShardedTensor.key`. Removing either the [Transformer mapping call](https://github.com/NVIDIA/Megatron-LM/blob/fde642669387c3a93cfb21cb4b15b0841609eea7/megatron/core/transformer/wide_residual_layer.py#L435-L441) or the [Mamba mapping call](https://github.com/NVIDIA/Megatron-LM/blob/fde642669387c3a93cfb21cb4b15b0841609eea7/megatron/core/ssm/wide_residual_mamba_layer.py#L89-L95) therefore leaves those assertions unaffected while restoring the historical distributed-checkpoint lookup failure.

**Correction:** Add focused tests calling both actual overrides, using initialized model-parallel groups with teardown. Reuse the Transformer tests’ active attention/MLP construction; Mamba can use its real constructor with `MambaLayerSubmodules()` because no forward execution is needed. Cover retention enabled and disabled. The invariant is that dictionary names remain current while checkpoint metadata uses the legacy namespace.

For each constructed layer, the core proposed assertions are:

```python
prefix = "decoder.layers.0."
sharded = layer.sharded_state_dict(
    prefix=prefix, sharded_offsets=((0, 1, 2),)
)
assert set(sharded) == {prefix + name for name in layer.state_dict()}
# suffixes: ("_self_attn", "_mlp") for Transformer; ("",) for Mamba.
for suffix in suffixes:
    parameters = [("read", "read_map.logit"), ("write", "write_map.logit")]
    if learned_retention:
        parameters.append(("write", "retention.retention_logit"))
    for operation, parameter in parameters:
        current = f"{prefix}residual_{operation}{suffix}.{parameter}"
        legacy = f"{prefix}residual_connection{suffix}.{parameter}"
        assert sharded[current].key == legacy
        assert sharded[current].global_shape == (2, 128)
        assert sharded[current].global_offset == (1, 0)
```

**Preservation and acceptance:** Specify expected names independently of the production compatibility table. Require these assertions to fail on the base implementation and pass with both overrides. Also check that disabled retention produces no retention entries and an unrelated parameter’s metadata name is unchanged. Retain the linked tests’ strict legacy-load tensor-equality checks and add equivalent strict current-state loading checks. These are proposed checks, not executed results.
