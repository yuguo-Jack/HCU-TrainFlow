# [Determinism] Support deterministic fused MoE auxiliary loss

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7697) · state: open · merged: False

## Original PR description

Detect TE's deterministic aux-loss API and propagate explicit or PyTorch global determinism through all three router loss paths. Allow supported fused execution in deterministic mode while preserving legacy TE compatibility and existing flag precedence.

Validate capability and dispatch compatibility, unfused-reference equivalence, and bitwise loss and gradient replay. Focused GB200 tests: 40 passed, with the atomic negative control observing nondeterminism.

TE PR should be merged first: https://github.com/NVIDIA/TransformerEngine/pull/3587

Fixes https://github.com/NVIDIA/Megatron-LM/issues/7221
