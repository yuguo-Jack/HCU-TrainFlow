# Allow FP8/FP4 with AbsorbedMLA up-projection recompute

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6914) · state: open · merged: False

## Original PR description

Mirror of #6178 (dev) onto main.

AbsorbedMLASelfAttention asserted that quantization was unsupported whenever "mla_up_proj" selective recompute was enabled, blocking FP8 and FP4 training for any model that needs that recompute to fit in memory. The assertion was a not-yet-validated placeholder from the initial absorbed-MLA implementation, not a guard for a known failure: the quantized replay is safe for the same reason it is in MLASelfAttention, which runs the identical CheckpointWithoutOutput pattern.

Add test_quantized_up_proj_recompute_parity, which requires bitwise-identical outputs and gradients between a recomputing and a non-recomputing module, with a bf16 reference run guarding against the check passing vacuously. Coverage: tensorwise/mxfp8/blockwise FP8 and nvfp4 FP4 across sbhd/thd layouts.
