# What does this PR do?

Clear GTP's autograd placeholder before invoking its manual DDP readiness callback.

GTP has already accumulated the reduced gradient into `main_grad`. However, when
`zero_out_wgrad=True` (for example, on an MTP embedding), DDP can still add an old
`param.grad` even though `grad_added_to_main_grad=True`. Under CUDA graph capture,
that redundant addition can record the address of a warmup allocation that is
released before replay.

Set `param.grad = None` at the GTP notification boundary. Preserve the
`zero_out_wgrad` convention, the placeholder returned to autograd, capture
bookkeeping, readiness notifications, and generic DDP accumulation behavior.
