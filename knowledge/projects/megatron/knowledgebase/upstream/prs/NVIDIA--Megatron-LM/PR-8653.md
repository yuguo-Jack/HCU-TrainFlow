# ci: Enable non-blocking GB300 tests for GitLab MRs

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8653) · state: closed · merged: True

## Original PR description

Enable the existing GB300 child pipeline for GitLab functional `mr` and `mr-slim` scopes on `dgxgb300_oci-jhb`. Mirror GB200's 23 MR workloads and two mr-slim workloads, retaining workload shapes and using measured GB300 reference goldens. All 69 existing GB300 nightly manifests remain unchanged.

Keep the nightly trigger's `allow_failure: true` and asynchronous behavior, so GB300 child failures do not fail or delay the parent. Existing build/functional-test eligibility is preserved; unit-only MRs remain unchanged.

Add 17 GB300 functional golden files and GB300 baseline entries for all four performance cases. The two existing smoke/rerun cases continue skipping golden comparisons. Existing GB200/H100 baselines are preserved.

Validation: three targeted pipeline tests, golden format/comparison checks, four performance comparisons, and saved checkpoint-resume comparisons pass. Formatting, linting, and type checks pass.

## Code provenance

GB300 recipes adapt existing GB200 recipes from this repository. No code copied from external repositories.
