# What does this PR do?

Reuse the NVRx reader across checkpoint load phases and release transient metadata inside `load_checkpoint`, including on failures. Reader implementation and unit tests have moved to [NVRx #482](https://github.com/NVIDIA/nvidia-resiliency-ext/pull/482).

**Pending dependency adoption:** merge and release NVRx first, then bump Megatron’s pin separately. This PR adds no version checks and leaves the current pin unchanged.
