# fix(fsdp): preserve retention parameter weight decay

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8516) · state: closed · merged: True

- [x] I, the PR author, have personally reviewed every line of this PR.

# What does this PR do?

MFSDP v2 drops `is_wide_residual_retention_parameter` when creating replacement parameters. The optimizer then treats retention vectors as ordinary one-dimensional parameters and disables their weight decay.

Preserve this marker during materialization and sharding so retention vectors keep the same weight-decay policy as the unsharded model. Extend the existing parameter-metadata preservation test.

## Validation

- `test_fully_shard_preserves_parameter_attributes` passed on four CUDA ranks.
- A fixed-gradient FusedAdam reproducer confirms that preserving the marker restores bit-identical updates to the unsharded reference.
- Black, isort, pylint, and Ruff passed. The autoformat script's optional mypy check reported missing local PyTorch, pytest, and Transformer Engine dependencies.
