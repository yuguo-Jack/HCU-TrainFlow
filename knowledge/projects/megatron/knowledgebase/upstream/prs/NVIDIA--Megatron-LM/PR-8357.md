# What does this PR do?

Fix incorrect MXFP8 quantization of non-contiguous input tensors in the Triton backend.

The kernel reads input as `row * K + column`, but the public entry points accept 2D tensors without requiring contiguous storage. Transposes and strided slices therefore produce incorrect quantized values without raising an error.

Normalize the input with `x.contiguous()` in `mxfp8_quantize_into`, the shared entry point used by `mxfp8_quantize` and `MXFP8Tensor.from_bf16(..., backend="triton")`. Contiguous inputs reuse their existing storage; non-contiguous inputs are copied before the kernel reads them. Caller-provided output storage is preserved.

Tests compare every data and scale byte against quantizing the same logical values in contiguous storage. Coverage includes BF16/FP16/FP32, transpose/row-slice/column-slice layouts, contiguous and nonzero-offset controls, allocating and preallocated outputs, and the MXFP8Tensor API. CUDA Graph tests update input contents between replays. The existing determinism test also covers transposed input under side-stream contention.

## Validation

Tested on two H100 80GB GPUs with Python 3.12.10, PyTorch 2.12.1+cu130 and Triton 3.7.1. All post-fix checks were rerun after rebasing to the latest fetched `main`.

- Before the fix: **45 failures and 24 passes per GPU** in the 69 new cases. Failures are confined to non-contiguous inputs.
- After the fix: **140 passed, 4 skipped per GPU**, including all 69 new cases. The skips are existing optional FlashInfer tests; FlashInfer is not installed.
- Bit-exact determinism: **2 passed per GPU**, covering contiguous and transposed large tensors with side-stream contention.
- Compute Sanitizer memcheck: **69 passed, 0 memory errors** on H100.
- Black, isort, Pylint, Ruff, kernel-determinism coverage and `git diff --check` passed. Default mypy reports missing/untyped optional Transformer Engine and Triton imports; with `--ignore-missing-imports`, the three changed files pass.

The targeted tests use `--confcutdir` to exclude unrelated training/data fixtures. These runs exercise real public APIs and GPU kernels; they do not cover the full model/training suite or the NGC CI container.
