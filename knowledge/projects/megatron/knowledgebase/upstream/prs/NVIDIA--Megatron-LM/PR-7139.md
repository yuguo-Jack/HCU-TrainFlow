## What does this PR do?

Clear all cached model-parallel topology state in `destroy_model_parallel()` so that reinitializing Megatron-LM with a different parallel configuration cannot reuse stale rank descriptors or process-group metadata.

This fixes stale topology state across repeated model-parallel initialization and destruction cycles.

### Add regression coverage for partial DP teardown

The added test does not seed or assert either `_INTRA_PARTIAL_DATA_PARALLEL_GROUP_WITH_CP` or its Gloo counterpart. Consequently, after correcting the cache-name typo, removing the new resets at `parallel_state.py:2645–2646` and `2727–2735` would still satisfy its assertions. These are separate cleanup fixes: initialization creates a distinct partial Gloo group with multiple optimizer instances (`1018–1045`), but aliases the full DP/CP Gloo group with one instance (`1046–1048`). The latter must not be destroyed twice.

**Correction:** Add a regression test in `tests/unit_tests/test_parallel_state.py` covering those branches and Gloo-disabled initialization. The invariant is that both partial-group globals become `None`, every live partial Gloo group is deregistered, and aliased or already-destroyed groups are not destroyed again. A proposed test, using the inspected `Utils` initialization/teardown contract, is:

```python
@pytest.mark.parametrize(
    "instances, create_gloo", [(1, True), (2, True), (2, False)]
)
def test_destroy_model_parallel_clears_partial_dp_state(instances, create_gloo):
    if world_size % instances:
        pytest.skip("World size must be divisible by optimizer instances")
    Utils.initialize_model_parallel(
        num_distributed_optimizer_instances=instances,
        create_gloo_process_groups=create_gloo,
    )
    try:
        partial = ps._INTRA_PARTIAL_DATA_PARALLEL_GROUP_WITH_CP_GLOO
        full = ps._DATA_PARALLEL_GROUP_WITH_CP_GLOO
        if create_gloo:
            assert partial is not None
            assert (partial is full) == (instances == 1)
            assert partial in torch.distributed.distributed_c10d._world.pg_map
        else:
            assert partial is None

        Utils.destroy_model_parallel()
        assert ps._INTRA_PARTIAL_DATA_PARALLEL_GROUP_WITH_CP is None
        assert ps._INTRA_PARTIAL_DATA_PARALLEL_GROUP_WITH_CP_GLOO is None
        if partial is not None:
            assert partial not in torch.distributed.distributed_c10d._world.pg_map
        ps.destroy_model_parallel()  # Repeated teardown must remain harmless.
    finally:
        Utils.destroy_model_parallel()
```

**Acceptance/preservation:** On the distributed unit-test runner, all three cases should pass: distinct registered groups are removed, the single-instance alias is removed only once, and disabled Gloo remains `None`. Also check the two-instance case after explicitly destroying the saved partial Gloo group before model-parallel teardown; teardown should still finish and clear both globals. Retain the existing cached-rank and hierarchical-group assertions. This is proposed, unexecuted code; verify it in the repository test environment before adopting it.
