# Skip dataset_id metadata during context-parallel batch partitioning

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/5778) · state: open · merged: False

## Original PR description

# What does this PR do?
<!-- Add a one line overview of what this PR aims to accomplish. -->
This PR fixes an error in context-parallel batch partitioning when the batch
contains sample-level metadata fields such as `dataset_id`.

`BlendedDataset.__getitem__()` adds `dataset_id` to each sample to record which
underlying dataset the sample comes from. After collation, this field becomes a
low-rank tensor with shape `[micro_batch]`

However, `_get_batch_on_this_cp_rank_per_sequence_balancing()` currently assumes
that non-metadata tensor fields are sequence tensors and tries to partition them
along the sequence dimension. This causes an `IndexError` for `dataset_id`
because it does not have a sequence dimension.
