# Use MLA's own TP group for its collectives and checkpoint shards

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8023) · state: closed · merged: False

## Original PR description

**Why.** `MLASelfAttention`, `FusedMLASelfAttention` and `AbsorbedMLASelfAttention` gather their TP-sharded q/kv down projections, and scatter them back to the sequence-parallel layout, with mapping helpers called without a group. Those collectives used the global TP group, while the projections are sharded over the module's `pg_collection.tp`. With `q_lora_rank=None`, `linear_q_proj` was also built without a group. `FusedMLASelfAttention.sharded_state_dict` split its fused down projection into tensors whose offsets and replica ids came from the global TP and DP×CP groups, unlike the rest of the module. On a model with its own grid this gives shape errors or mixed activations, and inconsistent checkpoint metadata.

**What.**
- Pass `self.tp_group` to the ten mapping calls, and `pg_collection.tp` to `linear_q_proj`.
- Build the split down-projection tensors with `self.tp_group` and `metadata['dp_cp_group']`, filled in the same way `MegatronModule.sharded_state_dict` does.

**Tests.** The new `tests/unit_tests/transformer/test_mla_process_groups.py` builds each variant on new communicators that use the global TP=2 layout, while the global TP/DP/CP accessors raise. Outputs, gradients and sharded-state-dict metadata match the module built on the global grid. Before the sync, these tests failed on main and passed here on 4 GPUs. An existing test's fake gather now also checks the group. On the pre-sync branch, `test_absorbed_mla.py` and the SP/TP/FusedMLA classes of `test_multi_latent_attention.py` gave the same results as on main. In the integration run (main with all #6307 PRs merged) against main, all 6 tests in `test_mla_process_groups.py` pass on 4 GPUs; main does not have this file. The integration run's 8-GPU (two-node) job for `test_multi_latent_attention.py` did not finish, so that file has no integration result.

**Compatibility.** On the standard grid the groups are the same as before, and checkpoint keys, offsets and replica ids are unchanged. This PR needs the `determinism-exempt` label: these files register a kernel, but the change only touches process-group plumbing.

Synced with main 77391e71cc on 2026-11-01 by a merge commit with no conflicts, so existing commits and review links stay valid. The merge also adds to the process-group allowlist the reads main added since this PR was written.
