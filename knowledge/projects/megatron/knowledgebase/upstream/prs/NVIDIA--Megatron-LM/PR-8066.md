# Preserve Slack group membership when team identities are unresolved

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8066) · state: closed · merged: False

## Original PR description

When one GitHub team member cannot be resolved to Slack, the sync currently replaces the entire Slack group with only the successfully resolved subset. Abort that sync before group creation or membership updates, preserving the current group for a later retry.

Validation: standalone CPU unittest regressions exercise the actual helper with isolated fixtures and mocked external boundaries. The regression fails on the base commit and passes with this fix. Python compilation and test formatting pass. No live Slack or team mutations were performed. The commit is signed and includes its sign-off.
