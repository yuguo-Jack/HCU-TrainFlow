# What does this PR do?

An empty contiguous slice currently accesses `sequence_pointers[start]`; at or beyond the dataset end that pointer does not exist. Return the correctly shaped empty result before reading data. Multimodal results retain their empty mode array and noncontiguous slices remain rejected.

This is an AI-assisted draft. Human author review and NVIDIA GPU/CI validation are pending.
