# Add packed THD context parallelism for DSv4

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7469) · state: closed · merged: True

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

DSv4 attention currently rejects CP > 1. This adds static context parallelism for packed THD inputs with `attention_cp_layout="contiguous"` and TP=1, covering window attention, ratio-4 CSA, ratio-128 HCA, and MTP. Packed inputs require `dsa_kernel_backend="cudnn"`; the existing SBHD native backend remains available.

- Exchange boundary hidden states, preserve document-relative RoPE, and assign compressed groups to their owning CP ranks. Handle packed padding, empty documents, and groups crossing rank boundaries.
- Connect packed FlashMLA/cuDNN attention and sparse/dense indexer loss, with asynchronous compressed-KV/indexer-K gathers, gradient reduce-scatter overlap, and KV reconstruction for selective recompute.
- Add contiguous MTP token/mask rolls, batch each phase's field exchanges, and return HSM boundary gradients to their original ranks.
- Add CP2/CP4 output and gradient comparisons against per-document native SBHD references, boundary/roll coverage, and kernel determinism registrations.

The implementation uses main's existing packing, process-group, RoPE, and static-spec interfaces. It preserves one dense indexer scoring call per CP-local query shard. Compact BF16/MXFP8 indexers and dynamic CP remain separate follow-ups; dependency versions are unchanged. This PR targets main independently of #6403.

## Related work

Related to #5795 and #6404. Static CP behavior follows the existing dev CSA implementation, adapted to main's interfaces and pinned cuDNN Frontend.

What I checked by reading the source (not by running it):
- **Compressed-group ownership:** each compressed group belongs to the rank that holds its last token. The 8-row halo always contains the ratio-4 overlap predecessor, so `is_first = group_id == 0` is correct.

- **Host syncs:** none were added. The code uses `torch._assert_async`, and its boolean-mask scalar fills dispatch to `masked_fill`.
