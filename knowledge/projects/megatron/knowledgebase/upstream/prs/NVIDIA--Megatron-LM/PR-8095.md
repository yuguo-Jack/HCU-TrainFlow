# Bound uniform routing coverage baselines at all experts

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8095) · state: open · merged: False

## Original PR description

When requested top-N exceeds the configured expert count, the aggregate uniform coverage baseline exceeds 100%, incorrectly reporting uniform routing as under-concentrated. Saturate the baseline at complete coverage.

Validation: real JSONL CLI regression with four uniformly routed experts and N=8 fails on baseline and passes fixed; isort, Black and Ruff pass for the regression. CPU tooling only; no GPU training or inference suite was run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
