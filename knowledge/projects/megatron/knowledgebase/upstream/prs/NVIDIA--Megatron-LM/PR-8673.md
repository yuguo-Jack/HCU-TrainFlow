# [MTP] Detach auxiliary output weights independently

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8673) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Add `TransformerConfig.mtp_detach_output_weight=False` to detach only the output projection weight used by the auxiliary MTP objective. This lets RL integrations keep auxiliary gradients to the backbone and input embeddings without letting that auxiliary objective update the policy output weight. The existing broader `mtp_detach_heads` behavior and default behavior are preserved. The main language-model projection remains trainable.
