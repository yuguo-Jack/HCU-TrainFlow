# Enable TE and full-iteration CUDA graphs for mHC

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7337) · state: open · merged: False

## Original PR description

## What does this PR do?

Enable Transformer Engine and full-iteration CUDA graphs for mHC, and combine selective mHC recompute with attention-only TE graphs (`--mhc-recompute-attn-cuda-graph-split`), including scheduler-packed THD.

Related to #2919. **Stacked on #8361**: merge after it. Until #8361 lands, this PR's diff against main also shows #8361's commits.

### Graph modes for mHC

- **TE graphs for mHC layers.** GPT `HyperConnectionTransformerLayer` and Hybrid mHC wrappers support TE capture, replay and manual hooks. Static inputs keep every residual stream. MoE layers capture the router (optionally preprocessing) and carry residuals and mHC mixing tensors across the graph boundary; expert dispatch and computation stay eager. Nested Hybrid MTP layers are discovered individually.
- **Full-iteration graphs.** Each `StaticBufferLoader` consumer gets its own batch dictionary over the captured storage. Batched P2P skips its device-wide fence only while the stream captures.
- **Attention graph split with selective mHC recompute** (new). With `--mhc-recompute-attn-cuda-graph-split`, each mHC attention sublayer captures only its input layernorm and self-attention. The mHC aggregate before the graph and the mHC bias-dropout-add after it run eagerly with the mHC recompute manager, as does the MLP sublayer. TE copies the aggregate into the graph's static input and keeps that copy for the captured backward, so the aggregate is not checkpointed and no checkpoint output shares memory with the graph. The recompute planner from #7923 and its managers are unchanged. The flag name matches dev.
- **Packed THD through the split** (new). The split takes #8361's fixed-capacity sequence offsets; the eager mHC operations and MLP receive the batch's packed metadata. #8361's replay-side decomposition is lifted into `TransformerLayer._decompose_packed_graph_inputs`, next to `_reconstruct_packed_graph_inputs`, so the split and the default path share it.

### Fixes found along the way

- **Checkpoint rebuilds under graph-safe RNG trackers** (affects main without this PR). `CheckpointWithoutOutput` snapshotted live generator handles, so an eager rebuild replayed dropout from the already-advanced position and also advanced the live generators. This hit mHC bias-dropout-add recompute whenever CUDA graphs force the TE RNG tracker. Rebuilds now rewind the live generator contents and restore them afterwards, keeping the default/tracker aliasing inside `fork()`.
- **mHC projection weight readiness.** `HyperConnectionModule` reads `mapping_proj.weight` directly, so `mapping_proj`'s forward pre-hook never waited for an overlapped parameter gather. `compute_mappings` now calls `ensure_params_ready`.
- **GDN under scheduler THD graphs.** GDN reads packed offsets on the host, which capture forbids; GDN layers now stay eager for scheduler-packed batches.
- **Order-dependent #7521 mHC tests** (test-only, affects main without this PR). The mHC `_compute_h`, Sinkhorn, aggregate and post-BDA helpers are `torch.compile`'d, and Dynamo keeps their variants for the whole pytest process. `test_hybrid_mhc.py` alone exceeds the default recompile limit (8), so its later cases check the eager fallback. After it and `test_mhc_precision.py` in one process, the grad pass of `test_mhc_projection_matches_with_and_without_grad[*-cuda]` uses a compiled variant while the no-grad checkpoint forward runs eagerly, and its bitwise checks fail. CI runs these files in different buckets today, so this is not visible there. `test_hybrid_mhc.py`, `test_mhc_precision.py` and `test_mhc_projection_recompute.py` now reset the compile cache around each case, as `test_pp_mhc_compatibility.py` and `test_dsv4_packed_cp.py` already do, keeping the default budget.

### Guards

TE and full-iteration mHC graphs reject selective mHC recompute unless the split is on, and the split requires TE graphs of `attn` only with `mhc` (optionally `mla_up_proj`) recompute. Activation offloading, EP communication overlap, local graphs, repeated MTP layers, inference capture and dynamic CP remain unsupported for mHC graphs. Scheduler-packed THD requires the split.
