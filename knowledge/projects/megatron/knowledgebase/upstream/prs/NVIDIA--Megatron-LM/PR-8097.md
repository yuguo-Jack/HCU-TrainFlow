# Reject nonfinite values in GRPO tolerance validation

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8097) · state: open · merged: False

## Original PR description

NaN differences never exceed a tolerance, so GRPO validation silently accepts invalid samples. Reject nonfinite golden and current values before computing differences.

Validation: five baseline regressions fail; six focused CPU tests pass with the fix. Black, isort and Ruff passed. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
