# Document native GH200 builds and compatibility validation

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8383) · state: open · merged: False

## Original PR description

Native aarch64 setup on GH200 can fail before Megatron tests execute: the selected PyTorch headers require C++20 while pinned Mamba/FlashAttention sources request C++17, and a Python-provided NCCL installation needs explicit include/link paths for the NCCL-EP extension. Document the exact measured runtime, the local build adjustments, wheel provenance, and a finite single-GPU test workflow that distinguishes collection, execution and unsupported topology/asset cases.

The note is based on completed native builds and GPU execution on GH200 (PyTorch 2.14.1+cu130, Triton 3.8.0, CUDA toolkit 13.2, TE 44f31bbe, Mamba 0048fbf2, causal-conv1d 1.7.0, FlashAttention 2.8.3.post2). Both NCCL-EP ranks and CE/MLA/mHC/SSD component checks executed. A 27-case synthetic model comparison also exposed a cross-process MLA mismatch and did not meet its performance gate; the linked evidence explicitly preserves those negatives.

This documents a measured native environment, not a new supported-container promise or full eight-GPU CI result. The broad non-internal unit inventory is world size one and retains missing-data failures, topology failures and timeouts. No Docker scripts or dependency pins are changed.

Validation: commands and versions checked against the retained build logs; FlashAttention wheel checksum and native imports verified; Markdown/code fences and `git diff --check` checked. The complete Sphinx site was not rebuilt locally.

The completed inventory collected 14,324 non-internal node IDs and attempted 14,212 unique IDs: 10,163 passed, 1,548 failed, 2,483 skipped, 8 xfailed, 6 xpassed and 4 interrupted. Another 112 remained explicitly blocked after a timeout in their file; twelve modules had separate collection errors. The last pytest process emitted its result journal and then exited with SIGSEGV during shutdown. An independent reader verified 117 original files, and the process observer found no surviving owned children. [Complete ledger and denominator](https://github.com/0z5a/Megatron-LM/tree/hopper-validation-evidence/validation/hopper-20261020/aarch64). These counts are a single-GPU compatibility inventory, not architecture bug counts or full CI qualification.

Dependency follow-up: 302 passed, 14 failed, 18 skipped across 334 collected node IDs, with three remaining CuTe/CUTLASS collection errors. A final isolated repair rerun passed all 11 targeted cases: five NCCL allocator/offload regressions after explicit header/linker paths, and six JSONL dataset regressions with the repository LTS datasets 4.8.5 pin. Those eleven outcomes are recorded separately rather than rewriting the initial inventory. Three topology-limited cases and the three collection errors remain in this follow-up subset. The documentation now includes both measured repairs.
