# Factor RL-specific code out of training.py

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4264) · state: closed · merged: True

## Original PR description

# What does this PR do ?
Adds two hooks to `train()`: `next_train_iterator` and `run_eval`.

These hooks are defined separately for an RL run compared to a non-RL run.

After this #4264 as well as #8134 and #8139 are merged, there will be no more RL-specific code in `training.py`.
