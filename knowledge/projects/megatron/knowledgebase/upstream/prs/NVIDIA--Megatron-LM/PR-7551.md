# What does this PR do?

Clear cached CPU/GPU optimizer gradients when a parameter is temporarily unused, preventing a previous step's gradient from being applied again when `grad is None`.

The cached CPU gradient buffer is reattached when gradients resume. A parameterized regression covers CPU-offloaded BF16/FP32 updates, the GPU optimizer path, and overlapping/non-overlapping transfers.

This PR was developed with AI assistance; I reviewed the final diff and ran the tests below.
