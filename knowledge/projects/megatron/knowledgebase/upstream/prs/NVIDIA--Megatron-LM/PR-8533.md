# What does this PR do?
Keep Pixtral vision RoPE frequencies and angles in FP32 when the model is converted to BF16 or FP16.

Registered floating-point buffers are cast during model conversion, rounding the RoPE frequencies before angle and sin/cos computation. Store these constants as an FP32 tensor attribute, following LLM RoPE, and cache their device copy on first use. Frequencies remain absent from the state dictionary, as with the previous non-persistent buffer.

Validation on 4× GB300 (Slurm 1480683, PyTorch 2.13.0a0, TE 2.20.dev, NCCL 2.30.7):
- All 28 vision tests passed on every rank, including 25 new cases covering BF16/FP16, conversion before/after CUDA placement, `Float16Module`, two head sizes, two image grids, and device moves.
- Frequencies, angles, and resulting Q/K rotations match the FP32 reference exactly.
- With the production file restored to unmodified main, all 25 new cases failed; the three existing tests still passed.
- Repository autoformat and kernel-determinism coverage gate passed.
