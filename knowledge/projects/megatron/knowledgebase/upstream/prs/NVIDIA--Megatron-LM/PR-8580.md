# Add 'nvfp4' MoE dispatch/combine-backward wire dtype

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8580) · state: open · merged: False

## Original PR description

Allow moe_dispatch_fwd_dtype / moe_combine_bwd_dtype = 'nvfp4' for FP4 models on the ncclep flex dispatcher: get_fp8_recipe_for_a2a('nvfp4') returns NVFP4BlockScaling, which the token dispatcher hands to Transformer Engine's EpBuffer. The payload is quantized to NVFP4 for the wire and the receiver builds the NVFP4 GroupedTensor the fused grouped MLP consumes. Requires fp4 with fp4_recipe='nvfp4', the op fuser and grouped GEMM, and the companion Transformer Engine change for NVFP4 EP payloads.
