# Add Liger-Kernel integration for RMSNorm and vocab-parallel cross-entropy

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/5438) · state: open · merged: False

## Original PR description

# What does this PR do ?

Adds native, opt-in support for two [Liger-Kernel](https://github.com/linkedin/Liger-Kernel) Triton kernels — **RMSNorm** and **vocab-parallel cross-entropy** — so users can enable them via config without runtime monkey-patching of Megatron internals. Behaviour is unchanged for users who don't set the new flags.

Linked Issue: #5488 

## Motivation

Liger-Kernel ships an `apply_liger_kernel_to_megatron(...)` helper that monkey-patches `LocalSpecProvider.layer_norm`, `megatron.core.fusions.fused_cross_entropy.fused_vocab_parallel_cross_entropy`, and `megatron.core.tensor_parallel.cross_entropy.vocab_parallel_cross_entropy` at runtime. That works but mutates Megatron's module namespaces invisibly to anyone reading the source.

This PR plugs the same kernels into the existing extension points instead:

- **RMSNorm** slots in via a new `LigerSpecProvider(LocalSpecProvider)` and a `use_liger=True` kwarg on `get_gpt_layer_local_spec` — mirrors the `TESpecProvider` / `KitchenSpecProvider` pattern.
- **Cross-entropy** reuses the existing `cross_entropy_fusion_impl` config field, extended with `'liger'` — mirrors how the `'te'` impl is wired today in `LanguageModule.compute_language_model_loss`.

## Summary of changes

| Area | Change |
|---|---|
| `megatron/core/extensions/liger_kernel_spec_provider.py` (new) | `LigerSpecProvider` overrides `layer_norm` → returns `LigerMegatronRMSNorm` when `rms_norm=True`, else falls through to `LocalSpecProvider` |
| `megatron/core/models/gpt/gpt_layer_specs.py` | New `use_liger: bool = False` kwarg on `get_gpt_layer_local_submodules`; mutually exclusive with `use_kitchen` |
| `megatron/core/fusions/liger_cross_entropy.py` (new) | `liger_vocab_parallel_cross_entropy(vocab_parallel_logits, target, tp_group)` — thin wrapper around `LigerMegatronCrossEntropy`; lazy import |
| `megatron/core/model_parallel_config.py` | `cross_entropy_fusion_impl: Literal['native', 'te']` → `Literal['native', 'te', 'liger']`; validation warning text updated |
| `megatron/core/models/common/language_module/language_module.py` | New `elif self.config.cross_entropy_fusion_impl == 'liger'` arm in `compute_language_model_loss` |
| `megatron/training/arguments.py` | Validation message lists `'liger'` as a valid alternative |
| `tests/unit_tests/fusions/test_liger_cross_entropy.py` (new) | TP=1 + TP=2 forward/backward parity vs `vocab_parallel_cross_entropy`; ImportError surface |
| `tests/unit_tests/transformer/test_liger_spec_provider.py` (new) | Slot dispatch, fallthrough, ImportError, `use_liger` plumbing, `use_kitchen` mutex |
| `docs/user-guide/features/liger_kernel.md` (new) | User guide |

Liger-Kernel is treated as an **optional runtime dependency** — every import is lazy and raises a clear `ImportError` if the package is missing.

## Usage

```python
from megatron.core.models.gpt.gpt_layer_specs import get_gpt_layer_local_spec
from megatron.core.transformer.transformer_config import TransformerConfig

config = TransformerConfig(
    normalization="RMSNorm",
    cross_entropy_loss_fusion=True,
    cross_entropy_fusion_impl="liger",
    ...,
)
layer_spec = get_gpt_layer_local_spec(normalization="RMSNorm", use_liger=True)
```

Each knob is independent — users can opt into RMSNorm only, CE only, or both.

## Benchmark

**Note:** See the comment for all details on benchmarking: https://github.com/NVIDIA/Megatron-LM/pull/5438#issuecomment-4774317040.

Measured on 8× H100 with TP=8, Llama-2-7B-sized `GPTModel` (32 layers, hidden 4096, 32 heads, ffn 11008, vocab 32k, seq 4096, batch 1, RMSNorm + SwiGLU + RoPE, bf16). End-to-end forward + backward + gradient sync through `get_forward_backward_func`; 5 warmup / 20 measured iterations.

| Mode | Median step | tokens/sec | Peak GB/rank |
|---|---|---|---|
| `local` (`fused_vocab_parallel_cross_entropy`, `WrappedTorchNorm`) | 234.76 ms | 17,447 | 34.23 |
| `liger` (`LigerMegatronCrossEntropy`, `LigerMegatronRMSNorm`)      | 177.21 ms | 23,113 | 31.16 |

**1.32× speedup, −3.07 GB peak memory per rank.**

## Out of scope (deferred)

`LigerMegatronFusedLinearCrossEntropy` (VP-FLCE) — fuses the lm_head matmul with vocab-parallel CE and skips materializing the `[S, B, V/tp]` logits tensor (the larger memory win at long context / large vocab). Deferred because it requires bypassing `output_layer()` in `GPTModel._postprocess` rather than slotting into the existing CE dispatch. Planned as a follow-up.

## Reproducing the benchmark numbers

The benchmark script isn't included in the PR (it's diagnostic tooling, not feature code). Instructions to reproduce the headline numbers locally are below.

### Setup

- Hardware: 8× NVIDIA H100.
- `git clone https://github.com/linkedin/Liger-Kernel.git && cd Liger-Kernel && pip install -e .`
- Check out this PR's branch.

### Command

Save the script in the collapsed section below to `tools/bench_liger.py` and run:

```bash
torchrun --nproc-per-node 8 tools/bench_liger.py --num-layers 32 --warmup 5 --iters 20
```

Runs in ~45 s and prints a comparison table. Defaults match Llama-2-7B (32 layers, hidden 4096, 32 heads, ffn 11008, vocab 32k, seq 4096, batch 1, RMSNorm + SwiGLU + RoPE, bf16) at TP=8.

### Expected output (the numbers in the PR description)

```
mode          median ms     p10 ms     p90 ms     tokens/sec    peak GB
local            234.76     234.66     234.87         17,447      34.23
liger            177.21     177.18     177.32         23,113      31.16
-----------------------------------------------------------------------
Liger speedup: 1.32× (median step) | peak memory: +3.07 GB (negative = Liger uses more)
```

### What the script does

Builds the same `GPTModel` twice in one launch — once with `use_liger=True` + `cross_entropy_fusion_impl='liger'`, once with the local defaults — and runs each through `get_forward_backward_func` + `DistributedDataParallel` + `finalize_model_grads` for warmup + measured iterations. Timing uses `torch.cuda.Event` on the GPU side, not CPU wall clock. The only knobs that differ between the two runs are `use_liger` and `cross_entropy_fusion_impl` — everything else (config, spec, data, seeds, scheduler) is identical, so the delta is attributable to the two kernels.

### Other configurations worth trying

```bash
# Long context (pushes activation memory; bigger memory delta)
torchrun --nproc-per-node 8 tools/bench_liger.py --num-layers 32 --seq-len 8192 --warmup 5 --iters 20

# Llama-3-style large vocab (128k)
torchrun --nproc-per-node 8 tools/bench_liger.py --num-layers 32 --vocab-size 128256 --warmup 5 --iters 20

# Llama-2-13B sized
torchrun --nproc-per-node 8 tools/bench_liger.py \
    --num-layers 40 --hidden-size 5120 --num-heads 40 --ffn-hidden-size 13824 \
    --warmup 5 --iters 20

# Run only one mode
torchrun --nproc-per-node 8 tools/bench_liger.py --mode local
torchrun --nproc-per-node 8 tools/bench_liger.py --mode liger
```

All flags: `--num-layers --hidden-size --num-heads --ffn-hidden-size --vocab-size --seq-len --micro-batch-size --tp-size --warmup --iters --mode --seed`.

```python
"""End-to-end benchmark: Liger-Kernel vs local Megatron defaults on a Llama-style GPT model.

Builds the same GPTModel twice in one launch — once with ``use_liger=True`` +
``cross_entropy_fusion_impl='liger'``, once with the local defaults — runs warmup
plus measured forward+backward steps via Megatron's ``get_forward_backward_func``,
and reports median step time, tokens/sec, and peak memory side-by-side.

Defaults match Llama-2-7B (32 layers, hidden 4096, 32 heads, ffn 11008, vocab 32k,
seq 4096, batch 1, RMSNorm, SwiGLU, RoPE, no biases) across TP=world_size.

Launch:
    torchrun --nproc-per-node 8 tools/bench_liger.py
    torchrun --nproc-per-node 8 tools/bench_liger.py \\
        --num-layers 16 --warmup 5 --iters 20 --mode both
"""

import argparse
import os
import statistics
from functools import partial
from typing import Iterator

import torch

from megatron.core import parallel_state
from megatron.core.distributed import DistributedDataParallel, DistributedDataParallelConfig
from megatron.core.distributed.finalize_model_grads import finalize_model_grads
from megatron.core.models.gpt.gpt_layer_specs import get_gpt_layer_local_spec
from megatron.core.models.gpt.gpt_model import GPTModel
from megatron.core.pipeline_parallel.schedules import get_forward_backward_func
from megatron.core.tensor_parallel.random import model_parallel_cuda_manual_seed
from megatron.core.transformer.transformer_config import TransformerConfig


def _parse_args() -> argparse.Namespace:
    p = argparse.ArgumentParser()
    # Llama-2-7B-ish defaults
    p.add_argument("--num-layers", type=int, default=32)
    p.add_argument("--hidden-size", type=int, default=4096)
    p.add_argument("--num-heads", type=int, default=32)
    p.add_argument("--ffn-hidden-size", type=int, default=11008)
    p.add_argument("--vocab-size", type=int, default=32000)
    p.add_argument("--seq-len", type=int, default=4096)
    p.add_argument("--micro-batch-size", type=int, default=1)
    p.add_argument("--tp-size", type=int, default=int(os.environ.get("WORLD_SIZE", 1)))
    p.add_argument("--warmup", type=int, default=5)
    p.add_argument("--iters", type=int, default=20)
    p.add_argument("--mode", choices=["liger", "local", "both"], default="both")
    p.add_argument("--seed", type=int, default=123)
    return p.parse_args()


def _init_distributed(tp_size: int) -> None:
    """Initialize torch.distributed and Megatron parallel state. Idempotent."""
    if not torch.distributed.is_initialized():
        rank = int(os.environ["RANK"])
        world_size = int(os.environ["WORLD_SIZE"])
        local_rank = int(os.environ["LOCAL_RANK"])
        torch.cuda.set_device(local_rank)
        torch.distributed.init_process_group(
            backend="nccl", rank=rank, world_size=world_size
        )
    parallel_state.destroy_model_parallel()
    parallel_state.initialize_model_parallel(tp_size, 1)


def _build_config(args: argparse.Namespace, fusion_impl: str) -> TransformerConfig:
    """Llama-style TransformerConfig with the selected CE fusion impl."""
    return TransformerConfig(
        num_layers=args.num_layers,
        hidden_size=args.hidden_size,
        num_attention_heads=args.num_heads,
        ffn_hidden_size=args.ffn_hidden_size,
        normalization="RMSNorm",
        gated_linear_unit=True,
        activation_func=torch.nn.functional.silu,
        add_bias_linear=False,
        bf16=True,
        params_dtype=torch.bfloat16,
        pipeline_dtype=torch.bfloat16,
        tensor_model_parallel_size=args.tp_size,
        pipeline_model_parallel_size=1,
        sequence_parallel=False,
        cross_entropy_loss_fusion=True,
        cross_entropy_fusion_impl=fusion_impl,
    )


def _build_model(args: argparse.Namespace, *, use_liger: bool) -> GPTModel:
    fusion_impl = "liger" if use_liger else "native"
    config = _build_config(args, fusion_impl=fusion_impl)
    spec = get_gpt_layer_local_spec(normalization="RMSNorm", use_liger=use_liger)
    model = GPTModel(
        config=config,
        transformer_layer_spec=spec,
        vocab_size=args.vocab_size,
        max_sequence_length=args.seq_len,
        position_embedding_type="rope",
    )
    return model.cuda()


def _make_data_iter(args: argparse.Namespace) -> Iterator[dict]:
    """Yield synthetic batches matching the GPTModel forward signature.

    Uses ``attention_mask=None`` so Megatron's causal-mask path takes over;
    the model owns the mask, we just feed tokens.
    """
    while True:
        b, s, v = args.micro_batch_size, args.seq_len, args.vocab_size
        yield {
            "tokens": torch.randint(0, v, (b, s), device="cuda", dtype=torch.int64),
            "labels": torch.randint(0, v, (b, s), device="cuda", dtype=torch.int64),
            "loss_mask": torch.ones((b, s), device="cuda", dtype=torch.float32),
            "position_ids": torch.arange(s, device="cuda").unsqueeze(0).expand(b, -1),
            "attention_mask": None,
        }


def _forward_step(data_iter: Iterator[dict], model: torch.nn.Module):
    """Megatron's forward_backward_func contract: returns (output, loss_fn)."""

    def loss_func(loss_mask, output_tensor):
        losses = output_tensor.float().view(-1)
        loss_mask = loss_mask.view(-1).float()
        loss = (losses * loss_mask).sum() / loss_mask.sum()
        return loss, {"lm loss": loss}

    batch = next(data_iter)
    output_tensor = model(
        batch["tokens"], batch["position_ids"], batch["attention_mask"],
        labels=batch["labels"],
    )
    return output_tensor, partial(loss_func, batch["loss_mask"])


def _bench_one_mode(args: argparse.Namespace, *, use_liger: bool) -> dict:
    model_parallel_cuda_manual_seed(args.seed)
    gpt_model = _build_model(args, use_liger=use_liger)
    ddp_cfg = DistributedDataParallelConfig(
        grad_reduce_in_fp32=False,
        overlap_grad_reduce=False,
        use_distributed_optimizer=False,
    )
    gpt_model = DistributedDataParallel(
        config=gpt_model.config, ddp_config=ddp_cfg, module=gpt_model
    )
    data_iter = _make_data_iter(args)
    fwd_bwd = get_forward_backward_func()

    def step() -> None:
        for p in gpt_model.parameters():
            p.grad = None
        fwd_bwd(
            forward_step_func=_forward_step,
            data_iterator=data_iter,
            model=gpt_model,
            num_microbatches=1,
            seq_length=args.seq_len,
            micro_batch_size=args.micro_batch_size,
            decoder_seq_length=args.seq_len,
            forward_only=False,
        )
        finalize_model_grads([gpt_model])

    # Warmup (untimed).
    for _ in range(args.warmup):
        step()
    torch.cuda.synchronize()
    torch.distributed.barrier()
    torch.cuda.reset_peak_memory_stats()

    # Timed iterations. Event-based timing avoids CPU launch-overhead noise.
    starts = [torch.cuda.Event(enable_timing=True) for _ in range(args.iters)]
    ends = [torch.cuda.Event(enable_timing=True) for _ in range(args.iters)]
    for i in range(args.iters):
        starts[i].record()
        step()
        ends[i].record()
    torch.cuda.synchronize()

    step_ms = sorted(starts[i].elapsed_time(ends[i]) for i in range(args.iters))
    peak_gb = torch.cuda.max_memory_allocated() / 1e9

    del gpt_model
    torch.cuda.empty_cache()

    return {
        "median_ms": statistics.median(step_ms),
        "p10_ms": step_ms[int(0.1 * len(step_ms))],
        "p90_ms": step_ms[int(0.9 * len(step_ms))],
        "peak_gb": peak_gb,
    }


def _print_summary(args: argparse.Namespace, results: dict) -> None:
    """Side-by-side table; tokens/sec uses median step time."""
    if torch.distributed.get_rank() != 0:
        return
    tokens_per_step = args.seq_len * args.micro_batch_size
    print()
    print("=" * 96)
    print(
        f"Llama-style GPTModel:  layers={args.num_layers}  hidden={args.hidden_size}  "
        f"heads={args.num_heads}  ffn={args.ffn_hidden_size}"
    )
    print(
        f"                       vocab={args.vocab_size}  seq={args.seq_len}  "
        f"batch={args.micro_batch_size}  TP={args.tp_size}  dtype=bf16"
    )
    print(
        f"                       warmup={args.warmup}  iters={args.iters}  "
        f"tokens/step={tokens_per_step}"
    )
    print("=" * 96)
    header = f"{'mode':10} {'median ms':>12} {'p10 ms':>10} {'p90 ms':>10} {'tokens/sec':>14} {'peak GB':>10}"
    print(header)
    print("-" * len(header))
    for mode in ("local", "liger"):
        if mode not in results:
            continue
        r = results[mode]
        toks_per_sec = tokens_per_step / (r["median_ms"] / 1000.0)
        print(
            f"{mode:10} {r['median_ms']:>12.2f} {r['p10_ms']:>10.2f} {r['p90_ms']:>10.2f} "
            f"{toks_per_sec:>14,.0f} {r['peak_gb']:>10.2f}"
        )
    if {"local", "liger"} <= results.keys():
        speedup = results["local"]["median_ms"] / results["liger"]["median_ms"]
        mem_delta = results["local"]["peak_gb"] - results["liger"]["peak_gb"]
        print("-" * len(header))
        print(
            f"Liger speedup: {speedup:.2f}× (median step) | "
            f"peak memory: {mem_delta:+.2f} GB (negative = Liger uses more)"
        )
    print("=" * 96)


def main() -> None:
    args = _parse_args()
    _init_distributed(args.tp_size)
    results = {}
    if args.mode in ("local", "both"):
        results["local"] = _bench_one_mode(args, use_liger=False)
    if args.mode in ("liger", "both"):
        results["liger"] = _bench_one_mode(args, use_liger=True)
    _print_summary(args, results)
    parallel_state.destroy_model_parallel()


if __name__ == "__main__":
    main()
```

# Comparison of Liger's Current VPCE with Transformer Engine

Liger's vocabulary-parallel cross-entropy is already a strong improvement over
Megatron's default implementations. Across TP=1/2/4/8 and vocabularies
4K-128K, Liger is consistently faster than both Megatron fused and unfused
cross-entropy while matching Megatron unfused memory usage.

Transformer Engine remains ahead on this H100/CUDA 13 stack:

| Operation | Average TE speedup over Liger |
|---|---:|
| Forward | **1.32x** |
| Forward + backward | **1.93x** |

At TP=8 and a 128K vocabulary:

| Implementation | Forward | Forward + backward | Peak memory/rank |
|---|---:|---:|---:|
| Transformer Engine | 0.374 ms | 0.597 ms | 257 MiB |
| **Liger** | **0.512 ms** | **1.153 ms** | **1,024 MiB** |
| Megatron fused | 1.530 ms | 2.345 ms | 1,536 MiB |
| Megatron unfused | 2.143 ms | 2.868 ms | 1,024 MiB |

At this representative production shape, Liger is **3.0x faster forward and
2.0x faster overall than Megatron fused**, while using 33% less memory. Against
Megatron unfused, Liger is **4.2x faster forward and 2.5x faster overall** with
the same peak memory.

## Why TE is faster as compared to liger?

TE is faster and more memory-efficient because its forward kernel computes both
the loss and the logits gradient using an online softmax, then writes that
gradient back into the original logits buffer. Backward therefore only needs to
scale the precomputed gradient, with no vocabulary-sized allocation. Liger
instead preserves the caller's logits and stores a vocabulary-sized FP32
exponential buffer for backward, which provides safer, non-destructive semantics
but requires more memory traffic and storage.

Overall, Liger VPCE is a competitive, portable alternative and a clear upgrade
over default Megatron. Closing the remaining gap with TE likely requires an
optional in-place fast path.

`use_liger` only changes the per-layer `TransformerLayerSubmodules`. When this `ModuleSpec` is passed to `GPTModel`, `TransformerBlock._get_block_submodules()` independently sets the block-level `layer_norm` to `LayerNormImpl`, so `model.decoder.final_layernorm` remains the default implementation. Please thread the Liger provider through the block-level norm as well (or return a block spec that selects it), and add a test covering the constructed model's final norm.

- guihong-nv · comment · 2026-07-21T19:30:51Z · [source](https://github.com/NVIDIA/Megatron-LM/pull/5438#discussion_r3625129445)

File: `megatron/core/models/common/language_module/language_module.py` · line None

This top-level import causes `liger_cross_entropy` to be imported whenever `LanguageModule` is imported, and that module immediately executes `from liger_kernel.megatron import LigerMegatronCrossEntropy`. Consequently the optional package is not actually lazy: initialization failures other than `ImportError` can break users whose `cross_entropy_fusion_impl` is still `native`. Please move the external Liger import behind the `'liger'` branch or into the wrapper call path.
