# What does this PR do?
Megatron RL had originally introduced some custom logic for keeping track of the number of sequences trained on within each iteration.

#7252 created a standard, `_samples_seen`, for the whole class of such problems.

This PR updates the RL loop to this standard. It changes the behavior of the `--skip-train` inference-only RL mode, but that is acceptable, because this metric does not matter in that usecase.
