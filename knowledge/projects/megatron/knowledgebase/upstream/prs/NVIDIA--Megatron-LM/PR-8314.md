# Add output-layer activation gradient clipping

## What does this PR do?

Port [ADLR/megatron-lm commit 4b8ed8c339bfd2d441ea20ba46de40aa34b81225](https://gitlab-master.nvidia.com/ADLR/megatron-lm/-/commit/4b8ed8c339bfd2d441ea20ba46de40aa34b81225) ("Per token output grad clip", Vinay Rao) onto current `main`.

Adds opt-in `--apply-per-token-grad-clipping` (default: off). When enabled, GPT's output projection installs the source backward hook, clipping `grad_input[0]` elementwise to a median/MAD threshold while preserving other input gradients. The threshold is `median(abs(d_input)) + 3 * max(MAD(abs(d_input)), 1e-6)`.

The executable hook body and legacy backward-hook registration match the source. Despite the flag's name, the threshold is computed across the entire local gradient tensor, rather than separately for each token. This clips gradients propagated into the output layer's inputs; it does not directly clip output-weight gradients.

Current `TransformerConfig` CLI generation and config-field copying already provide the new flag and propagation, so no duplicate parser option is added. Both optimizer/scheduler override spellings from the source are already supported on `main`.

## Validation

- Added six regression cases covering signed outliers, preservation of other gradients, missing input gradients, zero spread in FP32/BF16, all-zero inputs, and a real autograd backward pass through a tuple-returning module.
- All six passed on CPU with PyTorch 2.14.1 using isolated loading of the real hook and test file, bypassing CUDA-dependent Megatron package initializers and the distributed pytest harness.
- Checked CLI generation (default off / enabled by flag) and field propagation using the actual argument factory and field-copy loop with an extracted config field.
- Verified the hook's executable AST matches the source commit.
- Passed `uv run isort`, syntax parsing, `git diff --check`, and the repository's `BASE_REF=main CHECK_ONLY=true SKIP_DOCS=false bash tools/autoformat.sh` check. Black, isort, Pylint (10/10), and Ruff pass. The script's non-blocking mypy step reports nine type errors, all reproduced on the unchanged upstream base.

## Gaps and follow-ups

The distributed/GPU unit harness and training runs were not run. No stability or convergence improvement is claimed.

This port preserves the source's deprecated `register_backward_hook` API and `view(-1)` assumption. Before enabling it for production training, validate the actual output-layer variants with TP/GTP/SP, Transformer Engine, mixed precision, and CUDA graphs; measure clipping overhead and compare training stability against the disabled baseline. These remain explicit draft-PR follow-ups.
