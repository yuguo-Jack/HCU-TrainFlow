# Make packed DSv4 context-parallel attention deterministic

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7921) · state: closed · merged: False

## Original PR description

With `config.deterministic_mode=True`, packed DSv4 THD/context-parallel attention selects stable Top-K and uses deterministic cuDNN attention backward plus fixed-order sparse-indexer gradients. Learned-indexer no-grad and training forwards now use the same compressed-first, compacted attention indices. Both packed attention wrappers enforce sink-only padded rows before FlashMLA without mutating caller-owned indices. Global token-loss normalization and deferred CP reductions are preserved.

[Packed-only integration diff](https://github.com/Connor-XY/Megatron-LM/compare/codex/dsv4-packed-determinism-base...codex/dsv4-packed-cp-determinism-split)

Split from #7708. Depends on #7708 (shared determinism), #7469 (packed CP), and #7705 (compiled packed boundaries). This PR is temporarily stacked on `pull-request/7705` and carries the shared core patch too; the link above isolates the six packed-integration files.

## Original work and dev dependencies

- **Bo Li (@bobboli), #7169**, originated stable Top-K, forward key-order alignment and the padded-query guard. This PR extends his ordering approach to main's packed CP path; #7169 explicitly left CP ordering for follow-up. The adapted padding mask avoids mutating caller-owned tensors. Port commits retain Bo's co-author credit.
- **Haochen Yuan (@HaochenYuan), #7441**, originated the deterministic sparse-attention/indexer-backward work. The shared implementation also includes our sample-local indexing and clipped-KL corrections from #7706.
- The normal model's packed metadata already masks padded rows; the new direct-wrapper guard strengthens that boundary contract. The audit found equivalent teacher normalization and zero-loss gradient connectivity already present. Compact/MXFP8 indexer and dynamic/balanced CP features on dev remain separate scope.

## Validation

Runtime: four GB300 ranks, cuDNN Frontend 1.29.0 / cuDNN 9.23.2, BF16 attention, `NCCL_ALGO=Ring`, at most one NCCL channel, NVLS disabled, and isolated compiler caches per rank.

- Final head `8e2d0fe010db0978bc7d897416d9a0f401f5c6b2`, job **1103549**, `COMPLETED 0:0`: **343 passed per rank**, four ranks, no skips/xfails. This comprises **44 indexer + 27 fused-attention + 230 manifest + 31 packed-CP + 11 packed-kernel/boundary cases** per rank.
- With only the new tests overlaid on prior production `381787f`, **10 controls per rank** fail at their intended terminal assertions: 3 real CP forward-order cases, 4 generic-padding cases, 2 positive-indexer-padding cases and 1 deterministic-compaction case. These **40 expected failures** are reported separately from the **1,372 candidate passes**; unrelated exceptions do not satisfy a control.
- Normal repository conftest, all per-rank setup/call/teardown outcomes, pinned runtime/source manifests and equal before/after source guards were verified. Changed-test formatting, lint, syntax, copyright and determinism coverage checks passed.

New real-module parity covers CP1/2/4, zero/positive sparse indexer loss, an empty document, internal/tail padding and rank boundaries cutting documents/compression groups. It checks actual FlashMLA key IDs/lengths and exact forward bytes across repeated grad modes. Eight mocked wrapper cases independently check padding, compaction, backward placeholders and caller-tensor immutability. Existing real CP2 BF16 output/gradient replay covers compression ratios 0/4/128; numerical CP2/4 comparisons are retained.

The old #7705 base pins cudnn-frontend 1.26.0. Validation explicitly uses Frontend 1.29.0, required for deterministic backward and already pinned on current `main`. The dependency branch's old lock alone does not provide that API.

These focused checks do not certify a complete training recipe or equality across different parallelism configurations. No performance comparison is claimed; deterministic dense indexer backward remains unsupported.
