# Remove unnecessary copy from postprocessing graph

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4380) · state: open · merged: False

## Original PR description

# What does this PR do ?
Make the output postprocessing write directly into the `_all_logits_cuda` inference buffer, instead of requiring an intermediate copy.

This also significantly reduces CUDA graph memory pressure.

Stacked on top of #8235. Same as #8167.
