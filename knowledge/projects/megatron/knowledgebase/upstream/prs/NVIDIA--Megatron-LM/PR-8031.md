# Seed the RNG from the model's process-group collection

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8031) · state: closed · merged: False

## Original PR description

**Why.** `model_parallel_cuda_manual_seed` reads every rank it is not given from the global grid, and `pretrain(pg_collection=...)` passes only pp/dp/tp/ep/expt_tp groups. For a model on its own grid with GTP-remat, the GTP-remat ranks and sizes therefore come from the global grid:
- Without an initialized grid, the `gtp-remat-rng` tracker is never added, and the first GTP-remat layer fails to fork it.
- With another model's grid initialized, the offsets come from that model.

The explicit path also offsets `--data-parallel-random-init` seeds by the replicate `dp` rank, while the global path uses the GTP-remat-inclusive rank.

**What.**
- `model_parallel_cuda_manual_seed(..., *, pg_collection=None)`: ranks and sizes that are not passed come from `tp`, `ep`, `expt_tp`, `gtp_remat` and `expt_gtp_remat`. A field set to `None` means that axis is off; an unset field raises `ValueError`. Explicit ranks win, and the offsets are unchanged.
- `initialize_megatron(seed_pg_collection=)` and `_set_random_seed(pg_collection=)` are new keyword-only arguments, and `pretrain` passes its collection. The PP offset comes from `pp` and the DP offset from `dp_gtp_remat`.

**Tests.** Tracker states are `torch.equal` between the global and collection paths, with the global accessors patched to fail. This covers five TP/EP/ETP/GTP-remat layouts and three training grids. Before the sync, the 18 new tests (7 in `test_random.py`, 11 in `test_rng_ownership.py`) failed on main and passed here on 4 GPUs, and the existing seeding tests matched main. In the integration run (all #6307 PRs and the related fixes merged onto main 77391e71cc), this PR's test files show no regressions against main. `test_random.py` passes 21 tests vs 14 on main on 8 GPUs (two nodes). `test_rng_ownership.py` passes 86 tests vs 63 on main on 4 GPUs; that count also includes tests other #6307 PRs add to the file. Neither file has a failing test on either side.

**Compatibility.**
- Without a collection, seeds are unchanged.
- A collection passed to `pretrain` must set the five fields (`None` when off), plus `dp_gtp_remat` with `--data-parallel-random-init`.
- The tracker is per process, so co-located models with different layouts still cannot both be seeded.

Synced with main 77391e71cc on 2026-11-01 by a merge commit with no conflicts, so existing commits and review links stay valid. The merge also adds to the process-group allowlist the reads main added since this PR was written.
