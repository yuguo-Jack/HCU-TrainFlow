# test: Mark GDN2 and MoE overlap cases flaky in dev

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8120) · state: closed · merged: True

## Original PR description

GDN2 TP4 and grouped-GEMM all-to-all overlap tests intermittently hang in distributed execution, exhausting launcher retries and the CI job deadline. Mark the four affected parameter cases `flaky_in_dev`:

- GDN2: TP4/SP/CP1 with and without sequence packing, tracked in #7742. The four CP2 cases remain enabled.
- MoE overlap: grouped GEMM with the `alltoall` dispatcher, with and without permutation fusion. Extend the existing non-grouped all-to-all quarantine; other dispatchers remain enabled.

The existing dev marker filter excludes these cases before fixtures run in full, Testmon baseline, and Testmon-selected execution. Test IDs and LTS selection remain unchanged.

Failure evidence: [GDN2 on #8001](https://github.com/NVIDIA/Megatron-LM/actions/runs/38106665824/job/114374130289), [MoE overlap on #8001](https://github.com/NVIDIA/Megatron-LM/actions/runs/38128757991/job/114439165065).

Validation:

- Fourteen CPU-only pytest collection checks using the pinned pytest 9.1.1 and source decorators: unchanged node IDs and LTS selection; exactly four additional cases excluded in dev; explicitly selected marked node IDs also excluded.
- Repository `tools/autoformat.sh` check: Black, isort, Pylint, and Ruff passed. Mypy reported missing PyTorch imports in the host environment.
- `git diff --check` passed. GPU execution was not run; this change quarantines the intermittent failures and does not fix their underlying cause.
