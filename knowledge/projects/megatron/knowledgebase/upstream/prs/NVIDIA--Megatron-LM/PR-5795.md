## Original PR description

# DeepSeek-V4 main tracker

Updated: 2026-10-14. Tracks mainline support for the DSv4 HybridModel performance recipe.

**Progress:** Core foundations and all three tracked functional ports—Hash MoE, packed THD/CP, and mHC PP/VPP—are merged into main. Remaining work is performance parity.

**BatchedLinear blocker:** Dev [#5722](https://github.com/NVIDIA/Megatron-LM/pull/5722) and main [#7971](https://github.com/NVIDIA/Megatron-LM/pull/7971) both depend on [TE #3160](https://github.com/NVIDIA/TransformerEngine/pull/3160) for the optimized path. In [#7971](https://github.com/NVIDIA/Megatron-LM/pull/7971), the pinned TE does not provide BatchedLinear: the draft uses the einsum fallback and skips real BatchedLinear tests. Resolve the TE dependency, update the pin, recheck the final API, and pass BF16/MXFP8 GPU validation before marking the optimization ready. [#7971](https://github.com/NVIDIA/Megatron-LM/pull/7971) remains a draft.
