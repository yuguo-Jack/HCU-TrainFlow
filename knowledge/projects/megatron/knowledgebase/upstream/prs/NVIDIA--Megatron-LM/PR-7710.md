# Split MFSDP v2 adapter tests into focused files

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7710) · state: closed · merged: True

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

`test_mcore_adapter.py` combines dense, CUDA graph, MoE, and hybrid integration tests. Move each existing class into a focused `test_mcore_<behavior>.py` file (`dense`, `cuda_graph`, `moe`, and `hybrid`) with a matching class name, inline the small block constructor at its call sites, and share public `destroy_model_parallel()` cleanup in `mcore_utils.py`.

Preserve all 15 test bodies, assertions, existing markers, and parameter combinations. Each class now requests a fixture that explicitly depends on `distributed_setup`: this selects the NCCL symmetric-memory backend before the first FSDP allocation and runs adapter cleanup before process-group cleanup. CUDA graphs must be released before their process groups are destroyed. This fixes the CI failure `Backend can not be changed after use` when the split adapter tests run without another MFSDP test initializing the backend first. The existing DTensor cache cleanup and #7322 follow-up are preserved. The conversion to module-level tests and shorter helper names remains in #8354.

Update checkpoint documentation references and the GB200 selection expectation for the dense test's new path. The selection assertion also includes the already-marked `test_grad_comm_dtype.py`, which its previous expected list omitted.

Validation on the rebased code:

- All four adapter files, run directly in a fresh two-rank `torch.distributed.run` process on RTX A6000 GPUs: **29 passed, 5 skipped per rank**. The skips require Blackwell hardware or four ranks.
- Fresh-process regression running dense training before the NCCL user-buffer test: **2 passed per rank**. Without the fixture fix, the same sequence produced **1 passed, 1 failed per rank** with the CI backend error.
- All 15 test functions, including decorators and parameters, are AST-identical before and after the fixture fix.
- Test-selection checks: **27 passed**.
- `tools/autoformat.sh` in check mode: Black, isort, Pylint, and Ruff pass. Mypy is unavailable in the local container.
- Local image: NGC 26.08; `main` targets NGC 26.09. CI validation on the updated head is pending.
