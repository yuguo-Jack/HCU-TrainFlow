# Fix cached checkpoint validation for singleton process groups

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8695) · state: open · merged: False

## Original PR description

- [ ] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Fix a hang on repeated cached checkpoint saves when save-parallelization groups have mixed sizes.

A singleton group legitimately produces `None` as its shard distribution. On the second save, the wrapper mistakes that cached result for an uninitialized cache and repeats WORLD-wide sharding validation, while ranks in larger groups skip it. The collective sequence diverges.

Track successful validation independently from the distribution value, so all ranks validate once when distribution caching is enabled. Per-save validation without caching, disabled validation, and disk-cache-read behavior are preserved.

The eight-case regression covers sync/async saves, distribution caching on/off, and integrity validation on/off with mixed singleton and multi-rank groups. It counts repeated metadata gathers without entering a mismatched collective, so the old code fails an assertion instead of hanging.

## Validation

- Four CPU/Gloo ranks: all eight regression cases passed on every rank. Unmodified main reproduced the two cached/validated failures, for both save methods.
- Without metadata instrumentation: three repeated cached saves completed for each save method, using real distribution and global validation collectives with groups `[0,1]`, `[2]`, and `[3]`. The base save strategy was mocked.
- The local CPU harness executed the checked-in test body and real checkpointing runtime, bypassing unrelated GPU-only package initialization and model-parallel test setup. This is not a full pytest/GPU-suite result.
- Repository `tools/autoformat.sh`: Black, isort, pylint (10/10), and Ruff passed. Its optional mypy step reported two existing errors (`loaded_state_dict` annotation and `replica_id` on `object`), also reproduced on unmodified main.
- `git diff --check` passed. The commit is SSH-signed and signed off.

GPU/NCCL, actual checkpoint I/O, and the NVRx persistent worker have not been validated.
