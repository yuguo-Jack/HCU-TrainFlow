# Exclude infinite samples from training golden statistics

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8090) · state: open · merged: False

## Original PR description

Training aggregation excludes NaN but accepts numeric and string infinities. Those samples can contaminate means, deviations and recommended tolerances. Reject non-finite values in the existing numeric conversion seam, including the per-run timing arrays.

Validation: the focused CPU regression fails on the baseline and the complete regression file passes with the fix. Black, isort and Ruff passed for the test. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
