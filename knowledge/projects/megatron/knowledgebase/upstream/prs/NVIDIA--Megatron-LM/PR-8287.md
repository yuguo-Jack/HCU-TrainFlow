# [Dev] Add KPool DSA indexer, NoPE MLA support, and FP8 precision controls for the indexer and MLA attention (dev port of #7522)

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8287) · state: closed · merged: True

## Original PR description

## Summary

Dev port of #7522 (merged to `main` as eb001528f). Adds:

- **KPool DSA indexer** (`dsa_indexer_kpool > 1`): softmax-weighted key pooling with a BF16 per-token gate and an FP32 per-slot positional bias, pool selection expanded back to token indices, optional causal-tail append (`dsa_indexer_kpool_always_select_tail`), and per-document pooling for packed THD. The fused cuDNN DSA path is bypassed for KPool.
- **NoPE** (`qk_pos_emb_head_dim == 0`) for `DSAIndexer` and `AbsorbedMLASelfAttention`.
- **Precision controls**: `dsa_indexer_qk_proj_use_quantization`, `dsa_indexer_kpool_use_quantization`, and `mla_proj_use_quantization`.
- Chunked indexer score / indexer-loss backward computation, FP32 k-norm via explicit `layer_norm`, TileLang sparse-MLA top-k width padding, and a cuDNN indexer weights dtype guard.

### Dev-specific adaptations

- `absorbed_mla.py`: keeps dev's split K/V up-projection support (both combined and split builds are wrapped in the MLA projection precision context) and dev's fused MLA RoPE path (`should_use_fused_mla_rope`); NoPE skips RoPE setup entirely.
- `dsa.py`: keeps dev's fused indexer RoPE (`fused_mla_rope_inplace`) and CP-layout imports; NoPE returns early in `_apply_rope`.
- `transformer_config.py`: keeps dev's DSA CP `cp_comm_type=allgather` validation alongside the new KPool checks; only `mla_proj_use_quantization` is added to `MLATransformerConfig` (main-only fused MLA fields from the conflict context are not ported).
- Tests: the `tests/unit_tests/determinism/kernels/*` updates are dropped (that framework does not exist on dev). Dev's `test_dsa_indexer_fused_rope_matches_unfused` now sets `dsa_indexer_loss_coeff=1.0` so it keeps comparing parameter gradients, since indexer parameters are frozen when the indexer loss is disabled. Dev-only AbsorbedMLA stand-in tests (`test_absorbed_mla_qkv_rope_uses_microbatch_cp_group`, `test_dsa_integration.py`) now provide `use_rope` and the MLA projection precision context.

### Behavior note

As on `main`, indexer parameters are set to `requires_grad=False` when `dsa_indexer_loss_coeff` is unset or `<= 0`.
