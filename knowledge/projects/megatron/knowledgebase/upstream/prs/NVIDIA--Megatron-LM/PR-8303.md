[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8303) · state: open · merged: False

## Original PR description

## Summary
- Replace the git-installed cuDNN frontend (`CUDNN_FRONTEND_GIT_REF`, added in #8176) with the PyPI release `nvidia-cudnn-frontend==1.29.1`.
- `pyproject.toml`: bump `nvidia-cudnn-frontend[cutedsl]` from `==1.29.0` to `==1.29.1`.
- `uv.lock`: regenerated with uv 0.7.2 (the CI version). Only the `nvidia-cudnn-frontend` entries changed (version, wheel URLs and hashes, one specifier).
- `docker/Dockerfile.ci.dev`: remove the `CUDNN_FRONTEND_GIT_REF` arg and the post-sync git install, so `uv sync` installs the locked wheel.
- Mirrors NVIDIA-NeMo/Megatron-Bridge#6524.

## Not yet verified
- Test image build (draft until done).
- The lock was regenerated outside the CI image: `TMS_CUDA_MAJOR=13` and an `nvcc` 13.4 pip wheel stood in for the toolkit, which mamba-ssm's metadata build needs. The diff touches only cuDNN frontend, but CI may regenerate differently.
