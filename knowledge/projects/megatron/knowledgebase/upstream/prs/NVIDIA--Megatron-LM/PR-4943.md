# [feat] FSDP support for HybridStack EP-overlap (3/4 of #4798)

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4943) · state: open · merged: False

## Original PR description

**Depends on #4942** — merge #4942 first. [Scoped diff of this PR's own changes](https://github.com/NVIDIA/Megatron-LM/compare/Connor-XY:pr4798-2-hybrid-stack-grouped...Connor-XY:pr4798-3-fsdp-hybrid). The full diff also shows #4942's commits until it merges.

## What does this PR do?

Add Megatron FSDP v1 support for bracketed HybridStack groups in the 1F1B EP-overlap schedule. Each bracket group becomes one FSDP unit; the outer decoder stack is excluded.

Apply the same instance filter to parameter buckets and lifecycle hooks, so separate groups never share the outer stack's bucket identity. Preserve the existing constructor's positional arguments. Regression coverage includes grouped, mixed, and ungrouped unit selection, plus three-step loss/parameter parity against non-overlapped FSDP for grouped attention and Mamba patterns.

## Dependencies and review scope

- Depends on #4942; #4941 has merged.
- #4944 wires these FSDP units into the training launcher.
- FSDP slice: adapter, FSDP core/bucketing, and two test files. The MTP slot-boundary fix now belongs to #4942.
- Original feature split from #4798 by @Wohox and @Connor-XY.

## Validation

Restacked on #4942 at `980af2d63` (main through `5052ce8c4`); this PR's own commits applied without conflicts. Black, isort, repository-pinned pylint, Ruff, and diff checks pass for this slice. A limited CPU harness using PyTorch 2.14.0 passes all six unit-selection cases and fails the filtered case when the bucketing fix is removed. It executes the source grouping function with ordinary CPU parameters; this does not validate CUDA/FSDP collectives.

An internal GB200 run tested the integrated stack at #6960 `c331df5ef3f2d6e057ad11cee28cf6341d9cdd8b` plus #7192 `d2385590f5ed4e0189e19e434d262ed5c7ac02e7` on four GB200 GPUs (PyTorch `2.12.0a0+0291f960b6.nv26.04.48445190`, CUDA 13.2, Transformer Engine `2.14.0+f031cf87`). All 18 FSDP tests passed on every rank: 12 three-step loss/final-parameter parity cases across attention/Mamba/MLA, alltoall/flex dispatchers, shared experts off/on, plus six unit/bucket tests. That run validated the integrated source combination before the restack.

After the restack, `tests/unit_tests/a2a_overlap/test_fsdp_hybrid_overlap.py` at the top of the stack (#6958) passed all six alltoall cases (`[*E][*E]`, `[M*E][M*E]`, and the MLA `[+E][+E]` case that #6958 adds, shared experts off/on) on every rank across eight GB300 GPUs; the flex-dispatcher cases were deselected because DeepEP/HybridEP cannot initialize in that container. On four GPUs, `tests/unit_tests/distributed/mfsdp_v1/test_mfsdp_fully_shard.py` passed 26 (main: 19), with the same 315 skipped eight-rank cases and 6 xfailed as main.
