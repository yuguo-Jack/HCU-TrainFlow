# [MFSDP] Extract V1 and V2 wrappers from the MCore adapter

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

The MCore FSDP adapter contains both version-specific wrappers, making each implementation harder to navigate. Extract those implementations while preserving the existing public import path:

- `mcore_fsdp_adapter.py`: public factory and V1/V2 re-exports (52 lines).
- `mcore_adapter_v1.py`: V1 wrapper and its mesh, tensor-parallel, and RNG helpers.
- `mcore_adapter_v2.py`: V2 wrapper and its meta-materialization, placement, and mesh helpers.

Existing imports of `FullyShardedDataParallel`, `FullyShardedDataParallelV1`, and `FullyShardedDataParallelV2` from `mcore_fsdp_adapter` continue to work, as do the package-level factory exports. The remaining edits update the symmetric-memory test's monkeypatch target, a V1 test's source-location comment, and the process-group allowlist path.

All 14 moved function/class definitions and the existing placement constants are AST-identical to base main.
