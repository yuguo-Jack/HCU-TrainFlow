# Fix MoE GLU checkpoint layout conversion

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7606) · state: open · merged: False

## Original PR description

Convert contiguous expert FC1 checkpoint rows before loading model and FP32 master weights, and save model weights in a canonical contiguous layout. Preserve optimizer runtime rows with explicit layout metadata and reject incompatible optimizer resumes before distributed checkpoint tensor loading.

Cover indexed and single grouped weights, shared experts, sharded factories, legacy checkpoints, and Adam update/resume parity with CPU regression tests.

Refs NVIDIA/Megatron-LM#7576
