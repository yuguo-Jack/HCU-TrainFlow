# Refactor (tests): split MoE token dispatcher tests into per-dispatcher files

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/3975) · state: open · merged: False

## Original PR description

# What does this PR do ?
<!-- Add a one line overview of what this PR aims to accomplish. -->

This PR extracts `TestAllgatherDispatcher` and `TestFlexDispatcher` from the monolithic `test_token_dispatcher.py` into their own dedicated files (`test_ag_token_dispatcher.py` and `test_flex_token_dispatcher.py`).

This refactoring aligns these dispatchers with the existing pattern established by `TestAlltoAllDispatcher`, which already resides in its own file.

**Key Changes:**
- Dependency Isolation: Isolated DeepEP/HybridEP dependencies and skip logic within `test_flex_token_dispatcher.py`. This ensures that environment-specific skips for Flex Dispatcher do not affect the execution or reporting of All-gather dispatcher tests.
- Maintainability: Simplified individual test files to facilitate future extensions and easier debugging of specific dispatcher implementations.
- **No Functional Changes**: This is a pure refactoring PR; no core logic or test cases were modified.


**Tests**
All 37 test cases passed successfully, confirming the refactoring did not introduce any regressions.
