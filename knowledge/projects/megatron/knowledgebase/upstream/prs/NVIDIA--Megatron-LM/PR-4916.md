# fix MTP recompute padding mask forwarding

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4916) · state: open · merged: False

## Original PR description

## Summary
- Add `padding_mask` to `MultiTokenPredictionLayer._checkpointed_forward`.
- Forward the rolled padding mask through the recompute custom forward, TE checkpoint, tensor-parallel checkpoint, and block fallback paths.
- Add unit coverage for full recompute forwarding so the signature mismatch is caught.

## Root Cause
`MultiTokenPredictionLayer.forward()` passes `padding_mask` to `_checkpointed_forward()` when full recompute is enabled, and `_proj_and_transformer_layer()` already accepts and forwards that argument. The rewritten `_checkpointed_forward()` signature did not accept `padding_mask`, causing `TypeError: MultiTokenPredictionLayer._checkpointed_forward() got an unexpected keyword argument 'padding_mask'`.
