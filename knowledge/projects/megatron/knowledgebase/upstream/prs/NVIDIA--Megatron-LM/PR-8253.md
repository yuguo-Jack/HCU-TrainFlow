# Fix MFSDP checkpoint save/load across pipeline and virtual pipeline chunks

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8253) · state: open · merged: False

## Original PR description

## Design
Preprocess every pipeline chunk using local module paths, then emit globally numbered checkpoint names. Restore all raw chunk dictionaries after DCP fills shared storage. Fused v2 checkpoint sections use the owning buffer layout and preserve tensor aliases.

## Why
PP/VPP currently assumes a single model dictionary and can resolve optimizer names against the wrong chunk. V2 fused-weight handling also requires its own layout metadata rather than V1-only attributes.

## Validation
Added ownership, multi-chunk preprocessing/load, and fused uneven-shard regressions. Import sorting, Ruff, and AST checks pass. The prerequisite local-tensor/EP integration passed 14 checkpoint tests per rank on four GB300 GPUs. New PP/VPP end-to-end restart validation is pending.

Related: #7322 and #8230; their implementation is not duplicated here.
