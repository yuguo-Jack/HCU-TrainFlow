# What does this PR do?
<!-- Add a one line overview of what this PR aims to accomplish. -->

- Add mtp_loss_early_backward to cap MTP head logits memory
- Keep fused cross entropy in place under torch.compile, so that remove an intermediate tensor allocation
- Resolve MoE offload knobs per GroupedMLP instance instead of per model, so that we can enable MTP activation offloading
