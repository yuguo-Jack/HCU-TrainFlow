# [fix] Training wire-up for hybrid EP-overlap (4/4 of #4798)

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/4944) · state: open · merged: False

## Original PR description

**Depends on #4943** — merge #4943 first. [Scoped diff of this PR's own changes](https://github.com/NVIDIA/Megatron-LM/compare/Connor-XY:pr4798-3-fsdp-hybrid...Connor-XY:pr4798-4-training-wireup). The full diff also shows #4943's commits until it merges.

## What does this PR do?

When HybridModel training enables Megatron FSDP and 1F1B EP overlap, include HybridStack among the FSDP unit classes so each bracket group follows the schedule's gather/reshard lifecycle. Keep the existing TransformerLayer, MoETransformerLayer, and MambaLayer defaults for ungrouped layers in mixed patterns. The adapter excludes the outer decoder stack and skips children of selected groups.

## Dependencies and review scope

- Depends directly on #4943 and transitively on #4942; #4941 has merged.
- Training-only slice: 18 added lines in `megatron/training/training.py`.
- Original feature split from #4798 by @Wohox and @Connor-XY.

## Validation

Restacked on #4943 at `42cbd9607` (main through `5052ce8c4`) without conflicts. The new imports were sorted, syntax and diff checks pass, and a limited CPU harness verifies all four HybridModel/EP-overlap selection combinations. #4943 adds grouped/mixed/ungrouped bucket-selection regression coverage and the distributed grouped-FSDP parity test. The integrated grouped-FSDP test passed all 18 cases on each of four GB200 ranks in an internal GB200 run (top #6960 `c331df5ef`, checkpoint #7192 `d2385590f`). This GPU test constructs the FSDP wrapper directly; the launcher-selection branch is covered by the four CPU cases.
