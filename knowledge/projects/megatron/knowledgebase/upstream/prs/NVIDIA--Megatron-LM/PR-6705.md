# Add compatible endpoint for Mistral eval serving

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6705) · state: open · merged: False

## Original PR description

## Summary
- Add `/raw_completions` endpoint for token-in/token-out eval requests (no tokenizer on the server side)
- Key top-n logprob dicts by token id (decimal string) instead of detokenized string to avoid byte-fallback token collisions (U+FFFD)
- Re-key back to detokenized strings at the `/completions` edge for OpenAI wire format compatibility
- Add `tools/run_megatron_checkpoint_eval_server.py` eval server wrapper with eval-oriented defaults
- Refactor `tools/run_dynamic_text_generation_server.py` into reusable `main()` with configurable args

Ported from https://github.com/NVIDIA-NeMo/nv-mistralai-megatron/pull/107

## Test plan
- [ ] Unit tests added in `tests/unit_tests/inference/test_dynamic_text_generation_server_raw_completions.py`
- [ ] Verify `/raw_completions` endpoint accepts token id prompts and returns token id responses
- [ ] Verify `/completions` endpoint still returns string-keyed logprobs (backward compatible)
- [ ] Verify eval server starts with `run_megatron_checkpoint_eval_server.py`
