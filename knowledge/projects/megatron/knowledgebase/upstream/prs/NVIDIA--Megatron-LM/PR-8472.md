# perf(mtp): skip masked tokens in output projection

# What does this PR do?

Adds an opt-in MTP loss path that skips vocabulary projection and cross entropy for tokens masked out of the loss.

`TransformerConfig.mtp_loss_skip_masked_tokens` defaults to `False`. When enabled, each MTP head:

1. restores the full hidden-state layout under sequence parallelism;
2. selects only hidden states and labels with a nonzero loss mask;
3. runs the LM head and cross entropy on those compact tokens, optionally in `mtp_loss_chunk_size` chunks;
4. scatters the selected losses back to the original token layout.

The dense path is unchanged when the option is disabled. Empty masks retain graph connections to the hidden states and output weight and produce finite zero gradients.

The skips are existing environment constraints: TP=4 requires four GPUs, and the installed Transformer Engine fused cross entropy cannot return argmax.

### BF16 numerical comparison

TP=2 with sequence parallelism, hidden size 5120, vocabulary size 248320, sequence length 8192, and a 25% nonzero loss mask:

- selective and dense MTP loss: identical;
- hidden-state gradients: identical;
- LM-head weight-gradient relative L2 difference: approximately `1.21e-3`;
- LM-head weight-gradient max absolute difference: `3.81e-6`.

The weight-gradient difference is consistent with changing BF16 GEMM accumulation order.

### 131k core benchmark

TP=2 with sequence parallelism, BF16, hidden size 5120, vocabulary size 248320, sequence length 131000, a 25% nonzero loss mask, and chunk size 512:

| Mode | Time / rank | Peak allocated / rank | Peak reserved / rank | MTP loss |
|---|---:|---:|---:|---:|
| Chunked | 2.049 s | 6.332 GiB | 8.057 GiB | 13.45608711 |
| Selective + chunked | 1.216 s | 6.760 GiB | 9.252 GiB | 13.45608711 |

Selective projection reduced the isolated MTP loss time by 40.7%. Restoring the full sequence-parallel hidden states increased peak allocated memory by 0.43 GiB, while vocabulary projection and cross entropy processed only 32,750 of 131,000 token rows.

### 27B training A/B

For a TP2/PP2 27B training workload with a 25.26% effective policy mask:

- steady-state throughput: `8518 -> 8995 token/s` (`+5.6%`);
- actor time: `134.47 -> 127.33 s` (`-5.3%`);
- final pipeline-stage GPU peak: `158169 -> 105388 MiB`.

The end-to-end run selected masked tokens for both the policy objective and MTP; the Megatron change in this PR is the MTP portion.
