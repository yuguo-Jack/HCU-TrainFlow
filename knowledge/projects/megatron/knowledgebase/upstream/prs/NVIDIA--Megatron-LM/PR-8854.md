# What does this PR do?

Adds a packing-invariant Mamba SSD path for packed (THD) training, as proposed in #8852.

Megatron already has a varlen SSD forward, `mamba_chunk_scan_combined_varlen`, used by dynamic-inference prefill. Its chunks restart at every sequence start, so a sequence's result does not depend on its position in the pack. This PR adds its backward and uses it in `MambaMixer` training behind an opt-in `TransformerConfig.mamba_varlen_ssd_training` (default `False`).

The three commits match the three PRs proposed in #8852 and can be reviewed one at a time:

1. **Varlen SSD backward.** An in-tree port of mamba_ssm v2.3.2.post1's SSD backward kernels with the same math, addressing chunks through `cu_chunk_seqlens` like the forward, with int64 offsets. The forward kernels are reused; they only gain optional output buffers, with unchanged defaults.
2. **Fused split + conv1d + varlen SSD autograd Function**, following `MambaSplitConv1dScanCombinedFn`. It keeps the same activations for the backward as the fused path and recomputes conv1d. causal_conv1d is imported on first use.
3. **`MambaMixer` integration.** With the flag set and `packed_seq_params` given, the mixer uses the fused varlen Function and honors `mamba_training_ssm_states_dtype`. The chunk layout is built once per microbatch and model chunk (one GPU sync each) and cached on `PackedSeqParams` as a plain attribute. Under local CUDA graphs, Mamba layers run eagerly on packed input; `full_iteration` graphs are rejected.

With the flag off, the only behavior change is a context-parallel check. Mamba uses the static CP group, and it now asserts when a microbatch's CP group (`local_cp_size`) has other ranks; until now, with a same-size group on other ranks, the fused path silently produced wrong rows.

Tests:

- Kernels: against an FP64 reference (output and all gradients), bitwise packing invariance, and a bit-exact replay under deterministic mode.
- Fused Function: output and input gradient bitwise equal to conv1d followed by the varlen SSD, and a deterministic replay.
- Mixer: packing invariance of the output and input gradient at TP=1, and of the `out_proj` input at TP/CP/SP up to 8 GPUs; agreement with the fused path; the CUDA graph and CP guards; a deterministic replay.

Like mamba_ssm's, the backward reduces with atomics by default; deterministic mode switches to ordered workspaces.
