# build: require patched virtualenv on main

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8457) · state: closed · merged: True

## Original PR description

Megatron-LM resolves virtualenv 21.14.5, which is affected by CVE-2026-113725 and CVE-2026-113722. Both concern command execution from attacker-influenced virtual-environment names or destination paths when users activate an environment or invoke a generated launcher.

Require virtualenv >=21.14.9 as a transitive dependency constraint and regenerate `uv.lock`. The lock now resolves 21.14.13, which includes both fixes.

Validation: `uv lock` and `uv lock --check` in the Megatron-LM CI container, plus `git diff --check`. CI remains pending.
