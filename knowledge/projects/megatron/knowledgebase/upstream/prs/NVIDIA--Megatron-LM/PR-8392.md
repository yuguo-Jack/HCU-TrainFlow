# Accumulate MFSDP v2 expert weight gradients directly into main_grad

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8392) · state: closed · merged: False

## Original PR description

For expert parameters whose DP-inner axis has size 1, let Transformer Engine write weight gradients directly into the persistent FP32 main_grad buffer. This removes the intermediate expert weight-gradient buffer and the subsequent copy or accumulation into main_grad.

The optimization is opt-in through --megatron-fsdp-fuse-expert-wgrad-accumulation. The first backward overwrites the buffer, subsequent microbatches accumulate into it, and gradient scaling is applied once during finalization. Deferred DP-outer reduction remains unchanged.

Validation:

- Full MFSDP v2 unit suite passed.
- DSv4 Flash HSDP completed 20 iterations on 128 GB200 GPUs with MXFP8, full-iteration CUDA Graph, and optimizer CUDA Graph.
- End-to-end validation used the combined optimization stack; no isolated performance gain is claimed for this PR.
