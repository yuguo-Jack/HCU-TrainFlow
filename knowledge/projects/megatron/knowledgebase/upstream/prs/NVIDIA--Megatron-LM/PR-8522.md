# Drop the FP8-only gc.collect() after checkpoint saves

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8522) · state: closed · merged: True

## Original PR description

Someone added a gc.collect() supposedly for reclaiming GPU memory allocated for dequantized tensors. However, I am unable to reproduce any excess GPU memory allocation that is recovered by this gc.collect, any dequantized tensors created in NVRx code are deleted when code returns from NVRx. Additionally, the check only tests for fp8, but misses other conditions where quantization may occur, e.g., fp4.

Dropping this gc.collect() saves about about 30% of the total exposed time (including finalize) as measured by telemetry data. This overhead never showed up in the logs as it was not measured by the timers.
