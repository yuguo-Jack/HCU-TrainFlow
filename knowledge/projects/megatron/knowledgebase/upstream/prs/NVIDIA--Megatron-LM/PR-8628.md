# What does this PR do?

Record Testmon baselines during the existing full merge-group unit tests and publish them from a CPU-only workflow after merging into main. Remove the six-hour scheduled GPU rerun.

- Preserve production coverage on every rank using the existing pytest-cov dependency.
- Upload recorded databases and producer metadata from successful merge-group buckets.
- On a main push, find a successful main-targeting merge group with an identical Git tree, verify the producer SHA/attempt and cache identity, and use the existing cache helper to validate and finalize main's caches. The shared cache helper and cache format are unchanged.
- Preserve main-push container cache refreshes and manual baseline regeneration through Populate CI build caches.

A main publisher is needed because caches saved directly on temporary merge-group branches are unavailable to normal PR runs. It preserves the existing cache path and gzip format, verifies publication, and skips superseded main pushes. Discovery checks the latest 100 merge-group runs and waits up to ten minutes for a matching run to complete. Missing producers retain existing caches; no tests run in the publisher.
