### Preserve converted vocabulary in compatibility metadata

**Failure:** [The saver now updates only the tokenizer config](https://github.com/NVIDIA/Megatron-LM/blob/95e892c25497cbfa7fa690a2852ee912b73d7c0e/tools/checkpoint/saver_base.py#L391-L420), but [checkpoint serialization still saves legacy args](https://github.com/NVIDIA/Megatron-LM/blob/95e892c25497cbfa7fa690a2852ee912b73d7c0e/megatron/training/checkpointing.py#L1669-L1674). For example, the [HF Mixtral loader supplies `padded_vocab_size=32000`](https://github.com/NVIDIA/Megatron-LM/blob/95e892c25497cbfa7fa690a2852ee912b73d7c0e/tools/checkpoint/loader_mixtral_hf.py#L48-L55). Conversion to TP=8 with divisibility 128 produces 32768-row weights/config, while saved `args.padded_vocab_size` remains 32000. [Loading with `--use-checkpoint-args` restores that stale value](https://github.com/NVIDIA/Megatron-LM/blob/95e892c25497cbfa7fa690a2852ee912b73d7c0e/megatron/training/checkpointing.py#L2501-L2507), constructing 4000-row shards for saved 4096-row shards and failing model-state loading. The base saver updated this compatibility field.

**Correction:** Keep repadding/model construction config-owned, but synchronize the legacy serialization contract. The smallest converter-local fix is this line after the imports and before saving in [save_local_models_to_checkpoint](https://github.com/NVIDIA/Megatron-LM/blob/95e892c25497cbfa7fa690a2852ee912b73d7c0e/tools/checkpoint/saver_base.py#L345-L367):

```python
self.margs.padded_vocab_size = self.cfg.tokenizer.padded_vocab_size
```

The invariant is that saved compatibility vocabulary describes the tensors being saved, not source-checkpoint padding.

**Preservation / acceptance:** Propose a round trip with 32000 source rows, TP=8 and divisibility 128: model, config and saved args must all describe 32768 rows; reloading with `--use-checkpoint-args` must load 4096 rows per shard. Also cover unchanged padding, trimming larger source padding, and `true_vocab_size=None` retaining the original row count. Preserve original token rows, final-row replication for added padding, and the target-derived parallelism assertions in [test_checkpoint_saver_target_args](https://github.com/NVIDIA/Megatron-LM/blob/95e892c25497cbfa7fa690a2852ee912b73d7c0e/tests/unit_tests/tools/checkpoint/test_checkpoint_saver_target_args.py#L13-L37).
