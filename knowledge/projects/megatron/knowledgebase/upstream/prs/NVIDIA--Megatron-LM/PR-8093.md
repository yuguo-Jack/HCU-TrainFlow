# Quote output paths in generated local test scripts

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8093) · state: open · merged: False

## Original PR description

Generated local scripts interpolated --output-path unquoted into an export. Spaces or quote characters broke the script, and dollar signs were expanded instead of preserved. Quote the fixed output-directory portion while leaving UUID generation active.

Validation: actual script generator writes launch scripts which are executed by /bin/sh with space, apostrophe and dollar-sign paths. All three cases fail on baseline and pass after the fix. No training/GPU execution is claimed; Ruff, Black and isort pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
