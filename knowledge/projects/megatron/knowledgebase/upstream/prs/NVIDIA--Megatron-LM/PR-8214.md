# fix(inference): support batch-invariant Mamba prefix caching

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8214) · state: closed · merged: True

## Original PR description

## What changes

Enable prefix caching for batch-invariant Mamba inference when KV blocks align with the SSM scan chunks. Previously this combination was rejected, and the batch-invariant mixer skipped publishing intermediate states.

Cache complete-chunk FP32 SSM states using the existing extraction path. Restored prefixes start at the same scan boundary as uncached prefill; suffix prefill initializes the partial-tail replay buffers. Keep the FP32-state and non-speculative-decode requirements, and reject misaligned cache block sizes.

Also fix cached suffix scheduling: a 600-token prompt with 512 cached tokens and an 88-token compute budget previously rounded to zero and could wait indefinitely. The scheduler now excludes the cached prefix when applying the compute budget, while returning the full request span.

## Validation

- Seven targeted GPU regressions passed on one GB200 with Transformer Engine 2.19: four graph/chunking combinations plus cache-alignment and scheduler tests.
- Tiny BF16 hybrid model compares generated tokens and log probabilities exactly against uncached eager inference, including reordered batches, aligned and one-token suffixes, warm cache hits, and invalidation after a weight update.
- Standalone all-features probe exercised 18 graph steps and skipped 1,536 cached prefix tokens with exact token/log-probability parity.
- Kernel determinism coverage check passes with the new parity test registered.
- On current main, a broader run passed 90 tests before stopping at two existing TP4/PP4 cases requiring four ranks (this run used one). The four new GPU parity cases passed again.

Local runtime uses NeMo-RL's existing compatibility shim to enable its installed FlashAttention 4 beta. Full-model and multi-GPU reproducibility remain to be validated; these tests do not establish invariance across TP/EP configurations.

Needed by the deterministic GRPO draft https://github.com/NVIDIA-NeMo/RL/pull/4723. No dependency pins changed here.
