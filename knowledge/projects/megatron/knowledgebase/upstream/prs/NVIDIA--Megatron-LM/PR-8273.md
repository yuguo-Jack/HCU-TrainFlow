# What does this PR do?

Integrates Lens as an optional dependency and establishes Megatron's telemetry Resource, initialization, and child-process propagation contract.

This is PR 1 of 7 in the telemetry stack.

## Summary

- Composes launcher, Slurm, and Megatron attributes through the Lens Resource API.
- Publishes the resulting Resource to child processes for the trainer lifetime and restores the inherited environment exactly during teardown.
- Keeps telemetry optional and leaves application behavior unchanged when it is disabled or unavailable.
