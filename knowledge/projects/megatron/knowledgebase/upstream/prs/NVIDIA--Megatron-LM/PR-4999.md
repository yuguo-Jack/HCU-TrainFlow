# What does this PR do?

PR 3/4 of the scaling-recipes split requested in #4381. This builds on #4829 and the canonical
  width-MuP recipe PR.
Design doc: [PR_MuP.pdf](https://github.com/user-attachments/files/27854711/PR_MuP.pdf)

References: [1/4]: #4829, [2/4]: #4998, [4/4]: #5000

  Intended delta for review:
  https://github.com/plugyawn/Megatron-LM/compare/feature/scaling-recipe-mup...feature/depth-mup

  Because stacked PRs are not enabled in this repository, this PR is opened against `main` to track the intended progression, but the intended review delta is the comparison above.

  This PR adds an experimental `depth_mup` recipe for dense GPT-style residual transformers with
  Adam/AdamW.

  The recipe applies:
  - residual branch multiplier: `depth_mult^-1`;
  - hidden matrix-like LR depth multiplier: `depth_mult^0`;
  - hidden Adam epsilon depth multiplier: `depth_mult^-1`;
  - dense block output-projection init compensation: `depth_mult^+0.5`.

  The init compensation is included because Megatron already has layer-count-based residual output-
  projection initialization; this keeps the initialization behavior from double-counting depth while
  making residual branch scaling explicit in the forward graph.

  Supported surface in this PR:
  - dense GPT-style residual transformer blocks;
  - Adam/AdamW-style optimizer semantics;
  - standard next-token training.

  Explicitly out of scope for this first version:
  - SGD depth-MuP;
  - MTP depth transfer;
  - MoE/hybrid/Mamba depth transfer;
  - cross-attention and experimental attention variants;
  - general inference semantics.
