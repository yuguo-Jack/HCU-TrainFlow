# What does this PR do?

Migrate DDP/FSDP wrapper settings and consumers to `cfg.ddp` as part of training-loop configuration consolidation (C09).

- Use the resolved wrapper config for construction, bucket/layout settings, communication hooks and checkpoint backend selection.
- Retain the Torch FSDP2-specific schema and all existing CLI flags. Keep `use_megatron_fsdp` only in `cfg.ddp`.
- Centralize wrapper validation and cross-config derivation. Optimizer-owned overlap settings remain authoritative in `cfg.optimizer`; runtime copies keep bucket/timer mutations out of serialized configuration.
- Preserve existing optimizer extension hooks and add behavioral coverage in existing test modules.

This remains a draft. It does not change GPU kernels or introduce a new checkpoint format. It overlaps #7778's removal of the duplicate distributed-init FSDP selector; retain that single-owner change when integrating either PR first.
