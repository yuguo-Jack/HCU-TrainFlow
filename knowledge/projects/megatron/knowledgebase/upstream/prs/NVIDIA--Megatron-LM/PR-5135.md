## Original PR description

## Summary
- Enable latent MoE to use shared expert overlap with A2A/Flex dispatchers by running shared-expert pre-comm on full hidden states in `MoELayer`, while keeping shared-expert FC launches inside dispatcher overlap windows.
- Keep dispatcher-owned shared-expert pre/post handling for the non-latent path only, and add the latent shared-expert output after `fc2_latent_proj`.
- Add forward/backward parity coverage comparing shared-expert overlap vs no-overlap for latent A2A and HybridEP.
