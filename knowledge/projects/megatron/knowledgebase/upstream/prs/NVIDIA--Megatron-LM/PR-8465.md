# fix: backport MFSDP v2 EP checkpoint support to core_r0.20.0

# What does this PR do?
Backport #8230 to `core_r0.20.0` so MFSDP v2 can save and resume expert-parallel MoE checkpoints. Previously, a BF16 EP=2 run could train successfully but fail at its first save with `NotImplementedError: MFSDP v2 optimizer checkpointing does not support expert parallelism yet`. Loading now also refreshes compute weights from restored main weights before the next forward.

Two source commits are cherry-picked without content conflicts or release-specific code changes:

- #8230: `db3a6cd8a03eb550e9fa4532a0db96778bb56fc5` — checkpoint fix and regression tests.
- #8326: `74c9420e35cc3c1226e53421f5ff718653aa8399` — required test setup/teardown follow-up. With #8230 alone, running its EP checkpoint test first reproduces `Backend can not be changed after use` in the next expert-parallel test. This follow-up selects the backend through the shared fixture and clears cached DTensor meshes before destroying groups.

The release already contains the required runtime APIs. No other main-branch changes are included. Independent review of the complete release diff found no remaining actionable code issues.

## Validation

On two RTX 6000 Ada GPUs, PyTorch `2.13.0a0+8145d630e8.nv26.06`, Transformer Engine `2.17.1+4329ff84`:

- Checkpoint, optimizer-checkpoint, expert-parallel, annotation, and DBuffer files: **61 passed, 37 skipped per rank**.
- EP-first ordering that failed before #8326: **50 passed, 37 skipped per rank** after including it.
- `BASE_REF=core_r0.20.0 CHECK_ONLY=true SKIP_DOCS=false bash tools/autoformat.sh`: Black, isort, Pylint, and Ruff passed. Its nonblocking mypy step reports 19 annotation errors in two files; the release versions of those files also report 19, with an added diagnostic on `finish_grad_sync()` replacing one in the removed helper.
- `git diff --check` passed. Both commits are signed and include Chen's sign-off.

This exercises the TE <2.18 compatibility path. TE >=2.18, EP=4, EP>1 with expert-DP size greater than one, and end-to-end training were not run locally. Tests requiring additional ranks skip; full CI remains pending.
