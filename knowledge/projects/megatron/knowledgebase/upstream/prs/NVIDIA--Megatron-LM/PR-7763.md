# Fix modality MoE padding routing and selective recompute

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7763) · state: open · merged: False

## Original PR description

Stacked on NVIDIA/Megatron-LM#7502.

## Summary
- Keep dispatcher rows for padded tokens, zero their routing probabilities, and exclude them from load-balancing counters.
- Reuse the regular MoE checkpoint path for selective recompute in the modality MoE layer.
- Skip expert-bias collectives when the update rate is zero.
- Pad the shared expert's token dimension to the FP8/FP4 GEMM alignment and slice the output back, in both the plain and the overlapped forward. THD packing leaves the token count arbitrary, and TE's FP8 linears reject it (`dims=[639, 1, 5120]`). Without FP8 or FP4 nothing is padded.
- Add unit tests in `tests/unit_tests/models/test_deepseek_v41_components.py` and `tests/unit_tests/transformer/moe/test_shared_experts.py`.
