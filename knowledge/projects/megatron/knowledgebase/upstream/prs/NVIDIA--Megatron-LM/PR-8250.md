# fix(inference): AUT-2539 keep PP stages consistent when only some hold recurrent

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8250) · state: closed · merged: True

## Original PR description

## Background

With pipeline parallelism, a hybrid model can place only attention layers on some stages (for example `M*|**`). Each stage decided from its own layers whether it was a hybrid model, so the stages disagreed about Mamba prefix caching:
- With a Mamba prefix-cache budget (`prefix_caching_mamba_gb > 0`), initialization hung.
- With memory-only prefix caching, the attention-only stage could compute a different prompt-skip count than the recurrent stage.

## What changed

- `DynamicInferenceContext` gets a new `pipeline_has_recurrent_layers` attribute. The existing pipeline-parallel MIN all-reduce of the block count now also carries the local has-recurrent flag (as `has` and `-has`). From that, every stage learns whether any stage, and whether every stage, has Mamba/GDN layers. No collective is added.
- With a Mamba prefix-cache budget, a pipeline where only some stages are recurrent now raises the same `ValueError` on every stage.
- With memory-only prefix caching, `_compute_prefix_match` applies the recurrent-stage rule on every stage of a pipeline that has recurrent layers. All stages then skip the same number of prompt tokens.
- Three new unit tests are added, in `test_dynamic_context.py` and `test_dynamic_prefix_caching.py`.

## Details

The Mamba-budget case is rejected rather than allowed to finish initializing, which differs from the review suggestion. An attention-only stage holds no Mamba state, so it cannot follow the recurrent stage's Mamba-state cache hits. Letting it continue would make the stages process different token counts for the same request. Uniform layouts, where every stage or no stage has recurrent layers, behave as before.

The two review findings on 3f74b3e0 are fixed in this head. The new device literal is now double-quoted, and the two-token assertion is back in the continuation test.
