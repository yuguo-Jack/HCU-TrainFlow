# Add CSA2 chunked scoring and selective recompute compatibility

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7761) · state: open · merged: False

## Original PR description

Stacked on NVIDIA/Megatron-LM#7500.

## Summary
- Compute no-grad CSA2 indexer scores in key chunks (`_chunked_csa2_indexer_scores`), so the full per-head score tensor is never materialized at once.
- Allow selective recompute with CSA2 as long as no attention modules (`core_attn`, `gdn_norm_out`, `gdp_qkv`, `gdp_in_proj`, `shortcut_pre_mlp_layernorm`) are recomputed. Full recompute is still rejected because it would re-publish cross-layer KV.
- Recompute single-pass mHC mappings instead of keeping their activations.
