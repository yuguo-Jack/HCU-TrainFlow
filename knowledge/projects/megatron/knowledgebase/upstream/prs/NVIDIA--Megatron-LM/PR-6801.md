# [dev] Add native transport and arbitrary-size dynamic context parallelism

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/6801) · state: open · merged: False

## Original PR description

Native-capable dynamic CP training can use arbitrary integer widths and contiguous rank intervals through one existing DP×CP parent communicator. Attention, MoE auxiliary reductions and MTP halos share TE's native arena; unsupported configurations retain classic ProcessGroups.

This is the functional second PR after #8495. Its **41-file, +3,360/-483** diff contains logical CP descriptors and capability selection, native attention/reduction/halo integration, arbitrary-CP packing and metadata/layout handling, and functional/determinism tests. The runtime adapter relaxes the scheduler's width/start restrictions only when native transport is available. Both solver implementations, all cost models/parameters, the CPU worker and async training integration live in #8495; the implementation under `models/` and `runtime/` has **zero diff** here. DynamicUSP retains its original aligned power-of-two allocation policy.

Dependencies: #8495 and NVIDIA/TransformerEngine#3420 (TE source `0eb52eef7893d7942a84ed8b08fd957beba8fb76`).
