Forward parity passes at both CP layouts; 121 unit tests pass against a 106-test PR4 baseline with no regressions. The seven remaining failures are gradient parity, which need a non-learned-K backward branch that PR4 removed.

# What does this PR do ?

This is a fifth PR that adds to the stack of 4 PRs for simplified DSA (whose bottommost PR is #7181)This adds CP support to simplified DSA. The approach is to AllGather(K) in the indexer, and AllGather K and V for attention.
