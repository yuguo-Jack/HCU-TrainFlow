# Fail the resource gate when the queue cannot be checked

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8098) · state: open · merged: False

## Original PR description

An unexpected queue/API error was logged and then the resource wait CLI exited successfully, allowing scheduling without a successful capacity check. Return a Click error for these failures while keeping existing retries for transient network/list errors.

Validation: actual CLI tests show the baseline incorrectly succeeds on a queue read failure; the fixed CLI fails with its error message. A temporary network failure still retries and succeeds. CPU-only fixtures; Ruff, Black and isort pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
