# Continue past incomplete result markers in batch logs

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8080) · state: closed · merged: False

## Original PR description

When a batch log contains an incomplete attempt followed by a completed attempt, result discovery returns None at the first missing or empty output directory. Continue scanning the log so a later valid result marker remains discoverable.

Validation: the new CPU log discovery regression fails on the baseline; both statistics utility tests pass with the fix. Black, isort and Ruff passed. GPU training was not run.
