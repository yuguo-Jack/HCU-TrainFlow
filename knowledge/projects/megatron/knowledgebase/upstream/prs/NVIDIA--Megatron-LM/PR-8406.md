# Add Flash Attention Perfect Precision (PP) attention for inference

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8406) · state: open · merged: False

## Original PR description

## Summary

Stacked on https://github.com/NVIDIA/Megatron-LM/pull/8405 (PP training). Because both branches are on a fork, this PR targets `main` and its diff includes the training PR; review only the commits after `a5ea9e3`.

Adds the inference half of Flash Attention Perfect Precision (PP): with `--attention-backend pp`, the dynamic engine runs PP for paged prefill, chunked prefill, decode, and MTP verify. Every path produces the same bytes as the PP training forward for the same token, because all of them use the same super-block partials and left fold (see `docs/developer/determinism/pp_attention.md`).

What is in it:
- `megatron/core/transformer/pp/decode_kernel.py`, `combine_kernel.py`, `decode_api.py`: split decode and verify. Each work item computes one super-block partial; a combine kernel folds them in super-block order, so the number of splits does not change the bytes.
- The prefill kernel reads Megatron's paged KV cache directly: each 256-token block is read as two 128-token pages, so the KV allocator does not change.
- `PPDotProductAttention` gets prefill/decode entry points; `Attention.flash_decode_and_prefill` dispatches to them next to FA4. The verify token count comes from the speculative depth. A static KV cache is rejected.
- Unwritten KV slots: the pool is `torch.empty`, so the kernels zero V rows past the last valid key of a partial tile (the 2-CTA prefill path orders this with a cluster fence). Output does not depend on pool contents.
- `is_inference_column_parallel_linear` returns `False` without Transformer Engine, so the engine runs without TE.

Testing (SM100 GPU, cutlass-dsl 4.8.0 and 4.6.2, 78/78 each, including the training tests):
- `tests/unit_tests/inference/test_pp_attention_inference.py`: prefill over the paged cache == chunked prefill == decode == verify(K) == training forward, byte for byte, at hd128/hd256 with GQA and split decode; CUDA-graph replay == eager; NaN- and Inf-poisoned KV pools give the same bytes as a randn pool.
- `tests/unit_tests/inference/engines/test_pp_attention_dynamic_engine.py`: the dynamic engine with PP serves the training forward's log-probs.

Commits are DCO-signed (not GPG-signed).
