# Accept current-directory output prefixes when merging datasets

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8092) · state: open · merged: False

## Original PR description

A bare output prefix such as merged is rejected because dirname returns an empty string and isdir("") is false. Interpret an empty parent directory as the current directory, consistent with Python file creation. The CLI regression executes the real parser with dataset storage imports isolated; dataset merging and GPU training were not exercised.

Validation: the focused CPU regression fails on the baseline and the complete regression file passes with the fix. Black, isort and Ruff passed for the test. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
