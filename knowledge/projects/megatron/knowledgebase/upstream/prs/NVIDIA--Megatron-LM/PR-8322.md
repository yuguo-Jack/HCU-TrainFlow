# Fix Torch GDN recurrent state allocation during CUDA graph capture

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8322) · state: open · merged: False

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Fix CUDA graph capture in `torch_chunk_gated_delta_rule` when no initial recurrent state is supplied. The existing `torch.zeros(...).to(value)` allocates an unpinned CPU tensor and copies it to CUDA during capture, raising `CUDA error: operation not permitted when stream is capturing`.

Allocate the state directly with `value.new_zeros(...)`, preserving its shape, device, and FP32 dtype. The supplied-initial-state path and recurrence are unchanged.

Add 16 regression cases covering FP32/BF16, sequence lengths 64/65, supplied/absent initial state, and optional final state. Each captures forward and backward, compares changed-input replays bit-exactly with eager outputs and gradients, and verifies repeated replay.

## Validation

- Reproduced the original failure with NeMo 26.10 RC5 on 8 GB300 GPUs using `qwen35_text_9b_pretrain_8gpu_gb200_bf16_deterministic_config`: three finite training iterations, then failure during TE graph capture. Original vocabulary 248077, global batch 128, microbatch 2, sequence length 4096.
- In the same RC5 stack, the candidate passed 16 isolated raw CUDA graph cases and four Transformer Engine `make_graphed_callables` checks, including forward/backward, eager parity, changed inputs, and repeated replay.
- Full-model validation on 8 GB300 GPUs with the candidate and the original recipe passed TE graph capture and completed all 10 training iterations with finite, unskipped losses (10th loss: 0.2513471246). Final validation/test evaluation also completed; all eight ranks returned successfully and the batch exited 0. The stock installed dependencies and exact Bridge commit are retained; only this function's allocation expression is replaced in memory after an exact-source check.
- Kernel determinism coverage check, Black, isort, pylint, Ruff, and `git diff --check` passed. The `autoformat.sh` wrapper requires Git >=2.31; this workstation has 2.25.1, so its tools were run directly. Advisory mypy checks remain limited by unavailable workstation GPU dependencies.
- The full pytest module has not been run on current main. All 16 cases of the new regression function passed when exercised directly in the RC5 GPU validation job.

RC5 MCore: `e30d863a6d82a3c45f2d71355dc73fbf5610967b`. Bridge: `3b91885d5411e4a2f198066c88eb2104da99b12f`. The current-main function and the RC5 function are identical before this one-line change.
