## Integration-only adjustments

- Fork #43 and fork #44 inserted independent regressions at the same location in the shared async test file. Their single textual conflict retains both reviewed test blocks unchanged.
- Legacy partial-engine fixtures now provide the pending-logit state that every fully initialized engine owns, and verify that recompute clears it.
- Current `main` uses an explicit test-helper opt-in for MoE layer construction. The aggregate enables it only for the async matrix's actual MoE row; generic EP process-group tests remain dense.
- Current `main` routes unfiltered FlashInfer sampling through `sampling_from_logits`; the aggregate updates the test-only runtime witness to observe that kernel.
- An exploratory sampling-seed commit is followed by its exact revert and has no effect on the resulting tree.

No aggregate-only production behavior was added.
