# What does this PR do?

This PR adds native dynamic inference for simplified DSA over GQA, including paged KV caches, prefill, single-token decode, and mixed batches.

The Blackwell decode path combines Triton/Gluon indexer scoring, FlashInfer GVR2 topk, and Triton sparse attention.  The implementation also supports graph replay with changing token positions and active lengths, and manages decode workspaces across KV-cache suspend/resume.

## Performance

We also conducted the performance comparison between this PR (Triton/Gluon indexer + sparse attention with FlashInfer GVR2 topk against FlashInfer SDSA not public available yet):

| Prompt length | Batch per engine | FlashInfer SDSA (ms/step) | This PR: Gluon + GVR2 + Triton (ms/step) | Observed latency difference |
|---|---:|---:|---:|---:|
| ~32K | 8 | 7.372 | 7.400 | +0.38% |
| ~32K | 64 | 11.478 | 11.549 | +0.62% |
| ~200K | 8 | 7.7935 | 7.991 | +2.53% |


## Accurancy

**Checkpoint accuracy: current GVR2 path versus full FlashInfer SDSA**

The baseline uses FlashInfer indexer scoring, GVR2 selection, and TRTLLM-gen token-sparse attention. This PR uses the current Gluon indexer, public GVR2 selection, and Triton sparse attention. Both ran sequentially on the same four-GPU allocation.

| Benchmark | Coverage | Full FlashInfer SDSA | Current Triton + GVR2 | Difference (pp) |
|---|---|---:|---:|---:|
| GSM8K | All 1,319 test questions; 8-shot, greedy | 94.01% | 94.09% | +0.08 |
| MMLU-Pro | Guide 1,203-question subset; 5-shot CoT | 71.74% | 71.82% | +0.08 |
| MATH500, mean pass@1 | All 500 questions × 4 samples; 4-shot | 79.35% | 79.90% | +0.55 |
