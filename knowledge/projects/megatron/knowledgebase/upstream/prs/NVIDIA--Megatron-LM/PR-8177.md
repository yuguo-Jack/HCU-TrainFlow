# refactor(fsdp): Remove unused owner gather/scatter plans

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8177) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

The owner-compute P2P implementation sends tensor shards directly and never uses `OwnerGatherPlan` or `OwnerScatterPlan`. Remove these unused packing classes, their dedicated tests, and the packing-only test helper. Owner assignment and the gather/scatter API are unchanged.

Original owner-compute work by @janEbert. This addresses the [packing-plan cleanup discussion](https://github.com/NVIDIA/Megatron-LM/pull/7966#discussion_r4249530069). Related to #5533.

Validation:
- `test_owner_planning.py` and `test_gather_scatter.py` with two CUDA/NCCL ranks: 7 passed and 10 skipped per rank. The skipped cases require more ranks.
- Black, isort, pylint, Ruff, mypy, and `git diff --check` passed.
