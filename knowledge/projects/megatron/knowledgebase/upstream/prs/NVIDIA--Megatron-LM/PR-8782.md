# Hide more of the Muon optimizer step's communication

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8782) · state: open · merged: False

## Original PR description

Stacked on #8684, #8548 and #8547. Original Muon changes by @wujingyue in #8398.

## Changes

- Groups that need no communication skip gather/scatter; the first one runs before the gathers are posted and the others after the groups with communication.
- The momentum updates and gathers run on a side CUDA stream, so they overlap Newton-Schulz.
- All gathers are posted up front and the `lookahead` argument is removed.
- Rank ranges are computed once at construction and reused by `gather`/`scatter`.

## Results

DSV4-Pro, 7 layers, 64 GPUs, optimizer step window:

- GB200: 848 ms (#8684) -> 777-804 ms.
- GB300: 661-667 ms.
- Optimizer peak memory: 56.77 GiB.

## Tests

The whole `tests/unit_tests/distributed/mfsdp_v2` directory on 8 H100: 0 failures.
