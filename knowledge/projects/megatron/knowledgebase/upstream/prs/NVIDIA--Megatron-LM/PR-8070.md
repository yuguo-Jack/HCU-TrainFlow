# Preserve each recipe build image when no override is supplied

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8070) · state: open · merged: False

## Original PR description

When a selection depends on multiple builds (for example dev and LTS), load_workloads reuses the first source image for later builds because the fallback is assigned to the caller override variable. Resolve each fallback locally so every build keeps its own image, while an explicit override still applies to all builds.

Validation: CPU regression fails on the baseline for distinct images and passes with the fix; explicit override case also passes. Black, isort and Ruff passed. GPU training was not run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
