# Compute checkpoint replica ids over the module's own DP x CP group

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8044) · state: closed · merged: False

## Original PR description

**Why.** `sharded_state_dict()` called without metadata fills `metadata['dp_cp_group']` from the global DP x CP group. A model on its own grid, as built by tools, converters, tests or exports, then computes replica ids from another grid's ranks, so several ranks or none write each shard. Separately, a `tp_group` passed to the sharded-tensor helpers without a `dp_cp_group` makes every data-parallel rank a main replica.

**What.**
- `ensure_metadata_has_dp_cp_group(metadata, dp_cp_group=None)`: a group already in the metadata still wins; otherwise the given group, then the global default.
- `MegatronModule`, `MLP` (which keeps its `pg_collection`), `TransformerBlock` and `LanguageModule` pass their collection's `dp_cp_gtp_remat`, or `dp_cp` when unset: the group the global default stands for. One global read is removed.
- The last commit makes `make_sharded_tensors_for_checkpoint`, `make_tp_sharded_tensor_for_checkpoint` and `make_sharded_tensor_for_checkpoint` raise `ValueError` for a `tp_group` without a `dp_cp_group`. A `dp_cp_group` alone still means "not tensor-parallel". No in-repo caller is affected; the commit can be dropped if the restriction is unwanted.

**Tests.** With the global DP x CP accessor patched to raise, new tests compare `(key, global_offset, replica_id)` with the global default for an MLP, a transformer block and a GPT model at TP=2 and on a GTP=2 grid, and check the new error. Before the sync they failed on main and passed here on 4 GPUs, and distributed-checkpointing GPT and MLP, MIMO checkpoint and GTP DCP tests matched main. In the integration run on 4 GPUs, the two new test files give 8 passed and 1 skipped: `test_sharded_state_dict_dp_cp_group.py` 6 passed, `test_gpt_sharded_state_dict_dp_cp_group.py` 2 passed and 1 skipped. The skipped case is the GPT model with GTP-sharded weights, because the container's Transformer Engine is older than GTP needs. Neither file exists on main. In the integration run, this PR's test files show no regressions against main.

**Compatibility.** Replica ids on the standard grid do not change. MoE experts, hybrid/SSM mixers and TE layers still fill the global group; they follow per owner.
