# Fix stale pipeline recv buffer with block CUDA graphs

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8857) · state: open · merged: False

## Original PR description

Fixes #7829

## Problem

When using block-scoped CUDA graphs with pipeline parallelism, each forward pass allocated a new recv buffer tensor via torch.empty(). The CUDA graph captured the buffer address read through HybridStack.input_tensor (a Python attribute set via set_input_tensor()). Assigning a new tensor to that attribute did not update the captured address, so replay read **stale activations** from the previous forward's buffer.

This silently corrupted activations and generated tokens in hybrid inference. The bug affected all non-first pipeline stages when inference_cuda_graph_scope was set (e.g., 'attn', 'mlp', or 'full').

## Root cause

_allocate_recv_buffer() in abstract_model_inference_wrapper.py returns a fresh torch.empty() tensor on every forward. With block CUDA graphs:

1. First forward: allocate buffer A, receive activations X into A, capture graph reading A
2. Second forward: allocate buffer B, receive activations Y into B, replay graph
3. Graph still reads from A (stale X), not B (current Y) → **wrong output**

## Fix

Cache persistent recv buffers per (batch_size, seq_len) when CUDA graphs are enabled. _allocate_recv_buffer() now returns the same tensor across forward passes at the same shape, and recv_from_prev_pipeline_rank_ writes new activations directly into the cached buffer before replay.

The cache is only active when inference_cuda_graph_scope is not None, so eager prefill execution retains normal buffer lifetime semantics.

## Changes

- Add _cached_recv_buffers dict to AbstractModelInferenceWrapper.__init__
- Modify _allocate_recv_buffer() to cache and reuse buffers when CUDA graphs are enabled
- Add regression tests verifying buffer reuse, cache isolation, and correct behavior with/without CUDA graphs

## Testing

- Unit tests verify same-shape reuse, different-shape isolation, and no caching when CUDA graphs disabled
- E2e validation: 2-GPU PP=2 test with cuda_graph_scope='attn', same-shape decode replays with different activations
