# What does this PR do?

Adds opt-in, CUDA graph compatible Shortcut MoE inference overlap for GDP and FlashAttention layers. Serial inference remains the default, and existing training paths are preserved.

## Overlap schedule

Two CUDA streams execute independent branches:

- **Main:** mixer normalization, projections, GDP/attention, output projection, then shared experts.
- **Shortcut:** routing → NVLS all-gather → token/expert preparation → routed GEMMs → output reduction → NVLS reduce-scatter.

The streams fork from the pair input and join before the final routed/shared output and residual update.

**Prefill/mixed** use the ordinary atomic mixer forward, supporting chunked prefill and existing graph shape selection. **Decode** uses projection/core/post adapters for launch ordering. GDP and FlashAttention run once for the full batch. Block CUDA graphs capture both branches and their dependencies.

## Configuration

- `--inference-shortcut-moe-overlap`
- `--inference-shortcut-moe-expert-max-blocks 304`

The expert limit bounds the routed GEMM launch grid to reduce compute interference; it does not reserve SMs. Zero disables the cap. Serial and training ignore it.

Supported path: dynamic batching, BF16 `inference_optimized` language layers, TP=CP=1, vLLM fused grouped GEMMs, Triton NVLS, and GDP/FA predecessors. Unsupported combinations are rejected. Vision configs clear the language-only flag.
