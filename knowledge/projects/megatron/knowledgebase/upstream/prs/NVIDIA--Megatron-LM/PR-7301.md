# What does this PR do?

RL has a remote-environment server (`megatron/rl/server/agent/fastapi_env_server.py`) that runs an environment on another host, driven by the trainer over HTTP. Each request body carried the policy to generate through: the server picked a registered `InferenceServer` class by name and built it from body-supplied fields. Anyone who could reach the port could therefore make the env server send the environment's prompt to a host of their choice and treat the reply as the policy's output.

This PR fixes the policy endpoint at launch time instead. Separately, this codepath was already nonfunctional on `main`, and that is now fixed.

## The approach

 - The env server is provided `--policy-url` ahead of time, which points to a local Megatron Inference instance. Every remote route now generates through that same interface.
- The chat-completions client code is refactored so that the env server's request is formatted as expected before being received by the Megatron Inference engine.

- Remote rollouts are now driven one episode at a time! See second commit. This makes the pipeline treat a remote env like any local agent; it's basically an update to make this codepath obey the modern pipeline design. In fact, on `main` currently, the entire codepath being modified by this PR is entirely non-functional.
- Evaluation rollouts still work.
