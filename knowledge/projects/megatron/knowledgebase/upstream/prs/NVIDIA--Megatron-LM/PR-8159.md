## What does this PR do?

Fix Megatron-FSDP v1 mesh construction and checkpoint restart with non-interleaved pipeline parallelism.

With eight ranks and PP=2, the mesh helpers reshape all eight ranks using stage-local dimensions whose product is four. Include the outer PP axis in both FSDP and HSDP construction, then select the current stage and expert rank. Existing process-group consistency checks remain in place.

FSDP DTensor checkpointing also bypasses the block `sharded_state_dict()` methods that normally give pipeline layers global names. Two stages can consequently save different weights and Adam moments under the same `decoder.layers.0.*` keys. Add a shared handler that uses each layer's global `layer_number` for model tensors, optimizer state, and optimizer group metadata. Run it after fused-parameter, expert, and MTP processing on save and load, preserving the original tensor aliases for in-place loading. MTP retains its separate namespace.

Precision-aware v1 optimizers put gradients in `decoupled_grad`. Recognize that attribute when reducing shared embeddings across pipeline stages. Empty shards remain `None` for the optimizer, while synchronization retrieves their metadata-bearing buffer tensors so every DP rank participates.

Existing checkpoints affected by stage-local key collisions cannot recover the omitted weights and must be regenerated. The new checkpoint remapping applies only to v1; v2 optimizer keys are already global and must not be renamed again. PP=1 checkpoint names remain unchanged. The existing default missing-weight validation rejects incomplete legacy checkpoints.
