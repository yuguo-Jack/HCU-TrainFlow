# Fix MFSDP v2 sharding boundaries for shortcut MoE blocks

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7781) · state: closed · merged: False

## Original PR description

## What does this PR do?

Fix MFSDP v2's wrapping of `ShortcutMoEBlock`. The block calls its attention layer's two-stage methods and its MoE layer/MLP's routing methods directly, bypassing their `__call__` hooks. Wrapping those layers separately leaves their parameters sharded when shortcut execution accesses them; wrapping only their parent cannot gather parameters already owned by child FSDP units.

Make the shortcut block the FSDP unit for these parameters, and exclude its directly invoked attention layer, MoE layer, and MoE MLP from child-unit selection. Experts retain their separate expert-DP units. Other explicitly selected children, such as norms invoked through `__call__`, can still be units.

Stacked on #7809, reusing its real `HybridModel` EP test and process-group fixtures. This diff switches the shortcut cases from explicit block-only wrapping to automatic wrapping, including broad explicit child selection. All six preceding variants retain prefetch, five-step loss parity, overlap/recomputation coverage, and ownership/mesh assertions.
