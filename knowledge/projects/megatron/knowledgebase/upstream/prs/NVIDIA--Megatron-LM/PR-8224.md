# [DSv4.1] CSA2 Full/Reindex/Reuse and bounded candidate indexing

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8224) · state: open · merged: False

## Original PR description

Add BF16 and MXFP8 CSA2 ratio-1/ratio-2 compression with Full/Reindex/Reuse ownership, bounded candidate scoring, indexer loss and fused attention. Reuse main's packed metadata and contiguous CP primitives. Score tiles use up to 2048 query rows under the existing 32 MiB cap.

The MXFP8 indexer path adds rowwise quantization, packed scales and SM100 cuDNN scoring. Attention/indexer supervision retains its existing higher-precision path. Model-specific version checks belong to #8226.

Independent prerequisite based on main. CSA2 math comes from @hxbai in #7224; main-side composition comes from @guihong-nv in #7500.

Validation: H100 r1/r2 forward/backward parity, ordinary/candidate chunk parity, CP1/CP2 packed parity, graph replay and 16K CP2 training/eval passed. MXFP8 selection and the assembled 16-GB200, TP1/PP2/VPP4/EP8/CP4, 16K proxy completed with both BF16 and MXFP8 recipes. The assembled run includes other prerequisite PRs and MoK; it is not standalone validation of this PR against current main. Production and test files in the published assembled branch match the GPU-tested source.

Existing test fixes retain numerical assertions: FlashMLA availability is checked before launch, FP32 PP parity explicitly selects IEEE GEMMs, and THD parity uses nonblocking NCCL communicators for CP teardown.

This branch still needs reconciliation with newer main changes; the publication preserves the tested baseline.
