# [DSv4.1] CSA2 Full/Reindex/Reuse and bounded candidate indexing

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8224) · state: open · merged: False

## Original PR description

Add CSA2 ratio-1/ratio-2 compression with Full/Reindex/Reuse ownership, BF16 bounded candidate scoring, indexer loss and fused attention. Reuse main's packed metadata and contiguous CP primitives; dev-only MXFP8 workspace APIs are outside this change.

Independent prerequisite, based on main. CSA2 math comes from @hxbai in #7224; main-side composition comes from @guihong-nv in #7500.

Validation on H100: real Full/Reindex/Reuse forward/backward parity for r1/r2; output cosine >=0.999993 and meaningful gradient cosine >=0.9999356 in the wrapper audit. CP1/CP2 outputs matched for single and padded multiple documents; gradient cosine >=0.99999. The assembled stack completed 16K single-document CP2 training/eval with sparse indexer loss. Black/isort/Ruff/Pylint and diff checks passed.

Existing Hybrid registry/default snapshots are updated. Real r1/r2 parity passed on eight H100 ranks; the test reports skip only when the installed FlashMLA binary lacks kernels for the GPU (the standard CI image disables SM90). Numerical assertions are unchanged.

Score tiles now use up to 2048 query rows while retaining the existing 32 MiB score-workspace cap. The 8K no-candidate Full/Reindex/Reuse probe improved from 60.45 ms to 48.34 ms with unchanged peak allocated memory. Both ordinary and candidate selection passed 128-vs-2048-query forward/gradient parity.
