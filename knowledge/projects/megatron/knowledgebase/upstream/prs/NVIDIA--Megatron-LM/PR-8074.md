# Recognize quoted YAML environment keys in golden checks

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8074) · state: open · merged: False

## Original PR description

The golden checker misclassifies valid quoted YAML ENV_VARS keys as deterministic, although the test pipeline reads them normally. Recognize matched single or double quotes around the three comparison-control keys.

Validation: Six quoted-key regression cases fail on baseline and pass fixed; the existing golden-checker suite passes all 35 tests. isort, Black and Ruff pass for the regression file. CPU tooling checks only; no GPU training or inference suite was run.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
