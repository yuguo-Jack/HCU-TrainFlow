# ci(autobot): enable comment reviews on ready transitions

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8368) · state: open · merged: False

## Original PR description

## Background / motivation

- Run an automatic Autobot review when a draft PR becomes ready for review.

## What changed

- Add `.github/autobot/review-config.yml` with:

```yaml
auto-review:
  enabled: true
  mode: comment
  on: status_change
  when: ready_for_review
```

## Details

- `status_change` selects draft/readiness transitions; `when` filters the resulting PR state.
- `mode: comment` publishes findings as a `COMMENT` review.
- CI-Events reads the policy from the default branch, so it takes effect after merge.
- Policy semantics: [CI-Events automatic-review documentation](https://github.com/NVIDIA-NeMo/CI-Events-Workflows/blob/2e210caf3db9fd6f7ab30d17282229ab5f86e681/apps/workflows/capability/review-github-pr/README.md#automatic-reviews).
