# ci: Select unit tests on CPU before GPU execution

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8331) · state: closed · merged: False

## Original PR description

PR unit-test selection currently occupies GPU runners before tests execute. This change adds a CPU selection matrix to `cicd-main.yml`, reads the compatible main Testmon baseline without importing the GPU suite, and uploads a plan for each bucket. The existing H100 and GB200 GPU jobs consume those plans; missing or invalid plans run the full bucket.

Baseline generation stays on GPU. Plans retain mandatory test mappings and are validated against the commit, bucket, image, runtime, and world size before execution. Empty selections still allocate the existing GPU runner but execute no tests, preserving the existing coverage flow. No reusable unit-test workflow or special Codecov status path is added.

Validation: 250 Testmon workflow, planner, cache, selector, mandatory-selection, and GPU-consumer helper tests passed on CPU. Ruff, Black check, and git diff --check passed. Actionlint introduced no new diagnostics relative to main; existing main-workflow diagnostics remain. Live GPU/CI execution has not been verified.
