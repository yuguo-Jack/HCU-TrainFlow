# What does this PR do?

Add opt-in CPU offloading for tensors saved by the BF16/FLA GDN recurrence. Enable it with `--fine-grained-activation-offloading --offload-modules gdn_core_attn`. It is disabled by default. The training CLI requires `NVTE_CPU_OFFLOAD_V1=1` with Transformer Engine 2.10 or newer.

## Issue tracking

Related to #6757 ([scope](https://github.com/NVIDIA/Megatron-LM/issues/6757#issuecomment-5965296779), [base guidance](https://github.com/NVIDIA/Megatron-LM/issues/6757#issuecomment-6008766114)). The submission branch is rebased onto `main` at `e30d863a6d82a3c45f2d71355dc73fbf5610967b`; recorded measurements retain their original source commits. #7852 covers projection/conv-QKV recomputation and convolution-input offload; recurrence saves remain independently selectable.

## Implementation

- Reuse the existing manager, pool and streams. Capture FLA recurrence saves and commit on the raw recurrence output before gated normalization, preserving storage aliases retained by upstream operations.
- Anchor prefetch to an input that requires gradients so frozen Q remains supported. Bypass evaluation, no-grad and fully frozen recurrence execution. Preserve warmup across initial evaluation, select no transfers at fraction zero, and advance chunks by remaining forward groups.
- Order fallback H2D after D2H completion and pooled D2H writes after queued H2D reads. Delayed-copy regressions reproduce both races, including wrong-payload restoration from premature pinned-slot reuse.
- Fix native pre-GDR gate gradients: fixed 128×16 tiles write independent FP32 partials, followed by one ordered reduction on the existing stream. Disabled-offload repeats reproduced gradient/Adam differences with atomic accumulation. Fixed tiling also removes fresh-process backward-autotuning variability. This applies to the existing opt-in fusion and adds no new configuration or manager component.

Support is BF16 GDN1 with `gdn_kernel_backend="fla"`, including selective `gdn_norm_out` recomputation. The explicit backend check rejects Torch and Transformer Engine recurrence backends before model construction; the Qwen tool selects FLA for both disabled and offloaded baselines. Configuration rejects GDN2, non-BF16/quantized execution, the deterministic Torch reference, full-layer recomputation and CUDA graphs. Full pre-GDR fusion still rejects `deterministic_mode=True`.
