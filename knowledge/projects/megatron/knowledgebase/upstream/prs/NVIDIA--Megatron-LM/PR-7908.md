# What does this PR do?

Add opt-in `gdn_core_attn` activation offloading for BF16/FLA GDN training, using the existing manager, transfer streams and pinned-memory pool.

Enable with `--fine-grained-activation-offloading --offload-modules gdn_core_attn`. With TE 2.10 or newer, set `NVTE_CPU_OFFLOAD_V1=1` before launch. The scope wraps the FLA recurrence and commits before output normalization. A differentiable recurrence input anchors backward prefetch; shared inputs are not force-released. Evaluation, no-grad and fully frozen recurrence execution bypass the scope.

Selective `gdn_norm_out` recomputation and existing pre-GDR fusion are supported. GDN2, FP8/FP4, non-BF16 execution, other recurrence backends, full recomputation and CUDA graphs are rejected. GDN2/TE graph support is proposed in #8308.

Includes a saved-tensor profiler/benchmark and a local-Qwen training tool with native checkpoint save/load. Megatron Bridge is required only by the Qwen tool. See [usage and reproduction commands](https://github.com/Pinoeer-kingxi/Megatron-LM/blob/ff3994e08d65249bbbcb08fb2946d51961fd3365/docs/developer/gdn_activation_offloading.md).
