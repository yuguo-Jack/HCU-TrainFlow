# fix(inference): refresh EP consensus every step when there is no expert parallelism

# What does this PR do?

Fixes a prefill-engine crash in disaggregated serving of hybrid models: `AssertionError: No free recurrent-state slots for 1 expert-parallel dummy request(s)`.

`run_engine_with_coordinator` reuses the last EP work/pause consensus for up to `ep_consensus_interval` (20) iterations while that consensus showed work, to amortize the EP all-reduce. The cache was also used when the EP group has a single rank, where the consensus is just the local work count. When an EP=1 engine drained inside that window, it acted on the stale `global_work > 0` and called `controller.dummy_forward()`, an expert-parallel dummy step with no peers to join.

On hybrid models the dummy step needs a recurrent-state slot. Only EP > 1 contexts reserve a dedicated dummy slot, so EP=1 allocates from the request pool. A disaggregated prefill engine detaches each finished request's Mamba slot until decode releases the handoff, and the coordinator admits up to `max_requests` such handoffs, so with decode saturated every slot can be held while the prefill engine has no local work. The stale dummy step then fails and kills the engine. Reproduced with Nemotron-3-Nano, three TP=1/EP=1 prefill engines and one decode engine on one GB200 node, at 36-40 req/s.

The fix refreshes the consensus every step when `ep_world_size == 1`. The consensus is local and free there, so global work equals local work and the dummy branch cannot be reached without peers. EP=1 engines also stop running up to 19 idle dummy forwards after each drain and act on a pause at the next iteration. EP > 1 behavior (amortized consensus, reserved dummy slot, CUDA-graph replay of the dummy step) is unchanged.

## Testing

- New tests in `tests/unit_tests/inference/test_disagg_handoff_lifecycle.py`:
  - `test_idle_prefill_without_expert_parallelism_skips_dummy_forward` runs the real coordinator loop on an EP=1 disaggregated prefill engine that drains inside the consensus interval and asserts no dummy forward. It fails without the fix at `dynamic_engine.py:5237` with the production error message.
  - `test_idle_expert_parallel_rank_keeps_amortized_consensus_dummy_forward` (EP=2, busy peer) asserts the amortized consensus and dummy forwards are unchanged.
- Existing suites on GB200 (4 GPUs per node, so 8-rank parametrizations skip or error): disaggregation handoff/coordinator/scheduler/engine-factory/mamba-metadata 172 passed; data-parallel and prefix-caching coordinator 102 passed (1 error: a tp2-pp2-ep2 case needing 8 ranks); `test_dynamic_context.py` 165 passed; `test_dynamic_engine.py` 260 passed, 3 skipped.
- End-to-end reproducer (3 prefill + 1 decode, Nemotron-3-Nano, 4096-token prompts, 256 output tokens): unfixed, 1027 errors at 36 req/s and all 2400 requests failed at 40 req/s; fixed, 2160/2160 and 2400/2400 completed with 0 errors.
