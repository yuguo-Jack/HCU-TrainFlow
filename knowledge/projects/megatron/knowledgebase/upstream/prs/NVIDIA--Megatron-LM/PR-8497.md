# Support routed-only MoK, SiTU-GLU, and TP for latent MoE

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8497) · state: open · merged: False

## Original PR description

## Summary
- Add a native shared-expert mode: MoK handles routed experts, while MCore retains shared experts and latent projections with their native precision handling.
- Pass SiTU-GLU activation parameters to MoK independently of shared-expert fusion.
- Support TP with sequence parallelism and ETP=1 for routed-only MoK.

## Validation
- BF16/MXFP8 MoELayer checks and DeepSeek/Qwen regression tests passed.
- Validated the Kimi K3 9-layer MXFP8 proxy on 64 GB200 GPUs with TP4, EP64, and CP16.

Requires the companion MoK routed-only and SiTU-GLU changes.

File: `megatron/core/transformer/moe/moe_layer.py` · line 927

**Exercise the native-shared/latent branch through forward and backward.** The added [MoELayer test](https://github.com/NVIDIA/Megatron-LM/blob/0e3f344b7cc46e69fde09440c1934a5a24ba163d/tests/unit_tests/transformer/moe/test_moe_layer.py#L28-L79) stops after construction. The [adapter tests](https://github.com/NVIDIA/Megatron-LM/blob/0e3f344b7cc46e69fde09440c1934a5a24ba163d/tests/unit_tests/transformer/moe/test_mok_megakernel.py#L492-L606) invoke MoKMegakernel separately. Consequently, omitting a latent projection or the shared-output addition from this new branch would still pass the added tests; existing latent/recompute tests do not enable MoK.

**Correction:** add a regression around `MoELayer.forward`. A differentiable three-argument routed-backend stub is sufficient to test integration without the companion package. For model width 128 and latent width 64, verify that routing/shared computation receive width 128, the backend receives width 64, and the result equals `fc2_latent_proj(backend(fc1_latent_proj(x), ...)) + shared_experts(x)`. Fail if any native dispatcher method is called. Backward must reach both projections, the shared expert and the input.

**Preservation / acceptance (proposed, not executed):** cover no shared expert, forced-native shared without latent projections, and compatible fused shared execution, which must not compute shared experts twice. Include TP2/SP with ETP1 and rank-distinct token shards: outputs retain each rank’s local input shape, and finalized replicated-projection gradients match a reference over the combined shards. Include recompute on/off with matching outputs and gradients. These checks establish the new composition and TP behavior rather than merely successful construction.

- svcnvidia-nemo-ci · comment · 2026-10-28T07:00:22Z · [source](https://github.com/NVIDIA/Megatron-LM/pull/8497#discussion_r4397766484)

File: `megatron/core/transformer/moe/megakernel/mok/runtime.py` · line 131

**Add real-kernel bit-exact replay coverage for the new MoK modes.** Passing `situ_beta` and allowing absent shared weights changes external GPU dispatch, but the new [contract cases](https://github.com/NVIDIA/Megatron-LM/blob/0e3f344b7cc46e69fde09440c1934a5a24ba163d/tests/unit_tests/transformer/moe/test_mok_megakernel.py#L522-L553) replace forward with an input clone and backward with synthetic gradients. Numerical or replay failures in the new modes therefore remain undetectable. No kernel replay test or manifest is present under the head tree’s determinism test directory. The selected light-review rubric explicitly requires a bit-exact test and manifest registration for changed external-library dispatch.

**Correction:** add a real-MoK replay test under the required kernel-test directory and register this dispatch in its manifest. The invariant is byte-identical output and gradients for identical executions—not just correct keyword forwarding. Exact test implementation depends on the companion package and supported hardware, which are unavailable here.

**Preservation / acceptance (proposed, not executed):** use fixed nonzero inputs, weights, probabilities and routes; reset gradient buffers before at least three forward/backward replays; compare raw bytes of output, input/probability gradients and every routed parameter’s `main_grad`. Cover routed-only BF16 and MXFP8 SiTU with nondefault betas, plus a fused-shared SwiGLU control retaining shared FC1/FC2 and optional output-gate gradients. Retain the existing mocked assertions for absent shared weights/gradients, gate/up aliases and DDP accumulation. Make dependency/hardware skips explicit rather than replacing numerical execution with stand-ins.
