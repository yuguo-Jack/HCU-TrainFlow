# Enable colocated heterogeneous MiMo training

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/5839) · state: open · merged: False

## Original PR description

## What does this PR do?

Enable end-to-end colocated heterogeneous MiMo training for the PP=1 path. Encoder and language-model modules can share every physical rank while retaining their own TP/DP/EP process-group collections and RNG streams.

The existing non-colocated path remains unchanged.

## Design

- Add an explicit `--mimo-layout colocated` mode and validate that both module grids cover the world with PP=1 and CP=1.
- Construct both MiMo children through the existing public `ModelBuilder.build_model` override point, then DDP-wrap them with their existing `ProcessGroupCollection` objects.
- Select `expt_tp` for homogeneous expert optimizer buckets when a collection provides it, including existing homogeneous MoE callers with ETP != TP. Mixed Megatron-FSDP buckets continue to use `tp`.
- Derive colocated mock-data lanes from the actual `HyperCommGrid` TP-rank enumeration used by `ColocatedBridgeCommunicator`, rather than assuming process-group local-rank ordering.
- Namespace the existing singleton CUDA RNG tracker per module and enter the namespace only at child construction and stochastic forward boundaries. The core API documents its dynamic-scope contract and rejects TE, stateless inference, and CUDA-graph trackers; recompute callers must explicitly re-enter the namespace.
- Reuse the existing top-level `torch_dist` RNG checkpoint state. No checkpointing files or new checkpoint schema are introduced.
- Route colocated mock batches for both DP fan-in and fan-out, including deterministic loader resume offsets.
- Add the small PP=1 schedule-selection seam needed when heterogeneous bootstrap intentionally leaves global MPU pipeline state unset.
- Keep communicator teardown attached to the raw `MimoModel`, even when a pre-wrap hook returns an outer replacement.

## Validation

- H100 focused unit gate: 41 passed, with 3 expected 8-GPU skips (Slurm 14090596).
- H100 heterogeneous-vs-equal-DP correctness oracle: all 8 fan-in/fan-out, uniform/asymmetric-mask, and 1/4-microbatch cases passed (Slurm 14089268).
- H100 fan-in fresh training plus `torch_dist` checkpoint/resume: golden comparison and exact iteration 3/4 resume comparison passed (Slurm 14090657).
- H100 fan-out fresh training plus `torch_dist` checkpoint/resume: golden comparison and exact iteration 3/4 resume comparison passed (Slurm 14090656).
- Black, isort, Ruff, Python compilation, and diff checks passed.
- Independent builder lifecycle, optimizer/RNG correctness, and full-PR minimal-scope reviews completed twice with all findings addressed.

## Guarded v1 scope

Colocated training currently requires PP=1, CP=1, ETP=1, matching train/eval micro-batch sizes, `--rerun-mode disabled`, `--data-parallel-random-init`, and non-fully-parallel `torch_dist` checkpoint I/O. Unsupported recompute, async save, rerun, TE RNG tracking, FSDP, DDP overlap, FP16, CUDA graphs, meta initialization, and related modes fail closed.
