# Fuse the shared-expert and residual adds after the MoE combine

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7943) · state: closed · merged: True

## Original PR description

In the EP all-to-all overlap path (`fine_grained_callables`), the combine node adds the shared-expert output to the combined routed-expert output in `MoELayer.postprocess` and then adds the residual in `mlp_bda`. Without dropout on the MLP output, run both adds as one Triton kernel that reads the three tensors once. The routed and shared expert outputs are summed and rounded to the activation dtype before the residual is added, so the output and the gradients are bit-identical to the unfused adds. The unfused path is kept for dropout, a custom `mlp_bda`, mixed dtypes (e.g. an FP32 residual) and non-contiguous tensors.
