# What does this PR do?

OpenTelemetry span bookkeeping makes the training loop harder to follow. This change moves the lifecycle helpers and their state into `megatron/training/telemetry_spans.py`, so training code keeps the call sites while startup, checkpoint-interval, and shutdown behavior stay together.

Startup timestamps and the configured SIGTERM drain mode are passed explicitly. Graceful termination flushes telemetry while training finishes its iteration and checkpoint; immediate termination closes spans and shuts telemetry down. Exit hooks remain idempotent across repeated calls.
