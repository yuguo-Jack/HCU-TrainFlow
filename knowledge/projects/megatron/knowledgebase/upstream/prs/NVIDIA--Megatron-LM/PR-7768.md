# What does this PR do?
Preserve MTP metric reduction groups across CUDA graph replays.

After logging clears the metric accumulators, eager forward restores `reduce_group` and `avg_group` through `save_metrics_to_tracker`. Graph replay only updates the tensors; it does not repeat those Python assignments. Clearing the groups therefore makes later logging intervals skip the required reductions.

Keep the group references when zeroing the accumulators. A subsequent eager forward still overwrites them. The regression test covers sum, average, and combined reductions across three logging intervals in eager and graph modes.
