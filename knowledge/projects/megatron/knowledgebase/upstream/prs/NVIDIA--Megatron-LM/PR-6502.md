# What does this PR do?

Converting a `torch_dist` checkpoint to `torch` with `--verify-integrity` carries that flag into the converted checkpoint's saved arguments, even though integrity checks only support `torch_dist`.

Clear `args.verify_integrity` after loading the source and before saving an unsupported output format. Keep it enabled when the target is `torch_dist`.

This change does not update the `run_config.yaml` sidecar or the separate `tools/checkpoint/convert.py` conversion path. The sidecar can still contain the source checkpoint settings.
