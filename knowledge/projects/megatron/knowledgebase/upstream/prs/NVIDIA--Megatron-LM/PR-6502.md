# What does this PR do?

Fixes `run_config.yaml` metadata when converting checkpoints. Conversion changes the legacy args, while the active config still contains the source checkpoint format and save path. For example, a `torch` checkpoint converted to `torch_dist` currently writes YAML that still says `torch`.

Serialize a shallow output snapshot with the actual checkpoint format and destination. Disable `verify_integrity` in that snapshot for formats that do not support it, so the YAML can be loaded again. Capture the output settings before async finalization and preserve the active config.

General run-config saving landed in #7344. This PR now covers the remaining conversion bug.
