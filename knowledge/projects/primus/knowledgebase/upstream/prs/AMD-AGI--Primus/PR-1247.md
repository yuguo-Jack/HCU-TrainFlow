# perf(qwen3): Qwen3-30B-A3B FP8 on MI355X to 40k tokens/s/GPU with Primus-Turbo tensorwise

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1247) · state: closed · merged: True

## Original PR description


# Description

This PR switches the Qwen3-30B-A3B FP8 MI355X example config to Primus-Turbo tensorwise FP8 and turns on the Turbo fusions. On `rocm/primus:v26.7`, 8× MI355X go from **28,581 to 41,633 tokens/s/GPU (+45.7%)**. The loss curve tracks the stock run, about 0.01 lower throughout (tensorwise current scaling here, delayed scaling in the stock config).

New in this PR:

* Fused QKV split + Q/K RMSNorm + RoPE for head_dim 128. The patch was GPT-OSS-only (head_dim 64) before.
* `turbo_fp8_permute`: the DeepEP permute hands the fused grouped MLP FP8 tokens, and takes its gradient back in FP8.
* A fix for `enable_turbo_attention_float8`, which failed on its first call.

**Requires Primus-Turbo main** (AMD-AGI/Primus-Turbo#555 and #556; verified at `67b8e093`). The Turbo in `rocm/primus:v26.7` and the `TURBO_COMMIT` in `tools/installation/setup.sh` predate both; with them, set `turbo_fp8_permute: false`.

## Results

`rocm/primus:v26.7`, 8× MI355X, EP8, MBS 8, GBS 512, seq 4096, mock data, 50 steps; performance is the mean of iterations 11–50.

| run                                          | ms/iter  | TFLOP/s/GPU | tokens/s/GPU | loss@50     |
| -------------------------------------------- | -------- | ----------- | ------------ | ----------- |
| v26.7 image (Primus + Turbo as shipped)      | 9172.0   | 650.3       | 28,581       | 10.79581    |
| this PR + Primus-Turbo main                  | 6296.6   | 947.2       | 41,633       | 10.78232    |

<img width="2100" height="825" alt="image" src="https://github.com/user-attachments/assets/5422688a-9a86-4f3e-a3c6-8b065a37efcf" />


Known issue: during development, 1 of 13 runs at `turbo_deepep_num_cu: 160` hit a NaN loss on one rank in the first few iterations; it did not reproduce in verification.

## Changes

* `examples/megatron/configs/MI355X/qwen3_30B_A3B-FP8-pretrain.yaml`: tensorwise FP8 on Turbo GEMM / grouped GEMM, `use_turbo_fused_qk_rmsnorm_rope`, `turbo_fused_grouped_gemm`, `use_turbo_fused_act_with_probs`, `turbo_fp8_permute` and `turbo_deepep_num_cu: 160`.
* `qk_rmsnorm_rope_patches.py`: accept the head_dims Turbo supports (64, 128) and TE RMSNorm. The patch is now switched on by `use_turbo_fused_qk_rmsnorm_rope` (new in `primus_turbo.yaml`, default false) instead of the `PRIMUS_FUSED_QK_RMSNORM_ROPE` environment variable, which no longer has any effect.
* `primus_turbo.py`: FP8 dispatch / combine in `PrimusTurboDeepEPTokenDispatcher` behind `turbo_fp8_permute`; FP8 attention fix.
* `primus_turbo.yaml`, `rocm_arg_validation.py`: the new `turbo_fp8_permute` flag (default false) and its validation.

## Tests

* New unit tests for `turbo_fp8_permute` validation and dtype selection, and for the `use_turbo_fused_qk_rmsnorm_rope` switch; the related Megatron unit tests pass ({UNIT_RESULT}).
* End-to-end runs above.
