# feat(worldmirror): add HunyuanWorld-Mirror stage 1 and stage 2 training

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1242) · state: closed · merged: True

## Original PR description

## Summary

- Add HunyuanWorld-Mirror to Primus as `third_party/HunyuanWorld-Mirror-rocm`, tracking Tencent `main`. Primus launches the upstream Lightning trainer through `train posttrain` and does not patch that checkout.
- Stage 1 trains the geometry heads from the public Hugging Face weights. Stage 2 loads the stage-1 checkpoint, freezes the geometry backbone, and trains the Gaussian head. Dataset roots come from environment variables (`HYPERSIM_DIR` and the validation sets).
- ROCm fixes stay in Primus and are applied in memory: aiter attention with an SDPA fallback, a float32 cast before `gsplat`, a boolean depth-confidence mask, and a scalar aspect-ratio sample for NumPy 2. `gsplat` is built by the post-train install hook.
- Validation that the mounted data cannot load is omitted: iBims (OpenCV cannot read EXR), Re10K novel view, and DL3DV.
