## Original PR description

# Description

The GPT-OSS-20B MLPerf example on `main` still launches the FP8 recipe and leaves off the MXFP4 optimizations that have since landed on `main`. This PR makes `examples/mlperf/gpt_oss_20b` run the MLPerf 6.1 submission recipe ([AMD-AGI/mlperf-training](https://github.com/AMD-AGI/mlperf-training) `small_llm_moe_pretraining/primus`, df80c7a) by default:

- MXFP4 + de-oscillation is the default `EXP`. The FP8 yaml stays selectable through `EXP` and keeps its schedule.
- The MXFP4 schedule matches the submission: LR 5.7e-4, min LR 5.7e-5, 117 warmup iterations.
- On by default for MXFP4 (each one has an env override in the yaml or config):
  - fused grouped MLP (fc1+GLU, fc2+dGLU and the grouped WGRAD);
  - forward and backward permute-quant fusion;
  - fused Q/K RMSNorm+RoPE;
  - residual RMSNorm V2 with MXFP4 QKV operands;
  - fused de-oscillation with direct QDQ;
  - BF16 router backward and Turbo cross entropy;
  - grad-buffer ownership with WGRAD overwrite;
  - fused AdamW (clip, BF16 gradient and BF16 writeback);
  - 32 DDP buckets;
  - BF16 Adam moments with the FP32 MCore master. `PRIMUS_USE_PRECISION_AWARE_OPTIMIZER=false` restores FP32 moments.
- The submission's RCCL CE ReduceScatter environment is set. RCCL only acts on it with the forced CE ReduceScatter knobs from ROCm/rocm-systems dde68f30. RCCL 2.30.7 in v26.8 and rocm-systems develop ignore `RCCL_FORCE_CE_REDUCESCATTER`. On develop, CE ReduceScatter needs `MEGATRON_GRAD_REDUCE_BACKEND=rccl_sdma` instead.
- `MLLOG_LOWEST_NUMERICAL_PRECISION_IN_LINEAR` follows the selected recipe.
- `run_with_docker.sh` passes `EXP`, `MEGATRON_GRAD_REDUCE_BACKEND` and `PRIMUS_USE_PRECISION_AWARE_OPTIMIZER` to the config, so the recipe-specific settings follow host overrides.
- `PRIMUS_WEIGHT_DEOSC_START_STEP` and `PRIMUS_WEIGHT_DEOSC_LOG_FREQ` override the de-oscillation start step and logging.

This covers the deck rows up to 56.49 min TTT. The remaining two rows are in separate PRs: #1371 (DEOSC state alignment) and #1372 (router/expert input-gradient join).

The branch is based on 0a7f486d. The `main` commits after that only touch diffusion and specforge, and the branch merges cleanly.

## Validation

Validation is in progress on 8× MI355X with the `main` CI image stack (rocm/primus v26.8 base, Primus-Turbo d04ffd9b, AITER 04896172, Triton fc8d31a5, Megatron-LM core_v0.19.2), on the same tree as this branch:

- [ ] 200-step MLPerf short test with the step-30 profiler window (train and eval loss decrease, every enabled patch applied, MXFP4 grouped GEMM and WGRAD on FlyDSL), for RCCL 2.30.7, submission RCCL dde68f30, and rocm-systems develop with `rccl_sdma`
- [ ] BF16 vs FP32 Adam moments A/B
- [ ] full convergence to eval loss 3.34, with time to train against the 56.11 min target
