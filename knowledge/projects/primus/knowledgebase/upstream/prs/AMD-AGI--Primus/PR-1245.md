# Add opt-in Turbo fused cross entropy for TP1 training

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1245) · state: open · merged: False

## Original PR description

Megatron TP1 training can opt into Turbo fused cross entropy through the declared `use_turbo_cross_entropy` training argument. The patch preserves Core's sequence/batch layout and per-token loss contract; unsupported tensor parallelism, dtypes, and unfused configurations retain the configured implementation.

`turbo_ce_overwrite_input` additionally permits backward to reuse exclusively owned contiguous logits storage. Both arguments default false in `primus/configs/modules/megatron/primus_turbo.yaml` and support experiment YAML and Primus CLI overrides. The patch no longer reads `PRIMUS_TURBO_CROSS_ENTROPY` or `PRIMUS_TURBO_CE_OVERWRITE_INPUT`. Documentation is linked from the docs index and site navigation.

The Turbo dependencies [#546](https://github.com/AMD-AGI/Primus-Turbo/pull/546) and [#550](https://github.com/AMD-AGI/Primus-Turbo/pull/550) are merged. CI pins Turbo main at `4e6bd90b4fd9aa40c7945674d83975ee150a7b68`, which includes both MoE gather fusion and fused cross entropy.

Training subprocess tests now use independent c10d rendezvous ports allocated and held by torchrun. This fixes inherited `MASTER_PORT` collisions in pipeline-warmup and projection tests. A regression test launches two concurrent distributed jobs while the inherited port is occupied. Multi-node test settings are preserved.

Validation:
- Full CI passed for `99439f8d4`: https://github.com/AMD-AGI/Primus/actions/runs/38112167456
- MI300X PyTorch: 3,219 core tests passed (1,039 skipped, 8 deselected), including all 13 cross-entropy tests and the new concurrent-rendezvous regression. All 19 Megatron and 7 TorchTitan training tests passed, as did CLI smoke checks.
- TorchTitan Llama FP8 reported finite losses (`12.26768`, `22.06730`, `22.74743`) and gradients for all three steps. An earlier MI300X NaN failure did not recur; the rendezvous fix addresses port collisions, and no numerical workaround or relaxed metric assertion was added.
- All 25 focused local rendezvous, finite-metric, and cross-entropy configuration tests passed.
- Five local eight-GPU MI355X runs of the three-step TorchTitan Llama FP8 recipe passed with finite metrics, including fixed seeds 0/1/2 and a run through the updated training helper while the inherited port was deliberately occupied.
- JAX, lint, image build, dependency review, coverage summary, CodeQL, and documentation checks passed.
