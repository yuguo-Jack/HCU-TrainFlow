# [Megatron-LM] Add ZAYA1-8B Megatron pretraining implementation

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1199) · state: closed · merged: True

## Original PR description

## Summary
- Add a Primus Megatron pretraining path for ZAYA1-8B (`model_type: zaya1`) whose forward follows the SGLang implementation: 40 CCA stages and 40 MoE stages, per-sublayer residual scaling, vector EDA, and mixture-of-depths.
- Reuse the GPT training loop and dataset provider. Data, tensor, pipeline, context, and expert parallel sizes other than data parallel are rejected.
- Ship MI300X and MI355X mock-data configs for a 30-iteration smoke run, plus CPU tests of the SGLang math.
## Test plan
- [ ] `python -m pytest tests/unit_tests/megatron/transformer/zaya1/test_zaya1_sglang_math.py`
- [ ] `./primus-cli direct -- train pretrain --config examples/megatron/configs/MI300X/zaya1_8B-BF16-pretrain.yaml`
- [ ] Confirm the run gets past the global-batch check on 8 data-parallel ranks and completes 30 iterations
