File: `runner/helpers/hooks/train/posttrain/megatron/01_convert_checkpoints.py` · line 603

If rank 0 fails before another node enters this function (for example, an offline Hub download fails immediately), `failed_at_start` already identifies the current attempt's failure. The signature never changes again, so that node ignores the failure and waits until timeout—two hours on the download path—instead of stopping with rank 0's error. Distinguish stale failures using a shared invocation/attempt ID, rather than whether the marker predates this node's wait, and cover a waiter that starts after rank 0 has failed.
