<summary><strong>What changed in this PR</strong></summary>

This PR adds runner startup safeguards against ROCm allocation hangs on hosts with amdgpu DRM older than 3.64.

**Changes:**
- Disables virtual-memory-backed HIP pools on older drivers unless the user explicitly sets `HIP_MEM_POOL_USE_VM`.
- Adds a subprocess allocation probe with a 60-second timeout to the expandable-segments check.
- Documents the new environment-variable behavior.

| File | Description |
| ---- | ----------- |
| `runner/​helpers/​hooks/​05_check_expandable_segments.py` | Adds a timed allocation probe to detect hangs before training. |
| `runner/​helpers/​hooks/​05_check_amdgpu_vm_timeline.py` | Detects the amdgpu DRM version and emits the HIP pool workaround. |
| `docs/​03-configuration-reference/​environment-variables.md` | Documents `HIP_MEM_POOL_USE_VM`, its conditional default, and user overrides. |
