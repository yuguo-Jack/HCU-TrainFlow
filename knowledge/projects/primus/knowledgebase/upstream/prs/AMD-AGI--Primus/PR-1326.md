# feat(automodel): ZeRO-1 for Ideogram-4 on the DDP path

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1326) · state: closed · merged: True

## Original PR description

Part 3 of 4 of the Ideogram-4 work, stacked on 4b (#1325). The diff here shows only this commit. Once 4a–4d are reviewed, this PR is squash-merged into its base, and Ideogram-4 goes to `main` as 4a (#1324).

**What changes**
- A DDP preset for Ideogram-4, with the optimizer state optionally sharded across the data-parallel ranks (`primus_ideogram4.zero1`). DDP replicates parameters and gradients, so there is no per-layer all-gather, but it also replicates the AdamW state; ZeRO-1 shards only that. AutoModel compiles only on its FSDP2 path, so this is aimed at multi-node runs; it is tested on a single node only.
- Where ZeRO-1 does not apply (parameters already sharded, a single rank) it warns and keeps the plain optimizer. A construction failure raises, and so does `checkpoint.enabled`: AutoModel saves the optimizer through `state_dict()`, which `ZeroRedundancyOptimizer` refuses until consolidated, so the first save would crash. A ZeRO-1 run therefore cannot save or resume. `checkpoint.enabled` defaults to true and is read the way AutoModel reads it; the DDP experiments set it to false.
- The optimizer patch applies only to runs that train Ideogram-4.
- DDP experiments for synthetic and cached data.

**Breaking:** none.

**How to review.** `models/ideogram4/zero1.py`. The optimizer patch walks the optimizer-config hierarchy rather than naming classes, because the factory config the recipe uses for a plain torch optimizer overrides `build()` without calling `super()`.

**Test plan**
- Unit tests: the non-chaining override and a subclass defined after install in a stubbed hierarchy, the warn-versus-raise cases, the checkpoint refusal across the values AutoModel accepts, the Ideogram-4 gating, and the setting's spellings. Against real torch: on two CPU ranks, a real `ZeroRedundancyOptimizer` over AdamW that keeps the parameter groups and steps like a plain AdamW; and, where AutoModel is installed, the walk over its real hierarchy.
- On MI355X: the DDP experiment with ZeRO-1, plain DDP, ZeRO-1 declining on FSDP2, and the DDP cache experiment with ZeRO-1 on a real cache.
