File: `primus/backends/megatron/patches/training_log/first_iteration_reset_patches.py` · line 49

The installed wrapper is never removed, and this getter never checks `reset_log_on_first_iteration` for the current run. After an enabled run, a later run in the same Python process with the flag disabled still resets losses and timers on its first log boundary and changes TensorBoard/W&B logging. Check the current flag here and return a disabled interval when it is off, so the wrapper leaves that run unchanged.
