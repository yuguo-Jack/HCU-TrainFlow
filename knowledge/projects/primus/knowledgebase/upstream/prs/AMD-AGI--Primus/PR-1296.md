# feat(examples): hipBLASLt GEMM tuning for GPT-OSS 20B and 120B on MI455X

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1296) · state: closed · merged: True

## Original PR description

Add a hipBLASLt tuning file for GPT-OSS on gfx1250, tuned for the hipBLASLt in amdprimus/amdprimus:tas-20261019 (hipBLASLt e1e7fdcab9, ROCm 10.2.0a20261011): hipblaslt_tuning/gpt_oss-gfx1250-hipblaslt_e1e7fdcab9-rocm_10.2.0a20261011.txt, 37 rows covering 20B and 120B. run_gpt_oss_mi455x.sh loads it by default through HIPBLASLT_TUNING_OVERRIDE_FILE; an empty value restores hipBLASLt's default kernel selection.

4x MI455X, iterations 3-10, 2 runs each, default vs tuning file:
- 20B (MBS 8 / GBS 64): 2200.2 -> 2106.8 ms/iter (4.2% faster), 823 -> 860 TFLOP/s/GPU, 29,788 -> 31,109 tokens/s/GPU, same loss and memory.
- 120B proxy, 8 of 36 layers, "120B tuning" settings: 849.6 -> 817.7 ms/iter (3.8% faster), 889 -> 924 TFLOP/s/GPU, 77,141 -> 80,150 tokens/s/GPU.
- The 120B yaml (MBS 1) is unchanged: only the shared-expert GEMMs match.

The README documents the results, how the file was made and how to build hipblaslt-bench (hipblaslt_tuning/hipblaslt_bench). The per-GEMM record and a 20B in-training profile are next to the tuning file.
