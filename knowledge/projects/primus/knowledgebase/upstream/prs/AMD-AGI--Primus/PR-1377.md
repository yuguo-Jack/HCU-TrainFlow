File: `runner/helpers/hooks/train/pretrain/diffusion/prepare.py` · line 91

This accepts nonexistent paths such as `cache/models/t5` as Hugging Face references, so FLUX preparation can report success before encoder or `hf_repo` dataset loading fails in the training processes. Those loaders pass the entire value to `from_pretrained` or `load_dataset`, which do not interpret it as `org/repo/subfolder`. Require repository-only references for these callers, while allowing `org/repo/filename` separately for the FLUX autoencoder loader, which supports that syntax.
