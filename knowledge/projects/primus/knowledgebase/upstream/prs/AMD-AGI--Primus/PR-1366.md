# Port MoE token dedup (ROCm/Megatron-LM PR #165) to the Megatron backend

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1366) · state: open · merged: False

## Original PR description

Add `moe_token_dedup` / `moe_token_dedup_weighted_combine` as Primus patches over the Megatron-core v0.19 all-to-all dispatcher; third_party/Megatron-LM is untouched. PrimusDedupAlltoAllTokenDispatcher sends one All-to-All row per unique (token, destination EP rank) in both the dispatch and combine direction; the Triton kernels and autograd functions are the PR's, unchanged.

Validated on 8x MI300X (rocm/primus:v26.8): EP8 dedup matches the stock dispatcher within fp32 tolerance, and a 4-layer Qwen3-30B-A3B smoke gives bit-identical loss to the baseline.
