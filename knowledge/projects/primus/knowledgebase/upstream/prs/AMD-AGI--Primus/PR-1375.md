## Summary

Documentation for the v26.9 training images:

- `rocm/primus:v26.9` (Megatron-LM, TorchTitan, Megatron Bridge), built 2026-10-30
- `rocm/jax-training:maxtext-v26.9` (MaxText), built 2026-10-30

Both are built from Primus `db1a4160` on `release/v26.9`. The docs were written from the CI images that passed
QA, each probed under its release tag, with the release-docs-update skill.

**Stacked on #1374**, whose tools generated it: this PR targets `dev/release-docs-ci-images` and contains only
the 7 docs commits. It moves to `main` once #1374 is merged.

## Commits (one per phase)

1. **Image snapshots and release Dockerfiles**: `tools/release_docs/data/v26.9-{primus,jax}.json` and
   `.github/workflows/docker-release/Dockerfile.{primus,jax}-v26.9`, both taken from the images (the
   committed Dockerfiles match the images' baked-in copies).
2. **Version references** v26.8 → v26.9 across the docs, `README.md`, `runner/` and `primus/__init__.py`.
   References outside the documentation surface are kept: CI base images, example configs and their comments,
   tests, `tools/perf`.
3. **Release notes**: the v26.9 section (tables generated from the snapshots, the "Changes since v26.8" delta,
   Primus source) and the v26.9 Highlights for both families. The v26.8 Highlights move into the v26.8
   section; v26.6 leaves the detailed list.
4. **Recipe notes and new models**: "Important notes for v26.9" on the Megatron-LM, TorchTitan and MaxText
   pages, and the new recipes in the model lists and the model-support matrix (GLM-5.3-Flash,
   HunyuanWorld-Mirror post-training, ZAYA1-8B FP8, MI325X ZAYA1-8B).
5. **Bare-metal install** re-pinned to the v26.9 Dockerfiles: `tools/installation*/setup.sh`, `env.sh`, the
   READMEs and the bare-metal guides.
6. **Review answers**: the JAX page no longer says the image ships no Primus (v26.9 bundles it again); history
   references restored to v26.8; the "Primus source" section notes that `release/v26.9` has moved past the
   build commit (`93dd9201`, MI325X GPT-OSS-20B and ZAYA1-8B tuning, #1355).
7. **Review edits**: the README "What's New" entry for v26.9, and a "Primus training performance" section in
   the overview linking AMD's published training results.

## Release highlights

**`rocm/primus:v26.9`**: a ROCm 10.2 nightly with a PyTorch 2.16 pre-release and a TransformerEngine 2.20
development build; new models (GLM-5.3-Flash, HunyuanWorld-Mirror post-training, ZAYA1-8B FP8); a fused AdamW
optimizer by default in TorchTitan; MoE correctness fixes; mock-data benchmarks now use each model's real
vocabulary.

**`rocm/jax-training:maxtext-v26.9`**: JAX 0.12.0 and a TransformerEngine 2.19 development build on a ROCm 10.3
nightly; MaxText pinned to `release/v26.9`; Primus bundled in the image again; a lower default XLA autotuning
level fixes intermittent compile-time crashes.

Details and PR links are in `docs/01-getting-started/release-notes.md` under "Highlights for v26.9".

**5. 🟠 Should fix: JAX image build fetches full clones of unused PyTorch submodules: this PR restored `--recurse-submodules` clone**

The Primus layer in `Dockerfile.jax-v26.9` runs `git clone --recurse-submodules`. That fetches full, non-shallow clones of all 10 submodules in `.gitmodules` at the default-branch pins, before `git checkout ${PRIMUS_BRANCH}`. The layer then re-initialises only `third_party/maxtext`. The image uses its own `/workspace/maxtext` through `MAXTEXT_PATH`, so the PyTorch-backend submodules (Megatron-LM, torchtitan, Megatron-Bridge, Automodel, ...) are dead weight that costs build time and image size. The block is copied unchanged from `Dockerfile.jax-v26.4` through `v26.7`. A plain clone followed by a shallow `git submodule update --init --depth 1 third_party/maxtext` would avoid the cost.

**Who is affected:** Anyone building the v26.9 JAX release image; it costs build time and image size, and the image still works.
