[Upstream PR](https://github.com/AMD-AGI/Primus/pull/518) · state: closed · merged: True

## Original PR description

Add explicit parameter override support for the Megatron-Bridge backend, allowing users to override backend-specific arguments at runtime without modifying the base YAML config.

This enables faster iteration for post-training (SFT/LoRA) workflows and keeps Megatron-Bridge aligned with Primus' unified config and CLI model.

## Module imports itself

The module 'primus.backends.megatron_bridge.patches' imports itself.

---

In general, to fix a module importing itself from within its own <code>__init__.py</code>, replace absolute imports that re-specify the package name with relative imports that directly reference submodules. This way, the package does not try to import itself; it only imports its child modules.</p>
<p>For this file, the best fix is to change the line:</p>
<pre><code>from primus.backends.megatron_bridge.patches import dataset_patches  # noqa: F401
</code></pre>
<p>to a relative import that pulls in the <code>dataset_patches</code> submodule from the same package:</p>
<pre><code>from . import dataset_patches  # noqa: F401
</code></pre>
<p>This keeps the existing behavior—importing <code>dataset_patches</code> for its registration side effects—while avoiding the self-import pattern. No other lines in <code>primus/backends/megatron_bridge/patches/__init__.py</code> need to change, and no additional imports or new definitions are required.
