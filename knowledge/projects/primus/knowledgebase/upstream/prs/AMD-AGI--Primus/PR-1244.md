# Add opt-in Turbo CE to Megatron TP1 training

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1244) · state: closed · merged: True

## Original PR description

Add opt-in Turbo cross-entropy dispatch for Megatron TP=1 BF16/FP32 training, preserving per-token loss and layout semantics. Both enablement and logits-overwrite flags default off; unsupported configurations retain the existing implementation.

Validation: five GPU integration tests passed, covering gradient propagation, storage modes and fallbacks. Requires [Primus-Turbo #548](https://github.com/AMD-AGI/Primus-Turbo/pull/548).
