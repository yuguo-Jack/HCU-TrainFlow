# chore(config): update MI300X Llama-3.1-70B FP8 batch size

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1303) · state: closed · merged: True

## Original PR description

## Summary

Updates the MI300X Llama-3.1-70B FP8 batch size in the TorchTitan example config to the single-node MI300X value in the v26.8 QA benchmark table. Only the batch size changes; sequence length and all other settings are untouched.

## Changes

| File | Micro batch, old → new | Global batch, old → new |
| --- | --- | --- |
| `examples/torchtitan/configs/MI300X/llama3.1_70B-FP8-pretrain.yaml` | 1 → 4 | 8 → 32 |

The micro batch is `training.local_batch_size`. The config doesn't set `global_batch_size`, so TorchTitan uses the Primus default of `-1`: local batch × data-parallel degree, which is 8 on one 8-GPU node. The global batch above is derived that way, so the file changes only `local_batch_size`. The config keeps full activation checkpointing and sequence length 8192.

The old value is the batch size in the MI300X benchmark targets Claire shared on 2026-10-23. _Reason for the new size: to be added._

Unchanged: the TorchTitan Llama-3.1-70B BF16 config (`llama3.1_70B-BF16-pretrain.yaml`, micro 2 / global 16) and the Megatron-LM Llama-3.1-70B configs (`examples/megatron/configs/MI300X/llama3.1_70B-{BF16,FP8}-pretrain.yaml`, micro 3 / global 24).
