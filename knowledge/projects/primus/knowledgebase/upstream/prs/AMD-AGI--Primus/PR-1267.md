# feat(examples): MI455X DeepSeek-V3 proxy on FlyDSL attention and grouped GEMM, image tas-20261019

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1267) · state: closed · merged: True

## Original PR description

## Summary
- The MI455X DeepSeek-V3 proxy example runs attention (`PRIMUS_TURBO_ATTN_BACKEND=flydsl`) and the expert grouped GEMMs (`turbo_grouped_gemm_backend: bf16:flydsl`) on Primus-Turbo's FlyDSL kernels.
- Default image `amdprimus/amdprimus:tas-20261019`: `tas-20261015` + hipBLASLt from ROCm/rocm-libraries `develop` e1e7fdcab + Primus-Turbo `main` 21588d59 (#567). The image's Primus-Turbo runs the defaults; `TURBO_DIR` is optional.
- `prepare_mi455x.sh` removed; the README gives the `docker run` for running inside a container and the one-command in-place build of another Primus-Turbo checkout.
- README: reference numbers, grad norms and profile re-measured on the new image; known issues updated.

## Results (4x MI455X, tas-20261019, iterations 3-10)

| Variant | ms/iter | TFLOP/s/GPU | Peak VRAM/GPU |
| --- | --- | --- | --- |
| 4-GPU, FlyDSL attention + grouped GEMM (new default) | 1227 | 1157 | 152.5-154.7 GiB |
| 4-GPU, TE unfused attention + Triton grouped GEMM (previous default) | 2179 | 652 | 196.9-199.1 GiB |
| 1-GPU, 4 layers | 1014 | 1400 | 119.0 GiB |
| 1-GPU, 1 layer | 443 | 1427 | 62.7 GiB |

## Test
- 4-GPU: 3 runs + 1 profiled run (FlyDSL MLA and FlyDSL grouped GEMM kernels confirmed in the trace), 2 runs of the previous defaults; 1-GPU: 3 runs of each variant.
- Non-root in-place build of Primus-Turbo 21588d59 with the README command, then a `TURBO_DIR` run: loss and grad norms equal to the reference.
- pre-commit; `tests/runner/test_docs_cli_examples.py`.
- Trial merges into `dev/mi455x_v1` and `main`: no conflicts. On the merged `main` tree the 1-GPU runs pass (1-layer 432 ms, 4-layer 1008 ms); loss and grad norms differ from the README because `main` uses DeepSeek-V3's vocabulary 129280 (#1249), as the README notes.

Suggest squash-merge (one commit message, 5980ae39 names an old image tag).
