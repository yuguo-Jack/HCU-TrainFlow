# [Hybrid Models] Add a dense-to-hybrid checkpoint upcycler for non-MoE models.

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1205) · state: open · merged: False

## Original PR description

Continued pretraining can reuse a dense checkpoint's embeddings and MLPs while new recurrent layers keep the hybrid initialization.

## Reproducing the Zebra-Llama stage-1 checkpoints

The PR contains what is needed to train the all-Mamba-2 and all-MLA Enhanced-ILD students so they match the reference stage-1 checkpoints, and to check the match. The runbook is "Reproduce the reference stage-1 checkpoints" in `docs/04-technical-guides/hybrid-models/hylo-native-training.md`.

- **Packed recipes.** `examples/megatron/configs/MI300X/hylo_m2_1B-enhanced-ild-packed.yaml` and `hylo_mla_1B-enhanced-ild-packed.yaml` keep the SFT recipes' model, teacher, and optimizer and train through the pretrain data path on the reference's packed 2048-token windows, 6934 steps of 96.
- **Packed data.** `tools/hybrid/prepare_hylo_packed_data.py` rebuilds the reference's training and test text: the alignment-handbook 20% selection, the recipe's Llama-3 template, HumanEval decontamination, and TRL's tokenization.
- **All-Mamba-2 random init.** The from-teacher init leaves part of each Mamba-2 mixer at random values that barely move in training, and PyTorch's GPU generator orders its stream by the GPU's compute-unit count. `tools/hybrid/scan_mamba2_reference_draw.py` finds the count that rebuilds the reference's draw by matching it against the reference, and `tools/hybrid/write_mamba2_reference_init.py` writes that draw into the upcycled checkpoint. The all-MLA init is deterministic.
- **Evaluation and comparison.** `tools/hybrid/run_hylo_ild_eval.sh` with `hylo_m2_1B-ild-eval.yaml` or `hylo_mla_1B-ild-eval.yaml` scores fixed weights on the packed test split; `tools/hybrid/convert_hylo_reference_to_megatron.py` loads a reference student as a Megatron checkpoint so it is scored the same way; `summarize_hylo_ild_eval.py` and `summarize_hylo_ild_loss.py` summarize the logs; `compare_hylo_ild_to_reference.py` compares a student with its reference tensor by tensor.
- **SFT-path fix.** On the padded SFT path, Enhanced-ILD now averages over each sample's real tokens; the packed path is unchanged.

Trained this way, the students match the references on 348 held-out packed batches scored against the same teacher:

| Student | Enhanced-ILD, ours | Enhanced-ILD, reference | Weights against the reference |
| --- | --- | --- | --- |
| all-MLA | 28.75 | 28.76 | median cosine 0.998 or more in every tensor group |
| all-Mamba-2, from the reference's random draw | 35.25 | 35.22 | median cosine 0.993 or more in every tensor group |

## Checks

- Unit tests for the new and changed code, plus every example config: 526 passed, including the GPU check of the Philox model against the GPU's own `uniform_`.
- Both packed recipes, run from the repository for three iterations, give the earlier full runs' first-iteration Enhanced-ILD exactly (all-Mamba-2 1053.0, all-MLA 131.5), and `run_hylo_ild_eval.sh` reproduces the earlier evaluation's per-step losses.
- Run on the reference, the scan and the writer rebuild the earlier all-Mamba-2 init bit for bit, and the comparison tool reproduces the earlier comparison table.
