# feat(mi455x): add FP8 hybrid LoRA SFT proxy recipes

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1248) · state: closed · merged: True

## Original PR description

## Summary
- Add 4-layer, 1-GPU FP8 hybrid LoRA SFT smokes for Llama-2-70B, Qwen2.5-72B, and Qwen3-235B-A22B on MI455X (gfx1250).
- Each recipe is the existing BF16 proxy with Transformer Engine FP8 hybrid (`fp8: hybrid`, delayed scaling) and `no_fp8_weight_transpose_cache: true`. Master weights and LoRA adapters stay BF16. Random init, no full-model download.
- Qwen2.5 also sets `add_qkv_bias: true`. Qwen3 LoRA stays attention-only (`linear_qkv`, `linear_proj`).
- Document the new configs in the native MI455X LoRA README.
