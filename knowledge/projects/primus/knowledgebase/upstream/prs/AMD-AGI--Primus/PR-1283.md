# ci: bump the MaxText CI image to maxtext-v26.8

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1283) · state: closed · merged: True

## Original PR description

## Summary

Move the MaxText CI to `rocm/jax-training:maxtext-v26.8`.

## Changes

- **`ci.yaml`**: `MAXTEXT_BASE_IMAGE` → `rocm/jax-training:maxtext-v26.8`; `run-unittest-jax` runs on `primus-jax-tas-runner-v26.8`, a runner container on a16-31 built from that image.
- **Skip the Triton buffer-store WAR patch when Triton is not installed.** The v26.8 MaxText image ships ROCm torch but no Triton, so the ROCm-only gate passed and the patch failed at startup with an `ImportError`.

## Validation

- `run-unittest-jax` on `primus-jax-tas-runner-v26.8`: CLI shell tests pass; MaxText E2E 2 passed, 14 skipped.
- `tests/unit_tests/core/patches/test_triton_bufops_war.py`: 19 passed.
