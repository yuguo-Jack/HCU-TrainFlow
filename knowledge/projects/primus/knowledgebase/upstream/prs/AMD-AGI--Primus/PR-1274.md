# ci/docker, torchtitan: v26.8 CI follow-ups (origami -Bsymbolic, SAC profiler ops, perf_host flake)

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1274) · state: closed · merged: True

## Original PR description

## Summary

Follow-ups for the v26.8 CI image that #1271 moved `main` to (torch 2.14.0+rocm10.1, TE 2.17.1); fixes `main`'s current `run-unittest-torch` failure.

This also unblocks #1216: its `test_deepseek_v3_16b` NaN comes from the v26.5 CI image's from-source Triton 3.7 and does not reproduce on v26.8 ([details](https://github.com/AMD-AGI/Primus/pull/1216#issuecomment-6290020934)).

## Changes

- **origami: link the extension with `-Wl,-Bsymbolic`.** ROCm 10.1 ships its own, ABI-incompatible `liborigami.so.1`, which torch loads first. Without this the extension's `origami::` calls bind there and `rank_configs` dies with SIGFPE (`hardware_t::get_mi_latency`), crashing Turbo Triton grouped GEMM on v26.8.
- **TorchTitan: let SAC ignore profiler `record_function` ops.** torch 2.14's selective activation checkpointing requires every op to repeat the same number of times in forward and recompute; under torch.compile, FSDP2's `record_function` markers do not, so the GPT-OSS E2E tests (selective op AC) fail backward with `profiler._record_function_enter_new ... not found in storage`. A setup patch adds those profiler-only ops to `SAC_IGNORED_OPS`.
- **`test_te_vs_local_spec_attention.py`: round TE like Primus-Turbo.** With only `NVTE_CK_IS_V3_ATOMIC_FP32=1` (from #1271), TE's FAv3 rounds with the images' `rtz` while Turbo uses `rtna`, so the specs drift 2–3% over 100 steps; `test_te_eager_vs_local_compiled` fails on `main` ([job](https://github.com/AMD-AGI/Primus/actions/runs/39520984894/job/119014081278), 0.029 > 0.02). Setting `NVTE_CK_HOW_V3_BF16_CVT=1` makes the loss curves match exactly, so `test_eager_te_vs_local` goes back to 0.02.
- **`test_perf_host`: compare settings keys, not live values.** The snapshot test read the host twice and compared exact text; GPU clocks and NIC state change in between (CI: `sclk 2103` vs `2104 MHz`).
- **`examples/README.md`**: point at `rocm/primus:v26.8`.

## Validation

On a v26.8 CI image built before #1271 (Turbo `67b8e09`, aiter 0.1.14, 8× MI300X, CI's commands):

- origami probe (`origama_select_params`, M = 1…4096): SIGFPE without `-Bsymbolic`, fine with it.
- TorchTitan E2E: GPT-OSS 20B BF16/FP8 fail without the SAC patch, 7/7 pass with it. Megatron E2E 21/21.
- Core unit tests pass apart from the `test_perf_host` flake fixed here.

- `test_te_vs_local_spec_attention.py` with the rounding fix: 3 passed, loss diff 0.000 (×2).

On the current `main` image (Turbo `de8fa6ca`, aiter 0.1.24, Triton 3.9) this PR's CI is the validation.
