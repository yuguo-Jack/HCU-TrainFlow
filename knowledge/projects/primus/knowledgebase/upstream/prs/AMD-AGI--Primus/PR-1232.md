# feat(projection): MaxText/JAX backend for Primus Projection

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1232) · state: closed · merged: True

## Original PR description

Re-lands the MaxText/JAX part of #1203. #1203 was stacked on the TorchTitan branch, so its revert (#1220) removed TorchTitan as well; TorchTitan has since merged on its own in #1202. This PR adds only the MaxText/JAX delta on top of it.

- MaxText config adapter (`frameworks/jax.py`) translating MaxText's config into the projection's flat fields, plus MaxText model-spec aliases in `model_specs.py`.
- Self-contained bench runner (`bench_harness/maxtext.py`, `jax_timing.py`). Flax layers have no autograd hooks and XLA preallocates device memory, so MaxText times its layers and reads memory itself. The TP all-reduce and `optimizer.step()` sub-benches are skipped for it (XLA collectives, optax optimizer) and the analytical models stand in.
- `setup_model_only` for MaxText. The runtime no longer calls `init()` before it, because MaxText's `init()` builds the training state; Megatron's `init()` only logs and TorchTitan's `setup_model_only` already builds what it needs.
- Workload registry aliases `maxtext` and `jax`; docs and skill updated.

## Test plan

- `pytest tests/unit_tests/core/projection`: 406 passed, 55 skipped (adds MaxText adapter, cross-backend shape agreement, and JAX bench tests).
- black and isort clean.
- Not yet run on GPU: the MaxText benchmark path is CPU-verified only.
