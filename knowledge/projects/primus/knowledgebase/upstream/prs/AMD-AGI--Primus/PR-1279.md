# [CP] feat(zaya1): size MI355X 8B batches to GPU memory- (#1276)

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1279) · state: closed · merged: True

## Original PR description

- Set micro_batch_size on MI355X to the largest multiple of 8 that completes on one 8-GPU node with rocm/primus:v26.8, with one micro batch per GPU per step: BF16 248 (peaks at 282 of 288 GB, 256 runs out of memory) and FP8 208 (284 of 288 GB, 216 runs out of memory). They replace the MI300X sizes, 128 and 120.
- Docs: MI355X rows in the ZAYA1 throughput table, and the support matrix no longer calls MI355X untested.
