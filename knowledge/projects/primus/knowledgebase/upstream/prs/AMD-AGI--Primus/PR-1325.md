# feat(automodel): Ideogram-4 encoded-cache dataloader and cache builder

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1325) · state: closed · merged: True

## Original PR description

Part 2 of 4 of the Ideogram-4 work, stacked on 4a (#1324). The diff here shows only this commit. Once 4a–4d are reviewed, this PR is squash-merged into 4a's branch, and Ideogram-4 goes to `main` as 4a.

**What changes**
- The real-data path for Ideogram-4: an offline builder that encodes images and captions once, a dataloader that reads the result, and a CLI that runs the builder: `primus-cli direct --single -- data automodel-cache --model ideogram4`.
- The dataloader emits the same batch contract as 4a's synthetic loader, so a config swaps one for the other. The text width comes from the cache metadata, so the packed length is the same on every step and rank. A cached caption is never truncated: a width below the longest caption is refused, and each sample is checked against the index.
- The build is deterministic by default. Over-length captions are dropped before anything is encoded, rather than truncated, and the skip counts are recorded in `metadata.json`. Unreadable images are counted rather than raised on, but a run of consecutive failures stops the build. The encoders load before the output directory is touched; a rebuild then clears the old index and samples, and `metadata.json` is written last and atomically, so an interrupted build is never read as complete.
- A cache module preset and experiment. Building a cache needs the encoder weights: the text encoder is public, while the autoencoder's repository is gated on Hugging Face. Training reads only the cache.

**Breaking:** none. The existing `diffusion-*` data commands are unchanged; the new command is a sibling.

**How to review.** `models/ideogram4/data/cache.py` (the loader), then `data/build.py` (the builder; every transform is the inverse of the inference pipeline's), then the registry and CLI in `primus/backends/automodel/data/`.

**Test plan**
- Unit tests: the batch contract shared with the synthetic loader, left-padding, the derived width and the no-truncation refusals, path containment and index validation, a full build read back by the loader, that an interrupted or failed rebuild leaves no stale index, the registry's lazy imports, and CLI wiring, including the existing commands. They run without AutoModel installed.
- On MI355X: a small cache built with this builder and the default encoders, covering each skip reason, the cache experiment on it, and a smaller rebuild into the same directory leaving no stale samples.
