# perf(megatron): tune MI300X GPT-OSS-20B and Llama 70B pretrain configs

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1329) · state: closed · merged: True

## Original PR description

Tuned on one 8x MI300X node with the primus_ci_655d58f_20261026 image. Tokens/s/GPU over 20 iterations, before = the release/v26.9 configs:

  config              before   after
  gpt_oss_20B  BF16    11497   13730
  gpt_oss_20B  FP8     12232   14797
  llama3.1_70B BF16      799     805
  llama3.1_70B FP8       OOM    1184
  llama3.3_70B BF16        -     804
  llama3.3_70B FP8         -    1186

GPT-OSS-20B (BF16 and FP8):
- Run the Turbo grouped GEMM on hipBLASLt; the default Triton backend is slower on MI300X.
- Enable TE fused cross entropy, RoPE fusion, Turbo RMSNorm and gradient accumulation fusion.
- Enable the fused activation-with-probs on sync-free stage 2; stage 3 itself OOMs on 192 GB.
- Raise turbo_deepep_num_cu from 64 to 160.

Llama 3.1 / 3.3 70B (BF16 and FP8):
- Comment out PYTORCH_HIP_ALLOC_CONF=expandable_segments:True, which cannot run on hosts with older amdgpu drivers.
- Use TE attention instead of Turbo attention.
- FP8: MBS 1, GBS 48, recompute 72 layers. Without expandable segments MBS 3 OOMs and MBS 2 leaves under 1 GB of device memory free.
- Carry over the release/v26.9 settings from #1307 that main lacked: GPU_MAX_HW_QUEUES=4, 20 iterations, BF16 MBS 2 / GBS 16 / recompute 76, and fused cross entropy for llama3.3.
