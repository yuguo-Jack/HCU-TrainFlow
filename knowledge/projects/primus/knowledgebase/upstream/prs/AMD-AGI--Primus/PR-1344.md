# feat(diffusion): Add AMDB Wan2.1 image-to-video benchmark support

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1344) · state: closed · merged: True

## Original PR description

## Summary

Add **Wan2.1 Image-to-Video (I2V)** support for AMDiffusionBenchmark by extending the existing native Wan implementation in Primus.

Instead of introducing a separate Wan model stack, this PR reuses the existing Wan DiT, VAE, text encoder, adapter, and training pipeline, adding the components required for image-conditioned video generation.

## Changes

### Wan2.1 I2V integration
- Extend the existing `models/wan` implementation with image-to-video support.
- Add image cross-attention to the native Wan DiT.
- Add `MLPProj` for image conditioning.
- Add the CLIP vision tower and supporting components:
  - `clip.py`
  - `clip_attention.py`
  - `clip_vision.py`
  - `xlm_roberta.py`
- Integrate the AMDiffusionBenchmark noise schedule.
- Enable I2V-specific components only when `model_type` is `i2v`.

### Compatibility
- Reuse the native Wan model builder and registration path.
- Preserve the existing Wan training pipeline.
- Keep the existing `wan` trainer unchanged.
- Ensure the new image-conditioning components and benchmark noise schedule are gated behind `model_type == "i2v"`.

### AMDB integration
- Integrate with the shared `AMDBBenchmarkTrainer`, extending `FSDP2Trainer`.
- Include shared AMDB dataset loading and checkpoint download support.
- Reuse the existing training step loop, batch handling, logging, and parameter counting utilities.

## Reused Components

- `models/wan/wan_dit.py`
- `models/wan/adapter.py`
- `models/wan/components.py`
- `models/wan/train_pipeline.py`
- `models/wan/vae2_1.py`
- `models/wan/vae2_2.py`
- `models/wan/t5.py`
- `models/registrations/wan.py`

## Validation

- [x] End-to-end wan model benchmark training.
