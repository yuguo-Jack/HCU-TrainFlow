# docs: update docs/examples to use ./primus-cli from repo root

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/512) · state: closed · merged: True

## Original PR description

The repo now provides a root-level entrypoint (./primus-cli). Some docs still referenced ./runner/primus-cli or primus-cli, which is inconsistent and less copy‑paste friendly when users run from the repository root.

## Pull request overview

This PR updates documentation and examples to use the new root-level `./primus-cli` entrypoint instead of the previous `./runner/primus-cli` or bare `primus-cli` references, improving consistency and usability when running commands from the repository root.

**Changes:**
- Added a new root-level `primus-cli` wrapper script that delegates to `runner/primus-cli`
- Updated all documentation examples to use `./primus-cli` from the repo root
- Added a new section in CLI documentation explaining how to run from a source checkout
