# fix(megatron-bridge): add version constraint to turbo TE spec provider patch

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/524) · state: closed · merged: True

## Original PR description

## Summary

Add version constraint to the Primus Turbo TESpecProvider patch to limit its application to Megatron versions < 0.16.

## Changes

- Add `backend_versions=["<0.16"]` parameter to the `@register_patch` decorator in `te_spec_provider_patches.py`
- This ensures the patch only applies when using Megatron versions earlier than 0.16

## Motivation

The Primus Turbo TESpecProvider patch is designed for Megatron 0.15.x and may not be compatible with newer versions. Megatron-Bridge now uses the newer Megatron 0.16.0, which has different internal implementations that are incompatible with this patch. Adding this version constraint prevents the patch from being incorrectly applied to Megatron 0.16.0 and later versions.

## Implementation Details

The patch uses the `backend_versions` parameter with the version pattern `"<0.16"`, which leverages the existing `version_in_range()` utility function that supports:
- Exact matches: `"0.15.0"`
- Wildcards: `"0.15.*"`
- Comparators: `">=0.8.0"`, `"<0.16"`, `"<=1.2.3"`, `">1.1.0"`
- Ranges: `"0.8.0~0.8.5"`

When the patch is skipped due to version mismatch, users will see:
[Patch] ⊘ Skipped: megatron.turbo.te_spec_provider (backend version mismatch: required=['<0.16'], actual=0.16.0)


## Context

- **Megatron 0.15.x**: Used by the original Megatron backend, compatible with this Primus Turbo patch
- **Megatron 0.16.0**: Used by Megatron-Bridge, has architectural changes that require different handling
