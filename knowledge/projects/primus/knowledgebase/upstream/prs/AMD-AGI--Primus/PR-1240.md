# perf(megatron): integrate opt-in BF16 router backward GEMMs

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1240) · state: closed · merged: True

## Original PR description

GPT-OSS currently carries a downstream Megatron patch to avoid promoting BF16 router inputs and weights to FP32 for the backward GEMMs. Move that behavior into Primus behind `moe_router_bwd_bf16` (disabled by default), allowing MLPerf to enable it through configuration and remove the Dockerfile patch.

The forward stays unchanged. For an FP32 router with BF16 inputs and weights, backward uses BF16 GEMM operands, emits BF16 input gradients, and emits FP32 weight gradients before conversion to the parameter dtype. Bias reduction retains the original gradient precision. Other precision combinations and the non-TE path delegate to the original Megatron backward; installation is idempotent.

Validation:
- 11 focused CPU tests passed, covering numerical results, tensor shapes, bias reduction, precision fallbacks, opt-in behavior, and repeated installation.
- Black, isort, and diff checks passed.
