## Scope

In this pull request (each phase's rungs verified):

- **text-core** (Text decoder (all 8 layers: SWA and global attention with rel bias, four short convs, sigmoid-router MoE with shared sink experts, embed norm, muP head), YAML preset and experiments, converter, trainer test entry, and fine-tuning from the released checkpoint reach L0, L1, L3 and L4 with eager/dense reference-style ops): `preset-settings`, `comp-embedding`, `comp-hybrid-gqa-attention`, `comp-rel-pos-bias`, `comp-log-scaling`, `comp-kv-short-conv`, `comp-block-short-conv`, `comp-moe-router`, `comp-shared-experts-sink`, `comp-lm-head`, `comp-loader`, `finetune-from-checkpoint`
- **fused-kernels** (Training-grade kernels: fused attention with the per-query relative-bias score_mod (forward and backward), and causal short-conv kernels (k=4, fp32 residual, packed-sequence reset, CP/SP halo exchange) for K/V and block outputs; parity at L2 and unchanged L3/L4 results): `kernels-rel-pos-bias`, `kernels-kv-short-conv`, `kernels-block-short-conv`
- **mtp** (Two MTP depths (depth 0 global, depth 1 local) with the dense SwiGLU MLP and global_scale, loaded from mtp.safetensors, match the reference and train with MTP loss): `comp-dense-mlp`, `comp-mtp`
- **main-checkpoint** (Verify the released main-branch Inkling (66 layers, hidden 6144, ~952B params, 41B active) with the finished port: config parity and logprob parity, fine-tuning from the converted checkpoint, and training across nodes. No new work items; checked by the gates.): verification only

Not in this pull request:

- **mm-encoders** (dMel audio embedding and HMLP vision patch encoder, with placeholder-token masked_scatter into the text stream, match the reference): `comp-audio-dmel`, `comp-vision-hmlp`. Deferred: the audio and vision encoders come in a follow-up pull request, after the text model.

- copilot-pull-request-reviewer[bot] · comment · 2026-11-03T03:20:19Z · [source](https://github.com/AMD-AGI/Primus/pull/1369#discussion_r4450575488)

File: `primus/backends/megatron/core/models/inkling/inkling_builders.py` · line 31

With `reset_attention_mask=True` and `reset_position_ids=False`, this builder accepts a run whose attention scores isolate documents, but whose K/V and residual-branch convolutions still read the preceding document. Training therefore silently crosses the requested document boundaries. Reject `reset_attention_mask` here until document IDs are propagated to all four convolutions.

- copilot-pull-request-reviewer[bot] · comment · 2026-11-03T03:20:20Z · [source](https://github.com/AMD-AGI/Primus/pull/1369#discussion_r4450575518)

File: `primus/backends/megatron/checkpoint/native_loader_inkling_mm_model.py` · line 387

BF16 and FP16 conversion leave the routed and shared expert parameters in their default fp32 storage because this builder never applies `margs.params_dtype`. `_place` copies into that storage and saves it unchanged, roughly doubling expert checkpoint size. Cast the model parameters before mapping, while preserving fp32 buffers such as `expert_bias`, and add a BF16 conversion regression test.

- copilot-pull-request-reviewer[bot] · comment · 2026-11-03T03:20:20Z · [source](https://github.com/AMD-AGI/Primus/pull/1369#discussion_r4450575541)

File: `primus/backends/megatron/core/models/inkling/inkling_model.py` · line 321

With MTP enabled, training with `recompute_granularity: full` and `recompute_layer_ids` fails on its first forward: this extraction request reaches `recompute_layer_patches.py:163-164`, which explicitly rejects it. Support pre-final-norm extraction in that recompute path, or reject the combination during Inkling configuration validation.

- copilot-pull-request-reviewer[bot] · comment · 2026-11-03T03:20:20Z · [source](https://github.com/AMD-AGI/Primus/pull/1369#discussion_r4450575559)

File: `primus/backends/megatron/core/transformer/inkling/inkling_layers.py` · line 437

When an attention-mask row hides every key (for example, a fully padded query), filling its scores with a finite minimum makes softmax return a uniform distribution. The eager path therefore averages masked values—including future keys in the query chunk—instead of returning zero as the fused path does. Zero the masked probabilities after softmax so fully masked rows contribute neither output nor gradients.
