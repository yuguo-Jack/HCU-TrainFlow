# container: pass HIPBLASLT_* env vars through to container

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/506) · state: closed · merged: True

## Original PR description

## What
Enable `HIPBLASLT_*` environment variables to be passed through in Primus CLI container mode.

## Why
Some HipBLASLt tuning/config knobs are controlled via `HIPBLASLT_*` env vars.
Before this change, container mode only forwarded a limited allowlist (e.g. `PRIMUS_`, `NCCL_`, `RCCL_`, `GLOO_`, `IONIC_`), causing container runs to differ from direct-mode behavior and making tuning/debugging harder.
