File: `primus/cli/main.py` · line 107

The logic assumes that a token after '--' is a command, but '--' is typically used to separate options from positional arguments in Unix conventions, not to prefix commands. If a user runs `primus -- train`, this would incorrectly extract 'train' as the command when it should be treated as a positional argument after the separator. Consider removing this branch or clarifying the intended behavior.
