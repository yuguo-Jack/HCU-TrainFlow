# feat(gpt-oss): add MI455X v0 baseline launcher for GPT-OSS 20B / 120B

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1264) · state: closed · merged: True

## Original PR description


Add examples/megatron/models/gpt-oss/run_gpt_oss_mi455x.sh, a single-node 4x MI455X (gfx1250) launcher for GPT-OSS 20B and the 8-layer 120B proxy, plus a README with the v0 baseline and the known issues on amdprimus/amdprimus:tas-20261011.

The script starts the image from the host (or runs directly inside it) and applies the gfx1250 settings every run needs: PRIMUS_GPU_MODEL=MI455X, Triton expert scheduling off (env var plus a patch of Triton's default), the Triton Turbo attention backend and no GPU core dumps. 20B uses TE cross entropy because the native fused CE fails at step 1 on pinned host memory; the 120B proxy disables the yaml's torch profiler.

v0 baseline (EP4, mock data, iterations 3-10):
  GPT-OSS 20B        2114 ms/iter, 819 TFLOP/s/GPU, lm loss 11.34809
  GPT-OSS 120B proxy  447 ms/iter, 191 TFLOP/s/GPU, lm loss 11.39837
