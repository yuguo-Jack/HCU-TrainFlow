# fix(projection): price DeepSeek-V4 attention as sparse MLA and use CDNA4 peaks

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1300) · state: open · merged: False

## Original PR description

The V4 attention core was priced as a dense causal FAv3 kernel over (window + pool) keys with a flat 0.5 causal factor. That halved the constant-width window band and the CSA top-K (which is nearly full at long sequences), used FAv3's 256-row D=128 tiles for a head_dim-512 shared-latent kernel, and gave a backward that was flat across head counts whenever fewer than 256 keys were visible.

- Count valid keys per query exactly: full-width window band, causal HCA pool, and CSA top-K times the fill ratio already used by the dKV scatter.
- Add SDPASimulator.simulate_sparse_mla: one workgroup per (token, head block), five per-token backward GEMMs, softmax on the vector units, and a floor at the matrix peak. PRIMUS_ATTN_V4_CORE=fav3 restores the old core.
- Set MI350X/MI355X/gfx950 peaks and base clocks to the published peak values, and size the indexer score from the target's peak instead of a fixed anchor.
