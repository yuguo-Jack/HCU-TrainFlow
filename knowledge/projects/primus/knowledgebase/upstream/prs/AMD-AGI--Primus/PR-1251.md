# feat(auto_benchmark): add release suites, backends and record the setup with each result

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1251) · state: closed · merged: True

## Original PR description

## Summary
- Add an interactive auto-benchmark menu for Megatron, TorchTitan, Megatron Bridge, MLPerf, MaxText, and MaxDiffusion on MI300X, MI325X, and MI355X.
- A Docker release choice detects the GPU and runs the Primus suite (megatron, megatron_bridge, torchtitan) or the JAX suite (maxtext, maxdiffusion) with no model prompts. A login node submits one Slurm job; a GPU machine detaches the run so a dropped SSH session does not stop it.
- One failed model is logged and the rest of the suite still runs. Each run keeps the log, working YAML, system snapshot, reproduce script, and, on failure, a GPU capture plus a failure archive. Repo YAML files are not modified.
- Metrics drop the first five steps and use a harmonic mean for throughput. Every CSV row and the suite manifest record the image digest, Primus commit, submodule pins, GPU, framework versions, and the ROCm version from `amd-smi` inside the launched image. The host ROCm install is not recorded, and tokens are not written into snapshots or Slurm scripts.

## Test plan
Tested on MI300X with two models for each suite. Each model finished with status OK and wrote a metrics row.

- [x] Megatron: `llama3.1_8B-BF16-pretrain`, `mamba_370M-pretrain`
- [x] Megatron Bridge: `qwen3_32b_lora_posttrain`, `qwen3_32b_sft_posttrain`
- [x] TorchTitan: `llama3.1_8B-BF16-pretrain`, `llama3.1_8B-FP8-pretrain`
- [x] MaxText: `llama2_7B-bf16-pretrain`, `llama3_8B-bf16-pretrain`
- [x] MaxDiffusion: `flux_dev-pretrain`, `wan2.1_1.3b-pretrain`
