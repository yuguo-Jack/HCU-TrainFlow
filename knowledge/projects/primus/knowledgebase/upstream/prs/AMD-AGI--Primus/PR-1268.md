- Copilot · comment · 2026-10-19T15:01:32Z · [source](https://github.com/AMD-AGI/Primus/pull/1268#discussion_r4315381207)

File: `examples/megatron/models/deepseek-v3/run_deepseek_v3_proxy_mi455x.sh` · line 105

Setting `PRIMUS_RECOMPUTE_LAYER_IDS=0` makes training fail during model construction. Primus's CLI parser converts `0` to an integer, but `validate_specified_recompute_layers()` accepts a string or iterable and raises `TypeError: 'int' object is not iterable`. Pass the comma-separated IDs as a list literal so both single-layer and multi-layer selections work.
