# Emit MLPerf 6.1 disclosure keys from the Flux diffusion trainer

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1231) · state: closed · merged: True

## Original PR description

## Summary
- Emit the MLPerf Training 6.1 disclosure keys from the Flux FSDP2 trainer in `_mlperf_log_run_start`, after `evaluation_frequency` and before `init_start`.
- Validate `MLLOG_LOWEST_NUMERICAL_PRECISION_IN_{LINEAR,ATTN,COMM}` and `MLLOG_CONFIG_FILENAME` on every rank in `_setup_mlperf`, before the logging import and before training. Rank 0 still writes the compliance log.
- Keep the args-independent helper in `primus/backends/diffusion/patches/flux_mlperf_v61_logging.py`. `MLLOG_LOWEST_NUMERICAL_PRECISION_LINEAR` remains a linear alias; `IN_LINEAR` wins when it is set, including when it is empty.
- Parallelism for this backend is TP=1, PP=1, EP=1, `context_parallelism=sp_size`, and `micro_batch_size=per_device_train_batch_size`.

## Test plan
- [x] `pytest tests/unit_tests/backends/diffusion/test_flux_mlperf_logging.py` in `rocm/primus:v26.7`: 10 passed. Covers key order, the linear alias, and invalid or missing precision raising on non-zero ranks.
- [x] 20-step Flux smoke on 1x8 MI355X (`flux.1_schnell_t2i-pretrain.yaml`, `MLPERF_ENABLE=true`, sdpa, local batch 1). `torchrun` exited 0.
- [x] Compliance log contains, in order: `evaluation_frequency`, `lowest_numerical_precision_in_{linear,attn,comm}` (`fp8` / `bfloat16` / `bfloat16`), `tensor_parallelism`, `pipeline_parallelism`, `context_parallelism`, `expert_parallelism`, `micro_batch_size`, `config_filename`, then `init_start`. `run_stop` is `aborted` with `samples_count=160`, which is expected for a short run that does not hit the accuracy target.

## Notes
- Diffusion hook pin is already `mlperf-logging @6.1.0-rc2`. This PR does not change the global `pyproject.toml` pin.
- Official Flux launchers (`examples/mlperf/flux1/run_with_docker.sh` and `run_with_docker_slurm.sh`) still do not export or forward the new `MLLOG_*` variables. A stock launch raises `ValueError` on every rank until those are set.
- The Megatron `MLPerfLogger` is unchanged. The helper is available if that path needs the same extraction later.
