# feat(specforge): take online capture settings from the recipe

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/1313) · state: closed · merged: False

## Original PR description

## Summary
- Online SGLang capture now reads `model.draft_model_config` and `model.target_model_path` from the SpecForge Hydra file (or a Hydra override) instead of always using the Qwen3.5-4B draft layer ids.
- `--skip-tokenizer-init` stays on by default and can be turned off with `specforge_online.skip_tokenizer_init` or `SKIP_TOKENIZER_INIT`, so a checkpoint that assigns `chat_template` during server load can initialize the tokenizer.
- Drop the `--no-deps` tensorboard install from the light-deps script and smoke-check `torch.utils.tensorboard.SummaryWriter`.

## Test plan
- [x] Ran the online launch helpers locally (module is `pytest.mark.skip` in CI): Qwen layer ids still win when the recipe has no draft file, an explicit `capture_layer_ids` override still wins, a recipe draft JSON and `target_model_path` are picked up, and `skip_tokenizer_init: false` removes `--skip-tokenizer-init`.
- [ ] Build the SpecForge image and confirm `smoke-check.sh` still passes, including the SummaryWriter import.
