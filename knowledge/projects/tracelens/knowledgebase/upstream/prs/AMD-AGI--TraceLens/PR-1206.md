# feat(perfmodel): add DeepSeek-V4 sparse MLA and MXFP4 indexer logits perf models

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1206) · state: open · merged: False

## Original PR description

## Summary

Adds perf models for the DeepSeek-V4 sparse attention ops from #1174:

| Op | Model | Notes |
|---|---|---|
| `aiter::mla_sparse_prefill_fp8_asm_fwd` | `mla_sparse_prefill_fp8_asm_fwd` | Decode steps; attended rows from the sq/sk step annotation |
| `aiter::_fwd_sched_raw` (MXFP4 MQA logits) | `pa_mqa_logits_mxfp4` | Prefill and decode; scored keys = causal pairs / CSA stride |
| `fused_compress_attn_*`, `hca_compress_forward_*` | category only | Work depends on a device-side boundary count |

- Sparse MLA: the index buffers are CUDA-graph capacities, so each query's rows come from the annotation: `min(ctx, 128)` window rows plus `min(ctx/4, 1024)` CSA or `ctx/128` HCA compressed rows. The layer type is stamped from the layer's compress kernel. The head dim is the output's (512): each 512-byte FP8 NoPE row packs 448 values with their scales.
- MXFP4 logits: per row, Q, its scales and the weights are read once. Per key: the packed KV row, its scale, a page-id share and an FP32 logit. KV reads are shared across the `q_per_block` rows of a CTA.
- Shared helper `InferenceAttention._causal_kv_pairs`, also used by `sgl_kernel_fast_topk_transform_fused`.

## Validation

- Formulas checked against the aiter source (`mla_sparse_prefill.py`, `pa_mqa_logits_mxfp4.py` and its kernel/schedule headers).
- Unit tests for CSA/HCA row counts, the window/top-k caps, prefill causal pairs, `q_per_block` sharing, no-perf paths and the mode stamping; `tests/test_perfmodel_extensions.py` passes (331).

## Limitations

- Needs an sq/sk step annotation; capture traces without one report no FLOPs or bytes.
- Sparse MLA prefill and mixed steps are no-perf.
- MXFP4 logits ignores the round-up to whole 64-key tiles.
- Not yet run on a real trace end to end.
