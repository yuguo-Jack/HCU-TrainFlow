# Eliminate redundant compute_metrics() calls

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/695) · state: closed · merged: False

## Original PR description

self.GPUEventAnalyser(list_kernels).compute_metrics()["busy_time"] does a large amount of work that is not needed just to get busy time. 

By creating a separate function to compute busy time, we avoid the unecessary work that compute_metrics calls: get_gpu_event_lists() and compute_metrics_dict().

## Pull request overview

This PR optimizes GPU busy-time calculation in `TreePerfAnalyzer` by avoiding full `GPUEventAnalyser.compute_metrics()` execution when only `"busy_time"` is needed, reducing unnecessary categorization and metric computation work.

**Changes:**
- Added `GPUEventAnalyser.compute_busy_time()` to compute merged busy time directly from a kernel/event list.
- Updated `TreePerfAnalyzer.compute_perf_metrics()` to use `compute_busy_time()` instead of `compute_metrics()["busy_time"]`.
- Removed redundant re-traversal for non-data-movement kernels by filtering the already-collected kernel list in-memory.
