# fix(ci): keep every skipped package out of the coverage gate

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1190) · state: closed · merged: True

## Original PR description

## Summary

- The ModelUtils and Visualizer jobs stay skipped when a pull request does not touch them. The 95% coverage gate still has to leave those packages out of the total.
- coverage.py keeps a single `--omit` value, so the second flag in #1186 replaced the first. On #1128 that dropped Visualizer and left ModelUtils at 0%, which failed Codecov (51%) and the Unit Tests gate.
- Pass every skipped package in one quoted, comma-separated `--omit` for both `coverage xml` and `coverage report`. A push still runs both suites and passes no flag.

## Test plan

- [x] With coverage 7.16.2, `--omit=pkg/modelutils/* --omit=pkg/visualizer/*` reports only the last package as omitted, and `--omit=pkg/modelutils/*,pkg/visualizer/*` omits both, including nested modules.
- [ ] After merge, a pull request that does not touch ModelUtils or Visualizer (for example #1128) passes Codecov and Unit Tests while those jobs stay skipped.
