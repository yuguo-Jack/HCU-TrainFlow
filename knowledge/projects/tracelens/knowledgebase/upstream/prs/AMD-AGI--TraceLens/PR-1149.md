# Keep graph edges on values that are actually read

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1149) · state: closed · merged: True

## Original PR description

## Summary
- A method whose body only forwards to `self.<method>(...)` is expanded as that method, and shape inference follows the same delegation. An unresolved module takes the tensor its meta-trace recorded, including a structured model output.
- A discarded unpack slot (`_`), a discarded call, an unread merge, and a statement-level check stay connected, so they are not reported as dead nodes.
- A mutually exclusive branch with only one live arm is removed. Graph generation warns if one is still present at the end. Each branch records the variable it rebinds (`merges:`).
- Layer variants of one repeat stack meet in a single output tile of that stack. The consumer reads that tile, so the collapsed stack has one edge out and opening it shows one input per variant. On Qwen the tile is `hidden_states`, fed by the 48× and 16× loop outputs, and the final norm reads it.
- A boundary that took a branch's name takes the variable that branch rebound once the branch is no longer drawn. Qwen's `create_causal_mask` input from `Expand` is `position_ids`. The `use_vmap` branch inside that function is still drawn, and the function's output tile keeps that branch's name.
