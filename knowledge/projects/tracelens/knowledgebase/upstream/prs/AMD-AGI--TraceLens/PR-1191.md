# feat(roofline): cost traced persistent state

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1191) · state: closed · merged: True

## Original PR description

## What

Add a generic, trace-derived memory roofline row for every tensor the model graph writes into persistent state. The existing code tracer marks a producer with `stores: <state name>` and records its output shape and dtype. The projection now prices that exact tensor as one HBM read plus one replacement write.

This covers recurrent state and caches without recognizing a model family, kernel name, or configuration key. A repeated decoder section scales the state row with the graph’s existing repeat count.

## Scope

- No Mamba, gated-delta, or model-specific config matching.
- No attempt to estimate fused-kernel FLOPs; the new row only fills the persistent-state memory traffic that the traced graph proves exists.
- State tensors without a resolved shape or known dtype remain unmodeled rather than guessed.

## Tests

- Added unit coverage for the state read/write byte count, memory-bound roofline time, repeat scaling, and unresolved-state skip path.
- `python3 -m py_compile TraceLens/Visualizer/model_explorer_export/roofline_projection.py tests/Visualizer/test_roofline_projection.py` passed.
- Targeted pytest could not run in this environment because no available Python environment has `pytest` installed.
