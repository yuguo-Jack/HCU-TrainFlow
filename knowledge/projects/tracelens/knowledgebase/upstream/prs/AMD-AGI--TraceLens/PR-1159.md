# fix(ci): report Unit Tests on every pull request

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1159) · state: closed · merged: True

## Original PR description

## Summary
- Pull requests no longer use a path filter on the Unit Tests workflow. Branch protection requires the `Unit Tests` and `Codecov` checks, and a skipped workflow never reports them, so diffs that do not touch Python (such as a `.patch` file) stayed pending and blocked merge.
- `scripts/select_related_tests.py` still selects only the related tests, and the existing gate passes when those suites are skipped. Pushes to `main` keep the path filter and still run the full suite.

## Test plan
- [ ] Confirm this pull request starts the Unit Tests workflow and reports both `Unit Tests` and `Codecov` (this diff changes the workflow, so the selector runs the full suite).
- [ ] After merge, a pull request that only changes a non-Python path should start the same workflow, skip the test suites, and still post successful `Unit Tests` and `Codecov` checks.
