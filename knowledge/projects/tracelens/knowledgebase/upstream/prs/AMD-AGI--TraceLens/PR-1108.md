# perf: use deque for BFS in get_subtree_events

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1108) · state: closed · merged: True

## Original PR description

`list.pop(0)` is O(N) per call, making the BFS O(N²) for large subtrees. `deque.popleft()` is O(1), reducing overall complexity to O(N).

## Summary
- Fix O(N^2) BFS traversal in `get_subtree_events` by replacing `list.pop(0)` with `deque.popleft()`
- `list.pop(0)` shifts all remaining elements on every call, making BFS quadratic in subtree size
- `deque.popleft()` is O(1), reducing overall traversal to O(N)
- `deque` is already imported in the file but was not used here

## Context

`get_subtree_events` is called per graph root during capture/replay merge. On large traces with thousands of iterations and subtrees containing hundreds to thousands of events each, the quadratic cost accumulates significantly.
