# Fix --sheets all when kernel_summary is missing

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1046) · state: closed · merged: True

## Original PR description

### Summary

`TraceLens_compare_perf_reports_pytorch --sheets all` fails with `ValueError: kernel_summary sheet not found` on every report generated without `--enable_kernel_summary` — which is the default for PyTorch reports. The `kernel_summary` sheet is rocprof-specific and requires an opt-in flag at report-generation time, but the comparison tool treated it as mandatory whenever `all` was requested.

### Implementation

**`TraceLens/Reporting/compare_perf_reports_pytorch.py`**

Restructured the `kernel_summary` block in `generate_compare_perf_reports_pytorch()`. If `kernel_summary` exists in the report, process it normally. If it's absent and the user explicitly requested `--sheets kernel_summary`, raise an error explaining that `--enable_kernel_summary` is needed at generation time. If it's absent and the user just said `--sheets all`, skip `kernel_summary`.

**`tests/test_compare_perf_reports.py`**

Added two unit tests:
- `test_sheets_all_skips_missing_kernel_summary` — verifies `--sheets all` succeeds and produces `gpu_timeline` + `ops_summary` results without `kernel_summary` when the sheet is absent.
- `test_sheets_kernel_summary_explicit_raises_when_absent` — verifies that explicitly requesting `--sheets kernel_summary` when `kernel_summary` raises a `ValueError` with a message pointing to `--enable_kernel_summary`.

### Tests

- Both new tests pass locally.

Closes #1015
