# fix(tracelens): keep one decimal in the measured arch spec

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1123) · state: closed · merged: True

## Original PR description

## Summary
- `microbench._build_measured_arch_json` stored `int(round(x))` for every peak, so a measured value below 0.5 TFLOPS (fp64 at 0.4) became 0 and is dropped by consumers that skip zero peaks, and the other peaks shifted by up to half a TFLOPS. It now stores `round(x, 1)` for the TFLOPS peaks, `mem_bw_gbps` and `memory_gb`; the benchmarks already report one decimal, and bundled `Radeon_8060S.json` already holds fractional peaks.
- The microbench README now states the values are floats.

## Test plan
- [x] New `test_build_measured_arch_json_keeps_sub_one_tflops` and the updated `test_build_measured_arch_json_shape` fail before the change (`0 == 0.4`, `123 == 123.4`) and pass after.
- [x] `tests/test_perfmodel_benchmarking.py` on current `main` with this change: 47 passed, 3 skipped (46 passed, 3 skipped before; the one extra test is the new one). Run with a CPU `torch`; no GPU call is made.
