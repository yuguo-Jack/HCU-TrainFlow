# docs(arch): mark the Radeon 8060S spec as theoretical peak

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1171) · state: closed · merged: False

## Original PR description

Adds a `source` field to `Radeon_8060S.json` saying its rates are theoretical peaks, from 40 CUs at 2.9 GHz and the 256-bit LPDDR5x-8000 memory interface, and lists the Ryzen AI Max+ 395 product page as the source for its figures in the arch README. No values change.

Tests: the spec loads through `arch_utils.load_arch`; `tests/test_reporting_gpu_arch.py`, `tests/test_analysis_agent_utils.py`, `tests/test_roofline_bound.py` and `tests/test_util.py` pass.
