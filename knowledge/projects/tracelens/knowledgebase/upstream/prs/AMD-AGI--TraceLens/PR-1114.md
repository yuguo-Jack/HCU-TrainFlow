# Add copyright check to lint

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1114) · state: closed · merged: True

## Original PR description

Unit tests run when certain files are changed. This is so that unit tests don't run for minor changes to documentation or files in TraceLens that don't affect analysis. However this caused https://github.com/AMD-AGI/TraceLens/pull/1084 to merge without test failure. The PR adds `.md` and `.sh` files that are not in core TraceLens or in `tests/` so the unit tests weren't triggered. This behavior is correct since the PR didn't affect any component of TraceLens analysis. However this meant that the copyright check didn't run when it should have.

Since the copyright check is moreso a formatting check, this should go in the lint checks. However the lint checks also only run when certain files are changed. But since they're very lightweight (~30 seconds), this PR changes them to always run regardless of what's changed.

This prevents new files from being added and merged without copyright headers.
