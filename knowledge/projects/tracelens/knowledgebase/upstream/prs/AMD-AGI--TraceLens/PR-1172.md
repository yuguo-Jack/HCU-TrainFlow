# chore(arch): let the Radeon 8060S use the arch microbenchmark

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1172) · state: closed · merged: True

## Original PR description

Boards without a bundled arch spec, such as the Radeon AI PRO R9700, get their max-achievable rates from the arch microbenchmark, which measures them on the board and keeps the result locally. This removes `Radeon_8060S.json` so the Radeon 8060S follows the same path. Spec files without `memory_gb` stay supported.

Tests: `tests/test_reporting_gpu_arch.py`, `tests/test_analysis_agent_utils.py`, `tests/test_analysis_agent_category_utils.py`, `tests/test_roofline_bound.py`, `tests/test_util.py` and `tests/test_perfmodel_benchmarking.py` pass.
