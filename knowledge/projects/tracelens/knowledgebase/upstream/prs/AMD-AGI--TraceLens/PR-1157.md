# Visualizer cleanup

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1157) · state: closed · merged: True

## Original PR description

## Summary
- Load `ai-edge-model-explorer-visualizer` 0.1.2 the way its README specifies: the component and static files come from unpkg, and the layout worker is served from the same origin because a cross-origin worker is not supported. The Apache-2.0 license and the "Copyright 2024 The Model Explorer Authors" notice ship with the viewer.
- Route GitHub and PyPI downloads through `github.py`, and keep ModelUtils from importing the Visualizer with a forbidden import-linter contract. Shape inference stays in ModelUtils.
- Require `Unit Tests` and `Codecov` on main. Pushes to main run both suites, and each pinned model graph is built once and cached.
- Replace the vendored Kimi and kernel sources with a short stub. The Visualizer tests are 15 files. Graph-structure checks that used to read upstream GLM line numbers now load `tests/fixtures/glm_patterns` and assert by module name.

Still open: the Visualizer suite is about 20k lines, not 9–10k, because the branch-hit tests in `test_merge_extra.py` and `test_export_merge.py` are still there. Loop threading, operation labels, and the fact sheet still load the real GLM-5.3-Flash pin.

- [ ] `lint-imports` keeps the acyclic contract and the ModelUtils/Visualizer forbidden contract
- [ ] A pull request that only changes viewer `.js`, `.html`, `NOTICE`, or `.LICENSE` still triggers `visualizer-tests`
