[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1176) · state: open · merged: False

## Original PR description

## Summary

Adds FLOPs/bytes models and SGLang Flash injector bridges for the DeepSeek-V4.1-Flash gaps (indexer, sparse decode, mHC, and remaining pack).

**Related:** #1174 #1140 #1106

### Changes

| Gap | Approach |
| --- | --- |
| `sgl_kernel::deepseek_v4_topk_transform_512` | Full FLOPs model (+ `fast_topk`) |
| `pa_mqa_logits_fp4_*` | `pseudo_pa_mqa_logits_fp4` model + injector; Synthetic Op category-only fallback |
| `_quantize_fp4_indexer` | `pseudo_quantize_fp4_indexer` + injector |
| `_pa_decode_sparse_*` | Bridge to existing `pseudo_v4_paged_decode_{swa,csa,hca}` |
| sparse reduce | Category-only / same owner family |
| `hc_boundary_*` | New `_MHCBase` model + injector |
| sinkhorn | `hc_mix_reduce_sinkhorn` + injector |
| indexer TopK (`aten::topk`) | Guarded FLOPs map + pseudo parent for root TopK |
| MXFP8 GEMV | `pseudo_mxfp8_gemv` + injector |
| MoE gemm2/reduction children | Injector → `moe_flydsl_stage2` shapes (partial attach) |
| rmsnorm fake-quant | `pseudo_rmsnorm_fake_quant_fp8` |
| router GEMV/gate | Pseudo models + injectors |
| FlashMLA prep | `fused_k_norm_rope_q_flashmla` |
