# Add a model visualizer agent skill

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1165) · state: closed · merged: True

## Original PR description

## Summary
- Add a TraceLens agent skill that exports a Hugging Face checkpoint to a standalone Model Explorer HTML file with `visualize_model_in_explorer`.
- Document how to run it from chat and from the `agent` CLI, and ship it in the package the same way as the analysis orchestrator.
- Grade the skill with skillscope: a skill card, routing prompts, and one behavioral case that expects `model.html`.

## Test plan
- [ ] `skillscope structural --skills-dir 'TraceLens/Agent/Analysis/skills/analysis-orchestrator,TraceLens/Agent/Visualizer/skills/model-visualizer' --skill-files skill-card.md --skill-sections Description,Owner,License` passes for the new skill
- [ ] Confirm AMD Skills Checks runs structural validation for both skills on this PR
- [ ] Optionally dispatch routing and behavioral checks; the behavioral case needs the Visualizer extra and Hugging Face network access
- [ ] From a chat: `Follow the model visualizer installed with TraceLens and export <model> to <path>.html` writes an HTML file containing `model-explorer-visualizer`
