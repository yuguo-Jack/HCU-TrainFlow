# feat(inference-analysis): add SGLang prefill CUDA-graph capture patch

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1153) · state: closed · merged: True

## Original PR description

## Summary
Adds `examples/custom_workflows/inference_analysis/sglang_gc_patch/sglang_0_5_21/prefill_cuda_graph_runner.patch`,
the prefill companion to the existing `decode_cuda_graph_runner.patch` in the same
directory. It brackets SGLang's prefill CUDA-graph capture
(`BreakableCudaGraphBackend`) with the torch profiler so each captured prefill
shape is exported as a per-shape sidecar trace
(`PrefillCudaGraphRunner_tokens_<n>_rank<r>.json.gz`) under
`graph_capture_profile_dir()`, gated on `--enable-profile-cuda-graph` +
`SGLANG_GRAPH_BATCH_CAPTURE` (identical gating to the decode patch).

Currently only decode graph replays are decomposed; prefill graph replays remain
opaque (`hipGraphLaunch`), which for prefill-heavy traces trips the TraceLens
inference analysis graph-under-recorded (degraded) gate. This patch supplies the
missing prefill graph-capture sidecars so those replays can be decomposed.

## Changes
Adds a single patch artifact (one new file in this repo). When applied to the
in-container SGLang, the patch modifies two SGLang source files:
- `python/sglang/srt/model_executor/runner/prefill_cuda_graph_runner.py` — adds
  the profiler context, per-shape `_set_profile_trace_tag`, and post-process.
- `python/sglang/srt/model_executor/runner_backend/breakable_cuda_graph_backend.py`
  — steps the runner's profiler once per captured shape.

## Validation
Exercised end-to-end on `lmsysorg/sglang:v0.5.21-rocm10-mi35x`,
DeepSeek-V4-Pro-0813, TP8, via a Magpie profile-only run:
- Prefill capture completed 74/74 shapes -> **392** `PrefillCudaGraphRunner_tokens_*`
  sidecars (49 sizes x 8 ranks), alongside the decode patch's 32
  `DecodeCudaGraphRunner_bs_*` (4 x 8).
- `capture.json` `status: complete`.
