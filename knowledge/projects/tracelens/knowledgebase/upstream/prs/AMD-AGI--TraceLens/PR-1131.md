# Perf models for SGLang DSA top-k ops (GLM-5.3 decode)

Two top-k ops in GLM-5.3 FP8 SGLang decode traces showed up as unmodeled `other`. This PR gives both a perf model:
| op | change | category |
|----|--------|----------|
| `sgl_kernel::fast_topk_transform_fused` | new model `sgl_kernel_fast_topk_transform_fused` | `InferenceAttention` |
| `sglang_profiler::topk__post_process_topk_ids` | mapped to existing `sglang_fused_append_shared_experts` | `MoE_aux` |

## Changes

- `PerfModel/extensions/attention_perf_model_extensions.py`: new `sgl_kernel_fast_topk_transform_fused`.
- `PerfModel/extensions/pseudo_ops_perf_utils.py`: register both ops.
- `Reporting/generate_perf_report_pytorch_inference.py`: add `fast_topk_transform_fused` to the
  `apply_annotation` name filters so it gets the step annotation.
- `tests/test_sglang_dsa_decode_perf_models.py`: new tests.

## Modeling

**`fast_topk_transform_fused`** (DSA indexer top-k + page-table gather). Inputs are
`score (rows, L_max) fp32`, `lengths`, `dst_page_table (rows, topk) int32`, `src_page_table`

`score` is padded to the max context length, so the real work is the number of valid scores.
That number comes from the step annotation, which is causal within each request:

```
valid_scores = Σ_{c,g} sqsk - (sqsq - sq) / 2
flops        = valid_scores                       # one compare per score
bytes        = valid_scores * bpe(score)          # read scores
             + rows * (min(topk, valid_scores/rows) + topk) * bpe(int32)   # gather src + write dst
```

Precision is the score dtype, and MAF type is `vector`. Without a step annotation it
returns `None` (fail-closed), the same way the existing annotation-driven attention models behave.

**`topk__post_process_topk_ids`**: on the aiter path this op only launches
`_fused_append_shared_experts_kernel`. Its `(ids, weights)` args have the same layout as
`sglang_fused_append_shared_experts`, so it reuses that model.


## Tests

- `tests/test_sglang_dsa_decode_perf_models.py`: 7 passed. Covers the mappings and categories,
  post-process flops/bytes/precision, decode and short-row bytes, causal prefill valid scores,
  and the missing-annotation case.
- The full suite on a compute node passed 3,269 tests. The remaining failures are environmental
  (no JAX extra, pandas missing in a subprocess, and a hanging triage smoke test). The same
  tests fail on `origin/main`.
