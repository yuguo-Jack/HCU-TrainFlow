[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1177) · state: closed · merged: True

## Original PR description

## Summary

Adds `TraceLens/Agent/Visualizer/skills/model-roofline-projection/`, a skill driving `TraceLens_model_roofline_projection` (merged in #1175): projects a kernel-by-kernel roofline (FLOPs, bytes, compute/memory-bound time) for a checkpoint from its config and modeling source alone — no trace, no GPU run.

Structured like the existing [model-visualizer](TraceLens/Agent/Visualizer/skills/model-visualizer/) skill:

- `SKILL.md` — overview, rules, workflow index, primary outputs
- `reference.md` — step-by-step decision procedure (inputs, install, command, GPU arch selection, device sharding, config/attention/regime, output formats, footguns)
- `skill-card.md` — description/owner/license
- `evals/` — routing + one behavioral case, graded with [skillscope](https://github.com/amd/skillscope)

## Other changes

- `.github/workflows/skill-evals.yml`: register the new skill in the structural, routing, and external-reference jobs (same pattern as `model-visualizer`).
- `setup.py`: exclude the new skill's `evals/` from the built wheel, same as the other packaged skills.
- `TraceLens/Agent/Visualizer/README.md` and `docs/how-to/generate-model-roofline-projection.md`: cross-link the new skill.
