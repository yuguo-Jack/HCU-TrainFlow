## Original PR description

## Summary
- Stacked on #1134 (`feat/torch-module-input-spec`). This pull request's base is that branch, so the diff here is only the unpublished-pin commit. Merge #1134 first; GitHub will then retarget this pull request onto `main`.
- Auto-venv still switches when a checkpoint's `transformers_version` is newer than the installed release, and still switches an older pin only when the model cannot be imported. An unpublished newer pin installs the newest PyPI release after it (`5.18.0.dev0` → `5.20.2`); if no published release is newer, it installs the current transformers `main` commit.
- Modeling-file lookup tries the wrapper type before the flattened text type, so a Muse Spark config resolves to `modeling_muse_spark.py` without `--code-path`. Hub downloads of modeling code skip weight blobs, and config download refuses them.
- `python -m TraceLens.Visualizer.visualize_model_in_explorer unsloth/Muse-Spark-Open-816B-A42B` is the full export. It provisions the substitute release into `~/.cache/tracelens/model-envs/` and writes the HTML viewer.
