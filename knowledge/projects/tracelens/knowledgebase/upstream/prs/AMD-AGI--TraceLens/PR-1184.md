# feat(graph): generalize expansion to non-uniform nested repeated groups (ConvNeXt convs)

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1184) · state: closed · merged: True

## Original PR description

Builds on #1181. Generalizes the static **graph** expansion from *one uniform decoder stack* to *arbitrary non-uniform nested repeated groups*, so a convolutional model's encoder renders as real graph nodes — the graph-path counterpart to #1181's meta-forward roofline supplement.

## The problem
The pipeline modeled every checkpoint as a single uniform decoder stack (`num_hidden_layers` + one `decoder_class`; `_select_primary_group` picks **one** `nn.ModuleList`). ConvNeXt's 4 **non-uniform** stages (`depths=[3,3,27,3]`, channels `[128,256,512,1024]`) can't fit that, so its convolutions never became graph nodes at all. ResNet's stage bodies are `nn.Sequential`, so they were invisible to a ModuleList-only walk.

## Approach — driven by the live meta tree (AST untouched)
The AST already parses the element classes (`ConvNextLayer` has `forward_ops=5`: dwconv/permute/layernorm/pwconv1/act/pwconv2); only the **repeat structure** was missing. That comes from `walk_meta_module_tree`, so no `ast_analyze.py` changes.

- **`blocks.RepeatedGroup` + `extract._build_nested_groups`** — reconstruct the nesting tree from the flat `MetaModuleGroup` list by dotted-path containment, collapsing per-stage index segments (`stages.{0..3}.layers` → one child with `per_index_counts=[3,3,27,3]`).
- **`extract._is_non_uniform`** — fires only on differing **positive** per-position counts, the one signal a uniform transformer can't produce. A standard MoE stack (uniform expert count) and a dense-replace MoE (`[0,0,256,…]`) both stay uniform. `reconcile_live_module_groups` takes an early return that leaves the single-stack fields untouched ⇒ **LLM path byte-identical**.
- **`merge._append_nested_repeated_group`** — emits the tree: each stage a flat, series-threaded `N×` container whose element-class body is expanded via the existing `_append_section` (element trees registered like `_append_vision_section_tree`). The container banner is the stage index (`stage 2 · 27× ConvNextLayer`).
- **Leading convs** — the stem stays the patch-embedding conv at the front of the encoder. A mixed-class list (ConvNeXt's downsample is LayerNorm then Conv2d) is drawn element by element ahead of that stage's repeated body, not as `N×` the first class. `ast_build._attach_conv_meta_shapes` stamps each conv's concrete per-stage `[B,C,H,W]` from a meta forward (`trace_meta_conv_ops`), matched by `meta_path` (an exact module path for a leading conv).
- **Stage Sequentials** — `repeated_module_groups` also records a homogeneous `nn.Sequential` whose parent is a `ModuleList` element (ResNet's `stage.layers`). A Sequential nested inside the block, or a heterogeneous one, stays part of the element class.
- **Fact sheet** — a non-uniform model lists the stage tree, pipeline first (`stage 2: ConvNextLayerNorm → Conv2d, 27× ConvNextLayer`).

## Validation
`facebook/convnext-base-224-22k`:
- Encoder renders as `stage 0 · 3×` / `stage 1 · 3×` / `stage 2 · 27×` / `stage 3 · 3×` `ConvNextLayer`.
- Dwconv sizes `[B,128,56,56]` / `[B,256,28,28]` / `[B,512,14,14]` / `[B,1024,7,7]`; stem `[B,3,224,224]→[B,128,56,56]`.
- Downsample convs lead stages 1–3 at `[B,256,28,28]` / `[B,512,14,14]` / `[B,1024,7,7]`.
- Fact sheet lists the four stages and the norm→conv pipeline.

`microsoft/resnet-50` (`depths=[3,4,6,3]`):
- Stages render as `3×` / `4×` / `6×` / `3×` `ResNetBottleNeckLayer`, labeled per stage.
- Fact sheet lists `stage 2: 6× ResNetBottleNeckLayer`. The stem conv leads the encoder.

Roofline CLI still costs every live conv from the meta pass and supersedes the graph's conv rows, so a repeated stage is not double-counted. Existing Visualizer graph-build suites pass unchanged (LLM/fixture no-regression).

## Tests
- `tests/ModelUtils/test_nested_module_groups.py` (torch-free): reconstruction, the non-uniform predicate (uniform LLM, uniform MoE, dense-replace MoE all stay uniform), pipeline-first order, and the ResNet depth tree.
- `tests/ModelUtils/test_meta_trace.py`: a ResNet-shaped module records stage Sequentials and the downsample class sequence, and does not record an inner conv stack or a mixed stem Sequential.
- `tests/Visualizer/test_nested_stage_graph.py` (torch-free): per-stage banners and the downsample conv leading the stage body.
- `tests/Visualizer/test_fact_sheet.py`: ConvNeXt and ResNet stage lines.
- `tests/Visualizer/test_convnext_graph.py` and `tests/Visualizer/test_resnet_graph.py` (torch, skip offline): end-to-end labels, fact sheet, and concrete spatial conv shapes.

## Scope
Full `detailed=True` diagram expansion for ConvNeXt still hits a **pre-existing** (base-branch) recursion in the diagram machinery, unrelated to this change; the roofline/export path is unaffected.
