# Pass --omit to coverage report when suites are skipped

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1186) · state: closed · merged: True

## Original PR description

The combine coverage step patches [run] omit in .coveragerc to omit ModelUtils/Visualizer from the coverage calculation. However this runs after coverage combine already ran, so the omit has no effect on the collected data. 
The coverage report then reports ModelUtils/Visualizer at 0% coverage and fails on PR.s

Pass --omit flags directly to coverage xml and coverage report so skipped packages are excluded from the report regardless of when .coveragerc is patched.
