# feat(perfmodel): model DeepSeek-V4 SGLang and vLLM inference ops

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1150) · state: closed · merged: True

## Original PR description

## Summary
- Add trace-backed FLOP and byte models for the SGLang DeepSeek kernels: preshuffle GEMM, Opus BMM, bounded MX quant, router, MoE sort, and MLA decode. Paged top-k and MLA stage 2 stay category-only because their trip counts are device-side.
- Cover the highest-runtime unmodeled vLLM ops: local-shard all-reduce, out-less preshuffle GEMM, Opus MoE stage 1, the softplus-sqrt router, Opus MoE sort, and one FP8-KV sparse-decode parent for each partial/reduce pair. Per-row top-k stays `InferenceAttention` only, because the scanned length is the device `seq_lens` tensor.

### Changed coverage check
- Skip the ModelUtils and Visualizer packages in the coverage check when their tests did not run, so a perf-model change is not failed for code it never touched. The 95% bar stays the same.

## Test plan
- [x] `pytest tests/test_perfmodel_extensions.py` (320 passed), including decode/prefill fixtures, hash and split-K branches, malformed metadata, and a sparse partial/reduce single-owner tree.
