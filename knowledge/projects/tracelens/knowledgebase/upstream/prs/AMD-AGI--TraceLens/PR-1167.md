# fix(tests): unbreak CI on pytest 9.2 (nested pytest.approx)

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1167) · state: closed · merged: True

## Original PR description

CI installs the latest pytest, and pytest 9.2.0 (released 2026-10-27) rejects nested data in `pytest.approx`. That breaks `test_standalone_module_candidates`, which compared a list of `(data_in_mb, data_out_mb)` tuples, on every branch:

```
TypeError: pytest.approx() does not support nested data structures: (6.923076923076923, 3.076923076923077) at index 0
```

This flattens the pairs into one list, so the test checks the same values and runs on both old and new pytest.

Tested: `tests/test_analysis_agent_utils.py` passes (247 tests) on pytest 9.2.0. It's the only test in the suite that fails on 9.2.0.
