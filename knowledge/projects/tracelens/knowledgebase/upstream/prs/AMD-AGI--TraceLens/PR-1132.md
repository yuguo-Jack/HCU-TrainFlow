# perfmodel: fused Q+K RMSNorm for aiter::_fused_qk_rmsnorm_kernel

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/1132) · state: closed · merged: True

## Original PR description

## Summary

Adds a tiny RMSNorm subclass for `aiter::_fused_qk_rmsnorm_kernel` (~1.82% glm53 decode). The fused kernel runs **two independent affine RMSNorms** (Q channels + K/KV channels); plain `aiter_rmsnorm` expects a single `[out, in, w, …]` layout and is the wrong target.

- New class `aiter_fused_qk_rmsnorm`: FLOPs/bytes = RMSNorm(Q) + RMSNorm(K) from Input Dims `[q, q_w, q_eps, k, k_w, k_eps, q_out, k_out]`
- Map `aiter::_fused_qk_rmsnorm_kernel` → that class
- Unit test with glm53 decode dims `((12,2048),…,(12,512),…)`
