# fix(treeperf): preserve kernel time when perf model fails

[Upstream PR](https://github.com/AMD-AGI/TraceLens/pull/611) · state: closed · merged: False

## Original PR description

When an operation is being added to `unified_perf_summary`, kernel metrics can be left blank or excluded from `unified_perf_summary` if:
- Operation name suggests there is a perf model, but perf model doesn't actually exist for the operation
- Operation parameters are missing or misconfigured

Kernel metrics (runtime) should not be dropped just because perf metrics (bandwidth, AI) could not be populated. Now, kernel metrics are populated regardless of if deriving perf metrics for it fails
