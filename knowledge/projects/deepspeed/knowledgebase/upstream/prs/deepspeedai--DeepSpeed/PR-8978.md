# Propagate the user script's exit code from launcher_helper

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8978) · state: open · merged: False

## Original PR description

`launcher_helper` always exits 0, so under `--launcher mpich` a rank that crashes or is killed is reported as a success.

**Cause:** it waits for the user script and then returns normally, and `mpirun` only sees the helper's exit status.

**Fix:** exit with the script's return code when it is not zero.

**Not a duplicate:** no open or closed PR or issue covers it (searched `launcher_helper exit code`, `launcher_helper returncode`).

**Test:** `pytest tests/unit/launcher/test_launcher_helper.py -q` on CPU only (macOS, no mpich): the new `test_launcher_helper_propagates_exit_code` fails before (`DID NOT RAISE SystemExit`) and passes after. Not covered: a real MPICH launch, GPU, ZeRO.
