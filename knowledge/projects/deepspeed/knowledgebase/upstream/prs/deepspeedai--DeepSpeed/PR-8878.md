# Precompute optimizer param_id counts in _check_for_duplicates

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8878) · state: open · merged: False

## Original PR description

## Summary

`DeepSpeedEngine._check_for_duplicates` (`deepspeed/runtime/engine.py`) is called during `deepspeed.initialize()` whenever a client optimizer or `create_generic_optimizer` is configured. Previously, for every parameter in `self.module.named_parameters()`, it iterated over `optimizer.param_groups`, rebuilt `[id(param) for param in group['params']]` twice per group, and scanned the resulting list with `in` and `.count(param_id)`:

```python
for name, param in self.module.named_parameters():
    param_id = id(param)

    def ids_list(group):
        return [id(param) for param in group]

    occurrence = sum([
        ids_list(group['params']).count(param_id) if param_id in ids_list(group['params']) else 0
        for group in optimizer.param_groups
    ])
```

For large models with $P$ parameters (e.g., deeply layered transformers or MoE models with thousands of parameter tensors), this performs $4 P^2$ iterations and allocates $2 P$ temporary ID lists on every rank during initialization.

## Change

Precompute parameter `id(param)` frequencies once across `optimizer.param_groups` using `collections.Counter` in $O(P)$ time, then verify `param_counts[id(param)] <= 1` for each named parameter in $O(1)$ time.

## Benchmark

| Parameter Tensors ($P$) | Before ($O(P^2)$) | After ($O(P)$ `Counter`) | Speedup |
|------------------------:|------------------:|-------------------------:|--------:|
| 2,000 | 0.4589 s | 0.0044 s | **104.9x** |
| 5,000 | 2.8071 s | 0.0115 s | **243.9x** |
| 10,000 | 11.1543 s | 0.0240 s | **465.7x** |

## Testing

- Added `test_check_for_duplicates` in `tests/unit/runtime/test_ds_initialize.py` covering both valid multi-group optimizers and duplicate parameter detection.
- Verified with `pytest tests/unit/runtime/test_ds_initialize.py -k test_check_for_duplicates`.
