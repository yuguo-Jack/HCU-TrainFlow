## Original PR description

# Description

Follow-up to #8688, which fixed 30 dead links: while checking the remaining links in the Markdown sources I found five more that are dead or point to pages that no longer exist. All old URLs return 404 and all replacements return 200 (checked today).

- **`README.zh.md`**: `https://hipc.org/advance-program/` no longer exists. The English `README.md` already dropped that link in #8688, so this mirrors the same change: the citation text stays, the link is removed.
- **`docs/index.md`**: the Lightning card points at the old PyTorch Lightning readthedocs API page (`.../pytorch_lightning.strategies.DeepSpeedStrategy.html`, 404); replaced with the current `https://lightning.ai/docs/pytorch/stable/api/lightning.pytorch.strategies.DeepSpeedStrategy.html`.
- **`docs/_tutorials/getting-started.md`**: the PyTorch Lightning "See more details" link points at the removed `.../multi_gpu.html#deepspeed` page (404); replaced with the current DeepSpeed integration page `https://lightning.ai/docs/pytorch/stable/advanced/model_parallel/deepspeed.html`.
- **`docs/_tutorials/ds-sequence.md`**: `/tutorials/getting-started/` is not a valid site path (404); the installation page is `/getting-started/`. Also fixes the `exampele` typo in the same paragraph, because the `codespell` pre-commit hook runs on every changed file and would fail on it.
- **`blogs/deepspeed-chat/japanese/README.md`**: replaces the old Lightning API and MosaicML Composer links with the pages they moved to (`docs.mosaicml.com/projects/composer/en/stable/...`).

Old and new URL statuses were checked with an HTTP client; `codespell` on the changed files passes, and all five files have no trailing whitespace, use LF line endings and end with a newline, so the pre-commit hooks should pass.

Documentation-only change: no code or GPU tests are affected.

Signed-off-by is included in the commit (DCO).
