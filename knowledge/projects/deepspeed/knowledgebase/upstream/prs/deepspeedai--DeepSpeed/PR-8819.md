**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Emit the driver report outside pytest capture**

In the Modal path, `ci/torch_latest.py:739-748` invokes pytest with `--verbose` but not `-s`; `pytest --help` documents `-s` as the shortcut for `--capture=no` and says captured output is shown for failed tests. Because this test normally passes, the printed driver version is suppressed and therefore does not become visible in the CI log as intended. Emit it as an unconditional controller command before pytest or explicitly disable capture for the probe.
