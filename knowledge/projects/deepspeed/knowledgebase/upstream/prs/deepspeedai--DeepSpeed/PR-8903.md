# Track implicit package initializer dependencies in CI test selection

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8903) · state: open · merged: False

## Original PR description

## Problem

The diff-based test selector can skip tests after a package initializer changes. Python executes parent `__init__.py` files when importing a submodule, but the selector currently records only the deepest resolved module. A change to a parent initializer therefore has no reverse dependency edge to those importers.

For example, importing `deepspeed.pkg.nested.leaf` raises if `deepspeed/pkg/__init__.py` raises, while the current selector reports `mode=none` for that initializer-only diff. Static inspection of the current tree also identifies seven existing tests that directly import `deepspeed.sequence.*` but are omitted when considering a change to `deepspeed/sequence/__init__.py`. This is a selector coverage gap, not a claim that a particular upstream CI run failed.

## Fix

Record each existing parent package initializer alongside the resolved import dependency. Preserve the existing opaque-module behavior. The regression test uses real temporary Git repositories, two initializer depths, three direct import forms and a transitive importer. An actual Python subprocess establishes that the initializer runs; exact selected-file assertions exclude unrelated tests.

## Reproduction

1. Create a package `deepspeed/pkg/nested/leaf.py` and empty parent initializers in a temporary Git repository.
2. Add a test importing `deepspeed.pkg.nested.leaf` and commit the baseline.
3. Change only `deepspeed/pkg/__init__.py` to `raise RuntimeError('broken package initializer')` and commit.
4. Run `TestSelector(...).select(base)` and import the leaf in a Python subprocess.

Before: selection is `none`, while Python exits 1 with `RuntimeError: broken package initializer`.
After: the importing tests are selected. The regression test fails against the unmodified selector and passes with this change.

Opaque-root outgoing dependencies remain unexpanded.
