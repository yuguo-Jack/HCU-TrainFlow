# Reduce chunked cross-entropy memory test footprint

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8824) · state: closed · merged: True

## Original PR description

The original 8,192-token by 151,936-vocabulary test needs 4.64 GiB for each full FP32 logits-sized tensor. In the reproduced CI stall, a long-lived pytest worker held 28,832 MiB (28.2 GiB) of GPU memory.

This PR reduces the token count from 8,192 to 128 while retaining the 151,936-entry vocabulary: each full FP32 tensor becomes 74.2 MiB, a 64-fold reduction. Preserve loss/gradient tolerances and the two-FP32-tensor memory-savings requirement, and release test-owned CUDA references and cache state on exit.

We now compare gradients in eight-row blocks and calculate the match fraction from integer counts instead of an FP32 mean. The 99.9% threshold is unchanged, but boundary rounding can differ. Check both torch (block_rows=8) and available Triton, instead of selecting just one backend.
