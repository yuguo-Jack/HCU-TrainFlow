# Fix inference normalization row bounds and small-channel dispatch

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8895) · state: open · merged: False

## Original PR description

Draft alternative for #8826 and #8828. **This overlaps the existing #8827 (32-thread dispatch) and #8830 (tail-row bounds) PRs.** No exclusive claim or maintainer approval is asserted. Both existing PRs were open when this draft was submitted.

For small inference normalization inputs, the launchers omit the 32-thread group needed for FP32 hidden sizes 65–128, and partially filled multi-row blocks can access rows past the tensor boundary. This patch adds the missing dispatch and bounds logical rows before tensor offsets, global loads and stores in the v1 LayerNorm/residual LayerNorm/RMSNorm/pre-RMSNorm kernels. It keeps the multi-row schedule and reduction participation.
