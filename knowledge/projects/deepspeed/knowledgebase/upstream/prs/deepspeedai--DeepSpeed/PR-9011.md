# [AffineIR] Check affine holders and source regions without pairwise comparisons

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/9011) · state: open · merged: False

## Original PR description

**Stacked on #9010** (only the last commit is new here; I will rebase after #9010 merges).

`_validate_holders` compared every piece with every other piece, and `_sources` compared every source region with every other region. Planning time therefore grew quadratically with the number of pieces, and a map with 1024 pieces already exceeded the default `max_pair_checks`.

When no rank repeats a box and distinct boxes do not overlap, a rank covers a box exactly when it holds that very box, so the holders of each box can be read from a table. This PR adds `boxes_disjoint` to `affine_geometry`. It sweeps along the axis whose box origins vary most and compares each box only with the boxes still open where it starts. Maps that fail the fast checks fall back to the original pairwise walk, which names the offending piece, so error messages are unchanged.

Planning time (8 ranks with interleaved rows, re-sharded to 8 row shards; ms, before → after):

| pieces | before | after |
|---|---|---|
| 256 | 388 | 28 |
| 512 | 1568 | 87 |
| 1024 | 6277 (refused by default budget) | 295 |
| 2048 | 25074 | 1074 |
| 4096 | 98607 | 4269 |

Tests:
- Randomized oracle over 200 seeds: plans and errors match the pairwise walk, including replicas split at different points, overlapping pieces and wrong holder lists.
- `boxes_disjoint` is checked against an all-pairs reference over 100 seeds.
- Mutation check: the tests catch dropped intersections and wrong holder sets.

The remaining near-quadratic steps, the source × target join and `_covers_union`, overlap with #8936 and will follow after it lands.
