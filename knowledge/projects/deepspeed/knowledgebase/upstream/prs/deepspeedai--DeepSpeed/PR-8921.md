# Bump AWS capacity-fallback Python from 3.10.13 to 3.12.14

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8921) · state: closed · merged: True

## Original PR description

The modal-torch-latest AWS capacity fallback installs the same transformers git main ref as the Modal sandbox, but still provisions Python 3.10.13. transformers main now requires >=3.11.0, so [aws:prepare] fails: `Package 'transformers' requires a different Python: 3.10.13 not in '>=3.11.0'`.

#8902 bumped only the Modal sandbox. This aligns the fallback: AWS_PYTHON_VERSION 3.10.13 -> 3.12.14 (CPython the pinned uv 0.12.7 can download, verified), runtime root python310 -> python312, test assertions updated.

Validation: pytest ci/test_torch_latest.py 49 passed; yapf/flake8 clean.

Signed-off-by: Guokai Ma <guokai.ma@intel.com>
