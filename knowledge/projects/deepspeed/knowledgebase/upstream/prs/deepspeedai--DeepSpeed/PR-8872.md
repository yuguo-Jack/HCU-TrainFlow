## Original PR description

Make root  version.txt  a shared exclusion for both PRs and merge-queue entries, alongside existing documentation exclusions. Version/docs-only diffs skip CPU tests, native-op precompilation, and Python install smoke; mixed code changes still run normally. Required statuses, formatting, DCO, and scheduled/manual runs remain unchanged.

Reuses the existing filter; no overlapping open fix was found. Takes effect after merge, because CI deliberately runs the base branch’s filter.
