# ci: pin torch<2.15 for MPS workflow until pytorch/pytorch#202529 is fixed

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8955) · state: closed · merged: True

## Original PR description

## Summary

`mps-torch-latest` has failed on **every** run since 2026-10-28 (nightly master runs included, e.g. runs #231 and #238), always at the *Install PyTorch* step within ~50s. Root cause is upstream, not a DeepSpeed change:

- torch 2.15.0 (released 2026-10-28) replaced the MPS device-family check with `MTLGPUFamilyApple7` ([pytorch/pytorch#197200](https://github.com/pytorch/pytorch/pull/197200)).
- The paravirtual GPU of GitHub-hosted macOS runners only reports `MTLGPUFamilyMac2`, so `torch.backends.mps.is_available()` returns `False` ("Skipping device Apple Paravirtual device that does not support Metal 2.0") and the workflow's assert fires.
- Tracked upstream as [pytorch/pytorch#202529](https://github.com/pytorch/pytorch/issues/202529). Real Apple Silicon is unaffected; only virtualized GPUs (i.e. our CI runners) hit this.

This PR pins `torch<2.15` (last known-good series: 2.14.1) in the workflow with a comment referencing the upstream issue, restoring CI signal until the fix ships (patch release or 2.16). It also unblocks unrelated PRs that touch `accelerator/**` and currently inherit a red MPS check, e.g. #8933.

## Verification

Dispatched the workflow on both refs as a controlled A/B ([runs](https://github.com/deepspeedai/DeepSpeed/actions/workflows/mps-torch-latest.yml)):

| run | ref | result |
|---|---|---|
| #244 | `master` (torch 2.15.0) | *Install PyTorch* failed in ~40s |
| #243 | `gma/mps-pin-torch-pre-2.15` (torch 2.14.x) | *Install PyTorch* and *Install DeepSpeed* passed; unit tests running (link in run history) |

The only delta between the two is the pin, which closes the causal chain.

## Notes

- The pin should be reverted once pytorch/pytorch#202529 is fixed and released (a TODO comment marks the spot).
- No source code is touched; only `.github/workflows/mps-torch-latest.yml`.
- Not a duplicate: no open PR pins torch for the MPS workflow (searched "mps torch pin" and "202529 in:body").

AI assistance was used to investigate the CI failure history and draft this change; the diff is a two-line workflow pin plus comment, reviewed and test-dispatched by the submitter.
