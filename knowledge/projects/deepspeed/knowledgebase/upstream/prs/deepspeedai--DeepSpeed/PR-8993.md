# Fix DynamicLossScaler never lowering scale when hysteresis <= 0

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8993) · state: open · merged: False

## Original PR description

When `fp16.hysteresis` is set to 0 or a negative value, `DynamicLossScaler.update_scale` tests `self.cur_hysteresis == 1`, which never triggers because the counter starts at 0 (or below) and only decrements further from 1. The loss scale is never reduced after overflow, causing every subsequent step to be skipped indefinitely.

**Fix:** change `== 1` to `<= 1` so that a hysteresis of 0 or below is treated as "no delay", matching the stage 0 fp16 optimizers (#8647). The default `hysteresis: 2` is unaffected.

**Testing:** added `tests/unit/runtime/test_dynamic_loss_scaler_hysteresis.py` covering hysteresis values of 0, -1, -5, 1, and 2.

Fixes #8982
