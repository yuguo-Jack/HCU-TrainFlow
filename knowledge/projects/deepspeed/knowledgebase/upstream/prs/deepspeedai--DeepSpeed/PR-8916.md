# Fix the default data parallel checkpoint writer crash on dp_rank

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8916) · state: open · merged: False

## Original PR description

With `checkpoint.writer` set and `data_parallel` unset (the default), plain data parallel on ZeRO 0/1/2 with no mpu and no MoE crashes at engine init: `AttributeError: 'UniversalParallelInfo' object has no attribute 'dp_rank'`.

**Cause:** `DataParallelWriterFactory._get_data_parallel_config` reads `self._uni_parallel_info.dp_rank`, which the dataclass does not have.

**Fix:** with no mpu, global rank is the data-parallel rank, so read `global_rank` there.

**Test:** `pytest tests/unit/checkpoint/test_writer_default_data_parallel.py` on CPU (no process group, macOS, no GPU) fails before (`AttributeError`), passes after (3 passed): rank 0 only writes at ZeRO 0, every rank writes its partition at ZeRO 1 and 2.

Touches the same file as open #8646 (a different line, `slice_resources`); the hunks do not overlap.
