# Skip blank and comment lines in .deepspeed_env

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8969) · state: open · merged: False

## Original PR description

A blank or `#` line in `.deepspeed_env` aborts the launch with `ValueError`, and a commented-out `# VAR=val` line is exported as a variable named `# VAR`.

**Cause:** `runner.py` splits every line of the file on `=` and unpacks two values. Under pdsh the `#` in the generated `export # VAR=val` comments out the rest of the remote command, so nothing launches.

**Fix:** skip lines that are blank or start with `#`.

**Not a duplicate:** no open or closed PR or issue covers it (searched `deepspeed_env`, `comment`, `blank`). #4006 and #4992 only added `DS_ENV_FILE`.

**Test:** `pytest tests/unit/launcher/test_multinode_runner.py -q` on CPU only (macOS, no pdsh or ssh): the new `test_runner_main_skips_blank_and_comment_lines_in_env_file` fails before with the `ValueError` and 18 pass after. Not covered: a real pdsh or MPI launch, GPU, ZeRO.
