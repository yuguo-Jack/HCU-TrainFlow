# Fix numerical stability in Triton masked softmax

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8782) · state: open · merged: False

## Original PR description

Fixes NaNs when a mask suppresses the row maximum by subtracting the masked maximum before exponentiation. Keeps the initial shift to preserve FP32 mask precision.

Adds focused regression tests. All 37 softmax cases passed in an isolated GPU harness.

Fixes #8780.
