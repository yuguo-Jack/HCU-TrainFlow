# Fix numerical stability in Triton masked softmax

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8782) · state: open · merged: False

## Original PR description

Fixes #8780. A mask that suppresses the row max made every `exp()` underflow to 0, giving 0/0 = NaN. Now the row max is subtracted again after the mask is added.
The first shift stays to keep FP32 mask precision.
Adds one regression test.
