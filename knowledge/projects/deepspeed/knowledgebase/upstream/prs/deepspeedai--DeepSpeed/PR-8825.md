# [CI] Run torch-latest only on AWS

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8825) · state: closed · merged: True

## Original PR description

(#8824 should be merged first)

In #8770, we pinned Modal sandbox placement to Oracle Cloud Infrastructure (OCI), where a working NVIDIA driver version was still available, to avoid the CUDA/NCCL failures seen on other Modal hosts.
The affected driver has since been rolled out to OCI as well, so this workaround no longer provides a reliable path for our multi-GPU CI workload. Modal has identified the issue and is working on a fix.

This PR temporarily disables Modal until the driver issue is resolved, and run the required torch-latest workflow entirely on the existing AWS backend.
