# Fix race between folded checkpoint load and metadata drop in AutoEP+AutoTP test

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8943) · state: closed · merged: True

## Original PR description

Fixes #8925.

## Problem

`test_cpu_gloo_folded_checkpoint_edp_replica_resume` fails intermittently with `Missing AutoEP+AutoTP folding metadata in folded checkpoint`. In `_run_folded_checkpoint_same_topology_resume`, the positive `load_checkpoint` is followed by `_drop_folding_metadata_from_model_checkpoints`, where rank 0 rewrites every `mp_rank_*_model_states.pt` in the shared directory. That helper synchronized only after the rewrite. A rank that was still loading could read a file whose metadata rank 0 had already removed.

## Fix

Add a `dist.barrier()` in `_drop_folding_metadata_from_model_checkpoints` before rank 0 rewrites the files, as suggested in the issue. It sits in the helper, not at the call site, so every caller waits for all ranks to finish reading.

## Validation

CPU/gloo, `world_size=8`:
- Forced race: rank 7 sleeps 10 s before the positive `load_checkpoint`.
  - Without the fix: fails with the reported `Missing AutoEP+AutoTP folding metadata`.
  - With the fix: passes.
- Without the injected delay: the test passes 3 out of 3 runs.
- `tests/unit/v1/moe/test_autoep_autotp_checkpoint.py`: 6 passed, 2 skipped (H100-only).
