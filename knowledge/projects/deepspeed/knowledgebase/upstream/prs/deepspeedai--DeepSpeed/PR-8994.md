# ZeRO-3: build the partial-offload device string from the public accelerator API

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8994) · state: closed · merged: True

## Original PR description

`get_accelerator()._name` is the accelerator internal backend name, which maybe not the torch device name like in KLXPU, and can fail test `tests/unit/v1/zero/test_zero.py::TestZero3OffloadPinnedCopyBack::test[0.5]`.

`device_name()` is a better choice here.

The PR has been validated on KLXPU.
