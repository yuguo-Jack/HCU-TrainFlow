# Fix shared-submodule params missing from ZeRO checkpoint reconstruction

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8686) · state: closed · merged: False

## Original PR description

## Summary

`DeepSpeedEngine._get_shared_params()` walks the module tree with
`named_children()`, which **de-duplicates children by identity**. When an entire
submodule — not just a tied leaf `Parameter` — is aliased under a second
attribute name, the second name's subtree is never visited. Its parameters are
therefore never recorded as shared, and they go missing from the state dict
reconstructed by `zero_to_fp32.py` / `load_state_dict_from_zero_checkpoint()`
after a ZeRO stage 1/2/3 checkpoint.

`nn.Module.state_dict()` itself walks `_modules` directly and does not
de-duplicate, so the save path and this reconstruction path disagree about which
names exist.

Fixes #1789

**Impact: silent-wrong-result**

Who reaches it: any model that reuses a whole child module under two attribute
names (`self.layer2 = self.layer1`) and is checkpointed with ZeRO. No special
configuration is needed. The failure is silent — the checkpoint is written
without error and the missing keys only surface later, as a `load_state_dict`
failure or, worse, as a silently incomplete model.

The de-duplication is easy to confirm in isolation:

```python
inner = nn.Linear(2, 2)
m = nn.Module(); m.a = inner; m.b = inner
[n for n, _ in m.named_children()]   # ['a']       <- 'b' is dropped
[n for n, _ in m._modules.items()]   # ['a', 'b']
```

## Changes

- Walk `module._modules.items()` instead of `named_children()`, matching the
  traversal `nn.Module.state_dict()` uses.
- Add `test_get_shared_params_records_aliased_submodule`, which exercises
  `_get_shared_params()` directly.

A note on that test: this file's existing end-to-end conversion test requires an
accelerator and is skipped in most environments, so it cannot demonstrate this
defect. The bug is in the tree walk, and `_get_shared_params()` reads only
`self.module`, `zero_optimization_partition_weights()` and the rank — so the
traversal can be driven directly, at the level the defect actually lives. The
end-to-end case is kept for environments that can run it.
