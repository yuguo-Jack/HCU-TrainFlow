# Run the v1 multi-rank CPU suite on pull requests

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8944) · state: open · merged: False

## Original PR description

Follow-up to #8926 per its rollout plan.

The `cpu-torch-latest-v1-multirank` suite has been green on repeated manual dispatch runs against master, so:

- `pull_request:` is added back to the `on:` block; diff-based selection (`collect-tests` + `ci/tests_fetcher.py`) keeps unrelated PRs at `mode=none`, so the ~1h suite only runs for PRs that touch the `tests/unit/v1` dependency graph.
- `merge_group:` is included so the merge queue can satisfy the check once it is registered as required in branch protection (a merge_group event has no PR base, so it runs the full v1 scope).
- The header comment now records the rollout state instead of the plan.

Required-check registration in branch protection is a repo-settings step for maintainers and is not part of this diff.

AI assistance: prepared with AI assistance (DeepSeek Harness agent) under human review; the submitter has read every changed line.
