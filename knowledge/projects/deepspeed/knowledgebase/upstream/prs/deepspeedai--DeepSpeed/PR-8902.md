# Bump modal-torch-latest CI Python from 3.10 to 3.12

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8902) · state: closed · merged: True

## Original PR description

## Description

The `modal-torch-latest` CI installs transformers from the `main` branch by default. transformers `main` now declares `SUPPORTED_PYTHON_VERSIONS = (11, 14)`, i.e. `python_requires>=3.11`, which conflicts with the Python 3.10 environment provisioned via `add_python="3.10"` in the Modal sandbox (pip fails the install with a requires-python conflict).

This bumps `add_python` from `"3.10"` to `"3.12"` in `ci/torch_latest.py`. Python 3.12 is within DeepSpeed's officially supported range (setup.py classifiers list 3.8–3.12) and satisfies the new transformers requirement.

Example failing run: https://github.com/deepspeedai/DeepSpeed/actions/runs/39958850024/job/120431585981

`ci/accelerate.py` still uses `add_python="3.10"`, left unchanged since it installs transformers from published requirements (currently `>=3.10` compatible).
