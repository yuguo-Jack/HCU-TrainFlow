# Add end-to-end BF16 stage 1 tests for zero and invalid gradient norms

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8614) · state: open · merged: False

## Original PR description

Adds two end-to-end BF16 ZeRO stage 1 tests, built through `deepspeed.initialize`: an all-zero-gradient step (fully masked batch) runs and reports norm 0, and an inf loss skips the step (`skipped_steps == 1`) with parameters unchanged.

Not a duplicate: #8638 already changed the behavior this PR first targeted, so the source change is dropped. Its only BF16 skip test, `test_bf16_optimizer_reports_invalid_step_and_recovers`, mocks the norm; nothing covers these two cases on a real engine. No other open PR adds them.

Tests (CPU only, current master):
- `pytest tests/unit/runtime/half_precision/test_bf16_grad_norm_guard.py`: 2 passed. Both fail if `assert all_groups_norm > 0.` is restored.
- `pytest tests/unit/v1/zero/test_invalid_grad_norm.py`: 17 passed, 1 skipped (needs 2 GPUs).

GPU/NPU and the compatibility matrix were not run.
