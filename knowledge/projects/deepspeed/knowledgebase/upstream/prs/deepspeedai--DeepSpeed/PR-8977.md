# Keep --venv_script out of the pdsh pkill pattern

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8977) · state: open · merged: False

## Original PR description

With `--venv_script`, the pdsh runner's remote `pkill` pattern no longer names `deepspeed.launcher.launch`, so ranks survive Ctrl-C.

**Cause:** `PDSHRunner` builds the pattern from `deepspeed_launch[2:6]`, but `--venv_script` prepends a `source ...;` entry first, so the slice shifts to `cd <dir>;`, the python path, `-u` and `-m`. The unquoted `;` also splits the remote command.

**Fix:** take the slice before the prepend.

**Not a duplicate:** no open or closed PR or issue covers it (searched `venv_script pkill`, `pdsh pkill venv`).

**Test:** `pytest tests/unit/launcher/test_multinode_runner.py -q` on CPU only (macOS, no pdsh or ssh): the new `test_pdsh_kill_cmd_with_venv_script` fails before and 18 pass after. Not covered: a real pdsh launch, GPU, ZeRO.
