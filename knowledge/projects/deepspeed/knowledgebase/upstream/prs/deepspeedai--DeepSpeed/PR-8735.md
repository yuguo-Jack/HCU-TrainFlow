# Count every pipeline stage in the fp32 gradient-clipping norm

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8735) · state: open · merged: False

## Original PR description

With fp32 pipeline parallelism and `gradient_clipping`, the engine clips with the first stage's gradient norm only.

`clip_grad_norm_` keeps a gradient when `mpu.get_model_parallel_rank() == 0`. For `PipelineParallelGrid` that is the rank across stages (`ds_model_rank`), so stage 1 and later contribute nothing before the sum over `get_model_parallel_group()`. The fix filters on `bwc_tensor_model_parallel_rank(mpu)` and skips `ds_pipe_replicated` tied weights, matching `get_weight_norm` and `get_grad_zeros`.

Two-stage gloo run through `train_batch`, per-stage norms 35.38 and 950.72:
- before: clips with 35.38
- after: clips with 951.38, the true norm

Test: a new 2-rank case expects `sqrt(3^2 + 4^2 + 12^2) = 13` with a tied weight. It fails on master (12.37) and passes with the fix.
