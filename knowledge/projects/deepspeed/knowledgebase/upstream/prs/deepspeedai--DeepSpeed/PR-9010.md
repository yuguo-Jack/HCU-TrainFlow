# [AffineIR] Move shared affine index and box geometry into affine_geometry

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/9010) · state: open · merged: False

## Original PR description

Row-major strides, shape products, offset/coordinate/address conversion, row-major range-to-box splitting and `LogicalBox` were each implemented two or three times across `affine.py`, `affine_transfer.py` and `autoep_affine.py`.

This PR collects one copy of each in a new pure module, `deepspeed/checkpoint/affine_geometry.py`, and imports it under the old private names. Call sites and behavior are unchanged.

| Helper | Previous copies |
|---|---|
| `product` | `affine._product`, `affine_transfer._product`, `autoep_affine._product` |
| `row_major_strides` | `affine`, `affine_transfer`, `autoep_affine` |
| `coordinate` | `affine_transfer._coordinate` |
| `dot`, `strided_address`, `row_major_range_boxes` | `affine` |
| `LogicalBox` | `affine_transfer` |

This is a pure move, kept separate so that the follow-up planner-complexity work, which replaces pairwise O(n²) checks with sweeps over these primitives, reviews as algorithm changes only. The first follow-up (holder/source validation) is stacked on this PR.

Test: existing `tests/unit/checkpoint -k affine` passes unchanged on CPU.
