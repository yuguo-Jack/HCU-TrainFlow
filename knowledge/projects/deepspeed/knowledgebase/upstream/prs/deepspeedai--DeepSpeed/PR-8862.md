# Fix subgroup communication bandwidth calculation

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8862) · state: open · merged: False

## Original PR description

## Summary

Fix incorrect bus bandwidth calculations for collectives operating on subgroups.

- Propagate the collective process group through `timed_op()` to the communication logger.
- Calculate bus bandwidth using the participating process group's size.
- Preserve compatibility for callers that omit the group and keep world-group record names unchanged.
- Separate summary records for different subgroup sizes.
- Add regression coverage for subgroup bandwidth calculations, summary separation, and process-group propagation.

## Validation

- Isolated communication-logger tests: 8 passed, 2 warnings.
- Python syntax validation: passed.
- `git diff --check`: passed.
- Normal pytest collection is blocked by the missing `cpuinfo` dependency.
- The wrapper-level regression test has not yet been executed successfully through normal pytest collection.

## Scope

This PR addresses the subgroup bandwidth calculation and summary separation described in #8861. Distinguishing different process groups of the same size and subgroup-aware straggler analysis remain out of scope.

Fixes #8861
