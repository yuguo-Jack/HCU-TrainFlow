# Fix ZeRO-3 checkpoint conversion with --debug

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8530) · state: open · merged: False

## Original PR description

The checkpoint converter crashes with `--debug` on ZeRO-3 checkpoints.

`_zero3_merge_trainable_params` receives each rank's optimizer groups as a list and the debug block treats it as a tensor, reading `.shape` and `.numel()` off the list. Print the per-group shapes instead, the way the ZeRO-2 debug block above it already does, and drop the `avail_numel` reassignment: it recomputed, wrongly, a value the top of the function already has.

Tests: `DS_ACCELERATOR=cpu python -m pytest tests/unit/checkpoint/test_convert_checkpoint.py -k 'not TestCheckpointConvert' -q`. Debug export fails before. Five converter tests pass after. A separate real ZeRO-3 Adam step with two parameter groups, checkpoint save and debug export produces matching weights. Changed-file pre-commit passes. Apple M2 Pro CPU, PyTorch 2.10, one-rank Gloo; no GPU run.
