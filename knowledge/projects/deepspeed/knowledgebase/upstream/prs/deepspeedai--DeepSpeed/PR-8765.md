# Detect NEON when py-cpuinfo reports no CPU flags

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8765) · state: open · merged: False

## Original PR description

On Apple Silicon, building CPU ops such as `cpu_adam` fails with `KeyError: 'flags'` before the compiler runs.

`simd_width()` indexes `cpu_info['flags']`, but py-cpuinfo returns no `flags` key on M-series Macs (it gives only arch, brand, bits and count). The SVE check added in #8365 sits ahead of the NEON branch from #8453, so these CPUs never reach NEON.

Fix: read the flags once with `cpu_info.get('flags', [])`. Apple Silicon now gets `-D__NEON__`; CPUs that report flags are unchanged.

Test: new parametrized test in `tests/unit/ops/test_op_builder.py` covers a cpu_info without flags (fails on master with KeyError, passes here) and one with `sve`. On an M2 Pro with real py-cpuinfo, `simd_width()` goes from KeyError to `-D__NEON__`. The test file: 18 passed, 1 skipped; yapf and flake8 clean.
