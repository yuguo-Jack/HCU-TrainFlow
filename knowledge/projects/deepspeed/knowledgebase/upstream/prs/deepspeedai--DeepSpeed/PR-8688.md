## Original PR description

All old URLs return 404 or no longer resolve; all replacements verified live (including the ten section anchors on the training page).

- `deepspeed.ai/features/` was folded into `/training/` (10 links in `_pages/training.md`)
- ZeRO-Offload tutorial slug is lowercase
- DeepSpeedExamples moved autotuning, bing_bert, cifar and gan under `training/` (8 links)
- DeepNVMe blog moved to `blogs/deepnvme/08-2024`
- Megatron-DeepSpeed `moe-training` branch is gone; the MoE examples live on `main`
- transformers `modeling_bert.py` moved under `models/bert/`
- PyTorch removed the `_modules/` source pages; the Adam and optim docs replace them (3 links)
- `deepspeed4science.ai` no longer resolves; the DeepSpeed4Science page on deepspeed.ai replaces it (4 links)
- `bigscience.huggingface.co` no longer resolves; the Hub org page replaces it
- azureml-examples restructured to `sdk/python` (2 links)
- Composer trainer page: dropped the dead anchor, and `docs/index.md` was missing the `projects/composer` path
- HiPC advance-program page is gone, and no 2022 archive page exists; removed that link and kept the citation text (the arXiv link stays)

Not changed, no live replacement found: the Determined AI docs link, the note.microsoft.com webinar links, and the `Megatron-LM-v1.1.5-ZeRO3` example links.
