# Fix get_global_grad_norm() returning None with fp32 at ZeRO stage 0

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8708) · state: closed · merged: False

## Original PR description

Fixes #8660.

This patch correctly stores the gradient norm calculated during \clip_fp32_gradients()\ to \self._global_grad_norm\ when using ZeRO stage 0.

Also resets \self._global_grad_norm\ to \None\ at the beginning of \_take_model_step()\ and documents that the function returns \None\ when Stage 0 gradient clipping is disabled.
