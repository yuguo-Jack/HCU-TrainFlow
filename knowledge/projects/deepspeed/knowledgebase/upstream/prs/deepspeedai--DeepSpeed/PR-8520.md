# Fill curriculum batches across repeated cluster shuffles

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8520) · state: open · merged: False

## Original PR description

Requesting eight samples from a two-item curriculum cluster returns only four. With drop_last enabled, short batches can prevent iteration from progressing.

**Cause:** Cluster sampling wraps only once, even when the requested batch needs several passes over a small cluster.

**Fix:** Keep drawing and reshuffling until the requested sample count is filled, advancing the cursor by the samples actually taken.

**Test:** `DS_ACCELERATOR=cpu python -m pytest tests/unit/runtime/test_data_efficiency.py -k 'test_small_curriculum_cluster or test_curriculum_' -q`. Two regressions fail before; 17 CPU checks pass after, with two GPU skips. Tests use real mmap data, one-rank Gloo and three SGD steps on Apple Silicon with PyTorch 2.10. Changed-file pre-commit passes.
