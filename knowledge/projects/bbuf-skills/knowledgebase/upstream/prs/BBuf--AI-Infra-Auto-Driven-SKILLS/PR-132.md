# sglang-explainer-video: seg_check for word cuts, 1eN / 权重 / row-行 readings, worker notes

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/132) · state: closed · merged: True

## Original PR description

Lessons from three explainer videos of SGLang kernel PRs (tiny GEMM SIMT/MMA, one-warp-per-token MoE router, JIT softmax/argmax; ~11 min each, 127 frames total).

**Pronunciation** (`pronunciation.json` + evidence rows in `pronunciation.md`)

- **Scientific notation**
  - `1eN` → 「10 的 N 次方」, `1e-N` → 「10 的负 N 次方」, `x.ye-N` → 「x.y 乘 10 的负 N 次方」.
  - Edge expanded 1e30 to 「负1乘以10的30次方」 on its own, so pron_check FAILed.
- **权重**
  - 权重 → 权众. The user heard quán chóng in review.
  - poly_probe reads it right in two carriers, so the misread depends on the take. 0/6 after the respelling.
- **Row 行**
  - 行宽 → 航宽: 3/6 → 0/6. The pattern skips 执/运/进/并 … before 行.
  - 拆行 → 拆航: 2–4/6 → 0/6.
  - 的行[，。；、] → 的航: 3–5/6 → 0/6.
  - 行和 (6/6) and 第 row 行 (4/6) are reworded rather than respelled.
- **Other evidence rows**
  - key: heard P/T, the fifth video in a row → say 键.
  - topk inside function names → top k.
  - SIMT: Whisper hears SIMP for every spelling, so no respelling.

**Word segmentation** (`scripts/seg_check.py`, new)
- The user asked that every line follow Chinese reading. `seg_check.py` compares Edge's word tokens with a jieba segmentation and flags two cases:
  - a token that straddles a word boundary (值相同时下标 → 「时下|标」, 下标取反 → 「标取|反放」);
  - a pause inside a word (1 除以 T → 「除 100 ms 以」).
- Natural cuts (两|个数, 第几|行, 取|出来) are not reported.
- `setup_env.sh` installs jieba. SKILL.md step 4 runs the check after pron_check. `pronunciation.md` lists the nine cuts found in these videos and how each was reworded.
- The row-行 rule now also covers 行数 / 行号 / 行首 / 行尾.

**Worker dispatch notes** (`worker-dispatch.md`)

- Put hook number cards on screen at t≈0.3 s.
- A `z-index:-1` highlight needs a stacking context on its parent.
- Draw bit cells j = 7 … 0 next to a `0b…` string.
- Use one code title-bar style across workers.
- Dispatch long films through `work/dispatch/<id>.txt` files.

**Tests**: `tests/test_explainer_pronounce.py` covers the new patterns; 27 pass.
