# Refresh AI infrastructure skills against July 2026 upstreams

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/75) · state: closed · merged: True

## Original PR description

## Summary

This is a comprehensive, evidence-first refresh of all 12 repository skills, their bundled executables, generated model histories, operational references, prompts, manifests, and CI/tooling.

- fixes correctness bugs in pipeline trace analysis, framework-specific capacity parsing, measured MFU computation, incident replay, and model-history generation
- refreshes model/PR evidence and current source guidance for SGLang, vLLM, TensorRT-LLM, and TokenSpeed
- adds supported current model coverage (including DeepSeek V4, Hunyuan3 Preview, MOSS-VL, Qwen3.6, MiniMax M3, and Kimi K3 where each destination has defensible evidence)
- removes retired vLLM partial-prefill flags, updates SGLang kernel paths, synchronizes SOTA prompts/configs, and refreshes profiler/fusion catalogs
- updates Claude/Codex usage guidance, plugin metadata, CI action/tool pins, and open-PR watch data

## Root causes addressed

- trace tools used fixed timing assumptions and could contaminate JSON output
- vLLM startup logs could be interpreted with SGLang semantics, fabricating capacity values
- compute summaries used template FLOPs without measured kernel-flow timing
- replay accepted invalid numeric inputs and consumed failed HTTP responses before surfacing status errors
- the PR-history generator could poison its cache on transient API failures, omit supporting runtime code when tracing through tests/docs, lose branch-added cards on a second generation, and delete a previously audited card when GitHub later returned 404
- benchmark/profiler docs and examples contained retired flags, stale source paths, or mutable/current-state claims without an immutable snapshot

The generator now preserves the union of current-branch and branch-point evidence, keeps audited cards when current metadata is unavailable, labels that fallback explicitly, and has focused regression coverage. Relative to `main`, the final English history set has zero removed PR cards and 347 new model/framework card instances.
