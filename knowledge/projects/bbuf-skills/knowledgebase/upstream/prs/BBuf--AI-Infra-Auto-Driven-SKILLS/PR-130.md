## Original PR description

Lessons from the SGLang PR 43570 + 47387 video (2026-11-01, 5:02).

- `pronunciation.json`: `capture` → `Capture`. In a carrier sentence the voice was heard as "Catcher"; with the respelling the take of 「CUDA graph 照样能 capture 和 replay」 comes back as capture. Evidence row added to `references/pronunciation.md`.
- `pronunciation.json` pattern: a number right before 只要 / 只有 / 只需 … gets a pause (「24 只要」 → 「24，只要」). Without it Edge read 只 as a classifier, 二十四只（zhī）要, in 6/6 takes (poly_probe); with it 0/6. Flagged by the user in review. Test added.
- `references/worker-dispatch.md`, three worker notes:
  - a flex title bar drops the space before a function-name span (`·&nbsp;<span>`);
  - step counters must show values of the whole expression, never a false intermediate equation;
  - no bundled face has ⌈ ⌉ / ⋮, so Scene lines write 「向上取整」.
