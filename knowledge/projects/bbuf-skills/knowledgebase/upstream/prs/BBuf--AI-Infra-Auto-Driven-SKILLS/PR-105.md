# sglang-explainer-video: SGLang follow strip on the last frame of every video

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/105) · state: closed · merged: True

## Original PR description

Every SGLang explainer video now ends with a fixed **关注 SGLang** strip: GitHub `github.com/sgl-project/sglang` · 博客 `sglang.io/blog` · 文档 `docs.sglang.io`.

![follow strip](https://raw.githubusercontent.com/BBuf/AI-Infra-Auto-Driven-SKILLS/sglang-explainer-video-follow-strip/skills/sglang-explainer-video/assets/brand/follow-strip-example.png)

## Changes
- `assets/brand/follow-strip.html` holds the strip's CSS and markup. The last-frame worker pastes it verbatim.
  - Placement: y 792–872, just above the caption band.
  - It is on screen only and is not narrated.
- `references/house-style.md` adds a new section, §Follow strip. `SKILL.md` step 3 and `references/worker-dispatch.md` were also updated, so the storyboard and the last-frame worker both reserve space for the strip (frame content ends above y≈770).
- `scripts/check_frames.mjs` now fails the last frame if the strip is missing or any of its three URLs is missing.
- Plugin version 0.9.3 → 0.9.4.

## Test
On a copy of the Step 5 Preview project, the strip was pasted into the last frame. Results:
- `check_frames` → OK.
- `subset_fonts` covered the new CJK text.
- `hf lint` → 0 errors.
- `hf snapshot` at the final second shows the strip (the image above).

On the unmodified project, `check_frames` reports `FAIL 17-summary.html — last frame lacks the SGLang follow strip`, as expected.
