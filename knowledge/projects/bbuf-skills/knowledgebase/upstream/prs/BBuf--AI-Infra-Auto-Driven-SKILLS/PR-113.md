# sglang-explainer-video: lexicon + pron_check carrier fix (24GB video)

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/113) · state: closed · merged: True

## Original PR description

## What

Pronunciation fixes found while making the 「24GB 显卡跑 60GB 视频模型」 explainer video (2026-10-19). Every entry was measured with `pron_check.py` (Xiaoxiao voice + Whisper):

| Written | Spoken | Before (Whisper) → after |
| --- | --- | --- |
| checkpoint | check point | ChatPoint in every carrier → **checkpoint** |
| OOM | O O M | Om (read as a word) → **OOM** |
| comfy-kitchen | Comfy Kitchen | a bare *kitchen* → Tichen in every spelling; the pair passes |
| fa (FlashAttention backend) | F A | read as a syllable in context (Fall / 发 / 法 / Ford) → **FA** |

Rewords added to the table:
- `int mm` → 「PyTorch 自带的 INT8 矩阵乘接口」
- `INT32` → 「32 位整数累加」

The 行 note now also covers 「按行动态量化」: there 行 sits before 动 and forms 行动, so the text should be written 「逐行做动态量化」.

## pron_check fix

The carrier now reads the term's full spoken form with `patterns` applied (`to_spoken`, not just `spoken_token`). Before this, `24GB` was synthesized raw and reported as a FAIL (heard `24G`), even though the engine sends `24 G B`, which passes. Verified: `24 G B` / `60 G B` / `32 G B` all come back OK.

## Worker-dispatch lessons

`references/worker-dispatch.md` gains a list of lessons to append to every dispatch:
- no whole-frame camera drift;
- SVG `transformOrigin` on both sides of a `fromTo` (to-side only shifted an axis by 480px);
- how to chain short video clips, and why the `nested_media_start_basis_ambiguous` lint warning is expected;
- `check_frames` reports "missing follow strip" on whichever frame is currently the highest-numbered, so workers should ignore it mid-run;
- excerpt line ranges are fixed upstream, never paraphrased.
