# sglang-explainer-video: Xiaoxiao voice + English terms read right

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/106) · state: closed · merged: True

## Original PR description

## Summary

Explainer videos now use **zh-CN-XiaoxiaoNeural** (picked from a 16-voice female audition, after a viewer asked for an "SGL girl" voice), and every English term has to be **read correctly and in one breath**.

- **Spoken forms** (`scripts/pronounce.py` + `scripts/pronunciation.json`): edge-tts gets a rewritten text, while the narration, captions and scene cues keep the written one. `edge_tts_engine.py` maps the WordBoundary timings back onto the written tokens.
  - snake_case / SCREAMING_CASE is split into words. The voice used to say 下划线: `flashmla_sparse_q8` → Flash MLA sparse Q8.
  - CamelCase brand names that run words together get spaces: FlashInfer → Flash Infer ("Flesh and Fur" before), DeepSeek → Deep Seek.
  - Letter-spelled acronyms get spaced letters: VAE → V A E (just "V" before), DiT → D I T, GEMM → G E M M.
  - Symbols:
    - `3.7×` → 3.7倍 (乘 before)
    - `8×B300` → 8卡B300 (八成 before)
    - `#N` drops the `#` (警号 before)
    - `+5%` / `−12%` → 提升5% / 降低12%
    - **`-1` → 负1** (the voice silently dropped the minus)
  - Other respellings: `top-k` → top k (Talk K in a sentence before), `V2` → V two.
  - A space between two Han characters is dropped, because the voice paused about 0.3 s there.
  - `approved` terms are never respelled. SGLang stays as the voice reads it; the user chose that by ear from 5 candidates.
- **`scripts/pron_check.py`**:
  - Before TTS, it reads every English term of SCRIPT.md in a carrier sentence and transcribes it with mlx-whisper (large-v3-turbo, on device).
    - **OK**: an unbiased pass writes the term back.
    - **OK~**: only a pass primed with the term gets it.
    - **FAIL**: neither pass gets it. The tool tries respellings and prints the first that passes.
    - Verdicts are cached per voice.
  - After TTS, it flags pauses longer than 0.2 s inside a clause and re-checks every term in its real sentence.
- `references/pronunciation.md` has the rules and the measurement table. SKILL.md (voice, both checks in steps 3 and 4), house-style (voice section) and troubleshooting are updated.
- `setup_env.sh` installs mlx-whisper on Apple Silicon. Plugin version 0.9.4 → 0.10.0.

The free Edge endpoint rejects inline SSML (`<phoneme>`, `<sub>`, `<lang>`, `<break>` all return NoAudioReceived), so respelling is the only lever.

## The lexicon keeps learning

`references/pronunciation.md` §The lexicon is a living file, together with SKILL.md §4 and §9, makes this a required step of every video. Any term the video exposes as misread is folded back into `pronunciation.json`. That covers `pron_check` FAILs, OK~ terms that sound wrong, and anything the user flags in review.

- Each fix uses the most general rule that holds, in this order: patterns > parts > lexicon > approved.
- Each fix gets an evidence row in the doc and a test case when the rule is new.
- The fixes ship as a skill PR before the video is delivered.

`pron_check.py --audit` re-measures every entry. It flags a respelling that no longer passes, and hints when the written form now passes. An entry is dropped only after the written form also reads right in a real sentence.

`map_back` now also cuts edge-tts words that straddle a rewritten span. edge-tts split 改回负1 into 改 | 回负 | 1, and the caption showed 「改回负-1」.
