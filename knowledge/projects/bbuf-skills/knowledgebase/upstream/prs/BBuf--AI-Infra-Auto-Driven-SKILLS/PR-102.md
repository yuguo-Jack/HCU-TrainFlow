# sglang-explainer-video: Bilibili-safe 1440x1080 cover (--png-bili)

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/102) · state: closed · merged: True

## Original PR description

## Why

Bilibili keeps **one** cover image per video and crops it to two ratios: 4:3 (home feed) and a centred 1440×810 16:9 band (personal space). Uploading a different image for each ratio doesn't stick. With the 1920×1080 still from `make_cover.py --png`, the 4:3 crop cuts the right-hand badge (`#43238` / `Diffusion` → `Diffu`). Learned while publishing the two first videos.

## What

- `scripts/make_cover.py`: new `--png-bili PATH` renders the same cover design at **1440×1080**, with every element inside **y 135–945**. Both the full 4:3 image and its 16:9 band then show the logo, title and badge intact. The badge is capped at 110 px and the meta line moves up so the two don't overlap.
- `SKILL.md`: Step 6 renders `cover_bili.png`; Step 9 copies it to `~/Desktop/…_封面_B站.png`.
- `references/house-style.md`: new Bilibili cover rule under §Cover (and in the Delivery file list). `references/troubleshooting.md` gets a matching row.
- `assets/brand/cover-example-bili.png`: reference render.
- Plugin version 0.9.0 → 0.9.1.

## Verification

- The video cover frame (`caption_safe=True`) and the 1920×1080 still produce **identical** markup to `main`. The re-rendered still is pixel-identical to the existing article `cover.png`.
- The `--png-bili` output is byte-identical to the covers actually uploaded for both videos. Bilibili's saved 4:3 (1440×1080) and 16:9 (1440×810) crops were checked: logo, title and badge are fully visible in both.
