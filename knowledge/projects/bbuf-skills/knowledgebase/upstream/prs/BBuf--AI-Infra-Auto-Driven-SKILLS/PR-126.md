## Original PR description

Lessons from the Claude Code code-review explainer video (2026-10-28).

**Pronunciation**
- `queue` → `Q`: in a carrier sentence the voice's "queue" came back as 「Continue」; the letter Q reads the same word (English ASR writes "merge queue").
- Reword table: `diff` (Dev / Dave's), `skill` (Scale), `nit` (Net; knit / nitpick fail too), `on-call` (Encore), `clone` (Clan) have no passing respelling, so the narration says 改动 / 技能 / 小毛病 / 值班 / 克隆 and keeps the English on screen.
- New test: `test_queue_is_letter_q`.

**Worker dispatch**
- Every frame carries the kicker and title even when its Scene lines don't name them (one worker left them off four frames).
- A diagram continued across consecutive frames goes to one worker, or the second worker reads the first frame and matches it (a table split across two workers got two different headers).
- Recurring elements need an exact CSS spec (the 「N / 7」 badge came back in four sizes from four workers).
- Scene-line pointer coordinates on real figures are estimates; workers should measure the figure.
