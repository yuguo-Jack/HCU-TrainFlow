# sglang-explainer-video: re-voice finished videos + lexicon from 13 videos

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/107) · state: closed · merged: True

## Original PR description

## Summary

The 13 published explainer videos are being re-voiced with Xiaoxiao, keeping every frame and swapping only the narration. That needed tooling fixes, and it taught the pronunciation lexicon a lot (the living-lexicon rule from #106 in action).

- **`scripts/revoice.sh <project>`**: one command per project.
  - Backs up the old state once to `revoice_backup/`.
  - Synthesizes the new take through the pronunciation layer. `SKIP_TTS=1` keeps the current take.
  - Restores the frames, then retimes them.
  - Runs the pause check, captions, font subset, assemble, lint and check.
  - Renders `renders/video_revoiced.mp4`; the original `renders/video.mp4` is never touched.
- **`retime_frames.py`**:
  - Frames now map through STORYBOARD.md `- src:`. NVFP4 has `19b-*/19c-*` frames that the NN+1 rule mis-mapped.
  - The registration regex accepts `=tl;` without spaces (PR 44051 frames).
  - `--chain` composes the new anchors through an existing WARP when the built take was lost by an earlier retime (PR 43238).
- **Pronunciation layer**:
  - A hyphen between two letters becomes a space (bit-exact, top-k).
  - Lexicon lookups fall back to case-insensitive (flashinfer).
  - New rules: number + GB/MB/TB/KB; Qwen → Kwen, also inside Qwen3-8B and Qwen-Image.
  - New respellings: SANA, epilogue, launch, denoise → 去噪, DeepSelect, hmax2, ctas.
  - **Readings the user picked by ear:** Qwen → Kwen, EAGLE → Eagle, RAGGED → Ragged. Kimi, PR and dB are approved as read.
  - `pron_check --meta` accepts a Chinese spoken form (去噪).
- **Docs**:
  - `references/pronunciation.md` gets new measurement rows, the user's picks, the listen-on-render list (Claude, Lean, README, TopK), and the note that in-context checks of long lines are noisy.
  - SKILL.md and troubleshooting document re-voicing.

## Verification

- `pytest`: 242 passed (7 pronunciation tests). `pre-commit` is clean.
- PR 43238 went through the whole path end to end, including `--chain`, and was rendered (83 s) and checked on QA sheets: animation, voice and captions stay in sync.
- **All 13 published videos were re-voiced and rendered** with `revoice.sh`:
  - 13/13 exited with rc=0; every frame of every project was retimed (9–54 frames per video).
  - Total length went from 132 min to 142.6 min. Xiaoxiao is about 8% slower than Yunyang.
  - Rendering ran at about 0.7–1.6× real time on an M4.
  - QA contact sheets of every video confirm that animation, voice and captions stay in sync.
  - The fixed cases rendered correctly:
    - NVFP4 `19b/19c` frames, mapped through the storyboard (43/43 retimed);
    - PR 44051 frames that register with `=tl;` and no spaces (46/46 retimed);
    - PR 43238 via `--chain` (cue times preserved through the old WARP).
- The run itself exercised the living-lexicon loop:
  - in-context Whisper checks of every line;
  - re-probing the FAILs in short sentences;
  - an A/B page for the brand words, where the user picked Kwen / Eagle / Ragged.
