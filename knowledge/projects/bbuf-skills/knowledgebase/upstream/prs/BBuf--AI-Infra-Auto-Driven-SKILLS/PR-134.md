# sglang-explainer-video: checks every publish must pass

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/134) · state: closed · merged: True

## Original PR description

## Why

B站 and 小红书 both drop input without saying so. Each of these has already happened at least once:

- **Empty 简介:** 7 videos went live with an empty 简介 (`quill.setText` only changed the view).
- **Dropped tags:** RTX4090 and 高性能计算 were silently removed.
- **Blank cover:** the 小红书 auto cover was a blank first frame.
- **Wrong file:** the previous video, still selected in the file dialog, was uploaded.
- **Lost 标记:** swapping the video in place removed the SGLang 标记.

A publish should count as done only after we read back what each site actually stored.

## What

- **`scripts/publish_check.py`** runs on the files and texts before anything is uploaded. It checks:
  - the upload copy is byte-identical to the render;
  - the cover is 1440×1080;
  - B站 title ≤ 80 and 小红书 title ≤ 20 (ASCII counts as half);
  - 简介 ≤ 2000 and the 小红书 body ≤ 1000;
  - the B站 简介 has the AI-voice line;
  - no 「#」 before a digit in the 小红书 body;
  - no PR status in any text.

  It also prints the duration, so it can be compared with what the sites store.
- **`references/publishing.md` §Checks** has page snippets for:
  - the B站 form before 立即投稿;
  - the stored archive after submit: 简介 length, tags, 分区, part duration, cover and 合集 单集标题;
  - the 小红书 form before 发布: topics, 标记, AI 声明, and the cover image actually used;
  - the note list after 发布.
- **`publishing.md`** also fixes the steps behind past misses:
  - type the 简介 with `execCommand`;
  - always upload the 小红书 cover;
  - pick the official SGLang account by avatar id;
  - count topics inside the editor;
  - re-add the 标记 after a video swap.
- **`SKILL.md`** step 10 now requires all five checks.

## Checked

- **Tests:** `tests/test_explainer_publish_check.py` covers the title weighting, `#`+digit, PR status and the AI-voice line. 32 explainer tests pass.
- **Real files:** I ran `publish_check.py` on the PR 47683 upload files.
  - The upload copy matches `renders/video_v5.mp4` byte for byte, and the cover and lengths are fine.
  - It flags that the 简介 lacks the AI-voice line. That line is required by the hard rule in this file, but it is missing from the last six published B站 descriptions as well.
  - Run against the wrong video, it fails the same-bytes check and the title length check.
- **Post-submit snippet:** I ran it unchanged against BV1Lo4M6nEgR. It returned 简介 1518, the 8 tags, 人工智能 and a 761 s part.
