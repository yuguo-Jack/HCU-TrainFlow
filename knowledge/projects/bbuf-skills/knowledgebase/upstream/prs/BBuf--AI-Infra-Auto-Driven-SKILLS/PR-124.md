# sglang-explainer-video: leading-underscore identifiers, config / flush rewordings

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/124) · state: closed · merged: True

## Original PR description

Lessons from the PR 28185 explainer video (int8 checkpoint pool for the linear-attn prefix cache).

- **pronounce.py**: `TOKEN` now absorbs leading / trailing underscores. Before, `_commit_int8_checkpoint` left its `_` in the spoken text and the voice said 「下划线 commit int8 checkpoint」 (pron_check heard it on the recorded take). `__init__` → `init`. Regression test added in `tests/test_explainer_pronounce.py`.
- **captions patch**:
  - `LATIN_EDGE` includes `_`, so 「新增的 _free_mamba_value」 keeps its space in the caption line.
  - Displayed word text gets a thin space between `%` and CJK punctuation: in the serif caption 「0.7%。」 read as ‰ (QA finding). Group text keys are unchanged, so translations still match.
  - That hunk now carries trailing context; without it `git apply` only matches a hunk at end of file.
- **pronunciation.md**: rule 1 notes the underscore fix; reword table gains `config` (看Fake for config / Config / con fig / kon fig; configuration passes → narration says 模型配置) and `flush` (heard Flash in context → narration describes the clear instead).
- **worker-dispatch.md**: − and × stay in Inter / JetBrains Mono / EB Garamond (all carry them). Forcing them into a Noto Sans SC span dropped negative numbers 3–4 px below their row.

Tests: `pytest tests/test_explainer_pronounce.py` (16 passed); pre-commit clean; the patch applies to the pinned HyperFrames commit.
