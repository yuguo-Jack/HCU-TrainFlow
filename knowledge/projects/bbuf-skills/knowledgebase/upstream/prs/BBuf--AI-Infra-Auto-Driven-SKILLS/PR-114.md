# sglang-explainer-video: kimi-dark theme, glyph check, lexicon (Kimi K3 video)

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/114) · state: open · merged: False

## Original PR description

From the Kimi K3 explainer video (2026-10-19, 20:36, 59 frames). The user said the 19 orange covers had become 审美疲劳 and asked for a look aligned with kimi.com.

## Themes
- `apply_brand.py --theme sglang-orange|kimi-dark` (default `sglang-orange`). `kimi-dark` installs `assets/themes/kimi-dark/{frame.md, caption-skin.html, follow-strip.html}`:
  - `#121212` ground;
  - Noto Sans SC at 330/450/300 and JetBrains Mono for code;
  - one Kimi-blue `#1A88FF` accent per frame;
  - a muted semantic diagram palette sampled from Moonshot's official architecture figure.
- Both themes now copy their follow strip to the project's `assets/brand/follow-strip.html` and record the theme in `.hyperframes/theme`.
- `make_cover.py --theme kimi-dark` (or read from `.hyperframes/theme`). Layout: SGL logo chip + series pill, title, subtitle, mono line, light stat numbers, optional right-hand SVG (`--visual`). The 1440×1080 B站 still follows the same crop-safe rule as the orange cover.
- The Chrome screenshot code is factored into `_shoot()`. `killpg` no longer crashes when Chrome is gone or the process group is not ours (seen here: `PermissionError`).
- `house-style.md` gains a **Themes** section: when to use kimi-dark, and never put the subject's logo on the cover. `worker-dispatch.md` gets per-theme slots plus a `_role.md` theme-override line. Without that line, workers follow the role file's cream/coral wording.

## Glyphs
- `subset_fonts.py` now warns about any used character that no bundled font covers. Noto Sans SC lacks ᵀ ₁ ₂ ⁻ ⁰ ⁵–⁹ ⁺ ᵢ ⱼ ⋮ ✗. In this video they were found only after two worker waves, and one caption still had ᵀ.
- New dispatch lessons:
  - write super/subscripts with `<sup>`/`<sub>`;
  - turn ligatures off on every JetBrains Mono element (`==`, `->`, `!=` rendered as ligatures).

## Lexicon (pron_check, zh-CN-XiaoxiaoNeural)
- `MLA` → "M L A". A/B on one line: the bare form was heard as MBA in 3/3 takes; the spaced form was heard as MLA in 3/3.
- `SiTU` → "S I T U". It was heard as C2.
- `tanh` → "tan h".
- `kimi_k3.py` → "Kimi K3 点 P Y".
- Rewords recorded in the table: key (128 个 key 通道), e 的负 80 次方, tok/s, copy on write.

## Testing
- `tests/test_explainer_pronounce.py`: 12 passed (new `test_terms_from_the_k3_video`).
- `apply_brand.py` run on fresh projects for both themes: correct frame.md, caption skin, strip colour and fonts.
- `make_cover.py --theme kimi-dark`:
  - the frame passes `frame-contract.mjs`;

  - the theme is picked up from `.hyperframes/theme` without `--theme`.
