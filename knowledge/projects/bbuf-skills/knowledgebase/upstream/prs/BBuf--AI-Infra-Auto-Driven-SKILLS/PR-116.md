# sglang-explainer-video: GPU lexicon, cta_group:: caption fix, worker lessons

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/116) · state: closed · merged: True

## Original PR description

Fixes and lessons from the two GPU explainer videos (2-CTA / CUDA practice and MegaMoE, NVIDIA dark theme).

**Pronunciation**
- `scripts/pronunciation.json`: MiB, DSMEM, tcgen05, mbarrier, ptxas, ncu, PipelineUmmaAsync, PipelineTmaUmmaAsync, Nsight, initcheck, FC1, op. Each entry was checked with `pron_check.py --asr`.
- `references/pronunciation.md`: evidence rows for these entries, plus Chinese rewordings for words no respelling fixed: thread, phase, baseline, wrapper, traits, subtile and a lone `j`. MiB is added to the expected KiB/GiB "FAIL" row.

**Captions (`patches/hyperframes-captions-cjk-bilingual.patch`, `assets/caption-skin.html`, `assets/themes/kimi-dark/caption-skin.html`)**
- `::` (C++ scope, e.g. `cta_group::2`) no longer counts as a sentence end.
- A TTS pause after `::` no longer splits a caption.
- No gap is inserted after `::` in the Chinese line.
- Before the fix, six captions in the 2-CTA video were cut into `cta_group::` + `2`.
- The regenerated patch applies cleanly on the pinned HyperFrames commit.

**`references/worker-dispatch.md` lessons**
- An accent code highlight and any state label follow the voice: they fade or switch when the narration moves on.
- No inferred mechanisms: a worker had drawn a staging buffer that no source stated.
- After the last wave, put every frame's kicker into one montage and normalise the outliers. When scripting it, cut the kicker out by balanced tags.
