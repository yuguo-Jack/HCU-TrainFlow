# sglang-explainer-video: digit-comma reading, bare 调 rule, warmup glossary

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/117) · state: closed · merged: True

## Original PR description

These fixes come from the user's review of the GPU 2-CTA explainer video.

- **The comma between two numbers was read as a thousands separator.** Edge returned `间距是 2，257` as a single word and read it as 两千二百五十七 in 3 of 3 takes. `pronunciation.json` gets a new pattern that adds a space after a full-width `，` or `、` between digits (`2， 257`). The WordBoundary output then has `2` and `257` as separate words with a 0.35 s pause, and the captions still show `2，257`. Older projects had the same merge, for example `4 乘 128，512`.
- **调 on its own meaning "tune" is read diào.** `可以调 block 大小` came out wrong in 6 of 6 takes (poly_probe). With `调整` it was wrong in 0 of 6. `pronunciation.md` rule 11 now says to write a compound (调整 / 调优 / 调参). 调用 and 调度 already read correctly.
- **`house-style.md`:** warmup stays in English, never 暖机, and 暖机 is added to the list of Chinese renderings to grep for before TTS.
- **Tests:** `tests/test_explainer_pronounce.py` covers the digit-comma pattern. The `5、1、-1` expectation was updated for the extra space. All 13 tests pass.
