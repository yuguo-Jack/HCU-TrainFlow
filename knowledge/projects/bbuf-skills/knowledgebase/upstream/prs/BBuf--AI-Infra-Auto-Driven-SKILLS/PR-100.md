# [Feat] Add an optimization analysis skill for tradeoffs and applicability

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/100) · state: closed · merged: False

## Original PR description

An optimization task can produce a faster implementation without explaining why it helps, which conditions the benefit depends on, or whether costs have shifted elsewhere. These questions are easy to leave implicit when the request is simply “optimize this.”

This skill aims to make that coverage more consistent. A capable model may already know how to investigate these questions; the skill makes them an explicit part of the task and its deliverables, while leaving implementation choices and investigative steps to the agent.

The guide connects a concrete before/after execution path to four questions:

- What cost is removed?
- Under what conditions does the change hold?
- What cost is added or shifted?
- What controlled comparison would validate the explanation?

It then asks for the decisive causal relationships, the demonstrated and untested applicability boundaries, and the next useful check or experiment. It complements the existing history, profiling, and benchmark tools by clarifying what needs to be established with their evidence.

A worked example analyzes replacing repeated tensor concatenation with a chunk queue. It is explicitly labeled as an unmeasured illustration, not evidence of a performance improvement.

Validation: checked YAML frontmatter, relative links, and whitespace. The standard skill validator could not run because PyYAML was unavailable. No performance experiments or comparative evaluation of the skill's effectiveness have been run.
