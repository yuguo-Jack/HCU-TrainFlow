# Refresh serving skills, consolidate optimization guidance, and audit source evidence

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/98) · state: closed · merged: True

## Original PR description

Refresh outdated serving guidance against frozen October 5 upstream sources, and correct source claims and analysis paths that could misidentify dispatch, memory use, or performance.

- Update the 10 retained task skills and model-history knowledge base; simplify the README and bump plugin metadata to 0.8.0. Remove both dedicated SGLang and vLLM SOTA loop skills: the benchmark, profiler, kernel, and general agent workflows cover this work.
- Consolidate the three standalone DeepSeek V4.1 optimization references into general analysis principles and operator catalogs. Preserve the manually reviewed source evidence inside the existing model-history dossiers, including the TokenSpeed reviews.
- Complete TokenSpeed/FlashInfer source sweeps and expand fusion/overlap coverage across five frameworks, with explicit caller guards, dependency pins, historical paths, and PR states. Expand bilingual model dossiers from 72 to 118 while retaining the existing 4,085 English PR entries.
- Fix profiler control/trace selection, model configuration and layer boundaries, compute templates, benchmark recipes, capacity parsing, incident summaries, and Day-0/review interfaces.

### Corrections from the second source audit

The audit found real errors after the initial review. This revision fixes shared-directory capture selection, GQA replication and target/draft/Mamba memory accounting, phase-keyed graph memory summaries, KDA gate and ReLU² shared-FFN FLOPs, C4 compression projections, and prefill epilogue work. Whole-pass MFU now requires elapsed time instead of using summed overlapping kernel durations, and pipeline tools require a verified layer count.

Catalog entries now distinguish grouped GEMMs from separate quantization/combine work, qualify platform/deferred-finalize guards, and scope benchmark numbers to their original experiments. Fifty conflicting PR date records were checked against GitHub `merged_at` in UTC. The current KV selector is no longer described as probing reader capability, and the GLM-5.3-Flash B200 FP8 recipe correctly records upstream verification as in progress.
