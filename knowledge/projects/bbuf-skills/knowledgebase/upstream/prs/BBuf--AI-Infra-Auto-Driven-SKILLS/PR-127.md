## Original PR description

Lessons from the Humanize 2 / Flame Chase explainer (2026-10-29, 50 frames, 13:23).

- **Captions patch:** `LATIN_EDGE` now includes `@` and `-`, so groups read `用 @flow` and `两个 -a` instead of `用@flow` / `两个-a`. The patched line is an added line, so the patch still applies (`git apply --check -R` passes on the applied tree).
- **Caption skins:** the runtime seam test in `assets/caption-skin.html` (and the kimi-dark skin) decides the gap per word span, so it now uses the same set (`_ + @ -`); the build-time fix alone left the render unspaced.
- **Troubleshooting:**
  - Edge's WordBoundary drops a leading `-` on CLI flags (like the known leading `/`); fix by prefixing the word text in the three meta files.
  - `pron_check --asr` fails with a SOCKS `all_proxy`; run it with `env -u all_proxy -u ALL_PROXY HF_HUB_OFFLINE=1`.
- **Pronunciation reword rows:** an English tagline read as a sentence, pytest, done, resume, chasoid, epoch, tree — all pron_check FAILs in this video, fixed by Chinese rewording.
- **Worker lessons:** size images to the card's inner width (3 frames overflowed by ~13 px); crop web-figure footnotes; no fixed-height terminal bodies with `overflow:hidden` (a key line was clipped); never `pkill` by a generic script name across concurrent workers.
