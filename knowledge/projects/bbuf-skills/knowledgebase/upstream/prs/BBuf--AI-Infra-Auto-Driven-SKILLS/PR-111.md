# sglang-explainer-video: lexicon (GiB/KiB/MoE), key reword, polyphone + glossary checks (DeepSeek V4.1 video)

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/111) · state: closed · merged: True

## Original PR description

Pronunciation and wording lessons from the DeepSeek V4.1 overview video (2026-10-18), most of them from the user's review.

- **GiB / KiB** (user's ear): read like GB / KB. New lexicon entries `GiB → G B`, `KiB → K B`. Before, the voice garbled them (Whisper heard GIG / TB); a letter-by-letter G I B reading was tried and rejected by the user.
- **MoE** (user's ear): read as "Mo", like the name *Moe*. New lexicon entries `MoE` / `DeepSeekMoE` / `MegaMoE` → `M O E`; the `moe` part (identifiers like `fused_moe`) now maps to `M O E`; MoE is removed from the "reads right as written" list.
- **key** (as in "indexer key"): heard as T in every carrier, including 索引 key. Added to the reword table; narration says 索引键 / 键 and the term stays on screen.
- **Chinese polyphones across a word boundary** (user's ear): 「生成长距离」 was read as 生成 zhǎng 距离, because the voice formed 「成长」 across the boundary. 「decoder 侧重放」 was read as 侧重 (cè zhòng). `pron_check` cannot see these because Whisper writes the same character for either reading. Added a note to `references/pronunciation.md`: scan for polyphones whose neighbour forms another word before TTS, reword (「侧的重放」), and prefer dictionary words (重新算 over 重算).
- **Glossary compliance** (user review): a title said 预填. `references/house-style.md` now says to grep the narration and the on-screen strings for Chinese renderings of glossary terms (预填 → prefill, 前缀 → prefix, 每批 / 批次 → batch, 内核, 混批) before TTS.

Checks:

- `to_spoken` gives `Deep Seek M O E` / `M O E` / `fused M O E`.
- The video was re-voiced and re-rendered with these fixes.
