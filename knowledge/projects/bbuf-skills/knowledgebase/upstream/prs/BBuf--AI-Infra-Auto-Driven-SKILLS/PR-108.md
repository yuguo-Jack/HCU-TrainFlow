# sglang-explainer-video: troubleshooting row for number + classifier caption splits

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/108) · state: closed · merged: True

## Original PR description

## What

One new row in `skills/sglang-explainer-video/references/troubleshooting.md`.

## Why

While building the SGLang Diffusion bottlenecks video (「视频生成为什么慢？三种瓶颈对应三把刀」), the narration `FastWan2.2 只跑 3 步` produced the caption groups `FastWan2.` and `2 只跑 3 步，`:

- edge-tts tokenized `2 只` (number + Chinese classifier) as one word, so `merge_split_terms` could not re-join `FastWan2.2`;
- `attach_punct` then treated the `.` as a sentence end and the caption group broke inside the term.

The existing check (groups that end without punctuation) does not catch it, because the group ends in `.`.

Fix used: put a comma right after the term (`FastWan2.2，只跑 3 步`) and re-TTS that one line. The new row records the symptom, the cause and this fix, plus what to scan for in `caption_groups.json`.
