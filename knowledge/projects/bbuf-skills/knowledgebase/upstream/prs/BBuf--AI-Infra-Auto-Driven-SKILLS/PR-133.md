# sglang-explainer-video: line_asr for Chinese readings, 累加 / mma rules, spoken-style narration

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/133) · state: closed · merged: True

## Original PR description

## Why

The user listened to the tiny GEMM video (PR 47683) and flagged two problems: misread words, and narration that sounded machine-written ("AI 味很重"). This PR feeds the fixes back into the skill. It also includes the results of re-checking the PR 47641 and PR 47512 videos the same way.

## Changes

- **`scripts/line_asr.py`** (new): transcribes every recorded line with Whisper and diffs it against the narration in pinyin, so the Chinese is checked too, not only the English terms. It caught these in the v4 take:
  - 「清空 L2 时是 0.88」 was heard as 「L20 是」, because 「L2 时」 sounds the same as 二十.
  - 「batch 是 1 的时候」 was heard as 「batch 11」.
  - In the PR 47512 video, 「batch 为 1」 sounds exactly like 唯一.
  - On the v5 take, every line comes back clean.
- **`pronunciation.json`**, two new rules:
  - 累加 → 垒加. Edge read it as lèi jiā in 6/6 takes. Controls: 积累 and 累计 0/6, 太累 6/6 lèi. After the respelling, 0/6.
  - Lowercase `mma` → `MMA`. As written, Whisper heard 安班杯.
- **`references/pronunciation.md`**:
  - Rows for N_TILE / tile (heard NTAO / Tao), the bare letter r (第 r 份 sounds like 第二份), wave inside a sentence (heard WIM) and 藏在 (zàng in 3/6 and 4/12).
  - A note on poly_probe's noise floor. A respelling with only one possible reading (步常) still scored 4/12, and 数一数 / 弹出 / 步长 did not repeat, so they get no rules.
  - Why a take that is already in a published video cannot be graded against fresh syntheses: the windowed comparison failed its own controls.
- **`references/house-style.md`**: a new rule to write the narration to be heard, not read:
  - no 「X：Y」 reveal on every line;
  - 「的时候」 after a number;
  - the roadmap frame is a plan, not a numbered table of contents;
  - one plain takeaway before the closing line.
- **`SKILL.md`**: step 4 now runs `line_asr.py` after `seg_check.py`.
- **`setup_env.sh`**: installs `pypinyin`.
