# sglang-explainer-video: K 是 N / lone-letter readings, four word cuts, designed cover on request

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/136) · state: closed · merged: True

## Original PR description

Lessons from the Paged Experts explainer video (sgl-project/sglang PR 42557 and its five follow-ups).

- **pronunciation.md, line_asr table:** 「K 是 63」 is heard as K163 because 是 after a letter fuses into the number, so write 「K 等于 63」. A lone lowercase code variable (专家 e) is read as 一, so name the thing instead. 散回 is heard as 算回. The narration rule paragraph now says both.
- **pronunciation.md, seg_check table:** four new cuts with the rewordings that passed: 内存放不下 → 内|存放, 上下文限到 → 上下|文限, 单独列出来 → 单|独列, 拿来放 → 拿|来放.
- **house-style.md:** when the user asks for it, an SGLang video may use a designed, project-local cover instead of cover A. The hook words are the largest line, it uses one accent and a line-art illustration of the mechanism, and it keeps a small 「SGLang PR 讲解 · #N」 tag so the 小红书 标记 still fits.
