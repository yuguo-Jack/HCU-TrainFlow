# sglang-explainer-video: re-check of published videos, seg_check classifier, replacing a published video

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/135) · state: closed · merged: True

## Original PR description

## Why

The user asked to re-check the narration of the six most recent published explainer videos and replace any that had misread lines. Two needed fixes: PR 28185 (2 lines) and PR 47684 (2 lines). Both were re-voiced, re-rendered and replaced in place on B站 and 小红书. This PR feeds what the check learned back into the skill.

## Changes

- **`scripts/seg_check.py`:** a new `classifier` hit for a number fused with 只 in one voice token (`'24只'|'要'`, read as a measure word).
  - It flags the PR 43570 take the user caught earlier.
  - It reports nothing on the six current takes.
- **`references/pronunciation.md`:**
  - New line_asr rows: 大时 and 接近时 (heard as 十), SM 数只查 (heard 之差), 半空着 (heard 半空整), 树记下 (heard 数据下).
  - The narration rule now covers a clause-final 时 after any word, not only after a digit.
  - How to tell a misreading from Whisper noise:
    - Edge returns nearly the same audio for the same text, so a repeat in fresh takes proves nothing.
    - Compare token durations instead: 吞吐 was 0.55 s in the doubtful line vs 0.53 s in lines heard right, so no syllable was added.
    - Tone sandhi and Whisper's bias toward common words produce false hits (因果→英国, 四舍五入→四手).
  - `poly_probe` cannot measure tone-only polyphones: the control 「它只能存」 scored 12/12 wrong. For 只, use the WordBoundary tokens instead.
- **`SKILL.md`, `references/publishing.md`:** a new section on replacing the video of a published post.
  - B站: 更换视频.
  - 小红书: 重新上传, which drops the 标记.
  - The file dialog needs the Browser pane on screen; an upload started while it was hidden froze at 100%.
  - The 标记 dialog's 确定 buttons need real clicks; a JS click closes the editor without saving.
- **`references/troubleshooting.md`:** re-synthesize the film's last line on its own with `EDGE_TTS_PAD_LAST=2.0` to keep the 2 s closing hold.
- **`tests/test_explainer_seg_check.py`:** classifier vs right takes. It is skipped where jieba is not installed, which includes CI.
