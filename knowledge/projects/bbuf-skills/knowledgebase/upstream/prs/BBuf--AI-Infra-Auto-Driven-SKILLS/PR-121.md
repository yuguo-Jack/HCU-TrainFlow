# sglang-explainer-video: rid lexicon, Gloo / MIN rewordings, dotted-version caption split

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/121) · state: closed · merged: True

## Original PR description

Lessons from the SGLang PR 37909 explainer video (disaggregated prefill bootstrap rid alignment).

- `pronunciation.json`: `rid` → `R I D`. Xiaoxiao read it as "reed" (Whisper: read / Reed in 10 of 11 lines); after the fix Whisper hears RID / rid.
- `pronunciation.md` reword table: **Gloo** (glue / Glue / Gluu / Glooo / G loo all fail, heard 格尔 / 歌) → say CPU 上的通信组 / 这个后端; **MIN** (heard main; min fails, minimum passes) → say 取最小值. Both stay on screen.
- `troubleshooting.md`:
  - a dotted version followed by a CJK character splits the caption (`v0.` | `5.18 里，`) because edge-tts returns `5.18 里` as one word; end the version with punctuation (`当时用的是 v0.5.18，…`).
  - `pron_check --asr` under a SOCKS `all_proxy` fails with a socksio ImportError; run it with `env -u all_proxy -u ALL_PROXY HF_HUB_OFFLINE=1`.
  - re-voicing one line after its frame was built while other frames use the newer take: retime only that frame with `--frames <fid>=<N>` against a snapshot of the built take.
