# Fix Windows CUDA dynamic loading and error reporting

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1515) · state: closed · merged: False

## Original PR description

## Summary

Fix Windows CUDA dynamic loading in `cudnn_frontend_shim.h`: use `nvcuda.dll` and `cudart64_12.dll`/`cudart64_13.dll`, and report numeric Win32 error codes only when loading or symbol lookup fails. Previously the loader used Linux library names, reinterpreted `GetLastError()` as a string pointer (causing an access violation), and could reject successful calls because of stale error codes.
