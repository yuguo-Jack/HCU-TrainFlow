## Summary

Refs #1567, refs #1570. Both issues are silent wrong output from SDPA forward execute-time overrides. The fixes belong in the backend. This PR records each one where the override contract is documented.

**1. The off-grid window is set by the KV tile (#1567).**

#1148 recorded that a non-causal override off the plan's tile grid returns wrong output, and attributed the window to the Q tile. On cuDNN 9.27, with A100, L40S, H100 and B200 and each native plan pinned, the window is set by the **KV** tile:
- an `s_q`-only override off the grid is correct;
- an `s_kv` override off the KV tile matches the reference over `K[:ceil(s_kv / tile) * tile]`, i.e. it attends the padding rows.

On the first-ranked H100/B200 plans (`eng9`/`eng10`) that tile is 128, so even `s_kv = 64` is wrong. Two forms served every override measured:
- a declaration off the KV tile (255);
- carrying the real lengths in `seq_len_q` / `seq_len_kv` with `use_padding_mask=True`, dense or ragged.

This PR corrects the boundaries row and consequence 2. The existing xfail now overrides only `s_kv` (64 × 96), so only the KV axis can fail it.

**2. `override_strides` are accepted but not used (#1570).**

The native plans read and write with the strides declared at build time. Two cases show it:
- BSHD buffers at the declared shape, with matching `override_strides`, give O(1) error. The output matches attention over the same storage read with the declared BHSD strides.
- A graph declared with `b = 1` and overridden to `b = 2` leaves batch 1 of O unwritten.

Measured on A100, L40S, H100 and B200 with 9.27, and on L40S with 9.26 on the measured plan. The docs already said "the strides describe the declared storage". This PR adds that other strides are ignored, adds two boundary rows, and adds a pointer in the generic `override_strides` description. A new strict xfail, `test_override_strides_for_another_layout_are_honored`, uses the existing cc 8.9 / 9.26 / pinned-plan gate.

- On other GPU/version combinations, the measured cases skip as before.
