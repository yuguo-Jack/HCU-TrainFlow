# feat(sdpa): extend D256 THD split to Blackwell and nonpaged KV

[Upstream PR](https://github.com/NVIDIA/cudnn-frontend/pull/1533) · state: closed · merged: True

## Original PR description

Packed D256 prefill could use split-KV only on Rubin with paged K/V. This extends the same prepared two-CTA partial/combine path to Blackwell paged prefill and to nonpaged packed prefill on Blackwell and Rubin.

The supported domain is exact D256/V256 FP16/BF16 on SM100/SM103/SM107, with unpacked heads and CGA2. Nonpaged Rubin split plans select the existing shared SM100 D256 body; unsplit Rubin plans retain their existing implementation. The native binder accepts the nonpaged geometry and advertises it separately so older extensions decline safely. No new kernel mainloop, synchronization protocol, public knob, execute-time allocation, staging copy or device-to-host metadata read is added.

Packed NH/HN Stats, optional log2 Stats, runtime sequence lengths and bounded overrides retain the common graph contract. Sink, padded Stats, fused gate, pre-folded scale, quantized and PackGQA split combinations retain their current exclusions. The support tracker is updated. Automatic selection is unchanged: the newly supported domains are explicit candidates for a separate measured heuristic update.

Validation with matching rebuilt extensions, cuDNN 9.27 and CuTe DSL 4.8:

- SM103 and SM107: 112 tests passed on each, including 60 native binder cases, 40 paged D256 capture/replay cells and the initial 12 nonpaged cells.
- Final expanded support/capture coverage: 52 passed on each, comprising 36 admission/decline cases and 16 nonpaged FP16/BF16 capture cases. These overlap the initial run; they are not additive totals.
- Coverage includes B1/B3, Q1 and non-tile-aligned Q, causal/unmasked attention, empty/keyless rows, NH/HN/absent Stats, ln/log2 Stats, rebased strided views, poisoned output slack, changed inputs/lengths under replay and missing native support. Tests check outputs and support contracts without heuristic-order or timing goldens.
- Compute Sanitizer memcheck on SM107: all 16 nonpaged capture cases passed, 0 errors. No new full-mainloop racecheck claim is made.
- The new nonpaged graph regression fails at the old unsupported-plan gate on unmodified develop. Changed-file format/license checks pass. SM100 shares the SM103 path; its device qualification is left to the requested internal CI.

All explicit configurations in the local candidate sweeps passed O/LSE checks against FP64 before and after graph replay. Default selection remains a separate task; support for splitting does not imply that splitting is beneficial for an already occupied GPU.
