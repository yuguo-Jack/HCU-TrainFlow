# [ac] Fix RegionAC compiled graph replay order

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5205) · state: open · merged: False

## Original PR description

## Summary

- Run the existing Dynamo LRU graph-order workaround from RegionAC.apply.
- Add a regression test covering checkpoint replay after a static-to-dynamic compile transition.

## Why

RegionAC overrides the base activation-checkpointing apply method, so it skipped the process-wide setup already used by the other checkpointing policies. With pipeline parallelism, one rank can execute a compiled function with several input shapes before an earlier checkpoint is replayed. Dynamo LRU ordering can then choose the newer dynamic graph during recomputation even though the original forward used the static graph, causing a checkpoint tensor-metadata mismatch.

This uses the existing workaround for pytorch/pytorch#166926 and does not change checkpoint policy or model numerics.
