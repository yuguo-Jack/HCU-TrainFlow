## Description
This pull request adds a comprehensive Simplified Chinese translation of the documentation (`README.zh.md`) for **torchtitan**.

### Key Changes
- Added `README.zh.md` covering:
  - Architecture & vision (composable parallelism, built for research, pretraining to RL in one stack, frontier models and techniques)
  - Quick start workflows (installation with nightly PyTorch, debug model, real model, custom recipe creation)
  - Supported model matrix (Llama 3, Qwen3, Qwen3.5/3.6/3.8, DeepSeek V3/V4, gpt-oss, Kimi K2.7/K3, Muse Glimmer, FLUX)
  - Features overview (parallelism schemes, memory & performance optimizations, Grain data pipeline, TitanRL post-training, distributed checkpointing, metrics/observability, extensibility)
  - Hardware test status matrix & multi-node Slurm guide
  - Documentation links & contribution guidelines
- Added bidirectional language switchers (`English` · `简体中文`) in both `README.md` and `README.zh.md`.
- Added a volunteer maintenance note committing to long-term synchronization with upstream documentation updates.

No code or core project configuration files were altered.
