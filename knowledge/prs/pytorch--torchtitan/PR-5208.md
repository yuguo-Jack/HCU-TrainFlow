# [graph_trainer] Accumulate PP gradients in graph

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5208) · state: open · merged: False

## Original PR description

PP previously returned each microbatch parameter gradient to Python for accumulation.

Use the same first/repeated lifecycle as PP1: the first backward returns initial gradients; repeated full, split-dW, and multiplexed backward graphs receive and update those handles; REDUCE_GRAD consumes the final handles once.

With the shared add-chain support from #5119, supported repeated WGrad producers fuse into the accumulator when enabled. Unsupported producers retain explicit add_.

Validation: 86 focused WGrad and GraphPP runtime tests passed.
