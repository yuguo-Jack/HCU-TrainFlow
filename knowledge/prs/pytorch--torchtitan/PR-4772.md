i am looking into this, but seems like it's a bug that actually helps modeling, because this is mutable state?

say you have pp schedule like
`f0 f1 f2 f3 b0 b1 b2 b3`

with no AC, b0 will read the stats buffer saved from `counts(f0)`, so it's just the first batch
b1 reads `counts(f0) + counts(f1)`, so it's the rolling approximate

with AC, it seems the buffer is not snapshotted, but used when b0 recomputes f0. but now f0-f3 have accumulated into the buffer, so it actually reads the global stat `counts(f0) + counts(f1) + counts(f2) + counts(f3)`, which is not approximate but exact lol

but also the exact numerics will depend on PP schedule
@soulitzer in case this makes sense to you, maybe i'm doing something wrong
