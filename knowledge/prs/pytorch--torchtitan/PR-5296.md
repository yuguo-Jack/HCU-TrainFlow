# [Attn] Remove SDPA and use Varlen attention in Flux

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5296) · state: open · merged: False

## Original PR description

This PR removes the core SDPA backend and moves Flux and GraphTrainer recipes to shared Varlen attention, reducing the number of attention implementations to maintain.

Flux keeps its existing `[B, L, D]` activations and packs Q/K/V only at attention calls. Per-sample document boundaries are built once per forward, preserving bidirectional attention within each sample and isolation between samples. Under CP, K/V are gathered before packing.

## Tests

### Numerics

10-step synthetic `flux-debug`, seed 42, strict determinism, CP=1 and CP=2: outputs, loss, grad_norm, parameter gradients, and final weights match `0b34e4ea36` bitwise.

Varlen/cuDNN versus original SDPA/cuDNN on captured training inputs: maximum relative L2 difference (%), across four layers per recipe.

| Recipe | Output | dQ | dK | dV |
| --- | ---: | ---: | ---: | ---: |
| dev | 0.0035 | 0.0100 | 0.0169 | 0.0042 |
| schnell | 0.0035 | 0.0093 | 0.0163 | 0.0040 |

### Performance

Measured at `d2ddc8d2d5` on one H100, BF16, 24 heads x 128, PyTorch 2.14.0+cu130 / cuDNN 9.24. Both backends verified as cuDNN; TF32 off, deterministic=False.
