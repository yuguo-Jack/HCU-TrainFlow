# [dsv4][perf] Don't cache the Indexer's Hadamard matrix

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5201) · state: open · merged: False

## Original PR description

**TLDR:** Stop caching the Compressor's Hadamard matrix: a fake-tensor trace poisoned the cache and broke later eager calls. Correctness fix, speed-neutral.

**Problem**
1. **Cached matrix.** `compressor._hadamard` builds a 128x128 matrix under `functools.cache`.
2. **Fake first.** A fake-tensor trace (make_fx, GraphTrainer) fills the cache with a FakeTensor.
3. **Breaks eager.** Later eager Indexer calls get that FakeTensor and fail.
4. **Real first.** The other order bakes a real tensor into the trace as a constant.

**Solution**
1. **No cache.** Build the 128x128 matrix on every call.
2. **Unchanged:** the matrix and the Indexer math.
