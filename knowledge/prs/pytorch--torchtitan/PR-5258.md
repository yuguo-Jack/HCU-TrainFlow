* #5265
* #5264
* #5261
* #5259
* __->__ #5258

Fuse sigmoid, grouped top-k, routing weights/map/counts, and score/routing
gradients. Preserve the native gate and auxiliary-loss boundaries.

Keep kernels, custom operators, autograd and override in one file, with
one CPU test file and one GPU test file.

Recorded GB300 FP32 [4096,256], native -> CuTeDSL:
Fwd 170.41 -> 13.06 us; Bwd 27.08 -> 3.52 us; F+B 193.87 -> 15.75 us.
Bitwise checks pass; roofline acceptance remains open. Requires CuTeDSL 4.8+.
