# Fuse DSv3 HiMidLo router-gate backward experimentally

[Upstream PR](https://github.com/pytorch/torchtitan/pull/5264) · state: open · merged: False

## Original PR description

Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #5265
* __->__ #5264
* #5261
* #5259
* #5258

Fuse BF16 gradient splitting and weight repetition in one CuTeDSL kernel,
then the three dW GEMMs and FP32 sums in another. Use native forward/dX
GEMMs with FP32 weight gradients and native FSDP ownership. Backward
uses three GPU kernels.

GB300, BF16 x=[4096,7168], weight=[256,7168], native -> candidate:
Backward 101.05 -> 59.12 us; F+loss+B 131.97 -> 93.79 us (28.9% saved).
Native local_compile F+loss+B: 117.20 us. Peak allocated memory versus
native: 179.5 -> 176.0 MiB; peak reserved stays 198.0 MiB.

61 CPU/GPU tests pass, including bitwise, compile and FakePG/FSDP128.
Keep default-off: 88.2% of the calibrated roof at p90 is below 90%.
Extended tensor-operation checking remains unresolved; the same failure
reproduces in NVIDIA's reference kernel.

One self-contained override file, one CPU test file and one GPU test file.
