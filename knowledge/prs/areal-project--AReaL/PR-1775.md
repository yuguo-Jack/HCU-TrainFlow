## Description

Reject non-inline image sources before local base64 decoding with a clear error for both
OpenAI-compatible proxy requests and direct `ArealOpenAI` calls. Clarify the inline-only
contract in docstrings and validation messages while preserving URL forwarding for
tokenizer-only clients.
