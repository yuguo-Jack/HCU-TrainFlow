# fix(proxy): assign terminal rewards to completed interactions

[Upstream PR](https://github.com/areal-project/AReaL/pull/1755) · state: open · merged: False

## Original PR description

## Description

When a completed interaction A is followed by an unfinished request B, implicit terminal reward assignment currently targets B. Export then removes B, leaving A without a reward and potentially rejecting the entire rollout group. Assign the reward to the latest completed interaction instead, using the same completeness check as export.

Exclude unfinished entries from retry-orphan candidates so an unfinished duplicate cannot displace a completed response. Preserve existing parent-child consumption evidence. If no completed interaction exists, return an error and propagate implicit assignment failures to the caller. Explicit completion IDs and stream aliases retain their existing behavior.
