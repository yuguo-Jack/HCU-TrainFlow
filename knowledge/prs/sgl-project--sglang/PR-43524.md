# Fix duplicate global scaling in NVFP4 prefill workspaces

[Upstream PR](https://github.com/sgl-project/sglang/pull/43524) · state: open · merged: False

## Original PR description

## Motivation

FlashInfer prefill applies NVFP4 global K/V scales twice when reading the FP8
dequant workspace. The existing NVFP4 recipe restores physical values with
`packed * block_scale * global_scale` before conversion to FP8. Passing the same
global scales to the paged attention consumer then changes both logits and
output values. This affects non-unit scales in paged prefill and the cached
prefix of ragged prefill.

## Modifications

Pass no additional K/V global scales to these two consumers when
`prefill_uses_dequant_workspace` is selected. Ordinary FP8 reads retain their
existing scale arguments. No decode, planner/CSR, native packed access, TRTLLM,
pool allocation or model-weight changes are included.

The branch starts at exact main
`e35f60b9bcb51045fd0602d8ed12cff8021c040f`. This is a standalone correction to
the existing workspace path. It does not require or duplicate native-prefill
#43471 or the FlashInfer decode/heterogeneous changes in #43247.

Reviewed candidate commit: `3c06207371` (DCO signed off, AI-attributed).

## Accuracy Tests

Pinned CPU red/green regression with non-unit unequal global scales K=2, V=4:

- Baseline main plus the new test: two workspace cases fail; two ordinary FP8
  control cases pass.
- Corrected source: one test, all four subcases pass, covering paged prefill
  with physical fresh KV and ragged suffix/cached-prefix composition.

The test executes actual `FlashInferAttnBackend.forward_extend` and the actual
NVFP4 recipe's global-scale selection/FP8 conversion under a real scoped runtime
topology. It substitutes CPU numerical attention/merge and the CUDA unpack
primitive. It therefore verifies the serving consumer contract and numerical
regression, not compiled FlashInfer kernel execution or end-to-end model quality.

Exact CPU environment: `/home/jethac/sglang-stage1-20261010/venv/bin/python`,
`CUDA_VISIBLE_DEVICES=99`, `PYTHONPATH=<exact-source>/python`; command:

```sh
python test/registered/unit/layers/attention/test_nvfp4_workspace_globals.py
```

No GPU serving test has been run for this main-based source. Historical GPU
results from composed campaign branches are not used as evidence for this PR.
