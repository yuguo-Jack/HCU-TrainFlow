## Original PR description

## Motivation

Add FlashInfer support for zigzag prefill context parallelism on dense MHA/GQA models, addressing #21788.

## Modifications

- Add FlashInfer CP dispatch and CP-aware paged prefill metadata/execution.
- Gather full KV while keeping queries zigzag-sharded; support eager dense causal MHA/GQA with direct NHD KV.
- Use current runtime configuration without deprecated `enable_cp_v2` or model-file changes; add CPU routing/padding coverage and a Qwen3-8B `GSM8KMixin` test.

Qwen3-8B BF16 on 2× H100. Parity compares TP2/CP2 with both cold cache and prefix reuse.
