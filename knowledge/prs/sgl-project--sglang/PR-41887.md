## Motivation

Adds a Blackwell CuTe DSL dual-GEMM kernel that fuses:

gate = input @ gate_weight
up = input @ up_weight
output = SiLU(gate) * up

Tested on B200
- Llama 3 8B FP8, BS1, **5.2% Offline Gains**
- Qwen 2 7B FP8, BS1, **7.8% Offline Gains**

## Modifications
  - Supports BF16, FP16, and FP8 inputs.
  - FP8 supports:
      - Static per-tensor
      - Static per-token
      - Dynamic per-tensor
      - Dynamic per-token
  - Supports decode batches from 1–16 tokens.
  - Uses TMA loads, tcgen05 MMA, warp specialization, one/two-CTA tactics, and resident-grid dynamic reductions.
  - Adds B200-tuned tactic selection based on batch size, hidden size, intermediate size, quantization mode, and dtype.
  - Gates the fused path to SM10x, aligned shapes, and intermediate sizes up to 18,944.
  - Supports prequantized activations and avoids redundant down-projection quantization.
  - Adds a reusable non-nn.Module DualGemm integration layer.
  - Integrates the fused path into Llama and Qwen2 MLPs.
  - Adds kernel correctness tests, layer integration tests, and benchmarks against the existing SGLang operator sequence.
