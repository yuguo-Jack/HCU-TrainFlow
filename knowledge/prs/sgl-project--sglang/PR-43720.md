# [Perf] Fuse asynchronous NaN validation into one kernel

[Upstream PR](https://github.com/sgl-project/sglang/pull/43720) · state: open · merged: False

## Original PR description

## Motivation

Enabled NaN validation launches separate `isnan`, reduction, negation, and device-assert kernels. This adds overhead to logits and probability checks, including non-contiguous vocabulary slices.

## Modifications

Fuse CUDA floating-point NaN validation into one read-only Triton kernel. Support contiguous tensors and strided 2D views, including transposes, storage offsets, and broadcast rows. Use 64-bit offsets and a flat launch grid for large strides and tall views.

Keep device assertions enabled with `TRITON_DEBUG=0`, including during CUDA graph replay. Keep the Torch fallback for compiled callers: compilation can eliminate the read-only Triton call and silently lose the assertion. Other devices/dtypes and higher-rank non-contiguous inputs also retain the Torch path.

NaNs still fail asynchronously, infinities remain valid, and inputs remain unchanged. The existing flags and their defaults are unchanged.

## Accuracy Tests

26 tests passed on NVIDIA GB300 (202 seconds). Coverage includes fatal NaNs in eager execution, CUDA graph replay, compiled callers, strided/transposed inputs, and strided graph replay; FP16/BF16/FP32/FP64 finite and infinite inputs; block boundaries; both enable flags; disabled CUDA checks; excluded NaN padding; storage offsets; row/column strides; and empty, broadcast, and 65,537-row views. Each fatal assertion runs in a subprocess so its invalid CUDA context cannot affect other tests.

Registered in `base-b-test-1-gpu-small`.

Reproduce:

```bash
python -m pytest test/registered/unit/utils/test_async_probe.py -q
```

## Speed Tests and Profiling

NVIDIA GB300, PyTorch 2.11, Triton 3.6. Median GPU microseconds over three CUDA-graph rounds. Each large-input round cycles through disjoint tensors totaling at least 512 MiB; the 16×8 case measures launch overhead. Baseline is the existing Torch expression.

| Input | Torch (μs) | Fused (μs) |
| --- | ---: | ---: |
| FP32 contiguous 16x154856 | 24.87 | 3.34 |
| FP32 vocabulary slice 16x154856 | 29.20 | 3.47 |
| FP32 vocabulary slice 64x154856 | 47.22 | 7.86 |
| BF16 vocabulary slice 16x154856 | 29.03 | 3.02 |
| FP32 transposed vocabulary slice 16x154856 | 29.29 | 3.36 |
| FP32 contiguous 16x8 | 12.94 | 1.07 |

These are isolated operator timings; full-model throughput was not measured.

<details>
<summary>Benchmark reproduction script</summary>

Save as `bench_async_nan.py` and run `python bench_async_nan.py` on one CUDA GPU with this checkout installed.

```python
import json
import os
import statistics

os.environ['SGLANG_ENABLE_NAN_LOGITS_CHECK'] = '1'
os.environ['SGLANG_ENABLE_ASYNC_ASSERT'] = '0'

import torch
import triton
from sglang.srt.utils.async_probe import maybe_detect_nan


def baseline(x):
    torch._assert_async(~torch.any(torch.isnan(x)), 'NaN detected! benchmark')


def fused(x):
    maybe_detect_nan(x, 'benchmark')


def measure(fn, tensors):
    for x in tensors:
        fn(x)
    torch.cuda.synchronize()
    def check_all():
        for x in tensors:
            fn(x)
    return statistics.median(triton.testing.do_bench_cudagraph(check_all, rep=1000) * 1000 / len(tensors) for _ in range(3))


print(json.dumps({'gpu': torch.cuda.get_device_name(), 'torch': torch.__version__, 'triton': triton.__version__}), flush=True)
for label, dtype, rows, cols, sliced, transposed in (
    ('FP32 contiguous 16x154856', torch.float32, 16, 154856, False, False),
    ('FP32 vocabulary slice 16x154856', torch.float32, 16, 154856, True, False),
    ('FP32 vocabulary slice 64x154856', torch.float32, 64, 154856, True, False),
    ('BF16 vocabulary slice 16x154856', torch.bfloat16, 16, 154856, True, False),
    ('FP32 transposed vocabulary slice 16x154856', torch.float32, 16, 154856, True, True),
    ('FP32 contiguous 16x8', torch.float32, 16, 8, False, False),
):
    n = max(1, triton.cdiv(512 * 1024**2, rows * cols * torch.empty((), dtype=dtype).element_size())) if cols > 8 else 1
    tensors = [torch.randn(rows, cols + int(sliced), dtype=dtype, device='cuda')[:, :cols] for _ in range(n)]
    if transposed:
        tensors = [x.T for x in tensors]
    before = measure(baseline, tensors)
    after = measure(fused, tensors)
    print(json.dumps({'input': label, 'tensors': n, 'torch_us': round(before, 2), 'fused_us': round(after, 2)}), flush=True)
    del tensors
```
