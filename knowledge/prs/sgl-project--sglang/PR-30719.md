For dtype:

- Input is bf16 in most casse, with a bf16 packed weight and a bias that is either absent or fp32. 
- The exception is Wan, where text_embedder.fc_in gets an fp32 input (the UMT5 text-encoder output) against a bf16 packed weight and fp32 bias, so .to(weight.dtype) is required.

For some typical shapes (M, K, N) from Z-Image-Turbo at 1024×1024:
- Main DiT (M = 4128, i.e. 4096 image tokens + 32 text tokens): 4128×3840×20480 (w13), 4128×10240×3840 (w2), 4128×3840×11520 (to_qkv), 4128×3840×3840 (to_out).
- adaLN modulation: 1×256×15360.
- Qwen3 text encoder: 512×2560×6144, 512×4096×2560, 512×2560×19456, 512×9728×2560.
