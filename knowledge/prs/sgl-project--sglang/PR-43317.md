# [CLI] Keep the diffusion pipeline runtime out of backend auto-detection

[Upstream PR](https://github.com/sgl-project/sglang/pull/43317) · state: open · merged: False

## Original PR description

## Motivation

`--model-type` is optional, so `sglang serve` auto-detects the backend before it knows which one it will start. Detection called `has_registered_diffusion_model_path()`, which ran `_ensure_registry_initialized()` and imported every built-in diffusion pipeline. Those transitively import the `attentions` package and load its bundled `libcust_opapi.so`.

On Ascend the LLM runtime also loads CANN's `custom_transformer/libcust_opapi.so`. Both export `aclnnQuantLightningIndexer` and `aclnnQuantLightningIndexerGetWorkspaceSize`, so the duplicate registration breaks operator resolution and `sglang serve <model>` only starts reliably with an explicit `--model-type llm`, which skips detection.

## Modifications

One line of behaviour in `python/sglang/multimodal_gen/registry.py`: `has_registered_diffusion_model_path()` now calls `load_external_model_package()` instead of `_ensure_registry_initialized()`.

Detection only reads `_MODEL_HF_PATH_TO_NAME` and `KNOWN_NON_DIFFUSERS_DIFFUSION_MODEL_PATTERNS`, never `_PIPELINE_REGISTRY`, which is the only thing discovery fills. The path aliases are already registered at import time by `_discover_and_register_configs()`. Measured with `diffusers` installed: discovery takes `_PIPELINE_REGISTRY` from 0 to 56 and leaves `_MODEL_HF_PATH_TO_NAME` at 99, and every registered path stays detectable without it.

`load_external_model_package()` is kept so `SGLANG_EXTERNAL_MODEL_PACKAGE` models stay detectable. Diffusion serving is unaffected, since `get_pipeline_class()` still initializes the registry on demand. Without `diffusers`, `_diffusion_deps_available()` returns `False` as before.

## Tests

Three CPU unit tests, each verified failing on the code it guards:

- `test_server_args.py`: detection does not populate `_PIPELINE_REGISTRY`.
- `test_server_args.py`: pipeline discovery registers no model path aliases.
- `test_serve_backends.py`: importing `sglang.multimodal_gen` does not import the generator runtime.

The first two need `diffusers`, so they belong to `base-b-test-diffusion-unit-1-gpu-h100` rather than `base-a-test-cpu`. 370 tests pass across the consumers of the touched functions, and `pre-commit run` is clean.
