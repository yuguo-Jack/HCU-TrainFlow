# [PD][MORI] Transfer DCP-replicated DSPARK draft KV

[Upstream PR](https://github.com/sgl-project/sglang/pull/39197) · state: closed · merged: False

## Original PR description

## Summary

MORI counterpart to #37709, stacked on #38317 (the MORI counterpart to #35762).

For DCP1 -> DCP-N DSPARK transfers, target KV remains owner-strided and uses the packed path from #38317. Draft KV is replicated, so every row is sent un-packed with the widened virtual-page destination mapping from #37709.

## Changes

- Split MORI DCP descriptors into target and draft tails using `num_draft_entries`.
- Exclude the draft tail from pack-buffer sizing and target gather.
- Keep target rows packed; submit draft rows as a separate replicated transfer part.
- Retain both parts in the shared status sink so earlier RDMA writes are drained if a later submission fails.
- Test packed-target/raw-draft addressing, draft-only and empty plans, permuted destination mapping, and partial-submission status retention.

## Validation

- `130 passed, 16 subtests passed` in the focused disaggregation/MORI regression suite.
- Repository AST, isort, Ruff, Ruff format, codespell, and merge-conflict checks passed.

Out of scope, matching #37709: DCP>1 prefill and heterogeneous prefill/decode TP with DSPARK.

Dependency: #38317. Until it merges, GitHub includes the base series in this PR; the isolated follow-up diff is [here](https://github.com/AMD-yanfeiwang/sglang/compare/rocm/mori-dcp-packed-transfer...rocm/mori-dcp-dspark-draft-kv).
