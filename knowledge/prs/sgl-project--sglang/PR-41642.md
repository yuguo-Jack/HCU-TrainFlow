# [NPU] Transfer MTP draft pools in MLA kernel_ascend L2 IO

[Upstream PR](https://github.com/sgl-project/sglang/pull/41642) · state: open · merged: False

## Original PR description

## Summary

Fix MLA HiCache L2 kernel_ascend IO so that the MTP draft pool is transferred together with the target pool on NPU.

## Changes

- **mla.py**: transfer the target and MTP draft pools separately in kernel_ascend H2D/D2H via `_npu_transfer_pool_slices()` (skip draft pools whose component width/dtype does not match the host mirror).
- **mla.py / memory_pool_npu.py / hybrid_pool_assembler.py / tensorcast_store.py**: build the packed target+draft device pointer tables through an overridable `_init_packed_device_transfer_buffers()` hook and a `get_mla_host_pool_cls()` factory that dispatches to a new `NPUMLATokenToKVPoolHost` subclass on NPU (mirrors #41054). The subclass skips the packed build because NPU pools never build the CUDA-style `data_ptrs`/`kv_buffer` arrays, avoiding `AttributeError: NPUMLATokenToKVPool has no attribute data_ptrs`.

## Verification

- GLM-5.2-w8a8 + NEXTN MTP + L2 cache (kernel_ascend, page_first_kv_split) on NPU: server starts, spec decoding active, L2 cache hit confirmed (same long prefix second request reports `cached_tokens=640`).
- L3 (npu_memcache, device_sdma) write works: 0 failures.
