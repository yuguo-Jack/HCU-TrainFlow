# [sgl-router] refactor - config and organize CLI options

[Upstream PR](https://github.com/sgl-project/sglang/pull/39867) · state: closed · merged: True

## Original PR description

Stacked on #39861.

Group CLI options by purpose and use focused builders to make configuration conversion and validation easier to follow. Preserve all 55 current flag names, types, defaults, and parser constraints.

## Changes

- Keep six CLI groups: model/tokenizer/sampling; server/timeouts/logging; worker discovery; routing/admission/circuit breaker; cache-aware routing; and session/sticky affinity with pressure guards.
- Include main's `--disable-input-ids-forwarding` in model options and `--min-load-choices` in cache-aware options, preserving their validation and configuration wiring.
- Simplify builders and validation, reduce unnecessary cloning, and retain concise comments explaining behavioral constraints.

- Compare all 55 CLI flag declarations against main; types, defaults, and parser attributes match.
- CLI help smoke check and existing six-section help coverage pass.
