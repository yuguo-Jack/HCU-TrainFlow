# [Perf] Check tool parameter schemas with jsonschema-rs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43274) · state: open · merged: False

## Original PR description

## Motivation

The chat endpoint checks each tool's `parameters` against the JSON Schema 2020-12 metaschema on every request, on the API server's event loop. `Draft202012Validator.check_schema` is pure Python and takes about 1 ms per tool, so an agent that sends 18 tools adds 16 ms of blocking CPU to each request.

#42213 adds a cache and skips the check for schemas it has already seen. This PR instead makes the check itself about as fast as a cache read, so a new schema is fast too and no cache is needed.

## Modifications

- Check tool parameters with a `jsonschema_rs.Draft202012Validator` built once at import.
- Add `jsonschema-rs==0.58.6` (MIT, prebuilt wheels) to every `pyproject`.
- Error messages keep the same form: the failing value, the keyword, and the location in the schema.

## Accuracy Tests

Model inputs and sampling are unchanged. On 41,559 schemas (edge cases, two fuzzers over real agent tool schemas, and nesting up to the HTTP body limit), jsonschema-rs accepted every schema that `check_schema` accepts. It also accepts schemas nested past Python's recursion limit (about 98 levels) and `pattern` regexes that Python's `re` cannot compile; xgrammar reports an invalid pattern when it builds a grammar from the schema.

## Speed Tests and Profiling

Checking the 18 tool schemas of a coding agent, median of 5,000 runs on one thread:

| | check_schema | jsonschema-rs |
|---|---|---|
| 18 tools | 15.9 ms | 0.05 ms |

End-to-end: Qwen3-8B on one H100, streamed chat with a cached 11K-token prefix (system prompt and the 18 tools) and 32 output tokens. One server ran both checks, alternating in blocks over 10 rounds per concurrency.

| Concurrency | TTFT p50 before (ms) | TTFT p50 after (ms) | Change |
|---|---|---|---|
| 1 | 58.4 | 34.9 | −40% |
| 4 | 90.8 | 59.8 | −34% |
| 16 | 436.4 | 87.2 | −80% |

Unit tests pass, with one new test in `test_serving_chat.py`:
- `test_serving_chat.py` (151)
- `test_normalize_json_schema_types.py` (23)
- `test_json_schema_constraint.py` (18)
