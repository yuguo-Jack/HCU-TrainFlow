# [NPU]Update references from A5 to arch35 or Ascned 950 across multiple modules

[Upstream PR](https://github.com/sgl-project/sglang/pull/41504) · state: open · merged: False

## Original PR description

## Motivation

Ascend NPU code uses inconsistent hardware terminology, including A5, Atlas A5, and arch35. This PR standardizes hardware descriptions to Ascend 950 and aligns KV-cache helper names with the existing `is_npu_arch35()` capability check.

## Modifications

- Update comments, docstrings, error messages, and CLI help to use Ascend 950 across NPU attention, quantization, MoE, disaggregation, and multimodal generation code.
- Rename `a5_packed_kv_dim` to `arch35_packed_kv_dim` and `_write_a5_packed_kv` to `_write_arch35_packed_kv`, updating all callers.
- Update hardware references in DeepSeek-V4 model code and NPU test utilities.
