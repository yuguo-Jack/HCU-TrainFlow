# [Fix] Expose DP scheduler rank count on ServerArgs

[Upstream PR](https://github.com/sgl-project/sglang/pull/42563) · state: open · merged: False

## Original PR description

## Motivation

After #41818, the deprecated `--dp-size N --enable-dp-attention` spelling resolves to `dp_size=1` and `attn_dp_size=N`. In-process integrations that read `ServerArgs.dp_size` therefore register only one scheduler rank, even though SGLang serves N ranks.

This exposes the configured scheduler rank count as `ServerArgs.num_dp_ranks` and points users of the deprecated flag to that accessor.

Fixes #42560.

## Modifications

- Add `ServerArgs.num_dp_ranks`, computed from the resolved replica and attention-DP widths.
- Include the accessor in the deprecated flag's migration warning for in-process integrations.
- Extend the registered regression tests for the legacy spelling, the explicit attention-DP flag, and ordinary data parallelism.
