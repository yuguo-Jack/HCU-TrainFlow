# [DSv4.1] Fold encoder-SWA replay into the extend forward

[Upstream PR](https://github.com/sgl-project/sglang/pull/43166) · state: open · merged: False

## Original PR description

## Motivation

With `--enable-encoder-swa-bounded-replay`, every prefix hit runs one extra eager full-model forward (≤128 tokens) before the batch's extend, one hit after another. Each costs about 240 ms on GB300 regardless of context length, almost all host time, so 16 concurrent hits wait for 16 serial forwards.

```bash
python3 -m sglang.launch_server --model-path deepseek-ai/DeepSeek-V4.1-Flash --trust-remote-code \
  --tp 4 --ep-size 4 --cuda-graph-backend-prefill disabled --max-running-requests 128 \
  --speculative-algorithm DSPARK --speculative-dspark-block-size 5 \
  --enable-encoder-swa-bounded-replay
python3 hit_repro.py 65536 16     # shared 64K prefix + 1,024 new tokens, 16 requests at once
```

<details><summary><code>hit_repro.py</code> (stdlib only)</summary>

```python
# usage: python3 hit_repro.py PREFIX_TOKENS CONCURRENCY   (server at $URL, default :30000)
import json, os, random, statistics, sys, time, urllib.request
from concurrent.futures import ThreadPoolExecutor

URL = os.environ.get("URL", "http://127.0.0.1:30000") + "/generate"
PREFIX, CONC = int(sys.argv[1]), int(sys.argv[2])
prefix = [random.Random(PREFIX).randrange(1000, 120000) for _ in range(PREFIX)]


def ttft(new_tokens):
    body = {"input_ids": prefix + new_tokens, "stream": True,
            "sampling_params": {"temperature": 0, "max_new_tokens": 8, "ignore_eos": True}}
    req = urllib.request.Request(URL, json.dumps(body).encode(), {"Content-Type": "application/json"})
    t0 = time.perf_counter()
    with urllib.request.urlopen(req) as r:
        while not r.readline().startswith(b"data:"):
            pass
        first = time.perf_counter() - t0
        r.read()
    return first


def wave():  # CONC requests at once, each the shared prefix + 1,024 new tokens
    news = [[random.randrange(1000, 120000) for _ in range(1024)] for _ in range(CONC)]
    with ThreadPoolExecutor(CONC) as ex:
        return list(ex.map(ttft, news))


ttft([])  # put the prefix in the cache
for _ in range(2):
    wave()
times = [t for _ in range(5) for t in wave()]
print(f"prefix {PREFIX} + 1024 new, {CONC} at once: TTFT p50 {1e3 * statistics.median(times):.0f} ms, "
      f"max {1e3 * max(times):.0f} ms over {len(times)} requests")
```

## Modifications

- Fold the replay into the extend forward (CUDA `DeepseekV4AttnBackend`): each hit's extend starts at `max(0, prefix − 128)`; replayed tokens reuse their cached KV slots, are window-floored at the replay start as before, and skip the low-ratio compressors (their compressed KV is already cached).
- Backends without the fold (gfx950) replay all hits of a step in one batched forward instead of one per request.
- Hidden states, logits and the KV location plan handed to the speculative draft cover only the scheduled rows.
- Works with `--enable-decoder-swa-bounded-replay` (the decoder tail keeps its own window floor and its hidden rows are mapped back) and with MLP-sync configurations (the forward's token counts include the replay rows).
- Unit tests: `test/registered/unit/model_executor/test_encoder_swa_replay.py`.

## Accuracy Tests

GSM8K, first 200 test questions, 5-shot, greedy, 128 in flight; cold pass, then the same prompts as full prefix hits (200/200 served from cache). Current main, same node:

| GSM8K-200 cold / hit | main, flag off | main, flag on | this PR, flag on |
|---|---|---|---|
| encoder replay | 197 / 196 | 194 / 195 | 196 / 198 |
| encoder + decoder replay, DSpark | — | — | 197 / 195 |

On top of #42715 + #42921: GSM8K 1,319 hit 0.9719 vs 0.9727 (± 0.0045) against the replay forward; needle 40/40 at 32K and 64K; first-token KL within run-to-run noise.

## Speed Tests and Profiling

Current main, one node, `hit_repro.py` for the hit rows:

| | main, flag off | main, flag on | **this PR, flag on** |
|---|---|---|---|
| 64K hit TTFT p50, 1 request | 250 ms | 511 ms | **274 ms** |
| 64K hit TTFT p50, 16 at once | 582 ms | 4,608 ms | **983 ms** |
| 7K hit TTFT p50, 16 at once | 561 ms | 4,530 ms | **878 ms** |
| decode step p50, 32 requests | 15.3 ms | 24.0 ms | 24.1 ms |

The remaining flag cost (decode step, cold prefill) comes from the request-window copies on main, which #42715 + #42921 address; with them underneath, 64K × 16 hits go from 3,730 ms to 850 ms (flag off 641 ms). A hit also carries 128 extra tokens, so 7 instead of 8 fit an 8,192-token chunk.
