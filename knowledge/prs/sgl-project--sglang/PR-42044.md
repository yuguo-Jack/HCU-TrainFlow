## Validation

### CP + MTP accuracy after review fixes (2026-10-08 UTC)

Validated on `glm53-dev-v2`, **4 × NVIDIA B300**, with the launch arguments from `TestGLM53FlashB200ContextParallel` in `test/registered/cp/test_glm53_flash_cp.py` (local model snapshot/host/port substituted). DSA interleave CP4, KDA/MoE/dense TP4, EP1, native EAGLE MTP **5 steps / top-k 1 / 6 draft tokens**, multimodal enabled, no LayerSplit.

| Check | Result |
| --- | --- |
| AIME26, all 30 questions × 16 repeats | **94.17% mean pass@1 (452 / 480)** |
| AIME26 majority@16 / pass@16 | 100% / 100% |
| AIME26 length-truncated / request errors | **0 / 0** |
| Registered GSM8K, 500 examples / 20 shots | **93.8% (469 / 500)**; passes ≥93% |
| GSM8K average speculative acceptance length | **4.1221**; passes >4.0 |
| Registered red/blue image-input checks | Passed before AIME26 and after GSM8K |

AIME26 used **sgl-eval 0.1.2**, reasoning enabled (`--thinking --chat-template-kwarg enable_thinking=true`), **temperature=1, top_p=1, max_tokens=300000**, and client concurrency 64. All 480 responses ended with `stop` and had nonempty reasoning. Seven unparsed/missing final answers remain in the denominator. One complete run, with no excluded samples or cherry-picked retries. The server resolved max-running-requests=48 and chunked-prefill-size=16384. GSM8K acceptance was recorded after its cache/metrics reset, not taken from the AIME26 workload.

Model snapshot: `eb9eb208eb0d988989d07a6a12d0fdeb5f52574a`. Tested runtime source: `0fcf9d3e4a`; head `79f7c61075` adds only a main merge of CI orchestration changes, with identical Python/model/test code. SHA-256 verification covered all 4,259 tracked Python files. Isolated runtime: Torch 2.14.1 / CUDA 13.0, sglang-kernel 0.4.9, FlashInfer 0.7.0.post1, Transformers 5.17.0.

The historical CP-only result below (455/480) is not a paired same-revision/runtime baseline; the three-answer difference does not by itself establish an MTP regression. These are **B300 devbox results, not B200 CI results**. Raw responses, commands, runtime metadata, and independently recomputed audits are retained locally. The validation server has been stopped and all four GPUs released.

### CP vs TP P50 TTFT (2026-10-07)

Both arms use native EAGLE/MTP **5 steps / top-k 1 / 6 draft tokens**, TP4, MoE/dense TP4, EP1, TRT-LLM DSA, FP8 KV, and multimodal serving enabled (no `--language-only`). CP adds only `--enable-prefill-cp --cp-strategy interleave --attn-cp-size 4`: DSA runs CP4 while KDA and MoE remain TP4. Both use `--chunked-prefill-size 16384 --max-prefill-tokens 16384 --max-running-requests 128 --random-seed 42`, at historical revision `ab2ba1e197` with Torch 2.13.0+cu130, sglang-kernel 0.4.8, and FlashInfer 0.6.18. This TTFT table has not been rerun after the review fixes.

Client workload: `bench_one_batch_server.py --model-path None --base-url http://127.0.0.1:32101 --batch-size <BS> --input-len 16384 --output-len 1024 --cache-hit-rate 0 --dataset-name random-ids --show-report`, with seed 42 and temperature 0.

Each arm/BS has the client's default 1024/16 warmup plus a separate full-shape warmup, followed by **one measured, unprofiled batch**. TTFT is measured client-side from the common batched POST start to each request's first token; the table reports the **median across requests within that batch**, not a median across repeated runs. Reduction is `100 × (1 − CP TTFT / TP TTFT)`.

| Batch size | TP4 + MTP P50 TTFT (ms) | CP4 + MTP P50 TTFT (ms) | CP TTFT reduction |
| ---: | ---: | ---: | ---: |
| 1 | 382.84 | 349.80 | 8.63% |
| 2 | 680.92 | 666.42 | 2.13% |
| 4 | 1166.12 | 1126.60 | 3.39% |
| 8 | 1878.05 | 1777.96 | 5.33% |
| 16 | 3314.96 | 3050.62 | 7.97% |
| 32 | 6171.95 | 5606.01 | 9.17% |
| 64 | 11861.45 | 10733.38 | 9.51% |
| 128 | 23302.45 | 21698.23 | 6.88% |

CP lowered P50 TTFT by **2.13%–9.51%** in this sweep. These are single-run observations on B300, not confidence intervals or B200 CI results. An independent raw-record audit verified matching prompt hashes between TP and CP, all **510 measured requests** producing exactly 1024 output tokens, cache-hit rate 0, and the recomputed P50 values. Raw requests, launch/client commands, environment records, and the audit are retained locally.
