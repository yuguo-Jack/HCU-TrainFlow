# feat(benchmark): add accuracy evaluation to benchmark.serving (#1096)

[Upstream PR](https://github.com/sgl-project/sglang/pull/36064) · state: open · merged: False

## Original PR description

## Summary

Add accuracy evaluation to `sglang.benchmark.serving` for Ascend/sglang #1096.

- New flags: `--eval-accuracy`, `--accuracy-only`, `--accuracy-output`, `--hf-endpoint`, etc.
- New module `python/sglang/benchmark/accuracy/` bridging to `sglang.test.run_eval`
- Datasets: **GSM8K**, **GPQA-Diamond**, **AIME24/25/26**, **MMMU**
- New `simple_eval_aime.py` for AIME 2024/2026 HuggingFace loaders
- Rebased onto latest `sgl-project/sglang` `main`; implementation lives in `benchmark/serving.py` (`bench_serving` remains a compatibility shim)

## Usage

```bash
# Text accuracy (server must be running)
python -m sglang.benchmark.serving \
  --backend sglang-oai --base-url http://127.0.0.1:30000 \
  --model Qwen/Qwen2.5-7B-Instruct \
  --dataset-name gsm8k --eval-accuracy --accuracy-only \
  --num-prompts 50 --hf-endpoint https://hf-mirror.com \
  --accuracy-output results/gsm8k_acc.json

# MMMU (VL model)
python -m sglang.benchmark.serving \
  --backend sglang-oai --base-url http://127.0.0.1:30000 \
  --model Qwen/Qwen2.5-VL-7B-Instruct \
  --dataset-name mmmu --eval-accuracy --accuracy-only \
  --num-prompts 10 --accuracy-output results/mmmu_acc.json
```

(`python -m sglang.bench_serving` still works via the shim.)
