# [Bugfix] Preserve Anthropic xhigh reasoning effort

[Upstream PR](https://github.com/sgl-project/sglang/pull/36769) · state: closed · merged: False

## Original PR description

## Summary

`output_config.effort=xhigh` was rewritten to `max` before rendering the model's chat template, breaking templates that accept `xhigh` but reject `max`. Preserve the requested tier and return HTTP 400 `invalid_request_error` with the template's validation message when conversion raises `ValueError`, for both streaming and non-streaming requests.

Add a CPU HTTP regression that exercises the real Anthropic handler, OpenAI conversion and response paths, Hugging Face tokenizer, and Jinja rendering. Only token generation is stubbed. With a template accepting `xhigh`, `medium`, and `low`, it verifies:

- omitted effort, `low`, `medium`, and `xhigh` return complete successful responses in both modes;
- `high` and `max` return 400 with the accepted values before generation begins;
- successful streams contain output text, terminate normally, and contain no error event.

Fixes #36741.
