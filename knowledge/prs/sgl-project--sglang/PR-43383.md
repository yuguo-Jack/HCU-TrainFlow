# [AMD]Qwen add Sparse attention to capturing hip graphs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43383) · state: closed · merged: True

## Original PR description

Enable HIP draft-extend graph capture for QwenSparseAttnBackend by adding it to the supported backends. This lets Qwen sparse-attention models replay the draft-extend graph, reducing execution overhead during speculative decoding.

  On MI355X with TP=1, concurrency=8, and 32k input/output lengths, this improved p90 end-to-end interactivity by 13.0% and output throughput by 12.6%. Validated with two trials per version using simulated acceptance length 2.32; all
  32 requests completed successfully.

| Metric | Baseline | With QSA in graph | Improvement |
|----------|---------------:|------------:|------------:|
| P90 end-to-end interactivity | 94.87 tok/s | 107.22 tok/s | +13.02% |
| P90 decode-only interactivity | 95.69 tok/s | 108.15 tok/s | +13.03% |
| Output throughput | 763.10 tok/s | 859.58 tok/s | +12.64% |
| Input + output throughput | 1,526.20 tok/s | 1,719.16 tok/s | +12.64% |
