# [Docs] Add Qwen3.5 B300 NVFP4 agentic recipes to the selector / [Docs] 在 Qwen3.5 选择器中添加 B300 NVFP4 Agentic 配方

[Upstream PR](https://github.com/sgl-project/sglang/pull/43224) · state: open · merged: False

## Original PR description

The Qwen3.5 selector has no entry for the B300 NVFP4 agentic deployment, so its HiCache, MTP and scheduler settings are not documented. Add **Agentic aggregated + router (B300 NVFP4)** to the existing selector, backed by the five serving variants qualified in [InferenceX #2978](https://github.com/SemiAnalysisAI/InferenceX/pull/2978).

The selector generates a copyable worker command (`sglang serve`) and router command (`sglang_router.launch_router`) for TP2, TP2/EP2 and TP4 variants with MTP depths 3, 5, 6 and 7 and HiCache. A new section 3.3 documents the pinned container, the `nvidia/Qwen3.5-397B-A17B-NVFP4` checkpoint (not NVFP4-V2), host-DRAM needs, and the excluded harness settings. The InferenceX lane is labelled `dynamo-sglang`, but its executed commands were plain `sglang.launch_server` behind `sglang_router`, so the page does not present it as Dynamo. Small `--max-running-requests` limits (1 to 8; 224 for TP2/EP2), FP8 KV cache, `--enable-linear-replayssm-spec` drift, the long watchdog and `--allow-auto-truncate` are called out as tradeoffs.

The rendered Mintlify selector was exercised across all five variants and both roles, including copy, on an earlier iteration of this branch that also carried the GB200 selector; after rebasing onto `main` only the Mintlify build validation, broken-link check, cookbook config check and codespell were re-run. [Run 34548026742, attempt 1](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/34548026742), at InferenceX commit `6b7dcd07ab0c8c0805ac7fbec2f2ded38d450c20`, executed five agentic benchmarks and four GSM8K evals; strict exact match was 0.9735 to 0.9788 (n=1319). The TP4/c4 variant had no eval. That is existing harness qualification. The generated standalone Docker, worker and router commands have **not** been independently executed on B300.
