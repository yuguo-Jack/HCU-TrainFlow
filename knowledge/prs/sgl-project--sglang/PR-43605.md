## Motivation

Stage declarations and residual capability checks currently share a module with connection resolution and layer stack assembly. Put declarations in their own module so model authors can find the declaration API independently of binding.

## Changes

Move the declaration class, capability checks and declaration factories unchanged into declarations.py. Export the same function objects through the package and include the new module in the test patch registry.
