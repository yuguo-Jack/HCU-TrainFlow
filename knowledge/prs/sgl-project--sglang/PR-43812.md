# [DSV4.1] Support decoder SWA bounded replay with CUDA DP attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/43812) · state: open · merged: False

## Original PR description

## Changes

Enable decoder SWA bounded replay with CUDA DP attention (attention TP=1) for MegaMoE and TP MoE. Update late-layer row counts, token IDs and padding masks, then restore the full batch layout for logits/DSpark. Keep target peers eager during coordinated prefill so their collectives agree.

TRT-LLM and prefill CUDA graphs remain unsupported with bounded replay.

## Accuracy

DeepSeek-V4.1-Flash, 2×GB300, TP2/DP2/EP2, MegaMoE + FlashMLA, native DSpark acceptance. GSM8K: 1,314 scored questions, five-shot chat, thinking disabled, temperature 0, concurrency 64, max output 4,096 tokens.

| Configuration | Correct | Accuracy | Request errors |
|---|---:|---:|---:|
| Replay disabled | 1,278 / 1,314 | 97.26% | 0 |
| Decoder replay enabled | 1,281 / 1,314 | 97.49% | 0 |

Neither run reached the output limit.
