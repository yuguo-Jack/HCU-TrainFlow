# [diffusion] comfyui: add a workflow validator and e2e harness for the shipped workflows

## Motivation

The ComfyUI plugin tests exercise adapters with stubs. Bugs such as the missing `VideoInput.as_trimmed` and the `get_model_info` 404 only showed up when a real ComfyUI ran a real workflow. This adds the pieces to run the shipped workflows against a real ComfyUI and compare the result with native ComfyUI.

## Modifications

All new files; no existing plugin source is edited.

- `ci/workflow_check.py`: checks every `workflows/*.json` against a ComfyUI checkout's real node definitions (plus the plugin's own nodes). It reports unknown classes, missing and unknown inputs, dangling links, wrong output slots, link type mismatches and invalid static combo values.
- `ci/native_convert.py`: rewrites an integrated-mode workflow into its native-ComfyUI twin (`SGLDUNETLoader` to `UNETLoader`, `SGLDOptions` removed, `SGLDLoraLoader` to `LoraLoaderModelOnly`), and classifies a workflow as integrated, server or native.
- `ci/compare.py`: PSNR and correlation between two outputs, for images and video (first and last frame).
- `ci/run_workflows.py`: starts ComfyUI headless, posts each workflow to `/prompt`, runs the native twin with the same seed and compares. Workflows whose model files are missing are skipped and listed.
- `.github/workflows/comfyui-workflow-e2e.yml`: manual dispatch only. A CPU job runs the static check and the tests; a GPU job runs the end-to-end comparison.
- `test/unit/test_comfyui_workflow_ci.py`: 42 tests, including one that proves the validator catches a broken workflow.

The static check already finds two shipped workflows that cannot run. They are not changed here:
- `qwen_image_sgld.json`: the `SaveImage` node has no `images` input.
- `sgld_text2img.json`: uses `SGLDiffusionSetLora`, which does not exist (the registered name is `SGLDiffusionServerSetLora`).

## Accuracy Tests

Not applicable, no model code changes.

Tests (CPU): `pytest test_comfyui_workflow_ci.py` gives 28 passed and 14 skipped without a ComfyUI checkout, and 39 passed with 3 intentional strict xfails when `COMFYUI_DIR` points at one. The 3 xfails mark the known defects above, so fixing a workflow turns its entry into a failure until it is removed. The repo's lint hooks (isort, ruff, ruff format, codespell, yaml, workflow job names) pass.

Not run, and called out in the workflow file header: `run_workflows.py` past its skip logic, the GitHub workflow on a real GPU runner, server-mode runs, and the comparison thresholds (PSNR 25 dB, correlation 0.90), which are uncalibrated placeholders.
