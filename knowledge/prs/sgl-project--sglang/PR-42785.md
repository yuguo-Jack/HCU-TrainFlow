# fix(hicache): handle tensor device buffers

[Upstream PR](https://github.com/sgl-project/sglang/pull/42785) · state: open · merged: False

## Original PR description

## Motivation

Fixes #42672.

NPU HiCache without FIA exposes `k_buffer` and `v_buffer` as multi-layer tensors. `MHATokenToKVPoolHost` used `getattr(..., None) or ()` before iterating them, which evaluates the tensor as a boolean and raises `RuntimeError: Boolean value of Tensor with more than one value is ambiguous` during host-pool construction.

## Modifications

- Add a small iterator that handles missing buffers explicitly without boolean evaluation.
- Preserve existing list/tuple behavior and let multi-layer tensors yield zero-copy per-layer views.
- Add a CPU regression test that constructs an MHA host pool from stacked multi-layer tensor buffers.

## Accuracy Tests

Not applicable. This changes buffer discovery during HiCache initialization and does not change model computation or outputs.

## Speed Tests and Profiling

Not applicable. The change runs only during host-pool construction.
