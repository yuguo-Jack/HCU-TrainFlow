# :construction: [WIP][llm][npu][quant] Add W4A8 MXFP quantization support for Qwen3.5 MoE on Ascend NPU

[Upstream PR](https://github.com/sgl-project/sglang/pull/32601) · state: closed · merged: False

## Original PR description

## Summary

Extend `--quantization mxfp_w4a8` to Ascend FusedMoE experts. `NPUW4A8MXFP4OnlineMoEMethod` retains the unquantized weight-loader lifecycle and attaches `NPUW4A8MXFP4MoEMethod` for W13/W2. BF16/FP16 expert weights are quantized after loading; ModelSlim packed checkpoints reuse the same execution kernels without requantization.

## Dependencies and review scope

Updated on 2026-10-10 with ordinary merges; base remains `main`. Branch head: `ded4671577`. Includes official main `c55790d38b`.

Merge order: sgl-project/sgl-kernel-npu#638 (Gemma API/wheel) → #32745 → **#32601** → #32602. This branch contains #32745 at `cf48b477db`. #734's provider staging is already inside kernel #638. #32266 stays closed and is no longer a pending prerequisite. #36426 is a separate validation dependency, not a newly stacked PR.

Review the W4A8 increment against [the refreshed #32745 branch](https://github.com/TallMessiWu/sglang/compare/junlin_qwen3.5_dense_w8a8...junlin_qwen3.5_moe_w4a8). Existing ModelSlim projection mapping and vision quant-config forwarding carried by this branch are retained.

## Execution contracts

- Online MXFP4 scales arrive as `[E,N,K/64,2]`; flatten those pairs before the shared main helper, which produces `[E,K/64,N,2]`. A regression case compares online and offline layouts.
- Keep main's shared weight/scale preparation, fused GMM1 path, and unfused fallback when SwiGLU clamp is required.
- Keep DeepEP normal dispatch in BF16 and low-latency dispatch in MXFP8. These are implementation paths; EP/multi-node support is not certified by CPU checks.
- Dense A8W4 bias uses BF16 `[1,N]`. Online Dense layers with non-32-aligned input sizes fall back to BF16.

## Current validation

Applicable pre-commit hooks passed. Isolated execution of the actual Python methods passed online/offline weight-layout and dispatch checks, fusion/clamp gate checks, and bias checks. Shared MXFP8 scale probes passed for K=32,64,96,4304; 8 isolated Gemma tests passed.

These are CPU/static checks, not 910/950 operator, model-load, warmup, accuracy, or performance validation. Full SRT test collection was unavailable in this environment because its serving dependencies are not installed. Target hardware validation remains required.

Remains Draft. GitHub reports `viewerCanReopen=false` for the author account; the updated fork branch is pushed, but reopening the closed PR requires repository permissions.
