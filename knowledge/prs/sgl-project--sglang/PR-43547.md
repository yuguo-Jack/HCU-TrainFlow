# [AMD][CI] Cap pyarrow below 26 for lmms-eval

[Upstream PR](https://github.com/sgl-project/sglang/pull/43547) · state: closed · merged: True

## Original PR description

## Problem

PyArrow 26 requires NumPy 2 at import time, while `lmms-eval` v0.4.1 pins `numpy==1.26.4`. The AMD test dependency install can therefore leave PyArrow 26 installed after downgrading NumPy, causing every path that imports `datasets` to fail.

## Change

Install `pyarrow<26` in the same pip transaction as `lmms-eval`. This resolves PyArrow 25.0.1, which supports NumPy 1.26.4, until LMMS allows NumPy 2.

This is a focused cherry-pick of the original fix in commit [`79423c5591`](https://github.com/sgl-project/sglang/commit/79423c5591eeabc944ea4f7c34a81af9ef14298a) from #43021. The original author is preserved in the commit metadata.
