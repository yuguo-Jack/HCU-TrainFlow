## Motivation

Several docs and comments point at source files that were moved or deleted, so readers following them land on a 404 or a missing path.

## Modifications

- `separate_reasoning.mdx`: `srt/reasoning_parser.py` is now `srt/parser/reasoning_parser.py`.
- `sampling_params.mdx`: `load_image` lives in `srt/utils/common.py` (`srt/utils.py` became a package).
- `development_jit_kernel_guide.mdx` and the `kvcacheio/hicache.cuh` comment: `kernels/jit/utils/compile.py` became the `compile/` package (`load_jit` is in `compile/loader.py`).
- `mem_cache/unified_cache/components/README.md`: the file-layout table used paths relative to the wrong directory; they now resolve from the README's location.
- `examples/runtime/README.md`: drop `openai_batch_chat.py`, `openai_batch_complete.py` (removed in #7400) and `offline_batch_inference_torchrun.py` (removed in #7326).
