# [Anthropic] Add opt-in keepalives for idle message streams

[Upstream PR](https://github.com/sgl-project/sglang/pull/43728) · state: open · merged: False

## Original PR description

## Motivation

Streaming `/v1/messages` sends its first frame only after model output arrives. A long prefill or queue wait can therefore leave the connection silent until an intermediary's idle timeout closes it.

## Modifications

Add opt-in `SGLANG_SSE_KEEPALIVE_S` (seconds, default `0`, disabled). For example, `20` emits an SSE comment after each 20 seconds without a frame. Comments leave the Anthropic event sequence and payloads unchanged.

The wrapper keeps one pending read alive across timeouts, cancels it on disconnect, and closes the source generator. The existing response abort task remains attached. Document the option and the requirement that proxies forward streaming data without buffering.

## Accuracy Tests

CPU tests: **72 passed**, comprising 63 existing Anthropic tests and nine new lifecycle/integration tests. New coverage includes repeated idle frames without restarting the read, frame order, disabled behavior, exhaustion, error propagation, closure after a frame, cancellation during a pending read, handler wiring, and an ASGI disconnect through `StreamingResponse`.

```bash
PYTHONPATH=python python -m pytest -q test/registered/unit/entrypoints/anthropic
```

Tests use synthetic streams and do not load a model. Sampling and model kernels are unchanged.

## Speed Tests and Profiling

No inference throughput claim. This change addresses idle connection liveness; execution timeouts remain unchanged. The option is disabled by default.
