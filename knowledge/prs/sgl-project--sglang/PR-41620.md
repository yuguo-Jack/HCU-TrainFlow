# ci: diffusion-only option for the runner utilization report

[Upstream PR](https://github.com/sgl-project/sglang/pull/41620) · state: closed · merged: True

## Original PR description

Adds a `diffusion_only` checkbox to the Runner Utilization Report's **Run workflow** form. When checked, the report counts only multimodal/diffusion CI jobs, so each pool's utilization reads as the **share of that pool consumed by diffusion CI** — useful for attributing compute cost to the multimodal suite.

Implemented as a generic `--job-name-filter <regex>` flag on the report script (the checkbox passes `multimodal|diffusion`); the report title is annotated when a filter is active. Scheduled daily runs are unchanged, and the dashboard's log parser is unaffected (table format and title prefix unchanged).

Verified: unit suite passes; live smoke run with the flag kept 20/208 jobs over a 12-minute window and produced the filtered table.
