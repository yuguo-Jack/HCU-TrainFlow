# [MemCache] Serve disabled pure-SWA models with `PureSWARadixCache`

[Upstream PR](https://github.com/sgl-project/sglang/pull/43198) · state: closed · merged: True

## Original PR description

Stacks on #43197

- Disabled pure-SWA models build `PureSWARadixCache(disable=True)` instead of `PureSWAChunkCache`, whatever the chunked prefill setting, and no longer fall through to the lmcache / external-linker arms (a disabled cache publishes nothing)
- Host-pool retraction still routes to `UnifiedRadixCache`, which rejects pure-SWA
- Tests: disabled `PureSWARadixCache` release semantics and window threshold; registry routes
- Validated with `test_unlimited_ocr_server.py` (chunked prefill 256 and -1, overlap on and off)
