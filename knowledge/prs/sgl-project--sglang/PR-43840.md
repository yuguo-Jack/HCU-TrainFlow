# [Spec][Bugfix] Fix EAGLE3 draft lm_head when a reduced vocab is tied

[Upstream PR](https://github.com/sgl-project/sglang/pull/43840) · state: open · merged: False

## Original PR description

## Motivation

An EAGLE3 draft that declares **both** `tie_word_embeddings: true` and a reduced `draft_vocab_size` loads the wrong output head, silently.

`AngelSlim/Qwen3-1.7B_eagle3` (target `Qwen/Qwen3-1.7B`) declares `draft_vocab_size: 32000` against `vocab_size: 151936` and ships its own 32000-row `lm_head.weight`. But `llama_eagle3.py` and `kimi_k25_eagle3.py` both checked `tie_word_embeddings` **before** `draft_vocab_size`, so the tied branch won and `draft_vocab_size` was never consulted. `lm_head` became the 151936-row target embedding while the `LogitsProcessor` was still built for 32000, so it silently truncated the logits (`logits[:, :32000]`) and the trained head was dropped by name-matching (with `lm_head is embed_tokens`, `named_parameters()` dedupes the alias).

Result: `spec_accept_rate = 0.0`, `accept_length ≈ 1.0`. No error, no warning — it reads as "the draft model is bad".

Related but distinct: #42094 fixes the same class of bug in `qwen3_5_mtp.py`, at runtime. This one is at load time, needs no `--speculative-token-map`, and fails silently rather than crashing.

## Modifications

Consult `draft_vocab_size` **first**; the tied embedding is only a fallback:

```python
draft_vocab_size = getattr(config, "draft_vocab_size", None)
if draft_vocab_size is not None:
    self.lm_head = ParallelLMHead(draft_vocab_size, ...)
elif config.tie_word_embeddings:
    self.lm_head = self.model.embed_tokens
else:
    self.load_lm_head_from_target = True
```

Only the `draft_vocab_size` set + `tie=True` case changes behavior; the other three rows are unchanged. `getattr` rather than `config.draft_vocab_size` because the latter raises `AttributeError` when the key is absent, and it is now read first.

## Accuracy Tests

H100, `Qwen/Qwen3-1.7B` + `AngelSlim/Qwen3-1.7B_eagle3`, EAGLE3, K=3, greedy:

| | `spec_accept_rate` | drafts accepted |
|---|---|---|
| before | 0.0000 | 0 / 1512 (8 prompts) |
| after | 0.1969 | 189 / 960 |

Before, **zero** drafts were accepted on any prompt; after, every prompt accepts (0.095–0.378).

Added `test/registered/unit/spec/test_eagle3_reduced_vocab_lm_head.py` — a CPU test over all four cases, non-vacuous (3 of 4 fail against the pre-fix code).
