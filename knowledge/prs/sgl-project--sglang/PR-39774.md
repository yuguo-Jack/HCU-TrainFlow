# test(npu): add e2e test for --return-output-ids parameter

[Upstream PR](https://github.com/sgl-project/sglang/pull/39774) · state: open · merged: False

## Original PR description

## Summary

Add an NPU end-to-end test for the `--return-output-ids` server parameter,
verifying that each `/v1/chat/completions` response returns the sampled
output token ids via the response-level `sglext` extension.

## Changes

- Add `test/registered/npu/basic_function/parameter/test_npu_return_output_ids.py`.
- Launch a single-NPU server with:
  `--attention-backend ascend --disable-cuda-graph --return-output-ids`
  on `LLAMA-3.2-1B-Instruct`.
- Send one chat completion request and assert:
  - `data["sglext"]["output_ids"]` exists;
  - for `n == 1` it is a non-empty nested list of `int`;
  - decoding the ids round-trips back to the generated content.

## Test

- Registered via `register_npu_ci(est_time=400, suite="full-1-npu-a3", nightly=True)`.
- Ran on NPU: passed.
