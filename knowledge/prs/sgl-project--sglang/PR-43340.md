# [NPU] Bump SGLANG_KERNEL_NPU_TAG to 2026.9.0.post9

[Upstream PR](https://github.com/sgl-project/sglang/pull/43340) · state: closed · merged: True

## Original PR description

## Motivation

The pinned `SGLANG_KERNEL_NPU_TAG` still points at `2026.9.0.post6`, so NPU CI and
release images build against an outdated SGLang NPU kernel wheel. This bumps the tag
to the latest `2026.9.0.post9` release.

## Modifications

- Bump the default `SGLANG_KERNEL_NPU_TAG` from `2026.9.0.post6` to `2026.9.0.post9`
  in `scripts/ci/npu/npu_ci_install_dependency.sh` and `docker/npu.Dockerfile`.
- Update the corresponding `build-args` in the `release-docker-npu` and
  `release-docker-npu-nightly` workflows so the released images use the same tag.

## Accuracy Tests

Not applicable — version pin bump only, no model or kernel code changes.
