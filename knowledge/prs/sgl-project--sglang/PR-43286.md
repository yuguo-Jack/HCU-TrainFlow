# [KV canary] Expect sweep counters on the target runner only

[Upstream PR](https://github.com/sgl-project/sglang/pull/43286) · state: closed · merged: True

## Original PR description

## Motivation

With the KV canary sweep on (`--kv-canary raise --kv-canary-sweep-interval N`, which is also the scripted-runtime harness default), any EAGLE / EAGLE3 server dies about 100 decode steps in:

```
RuntimeError: kv-canary: kernel_run_counter did not increase since previous check for tags=[SWEEP_K_FULL] at step=101; canary path is not executing
```

The error is raised from the draft runner's canary (`_draft_extend_for_decode`), not the target's. The sweep walks the radix cache, and the scheduler attaches the radix cache only to the target runner's canary manager, so `SweepOrchestrator.maybe_run_sweep` returns before launching anything on the draft runner. The health checker still expects the `SWEEP_*` counters to advance whenever `sweep_interval > 0`, so the draft side trips it. No KV is corrupted; the target sweep keeps running and reporting normally.

The draft runner shares the target's req_to_token pool and slot allocator, but nothing attaches a radix cache to it, so its sweep never runs by design.

## Modifications

- `KernelRunCounterHealthChecker` takes `is_draft_runner` (the canary manager's `is_eagle_draft_decode`, set from `model_runner.is_draft_worker`) and drops the `SWEEP_*` tags from its expected set on a draft runner, as it already does when `sweep_interval` is 0.
- The exemption is keyed on the runner's role, not on whether a radix cache is attached: if the target's attach ever goes missing, its sweep stops launching and the health check still fails at step 101.
- Unit test: with the sweep interval set and no sweep counter advancing, a draft runner passes the watchdog and a target runner raises on `SWEEP_K_FULL`.

## Checks

- The new unit test fails on main (the draft runner raises).
- Reproduced on main with Llama-3.1-8B-Instruct + EAGLE3 under the scripted-runtime harness defaults (`kv_canary=raise`, sweep interval 100), with and without `enable_mixed_chunk`: both raise at step 101 from the draft runner's canary.
- kv-canary unit and e2e tests on CI: see the `/rerun-test` comment below.
