## Motivation

Issue #39700. Developed based on #40177. Currently megamoe cannot be enabled on decode node on dsv4.1.

## Modifications

1. In _run_mega_routed, use vision_topk to apply ViT bias to image tokens, so that megamoe will not be restricted for language-only deployment.
