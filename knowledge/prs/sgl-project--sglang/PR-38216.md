## Motivation

@humansand

- Extend the existing FP4 all-gather path to `--moe-a2a-backend none` with `flashinfer_trtllm`, `flashinfer_trtllm_routed`, and `flashinfer_cutedsl`, using `SGLANG_MOE_NVFP4_DISPATCH=1`.
- Quantize DP-local activations before communication and reuse those packed activations in the expert GEMM. Cover static per-tensor FP32 activation scales plus serialized and online per-token FP32 activation scales.
- Reuse the contracts and tests from #22918 (serialized per-token TRTLLM), #26083 (`nvfp4_online`), #28220 (CuTe DSL quantizer), #28354 (CuTe DSL W4A4/MTP/reload), #33115 (static `modelopt_fp4` versus per-token `nvfp4_online`), and #36985 (re-enabled per-token tests). Preserve #35120's W4A16 behavior.

**Draft status:** This PR remains a draft. The measured global-batch 16/64/128 matrix shows no general decode speedup: routed TRTLLM per-token mean latency falls 3.35–5.41%, while static raw TRTLLM rises 0.35–8.73%. Static raw batches 512/1024 show small mean reductions of 1.78%/0.41% with mixed execution-order results. These benchmarks and earlier E2Es retain their recorded source revisions. The focused runner/model and configuration tests and all 33 four-GPU transport configurations passed on `5e368b1`; GPU tests and benchmarks have not been repeated after the rebase and subsequent cleanups. No statistical significance is claimed.

## Modifications

- **Eligibility:** the three new runners require DP attention with TP = EP = attention-DP > 1 and `modelopt_fp4` or `nvfp4_online`. A single explicit validation after runner/A2A resolution rejects Kimi-K3 and Inkling custom layouts when this opt-in would apply. Existing CUTLASS automatic enablement remains; `--disable-flashinfer-cutlass-moe-fp4-allgather` still disables the optimization.
- **Scale contract:** `modelopt_fp4` retains checkpoint per-tensor FP32 scales unless `SGLANG_FLASHINFER_NVFP4_PER_TOKEN_ACTIVATION=1`; `nvfp4_online` remains per-token. Communicate packed E2M1 activations plus linear E4M3 block scales and, for per-token activation quantization, the FP32 row scale. Reuse FlashInfer's canonical quantizer/global-scale helper and preserve scale storage across weight reloads.
- **Routing:** gather FP32 raw logits for non-routed TRTLLM, or top-k weights and IDs for routed runners, in global token order. TRTLLM routed then uses its existing packing helper. Empty ranks preserve the same routing format; BF16/FP16-source raw logits are cast to FP32. Standalone packed routing carriers are outside this path.
- **Combine:** reduce-scatter the expert output without a second post-expert all-reduce. Prepacked TRTLLM follows the native kernel's BF16 output contract. Allocate the combine buffer from the actual expert-output width and dtype, including latent MoE widths. Layers excluded from NVFP4 retain their input precision while using the same gather/combine geometry.
- **Nemotron/empty ranks:** keep target-model activations DP-local until FP4 dispatch, use local shared experts, and preserve Nemotron's latent MoE width (1024 in the tested fixture, versus model width 4096). Empty ranks still join dispatch/combine while bypassing local GEMMs; nonempty latent outputs retain the upstream fused projection/shared-add path. Globally empty runner inputs return empty outputs without invoking native MoE kernels.
- **Reuse:** CuTe DSL and TRTLLM consume the dispatched activation/scales directly without requantization. Keep CUTLASS's post-gather scale swizzle and existing FP8 prequantization metadata separate.
- **Tests:** opt the retained raw TRTLLM static/online, routed TRTLLM serialized per-token, CuTe DSL online/MTP, and reload tests into actual TP/DP/EP4 communication. Reuse runner and Nemotron model tests, and cover 33 real four-rank transport configurations: 27 runner/activation/size cases, three ignored-layer BF16 cases, and three latent-width cases. Preserve existing GSM8K thresholds, reload tolerances, W4A16 regressions, exact wire/scales/routing checks, and empty-rank behavior.
- **Boundaries:** W4A16 retains BF16 activations. Kimi-K3 and Inkling custom layouts require leaving this opt-in disabled; enabling an otherwise eligible configuration raises an explicit error. The existing speculative A2A context still disables FP4 all-gather for draft/MTP forwards; the Nemotron MTP/EAGLE test does not claim FP4 transport for the draft. This PR does not extend DeepEP or FlashInfer A2A transport, per-token CUTLASS, or custom/experimental TRTLLM layouts.

## Speed Tests and Profiling

- **Completed main matrix:** 24 process arms on `02498dcc1268d20bc415a0de64c72e8f28758c25`; all three runners and static/per-token activation modes, with off/on then on/off order. The earlier raw/static sanity pair on `d23cd8ca` remains excluded from these results.

- **Workload:** TP=EP=DP4; global batches 16/64/128; input length 1024; 64 timed decode steps; fixed attention, dense GEMM and KV-cache backends; full decode CUDA graphs. Upstream `one_batch` reports prefill separately from median decode latency.
- **Batch semantics:** `one_batch --batch-size` is per DP rank, so local batches 4/16/32 correspond to global 16/64/128. `--output-len 65` measures 64 decode steps after prefill. Every retained shape receives a same-shape warmup; raw rank-0 throughput is multiplied by four only when reporting aggregate throughput.
- **Evidence boundary:** activation payload is `H/2 + H/16` bytes per token, plus four bytes for the per-token scale when enabled; routing metadata and unquantized expert-output combine remain (BF16 for prepacked TRTLLM). Non-routed TRTLLM gathers FP32 router logits; routed paths gather top-k IDs/weights and pack in the existing runner when needed. This predicts lower activation traffic, not a 3.56x reduction of total communication or an end-to-end speedup. The env=0/1 ablation includes moving both quantization and routing relative to communication. No historical PR numbers or accuracy-test throughput are attributed to this patch.

**Observed main-matrix results:** decode latency reduction ranges from -8.73% to +5.41% (6 faster, 12 slower configurations); prefill latency reduction ranges from -14.07% to +34.73% (14 faster, 4 slower configurations). These are descriptive results from two AB/BA repetitions.

import os
from pathlib import Path

import numpy as np
import sglang.benchmark.one_batch as bench
from sglang.srt.runtime_context import get_parallel

assert (
    Path(bench.__file__)
    .resolve()
    .is_relative_to(Path(os.environ["FP4_BENCH_REPO"]).resolve())
), bench.__file__
_prepare_inputs = bench.prepare_synthetic_inputs_for_latency_test


def prepare_inputs(batch_size, input_len, custom_inputs=None):
    if not custom_inputs:
        rng = np.random.default_rng(
            np.random.SeedSequence(
                [
                    int(os.environ.get("FP4_BENCH_SEED", "42")),
                    get_parallel().attn_dp_rank,
                    batch_size,
                    input_len,
                ]
            )
        )
        custom_inputs = rng.integers(
            0, 10000, (batch_size, input_len), dtype=np.int32
        ).tolist()
    return _prepare_inputs(batch_size, input_len, custom_inputs)


# Spawned ranks import this entrypoint too, so each rank installs the same
# input-only shim. Model loading, CUDA graphs, warmup, and timing stay upstream.
bench.prepare_synthetic_inputs_for_latency_test = prepare_inputs


if __name__ == "__main__":
    bench.cli_main()

"""Same-source env=0/1 NVFP4 dispatch ablation using upstream one_batch."""

import argparse
import hashlib
import itertools
import json
import os
import signal
import subprocess
import sys
from pathlib import Path


def source_state(repo):
    head = subprocess.check_output(
        ["git", "rev-parse", "HEAD"], cwd=repo, text=True
    ).strip()
    patch = subprocess.check_output(
        ["git", "diff", "HEAD", "--", "python/sglang"], cwd=repo
    )
    return {"git_head": head, "runtime_diff_sha256": hashlib.sha256(patch).hexdigest()}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--repo", type=Path, required=True)
    parser.add_argument("--output", type=Path, required=True)
    parser.add_argument("--gpus", default="0,1,2,3")
    parser.add_argument("--cache-dir", type=Path)
    parser.add_argument(
        "--runners",
        nargs="+",
        default=["flashinfer_trtllm", "flashinfer_trtllm_routed", "flashinfer_cutedsl"],
    )
    parser.add_argument(
        "--modes",
        nargs="+",
        choices=["static", "per_token"],
        default=["static", "per_token"],
    )
    parser.add_argument("--global-batches", nargs="+", type=int, default=[16, 64, 128])
    parser.add_argument("--input-len", type=int, default=1024)
    parser.add_argument("--decode-steps", type=int, default=64)
    parser.add_argument("--repeats", type=int, default=1)
    parser.add_argument("--four-over-six", choices=["0", "1"], default="0")
    parser.add_argument("--timeout", type=int, default=1800)
    parser.add_argument("--dry-run", action="store_true")
    args = parser.parse_args()
    args.repo = args.repo.resolve()
    args.output = args.output.resolve()
    args.cache_dir = (args.cache_dir or args.output / "cache").resolve()
    assert len(args.gpus.split(",")) == 4
    assert all(b > 0 and b % 4 == 0 for b in args.global_batches)
    assert args.decode_steps > 0 and args.repeats > 0
    args.output.mkdir(parents=True, exist_ok=False)
    driver = Path(__file__).with_name("one_batch_deterministic.py").resolve()
    source = source_state(args.repo)
    source["driver_sha256"] = hashlib.sha256(driver.read_bytes()).hexdigest()
    manifest = {"source": source, "arguments": vars(args).copy(), "arms": []}
    manifest["arguments"] = {
        k: str(v) if isinstance(v, Path) else v
        for k, v in manifest["arguments"].items()
    }
    # Repeating each batch warms that exact shape before its retained sample.
    local_batches = list(
        itertools.chain.from_iterable((b // 4, b // 4) for b in args.global_batches)
    )
    measurements = []
    for runner, mode, repeat in itertools.product(
        args.runners, args.modes, range(args.repeats)

        for dispatch in (0, 1) if repeat % 2 == 0 else (1, 0):
            name = f"{runner}-{mode}-r{repeat}-dispatch{dispatch}"
            raw_path = args.output / f"{name}.jsonl"
            env_delta = {

                "PYTHONPATH": str(args.repo / "python"),
                "PYTHONUNBUFFERED": "1",
                "TOKENIZERS_PARALLELISM": "false",
                "FP4_BENCH_REPO": str(args.repo),
                "FP4_BENCH_SEED": "42",
                "SGLANG_MOE_NVFP4_DISPATCH": str(dispatch),
                "SGLANG_FLASHINFER_NVFP4_PER_TOKEN_ACTIVATION": str(
                    int(mode == "per_token")
                ),
                "SGLANG_FLASHINFER_CUTEDSL_NVFP4_W4A16": "0",
                "SGLANG_FLASHINFER_MOE_FUSED_FINALIZE": "1",
                "FLASHINFER_NVFP4_4OVER6": args.four_over_six,
                "SGLANG_CACHE_DIR": str(args.cache_dir),
                "FLASHINFER_WORKSPACE_BASE": str(args.cache_dir / "flashinfer"),
            }
            command = [
                sys.executable,
                str(driver),
                "--model-path",
                "nvidia/Qwen3-30B-A3B-NVFP4",
                "--revision",
                "2538ded2a4edb247b4d2b4a8ba24e44bd4c017c3",
                "--quantization",
                "modelopt_fp4",
                "--tp-size",
                "4",
                "--ep-size",
                "4",
                "--dp-size",
                "4",
                "--enable-dp-attention",
                "--moe-a2a-backend",
                "none",
                "--moe-runner-backend",
                runner,
                "--fp4-gemm-backend",
                "flashinfer_trtllm",
                "--attention-backend",
                "flashinfer",
                "--kv-cache-dtype",
                "bf16",
                "--mem-fraction-static",
                "0.7",
                "--random-seed",
                "42",
                "--cuda-graph-backend-prefill",
                "disabled",
                "--cuda-graph-backend-decode",
                "full",
                "--batch-size",
                *map(str, local_batches),
                "--input-len",
                str(args.input_len),
                "--output-len",
                str(args.decode_steps + 1),
                "--log-decode-step",
                "1",
                "--run-name",
                name,
                "--result-filename",
                str(raw_path),

            manifest["arms"].append(arm)
            (args.output / "manifest.json").write_text(

            print(json.dumps(arm), flush=True)
            if args.dry_run:
                continue

                k: source[k] for k in ("git_head", "runtime_diff_sha256")

                        **row,

                row["fp4_dispatch"]: row

                    "repeat": repeat,
                    "global_batch_size": batch,
                    "decode_latency_reduction_percent": 100
                    * (
                        1
                        - pair[1]["median_decode_latency"]
                        / pair[0]["median_decode_latency"]
                    ),
                    "prefill_latency_reduction_percent": 100
                    * (1 - pair[1]["prefill_latency"] / pair[0]["prefill_latency"]),
                    "off": pair[0],
                    "on": pair[1],
                }
            )
        (args.output / "pairs.json").write_text(json.dumps(pairs, indent=2) + "\n")


if __name__ == "__main__":
