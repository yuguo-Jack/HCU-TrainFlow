# [diffusion] Z-Image: autotune the shared transformer block at both token scales (H100 1024^2 denoise 13.58 -> 9.58 s, 1.42x)

[Upstream PR](https://github.com/sgl-project/sglang/pull/35755) · state: closed · merged: True

## Original PR description

torch.compile on zimage-base gets 1.42x faster: steady-state denoise at
1024x1024 goes 13.575 s -> 9.577 s on one H100, from a single kernel.

Z-Image reuses one transformer block for the context refiner (a few dozen
caption tokens), the noise refiner (4096) and the unified stream (4128 at
1024x1024). The flash-attn call breaks the graph, so the block's attention
compiles into a frame of its own that is entered with all three counts;
automatic dynamic shapes make its token dim symbolic, and Inductor autotunes the
fused-qkv GEMM once, against whichever count it traced first. The caption branch
wins that race and the resulting BLOCK_M=32/BLOCK_N=32 config then runs the
4096- and 4128-token layers too. It is the only dynamic-shape Triton template
the model selects, and it accounts for the entire difference above. The same
gap appears in the comparison table in BBuf/how-to-optim-algorithm-in-cuda#21.

Set inductor's multi_kernel_hints for this model, so the block is compiled once
per hint and dispatched on the runtime shape and the token dim stays dynamic.
The knob is a generic DiTConfig.torch_compile_inductor_config passthrough that
is empty for every other model; inductor config is process-global and is read
when a graph compiles, so it cannot be scoped to the torch.compile call, and
`mode` rules out torch.compile(options=...).

The root cause is the flash-attn graph break, which is what routes three very
different token counts through one compiled frame. Removing it would help any
DiT with mixed sequence lengths and is worth doing separately.

Test Plan:

Steady-state denoise on one H100, min of requests 2..8 (request 1 carries the
compile), stock preset with no extra flags:

```
export CUDA_VISIBLE_DEVICES=0 CI=1 SGLANG_DIFFUSION_SYNC_STAGE_PROFILING=1 \
       FLASHINFER_DISABLE_VERSION_CHECK=1
B=python/sglang/multimodal_gen/.claude/skills/sglang-diffusion-benchmark-profile/scripts/bench_diffusion_denoise.py
rm -rf ~/.cache/sgl_diffusion/torch_compile_cache
python3 $B --model zimage-base --iterations 8 --label compile --output-dir /tmp/zb
python3 $B --model zimage-base --iterations 8 --label eager --no-torch-compile --output-dir /tmp/zb
```

| arm                  | denoise  |              |
|----------------------|----------|--------------|
| torch.compile before | 13.575 s |              |
| torch.compile after  |  9.577 s | 1.42x faster |
| eager, for reference |  9.567 s |              |

First-request e2e goes 79.6 s -> 96.2 s, the cost of autotuning the block at two
sizes instead of one. Verified from the generated code that the fused-qkv site
is now autotuned at 32, 64, 4096 and 4128 rather than at 32 alone.
