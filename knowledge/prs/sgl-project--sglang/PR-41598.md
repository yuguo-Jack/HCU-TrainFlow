# [WIP] prototype move runtime out of sgl-renderer

[Upstream PR](https://github.com/sgl-project/sglang/pull/41598) · state: closed · merged: False

## Original PR description

1. move rust frontend out of sgl-renderer into a shared crate
2. keep sgl-renderer a shared lib over dynamo crates
3. move standalone renderer process into a separate sgl-renderer-server for standalone renderer service

```text
sglang-renderer-server (binary)
└── sglang-frontend (library)
    ├── sglang-renderer (library)
    │   ├── dynamo-renderer
    │   ├── dynamo-tokenizers
    │   ├── dynamo-parsers
    │   └── dynamo-protocols
    ├── dynamo-renderer
    ├── dynamo-tokenizers
    └── dynamo-protocols

sglang-server (unchanged)
├── dynamo-renderer
├── dynamo-tokenizers
├── dynamo-parsers
└── dynamo-protocols

```
