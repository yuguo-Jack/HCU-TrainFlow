# [GLM5.3 Flash] Support CP/BCG prefill PD with DFlash2

[Upstream PR](https://github.com/sgl-project/sglang/pull/43774) · state: open · merged: False

## Original PR description

## Motivation

Stacked on #43182. Enable GLM-5.3 Flash with interleave CP + breakable prefill CUDA graphs on the prefill worker, full TP on the decode worker, Mooncake PD transfer, and the external GLM-5.3 Flash DFlash2 draft.

## Modifications

- Route a CP/TP-sharing prefill rank to the matching physical decode TP rank. Transfer replicated DSA KV/KPool data and that rank's TP-owned KDA/draft state without ordinary CP page filtering or attention-TP-based state slicing. Advertise and validate the sharing topology at bootstrap; ordinary bootstrap responses retain their previous wire shape.
- Run the external attention-owning DFlash draft, including memory-pool allocation, in a full-TP scope. Suspend and restore the target CP strategy together with the runtime topology, including on exceptions.
- Gather captured auxiliary features into global token order before DFlash consumes them. Preserve the live request's KDA host checkpoint metadata in the static prefill graph batch.
- Add an 8-GPU registered PD smoke test covering exact BCG buckets, repeated/prefix-cache requests, eager fallbacks and multi-chunk prefill. Per request, this PR retains only `test/registered/e2e/disaggregation/test_glm53_cp_bcg_dflash.py` as a test change; the other unit-test additions have been removed and existing unit-test files restored to the parent branch.

Supported here: equal physical P/D TP sizes, prefill CP size equal to TP size, Mooncake, DFLASH, DP=PP=EP=1. This does not add unequal-width PD, layer split, DCP, or other transfer backends.

## Accuracy Tests

Both datasets pass the predeclared accuracy and zero-error criteria.

Accuracy-tested source: `ca34205513384bf02be37f4d2e89b48d43befd38`; base #43182 at `199aaf03bf0b7951ddd1aaa87e8f9792723943ac`. The subsequent cleanup changes tests only: runtime code and the retained e2e test are byte-for-byte unchanged. Accuracy evaluation was not rerun for that cleanup.

Hardware: one 8×B300 devbox; GPUs 0–3 for TP4/CP4 prefill and GPUs 4–7 for TP4 decode. Baseline is integrated TP4+DFlash2 on GPUs 0–3 using the same source and dependencies. No language-only restriction.

Frozen protocol: sgl-eval 0.1.2, reasoning enabled, temperature=1, top_p=1, max_tokens=300000, concurrency=16. AIME26 uses all 30 questions for each of seeds 42/43/44/45 (120 samples per arm); MMLU-Pro uses the original first 500 test examples, seed 42. Every output remains in the denominator; no selective retries. Acceptance requires an absolute accuracy difference of at most 1 percentage point **on each dataset**, with no client/request/transport errors.

## Reproduction

Common server options (use these on both workers):

```bash
COMMON=(
  --model-path zai-org/GLM-5.3-Flash
  --tp-size 4
  --dsa-prefill-backend trtllm
  --dsa-decode-backend trtllm
  --kv-cache-dtype fp8_e4m3
  --moe-runner-backend flashinfer_trtllm
  --speculative-algorithm DFLASH
  --speculative-draft-model-path incoai/GLM-5.3-Flash-DFlash2
  --speculative-draft-attention-backend fa4
  --reasoning-parser auto --tool-call-parser auto
  --max-running-requests 16 --cuda-graph-max-bs-decode 16
  --chunked-prefill-size 8192 --mem-fraction-static 0.9
  --enable-metrics --random-seed 42 --host 0.0.0.0
)

# Prefill worker
CUDA_VISIBLE_DEVICES=0,1,2,3 sglang serve "${COMMON[@]}" \
  --port 30000 --nccl-port 30200 \
  --attn-cp-size 4 --enable-prefill-cp --cp-strategy interleave \
  --cuda-graph-backend-prefill breakable \
  --cuda-graph-bs-prefill 512 1024 2048 4096 8192 \
  --disaggregation-mode prefill --disaggregation-transfer-backend mooncake \
  --disaggregation-bootstrap-port 30005

# Decode worker (separate shell)
CUDA_VISIBLE_DEVICES=4,5,6,7 sglang serve "${COMMON[@]}" \
  --port 30001 --nccl-port 30201 \
  --disaggregation-mode decode --disaggregation-transfer-backend mooncake \
  --disaggregation-bootstrap-port 30005

# Integrated baseline, after stopping the candidate workers
CUDA_VISIBLE_DEVICES=0,1,2,3 sglang serve "${COMMON[@]}" \
  --port 30000 --nccl-port 30200
```

Candidate router (sglang-router 0.3.2):

```bash
python -m sglang_router.launch_router \
  --pd-disaggregation --prefill http://127.0.0.1:30000 30005 \
  --decode http://127.0.0.1:30001 --host 127.0.0.1 --port 30002 \
  --request-timeout-secs 7200 --worker-startup-timeout-secs 7200 \
  --retry-max-retries 1 --health-check-timeout-secs 60
```

Use `http://127.0.0.1:30002/v1` for candidate evaluation and the direct `http://127.0.0.1:30000/v1` baseline endpoint. Raw per-request outputs, evaluator/dataset hashes, launch records, and exact-window server audits are retained locally.

## Speed Tests and Profiling

No performance claim. RDMA device access was unavailable in the experiment environment, so Mooncake used TCP fallback. This validates correctness, not RDMA throughput or latency.
