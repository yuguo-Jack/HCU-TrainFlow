# [CI] Skip eval retries in the PD transfer-failure test

[Upstream PR](https://github.com/sgl-project/sglang/pull/43769) · state: closed · merged: True

## Original PR description

- `TestDisaggregationMooncakeFailure` sends 64 concurrent `/generate` requests directly instead of running a 200-example gsm8k eval. The injected failure is rolled on every poll, so nearly every request fails, and the eval client retried each one six times with exponential backoff: about 145s of waiting per run.
- The test now always checks that both prefill and decode are alive and pass `/health_generate`; before, it checked only when the eval raised. A hung request now fails the test after 120s.
- Lower `est_time` from 1007 to 870.

No behavior change outside the test.
