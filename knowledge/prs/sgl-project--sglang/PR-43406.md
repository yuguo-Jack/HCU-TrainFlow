## Summary

Route ComfyUI requests by `extra["comfyui_session_id"]` so successive DiT steps stay on the replica that owns the per-run conditioning cache. Keep realtime session affinity and round-robin routing for unkeyed requests unchanged.

Add DP routing coverage asserting that ComfyUI session requests remain on one replica and do not consume the round-robin counter.
