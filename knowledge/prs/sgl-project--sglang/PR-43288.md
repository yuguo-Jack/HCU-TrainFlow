# [Diffusion] Wan2.2-S2V: wav2vec2 lip-sync fix and DiT speedups (follow-up to #43279)

[Upstream PR](https://github.com/sgl-project/sglang/pull/43288) · state: open · merged: False

## Original PR description

## Motivation

Follow-ups to #43279 (Wan2.2-S2V-14B port): one correctness fix and three speedups for the S2V DiT. **Depends on #43279.** This branch contains its commit; review the 4 commits on top. They are kept separate so that the PR can be split or partly dropped in review.

## Modifications

| commit | files | change | platforms |
|---|---|---|---|
| wav2vec2 last layer | `encoders/wan_s2v_audio.py` (+6 −6) | take the last layer from `last_hidden_state`. On transformers >= 5.17 (main pins 5.19.0), `hidden_states[-1]` is the pre-LayerNorm state, about 60x off, and the video loses lip sync | all |
| fp32 RoPE | `dits/wan_s2v.py` (+23 −15) | RoPE through `_apply_rotary_emb` with fp32 cos/sin and a 1-head table, as `wanvideo.py` does for I2V, instead of a per-forward complex128 table of all 40 heads (they are identical) | all |
| fused segmented modulation | `layers/layernorm.py`, `layers/elementwise.py`, `dits/wan_s2v.py` (+99 −42) | two `CustomOp`s, `LayerNormScaleShift2Seg` and `GatedResidual2Seg`, for the block modulation whose shift/scale/gate switch rows at a token index. `forward_native` / `forward_cuda`: the per-segment platform norm kernels and fp32 products, as before. `forward_xpu`: one compiled kernel for norm + both segments, and bf16 `addcmul` into one output, with no fp32 products and no `cat` | XPU path only; CUDA/ROCm/NPU/CPU run `forward_native` |
| minimal-copy Ulysses exchange | `dits/wan_s2v.py` (+58 −29) | for Ulysses with the replicated ref/motion suffix (ring degree 1, no `--kv-gather-degree`): pack each tensor destination-major in one copy, receive straight into the `[s_global + suffix]` buffer, and gather the suffix rows with `all_gather_single`. This replaces `UlyssesAttention(replicated_*)`'s stacked q/k/v and suffix `cat`s, a path that had no fast all-to-all on any platform. Same values and K/V order | all (Ulysses only) |

## Accuracy Tests

Wan2.2-S2V-14B, 704x1024x81, seed 42, image + `talk.wav`, SP=2 Ulysses.

- **2x A100-40GB (CUDA, torch 2.13.0+cu130, transformers 5.12.1), 3 steps, #43279 vs this branch:**
  - lip sync max r +0.506 / +0.510 (p < 0.001, same lag);
  - video PSNR between them 33.14 dB mean, from the RoPE numerics; this branch's own SP=2 vs SP=1 is 33.08 dB;
  - this branch reproduces bit for bit: two runs give the same output md5.
- **Ulysses exchange:** a 2-GPU NCCL check gives attention **bit-identical** (max abs 0) to full-sequence attention, for b=1 and b=2.
- **RoPE:** the 40 table heads are identical, so the 1-head table is bit-exact; rotated q differs from the old path on 0.0013 % of elements by 1 bf16 ULP.
- **wav2vec2:** the fixed features are identical (max |diff| 0) under transformers 5.12.1, 5.17.0 and 5.19.0.
- **2x Intel Arc B60 (XPU), 40 steps, earlier revisions of these commits:** output vs the port at the same-code PSNR noise floor; with the wav2vec2 fix, lip sync r +0.50. A variant of `GatedResidual2Seg.forward_xpu` with fp32 products was measured at -0.4 dB vs the floor and 3.6 % slower, so the bf16 path is kept.
