# [BugFix] Handle valid OTEL trace inputs in the Perfetto converter

[Upstream PR](https://github.com/sgl-project/sglang/pull/43541) · state: open · merged: False

## Original PR description

Fixes #43540

## Motivation

The OTEL converter fails on supported JSON arrays with leading whitespace and on ordinary SMG spans without its internal `child` field. This prevents conversion before a Perfetto trace can be written.

## Modifications

- Detect JSON arrays using the first non-whitespace character, preserving JSONL parsing.
- Initialize each flat SMG span's internal child list before using the shared conversion functions. Existing engine tree traversal and cross-service flow links are preserved.
- Add focused tests that execute the real CLI for arrays, whitespace-prefixed arrays, JSONL, flat/parent-child SMG traces, and a whitespace-prefixed mixed SMG/engine trace. Assertions check output equivalence, span counts, layout rows, duration, and flow endpoints.

## Accuracy Tests

`python scripts/tests/test_convert_otel_2_perfetto.py -v`: 3 test methods, 8 CLI executions pass on macOS arm64 with Python 3.11.15. The same tests against unmodified main expose five failing subtests/assertions. No model output code is changed; full inference and live-exporter testing were not run.

## Speed Tests and Profiling

No inference speed change. The standalone CPU regression completes in under one second; no performance benchmark is claimed.
