# Init persistent cache for breaking modules in prefill breakable graph

[Upstream PR](https://github.com/sgl-project/sglang/pull/43776) · state: open · merged: False

## Original PR description

## Summary

Persist missing attention compilation/tuning results across server restarts for eager intervals in breakable prefill:

- Reuse SGLang's CuTe AOT cache for FlashInfer GDN and LayerNorm inside the GLM K-pool indexer's eager break.
- Enable existing Triton tuning persistence for two KDA autotuners.
- Reuse existing files and cache infrastructure; no additional warmup pass or FlashInfer source changes. The adapters rely on private FlashInfer interfaces.

## H200 validation

Four-layer BF16 **dummy-weight** GLM-5.3-Flash (TP4), Qwen3.5-0.8B and Qwen3-0.6B (single GPU). PyTorch 2.14.1+cu130, Triton 3.8, FlashInfer 0.7.0.post1, CuTe DSL 4.8. No weights downloaded.

Populate disk caches, restart, then forbid actual attention compilation/tuning from initialization onward. All three server configurations passed requests and breakable replay, with matching output token IDs. GLM KDA was forced eager with `SGLANG_DISABLE_KDA_PREFILL_GRAPH_EXTEND=1`.

Synchronized attention timings within the existing capture warmup, bucket 256:

| Path | First call after restart | Second call, same layer |
| --- | ---: | ---: |
| FlashInfer GDN | 30.781 ms | 0.839 ms |
| FlashInfer MHA | 6.290 ms | 0.194 ms |
| Triton KDA | 47.094 ms | 0.938 ms |
| TileLang sparse attention | 1055.827 ms | 0.827 ms |
| FA3 | 6.162 ms | 0.234 ms |

**No repeated backend compilation/tuning was observed for these signatures.** These are single-startup measurements, not HTTP latency or a before/after speedup. GLM values are medians across four ranks; sparse attention excludes the separate indexer break. First-call cache/object loading remains; TileLang also retains substantial lazy DSL/AST construction overhead. MHA/FA3 validate existing behavior.

LayerNorm passed 16 reference cases (BF16/FP32, H128/256, M1/64/173/256), then all 16 again in a fresh process with `cute.compile` forbidden. Serving covered variable lengths, batching and chunked prefill. These are preliminary cache/functional checks, not full-model accuracy or throughput results. H200 measurements used `8eaa7026ea`; the follow-up only changes formatting, test conventions and documentation.
