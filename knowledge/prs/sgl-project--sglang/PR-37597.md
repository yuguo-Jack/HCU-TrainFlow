# [CPU] enbale GLM_OCR

[Upstream PR](https://github.com/sgl-project/sglang/pull/37597) · state: open · merged: False

## Original PR description

Enable GLM_OCR on XEON.  

1. add RGB support to AMX Conv3d kernel
2. add mix dtype support to Layernorm
3. support TP=6 in frontend.

The input/weight/bias of Layernorm support fp16/bf16/fp32 and these three dtypes are independent of one another.
output/gate/residual has the same dtype with input.
residual and bias is optional.
