## Summary

This is the final PR in the DSpark PD hidden-state transfer stack.

Depends on: https://github.com/sgl-project/sglang/pull/32423

It implements GPU-to-GPU streaming hidden transfer for Mooncake, including READY/ACK flow control and independent hidden-buffer lifetime management.

## Changes

- Add the Mooncake-specific [`PDHiddenEventManager`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/hidden_events.py#L19-L461) for ACK waiters, per-room serialization, CUDA completion handling, timeout recovery, and row release.

- Advertise the Mooncake streaming capability and expose event-manager operations at [lines 270-405](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L270-L405).

- Add READY and ACK control messages in [`notify_pd_hidden_chunk_ready`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L422-L449) and [`ack_pd_hidden_chunk`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L451-L465).

- Transfer registered hidden rows through fixed or dynamic destinations in [`_send_pd_hidden_packet`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L1449-L1530).

- Integrate hidden packet transmission, per-room ordering, ACK parking, early source-row release, abort handling, and independent hidden completion into [`transfer_worker`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L1681-L2130).

- Parse incoming READY messages and queue Decode-side chunks at [lines 2305-2331](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L2305-L2331).

- Attach source CUDA events and hidden chunk metadata to transfer requests through [`MooncakeKVSender.set_pd_hidden_chunk_meta`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L2532-L2565).

- Route PP-specific destination rows and hidden metadata to each Prefill rank in [`MooncakeKVReceiver.send_metadata`](https://github.com/bytedance-iaas/sglang/blob/2968650181534247bb34bb1ca4562aee803258f8/python/sglang/srt/disaggregation/mooncake/conn.py#L2753-L2847).

## Transfer Flow

1. Prefill writes one hidden chunk into registered GPU rows.
2. Mooncake transfers the rows directly to Decode GPU memory.
3. Prefill sends `PD_HIDDEN_CHUNK_READY`.
4. Decode injects the rows into DSpark draft KV.
5. Decode waits for the injection CUDA event and sends an ACK.
6. Prefill releases the source rows and advances the streaming window.

## Scope

- Streaming hidden transfer is enabled for Mooncake.
- NIXL and MORI remain on the non-streaming path.
- Prefill context parallelism is not supported yet.
- Target layers split across multiple Prefill PP ranks are not supported by the current receive layout.
