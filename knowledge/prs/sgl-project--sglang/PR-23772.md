# fix(zimage): align SGLD CFG combine formula with diffusers Z-Image

[Upstream PR](https://github.com/sgl-project/sglang/pull/23772) · state: closed · merged: True

## Original PR description

## Motivation

Z-Image uses `positive + scale * (positive - negative)`, not standard CFG's `negative + scale * (positive - negative)`. Its CFG activation threshold is also `scale > 0`, and a missing negative prompt means an empty string. The previous generic path did not preserve these semantics.

## Changes

- Merge current main without rewriting the PR history.
- Use a model-local CFG policy with Diffusers' FP32 arithmetic and the same combine order for serial and CFG-parallel execution. The native DiT already supplies the output sign inversion.
- Move CFG activation into a sampling-params hook; Z-Image supports all positive guidance values, including `0 < scale <= 1`. Preserve other models' activation rules, `true_cfg_scale` precedence and explicitly enabled request CFG flags.
- Share Z-Image/Turbo sampling behavior and default omitted negative prompts to an empty string.
- Keep the no-CFG prediction tensor/dtype, default Turbo guidance, existing CI workloads, GT and performance baselines unchanged.
- Document the guidance convention and the extra branch cost when enabling CFG.

## Validation

- Independent B200 development environment: 197 related tests passed, covering Z-Image, sampling parameters, CFG policy/gating, CFG-parallel warmup and text-encoding cache, including CPU/CUDA cache paths.
- Exact FP32 formula tests cover guidance `0.5`, `1`, `3.5` and serial/parallel combine. Activation tests additionally cover zero guidance and omitted/empty/explicit negative prompts.
- Pre-commit passed.
- The original author's image-quality numbers predate this implementation update. Full-model Diffusers parity and new end-to-end performance have not been rerun for the revised implementation; those older numbers are not claimed as validation of this head.
