# test(diffusion): skip the LTX-2 RMSNorm-modulation guard test off the CUDA platform

[Upstream PR](https://github.com/sgl-project/sglang/pull/43574) · state: closed · merged: True

## Original PR description

## Motivation

`test_ltx2_rmsnorm_modulate_fallback.py` skips with `torch.cuda.is_available()`, but ROCm answers that `True` as well. The fused RMSNorm-modulation kernel is CUDA-only and gated by the platform's `is_cuda()`, so on MI300 the guard correctly returns `False` while the test asserts `True`. Both tests in the class fail on every AMD unit run (AMD 1-GPU partition 1, seen on #41819's runs on 2026-10-07).

## Modifications

Skip on the same predicate the kernel gate uses (`sglang.kernels.ops.diffusion.common.platform.is_cuda`), with a one-line note on why `torch.cuda.is_available()` is not enough.
