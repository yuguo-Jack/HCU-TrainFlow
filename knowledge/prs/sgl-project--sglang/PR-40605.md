# [sgl-router] Abort unfinished engine requests on cancellation

[Upstream PR](https://github.com/sgl-project/sglang/pull/40605) · state: closed · merged: False

## Original PR description

Cancelled chat requests can leave the engine generating after the router releases its resources.

## Modifications
Add a small abort guard for plain-mode dispatch and streaming. Preserve a caller's string `rid`, otherwise inject a fresh UUID (gateway request IDs are reused across retries and the engine keys in-flight state by `rid`), and send a bounded, best-effort `/abort_request` when forwarding ends unfinished. Completed responses and rejected streams disarm the guard; PD prefill keeps its existing lifetime.

Stacked on #40604.

## Accuracy Tests
Workspace library and integration tests passed after updating payload assertions for the injected ID. Added one compact regression covering unary/streaming cancellation, successful completion, ID preservation, and abort authorization. `cargo check --locked --workspace --all-targets`, strict Clippy, and formatting passed.

## Speed Tests and Profiling
Not run; no inference changes.
