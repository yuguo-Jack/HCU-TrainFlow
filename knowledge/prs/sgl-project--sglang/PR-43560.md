# [diffusion] Fix dLLM running timeout between denoising rounds

[Upstream PR](https://github.com/sgl-project/sglang/pull/43560) · state: open · merged: False

## Original PR description

## Motivation

dLLM requests held in `dllm_manager.waiting_queue` between denoising rounds could fall outside `SGLANG_REQ_RUNNING_TIMEOUT` coverage after their first forward.

## Modifications

- Include dLLM manager-held requests in running-timeout polling.
- Preserve existing timeout guards, request ID deduplication, and rank-consistent abort handling.
- Add a focused regression covering stale, fresh, and never-started manager-held requests, including duplicate membership in a running batch.
