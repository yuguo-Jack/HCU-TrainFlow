# [DSV4.1] Support encoder SWA bounded replay with CUDA DP attention

[Upstream PR](https://github.com/sgl-project/sglang/pull/43813) · state: open · merged: False

## Original PR description

## Changes

Enable encoder SWA bounded replay with DP attention at attention TP=1. Pack prefix tails within the resolved per-rank prefill budget, synchronize replay rounds and let ranks without hits participate idly. Invalidate preplanned verification metadata after replay and keep temporary replay batches eager. Reuse the existing platform/model checks; require at least 128 prefill tokens per attention DP rank.

TRT-LLM and prefill CUDA graphs remain unsupported with bounded replay.

## Accuracy

DeepSeek-V4.1-Flash, 2×GB300, TP2/DP2/EP2, MegaMoE + FlashMLA, native DSpark acceptance. GSM8K: 1,314 scored questions, five-shot chat, thinking disabled, temperature 0, concurrency 64, max output 4,096 tokens.

| Configuration | Correct | Accuracy | Request errors |
|---|---:|---:|---:|
| Replay disabled | 1,278 / 1,314 | 97.26% | 0 |
| Encoder replay enabled | 1,281 / 1,314 | 97.49% | 0 |

One encoder-replay completion reached the output limit; the baseline had none.
