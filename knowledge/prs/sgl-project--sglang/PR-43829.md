# docs: add MiniCPM-V 4.7 cookbook

[Upstream PR](https://github.com/sgl-project/sglang/pull/43829) · state: open · merged: False

## Original PR description

## Motivation

Adds the MiniCPM-V 4.7 cookbook page for the model support in #41993.

Merge after #41993 merges and the `openbmb/MiniCPM-V-4.7-*` checkpoints are public on Hugging Face.

## Modifications

- `docs/cookbook/autoregressive/OpenBMB/MiniCPM-V-4_7.mdx`: new page. Deploy panel and Playground, model introduction and checkpoint table, configuration tips, the transformers 5.17 remote-code workaround for the FP8/INT4 checkpoints, and per-request `mm_processor_kwargs` (`downsample_mode`, `max_slice_nums`) with measured prompt-token counts.
- `docs/src/snippets/configs/openbmb/minicpm-v-4.7.jsx` and `-benchmarks.jsx`: GB300 cells for 1B (BF16, TP=1) and 35B-A3B (BF16 TP=2, FP8 TP=2, INT4 TP=1), a DSPARK overlay that picks the variant's draft checkpoint, a `qwen3` reasoning-parser opt-in, and GSM8K accuracy rows.
- `docs/docs.json`: page added at the top of the OpenBMB group. The `NEW` tag moves from MiniCPM5-2B to this page, and the OpenBMB vendor card now links here.

## Validation

All recipes were served on 4×GB300 with the #41993 head. GSM8K: sgl-eval, full 1,319 questions, temperature 1.0 / top-p 0.95. Stop rate was 100% on every row.

| Config | GSM8K |
|---|---|
| 1B | 84.08% |
| 1B + DSPARK | 83.70% |
| 35B-A3B (TP=2) | 96.36% |
| 35B-A3B + DSPARK (TP=2) | 96.97% |
| 35B-A3B FP8 (TP=2) | 96.97% |
| 35B-A3B INT4 (TP=1) | 96.97% |

Docs checks: `mint validate` and `mint broken-links` pass, and `node docs/scripts/check_cookbook_configs.mjs` is OK. In `mint dev`, the page rendered the expected commands for the 1B BF16 cell and for 35B-A3B INT4 + DSPARK.
