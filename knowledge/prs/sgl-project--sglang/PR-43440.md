# [Dsv4.1] allow decoder bounded replay with breakable prefill graphs

[Upstream PR](https://github.com/sgl-project/sglang/pull/43440) · state: open · merged: False

## Original PR description

Keep captured prefills on full rows, clear stale eager-tail metadata on capture and replay, and only trim model/logits inputs when the current batch carries tail metadata. Larger eager prefills retain decoder bounded replay; DP attention and other prefill graph backends remain unsupported.

Add six CPU regression tests covering configuration guards, eager/graph metadata transitions and logits row selection. All six pass against the rebased source and all pre-commit checks pass. Earlier lab GPU/quality/AgentX runs provide context only; this rebased branch has not received a new GPU end-to-end run.
