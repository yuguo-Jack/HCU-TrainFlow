## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Currently there's support for packing the Q/K/V into one tensor and exchanging them in a single a2a instead of three separate ones in Ulysses. That fast path was gated on all three tensors being fully contiguous, which is stricter than the pack kernel requires: it reads Q/K/V through explicit row and head strides, so only the `head_size` dim needs unit stride.

This now exluded many cases. FLUX.2, for example, produces Q/K/V as `qkv.chunk(3, dim=-1)`of a merged `to_qkv_mlp_proj` and hands then to attention withhout a `.contiguous()`, so every attention call fell back to three collectives.

This PR replaces the contiguous check with one that checks what the kernel needs and routes the remainig call sites through the packed helper. Only data movements changes, output remain indentical.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Add `_packed_qkv_row_view_is_free()`and use it in `_can_use_packed_qkv_a2a_4d()`in place of the three `is_contiguous()` checks.
- Route the replicated-prefix and replicated-suffix USP paths through `_usp_input_all_to_all_qkv` instead of three separate a2a. For ineligible layouts this helpers falls back to the three separate calls.
- Add predicate tests: the FLUX.2 layout (chunk of a merged projection) is accepted and its row view verified copy-free; `b > 1` sliced along seq is rejected, since merging batch and seq there would copy; contiguous input is unchanged; a gapped head dim is rejected.
