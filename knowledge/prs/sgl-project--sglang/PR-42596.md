# [Fix] Type-check request fields on /generate to prevent server crashes

[Upstream PR](https://github.com/sgl-project/sglang/pull/42596) · state: open · merged: False

## Original PR description

Fixes #41466

## Motivation

On the native `/generate` (and `/encode`, `/classify`) endpoint, incoming requests were not strictly type-checked against `GenerateReqInput`, `SamplingParams`, and `SessionParams`. Because `SamplingParams` and `SessionParams` are `msgspec.Struct` definitions, standard `__init__(**kwargs)` constructors do not validate field types. 

## Modifications

1. **`python/sglang/srt/sampling/sampling_params.py`**:
   - In `SamplingParams.verify()`: Added strict integer checks (`isinstance(int) and not isinstance(bool)`) for `max_new_tokens`, `min_new_tokens`, `beam_width`, and `top_k`.
   - Bounded `top_k` to the signed 32-bit integer range `[-1, 2**31 - 1]` to prevent downstream PyTorch/C++ integer overflow errors.
   - Enforced boolean type validation (`isinstance(bool)`) for `skip_special_tokens`, `ignore_eos`, `spaces_between_special_tokens`, and `no_stop_trim`.
   - Enforced string validation on grammar constraints (`regex`, `json_schema`, `ebnf`, `structural_tag`).

2. **`python/sglang/srt/managers/io_struct.py`**:
   - Added `SessionParams.verify()` to validate field types (`id`, `rid`, `offset`, `replace`, `drop_previous_output`).
   - In `GenerateReqInput._validate_inputs()`: Enforced that `session_params` is a dictionary, list of dictionaries, or `None`.
   - In `GenerateReqInput._normalize_single_inputs()` & `_normalize_batch_inputs()`: Enforced that `lora_id` is `Optional[str]` for single requests and a list of strings for batch requests; verified that `positional_embed_overrides` conforms to `PositionalEmbeds`.
   - Applied identical input validation to `EmbeddingReqInput`.

3. **`python/sglang/srt/managers/tokenizer_manager.py`**:
   - In `_create_tokenized_object()`: Wrapped `SamplingParams` and `SessionParams` constructor calls and `verify()` invocations in `try ... except (TypeError, ValueError)` to translate any argument/type errors into `ValueError`.

4. **`python/sglang/srt/entrypoints/http_server.py`**:
   - Expanded endpoint exception handling in `/generate`, `/encode`, and `/classify` to catch `(ValueError, TypeError)`, ensuring clean HTTP 400 Bad Request responses and avoiding unhandled exceptions.

5. **Tests**:
   - Added unit tests in `test/registered/unit/sampling/test_sampling_params.py` and `test/registered/unit/managers/test_io_struct.py`.
   - Added a dedicated BDD test suite in `test/registered/unit/sampling/test_native_generate_bdd_spec.py` verifying all 7 crash causes from #41466 and guarding against happy-path regression.
