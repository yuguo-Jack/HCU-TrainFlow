## Motivation

Clarify the distinction between prefill context parallelism (PCP), tensor parallelism (TP), and decode context parallelism (DCP), and simplify the existing prefill CP documentation.

## Modifications

- Remove the page description sentence.
- Replace the introductory comparison with a shorter explanation of TP head/weight partitioning, PCP prompt-token partitioning, and DCP KV-cache partitioning.
- Explicitly state that PCP and DCP are independent optimizations for different inference phases.
- Remove the decode/target-verification sentence from the speculative-decoding subsection.
- Remove "(Experimental)" from the CUDA graphs subsection heading, leaving the compatibility details unchanged.

Only `docs/docs/advanced_features/prefill_cp.mdx` is changed. Based on main at `166b4ae7fcd`.
