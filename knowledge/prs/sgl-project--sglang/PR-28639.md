# [Perf][DSV4] add ag_gemm and moe_rs overlap kernels for dsv4 prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/28639) · state: open · merged: False

## Original PR description

## 1. Motivation
We implement communication-computation overlap for DeepSeek V4 Prefill CP by introducing two fused Triton kernels built on `torch.symmetric_memory`:
1. Fused AllGather + FP8 Quantization + GEMM: the CP AllGather is performed on a dedicated stream via Copy Engine (CE) P2P pulls (consuming no SMs), while a fused kernel on the compute stream performs on-the-fly FP8 quantization and shared expert `gate_up_proj` GEMM. The compute kernel poll signals to consume each chunk as soon as the CE delivers it, overlapping the AllGather with computation.
2. Fused MoE TopK-Reduce + Shared Expert Add + ReduceScatter: the routed expert output reduction, shared expert addition, and ReduceScatter send are fused into a single kernel, overlapping the ReduceScatter communication with the reduction computation.
- Co-auther: @zxdukki

## 2. Modifications
- **Environment Variable**
  - Add `SGLANG_OPT_USE_TORCH_SYMM_MEM_FUSED_KERNEL` (default `False`) to enable the fused kernels.
- **New Triton Kernels (`symm_mem_kernels/`)**
  - Add allgather_gemm_symm_mem.py: triton kernel for CE-driven AllGather + on-the-fly FP8 quantization and GEMM with signal-based coordination across two streams.
  - Add moe_reduce_rs_symm_mem.py: fused MoE topk-reduce + shared expert addition + ReduceScatter in a single triton kernel.
- **TorchSymmMemCommunicator (torch_symm_mem.py)**
  - Split `disabled` / `allreduce_disabled` so fused-kernel contexts work without multicast support.
  - Add lazy-init helpers to cache AG-GEMM and MoE-RS contexts.
  - Add CP-mode activation via `set_use_cp()` / `get_active_comm()`.
- **Model & Layer (parallel_state.py, fused_moe.py, deepseek_v2/v4.py)**
  - Initialize `TorchSymmMemCommunicator` when the fused-kernel env var is enabled.
  - Add `no_topk_reduce` option to skip in-kernel reduction (deferred to the fused RS kernel).
  - Integrate `maybe_fused_ag_shared_experts` and `maybe_fused_shared_add_rs` into the MoE forward path.
  - Skip the standalone CP AllGather in `DeepseekV4DecoderLayer` when the fused path is active.

The current implementation of `_cas_sys_release` uses Python f-string formatting to insert `expected` and `desired` values directly into the PTX assembly string. However, PTX `atom.cas` instructions do not support immediate/literal values for these operands; they must be registers. Additionally, using `dtype=addrs.dtype` is incorrect because `addrs` is a pointer type, whereas the CAS instruction returns a `uint32` value.

Pass `expected` and `desired` as arguments to `tl.inline_asm_elementwise` with register constraints, and set `dtype=tl.uint32`.

```python
@triton.jit
def _cas_sys_release(addrs, expected, desired):
    """atom.global.release.sys.cas.b32 — spins until CAS succeeds."""
    return tl.inline_asm_elementwise(
        """
        {
            .reg .u32   %tmp32_0;
            .reg .pred  %p0;
            cas_loop:
                atom.global.release.sys.cas.b32 %tmp32_0, [$1], $2, $3;
                setp.eq.u32 %p0, %tmp32_0, $2;
                @!%p0 bra cas_loop;
            mov.u32 $0, %tmp32_0;
        }
        """,
        "=r,l,r,r",
        [addrs, expected, desired],
        dtype=tl.uint32,
        is_pure=False,
        pack=1,
    )
```

In offline testing or benchmarking environments, `get_global_server_args()` can return `None`. Accessing `server_args.chunked_prefill_size` directly without a null check will raise an `AttributeError`.

Add a defensive check to handle `None` and provide a safe fallback value (e.g., `4096`).

```python
    def _get_max_forward_tokens(self) -> int:
        """Return max tokens per forward (chunked_prefill_size or max_prefill_tokens)."""
        server_args = get_global_server_args()
        if server_args is None:
            return 4096
        cps = getattr(server_args, "chunked_prefill_size", None)
        if cps is not None and cps > 0:
            return cps
        return getattr(server_args, "max_prefill_tokens", 4096)
```
