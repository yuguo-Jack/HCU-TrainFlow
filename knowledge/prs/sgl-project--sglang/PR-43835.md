# Add Hopper CuTe DSL DualGEMM SwiGLU kernel

[Upstream PR](https://github.com/sgl-project/sglang/pull/43835) · state: open · merged: False

## Original PR description

## Motivation

CUTLASS and xFormers already provides DualGEMM for sm80, which fuses the swiglu elementwise computation into the gate/up matrix multiplication. But they need rewriting and tuning on sm90+. Recently there is dualgemm PR #41887 for Blackwell using CuTeDSL, so the pr sticks with cutedsl sm90 dualgemm instead of cutlass in the end.

## Modifications

Add an SM90 CuTe DSL kernel that fuses gate/up projections with SwiGLU for BF16 and FP16 decode batches of up to 16 tokens. It uses TMA loads, warp specialization and WGMMA, with two configurations and dispatch calibrated on H100 PCIe.
Includes tests for numerical accuracy, pipeline reuse, input validation, CUDA Graph replay and torch.compile. The kernel is exposed as a standalone operator. Model integration will be added later.

## Accuracy Tests

No end-to-end test yet, while the unit tests are available which compares the actual output with reference
- actual: the sm90 dual gemm
- reference: fp64 gate/up matmul + fp32 silu and mul, with element-wise allclose, and rms check.

## Speed Tests and Profiling

Currently there are 2 sets of tactics T1/T2 available with auto dispatch, and I've also tested another two sets of tactics T3/T4, but found them **worse** than T1/T2, so they are abandoned for now.
