# [XPU] Upgrade XPU backend to PyTorch 2.14

[Upstream PR](https://github.com/sgl-project/sglang/pull/42003) · state: closed · merged: True

## Original PR description

## Summary

Brings the Intel XPU backend up to PyTorch 2.14.

- Bump XPU wheel pins to `torch==2.14.0+xpu`, `torchvision==0.29.0+xpu`, `torchaudio==2.11.0+xpu` (and `torchcodec==0.17.0`) in `pyproject_xpu.toml`, the XPU Dockerfile, and the XPU install docs.
- Bump the XPU Dockerfile base image to `intel/deep-learning-essentials:2026.1.2-devel-ubuntu24.04`, and the pinned Level-Zero UMD / IGC to `26.27.39122.11` / `2.38.2+22051`.
- Rework the `SG_LANG_KERNEL_SOURCE=source` path in the XPU Dockerfile. Instead of a separate `--no-build-isolation` reinstall step with `SG_LANG_KERNEL_TARGET`, it now rewrites the `sglang-kernel-xpu` dependency in `pyproject_xpu.toml` to `git+${SG_LANG_KERNEL_REPO}@${SG_LANG_KERNEL_BRANCH}`. The kernel then builds from source during the main `pip install`. The default `wheel` path is unchanged.
- Docs: install the `dev` and `diffusion` extras in the XPU source build (`pip install -v ".[dev,diffusion]"`), matching the Dockerfile.

The Rust TreeCore extension's PT 2.14 build fixes that were in earlier revisions of this PR have been dropped. Upstream #38641 now covers them: it allows PyTorch 2.14, adds `-std=c++20`, and replaces the old compat header with a single `torch_compat.h`.
