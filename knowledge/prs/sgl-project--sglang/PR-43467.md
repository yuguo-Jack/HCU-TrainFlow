# [Fix] Close Qwen3 Coder streamed arguments at the tool boundary

[Upstream PR](https://github.com/sgl-project/sglang/pull/43467) · state: open · merged: False

## Original PR description

## Motivation

Fixes #43150. When Qwen3 Coder output closes `</tool_call>` without `</function>`, streaming leaves the argument object unterminated or drops the last parameter, even though non-streaming recovers it.

## Modifications

Use `</tool_call>` as a parameter terminator and route an unfinished function through the existing argument-closing path. Keep normal function endings, subsequent tool calls, and trailing assistant text intact.

## Accuracy Tests

- The two regression tests fail on the unchanged upstream parser (11 failing subcases), then pass after the fix. They cover closed/missing parameter endings, empty arguments, character-sized and larger chunks, and a following well-formed call.
- `PYTHONPATH=python python -m pytest test/registered/unit/function_call/ -q`: **631 passed, 1640 subtests passed**.
- `pre-commit run --all-files`: all configured hooks pass, including the Rust checks.
