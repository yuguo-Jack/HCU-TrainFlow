# [Docs] Add weight cache flags to the server args table

[Upstream PR](https://github.com/sgl-project/sglang/pull/43842) · state: open · merged: False

## Original PR description

## Motivation

`--weight-cache-mode`, `--weight-cache-socket` and `--weight-cache-timeout` are live flags with no row in `server_arguments.mdx`. They sat on the undocumented allowlist added in #38520.

## Modifications

- Added a row for each flag to `docs/docs/advanced_features/server_arguments.mdx`. Descriptions, defaults and choices come from the existing `Arg(help=...)` strings in `arg_groups/fields/model.py`, so nothing new is being claimed about behavior.
- Removed the three flags from `server_arguments_undocumented.txt`.

`test_server_args_docs_coverage.py` passes locally.
