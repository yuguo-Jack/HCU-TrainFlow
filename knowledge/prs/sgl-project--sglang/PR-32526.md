# [Spec][DSV4] perf: Skip inactive target-verify metadata tails

[Upstream PR](https://github.com/sgl-project/sglang/pull/32526) · state: closed · merged: False

## Original PR description

## Motivation

DSV4 MTP target verification captures metadata buffers for a 1M-token maximum context. On every CUDA-graph replay, `_page_table_positions_kernel` and `_init_compressed_attn_metadata_kernel` traversed the full capture capacity even when the current sequence was short. This made two memory-bound metadata kernels a measurable part of target-verify GPU time.

## Modifications

- Add CUDA-graph-safe live-prefix execution to both Triton metadata kernels. Launch grids stay static, while blocks beyond device-side live lengths exit without rewriting inactive tails.
- Preserve scalar metadata updates and the required C128 sentinel for empty sequences.
- Enable the optimization only for the validated default SM100 path. Alternative indexer, top-k, HiSparse, and non-CUDA paths retain full-tail initialization.
- Add focused B200 replay and poisoned-tail consumer tests, plus a local non-CI CUDA-graph benchmark.
