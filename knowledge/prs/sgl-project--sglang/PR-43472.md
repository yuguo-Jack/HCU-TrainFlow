# [Docs] Standardize diffusion cookbook command builders

[Upstream PR](https://github.com/sgl-project/sglang/pull/43472) · state: closed · merged: True

## Original PR description

## Summary

- Use the H3-style Setup / Server / Request builder across all 29 diffusion model pages, with Quick start before model capabilities.
- Replace nine standalone pickers and add builders for thirteen pages that previously had static commands. Keep existing builder recipes, model-specific instructions, benchmarks, and old section anchors.
- Preserve hardware, checkpoint, precision, and LoRA choices. Keep documented but untested combinations explicitly unverified, and require LTX-2.5 decoder weights to be loaded before selecting diffusion decode.
- Add regression coverage for page structure, hardware visibility, resource validation, request payloads, and model-specific controls. Add a compact CLI-reference tip at the bottom of the Server panel across diffusion builders. Runtime code and command-generation logic are unchanged.

## Validation

Cookbook contract checks, 38 Node tests, pre-commit, Mintlify build/link validation, and local browser checks across all 29 pages. Checked mobile layout and representative hardware, precision, GPU-count, and decoder interactions. No new GPU benchmarks or end-to-end inference claims.

Follows #43380, which is already merged.
