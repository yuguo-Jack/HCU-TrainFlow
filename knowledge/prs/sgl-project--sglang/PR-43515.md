# [Perf] Reduce KV-cache gather overhead in DCP MLA prefill

[Upstream PR](https://github.com/sgl-project/sglang/pull/43515) · state: open · merged: False

## Original PR description

## Motivation

Profiling and code analysis showed that DCP prefill KV gathering incurs substantial overhead beyond communication, including repeated layout preparation, temporary allocations, concatenation, padding, and copies across layers. The optimization therefore focuses on producing the communication layout directly during KV reads and reusing metadata across layers. The design draws inspiration from vLLM’s approach of gathering and optionally dequantizing cached KV directly into a contiguous workspace. In SGLang, we reuse the existing Triton pool reader to combine KV reads, dtype conversion, and packing into a single operation that writes directly into a contiguous send buffer with padding slots. Send indices and receive-layout metadata are prepared once per forward/chunk and reused across layers. After all-gather, a Triton kernel reorders valid KV entries directly into the final attention buffers. This eliminates intermediate KV tensors, concatenation, and per-request KV padding/copies, reducing CPU dispatch overhead, kernel launches, and GPU memory traffic while preserving communication volume and computational semantics.
