# fix(spec): prefer decode and default EAGLE chunked prefill to 1024 (#1093)

[Upstream PR](https://github.com/sgl-project/sglang/pull/40518) · state: closed · merged: False

## Original PR description

## Summary

Fix multi-turn speculative TPOT bubbles on Ascend when chunked prefill is disabled and scheduling is prefill-first (Ascend/sglang #1093).

- While speculative decoding is on, mixed chunk is off, and a decode batch is running, skip new prefills **and** in-flight `chunked_req` continuations so decode is not starved.
- If `--chunked-prefill-size` is unset or `<= 0` under EAGLE/NEXTN, default it to **1024**. An explicit positive value is unchanged.

## NPU retest (Qwen3-Next W8A8 + NEXTN, C=2, generated-shared-prefix)

Formal baseline before the fix: Mean TPOT delta **-22.82** (fail), Max ITL about 4s.

Adopted scheme (decode-prefer + chunked 1024), 10/10 runs with |delta| <= 1 ms (max |delta| 0.92):

| Run | A | B | delta |
|-----|---|---|-------|
| 1 | 14.56 | 15.39 | +0.83 |
| 2 | 15.40 | 15.17 | -0.23 |
| 3 | 15.03 | 15.20 | +0.17 |
| 4 | 15.23 | 15.19 | -0.04 |
| 5 | 14.76 | 15.07 | +0.31 |
| 6 | 15.53 | 15.21 | -0.32 |
| 7 | 15.26 | 15.04 | -0.22 |
| 8 | 14.16 | 15.05 | +0.89 |
| 9 | 16.25 | 15.33 | -0.92 |
| 10 | 15.02 | 15.49 | +0.47 |

V2 + chunked 2048 was only 8/10, so 1024 is the default.
