# [3/3] [EAGLE] perf: Remove redundant draft capture input staging

[Upstream PR](https://github.com/sgl-project/sglang/pull/30949) · state: closed · merged: False

## Original PR description

## Motivation

Multi-step EAGLE/MTP CUDA graph capture routes per-step draft forwards through the eager runner. Staging fields that already alias graph-stable draft buffers records redundant copy nodes into the captured graph.

This is part 3 of 3 extracted from #30388.

## Changes

- Add `ForwardBatch.skip_eager_input_staging` to explicitly identify batches backed by persistent graph buffers.
- Set the flag for EAGLE draft and frozen-KV MTP draft CUDA graph capture batches.
- Keep generic capture staging unchanged unless the explicit batch flag or global `SGLANG_EAGER_INPUT_NO_COPY` override is set.
- Add `SGLANG_EAGER_INPUT_NO_COPY_IN_DRAFT_CAPTURE` as the draft-capture kill switch.
- Add focused `EagerRunner.load_batch` unit coverage.

These 3 memcopies are removed from each DRAFT loop:
<img width="1877" height="523" alt="image" src="https://github.com/user-attachments/assets/4f42c8b2-6a63-4a9e-97cd-dfa500da822b" />


## Safety

The marked capture batches contain views into each draft graph runner's persistent input buffers. Replay refreshes those buffers in place, so their tensor addresses remain stable. Generic capture mode alone does not establish that aliasing contract and continues to stage inputs.

Accuracy and speedup were measured on the unified three-part stack. See the full results in #30388.

## Code Review

This pull request introduces a mechanism to skip eager input staging for graph-captured speculative draft loops, preventing redundant copy kernels from being baked into the CUDA graph. This is achieved by adding a new environment variable `SGLANG_EAGER_INPUT_NO_COPY_IN_DRAFT_CAPTURE` and a `skip_eager_input_staging` flag on `ForwardBatch`. Unit tests are also added to verify these behaviors. The feedback suggests using `getattr` when accessing `skip_eager_input_staging` on `forward_batch` to avoid potential `AttributeError`s if mock, proxy, or duck-typed objects are passed.

To prevent potential `AttributeError`s when `forward_batch` is a mock, proxy, or a duck-typed object (such as `SimpleNamespace` views used in speculative decoding or testing), it is safer to use `getattr` to retrieve `skip_eager_input_staging` with a default value of `False`.

```suggestion
        if (
            envs.SGLANG_EAGER_INPUT_NO_COPY.get()
            or getattr(forward_batch, "skip_eager_input_staging", False)
        ):
```
