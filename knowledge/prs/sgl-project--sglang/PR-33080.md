## Original PR description

## Motivation

The DSV4 draft-extend CUDA graph prologue translated full KV-cache locations into SWA locations with two GPU launches on every replay: an int64 mapping gather followed by an int32 cast. This is a latency-sensitive captured path, so the two operations can be expressed more directly as one kernel.

## Modifications

- Compiled the index select + int32 casting with torch compile during capturing
