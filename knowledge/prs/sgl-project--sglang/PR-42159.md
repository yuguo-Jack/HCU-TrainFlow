# [DSV4.1] Reduce eager Engram extend preparation

[Upstream PR](https://github.com/sgl-project/sglang/pull/42159) · state: closed · merged: True

## Original PR description

Resolve request rows inside the hash kernel and commit extend history in a separate ordered kernel. Avoid materializing the per-token row map and intermediate history-update tensors. Keep the existing path by default behind SGLANG_OPT_ENGRAM_EXTEND_HASH.

Carry CUDA parity tests for request boundaries, padding, history modes, multimodal tokens and integer metadata types. All applicable pre-commit hooks passed.

Extracted from optimization-lab commit 79d2cda34c; independent of the other lab optimizations.
