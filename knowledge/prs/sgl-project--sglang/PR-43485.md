# [perf] Reduce `import sglang` time by lazily importing video decoder

[Upstream PR](https://github.com/sgl-project/sglang/pull/43485) · state: open · merged: False

## Original PR description

## Motivation

`import sglang` takes several seconds. `srt/utils/common.py` imported `video_decoder` at module load, which transitively pulls in `torchcodec` — a cost paid on every `import sglang`, even for text-only workloads.

## Change

Move the `video_decoder` import from module level into the functions that use it: `load_audio`, `load_video`, `encode_video`.

## Result

Measured with `python -X importtime`, A/B alternating in the same container:

- `import sglang`: 7.36s -> 7.20s (-164ms, ~2.2%)
- `torchcodec` no longer appears on the `import sglang` path

Audio/video decoding still works: `_BACKEND` resolves to `torchcodec` and the decoders load on first use.
