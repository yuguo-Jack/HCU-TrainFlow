# [MemCache] Skip KV events and eviction config on a disabled radix cache

[Upstream PR](https://github.com/sgl-project/sglang/pull/43253) · state: closed · merged: True

## Original PR description

- A disabled cache holds nothing, so `reset()` no longer records `AllBlocksCleared`, and the eviction strategy is not built from `--radix-eviction-policy-config` (an unknown key no longer fails startup)
- `UnifiedRadixCache(disable=True)` passes the tree core `enable_kv_cache_events=False` and the default LRU policy; classic `RadixCache` (and `PureSWARadixCache`) does the same for its recorder and strategy
- Restores the behavior of the retired chunk caches for `--disable-radix-cache` (#43199, #43200, #43198); also applies to disabled mamba / streaming caches, which already used `UnifiedRadixCache`
- Tests: a disabled cache emits no events after `reset()` and ignores a bad eviction config; an enabled one still raises
