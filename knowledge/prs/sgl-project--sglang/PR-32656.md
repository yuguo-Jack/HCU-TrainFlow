# [Spec][DSV4] perf: Fuse target-verify metadata prologue

[Upstream PR](https://github.com/sgl-project/sglang/pull/32656) · state: closed · merged: False

## Original PR description

## Motivation

DSV4 MTP target verification rebuilds fixed-width causal metadata through several small ATen kernels on every CUDA-graph replay. Their launch overhead is significant for the small batches used by speculative decoding.

## Modifications

- Add a local Triton kernel that produces extended sequence lengths, causal lengths, and repeated request-pool indices in one launch.
- Remove redundant planner casts and no-op page-index padding.
- Preserve CPU dispatch and CUDA-graph replay semantics, with registered parity and replay tests.
