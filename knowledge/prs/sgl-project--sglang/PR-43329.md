# [PP+PD] Harden PPConsensusStore: msgspec wire format, drop malformed messages

[Upstream PR](https://github.com/sgl-project/sglang/pull/43329) · state: closed · merged: True

## Original PR description

## Motivation

Follow-up to the review on #38959. `PPConsensusStore` binds its PULL socket on `get_local_ip_auto()` (required for multi-node PP) with no authentication, and the receive loop called `pickle.loads` on whatever arrived. Two problems:

1. Anyone who can reach that port gets code execution in the PP0 prefill scheduler. The repo already treats this socket class as a hardening target (see the CVE-2026-3060 note on `get_zmq_socket_on_host`), and the rest of disaggregation avoids pickle on zmq.
2. The receive loop had no error handling, and the worker thread's catch-all runs `os._exit(1)`. A single garbage datagram (or a transient decode error) took down the whole PP0 prefill instance.

## Modifications

- Wire format is now a `msgspec.Struct(array_like=True)` of `(kind, rank, key, value)`, msgpack-encoded. Decoding is typed, so only that exact shape is accepted.
- `_decode` drops and logs messages that fail to decode, come from a rank outside `(0, pp_size)`, or carry an unknown op kind. The `os._exit(1)` path is kept for genuine internal failures but is no longer reachable from network input.
- Encoding moved to the caller's thread (`__setitem__` / `pop` / `__delitem__`), so an unencodable value raises at the call site and leaves the local map untouched, instead of killing the background sender.

## Test

`test/registered/unit/disaggregation/test_pp_consensus_store.py` (base-a-test-cpu), three new cases:

- `test_malformed_messages_are_dropped`: pushes empty, invalid-msgpack, pickle, wrong-shape, rank-0, out-of-range-rank, unknown-op, bad-key-type and bad-value-type frames at the PP0 socket, then a valid PUT on the same connection, and asserts the PUT landed. Against the #38959 store this test kills the pytest process (exit 1, no output); with this change all 21 tests pass.
- `test_int_room_key_round_trip`: integer bootstrap-room keys survive the typed wire format.
- `test_unencodable_value_raises_in_caller`: the new encode-at-call-site contract.

Ran locally on CPU: 21 passed. black/isort clean.
