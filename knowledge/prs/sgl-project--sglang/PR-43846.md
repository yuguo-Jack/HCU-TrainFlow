# [Docs] Add four HiCache flags to the server arguments table

[Upstream PR](https://github.com/sgl-project/sglang/pull/43846) · state: open · merged: False

## Original PR description

 ## Motivation

Four HiCache flags are registered but have no row in the server arguments table: `--hicache-host-memory-mode`, `--hicache-host-memory-fraction`, `--hicache-storage-prefetch-retry-poll-interval` and `--hicache-storage-prefetch-retry-max-attempts`. They only show up in `--help`.

## Modifications

- Add a row for each flag to `server_arguments.mdx`. Descriptions, defaults and choices are copied from the field declarations in `arg_groups/fields/memory.py`.
- Remove the four flags from `server_arguments_undocumented.txt`, since the coverage test fails if a documented flag stays on that list.

Docs only, no code changes. No open PR documents these flags.
