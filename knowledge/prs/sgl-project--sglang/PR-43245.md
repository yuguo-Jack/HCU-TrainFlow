# [moe] Fill num_token_non_padded for the customized A2A backend at EP 1

[Upstream PR](https://github.com/sgl-project/sglang/pull/43245) · state: closed · merged: True

## Original PR description

## Motivation

`ForwardBatch` fills `global_num_token_non_padded` (and the per-rank `num_token_non_padded` derived from it) only when `enable_num_token_non_padded()` is true, which today means expert parallelism (`moe_ep_size > 1`) or a WORLD-group DP gather.

`--moe-a2a-backend customized` is the extension point for an out-of-tree dispatcher. The predicate leaves the count unset for it whenever `moe_ep_size` is 1 and no WORLD-group DP gather is enabled, so a dispatcher selected through that option receives no real-token count to mask the padded rows of a CUDA-graph bucket with.

## Modifications

- `enable_num_token_non_padded()` also returns true when the A2A backend is `customized`. The import is local, like the existing `get_moe_a2a_backend` import elsewhere in `forward_batch_info.py`.
- The field comment on `global_num_token_non_padded` no longer names `moe_ep_size > 1` as the only condition; the predicate is the single statement of when the count is present.
- `test/registered/unit/model_executor/test_num_token_non_padded_localization.py` gains one CPU case pinning that at EP 1 the predicate is true for `customized` and false for `none`. With only the test applied to `main`, the `customized` subtest fails; on this branch it passes.

No behavior changes for any in-tree A2A backend: `none`, `deepep`, `mooncake`, `nixl`, `mori`, `flashinfer`, the Ascend backends and the MegaMoE variants keep the existing gate.

## Accuracy Tests

Not applicable: the change only fills a count that existing backends already receive under EP, and no in-tree backend selects `customized`. The CPU unit file passes on this head (7 tests, 46 subtests), and `isort`, `ruff`, `ruff format` and `codespell` from the repository's pre-commit config are clean on both changed files.

## Speed Tests and Profiling

None run; the added work is one scalar host-to-device copy per forward, and only for the `customized` backend at EP 1.
