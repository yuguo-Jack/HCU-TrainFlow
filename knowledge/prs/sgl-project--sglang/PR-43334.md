# [XPU] Fix XPU CI breaks from #41105 (KDA chunk_offsets) and #42588 (int4 test tp_group)

[Upstream PR](https://github.com/sgl-project/sglang/pull/43334) · state: closed · merged: True

## Original PR description

## Motivation

#41105 added a `chunk_offsets` argument to the generic `fla/chunk_delta_h.py::chunk_gated_delta_rule_fwd_h` and made `chunk_kda_fwd` pass `chunk_offsets=chunk_offsets`. On XPU, `kda.py` imports the XPU override instead:

```python
if is_intel:
    from sglang.srt.hardware_backend.xpu.kernels.fla.chunk_delta_h import chunk_gated_delta_rule_fwd_h
```

That override's signature was not updated, so every `chunk_kda` call on XPU fails:

```
File ".../sglang/kernels/ops/attention/fla/kda.py", line 1235, in chunk_kda_fwd
    h, v_new = chunk_gated_delta_rule_fwd_h(
TypeError: chunk_gated_delta_rule_fwd_h() got an unexpected keyword argument 'chunk_offsets'
```

This breaks `test/registered/xpu/test_kda_track_state_xpu.py` on `main`, and because the error isn't retried, the XPU suite stops there (16/38 files run): https://github.com/sgl-project/sglang/actions/runs/37893946145/job/113701033110

#41105's own XPU job failed at "Checkout code" (infra), so this wasn't caught before merge.

## Modifications

Mirror the generic change in the XPU `chunk_gated_delta_rule_fwd_h`: accept `chunk_offsets`, and only derive it with `prepare_chunk_offsets` when the caller doesn't pass one. Behaviour is unchanged when `chunk_offsets` is `None`.

## Notes

Independent of #43306 (int4 dense test fix); both are needed for a green XPU suite on `main`.
