# Accept iterable inputs in GlobalLayout constructor

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7993) · state: closed · merged: True

## Original PR description

- [x] I, the PR author, have personally reviewed every line of this PR.

## What does this PR do?

Give the frozen `GlobalLayout` dataclass a typed constructor that accepts iterable shapes and offsets, so callers can pass lists or generators without converting them to tuples. The constructor normalizes shapes to `torch.Size` and offsets to tuples using `object.__setattr__`, then calls the existing validation. Equality, hashing, and representation remain generated by the dataclass.

Remove redundant conversions in the layout builders and quantized scale layouts.

## Validation
