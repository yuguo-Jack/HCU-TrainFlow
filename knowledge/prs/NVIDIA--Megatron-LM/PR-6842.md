# Add DSA indexer weights projection precision controls

## Related PRs

## Summary

- Add independent controls for whether the ordinary DSA indexer `linear_weights_proj` participates in FP8/FP4 quantization and whether its output is BF16 or FP32.
- Preserve the existing defaults: follow the enclosing quantization context and return BF16 projection output.
- Add a non-quantized true-FP32-output path using BF16 parameters and inputs, Transformer Engine `general_gemm` when supported, and a cached FP32 `torch.mm` fallback otherwise.
- Preserve checkpoint keys and BF16 parameter storage while retaining immediate and deferred WGrad, gradient-accumulation fusion, FSDP main-grad buffers, CUDA Graph capture, and asynchronous parameter readiness.
- Keep the cuDNN DSA backend on its required BF16 weights-tensor contract; FP32 projection output remains available to the unfused and TileLang paths.

## Testing

- Megatron-LM autoformat check against `main`: passed with Black 26.3, isort, Pylint 10/10, and Ruff.

- Corresponding #6279 precision suite: 33 passed / 4 skipped on H100 and 35 passed / 1 skipped on GB200; the delayed + fused-WGrad hook regression passed.
- Added main-specific regressions for asynchronous projection-weight readiness and the `DSAIndexer` deferred-WGrad flush chain.
