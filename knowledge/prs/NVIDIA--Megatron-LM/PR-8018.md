# What does this PR do?
<!-- Add a one line overview of what this PR aims to accomplish. -->

Extend native DeepSeek V4.1 CSA2 with packed THD and contiguous context-parallel support, plus stateful full activation recompute that preserves cross-layer CSA2 and single-pass mHC state. The model path also carries packed image spans and Engram prefixes across CP partitions.

## Implementation details

- Add shared THD layout utilities for logical and padded sequence metadata, compression groups, validity masks, and rotary positions.
- Add contiguous CP support for CSA2 with boundary halo exchange, local compression layouts, canonical global KV ownership, and packed candidate masks.
- Extend DeepSeek V4.1 attention and model paths to handle packed THD inputs, packed image spans, and Engram prefix hashing.
- Add a stateful CSA2 HybridStack adapter for full recompute with preserved shared KV, index, candidate, and mHC state.
- Add parity tests for packed sequences, CP forward and gradient behavior, candidate masks, full recompute, vision, and Engram integration.
- Resolve the CSA2 lint findings in the touched files.

## Known limitations

- CSA2 remains TP=1.
- CP requires contiguous THD partition metadata.
- CSA2 indexer loss is not supported with CP.
