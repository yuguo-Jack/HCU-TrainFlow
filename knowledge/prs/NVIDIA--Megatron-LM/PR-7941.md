# Resolve the checkpoint iteration on every rank in the MIMO load check

# What does this PR do?
`_check_mimo_checkpoint_fully_loaded` read the checkpoint's tensor keys on rank 0 only. Without `--ckpt-step` that resolves the iteration from the tracker file through read_metadata, which all-reduces across ranks, so rank 0 waited in that all-reduce while the other ranks waited in the broadcast that follows, and the server hung until the NCCL timeout. Resolve the checkpoint directory on every rank and read the metadata on rank 0 only.
