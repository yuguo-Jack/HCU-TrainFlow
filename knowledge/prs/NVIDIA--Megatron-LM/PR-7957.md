# Copy MLA's down-projection slices with a vectorized kernel

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7957) · state: closed · merged: True

## Original PR description

The q and kv inputs of MLA's up-projections are column slices of the down-projection output; with mla_down_proj_fusion, of one [s, b, q_lora_rank + kv_lora_rank + qk_pos_emb_head_dim] GEMM output. TE's linear modules make them contiguous with Tensor.contiguous, which copies such row-strided views with PyTorch's generic strided kernel, without vectorized accesses. Copy them before the up-projections with a 2D-tiled Triton kernel (megatron/core/fusions/fused_row_copy.py) instead. The copy is exact and its gradient is passed through, as for Tensor.contiguous.

- lmcafee-nvidia · comment · 2026-10-08T15:06:13Z · [source](https://github.com/NVIDIA/Megatron-LM/pull/7957#discussion_r4220665248)

File: `megatron/core/transformer/multi_latent_attention.py` · line None

please keep `contiguous_rows` out of the `local` backend path when `qk_layernorm=False`: its projection can already read the original slice, so this adds a copy. apply the optimization only where the projection requires that copy.

an example flow:

- a run uses `transformer_impl='local'`, `qk_layernorm=False`, and one GPU.
- the key/value input takes 512 columns from each 576-column row.
- for 4096 tokens in `BF16`, this now allocates and copies 4 MiB before the projection.
- the existing `torch.matmul` path can use the original rows directly.

one possible change is to apply the copy only to Transformer Engine projection modules:

```python
def _prepare_up_proj_input(projection, x):
    if HAVE_TE and isinstance(
        projection, (TELinear, TELayerNormColumnParallelLinear)
    ):
        return contiguous_rows(x)
    return x
```

then use it at both changed call sites:

```python
q, _ = self.linear_q_up_proj(
    _prepare_up_proj_input(self.linear_q_up_proj, q_compressed)
)
kv, _ = self.linear_kv_up_proj(
    _prepare_up_proj_input(self.linear_kv_up_proj, kv_compressed)
)
```

this checks the actual projection implementation; `TEColumnParallelLinear` is covered because it inherits from `TELinear`. a regression test should confirm that local projections receive the original tensor without copying.
