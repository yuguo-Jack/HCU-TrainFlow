# Declare the residual on the pre-MLP norm of the fused MLA spec

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7942) · state: closed · merged: True

## Original PR description

The `mla_down_proj_fusion` branch of the TE GPT layer spec builds the MoE pre-MLP norm with `backend.layer_norm()`, while the unfused MLA branch and the standard attention branch pass `has_residual=True`. With `fused_residual_rmsnorm=True` that norm therefore stays a plain TE RMSNorm: its backward runs `rmsnorm_bwd` plus a separate residual-gradient add instead of TE's fused `rmsnorm_bwd_add`. Declare the residual as the other branches do.
