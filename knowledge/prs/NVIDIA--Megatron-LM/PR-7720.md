# What does this PR do?

`flatten_products` reads only `product["test_case"][0]`. Both grouped inference performance recipes therefore omit their async-scheduler scenario: `gpt_583m_perf_async_sched` on H100 and `gpt_583m_perf_async_sched_gb200_4gpu` on GB200.

Expand the outer test-case list as another Cartesian dimension alongside the existing parameters. Cadence stays a list-valued attribute, and legacy scope aliases retain their per-row cadence semantics.

The regressions load both existing recipe files through the production parser and also exercise multiple cases across platform/scope combinations.
