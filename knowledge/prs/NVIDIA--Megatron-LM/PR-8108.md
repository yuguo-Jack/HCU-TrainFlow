# support QK clipping with distributed and CPU-offloaded AdamW

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8108) · state: open · merged: False

## Original PR description

This PR fixes QK clipping with distributed Adam/AdamW and optimizer CPU
offloading, and corrects the maximum attention logit reported to TensorBoard.

- **Support distributed Adam/AdamW and optimizer CPU offloading.**
  Apply QK clipping to the local FP32 master parameter shards after optimizer
  updates and before parameter copy-back, including CPU-offloaded parameters.

- **Modify only master weights.**
  Remove direct clipping of model weights so that only one copy of each
  parameter is modified. Model weights receive the clipped values through
  the optimizer's existing copy-back and synchronization path.

- **Log the maximum attention logit across all layers.**
