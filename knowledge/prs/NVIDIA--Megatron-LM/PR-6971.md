# What does this PR do?

Propagates persistent async checkpoint worker failures to every training rank and cleans up failed worker state without waiting indefinitely on joinable queues.

An exception in a persistent worker's preload or async function could terminate the child without publishing a completion record. A blocking finalization would then keep waiting, and a single failed rank could strand its distributed peers.

This change:

- reports rank-tagged worker tracebacks and process exit codes to all ranks;
- adds failure-aware preload acknowledgements and worker-liveness checks;
- avoids unbounded queue joins during failure cleanup;
- clears stale pending requests and resets singleton worker state; and
- verifies that a replacement persistent worker can start and complete successfully.
