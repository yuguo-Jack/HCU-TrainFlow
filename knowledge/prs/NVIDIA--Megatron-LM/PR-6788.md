# What does this PR do?

Large training modules are harder to review and maintain when telemetry lifecycle code is mixed into the training loop. This change moves OpenTelemetry span state and lifecycle helpers from `megatron/training/training.py` into `megatron/training/telemetry_spans.py`, while leaving the training call sites unchanged.

The extracted module owns startup and checkpoint-interval spans, shutdown state, and one-time `atexit` and SIGTERM hook installation. Startup timestamps are passed explicitly to avoid a circular dependency on `training.py`.

CPU-only tests cover startup closure, interval rerooting, one-time hook installation, hard SIGTERM teardown, and graceful SIGTERM flushing.
