# What does this PR do?
Documents two features from the September 2026 activity report (#7100) that merged to `main` without user-facing documentation.

- **MoE hash routing** (#6403, report section "HybridModel, GDN, and mHC execution"): adds a "Hash Routing" subsection to the MoE README, plus a row in the router types table and in the router arguments table. `docs/user-guide/features/moe.md` includes this README, so the published MoE guide picks it up.
- **Request aborts on client disconnect** (#6916, report section "Inference serving, caching, and request lifecycle"): notes in the OpenAI-compatible HTTP server section of the inference user guide that a call's in-flight requests are aborted when the client disconnects.

#7100 does not list specific documentation changes, so I picked items from its "Delivered" section that had no documentation. Happy to adjust the scope if you had something else in mind.

The statements were checked against the current `main` sources: `moe/router.py`, `transformer_config.py`, `models/hybrid/hybrid_model.py`, `models/gpt/gpt_model.py`, `training/global_vars.py`, and the `dynamic_text_gen_server` endpoint handlers. Documentation only, no code changes. The Sphinx build was not run locally.

For major changes (either in lines of code or in its impact), please make sure to first share a design doc with the team. If you're unsure what's the best way to do so, contact @NVIDIA/mcore-oncall.
