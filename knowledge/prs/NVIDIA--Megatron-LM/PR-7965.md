# build: require W&B 0.30.0 or newer

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7965) · state: closed · merged: False

## Original PR description

## What does this PR do?

Require `wandb>=0.30.0` for both the `training` and legacy `mlm` extras, preventing installers from selecting older W&B releases whose bundled `wandb-core` binaries were identified during container vulnerability investigation.

Update the matching project dependency metadata in `uv.lock`. The resolved W&B package is 0.30.0.

## Validation

- Parsed `pyproject.toml` and `uv.lock` and verified that both extras and their lockfile metadata require W&B >=0.30.0.
- Verified that all resolved third-party package records match current `main`, with no missing dependency nodes.
- `BASE_REF=main CHECK_ONLY=true SKIP_DOCS=false bash tools/autoformat.sh` passed (no changed Python files).
- `git diff --check` against current `main` passed.

Full image builds, GPU training, and a fresh container vulnerability scan were not run for this metadata change.
