# What does this PR do?
Megatron-Bridge checkpoints store no training args, so VLM detection fell back to a plain GPT/hybrid model and never consulted the command line, even when --vision-model-type was passed. Their keys are LLaVAModel's own (language_model.*, vision_model.*, vision_projection.*), which is the MIMO checkpoint model with every prefix mapped to itself. When the checkpoint has no saved args and --vision-model-type is passed, build that model, with the architecture taken entirely from the command line.
