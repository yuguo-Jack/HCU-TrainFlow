# [Dev] Add identity hyper-connections (iHC)

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8131) · state: open · merged: False

## Original PR description

## Summary

Adds an identity hyper-connections (iHC) variant of mHC behind a new `TransformerConfig` flag, `enable_identity_hyper_connections` (CLI: `--enable-identity-hyper-connections`; requires `--enable-hyper-connections`).

With the flag on, `HyperConnectionModule` fixes the residual mixing matrix `H_res` to the `n x n` identity instead of the Sinkhorn-projected manifold matrix:

- `mapping_proj` only produces `H_pre` and `H_post` (`2n` outputs instead of `n^2 + 2n`); `alpha_res` and the `H_res` part of `bias` are not created.
- The `H_res` projection and the Sinkhorn-Knopp step are skipped entirely; `compute_mappings` materializes a per-token identity `[s, b, n, n]` in the activation dtype.
- The downstream `H_res` / `H_post` / BDA path (`fused_h_res_h_post_bda`, native and fused `h_post_bda` kernels, mHC recompute, CUDA graph plumbing) is unchanged and consumes the identity as-is. Kernel-level shortcuts for the identity case are left for a follow-up.
- With `use_fused_mhc=True`, aggregate and `h_post_bda` stay fused; the projection takes the native path because the fused `proj_rms_compute_h` kernel assumes the mHC output layout.

The resulting propagation is `x_{l+1} = x_l + H_post^T @ F(H_pre @ x_l)`.

## Test plan

- New `tests/unit_tests/transformer/test_identity_hyper_connection.py`:
  - config validation, parameter layout (`2n` rows, no `alpha_res`), identity `h_res` in fp32 / bf16, empty-sequence forward/backward
  - output equals `x_l + H_post^T (F + bias)` stream by stream
  - iHC matches mHC whose Sinkhorn output is forced to the identity (outputs and gradients)
  - `_forward_with_checkpoint` matches `_forward_normal` under `MHCCheckpointManager`
  - `use_fused_mhc=True` path, and `HyperConnectionTransformerLayer` forward/backward with and without `recompute_modules=[mhc]`
- Existing mHC unit tests are unaffected (default flag is off; mHC parameter layout and code path unchanged).
- `black` / `isort` / `ruff` / `pylint` / copyright check pass against `dev`.
