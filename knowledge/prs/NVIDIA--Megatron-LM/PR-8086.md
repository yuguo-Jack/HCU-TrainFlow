# Respect lambda and comprehension bindings in process-group checks

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8086) · state: open · merged: False

## Original PR description

The process-group usage checker resolves lambda arguments and comprehension targets as if they belonged to the enclosing scope, causing false violations when these local values share an imported module name. Track expression scope bindings while evaluating the first comprehension iterable in its enclosing scope.

Validation: regression fails on baseline and both new tests pass after the fix, including five shadowing forms and preservation of detection in the outer iterable. All 29 existing stdlib checker tests pass. CPU-only; no GPU training run.

Follow-up review validation: Only immediate comprehensions use preceding imports; deferred lambdas/generators retain later binding visibility. Attribute/subscript target reads are not treated as local names. Five focused methods and all 29 existing checker tests pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
