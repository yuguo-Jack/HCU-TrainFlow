# Check process-group calls in function annotations

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8088) · state: open · merged: False

## Original PR description

Function parameter and return annotations are evaluated in the surrounding scope on supported Python versions, but the process-group checker skips them when overriding the function visitor. Inspect those expressions before entering the function body scope.

Validation: four annotation forms fail baseline detection and pass with the fix. The 29 existing stdlib checker tests also pass. CPU-only checker validation; no GPU run.

Follow-up review validation: Postponed annotations are excluded while defaults and decorators remain checked. Three focused methods and all 29 existing checker tests pass.

Review requested: @NVIDIA/mcore-oncall. This PR is ready for review with CPU regression evidence above. Upstream runner validation remains subject to NVIDIA contributor vetting.
