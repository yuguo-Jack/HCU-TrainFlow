# Let clip_qk reduce over the model's data-parallel group

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8043) · state: open · merged: False

## Original PR description

**Why.** `clip_qk` reduces the maximum attention logits over the global DP x CP group. A model on its own grid then reduces over another grid's ranks, so ranks holding the same attention weights can clip them differently, and the global grid must exist.

**What.**
- `clip_qk(model, log_max_only=False, *, dp_cp_group=None)`. Without a group it uses the global GTP-inclusive DP x CP group, as before.
- `train_step` passes the model's `dp_cp_gtp_remat` group, or `dp_cp` when the collection does not set it, the same choice it makes for the reported loss.

**Tests.** `test_qk_clip.py` reduces over a two-rank group with the global accessor patched to raise, and checks the default. `test_train_step_qk_clip_group.py` checks that `train_step` passes the model's group, with and without `dp_cp_gtp_remat`. They fail on main and pass here on 4 GPUs.

**Compatibility.** On the standard grid the group is the same. Callers that pass no group keep the global default.
