# Add output gating to absorbed MLA

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8008) · state: open · merged: False

## Original PR description

## Summary

Main counterpart of #8006. Enable `attention_output_gate` in absorbed MLA, including the default DSA training path, with headwise and elementwise gates applied before the output projection.

Determinism-test infrastructure prerequisite: #8007 (kept outside this feature commit).

## Changes

- Add sharded gate projections to the GPT and hybrid training DSA specifications, including input saving for recomputation and the new projection's deferred weight gradients.
- Share FP32 sigmoid output gating with regular Attention while preserving casting and compilation policies. Absorbed elementwise gates remain eager; headwise gates use the compiled MLA sequence.
- Add the gate granularity option and explicitly reject gating in ordinary/fused MLA and the hybrid ordinary-MLA inference path, which main does not support.
- Add independent numerical and distributed regressions plus registered bit-exact replay coverage for the actual compiled gate paths.
- Skip the optional cuDNN parity case when CUDA, SM90+ hardware, or its kernel dependencies are unavailable; supported environments still exercise the real fused path.
- Update the existing DSA module-spec regression to validate the added gate projection alongside the Q/KV/output projections.

## Test plan

- The complete existing attention module-spec file rerun after adding the gate expectation: all 8 H100 ranks passed 46 cases, with no skips or failures. The corrected projection-slot case explicitly passed. This run used the original main test fixture without the #8007 overlay.
- The guard matches dev exactly. Isolated control-flow checks cover unavailable CUDA, SM80, and each missing dependency on both branches; the shared behavior was also verified with an actual missing-FlashMLA dev run.
- After the availability update, the cuDNN parity case passed on all 8 H100 ranks, including the original numerical, gradient, and fused-kernel assertions.
- Full suite before the availability guard, using the canonical unit-test runner on 8 H100 GPUs: every rank passed 76 feature cases with no skips (34 output-gate, 38 DSA/guard/deferred-projection, and 4 bit-exact replay cases). Kernel manifest checks passed separately. The determinism replay run includes the independent fixture fix from #8007.
- Isolated gate outputs and VJPs match independent frozen primitives with zero tolerance. DSA parity includes the real fused cuDNN path, TP/SP/CP, packed sequences, selective recomputation, disabled gating, and checkpoint shard metadata.
- The new gate projection's real TE deferred queue and gradients match immediate execution. These tests do not assert support for main's complete DSA deferred-gradient path, which has existing KV-up/indexer scheduling gaps.
- `CHECK_ONLY=true BASE_REF=main bash tools/autoformat.sh` passed Black, isort, Pylint, and Ruff; the kernel determinism coverage check passed without exemptions.

GPU validation ran the exact main-port source on main `724886e5` in the cached CI-derived environment: Torch 26.04, TE 2.14, cuDNN frontend 1.28, CUTLASS DSL 4.5, and pytest 8.3.5. This is not validation of a fresh install from main's current lockfile (26.08 image, TE 2.20.2, frontend 1.29, CUTLASS DSL 4.8, and pytest 9.1.1).
