# What does this PR do?

The `sequence_modes` property currently asserts the NumPy array itself. Multiple items raise an ambiguous-truth-value error, and a valid single mode 0 is rejected. Check for `None` instead, preserving the existing unimodal rejection while returning valid empty and nonempty mode arrays.
