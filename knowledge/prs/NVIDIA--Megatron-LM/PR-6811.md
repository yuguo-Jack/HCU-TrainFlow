# What does this PR do?

ModelOpt pruning needs a hybrid model whose MoE experts use separate linear layers instead of grouped GEMM. This change adds a statically composed `hybrid_stack_spec_no_moe_grouped_gemm` next to the existing grouped-GEMM spec.

Callers choose the named spec at model construction time, so the exact implementation remains visible from the module spec and does not switch from a runtime boolean. The existing `hybrid_stack_spec` behavior is unchanged. ModelOpt now reuses the shared static spec instead of maintaining a partial duplicate, and the Mamba compatibility name is retained.
