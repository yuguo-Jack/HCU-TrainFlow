[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/8079) · state: open · merged: False

## Original PR description

The direct result discovery fallback omits generations*.json even though log-based discovery and the statistics aggregator support inference generation output. Include the same inference filename pattern so a results directory without batch .out files can produce statistics.

Validation: the new CPU discovery regression fails on the baseline; both statistics utility tests pass with the fix. Black, isort and Ruff passed. GPU training was not run.
