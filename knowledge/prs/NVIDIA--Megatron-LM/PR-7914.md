# feat(rl): add shared-prefix packing and hybrid model execution

[Upstream PR](https://github.com/NVIDIA/Megatron-LM/pull/7914) · state: open · merged: False

## Original PR description

GRPO and multi-completion PPO batches can contain several answers to the same prompt. This adds opt-in shared-prefix packing and hybrid model execution so completions reuse the prompt while keeping independent causal suffixes.

`megatron.rl` owns the reusable tree descriptors, source-row/loss maps, packing plans, tensor materialization, TP/CP geometry, real-row alignment and dense reconstruction. It accepts ordinary metadata/tensors without a NeMo RL or Ray dependency. Parent-linked descriptors and reference masks support arbitrary-depth trees; the model backend accepts contiguous stars/forests with unpadded roots and rejects unsupported lowering. The matching MCore wheel must be installed in both planning drivers and model workers.

Attention reuses prefix keys/values and accumulates branch gradients into the prefix. Mamba shares the chunk-aligned prompt state, forks branches, and retains prompt-tail replay and convolution halos. Logical multiplicities preserve MoE accounting and recomputation scope. MTP uses dense expanded branches with auxiliary-loss grouping. Ordinary dense execution remains the default, and unsupported model/layout/training combinations fail explicitly.

The cleanup removes redundant packing and inactive MTP/attention paths while preserving default attention arithmetic and both planners. Three default-off attention experiments are deferred: `NRL_SP_FUSED_KV_GATHER`, `NRL_SP_FUSED_BACKWARD_GLUE` and `NRL_SP_FUSED_DQ_ASSEMBLY`. Enabling a deferred option or specifying its retired merge-tile controls raises an explicit error. The CP replay and packed-fused diagnostic entry points remain available.

Validation:

- Portable packing, tensor/tree, adapter, MTP/branch and import-guard contracts pass, together with configured formatting and lint. Default attention numerical ASTs and planner behavior match the retained implementation.
- Four GB200 workers completed native CP1 attention validation with BF16/FP16 outputs and every Q/K/V gradient byte-exact: 128 diagnostic comparisons and 96 production-default comparisons per worker. This qualifies the pinned attention cleanup; CP collectives and full-model training require separate evidence.
- All four GB200 workers passed the checked-in native replay suite: **126 tests per worker**, with no failures, skips or deselections. It uses independent numerical references, actual import guards, stream contention and real NCCL CP1/2/4 execution. The registration reduces kernel determinism coverage debt from 13 issues to **12**, with no exemptions; the full gate still fails. The allocation and every Slurm step completed `0:0` (HSG job `7819363`, 10m44s).
- Existing tiny PPO tree/packing overlays completed real actor updates. Those receipts apply to their pinned sources and configurations; combined current-main distributed model and GRPO/PPO qualification remains pending.

This remains a draft. Current-main full-model CP/TP/EP, Mamba, training/evaluation, dense/shared numerical acceptance and maintainer review remain required. Existing dense/shared backbone-gradient differences remain unresolved.

Companion integration: [NeMo RL #4537](https://github.com/NVIDIA-NeMo/RL/pull/4537), with [DP output ordering #4536](https://github.com/NVIDIA-NeMo/RL/pull/4536). [HybridEP capacity alignment #7913](https://github.com/NVIDIA/Megatron-LM/pull/7913) has separate allocator/dispatch qualification. Layout context: [#7386](https://github.com/NVIDIA/Megatron-LM/issues/7386).

Diff accounting versus `cff9cf4e`: **10,096 additions**, including **2,112 lines under `tests/`** (24 are manifest registration; 2,088 are test source). This cleanup removes **675 runtime lines**, retains every prior test, and adds 447 lines of test coverage and registration. Its net diff reduction is 213 lines after tests and documentation.
