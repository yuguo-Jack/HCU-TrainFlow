## Pull request overview

This PR adds WandB (Weights & Biases) integration for MaxText backend training, complementing the existing TorchTitan WandB support. The implementation includes default configuration values, metrics logging, and environment variable setup for WandB.

**Key Changes:**
- Added WandB metrics logging for MaxText backend via custom `PrimusMetricLogger`
- Set default WandB configurations (project name, run name) based on experiment metadata
- Added `enable_wandb` configuration flag with default value of `false`

## Explicit returns mixed with implicit (fall through) returns

Mixing implicit and explicit returns may indicate an error, as implicit returns always return None.

---

<p>To fix this issue, we should ensure that all control-flow paths of <code>initialize_wandb_writer</code> use explicit returns, either <code>return wandb</code> when wandb is initialized, or <code>return None</code> otherwise (e.g. for processes with index other than 0, or in any possible early exit or fallthrough). In the current function, if the first <code>if</code> condition on line 55 (<code>if jax.process_index() != 0:</code>) is true, we already use an explicit <code>return</code>. The main missing piece is an explicit <code>return None</code> at the end of the function to catch any fallthrough paths that could implicitly return None.</p>
<p>Therefore, add an explicit <code>return None</code> at the end of the function after line 88.</p>
<p>No new imports or method definitions are necessary.</p>
