## Pull request overview

This PR introduces stage-based trainer registration to the BackendRegistry, enabling backends to register multiple trainers (e.g., pretrain, sft) under a single backend name using a (backend, stage) composite key.

**Changes:**
- Modified trainer registration to use composite keys (backend, stage) instead of backend-only keys
- Updated all trainer registration and retrieval calls to accommodate the new signature
- Added test coverage for stage-based trainer registration

- Copilot · comment · 2026-01-29T05:14:27Z · [source](https://github.com/AMD-AGI/Primus/pull/523#discussion_r2739984346)

File: `primus/backends/megatron_bridge/__init__.py` · line 22

The registration uses 'sft' as the stage, but the config references use 'post_trainer' and the trainer is named 'MegatronBridgePosttrainTrainer'. This mismatch between naming conventions could cause confusion. Consider either: (1) changing the stage to 'posttrain' to match the trainer name, or (2) renaming the trainer to MegatronBridgeSFTTrainer to match the stage name.
```suggestion
BackendRegistry.register_trainer_class(MegatronBridgePosttrainTrainer, "megatron_bridge", "posttrain")
```

- Copilot · comment · 2026-01-29T05:14:27Z · [source](https://github.com/AMD-AGI/Primus/pull/523#discussion_r2739984364)

File: `primus/core/backend/backend_registry.py` · line 121

The order of operations has been reversed compared to the original code (setup_backend_path was Step 1, now it's Step 2). The comment 'Step 2' is assigned to resolved_path but it's never used after assignment. Consider either removing the unused variable or documenting why the order was changed.

- Copilot · comment · 2026-02-02T03:18:27Z · [source](https://github.com/AMD-AGI/Primus/pull/523#discussion_r2752374896)

File: `primus/backends/megatron_bridge/__init__.py` · line 22

The third parameter should use the keyword argument 'stage=\"sft\"' for clarity and consistency with the function signature, especially since 'sft' doesn't match the trainer class name suffix 'Posttrain'.
```suggestion
BackendRegistry.register_trainer_class(MegatronBridgePosttrainTrainer, "megatron_bridge", stage="sft")
```
