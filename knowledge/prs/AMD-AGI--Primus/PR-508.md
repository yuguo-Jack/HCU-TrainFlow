# tests: run megatron/torchtitan trainer UT via primus-cli direct (instead of run_pretrain.sh)

[Upstream PR](https://github.com/AMD-AGI/Primus/pull/508) · state: closed · merged: True

## Original PR description

## What
Switch Megatron trainer unit tests to invoke the unified CLI entrypoint:
`bash ./runner/primus-cli direct -- train pretrain --config <exp> ...`
instead of the legacy `bash examples/run_pretrain.sh`.

## Why
- Keep UT entry consistent with Primus CLI design (single entry point).
- Reduce reliance on the legacy bash wrapper.
- Preserve the existing UT behavior pattern (runtime output + optional TRAIN_LOG read).

## Changes
- Update `tests/trainer/test_megatron_trainer.py` to:
  - use `./runner/primus-cli direct -- train pretrain --config <exp_path>`
  - keep reading `TRAIN_LOG` when present (same pattern as other trainer UTs)

## Test Plan
- `pytest -q tests/trainer/test_megatron_trainer.py` (environment permitting)
