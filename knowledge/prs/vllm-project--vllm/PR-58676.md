# [Test][Hybrid] Add TP2 Mamba2 prefix-cache hit regression

[Upstream PR](https://github.com/vllm-project/vllm/pull/58676) · state: open · merged: False

## Original PR description

## Purpose

Adds a TP=2 Mamba2 prefix-cache regression using `Zyphra/Zamba2-1.2B-instruct`, addressing the “Test TP>1 behaviour” work item in #26201 for align mode.

The test runs cold, warm, and cache-read-bypassed requests in one engine. It requires a non-empty warm cache hit, verifies zero cached tokens for cold and bypass requests, and compares warm versus bypass output token IDs and chosen-token logprobs at every generated position.

Uses the existing two-GPU distributed test marker and CI lane. Coverage is limited to this Mamba2 hybrid model with TP=2 and the default align mode. No production code or CI configuration changes.

Duplicate-work checks found no equivalent open regression test. #45575 addresses block-size alignment, while #56291 reorganizes the existing hybrid tests.

## Test Plan

Run the targeted test on two GPUs:

```sh
CUDA_VISIBLE_DEVICES=4,5 VLLM_USE_FLASHINFER_SAMPLER=0 \
.venv/bin/python -m pytest \
  tests/models/language/generation/test_hybrid.py::test_zamba2_mamba2_align_apc_tp2_cache_hit \
  -v -s
```

Run static checks:

```sh
ruff check tests/models/language/generation/test_hybrid.py
ruff format --check tests/models/language/generation/test_hybrid.py
```

Verify collection under the existing CI selector:

```sh
.venv/bin/python -m pytest --collect-only -q \
  tests/models/language/generation/test_hybrid.py::test_zamba2_mamba2_align_apc_tp2_cache_hit \
  -m 'distributed(num_gpus=2)'
```

Check test sensitivity by temporarily disabling prefix-cache reads for the warm request. This mutation is not included in the patch.

## Test Result

- Targeted pytest passed on 2× NVIDIA L20: `1 passed, 14 warnings in 60.49s`, with no skips.
- Logs confirmed `Zamba2ForCausalLM`, TP=2, and align cache mode.
- A separate metrics run recorded cold/warm/bypass cached tokens of `0 / 2016 / 0`, matching output token IDs at all 16 positions, and a maximum chosen-token logprob difference of `0.0`.
- The temporary cache-read mutation failed at the non-empty-hit assertion.
- Ruff check and format check passed.
- The new test was collected by the two-GPU distributed selector.

Local validation used Python source at `8b365ff94926` with native core/MoE libraries built from `c9611215195e`. Compilation and CUDA graphs remained enabled.
