# [CI][ROCm] Add AITER nightly overlay scripts

[Upstream PR](https://github.com/vllm-project/vllm/pull/60883) · state: open · merged: False

## Original PR description

## Overview

Adds the two scripts to be used for the AMD CI AITER nightly: they let CI test vLLM against the latest [AITER](https://github.com/ROCm/aiter) nightly wheels instead of the AITER version baked into the ROCm `ci_base`. ci-infra's AMD template runs them when `AITER_NIGHTLY=1` (vllm-project/ci-infra#733). Must be run within `AMD-CI` pipeline.

## Claims

- With `AITER_NIGHTLY=1` builds within `AMD-CI` will have `ci_base` will run with the newest AITER nightly wheel installed over it. Leaving this unset, nothing changes. Setting `AITER_NIGHTLY=1` in other buidlkite pipelines will do nothing here, bootstrapped to `AMD-CI` pipeline only.
- The wheel is chosen to match the image, so it can't be a mismatched ROCm, torch or Python build.

## Validation

- Build with `AITER_NIGHTLY=1`: <https://buildkite.com/vllm/amd-ci/builds/14397>.
- Build without `AITER_NIGHTLY`: <https://buildkite.com/vllm/amd-ci/builds/14403>. 

## Details

**Merge order:** this should merge before vllm-project/ci-infra#733, which runs these scripts.
