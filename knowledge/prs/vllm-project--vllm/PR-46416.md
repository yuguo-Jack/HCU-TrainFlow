# [rust][tool-parser] Add streaming invariant tests

[Upstream PR](https://github.com/vllm-project/vllm/pull/46416) · state: open · merged: False

## Original PR description

## Overview

Adds deterministic streaming/complete invariant coverage for Rust tool parsers, related to #44280. This PR changes test infrastructure and corpus tests only.

## Claims

- Checks MiniMax M2, DeepSeek V3.2, Gemma4, Kimi K2, and Qwen Coder.
- Compares whole-text parsing with one-chunk input, every internal Unicode character-boundary split, and adjacent two-boundary splits.
- Covers plain text, parallel calls, Unicode, parameterless calls, surrounding text, marker-like values, and malformed or incomplete input.

## Validation

Rebased onto `main` at `a98247ab4db686ee03c66d5feb3c761e52a2f8ab` on October 10. The Qwen test conflict was resolved by preserving upstream's schema-reference regression alongside the streaming invariant test and retaining both imports.

Using the repository's pinned Rust 1.95 toolchain:

```bash
cargo test --manifest-path rust/Cargo.toml -p vllm-parser
# 558 passed, including all five streaming/complete invariant tests
# One existing doctest ignored
cargo fmt --manifest-path rust/Cargo.toml --all -- --check
cargo clippy --manifest-path rust/Cargo.toml -p vllm-parser --all-targets -- -D warnings
git diff --check upstream/main...HEAD
```

All commands passed. No model evaluation or GPU run was performed because this PR changes tests only.

## Details

The shared helper compares final coalesced output after `finish()`, allowing legitimate differences in intermediate deltas. Malformed-input cases check that streaming and whole-text parsing agree on success or failure.

Duplicate-work check: the helper and these corpora are absent from current main. Related Python parser-engine changes such as #46274 and #46351 do not cover Rust `vllm-parser` invariants.

AI assistance was used for implementation, rebase, and validation. The human submitter remains responsible for reviewing the changed lines and defending the contribution.
