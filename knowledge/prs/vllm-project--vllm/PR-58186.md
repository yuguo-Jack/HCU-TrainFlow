# [Frontend] Stream /v1/translations for the encoder-decoder direct path

[Upstream PR](https://github.com/vllm-project/vllm/pull/58186) · state: closed · merged: False

## Original PR description

Adds SSE streaming to the encoder-decoder direct-generate path of the text `/v1/translations` endpoint (it previously returned a 400 for `stream: true`).

- When `stream=true`, sampling params request incremental `DELTA` outputs; each `RequestOutput` is forwarded verbatim as a `translation.chunk` delta (no per-chunk stripping, which would corrupt token spacing). The stream ends with `data: [DONE]`.
- Setup errors (no engine client, unsupported target language) are still returned synchronously as an `ErrorResponse` before streaming starts, so an unknown target yields a clean 400 rather than a half-open stream.
- A generation error mid-stream is emitted as a single error data line so the client is not left hanging.

Adds 2 GPU-free unit tests (SSE chunking + DELTA output-kind, streaming unknown-language → synchronous 400) and replaces the old streaming-rejection test.

> Stacks on #58174; review that first.
