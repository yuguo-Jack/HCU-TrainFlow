# [EPLB] Add EPLB support to dspark draft models (DeepSeekV4)

[Upstream PR](https://github.com/vllm-project/vllm/pull/57549) · state: open · merged: False

## Original PR description

## Purpose
Enable EPLB for DSpark draft models on DeepSeek V4.

DSpark MoE drafters now implement MixtureOfExperts, so EPLB can register and rebalance draft experts alongside the target model when using --enable-eplb with DSpark speculative decoding. 

Dsv4.1 Dspark draft is not supported because EPLB requires target and draft models have the same number of routed experts.
Add logging of draft models to distinguish eplb run of target and draft models.

Scope / what does not need changes:

- Other DSpark drafts (Qwen3, Gemma4, K3 MLA) — dense drafts with no MoE layers; EPLB on the draft is N/A. If the target is MoE, existing target-side EPLB is unchanged.
- DSV4 DSpark on AMD/XPU those platforms don’t yet expose MixtureOfExperts on the target path either.

## Test Plan
- test_dspark_draft_registers_mixture_of_experts — draft model exposes MixtureOfExperts
- test_eplb_registers_dspark_draft_model / test_eplb_skips_dspark_registration_with_dummy_weights — EPLB controller registers DSpark draft
- test_v2_load_model_registers_dspark_speculator_with_eplb — v2 GPU model runner wires speculator EPLB at load
