# [ROCm][MLA] Keep DCP prefill context in FP8 through AllGather

[Upstream PR](https://github.com/vllm-project/vllm/pull/59070) · state: open · merged: False

## Original PR description

## Overview

Keep ROCm MLA's cached DCP context in FP8 through AllGather, then use AITER's fused gather/projection kernel to expand it into K/V. This removes the BF16 communication payload and separate reorganization, dequantization, projection and packing operations for supported configurations.

```diff
 local cached context
-  gather/dequant → BF16 AllGather → reorg → kv_b_proj → K/V pack
+  gather bytes → FP8 AllGather → fused reorg/dequant/kv_b_proj/K/V pack
```

## Claims

- Halves AllGather bytes for the same padded row count, preserving the existing FP8 cache bytes, workspace capacity, chunking and merge plan.
- Falls back to the original path for unsupported cache formats, dimensions, dtypes or projection layouts. The optional upstream K/V concatenation callback is forwarded on that fallback.
- Historical full-model K3 measurements below show unchanged aggregate GSM8K accuracy and lower cached-prefix TTFT with **both this PR and #59069**. Those measurements do not isolate this PR's end-to-end contribution or validate the current rebased head.

## Details

A compact row map is built once per metadata step; the shared eligibility check prevents unnecessary map construction for unsupported configurations. Expose the AITER operation through `_aiter_ops.py`, including mutation declarations, fake implementation and opcheck coverage. The required kernel was already present in main's pinned AITER `v0.1.23`; this PR requires no AITER bump or PD connector changes.

Duplicate checks covered #50682, #53166, #56881 and #52239. #53166 enables the AITER gather path only at DCP=1; #56881 packs already-projected K/V in the NVIDIA path; #52239 uses NVIDIA symmetric-memory multicast. This change supplies ROCm compressed AllGather plus fused expansion at DCP>1.

Rollback is a two-way change: no checkpoint or cache format changes; reverting restores the original computation path. Impact is limited to ROCm MLA DCP prefill. AI assistance (OpenAI Codex) was used for implementation, analysis and validation.
