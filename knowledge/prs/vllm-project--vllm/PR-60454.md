## Original PR description

## Overview
Extract the opt-in sparse decode runtime path from #54955 and Draft #59883. `VLLM_DS4_DECODE_KERNEL=sparse` selects the prefill-style FlashMLA path; `paged` remains the default.

## Claims
- Reuse the C4/C128 decode index operators and graph-stable metadata from the earlier P2 splits.
- Keep sparse decode opt-in and reject unsupported scheduler metadata.
- Reuse existing test files; add no binding, shared library, or test file.

## Validation
- H100 environment: 5 targeted decode routing tests and 1 environment-variable test passed. Tests used a previously compiled integration extension, not a native rebuild of this isolated branch.
- Ruff lint/format and `git diff --check` passed.
- Full-path GPU and model-level evaluation of the combined P2 splits remains pending.

## Details
This is the runtime portion of Draft #59883, based directly on main. Complete batch-invariant behavior requires P2-01 #60442, P2-02 #60443, P2-03 #60444, and P2-04; this PR should remain Draft until their combined path is validated. AI assistance was used; the submitter should review the diff and validation before requesting review.
