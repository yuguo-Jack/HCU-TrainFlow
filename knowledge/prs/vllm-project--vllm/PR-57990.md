# [Bugfix] [Frontend] Preserve prompt_logprobs in /v1/completions/derender

[Upstream PR](https://github.com/vllm-project/vllm/pull/57990) · state: open · merged: False

## Original PR description

Fixes #57929

**What/Why:** Non-streaming `/v1/completions/derender` returned `prompt_logprobs: null` — `OnlineDerenderer._derender_completion` built each choice without the field, discarding data the engine had already computed. The chat derender path and direct `/v1/completions` already pass it through.

**How:** One line in `vllm/renderers/online_derenderer.py` — attach `gen.prompt_logprobs` to every choice of that response (per-prompt semantics identical to the direct endpoint), plus regression test 

**Updated:** Chat fills `prompt_logprobs` inside `_derender_chat`, in the same background call that decodes the text 

`test_derender_completion_prompt_logprobs_passthrough` in `tests/entrypoints/scale_out/derender/test_derender.py` (fails on unfixed code, passes after).


**Tests:** `pytest tests/entrypoints/scale_out/derender/test_derender.py` → 37/37 passed locally; pre-commit clean; GPU parity suite left to CI. Not model-affecting (frontend response assembly only).
