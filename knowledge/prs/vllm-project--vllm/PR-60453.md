# [DeepSeek-V4-P2-04] Isolate deterministic sparse top-k selection

[Upstream PR](https://github.com/vllm-project/vllm/pull/60453) · state: open · merged: False

## Original PR description

## Overview
Extract the deterministic sparse top-k selector from #54955 and Draft #59883. Batch-invariant prefill and decode use the same request-local score and index ordering.

## Claims
- Register the original CUDA selector in vLLM's stable `_C` extension; leave non-BI selection unchanged.
- Reject unsupported BI DCP/PCP selection instead of silently changing the numerical contract.
- Reuse the existing top-k test file; add no test file.

## Validation
- H100: targeted top-k tests, 7 passed. Tests used the previously compiled integration extension containing the same CUDA kernel; this isolated branch was not rebuilt natively.
- Ruff lint/format and `git diff --check` passed.
- Full-model evaluation remains pending.

## Details
This is the selector portion of Draft #59883, based directly on main. It avoids carrying P1's quantization code into this PR. AI assistance was used; the submitter should review the diff and validation before requesting review.
