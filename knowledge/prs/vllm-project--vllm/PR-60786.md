# [Frontend] Add cache salt and tracing to structured decisions

[Upstream PR](https://github.com/vllm-project/vllm/pull/60786) · state: closed · merged: True

## Original PR description



## Overview

Follow-up to #59299 for the `cache_salt` and trace header support requested in [review](https://github.com/vllm-project/vllm/pull/59299#pullrequestreview-5453057353).

`/v1/systemone` now accepts a cache salt and forwards incoming trace headers to each question's engine request.

## Claims

- Validates `cache_salt` with the shared validator and applies it to every question's prompt.
- Forwards `traceparent` and `tracestate` when tracing is enabled. Other HTTP headers are excluded.

## Validation

- Structured-decision tests and shared request-validation tests passed.
- Ran `Qwen/Qwen3-0.6B` and checked cache salt handling and trace propagation through `/v1/systemone`.

## Details

The endpoint did not expose `cache_salt` or forward incoming trace headers. This change validates the salt and propagates both through the read strategy to every question's engine request, using the existing renderer and tracing helpers.
