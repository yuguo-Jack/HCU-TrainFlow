# [Model] Add NLLB / M2M100 encoder-decoder translation model

[Upstream PR](https://github.com/vllm-project/vllm/pull/58110) · state: closed · merged: False

## Original PR description

## Summary
Add NLLB-200 / M2M100 (`M2M100ForConditionalGeneration`) as an encoder-decoder translation model. The single architecture serves both the NLLB-200 and M2M100 checkpoint families; the family is selected from the tokenizer at runtime.

## Details
- New `vllm/model_executor/models/nllb.py` following the Whisper enc-dec pattern (registered via `@MULTIMODAL_REGISTRY.register_processor`, source text fed through `create_encoder_prompt`, forced decoder-start via `create_decoder_prompt`). Pre-norm layers, a final layer norm, and computed sinusoidal positions; tied shared embeddings + LM head with no `final_logits_bias`. Shares MarianMT's structure.
- Registered `M2M100ForConditionalGeneration` in the model registry.
- Added an `_HfExamplesInfo` entry (NLLB-200 primary, M2M100 as an extra) for test coverage.

## Test
- `tests/models/test_registry.py` passes for `M2M100ForConditionalGeneration`.
- Registration + arch resolution verified (engine detects encoder-decoder).
