## Details

Server metrics can report cache hits while API cache fields are absent because response accounting is opt-in. The guide now names the flag, each endpoint's fields, the Anthropic input-token subtraction and how to request streaming usage. It also documents checkpoint retention's default and accepted values, unaffected cache groups and startup validation.

The refresh preserves the `--enable-mamba-shared-prefix-checkpoint` rename from merged #57382. This PR changes one documentation file, adding 44 lines; it does not change the existing Hybrid Mamba guidance.
