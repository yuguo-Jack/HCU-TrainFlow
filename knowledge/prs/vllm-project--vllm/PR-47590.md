# [Bugfix][Pooling] Forward instruction to Jina reranker scoring prompts

[Upstream PR](https://github.com/vllm-project/vllm/pull/47590) · state: closed · merged: True

## Original PR description


## Purpose

`/v1/score` and `/v1/rerank` expose `instruction` for task-specific reranking, and the request model already folds it into `chat_template_kwargs`. The Jina reranker path builds its own prompt and did not pass that value into the existing formatter, so `jinaai/jina-reranker-v3` accepted instruction requests with HTTP 200 while scoring the default prompt.

This PR forwards the normalized instruction into the Jina prompt formatter for both one-query-many-docs and paired query/doc requests. Requests without instruction keep the same prompt.

## Test Plan

Validate the real OpenAI server with `jinaai/jina-reranker-v3` by sending the same `/v1/score` and `/v1/rerank` payloads with and without `instruction`. Revert the fix and rerun the same server repro to confirm that instruction becomes a no-op again. Run scoped ruff on the changed file.

<summary>💡 Fix Suggestion</summary>

**Suggestion:** Replace the single-pass `str.replace` with a loop that repeatedly removes each special token until none remain. This prevents recursive/nested token patterns (e.g., `<|<|embed_token|>embed_token|>`) from surviving sanitization. Change the `sanitize_input` function to use a `while` loop for each token:

```python
def sanitize_input(text: str) -> str:
    for token in special_tokens.values():
        while token in text:
            text = text.replace(token, "")
    return text
```
