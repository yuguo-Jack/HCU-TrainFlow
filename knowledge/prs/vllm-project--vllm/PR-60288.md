## Overview

Add seeded, single-forward Nemotron masked decision reads and adapt the existing structured diffusion example gateway for Choice, Noul and Score. This PR targets upstream main and depends on #58387 and #60287. Tracking: #60283.

[Review the isolated decision delta](https://github.com/pst2154/vllm/compare/d3df247914bbc43ebc82957cc67afe23c6b1b2d9...98d1cfc0394ddf57f7befa498d47d638afb49a77). The main comparison temporarily includes the unmerged dependencies. This reuses the existing gateway instead of introducing a competing native endpoint.

## Claims

- Keep fixed template tokens while scoring masked answer positions in one bidirectional forward after causal prefill, without a causal verification/commit pass.
- Return exact requested candidate logprobs through the existing indexed-logprob machinery, including candidates outside top-k.
- Validate seeded reads against the engine canvas before worker execution.
- Reuse `structured_server.py --backend nemotron` for the separate `/v1/systemone` example gateway. This is not a route built into `vllm serve`.

No ordering heuristics or linear-speculation code are included. The model-runner and its state interface are unchanged.

## Details

The sampler uses staged writes, existing request-slot state and `compute_topk_scores`; read flags and seed canvases reset on slot reuse. The engine canvas is explicitly passed through admission validation. This validation plumbing belongs to the decision PR now that the former linear-speculation plumbing is removed from its dependency.

Reads require greedy masked diffusion, the full engine canvas and `max_tokens <= canvas_length`. The example supports text/JSON state, at most 64 questions and 26 alternatives, one compatible token per answer slot and one deterministic sample. Thinking, images and multi-step reads are unsupported. Returned probabilities are uncalibrated model scores. A graph boundary avoids the previously reproduced SM100 compiler issue but can add launches; no end-to-end speedup is claimed. RTX was not validated.

Rebase and rerun affected CUDA/HTTP validation after the dependencies land. Codex assisted with the implementation, rebase, checks and review update; human review and confirmation of relevant validation remain necessary before merge.
