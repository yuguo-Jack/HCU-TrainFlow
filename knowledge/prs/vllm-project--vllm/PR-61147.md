# [Bugfix][Tool Calling] Fix doom loop with strict-mode empty-argument tools

[Upstream PR](https://github.com/vllm-project/vllm/pull/61147) · state: open · merged: False

## Original PR description

## Summary

- Fixes infinite generation loop (token 197 / tab) when a tool has `strict: true` and empty parameters (`{"type": "object", "properties": {}, "required": []}`)
- The xgrammar grammar for such schemas only accepts whitespace, causing the model to generate tabs forever
- Both the xgrammar-builtin path (`_dump_tool_for_xgrammar`) and the vLLM-defined structural tag path (`get_function_parameters`) now treat empty-properties schemas as unconstrained, since the only valid output is `{}`

## Test plan

- [ ] Verify with Qwen 3.x model and a tool with empty properties and `strict: true`
- [ ] Verify that tools with non-empty properties and `strict: true` still work correctly
- [ ] Verify that `strict: false` tools are unaffected
