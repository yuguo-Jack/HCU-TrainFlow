# [Bugfix][NIXL] Fix receive post-process for different P/D block sizes

[Upstream PR](https://github.com/vllm-project/vllm/pull/58860) · state: closed · merged: True

## Original PR description

## Purpose

NixlConnector pull with a smaller `--block-size` on P than on D writes wrong KV on D, or crashes D when a rank holds fewer KV heads than `block_size_ratio`. The receive post-process indexes attention views as `[B, N, H, D]`; since #44455 they are `[B, H, N, 2*D]` on every layout.

- `kv_postprocess_blksize_on_receive`: drop the two "physical order" permutes. On `LBHNC` they scramble every received block; with fewer heads than `block_size_ratio` the reshape fails.
- `post_process_device_kv_on_receive`: zero the untransferred tail along the token dim, not the head dim.
- `kv_postprocess_blksize_and_layout_on_receive` (`enable_permute_local_kv`): read the received bytes in memory order before viewing them as the remote's head-major blocks. It now also serves ratio 1 and replaces `kv_postprocess_layout_on_receive`, which had the same bug and a 5-D branch from #47791 that is dead since #51718.
- `enable_permute_local_kv` is enabled only for a local `LBNHC` cache; any other local layout (e.g. head-major `BLHNC`) now fails the handshake instead of receiving wrong KV.
- HMA groups alias the same KV tensors, but each group's block ids went through every attention view, regrouping a block once per aliasing group. Each group now uses its own views.
- `LBNHC`/`BLNHC` receive the remote sub-blocks in token order; only `is_block_contiguous` layouts are regrouped.

Block lists that start or end at different tokens on P and D are paired in #59746. No other open PR changes the receive post-process.

## Test Plan

```bash
pytest tests/v1/kv_connector/unit/test_nixl_connector_hma.py -k test_post_process_zeroes_untransferred_tail
pytest tests/v1/kv_connector/unit/test_nixl_connector.py -k test_handshake_fails_on_kv_cache_layout_mismatch
```

The test now holds distinct values in a `[B, H, N, C]` cache with fewer KV heads than the ratio, aliased by two attention groups, on `LBHNC`, `LBNHC` and `LBNHC` + `enable_permute_local_kv`.

GB10: P and D on one GPU, pull, greedy, `--enforce-eager`. Each run is compared with P and D both at D's block size, without `enable_permute_local_kv`; D loads the whole prompt over NIXL, except the last token on GDN or with #59330.
