# [Feature][Ray] Make placement group strategy configurable

[Upstream PR](https://github.com/vllm-project/vllm/pull/57542) · state: open · merged: False

## Original PR description

## Summary

Adds `VLLM_RAY_PG_STRATEGY` to make the Ray placement group strategy configurable when vLLM creates a placement group.

The environment variable defaults to `PACK` to preserve the existing behavior and accepts:

- `PACK`
- `SPREAD`
- `STRICT_PACK`
- `STRICT_SPREAD`

The value is validated with the existing `env_with_choices()` helper and passed to `ray.util.placement_group()` in `initialize_ray_cluster`.

Fixes #49527.

## Why this is not a duplicate

Before opening this PR, I checked open PRs referencing #49527, open PRs containing `VLLM_RAY_PG_STRATEGY`, and open PRs related to configurable Ray placement group strategy.
