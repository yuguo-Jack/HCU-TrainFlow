# [Bugfix][Core] Close underlying iterator in merge_async_iterators single-iterator fast path

[Upstream PR](https://github.com/vllm-project/vllm/pull/44726) · state: closed · merged: True

## Original PR description


## Purpose

`merge_async_iterators` has a fast path for the single-iterator case that yields directly, without the `try/finally` cleanup the multi-iterator path uses:

```python
if len(iterators) == 1:
    # Fast-path single iterator case.
    async for item in iterators[0]:
        yield 0, item
    return
```

When the merged generator is closed (a cancelled or disconnected consumer), the underlying generator is never closed and keeps running. The multi-iterator path already `aclose()`s its iterators in a `finally`; the single-iterator path does not.

For a single-prompt request this leaves `AsyncLLM.generate()` alive: after the consumer is cancelled the request stays in the `OutputProcessor` and keeps consuming scheduler/engine resources until it finishes naturally. Single prompt is the common path for OpenAI completion/chat, pooling, scoring, etc.

Fix: wrap the fast path in `try/finally` and `aclose()` the underlying iterator, matching the multi-iterator cleanup.

This only affects the window where the consumer is cancelled after the merged generator has yielded a chunk and while it is in downstream processing. If cancellation lands while `generate()` is itself awaiting the next output, `generate()` already aborts; this is not "every single-prompt cancel leaks".

## Test Result

Unit test: passes with the fix, fails without it (`assert closed` is `False` on `main`).

Real `AsyncLLM` (TinyLlama-1.1B, single prompt, `max_tokens=min_tokens=900, ignore_eos=True` to hold the request open), consume first chunk then `await merged.aclose()`, then poll `output_processor.get_num_unfinished_requests()`:

| | unfinished after close (0.5s..3.0s) | at engine shutdown |
| --- | --- | --- |
| `main` | `[1, 1, 1, 1, 1, 1]` (lingers) | 1 in-flight request aborted |
| with fix | `[0, 0, 0, 0, 0, 0]` (cleared) | none |

<details>
<summary>repro (real AsyncLLM)</summary>

```python
import asyncio
from vllm import SamplingParams
from vllm.engine.arg_utils import AsyncEngineArgs
from vllm.v1.engine.async_llm import AsyncLLM
from vllm.utils.async_utils import merge_async_iterators

async def main():
    engine = AsyncLLM.from_engine_args(AsyncEngineArgs(
        model="TinyLlama/TinyLlama-1.1B-Chat-v1.0",
        enforce_eager=True, max_model_len=1024, gpu_memory_utilization=0.30))
    sp = SamplingParams(max_tokens=900, min_tokens=900, ignore_eos=True, temperature=0.0)
    merged = merge_async_iterators(engine.generate("Hello, tell me a long story.", sp, "r1"))
    await anext(merged)
    op = engine.output_processor
    await merged.aclose()
    series = []
    for _ in range(6):
        await asyncio.sleep(0.5)
        series.append(op.get_num_unfinished_requests())
    print(series)            # [1,1,1,1,1,1] on main, [0,0,0,0,0,0] with fix
    engine.shutdown()

asyncio.run(main())
```
