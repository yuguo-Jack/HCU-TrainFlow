# [XPU][MLA] Support FlashAttnMLA backend on XPU

[Upstream PR](https://github.com/vllm-project/vllm/pull/58297) · state: open · merged: False

## Original PR description

## Summary

- Route XPU MLA through the existing `FLASH_ATTN_MLA` backend, matching the way XPU support is integrated under `FLASH_ATTN`.
- On XPU, use `vllm-xpu-kernels` `flash_attn_varlen_func` for MLA paged decode by packing `q = [q_nope, q_pe]` and using the latent cache as K with a narrowed V view.
- Keep CUDA FlashAttnMLA behavior unchanged, including FA3 decode/LSE handling.
- Fix XPU varlen output allocation so omitted `out` tensors use the V head dimension. This is required for MLA where Q/K dim is 576 and V dim is 512, and is behavior-preserving for regular attention where `q.shape[-1] == v.shape[-1]`.

## Validation method

Run from a vLLM checkout on an Intel XPU machine with `vllm-xpu-kernels` installed or on `PYTHONPATH`.

2. End-to-end test

```bash
#!/usr/bin/env bash
set -euo pipefail

tmp_script="$(mktemp /tmp/vllm_xpu_mla_validate.XXXXXX.py)"
trap 'rm -f "${tmp_script}"' EXIT

cat >"${tmp_script}" <<'PY'
from vllm import LLM, SamplingParams

def main():
    llm = LLM(
        model="deepseek-ai/DeepSeek-V2-Lite",
        tensor_parallel_size=2,
        dtype="bfloat16",
        attention_backend="FLASH_ATTN_MLA",
        block_size=64,
        max_model_len=512,
        trust_remote_code=True,
        enforce_eager=True,
        gpu_memory_utilization=0.80,
    )

    prompts = [
        "Hello, my name is",
        "The capital of France is",
        "The future of AI in 2030 will be",
    ]
    sampling_params = SamplingParams(
        temperature=0.0,
        max_tokens=64,
        repetition_penalty=1.1,
    )
    outputs = llm.generate(prompts, sampling_params)
    for output in outputs:
        print("=" * 60)
        print("PROMPT:", output.prompt)
        print("OUTPUT:", output.outputs[0].text)

if __name__ == "__main__":
    main()
PY

python "${tmp_script}"
```

Expected result:
- Logs show `Using Flash Attention MLA backend on XPU.`
- Generation reaches `Processed prompts: 100%` and prints outputs for all prompts.

This was validated locally on 2x Intel Arc Pro B60; the run logged `Using Flash Attention MLA backend on XPU.`, completed `Processed prompts: 100%`, and generated coherent outputs for all three prompts (e.g. "Hello, my name is" -> "John. I am a 20 year old male...", "The capital of France is" -> "Paris.").

3. Compile check

```bash
python -m py_compile vllm/_xpu_ops.py vllm/platforms/xpu.py vllm/v1/attention/backends/fa_utils.py vllm/v1/attention/backends/mla/flashattn_mla.py vllm/v1/attention/backends/registry.py
```
All 5 changed files compile cleanly with no errors.

4. Accuracy

Ran `lm_eval` with `--model vllm` against DeepSeek-V2-Lite on Intel Arc Pro B60 with `attention_backend=FLASH_ATTN_MLA`:

- TP=2, `dtype=bfloat16`, `max_model_len=4096`, `enforce_eager=True`:
  - GSM8K (5-shot): `exact_match,strict-match` = 0.3723, `exact_match,flexible-extract` = 0.3783
  - MMLU: overall `acc` = 0.5895 ± 0.0277 (humanities 0.5846, other 0.5538, social_sciences 0.7667, stem 0.5053)
- DeepSeek-V2-Lite GSM8K with `ATTENTION_BACKEND=FLASH_ATTN_MLA`, TP=4, `APPLY_CHAT_TEMPLATE=0`, `NUM_FEWSHOT=5`, `MAX_MODEL_LEN=2048` completed successfully; 300-sample result was strict-match 0.3800 / flexible-extract 0.3833, consistent with the base model's expected GSM8K range.

Both are consistent with DeepSeek-V2-Lite's published reference numbers.
