# [PoC] Transfer hidden states for P/D

[Upstream PR](https://github.com/vllm-project/vllm/pull/60545) · state: open · merged: False

## Original PR description

Advantages:
- Avoids most of the N-1 truncation complexity and special case issues that introduces
    - For example related to prompt logprobs
- Avoids redundant computation of last prompt token on D
- Avoids need for MM encoding on D side (cases where we would back-off into image tokens)
    - Which could otherwise impact ITL
    - Can avoid loading mm encoder weights on D for more kv cache capacity
- Preserves target model uniform decode full cuda graphs in multi-module MTP case (which otherwise recompute k-1 prompt tokens)
- Consistency across model/attention types

This implementation stashes the final hidden states (including aux layers and extra positions for eagle3 / multi-module mtp) into kvcache token slots past the end of the prompt. This means:
- Usually zero additional memory or transfer overhead (uses existing block padding)
- Simpler code - we can piggy-back on much of the existing lifecycle logic without needing an additional custom buffer with it's own slot management and nixl registration
- Existing connectors with HMA support need minimal changes

This is tested and working with NIXL, including push/pull and hetero TP. Compatibility with the following will require some additional changes: CP, nixl host-buffer mode, HiSparse. Other P/D connectors also not yet tested.

Thanks to @Dao007forever and @ivanium for help with these ideas.
