# [Bugfix][Pooling] Ignore token stream intervals for pooling

[Upstream PR](https://github.com/vllm-project/vllm/pull/55226) · state: open · merged: False

## Original PR description

<!-- markdownlint-disable -->
## Overview

Prevent a pooling request from crashing AsyncLLM's shared output handler when the server uses `--stream-interval 2` or higher. Apply token-stream interval handling only to generation output.

## Claims

- Completed embeddings and pooling cancellations reach their existing output path without requiring a detokenizer.
- Generation retains its existing interval behavior.
- The production fix changes one condition in the shared OutputProcessor.

## Validation

Validated on 2026-10-10 at published head `b8ea945d51` and in a temporary merge with upstream `276fbcff2717bd934cfa37c8a2e4c391f3e7237b`. The published branch was not rebased.

```sh
VLLM_TARGET_DEVICE=cpu CUDA_VISIBLE_DEVICES='' .venv/bin/python -m pytest tests/v1/engine/test_output_processor.py -q
.venv/bin/pre-commit run --hook-stage manual --files vllm/v1/engine/output_processor.py tests/v1/engine/test_output_processor.py
```

The complete output-processor suite passes **43 tests at the PR head** and **53 on current upstream plus the fix**. All applicable scoped hooks pass. Removing the condition gives **4 failures and 2 passes** for pooling completion/cancellation at intervals 1, 2, and 10 (`AssertionError` at the missing detokenizer).

The requested GPU MRV2 validation was performed on 2026-09-10 and was not repeated in this review. On an RTX 5070 Ti with `Qwen/Qwen3-Embedding-0.6B`, two sequential requests each returned a 1024-dimensional embedding and a four-input batch returned four. Responses and health checks were HTTP 200 with no `AssertionError`; see [the recorded run](https://github.com/vllm-project/vllm/pull/55226#issuecomment-5613201182).

```sh
CUDA_VISIBLE_DEVICES=0 VLLM_USE_V2_MODEL_RUNNER=1 .venv-gpu/bin/python -m vllm.entrypoints.cli.main serve Qwen/Qwen3-Embedding-0.6B --runner pooling --stream-interval 2 --max-model-len 512 --gpu-memory-utilization 0.6 --enforce-eager --port 18002
```

That run used the then-current main merged with this PR and precompiled extensions from its base. Submit two sequential single-input requests and one four-input request to `/v1/embeddings`, checking `/health` before and after.

## Details

Pooling requests have no detokenizer. The token interval branch asserted that one existed before reaching pooling handling, including the empty-tensor cancellation sentinel. In AsyncLLM the assertion terminated the shared handler and affected unrelated pending requests.

Fresh open-PR searches for pooling/stream-interval and detokenizer terms found no duplicate fix. This changes output dispatch, not model arithmetic. Upstream CI remains stopped at the contributor-authorization gate; its skipped checks are not passing validation.

AI assistance was used for investigation, implementation, tests, and review.
