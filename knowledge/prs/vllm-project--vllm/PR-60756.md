## Original PR description



## Overview

The kernel works on gfx950 and is a drop in replacement for fp8_mqa_logits (that's gluon), see [docstring](https://github.com/ROCm/aiter/blob/e6ded2168ef43111c57d591dd310eccdfc27aaf1/aiter/ops/flydsl/fp8_mqa_logits_kernels.py#L481).

**Note**: https://github.com/vllm-project/vllm/pull/60294 and https://github.com/ROCm/aiter/pull/6185 will fix so we don't have to manually select between the gluon and flydsl mqa_logits kernel here from vllm. However those are still wip, so I suggest we move fast and delete the current manual selection once those are merged. I suspect we'd want to use flydsl in most cases anyways

## Claims

- 10-20% improved TTFT
- 5-20% improved throughput at 64k+ ctx
- Unaffected ITL (as expected) 
- Improvements growing with ctx len

## Details

### Before

At 512k ISL, the final chunk's indexer splits the context into **16** chunks and scores+topk's each of them individually. This happens for each of the **11** sparse MLA layers. These kernels execute in
- mqa_logits: ~800us
- indexer topk: 1.9ms

Hence we spend `800us * 11 * 16 = 140ms` on topk only, The full forward takes 800ms, so 18% of chunked prefill is spent just computing indexer logits!
