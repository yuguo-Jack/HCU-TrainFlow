# [Perf][Distributed] Skip movedim+reshape for dim=0 in CudaCommunicator all_gather

[Upstream PR](https://github.com/vllm-project/vllm/pull/61136) · state: open · merged: False

## Original PR description

## Overview

Skip redundant `movedim` + `reshape` tensor view operations when `dim=0` in `all_gather` and `reduce_scatter`, the common case for sequence parallelism.

## Claims

- Eliminates 2-3 redundant tensor view operations per `all_gather(dim=0)` call
- Eliminates 2 redundant `movedim` + `contiguous` calls per `reduce_scatter(dim=0)` call
- These are on the TP forward pass hot path (2N calls for N-layer models)

## Validation

- `ruff check` and `ruff format --check`: all passed
- Logic verification: when `dim=0`, `movedim(0, 0)` returns the same tensor (no-op), and `reshape` produces the same shape — skipping them is behavior-preserving

## Details

`all_gather` with `dim=0` performs:
1. `output_tensor.reshape((world_size,) + input_size)` — creates a view
2. `output_tensor.movedim(0, 0)` — no-op, returns same tensor
3. `output_tensor.reshape(output_size)` — same shape as before step 1

All three are redundant when `dim=0`. Return `output_tensor` directly after `all_gather`.

`reduce_scatter` with `dim=0` performs:
1. `input_.movedim(0, 0).contiguous()` — movedim is no-op, contiguous returns same tensor if already contiguous
2. `output.movedim(0, 0).contiguous()` — same

Skip both movedim calls and only call `.contiguous()` on the input (needed for correctness regardless of dim).
