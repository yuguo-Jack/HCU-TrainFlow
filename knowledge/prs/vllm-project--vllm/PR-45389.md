# [Bugfix][ToolParser] Handle braces in required tool streaming strings

[Upstream PR](https://github.com/vllm-project/vllm/pull/45389) · state: closed · merged: True

## Original PR description


## Purpose

Related: #41111. In required `tool_choice` streaming, vLLM trims streamed tool-call JSON by counting the wrapper's bracket level. The counter currently treats `{` and `}` inside JSON string values as structural braces, so a valid generated argument such as `{"city": "a } b"}` can be emitted to the client as malformed `function.arguments`.

This PR makes that bracket scan JSON-string aware. It also keeps the initial `"parameters"` substring extraction caller-aware: true stream continuations carry string and escape state forward, while the first extracted parameter substring is scanned with its preceding prefix as context. The existing greedy `"parameters"` match stays in place so multi-tool streaming keeps selecting the latest parameter segment.

This is not the same bug as #45310. #45310 fixes the Hermes `</tool_call>` tag boundary; this PR fixes the generic required-tool wrapper trimming helper used after required-tool JSON has already been generated.

Client trigger. The tool schema constrains the model to produce one exact `city` value. The test sends both a non-streaming request and a streaming request for each value, then parses the returned tool arguments with `json.loads`.

```python
import json
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="EMPTY")
model = "Qwen/Qwen3-0.6B"

def check_city(city: str):
    tools = [{
        "type": "function",
        "function": {
            "name": "get_current_weather",
            "description": "Get the current weather in a city",
            "parameters": {
                "type": "object",
                "properties": {"city": {"type": "string", "enum": [city]}},
                "required": ["city"],
            },
        },
    }]
    request = {
        "model": model,
        "messages": [{"role": "user", "content": f"Call the weather tool for {city}."}],
        "tools": tools,
        "tool_choice": "required",
        "temperature": 0.0,
    }

    response = client.chat.completions.create(**request)
    args = response.choices[0].message.tool_calls[0].function.arguments
    assert json.loads(args) == {"city": city}

    stream = client.chat.completions.create(**request, stream=True)
    streamed_args = ""
    for chunk in stream:
        for tool_call in chunk.choices[0].delta.tool_calls or []:
            if tool_call.function and tool_call.function.arguments:
                streamed_args += tool_call.function.arguments
    assert json.loads(streamed_args) == {"city": city}
    return streamed_args

for value in ("a { b", "a } b"):
    print(value, check_city(value))
```
