# [Bugfix][Spec Decode] Relay Qwen3.5 auxiliary states over PP

[Upstream PR](https://github.com/vllm-project/vllm/pull/61180) · state: open · merged: False

## Original PR description

## Overview

Enable Qwen3.5 to relay ordered EAGLE3 and DFlash auxiliary hidden states across pipeline-parallel stages. Fixes #60765.

## Claims

- Opt `Qwen3_5Model` into auxiliary hidden-state transport over pipeline parallelism without enabling the broader Qwen3Next family.
- Pack stage-local auxiliary states into `IntermediateTensors` and collect upstream states in global layer order.
- Configure per-stage auxiliary-state slots through `EagleModelMixin._set_aux_hidden_state_layers()`.
- Preserve existing PP1 and no-auxiliary-state behavior.
- Raise an explicit error when an expected upstream auxiliary-state slot is missing instead of silently dropping it.

## Details

`Qwen3NextModel.forward()` captured stage-local auxiliary states but did not include them in `IntermediateTensors` on non-final pipeline stages or collect upstream states on the final stage. In addition, the Qwen3.5 text model assigned the requested layer tuple directly, bypassing the `EagleModelMixin` metadata used to map global auxiliary-state positions to stage-local transport slots.

This change reuses the existing `EagleModelMixin` pack-and-collect contract in the shared Qwen3Next forward path while enabling cross-stage transport only for `Qwen3_5Model`. Focused tests cover PP2 global ordering, missing upstream slots, PP1 behavior, and the no-auxiliary-state path.
