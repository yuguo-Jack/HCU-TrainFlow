# [Bugfix][RL] Load GPT-OSS attention sinks through weight_loader in all quant paths

[Upstream PR](https://github.com/vllm-project/vllm/pull/57805) · state: closed · merged: False

## Original PR description

Fix all three GPT-OSS attention sink loading paths: `_load_weights_mxfp4`, `_load_weights_quark`, and `_load_weights_other`. Each path now obtains the parameter's current loader through the existing `_get_weight_loader` helper and passes it the local sink slice.



The MXFP4 path also records the sink in `loaded_params`. This PR changes only `gpt_oss.py`.
