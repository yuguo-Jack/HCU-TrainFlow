# [KV Offload] Add compact filesystem files

[Upstream PR](https://github.com/vllm-project/vllm/pull/58595) · state: open · merged: False

## Original PR description

Related to #56871 and #56953, this complements the CPU allocation fix by removing unused padding from filesystem files for unequal cache groups. It adds opt-in `compact_groups: true` for supported packed BLHNC layouts without changing CPU storage; the extra copies can slow reloads, so it defaults to `false`.

## Tests

- 1× NVIDIA H200: 228 focused and compatibility tests passed.
- Synthetic GPU → CPU → filesystem → CPU → GPU roundtrip passed with exact KV bytes; the smaller group's file fell from 408 to 256 KiB, and the two-file total from 816 to 664 KiB.
- Local O_DIRECT reload microbenchmark, 32 files: 102 → 83 MiB, but median reload rose from 42.59 to 62.09 ms, supporting the opt-in default.
