## Original PR description

## Purpose

A parser that identifies reasoning or tool-call boundaries by token ID can miss a boundary emitted as ordinary vocabulary tokens, even when the decoded text looks correct. Explain this contract for custom grammars and show XGrammar token-level structural tags. Qwen3 is the concrete example. Related to #58105.

The warning is under Reasoning Outputs. Tool Calling links to it from Automatic Function Calling, before the model-specific sections. Runtime parsing is unchanged.
