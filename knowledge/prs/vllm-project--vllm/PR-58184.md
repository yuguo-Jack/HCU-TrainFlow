# [Bugfix][Model] MiMo-V2: skip fused fp8 qkv_proj tensors for layers the model does not have

[Upstream PR](https://github.com/vllm-project/vllm/pull/58184) · state: open · merged: False

## Original PR description

## Overview

Skip fused fp8 `qkv_proj` checkpoint tensors for decoder layers the `MiMoV2Model` instance does not have, as every other branch of `load_weights` already does. Related: #58142 (same loader, pending-pair state across calls).

## Claims

- A checkpoint with more decoder layers than the instance, e.g. `--hf-overrides '{"num_hidden_layers": N}'`, no longer fails engine init with `AttributeError: ModuleList has no attribute 'N'` in `_try_load_fp8_qkv_proj`.
- One regression test through `MiMoV2Model.load_weights` guards this fix and #58142.

## Validation

`tests/models/quantization/test_mimo_v2_qkv_shard.py::test_load_weights_pairs_split_fp8_qkv_proj_and_skips_absent_layers` builds a one-layer `MiMoV2Model` and calls `load_weights` twice. The present layer's `weight` / `weight_scale_inv` pair is split across the calls, and an absent layer's pair arrives within the first. The test asserts the returned loaded set, the dequantized values of the loaded layer against the unquantized source (existing helpers in the file), and an empty `_pending_fp8_qkv_proj`.

```
pytest tests/models/quantization/test_mimo_v2_qkv_shard.py -q
```

CPU only (macOS arm64, Python 3.12, torch 2.13.0, `uv` venv with this tree on `PYTHONPATH`):

| `mimo_v2.py` | result |
|---|---|
| `main` (`cc9b0f097d`) | 1 failed, 19 passed: `AttributeError: ModuleList has no attribute '7'` |
| this PR with #58142's persistent pending dict reverted | 1 failed, 19 passed: the split pair is dropped |
| this PR | 20 passed |

`ruff check` / `ruff format --check` (0.14.0) clean on both files. CI runs this file in the Quantized Models step.

End to end, on an earlier head with the same fix (`a1538ff185`): `XiaomiMiMo/MiMo-V2.6-Pro-RL` with `--hf-overrides '{"num_hidden_layers":16}'` loads and serves on one GB300. Output is garbage, as expected for a truncated model, but it boots.

Model evaluation: not applicable. The new branch only runs for a checkpoint tensor with no matching parameter, which a full-depth model never has (pipeline-parallel missing layers are caught earlier by `is_pp_missing_parameter`), so the weights loaded for full models are unchanged.

Not a duplicate: no other open PR changes this path. #46755 adds fused fp8 `qkv_proj` loading to the MTP loader (`mimo_v2_mtp.py`), not `MiMoV2Model.load_weights`.

## Details

`_try_load_fp8_qkv_proj` buffers a layer's fused `qkv_proj` weight and scale until both arrive, then calls `self.get_submodule(<layer>.self_attn)`. For a layer the instance does not have, that raises. Since #58142 made the pending dict persist across `load_weights` calls, a lone absent-layer tensor would otherwise also stay pending for the model's lifetime. The fix returns early when `<prefix>.weight` is not in `params_dict`, matching the expert and generic branches. Truncated boots take minutes instead of hours, which is what makes bisection on this model family practical (context: #58142, https://al-engr.com/gb300-mimo-v26-pro-testing.html).
