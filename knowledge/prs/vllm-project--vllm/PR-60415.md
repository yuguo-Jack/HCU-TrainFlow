# [Model] Add zerank-2 reranker

[Upstream PR](https://github.com/vllm-project/vllm/pull/60415) · state: closed · merged: True

## Original PR description

## Purpose

Add a score template for [zerank-2](https://huggingface.co/zeroentropy/zerank-2-reranker) (ZeroEntropy, Qwen3-4B based, Apache 2.0), next to the existing Qwen3 / mxbai / nemotron templates.

- `examples/pooling/score/template/zerank2.jinja`: query in the system turn, document in the user turn, assistant suffix emitted unconditionally (score templates are rendered without `add_generation_prompt`, and zerank-2's own `chat_template.jinja` only emits the suffix when it is set, see #60409). Supports the `instruction` request field; without it, the prompt is exactly the official one.
- `using_template_online.py` / `using_template_offline.py`: add `polaria-tech/zerank-2-reranker-vllm`, a `Qwen3ForSequenceClassification` conversion of zerank-2 (single `Yes` token, head scaled by 1/5 so the default sigmoid returns zerank-2's calibrated `sigmoid(logit / 5)`).
- `docs/models/pooling_models/scoring.md`: list the model and template.

Docs and examples only, no code change.

## Test Plan

Parity against the official `CrossEncoder("zeroentropy/zerank-2-reranker").predict()`, with an fp32 ground truth, on vLLM 0.29.0 and 0.31.0 (H100, bf16, `--chat-template` with this template): 47 pairs from 19 to 38k tokens, mixed lengths per batch.

## Test Result

- Prompt token ids identical to the official path on 47/47 pairs.
- Max deviation from fp32: 0.095–0.136 logit for vLLM vs 0.183 for the official bf16 path itself (0-1 score: 0.0040 vs 0.0053).
- Without the template: mean error 11.4 logit; with zerank-2's own `chat_template.jinja`: 9.9.

Method and scripts: https://github.com/polaria-tech/zerank-2-reranker-vllm/blob/main/NOTES.md

Happy to add an MTEB test under `tests/models/language/pooling_mteb_test/` if you'd like one for this model.

Added `tests/models/language/pooling_mteb_test/test_zerank.py`, following `test_qwen3_reranker.py`. The HF reference loads the original `zeroentropy/zerank-2-reranker` causal LM (the converted checkpoint has no `lm_head`) and scores the `Yes` token logit, which ranks identically to the converted head's `sigmoid(logit / 5)`.

Run on H100 with vLLM `81198e97`:
```
VLLM: dtype:torch.bfloat16 head_dtype:torch.float32 0.34282
SentenceTransformers: torch.float32 0.34305
Difference: 0.00023
PASSED
```
`mteb_score` is set to the fp32 reference (0.34305). Note it's a 4B model, so I left `enable_test=True` like Qwen3-Reranker-0.6B; happy to switch it to `False` if it's too heavy for CI.
