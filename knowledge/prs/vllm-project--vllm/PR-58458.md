# [Bugfix] Ignore DeepSeek V4 thinking sampling overrides

[Upstream PR](https://github.com/vllm-project/vllm/pull/58458) · state: open · merged: False

## Original PR description




## Purpose
Fixes #58155 
DeepSeek V4 thinking mode accepts `temperature`, `presence_penalty`,
and `frequency_penalty` for API compatibility but should ignore them.

This change ignores those request overrides only when:

- The resolved architecture is DeepSeek V4.
- Thinking mode is enabled.

Other models and DeepSeek V4 non-thinking requests retain their existing
sampling behavior.

No existing open PR was found for #58155 or this sampling behavior.
