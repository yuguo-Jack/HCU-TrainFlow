# [Frontend] Add cache salt support to generative scoring

[Upstream PR](https://github.com/vllm-project/vllm/pull/60841) · state: closed · merged: True

## Original PR description

## Overview

`/generative_scoring` now accepts `cache_salt` and applies it to every item's prompt, allowing prefix-cache reuse to be scoped by salt in multi-tenant deployments.

## Claims

- Validates `cache_salt` with the shared validator and passes it to every item's engine input.
- Preserves the existing behavior when `cache_salt` is omitted or `null`.

## Validation

- Generative-scoring tests and shared request-validation tests passed.
- Ran `Qwen/Qwen3-0.6B` locally and sent HTTP requests to `/generative_scoring`. Verified cache reuse with the same salt, no reuse between different salts, and the same scores across these requests.

## Details

The request model did not expose `cache_salt`, and prompts were built without it. This change reuses the shared validator and the existing `tokens_input` support.
