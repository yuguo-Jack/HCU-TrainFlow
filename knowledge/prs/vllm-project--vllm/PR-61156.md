# [EP] Bound NIXL EP dispatch capacity

[Upstream PR](https://github.com/vllm-project/vllm/pull/61156) · state: open · merged: False

## Original PR description

Depends on #60900. Follow-up to [@itayalroy's request](https://github.com/vllm-project/vllm/pull/60900#pullrequestreview-5476763020).

Cap NIXL EP dispatch at 1,024 tokens per rank and reuse the synchronized chunking path for larger batches. This bounds RDMA buffers and expert workspaces independently of the scheduler batch size.

## Tests

2× H100 80GB, Qwen3-30B-A3B BF16, EP2/DP2, 4,096 batched tokens, nightly binaries, with #60900 applied:

- Uneven-rank dispatch and CUDA-graph replay matched the reference.
- Per GPU: RDMA buffer 8.12 → 2.03 GiB; KV cache 20.24 → 30.00 GiB.
- Sampled GSM8K: 60/64 → 59/64.
- C8, input/output 2048/128, three runs: throughput 143.6 → 129.2 tok/s; median TTFT 0.70 → 0.90 s.
