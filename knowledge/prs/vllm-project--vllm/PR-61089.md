# [Bugfix][Frontend] Forward --enable-log-outputs to the Cohere Chat v2

[Upstream PR](https://github.com/vllm-project/vllm/pull/61089) · state: open · merged: False

## Original PR description

`--enable-log-outputs` / `--enable-log-deltas` are silently ignored for `/cohere/v2/chat`.
Same fix as #60982 (Anthropic, #60971), applied to the Cohere handler.

With this PR, `/cohere/v2/chat` now honors `--enable-log-outputs` and `--enable-log-deltas`.

## Validation

    .venv/bin/python -m pytest -q tests/entrypoints/cohere
    215 passed, 12 errors

The 12 errors are GPU-only setup errors, with identical per-test results on unmodified `main`.
I did not run the tests on a GPU machine. 

## Details

`CohereServingChatV2.__init__` didn't accept the two flags and `init_generate_state` didn't pass them, so they kept the `OpenAIServingChat` defaults.
