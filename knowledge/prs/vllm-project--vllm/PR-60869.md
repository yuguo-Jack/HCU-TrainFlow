# [HiSparse] Prefault the shared host pool in parallel

[Upstream PR](https://github.com/vllm-project/vllm/pull/60869) · state: open · merged: False

## Original PR description

Related to #60072. Depends on #59545.

HiSparse prepares its shared host pool on one TP worker. Reuse the helper from #59545 to split page preparation across TP workers and synchronize before CUDA registration.

## Tests

- 4 H200s, 128 GiB pool: 52.9 → 34.2s and 48.7 → 32.0s, about 35% faster on average. Shared-memory GPU data checks and cleanup passed.
- `pytest tests/v1/worker/test_utils.py tests/v1/kv_offload/cpu/test_shared_offload_region.py -q`: 108 passed.

Component timing only; full GLM startup savings have not been measured.
