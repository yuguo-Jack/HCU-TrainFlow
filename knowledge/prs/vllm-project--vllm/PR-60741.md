# [Kernel][HYV4] CUDA fused iHC boundary op (post -> pre -> RMSNorm)

[Upstream PR](https://github.com/vllm-project/vllm/pull/60741) · state: open · merged: False

## Original PR description

## Purpose

**Depends on #58581** (cross-layer iHC fusion). Until it merges, this diff includes its commit; review only the last commit.

Adds a vLLM CUDA op, `torch.ops._C.hy_v4_ihc_boundary`, as an alternative to HPC's `fuse_ihc_post_pre` and `fuse_ihc_pre`. It follows the design of TRT-LLM's fused mHC kernel (`cpp/tensorrt_llm/kernels/mhcKernels`). On SM90+ builds `CudaIHCPostPre` is preferred over `HpcIHCPre` / `HpcIHCPostPre`, so the cross-layer schedule from #58581 no longer requires the external `hpc-ops` wheel.

The op runs two kernels per boundary:
- **Statistics kernel.** A CTA owns 16 tokens and one split of the 4 × hidden reduction. It applies the post step, stores the new residual, and computes the per-split sums of squares and the 8 gate projections. The projections run on tensor cores (`mma.sync` m16n8k16, N = 8 gates). The FP32 weight is split into three BF16 parts (hi + mid + lo), so the products equal FP32 products. Weight tiles are shared by the 16 tokens.
- **Finish kernel**, one CTA per token. It sums the splits in a fixed order, so results are deterministic. Then it computes the gates, the gated reduction and the RMSNorm.
- Both kernels launch with PDL.

## Numerics
Direct comparison with `hpc.fuse_ihc_post_pre` / `fuse_ihc_pre` on identical inputs (hidden 4096/6144, 1–8192 tokens, both forms):
- **Residual:** 100% bitwise equal. The post step is one FMA, so the new residual is the exact result rounded to BF16.
- **Hidden state:** 99.97–100% bitwise equal, relative L2 ≤ 3e-5 (FP32 summation order). By default the gated reduction enters the RMSNorm in FP32, like the HPC kernel; `round_before_norm=True` rounds it to BF16 first, like the unfused Triton path.
- **Gates:** max difference ≤ 1.1e-6.

## Test Plan
- `pytest tests/kernels/test_hy_v4_ihc_boundary.py`: compares the op with the unfused Triton pre + RMSNorm on the same residual, and the post step with an FP64 reference, across hidden sizes, split-count boundaries and offset views, in both rounding modes; checks determinism.
- Kernel benchmark and end-to-end PCP4 prefill on GB300 (below).
