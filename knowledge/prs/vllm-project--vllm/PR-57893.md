# [Perf][DSv4.1] Speed up small Engram lookups

[Upstream PR](https://github.com/vllm-project/vllm/pull/57893) · state: open · merged: False

## Original PR description

## Overview

Use two-row tiles for small Engram lookups, retaining the persistent 16-row path for larger batches. Complements #59327's sorted host lookups.

## Claims

Historical GB300 results: 1/2/4-user lookup kernels improved 6.1%/19.4%/28.1%. Six balanced serving pairs measured +0.11% throughput (95% CI −1.55% to +1.80%): no demonstrated serving gain.

## Validation

Refreshed onto main `b0b23a48d4`. GB300, NGC 26.08: 64 isolated production-lookup cases passed, including host/HBM, sorting, padding and graph replay; both benchmark capture variants passed. Fixed the benchmark's stale kernel arguments. Ruff and Linux-targeted mypy passed. The Mac pre-commit type check hits main’s existing Linux-only `mmap.MADV_HUGEPAGE` constant. These checks do not replace the full integration suite or repeat the historical performance measurements.

## Details

The kernel math is unchanged. Small batches spread across more SMs; larger batches keep the existing launch policy. AI-assisted update; draft retained for review.
