# [Model Loader] Apply EP weight filtering in InstantTensor

[Upstream PR](https://github.com/vllm-project/vllm/pull/61167) · state: open · merged: False

## Original PR description

## Overview

Apply EP weight filtering before InstantTensor I/O. Depends on scitix/InstantTensor#29 and its release; dependency pin pending.

## Claims

Skip non-local expert payloads while retaining scales, shared experts, and fused tensors. Unfiltered loading is unchanged.

## Validation

H100: `python -m pytest --noconftest -q tests/model_executor/model_loader/instanttensor_loader/test_weight_utils.py tests/model_executor/model_loader/test_ep_weight_filter.py` — 41 passed.

Tiny Qwen2MoE filtered-path smoke test: identical tokens and top-5 logprobs to safetensors for 2 prompts × 8 tokens, with all four experts selected on one GPU. Multi-GPU EP remains untested. Pre-commit checks and Linux-target mypy passed; macOS mypy hits two existing `posix_fadvise` errors.

## Details

11 production lines reuse the existing EP predicate. Filtered ranks load independently because NCCL loading requires identical layouts. #58016 covers the standard safetensors reader, rather than InstantTensor.
