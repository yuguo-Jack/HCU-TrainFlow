# [Frontend] Condition /v1/translations on the requested target language

[Upstream PR](https://github.com/vllm-project/vllm/pull/58174) · state: closed · merged: False

## Original PR description

Conditions the text `/v1/translations` endpoint on the requested target language for encoder-decoder MT models.

On the direct-generate path, the request's `target_language` is forwarded as the decoder prompt so the model's own `create_decoder_prompt` hook selects the output language:
- NLLB / M2M100 resolve the code to a `forced_bos_token_id`.
- A bilingual MarianMT implies the target and ignores it.

An unsupported code is rejected with a **400** before generation via `_validate_target_language`, which resolves the code through the model's own processor. A `ValueError` raised during `generate` is also mapped to 400 as a backstop.

Adds 5 GPU-free unit tests (target-language forwarding, pre-validation reject/allow, skip without renderer, ValueError→400).

> Stacks on #58111; review that first. Streaming for this path lands in a follow-up.
