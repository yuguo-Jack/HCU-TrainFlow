# Add sglang-explainer-video: SGLang PR / article → bilingual explainer video

[Upstream PR](https://github.com/BBuf/AI-Infra-Auto-Driven-SKILLS/pull/101) · state: closed · merged: True

## Original PR description

## What

New skill `skills/sglang-explainer-video/`: send it an SGLang PR number (or a Markdown article path) and it produces a 1–3 min **Chinese explainer video** with word-synced **中文 / English captions**, the unified **SGLang cover**, and SGLang-brand visuals, delivered to `~/Desktop` together with a still cover PNG.

It drives HyperFrames' `pr-to-video` workflow (heygen-com/hyperframes, pinned at `d0b551d0`) and packages every fix needed to make it work for Chinese, so a fresh Claude session can reproduce the whole flow from `SKILL.md`.

## Pieces

| Path | Role |
| --- | --- |
| `SKILL.md` | Step-by-step flow for PR mode and article mode (ingest → brand → story/script → TTS → visual design → cover → captions → ≤3 frame workers → lint/check → render → frame-by-frame QA → Desktop) |
| `references/house-style.md` | User-confirmed rules: English technical terms (kernel, batch, mixed chunk…), Yunyang voice, bilingual captions, cover A spec, author page (name not spoken), never state PR status |

| `references/troubleshooting.md` | Every failure seen while building this, with the fix |

| `scripts/edge_tts_engine.{py,mjs}` | `HF_MEDIA_ENGINE` replacement: edge-tts narration with per-word timings, punctuation re-attached, split terms re-joined (FP32, FLUX.2, torch.equal), closing pad, 403 workaround (rany2/edge-tts#491) |
| `patches/hyperframes-captions-cjk-bilingual.patch` | `captions.mjs`: clause-level CJK grouping, CJK-aware joining, optional `caption-translations.json` English line |
| `assets/caption-skin.html` | Caption skin: no inter-word gap for Chinese, English line under the karaoke line, bundled Noto fonts |
| `scripts/make_cover.py` | The fixed cover (design A, brand orange): video frame 1 (caption-safe, seek-safe) + still PNG |
| `scripts/apply_brand.py` | SGLang palette remixed onto the code-editorial preset, caption skin, logos |
| `scripts/subset_fonts.py` | Noto Sans/Serif SC subsets for every rendered glyph (no `local()` fonts — they garble in Studio) |
| `scripts/check_frames.mjs`, `retime_frames.py`, `qa_sheet.sh` | Frame-contract + font check, re-timing frames to a new narration take, contact sheets of the rendered MP4 |
