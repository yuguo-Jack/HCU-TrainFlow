**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Preserve disabled bias correction in the custom AdamW path**

When the vendor `custom_ops` kernel is present and a user constructs `FusedAdam(adam_w_mode=True, bias_correction=False)`, these values are nevertheless `beta**step`; the `optimizer_AdamW` call below has no `bias_correction` argument, so this path cannot honor the disabled correction while the fallback explicitly substitutes `1.0`. This silently changes valid optimizer configurations and training results, so bypass this kernel or pass correction-neutral powers when correction is disabled.

**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Synchronize host timers before reading KLXPU time**

With `XPU_EVENT_KL3_ENABLE` unset, this default makes `SynchronizedWallClockTimer.Timer.start/stop` take plain `time.time()` readings (`deepspeed/utils/timer.py:63-77`) without synchronizing. Because KLXPU inherits CUDA's asynchronous `is_synchronized_device=False`, kernels can remain queued when the stop timestamp is captured, turning wall-clock and communication measurements into enqueue latency rather than execution latency; the host-timer path needs device synchronization or a functional event-based replacement.
