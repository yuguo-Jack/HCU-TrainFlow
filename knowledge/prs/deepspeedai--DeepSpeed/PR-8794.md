# Reduce unnecessary CI work for documentation changes and consolidate agent instructions in AGENTS.md

[Upstream PR](https://github.com/deepspeedai/DeepSpeed/pull/8794) · state: closed · merged: True

## Original PR description

Documentation changes should not consume expensive CPU/GPU CI capacity or expand test selection for unrelated code changes. This PR avoids that unnecessary work while preserving coverage and required CI safeguards.

• Share documentation detection across CI gates and the Modal selector:  `docs/** `,  `blogs/** `, and ` .md`  files anywhere. Documentation in mixed PRs doesn't widen GPU test selection.
• Skip CPU/GPU suites, Python install smoke, and native-op precompilation for documentation-only PRs and merge-queue entries. Preserve scheduled/manual runs and required status reporting.
• Run the gate from the base revision. Compare PR merge commits against their first parent to avoid counting upstream changes when ` pull_request.base.sha ` is stale. Preserve rename/deletion handling and conservative failure fallbacks, with a bounded gate timeout.
• Exclude Markdown from the optional MPS and no-torch PR triggers. Run lightweight gate/selector self-tests and README validation independently in the required formatting workflow.
• Update CI documentation and consolidate agent guidance in ` AGENTS.md `, removing duplicate ` CLAUDE.md ` because Claude code now support agents.md. 

Only active workflows are changed; disabled legacy workflows remain untouched.
