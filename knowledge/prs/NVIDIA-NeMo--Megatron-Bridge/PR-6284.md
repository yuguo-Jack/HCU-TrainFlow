# feat: add DiffusionGemma support

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6284) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Adds Megatron Bridge conversion, inference, and block-diffusion SFT support for the public `google/diffusiongemma-26B-A4B-it` checkpoint.

# Changelog

- Add a DiffusionGemma HF ↔ Megatron bridge with exact checkpoint tensor coverage.
- Add the DiffusionGemma provider and multimodal encoder/decoder model.
- Add block-diffusion SFT losses: `base-sft`, `reweighted-ce`, `loo-ce`, and `reweighted-loo-ce`.
- Add uniform-state corruption, detached two-pass self-conditioning, and an optional clean-target encoder loss.
- Support tensor parallelism with sequence parallelism, expert parallelism, and the distributed optimizer.
- Fix Gemma 4 global-attention masking so global layers do not inherit local sliding-window limits.
- Add a JSONL message/completion dataset adapter with explicit train/validation/test splits and multi-block completion handling.
- Add an EP=8 26B SFT recipe with full activation recomputation enabled by default for long multimodal contexts.
- Add docs, example validation scripts, unit tests, and functional tests.

# Validation

- DiffusionGemma unit tests: 20 passed.
- Gemma regressions: 305 passed, 2 skipped.
- Gemma-VL regressions: 207 passed.
- Functional tests: 4 passed on 2 GPUs.
  - Tiny HF/Megatron loss, logits, and gradient parity, including a prompt crossing the sliding-window boundary.
  - TP=2 and EP=2 parity.
  - `pretrain()` save at step 3 and fresh-process resume; resumed losses, gradient norms, and sample counters exactly match an uninterrupted run.
- Real 26B FP32 HF ↔ Megatron parity passes for synthetic text and image prompts.
- Real 26B BF16 one-GPU training step passes.
- Real 26B EP=8 three-step training loop passes with the distributed optimizer; peak rank-0 allocation was 83.6 GiB.
- Long-context multimodal recipe smoke passes with activation recomputation; peak rank-0 allocation was 123.8 GiB. The same synthetic example without recomputation runs out of memory on H200.

These checks validate conversion, numerical parity, and training mechanics. They do not claim task quality on any downstream dataset.
