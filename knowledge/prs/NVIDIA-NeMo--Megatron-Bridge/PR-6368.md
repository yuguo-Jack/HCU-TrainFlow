# fix(qwen3-asr): restore vendored generation on transformers 5

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6368) · state: closed · merged: True

## Original PR description

# What does this PR do?

Restore construction, forward passes, generation and checkpoint reload for the vendored Qwen3-ASR classes on Transformers 5.15–5.17. Direct construction currently fails on the missing `pad_token_id`; correcting that alone exposes removed RoPE, masking, generation and checkpoint APIs.

Fixes NVBug 6900515.

# Changelog

- Use the current RoPE and causal-mask APIs and the existing `GenerationMixin` input preparation.
- Derive positions from the current request and cache, preserving padding and explicit positions across repeated requests.
- Update tied-weight metadata and reconstruct the deterministic audio position buffer when loading checkpoints.
- Add numerical regression tests for text/audio generation, cached versus full-prefix logits, native Qwen3 shared-weight comparison, RoPE, padding, weight sharing and checkpoint reload.

# Validation

- Untouched source reproduces the constructor failure; controlled staged checks reproduce all reported API failures. All 20 initial regressions fail before the fix.
- 47 focused CPU tests pass on each of Transformers 5.15.0, 5.16.0 and 5.17.0 (22 new numerical regressions plus 25 adjacent configuration/Bridge tests; 141 executions), with no skips. New audio reload checks fail before the targeted buffer fix and pass afterward, including exact FP32/BF16 encoder outputs, buffers and logits with matching casts.
- Direct reported model APIs: one-layer FP32 and two-layer BF16 construction, finite/nonconstant logits, deterministic cached/uncached generation and exact parameter reload. BF16 exact-logit reload comparisons apply the same whole-model cast to both models; dtype-only loading retains FP32 rotary and audio position buffers.
- `uv run --no-sync pre-commit run --all-files` and `git diff --check` pass.
- Strict local mypy remains non-clean: 85 diagnostics versus 86 on baseline using the same flags. Existing vendored annotations and unavailable dependency types limit this check.
- The full conversion launcher remains unverified because its dataset fixture requires network access. This PR does not promote that launcher from flaky or claim GPU execution or trained-model transcription quality.
