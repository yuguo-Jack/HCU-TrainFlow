[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6332) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Fixes the published BERT example `examples/models/bert/megatron-bert/conversion.sh` exiting 2 on its first command: it still called `examples/conversion/convert_checkpoints.py`, removed in #4873.

# Changelog

- `examples/models/bert/megatron-bert/conversion.sh`: import and export steps now call `./scripts/conversion/convert.sh` (same migration #4873 applied to the other model examples); flags unchanged.
- `tests/unit_tests/doc_consistency/test_readme_consistency.py`: add `test_model_example_scripts_reference_existing_conversion_scripts` (every `examples/conversion/.py` path used by an `examples/models/**/.sh` script must exist).

# Additional Information

- Root cause: #4737 (BERT) was developed before #4873 deleted `convert_checkpoints.py` and was never migrated.
- Regression: no — broken since BERT support merged (efb58880).
- Verification: new test fails on main, passes with the fix; on H100 the real `conversion.sh` now completes, round-trip 394/394 weights match.
- Pre-existing, unrelated: `test_readme_supported_models_table_lists_every_shipped_model_family` already fails on main (no bagel / muse_glimmer row).
- QA: NVBug 6882924.
