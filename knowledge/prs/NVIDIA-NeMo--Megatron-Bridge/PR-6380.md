# docs(model): unpublish Nemotron 3.5 Super VL guides

[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6380) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Unpublish the Nemotron 3.5 Super VL and text-only guides while retaining their Markdown and MDX sources byte-for-byte in GitHub.

# Changelog

- Follow the required precedent, [AutoModel #4254](https://github.com/NVIDIA-NeMo/Automodel/pull/4254), merged into `r0.7.0` as [`7e7c184e26c1365bf5c55fd6fcc57d927619fb8b`](https://github.com/NVIDIA-NeMo/Automodel/commit/7e7c184e26c1365bf5c55fd6fcc57d927619fb8b): remove the guides from Fern navigation to exclude them from publication and redirect their old URLs to an overview while preserving sources unchanged. #4254 is the release cherry-pick of Alexandros Koumparoulis's #4253; their complete diffs are byte-for-byte identical. No source metadata changes are needed.
- Add exact Sphinx exclusions because Bridge also publishes the requested `.html` URLs through its nightly Sphinx pipeline. Remove the two toctree entries and incoming family-index links.
- Filter unpublished guides from the catalog generator's public directory and regenerate both directory formats. Preserve authoritative cards, normalized JSON, model/example code, and both guide sources. The generator change prevents regeneration from restoring broken public links.
- Redirect native Fern and legacy HTML URLs, including unversioned and nightly forms, to the nightly Supported Models page. The frozen default version lacks that landing page.

# GitHub Actions CI

Local validation:

- 23 focused catalog tests passed, including source/navigation preservation and redirect coverage.
- Catalog generator `--check`, `uv run pre-commit run --all-files`, and `git diff --check` passed.
- Pinned Fern 5.40.0 `check --warnings`: zero errors and the same single baseline warning that hosted redirect comparison requires authentication.

- Complete Sphinx renders: 1,069 → 1,067 HTML pages, with exactly the two target pages removed. Their search entries/source downloads and all incoming HTML links are absent. Four MD/MDX source hashes are unchanged; surrounding Nemotron pages render correctly (also inspected in Chrome).
- Full rendered local-link/anchor comparison: zero new failures. Both strict builds report the same single pre-existing warning for an MTP link to an unavailable Megatron-LM submodule file; `-W` therefore exits 1 in both baseline and changed builds.
- Focused Sphinx `linkcheck` passed for the model directory and neighboring Nemotron guides. Unchanged external HTTP(S) URLs were excluded from this focused run.
