[Upstream PR](https://github.com/NVIDIA-NeMo/Megatron-Bridge/pull/6371) · state: closed · merged: True

## Original PR description

# What does this PR do ?

Flatten Nemotron example directories so each model has a direct, importable path under `examples/models/nemotron/`.

# Changelog

- Use Nano, Nano Omni, Super, Ultra, Lightning, Super VL order consistently in example tables, model indexes, navigation, and generated catalog listings.

- Move Nano, Nano Omni, Super, Ultra, Lightning, and Super VL into their model-specific directories. Lightning and Super VL use `nemotron_3_5_*` names.
- Remove the deprecated Nano v2 VL example script and two YAML overrides. Current docs point to the verified `v0.6.0` guide for those historical examples; public model and recipe APIs are unchanged.
- Move the family index up one level and document the intentional example-path break. Public recipes and model conversion entry points are unchanged; all 35 examples for the six requested model families are retained.
- Update current documentation, commands, test discovery, the verification card/catalog, and the skill card. Preserve verified historical branch links and correct archived 0.4.2 commands against that release's actual tree.
- Add package-discovery and repository/link regression checks.

None of the three unit-test shards for this PR's base commit on main ([run 37890877242](https://github.com/NVIDIA-NeMo/Megatron-Bridge/actions/runs/37890877242)) collected anything from that folder. It only passes when invoked by explicit path.

Could you move it to `tests/unit_tests/doc_consistency/`, next to `test_readme_consistency.py`? It's the same depth, so `parents[3]` still resolves to the repo root. I tried the move locally: it gets collected from `tests/unit_tests` and passes there.
