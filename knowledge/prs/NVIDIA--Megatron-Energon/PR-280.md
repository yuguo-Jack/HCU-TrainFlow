# perf(sampler): use Feistel-network permutations for slice shuffling

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/280) · state: open · merged: False

## Original PR description

## Summary

Replaces materialized index permutations in `DatasetSampler` with memory-constant,
RNG-backed permutations based on a Feistel network (`rng.FeistelPermutation`, cycle-walking for
non-power-of-two ranges). This keeps memory usage flat for very large datasets.

## Changes

- `rng.py`: `FeistelPermutation` and helpers.
- `DatasetSampler`: uses the RNG permutation for all slice modes.
- `Sharder`: compact range-based slice offsets for `max_samples_per_sequence=1`.
- `compatibility.md`: documents the permutation as part of the iteration-order surface.

## Compatibility

- `ITERATION ORDER BREAKING CHANGE`: shuffled slice order changes for a fixed seed.

## Tests

- New `test_dataset.TestDataset.test_max_samples_per_sequence_one_uses_compact_indexes`;
  expected orders in existing tests updated.

## Validation

- Full unit test suite on this layer: 141 tests passed (CPU).
- `ruff check`, `ruff format --check`, license headers: clean.
- Sphinx docs build (`-E -a`): no warnings.
