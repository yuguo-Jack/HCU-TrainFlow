## Original PR description

## Keep datasets usable after closing a loader

Fixes for #278.

Closing or garbage collecting a loader closed the caller's dataset for good:

- JSONL datasets could not be iterated again (`ValueError: I/O operation on closed file`), and closing one loader broke a second loader on the same dataset.
- `DatasetSampler` closed its readers only once, so files reopened later were never released.
- `save_state_rank()` after `close()` hung on the stopped workers.
- `.tar.idx` readers, checkpoint queues and iterators without workers were not cleaned up.

### Changes

- **Readers can be reopened:** `IJsonlReader` reopens its file after `close()`, and `ShardInfosITarReader` also closes its `.tar.idx` offset readers.
- **`close()` is idempotent and keeps the dataset usable:** the one-shot `_reader_closed` flag is gone. Wrappers and the sampler close all children/readers, even if one of them fails.
- **One shared close implementation for both loaders:** it finalizes open iterators, stops the workers, closes the checkpoint queues, then closes the dataset.
- **Only an explicit `close()` closes the dataset:** the loaders no longer have `__del__`.
- **A closed loader raises `RuntimeError`** on `__iter__`, `save_state_rank` and `restore_state_rank`.
- **Test:** the mock reader test is replaced by an end-to-end test on WebDataset and JSONL, with 0 and 2 workers. It covers dataset reuse, closing one loader while another iterates, no open files or worker processes after close, and errors from a closed loader.

### Breaking changes

- Garbage collecting a loader no longer closes the dataset's files; call `close()` or use `with`.
- A closed loader cannot be reused; create a new loader for the same dataset.

File: `src/megatron/energon/flavors/webdataset/itar.py` · line None

If closing one cached `.tar.idx` reader raises, this loop stops immediately and the remaining descriptors stay open; the cache also remains populated with closed/stale entries. That contradicts the new best-effort cleanup behavior. Detach the entries first and use `ExitStack` so every close callback runs even when one fails.

- Copilot · comment · 2026-10-07T12:26:54Z · [source](https://github.com/NVIDIA/Megatron-Energon/pull/301#discussion_r4206851342)

File: `src/megatron/energon/flavors/webdataset/itar_reader.py` · line None

Joined WebDatasets still leak their join-index descriptors. They construct `JoinIndexFileITarReader` instances whose `index_reader_cache` contains open `JoinIndexReader.join_index_file` handles, but that sibling class inherits `ITarReader.close()`, which only clears tar files. Please add a reusable `close()` override there that closes and clears every cached join-index reader as well; otherwise the new loader-close contract is incomplete for joined datasets.

This issue also appears on line 471 of the same file.
