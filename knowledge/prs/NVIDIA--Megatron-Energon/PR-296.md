# Preserve partial data across retry-stream reads

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/296) · state: closed · merged: False

## Original PR description

## Summary

Fixes #295.

Accumulate and return every successful short-read chunk, request only the remaining byte count, and count I/O failures separately from successful partial reads. Previously, a backend returning seven bytes per read could make read(20) advance by 70 bytes and return None; other paths returned only the last chunk. This can corrupt indexed tar/sample reads.

Reopening after a transient failure retains the tracked offset and collected prefix. Guard closing the handle when opening itself failed, and retain the ten-failure limit. The public interface, seeking, storage configuration and sample ordering are unchanged.

## Validation

Seven unittest cases use actual local files with a bounded-read wrapper and injected transient errors. They cover exact-sized reads, no overread, many short reads, retry after partial progress, open failures, bounded persistent failures, zero-length reads, EOF, seeking, empty files and extraction of real tar members. The stream and parser implementations are not mocked; only the storage read/open behavior is deliberately fault-injected.

- All seven new cases fail on unchanged develop, with four assertion failures and three exceptions.
- `python -m unittest tests.test_retry_stream tests.test_sample_utils tests.test_file_cache_pool -q`: **16 tests passed**.
- Repository-configured Ruff lint and formatting checks passed for both changed files. The repository license checker passed over tests. Compilation and `git diff --check` passed.

Testing used Python 3.12.11 on macOS CPU. The complete repository suite, remote storage services, multi-worker data loading, GPU decoding and performance benchmarks were not run. The change assumes the underlying file follows the blocking BinaryIO read contract and does not redefine reads after close or seek-error recovery. No dependencies or existing test expectations change.
