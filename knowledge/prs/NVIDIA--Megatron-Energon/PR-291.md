# feat(task_encoder): add finite data processing pipelines

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/291) · state: open · merged: False

## Original PR description

## Summary

Adds an explicit entry point for offline data processing (e.g. tokenization, statistics,
export) that reuses the task-encoder pipeline without training semantics.

## Changes

- `get_processing_dataset(path, ...)`: one finite pipeline over all resolved recipe leaves,
  concatenated in recipe order; blend weights and repetitions are ignored; cooking, encoding and
  post-encoding are applied, without shuffling, packing, batching or repetition.
- `get_processing_datasets(path, ...)`: one pipeline per resolved leaf, paired with its source
  factory.
- `TaskEncoder.build_processing_datasets()` as the overridable hook.
- Docs: new *Data Processing* page.

## Tests

- `test_recipe`: `test_processing_dataset_ignores_recipe_blend_weights`,
  `test_processing_datasets_returns_each_recipe_leaf`.
