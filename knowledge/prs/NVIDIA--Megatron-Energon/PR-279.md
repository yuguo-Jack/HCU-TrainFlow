# refactor(recipe)!: rename Metadataset to Recipe and remove Metadatase…

[Upstream PR](https://github.com/NVIDIA/Megatron-Energon/pull/279) · state: open · merged: False

## Original PR description

## Summary

Renames the dataset composition layer from *Metadataset* to *Recipe* and removes the
long-deprecated Metadataset v1 format.

## Changes

- `megatron.energon.metadataset` → `megatron.energon.recipe`; `metadataset_v2.py` → `recipe.py`.
- `MetadatasetV2` → `Recipe`, `prepare_metadataset` → `prepare_recipe`,
  `traverse_metadataset` → `traverse_recipe`, `is_metadataset` → `is_recipe`. The old names
  remain importable with a `DeprecationWarning`.
- Metadataset v1 (`metadataset.py`) and its tests are removed; the relevant v1 tests are folded
  into `tests/test_recipe.py` (renamed from `test_metadataset_v2.py`).
- Docs: `basic/metadataset.md` → `basic/recipe.md`, all user docs updated to Recipe terminology,
  updated data-flow image.
- New *Internals* documentation for the restructured architecture (`code_structure`,
  `dataset_formats`, `savability`, `recipe_checkpoint`, `packing_blending`, `epath_storage`,
  `compatibility`) and a rewritten contributor guide (ruff-based workflow, compatibility labels).

## Compatibility

- `API BREAKING CHANGE`: Metadataset v1 is removed; `MetadatasetV2` and the
  `*_metadataset` helpers are deprecated aliases of the Recipe API.
- `RECIPE CONFIG BREAKING CHANGE`: Recipe replaces the legacy Metadataset structure
  (`__class__: MetadatasetV2` still loads via the alias).

## Validation

- Full unit test suite on this layer: 140 tests passed (CPU).
- `ruff check`, `ruff format --check`, license headers: clean.
- Sphinx docs build (`-E -a`): no warnings.
