# [PyTorch][CP][CI] Reset all CP process pools before retrying a failed test

[Upstream PR](https://github.com/NVIDIA/TransformerEngine/pull/3608) · state: closed · merged: True

## Original PR description


# Description

Persistent workers for different world sizes may share GPUs. Restarting only the failed worker can leave CUDA and NCCL state from another pool resident, so the retry starts under the same resource pressure.

Shut down every active pool before retrying. Pool objects remain registered and restart lazily when requested, preserving reuse on the normal path.
