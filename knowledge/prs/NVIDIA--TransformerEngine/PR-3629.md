<a href="#"><img alt="P2" src="https://greptile-static-assets.s3.amazonaws.com/badges/p2.svg?v=9" align="top"></a> **Workspace view can become invalid** If a later operation grows the communicator’s workspace while wgrad still uses this view, cuBLASMp frees the allocation behind it. Wgrad could then read invalid memory. The view does not keep that allocation alive, so its lifetime needs to be protected until consumption finishes.
