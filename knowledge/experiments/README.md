# 模型最终优化里程碑

本目录只保存模型已结束优化阶段的最终总结和关键数据：初始基线、最终配置与关键改动、性能/显存/loss 验收、适用及未达目标的边界。每项结论保留环境、源快照、比较方法和最少充分证据。

当前尚无完成收录验收的最终模型优化总结。正在进行的项目、局部候选、逐次调参和故障过程记录保存在对应 workspace 与看板，不进入共享 Wiki。最终里程碑可以明确保留未实现的整体目标，但不能把中间试验改名当作最终结果。

复用前联查 [环境经验](../sites/README.md)，核对实际部署差异；收录标准见 [知识架构](../../docs/knowledge-architecture.md)。完整 trace、数据、checkpoint 和过程档案留在 workspace。
