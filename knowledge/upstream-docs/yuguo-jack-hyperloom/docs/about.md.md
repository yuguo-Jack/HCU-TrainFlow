# About Hyperloom

Hyperloom is developed by AMD AGI as part of the ROCm platform for autonomous
LLM inference optimization on AMD GPUs.

This page covers Hyperloom's background, licensing, policies, and external resources.

## Policies

The following policies govern contributions and community behavior:

- [Security policy](https://github.com/AMD-AGI/Hyperloom/blob/main/SECURITY.md)
- [Code of conduct](https://github.com/AMD-AGI/Hyperloom/blob/main/CODE_OF_CONDUCT.md)
- [Contributing guidelines](https://github.com/AMD-AGI/Hyperloom/blob/main/CONTRIBUTING.md)

## Resources

The following resources are available if you use or contribute to Hyperloom:

- [Hyperloom repository](https://github.com/AMD-AGI/Hyperloom)
- LLM Gateway: obtain your API key from your organization's LLM gateway.
